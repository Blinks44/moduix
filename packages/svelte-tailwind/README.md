# @moduix/svelte-tailwind

Svelte 5 components built on [Ark UI](https://ark-ui.com/), styled with Tailwind CSS v4.
The adapter is in development and is not published to npm yet.

It follows the same flat component API as the React, Solid, and Vue packages. The npm package will
ship Svelte source compiled by the consumer's Svelte version, so SvelteKit SSR works without a
separate server build.
