## Référence de l’API

Ark UI ne fournit pas de primitive dédiée aux titres. Moduix construit ce composant avec l’[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) officielle et suit les recommandations d’Ark concernant la [composition](https://ark-ui.com/docs/guides/composition), la [personnalisation des styles](https://ark-ui.com/docs/guides/styling) et les [refs](https://ark-ui.com/docs/guides/ref).

## Anatomie

`Heading` ne comporte qu’une partie racine. `Heading.Root` est une forme équivalente avec espace de noms, cohérente avec Ark.

```text
Heading / Heading.Root
└─ text or inline content
```

| Partie                     | Rôle                                                               |
| -------------------------- | ------------------------------------------------------------------ |
| `Heading` / `Heading.Root` | Titre sémantique natif utilisant les styles typographiques moduix. |

## Composition

### Composition recommandée

Utilisez `<Heading>` pour `h1`. Pour un autre niveau sémantique, transmettez `as="h2"` jusqu’à `as="h6"` :

```tsx
<Heading as="h2" size="2xl">
  Page title rendered as h2
</Heading>
```

Utilisez `asChild` uniquement lorsque l’élément enfant sémantique de titre doit posséder le nœud DOM tout en recevant les propriétés du composant, son nom de classe, ses attributs de données et la ref transférée.

### Quand créer une composition personnalisée

Pour les ajustements visuels, utilisez `className` et les variables publiques `--moduix-heading-*`. Utilisez `Text` lorsque le contenu est du corps de texte ou de la typographie générale, et non un titre de document.

### Propriétés par défaut

| Élément     | Valeur par défaut          | Valeurs et remarques                              |
| ----------- | -------------------------- | ------------------------------------------------- |
| element     | `h1`                       | Utilisez `as` pour `h2` à `h6`                    |
| `size`      | selon l’élément affiché     | `xs`, `sm`, `md`, `lg`, `xl`, `2xl`               |
| `weight`    | `semibold`                 | `regular`, `medium`, `semibold`, `bold`            |
| `asChild`   | `false`                    | Composition Ark factory                            |
| `className` | —                          | Appliqué à la racine du titre affiché              |

### Comportement

- La taille visuelle par défaut dépend de l’élément affiché : `h1 -> 2xl`, `h2 -> xl`, `h3 -> lg`, `h4 -> md`, `h5 -> sm` et `h6 -> xs`.
- Une valeur `size` explicite remplace la valeur dépendant de l’élément sans modifier la sémantique.
- La partie racine transfère la ref à l’élément de titre affiché.
- Les titres natifs ne nécessitent aucun attribut ARIA supplémentaire. N’utilisez pas `asChild` avec un élément enfant qui n’est pas un titre.
- `Heading` ne possède ni état, ni callback, ni comportement clavier, ni provider, ni hook de contexte.

### Sélecteurs de style

- `data-scope="heading"` identifie la portée du composant, conformément à Ark.
- `data-part="root"` identifie l’unique partie racine.
- `data-slot="heading-root"` est un sélecteur moduix stable.
- `data-size` est présent lorsqu’une valeur `size` est définie explicitement.
- `data-weight` contient `regular`, `medium`, `semibold` ou `bold`.
- Utilisez `className` et les variables `--moduix-heading-*` pour les ajustements visuels locaux.
