# Code de vérification

Vérifiez une adresse e-mail avec un code à usage unique de six chiffres. `PinInput` fournit le champ
de formulaire natif, la navigation au clavier et le remplissage automatique OTP sur mobile. Envoyez
moins de six chiffres pour afficher l’erreur intégrée au champ.

## Utilisation dans une route

Affichez `VerificationCode` après l’envoi du code par e-mail et transmettez-lui le véritable
gestionnaire d’envoi. `onSubmit` reçoit l’événement natif du formulaire : lisez donc
`new FormData(event.currentTarget)` et vérifiez la valeur `code` auprès de votre serveur. Remplacez
le lien `/sign-in` par la route de votre application.

La prévisualisation ne contient volontairement aucun serveur de vérification. Après six chiffres,
elle exécute son gestionnaire d’envoi vide ; la recette copiée exécute à la place le gestionnaire que
vous fournissez.

Désactivez les vérifications en double tant que la requête est en attente. Pour un code incorrect,
conservez les chiffres saisis et associez l’erreur au champ ; pour un code expiré, expliquez qu’un
nouveau code est nécessaire. Placez le renvoi derrière un court délai, annoncez l’envoi du nouveau
code et laissez le serveur appliquer la véritable limitation de débit. Ne considérez jamais le
compte à rebours côté client comme une autorisation.
