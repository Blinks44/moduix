## Référence de l’API

Ark UI ne fournit pas de primitive `aspect-ratio` dédiée. Moduix construit ce composant avec la
[fabrique Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) officielle et suit les recommandations d'Ark en matière de
[composition](https://ark-ui.com/docs/guides/composition), de [styles](https://ark-ui.com/docs/guides/styling) et de
[ref](https://ark-ui.com/docs/guides/ref).

## Exemple de base

Commencez par `AspectRatio`, mettez width ou max-width sur la racine elle-même et transmettez un positif fini
numérique `ratio`. Les enfants directs `img`, `video`, `iframe`, `canvas` et `svg` remplissent le cadre
automatiquement. Définissez `object-fit` sur les images et les vidéos lorsque vous avez besoin d'un recadrage ou d'un confinement.

## Composition

### Composition recommandée

Utilisez `AspectRatio` pour la plupart des images multimédias. Placez les classes de dimensionnement, de rayon et de disposition sur la racine elle-même ;
`AspectRatio.Root` est la même racine exposée pour la cohérence de l'espace de noms.

- `ratio` est obligatoire et numérique ; passer une valeur finie supérieure à zéro pour un comportement CSS valide
- `asChild` utilise la composition de l'usine Ark et nécessite exactement un élément React
- Les enfants directs `img`, `video`, `iframe`, `canvas` et `svg` remplissent automatiquement le cadre ; ensemble
`object-fit` sur les images et vidéos pour choisir le recadrage ou le confinement
- `className` stylise et dimensionne directement la racine
- `--moduix-aspect-ratio-radius` contrôle le cadre arrondi par défaut

### Quand créer une composition personnalisée

Entourez `AspectRatio` d’un conteneur lorsque les ombres, les anneaux de focus ou d’autres éléments décoratifs doivent dépasser de la zone recadrée.
cadre. Conservez le découpage sur la racine elle-même et remplacez la racine `aspect-ratio` dans votre propre CSS
lorsqu'un point d'arrêt a besoin d'un cadre différent.

### Propriétés par défaut

| Entrée | Par défaut | Valeurs / Remarques |
| ------------------------------ | ------------------------- | ------------------------------------ |
| `ratio` | - | Fini positif requis `number` |
| `className` | `undefined` | Styles et tailles la racine |
| `style` | `undefined` | Peut remplacer `aspect-ratio` directement |
| `asChild` | `undefined` | Composition de l'usine d'arche |
| `--moduix-aspect-ratio-radius` | `var(--moduix-radius-md)` | Longueur CSS ou valeur du jeton |

### Comportement

- La racine s'affiche avec `data-scope="aspect-ratio"`, `data-part="root"` et
`data-slot="aspect-ratio-root"`.
- La racine est au niveau du bloc et utilise le dimensionnement de la bordure, y compris lorsque `asChild` change d'hôte
élément.
- `position: relative` à la racine est intentionnel et prend en charge les modèles enfants à remplissage absolu tels que
comme Next.js `Image fill`.
- Les enfants directs `iframe` remplissent le cadre sans la bordure par défaut du navigateur.
- Les chaînes prédéfinies précédentes (`square`, `video`, `portrait`, `photo`) ont été supprimées lors de l'Ark.
migration. Utilisez des nombres tels que `1`, `16 / 9`, `9 / 16` et `4 / 3`.

### Points d’accroche CSS

- `data-scope="aspect-ratio"` et `data-part="root"` sont les crochets racine alignés sur Ark.
- `data-slot="aspect-ratio-root"` est le hook racine moduix stable.
- Mettez les styles de largeur, de largeur maximale et de mise en page sur la racine elle-même. Remplacez `aspect-ratio` par le vôtre
CSS lorsqu'un point d'arrêt nécessite un rapport différent.
- Les médias directs utilisent le dimensionnement des zones de bordure ; les images et les vidéos conservent leur propre valeur `object-fit` afin que le
le consommateur choisit entre la culture et le confinement.
- `overflow: hidden` est intentionnel. Si une décoration visible doit s'échapper du cadre, placez-la
décoration sur une enveloppe extérieure au lieu de retirer les coupures de racines.
