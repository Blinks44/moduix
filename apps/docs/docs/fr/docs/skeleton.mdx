## Anatomie

`Skeleton` se compose d’une seule partie visuelle. La mise en page reste gérée par le balisage environnant.

```text
Skeleton.Root
└─ children (facultatifs, affichés lorsque loading={false})
```

| Partie                        | Rôle                                                                                                                  |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `Skeleton` / `Skeleton.Root` | Surface d’attente. Affiche un élément de la fabrique Ark et accepte `asChild` pour des éléments hôtes personnalisés. |

## Composition

### Composition recommandée

Utilisez directement `Skeleton` pour les lignes de texte, les cartes, les avatars et les espaces réservés aux
médias. Tant que `loading` vaut `true`, il affiche un seul bloc décoratif ; avec `loading={false}`, il affiche ses enfants.

La variante par défaut est `variant="pulse"`. Utilisez `variant="none"` si aucune animation n’est nécessaire.
La surface reste toujours statique pour les personnes qui préfèrent réduire les animations.

### Quand créer une composition personnalisée

Utilisez `asChild` lorsqu’un autre élément sémantique doit posséder le nœud affiché. Cet élément doit être l’unique
enfant et rester sémantique, conformément aux recommandations de composition d’Ark.

Pour les dimensions courantes, utilisez `width`, `height`, `boxSize` et `borderRadius`. Pour les surfaces plus
spécifiques, utilisez `className`, `style` ou les variables CSS publiques.

### Propriétés par défaut

| Propriété       | Par défaut                             | Remarques                                                                                                                        |
| --------------- | -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `loading`       | `true`                                 | Active les styles d’attente ou affiche normalement les enfants.                                                                 |
| `variant`       | `pulse`                                | Accepte `pulse` et `none`.                                                                                                       |
| `height`        | `1rem` pendant le chargement           | Le CSS de chargement définit une hauteur standard. Le contenu chargé conserve sa hauteur naturelle si aucune hauteur n’est fixée. |
| `width`         | `100%`                                 | Le CSS définit la largeur standard de la racine. Les valeurs numériques sont converties en `px`.                                |
| `boxSize`       | -                                      | Définit simultanément la largeur et la hauteur si l’axe correspondant n’est pas précisé.                                         |
| `borderRadius`  | `var(--moduix-skeleton-border-radius)` | Les valeurs numériques sont converties en `px` ; les remplacements via `style` restent prioritaires.                            |

### Comportement

- `Skeleton.Root` désigne le même composant que `Skeleton` ; cet alias assure la cohérence de l’espace de noms.
- `loading={true}` définit `aria-hidden`, `data-state="loading"` et `data-loading`.
- `loading={false}` définit `data-state="loaded"` et laisse les enfants utiliser leur hauteur naturelle si `height`,
  `boxSize` et `style.height` ne sont pas définis.
- `variant` agit uniquement sur les styles ; aucun minuteur interne ni gestion d’état n’est ajouté.
- `asChild` provient de la composition de la fabrique Ark et remplace l’ancienne composition fondée sur une render prop.
- `Skeleton` est décoratif et n’annonce pas le chargement. Définissez `aria-busy` sur la zone qui possède l’état de
  chargement, ou utilisez `Spinner` lorsqu’un statut inline doit être annoncé.

`--moduix-skeleton-*` pour la couleur, le rayon et le mouvement.

### Points d’accroche CSS

- `[data-scope="skeleton"][data-part="root"]` cible la racine exportée.
- `data-slot="skeleton-root"` est le sélecteur stable de moduix pour la racine.
- `data-state="loading"` et `data-state="loaded"` reflètent la propriété `loading`.
- `data-variant="pulse"` et `data-variant="none"` reflètent la variante.
- `data-loading` n’est présent que pendant l’activation des styles d’attente.
