## Anatomie

Le parcours standard pour les consommateurs est court :

```text
Spinner
└─ spinner-indicator
   └─ spinner-ring (indicateur par défaut uniquement)
```

| Partie              | Rôle                                                                                                        |
| ------------------- | ----------------------------------------------------------------------------------------------------------- |
| `Spinner`           | Élément racine de statut. Accepte `size`, `decorative`, `asChild` et les propriétés natives de `span`.     |
| `spinner-indicator` | Enveloppe interne rotative qui gère la taille et l’animation de rotation.                                   |
| `spinner-ring`      | Indicateur circulaire par défaut. Il n’est affiché qu’en l’absence de `children` personnalisés.            |

## Composition

### Composition recommandée

Conservez l’anneau par défaut lorsqu’un indicateur de chargement compact suffit.

- Utilisez `size` pour ajuster la densité.
- Utilisez `decorative` si un texte visible adjacent annonce déjà le chargement.
- Utilisez `aria-label` ou `aria-labelledby` si le statut nécessite un nom plus précis que `"Loading"`.

### Quand créer une composition personnalisée

`Spinner` est un composant à racine unique. Utilisez `children` pour remplacer l’anneau par défaut tout en
conservant la racine, la taille et l’enveloppe rotative standard de l’indicateur.

Utilisez `asChild` lorsque l’élément racine lui-même doit être fourni par le consommateur. Dans ce mode, Ark fusionne
les propriétés de la racine avec l’unique élément enfant, qui possède donc son propre contenu visuel.

L’enfant de `asChild` ne doit pas être interactif. Il sert d’hôte visuel au spinner, et non de bouton ou de lien.

### Propriétés par défaut

| Propriété     | Par défaut  | Remarques                                                                                      |
| ------------- | ----------- | ---------------------------------------------------------------------------------------------- |
| `size`        | `'md'`      | Accepte `'inherit' \| 'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`. `inherit` utilise `1em`.       |
| `decorative`  | `false`     | Masque la racine par défaut aux technologies d’assistance ; avec `asChild`, conserve la sémantique de l’enfant. |
| `asChild`     | `false`     | Fusionne les propriétés de la racine avec l’unique élément enfant.                             |
| `aria-label`  | `'Loading'` | Appliqué par défaut lorsque le spinner n’est pas décoratif.                                    |

### Comportement

- La racine par défaut est un `span` avec `data-scope="spinner"`, `data-part="root"`, `data-slot="spinner-root"` et `data-size`.
- `Spinner.Root` est un alias de compatibilité de `Spinner` ; utilisez `Spinner` dans le nouveau code.
- Les spinners non décoratifs sont affichés avec `role="status"`.
- `decorative={true}` masque la racine par défaut aux technologies d’assistance. Avec `asChild`, il
  retire plutôt le statut et les propriétés de libellé de Spinner tout en préservant la sémantique de l’enfant.
- `Spinner` possède cette sémantique et ses hooks `data-scope`, `data-part`, `data-slot` et `data-size` ; les propriétés
  natives ne peuvent donc pas les remplacer.
- L’enveloppe rotative utilise `data-scope="spinner"`, `data-part="indicator"` et `data-slot="spinner-indicator"`.
- Les `children` personnalisés remplacent uniquement l’anneau par défaut. L’enveloppe continue de gérer la taille et la rotation.
- Avec `asChild`, l’enfant fourni par le consommateur devient la racine et doit afficher lui-même l’indicateur visuel nécessaire.
- Spinner conserve l’animation de chargement avec `prefers-reduced-motion`, car le mouvement constitue un indice visuel du chargement.

### Points d’accroche CSS

- `[data-scope="spinner"][data-part="root"]` cible la racine selon les conventions d’Ark.
- `[data-scope="spinner"][data-part="indicator"]` cible l’enveloppe interne rotative.
- `[data-scope="spinner"][data-part="ring"]` cible uniquement l’anneau par défaut.
- `data-slot="spinner-root"` est le sélecteur stable de moduix pour la racine exportée.
- `data-slot="spinner-indicator"` est le sélecteur stable de moduix pour l’enveloppe interne rotative.
- `data-slot="spinner-ring"` cible uniquement l’anneau par défaut.
- `Spinner` écrit `data-size="inherit" | "xs" | "sm" | "md" | "lg" | "xl"` sur la racine.
- `className` est appliqué uniquement à la racine. Ciblez l’indicateur ou l’anneau avec des sélecteurs descendants si nécessaire.
