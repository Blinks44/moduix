## Choisir le bon composant

- Choisissez **`Input`** pour les valeurs textuelles ordinaires.
- Choisissez **`DateInput`** lorsque les utilisateurs ont besoin de segments de date accessibles au clavier et de valeurs de formulaire natives.
- Choisissez **`DatePicker`** lorsqu’ils ont besoin d’un calendrier contextuel. `DateInput` privilégie volontairement
  le clavier et n’ajoute pas de calendrier.

## Exemple de base

Rendez des segments de date adaptés à la locale avec `DateInput.Segments`. Ark gère leur ordre, l’édition au clavier,
le focus, les espaces réservés et la synchronisation avec le formulaire, tandis que moduix conserve les parties visuelles
stylées et évite le code répétitif de rendu des segments dans le scénario courant.

## Anatomie

```text
DateInput.Root
├─ DateInput.Label
├─ DateInput.Control
│  └─ DateInput.Segments
└─ champ natif (automatique)

Personnalisation avancée :

DateInput.SegmentGroup
└─ DateInput.SegmentContext
   └─ DateInput.Segment

DateInput.RootProvider
└─ le même arbre de parties connecté au store `useDateInput()`
```

| Partie                         | Rôle |
| ------------------------------ | ---- |
| `DateInput` / `DateInput.Root` | Gère la valeur de date, le formatage localisé, le focus des segments et la validation. |
| `DateInput.RootProvider`       | Connecte les parties à l’état créé avec `useDateInput()`. |
| `DateInput.Label`              | Libellé accessible du champ de date. |
| `DateInput.Control`            | Cadre visuel autour d’un ou plusieurs groupes de segments. |
| `DateInput.SegmentGroup`       | Regroupe les segments pour un index de date. |
| `DateInput.Segment`            | Segment de date modifiable ou littéral renvoyé par Ark. |
| `DateInput.Segments`           | Rend un groupe de segments adapté à la locale pour le scénario courant. |
| `DateInput.Separator`          | Texte décoratif pour les mises en page de plage. |
| `DateInput.Context`            | Accès sans balisage à l’état actuel du champ de date. |
| `DateInput.SegmentContext`     | Utilitaire de rendu Ark pour afficher des segments adaptés à la locale. |

## Composition

### Composition recommandée

Utilisez `DateInput` sous sa forme racine abrégée. Rendez `DateInput.Segments` dans `DateInput.Control` pour obtenir
un groupe de segments standard adapté à la locale.

Le composant racine rend automatiquement les champs natifs nécessaires à l’envoi et à la réinitialisation du formulaire.
Pour une plage, rendez des `DateInput.Segments` indexés. Un `name="date"` commun envoie `date[0]` et `date[1]` ;
transmettez un tuple `names` de deux éléments lorsque chaque côté exige un nom de base distinct, par exemple
`check-in[0]` et `check-out[1]`.

### Quand créer une composition personnalisée

Utilisez directement `DateInput.SegmentGroup`, `DateInput.SegmentContext` et `DateInput.Segment` lorsque les classes
ou le rendu doivent varier selon le segment.
Utilisez `asChild` sur les parties Ark lorsqu’un élément racine personnalisé est nécessaire. L’enfant doit être unique
et sémantiquement correct.
Utilisez `ids` lorsqu’un libellé externe, un texte d’aide ou un autre composant doit partager les mêmes identifiants.

### Propriétés par défaut

| Propriété                         | Valeur par défaut | Remarques |
| --------------------------------- | ----------------- | --------- |
| `DateInput` / `DateInput.Root`    | —                 | Aucun comportement local par défaut ; les valeurs Ark s’appliquent. |
| `DateInput.Segments`              | —                 | Rend un groupe de segments adapté à la locale pour un index. |
| `DateInput.names`                 | —                 | Deux noms de base pour les champs d’une plage ; Ark ajoute les index. |
| `DateInput.Separator.aria-hidden` | `true`            | Le texte décoratif est masqué aux technologies d’assistance. |
| `DateInput.Separator.role`        | `presentation`    | Retire les séparateurs de plage de l’arbre d’accessibilité. |

### Comportement

- Les valeurs sont des objets `DateInputDateValue[]` d’Ark / `@internationalized/date`, et non des chaînes.
- `onValueChange(details)` conserve l’objet `details` Ark avec `details.value` et `details.valueAsString`.
- `focused`, `defaultFocused` et `onFocusChange(details)` contrôlent l’état de focus du composant racine.
- `placeholderValue`, `defaultPlaceholderValue` et `onPlaceholderChange(details)` contrôlent la date de l’espace réservé.
- `selectionMode="range"` active les groupes de segments indexés et les champs natifs automatiques.
- `shouldForceLeadingZeros` détermine si les segments numériques sont complétés par des zéros initiaux.
- `min`, `max` et `isDateUnavailable` valident les dates confirmées.
- `locale`, `timeZone`, `hourCycle`, `granularity`, `formatter`, `format`, `translations`, `dir` et
  `createCalendar` sont transmis à Ark. Utilisez un formateur limité à l’heure avec `granularity="minute"` ou
  `"second"` lorsque la date n’est pas nécessaire.
- Importez `useDateInput()`, `useDateInputContext()` et `DateInputDateValue` depuis `@moduix/react`.
  Utilisez `DateInput.Context` ou `useDateInputContext()` pour lire l’état dans l’arbre, et
  `DateInput.SegmentContext` pour les segments. Les imports directs depuis Ark restent réservés aux types bas niveau
  et aux utilitaires que moduix n’exporte pas.

### Points d’accroche CSS

- `data-slot="date-input-root"` sur le composant racine.
- `data-slot="date-input-label"` sur le libellé.
- `data-slot="date-input-control"` sur le cadre visuel.
- `data-slot="date-input-segment-group"` sur chaque groupe de dates.
- `data-slot="date-input-segment"` sur les segments modifiables et littéraux.
- `data-slot="date-input-hidden-input"` sur le champ natif masqué.
- `data-slot="date-input-separator"` sur le séparateur de plage auxiliaire de moduix.
- Les attributs d’état Ark comprennent `data-disabled`, `data-readonly`, `data-invalid` et `data-focus` sur les
  groupes de contrôle et de segments, ainsi que `data-type`, `data-editable` et `data-placeholder-shown`.
