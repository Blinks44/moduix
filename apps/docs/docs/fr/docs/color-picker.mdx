## Choisir le bon composant

Utilisez `ColorPicker` lorsque les utilisateurs doivent choisir ou ajuster précisément une couleur. Utilisez `Input`
lorsqu’il suffit de coller une valeur connue et qu’aucun contrôle direct de la couleur n’est nécessaire.

## Anatomie

```text
ColorPicker
├─ ColorPicker.Label
├─ ColorPicker.Control
│  ├─ ColorPicker.ChannelInput[channel]
│  └─ ColorPicker.Trigger
│     ├─ ColorPicker.TransparencyGrid
│     └─ ColorPicker.ValueSwatch
├─ Sous-arbre de l’overlay (placé automatiquement dans un portail)
│  └─ ColorPicker.Positioner
│     └─ ColorPicker.Content
│        ├─ ColorPicker.Area
│        │  ├─ ColorPicker.AreaBackground
│        │  └─ ColorPicker.AreaThumb
│        ├─ ColorPicker.EyeDropperTrigger
│        ├─ ColorPicker.ChannelSlider[channel]
│        │  ├─ ColorPicker.TransparencyGrid
│        │  ├─ ColorPicker.ChannelSliderTrack
│        │  └─ ColorPicker.ChannelSliderThumb
│        ├─ ColorPicker.SwatchGroup
│        │  └─ ColorPicker.SwatchTrigger[value]
│        │     └─ ColorPicker.Swatch[value]
│        │        └─ ColorPicker.SwatchIndicator
│        └─ ColorPicker.View[format]
│           └─ ColorPicker.ChannelInput[channel]
└─ champ natif (automatique)
```

| Partie                           | Rôle |
| -------------------------------- | ---- |
| `ColorPicker`                    | Gère la valeur et le format de couleur, l’état du popup et l’intégration au formulaire. |
| `ColorPicker.Control`            | Regroupe les champs visibles et le déclencheur. |
| `ColorPicker.Trigger`            | Bouton qui ouvre le popup et rend le nuancier courant par défaut. |
| `ColorPicker.Content`            | Partie de contenu réelle du popup Ark. |
| `ColorPicker.Area`               | Surface bidimensionnelle de contrôle de la couleur. |
| `ColorPicker.ChannelSlider`      | Contrôle unidimensionnel de la teinte, du canal alpha ou d’un autre canal. |
| `ColorPicker.Sliders`            | Paire stylée de curseurs de teinte et de canal alpha. |
| `ColorPicker.ChannelInput`       | Champ textuel ou numérique pour un canal de couleur donné. |
| `ColorPicker.SwatchTrigger`      | Bouton de sélection d’une couleur prédéfinie. |
| `ColorPicker.ValueSwatch`        | Aperçu visuel de la valeur actuelle. |

`ColorPicker.RootProvider`, `parseColor`, `useColorPicker` et `useColorPickerContext` couvrent le scénario avancé
standard de gestion d’état. Importez directement les types auxiliaires d’Ark si nécessaire.

## Composition

Le composant racine place automatiquement `Positioner` dans un portail. Utilisez `portalled={false}` pour un rendu
intégré ou `portalRef` pour un conteneur personnalisé ; les parties structurelles restent explicites et stylables.

### Composition recommandée

Pour un sélecteur dans un popup, conservez `ColorPicker.Positioner` et `ColorPicker.Content` explicites. `Content` est
la partie Ark réelle ; le composant racine automatise uniquement la limite du portail.

Ne transmettez pas d’enfants à `Trigger`, `Area`, `ChannelSlider` et `SwatchTrigger` pour utiliser leur composition
visuelle standard. Pour la paire habituelle teinte–canal alpha, utilisez `ColorPicker.Sliders`. Stylez les canaux avec
`data-channel` ou les variables CSS ; ne fournissez des enfants que pour personnaliser la structure d’une partie.
Ajoutez `data-fit-content` lorsque la taille du déclencheur doit suivre son contenu, par exemple un nuancier avec `ValueText`.

Pour l’envoi et la réinitialisation natifs du formulaire, transmettez `name` à `ColorPicker`. Le composant rend et
synchronise automatiquement le champ natif ; `FormData` et `form.reset()` ne demandent aucune configuration supplémentaire.

### Quand créer une composition personnalisée

Utilisez `inline` sur `ColorPicker` lorsque la zone, les curseurs, les champs et les nuanciers doivent rester affichés
dans un panneau plutôt que dans un popup. Utilisez `ColorPicker.View` pour n’afficher que les champs d’un format à la fois.

Utilisez `useColorPicker` avec `ColorPicker.RootProvider` lorsque l’état doit vivre hors du sous-arbre rendu. Ne rendez
pas `Root` et `RootProvider` pour une même instance d’état.

Utilisez `asChild` sur les parties Ark exportées lorsqu’un autre élément sémantique doit constituer le nœud DOM.
L’enfant doit rester unique et préserver le comportement requis pour le focus et les interactions.

### Propriétés par défaut

Par défaut, le contenu de l’overlay dans le portail est monté à la demande et démonté après l’animation de sortie.
Définissez `unmountOnExit={false}` pour le conserver après la première ouverture ; désactivez les deux propriétés de
cycle de vie uniquement lorsqu’un rendu initial immédiat est nécessaire.

| Surface / propriété                         | Valeur par défaut | Remarques |
| ------------------------------------------- | ----------------- | --------- |
| `defaultValue`                              | `parseColor("#000000")` | Valeur de couleur Ark standard. |
| `defaultFormat`                             | `"rgba"` | Format Ark standard. |
| largeur de `ColorPicker.Content`            | `16rem` | Évite qu’il se réduise à la largeur du nuancier du déclencheur. |
| `ColorPicker.EyeDropperTrigger`             | icône de pipette moduix | Utilisée en l’absence d’enfants. |
| enfants de `ColorPicker.Trigger`            | nuancier actuel | Rend `TransparencyGrid` et `ValueSwatch`. |
| enfants de `ColorPicker.Area`               | arrière-plan et curseur | Utilisés en l’absence d’enfants. |
| enfants de `ColorPicker.ChannelSlider`      | piste et curseur | Les curseurs alpha rendent aussi `TransparencyGrid`. |
| `ColorPicker.Sliders`                       | paire teinte–canal alpha | Stylée via `data-channel` ou les variables CSS. |
| enfants de `ColorPicker.SwatchTrigger`      | nuancier et indicateur | Utilisent la prop `value` du déclencheur. |
| `ColorPicker.SwatchIndicator`               | icône de confirmation moduix | Utilisée en l’absence d’enfants. |
| largeur de `ColorPicker`                    | `16rem` (max. `100%`) | Largeur standard du composant racine stylé. |

### Comportement

- `value` et `defaultValue` utilisent des objets Ark `Color`. Pour les chaînes, utilisez `parseColor()`.
- `onValueChange(details)` et `onValueChangeEnd(details)` conservent les objets `details` d’Ark.
- `onFormatChange(details)` et `onOpenChange(details)` conservent les objets `details` d’Ark.
- `ids` est transmis à Ark pour partager les identifiants d’accessibilité dans les compositions personnalisées.
- L’état de Field et Fieldset est transmis avec les props racine compatibles Ark `disabled`, `invalid`, `required` et `readOnly`.
- Utilisez `positioning`, `initialFocusEl` et `openAutoFocus` pour adapter le placement ou le focus au contexte.
- `lazyMount` et `unmountOnExit` valent `true` par défaut ; `present` et `onExitComplete` conservent le cycle de présence
  Ark pour contrôler le montage ou l’animation de sortie.
- Toutes les parties DOM Ark conservent `asChild`.

### Points d’accroche CSS

Utilisez la partie qui contrôle l’aspect visuel concerné :

- `ColorPicker` pour la largeur, les espacements, la couleur générale et l’opacité de l’état désactivé ;
- `ColorPicker.Control`, `ChannelInput`, `Trigger`, `FormatSelect` et `FormatTrigger` pour les éléments visibles du champ ;
- `ColorPicker.Positioner` et `ColorPicker.Content` pour les couches, la largeur, les espacements, l’arrondi, l’ombre
  et les animations d’état du popup ;
- `ColorPicker.Area`, `AreaBackground` et `AreaThumb` pour la surface de couleur bidimensionnelle ;
- `ColorPicker.ChannelSlider`, `ChannelSliderTrack`, `ChannelSliderThumb` et `Sliders` pour les curseurs de teinte,
  de canal alpha et des autres canaux ;
- `ColorPicker.SwatchGroup`, `SwatchTrigger`, `Swatch` et `SwatchIndicator` pour les grilles de couleurs prédéfinies ;
- `ColorPicker.ValueSwatch`, `ValueText`, `View` et `TransparencyGrid` pour l’affichage de la valeur et les mises en page propres au format.

Les principaux hooks d’état sont `data-state`, `data-focus`, `data-invalid`, `data-disabled`, `data-readonly`,
`data-required`, `data-channel`, `data-orientation`, `data-value`, `data-placement` et `data-side`. Les variables Ark
à l’exécution comprennent `--color`, `--value`, `--available-width`, `--available-height` et `--transform-origin`.

Lorsque `prefers-reduced-motion` est activé, les animations d’ouverture et de fermeture du popup
sont réduites à 1 ms afin qu’Ark termine son cycle de sortie sans mouvement visible.
