## Anatomie

```tsx
<ImageCropper>
  <ImageCropper.Viewport>
    <ImageCropper.Image />
    <ImageCropper.CropArea />
  </ImageCropper.Viewport>
</ImageCropper>
```

| Partie                                | Rôle                                                                                                                   |
| ------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `ImageCropper` / `ImageCropper.Root` | Groupe racine qui gère l’état de recadrage, les transformations, les libellés ARIA et les variables CSS d’exécution.   |
| `ImageCropper.RootProvider`          | Racine affichée à partir d’une instance `useImageCropper` créée hors de l’arborescence.                                |
| `ImageCropper.Viewport`              | Surface de déplacement et zone d’affichage dans laquelle l’image est découpée.                                         |
| `ImageCropper.Image`                 | Élément d’image transformable contrôlé par Ark.                                                                        |
| `ImageCropper.Selection`             | Sélection de recadrage pouvant recevoir le focus et cible des interactions clavier.                                    |
| `ImageCropper.Grid`                  | Guides de recadrage horizontaux ou verticaux.                                                                          |
| `ImageCropper.Handle`                | Poignée de redimensionnement pour chaque position de `ImageCropper.handles`.                                            |
| `ImageCropper.CropArea`              | Sélection recommandée comprenant les deux grilles et toutes les poignées de redimensionnement.                          |

## Composition

### Composition recommandée

Utilisez `ImageCropper.CropArea` pour l’anatomie de recadrage habituelle. Il préserve l’arborescence des parties Ark tout en supprimant le balisage répétitif de la sélection, des grilles et des poignées. Transmettez `className`, `gridClassName` ou `handleClassName` pour styliser les parties affichées. Comme le composant gère cette structure enfant, utilisez explicitement les parties `Selection`, `Grid` et `Handle` à la place de `children` ou `asChild` si vous avez besoin d’une structure différente.

### Quand créer une composition personnalisée

Utilisez `ImageCropper.Context` pour les barres d’outils situées dans la racine. Utilisez `useImageCropper` de moduix avec `ImageCropper.RootProvider` lorsqu’un contrôle, un aperçu du recadrage ou une intégration de formulaire nécessite l’API de recadrage hors du sous-arbre racine. Pour une même instance d’état, ne combinez pas `RootProvider` avec `ImageCropper.Root`.

### Propriétés par défaut

| Propriété                 | Valeur par défaut                        | Remarques                                                                           |
| ------------------------- | ---------------------------------------- | ----------------------------------------------------------------------------------- |
| `cropShape`               | `"rectangle"`                            | Utilisez `"circle"` pour un recadrage de type avatar.                               |
| `defaultZoom`             | `1`                                      | Niveau de zoom initial de l’image.                                                   |
| `defaultRotation`         | `0`                                      | Rotation initiale de l’image en degrés.                                              |
| `defaultFlip`             | `{ horizontal: false, vertical: false }` | État initial de retournement.                                                        |
| `minZoom`                 | `1`                                      | Facteur de zoom minimal.                                                             |
| `maxZoom`                 | `5`                                      | Facteur de zoom maximal.                                                             |
| `minWidth` / `minHeight`  | `40`                                     | Taille minimale de la sélection de recadrage.                                        |
| `fixedCropArea`           | `false`                                  | Si vrai, l’utilisateur déplace l’image sous une sélection fixe.                      |

### Comportement

Ark gère le glisser au pointeur, le panoramique, le zoom à la molette et par geste, le déplacement au clavier, les identifiants générés, les libellés ARIA et les helpers de résultat du recadrage. Les touches fléchées déplacent la sélection, `Alt` avec les flèches la redimensionne, `Shift` et `Ctrl`/`Cmd` utilisent les propriétés de pas de déplacement, et `+` / `-` contrôlent le zoom. L’état contrôlé conserve les objets de détails Ark via `onCropChange`, `onZoomChange`, `onRotationChange` et `onFlipChange`.

### Sélecteurs de style

Utilisez les sélecteurs `data-slot` stables : `image-cropper-root`, `image-cropper-viewport`, `image-cropper-image`, `image-cropper-selection`, `image-cropper-grid` et `image-cropper-handle`. Ark fournit également `data-scope="image-cropper"`, les valeurs `data-part`, `data-shape`, `data-ready`, `data-disabled`, `data-dragging`, `data-panning`, `data-axis` et `data-position`.
