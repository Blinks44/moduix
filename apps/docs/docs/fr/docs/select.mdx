## Choisir le bon composant

Utilisez `Select` lorsque l’utilisateur choisit dans une collection fixe et que le déclencheur reste en lecture seule. Utilisez `Combobox` lorsque la saisie aide à rechercher ou à créer une valeur.

## Exemple de base

Transmettez une collection à `Select`, utilisez `Select.Field` pour le contrôle visible standard et conservez une structure explicite pour la fenêtre contextuelle. `clearLabel` ajoute une action d’effacement accessible. La racine affiche automatiquement un contrôle de formulaire natif pour la soumission, le remplissage automatique et la réinitialisation.

## Anatomie

```text
Select / Select.Root
├─ Select.Label
├─ Select.Control / Select.Field
│  ├─ Select.Trigger
│  │  ├─ Select.ValueText
│  │  └─ Select.Indicator
│  └─ Select.ClearTrigger
├─ Overlay subtree (automatically portalled)
│  └─ Select.Positioner
│     └─ Select.Content
│        ├─ Select.List
│        └─ Select.ItemGroup
│           ├─ Select.ItemGroupLabel
│           └─ Select.Item[item]
│              ├─ Select.ItemText
│              └─ Select.ItemIndicator
└─ native form control (automatic)
```

| Partie                    | Rôle                                                                                             |
| ------------------------- | ------------------------------------------------------------------------------------------------ |
| `Select` / `Select.Root`  | État racine, collection, sélection, cycle de vie de la fenêtre contextuelle et données du formulaire. |
| `Select.RootProvider`     | Affiche l’arborescence Select à partir de l’état renvoyé par `Select.useSelect`.                 |
| `Select.Label`            | Libellé accessible hérité par le déclencheur et le contrôle de formulaire natif.                |
| `Select.Control`          | Enveloppe du champ visible qui reçoit les états de focus, d’invalidité et d’ouverture.           |
| `Select.Field`            | Assistant Moduix qui affiche le control, le déclencheur et les actions standard.                 |
| `Select.Trigger`          | Bouton qui ouvre la fenêtre contextuelle et reçoit les saisies au clavier.                       |
| `Select.ValueText`        | Placeholder ou libellés des éléments sélectionnés.                                               |
| `Select.ClearTrigger`     | Bouton qui efface la valeur actuelle.                                                             |
| `Select.Indicator`        | Indicateur du déclencheur avec l’icône de flèche moduix par défaut.                               |
| `Select.Positioner`       | Calque flottant qui expose les variables CSS de positionnement d’Ark.                            |
| `Select.Content`          | Surface de la fenêtre contextuelle et conteneur listbox.                                         |
| `Select.List`             | Enveloppe de liste facultative pour la virtualisation et les dispositions personnalisées.        |
| `Select.ItemGroup`        | Enveloppe d’un groupe d’éléments associés de la collection.                                      |
| `Select.ItemGroupLabel`   | Libellé d’un groupe de la collection.                                                             |
| `Select.Item`             | Ligne sélectionnable. Transmettez l’élément de collection avec `item`.                           |
| `Select.ItemText`         | Texte destiné à l’affichage et à l’accessibilité.                                                 |
| `Select.ItemIndicator`    | Indicateur de sélection avec l’icône de coche moduix par défaut.                                 |

## Composition

La racine place automatiquement `Positioner` dans un portail. Utilisez `portalled={false}` pour un rendu inline et `portalRef` pour un conteneur personnalisé ; `Positioner` et `Content` restent explicites et accessibles au style.

### Composition recommandée

`Select.Field` affiche `Control`, `Trigger`, `ValueText` et l’indicateur par défaut. Transmettez `clearLabel` pour activer une action d’effacement avec libellé, ou `indicator={<Icon />}` pour remplacer uniquement la flèche. Gardez `Positioner`, `Content` et les éléments visibles dans la composition.

`Select` est la forme racine courte ; `Select.Root` reste son alias équivalent dans l’espace de noms.

### Quand créer une composition personnalisée

Utilisez explicitement `Control`, `Trigger` et les parties visuelles lorsque leur disposition nécessite une composition indépendante. `asChild` exige un conteneur sémantique unique capable de recevoir le contrôle de formulaire natif automatique ; utilisez un conteneur tel que `div` ou `section`, et non un élément interactif tel que `button`. Utilisez `Select.List` pour les enveloppes de liste personnalisées et les parcours virtualisés.

### Propriétés par défaut

Par défaut, le contenu de l’overlay placé dans un portail est monté de manière différée puis démonté après l’animation de sortie. Définissez `unmountOnExit={false}` pour le conserver après la première ouverture ; ne définissez les deux propriétés du cycle de vie sur `false` que si un rendu initial immédiat est nécessaire.

| Propriété                 | Valeur par défaut | Remarques                                                    |
| ------------------------- | ----------------- | ------------------------------------------------------------ |
| `closeOnSelect`           | `true`            | Ferme la fenêtre contextuelle après la sélection d’un élément. |
| `composite`               | `true`            | Active la composition clavier de la listbox.                 |
| `defaultValue`            | `[]`              | Les valeurs sont des tableaux de chaînes, même en sélection unique. |
| `lazyMount`               | `true`            | Diffère le montage du contenu jusqu’à l’ouverture.           |
| `loopFocus`               | `false`           | Par défaut, la navigation avec les flèches ne boucle pas.    |
| `multiple`                | `false`           | Autorise plusieurs valeurs lorsqu’elle est activée.          |
| `unmountOnExit`           | `true`            | Supprime le contenu après l’animation de sortie.             |
| `ValueText.placeholder`   | -                 | Texte affiché lorsque le tableau de valeurs est vide.        |

### Notes sur le comportement

`value`, `defaultValue` et `onValueChange(details)` utilisent des tableaux de chaînes. Lisez les clés sélectionnées dans `details.value` et les éléments de collection dans `details.items`. `onOpenChange(details)`, `onHighlightChange(details)` et `onSelect(details)` conservent les objets details d’Ark sans modification.

Utilisez `Select.useSelect` avec `Select.RootProvider` lorsque l’état doit être disponible hors de l’arborescence Select. Pour lire l’état dans l’arborescence, utilisez `Select.Context`, `Select.ItemContext`, `Select.useSelectContext` et `Select.useSelectItemContext`. `Field.Root` et `Fieldset.Root` transmettent les états disabled, invalid, required et read-only par le contexte Ark.

Le select natif standard conserve la validation du navigateur, le remplissage automatique, la réinitialisation et l’amélioration progressive. Pour une collection virtualisée, `nativeFormControl="input"` soumet un input masqué par valeur sélectionnée plutôt qu’une option par élément. Il synchronise toujours la réinitialisation du formulaire et l’état disabled du fieldset, mais ne fournit volontairement ni remplissage automatique natif du select, ni validation, ni amélioration progressive.

### Hooks de style

`Select.Field` affiche les slots existants `select-control`, `select-trigger`, `select-value-text`, `select-indicator` et le slot facultatif `select-clear-trigger`. Sa propriété `indicator` transmet un enfant au slot d’indicateur existant.

- Les racines fournissent `data-slot="select-root"` et `data-slot="select-root-provider"`.
- L’anatomie Ark utilise `data-scope="select"` et `data-part`.
- Le style des états utilise `data-state="open" | "closed"`, `data-focus`, `data-invalid`, `data-disabled`, `data-readonly`, `data-placeholder-shown`, `data-highlighted` et l’état d’élément `data-state="checked" | "unchecked"`.
- `Select.Positioner` fournit `--reference-width`, `--reference-height`, `--available-width`, `--available-height`, `--x`, `--y`, `--z-index` et `--transform-origin`.
