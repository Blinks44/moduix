## Référence API

Ark UI ne fournit pas de primitive `breadcrumbs` dédiée. Moduix construit ce composant avec l’outil officiel
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) et suit les recommandations d’Ark concernant la
[composition](https://ark-ui.com/docs/guides/composition), les [styles](https://ark-ui.com/docs/guides/styling) et les
[ref](https://ark-ui.com/docs/guides/ref).

## Exemple de base

Commencez par `Breadcrumbs.Path` lorsque l’application connaît déjà le chemin visible. Il affiche une liste ordonnée, ses éléments, les liens, la page actuelle et les séparateurs par défaut à partir d’un petit tableau `items`.

## Anatomie

`Breadcrumbs` expose des parties avec espace de noms conformes à Ark.

```text
Breadcrumbs / Breadcrumbs.Root
└─ Breadcrumbs.List
   ├─ Breadcrumbs.Item
   │  └─ Breadcrumbs.Link
   ├─ Breadcrumbs.Separator
   └─ Breadcrumbs.Item
      └─ Breadcrumbs.Page
```

| Partie                              | Rôle                                                               |
| ----------------------------------- | ------------------------------------------------------------------ |
| `Breadcrumbs` / `Breadcrumbs.Root` | Zone de navigation racine avec un `aria-label` par défaut.         |
| `Breadcrumbs.List`                 | Liste ordonnée des segments du fil d’Ariane.                        |
| `Breadcrumbs.Item`                 | Élément de liste enveloppant un segment.                            |
| `Breadcrumbs.Link`                 | Ancre stylisée pour les segments accessibles ; prend en charge `asChild`. |
| `Breadcrumbs.Page`                 | Texte de la page actuelle avec `aria-current="page"`.              |
| `Breadcrumbs.Separator`            | Séparateur visuel de présentation, masqué pour les technologies d’assistance. |
| `Breadcrumbs.Ellipsis`             | Indicateur minimal d’un chemin replié destiné aux déclencheurs de menu. |

`Breadcrumbs.Path` est un raccourci local qui affiche `Breadcrumbs.List`, `Breadcrumbs.Item`, `Breadcrumbs.Link`, `Breadcrumbs.Page` et `Breadcrumbs.Separator` à partir d’un tableau `items`.

## Composition

### Composition recommandée

Utilisez `Breadcrumbs.Path` pour les chemins simples fondés sur des ancres. Le dernier élément devient la page actuelle, le séparateur par défaut est un chevron et `separator` peut le remplacer dans chaque intervalle visible.

### Quand créer une composition personnalisée

Utilisez les parties explicites lorsque vous avez besoin des liens du routeur d’un framework, d’une section intermédiaire repliée ou d’un balisage différent selon les éléments. `asChild` d’Ark continue de gérer les liens du routeur ; l’enfant doit être l’unique lien sémantique et conserver les `href`, le focus et le comportement clavier attendus.

Combinez le composant avec `Menu` lorsque les segments intermédiaires doivent être regroupés derrière un déclencheur avec points de suspension. Gardez la structure de Menu explicite : `Menu.Positioner`, `Menu.Content` et `Menu.Item asChild` ; Menu gère la limite du portail.

### Propriétés par défaut

| Surface                             | Valeur par défaut | Remarques                                                    |
| ----------------------------------- | ----------------- | ------------------------------------------------------------ |
| `Breadcrumbs` / `Breadcrumbs.Root` | —                 | Aucune valeur de comportement supplémentaire par défaut ; les valeurs Ark s’appliquent. |
| `Breadcrumbs.Path`                 | chevron           | Affiche des chevrons comme séparateurs si `separator` n’est pas défini. |

### Notes sur le comportement

- `Breadcrumbs` affiche un repère `nav` dont l’`aria-label` par défaut vaut `"Breadcrumb"`.
- `Breadcrumbs.Path` affiche une liste ordonnée à partir de `items` ; le dernier élément est toujours la page actuelle.
- `Breadcrumbs.Separator` est purement présentatif et masqué pour les technologies d’assistance.
- `Breadcrumbs.Ellipsis` est masqué pour les technologies d’assistance, car le déclencheur porte le libellé.
- Le libellé accessible du chemin replié doit être placé sur `Menu.Trigger`.
- Tout élément visible du fil d’Ariane peut rétrécir lorsque l’espace manque ; la page actuelle reste la cible principale de la troncature grâce à `--moduix-breadcrumbs-item-max-width`.
- Il n’existe aucune propriété contrôlée, aucun callback, hook de contexte, `RootProvider`, id, `HiddenInput` ou intégration avec l’état d’un formulaire, car Breadcrumbs ne possède aucun état interactif ni état de formulaire.

Utilisez les parties de `Menu` migrées vers Ark lorsque les segments intermédiaires masqués ont besoin d’un comportement d’ouverture. Cet exemple conserve les parties explicites, car le déclencheur et le contenu du menu portent la véritable interaction.

## Styles

Chaque partie exportée possède les attributs `data-scope="breadcrumbs"` et `data-part` de style Ark, ainsi que les hooks moduix stables `data-slot`. Les variables publiques `--moduix-breadcrumbs-*` couvrent la disposition, les styles du texte, l’anneau de focus, les séparateurs et la taille des points de suspension.

### Hooks de style

- `data-scope="breadcrumbs"` est présent sur chaque partie exportée.
- Les valeurs `data-part="root"`, `list`, `item`, `link`, `page`, `separator` et `ellipsis` suivent le contrat Ark factory utilisé par ce composant.
- Les valeurs `data-slot="breadcrumbs-root"`, `breadcrumbs-list`, `breadcrumbs-item`, `breadcrumbs-link`, `breadcrumbs-page`, `breadcrumbs-separator` et `breadcrumbs-ellipsis` restent des sélecteurs moduix stables.
- `Breadcrumbs.Link`, `Breadcrumbs.Page` et `Breadcrumbs.Ellipsis` utilisent le même espacement intérieur en ligne défini par `--moduix-breadcrumbs-item-padding-x`.
- Les parties visibles de `Breadcrumbs.Item` peuvent rétrécir pour préserver le chemin ; la dernière partie visible reste la cible principale de la troncature et utilise `--moduix-breadcrumbs-item-max-width`.
