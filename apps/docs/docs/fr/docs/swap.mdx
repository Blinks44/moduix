## Anatomie

```text
Swap / Swap.Root
├─ Swap.Indicator type="off"
└─ Swap.Indicator type="on"
```

| Partie               | Rôle                                                                       |
| -------------------- | -------------------------------------------------------------------------- |
| `Swap` / `Swap.Root` | Possède l’état Ark `swap` et superpose les deux états visuels.             |
| `Swap.RootProvider`  | Utilise un état créé avec `Swap.useSwap()` à l’extérieur du sous-arbre.    |
| `Swap.Indicator`     | Affiche un état visuel `on` ou `off` avec les attributs de Presence.       |

## Composition

### Composition recommandée

Réservez `Swap` au remplacement visuel. Placez-le dans un bouton, un lien ou une surface de statut sémantique ; ce
parent gère les événements, le focus et le nom accessible. Marquez les indicateurs composés uniquement d’une icône
avec `aria-hidden="true"` et placez le nom accessible courant sur le contrôle hôte.

### Quand créer une composition personnalisée

Utilisez `animation` pour sélectionner l’une des recettes incluses : `fade`, `scale`, `rotate` ou `flip`. La
propriété accepte également un nom personnalisé : moduix l’écrit dans `data-animation` et laisse les indicateurs
sans animation afin que le CSS du consommateur puisse exploiter les attributs `data-state` d’Ark sans entrer en
conflit avec une animation par défaut.

### Propriétés par défaut

| Propriété       | Par défaut | Remarques                                                                  |
| --------------- | ---------- | -------------------------------------------------------------------------- |
| `swap`          | `false`    | Sélectionne l’indicateur `off`.                                            |
| `animation`     | `scale`    | Animation moduix par défaut conservée, combinant fondu et mise à l’échelle. |
| `lazyMount`     | `false`    | Diffère le montage d’un indicateur inactif jusqu’à son premier affichage.  |
| `unmountOnExit` | `false`    | Retire un indicateur inactif après son animation de sortie.                |

### Notes sur le comportement

- `swap` est contrôlé ; `Swap` ne réagit pas de lui-même au survol ou aux clics.
- Chaque indicateur reçoit l’attribut Ark `data-state="open" | "closed"` pendant la transition.
- `Swap.RootProvider` accepte l’état de `Swap.useSwap()`, et `useSwapContext()` lit cet état depuis un descendant
  lorsqu’une composition personnalisée en a besoin.
- `asChild` est disponible sur chaque partie. Fournissez exactement un enfant sémantique afin qu’il puisse recevoir
  les propriétés et refs d’Ark ainsi que les hooks de style de moduix.

### Animation personnalisée

Fournissez un nom d’`animation` personnalisé et ciblez le `data-animation` de la racine ainsi que le `data-state`
Ark des indicateurs. Cette animation de rebond utilise volontairement du CSS ordinaire : aucune API Swap ni aucun
JavaScript supplémentaire n’est nécessaire.

<style>{SwapDocs.swapCustomAnimationCss}</style>

<PreviewFrame>
  ```tsx preview file="../../en/docs/_snippets/swap/custom-animation.tsx"

  ```
</PreviewFrame>

```css
.swap-custom-animation[data-animation='bounce'] [data-slot='swap-indicator'][data-state='open'] {
  animation: swap-bounce-enter var(--moduix-swap-transition, var(--moduix-transition-slow));
}

.swap-custom-animation[data-animation='bounce'] [data-slot='swap-indicator'][data-state='closed'] {
  animation: swap-bounce-exit var(--moduix-swap-transition, var(--moduix-transition-slow));
}
```

### Root Provider

### Hooks de style

- `Swap.Root` → `data-slot="swap-root"`
- `Swap.RootProvider` → `data-slot="swap-root-provider"`
- `Swap.Indicator` → `data-slot="swap-indicator"`
- `animation` est exposée sous forme de `data-animation` sur `Swap` et `Swap.RootProvider`.
- Ark ajoute `data-scope="swap"` et `data-part="root" | "indicator"`.
- Ark ajoute `data-state="open" | "closed"` aux indicateurs ; moduix utilise ces attributs pour ses animations
  incluses.
