# Navigation mobile avec tiroir

Ajoutez un modèle de navigation mobile compact avec un tiroir fixé au bord de l’écran. Les liens de
navigation ferment le tiroir après la sélection, tandis que le primitif Drawer assure une gestion
accessible du focus, de la touche Escape et de l’arrière-plan.

## Utilisation dans une route

Remplacez les liens et le contenu du tableau de bord d’exemple par vos routes et vos données. Placez
chaque lien de navigation dans `Drawer.CloseTrigger` afin que la sélection ferme automatiquement le
tiroir mobile.

Utilisez le composant Link de votre routeur via `asChild` lorsqu’il doit gérer la navigation et
marquez le lien actuel avec `aria-current="page"`. Gardez le déclencheur visible sur les largeurs
mobiles et proposez les mêmes destinations dans un en-tête permanent pour ordinateur ou dans le
[Tableau de bord avec barre latérale](/docs/sidebar-dashboard) sur les écrans plus larges. N’affichez
pas deux copies focalisables de la même navigation au même point de rupture.
