## Anatomie

```text
QrCode / QrCode.Root
├─ QrCode.Frame
│  └─ QrCode.Pattern
├─ QrCode.Overlay
└─ QrCode.DownloadTrigger

QrCode.RootProvider
└─ same part tree connected to useQrCode() from @moduix/react
```

| Partie                    | Rôle                                                                           |
| ------------------------- | ------------------------------------------------------------------------------ |
| `QrCode` / `QrCode.Root`  | État de la valeur, options de génération, identifiants et variables CSS.       |
| `QrCode.RootProvider`     | Affiche l’arbre du QR code depuis l’état renvoyé par `useQrCode()` de moduix.  |
| `QrCode.Frame`            | Cadre SVG généré par Ark.                                                      |
| `QrCode.Pattern`          | Chemin SVG représentant les modules du QR code.                               |
| `QrCode.Overlay`          | Contenu personnalisé centré au-dessus du QR code.                              |
| `QrCode.DownloadTrigger`  | Bouton qui télécharge le cadre actuel du QR code sous forme d’image.           |

## Composition

### Composition recommandée

Conservez la structure Ark explicite : `QrCode`, `QrCode.Frame` et `QrCode.Pattern`. `QrCode.Root` reste disponible comme alias explicite correspondant à Ark. N’ajoutez `QrCode.Overlay` que si la correction d’erreurs du QR code suffit pour la zone masquée.

### Quand créer une composition personnalisée

Utilisez `encoding` pour les options de génération du QR code, notamment `encoding={{ ecc: 'H' }}` lors de l’ajout d’une superposition. Utilisez `QrCode.DownloadTrigger` lorsque les utilisateurs ont besoin d’un fichier image généré. Utilisez `useQrCode()` de `@moduix/react` avec `QrCode.RootProvider` lorsque des contrôles situés en dehors de l’arbre doivent accéder à l’API du QR code actuel.

Utilisez `asChild` sur les parties Ark lorsque vous remplacez l’élément hôte. Conservez un seul enfant de remplacement et assurez-vous qu’il reste sémantique. Utilisez `ids` si l’arbre personnalisé a besoin d’identifiants stables pour l’élément racine ou le cadre.

### Propriétés par défaut

| Propriété      | Par défaut | Notes                                                                            |
| -------------- | ----------- | -------------------------------------------------------------------------------- |
| `defaultValue` | —           | Valeur encodée initiale non contrôlée.                                           |
| `value`        | —           | Valeur encodée contrôlée.                                                        |
| `encoding`     | —           | Options de génération du QR code, comme `ecc` et `boostEcc`.                     |
| `pixelSize`    | —           | Taille de pixel transmise au générateur Ark/Zag.                                 |
| `id`           | —           | Identifiant machine stable transmis à Ark.                                       |
| `ids`          | —           | Identifiants stables pour `root` et `frame`.                                     |
| `fileName`     | —           | Requis pour `DownloadTrigger`.                                                   |
| `mimeType`     | —           | Requis pour `DownloadTrigger`, par exemple `image/png` ou `image/svg+xml`.       |
| `quality`      | —           | Qualité facultative de l’image téléchargée.                                      |

### Notes sur le comportement

Utilisez `value` avec `onValueChange(details)` lorsque l’URL ou le texte encodé doit rester synchronisé avec l’état environnant. La signature du callback correspond à l’objet de détails Ark d’origine.

`useQrCode()` de `@moduix/react` permet de créer l’état du QR code en dehors de l’arbre affiché. Utilisez `QrCode.Context` ou `useQrCodeContext()` de moduix pour lire l’état du QR code dans un descendant.

Le QR code n’a pas de navigation dédiée avec les flèches, de roving focus ni de champ de saisie masqué. `DownloadTrigger` est un bouton natif : il conserve donc l’activation au clavier et le comportement de focus d’un bouton.

Le SVG est un rendu visuel. Lorsque le QR code transmet une information, ajoutez `role="img"` et `aria-label` à `QrCode.Frame`. Utilisez un texte adjacent ou `aria-hidden="true"` lorsque le QR code duplique une information.

### Hooks de style

- `QrCode.Root` -> `data-slot="qr-code-root"`
- `QrCode.RootProvider` -> `data-slot="qr-code-root-provider"`
- `QrCode.Frame` -> `data-slot="qr-code-frame"`
- `QrCode.Pattern` -> `data-slot="qr-code-pattern"`
- `QrCode.Overlay` -> `data-slot="qr-code-overlay"`
- `QrCode.DownloadTrigger` -> `data-slot="qr-code-download-trigger"`
- Hooks Ark : `data-scope="qr-code"`, `data-part="root|frame|pattern|overlay|download-trigger"`,
  ainsi que les variables CSS d’exécution `--qrcode-pixel-size`, `--qrcode-width` et `--qrcode-height`.
