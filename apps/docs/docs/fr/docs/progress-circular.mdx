## Choisir le bon composant

Choisissez `ProgressCircular` pour les états compacts en ligne, les cartes, les indicateurs de barre d’outils et les petits tableaux de bord. Choisissez `ProgressLinear` lorsqu’une comparaison horizontale avec une piste complète est importante.

## Anatomie

```text
ProgressCircular / ProgressCircular.Root
├─ ProgressCircular.Label
├─ ProgressCircular.Ring
│  └─ fixed Circle, CircleTrack, and CircleRange subtree
├─ ProgressCircular.Circle
│  ├─ ProgressCircular.CircleTrack
│  └─ ProgressCircular.CircleRange
└─ ProgressCircular.ValueText

ProgressCircular.RootProvider
└─ same part tree connected to ProgressCircular.useProgress()
```

| Partie                                        | Rôle                                                                       |
| --------------------------------------------- | -------------------------------------------------------------------------- |
| `ProgressCircular` / `ProgressCircular.Root`  | Gère l’état de progression, le formatage et les identifiants.              |
| `ProgressCircular.RootProvider`               | Relie les parties à l’état créé par `ProgressCircular.useProgress()`.      |
| `ProgressCircular.Context`                    | Donne accès à l’état de progression actuel via une render prop.            |
| `ProgressCircular.Label`                      | Fournit un contexte visible à l’indicateur de progression.                 |
| `ProgressCircular.Ring`                       | Sous-arbre pratique par défaut comprenant le cercle, la piste et la plage. |
| `ProgressCircular.Circle`                     | Surface SVG de l’indicateur portant la valeur ARIA.                         |
| `ProgressCircular.CircleTrack`                | Cercle d’arrière-plan.                                                      |
| `ProgressCircular.CircleRange`                | Cercle de premier plan reflétant le pourcentage ou l’état actuel.           |
| `ProgressCircular.ValueText`                  | Texte visible de la valeur, produit à partir des traductions Ark.           |
| `ProgressCircular.View`                       | Vue conditionnelle pour `indeterminate`, `loading` ou `complete`.           |

## Composition

### Composition recommandée

`ProgressCircular` est la forme racine concise. Elle équivaut à `ProgressCircular.Root`. `ProgressCircular.Ring` est le sous-arbre fixe recommandé pour le cercle SVG, la piste et la plage ; il accepte `className`, les propriétés ARIA et les mêmes variables CSS que `ProgressCircular.Circle`.

Utilisez `defaultValue` pour une progression non contrôlée, `value` avec `onValueChange(details)` pour une progression contrôlée, et `defaultValue={null}` ou `value={null}` pour une progression indéterminée.

### Quand créer une composition personnalisée

Utilisez `translations.value(details)` pour personnaliser le texte visible de la valeur. Attribuez à `Ring` ou `Circle` un `aria-label` décrivant la tâche, puis enveloppez le cercle et le texte de la valeur dans votre propre élément de disposition si le nombre doit être centré.

Utilisez `Circle`, `CircleTrack` et `CircleRange` lorsque vous devez personnaliser leur structure ou la composition Ark via `asChild`. Utilisez `ids` lorsque le libellé, le cercle ou la disposition environnante ont besoin d’identifiants explicites et stables dans un arbre personnalisé. Utilisez `ProgressCircular.useProgress()` avec `RootProvider` lorsque l’état doit exister en dehors de l’arbre affiché, et `ProgressCircular.useProgressContext()` sous la racine ou le fournisseur lorsqu’un composant personnalisé a besoin de l’état actuel. Les imports Ark directs restent une solution de repli pour les surfaces volontairement exclues de l’API moduix.

### Propriétés par défaut

| Propriété       | Par défaut             | Notes                                                        |
| --------------- | ---------------------- | ------------------------------------------------------------ |
| `defaultValue`  | `50`                   | Valeur initiale non contrôlée.                               |
| `min`           | `0`                    | Limite inférieure du pourcentage et de la valeur ARIA.       |
| `max`           | `100`                  | Limite supérieure du pourcentage et de la valeur ARIA.       |
| `formatOptions` | `{ style: 'percent' }` | Contrôle le formatage de `ValueText`.                        |
| `locale`        | `'en-US'`              | Locale utilisée par `Intl.NumberFormat`.                     |

### Notes sur le comportement

`ProgressCircular.Circle` reçoit d’Ark le rôle d’indicateur de progression et les attributs ARIA de valeur. Attribuez à `Ring` ou `Circle` un `aria-label` décrivant la tâche ; `ProgressCircular.Label` fournit un contexte visible, mais ne crée pas automatiquement cette association ARIA. Ark gère également les variables SVG de rayon, de circonférence, de pourcentage et de décalage du trait.

Toutes les parties fondées sur Ark, à l’exception de la structure fixe de `Ring`, prennent en charge `asChild` via la composition polymorphe. Préservez la sémantique des enfants de remplacement ainsi que celle de l’indicateur de progression sur le cercle.

`ProgressCircular.ValueText` annonce les changements avec `aria-live="polite"`. Conservez un libellé visible dans l’arbre ou fournissez `aria-label`/`aria-labelledby` lorsque la composition n’inclut pas `ProgressCircular.Label`.

### Hooks de style

- `data-slot="progress-circular-root"`, `progress-circular-root-provider`, `progress-circular-label`, `progress-circular-circle`, `progress-circular-circle-track`, `progress-circular-circle-range`, `progress-circular-value-text` et `progress-circular-view`.
- `ProgressCircular.Ring` utilise les mêmes `data-slot`, `className`, ref et variables de taille et d’épaisseur `--moduix-progress-circular-*` que `ProgressCircular.Circle`.
- Hooks Ark : `data-scope="progress"`, `data-part`, `data-state="indeterminate|loading|complete"`, `data-orientation`, `data-value` et `data-max`.
- Variables de cercle Ark : `--size`, `--thickness`, `--radius`, `--circumference`, `--percent` et `--offset`.
