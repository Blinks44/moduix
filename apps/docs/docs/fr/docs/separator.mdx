Ark UI ne fournit pas de primitive separator dédiée. ## Anatomie

`Separator` fournit une seule partie racine.

```text
Separator / Separator.Root
└─ root[data-scope="separator"][data-part="root"][data-slot="separator-root"]
```

| Partie                          | Rôle                                                                                                             |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `Separator` / `Separator.Root`  | Élément séparateur racine. Gère l’orientation, les métadonnées d’accessibilité et la recette visuelle.          |

Stylisez directement la racine avec `className`, `asChild` ou les propriétés CSS `--moduix-separator-*`.

## Composition

### Composition recommandée

Pour la plupart des séparateurs, utilisez la forme courte `<Separator />`. Elle équivaut à `<Separator.Root />` et maintient une forme racine publique cohérente avec les composants composés dans le style d’Ark.

### Quand créer une composition personnalisée

Utilisez `asChild` uniquement lorsqu’un autre élément hôte doit posséder le nœud DOM affiché. `Separator` affiche déjà un séparateur sémantique ; son enfant doit être un élément unique capable de recevoir les role, attributs ARIA et data fusionnés, ainsi que le nom de classe et la ref.

### Propriétés par défaut

| Propriété       | Valeur par défaut | Remarques                                                        |
| --------------- | ----------------- | ---------------------------------------------------------------- |
| `orientation`   | `horizontal`      | `horizontal`, `vertical`                                         |
| `variant`       | `solid`           | `solid`, `dashed`, `dotted`                                      |
| `size`          | `sm`              | `xs`, `sm`, `md`, `lg`                                           |
| `asChild`       | `false`           | Composition de la fabrique Ark avec un enfant unique             |
| `role`          | `separator`       | Transmettez `presentation` pour une utilisation décorative       |

### Comportement

- `Separator` définit `aria-orientation` lorsque son rôle est `separator`.
- Utilisez `role="presentation"` lorsque la ligne est purement décorative. Ce comportement diffère de la valeur décorative par défaut de shadcn : moduix conserve par défaut les séparateurs de contenu significatifs dans l’arbre d’accessibilité.
- Les séparateurs horizontaux occupent toute la largeur disponible par défaut.
- Les séparateurs verticaux mesurent `1em` de haut par défaut, ce qui les aligne naturellement avec le texte en ligne et les rangées d’actions compactes.
- `Separator` n’est pas interactif et ne fournit ni état, ni rappel, ni comportement disabled, ni gestion du focus.
- Pour créer des espaces vides, utilisez des primitives de disposition ou des tokens d’espacement.

## Styles

`Separator` fournit des sélecteurs de parties dans le style d’Ark et un contrat compact de variables CSS `--moduix-separator-*` pour la couleur, le style de bordure, l’épaisseur et la longueur dépendante de l’orientation.

### Points d’accroche CSS

- `data-scope="separator"` et `data-part="root"` définissent la partie racine dans le style d’Ark.
- `data-slot="separator-root"` est le sélecteur stable de moduix.
- `data-orientation="horizontal"` et `data-orientation="vertical"` ciblent les styles propres à chaque axe.
- `data-size="xs|sm|md|lg"` et `data-variant="solid|dashed|dotted"` exposent la recette visuelle.
- `className` et `style` sont appliqués directement à l’élément séparateur racine.
