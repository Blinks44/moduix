## Choisir le bon composant

Utilisez `Menu` pour les listes de commandes ouvertes par un déclencheur, les menus contextuels, les sélections
légères et les actions imbriquées.

- Choisissez **`Menu`** pour les actions supplémentaires, les actions de ligne et les listes de commandes ouvertes
  par un bouton ou un déclencheur contextuel.

## Exemple de base

```text
│  └─ Menu.Positioner
│     └─ Menu.Content
│        ├─ Menu.Arrow
│        │  └─ Menu.ArrowTip
│        ├─ Menu.Item
│        ├─ Menu.CheckboxItem
│        │  ├─ Menu.ItemIndicator
│        │  └─ Menu.ItemText
│        ├─ Menu.RadioItemGroup
│        │  └─ Menu.RadioItem
│        ├─ Menu.ItemGroup
│        │  └─ Menu.ItemGroupLabel
│        └─ Menu
│           └─ Menu.TriggerItem
```

| Partie | Rôle |
| --------------------- | ----------------------------------------------------------------- |
| `Menu` / `Menu.Root` | Racine Ark qui gère l’ouverture, le positionnement, la recherche par saisie et la fermeture. |
| `Menu.RootProvider` | Affiche un menu à partir d’une instance d’état `useMenu`.             |
| `Menu.Trigger` | Bouton d’ouverture ; utilisez `asChild` pour un élément personnalisé. |
| `Menu.Indicator` | Indicateur Ark qui reflète l’état du déclencheur.                   |
| `Menu.ContextTrigger` | Déclencheur par clic droit ou appui prolongé pour les menus contextuels. |
| `Menu.Positioner` | Positionne le calque flottant.                                      |
| `Menu.Content` | Surface contextuelle avec le rôle menu et la collection d’éléments.     |
| `Menu.Item` | Ligne de commande.                                                   |
| `Menu.CheckboxItem` | Option booléenne.                                   |
| `Menu.RadioItemGroup` | Groupe de choix exclusifs.            |
| `Menu.RadioItem` | Option mutuellement exclusive.                             |
| `Menu.TriggerItem` | Ligne qui ouvre un `Menu` imbriqué.                             |
| `Menu.ItemIndicator` | Indicateur de sélection des cases à cocher et des options radio.                     |

## Composition

La racine place automatiquement `Positioner` dans un portail. Utilisez `portalled={false}` pour un rendu dans le
flux ou `portalRef` pour choisir le conteneur. Les parties structurelles restent explicites et personnalisables.

### Composition recommandée

Gardez la structure de la fenêtre contextuelle explicite. `Menu.Content` est la véritable partie de contenu Ark ;
elle n’inclut plus implicitement `Menu.Positioner`.

```tsx
<Menu positioning={{ placement: 'bottom-start', gutter: 8 }}>
  <Menu.Trigger asChild>
    <Button>
      Actions
      <Menu.Indicator />
    </Button>
  </Menu.Trigger>
  <Menu.Positioner>
    <Menu.Content className="menu-content">
      <Menu.Item value="edit">Edit</Menu.Item>
    </Menu.Content>
  </Menu.Positioner>
</Menu>
```

### Quand créer une composition personnalisée

Utilisez `asChild` lorsqu’un déclencheur, un élément ou le contenu doit être affiché par un autre élément
sémantique. Transmettez un seul enfant afin qu’Ark puisse lui appliquer les attributs ARIA, le focus et le
comportement clavier. Pour un lien, placez `asChild` sur `Menu.Item` ; pour une surface personnalisée, placez-le sur
`Menu.Content`.

Un menu imbriqué est une racine `Menu` ordinaire dans le contenu du menu parent. Il utilise `Menu.TriggerItem`, puis
son propre `Menu.Positioner` et son propre `Menu.Content`.

### Propriétés par défaut

Par défaut, le contenu placé dans le portail est monté à la demande puis démonté après l’animation de fermeture.
Définissez `unmountOnExit={false}` pour le conserver après la première ouverture. Désactivez les deux propriétés de
cycle de vie uniquement si un rendu initial immédiat est nécessaire.

| Surface | Par défaut | Remarques |
| --------------------------------- | ------------ | ----------------------------------------------------------- |
| `Menu` / `Menu.Root` | — | Aucun autre comportement par défaut ; les valeurs Ark s’appliquent. |
| `Menu.CheckboxItem` / `RadioItem` | `start` | `indicator` contrôle la position de la colonne indicatrice.          |

### Comportement

- `lazyMount` et `unmountOnExit` valent `true` par défaut dans moduix. `open`, `defaultOpen`, `onOpenChange(details)`, `highlightedValue`, `onHighlightChange(details)`, `onSelect(details)`, `closeOnSelect`, `ids` et `present` sont transmis à Ark sans valeur par défaut supplémentaire dans moduix.
- Pour l'identité des éléments de menu, utilisez `value` plutôt que le `id` personnalisé.
- `Menu.CheckboxItem.onCheckedChange` reçoit le prochain état logique sélectionné.
- `Menu.RadioItemGroup.onValueChange` reçoit `details.value`.
- Utilisez `Menu.RootProvider` avec une instance de `useMenu` au lieu d’afficher une seconde racine `Menu` pour le même état.
- `Menu.Context`, `useMenuContext` et `useMenuItemContext` fournissent l'état Ark aux descendants pour une composition étendue.
- Les racines portent automatiquement `Menu.Positioner`. Utilisez `portalled={false}` pour laisser un menu dans une boîte de dialogue ou un conteneur déroulant, et combinez-le avec `positioning={{ strategy: 'fixed', hideWhenDetached: true }}` si le conteneur est déroulant.
- `Menu.Indicator` reprend la partie indicator d’Ark. `Menu.TriggerIcon`, `Menu.TriggerItemIcon`, `Menu.ItemShortcut` et les utilitaires de texte sont uniquement des raccourcis de présentation moduix.

### Points d’accroche CSS

- Attributs Ark : `[data-scope='menu']`, `[data-part='trigger']`, `[data-part='indicator']`, `[data-part='content']`, `[data-part='item']`, `[data-type='checkbox' | 'radio']`, `[data-state='open' | 'closed' | 'checked' | 'unchecked']`, `[data-current]`, `[data-highlighted]`, `[data-disabled]`, `[data-placement]` et `[data-side]`.
- Variables Ark : `--reference-width`, `--available-width`, `--available-height`, `--transform-origin`, `--layer-index`, `--arrow-size` et `--arrow-background`.
- Hooks moduix : `data-slot="menu-trigger"`, `menu-content`, `menu-item`, `menu-checkbox-item`, `menu-radio-item`, `menu-trigger-item`, `menu-item-indicator` et `menu-item-shortcut`.
