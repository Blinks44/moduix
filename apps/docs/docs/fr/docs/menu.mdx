## Choisir le bon composant

Utilisez `Menu` pour les listes de déclencheurs, les menus contextuels, la sélection simple et
actions imbriquées.

- Sélectionnez **`Menu`** pour les actions de débordement, les actions de ligne et les listes de commandes ouvertes par un bouton ou un déclencheur contextuel.

| `Menu.Positioner` | Positionneur de couche flottante.                                      |
| `Menu.Content` | Une surface pop-up avec le rôle d'un menu et d'une collection d'éléments.     |
| `Menu.Item` | Chaîne de commande.                                                   |
| `Menu.CheckboxItem` | Élément de paramètre booléen.                                   |
| `Menu.RadioItemGroup` | Un groupe d'une valeur sélectionnée pour les éléments radio.            |

## Composition

Root porte automatiquement `Positioner`. Utilisez `portalled={false}` pour le rendu en ligne et
`portalRef` pour un conteneur personnalisé ; les pièces structurelles restent explicites et disponibles pour le style.

### Composition recommandée

Gardez la structure contextuelle explicite. `Menu.Content` - partie réelle du contenu d'Ark ; il est plus grand
ne cache pas `Menu.Positioner`.

```tsx
<Menu positioning={{ placement: 'bottom-start', gutter: 8 }}>
  <Menu.Trigger asChild>
    <Button>
      Actions
      <Menu.Indicator />
    </Button>
  </Menu.Trigger>
  <Menu.Positioner>
    <Menu.Content className="menu-content">
      <Menu.Item value="edit">Edit</Menu.Item>
    </Menu.Content>
  </Menu.Positioner>
</Menu>
```

### Quand créer une composition personnalisée

Utilisez `asChild` lorsqu'un déclencheur, un élément ou un contenu doit être rendu par une autre sémantique
élément. Transmettez un enfant sémantique pour qu'Ark puisse appliquer les bons attributs ARIA,
Concentration et comportement du clavier. Pour les liens, mettez `asChild` à `Menu.Item` ; pour hôte personnalisé
fenêtre contextuelle - à `Menu.Content`.

Les menus imbriqués sont des racines `Menu` normales dans le contenu du menu parent. Utilisations racine imbriquées
`Menu.TriggerItem`, puis possède `Menu.Positioner` et `Menu.Content`.

### Propriétés par défaut

Le contenu de superposition porté est monté et démonté paresseusement après l'animation de fermeture par défaut.
Réglez `unmountOnExit={false}` pour l'enregistrer après la première ouverture ; installer les deux accessoires
cycle de vie dans `false`, uniquement lorsque le rendu initial sans délai est nécessaire.

| Surfaces | Par défaut | Remarques |
| --------------------------------- | ------------ | ----------------------------------------------------------- |
| `Menu` / `Menu.Root` | — | Il n’y a aucune implication comportementale supplémentaire ; Les valeurs Ark s'appliquent. |
| `Menu.CheckboxItem` / `RadioItem` | `start` | `indicator` contrôle la position de la colonne indicatrice.          |

### Notes de comportement

- `open`, `defaultOpen`, `onOpenChange(details)`, `highlightedValue`, `onHighlightChange(details)`, `onSelect(details)`, `closeOnSelect`, `ids`, `lazyMount`, `unmountOnExit` sont égaux à `true` par défaut ; `present` est transféré directement vers Ark.
- Pour l'identité des éléments de menu, utilisez `value` plutôt que le `id` personnalisé.
- `Menu.CheckboxItem.onCheckedChange` reçoit le prochain état logique sélectionné.
- `Menu.RadioItemGroup.onValueChange` reçoit `details.value`.
- `Menu.RootProvider` doit être utilisé avec une instance de `useMenu`, plutôt que de dessiner une deuxième racine `Menu` pour le même état.
- `Menu.Context`, `useMenuContext` et `useMenuItemContext` fournissent l'état Ark aux descendants pour une composition étendue.
- Les racines portent automatiquement `Menu.Positioner`. Utilisez `portalled={false}` pour laisser un menu dans une boîte de dialogue ou un conteneur déroulant, et combinez-le avec `positioning={{ strategy: 'fixed', hideWhenDetached: true }}` si le conteneur est déroulant.
- `Menu.Indicator` répète une partie de l'indicateur Ark. `Menu.TriggerIcon`, `Menu.TriggerItemIcon`, `Menu.ItemShortcut` et les assistants de texte d'élément sont uniquement des abréviations de feuille de module.
