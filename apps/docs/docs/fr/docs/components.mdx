# Composants

Les composants moduix sont des wrappers Ark UI stylisés et composables qui partagent un langage de
tokens commun. Commencez par le besoin produit ci-dessous, puis utilisez la barre latérale ou la
recherche pour le catalogue complet. Chaque page de composant présente l'arbre de parties public,
des exemples, le comportement aligné sur Ark et les variables CSS locales.

## Choisissez par interaction

| Si l'utilisateur a besoin de… | Commencez par |
| --- | --- |
| Sélectionner une valeur dans une liste connue | [Select](https://moduix.dev/docs/select) |
| Rechercher ou saisir une valeur lors d'une sélection | [Combobox](https://moduix.dev/docs/combobox) |
| Accomplir une tâche ciblée qui bloque la page | [Dialog](https://moduix.dev/docs/dialog) |
| Accomplir une tâche depuis un bord ou sur mobile | [Drawer](https://moduix.dev/docs/drawer) |
| Choisir une action dans une liste compacte | [Menu](https://moduix.dev/docs/menu) |
| Ouvrir un petit panneau non modal près de son déclencheur | [Popover](https://moduix.dev/docs/popover) |
| Présenter des lignes et colonnes en lecture seule | [Table](https://moduix.dev/docs/table) |
| Trier, filtrer, sélectionner ou paginer des enregistrements | [Recette Data Table](https://moduix.dev/docs/data-table) |

Quand deux composants semblent proches, choisissez selon le comportement de l'utilisateur plutôt
que selon l'apparence. La page du composant explique ensuite son modèle clavier, la composition
recommandée et les cas où un autre composant convient mieux.

Le catalogue complet des composants et leurs exemples sont actuellement disponibles
en [anglais](https://moduix.dev/docs/components).

## Avant de composer

- Utilisez le [Démarrage rapide](/docs/quick-start) pour choisir l'installation par paquet ou avec
  code source dans le projet.
- Lisez les [Patrons de composition](https://moduix.dev/docs/composition-patterns) avant de masquer des parties de
  composants dans des wrappers produit.
- Utilisez [Thèmes](/docs/themes) et [Tokens](/docs/tokens) pour les modifications visuelles à
  l'échelle du système ; réservez les alias de composants aux exceptions intentionnelles.
- Démarrez depuis les [Recettes](https://moduix.dev/docs/recipes) quand vous avez besoin d'un patron produit
  prêt à copier plutôt que d'une seule primitive.
