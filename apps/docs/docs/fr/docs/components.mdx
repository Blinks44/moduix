# Composants

Les composants moduix sont des wrappers Ark UI stylisés et composables qui partagent un langage de
tokens commun. Commencez par le besoin produit ci-dessous, puis utilisez la barre latérale ou la
recherche pour parcourir le catalogue complet. Chaque page de composant présente l'arbre public de
ses parties, des exemples, le comportement conforme à Ark et les variables CSS locales.

## Choisissez par interaction

| Si l'utilisateur a besoin de… | Commencez par |
| --- | --- |
| Sélectionner une valeur dans une liste connue | [Select (en anglais)](https://moduix.dev/docs/select) |
| Rechercher ou saisir une valeur lors d'une sélection | [Combobox (en anglais)](https://moduix.dev/docs/combobox) |
| Accomplir une tâche ciblée qui bloque la page | [Dialog (en anglais)](https://moduix.dev/docs/dialog) |
| Accomplir une tâche depuis un bord de l'écran ou sur mobile | [Drawer (en anglais)](https://moduix.dev/docs/drawer) |
| Choisir une action dans une liste compacte | [Menu (en anglais)](https://moduix.dev/docs/menu) |
| Ouvrir un petit panneau non modal près de son déclencheur | [Popover (en anglais)](https://moduix.dev/docs/popover) |
| Présenter des lignes et des colonnes en lecture seule | [Table (en anglais)](https://moduix.dev/docs/table) |
| Trier, filtrer, sélectionner ou paginer des enregistrements | [Recette Data Table](/docs/data-table) |

Lorsque deux composants semblent proches, choisissez selon le comportement de l'utilisateur plutôt
que selon leur apparence. La page du composant explique ensuite son modèle d'interaction au clavier,
la composition recommandée et les cas où un autre composant convient mieux.

## Avant de composer

- Utilisez le [Démarrage rapide](/docs/quick-start) pour choisir l'installation par paquet ou avec
  code source dans le projet.
- Lisez les [Modèles de composition](/docs/composition-patterns) avant de masquer des parties de
  composants dans des wrappers produit.
- Utilisez [Thèmes](/docs/themes) et [Tokens](/docs/tokens) pour les modifications visuelles à
  l'échelle du système ; réservez les alias de composants aux exceptions intentionnelles.
- Commencez par les [Recettes](/docs/recipes) lorsque vous avez besoin d'un modèle produit prêt à
  copier plutôt que d'une seule primitive.
