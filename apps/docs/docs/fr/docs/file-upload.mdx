## Anatomie

```text
FileUpload / FileUpload.Root
├─ FileUpload.Label
├─ FileUpload.Dropzone
│  ├─ FileUpload.DropzoneIcon
│  └─ FileUpload.Trigger
├─ FileUpload.ItemGroup[type]
│  ├─ FileUpload.Items
│  └─ FileUpload.Context
│     └─ FileUpload.Item[file]
│        ├─ FileUpload.ItemPreview[type]
│        │  ├─ FileUpload.ItemPreviewImage
│        │  └─ FileUpload.ItemPreviewIcon
│        ├─ FileUpload.ItemName
│        ├─ FileUpload.ItemMetadata[file]
│        ├─ FileUpload.ItemSizeText
│        └─ FileUpload.ItemDeleteTrigger
├─ FileUpload.ClearTrigger
└─ native input (automatic)
```

| Partie | Rôle |
| -------------------------------- | ------------------------------------------------------------------------ |
| `FileUpload` / `FileUpload.Root` | Gère l’état des fichiers, la validation, le glisser-déposer, l’insertion et l’intégration des formulaires. |
| `FileUpload.RootProvider` | Rend l’arbre de téléversement à partir de l’état renvoyé par `useFileUpload` d’Ark. |
| `FileUpload.Label` | Libellé accessible pour l’input masqué et les contrôles de téléversement.       |
| `FileUpload.Dropzone` | Cible de dépôt des fichiers. Utilisez `disableClick` avec un déclencheur imbriqué. |
| `FileUpload.DropzoneIcon` | Élément décoratif avec une icône de téléversement pour la zone de dépôt.         |
| `FileUpload.Trigger` | Un bouton qui ouvre le sélecteur de fichiers natif.                            |
| `FileUpload.ItemGroup` | Un wrapper de liste pour les fichiers acceptés ou rejetés.                      |
| `FileUpload.Items` | Cartes d’images ou lignes de fichiers avec aperçus, métadonnées et suppression. |
| `FileUpload.Context` | Contexte avec prop de rendu compatible Ark pour des lignes de fichiers personnalisées. |
| `FileUpload.Item` | Ligne de fichier. Transmettez l'objet actuel `file`.                           |
| `FileUpload.ItemPreview` | Emplacement d’aperçu conditionnel correspondant au type MIME.                     |
| `FileUpload.ItemPreviewImage` | Aperçu de l'image à l'intérieur du `ItemPreview`.                                |
| `FileUpload.ItemPreviewIcon` | Icône de fichier universelle pour secours dans `ItemPreview`.                 |
| `FileUpload.ItemName` | Texte du nom de fichier.                                                       |
| `FileUpload.ItemMetadata` | Type de fichier et taille localisée ; passer le `file` actuel.             |
| `FileUpload.ItemSizeText` | Texte de taille de fichier localisé.                                      |
| `FileUpload.ItemDeleteTrigger` | Supprime un fichier. Par défaut, il utilise l'icône de la corbeilmoduix.        |
| `FileUpload.ClearTrigger` | Efface les fichiers sélectionnés. Par défaut, il utilise l'icône de fermeture moduix. |

## Composition

### Composition recommandée

Gardez l'arborescence des parties d’Ark visible. Utilisez le `Trigger` pour les commandes de chargement compactes et le `Dropzone`
pour les surfaces de traînée. Si `Trigger` est imbriqué dans `Dropzone`, passez `disableClick` dans `Dropzone`,
afin que le sélecteur de fichiers natif ne s'ouvre pas deux fois.

La racine rend toujours l’input de formulaire natif. Utilisez `Items` pour les lignes compactes des fichiers acceptés. Lisez
les fichiers acceptés depuis `FileUpload.Context.acceptedFiles` et les fichiers rejetés depuis `FileUpload.Context.rejectedFiles`
lorsque des lignes personnalisées sont nécessaires.

Importez `FileUpload.Context`, `useFileUpload()` et `useFileUploadContext()` depuis `@moduix/react` lorsqu’un accès avancé à l’état est nécessaire.
Il s’agit de réexportations directes d’Ark : les objets des callbacks et les contrats d’état restent donc inchangés.

### Quand créer une composition personnalisée

`Items` rend les fichiers image sous forme de cartes verticales compactes et les autres fichiers sous forme de lignes horizontales avec leurs métadonnées.
Utilisez la composition explicite `Context` pour créer des lignes personnalisées. `ItemPreview.type` est un prédicat avec expression régulière,
et non une liste de priorités : rendez exactement un aperçu pour le fichier actuel. Par exemple, utilisez
`file.type.startsWith("image/")` pour sélectionner `ItemPreviewImage` ; sinon rendez `ItemPreviewIcon` puis composez
`ItemName`, `ItemMetadata file={file}` et `ItemDeleteTrigger`. Utilisez `asChild` uniquement lorsque l'élément enfant est
le seul élément sémantique capable de préserver le comportement souhaité d'un bouton, d'une étiquette ou d'une entrée.

### Propriétés par défaut

| Propriété | Par défaut | Remarques |
| --------------------- | ------------ | ----------------------------------------------------------------- |
| `allowDrop` | `true` | Permet le glisser-déposer dans `Dropzone`.                            |
| `maxFiles` | `1` | Augmentez ou supprimez cette limite pour téléverser plusieurs fichiers et dossiers. |
| `minFileSize` | `0` | Taille minimale du fichier reçu en octets.                   |
| `maxFileSize` | `∞` | La taille maximale du fichier reçu en octets.                  |
| `preventDocumentDrop` | `true` | Empêche la navigation accidentelle lors de la réinitialisation hors de la cible.            |
| `locale` | `en-US` | Utilisé pour formater la taille du fichier.                    |

### Notes de comportement

`acceptedFiles`, `defaultAcceptedFiles` et `onFileChange(details)` conservent l'état géré et non géré d’Ark.
`onFileAccept(details)` et `onFileReject(details)` conservent les objets details d’Ark. `Field.Root` et `Fieldset.Root` peuvent
fournir les états désactivé, invalide, obligatoire et en lecture seule. Utilisez `ids` lorsque des libellés ou des descriptions individuels
nécessitent des associations d’accessibilité stables.

### Hooks de style

Utilisez des emplacements moduix stables tels que `[data-slot="file-upload-dropzone"]`,
`[data-slot="file-upload-item"]` et `[data-slot="file-upload-item-delete-trigger"]`.
Ark fournit également `data-scope="file-upload"`, `data-part` pour les attributs spécifiques aux parties et à l'état :
`data-disabled`, `data-readonly`, `data-invalid`, `data-required`, `data-dragging` et `data-type`.
