## Référence API

Ark UI ne fournit pas de primitive `bleed` dédiée. Moduix construit ce composant avec l’outil officiel
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) et suit les recommandations d’Ark concernant la
[composition](https://ark-ui.com/docs/guides/composition), les [styles](https://ark-ui.com/docs/guides/styling) et les
[ref](https://ark-ui.com/docs/guides/ref).

Commencez par le comportement par défaut `inline="full"` lorsque des médias, des bannières ou des accents de section doivent dépasser un conteneur contraint tout en restant dans le flux normal du document.

## Anatomie

`Bleed` possède un seul élément racine conforme à Ark. Il applique à cette racine des marges négatives sur l’axe en ligne et/ou l’axe de bloc.

```text
Bleed.Root
└─ root[data-scope="bleed"][data-part="root"][data-slot="bleed-root"]
   └─ children
```

| Partie                 | Rôle                                                                       |
| ---------------------- | -------------------------------------------------------------------------- |
| `Bleed` / `Bleed.Root` | Enveloppe de mise en page racine pour le bleed sur les axes en ligne et de bloc. |
| `Bleed`                | Alias appelable de `Bleed.Root`.                                           |

## Composition

### Composition recommandée

Utilisez la forme courte `Bleed` lorsque la mise en page n’a besoin que de marges négatives contrôlées sur une seule enveloppe. `Bleed.Root` est la forme équivalente avec espace de noms, conforme à Ark.
C’est le chemin prévu pour les médias pleine largeur, les arrière-plans de sections imbriquées, les séparateurs et les bannières à l’intérieur d’enveloppes centrées ou dotées d’un espacement intérieur.

### Quand créer une composition personnalisée

Utilisez `className` et des remplacements locaux de `--moduix-bleed-*` lorsqu’un drawer, une zone de défilement imbriquée ou l’enveloppe d’une application nécessite un autre calcul du bleed complet que les valeurs par défaut fondées sur le viewport.

### Propriétés par défaut

| Élément     | Valeur par défaut | Valeurs / remarques                            |
| ----------- | ----------------- | ---------------------------------------------- |
| `inline`    | `full`            | `none`, `xs`, `sm`, `md`, `lg`, `xl`, `full`  |
| `block`     | `none`            | `none`, `xs`, `sm`, `md`, `lg`, `xl`          |
| `asChild`   | `false`           | Composition Ark factory                        |
| `className` | —                 | Appliqué à l’élément racine                    |

### Notes sur le comportement

- `Bleed.Root` affiche exactement un élément racine et lui transmet les propriétés `div` d’Ark factory.
- La `ref` pointe vers l’élément racine affiché. Avec `asChild`, elle pointe vers l’unique élément enfant.
- `asChild` exige un seul enfant sémantique capable d’accepter les propriétés DOM et une ref.
- Utilisez `inline` pour dépasser horizontalement et ajoutez `block` lorsque la surface doit également dépasser les espacements intérieurs verticaux.
- L’ancienne propriété `as` a été supprimée lors de la migration vers Ark. Utilisez `asChild` lorsqu’un élément sémantique doit posséder le nœud DOM.
- Utilisez l’une des valeurs fixes de l’échelle lorsque le contenu doit seulement dépasser l’espacement intérieur du conteneur, et non atteindre le bord du viewport.
- `inline="full"` utilise un calcul fondé sur le viewport ; les enveloppes imbriquées peuvent donc nécessiter des remplacements locaux de `--moduix-bleed-inline-full` et `--moduix-bleed-inline-full-size`.
- Les ancêtres avec `overflow: hidden` ou `overflow: clip` peuvent couper le bleed.
- Contrairement à la primitive de mise en page Chakra, moduix expose volontairement des modes `inline` et `block` fondés sur les tokens plutôt que les propriétés unilatérales `inlineStart`, `inlineEnd`, `blockStart` et `blockEnd`.

## Styles

`Bleed` expose un petit contrat de variables CSS et des attributs de données stables sur l’élément racine. Utilisez les variables lorsque le calcul de la mise en page doit changer, et `className` pour la surface visuelle à l’intérieur du bleed.

### Hooks de style

- `data-scope="bleed"` et `data-part="root"` fournissent des hooks conformes à Ark sur l’élément racine exporté.
- `data-slot="bleed-root"` est un sélecteur moduix stable sur l’élément racine exporté.
- `data-inline` reflète le mode de bleed actuel sur l’axe en ligne : `none`, `xs`, `sm`, `md`, `lg`, `xl` ou `full`.
- `data-block` reflète le mode de bleed actuel sur l’axe de bloc : `none`, `xs`, `sm`, `md`, `lg` ou `xl`.
- L’API CSS publique `--moduix-bleed-*` couvre à la fois les valeurs de bleed fondées sur l’échelle et le calcul du viewport utilisé par `inline="full"`.
