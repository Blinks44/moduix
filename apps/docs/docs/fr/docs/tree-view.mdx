## Anatomie

```text
TreeView / TreeView.Root
├─ TreeView.Label
└─ TreeView.Tree
   └─ TreeView.Node ou TreeView.NodeProvider
      ├─ TreeView.Branch
      │  ├─ TreeView.BranchControl
      │  │  ├─ TreeView.BranchIndicator
      │  │  └─ TreeView.BranchText
      │  └─ TreeView.BranchContent
      │     ├─ TreeView.BranchIndentGuide
      │     └─ nœuds imbriqués
      └─ TreeView.Item
         └─ TreeView.ItemText
```

| Partie | Rôle |
| --- | --- |
| `TreeView` / `TreeView.Root` | Gère la collection, la sélection, le développement, le focus, les cases à cocher et le renommage. |
| `TreeView.RootProvider` | Relie les parties à une instance de `useTreeView`. |
| `TreeView.Label` | Donne un nom accessible à l’arborescence. |
| `TreeView.Tree` | Conteneur ARIA de l’arborescence. |
| `TreeView.Node` | Provider pratique avec `{ node, indexPath, state }`. |
| `TreeView.NodeProvider` | Limite de contexte Ark de bas niveau pour une composition personnalisée. |
| `TreeView.Branch*` | Nœud extensible, déclencheur, indicateur, libellé et descendants. |
| `TreeView.Item*` | Élément terminal de l’arborescence et indicateur facultatif de l’état sélectionné. |
| `TreeView.NodeCheckbox*` | Contrôle d’arborescence avec case à cocher et indicateur d’état coché ou indéterminé. |
| `TreeView.NodeRenameInput` | Champ intégré affiché pendant le renommage d’un nœud. |

## Composition

### Approche recommandée

Utilisez `TreeView.Node` pour les moteurs de rendu récursifs habituels. Son callback de rendu reçoit les valeurs
actuelles `node` et `indexPath`, ainsi que l’état de nœud Ark `state` ; il peut donc choisir la composition d’une
branche ou d’un élément sans composant de contexte distinct. `NodeProvider` reste disponible lorsqu’un arbre de
composants personnalisé nécessite un contrôle direct.

### Déclencheur de développement dédié

Par défaut, `BranchControl` développe toute la ligne. Lorsque vous rendez un `BranchTrigger` distinct, définissez
`role="none"` sur `BranchControl` afin que le déclencheur ne soit pas imbriqué dans un autre élément interactif de
l’arborescence.

### Liens et autres éléments terminaux sémantiques

Utilisez `asChild` sur `TreeView.Item` pour un unique descendant sémantique, comme un lien. L’élément de remplacement
doit accepter les props Ark et conserver le comportement du clavier et du focus.

### État et comportement du clavier

Ark gère le pattern d’arborescence WAI-ARIA : focus mobile, navigation par flèches, Home/End, recherche à la saisie,
sélection, cases à cocher, nœuds désactivés, chargement asynchrone et touches de renommage. Contrôlez `expandedValue`,
`selectedValue`, `checkedValue` et `focusedValue` avec leurs callbacks de détails Ark.

| Prop | Valeur par défaut | Remarques |
| --- | --- | --- |
| `selectionMode` | `"single"` | Utilisez `"multiple"` pour sélectionner une plage ou employer des touches de modification. |
| `expandOnClick` | `true` | Un clic sur la ligne d’une branche la développe ou la réduit. |
| `typeahead` | `true` | Utilise `nodeToString` de la collection. |
| `lazyMount` | `false` | Diffère le rendu du contenu d’une branche jusqu’à son premier développement. |
| `unmountOnExit` | `false` | Démonte le contenu fermé après le cycle de fermeture. |

### Renommage et virtualisation

Activez le renommage intégré avec `canRename`, rendez `NodeRenameInput` tant que `state.renaming` vaut true, puis
mettez à jour la collection dans `onRenameComplete`. Pour les grandes arborescences, utilisez `RootProvider`,
`getVisibleNodes()` et `scrollToIndexFn` avec un virtualiseur ; moduix n’ajoute pas d’API de virtualisation concurrente.

### Root Provider

Créez l’état hors de l’arbre rendu avec `useTreeView` lorsque des contrôles situés ailleurs ont besoin de méthodes
comme `expand()` et `collapse()`. Dans l’aperçu, les deux contrôles et le retour d’état restent centrés dans `PreviewMeta`.

## Styles

Utilisez `className` sur les parties exportées pour la mise en forme structurelle. Les parties de branche exposent
`data-state="open|closed"`, les parties de case à cocher exposent
`data-state="checked|unchecked|indeterminate"` et les parties de nœud exposent `data-focus`,
`data-selected`, `data-disabled`, `data-loading`, `data-renaming`, `data-depth`, `data-path` et `data-value`.
L’enveloppe respecte les variables d’indentation Ark `--depth` et de mesure de réduction `--height`, et désactive
l’animation des branches lorsque la préférence de réduction des animations est activée.
