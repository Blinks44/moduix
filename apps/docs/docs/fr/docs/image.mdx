## Référence de l’API

`Image` est le wrapper moduix de l’élément `<img>`, construit autour d’[Unpic React](https://unpic.pics/img/react/). Ark UI ne fournit pas de primitive d’image dédiée à ce composant ; il conserve donc la composition native `<img>` et `<picture>` au lieu d’adapter une partie Ark. Consultez son [guide de composition](https://ark-ui.com/react/docs/guides/composition) pour ce modèle d’éléments natifs.

## Exemple de base

Utilisez `Image` avec l’URL d’un CDN d’images pris en charge et indiquez ses dimensions pour une mise en page contrainte standard. Unpic génère les attributs adaptatifs `srcSet` et `sizes`, tandis que le navigateur réserve à l’avance l’espace nécessaire à l’image.

## Anatomie

```text
Image / Image.Root
└─ img

picture (native)
├─ Image.Source
└─ Image / Image.Root
```

| Partie                 | Rôle                                                                                       |
| ---------------------- | ------------------------------------------------------------------------------------------ |
| `Image` / `Image.Root` | Image native adaptative ; Unpic génère `srcSet`, `sizes` et les styles.                     |
| `Image.Source`         | Élément `<source>` adaptatif destiné à un élément natif `<picture>`.                        |

## Composition

### Composition recommandée

`Image` est la forme racine courte, équivalente à `Image.Root`. Utilisez `width` et `height` avec le `layout="constrained"` par défaut pour préserver le rapport de dimensions de la ressource et éviter les décalages de mise en page. Pour les URL distantes de fournisseurs pris en charge, Unpic détecte le fournisseur et génère automatiquement les entrées `srcSet` transformées.

Utilisez `priority` uniquement pour les images qui doivent se charger immédiatement, comme l’image principale d’un hero au-dessus de la ligne de flottaison. Cette propriété active le chargement immédiat et une priorité de récupération élevée, sauf si `loading` ou la propriété React `fetchPriority` en camelCase sont fournis explicitement.

### Quand créer une composition personnalisée

Utilisez un élément natif `<picture>` avec `Image.Source` pour la direction artistique ou pour fournir différentes sources selon les media queries. Gardez `Image` comme dernier enfant afin de fournir l’image de repli. Transmettez `fallback`, `options` ou `operations` si une URL non reconnue doit utiliser un fournisseur Unpic précis.

Pour sélectionner un format, placez une `Image.Source` avec une valeur `type` avant la source équivalente sans `type` ; le navigateur utilise le premier format pris en charge.

### Propriétés par défaut

| Propriété                | Valeur par défaut                    | Remarques                                                                        |
| ------------------------ | ------------------------------------ | -------------------------------------------------------------------------------- |
| `layout`                 | `constrained`                        | Respecte les dimensions fournies et se réduit si nécessaire.                     |
| `loading`                | `lazy`                               | Devient `eager` lorsque `priority` est défini.                                    |
| `decoding`               | `async` pour les images sans `priority` | Une valeur native est conservée ; omise par défaut avec `priority`.             |
| `fetchPriority`          | `high` avec `priority`               | Une valeur native remplace la valeur par défaut de `priority`.                    |
| `objectFit`              | `cover`                              | Appliqué via les styles en ligne générés par Unpic.                               |
| `--moduix-image-radius`  | `var(--moduix-radius-md)`            | Rayon visible par défaut de moduix.                                               |

### Comportement

- `fixed` conserve les dimensions indiquées en pixels CSS et peut déborder d’un parent plus étroit, tandis que `fullWidth` remplit la largeur du conteneur.
- `alt` est obligatoire pour les images porteuses de sens. Pour une image décorative, utilisez `alt=""` ; Unpic applique alors `role="presentation"`, sauf si vous remplacez explicitement ce rôle.
- Unpic génère `srcSet` à partir de l’URL source. Utilisez `breakpoints` lorsque ses largeurs adaptatives par défaut ne conviennent pas.
- Les propriétés natives `loading`, `decoding` et `fetchPriority` de React en camelCase restent disponibles lorsque les valeurs générées ne correspondent pas aux besoins de chargement de l’image.
- `background="auto"` crée un arrière-plan basse résolution chez les fournisseurs pris en charge. Celui-ci reste après le chargement ; utilisez-le donc uniquement pour les images opaques ou fournissez une valeur d’arrière-plan choisie explicitement.
- `unstyled` désactive les styles de mise en page en ligne générés par Unpic ; les styles d’affichage et de rayon ainsi que les sélecteurs `data-slot` de moduix restent disponibles. Utilisez-le lorsque des sources avec direction artistique nécessitent d’autres règles de mise en page adaptative, puis définissez ces règles dans votre propre CSS.

### Taille fixe

Utilisez `layout="fixed"` lorsque l’image doit conserver des dimensions exactes en pixels CSS. Vérifiez que son parent dispose de suffisamment d’espace : les images fixes ne se réduisent pas pour tenir dans un conteneur plus étroit.

### Points d’accroche CSS

- `data-slot="image-root"` permet de styliser l’élément `<img>` affiché.
- `data-slot="image-source"` sélectionne le nœud source dans un élément natif `<picture>`.
- `className` sur `Image` est la méthode recommandée pour appliquer des styles locaux. Par défaut, la racine est un élément de type bloc.
