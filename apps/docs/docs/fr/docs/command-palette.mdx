## Référence de l’API

Ark UI ne propose pas de primitive `command-palette` dédiée. Moduix construit ce composant avec l’outil officiel
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory), conformément aux recommandations d’Ark sur
la [composition](https://ark-ui.com/docs/guides/composition), les [styles](https://ark-ui.com/docs/guides/styling) et
les [refs](https://ark-ui.com/docs/guides/ref), et compose Ark [`Dialog`](https://ark-ui.com/docs/components/dialog)
avec Ark [`Combobox`](https://ark-ui.com/docs/components/combobox) pour le comportement.

## Exemple de base

Utilisez `CommandPalette.Panel` pour l’enveloppe de dialogue standard et placez `CommandPalette.Combobox` à l’intérieur.
`CommandPalette.Search` affiche une barre de recherche semblable à un champ de saisie avec un bouton d’effacement :
celui-ci apparaît après la saisie et efface la requête. La collection reste hors de l’arbre rendu, comme dans les
exemples Ark Combobox.

## Composition

Le composant racine place automatiquement `Backdrop` et `Positioner` dans un portail. Utilisez `portalled={false}`
pour un rendu intégré ou `portalRef` pour un conteneur personnalisé ; les parties structurelles restent explicites et
accessibles aux styles.

### Composition recommandée

Utilisez `useListCollection` avec `itemToString`, `itemToValue` et `groupBy`, puis appelez
`filter(details.inputValue)` depuis `onInputValueChange` de `CommandPalette.Combobox`. Utilisez
`CommandPalette.Panel` pour l’enveloppe d’overlay récurrente et `CommandPalette.Search` pour la barre de recherche
standard avec action d’effacement.

### Quand créer une composition personnalisée

Rendez directement `Backdrop`, `Positioner`, `Content`, `Header`, `Body`, `Control`, `Input` et `ClearTrigger` lorsque
vous avez besoin d’une structure d’overlay ou d’éléments de recherche personnalisés. Définissez `closeOnSelect={false}`
sur `CommandPalette.Combobox` si la sélection doit mettre à jour l’état de la palette au lieu de fermer le dialogue.
Pour un libellé accessible recommandé, utilisez `aria-label` sur le composant racine ou rendez `CommandPalette.Title`
si la composition exige un titre de dialogue visible. `CommandPalette.ItemIndicator` rend l’icône de confirmation
standard et peut partager la zone de fin de ligne avec `ItemMeta`. Utilisez `CommandPalette.RootProvider` pour un état
de dialogue externe créé avec `useDialog` d’Ark ; importez les API avancées du provider et du contexte Combobox
directement depuis `@ark-ui/react/combobox` si nécessaire. Les autres propriétés racine Ark Dialog, dont `ids`,
`initialFocusEl`, `finalFocusEl`, `present` et `onExitComplete`, conservent leurs contrats ; les refs des parties pointent
vers les parties DOM Ark correspondantes. La palette ne rend pas de `HiddenInput`, car elle sert à exécuter des actions,
pas à gérer un formulaire.

### Propriétés par défaut

Par défaut, le contenu de l’overlay dans le portail est monté à la demande et démonté après l’animation de sortie.
Définissez `unmountOnExit={false}` pour le conserver après la première ouverture ; désactivez les deux propriétés de
cycle de vie uniquement lorsqu’un rendu initial immédiat est nécessaire.

| Propriété                                   | Valeur par défaut | Remarques                                                                         |
| ------------------------------------------- | ----------------- | --------------------------------------------------------------------------------- |
| `CommandPalette.shortcut`                   | `false`           | Transmettez `alt+k` ou un autre modificateur principal avec une touche pour l’activer. |
| `CommandPalette.shortcutTarget`             | `document`        | Utilisé uniquement avec `shortcut` ; `null` n’enregistre aucun gestionnaire.      |
| `CommandPalette.lazyMount`                  | `true`            | Diffère la création du DOM du dialogue jusqu’à l’ouverture.                       |
| `CommandPalette.unmountOnExit`              | `true`            | Conserve le DOM pendant l’animation de sortie, puis le démonte.                   |
| `CommandPalette.Combobox.open`              | `true`            | Maintient la listbox visible tant que le dialogue est monté.                      |
| `CommandPalette.Combobox.inputBehavior`     | `autohighlight`   | Met en surbrillance la première commande correspondante pendant la saisie.        |
| `CommandPalette.Combobox.selectionBehavior` | `preserve`        | Conserve la requête saisie au lieu de la remplacer par l’élément sélectionné.     |
| `CommandPalette.Combobox.disableLayer`      | `true`            | N’ajoute pas de couche dismissable superflue dans le dialogue.                    |
| `CommandPalette.Combobox.closeOnSelect`     | `true`            | Ferme également le dialogue après la sélection dans Ark Combobox.                 |

### Comportement

Le gestionnaire de raccourci est activé explicitement, car les pages de documentation et les applications complexes
peuvent monter plusieurs palettes à la fois. Il accepte un modificateur et une touche, par exemple `mod+k`, `ctrl+1`,
`meta+k` ou `alt+k`. Les alias `mod`, `ctrl` / `control`, `meta` / `cmd` / `command` et `alt` / `option` sont pris en
charge. Lorsqu’il est activé, le gestionnaire ignore les événements keydown répétés et les cibles `input`, `textarea`,
`select` et `contenteditable` tant que la palette est fermée ; une nouvelle pression du même raccourci ferme la palette
ouverte. `alt+k` est recommandé dans la documentation, car la recherche utilise `Cmd+K`. Le modificateur `mod` accepte
Meta ou Control, ce qui rend le composant indépendant de la plateforme. `CommandPalette.ClearTrigger` efface
`inputValue`, pas la valeur sélectionnée du Combobox, et reste masqué pour une requête vide. `CommandPalette` conserve
`onOpenChange(details)` d’Ark, et `CommandPalette.Combobox` les objets de détails des callbacks Ark Combobox, notamment
`onInputValueChange(details)`, `onSelect(details)` et `onValueChange(details)`.

### Points d’accroche CSS

- Les parties visuelles exportées fournissent les hooks `data-slot` stables suivants : `command-palette-trigger`,
  `command-palette-backdrop`, `command-palette-positioner`, `command-palette-content`, `command-palette-list`,
  `command-palette-scroll-area`, `command-palette-scrollbar` et `command-palette-item`.
- Les hooks d’état Ark Dialog comprennent `data-scope="dialog"`, `data-part` et `data-state="open" | "closed"` sur
  l’arrière-plan et le contenu.
- Les hooks d’état Ark Combobox comprennent `data-scope="combobox"`, `data-part`, `data-state`, `data-highlighted`,
  `data-disabled`, `data-invalid` et `data-empty`.
- L’animation est liée à `data-state` d’Ark ; les anciens attributs `data-starting-style`, `data-ending-style` et
  `data-open` ne font pas partie du contrat de command-palette.
