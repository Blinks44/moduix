## Anatomie

```text
NumberInput.Root
├─ NumberInput.Label
├─ NumberInput.Scrubber (optional)
├─ NumberInput.Field (recommended)
├─ NumberInput.Control
│  ├─ NumberInput.DecrementTrigger
│  ├─ NumberInput.Input
│  └─ NumberInput.IncrementTrigger
└─ NumberInput.ValueText (optional)

NumberInput.RootProvider
└─ same part tree connected to state created with `useNumberInput()`
```

| Partie                             | Rôle                                                                         |
| ---------------------------------- | ---------------------------------------------------------------------------- |
| `NumberInput` / `NumberInput.Root` | Gère l’état du champ numérique, l’analyse, le formatage et le clavier.        |
| `NumberInput.RootProvider`         | Relie les parties à l’état créé avec `useNumberInput()`.                     |
| `NumberInput.Context`              | Fournit les valeurs formatée et numérique ainsi que les méthodes impératives. |
| `NumberInput.Label`                | Libellé accessible associé au champ géré.                                    |
| `NumberInput.Scrubber`             | Zone de glissement facultative qui modifie la valeur par déplacement du pointeur. |
| `NumberInput.Control`              | Conteneur structurel du champ et des déclencheurs d’incrémentation et de décrémentation. |
| `NumberInput.Field`                | Affiche le contrôle, le champ et le groupe de déclencheurs par défaut.       |
| `NumberInput.DecrementTrigger`     | Bouton qui diminue la valeur actuelle. Utilise par défaut l’icône moins de moduix. |
| `NumberInput.Input`                | Champ de texte numérique modifiable géré par Ark UI.                         |
| `NumberInput.IncrementTrigger`     | Bouton qui augmente la valeur actuelle. Utilise par défaut l’icône plus de moduix. |
| `NumberInput.ValueText`            | Zone de texte en lecture seule pour la valeur formatée.                      |

## Composition

### Composition recommandée

`NumberInput` prend en charge l’analyse, les contrôles de plage, l’incrémentation et la décrémentation au clavier,
la répétition lors d’un appui prolongé, l’interaction par glissement et le formatage. Activez `allowMouseWheel`
lorsque les modifications à la molette sont intentionnelles. Utilisez `NumberInput.Field` pour les parties visibles
par défaut.

Utilisez des chaînes pour `value` et `defaultValue`. Ark signale les modifications avec
`onValueChange(details)`, où `details.value` est la valeur sous forme de chaîne et `details.valueAsNumber` le nombre analysé.

### Quand créer une composition personnalisée

Utilisez `NumberInput.Control` avec ses parties individuelles lorsque l’ordre des déclencheurs, les icônes ou les
styles du champ doivent différer de `NumberInput.Field`. Ajoutez `NumberInput.Scrubber` à côté du champ pour permettre
la modification par glissement.

### Propriétés par défaut

| Propriété                          | Valeur par défaut | Remarques                                                        |
| ---------------------------------- | ----------------- | ---------------------------------------------------------------- |
| `NumberInput` / `NumberInput.Root` | —                 | Aucun comportement supplémentaire ; les valeurs Ark s’appliquent. |
| `NumberInput.Field`                | —                 | Affiche le contrôle, le champ et le groupe de déclencheurs par défaut. |
| `NumberInput.DecrementTrigger`     | —                 | Affiche l’icône moins de moduix lorsqu’aucun enfant n’est fourni. |
| `NumberInput.IncrementTrigger`     | —                 | Affiche l’icône plus de moduix lorsqu’aucun enfant n’est fourni.  |

### Comportement

- Pour le formatage localisé des nombres, utilisez `formatOptions` et non `format`.
- Utilisez `translations.incrementLabel`, `translations.decrementLabel` et `translations.valueText` pour les libellés accessibles localisés.
- `min`, `max`, `step`, `allowOverflow`, `clampValueOnBlur`, `spinOnPress`, `inputMode` et `allowMouseWheel` sont transmis directement à Ark.
- `onValueInvalid(details)` signale `rangeUnderflow` ou `rangeOverflow` lorsque la valeur dépasse les limites configurées.
- Définissez `clampValueOnBlur={false}` si les valeurs saisies hors de `min` ou `max` doivent rester inchangées à la perte du focus.
- Utilisez `ids` lorsque des libellés ou descriptions externes ont besoin d’identifiants d’élément stables.
- Les parties basées sur Ark prennent en charge `asChild` pour composer un hôte personnalisé ; `NumberInput.Field`
  affiche volontairement sa structure fixe en trois parties et transmet sa référence à `NumberInput.Control`.
- `useNumberInput`, `useNumberInputContext` et `NumberInput.Context` sont disponibles depuis `@moduix/react`.
- Pour soumettre une valeur numérique, affichez un champ natif masqué depuis `NumberInput.Context` avec
  `context.valueAsNumber`.
