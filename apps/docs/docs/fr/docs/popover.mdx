## Choisir le bon composant

Utilisez `Popover` pour un contenu interactif compact associé à un déclencheur. Utilisez `Tooltip` pour les indications
non interactives et `Dialog` pour les flux plus importants ou fortement interruptifs.

## Anatomie

```text
Popover / Popover.Root
├─ Popover.Anchor (optional)
├─ Popover.Trigger
│  └─ Popover.Indicator (optional)
└─ Overlay subtree (automatically portalled)
   └─ Popover.Positioner
      └─ Popover.Content
         ├─ Popover.Arrow
         │  └─ Popover.ArrowTip
         ├─ Popover.Header
         │  ├─ Popover.Title
         │  └─ Popover.Description
         ├─ Popover.Body
         ├─ Popover.Footer
         └─ Popover.CloseTrigger / Popover.CloseIcon
```

| Partie                       | Rôle                                                                  |
| ---------------------------- | --------------------------------------------------------------------- |
| `Popover` / `Popover.Root`   | État racine, cycle de vie, fermeture, focus et positionnement.        |
| `Popover.RootProvider`       | Affiche un arbre Popover depuis l’état renvoyé par `usePopover`.      |
| `Popover.Context`            | Lit l’état actuel via une propriété de rendu descendante.             |
| `Popover.Anchor`             | Référence de positionnement personnalisée facultative.                |
| `Popover.Trigger`            | Bouton qui ouvre ou ferme le Popover et peut porter une `value`.      |
| `Popover.Indicator`          | Indicateur facultatif de l’état du déclencheur.                       |
| `Popover.Positioner`         | Calque flottant qui expose les variables CSS de positionnement Ark.   |
| `Popover.Content`            | Surface contextuelle interactive.                                    |
| `Popover.Arrow` / `ArrowTip` | Flèche positionnée facultative et sa pointe visible.                  |
| `Popover.Title`              | Titre accessible relié au contenu.                                   |
| `Popover.Description`        | Description accessible reliée au contenu.                            |
| `Popover.CloseTrigger`       | Déclencheur de fermeture de bas niveau.                              |
| `Popover.CloseIcon`          | Aide de fermeture partagée sous forme d’icône, fondée sur le déclencheur Ark. |
| `Popover.Header` / `Body`    | Conteneurs de mise en page moduix avec slots stables.                 |
| `Popover.Footer`             | Conteneur moduix de rangée d’actions avec slot stable.                |

## Composition

La racine place automatiquement `Positioner` dans un portail. Utilisez `portalled={false}` pour un rendu en ligne
et `portalRef` pour un conteneur personnalisé ; les parties structurelles restent explicites et personnalisables.

### Composition recommandée

Conservez `Popover.Positioner` et `Popover.Content` explicites. `Popover` équivaut à `Popover.Root`. Configurez
le placement, la gestion des collisions, les décalages et la largeur identique avec `positioning`.

### Quand créer une composition personnalisée

Utilisez `Anchor` lorsque la référence de positionnement diffère du déclencheur. Utilisez `asChild` avec un seul
enfant sémantique pour personnaliser l’hôte du déclencheur, de l’ancre, du contenu ou du déclencheur de fermeture.
Définissez `portalled={false}` lorsqu’un Popover à l’intérieur d’une autre superposition doit être affiché en ligne.
Utilisez `lazyMount` et `unmountOnExit` uniquement lorsque le montage différé et le retrait après l’animation de sortie sont utiles.

### Propriétés par défaut

Le contenu de la superposition dans le portail est monté à la demande et retiré après son animation de sortie par défaut.
Définissez `unmountOnExit={false}` pour le conserver après la première ouverture ; définissez les deux propriétés de
cycle de vie à `false` uniquement si un rendu initial immédiat est nécessaire.

| Propriété                | Valeur par défaut | Remarques                                                        |
| ------------------------ | ----------------- | ---------------------------------------------------------------- |
| `autoFocus`              | `true`            | Place le focus sur le premier élément interactif à l’ouverture.  |
| `closeOnEscape`          | `true`            | Ferme le Popover avec Échap.                                     |
| `closeOnInteractOutside` | `true`            | Ferme le Popover lors d’une interaction extérieure.              |
| `lazyMount`              | `true`            | Diffère le montage du contenu jusqu’à la première ouverture.     |
| `modal`                  | `false`           | Active le piège à focus, le verrouillage du défilement et l’isolation extérieure. |
| `portalled`              | `true`            | Place le positionneur dans un portail et préserve le comportement de tabulation Ark. |
| `portalRef`              | -                 | Cible un conteneur de portail personnalisé.                      |
| `skipAnimationOnMount`   | `false`           | Conserve l’animation de présence initiale.                       |
| `unmountOnExit`          | `true`            | Retire le contenu après l’animation de sortie.                   |
| `defaultOpen`            | -                 | État d’ouverture initial non contrôlé.                           |
| `open`                   | -                 | État d’ouverture contrôlé.                                       |
| `ids`                    | -                 | Identifiants stables du déclencheur, du contenu, du titre, de la description et de l’ancre. |
| `initialFocusEl`         | -                 | Fonction qui renvoie l’élément à cibler à l’ouverture.           |
| `positioning`            | -                 | Options de positionnement flottant Ark.                          |
| `present`                | -                 | Présence contrôlée pour les cycles de vie d’animation JavaScript. |

### Comportement

- Les références sont transmises aux parties DOM Ark sous-jacentes : `Trigger` et `CloseTrigger` ciblent des boutons,
  tandis que `Anchor`, `Positioner`, `Content`, `Arrow`, `ArrowTip`, `Title`, `Description`, `Indicator`, `Header`,
  `Body` et `Footer` ciblent leurs éléments affichés.
- `onOpenChange` reçoit `{ open }` ; les rappels ne sont pas convertis en valeurs positionnelles.
- `modal` est un booléen qui active le piège à focus, le verrouillage du défilement, le blocage des interactions extérieures
  et l’isolation pour les lecteurs d’écran.
- `RootProvider` reçoit l’objet renvoyé par `usePopover` ; n’enveloppez pas le même état dans `Root`.
- `Popover.Context` et `usePopoverContext` exposent l’état Ark actuel aux descendants. Le hook est exporté depuis
  `@moduix/react` ; utilisez `Context` lorsqu’une propriété de rendu est plus lisible.
- `usePopover` est exporté pour posséder l’état Ark avec `RootProvider`.
- `Popover.Arrow` affiche l’élément `ArrowTip` par défaut ; affichez `ArrowTip` explicitement uniquement pour le personnaliser.
- Ark ferme le Popover avec Échap et lors d’une interaction extérieure par défaut. Ces comportements peuvent être désactivés séparément.
- Utilisez `ids` lorsque des identifiants stables sont nécessaires pour le déclencheur, le contenu, le titre, la description, l’ancre ou le déclencheur de fermeture.
- Les animations CSS de sortie utilisent l’état de présence fermé d’Ark. Utilisez `present` pour les cycles de vie pilotés par JavaScript.
- Pour un contenu qui peut dépasser la hauteur disponible, placez la zone défilable dans `Popover.Body`.

### Points d’accroche CSS

Les parties Ark conservent `data-scope="popover"` et leurs valeurs de `data-part`. Chaque partie affichée exportée
accepte `className` ; moduix ajoute `data-slot="popover-*"` aux conteneurs affichés. Ciblez
`data-state="open|closed"`, `data-placement`, `data-nested`, `data-has-nested` et `data-expanded` pour adapter les styles
à l’état. Lorsque plusieurs déclencheurs possèdent une `value`, utilisez `data-current` pour ne styliser que celui qui
a ouvert le Popover.

`Positioner` expose `--reference-width`, `--reference-height`, `--available-width`, `--available-height`, `--x`, `--y`,
`--z-index` et `--transform-origin`. `Content` expose `--layer-index` et `--nested-layer-count` ; `Arrow` expose les
variables de mesure de la flèche Ark.
