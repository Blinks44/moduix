## Anatomie

Le parcours habituel pour les consommateurs reste proche du balisage natif des tableaux :

```text
Table.ScrollArea (facultatif)
└─ Table
   ├─ Table.ColumnGroup (facultatif)
   │  └─ Table.Column
   ├─ Table.Caption (facultatif)
   ├─ Table.Header
   │  └─ Table.Row
   │     └─ Table.ColumnHeader
   ├─ Table.Body
   │  ├─ Table.Row
   │  │  └─ Table.Cell
   │  └─ Table.Empty (facultatif)
   └─ Table.Footer (facultatif)
```

| Partie                 | Rôle                                                                             |
| ---------------------- | -------------------------------------------------------------------------------- |
| `Table`                | Racine native `table`. Gère la typographie, les séparateurs et les attributs d’état. |
| `Table.ScrollArea`     | Surface facultative à bordure et débordement pour le cas courant du tableau encadré. |
| `Table.ColumnGroup`    | Enveloppe native `colgroup` pour répartir la largeur des colonnes.               |
| `Table.Column`         | Enveloppe native `col`. Accepte `htmlWidth`.                                      |
| `Table.Caption`        | Libellé facultatif au-dessus ou au-dessous du tableau via `side`.                 |
| `Table.Header`         | Enveloppe native `thead` des en-têtes de colonne.                                 |
| `Table.Body`           | Enveloppe native `tbody` des lignes de contenu.                                   |
| `Table.Footer`         | Enveloppe native `tfoot` des lignes de synthèse.                                  |
| `Table.Row`            | Enveloppe native `tr` avec gestion des séparateurs.                               |
| `Table.ColumnHeader`   | Enveloppe native `th`. Accepte `numeric`.                                         |
| `Table.Cell`           | Enveloppe native `td`. Accepte `numeric`.                                         |
| `Table.Empty`          | Ligne d’état vide pratique à l’intérieur de `Table.Body`.                         |

## Composition

### Composition recommandée

Pour la plupart des vues de données en lecture seule, conservez `Table.ScrollArea` avec les parties sémantiques du
tableau.

Utilisez `Table.ScrollArea` pour obtenir la surface courante à bordure avec défilement horizontal. Utilisez
`numeric` sur `Table.ColumnHeader` et `Table.Cell` pour les montants, les quantités, les pourcentages et les colonnes
de latence. Utilisez `Table.Caption` lorsque le tableau nécessite un libellé ou un résumé court, et `Table.Footer`
lorsque la dernière ligne représente des totaux ou des agrégats. Utilisez `striped`, `interactive`,
`showColumnBorder`, `stickyHeader` et `size` / `variant` lorsque le tableau nécessite des modes visuels inspirés de
Chakra sans ajouter l’état d’une data grid.

### Quand créer une composition personnalisée

Omettez `Table.ScrollArea` lorsque la mise en page environnante gère déjà le défilement, le padding, la bordure ou
les styles de surface. Conservez alors `Table` et déplacez ces responsabilités d’enveloppe dans votre propre
composant de mise en page ou balisage de surface.

`Table` ne gère volontairement ni le tri, ni le filtrage, ni la sélection, ni la pagination, ni l’état des actions
de ligne. Considérez-le comme la primitive visuelle et sémantique sur laquelle des abstractions de tableau de plus
haut niveau peuvent s’appuyer. Pour l’état et le rendu de TanStack Table, consultez le guide de composition
[Data Table](/docs/data-table).

### Propriétés par défaut

Toutes les parties acceptent `className` et les propriétés natives de l’élément correspondant.

| Composant            | Propriété          | Par défaut | Remarques                                                      |
| -------------------- | ------------------ | ---------- | -------------------------------------------------------------- |
| `Table`              | `interactive`      | `false`    | Active la mise en évidence au survol des lignes de contenu.    |
| `Table`              | `showColumnBorder` | `false`    | Ajoute des bordures entre les colonnes visibles.               |
| `Table`              | `size`             | `'md'`     | Accepte `'sm'`, `'md'` et `'lg'`.                              |
| `Table`              | `stickyHeader`     | `false`    | Rend `Table.Header` sticky dans un conteneur défilant.         |
| `Table`              | `striped`          | `false`    | Alterne le fond des lignes paires, hors lignes vides.          |
| `Table`              | `variant`          | `'line'`   | Accepte `'line'` et `'outline'`.                               |
| `Table.Caption`      | `side`             | `'bottom'` | Accepte `'top'` et `'bottom'`.                                 |
| `Table.Column`       | `htmlWidth`        | —          | Correspond à l’attribut natif `width` de `col`.                |
| `Table.ColumnHeader` | `numeric`          | `false`    | Aligne le contenu à la fin inline et utilise des chiffres tabulaires. |
| `Table.Cell`         | `numeric`          | `false`    | Aligne le contenu à la fin inline et utilise des chiffres tabulaires. |
| `Table.Empty`        | `colSpan`          | obligatoire | Doit correspondre au nombre actuel de colonnes du corps.       |

### Notes sur le comportement

- `Table.Empty` affiche une ligne complète pour l’état vide : transmettez donc le nombre de colonnes du corps via
  `colSpan`. Sa ligne expose `data-empty` et ne reçoit ni les rayures ni les styles de survol interactifs.
- Les lignes d’en-tête et de contenu affichent un séparateur inférieur commun. La dernière ligne de contenu n’a pas
  de bordure.
- Les lignes de contenu reçoivent un arrière-plan discret au survol uniquement lorsque `interactive` est défini.
- `Table.Caption` hérite d’une typographie atténuée et ajoute un padding inline afin de ne pas toucher les bords du
  tableau.

## Styles

Stylisez `Table` avec `className`, les hooks publics `data-slot`, les attributs `data-side` et `data-numeric`, ainsi
que les variables CSS `--moduix-table-*` présentées ci-dessous.

### Hooks de style

Utilisez la partie responsable de l’aspect visuel concerné :

- `className` sur `Table.ScrollArea` pour remplacer la bordure, le rayon et la surface de l’enveloppe entière
- `className` sur `Table` pour la typographie du tableau et les contraintes de largeur
- `data-slot="table-root"`, `table-scroll-area`, `table-column-group`, `table-column`, `table-caption`,
  `table-header`, `table-body`, `table-footer`, `table-row`, `table-column-header`, `table-cell` et `table-empty` pour
  cibler chaque partie
- `data-side="top" | "bottom"` sur `Table.Caption` pour styliser la position de la légende
- `data-numeric` sur `Table.ColumnHeader` et `Table.Cell` pour cibler les colonnes numériques
- `data-empty` sur la ligne générée par `Table.Empty` pour cibler la ligne vide
- `data-size`, `data-variant`, `data-striped`, `data-interactive`, `data-sticky-header` et
  `data-show-column-border` sur `Table` pour les styles d’état au niveau de la racine
- `data-sticky="start" | "end"` sur `Table.ColumnHeader` et `Table.Cell` pour les colonnes sticky
