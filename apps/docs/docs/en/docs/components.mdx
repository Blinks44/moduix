# Components

moduix components are styled, composable Ark UI wrappers with a shared token language. Start from
the product need below, then use the sidebar or search for the complete catalog. Every component
page shows the public part tree, examples, Ark-aligned behavior, and local CSS variables.

## Choose by interaction

| If the user needs to…                         | Start with                                                   |
| --------------------------------------------- | ------------------------------------------------------------ |
| Pick one value from a known list              | [Select](/docs/select)                                       |
| Search or enter a value while choosing        | [Combobox](/docs/combobox)                                   |
| Complete a focused task that blocks the page  | [Dialog](/docs/dialog)                                       |
| Complete a task from an edge or on mobile     | [Drawer](/docs/drawer)                                       |
| Choose an action from a compact list          | [Menu](/docs/menu)                                           |
| Open a small non-modal panel near its trigger | [Popover](/docs/popover)                                     |
| Present read-only rows and columns             | [Table](/docs/table)                                         |
| Sort, filter, select, or paginate records      | [Data Table recipe](/docs/data-table)                        |

When two components seem close, choose by user behavior rather than appearance. The component page
then explains its keyboard model, recommended composition, and cases where another component fits
better.

## Before you compose

- Use [Quick start](/docs/quick-start) to choose package-managed or copy-owned installation.
- Read [Composition Patterns](/docs/composition-patterns) before hiding component parts in product
  wrappers.
- Use [Themes](/docs/themes) and [Tokens](/docs/tokens) for system-wide visual changes; keep
  component aliases for deliberate exceptions.
- Start from [Recipes](/docs/recipes) when you need a copy-paste product pattern rather than one
  primitive.
