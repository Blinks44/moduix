## Anatomy

```text
TreeView / TreeView.Root
├─ TreeView.Label
└─ TreeView.Tree
   └─ TreeView.Node or TreeView.NodeProvider
      ├─ TreeView.Branch
      │  ├─ TreeView.BranchControl
      │  │  ├─ TreeView.BranchIndicator
      │  │  └─ TreeView.BranchText
      │  └─ TreeView.BranchContent
      │     ├─ TreeView.BranchIndentGuide
      │     └─ nested nodes
      └─ TreeView.Item
         └─ TreeView.ItemText
```

| Part                             | Role                                                                  |
| -------------------------------- | --------------------------------------------------------------------- |
| `TreeView` / `TreeView.Root`     | Owns collection, selection, expansion, focus, checking, and rename. |
| `TreeView.RootProvider`          | Connects parts to a `useTreeView` instance.                          |
| `TreeView.Label`                 | Gives the tree its accessible name.                                  |
| `TreeView.Tree`                  | The ARIA tree container.                                             |
| `TreeView.Node`                  | Convenience provider with `{ node, indexPath, state }`.              |
| `TreeView.NodeProvider`          | Low-level Ark context boundary for custom composition.               |
| `TreeView.Branch*`               | Expandable node, trigger, indicator, label, and children.            |
| `TreeView.Item*`                 | Leaf tree item and optional selected-state indicator.                |
| `TreeView.NodeCheckbox*`         | Checkbox tree control and checked/indeterminate indicator.           |
| `TreeView.NodeRenameInput`       | Inline input rendered while a node is renamed.                       |

## Composition

### Recommended path

Use `TreeView.Node` for ordinary recursive renderers. Its render callback receives the current
`node`, `indexPath`, and Ark node `state`, so it can choose branch or item markup without a separate
context component. `NodeProvider` remains available when a custom component tree needs direct control.

### Dedicated expand trigger

`BranchControl` expands the whole row by default. When rendering a separate `BranchTrigger`, set
`role="none"` on `BranchControl` so the trigger is not nested in another interactive tree item.

### Links and other semantic leaves

Use `asChild` on `TreeView.Item` for a single semantic child such as a link. The replacement element
must accept Ark props and preserve keyboard and focus behaviour.

### State and keyboard behaviour

Ark owns the WAI-ARIA tree pattern: roving focus, arrow-key navigation, Home/End, typeahead,
selection, checking, disabled nodes, async loading, and rename keys. Keep `expandedValue`,
`selectedValue`, `checkedValue`, and `focusedValue` controlled through their Ark detail callbacks.

| Prop            | Default    | Notes                                                       |
| --------------- | ---------- | ----------------------------------------------------------- |
| `selectionMode` | `"single"` | Use `"multiple"` for range and modifier-key selection.      |
| `expandOnClick` | `true`     | Clicking a branch row expands or collapses it.              |
| `typeahead`     | `true`     | Uses `nodeToString` from the collection.                    |
| `lazyMount`     | `false`    | Defers branch-content rendering until it is first expanded. |
| `unmountOnExit` | `false`    | Removes closed content after the exit lifecycle.            |

### Renaming and virtualization

Enable inline rename with `canRename`, render `NodeRenameInput` while `state.renaming` is true, and
update the collection in `onRenameComplete`. For large trees, use `RootProvider`, `getVisibleNodes()`,
and `scrollToIndexFn` with a virtualizer; moduix does not add a competing virtualization API.

## Styling

Use `className` on exported parts for structural styling. Ark provides `data-state="open|closed"`,
`data-focus`, `data-selected`, `data-disabled`, `data-loading`, `data-renaming`, `data-checked`,
`data-indeterminate`, `data-depth`, `data-path`, and `data-value`. The wrapper respects Ark’s
`--depth` indentation and `--height` collapse measurement variables, and disables branch animation
for reduced-motion preferences.
