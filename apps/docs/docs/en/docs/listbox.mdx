Pass a `collection`, render `Content`, and pass each item through `Listbox.Item item={item}`.

## Anatomy

```text
Listbox / Listbox.Root
├─ Listbox.Label
├─ Listbox.Filter
│  ├─ Listbox.Input
│  └─ Listbox.ClearTrigger
├─ Listbox.Content
│  ├─ Listbox.Empty
│  ├─ Listbox.ItemGroup
│  │  ├─ Listbox.ItemGroupLabel
│  │  └─ Listbox.Item[item]
│  │     ├─ Listbox.ItemText
│  │     └─ Listbox.ItemIndicator
│  └─ Listbox.Item[item]
│     ├─ Listbox.ItemText
│     │  └─ Listbox.ItemTextContent (optional)
│     │     ├─ Listbox.ItemTextIcon (optional)
│     │     └─ Listbox.ItemTextLabel (optional)
│     └─ Listbox.ItemIndicator
└─ Listbox.ValueText
```

| Part                       | Role                                                          |
| -------------------------- | ------------------------------------------------------------- |
| `Listbox` / `Listbox.Root` | Owns collection, selected values, highlighted item, and mode. |
| `Listbox.RootProvider`     | Renders a listbox tree from state returned by `useListbox`.   |
| `Listbox.Label`            | Accessible label for the listbox content.                     |
| `Listbox.Filter`           | Default search field with an icon; place it before `Content`. |
| `Listbox.Input`            | Filter input, normally composed inside `Filter`.              |
| `Listbox.ClearTrigger`     | Consumer-wired query reset button with a default close icon.  |
| `Listbox.Content`          | Focusable listbox surface with keyboard navigation.           |
| `Listbox.Empty`            | Empty-state content for filtered collections.                 |
| `Listbox.ItemGroup`        | Group wrapper for related collection items.                   |
| `Listbox.ItemGroupLabel`   | Label for a collection group.                                 |
| `Listbox.Item`             | Selectable row. Pass the collection item through `item`.      |
| `Listbox.ItemText`         | Text used for display and accessibility.                      |
| `Listbox.ItemTextContent`  | Optional helper for icon and text layouts inside `ItemText`.  |
| `Listbox.ItemTextIcon`     | Optional icon wrapper inside `ItemTextContent`.               |
| `Listbox.ItemTextLabel`    | Truncation-safe label inside `ItemTextContent`.               |
| `Listbox.ItemIndicator`    | Selected-state indicator with the moduix default check icon.  |
| `Listbox.ValueText`        | Selected value summary.                                       |

## Composition

### Recommended composition

Render the Ark part tree directly: `Listbox` owns the collection, `Listbox.Content` owns focus and
keyboard navigation, and each `Listbox.Item` receives the original collection item through `item`.
Use `Listbox.ItemIndicator` when rows should reserve selected-state space.

For filtering, place `Listbox.Input` inside `Listbox.Filter` immediately before `Listbox.Content`.
`Filter` provides the default search icon and joins the input with results into one bordered surface.

### When to go custom

Use `asChild` only when a custom element can keep the required listbox semantics and receive Ark's
props. Use `ids` when listbox parts need stable IDs for composition with surrounding UI. Use moduix
`useListbox` with `Listbox.RootProvider` when state must be controlled outside the rendered tree;
do not render `Listbox.Root` for the same state instance. Render `Listbox.Input` directly when a
filter field should remain visually separate from the list or sit in custom surrounding UI.

### Default props

| Prop                      | Default    | Notes                                                                 |
| ------------------------- | ---------- | --------------------------------------------------------------------- |
| `collection`              | -          | Required Ark collection. Use `createListCollection` or grid variants. |
| `defaultValue`            | `[]`       | Initial selected values for uncontrolled state.                       |
| `defaultHighlightedValue` | -          | Initial highlighted item for uncontrolled highlight state.            |
| `deselectable`            | -          | Allows Escape to clear a non-empty selection.                          |
| `disabled`                | `false`    | Disables the whole listbox.                                           |
| `disallowSelectAll`       | `false`    | Disables `Cmd/Ctrl + A` selection.                                    |
| `loopFocus`               | `false`    | Keeps arrow navigation from wrapping by default.                      |
| `orientation`             | `vertical` | Controls layout and arrow-key direction.                              |
| `selectionMode`           | `single`   | Supports `single`, `multiple`, and `extended`.                        |
| `selectOnHighlight`       | `false`    | Selects items as keyboard highlight changes.                          |
| `typeahead`               | `true`     | Enables typeahead unless a filtering input owns text entry.           |

### Behavioral notes

`value`, `defaultValue`, and `onValueChange(details)` use string arrays. Read `details.value` for
selected keys and `details.items` for selected collection items.

`highlightedValue`, `defaultHighlightedValue`, and `onHighlightChange(details)` control active
descendant movement. `onSelect(details)` fires for item selection with the selected value.

`useListbox`, `useListboxContext`, `useListboxItemContext`, `Listbox.Context`, and
`Listbox.ItemContext` are available from `@moduix/react` for advanced state and item composition.
Refs forward to the corresponding Ark part; root and root provider refs target their rendered `div`
elements. Use `ids` when listbox parts need stable IDs for composition with surrounding UI.

Listbox does not render a native form control for its selected values. Keep submission and reset state
in your form model when the selection must be submitted.

`Listbox.Input` is only needed for filtering. Put it in `Listbox.Filter` for the default search
appearance, or render it directly for a separate input. Set `typeahead={false}` so typeahead and
filtering do not compete. Filtering state remains explicit: render `Listbox.ClearTrigger` for a
non-empty query and clear the query plus the collection filter in its `onClick` handler.

Ark owns the ARIA listbox pattern, active-descendant focus management, keyboard navigation,
typeahead, Home/End behavior, disabled item handling, and orientation-specific arrow keys. Keep
`Listbox.Label` in the tree when the listbox needs a visible label.

- Ark anatomy hooks: `data-scope="listbox"` and `data-part` on root, label, input, content,
  item group, item group label, item, item text, item indicator, value text, and empty.
- State hooks: `data-orientation`, `data-disabled`, `data-empty`, `data-layout`,
  `data-activedescendant`, `data-value`, `data-selected`, `data-state`, and `data-highlighted`.
- Moduix hooks: `data-slot="listbox-root"`, `listbox-label`, `listbox-filter`,
  `listbox-filter-icon`, `listbox-input`, `listbox-clear-trigger`, `listbox-content`,
  `listbox-empty`, `listbox-item-group`, `listbox-item-group-label`, `listbox-item`,
  `listbox-item-text`, `listbox-item-text-content`, `listbox-item-text-icon`,
  `listbox-item-text-label`, `listbox-item-indicator`, and `listbox-value-text`.
