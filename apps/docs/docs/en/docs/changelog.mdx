- Fixed Next.js App Router compatibility for copy-owned components that use local client APIs.

- Added the Drawer `island` content variant for detached, edge-inset drawers.

## v2.2.0 — July 22, 2026

- Namespaced public CSS tokens under `--moduix-*`.
- Namespaced cascade layers under `moduix.*`.

If application CSS overrides an older unprefixed moduix token, rename that override to its
`--moduix-*` equivalent. Ark UI runtime variables such as `--height` and `--transform-origin`
remain unprefixed because Ark writes them directly to component parts.

## v2.1.0 — July 21, 2026

- Refined focus treatments, popup density, Select composition, and theming tokens.
- Added the Typeset component and the Calm, Dense, Soft, and Contrast theme presets.

## v2.0.0 — July 19, 2026

moduix v2 moves the React component foundation from Base UI to Ark UI. This is an intentional major
release: component composition, state access, and lower-level props now follow Ark UI's accessible
primitive model.

### What changed

- Components with a dedicated primitive now use Ark UI for behavior and accessibility.
- The public API follows Ark's part composition: roots, structural parts, `RootProvider`, contexts,
  and callbacks keep the corresponding Ark contracts where they are exposed.
- Native CSS and the package-or-copy installation paths remain. The hosted registry continues to
  install self-contained component source.
- Default component icons are internal implementation details. Import application icons directly
  from your preferred library, such as `lucide-react`.

### Themes

v2 adds curated CSS token presets: `Calm`, `Dense`, `Soft`, and `Contrast`. They change semantic
colors, spacing, control sizes, radius, shadows, and Sidebar tokens without a provider or theme
runtime. `Calm` is the default foundation; import one of the other presets after `style.css` and set
the theme on `<html>`:

```tsx
import '@moduix/react/style.css';
import '@moduix/react/presets/soft.css';
```

```html
<html data-moduix-theme="soft" data-moduix-color-scheme="dark"></html>
```

The `data-moduix-color-scheme` attribute selects the dark values for the active preset. Themes remain ordinary CSS, so you
can create a project-owned theme by defining the same semantic tokens after the foundation import.
See [Themes](/docs/themes) for the complete custom-theme guide, all presets, and the hosted registry
path.

### Migrating to v2

1. Install the v2 package with its Ark UI peer dependency:

   ```bash
   npm install @moduix/react@2 @ark-ui/react
   ```

2. Review the v2 page for every used component. Recompose its explicit parts where the previous
   Base UI API was flatter or used different names.
3. Replace imports of moduix icons with an application-owned icon library:

   ```tsx
   import { Check as CheckIcon } from 'lucide-react';
   import { Toggle } from '@moduix/react/toggle';
   ```

4. For copy-owned components, inspect changes before updating and merge the result into your source:

   ```bash
   npx shadcn@latest add @moduix-react/button --diff
   ```

For the permanent package and copy-owned update flow, see [Updating and migration](/docs/updating).

### Breaking changes

- Base UI-specific component APIs are removed.
- `@moduix/react` no longer exports its internal default icons.
- Copy-owned components must be reviewed and updated explicitly; they are source in your project,
  not automatically updated package code.

## Version and support policy

moduix follows Semantic Versioning. Major releases may include breaking changes; minor releases add
backward-compatible features; patch releases contain backward-compatible fixes.

The latest major is actively supported. v2 supports React 18 and 19, and moduix keeps its Ark UI
integration aligned with current releases. For each major release, this page records affected APIs,
migration steps, and package or registry implications.
