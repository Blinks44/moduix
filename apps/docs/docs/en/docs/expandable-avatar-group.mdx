label. Hovering or focusing one avatar makes room after it and opens the matching tooltip.

## How it works

The group uses `Avatar.Image` with `Avatar.Fallback` as a loading fallback, and
`Tooltip.Trigger asChild` so each avatar remains a semantic button. The motion is CSS-only: the
active button lifts slightly while its following siblings make room for it.

Keep the tooltip content short and non-essential. If selecting a member should navigate or perform
an action, replace the button with the appropriate semantic control and preserve its accessible
name.
