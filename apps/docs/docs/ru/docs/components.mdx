# Компоненты

Компоненты moduix — это стилизованные, компонуемые обёртки Ark UI с общим языком токенов. Начните с продуктовой
задачи ниже, затем используйте сайдбар или поиск для полного каталога. На странице каждого компонента показаны
публичное дерево частей, примеры, соответствующее Ark поведение и локальные CSS-переменные.

## Выберите по взаимодействию

| Если пользователю нужно… | Начните с |
| --- | --- |
| Выбрать одно значение из известного списка | [Select](../../docs/select) |
| Найти или ввести значение при выборе | [Combobox](../../docs/combobox) |
| Выполнить сфокусированную задачу, блокирующую страницу | [Dialog](../../docs/dialog) |
| Выполнить задачу с края экрана или на мобильном устройстве | [Drawer](../../docs/drawer) |
| Выбрать действие из компактного списка | [Menu](../../docs/menu) |
| Открыть небольшую немодальную панель рядом с триггером | [Popover](../../docs/popover) |
| Показать строки и столбцы только для чтения | [Table](../../docs/table) |
| Сортировать, фильтровать, выбирать записи или разбивать их на страницы | [Рецепт Data Table](../../docs/data-table) |

Когда два компонента кажутся похожими, выбирайте по поведению пользователя, а не по внешнему виду. Затем на странице
компонента будут описаны его модель клавиатурного взаимодействия, рекомендуемая композиция и случаи, когда лучше
подходит другой компонент.

## Перед композицией

- В [Быстром старте](../../docs/quick-start) выберите установку через пакет или с исходным кодом в проекте.
- Прочитайте [Паттерны композиции](../../docs/composition-patterns), прежде чем скрывать части компонентов в продуктовых
  обёртках.
- Используйте [Темы](/ru/docs/themes) и [Токены](/ru/docs/tokens) для системных визуальных изменений; алиасы
  компонентов оставьте для осознанных исключений.
- Начните с [Рецептов](../../docs/recipes), если нужен готовый к копированию продуктовый паттерн, а не один примитив.
