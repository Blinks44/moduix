## Справочник API

В Ark UI нет отдельного примитива `simple-grid`. Moduix создаёт этот компонент с помощью официальной
[фабрики Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[ref](https://ark-ui.com/docs/guides/ref). На модель раскладки с `columns` и `minChildWidth` влияет
[SimpleGrid](https://chakra-ui.com/docs/components/simple-grid) из Chakra UI.

## Базовый пример

Используйте `minChildWidth`, когда элементы равной ширины должны автоматически распределяться по колонкам

контейнеров. Для неразрывного содержимого дочернего элемента добавьте `min-width: 0` или подходящее

## Анатомия

`SimpleGrid` рендерит один корневой элемент сетки в стиле Ark и не оборачивает дочерние элементы.

```text
SimpleGrid
└─ root[data-scope="simple-grid"][data-part="root"][data-slot="simple-grid-root"]
   └─ children
```

| Часть        | Назначение                                           |
| ------------ | ---------------------------------------------------- |
| `SimpleGrid` | Корневой контейнер, создающий равные колонки CSS Grid. |

## Композиция

### Рекомендуемая композиция

Используйте `SimpleGrid` как корневой компонент. `SimpleGrid.Root` остаётся псевдонимом для совместимости.

Выберите один режим раскладки:

- `minChildWidth` позволяет браузеру разместить столько равных колонок, сколько допускает доступная ширина.
- `columns` создаёт точное число равных колонок.

Всегда задавайте осознанный `gap`, `rowGap` или `columnGap`, когда элементам сетки требуется визуальное
разделение. Используйте `asChild`, если корнем должен быть семантический элемент, например `ul`, `section`
или `nav`.

### Когда нужна собственная композиция

Используйте локальный CSS, если раскладке нужны именованные области, неравные дорожки, растягивание
элементов или точное число колонок на нескольких контрольных точках media- или container-запросов.
Не передавайте `columns` и `minChildWidth`, если `grid-template-columns` задаётся таблицей стилей.

### Свойства по умолчанию

| Свойство       | По умолчанию     | Примечания                                                    |
| -------------- | ---------------- | ------------------------------------------------------------- |
| `columns`      | `1`              | Конечное положительное целое число равных колонок             |
| `minChildWidth`| -                | Минимальная ширина дорожки; числа преобразуются в пиксели     |
| `gap`          | браузер по умолчанию | CSS-длина (`number` = `px`)                                |
| `rowGap`       | браузер по умолчанию | CSS-длина (`number` = `px`)                                |
| `columnGap`    | браузер по умолчанию | CSS-длина (`number` = `px`)                                |
| `asChild`      | `false`          | Композиция фабрики Ark с одним семантическим дочерним элементом |

### Особенности поведения

- Если переданы оба свойства раскладки, `minChildWidth` имеет приоритет над `columns`.
- `columns={3}` создаёт три равные дорожки без обёрток вокруг дочерних элементов.
- `minChildWidth={160}` создаёт столько дорожек, сколько помещается, и трактует число как `160px`.
- Режим auto-fit предотвращает переполнение, когда сетка становится уже `minChildWidth`.
- `gap`, `rowGap` и `columnGap` записываются в inline-стили только при передаче.
- `style` применяется последним и может переопределить сгенерированные `gridTemplateColumns` или отступы.
- `ref` указывает на отрендеренный корень. При `asChild` он указывает на единственный дочерний элемент.
- Компонент не добавляет роли, подписи, поведение клавиатуры, управление фокусом, состояние или контекст
  провайдера.

## Стилизация

У `SimpleGrid` нет CSS-переменных, характерных только для компонента, поэтому отдельный справочник
CSS-свойств не нужен. Свойства раскладки записываются в inline-стили корневого элемента.

### Хуки стилизации

- `className` стилизует единственный корень: ширину, расположение, фон и адаптивную раскладку, если
  `columns` и `minChildWidth` не переданы.
- `data-scope="simple-grid"` и `data-part="root"` согласуют обёртку с соглашениями Ark о стилизации.
- `data-slot="simple-grid-root"` — стабильный селектор moduix для обращения к корню в локальном CSS.
- `columns`, `minChildWidth`, `gap`, `rowGap` и `columnGap` записывают inline-стили и поэтому имеют
  приоритет над объявлениями из `className`.
- `style` объединяется после этих свойств и является последним переопределением для экземпляра.
- Компонент не предоставляет хуков стилизации для состояния или анимации.
