# Мобильная навигация с выдвижной панелью

Добавьте компактный паттерн мобильной навигации с панелью, прикреплённой к краю экрана. Ссылки навигации закрывают
панель после выбора, а примитив Drawer обеспечивает доступное управление фокусом, обработку Escape и
поведение подложки.

## Использование в маршруте

Замените примеры ссылок и содержимое панели управления своими маршрутами и данными. Размещайте каждую навигационную
ссылку внутри `Drawer.CloseTrigger`, чтобы выбор автоматически закрывал мобильную панель.

Используйте Link вашего роутера через `asChild`, когда именно он должен управлять навигацией, и отмечайте текущую ссылку
через `aria-current="page"`. Оставляйте триггер видимым на мобильной ширине и предоставляйте те же пункты назначения
в постоянном заголовке десктопной версии или в [рабочей панели с боковой навигацией](/docs/sidebar-dashboard) на более широких экранах.
Не рендерите две фокусируемые копии одной и той же навигации на одной контрольной точке.
