## Справочник по API

Ark UI не поставляется с выделенным примитивом `table`. Moduix собирает этот компонент на официальной [фабрике Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory), следует руководствам Ark по [композиции](https://ark-ui.com/docs/guides/composition), [стилю](https://ark-ui.com/docs/guides/styling) и [ref](https://ark-ui.com/docs/guides/ref).

## Анатомия

Обычный потребительский путь остается близким к собственной разметке таблицы:

```text
Table.ScrollArea (optional)
└─ Table
   ├─ Table.ColumnGroup (optional)
   │  └─ Table.Column
   ├─ Table.Caption (optional)
   ├─ Table.Header
   │  └─ Table.Row
   │     └─ Table.ColumnHeader
   ├─ Table.Body
   │  ├─ Table.Row
   │  │  └─ Table.Cell
   │  └─ Table.Empty (optional)
   └─ Table.Footer (optional)
```

|Часть|Роль|
| ---------------------- | -------------------------------------------------------------------------- |
|`Table`|Родной корень `table`. Владеет типографикой, разделителями и атрибутами состояния.|
|`Table.ScrollArea`|Дополнительная оболочка переполнения с рамкой для обычного случая «стол на поверхности».|
|`Table.ColumnGroup`|Собственная оболочка `colgroup` для распределения ширины столбцов.|
|`Table.Column`|Родная оболочка `col`. Поддерживает `htmlWidth`.|
|`Table.Caption`|Дополнительная метка над или под таблицей через `side`.|
|`Table.Header`|Собственная оболочка `thead` для заголовков столбцов.|
|`Table.Body`|Собственная оболочка `tbody` для строк тела.|
|`Table.Footer`|Собственная оболочка `tfoot` для итоговых строк.|
|`Table.Row`|Собственная оболочка `tr` с разделителем.|
|`Table.ColumnHeader`|Родная оболочка `th`. Поддерживает `numeric`.|
|`Table.Cell`|Родная оболочка `td`. Поддерживает `numeric`.|
|`Table.Empty`|Удобная пустая строка внутри `Table.Body`.|

## Состав

### Рекомендуемый состав

Оставайтесь с `Table.ScrollArea` плюс частями семантической таблицы для большинства представлений данных, доступных только для чтения.

Используйте `Table.ScrollArea`, если вам нужна общая оболочка с горизонтальной прокруткой с границами. Используйте `numeric` в `Table.ColumnHeader` и `Table.Cell` для столбцов сумм, счетчиков, процентов и задержки. Используйте `Table.Caption`, когда таблице нужна короткая метка или сводка, и `Table.Footer`, когда последняя строка представляет итоги или свертки. Используйте `striped`, `interactive`, `showColumnBorder`, `stickyHeader` и `size`/`variant`, когда таблице требуются визуальные режимы в стиле Chakra без добавления состояния сетки данных.

### Когда переходить к индивидуальному подходу

Пропустите `Table.ScrollArea`, если в окружающем макете уже есть прокрутка, отступы, границы или стили поверхности. В этом случае сохраните сам `Table` и переместите проблемы-оболочки в свой собственный компонент макета или разметку оболочки.

`Table` намеренно не владеет состоянием сортировки, фильтрации, выбора, разбиения на страницы или действия строки. Рассматривайте его как визуальный и семантический примитив, на котором могут строиться табличные абстракции более высокого уровня. Для состояния и рендеринга TanStack Table следуйте руководству по композиции [Data Table](/docs/data-table).

### Реквизит по умолчанию

Все части принимают `className` и соответствующие им собственные реквизиты элемента.

|Компонент|Опора|По умолчанию|Примечания|
| -------------------- | ------------------ | ---------- | ------------------------------------------------------- |
|`Table`|`interactive`|`false`|Включает подсветку строк тела при наведении.|
|`Table`|`showColumnBorder`|`false`|Добавляет границы между видимыми столбцами.|
|`Table`|`size`|`'md'`|Поддерживает `'sm'`, `'md'` и `'lg'`.|
|`Table`|`stickyHeader`|`false`|Делает `Table.Header` липким внутри контейнера прокрутки.|
|`Table`|`striped`|`false`|Зебровые полосы выравнивают ряды тела, исключая пустые ряды.|
|`Table`|`variant`|`'line'`|Поддерживает `'line'` и `'outline'`.|
|`Table.Caption`|`side`|`'bottom'`|Поддерживает `'top'` и `'bottom'`.|
|`Table.Column`|`htmlWidth`|—|Сопоставляется с собственным атрибутом `width` на `col`.|
|`Table.ColumnHeader`|`numeric`|`false`|Выравнивает содержимое по концу строки и использует табличные числа.|
|`Table.Cell`|`numeric`|`false`|Выравнивает содержимое по концу строки и использует табличные числа.|
|`Table.Empty`|`colSpan`|необходимый|Должно соответствовать текущему количеству столбцов тела.|

### Поведенческие замечания

- `Table.Empty` отображает полную строку таблицы для пустого состояния, поэтому передайте количество столбцов тела через `colSpan`. Его строка предоставляет `data-empty` и не получает полосатых стилей или стилей интерактивного наведения. — Строки заголовка и тела отображают общий нижний разделитель. Последняя строка тела удаляет границу. — Строки тела получают тонкий фон при наведении, только если установлен `interactive`. - `Table.Caption` наследует приглушенную типографику и добавляет встроенные отступы, чтобы они не прилегали к краям таблицы.

### Крючки для стиля

Используйте ту часть, которая отвечает за визуальное представление:

- `className` на `Table.ScrollArea` для переопределения границы, радиуса и поверхности всей оболочки - `className` на `Table` для типографики таблицы и ограничений ширины - `data-slot="table-root"`, `table-scroll-area`, `table-column-group`, `table-column`, `table-caption`, `table-header`, `table-body`, `table-footer`, `table-row`, `table-column-header`, `table-cell` и `table-empty` для таргетинга на уровне части - `data-side="top" | "bottom"` для `Table.Caption` для стиля размещения подписей - `data-numeric` для `Table.ColumnHeader` и `Table.Cell` для таргетинга на числовые столбцы – `data-empty` для строки, сгенерированной `Table.Empty` для таргетинга на пустую строку – `data-size`, `data-variant`, `data-striped`, `data-interactive`, `data-sticky-header` и `data-show-column-border` на `Table` для стилизации состояния корневого уровня — `data-sticky="start" | "end"` на `Table.ColumnHeader` и `Table.Cell` для закрепленных столбцов.
