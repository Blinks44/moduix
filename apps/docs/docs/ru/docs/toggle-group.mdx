## Выбор подходящего компонента

Используйте `ToggleGroup`, если несколько нажатых кнопок относятся к одному общему набору значений.

- Выберите **`ToggleGroup`** для сегментированных контролов, компактных наборов фильтров и панелей форматирования.
- Выберите **`Toggle`** для одного отдельного действия с двумя состояниями.
- Выберите **`Tabs`**, если выбор также переключает связанные панели.
- Выберите **`RadioGroup`**, если варианты должны выглядеть как опции формы.

## Анатомия

```text
ToggleGroup / ToggleGroup.Root
├─ ToggleGroup.Context (необязательно)
└─ ToggleGroup.Item[value]

ToggleGroup.RootProvider
└─ ToggleGroup.Item[value]
```

| Часть                               | Назначение                                                                    |
| ----------------------------------- | ----------------------------------------------------------------------------- |
| `ToggleGroup` / `ToggleGroup.Root`  | Корневая машина состояний для выбранных значений, roving focus, ориентации и отключения. |
| `ToggleGroup.Item`                  | Кнопка-элемент с обязательным `value` и состоянием Ark `data-state` вкл./выкл. |
| `ToggleGroup.RootProvider`          | Корневой компонент, управляемый экземпляром состояния `useToggleGroup()` вне отрисовываемого дерева. |
| `ToggleGroup.Context`               | Доступ через render prop к текущему состоянию группы.                         |

## Композиция

### Рекомендуемая композиция

Используйте `ToggleGroup` как корневой компонент, а `ToggleGroup.Item` — для каждой кнопки. `value` и
`defaultValue` являются массивами строк в режимах одиночного и множественного выбора.

moduix добавляет два визуальных свойства к `ToggleGroup`, `ToggleGroup.Root`, `ToggleGroup.RootProvider` и
`ToggleGroup.Item`:

| Свойство  | По умолчанию | Значения                                                |
| --------- | ------------ | ------------------------------------------------------- |
| `variant` | `default`    | `default`, `outline`, `ghost`                           |
| `size`    | `md`         | `xs`, `sm`, `md`, `lg`, `icon-sm`, `icon-md`, `icon-lg` |

### Когда нужна собственная композиция

Используйте `asChild` на `ToggleGroup.Item`, когда другой семантической кнопке нужно владеть отрисовываемым
элементом. Сохраняйте дочерний элемент единственным и кнопкоподобным, чтобы Ark мог объединить с ним свойства
взаимодействия и состояние ARIA.

Используйте `ToggleGroup.RootProvider` с moduix `useToggleGroup()`, когда состояние нужно создать вне
отрисовываемого корневого компонента. Используйте moduix `useToggleGroupContext()` ниже root/provider, когда
пользовательскому компоненту необходимо текущее состояние группы. Не отрисовывайте `ToggleGroup.Root` и
`ToggleGroup.RootProvider` для одного экземпляра состояния. Прямые импорты Ark остаются способом выхода для
поверхностей, намеренно находящихся вне API moduix.

### Свойства по умолчанию

| Свойство      | По умолчанию | Примечания                                                          |
| ------------- | ------------ | ------------------------------------------------------------------- |
| `deselectable`| `true`       | Разрешает пустой выбор, если `multiple` не включён.                 |
| `loopFocus`   | `true`       | Переносит фокус стрелкой с последнего элемента на первый и обратно. |
| `orientation` | `horizontal` | Управляет направлением раскладки и соответствующей клавиатурной навигацией. |
| `rovingFocus` | `true`       | Использует roving tab index, поэтому в порядке Tab участвует один элемент. |
| `multiple`    | `false`      | Разрешает нескольким элементам оставаться нажатыми одновременно.    |
| `variant`     | `default`    | Визуальный вариант moduix.                                          |
| `size`        | `md`         | Размер элемента moduix.                                             |

### Особенности поведения

- `onValueChange` получает сведения Ark: для выбранного массива строк используйте `details.value`.
- `deselectable` игнорируется, когда включён `multiple`.
- Группе нужно доступное имя из `aria-label` или `aria-labelledby`.
- Элементам только с иконками нужно собственное доступное имя, например `aria-label="Align left"`.
- Используйте `disabled` на группе для всего набора или на одном элементе для отдельного недоступного выбора.
- Используйте `ids`, чтобы задать стабильные ID корневого элемента и элементов при композиции группы с другим
  доступным UI.
- Группы с одиночным выбором используют семантику `radiogroup`/`radio`; группы с множественным выбором используют
  `group` и `aria-pressed`.
- Горизонтальные группы используют стрелки влево/вправо, вертикальные — вверх/вниз, а Home/End перемещают к
  первому/последнему доступному элементу. Space/Enter активируют кнопку в фокусе, а `loopFocus` управляет
  зацикливанием навигации стрелками.
- Ark записывает `data-scope="toggle-group"`, `data-part`, `data-orientation`, `data-disabled`,
  `data-focus` и `data-state="on" | "off"` на элементах для стилизации.
- Горизонтальные группы прокручиваются, когда они шире контейнера, вместо переноса, который изменил бы раскладку
  клавиатурной навигации.

## Стилизация

`ToggleGroup` предоставляет стабильные хуки `data-slot` для moduix и атрибуты анатомии и состояния Ark для
поведенческой стилизации.

### Хуки стилизации

- `data-slot="toggle-group-root"` и `data-slot="toggle-group-root-provider"` — стабильные селекторы корневого элемента.
- `data-slot="toggle-group-item"` — стабильный селектор элемента.
- `data-scope="toggle-group"` и `data-part="root" | "item"` предоставляются Ark.
- `data-state="on" | "off"` записывается на каждом элементе.
- `data-orientation="horizontal" | "vertical"` записывается на корневом и дочерних элементах.
- `data-disabled` и `data-focus` — атрибуты состояния Ark.
- `data-variant` и `data-size` отражают визуальные свойства moduix.
