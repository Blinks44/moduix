# Таблица данных

`Data Table` — это паттерн композиции, а не компонент, экспортируемый moduix. Используйте семантические
и стилизованные части `Table` для разметки, а TanStack Table — для моделирования состояния таблицы данных. Функциональность продукта
владеет своими записями и управляет состоянием таблицы, когда оно определяет маршрут или серверный запрос.
У каждого продукта разные столбцы, фильтры, действия со строками и серверные контракты, поэтому держите это
поведение рядом с функциональностью, которой оно нужно.

Готовый к копированию рецепт ниже — это та же интерактивная таблица, которая показана на главной странице. В ней есть
поиск, сортировка, видимость столбцов, выбор строк, действия и пагинация; замените её примеры
записей и действий данными своего продукта.

## Выберите самую простую подходящую таблицу

| Потребность | С чего начать |
| ----------- | ------------ |
| Строки и столбцы только для чтения | Семантический компонент [Table](/docs/table) |
| Локальная сортировка или фильтрация небольшого набора данных | Table и соответствующая модель строк TanStack |
| Серверная сортировка, фильтрация или пагинация | Управляемое состояние запроса с параметрами TanStack для ручного управления ниже |
| Виртуализированные строки | Добавляйте виртуализацию только после измерения реальной проблемы с производительностью |

Не копируйте по умолчанию каждый элемент управления из полного рецепта. Уберите выбор, видимость столбцов,
действия или пагинацию, если пользователь не может использовать эту возможность.

## Соберите паттерн самостоятельно

Установите TanStack Table в приложение, которому принадлежит поведение таблицы данных:

```bash
npm install @tanstack/react-table
```

`Table` уже поставляется из `@moduix/react/table`. Он намеренно не включает TanStack Table, поэтому
приложениям, которым нужна только семантическая таблица, не приходится платить за логику таблицы данных.

## Базовый пример

Определите типизированные записи `ColumnDef`, создайте экземпляр таблицы с `getCoreRowModel()` и сопоставьте его
группы заголовков и видимые ячейки с анатомией таблицы moduix. Используйте `flexRender` для заголовков и
ячеек: определения столбцов могут содержать простые значения или функции рендеринга React.

## Сохраняйте данные и столбцы стабильными

В примерах `payments` и `columns` определены вне компонентов, поэтому TanStack Table получает
одни и те же ссылки между рендерами. Когда данные или столбцы зависят от props или состояния, используйте `useMemo`
для итогового массива вместо создания его внутри компонента или передачи `data.filter(...)` напрямую
в `useReactTable`. Новые ссылки заставляют TanStack Table пересчитываться и могут привести к циклам
рендеринга React. Полное объяснение смотрите в [FAQ](https://tanstack.com/table/latest/docs/faq) TanStack.

## Стабильная ширина столбцов

Используйте нативные `Table.ColumnGroup` и `Table.Column htmlWidth` для столбцов, ширина которых должна оставаться
стабильной. Сочетайте их с `table-layout: fixed` на корневом элементе таблицы: оставшийся столбец занимает
доступное пространство, а изменяющийся значок сортировки не может изменить ширину своего столбца.

## Сортировка, фильтрация, пагинация и выбор

фильтруется столбец электронной почты, строки выбираются по стабильным идентификаторам платежей и

## Серверные данные

Когда API фильтрует, сортирует или разбивает записи на страницы, храните эти значения в состоянии запроса функциональности.
Передавайте возвращённую страницу в TanStack Table и отключайте соответствующие преобразования на стороне клиента.
Эта конфигурация заменяет модели строк на стороне клиента из интерактивного примера:

```tsx
const table = useReactTable({
  data: response.rows,
  columns,
  getCoreRowModel: getCoreRowModel(),
  manualFiltering: true,
  manualPagination: true,
  manualSorting: true,
  rowCount: response.rowCount,
  onColumnFiltersChange: setColumnFilters,
  onPaginationChange: setPagination,
  onSortingChange: setSorting,
  state: { columnFilters, pagination, sorting },
});
```

Не добавляйте `getFilteredRowModel`, `getSortedRowModel` или `getPaginationRowModel` для соответствующего поведения,
которым управляет сервер: TanStack предполагает, что `response.rows` уже отражает запрос. Передавайте
`pageCount` вместо `rowCount`, если именно его предоставляет API. `manualPagination` также отключает
обычный сброс страницы, поэтому сбрасывайте `pagination.pageIndex` на `0` при каждом изменении удалённого фильтра или сортировки;
иначе API может вернуть пустую страницу. Руководства TanStack по
[фильтрации](https://tanstack.com/table/latest/docs/guide/global-filtering),
[сортировке](https://tanstack.com/table/latest/docs/guide/sorting) и
[пагинации](https://tanstack.com/table/latest/docs/guide/pagination) описывают слой запросов.

Отображайте состояние запроса рядом с таблицей, а не внутри несвязанных ячеек:

| Состояние запроса | Рекомендуемый результат |
| ----------------- | ----------------------- |
| Первичная загрузка | Оставьте заголовки столбцов видимыми и покажите подписанную строку загрузки или skeleton. |
| Повторный запрос | Сохраните текущие строки, отметьте панель инструментов как занятую и предотвратите повторные запросы. |
| Пустой результат | Объясните, нет ли записей или фильтры исключили все совпадения. |
| Ошибка | Сохраните элементы управления запросом доступными и предложите повторить тот же запрос. |

## Добавляйте возможности осознанно

TanStack Table не содержит UI. Выбирайте состояние и модели строк для поведения, которое относится к этому
конкретному представлению данных, вместо того чтобы включать все возможности таблицы по умолчанию.

| Потребность | Что добавить в эту таблицу |
| ----------- | -------------------------- |
| Действия со строками | Рендерите `Menu` в столбце действий; обработчики действий остаются в функциональности продукта. |
| Выбор строк | Управляйте `rowSelection`, настройте `getRowId` с долговечным идентификатором записи и рендерите элементы moduix `Checkbox` в столбце выбора. |
| Видимость столбцов | Управляйте `columnVisibility` и предоставляйте `column.toggleVisibility()` через `Menu`. |
| Серверные данные | Храните состояние запроса в маршруте или слое данных. Используйте `manualFiltering`, `manualSorting` и `manualPagination` только для преобразований, которыми владеет API, затем передавайте строки ответа с `rowCount` или `pageCount`. |
| Большие наборы данных | Добавляйте виртуализацию к телу таблицы только после измерений; сохраняйте семантику нативных `table`, `thead`, `tbody`, `tr`, `th` и `td`. |

В [руководстве по моделям строк](https://tanstack.com/table/latest/docs/guide/row-models) TanStack Table перечислены
доступные преобразования на стороне клиента. В [руководстве по выбору строк](https://tanstack.com/table/latest/docs/guide/row-selection)
объясняются управляемое состояние выбора и выбор на уровне страницы, а в [React adapter](https://tanstack.com/table/latest/docs/framework/react/react-table)
документирован `useReactTable`. На странице moduix [Table](/docs/table) описаны отрендеренная структура
и хуки стилизации.

С `manualPagination` сохраняйте полное состояние `rowSelection` для действий, охватывающих страницы. Модели выбранных строк TanStack
могут возвращать только записи, которые сейчас переданы таблице, даже когда состояние выбора также содержит ID с других страниц.

## Повторное использование после стабилизации паттерна

Если одна и та же таблица продукта появляется более чем в одном месте, вынесите её столбцы, панель инструментов или
элементы управления пагинацией в локальные компоненты функциональности. Делайте итоговый API специфичным для продукта:
`PaymentsTable` проще поддерживать, чем широкий wrapper `DataTable`, который пытается предугадать каждый
фильтр, ответ сервера, действие или правило выбора.

## Доступность

Сохраняйте нативные части таблицы в отрендеренном выводе. Используйте `Table.ColumnHeader` для заголовков,
`Table.Cell` для данных и короткую подпись, если окружающий заголовок не определяет данные.
Интерактивным элементам внутри ячеек нужны описательные доступные имена, а сортируемые заголовки должны
передавать текущее направление через `aria-sort`. Поле фильтра и элементы выбора в интерактивном примере имеют явные
доступные имена, а не полагаются на placeholder или текст значка.
