## Справочник API

В Ark UI нет отдельного примитива close-button. Moduix строит этот компонент с помощью официального
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory), следуя рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[ref](https://ark-ui.com/docs/guides/ref).

## Базовый пример

Используйте `CloseButton`, когда сам элемент управления выполняет действие закрытия. Он предоставляет
семантику кнопки и стандартный символ закрытия, но не управляет состоянием оверлея самостоятельно.

## Анатомия

`CloseButton` предоставляет одну корневую часть в стиле Ark.

```text
CloseButton / CloseButton.Root
└─ root[data-scope="close-button"][data-part="root"][data-slot="close-button-root"]
   └─ CloseIcon (стандартная) | пользовательские дочерние элементы
```

| Часть                              | Назначение                                                              |
| ---------------------------------- | ------------------------------------------------------------------------ |
| `CloseButton` / `CloseButton.Root` | Интерактивный элемент закрытия на основе семантики и доступности кнопки. |

## Композиция

### Рекомендуемая композиция

Используйте `CloseButton` напрямую, когда нативная кнопка должна выполнять действие закрытия. Обёртка
перенаправляет пропы кнопки Ark factory, нативные атрибуты, обработчики событий и ref.

### Когда нужна собственная композиция

Используйте `asChild`, когда узлом DOM должен владеть другой компонент кнопки. Композиция Ark требует один
дочерний элемент, и он должен включать собственное содержимое иконки.

Если компонент оверлея уже предоставляет триггер закрытия, предпочитайте его, чтобы он мог управлять
состоянием закрытия и жизненным циклом фокуса.

### Свойства по умолчанию

| Проп         | По умолчанию                                   | Значения / примечания                      |
| ------------ | ----------------------------------------------- | ------------------------------------------ |
| `type`       | `button`                                        | Применяется только к нативному корневому компоненту |
| `aria-label` | `Close`, когда отсутствует `aria-labelledby`    | В реальном интерфейсе предпочитайте метку, относящуюся к поверхности |
| `children`   | `CloseIcon`                                     | Заменяется пользовательским содержимым иконки |
| `asChild`    | `false`                                         | Композиция Ark factory с одним дочерним элементом |

### Особенности поведения

- `CloseButton` ничего не закрывает самостоятельно; подключите `onClick` или используйте триггер закрытия
  оверлея.
- Резервная метка — `Close`; передайте `aria-label` или `aria-labelledby` для метки, относящейся к поверхности
  интерфейса.
- Нативные `disabled` и `aria-disabled="true"` предоставляют `data-disabled` для стилизации состояния
  в стиле Ark и подавляют активацию по клику.
- При `asChild` свойство `disabled` не добавляет нативный атрибут `disabled` к пользовательскому
  элементу. Вместо этого добавляются `aria-disabled="true"` и `data-disabled`, а активация по
  клику блокируется.
- Предыдущие пропы `render`, `nativeButton` и `focusableWhenDisabled` удалены.
- `CloseButton.Root` доступен как эквивалентная форма пространства имён, согласованная с Ark.

### Хуки стилизации

- `data-scope="close-button"` определяет семейство компонента.
- `data-part="root"` определяет единственную экспортируемую часть.
- `data-slot="close-button-root"` предоставляет хук слота moduix.
- `data-disabled` предоставляет нормализованное состояние стилизации `disabled` и `aria-disabled="true"`.
- Прямые вложенные SVG-дочерние элементы наследуют размер от `--moduix-close-button-icon-size`.
