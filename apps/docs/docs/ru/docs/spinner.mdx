## Справочник API

Ark UI не предоставляет отдельный примитив spinner. Moduix строит этот компонент с помощью официальной
[фабрики Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[ref](https://ark-ui.com/docs/guides/ref).

Используйте `Spinner` для компактных состояний ожидания внутри кнопок, строк со встроенным статусом

## Анатомия

Стандартный путь для потребителя короткий:

```text
Spinner
└─ spinner-indicator
   └─ spinner-ring (только стандартный индикатор)
```

| Часть               | Назначение                                                                                  |
| ------------------- | ------------------------------------------------------------------------------------------- |
| `Spinner`           | Корневой элемент статуса. Поддерживает `size`, `decorative`, `asChild` и нативные свойства `span`. |
| `spinner-indicator` | Внутренняя вращающаяся обёртка, отвечающая за размер и анимацию вращения.                   |
| `spinner-ring`      | Стандартный кольцевой индикатор. Рендерится только при отсутствии пользовательских `children`. |

## Композиция

### Рекомендуемая композиция

Оставьте стандартное кольцо, если достаточно компактного индикатора загрузки.

- Используйте `size` для изменения плотности.
- Используйте `decorative`, если соседний видимый текст уже сообщает о загрузке.
- Используйте `aria-label` или `aria-labelledby`, если статусу нужно более конкретное имя, чем `"Loading"`.

### Когда нужна собственная композиция

`Spinner` — компонент только с корнем. Используйте `children`, чтобы заменить стандартное кольцо, сохранив
стандартные корень, размер и вращающуюся обёртку индикатора.

Используйте `asChild`, когда сам корневой элемент должен предоставляться потребителем. В этом режиме Ark
объединяет свойства корня с единственным дочерним элементом, поэтому ребёнок владеет своим визуальным содержимым.

Дочерний элемент `asChild` не должен быть интерактивным. Это визуальный host для spinner, а не кнопка или ссылка.

### Свойства по умолчанию

| Свойство     | По умолчанию | Примечания                                                                 |
| ------------ | ------------ | -------------------------------------------------------------------------- |
| `size`       | `'md'`       | Принимает `'inherit' \| 'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`. `inherit` использует `1em`. |
| `decorative` | `false`      | Скрывает стандартный корень от ассистивных технологий; с `asChild` сохраняет семантику ребёнка. |
| `asChild`    | `false`      | Объединяет свойства корня с единственным дочерним элементом.              |
| `aria-label` | `'Loading'`  | По умолчанию применяется, когда spinner не декоративный.                  |

### Особенности поведения

- Стандартный корень рендерится как `span` с `data-scope="spinner"`, `data-part="root"`, `data-slot="spinner-root"` и `data-size`.
- `Spinner.Root` — псевдоним совместимости для `Spinner`; в новом коде используйте `Spinner`.
- Недекоративные spinner рендерятся с `role="status"`.
- `decorative={true}` скрывает стандартный корень от ассистивных технологий. С `asChild` он вместо
  этого удаляет статус и свойства подписи Spinner, сохраняя семантику ребёнка.
- `Spinner` владеет этой семантикой и своими хуками `data-scope`, `data-part`, `data-slot` и `data-size`, поэтому нативные свойства не могут их переопределить.
- Вращающаяся обёртка использует `data-scope="spinner"`, `data-part="indicator"` и `data-slot="spinner-indicator"`.
- Пользовательские `children` заменяют только стандартное кольцо. Размером и вращением по-прежнему владеет обёртка.
- При `asChild` корнем становится предоставленный потребителем ребёнок, который должен сам отрисовать необходимый визуальный индикатор.
- Spinner сохраняет анимацию загрузки при `prefers-reduced-motion`, поскольку движение служит визуальным признаком загрузки.

## Стилизация

Стилизуйте `Spinner` через `className`, селекторы Ark `data-scope` / `data-part`, стабильные хуки `data-slot`,
`data-size` и публичные переменные `--moduix-spinner-*`, описанные в CSS API.

### Хуки стилизации

- `[data-scope="spinner"][data-part="root"]` нацеливает корень в стиле Ark.
- `[data-scope="spinner"][data-part="indicator"]` нацеливает вращающуюся внутреннюю обёртку.
- `[data-scope="spinner"][data-part="ring"]` нацеливает только стандартное кольцо.
- `data-slot="spinner-root"` — стабильный селектор moduix для экспортируемого корня.
- `data-slot="spinner-indicator"` — стабильный селектор moduix для вращающейся внутренней обёртки.
- `data-slot="spinner-ring"` нацеливает только стандартное кольцо.
- `Spinner` записывает в корень `data-size="inherit" | "xs" | "sm" | "md" | "lg" | "xl"`.
- `className` применяется только к корню. При необходимости нацеливайте индикатор или кольцо дочерними селекторами от этого корня.
