# moduix

moduix — стилизованная система React-компонентов, созданная на базе [Ark UI](https://ark-ui.com/). Она сочетает
доступные примитивы взаимодействия Ark с продуманными настройками по умолчанию, явной композицией и CSS-токенами,
предназначенными для продуктовых интерфейсов.

Чтобы попробовать библиотеку прямо сейчас, выберите способ установки в [Быстром старте](../../docs/quick-start), отобразите
Button и вернитесь сюда, когда понадобится более широкое представление о системе.

Визуальный язык и подход к доставке исходного кода [вдохновлены shadcn/ui](https://ui.shadcn.com/): компоненты должны
выглядеть продуманно без дополнительной настройки, оставаться понятными при чтении и становиться частью приложения,
когда такой процесс работы подходит лучше. moduix сохраняет характерные для Ark поведение и анатомию, не пытаясь быть
полной заменой shadcn.

## Выберите модель владения

Выберите npm-пакет, если хотите получать обновления через менеджер пакетов. Выберите размещённый реестр shadcn, если
исходный код компонента, стили и вспомогательные утилиты должны находиться в вашем репозитории.

| Способ работы | Импорты | Лучше всего подходит для |
| --- | --- | --- |
| npm-пакет | `@moduix/react/*` | Централизованных обновлений и минимального объёма кода, которым владеет приложение. |
| Реестр shadcn с исходным кодом в проекте | `@/components/moduix/*` | Непосредственного владения исходным кодом и осознанных локальных изменений. |

В обоих случаях доступны одни и те же контракты компонентов и система токенов. В [Быстром старте](../../docs/quick-start)
описана полная настройка для каждого варианта.

## Что означает «на базе Ark»

Сложные компоненты сохраняют модель Ark UI: именованные части, контролируемое и неконтролируемое состояние, объекты
подробностей в колбэках, провайдеры контекста, композицию `asChild`, нативные элементы форм и атрибуты состояния.
moduix добавляет стили, значения по умолчанию, удобную композицию и стабильные хуки `data-slot`, не скрывая структуру
примитивов, необходимую для сложных продуктовых сценариев.

Ark UI остаётся источником истины для поведения взаимодействий и доступности. moduix — расположенный поверх него
продуктовый слой с собственным мнением.

## Что означает «вдохновлён shadcn»

Это практическое, а не косметическое вдохновение:

- проработанные значения по умолчанию, которые выглядят целостно ещё до настройки;
- понятная композиция вместо обёрток с избыточной конфигурацией;
- открытые CSS-переменные и исходный код, которые легко изучать;
- размещённый реестр shadcn для установки исходного кода в проект;
- документация, которая сначала показывает основной путь и не скрывает возможности тонкой настройки.

moduix не требует Tailwind CSS и не заменяет анатомию Ark контрактами обёрток, специфичными для shadcn. Основой
стилизации остаются нативный CSS и CSS Modules.

## Контракт стилизации

Плотность по умолчанию задаёт основные элементы управления высотой `36px` и строки всплывающих списков высотой `32px`
через `--moduix-size-md` и `--moduix-size-sm`. Одну и ту же шкалу используют поля ввода, кнопки, триггеры Select и
Combobox, элементы выбора даты, пагинация, пункты меню и связанные паттерны.

Цвета, интервалы, скругления, типографика, кольца фокуса, анимация, тени и решения, специфичные для компонентов,
выражены через пользовательские свойства CSS. Переопределите семантический токен, чтобы изменить всю систему, общий
токен семейства — чтобы настроить связанные компоненты, или переменную `--<component>-*` для одного локального
исключения. Полная иерархия приведена в [Токенах](/ru/docs/tokens), а готовые пресеты — в [Темах](/ru/docs/themes).

## Благодарности

moduix возможен благодаря работе и идеям этих проектов:

- [Ark UI](https://ark-ui.com/) — за доступные примитивы на базе конечных автоматов, которые формируют основу поведения.
- [Chakra UI](https://chakra-ui.com/) — за соответствующую Ark эргономику композиции и мастерство дизайн-системы,
  которые продолжают влиять на moduix.
- [shadcn/ui](https://ui.shadcn.com/) — за распространение открытого кода, красивые значения по умолчанию и стиль
  документации, сосредоточенный на практическом владении.
- [UnoCSS](https://unocss.dev/) и [Tailwind CSS](https://tailwindcss.com/) — за основы, адаптированные для
  дополнительного reset.
- [Rspress](https://rspress.rs/) — за систему документации и инструменты предпросмотра компонентов.
- [Rstack](https://rspack.rs/) — за основанную на Rust инфраструктуру сборки документации.
- [VoidZero](https://voidzero.dev/) — за инструменты JavaScript, используемые во всём рабочем пространстве.
