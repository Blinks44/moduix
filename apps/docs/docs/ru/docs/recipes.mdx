# Рецепты

Рецепты — это готовые к копированию примеры распространённых паттернов интерфейса и продуктовых сценариев. Скопируйте компонент
и CSS со страницы рецепта, установите используемые им компоненты moduix, а затем адаптируйте данные и поведение
под своё приложение.

должны работать на обеих контрольных точках. Заголовок приложения можно расположить над любым из этих каркасов.

Каждый рецепт намеренно заканчивается там, где начинаются ваши маршруты, API, правила авторизации и
аналитика. На странице отмечены эти связи с продакшеном, чтобы скопированный интерфейс не создавал впечатления, будто он реализует поведение продукта.
