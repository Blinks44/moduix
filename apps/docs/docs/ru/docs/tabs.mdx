## Выбор подходящего компонента

Используйте `Tabs`, когда пользователю нужно переключаться между взаимоисключающими представлениями в одной области страницы.

- Выберите **`Tabs`**, если выбранная вкладка должна показывать одну связанную панель содержимого.
- Выберите **`Accordion`**, если разделы должны располагаться друг под другом и раскрываться независимо.
- Выберите **`ToggleGroup`**, если элемент управления меняет состояние или режим, но не управляет панелью содержимого.

## Анатомия

```text
Tabs
├─ Tabs.List
│  ├─ Tabs.Trigger[value]
│  ├─ Tabs.Trigger[value]
│  └─ Tabs.Indicator (optional)
└─ Tabs.Content[value]

Tabs.RootProvider
└─ same part tree connected to a useTabs() store

Tabs.Context
└─ advanced render-prop access to the current tab state
```

| Часть                | Назначение                                                                 |
| -------------------- | -------------------------------------------------------------------------- |
| `Tabs`               | Управляет выбранным значением, фокусом, ориентацией и режимом активации.   |
| `Tabs.RootProvider`  | Связывает части с состоянием, созданным через moduix `useTabs()`.          |
| `Tabs.Context`       | Предоставляет расширенный доступ к текущему состоянию через render prop.   |
| `Tabs.List`          | Группирует вкладки и управляет перемещением фокуса внутри списка.          |
| `Tabs.Trigger`       | Интерактивная вкладка или хост `asChild` с обязательным значением.         |
| `Tabs.Indicator`     | Необязательный индикатор активной вкладки, который позиционирует Ark.      |
| `Tabs.Content`       | Область содержимого, связанная со вкладкой через совпадающее значение.     |

## Композиция

### Рекомендуемая композиция

`Tabs` управляет клавиатурной навигацией, фокусом и выбранным значением. На корневом компоненте доступны `value`,
`defaultValue`, `onValueChange(details)`, `onFocusChange(details)`, `activationMode`, `orientation`, `loopFocus`,
`deselectable`, `lazyMount`, `unmountOnExit`, `ids` и `navigate`.

Сохраняйте структуру частей Ark явной. `Tabs.Indicator` необязателен: добавляйте его только тогда, когда нужен
визуальный индикатор активной вкладки.

### Когда нужна собственная композиция

Используйте `asChild` у `Tabs.Trigger`, если вкладка должна отображаться как ссылка или компонент маршрутизатора.
Дочерним должен быть один семантический элемент, способный принять клавиатурное поведение, фокус и ARIA-атрибуты Ark.

Используйте moduix `useTabs()` вместе с `Tabs.RootProvider`, если состояние вкладок нужно создать вне отображаемого
дерева. Не оборачивайте тот же экземпляр состояния в `Tabs`. Чтобы прочитать текущее состояние в соседнем элементе
интерфейса, используйте `Tabs.Context` или `useTabsContext()`.

### Свойства по умолчанию

| Свойство                  | По умолчанию | Примечание                                                         |
| ------------------------- | ------------ | ------------------------------------------------------------------ |
| `Tabs.variant`            | `default`    | Визуальный вариант moduix: `default` или `line`.                   |
| `Tabs.activationMode`     | `automatic`  | Фокус сразу выбирает вкладку; `manual` требует отдельной активации. |
| `Tabs.orientation`        | `horizontal` | Для `horizontal` используются стрелки влево/вправо, для `vertical` — вверх/вниз. |
| `Tabs.loopFocus`          | `true`       | После последней вкладки фокус переходит к первой, и наоборот.      |
| `Tabs.lazyMount`          | `false`      | Откладывает монтирование содержимого до выбора вкладки.            |
| `Tabs.unmountOnExit`      | `false`      | Удаляет неактивное содержимое из DOM при ленивом монтировании.     |

### Особенности поведения

- `onValueChange` получает объект `details`; выбранное значение находится в `details.value`.
- `Tabs.Trigger` и `Tabs.Content` связываются одинаковыми строковыми значениями свойства `value`.
- `Tabs.List` не добавляет индикатор автоматически. При необходимости явно отобразите `Tabs.Indicator`.
- `variant="line"` использует заполненный вариант `default` для вертикальных `Tabs` и `Tabs.RootProvider`.
- Ark управляет атрибутами доступности, связями с `tabpanel`, перемещением фокуса и поведением отключённых вкладок.

## Стилизация

Настраивайте `Tabs` через `className`, стабильные хуки `data-slot="tabs-*"`, атрибуты Ark `data-scope` и `data-part`,
`data-variant` и перечисленные ниже публичные CSS-переменные `--moduix-tabs-*`.

### Хуки стилизации

Настраивайте ту часть, которая отвечает за нужный элемент интерфейса:

- `Tabs` — ширина, общий интервал, ориентация и переопределения варианта;
- `Tabs.List` — оформление списка, границы, фон и отступы контейнера индикатора;
- `Tabs.Trigger` — расположение подписи, интервал рядом со значком, выбранное и отключённое состояния, фокус;
- `Tabs.Indicator` — цвет, размер и анимация индикатора;
- `Tabs.Content` — фон, внутренние отступы и оформление фокуса панели.

Основные публичные хуки: `data-slot="tabs-root"`, `data-slot="tabs-root-provider"`, `data-slot="tabs-list"`,
`data-slot="tabs-trigger"`, `data-slot="tabs-indicator"` и `data-slot="tabs-content"`.

Полезные хуки Ark: `data-scope="tabs"`, `data-part`, `data-orientation`, `data-selected`, `data-disabled`,
`data-focus`, а также переменные индикатора `--left`, `--top`, `--width` и `--height`.
