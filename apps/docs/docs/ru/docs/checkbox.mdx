`Checkbox` позволяет выбирать один или несколько независимых вариантов в формах, настройках и
списках фильтров. Используйте `RadioGroup`, когда можно выбрать только один вариант, а `Switch` -
когда настройка должна применяться сразу.

## Анатомия

```text
Checkbox.Root
├─ Checkbox.Control
│  ├─ Checkbox.Indicator
│  └─ Checkbox.Indicator[indeterminate] (optional)
├─ Checkbox.Label
└─ native input (automatic)

Checkbox.RootProvider
└─ same part tree connected to useCheckbox()

Checkbox.Group
└─ Checkbox.Root[value]
   ├─ Checkbox.Control
   ├─ Checkbox.Label
   └─ the native form input
```

| Часть                         | Назначение                                                                              |
| ---------------------------- | ---------------------------------------------------------------------------------------- |
| `Checkbox` / `Checkbox.Root` | Владеет состоянием одного checkbox и отрисовывает оборачивающий элемент label. |
| `Checkbox.RootProvider`      | Подключает части к состоянию Ark, созданному за пределами отрисованного поддерева. |
| `Checkbox.Control`           | Визуальная поверхность управления. Без дочерних элементов отрисовывает стандартные индикаторы выбранного и неопределённого состояния. |
| `Checkbox.Indicator`         | Необязательный слот иконки для пользовательской композиции. При необходимости используйте `indeterminate`. |
| `Checkbox.Label`             | Видимый текст метки внутри корневого компонента. |
| `Checkbox.Group`             | Разделяет состояние значения между несколькими корневыми checkbox. |

## Композиция

### Рекомендуемая композиция

Сохраняйте дерево частей Ark видимым. `Checkbox.Root` принимает пропы корневого компонента Ark, такие как `checked`,
`defaultChecked`, `onCheckedChange(details)`, `disabled`, `readOnly`, `invalid`, `required`,
`name`, `value`, `form`, `ids` и `asChild`.

`Checkbox.Group` принимает `value`, `defaultValue`, `onValueChange(value)`, `disabled`, `readOnly`,
`invalid`, `maxSelectedValues` и `name`.

`Checkbox.Control` - стандартное сокращение moduix: оставьте его пустым для встроенных иконок или передайте
дочерние элементы для пользовательской композиции индикатора. `size` - единственный дополнительный DX-проп у
`Checkbox.Root` и `Checkbox.RootProvider`.

### Когда нужна собственная композиция

Используйте `Checkbox.RootProvider`, когда состоянием checkbox нужно владеть за пределами отрисованного поддерева. moduix
повторно экспортирует для этого пути `useCheckbox()`. `Checkbox.Context`, `useCheckboxContext()`,
`useCheckboxGroup()` и `useCheckboxGroupContext()` сохраняют доступ к состоянию Ark для расширенной
композиции. Явно отрисовывайте `Checkbox.Indicator`, только когда нужны пользовательские иконки или
нестандартная компоновка индикатора.

### Свойства по умолчанию

| Поверхность                   | По умолчанию | Примечания                                            |
| ---------------------------- | ------- | ------------------------------------------------------- |
| `Checkbox` / `Checkbox.Root` | -           | Дополнительных поведенческих значений нет; применяются значения Ark. |
| `size`                       | `md`         | Применяется к `Checkbox.Root` и `Checkbox.RootProvider`. |

### Особенности поведения

Корневой компонент автоматически отрисовывает нативное поле формы для участия в нативных формах, валидации, сброса формы
и отправки. Для отдельного checkbox передайте `name` и `value` в `Checkbox.Root`. Для
группы передайте `name` в `Checkbox.Group`, а `value` - в каждый `Checkbox.Root`.

Для пользователей shadcn, переходящих на moduix, `Checkbox.Control` уже содержит стандартное оформление иконки. Основные
явные части, остающиеся в дереве, - control и label; скрытое поле ввода остаётся
внутренним.

Ark `Checkbox.Root` отрисовывает `label`. Если используется `asChild`, непосредственный дочерний элемент также должен быть
семантическим `label`, иначе checkbox больше не будет иметь корректной метки элемента формы.

При `readOnly` moduix также устанавливает `aria-readonly` на автоматически добавленном нативном
поле, а Ark блокирует взаимодействие.

Ref указывает на соответствующую часть DOM Ark. Checkbox в фокусе переключается клавишей <kbd>Space</kbd>.

### Хуки стилизации

- `Checkbox.Root` предоставляет `data-slot="checkbox-root"`, `data-size` и атрибуты состояния Ark, такие как `data-state`, `data-disabled`, `data-readonly`, `data-invalid`, `data-required`, `data-hover`, `data-focus` и `data-focus-visible`.
- `Checkbox.RootProvider` предоставляет `data-slot="checkbox-root-provider"` и тот же контракт стилизации корневого компонента.
- `Checkbox.Control` предоставляет `data-slot="checkbox-control"` и атрибуты состояния Ark, включая `data-state="checked" | "indeterminate" | "unchecked"`.
- `Checkbox.Indicator` предоставляет `data-slot="checkbox-indicator"` и наследует атрибуты состояния checkbox из Ark.
- `Checkbox.Label` предоставляет `data-slot="checkbox-label"` и атрибуты состояния checkbox из Ark.
- `Checkbox.Group` exposes `data-slot="checkbox-group"`.
