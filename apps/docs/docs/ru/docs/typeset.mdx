## Справочник API

Ark UI не предоставляет отдельный примитив для набора текста. Moduix строит `Typeset` с помощью [фабрики Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory), поэтому его корневой компонент и необязательная обёртка прокрутки сохраняют стандартные свойства HTML, `asChild` и ref для отрендеренных элементов.

## Базовый пример

Используйте короткий корневой компонент `<Typeset>` для отрендеренного HTML. Добавьте `asChild`, когда сам контейнер должен быть семантическим, например `article` или `section`. Используйте обычные элементы `<ul>` и `<ol>`: Typeset добавляет маркеры, нумерацию, вложенные маркеры и ритм чтения без utility-классов.

## Анатомия

```text
Typeset
└─ Typeset.Scroll (необязательно)
```

| Часть | Роль |
| --- | --- |
| `Typeset` / `Typeset.Root` | Изолированный корневой компонент, стилизующий семантических потомков. |
| `Typeset.Scroll` | Фокусируемый горизонтальный скроллер для широкого отрендеренного блока. |

## Композиция

### Рекомендуемая композиция

Оставьте разбор Markdown, очистку, рендеринг и ширину чтения приложению. `Typeset` предоставляет только изолированный визуальный ритм и намеренно не задаёт ширину чтения. Используйте `Typeset.Scroll` вокруг широкой таблицы или другого блока, который должен прокручиваться горизонтально.

### Когда нужна собственная композиция

Используйте семантический HTML напрямую, когда отрендеренному поддереву нужен другой визуальный контракт, затем добавьте `.not-typeset` или `data-not-typeset`, чтобы исключить его и всех потомков. Передайте `aria-label` или `aria-labelledby` в `Typeset.Scroll`, когда его области прокрутки нужно имя; тогда moduix задаст этой подписанной обёртке роль `region`. Также можно передать пользовательские `role` или `tabIndex`.

### Свойства по умолчанию

| Часть | По умолчанию | Примечания |
| --- | --- | --- |
| `Typeset` | `div` | Используйте `asChild` с ровно одним семантическим потомком, чтобы отрендерить другой контейнер. |
| `Typeset.Scroll` | `div`, `tabIndex={0}` | Фокусируемое состояние по умолчанию делает переполненную статическую таблицу доступной с клавиатуры; переданное доступное имя добавляет `role="region"`. |

### Особенности поведения

У `Typeset` нет машины состояний, управляемого состояния, поведения клавиатуры, интеграции с формами или скрытых полей ввода. Исключение — `Typeset.Scroll`: он фокусируем с клавиатуры по умолчанию, чтобы браузер мог прокручивать широкий статический блок. Его стили используют `margin-block-start` и избегают `:last-child`, `:has()` и `:empty`, поэтому добавление потокового блока Markdown не меняет стили прежних блоков.

### CSS-свойства

Три элемента управления ритмом: `--moduix-typeset-size`, `--moduix-typeset-leading` и `--moduix-typeset-flow`. Переменные шрифта необязательны; цвета, границы и радиус напрямую берутся из активной темы moduix. Правила элементов находятся в слое `moduix.components` и используют селекторы низкой специфичности `:where()`, поэтому обычный CSS приложения может переопределять отдельные элементы без `!important`.

### Хуки стилизации

- `data-slot="typeset"` нацелен на корневой контейнер.
- `data-slot="typeset-scroll"` нацелен на необязательную обёртку переполнения и её состояние focus-visible.
- `[data-scope="typeset"][data-part="root"]` и `[data-part="scroll"]` предоставляют стабильные хуки анатомии.
