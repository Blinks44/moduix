## Справочник API

В Ark UI нет отдельного примитива заголовка. Moduix строит этот компонент с помощью официальной
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[ref](https://ark-ui.com/docs/guides/ref).

## Анатомия

`Heading` — компонент только с корневой частью. `Heading.Root` — равнозначная форма пространства имён, согласованная с Ark.

```text
Heading / Heading.Root
└─ text or inline content
```

| Часть                      | Назначение                                                  |
| -------------------------- | ----------------------------------------------------------- |
| `Heading` / `Heading.Root` | Нативный семантический заголовок со стилями типографики moduix. |

## Композиция

### Рекомендуемая композиция

Используйте `<Heading>` для `h1`. Для другого семантического уровня передайте `as="h2"` вплоть до `as="h6"`:

```tsx
<Heading as="h2" size="2xl">
  Page title rendered as h2
</Heading>
```

Используйте `asChild` только когда семантический дочерний заголовок должен владеть DOM-узлом, но получать
свойства компонента, имя класса, атрибуты данных и перенаправленный ref.

### Когда нужна собственная композиция

Для визуальных переопределений используйте `className` и публичные переменные `--moduix-heading-*`.
Используйте `Text`, если содержимое является основным текстом или общей типографикой, а не заголовком документа.

### Свойства по умолчанию

| Элемент     | По умолчанию        | Значения и примечания                      |
| ----------- | ------------------- | ------------------------------------------ |
| element     | `h1`                | Используйте `as` для `h2` — `h6`           |
| `size`      | по рендеримому элементу | `xs`, `sm`, `md`, `lg`, `xl`, `2xl`     |
| `weight`    | `semibold`          | `regular`, `medium`, `semibold`, `bold`    |
| `asChild`   | `false`             | Композиция Ark factory                     |
| `className` | —                   | Применяется к корню отрендеренного заголовка |

### Особенности поведения

- Визуальный размер по умолчанию зависит от рендеримого элемента: `h1 -> 2xl`, `h2 -> xl`, `h3 -> lg`,
  `h4 -> md`, `h5 -> sm` и `h6 -> xs`.
- Явно заданный `size` переопределяет зависящее от элемента значение, не меняя семантику.
- Корневая часть перенаправляет ref на отрендеренный элемент заголовка.
- Нативным заголовкам не нужны дополнительные ARIA-атрибуты. Не используйте `asChild` с дочерним элементом, не являющимся заголовком.
- `Heading` не имеет состояния, обратных вызовов, поведения клавиатуры, провайдеров или контекстных хуков.

### Хуки стилизации

- `data-scope="heading"` обозначает область компонента, согласованную с Ark.
- `data-part="root"` обозначает единственную корневую часть.
- `data-slot="heading-root"` — стабильный селектор moduix.
- `data-size` присутствует, когда `size` задан явно.
- `data-weight` содержит `regular`, `medium`, `semibold` или `bold`.
- `Heading` владеет этими атрибутами: одноимённые `data-*` props не могут изменить его контракт стилизации.
- Используйте `className` и переменные `--moduix-heading-*` для локальных визуальных переопределений.
