## Выбор подходящего компонента

Используйте `Slider`, когда пользователь должен напрямую изменить ограниченное числовое значение указателем
или клавиатурой.

- Выберите **`Slider`** для громкости, яркости, бюджета, пороговых значений и диапазонов с несколькими ползунками.
- Выберите **`Input`** или **`NumberInput`**, когда точный ввод важнее перетаскивания.
- Выберите **`ProgressLinear`** или **`ProgressCircular`**, когда значение предназначено только для отображения.

## Базовый пример

`Slider.Thumbs` — рекомендуемый способ отрисовать один стилизованный ползунок для каждого значения. Каждый

## Анатомия

```text
Slider / Slider.Root
├─ Slider.Label
├─ Slider.ValueText
├─ Slider.Control
│  ├─ Slider.Track
│  │  └─ Slider.Range
│  └─ Slider.Thumbs
│     └─ Slider.Thumb[index]
│        ├─ Slider.DraggingIndicator
│        └─ native input (автоматически)
└─ Slider.MarkerGroup
   └─ Slider.Marker[value]
```

| Часть                                  | Назначение                                                       |
| -------------------------------------- | ---------------------------------------------------------------- |
| `Slider` / `Slider.Root`               | Стилизованный корень Ark для управляемого и неуправляемого состояния. |
| `Slider.RootProvider`                  | Корень, принимающий внешнюю машину `useSlider`.                  |
| `Slider.Label`                         | Видимая подпись группы slider.                                   |
| `Slider.ValueText`                     | Текст текущего значения, формируемый Ark.                        |
| `Slider.Control`                       | Область взаимодействия указателем.                               |
| `Slider.Track`                         | Полная визуальная направляющая.                                  |
| `Slider.Range`                         | Заполненный отрезок от заданной точки отсчёта до значения.       |
| `Slider.Thumb`                         | Ползунок slider, принимающий фокус.                              |
| `Slider.Thumbs`                        | Помощник Moduix, рендерящий ползунок для каждого значения.       |
| `Slider.MarkerGroup` / `Slider.Marker` | Необязательная группа делений и отдельное деление.               |
| `Slider.DraggingIndicator`             | Необязательное значение во всплывающей подсказке при перетаскивании. |

## Композиция

### Рекомендуемая композиция

Используйте дерево частей Ark: корень, подпись, необязательный текст значения, элемент управления, направляющую,
диапазон и `Slider.Thumbs`. Он создаёт один ползунок для каждого значения; каждый ползунок автоматически добавляет
нативный элемент ввода формы.

`Slider` — краткая форма корня, эквивалентная `Slider.Root`.

### Когда нужна собственная композиция

Используйте `asChild`, когда часть должна отрисовать пользовательский host-элемент, но оставляйте единственный
семантический дочерний элемент, способный принять свойства Ark. Используйте явный `Slider.Thumb` для пользовательских
дочерних элементов, подписей или порядка ползунков; он сохраняет автоматический нативный элемент ввода формы.
Для расширенного доступа к состоянию импортируйте `useSliderContext` или `useSlider` из `@moduix/react` и используйте
их вместе с `Slider.RootProvider`.

### Свойства по умолчанию

| Свойство                 | По умолчанию  | Примечания                                                        |
| ------------------------ | ------------ | ----------------------------------------------------------------- |
| `defaultValue`           | `[min]`      | Ark хранит значения slider как `number[]`.                        |
| `orientation`            | `horizontal` | Используйте `vertical` для вертикальной клавиатурной оси.         |
| `min`                    | `0`          | Нижняя граница.                                                   |
| `max`                    | `100`        | Верхняя граница.                                                  |
| `step`                   | `1`          | Шаг для указателя и клавиатуры.                                   |
| `minStepsBetweenThumbs`  | `0`          | Минимальный промежуток между ползунками диапазона.                |
| `origin`                 | `start`      | Начало заполнения для диапазонов с одним значением.               |
| `thumbAlignment`         | `contain`    | Используйте `center`, чтобы позволить ползунку выходить за края.  |
| `thumbCollisionBehavior` | `none`       | Используйте `push` или `swap` при перетаскивании диапазона.       |
| `thumbSize`              | измеряется   | Переопределяет измеренные Ark размеры ползунка.                   |

`value`, `defaultValue`, `onValueChange(details)` и `onValueChangeEnd(details)` используют объекты details Ark.
Чтобы прочитать массив, используйте `details.value`.

### Особенности поведения

`Slider` следует поведению WAI-ARIA slider из Ark. Каждому ползунку нужно доступное имя через `Slider.Label`,
`aria-label` или `aria-labelledby`. Горизонтальные slider используют клавиши со стрелками влево и вправо;
вертикальные — вверх и вниз. Page Up, Page Down, Home и End используют настроенный большой шаг или границы.

Каждый `Slider.Thumb` автоматически рендерит нативный элемент ввода формы для отправки формы, связи с ней и
синхронизации сброса. `disabled`, `invalid`, `readOnly`, `name`, `form`, `ids`, `aria-label`, `aria-labelledby`
и `getAriaValueText(details)` передаются в Ark.

### Хуки стилизации

Ark записывает `data-scope="slider"` и `data-part` во все отрендеренные части. Moduix также записывает
значения `data-slot`: `slider-root`, `slider-root-provider`, `slider-label`, `slider-value-text`,
`slider-control`, `slider-track`, `slider-range`, `slider-thumb`, `slider-hidden-input`,
`slider-marker-group`, `slider-marker` и `slider-dragging-indicator`.

К важным хукам состояния Ark относятся `data-orientation`, `data-disabled`, `data-invalid`,
`data-focus`, `data-dragging`, `data-state` маркера и `data-state="open | closed"` индикатора
перетаскивания. CSS-переменные среды выполнения Ark: `--slider-thumb-width`, `--slider-thumb-height`,
`--slider-thumb-transform`, `--slider-range-start`, `--slider-range-end`, `--translate-x` и `--translate-y`.

moduix добавляет `data-readonly` к `Slider`, когда задано свойство `readOnly`. В состоянии ошибки по умолчанию
используется деструктивный цвет для направляющей, выбранного диапазона и ползунка.

Стандартное кольцо фокуса ползунка использует `:focus-visible` для фокуса с клавиатуры и Ark `data-dragging`,
пока ползунок нажат. После отпускания указателя оно убирается.
