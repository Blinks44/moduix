## Справочник API

Ark UI не предоставляет отдельный примитив `text`. moduix строит этот компонент с помощью официального
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[ref](https://ark-ui.com/docs/guides/ref).

## Выбор подходящего компонента

Используйте `Text` для основного и вспомогательного текста, встроенного акцента и сопроводительного текста интерфейса,
который должен оставаться на типографической шкале moduix.

- Выбирайте **`Heading`** для структуры документа и иерархии заголовков.
- Выбирайте **`Text`**, когда содержимое должно сохранять семантику абзаца или встроенного текста со стилями основного текста.
- Используйте локальный CSS, когда задача связана с разметкой форматированного текста, отступами или раскрытием усечённого текста.

## Анатомия

`Text` рендерит один корневой элемент Ark factory. Краткая форма `<Text>` и `<Text.Root>` равнозначны.

```text
Text / Text.Root
└─ text or inline content
```

| Часть                 | Назначение                                                            |
| --------------------- | --------------------------------------------------------------------- |
| `Text` / `Text.Root` | Семантический корневой элемент текста с типографикой дизайн-системы и data-хуками. |

## Композиция

### Рекомендуемая композиция

Используйте краткую форму `<Text>` для основного и вспомогательного текста. Она равнозначна `<Text.Root>`,
по умолчанию рендерит `p` и передаёт ref отрендеренному `HTMLElement`.

### Когда нужна собственная композиция

Используйте `as` для поддерживаемых встроенных тегов, когда нужно изменить семантический элемент. Используйте `asChild`,
когда один пользовательский хост-элемент должен получить класс moduix, стили, data-атрибуты и ref. Рецепт
Chakra [Text](https://chakra-ui.com/docs/components/text) определяет локальные API размеров, насыщенности, усечения
и ограничения числа строк.

### Свойства по умолчанию

| Свойство    | По умолчанию      | Примечания                                                   |
| ----------- | ----------------- | ------------------------------------------------------------ |
| `as`        | `p`               | `p`, `span`, `small`, `strong`, `em` или `div`.              |
| `asChild`   | `false`           | Использует единственный дочерний элемент как хост.           |
| `size`      | Зависит от элемента | Для `small` по умолчанию - `sm`; для других корней - `md`. |
| `weight`    | Зависит от элемента | Для `strong` по умолчанию - `semibold`; иначе - `regular`. |
| `tone`      | `default`         | `default`, `muted`, `subtle`, `primary`, `destructive`.     |
| `align`     | Не задано (`start`) | `start`, `center`, `end`, `left`, `right` или `justify`.   |
| `truncate`  | `false`           | Однострочное CSS-усечение с многоточием.                    |
| `lineClamp` | Не задано         | Положительное целое число; некорректные значения отключают ограничение. |

### Особенности поведения

У `Text` нет машины состояний, управляемого состояния, поведения клавиатуры, интеграции с `Field`/`Fieldset`,
`HiddenInput`, идентификаторов, контекстных хуков или `RootProvider`. `truncate` и `lineClamp` - визуальные CSS-ограничения;
`lineClamp` принимает только положительные целые числа. Поведение раскрытия содержимого определяет окружающий макет.

## Стилизация

Стилизуйте `Text` через `className`, корневые data-атрибуты в стиле Ark и публичные CSS-переменные `--moduix-text-*`,
описанные в публичном CSS API.

### Хуки стилизации

- `data-scope="text"` и `data-part="root"` обозначают корневой элемент в стиле Ark.
- `data-slot="text-root"` - стабильный селектор moduix на экспортируемом корне.
- `data-size` отражает вычисленный визуальный размер: `xs`, `sm`, `md`, `lg` или `xl`.
- `data-weight` отражает активную предустановку насыщенности: `regular`, `medium`, `semibold` или `bold`.
- `data-tone` отражает активную предустановку тона: `default`, `muted`, `subtle`, `primary` или `destructive`.
- `data-align` появляется, только когда `align` явно задан как `start`, `center`, `end`, `left`, `right` или `justify`.
- `data-truncate` появляется при активном однострочном усечении с многоточием.
- `data-line-clamp` появляется, когда `lineClamp` - положительное целое число, и задаёт резервное
  значение. Укажите `--moduix-text-line-clamp`, чтобы переопределить его через публичный CSS API.
