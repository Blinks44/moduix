## Справочник API

`NativeSelect` оборачивает компонент Ark UI
[Field.Select](https://ark-ui.com/docs/components/field) и рендерит настоящий HTML-элемент `<select>`.
Его визуальная связь с пользовательским `Select` основана на Chakra UI
[Native Select](https://chakra-ui.com/docs/components/native-select), но moduix сохраняет единый публичный API.

## Выбор подходящего компонента

Используйте `NativeSelect` для простых списков вариантов, когда нужны автозаполнение браузера, сброс формы,
встроенное управление с клавиатуры и системные элементы выбора на мобильных устройствах. Используйте
[`Select`](/docs/select), когда интерфейсу нужны собственное всплывающее окно, API коллекций, составные элементы,
очистка, отображение нескольких значений или управляемое состояние всплывающего окна.

## Анатомия

`NativeSelect` сохраняет настоящий элемент `<select>` в качестве элемента управления формой и добавляет
неинтерактивный moduix-значок `ChevronDownIcon`, выравнивающий его с `Select`.

```text
NativeSelect
└─ span[data-scope="native-select"][data-part="control"]
   ├─ select[data-scope="field"][data-part="select"][data-slot="native-select-root"]
   │  ├─ option
   │  └─ optgroup
   └─ span[data-scope="native-select"][data-part="indicator"]
      └─ ChevronDownIcon
```

| Часть          | Назначение                                                |
| -------------- | --------------------------------------------------------- |
| `NativeSelect` | Стилизованный нативный элемент `<select>` с индикатором. |

## Композиция

### Рекомендуемая композиция

Используйте короткую форму `NativeSelect` с нативными дочерними элементами и стандартными управляемыми или
неуправляемыми свойствами HTML. Поместите компонент в `Field.Root`, если элементу управления нужны видимая
подпись, пояснение, сообщение об ошибке или общие состояния `required`, `invalid` и `disabled`.

`NativeSelect.Root` - псевдоним для обратной совместимости; в коде приложения предпочитайте `NativeSelect`.

### Когда нужна собственная композиция

Перейдите на `Select`, если приложению нужно управлять отображением вариантов, позиционированием выпадающего окна,
состоянием коллекции или собственными индикаторами. Используйте `NativeSelect`, когда выбором должен управлять браузер.

### Свойства по умолчанию

| Свойство       | По умолчанию       | Примечание                                                   |
| -------------- | ------------------ | ------------------------------------------------------------ |
| `value`        | -                  | Нативное управляемое значение                                |
| `defaultValue` | -                  | Нативное неуправляемое значение                              |
| `onChange`     | -                  | Нативный `ChangeEvent<HTMLSelectElement>`                    |
| `multiple`     | `false`            | Включает встроенный множественный выбор                      |
| `size`         | значение браузера  | Количество видимых строк, а не визуальный размер компонента  |
| `disabled`     | `false`            | Нативное отключённое состояние                               |
| `controlProps` | -                  | Свойства внешнего контейнера                                 |
| `asChild`      | `false`            | Композиция Ark; дочерний элемент должен оставаться `<select>` |

### Особенности поведения

- Реф нацелен на настоящий `HTMLSelectElement`.
- Нативная отправка формы, автозаполнение, сброс, обязательная проверка, варианты и клавиатурное поведение сохраняются.
- `multiple` и нативные значения `size` больше единицы используют собственную высоту списка.
- `Field.Root` передаёт идентификаторы, `aria-describedby`, недопустимое состояние и нативные состояния поля.
- При использовании `asChild` оставляйте дочерний элемент семантическим HTML-элементом `<select>`.
- HTML-элемент `<select>` не поддерживает состояние только для чтения.
- `ChevronDownIcon` визуально согласует закрытый элемент с `Select`, но выпадающее окно по-прежнему отображает браузер.

## Стилизация

### CSS-свойства

`NativeSelect` повторно использует переменные уровня элемента управления `--moduix-select-*`, поэтому нативный
и пользовательский `Select` могут использовать общие размеры, отступы индикатора, границы, цвета, радиус,
кольцо фокуса, непрозрачность отключённого состояния и переходы. Его отступы по умолчанию и геометрия индикатора
следуют общей шкале с шагом 4 px.

### Хуки стилизации

- `className` стилизует настоящий элемент `<select>`. Используйте `controlProps.className` для внешнего контейнера.
- Поместите в `controlProps.style` переменные `--moduix-select-*`, влияющие на индикатор, чтобы их наследовали и
  элемент `<select>`, и индикатор.
- `data-scope="field"` и `data-part="select"` сохраняют контракт на стилизацию Ark Field.
- `data-slot="native-select-root"` - стабильный селектор moduix для элемента управления.
- `data-slot="native-select-control"` и `data-slot="native-select-indicator"` нацеливают внутренний контейнер и значок.
- Нативные селекторы `:focus-visible`, `:disabled`, `[aria-invalid="true"]`, `[multiple]` и `[size]` определяют
  визуальные состояния.
