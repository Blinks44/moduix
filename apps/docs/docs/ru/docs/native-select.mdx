## Справочник API

`NativeSelect` оборачивает пользовательский интерфейс Ark
[Field.Select](https://ark-ui.com/docs/components/field) и отображает настоящий HTML-код `<select>`.
Пользовательский интерфейс Chakra [Native Select](https://chakra-ui.com/docs/components/native-select) сообщает о своем визуальном изображении.
связь с пользовательским Select, в то время как moduix сохраняет общедоступный API в одном компоненте.

## Выбор подходящего компонента

Используйте `NativeSelect` для простых списков опций, в которых есть автозаполнение браузера, сброс формы, встроенные функции.
поведение клавиатуры и средства выбора мобильной платформы желательны. Используйте [`Select`](https://moduix.dev/docs/select), когда
интерфейсу требуется собственное всплывающее окно, API-интерфейсы сбора данных, расширенные элементы, очистка, представление нескольких значений,
или контролируемое поведение всплывающих окон.

## Анатомия

`NativeSelect` сохраняет реальный выбор в качестве элемента управления формой и добавляет неинтерактивный модуль.
`ChevronDownIcon` для согласованного совмещения с `Select`.

```text
NativeSelect
└─ span[data-scope="native-select"][data-part="control"]
   ├─ select[data-scope="field"][data-part="select"][data-slot="native-select-root"]
   │  ├─ option
   │  └─ optgroup
   └─ span[data-scope="native-select"][data-part="indicator"]
      └─ ChevronDownIcon
```

|Часть|Роль|
| -------------- | --------------------------------------------- |
|`NativeSelect`|Стилизованный нативный выбор с визуальным индикатором.|

## Композиция

### Рекомендуемая композиция

Используйте короткую форму `NativeSelect` с нативными детьми и нативными контролируемыми или неконтролируемыми реквизитами.
Составьте его внутри `Field.Root`, когда элементу управления требуется видимая метка, вспомогательный текст, текст ошибки или
общее обязательное, недопустимое или отключенное состояние.

`NativeSelect.Root` — псевдоним совместимости; предпочитайте `NativeSelect` в коде приложения.

### Когда нужна собственная композиция

Переключитесь на `Select` при рендеринге параметров, расположении всплывающего окна, состоянии коллекции или пользовательских индикаторах.
должно контролироваться приложением. Оставьте `NativeSelect` для поведения выбора, принадлежащего браузеру.

### Свойства по умолчанию

|Опора|По умолчанию|Примечания|
| -------------- | --------------- | --------------------------------------------------- |
|`value`| -               |Исходное контролируемое значение|
|`defaultValue`| -               |Родное неконтролируемое значение|
|`onChange`| -               |Родной `ChangeEvent<HTMLSelectElement>`|
|`multiple`|`false`|Включает встроенный множественный выбор|
|`size`|браузер по умолчанию|Собственный видимый счетчик строк, а не вариант визуального размера|
|`disabled`|`false`|Родное отключенное состояние|
|`controlProps`| -               |Реквизит для внешнего диапазона макета|
|`asChild`|`false`|Состав ковчега; обычно оставляю это выключенным|

### Особенности поведения

- Реф нацелен на настоящий `HTMLSelectElement`.
- Встроенная отправка, автозаполнение, сброс, обязательная проверка, параметры и поведение клавиатуры.
сохранился.
- `multiple` и собственные значения `size` больше единицы используют внутреннюю высоту списка.
- `Field.Root` предоставляет идентификаторы, `aria-describedby`, недопустимое состояние и реквизиты собственного состояния.
- HTML select не поддерживает состояние только для чтения.
- `ChevronDownIcon` сохраняет свернутый элемент управления в соответствии с `Select`; браузер по-прежнему владеет
появление всплывающего окна.

## Стилизация

### CSS-свойства

`NativeSelect` повторно использует переменные `--moduix-select-*` уровня управления, поэтому можно использовать собственные и пользовательские выборки.
общие размеры, расстояние между индикаторами, границы, цвета, радиус, кольцо фокусировки, отключенная непрозрачность и
переходы. Его отступы по умолчанию и геометрия индикатора соответствуют общему масштабу интервалов 4 пикселя.

### Хуки стилизации

- `className` стилизует настоящий элемент выбора. Используйте `controlProps.className` для внешнего диапазона макета.
- Поместите переменные `--moduix-select-*`, влияющие на индикатор, в `controlProps.style`, чтобы оба элемента выбора
и индикатор наследует их.
- `data-scope="field"` и `data-part="select"` сохраняют контракт на оформление Ark Field.
- `data-slot="native-select-root"` — это стабильный переключатель модулей управления.
- `data-slot="native-select-control"` и `data-slot="native-select-indicator"` нацелены на внутреннюю
макет и значок.
- Собственные селекторы `:focus-visible`, `:disabled`, `[aria-invalid="true"]`, `[multiple]` и `[size]`.
управлять визуальными состояниями.
