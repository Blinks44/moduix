## Справочник API

`NativeSelect` оборачивает компонент Ark UI
[Field.Select](https://ark-ui.com/docs/components/field) и рендерит настоящий HTML-элемент `<select>`.
Визуальная связь с пользовательским компонентом Select основана на Chakra UI
[Native Select](https://chakra-ui.com/docs/components/native-select), при этом moduix сохраняет единый публичный API.

## Выбор подходящего компонента

Используйте `NativeSelect` для простых списков вариантов, когда нужны автозаполнение браузера, сброс формы,
встроенное управление с клавиатуры и системные элементы выбора на мобильных устройствах. Используйте
[`Select`](/docs/select), когда интерфейсу нужны собственное всплывающее окно, API коллекций, составные элементы,
очистка, отображение нескольких значений или управляемое состояние всплывающего окна.

## Анатомия

`NativeSelect` сохраняет реальный выбор в качестве элемента управления формой и добавляет неинтерактивный модуль.
`ChevronDownIcon` для согласованного совмещения с `Select`.

```text
NativeSelect
└─ span[data-scope="native-select"][data-part="control"]
   ├─ select[data-scope="field"][data-part="select"][data-slot="native-select-root"]
   │  ├─ option
   │  └─ optgroup
   └─ span[data-scope="native-select"][data-part="indicator"]
      └─ ChevronDownIcon
```

| Часть          | Назначение                                      |
| -------------- | --------------------------------------------- |
|`NativeSelect`|Стилизованный нативный `select` со значком раскрытия.|

## Композиция

### Рекомендуемая композиция

Используйте короткую форму `NativeSelect` с нативными `option` и управляемыми или неуправляемыми свойствами HTML.
Поместите его в `Field.Root`, если элементу управления нужны видимая подпись, пояснение, сообщение об ошибке или
общие состояния required, invalid и disabled.

`NativeSelect.Root` — псевдоним совместимости; предпочитайте `NativeSelect` в коде приложения.

### Когда нужна собственная композиция

Перейдите на `Select`, если приложению нужно управлять отображением вариантов, позиционированием выпадающего окна,
состоянием коллекции или собственными индикаторами. Используйте `NativeSelect`, когда выбором должен управлять браузер.

### Свойства по умолчанию

| Свойство       | По умолчанию     | Примечание                                               |
| -------------- | --------------- | --------------------------------------------------- |
|`value`| -               |Нативное управляемое значение|
|`defaultValue`| -               |Нативное неуправляемое значение|
|`onChange`| -               |Нативный `ChangeEvent<HTMLSelectElement>`|
|`multiple`|`false`|Включает встроенный множественный выбор|
|`size`|значение браузера|Количество видимых строк, а не визуальный размер компонента|
|`disabled`|`false`|Нативное отключённое состояние|
|`controlProps`| -               |Свойства внешнего контейнера|
|`asChild`|`false`|Композиция Ark; обычно менять это значение не требуется|

### Особенности поведения

- Реф нацелен на настоящий `HTMLSelectElement`.
- Нативная отправка формы, автозаполнение, сброс, обязательная проверка, варианты и клавиатурное поведение сохраняются.
- `multiple` и нативные значения `size` больше единицы превращают элемент в список заданной высоты.
- `Field.Root` передаёт идентификаторы, `aria-describedby`, недопустимое состояние и нативные состояния поля.
- HTML select не поддерживает состояние только для чтения.
- `ChevronDownIcon` визуально согласует закрытый элемент с `Select`, но выпадающее окно по-прежнему отображает браузер.

## Стилизация

### CSS-свойства

`NativeSelect` повторно использует переменные `--moduix-select-*` уровня управления, поэтому можно использовать собственные и пользовательские выборки.
общие размеры, расстояние между индикаторами, границы, цвета, радиус, кольцо фокусировки, отключенная непрозрачность и
переходы. Его отступы по умолчанию и геометрия индикатора соответствуют общему масштабу интервалов 4 пикселя.

### Хуки стилизации

- `className` стилизует настоящий элемент выбора. Используйте `controlProps.className` для внешнего диапазона макета.
- Поместите переменные `--moduix-select-*`, влияющие на индикатор, в `controlProps.style`, чтобы оба элемента выбора
и индикатор наследует их.
- `data-scope="field"` и `data-part="select"` сохраняют контракт на оформление Ark Field.
- `data-slot="native-select-root"` — это стабильный переключатель модулей управления.
- `data-slot="native-select-control"` и `data-slot="native-select-indicator"` нацелены на внутреннюю
макет и значок.
- Собственные селекторы `:focus-visible`, `:disabled`, `[aria-invalid="true"]`, `[multiple]` и `[size]`.
управлять визуальными состояниями.
