## Анатомия

```text
NumberInput.Root
├─ NumberInput.Label
├─ NumberInput.Scrubber (optional)
├─ NumberInput.Field (recommended)
├─ NumberInput.Control
│  ├─ NumberInput.DecrementTrigger
│  ├─ NumberInput.Input
│  └─ NumberInput.IncrementTrigger
└─ NumberInput.ValueText (optional)

NumberInput.RootProvider
└─ same part tree connected to state created with `useNumberInput()`
```

|Часть|Роль|
| ---------------------------------- | ---------------------------------------------------------------------- |
|`NumberInput` / `NumberInput.Root`|Управляет состоянием ввода чисел, синтаксическим анализом, форматированием и поведением клавиатуры.|
|`NumberInput.RootProvider`|Соединяет детали с состоянием, созданным с помощью `useNumberInput()`.|
|`NumberInput.Context`|Предоставляет форматированные и числовые значения, а также методы императивного состояния.|
|`NumberInput.Label`|Доступная метка, связанная с управляемым входом.|
|`NumberInput.Scrubber`|Необязательная цель перетаскивания, которая меняет значение посредством перемещения указателя.|
|`NumberInput.Control`|Структурная оболочка для триггеров ввода и увеличения/уменьшения.|
|`NumberInput.Field`|Отображает элемент управления, ввод и группу триггеров по умолчанию.|
|`NumberInput.DecrementTrigger`|Кнопка, уменьшающая текущее значение. По умолчанию используется значок минуса moduix.|
|`NumberInput.Input`|Редактируемый ввод числового текста, управляемый пользовательским интерфейсом Ark.|
|`NumberInput.IncrementTrigger`|Кнопка, увеличивающая текущее значение. По умолчанию используется значок плюса moduix.|
|`NumberInput.ValueText`|Текстовая поверхность только для чтения для форматированного значения.|

## Композиция

### Рекомендуемая композиция

`NumberInput` владеет синтаксическим анализом, проверкой диапазона, увеличением/уменьшением клавиатуры, вращением при нажатии, скруббером.
взаимодействие и форматирование. Установите `allowMouseWheel`, если изменения с помощью колеса являются преднамеренными. Использовать
`NumberInput.Field` для видимых частей по умолчанию.

Используйте строковые значения для `value` и `defaultValue`. Арк сообщает об изменениях через
`onValueChange(details)`, где `details.value` — строковое значение, а `details.valueAsNumber` —
разобранный номер.

### Когда нужна собственная композиция

Используйте `NumberInput.Control` с отдельными частями, когда порядок триггеров, значки или стиль ввода
должен отличаться от значения по умолчанию `NumberInput.Field`. Используйте `NumberInput.Scrubber` рядом с полем для
перетаскивание для изменения ввода.

### Свойства по умолчанию

|Опора|По умолчанию|Примечания|
| ---------------------------------- | ------- | ------------------------------------------------------------ |
|`NumberInput` / `NumberInput.Root`| —       |Никаких дополнительных поведенческих настроек по умолчанию; Применяются настройки Ark по умолчанию.|
|`NumberInput.Field`| —       |Отображает элемент управления, ввод и группу триггеров по умолчанию.|
|`NumberInput.DecrementTrigger`| —       |Отображает значок значок минуса moduix, когда дочерние элементы не указаны.|
|`NumberInput.IncrementTrigger`| —       |Отображает значок значок плюса moduix, когда дочерние элементы не указаны.|

### Особенности поведения

- Для форматирования локализованных чисел используйте `formatOptions`, а не `format`.
- Используйте `translations.incrementLabel`, `translations.decrementLabel` и `translations.valueText` для доступа к локализованным меткам.
- `min`, `max`, `step`, `allowOverflow`, `clampValueOnBlur`, `spinOnPress`, `inputMode` и `allowMouseWheel` проходят непосредственно в Арк.
- `onValueInvalid(details)` сообщает `rangeUnderflow` или `rangeOverflow`, когда значение превышает настроенные границы.
- Установите `clampValueOnBlur={false}`, когда введенные значения за пределами `min` или `max` должны оставаться неизменными при размытии.
- Используйте `ids`, когда внешним меткам или описаниям требуются стабильные идентификаторы элементов.
- Части с поддержкой Ark поддерживают `asChild` для пользовательской композиции хоста; `NumberInput.Field` намеренно
отображает фиксированную трехчастную структуру и пересылает ссылку на `NumberInput.Control`.
- `useNumberInput`, `useNumberInputContext` и `NumberInput.Context` доступны на сайте `@moduix/react`.
- Чтобы отправить числовое значение, отобразите скрытый собственный ввод из `NumberInput.Context` с помощью
`context.valueAsNumber`.
