## Анатомия

```text
HoverCard
├─ HoverCard.Trigger
└─ Overlay subtree (automatically portalled)
   └─ HoverCard.Positioner
      └─ HoverCard.Content
         ├─ HoverCard.Arrow
         │  └─ HoverCard.ArrowTip
         └─ content

HoverCard.RootProvider
└─ same part tree connected to a moduix useHoverCard() store
```

| Часть                      | Назначение                                                               |
| -------------------------- | ------------------------------------------------------------------------ |
| `HoverCard`                | Корневое состояние, задержки, позиционирование, ids, присутствие и взаимодействие снаружи. |
| `HoverCard.RootProvider`   | Рендерит дерево hover card из состояния, возвращённого moduix `useHoverCard`. |
| `HoverCard.Trigger`        | Цель для наведения и фокуса. Для ссылок или пользовательских хостов используйте `asChild`. |
| `HoverCard.Positioner`     | Плавающий слой, предоставляющий CSS-переменные позиционирования Ark.    |
| `HoverCard.Content`        | Видимая поверхность всплывающего окна и dismissable layer.              |
| `HoverCard.Arrow`          | Обёртка позиционированной стрелки. По умолчанию содержит `HoverCard.ArrowTip`. |
| `HoverCard.ArrowTip`       | Наконечник стрелки, стилизуемый через переменные стрелки Ark.           |

`HoverCard.Root` остаётся псевдонимом для совместимости; в пользовательском коде используйте короткую
корневую форму `HoverCard`.

## Композиция

Корень автоматически портализирует `HoverCard.Positioner`. Установите `portalled={false}`, чтобы отрендерить его
встроенно, или передайте `portalRef`, чтобы выбрать пользовательский контейнер. Сохраняйте структурные части
явными, чтобы размещение, содержимое и стрелка оставались независимо компонуемыми.

### Когда нужна собственная композиция

Используйте `asChild` на `HoverCard.Trigger` для настоящей ссылки или собственной семантической кнопки.
Рендерите `HoverCard.ArrowTip` напрямую только когда нужно изменить его разметку. Используйте
`HoverCard.RootProvider` с moduix `useHoverCard()`, когда состоянием нужно делиться за пределами отрендеренного
дерева, а `HoverCard.Context` или `useHoverCardContext()` — для чтения состояния внутри.

### Свойства по умолчанию

По умолчанию содержимое портализированного оверлея лениво монтируется и демонтируется после анимации закрытия.
Установите `unmountOnExit={false}`, чтобы сохранять его после первого открытия; устанавливайте оба свойства
жизненного цикла в `false` только когда нужен нетерпеливый начальный рендеринг.

| Свойство               | По умолчанию | Примечания                                                        |
| ---------------------- | ------------ | ----------------------------------------------------------------- |
| `closeDelay`           | `300`        | Время в мс от ухода указателя с триггера или содержимого до закрытия. |
| `openDelay`            | `600`        | Время в мс от входа указателя на триггер до открытия.            |
| `lazyMount`            | `true`       | Откладывает монтирование содержимого до первого открытия.        |
| `unmountOnExit`        | `true`       | Удаляет содержимое после анимации закрытия.                       |
| `skipAnimationOnMount` | `false`      | По умолчанию разрешает начальную анимацию появления.              |

### Особенности поведения

`onOpenChange` получает объекты деталей Ark, например `{ open }`; используйте `details.open`. Для нескольких
триггеров применяйте `Trigger value` вместе с `onTriggerValueChange`. `ids` позволяет зафиксировать ids триггера,
содержимого, positioner и стрелки для составной доступности. Свойства присутствия Ark, включая `present`,
`immediate` и `onExitComplete`, передаются без изменений.

Hover card предназначены только для дополнительных предпросмотров. Информация, необходимая для понимания или
выполнения задачи, должна быть доступна без открытия карточки.

### Хуки стилизации

Каждая отрендеренная часть принимает `className`; moduix также добавляет хуки `data-slot="hover-card-*"` для
корня, корневого провайдера, триггера, positioner, содержимого, стрелки и наконечника стрелки. Ark предоставляет
на своих частях `data-scope="hover-card"` и `data-part`. Для зависящей от состояния стилизации используйте
`data-state="open|closed"`, `data-placement`, `data-side`, `data-value`, `data-current`, `data-nested` и
`data-has-nested`.

`HoverCard.Positioner` предоставляет `--reference-width`, `--reference-height`, `--available-width`,
`--available-height`, `--x`, `--y`, `--z-index` и `--transform-origin`. `HoverCard.Content` предоставляет
`--layer-index` и `--nested-layer-count`; `HoverCard.Arrow` предоставляет `--arrow-size`, `--arrow-size-half`,
`--arrow-background` и `--arrow-offset`.
