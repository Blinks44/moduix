## Справочник по API

Ark UI не поставляется с выделенным компонентом текстовой области. Moduix стилизует и реэкспортирует [Ark Field.Textarea](https://ark-ui.com/docs/components/field), сохраняя собственный API текстовой области, `autoresize`, пересылку ссылок, `asChild` и наследование состояний Field.

## Выбор подходящего компонента

Используйте `Textarea`, когда значение представляет собой обычный текст, может занимать несколько строк и должно сохранять поведение текстовой области, характерное для браузера.

- Выбирайте **`Input`** для коротких однострочных значений: имён, URL или компактных фильтров.
- Выбирайте **`Textarea`** для заметок, комментариев, описаний и другого длинного произвольного текста.
- Выбирайте **`Editable`** для текста, который сначала показывается, а затем переключается в режим редактирования.
- Выбирайте **`Field` + `Textarea`**, если метки, описания и валидация должны оставаться декларативными.

## Анатомия

Государственная структура намеренно мала:

```text
Field (optional wrapper)
└─ Textarea
```

|Часть|Роль|
| ---------- | ---------------------------------------------------------- |
|`Textarea`|Собственный элемент textarea со стилями moduix и данными полей.|

`Textarea` не добавляет оболочки-оболочки, подразделы, перехватчики поставщика/контекста, скрытые входные данные или реквизиты слота, специфичные для текстовой области.

## Состав

### Рекомендуемый состав

Оставайтесь с `Textarea` для обычного многострочного ввода текста.

Используйте `Textarea` непосредственно для собственных реквизитов, таких как `rows`, `name`, `placeholder`, `maxLength`, `readOnly`, `disabled`, `required`, `value` и `defaultValue`.

Оберните его с помощью `Field`, `Field.Label`, `Field.HelperText` и `Field.ErrorText`, когда входные данные должны иметь общие декларативные метки, вспомогательный текст и сообщения проверки.

### Когда переходить к индивидуальному подходу

За пределами стилизованного корня текстовой области не существует пути композиции `Textarea` нижнего уровня. `Field.Textarea` по-прежнему доступен в виде аварийного люка в форме ковчега, но предпочтение отдается `Textarea`, поэтому многострочные элементы управления везде используют один и тот же контракт стиля moduix.

Используйте `Editable` вместо создания пользовательских элементов управления только для чтения/редактирования на основе `Textarea`.

### Реквизит по умолчанию

|Опора|По умолчанию|Примечания|
| ------------ | ------- | ------------------------------------------------ |
|`autoresize`|`false`|Ark Поведение автоматического изменения размера является добровольным для каждой текстовой области.|

### Поведенческие замечания

- Используйте `value` с собственным `onChange` для контролируемого текста. - Используйте `name` плюс обычную отправку формы, когда значение нужно только прочитать из `FormData`. - Реф указывает на настоящий `HTMLTextAreaElement`; используйте `asChild` только с одним хостом семантической текстовой области, который может получать объединенные реквизиты и ссылку. - Используйте Ark `autoresize`, когда поле должно расти вместе с содержимым. Ark отключает ручное изменение размера, пока оно включено, поэтому `--moduix-textarea-resize` применяется только тогда, когда `autoresize` имеет значение false. - Используйте `Editable` для встроенных потоков редактирования/только для чтения с предварительным просмотром текста, триггерами редактирования и элементами управления подтверждением или отменой.

### Крючки для стиля

Используйте корень текстовой области для самого визуального элемента управления и окружающий его `Field` для макета или текста вокруг него.

- Корень `Textarea` для рамки, фона, заполнителя, поведения изменения размера и кольца фокусировки. - Оболочка `Field` для ширины, максимальной ширины, интервала, макета метки, описания и текста проверки. - `data-slot="textarea-root"` для стабильного таргетинга в стилях с ограниченной областью. - `data-autoresize`, когда `autoresize` включен. - `data-invalid`, `[aria-invalid='true']`, `[disabled]`, `data-disabled`, `:read-only` и `data-readonly` для стилей с учетом состояния.
