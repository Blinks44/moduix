## Анатомия

```text
Tour
└─ Поддерево оверлея (по умолчанию портируется)
   ├─ Tour.Backdrop
   ├─ Tour.Spotlight
   └─ Tour.Positioner
      └─ Tour.Content
         ├─ Tour.Arrow
         ├─ Tour.CloseIcon / Tour.CloseTrigger
         ├─ Tour.Body
         │  ├─ Tour.Title
         │  ├─ Tour.Description
         │  └─ Tour.ProgressText
         └─ Tour.Control
            ├─ Tour.ActionList
            └─ Tour.Actions
               └─ Tour.ActionTrigger[action]
```

| Часть | Роль |
| --- | --- |
| `Tour` | Корневой компонент, связанный с объектом `UseTourReturn`. `Tour.Root` остаётся псевдонимом. |
| `Tour.Backdrop` / `Tour.Spotlight` | Необязательные оверлей и подсветка текущего целевого элемента. |
| `Tour.Positioner` / `Tour.Content` | Позиционируют и рендерят поверхность Ark `alertdialog`. |
| `Tour.Arrow` | По умолчанию рендерит moduix `ArrowTip` для шагов с tooltip. |
| `Tour.CloseIcon` | Доступный помощник закрытия только со значком; для пользовательской разметки используйте `CloseTrigger`. |
| `Tour.Body` | Прокручиваемая обёртка содержимого moduix для заголовка, описания и прогресса. |
| `Tour.Control` / `Tour.ActionList` | Рекомендуемая строка действий и прямое отображение действий текущего шага. |
| `Tour.Actions` / `Tour.ActionTrigger` | Запасной вариант с render props в стиле Ark для пользовательского интерфейса действий. |

## Композиция

`Tour` автоматически портирует `Backdrop`, `Spotlight` и `Positioner`. Устанавливайте `portalled={false}`, только если требуется встроенный оверлей, или передайте `portalRef` для пользовательского контейнера. Структурные части остаются явными и независимо стилизуемыми.

### Доступное содержимое

Рендерите `Tour.Title` для доступного имени диалога с предупреждением и `Tour.Description` для его описания. Ark управляет перемещением и возвратом фокуса, Escape, внешним взаимодействием и навигацией стрелками влево и вправо; оставляйте `keyboardNavigation` включённым, если шаг намеренно не использует эти клавиши. В RTL Ark меняет местами навигацию влево и вправо.

### Состояние и пользовательские действия

`useTour` управляет `steps`, `stepId`, `onStepChange`, `onStepsChange` и `onStatusChange`. Используйте экспортируемые moduix `useTourContext` или `Tour.Context` внутри дерева, когда пользовательскому интерфейсу нужны активный шаг или методы навигации. `Tour.ActionList` — краткий вариант по умолчанию; используйте `Tour.Actions`, только если сам интерфейс действий должен изменяться.

### Свойства по умолчанию

Содержимое портированного оверлея по умолчанию монтируется лениво и удаляется после анимации закрытия. Установите `unmountOnExit={false}`, чтобы сохранять его после первого открытия; устанавливайте оба свойства жизненного цикла в `false`, только когда нужен ранний первоначальный рендеринг.

| Свойство | По умолчанию | Примечания |
| --- | --- | --- |
| `closeOnEscape` | `true` | Escape закрывает тур. |
| `closeOnInteractOutside` | `true` | Внешнее взаимодействие закрывает тур, если не отключено. |
| `keyboardNavigation` | `true` | Стрелки влево и вправо переключают доступные шаги. |
| `preventInteraction` | `false` | Установите `true`, чтобы блокировать взаимодействие со страницей, пока тур открыт. |
| `spotlightOffset` | `{ x: 10, y: 10 }` | Расширяет область подсвеченного целевого элемента. |
| `spotlightRadius` | `4` | Задаёт радиус угла clip-path для подсветки. |
| `lazyMount` | `true` | Откладывает монтирование оверлея тура до его первого открытия. |
| `unmountOnExit` | `true` | Удаляет компонент после анимации закрытия. |

### Хуки стилизации

Используйте хуки moduix `data-slot`, такие как `tour-content`, `tour-body` и `tour-action-trigger`, для локальной стилизации. Ark предоставляет `data-scope="tour"`, `data-part`, `data-state`, `data-type`, `data-placement`, `data-side`, `data-step` и `data-disabled`; его переменные времени выполнения включают `--tour-layer`, `--tour-z-index`, `--available-width`, `--available-height`, `--transform-origin` и переменные стрелки. Передайте `className` в `Tour.ActionList`, чтобы стилизовать каждый сгенерированный триггер. При настройке reduced motion Tour сокращает анимации появления оверлея и отключает переходы кнопок действий.
