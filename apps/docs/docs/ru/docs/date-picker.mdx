## Выбор подходящего компонента

- Выберите **`Input`** для простых строковых дат без поведения календаря.
- Выберите **`DateInput`** для сегментированного ввода даты с приоритетом клавиатуры.
- Выберите **`DatePicker`**, когда пользователям нужны редактируемое поле ввода и всплывающий или встроенный календарь.

## Базовый пример

`DatePicker` сохраняет состояние даты и поведение календаря Ark, добавляя небольшие вспомогательные части для
обычного сценария. Используйте `DatePicker.Field` для действий с полем ввода и `DatePicker.DayTable` для
стандартной сетки дней.

## Композиция

### Рекомендуемая композиция

Используйте `DatePicker.Field` для стандартного поля одной даты, `DatePicker.RangeField` — для полей диапазона, а
`DatePicker.DayTable` — внутри представления дней. Корневой компонент автоматически переносит `Positioner` в портал.
Используйте `portalled={false}`, чтобы оставить всплывающее окно в текущем DOM-поддереве, или `portalRef` для собственного
контейнера. Задайте `inline`, когда календарь должен рендериться в обычном потоке документа; структурные части
всплывающего окна остаются явными и доступными для стилизации.

### Когда нужна собственная композиция

Используйте `DatePicker.Control`, `DatePicker.Input`, `DatePicker.Trigger`, `DatePicker.ClearTrigger` и низкоуровневые
части `Table*` напрямую, когда полю или сетке календаря нужна собственная структура. Используйте `DatePicker.Context`,
когда собственному рендерингу нужно состояние календаря: `weekDays`, `weeks`, `getMonthsGrid()`, `getYearsGrid()`,
`getOffset()` или вспомогательные действия.

### Свойства по умолчанию

По умолчанию содержимое оверлея в портале монтируется лениво и размонтируется после анимации выхода. Задайте
`unmountOnExit={false}`, чтобы сохранять его после первого открытия; отключайте оба свойства жизненного цикла только
когда нужен немедленный первоначальный рендеринг.

| Свойство                                 | По умолчанию       | Примечания                                        |
| ---------------------------------------- | ------------------ | ------------------------------------------------- |
| `DatePicker.Field.placeholder`           | шаблон локали Ark  | Переопределяет сгенерированную подсказку поля.     |
| `DatePicker.Field.clearLabel`            | перевод Ark        | Переопределяет подпись триггера очистки.          |
| `DatePicker.Field.triggerLabel`          | перевод Ark        | Переопределяет подпись триггера открытия.         |
| `DatePicker.RangeField.startPlaceholder` | шаблон локали Ark  | Переопределяет подсказку поля начала диапазона.    |
| `DatePicker.RangeField.endPlaceholder`   | шаблон локали Ark  | Переопределяет подсказку поля конца диапазона.     |
| `DatePicker.DayTable.showHeader`         | `true`             | Рендерит элементы назад/вид/вперёд перед таблицей. |
| `DatePicker.DayTable.showWeekNumbers`    | `false`            | Рендерит заголовок и ячейки с номерами недель.     |

### Особенности поведения

`value`, `defaultValue` и `onValueChange(details)` используют Ark `DateValue[]`. Импортируйте `DatePicker.Context`,
`useDatePicker` и `useDatePickerContext` из `moduix`; при необходимости импортируйте `parseDate` и типы даты Ark из
`@ark-ui/react/date-picker`. Стандартная ширина корневого компонента и всплывающего окна — `18.75rem` (300 px);
переопределите `--moduix-date-picker-width` или `--moduix-date-picker-content-width`, когда нужна более широкая композиция.
Поскольку содержимое окна находится в портале, задавайте переменные его размера на `DatePicker.Content` или другом
элементе внутри поддерева оверлея, а не только на `DatePicker`.

`open`, `defaultOpen` и `onOpenChange(details)` управляют состоянием всплывающего окна. `view`, `defaultView`,
`minView`, `maxView` и `onViewChange(details)` управляют активной панелью календаря. Если композиция рендерит только
одну панель, задайте этот вид одновременно в `minView` и `maxView`.

Внутри `Field` или `Fieldset` moduix компонент `DatePicker` наследует `disabled` и `invalid`; `Field` также передаёт
`readOnly` и `required`. Свойства, заданные непосредственно на `DatePicker`, имеют приоритет. `DatePicker.Field`
всегда использует индекс поля `0`; `DatePicker.RangeField` резервирует `0` и `1` для полей начала и конца. Для другой
структуры полей используйте `Control` и `Input` напрямую.

Используйте `selectionMode="single"`, `"range"` или `"multiple"`. `maxSelectedDates` применяется только к
множественному выбору. `numOfMonths`, `fixedWeeks` и `showWeekNumbers` изменяют таблицу календаря.

Для недоступных дат используйте `min`, `max` и `isDateUnavailable(date, locale)`. Для локализации используйте
`locale`, `timeZone`, `format`, `parse`, `translations` и `createCalendar`.

### Хуки стилизации

- `data-slot="date-picker-root"` на корневом компоненте.
- `data-slot="date-picker-root-provider"` на корневом компоненте провайдера.
- `data-slot="date-picker-label"` на подписи.
- `data-slot="date-picker-control"` на обёртке поля.
- `data-slot="date-picker-control"` на `DatePicker.Field` и `DatePicker.RangeField`, поскольку оба рендерят `DatePicker.Control`.
- `data-slot="date-picker-input"` на редактируемом поле.
- `data-slot="date-picker-trigger"` и `date-picker-clear-trigger` на действиях поля.
- `data-slot="date-picker-value-text"` на сводках выбранного значения.
- `data-slot="date-picker-positioner"` и `date-picker-content` на плавающем слое.
- `data-slot="date-picker-view"`, `view-control`, `view-trigger`, `prev-trigger` и `next-trigger` на навигации календаря.
- `data-slot="date-picker-table*"` на частях таблицы и `date-picker-table-cell-trigger` на ячейках.
- `data-slot="date-picker-week-number-*"` на ячейках номера недели.
- `data-slot="date-picker-month-select"` и `date-picker-year-select` на нативных элементах выбора.
- `data-slot="date-picker-preset-trigger"` на кнопках предустановленных диапазонов.

Атрибуты состояния Ark включают `data-state`, `data-disabled`, `data-readonly`, `data-invalid`,
`data-focus`, `data-selected`, `data-today`, `data-unavailable`, `data-outside-range`,
`data-in-range`, `data-range-start`, `data-range-end`, `data-in-hover-range`,
`data-hover-range-start`, `data-hover-range-end` и `data-view`.
