## Выбор подходящего компонента

Используйте `Toggle`, если элемент управления остаётся кнопкой, которая показывает нажатое состояние.

- Выберите **`Toggle`** для избранного, сохранённых состояний, действий форматирования и компактных действий панели инструментов.
- Выберите **`Switch`** для элементов вкл./выкл. в настройках, которые выглядят как строка предпочтения.
- Выберите **`Checkbox`** для отправляемого выбора в списке или форме.
- Выберите **`ToggleGroup`**, если несколько переключателей должны использовать одну модель выбора.

## Анатомия

```text
Toggle / Toggle.Root
└─ Toggle.Indicator (необязательно)
```

| Часть                     | Назначение                                                                |
| ------------------------- | ------------------------------------------------------------------------- |
| `Toggle` / `Toggle.Root`  | Корневая кнопка с двумя состояниями, управляющая состояниями нажатия, фокуса, отключения и `asChild`. |
| `Toggle.Indicator`        | Отрисовывает содержимое для нажатого состояния и необязательное `fallback`, когда переключатель выключен. |

## Композиция

### Рекомендуемая композиция

Используйте `Toggle` как стандартный корневой компонент. Он передаёт ref части кнопки Ark и поддерживает
`pressed`, `defaultPressed`, `onPressedChange(pressed)`, `disabled`, `asChild` и обычные атрибуты кнопки.

`Toggle.Indicator` необязателен. Используйте его, если видимая иконка или подпись должна меняться в зависимости от
нажатого состояния переключателя.

### Когда нужна собственная композиция

Используйте `asChild`, когда другой семантической кнопке нужно владеть отрисовываемым элементом. Оставляйте дочерний
элемент единственным кнопкоподобным элементом, чтобы Ark мог объединить с ним обязательные свойства и поведение.

Для пользовательского потомка, считывающего состояние, используйте `Toggle.Context` или `useToggleContext()` из
`@moduix/react/toggle`. Оба получают состояние ближайшего переключателя без прямого импорта Ark.

Вместо ручной координации нескольких отдельных переключателей используйте `ToggleGroup`, когда несколько нажатых
кнопок относятся к одному общему набору выбора.

### Свойства по умолчанию

| Свойство  | По умолчанию | Примечания                                                              |
| --------- | ------------ | ----------------------------------------------------------------------- |
| `variant` | `default`    | Визуальный вариант moduix: вторичный `default`, обведённый `outline` или прозрачный `ghost`. |
| `size`    | `md`         | Интервалы moduix или геометрия только для иконки.                      |

### Особенности поведения

- Переключателям только с иконкой нужно доступное имя, например `aria-label="Favorite"`.
- `disabled` сохраняет текущее визуальное состояние, но предотвращает взаимодействие.
- Ark записывает `data-state="on" | "off"`, `data-pressed` и `data-disabled` для стилизации.
- Ark Toggle не предоставляет `RootProvider` или скрытое поле формы.
- `Toggle.Context` и `useToggleContext()` доступны из `@moduix/react/toggle`.
- Устаревшие `render` и `nativeButton` не входят в API на базе Ark; используйте `asChild`.

## Стилизация

`Toggle` предоставляет стилизованный корневой элемент, необязательную часть индикатора и полный набор токенов
`--moduix-toggle-*` для вариантов, размеров, кольца фокуса, интервалов и размера иконок.

### Хуки стилизации

- `data-slot="toggle-root"` — стабильный селектор корневого элемента.
- `data-slot="toggle-indicator"` — стабильный селектор на `Toggle.Indicator`.
- `data-scope="toggle"` и `data-part="root" | "indicator"` предоставляются Ark UI.
- `data-state="on" | "off"` отражает нажатое состояние корневого элемента и индикатора.
- `data-pressed` присутствует, когда переключатель нажат.
- `data-variant` отражает визуальный вариант moduix.
- `data-size` отражает размер moduix, включая `icon-sm`, `icon-md` и `icon-lg`.
- `data-disabled` управляет отключёнными стилями; Ark также сохраняет нативный атрибут `disabled`.
- Прямые дочерние иконки и иконки внутри `Toggle.Indicator` получают размер через
  `--moduix-toggle-icon-size`.
