## Выбор подходящего компонента

Используйте `Switch` для немедленных настроек «вкл./выкл.», когда изменение элемента управления должно
переключать одно булево состояние.

- Выбирайте **`Switch`** для таких настроек, как уведомления, напоминания или флаги функций.
- Выбирайте **`Checkbox`**, когда элемент управления ведёт себя как отправляемый выбор, а не как немедленное переключение настройки.
- Выбирайте **`RadioGroup`**, когда пользователь должен выбрать один вариант из нескольких взаимоисключающих значений.

## Анатомия

```text
Switch
├─ Switch.Control
│  └─ Switch.Thumb
├─ Switch.Label
└─ native input (automatic)
```

| Часть                 | Назначение                                                              |
| --------------------- | ----------------------------------------------------------------------- |
| `Switch`              | Корневой элемент `label`. Управляет состоянием выбора, ID, свойствами формы и `size`. |
| `Switch.Control`      | Визуальная дорожка и цель для кольца фокуса. Автоматически отрисовывает `Switch.Thumb`. |
| `Switch.Thumb`        | Подвижный ползунок для стандартного вида или пользовательского содержимого. |
| `Switch.Label`        | Текст метки Ark, связанный с переключателем.                            |
| `Switch.RootProvider` | Корневая метка, управляемая внешним экземпляром состояния Ark `useSwitch()`. |

`Switch.Context`, `useSwitchContext` и `useSwitch` экспортируются из `@moduix/react` вместе с компонентом.

## Композиция

### Рекомендуемая композиция

Сохраняйте видимое дерево частей Ark явным: используйте `Switch.Control` и `Switch.Label`. `Switch` автоматически
отрисовывает нативное поле формы.

`Switch.Control` отрисовывает стандартный `Switch.Thumb`, когда дочерние элементы не переданы. Напрямую
компонуйте `Switch.Thumb`, когда ползунку нужны пользовательское содержимое или стилизация.

### Когда нужна собственная композиция

Используйте `asChild`, только когда корень должен отрисовывать пользовательский host-элемент. Ark отрисовывает
корень как `label`; непосредственный элемент `asChild` должен быть совместим с `label`, чтобы переключатель
сохранил корректное доступное имя.

Используйте `Switch.Context`, `useSwitchContext` или `useSwitch` из `@moduix/react`, когда окружающему интерфейсу
нужно читать состояние переключателя Ark или владеть им.

### Свойства по умолчанию

| Свойство    | По умолчанию | Примечания                                           |
| ----------- | ------------ | ---------------------------------------------------- |
| `size`      | `md`         | Дополнение moduix: `xs`, `sm`, `md`, `lg`, `xl`.     |
| `value`     | `on`         | Значение скрытого поля Ark для отправки формы.       |
| `children`  | `undefined`  | Явно компонуйте части Ark.                           |
| `className` | `undefined`  | Применяется к корневой метке Ark.                    |

### Особенности поведения

- Для неуправляемого режима используйте `defaultChecked`, а для управляемого — `checked` с `onCheckedChange(details)`.
- `details.checked` — следующее булево состояние. Старый колбэк с необработанным булевым значением удалён.
- Корень отрисовывает нативное поле формы, когда переключатель участвует в нативных формах или сбросе формы.
- Для расширенного чтения состояния используйте `Switch.Context`, `useSwitchContext` или `useSwitch` из `@moduix/react`, а не адаптеры колбэков уровня обёртки.
- Используйте `asChild` для пользовательского корневого host-элемента. Дочерний элемент должен оставаться единственным семантическим элементом, совместимым с `label`.

## Стилизация

Стилизуйте `Switch` с помощью `className`, публичных хуков `data-slot`, атрибутов состояния Ark и публичных
CSS-переменных `--moduix-switch-*`, показанных ниже.

### Хуки стилизации

- `Switch` и `Switch.RootProvider` предоставляют `data-slot="switch-root"` / `data-slot="switch-root-provider"` и записывают `data-size` moduix.
- `Switch.Control` предоставляет `data-slot="switch-control"` и получает атрибуты состояния Ark, включая `data-state`, `data-focus-visible`, `data-hover`, `data-disabled`, `data-readonly`, `data-invalid` и `data-required`.
- `Switch.Thumb` предоставляет `data-slot="switch-thumb"` и получает те же атрибуты состояния Ark для движения ползунка и стилизации пользовательского содержимого.
- `Switch.Label` предоставляет `data-slot="switch-label"` для переопределения типографики.
- Нативное поле формы предоставляет `data-slot="switch-hidden-input"` для инспекционных хуков, но должно оставаться визуально скрытым средствами Ark.
