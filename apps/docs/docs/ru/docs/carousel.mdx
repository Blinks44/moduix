## Анатомия

```text
Carousel / Carousel.Root
├─ Carousel.ItemGroup
│  └─ Carousel.Item[index]
├─ Carousel.Control
│  ├─ Carousel.PrevTrigger
│  └─ Carousel.NextTrigger
├─ Carousel.Indicators
│  └─ Carousel.IndicatorGroup
│     └─ Carousel.Indicator[index]
└─ Carousel.ProgressText
```

| Часть                        | Назначение                                                      |
| ---------------------------- | -------------------------------------------------------------- |
| `Carousel` / `Carousel.Root` | Управляет состоянием карусели, навигацией и коллекцией элементов. |
| `Carousel.Control`           | Обёртка для компоновки триггеров навигации и сопутствующих элементов управления. |
| `Carousel.ItemGroup`         | Дорожка слайдов, содержащая части `Carousel.Item`.              |
| `Carousel.Item`              | Отдельный слайд со стабильным `index`.                          |
| `Carousel.PrevTrigger`       | Триггер перехода на предыдущую страницу.                       |
| `Carousel.NextTrigger`       | Триггер перехода на следующую страницу.                        |
| `Carousel.Indicators`        | Удобная обёртка moduix для стандартных индикаторов страниц.     |
| `Carousel.IndicatorGroup`    | Групповая обёртка индикаторов страниц.                          |
| `Carousel.Indicator`         | Триггер индикатора для заданного индекса слайда или страницы.   |
| `Carousel.ProgressText`      | Текст с текущей страницей и общим количеством страниц.          |

Для расширенных сценариев также доступны:

- `Carousel.Context`
- `Carousel.AutoplayTrigger`
- `Carousel.AutoplayIndicator`
- `Carousel.RootProvider`

`useCarousel` и `useCarouselContext` доступны из `@moduix/react`.

## Композиция

### Рекомендуемая композиция

Используйте `Carousel` как корневой компонент, рендерите `Carousel.ItemGroup` как дорожку, размещайте элементы
навигации в `Carousel.Control` и добавляйте `Carousel.Indicators`, когда достаточно стандартного точечного индикатора.

Обычно `Carousel.Control` — соседняя с `Carousel.ItemGroup` панель инструментов.

`Carousel.Root` остаётся явным алиасом `Carousel`, когда в коде нужно показать пространство имён.

### Когда нужна собственная композиция

Используйте `Carousel.Context` вместе с `Carousel.IndicatorGroup` и `Carousel.Indicator`, когда нужны собственная
компоновка пагинатора, индикаторы-миниатюры или более точное управление `pageSnapPoints`.

Используйте `Carousel.RootProvider` из moduix вместе с `useCarousel()`, когда состояние карусели должно создаваться
вне отрендеренного поддерева.

Используйте `useCarouselContext()` внутри пользовательских дочерних компонентов, которым нужен API карусели без
render prop.

Используйте `Carousel.AutoplayTrigger` и `Carousel.AutoplayIndicator`, когда элементы управления автопрокруткой
должны быть видимой частью интерфейса, а не только свойством корневого компонента.

### Свойства по умолчанию

| Свойство     | По умолчанию | Примечания                            |
| ------------ | ------- | ----------------------------------------- |
| `slideCount` | —       | Обязательно для `Carousel` / `Carousel.Root`. |

### Особенности поведения

- `onPageChange(details)` сохраняет форму Ark и предоставляет активную страницу как `details.page`.
- Задайте `Carousel` или `Carousel.RootProvider` атрибут `aria-label` либо `aria-labelledby`, чтобы landmark карусели
  имел доступное имя.
- `spacing`, `padding`, `slidesPerPage`, `slidesPerMove` и `autoSize` напрямую следуют правилам размеров и точек
  привязки Ark.
- Вертикальная карусель использует тот же публичный API. Стандартные триггеры автоматически поворачиваются, если
  компонент использует шевроны moduix.
- Стандартные горизонтальные триггеры автоматически отражаются при `dir="rtl"`.
- `Carousel.ProgressText` сохраняет читаемый порядок чисел «текущий / всего» в RTL-каруселях.
- `--moduix-carousel-indicator-size` управляет компактной кнопкой индикатора, поэтому focus ring
  повторяет геометрию точки или активной капсулы.
- При `prefers-reduced-motion: reduce` дорожка прокручивается без плавной анимации, а переходы элементов управления
  и индикаторов moduix отключаются.

## Стилизация

Используйте `className` на экспортируемых частях для структурных изменений стилей. Для стилизации состояния отдавайте
предпочтение data-атрибутам Ark (`data-part`, `data-orientation`, `data-current`, `data-dragging`) и хукам
`data-slot` из moduix.

### CSS-свойства

### Хуки стилизации

- `data-slot="carousel-root"`, `carousel-control`, `carousel-item-group`, `carousel-item`,
  `carousel-prev-trigger`, `carousel-next-trigger`, `carousel-indicator-group`,
  `carousel-indicator`, `carousel-autoplay-trigger`, `carousel-autoplay-indicator` и
  `carousel-progress-text` — стабильные селекторы экспортируемых частей.
- Ark также предоставляет имена `data-scope="carousel"` и `data-part` на отрендеренных узлах.
- `data-orientation="horizontal" | "vertical"` доступен на корневом компоненте и структурных частях.
- `Carousel.ItemGroup` предоставляет `data-dragging` во время перетаскивания.
- `Carousel.Indicator` предоставляет `data-current`, а `Carousel.Item` — `data-index` и
  `data-inview`.
- `Carousel.Indicator` предоставляет `data-readonly`, а `Carousel.AutoplayTrigger` —
  `data-pressed`.
