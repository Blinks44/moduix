## Выбор подходящего компонента

Используйте `AngleSlider`, когда пользователи должны напрямую изменять направление или поворот на круговом регуляторе.

- Выберите **`AngleSlider`** для поворота, курса, направления прожектора и других угловых значений.
- Выберите **`Slider`**, если значение лучше воспринимается на линейной шкале.
- Выберите **`NumberInput`**, если точный ввод градусов важнее прямого взаимодействия.

## Анатомия

```text
AngleSlider.Root
├─ AngleSlider.Label
├─ AngleSlider.Control
│  ├─ AngleSlider.MarkerGroup
│  │  └─ AngleSlider.Marker[value]
│  └─ AngleSlider.Thumb
└─ AngleSlider.ValueText
```

| Часть                              | Назначение                                                              |
| ---------------------------------- | ----------------------------------------------------------------------- |
| `AngleSlider` / `AngleSlider.Root` | Хранит неуправляемое или управляемое состояние слайдера.                |
| `AngleSlider.RootProvider`         | Подключает внешнее состояние Ark.                                       |
| `AngleSlider.Label`                | Связывает видимую метку с бегунком слайдера.                            |
| `AngleSlider.Control`              | Круглая поверхность для взаимодействия указателем.                      |
| `AngleSlider.Dial`                 | Удобная обёртка, отрисовывающая `Control` и `Thumb`.                    |
| `AngleSlider.MarkerGroup`          | Содержит необязательные опорные метки.                                  |
| `AngleSlider.Marker`               | Размещает числовую метку и предоставляет её связь с текущим значением.  |
| `AngleSlider.Marks`                | Удобная обёртка, отрисовывающая элементы `MarkerGroup` и `Marker`.      |
| `AngleSlider.Thumb`                | Фокусируемый бегунок слайдера и поворачивающийся индикатор угла.        |
| `AngleSlider.ValueText`            | Отрисовывает текущее значение как текст в градусах.                     |

## Композиция

### Рекомендуемая композиция

Начните с `Dial`, затем добавляйте только части, соответствующие задаче:

- добавьте `Label` или сохраните `aria-label` для доступного имени
- добавьте `Marks`, если пользователям нужны опорные точки вокруг регулятора
- добавьте `ValueText`, если числовое значение угла должно оставаться видимым
- задайте `name`, если угол должен участвовать в отправке нативной формы

### Когда нужна собственная композиция

Используйте явные части `Control`, `Thumb`, `MarkerGroup` и `Marker`, когда регулятору требуются пользовательские
дочерние элементы, свойства для каждой метки или нестандартный порядок. Используйте `useAngleSlider()` из `@moduix/react`
вместе с `AngleSlider.RootProvider`, если состояние нужно контролировать вне отрисовываемого поддерева слайдера.
Для чтения контекста используйте `AngleSlider.Context` и `useAngleSliderContext()` из moduix. Не отрисовывайте
`Root` и `RootProvider` для одного экземпляра состояния.

DOM-части Ark поддерживают `asChild`; передавайте один совместимый дочерний элемент, способный сохранить их поведение
клавиатуры, фокуса, ARIA и указателя. `Dial` и `Marks` сохраняют фиксированную композицию из нескольких частей, поэтому
не принимают `asChild`. С `Root` или `RootProvider` используйте контейнер, который может содержать внутренне
отрисованное скрытое поле ввода и части слайдера. Используйте `ids` на `Root`, если составным элементам нужны стабильные общие
идентификаторы. Ref перенаправляются к DOM-элементу, отрисованному каждой обёрнутой частью Ark.

### Свойства по умолчанию

| Свойство       | По умолчанию | Примечания                                      |
| -------------- | ------------ | ----------------------------------------------- |
| `defaultValue` | `0`          | Начальный угол в неуправляемом режиме           |
| `step`         | `1`          | Приращение значения для клавиатуры и указателя  |
| `disabled`     | `false`      | Запрещает фокус и взаимодействие                |
| `readOnly`     | `false`      | Оставляет значение видимым, но недоступным для изменения |
| `invalid`      | `false`      | Открывает недопустимое состояние для ARIA и стилизации |

### Особенности поведения

- `value` — одно число; `onValueChange(details)` и `onValueChangeEnd(details)` сохраняют объекты
  колбэков Ark с `details.value` и `details.valueAsDegree`.
- Бегунок поддерживает клавиатурное поведение слайдера Ark и перетаскивание указателем вокруг круглого элемента управления.
- `AngleSlider.Marks` отрисовывает тот же DOM меток и хуки стилизации, что и явная композиция `MarkerGroup` /
  `Marker`.
- `Root` и `RootProvider` автоматически отрисовывают нативное поле формы. Задайте `name` для
  отправки формы; синхронизация сброса остаётся активной без добавления другой части компонента.
- `ValueText` отрисовывает строку с градусами Ark, если не переданы пользовательские дочерние элементы.
- Для стилизации по-прежнему доступны `data-disabled`, `data-invalid`, `data-readonly`, `data-state` метки, `--value`, `--angle`,
  `--marker-value` и `--marker-display-value`.

## Стилизация

Стилизуйте компонент через `className`, стабильные хуки `data-slot="angle-slider-*"`, атрибуты Ark
`data-scope="angle-slider"` / `data-part`, атрибуты состояния и публичные CSS-переменные ниже.

### CSS-свойства

<CssPropertiesSection properties={AngleSliderDocs.angleSliderCssProperties} />

### Хуки стилизации

- `data-slot="angle-slider-root"` и `data-slot="angle-slider-root-provider"` управляют общей раскладкой.
- `data-slot="angle-slider-control"` управляет регулятором и получает `data-disabled`, `data-invalid`
  и `data-readonly`.
- `data-slot="angle-slider-thumb"` управляет фокусируемым поворачивающимся индикатором и может выбираться через
  `:focus-visible`.
- `data-slot="angle-slider-marker"` предоставляет `data-value` и
  `data-state="under-value | at-value | over-value"`.
- `AngleSlider.Marks` отрисовывает те же хуки `data-slot="angle-slider-marker-group"` и
  `data-slot="angle-slider-marker"`, что и явные части меток.
- Сохраняются корневые переменные Ark `--value` и `--angle`, а также переменные меток `--marker-value` и
  `--marker-display-value`.
