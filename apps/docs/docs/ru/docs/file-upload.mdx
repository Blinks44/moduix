## Анатомия

```text
FileUpload / FileUpload.Root
├─ FileUpload.Label
├─ FileUpload.Dropzone
│  ├─ FileUpload.DropzoneIcon
│  └─ FileUpload.Trigger
├─ FileUpload.ItemGroup[type]
│  ├─ FileUpload.Items
│  └─ FileUpload.Context
│     └─ FileUpload.Item[file]
│        ├─ FileUpload.ItemPreview[type]
│        │  ├─ FileUpload.ItemPreviewImage
│        │  └─ FileUpload.ItemPreviewIcon
│        ├─ FileUpload.ItemName
│        ├─ FileUpload.ItemMetadata[file]
│        ├─ FileUpload.ItemSizeText
│        └─ FileUpload.ItemDeleteTrigger
├─ FileUpload.ClearTrigger
└─ native input (automatic)
```

| Часть                            | Назначение                                                               |
| -------------------------------- | ------------------------------------------------------------------------ |
| `FileUpload` / `FileUpload.Root` | Управляет состоянием файлов, валидацией, перетаскиванием, вставкой и интеграцией с формой. |
| `FileUpload.RootProvider`        | Отрисовывает дерево загрузки файлов из состояния, возвращённого Ark `useFileUpload`. |
| `FileUpload.Label`               | Доступная метка для скрытого input и элементов управления загрузкой.     |
| `FileUpload.Dropzone`            | Цель для перетаскивания. Используйте `disableClick` с вложенным trigger. |
| `FileUpload.DropzoneIcon`        | Декоративный помощник с иконкой загрузки для поверхностей dropzone.      |
| `FileUpload.Trigger`             | Кнопка, открывающая нативный выборщик файлов.                            |
| `FileUpload.ItemGroup`           | Обёртка списка для принятых или отклонённых файлов.                      |
| `FileUpload.Items`               | Карточки изображений или строки файлов с превью, метаданными и удалением. |
| `FileUpload.Context`             | Совместимый с Ark контекст render prop для пользовательских строк файлов. |
| `FileUpload.Item`                | Строка файла. Передайте текущий объект `file`.                           |
| `FileUpload.ItemPreview`         | Условный слот превью, сопоставляемый по MIME-типу.                       |
| `FileUpload.ItemPreviewImage`    | Превью изображения внутри `ItemPreview`.                                |
| `FileUpload.ItemPreviewIcon`     | Универсальная иконка файла для fallback в `ItemPreview`.                 |
| `FileUpload.ItemName`            | Текст имени файла.                                                       |
| `FileUpload.ItemMetadata`        | Тип файла и локализованный размер; передайте текущий `file`.             |
| `FileUpload.ItemSizeText`        | Локализованный текст размера файла.                                      |
| `FileUpload.ItemDeleteTrigger`   | Удаляет один файл. По умолчанию использует иконку корзины moduix.        |
| `FileUpload.ClearTrigger`        | Очищает выбранные файлы. По умолчанию использует иконку закрытия moduix. |

## Композиция

### Рекомендуемая композиция

Сохраняйте дерево частей Ark видимым. Используйте `Trigger` для компактных элементов управления загрузкой и `Dropzone`
для поверхностей перетаскивания. Если `Trigger` вложен в `Dropzone`, передайте `disableClick` в `Dropzone`,
чтобы нативный выборщик файлов не открывался дважды.

Корень всегда отрисовывает нативный input формы. Используйте `Items` для компактных строк принятых файлов. Читайте
принятые файлы из `FileUpload.Context.acceptedFiles`, а отклонённые — из `FileUpload.Context.rejectedFiles`,
когда нужны пользовательские строки.

Импортируйте `FileUpload.Context`, `useFileUpload()` и `useFileUploadContext()` из `@moduix/react`, когда нужен расширенный
доступ к состоянию. Это прямые реэкспорты Ark, поэтому объекты колбэков и контракты состояния остаются неизменными.

### Когда нужна собственная композиция

`Items` отрисовывает файлы изображений как компактные вертикальные карточки, а остальные файлы — как горизонтальные строки
метаданных. Используйте явную композицию `Context` для пользовательских строк. `ItemPreview.type` — предикат с регулярным
выражением, а не список приоритетов: отрисовывайте ровно одно превью для текущего файла. Например, используйте
`file.type.startsWith("image/")`, чтобы выбрать `ItemPreviewImage`; иначе отрисуйте `ItemPreviewIcon`, затем скомпонуйте
`ItemName`, `ItemMetadata file={file}` и `ItemDeleteTrigger`. Используйте `asChild`, только когда дочерний элемент —
единственный семантический элемент, способный сохранить требуемое поведение кнопки, метки или input.

### Свойства по умолчанию

| Свойство              | По умолчанию | Примечания                                                        |
| --------------------- | ------------ | ----------------------------------------------------------------- |
| `allowDrop`           | `true`       | Включает перетаскивание в `Dropzone`.                            |
| `maxFiles`            | `1`          | Увеличьте или удалите для загрузки нескольких файлов и каталогов. |
| `minFileSize`         | `0`          | Минимальный размер принимаемого файла в байтах.                   |
| `maxFileSize`         | `∞`          | Максимальный размер принимаемого файла в байтах.                  |
| `preventDocumentDrop` | `true`       | Предотвращает случайную навигацию при сбросе вне цели.            |
| `locale`              | `en-US`      | Используется для форматирования размера файла.                    |

### Особенности поведения

`acceptedFiles`, `defaultAcceptedFiles` и `onFileChange(details)` сохраняют управляемое и неуправляемое состояние Ark.
`onFileAccept(details)` и `onFileReject(details)` сохраняют объекты деталей Ark. `Field.Root` и `Fieldset.Root` могут
предоставлять состояния disabled, invalid, required и read-only. Используйте `ids`, когда отдельным меткам или описаниям
нужны стабильные ссылки доступности.

### Хуки стилизации

Используйте стабильные слоты moduix, такие как `[data-slot="file-upload-dropzone"]`,
`[data-slot="file-upload-item"]` и `[data-slot="file-upload-item-delete-trigger"]`.
Ark также предоставляет `data-scope="file-upload"`, `data-part` для конкретной части и атрибуты состояния:
`data-disabled`, `data-readonly`, `data-invalid`, `data-required`, `data-dragging` и `data-type`.
