## Справочник API

Ark UI не предоставляет отдельный примитив `button`. Moduix строит этот компонент с помощью официального
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[ref](https://ark-ui.com/docs/guides/ref).

## Анатомия

`Button` — односоставной компонент.

```text
Button.Root
└─ root[data-scope="button"][data-part="root"][data-slot="button-root"]
   └─ children
```

| Часть                    | Роль                                                   |
| ------------------------ | ------------------------------------------------------ |
| `Button` / `Button.Root` | Корневая интерактивная поверхность со стилизацией moduix. |
| `Button`                 | Вызываемый псевдоним `Button.Root`.                    |

## Композиция

### Рекомендуемая композиция

Для действий используйте нативный корневой элемент. Его значение по умолчанию — `type="button"`, чтобы избежать случайной отправки формы; для отправки формы явно задайте `type="submit"`.

### Свойства по умолчанию

| Свойство  | По умолчанию | Значения                                                                             |
| --------- | ------------ | ------------------------------------------------------------------------------------ |
| `loading` | `false`      | `boolean`                                                                            |
| `variant` | `default`    | `default`, `outline`, `secondary`, `destructive`, `destructive-outline`, `ghost`, `link` |
| `size`    | `md`         | `xs`, `sm`, `md`, `lg`, `xl`, `icon-sm`, `icon-md`, `icon-lg`                       |
| `type`    | `button`     | Только нативные корневые элементы                                                    |

### Когда нужна собственная композиция

Используйте `asChild`, когда DOM-узлом должен владеть один семантический дочерний элемент. Композиция Ark требует ровно одного дочернего элемента. Значение `type="button"` по умолчанию не добавляется к цели `asChild`.

Когда `Dialog.Trigger`, `Menu.Trigger` или другая часть Ark компонует Button как дочерний элемент, `data-scope` и `data-part` родительской части имеют приоритет на общем DOM-узле. Button сохраняет классы рецепта и стабильный `data-slot`, а Ark продолжает объединять обработчики триггера и ref.

Для навигации используйте настоящую ссылку. На хосте `asChild` свойства `disabled`, `loading` и `aria-disabled="true"` добавляют `aria-disabled`, применяют состояние оформления disabled и предотвращают активацию по клику. Они не добавляют нативный атрибут `disabled` к пользовательскому хосту.

### Особенности поведения

- Нативные атрибуты, `className` и `style` передаются без преобразования колбэков. Клики по отключённым корневым элементам предотвращаются.
- Переданный ref указывает на отрисованный корневой элемент.
- Нативные `disabled`, `aria-disabled="true"` и `loading` добавляют `data-disabled`.
- `loading` — узкий sugar: он задаёт `data-loading`, `aria-busy` и путь оформления disabled, в то время как спиннер и метка остаются полностью компонуемыми.
- Необязательные хуки `data-icon="inline-start|inline-end"` можно применить к дочерним значкам или спиннерам, когда потребителю нужны явные хуки стилизации встроенных значков.
- Прямые дочерние элементы `svg` наследуют `currentColor` и используют `--moduix-button-icon-size`.
- Кнопкам только со значком требуется доступное имя.
- Свойства Chakra `colorPalette`, адаптивные свойства рецепта, `ButtonGroup` и управляемые свойства загрузки намеренно не входят в этот контракт moduix с одним корневым элементом.

### Хуки стилизации

- `data-slot="button-root"` — стабильный селектор moduix.
- Отдельные корневые элементы по умолчанию используют `data-scope="button"` и `data-part="root"`. Компонуемый родитель Ark может заменить их собственными значениями анатомии.
- `data-variant` и `data-size` отражают активный визуальный рецепт.
- `data-disabled` присутствует для нативных `disabled`, `aria-disabled="true"` и `loading`.
- `data-loading` присутствует, когда `loading={true}`.
- Дочерние значки и спиннеры могут использовать `data-icon="inline-start"` или `data-icon="inline-end"` для явного нацеливания встроенных значков.
- `[data-disabled]` отвечает за оформление disabled для нативных `disabled`, `aria-disabled="true"` и `loading`.
- Варианты активных кнопок используют едва заметное смещение при нажатии; у `link` остаётся только обратная связь через непрозрачность, а при предпочтении уменьшенного движения смещение не применяется.
