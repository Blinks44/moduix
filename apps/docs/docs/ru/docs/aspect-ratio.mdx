## Справочник API

Ark UI не предоставляет отдельный примитив `aspect-ratio`. Moduix строит этот компонент с помощью официальной
[фабрики Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[ref](https://ark-ui.com/docs/guides/ref).

## Базовый пример

Начните с `AspectRatio`, задайте ширину или максимальную ширину на самом корневом элементе и передайте конечное положительное
числовое значение `ratio`. Прямые дочерние элементы `img`, `video`, `iframe`, `canvas` и `svg`
автоматически заполняют кадр. Задайте `object-fit` для изображений и видео, если требуется обрезка или вписывание.

## Композиция

### Рекомендуемая композиция

Используйте `AspectRatio` для большинства медиаконтейнеров. Задавайте размеры, радиус и классы раскладки на самом корневом элементе;
`AspectRatio.Root` — тот же корень, предоставленный для единообразия пространства имён.

- `ratio` обязателен и является числом; для корректного CSS-поведения передавайте конечное значение больше нуля
- `asChild` использует композицию фабрики Ark и требует ровно один элемент React
- прямые дочерние элементы `img`, `video`, `iframe`, `canvas` и `svg` автоматически заполняют кадр; задайте
  `object-fit` для изображений и видео, чтобы выбрать обрезку или вписывание
- `className` напрямую стилизует и задаёт размер корневого элемента
- `--moduix-aspect-ratio-radius` управляет радиусом скругления кадра по умолчанию

### Когда нужна собственная композиция

Оберните `AspectRatio`, если тени, кольца фокуса или декоративные элементы раскладки должны выходить за пределы обрезанного
кадра. Сохраняйте обрезку на самом корневом элементе и переопределяйте корневой `aspect-ratio` в собственном CSS,
если на определённом брейкпоинте требуется другой кадр.

### Свойства по умолчанию

| Элемент                         | По умолчанию              | Значения / примечания                   |
| ------------------------------- | ------------------------- | ---------------------------------------- |
| `ratio`                         | -                         | Обязательное положительное конечное `number` |
| `className`                     | `undefined`               | Стилизует и задаёт размер корневого элемента |
| `style`                         | `undefined`               | Может напрямую переопределить `aspect-ratio` |
| `asChild`                       | `undefined`               | Композиция фабрики Ark                   |
| `--moduix-aspect-ratio-radius`  | `var(--moduix-radius-md)` | Значение длины CSS или токен             |

### Особенности поведения

- Корневой элемент отрисовывается с `data-scope="aspect-ratio"`, `data-part="root"` и
  `data-slot="aspect-ratio-root"`.
- Корневой элемент имеет блочное отображение и использует `border-box`, в том числе когда `asChild` меняет
  хост-элемент.
- `position: relative` на корневом элементе задан намеренно и поддерживает паттерны дочерних элементов с абсолютным заполнением,
  например Next.js `Image fill`.
- Прямые дочерние `iframe` заполняют кадр без браузерной рамки по умолчанию.
- Предыдущие строковые предустановки (`square`, `video`, `portrait`, `photo`) были удалены при миграции на Ark.
  Используйте числа: `1`, `16 / 9`, `9 / 16` и `4 / 3`.

### Хуки стилизации

- `data-scope="aspect-ratio"` и `data-part="root"` — хуки корневого элемента, согласованные с Ark.
- `data-slot="aspect-ratio-root"` — стабильный хук корневого элемента moduix.
- Задавайте ширину, максимальную ширину и стили раскладки на самом корневом элементе. Переопределяйте `aspect-ratio` в собственном
  CSS, если на определённом брейкпоинте требуется другое соотношение сторон.
- Прямой медиаконтент использует `border-box`; изображения и видео сохраняют собственное значение `object-fit`, чтобы
  потребитель мог выбрать обрезку или вписывание.
- `overflow: hidden` задан намеренно. Если видимый декоративный элемент должен выходить за пределы кадра, поместите
  его на внешнюю обёртку, а не убирайте обрезку корневого элемента.
