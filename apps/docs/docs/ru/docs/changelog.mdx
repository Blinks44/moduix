## v2.2.3 — 24 июля 2026 г.

- Исправлена совместимость с Next.js App Router для компонентов с исходным кодом в проекте, использующих локальные client API.
- Исправлена стрелка Menu: теперь она остаётся видимой и аккуратно соединяется с рамкой всплывающего окна.

Эти исправления затрагивают как исходный код, установленный из реестра, так и пользователей пакета. Если вы владеете
скопированными файлами, перед применением просмотрите обновление командой `npx shadcn@latest add <item> --diff`.

## v2.2.2 — 24 июля 2026 г.

- Реорганизованы исходный код пакета и пути зависимостей, чтобы вывод CLI shadcn оставался самодостаточным.
- Публичный API компонентов не изменился.

## v2.2.1 — 23 июля 2026 г.

- Для Drawer добавлен вариант содержимого `island` — для отделённых от края экранов выдвижных панелей.
- Фон Drawer остаётся видимым при перетаскивании между точками привязки.
- Добавлена неисполняемая таблица ссылок на переменные Ark UI для IDE-инструментов в репозитории.

## v2.2.0 — 22 июля 2026 г.

- Публичные CSS-токены получили пространство имён `--moduix-*`.
- Слои каскада получили пространство имён `moduix.*`.

Если CSS приложения переопределяет устаревший токен moduix без префикса, переименуйте это переопределение в эквивалент
`--moduix-*`. Переменные времени выполнения Ark UI, например `--height` и `--transform-origin`, остаются без префикса,
поскольку Ark записывает их непосредственно в части компонента.

## v2.1.0 — 21 июля 2026 г.

- Основные элементы управления стандартизированы вокруг средней шкалы размеров, а строки всплывающих списков — вокруг малой.
- Уточнены обработка фокуса, плотность всплывающих списков, композиция Select и токены тем.
- Добавлен компонент Typeset и пресеты тем Calm, Dense, Soft и Contrast.

## v2.0.0 — 19 июля 2026 г.

В moduix v2 фундамент React-компонентов перенесён с Base UI на Ark UI. Это осознанный мажорный релиз: теперь композиция
компонентов, доступ к состоянию и низкоуровневые пропсы следуют доступной модели примитивов Ark UI.

### Что изменилось

- Компоненты с выделенным примитивом теперь используют Ark UI для поведения и доступности.
- Публичный API следует композиции частей Ark: корневые и структурные части, `RootProvider`, контексты и колбэки
  сохраняют соответствующие контракты Ark там, где они доступны.
- Нативный CSS и варианты установки из пакета или с исходным кодом остаются. Размещённый реестр по-прежнему
  устанавливает самодостаточный исходный код компонентов.
- Стандартные иконки компонентов — внутренняя деталь реализации. Импортируйте иконки приложения напрямую из выбранной
  библиотеки, например `lucide-react`.

### Темы

В v2 добавлены тщательно подобранные пресеты CSS-токенов: `Calm`, `Dense`, `Soft` и `Contrast`. Они изменяют
семантические цвета, интервалы, размеры элементов управления, скругления, тени и токены Sidebar без провайдера или
рантайма темы. `Calm` — основа по умолчанию; импортируйте один из остальных пресетов после `style.css` и задайте тему
на `<html>`:

```tsx
import '@moduix/react/style.css';
import '@moduix/react/presets/soft.css';
```

```html
<html data-moduix-theme="soft" data-moduix-color-scheme="dark"></html>
```

Атрибут `data-moduix-color-scheme` выбирает тёмные значения для активного пресета. Темы остаются обычным CSS, поэтому
можно создать тему, которой владеет проект, определив те же семантические токены после импорта основы. Полное руководство
по пользовательской теме, все пресеты и путь через размещённый реестр описаны в разделе [Темы](/docs/themes).

### Миграция на v2

1. Установите пакет v2 вместе с его peer dependency Ark UI:

   ```bash
   npm install @moduix/react@2 @ark-ui/react
   ```

2. Просмотрите страницу v2 для каждого используемого компонента. Соберите его явные части заново там, где предыдущий
   API Base UI был более плоским или использовал другие имена.
3. Замените импорты иконок moduix библиотекой иконок, которой владеет приложение:

   ```tsx
   import { Check as CheckIcon } from 'lucide-react';
   import { Toggle } from '@moduix/react/toggle';
   ```

4. Для компонентов с исходным кодом в проекте изучите изменения перед обновлением и объедините результат с исходным
   кодом:

   ```bash
   npx shadcn@latest add @moduix-react/button --diff
   ```

Постоянный процесс обновления пакета и исходного кода в проекте описан в разделе
[Обновление и миграция](/docs/updating).

### Критические изменения

- Удалены API компонентов, специфичные для Base UI.
- `@moduix/react` больше не экспортирует внутренние стандартные иконки.
- Компоненты с исходным кодом в проекте нужно явно проверять и обновлять: это исходный код вашего проекта, а не код
  пакета, обновляемый автоматически.

## Политика версий и поддержки

moduix следует Semantic Versioning. Мажорные релизы могут включать критические изменения; минорные релизы добавляют
обратно совместимые возможности; патч-релизы содержат обратно совместимые исправления.

Последний мажорный релиз активно поддерживается. v2 поддерживает React 18 и 19, а интеграция moduix с Ark UI
синхронизирована с актуальными релизами. Для каждого мажорного релиза на этой странице фиксируются затронутые API,
шаги миграции и последствия для пакета или реестра.
