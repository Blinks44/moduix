## Выбор подходящего компонента

Используйте `Combobox`, когда пользователи выбирают из известных значений, а ввод помогает отфильтровать доступные варианты.
Используйте `Select`, когда тот же заранее заданный выбор не требует редактируемого поля ввода.

## Базовый пример

Создайте Ark `ListCollection`, передайте её в `Combobox` и сохраняйте структуру всплывающего окна явной.
Используйте `Combobox.Option` для обычных строк; переходите к `Combobox.Item`, когда строке нужна пользовательская структура.
`onInputValueChange` получает объект details Ark.

## Анатомия

```text
Combobox.Root[collection]
├─ Combobox.Label
├─ Combobox.Control
│  ├─ Combobox.Input
│  ├─ Combobox.ClearTrigger
│  └─ Combobox.Trigger
└─ Поддерево оверлея (автоматически портируется)
 └─ Combobox.Positioner
    └─ Combobox.Content
       ├─ Combobox.Empty
       ├─ Combobox.Status
       ├─ Combobox.List
       │  ├─ Combobox.Option[item]
       │  └─ Combobox.Item[item]
       │     ├─ Combobox.ItemText
       │     └─ Combobox.ItemIndicator
       └─ Combobox.ItemGroup
          ├─ Combobox.ItemGroupLabel
          └─ Combobox.Item
```

| Часть                        | Назначение                                                         |
| ---------------------------- | ------------------------------------------------------------------ |
| `Combobox` / `Combobox.Root` | Управляет состоянием, фильтрацией, подсветкой и выбранными значениями Combobox. |
| `Combobox.Control`           | Обёртка элементов поля и триггера.                                |
| `Combobox.Input`             | Текстовое поле, управляющее поиском и выбором.                     |
| `Combobox.Trigger`           | Открывает и закрывает всплывающий список.                          |
| `Combobox.ClearTrigger`      | Очищает текущее значение и/или поле.                               |
| `Combobox.Positioner`        | Плавающий позиционер всплывающего содержимого.                     |
| `Combobox.Content`           | Контейнер содержимого всплывающего окна.                           |
| `Combobox.Status`            | Стилизованное сообщение приложения о загрузке, ошибке или подсказке. |
| `Combobox.List`              | Обёртка списка вариантов.                                         |
| `Combobox.Option`            | Готовая строка простого варианта с текстом и индикатором.          |
| `Combobox.Item`              | Выбираемая строка варианта.                                       |
| `Combobox.ItemText`          | Слот текстовой подписи внутри элемента.                            |
| `Combobox.ItemIndicator`     | Слот индикатора выбора или подсветки элемента.                     |
| `Combobox.Context`           | Доступ к текущему состоянию Combobox без дополнительной разметки. |

`Combobox.RootProvider` рендерит тот же стилизованный корневой компонент вокруг состояния, созданного через
`useCombobox` из moduix. Читайте состояние внутри дерева через `Combobox.Context` или `useComboboxContext` из moduix.

## Композиция

Корневой компонент автоматически переносит `Positioner` в портал. Для встроенного рендеринга используйте
`portalled={false}`, а для собственного контейнера - `portalRef`; структурные части остаются явными и доступными для стилизации.

### Рекомендуемая композиция

Используйте `createListCollection` для статической коллекции или `useListCollection`, когда фильтрация меняет
отрендеренные элементы. Для коллекций объектов задайте `itemToString` и `itemToValue`.

Сохраняйте `Combobox.Positioner` и `Combobox.Content` явными. `Content` - фактическая часть содержимого Ark;
корневой компонент автоматизирует только границу портала.

Если эта структура всплывающего окна повторяется, используйте небольшой локальный помощник. Для простых строк
выбирайте `Combobox.Option`, а `Combobox.Item` оставляйте для ссылок, сложных строк или собственного размещения индикатора:

```tsx
function FruitComboboxPopup({ items }: { items: Array<{ label: string; value: string }> }) {
  return (
    <Combobox.Positioner>
      <Combobox.Content>
        <Combobox.Empty>No fruits found.</Combobox.Empty>
        <Combobox.List>
          {items.map((item) => (
            <Combobox.Option key={item.value} item={item}>
              {item.label}
            </Combobox.Option>
          ))}
        </Combobox.List>
      </Combobox.Content>
    </Combobox.Positioner>
  );
}
```

### Когда нужна собственная композиция

Используйте управляемое `value` и колбэки сведений Ark, когда соседнему интерфейсу нужны выбранные значения. Если
состояние нужно создать вне отрендеренного поддерева, создайте его через `useCombobox` из `@moduix/react` и отрендерите
`Combobox.RootProvider`. Для состояния элемента используйте `Combobox.ItemContext` или `useComboboxItemContext` из
moduix; из Ark импортируйте только отсутствующие в moduix помощники коллекций и типы.

Множественный выбор не добавляет отдельный API чипов для Combobox. Рендерите теги или другое представление значений из
управляемого состояния, а поведение выбора оставляйте на `Combobox multiple`.

Ark не предоставляет часть статуса Combobox. `Combobox.Status` из moduix - стилизованный `div` для сообщений приложения
о загрузке, ошибке или подсказке; он не управляет состоянием и не задаёт ARIA-роль.

### Свойства по умолчанию

По умолчанию содержимое оверлея в портале монтируется лениво и размонтируется после анимации выхода. Задайте
`unmountOnExit={false}`, чтобы сохранять его после первого открытия; отключайте оба свойства жизненного цикла только
когда нужен немедленный первоначальный рендеринг.

| Поверхность                        | По умолчанию          | Примечания                                                            |
| ---------------------------------- | --------------------- | --------------------------------------------------------------------- |
| `Combobox.Trigger`                 | шеврон moduix         | Используется, когда дочерние элементы не переданы.                    |
| `Combobox.ClearTrigger`            | иконка закрытия moduix | Используется, когда дочерние элементы не переданы.                   |
| `Combobox.ItemIndicator`           | иконка подтверждения moduix | Используется, когда дочерние элементы не переданы.               |
| `Combobox.Option.indicator`        | иконка подтверждения  | Передайте `false`, чтобы скрыть её, или React-узел, чтобы заменить.   |
| ширина `Combobox`                  | `16rem` (макс. `100%`) | Стандартная ширина стилизованного корневого компонента.              |
| переменные `Combobox.Positioner`   | переменные времени выполнения Ark | Использует `--reference-width`, `--available-height`, `--transform-origin`. |

### Особенности поведения

- `collection` обязателен.
- `value` и `defaultValue` - массивы строк, в том числе при одиночном выборе.
- `onValueChange(details)` читает текущие значения из `details.value`.
- `onInputValueChange(details)` читает текст поля из `details.inputValue`, а его источник - из
  `details.reason`.
- `onOpenChange`, `onHighlightChange` и `onSelect` сохраняют форму сведений Ark.
- Все DOM-части Ark сохраняют `asChild`.
- Текущий пакет Ark Combobox не предоставляет часть `HiddenInput`. Для встроенной отправки формы Ark используйте
  корневые свойства `name` и `form`.
- `Combobox.RootProvider` сохраняет стили корневого компонента moduix и настройки портала для состояния Ark, созданного
  снаружи. Для сценариев провайдера и контекста используйте `useCombobox`, `Combobox.Context`, `useComboboxContext`,
  `Combobox.ItemContext` и `useComboboxItemContext` из moduix.
- Наследование состояния Ark `Field.Root` остаётся доступным через `Field.Root` из moduix на базе Ark; `readOnly` и
  `required` сохраняют поведение Ark.
- Используйте `ids`, когда отдельно скомпонованным частям нужны общие идентификаторы доступности. `lazyMount` и
  `unmountOnExit` по умолчанию равны `true`; `present` сохраняет жизненный цикл присутствия Ark для анимаций выхода.
- `selectionBehavior` и `closeOnSelect` передаются в Ark без изменений. В режиме множественного выбора Ark очищает
  поле после выбора.

### Миграция с shadcn

Сохраняйте форму API moduix согласованной с Ark и явно сопоставляйте распространённые удобства shadcn:

| Паттерн shadcn          | Путь в moduix                                                        |
| ----------------------- | -------------------------------------------------------------------- |
| `items` на корневом компоненте | `createListCollection()` или `useListCollection()`, затем `collection` |
| `itemToStringValue`     | `itemToString` и обычно `itemToValue` на коллекции                   |
| `showClear`             | При необходимости рендерите `Combobox.ClearTrigger`                  |
| Обычный `ComboboxItem`  | Используйте `Combobox.Option`; для собственной структуры строки - `Combobox.Item` |
| Встроенная область чипов | Управляемое `value` с собственными тегами или композиция `TagsInput` |
| Обёртка `ComboboxContent` | Явные `Combobox.Positioner` и `Combobox.Content`                    |

### Хуки стилизации

- Стабильные слоты включают `combobox-root`, `combobox-root-provider`, `combobox-label`,
  `combobox-control`, `combobox-input`, `combobox-clear-trigger`, `combobox-trigger`,
  `combobox-positioner`, `combobox-content`, `combobox-empty`, `combobox-status`, `combobox-list`,
  `combobox-item-group`, `combobox-item-group-label`, `combobox-item`, `combobox-item-text` и
  `combobox-item-indicator`. `Combobox.Option` переиспользует слоты элемента, не добавляя собственного
  хука стилизации.
- Хуки состояния Ark включают `data-state="open|closed"`, `data-focus`, `data-invalid`, `data-disabled`,
  `data-highlighted`, `data-empty`, `data-placement` и `data-side`.
- Переменные позиционирования Ark включают `--reference-width`, `--available-width`, `--available-height`,
  `--transform-origin`, `--z-index` и `--layer-index`. Общая тема регистрирует нейтральные начальные значения для
  инструментов и непозиционированного содержимого; Ark заменяет их измеренными значениями на `Positioner`.
