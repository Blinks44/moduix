## Справочник API

В Ark UI нет отдельного примитива разделителя. moduix создаёт этот компонент с помощью официальной
[фабрики Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[ref](https://ark-ui.com/docs/guides/ref).

## Анатомия

`Separator` предоставляет одну корневую часть.

```text
Separator / Separator.Root
└─ root[data-scope="separator"][data-part="root"][data-slot="separator-root"]
```

| Часть                          | Назначение                                                                          |
| ------------------------------ | ----------------------------------------------------------------------------------- |
| `Separator` / `Separator.Root` | Корневой элемент-разделитель. Управляет ориентацией, метаданными доступности и визуальным рецептом. |

Стилизуйте корневой элемент напрямую с помощью `className`, `asChild` или CSS-свойств `--moduix-separator-*`.

## Композиция

### Рекомендуемая композиция

Для большинства разделителей используйте короткую форму `<Separator />`. Она эквивалентна
`<Separator.Root />` и поддерживает единообразие публичной корневой формы с составными компонентами
в стиле Ark.

### Когда нужна собственная композиция

Используйте `asChild` только тогда, когда другой host должен владеть отрендеренным DOM-узлом.
`Separator` уже рендерит семантический разделитель; дочерним элементом должен быть единственный элемент,
который может принять объединённые role, ARIA- и data-атрибуты, имя класса и ref.

### Свойства по умолчанию

| Свойство       | По умолчанию  | Примечания                                  |
| -------------- | ------------- | ------------------------------------------- |
| `orientation`  | `horizontal`  | `horizontal`, `vertical`                    |
| `variant`      | `solid`       | `solid`, `dashed`, `dotted`                 |
| `size`         | `sm`          | `xs`, `sm`, `md`, `lg`                      |
| `asChild`      | `false`       | Композиция фабрики Ark с одним дочерним элементом |
| `role`         | `separator`   | Для декоративного применения передайте `presentation` |

### Особенности поведения

- `Separator` выводит `aria-orientation` из `orientation`, когда его роль - `separator`, и не
  добавляет атрибут для декоративной роли, поэтому сквозные атрибуты не могут противоречить семантике.
- Используйте `role="presentation"`, когда линия только декоративная. Это отличается от декоративного
  поведения shadcn по умолчанию: moduix по умолчанию сохраняет значимые разделители содержимого в дереве
  доступности.
- Горизонтальные разделители по умолчанию занимают всю доступную ширину.
- Вертикальные разделители по умолчанию имеют высоту `1em`, поэтому естественно выравниваются с текстом
  в строке и компактными рядами действий.
- `Separator` не интерактивен и не предоставляет состояния, колбэки, отключённое поведение или
  управление фокусом.
- Для пустых промежутков используйте примитивы раскладки или токены отступов.

## Стилизация

`Separator` предоставляет селекторы частей в стиле Ark и небольшой контракт CSS-переменных
`--moduix-separator-*` для цвета, стиля границы, толщины и длины, зависящей от ориентации.

### Хуки стилизации

- `data-scope="separator"` и `data-part="root"` определяют корневую часть в стиле Ark.
- `data-slot="separator-root"` - стабильный селектор moduix.
- `data-orientation="horizontal"` и `data-orientation="vertical"` нацеливают стили для конкретной оси.
- `data-size="xs|sm|md|lg"` и `data-variant="solid|dashed|dotted"` раскрывают визуальный рецепт.
- `className` и `style` применяются непосредственно к корневому элементу разделителя.
