# Раскрывающаяся группа аватаров

Используйте этот компактный состав команды, когда пространство ограничено, но каждый человек всё равно должен иметь
распознаваемую подпись. При наведении или фокусе на аватаре после него освобождается место и открывается соответствующая всплывающая подсказка.

## Как это работает

Группа использует `Avatar.Image` с `Avatar.Fallback` в качестве fallback во время загрузки и
`Tooltip.Trigger asChild`, поэтому каждый аватар остаётся семантической кнопкой. Анимация реализована только на CSS:
активная кнопка слегка приподнимается, а следующие за ней элементы освобождают для неё место. Перед выпуском рецепта замените URL изображений
из фикстуры источником аватаров вашего приложения.

Делайте содержимое всплывающей подсказки коротким и необязательным. Если выбор участника должен вести по ссылке или выполнять
действие, замените кнопку подходящим семантическим элементом управления и сохраните его доступное имя.

Используйте `role="group"` с понятной подписью для состава и включайте роль каждого человека в
доступное имя кнопки, когда она помогает пользователям различать похожие имена. Для большой команды показывайте
только нескольких первых участников и финальный элемент управления `+N`, открывающий полный список людей с поиском.
Сохраняйте стабильный порядок списка и сохраняйте раскрытые интервалы, отключая эффекты поднятия и перехода при
`prefers-reduced-motion: reduce`.
