## Справочник по API

Ark UI не поставляется с выделенным примитивом `tag`. Moduix собирает этот компонент на официальной [фабрике Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory), следует руководствам Ark по [композиции](https://ark-ui.com/docs/guides/composition), [стилю](https://ark-ui.com/docs/guides/styling) и [ref](https://ark-ui.com/docs/guides/ref).

## Выбор подходящего компонента

Используйте `Tag`, когда пользовательский интерфейс отображает **само выбранное значение** и это значение, возможно, потребуется удалить, переупорядочить или управлять им как часть текущего состояния интерфейса.

- Выбирайте **`Badge`**, когда интерфейс показывает короткие метаданные: статус, категорию, версию или количество.
- Выбирайте **`Tag`**, когда интерфейс показывает выбранные значения, фильтры, назначения или метки, относящиеся к текущему состоянию.

## Анатомия

Корень также экспортируется как `Tag.Root` для согласованности пространства имен с составными компонентами в стиле Ark.

```text
Tag / Tag.Root
├─ Tag.StartElement (optional)
├─ Tag.Label
└─ Tag.EndElement (optional)
   └─ Tag.CloseTrigger (optional)
```

|Часть|Роль|
| ------------------ | ---------------------------------------------------------------------------------- |
|`Tag` / `Tag.Root`|Корневой слот. Применяет макет токена, границу, размер, вариант и состав `asChild`.|
|`Tag.Label`|Оболочка усечения видимого значения токена.|
|`Tag.StartElement`|Дополнительный ведущий слот для значков, аватаров или маркеров статуса.|
|`Tag.EndElement`|Дополнительный завершающий слот для значков или действий.|
|`Tag.CloseTrigger`|Дополнительное действие кнопки для отклонения или удаления токена.|

## Состав

### Рекомендуемый состав

Сохраняйте текст токена в формате `Tag.Label`. Поместите декоративные или вспомогательные элементы в `Tag.StartElement` и `Tag.EndElement`, а `Tag.CloseTrigger` поместите внутрь `Tag.EndElement`, если жетон съемный.

### Когда переходить к индивидуальному подходу

Используйте `asChild`, когда самому корню требуется собственная семантика кнопок или ссылок. Дочерний элемент должен быть единым семантическим элементом и ему принадлежит поведение взаимодействия.

### Реквизит по умолчанию

|Поверхность|Опора|По умолчанию|Примечания|
| ------------------ | ------------ | ------------ | ----------------------------------------------------------------------------- |
|`Tag`|`variant`|`default`|`default`, `secondary`, `outline`, `ghost`, `destructive`|
|`Tag`|`size`|`md`|`sm`, `md`|
|`Tag.CloseTrigger`|`type`|`button`|Предотвращает случайную отправку формы, если не используется `asChild`.|
|`Tag.CloseTrigger`|`children`|значок закрытия|Используется только тогда, когда не используется `asChild`; заменены пользовательскими детьми.|
|`Tag.CloseTrigger`|`aria-label`|`Remove tag`|Применяется только без пользовательских дочерних элементов, без `aria-labelledby` и без `asChild`.|

### Поведенческие замечания

- `Tag` не имеет собственного состояния, обратных вызовов, перемещения клавиатуры или поведения формы. - `Tag.CloseTrigger` — это явная композиция, а не опора `onClose` корневого уровня. - Встроенные варианты используют ту же цветовую семантику, что и `Badge`; `Tag` отличается анатомией деталей и доступностью. - Присвойте каждому триггеру закрытия определенное доступное имя, когда несколько съемных тегов появляются вместе. - `asChild` соответствует заводской композиции Ark и требует одного дочернего элемента. - `Tag.CloseTrigger asChild` требует явного семантического дочернего элемента; значок закрытия по умолчанию отображается только хостом кнопки по умолчанию. - Триггер закрытия по умолчанию составляет общий `CloseButton`; существующие переменные `--moduix-tag-close-trigger-*` и слот данных `tag-close-trigger` остаются API стиля.

### Крючки для стиля

- `data-scope="tag"` и `data-part="root" | "label" | "start-element" | "end-element" | "close-trigger"` излучаются на экспортируемых деталях. - `data-slot="tag-root"`, `data-slot="tag-label"`, `data-slot="tag-start-element"`, `data-slot="tag-end-element"` и `data-slot="tag-close-trigger"` являются стабильными селекторами moduix. - `Tag` записывает выбранный размер и тон в `data-size` и `data-variant`. - `Tag.CloseTrigger` предоставляет `data-disabled` для отключенных состояний или состояний `aria-disabled` и наследует цвет токена.
