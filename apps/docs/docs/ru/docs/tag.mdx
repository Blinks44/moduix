## Справочник API

В Ark UI нет отдельного примитива `tag`. Moduix создаёт этот компонент через официальную [фабрику Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по [композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и работе с [ref](https://ark-ui.com/docs/guides/ref).

## Выбор подходящего компонента

Используйте `Tag`, когда интерфейс показывает **само выбранное значение**, которое можно удалить, переместить или изменить.

- Выбирайте **`Badge`**, когда интерфейс показывает короткие метаданные: статус, категорию, версию или количество.
- Выбирайте **`Tag`**, когда интерфейс показывает выбранные значения, фильтры, назначения или метки, относящиеся к текущему состоянию.

## Анатомия

Корневой компонент также экспортируется как `Tag.Root`, чтобы API был согласован с составными компонентами в стиле Ark.

```text
Tag / Tag.Root
├─ Tag.StartElement (optional)
├─ Tag.Label
└─ Tag.EndElement (optional)
   └─ Tag.CloseTrigger (optional)
```

| Часть              | Назначение                                                                      |
| ------------------ | ------------------------------------------------------------------------------- |
| `Tag` / `Tag.Root` | Корень с разметкой, границей, размером, вариантом и поддержкой `asChild`.       |
| `Tag.Label`        | Видимый текст метки с поддержкой обрезки.                                      |
| `Tag.StartElement` | Необязательная начальная область для значка, аватара или индикатора состояния. |
| `Tag.EndElement`   | Необязательная конечная область для значка или действия.                       |
| `Tag.CloseTrigger` | Необязательная кнопка для удаления метки.                                      |

## Композиция

### Рекомендуемая композиция

Размещайте текст метки в `Tag.Label`, а декоративные и вспомогательные элементы — в `Tag.StartElement` и
`Tag.EndElement`. Если метку можно удалить, поместите `Tag.CloseTrigger` внутрь `Tag.EndElement`.

### Когда нужна собственная композиция

Используйте `asChild`, если корень должен отображаться как кнопка или ссылка. Передайте один семантический дочерний
элемент: именно он будет отвечать за взаимодействие.

### Свойства по умолчанию

| Компонент          | Свойство     | По умолчанию | Примечание                                                                    |
| ------------------ | ------------ | ------------ | ----------------------------------------------------------------------------- |
|`Tag`|`variant`|`default`|`default`, `secondary`, `outline`, `ghost`, `destructive`|
|`Tag`|`size`|`md`|`sm`, `md`|
|`Tag.CloseTrigger`|`type`|`button`|Предотвращает случайную отправку формы, если не используется `asChild`.|
|`Tag.CloseTrigger`|`children`|значок закрытия|Используется без `asChild` и заменяется собственным дочерним содержимым.|
|`Tag.CloseTrigger`|`aria-label`|`Remove tag`|Добавляется только без собственных дочерних элементов, `aria-labelledby` и `asChild`.|

### Особенности поведения

- `Tag` не управляет состоянием, событиями, клавиатурной навигацией или поведением формы.
- `Tag.CloseTrigger` добавляется явно; у корневого компонента нет свойства `onClose`.
- Встроенные варианты используют ту же цветовую семантику, что и `Badge`. Компоненты различаются анатомией и наличием кнопки удаления.
- Если рядом несколько удаляемых меток, задайте каждой кнопке удаления точное доступное имя.
- `asChild` следует правилам композиции Ark и принимает один дочерний элемент.
- Для `Tag.CloseTrigger asChild` нужен собственный семантический дочерний элемент; стандартный значок отображается только в кнопке по умолчанию.
- Стандартный `Tag.CloseTrigger` использует общий `CloseButton`; переменные `--moduix-tag-close-trigger-*` и `data-slot="tag-close-trigger"` остаются частью API стилизации.

## Стилизация

Сначала выбирайте встроенные варианты. Для единичных изменений размера или цвета используйте локальные CSS-переменные.
Общие переменные цвета имеют приоритет; в остальных случаях каждый встроенный вариант использует собственные
переменные фона, границы и текста, а затем базовые токены.

### Хуки стилизации

- Экспортируемые части получают `data-scope="tag"` и соответствующие значения `data-part`: `root`, `label`, `start-element`, `end-element` и `close-trigger`.
- `data-slot="tag-root"`, `tag-label`, `tag-start-element`, `tag-end-element` и `tag-close-trigger` — стабильные селекторы moduix.
- Выбранные размер и вариант записываются в `data-size` и `data-variant`.
- `Tag.CloseTrigger` получает `data-disabled` в отключённом состоянии или при `aria-disabled` и наследует цвет метки.
