## Справочник API

Ark UI не предоставляет отдельный примитив kbd. moduix строит этот компонент с помощью официального
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[ref](https://ark-ui.com/docs/guides/ref).

## Анатомия

Обычный путь для потребителя краток:

```text
Kbd.Group
├─ Kbd / Kbd.Root
├─ +
└─ Kbd / Kbd.Root
```

| Часть               | Назначение                                                   |
| ------------------- | ------------------------------------------------------------ |
| `Kbd` / `Kbd.Root` | Полиморфный корневой элемент клавиши; по умолчанию отрисовывает `kbd`. |
| `Kbd.Group`         | Полиморфная встроенная обёртка с ролью `group` по умолчанию для комбинаций клавиш. |

## Композиция

### Рекомендуемая композиция

Используйте `Kbd` как сокращённую форму корня и `Kbd.Group` для подсказок сочетаний, меню команд и встроенной справки.

`Kbd` и `Kbd.Root` принимают `HTMLArkProps<'kbd'>`; `Kbd.Group` принимает `HTMLArkProps<'span'>` и по умолчанию
отрисовывается с `role="group"`.
Каждая часть перенаправляет свой ref к отрисованному элементу и поддерживает `asChild`.
Нет API вариантов, размеров, разделителей, колбэков или состояния.

### Когда нужна собственная композиция

Используйте `asChild`, когда существующий семантический элемент `<kbd>` должен получить стили moduix и поведение
композиции Ark. Дочерним элементом должен быть один элемент, сохраняющий семантику клавиатурного ввода.

### Особенности поведения

- `Kbd`, `Kbd.Root` и `Kbd.Group` - статические подписи сочетаний, а не интерактивные элементы управления.
- Разделители, такие как `+`, `/` или `then`, остаются обычным текстом в простой композиции.
- Добавляйте `aria-label` к `Kbd.Group`, когда сокращениям или символам нужна более понятная речевая форма.
- Части предоставляют `data-scope="kbd"`, `data-part` и стабильные атрибуты `data-slot`.

## Стилизация

Стилизуйте `Kbd` и `Kbd.Group` через `className`, атрибуты анатомии Ark, стабильные хуки `data-slot` и публичные
CSS-переменные `--moduix-kbd-*`, приведённые ниже.

### CSS-свойства

<CssPropertiesSection properties={KbdDocs.kbdOverrideCssProperties} />

### Хуки стилизации

- `data-slot="kbd-root"` выбирает отдельный элемент клавиши
- `data-slot="kbd-group"` выбирает встроенную обёртку для сгруппированных сочетаний
- `[data-scope="kbd"][data-part="root"]` и `[data-part="group"]` предоставляют селекторы анатомии в стиле Ark
- `Kbd.Group` наследует стили текста для разделителей, а `--moduix-kbd-group-separator-color` управляет их цветом
