## Анатомия

```text
createToaster()
└─ Поддерево overlay (портализируется автоматически)
   └─ Toaster
      └─ Toast
         ├─ Toast.Title
         ├─ Toast.Description
         ├─ Toast.ActionTrigger
         └─ Toast.CloseTrigger
```

| Часть                  | Назначение                                                                  |
| ---------------------- | --------------------------------------------------------------------------- |
| `Toast`                | Видимая поверхность уведомления, связанная с текущим контекстом toast Ark. |
| `Toaster`              | Отрисовывает хранилище уведомлений и владеет группой toast Ark.            |
| `Toast.Title`          | Часть заголовка. Без дочерних элементов использует текущий `title` уведомления. |
| `Toast.Description`    | Часть описания. Без дочерних элементов использует текущее `description` уведомления. |
| `Toast.ActionTrigger`  | Кнопка действия, связанная с `toast.action.onClick`. Передайте `toast.action.label` как содержимое. |
| `Toast.CloseTrigger`   | Кнопка закрытия. По умолчанию отрисовывает `CloseButton.Root`.             |

## Композиция

`Toaster` по умолчанию портализируется сам. Для встроенной отрисовки используйте `portalled={false}`, а для
пользовательского контейнера — `portalRef`; обёртка `Portal` не нужна.

### Рекомендуемая композиция

Создайте стабильное хранилище уведомлений через `createToaster(options)`, затем один раз отрисуйте его с `Toaster`.
Хранилище управляет размещением, наложением, расстоянием, максимальным размером очереди, длительностью, задержкой
удаления, паузой в простое и горячей клавишей фокуса `Alt+T`.

По умолчанию `Toaster` использует `document.body`. Для встроенной отрисовки установите `portalled={false}` или
передайте `portalRef` для другого контейнера.

В коде приложения используйте `Toast` как корневую форму. `Toast.Root` остаётся доступен как алиас для
совместимости.

Без render prop `Toaster` отрисовывает стандартное уведомление moduix: заголовок и описание — только если они есть,
действие — если оно задано, и кнопку закрытия, если не установлено `closable: false`. Это рекомендуемый путь для
обычной обратной связи в приложении.

### Когда нужна собственная композиция

Используйте render prop `Toaster`, если каждому уведомлению нужна собственная раскладка, иконки или элементы
управления, отличающиеся от стандартных. Например, с его помощью можно заменить стандартную иконку закрытия.
Сохраняйте `Toast` внешним элементом, чтобы Ark мог поддерживать стек, измерение высоты, жизненный цикл закрытия,
паузу, клавиатурный фокус и атрибуты типа и состояния.

Все экспортируемые части Ark поддерживают `asChild`; пользовательские дочерние элементы должны сохранять семантику
и поведение кнопки для `ActionTrigger` и `CloseTrigger`.

Если пользовательской дочерней части нужен прямой доступ к состоянию уведомления, импортируйте `useToastContext()`
из `@moduix/react/toast`.

### Свойства по умолчанию

| Свойство                       | По умолчанию         | Примечания                                                                            |
| ------------------------------ | -------------------- | ------------------------------------------------------------------------------------- |
| `createToaster.gap`            | `16`                 | Расстояние между уведомлениями.                                                        |
| `createToaster.max`            | `24`                 | Новые уведомления ставятся в очередь, когда видимый стек достигает этого лимита.      |
| `createToaster.hotkey`         | `["altKey", "KeyT"]` | Перемещает фокус на группу уведомлений.                                             |
| `createToaster.offsets`        | `"1rem"`           | Отступ от безопасной границы для группы уведомлений.                                   |
| `createToaster.overlap`        | `false`              | Режим стека Ark. Используйте `true` для перекрывающихся стеков.                       |
| `createToaster.pauseOnPageIdle`| `false`              | Установите `true`, чтобы приостанавливать таймеры, когда страница бездействует.        |
| `createToaster.placement`      | `"bottom"`         | Используйте размещения Ark: `top-start`, `top`, `top-end`, `bottom-start`, `bottom`, `bottom-end`. |
| `createToaster.removeDelay`    | `200`                | Сохраняет закрытые уведомления в DOM достаточно долго для анимации выхода.             |

### Особенности поведения

- Используйте `toaster.create()`, `success()`, `error()`, `warning()`, `info()`, `loading()`,
  `promise()`, `update()`, `dismiss()`, `remove()` и `dismissByPlacement()` непосредственно из хранилища
  уведомлений Ark.
- moduix следует значению Ark по умолчанию `type: "info"`; card-поверхность `info` и поверхности
  `success`, `warning`, `error` согласованы с `Alert`.
- `toast.action` использует `{ label, onClick }`, отрисовываемый `Toast.ActionTrigger`.
- `toast.duration` задаёт одно уведомление; `createToaster({ duration })` задаёт значение по умолчанию.
- `toast.onStatusChange(details)` получает изменения статуса Ark: `visible`, `dismissing` и `unmounted`.
- Если уведомление создаётся внутри эффекта, отложите вызов хранилища через `queueMicrotask()`, чтобы избежать
  предупреждений React `flushSync`.
- `Toast` предоставляет атрибуты состояния Ark, такие как `data-state`, `data-type`, `data-placement`,
  `data-side`, `data-mounted`, `data-paused`, `data-first`, `data-sibling`, `data-stack` и `data-overlap`.

### Хуки стилизации

Используйте `Toast` для поверхности, границы, анимации, вариантов по типу и переменных времени выполнения Ark.
Используйте `Toast.Title`, `Toast.Description`, `Toast.ActionTrigger` и `Toast.CloseTrigger` для внутренней
типографики и элементов управления.

Важные хуки Ark:

- `[data-scope='toast'][data-part='group']` на `Toaster`
- `[data-scope='toast'][data-part='root']` на `Toast`
- `[data-scope='toast'][data-part='title']` на `Toast.Title`
- `[data-scope='toast'][data-part='description']` на `Toast.Description`
- `[data-scope='toast'][data-part='action-trigger']` на `Toast.ActionTrigger`
- `[data-scope='toast'][data-part='close-trigger']` на `Toast.CloseTrigger`
- `--x`, `--y`, `--scale`, `--z-index`, `--height`, `--opacity` и `--gap` на `Toast`

moduix также добавляет стабильные хуки: `data-slot="toast-toaster"`, `toast-root`, `toast-title`,
`toast-description`, `toast-action-trigger` и `toast-close-trigger`.

При ширине viewport до `40rem` moduix следует мобильным рекомендациям Ark: группа уведомлений занимает viewport,
а каждый корневой элемент использует `--gap` для безопасного внутреннего отступа.
