# Карточка с параллаксом

Карточка с фотографией на весь фон и лёгким 3D-наклоном. Декоративным слоем фотографии управляет
`Card.Background`, а для движения курсора используется `react-parallax-tilt`; эффект не включается
без точного hover-курсора и при настройке reduced motion.

## Использование на странице

Замените URL изображения и содержание карточки. Оставьте у декоративного фона `alt=""`; если
изображению нужен альтернативный текст, используйте `Card.Media`. Анимация здесь декоративна, поэтому
карточка должна оставаться читаемой и полезной без hover; для перехода добавьте обычную ссылку или кнопку.
