## Использование в маршруте

Рендерите `LoginSimple` в маршруте, отвечающем за аутентификацию, и передайте ему настоящий обработчик отправки.
Замените стандартные ссылки `/forgot-password` и `/sign-up` маршрутами своего приложения.

| Результат | Поведение маршрута |
| --------- | ----------------- |
| Ожидание | Отключите повторную отправку и задайте кнопке подпись `Signing in…`. |
| Неверные учётные данные | Покажите одну ошибку уровня формы, не указывая, какие именно учётные данные неверны. |
| Ошибка сети | Сохраните электронную почту и предложите повторить попытку; не очищайте пароль до необходимости. |
| Успех | Замените запись в истории или перенаправьте пользователя в безопасный пункт назначения, выбранный приложением. |

Проверяйте любой URL `returnTo` или перенаправления на сервере до перехода по нему.
