## Справочник API

Ark UI не предоставляет отдельный примитив input. Moduix построен на основе
[Ark Field.Input](https://ark-ui.com/react/docs/components/field) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/react/docs/guides/composition),
[стилизации](https://ark-ui.com/react/docs/guides/styling) и
[ref](https://ark-ui.com/react/docs/guides/ref).

## Выбор подходящего компонента

- Выберите **`Input`** для обычного однострочного нативного поля ввода.
- Выберите **`InputGroup`** для встроенных дополнений, текста или действий.
- Выберите **`PasswordInput`** для существующей обёртки с переключателем видимости.
- Выберите **`NumberInput`** для разбора чисел и изменения значения по шагам.
- Выберите **`Textarea`** для многострочного содержимого.
- Выберите **`Editable`** для текста, который сначала показывается, а затем переключается в режим редактирования.

## Композиция

### Рекомендуемая композиция

Отрисовывайте `Input` внутри `Field` для меток, поясняющего текста или текста ошибки, идентификаторов и общего состояния
`disabled`, `invalid`, `required` или `readOnly`. `Fieldset` может предоставлять состояние `disabled` вложенным полям.

Используйте нативные свойства и события input. В управляемых полях используются `value` и `onChange(event)`;
в неуправляемых — `defaultValue`.

### Когда нужна собственная композиция

Используйте `asChild`, когда один семантический элемент input должен владеть отрисованным узлом. Ark объединяет свойства
обёртки, поля, класс и ref в этом единственном дочернем элементе.

Для элемента управления, несовместимого с input, не пытайтесь использовать `Input`; скомпонуйте его с
компонентом, которому принадлежит правильный примитив элемента управления Ark.

### Свойства по умолчанию

| Свойство   | По умолчанию | Примечания                                                                |
| ---------- | ------------ | ------------------------------------------------------------------------- |
| `size`     | `md`         | Визуальный размер: `xs`, `sm`, `md`, `lg` или `xl`.                      |
| `htmlSize` | —            | Задаёт нативное символьное значение `input[size]` и по умолчанию использует его ширину. |
| `asChild`  | `false`      | Объединяет свойства в одном семантическом дочернем элементе через Ark Slot. |

### Особенности поведения

- Ref указывает на настоящий `HTMLInputElement`.
- `HiddenInput` не нужен, поскольку `Input` — нативный элемент управления формы.
- Ark `Field` предоставляет `aria-describedby`, `aria-invalid`, идентификаторы и свойства состояния.
- `Input` не управляет значением, валидностью, фокусом или навигацией с клавиатуры.

### Хуки стилизации

- `data-slot="input-root"`
- `data-size="xs" | "sm" | "md" | "lg" | "xl"`
- `data-scope="field"` и `data-part="input"`
- `data-invalid`, `data-required` и `data-readonly` Ark внутри `Field`
- нативные `:disabled`, `:read-only`, `:focus-visible` и `[aria-invalid="true"]`
