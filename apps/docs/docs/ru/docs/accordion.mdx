## Анатомия

```text
Accordion.Root
└─ Accordion.Item[value]
 ├─ Accordion.ItemTrigger
 │  ├─ label
 │  └─ Accordion.ItemIndicator (optional)
 └─ Accordion.ItemContent
    └─ Accordion.ItemBody
       └─ content

Accordion.RootProvider
└─ same item tree connected to a useAccordion() store
```

| Часть                          | Назначение                                                                                |
| ------------------------------ | ----------------------------------------------------------------------------------------- |
| `Accordion` / `Accordion.Root` | Управляет состоянием аккордеона и поведением клавиатуры.                                  |
| `Accordion.RootProvider`       | Подключает части к состоянию, созданному с помощью `useAccordion()`.                      |
| `Accordion.Item`               | Один сворачиваемый элемент с обязательным `value`.                                        |
| `Accordion.ItemTrigger`        | Интерактивная кнопка, открывающая или закрывающая элемент.                                |
| `Accordion.ItemIndicator`      | Визуальный индикатор открытия/закрытия. По умолчанию — иконка плюса moduix без дочерних элементов. |
| `Accordion.ItemContent`        | Сворачиваемая область содержимого, сохраняющая поведение анимации размера Ark.            |
| `Accordion.ItemBody`           | Обёртка с внутренними отступами по умолчанию для содержимого панели.                      |

## Композиция

### Рекомендуемая композиция

`Accordion` управляет навигацией с клавиатуры, перемещением фокуса и состоянием открытых элементов. Используйте его для
`value`, `defaultValue`, `onValueChange(details)`, `onFocusChange(details)`, `multiple`,
`collapsible`, `orientation`, `lazyMount`, `unmountOnExit` и `ids`.

Для стандартной композиции Ark используйте `Accordion`, `Accordion.Item`, `Accordion.ItemTrigger`, `Accordion.ItemIndicator`,
`Accordion.ItemContent` и `Accordion.ItemBody`.

### Когда нужна собственная композиция

`value` и `defaultValue` всегда являются массивами, в том числе в режиме с единственным открытым элементом. `onValueChange` соответствует
форме колбэка Ark и предоставляет текущие значения элементов в `details.value`.

Используйте `Accordion.RootProvider` вместе с `useAccordion()` из `@moduix/react`, если состояние аккордеона нужно создать
вне отрисовываемого поддерева.

Используйте `Accordion.Context`, `Accordion.ItemContext`, `useAccordionContext()` и
`useAccordionItemContext()` из moduix, если окружающему интерфейсу требуется читать состояние корня или элемента.

`Accordion.Item` требует стабильного `value`. Используйте `disabled` для элемента, если раздел должен оставаться
видимым, но недоступным.

`Accordion.ItemIndicator` необязателен. В moduix по умолчанию он отрисовывает `PlusIcon`, если не переданы дочерние элементы,
но содержимое индикатора можно полностью заменить.

Используйте `asChild` только тогда, когда другой элемент должен владеть отрисованным узлом. Сохраняйте дерево частей Ark видимым,
а не скрывайте его за удобными обёртками.

### Свойства по умолчанию

| Свойство              | По умолчанию | Примечания                                                            |
| --------------------- | ------------ | --------------------------------------------------------------------- |
| `collapsible`         | `false`      | Удерживает один развёрнутый элемент открытым, пока не будет выбран другой. |
| `lazyMount`           | `false`      | Сразу монтирует содержимое элемента.                                  |
| `multiple`            | `false`      | По умолчанию разрешает один развёрнутый элемент.                      |
| `orientation`         | `vertical`   | Использует вертикальное поведение клавиатуры и раскладки.             |
| `unmountOnExit`       | `false`      | Сохраняет свёрнутое содержимое смонтированным.                        |
| `value`/`defaultValue` | `[]`        | Значения — строковые массивы, в том числе в режиме с единственным открытым элементом. |

### Особенности поведения

Задавайте отступы у `Accordion.ItemBody`, а не у `Accordion.ItemContent`. Переменные измерения Ark
управляют анимацией открытия/закрытия: `--height` для вертикальных аккордеонов и `--width` для горизонтальных
аккордеонов.

Все экспортируемые части поддерживают `asChild` для случаев, когда другой элемент должен владеть отрисованным узлом.

## Стилизация

Используйте `className` на экспортируемых частях для структурных изменений стилей. Для стилизации по состоянию предпочтительны
атрибуты данных Ark (`data-state`, `data-disabled`, `data-orientation`) и хуки `data-slot` moduix.

### CSS-свойства

<CssPropertiesSection properties={AccordionDocs.accordionOverrideCssProperties} />

### Хуки стилизации

- Селекторы `data-slot="accordion-root"`, `accordion-root-provider`, `accordion-item`,
  `accordion-item-trigger`, `accordion-item-indicator`, `accordion-item-content` и
  `accordion-item-body`.
- Хуки анатомии Ark: `data-scope="accordion"` и `data-part="root|item|item-trigger|item-indicator|item-content"`.
- Хук удобной части moduix: `data-part="item-body"` на `Accordion.ItemBody`.
- Хуки состояния Ark: `data-state="open|closed"`, `data-disabled`, `data-focus`,
  `data-controls` и `data-orientation="horizontal|vertical"`.
- Переменные содержимого Ark: `--height` для вертикальной анимации и `--width` для горизонтальной анимации.
