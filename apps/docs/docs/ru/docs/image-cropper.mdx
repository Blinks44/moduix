## Анатомия

```tsx
<ImageCropper>
  <ImageCropper.Viewport>
    <ImageCropper.Image />
    <ImageCropper.CropArea />
  </ImageCropper.Viewport>
</ImageCropper>
```

| Часть                                | Назначение                                                                               |
| ------------------------------------ | ---------------------------------------------------------------------------------------- |
| `ImageCropper` / `ImageCropper.Root` | Корневая группа, управляющая состоянием кадрирования, преобразованиями, ARIA-метками и CSS-переменными времени выполнения. |
| `ImageCropper.RootProvider`          | Корень, отрисованный из экземпляра `useImageCropper`, созданного вне дерева.             |
| `ImageCropper.Viewport`              | Поверхность для перемещения и область просмотра изображения с отсечением.                |
| `ImageCropper.Image`                 | Преобразуемый элемент изображения под управлением Ark.                                   |
| `ImageCropper.Selection`             | Фокусируемое выделение кадра и цель для взаимодействия с клавиатурой.                    |
| `ImageCropper.Grid`                  | Горизонтальные или вертикальные направляющие кадрирования.                               |
| `ImageCropper.Handle`                | Маркер изменения размера для каждой позиции из `ImageCropper.handles`.                   |
| `ImageCropper.CropArea`              | Рекомендуемое выделение с обеими сетками и всеми маркерами изменения размера.            |

## Композиция

### Рекомендуемая композиция

Используйте `ImageCropper.CropArea` для обычной анатомии кадрирования. Он сохраняет дерево частей Ark нетронутым,
устраняя повторяющуюся разметку выделения, сетки и маркеров. Передавайте `className`, `gridClassName` или
`handleClassName`, чтобы стилизовать отрисованные части. Компонент управляет этой дочерней структурой, поэтому при иной
структуре используйте явные части `Selection`, `Grid` и `Handle` вместо `children` или `asChild`.

### Когда нужна собственная композиция

Используйте `ImageCropper.Context` для панелей инструментов внутри корня. Используйте moduix `useImageCropper` вместе с
`ImageCropper.RootProvider`, когда элементам управления, предварительному просмотру кадра или интеграции с формой
нужен API кадрирования вне поддерева корня. Для одного экземпляра состояния не объединяйте `RootProvider` с
`ImageCropper.Root`.

### Свойства по умолчанию

| Свойство                | По умолчанию                             | Примечания                                                              |
| ----------------------- | ---------------------------------------- | ----------------------------------------------------------------------- |
| `cropShape`             | `"rectangle"`                            | Используйте `"circle"` для кадрирования в стиле аватара.              |
| `defaultZoom`           | `1`                                      | Начальное масштабирование изображения.                                 |
| `defaultRotation`       | `0`                                      | Начальный поворот изображения в градусах.                              |
| `defaultFlip`           | `{ horizontal: false, vertical: false }` | Начальное состояние отражения.                                         |
| `minZoom`               | `1`                                      | Минимальный коэффициент масштабирования.                               |
| `maxZoom`               | `5`                                      | Максимальный коэффициент масштабирования.                              |
| `minWidth` / `minHeight` | `40`                                   | Минимальный размер выделения кадра.                                     |
| `fixedCropArea`         | `false`                                  | Когда значение истинно, пользователь перемещает изображение под фиксированным выделением. |

### Особенности поведения

Ark управляет перетаскиванием указателем, панорамированием, масштабированием колесом и жестом, перемещением с клавиатуры,
генерируемыми идентификаторами, ARIA-метками и помощниками для результата кадрирования. Клавиши со стрелками перемещают выделение,
`Alt` со стрелками изменяет его размер, `Shift` и `Ctrl`/`Cmd` используют свойства шага перемещения, а `+` / `-`
масштабируют. Управляемое состояние сохраняет объекты details Ark через `onCropChange`, `onZoomChange`,
`onRotationChange` и `onFlipChange`.

### Хуки стилизации

Используйте стабильные хуки `data-slot`: `image-cropper-root`, `image-cropper-viewport`,
`image-cropper-image`, `image-cropper-selection`, `image-cropper-grid` и
`image-cropper-handle`. Ark также предоставляет `data-scope="image-cropper"`, значения `data-part`,
`data-fixed`, `data-shape`, `data-pinch`, `data-ready`, `data-disabled`, `data-measured`,
`data-dragging`, `data-panning`, `data-axis` и `data-position`.

Ark записывает в корень `--crop-width`, `--crop-height`, `--crop-x`, `--crop-y`, `--image-zoom`,
`--image-rotation`, `--image-offset-x` и `--image-offset-y`. Считайте их доступными только для
чтения значениями времени выполнения при синхронизации собственного интерфейса; для визуальной
настройки используйте описанные выше свойства `--moduix-image-cropper-*`.
