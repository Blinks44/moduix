## Основы

Используйте `Listbox` для видимой коллекции, в которой пользователь выбирает один или несколько элементов,
не открывая всплывающее окно. Передайте `collection`, отрисуйте `Content` и передайте каждый элемент в
`Listbox.Item item={item}`.

## Композиция

### Рекомендуемая композиция

Отрисовывайте дерево частей Ark напрямую: `Listbox` владеет коллекцией, `Listbox.Content` владеет фокусом
и клавиатурной навигацией, а каждый `Listbox.Item` получает исходный элемент коллекции через `item`.
Используйте `Listbox.ItemIndicator`, когда строкам нужно резервировать место для выбранного состояния.

Для фильтрации поместите `Listbox.Input` в `Listbox.Filter` непосредственно перед `Listbox.Content`.
`Filter` предоставляет стандартную иконку поиска и объединяет поле ввода с результатами в одну поверхность с рамкой.

### Когда нужна собственная композиция

Используйте `asChild`, только когда пользовательский элемент может сохранить требуемую семантику listbox и
получить пропы Ark. Используйте `ids`, когда частям listbox нужны стабильные ID для композиции с окружающим
интерфейсом. Используйте moduix `useListbox` вместе с `Listbox.RootProvider`, когда состоянием необходимо
управлять вне отрисованного дерева; не отрисовывайте `Listbox.Root` для того же экземпляра состояния.
Отрисовывайте `Listbox.Input` напрямую, когда поле фильтра должно оставаться визуально отдельным от списка
или находиться в пользовательском окружении.

### Значения по умолчанию

| Проп                      | По умолчанию | Примечания                                                                 |
| ------------------------- | ------------ | -------------------------------------------------------------------------- |
| `collection`              | —            | Обязательная коллекция Ark. Используйте `createListCollection` или варианты для сетки. |
| `defaultValue`            | `[]`         | Начальные выбранные значения для неуправляемого состояния.                 |
| `defaultHighlightedValue` | —            | Начальный подсвеченный элемент для неуправляемого состояния подсветки.      |
| `deselectable`            | —            | Позволяет Escape очистить непустой выбор.                                  |
| `disabled`                | `false`      | Отключает весь listbox.                                                     |
| `disallowSelectAll`       | `false`      | Отключает выбор `Cmd/Ctrl + A`.                                            |
| `loopFocus`               | `false`      | По умолчанию стрелочная навигация не зацикливается.                         |
| `orientation`             | `vertical`   | Управляет раскладкой и направлением стрелочных клавиш.                      |
| `selectionMode`           | `single`     | Поддерживает `single`, `multiple` и `extended`.                            |
| `selectOnHighlight`       | `false`      | Выбирает элементы при изменении подсветки с клавиатуры.                     |
| `typeahead`               | `true`       | Включает поиск по вводу, если текстовый ввод не принадлежит фильтру.        |

### Особенности поведения

`value`, `defaultValue` и `onValueChange(details)` используют массивы строк. Читайте `details.value`
для выбранных ключей, а `details.items` — для выбранных элементов коллекции.

`highlightedValue`, `defaultHighlightedValue` и `onHighlightChange(details)` управляют перемещением
активного потомка. `onSelect(details)` срабатывает при выборе элемента с выбранным значением.

`useListbox`, `useListboxContext`, `useListboxItemContext`, `Listbox.Context` и
`Listbox.ItemContext` доступны из `@moduix/react` для расширенной композиции состояния и элементов.
Ref передаются соответствующей части Ark; ref корня и root provider указывают на отрисованные элементы `div`.
Используйте `ids`, когда частям listbox нужны стабильные ID для композиции с окружающим интерфейсом.

`Listbox.Input` нужен только для фильтрации. Помещайте его в `Listbox.Filter` для стандартного вида поиска
или отрисовывайте напрямую для отдельного поля ввода. Установите `typeahead={false}`, чтобы поиск по вводу
и фильтрация не конкурировали. Состояние фильтрации остаётся явным: отрисовывайте `Listbox.ClearTrigger`
для непустого запроса и очищайте запрос вместе с фильтром коллекции в его обработчике `onClick`.

Ark владеет ARIA-паттерном listbox, управлением фокусом активного потомка, клавиатурной навигацией,
поиском по вводу, поведением Home/End, обработкой отключённых элементов и стрелочными клавишами в зависимости
от ориентации. Оставляйте `Listbox.Label` в дереве, когда listbox нужна видимая метка.

### Хуки стилизации

- Хуки анатомии Ark: `data-scope="listbox"` и `data-part` на корне, метке, поле ввода, содержимом,
  группе элементов, метке группы, элементе, тексте элемента, индикаторе элемента, тексте значения и пустом состоянии.
- Хуки состояния: `data-orientation`, `data-disabled`, `data-empty`, `data-layout`,
  `data-activedescendant`, `data-value`, `data-selected`, `data-state` и `data-highlighted`.
- Хуки moduix: `data-slot="listbox-root"`, `listbox-label`, `listbox-filter`,
  `listbox-filter-icon`, `listbox-input`, `listbox-clear-trigger`, `listbox-content`,
  `listbox-empty`, `listbox-item-group`, `listbox-item-group-label`, `listbox-item`,
  `listbox-item-text`, `listbox-item-text-content`, `listbox-item-text-icon`,
  `listbox-item-text-label`, `listbox-item-indicator` и `listbox-value-text`.
