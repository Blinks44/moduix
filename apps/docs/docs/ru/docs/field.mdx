## Выбор подходящего компонента

Используйте `Field`, когда одному элементу управления нужны видимая метка, поясняющий текст, текст ошибки
или общее состояние `disabled`, `invalid`, `required` и `readOnly`.

- Выбирайте **`Field`** для одного элемента управления и его метки или поясняющего текста.
- Выбирайте **`Fieldset`**, когда нескольким связанным полям нужна одна общая легенда.
- Используйте отдельный элемент управления, когда не требуются ARIA-связи на уровне поля или общее состояние.

## Анатомия

`Field` следует составным частям Ark UI и сохраняет их имена в публичном API moduix.

```text
Field
├─ Field.Label
├─ Field.Input | Field.Textarea | Field.Select | custom control
├─ Field.HelperText
├─ Field.ErrorText
└─ Field.RequiredIndicator
```

| Часть                     | Назначение                                                                 |
| ------------------------- | -------------------------------------------------------------------------- |
| `Field` / `Field.Root`    | Корневой контекст и стандартный `<div role="group">`.                    |
| `Field.RootProvider`      | Корень, работающий с экземпляром `useField()`, созданным вне дерева.       |
| `Field.Context`           | Нерисующий доступ к текущему состоянию поля.                               |
| `Field.Label`             | Метка, связанная с идентификатором текущего элемента управления.           |
| `Field.Input`             | Низкоуровневый нативный input в стиле Ark. Предпочтительнее `Input`.       |
| `Field.Textarea`          | Низкоуровневый textarea в стиле Ark. Предпочтительнее `Textarea`.         |
| `Field.Select`            | Нативный select, связанный с ARIA и свойствами состояния поля.             |
| `Field.HelperText`        | Поясняющий текст, включённый в `aria-describedby`.                         |
| `Field.ErrorText`         | Текст ошибки, отрисовываемый только когда `Field` имеет `invalid`.         |
| `Field.RequiredIndicator` | Визуальный маркер обязательности с необязательным `fallback`.              |
| `Field.Item`              | Контекст поля для элемента групповых контролов через `value`; его ref указывает на обёртку строки. |

## Композиция

### Рекомендуемая композиция

Оставляйте одну видимую метку в корне, отрисовывайте ровно один основной элемент управления moduix, например `Input`,
`Textarea` или `NativeSelect`, и добавляйте поясняющий текст или текст ошибки, если нужно описание или обратная связь валидации.

### Когда нужна собственная композиция

Используйте `Field.Item value` вместе с корневым `target`, когда поле содержит несколько нативных элементов управления,
а метка должна указывать на один из них. `Field.Input`, `Field.Textarea` и `Field.Select` остаются доступны для
расширенной композиции в стиле Ark, однако в обычном коде приложения следует применять предназначенные для них элементы moduix.

### Свойства по умолчанию

| Поверхность              | По умолчанию | Примечания                                                |
| ------------------------ | ------------ | --------------------------------------------------------- |
| `Field` / `Field.Root`   | —            | Дополнительных поведенческих значений нет; действуют значения Ark. |

### Особенности поведения

- `Field.ErrorText` отсутствует в DOM, пока корень не имеет `invalid`.
- Длинные метки, поясняющий текст и текст ошибки переносятся внутри поля, а не выходят за его границы.
- `Field.RootProvider` должен получать состояние из `useField()`, импортированного из `@moduix/react`,
  и не должен быть вложен в `Field.Root` для того же экземпляра поля.
- Используйте `Field.Context` или `useFieldContext` из `@moduix/react`, когда пользовательскому элементу управления
  требуется текущее состояние поля. Прямой импорт из Ark нужен только для низкоуровневых API, не экспортируемых moduix.
- `Field.Item` передаёт свой ref обёртке строки moduix, которую отрисовывает вокруг дочерних элементов.
- `Field` не отрисовывает скрытый input: составные элементы, такие как `Checkbox` и `RadioGroup`, владеют
  собственными нативными частями формы.

## Стилизация

Стилизуйте `Field` через `className`, атрибуты Ark `data-scope="field"` / `data-part="..."`,
хуки moduix `data-slot="field-*"` и публичные CSS-переменные `--moduix-field-*`, приведённые ниже.

### Хуки стилизации

Ark добавляет `data-disabled`, `data-invalid`, `data-readonly` и `data-required` к соответствующим частям.
`Field.ErrorText` отрисовывается только когда контекст текущего поля невалиден. Идентификатор поясняющего текста
включается в `aria-describedby` элемента управления, а идентификатор активного текста ошибки — в
`aria-errormessage`. Каждая DOM-часть также сохраняет стабильный хук `data-slot="field-*"`.
