# Тёмная тема

moduix по умолчанию поставляется со светлыми токенами, а набор тёмных токенов включается атрибутом
`data-moduix-color-scheme="dark"`. Один раз импортируйте таблицу стилей основы. Приложение управляет
выбранной темой, а moduix реагирует на итоговую тему.

```tsx
import '@moduix/react/style.css';
```

## Примените тему к корневому элементу документа

Когда ваше решение для управления темой выбирает тёмную тему, оно должно установить
`data-moduix-color-scheme="dark"` на `<html>`; для светлой темы используйте `light`. moduix не требует
провайдера, не хранит настройки и не выбирает пакет темы, поэтому остаётся независимым от существующих
в приложении селекторов и токенов темы.

```html
<!-- Dark theme -->
<html data-moduix-color-scheme="dark"></html>
```

Используйте корневой элемент документа для темы всего приложения. Компоненты, отрисовываемые через
портал, такие как Dialog, Popover и Select, также наследуют заданные там токены.

Если приложение рендерится на сервере, используйте его механизм раннего применения темы, чтобы итоговый
атрибут был установлен до показа страницы. Это предотвращает кратковременное отображение светлой темы,
пока клиентский JavaScript применяет сохранённую настройку.

## Добавьте простой переключатель

Храните явно выбранную пользователем тему в приложении и обновляйте атрибут документа. Если сохранённого
выбора нет, определяйте системную настройку с помощью `matchMedia`.

```tsx
type ColorScheme = 'light' | 'dark';

export function applyColorScheme(scheme: ColorScheme) {
  document.documentElement.dataset.moduixColorScheme = scheme;
}

export function resolveColorScheme(): ColorScheme {
  const saved = localStorage.getItem('color-scheme');
  if (saved === 'light' || saved === 'dark') return saved;

  return matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
}

export function saveColorScheme(scheme: ColorScheme) {
  localStorage.setItem('color-scheme', scheme);
  applyColorScheme(scheme);
}
```

Выполните эквивалент `applyColorScheme(resolveColorScheme())` в раннем inline-скрипте темы своего
фреймворка до первой отрисовки. Пусть видимый переключатель вызывает `saveColorScheme` со следующим
значением. Так системная настройка остаётся значением по умолчанию, пока пользователь явно не сделает
выбор. Дайте переключателю доступное имя, описывающее действие, например `Switch to dark mode`.

## Совместите тёмную тему с пресетом

Цветовая схема и визуальные пресеты — независимые слои. Установите `data-moduix-color-scheme` и
`data-moduix-theme` на одном корневом элементе, чтобы обычные компоненты и компоненты, отрисовываемые
через портал, использовали одну палитру, плотность, радиусы и токены фокуса.

```tsx
import '@moduix/react/style.css';
import '@moduix/react/presets/dense.css';
```

<div style={{ height: '1rem' }} aria-hidden="true" />

```html
<html data-moduix-color-scheme="dark" data-moduix-theme="dense"></html>
```

Смена цветовой схемы не меняет плотность. Выбранный пресет сохраняет масштаб элементов управления и
всплывающих компонентов в обоих режимах. Сравнение пресетов и подход к созданию собственной темы
описаны в разделе [Темы](/docs/themes).

## Ограничьте область предпросмотра или встроенной поверхности

Если тёмные токены нужны только этому поддереву, можно установить `data-moduix-color-scheme="dark"` на
обычный контейнер:

```tsx
<section data-moduix-color-scheme="dark">
  <Card>Dark preview</Card>
</section>
```

Это полезно для предварительного просмотра настроек или встроенного виджета. Содержимое, отрисованное
через портал, находится за пределами этого контейнера, поэтому, если поддерево открывает оверлеи,
сохраняйте атрибут на `<html>`, `body` или контейнере портала.

## Настройте обе темы

Переопределяйте одни и те же семантические токены в `:root` и
`[data-moduix-color-scheme='dark']`. Компоненты используют семантические алиасы, такие как
`--moduix-color-background`, `--moduix-color-foreground` и `--moduix-color-border`, поэтому значения
остаются согласованными во всей библиотеке.

```css
:root {
  --moduix-background: oklch(0.99 0.004 285);
  --moduix-primary: oklch(0.5 0.18 260);
}

[data-moduix-color-scheme='dark'] {
  --moduix-background: oklch(0.16 0.01 285);
  --moduix-primary: oklch(0.76 0.13 260);
}
```

Справочник системных токенов приведён в разделе [Токены](/docs/tokens), а локальные визуальные
переопределения — на страницах компонентов.
