# Обзор коллекций

Коллекции — слой данных для компонентов Ark, работающих со списками. Это не стилизованные компоненты
moduix: при работе с `Select`, `Combobox`, `Listbox`, `TreeView` или пользовательскими интерфейсами
на основе коллекций импортируйте их напрямую из Ark UI.

Поскольку код приложения импортирует Ark UI напрямую, укажите его как прямую зависимость:

```bash
npm install @ark-ui/react
```

Все API коллекций, рассмотренные в этом разделе, используют точку входа коллекций для React:

```tsx
import { createListCollection } from '@ark-ui/react/collection';
```

Обычный сценарий выглядит так:

```text
элементы приложения → коллекция Ark → компонент moduix → выбор пользователя
```

Коллекция нормализует идентификатор, текст, отключённое состояние элементов и обход. Компонент moduix
рендерит доступное взаимодействие и управляет поведением фокуса и выбора.

## Выбор подходящей коллекции

- Начните с `createListCollection` для фиксированного массива вариантов.
- Используйте `useListCollection`, когда список нужно фильтровать или изменять из состояния React.
- Используйте `createTreeCollection` для вложенных данных.
- Используйте `useAsyncList`, когда загрузкой, фильтрацией, сортировкой или разбиением на страницы
  управляет сервер.
- Используйте `useListSelection` для выбора в пользовательском списке. Компоненты коллекций moduix
  уже управляют собственным состоянием выбора.

Коллекции нормализуют идентификатор и текст элементов, но не рендерят интерфейс. Передайте полученную
коллекцию в соответствующий компонент moduix:

- [Select](/docs/select)
- [Combobox](/docs/combobox)
- [Listbox](/docs/listbox)
- [Tree View](/docs/tree-view)

## Граница ответственности

Ark UI отвечает за эти API и их жизненный цикл релизов. moduix принимает полученные объекты коллекций,
не оборачивая и не реэкспортируя их. На следующих страницах описан полный сценарий, необходимый
пользователям moduix, и вверху приведены ссылки на соответствующую справку Ark.
