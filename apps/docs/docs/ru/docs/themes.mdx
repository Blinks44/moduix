# Темы

Темы moduix — это обычные слои CSS-токенов. `Calm` — сбалансированная основа; `Dense`, `Soft` и `Contrast` —
дополнительные отправные точки для другого визуального направления. Пресет может изменить палитру, скругления,
интервалы, плотность элементов управления, тени и токены Sidebar, не меняя API компонентов и не добавляя рантайм темы.

## Выберите пресет

| Пресет | Элементы управления / строки всплывающих списков | Оптимальная отправная точка для |
| --- | --- | --- |
| Calm | 36px / 32px | Большинства продуктовых интерфейсов; нейтрального ритма и спокойных поверхностей. |
| Dense | 34px / 30px | Инструментов с большим объёмом данных, где важна видимая плотность информации. |
| Soft | 40px / 34px | Удобных для касания или просторных интерфейсов с более тёплым визуальным направлением. |
| Contrast | 36px / 32px | Интерфейсов, которым полезны более выразительные границы и разделение фокуса. |

В предпросмотре используются реальные элементы управления moduix. Откройте Select и перемещайтесь по полям с
клавиатуры, чтобы вместе сравнить плотность триггеров, более компактные строки всплывающих списков, метки,
поверхности и обработку фокуса. Названия пресетов описывают визуальное направление, а не гарантируют доступность.
Перед выпуском проверьте с вашим контентом и переопределениями приложения контраст текста, видимость фокуса, масштаб
и размеры целей.

## Как работают слои

Таблица стилей основы определяет полный контракт токенов и значения `Calm` по умолчанию. Пресет выборочно
переопределяет этот контракт; затем приложение может переопределить только решения, относящиеся к вашему бренду.
Компоненты используют семантические алиасы и алиасы уровня компонента, поэтому изменение палитры или плотности
распространяется на связанные элементы управления, а не превращается в набор разовых правил.

```text
foundation tokens → optional preset → application overrides → component aliases
```

CSS пресетов остаётся небольшим, читаемым и удаляемым. В разделе [Токены](/docs/tokens) перечислены переменные,
которые образуют публичную поверхность темизации.

## Использование с npm-пакетом

Сначала импортируйте основу, затем один пресет. Разместите `data-moduix-theme` на `<html>`, чтобы компоненты,
отрендеренные через портал, наследовали те же токены. Для тёмной палитры moduix задайте на этом элементе
`data-moduix-color-scheme="dark"`.

```tsx
import '@moduix/react/style.css';
import '@moduix/react/presets/soft.css';
```

```html
<html data-moduix-theme="soft" data-moduix-color-scheme="dark"></html>
```

Вместо `soft.css` выберите один из этих путей:

```text
@moduix/react/presets/dense.css
@moduix/react/presets/contrast.css
```

## Использование с размещённым реестром

Установите один пресет с исходным кодом в проекте, затем импортируйте созданный CSS после таблицы стилей основы.

```bash
npx shadcn@latest add @moduix-react/theme-dense
```

```tsx
import '@/lib/moduix/styles/style.css';
import '@/lib/moduix/presets/dense.css';
```

```html
<html data-moduix-theme="dense"></html>
```

Замените `dense` на `soft` или `contrast`, чтобы использовать другой пресет.

## Переключение тем во время работы

Храните состояние темы на элементе документа, чтобы обычное содержимое и оверлеи в портале получали одни и те же
токены. Сохраняйте выбранное имя, только если продукту нужно его запоминать.

```tsx
function setTheme(theme: 'calm' | 'dense' | 'soft' | 'contrast') {
  document.documentElement.dataset.moduixTheme = theme;
  localStorage.setItem('moduix-theme', theme);
}
```

Применяйте сохранённое значение до отрисовки приложения, чтобы при запуске не было заметной смены темы.

## Настройка пресета

Пресет — это лишь слой CSS-переменных. Переопределите его в собственной таблице стилей после импорта пресета.
Меняйте семантические токены для решений уровня системы, а алиасы компонентов — только для осознанных исключений.

```css
[data-moduix-theme='soft'] {
  --moduix-primary: oklch(0.5 0.17 285);
  --moduix-radius: 0.875rem;
}
```

## Создание пользовательской темы

Создайте таблицу стилей после основы и примените её имя на `<html>`. Начните с токенов, задающих визуальное
направление; пропущенные токены сохранят значения основы. Добавляйте токены размеров или интервалов, только если тема
намеренно меняет плотность. Используйте пресет как ориентир, когда хотите заменить полную палитру, токены Sidebar,
интервалы и тени.

```tsx
import '@moduix/react/style.css';
import './brand.css';
```

```css
/* brand.css */
[data-moduix-theme='brand'] {
  --moduix-background: oklch(0.98 0.01 260);
  --moduix-foreground: oklch(0.2 0.02 260);
  --moduix-card: oklch(1 0 0);
  --moduix-card-foreground: oklch(0.2 0.02 260);
  --moduix-primary: oklch(0.5 0.18 260);
  --moduix-primary-foreground: oklch(0.99 0.002 260);
  --moduix-border: oklch(0.86 0.02 260);
  --moduix-input: oklch(0.82 0.025 260);
  --moduix-ring: oklch(0.58 0.15 260);
  --moduix-radius: 0.875rem;
  --moduix-size-sm: 2rem;
  --moduix-size-md: 2.25rem;
}

[data-moduix-theme='brand'][data-moduix-color-scheme='dark'] {
  --moduix-background: oklch(0.17 0.02 260);
  --moduix-foreground: oklch(0.97 0.004 260);
  --moduix-card: oklch(0.22 0.024 260);
  --moduix-card-foreground: oklch(0.97 0.004 260);
  --moduix-primary: oklch(0.78 0.13 260);
  --moduix-primary-foreground: oklch(0.18 0.024 260);
  --moduix-border: oklch(0.76 0.03 260 / 0.28);
  --moduix-input: oklch(0.76 0.03 260 / 0.34);
  --moduix-ring: oklch(0.74 0.12 260);
}
```

```html
<html data-moduix-theme="brand" data-moduix-color-scheme="dark"></html>
```

Для системной справки по токенам используйте [Токены](/docs/tokens), а для реализованного приложением
переключателя светлой и тёмной темы — [Тёмный режим](/docs/dark-mode).
