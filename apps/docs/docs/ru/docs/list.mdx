## Справочник API

В Ark UI нет отдельного примитива списка. Moduix строит этот компонент с помощью официальной
[фабрики Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark
по [композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[ref](https://ark-ui.com/docs/guides/ref).

## Анатомия

Обычный путь для потребителя краток:

```text
List / List.Root
└─ List.Item | li
```

| Часть                 | Назначение                                                               |
| -------------------- | ------------------------------------------------------------------------ |
| `List` / `List.Root` | Семантический корень списка, управляющий маркером, отступами, размером и тоном. |
| `List.Item`          | Необязательная Ark-подобная часть элемента для стабильного слота `li` и `asChild`. |

## Композиция

### Рекомендуемая композиция

Используйте `<List>` для неупорядоченного содержимого, а `as="ol"`, когда нужна упорядоченная
семантика. Применяйте `asChild`, только если необходимо заменить `List` одним семантическим `<ul>` или
`<ol>`, либо `List.Item` одним семантическим `<li>`.

### Когда нужна собственная композиция

`List` не предоставляет внутреннюю машину состояний, помощники вложенной структуры или API рендеринга
маркеров. Для обычной стилизации элементов используйте `className` и нативный CSS, например `li::marker`.
Оставьте `asChild` для компонента, принадлежащего вызывающему коду, который передаёт ref и пропы и
отрисовывает необходимый семантический хост.

Оставляйте элементы прямыми потомками `li`. Встроенные отступы и стилизация маркера применяются только
к непосредственным элементам списка.

### Свойства по умолчанию

| Проп      | По умолчанию     | Примечания                                                                |
| --------- | ---------------- | ------------------------------------------------------------------------- |
| `gap`     | `sm`             | Отступ между непосредственными элементами списка.                         |
| `size`    | `md`             | Токен размера типографики.                                                |
| `tone`    | `default`        | Семантический путь цвета для текста и маркеров.                           |
| `marker`  | семантический `auto` | `disc` для `ul`, маркеры упорядоченного списка браузера для `ol` или `none`. |
| `as`      | `ul`             | Переключает нативный хост списка между `ul` и `ol`.                       |
| `asChild` | `false`          | Заменяет семантический хост единственным дочерним элементом вызывающего кода. |

### Особенности поведения

- Пропы упорядоченного списка, такие как `start`, `reversed` и `type`, доступны при использовании `as="ol"`.
- Используйте `marker="none"`, чтобы скрыть маркеры, сохранив семантику списка. На этом пути `List` добавляет `role="list"`, если вы явно не переопределите `role`.
- `List.Item` необязателен. Используйте простые элементы `li`, когда экспортируемый слот элемента не даёт преимуществ.

## Стилизация

### Хуки стилизации

`List` предоставляет небольшую публичную поверхность стилизации:

- корень: `data-scope="list"`, `data-part="root"`, `data-slot="list-root"`
- элемент: `data-scope="list"`, `data-part="item"`, `data-slot="list-item"`
- `data-gap="xs" | "sm" | "md" | "lg" | "xl" | "2xl"` для стилизации, зависящей от отступов
- `data-marker="auto" | "disc" | "decimal" | "none"` для стилизации, зависящей от маркера
- `data-size="xs" | "sm" | "md" | "lg" | "xl"` для стилизации размера типографики
- `data-tone="default" | "muted" | "subtle" | "primary" | "destructive"` для семантических путей цвета
- нативный селектор `li::marker` для переопределения цвета или толщины маркера
