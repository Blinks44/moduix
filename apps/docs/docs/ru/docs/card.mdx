## Справочник API

В Ark UI нет отдельного примитива card. Moduix строит этот компонент с помощью официального
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory), следуя рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[ref](https://ark-ui.com/docs/guides/ref).

## Анатомия

```text
Card.Root
├─ Card.Background (необязательное упрощение moduix)
├─ Card.Media (необязательное упрощение moduix)
├─ Card.Header
│  ├─ Card.Title
│  ├─ Card.Description
│  └─ Card.Action (необязательное упрощение moduix)
├─ Card.Body
└─ Card.Footer (необязательно)
```

`Card` и `Card.Root` — один и тот же корневой компонент.

| Часть                | Назначение                                                                                     |
| -------------------- | ---------------------------------------------------------------------------------------------- |
| `Card` / `Card.Root` | Корневой контейнер со свойствами `size`, `variant` и `asChild`.                                |
| `Card.Background`    | Необязательный полнофоновый слой для декоративного медиа.                                      |
| `Card.Media`         | Необязательная обёртка для медиа от края до края с предсказуемым скруглением верхних углов.     |
| `Card.Header`        | Компоновка заголовка, описания и необязательного действия в конце строки.                       |
| `Card.Body`          | Основная область содержимого.                                                                  |
| `Card.Footer`        | Переносимая строка действий или метаданных.                                                     |
| `Card.Title`         | Часть заголовка. По умолчанию рендерит `h3`; для другого уровня используйте `asChild`.          |
| `Card.Description`   | Вспомогательный текст.                                                                         |
| `Card.Action`        | Слот moduix для компоновки действия в заголовке.                                                |
| `Card.Link`          | Растянутая ссылка moduix для навигационной карточки, которая также содержит отдельные действия. |

## Композиция

### Рекомендуемая композиция

Используйте `<Card />`, `Card.Header`, `Card.Title`, `Card.Description`, `Card.Body` и `Card.Footer`.
Оберните начальное медиа в `Card.Media`, если оно должно доходить до краёв карточки без собственного обрезания.
Используйте `Card.Background` для декоративного изображения за всей карточкой; контраст добавляйте
в стилях приложения.
По умолчанию корневой компонент использует `size="md"` и `variant="outline"`.

### Когда нужна собственная композиция

Используйте `asChild`, когда DOM-узлом части должен быть единственный семантический дочерний элемент. Композиция Ark
требует ровно один дочерний элемент. Корневой элемент-ссылка не должен содержать вложенные кнопки, поля ввода или ссылки.

Используйте `Card.Link` внутри заголовка, когда карточке нужна ссылка по всей поверхности и она также содержит
независимые элементы управления. `Card.Link` реализует паттерн растянутой ссылки: видимая ссылка остаётся в заголовке,
а её область нажатия распространяется на всю карточку, не перекрывая отдельные интерактивные элементы.
`Card.Action` отвечает только за компоновку и не создаёт ARIA-связей.

| Ситуация                                                                                       | Рекомендуемый API                                                |
| ---------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| Вся карточка является одной ссылкой и не содержит вложенных элементов управления.              | `Card asChild` с корневым элементом `<a>`                         |
| Карточка открывает страницу, но также содержит кнопки, меню или другие независимые действия.    | `Card.Link` внутри `Card.Title`, при необходимости с `Card.Action` |
| Карточка только объединяет содержимое и не выполняет навигацию.                                 | Обычная композиция `Card` без растянутой ссылки                   |

### Свойства по умолчанию

| Часть       | Свойство  | По умолчанию | Значения                              |
| ----------- | --------- | ----------- | ------------------------------------- |
| `Card.Root` | `size`    | `'md'`      | `'sm' \| 'md' \| 'lg'`                |
| `Card.Root` | `variant` | `'outline'` | `'elevated' \| 'outline' \| 'subtle'` |

### Особенности поведения

- По умолчанию корневой компонент рендерит презентационный `div` и передаёт ref отрендеренному элементу.
- Все части принимают нативные свойства, `className`, `style` и свойство `asChild` фабрики Ark.
- `Card.Media` — необязательная удобная обёртка. Не используйте её, если нужны собственное оформление медиа или расположение не в начале карточки.
- `Card.Background` — необязательное упрощение для декоративного медиа на всю карточку. Оставляйте у
  такого изображения `alt=""`; если изображению нужен альтернативный текст, используйте `Card.Media`.
- `Card.Title` по умолчанию рендерит `h3`.
- Интерактивные корневые элементы, созданные с `asChild`, и `Card.Link` получают одинаковое настраиваемое кольцо `:focus-visible`.
- Card не управляет состоянием, колбэками, клавиатурным поведением, провайдером, контекстом или скрытым полем ввода.
- `Card.Body` сбрасывает внешние отступы первого и последнего непосредственных дочерних элементов.
- `--moduix-card-spacing`, `--moduix-card-spacing-sm` и `--moduix-card-spacing-lg` управляют общими внутренними отступами и интервалами между разделами, не заменяя более узкие переопределения `--moduix-card-*`.

### Хуки стилизации

- Каждая часть предоставляет `data-scope="card"` и соответствующий `data-part`.
- Стабильные хуки moduix: `data-slot="card-root"`, `card-background`, `card-media`, `card-header`, `card-body`,
  `card-footer`, `card-title`, `card-description`, `card-action` и `card-link`.
- Корневой компонент предоставляет `data-size="sm | md | lg"` и
  `data-variant="elevated | outline | subtle"`.
- Общие переопределения `--moduix-card-bg`, `--moduix-card-color`, `--moduix-card-border-*` и
  `--moduix-card-shadow` имеют приоритет над соответствующими переменными отдельных вариантов.
- Card не имеет атрибутов интерактивного состояния, поскольку не управляет состоянием или поведением.
