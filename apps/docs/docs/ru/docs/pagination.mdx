## Анатомия

```text
Pagination
├─ Pagination.FirstTrigger (optional)
├─ Pagination.PrevTrigger
├─ Pagination.Items (recommended)
├─ Pagination.Context (advanced render-prop access)
│  ├─ Pagination.Item
│  └─ Pagination.Ellipsis
├─ Pagination.NextTrigger
└─ Pagination.LastTrigger (optional)

Pagination.RootProvider
└─ то же дерево триггеров, элементов, многоточия и контекста, подключённое к usePagination()
```

|Часть|Роль|
| --------------------------------- | ------------------------------------------------------------------ |
|`Pagination`|Корень навигации, которому принадлежит страница и состояние размера страницы.|
|`Pagination.RootProvider`|Соединяет детали с состоянием, созданным с помощью `Pagination.usePagination()`.|
|`Pagination.Items`|Отрисовывает стандартные вычисляемые элементы страницы и эллипсы.|
|`Pagination.Context`|Считывает корневое состояние и помощников через опору рендеринга Ark.|
|`Pagination.usePagination`|Создает состояние разбиения на страницы Ark вне отображаемого корня.|
|`Pagination.usePaginationContext`|Считывает состояние нумерации страниц Ark от потомка.|
|`Pagination.Item`|Интерактивный элемент страницы. Получает `{ type: 'page', value }`.|
|`Pagination.Ellipsis`|Неинтерактивный маркер свернутого диапазона с обязательным `index`.|
|`Pagination.PrevTrigger`|Переходит на предыдущую страницу и отключается в начале.|
|`Pagination.NextTrigger`|Переходит на следующую страницу и отключается в конце.|
|`Pagination.FirstTrigger`|Переходит на первую страницу и отключается при запуске.|
|`Pagination.LastTrigger`|Переходит на последнюю страницу и отключается в конце.|

## Композиция

### Рекомендуемая композиция

`Pagination.Root` управляет поведением клавиатуры, текущей страницей, размером страницы, состоянием отключенного триггера, диапазоном страниц.
расчет и доступные метки. Используйте `count` для общего количества элементов данных, а не для количества.
страниц. Соедините его с `pageSize` или `defaultPageSize`, чтобы Арк мог вычислить `totalPages`.

Используйте `Pagination.Items` для стандартного списка страниц. Он отображает текущий массив Ark `pages` с помощью
`Pagination.Item` и `Pagination.Ellipsis`, сохраняя выбранное состояние, метки и обработчики.

### Когда нужна собственная композиция

Используйте `Pagination.Context`, если элементы страниц или соседние элементы управления требуют собственного
отображения. Чтобы создать состояние вне дерева пагинации, используйте `Pagination.usePagination()` с
`Pagination.RootProvider`. Дочерний компонент может прочитать то же состояние через
`Pagination.usePaginationContext()`. Задайте `type="link"` и `getPageUrl(details)`, если номера страниц должны
отображаться как навигационные ссылки.

### Свойства по умолчанию

| Свойство          | По умолчанию | Примечание                                                        |
| ----------------- | ------------ | ----------------------------------------------------------- |
|`aria-label`|`Pagination`|Корневое значение Moduix по умолчанию для навигационного ориентира.|
|`defaultPage`| `1`          |Начальная активная страница в неуправляемом режиме.|
|`defaultPageSize`| `10`         |Начальное количество элементов на странице в неуправляемом режиме.|
|`siblingCount`| `1`          |Страницы Ark отображаются рядом с активной страницей.|
|`boundaryCount`| `1`          |Страницы Ark отображаются в начале и конце диапазона страниц.|
|`type`|`button`|Используйте `link` вместе с `getPageUrl(details)` для ссылок.|

### Особенности поведения

Для неуправляемого состояния используйте `defaultPage` и `defaultPageSize`, а для управляемого — `page`, `pageSize`,
`onPageChange(details)` и `onPageSizeChange(details)`. Callback-функции получают объекты Ark `details`; текущие
значения находятся в `details.page` и `details.pageSize`. Ark сохраняет клавиатурное поведение, семантику выбранного
элемента, отключённое состояние кнопок, `ids`, `asChild`, переводы и создание URL для ссылок.

### Хуки стилизации

- `data-scope="pagination"` и `data-part="item"` на `Pagination.Item`
- `data-scope="pagination"` и `data-part="prev-trigger"` на `Pagination.PrevTrigger`
- `data-scope="pagination"` и `data-part="next-trigger"` на `Pagination.NextTrigger`
- `data-scope="pagination"` и краевые части триггера на первом и последнем триггерах
- `data-selected` на активном элементе страницы
- `data-disabled` о недоступных триггерах
- `data-slot="pagination-root"`, `pagination-root-provider`, `pagination-item`,
`pagination-ellipsis` и специальные слоты для переопределений Moduix.
