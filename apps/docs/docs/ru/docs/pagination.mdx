## Анатомия

```text
Pagination
├─ Pagination.FirstTrigger (необязательно)
├─ Pagination.PrevTrigger
├─ Pagination.Items (рекомендуется)
├─ Pagination.Context (расширенный доступ через render prop)
│  ├─ Pagination.Item
│  └─ Pagination.Ellipsis
├─ Pagination.NextTrigger
└─ Pagination.LastTrigger (необязательно)

Pagination.RootProvider
└─ те же триггеры, элементы, многоточия и контекст, подключённые к usePagination()
```

| Часть                             | Роль                                                                  |
| --------------------------------- | --------------------------------------------------------------------- |
| `Pagination`                      | Корень навигации, которому принадлежит состояние страницы и её размера. |
| `Pagination.RootProvider`         | Подключает части к состоянию, созданному `Pagination.usePagination()`. |
| `Pagination.Items`                | Отображает стандартные вычисленные элементы страниц и многоточия.    |
| `Pagination.Context`              | Передаёт состояние корня и его методы в render prop Ark.             |
| `Pagination.usePagination`        | Создаёт состояние пагинации Ark вне отображаемого корня.             |
| `Pagination.usePaginationContext` | Читает состояние пагинации Ark из потомка.                           |
| `Pagination.Item`                 | Интерактивный элемент страницы; получает `{ type: 'page', value }`.  |
| `Pagination.Ellipsis`             | Неинтерактивный маркер свёрнутого диапазона с обязательным `index`.  |
| `Pagination.PrevTrigger`          | Переходит на предыдущую страницу и отключается в начале.             |
| `Pagination.NextTrigger`          | Переходит на следующую страницу и отключается в конце.               |
| `Pagination.FirstTrigger`         | Переходит на первую страницу и отключается в начале.                 |
| `Pagination.LastTrigger`          | Переходит на последнюю страницу и отключается в конце.               |

## Композиция

### Рекомендуемая композиция

`Pagination.Root` управляет клавиатурным взаимодействием, текущей страницей, размером страницы,
неактивным состоянием триггеров, расчётом диапазона страниц и доступными метками. Используйте `count`
для общего числа элементов данных, а не числа страниц. Передайте также `pageSize` или `defaultPageSize`,
чтобы Ark мог вычислить `totalPages`.

Для стандартного списка страниц используйте `Pagination.Items`. Он отображает текущий массив Ark `pages`
через `Pagination.Item` и `Pagination.Ellipsis`, сохраняя выбранное состояние, метки и обработчики.

### Когда нужна собственная композиция

Используйте `Pagination.Context`, когда элементам страницы или соседним элементам управления нужно
собственное отображение. Если состоянием нужно владеть вне отображаемого дерева пагинации, используйте
`Pagination.usePagination()` с `Pagination.RootProvider`. Потомки могут прочитать это же состояние через
`Pagination.usePaginationContext()`. Чтобы показывать номера страниц как навигационные ссылки, задайте
`type="link"` и `getPageUrl(details)`.

### Свойства по умолчанию

| Свойство          | По умолчанию | Примечание                                                        |
| ----------------- | ------------ | ----------------------------------------------------------------- |
| `aria-label`      | `Pagination` | Значение Moduix по умолчанию для навигационного ориентира.        |
| `defaultPage`     | `1`          | Начальная активная страница в неуправляемом режиме.               |
| `defaultPageSize` | `10`         | Начальное число элементов на странице в неуправляемом режиме.     |
| `siblingCount`    | `1`          | Число страниц Ark рядом с активной страницей.                     |
| `boundaryCount`   | `1`          | Число страниц Ark в начале и конце диапазона.                     |
| `type`            | `button`     | Для ссылок используйте `link` вместе с `getPageUrl(details)`.     |

### Особенности поведения

Для неуправляемого состояния используйте `defaultPage` и `defaultPageSize`; для управляемого — `page`,
`pageSize`, `onPageChange(details)` и `onPageSizeChange(details)`. Функции обратного вызова получают
объекты Ark `details`; текущие значения доступны в `details.page` и `details.pageSize`. Ark сохраняет
клавиатурное поведение, семантику выбранного элемента, неактивное состояние триггеров, `ids`, `asChild`,
переводы и генерацию URL для ссылок.

### Хуки стилизации

- `data-scope="pagination"` и `data-part="item"` на `Pagination.Item`
- `data-scope="pagination"` и `data-part="prev-trigger"` на `Pagination.PrevTrigger`
- `data-scope="pagination"` и `data-part="next-trigger"` на `Pagination.NextTrigger`
- `data-scope="pagination"` и части крайних триггеров на первом и последнем триггерах
- `data-selected` на активном элементе страницы
- `data-disabled` на недоступных триггерах
- `data-slot="pagination-root"`, `pagination-root-provider`, `pagination-item`,
  `pagination-ellipsis` и специальные слоты триггеров для переопределений Moduix
