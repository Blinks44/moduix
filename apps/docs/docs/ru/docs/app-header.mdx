## Адаптация для приложения

Рецепт использует настоящие ссылки для каждого действия навигации и `aria-current="page"` для активного
пункта назначения. Замените фикстуры значениями из роутера и состояния учётной записи.

| Замените эту фикстуру | Значением из вашего приложения |
| --------------------- | ------------------------------ |
| Orbit и Acme Studio | Ссылкой на главную страницу продукта и текущим рабочим пространством |
| Навигационные ссылки | Ссылками роутера; задавайте `aria-current="page"` по текущему маршруту |
| Поиск и Новый проект | Настоящими пунктами назначения или элементами управления, открывающими поиск и создание |
| Изображение и данные учётной записи | Данными аутентифицированного пользователя и URL изображения, принадлежащим приложению |
| Ссылки меню учётной записи | Маршрутами профиля, настроек, справки и другими маршрутами, которые действительно нужны пользователям |

Если роутер предоставляет компонент Link, передайте его через `Button asChild` или `Menu.Item asChild`,
а не вкладывайте один интерактивный элемент в другой. Сохраняйте fallback аватара, чтобы элемент управления учётной записью
оставался узнаваемым, пока загружается изображение или когда изображения нет.

## Адаптивное поведение

Ниже 48rem центрированная навигация перемещается в настоящий `Menu`, а не исчезает. Ниже
36rem второстепенные подписи сворачиваются, при этом каждое действие сохраняет доступное имя. Для более глубокой
навигации с группами или вложенными маршрутами замените компактное меню рецептом
[Мобильная навигация с выдвижной панелью](/docs/mobile-drawer-navigation).
