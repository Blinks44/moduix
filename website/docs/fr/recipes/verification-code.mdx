# Code de vérification

Vérifiez une adresse e-mail avec un code à usage unique de six chiffres. `PinInput` apporte le champ de
formulaire natif, la navigation au clavier et le remplissage automatique OTP sur mobile. Envoyez le formulaire
avec moins de six chiffres pour afficher l’erreur intégrée au champ.

## Dans une route

Affichez `VerificationCode` après l’envoi du code par e-mail et passez-lui le véritable gestionnaire d’envoi
du formulaire. `onSubmit` reçoit l’événement natif du formulaire : lisez `new FormData(event.currentTarget)`
et vérifiez la valeur `code` auprès du serveur. Remplacez le lien `/sign-in` par la route de l’application.

La prévisualisation ne contient volontairement aucun serveur de vérification. Après la saisie de six chiffres,
elle exécute son gestionnaire d’envoi vide ; dans la recette copiée, c’est le gestionnaire que vous fournissez
qui sera appelé.

Tant que la requête n’est pas terminée, désactivez les envois en double. Si le code est incorrect,
conservez les chiffres saisis et affichez l’erreur sur le champ ; s’il est expiré, expliquez qu’il faut
en demander un nouveau. N’autorisez le renvoi qu’après un court délai, annoncez l’envoi du nouveau code
et laissez le serveur appliquer la véritable limitation de débit. Ne considérez jamais le compte à rebours
côté client comme une preuve d’autorisation.
