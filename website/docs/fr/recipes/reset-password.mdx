# Nouveau mot de passe

L’utilisateur peut choisir un nouveau mot de passe après avoir ouvert un lien de réinitialisation
vérifié. La validation native vérifie que les deux champs sont remplis ; contrôlez que les mots de
passe correspondent dans le gestionnaire `onSubmit`.

## Dans une route

Affichez `ResetPassword` dans la route atteinte depuis un lien de réinitialisation vérifié et passez-lui le
véritable gestionnaire d’envoi du formulaire. Remplacez le lien `/sign-in` par la route de l’application.

Vérifiez le jeton de réinitialisation sur le serveur avant d’enregistrer le mot de passe. Présentez un jeton
expiré ou déjà utilisé comme un état de page distinct, avec un lien pour demander un nouvel e-mail. Pendant
l’envoi, désactivez les requêtes en double, validez le champ de confirmation et affichez une erreur serveur
sans risque dans le formulaire. Après la réussite, invalidez le jeton et dirigez l’utilisateur vers la
connexion ou une session authentifiée, selon la politique du produit.
