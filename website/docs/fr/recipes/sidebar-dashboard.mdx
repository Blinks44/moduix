# Tableau de bord

Créez un espace de travail pour ordinateur avec une barre latérale réductible et redimensionnable,
ainsi qu’une vue d’ensemble simple des indicateurs clés. `Sidebar` gère la réduction, le
redimensionnement au clavier et les infobulles lorsque la navigation est réduite. L’élément Projects
illustre aussi une navigation imbriquée, et le pied de page contient un menu d’espace de travail.

## Dans une route

Remplacez les liens, les libellés et le contenu de démonstration par vos routes et vos données. Cette
recette est pensée pour ordinateur ; adaptez la navigation responsive, les menus du compte et les
notifications à votre application.

Marquez la destination active avec `aria-current="page"`. Si le composant Link de votre routeur gère
la navigation, passez-le via `asChild`. Ne mémorisez la largeur réduite que si elle est utile aux
personnes qui reviennent ; lisez le stockage du navigateur après l’hydratation et gardez un état par
défaut utilisable sans lui.
