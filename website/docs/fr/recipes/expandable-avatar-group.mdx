# Groupe d’avatars extensible

Utilisez cette recette pour afficher une petite équipe dans un espace réduit tout en permettant
d’identifier facilement chaque personne. Survolez un avatar ou placez le focus dessus pour écarter le
groupe et afficher le nom et le rôle correspondants.

Cette recette est une composition à copier, et non un composant `ExpandableAvatarGroup` exporté par
moduix. Elle combine `Avatar` et `Tooltip`. Installez ces deux composants, copiez le code
et les styles ci-dessous, puis remplacez les membres d’exemple par les données de votre application.

L’aperçu interactif utilise le paquet React. Les onglets de code présentent des implémentations natives pour React et Solid avec les mêmes styles.

## Personnaliser la recette

Remplacez les données d’exemple de `members` par celles de votre application et conservez un ordre
stable. Utilisez une URL d’image fournie par votre application pour chaque membre. `AvatarFallback` affiche
les initiales pendant le chargement de l’image ou lorsqu’elle n’est pas disponible. Les parties composées
sont décrites dans la documentation d’[Avatar](/docs/avatar) et de [Tooltip](/docs/tooltip).

La recette rend chaque membre sous la forme d’un bouton natif. `TooltipTrigger asChild` permet à
l’infobulle de réutiliser ce bouton sans ajouter de conteneur, tandis que `TooltipBody` affiche le
nom et le rôle de la personne. Le `aria-label` du bouton contient ces deux informations, car l’image
utilise `alt=""` et l’infobulle est complémentaire. Gardez son contenu court et non indispensable.

Si un clic sur un membre doit ouvrir une page ou déclencher une action, reliez le bouton à ce
comportement ou remplacez-le par le contrôle sémantique approprié. Conservez son nom accessible.

Utilisez `role="group"` avec un libellé utile pour le groupe. Pour une grande équipe, affichez
seulement quelques membres, puis ajoutez un bouton `+N` qui ouvre une liste complète avec recherche.

L’animation repose uniquement sur le CSS. Le bouton actif se soulève légèrement et les autres
boutons s’écartent pour lui faire de la place. La règle `prefers-reduced-motion: reduce` fournie
désactive les transitions, mais conserve le déplacement instantané. Si votre politique d’accessibilité
doit aussi supprimer ce déplacement, annulez les transformations dans cette requête média.
