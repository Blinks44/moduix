# Galerie

Un carrousel de contenu à la une avec diapositives voisines partiellement visibles, navigation latérale, panneau
de texte flouté et indicateurs qui se remplissent pendant le délai de lecture automatique. Il n’utilise que les
parties de `Carousel` : `Carousel.Context` transmet l’état de lecture à l’animation CSS, et les flèches comme les
indicateurs relancent la lecture sans ajouter de bouton distinct.

## Dans une page

Remplacez les images et le texte des diapositives par votre contenu. La durée de l’animation CSS doit correspondre
à `autoplay.delay`, afin que l’indicateur se remplisse exactement jusqu’à l’apparition de la diapositive suivante.
Après une navigation manuelle, les callbacks reportent `api.play()` à l’image suivante : Ark traite d’abord le
changement de diapositive qui met la lecture automatique en pause, puis un nouvel intervalle démarre sans contrôle
distinct. Ark met la lecture automatique en pause lorsque le document est masqué ; la recette appelle la méthode
publique `api.play()` lorsqu’il redevient visible.
