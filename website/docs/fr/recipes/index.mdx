# Recettes

Les recettes sont des exemples prêts à copier-coller pour des modèles d’interface et des parcours
produit courants. Copiez le composant et le CSS depuis la page de la recette, installez les composants
moduix qu’elle utilise, puis adaptez ses données et son comportement à votre application.

Utilisez le tiroir mobile seul ou associez-le à la barre latérale pour ordinateur lorsque les mêmes
destinations doivent fonctionner aux deux points de rupture. L’en-tête d’application peut se placer
au-dessus de l’une ou l’autre structure.

Chaque recette s’arrête volontairement là où commencent vos routes, votre API, vos règles
d’autorisation et vos outils d’analyse. La page signale ces raccordements à la production afin que
l’interface copiée ne prétende pas implémenter le comportement du produit.
