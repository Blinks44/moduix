# Recettes

Vous trouverez ici des exemples prêts à copier-coller pour des modèles d’interface et des parcours produit
courants. Reprenez le composant et le CSS depuis une recette, installez les composants moduix nécessaires,
puis adaptez les données et le comportement à votre application.

Chaque recette s’arrête là où commencent vos routes, votre API, vos règles d’autorisation et vos outils
d’analyse. La page indique ce qu’il faut brancher en production afin que l’interface copiée ne laisse pas
croire que toute la logique produit est déjà implémentée.
