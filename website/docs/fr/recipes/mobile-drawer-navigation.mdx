# Navigation mobile

Ajoutez à votre version mobile une navigation compacte avec un tiroir fixé au bord de l’écran. Le tiroir se
ferme après la sélection d’un lien, tandis que Drawer gère le focus, la touche Escape et l’arrière-plan de
façon accessible.

## Dans une route

Remplacez les liens et le contenu de démonstration par vos routes et vos données. Placez chaque lien de
navigation dans `Drawer.CloseTrigger` afin que le tiroir mobile se ferme automatiquement après la sélection.

Si le composant Link de votre routeur doit gérer la navigation, passez-le via `asChild` et marquez le lien
actuel avec `aria-current="page"`. Gardez le déclencheur visible sur mobile ; sur les écrans larges,
proposez les mêmes destinations dans un en-tête permanent ou dans le
[Tableau de bord avec barre latérale](/recipes/sidebar-dashboard). N’affichez pas deux copies focalisables
de la même navigation à la même largeur d’écran.
