# Connexion

Un formulaire compact avec e-mail et mot de passe, validation native, option « Se souvenir de moi » et liens
clairs pour récupérer l’accès au compte. L’authentification n’y est volontairement pas intégrée : passez
`onSubmit` pour y brancher votre propre action ou API.

## Dans une route

Affichez `LoginSimple` dans la route qui gère l’authentification et passez-lui le véritable gestionnaire
d’envoi du formulaire. Remplacez les liens `/forgot-password` et `/sign-up` par les routes de l’application.

| Résultat | Comportement de la route |
| -------- | ------------------------ |
| Envoi | Désactivez les envois en double et attribuez au bouton le libellé `Signing in…`. |
| Informations incorrectes | Affichez une seule erreur de formulaire, sans préciser ce qui est incorrect. |
| Erreur réseau | Conservez l’e-mail et proposez de réessayer ; n’effacez pas le mot de passe sans nécessité. |
| Réussite | Remplacez l’entrée de l’historique ou redirigez vers une page sûre, choisie par l’application. |

Validez sur le serveur toute URL `returnTo` ou de redirection avant d’y naviguer.
