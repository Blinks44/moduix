## Exemple de base

Utilisez la composition standard pour un menu ouvert par un bouton, un déclencheur personnalisé ou un déclencheur contextuel. Le composant racine gère la navigation au clavier, la recherche par saisie, le focus et la fermeture. Attribuez une valeur `value` stable à chaque élément afin de préserver la sélection et la recherche par saisie lorsque la liste change.


Ce composant est disponible pour React et Solid, avec des variantes CSS Modules et Tailwind. L’aperçu utilise React avec CSS Modules ; les onglets affichent le code natif correspondant à chaque framework.

## Anatomie

```text
Menu / Menu.Root
├─ Menu.Trigger
│  ├─ Menu.TriggerIcon
│  └─ Menu.Indicator
├─ Menu.ContextTrigger
└─ Sous-arbre du calque (placé automatiquement dans un portail)
   └─ Menu.Positioner
      └─ Menu.Content
         ├─ Menu.Arrow
         │  └─ Menu.ArrowTip
         ├─ Menu.Item
         │  ├─ Menu.ItemText
         │  │  ├─ Menu.ItemTextIcon
         │  │  └─ Menu.ItemTextLabel
         │  └─ Menu.ItemShortcut
         ├─ Menu.CheckboxItem
         │  └─ Menu.ItemIndicator
         ├─ Menu.RadioItemGroup
         │  └─ Menu.RadioItem
         ├─ Menu.ItemGroup
         │  └─ Menu.ItemGroupLabel
         ├─ Menu.Separator
         └─ Menu
            └─ Menu.TriggerItem
               └─ Menu.TriggerItemIcon
```

| Partie | Rôle |
| --- | --- |
| `Menu` / `Menu.Root` | Composant racine qui gère l’ouverture, le positionnement, la recherche par saisie, le focus et la fermeture. |
| `Menu.RootProvider` | Relie le menu à une instance d’état créée avec `useMenu`. |
| `Menu.Trigger` | Bouton qui ouvre le menu. Utilisez `asChild` pour fournir un autre élément sémantique. |
| `Menu.TriggerIcon` | Conteneur pour l’icône du déclencheur. Un chevron par défaut est rendu sans enfant. |
| `Menu.Indicator` | Indicateur du déclencheur qui reflète son état, généralement affiché comme un chevron. |
| `Menu.ContextTrigger` | Déclencheur pour les menus contextuels ouverts par clic droit ou appui prolongé. |
| `Menu.Positioner` | Positionne le calque flottant du menu. |
| `Menu.Content` | Surface de la fenêtre contextuelle avec le rôle `menu` et sa collection d’éléments. |
| `Menu.Arrow` / `Menu.ArrowTip` | Flèche facultative qui relie visuellement la fenêtre contextuelle à son déclencheur. |
| `Menu.Item` | Élément de commande standard. |
| `Menu.CheckboxItem` | Élément doté d’un état booléen indépendant. |
| `Menu.RadioItemGroup` / `Menu.RadioItem` | Groupe et éléments permettant de choisir une seule valeur. |
| `Menu.ItemIndicator` | Indicateur de sélection des éléments avec case à cocher et des options radio. |
| `Menu.ItemText` et composants utilitaires de texte | Composants utilitaires pour composer le texte d’un élément avec une icône et un libellé. |
| `Menu.ItemShortcut` | Conteneur pour un raccourci clavier ou une autre indication placée à droite. |
| `Menu.ItemGroup` / `Menu.ItemGroupLabel` | Groupe et libellé pour des éléments associés. |
| `Menu.Separator` | Séparateur entre des groupes d’éléments. |
| `Menu.TriggerItem` / `Menu.TriggerItemIcon` | Élément et icône pour ouvrir un menu imbriqué. |
| `Menu.ItemContext` | Fournit l’état de l’élément à son contenu. |

## Composition

Utilisez `defaultOpen` pour un menu non contrôlé. Lorsque l’ouverture ou l’élément mis en surbrillance est géré par une autre partie de l’application, passez `open` ou `highlightedValue` avec le callback correspondant. Utilisez `useMenu()` avec `Menu.RootProvider` lorsque le store doit être créé en dehors de l’arbre rendu ; ne rendez pas une seconde racine `Menu` pour le même store.

`Menu.Positioner` et `Menu.Content` sont des parties distinctes, mais le positionneur est automatiquement rendu dans un portail. Définissez `portalled={false}` dans une boîte de dialogue ou un conteneur défilant, et utilisez `positioning={{ strategy: 'fixed', hideWhenDetached: true }}` lorsque ce conteneur peut défiler. Utilisez `asChild` avec exactement un enfant sémantique lorsqu’un trigger, un item ou l’hôte du contenu doit porter le nœud DOM. Un menu imbriqué est une autre racine `Menu` dans le contenu parent, avec ses propres parties `TriggerItem`, `Positioner` et `Content`.

### Points d’accroche CSS

Utilisez les attributs d’état d’Ark pour styliser le menu et ses éléments :

- Attributs Ark : `[data-scope='menu']`, `[data-part='trigger']`, `[data-part='indicator']`, `[data-part='content']`, `[data-part='item']`, `[data-type='checkbox' | 'radio']`, `[data-state='open' | 'closed' | 'checked' | 'unchecked']`, `[data-current]`, `[data-highlighted]`, `[data-disabled]`, `[data-placement]` et `[data-side]`.
- Attributs moduix : `[data-slot='menu-trigger']`, `[data-slot='menu-trigger-icon']`, `[data-slot='menu-indicator']`, `[data-slot='menu-context-trigger']`, `[data-slot='menu-positioner']`, `[data-slot='menu-content']`, `[data-slot='menu-arrow']`, `[data-slot='menu-arrow-tip']`, `[data-slot='menu-item']`, `[data-slot='menu-trigger-item']`, `[data-slot='menu-trigger-item-icon']`, `[data-slot='menu-separator']`, `[data-slot='menu-item-group']`, `[data-slot='menu-item-group-label']`, `[data-slot='menu-radio-item-group']`, `[data-slot='menu-radio-item']`, `[data-slot='menu-checkbox-item']`, `[data-slot='menu-item-indicator']`, `[data-slot='menu-item-text']`, `[data-slot='menu-item-text-content']`, `[data-slot='menu-item-text-icon']`, `[data-slot='menu-item-text-label']`, `[data-slot='menu-item-shortcut']` et `[data-indicator-position='start' | 'end' | 'none']`.
- Variables de positionnement : `--reference-width`, `--available-width`, `--available-height`, `--transform-origin`, `--layer-index`, `--arrow-size` et `--arrow-background`.
