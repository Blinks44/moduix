## Exemple de base

Utilisez la composition standard pour un menu ouvert par un bouton, un déclencheur personnalisé ou un déclencheur contextuel. Le composant racine gère la navigation au clavier, la recherche par saisie, le focus et la fermeture. Attribuez une valeur `value` stable à chaque élément afin de préserver la sélection et la recherche par saisie lorsque la liste change.

| Partie | Rôle |
| --- | --- |
| `Menu` / `Menu.Root` | Composant racine qui gère l’ouverture, le positionnement, la recherche par saisie, le focus et la fermeture. |
| `Menu.RootProvider` | Relie le menu à une instance d’état créée avec `useMenu`. |
| `Menu.Trigger` | Bouton qui ouvre le menu. Utilisez `asChild` pour fournir un autre élément sémantique. |
| `Menu.TriggerIcon` | Conteneur pour l’icône du déclencheur. Un chevron par défaut est rendu sans enfant. |
| `Menu.Indicator` | Indicateur du déclencheur qui reflète son état, généralement affiché comme un chevron. |
| `Menu.ContextTrigger` | Déclencheur pour les menus contextuels ouverts par clic droit ou appui prolongé. |
| `Menu.Positioner` | Positionne le calque flottant du menu. |
| `Menu.Content` | Surface de la fenêtre contextuelle avec le rôle `menu` et sa collection d’éléments. |
| `Menu.Arrow` / `Menu.ArrowTip` | Flèche facultative qui relie visuellement la fenêtre contextuelle à son déclencheur. |
| `Menu.Item` | Élément de commande standard. |
| `Menu.CheckboxItem` | Élément doté d’un état booléen indépendant. |
| `Menu.RadioItemGroup` / `Menu.RadioItem` | Groupe et éléments permettant de choisir une seule valeur. |
| `Menu.ItemIndicator` | Indicateur de sélection des éléments avec case à cocher et des options radio. |
| `Menu.ItemText` et composants utilitaires de texte | Composants utilitaires pour composer le texte d’un élément avec une icône et un libellé. |
| `Menu.ItemShortcut` | Conteneur pour un raccourci clavier ou une autre indication placée à droite. |
| `Menu.ItemGroup` / `Menu.ItemGroupLabel` | Groupe et libellé pour des éléments associés. |
| `Menu.Separator` | Séparateur entre des groupes d’éléments. |
| `Menu.TriggerItem` / `Menu.TriggerItemIcon` | Élément et icône pour ouvrir un menu imbriqué. |
| `Menu.ItemContext` | Fournit l’état de l’élément à son contenu. |

## Composition

`Menu` place automatiquement `Menu.Positioner` dans un portail. Définissez `portalled={false}` pour afficher le menu dans son conteneur courant, ou passez `portalRef` pour utiliser un conteneur de portail précis. `Menu.Positioner` et `Menu.Content` restent explicites, ce qui permet de les styliser et de les composer séparément.

### Composition recommandée

Gardez la structure de la fenêtre contextuelle visible dans votre code. `Menu.Content` est la partie de contenu Ark, tandis que `Menu.Positioner` gère le positionnement séparément.

```tsx
import { Button } from '@moduix/react/button';
import { Menu } from '@moduix/react/menu';

export function ActionsMenu() {
  return (
    <Menu positioning={{ placement: 'bottom-start', gutter: 8 }}>
      <Menu.Trigger asChild>
        <Button>
          Actions
          <Menu.Indicator />
        </Button>
      </Menu.Trigger>
      <Menu.Positioner>
        <Menu.Content>
          <Menu.Item value="edit">Edit</Menu.Item>
        </Menu.Content>
      </Menu.Positioner>
    </Menu>
  );
}
```

### Quand créer une composition personnalisée

Utilisez `asChild` lorsqu’une partie du déclencheur, de l’élément ou du contenu doit être rendue avec un autre élément sémantique. Passez exactement un enfant sémantique afin qu’Ark puisse fusionner ses attributs ARIA, ses gestionnaires d’événements et sa ref. Pour les liens, placez `asChild` sur `Menu.Item` afin que l’ancre elle-même reçoive le comportement du menu. Pour fournir un conteneur personnalisé à la fenêtre contextuelle, placez-le sur `Menu.Content`.

Un menu imbriqué est une racine `Menu` standard placée dans le contenu du menu parent. Ajoutez-y `Menu.TriggerItem`, puis son propre `Menu.Positioner` et son propre `Menu.Content`.

### Propriétés par défaut

Par défaut, moduix monte le contenu de la fenêtre contextuelle à la première ouverture, puis le démonte après l’animation de sortie. Définissez `unmountOnExit={false}` pour conserver le contenu monté après sa première ouverture. Définissez `lazyMount={false}` et `unmountOnExit={false}` uniquement si le contenu doit être rendu immédiatement et rester monté.

| Propriété ou partie | Par défaut | Remarques |
| --- | --- | --- |
| `lazyMount` | `true` | Diffère le montage de la fenêtre contextuelle jusqu’à sa première ouverture. |
| `unmountOnExit` | `true` | Démonte la fenêtre contextuelle après son animation de sortie. |
| `closeOnSelect` | `true` | Valeur par défaut d’Ark. Passez `false` si l’utilisateur doit effectuer plusieurs sélections avant de fermer le menu. |
| `loopFocus` | `false` | Valeur par défaut d’Ark. Le focus clavier ne revient pas du dernier élément au premier. |
| `typeahead` | `true` | Valeur par défaut d’Ark. Les caractères saisis déplacent la mise en évidence vers l’élément correspondant. |
| `indicator` de `Menu.CheckboxItem` / `Menu.RadioItem` | `start` | Propriété propre à moduix qui contrôle la colonne de l’indicateur. Utilisez `end` ou `none` si nécessaire. |

### Comportement

- Contrôlez le menu avec `open`, `defaultOpen` et `onOpenChange(details)`. La fonction reçoit l’objet de détails d’Ark.
- Utilisez `value` pour identifier un élément. Utilisez `valueText` lorsque le texte affiché doit différer du texte utilisé par la recherche par saisie. N’attribuez pas d’`id` arbitraire aux éléments : Ark génère et utilise ces identifiants en interne.
- Utilisez `highlightedValue` et `onHighlightChange(details)` pour contrôler ou observer l’élément mis en évidence. Utilisez `present` uniquement lorsque le cycle de vie du contenu monté doit être contrôlé depuis l’extérieur.
- `onSelect(details)` sur la racine s’exécute pour chaque élément sélectionné. Des gestionnaires `onSelect` sont également disponibles au niveau des éléments.
- `Menu.CheckboxItem.onCheckedChange` reçoit le nouvel état booléen.
- `Menu.RadioItemGroup.onValueChange` reçoit un objet de détails. Lisez la valeur sélectionnée dans `details.value`.
- Pour plusieurs déclencheurs, utilisez `triggerValue`, `defaultTriggerValue` et `onTriggerValueChange(details)` lorsque le déclencheur actif doit être contrôlé ou observé.
- Utilisez `Menu.RootProvider` avec une instance créée par `useMenu` lorsque du code situé en dehors de l’arbre rendu doit accéder à l’API du menu. Ne rendez pas une seconde racine pour la même instance d’état.
- `Menu.Context`, `useMenuContext`, `Menu.ItemContext` et `useMenuItemContext` exposent l’état pour les compositions avancées.
- La racine place automatiquement `Menu.Positioner` dans un portail. Utilisez `portalled={false}` dans une boîte de dialogue ou un conteneur défilant. Si ce conteneur défile, ajoutez `positioning={{ strategy: 'fixed', hideWhenDetached: true }}`.
- `Menu.ContextTrigger` s’ouvre au clic droit et, sur les appareils tactiles ou avec un stylet, après un appui prolongé d’environ 700 ms.
- Les animations d’ouverture et de fermeture respectent `prefers-reduced-motion`.
- moduix ajoute `tone="destructive"` pour les actions destructives ainsi que des composants utilitaires comme `Menu.TriggerIcon`, `Menu.TriggerItemIcon`, `Menu.ItemTextContent`, `Menu.ItemTextIcon`, `Menu.ItemTextLabel` et `Menu.ItemShortcut`.

### Points d’accroche CSS

Utilisez les attributs d’état d’Ark pour styliser le menu et ses éléments :

- Attributs Ark : `[data-scope='menu']`, `[data-part='trigger']`, `[data-part='indicator']`, `[data-part='content']`, `[data-part='item']`, `[data-type='checkbox' | 'radio']`, `[data-state='open' | 'closed' | 'checked' | 'unchecked']`, `[data-current]`, `[data-highlighted]`, `[data-disabled]`, `[data-placement]` et `[data-side]`.
- Attributs moduix : `[data-slot='menu-trigger']`, `[data-slot='menu-trigger-icon']`, `[data-slot='menu-indicator']`, `[data-slot='menu-context-trigger']`, `[data-slot='menu-positioner']`, `[data-slot='menu-content']`, `[data-slot='menu-arrow']`, `[data-slot='menu-arrow-tip']`, `[data-slot='menu-item']`, `[data-slot='menu-trigger-item']`, `[data-slot='menu-trigger-item-icon']`, `[data-slot='menu-separator']`, `[data-slot='menu-item-group']`, `[data-slot='menu-item-group-label']`, `[data-slot='menu-radio-item-group']`, `[data-slot='menu-radio-item']`, `[data-slot='menu-checkbox-item']`, `[data-slot='menu-item-indicator']`, `[data-slot='menu-item-text']`, `[data-slot='menu-item-text-content']`, `[data-slot='menu-item-text-icon']`, `[data-slot='menu-item-text-label']`, `[data-slot='menu-item-shortcut']` et `[data-indicator-position='start' | 'end' | 'none']`.
- Variables de positionnement : `--reference-width`, `--available-width`, `--available-height`, `--transform-origin`, `--layer-index`, `--arrow-size` et `--arrow-background`.
