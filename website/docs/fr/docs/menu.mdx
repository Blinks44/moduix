## Choisir le bon composant

Utilisez `Menu` pour des actions contextuelles dans une fenêtre contextuelle temporaire, comme des
commandes, des liens ou un menu contextuel. Utilisez `NavigationMenu` pour une navigation de site ou
de produit persistante, et `Dialog` pour les flux qui exigent toute l’attention de l’utilisateur.

## Exemple de base

Utilisez la composition standard pour un menu ouvert par un bouton, un déclencheur personnalisé ou un déclencheur contextuel. Le composant racine gère la navigation au clavier, la recherche par saisie, le focus et la fermeture. Attribuez une valeur `value` stable à chaque élément afin de préserver la sélection et la recherche par saisie lorsque la liste change.

Ne définissez pas d’`id` personnalisé sur `MenuItem` : Ark identifie les éléments par `value`, et un `id`
supplémentaire casse la recherche d’éléments, la navigation par saisie et la gestion du focus.

## Anatomie

```text
Menu
├─ MenuTrigger
│  ├─ MenuTriggerIcon
│  └─ MenuIndicator
├─ MenuContextTrigger
└─ Sous-arbre du calque (placé automatiquement dans un portail)
   └─ MenuPositioner
      └─ MenuContent
         ├─ MenuArrow
         │  └─ MenuArrowTip
         └─ MenuViewport
            ├─ MenuItem
            │  ├─ MenuItemText
            │  │  ├─ MenuItemTextIcon
            │  │  └─ MenuItemTextLabel
            │  └─ MenuItemShortcut
            ├─ MenuCheckboxItem
            │  └─ MenuItemIndicator
            ├─ MenuRadioItemGroup
            │  └─ MenuRadioItem
            ├─ MenuItemGroup
            │  └─ MenuItemGroupLabel
            ├─ MenuSeparator
            └─ Menu
               └─ MenuTriggerItem
                  └─ MenuTriggerItemIcon
```

| Partie | Rôle |
| --- | --- |
| `Menu` | Composant racine qui gère l’ouverture, le positionnement, la recherche par saisie, le focus et la fermeture. |
| `MenuRootProvider` | Relie le menu à une instance d’état créée avec `useMenu`. |
| `MenuTrigger` | Bouton qui ouvre le menu. Utilisez `asChild` pour fournir un autre élément sémantique. |
| `MenuTriggerIcon` | Conteneur pour l’icône du déclencheur. Un chevron par défaut est rendu sans enfant. |
| `MenuIndicator` | Indicateur du déclencheur qui reflète son état, généralement affiché comme un chevron. |
| `MenuContextTrigger` | Déclencheur pour les menus contextuels ouverts par clic droit ou appui prolongé. |
| `MenuPositioner` | Positionne le calque flottant du menu. |
| `MenuContent` | Surface de la fenêtre contextuelle avec le rôle `menu` et sa collection d’éléments. |
| `MenuViewport` | Conteneur de défilement explicite autour de la collection d’éléments. |
| `MenuArrow` / `MenuArrowTip` | Flèche facultative qui relie visuellement la fenêtre contextuelle à son déclencheur. |
| `MenuItem` | Élément de commande standard. |
| `MenuCheckboxItem` | Élément doté d’un état booléen indépendant. |
| `MenuRadioItemGroup` / `MenuRadioItem` | Groupe et éléments permettant de choisir une seule valeur. |
| `MenuItemIndicator` | Indicateur de sélection des éléments avec case à cocher et des options radio. |
| `MenuItemText` et composants utilitaires de texte | Composants utilitaires pour composer le texte d’un élément avec une icône et un libellé. |
| `MenuItemShortcut` | Conteneur pour un raccourci clavier ou une autre indication placée à droite. |
| `MenuItemGroup` / `MenuItemGroupLabel` | Groupe et libellé pour des éléments associés. |
| `MenuSeparator` | Séparateur entre des groupes d’éléments. |
| `MenuTriggerItem` / `MenuTriggerItemIcon` | Élément et icône pour ouvrir un menu imbriqué. |
| `MenuItemContext` | Fournit l’état de l’élément à son contenu. |

## Composition

Utilisez `defaultOpen` pour un menu non contrôlé. Lorsque l’ouverture ou l’élément mis en surbrillance est géré par une autre partie de l’application, passez `open` ou `highlightedValue` avec la fonction de rappel correspondante. Utilisez `useMenu()` avec `MenuRootProvider` lorsque le store doit être créé en dehors de l’arbre rendu ; ne rendez pas une seconde racine `Menu` pour le même store.

`MenuPositioner`, `MenuContent` et `MenuViewport` sont des parties distinctes, mais le positionneur est automatiquement rendu dans un portail. Définissez `portalled={false}` dans une boîte de dialogue ou un conteneur défilant, et utilisez `positioning={{ strategy: 'fixed', hideWhenDetached: true }}` lorsque ce conteneur peut défiler. Utilisez `asChild` avec exactement un enfant sémantique lorsqu’un déclencheur, un élément ou l’hôte du contenu doit porter le nœud DOM. En Solid, assignez la ref à l’élément créé dans la fonction de rendu `asChild`, car une ref posée sur une partie `Menu` elle-même n’est pas transmise par ce chemin de composition. Dans `MenuContent`, entourez les éléments défilants avec `MenuViewport`. Conservez l’éventuel `MenuArrow` comme enfant direct de `MenuContent`, à côté du viewport, afin qu’il ne soit pas rogné pendant le défilement. Un menu imbriqué est une autre racine `Menu` dans le contenu parent, avec ses propres parties `TriggerItem`, `Positioner` et `Content`.

## Styles

Utilisez `className` dans React, ou `class` dans Solid et Vue, sur les parties exportées pour appliquer des styles structurels. Pour les styles liés à un état, privilégiez les attributs de données Ark tels que `data-state`, `data-disabled` et `data-highlighted`, avec les sélecteurs `data-slot` de moduix. Les variantes Tailwind utilisent des classes utilitaires natives et les classes du consommateur ; les variables CSS ci-dessous personnalisent les variantes CSS Modules. Les attributs de données et les sélecteurs `data-slot` sont communs aux deux modes de style.

### Points d’accroche CSS

Utilisez les attributs d’état d’Ark pour styliser le menu et ses éléments :

- Attributs Ark : `[data-scope='menu']`, `[data-part='trigger']`, `[data-part='indicator']`, `[data-part='content']`, `[data-part='viewport']`, `[data-part='item']`, `[data-type='checkbox' | 'radio']`, `[data-state='open' | 'closed' | 'checked' | 'unchecked']`, `[data-current]`, `[data-highlighted]`, `[data-disabled]`, `[data-placement]` et `[data-side]`.
- Attributs moduix : `[data-slot='menu-trigger']`, `[data-slot='menu-trigger-icon']`, `[data-slot='menu-indicator']`, `[data-slot='menu-context-trigger']`, `[data-slot='menu-positioner']`, `[data-slot='menu-content']`, `[data-slot='menu-viewport']`, `[data-slot='menu-arrow']`, `[data-slot='menu-arrow-tip']`, `[data-slot='menu-item']`, `[data-slot='menu-trigger-item']`, `[data-slot='menu-trigger-item-icon']`, `[data-slot='menu-separator']`, `[data-slot='menu-item-group']`, `[data-slot='menu-item-group-label']`, `[data-slot='menu-radio-item-group']`, `[data-slot='menu-radio-item']`, `[data-slot='menu-checkbox-item']`, `[data-slot='menu-item-indicator']`, `[data-slot='menu-item-text']`, `[data-slot='menu-item-text-content']`, `[data-slot='menu-item-text-icon']`, `[data-slot='menu-item-text-label']`, `[data-slot='menu-item-shortcut']` et `[data-indicator-position='start' | 'end' | 'none']`.
- Variables de positionnement : `--reference-width`, `--available-width`, `--available-height`, `--transform-origin`, `--layer-index`, `--arrow-size` et `--arrow-background`.
