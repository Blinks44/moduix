## Choisir le bon composant

Utilisez `Menu` pour les listes de commandes ouvertes depuis un déclencheur, les menus contextuels, les sélections
simples et les actions imbriquées.

- Choisissez **`Menu`** pour les actions supplémentaires, les actions sur une ligne et les listes de commandes ouvertes
  par un bouton ou un déclencheur de menu contextuel.

## Exemple de base

Commencez par l’arborescence des parties Ark : `Menu`, `Menu.Trigger`, `Menu.Positioner` et `Menu.Content`. Les éléments
utilisent des valeurs `value` stables pour la sélection et la recherche par saisie.

## Anatomie

```text
Menu
├─ Menu.Trigger
│  └─ Menu.Indicator
├─ Menu.ContextTrigger
├─ Sous-arbre du calque (placé automatiquement dans un portail)
│  └─ Menu.Positioner
│     └─ Menu.Content
│        ├─ Menu.Arrow
│        │  └─ Menu.ArrowTip
│        ├─ Menu.Item
│        ├─ Menu.CheckboxItem
│        │  ├─ Menu.ItemIndicator
│        │  └─ Menu.ItemText
│        ├─ Menu.RadioItemGroup
│        │  └─ Menu.RadioItem
│        ├─ Menu.ItemGroup
│        │  └─ Menu.ItemGroupLabel
│        └─ Menu
│           └─ Menu.TriggerItem
```

| Partie | Rôle |
| --------------------- | ----------------------------------------------------------------- |
| `Menu` / `Menu.Root` | Racine Ark qui gère l’ouverture, le positionnement, la recherche par saisie et la fermeture. |
| `Menu.RootProvider` | Affiche un menu à partir de l’instance d’état créée par `useMenu`.             |
| `Menu.Trigger` | Bouton d’ouverture ; utilisez `asChild` pour fournir votre propre élément. |
| `Menu.Indicator` | Indicateur Ark qui reflète l’état du déclencheur.                   |
| `Menu.ContextTrigger` | Déclencheur par clic droit ou appui prolongé pour un menu contextuel. |
| `Menu.Positioner` | Positionne le calque flottant.                                      |
| `Menu.Content` | Surface de la fenêtre contextuelle, avec le rôle menu et la collection d’éléments.     |
| `Menu.Item` | Commande du menu.                                                   |
| `Menu.CheckboxItem` | Option activable ou désactivable.                                   |
| `Menu.RadioItemGroup` | Groupe d’options dont une seule peut être choisie.            |
| `Menu.RadioItem` | Option d’un groupe à choix unique.                             |
| `Menu.TriggerItem` | Ligne qui ouvre un sous-menu.                             |
| `Menu.ItemIndicator` | Indicateur de sélection pour les cases à cocher et les options radio.                     |

## Composition

La racine place automatiquement `Positioner` dans un portail. Utilisez `portalled={false}` pour afficher le menu dans
son conteneur, ou `portalRef` pour choisir un autre conteneur de portail. Les parties structurelles restent explicites
et peuvent être stylées.

### Composition recommandée

Conservez une structure explicite pour la fenêtre contextuelle. `Menu.Content` est la partie de contenu Ark elle-même ; elle
n’intègre plus implicitement `Menu.Positioner`.

```tsx
<Menu positioning={{ placement: 'bottom-start', gutter: 8 }}>
  <Menu.Trigger asChild>
    <Button>
      Actions
      <Menu.Indicator />
    </Button>
  </Menu.Trigger>
  <Menu.Positioner>
    <Menu.Content className="menu-content">
      <Menu.Item value="edit">Edit</Menu.Item>
    </Menu.Content>
  </Menu.Positioner>
</Menu>
```

### Quand créer une composition personnalisée

Utilisez `asChild` lorsqu’un déclencheur, un élément ou le contenu doit être rendu sous la forme d’un autre élément
sémantique. Fournissez un seul enfant sémantique pour permettre à Ark d’appliquer les bons attributs ARIA et de
gérer correctement le focus et le clavier. Pour un lien, placez `asChild` sur `Menu.Item` ; pour un conteneur
personnalisé de la fenêtre contextuelle, placez-le sur `Menu.Content`.

Un sous-menu est une racine `Menu` ordinaire placée dans le contenu du menu parent. Il utilise `Menu.TriggerItem`, puis
son propre `Menu.Positioner` et son propre `Menu.Content`.

### Propriétés par défaut

Par défaut, le contenu placé dans le portail est monté à la demande puis démonté après l’animation de fermeture.
Définissez `unmountOnExit={false}` pour le conserver après la première ouverture. Définissez `lazyMount={false}` et
`unmountOnExit={false}` uniquement si le contenu doit être rendu immédiatement.

| Surface | Par défaut | Remarques |
| --------------------------------- | ------------ | ----------------------------------------------------------- |
| `Menu` / `Menu.Root` | - | Aucun comportement supplémentaire par défaut ; les valeurs Ark s’appliquent. |
| `Menu.CheckboxItem` / `Menu.RadioItem` | `start` | `indicator` contrôle la position de la colonne de l’indicateur.          |

### Comportement

- Dans moduix, `lazyMount` et `unmountOnExit` valent `true` par défaut. `open`, `defaultOpen`, `onOpenChange(details)`,
  `highlightedValue`, `onHighlightChange(details)`, `onSelect(details)`, `closeOnSelect`, `ids` et `present` sont
  transmis à Ark tels quels, sans autre valeur par défaut de moduix.
- Pour identifier un élément du menu, utilisez `value` plutôt qu’un `id` personnalisé.
- `Menu.CheckboxItem.onCheckedChange` reçoit la nouvelle valeur booléenne de l’état coché.
- `Menu.RadioItemGroup.onValueChange` reçoit `details.value`.
- Utilisez `Menu.RootProvider` avec une instance de `useMenu` ; n’affichez pas une seconde racine `Menu` pour le même état.
- `Menu.Context`, `useMenuContext` et `useMenuItemContext` donnent aux descendants accès à l’état Ark pour les compositions avancées.
- Le composant racine place automatiquement `Menu.Positioner` dans un portail. Utilisez `portalled={false}` pour laisser
  le menu dans une boîte de dialogue ou un conteneur défilant. Lorsque le conteneur défile, ajoutez
  `positioning={{ strategy: 'fixed', hideWhenDetached: true }}`.
- Les animations d’ouverture et de fermeture respectent `prefers-reduced-motion`.
- `Menu.Indicator` correspond à la partie indicator d’Ark. `Menu.TriggerIcon`, `Menu.TriggerItemIcon`, `Menu.ItemShortcut`
  et les utilitaires de texte des éléments sont uniquement des composants utilitaires moduix pour les cas courants.

### Points d’accroche CSS

- Attributs Ark : `[data-scope='menu']`, `[data-part='trigger']`, `[data-part='indicator']`, `[data-part='content']`, `[data-part='item']`, `[data-type='checkbox' | 'radio']`, `[data-state='open' | 'closed' | 'checked' | 'unchecked']`, `[data-current]`, `[data-highlighted]`, `[data-disabled]`, `[data-placement]` et `[data-side]`.
- Variables Ark : `--reference-width`, `--available-width`, `--available-height`, `--transform-origin`, `--layer-index`, `--arrow-size` et `--arrow-background`.
- Hooks moduix : `data-slot="menu-trigger"`, `menu-content`, `menu-item`, `menu-checkbox-item`, `menu-radio-item`, `menu-trigger-item`, `menu-item-indicator` et `menu-item-shortcut`.
