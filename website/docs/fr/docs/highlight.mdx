## Choisir le bon composant

Utilisez `Highlight` pour mettre en évidence des termes de recherche dans un texte qui possède déjà
un conteneur sémantique. Le composant rend les segments correspondants sans ajouter son propre
conteneur.

- Choisissez **`Highlight`** lorsqu’un ou plusieurs termes doivent ressortir dans une phrase, un libellé ou un bloc de texte existant.
- Choisissez **`Text`** lorsque toute la chaîne a seulement besoin d’un style typographique, sans recherche de correspondances.

## Anatomie

`Highlight` n’expose qu’une racine publique et renvoie un fragment sans ajouter de conteneur
supplémentaire. Chaque segment correspondant devient un élément natif `<mark>`, tandis que le texte
sans correspondance reste du texte ordinaire dans le flux environnant.

```text
Highlight / Highlight.Root
└─ segments correspondants rendus dans des éléments <mark> successifs
```

| Partie                         | Rôle                                                                  |
| ------------------------------ | --------------------------------------------------------------------- |
| `Highlight` / `Highlight.Root` | Applique les styles moduix à chaque correspondance du texte fourni.   |

## Composition

`Highlight` est sans état et ne crée pas de conteneur de mise en page. Placez-le dans un conteneur
de texte existant comme `Text`, un titre, un élément de liste ou une cellule de tableau. Contrôlez
`query` depuis le composant parent lorsque la recherche change et utilisez la forme `Highlight.Root`
seulement si elle rend la composition plus claire. Un tableau de chaînes exige que `matchAll` reste
à `true` ; si chaque correspondance doit utiliser un élément différent ou un comportement interactif,
construisez cette structure dans votre propre composant.

## Styles

Les segments correspondants reçoivent les styles `<mark>` par défaut de moduix. Utilisez `className`
dans React ou `class` dans Solid pour une modification locale. Les variantes CSS Modules exposent
également les variables `--moduix-highlight-*` ; pour Tailwind, utilisez des classes utilitaires ou
les classes du consommateur.

### Points d’accroche CSS

- Chaque `<mark>` correspondant porte `data-scope="highlight"` et `data-part="root"`.
- `data-slot="highlight-root"` est le sélecteur moduix stable de chaque `mark` correspondant.
- Les propriétés comme `className`/`class`, `style`, `title`, `id` et `data-*` s’appliquent à chaque `<mark>` correspondant.
- Il n’y a ni conteneur supplémentaire, ni attribut d’état, ni variable CSS d’exécution Ark.
