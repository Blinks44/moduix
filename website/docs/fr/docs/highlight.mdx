## Choisir le bon composant

Utilisez `Highlight` pour mettre en évidence des termes de recherche dans un texte qui possède
déjà un conteneur sémantique. Le composant rend les segments correspondants sans ajouter son
propre conteneur de mise en page.

- Choisissez **`Highlight`** lorsqu’un ou plusieurs termes doivent ressortir dans une phrase, un libellé ou un bloc de texte existant.
- Choisissez **`Text`** lorsque toute la chaîne a seulement besoin d’un style typographique, sans recherche de correspondances.

## Exemple de base

## Anatomie

`Highlight` n’expose qu’une racine publique. Il renvoie un fragment sans ajouter de conteneur
supplémentaire. Chaque segment correspondant devient un élément natif `<mark>`, tandis que le texte
sans correspondance reste du texte ordinaire dans le flux environnant.

```text
Highlight / Highlight.Root
└─ segments correspondants rendus dans des éléments <mark> successifs
```

| Partie                         | Rôle                                                                  |
| ------------------------------ | --------------------------------------------------------------------- |
| `Highlight` / `Highlight.Root` | Applique les styles moduix à chaque correspondance du texte fourni. |

## Composition

### Composition recommandée

Utilisez la forme courte `<Highlight>` dans `Text`, `Heading`, un élément de liste, une cellule de
tableau ou tout autre conteneur qui contient le texte. Elle équivaut à `<Highlight.Root>`.

### Quand créer une composition personnalisée

Utilisez `Highlight` lorsque chaque correspondance peut être rendue dans un élément natif `<mark>`.
Si les correspondances doivent utiliser des éléments différents, recevoir un comportement interactif
ou contenir un contenu spécifique, construisez cette structure dans votre propre composant. Le composant
moduix ne fournit volontairement pas d’API de rendu personnalisé pour chaque segment.

### Propriétés par défaut

| Propriété     | Valeur par défaut                    | Remarques                                                     |
| ------------- | ------------------------------------ | ------------------------------------------------------------- |
| `query`       | -                                    | Chaîne ou tableau de chaînes à rechercher.                    |
| `text`        | -                                    | Texte source complet obligatoire.                             |
| `ignoreCase`  | `false`                              | Ignore la casse pendant la recherche.                        |
| `matchAll`    | `false` pour une chaîne ; `true` pour un tableau | Met en évidence chaque correspondance. Avec un tableau, la valeur `false` provoque une erreur. |
| `exactMatch`  | `false`                              | Recherche des mots entiers, et non des fragments de mots.    |

### Comportement

`className`, `style`, `title`, `id` et les autres propriétés de `<mark>` s’appliquent à chaque
segment correspondant. Lorsque rien ne correspond, `Highlight` affiche le texte source sans aucun
élément `<mark>`.

`Highlight` n’ajoute pas de conteneur et ne gère ni l’état, ni le focus, ni les interactions au clavier,
ni le comportement des formulaires. Les attributs `data-*` stables de moduix sur chaque élément
correspondant sont décrits dans la section [Styles](#styles).

`exactMatch` utilise les limites de mots de JavaScript. Cela fonctionne de manière fiable pour le
texte latin, mais ces limites ne reconnaissent pas le cyrillique ni certaines autres écritures non ASCII
comme des mots entiers. Si la recherche de mots entiers doit fonctionner pour ces écritures, effectuez-la
avec une logique adaptée à la langue, puis affichez vous-même le résultat.

## Styles

Les segments correspondants reçoivent les styles `<mark>` par défaut de moduix. Utilisez `className`
pour une modification locale, ou les variables `--moduix-highlight-*` si la même apparence doit être
partagée par plusieurs instances.

### Points d’accroche CSS

- Chaque `<mark>` correspondant porte `data-scope="highlight"` et `data-part="root"`.
- `data-slot="highlight-root"` est le sélecteur moduix stable de chaque `mark` correspondant.
- Il n’y a ni conteneur supplémentaire, ni attribut d’état, ni variable CSS d’exécution Ark. Le rendu
  se compose uniquement de nœuds de texte ordinaires et d’éléments `<mark>` correspondants.
