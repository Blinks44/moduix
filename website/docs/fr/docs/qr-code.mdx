## Anatomie

```text
QrCode / QrCode.Root
├─ QrCode.Frame
│  └─ QrCode.Pattern
├─ QrCode.Overlay
└─ QrCode.DownloadTrigger

QrCode.RootProvider
└─ même arborescence de parties, connectée à useQrCode() de @moduix/react
```

| Partie                    | Rôle                                                                    |
| ------------------------- | ----------------------------------------------------------------------- |
| `QrCode` / `QrCode.Root` | Gère la valeur encodée et les options de génération, et fournit l’état du QR code. |
| `QrCode.RootProvider`    | Relie les parties à un objet d’état créé avec `useQrCode()` en dehors de l’arbre.      |
| `QrCode.Frame`           | Élément SVG qui contient le code QR généré.                             |
| `QrCode.Pattern`         | Chemin SVG qui dessine les modules du code QR.                          |
| `QrCode.Overlay`         | Contenu centré affiché par-dessus le code QR.                           |
| `QrCode.DownloadTrigger` | Bouton qui télécharge le code QR actuel sous forme d’image.             |

## Composition

### Composition recommandée

`QrCode` est la forme abrégée de `QrCode.Root`. Utilisez l’un ou l’autre en gardant `QrCode.Frame`
et `QrCode.Pattern` explicites. Utilisez `defaultValue` pour un code QR non contrôlé. Si la valeur
provient de l’état de l’application, utilisez plutôt `value` avec `onValueChange(details)`.

Ajoutez `QrCode.Overlay` uniquement si la zone masquée reste assez petite pour que le code soit lisible.
Pour une superposition, définissez `encoding={{ ecc: 'H' }}` et testez le code final avec les scanners
utilisés par vos utilisateurs.

### Quand créer une composition personnalisée

Utilisez `QrCode.RootProvider` lorsque l’état du code QR doit être créé en dehors de l’arbre rendu ou
lorsque des contrôles externes doivent accéder à l’API du code QR. Créez l’état avec `useQrCode()` depuis
`@moduix/react/qr-code`, puis transmettez-le à `RootProvider`. Utilisez `QrCode.Context` ou
`useQrCodeContext()` lorsqu’un descendant a besoin de la valeur actuelle ou de l’API du code QR.
N’utilisez pas `QrCode` et `QrCode.RootProvider` avec le même objet d’état.

Utilisez `asChild` sur une partie Ark uniquement lorsqu’un autre élément doit porter le nœud DOM rendu.
Conservez un enfant unique et sémantique. Utilisez `ids` lorsqu’une composition personnalisée a besoin
d’identifiants stables pour la racine ou le cadre.

### Propriétés courantes

Le tableau réunit les propriétés dont la plupart des utilisateurs ont besoin. Chaque partie accepte
également les attributs DOM correspondants, notamment `className` et `asChild` lorsque ces propriétés
sont prises en charge. Consultez la référence pour voir toute l’API Ark.

| Partie          | Propriété       | Rôle                                                                  |
| --------------- | --------------- | --------------------------------------------------------------------- |
| Root            | `defaultValue`  | Valeur initiale pour un usage non contrôlé.                           |
| Root            | `value`         | Valeur contrôlée à encoder.                                           |
| Root            | `onValueChange` | Reçoit l’objet `details` d’origine d’Ark. Lisez la nouvelle valeur dans `details.value`. |
| Root            | `encoding`      | Options du générateur, notamment `ecc` et `boostEcc`.                 |
| Root            | `pixelSize`     | Taille de pixel transmise au générateur de code QR.                   |
| Root            | `id`            | Identifiant stable de la machine transmis à Ark.                      |
| Root            | `ids`           | Identifiants stables de la racine et du cadre.                        |
| RootProvider    | `value`         | Objet d’état obligatoire renvoyé par `useQrCode()`.                   |
| DownloadTrigger | `fileName`      | Nom obligatoire du fichier téléchargé.                                |
| DownloadTrigger | `mimeType`      | Type d’image obligatoire, par exemple `image/png` ou `image/svg+xml`.  |
| DownloadTrigger | `quality`       | Qualité facultative transmise au générateur.                           |

### Comportement

En mode contrôlé, `onValueChange(details)` synchronise la valeur avec l’état du code QR. Il utilise
l’objet `details` d’origine d’Ark, donc lisez la nouvelle valeur encodée dans `details.value`.

`QrCode.Context` et `useQrCodeContext()` fournissent aux descendants l’API du code QR le plus proche.
Cette API comprend la `value` actuelle, `setValue` et `getDataUrl()` pour générer une URL de données.

Le code QR n’est pas un contrôle de formulaire et n’ajoute pas de champ masqué. Il ne fournit pas non
plus de navigation spécifique avec les flèches ni de déplacement du focus entre ses parties.
`QrCode.DownloadTrigger` est un bouton natif : il conserve le focus, l’activation au clavier et le
comportement `disabled` habituels d’un bouton.

Le SVG est un contenu visuel. Lorsque le code QR transmet une information, ajoutez `role="img"` et
`aria-label` à `QrCode.Frame`. S’il répète un texte adjacent, conservez ce texte et ajoutez
`aria-hidden="true"` à `QrCode.Frame`.

### Correction d’erreurs

Utilisez `encoding.ecc` pour choisir la quantité de données endommagées que le code QR peut récupérer.
Les niveaux élevés sont utiles lorsqu’une superposition recouvre une partie du code ou lorsque celui-ci
risque d’être rayé ou déformé.

- `L` : récupère jusqu’à 7 % des données endommagées.
- `M` : récupère jusqu’à 15 %.
- `Q` : récupère jusqu’à 25 %.
- `H` : récupère jusqu’à 30 %.

## Styles

Moduix ajoute des styles fondés sur des tokens pour la taille et l’espacement du code QR, son remplissage,
sa superposition et son déclencheur de téléchargement. Utilisez `className` pour les styles propres au
composant et les attributs `data-slot` stables pour les sélecteurs partagés. Le panneau CSS Variables
présente l’ensemble des variables publiques.

Ark définit également à l’exécution `--qrcode-pixel-size`, `--qrcode-width` et `--qrcode-height` sur la
racine. Ces variables décrivent le cadre généré et peuvent servir à intégrer des styles personnalisés.

### Points d’accroche CSS

- `QrCode.Root` -> `data-slot="qr-code-root"`
- `QrCode.RootProvider` -> `data-slot="qr-code-root-provider"`
- `QrCode.Frame` -> `data-slot="qr-code-frame"`
- `QrCode.Pattern` -> `data-slot="qr-code-pattern"`
- `QrCode.Overlay` -> `data-slot="qr-code-overlay"`
- `QrCode.DownloadTrigger` -> `data-slot="qr-code-download-trigger"`
- Attributs Ark : `data-scope="qr-code"` et `data-part="root|frame|pattern|overlay|download-trigger"`
