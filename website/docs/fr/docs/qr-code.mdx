## Exemples

### Valeur contrôlée

Contrôlez `value` lorsque le code QR doit suivre une destination sélectionnée ou un autre état de
l’application.

<Example name="qr-code/controlled" />

### Téléchargement

Ajoutez `QrCodeDownloadTrigger` lorsque les utilisateurs doivent enregistrer le code généré comme
image. Définissez `fileName` et `mimeType` sur le trigger.

<Example name="qr-code/download" />

### Correction d’erreurs

Utilisez `encoding.ecc` pour choisir la quantité de données endommagées que le code QR peut
récupérer. Les niveaux élevés sont utiles lorsqu’une superposition couvre une partie du code ou
qu’il peut être rayé ou déformé.

- `L` : récupère jusqu’à 7 % des données endommagées.
- `M` : jusqu’à 15 %.
- `Q` : jusqu’à 25 %.
- `H` : jusqu’à 30 %.

<Example name="qr-code/error-correction" />

### Remplissage

Par défaut, les modules du code QR utilisent `currentColor`. Modifiez le remplissage du SVG avec
`style` ou une classe sur `QrCodeFrame`, ou définissez la couleur du texte d'un parent.

<Example name="qr-code/fill" />

### Champ de saisie

Liez `value` à un champ de texte lorsque les utilisateurs doivent saisir ou modifier le contenu
encodé dans le code QR. Donnez à la frame un nom accessible qui explique ce que représente le code.

<Example name="qr-code/input" />

### Superposition

Utilisez `QrCodeOverlay` pour un logo compact ou une marque textuelle. Définissez un niveau élevé
de correction d’erreurs et gardez la superposition assez petite pour que les scanners puissent
encore lire le code.

<Example name="qr-code/overlay" />

dehors de l’arbre QR, puis transmettez cet état à `QrCodeRootProvider`.

## Composition

Utilisez `defaultValue` pour un code QR non contrôlé. Lorsque l’état de l’application possède la
valeur, utilisez `value` avec `onValueChange(details)` et lisez la nouvelle valeur dans
`details.value`. Créez l’état avec `useQrCode()` depuis le package du framework correspondant, puis
transmettez-le à `QrCodeRootProvider` lorsqu’il doit être partagé en dehors de l’arbre QR. Ne
restituez pas `QrCode` et `QrCodeRootProvider` pour le même store.

Utilisez `QrCodeContext` ou `useQrCodeContext()` lorsqu’un descendant a besoin de l’API QR actuelle.
Ajoutez `QrCodeOverlay` uniquement avec un niveau de correction suffisant pour la zone couverte,
puis testez le code final avec les scanners utilisés par vos utilisateurs.

## Anatomie

```text
QrCode
├─ QrCodeFrame
│  └─ QrCodePattern
├─ QrCodeOverlay
└─ QrCodeDownloadTrigger

QrCodeRootProvider
└─ même arbre de parties connecté à un store useQrCode()
```

| Part                     | Rôle                                                                  |
| ------------------------ | --------------------------------------------------------------------- |
| `QrCode`                | Possède la valeur encodée et les options de génération, et fournit l’état du code QR. |
| `QrCodeRootProvider`    | Connecte les parties à l’état créé avec `useQrCode()`.                |
| `QrCodeFrame`           | Élément SVG qui contient le code QR généré.                            |
| `QrCodePattern`         | Chemin SVG qui dessine les modules du code QR.                         |
| `QrCodeOverlay`         | Contenu affiché au centre du code QR.                                  |
| `QrCodeDownloadTrigger` | Bouton qui télécharge le code QR actuel comme image.                   |

## Styles

Utilisez `className` en React ou `class` en Solid et Vue sur les parties exportées pour les styles
structurels. Les variantes Tailwind utilisent les utilitaires natifs et les classes du consommateur ;
les variables ci-dessous personnalisent les variantes CSS Modules. Les attributs de données et les
hooks `data-slot` sont partagés par les deux pistes de style.

Le panneau CSS Variables répertorie l’ensemble des variables publiques. Ark définit également au
runtime `--qrcode-pixel-size`, `--qrcode-width` et `--qrcode-height` sur la racine.
