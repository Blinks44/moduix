## Anatomie

```text
QrCode / QrCode.Root
├─ QrCode.Frame
│  └─ QrCode.Pattern
├─ QrCode.Overlay
└─ QrCode.DownloadTrigger

QrCode.RootProvider
└─ même arbre de parties connecté à un store useQrCode()
```

| Part                     | Rôle                                                                  |
| ------------------------ | --------------------------------------------------------------------- |
| `QrCode` / `QrCode.Root` | Possède la valeur encodée et les options de génération, et fournit l’état du code QR. |
| `QrCode.RootProvider`    | Connecte les parties à l’état créé avec `useQrCode()`.                |
| `QrCode.Frame`           | Élément SVG qui contient le code QR généré.                            |
| `QrCode.Pattern`         | Chemin SVG qui dessine les modules du code QR.                         |
| `QrCode.Overlay`         | Contenu affiché au centre du code QR.                                  |
| `QrCode.DownloadTrigger` | Bouton qui télécharge le code QR actuel comme image.                   |

## Composition

Utilisez `defaultValue` pour un code QR non contrôlé. Lorsque l’état de l’application possède la
valeur, utilisez `value` avec `onValueChange(details)` et lisez la nouvelle valeur dans
`details.value`. Créez l’état avec `useQrCode()` depuis le package du framework correspondant, puis
transmettez-le à `QrCode.RootProvider` lorsqu’il doit être partagé en dehors de l’arbre QR. Ne
restituez pas `QrCode` et `QrCode.RootProvider` pour le même store.

Utilisez `QrCode.Context` ou `useQrCodeContext()` lorsqu’un descendant a besoin de l’API QR actuelle.
Ajoutez `QrCode.Overlay` uniquement avec un niveau de correction suffisant pour la zone couverte,
puis testez le code final avec les scanners utilisés par vos utilisateurs.

### Correction d’erreurs

Utilisez `encoding.ecc` pour choisir la quantité de données endommagées que le code QR peut
récupérer. Les niveaux élevés sont utiles lorsqu’une superposition couvre une partie du code ou
qu’il peut être rayé ou déformé.

- `L` : récupère jusqu’à 7 % des données endommagées.
- `M` : jusqu’à 15 %.
- `Q` : jusqu’à 25 %.
- `H` : jusqu’à 30 %.

## Styles

Utilisez `className` en React ou `class` en Solid sur les parties exportées pour les styles
structurels. Les variantes Tailwind utilisent les utilitaires natifs et les classes du consommateur ;
les variables ci-dessous personnalisent les variantes CSS Modules. Les attributs de données et les
hooks `data-slot` sont partagés par les deux pistes de style.

Le panneau CSS Variables répertorie l’ensemble des variables publiques. Ark définit également au
runtime `--qrcode-pixel-size`, `--qrcode-width` et `--qrcode-height` sur la racine.

### Points d’accroche CSS

- Sélecteurs `data-slot` stables : `qr-code-root`, `qr-code-root-provider`, `qr-code-frame`,
  `qr-code-pattern`, `qr-code-overlay` et `qr-code-download-trigger`.
- Sélecteurs de parties Ark : `data-scope="qr-code"` et
  `data-part="root|frame|pattern|overlay|download-trigger"`.
