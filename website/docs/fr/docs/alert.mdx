## Référence de l’API

Ark UI ne fournit pas de primitive `alert` dédiée. moduix construit `Alert` avec la fabrique officielle
d’Ark, en suivant les recommandations d’Ark en matière de [composition](https://ark-ui.com/docs/guides/composition), de
[styles](https://ark-ui.com/docs/guides/styling) et de [gestion des refs](https://ark-ui.com/docs/guides/ref).

Importez `Alert` depuis `@moduix/react/alert`. Vous pouvez utiliser `Alert` comme composant racine ou
passer par `Alert.Root` : les deux formes rendent la même partie racine. Les autres parties publiques sont
`Alert.Indicator`, `Alert.Content`, `Alert.Title`,
`Alert.Description` et `Alert.Actions`.

Chaque partie accepte les propriétés usuelles de l’élément qu’elle rend, notamment `className` et
`asChild`, et transmet la ref à l’élément rendu.

## Choisir le bon composant

Utilisez `Alert` lorsqu’un message doit faire partie de la mise en page et occuper une place dans le
flux normal du document.

- Utilisez **`Alert`** pour les mises à jour de statut, les résultats de validation et les messages système dans les formulaires, les panneaux ou le contenu de la page.
- Utilisez **`Toast`** pour les notifications temporaires qui s’affichent au-dessus de la page, n’occupent pas de place dans le flux du document et se ferment automatiquement.

## Anatomie

Pour un message compact, placez `Alert.Title` et `Alert.Description` directement dans l’élément racine.
Lorsque l’indicateur doit être placé à côté d’un texte et de contrôles regroupés, placez-les dans
`Alert.Content`.

```text
Alert / Alert.Root
├─ Alert.Indicator (optional)
├─ Alert.Title
├─ Alert.Description
└─ Alert.Content (optional)
   ├─ Alert.Title
   ├─ Alert.Description
   ├─ Alert.Actions (optional)
   └─ Extra custom blocks
```

| Partie                 | Rôle                                                                  | `data-part`   |
| ---------------------- | --------------------------------------------------------------------- | ------------- |
| `Alert` / `Alert.Root` | Élément racine. Applique les styles du statut et la sémantique automatique de région dynamique. | `root`        |
| `Alert.Indicator`      | Repère visuel facultatif. Les icônes SVG qu’il contient ont une taille cohérente. | `indicator`   |
| `Alert.Content`        | Conteneur en colonne facultatif pour regrouper le texte et les actions. | `content`     |
| `Alert.Title`          | Titre de l’alerte. Rend un `p` par défaut.                              | `title`       |
| `Alert.Description`    | Texte complémentaire du message.                                       | `description` |
| `Alert.Actions`        | Ligne d’actions facultative avec retour à la ligne dans `Content`.     | `actions`     |

## Composition

### Composition recommandée

Pour le cas courant d’un message intégré à la page, composez `<Alert>` avec `Alert.Title` et
`Alert.Description`.

Définissez `status` pour choisir le type de message : `info`, `success`, `warning` ou `error`.

Ajoutez `Alert.Indicator` lorsque l’alerte a besoin d’un repère visuel explicite. Les actions restent
du contenu ordinaire à placer dans `Alert.Content` ; le composant ne crée ni boutons ni slots d’action.

### Quand personnaliser la composition

Ajoutez `Alert.Content` lorsque le titre, la description et les contrôles supplémentaires doivent
rester regroupés dans une même colonne à côté de l’indicateur. Utilisez `Alert.Actions` pour une ligne
d’actions avec retour à la ligne dans cette colonne. Avec `asChild`, fournissez un seul enfant
sémantiquement adapté afin qu’il prenne en charge l’élément DOM rendu.

Si la hiérarchie des titres du document exige un autre élément, utilisez `Alert.Title asChild` :

```tsx
<Alert.Title asChild>
  <h2>Billing issue</h2>
</Alert.Title>
```

### Propriétés par défaut

| Propriété | Valeur par défaut | Valeurs et remarques                                             |
| --------- | ----------------- | ----------------------------------------------------------------- |
| `status`  | `info`            | `info`, `success`, `warning`, `error`                             |
| `role`    | Automatique       | `role="status"` par défaut, `role="alert"` pour `status="error"` |

### Comportement

- `Alert.Root` utilise `role="status"` par défaut et passe à `role="alert"` pour `status="error"`.
- `role="status"` annonce généralement les mises à jour sans interrompre la lecture en cours, tandis que `role="alert"` les annonce immédiatement. Si le message doit être annoncé, montez l’alerte avant de mettre son texte à jour. Un contenu déjà présent au chargement de la page peut ne pas être annoncé.
- Remplacez `role` lorsque l’alerte est un encart statique et non un message signalant une mise à jour. Pour une information statique complémentaire, utilisez `role="note"`.
- `Alert.Indicator` utilise `aria-hidden="true"` par défaut.
- Gardez le sens essentiel dans le titre ou la description, car l’indicateur est masqué pour les technologies d’assistance.
- `Alert.Title` rend un `p` par défaut. Utilisez `asChild` d’Ark lorsque le titre doit être rendu avec un autre élément.
- `Alert.Content` est facultatif. Utilisez-le lorsque le titre, la description et les contrôles supplémentaires doivent partager une même colonne à côté de l’indicateur.
- `Alert.Actions` est facultatif. Utilisez-le lorsque des boutons ou des liens doivent utiliser les styles par défaut de la ligne d’actions avec retour à la ligne.
- Le composant se limite à l’affichage. Il ne gère ni l’état de fermeture, ni le focus, ni le comportement clavier des actions que vous placez à l’intérieur.

## Styles

Utilisez `className` sur la racine ou sur les différentes parties pour appliquer des styles locaux.
Définissez les variables `--moduix-alert-*` sur la racine lorsqu’une alerte nécessite un thème local.

Les variables communes `--moduix-alert-bg`, `--moduix-alert-border-color`, `--moduix-alert-color` et
`--moduix-alert-indicator-color` s’appliquent à tous les statuts. Utilisez les variables
`--moduix-alert-<status>-*` correspondantes lorsqu’un seul statut doit changer.

Les statuts intégrés utilisent également les tokens de palette partagée :

| Statut    | Token partagé                | Valeur par défaut            |
| --------- | ---------------------------- | ---------------------------- |
| `info`    | `--moduix-color-card`        | surface de carte du thème    |
| `success` | `--moduix-color-success`     | `oklch(0.627 0.194 149.214)` |
| `warning` | `--moduix-color-warning`     | `oklch(0.795 0.184 86.047)`  |
| `error`   | `--moduix-color-destructive` | couleur destructive du thème |

### Sélecteurs de style

- Sélecteurs `data-slot` stables : `alert-root`, `alert-indicator`, `alert-content`, `alert-title`, `alert-description` et `alert-actions`
- Sélecteurs de style Ark : `data-scope="alert"` avec `data-part="root"`, `indicator`, `content`, `title`, `description` ou `actions`
- `Alert.Root` écrit le statut sélectionné dans `data-status`
