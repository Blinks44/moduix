## Référence de l’API

Ark UI ne fournit pas de primitive `alert` dédiée. moduix construit `Alert` avec la fabrique officielle
d’Ark, en suivant les recommandations d’Ark en matière de [composition](https://ark-ui.com/docs/guides/composition), de
[styles](https://ark-ui.com/docs/guides/styling) et de [gestion des refs](https://ark-ui.com/docs/guides/ref).

Importez `Alert` depuis `@moduix/react/alert`. `Alert` est la partie racine, et les autres parties
publiques sont `AlertIndicator`, `AlertContent`, `AlertTitle`,
`AlertDescription` et `AlertActions`.

Chaque partie accepte les propriétés usuelles de l’élément qu’elle rend, notamment `className` et
`asChild`, et transmet la ref à l’élément rendu.

## Choisir le bon composant

Utilisez `Alert` lorsqu’un message doit faire partie de la mise en page et occuper une place dans le
flux normal du document.

- Utilisez **`Alert`** pour les mises à jour de statut, les résultats de validation et les messages système dans les formulaires, les panneaux ou le contenu de la page.
- Utilisez **`Toast`** pour les notifications temporaires qui s’affichent au-dessus de la page, n’occupent pas de place dans le flux du document et se ferment automatiquement.


Les mêmes exports sont disponibles depuis `@moduix/solid/alert` pour Solid et depuis
`@moduix/vue/alert` pour Vue.

## Anatomie

Placez le contenu du message dans `AlertContent`. `AlertIndicator` est facultatif et se place à
côté de ce contenu lorsqu’il aide à identifier le message.

```text
Alert
├─ AlertIndicator (optional)
└─ AlertContent
   ├─ AlertTitle
   ├─ AlertDescription
   ├─ AlertActions (optional)
   └─ Extra custom blocks
```

| Partie             | Rôle                                                                  | `data-part`   |
| ------------------ | --------------------------------------------------------------------- | ------------- |
| `Alert`            | Élément racine. Applique les styles du statut.                         | `root`        |
| `AlertIndicator`   | Repère visuel facultatif. Les icônes SVG qu’il contient ont une taille cohérente. | `indicator`   |
| `AlertContent`     | Conteneur en colonne obligatoire pour le contenu et les actions.   | `content`     |
| `AlertTitle`       | Titre de l’alerte. Rend un `p` par défaut.                              | `title`       |
| `AlertDescription` | Texte complémentaire du message.                                       | `description` |
| `AlertActions`     | Ligne d’actions facultative avec retour à la ligne dans `Content`.     | `actions`     |

## Composition

`Alert` est un composant de présentation : le composant qui l’affiche gère sa visibilité et sa fermeture. Il ne prend pas en charge le focus ni le clavier des boutons et des liens qu’il contient. `AlertContent` est obligatoire et regroupe le titre, la description, les contrôles et le reste du contenu. Placez les contrôles dans `AlertActions` lorsqu’ils doivent bénéficier de la mise en ligne avec retour à la ligne.

Si le titre doit utiliser un autre élément sémantique, utilisez `AlertTitle asChild` avec un seul enfant sémantique. En Solid, `asChild` utilise la forme avec fonction de rendu d’Ark UI, comme dans l’exemple « Titre personnalisé ». En Vue, on utilise l’attribut `as-child` avec un seul élément enfant.

## Styles

Utilisez `className` en React ou `class` en Solid et Vue sur la racine et ses différentes parties pour
appliquer des styles locaux. Les variantes Tailwind se personnalisent avec des utilitaires et des
classes supplémentaires. Dans les variantes CSS Modules, définissez les variables
`--moduix-alert-*` sur la racine lorsqu’une alerte nécessite un thème local.

Dans les variantes CSS Modules, les variables communes `--moduix-alert-bg`,
`--moduix-alert-border-color`, `--moduix-alert-color` et `--moduix-alert-indicator-color`
s’appliquent à tous les statuts. Utilisez les variables `--moduix-alert-<status>-*` correspondantes
lorsqu’un seul statut doit changer.

Les statuts intégrés utilisent également les tokens de palette partagée :

| Statut    | Token partagé                | Valeur par défaut            |
| --------- | ---------------------------- | ---------------------------- |
| `info`    | `--moduix-color-card`        | surface de carte du thème    |
| `success` | `--moduix-color-success`     | `oklch(0.627 0.194 149.214)` |
| `warning` | `--moduix-color-warning`     | `oklch(0.795 0.184 86.047)`  |
| `error`   | `--moduix-color-destructive` | couleur destructive du thème |

### Sélecteurs de style

- Sélecteurs `data-slot` stables : `alert-root`, `alert-indicator`, `alert-content`, `alert-title`, `alert-description` et `alert-actions`
- Sélecteurs de style Ark : `data-scope="alert"` avec `data-part="root"`, `indicator`, `content`, `title`, `description` ou `actions`
- `Alert` écrit le statut sélectionné dans `data-status`
