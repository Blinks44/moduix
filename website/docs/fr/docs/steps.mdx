## Exemple de base

`Steps` est disponible dans chaque framework et variante de style actuels. L’aperçu utilise le
package React CSS Modules ; les onglets présentent le code natif de chaque adaptateur publié.

Utilisez `Steps` avec `count`, une `Steps.List` contenant un `Steps.Item` par étape, les panneaux
`Steps.Content` correspondants et les boutons intégrés pour avancer ou reculer. Les index des étapes
commencent à zéro. Par exemple, `count={3}` utilise les index `0`, `1` et `2`. Lorsque la valeur de
l’étape atteint `count`, `Steps.CompletedContent` s’affiche.

L’export `Steps` est le composant racine. Utilisez `Steps.Root` lorsque vous souhaitez expliciter le
nom de cette partie.

## Anatomie

```text
Steps
├─ Steps.Progress (optional)
├─ Steps.List
│  └─ Steps.Item[index]
│     ├─ Steps.Trigger
│     │  └─ Steps.Indicator
│     └─ Steps.Separator
├─ Steps.Content[index]
├─ Steps.CompletedContent
├─ Steps.PrevTrigger
└─ Steps.NextTrigger

Steps.RootProvider
└─ same part tree connected to a Steps.useSteps() store
```

| Partie                            | Rôle                                                                                |
| --------------------------------- | ----------------------------------------------------------------------------------- |
| `Steps` / `Steps.Root`            | Machine d’état racine pour les étapes, l’orientation, la navigation, la validation et les identifiants. |
| `Steps.RootProvider`              | Relie les parties à l’état créé avec `Steps.useSteps()`.                            |
| `Steps.Progress`                  | Barre de progression visuelle facultative, pilotée par la variable Ark `--percent`. |
| `Steps.List`                      | Liste d’onglets contenant les déclencheurs des étapes.                              |
| `Steps.Item`                      | Étape avec un `index` obligatoire commençant à zéro.                               |
| `Steps.Trigger`                   | Déclencheur d’onglet ; prend en charge `asChild` pour les éléments sémantiques.     |
| `Steps.Indicator`                 | Marqueur d’étape avec un nombre ou une icône de validation par défaut.              |
| `Steps.Separator`                 | Connecteur décoratif entre les étapes.                                              |
| `Steps.Content`                   | Panneau de contenu d’une étape, associé à son `index`.                              |
| `Steps.CompletedContent`           | Panneau affiché lorsque la valeur de l’étape courante vaut `count`.                 |
| `Steps.PrevTrigger` / `NextTrigger` | Boutons reliés aux actions Ark précédente et suivante.                              |

## Composition

Utilisez `Steps` ou `Steps.Root` comme propriétaire de l’état. Chaque `Steps.Item` et le
`Steps.Content` correspondant doivent partager le même `index` commençant à zéro ; `count` définit
le nombre total d’étapes et sa valeur représente la fin du parcours. Utilisez `Steps.RootProvider`
uniquement avec un store créé par `Steps.useSteps()` lorsque l’état doit être créé en dehors de
l’arbre des parties. Ne rendez pas la racine et le provider pour un même store.

`Steps.Trigger`, `Steps.PrevTrigger` et `Steps.NextTrigger` acceptent `asChild`. Passez un seul
enfant sémantique lorsqu’un contrôle doit être rendu comme une ancre, un lien de routeur ou un bouton
de votre système de design. Sans enfant, `Steps.Indicator` affiche le numéro de l’étape ou l’icône
de validation partagée lorsque l’étape est terminée ; fournissez un contenu pour personnaliser le
marqueur.

## Styles

Stylez `Steps` avec `className` dans React ou `class` dans Solid, les attributs Ark
`data-scope="steps"` et `data-part`, les attributs d’état Ark, les hooks moduix `data-slot` et les
variables CSS publiques `--moduix-steps-*` listées ci-dessous.

### Hooks de style

Les hooks publics utiles sont les suivants :

- `className` dans React ou `class` dans Solid sur `Steps`, `Steps.RootProvider`, `Steps.List`, `Steps.Item`, `Steps.Trigger`, `Steps.Indicator`, `Steps.Separator`, `Steps.Content`, `Steps.CompletedContent`, `Steps.PrevTrigger`, `Steps.NextTrigger` et `Steps.Progress`
- `data-slot="steps-root"`, `steps-root-provider`, `steps-list`, `steps-item`, `steps-trigger`, `steps-indicator`, `steps-separator`, `steps-content`, `steps-completed-content`, `steps-prev-trigger`, `steps-next-trigger` et `steps-progress`
- Les valeurs Ark `data-scope="steps"` et `data-part` pour chaque partie primitive
- `data-orientation="horizontal" | "vertical"` sur la racine, la liste, l’étape, le déclencheur, le contenu et le séparateur
- `data-current`, `data-complete` et `data-incomplete` sur les surfaces d’état de l’indicateur, du séparateur et du déclencheur
- `data-state="open" | "closed"` sur les déclencheurs et les panneaux de contenu
- `data-complete` sur `Steps.Progress`
- La variable Ark `--percent` sur la racine, consommée par `Steps.Progress`
