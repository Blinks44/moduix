## Utilisation

Utilisez `Separator` pour marquer visuellement la limite entre des sections liées. Par défaut, le
composant utilise `orientation="horizontal"`, `variant="solid"` et `size="sm"`.

## Exemples

### Décoratif

Utilisez `role="presentation"` pour une ligne purement visuelle qui n’apporte aucune structure aux
technologies d’assistance.

Utilisez `size` pour choisir l’épaisseur du séparateur, puis les propriétés CSS pour l’ajuster si

### Variantes

## Composition

Ses propriétés `orientation`, `variant` et `size` reprennent le modèle familier du `Separator` de Chakra UI. Consultez la [documentation de Chakra UI relative à Separator](https://chakra-ui.com/docs/components/separator), qui a servi de référence pour cette API.

`Separator` se limite à une partie racine : il ne gère donc aucun état et ne nécessite pas de
provider. Pour un séparateur courant, utilisez `<Separator />`. Lorsqu’un autre élément doit porter
le séparateur, utilisez `asChild` avec
un seul enfant capable d’accepter les propriétés fusionnées de rôle, ARIA, `data-*`, de classe et de
ref. En React et Vue, l’élément enfant est transmis directement ; en Solid, utilisez
`asChild={(props) => <hr {...props()} />}`.

## Anatomie

`Separator` n’expose qu’une seule partie racine.

```text
Separator
└─ root[data-scope="separator"][data-part="root"][data-slot="separator-root"]
```

| Partie      | Rôle                                                                    |
| ----------- | ----------------------------------------------------------------------- |
| `Separator` | Élément séparateur racine. Définit l’orientation, l’accessibilité et le style. |

## Styles

Utilisez `className` en React ou `class` en Solid et Vue sur la racine. Les variantes Tailwind utilisent
des classes utilitaires natives et les classes du consommateur ; les propriétés CSS ci-dessous
personnalisent les variantes CSS Modules. Les attributs de données et les sélecteurs `data-slot`
sont communs aux deux modes de style.

### Points d’accroche CSS

- `data-scope="separator"` et `data-part="root"` identifient la partie racine au format Ark.
- `data-slot="separator-root"` est le sélecteur moduix stable.
- `data-orientation="horizontal"` et `data-orientation="vertical"` permettent de cibler les styles propres à chaque axe.
- `data-size="xs|sm|md|lg"` et `data-variant="solid|dashed|dotted"` exposent les paramètres du style visuel.
- `className` ou `class`, ainsi que `style`, s’appliquent directement à l’élément séparateur racine.
