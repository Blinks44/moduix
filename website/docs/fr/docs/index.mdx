# moduix

moduix est une bibliothèque de composants accessibles pour React, Solid, Vue et Svelte.
[Ark UI](https://ark-ui.com/) gère les interactions au clavier, le focus et la sémantique ARIA ;
moduix ajoute les styles, les tokens de design et des compositions prêtes à l’emploi. Chaque paquet
utilise les propriétés, les événements et la réactivité de son framework.

Pour afficher votre premier composant, ouvrez le [Démarrage rapide](/docs/quick-start).

## Comment moduix est construit

| Couche | Fournie par | Ce que vous pouvez modifier |
| ------ | ----------- | --------------------------- |
| Comportement | Ark UI | Assembler les parties nommées, contrôler l’état, utiliser `asChild`, les providers et les hooks de contexte d’Ark. |
| Styles | CSS Modules ou Tailwind CSS | Redéfinir les tokens `--moduix-*`, ajouter des classes ou cibler les attributs `data-slot`. |
| Code source | Paquet npm ou registre shadcn | Mettre à jour avec votre gestionnaire de paquets, ou modifier le code copié dans votre application. |

## Choisir votre installation

Chaque choix est indépendant des autres. Le [Démarrage rapide](/docs/quick-start) couvre toutes les
combinaisons.

| Choix | Options | Quand le choisir |
| ----- | ------- | ---------------- |
| Framework | React, Solid, Vue, Svelte | Celui de votre application. Les composants et leurs parties portent les mêmes noms dans chaque framework. |
| Styles | CSS Modules, Tailwind CSS | CSS Modules si l’application n’utilise pas Tailwind ; Tailwind CSS v4 si elle est stylée avec des utilitaires. |
| Installation | Paquet, shadcn CLI | Un paquet pour les mises à jour via le gestionnaire de paquets ; la CLI shadcn pour copier le code et le modifier. |

Les paquets s’appellent `@moduix/<framework>` et `@moduix/<framework>-tailwind`, par exemple
`@moduix/vue-tailwind`. Un paquet et son registre exposent la même API.

## Versions prises en charge

Les plages déclarées dans `peerDependencies` définissent les versions prises en charge :

| Technologie | Versions prises en charge | Utilisée par |
| ----------- | ------------------------- | ----------- |
| React et React DOM | 18 et 19 | `@moduix/react`, `@moduix/react-tailwind` |
| Solid | 1.9 et versions 1.x ultérieures | `@moduix/solid`, `@moduix/solid-tailwind` |
| Vue | 3.5 et versions ultérieures de la branche 3.x | `@moduix/vue`, `@moduix/vue-tailwind` |
| Svelte | 5.29 et versions ultérieures de la branche 5.x | `@moduix/svelte`, `@moduix/svelte-tailwind` |
| Tailwind CSS | 4.x | Paquets et registres Tailwind uniquement |
| Ark UI | `^5.40.0` pour React, Solid et Vue ; `^5.25.1` pour Svelte | Le paquet React, Solid, Vue ou Svelte correspondant |

Votre gestionnaire de paquets vérifie ces plages à l’installation. Les paquets CSS Modules ne
requièrent pas Tailwind CSS.

## Styles

Les deux approches partagent les couleurs sémantiques, les tokens, les animations et le comportement
des composants. Importez `style.css` une seule fois pour charger les tokens et les styles de base,
puis :

- passez `className` avec React ou `class` avec Solid, Vue et Svelte à n’importe quelle racine ou partie ;
- ciblez `data-slot` et les attributs d’état d’Ark, comme `data-state`, pour styler un état précis ;
- redéfinissez les tokens `--moduix-*` pour changer le thème de toute la bibliothèque.

Les paquets CSS Modules exposent aussi des variables `--moduix-<component>-*`, comme
`--moduix-button-*`, pour ajuster un seul composant. Les paquets Tailwind utilisent des classes
utilitaires à la place. Consultez [Tokens](/docs/tokens) pour la hiérarchie des tokens,
[Thèmes](/docs/themes) pour des préréglages prêts à l’emploi et [Styles](/docs/styling) pour les
redéfinitions.

## Remerciements

moduix existe grâce au travail et aux idées de ces projets :

- [Ark UI](https://ark-ui.com/) pour les primitives d’interaction.
- [Chakra UI](https://chakra-ui.com/) pour la composition et les styles des composants.
- [shadcn/ui](https://ui.shadcn.com/) pour la distribution du code source via les registres.
- [Lucide](https://lucide.dev/) pour le jeu d’icônes open source utilisé dans toute la bibliothèque de composants.
- [UnoCSS](https://unocss.dev/) et [Tailwind CSS](https://tailwindcss.com/) pour les bases adaptées
  par le reset optionnel.
- [Rstack](https://rstack.rs/) pour son écosystème Rust : Rspress pour la documentation, Rslib pour
  la construction de la bibliothèque et Rstest pour les tests.
- [VoidZero](https://voidzero.dev/) pour les outils JavaScript utilisés dans tout l’espace de travail.
