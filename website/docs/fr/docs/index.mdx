# moduix

moduix est un système de composants React stylisés construit sur [Ark UI](https://ark-ui.com/). Il combine
les primitives d'interaction accessibles d'Ark avec des valeurs par défaut réfléchies, une composition
explicite et un socle de tokens CSS conçu pour les interfaces produit.

Pour l'essayer dès maintenant, choisissez une méthode d'installation dans le
[Démarrage rapide](/docs/quick-start), ajoutez `Button` à votre application, puis revenez ici quand vous aurez
besoin d'une vue d'ensemble plus complète du système.

Le langage visuel et le mode de distribution du code source sont [inspirés de shadcn/ui](https://ui.shadcn.com/) :
les composants doivent avoir un aspect soigné sans personnalisation préalable, et leur code source doit
rester lisible et facile à adapter dans votre application.

## Choisissez votre mode d’intégration

Choisissez le paquet npm pour des mises à jour gérées par votre gestionnaire de paquets. Choisissez
le registre shadcn si vous voulez conserver le code source des composants, les styles et les
utilitaires dans votre dépôt.

| Mode | Imports | Recommandé si |
| --- | --- | --- |
| Paquet npm | `@moduix/react/*` | Vous souhaitez des mises à jour centralisées et réduire au minimum le code géré par l’application. |
| Registre shadcn avec code source dans le projet | `@/components/moduix/*` | Vous souhaitez contrôler directement le code source et effectuer des modifications locales délibérées. |

Les deux approches fournissent les mêmes contrats de composants et le même système de tokens. Le
[Démarrage rapide](/docs/quick-start) explique la configuration complète de chacune.

## Ce que signifie « basé sur Ark »

Les composants complexes préservent le modèle Ark UI : parties nommées, état contrôlé et non
contrôlé, objets `details` transmis aux callbacks, fournisseurs de contexte, composition `asChild`,
contrôles de formulaire natifs et attributs d'état. moduix ajoute des styles, des valeurs par défaut,
des compositions pratiques et des hooks `data-slot` stables, sans masquer la structure des primitives
nécessaire aux scénarios produit avancés.

Ark UI reste la référence pour le comportement des interactions et l'accessibilité. moduix ajoute
par-dessus une couche produit avec des choix assumés.

## Ce que signifie « inspiré de shadcn »

L'inspiration est pratique, pas seulement cosmétique :

- des valeurs par défaut soignées qui paraissent cohérentes avant toute personnalisation ;
- une composition lisible plutôt que des composants enveloppes surchargés de configuration ;
- des variables CSS et un code source ouverts, faciles à inspecter ;
- un registre shadcn pour installer le code source dans le projet ;
- une documentation qui présente d'abord le chemin principal sans masquer les options de bas niveau.

moduix ne requiert pas Tailwind CSS et ne remplace pas l'anatomie Ark par des contrats de composants
enveloppes propres à shadcn. Le CSS natif et les CSS Modules restent le socle du style.

## Le contrat de style

Par défaut, les principaux contrôles font `36px` de haut et les lignes des éléments contextuels
`32px`, grâce à `--moduix-size-md` et `--moduix-size-sm`. Les champs de saisie, les boutons, les
déclencheurs Select et Combobox, les contrôles de date, la pagination, les éléments de menu et les
composants associés partagent la même échelle.

Les couleurs, l'espacement, les rayons, la typographie, les anneaux de focus, les animations, les
ombres et les décisions propres aux composants sont définis par des variables CSS personnalisées.
Remplacez un token sémantique pour modifier tout le système, un token de famille partagé pour ajuster
les composants liés, ou une variable `--<component>-*` pour une exception locale. Consultez
[Tokens](/docs/tokens) pour la hiérarchie complète et [Thèmes](/docs/themes) pour des préréglages
prêts à l'emploi.

## Remerciements

moduix est rendu possible par le travail et les idées de ces projets :

- [Ark UI](https://ark-ui.com/) pour les primitives accessibles fondées sur des machines à états,
  qui définissent le socle comportemental.
- [Chakra UI](https://chakra-ui.com/) pour l’ergonomie de composition alignée sur Ark et le
  savoir-faire en design system qui continuent d’inspirer moduix.
- [shadcn/ui](https://ui.shadcn.com/) pour la distribution de code ouvert, les belles valeurs par
  défaut et un style de documentation centré sur la maîtrise concrète du code.
- [UnoCSS](https://unocss.dev/) et [Tailwind CSS](https://tailwindcss.com/) pour les bases adaptées
  par le reset optionnel.
- [Rstack](https://rstack.rs/) pour son écosystème Rust : Rspress pour la documentation, Rslib pour
  la construction de la bibliothèque et Rstest pour les tests.
- [VoidZero](https://voidzero.dev/) pour les outils JavaScript utilisés dans tout l’espace de travail.
