## Créer un projet en local

Vous préférez votre éditeur ? giget copie le dossier d’un projet sans cloner le monorepo ni son historique.

<Steps>

### Installer et lancer

Les projets utilisent les paquets publiés : vous pouvez choisir votre gestionnaire de paquets.

<StarterInstall />

### Personnaliser le projet

Remplacez les exemples de données de `src/data.ts` par votre API, puis supprimez les pages inutiles.

</Steps>

## Contenu du projet

Une petite application par framework. Vous pouvez modifier ou supprimer chaque fichier source.

<StarterContents />

:::info Vous utilisez Tailwind ?
Les projets utilisent CSS Modules. Choisissez le paquet `-tailwind` correspondant, puis configurez Tailwind CSS v4 et sa feuille de styles en suivant le [guide Vite](/docs/installation/vite).
:::
