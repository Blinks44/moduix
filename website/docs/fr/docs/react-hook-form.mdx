# React Hook Form

[React Hook Form](https://react-hook-form.com/get-started) est une bibliothèque réservée à React.
Cette page décrit son intégration avec l’adaptateur React de Moduix sans suggérer une prise en charge
de Solid, Vue ou Svelte.

## Prise en charge des frameworks

<PackageManagerTabs command="install react-hook-form" />

Utilisez cette intégration uniquement avec `@moduix/react` ou `@moduix/react-tailwind`. Pour Solid,
choisissez un formulaire natif, [Formisch](/docs/formisch) ou [TanStack Form](/docs/tanstack-form).

## Relier les composants

Utilisez `register` pour les éléments natifs et `Controller` pour les composants composés dont la
valeur passe par des propriétés et des objets de détails dans les callbacks.

| Composant Moduix                       | Correspondance React Hook Form                         |
| -------------------------------------- | ------------------------------------------------------ |
| `Input`, `Textarea`, sélecteurs natifs | Transmettez `register(name, rules)` au contrôle.       |
| `Select`, `Combobox`                   | Convertissez la valeur scalaire vers `string[]`.       |
| `Checkbox`                             | Convertissez `details.checked === true` en booléen.    |
| Autres composants contrôlés            | Reliez leur contrat de valeur avec `Controller`.       |

Définissez chaque champ contrôlé dans `defaultValues`. Conservez l’élément natif Moduix dans la
composition et n’enregistrez pas un second élément input masqué pour la même valeur.

## Validation et réinitialisation

Utilisez `rules` pour les règles locales et un resolver pour un schéma ou des règles entre champs.
Transmettez `fieldState.invalid` à `Field` et affichez `fieldState.error?.message` avec
`Field.ErrorText`.

Ajoutez `noValidate` uniquement lorsque React Hook Form gère les erreurs visibles. Appelez `reset()`
pour que son état et les valeurs contrôlées de Moduix soient réinitialisés ensemble.

## Champs répétés et erreurs du serveur

Utilisez `useFieldArray` pour les listes modifiables. Rendez les lignes avec le `field.id` stable et
gardez l’index courant uniquement dans le chemin enregistré. Placez la légende et le message du
groupe dans `Fieldset`.

Appelez `setError(name, ...)` pour une erreur liée à un champ et utilisez l’espace de noms `root` pour
une erreur générale. Conservez les valeurs saisies après l’échec de la requête.

## Focus et comportement

- Transmettez `field.ref` à `Select.Trigger` ou `Combobox.Input` pour focaliser le contrôle visible.
- Appelez `field.onBlur` à la fin d’une interaction composée.
- Convertissez explicitement les objets de détails Ark au lieu d’étaler un champ de `Controller`.
- Utilisez `formState.isSubmitting` pour l’état d’attente et pour bloquer les envois en double.
