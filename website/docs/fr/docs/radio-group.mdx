Utilisez `RadioGroup` lorsqu’une personne doit choisir une seule option parmi plusieurs options
visibles, par exemple un framework, un forfait ou un type de compte. Utilisez `Checkbox` pour des
choix indépendants et `Switch` pour un réglage qui s’applique immédiatement.

## Référence de l’API

`RadioGroup` suit la primitive radio-group d’Ark UI et ajoute les styles moduix, des attributs
`data-slot` stables et le composant pratique `Option`. Le composant est exporté depuis
`@moduix/react/radio-group`.

<PrimitiveReference href="https://ark-ui.com/docs/components/radio-group" />

## Anatomie

```text
RadioGroup.Root
├─ RadioGroup.Label
├─ RadioGroup.Indicator
└─ RadioGroup.Item[value]
   ├─ RadioGroup.ItemControl
   ├─ RadioGroup.ItemText
   └─ RadioGroup.ItemHiddenInput (explicite)

RadioGroup.RootProvider
└─ RadioGroup.* + useRadioGroup()

RadioGroup.Option
└─ RadioGroup.Item + ItemControl + ItemText + ItemHiddenInput (composition fixe)
```

| Partie                     | Rôle                                                        |
| ------------------------- | ----------------------------------------------------------- |
| `RadioGroup` / `.Root`    | Gère la valeur, la navigation au clavier, l’orientation et les formulaires. |
| `RadioGroup.ItemHiddenInput` | Champ natif d’Ark ; composition explicite décrite ci-dessous. |
| `RadioGroup.RootProvider` | Relie les parties à l’état créé avec `useRadioGroup()`.    |
| `RadioGroup.Label`        | Libellé accessible du groupe.                              |
| `RadioGroup.Item`         | Une option sélectionnable ; rend un `label` par défaut.    |
| `RadioGroup.Option`       | Élément pratique avec contrôle, texte et champ masqué.     |
| `RadioGroup.ItemControl`  | Contrôle radio visuel ; accepte la prop moduix `size`.      |
| `RadioGroup.ItemText`     | Texte visible de l’option.                                 |
| `RadioGroup.Indicator`    | Indicateur facultatif de l’élément actif, mesuré par Ark.   |

## Composition

### Champ de formulaire natif

`RadioGroup.ItemHiddenInput` est exporté directement depuis Ark. Placez-en un dans chaque
`RadioGroup.Item` explicite : l’élément ne l’ajoute pas. Conservez ce champ pour les interactions natives
au clavier et les formulaires. Définissez `name`, `required` et `form` sur la racine,
ou dans les options du hook avec `RootProvider`.

`RadioGroup.Option` inclut déjà `ItemHiddenInput` dans sa composition fixe ; n’ajoutez pas de second champ.

### Composition recommandée

`RadioGroup` est la forme courte de `RadioGroup.Root`. Utilisez `RadioGroup.Option` pour l’élément
avec libellé standard. Il accepte les props de l’élément Ark, la prop moduix `size` et `className`.
La classe est appliquée à l’`Item` sous-jacent, ce qui permet toujours de cibler les parties
imbriquées avec leurs attributs `data-slot`.

### Quand créer une composition personnalisée

Utilisez `RadioGroup.RootProvider` avec `useRadioGroup()` de `@moduix/react` lorsque l’état doit être
créé avant l’affichage du groupe, partagé avec des contrôles situés hors de l’arbre rendu ou lu par
une autre partie de l’interface. Passez l’état renvoyé à `RootProvider` et n’utilisez pas `Root` et
`RootProvider` pour la même instance d’état.

Utilisez l’arbre explicite d’`Item` lorsque les parties imbriquées ont besoin de leur propre
positionnement ou de leurs propres classes, ou lorsque `RadioGroup.Item asChild` doit laisser un autre
élément porter le nœud DOM de l’option. L’enfant direct d’un `Item` avec `asChild` doit rester un
`label` sémantique.

Pour lire l’état dans l’arbre, utilisez `RadioGroup.Context`, `RadioGroup.ItemContext`,
`useRadioGroupContext()` ou `useRadioGroupItemContext()` de `@moduix/react`.

### Propriétés par défaut

| Propriété                         | Par défaut | Notes                                                       |
| --------------------------------- | ---------- | ----------------------------------------------------------- |
| `RadioGroup` / `RadioGroup.Root`  | -          | Les valeurs Ark s’appliquent ; moduix n’ajoute pas de comportement par défaut au groupe. |
| `RadioGroup.Option size`          | `md`       | Diamètre du contrôle et taille du point indicateur.         |
| `RadioGroup.ItemControl size`     | `md`       | Diamètre du contrôle moduix et taille du point indicateur.  |

### Comportement

`RadioGroup.Root` accepte notamment les props Ark `value`, `defaultValue`,
`onValueChange(details)`, `name`, `form`, `orientation`, `disabled`, `invalid`, `readOnly`,
`required`, `ids` et `asChild`. Dans le callback, lisez la valeur sélectionnée dans `details.value`.

`RadioGroup.Option` inclut son champ natif. Une composition directe de `RadioGroup.Item` nécessite
`RadioGroup.ItemHiddenInput` pour l’envoi, la validation et la réinitialisation natives. Définissez
`name` sur la racine lorsque la valeur doit être incluse dans `FormData`.

Ark gère l’état contrôlé ou non contrôlé, le comportement WAI-ARIA, le déplacement du focus et la
navigation au clavier. La touche <kbd>Tab</kbd> place le focus sur l’élément sélectionné ou sur le
premier élément si aucun choix n’est encore fait. <kbd>Espace</kbd> sélectionne l’élément qui a le
focus ; les touches fléchées déplacent le focus et sélectionnent l’option suivante ou précédente.

`Field.Root` fournit un libellé visible, un texte d’aide et un message d’erreur, mais ne transmet pas
son état à `RadioGroup`. Transmettez `disabled`, `invalid`, `readOnly` et `required` au groupe lui-même.
`Fieldset.Root` transmet aux groupes radio imbriqués ses états Ark `disabled` et `invalid`.

Chaque partie stylée transmet sa ref à la partie DOM Ark correspondante, y compris `ItemHiddenInput`.

## Styles

Personnalisez `RadioGroup` avec `className`, les attributs stables `data-slot="radio-group-*"`, les
attributs Ark `data-scope`, `data-part` et `data-state`, ainsi que les variables CSS publiques
`--moduix-radio-*` ci-dessous.

### Points d’accroche CSS

- Attributs d’anatomie Ark : `data-scope="radio-group"` et `data-part` sur root, label, item,
  item-control, item-text, item-hidden-input et indicator.
- Attributs d’état Ark : `data-state="checked|unchecked"`, `data-disabled`, `data-readonly`,
  `data-invalid`, `data-required`, `data-focus`, `data-focus-visible`, `data-hover`, `data-active`
  et `data-orientation`.
- Variables de l’indicateur Ark : `--transition-property`, `--left`, `--top`, `--width` et `--height`.
- Attributs moduix : `data-slot="radio-group-root"`, `radio-group-root-provider`, `radio-group-label`,
  `radio-group-item`, `radio-group-item-control`, `radio-group-item-text` et
  `radio-group-indicator`.
