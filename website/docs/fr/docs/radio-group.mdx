## Référence de l’API

`RadioGroup` suit la primitive radio-group d’Ark UI et ajoute les styles moduix, des attributs
`data-slot` stables et le composant pratique `Option`. Il est exporté depuis
`@moduix/react/radio-group` et `@moduix/solid/radio-group`.

<PrimitiveReference href="https://ark-ui.com/docs/components/radio-group" />

## Choisir le bon composant

Utilisez `RadioGroup` lorsqu’une personne doit choisir une seule option parmi plusieurs options
visibles, par exemple un framework, un forfait ou un type de compte. Utilisez `Checkbox` pour des
choix indépendants et `Switch` pour un réglage qui s’applique immédiatement.

## Anatomie

```text
RadioGroup / RadioGroup.Root
├─ RadioGroup.Label
├─ RadioGroup.Indicator (facultatif)
└─ RadioGroup.Item[value]
   ├─ RadioGroup.ItemControl
   ├─ RadioGroup.ItemText
   └─ RadioGroup.ItemHiddenInput (explicite)

RadioGroup.RootProvider
└─ le même arbre de parties connecté à useRadioGroup()

RadioGroup.Option
└─ Item + ItemControl + ItemText + ItemHiddenInput (composition fixe)
```

| Partie                        | Rôle                                                            |
| ---------------------------- | --------------------------------------------------------------- |
| `RadioGroup` / `.Root`       | Gère la valeur, la navigation au clavier, l’orientation et les formulaires. |
| `RadioGroup.RootProvider`    | Relie les parties à l’état créé avec `useRadioGroup()`.         |
| `RadioGroup.Label`           | Libellé accessible du groupe.                                   |
| `RadioGroup.Item`             | Une option sélectionnable ; rend un `label` par défaut.         |
| `RadioGroup.Option`           | Élément pratique avec contrôle, texte et champ masqué.           |
| `RadioGroup.ItemControl`      | Contrôle radio visuel ; accepte la prop moduix `size`.           |
| `RadioGroup.ItemText`         | Texte visible de l’option.                                      |
| `RadioGroup.ItemHiddenInput`  | Champ natif pour la composition explicite de `Item`.             |
| `RadioGroup.Indicator`        | Indicateur facultatif de l’élément actif, mesuré par Ark.        |

## Composition

Utilisez `defaultValue` pour un groupe non contrôlé. Utilisez `value` avec `onValueChange(details)`
lorsqu’une autre partie de l’application possède la valeur sélectionnée. Lorsque l’état doit être
créé en dehors de l’arbre rendu, utilisez `RootProvider` avec `useRadioGroup()` depuis le package du
framework correspondant. Ne rendez pas `RadioGroup` et `RadioGroup.RootProvider` pour la même instance
d’état. React lit le store comme un objet ; Solid lit son état réactif via l’accessor retourné.

`RadioGroup.Option` inclut `ItemHiddenInput` dans sa composition fixe. Avec une composition directe de
`RadioGroup.Item`, ajoutez vous-même `RadioGroup.ItemHiddenInput`. Utilisez l’arbre explicite lorsque
les parties imbriquées doivent être placées ou configurées séparément, ou lorsque `asChild` doit
laisser un autre élément posséder le nœud DOM de l’option. Dans Solid, `asChild` utilise une fonction
de rendu et son enfant direct doit rester un `label` sémantique.

`Field.Root` fournit un libellé visible, un texte d’aide et un message d’erreur, mais ne transmet pas
son état à `RadioGroup`. Passez `disabled`, `invalid`, `readOnly` et `required` directement au groupe.
`Fieldset.Root` transmet ses états Ark `disabled` et `invalid` aux groupes radio imbriqués.

## Styles

Utilisez `className` dans React ou `class` dans Solid sur les parties exportées pour les styles
structurels. Pour les styles liés à l’état, préférez les attributs de données Ark comme `data-state`,
`data-disabled` et `data-orientation`, avec les sélecteurs `data-slot` de moduix. Les variantes
Tailwind utilisent les utilitaires natifs et les classes du consommateur ; les variables ci-dessous
personnalisent les variantes CSS Modules. Les attributs de données et les hooks `data-slot` sont
partagés par les deux approches de style.

### Points d’accroche CSS

- Hooks d’anatomie Ark : `data-scope="radio-group"` et `data-part` sur la racine, le libellé,
  l’option, le contrôle, le texte, le champ masqué et l’indicateur.
- Hooks d’état Ark : `data-state="checked|unchecked"`, `data-disabled`, `data-readonly`,
  `data-invalid`, `data-required`, `data-focus`, `data-focus-visible`, `data-hover`,
  `data-active` et `data-orientation`.
- Variables de l’indicateur Ark : `--transition-property`, `--left`, `--top`, `--width` et `--height`.
- Hooks moduix : `data-slot="radio-group-root"`, `radio-group-root-provider`,
  `radio-group-label`, `radio-group-item`, `radio-group-item-control`, `radio-group-item-text` et
  `radio-group-indicator`.
