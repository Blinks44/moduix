Utilisez `Clipboard` lorsque les utilisateurs doivent copier une valeur textuelle. Selon les parties
utilisées, cette valeur peut être modifiable, en lecture seule ou affichée comme du texte ordinaire.

## Référence de l’API

<PrimitiveReference href="https://ark-ui.com/docs/components/clipboard" />

## Exemple de base

Utilisez `Clipboard` pour afficher une valeur que les utilisateurs peuvent copier. Ajoutez
`Clipboard.Input` si la valeur doit apparaître dans un champ et définissez `readOnly` si elle ne doit
pas être modifiée. `Clipboard.Trigger` est le bouton de copie. `Clipboard.Indicator` et
`Clipboard.CopyText` fournissent les icônes et les libellés par défaut de moduix pour les états
initial et copié.

## Anatomie

```text
Clipboard | Clipboard.RootProvider
├─ Clipboard.Label (facultatif)
├─ Clipboard.Control
│  ├─ Clipboard.Input ou Clipboard.ValueText
│  └─ Clipboard.Trigger
│     ├─ Clipboard.Indicator (facultatif)
│     └─ Clipboard.CopyText (facultatif)
```

| Partie | Rôle |
| --- | --- |
| `Clipboard` | Gère la valeur et l’état temporaire qui suit la copie. |
| `Clipboard.RootProvider` | Relie les parties à l’état créé avec `Clipboard.useClipboard()`. |
| `Clipboard.Label` | Fournit un libellé accessible pour la valeur. |
| `Clipboard.Control` | Regroupe l’affichage de la valeur et le bouton de copie. |
| `Clipboard.Input` | Affiche la valeur dans un champ. Il est modifiable sauf si `readOnly` est défini. |
| `Clipboard.Trigger` | Copie la valeur actuelle lorsqu’il est activé. Il s’affiche comme un bouton par défaut. |
| `Clipboard.Indicator` | Affiche un contenu différent selon que la valeur a été copiée ou non. |
| `Clipboard.CopyText` | Version textuelle du même indicateur. Les valeurs par défaut sont `Copy` et `Copied`. |
| `Clipboard.ValueText` | Affiche la valeur sous forme de texte lorsqu’un champ n’est pas adapté. |

## Composition

### Composition recommandée

Dans la plupart des cas, utilisez la forme courte `<Clipboard>` comme racine. Composez-la avec
`Clipboard.Label`, `Clipboard.Control`, `Clipboard.Input` et `Clipboard.Trigger`. Ajoutez
`Clipboard.Indicator` pour une icône, `Clipboard.CopyText` pour un libellé d’état, ou les deux.

Les props de la racine Ark sont transmises sans modification. Utilisez `defaultValue` pour une valeur
non contrôlée, `value` avec `onValueChange(details)` pour une valeur contrôlée et
`onStatusChange(details)` pour suivre l’état de copie. `timeout` définit la durée de cet état, tandis
que `ids` permet de fournir des identifiants stables pour les parties.

`Clipboard.Indicator` et `Clipboard.CopyText` sont facultatifs. Si vous ne fournissez pas leur
contenu, moduix affiche ses icônes de copie et de confirmation ainsi que les libellés `Copy` et
`Copied`.

### Quand choisir une autre composition

Utilisez `Clipboard.ValueText` lorsque la valeur doit s’insérer dans du texte courant ou une mise en
page compacte sans champ de saisie.

Utilisez `Clipboard.useClipboard()` avec `Clipboard.RootProvider` lorsque l’état doit être créé ou
partagé indépendamment de l’arbre de composants rendu. Les composants descendants peuvent y accéder
avec `Clipboard.Context` ou `useClipboardContext()`.

Utilisez `asChild` sur `Clipboard.Input` ou `Clipboard.Trigger` uniquement lorsqu’un autre élément
sémantique doit porter le nœud DOM rendu. Vous pouvez par exemple fournir un `Input` ou un `Button` de
moduix tout en gardant les parties Clipboard explicites dans le balisage.

### Propriétés par défaut

| Propriété | Valeur par défaut | Remarque |
| --- | --- | --- |
| `timeout` | `3000` | Durée de l’état copié, en millisecondes. |
| `Indicator.children` | non défini | Utilise `CopyIcon` de moduix à l’état initial. |
| `Indicator.copied` | non défini | Utilise `CheckIcon` de moduix à l’état copié. |
| `CopyText.children` | `Copy` | Texte affiché avant la copie. |
| `CopyText.copied` | `Copied` | Texte affiché lorsque l’état copié est actif. |

### Comportement

- `onValueChange(details)` fournit la nouvelle valeur dans `details.value`.
- `onStatusChange(details)` signale les changements de l’état de copie. Vérifiez `details.copied` si
  vous devez mettre à jour une partie voisine de l’interface, des données analytiques ou un compteur.
- Ark ajoute `data-copied` à `Root`, `Label`, `Control`, `Input` et `Trigger` tant que l’état copié
  est actif. Par défaut, moduix ne modifie pas l’apparence du champ ni du bouton ; vous pouvez donc
  utiliser cet attribut dans vos propres styles.
- La racine n’a pas de prop `disabled`. Transmettez la prop native `disabled` à `Clipboard.Input`
  et à `Clipboard.Trigger` lorsque les utilisateurs ne doivent ni modifier ni copier la valeur.
- `Clipboard` ne limite pas sa largeur par défaut. Définissez `--moduix-clipboard-max-width` lorsque
  votre mise en page a besoin d’une largeur maximale.
- Si vous migrez depuis `CopyButton`, utilisez les parties Clipboard. `copiedDuration`, `copyLabels`,
  `onCopy` et `onCopyError` ne font pas partie de cette API.

### Points d’accroche CSS

- `Clipboard` -> `data-slot="clipboard-root"`
- `Clipboard.RootProvider` -> `data-slot="clipboard-root-provider"`
- `Clipboard.Label` -> `data-slot="clipboard-label"`
- `Clipboard.Control` -> `data-slot="clipboard-control"`
- `Clipboard.Input` -> `data-slot="clipboard-input"`
- `Clipboard.Trigger` -> `data-slot="clipboard-trigger"`
- `Clipboard.Indicator` -> `data-slot="clipboard-indicator"`
- `Clipboard.CopyText` -> `data-slot="clipboard-copy-text"`
- `Clipboard.ValueText` -> `data-slot="clipboard-value-text"`
- Ark ajoute `data-copied` à `Root`, `Label`, `Control`, `Input` et `Trigger` tant que l’état copié
  est actif.
- Ark ajoute `data-readonly` à `Clipboard.Input` lorsque le champ est en lecture seule.
- `Clipboard.Indicator` ajoute `data-slot="clipboard-indicator-idle-icon"` et
  `data-slot="clipboard-indicator-copied-icon"` aux nœuds de ses icônes par défaut.
