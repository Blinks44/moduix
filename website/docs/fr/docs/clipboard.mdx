## Anatomie

```text
Clipboard | Clipboard.RootProvider
├─ Clipboard.Label (facultatif)
├─ Clipboard.Control
│  ├─ Clipboard.Input ou Clipboard.ValueText
│  └─ Clipboard.Trigger
│     ├─ Clipboard.Indicator (facultatif)
│     └─ Clipboard.CopyText (facultatif)
```

| Partie | Rôle |
| --- | --- |
| `Clipboard` | Conserve la valeur et gère l’état de copie. |
| `Clipboard.RootProvider` | Fournit un état créé avec `Clipboard.useClipboard()` hors du sous-arbre. |
| `Clipboard.Label` | Donne à la valeur un libellé accessible. |
| `Clipboard.Control` | Regroupe et organise la valeur et le bouton de copie. |
| `Clipboard.Input` | Affiche la valeur dans un champ modifiable ou en lecture seule. |
| `Clipboard.Trigger` | Copie la valeur actuelle lorsqu’il est activé. |
| `Clipboard.Indicator` | Affiche une icône de copie ou de confirmation selon l’état. |
| `Clipboard.CopyText` | Affiche un libellé d’état. Les valeurs par défaut sont `Copy` et `Copied`. |
| `Clipboard.ValueText` | Affiche la valeur sous forme de texte lorsqu’un champ ne convient pas. |

## Composition

### Composition recommandée

Dans la plupart des cas, combinez `Clipboard`, `Clipboard.Label`, `Clipboard.Control`,
`Clipboard.Input`, `Clipboard.Trigger` et `Clipboard.Indicator`. Cette structure suit la
composition Ark standard et permet de personnaliser chaque partie facilement.

`value`, `defaultValue`, `onValueChange(details)`, `onStatusChange(details)`, `timeout` et `ids`
fonctionnent exactement comme dans Ark. moduix conserve les noms des props et les arguments des
fonctions de rappel.

`Clipboard.Indicator` et `Clipboard.CopyText` sont facultatifs. Sans contenu personnalisé, ils
affichent les icônes moduix de copie et de confirmation, ainsi que les libellés `Copy` et `Copied`.

### Quand personnaliser la composition

Utilisez `Clipboard.ValueText` lorsque la valeur doit ressembler à du texte courant plutôt qu’à un
champ de saisie.

Utilisez `Clipboard.useClipboard()` avec `Clipboard.RootProvider` lorsque l’état doit être créé hors
du sous-arbre affiché. Les composants enfants peuvent le lire avec `Clipboard.Context` ou
`useClipboardContext()` de moduix.

Utilisez `asChild` sur `Clipboard.Input` et `Clipboard.Trigger` pour rendre un autre élément, par
exemple `Input` ou `Button` de moduix. Laissez les parties Ark visibles dans le balisage pour
conserver une structure claire et accessible.

### Propriétés par défaut

| Propriété | Valeur par défaut | Valeurs et remarques |
| --- | --- | --- |
| `timeout` | `3000` | Durée de l’état copié d’Ark, en millisecondes |
| `Indicator.copied` | - | Utilise `CheckIcon` de moduix par défaut |
| `Indicator.children` | - | Utilise `CopyIcon` de moduix par défaut |
| `CopyText.copied` | `Copied` | Libellé affiché après une copie réussie |
| `CopyText.children` | `Copy` | Libellé affiché avant la copie |

### Comportement

- `onValueChange(details)` fournit la nouvelle valeur dans `details.value`.
- Utilisez `onStatusChange(details)` pour mettre à jour une zone voisine, des données analytiques ou
  un compteur après une copie.
- Ark ajoute `data-copied` tant que l’état copié est actif. Par défaut, moduix ne modifie pas
  visuellement le champ ni le bouton, mais vous pouvez utiliser cet attribut dans vos styles.
- Ark ne propose pas de prop `disabled` sur la racine. Transmettez la prop native `disabled` à
  `Clipboard.Input` et à `Clipboard.Trigger` lorsque la valeur ne doit être ni modifiée ni copiée.
- `Clipboard` ne limite pas la largeur du champ par défaut. Définissez
  `--moduix-clipboard-max-width` si votre mise en page a besoin d’une largeur maximale.
- L’ancienne API `CopyButton` n’est plus disponible. `Clipboard` ne prend pas en charge
  `copiedDuration`, `copyLabels`, `onCopy` et `onCopyError`.

### Points d’accroche CSS

- `Clipboard` -> `data-slot="clipboard-root"`
- `Clipboard.RootProvider` -> `data-slot="clipboard-root-provider"`
- `Clipboard.Label` -> `data-slot="clipboard-label"`
- `Clipboard.Control` -> `data-slot="clipboard-control"`
- `Clipboard.Input` -> `data-slot="clipboard-input"`
- `Clipboard.Trigger` -> `data-slot="clipboard-trigger"`
- `Clipboard.Indicator` -> `data-slot="clipboard-indicator"`
- `Clipboard.CopyText` -> `data-slot="clipboard-copy-text"`
- `Clipboard.ValueText` -> `data-slot="clipboard-value-text"`
- Ark ajoute `data-copied` à `Root`, `Label`, `Control`, `Input` et `Trigger` tant que l’état copié est actif.
- Ark ajoute `data-readonly` à `Clipboard.Input` lorsque le champ est en lecture seule.
- `Clipboard.Indicator` ajoute `data-slot="clipboard-indicator-idle-icon"` et
  `data-slot="clipboard-indicator-copied-icon"` à ses nœuds d’icône par défaut.
