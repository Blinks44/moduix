## Référence de l’API

Ark UI ne fournit pas de primitive `button` dédiée. moduix construit ce composant à partir de l’outil officiel
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) et suit les recommandations d’Ark pour la
[composition](https://ark-ui.com/docs/guides/composition), le [style](https://ark-ui.com/docs/guides/styling) et la
[gestion des refs](https://ark-ui.com/docs/guides/ref).

## Anatomie

`Button` ne comporte qu’une seule partie.

```text
Button.Root
└─ root[data-scope="button"][data-part="root"][data-slot="button-root"]
   └─ children
```

| Partie                   | Rôle                                                        |
| ------------------------ | ----------------------------------------------------------- |
| `Button` / `Button.Root` | Élément interactif racine avec les styles moduix.            |
| `Button`                 | Alias appelable de `Button.Root`.                            |

## Composition

### Composition recommandée

Pour les actions, utilisez l’élément racine natif. Il reçoit `type="button"` par défaut afin d’éviter l’envoi accidentel d’un formulaire. Pour envoyer le formulaire, définissez explicitement `type="submit"`.

### Propriétés par défaut

| Propriété | Valeur par défaut | Valeurs                                                                                |
| --------- | ----------------- | -------------------------------------------------------------------------------------- |
| `loading` | `false`           | `boolean`                                                                              |
| `variant` | `default`         | `default`, `outline`, `secondary`, `destructive`, `destructive-outline`, `ghost`, `link` |
| `size`    | `md`              | `xs`, `sm`, `md`, `lg`, `xl`, `icon-sm`, `icon-md`, `icon-lg`                         |
| `type`    | `button`          | Éléments racine natifs uniquement                                                      |

### Quand utiliser un élément personnalisé

Utilisez `asChild` lorsqu’un seul enfant sémantique doit prendre en charge le nœud DOM. La composition Ark exige exactement un enfant. La valeur par défaut `type="button"` n’est pas injectée dans l’élément utilisé avec `asChild`.

Lorsque `Dialog.Trigger`, `Menu.Trigger` ou une autre partie d’Ark compose Button comme enfant, les `data-scope` et `data-part` de la partie parente sont prioritaires sur le nœud DOM partagé. Button conserve les classes produites par sa recette et son `data-slot` stable ; Ark continue de fusionner les gestionnaires du déclencheur et les refs.

Pour la navigation, utilisez un véritable lien. Sur l’élément utilisé avec `asChild`, les propriétés `disabled`, `loading` et `aria-disabled="true"` ajoutent `aria-disabled`, appliquent les styles de l’état désactivé et empêchent l’activation au clic. Elles n’ajoutent pas l’attribut natif `disabled` à cet élément.

### Comportement

- Les attributs natifs, `className` et `style` sont transmis tels quels. Les clics sur les éléments racine désactivés sont bloqués.
- La ref transmise pointe vers l’élément racine rendu.
- Les propriétés `disabled`, `aria-disabled="true"` et `loading` ajoutent `data-disabled`.
- `loading` est un raccourci qui configure uniquement l’état : il définit `data-loading`, `aria-busy` et les styles désactivés, tandis que l’indicateur de chargement et le libellé restent entièrement composables.
- Les éléments `svg` enfants directs héritent de `currentColor` et utilisent `--moduix-button-icon-size`.
- Les boutons composés uniquement d’une icône doivent avoir un nom accessible.
- Les propriétés propres à Chakra `colorPalette`, les propriétés de recette responsives, `ButtonGroup` et les propriétés de chargement gérées sont volontairement exclues de ce contrat moduix limité à un seul élément racine.

### Sélecteurs de style

- `data-slot="button-root"` est le sélecteur moduix stable.
- Les éléments racine utilisés seuls adoptent par défaut `data-scope="button"` et `data-part="root"`. Un parent Ark qui compose Button peut les remplacer par ses propres valeurs d’anatomie.
- `data-variant` et `data-size` indiquent la variante et la taille visuelles actives.
- `data-disabled` est présent pour les propriétés natives `disabled`, `aria-disabled="true"` et `loading`.
- `data-loading` est présent lorsque `loading={true}`.
- `[data-disabled]` contrôle les styles de l’état désactivé pour `disabled`, `aria-disabled="true"` et `loading`.
- Les variantes actives du bouton utilisent un léger déplacement à l’appui ; `link` ne modifie que l’opacité, et le déplacement est supprimé lorsque l’utilisateur préfère réduire les animations.
