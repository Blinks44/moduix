## Référence de l’API

Ark UI ne fournit pas de primitive `button` dédiée. moduix construit ce composant à partir de l’outil officiel
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) et suit les recommandations d’Ark pour la
[composition](https://ark-ui.com/docs/guides/composition), le [style](https://ark-ui.com/docs/guides/styling) et la
[gestion des refs](https://ark-ui.com/docs/guides/ref).


Les mêmes exports sont disponibles depuis `@moduix/solid/button` pour Solid et `@moduix/vue/button` pour Vue.

## Anatomie

`Button` ne comporte qu’une seule partie.

```text
Button
└─ root[data-scope="button"][data-part="root"][data-slot="button-root"]
   └─ children
```

| Partie   | Rôle                                             |
| -------- | ------------------------------------------------ |
| `Button` | Élément interactif racine avec les styles moduix. |

## Composition

`Button` est une racine à partie unique. Utilisez `asChild` lorsqu’un autre élément sémantique doit porter le nœud DOM rendu : React reçoit exactement un enfant, Solid utilise une fonction de rendu avec `asChild` et Vue fournit l’élément sémantique comme contenu du slot par défaut. Lorsqu’une partie Ark compose Button, le parent reste propriétaire de `data-scope` et `data-part` ; Button conserve ses classes de recette et son `data-slot` stable.

La propriété `loading` ne gère que l’état occupé et désactivé (`data-loading`, `aria-busy` et `data-disabled`) ; l’application reste responsable de l’indicateur de chargement, du libellé et du cycle asynchrone. Les racines natives utilisent `type="button"` par défaut, mais les cibles `asChild` ne reçoivent pas cette valeur par défaut.

### Points d’accroche CSS

- `data-slot="button-root"` est le sélecteur moduix stable.
- Les éléments racine utilisés seuls adoptent par défaut `data-scope="button"` et `data-part="root"`. Un
  parent Ark qui compose Button peut les remplacer par ses propres valeurs d’anatomie.
- `data-variant` et `data-size` indiquent la variante et la taille visuelles actives.
- `data-disabled` est présent pour les propriétés natives `disabled`, `aria-disabled="true"` et `loading`.
- `data-loading` est présent lorsque `loading={true}`.
- `[data-disabled]` contrôle les styles de l’état désactivé pour `disabled`, `aria-disabled="true"` et `loading`.
- Les variantes actives du bouton utilisent un léger déplacement à l’appui ; `link` ne modifie que l’opacité,
  et le déplacement est supprimé lorsque l’utilisateur préfère réduire les animations.
