### Ref

La ref transmise pointe vers l’élément racine rendu ; vous pouvez l’utiliser pour lui donner le focus par programmation ou le mesurer. Dans Solid, attribuez la ref à l’élément créé dans la fonction de rendu `asChild` : une ref placée sur `Button` n’est pas transmise dans ce cas. Dans Vue, une ref de template pointe vers l’instance du composant ; utilisez `$el` pour accéder à la racine rendue, qui est l’élément sémantique enfant avec `asChild`. Dans Svelte, utilisez `bind:ref` sur `Button` : il contient l’élément racine rendu, qui est l’élément du snippet avec `asChild`.

## Composition

`Button` est une racine à partie unique construite avec la [fabrique Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory).
Utilisez `asChild` lorsqu’un autre élément sémantique doit porter le nœud DOM rendu : React reçoit exactement un
enfant, Solid utilise une fonction de rendu avec `asChild`, Vue fournit l’élément sémantique comme contenu du slot par défaut et Svelte utilise un snippet `asChild` qui applique `props()` à son élément sémantique. Lorsqu’une partie Ark compose Button, le parent garde ses propres `data-scope` et
`data-part` ; Button conserve ses classes de recette et son `data-slot` stable.

La propriété `loading` ne gère que l’état occupé et désactivé ; l’application reste responsable de l’indicateur
de chargement, du libellé et du cycle asynchrone. Les racines natives utilisent `type="button"` par défaut, mais
les cibles `asChild` ne reçoivent pas cette valeur par défaut.

## Styles

Commencez par une variante et une taille intégrées. Pour un ajustement ponctuel, définissez les variables
publiques `--moduix-button-*` sur le bouton via une classe ou un style en ligne. Pour personnaliser une
variante dans toute l’application, définissez les mêmes variables sur
`[data-slot='button-root'][data-variant='<variant>']`. Ces variables CSS concernent les paquets CSS Modules ;
les paquets Tailwind utilisent des utilitaires natifs et vos propres classes.

### Variables CSS

### Points d’accroche CSS

Utilisez `className` en React et `class` en Solid, Vue ou Svelte sur la racine. Ces attributs sont communs aux deux
approches de style.

| Attribut                  | Présent lorsque                                                              |
| ------------------------- | ---------------------------------------------------------------------------- |
| `data-slot="button-root"` | Toujours. Le sélecteur moduix stable.                                        |
| `data-scope`, `data-part` | `button` et `root` sur une racine seule ; un parent Ark les remplace.        |
| `data-variant`            | Toujours. Reflète la propriété `variant`.                                    |
| `data-size`               | Toujours. Reflète la propriété `size`.                                       |
| `data-loading`            | `loading` vaut `true`.                                                       |
| `data-disabled`           | `disabled`, `aria-disabled="true"` ou `loading`.                             |

Un Button utilisé seul se décale de 1px vers le bas à l’appui. Les variantes `link`, les déclencheurs avec
`aria-haspopup`, les éléments composés dont le `data-slot` est différent et la préférence de réduction des
animations désactivent ce déplacement.

## Clavier

Les boutons natifs conservent le comportement clavier du navigateur, et un lien avec `asChild` suit
celui de l’élément rendu. Donnez un nom accessible aux boutons composés uniquement d’une icône.

## Référence de l’API

| Propriété  | Type            | Par défaut  | Description |
| ---------- | --------------- | ----------- | --- |
| `variant`  | `ButtonVariant` | `'default'` | Style visuel : `default`, `outline`, `secondary`, `destructive`, `destructive-outline`, `ghost` ou `link`. |
| `size`     | `ButtonSize`    | `'md'`      | `xs`, `sm`, `md`, `lg`, `xl`, ou les tailles carrées `icon-sm`, `icon-md`, `icon-lg` pour un bouton icône. |
| `loading`  | `boolean`       | `false`     | Définit `aria-busy` et bloque l’activation. Ajoutez votre propre `Spinner`. |
| `asChild`  | `boolean`       | `false`     | Applique les styles et propriétés de Button à son unique enfant, par exemple un lien. |
| `disabled` | `boolean`       | `false`     | Désactive le bouton. |
