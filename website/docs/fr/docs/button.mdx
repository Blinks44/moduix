## Référence de l’API

Ark UI ne fournit pas de primitive `button` dédiée. moduix construit ce composant à partir de l’outil officiel
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) et suit les recommandations d’Ark pour la
[composition](https://ark-ui.com/docs/guides/composition), le [style](https://ark-ui.com/docs/guides/styling) et la
[gestion des refs](https://ark-ui.com/docs/guides/ref).

## Anatomie

`Button` ne comporte qu’une seule partie.

```text
Button.Root
└─ root[data-scope="button"][data-part="root"][data-slot="button-root"]
   └─ children
```

| Partie                   | Rôle                                                        |
| ------------------------ | ----------------------------------------------------------- |
| `Button` / `Button.Root` | Élément interactif racine avec les styles moduix.            |
| `Button`                 | Alias de `Button.Root`, utilisable directement.              |

## Composition

### Composition recommandée

Pour une action, utilisez l’élément racine natif. Il utilise `type="button"` par défaut, ce qui évite de
soumettre accidentellement le formulaire. Définissez explicitement `type="submit"` lorsque le bouton
doit envoyer le formulaire.

### Propriétés par défaut

| Propriété | Valeur par défaut | Valeurs                                                                                |
| --------- | ----------------- | -------------------------------------------------------------------------------------- |
| `loading` | `false`           | `boolean`                                                                              |
| `variant` | `default`         | `default`, `outline`, `secondary`, `destructive`, `destructive-outline`, `ghost`, `link` |
| `size`    | `md`              | `xs`, `sm`, `md`, `lg`, `xl`, `icon-sm`, `icon-md`, `icon-lg`                         |
| `type`    | `button`          | Éléments racine natifs uniquement                                                      |
| `asChild` | `false`           | Utilise l’unique enfant comme racine rendue                                             |

### Quand utiliser un élément personnalisé

Utilisez `asChild` lorsqu’un élément sémantique existant doit porter le nœud DOM rendu. La composition
Ark exige exactement un enfant. La valeur par défaut `type="button"` n’est pas ajoutée à l’élément
utilisé avec `asChild`.

Lorsque `Dialog.Trigger`, `Menu.Trigger` ou une autre partie d’Ark compose Button comme enfant, les
`data-scope` et `data-part` de la partie parente sont prioritaires sur le nœud DOM partagé. Button
conserve ses classes de style et son `data-slot` stable ; Ark continue de fusionner les gestionnaires
du déclencheur et les refs.

Pour la navigation, utilisez un véritable élément `<a>`. Sur l’élément utilisé avec `asChild`, les
propriétés `disabled`, `loading` et `aria-disabled="true"` signalent l’état désactivé via
`aria-disabled`, appliquent les styles correspondants et bloquent l’activation au clic. L’attribut
natif `disabled` n’est pas ajouté à cet élément.

### Comportement

- Les attributs natifs, `style` et les gestionnaires d’événements sont transmis à la racine. `className`
  est combiné avec les styles moduix, et l’activation est bloquée lorsque la racine est désactivée.
- La ref transmise pointe vers l’élément racine rendu.
- Les propriétés `disabled`, `aria-disabled="true"` et `loading` ajoutent `data-disabled`.
- `loading` est un raccourci qui configure uniquement l’état : il définit `data-loading`, `aria-busy` et
  les styles désactivés. Vous gardez la main sur le libellé et l’indicateur de chargement.
- Les éléments `svg` enfants directs héritent de `currentColor` et utilisent `--moduix-button-icon-size`.
- Un bouton composé uniquement d’une icône doit avoir un nom accessible.
- Les API propres à Chakra, comme `colorPalette`, les propriétés de recette responsives, `ButtonGroup` et
  les propriétés de chargement gérées, ne font volontairement pas partie du contrat moduix à un seul
  élément racine.

### Points d’accroche CSS

- `data-slot="button-root"` est le sélecteur moduix stable.
- Les éléments racine utilisés seuls adoptent par défaut `data-scope="button"` et `data-part="root"`. Un
  parent Ark qui compose Button peut les remplacer par ses propres valeurs d’anatomie.
- `data-variant` et `data-size` indiquent la variante et la taille visuelles actives.
- `data-disabled` est présent pour les propriétés natives `disabled`, `aria-disabled="true"` et `loading`.
- `data-loading` est présent lorsque `loading={true}`.
- `[data-disabled]` contrôle les styles de l’état désactivé pour `disabled`, `aria-disabled="true"` et `loading`.
- Les variantes actives du bouton utilisent un léger déplacement à l’appui ; `link` ne modifie que l’opacité,
  et le déplacement est supprimé lorsque l’utilisateur préfère réduire les animations.
