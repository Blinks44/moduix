## Choisir le bon composant

Utilisez `AngleSlider` lorsque l’utilisateur doit définir une direction ou une rotation à l’aide d’un cadran
circulaire.

- Choisissez **`AngleSlider`** pour faire pivoter un objet, définir un cap, orienter un projecteur ou régler toute
  autre valeur angulaire.
- Choisissez **`Slider`** lorsque la valeur est plus facile à choisir sur une échelle linéaire.
- Choisissez **`NumberInput`** lorsque la saisie précise d’une valeur en degrés est plus importante qu’une
  manipulation directe.


Les mêmes exports sont disponibles depuis `@moduix/solid/angle-slider` pour Solid.

## Anatomie

```text
AngleSlider.Root
├─ AngleSlider.Label
├─ AngleSlider.Control
│  ├─ AngleSlider.MarkerGroup
│  │  └─ AngleSlider.Marker[value]
│  └─ AngleSlider.Thumb
├─ AngleSlider.ValueText
└─ AngleSlider.HiddenInput (explicite)
```

| Partie                             | Rôle                                                                    |
| ---------------------------------- | ----------------------------------------------------------------------- |
| `AngleSlider` / `AngleSlider.Root` | Racine stylisée qui gère l’état contrôlé ou non contrôlé du curseur.    |
| `AngleSlider.HiddenInput` | Champ natif d’Ark ; composition explicite décrite ci-dessous. |
| `AngleSlider.RootProvider`         | Relie les parties à l’état Ark créé en dehors de l’arborescence rendue.  |
| `AngleSlider.Label`                | Associe une étiquette visible au curseur.                               |
| `AngleSlider.Control`              | Fournit la zone circulaire d’interaction avec le pointeur.              |
| `AngleSlider.Dial`                 | Associe `Control` et `Thumb` ; accepte des enfants.                           |
| `AngleSlider.MarkerGroup`          | Contient les marqueurs de référence facultatifs.                        |
| `AngleSlider.Marker`               | Place un marqueur numérique et indique sa relation avec la valeur courante. |
| `AngleSlider.Marks`                | Composition pratique qui crée les marqueurs à partir d’un tableau `values`. |
| `AngleSlider.Thumb`                | Poignée pouvant recevoir le focus et indiquant l’angle courant.          |
| `AngleSlider.ValueText`            | Affiche la valeur actuelle en degrés.                                   |

Composez explicitement `AngleSlider.HiddenInput` dans `Root` ou `RootProvider` lorsque la valeur
doit participer à un formulaire natif.

## Composition

Utilisez `defaultValue` pour un curseur non contrôlé et `value` avec `onValueChange(details)` lorsque l’angle est géré par une autre partie de l’application. Utilisez `AngleSlider.RootProvider` avec `useAngleSlider()` du framework concerné uniquement lorsque le store doit être créé en dehors de l’arbre du curseur ; ne rendez pas `Root` et `RootProvider` pour la même instance d’état. En Solid, lisez le store fourni via son accessor, par exemple `angleSlider().value`.

`Dial` et `Marks` sont des compositions pratiques. Utilisez `Control` avec `Thumb`, ou `MarkerGroup` avec `Marker`, lorsque vous avez besoin d’enfants personnalisés, d’un ordre différent ou de propriétés propres à chaque marqueur. Composez explicitement `HiddenInput` pour les formulaires natifs. Définissez `name` sur la racine si le formulaire se trouve dans le même arbre, ou `form` sur `HiddenInput` si le formulaire est ailleurs.

## Styles

Personnalisez l’apparence du composant avec `className` en React ou `class` en Solid, les sélecteurs
stables `data-slot="angle-slider-*"`, les attributs Ark `data-scope="angle-slider"` / `data-part` et
les attributs d’état. Les variantes Tailwind se personnalisent avec des utilitaires et des classes
supplémentaires ; les variables de composant ci-dessous concernent uniquement les variantes CSS
Modules. Les variables d’exécution Ark et les sélecteurs indiqués restent disponibles dans les deux
approches.

### Sélecteurs de style

- `data-slot="angle-slider-root"` et `data-slot="angle-slider-root-provider"` fournissent la mise en page commune.
- `data-slot="angle-slider-control"` style le cadran et reçoit `data-disabled`, `data-invalid` et `data-readonly`.
- `data-slot="angle-slider-thumb"` identifie l’indicateur rotatif qui peut recevoir le focus et être ciblé avec
  `:focus-visible`.
- `data-slot="angle-slider-marker"` expose `data-value` et
  `data-state="under-value | at-value | over-value"`.
- `AngleSlider.Marks` expose les mêmes sélecteurs `data-slot="angle-slider-marker-group"` et
  `data-slot="angle-slider-marker"` que les parties de marqueur explicites.
- Les variables Ark du root `--value` et `--angle`, ainsi que les variables de marqueur `--marker-value` et
  `--marker-display-value`, restent disponibles.
- Les couleurs de l’anneau au survol et lors de l’appui s’appliquent uniquement lorsque le cadran est interactif.
  Les transitions de la poignée sont supprimées lorsque l’utilisateur préfère réduire les mouvements.
