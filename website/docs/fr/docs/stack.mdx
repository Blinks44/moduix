## Référence de l’API

Ark UI ne propose pas de primitive `Stack` dédiée. moduix implémente ce composant avec la [fabrique officielle
d’Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) et suit ses recommandations pour la
[composition](https://ark-ui.com/docs/guides/composition), les [styles](https://ark-ui.com/docs/guides/styling) et
les [refs](https://ark-ui.com/docs/guides/ref). La documentation de [Stack](https://chakra-ui.com/docs/components/stack)
de Chakra UI sert uniquement de référence pour les noms des propriétés de mise en page.

## Anatomie

`Stack` rend un seul conteneur flex racine, basé sur le modèle de fabrique d’Ark. Il gère la direction, l’espacement,
l’alignement, le retour à la ligne et un simple changement de direction responsive. Gardez les règles de mise en page
plus générales dans votre CSS local.

```text
Stack / Stack.Root
└─ root[data-scope="stack"][data-part="root"][data-slot="stack-root"]
   └─ children
```

| Partie                 | Rôle                                                                    |
| ---------------------- | ----------------------------------------------------------------------- |
| `Stack` / `Stack.Root` | Conteneur flex racine pour la direction, l’espacement, l’alignement et l’écart entre les enfants. |

## Composition

`Stack` ne gère aucun état et n’expose qu’une racine. Utilisez la forme courte `<Stack>` pour rendre normalement un
`div` ; `Stack.Root` est un alias de cette même racine. `fill` agit sur le `Stack` en tant qu’élément flex, et non sur
ses enfants. Ajoutez directement `Separator` lorsqu’un séparateur est nécessaire et utilisez `asChild` lorsque la
racine doit être un élément sémantique.

## Styles

Utilisez `className` en React ou `class` en Solid sur la racine pour les styles structurels. Les variantes Tailwind
utilisent des classes utilitaires natives et les surcharges du consommateur ; les variables CSS ci-dessous
personnalisent les variantes CSS Modules. Les attributs de données et le hook `data-slot` sont communs aux deux
approches de style.

### Propriétés CSS

`Stack` expose des variables CSS publiques sur sa racine. Par défaut, elles prennent les valeurs `column` et `initial` ;
les propriétés `direction` et `fill` écrivent des valeurs inline lorsqu’elles sont fournies, et `style` peut les
remplacer pour une instance donnée.

### Points d’accroche CSS

- `className` ou `class` applique les styles à l’unique racine pour la largeur, les espacements internes, les bordures, les arrière-plans et les autres aspects visuels.
- `data-scope="stack"` et `data-part="root"` alignent l’enveloppe sur les conventions de style d’Ark.
- `data-slot="stack-root"` est le sélecteur moduix stable permettant de cibler la racine dans le CSS local.
- `style` est appliqué en dernier et peut donc remplacer les valeurs calculées de `gap`, `alignItems`, `justifyContent`, `flexWrap` et toute variable `--moduix-stack-*` écrite par les propriétés.
- Le contrat public ne contient aucun attribut d’état, aucune variable d’animation CSS et aucune map `slotProps`.
