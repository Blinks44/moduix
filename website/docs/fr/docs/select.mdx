## Choisir le bon composant

Utilisez `Select` lorsque l’utilisateur choisit une valeur dans une collection fixe et ne saisit pas
de texte dans le déclencheur. Préférez `Combobox` lorsqu’une saisie permet de rechercher ou de
créer une valeur.

## Exemple de base

Passez une collection à `Select`, utilisez `Select.Field` pour le contrôle visible standard et gardez la structure de la fenêtre contextuelle explicite. `clearLabel` ajoute une action d’effacement accessible. Ajoutez explicitement `Select.HiddenSelect` lorsque la soumission, le remplissage automatique, la validation et la réinitialisation natives sont nécessaires.

## Anatomie

```text
Select / Select.Root
├─ Select.Label
├─ Select.Control / Select.Field
│  ├─ Select.Trigger
│  │  ├─ Select.ValueText
│  ├─ Select.ClearTrigger
│  └─ Select.Indicator
├─ Sous-arbre de l’overlay (portail automatique)
│  └─ Select.Positioner
│     └─ Select.Content
│        ├─ Select.List
│        └─ Select.ItemGroup
│           ├─ Select.ItemGroupLabel
│           └─ Select.Item[item]
│              ├─ Select.ItemText
│              │  └─ Select.ItemTextContent
│              │     ├─ Select.ItemTextIcon
│              │     └─ Select.ItemTextLabel
│              └─ Select.ItemIndicator
└─ Select.HiddenSelect (explicite)
```

| Partie                    | Rôle                                                                                             |
| ------------------------- | ------------------------------------------------------------------------------------------------ |
| `Select` / `Select.Root`  | État racine, collection, sélection, cycle de vie de la fenêtre contextuelle et données du formulaire. |
| `Select.HiddenSelect` | Champ natif d’Ark ; composition explicite décrite ci-dessous. |
| `Select.RootProvider`     | Affiche l’arborescence Select à partir de l’état renvoyé par `Select.useSelect`.                 |
| `Select.Label`            | Libellé accessible associé au déclencheur et au contrôle de formulaire natif.                   |
| `Select.Control`          | Enveloppe du champ visible qui reflète les états de focus, d’erreur et d’ouverture.              |
| `Select.Field`            | Composant utilitaire moduix pour le champ, le déclencheur et les actions standard.               |
| `Select.Trigger`          | Bouton qui ouvre la fenêtre contextuelle et gère la saisie au clavier.                          |
| `Select.ValueText`        | Placeholder ou libellés des éléments sélectionnés.                                               |
| `Select.ClearTrigger`     | Bouton qui efface la valeur actuelle.                                                            |
| `Select.Indicator`        | Indicateur du déclencheur avec l’icône de flèche moduix par défaut.                              |
| `Select.Positioner`       | Calque flottant qui expose les variables CSS Ark pour le positionnement.                        |
| `Select.Content`          | Contenu de la fenêtre contextuelle et conteneur de la listbox.                                   |
| `Select.List`             | Enveloppe de liste facultative pour la virtualisation et les mises en page personnalisées.      |
| `Select.ItemGroup`        | Enveloppe d’un groupe d’éléments associés de la collection.                                     |
| `Select.ItemGroupLabel`   | Libellé d’un groupe de la collection.                                                            |
| `Select.Item`             | Ligne sélectionnable. Passez l’élément de collection avec `item`.                               |
| `Select.ItemText`         | Texte utilisé pour l’affichage et l’accessibilité.                                               |
| `Select.ItemTextContent`  | Composant de mise en page pour du texte d’élément enrichi.                                       |
| `Select.ItemTextIcon`     | Conteneur d’icône pour du texte d’élément enrichi.                                               |
| `Select.ItemTextLabel`    | Conteneur de libellé pour du texte d’élément enrichi.                                            |
| `Select.ItemIndicator`    | Indicateur de sélection avec l’icône de coche moduix par défaut.                                 |

## Composition

`Select.Field` est le raccourci pour `Control`, `Trigger`, `ValueText` et l’`Indicator` par défaut. Ajoutez `clearLabel` pour une action d’effacement libellée, ou utilisez les parties explicites lorsque la mise en page du déclencheur doit être stylisée indépendamment. Gardez `Positioner`, `Content` et les éléments de la collection dans la même arborescence Select.

Ajoutez explicitement `Select.HiddenSelect` dans `Select` ou `Select.RootProvider` lorsque la sélection doit participer à la soumission native, à la validation, au remplissage automatique ou à la réinitialisation du formulaire. La racine ne l’affiche pas automatiquement. `Positioner` est rendu dans un portail par défaut ; utilisez `portalled={false}` pour le rendre dans le flux normal ou `portalRef` pour un conteneur personnalisé.

Utilisez `Select.useSelect` avec `Select.RootProvider` lorsque l’état doit être partagé avec des contrôles situés en dehors de l’arborescence Select. Le store renvoyé est un objet en React et un accessor en Solid.

## Styles

Stylisez Select avec `className` en React ou `class` en Solid, les hooks stables `data-slot="select-*"`, les attributs Ark et les variables CSS publiques `--moduix-select-*`. Les variantes Tailwind utilisent des classes utilitaires natives et les classes du consommateur ; les variantes CSS Modules utilisent les variables documentées ci-dessous.

### Propriétés CSS

<CssPropertiesSection properties={SelectDocs.selectOverrideCssProperties} />

### Points d’accroche CSS

`Select.Field` affiche les slots existants `select-control`, `select-trigger`, `select-value-text`,
`select-indicator` et le slot facultatif `select-clear-trigger`. Sa propriété `indicator` fournit
l’enfant du slot d’indicateur existant. Les composants de texte enrichi exposent les slots
`select-item-text-content`, `select-item-text-icon` et `select-item-text-label`.

- Les racines fournissent `data-slot="select-root"` et `data-slot="select-root-provider"`.
- L’anatomie Ark utilise `data-scope="select"` et `data-part`.
- Le style des états utilise `data-state="open" | "closed"`, `data-focus`, `data-invalid`,
  `data-disabled`, `data-readonly`, `data-required`, `data-placeholder-shown`,
  `data-highlighted` et, pour les éléments, `data-state="checked" | "unchecked"`.
- `Select.Positioner` fournit `--reference-width`, `--reference-height`, `--available-width`,
  `--available-height`, `--x`, `--y`, `--z-index` et `--transform-origin`.
