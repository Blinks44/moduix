# Thèmes

Les thèmes sont des couches de tokens CSS. `Calm` est le thème par défaut ; `Dense`, `Soft` et
`Contrast` sont des préréglages facultatifs qui modifient la palette, les rayons, l’espacement, la
densité et les ombres sans toucher à l’API des composants.

<ThemePresets />

## Choisir un préréglage

Les tailles indiquent la hauteur par défaut des contrôles principaux et des lignes de liste contextuelle de chaque préréglage.

| Préréglage | Contrôle / ligne de liste | Bon point de départ pour                                                                              |
| ---------- | ------------------------- | ----------------------------------------------------------------------------------------------------- |
| Calm       | 36px / 32px               | Les écrans d’application avec des couleurs neutres et un espacement standard.                         |
| Dense      | 34px / 30px               | Les interfaces d’administration et les tableaux de données, avec un espacement compact et des accents bleus. |
| Soft       | 40px / 34px               | Les interfaces avec de grands contrôles, des coins arrondis et des accents violets.                   |
| Contrast   | 36px / 32px               | Les interfaces avec des bordures et des indicateurs de focus plus marqués.                            |

:::info Testez avec votre contenu
Les noms des préréglages indiquent une direction visuelle, pas une garantie d’accessibilité.
Vérifiez le contraste du texte, la visibilité du focus, le zoom et la taille des cibles avant la
mise en production.
:::

## Comment fonctionnent les couches

Le socle définit le contrat complet des tokens et les valeurs de `Calm`. Un préréglage redéfinit
certaines valeurs, votre application ne modifie que ses propres choix, et les composants lisent les
alias obtenus.

```text
foundation tokens → optional preset → application overrides → component aliases
```

## Utiliser le registre

Les préréglages partagent le registre du socle entre les frameworks et les méthodes de style.
Installez chaque préréglage que vous voulez proposer.

<PackageManagerTabs command="shadcn@latest add https://moduix.dev/r/foundation/theme-dense.json" dlx />

```tsx
import '@/lib/moduix/styles/style.css';
import '@/lib/moduix/presets/dense.css';
```

## Changer de thème à l’exécution

Chargez d’abord les préréglages sélectionnables. Appliquez le choix sur `html` pour que le contenu
rendu dans un portail reçoive les mêmes tokens.

```ts
document.documentElement.dataset.moduixTheme = 'soft';
document.documentElement.dataset.moduixColorScheme = 'dark';
```

## Personnaliser un préréglage

Chargez les redéfinitions de votre produit après le préréglage. Modifiez les tokens sémantiques pour
les choix communs à plusieurs composants.

```css
[data-moduix-theme='soft'] {
  --moduix-primary: oklch(0.5 0.17 285);
  --moduix-radius: 0.875rem;
}
```

## Créer un thème personnalisé

Partez du socle et ajoutez une couche CSS nommée. Les valeurs omises gardent celles du socle.

Pour choisir les valeurs visuellement ou reprendre un thème shadcn, ouvrez le [créateur de thème](/docs/theme-builder).

```css
/* brand.css · chargé après le socle */
[data-moduix-theme='brand'] {
  --moduix-primary: oklch(0.5 0.17 250);
  --moduix-radius: 0.75rem;
}

/* À appliquer sur html : data-moduix-theme="brand" */
```
