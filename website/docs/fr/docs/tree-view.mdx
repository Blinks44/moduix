Créez la collection de données avec `createTreeCollection`, puis transmettez-la à `TreeView`.
`TreeViewNode` fournit au rendu récursif les valeurs courantes `node`, `indexPath` et `state`, ce qui
permet d’afficher une branche ou une feuille tout en gardant la structure des parties explicite.

React, Solid et Vue utilisent les mêmes noms plats pour TreeView ; les onglets ci-dessous conservent la composition native de chaque framework.

## Exemples

### Liens

Utilisez `asChild` sur `TreeViewItem` lorsqu’une feuille doit être un seul élément sémantique,
comme un lien. Cet élément doit accepter les props Ark afin de préserver le focus et la navigation au
clavier.

<Example name="tree-view/links" />

### Chargement asynchrone

Pour une branche dont la valeur `childrenCount` est connue, chargez les enfants avec `loadChildren`.
Dans `onLoadChildrenComplete`, remplacez la collection de l’application par `details.collection`.

<Example name="tree-view/async-loading" />

### Arborescence avec cases à cocher

Placez `TreeViewNodeCheckbox` dans les contrôles de branche comme dans les feuilles. Son indicateur par défaut
couvre déjà les états coché et indéterminé.

En Vue, le slot par défaut définit l’icône de l’état coché, et les slots nommés `indeterminate`
et `fallback` celles des états indéterminé et non coché. Personnalisez ces états avec les slots,
et non avec des props.

<Example name="tree-view/checkboxes" />

### Icônes de fichiers

Placez les icônes décoratives de fichiers et de dossiers dans `TreeViewBranchText` et `TreeViewItemText`. Gardez
`TreeViewBranchIndicator` séparé afin qu’il reste le seul élément consacré au dépliage et au repliage.

<Example name="tree-view/file-icons" />

### Sélection multiple

Définissez `selectionMode="multiple"`. Utilisez Ctrl ou ⌘ pour ajouter ou retirer des éléments
individuels, et Maj pour étendre une plage de sélection. L’exemple conserve les valeurs sélectionnées
dans l’état de l’application.

<Example name="tree-view/controlled-selection" />

### Root provider

Créez l’état de l’arborescence avec `useTreeView` si des contrôles extérieurs doivent appeler des
méthodes comme `expand()` ou `collapse()`. Transmettez cet état à `TreeViewRootProvider` au lieu de rendre un
second `TreeView`. Cet exemple montre aussi la composition bas niveau d’un nœud : chaque nœud utilise
`TreeViewNodeProvider` et lit son état dans `TreeViewNodeContext` au lieu du raccourci `TreeViewNode`.

## Composition

Utilisez `TreeViewNode` pour le rendu récursif. Il fournit `node`, `indexPath` et l’état courant du
nœud, tandis que vous choisissez les parties `TreeViewBranch` ou `TreeViewItem`. Si votre composant récursif doit
accéder directement au contexte du nœud, utilisez `TreeViewNodeProvider` directement. Lorsque des contrôles externes doivent gérer l’état de l’arborescence,
créez-le avec `useTreeView` et transmettez-le à `TreeViewRootProvider` ; ne rendez pas un second root
pour la même instance. Si une branche utilise un `TreeViewBranchTrigger` distinct, ajoutez `role="none"` à
`TreeViewBranchControl`.

En Vue, `TreeViewNode` fournit les données de rendu dans le slot par défaut avec paramètres.
Contrôlez les valeurs avec `v-model:expanded-value`, `v-model:selected-value`,
`v-model:checked-value` et `v-model:focused-value` ; les événements comme `@selection-change`
conservent les objets de détails Ark. Stockez une collection remplaçable dans une `shallowRef`
pour que Vue préserve son instance de classe.

## Styles

Utilisez `className` en React, `class` en Solid ou `class` en Vue sur chaque partie exportée pour les styles
structurels. Les parties de branche exposent `data-state="open|closed"`, celles des cases à cocher
`data-state="checked|unchecked|indeterminate"`, et celles des nœuds exposent `data-focus`,
`data-selected`, `data-disabled`, `data-loading`, `data-renaming`, `data-depth`, `data-path` et
`data-value`. Le composant respecte les variables Ark `--depth` pour l’indentation et `--height` pour
la hauteur pendant le repli, et désactive l’animation des branches si l’utilisateur préfère réduire
les mouvements.

Les variantes Tailwind utilisent des classes utilitaires natives et les classes de l’application. Les
variantes CSS Modules prennent les couleurs, les espacements et la typographie dans les tokens de
foundation et n'exposent en variables CSS que la largeur de la racine et le pas d'indentation ;
surchargez le reste avec une classe sur la partie.

## Clavier

| Touche | Action |
| --- | --- |
| `ArrowDown` / `ArrowUp` | Déplace le focus vers le nœud visible suivant ou précédent. |
| `ArrowRight` | Ouvre une branche fermée ou entre dans une branche ouverte. |
| `ArrowLeft` | Ferme une branche ouverte ou remonte au parent. |
| `Home` / `End` | Déplace le focus vers le premier ou le dernier nœud. |
| `Enter` / `Space` | Sélectionne le nœud ou bascule une branche. |
| `*` | Ouvre toutes les branches sœurs. |
| Lettres | Déplace le focus vers le nœud visible suivant qui commence par le texte saisi. |
| `Ctrl+A` / `Cmd+A` | Sélectionne tous les nœuds lorsque selectionMode vaut multiple. |
| `F2` | Lance le renommage si canRename l’autorise. |
