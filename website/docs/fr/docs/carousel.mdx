## Anatomie

```text
Carousel / Carousel.Root
├─ Carousel.ItemGroup
│  └─ Carousel.Item[index]
├─ Carousel.Control
│  ├─ Carousel.PrevTrigger
│  └─ Carousel.NextTrigger
├─ Carousel.Indicators
│  └─ Carousel.IndicatorGroup
│     └─ Carousel.Indicator[index]
└─ Carousel.ProgressText
```

| Partie                       | Rôle                                                                                 |
| ---------------------------- | ------------------------------------------------------------------------------------ |
| `Carousel` / `Carousel.Root` | Gère l’état du carrousel, la navigation et la collection d’éléments.               |
| `Carousel.Control`           | Conteneur des déclencheurs de navigation et des contrôles associés.                  |
| `Carousel.ItemGroup`         | Piste des diapositives contenant les parties `Carousel.Item`.                        |
| `Carousel.Item`              | Diapositive individuelle avec un `index` stable.                                     |
| `Carousel.PrevTrigger`       | Déclencheur vers la page précédente.                                                 |
| `Carousel.NextTrigger`       | Déclencheur vers la page suivante.                                                   |
| `Carousel.Indicators`        | Composant pratique moduix pour les indicateurs de page par défaut.                   |
| `Carousel.IndicatorGroup`    | Conteneur des indicateurs de page.                                                   |
| `Carousel.Indicator`         | Déclencheur d’indicateur pour un index de diapositive ou de page donné.              |
| `Carousel.ProgressText`      | Texte affichant la page actuelle et le nombre total de pages.                        |

Ces parties plus avancées restent disponibles lorsque vous avez besoin d’un contrôle plus fin :

- `Carousel.Context`
- `Carousel.AutoplayTrigger`
- `Carousel.AutoplayIndicator`
- `Carousel.RootProvider`

`useCarousel` et `useCarouselContext` sont disponibles depuis `@moduix/react`.

## Composition

### Composition recommandée

Utilisez `Carousel` comme racine, `Carousel.ItemGroup` comme piste et `Carousel.Control` pour la navigation.
Ajoutez `Carousel.Indicators` lorsque la pagination par points par défaut suffit.

`Carousel.Control` se place généralement à côté de `Carousel.ItemGroup` dans une barre d’outils.

`Carousel.Root` est un alias explicite de `Carousel`. Utilisez-le lorsque vous préférez la forme avec espace de noms.

### Quand passer à une composition personnalisée

Utilisez `Carousel.Context` avec `Carousel.IndicatorGroup` et `Carousel.Indicator` lorsque vous avez besoin d’une
mise en page de pagination personnalisée, d’indicateurs sous forme de miniatures ou d’un contrôle plus précis de
`pageSnapPoints`.

Utilisez `Carousel.RootProvider` de moduix avec `useCarousel()` lorsque vous devez créer l’état du carrousel
en dehors du sous-arbre rendu.

Utilisez `useCarouselContext()` dans un composant enfant personnalisé qui a besoin de l’API du carrousel sans
utiliser de render prop.

Utilisez `Carousel.AutoplayTrigger` et `Carousel.AutoplayIndicator` lorsque les contrôles de lecture automatique
doivent être visibles dans l’interface et non définis uniquement par une propriété de la racine.

### Propriétés par défaut

| Propriété    | Valeur par défaut | Remarques                                         |
| ------------ | ----------------- | ------------------------------------------------- |
| `slideCount` | -                 | Requis pour `Carousel` / `Carousel.Root`.         |

### Comportement

- `onPageChange(details)` utilise la forme de callback d’Ark et expose la page active via `details.page`.
- Ajoutez `aria-label` ou `aria-labelledby` à `Carousel` ou `Carousel.RootProvider` pour donner un nom accessible
  au repère du carrousel.
- `spacing`, `padding`, `slidesPerPage`, `slidesPerMove` et `autoSize` reprennent directement le comportement d’Ark
  pour les dimensions et les points d’accroche.
- Les carrousels verticaux utilisent la même API publique. Si le composant utilise les chevrons moduix, les
  déclencheurs par défaut pivotent automatiquement.
- Avec `dir="rtl"`, les déclencheurs horizontaux par défaut s’inversent automatiquement.
- `Carousel.ProgressText` conserve l’ordre numérique lisible « actuel / total » dans les carrousels RTL.
- `--moduix-carousel-indicator-size` contrôle le bouton indicateur compact ; son anneau de focus suit
  donc la géométrie du point ou de la capsule active.
- Avec `prefers-reduced-motion: reduce`, la piste défile immédiatement et moduix désactive les transitions des
  contrôles et des indicateurs.

## Styles

Utilisez `className` sur les parties exportées pour modifier leur structure. Pour les styles liés à l’état, préférez
les attributs de données d’Ark (`data-part`, `data-orientation`, `data-current`, `data-dragging`) et les hooks
`data-slot` de moduix.

### Points d’accroche CSS

- `data-slot="carousel-root"`, `carousel-control`, `carousel-item-group`, `carousel-item`,
  `carousel-prev-trigger`, `carousel-next-trigger`, `carousel-indicator-group`,
  `carousel-indicator`, `carousel-autoplay-trigger`, `carousel-autoplay-indicator` et
  `carousel-progress-text` sont des sélecteurs stables des parties exportées.
- Ark ajoute également `data-scope="carousel"` et les noms `data-part` aux nœuds rendus.
- `data-orientation="horizontal" | "vertical"` est disponible sur le composant racine et les parties structurelles.
- `Carousel.ItemGroup` expose `data-dragging` pendant le glissement.
- `Carousel.Indicator` expose `data-current`, tandis que `Carousel.Item` expose `data-index` et `data-inview`.
- `Carousel.Indicator` expose `data-readonly`, tandis que `Carousel.AutoplayTrigger` expose `data-pressed`.
