## Anatomie

```text
Carousel / Carousel.Root
├─ Carousel.ItemGroup
│  └─ Carousel.Item[index]
├─ Carousel.Control
│  ├─ Carousel.PrevTrigger
│  └─ Carousel.NextTrigger
├─ Carousel.IndicatorGroup
│  └─ Carousel.Indicator[index]
└─ Carousel.ProgressText
```

| Élément                       | Rôle                                                                       |
| ---------------------------- | -------------------------------------------------------------------------- |
| `Carousel` / `Carousel.Root` | Crée le carrousel et gère son état, sa navigation et sa liste de diapositives. |
| `Carousel.RootProvider`       | Relie les éléments à l’état créé avec `useCarousel()`.                    |
| `Carousel.Control`            | Conteneur des boutons de navigation et des autres contrôles.              |
| `Carousel.ItemGroup`          | Piste contenant les éléments `Carousel.Item`.                             |
| `Carousel.Item`               | Diapositive individuelle avec un `index` stable.                           |
| `Carousel.PrevTrigger`        | Bouton qui passe à la page précédente.                                     |
| `Carousel.NextTrigger`        | Bouton qui passe à la page suivante.                                       |
| `Carousel.Indicators`         | Composant pratique moduix qui génère les indicateurs de page par défaut.   |
| `Carousel.IndicatorGroup`     | Conteneur pour les indicateurs de page personnalisés.                     |
| `Carousel.Indicator`          | Bouton qui mène à la page correspondant à l’index indiqué.                 |
| `Carousel.ProgressText`       | Texte affichant la page actuelle et le nombre total de pages.              |

`Carousel.Indicators` lit `pageSnapPoints` dans le contexte et génère un `Carousel.Indicator` par page.
Utilisez-le à la place de `Carousel.IndicatorGroup` lorsque les indicateurs par défaut suffisent.
Vous pouvez aussi lui passer `indicatorClassName` pour styliser les indicateurs générés.

Pour les compositions avancées, ces parties sont également disponibles :

- `Carousel.Context`
- `Carousel.AutoplayTrigger`
- `Carousel.AutoplayIndicator`
- `Carousel.RootProvider`

`Carousel`, `useCarousel` et `useCarouselContext` sont disponibles depuis `@moduix/react`. Vous pouvez
aussi importer le composant depuis `@moduix/react/carousel`.

## Composition

### Composition recommandée

Utilisez `Carousel` comme racine, `Carousel.ItemGroup` comme piste et `Carousel.Control` pour la navigation.
Ajoutez `Carousel.Indicators` lorsque les indicateurs par défaut en forme de points suffisent.

`Carousel.Control` est généralement placé à côté de `Carousel.ItemGroup` et sert de barre d’outils.
Pour une disposition compacte en ligne, vous pouvez placer `Carousel.ItemGroup` à l’intérieur de
`Carousel.Control`.

`Carousel.Root` est un alias explicite de `Carousel`. Utilisez-le lorsque vous préférez la forme avec espace
de noms dans votre code.

### Quand utiliser une composition personnalisée

Utilisez `Carousel.Context` avec `Carousel.IndicatorGroup` et `Carousel.Indicator` lorsque vous avez besoin
d’une pagination personnalisée, d’indicateurs sous forme de miniatures ou d’un accès direct à
`pageSnapPoints`.

Utilisez `Carousel.RootProvider` avec `useCarousel()` lorsque l’état du carrousel doit être créé en dehors
du sous-arbre rendu et partagé entre plusieurs parties de la composition.

Utilisez `useCarouselContext()` dans vos composants enfants personnalisés lorsqu’ils ont besoin de l’API du
carrousel sans fonction de rendu passée comme enfant.

Utilisez `Carousel.AutoplayTrigger` et `Carousel.AutoplayIndicator` lorsque les contrôles de lecture automatique
doivent être visibles dans l’interface plutôt que configurés uniquement sur la racine.

### Propriétés par défaut

| Propriété    | Valeur par défaut | Remarques                                                                       |
| ------------ | ----------------- | ------------------------------------------------------------------------------ |
| `slideCount` | -                 | Requis sur `Carousel` / `Carousel.Root` ; passez-le à `useCarousel()` avec `RootProvider`. |

### Points importants sur le comportement

- `onPageChange(details)` reprend la signature de callback d’Ark et expose la page active dans `details.page`.
- Ajoutez `aria-label` ou `aria-labelledby` à `Carousel` ou `Carousel.RootProvider` pour donner un nom
  accessible au repère du carrousel.
- `spacing`, `padding`, `slidesPerPage`, `slidesPerMove` et `autoSize` utilisent directement les règles d’Ark
  pour le dimensionnement et les points d’accroche.
- Les carrousels verticaux utilisent la même API publique. Les chevrons moduix par défaut pivotent
  automatiquement, et `--moduix-carousel-height` définit la hauteur de la racine en orientation verticale.
- Avec `dir="rtl"`, les déclencheurs horizontaux par défaut s’inversent automatiquement.
- `Carousel.ProgressText` conserve l’ordre numérique `current / total` pour rester lisible dans un carrousel RTL.
- `--moduix-carousel-indicator-size` contrôle le bouton indicateur compact. Son contour de focus suit la forme
  du point ou de la capsule active.
- Avec `prefers-reduced-motion: reduce`, la piste défile immédiatement et moduix désactive les transitions
  des contrôles et des indicateurs.

## Styles

Utilisez `className` sur les parties exportées pour appliquer les styles structurels. Pour les styles liés à l’état,
privilégiez les attributs de données Ark (`data-part`, `data-orientation`, `data-current`, `data-dragging`) et les
points d’accroche `data-slot` de moduix.

### Points d’accroche CSS

- `data-slot="carousel-root"`, `carousel-root-provider`, `carousel-control`, `carousel-item-group`,
  `carousel-item`, `carousel-prev-trigger`, `carousel-next-trigger`, `carousel-indicator-group`,
  `carousel-indicator`, `carousel-autoplay-trigger`, `carousel-autoplay-indicator` et
  `carousel-progress-text` sont des sélecteurs stables pour les parties exportées.
- Ark ajoute également `data-scope="carousel"` et les noms `data-part` aux nœuds rendus.
- `data-orientation="horizontal" | "vertical"` est disponible sur la racine et les parties structurelles.
- `Carousel.ItemGroup` fournit `data-dragging` pendant une interaction de glissement.
- `Carousel.Indicator` fournit `data-current`, tandis que `Carousel.Item` fournit `data-index` et `data-inview`.
- `Carousel.Indicator` fournit `data-readonly`, tandis que `Carousel.AutoplayTrigger` fournit `data-pressed`.
