## Anatomie

```text
Carousel / Carousel.Root
├─ Carousel.ItemGroup
│  └─ Carousel.Item[index]
├─ Carousel.Control
│  ├─ Carousel.PrevTrigger
│  └─ Carousel.NextTrigger
├─ Carousel.Indicators
│  └─ Carousel.IndicatorGroup
│     └─ Carousel.Indicator[index]
└─ Carousel.ProgressText
```

| Partie                       | Rôle                                                                                 |
| ---------------------------- | ------------------------------------------------------------------------------------ |
| `Carousel` / `Carousel.Root` | Gère l’état du carrousel, la navigation et la collection d’éléments.                 |
| `Carousel.Control`           | Enveloppe de disposition pour les déclencheurs de navigation et les contrôles associés. |
| `Carousel.ItemGroup`         | Bande de diapositives contenant les parties `Carousel.Item`.                         |
| `Carousel.Item`              | Diapositive individuelle dotée d’un `index` stable.                                  |
| `Carousel.PrevTrigger`       | Déclencheur qui accède à la page précédente.                                         |
| `Carousel.NextTrigger`       | Déclencheur qui accède à la page suivante.                                           |
| `Carousel.Indicators`        | Enveloppe de commodité moduix pour les indicateurs de page standard.                 |
| `Carousel.IndicatorGroup`    | Enveloppe qui regroupe les indicateurs de page.                                      |
| `Carousel.Indicator`         | Déclencheur d’indicateur pour un index de diapositive ou de page donné.              |
| `Carousel.ProgressText`      | Texte indiquant la page actuelle et le nombre total de pages.                        |

Pour les scénarios avancés, les éléments suivants sont également disponibles :

- `Carousel.Context`
- `Carousel.AutoplayTrigger`
- `Carousel.AutoplayIndicator`
- `Carousel.RootProvider`

`useCarousel` et `useCarouselContext` sont disponibles depuis `@moduix/react`.

## Composition

### Composition recommandée

Utilisez `Carousel` comme composant racine, rendez `Carousel.ItemGroup` comme bande, placez les éléments de
navigation dans `Carousel.Control` et ajoutez `Carousel.Indicators` lorsqu’un indicateur à points standard suffit.

En général, `Carousel.Control` est une barre d’outils voisine de `Carousel.ItemGroup`.

`Carousel.Root` reste un alias explicite de `Carousel` lorsque le code doit faire apparaître l’espace de noms.

### Quand créer une composition personnalisée

Utilisez `Carousel.Context` avec `Carousel.IndicatorGroup` et `Carousel.Indicator` lorsque vous avez besoin d’une
mise en page personnalisée du paginateur, de miniatures comme indicateurs ou d’un contrôle plus fin de `pageSnapPoints`.

Utilisez `Carousel.RootProvider` de moduix avec `useCarousel()` lorsque l’état du carrousel doit être créé
en dehors du sous-arbre rendu.

Utilisez `useCarouselContext()` dans les enfants personnalisés qui ont besoin de l’API du carrousel sans render prop.

Utilisez `Carousel.AutoplayTrigger` et `Carousel.AutoplayIndicator` lorsque les contrôles de lecture automatique
doivent faire partie de l’interface visible, plutôt que d’être uniquement une propriété du composant racine.

### Propriétés par défaut

| Propriété    | Valeur par défaut | Remarques                                         |
| ------------ | ----------------- | ------------------------------------------------- |
| `slideCount` | -                 | Requis pour `Carousel` / `Carousel.Root`.         |

### Comportement

- `onPageChange(details)` conserve la forme d’Ark et expose la page active via `details.page`.
- Attribuez `aria-label` ou `aria-labelledby` à `Carousel` ou `Carousel.RootProvider` afin que le landmark du carrousel possède un nom accessible.
- `spacing`, `padding`, `slidesPerPage`, `slidesPerMove` et `autoSize` suivent directement les règles d’Ark relatives aux dimensions et aux points d’accroche.
- Le carrousel vertical utilise la même API publique. Les déclencheurs standard pivotent automatiquement lorsque le composant utilise les chevrons moduix.
- Les déclencheurs horizontaux standard sont automatiquement inversés avec `dir="rtl"`.
- `Carousel.ProgressText` conserve l’ordre numérique lisible « actuel / total » dans les carrousels RTL.
- `--moduix-carousel-indicator-size` contrôle le bouton indicateur compact ; son anneau de focus suit
  donc la géométrie du point ou de la capsule active.
- Avec `prefers-reduced-motion: reduce`, la piste défile immédiatement et les transitions des contrôles et
  indicateurs moduix sont désactivées.

## Styles

Utilisez `className` sur les parties exportées pour modifier la structure visuelle. Pour mettre en forme les états,
préférez les attributs de données d’Ark (`data-part`, `data-orientation`, `data-current`, `data-dragging`) et les hooks
`data-slot` de moduix.

### Points d’accroche CSS

- `data-slot="carousel-root"`, `carousel-control`, `carousel-item-group`, `carousel-item`,
  `carousel-prev-trigger`, `carousel-next-trigger`, `carousel-indicator-group`,
  `carousel-indicator`, `carousel-autoplay-trigger`, `carousel-autoplay-indicator` et
  `carousel-progress-text` sont des sélecteurs stables pour les parties exportées.
- Ark fournit également `data-scope="carousel"` et les noms `data-part` sur les nœuds rendus.
- `data-orientation="horizontal" | "vertical"` est disponible sur le composant racine et les parties structurelles.
- `Carousel.ItemGroup` fournit `data-dragging` pendant le glissement.
- `Carousel.Indicator` fournit `data-current`, tandis que `Carousel.Item` fournit `data-index` et `data-inview`.
- `Carousel.Indicator` fournit `data-readonly`, tandis que `Carousel.AutoplayTrigger` fournit `data-pressed`.
