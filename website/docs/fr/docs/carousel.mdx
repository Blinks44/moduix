Commencez par `Carousel` comme composant racine. Ajoutez `CarouselItemGroup` pour la piste des diapositives,
placez les boutons précédent et suivant dans `CarouselControl`, puis utilisez `CarouselIndicators` et
`CarouselProgressText` pour la pagination par défaut.

## Exemples

### Lecture automatique

Utilisez la lecture automatique pour les galeries dont les diapositives doivent avancer seules, tout en gardant
des contrôles visibles. Dans cet exemple, elle s’interrompt lorsque le pointeur entre dans le carrousel ou
qu’un élément reçoit le focus. L’utilisateur peut la relancer avec `CarouselAutoplayTrigger`.

qui se remplissent au fil du défilement, consultez le [bloc de galerie en lecture automatique](/blocks/autoplay-gallery).

## Composition

Les mêmes exports sont disponibles depuis `@moduix/solid/carousel` pour Solid.

`Carousel` gère son état à l’intérieur de la racine. Utilisez `defaultPage` pour un carrousel non contrôlé ; utilisez `page` avec `onPageChange(details)` lorsque la page courante est gérée par le routage, des filtres ou une autre partie de l’application. `slideCount` est obligatoire et doit rester synchronisé avec les éléments rendus lorsque la collection change.

Utilisez `CarouselRootProvider` avec `useCarousel()` lorsque le store doit être créé en dehors de l’arbre rendu ou partagé entre plusieurs limites de composition. Passez ce store à `CarouselRootProvider` et ne rendez pas une seconde racine `Carousel` pour le même store.

`CarouselIndicators` lit `pageSnapPoints` dans le contexte et crée les indicateurs standard. Pour personnaliser leur contenu, rendez `CarouselIndicatorGroup` et `CarouselIndicator` dans `CarouselContext`, puis utilisez `pageSnapPoints` de l’API du contexte lorsque le nombre d’indicateurs doit suivre le nombre de pages calculées.

En Solid, assignez la ref à l’élément créé dans la fonction de rendu `asChild` ; une ref posée sur une partie Carousel elle-même n’est pas transmise par ce chemin de composition.

En Vue, une ref de template sur une partie pointe vers son hôte rendu via `$el`, y compris l’hôte de substitution créé par `asChild`.

`CarouselIndicators` lit `pageSnapPoints` dans le contexte et génère un `CarouselIndicator` par page.
Utilisez-le à la place de `CarouselIndicatorGroup` lorsque les indicateurs par défaut suffisent.
Vous pouvez aussi lui passer `indicatorClassName` pour styliser les indicateurs générés.

Pour les compositions avancées, ces parties sont également disponibles :

- `CarouselContext`
- `CarouselAutoplayTrigger`
- `CarouselAutoplayIndicator`
- `CarouselRootProvider`

`Carousel`, `useCarousel` et `useCarouselContext` sont disponibles depuis `@moduix/react`. Vous pouvez
aussi importer le composant depuis `@moduix/react/carousel`.

## Styles

Utilisez `className` en React ou `class` en Solid et Vue sur les parties exportées pour appliquer les styles

`data-orientation`, `data-current`, `data-dragging`) et les points d’accroche `data-slot` de moduix.

### Points d’accroche CSS

| Partie | `data-slot` |
| --- | --- |
| `Carousel` | `carousel-root` |
| `CarouselRootProvider` | `carousel-root-provider` |
| `CarouselControl` | `carousel-control` |
| `CarouselItemGroup` | `carousel-item-group` |
| `CarouselItem` | `carousel-item` |
| `CarouselPrevTrigger` | `carousel-prev-trigger` |
| `CarouselNextTrigger` | `carousel-next-trigger` |
| `CarouselIndicatorGroup` | `carousel-indicator-group` |
| `CarouselIndicator` | `carousel-indicator` |
| `CarouselAutoplayTrigger` | `carousel-autoplay-trigger` |
| `CarouselAutoplayIndicator` | `carousel-autoplay-indicator` |
| `CarouselProgressText` | `carousel-progress-text` |

- Ark ajoute également `data-scope="carousel"` et les noms `data-part` aux nœuds rendus.
- `data-orientation="horizontal" | "vertical"` est disponible sur la racine et les parties structurelles.
- `CarouselItemGroup` fournit `data-dragging` pendant une interaction de glissement.
- `CarouselIndicator` fournit `data-current`, tandis que `CarouselItem` fournit `data-index` et `data-inview`.
- `CarouselIndicator` fournit `data-readonly`, tandis que `CarouselAutoplayTrigger` fournit `data-pressed`.

## Clavier

| Touche | Action |
| --- | --- |
| `ArrowLeft` / `ArrowRight` | Passe d’un indicateur à l’autre ; ArrowUp et ArrowDown en vertical. |
| `Home` / `End` | Va à la première ou dernière page depuis les indicateurs. |
| `Enter` / `Space` | Active le bouton précédent, suivant ou lecture ayant le focus. |
