## Exemple de base

`Toc` est la forme abrégée de `Toc.Root`. Passez-lui un tableau `items` contenant les titres à
suivre. Chaque élément doit avoir une `value` correspondant à l’attribut `id` d’un titre et un
`depth` correspondant à son niveau sémantique, par exemple `2` pour `<h2>`. Utilisez le même objet
pour rendre `Toc.Item`, puis construisez le fragment de `Toc.Link` à partir de sa `value`.


Sur une page classique, omettez `scrollEl` et le composant observe la fenêtre. L’aperçu ci-dessous
utilise sa propre zone de défilement. Passez cet élément à `scrollEl` pour que le suivi et la
navigation par lien restent dans l’aperçu.

## Anatomie

```text
Toc / Toc.Root
├─ Toc.Content
└─ Toc.Nav
   ├─ Toc.Title
   └─ Toc.List
      ├─ Toc.Indicator (facultatif)
      └─ Toc.Item[item]
         └─ Toc.Link
            └─ Toc.Rail (facultatif)

Toc.RootProvider
└─ même arbre de parties connecté à useToc()
```

| Partie              | Rôle                                                                    |
| ------------------- | ----------------------------------------------------------------------- |
| `Toc` / `Toc.Root`  | Partie racine qui gère l’état de suivi à partir de la liste d’éléments. |
| `Toc.Content`       | Article contenant les titres dont les ID correspondent aux valeurs.     |
| `Toc.Nav`           | Zone de navigation liée au titre du sommaire.                           |
| `Toc.Title`         | Nom accessible et titre visible de la navigation.                       |
| `Toc.List`          | Liste des liens vers les titres et de l’indicateur facultatif.          |
| `Toc.Item`          | Élément associé à un titre, avec son niveau et son état actif.          |
| `Toc.Link`          | Lien vers une section de la même page.                                  |
| `Toc.Indicator`     | Repère discret qui suit la plage active dans la liste.                  |
| `Toc.RootProvider`  | Relie les parties à un état de suivi créé en dehors de l’arbre.          |
| `Toc.Rail`          | Branche SVG facultative qui relie les niveaux de titres voisins.         |

## Composition

Passez un élément pour chaque titre suivi. `item.value`, l’attribut `id` du titre et le fragment de
`Toc.Link` doivent être identiques, tandis que `depth` doit correspondre au niveau sémantique du
titre. Omettez `scrollEl` lorsque la fenêtre gère le défilement ; passez la zone de lecture lorsqu’elle
possède son propre conteneur défilant.

Contrairement à Ark UI, `autoScroll` vaut `false` par défaut, à la fois pour `Toc` et pour
`useToc()`. Passez `autoScroll` pour l’activer uniquement lorsque la révélation automatique de
l’élément de navigation actif ne peut pas faire défiler un conteneur ancêtre.

Utilisez `Toc.RootProvider` avec `useToc()` uniquement lorsque des contrôles extérieurs à l’arbre
ont besoin du même état de suivi, par exemple `activeIds` ou `scrollTo`. React expose le store comme
un objet ; Solid donne accès à son état réactif au moyen de la fonction retournée. Utilisez
`Toc.Context` si une composition environnante, comme `Collapsible`, a besoin des éléments actifs.
Pour les liens d’un routeur, utilisez `Toc.Link asChild` avec un seul enfant `<a>` sémantique ; en
Solid, transmettez cet enfant avec la fonction de rendu attendue par `asChild`. Choisissez
`Toc.Indicator` pour marquer la plage active ou `Toc.Rail` pour montrer la hiérarchie de chaque
lien ; ne rendez pas les deux dans la même liste.

## Styles

Stylisez le composant avec `className` en React ou `class` en Solid, les attributs Ark, les hooks
`data-slot` de moduix et les variables publiques `--moduix-table-of-contents-*`. Les packages CSS
Modules utilisent ces variables ; les packages Tailwind utilisent les classes utilitaires natives et
les classes du consommateur pour les surcharges.

### Propriétés CSS

<CssPropertiesSection properties={TocDocs.tableOfContentsOverrideCssProperties} />

### Points d’accroche CSS

- `data-slot="toc-root"`, `toc-root-provider`, `toc-content`, `toc-nav`, `toc-title`, `toc-list`,
  `toc-item`, `toc-link`, `toc-indicator` et `toc-rail`
- Les attributs Ark `data-scope="toc"` et `data-part` sur les parties primitives
- Les attributs et variables de `Toc.Item` : `data-value`, `data-depth`, `data-active`, `data-first`,
  `data-last` et `--depth` ; `Toc.Link` expose `data-value`, `data-active` et `aria-current`
- Les variables d’exécution Ark `--top`, `--left`, `--width` et `--height` sur la racine
