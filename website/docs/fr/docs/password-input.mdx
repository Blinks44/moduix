## Choisir le bon composant

Utilisez `PasswordInput` lorsqu’une valeur sensible doit rester masquée par défaut tout en pouvant
être affichée à la demande.

- Choisissez **`Input`** pour un champ textuel sans bouton de visibilité.
- Choisissez **`PasswordInput`** pour les mots de passe, les clés d’API et les autres valeurs confidentielles.
- Choisissez **`InputGroup`** lorsque le champ nécessite une action intégrée personnalisée sans rapport avec la visibilité du mot de passe.

## Anatomie

```text
PasswordInput / PasswordInput.Root
├─ PasswordInput.Label
└─ PasswordInput.Field
   └─ PasswordInput.Control
      ├─ PasswordInput.Input
      └─ PasswordInput.VisibilityTrigger
         └─ PasswordInput.Indicator

PasswordInput.RootProvider
└─ même arborescence reliée à l’état de usePasswordInput()
```

| Partie                                 | Rôle                                                                            |
| -------------------------------------- | ------------------------------------------------------------------------------ |
| `PasswordInput` / `PasswordInput.Root` | Partie racine qui gère la visibilité du mot de passe et l’état du champ.        |
| `PasswordInput.RootProvider`           | Relie les parties à l’état créé avec `usePasswordInput()`.                      |
| `PasswordInput.Label`                  | Associe un libellé au champ et reflète les états required, disabled, invalid et read-only. |
| `PasswordInput.Field`                  | Composition prête à l’emploi du contrôle, du champ, du bouton et de l’indicateur. |
| `PasswordInput.Control`                | Regroupe le champ et le bouton de visibilité.                                   |
| `PasswordInput.Input`                  | Champ natif dont le `type` alterne entre `password` et `text`.                   |
| `PasswordInput.VisibilityTrigger`      | Bouton qui alterne la visibilité.                                               |
| `PasswordInput.Indicator`              | Affiche un contenu selon l’état ; moduix fournit les icônes par défaut.         |

## Composition

`PasswordInput.Field` est la composition prête à l’emploi du contrôle, du champ, du bouton de
visibilité et de l’indicateur. Remplacez-la par `Control`, `Input`, `VisibilityTrigger` et `Indicator`
lorsque la structure, les propriétés du champ, les icônes ou le style des parties doivent changer.

Conservez l’état de visibilité sur la racine. Utilisez `defaultVisible` pour définir l’état initial sans
contrôle externe, ou associez `visible` à `onVisibilityChange(details)` lorsque l’application contrôle
la visibilité. Utilisez `usePasswordInput()` avec `PasswordInput.RootProvider` lorsqu’un contrôle voisin
ou externe doit accéder au même état.

Passez les propriétés de valeur, telles que `value`, `defaultValue`, `placeholder` et `onInput` ou
`onChange`, à `PasswordInput.Input`. Le champ natif participe à la soumission et à la réinitialisation
du formulaire. Passez donc `name` à `PasswordInput` ; ce composant ne rend pas de partie `HiddenInput` séparée.

## Styles

Les paquets CSS Modules exposent les variables `--moduix-password-input-*` pour la coque du contrôle,
la zone de saisie et le bouton de visibilité, en complément des styles partagés d’`Input`. Les paquets
Tailwind utilisent des classes utilitaires et les classes du consommateur au lieu de reproduire ces
variables propres au composant.

### Points d’accroche CSS

- La racine et le fournisseur de racine exposent `data-slot="password-input-root"` et
  `data-slot="password-input-root-provider"`.
- Les parties Ark conservent `data-scope="password-input"` et les valeurs `data-part` pour `root`, `label`,
  `control`, `input`, `visibility-trigger` et `indicator`.
- Utilisez `data-state="visible" | "hidden"` sur le champ, le bouton et l’indicateur pour les styles de visibilité.
  Utilisez `data-disabled`, `data-invalid`, `data-readonly` et `data-required` là où Ark les fournit. Le contrôle
  reçoit les attributs disabled, invalid et read-only utilisés par la coque du champ.
- Ark n’expose pas de variables CSS propres à ce composant à l’exécution ; moduix ajoute
  `--moduix-password-input-*` pour les valeurs visuelles par défaut des paquets CSS Modules.
