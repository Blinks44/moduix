# Utilitaires

Cette section rassemble des briques de bas niveau d’Ark UI et des composants moduix qui les adaptent. Utilisez-les pour
afficher du contenu uniquement dans le navigateur, travailler avec une iframe ou un autre document, gérer le focus,
formater des valeurs, enregistrer des raccourcis clavier ou contrôler le moment où un contenu est monté dans le DOM.

Dans la plupart des guides, l’import vient directement d’Ark UI. `Highlight`, `JsonTreeView` et `Swap` sont des
composants moduix qui ajoutent des styles ou des réglages par défaut. `Locale` est exposé via le point d’entrée stable
`@moduix/react/locale`. Chaque guide indique l’import à utiliser, propose un exemple exécutable et renvoie vers l’API
complète d’Ark.

Commencez par un composant moduix lorsqu’il gère déjà l’interaction. Utilisez l’un de ces utilitaires lorsque votre
application contrôle la structure environnante ou le comportement associé.
