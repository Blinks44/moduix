# Utilitaires

Utilisez un utilitaire lorsque votre application contrôle la structure environnante ou le comportement associé. Si un
composant moduix gère déjà l’interaction voulue, commencez par lui.

Les guides ci-dessous couvrent les utilitaires Ark UI directs et les composants moduix construits sur les mêmes
primitives. Les utilitaires Ark UI fournissent un comportement propre au framework sans imposer de système de styles.
`Highlight`, `JsonTreeView` et `Swap` encapsulent les primitives Ark UI correspondantes et ajoutent la composition et
les styles moduix. Ils sont disponibles dans les packages React et Solid, pour les deux modes de style.

votre application.

## Contexte de locale

`Locale` fournit la locale et la direction du texte aux formateurs Ark UI et aux composants qui gèrent la locale. Il
s’agit d’un contexte de framework, pas d’un composant stylé : utilisez `@moduix/react/locale` avec React ou
`@moduix/solid/locale` avec Solid. La configuration des packages et des feuilles de style est décrite dans [Quick
Start](/docs/quick-start).
