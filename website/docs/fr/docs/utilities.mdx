# Utilitaires

Les utilitaires Ark UI sont de petits blocs pour les besoins qui ne relèvent pas d’un composant moduix précis : rendu
dans le navigateur, document alternatif, gestion du focus, formatage ou cycle de vie du contenu.

Lorsqu’un composant moduix gère déjà l’interaction, préférez son API. Utilisez un utilitaire directement lorsque
l’application contrôle le balisage ou le comportement qui l’entoure. Chaque page indique l’import recommandé,
propose des exemples exécutables et renvoie vers l’API Ark complète.
