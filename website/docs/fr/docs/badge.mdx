## Référence de l’API

Ark UI ne fournit pas de primitive `Badge` dédiée. moduix construit `Badge` avec la [factory Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory)
officielle et suit les recommandations d’Ark pour la [composition](https://ark-ui.com/docs/guides/composition), les
[styles](https://ark-ui.com/docs/guides/styling) et les [références](https://ark-ui.com/docs/guides/ref).

## Choisir le bon composant

Utilisez `Badge` pour afficher une information courte sur un élément. C’est un composant de présentation : il ne remplace
pas un contrôle qui permet à l’utilisateur de sélectionner ou de modifier une valeur.

- Choisissez **`Badge`** pour de courtes métadonnées comme un statut, une catégorie, une version ou un nombre.
- Choisissez **`Tag`** pour des valeurs sélectionnées, des filtres, des affectations ou des libellés qui font partie de l’état actuel de l’interface.


Les exports Vue sont disponibles depuis `@moduix/vue/badge` pour CSS Modules et `@moduix/vue-tailwind/badge` pour Tailwind CSS. Les exports Solid restent disponibles depuis `@moduix/solid/badge`.
## Exemple de base

Commencez par un `<Badge>` simple. Par défaut, le composant rend un `span` de présentation. Définissez `variant` pour
choisir un style intégré, `size` pour choisir `sm`, `md` ou `lg`, et ajoutez `BadgeDot` uniquement lorsqu’un statut
a besoin d’un indicateur visuel.

## Anatomie

`Badge` est le composant racine. Son API publique reste volontairement réduite aux parties visibles.

```text
Badge
├─ BadgeLabel (facultatif ; à utiliser explicitement pour la troncature)
├─ BadgeDot (facultatif)
└─ icône svg (facultative)
```

| Partie      | Rôle                                                                                  |
| ----------- | ------------------------------------------------------------------------------------- |
| `Badge`     | Partie racine. Applique la variante, la bordure et les espacements.                    |
| `BadgeLabel` | Partie de texte explicite. Permet de tronquer correctement un badge composé.          |
| `BadgeDot`  | Partie décorative. Affiche un marqueur circulaire qui reprend la couleur du texte.    |

## Composition

`Badge` est un composant de présentation et ne gère aucun état. Le texte direct reste inchangé ; utilisez `BadgeLabel` lorsqu’un libellé contraint doit être tronqué ou lorsqu’il est combiné avec `BadgeDot` ou une icône. Pour un lien ou un bouton sémantique, utilisez `asChild` avec exactement un enfant en React. En Solid, passez une fonction de rendu à `asChild` ; l’enfant rendu conserve ses sémantiques natives.

En Vue, placez exactement un enfant dans le slot par défaut avec `as-child` ; l’enfant conserve ses sémantiques natives.

## Styles

Commencez avec une variante et une taille intégrées. Pour une modification ponctuelle, définissez les
variables `--moduix-badge-*` publiques sur le badge via une classe ou un style en ligne. Pour personnaliser
une variante dans toute l’application, définissez les mêmes variables sur
`[data-slot='badge-root'][data-variant='<variant>']`.

Ces variables CSS s’appliquent aux packages CSS Modules ; les packages Tailwind utilisent des utilitaires natifs et les classes du consommateur. Utilisez `className` en React ou `class` en Solid et Vue sur les parties exportées. Les hooks `data-slot` et les attributs Ark sont communs aux deux approches de style et aux trois frameworks.

### Points d’accroche CSS

- `data-slot="badge-root"`, `data-slot="badge-label"` et `data-slot="badge-dot"` sont des sélecteurs stables pour cibler les parties exportées en CSS.
- `Badge` expose également `data-scope="badge"` et `data-part="root"`. `BadgeLabel` et `BadgeDot` exposent `data-part="label"` et `data-part="dot"`.
- `Badge` indique la variante sélectionnée dans l’attribut `data-variant` et la taille dans `data-size`.
- Les hôtes focalisables rendus avec `Badge asChild` reçoivent le style de focus visible. Les racines de type lien reçoivent aussi le survol de la variante et le curseur pointeur ; les styles propres aux boutons restent gérés par l’application.
- Les icônes `svg` placées directement comme enfants héritent de `currentColor`, ne capturent pas les événements du pointeur et utilisent `--moduix-badge-icon-size`.
- `Badge` ne dispose ni d’une primitive Ark dédiée ni d’une machine de comportement ; il n’expose donc aucun état géré par Ark ni aucune variable CSS d’exécution.
