## Référence de l’API

Ark UI ne fournit pas de primitive `Badge` dédiée. moduix s’appuie sur l’outil officiel
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) pour construire ce composant et suit les recommandations d’Ark pour la
[composition](https://ark-ui.com/docs/guides/composition), les [styles](https://ark-ui.com/docs/guides/styling) et les
[ref](https://ark-ui.com/docs/guides/ref).

## Choisir le bon composant

Utilisez `Badge` pour afficher de brèves informations sur un autre objet, et non une valeur sélectionnée par l’utilisateur.

- Choisissez **`Badge`** pour de courtes métadonnées : statut, catégorie, version ou nombre.
- Choisissez **`Tag`** pour afficher des valeurs sélectionnées, des filtres, des affectations ou des libellés associés à l’état actuel de l’interface.

## Anatomie

`Badge` conserve une API publique réduite et n’expose que les parties visibles.

```text
Badge / Badge.Root
├─ Badge.Label (optional; direct text is wrapped automatically)
├─ Badge.Dot (optional)
└─ svg icon (optional)
```

| Partie                 | Rôle                                                                                  |
| ---------------------- | ------------------------------------------------------------------------------------- |
| `Badge` / `Badge.Root` | Partie racine. Applique la variante, la bordure, les espacements et la troncature du texte. |
| `Badge.Label`          | Partie de texte explicite. Permet de tronquer correctement un libellé composé.        |
| `Badge.Dot`            | Partie d’indicateur facultative. Affiche un marqueur circulaire qui reprend la couleur du texte. |

## Composition

### Composition recommandée

Pour afficher un statut, une catégorie, une version ou un compteur court, utilisez directement `Badge`.

Utilisez `variant` pour les styles intégrés : `default`, `secondary`, `destructive`, `outline`, `ghost` et `link`.

Placez `Badge.Dot` ou une icône enfant directe à côté de `Badge.Label` lorsqu’un badge composé a besoin d’un repère visuel supplémentaire. Le texte brut est automatiquement placé dans `Badge.Label`.

`Badge.Root`, `Badge.Label` et `Badge.Dot` transmettent leur `ref` aux éléments DOM qu’ils rendent.

### Quand créer une composition personnalisée

Utilisez `Badge asChild` lorsqu’un autre élément sémantique doit devenir le nœud DOM racine. La composition Ark exige un seul enfant. L’enfant interactif conserve sa sémantique native et reçoit les styles par défaut du badge pour le curseur, le survol et le focus clavier.

Utilisez les variables CSS locales ou remplacez `className` lorsque le composant nécessite une taille ou un style personnalisé.

### Propriétés par défaut

| Propriété | Valeur par défaut | Valeurs / remarques                                             |
| --------- | ----------------- | --------------------------------------------------------------- |
| `variant` | `default`         | `default`, `secondary`, `destructive`, `outline`, `ghost`, `link` |
| `asChild` | `false`           | Composition Ark factory avec exactement un enfant               |

### Comportement

- Par défaut, `Badge` sert uniquement à afficher une information et rend un `span`.
- `Badge.Dot` est décoratif et masqué pour les technologies d’assistance ; le texte visible doit donc transmettre la signification du statut.
- `Badge` n’ajoute à lui seul ni interaction ni sémantique de lien ou de bouton.
- Les liens et boutons sémantiques rendus avec `asChild` conservent leur sémantique native et reçoivent les styles par défaut du curseur, du survol et du focus visible.
- Les boutons désactivés et les éléments avec `aria-disabled="true"` conservent leur sémantique, n’appliquent pas les styles de survol et utilisent la variable publique d’opacité dédiée à l’état désactivé.
- Les libellés longs restent sur une ligne et sont tronqués avec des points de suspension par l’élément racine. `title` affiche la valeur complète au survol ; dans les interfaces tactiles, choisissez un libellé qui tient dans l’espace disponible.
- Le texte brut est automatiquement placé dans `Badge.Label`. Utilisez explicitement `Badge.Label` lorsque le texte est composé avec un point, une icône ou un autre élément.
- Les icônes `svg` placées directement comme enfants héritent de `currentColor` et utilisent `--moduix-badge-icon-size`.
- Le contenu numérique utilise des chiffres tabulaires et, par défaut, le texte du badge n’est pas sélectionnable.
- Les tailles proposées par Chakra sont exposées sous forme de variables CSS publiques plutôt que par une propriété `size`.

## Styles

Commencez avec une variante intégrée. Utilisez les variables CSS locales pour les ajustements ponctuels de taille et de style.
Utilisez les variables `--moduix-badge-<variant>-*` pour personnaliser une variante dans toute l’application. Les variables générales
`--moduix-badge-bg`, `--moduix-badge-border-color` et `--moduix-badge-color` ont une priorité supérieure pour personnaliser un badge donné.

### Points d’accroche CSS

- `data-slot="badge-root"`, `data-slot="badge-label"` et `data-slot="badge-dot"` sont des sélecteurs stables pour cibler les parties exportées en CSS.
- `Badge.Root` expose également `data-scope="badge"` et `data-part="root"`. `Badge.Label` et `Badge.Dot` exposent `data-part="label"` et `data-part="dot"`.
- `Badge.Root` indique la variante sélectionnée dans `data-variant`.
- Les liens et boutons sémantiques rendus avec `Badge asChild` ou `Badge.Root asChild` reçoivent les styles par défaut du focus visible définis par la racine.
- Les icônes `svg` placées directement comme enfants héritent de `currentColor`, ne reçoivent pas les événements du pointeur et utilisent `--moduix-badge-icon-size`.
- Badge ne dispose ni d’une primitive Ark dédiée ni d’une machine de comportement ; il n’expose donc aucun état Ark contrôlé ni variable CSS d’exécution.
