## Exemple de base

Splitter est disponible pour React et Solid dans les packages CSS Modules et Tailwind. L'aperçu de
cette page utilise le package React CSS Modules ; les onglets présentent le code natif correspondant
au même contrat public.

Construisez un splitter avec `Splitter`, `Splitter.Panel` et `Splitter.ResizeTrigger`. La prop
`panels` contient les identifiants des panneaux et leurs contraintes de taille. Chaque
`Splitter.Panel` rendu doit utiliser l'un de ces identifiants. Si vous n'ajoutez pas de contenu à la
poignée, moduix génère automatiquement l'indicateur de redimensionnement.

## Anatomie

```text
Splitter / Splitter.Root
├─ Splitter.Panel[id]
├─ Splitter.ResizeTrigger[id="panel-a:panel-b"]
│  └─ Splitter.ResizeTriggerIndicator (par défaut, personnalisable)
└─ Splitter.Panel[id]

Splitter.RootProvider
└─ même arborescence de panneaux reliée à un état useSplitter()
```

| Partie                              | Rôle                                                                          |
| ----------------------------------- | ----------------------------------------------------------------------------- |
| `Splitter` / `Splitter.Root`        | Gère les panneaux, leurs tailles, l'orientation, les rappels et l'état.      |
| `Splitter.Panel`                    | Région redimensionnable dont l'`id` correspond à une entrée de `panels`.      |
| `Splitter.ResizeTrigger`            | Bouton accessible qui redimensionne les deux panneaux adjacents.             |
| `Splitter.ResizeTriggerIndicator`   | Poignée visuelle par défaut. Un contenu personnalisé la remplace.             |
| `Splitter.RootProvider`             | Affiche les mêmes parties avec l'état créé par `useSplitter()`.              |

## Composition

Utilisez `size` avec `onResize(details)` lorsque l'application doit gérer les tailles actuelles des
panneaux. Utilisez `Splitter.RootProvider` avec `useSplitter()` lorsque l'état ou ses contrôles
doivent vivre en dehors de l'arborescence rendue, et choisissez une seule racine par état. Pour des
splitters imbriqués qui doivent se redimensionner ensemble aux intersections des poignées, créez un
seul `createSplitterRegistry()` et transmettez-le à chaque racine.

Utilisez `asChild` avec un seul enfant interactif qui conserve la sémantique d'un bouton, la gestion du
focus et les interactions au clavier ; cela remplace l'indicateur de redimensionnement par défaut. En
Solid, `useSplitter()` renvoie un accessor : transmettez-le à `value` et lisez l'API avec `splitter()`.

## Accessibilité

`ResizeTrigger` génère un bouton et prend en charge le redimensionnement à la souris et au clavier,
conformément au modèle WAI-ARIA Window Splitter. Donnez à chaque poignée un nom accessible, par exemple
avec `aria-label="Resize panels"`, lorsque l'indicateur visuel n'a pas de libellé. Avec `asChild`,
l'élément hôte personnalisé doit conserver la sémantique d'un bouton, le focus et les interactions au
clavier.

Ark expose l'état avec des attributs tels que `data-orientation`, `data-dragging`, `data-focus` et
`data-disabled`. Utilisez-les pour styliser les états d'interaction.

## Styles

Utilisez `className` en React ou `class` en Solid sur les parties exportées pour les styles structurels.
Les variantes Tailwind utilisent des utilitaires natifs et les classes du consommateur ; la variante
CSS Modules expose les variables du composant ci-dessous. Les attributs d'état et les points d'accroche
`data-slot` sont communs aux deux modes de style.

La poignée réserve un séparateur de `1px` dans la mise en page et dessine par-dessus une ligne de
`0.5px`. Sa zone de clic transparente facilite la manipulation, et l'indicateur arrondi se place sur
la ligne. Les états de survol et de glissement renforcent la ligne, la bordure et l'ombre. Remplacez
les variables `--moduix-splitter-resize-trigger-*` correspondantes si votre thème nécessite un autre
rendu.

### Points d'accroche pour les styles

Ark écrit `data-scope="splitter"` et `data-part` sur les parties rendues. moduix ajoute également les
valeurs `data-slot` suivantes : `splitter-root`, `splitter-root-provider`, `splitter-panel`,
`splitter-resize-trigger` et `splitter-resize-trigger-indicator`.

Les attributs utiles selon les parties sont notamment `data-id` et `data-index` sur les panneaux, ainsi
que `data-orientation`, `data-dragging`, `data-focus` et `data-disabled` sur les éléments concernés.
