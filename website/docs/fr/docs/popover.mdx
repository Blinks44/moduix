## Choisir le bon composant

Utilisez `Popover` pour un contenu interactif compact ouvert par un déclencheur. Utilisez `Tooltip`
pour une indication courte et non interactive, et `Dialog` pour les parcours plus importants qui
requièrent toute l’attention de l’utilisateur.

## Anatomie

```text
Popover / Popover.Root
├─ Popover.Anchor (facultatif)
├─ Popover.Trigger
│  └─ Popover.Indicator (facultatif)
└─ Sous-arbre de superposition (rendu automatiquement dans un portail)
   └─ Popover.Positioner
      └─ Popover.Content
         ├─ Popover.Arrow
         │  └─ Popover.ArrowTip
         ├─ Popover.Header
         │  ├─ Popover.Title
         │  └─ Popover.Description
         ├─ Popover.Body
         ├─ Popover.Footer
         └─ Popover.CloseTrigger / Popover.CloseIcon

Popover.RootProvider
└─ même arborescence reliée à l’état moduix créé avec usePopover()

Popover.Context
└─ fonction de rendu avec l’état courant de la fenêtre contextuelle
```

| Partie                       | Rôle                                                                  |
| --------------------------- | --------------------------------------------------------------------- |
| `Popover` / `Popover.Root`  | Gère l’état, l’ouverture et la fermeture, le focus, la fermeture extérieure et le positionnement. |
| `Popover.RootProvider`      | Relie les parties à l’état créé avec `usePopover()`.                 |
| `Popover.Context`            | Expose l’état courant aux descendants via une fonction de rendu.      |
| `Popover.Anchor`             | Élément de référence facultatif utilisé pour le positionnement.       |
| `Popover.Trigger`            | Bouton qui ouvre ou ferme la fenêtre et peut recevoir une `value`.     |
| `Popover.Indicator`          | Indicateur facultatif de l’état du déclencheur.                       |
| `Popover.Positioner`         | Calque flottant qui expose les variables CSS de positionnement d’Ark. |
| `Popover.Content`             | Surface interactive visible de la fenêtre contextuelle.              |
| `Popover.Arrow` / `ArrowTip` | Flèche positionnée facultative et sa pointe visible.                  |
| `Popover.Title`               | Titre accessible associé au contenu.                                  |
| `Popover.Description`         | Description accessible associée au contenu.                           |
| `Popover.CloseTrigger`        | Déclencheur bas niveau qui ferme la fenêtre.                           |
| `Popover.CloseIcon`            | Aide moduix qui associe le déclencheur de fermeture Ark à un bouton avec icône. |
| `Popover.Header` / `Body`      | Aides de mise en page moduix avec des slots stables.                  |
| `Popover.Footer`               | Aide moduix pour la rangée d’actions avec un slot stable.              |

Dans le code de l’application, utilisez la forme courte `Popover`. `Popover.Root` reste disponible
lorsque le nom explicite de la racine rend la composition plus lisible.

## Composition

Gardez `Popover.Positioner` et `Popover.Content` explicites afin que la structure de la superposition
reste facile à styliser. `Positioner` est rendu dans un portail par défaut. Définissez
`portalled={false}` pour le conserver dans l’arbre DOM courant, ou passez `portalRef` pour choisir un
conteneur de portail personnalisé. Avec `Popover.RootProvider`, configurez `portalled` dans
`usePopover()` et transmettez le store au provider. N’utilisez pas `Popover` ou `Popover.Root` pour
le même store.

Utilisez `Anchor` lorsqu’un autre élément doit déterminer le positionnement. Utilisez `asChild` avec
un seul enfant sémantique lorsque votre élément doit rendre un déclencheur, une ancre ou un
déclencheur de fermeture. Pour les Popover imbriqués, définissez `portalled={false}` sur la racine
imbriquée afin qu’elle reste dans la superposition parente. Lorsque plusieurs déclencheurs partagent
une même fenêtre, attribuez une `value` à chacun et mettez à jour le contenu via
`onTriggerValueChange(details)`.

## Styles

Utilisez `className` en React ou `class` en Solid sur les parties exportées pour les styles
structurels. Les variantes Tailwind utilisent des utilitaires natifs et les classes du consommateur.
Les variables CSS ci-dessous personnalisent les variantes CSS Modules ; les attributs de données Ark
et les hooks `data-slot` de moduix sont partagés par les deux pistes de style.

### Ciblage des styles

Chaque partie rendue accepte `className` ou `class`. Les parties Ark conservent `data-scope="popover"`
et leurs valeurs `data-part`, tandis que moduix ajoute `data-slot="popover-*"` aux conteneurs rendus.
`Popover` et `Popover.RootProvider` fournissent l’état, mais ne rendent pas d’éléments DOM. Pour les
styles liés à l’état, ciblez `data-state="open|closed"`, `data-placement`, `data-side`, `data-value`,
`data-nested`, `data-has-nested`, `data-expanded` et `data-current` lorsque plusieurs déclencheurs
avec une `value` partagent une même fenêtre.

`Positioner` expose `--reference-width`, `--reference-height`, `--available-width`,
`--available-height`, `--x`, `--y`, `--z-index` et `--transform-origin`. `Content` expose
`--layer-index` et `--nested-layer-count`. `Arrow` expose les variables de mesure de la flèche Ark.
Le contenu renvoie les longues chaînes sans séparateur à la ligne et désactive ses animations lorsque
l’utilisateur préfère réduire les animations.
