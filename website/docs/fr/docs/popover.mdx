Utilisez `Popover` comme racine et importez directement chaque partie supplémentaire, par exemple
`PopoverTrigger` et `PopoverContent`. Ces noms plats sont identiques dans les paquets npm et les
sources du registre shadcn. Configurez le positionnement sur la racine et utilisez `asChild` lorsque
votre propre bouton doit servir de déclencheur.

## Choisir le bon composant

Utilisez `Popover` pour un contenu interactif compact ouvert par un déclencheur. Utilisez `Tooltip`
pour une indication courte et non interactive, et `Dialog` pour les parcours plus importants qui
requièrent toute l’attention de l’utilisateur.

## Composition

Gardez `PopoverPositioner` et `PopoverContent` explicites afin que la structure de la superposition
reste facile à styliser. `PopoverPositioner` est rendu dans un portail par défaut. Définissez
`portalled={false}` pour le conserver dans l’arbre DOM courant, ou passez `portalRef` pour choisir un
conteneur de portail personnalisé. Avec `PopoverRootProvider`, configurez `portalled` dans
`usePopover()` et transmettez le store au provider. N’utilisez pas `Popover` et
`PopoverRootProvider` pour le même store.

Utilisez `PopoverAnchor` lorsqu’un autre élément doit déterminer le positionnement. Utilisez `asChild` avec
un seul enfant sémantique lorsque votre élément doit rendre un déclencheur, une ancre ou un
déclencheur de fermeture. Pour les Popover imbriqués, définissez `portalled={false}` sur la racine
imbriquée afin qu’elle reste dans la superposition parente. Lorsque plusieurs déclencheurs partagent
une même fenêtre, attribuez une `value` à chacun et mettez à jour le contenu via
`onTriggerValueChange(details)`.

## Styles

Sans `asChild`, `PopoverTrigger` et `PopoverCloseTrigger` s’affichent comme des boutons à contour.
`PopoverContent` mesure de 16 à 28rem de large et au plus 24rem de haut dans l’espace disponible ;
avec un enfant direct `PopoverBody`, c’est le corps qui défile. `PopoverBody` est espacé d’un
`PopoverHeader` qui le précède, et `PopoverFooter` du contenu au-dessus. L’animation du contenu lit
les variables partagées `--moduix-popup-motion-*`.

Utilisez `className` en React ou `class` en Solid et Vue sur les parties exportées. Les variantes
Tailwind utilisent les utilitaires natifs et les classes du consommateur. Les variantes CSS Modules
reposent sur les jetons de foundation et n’ont pas de variables de composant : une classe sur la partie
remplace les styles du composant en couche. Les attributs d’état et les hooks `data-slot` sont communs
aux deux modes de style.

### Points d’accroche CSS

| Partie | `data-slot` |
| --- | --- |
| `PopoverAnchor` | `popover-anchor` |
| `PopoverTrigger` | `popover-trigger` |
| `PopoverIndicator` | `popover-indicator` |
| `PopoverPositioner` | `popover-positioner` |
| `PopoverContent` | `popover-content` |
| `PopoverArrow` | `popover-arrow` |
| `PopoverArrowTip` | `popover-arrow-tip` |
| `PopoverTitle` | `popover-title` |
| `PopoverDescription` | `popover-description` |
| `PopoverCloseTrigger` | `popover-close-trigger` |
| `PopoverCloseIcon` | `popover-close-icon` |
| `PopoverHeader` | `popover-header` |
| `PopoverBody` | `popover-body` |
| `PopoverFooter` | `popover-footer` |

Chaque partie rendue accepte `className` ou `class`. Les parties Ark conservent `data-scope="popover"`
et leurs valeurs `data-part`, tandis que moduix ajoute `data-slot="popover-*"` aux conteneurs rendus. `Popover` et `PopoverRootProvider` fournissent l’état, mais ne rendent pas d’éléments DOM. Pour les
styles liés à l’état, ciblez `data-state="open|closed"`, `data-placement`, `data-side`, `data-value`,
`data-nested`, `data-has-nested`, `data-expanded` et `data-current` lorsque plusieurs déclencheurs
avec une `value` partagent une même fenêtre.

`PopoverPositioner` expose `--reference-width`, `--reference-height`, `--available-width`,
`--available-height`, `--x`, `--y`, `--z-index` et `--transform-origin`. `PopoverContent` expose
`--layer-index` et `--nested-layer-count`. `PopoverArrow` expose les variables de mesure de la flèche Ark. Le contenu renvoie les longues chaînes sans séparateur à la ligne et désactive ses animations lorsque
l’utilisateur préfère réduire les animations.

## Clavier

| Touche | Action |
| --- | --- |
| `Enter` / `Space` | Ouvre ou ferme le popover depuis le déclencheur. |
| `Tab` / `Shift+Tab` | Parcourt le contenu ; en sortir ferme un popover non modal. |
| `Esc` | Ferme et rend le focus au déclencheur. |
