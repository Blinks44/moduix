## Choisir le bon composant

Utilisez `Popover` pour un contenu interactif compact associé à un déclencheur. Utilisez `Tooltip` pour les indications
non interactives et `Dialog` pour les parcours plus longs qui interrompent la tâche en cours.

## Anatomie

```text
Popover / Popover.Root
├─ Popover.Anchor (optional)
├─ Popover.Trigger
│  └─ Popover.Indicator (optional)
└─ Overlay subtree (automatically portalled)
   └─ Popover.Positioner
      └─ Popover.Content
         ├─ Popover.Arrow
         │  └─ Popover.ArrowTip
         ├─ Popover.Header
         │  ├─ Popover.Title
         │  └─ Popover.Description
         ├─ Popover.Body
         ├─ Popover.Footer
         └─ Popover.CloseTrigger / Popover.CloseIcon
```

| Partie                       | Rôle                                                                  |
| ---------------------------- | --------------------------------------------------------------------- |
| `Popover` / `Popover.Root`   | Gère l’état, le cycle de vie, la fermeture, le focus et le positionnement de la fenêtre. |
| `Popover.RootProvider`       | Affiche l’arbre Popover à partir de l’état renvoyé par `usePopover`.  |
| `Popover.Context`            | Lit l’état actuel via le `render prop` d’un descendant.               |
| `Popover.Anchor`             | Élément de référence de positionnement personnalisé, facultatif.      |
| `Popover.Trigger`            | Bouton qui ouvre ou ferme la fenêtre et peut recevoir une `value`.    |
| `Popover.Indicator`          | Indicateur facultatif de l’état du déclencheur.                       |
| `Popover.Positioner`         | Élément flottant qui expose les variables CSS de positionnement Ark. |
| `Popover.Content`            | Surface interactive de la fenêtre contextuelle.                      |
| `Popover.Arrow` / `ArrowTip` | Flèche facultative et sa pointe visible.                             |
| `Popover.Title`              | Titre accessible associé au contenu.                                 |
| `Popover.Description`        | Description accessible associée au contenu.                          |
| `Popover.CloseTrigger`       | Déclencheur bas niveau qui ferme la fenêtre.                         |
| `Popover.CloseIcon`          | Bouton de fermeture partagé avec une icône, basé sur le déclencheur Ark. |
| `Popover.Header` / `Body`    | Conteneurs de mise en page moduix avec des slots stables.             |
| `Popover.Footer`             | Conteneur moduix de rangée d’actions avec slot stable.                |

## Composition

La racine place automatiquement `Positioner` dans un portail. Utilisez `portalled={false}` pour l’afficher dans le
conteneur courant, ou `portalRef` pour choisir un conteneur de portail personnalisé. Les parties structurelles restent
explicites et peuvent être stylées.

### Composition recommandée

Conservez `Popover.Positioner` et `Popover.Content` explicites. `Popover` est un alias de `Popover.Root`. Configurez
le placement, la gestion des collisions et les décalages via `positioning`. Définissez `positioning.sameWidth` pour
aligner la largeur de la fenêtre sur celle de l’élément de référence.

### Quand créer une composition personnalisée

Utilisez `Anchor` lorsque l’élément de référence du positionnement diffère du déclencheur. Utilisez `asChild` avec un
seul enfant sémantique lorsque vous voulez fournir votre propre élément pour le déclencheur, l’ancre, le contenu ou le
déclencheur de fermeture. Définissez `portalled={false}` lorsqu’une fenêtre contextuelle dans un autre calque doit
être rendue dans le conteneur courant. Utilisez `lazyMount` et `unmountOnExit` uniquement si le montage différé et le
retrait après l’animation de sortie sont nécessaires.

### Propriétés par défaut

Par défaut, le contenu de la superposition placé dans un portail est monté à la première ouverture puis démonté après
l’animation de sortie. Définissez `unmountOnExit={false}` pour le conserver monté après la première ouverture. Définissez
ces deux propriétés de cycle de vie à `false` uniquement si le contenu doit être rendu dès le départ.

| Propriété                | Valeur par défaut | Remarques                                                        |
| ------------------------ | ----------------- | ---------------------------------------------------------------- |
| `autoFocus`              | `true`            | Place le focus sur le premier élément pouvant le recevoir à l’ouverture. |
| `closeOnEscape`          | `true`            | Ferme le Popover lorsque l’utilisateur appuie sur Échap.          |
| `closeOnInteractOutside` | `true`            | Ferme le Popover lors d’une interaction en dehors.               |
| `lazyMount`              | `true`            | Diffère le montage du contenu jusqu’à la première ouverture.     |
| `modal`                  | `false`           | Active le piégeage du focus, le verrouillage du défilement et l’isolation du contenu extérieur. |
| `portalled`              | `true`            | Place le positionneur dans un portail et conserve le comportement de la touche Tab d’Ark. |
| `portalRef`              | -                 | Cible un conteneur de portail personnalisé.                      |
| `skipAnimationOnMount`   | `false`           | Conserve l’animation d’entrée lors du montage initial.            |
| `unmountOnExit`          | `true`            | Retire le contenu après l’animation de sortie.                   |
| `defaultOpen`            | -                 | État d’ouverture initial non contrôlé.                           |
| `open`                   | -                 | État d’ouverture contrôlé.                                       |
| `ids`                    | -                 | Identifiants stables du déclencheur, du contenu, du titre, de la description et de l’ancre. |
| `initialFocusEl`         | -                 | Fonction qui renvoie l’élément à cibler à l’ouverture.           |
| `positioning`            | -                 | Options de positionnement flottant Ark.                          |
| `present`                | -                 | Contrôle la présence pour les animations pilotées par JavaScript. |

### Comportement

- Les `ref` pointent vers les parties DOM Ark sous-jacentes : `Trigger` et `CloseTrigger` pointent vers des boutons,
  tandis que `Anchor`, `Positioner`, `Content`, `Arrow`, `ArrowTip`, `Title`, `Description`, `Indicator`, `Header`,
  `Body` et `Footer` pointent vers leurs éléments rendus.
- `onOpenChange` reçoit `{ open }` ; la fonction de rappel reçoit un objet et non un argument positionnel.
- La propriété `modal` est booléenne. Lorsqu’elle vaut `true`, elle piège le focus, verrouille le défilement, bloque les
  interactions extérieures et isole le contenu vis-à-vis des lecteurs d’écran. Un Popover modal est toujours rendu dans
  un portail, même lorsque `portalled={false}` est transmis.
- Passez l’objet renvoyé par `usePopover` à `RootProvider`. N’enveloppez pas le même état dans `Root`.
- `Popover.Context` et `usePopoverContext` donnent aux descendants accès à l’état Ark actuel. Le hook est exporté depuis
  `@moduix/react` ; utilisez `Context` lorsqu’un `render prop` est plus lisible.
- Utilisez `usePopover` pour gérer l’état en dehors de l’arbre rendu, puis passez-le à `RootProvider`.
- `Popover.Arrow` rend `ArrowTip` par défaut ; rendez `ArrowTip` explicitement uniquement pour le personnaliser.
- Par défaut, Ark ferme le Popover avec Échap et lors d’une interaction extérieure. Ces comportements peuvent être désactivés séparément.
- Utilisez `ids` lorsque des identifiants stables sont nécessaires pour le déclencheur, le contenu, le titre, la description, l’ancre ou le déclencheur de fermeture.
- Les animations CSS de sortie utilisent l’état fermé de la présence Ark. Utilisez `present` pour les cycles de vie pilotés par JavaScript.
- Pour un contenu qui peut dépasser la hauteur disponible, placez la zone défilable dans `Popover.Body`.

### Points d’accroche CSS

Les parties Ark conservent `data-scope="popover"` et leurs valeurs de `data-part`. Chaque partie exportée et rendue
accepte `className`, et moduix ajoute `data-slot="popover-*"` aux conteneurs rendus. Ciblez
`data-state="open|closed"`, `data-placement`, `data-side`, `data-nested`, `data-has-nested` et `data-expanded` pour adapter les styles
à l’état. Lorsque plusieurs déclencheurs possèdent une `value`, utilisez `data-current` pour ne styliser que celui qui a
ouvert le Popover.

`Positioner` expose `--reference-width`, `--reference-height`, `--available-width`, `--available-height`, `--x`, `--y`,
`--z-index` et `--transform-origin`. `Content` expose `--layer-index` et `--nested-layer-count` ; `Arrow` expose les
variables de mesure de la flèche Ark. Le contenu force le retour à la ligne des longues chaînes sans séparateur et
désactive ses animations lorsque l’utilisateur préfère réduire les animations.
