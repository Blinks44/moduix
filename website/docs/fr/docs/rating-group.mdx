## Anatomie

```text
RatingGroup.Root
├─ RatingGroup.Label
└─ RatingGroup.Control
   ├─ RatingGroup.Items (recommended)
   │  └─ RatingGroup.Item[index]
   │     └─ RatingGroup.ItemIndicator
   ├─ RatingGroup.Context (advanced, optional)
   │  └─ RatingGroup.Item[index]
   │     └─ RatingGroup.ItemIndicator
   └─ the native form input (automatic)

RatingGroup.RootProvider
└─ same part tree connected to a moduix useRatingGroup() store
```

| Partie                               | Rôle                                                                       |
| ------------------------------------ | -------------------------------------------------------------------------- |
| `RatingGroup` / `RatingGroup.Root`   | Gère la valeur de notation, le comportement au clavier et l’état du formulaire. |
| `RatingGroup.RootProvider`           | Relie les parties à l’état créé avec `useRatingGroup()`.                   |
| `RatingGroup.Context`                | Donne accès à l’état racine actuel via une render prop.                    |
| `RatingGroup.ItemContext`            | Donne accès à l’état de l’élément actuel via une render prop.              |
| `RatingGroup.Label`                  | Libellé accessible du groupe de notation.                                  |
| `RatingGroup.Control`                | Regroupe les éléments interactifs de notation.                             |
| `RatingGroup.Items`                  | Affiche les éléments Ark et les étoiles par défaut.                        |
| `RatingGroup.Item`                   | Un élément de notation sélectionnable ; nécessite `index`.                |
| `RatingGroup.ItemIndicator`          | Étoile visuelle moduix qui suit le contexte de l’élément Ark.              |

## Composition

### Composition recommandée

`RatingGroup` est la forme racine concise. Il gère l’état de la valeur Ark, l’état de survol, le déplacement du focus, les libellés, l’intégration aux formulaires et le comportement au clavier. Utilisez `RatingGroup.Items` pour les étoiles générées standard. L’élément racine affiche automatiquement un champ natif de formulaire synchronisé. Transmettez un `RatingGroup.ItemIndicator` personnalisé comme enfant pour modifier l’icône tout en conservant le même comportement d’élément.

### Quand créer une composition personnalisée

Utilisez `RatingGroup.Context`, `RatingGroup.ItemContext` ou `useRatingGroupItemContext()` de moduix lorsque l’arbre d’éléments personnalisé a besoin des états `highlighted`, `checked` ou `half`. L’élément racine affiche automatiquement un champ natif de formulaire. Utilisez `RatingGroup.RootProvider` avec `useRatingGroup()` de moduix lorsque l’état de notation doit être créé en dehors du sous-arbre affiché.

Toutes les parties Ark prennent en charge `asChild`. Conservez un seul enfant sémantique capable de prendre en charge le focus et les interactions de la partie.

### Propriétés par défaut

| Propriété                    | Par défaut | Notes                                                               |
| ---------------------------- | ----------- | ------------------------------------------------------------------- |
| `count`                      | `5`         | Nombre d’éléments Ark.                                              |
| `size`                       | `md`        | Taille moduix : `xs`, `sm`, `md`, `lg` ou `xl`.                    |
| `RatingGroup.Items`          | -           | Affiche les éléments par défaut.                                    |
| `RatingGroup.ItemIndicator`  | star        | Affiche par défaut les plans avant et arrière de l’étoile moduix.   |

### Comportement

- `value` et `defaultValue` sont des nombres.
- `onValueChange` reçoit les détails Ark ; lisez la valeur dans `details.value`.
- `onHoverChange` reçoit les détails de survol Ark.
- `allowHalf` active la sélection par demi-pas et l’affichage d’une demi-étoile.
- `name`, `form` et `required` fonctionnent avec le champ natif du formulaire affiché automatiquement par l’élément racine.
- Ark gère `disabled` et `readOnly`, et reflète ces états par des attributs de données.

### Points d’accroche CSS

- `data-slot="rating-group-root"` et `data-slot="rating-group-root-provider"`
- `data-slot="rating-group-label"`
- `data-slot="rating-group-control"`
- `data-slot="rating-group-item"`
- `data-slot="rating-group-item-indicator"`
- `data-slot="rating-group-hidden-input"`
- `data-size="xs" | "sm" | "md" | "lg" | "xl"` sur l’élément racine ou le root provider
- Attributs Ark du libellé : `data-disabled` et `data-required`
- Attributs Ark du contrôle : `data-disabled` et `data-readonly`
- Attributs Ark de l’élément : `data-checked`, `data-highlighted`, `data-half`, `data-disabled` et `data-readonly`
