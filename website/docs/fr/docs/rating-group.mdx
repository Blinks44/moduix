## Anatomie

```text
RatingGroup / RatingGroup.Root
├─ RatingGroup.Label
└─ RatingGroup.Control
   ├─ RatingGroup.Items
   │  └─ RatingGroup.Item[index]
   │     └─ RatingGroup.ItemIndicator
   ├─ RatingGroup.Context
   │  └─ RatingGroup.Item[index]
   │     └─ RatingGroup.ItemIndicator
   └─ RatingGroup.HiddenInput (explicite)

RatingGroup.RootProvider
└─ même arbre de parties relié à un état moduix créé avec useRatingGroup()
```

| Partie                               | Rôle                                                                |
| ------------------------------------ | ------------------------------------------------------------------- |
| `RatingGroup` / `RatingGroup.Root`   | Gère l’état de la note, la navigation au clavier, le focus et les formulaires. |
| `RatingGroup.HiddenInput`             | Champ natif d’Ark à composer explicitement.                         |
| `RatingGroup.RootProvider`            | Relie les parties à l’état créé avec `useRatingGroup()`.             |
| `RatingGroup.Context`                 | Donne accès à l’état racine actuel via une render prop.              |
| `RatingGroup.ItemContext`             | Donne accès à l’état actuel de l’élément via une render prop.        |
| `RatingGroup.Label`                   | Libellé accessible du groupe de notation.                            |
| `RatingGroup.Control`                 | Regroupe les éléments interactifs de notation.                       |
| `RatingGroup.Items`                   | Crée un élément pour chaque valeur et fournit l’étoile par défaut.   |
| `RatingGroup.Item`                    | Élément sélectionnable qui nécessite un `index` numérique.           |
| `RatingGroup.ItemIndicator`           | Visuel étoilé moduix par défaut pour un élément.                     |

## Composition

Utilisez `RatingGroup.Items` pour l’arbre standard généré. Pour remplacer le visuel répété, passez un
`RatingGroup.ItemIndicator` personnalisé comme enfant. `RatingGroup.HiddenInput` est indépendant de
`Items`, ajoutez-le donc explicitement dans la racine ou `RatingGroup.RootProvider` ; définissez
`name` sur la racine lorsque la valeur doit être envoyée par un formulaire natif.

Pour un arbre d’éléments personnalisé, utilisez `RatingGroup.Context` avec `RatingGroup.Item`.
Utilisez `RatingGroup.RootProvider` avec `useRatingGroup()` lorsque l’état doit être créé en dehors
de l’arbre rendu. React lit le store comme un objet, tandis que Solid lit son état réactif via la
fonction retournée.

## Styles

Utilisez `className` en React ou `class` en Solid sur les parties exportées pour les styles
structurels. Ark expose aussi les attributs `data-scope="rating-group"` et `data-part`. Pour les styles liés à l’état, utilisez les attributs de données tels que
`data-disabled`, `data-readonly`, `data-checked`, `data-highlighted` et `data-half`, avec les hooks
`data-slot` de moduix. Les variantes Tailwind utilisent des utilitaires natifs et les classes du
consommateur ; les variantes CSS Modules exposent aussi les variables enregistrées
`--moduix-rating-group-*`.

### Points d’accroche CSS

- `data-slot="rating-group-root"` et `data-slot="rating-group-root-provider"`
- `data-slot="rating-group-label"`
- `data-slot="rating-group-control"`
- `data-slot="rating-group-item"`
- `data-slot="rating-group-item-indicator"`
- `data-slot="rating-group-item-indicator-bg"` et `data-slot="rating-group-item-indicator-fg"`
- `data-size="xs" | "sm" | "md" | "lg" | "xl"` sur la racine ou le root provider
- Attributs du label Ark : `data-disabled` et `data-required`
- Attributs du control Ark : `data-disabled` et `data-readonly`
- Attributs de l’item Ark : `data-checked`, `data-highlighted`, `data-half`, `data-disabled` et `data-readonly`
