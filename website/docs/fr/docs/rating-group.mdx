## Choisir le bon composant

Utilisez `RatingGroup` lorsque l’utilisateur doit choisir une note numérique parmi une série d’étoiles ou d’icônes répétées.

## Exemple de base


Utilisez `RatingGroup` comme racine et ajoutez `RatingGroupLabel`, `RatingGroupControl` et
`RatingGroupItems` pour une notation standard par étoiles. Rendez `RatingGroupHiddenInput`
explicitement lorsque la valeur doit participer à l’envoi d’un formulaire natif.

## Anatomie

```text
RatingGroup
├─ RatingGroupLabel
└─ RatingGroupControl
   ├─ RatingGroupItems
   │  └─ RatingGroupItem[index]
   │     └─ RatingGroupItemIndicator
   ├─ RatingGroupContext
   │  └─ RatingGroupItem[index]
   │     └─ RatingGroupItemIndicator
   └─ RatingGroupHiddenInput (explicite)

RatingGroupRootProvider
└─ même arbre de parties relié à un état moduix créé avec useRatingGroup()
```

| Partie                               | Rôle                                                                |
| ------------------------------------ | ------------------------------------------------------------------- |
| `RatingGroup`                    | Gère l’état de la note, la navigation au clavier, le focus et les formulaires. |
| `RatingGroupHiddenInput`             | Champ natif d’Ark à composer explicitement.                         |
| `RatingGroupRootProvider`            | Relie les parties à l’état créé avec `useRatingGroup()`.             |
| `RatingGroupContext`                 | Donne accès à l’état racine actuel via une render prop.              |
| `RatingGroupItemContext`             | Donne accès à l’état actuel de l’élément via une render prop.        |
| `RatingGroupLabel`                   | Libellé accessible du groupe de notation.                            |
| `RatingGroupControl`                 | Regroupe les éléments interactifs de notation.                       |
| `RatingGroupItems`                   | Crée un élément pour chaque valeur et fournit l’étoile par défaut.   |
| `RatingGroupItem`                    | Élément sélectionnable qui nécessite un `index` numérique.           |
| `RatingGroupItemIndicator`           | Visuel étoilé moduix par défaut pour un élément.                     |

## Composition

Utilisez `RatingGroupItems` pour l’arbre standard généré. Pour remplacer le visuel répété, passez un
`RatingGroupItemIndicator` personnalisé comme enfant. `RatingGroupHiddenInput` est indépendant de
`Items`, ajoutez-le donc explicitement dans la racine ou `RatingGroupRootProvider` ; définissez
`name` sur la racine lorsque la valeur doit être envoyée par un formulaire natif.

Pour un arbre d’éléments personnalisé, utilisez `RatingGroupContext` avec `RatingGroupItem`.
Utilisez `RatingGroupRootProvider` avec `useRatingGroup()` lorsque l’état doit être créé en dehors
de l’arbre rendu. React lit le store comme un objet, Solid lit son état réactif via la fonction
retournée, et Vue expose directement le store réactif dans le template.

## Exemples

### État contrôlé

Gérez `value` avec `useState` en React, `createSignal` en Solid, ou `ref` et `v-model` en Vue lorsque
la note dépend d’un autre état, pilote l’interface voisine ou doit être réinitialisée par le parent.

<Example name="rating-group/controlled" />

### Icône personnalisée

Passez un `RatingGroupItemIndicator` personnalisé comme enfant de `RatingGroupItems` lorsque tous
les éléments doivent utiliser la même icône. L’indicateur reçoit toujours les attributs d’état Ark
`data-highlighted` et `data-half`, utilisables dans vos styles.

<Example name="rating-group/custom-icon" />

### État désactivé et lecture seule

Utilisez `disabled` pour désactiver les interactions. Utilisez `readOnly` pour laisser la note visible
sans permettre sa modification.

<Example name="rating-group/disabled-and-readonly" />

### Field

Entourez le groupe de notation avec `Field` lorsque le texte d’aide ou de validation doit être
associé à son `RatingGroupHiddenInput`. Ark hérite de `Field` les propriétés `disabled`, `readOnly`
et `required`; l’état de validation reste géré par `Field` et le code de l’application.

<Example name="rating-group/field" />

### Formulaires

Passez `name` et rendez `RatingGroupHiddenInput` lorsque la note sélectionnée doit être incluse dans
`FormData`.

<Example name="rating-group/forms" />

### Notation par demi-pas

Définissez `allowHalf` pour activer la sélection et l’affichage par demi-pas.

<Example name="rating-group/half-rating" />

### Tailles

Utilisez la propriété `size` de moduix lorsque la notation doit conserver le comportement d’Ark avec
une densité visuelle différente.

<Example name="rating-group/sizes" />

### Composition avancée

Utilisez `RatingGroupRootProvider` avec `useRatingGroup()` lorsque l’état doit être créé en dehors
de l’arbre rendu. Utilisez `RatingGroupContext` lorsque `RatingGroupItems` ne suffit pas et que
vous devez rendre chaque élément vous-même.

<Example name="rating-group/advanced-customization" />

## Styles

Utilisez `className` en React ou `class` en Solid et Vue sur les parties exportées pour les styles
structurels. Ark expose aussi les attributs `data-scope="rating-group"` et `data-part`. Pour les styles liés à l’état, utilisez les attributs de données tels que
`data-disabled`, `data-readonly`, `data-checked`, `data-highlighted` et `data-half`, avec les hooks
`data-slot` de moduix. Les variantes Tailwind utilisent des utilitaires natifs et les classes du
consommateur ; les variantes CSS Modules exposent aussi les variables enregistrées
`--moduix-rating-group-*`.

### Points d’accroche CSS

- `data-slot="rating-group-root"` et `data-slot="rating-group-root-provider"`
- `data-slot="rating-group-label"`
- `data-slot="rating-group-control"`
- `data-slot="rating-group-item"`
- `data-slot="rating-group-item-indicator"`
- `data-slot="rating-group-item-indicator-bg"` et `data-slot="rating-group-item-indicator-fg"`
- `data-size="xs" | "sm" | "md" | "lg" | "xl"` sur la racine ou le root provider
- Attributs du label Ark : `data-disabled` et `data-required`
- Attributs du control Ark : `data-disabled` et `data-readonly`
- Attributs de l’item Ark : `data-checked`, `data-highlighted`, `data-half`, `data-disabled` et `data-readonly`
