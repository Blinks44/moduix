## Anatomie

```text
Avatar.Root | Avatar.RootProvider
├─ Avatar.Fallback
└─ Avatar.Image
```

| Composant | Rôle |
| ------------------------ | ----------------------------------------------------------------- |
| `Avatar` / `Avatar.Root` | Crée l’élément racine et gère l’état de l’avatar Ark UI. |
| `Avatar.RootProvider` | Relie l’avatar à un état Ark UI créé en dehors de son arbre. |
| `Avatar.Fallback` | Affiche des initiales, une icône ou un contenu personnalisé jusqu’au chargement de l’image. |
| `Avatar.Image` | Affiche l’image après un chargement réussi. |

## Composition

### Composition recommandée

Utilisez `Avatar` dans le cas général. `Avatar.Root` reste disponible si vous préférez le nom explicite de la
racine utilisé par Ark. `onStatusChange(details)` signale l’état de chargement géré par Ark, tandis que `ids`
permet de fournir des identifiants stables pour la racine, l’image et le contenu de remplacement. Toutes les
parties DOM transmettent leur `ref` et prennent en charge la propriété `asChild` d’Ark.

`Avatar.Image` génère un élément `img` natif. Indiquez un texte `alt` pertinent lorsque l’image aide à
identifier l’utilisateur. Utilisez `alt=""` lorsque le lien ou le bouton environnant possède déjà un nom accessible.

`Avatar.Fallback name="Alex T."` prend le premier caractère du premier et du dernier mot dans le cas général,
sans couper les emoji ni les caractères composés. Les initiales restent ainsi correctes pour les noms
internationaux. Ajoutez du contenu enfant lorsque vous avez besoin d’un contenu de remplacement personnalisé.
Les enfants explicites sont prioritaires sur `name`.

### Quand personnaliser la composition

Utilisez `useAvatar` depuis `@moduix/react` avec `Avatar.RootProvider` lorsque vous devez créer l’état
en dehors de l’arbre de l’avatar. Transmettez cet état à `Avatar.RootProvider`. N’utilisez pas `Avatar.Root`
et `Avatar.RootProvider` en même temps pour la même instance d’état.

Pour intégrer un composant d’image fourni par un framework, utilisez `useAvatarContext()` depuis
`@moduix/react` et conservez la gestion des états `hidden` et `visible` assurée par Ark. Importez les API
de contexte Ark plus avancées et les alias de types depuis `@ark-ui/react/avatar`.

Utilisez `asChild` avec un seul enfant sémantiquement adapté lorsqu’un lien, un bouton ou un composant de
framework doit contrôler le nœud DOM d’une partie.

### Propriétés par défaut

| Composant | Propriété | Valeur visuelle par défaut | Valeurs |
| ----------------------------------------------- | ------ | -------------- | ---------------------------- |
| `Avatar` / `Avatar.Root`, `Avatar.RootProvider` | `size` | `md` | `xs`, `sm`, `md`, `lg`, `xl` |

Lorsque `size` est omis, Avatar utilise la taille visuelle `md` sans ajouter `data-size`. Passez
`size="md"` si vos sélecteurs ont besoin de cet attribut.

### Comportement

- Ark gère `data-state="visible" | "hidden"` sur `Avatar.Image` et `Avatar.Fallback`.
- `Avatar.Fallback` calcule les initiales à partir du premier caractère du premier et du dernier mot de `name`,
  sans couper les caractères composés, uniquement lorsqu’aucun enfant n’est fourni.
- `Avatar.Fallback` affiche une icône utilisateur décorative intégrée lorsqu’il n’y a ni enfant ni initiales utilisables dans `name`.
- `onStatusChange` reçoit un objet dont `details.status` vaut `loaded` ou `error`.
- Si l’image est absente ou ne peut pas être chargée, le contenu de remplacement reste visible.
- `Avatar.RootProvider` doit recevoir la valeur renvoyée par `useAvatar`.
- `useAvatar` et `useAvatarContext` sont exportés par `@moduix/react`.
- `Avatar.Context` est également exporté par `@moduix/react`. Les alias de types Ark restent disponibles depuis `@ark-ui/react/avatar`.
- moduix ajoute uniquement des réglages visuels par défaut, des points d’accroche `data-slot` stables, des variables CSS et `size`.

## Styles

Utilisez `className` et les variables CSS de moduix pour modifier l’apparence. Utilisez les attributs de
données fournis par Ark lorsque le style dépend de l’état de l’image.

### Propriétés CSS

<CssPropertiesSection properties={AvatarDocs.avatarCssProperties} />

### Points d’accroche CSS

- `data-slot="avatar-root"`, `avatar-root-provider`, `avatar-image`, `avatar-fallback` et
  `avatar-fallback-icon`.
- Attributs d’anatomie Ark : `data-scope="avatar"` et
  `data-part="root" | "image" | "fallback"`.
- État de l’image géré par Ark : `data-state="visible" | "hidden"` sur `Avatar.Image` et
  `Avatar.Fallback`.
- Attribut de taille de moduix : `data-size="xs" | "sm" | "md" | "lg" | "xl"` sur
  `Avatar.Root` et `Avatar.RootProvider` lorsque `size` est fourni.
