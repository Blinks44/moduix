## Exemple de base

Utilisez `Avatar`, `AvatarFallback` et `AvatarImage` ensemble. Gardez `AvatarFallback` dans l’arbre
pour qu’Ark UI puisse basculer entre le contenu de remplacement et l’image lorsque l’état de chargement change.

React, Solid et Vue partagent les mêmes noms de valeurs à plat. Importez `Avatar` comme racine et chaque
partie supplémentaire directement, par exemple `AvatarImage` et `AvatarFallback`. Ces mêmes noms
fonctionnent avec les paquets npm et les sources du registre shadcn.

## Anatomie

```text
Avatar
├─ AvatarFallback
└─ AvatarImage

AvatarRootProvider
└─ les mêmes parties connectées à un store useAvatar()
```

| Composant           | Rôle |
| ------------------- | ----------------------------------------------------------------- |
| `Avatar`            | Crée l’élément racine et gère l’état de l’avatar Ark UI. |
| `AvatarRootProvider` | Relie l’avatar à un état Ark UI créé en dehors de son arbre. |
| `AvatarFallback`    | Affiche le contenu fourni par le consommateur jusqu’au chargement de l’image. |
| `AvatarImage`       | Affiche l’image après un chargement réussi. |

## Composition

Gardez `AvatarFallback` et `AvatarImage` sous la même racine afin qu’Ark UI puisse gérer leur visibilité. Lorsqu’une autre partie de l’application possède l’état, créez-le avec `useAvatar()` du framework concerné et transmettez-le directement à `AvatarRootProvider` ; ne rendez pas une seconde racine pour le même store. React reçoit le store comme un objet, tandis que Solid fournit un accesseur réactif. En Vue, transmettez directement le résultat de `useAvatar()` à `AvatarRootProvider`. React et Solid peuvent utiliser `useAvatarContext()` pour un rendu d’image personnalisé et conserver les états masqué et visible de `getImageProps()`. En Vue, le slot de `AvatarContext` expose le même état. Utilisez `asChild` avec un seul enfant sémantique lorsqu’un autre élément doit porter le nœud DOM racine.

## Styles

Utilisez `className` dans React ou `class` dans Solid et Vue, ainsi que les variables CSS de moduix, pour modifier l’apparence. Utilisez les attributs de
données fournis par Ark lorsque le style dépend de l’état de l’image.

### Propriétés CSS

<CssPropertiesSection properties={AvatarDocs.avatarCssProperties} />

### Points d’accroche CSS

- `data-slot="avatar-root"`, `avatar-root-provider`, `avatar-image` et `avatar-fallback`.
- Attributs d’anatomie Ark : `data-scope="avatar"` et
  `data-part="root" | "image" | "fallback"`.
- État de l’image géré par Ark : `data-state="visible" | "hidden"` sur `AvatarImage` et
  `AvatarFallback`.
- Attribut de taille de moduix : `data-size="xs" | "sm" | "md" | "lg" | "xl"` sur
  `Avatar` et `AvatarRootProvider` lorsque `size` est fourni.
