## Anatomie

```text
Avatar.Root | Avatar.RootProvider
├─ Avatar.Fallback
└─ Avatar.Image
```

| Composant | Rôle |
| ------------------------ | ----------------------------------------------------------------- |
| `Avatar` / `Avatar.Root` | Crée et gère l’état de l’avatar Ark UI. |
| `Avatar.RootProvider` | Affiche un avatar à partir d’un état Ark UI créé en dehors du composant. |
| `Avatar.Fallback` | Affiche des initiales, une icône ou un contenu personnalisé jusqu’au chargement de l’image. |
| `Avatar.Image` | Affiche l’image après un chargement réussi. |

## Composition

### Composition recommandée

Utilisez `Avatar` dans le cas général. `Avatar.Root` reste disponible si vous préférez l’espace de noms explicite
aligné sur Ark. `onStatusChange(details)` signale l’état de chargement géré par Ark, tandis que `ids`
fournit des identifiants stables pour la racine, l’image et le contenu de remplacement. Toutes les parties DOM
transmettent leur `ref` et prennent en charge `asChild` d’Ark.

`Avatar.Image` génère un élément `img`. Indiquez un texte `alt` pertinent lorsque l’image identifie
l’utilisateur. Utilisez `alt=""` lorsque le lien ou le bouton environnant possède déjà un nom accessible.

`Avatar.Fallback name="Alex T."` utilise le premier graphème du premier et du dernier mot dans le cas
général. Les initiales restent ainsi correctes pour les noms internationaux et les emoji. Ajoutez des
enfants lorsque vous avez besoin d’un contenu de remplacement personnalisé. Le contenu passé en enfant
est prioritaire sur `name`.

### Quand créer une composition personnalisée

Utilisez `useAvatar` depuis `@moduix/react` avec `Avatar.RootProvider` lorsque vous devez créer l’état
en dehors de l’avatar affiché. N’utilisez pas `Avatar.Root` et `Avatar.RootProvider` en même temps pour
la même instance d’état.

Pour intégrer un composant d’image fourni par un framework, utilisez `useAvatarContext()` depuis
`@moduix/react` et conservez les états `hidden` et `visible` gérés par Ark. Importez les API de contexte
Ark plus spécifiques et les alias de types depuis `@ark-ui/react/avatar`.

Utilisez `asChild` avec un seul enfant sémantique lorsqu’un lien, un bouton ou un composant de framework
doit contrôler le nœud DOM d’une partie.

### Propriétés par défaut

| Composant | Propriété | Valeur visuelle par défaut | Valeurs |
| ----------------------------------------------- | ------ | -------------- | ---------------------------- |
| `Avatar` / `Avatar.Root`, `Avatar.RootProvider` | `size` | `md` | `xs`, `sm`, `md`, `lg`, `xl` |

Lorsque `size` est omis, Avatar utilise les tokens visuels `md` sans ajouter `data-size`. Passez
`size="md"` si vos sélecteurs ont besoin de cet attribut.

### Comportement

- Ark gère `data-state="visible" | "hidden"` sur `Avatar.Image` et `Avatar.Fallback`.
- `Avatar.Fallback` calcule des initiales en respectant les graphèmes Unicode du premier et du dernier mot de `name`,
  uniquement lorsqu’aucun enfant n’est fourni.
- `Avatar.Fallback` affiche une icône utilisateur décorative intégrée lorsqu’il n’y a ni enfant ni initiales utilisables dans `name`.
- `onStatusChange` reçoit un objet de détails. L’état courant se trouve dans `details.status`.
- Si l’image est absente ou ne peut pas être chargée, le contenu de remplacement reste visible.
- `Avatar.RootProvider` doit recevoir la valeur renvoyée par `useAvatar`.
- `useAvatar` et `useAvatarContext` sont exportés par `@moduix/react`.
- `Avatar.Context` est également exporté par `@moduix/react`. Les alias de types Ark restent disponibles depuis `@ark-ui/react/avatar`.
- moduix ajoute uniquement des valeurs visuelles par défaut, des points d’accroche `data-slot` stables, des variables CSS et `size`.

## Styles

Utilisez `className` et les variables CSS de moduix pour modifier l’apparence. Utilisez les attributs de
données fournis par Ark lorsque le style dépend de l’état de l’image.

### Propriétés CSS

<CssPropertiesSection properties={AvatarDocs.avatarCssProperties} />

### Points d’accroche CSS

- `data-slot="avatar-root"`, `avatar-root-provider`, `avatar-image`, `avatar-fallback` et
  `avatar-fallback-icon`.
- Attributs d’anatomie Ark : `data-scope="avatar"` et
  `data-part="root" | "image" | "fallback"`.
- État de l’image géré par Ark : `data-state="visible" | "hidden"` sur `Avatar.Image` et
  `Avatar.Fallback`.
- Attribut de taille de moduix : `data-size="xs" | "sm" | "md" | "lg" | "xl"` sur
  `Avatar.Root` et `Avatar.RootProvider` lorsque `size` est fourni.
