## Choisir le bon composant

- Choisissez **`Input`** pour saisir une date sous forme de texte, sans comportement de calendrier.
- Choisissez **`DateInput`** lorsque les utilisateurs doivent modifier des segments de date au clavier.
- Choisissez **`DatePicker`** lorsqu’ils ont besoin d’un champ de date modifiable avec un calendrier contextuel ou intégré.

## Anatomie

```text
DatePicker / DatePicker.Root
├─ DatePicker.Label
├─ DatePicker.Control
│  ├─ DatePicker.Input
│  ├─ DatePicker.ClearTrigger
│  └─ DatePicker.Trigger
├─ DatePicker.Field / DatePicker.RangeField (parties pratiques)
├─ Sous-arbre du calendrier contextuel (mis dans un portail automatiquement)
│  └─ DatePicker.Positioner
│     └─ DatePicker.Content
│        ├─ DatePicker.View[view="day" | "month" | "year"]
│        │  ├─ DatePicker.ViewControl
│        │  │  ├─ DatePicker.PrevTrigger
│        │  │  ├─ DatePicker.ViewTrigger / DatePicker.RangeText
│        │  │  └─ DatePicker.NextTrigger
│        │  ├─ DatePicker.DayTable (table des jours pratique)
│        │  └─ DatePicker.Table
│        │     ├─ DatePicker.TableHead / TableBody / TableRow
│        │     ├─ DatePicker.TableHeader
│        │     ├─ DatePicker.TableCell
│        │     ├─ DatePicker.TableCellTrigger
│        │     ├─ DatePicker.WeekNumberHeaderCell
│        │     └─ DatePicker.WeekNumberCell
│        ├─ DatePicker.MonthSelect / DatePicker.YearSelect
│        └─ DatePicker.PresetTrigger
├─ DatePicker.ValueText (résumé facultatif des valeurs sélectionnées)
└─ DatePicker.Context

DatePicker.RootProvider
└─ même arborescence reliée à un store useDatePicker()
```

| Partie                            | Rôle                                                               |
| --------------------------------- | ------------------------------------------------------------------ |
| `DatePicker` / `DatePicker.Root`  | Racine qui gère la valeur, la vue, l’ouverture, la locale, la validation et le formulaire. |
| `DatePicker.RootProvider`         | Affiche les parties avec l’état renvoyé par `useDatePicker()`.     |
| `DatePicker.Label`                | Libellé accessible du champ de date.                               |
| `DatePicker.Control`              | Conteneur du champ pour une disposition personnalisée.             |
| `DatePicker.Field`                | Champ pratique avec saisie, effacement et ouverture du calendrier. |
| `DatePicker.RangeField`           | Champ de plage avec saisies de début et de fin indexées.           |
| `DatePicker.Input`                | Saisie de date modifiable, incluse dans l’envoi natif du formulaire. |
| `DatePicker.Trigger`              | Ouvre le calendrier.                                                |
| `DatePicker.ClearTrigger`         | Efface la valeur courante.                                          |
| `DatePicker.Positioner`           | Positionne le calendrier contextuel.                                |
| `DatePicker.Content`              | Conteneur du calendrier contextuel ou intégré.                      |
| `DatePicker.View`                 | Vue du jour, du mois ou de l’année.                                 |
| `DatePicker.ViewControl`          | En-tête contenant les commandes de navigation.                      |
| `DatePicker.PrevTrigger`          | Passe au mois, à l’année ou à la décennie précédente.               |
| `DatePicker.NextTrigger`          | Passe au mois, à l’année ou à la décennie suivante.                 |
| `DatePicker.ViewTrigger`          | Change de vue du calendrier.                                        |
| `DatePicker.RangeText`            | Affiche la plage visible dans l’en-tête.                            |
| `DatePicker.ValueText`            | Affiche les valeurs sélectionnées.                                  |
| `DatePicker.DayTable`             | Table standard de la vue des jours.                                 |
| `DatePicker.Table*`               | Parties pour composer une grille personnalisée.                     |
| `DatePicker.WeekNumberHeaderCell` | En-tête de la colonne des numéros de semaine.                       |
| `DatePicker.WeekNumberCell`       | Cellule contenant un numéro de semaine.                             |
| `DatePicker.MonthSelect`          | Sélecteur de mois natif lié à la date ciblée.                        |
| `DatePicker.YearSelect`           | Sélecteur d’année natif lié à la date ciblée.                       |
| `DatePicker.PresetTrigger`        | Bouton d’une plage prédéfinie.                                      |
| `DatePicker.Context`              | Accès sans rendu à l’état du calendrier.                            |

## Composition

Utilisez `DatePicker.Field` pour un champ de date simple, `DatePicker.RangeField` pour une plage et
`DatePicker.DayTable` dans la vue des jours. Utilisez `DatePicker.RootProvider` avec
`useDatePicker()` lorsque l’état doit être partagé avec des contrôles situés hors de l’arbre racine.

Pour personnaliser le champ ou la grille, composez directement `Control`, `Input`, `Trigger`,
`ClearTrigger` et les parties `Table*`. Lisez `weekDays`, `weeks` et les fonctions de grille via
`DatePicker.Context`. En mode de sélection multiple, affichez les valeurs sélectionnées via
`Context`, car une seule saisie ne peut pas représenter toute la liste, puis appelez `setValue()`
pour supprimer une valeur.

La racine place automatiquement le calendrier contextuel dans un portail. Utilisez
`portalled={false}` pour le conserver dans le sous-arbre DOM actuel, `portalRef` pour un conteneur
personnalisé ou `inline` pour garder `Content` dans le flux normal du document.

## Styles

Utilisez `className` en React et `class` en Solid sur les parties exportées pour les styles
structurels. Les variantes Tailwind utilisent les utilitaires natifs et les classes du consommateur ;
les variantes CSS Modules exposent les variables ci-dessous. Les deux approches partagent les
attributs d’état Ark et les hooks `data-slot` de moduix.

### Points d’accroche CSS

Utilisez ces hooks `data-slot` pour cibler les différentes parties :

- `date-picker-root`, `date-picker-root-provider`, `date-picker-label`, `date-picker-control` et `date-picker-input`.
- `date-picker-trigger`, `date-picker-clear-trigger` et `date-picker-value-text`.
- `date-picker-positioner`, `date-picker-content`, `date-picker-view` et `date-picker-view-control`.
- `date-picker-view-trigger`, `date-picker-prev-trigger`, `date-picker-next-trigger` et `date-picker-range-text`.
- `date-picker-table-*`, `date-picker-table-cell-trigger`, `date-picker-week-number-header-cell` et `date-picker-week-number-cell`.
- `date-picker-month-select`, `date-picker-year-select` et `date-picker-preset-trigger`.

Les attributs d’état Ark comprennent `data-state`, `data-disabled`, `data-readonly`, `data-invalid`,
`data-focus`, `data-selected`, `data-today`, `data-unavailable`, `data-outside-range`,
`data-in-range`, `data-range-start`, `data-range-end`, `data-in-hover-range`,
`data-hover-range-start`, `data-hover-range-end` et `data-view`.
