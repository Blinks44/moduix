# Carte avec parallaxe

Une carte à image plein fond avec une légère inclinaison 3D. `Card.Background` gère la couche photo
décorative et `react-parallax-tilt` gère le mouvement du pointeur ; l’effet reste immobile sans
pointeur de survol précis ou avec la préférence reduced motion.

## Utilisation dans une page

Remplacez l’URL de l’image et le contenu. Gardez `alt=""` pour l’image de fond décorative ; utilisez
`Card.Media` lorsqu’une image nécessite un texte alternatif. Le mouvement est décoratif : la carte doit
rester lisible et utile sans survol ; utilisez un lien ou un bouton classique pour la destination.
