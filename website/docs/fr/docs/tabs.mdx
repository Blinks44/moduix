## Choisir le bon composant

Utilisez `Tabs` pour basculer entre des vues liées dans une même zone de la page. La sélection d’un
onglet affiche le panneau correspondant et masque les autres panneaux.

- Choisissez **`Tabs`** lorsque chaque onglet doit afficher un panneau associé.
- Choisissez **`Accordion`** lorsque les sections doivent rester empilées et s’ouvrir indépendamment.
- Choisissez **`ToggleGroup`** lorsque le contrôle modifie un état ou un mode sans gérer le contenu d’un panneau.

## Anatomie

```text
Tabs / Tabs.Root
├─ Tabs.List
│  ├─ Tabs.Trigger[value]
│  ├─ Tabs.Trigger[value]
│  └─ Tabs.Indicator
└─ Tabs.Content[value]

Tabs.RootProvider
└─ mêmes parties reliées à un store useTabs()

Tabs.Context
└─ render prop
```

| Partie                | Rôle                                                               |
| --------------------- | ------------------------------------------------------------------ |
| `Tabs` / `Tabs.Root`  | Racine qui gère la valeur sélectionnée, le focus, l’orientation et le mode. |
| `Tabs.RootProvider`   | Relie les parties à l’état créé avec `useTabs()` de moduix.        |
| `Tabs.Context`        | Expose l’état courant des onglets via une render prop.             |
| `Tabs.List`           | Regroupe les déclencheurs et gère les déplacements du focus.       |
| `Tabs.Trigger`        | Bouton d’onglet interactif, ou hôte `asChild`, avec une valeur obligatoire. |
| `Tabs.Indicator`      | Indicateur facultatif de l’onglet sélectionné.                     |
| `Tabs.Content`        | Panneau associé au déclencheur qui possède la même valeur.        |

## Composition

Utilisez `defaultValue` pour un composant non contrôlé. Lorsqu’une autre partie de l’application
gère la sélection, transmettez `value` et `onValueChange(details)`, puis lisez la valeur choisie
dans `details.value`.

Utilisez `Tabs.RootProvider` avec `useTabs()` lorsque l’état doit être créé en dehors de l’arbre
rendu ou partagé avec une interface voisine. Transmettez le store à `RootProvider` et ne rendez pas
une autre racine `Tabs` pour ce même état. Utilisez `asChild` sur `Tabs.Trigger` pour un lien ou un
composant de routeur, et rendez `Tabs.Indicator` explicitement, car `Tabs.List` ne l’ajoute pas
automatiquement.

## Styles

Utilisez `className` en React ou `class` en Solid sur les parties exportées pour les styles de
structure. Pour les styles liés à l’état, préférez les attributs de données d’Ark tels que
`data-selected`, `data-disabled` et `data-orientation`, avec les sélecteurs `data-slot` de moduix.
Les variantes Tailwind utilisent les utilitaires natifs et les classes du consommateur ; les
variables ci-dessous personnalisent les variantes CSS Modules.

### Points d’accroche CSS

Ciblez la partie qui porte la responsabilité visuelle concernée :

- `Tabs` pour la largeur, l’espacement général, l’orientation et les remplacements liés à la variante
- `Tabs.List` pour le fond, les bordures, l’habillage de la liste et l’espacement autour de l’indicateur
- `Tabs.Trigger` pour la disposition du libellé, l’espacement de l’icône, les états sélectionné et désactivé, et le focus
- `Tabs.Indicator` pour la couleur, la taille et les transitions de l’indicateur
- `Tabs.Content` pour la surface, les marges internes et le focus du panneau

Les principaux points d’accroche publics sont `data-slot="tabs-root"`,
`data-slot="tabs-root-provider"`, `data-slot="tabs-list"`, `data-slot="tabs-trigger"`,
`data-slot="tabs-indicator"` et `data-slot="tabs-content"`.

Les points d’accroche Ark utiles sont `data-scope="tabs"`, `data-part`, `data-orientation`,
`data-selected`, `data-disabled`, `data-focus`, ainsi que les variables de l’indicateur `--left`,
`--top`, `--width`, `--height` et `--transition-property`.
