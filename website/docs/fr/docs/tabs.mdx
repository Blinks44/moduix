## Choisir le bon composant

Utilisez `Tabs` pour faire alterner des vues liées dans une même zone de page. La sélection d’un onglet affiche le
panneau correspondant et masque les autres.

- Choisissez **`Tabs`** lorsque chaque onglet doit afficher un panneau de contenu associé.
- Choisissez **`Accordion`** lorsque les sections doivent rester empilées et s’ouvrir indépendamment.
- Choisissez **`ToggleGroup`** lorsque le contrôle change un état ou un mode sans gérer le contenu d’un panneau.

## Anatomie

```text
Tabs
├─ Tabs.List
│  ├─ Tabs.Trigger[value]
│  ├─ Tabs.Trigger[value]
│  └─ Tabs.Indicator
└─ Tabs.Content[value]

Tabs.RootProvider
└─ Tabs.* + useTabs()

Tabs.Context
└─ render prop
```

| Partie              | Rôle                                                               |
| ------------------- | ------------------------------------------------------------------ |
| `Tabs`              | Racine qui gère la valeur sélectionnée, le focus, l’orientation et le mode. |
| `Tabs.RootProvider` | Relie les parties à l’état créé avec `useTabs()` de moduix.        |
| `Tabs.Context`      | Expose l’état courant des onglets via une fonction de rendu.       |
| `Tabs.List`         | Regroupe les onglets et gère le déplacement du focus entre eux.   |
| `Tabs.Trigger`      | Bouton d’onglet interactif, ou hôte `asChild`, avec une valeur obligatoire. |
| `Tabs.Indicator`    | Indicateur facultatif de l’onglet sélectionné.                    |
| `Tabs.Content`      | Panneau associé à un onglet qui possède la même valeur.           |

## Composition

### Composition recommandée

Utilisez `<Tabs>` dans le cas courant. Il gère la navigation au clavier, le déplacement du focus et l’onglet
sélectionné. Utilisez `defaultValue` pour choisir l’onglet initial, ou associez `value` à
`onValueChange(details)` lorsque l’état React doit contrôler la sélection. Lisez la valeur sélectionnée dans
`details.value`.

La racine accepte aussi `onFocusChange(details)`, `activationMode`, `orientation`, `loopFocus`, `deselectable`,
`lazyMount`, `unmountOnExit`, `ids` et `navigate`, qui sont transmis à Ark UI.

Conservez l’arbre de parties explicite. `Tabs.List` regroupe les onglets mais ne rend pas automatiquement
l’indicateur. Ajoutez `Tabs.Indicator` lorsque l’onglet sélectionné doit être mis en évidence.

### Composition personnalisée

Utilisez `asChild` sur `Tabs.Trigger` lorsqu’un onglet doit être rendu comme un lien ou un composant de votre
routeur. L’enfant doit être un unique élément sémantique qui conserve les comportements clavier, focus et ARIA
d’Ark.

Utilisez `useTabs()` ou `Tabs.useTabs()` avec `Tabs.RootProvider` lorsque l’état des onglets doit être créé en
dehors de l’arbre rendu, ou lorsque l’interface voisine doit lire ou modifier la sélection. N’entourez pas la même
instance d’état d’une autre racine `Tabs`.

Utilisez `Tabs.Context` pour une fonction de rendu (`render prop`), ou `useTabsContext()` pour lire l’état courant
depuis les descendants de `Tabs` ou de `Tabs.RootProvider`.

### Propriétés par défaut

| Propriété              | Valeur par défaut | Remarques                                                              |
| ---------------------- | ----------------- | ---------------------------------------------------------------------- |
| `Tabs.variant`         | `default`         | Style visuel : `default` ou `line`.                                   |
| `Tabs.activationMode`  | `automatic`       | Le focus sélectionne automatiquement l’onglet, sauf avec `manual`.    |
| `Tabs.orientation`     | `horizontal`      | Les onglets horizontaux utilisent gauche/droite, les verticaux haut/bas. |
| `Tabs.loopFocus`       | `true`            | Le focus revient au premier onglet après le dernier.                  |
| `Tabs.lazyMount`       | `false`           | Monte un panneau lorsqu’il est sélectionné pour la première fois.     |
| `Tabs.unmountOnExit`   | `false`           | Démonte les panneaux inactifs, généralement avec `lazyMount`.         |

### Comportement

- `Tabs.Trigger` et `Tabs.Content` sont associés par des valeurs `value` identiques, qui doivent être des chaînes.
- Avec `activationMode="automatic"`, déplacer le focus sélectionne l’onglet. Avec `manual`, le focus se déplace d’abord et la sélection se fait lors de l’activation.
- `onValueChange` reçoit l’objet `details` d’Ark UI. La valeur sélectionnée se trouve dans `details.value`.
- Un `Tabs.Trigger` désactivé reste visible, mais ne peut recevoir ni le focus ni la sélection.
- `variant="line"` s’applique uniquement aux onglets horizontaux. Les onglets verticaux utilisent le style rempli `default`, y compris avec `Tabs.RootProvider`.
- Ark UI gère les attributs ARIA, les relations entre onglets et panneaux, la navigation au clavier, le déplacement du focus et le comportement des onglets désactivés.

### Points d’accroche CSS

Ciblez la partie responsable de l’aspect que vous souhaitez modifier :

- `Tabs` pour la largeur, l’espacement global, l’orientation et les surcharges liées à la variante
- `Tabs.List` pour l’apparence de la liste, les bordures, l’arrière-plan et l’espacement autour de l’indicateur
- `Tabs.Trigger` pour la disposition du libellé, l’espacement de l’icône, les états sélectionné et désactivé et le style du focus
- `Tabs.Indicator` pour personnaliser la couleur, la taille et les transitions de l’indicateur
- `Tabs.Content` pour la surface du panneau, l’espacement intérieur et le style du focus

Les principaux points d’accroche publics sont `data-slot="tabs-root"`, `data-slot="tabs-root-provider"`,
`data-slot="tabs-list"`, `data-slot="tabs-trigger"`, `data-slot="tabs-indicator"` et
`data-slot="tabs-content"`.

Parmi les attributs Ark utiles figurent `data-scope="tabs"`, `data-part`, `data-orientation`, `data-selected`,
`data-disabled`, `data-focus` et les variables de positionnement de l’indicateur `--left`, `--top`, `--width`,
`--height` et `--transition-property`.
