## Choisir le bon composant

Utilisez `Tabs` lorsque les utilisateurs basculent entre des vues mutuellement exclusives qui partagent une même
zone de la page.

- Choisissez **`Tabs`** lorsqu’un déclencheur sélectionné doit révéler un panneau de contenu sélectionné.
- Choisissez **`Accordion`** lorsque les sections doivent rester empilées et se développer indépendamment.
- Choisissez **`ToggleGroup`** lorsque le contrôle modifie un état ou un mode, sans posséder le contenu d’un panneau.

## Anatomie

```text
Tabs
├─ Tabs.List
│  ├─ Tabs.Trigger[value]
│  ├─ Tabs.Trigger[value]
│  └─ Tabs.Indicator (facultatif)
└─ Tabs.Content[value]

Tabs.RootProvider
└─ même arbre de parties connecté à un store useTabs()

Tabs.Context
└─ accès avancé avec une render prop à l’état courant des onglets
```

| Partie               | Rôle                                                                        |
| -------------------- | --------------------------------------------------------------------------- |
| `Tabs`               | Contrôle la valeur sélectionnée, le déplacement du focus, l’orientation et le mode. |
| `Tabs.RootProvider`  | Connecte les parties à l’état créé avec `useTabs()` de moduix.              |
| `Tabs.Context`       | Accès avancé avec une render prop à l’état courant des onglets.             |
| `Tabs.List`          | Regroupe les déclencheurs et possède la sémantique de liste à focus mobile. |
| `Tabs.Trigger`       | Bouton d’onglet interactif ou hôte `asChild` avec une valeur obligatoire.   |
| `Tabs.Indicator`     | Indicateur facultatif du déclencheur actif, positionné par les variables d’Ark. |
| `Tabs.Content`       | Zone de contenu correspondant à la valeur du déclencheur.                   |

## Composition

### Composition recommandée

`Tabs` gère la navigation clavier, le déplacement du focus et la valeur sélectionnée. Utilisez-le pour `value`,
`defaultValue`, `onValueChange(details)`, `onFocusChange(details)`, `activationMode`, `orientation`, `loopFocus`,
`deselectable`, `lazyMount`, `unmountOnExit`, `ids` et `navigate`.

Gardez l’arbre de parties Ark visible. `Tabs.Indicator` est facultatif et doit être affiché explicitement lorsque
vous souhaitez montrer l’indicateur du déclencheur actif.

### Quand créer une composition personnalisée

Utilisez `asChild` sur `Tabs.Trigger` lorsqu’un déclencheur doit afficher un lien ou un composant de routeur.
L’enfant doit être un unique élément sémantique capable de préserver les comportements clavier, focus et ARIA
d’Ark.

Utilisez `useTabs()` de moduix avec `Tabs.RootProvider` lorsque l’état des onglets doit être créé en dehors de
l’arbre affiché. N’affichez pas `Tabs` autour de la même instance d’état. Utilisez `Tabs.Context` ou
`useTabsContext()` lorsque l’interface environnante doit lire l’état courant des onglets.

### Propriétés par défaut

| Propriété                    | Par défaut   | Remarques                                                        |
| ---------------------------- | ------------ | ---------------------------------------------------------------- |
| `Tabs.variant`               | `default`    | Variante visuelle moduix : `default` ou `line`.                  |
| `Tabs.activationMode`        | `automatic`  | Le focus sélectionne automatiquement sauf avec `manual`.         |
| `Tabs.orientation`           | `horizontal` | `horizontal` utilise gauche/droite ; `vertical` utilise haut/bas. |
| `Tabs.loopFocus`             | `true`       | Le focus mobile boucle dans la liste des déclencheurs.           |
| `Tabs.lazyMount`             | `false`      | Diffère le montage du contenu jusqu’à sa sélection.              |
| `Tabs.unmountOnExit`         | `false`      | Retire le contenu inactif lorsqu’il est associé au montage différé. |

### Comportement

- `onValueChange` suit Ark et reçoit `details` ; lisez la valeur sélectionnée depuis `details.value`.
- `Tabs.Trigger` et `Tabs.Content` sont reliés par des propriétés `value` de type chaîne identiques.
- `Tabs.List` n’affiche plus automatiquement d’indicateur. Affichez explicitement `Tabs.Indicator` si nécessaire.
- `variant="line"` utilise le traitement rempli `default` pour les `Tabs` et `Tabs.RootProvider` verticaux.
- Ark contrôle les attributs d’accessibilité, les relations avec les tabpanels, le focus mobile et le comportement
  des déclencheurs désactivés.

### Points d’accroche CSS

Utilisez la partie responsable de l’aspect visuel concerné :

- `Tabs` pour la largeur de mise en page, l’espacement global, l’orientation et les remplacements liés à la variante
- `Tabs.List` pour l’apparence de la liste, les bordures, l’arrière-plan et l’espacement du conteneur de l’indicateur
- `Tabs.Trigger` pour la disposition du libellé, l’espacement de l’icône, l’état sélectionné, l’état désactivé et le
  style du focus
- `Tabs.Indicator` pour personnaliser la couleur, la taille et les transitions de l’indicateur
- `Tabs.Content` pour la surface du contenu, le padding et le style du focus

Les principaux hooks publics comprennent `data-slot="tabs-root"`, `data-slot="tabs-root-provider"`,
`data-slot="tabs-list"`, `data-slot="tabs-trigger"`, `data-slot="tabs-indicator"` et `data-slot="tabs-content"`.

Les hooks Ark utiles comprennent `data-scope="tabs"`, `data-part`, `data-orientation`, `data-selected`,
`data-disabled`, `data-focus` et les variables d’indicateur `--left`, `--top`, `--width` et `--height`.
