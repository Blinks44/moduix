## Choisir le bon composant

Utilisez `ProgressLinear` lorsque l’utilisateur doit suivre l’avancement sur une barre. Préférez
`ProgressCircular` pour un indicateur d’état compact dans une carte, une barre d’outils ou tout autre
espace limité.

## Anatomie

```text
ProgressLinear / ProgressLinear.Root
├─ ProgressLinear.Label
├─ ProgressLinear.ValueText
├─ ProgressLinear.Track
│  └─ ProgressLinear.Range
└─ ProgressLinear.View

ProgressLinear.RootProvider
└─ same part tree connected to ProgressLinear.useProgress()
```

| Partie                                    | Rôle                                                                            |
| ----------------------------------------- | ------------------------------------------------------------------------------- |
| `ProgressLinear` / `ProgressLinear.Root`  | Gère l’état de progression et transmet à Ark le formatage, les identifiants et les autres propriétés. |
| `ProgressLinear.RootProvider`             | Relie les parties à l’état renvoyé par `ProgressLinear.useProgress()`.          |
| `ProgressLinear.Context`                  | Transmet l’état courant à une fonction de rendu.                                |
| `ProgressLinear.Label`                    | Libellé visible de la tâche. Il ne devient pas automatiquement le nom accessible de `Track`. |
| `ProgressLinear.ValueText`                | Affiche le pourcentage formaté et annonce les changements. Utilisez `Context` pour afficher un texte personnalisé. |
| `ProgressLinear.Track`                   | Piste de progression. Ark lui ajoute le rôle et les attributs ARIA de valeur.  |
| `ProgressLinear.Range`                   | Partie remplie qui représente l’avancement actuel.                             |
| `ProgressLinear.View`                    | Affiche son contenu uniquement lorsque son `state` correspond à l’état courant. |

## Composition

### Composition recommandée

Pour le cas courant, utilisez `ProgressLinear` ou `ProgressLinear.Root` comme racine.
`ProgressLinear` est un raccourci pour `ProgressLinear.Root`. Les parties visibles restent
explicites afin que vous gardiez la maîtrise de la structure rendue.

Utilisez `defaultValue` pour une progression non contrôlée. Pour une progression contrôlée, utilisez
`value` avec `onValueChange(details)` lorsque votre application gère la valeur courante. Définissez
`defaultValue={null}` ou `value={null}` lorsque la tâche est en cours mais que son avancement est
inconnu.

`ProgressLinear.RootProvider` remplace la racine lorsque l’état est créé avec
`ProgressLinear.useProgress()`. Ne rendez pas `Root` et `RootProvider` ensemble.

### Quand créer une composition personnalisée

Utilisez `ProgressLinear.RootProvider` avec `ProgressLinear.useProgress()` lorsqu’un composant parent
ou une autre partie de l’application doit créer ou contrôler l’état de progression.

Utilisez `translations.value(details)` lorsque le nom accessible généré doit décrire la tâche plus
précisément. Ark utilise la chaîne retournée comme `aria-label` généré sur `Track`. Le `ValueText`
standard continue d’afficher le pourcentage formaté. Pour rendre le texte personnalisé visible,
affichez `state.valueAsString` via `ProgressLinear.Context`. Un `aria-label` ou un
`aria-labelledby` explicite sur `Track` est prioritaire lorsque vous devez définir vous-même le nom
de la tâche.

Utilisez `ids` lorsqu’une composition personnalisée a besoin d’identifiants stables et explicites
pour le libellé, la piste ou la mise en page environnante. Utilisez `ProgressLinear.View` lorsque le
contenu d’accompagnement doit changer avec l’état de progression Ark, sans dupliquer les vérifications
d’état. Utilisez `ProgressLinear.Context` ou `ProgressLinear.useProgressContext()` lorsqu’une
interface personnalisée doit accéder à l’état sous une racine ou un fournisseur. Réservez les
imports directs d’Ark aux intégrations qui ne peuvent pas utiliser l’API moduix.

### Propriétés par défaut

| Propriété       | Par défaut             | Notes                                                  |
| --------------- | ---------------------- | ------------------------------------------------------ |
| `defaultValue`  | `50`                   | Valeur initiale d’une progression non contrôlée.      |
| `min`           | `0`                    | Minimum utilisé pour le pourcentage et les valeurs ARIA. |
| `max`           | `100`                  | Maximum utilisé pour le pourcentage et les valeurs ARIA. |
| `formatOptions` | `{ style: 'percent' }` | Options utilisées pour formater `ValueText`.          |
| `locale`        | `'en-US'`              | Locale transmise à `Intl.NumberFormat`.               |
| `orientation`   | `'horizontal'`         | Utilisez `vertical` avec une hauteur définie.          |

### Comportement

`ProgressLinear.Track` reçoit d’Ark `role="progressbar"`, `aria-valuemin`, `aria-valuemax` et
`aria-valuenow`. La racine expose `data-state="indeterminate|loading|complete"` et
`data-orientation`. Pour une progression indéterminée, l’attribut `aria-valuenow` est omis.

`ProgressLinear.Label` fournit un contexte visible, mais ne nomme pas automatiquement `Track`.
La piste reçoit par défaut un nom accessible généré à partir de la valeur par
`translations.value(details)`. Pour donner explicitement le nom de la tâche, ajoutez
`aria-label` ou `aria-labelledby` à `Track`. `ProgressLinear.ValueText` annonce les changements avec
`aria-live="polite"`.

Toutes les parties rendues prennent en charge `asChild` via la composition polymorphe d’Ark. Gardez
des éléments de remplacement sémantiques et préservez la sémantique de l’indicateur sur `Track`.
La progression est informative : le composant ne gère ni interaction au clavier ni gestion du focus.

Ark ajoute `data-orientation` à la racine, au libellé, à la piste et à la partie remplie. En RTL, la
progression déterminée commence au début de la ligne et l’animation indéterminée change de direction.

## Styles

Utilisez `className` sur les parties exportées pour modifier la structure visuelle. Pour les styles
dépendants de l’état, utilisez les attributs de données Ark et les points d’accroche `data-slot` de
moduix.

La racine a une largeur par défaut de `12rem`. En mode vertical, sa hauteur par défaut est également
de `12rem`. Utilisez les variables publiques `--moduix-progress-linear-*` pour adapter le composant
à votre mise en page.
