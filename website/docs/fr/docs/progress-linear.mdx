Composez la barre de progression avec les parties explicites `ProgressLinearLabel`, `ProgressLinearValueText`, `ProgressLinearTrack` et
`ProgressLinearRange`. Donnez à `ProgressLinearTrack` un nom accessible qui décrit la tâche.
React, Solid et Vue exposent les mêmes noms de parties plats ; Vue utilise `class`, les slots et `v-model` lorsque le contrat le prévoit.

## Choisir le bon composant

Utilisez `ProgressLinear` lorsque l’utilisateur doit suivre l’avancement sur une barre. Préférez
`ProgressCircular` pour un indicateur d’état compact dans une carte, une barre d’outils ou tout autre
espace limité.

Créez l’état de progression avec `useProgress()` dans un composant parent, puis

### Vues d’état

Utilisez `ProgressLinearView` lorsque le texte ou l’interface d’accompagnement doit changer avec

### Texte de la valeur

Utilisez `ProgressLinearContext` avec `translations.value(details)` lorsque le texte visible de la

### Orientation verticale

Définissez `orientation="vertical"` lorsque la partie remplie doit progresser du bas vers le haut.
En mode vertical, la hauteur par défaut est de `12rem`. Si votre mise en page nécessite une autre
hauteur, définissez `height` sur la racine.

## Composition

Utilisez `defaultValue` pour une progression non contrôlée. Pour une progression contrôlée, utilisez
`value` avec `onValueChange(details)` lorsque votre application gère la valeur courante. Utilisez
`defaultValue={null}` ou `value={null}` lorsque l’avancement est inconnu. Si l’état est créé avec
`useProgress()`, rendez les parties dans `ProgressLinearRootProvider` plutôt que dans
`ProgressLinear`. Utilisez `ProgressLinearView` pour le contenu dépendant de
l’état et `ProgressLinearContext` lorsque votre texte personnalisé doit accéder à l’état courant.
Dans Vue, utilisez `v-model` pour la même valeur contrôlée.

## Styles

Utilisez `className` dans React ou `class` dans Solid et Vue sur les parties exportées pour modifier la
structure visuelle. Pour les styles dépendants de l’état, utilisez les attributs de données Ark et
les points d’accroche `data-slot` de moduix. Les variantes Tailwind utilisent des utilitaires natifs et
des classes du consommateur ; les variables ci-dessous personnalisent les variantes CSS Modules.

La racine occupe toute la largeur de son conteneur. En mode vertical, elle prend la largeur de son
contenu et une hauteur de `12rem`. Définissez `width` ou `height` sur la racine pour l'adapter à
votre mise en page.
`--moduix-progress-linear-track-size` règle l'épaisseur de la barre dans les deux orientations. La
progression indéterminée fait défiler une plage de 35 % du bord de début vers le bord de fin (de droite
à gauche en RTL) ; lorsque les animations réduites sont préférées, la plage reste immobile au bord de
début.

## Référence de l’API

| Prop | Type | Défaut |
| --- | --- | --- |
| `value` | `number \| null` | — |
| `defaultValue` | `number \| null` | `50` |
| `onValueChange` | `(details: ValueChangeDetails) => void` | — |
| `min` | `number` | `0` |
| `max` | `number` | `100` |
| `formatOptions` | `Intl.NumberFormatOptions` | `{ style: 'percent' }` |
| `locale` | `string` | — |
| `translations` | `IntlTranslations` | — |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` |
