## Choisir le bon composant

Utilisez `ProgressLinear` lorsque l’utilisateur doit suivre l’avancement sur une barre. Préférez
`ProgressCircular` pour un indicateur d’état compact dans une carte, une barre d’outils ou tout autre
espace limité.

## Anatomie

```text
ProgressLinear
├─ ProgressLinearLabel
├─ ProgressLinearValueText
├─ ProgressLinearTrack
│  └─ ProgressLinearRange
└─ ProgressLinearView

ProgressLinearRootProvider
└─ le même arbre de parties relié à useProgress()
```

| Partie                                    | Rôle                                                                            |
| ----------------------------------------- | ------------------------------------------------------------------------------- |
| `ProgressLinear`  | Gère l’état de progression et transmet à Ark le formatage, les identifiants et les autres propriétés. |
| `ProgressLinearRootProvider`             | Relie les parties à l’état renvoyé par `useProgress()`.          |
| `ProgressLinearContext`                  | Transmet l’état courant à une fonction de rendu.                                |
| `ProgressLinearLabel`                    | Libellé visible de la tâche. Il ne devient pas automatiquement le nom accessible de `ProgressLinearTrack`. |
| `ProgressLinearValueText`                | Affiche le pourcentage formaté et annonce les changements. Utilisez `ProgressLinearContext` pour un texte personnalisé. |
| `ProgressLinearTrack`                    | Piste de progression. Ark lui ajoute le rôle et les attributs ARIA de valeur.  |
| `ProgressLinearRange`                    | Partie remplie qui représente l’avancement actuel.                             |
| `ProgressLinearView`                     | Affiche son contenu uniquement lorsque son `state` correspond à l’état courant. |

## Composition

Utilisez `defaultValue` pour une progression non contrôlée. Pour une progression contrôlée, utilisez
`value` avec `onValueChange(details)` lorsque votre application gère la valeur courante. Utilisez
`defaultValue={null}` ou `value={null}` lorsque l’avancement est inconnu. Si l’état est créé avec
`useProgress()`, rendez les parties dans `ProgressLinearRootProvider` plutôt que dans
`ProgressLinear` ou `ProgressLinear`. Utilisez `ProgressLinearView` pour le contenu dépendant de
l’état et `ProgressLinearContext` lorsque votre texte personnalisé doit accéder à l’état courant.

## Styles

Utilisez `className` dans React ou `class` dans Solid sur les parties exportées pour modifier la
structure visuelle. Pour les styles dépendants de l’état, utilisez les attributs de données Ark et
les points d’accroche `data-slot` de moduix. Les variantes Tailwind utilisent des utilitaires natifs et
des classes du consommateur ; les variables ci-dessous personnalisent les variantes CSS Modules.

La racine a une largeur par défaut de `12rem`. En mode vertical, sa hauteur par défaut est également
de `12rem`. Utilisez les variables publiques `--moduix-progress-linear-*` pour adapter le composant
à votre mise en page.

### Points d’accroche CSS

- `data-slot="progress-linear-root"`, `progress-linear-root-provider`, `progress-linear-label`,
  `progress-linear-value-text`, `progress-linear-track`, `progress-linear-range` et
  `progress-linear-view`.
- Attributs Ark : `data-scope="progress"`, `data-part`, `data-state="indeterminate|loading|complete"`,
  `data-orientation="horizontal|vertical"`, `data-value` et `data-max`.
