## Ce que fait Presence

`Presence` est un utilitaire d’Ark UI, et non un composant exporté par `@moduix/react`. Il contrôle un sous-arbre avec
la prop `present`. Selon les options de stratégie de rendu, ce sous-arbre peut rester monté tout en étant masqué, être
monté uniquement lors de sa première apparition ou être démonté après son animation de sortie.

Par défaut, Presence rend une racine `<div>` avec `data-scope="presence"` et `data-part="root"`. La racine reçoit aussi
`data-state="open"` ou `data-state="closed"`, ce qui permet de cibler les états d’entrée et de sortie en CSS. Utilisez
`asChild` lorsqu’un élément enfant existant doit recevoir les props de Presence au lieu d’ajouter une racine.

Importez-le directement depuis Ark UI :

```tsx
import { Presence } from '@ark-ui/react/presence';
```

## Quand l’utiliser

Utilisez `Presence` seul pour des panneaux, notifications, cartes ou autres contenus contrôlés par l’application dont le
cycle de montage doit être géré explicitement.

Pour Dialog, Drawer, Lightbox, Menu, Popover, Tooltip, Tour et les racines moduix similaires, utilisez les props de
présence exposées par ces composants. Ils coordonnent déjà la présence avec la gestion du focus, le positionnement et
la fermeture. Utilisez `Presence` seul lorsque le cycle de vie relève de votre application et non d’une racine moduix
existante.

## Monter à la demande

Combinez `lazyMount` et `unmountOnExit` lorsque le contenu ne doit pas exister avant sa première apparition ni après sa
fermeture. `lazyMount` retarde le premier montage, mais ne retire pas le contenu à la fermeture. `unmountOnExit` s’en
charge.

## Animations de sortie

Lorsque `unmountOnExit` est activé, Presence laisse la racine dans le DOM pendant l’exécution de son animation CSS de
sortie. Ciblez `data-state="open"` et `data-state="closed"` pour définir les styles d’entrée et de sortie. Utilisez
`onExitComplete` lorsqu’un autre traitement doit attendre la fin de l’animation de sortie.

```tsx
import { Presence } from '@ark-ui/react/presence';
import { Card } from '@moduix/react/card';

export function ActivityPanel({ open }: { open: boolean }) {
  return (
    <Presence className="activity-panel" present={open} unmountOnExit>
      <Card>Saved filters will apply to the next refresh.</Card>
    </Presence>
  );
}
```

```css
@keyframes activity-panel-enter {
  from {
    opacity: 0;
    transform: translateY(-0.25rem);
  }
}

@keyframes activity-panel-exit {
  to {
    opacity: 0;
    transform: translateY(-0.25rem);
  }
}

.activity-panel[data-state='open'] {
  animation: activity-panel-enter 160ms ease-out;
}

.activity-panel[data-state='closed'] {
  animation: activity-panel-exit 120ms ease-in;
}
```

Définissez `skipAnimationOnMount` lorsque la première apparition doit être immédiate. Définissez `immediate` lorsque
le changement de `present` doit s’appliquer immédiatement au lieu d’être reporté à la prochaine frame.

## Masquer un contenu monté

Lorsque le contenu reste monté, `hideMode` détermine la façon dont Ark le masque :

- `display-none` est le mode par défaut. Il utilise l’attribut `hidden`, les effets du sous-arbre continuent donc de
  s’exécuter.
- `activity` utilise le composant `Activity` de React 19 avec `mode="hidden"`, ce qui met les effets en pause lorsque
  le contenu est masqué. Cette option nécessite React 19 ou une version ultérieure. Si `Activity` n’est pas disponible,
  Ark revient au comportement fondé sur l’attribut `hidden`.

Choisissez `lazyMount` et `unmountOnExit` lorsque le sous-arbre ne doit pas exister en dehors de son cycle de vie actif.
Choisissez `hideMode` lorsqu’il doit rester monté, mais avec un comportement différent à l’état masqué.

## Composition

### Composition recommandée

Placez `Presence` au plus près du contenu dont il contrôle le cycle de montage. Il peut envelopper un composant moduix
ou un élément HTML sémantique. Passez `className` à la racine de Presence lorsque ce conteneur a besoin de styles de
mise en page ou d’animation.

### Quand utiliser `asChild`

Utilisez `asChild` lorsque vous avez déjà un élément racine adapté et que vous voulez lui transmettre les props de
Presence. Vérifiez que l’enfant peut recevoir une ref, `hidden`, `data-*` et la classe transmise. N’utilisez pas
`asChild` avec plusieurs enfants.

## Utiliser moduix

Placez n’importe quel composant moduix dans `Presence` : cartes, boutons, formulaires et panneaux personnalisés
conservent leur style et leur comportement habituels. Presence gère uniquement le cycle de montage et les attributs
d’état ; il ne modifie ni la sémantique ni le modèle d’interaction de l’enfant.

## Ark UI et moduix

Ark UI fournit l’API de `Presence`, la stratégie de montage et le cycle de vie des animations. `@moduix/react` ne
ré-exporte pas `Presence` : importez-le depuis `@ark-ui/react/presence` et utilisez les composants moduix à l’intérieur.
Les racines moduix qui gèrent leur propre comportement d’ouverture, de fermeture ou de superposition exposent des props
de présence équivalentes lorsque cela est pertinent.

Si vous utilisez l’utilitaire seul avec moduix, installez les deux paquets :

```bash
pnpm add @ark-ui/react @moduix/react
```
