# Animations

moduix fournit des variables CSS de mouvement communes pour le contenu flottant et modal. Définissez-les une seule
fois pour appliquer la même durée, la même courbe et les mêmes effets de fondu, d’échelle ou de déplacement à tous
les panneaux flottants pris en charge. Lorsqu’un composant doit avoir un mouvement différent, utilisez ses variables locales.

Les composants utilisent les attributs `data-state` d’Ark pour choisir les animations d’entrée et de sortie. Lorsqu’un
contenu se ferme, Ark le conserve dans le DOM jusqu’à la fin de son animation de sortie.

Les tokens partagés `--moduix-duration-*`, `--moduix-ease-*`, `--moduix-transition-*` et `--moduix-scale-*`
servent dans de nombreuses parties du système. Utilisez `--moduix-popup-motion-*` lorsque seul le contenu flottant
doit changer dans tout le projet.

Quand la réduction des mouvements est activée dans le système d’exploitation, les tokens de durée partagés passent à
`0.01ms` et les animations communes de pulsation, de fondu, de déplacement et de rotation sont désactivées. Les
composants dont le mouvement est spécifique, comme `Marquee` et `Progress` indéterminé, gardent leur propre gestion
de `prefers-reduced-motion`.

## Choisir l’API d’animation

### Animation partagée des panneaux flottants

Utilisez `*-starting-*` pour l’entrée et `*-ending-*` pour la sortie. Les variables partagées s’appliquent aux
parties `Content` suivantes : `Popover.Content`, `Menu.Content`, `Tooltip.Content`, `HoverCard.Content`,
`FloatingPanel.Content`, `Dialog.Content`, `CommandPalette.Content`, `Lightbox.Content`, `Tour.Content`,
`NavigationMenu.Content`, `Select.Content`, `Combobox.Content`, `DatePicker.Content` et `ColorPicker.Content`.

Par exemple, ce réglage fait entrer tout le contenu pris en charge depuis la gauche et le fait repartir vers la gauche
avec la même courbe :

```css
:root {
  --moduix-popup-motion-duration: 220ms;
  --moduix-popup-motion-easing: cubic-bezier(0.22, 1, 0.36, 1);
  --moduix-popup-motion-starting-opacity: 0;
  --moduix-popup-motion-ending-opacity: 0;
  --moduix-popup-motion-starting-scale: 1;
  --moduix-popup-motion-ending-scale: 1;
  --moduix-popup-motion-starting-translate-x: -0.75rem;
  --moduix-popup-motion-ending-translate-x: -0.75rem;
}
```

Pour les panneaux rendus habituellement dans un portail, définissez les variables sur `:root`. Une variable placée
uniquement sur un conteneur local n’atteint pas le contenu rendu dans `document.body`. Elle fonctionne avec un
composant rendu avec `portalled={false}`.

### Redéfinitions locales

Les variables propres au composant prennent le pas sur les valeurs partagées. Utilisez-les pour une exception locale
à la règle du projet et ajoutez une classe à la partie visuelle indiquée dans le tableau. Les panneaux ancrés
conservent le `transform-origin` d’Ark : les recettes fondées sur l’échelle s’ouvrent toujours depuis le déclencheur.

| Surface | Appliquer la classe à | Variables de mouvement |
| --- | --- | --- |
| Popover | `Popover.Content` | `--moduix-popover-transition`, `--moduix-popover-content-*` |
| Menu | `Menu.Content` | `--moduix-menu-transition`, `--moduix-menu-popup-*` |
| Tooltip | `Tooltip.Content` | `--moduix-tooltip-transition`, `--moduix-tooltip-popup-*` |
| Hover Card | `HoverCard.Content` | `--moduix-hover-card-transition`, `--moduix-hover-card-content-*` |
| Floating Panel | `FloatingPanel.Content` | `--moduix-floating-panel-transition`, `--moduix-floating-panel-*` |
| Dialog | `Dialog.Content` | `--moduix-dialog-transition`, `--moduix-dialog-content-*` |
| Command Palette | `CommandPalette.Content` | `--moduix-command-palette-transition`, `--moduix-command-palette-content-*` |
| Lightbox | `Lightbox.Content` | `--moduix-lightbox-transition`, `--moduix-lightbox-content-*` |
| Tour | `Tour.Content` | `--moduix-tour-transition`, `--moduix-tour-content-*` |
| Navigation Menu | `NavigationMenu.Content` | `--moduix-navigation-menu-transition`, `--moduix-navigation-menu-content-*` |
| Select | `Select.Content` | `--moduix-select-transition`, `--moduix-select-content-*` |
| Combobox | `Combobox.Content` | `--moduix-combobox-transition`, `--moduix-combobox-content-*` |
| Date Picker | `DatePicker.Content` | `--moduix-date-picker-transition`, `--moduix-date-picker-content-*` |
| Color Picker | `ColorPicker.Content` | `--moduix-color-picker-transition`, `--moduix-color-picker-content-*` |

Avec un `Viewport`, `NavigationMenu` utilise aussi les tokens partagés pour le dimensionnement de la zone et le
mouvement directionnel de son contenu. Pour personnaliser la zone elle-même, utilisez
`--moduix-navigation-menu-viewport-*`.

`Dialog`, `CommandPalette`, `Lightbox` et `Tour` exposent également des variables `*-backdrop-*` sur leur partie
`Backdrop`. Les arrière-plans utilisent leur propre variable de transition et n’animent que `opacity` et `blur` ; ils
n’utilisent pas les valeurs partagées d’échelle ou de déplacement. Le contenu partagé des panneaux peut animer
`opacity`, `scale` et `translate-x` ou `translate-y`. Pour le flou, utilisez des filtres CSS comme `blur(4px)` ou
`none`.

### Animation des états

Ces composants ont leur propre système d’animation et n’acceptent donc pas `--moduix-popup-motion-*` :

| Composant | Partie visuelle | Personnalisation prise en charge |
| --- | --- | --- |
| Accordion | `Accordion.ItemContent` | `--moduix-accordion-item-content-transition`, `--moduix-accordion-item-content-open-opacity`, `--moduix-accordion-item-content-closed-opacity` |
| Collapsible | `Collapsible.Content` | `--moduix-collapsible-content-transition`, `--moduix-collapsible-content-open-opacity`, `--moduix-collapsible-content-closed-opacity` |
| Drawer | `Drawer.Content` et `Drawer.Backdrop` | `--moduix-drawer-transition`, `--moduix-drawer-backdrop-transition` ; la direction et le glissement contrôlent la transformation |
| Swap | `Swap.Indicator` | `--moduix-swap-transition` et variables distinctes d’opacité et d’échelle pour l’entrée et la sortie |
| Tree View | `TreeView.BranchContent` | `--moduix-tree-view-transition`, `--moduix-tree-view-content-transition-duration` |

`Toast` utilise les variables de mise en page d’Ark pour empiler les notifications et les fermer. Ne modifiez pas
`--x`, `--y`, `--scale`, `--height` ni `--opacity`. Les recettes de cette page ne font pas partie de l’API de
`Toast`.

## Recettes prêtes à l’emploi

Choisissez une animation en fonction de son objectif, puis réutilisez la même recette pour des panneaux similaires :

| Objectif du produit | Point de départ |
| --- | --- |
| Apparition discrète, sans signification spatiale | Fondu |
| Un panneau apparaît depuis un bord proche | Déplacement dans la direction correspondante |
| Un menu ou un sélecteur ancré s’ouvre depuis son déclencheur | Échelle ou remontée |
| Une confirmation courte et conviviale | Apparition douce, à utiliser avec modération |

Définissez ces variables sur `:root` pour appliquer la recette à tout le contenu des panneaux flottants pris en
charge. Pour une exception, utilisez les variables du composant correspondant dans le tableau ci-dessus.

### Fondu

```css
:root {
  --moduix-popup-motion-starting-opacity: 0;
  --moduix-popup-motion-ending-opacity: 0;
  --moduix-popup-motion-starting-scale: 1;
  --moduix-popup-motion-ending-scale: 1;
  --moduix-popup-motion-starting-translate-y: 0;
  --moduix-popup-motion-ending-translate-y: 0;
}
```

### Déplacement vers le haut

```css
:root {
  --moduix-popup-motion-starting-opacity: 0;
  --moduix-popup-motion-ending-opacity: 0;
  --moduix-popup-motion-starting-scale: 1;
  --moduix-popup-motion-ending-scale: 1;
  --moduix-popup-motion-starting-translate-y: 0.75rem;
  --moduix-popup-motion-ending-translate-y: 0.75rem;

```

### Déplacement vers le bas

## Recettes par composant

### Focus avec effet de verre

Pour un arrière-plan modal, ajoutez la première classe à `Dialog.Backdrop` et la seconde à `Dialog.Content`. Pour
les autres familles modales, remplacez `dialog` par `command-palette`, `lightbox` ou `tour`.

```css
.glassFocusBackdrop {
  --moduix-dialog-backdrop-transition: 220ms var(--moduix-ease-out);
  --moduix-dialog-backdrop-starting-opacity: 0;
  --moduix-dialog-backdrop-ending-opacity: 0;
  --moduix-dialog-backdrop-starting-blur: none;
  --moduix-dialog-backdrop-ending-blur: none;
}

.glassFocusContent {
  --moduix-dialog-transition: 220ms cubic-bezier(0.22, 1, 0.36, 1);
  --moduix-dialog-content-starting-opacity: 0;
  --moduix-dialog-content-ending-opacity: 0;
  --moduix-dialog-content-starting-scale: 0.96;
  --moduix-dialog-content-ending-scale: 0.98;
  --moduix-dialog-content-starting-translate-y: 0.75rem;
  --moduix-dialog-content-ending-translate-y: 0.75rem;
}
```

### Mise à l’échelle douce

Cette recette applique une mise à l’échelle douce au contenu d’un sélecteur. Ajoutez la classe à `Select.Content`.
Pour `Combobox`, `ColorPicker` ou `DatePicker`, remplacez le préfixe `select` par `combobox`, `color-picker` ou
`date-picker`.

```css
.softScalePicker {
  --moduix-select-transition: 180ms cubic-bezier(0.22, 1, 0.36, 1);
  --moduix-select-content-closed-opacity: 0;
  --moduix-select-content-closed-scale: 0.96;
}
```

### Ouverture souple

Ajoutez cette classe à `Accordion.ItemContent`. Pour `Collapsible.Content`, utilisez à la place le préfixe
`--moduix-collapsible-content-*`.

```css
.relaxedDisclosure {
  --moduix-accordion-item-content-transition: 240ms var(--moduix-ease-out);
  --moduix-accordion-item-content-closed-opacity: 0;
}
```

### Transition accentuée

Ajoutez cette classe à `Swap.Indicator` lorsque l’élément sortant doit s’effacer et que le suivant doit apparaître
avec plus d’énergie.

```css
.emphasizedSwap {
  --moduix-swap-transition: 180ms cubic-bezier(0.22, 1, 0.36, 1);
  --moduix-swap-enter-starting-opacity: 0;
  --moduix-swap-enter-starting-scale: 0.82;
  --moduix-swap-exit-ending-opacity: 0;
  --moduix-swap-exit-ending-scale: 1.08;
}
```

## Règles d’utilisation

- Placez les variables de mouvement locales sur la partie visuelle qui porte l’animation. Définissez les variables
  partagées des panneaux flottants sur `:root` pour les panneaux rendus par défaut dans un portail.
- Gardez les valeurs d’entrée et de sortie symétriques, sauf si une asymétrie est volontaire.
- Pour un fondu ou un déplacement sans mise à l’échelle, définissez l’échelle à `1`.
- Utilisez `--moduix-popup-motion-*` pour une règle commune à tout le projet. Réservez les variables locales du
  composant aux exceptions.
- Ne remplacez pas les transformations de `Drawer` ni les variables de mise en page gérées par Ark pour `Toast`.
  Elles sont synchronisées avec l’interaction et la fermeture.
- L’animation de sortie fonctionne par défaut. N’utilisez `present` que lorsque JavaScript doit contrôler
  explicitement le montage d’une partie. Les recettes CSS ordinaires n’en ont pas besoin.
