# Animations

Utilisez une animation pour expliquer un changement d’état, pas pour décorer chaque interaction.
Commencez par le mouvement fourni par Moduix, ne modifiez une règle partagée que si tout le produit en
a besoin et placez les exceptions sur la partie visuelle qui porte l’animation.

Ark expose l’entrée et la sortie avec les attributs `data-state` et conserve le contenu fermé dans le
DOM jusqu’à la fin de son animation. La fondation réduit aussi les animations partagées lorsque le
système demande `prefers-reduced-motion`.

## Choisir une méthode de style

| Méthode | Approche recommandée |
| --- | --- |
| CSS Modules | Redéfinissez les variables documentées, partagées ou propres au composant. |
| Tailwind CSS | Utilisez les animations du composant Tailwind, puis les classes du consommateur ou le code du registre pour une exception ciblée. |

Les variables ci-dessous appartiennent aux packages CSS Modules de tous les frameworks publiés. React
et Solid partagent les mêmes noms. Les packages Tailwind utilisent des classes utilitaires et ne
promettent pas le contrat des variables locales de CSS Modules.

## Définir le mouvement partagé des popups

Définissez `--moduix-popup-motion-*` sur `:root` lorsque les popups pris en charge doivent partager la
même durée, courbe, opacité, échelle ou translation. Les valeurs `starting` gèrent l’entrée et les
valeurs `ending` la sortie.

```css
:root {
  --moduix-popup-motion-duration: 220ms;
  --moduix-popup-motion-easing: cubic-bezier(0.22, 1, 0.36, 1);
  --moduix-popup-motion-starting-opacity: 0;
  --moduix-popup-motion-ending-opacity: 0;
  --moduix-popup-motion-starting-scale: 0.96;
  --moduix-popup-motion-ending-scale: 0.98;
  --moduix-popup-motion-starting-translate-y: 0.5rem;
  --moduix-popup-motion-ending-translate-y: 0.5rem;
}
```

Utilisez `:root` pour les superpositions normalement rendues dans un portail. Une variable placée sur
un conteneur local ne les atteint que si elles restent dans ce sous-arbre, par exemple avec
`portalled={false}` ou un conteneur de portail dédié.

Ces variables couvrent le contenu de Popover, Menu, Tooltip, Hover Card, Floating Panel, Dialog,
Command Palette, Lightbox, Tour, Navigation Menu, Select, Combobox, Date Picker et Color Picker.

## Ajouter une exception locale

Les variables propres au composant ont priorité sur les valeurs partagées. Placez-les sur la partie
visuelle qui porte l’animation.

| Surface | Partie | Famille de variables |
| --- | --- | --- |
| Popover | `Popover.Content` | `--moduix-popover-content-*` |
| Dialog | `DialogContent` | `--moduix-dialog-content-*` |
| Select | `Select.Content` | `--moduix-select-content-*` |
| Navigation Menu | `NavigationMenuContent` | `--moduix-navigation-menu-content-*` |

Par exemple, appliquez une échelle plus douce à un seul Select :

```css
.softScalePicker {
  --moduix-select-transition: 180ms cubic-bezier(0.22, 1, 0.36, 1);
  --moduix-select-content-closed-opacity: 0;
  --moduix-select-content-closed-scale: 0.96;
}
```

Consultez la page du composant pour la liste complète. Le Backdrop d’une modale possède ses propres
variables de transition, d’opacité et de flou ; il n’hérite pas de l’échelle ni de la translation des
popups.

## Séparer les mouvements liés à l’état

Certaines interactions dépendent de leur géométrie ou de leur cycle de vie et conservent donc leur
propre contrat.

| Composant | Pourquoi le système reste séparé |
| --- | --- |
| Accordion et Collapsible | La hauteur du contenu et l’état déplié pilotent la transition. |
| Drawer | La direction du glissement pilote la transformation. |
| Swap | Les indicateurs entrant et sortant s’animent séparément. |
| Tree View | Le dépliage d’une branche possède sa propre durée. |
| Toast | Les variables d’exécution d’Ark coordonnent la pile et la fermeture. |

Ne remplacez pas les transformations de Drawer ni les variables de disposition de Toast par une
recette de popup.

## Comparer les recettes

L’aperçu utilise React, car le site de documentation fonctionne avec React. Les recettes sont en CSS
et s’appliquent de la même manière à tous les adaptateurs CSS Modules publiés.

<ExampleFrame variant="component">
  <AnimationDocs.MotionRecipesExample />
</ExampleFrame>

| Intention | Point de départ |
| --- | --- |
| Dépliage discret | Fade |
| Mouvement depuis un bord proche | Slide dans la direction correspondante |
| Menu ou Select ancré à son déclencheur | Zoom ou Lift |
| Confirmation courte et amicale | Soft Pop, avec parcimonie |

## Vérifier les animations

- Testez l’entrée et la sortie, pas seulement l’ouverture.
- Vérifiez les portails et les redéfinitions locales dans leur vrai conteneur.
- Assurez-vous que l’animation ne retarde ni ne masque le focus clavier.
- Activez la réduction des animations du système.
- Gardez l’entrée et la sortie symétriques, sauf si la différence explique une direction ou une hiérarchie.
