## Référence de l’API

Ark UI ne fournit pas de primitive Card dédiée. moduix construit Card avec la [fabrique officielle d’Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) et suit les recommandations d’Ark pour la [composition](https://ark-ui.com/docs/guides/composition), le [style](https://ark-ui.com/docs/guides/styling) et les [refs](https://ark-ui.com/docs/guides/ref).


Les mêmes exports sont disponibles depuis `@moduix/solid/card` pour Solid.

## Anatomie

```text
Card
├─ CardBackground (aide moduix facultative)
├─ CardMedia (aide moduix facultative)
├─ CardHeader
│  ├─ CardTitle
│  ├─ CardDescription
│  └─ CardAction (aide moduix facultative)
├─ CardBody
└─ CardFooter (facultatif)
```

| Partie               | Rôle                                                                                          |
| -------------------- | --------------------------------------------------------------------------------------------- |
| `Card` | Conteneur racine avec les props `size`, `variant` et `asChild`.                               |
| `CardBackground`    | Couche de fond facultative couvrant toute la carte pour un média décoratif.                  |
| `CardMedia`         | Conteneur facultatif pour un média bord à bord, avec un arrondi uniforme des angles supérieurs. |
| `CardHeader`        | Mise en page de l’en-tête pour le titre, la description et une éventuelle action à droite.    |
| `CardBody`          | Zone principale du contenu.                                                                  |
| `CardFooter`        | Ligne inférieure pour les actions ou les métadonnées. Elle passe à la ligne si nécessaire.   |
| `CardTitle`         | Titre rendu en `h3` par défaut. Utilisez `asChild` pour choisir un autre niveau.              |
| `CardDescription`   | Texte complémentaire sous le titre.                                                          |
| `CardAction`        | Emplacement réservé à une action dans l’en-tête.                                             |
| `CardLink`          | Lien dont la zone cliquable s’étend à toute la carte sans bloquer les autres contrôles.      |

## Composition

Card ne gère aucun état, fonction de rappel, contexte, comportement clavier ni champ masqué. Utilisez ses parties simples pour le contenu de présentation. Utilisez `asChild` lorsqu’un élément sémantique doit porter la racine ou une autre partie ; il doit rendre exactement un enfant capable de recevoir les propriétés fusionnées. En Solid, `asChild` utilise une fonction de rendu telle que `asChild={(props) => <a {...props()} />}`.

Lorsqu’une carte est entièrement un lien et ne contient aucun contrôle imbriqué, composez la racine avec `asChild`. Si la carte contient aussi des boutons ou d’autres actions, gardez `CardLink` dans `CardTitle` et placez ces contrôles dans `CardAction` ; la zone cliquable étendue du lien ne gênera ainsi pas les autres éléments interactifs. Utilisez `CardMedia` pour un média informatif placé en tête et `CardBackground` pour un média décoratif derrière le contenu. Donnez un `alt` vide aux images d’arrière-plan et gérez dans l’application les éventuelles superpositions ou styles assurant le contraste du texte.

### Attributs utiles pour le style

- Chaque partie expose `data-scope="card"` et le `data-part` correspondant.
- Les points d’accroche `data-slot` stables de moduix sont `card-root`, `card-background`, `card-media`, `card-header`, `card-body`,
  `card-footer`, `card-title`, `card-description`, `card-action` et `card-link`.
- Le composant racine expose `data-size="sm | md | lg"` et
  `data-variant="elevated | outline | subtle"`.
- Les variables CSS s’appliquent à toutes les variantes. Pour personnaliser une variante dans toute
  l’application, définissez-les sur `[data-slot='card-root'][data-variant='<variant>']`.
- Chaque section a la même marge intérieure en haut, et la dernière l’a aussi en bas. Avec Tailwind,
  modifiez cette marge basse avec `last:pb-*` sur la section ou `[--card-spacing:…]` sur la racine.
- Card n’expose aucun attribut d’état interactif, car il ne gère ni état ni comportement.
