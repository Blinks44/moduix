## Référence de l’API

Ark UI ne fournit pas de primitive card dédiée. moduix construit ce composant avec l’[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) officielle, conformément aux recommandations d’Ark sur la [composition](https://ark-ui.com/docs/guides/composition), les [styles](https://ark-ui.com/docs/guides/styling) et les [refs](https://ark-ui.com/docs/guides/ref).

## Anatomie

```text
Card.Root
├─ Card.Background (raccourci moduix facultatif)
├─ Card.Media (raccourci moduix facultatif)
├─ Card.Header
│  ├─ Card.Title
│  ├─ Card.Description
│  └─ Card.Action (raccourci moduix facultatif)
├─ Card.Body
└─ Card.Footer (facultatif)
```

`Card` et `Card.Root` désignent le même composant racine.

| Partie               | Rôle                                                                                                         |
| -------------------- | ------------------------------------------------------------------------------------------------------------ |
| `Card` / `Card.Root` | Conteneur racine avec les propriétés `size`, `variant` et `asChild`.                                         |
| `Card.Background`    | Couche plein fond facultative pour un média décoratif.                                                        |
| `Card.Media`         | Enveloppe facultative pour un média bord à bord avec un arrondi prévisible des angles supérieurs.            |
| `Card.Header`        | Dispose le titre, la description et une éventuelle action en fin de ligne.                                   |
| `Card.Body`          | Zone de contenu principale.                                                                                  |
| `Card.Footer`        | Ligne portable d’actions ou de métadonnées.                                                                  |
| `Card.Title`         | Partie de titre. Rend un `h3` par défaut ; utilisez `asChild` pour choisir un autre niveau.                   |
| `Card.Description`   | Texte complémentaire.                                                                                        |
| `Card.Action`        | Slot moduix destiné à disposer une action dans l’en-tête.                                                    |
| `Card.Link`          | Lien étendu moduix pour une carte de navigation qui contient également des actions distinctes.               |

## Composition

### Composition recommandée

Utilisez `<Card />`, `Card.Header`, `Card.Title`, `Card.Description`, `Card.Body` et `Card.Footer`.
Placez le média initial dans `Card.Media` lorsqu’il doit atteindre les bords de la carte sans nécessiter son propre rognage.
Utilisez `Card.Background` pour une image décorative derrière toute la carte ; ajoutez le traitement de
contraste dans les styles de votre application.
Par défaut, le composant racine utilise `size="md"` et `variant="outline"`.

### Quand créer une composition personnalisée

Utilisez `asChild` lorsque l’unique enfant sémantique doit posséder le nœud DOM d’une partie. La composition Ark
exige exactement un enfant. Un élément racine qui est un lien ne doit pas contenir de boutons, de champs de saisie ni d’autres liens imbriqués.

Utilisez `Card.Link` dans l’en-tête lorsque la carte doit être cliquable sur toute sa surface tout en contenant
des contrôles indépendants. `Card.Link` applique le motif du lien étendu : le lien visible reste dans l’en-tête,
mais sa zone cliquable s’étend à toute la carte sans recouvrir les éléments interactifs distincts.
`Card.Action` ne gère que la disposition et ne crée aucune relation ARIA.

| Situation                                                                                                  | API recommandée                                                    |
| ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| La carte entière est un lien unique et ne contient aucun contrôle imbriqué.                                | `Card asChild` avec un élément racine `<a>`                         |
| La carte ouvre une page, mais contient aussi des boutons, menus ou autres actions indépendantes.           | `Card.Link` dans `Card.Title`, avec `Card.Action` si nécessaire     |
| La carte sert uniquement à regrouper du contenu, sans navigation.                                          | Composition `Card` ordinaire sans lien étendu                       |

### Propriétés par défaut

| Partie      | Propriété  | Valeur par défaut | Valeurs                               |
| ----------- | ---------- | ----------------- | ------------------------------------- |
| `Card.Root` | `size`     | `'md'`            | `'sm' \| 'md' \| 'lg'`              |
| `Card.Root` | `variant`  | `'outline'`       | `'elevated' \| 'outline' \| 'subtle'` |

### Comportement

- Le composant racine rend par défaut un `div` de présentation et transmet la ref à l’élément rendu.
- Toutes les parties acceptent les propriétés natives, `className`, `style` et la propriété `asChild` de l’Ark factory.
- `Card.Media` est une enveloppe de commodité facultative. Ne l’utilisez pas si le média nécessite ses propres styles ou s’il n’apparaît pas au début de la carte.
- `Card.Background` est un raccourci facultatif pour un média décoratif sur toute la carte. Gardez
  `alt=""` pour cette image ; utilisez `Card.Media` lorsqu’elle requiert un texte alternatif.
- `Card.Title` rend un `h3` par défaut.
- Les racines interactives créées avec `asChild` et `Card.Link` reçoivent le même anneau `:focus-visible` personnalisable.
- Card ne gère ni état, ni callbacks, ni comportement clavier, ni provider, ni contexte, ni champ de saisie masqué.
- `Card.Body` réinitialise les marges externes du premier et du dernier enfant direct.
- `--moduix-card-spacing`, `--moduix-card-spacing-sm` et `--moduix-card-spacing-lg` contrôlent les espacements intérieurs communs et l’écart entre les sections, sans remplacer les redéfinitions `--moduix-card-*` plus ciblées.

### Points d’accroche CSS

- Chaque partie fournit `data-scope="card"` et le `data-part` correspondant.
- Hooks moduix stables : `data-slot="card-root"`, `card-background`, `card-media`, `card-header`, `card-body`,
  `card-footer`, `card-title`, `card-description`, `card-action` et `card-link`.
- Le composant racine fournit `data-size="sm | md | lg"` et
  `data-variant="elevated | outline | subtle"`.
- Les redéfinitions globales `--moduix-card-bg`, `--moduix-card-color`, `--moduix-card-border-*` et
  `--moduix-card-shadow` ont priorité sur les variables correspondantes propres à chaque variante.
- Card ne possède aucun attribut d’état interactif, car il ne gère ni état ni comportement.
