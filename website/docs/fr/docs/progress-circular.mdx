## Choisir le bon composant

Utilisez `ProgressCircular` pour afficher un état compact dans du contenu en ligne, des cartes, des badges de barre d’outils ou de petits tableaux de bord. Préférez `ProgressLinear` lorsque l’utilisateur doit comparer la progression à une piste horizontale.

## Exemple de base

Utilisez `ProgressCircular.Ring` pour le cercle SVG standard, sa piste et son arc de progression. Ajoutez `ProgressCircular.ValueText` si la valeur actuelle doit être visible. Dans cet exemple, l’élément conteneur place la valeur au centre du cercle. Donnez à `Ring` un `aria-label` qui décrit la tâche et correspond au libellé visible.

## Anatomie

```text
ProgressCircular / ProgressCircular.Root
├─ ProgressCircular.Label
├─ ProgressCircular.Circle
│  ├─ ProgressCircular.CircleTrack
│  └─ ProgressCircular.CircleRange
├─ ProgressCircular.Ring
│  └─ fixed Circle, CircleTrack, and CircleRange subtree
├─ ProgressCircular.ValueText
└─ ProgressCircular.View

ProgressCircular.RootProvider
└─ same part tree connected to ProgressCircular.useProgress()
```

| Partie                                        | Rôle                                                                       |
| --------------------------------------------- | -------------------------------------------------------------------------- |
| `ProgressCircular` / `ProgressCircular.Root`  | Gère l’état de progression, le formatage et les identifiants.                 |
| `ProgressCircular.RootProvider`               | Relie les parties à l’état créé par `ProgressCircular.useProgress()`.         |
| `ProgressCircular.Context`                    | Transmet l’état de progression courant à une fonction de rendu.               |
| `ProgressCircular.Label`                      | Ajoute un contexte visible à l’indicateur de progression.                     |
| `ProgressCircular.Ring`                       | Raccourci pratique pour le cercle, la piste et l’arc de progression par défaut. |
| `ProgressCircular.Circle`                     | Surface SVG de l’indicateur avec son rôle et ses attributs de valeur ARIA.    |
| `ProgressCircular.CircleTrack`                | Cercle d’arrière-plan.                                                        |
| `ProgressCircular.CircleRange`                | Cercle au premier plan représentant le pourcentage ou l’état courant.         |
| `ProgressCircular.ValueText`                  | Affiche la valeur formatée et annonce ses changements.                       |
| `ProgressCircular.View`                       | Affiche du contenu pour `indeterminate`, `loading` ou `complete`.             |

## Composition

### Composition recommandée

`ProgressCircular` est le composant racine abrégé, équivalent à `ProgressCircular.Root`. Utilisez `ProgressCircular.Ring` pour le cercle, la piste et l’arc de progression standard. Il accepte `className`, les propriétés ARIA et les mêmes variables CSS que `ProgressCircular.Circle`.

Utilisez `defaultValue` pour une progression non contrôlée. Utilisez `value` avec `onValueChange(details)` pour la contrôler. Définissez `defaultValue={null}` ou `value={null}` lorsque la fin de la tâche est inconnue.

### Quand créer une composition personnalisée

Utilisez `translations.value(details)` pour personnaliser le nom accessible généré par Ark lorsque `Ring` ou `Circle` n’a pas d’`aria-label` explicite. Pour afficher le même texte dans l’interface, affichez `ValueText` dans `ProgressCircular.Context` et transmettez `progress.valueAsString` comme enfant. Si la valeur doit apparaître au centre du cercle, enveloppez le cercle et le texte dans l’élément de mise en page de votre choix.

Utilisez `Circle`, `CircleTrack` et `CircleRange` lorsque vous devez modifier la structure SVG ou utiliser la composition Ark `asChild`. Utilisez `ids` lorsque le libellé, le cercle ou la mise en page environnante ont besoin d’identifiants explicites et stables dans un arbre personnalisé. Utilisez `ProgressCircular.useProgress()` avec `RootProvider` lorsqu’un autre composant doit créer ou contrôler l’état en dehors de l’arbre rendu. Utilisez `ProgressCircular.useProgressContext()` sous une racine ou un fournisseur lorsqu’un composant personnalisé doit accéder à l’état courant. Réservez les imports directs d’Ark aux intégrations qui ne peuvent pas utiliser l’API moduix.

### Propriétés par défaut

| Propriété       | Par défaut             | Notes                                                        |
| --------------- | ---------------------- | ------------------------------------------------------------ |
| `defaultValue`  | `50`                   | Valeur de départ d’une progression non contrôlée.              |
| `min`           | `0`                    | Minimum utilisé pour le pourcentage et la valeur ARIA.         |
| `max`           | `100`                  | Maximum utilisé pour le pourcentage et la valeur ARIA.         |
| `formatOptions` | `{ style: 'percent' }` | Options utilisées pour formater `ValueText`.                   |
| `locale`        | `'en-US'`              | Locale transmise à `Intl.NumberFormat`.                        |

### Comportement

`ProgressCircular.Circle` reçoit d’Ark le rôle d’indicateur de progression et les attributs ARIA de valeur. Donnez à `Ring` ou `Circle` un `aria-label` qui nomme la tâche. `ProgressCircular.Label` ajoute un contexte visible, mais n’associe pas automatiquement ce texte au cercle. Ark gère également les variables SVG de rayon, de circonférence, de pourcentage et de décalage du trait.

Toutes les parties fournies par Ark, à l’exception de `Ring`, prennent en charge `asChild` via la composition polymorphe. Les enfants de remplacement doivent rester sémantiques et conserver la sémantique de l’indicateur de progression sur le cercle.

`ProgressCircular.ValueText` annonce les changements avec `aria-live="polite"`. Conservez un libellé visible dans l’arbre ou fournissez `aria-label`/`aria-labelledby` lorsque la composition n’inclut pas `ProgressCircular.Label`.

## Styles

Utilisez `className` sur les parties exportées pour les changements structurels de style. Pour les styles qui dépendent de l’état, préférez les attributs de données Ark, les variables SVG Ark et les hooks `data-slot` de moduix.

Utilisez `--moduix-progress-circular-range-indeterminate-bg` pour donner à la progression indéterminée une couleur sémantique différente de celle de la progression déterminée. Lorsque l’utilisateur préfère réduire les animations, l’arc n’effectue ni transition ni rotation. Utilisez la variable du motif de tirets prévue pour ce mode afin de conserver un repère statique visible.

### Points d’accroche CSS

- `data-slot="progress-circular-root"`, `progress-circular-root-provider`, `progress-circular-label`, `progress-circular-circle`, `progress-circular-circle-track`, `progress-circular-circle-range`, `progress-circular-value-text` et `progress-circular-view`.
- `ProgressCircular.Ring` utilise les mêmes `data-slot`, `className`, ref et variables de taille et d’épaisseur `--moduix-progress-circular-*` que `ProgressCircular.Circle`.
- Hooks Ark : `data-scope="progress"`, `data-part`, `data-state="indeterminate|loading|complete"`, `data-orientation`, `data-value` et `data-max`.
- Variables de cercle Ark : `--size`, `--thickness`, `--radius`, `--circumference`, `--percent` et `--offset`.
