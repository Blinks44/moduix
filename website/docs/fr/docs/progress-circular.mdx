## Choisir le bon composant

Utilisez `ProgressCircular` pour afficher une indication compacte de l’avancement dans un texte,
des cartes, des badges de barre d’outils et de petits tableaux de bord. Choisissez `ProgressLinear`
lorsque la progression se compare plus facilement sur une barre horizontale.

## Exemple de base

Utilisez `ProgressCircular.Ring` pour afficher le cercle SVG standard, sa piste et son arc de
progression. Ajoutez `ProgressCircular.ValueText` pour afficher la valeur actuelle. L’exemple place
ce texte au centre du cercle grâce à un conteneur externe. Donnez à `Ring` un `aria-label` qui
identifie la tâche et correspond au libellé visible.

## Anatomie

```text
ProgressCircular / ProgressCircular.Root
├─ ProgressCircular.Label
├─ ProgressCircular.Circle
│  ├─ ProgressCircular.CircleTrack
│  └─ ProgressCircular.CircleRange
├─ ProgressCircular.Ring
│  └─ fixed Circle, CircleTrack, and CircleRange subtree
├─ ProgressCircular.ValueText
└─ ProgressCircular.View

ProgressCircular.RootProvider
└─ same part tree connected to ProgressCircular.useProgress()
```

| Partie                                        | Rôle                                                                                |
| --------------------------------------------- | ----------------------------------------------------------------------------------- |
| `ProgressCircular` / `ProgressCircular.Root`  | Gère l’état de progression, le formatage et les identifiants générés.                |
| `ProgressCircular.RootProvider`               | Relie les parties à l’état créé par `ProgressCircular.useProgress()`.                |
| `ProgressCircular.Context`                    | Expose l’état de progression courant via une fonction de rendu.                      |
| `ProgressCircular.Label`                      | Fournit le contexte visible de l’indicateur de progression.                          |
| `ProgressCircular.Ring`                       | Partie pratique qui rend le cercle, la piste et l’arc par défaut.                    |
| `ProgressCircular.Circle`                     | Élément SVG auquel Ark ajoute le rôle et les attributs ARIA de valeur.               |
| `ProgressCircular.CircleTrack`                | Cercle d’arrière-plan.                                                               |
| `ProgressCircular.CircleRange`                | Arc au premier plan qui reflète la progression actuelle ou l’état indéterminé.       |
| `ProgressCircular.ValueText`                  | Affiche la valeur formatée et annonce les mises à jour.                             |
| `ProgressCircular.View`                       | Rend du contenu pour les états `indeterminate`, `loading` ou `complete`.             |

## Composition

### Composition recommandée

`ProgressCircular` est la forme abrégée de la racine et équivaut à `ProgressCircular.Root`. Pour le
cercle standard, utilisez `ProgressCircular.Ring` : il rend `Circle`, `CircleTrack` et
`CircleRange` pour vous. `Ring` accepte `className`, les propriétés ARIA et les mêmes variables CSS
que `Circle`.

Utilisez `defaultValue` pour une progression non contrôlée. Pour une progression contrôlée, utilisez
`value` avec `onValueChange(details)`. Définissez `defaultValue={null}` ou `value={null}` lorsque la
progression ne peut pas encore être mesurée.

### Quand créer une composition personnalisée

Utilisez `translations.value(details)` pour fournir à Ark un nom accessible propre à la tâche lorsque
`Ring` ou `Circle` n’a pas d’`aria-label` explicite. Cette option ne modifie que le nom accessible.
Pour afficher la même formulation dans l’interface, rendez `ValueText` dans
`ProgressCircular.Context` et transmettez-lui `progress.valueAsString` comme enfant. Pour centrer la
valeur, enveloppez le cercle et le texte dans l’élément de mise en page de votre choix.

Utilisez `Circle`, `CircleTrack` et `CircleRange` lorsque vous devez modifier l’arborescence SVG ou
recourir à la composition Ark `asChild`. Utilisez `ids` si une structure personnalisée a besoin
d’identifiants stables et explicites pour la racine, le libellé ou le cercle. Utilisez
`ProgressCircular.useProgress()` avec `RootProvider` lorsque l’état doit être créé en dehors de
l’arbre rendu ou partagé avec un autre composant. Utilisez
`ProgressCircular.useProgressContext()` sous une racine ou un fournisseur lorsqu’un composant
personnalisé doit accéder à l’état courant. Réservez les imports directs d’Ark aux intégrations qui
ne peuvent pas s’appuyer sur l’API moduix.

### Propriétés par défaut

| Propriété       | Par défaut             | Notes                                                            |
| --------------- | ---------------------- | ---------------------------------------------------------------- |
| `defaultValue`  | `50`                   | Valeur initiale en mode non contrôlé.                           |
| `min`           | `0`                    | Valeur minimale pour le pourcentage et les attributs ARIA.      |
| `max`           | `100`                  | Valeur maximale pour le pourcentage et les attributs ARIA.      |
| `formatOptions` | `{ style: 'percent' }` | Définit le formatage de `ValueText`.                            |
| `locale`        | `'en-US'`              | Paramètres régionaux utilisés par `Intl.NumberFormat`.          |
| `orientation`   | `'horizontal'`         | Orientation Ark. Pour un cercle, laissez généralement `horizontal`. |

### Comportement

`ProgressCircular.Circle` reçoit d’Ark le rôle `progressbar` et les attributs ARIA de valeur.
`ProgressCircular.Label` fournit un contexte visible, mais ne donne pas automatiquement de nom
accessible au cercle. Donnez à `Ring` ou `Circle` un `aria-label` ou un `aria-labelledby` qui
identifie la tâche. Ark définit également les variables SVG du rayon, de la circonférence, du
pourcentage et du décalage du trait.

Toutes les parties Ark exportées, à l’exception de `Ring`, prennent en charge `asChild` via la
composition polymorphe. Si vous remplacez l’élément rendu, préservez sa sémantique et le rôle
`progressbar` du cercle.

`ProgressCircular.ValueText` annonce les changements avec `aria-live="polite"`. Conservez un libellé
visible dans l’arbre ou fournissez `aria-label` ou `aria-labelledby` lorsque la composition
n’inclut pas `ProgressCircular.Label`.

## Styles

Utilisez `className` sur les parties exportées pour modifier la structure et l’apparence. Pour les
styles dépendants de l’état, préférez les attributs de données Ark, les variables SVG Ark et les
points d’accroche `data-slot` de moduix.

Utilisez `--moduix-progress-circular-range-indeterminate-bg` pour donner à la progression
indéterminée une couleur sémantique distincte. Lorsque l’utilisateur préfère réduire les animations,
l’arc n’effectue ni transition ni rotation. Utilisez
`--moduix-progress-circular-range-indeterminate-reduced-motion-dasharray` pour conserver un repère
statique visible.

### Points d’accroche CSS

- `data-slot="progress-circular-root"`, `data-slot="progress-circular-root-provider"`,
  `data-slot="progress-circular-label"`, `data-slot="progress-circular-circle"`,
  `data-slot="progress-circular-circle-track"`, `data-slot="progress-circular-circle-range"`,
  `data-slot="progress-circular-value-text"` et `data-slot="progress-circular-view"`.
- `ProgressCircular.Ring` utilise les mêmes `data-slot`, `className`, ref et variables de taille et
  d’épaisseur `--moduix-progress-circular-*` que `ProgressCircular.Circle`.
- Attributs Ark : `data-scope="progress"`, `data-part`, `data-state="indeterminate|loading|complete"`,
  `data-orientation`, `data-value` et `data-max`.
- Variables SVG Ark du cercle : `--size`, `--thickness`, `--radius`, `--circumference`, `--percent`
  et `--offset`.
