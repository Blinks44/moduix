# De droite à gauche (RTL)

Une interface RTL demande deux réglages coordonnés : les attributs natifs `lang` et `dir` pour le
navigateur, et le `LocaleProvider` de Moduix pour le comportement localisé d’Ark. Placez-les au niveau
le plus élevé qui porte la langue.

## Configurer le document

Pour toute l’application, définissez `lang` et `dir` sur `<html>` :

```html
<html lang="ar" dir="rtl"></html>
```

Entourez l’application avec le provider de son adaptateur natif :

<Tabs groupId="framework">
  <Tab label="React" value="react">

```tsx
import { LocaleProvider } from '@moduix/react/locale';

<LocaleProvider locale="ar-EG">{children}</LocaleProvider>;
```

  </Tab>
  <Tab label="Solid" value="solid">

```tsx
import { LocaleProvider } from '@moduix/solid/locale';

<LocaleProvider locale="ar-EG">{props.children}</LocaleProvider>;
```

  </Tab>
</Tabs>

`LocaleProvider` déduit la direction d’Ark à partir de la locale, mais ne modifie pas les attributs
natifs. Si la langue change sans rechargement, mettez à jour `lang`, `dir` et la locale du provider
ensemble.

## Limiter le RTL à une section

Pour une zone RTL dans une application LTR, placez `lang` et `dir` sur sa racine et entourez les
composants Moduix avec `LocaleProvider`.

  </Tab>
  <Tab label="Solid" value="solid">

La collection vient de l’adaptateur Ark UI correspondant. Select, Button et LocaleProvider viennent
de l’adaptateur Moduix correspondant. Aucun prop RTL supplémentaire n’est nécessaire.

## Gérer les portails et les directions mixtes

Un contenu rendu dans un portail hérite de la direction CSS de son conteneur de destination, pas de
son déclencheur. Utilisez la direction du document pour toute l’application ou placez un conteneur de
portail dans le sous-arbre RTL.

Pour un contenu mixte :

- utilisez `dir="auto"` lorsque la direction du texte est inconnue ;
- utilisez `dir="ltr"` pour les adresses e-mail, URL, codes et numéros de téléphone ;
- gardez la direction de l’application sur le conteneur extérieur.

## Utiliser les propriétés logiques

Préférez les propriétés logiques lorsqu’une règle suit le sens de lecture :

```css
.item {
  padding-inline: var(--moduix-spacing-4);
  border-inline-start: var(--moduix-border-width-sm) solid var(--moduix-color-border);
  text-align: start;
}
```

Conservez `left` et `right` pour la géométrie physique, comme une coordonnée mesurée, une poignée de
redimensionnement ou la direction explicite d’un geste. Inversez les icônes directionnelles, mais pas
les icônes de lecture, de validation, de téléchargement ni les logos.

## Vérifier le RTL avant publication

- Les champs avec bouton d’effacement ou action secondaire.
- Les déclencheurs de Select, Combobox et Date Picker.
- Les contenus de Dialog, Popover, Menu et Tooltip rendus dans un portail.
- La navigation au clavier et l’ordre visible du focus.
- Le texte arabe ou hébreu mélangé avec des adresses, nombres et codes.
- Les icônes directionnelles, gestes et alignements sur écran étroit.
