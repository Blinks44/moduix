## Anatomie

```text
NumberInput.Root
├─ NumberInput.Label
├─ NumberInput.Scrubber (facultatif)
├─ NumberInput.Field (recommandé)
├─ NumberInput.Control
│  ├─ NumberInput.DecrementTrigger
│  ├─ NumberInput.Input
│  └─ NumberInput.IncrementTrigger
└─ NumberInput.ValueText (facultatif)

NumberInput.RootProvider
└─ même arborescence reliée à l’état créé avec `useNumberInput()`
```

| Partie                             | Rôle                                                                         |
| ---------------------------------- | ---------------------------------------------------------------------------- |
| `NumberInput` / `NumberInput.Root` | Gère l’état du champ numérique, l’interprétation de la saisie, le formatage et le comportement au clavier. |
| `NumberInput.RootProvider`         | Relie les parties à l’état créé avec `useNumberInput()`.                    |
| `NumberInput.Context`              | Expose la valeur formatée, sa représentation numérique et les méthodes permettant de manipuler l’état. |
| `NumberInput.Label`                | Libellé accessible associé au champ géré.                                   |
| `NumberInput.Scrubber`             | Zone de glissement facultative qui modifie la valeur selon le déplacement du pointeur. |
| `NumberInput.Control`              | Conteneur structurel du champ et des boutons d’incrémentation et de décrémentation. |
| `NumberInput.Field`                | Affiche la structure standard avec le contrôle, le champ et les boutons.    |
| `NumberInput.DecrementTrigger`     | Bouton qui diminue la valeur actuelle. Affiche par défaut l’icône moins de moduix. |
| `NumberInput.Input`                | Champ de texte numérique modifiable géré par Ark UI.                         |
| `NumberInput.IncrementTrigger`     | Bouton qui augmente la valeur actuelle. Affiche par défaut l’icône plus de moduix. |
| `NumberInput.ValueText`            | Texte en lecture seule qui affiche la valeur formatée.                      |

## Composition

### Composition recommandée

`NumberInput` gère l’interprétation de la saisie, les limites de la plage, l’incrémentation et la décrémentation au clavier,
la répétition lorsqu’un bouton est maintenu, la modification par glissement et le formatage. Activez `allowMouseWheel`
lorsque la molette doit modifier la valeur dans votre cas d’utilisation. Utilisez `NumberInput.Field` pour afficher
les parties standard.

Utilisez des chaînes de caractères pour `value` et `defaultValue`. Ark signale les modifications avec
`onValueChange(details)`, où `details.value` est la valeur sous forme de chaîne et `details.valueAsNumber` le nombre obtenu après conversion.

### Quand utiliser une composition personnalisée

Utilisez `NumberInput.Control` avec ses parties individuelles lorsque l’ordre des boutons, les icônes ou les styles
du champ doivent différer de `NumberInput.Field`. Ajoutez `NumberInput.Scrubber` à côté du champ pour permettre une
modification par glissement.

### Propriétés par défaut

| Propriété                          | Valeur par défaut | Remarques                                                        |
| ---------------------------------- | ----------------- | ---------------------------------------------------------------- |
| `NumberInput` / `NumberInput.Root` | -                 | Aucun comportement supplémentaire. Les valeurs par défaut d’Ark s’appliquent. |
| `NumberInput.Field`                | -                 | Affiche la structure standard avec le contrôle, le champ et les boutons. |
| `NumberInput.DecrementTrigger`     | -                 | Affiche l’icône moins de moduix lorsqu’aucun enfant n’est fourni. |
| `NumberInput.IncrementTrigger`     | -                 | Affiche l’icône plus de moduix lorsqu’aucun enfant n’est fourni.  |

### Comportement

- Pour formater les nombres selon la langue, utilisez `formatOptions` et non `format`.
- Utilisez `translations.incrementLabel`, `translations.decrementLabel` et `translations.valueText` pour fournir des libellés accessibles dans la langue de l’interface.
- `min`, `max`, `step`, `allowOverflow`, `clampValueOnBlur`, `spinOnPress`, `inputMode` et `allowMouseWheel` sont transmis directement à Ark.
- `onValueInvalid(details)` signale `rangeUnderflow` ou `rangeOverflow` lorsque la valeur dépasse les limites configurées.
- Définissez `clampValueOnBlur={false}` si les valeurs saisies hors de `min` ou `max` doivent rester inchangées à la perte du focus.
- Utilisez `ids` lorsque des libellés ou des descriptions externes ont besoin d’identifiants d’élément stables.
- Les parties fournies par Ark acceptent `asChild` pour composer un élément hôte personnalisé. `NumberInput.Field`
  rend volontairement une structure fixe en trois parties et transmet sa référence à `NumberInput.Control`.
- `useNumberInput`, `useNumberInputContext` et `NumberInput.Context` sont exportés par `@moduix/react`.
- `name` et `form` sont transmis au spinbutton visible pour la soumission par un formulaire natif.
  Rendez un champ natif masqué via `NumberInput.Context` avec `context.valueAsNumber` uniquement lorsque le formulaire
  attend la représentation numérique obtenue après conversion plutôt que la chaîne affichée.
