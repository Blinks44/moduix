## Anatomie

```text
NumberInput / NumberInput.Root
├─ NumberInput.Label
├─ NumberInput.Scrubber (facultatif)
├─ NumberInput.Field (raccourci recommandé)
│  └─ affiche NumberInput.Control
│     ├─ NumberInput.DecrementTrigger
│     ├─ NumberInput.Input
│     └─ NumberInput.IncrementTrigger
└─ NumberInput.ValueText (facultatif)

NumberInput.RootProvider
└─ même arborescence reliée à l’état créé avec `useNumberInput()`
```

| Partie | Rôle |
| --- | --- |
| `NumberInput` / `NumberInput.Root` | Gère l’état du champ numérique, l’interprétation de la saisie, le formatage et le comportement au clavier. |
| `NumberInput.RootProvider` | Relie les parties à l’état créé avec `useNumberInput()`. |
| `NumberInput.Context` | Expose les valeurs formatée et numérique, ainsi que les méthodes impératives de gestion de l’état. |
| `NumberInput.Label` | Libellé accessible associé au champ géré. |
| `NumberInput.Scrubber` | Zone de glissement facultative qui modifie la valeur selon le déplacement du pointeur. |
| `NumberInput.Control` | Regroupe le champ et les boutons d’incrémentation et de décrémentation. |
| `NumberInput.Field` | Partie pratique qui affiche le contrôle standard et le groupe de boutons. |
| `NumberInput.DecrementTrigger` | Bouton qui diminue la valeur actuelle. Il affiche par défaut l’icône moins de moduix. |
| `NumberInput.Input` | Champ de texte numérique modifiable géré par Ark UI. |
| `NumberInput.IncrementTrigger` | Bouton qui augmente la valeur actuelle. Il affiche par défaut l’icône plus de moduix. |
| `NumberInput.ValueText` | Texte en lecture seule qui affiche la valeur formatée. |

## Composition

Utilisez `NumberInput.Field` pour le contrôle standard en trois parties. Conservez `value` et `defaultValue` sous forme
de chaînes et utilisez `details.value` de `onValueChange` lorsque le champ est contrôlé. Lorsque l’état doit être créé
en dehors de l’arbre des parties rendues, appelez `useNumberInput()` et transmettez le store correspondant à
`NumberInput.RootProvider`. Ne rendez pas `NumberInput` ou `NumberInput.Root` pour ce même store. React lit directement
les propriétés du store, tandis que Solid les lit via l’accesseur renvoyé.

Utilisez `NumberInput.Control` avec les parties individuelles lorsque l’ordre des boutons, les icônes ou le style du
champ doit changer. Ajoutez `NumberInput.Scrubber` à côté du champ pour permettre la modification par glissement.
Utilisez `NumberInput.Context` uniquement lorsqu’un autre élément, par exemple un champ masqué de formulaire, a besoin
de la valeur formatée ou de `valueAsNumber`.

## Styles

Utilisez `className` dans React ou `class` dans Solid pour les styles structurels des parties exportées. Les variantes
Tailwind utilisent des utilitaires natifs et les classes du consommateur ; les variables CSS ci-dessous personnalisent
les variantes CSS Modules. Les attributs de données et les hooks `data-slot` sont partagés par les deux modes de style.

### Points d’accroche CSS

- Sélecteurs `data-slot` stables : `number-input-root`, `number-input-root-provider`, `number-input-label`,
  `number-input-scrubber`, `number-input-control`, `number-input-decrement-trigger`, `number-input-input`,
  `number-input-increment-trigger` et `number-input-value-text`.
- Attributs d’état Ark : `data-disabled`, `data-invalid`, `data-focus` et `data-scrubbing`.
- Attributs des parties Ark : `data-scope="number-input"` et valeurs de `data-part` correspondant à l’anatomie Ark.
