## Référence de l’API

Ark UI ne propose pas de composant `Text` dédié. moduix propose ce composant typographique, construit avec la
[fabrique Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) officielle, et suit les recommandations
d’Ark concernant la [composition](https://ark-ui.com/docs/guides/composition), les
[styles](https://ark-ui.com/docs/guides/styling) et les [refs](https://ark-ui.com/docs/guides/ref).

## Choisir le bon composant

Utilisez `Text` pour le texte courant et auxiliaire, l’emphase en ligne et les autres textes d’interface qui doivent
suivre l’échelle typographique de moduix.

- Choisissez **`Heading`** pour la structure du document et la hiérarchie des titres.
- Choisissez **`Text`** lorsque le contenu doit conserver la sémantique d’un paragraphe ou d’un texte en ligne tout en utilisant les styles du texte courant.
- Utilisez du CSS local lorsque le besoin concerne la mise en page du texte enrichi, l’espacement ou le dépliage d’un texte tronqué.

## Anatomie

`Text` rend un seul élément racine avec la fabrique Ark. Les écritures `<Text>` et `<Text.Root>` sont équivalentes.

```text
Text / Text.Root
└─ texte ou contenu en ligne
```

| Partie                | Rôle                                                                  |
| --------------------- | --------------------------------------------------------------------- |
| `Text` / `Text.Root` | Racine typographique avec sémantique HTML et attributs `data-*` stables. |

## Composition

### Composition recommandée

Utilisez la forme courte `<Text>` pour le texte courant et les libellés auxiliaires. Elle équivaut à `<Text.Root>`,
rend un élément `p` par défaut et transmet la `ref` à l’élément `HTMLElement` rendu.

### Quand créer une composition personnalisée

Utilisez `as` pour choisir une balise HTML prise en charge lorsque l’élément sémantique doit changer. Utilisez `asChild`
si un élément existant, par exemple un lien, doit devenir la racine et recevoir la classe moduix, le style, les attributs
de données et la `ref`. L’enfant doit être un élément unique capable d’accepter les propriétés transmises.

`Text` accepte également les attributs HTML habituels de l’élément rendu, notamment `className`, `style`, les
gestionnaires d’événements et une `ref` transmise.

### Propriétés par défaut

| Propriété   | Valeur par défaut                 | Remarques                                                            |
| ----------- | --------------------------------- | -------------------------------------------------------------------- |
| `as`        | `p`                               | `p`, `span`, `small`, `strong`, `em` ou `div`.                       |
| `asChild`   | `false`                           | Utilise l’unique élément enfant comme élément racine.                |
| `size`      | Selon l’élément                  | `sm` par défaut pour `small` ; `md` pour les autres éléments.        |
| `weight`    | Selon l’élément                  | `semibold` par défaut pour `strong` ; `regular` dans les autres cas. |
| `tone`      | `default`                         | `default`, `muted`, `subtle`, `primary` ou `destructive`.            |
| `align`     | Non défini (visuellement `start`) | `start`, `center`, `end`, `left`, `right` ou `justify`.              |
| `truncate`  | `false`                           | Troncature CSS sur une ligne avec points de suspension.              |
| `lineClamp` | Non défini                       | Entier positif ; les valeurs non valides désactivent la limitation.  |

### Comportement

`Text` s’occupe de la présentation et de la sémantique du texte. Il ne gère ni l’état, ni les interactions au clavier,
ni le dépliage. `truncate` et `lineClamp` appliquent uniquement des contraintes visuelles CSS. Ajoutez séparément un
bouton ou un autre contrôle si les utilisateurs doivent pouvoir afficher le texte complet.

### Points d’accroche CSS

- `data-scope="text"` et `data-part="root"` identifient la racine utilisée par Ark.
- `data-slot="text-root"` est le sélecteur moduix stable de la racine exportée.
- `data-size` reflète la taille visuelle calculée : `xs`, `sm`, `md`, `lg` ou `xl`.
- `data-weight` reflète la graisse calculée : `regular`, `medium`, `semibold` ou `bold`.
- `data-tone` reflète la tonalité active : `default`, `muted`, `subtle`, `primary` ou `destructive`.
- `data-align` apparaît uniquement lorsque `align` vaut explicitement `start`, `center`, `end`, `left`, `right` ou `justify`.
- `data-truncate` apparaît lorsque la troncature sur une ligne avec points de suspension est active.
- `data-line-clamp` apparaît lorsque `lineClamp` est un entier positif. Dans ce cas, `lineClamp` définit le nombre de
  lignes utilisé par défaut. Définissez `--moduix-text-line-clamp` pour remplacer cette valeur via l’API CSS publique.
