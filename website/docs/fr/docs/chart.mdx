## Référence de l’API

Ark UI ne propose pas de primitive dédiée aux graphiques. moduix ajoute une structure sémantique
`figure`, un titre, une description, une légende et un corps d’info-bulle compact autour de l’[API
des graphiques TanStack Charts](https://tanstack.com/charts/latest/docs/framework/react/reference/chart).
Définissez les éléments graphiques, les échelles, les interactions et les callbacks avec TanStack
Charts ; moduix fournit la composition accessible qui les entoure.

`@tanstack/charts` est une dépendance peer facultative de moduix. Les paquets React et Solid
exposent la même API de définition des graphiques ; le paquet Solid utilise l’adaptateur de rendu de
TanStack.

## Anatomie

```text
Chart / Chart.Root
├─ Chart.Header (figcaption facultatif)
│  ├─ Chart.Title
│  └─ Chart.Description
├─ Chart.Plot
│  └─ zone de rendu TanStack (SVG par défaut)
└─ Chart.Legend (facultatif)
   └─ Chart.LegendItem
```

| Partie | Rôle |
| --- | --- |
| `Chart` / `Chart.Root` | Racine `figure` composée. Accepte les propriétés natives, `asChild` et une ref `HTMLElement`. |
| `Chart.Plot` | Hôte TanStack Charts. Nécessite `definition` et `ariaLabel`, utilise le préréglage d’animation moduix par défaut et accepte `motion={false}`. |
| `Chart.Header` | Structure `figcaption` du titre et de la description. |
| `Chart.Title` | Titre du graphique, rendu dans un `h3` par défaut. |
| `Chart.Description` | Explication visible qui accompagne le graphique. |
| `Chart.Legend` | Liste sémantique des séries visibles. |
| `Chart.LegendItem` | Élément de légende avec un `color` facultatif pour l’indicateur. |

## Composition

`Chart` est une enveloppe de présentation. La `definition` de TanStack possède les éléments
graphiques, les échelles, les interactions et les callbacks : gardez-la au niveau du module ou
mémoïsez-la entièrement lorsqu’elle dépend de props ou d’un état. Composez `Chart.Header`,
`Chart.Plot` et `Chart.Legend` sous la racine ; `Chart.Plot` continue de confier à TanStack le rendu,
le focus et l’état de l’info-bulle.

Utilisez `renderTooltipBody` uniquement pour envelopper ou étendre l’info-bulle native : rendez le
`defaultBody` fourni et n’ajoutez des contrôles interactifs que lorsque `pinned` vaut true. `Chart.Root`
et `Chart.Header` acceptent `asChild` lorsque l’élément sémantique ou la mise en page doivent être
contrôlés par l’application.

### Personnalisation avancée

## Styles

Stylisez la figure avec `Chart.Root` et l’hôte TanStack avec `Chart.Plot`. Les propriétés CSS
publiques contrôlent la surface, l’anneau de focus, l’enveloppe de l’info-bulle et sa mise en page
par défaut. Gardez la géométrie du graphique dans la définition TanStack, via les options des
éléments, les échelles et les canaux de couleur.

Les variantes Tailwind utilisent les utilitaires natifs et les classes de l’application ; les
propriétés CSS ci-dessous personnalisent les variantes CSS Modules. Les attributs de données et les
sélecteurs `data-slot` sont communs aux deux modes de style.

Ajoutez une classe locale (`className` en React ou `class` en Solid) lorsque le graphique nécessite
des remplacements locaux :

```css
.sales-chart {
  --moduix-chart-tooltip-bg: var(--moduix-color-card);
  --moduix-chart-tooltip-font-size: var(--moduix-text-sm);
  --moduix-chart-tooltip-line-height: var(--moduix-line-height-text-sm);
}
```

### Points d’accroche CSS

- `Chart.Root`, `Chart.Header`, `Chart.Title`, `Chart.Description`, `Chart.Legend` et
  `Chart.LegendItem` exposent `data-scope="chart"`, `data-part` et `data-slot`.
- `className` en React et `class` en Solid sur `Chart.Plot` atteignent l’élément externe `.ts-chart-host`.
- L’info-bulle par défaut utilise les slots `chart-tooltip-body`, `chart-tooltip-title`,
  `chart-tooltip-rows`, `chart-tooltip-row`, `chart-tooltip-swatch`, `chart-tooltip-label`,
  `chart-tooltip-value` et `chart-tooltip-text`.
- Utilisez `--moduix-color-chart-1` à `--moduix-color-chart-5` dans les échelles de couleurs TanStack.
- L’enveloppe de l’info-bulle se style avec les variables documentées `--ts-chart-tooltip-*`,
  associées aux propriétés moduix. Utilisez `tooltip.className` pour vos sélecteurs CSS, ou
  `renderTooltipBody` lorsque vous avez besoin d’un contenu personnalisé et du `defaultBody` natif.
