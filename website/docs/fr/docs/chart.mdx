## Référence de l’API

Ark UI ne propose pas de composant de graphique. moduix apporte la figure, le titre, la légende et
l’info-bulle autour du [composant React de TanStack Charts](https://tanstack.com/charts/latest/docs/framework/react/reference/chart).
Les éléments graphiques, échelles, interactions et callbacks restent définis avec TanStack Charts.
TanStack Charts 0.14 nécessite React 19.

## Exemple de base

Créez une définition TanStack et transmettez-la à `Chart.Plot`. Ajoutez le titre, la description et
la légende autour du graphique, puis donnez-lui un `ariaLabel` concis pour les personnes qui utilisent
des technologies d’assistance.

## Anatomie

```text
Chart / Chart.Root
├─ Chart.Header (figcaption facultatif)
│  ├─ Chart.Title
│  └─ Chart.Description
├─ Chart.Plot
│  └─ surface TanStack (SVG par défaut)
└─ Chart.Legend (facultatif)
   └─ Chart.LegendItem
```

| Partie | Rôle |
| --- | --- |
| `Chart` / `Chart.Root` | Élément racine `figure`. Accepte les propriétés natives, `asChild` et une ref `HTMLElement`. |
| `Chart.Plot` | Composant React TanStack. Nécessite `definition` et `ariaLabel` ; utilise le préréglage d’animation Moduix par défaut, que `motion={false}` désactive. |
| `Chart.Header` | Élément `figcaption` qui contient le titre et la description. |
| `Chart.Title` | Titre du graphique, rendu dans un `h3` par défaut. |
| `Chart.Description` | Explication visible qui accompagne le graphique. |
| `Chart.Legend` | Liste sémantique des séries visibles. |
| `Chart.LegendItem` | Élément de légende avec un `color` facultatif pour l’indicateur. |

## Composition

### Composition recommandée

Si votre définition TanStack ne change pas, déclarez-la hors du composant. Assemblez ensuite
`Chart.Header`, `Chart.Plot` et `Chart.Legend` dans le composant racine. Définissez directement
`barY`, `areaY`, `lineY`, `stack()`, les échelles, les guides et les canaux de couleur dans TanStack
Charts. moduix ne les remplace pas par des composants React.

L’échelle de couleur de la définition sert aux éléments graphiques comme aux pastilles de l’info-bulle.
Réutilisez les mêmes tokens moduix dans `Chart.LegendItem` pour que la légende reprenne les couleurs
du graphique.

### Choisir les éléments graphiques

`Chart.Plot` effectue le rendu, tandis que le contenu de la `definition` détermine la forme du
graphique. Toutes les variantes utilisent le même composant : `<Chart.Plot definition={definition} />`.

| Objectif | Éléments TanStack | Exemple |
| --- | --- | --- |
| Barres verticales | `barY` | Exemple de base, Barres empilées |
| Barres horizontales | `barX` | Barres horizontales |
| Courbe ou zone | `lineY`, `areaY` | Zone animée, Couleurs du graphique |
| Secteurs ou anneau | `pie`, `polar`, `radialArc` | Graphique en anneau |
| Nuage de points | `dot` | Nuage de points |
| Carte thermique | `cell` | Carte thermique |

### Personnaliser le rendu

`Chart.Plot` utilise le préréglage TanStack adaptatif `motion()` par défaut. Définissez
`motion={false}` pour un graphique SVG statique. Pour gérer les animations vous-même, transmettez un
autre moteur de rendu avec `renderer`. Un `renderer` défini explicitement est prioritaire sur
`motion`. Si votre application doit gérer directement la surface de rendu, utilisez le rendu Canvas
ou bas niveau de TanStack.

```tsx
<Chart.Plot definition={definition} ariaLabel="Monthly revenue" motion={false} />
```

Chart utilise une info-bulle Moduix compacte par défaut : les lignes sans pastille ne laissent pas de
colonne vide. Utilisez `renderTooltipBody` seulement pour ajouter du contenu React. Son callback
reçoit le `defaultBody` natif de TanStack avec le titre, les lignes, le formatage et les pastilles.
TanStack gère toujours l’ancrage, le positionnement, le portail, l’épinglage et la fermeture de
l’info-bulle. N’ajoutez des contrôles interactifs que si `pinned` vaut `true`.

### Propriétés par défaut

| Partie | Propriété | Par défaut | Notes |
| --- | --- | --- | --- |
| `Chart.Root` | élément | `figure` | `Chart.Header` est son `figcaption`. |
| `Chart.Plot` | `definition` | - | Définition TanStack requise. |
| `Chart.Plot` | `ariaLabel` | - | Nom accessible du graphique requis. |
| `Chart.Plot` | `motion` | `true` | Définissez `false` pour utiliser le renderer SVG statique de TanStack. |
| `Chart.Plot` | `renderer` | Préréglage d’animation Moduix | Anime la géométrie et l’info-bulle ; respecte la préférence de réduction des animations. |
| `Chart.Plot` | `height` | `320` | Utilisé lorsque `aspectRatio` est absent. |
| `Chart.Plot` | `width` | adaptative | S’adapte à la largeur du conteneur. |
| `Chart.Plot` | `initialWidth` | `640` | Largeur utilisée sur le serveur et avant la première mesure. |
| `Chart.Plot` | `tabIndex` | `0` | Conserve la navigation au clavier de TanStack dans l’ordre de tabulation. |

### Comportement

- Conservez une définition qui ne change pas au niveau du module. Si elle dépend de propriétés ou
  d’état, mémorisez-la entièrement avec `useMemo`.
- Le moteur de rendu par défaut anime la géométrie initiale, les mises à jour de données identifiées par une
  clé, les guides de focus et l’info-bulle native. Avec `prefers-reduced-motion: reduce`, les valeurs
  changent sans animation. `motion={false}` la désactive quelle que soit la préférence système.
- TanStack gère le focus au pointeur, la navigation par flèches, l’activation avec Entrée ou Espace,
  `onFocusChange` et `onSelect`.
- Le SVG du graphique reçoit l’anneau de focus moduix. Ne définissez pas `focusRing: false`, sauf si
  votre propre géométrie de focus remplace l’indicateur de point TanStack.
- Ajoutez `ariaDescription` si le titre et la description visibles n’expliquent pas suffisamment les données.
- `className` et `style` sur `Chart.Plot` ciblent l’élément externe de TanStack. Il n’expose pas de ref.

### Personnalisation avancée

Les composants créés par la factory Ark acceptent `asChild` et peuvent appliquer leurs styles aux
éléments sémantiques de votre mise en page. Dans cette section de tableau de bord, Chart fonctionne
avec Button : les éléments `figure` et `figcaption` sont remplacés par un `section` et un `header`
associés au titre, et la légende se trouve dans le `header`.

`Chart.Plot` reste le composant TanStack, et non un slot. Utilisez `className` et `style` sur son
élément externe, et `renderTooltipBody` pour enrichir l’info-bulle. Rendez `defaultBody` dans votre
propre conteneur : TanStack continue de le positionner et de le rendre dans un portail. N’ajoutez des
contrôles interactifs que dans une info-bulle épinglée.

## Styles

Stylisez la figure avec `Chart.Root` et l’élément TanStack avec `Chart.Plot`. Les propriétés CSS
publiques contrôlent la surface, l’anneau de focus, l’enveloppe de l’info-bulle et sa mise en page
par défaut. La géométrie du graphique reste dans la définition TanStack, avec les options des
éléments graphiques, les échelles et les canaux de couleur.

Attribuez une classe à la racine lorsqu’un graphique nécessite des ajustements locaux :

```tsx
<Chart className="sales-chart">...</Chart>
```

```css
.sales-chart {
  --moduix-chart-tooltip-bg: var(--moduix-color-card);
  --moduix-chart-tooltip-font-size: var(--moduix-text-sm);
  --moduix-chart-tooltip-line-height: var(--moduix-line-height-text-sm);
}
```

### Points d’accroche CSS

- `Chart.Root`, `Chart.Header`, `Chart.Title`, `Chart.Description`, `Chart.Legend`,
  et `Chart.LegendItem` exposent `data-scope="chart"`, `data-part` et `data-slot`.
- `className` sur `Chart.Plot` s’applique à l’élément externe `.ts-chart-host`.
- L’info-bulle par défaut utilise les slots de données `chart-tooltip-body`,
  `chart-tooltip-title`, `chart-tooltip-rows`, `chart-tooltip-row`, `chart-tooltip-swatch`,
  `chart-tooltip-label` et `chart-tooltip-value`.
- Utilisez `--moduix-color-chart-1` à `--moduix-color-chart-5` dans les échelles de couleur TanStack.
- L’enveloppe de l’info-bulle est stylisée par les variables documentées
  `--ts-chart-tooltip-*`, mappées depuis les propriétés Moduix. Utilisez `tooltip.className` de
  TanStack pour vos sélecteurs CSS, ou `renderTooltipBody` lorsque vous devez ajouter du contenu
  React au `defaultBody` natif.
