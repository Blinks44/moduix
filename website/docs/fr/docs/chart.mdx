## Référence de l’API

Ark UI ne fournit pas de primitif de graphique. moduix combine des parties Ark factory avec
l’[hôte React TanStack Charts](https://tanstack.com/charts/latest/docs/framework/react/reference/chart),
en conservant les définitions, marques, échelles, interactions et callbacks TanStack indépendants
du framework. TanStack Charts 0.14 nécessite React 19.

## Exemple de base

Créez une définition avec TanStack Charts, puis affichez-la dans `Chart.Plot`. Conservez le titre,
la description et la légende visibles dans la composition racine, et donnez au tracé un
`ariaLabel` concis.

## Anatomie

```text
Chart / Chart.Root
├─ Chart.Header (figcaption facultatif)
│  ├─ Chart.Title
│  └─ Chart.Description
├─ Chart.Plot
│  └─ surface TanStack (SVG par défaut)
└─ Chart.Legend (facultatif)
   └─ Chart.LegendItem

Chart.TooltipContent (dans renderTooltipBody)
```

| Partie | Rôle |
| --- | --- |
| `Chart` / `Chart.Root` | Surface `figure` composée. Accepte les props natives, `asChild` et une ref `HTMLElement`. |
| `Chart.Plot` | Hôte React TanStack. Nécessite `definition` et `ariaLabel` ; utilise par défaut le preset d’animation Moduix et accepte `motion={false}`. |
| `Chart.Header` | Mise en page `figcaption` pour le titre et la description. |
| `Chart.Title` | Titre du graphique ; rend un `h3` par défaut. |
| `Chart.Description` | Contexte visible complémentaire. |
| `Chart.Legend` | Liste sémantique des séries visibles. |
| `Chart.LegendItem` | Élément de légende avec un `color` facultatif pour l’indicateur. |
| `Chart.TooltipContent` | Mise en page du contenu React renvoyé par `renderTooltipBody`. |

## Composition

### Composition recommandée

Conservez une définition TanStack stable hors du composant, puis composez `Chart.Header`,
`Chart.Plot` et `Chart.Legend` dans la racine appelable. Utilisez directement `barY`, `areaY`,
`lineY`, l’empilement, les échelles, les guides et les canaux de couleur TanStack ; moduix ne les
duplique pas sous forme de parties React.

Utilisez l’échelle de couleur de la définition pour les marques et les indicateurs de l’info-bulle.
Réutilisez les tokens de couleur moduix correspondants dans `Chart.LegendItem` afin d’aligner la
légende visible sur le graphique.

### Choisir les marques

`Chart.Plot` est l’hôte du renderer, tandis que les marques de la `definition` déterminent le
résultat. Toutes les variantes utilisent la même composition
`<Chart.Plot definition={definition} />`.

| Objectif | Marques | Exemple |
| --- | --- | --- |
| Barres verticales | `barY` | Exemple de base, Barres empilées |
| Barres horizontales | `barX` | Barres horizontales |
| Courbe ou zone | `lineY`, `areaY` | Zone animée, Couleurs du graphique |
| Secteurs ou anneau | `pie`, `polar`, `radialArc` | Graphique en anneau |
| Nuage de points | `dot` | Nuage de points |
| Carte thermique | `cell` | Carte thermique |

### Quand créer une composition personnalisée

`Chart.Plot` utilise par défaut un preset réactif de TanStack `motion()`. Définissez `motion={false}`
pour un graphique SVG entièrement statique, ou transmettez un autre `renderer` pour une politique
d’animation personnalisée. Un `renderer` explicite est prioritaire sur `motion`. Utilisez directement
les entrées canvas ou renderer bas niveau de TanStack lorsque l’application possède elle-même la surface.

```tsx
<Chart.Plot definition={definition} ariaLabel="Monthly revenue" motion={false} />
```

Lors de la personnalisation de l’info-bulle, conservez `defaultBody` dans `Chart.TooltipContent`.
TanStack reste responsable de l’ancre, du positionnement, du portalling, de l’état épinglé et de la
fermeture. Ne rendez les contrôles interactifs que lorsque `pinned` vaut `true`.

### Propriétés par défaut

| Partie | Propriété | Par défaut | Notes |
| --- | --- | --- | --- |
| `Chart.Root` | élément | `figure` | `Chart.Header` est son `figcaption`. |
| `Chart.Plot` | `definition` | - | Définition TanStack requise. |
| `Chart.Plot` | `ariaLabel` | - | Nom accessible du graphique requis. |
| `Chart.Plot` | `motion` | `true` | Définissez `false` pour utiliser le renderer SVG statique de TanStack. |
| `Chart.Plot` | `renderer` | Preset d’animation Moduix | Anime la géométrie et l’info-bulle ; respecte la réduction des animations. |
| `Chart.Plot` | `height` | `320` | Utilisé lorsque `aspectRatio` est absent. |
| `Chart.Plot` | `width` | responsive | Suit la largeur de l’hôte. |
| `Chart.Plot` | `initialWidth` | `640` | Largeur sur le serveur et avant la mesure. |
| `Chart.Plot` | `tabIndex` | `0` | Maintient la navigation clavier TanStack dans l’ordre de tabulation. |

### Comportement

- Conservez une définition statique au niveau du module. Lorsqu’elle capture des props ou du state,
  mémorisez la définition complète avec `useMemo`.
- Le renderer de mouvement par défaut anime la géométrie initiale, les mises à jour de données avec
  clés, les guides de focus et l’info-bulle native. Il applique immédiatement les valeurs lorsque
  `prefers-reduced-motion: reduce` correspond ; `motion={false}` désactive l’animation indépendamment
  des préférences multimédias de l’utilisateur.
- Le focus du pointeur, la navigation par flèches, l’activation avec Entrée/Espace,
  `onFocusChange` et `onSelect` restent gérés par TanStack.
- Le SVG focalisable du tracé utilise l’anneau de focus moduix. Ne définissez pas
  `focusRing: false` sauf si une géométrie de focus personnalisée remplace l’indicateur TanStack.
- `ariaDescription` ajoute des détails lorsque le titre et la description visibles ne suffisent pas.
- `className` et `style` sur `Chart.Plot` ciblent l’hôte TanStack externe. L’hôte n’a pas d’API de ref.

## Styles

Stylisez la figure avec `Chart.Root` et l’hôte TanStack avec `Chart.Plot`. Les propriétés CSS
publiques contrôlent la surface, l’anneau de focus, l’enveloppe et les lignes par défaut de
l’info-bulle. La géométrie reste dans la définition TanStack via les options des marques, les
échelles et les canaux de couleur.

Attribuez une classe à la racine lorsqu’un graphique nécessite des ajustements locaux :

```tsx
<Chart className="sales-chart">...</Chart>
```

```css
.sales-chart {
  --moduix-chart-tooltip-bg: var(--moduix-color-card);
  --moduix-chart-tooltip-column-gap: var(--moduix-spacing-3);
  --moduix-chart-tooltip-font-size: var(--moduix-text-sm);
  --moduix-chart-tooltip-label-color: var(--moduix-color-foreground);
  --moduix-chart-tooltip-line-height: var(--moduix-line-height-text-sm);
}

.sales-chart [data-slot='chart-tooltip-value'] {
  font-weight: var(--moduix-weight-bold);
}
```

### Points d’accroche CSS

- `Chart.Root`, `Chart.Header`, `Chart.Title`, `Chart.Description`, `Chart.Legend`,
  `Chart.LegendItem` et `Chart.TooltipContent` exposent `data-scope="chart"`, `data-part` et
  `data-slot`.
- `className` sur `Chart.Plot` atteint l’élément externe `.ts-chart-host`.
- L’info-bulle par défaut expose les data slots `chart-tooltip-body`, `chart-tooltip-title`,
  `chart-tooltip-rows`, `chart-tooltip-row`, `chart-tooltip-swatch`, `chart-tooltip-label` et
  `chart-tooltip-value`.
- Utilisez `--moduix-color-chart-1` à `--moduix-color-chart-5` dans les échelles de couleur TanStack.
- TanStack conserve le positionnement et les interactions de l’enveloppe ; le corps, possédé par
  Moduix, évite les surcharges de spécificité et se remplace entièrement avec `renderTooltipBody`.
