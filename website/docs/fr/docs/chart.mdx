## Référence de l’API

Ark UI ne propose pas de primitive dédiée aux graphiques. moduix ajoute une structure sémantique
`figure`, un titre, une description, une légende et un corps d’info-bulle compact autour de l’[API
des graphiques TanStack Charts](https://tanstack.com/charts/latest/docs/framework/react/reference/chart).
Définissez les éléments graphiques, les échelles, les interactions et les callbacks avec TanStack
Charts ; moduix fournit la composition accessible qui les entoure.

`@tanstack/charts` est une dépendance peer facultative de moduix. Les paquets React, Solid et Vue
exposent la même API de définition des graphiques ; les paquets Solid et Vue utilisent l’adaptateur
de rendu de TanStack.

## Exemple de base


Créez une définition TanStack et transmettez-la à `ChartPlot`. Ajoutez autour du graphique un
titre, une description et une légende visibles, puis définissez un `ariaLabel` concis pour les

## Anatomie

```text
Chart
├─ ChartHeader (figcaption facultatif)
│  ├─ ChartTitle
│  └─ ChartDescription
├─ ChartPlot
│  └─ zone de rendu TanStack (SVG par défaut)
└─ ChartLegend (facultatif)
   └─ ChartLegendItem
```

| Partie | Rôle |
| --- | --- |
| `Chart` | Racine `figure` composée. Accepte les propriétés natives, `asChild` et une ref `HTMLElement` (`$el` de la ref de composant en Vue). |
| `ChartPlot` | Hôte TanStack Charts. Nécessite `definition` et `ariaLabel`, utilise le préréglage d’animation moduix par défaut et accepte `motion={false}`. |
| `ChartHeader` | Structure `figcaption` du titre et de la description. |
| `ChartTitle` | Titre du graphique, rendu dans un `h3` par défaut. |
| `ChartDescription` | Explication visible qui accompagne le graphique. |
| `ChartLegend` | Liste sémantique des séries visibles. |
| `ChartLegendItem` | Élément de légende avec un `color` facultatif pour l’indicateur. |

## Composition

`Chart` est une enveloppe de présentation. La `definition` de TanStack possède les éléments
graphiques, les échelles, les interactions et les callbacks : gardez-la au niveau du module ou
mémoïsez-la entièrement lorsqu’elle dépend de props ou d’un état. Composez `ChartHeader`,
`ChartPlot` et `ChartLegend` sous la racine ; `ChartPlot` continue de confier à TanStack le rendu,
le focus et l’état de l’info-bulle.

Utilisez `renderTooltipBody` uniquement pour envelopper ou étendre l’info-bulle native : rendez le
`defaultBody` fourni et n’ajoutez des contrôles interactifs que lorsque `pinned` vaut true. `Chart`
et `ChartHeader` acceptent `asChild` lorsque l’élément sémantique ou la mise en page doivent être
contrôlés par l’application.

<Example name="chart/line-colors" />

### Légende interactive

Utilisez `interactiveColorLegend` de TanStack plutôt qu’un `ChartLegend` séparé pour permettre de
masquer des séries. Avec la v1, `hover: 'series'` applique aussi les états des éléments au survol
et au focus clavier. Les états avec `source: 'legend'` mettent la série en évidence sans ouvrir
d’info-bulle ni modifier le focus du graphique. Gardez les séries visibles dans l’état du framework
via `controlledSignal` ; TanStack gère les boutons, le filtrage et les interactions au clavier.

<Example name="chart/interactive-legend" />

### Graphique radar

Comparez les indicateurs sur une même échelle de 0 à 100 avec `radialLine` et une courbe D3 fermée.
Les graphiques radar existaient avant la v1 ; la nouveauté ici est `polar.states`, qui atténue les
points hors du focus. `focusGroupAngle` regroupe les deux produits par indicateur pour l’info-bulle
et la navigation au clavier.

### Personnalisation avancée

Les parties de la factory Ark acceptent `asChild` et peuvent donc appliquer leurs styles à des
éléments sémantiques de votre mise en page. Cet exemple de tableau de bord combine Chart et Button,
remplace `figure` et `figcaption` par un `section` et un `header` identifiés, puis place la légende
dans l’en-tête.

`ChartPlot` reste l’hôte TanStack, pas un slot. Utilisez `class` ou `className` et `style` sur
l’élément externe, et `renderTooltipBody` pour étendre l’info-bulle. Rendez `defaultBody` dans votre
propre enveloppe pendant que TanStack continue de gérer le positionnement et le portail. N’ajoutez
des contrôles interactifs que dans une info-bulle épinglée.

## Styles

Stylisez la figure avec `Chart` et l’hôte TanStack avec `ChartPlot`. Les propriétés CSS ci-dessous
contrôlent la surface de `Chart` et l’indicateur de légende. Gardez la géométrie du graphique dans la
définition TanStack, via les options des éléments, les échelles et les canaux de couleur.

Les variantes Tailwind utilisent les utilitaires natifs et les classes de l’application ; les
propriétés CSS ci-dessous personnalisent les variantes CSS Modules. Les deux modes de style
définissent les variables TanStack `--ts-chart-tooltip-*` sur l’hôte `ChartPlot`, et partagent les
attributs de données et les sélecteurs `data-slot`.

Pour modifier l’enveloppe de l’info-bulle, remplacez ces variables avec une classe sur `ChartPlot`
(`className` en React ou `class` en Solid et Vue) :

```css
.sales-plot {
  --ts-chart-tooltip-background: var(--moduix-color-card);
  --ts-chart-tooltip-font: var(--moduix-weight-medium) var(--moduix-text-sm) /
    var(--moduix-line-height-text-sm) var(--moduix-font-sans);
}
```

### Points d’accroche CSS

- `Chart`, `ChartHeader`, `ChartTitle`, `ChartDescription`, `ChartLegend` et
  `ChartLegendItem` exposent `data-scope="chart"`, `data-part` et `data-slot`.
- `className` en React et `class` en Solid et Vue sur `ChartPlot` atteignent l’élément externe `.ts-chart-host`.
- L’info-bulle par défaut utilise les slots `chart-tooltip-body`, `chart-tooltip-title`,
  `chart-tooltip-rows`, `chart-tooltip-row`, `chart-tooltip-swatch`, `chart-tooltip-label`,
  `chart-tooltip-value` et `chart-tooltip-text`.
- Utilisez `--moduix-color-chart-1` à `--moduix-color-chart-5` dans les échelles de couleurs TanStack.
- Les lignes de l’info-bulle que TanStack marque comme `active` reçoivent `data-active`.
- L’enveloppe de l’info-bulle lit les variables TanStack `--ts-chart-tooltip-*` sur l’hôte
  `ChartPlot`. Utilisez `tooltip.className` pour vos sélecteurs CSS, ou `renderTooltipBody` pour un
  contenu personnalisé autour du `defaultBody` de moduix.
