## Référence de l’API

Ark UI ne propose pas de primitive dédiée aux graphiques. moduix ajoute une structure `figure`, un
titre, une description, une légende et un corps d’info-bulle compact autour du [composant hôte React de
TanStack Charts](https://tanstack.com/charts/latest/docs/framework/react/reference/chart). Définissez
les éléments graphiques, les échelles, les interactions et les callbacks avec TanStack Charts ; moduix
fournit la composition qui les entoure.

`@tanstack/charts` est une dépendance peer facultative de moduix. La plage de versions actuelle est
`^0.16.0`, et l’adaptateur React de TanStack nécessite React 19.

## Exemple de base

## Anatomie

```text
Chart / Chart.Root
├─ Chart.Header (figcaption facultatif)
│  ├─ Chart.Title
│  └─ Chart.Description
├─ Chart.Plot
│  └─ zone de rendu TanStack (SVG par défaut)
└─ Chart.Legend (facultatif)
   └─ Chart.LegendItem
```

| Partie | Rôle |
| --- | --- |
| `Chart` / `Chart.Root` | Racine `figure` composée. Accepte les propriétés natives, `asChild` et une ref `HTMLElement`. |
| `Chart.Plot` | Hôte React de TanStack Charts. Nécessite `definition` et `ariaLabel`, utilise le préréglage d’animation Moduix par défaut et accepte `motion={false}`. |
| `Chart.Header` | Structure `figcaption` du titre et de la description. |
| `Chart.Title` | Titre du graphique, rendu dans un `h3` par défaut. |
| `Chart.Description` | Explication visible qui accompagne le graphique. |
| `Chart.Legend` | Liste sémantique des séries visibles. |
| `Chart.LegendItem` | Élément de légende avec un `color` facultatif pour l’indicateur. |

## Composition

### Composition recommandée

Si votre définition TanStack ne change pas, déclarez-la en dehors du composant. Assemblez ensuite
`Chart.Header`, `Chart.Plot` et `Chart.Legend` dans le composant racine. Définissez directement
`barY`, `areaY`, `lineY`, `stack()`, les échelles, les guides et les canaux de couleur dans TanStack
Charts : moduix n’en fait pas des parties React.

Utilisez la même échelle de couleur de la définition pour les éléments graphiques et les pastilles de
l’info-bulle. Réutilisez les tokens moduix correspondants dans `Chart.LegendItem` pour que la légende
reprenne les couleurs du graphique.

### Choisir les éléments graphiques

`Chart.Plot` fournit la zone de rendu, tandis que la propriété `marks` de la `definition` détermine ce
qui est dessiné. Toutes les variantes utilisent la même composition :
`<Chart.Plot definition={definition} />`.

| Objectif | Éléments TanStack | Exemple |
| --- | --- | --- |
| Barres verticales | `barY` | Exemple de base, Barres empilées |
| Barres horizontales | `barX` | Barres horizontales |
| Courbe ou zone | `lineY`, `areaY` | Zone animée, Couleurs du graphique |
| Secteurs ou anneau | `pie`, `polar`, `radialArc` | Graphique en anneau |
| Nuage de points | `dot` | Nuage de points |
| Carte thermique | `cell` | Carte thermique |

### Personnaliser le rendu

`Chart.Plot` utilise le préréglage TanStack adaptatif `motion()` par défaut. Définissez `motion={false}`
pour obtenir un graphique SVG statique, ou transmettez un autre `renderer` si vous devez gérer le
rendu vous-même. Un `renderer` défini explicitement est prioritaire sur `motion`. Si votre application
doit gérer directement la surface de rendu, utilisez le renderer Canvas ou bas niveau de TanStack.

```tsx
<Chart.Plot definition={definition} ariaLabel="Monthly revenue" motion={false} />
```

Chart utilise par défaut un corps d’info-bulle compact de moduix : les lignes sans pastille ne réservent
pas de colonne vide. Utilisez `renderTooltipBody` uniquement pour ajouter du contenu React. Son contexte
contient le `defaultBody` natif de TanStack, avec le titre, les lignes, le formatage et les pastilles.
TanStack continue à gérer l’ancrage, le placement, le portail, l’épinglage et la fermeture de
l’info-bulle. N’ajoutez des contrôles interactifs que lorsque `pinned` vaut `true`.

### Propriétés par défaut

| Partie | Propriété | Par défaut | Notes |
| --- | --- | --- | --- |
| `Chart.Root` | élément | `figure` | `Chart.Header` est son `figcaption`. |
| `Chart.Plot` | `definition` | - | Définition TanStack requise. |
| `Chart.Plot` | `ariaLabel` | - | Nom accessible du graphique requis. |
| `Chart.Plot` | `motion` | `true` | Définissez `false` pour utiliser le renderer SVG statique de TanStack. |
| `Chart.Plot` | `renderer` | Préréglage d’animation Moduix | Anime la géométrie et l’info-bulle ; respecte la préférence système pour réduire les animations. |
| `Chart.Plot` | `height` | `320` | Utilisé lorsque `aspectRatio` est absent. |
| `Chart.Plot` | `width` | adaptative | S’adapte à la largeur du conteneur. |
| `Chart.Plot` | `initialWidth` | `640` | Largeur utilisée sur le serveur et avant la première mesure. |
| `Chart.Plot` | `tabIndex` | `0` | Conserve la navigation au clavier de TanStack dans l’ordre de tabulation. |

### Comportement

- Conservez une définition stable au niveau du module. Si elle dépend de propriétés ou d’un état,
  mémorisez-la entièrement avec `useMemo`.
- Le moteur de rendu par défaut anime la géométrie initiale, les mises à jour de données identifiées par
  une clé, les guides de focus et l’info-bulle native. Avec `prefers-reduced-motion: reduce`, il passe à
  des mises à jour instantanées ; `motion={false}` désactive l’animation quelle que soit la préférence
  système.
- TanStack gère le focus déclenché par le pointeur, la navigation par flèches, l’activation avec Entrée
  ou Espace, `onFocusChange` et `onSelect`.
- Le SVG focusable du graphique utilise l’anneau de focus moduix. Ne désactivez pas `focusRing` tant que
  votre définition ne fournit pas sa propre géométrie de focus.
- Ajoutez `ariaDescription` si le titre et la description visibles n’expliquent pas suffisamment les données.
- `className` et `style` sur `Chart.Plot` ciblent l’élément externe de TanStack. Il n’expose pas de ref.

### Personnalisation avancée

Les parties issues de la factory Ark acceptent `asChild` et peuvent appliquer leurs styles aux éléments
sémantiques de votre mise en page. Dans cet exemple de tableau de bord, Chart est utilisé avec Button :

externe, et `renderTooltipBody` pour enrichir l’info-bulle. Rendez `defaultBody` dans votre propre

## Styles

Utilisez `Chart.Root` pour styliser la figure et `Chart.Plot` pour l’hôte TanStack. Les propriétés CSS
publiques contrôlent la surface, l’anneau de focus, l’enveloppe de l’info-bulle et sa mise en page par
défaut. Conservez la géométrie du graphique dans la définition TanStack, avec les options des éléments
graphiques, les échelles et les canaux de couleur.

Attribuez une classe à la racine lorsqu’un graphique nécessite des ajustements locaux :

```tsx
<Chart className="sales-chart">...</Chart>
```

```css
.sales-chart {
  --moduix-chart-tooltip-bg: var(--moduix-color-card);
  --moduix-chart-tooltip-font-size: var(--moduix-text-sm);
  --moduix-chart-tooltip-line-height: var(--moduix-line-height-text-sm);
}
```

### Points d’accroche CSS

- `Chart.Root`, `Chart.Header`, `Chart.Title`, `Chart.Description`, `Chart.Legend`,
  et `Chart.LegendItem` exposent `data-scope="chart"`, `data-part` et `data-slot`.
- `className` sur `Chart.Plot` s’applique à l’élément externe `.ts-chart-host`.
- L’info-bulle par défaut utilise les slots de données `chart-tooltip-body`,
  `chart-tooltip-title`, `chart-tooltip-rows`, `chart-tooltip-row`, `chart-tooltip-swatch`,
  `chart-tooltip-label`, `chart-tooltip-value` et `chart-tooltip-text`.
- Utilisez `--moduix-color-chart-1` à `--moduix-color-chart-5` dans les échelles de couleur TanStack.
- L’enveloppe de l’info-bulle est stylisée par les variables documentées
  `--ts-chart-tooltip-*`, mappées depuis les propriétés Moduix. Utilisez `tooltip.className` de
  TanStack pour vos sélecteurs CSS, ou `renderTooltipBody` lorsque vous devez ajouter du contenu
  React au `defaultBody` natif.
