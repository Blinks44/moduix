## Référence de l’API

`Image` est un composant moduix léger qui s’appuie sur le composant `<img>` d’[Unpic React](https://unpic.pics/img/react/).
Ark UI ne propose pas de primitive dédiée aux images. `Image` utilise donc la composition native de `<img>` et de
`<picture>` plutôt que de les remplacer par une partie Ark. Consultez le [guide de composition d’Ark](https://ark-ui.com/docs/guides/composition)
pour en savoir plus sur son modèle fondé sur les éléments natifs.

## Exemple de base

Utilisez `Image` avec l’URL d’une image provenant d’un CDN pris en charge ou avec une URL d’image classique. Dans le
mode `layout="constrained"`, indiquez `width` et `height`. Unpic génère un `srcset` et un attribut `sizes` adaptés aux
différentes tailles d’écran lorsqu’il reconnaît le fournisseur. Dans le cas contraire, il conserve l’URL source telle quelle.
Le navigateur réserve l’espace nécessaire avant le chargement de l’image.

## Anatomie

```text
Image / Image.Root
└─ img

picture (native)
├─ Image.Source
└─ Image / Image.Root
```

| Partie                  | Rôle                                                                                              |
| ----------------------- | ------------------------------------------------------------------------------------------------ |
| `Image` / `Image.Root` | Élément `<img>` natif et adaptatif ; Unpic génère `srcset`, `sizes` et les styles.                 |
| `Image.Source`         | Élément `<source>` adaptatif utilisé dans un élément natif `<picture>`.                          |

## Composition

### Composition recommandée

`Image` est la forme courte de `Image.Root`. Pour les modes `layout="constrained"` et `layout="fixed"`, indiquez `width`
et `height` afin que le navigateur réserve l’espace nécessaire avant le chargement. Avec `layout="constrained"`, ces
dimensions préservent le rapport d’aspect de l’image et lui permettent de se réduire si son conteneur est plus étroit.
Si l’URL provient d’un fournisseur pris en charge, Unpic le détecte et génère automatiquement un `srcset` avec les variantes
transformées.

Utilisez `priority` uniquement pour les images qui doivent se charger immédiatement, par exemple l’image principale
visible dès l’ouverture de la page. Cette propriété active le chargement immédiat et une priorité de chargement élevée,
sauf si vous fournissez explicitement `loading` ou la propriété React `fetchPriority` en camelCase.

### Quand créer une composition personnalisée

Utilisez un élément natif `<picture>` avec `Image.Source` lorsque le cadrage doit varier selon la taille de l’écran ou
que plusieurs sources doivent être choisies selon des requêtes média. Placez toujours `Image` en dernier enfant. Il sert
d’image de secours si le navigateur ne sélectionne aucune balise `<source>`. Transmettez `fallback`, `options` ou
`operations` si Unpic ne reconnaît pas l’URL et doit utiliser un fournisseur précis.

Pour proposer plusieurs formats, placez une `Image.Source` avec `type` avant une source équivalente sans `type`. Le
navigateur retient le premier format qu’il prend en charge.

### Propriétés par défaut

| Propriété                | Valeur par défaut                       | Remarques                                                                     |
| ------------------------ | ------------------------------------ | -------------------------------------------------------------------------------- |
| `layout`                 | `constrained`                           | Respecte les dimensions indiquées et se réduit si nécessaire.                 |
| `loading`                | `lazy`                                  | Passe à `eager` lorsque `priority` est défini.                                |
| `decoding`               | `async` pour les images sans `priority` | Une valeur native est conservée ; avec `priority`, elle n’est pas définie par défaut. |
| `fetchPriority`          | `high` avec `priority`                  | Une valeur native explicite remplace la valeur par défaut de `priority`.     |
| `objectFit`              | `cover`                                 | Appliqué par les styles en ligne générés par Unpic.                           |
| `--moduix-image-radius`  | `var(--moduix-radius-md)`              | Rayon visible appliqué par défaut par moduix.                                |

### Comportement

- `fixed` conserve les dimensions indiquées en pixels CSS et peut déborder d’un conteneur parent plus étroit, tandis que
  `fullWidth` occupe toute la largeur du conteneur.
- Pour une image informative, indiquez un texte alternatif pertinent. Pour une image décorative, utilisez `alt=""`.
  Dans ce cas, Unpic ajoute `role="presentation"`, sauf si vous fournissez explicitement un autre rôle.
- Utilisez `aspectRatio` au lieu de `width` et `height` lorsque vous préférez indiquer uniquement le rapport largeur/hauteur.
- Unpic génère `srcset` à partir de l’URL source. Utilisez `breakpoints` si les largeurs responsives standard d’Unpic ne
  conviennent pas.
- Unpic détecte automatiquement les fournisseurs d’images pris en charge. Pour les autres URL, il conserve l’URL source
  telle quelle, sauf si vous fournissez un fournisseur `fallback`.
- Les attributs natifs `loading`, `decoding` et la propriété React `fetchPriority` en camelCase restent disponibles si
  vous avez besoin d’un autre comportement de chargement.
- `background="auto"` crée une image d’arrière-plan basse résolution pour les fournisseurs pris en charge. Elle reste
  visible après le chargement. Utilisez cette option uniquement pour les images opaques ou définissez vous-même un arrière-plan.
- `unstyled` désactive les styles de mise en page en ligne générés par Unpic. Le style d’affichage, le rayon et les
  points d’accroche `data-slot` de moduix restent disponibles. Utilisez cette option lorsque le cadrage varie selon la
  taille de l’écran, puis définissez vos propres règles dans votre CSS.

### Taille fixe

Utilisez `layout="fixed"` lorsque l’image doit conserver des dimensions exactes en pixels CSS. Vérifiez que son conteneur
parent dispose de suffisamment d’espace : une image fixe ne se réduit pas pour tenir dans un conteneur plus étroit.

### Points d’accroche CSS

- `data-slot="image-root"` permet de sélectionner l’élément `<img>` affiché en CSS.
- `data-slot="image-source"` permet de sélectionner le nœud `<source>` dans un élément natif `<picture>`.
- `className` sur `Image` est la méthode recommandée pour appliquer des styles locaux. La racine est un élément de type
  bloc par défaut.
