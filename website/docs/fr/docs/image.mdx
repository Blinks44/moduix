## Référence de l’API

`Image` est un composant moduix basé sur l’élément `<img>` d’[Unpic React](https://unpic.pics/img/react/).
Ark UI ne propose pas de primitive dédiée aux images : `Image` conserve donc la composition native `<img>` et
`<picture>`, au lieu de recourir à une partie d’Ark. Consultez le [guide de composition d’Ark](https://ark-ui.com/react/docs/guides/composition)
pour en savoir plus sur son modèle fondé sur les éléments natifs.

## Exemple de base

Utilisez `Image` avec l’URL d’une image hébergée sur un CDN pris en charge, puis indiquez sa largeur et sa hauteur. Par
défaut, le composant utilise le mode `layout="constrained"`. Unpic génère les attributs `srcSet` et `sizes` adaptés aux
différentes tailles d’écran, tandis que le navigateur réserve l’espace nécessaire avant le chargement de l’image.

## Anatomie

```text
Image / Image.Root
└─ img

picture (native)
├─ Image.Source
└─ Image / Image.Root
```

| Partie                  | Rôle                                                                                              |
| ----------------------- | ------------------------------------------------------------------------------------------------ |
| `Image` / `Image.Root` | Élément `<img>` natif et adaptatif ; Unpic génère `srcSet`, `sizes` et les styles.                |
| `Image.Source`         | Élément `<source>` adaptatif utilisé dans un élément natif `<picture>`.                          |

## Composition

### Composition recommandée

`Image` est la forme abrégée du composant racine et équivaut à `Image.Root`. Avec le mode `layout="constrained"`, indiquez
`width` et `height`. Cela préserve le rapport d’aspect de l’image et permet au navigateur de réserver l’espace nécessaire,
afin d’éviter que la page ne se décale pendant le chargement. Si l’URL provient d’un fournisseur pris en charge, Unpic le
détecte automatiquement ce fournisseur et génère les valeurs `srcSet` transformées.

Utilisez `priority` uniquement pour les images qui doivent se charger immédiatement, par exemple l’image principale
visible dès l’ouverture de la page. Cette propriété active le chargement immédiat et une priorité de chargement élevée,
sauf si vous fournissez explicitement `loading` ou la propriété React `fetchPriority` en camelCase.

### Quand créer une composition personnalisée

Utilisez un élément natif `<picture>` avec `Image.Source` lorsque le cadrage doit varier selon la taille de l’écran ou
que plusieurs sources doivent être choisies selon des requêtes média. Gardez `Image` en dernier enfant : il servira
d’image de remplacement. Transmettez `fallback`, `options` ou `operations` si Unpic ne reconnaît pas l’URL et doit
utiliser un fournisseur donné.

Pour sélectionner un format, placez une `Image.Source` avec une valeur `type` avant la source équivalente sans `type`.
Le navigateur utilise le premier format pris en charge.

### Propriétés par défaut

| Propriété                | Valeur par défaut                       | Remarques                                                                     |
| ------------------------ | ------------------------------------ | -------------------------------------------------------------------------------- |
| `layout`                 | `constrained`                           | Respecte les dimensions fournies et se réduit si nécessaire.                  |
| `loading`                | `lazy`                                  | Devient `eager` lorsque `priority` est défini.                                 |
| `decoding`               | `async` pour les images sans `priority` | Une valeur native est conservée ; omise par défaut avec `priority`.          |
| `fetchPriority`          | `high` avec `priority`                  | Une valeur native remplace la valeur par défaut de `priority`.                 |
| `objectFit`              | `cover`                                 | Appliqué via les styles en ligne générés par Unpic.                            |
| `--moduix-image-radius`  | `var(--moduix-radius-md)`               | Rayon d’arrondi visible par défaut dans moduix.                                |

### Comportement

- `fixed` conserve les dimensions indiquées en pixels CSS et peut déborder d’un conteneur parent plus étroit, tandis que
  `fullWidth` occupe toute la largeur du conteneur.
- `alt` est obligatoire pour les images porteuses de sens. Pour une image décorative, utilisez `alt=""` : Unpic applique
  alors `role="presentation"`, sauf si vous remplacez explicitement ce rôle.
- Unpic génère `srcSet` à partir de l’URL source. Utilisez `breakpoints` si les largeurs adaptatives standard d’Unpic ne
  conviennent pas.
- Les attributs natifs `loading`, `decoding` et la propriété React `fetchPriority` en camelCase restent disponibles si
  vous avez besoin d’un autre comportement de chargement.
- `background="auto"` crée un arrière-plan de faible résolution pour les fournisseurs pris en charge. Il reste affiché
  après le chargement : utilisez cette option uniquement pour les images opaques, ou définissez vous-même une valeur
  d’arrière-plan.
- `unstyled` désactive les styles de mise en page en ligne générés par Unpic. Le style d’affichage, le rayon et les
  points d’accroche `data-slot` de moduix restent disponibles. Utilisez cette option lorsque le cadrage varie selon la
  taille de l’écran, puis définissez vos propres règles dans votre CSS.

### Taille fixe

Utilisez `layout="fixed"` lorsque l’image doit conserver des dimensions exactes en pixels CSS. Vérifiez que son conteneur
parent dispose de suffisamment d’espace : une image fixe ne se réduit pas pour tenir dans un conteneur plus étroit.

### Pleine largeur

conteneur. Transmettez `height` si la hauteur du recadrage doit rester fixe.

### Points d’accroche CSS

- `data-slot="image-root"` permet de sélectionner l’élément `<img>` affiché en CSS.
- `data-slot="image-source"` permet de sélectionner le nœud `<source>` dans un élément natif `<picture>`.
- `className` sur `Image` est la méthode recommandée pour appliquer des styles locaux. La racine est un élément de type
  bloc par défaut.
