## Référence de l’API

`Image` est un composant moduix léger qui s’appuie sur le composant `<img>` d’[Unpic React](https://unpic.pics/img/react/).
Ark UI ne propose pas de primitive dédiée aux images. `Image` utilise donc la composition native de `<img>` et de
`<picture>` plutôt qu’une partie Ark. Consultez le [guide de composition d’Ark](https://ark-ui.com/docs/guides/composition)
pour en savoir plus sur son modèle fondé sur les éléments natifs.

## Exemple de base

`Image` est disponible pour React et Solid dans les variantes CSS Modules et Tailwind. L’aperçu rendu
sur cette page utilise le package React CSS Modules, tandis que les onglets présentent le code source
natif des deux frameworks pour le même contrat public.

Utilisez `Image` avec l’URL d’une image provenant d’un CDN pris en charge ou avec une URL d’image classique.
Dans le mode `layout="constrained"`, indiquez `width` et `height`. Unpic génère un `srcset` et un attribut
`sizes` adaptés lorsqu’il reconnaît le fournisseur. Dans le cas contraire, il conserve l’URL source telle quelle.
Le navigateur réserve l’espace nécessaire avant le chargement de l’image.

## Anatomie

```text
Image / Image.Root
└─ img

picture (native)
├─ Image.Source
└─ Image / Image.Root
```

| Partie                 | Rôle                                                                      |
| ---------------------- | ------------------------------------------------------------------------- |
| `Image` / `Image.Root` | Élément `<img>` natif et adaptatif ; Unpic génère `srcset`, `sizes` et les styles. |
| `Image.Source`         | Élément `<source>` adaptatif utilisé dans un élément natif `<picture>`.   |

## Composition

`Image` est la racine et peut être rendu directement. Utilisez `Image.Source` uniquement comme enfant
d’un élément natif `<picture>` et placez `Image` en dernier afin qu’il reste l’image de secours si
aucune source n’est sélectionnée. Pour choisir un format, placez une source avec `type` avant une
source équivalente sans `type` ; le navigateur retient le premier format qu’il prend en charge.

## Styles

Utilisez `className` en React ou `class` en Solid sur `Image` et `Image.Source` pour les styles locaux.
Les variantes Tailwind utilisent des utilitaires natifs et les classes du consommateur. La variable
`--moduix-image-radius` personnalise les variantes CSS Modules, tandis que les hooks `data-slot` sont
partagés par les deux modes de style.

### Points d’accroche CSS

- `data-slot="image-root"` permet de sélectionner l’élément `<img>` affiché en CSS.
- `data-slot="image-source"` permet de sélectionner le nœud `<source>` dans un élément natif `<picture>`.
- `className` en React et `class` en Solid sont les méthodes recommandées pour appliquer des styles locaux.
