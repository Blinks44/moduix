## Référence de l’API

<PrimitiveReference href="https://ark-ui.com/docs/components/dialog" />

Ark UI ne propose pas de primitive `lightbox` dédiée. moduix construit ce composant à partir de
`Dialog`, en suivant les recommandations d’Ark pour la
[composition](https://ark-ui.com/docs/guides/composition), le [style](https://ark-ui.com/docs/guides/styling)
et les [refs](https://ark-ui.com/docs/guides/ref). `Dialog` définit donc le comportement du composant.

## Choisir le bon composant

Utilisez `Lightbox` lorsque vous voulez principalement afficher des images ou d’autres médias dans une fenêtre modale.

- Choisissez **`Lightbox`** pour agrandir des images, afficher une galerie de produits ou consulter d’autres médias.
- Choisissez **`Dialog`** pour une interface applicative générale, par exemple des formulaires, des actions ou du contenu mixte.
- Placez **`Carousel` dans `LightboxGallery`** si l’aperçu nécessite des diapositives ou des flèches de navigation.

## Anatomie

```text
Lightbox
├─ LightboxTrigger
├─ LightboxBind
└─ Sous-arbre de la fenêtre modale (rendu automatiquement dans un portail)
   ├─ LightboxBackdrop
   └─ LightboxPositioner
      ├─ LightboxCloseTrigger ou LightboxCloseIcon
      └─ LightboxContent
         ├─ LightboxHeader (facultatif)
         │  ├─ LightboxTitle
         │  └─ LightboxDescription
         ├─ LightboxBody
         │  └─ LightboxImage
         └─ LightboxFooter (facultatif)

LightboxRootProvider
└─ le même arbre de composants, relié à useLightbox()
```

| Partie | Rôle |
| ---------------------------- | ------------------------------------------------------------------------------------ |
| `Lightbox` | Racine du Dialog Ark qui gère l’état d’ouverture, le focus, la fermeture et l’accessibilité. |
| `LightboxRootProvider` | Fournisseur de l’état créé avec `useLightbox()`. |
| `LightboxTrigger` | Déclencheur Ark. Utilisez `asChild` pour transmettre un bouton ou un lien sémantique personnalisé. |
| `LightboxBackdrop` | Arrière-plan modal avec `data-state` et les variables de calque d’Ark. |
| `LightboxPositioner` | Conteneur fixe qui centre le contenu de la fenêtre modale. |
| `LightboxContent` | Nœud qui contient le contenu du dialogue Ark. |
| `LightboxTitle` | Titre accessible facultatif. |
| `LightboxDescription` | Description accessible facultative. |
| `LightboxCloseTrigger` | Déclencheur de fermeture Ark de bas niveau. |
| `LightboxCloseIcon` | Raccourci moduix qui combine `CloseButton` avec le déclencheur de fermeture Ark. |
| `LightboxHeader` / `LightboxBody` | Conteneurs facultatifs pour organiser le texte et les médias. |
| `LightboxFooter` | Conteneur facultatif pour les actions ou l’état sous le média. |
| `LightboxImage` | Image native stylisée qui transmet sa ref à l’`HTMLImageElement`. |
| `LightboxGallery` | Zone qui définit la mise en page et le style d’un `Carousel` composé. |
| `LightboxBind` | Partie sans rendu qui relie un balisage externe à la racine. |

## Composition

`Lightbox` gère l’état du `Dialog`, tandis que `Backdrop`, `Positioner` et `Content` restent explicites.
Les parties de la fenêtre sont rendues dans un portail par défaut. Utilisez `portalled={false}` pour
les laisser en place ou `portalRef` pour cibler un conteneur. Placez `CloseIcon` à côté de `Content`,
dans `Positioner`, lorsqu’il doit rester ancré à la fenêtre et ne pas suivre les transformations du contenu.
Avec `asChild`, fournissez un seul élément sémantique. En Solid, `asChild` est une fonction de rendu qui
reçoit les props de cet élément.

Pour les galeries, gardez l’image sélectionnée et la page de `Carousel` dans l’état de l’application.
Passez la clé de l’image à `LightboxTrigger value` et mettez cet état à jour depuis
`onTriggerValueChange(details)` ou le callback de page de `Carousel`. Utilisez `LightboxRootProvider` avec
`useLightbox()` lorsque l’état ou le bouton d’ouverture se trouve en dehors de la racine, puis lisez
l’état enfant avec `useLightboxContext()`. `Bind` ne rend rien et sélectionne seulement une image dans
un balisage externe, la fenêtre doit donc toujours composer explicitement ses parties. `Image closeOnClick`
est le raccourci qui ferme la fenêtre après un clic sur l’image.

## Exemples

### Contenu provenant d’un CMS

Utilisez `LightboxBind` lorsque les images proviennent d’un CMS ou d’un balisage tiers que vous ne
rendez pas directement avec `LightboxTrigger`. Indiquez le conteneur avec `rootRef` ou `rootSelector`,
choisissez un `selector`, puis traitez `{ src, alt, element }` dans `onImageSelect`. `Bind` ouvre la
Lightbox parente sans rendre l’arrière-plan, le contenu ni les contrôles de fermeture. La source est
recherchée dans `data-lightbox-src`, puis `currentSrc` et `src`, et l’image est préchargée au survol ou
au focus clavier. Utilisez un bouton ou un lien sémantique pour `selector` afin que l’ouverture fonctionne
au clavier. Pour un tableau d’images structuré, utilisez la composition `LightboxGallery + Carousel`.

### Points d’accroche CSS

- Slots moduix : `lightbox-trigger`, `lightbox-backdrop`, `lightbox-positioner`, `lightbox-content`,
  `lightbox-title`, `lightbox-description`, `lightbox-close-trigger`, `lightbox-close-icon`,
  `lightbox-header`, `lightbox-body`, `lightbox-footer`, `lightbox-image` et `lightbox-gallery`.
- Attributs d’état et d’anatomie Ark : `data-scope="dialog"`, `data-part`,
  `data-state="open|closed"`, `data-nested`, `data-has-nested`, `--layer-index` et
  `--nested-layer-count`.
- Points d’accroche locaux : `LightboxImage` expose `data-slot="lightbox-image"` et, en option,
  `data-close-on-click`. `LightboxGallery` expose `data-slot="lightbox-gallery"` et applique des
  styles aux slots imbriqués de Carousel.
- L’animation dépend de l’attribut Ark `data-state`. Utilisez `present` uniquement si le contrôle de
  l’animation en JavaScript doit maintenir le contenu monté.
- Avec `prefers-reduced-motion: reduce`, l’arrière-plan et le contenu utilisent une animation de 1 ms.
  Le nettoyage après la fermeture reste ainsi intact, sans mouvement visible.
