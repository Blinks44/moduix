## Référence de l’API

<PrimitiveReference href="https://ark-ui.com/docs/components/dialog" />

Ark UI ne propose pas de primitive `lightbox` dédiée. moduix construit ce composant à partir de
`Dialog`, en suivant les recommandations d’Ark pour la
[composition](https://ark-ui.com/docs/guides/composition), le [style](https://ark-ui.com/docs/guides/styling)
et les [refs](https://ark-ui.com/docs/guides/ref). `Dialog` définit donc le comportement du composant.

## Choisir le bon composant

Utilisez `Lightbox` lorsque vous voulez principalement afficher des images ou d’autres médias dans une fenêtre modale.

- Choisissez **`Lightbox`** pour agrandir des images, afficher une galerie de produits ou consulter d’autres médias.
- Choisissez **`Dialog`** pour une interface applicative générale, par exemple des formulaires, des actions ou du contenu mixte.
- Placez **`Carousel` dans `Lightbox.Gallery`** si la galerie nécessite des diapositives et des flèches de navigation.

## Anatomie

```text
Lightbox / Lightbox.Root
├─ Lightbox.Trigger
├─ Lightbox.Bind
└─ Sous-arbre de la fenêtre modale (rendu automatiquement dans un portail)
   ├─ Lightbox.Backdrop
   └─ Lightbox.Positioner
      ├─ Lightbox.CloseTrigger ou Lightbox.CloseIcon
      └─ Lightbox.Content
         ├─ Lightbox.Header (facultatif)
         │  ├─ Lightbox.Title
         │  └─ Lightbox.Description
         ├─ Lightbox.Body
         │  └─ Lightbox.Image
         └─ Lightbox.Footer (facultatif)

Lightbox.RootProvider
└─ le même arbre de composants, relié à useLightbox()
```

| Partie | Rôle |
| ---------------------------- | ------------------------------------------------------------------------------------ |
| `Lightbox` / `Lightbox.Root` | Racine du Dialog Ark qui gère l’état d’ouverture, le focus, la fermeture et l’accessibilité. |
| `Lightbox.RootProvider` | Fournisseur de l’état créé avec `useLightbox()`. |
| `Lightbox.Trigger` | Déclencheur Ark. Utilisez `asChild` pour transmettre un bouton ou un lien sémantique personnalisé. |
| `Lightbox.Backdrop` | Arrière-plan modal avec `data-state` et les variables de calque d’Ark. |
| `Lightbox.Positioner` | Conteneur fixe qui centre le contenu de la fenêtre modale. |
| `Lightbox.Content` | Nœud qui contient le contenu du dialogue Ark. |
| `Lightbox.Title` | Titre accessible facultatif. |
| `Lightbox.Description` | Description accessible facultative. |
| `Lightbox.CloseTrigger` | Déclencheur de fermeture Ark de bas niveau. |
| `Lightbox.CloseIcon` | Raccourci moduix qui combine `CloseButton.Root` avec le déclencheur de fermeture Ark. |
| `Lightbox.Header` / `Body` | Conteneurs facultatifs pour organiser le texte et les médias. |
| `Lightbox.Footer` | Conteneur de mise en page facultatif pour les actions ou l’état sous le média. |
| `Lightbox.Image` | Image native stylisée qui transmet sa ref à l’`HTMLImageElement`. |
| `Lightbox.Gallery` | Zone qui définit la mise en page et le style d’un `Carousel` composé. |
| `Lightbox.Bind` | Partie sans rendu qui relie un balisage externe à la racine. |

## Composition

Par défaut, la racine rend `Backdrop` et `Positioner` via un portail. Utilisez `portalled={false}`
pour les rendre à leur emplacement, ou `portalRef` pour cibler un conteneur personnalisé. Les parties
structurelles restent explicites et peuvent être stylisées séparément.

### Composition recommandée

Gardez la structure de la fenêtre modale explicite. `Lightbox.Content` est l’élément de contenu Ark.
Il n’affiche pas automatiquement l’arrière-plan, le conteneur de positionnement, l’image, la galerie
ou le bouton de fermeture.

Utilisez `Lightbox.Image` pour une image unique. Il affiche un élément `<img>` natif, accepte ses
propriétés et transmet sa ref à l’`HTMLImageElement`. `Lightbox.Header`, `Body` et `Footer` sont des
conteneurs facultatifs qui séparent visuellement le texte, les médias et les actions.

Entourez `Carousel` de `Lightbox.Gallery` pour afficher une collection d’images connue à l’avance.
`Gallery` fournit la zone d’affichage de la lightbox, l’alignement des flèches, la taille des médias
et la disposition des indicateurs, tandis que `Carousel` continue de gérer les diapositives.

Placez `Lightbox.CloseIcon` à côté de `Lightbox.Content`, dans `Lightbox.Positioner`, pour l’ancrer
dans un angle de la fenêtre. S’il se trouve dans `Lightbox.Content`, il suit les transformations du
contenu pendant les animations d’entrée et de sortie.

### Quand créer une composition personnalisée

Affichez directement le contenu personnalisé dans `Lightbox.Content` lorsqu’il ne correspond ni à une
image unique ni à une galerie `Carousel`. Réservez `Lightbox.Bind` au balisage externe qui ne peut pas
inclure `Lightbox.Trigger`. Pour un tableau d’images structuré, utilisez des déclencheurs explicites
et placez `Carousel` dans `Lightbox.Gallery`.

### Propriétés par défaut

Par défaut, le contenu rendu dans un portail est monté à la demande, puis démonté après l’animation de
fermeture. Définissez `unmountOnExit={false}` pour le conserver après la première ouverture. Désactivez
`lazyMount` et `unmountOnExit` uniquement si le contenu doit être rendu immédiatement au chargement de la page.

| Propriété | Valeur par défaut | Remarques |
| ------------------------ | ------------ | ------------------------------------------------------------------------ |
| `closeOnEscape` | `true` | Hérité d’Ark Dialog. |
| `closeOnInteractOutside` | `true` | Hérité d’Ark Dialog. |
| `defaultOpen` | `false` | État initial en mode non contrôlé. |
| `modal` | `true` | Bloque les interactions extérieures et masque le contenu situé sous la fenêtre modale. |
| `preventScroll` | `true` | Empêche le défilement de la page lorsque la fenêtre modale est ouverte. |
| `role` | `"dialog"` | Pour donner un nom accessible, utilisez `aria-label` ou `Lightbox.Title`. `ids` stabilise uniquement les relations entre éléments. |
| `trapFocus` | `true` | Maintient le focus clavier dans la fenêtre modale lorsqu’elle est ouverte. |
| `lazyMount` | `true` | Diffère le montage des médias lourds jusqu’à la première ouverture. |
| `unmountOnExit` | `true` | Supprime les nœuds de la fenêtre modale après l’animation de fermeture. |

### Comportement

`onOpenChange` et `onTriggerValueChange` utilisent la forme d’objet `details` d’Ark. Pour contrôler
l’ouverture, lisez `details.open`. Pour une galerie avec plusieurs déclencheurs, lisez `details.value`.

Utilisez `useLightbox()` avec `Lightbox.RootProvider` lorsque les contrôles se trouvent en dehors de
la racine rendue. Dans un composant enfant, l’état du dialogue est accessible avec
`useLightboxContext()`. Les deux API sont exportées par `@moduix/react` et exposées sur l’espace de
noms `Lightbox`.

`Lightbox.Image closeOnClick` est le raccourci prévu pour fermer la fenêtre lorsque l’utilisateur
clique sur l’image. `Lightbox.Bind` relie un balisage provenant d’un CMS ou d’un service tiers lorsque
vous ne pouvez pas l’entourer avec `Lightbox.Trigger`. Il doit être rendu dans `Lightbox` et transmet
l’image sélectionnée via `onImageSelect(details)`. L’objet contient `src`, `alt` s’il est fourni, et
l’`HTMLImageElement` d’origine dans `element`. `selector` est obligatoire et doit cibler un bouton ou
un lien sémantique pour que chaque aperçu reste accessible au clavier.

Les autres propriétés héritées de `Dialog` sont transmises sans modification, notamment `id`, `ids`,
`initialFocusEl`, `finalFocusEl`, `persistentElements`, `restoreFocus`, `present`, `immediate`,
`skipAnimationOnMount` et les callbacks d’interaction extérieure.

## Exemples

### Contenu provenant d’un CMS

Utilisez `Lightbox.Bind` lorsque les images à prévisualiser proviennent d’un CMS ou d’un balisage tiers
que vous ne rendez pas directement avec `Lightbox.Trigger`. Indiquez le conteneur avec `rootRef` ou
`rootSelector`, choisissez un `selector`, puis traitez l’objet `{ src, alt, element }` dans
`onImageSelect`. `Bind` ouvre la Lightbox parente mais ne rend aucun élément de la fenêtre modale.
L’arrière-plan, le contenu, les contrôles de fermeture et la mise en page de l’image restent donc
entièrement sous votre contrôle. Le composant recherche la source dans `data-lightbox-src`, puis dans
`currentSrc`, puis dans `src`, et la précharge au survol ou au focus clavier. Utilisez un bouton ou un
lien sémantique comme élément ciblé par `selector` afin que son activation au clavier déclenche le clic
qui ouvre la Lightbox. Si votre serveur renvoie déjà un tableau d’images structuré, préférez la
composition `Lightbox.Gallery + Carousel` présentée plus haut.

### Points d’accroche CSS

- Slots moduix : `lightbox-trigger`, `lightbox-backdrop`, `lightbox-positioner`, `lightbox-content`,
  `lightbox-title`, `lightbox-description`, `lightbox-close-trigger`, `lightbox-close-icon`,
  `lightbox-header`, `lightbox-body`, `lightbox-footer`, `lightbox-image` et `lightbox-gallery`.
- Attributs d’état et d’anatomie Ark : `data-scope="dialog"`, `data-part`,
  `data-state="open|closed"`, `data-nested`, `data-has-nested`, `--layer-index` et
  `--nested-layer-count`.
- Points d’accroche locaux : `Lightbox.Image` expose `data-slot="lightbox-image"` et, en option,
  `data-close-on-click`. `Lightbox.Gallery` expose `data-slot="lightbox-gallery"` et applique des
  styles aux slots imbriqués de Carousel.
- L’animation dépend de l’attribut Ark `data-state`. Utilisez `present` uniquement si le contrôle de
  l’animation en JavaScript doit maintenir le contenu monté.
- Avec `prefers-reduced-motion: reduce`, l’arrière-plan et le contenu utilisent une animation de 1 ms.
  Le nettoyage après la fermeture reste ainsi intact, sans mouvement visible.
