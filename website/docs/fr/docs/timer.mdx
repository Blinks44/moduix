## Exemple de base


`TimerSegments` est la façon la plus simple d’afficher le temps au format courant, avec des deux-points comme
séparateurs. Par défaut, il affiche les heures, les minutes et les secondes. Passez `types` pour choisir un autre
ensemble d’unités. Utilisez les éléments de composition détaillés si vous avez besoin de libellés d’unité, de
séparateurs personnalisés ou d’une mise en forme différente pour chaque valeur.

`TimerSegments` accepte toutes les propriétés de `TimerArea`, sauf `children` et `asChild`, et transmet la ref de
la zone. Comme il crée lui-même les éléments et les séparateurs, utilisez `TimerArea` si vous devez remplacer
l’élément hôte ou fournir vos propres enfants.

## Anatomie

```text
Timer
├─ TimerArea
│  ├─ TimerItem
│  └─ TimerSeparator
└─ TimerControl
   └─ TimerActionTrigger

TimerRootProvider
└─ même arbre de composition relié à l’état créé par `useTimer()`

TimerSegments
└─ TimerArea avec les éléments TimerItem et TimerSeparator
```

| Élément | Rôle |
| ----------------------- | ------------------------------------------------------------------------ |
| `Timer` | Gère l’état du minuteur Ark, ses identifiants, l’intervalle et les fonctions de rappel. |
| `TimerRootProvider` | Relie les éléments à l’état créé par `useTimer()`. |
| `TimerSegments` | Construit les unités de temps standard et leurs séparateurs. |
| `TimerArea` | Regroupe les valeurs de temps visibles. |
| `TimerItem` | Affiche une unité de temps formatée, comme `hours`, `minutes` ou `seconds`. |
| `TimerSeparator` | Affiche un séparateur entre les unités de temps. |
| `TimerControl` | Regroupe les déclencheurs d’action. |
| `TimerActionTrigger` | Déclenche l’action `start`, `pause`, `resume`, `reset` ou `restart`. |

## Composition

`Timer` gère l’état du minuteur. `TimerSegments` crée lui-même les éléments `TimerArea`,
`TimerItem` et `TimerSeparator`. Utilisez donc la composition complète avec `TimerArea` pour ajouter des libellés
d’unité, des séparateurs personnalisés ou une mise en page propre à chaque valeur.

Utilisez `TimerRootProvider` avec `useTimer()` lorsque l’état doit être créé en dehors de l’arbre de composition
rendu. `TimerContext` et `useTimerContext()` conviennent lorsque d’autres éléments de l’interface doivent accéder à
l’état ou aux méthodes du minuteur. En Solid, l’état et le contexte se lisent via des fonctions réactives : utilisez
`timer()` et `api()`. En Vue, les refs sont automatiquement déballées dans les templates et s’utilisent avec `.value`
dans le code du script.

Dans la version installée d’Ark UI, `TimerItem` remplace son contenu enfant par la valeur formatée avant de traiter
`asChild`. L’élément fourni est donc perdu en Vue et en React. Utilisez l’élément par défaut de `TimerItem` en attendant
la correction dans Ark ; les exemples ci-dessus utilisent cette composition prise en charge.

## Styles

Pour modifier la structure, utilisez `className` en React ou `class` en Solid et en Vue sur les éléments exportés.
La variante CSS Modules expose des variables CSS pour les valeurs visuelles par défaut ; Tailwind utilise des
classes utilitaires et vos propres classes pour les remplacer. Les attributs Ark restent disponibles pour cibler chaque élément.

### Sélecteurs et attributs de style

- Sélecteurs `data-slot="timer-root"`, `timer-root-provider`, `timer-area`, `timer-item`,
  `timer-separator`, `timer-control` et `timer-action-trigger`.
- Attributs de structure Ark : `data-scope="timer"` et
  `data-part="root|area|item|separator|control|action-trigger"`.
- `TimerItem` expose `data-type` et la variable CSS `--value` mise à jour par Ark.
- Ark ajoute l’attribut `hidden` aux déclencheurs d’action indisponibles dans l’état courant du minuteur.
