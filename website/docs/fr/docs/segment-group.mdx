## Choisir le bon composant

Utilisez `SegmentGroup` lorsque l’utilisateur choisit une valeur dans un petit ensemble visible en
même temps.

- Choisissez **`Tabs`** lorsque la sélection doit également modifier un panneau de contenu visible.
- Choisissez **`ToggleGroup`** lorsque les éléments se comportent comme des boutons de barre d’outils et que plusieurs valeurs peuvent être actives.
- Choisissez **`RadioGroup`** lorsque le contrôle doit conserver l’apparence familière des boutons radio.
- Choisissez **`SegmentGroup`** lorsque l’interaction ressemble à celle d’un groupe de boutons radio, mais que l’interface doit rester compacte et segmentée.

## Anatomie

```text
SegmentGroup / SegmentGroup.Root
├─ SegmentGroup.Label (facultatif)
├─ SegmentGroup.Indicator
└─ SegmentGroup.Item[value]
   ├─ SegmentGroup.ItemText
   ├─ SegmentGroup.ItemControl
   └─ champ de formulaire natif

SegmentGroup.RootProvider
└─ même arborescence d’éléments reliée à un store moduix useSegmentGroup()

SegmentGroup.Context / SegmentGroup.ItemContext
└─ accès avancé à l’état Ark via render prop
```

| Partie                                | Rôle                                                                  |
| ------------------------------------- | --------------------------------------------------------------------- |
| `SegmentGroup` / `SegmentGroup.Root`  | Gère la valeur sélectionnée, la navigation au clavier et les formulaires. |
| `SegmentGroup.ItemHiddenInput` | Champ natif d’Ark ; composition explicite décrite ci-dessous. |
| `SegmentGroup.RootProvider`            | Relie les parties à l’état créé avec `useSegmentGroup()` de moduix.   |
| `SegmentGroup.Context`                 | Donne un accès avancé à l’état racine via render prop.                |
| `SegmentGroup.ItemContext`             | Donne un accès avancé à l’état de l’élément courant via render prop.  |
| `SegmentGroup.Label`                   | Libellé accessible facultatif du groupe.                              |
| `SegmentGroup.Indicator`               | Positionne la mise en évidence de l’élément actif avec les variables CSS d’Ark. |
| `SegmentGroup.Items`                   | Méthode recommandée pour afficher des segments textuels standard.     |
| `SegmentGroup.Item`                    | Segment sélectionnable ; rend un `label` par défaut.                  |
| `SegmentGroup.ItemText`                | Libellé visible du segment.                                           |
| `SegmentGroup.ItemControl`             | Partie Ark utilisée pour l’état de l’élément, masquée par les styles moduix. |

## Composition

Pour la composition courante, utilisez `SegmentGroup` avec `SegmentGroup.Indicator` avant
`SegmentGroup.Items`. `Items` inclut `ItemText`, `ItemControl` et exactement un
`ItemHiddenInput` pour chaque élément. Si vous rendez `SegmentGroup.Item` directement, composez ces
parties vous-même et conservez exactement un `ItemHiddenInput` dans chaque élément. L'enfant direct de
`asChild` doit rester un seul `label` sémantique.

Utilisez `SegmentGroup.RootProvider` avec `useSegmentGroup()` lorsque l'état doit être créé en dehors
de l'arbre rendu ou contrôlé par une autre partie de l'application. React expose le store comme un
objet, tandis que Solid lit son état réactif à travers la fonction d'accès renvoyée.

## Styles

Dans React, utilisez `className` et, dans Solid, `class` sur les parties exportées pour les styles
structurels. Pour les styles fondés sur l'état, préférez les attributs Ark comme `data-state`,
`data-disabled` et `data-orientation`, avec les sélecteurs moduix `data-slot`. Les variantes
Tailwind utilisent des utilitaires natifs et les classes du consommateur ; les variables ci-dessous
personnalisent les variantes CSS Modules. Les attributs d'état et les hooks data-slot sont partagés
par les deux modes de style.

### Hooks de style

- Sélecteurs `data-slot` stables : `segment-group-root`, `segment-group-root-provider`,
  `segment-group-label`, `segment-group-indicator`, `segment-group-item`,
  `segment-group-item-text` et `segment-group-item-control`.
- Sélecteurs des parties Ark : `data-scope="segment-group"` et `data-part` sur la racine, le libellé,
  l'indicateur, l'élément, le texte de l'élément, son control et le champ masqué.
- Sélecteurs d'état Ark : `data-state="checked|unchecked"`, `data-orientation`, `data-disabled`,
  `data-readonly`, `data-invalid`, `data-required` et `data-focus-visible`.
- L'indicateur utilise les variables d'exécution Ark `--left`, `--top`, `--width` et `--height` pour
  sa taille. Son mouvement utilise `--transition-duration` et `--transition-timing-function`, avec les
  valeurs par défaut moduix définies par `--moduix-segment-group-indicator-transition-duration` et
  `--moduix-segment-group-indicator-transition-timing-function`.
