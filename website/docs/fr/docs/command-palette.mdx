## Référence de l'API

Ark UI ne fournit pas de primitive `command-palette` dédiée. `CommandPalette` associe Ark
[`Dialog`](https://ark-ui.com/docs/components/dialog) et
[`Combobox`](https://ark-ui.com/docs/components/combobox), puis ajoute une structure standard de palette et une
barre de recherche. Le composant suit les recommandations d'Ark pour la [composition](https://ark-ui.com/docs/guides/composition),
les [styles](https://ark-ui.com/docs/guides/styling) et les [refs](https://ark-ui.com/docs/guides/ref).

## Exemple de base

`CommandPalette` est disponible pour React et Solid dans les packages CSS Modules et Tailwind. L'aperçu rendu
sur cette page utilise le package React CSS Modules, tandis que les onglets React et Solid affichent le code natif
pour le même contrat public.

Utilisez `CommandPalette.Panel` pour obtenir la structure de dialogue standard. Il rend automatiquement l'arrière-plan,
le conteneur de positionnement, le contenu et la zone principale. Placez `CommandPalette.Combobox` à l'intérieur,
transmettez-lui une collection et affichez les commandes filtrées dans `CommandPalette.List`. `CommandPalette.Search`
ajoute le champ de saisie et un bouton d'effacement, visible dès qu'une requête est saisie.

## Anatomie

```text
CommandPalette / CommandPalette.Root
├─ CommandPalette.Trigger
└─ Contenu de la superposition, automatiquement placé dans un portail
   ├─ CommandPalette.Backdrop
   └─ CommandPalette.Positioner
      └─ CommandPalette.Content
         ├─ CommandPalette.Header
         │  ├─ CommandPalette.Title
         │  └─ CommandPalette.Description
         └─ CommandPalette.Body
            └─ CommandPalette.Combobox
               ├─ CommandPalette.Control
               │  ├─ CommandPalette.Input
               │  └─ CommandPalette.ClearTrigger
               ├─ CommandPalette.List
               │  ├─ CommandPalette.Empty
               │  └─ CommandPalette.ItemGroup
               │     ├─ CommandPalette.ItemGroupLabel
               │     └─ CommandPalette.Item
               │        ├─ CommandPalette.ItemIcon
               │        ├─ CommandPalette.ItemText
               │        │  ├─ CommandPalette.ItemLabel
               │        │  └─ CommandPalette.ItemDescription
               │        ├─ CommandPalette.ItemMeta
               │        └─ CommandPalette.ItemIndicator
               └─ CommandPalette.Footer
                  └─ CommandPalette.Kbd

CommandPalette.Panel
└─ composition abrégée pour Backdrop, Positioner, Content et Body

CommandPalette.RootProvider
└─ le même arbre de contenu, relié à l'état créé avec useDialog()
```

| Partie | Rôle |
| --- | --- |
| `CommandPalette` / `CommandPalette.Root` | Gère l'état d'Ark Dialog et le gestionnaire facultatif de raccourci global. |
| `CommandPalette.RootProvider` | Relie les parties de la palette à l'état du dialogue créé en dehors de l'arbre rendu. |
| `CommandPalette.Trigger` | Ouvre la palette. Utilisez `asChild` pour fournir votre propre élément déclencheur. |
| `CommandPalette.Backdrop` | Arrière-plan d'Ark Dialog, avec l'état d'animation dans `data-state`. |
| `CommandPalette.Positioner` | Positionne le dialogue dans la fenêtre et maintient son contenu dans ses limites. |
| `CommandPalette.Content` | Contenu du dialogue et surface visuelle de la palette. |
| `CommandPalette.Panel` | Structure prête à l'emploi pour l'arrière-plan, le positionnement, le contenu et la zone principale standards. |
| `CommandPalette.Header` / `Title` / `Description` | Éléments de mise en page facultatifs, ainsi que les parties de titre et de description accessibles d'Ark Dialog. |
| `CommandPalette.Body` | Conteneur de mise en page de la zone Combobox dans le dialogue. |
| `CommandPalette.Combobox` | Racine Ark Combobox qui gère la recherche et la sélection des commandes. |
| `CommandPalette.Control` | Regroupe le champ de recherche et le bouton d'effacement. |
| `CommandPalette.Input` | Champ de saisie Ark Combobox. |
| `CommandPalette.Search` | Barre de recherche prête à l'emploi qui regroupe `Control`, `Input` et `ClearTrigger`. Elle ajoute aussi un nom accessible par défaut au champ. Utilisez les parties explicites lorsqu'elles nécessitent une configuration individuelle. |
| `CommandPalette.ClearTrigger` | Efface la requête et reste masqué lorsque le champ est vide. |
| `CommandPalette.List` | Liste des résultats Ark Combobox enveloppée dans un `ScrollArea` moduix. |
| `CommandPalette.Empty` | Message affiché lorsque la collection filtrée ne contient aucun résultat. |
| `CommandPalette.ItemGroup` / `ItemGroupLabel` | Sections groupées de commandes et leurs intitulés. |
| `CommandPalette.Item` | Ligne de commande avec des états de surbrillance, de sélection et de désactivation. |
| `CommandPalette.ItemText` | Conteneur du libellé et de la description de la commande. |
| `CommandPalette.ItemIndicator` | Indicateur de sélection, avec une coche par défaut. |
| `CommandPalette.ItemIcon`, `ItemLabel`, `ItemDescription`, `ItemMeta` | Parties visuelles pour l'icône, le texte, la description et les métadonnées à droite. |
| `CommandPalette.Separator` | Séparateur visuel entre les sections de commandes. |
| `CommandPalette.Footer` / `Kbd` | Zone de pied de page et enveloppe `Kbd` de moduix pour afficher les raccourcis. |

## Composition

La racine gère l'état de Dialog et place automatiquement `Backdrop` et `Positioner` dans un portail. Définissez
`portalled={false}` pour les rendre dans l'arbre courant, ou transmettez `portalRef` pour utiliser un conteneur
personnalisé. Utilisez `Panel` et `Search` pour la structure habituelle, puis rendez directement les parties
structurelles lorsque le dialogue ou les contrôles de recherche doivent suivre une autre organisation.

Conservez le filtrage de la collection auprès du propriétaire du `Combobox` : configurez `useListCollection` avec
`itemToString`, `itemToValue` et `groupBy`, puis appelez `filter(details.inputValue)` dans `onInputValueChange`.
Réinitialisez le filtre à la fermeture lorsque la collection est gérée en dehors de la palette. Définissez
`closeOnSelect={false}` pour garder la palette ouverte après une action, ou utilisez `RootProvider` avec `useDialog`
du package du framework correspondant lorsque l'état du dialogue doit être créé en dehors de l'arbre rendu.

## Styles

Utilisez les variables CSS sur les parties du déclencheur, de l'arrière-plan, du contenu, de la liste et des
éléments lorsque la palette doit s'intégrer à une interface plus dense ou adopter les couleurs de votre marque.
Utilisez les parties structurelles pour modifier la mise en page ou les couches. `CommandPalette.List` reste
défilable, mais n'affiche pas de barre de défilement visible.

### Points d'accroche CSS

- Les parties exportées fournissent des points d'accroche stables via `data-slot`, notamment `command-palette-trigger`, `command-palette-backdrop`, `command-palette-positioner`, `command-palette-content`, `command-palette-title`, `command-palette-description`, `command-palette-header`, `command-palette-body`, `command-palette-combobox`, `command-palette-control`, `command-palette-input`, `command-palette-clear-trigger`, `command-palette-list`, `command-palette-scroll-area`, `command-palette-scroll-viewport`, `command-palette-scroll-content`, `command-palette-empty`, `command-palette-item-group`, `command-palette-item-group-label`, `command-palette-item`, `command-palette-item-text`, `command-palette-item-indicator`, `command-palette-item-icon`, `command-palette-item-label`, `command-palette-item-description`, `command-palette-item-meta`, `command-palette-separator`, `command-palette-footer` et `command-palette-kbd`.
- Les attributs d'état d'Ark Dialog comprennent `data-scope="dialog"`, `data-part` et `data-state="open" | "closed"` sur les parties du dialogue, notamment le déclencheur, l'arrière-plan et le contenu.
- Les attributs d'état d'Ark Combobox comprennent `data-scope="combobox"`, `data-part`, `data-state`, `data-highlighted`, `data-disabled`, `data-invalid` et `data-empty` lorsque ces attributs s'appliquent.
- Les animations utilisent `data-state` d'Ark. Les anciens attributs `data-starting-style`, `data-ending-style` et `data-open` ne font pas partie du contrat de command-palette.
