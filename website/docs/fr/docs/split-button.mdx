## Utilisation

<Usage />

Utilisez `<SplitButton>` comme racine et gardez la structure du menu
explicite avec `SplitButtonAction`, `SplitButtonTrigger`, `SplitButtonPositioner` et `SplitButtonContent`.
L’action principale suit le même contrat `onClick` que `Button`.

## Choisir le bon composant

Utilisez `SplitButton` lorsqu’une action doit rester immédiatement disponible et que les alternatives associées
peuvent être regroupées dans un menu. Utilisez `Button` pour une seule action. Utilisez `Menu` lorsque les actions
sont au même niveau et qu’aucune ne doit être prioritaire.

## Composition

`SplitButton` associe une action principale `SplitButtonAction` à un `SplitButtonTrigger`. Gardez l’arbre de la fenêtre contextuelle
explicite : `SplitButtonPositioner` → `SplitButtonContent`, avec les éléments `MenuItem` partagés à l’intérieur de `SplitButtonContent`. Le positionneur
est placé automatiquement dans un portail ; utilisez `portalled={false}` ou `portalRef` uniquement lorsque la
fenêtre doit utiliser un autre conteneur. Les propriétés racine `size` et `variant` fournissent les valeurs par
défaut des deux boutons. La racine rend un `role="group"` sémantique ; fournissez `aria-label` ou `aria-labelledby`
lorsque le contexte environnant n’identifie pas déjà le groupe.

Le menu gère son état en interne par défaut. Passez `open` et `onOpenChange(details)` lorsqu’une autre partie de
l’application doit le contrôler. Pour un accès avancé à l’état, utilisez l’API `Menu` partagée plutôt
qu’une nouvelle enveloppe d’état propre à SplitButton. Utilisez `SplitButtonAction asChild` pour un lien ; le contenu visuel
personnalisé du déclencheur passe par `children`, afin que le déclencheur Ark et le Button moduix restent sur un seul
élément.

Dans Vue, utilisez `@click` pour l’action principale, `@open-change` ou `v-model:open` pour l’état du menu, et le slot par défaut pour le contenu du déclencheur.

`SplitButtonPositioner` enveloppe un portail : le `$el` de sa référence de composant Vue pointe donc vers le nœud d’ancrage du portail. L’élément positionné porte l’attribut `data-slot="split-button-positioner"`.

## Styles

Utilisez `className` en React ou `class` en Solid et Vue sur les parties exportées pour appliquer les styles structurels.
Les variantes Tailwind se personnalisent avec des utilitaires et des classes supplémentaires ; les variables
ci-dessous concernent les variantes CSS Modules. Les attributs de données et les hooks `data-slot` sont communs
aux deux modes de style.

L’apparence de boutons attachés associe les styles partagés de `Button` et `Menu` aux slots propres à SplitButton.
Les variantes pleines dessinent un séparateur dans le `::before` du déclencheur ; les variantes outline partagent
la bordure à la place. Utilisez `--moduix-split-button-separator-color` pour changer sa couleur, et une classe sur
`SplitButtonTrigger` pour modifier son padding horizontal.

### Points d’accroche CSS

| Partie | `data-slot` |
| --- | --- |
| `SplitButton` | `split-button-root` |
| `SplitButtonAction` | `split-button-action` |
| `SplitButtonTrigger` | `split-button-trigger` |
| `SplitButtonPositioner` | `split-button-positioner` |
| `SplitButtonContent` | `split-button-content` |

- `data-scope="split-button"` et `data-part="root"` ciblent le groupe sémantique.
- `SplitButtonTrigger` reçoit les attributs d’état d’Ark Menu, notamment `aria-expanded`, `aria-controls` et `data-state`.
- `SplitButtonContent` reçoit les attributs Ark Menu tels que `data-state`, `data-side`, `data-placement`,
  `data-nested` et `data-has-nested`.

## Clavier

| Touche | Action |
| --- | --- |
| `Enter` / `Space` | Lance l’action ou ouvre le menu depuis le déclencheur. |
| `ArrowDown` / `ArrowUp` | Ouvre le menu depuis le déclencheur et passe d’un élément à l’autre. |
| `Escape` | Ferme le menu et rend le focus au déclencheur. |

## Référence de l’API

| Prop | Type | Défaut | Description |
| --- | --- | --- | --- |
| `variant` | `SplitButtonVariant` | `'default'` | Style commun aux deux boutons : `default`, `outline`, `secondary`, `destructive`, `destructive-outline` ou `ghost`. |
| `size` | `SplitButtonSize` | `'md'` | Taille commune aux deux boutons : `xs`, `sm`, `md`, `lg` ou `xl`. |
| `aria-label` | `string` | — | Nom accessible du groupe qui entoure les deux boutons. |
| `open` / `onOpenChange` | `MenuRootProps` | — | État contrôlé du menu, transmis au `Menu` sous-jacent. |
