## Choisir le bon composant

Utilisez `Combobox` lorsque l’utilisateur doit choisir une valeur dans une liste connue et peut saisir du texte pour filtrer les options.
Utilisez `Select` lorsque la liste est prédéfinie et qu’un champ modifiable n’est pas nécessaire.

## Anatomie

```text
Combobox / Combobox.Root[collection]
├─ Combobox.Label
├─ Combobox.Control
│  ├─ Combobox.Input
│  ├─ Combobox.ClearTrigger
│  └─ Combobox.Trigger
└─ Sous-arbre du menu déroulant (placé automatiquement dans un portail)
 └─ Combobox.Positioner
    └─ Combobox.Content
       ├─ Combobox.Empty
       ├─ Combobox.Status
       ├─ Combobox.List
       │  ├─ Combobox.Option[item]
       │  └─ Combobox.Item[item]
       │     ├─ Combobox.ItemText
       │     └─ Combobox.ItemIndicator
       └─ Combobox.ItemGroup
          ├─ Combobox.ItemGroupLabel
          └─ Combobox.Item
```

| Partie | Rôle |
| --- | --- |
| `Combobox` / `Combobox.Root` | Gère l’état du composant, le filtrage, la mise en évidence et les valeurs sélectionnées. |
| `Combobox.Control` | Conteneur du champ de saisie et des boutons d’action. |
| `Combobox.Input` | Champ de texte utilisé pour rechercher et sélectionner une option. |
| `Combobox.Trigger` | Ouvre et ferme la liste d’options. |
| `Combobox.ClearTrigger` | Efface la valeur sélectionnée et/ou le texte du champ. |
| `Combobox.Positioner` | Positionne la liste flottante. |
| `Combobox.Content` | Conteneur du contenu de la liste. |
| `Combobox.Status` | Conteneur stylisé pour les messages de chargement, d’erreur ou d’aide de l’application. |
| `Combobox.List` | Conteneur de la liste des options. |
| `Combobox.Option` | Ligne prête à l’emploi pour une option simple, avec texte et indicateur. |
| `Combobox.Item` | Option sélectionnable de la liste. |
| `Combobox.ItemText` | Slot du texte de l’élément. |
| `Combobox.ItemIndicator` | Slot de l’indicateur de sélection. |
| `Combobox.Context` | Accès à l’état actuel du composant sans ajouter d’éléments au DOM. |
| `Combobox.ItemContext` | Accès à l’état de l’élément courant sans ajouter d’éléments au DOM. |

`Combobox.RootProvider` conserve le style du composant racine et l’applique à un état créé avec `useCombobox` de moduix.
Accédez à l’état du composant `Combobox` dans l’arbre avec `Combobox.Context` ou `useComboboxContext`. Pour l’état d’un élément,
utilisez `Combobox.ItemContext` ou `useComboboxItemContext`.

## Composition

Utilisez `createListCollection` pour les éléments statiques et `useListCollection` lorsque le filtrage ou d’autres mises à jour
modifient la collection. Pour les objets, définissez `itemToString` et `itemToValue`.

La racine place automatiquement `Positioner` dans un portail, mais `Positioner` et `Content` restent des parties explicites
de la composition. Définissez `portalled={false}` pour garder la liste dans l’arbre courant, ou transmettez `portalRef` pour
un conteneur précis. Utilisez `Combobox.Option` pour les lignes simples et `Combobox.Item` avec `asChild` pour les lignes personnalisées.

Conservez `value` dans l’état de l’application lorsqu’il doit être utilisé par d’autres éléments de l’interface. Si l’état est créé
en dehors de l’arbre rendu, transmettez `useCombobox` à `Combobox.RootProvider`. En sélection multiple, les tags et toute autre
représentation des valeurs appartiennent à l’application ; composez avec `TagsInput` pour les placer dans le même champ.
`Combobox.Status` est également un conteneur de messages géré par l’application et ne contrôle pas les états de chargement ou d’erreur.

## Styles

Utilisez `className` avec React ou `class` avec Solid sur les parties exportées pour les styles structurels.
Les variantes Tailwind utilisent les utilitaires natifs et les classes de l’application ; les variables CSS ci-dessous
personnalisent les variantes CSS Modules. Les attributs d’état et les hooks `data-slot` sont communs aux deux modes de style.

### Propriétés CSS

<CssPropertiesSection properties={ComboboxDocs.comboboxOverrideCssProperties} />

### Points d’accroche CSS

- Les parties Ark conservent `data-scope="combobox"` et leurs valeurs `data-part`. moduix ajoute des points d’accroche
  `data-slot` stables aux parties stylisées.
- Les slots stables comprennent `combobox-root`, `combobox-root-provider`, `combobox-label`,
  `combobox-control`, `combobox-input`, `combobox-clear-trigger`, `combobox-trigger`,
  `combobox-positioner`, `combobox-content`, `combobox-empty`, `combobox-status`, `combobox-list`,
  `combobox-item-group`, `combobox-item-group-label`, `combobox-item`, `combobox-item-text` et
  `combobox-item-indicator`. `Combobox.Option` réutilise les slots de l’élément sans ajouter de point d’accroche.
- Les attributs d’état Ark comprennent `data-state="open|closed"`, `data-focus`, `data-invalid`, `data-disabled`,
  `data-highlighted`, `data-empty`, `data-placement` et `data-side`.
- Les variables de positionnement Ark comprennent `--reference-width`, `--available-width`, `--available-height`,
  `--transform-origin`, `--z-index` et `--layer-index`. Le thème partagé définit des valeurs initiales neutres pour les outils
  de développement et le contenu non positionné, puis Ark les remplace par les mesures de `Positioner`.
