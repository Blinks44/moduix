## Choisir le bon composant

Utilisez `Combobox` lorsque les utilisateurs choisissent parmi des valeurs connues et que la saisie sert à filtrer les
options. Utilisez `Select` lorsque ce même choix prédéfini ne nécessite pas de champ modifiable.

## Exemple de base

Créez une `ListCollection` Ark, transmettez-la à `Combobox` et gardez la structure du popup explicite. Utilisez
`Combobox.Option` pour les chaînes simples et `Combobox.Item` lorsqu’une ligne exige une structure personnalisée.
`onInputValueChange` reçoit un objet `details` d’Ark.

## Anatomie

```text
Combobox.Root[collection]
├─ Combobox.Label
├─ Combobox.Control
│  ├─ Combobox.Input
│  ├─ Combobox.ClearTrigger
│  └─ Combobox.Trigger
└─ Sous-arbre de l’overlay (placé automatiquement dans un portail)
 └─ Combobox.Positioner
    └─ Combobox.Content
       ├─ Combobox.Empty
       ├─ Combobox.Status
       ├─ Combobox.List
       │  ├─ Combobox.Option[item]
       │  └─ Combobox.Item[item]
       │     ├─ Combobox.ItemText
       │     └─ Combobox.ItemIndicator
       └─ Combobox.ItemGroup
          ├─ Combobox.ItemGroupLabel
          └─ Combobox.Item
```

| Partie | Rôle |
| --- | --- |
| `Combobox` / `Combobox.Root` | Gère l’état, le filtrage, la surbrillance et les valeurs sélectionnées du Combobox. |
| `Combobox.Control` | Enveloppe les éléments du champ et le déclencheur. |
| `Combobox.Input` | Champ textuel qui contrôle la recherche et la sélection. |
| `Combobox.Trigger` | Ouvre et ferme la liste contextuelle. |
| `Combobox.ClearTrigger` | Efface la valeur actuelle et/ou le champ. |
| `Combobox.Positioner` | Positionneur flottant du contenu contextuel. |
| `Combobox.Content` | Conteneur du contenu du popup. |
| `Combobox.Status` | Message d’application stylé pour le chargement, une erreur ou une indication. |
| `Combobox.List` | Enveloppe de la liste des options. |
| `Combobox.Option` | Ligne prête à l’emploi pour une option simple, avec texte et indicateur. |
| `Combobox.Item` | Ligne d’option sélectionnable. |
| `Combobox.ItemText` | Slot du libellé textuel dans l’élément. |
| `Combobox.ItemIndicator` | Slot de l’indicateur de sélection ou de surbrillance. |
| `Combobox.Context` | Accès à l’état actuel du Combobox sans balisage supplémentaire. |

`Combobox.RootProvider` rend le même composant racine stylé autour d’un état créé avec `useCombobox` de moduix.
Lisez l’état dans l’arbre avec `Combobox.Context` ou `useComboboxContext` de moduix.

## Composition

Le composant racine place automatiquement `Positioner` dans un portail. Utilisez `portalled={false}` pour un rendu
intégré ou `portalRef` pour un conteneur personnalisé ; les parties structurelles restent explicites et stylables.

### Composition recommandée

Utilisez `createListCollection` pour une collection statique ou `useListCollection` lorsque le filtrage modifie les
éléments rendus. Pour une collection d’objets, définissez `itemToString` et `itemToValue`.

Conservez `Combobox.Positioner` et `Combobox.Content` explicites. `Content` est la partie de contenu Ark réelle ;
le composant racine automatise uniquement la limite du portail.

Si cette structure se répète, créez un petit utilitaire local. Pour les chaînes simples, choisissez `Combobox.Option` ;
réservez `Combobox.Item` aux liens, aux lignes complexes ou au placement personnalisé de l’indicateur :

```tsx
function FruitComboboxPopup({ items }: { items: Array<{ label: string; value: string }> }) {
  return (
    <Combobox.Positioner>
      <Combobox.Content>
        <Combobox.Empty>No fruits found.</Combobox.Empty>
        <Combobox.List>
          {items.map((item) => (
            <Combobox.Option key={item.value} item={item}>
              {item.label}
            </Combobox.Option>
          ))}
        </Combobox.List>
      </Combobox.Content>
    </Combobox.Positioner>
  );
}
```

### Quand créer une composition personnalisée

Utilisez une `value` contrôlée et les callbacks Ark qui reçoivent `details` lorsque l’interface voisine a besoin des valeurs
sélectionnées. Si l’état doit être créé hors du sous-arbre rendu, créez-le avec `useCombobox` de `@moduix/react`, puis
rendez `Combobox.RootProvider`. Pour l’état d’un élément, utilisez `Combobox.ItemContext` ou
`useComboboxItemContext` de moduix ; n’importez d’Ark que les utilitaires de collection et types absents de moduix.

La sélection multiple n’ajoute pas d’API de puces propre au Combobox. Rendez des tags ou une autre représentation depuis
l’état contrôlé et laissez `Combobox multiple` gérer la sélection.

Ark ne fournit pas de partie Status pour Combobox. `Combobox.Status` de moduix est un `div` stylé pour les messages de
chargement, d’erreur ou d’aide ; il ne gère aucun état et ne définit aucun rôle ARIA.

### Propriétés par défaut

Par défaut, le contenu de l’overlay dans le portail est monté à la demande et démonté après l’animation de sortie.
Définissez `unmountOnExit={false}` pour le conserver après la première ouverture ; désactivez les deux propriétés de
cycle de vie uniquement lorsqu’un rendu initial immédiat est nécessaire.

| Surface | Valeur par défaut | Remarques |
| --- | --- | --- |
| `Combobox.Trigger` | chevron moduix | Utilisé en l’absence d’enfants. |
| `Combobox.ClearTrigger` | icône de fermeture moduix | Utilisée en l’absence d’enfants. |
| `Combobox.ItemIndicator` | icône de confirmation moduix | Utilisée en l’absence d’enfants. |
| `Combobox.Option.indicator` | icône de confirmation | Transmettez `false` pour la masquer ou un nœud React pour la remplacer. |
| largeur de `Combobox` | `16rem` (max. `100%`) | Largeur standard du composant racine stylé. |
| variables de `Combobox.Positioner` | variables Ark à l’exécution | Utilise `--reference-width`, `--available-height`, `--transform-origin`. |

### Comportement

- `collection` est obligatoire.
- `value` et `defaultValue` sont des tableaux de chaînes, y compris en sélection unique.
- `onValueChange(details)` lit les valeurs actuelles dans `details.value`.
- `onInputValueChange(details)` lit le texte dans `details.inputValue` et son origine dans `details.reason`.
- `onOpenChange`, `onHighlightChange` et `onSelect` conservent la forme des détails Ark.
- Toutes les parties DOM Ark conservent `asChild`.
- Le package Ark Combobox actuel ne fournit pas de partie `HiddenInput`. Pour l’envoi natif du formulaire, utilisez les
  propriétés racine `name` et `form`.
- `Combobox.RootProvider` conserve les styles racine moduix et les réglages du portail pour un état Ark externe. Utilisez
  `useCombobox`, `Combobox.Context`, `useComboboxContext`, `Combobox.ItemContext` et `useComboboxItemContext` de moduix.
- L’héritage de l’état Ark `Field.Root` reste disponible via `Field.Root` de moduix ; `readOnly` et `required` conservent
  le comportement Ark.
- Utilisez `ids` pour partager des identifiants d’accessibilité entre des parties composées séparément. `lazyMount` et
  `unmountOnExit` valent `true` par défaut ; `present` conserve le cycle de présence Ark pour les animations de sortie.
- `selectionBehavior` et `closeOnSelect` sont transmis sans modification. En sélection multiple, Ark efface le champ
  après la sélection.

### Migration depuis shadcn

Gardez l’API moduix cohérente avec Ark et faites correspondre explicitement les facilités courantes de shadcn :

| Motif shadcn | Équivalent moduix |
| --- | --- |
| `items` sur le composant racine | `createListCollection()` ou `useListCollection()`, puis `collection` |
| `itemToStringValue` | `itemToString` et généralement `itemToValue` sur la collection |
| `showClear` | Rendez `Combobox.ClearTrigger` si nécessaire |
| `ComboboxItem` simple | Utilisez `Combobox.Option` ; pour une structure personnalisée, `Combobox.Item` |
| Zone de puces intégrée | `value` contrôlée avec vos propres tags ou composition avec `TagsInput` |
| Enveloppe `ComboboxContent` | `Combobox.Positioner` et `Combobox.Content` explicites |

### Points d’accroche CSS

- Les slots stables comprennent `combobox-root`, `combobox-root-provider`, `combobox-label`,
  `combobox-control`, `combobox-input`, `combobox-clear-trigger`, `combobox-trigger`,
  `combobox-positioner`, `combobox-content`, `combobox-empty`, `combobox-status`, `combobox-list`,
  `combobox-item-group`, `combobox-item-group-label`, `combobox-item`, `combobox-item-text` et
  `combobox-item-indicator`. `Combobox.Option` réutilise les slots de l’élément sans ajouter de hook.
- Les hooks d’état Ark comprennent `data-state="open|closed"`, `data-focus`, `data-invalid`, `data-disabled`,
  `data-highlighted`, `data-empty`, `data-placement` et `data-side`.
- Les variables de positionnement Ark comprennent `--reference-width`, `--available-width`, `--available-height`,
  `--transform-origin`, `--z-index` et `--layer-index`. Le thème partagé définit des valeurs initiales neutres pour les
  outils et le contenu non positionné ; Ark les remplace par les mesures de `Positioner`.
