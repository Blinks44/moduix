## Choisir le bon composant

Utilisez `Combobox` lorsque l’utilisateur doit choisir une valeur dans une liste et filtrer les options en saisissant du texte.
Utilisez `Select` lorsque cette liste ne nécessite pas de champ éditable.

## Exemple de base

Créez une `ListCollection` d’Ark, transmettez-la à `Combobox` et définissez explicitement la structure du menu déroulant.
Utilisez `Combobox.Option` pour les options simples et `Combobox.Item` lorsqu’un élément nécessite une structure personnalisée.
`onInputValueChange` reçoit un objet `details` fourni par Ark.

## Anatomie

```text
Combobox.Root[collection]
├─ Combobox.Label
├─ Combobox.Control
│  ├─ Combobox.Input
│  ├─ Combobox.ClearTrigger
│  └─ Combobox.Trigger
└─ Sous-arbre du menu déroulant (placé automatiquement dans un portail)
 └─ Combobox.Positioner
    └─ Combobox.Content
       ├─ Combobox.Empty
       ├─ Combobox.Status
       ├─ Combobox.List
       │  ├─ Combobox.Option[item]
       │  └─ Combobox.Item[item]
       │     ├─ Combobox.ItemText
       │     └─ Combobox.ItemIndicator
       └─ Combobox.ItemGroup
          ├─ Combobox.ItemGroupLabel
          └─ Combobox.Item
```

| Partie | Rôle |
| --- | --- |
| `Combobox` / `Combobox.Root` | Gère l’état, le filtrage, la mise en évidence et les valeurs sélectionnées. |
| `Combobox.Control` | Réunit le champ de saisie et les boutons d’action. |
| `Combobox.Input` | Champ de texte utilisé pour rechercher et sélectionner une option. |
| `Combobox.Trigger` | Ouvre et ferme le menu déroulant. |
| `Combobox.ClearTrigger` | Efface la valeur sélectionnée et/ou le texte du champ. |
| `Combobox.Positioner` | Positionne la liste déroulante. |
| `Combobox.Content` | Conteneur du contenu de la liste déroulante. |
| `Combobox.Status` | Conteneur stylé pour les messages de chargement, d’erreur ou d’aide. |
| `Combobox.List` | Conteneur de la liste des options. |
| `Combobox.Option` | Option prête à l’emploi pour une liste simple, avec texte et indicateur. |
| `Combobox.Item` | Option sélectionnable de la liste. |
| `Combobox.ItemText` | Slot du libellé textuel de l’élément. |
| `Combobox.ItemIndicator` | Slot de l’indicateur de sélection ou de surbrillance. |
| `Combobox.Context` | Accès à l’état actuel du Combobox sans ajouter d’éléments au DOM. |

`Combobox.RootProvider` affiche le même composant racine stylé autour d’un état créé avec `useCombobox` de moduix.
Accédez à l’état dans l’arbre avec `Combobox.Context` ou `useComboboxContext` de moduix.

## Composition

Le composant racine place automatiquement `Positioner` dans un portail. Utilisez `portalled={false}` pour afficher la liste
dans l’arbre courant, ou `portalRef` pour choisir votre conteneur. Les parties structurelles restent explicites et stylables.

### Composition recommandée

Utilisez `createListCollection` pour une collection statique ou `useListCollection` lorsque le filtrage modifie l’ensemble
des éléments affichés. Pour une collection d’objets, définissez `itemToString` et `itemToValue`.

Gardez `Combobox.Positioner` et `Combobox.Content` dans la composition. `Content` est l’élément de contenu fourni par Ark ;
le composant racine automatise uniquement la gestion du portail.

Si cette structure se répète, créez un petit composant utilitaire local. Pour les options simples, choisissez `Combobox.Option` ;
réservez `Combobox.Item` aux liens, aux options complexes ou au placement personnalisé de l’indicateur :

```tsx
function FruitComboboxPopup({ items }: { items: Array<{ label: string; value: string }> }) {
  return (
    <Combobox.Positioner>
      <Combobox.Content>
        <Combobox.Empty>No fruits found.</Combobox.Empty>
        <Combobox.List>
          {items.map((item) => (
            <Combobox.Option key={item.value} item={item}>
              {item.label}
            </Combobox.Option>
          ))}
        </Combobox.List>
      </Combobox.Content>
    </Combobox.Positioner>
  );
}
```

### Quand créer une composition personnalisée

Utilisez une `value` contrôlée et les callbacks Ark qui reçoivent l’objet `details` lorsque l’interface environnante a besoin
des valeurs sélectionnées. Si l’état doit être créé en dehors du sous-arbre affiché, créez-le avec `useCombobox` de
`@moduix/react`, puis affichez `Combobox.RootProvider`. Pour l’état d’un élément, utilisez `Combobox.ItemContext` ou
`useComboboxItemContext` de moduix. N’importez d’Ark que les utilitaires de collection et les types absents de moduix.

`Combobox` ne fournit pas d’API de tags dédiée à la sélection multiple. Affichez les tags ou une autre représentation depuis
l’état contrôlé et laissez `Combobox multiple` gérer la sélection.

Ark ne fournit pas de partie dédiée au statut de Combobox. `Combobox.Status` de moduix est un `div` stylé pour les messages
de chargement, d’erreur ou d’aide. Il ne gère aucun état et n’ajoute aucun rôle ARIA.

### Propriétés par défaut

Par défaut, le contenu du menu déroulant dans le portail est chargé à la première ouverture, puis supprimé après l’animation
de fermeture. Définissez `unmountOnExit={false}` pour le conserver après cette première ouverture. Ne désactivez les deux
propriétés du cycle de vie que si le menu doit être affiché dès le chargement de la page.

| Élément | Valeur par défaut | Remarques |
| --- | --- | --- |
| `Combobox.Trigger` | chevron moduix | Utilisé en l’absence d’enfants. |
| `Combobox.ClearTrigger` | icône de fermeture moduix | Utilisée en l’absence d’enfants. |
| `Combobox.ItemIndicator` | icône de coche moduix | Utilisée en l’absence d’enfants. |
| `Combobox.Option.indicator` | icône de coche | Transmettez `false` pour la masquer ou un nœud React pour la remplacer. |
| largeur de `Combobox` | `16rem` (max. `100%`) | Largeur par défaut du composant racine stylé. |
| variables de `Combobox.Positioner` | variables d’exécution d’Ark | Utilise `--reference-width`, `--available-height`, `--transform-origin`. |

### Comportement

- La propriété `collection` est obligatoire.
- `value` et `defaultValue` sont des tableaux de chaînes, même en sélection unique.
- Dans `onValueChange(details)`, les valeurs actuelles se trouvent dans `details.value`.
- Dans `onInputValueChange(details)`, le texte se trouve dans `details.inputValue` et la cause du changement dans `details.reason`.
- `onOpenChange`, `onHighlightChange` et `onSelect` reçoivent les objets `details` au format Ark.
- Toutes les parties DOM d’Ark prennent en charge `asChild`.
- Le package Ark Combobox actuel ne fournit pas de partie `HiddenInput`. Pour l’envoi natif du formulaire, utilisez les
  propriétés racine `name` et `form`.
- `Combobox.RootProvider` conserve les styles du composant racine moduix et les réglages du portail pour un état Ark créé à l’extérieur.
  Utilisez `useCombobox`, `Combobox.Context`, `useComboboxContext`, `Combobox.ItemContext` et `useComboboxItemContext` de moduix.
- Le contexte d’état de `Field.Root` d’Ark reste disponible via `Field.Root` de moduix, qui repose sur Ark. `readOnly` et
  `required` conservent le comportement Ark.
- Utilisez `ids` pour partager des identifiants d’accessibilité entre des parties composées séparément. `lazyMount` et
  `unmountOnExit` valent `true` par défaut, tandis que `present` conserve le cycle de présence d’Ark pour les animations de fermeture.
- `selectionBehavior` et `closeOnSelect` sont transmis tels quels. En sélection multiple, Ark efface le champ après la sélection.

### Migration depuis shadcn

Gardez l’API moduix alignée sur Ark et faites correspondre explicitement les fonctionnalités courantes de shadcn :

| Fonctionnalité shadcn | Équivalent moduix |
| --- | --- |
| `items` sur le composant racine | `createListCollection()` ou `useListCollection()`, puis `collection` |
| `itemToStringValue` | `itemToString` et généralement `itemToValue` sur la collection |
| `showClear` | Affichez `Combobox.ClearTrigger` si nécessaire |
| `ComboboxItem` simple | Utilisez `Combobox.Option` ; pour une structure personnalisée, `Combobox.Item` |
| Zone de tags intégrée | `value` contrôlée avec vos propres tags ou composition avec `TagsInput` |
| Enveloppe `ComboboxContent` | `Combobox.Positioner` et `Combobox.Content` explicites |

### Points d’accroche CSS

- Les slots stables comprennent `combobox-root`, `combobox-root-provider`, `combobox-label`,
  `combobox-control`, `combobox-input`, `combobox-clear-trigger`, `combobox-trigger`,
  `combobox-positioner`, `combobox-content`, `combobox-empty`, `combobox-status`, `combobox-list`,
  `combobox-item-group`, `combobox-item-group-label`, `combobox-item`, `combobox-item-text` et
  `combobox-item-indicator`. `Combobox.Option` réutilise les slots de l’élément sans ajouter de point d’accroche.
- Les attributs d’état Ark comprennent `data-state="open|closed"`, `data-focus`, `data-invalid`, `data-disabled`,
  `data-highlighted`, `data-empty`, `data-placement` et `data-side`.
- Les variables de positionnement Ark comprennent `--reference-width`, `--available-width`, `--available-height`,
  `--transform-origin`, `--z-index` et `--layer-index`. Le thème partagé définit des valeurs initiales neutres pour les outils
  de développement et le contenu non positionné, puis Ark les remplace par les mesures de `Positioner`.
