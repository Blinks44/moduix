## Choisir le bon composant

Utilisez `Combobox` lorsque l’utilisateur doit choisir une valeur dans une liste connue et peut saisir du texte pour filtrer les options.
Utilisez `Select` lorsque la liste est prédéfinie et qu’un champ modifiable n’est pas nécessaire.

## Exemple de base

Créez une collection Ark avec `useListCollection`, puis transmettez-la à `Combobox`. Déclarez explicitement la structure
de la liste. Utilisez `Combobox.Option` pour les options simples et `Combobox.Item` lorsqu’une ligne nécessite une mise en page personnalisée.
La fonction `onInputValueChange` reçoit un objet `details` fourni par Ark.

## Anatomie

```text
Combobox / Combobox.Root[collection]
├─ Combobox.Label
├─ Combobox.Control
│  ├─ Combobox.Input
│  ├─ Combobox.ClearTrigger
│  └─ Combobox.Trigger
└─ Sous-arbre du menu déroulant (placé automatiquement dans un portail)
 └─ Combobox.Positioner
    └─ Combobox.Content
       ├─ Combobox.Empty
       ├─ Combobox.Status
       ├─ Combobox.List
       │  ├─ Combobox.Option[item]
       │  └─ Combobox.Item[item]
       │     ├─ Combobox.ItemText
       │     └─ Combobox.ItemIndicator
       └─ Combobox.ItemGroup
          ├─ Combobox.ItemGroupLabel
          └─ Combobox.Item
```

| Partie | Rôle |
| --- | --- |
| `Combobox` / `Combobox.Root` | Gère l’état du composant, le filtrage, la mise en évidence et les valeurs sélectionnées. |
| `Combobox.Control` | Conteneur du champ de saisie et des boutons d’action. |
| `Combobox.Input` | Champ de texte utilisé pour rechercher et sélectionner une option. |
| `Combobox.Trigger` | Ouvre et ferme la liste d’options. |
| `Combobox.ClearTrigger` | Efface la valeur sélectionnée et/ou le texte du champ. |
| `Combobox.Positioner` | Positionne la liste flottante. |
| `Combobox.Content` | Conteneur du contenu de la liste. |
| `Combobox.Status` | Conteneur stylisé pour les messages de chargement, d’erreur ou d’aide de l’application. |
| `Combobox.List` | Conteneur de la liste des options. |
| `Combobox.Option` | Ligne prête à l’emploi pour une option simple, avec texte et indicateur. |
| `Combobox.Item` | Option sélectionnable de la liste. |
| `Combobox.ItemText` | Slot du texte de l’élément. |
| `Combobox.ItemIndicator` | Slot de l’indicateur de sélection. |
| `Combobox.Context` | Accès à l’état actuel du composant sans ajouter d’éléments au DOM. |
| `Combobox.ItemContext` | Accès à l’état de l’élément courant sans ajouter d’éléments au DOM. |

`Combobox.RootProvider` conserve le style du composant racine et l’applique à un état créé avec `useCombobox` de moduix.
Accédez à l’état du composant `Combobox` dans l’arbre avec `Combobox.Context` ou `useComboboxContext`. Pour l’état d’un élément,
utilisez `Combobox.ItemContext` ou `useComboboxItemContext`.

## Composition

La racine place automatiquement `Positioner` dans un portail. Définissez `portalled={false}` pour afficher la liste dans l’arbre
courant, ou transmettez `portalRef` pour cibler un conteneur précis. Vous devez malgré tout déclarer `Positioner` et `Content`
explicitement, et chaque partie peut être stylisée séparément.

### Composition recommandée

Utilisez `createListCollection` pour des données statiques. Utilisez `useListCollection` lorsque le filtrage ou d’autres mises à jour
modifient la collection. Pour une collection d’objets, définissez `itemToString` et `itemToValue`.

Gardez `Combobox.Positioner` et `Combobox.Content` dans votre JSX. `Content` est la partie de contenu fournie par Ark ;
le composant racine gère uniquement le conteneur dans lequel elle est rendue.

Si cette structure se répète, extrayez-la dans un petit composant utilitaire local. Pour les options simples, choisissez
`Combobox.Option` ; réservez `Combobox.Item` aux liens, aux options complexes ou au placement personnalisé de l’indicateur :

```tsx
function FruitComboboxPopup({ items }: { items: Array<{ label: string; value: string }> }) {
  return (
    <Combobox.Positioner>
      <Combobox.Content>
        <Combobox.Empty>No fruits found.</Combobox.Empty>
        <Combobox.List>
          {items.map((item) => (
            <Combobox.Option key={item.value} item={item}>
              {item.label}
            </Combobox.Option>
          ))}
        </Combobox.List>
      </Combobox.Content>
    </Combobox.Positioner>
  );
}
```

### Quand créer une composition personnalisée

Contrôlez `value` et utilisez les fonctions de rappel Ark qui reçoivent l’objet `details` lorsque le reste de l’interface a besoin
des valeurs sélectionnées. Si l’état doit être créé en dehors de l’arbre rendu, créez-le avec `useCombobox` de moduix,
puis transmettez-le à `Combobox.RootProvider`. Pour l’état d’un élément, utilisez `Combobox.ItemContext` ou
`useComboboxItemContext`. N’importez d’Ark que les utilitaires de collection et les types absents de moduix.

En sélection multiple, `Combobox` ne fournit pas d’API de tags dédiée. Affichez les tags ou une autre représentation depuis
l’état contrôlé ; la sélection reste gérée par la propriété `multiple`.

Ark ne fournit pas de partie dédiée au statut du composant `Combobox`. `Combobox.Status` de moduix est un `div` stylisé pour les messages
de chargement, d’erreur ou d’aide de votre application. Il ne gère pas l’état de chargement ou d’erreur et n’ajoute aucun rôle ARIA.

### Propriétés par défaut

Par défaut, le contenu placé dans le portail est monté à la première ouverture, puis démonté après l’animation de fermeture.
Définissez `unmountOnExit={false}` pour le conserver après la première ouverture. Ne définissez les deux propriétés du cycle de vie
sur `false` que si un rendu initial immédiat est nécessaire.

| Élément | Valeur par défaut | Remarques |
| --- | --- | --- |
| `Combobox.Trigger` | chevron moduix | Utilisé si aucun enfant n’est fourni. |
| `Combobox.ClearTrigger` | icône de fermeture moduix | Utilisée si aucun enfant n’est fourni. |
| `Combobox.ItemIndicator` | icône de coche moduix | Utilisée si aucun enfant n’est fourni. |
| `Combobox.Option.indicator` | icône de coche | Transmettez `false` pour la masquer ou un nœud React pour la remplacer. |
| `Combobox` `portalled` | `true` | Place automatiquement `Positioner` dans un portail. |
| `Combobox` `portalRef` | - | Conteneur facultatif du portail. |
| `Combobox` `lazyMount` | `true` | Monte le contenu de la liste à la première ouverture. |
| `Combobox` `unmountOnExit` | `true` | Démonte le contenu de la liste après l’animation de fermeture. |
| largeur de `Combobox` | `16rem` (max. `100%`) | Largeur par défaut du composant racine stylé. |
| variables de `Combobox.Positioner` | variables d’exécution d’Ark | Utilise `--reference-width`, `--available-height` et `--transform-origin`. |

### Comportement

- La propriété `collection` est obligatoire.
- `value` et `defaultValue` sont des tableaux de chaînes, même en sélection unique.
- Dans `onValueChange(details)`, les valeurs actuelles se trouvent dans `details.value`.
- Dans `onInputValueChange(details)`, le texte se trouve dans `details.inputValue` et la cause du changement dans `details.reason`.
- `onOpenChange`, `onHighlightChange` et `onSelect` reçoivent les objets `details` au format Ark.
- Toutes les parties DOM d’Ark prennent en charge `asChild`. `Combobox.Option` fait exception : ce composant
  utilitaire pour les lignes simples n’accepte pas `asChild`.
- `Combobox.Input asChild` conserve le comportement du champ Ark, mais laisse le style visuel à l’élément enfant.
- La version actuelle d’Ark ne fournit pas de partie `HiddenInput` pour Combobox. Pour l’envoi natif du formulaire, utilisez les
  propriétés racine `name` et `form`.
- `Combobox.RootProvider` conserve le style du composant racine moduix et les réglages du portail pour un état Ark créé à l’extérieur.
  Utilisez `useCombobox`, `Combobox.Context`, `useComboboxContext`, `Combobox.ItemContext` et `useComboboxItemContext` de moduix.
- Le contexte d’état de `Field.Root` d’Ark est transmis via `Field.Root` de moduix, qui repose sur Ark. Utilisez ce composant
  lorsque le composant `Combobox` doit hériter de l’état du champ. `readOnly` et `required` conservent le comportement Ark.
- Utilisez `ids` lorsque des parties composées séparément doivent partager des identifiants d’accessibilité. `lazyMount` et
  `unmountOnExit` valent `true` par défaut, tandis que `present` permet de contrôler le cycle de présence d’Ark pour les animations de fermeture.
- `selectionBehavior` et `closeOnSelect` sont transmis sans modification. En sélection multiple, Ark efface le champ après la sélection.

### Migration depuis shadcn

Gardez l’API moduix alignée sur Ark et faites correspondre explicitement les fonctionnalités courantes de shadcn :

| Fonctionnalité shadcn | Équivalent moduix |
| --- | --- |
| `items` sur le composant racine | `createListCollection()` ou `useListCollection()`, puis `collection` |
| `itemToStringValue` | `itemToString` et généralement `itemToValue` sur la collection |
| `showClear` | Affichez `Combobox.ClearTrigger` si nécessaire |
| `ComboboxItem` simple | Utilisez `Combobox.Option` ; pour une structure personnalisée, `Combobox.Item` |
| Zone de tags intégrée | `value` contrôlée avec vos propres tags ou composition avec `TagsInput` |
| Enveloppe `ComboboxContent` | `Combobox.Positioner` et `Combobox.Content` explicites |

### Points d’accroche CSS

- Les parties Ark conservent `data-scope="combobox"` et leurs valeurs `data-part`. moduix ajoute des points d’accroche
  `data-slot` stables aux parties stylisées.
- Les slots stables comprennent `combobox-root`, `combobox-root-provider`, `combobox-label`,
  `combobox-control`, `combobox-input`, `combobox-clear-trigger`, `combobox-trigger`,
  `combobox-positioner`, `combobox-content`, `combobox-empty`, `combobox-status`, `combobox-list`,
  `combobox-item-group`, `combobox-item-group-label`, `combobox-item`, `combobox-item-text` et
  `combobox-item-indicator`. `Combobox.Option` réutilise les slots de l’élément sans ajouter de point d’accroche.
- Les attributs d’état Ark comprennent `data-state="open|closed"`, `data-focus`, `data-invalid`, `data-disabled`,
  `data-highlighted`, `data-empty`, `data-placement` et `data-side`.
- Les variables de positionnement Ark comprennent `--reference-width`, `--available-width`, `--available-height`,
  `--transform-origin`, `--z-index` et `--layer-index`. Le thème partagé définit des valeurs initiales neutres pour les outils
  de développement et le contenu non positionné, puis Ark les remplace par les mesures de `Positioner`.
