## Choisir le bon composant

Utilisez `Fieldset` lorsque plusieurs contrôles associés doivent former un groupe avec une légende commune, par exemple
pour des coordonnées ou des préférences de notification. Utilisez `Field` lorsqu’un seul contrôle a besoin de son propre
libellé, texte d’aide et message de validation.

## Exemple de base

Créez un groupe avec `Fieldset`, `Fieldset.Legend`, les contrôles associés et, si nécessaire, un texte d’aide ou un message
d’erreur. La syntaxe courte `<Fieldset>` est équivalente à `<Fieldset.Root>`. La forme `.Root` reste disponible pour
conserver la compatibilité avec l’API Ark.

## Anatomie

```text
Fieldset.Root | Fieldset.RootProvider
├─ Fieldset.Legend
├─ grouped controls
├─ Fieldset.HelperText (optional)
└─ Fieldset.ErrorText (optional)
```

| Partie                        | Rôle                                                                                              |
| ----------------------------- | ------------------------------------------------------------------------------------------------- |
| `Fieldset` / `Fieldset.Root`  | Crée l’état et rend un élément `fieldset` natif.                                                  |
| `Fieldset.RootProvider`       | Rend un `fieldset` natif avec l’état créé par `useFieldset`.                                      |
| `Fieldset.Context`            | Expose l’état courant du groupe aux descendants sans rendre d’élément DOM supplémentaire.       |
| `Fieldset.Legend`             | Élément `legend` natif qui fournit le nom accessible du groupe.                                   |
| `Fieldset.HelperText`         | Description associée à la racine via `aria-describedby`.                                         |
| `Fieldset.ErrorText`          | Message de validation annoncé via `aria-live="polite"` et rendu uniquement quand `invalid` vaut `true`. |

## Composition

### Composition recommandée

Gardez une seule `Fieldset.Legend` visible dans la racine, de préférence avant les contrôles. Passez `disabled`, `invalid` et
`id` directement à la racine. Ark utilise la légende comme nom accessible du groupe et relie le texte d’aide ainsi que le
message d’erreur actif au fieldset via `aria-describedby`.

`Fieldset.Root`, `Fieldset.RootProvider`, `Fieldset.Legend`, `Fieldset.HelperText` et `Fieldset.ErrorText` transmettent leur
`ref` aux éléments DOM qu’ils rendent. Utilisez `asChild` avec un seul enfant sémantique lorsque vous devez remplacer l’élément
HTML rendu par une partie.

### Quand créer une composition personnalisée

Utilisez `useFieldset` de `@moduix/react` avec `Fieldset.RootProvider` lorsque l’état doit être créé en dehors de l’arbre JSX
ou partagé avec des contrôles voisins et des composants réutilisables. Utilisez `useFieldsetContext()` ou passez une fonction
de rendu à `Fieldset.Context` dans un descendant qui doit lire cet état. N’utilisez pas `Fieldset.Root` avec `Fieldset.RootProvider`
pour une même instance d’état.

### Propriétés par défaut

| Partie | Propriété | Par défaut |
| ----------------- | --------- | ------------ |
| `Fieldset.Root`   | `disabled` | `false`     |
| `Fieldset.Root`   | `invalid`  | `false`     |

### Comportement

- `Fieldset.Legend` rend un `legend` natif, et non un conteneur supplémentaire.
- Le navigateur désactive les contrôles natifs contenus dans un `fieldset` avec `disabled`.
- Les composants `Field` d’Ark placés dans le `fieldset` héritent de son état `disabled`. Définissez `invalid` sur les composants
  `Field` imbriqués lorsque des contrôles individuels doivent aussi afficher leur propre état invalide.
- `Fieldset.ErrorText` n’est pas présent dans le DOM tant que `invalid` ne vaut pas `true`.
- Les longues légendes, le texte d’aide et les messages d’erreur passent à la ligne dans le `fieldset` sans déborder de son conteneur.
- `useFieldsetContext()` et `Fieldset.Context` fournissent aux descendants le même état Ark que `useFieldset`.
- Fieldset ne gère ni valeur, ni navigation au clavier, ni fonction de rappel, ni `HiddenInput` qui lui soit propre.
- La prop obsolète `render` et les exports plats tels que `FieldsetLegend` ne sont pas pris en charge. Utilisez `asChild` et les
  parties du namespace à la place.

### Points d’accroche CSS

Chaque partie DOM possède les attributs Ark `data-scope="fieldset"` et `data-part` correspondant à l’anatomie. La racine et
la légende exposent `data-disabled` et `data-invalid` ; moduix ajoute également les attributs `data-slot="fieldset-*"`.
Utilisez `className` pour les ajustements locaux et les variables `--moduix-fieldset-*` pour personnaliser le thème, notamment
l’espacement de la légende et les variables de bordure de la racine.
