## Référence de l’API

Ark UI ne fournit pas de primitive dédiée à la fermeture. moduix construit `CloseButton` à partir de l’[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) officielle et suit les recommandations d’Ark pour la [composition](https://ark-ui.com/docs/guides/composition), les [styles](https://ark-ui.com/docs/guides/styling) et les [refs](https://ark-ui.com/docs/guides/ref).

## Exemple de base

Utilisez `CloseButton` pour ajouter un bouton de fermeture à une notification, une carte, un panneau superposé
ou une autre surface d’interface. Reliez son gestionnaire `onClick` à l’état qui masque ou supprime cette surface.
Le composant rend un bouton sémantique, lui attribue un nom accessible par défaut et affiche l’icône `CloseIcon`,
mais il ne gère pas lui-même l’état de la surface.

## Anatomie

`CloseButton` expose une seule partie racine, suivant le modèle d’Ark.

```text
CloseButton / CloseButton.Root
└─ root[data-scope="close-button"][data-part="root"][data-slot="close-button-root"]
   └─ CloseIcon (par défaut) | enfants personnalisés
```

| Partie                             | Rôle                                                                          |
| ---------------------------------- | ----------------------------------------------------------------------------- |
| `CloseButton` / `CloseButton.Root` | Contrôle interactif de fermeture fondé sur la sémantique et l’accessibilité d’un bouton. |

## Composition

### Composition recommandée

Utilisez directement `CloseButton` lorsque le composant doit rendre un élément `<button>` natif. Il transmet les
props de bouton de l’Ark factory, les attributs HTML natifs, les gestionnaires d’événements et la `ref`.

### Quand utiliser un élément personnalisé

Utilisez `asChild` lorsqu’un autre composant bouton doit fournir le nœud DOM rendu. Passez un seul enfant et placez
le contenu de l’icône dans cet enfant.

Si un panneau superposé fournit déjà un bouton de fermeture, utilisez-le afin qu’il gère l’état de fermeture et le
retour du focus.

### Propriétés par défaut

| Propriété    | Valeur par défaut                          | Valeurs et remarques                                      |
| ------------ | ------------------------------------------ | -------------------------------------------------------- |
| `type`       | `button`                                   | S’applique uniquement au composant racine natif          |
| `aria-label` | `Close` si les deux attributs de nom sont absents | Préférez un libellé qui précise ce qui sera fermé |
| `children`   | `CloseIcon`                                      | Remplace le contenu par défaut                    |
| `asChild`    | `false`                                          | Utilise un seul enfant comme racine rendue        |

### Comportement

- `CloseButton` ne ferme aucun élément tout seul. Reliez `onClick` à votre logique ou utilisez le bouton de fermeture
  fourni par le panneau superposé.
- Si `aria-label` et `aria-labelledby` sont tous les deux absents, le nom accessible est `Close`. Dans une interface
  réelle, utilisez un libellé qui précise la surface concernée, par exemple `Dismiss notification`.
- Les propriétés `disabled` et `aria-disabled="true"` définissent `data-disabled` et bloquent l’activation par clic.
- La racine native utilise `type="button"` par défaut. Avec `asChild`, définissez vous-même `type` sur l’enfant,
  en particulier si le bouton se trouve dans un formulaire.
- Avec `asChild`, `disabled` est représenté par `aria-disabled="true"` et non par l’attribut natif `disabled`.
  L’activation par clic reste bloquée.
- Vous pouvez aussi utiliser `CloseButton.Root` ; cette forme est équivalente.

### Sélecteurs de style

- `data-scope="close-button"` identifie la famille du composant.
- `data-part="root"` identifie l’unique partie exportée.
- `data-slot="close-button-root"` fournit le sélecteur de slot stable de moduix.
- `data-disabled` indique un état désactivé normalisé pour `disabled` et `aria-disabled="true"`.
- `className` est combiné avec les styles par défaut du composant sur la racine.
- Les éléments SVG enfants directs utilisent `--moduix-close-button-icon-size` pour leur largeur et leur hauteur.
