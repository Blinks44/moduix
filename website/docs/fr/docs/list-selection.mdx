# List Selection

`useListSelection` gère les valeurs sélectionnées dans une `ListCollection`, tandis que votre
application garde la responsabilité du balisage et des interactions.

## Référence de l’API

<PrimitiveReference href="https://ark-ui.com/docs/collections/list-selection" />

Ce hook est fourni par Ark UI et n’est pas réexporté par Moduix. Importez-le depuis le point d’entrée
des collections correspondant au framework de votre application :

## API essentiel

### Configuration

| Option                    | Description                                                        | Valeur par défaut |
| ------------------------- | ------------------------------------------------------------------ | ----------------- |
| `collection`              | `ListCollection` dont les valeurs peuvent être sélectionnées.     | requis            |
| `selectionMode`           | `'single'`, `'multiple'`, `'extended'` ou `'none'`.               | `'single'`        |
| `deselectable`            | Autorise la désélection en sélectionnant à nouveau la valeur.     | `true`            |
| `initialSelectedValues`   | Valeurs initiales de la sélection non contrôlée.                  | `[]`              |
| `resetOnCollectionChange` | Efface la sélection lorsque la collection change.                 | `false`           |

`initialSelectedValues` est lu lors de la création de l’état de sélection. Utilisez ensuite
`setSelectedValues` ou une autre action pour modifier la sélection. Dans Solid, les propriétés d’état
sont des accessors : lisez-les avec `selection.selectedValues()` et `selection.isEmpty()`. Les actions
gardent la même forme d’appel qu’en React.

### État et actions

| API                                | Description                                                  |
| ---------------------------------- | ------------------------------------------------------------ |
| `selectedValues`                   | Valeurs actuellement sélectionnées.                          |
| `isEmpty`                          | Indique si aucune valeur n’est sélectionnée.                 |
| `firstSelectedValue`               | Première valeur sélectionnée dans l’ordre de la collection, ou `null`. |
| `lastSelectedValue`                | Dernière valeur sélectionnée dans l’ordre de la collection, ou `null`. |
| `isSelected(value)`                | Vérifie si une valeur est sélectionnée.                      |
| `canSelect(value)`                 | Vérifie si la valeur peut être sélectionnée dans ce mode.    |
| `isAllSelected()`                  | Vérifie si toutes les valeurs de la collection sont sélectionnées. |
| `isSomeSelected()`                 | Vérifie si au moins une valeur de la collection est sélectionnée. |
| `select(value, forceToggle?)`      | Sélectionne selon le mode actuel.                            |
| `deselect(value)`                  | Retire une valeur de la sélection.                           |
| `toggle(value)`                    | Inverse l’état de sélection d’une valeur.                    |
| `replace(value)`                   | Remplace la sélection par une valeur.                        |
| `extend(anchorValue, targetValue)` | Étend la sélection entre deux valeurs dans l’ordre de la collection. |
| `setSelectedValues(values)`        | Définit les valeurs sélectionnées selon le mode actuel.       |
| `clear()`                          | Vide la sélection lorsque `deselectable` vaut `true`.         |
| `resetSelection()`                 | Crée une sélection vide avec les paramètres actuels.          |

`replace(null)` laisse la sélection actuelle inchangée. Utilisez `resetSelection()` pour obtenir une
sélection vide même lorsque `deselectable` vaut `false`.

## Interactions et accessibilité

`useListSelection` n’écoute pas les événements de la souris ou du clavier et n’ajoute pas d’attributs
ARIA. Choisissez la sémantique adaptée à votre balisage :

- Utilisez des boutons natifs avec `aria-pressed` lorsque chaque option est un contrôle indépendant,
  comme dans les exemples.
- Gérez le focus, les raccourcis clavier et les messages d’état dans la couche d’interaction de
  l’application.
- Pour un clic avec Maj ou un autre geste de sélection par plage, conservez la valeur d’ancrage dans
  l’état de l’application et appelez `extend(anchorValue, targetValue)`. Pour une sélection avec une
  touche modificatrice, appelez `select(value, true)`.
- Utilisez `Listbox` lorsque les utilisateurs ont besoin d’un sélecteur classique avec la sémantique
  listbox et la navigation au clavier. `Select` et `Combobox` gèrent également leur propre sélection.

Lorsque la collection change, gardez `resetOnCollectionChange: false` si un filtrage temporaire doit
conserver la sélection. Pour un nouveau jeu de données, définissez-le sur `true`. Si des valeurs
supprimées ne doivent plus rester sélectionnées, filtrez-les avec `collection.has(value)` puis appelez
`setSelectedValues` dans un gestionnaire d’événement ou un effet, jamais pendant le rendu.
