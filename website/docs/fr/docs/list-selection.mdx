# List Selection

## Référence de l’API

<PrimitiveReference href="https://ark-ui.com/docs/collections/list-selection" />

Le hook `useListSelection` suit les valeurs sélectionnées dans une `ListCollection`. Utilisez-le
pour créer une liste personnalisée qui a besoin d’un état de sélection sans adopter un composant de
collection prêt à l’emploi. `Select`, `Combobox` et `Listbox` gèrent déjà la sélection. Vous n’avez
donc généralement pas besoin de ce hook avec ces composants.

Importez les utilitaires de collection depuis Ark UI :

```tsx
import { createListCollection, useListSelection } from '@ark-ui/react/collection';
```

Cet exemple utilise des boutons pour une courte liste d’options indépendantes. Le hook suit les
valeurs sélectionnées, tandis que votre interface gère l’affichage, les rôles sémantiques, le focus,
les interactions au clavier et les libellés accessibles.

Les boutons conviennent ici, car chaque option est une action indépendante et `aria-pressed` expose
son état de sélection. N’ajoutez pas `role="listbox"` à une structure personnalisée sans implémenter
aussi le modèle complet de navigation au clavier et de gestion du focus d’une listbox. Pour un
sélecteur d’options classique, utilisez [Listbox](/docs/listbox), qui fournit la sémantique d’une
listbox et les interactions au clavier.

## Configuration

| Propriété                 | Description                                                               | Valeur par défaut |
| ------------------------- | ------------------------------------------------------------------------- | ----------------- |
| `collection`              | Collection contenant les valeurs pouvant être sélectionnées.              | requis            |
| `selectionMode`           | `'single'`, `'multiple'`, `'extended'` ou `'none'`.                      | `'single'`        |
| `deselectable`            | Indique si la sélection peut être vidée en sélectionnant à nouveau la valeur actuelle. | `true` |
| `initialSelectedValues`   | Valeurs initiales de la sélection non contrôlée.                          | `[]`              |
| `resetOnCollectionChange` | Réinitialise la sélection en la vidant lorsque la collection change.      | `false`           |

`initialSelectedValues` n’est utilisée qu’à la création de l’état de sélection. Utilisez
`setSelectedValues` pour modifier la sélection après le montage. Le mode `extended` convient lorsque votre couche
d’interaction transmet les touches modificatrices à `select(value, true)` ; le hook ne gère pas lui-même les
événements de la souris ou du clavier.

## État

| Valeur               | Description                                           |
| -------------------- | ----------------------------------------------------- |
| `selectedValues`     | Tableau des valeurs actuellement sélectionnées.      |
| `isEmpty`            | Indique si aucune valeur n’est sélectionnée.          |
| `firstSelectedValue` | Première valeur sélectionnée dans l’ordre de la collection, ou `null`. |
| `lastSelectedValue`  | Dernière valeur sélectionnée dans l’ordre de la collection, ou `null`. |

## Méthodes de vérification

| Méthode             | Description                                                  |
| ------------------- | ------------------------------------------------------------ |
| `isSelected(value)` | Vérifie si une valeur est sélectionnée.                     |
| `canSelect(value)`  | Vérifie si la sélection est autorisée par le mode actuel.       |
| `isAllSelected()`   | Vérifie si tous les éléments de la collection sont sélectionnés. |
| `isSomeSelected()`  | Vérifie si au moins un élément de la collection est sélectionné. |

Utilisez `canSelect` avant d’exposer une action de sélection personnalisée lorsque `selectionMode`
peut valoir `'none'`.

## Actions

| Méthode                             | Description                                                        |
| ---------------------------------- | ------------------------------------------------------------------ |
| `select(value, forceToggle?)`      | Sélectionne une valeur selon le mode actuel.                       |
| `deselect(value)`                  | Désélectionne une valeur.                                         |
| `toggle(value)`                    | Inverse l’état de sélection d’une valeur.                         |
| `replace(value)`                   | Remplace la sélection par une valeur. Avec `null`, elle reste inchangée. |
| `extend(anchorValue, targetValue)` | Étend la sélection entre deux valeurs dans l’ordre de la collection. |
| `setSelectedValues(values)`        | Définit la sélection avec les valeurs fournies, selon le mode actuel. |
| `clear()`                          | Vide la sélection lorsque `deselectable` vaut `true`.             |
| `resetSelection()`                 | Vide la sélection et la recrée avec les paramètres actuels.       |

`clear()` respecte `deselectable`. Utilisez `resetSelection()` pour obtenir une sélection vide même
lorsque `deselectable` vaut `false`.

## Sélection multiple

```tsx
import { createListCollection, useListSelection } from '@ark-ui/react/collection';
import { Button } from '@moduix/react/button';

const teams = createListCollection({
  items: [
    { label: 'Platform', value: 'platform' },
    { label: 'Product', value: 'product' },
    { label: 'Design', value: 'design' },
  ],
});

function TeamSelectionActions() {
  const selection = useListSelection({
    collection: teams,
    selectionMode: 'multiple',
    initialSelectedValues: ['platform'],
  });

  function toggleAll() {
    if (selection.isAllSelected()) {
      selection.clear();
      return;
    }

    selection.setSelectedValues(teams.getValues());
  }

  return (
    <Button type="button" onClick={toggleAll}>
      {selection.isAllSelected() ? 'Clear all' : 'Select all'}
    </Button>
  );
}
```

Définissez `selectionMode` sur `'multiple'` lorsque plusieurs valeurs peuvent être sélectionnées
simultanément. L’exemple utilise `isAllSelected()` pour choisir entre vider la sélection et
sélectionner toutes les valeurs.

Le hook suit uniquement l’état de sélection et ne désactive donc pas vos contrôles. Désactivez-les à
partir de l’état de l’élément dans la collection, comme dans l’exemple de base. Lorsque vous appelez
`setSelectedValues` avec des valeurs externes, vérifiez-les avec `collection.has` et
`collection.getItemDisabled` si les éléments désactivés doivent être exclus.

## Sélection par plage

Conservez la valeur d’ancrage dans votre logique d’interaction, puis appelez `extend` lorsque
l’utilisateur sélectionne une plage :

```tsx
import { useRef } from 'react';
import { useListSelection, type ListCollection } from '@ark-ui/react/collection';

type Team = {
  label: string;
  value: string;
};

function useRangeSelection(collection: ListCollection<Team>) {
  const selection = useListSelection({
    collection,
    selectionMode: 'multiple',
  });
  const anchorRef = useRef<string | null>(null);

  function handleSelect(value: string, withRange: boolean) {
    if (withRange && anchorRef.current) {
      selection.extend(anchorRef.current, value);
      return;
    }

    selection.replace(value);
    anchorRef.current = value;
  }

  return { selection, handleSelect };
}
```

Associez `withRange` à un clic avec la touche Maj ou à un autre geste de sélection par plage. La sélection par
plage au clavier nécessite aussi la gestion du focus et des touches Maj + Flèche. Si vous avez besoin
d’une listbox conforme à ARIA, utilisez [Listbox](/docs/listbox) et laissez-le gérer ces interactions.

## Mise à jour de la collection

Définissez `resetOnCollectionChange: true` lorsque la nouvelle collection représente un autre jeu de
données et que l’ancienne sélection ne doit pas être conservée.

Gardez la valeur par défaut `false` lorsque le filtrage masque temporairement des éléments et que la
sélection doit être conservée malgré le filtre. Si la collection supprime des valeurs qui ne doivent
plus rester sélectionnées, filtrez les valeurs sélectionnées et transmettez le résultat à
`setSelectedValues` :

```tsx
const validValues = selection.selectedValues.filter((value) => collection.has(value));

selection.setSelectedValues(validValues);
```

Effectuez cette synchronisation dans un gestionnaire d’événement ou un effet lorsque la collection
change, jamais pendant le rendu.
