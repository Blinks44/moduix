# List Selection

## API

<PrimitiveReference href="https://ark-ui.com/docs/collections/list-selection" />

`useListSelection` ajoute un état de sélection à un `ListCollection`. Utilisez-le pour les listes
personnalisées qui ne gèrent pas encore la sélection. `Select`, `Combobox` et `Listbox` gèrent leur
propre sélection et n’ont normalement pas besoin de ce hook.

```tsx
import { createListCollection, useListSelection } from '@ark-ui/react/collection';
```

## Sélection unique

```tsx preview file="../../en/docs/_snippets/list-selection/basic.tsx"

```

Cet exemple présente une sélection unique. Le hook gère uniquement les valeurs de sélection. Votre
interface reste en charge des rôles sémantiques, des interactions au clavier, du focus et des
libellés accessibles. Préférez `Listbox` pour le comportement standard d’une listbox.

L’exemple avec des boutons convient, car chaque option peut être activée ou désactivée
indépendamment. N’ajoutez pas `role="listbox"` à une structure personnalisée sans aussi implémenter
le modèle complet de navigation au clavier et de focus d’une listbox. Pour une liste d’options
classique, utilisez [Listbox](https://moduix.dev/docs/listbox) et laissez-le gérer ce comportement.

## Configuration

| Propriété | Objectif | Valeur par défaut |
| ------------------------- | ---------------------------------------------- | ---------- |
| `collection` | Collection dont les valeurs peuvent être sélectionnées. | requis |
| `selectionMode` | `'single'`, `'multiple'` ou `'none'`. | `'single'` |
| `deselectable` | Permet de désélectionner la sélection actuelle. | `true` |
| `initialSelectedValues` | Valeurs initiales pour une sélection non contrôlée. | `[]` |
| `resetOnCollectionChange` | Efface la sélection lorsque la collection change. | `false` |

`initialSelectedValues` définit uniquement l’état initial. Utilisez `setSelectedValues` lorsque la
sélection doit changer après le montage.

## État

| Valeur | Signification |
| -------------------- | ---------------------------------------------------- |
| `selectedValues` | Valeurs sélectionnées dans l'ordre de sélection. |
| `isEmpty` | Aucune valeur n'est sélectionnée. |
| `firstSelectedValue` | Première valeur sélectionnée dans l'ordre de la collection, ou `null`. |
| `lastSelectedValue` | Dernière valeur sélectionnée dans l'ordre de la collection, ou `null`. |

## Vérifications

| Méthode | Objectif |
| ------------------- | ------------------------------------------------------------ |
| `isSelected(value)` | Vérifie si une valeur est sélectionnée. |
| `canSelect(value)` | Vérifie le mode, l'état désactivé et si la sélection est valide. |
| `isAllSelected()` | Vérifie si chaque élément de collection est sélectionné. |
| `isSomeSelected()` | Vérifie si au moins un élément de collection est sélectionné. |

Utilisez `canSelect` avant d’afficher des actions de sélection personnalisées que l’interface ne
désactive pas déjà.

## Actions

| Méthode | Objectif |
| ---------------------------------- | ------------------------------------------------------- |
| `select(value, forceToggle?)` | Sélectionne une valeur selon le mode actuel. |
| `deselect(value)` | Supprime une valeur sélectionnée. |
| `toggle(value)` | Bascule une valeur. |
| `replace(value)` | Remplace la sélection par une valeur, ou l'efface avec `null`. |
| `extend(anchorValue, targetValue)` | Sélectionne la plage de la collection entre deux valeurs. |
| `setSelectedValues(values)` | Remplace la sélection par des valeurs explicites. |
| `clear()` | Efface la sélection actuelle. |
| `resetSelection()` | Recrée une sélection vide avec les paramètres actuels. |

## Sélection multiple

```tsx
import { Button } from '@moduix/react/button';

function TeamSelectionActions() {
  const selection = useListSelection({
    collection,
    selectionMode: 'multiple',
    initialSelectedValues: ['platform'],
  });

  function toggleAll() {
    if (selection.isAllSelected()) {
      selection.clear();
      return;
    }

    selection.setSelectedValues(collection.getValues());
  }

  return (
    <Button type="button" onClick={toggleAll}>
      {selection.isAllSelected() ? 'Clear all' : 'Select all'}
    </Button>
  );
}
```

Les valeurs désactivées ne peuvent pas être sélectionnées avec `select` ou `toggle`. Lorsque vous
définissez directement des valeurs, filtrez les données externes avec `selection.canSelect`, sauf si
elles sont déjà fiables.

## Sélection par plage

Conservez une valeur d’ancrage dans votre logique d’interaction, puis étendez la sélection à partir
de cette valeur :

```tsx
import { useRef } from 'react';

function useRangeSelection() {
  const selection = useListSelection({
    collection,
    selectionMode: 'multiple',
  });
  const anchorRef = useRef<string | null>(null);

  function handleSelect(value: string, extend: boolean) {
    if (extend && anchorRef.current) {
      selection.extend(anchorRef.current, value);
      return;
    }

    selection.replace(value);
    anchorRef.current = value;
  }

  return { selection, handleSelect };
}
```

Avec une souris, `extend` correspond généralement à Maj + clic. La sélection par plage au clavier
nécessite aussi de gérer le focus et les touches Maj + flèche ; utilisez un composant de collection
lorsque cette interaction suit un modèle ARIA établi.

## Mise à jour de la collection

Définissez `resetOnCollectionChange: true` lorsqu’une nouvelle collection représente un autre jeu de
données et que les anciennes valeurs ne doivent jamais être conservées.

Conservez la valeur par défaut `false` lorsque le filtrage ne masque les éléments que temporairement
et que la sélection doit être conservée malgré le filtre. Si des valeurs supprimées doivent être
retirées de la sélection, déterminez celles qui restent valides et appelez `setSelectedValues` :

```tsx
const validValues = selection.selectedValues.filter((value) => collection.has(value));

selection.setSelectedValues(validValues);
```

Exécutez cette synchronisation dans un gestionnaire d’événement ou un effet lorsque la collection
change, jamais pendant le rendu.
