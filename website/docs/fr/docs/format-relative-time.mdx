## Quand l’utiliser

Utilisez `Format.RelativeTime` lorsque la proximité avec le moment présent est plus utile qu’un horodatage exact : flux
d’activité, états de sauvegarde, échéances et événements à venir. Passez un objet `Date` à `value`. Lors du rendu, Ark
compare cette date à l’heure actuelle, choisit une unité adaptée, des secondes aux années, puis formate le résultat
avec `Intl.RelativeTimeFormat`.

Par défaut, `numeric` vaut `"always"` : le résultat reste numérique, par exemple « dans 12 minutes » ou « il y a 1 jour ».
Définissez `numeric="auto"` pour autoriser des formulations naturelles comme « demain » et « hier ».

Importez `Format` directement depuis Ark UI :

```tsx
import { Format } from '@ark-ui/react';
```

## Locale

`Format.RelativeTime` lit sa locale depuis `LocaleProvider`. Sans `LocaleProvider`, Ark utilise `en-US`. moduix
réexporte `LocaleProvider`, vous pouvez donc utiliser un seul `LocaleProvider` pour définir la locale du temps relatif
et d’autres composants qui en tiennent compte :

```tsx
import { Format } from '@ark-ui/react';
import { LocaleProvider } from '@moduix/react/locale';

const lastUpdatedAt = new Date(Date.now() - 24 * 60 * 60 * 1000);

export function LocalizedUpdate() {
  return (
    <LocaleProvider locale="fr-FR">
      <Format.RelativeTime numeric="auto" value={lastUpdatedAt} />
    </LocaleProvider>
  );
}
```

## Options d’affichage

`Format.RelativeTime` accepte les options standard de `Intl.RelativeTimeFormat`. Les plus utiles sont les suivantes :

| Option    | Valeurs                                    | Rôle                                         |
| --------- | ------------------------------------------ | -------------------------------------------- |
| `numeric` | `"always"` (par défaut), `"auto"`          | Choisir les nombres ou des formulations naturelles. |
| `style`   | `"long"` (par défaut), `"short"`, `"narrow"` | Contrôler la longueur du résultat.          |

Vous n’avez pas à fournir séparément l’unité et la valeur numérique. Le composant les déduit du `Date` passé à
`value`.

## Mise à jour dans le temps

`Format.RelativeTime` ne démarre pas de minuteur. Il calcule le texte au rendu et le conserve jusqu’au rendu suivant de
votre application. Si un libellé doit rester à jour, déclenchez de nouveaux rendus à une fréquence adaptée à
l’interface. Pour une durée ou un compte à rebours mis à jour en continu, utilisez [`Timer`](/docs/timer).

## Utilisation avec moduix

`Format.RelativeTime` ne rend que du texte, sans ajouter d’élément autour. Placez-le dans le composant de mise en page,
de statut ou d’affichage des données qui explique à quoi le temps relatif se rapporte. Les exemples de cette page utilisent
`Card` et `Stack` de moduix pour fournir ce contexte.

Le formateur vient d’Ark UI et s’importe depuis `@ark-ui/react`. moduix fournit les composants qui l’entourent et
réexporte `LocaleProvider`, mais ne réexporte pas `Format.RelativeTime`.
