Utilisez `ToggleGroup` comme racine et ajoutez un `ToggleGroupItem` pour chaque choix. Donnez au groupe
un nom accessible avec `aria-label` ou `aria-labelledby`.

## Choisir le bon composant

Utilisez `ToggleGroup` lorsque plusieurs boutons à bascule doivent former un seul contrôle navigable au
clavier. Le groupe peut autoriser une seule valeur sélectionnée ou plusieurs.

- Choisissez **`ToggleGroup`** pour les contrôles segmentés, les ensembles de filtres compacts et les barres d’outils de mise en forme.
- Choisissez **`Toggle`** pour une seule action autonome à deux états.
- Choisissez **`Tabs`** lorsque la sélection doit également afficher le panneau associé.
- Choisissez **`RadioGroup`** lorsque les choix sont des options de formulaire et doivent s’intégrer aux formulaires natifs.

## Composition

`ToggleGroup` s’appuie sur la primitive Toggle Group d’Ark UI et ajoute les props visuelles de moduix
pour les variantes et les tailles. Importez-le depuis le package du framework correspondant :
`@moduix/react/toggle-group`, `@moduix/solid/toggle-group`, `@moduix/react-tailwind/toggle-group`
ou `@moduix/solid-tailwind/toggle-group`. Les packages Vue sont `@moduix/vue/toggle-group` et
`@moduix/vue-tailwind/toggle-group`.

Utilisez `defaultValue` pour un groupe non contrôlé, ou `value` avec `onValueChange(details)` lorsque
la sélection est gérée par une autre partie de l’application React ou Solid. Dans Vue, utilisez
`v-model` et `@value-change` pour recevoir les détails Ark ; dans le script, accédez au store par
`.value`. Les valeurs sélectionnées sont des `string[]`, en
sélection unique comme en sélection multiple. Utilisez `ToggleGroupRootProvider` avec
`useToggleGroup()` du package correspondant lorsque l’état doit être créé en dehors de l’arbre rendu.
React lit le store comme un objet, Solid lit son état réactif via l’accesseur retourné, et Vue expose
directement le store réactif dans les expressions du template Vue.

Utilisez `ToggleGroupContext` ou `useToggleGroupContext()` lorsqu’un élément personnalisé a besoin de
l’état actuel du groupe. Avec `asChild`, React reçoit un enfant qui se comporte comme un bouton,
Solid reçoit une fonction de rendu qui retourne l’élément portant le comportement Ark, et
Vue reçoit un seul élément enfant. Ne rendez pas
`ToggleGroup` et `ToggleGroupRootProvider` pour la même instance d’état.

## Anatomie

```text
ToggleGroup
├─ ToggleGroupContext (facultatif)
└─ ToggleGroupItem[value]

ToggleGroupRootProvider
└─ ToggleGroupItem[value]
```

| Partie                    | Rôle                                                                                   |
| ------------------------- | -------------------------------------------------------------------------------------- |
| `ToggleGroup`             | Partie racine qui gère les valeurs sélectionnées, le focus, l’orientation et l’état désactivé. |
| `ToggleGroupItem`         | Élément interactif avec un `value` obligatoire et l’état de sélection géré par Ark.    |
| `ToggleGroupRootProvider` | Relie l’arbre des éléments à l’état créé avec `useToggleGroup()`.                      |
| `ToggleGroupContext`      | Expose l’état actuel du groupe via une fonction de rendu ou un slot avec portée Vue.    |

## Styles

Utilisez `className` en React ou `class` en Solid et Vue sur les parties exportées pour les styles structurels.
Les variantes Tailwind utilisent les utilitaires natifs et les classes du consommateur ; les variantes
CSS Modules exposent les tokens `--moduix-toggle-group-*`. Les éléments héritent de `variant` et de
`size` depuis la racine et peuvent remplacer l’une de ces props lorsqu’un élément doit avoir un style différent.

### Points d’accroche CSS

| Partie | `data-slot` |
| --- | --- |
| `ToggleGroup` | `toggle-group-root` |
| `ToggleGroupRootProvider` | `toggle-group-root-provider` |
| `ToggleGroupItem` | `toggle-group-item` |

- Sélecteurs des parties Ark : `data-scope="toggle-group"` et `data-part="root" | "item"`.
- Sélecteurs d’état Ark : `data-state="on" | "off"`, `data-disabled`, `data-focus` et
  `data-orientation="horizontal" | "vertical"`.
- Sélecteurs moduix : `data-variant` et `data-size`.

## Clavier

| Touche | Action |
| --- | --- |
| `ArrowLeft` / `ArrowRight` | Déplace le focus entre éléments ; ArrowUp et ArrowDown en vertical. |
| `Home` / `End` | Déplace le focus vers le premier ou le dernier élément. |
| `Enter` / `Space` | Enfonce ou relâche l’élément ayant le focus. |
