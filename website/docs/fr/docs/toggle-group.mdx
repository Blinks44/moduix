## Choisir le bon composant

Utilisez `ToggleGroup` lorsque plusieurs boutons activés appartiennent au même ensemble de valeurs.

- Choisissez **`ToggleGroup`** pour les contrôles segmentés, les ensembles de filtres compacts et les barres de mise en forme.
- Choisissez **`Toggle`** pour une action autonome à deux états.
- Choisissez **`Tabs`** si la sélection change également les panneaux associés.
- Choisissez **`RadioGroup`** si les choix doivent prendre la forme d’options de formulaire.

## Anatomie

```text
ToggleGroup / ToggleGroup.Root
├─ ToggleGroup.Context (facultatif)
└─ ToggleGroup.Item[value]

ToggleGroup.RootProvider
└─ ToggleGroup.Item[value]
```

| Partie                              | Rôle                                                                                                      |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `ToggleGroup` / `ToggleGroup.Root`  | Machine à états racine pour les valeurs sélectionnées, le focus mobile, l’orientation et la désactivation. |
| `ToggleGroup.Item`                  | Bouton d’élément avec un `value` obligatoire et l’état Ark `data-state` activé ou désactivé.              |
| `ToggleGroup.RootProvider`          | Racine pilotée par une instance d’état `useToggleGroup()` créée hors de l’arbre rendu.                    |
| `ToggleGroup.Context`               | Accès par render prop à l’état actuel du groupe.                                                          |

## Composition

### Composition recommandée

Utilisez `ToggleGroup` comme composant racine et `ToggleGroup.Item` pour chaque bouton. `value` et
`defaultValue` sont des tableaux de chaînes dans les modes de sélection unique et multiple.

moduix ajoute deux props visuelles à `ToggleGroup`, `ToggleGroup.Root`, `ToggleGroup.RootProvider` et
`ToggleGroup.Item` :

| Prop      | Valeur par défaut | Valeurs                                                 |
| --------- | ----------------- | ------------------------------------------------------- |
| `variant` | `default`         | `default`, `outline`, `ghost`                           |
| `size`    | `md`              | `xs`, `sm`, `md`, `lg`, `icon-sm`, `icon-md`, `icon-lg` |

Les éléments héritent de `variant` et de `size` depuis la racine. Définissez l’une de ces props sur
un élément uniquement lorsqu’un contrôle doit recevoir une personnalisation visuelle intentionnelle.

### Quand créer une composition personnalisée

Utilisez `asChild` sur `ToggleGroup.Item` lorsqu’un autre bouton sémantique doit posséder l’élément rendu.
Conservez un seul enfant assimilable à un bouton afin qu’Ark puisse lui associer les props d’interaction et l’état ARIA.

Utilisez `ToggleGroup.RootProvider` avec `useToggleGroup()` de moduix lorsque l’état doit être créé hors du composant
racine rendu. Utilisez `useToggleGroupContext()` de moduix sous la racine ou le provider lorsqu’un composant
personnalisé a besoin de l’état actuel du groupe. Ne rendez pas `ToggleGroup.Root` et `ToggleGroup.RootProvider` pour
la même instance d’état. Les imports directs depuis Ark restent une échappatoire pour les surfaces volontairement
hors de l’API moduix.

### Propriétés par défaut

| Prop          | Valeur par défaut | Remarques                                                                                  |
| ------------- | ----------------- | ------------------------------------------------------------------------------------------ |
| `deselectable`| `true`            | Autorise une sélection vide lorsque `multiple` n’est pas activé.                           |
| `loopFocus`   | `true`            | Fait passer le focus par les flèches du dernier élément au premier et inversement.          |
| `orientation` | `horizontal`      | Contrôle l’axe de la disposition et la navigation clavier correspondante.                  |
| `rovingFocus` | `true`            | Utilise un tab index mobile afin qu’un seul élément participe à l’ordre de tabulation.      |
| `multiple`    | `false`           | Autorise plusieurs éléments à rester activés simultanément.                                |
| `variant`     | `default`         | Variante visuelle moduix.                                                                  |
| `size`        | `md`              | Taille d’élément moduix.                                                                    |

### Comportement

- `onValueChange` reçoit les détails Ark : utilisez `details.value` pour obtenir le tableau de chaînes sélectionnées.
- `deselectable` est ignoré lorsque `multiple` est activé.
- Le groupe a besoin d’un nom accessible fourni par `aria-label` ou `aria-labelledby`.
- Les éléments qui n’affichent qu’une icône ont besoin de leur propre nom accessible, par exemple `aria-label="Align left"`.
- Utilisez `disabled` sur le groupe pour désactiver l’ensemble ou sur un élément pour rendre un choix précis indisponible.
- Utilisez `ids` pour définir des ID stables pour la racine et les éléments lorsque le groupe est composé avec une autre interface accessible.
- Les groupes à sélection unique utilisent les sémantiques `radiogroup`/`radio` ; ceux à sélection multiple utilisent `group` et `aria-pressed`.
- Les groupes horizontaux utilisent les flèches gauche/droite, les groupes verticaux les flèches haut/bas, et Home/End déplacent le focus vers le premier ou le dernier élément disponible. Espace/Entrée activent le bouton ayant le focus, tandis que `loopFocus` contrôle le bouclage de la navigation par flèches.
- Ark expose `data-scope="toggle-group"`, `data-part`, `data-orientation`, `data-disabled`, `data-focus` et `data-state="on" | "off"` sur les éléments pour la mise en forme.
- Les groupes horizontaux défilent lorsqu’ils dépassent la largeur du conteneur, au lieu de revenir à la ligne et de modifier la disposition de la navigation clavier.

## Styles

`ToggleGroup` fournit des hooks `data-slot` stables pour moduix ainsi que les attributs d’anatomie et d’état d’Ark
pour la mise en forme fondée sur le comportement.

Le tableau couvre les propriétés de groupe. Chaque `ToggleGroup.Item` prend également en charge les
[propriétés CSS de Toggle](/docs/toggle#css-properties) pour ses couleurs et ses états d’interaction.
Définissez une propriété `--moduix-toggle-*` sur la racine pour styliser tous les éléments, ou sur un
élément pour ne remplacer qu’un seul contrôle.

### Points d’accroche CSS

- `data-slot="toggle-group-root"` et `data-slot="toggle-group-root-provider"` - sélecteurs stables de la racine.
- `data-slot="toggle-group-item"` - sélecteur stable d’un élément.
- `data-scope="toggle-group"` et `data-part="root" | "item"` sont fournis par Ark.
- `data-state="on" | "off"` est exposé sur chaque élément.
- `data-orientation="horizontal" | "vertical"` est exposé sur la racine et ses enfants.
- `data-disabled` et `data-focus` sont des attributs d’état Ark.
- `data-variant` et `data-size` reflètent les props visuelles moduix.
