# Collections

Les collections Ark UI constituent la couche de données des interfaces à base de listes. Elles décrivent l’identité,
les libellés, l’état désactivé et l’ordre de parcours des éléments ; les composants moduix affichent l’interaction
accessible à partir de ces données.

Utilisez une collection lorsque les données sont partagées par `Select`, `Combobox`, `Listbox`, `TreeView` ou une
liste personnalisée. Ces API s’importent directement depuis Ark UI, et les pages associées montrent comment les
relier aux composants moduix.
