# Collections

Les collections forment la couche de données des composants Ark UI qui affichent des listes. Elles ne font pas
partie des composants moduix stylisés. Pour utiliser `Select`, `Combobox`, `Listbox`, `TreeView` ou une interface
personnalisée basée sur des collections, importez-les directement depuis Ark UI.

Puisque votre application utilise Ark UI directement, ajoutez-le aux dépendances directes :

```bash
npm install @ark-ui/react
```

Toutes les API de collection présentées ici sont disponibles depuis le point d’entrée React des collections :

```tsx
import { createListCollection } from '@ark-ui/react/collection';
```

Le flux suit généralement ce chemin :

```text
éléments de l’application → collection Ark → composant moduix → sélection de l’utilisateur
```

Une collection unifie l’identité, le texte, l’état désactivé et l’ordre de parcours des éléments. Le composant
moduix affiche une interface accessible et gère le focus ainsi que la sélection.

## Choisir une collection

Choisissez l’API selon la façon dont vos données sont stockées et mises à jour :

- Commencez par `createListCollection` pour un tableau fixe d'options.
- Utilisez `useListCollection` lorsque la liste doit être filtrée ou modifiée depuis l'état React.
- Utilisez `createTreeCollection` pour des données imbriquées.
- Utilisez `useAsyncList` lorsqu'un serveur gère le chargement, le filtrage, le tri ou la pagination.
- Utilisez `useListSelection` pour la sélection dans une liste personnalisée. Les composants de collection moduix
  gèrent déjà leur propre état de sélection.

Les collections normalisent l'identité et le texte des éléments, mais n'affichent pas d'interface. Passez la
collection obtenue au composant moduix correspondant :

- [Select](https://moduix.dev/docs/select)
- [Combobox](https://moduix.dev/docs/combobox)
- [Listbox](https://moduix.dev/docs/listbox)
- [Tree View](https://moduix.dev/docs/tree-view)

## Responsabilités

Ark UI est responsable de ces API et de leur cycle de publication. moduix utilise les objets de collection obtenus
sans les encapsuler ni les réexporter. Les pages suivantes décrivent les scénarios utiles aux utilisateurs de moduix
et renvoient en haut de page vers la référence Ark correspondante.
