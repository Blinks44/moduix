# Collections

Les collections sont des structures de données et des hooks pour les interfaces à base de listes. Elles regroupent
les valeurs et les libellés des éléments, leur état désactivé, la hiérarchie et l’état du chargement asynchrone dans
un format exploitable par les composants Ark UI. Elles ne rendent pas l’interface elles-mêmes : les composants moduix
fournissent l’interaction accessible autour de ces données.

Utilisez une collection avec `Select`, `Combobox`, `Listbox`, `TreeView`, une liste personnalisée ou une arborescence.
Les utilitaires de collection s’importent directement depuis Ark UI. Les guides ci-dessous montrent comment créer et
mettre à jour les collections, les relier aux composants moduix et gérer le chargement ou la sélection.
