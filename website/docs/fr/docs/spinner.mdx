## Référence de l’API

Ark UI ne propose pas de composant Spinner dédié. moduix construit `Spinner` avec la fabrique `ark.span` d’Ark UI
et expose une API réduite centrée sur une seule racine. Le composant suit les recommandations d’Ark pour la
[composition](https://ark-ui.com/docs/guides/composition), le [style](https://ark-ui.com/docs/guides/styling) et le
[transfert de `ref`](https://ark-ui.com/docs/guides/ref).


Les mêmes exports sont disponibles depuis `@moduix/solid/spinner` pour Solid et `@moduix/vue/spinner` pour Vue.
## Exemple de base

Utilisez `Spinner` pour les états de chargement de courte durée dans les boutons, les lignes de statut et les petits
blocs vides. Par défaut, le composant signale le chargement aux technologies d’assistance avec `role="status"` et
le libellé de secours `aria-label="Loading"`. Ce libellé est la chaîne anglaise `Loading` ; dans une interface non
anglophone, fournissez un `aria-label` localisé ou utilisez `aria-labelledby`.

Avec `prefers-reduced-motion: reduce`, le spinner cesse de tourner : le token de la fondation
`--moduix-animation-spin` devient `none`. Pour garder la rotation d’un spinner précis, définissez `animation`
sur son `[data-slot="spinner-indicator"]` dans votre propre classe.

Définissez `decorative` lorsqu’un texte visible décrit déjà le chargement : la racine reçoit alors
`aria-hidden="true"`, sans `role` ni libellé de repli.

## Anatomie

`Spinner` n’expose qu’une racine publique. En mode standard, moduix ajoute une enveloppe interne pour l’indicateur
et un anneau par défaut. Ce sont des nœuds DOM et des points d’accroche CSS, pas des composants exportés séparément.
Un contenu personnalisé passé via `children` remplace l’anneau ; `asChild` remplace la racine et laisse l’enfant fournir la structure
de l’indicateur.

```text
Spinner
└─ root[data-scope="spinner"][data-part="root"][data-slot="spinner-root"][data-size]
   └─ indicator[data-scope="spinner"][data-part="indicator"][data-slot="spinner-indicator"]
      └─ ring[data-scope="spinner"][data-part="ring"][data-slot="spinner-ring"] (par défaut uniquement)
```

| Partie              | Rôle                                                                                                        |
| ------------------- | ----------------------------------------------------------------------------------------------------------- |
| `Spinner`                   | Racine publique. Accepte `size`, `decorative`, `asChild`, `children` et les propriétés natives de `span`. |
| indicator                  | Enveloppe interne rotative qui gère la taille et l’animation de l’indicateur.                     |
| ring                       | Anneau par défaut interne. Il n’est pas rendu lorsqu’un contenu personnalisé est fourni via `children`. |

## Composition

`Spinner` représente un état de chargement géré par l’application ; il ne démarre, n’arrête et ne contrôle pas l’opération représentée. Rendez-le à partir de l’état qui possède déjà cette opération.

Passez des `children` personnalisés pour remplacer l’anneau par défaut tout en conservant la racine standard, le dimensionnement et le conteneur rotatif de l’indicateur. Utilisez `asChild` uniquement lorsqu’un autre composant doit porter l’élément racine : dans ce mode, l’indicateur et l’anneau intégrés ne sont pas rendus ; un seul enfant non interactif doit donc fournir le balisage visuel de l’indicateur.

## Styles

Appliquez des styles à `Spinner` avec `className` en React, `class` en Solid et Vue, les sélecteurs Ark `data-scope` / `data-part`, les points d’accroche
`data-slot` stables, `data-size` et les variables publiques `--moduix-spinner-*` décrites dans l’API CSS.

### Points d’accroche CSS

- `[data-scope="spinner"][data-part="root"]` cible la racine selon les conventions d’Ark.
- `[data-scope="spinner"][data-part="indicator"]` cible l’enveloppe interne rotative.
- `[data-scope="spinner"][data-part="ring"]` cible uniquement l’anneau par défaut.
- `data-slot="spinner-root"` est le sélecteur stable de moduix pour la racine rendue.
- `data-slot="spinner-indicator"` est le sélecteur stable de moduix pour l’enveloppe interne rotative.
- `data-slot="spinner-ring"` cible uniquement l’anneau par défaut.
- `Spinner` écrit `data-size="inherit" | "xs" | "sm" | "md" | "lg" | "xl"` sur la racine.
- `className` s’applique à la racine rendue. Avec `asChild`, il s’applique donc à l’unique enfant. Ciblez l’indicateur
  ou l’anneau avec des sélecteurs descendants si nécessaire.
