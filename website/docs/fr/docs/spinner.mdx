## Référence de l’API

Ark UI ne propose pas de composant Spinner dédié. moduix construit `Spinner` avec la fabrique `ark.span` d’Ark UI
et expose une API réduite centrée sur une seule racine. Le composant suit les recommandations d’Ark pour la
[composition](https://ark-ui.com/docs/guides/composition), le [style](https://ark-ui.com/docs/guides/styling) et le
[transfert de `ref`](https://ark-ui.com/docs/guides/ref).

## Exemple de base

Utilisez `Spinner` pour les états de chargement de courte durée dans les boutons, les lignes de statut et les petits
blocs vides. Par défaut, le composant signale le chargement aux technologies d’assistance avec `role="status"` et
le libellé de secours `aria-label="Loading"`. Ce libellé est la chaîne anglaise `Loading` ; dans une interface non
anglophone, fournissez un `aria-label` localisé ou utilisez `aria-labelledby`.

## Anatomie

`Spinner` n’expose qu’une racine publique. En mode standard, moduix ajoute une enveloppe interne pour l’indicateur
et un anneau par défaut. Ce sont des nœuds DOM et des points d’accroche CSS, pas des composants React exportés.
Un contenu personnalisé passé via `children` remplace l’anneau ; `asChild` remplace la racine et laisse l’enfant fournir la structure
de l’indicateur.

```text
Spinner / Spinner.Root
└─ root[data-scope="spinner"][data-part="root"][data-slot="spinner-root"][data-size]
   └─ indicator[data-scope="spinner"][data-part="indicator"][data-slot="spinner-indicator"]
      └─ ring[data-scope="spinner"][data-part="ring"][data-slot="spinner-ring"] (par défaut uniquement)
```

| Partie              | Rôle                                                                                                        |
| ------------------- | ----------------------------------------------------------------------------------------------------------- |
| `Spinner` / `Spinner.Root` | Racine publique. Accepte `size`, `decorative`, `asChild`, `children` et les propriétés natives de `span`. |
| indicator                  | Enveloppe interne rotative qui gère la taille et l’animation de l’indicateur.                     |
| ring                       | Anneau par défaut interne. Il n’est pas rendu lorsqu’un contenu personnalisé est fourni via `children`. |

## Composition

### Composition recommandée

Dans la plupart des cas, la forme courte `<Spinner />` suffit. Elle rend l’anneau par défaut et expose le statut
de chargement sans balisage supplémentaire.

- Utilisez `size` pour ajuster la densité.
- Utilisez `decorative` si un texte visible adjacent annonce déjà le chargement.
- Utilisez `aria-label` ou `aria-labelledby` si le statut nécessite un nom plus précis que `"Loading"`.
- Affichez `Spinner` selon l’état de chargement de votre application. Le composant ne démarre ni n’arrête l’opération
  représentée et n’en gère pas l’état.

### Quand créer une composition personnalisée

Passez votre contenu via `children` lorsque l’anneau par défaut ne convient pas, mais que la racine, la taille et
l’enveloppe rotative standard doivent rester en place.

Utilisez `asChild` uniquement lorsqu’un autre composant doit fournir l’élément DOM qui servira de racine. Fournissez un
seul enfant non interactif. Dans ce mode, l’enveloppe et l’anneau intégrés ne sont pas rendus : l’enfant doit donc
fournir lui-même le balisage de l’indicateur visuel.

### Propriétés par défaut

| Propriété         | Par défaut   | Remarques                                                                                                  |
| ----------------- | ------------ | ---------------------------------------------------------------------------------------------------------- |
| `size`            | `'md'`       | Accepte `'inherit' \| 'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`. `inherit` utilise `1em`.                      |
| `decorative`      | `false`      | Définit `role="presentation"` et `aria-hidden="true"` sur la racine standard ; avec `asChild`, conserve la sémantique de l’enfant. |
| `asChild`         | `false`      | Transmet les propriétés de la racine à l’unique élément enfant.                                           |
| `aria-label`      | `'Loading'`  | Utilisé lorsque `Spinner` n’est pas décoratif et que `aria-labelledby` n’est pas fourni.                   |
| `aria-labelledby` | non défini   | Permet de nommer le statut avec un texte visible situé ailleurs dans la page.                             |

### Comportement

- Par défaut, la racine est un `span` avec `data-scope="spinner"`, `data-part="root"`, `data-slot="spinner-root"`
  et `data-size`.
- `Spinner.Root` est un alias de compatibilité de `Spinner` ; utilisez `Spinner` dans le nouveau code.
- Un `Spinner` non décoratif utilise `role="status"`.
- `decorative={true}` masque la racine standard aux technologies d’assistance. Avec `asChild`, le composant n’ajoute
  ni son rôle ni ses attributs de libellé ; l’enfant personnalisé conserve donc sa propre sémantique.
- Spinner contrôle la sémantique du statut ainsi que les attributs `data-scope`, `data-part`, `data-slot` et `data-size`.
  Des propriétés natives contradictoires ne remplacent pas ces valeurs.
- L’enveloppe rotative utilise `data-scope="spinner"`, `data-part="indicator"` et `data-slot="spinner-indicator"`.
- Un contenu personnalisé passé via `children` remplace uniquement l’anneau par défaut. L’enveloppe intégrée continue de gérer la taille
  et la rotation.
- Avec `asChild`, l’enfant fourni par le consommateur devient la racine et doit fournir lui-même le contenu de l’indicateur visuel.
- `size="inherit"` définit une taille de `1em` ; les autres valeurs sont écrites dans `data-size` de la racine.
- Spinner conserve son animation de chargement lorsque `prefers-reduced-motion: reduce` est actif, car l’animation est
  l’indice visuel du chargement.

### Points d’accroche CSS

- `[data-scope="spinner"][data-part="root"]` cible la racine selon les conventions d’Ark.
- `[data-scope="spinner"][data-part="indicator"]` cible l’enveloppe interne rotative.
- `[data-scope="spinner"][data-part="ring"]` cible uniquement l’anneau par défaut.
- `data-slot="spinner-root"` est le sélecteur stable de moduix pour la racine rendue.
- `data-slot="spinner-indicator"` est le sélecteur stable de moduix pour l’enveloppe interne rotative.
- `data-slot="spinner-ring"` cible uniquement l’anneau par défaut.
- `Spinner` écrit `data-size="inherit" | "xs" | "sm" | "md" | "lg" | "xl"` sur la racine.
- `className` s’applique à la racine rendue. Avec `asChild`, il s’applique donc à l’unique enfant. Ciblez l’indicateur
  ou l’anneau avec des sélecteurs descendants si nécessaire.
