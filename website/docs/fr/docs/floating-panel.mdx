## Choisir le bon composant

Utilisez `FloatingPanel` pour une zone de travail flottante et non modale, par exemple un inspecteur ou une fenêtre utilitaire.
Choisissez `Popover` pour un contenu compact ancré à un déclencheur, `Dialog` pour les tâches modales et `Drawer` pour les
panneaux fixés à un bord, avec prise en charge des gestes ou des points d’ancrage.

## Exemple de base

`FloatingPanel.Content` représente la surface que l’on peut déplacer et redimensionner.

## Anatomie

```text
FloatingPanel / FloatingPanel.Root
├─ FloatingPanel.Trigger
└─ Overlay subtree (automatically portalled)
   └─ FloatingPanel.Positioner
      └─ FloatingPanel.Content
         ├─ FloatingPanel.DragTrigger
         │  └─ FloatingPanel.Header
         │     ├─ FloatingPanel.Title
         │     │  └─ FloatingPanel.DragIndicator (optional)
         │     └─ FloatingPanel.Control
         │        ├─ FloatingPanel.StageTrigger
         │        └─ FloatingPanel.CloseTrigger / CloseIcon
         ├─ FloatingPanel.Body
         ├─ FloatingPanel.Footer
         └─ FloatingPanel.ResizeTrigger / ResizeTriggerGroup
```

| Partie | Rôle |
| ----------------------------------------- | ----------------------------------------------------------------------- |
| `FloatingPanel` / `FloatingPanel.Root` | Gère l’état d’ouverture, la position, la taille, le déplacement, le redimensionnement et le mode de la fenêtre. |
| `FloatingPanel.Trigger` | Ouvre le panneau ou inverse son état.                                   |
| `FloatingPanel.Positioner` | Applique les valeurs Ark de position, de taille, de transformation et de z-index. |
| `FloatingPanel.Content` | Surface visible de la fenêtre flottante.                                 |
| `FloatingPanel.DragTrigger` | Définit la zone de déplacement, généralement l’en-tête.                 |
| `FloatingPanel.Header` | Partie d’en-tête Ark et conteneur recommandé pour la poignée de déplacement. |
| `FloatingPanel.Title` | Définit le titre accessible du panneau.                                  |
| `FloatingPanel.Control` | Regroupe les commandes de changement de mode et de fermeture.           |
| `FloatingPanel.StageTrigger` | Passe au mode `default`, `minimized` ou `maximized`.                     |
| `FloatingPanel.CloseTrigger` / `CloseIcon` | Ferme le panneau.                                                        |
| `FloatingPanel.Body` | Zone de contenu défilante.                                                |
| `FloatingPanel.Footer` | Zone facultative pour les actions secondaires ou le texte d’état.       |
| `FloatingPanel.ResizeTrigger` | Poignée de redimensionnement pour un axe Ark.                           |
| `FloatingPanel.ResizeTriggerGroup` | Composant auxiliaire moduix qui affiche tous les axes de redimensionnement ou seulement certains. |
| `FloatingPanel.RootProvider` | Relie les parties à l’état créé avec `FloatingPanel.useFloatingPanel()`. |

`FloatingPanel.DragIndicator`, `FloatingPanel.CloseIcon`, `FloatingPanel.Footer` et
`FloatingPanel.ResizeTriggerGroup` sont des composants auxiliaires de moduix. Ils complètent les
parties structurelles d’Ark sans les remplacer.

## Composition

Le composant racine place automatiquement `Positioner` dans un portail. Utilisez `portalled={false}` pour le rendre à son emplacement
dans l’arbre, ou `portalRef` pour choisir un conteneur personnalisé. Les parties structurelles restent explicites et peuvent
être stylées séparément.

### Composition recommandée

Utilisez `FloatingPanel` pour gérer l’état et le comportement. Rendez explicitement `Positioner` et `Content`, puis entourez
l’en-tête avec `DragTrigger` afin que le déplacement commence depuis une zone prévisible.

Utilisez `StageTrigger` avec `stage="minimized"`, `stage="maximized"` et `stage="default"` pour afficher les boutons
intégrés, avec leurs icônes, pour réduire, agrandir et restaurer le panneau. Ark masque le bouton de restauration tant que
le panneau n’est ni réduit ni agrandi. Lorsque `asChild` est défini sur un déclencheur ou un contrôle, transmettez un seul
enfant sémantique. moduix ajoute les icônes par défaut uniquement lorsque le déclencheur utilise le bouton Ark par défaut.

### Quand personnaliser la composition

Appliquez `className` directement à n’importe quelle partie exportée. Utilisez `asChild` avec exactement un enfant sémantique
pour vos déclencheurs d’ouverture, de fermeture ou de changement de mode. Passez `axes` à `ResizeTriggerGroup` pour n’afficher
que les poignées nécessaires, ou utilisez des parties `ResizeTrigger` individuelles lorsque chaque axe doit avoir son propre style.

Utilisez `FloatingPanel.Context` ou `FloatingPanel.useFloatingPanelContext()` dans l’arbre du panneau. Si l’état est créé
en dehors de cet arbre, créez-le avec `FloatingPanel.useFloatingPanel()` et transmettez-le à `RootProvider`. N’utilisez pas
`Root` et `RootProvider` pour une même instance d’état.

### Propriétés par défaut

Par défaut, le contenu de la superposition placé dans un portail n’est monté qu’à la première ouverture, puis démonté après
l’animation de fermeture. Définissez `unmountOnExit={false}` pour le conserver après cette première ouverture. Définissez les
deux propriétés de cycle de vie sur `false` uniquement si vous avez besoin d’un rendu initial immédiat.

| Propriété | Par défaut | Remarques |
| ---------------- | ------------ | ------------------------------------------------------------------------ |
| `closeOnEscape` | `true` | Ferme le panneau au premier plan lorsqu’il a le focus ; définissez `false` pour désactiver. |
| `persistRect` | `true` | Conserve la dernière position et la dernière taille pendant l’animation de fermeture. |
| `draggable` | Ark | Transmise à Ark telle quelle ; Ark lui donne `true` par défaut. |
| `resizable` | Ark | Transmise à Ark telle quelle ; Ark lui donne `true` par défaut. |
| `strategy` | Ark | Transmise à Ark telle quelle ; Ark utilise un positionnement fixe par défaut. |
| Propriétés du cycle de vie | moduix | `lazyMount` et `unmountOnExit` valent `true` par défaut ; les autres propriétés sont transmises telles quelles. |

### Comportement

- `onOpenChange(details)` transmet `details.open`.
- `onPositionChange(details)` et `onPositionChangeEnd(details)` transmettent `details.position`.
- `onSizeChange(details)` et `onSizeChangeEnd(details)` transmettent `details.size`.
- `onStageChange(details)` transmet l’objet de détails Ark du mode actuel.
- `position` et `size` sont contrôlés séparément. Utilisez `defaultPosition` et `defaultSize` pour une initialisation non contrôlée.
- `getAnchorPosition(details)` peut calculer la position initiale à partir du rectangle du déclencheur.
- Ark traite la touche Escape depuis le composant `Content` situé au premier plan et qui a le focus. Utilisez `autoFocus` lorsque le panneau doit recevoir
  le focus dès son ouverture.
- `ids`, `translations`, `getBoundaryEl`, `lockAspectRatio` et `gridSize` sont transmis à Ark tels quels.
- `Content` a `role="dialog"`. Quand il a le focus, les touches fléchées déplacent le panneau par incréments de `gridSize` et
  respectent `dir`. Utilisez `initialFocusEl`, `finalFocusEl` et `restoreFocus` pour transférer explicitement le focus.
- Définissez `persistRect` sur `false` si vous ne voulez pas conserver la dernière position et la dernière taille. La valeur par
  défaut est `true` afin que les animations de fermeture puissent utiliser ces valeurs.
- Le panneau est non modal : il ne maintient pas le focus et ne bloque pas les interactions externes.

### Points d’intégration CSS

Les parties Ark conservent `data-scope="floating-panel"` et leurs valeurs `data-part`. moduix ajoute
`data-slot="floating-panel-*"` aux conteneurs générés. Pour appliquer des styles selon l’état, utilisez
`data-state="open|closed"`, `data-dragging`, `data-disabled`, `data-stage`, `data-topmost`, `data-behind`, `data-minimized`,
`data-maximized`, `data-staged` et `data-axis`.

`Positioner` fournit `--width`, `--height`, `--x`, `--y`, `--reference-width`,
`--reference-height`, `--available-width`, `--available-height`, `--z-index` et `--transform-origin`.
Conservez la logique de dimensionnement et de transformation dans les variables d’exécution Ark au lieu de dupliquer
les mesures dans le code de l’application.
