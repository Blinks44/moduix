## Référence de l’API

Ark UI ne fournit pas de primitive dédiée à l’affichage des touches. `Kbd` est construit avec la [fabrique Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) officielle. Il suit ainsi les recommandations d’Ark pour la [composition](https://ark-ui.com/docs/guides/composition), les [styles](https://ark-ui.com/docs/guides/styling) et la [transmission des refs](https://ark-ui.com/docs/guides/ref).

## Anatomie

La structure d’un raccourci est simple. Le signe `+` est ici du texte ordinaire, pas une partie du composant.

```text
KbdGroup
├─ Kbd
├─ +
└─ Kbd
```

| Partie              | Rôle                                                                      |
| ------------------- | ------------------------------------------------------------------------- |
| `Kbd`              | Élément racine, rendu sous forme de `<kbd>` par défaut.                   |
| `KbdGroup`         | Conteneur en ligne pour les touches liées ; utilise le rôle `group` par défaut. |

## Composition

Utilisez `Kbd` pour afficher une touche et `KbdGroup` pour regrouper les touches liées. Gardez les séparateurs comme `+` sous forme de texte ordinaire dans le groupe et ajoutez un `aria-label` lorsque les symboles ou abréviations visuels ont besoin d’un nom accessible plus explicite.

Kbd est statique et ne gère ni état ni interaction clavier. Utilisez `asChild` uniquement lorsqu’un autre composant doit rendre l’élément sémantique `<kbd>` et fournissez exactement un enfant.

## Styles

Personnalisez `Kbd` et `KbdGroup` avec `className` en React ou `class` en Solid, les attributs d’anatomie Ark, les points d’accroche `data-slot` stables et les variables CSS publiques `--moduix-kbd-*` listées ci-dessous. Les variantes Tailwind utilisent des classes utilitaires natives ; les variantes CSS Modules utilisent les variables du composant et le CSS de l’application.

### Propriétés CSS

### Points d’accroche CSS

- `data-slot="kbd-root"` cible chaque touche affichée
- `data-slot="kbd-group"` cible le conteneur en ligne des raccourcis regroupés
- `[data-scope="kbd"][data-part="root"]` et `[data-part="group"]` fournissent des sélecteurs d’anatomie dans le style d’Ark
- Les séparateurs de `KbdGroup` héritent de la couleur du texte du groupe. Utilisez `--moduix-kbd-group-separator-color` pour la définir
