## Référence de l’API

Ark UI ne fournit pas de primitive dédiée à l’affichage des touches. `Kbd` est construit avec la [fabrique Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) officielle. Il suit ainsi les recommandations d’Ark pour la [composition](https://ark-ui.com/docs/guides/composition), les [styles](https://ark-ui.com/docs/guides/styling) et la [transmission des refs](https://ark-ui.com/docs/guides/ref).

## Exemple de base

Utilisez `Kbd` pour afficher une touche. Pour un raccourci composé de plusieurs touches, placez les touches et leurs

## Anatomie

La structure d’un raccourci est simple. Le signe `+` est ici du texte ordinaire, pas une partie du composant.

```text
Kbd.Group
├─ Kbd / Kbd.Root
├─ +
└─ Kbd / Kbd.Root
```

| Partie              | Rôle                                                                      |
| ------------------- | ------------------------------------------------------------------------- |
| `Kbd` / `Kbd.Root` | Élément racine, rendu sous forme de `<kbd>` par défaut.                    |
| `Kbd.Group`         | Conteneur en ligne pour les touches liées ; utilise le rôle `group` par défaut. |

## Composition

### Composition recommandée

Dans le cas courant, utilisez `Kbd` comme raccourci vers `Kbd.Root` pour afficher une touche. Utilisez `Kbd.Group` pour
regrouper un raccourci, une indication dans un menu de commandes ou une aide intégrée à l’interface.

`Kbd` et `Kbd.Root` acceptent `HTMLArkProps<'kbd'>`. `Kbd.Group` accepte `HTMLArkProps<'span'>` et utilise par défaut
`role="group"`. Chaque partie transmet `ref` à l’élément rendu et accepte `asChild`.
Le composant ne propose aucune API pour les variantes, les tailles, les séparateurs, les callbacks ou l’état.

### Quand créer une composition personnalisée

Utilisez `asChild` lorsqu’un autre composant rend déjà l’élément sémantique `<kbd>` et que vous souhaitez lui appliquer les styles
de Kbd. Fournissez exactement un enfant et conservez la sémantique de la touche.

### Comportement

- `Kbd`, `Kbd.Root` et `Kbd.Group` affichent des libellés statiques de touches. Ce ne sont pas des contrôles interactifs.
- Gardez `+`, `/` et les mots comme `then` sous forme de texte ordinaire, en dehors de `Kbd`.
- Ajoutez un `aria-label` à `Kbd.Group` lorsqu’une abréviation ou un symbole risque d’être mal interprété par une technologie d’assistance.
- Les parties exposent `data-scope="kbd"`, `data-part` et des attributs `data-slot` stables.

## Styles

Personnalisez `Kbd` et `Kbd.Group` avec `className`, les attributs d’anatomie Ark, les points d’accroche `data-slot` stables et les
variables CSS publiques `--moduix-kbd-*` listées ci-dessous.

### Points d’accroche CSS

- `data-slot="kbd-root"` cible chaque touche affichée
- `data-slot="kbd-group"` cible le conteneur en ligne des raccourcis regroupés
- `[data-scope="kbd"][data-part="root"]` et `[data-part="group"]` fournissent des sélecteurs d’anatomie dans le style d’Ark
- Les séparateurs de `Kbd.Group` héritent de la couleur du texte du groupe. Utilisez `--moduix-kbd-group-separator-color` pour la définir
