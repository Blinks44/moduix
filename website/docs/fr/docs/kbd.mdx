Utilisez `Kbd` pour afficher une touche. Pour un raccourci composé de plusieurs touches, placez les touches et leurs séparateurs textuels dans `KbdGroup`.

## Exemples

### Format compact

Utilisez des variables CSS locales lorsque vous souhaitez réduire les touches dans une zone précise de l’interface, sans ajouter de props au composant.

## Composition

Utilisez `Kbd` pour afficher une touche et `KbdGroup` pour regrouper les touches liées. Gardez les séparateurs comme `+` sous forme de texte ordinaire dans le groupe et ajoutez un `aria-label` lorsque les symboles ou abréviations visuels ont besoin d’un nom accessible plus explicite.

Kbd est statique et ne gère ni état ni interaction clavier. Utilisez `asChild` uniquement lorsqu’un autre composant doit rendre l’élément sémantique `<kbd>` et fournissez exactement un enfant.

## Anatomie

Un raccourci est un `KbdGroup` de touches `Kbd`. Le signe `+` entre les touches est du texte ordinaire, pas une partie du composant.

Survolez ou sélectionnez une partie pour la repérer dans l’aperçu.

## Styles

Personnalisez `Kbd` et `KbdGroup` avec `className` en React ou `class` en Solid et Vue, les attributs d’anatomie Ark, les points d’accroche `data-slot` stables et les variables CSS publiques `--moduix-kbd-*` listées ci-dessous. Les variantes Tailwind utilisent des classes utilitaires natives ; les variantes CSS Modules utilisent les variables du composant et le CSS de l’application.

### Points d’accroche CSS

| Partie | `data-slot` |
| --- | --- |
| `Kbd` | `kbd-root` |
| `KbdGroup` | `kbd-group` |

- `[data-scope="kbd"][data-part="root"]` et `[data-part="group"]` fournissent des sélecteurs d’anatomie dans le style d’Ark
- Les séparateurs de `KbdGroup` héritent de la couleur du texte du groupe. Pour la changer, définissez `color` sur `KbdGroup` avec votre propre classe

## Référence de l’API

`Kbd` rend un élément `kbd` et `KbdGroup` un `span`. Les deux acceptent leurs props natives et `asChild`.

| Prop | Type | Défaut |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |
