## Référence de l’API

`SimpleGrid` n’est pas une primitive d’Ark UI. moduix fournit un composant de mise en page compact,
construit avec la fabrique Ark. Il suit les recommandations d’Ark pour la
[composition](https://ark-ui.com/docs/guides/composition), les
[styles](https://ark-ui.com/docs/guides/styling) et les [références](https://ark-ui.com/docs/guides/ref).
Ses propriétés `columns` et `minChildWidth` reprennent le modèle de mise en page de
[SimpleGrid](https://chakra-ui.com/docs/components/simple-grid) de Chakra UI, sans reprendre les
propriétés de style adaptatif de Chakra.

## Exemple de base

Importez `SimpleGrid` depuis `@moduix/react/simple-grid`. Utilisez `minChildWidth` lorsque le nombre
de colonnes égales doit suivre la largeur disponible. Le composant s’appuie sur `auto-fit` et
`minmax()` de CSS Grid ; les valeurs numériques sont interprétées en pixels, tandis que les chaînes
peuvent contenir n’importe quelle longueur CSS valide.

Le nombre de colonnes s’ajuste à la largeur de l’élément racine, et les enfants restent des éléments
directs de la grille. Si un enfant contient du contenu qui ne peut pas être coupé, ajoutez
`min-width: 0` ou une règle de débordement adaptée sur cet enfant.

## Anatomie

`SimpleGrid` rend un seul élément racine CSS Grid et n’ajoute aucune enveloppe autour de ses enfants.

```text
SimpleGrid
└─ root[data-scope="simple-grid"][data-part="root"][data-slot="simple-grid-root"]
   └─ children
```

| Partie       | Rôle                                                     |
| ------------ | -------------------------------------------------------- |
| `SimpleGrid` | Élément racine qui crée des colonnes CSS Grid de même largeur. |

## Composition

### Composition recommandée

Utilisez la forme courte `<SimpleGrid>` pour la racine. `SimpleGrid.Root` rend le même composant et
reste disponible comme alias de compatibilité.

Choisissez un mode de mise en page :

- `minChildWidth` laisse le navigateur placer autant de colonnes égales que la largeur disponible le permet.
- `columns` crée un nombre précis de colonnes égales.

Si les éléments doivent être séparés visuellement, définissez `gap`, `rowGap` ou `columnGap`.
Utilisez `asChild` lorsque la racine doit être un élément sémantique comme `ul`, `section` ou `nav`.
`asChild` attend exactement un élément enfant, qui devient la racine rendue.

### Quand créer une composition personnalisée

Préférez votre CSS local si la mise en page nécessite des zones nommées, des pistes de tailles
différentes, des éléments qui s’étendent sur plusieurs pistes ou des modèles différents selon les
points de rupture définis par des requêtes média ou de conteneur. Ne transmettez ni `columns` ni
`minChildWidth`, puis définissez `grid-template-columns` dans la feuille de style.

### Propriétés par défaut

| Propriété        | Valeur par défaut                | Remarques                                                  |
| ---------------- | -------------------------------- | ---------------------------------------------------------- |
| `columns`        | `1`                              | Entier positif fini pour des colonnes de même largeur      |
| `minChildWidth`  | non définie                      | Longueur CSS ; les nombres sont interprétés en pixels      |
| `gap`            | valeur initiale du navigateur    | Longueur CSS ; les nombres sont interprétés en pixels      |
| `rowGap`         | valeur initiale du navigateur    | Longueur CSS ; les nombres sont interprétés en pixels      |
| `columnGap`      | valeur initiale du navigateur    | Longueur CSS ; les nombres sont interprétés en pixels      |
| `asChild`        | `false`                          | Composition Ark avec un seul enfant                       |
| `className`      | non définie                      | Appliquée à la racine rendue                              |
| `style`          | non définie                      | Appliqué en dernier pour l’instance                       |

### Comportement

- Si ni `columns` ni `minChildWidth` ne sont définis, la grille comporte une colonne de même largeur.
- Si les deux propriétés sont définies, `minChildWidth` est prioritaire sur `columns`.
- `columns={3}` crée trois pistes égales sans ajouter d’enveloppe autour des enfants.
- `minChildWidth={160}` crée autant de pistes que possible et interprète le nombre comme `160px`.
- Une valeur numérique de `columns` doit être un entier positif fini. Une valeur numérique de
  `minChildWidth` doit être finie et positive ou nulle.
- Le mode `auto-fit` évite les débordements lorsque la grille devient plus étroite que `minChildWidth`.
- `gap`, `rowGap` et `columnGap` ne sont ajoutés aux styles inline que lorsqu’ils sont définis.
- `style` est appliqué en dernier et peut remplacer toute valeur générée, notamment `display`,
  `gridTemplateColumns` et les espacements.
- La `ref` pointe vers l’élément racine réellement rendu. Avec `asChild`, elle pointe vers l’unique
  élément enfant.
- Le composant n’ajoute ni rôle, ni libellé, ni comportement clavier, ni gestion du focus, ni état,
  ni contexte de fournisseur. Choisissez les éléments sémantiques dans votre propre balisage.

## Styles

`SimpleGrid` ne définit aucune variable CSS propre au composant. Ses propriétés de mise en page sont
écrites dans les styles inline de la racine rendue ; ne transmettez donc ni `columns` ni
`minChildWidth` si la feuille de style doit gérer `grid-template-columns`.

### Points d’accroche CSS

- `className` permet de styliser la racine rendue pour sa largeur, son positionnement, son arrière-plan
  et sa mise en page adaptative.
- `data-scope="simple-grid"` et `data-part="root"` suivent les conventions de style d’Ark.
- `data-slot="simple-grid-root"` est le sélecteur moduix stable à utiliser dans votre CSS local.
- `columns`, `minChildWidth`, `gap`, `rowGap` et `columnGap` écrivent des styles inline, prioritaires
  sur les déclarations de `className`.
- `style` est fusionné après ces propriétés et constitue le dernier remplacement disponible pour
  l’instance.
- Le composant ne fournit aucun hook de style lié à un état ou à une animation.
