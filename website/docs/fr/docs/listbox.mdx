## Exemple de base

Utilisez `Listbox` lorsque l’utilisateur doit choisir un ou plusieurs éléments dans une liste toujours visible.
Fournissez une `collection`, affichez `Content`, puis transmettez chaque élément de la collection à
`Listbox.Item` via `item`.

## Anatomie

```text
Listbox / Listbox.Root
├─ Listbox.Label
├─ Listbox.Filter
│  ├─ Listbox.Input
│  └─ Listbox.ClearTrigger
├─ Listbox.Content
│  ├─ Listbox.Empty
│  ├─ Listbox.ItemGroup
│  │  ├─ Listbox.ItemGroupLabel
│  │  └─ Listbox.Item[item]
│  │     ├─ Listbox.ItemText
│  │     └─ Listbox.ItemIndicator
│  └─ Listbox.Item[item]
│     ├─ Listbox.ItemText
│     │  └─ Listbox.ItemTextContent (optional)
│     │     ├─ Listbox.ItemTextIcon (optional)
│     │     └─ Listbox.ItemTextLabel (optional)
│     └─ Listbox.ItemIndicator
└─ Listbox.ValueText
```

| Partie | Rôle |
| -------------------------- | ------------------------------------------------------------------- |
| `Listbox` / `Listbox.Root` | Gère la collection, les valeurs sélectionnées, l’élément actif et le mode de sélection. |
| `Listbox.RootProvider` | Rend l’arborescence de la listbox à partir de l’état renvoyé par `useListbox`.            |
| `Listbox.Label` | Libellé accessible de la listbox.                                                      |
| `Listbox.Filter` | Champ de recherche par défaut avec une icône. Placez-le avant `Content`.                 |
| `Listbox.Input` | Champ de filtrage, généralement placé dans `Filter`.                                    |
| `Listbox.ClearTrigger` | Bouton accessible de réinitialisation de la requête, avec l’icône de fermeture par défaut. |
| `Listbox.Content` | Conteneur de la listbox qui gère le focus et la navigation au clavier.                   |
| `Listbox.Empty` | Contenu affiché lorsque la collection filtrée ne contient aucun élément.                 |
| `Listbox.ItemGroup` | Conteneur de groupe pour les éléments de collection associés.                           |
| `Listbox.ItemGroupLabel` | Libellé d’un groupe de la collection.                                                   |
| `Listbox.Item` | Ligne sélectionnable. Transmettez-lui l’élément de collection via `item`.                 |
| `Listbox.ItemText` | Texte utilisé pour l’affichage et l’accessibilité.                                      |
| `Listbox.ItemTextContent` | Aide facultative pour disposer une icône et du texte dans `ItemText`.                    |
| `Listbox.ItemTextIcon` | Conteneur d’icône facultatif dans `ItemTextContent`.                                    |
| `Listbox.ItemTextLabel` | Libellé de `ItemTextContent` dont le texte peut être tronqué sans casser la mise en page. |
| `Listbox.ItemIndicator` | Indicateur de sélection avec l’icône de coche moduix par défaut.                         |
| `Listbox.ValueText` | Résumé des valeurs sélectionnées.                                                       |

## Composition

### Composition recommandée

Composez directement l’arbre des parties Ark. `Listbox` gère la collection, `Listbox.Content` le focus et la
navigation au clavier, et chaque `Listbox.Item` reçoit l’élément de collection d’origine via `item`.
Ajoutez `Listbox.ItemIndicator` lorsque les lignes doivent réserver de l’espace à l’indicateur de sélection.

Pour filtrer, placez `Listbox.Input` dans `Listbox.Filter`, juste avant `Listbox.Content`.
`Filter` ajoute l’icône de recherche par défaut et réunit visuellement le champ et les résultats dans une seule
surface bordée.

### Quand créer une composition personnalisée

Utilisez `asChild` uniquement si votre élément personnalisé conserve la sémantique requise de la listbox et accepte les
propriétés Ark. Utilisez `ids` lorsque les parties de la listbox ont besoin d’identifiants stables pour s’intégrer à
l’interface environnante. Utilisez `useListbox` de moduix avec `Listbox.RootProvider` lorsque l’état doit être contrôlé
en dehors de l’arbre rendu. Dans ce cas, ne rendez pas `Listbox.Root` pour la même instance d’état. Rendez
`Listbox.Input` directement lorsque le champ de filtre doit rester visuellement séparé de la liste ou s’intégrer à une
mise en page personnalisée.

### Propriétés par défaut

| Propriété | Par défaut | Remarques |
| ------------------------- | ------------ | -------------------------------------------------------------------------- |
| `collection` | - | Collection Ark obligatoire. Créez-la avec `createListCollection` ou utilisez une variante pour grille. |
| `defaultValue` | `[]` | Valeurs sélectionnées initiales en mode non contrôlé.                                              |
| `defaultHighlightedValue` | - | Élément initialement actif en mode non contrôlé.                                                    |
| `deselectable` | - | Permet à la touche `Escape` d’effacer une sélection non vide.                                        |
| `disabled` | `false` | Désactive l’ensemble de la listbox.                                                                 |
| `disallowSelectAll` | `false` | Désactive la sélection avec `Cmd/Ctrl + A`.                                                        |
| `loopFocus` | `false` | Empêche la navigation avec les flèches de revenir au début.                                         |
| `orientation` | `vertical` | Définit la disposition et la direction des touches fléchées.                                       |
| `selectionMode` | `single` | Prend en charge `single`, `multiple` et `extended`.                                                 |
| `selectOnHighlight` | `false` | Sélectionne automatiquement l’élément actif pendant la navigation au clavier.                      |
| `typeahead` | `true` | Active la recherche par saisie lorsqu’aucun champ de filtrage ne gère la saisie.                    |

### Comportement

`value`, `defaultValue` et `onValueChange(details)` sont des tableaux de chaînes. Lisez `details.value`
pour les clés sélectionnées et `details.items` pour les éléments de collection sélectionnés.

`highlightedValue`, `defaultHighlightedValue` et `onHighlightChange(details)` contrôlent le déplacement de l’élément actif.
`onSelect(details)` est appelé lorsqu’un élément est sélectionné et fournit sa valeur.

`useListbox`, `useListboxContext`, `useListboxItemContext`, `Listbox.Context` et
`Listbox.ItemContext` sont exportés par `@moduix/react` pour les compositions avancées. Les refs sont transmises à la
partie Ark correspondante. Pour la racine et le root provider, elles ciblent les éléments `div` rendus. Utilisez `ids`
lorsque les parties de la listbox ont besoin d’identifiants stables pour s’intégrer à l’interface environnante.

La listbox ne rend pas de contrôle de formulaire natif pour les valeurs sélectionnées. Si la sélection doit être
envoyée avec le formulaire, gérez sa valeur lors de la soumission et de la réinitialisation dans votre modèle de formulaire.

`Listbox.Input` n’est utile que pour le filtrage. Placez-le dans `Listbox.Filter` pour l’apparence de recherche par
défaut, ou affichez-le directement pour un champ séparé. Définissez `typeahead={false}` pour éviter que la recherche par
saisie et le filtrage ne se disputent la saisie. Gérez explicitement l’état du filtre : affichez `Listbox.ClearTrigger`
lorsque la requête n’est pas vide, puis effacez la requête et le filtre de collection dans son gestionnaire `onClick`.

Ark gère le modèle ARIA de listbox, le focus de l’élément actif, la navigation au clavier, la recherche par saisie,
le comportement des touches `Home` et `End`, les éléments désactivés et les touches fléchées adaptées à l’orientation.
Gardez `Listbox.Label` dans l’arbre lorsque la listbox nécessite un libellé visible.

### Points d’accroche CSS

- Hooks d’anatomie Ark : `data-scope="listbox"` et `data-part` sur la racine, le libellé, le champ de saisie, le contenu,
le groupe et le libellé du groupe, l’élément, son texte et son indicateur, le texte de la sélection et l’état vide.
- Hooks d’état : `data-orientation`, `data-disabled`, `data-empty`, `data-layout`,
`data-activedescendant`, `data-value`, `data-selected`, `data-state` et `data-highlighted`.
- Hooks moduix : `data-slot="listbox-root"`, `listbox-label`, `listbox-filter`,
  `listbox-filter-icon`, `listbox-input`, `listbox-clear-trigger`, `listbox-content`,
  `listbox-empty`, `listbox-item-group`, `listbox-item-group-label`, `listbox-item`,
  `listbox-item-text`, `listbox-item-text-content`, `listbox-item-text-icon`,
`listbox-item-text-label`, `listbox-item-indicator` et `listbox-value-text`.
