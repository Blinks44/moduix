## Choisir le bon composant

Utilisez `Listbox` lorsque les options doivent rester visibles et que l’utilisateur choisit des
éléments dans une collection. Utilisez `Select` lorsque les options doivent s’ouvrir dans une liste
contextuelle. Utilisez `Combobox` lorsqu’un champ doit permettre de rechercher ou de saisir une
valeur dans une liste contextuelle.

## Anatomie

```text
Listbox / Listbox.Root
├─ Listbox.Label
├─ Listbox.Filter
│  ├─ Listbox.Input
│  └─ Listbox.ClearTrigger
├─ Listbox.Content
│  ├─ Listbox.Empty
│  ├─ Listbox.ItemGroup
│  │  ├─ Listbox.ItemGroupLabel
│  │  └─ Listbox.Item[item]
│  │     ├─ Listbox.ItemText
│  │     └─ Listbox.ItemIndicator
│  └─ Listbox.Item[item]
│     ├─ Listbox.ItemText
│     │  └─ Listbox.ItemTextContent (facultatif)
│     │     ├─ Listbox.ItemTextIcon (facultatif)
│     │     └─ Listbox.ItemTextLabel (facultatif)
│     └─ Listbox.ItemIndicator
└─ Listbox.ValueText

Listbox.RootProvider
└─ même arbre d’éléments relié à un store useListbox()
```

| Partie                     | Rôle                                                                                     |
| ------------------------- | ---------------------------------------------------------------------------------------- |
| `Listbox` / `Listbox.Root` | Gère la collection, les valeurs sélectionnées, l’élément mis en évidence et le mode de sélection. |
| `Listbox.RootProvider`     | Rend l’arbre de la listbox à partir de l’état renvoyé par `useListbox`.                   |
| `Listbox.Label`            | Libellé qui fournit un nom accessible à la listbox.                                      |
| `Listbox.Filter`           | Conteneur visuel pour un champ de filtrage avec l’icône de recherche par défaut. Placez-le avant `Listbox.Content`. |
| `Listbox.Input`            | Champ de filtrage, généralement placé dans `Filter`.                                    |
| `Listbox.ClearTrigger`     | Bouton qui réinitialise la requête de filtrage, avec l’icône de fermeture par défaut.   |
| `Listbox.Content`          | Conteneur focalisable qui gère la navigation au clavier.                                |
| `Listbox.Empty`            | Contenu affiché lorsque la collection filtrée ne contient aucun élément.                 |
| `Listbox.ItemGroup`        | Conteneur pour des éléments liés de la collection.                                      |
| `Listbox.ItemGroupLabel`   | Libellé d’un groupe d’éléments.                                                          |
| `Listbox.Item`             | Élément sélectionnable. Transmettez-lui l’élément de la collection via `item`.           |
| `Listbox.ItemText`         | Texte utilisé pour l’affichage et l’accessibilité.                                      |
| `Listbox.ItemTextContent`  | Conteneur facultatif pour organiser une icône et du texte dans `ItemText`.               |
| `Listbox.ItemTextIcon`     | Conteneur facultatif pour une icône dans `ItemTextContent`.                              |
| `Listbox.ItemTextLabel`    | Conteneur du texte dans `ItemTextContent`, qui peut tronquer les libellés longs sans perturber la mise en page. |
| `Listbox.ItemIndicator`    | Indicateur de sélection avec l’icône de coche moduix par défaut.                         |
| `Listbox.ValueText`        | Résumé des valeurs sélectionnées.                                                        |

## Composition

Utilisez `defaultValue` pour une sélection non contrôlée. Lorsqu’une autre partie de l’application
gère la sélection, passez `value` et mettez-le à jour avec `onValueChange(details.value)`. Pour le
filtrage, définissez `typeahead={false}`, conservez la requête dans l’état de l’application et
appelez la fonction `filter` renvoyée par `useListCollection` depuis le gestionnaire du champ. `Listbox.Filter` ne
fournit que l’apparence regroupée du champ de recherche ; l’action d’effacement doit donc
réinitialiser la requête et le filtre de la collection.

Utilisez `useListbox` du paquet correspondant au framework avec `Listbox.RootProvider` lorsque le
store doit être créé en dehors de l’arbre rendu. Passez le store obtenu à `RootProvider` et ne rendez
pas `Listbox` ou `Listbox.Root` pour ce même store. `Listbox.Input` peut être rendu directement si le
filtre doit avoir son propre conteneur, et `Listbox.ValueText` peut être placé après `Content` pour
afficher un résumé des valeurs sélectionnées.

## Styles

Stylisez Listbox avec `className` dans React ou `class` dans Solid sur les parties exportées. Les
variantes Tailwind utilisent des utilitaires natifs et les classes du consommateur, tandis que les
variantes CSS Modules utilisent les variables CSS publiques `--moduix-listbox-*`.

### Propriétés CSS

<CssPropertiesSection properties={ListboxDocs.listboxOverrideCssProperties} />

### Points d’accroche CSS

- Points d’anatomie Ark : `data-scope="listbox"` et `data-part` sur la racine, le libellé, le champ,
  le contenu, le groupe d’éléments, le libellé du groupe, l’élément, son texte, son indicateur, le
  texte de valeur et l’état vide.
- Points d’état : `data-orientation`, `data-disabled`, `data-empty`, `data-layout`,
  `data-activedescendant`, `data-value`, `data-selected`, `data-state` et `data-highlighted`.
- Points moduix : `data-slot="listbox-root"`, `listbox-root-provider`, `listbox-label`,
  `listbox-filter`, `listbox-filter-icon`, `listbox-input`, `listbox-clear-trigger`,
  `listbox-content`, `listbox-empty`, `listbox-item-group`, `listbox-item-group-label`,
  `listbox-item`, `listbox-item-text`, `listbox-item-text-content`, `listbox-item-text-icon`,
  `listbox-item-text-label`, `listbox-item-indicator` et `listbox-value-text`.
