## Choisir le bon composant

Utilisez `Listbox` lorsque les options doivent rester visibles et que l’utilisateur choisit dans une collection.
Utilisez `Select` lorsque les options doivent s’ouvrir dans une fenêtre contextuelle. Utilisez `Combobox` lorsque
l’utilisateur a besoin d’une fenêtre contextuelle pilotée par un champ de saisie pour rechercher ou saisir une valeur.

## Exemple de base

Utilisez `Listbox` lorsque l’utilisateur doit choisir un ou plusieurs éléments dans une liste qui reste ouverte.
Fournissez une `collection`, affichez `Listbox.Content`, puis transmettez chaque élément de la collection à `Listbox.Item`
via `item`.

## Anatomie

```text
Listbox / Listbox.Root
├─ Listbox.Label
├─ Listbox.Filter
│  ├─ Listbox.Input
│  └─ Listbox.ClearTrigger
├─ Listbox.Content
│  ├─ Listbox.Empty
│  ├─ Listbox.ItemGroup
│  │  ├─ Listbox.ItemGroupLabel
│  │  └─ Listbox.Item[item]
│  │     ├─ Listbox.ItemText
│  │     └─ Listbox.ItemIndicator
│  └─ Listbox.Item[item]
│     ├─ Listbox.ItemText
│     │  └─ Listbox.ItemTextContent (optional)
│     │     ├─ Listbox.ItemTextIcon (optional)
│     │     └─ Listbox.ItemTextLabel (optional)
│     └─ Listbox.ItemIndicator
└─ Listbox.ValueText

Listbox.RootProvider
└─ same item tree connected to a useListbox() store
```

| Partie | Rôle                                                                                         |
| ------ | -------------------------------------------------------------------------------------------- |
| `Listbox` / `Listbox.Root` | Gère la collection, les valeurs sélectionnées, l’élément actif et le mode de sélection.       |
| `Listbox.RootProvider`     | Affiche l’arborescence de la listbox à partir de l’état renvoyé par `useListbox`.                |
| `Listbox.Label`            | Libellé qui donne à la listbox un nom accessible.                                               |
| `Listbox.Filter`           | Conteneur visuel du champ de filtrage, avec l’icône de recherche par défaut. Placez-le avant `Listbox.Content`. |
| `Listbox.Input`            | Champ de filtrage, généralement placé dans `Filter`.                                            |
| `Listbox.ClearTrigger`     | Bouton de réinitialisation de la requête, avec l’icône de fermeture par défaut.                 |
| `Listbox.Content`          | Conteneur de la listbox qui peut recevoir le focus et gère la navigation au clavier.             |
| `Listbox.Empty`            | Contenu affiché lorsque la collection filtrée ne contient aucun élément.                         |
| `Listbox.ItemGroup`        | Conteneur pour un groupe d’éléments associés de la collection.                                   |
| `Listbox.ItemGroupLabel`   | Libellé d’un groupe d’éléments de la collection.                                                 |
| `Listbox.Item`             | Élément sélectionnable. Transmettez l’élément correspondant de la collection via `item`.         |
| `Listbox.ItemText`         | Texte utilisé pour l’affichage et l’accessibilité.                                               |
| `Listbox.ItemTextContent`  | Conteneur facultatif permettant d’organiser une icône et du texte dans `ItemText`.               |
| `Listbox.ItemTextIcon`     | Conteneur facultatif pour l’icône dans `ItemTextContent`.                                        |
| `Listbox.ItemTextLabel`    | Encapsule le texte dans `ItemTextContent` et permet de tronquer les libellés longs sans casser la mise en page. |
| `Listbox.ItemIndicator`    | Indicateur de sélection avec l’icône de coche par défaut de moduix.                              |
| `Listbox.ValueText`        | Résumé des valeurs sélectionnées.                                                               |

## Composition

### Composition recommandée

Assemblez la listbox directement à partir de ses parties Ark. `Listbox` gère la collection, `Listbox.Content` le
focus et la navigation au clavier, et chaque `Listbox.Item` reçoit l’élément d’origine de la collection via `item`.
Ajoutez `Listbox.ItemIndicator` lorsque les lignes doivent réserver de l’espace à l’indicateur de sélection.

La forme courte de la racine est `Listbox`, qui équivaut à `Listbox.Root`. Pour le filtrage, placez `Listbox.Input`
dans `Listbox.Filter`, juste avant `Listbox.Content`. `Filter` ajoute l’icône de recherche par défaut et réunit
visuellement le champ et les résultats dans une seule surface bordée. Il s’agit uniquement d’une enveloppe visuelle :
votre code gère toujours l’état de la requête et le filtrage de la collection.

### Quand créer une composition personnalisée

Utilisez `asChild` uniquement si votre élément personnalisé conserve la sémantique requise de la listbox et accepte les
propriétés Ark. Utilisez `ids` lorsque les parties de la listbox ont besoin d’identifiants stables pour s’intégrer à
l’interface environnante. Utilisez `useListbox` depuis `@moduix/react/listbox` avec `Listbox.RootProvider` lorsque
l’état doit être contrôlé en dehors de l’arbre rendu. Dans ce cas, ne rendez pas `Listbox.Root` pour la même instance
d’état. Affichez `Listbox.Input` directement lorsque le champ de filtre doit rester visuellement séparé de la liste
ou s’intégrer à une mise en page personnalisée.

### Propriétés par défaut

| Propriété                 | Valeur par défaut | Remarques                                                                                              |
| ------------------------- | ----------------- | ------------------------------------------------------------------------------------------------------ |
| `collection`              | -                 | Collection Ark obligatoire. Créez-la avec `createListCollection` ou utilisez une collection de grille. |
| `defaultValue`            | `[]`              | Valeurs sélectionnées initiales lorsque l’état n’est pas contrôlé.                                     |
| `defaultHighlightedValue` | -                 | Élément actif initial lorsque l’état n’est pas contrôlé.                                               |
| `deselectable`            | -                 | Permet à la touche `Escape` d’effacer une sélection non vide.                                          |
| `disabled`                | `false`           | Désactive toute la listbox.                                                                             |
| `disallowSelectAll`       | `false`           | Désactive la sélection de tous les éléments avec `Cmd/Ctrl + A`.                                       |
| `loopFocus`               | `false`           | Empêche la navigation avec les flèches de revenir au début.                                            |
| `orientation`             | `vertical`        | Définit la disposition et la direction des touches fléchées.                                           |
| `selectionMode`           | `single`          | Prend en charge `single`, `multiple` et `extended`.                                                     |
| `selectOnHighlight`       | `false`           | Sélectionne l’élément lorsqu’il est mis en évidence au clavier.                                         |
| `typeahead`               | `true`            | Active la recherche par saisie lorsqu’aucun champ de filtrage ne gère la saisie.                       |

### Comportement

`value`, `defaultValue` et `onValueChange(details)` utilisent des tableaux de chaînes. Utilisez `details.value`
pour lire les clés sélectionnées et `details.items` pour les éléments sélectionnés de la collection.

`highlightedValue`, `defaultHighlightedValue` et `onHighlightChange(details)` contrôlent l’élément actif pendant la
navigation. `onSelect(details)` est appelé lorsqu’un élément est sélectionné et fournit sa valeur.

`useListbox`, `useListboxContext`, `useListboxItemContext`, `Listbox.Context` et `Listbox.ItemContext` sont
disponibles depuis `@moduix/react/listbox` pour les compositions avancées qui ont besoin d’accéder à l’état ou au
contexte d’un élément. Les refs sont transmises à la partie Ark correspondante. Pour la racine et le root provider,
elles ciblent les éléments `div` rendus. Utilisez `ids` lorsque les parties de la listbox ont besoin d’identifiants
stables pour s’intégrer à l’interface environnante.

La listbox ne génère pas de contrôle de formulaire natif pour les valeurs sélectionnées. Si la sélection doit être
envoyée avec le formulaire, gérez sa valeur et la réinitialisation dans votre modèle de formulaire.

`Listbox.Input` ne sert qu’au filtrage. Placez-le dans `Listbox.Filter` pour l’apparence de recherche par défaut, ou
affichez-le directement pour un champ séparé. Définissez `typeahead={false}` pour éviter que la recherche par saisie
et le filtrage ne se concurrencent. Gérez explicitement l’état du filtre : affichez `Listbox.ClearTrigger` lorsque la
requête n’est pas vide, puis effacez la requête et le filtre de collection dans son gestionnaire `onClick`.

Ark gère le modèle ARIA de la listbox, le focus de l’élément actif, la navigation au clavier, la recherche par saisie,
le comportement des touches `Home` et `End`, les éléments désactivés et les touches fléchées adaptées à l’orientation.
Gardez `Listbox.Label` dans l’arbre lorsque la listbox nécessite un libellé visible.

## Styles

Stylisez `Listbox` avec `className`, les sélecteurs `data-slot="listbox-*"` stables, les attributs Ark
`data-scope="listbox"` / `data-part`, les attributs d’état et les variables CSS publiques `--moduix-listbox-*`.

### Points d’accroche CSS

- Attributs d’anatomie Ark : `data-scope="listbox"` et `data-part` sur la racine, le libellé, le champ de saisie, le
  contenu, le groupe et le libellé du groupe, l’élément, son texte et son indicateur, le texte de la sélection et l’état vide.
- Attributs d’état : `data-orientation`, `data-disabled`, `data-empty`, `data-layout`, `data-activedescendant`,
  `data-value`, `data-selected`, `data-state` et `data-highlighted`.
- Sélecteurs moduix : `data-slot="listbox-root"`, `listbox-root-provider`, `listbox-label`, `listbox-filter`,
  `listbox-filter-icon`, `listbox-input`, `listbox-clear-trigger`, `listbox-content`, `listbox-empty`,
  `listbox-item-group`, `listbox-item-group-label`, `listbox-item`, `listbox-item-text`,
  `listbox-item-text-content`, `listbox-item-text-icon`, `listbox-item-text-label`, `listbox-item-indicator` et
  `listbox-value-text`.
