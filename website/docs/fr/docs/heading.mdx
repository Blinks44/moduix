## Référence de l’API

Ark UI ne propose pas de primitive dédiée aux titres. moduix implémente `Heading` avec la
[fabrique Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) officielle et suit les recommandations
d’Ark pour la [composition](https://ark-ui.com/docs/guides/composition), la [mise en forme](https://ark-ui.com/docs/guides/styling)
et le [transfert de ref](https://ark-ui.com/docs/guides/ref).

## Anatomie

`Heading` rend un seul élément de titre natif.

```text
Heading
└─ texte ou contenu en ligne
```

| Partie                     | Rôle                                                               |
| -------------------------- | ------------------------------------------------------------------ |
| `Heading` | Titre sémantique natif avec la mise en forme typographique de moduix. |

## Composition

`Heading` est un composant sans état limité à sa racine : il n’a donc besoin ni de provider ni de parties
coordonnées. Utilisez `<Heading>`, transmettez `as` pour choisir le niveau sémantique de `h1` à `h6`,
et définissez `size` séparément si l’importance visuelle doit différer.
Sans `size` explicite, l’élément rendu choisit l’échelle de `2xl` pour `h1` à `xs` pour `h6`, et `weight`
vaut `semibold` par défaut. Utilisez `asChild` uniquement lorsqu’un autre élément sémantique de titre doit
porter le nœud DOM rendu.

## Styles

Personnalisez `Heading` avec `className` en React ou `class` en Solid, les attributs de données de la racine
et les variables CSS publiques `--moduix-heading-*` présentées dans la référence CSS ci-dessous. Les paquets
CSS Modules exposent ces variables ; les paquets Tailwind utilisent des classes utilitaires natives et les
surcharges de classes fournies par l’application.

### Points d’accroche CSS

- `data-scope="heading"` et `data-part="root"` identifient la racine selon les conventions d’Ark.
- `data-slot="heading-root"` est un sélecteur moduix stable.
- `data-size` est présent lorsque `size` est défini explicitement.
- `data-weight` indique la graisse choisie : `regular`, `medium`, `semibold` ou `bold`.
- `Heading` définit lui-même ces attributs. Les propriétés `data-*` correspondantes ne peuvent pas remplacer le contrat de style du composant.
- Utilisez `className` ou `class` pour les classes utilitaires de l’application et les ajustements de style locaux.
