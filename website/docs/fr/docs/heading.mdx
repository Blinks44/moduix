Par défaut, `Heading` rend un `h1`. Utilisez-le pour les titres du document et choisissez la valeur de `as`
en fonction de sa place dans la structure du document. Définissez `size` séparément lorsque l’importance
visuelle doit différer du niveau sémantique.

## Exemples

### Élément personnalisé

Utilisez `asChild` lorsqu’un autre élément sémantique de titre doit porter le nœud DOM rendu. Pour les cas
courants avec `h1` à `h6`, utilisez plutôt `as`. La taille par défaut suit `as` et non l’élément enfant :
définissez donc `size` selon l’enfant.

## Composition

`Heading` est un composant sans état limité à sa racine : il n’a donc besoin ni de provider ni de parties
coordonnées. Utilisez `<Heading>`, transmettez `as` pour choisir le niveau sémantique de `h1` à `h6`,
et définissez `size` séparément si l’importance visuelle doit différer.
Sans `size` explicite, `as` choisit l’échelle de `2xl` pour `h1` à `xs` pour `h6`, et `weight`
vaut `semibold` par défaut. Utilisez `asChild` uniquement lorsqu’un autre élément sémantique de titre doit
porter le nœud DOM rendu.

## Styles

Utilisez `className` en React ou `class` en Solid et Vue sur `Heading`. Les variantes Tailwind utilisent
des utilitaires natifs et les classes de l’application. Les variantes CSS Modules reposent sur les jetons
typographiques de foundation et n’ont pas de variables de composant : une classe sur la racine remplace les
styles du composant déclarés dans leur couche.

### Points d’accroche CSS

| Partie | `data-slot` |
| --- | --- |
| `Heading` | `heading-root` |

- `data-scope="heading"` et `data-part="root"` identifient la racine selon les conventions d’Ark.
- `data-size` indique la taille résolue : la valeur explicite de `size` ou la taille par défaut de `as`.
- `data-weight` indique la graisse choisie : `regular`, `medium`, `semibold` ou `bold`.
- `Heading` définit lui-même ces attributs. Les propriétés `data-*` correspondantes ne peuvent pas remplacer le contrat de style du composant.
- Utilisez `className` ou `class` pour les classes utilitaires de l’application et les ajustements de style locaux.

## Référence de l’API

Accepte aussi les props natives de son élément et `asChild`.

| Prop | Type | Défaut |
| --- | --- | --- |
| `as` | `'h1' \| 'h2' \| 'h3' \| 'h4' \| 'h5' \| 'h6'` | `'h1'` |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'` | — |
| `weight` | `'regular' \| 'medium' \| 'semibold' \| 'bold'` | `'semibold'` |
