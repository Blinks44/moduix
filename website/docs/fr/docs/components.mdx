# Composants

moduix propose des composants React accessibles et composables, fondés sur des tokens CSS partagés.
De nombreux composants interactifs s’appuient sur les primitives d’Ark UI, tout en conservant une
composition explicite dans leur API publique. Choisissez une catégorie ci-dessous, puis ouvrez une
page depuis la barre latérale ou la recherche. Chaque page contient un exemple de base à copier, la
structure des parties publiques, des notes sur le comportement et les possibilités de personnalisation
CSS du composant.

## Pour bien commencer

- Consultez le [Démarrage rapide](/docs/quick-start) pour choisir entre l’installation du package et
  la copie des fichiers sources dans votre projet.
- Lisez les [Modèles de composition](/docs/composition-patterns) avant d’encapsuler des parties de
  composant dans vos composants métier.
- Utilisez [Thèmes](/docs/themes) et [Tokens](/docs/tokens) pour les changements visuels à l’échelle
  du système. Réservez les alias de composants aux exceptions locales et intentionnelles.
- Commencez par les [Recettes](/recipes) si vous cherchez un modèle d’interface prêt à copier qui
  assemble plusieurs composants.
