# Composants

Les composants moduix sont des wrappers Ark UI stylisés et composables, fondés sur un même système de
tokens. Choisissez d’abord la catégorie qui convient, puis parcourez le catalogue complet depuis la
barre latérale ou la recherche. Chaque page présente l’arbre des parties exposées, des exemples, un
comportement cohérent avec Ark UI et les variables CSS locales.

## Avant de commencer

- Consultez le [Démarrage rapide](/docs/quick-start) pour choisir entre l’installation du package et
  la copie du code source dans votre projet.
- Lisez les [Modèles de composition](/docs/composition-patterns) avant de masquer des parties de
  composants dans vos wrappers applicatifs.
- Utilisez [Thèmes](/docs/themes) et [Tokens](/docs/tokens) pour les changements visuels à l’échelle
  du système ; réservez les alias de composants aux exceptions choisies en connaissance de cause.
- Commencez par les [Recettes](/recipes) si vous cherchez un modèle d’interface prêt à copier plutôt
  qu’une primitive isolée.
