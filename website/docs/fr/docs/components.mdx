# Composants

moduix propose des composants accessibles et composables dans chaque adaptateur publié, fondés sur des tokens CSS
partagés. Chaque implémentation conserve le même comportement public avec les API natives de son framework. De nombreux
composants interactifs s’appuient sur les primitives d’Ark UI et gardent une composition explicite.

Le catalogue ci-dessous est disponible pour React, Solid et Vue dans les paquets CSS Modules et Tailwind.
Choisissez une catégorie, puis ouvrez une page depuis la barre latérale ou la recherche. Chaque page
présente un exemple à copier, l’anatomie publique, les points d’extension des styles et, lorsqu’elles sont
utiles, des recommandations propres au composant.

## Pour bien commencer

- Consultez le [Démarrage rapide](/docs/quick-start) pour choisir entre l’installation du package et
  la copie des fichiers sources dans votre projet.
- Lisez les [Modèles de composition](/docs/composition-patterns) avant d’encapsuler des parties de
  composant dans vos composants métier.
- Utilisez [Thèmes](/docs/themes) et [Tokens](/docs/tokens) pour les changements visuels à l’échelle
  du système. Réservez les alias de composants aux exceptions locales et intentionnelles.
- Commencez par les [Blocs](/blocks) si vous cherchez une interface prête à installer qui
  assemble plusieurs composants.
