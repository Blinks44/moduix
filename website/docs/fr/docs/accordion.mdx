## Choisir le bon composant

Utilisez `Accordion` lorsque plusieurs sections liées doivent partager la même navigation au clavier
et le même état. Pour une seule section indépendante, préférez `Collapsible`.

## Exemple de base


Utilisez `Accordion` comme racine et attribuez un identifiant `value` stable à chaque élément.
Placez le libellé interactif dans le déclencheur, le panneau dans la partie de contenu, puis son
contenu interne dans le corps de l'élément. L'indicateur est facultatif et affiche par défaut
l'icône plus de moduix.

React, Solid et Vue utilisent les mêmes noms plats. Importez `Accordion` comme racine et chaque
partie supplémentaire directement, par exemple `AccordionItem` et `AccordionItemTrigger`. Les mêmes
noms fonctionnent avec les paquets npm et les sources du registre shadcn.

## Anatomie

```text
Accordion
└─ AccordionItem[value]
 ├─ AccordionItemTrigger
 │  ├─ label
 │  └─ AccordionItemIndicator (facultatif)
 └─ AccordionItemContent
    └─ AccordionItemBody
       └─ content

AccordionRootProvider
└─ même arbre d'éléments relié à l'état fourni par useAccordion()
```

| Partie                   | Rôle                                                                                         |
| ------------------------ | -------------------------------------------------------------------------------------------- |
| `Accordion`              | Racine qui gère l'état de l'accordéon et la navigation au clavier.                            |
| `AccordionRootProvider`  | Fournit aux parties l'état créé avec `useAccordion()`.                                        |
| `AccordionItem`          | Élément repliable avec une valeur `value` obligatoire et stable.                             |
| `AccordionItemTrigger`   | Bouton qui ouvre ou ferme l'élément.                                                          |
| `AccordionItemIndicator` | Indicateur facultatif. Affiche l'icône plus de moduix sans contenu enfant.                    |
| `AccordionItemContent`   | Panneau repliable qui utilise l'animation fondée sur les mesures de taille d'Ark.             |
| `AccordionItemBody`      | Conteneur interne moduix qui fournit l'espacement par défaut du panneau.                      |

## Composition

Utilisez `defaultValue` pour un accordéon non contrôlé. Utilisez `value` avec
`onValueChange(details)` lorsqu'une autre partie de l'application gère l'état. Ces deux propriétés
attendent un tableau `string[]`, même lorsqu'un seul élément peut être ouvert.

Utilisez `AccordionRootProvider` avec `useAccordion()` du paquet correspondant au framework lorsque
l’état doit être créé en dehors de l’arbre rendu. Ne rendez pas `Accordion` pour le même état. React
expose le store comme un objet, Solid donne accès à son état réactif au moyen de la fonction
retournée, et Vue expose directement le store réactif au template.

## Styles

Utilisez `className` en React ou `class` en Solid et Vue sur les parties exportées pour appliquer les styles
structurels. Pour les styles liés à l’état, privilégiez les attributs de données Ark comme
`data-state`, `data-disabled` et `data-orientation`, ainsi que les sélecteurs `data-slot` de moduix.
Les variantes Tailwind se personnalisent avec des utilitaires et des classes supplémentaires. Les
variables de composant ci-dessous concernent uniquement les variantes CSS Modules ; les attributs de
données, les sélecteurs `data-slot` et les variables d’exécution Ark sont communs aux deux approches.

Placez l’espacement du panneau sur `AccordionItemBody` plutôt que sur `AccordionItemContent` afin
qu’Ark puisse mesurer et animer correctement le panneau.

### Points d’accroche CSS

- Sélecteurs `data-slot` stables : `accordion-root`, `accordion-root-provider`, `accordion-item`,
  `accordion-item-trigger`, `accordion-item-indicator`, `accordion-item-content` et
  `accordion-item-body`.
- Sélecteurs des parties Ark : `data-scope="accordion"` et
  `data-part="root|item|item-trigger|item-indicator|item-content"`.
- Sélecteur spécifique à moduix : `data-part="item-body"` sur la partie interne de l'élément.
- Sélecteurs d'état Ark : `data-state="open|closed"`, `data-disabled`, `data-focus`, `data-controls`
  et `data-orientation="horizontal|vertical"`.
- Variables de contenu Ark : `--height` pour l'animation verticale et `--width` pour l'animation horizontale.
