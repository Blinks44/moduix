## Choisir le bon composant

Utilisez `Accordion` lorsque plusieurs sections liées doivent partager la même navigation au clavier
et le même état. Pour une seule section indépendante, préférez `Collapsible`.

## Exemple de base


Utilisez `Accordion` comme racine et attribuez un identifiant `value` stable à chaque
`Accordion.Item`.
Placez le libellé interactif dans `Accordion.ItemTrigger`, le panneau dans
`Accordion.ItemContent`, puis son contenu interne dans `Accordion.ItemBody`. `Accordion.ItemIndicator`
est facultatif et affiche par défaut l'icône plus de moduix.

Utilisez `Accordion` comme racine dans la plupart des cas. `Accordion.Root` est un alias de cette
même racine lorsque vous souhaitez rendre cette partie explicite dans votre composition.

## Anatomie

```text
Accordion / Accordion.Root
└─ Accordion.Item[value]
 ├─ Accordion.ItemTrigger
 │  ├─ label
 │  └─ Accordion.ItemIndicator (facultatif)
 └─ Accordion.ItemContent
    └─ Accordion.ItemBody
       └─ content

Accordion.RootProvider
└─ même arbre d'éléments relié à l'état fourni par useAccordion()
```

| Partie                         | Rôle                                                                                              |
| ------------------------------ | ------------------------------------------------------------------------------------------------- |
| `Accordion` / `Accordion.Root` | Racine qui gère l'état de l'accordéon et la navigation au clavier.                                |
| `Accordion.RootProvider`       | Fournit aux parties l'état créé avec `useAccordion()`.                                            |
| `Accordion.Item`               | Élément repliable avec une valeur `value` obligatoire et stable.                                  |
| `Accordion.ItemTrigger`        | Bouton qui ouvre ou ferme l'élément.                                                              |
| `Accordion.ItemIndicator`      | Indicateur facultatif. Affiche l'icône plus de moduix lorsqu'aucun enfant n'est fourni.           |
| `Accordion.ItemContent`        | Panneau repliable qui utilise l'animation fondée sur les mesures de taille d'Ark.                |
| `Accordion.ItemBody`           | Conteneur interne moduix qui fournit l'espacement par défaut du panneau.                          |

## Composition

Utilisez `defaultValue` pour un accordéon non contrôlé. Utilisez `value` avec
`onValueChange(details)` lorsqu'une autre partie de l'application gère l'état. Ces deux propriétés
attendent un tableau `string[]`, même lorsqu'un seul élément peut être ouvert.

Utilisez `Accordion.RootProvider` avec `useAccordion()` du paquet correspondant au framework lorsque
l’état doit être créé en dehors de l’arbre rendu. Transmettez le store obtenu à `RootProvider` et ne
rendez pas `Accordion` ou `Accordion.Root` pour le même état. React expose le store comme un objet ;
Solid donne accès à son état réactif au moyen de la fonction retournée.

## Styles

Utilisez `className` en React ou `class` en Solid sur les parties exportées pour appliquer les styles
structurels. Pour les styles liés à l’état, privilégiez les attributs de données Ark comme
`data-state`, `data-disabled` et `data-orientation`, ainsi que les sélecteurs `data-slot` de moduix.
Les variantes Tailwind se personnalisent avec des utilitaires et des classes supplémentaires. Les
variables de composant ci-dessous concernent uniquement les variantes CSS Modules ; les attributs de
données, les sélecteurs `data-slot` et les variables d’exécution Ark sont communs aux deux approches.

Placez l’espacement du panneau sur `Accordion.ItemBody`, et non sur `Accordion.ItemContent`, afin
qu’Ark puisse mesurer et animer correctement le panneau.

### Points d’accroche CSS

- Sélecteurs `data-slot` stables : `accordion-root`, `accordion-root-provider`, `accordion-item`,
  `accordion-item-trigger`, `accordion-item-indicator`, `accordion-item-content` et
  `accordion-item-body`.
- Sélecteurs des parties Ark : `data-scope="accordion"` et
  `data-part="root|item|item-trigger|item-indicator|item-content"`.
- Sélecteur spécifique à moduix : `data-part="item-body"` sur `Accordion.ItemBody`.
- Sélecteurs d'état Ark : `data-state="open|closed"`, `data-disabled`, `data-focus`, `data-controls`
  et `data-orientation="horizontal|vertical"`.
- Variables de contenu Ark : `--height` pour l'animation verticale et `--width` pour l'animation horizontale.
