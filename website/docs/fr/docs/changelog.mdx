<ChangelogNewsItem>
  <TailwindReleaseHero />

Tailwind est maintenant disponible pour tout le catalogue moduix. [`@moduix/react-tailwind`](/docs/quick-start)
et `@moduix/solid-tailwind` couvrent les mêmes composants que les paquets CSS Modules.

### Tailwind pour tout le catalogue

L’API publique et le comportement des composants restent identiques. Le choix de Tailwind ne change
donc pas la manière de les composer.

Vos valeurs `className` ou `class` sont fusionnées après les valeurs par défaut avec `tailwind-merge`.
Les espaces de noms du registre `@moduix-react-tailwind` et `@moduix-solid-tailwind` incluent la
feuille de style de base, prête à être personnalisée.
</ChangelogNewsItem>

<ChangelogNewsItem>
  <SolidReleaseHero />

Le catalogue complet de moduix est maintenant disponible pour Solid. [`@moduix/solid`](/docs/quick-start)
et `@moduix/solid-tailwind` utilisent les API natives de Solid et les primitives Ark UI.

### Le catalogue complet pour Solid

Les composants Solid utilisent `class` et la composition native de Solid. Leurs contrats publics
correspondent à ceux des paquets React, tout en respectant le modèle de rendu de Solid.

CSS Modules et Tailwind sont tous deux disponibles pour Solid. Les deux variantes partagent les
tokens, les thèmes et les espaces de noms du registre `@moduix-solid` et `@moduix-solid-tailwind`.
</ChangelogNewsItem>

<ChangelogNewsItem>
  <TableOfContentsHero />

[Table of Contents](/docs/table-of-contents) suit les titres visibles et indique la section active.
Indiquez les titres à suivre pour relier chaque entrée au titre correspondant.

### Un sommaire pour les pages longues

Utilisez `Toc.Content` pour la zone de lecture et `Toc.Nav` pour la liste des titres. L’entrée active
change au fil du défilement.

Utilisez `Toc.Indicator` ou `Toc.Rail` pour montrer la hiérarchie. Ajoutez `Toc.RootProvider` lorsque
des contrôles externes doivent partager l’état du sommaire.
</ChangelogNewsItem>

<ChangelogNewsItem>
  <NavigationMenuHero />

[Navigation Menu](/docs/navigation-menu) sépare les destinations directes des groupes de liens
associés. C’est utile pour la navigation principale d’un site ou d’un produit.

### Des groupes de liens sans masquer les destinations

Utilisez `NavigationMenuLink` pour une destination directe. Pour un groupe de liens, associez
`NavigationMenuTrigger` à `NavigationMenuContent`.

Ajoutez `NavigationMenuViewport` lorsque plusieurs panneaux doivent s’animer dans une même zone.
Ark UI gère le clavier, le focus et l’élément ouvert. `NavigationMenuArrow` est facultatif.
</ChangelogNewsItem>

<ChangelogNewsItem>
  <ChartHero />

[Chart](/docs/chart) ajoute une balise `figure` accessible autour de TanStack Charts. Définissez le
graphique avec TanStack, puis ajoutez l’en-tête, la légende, l’infobulle compacte et les réglages
d’animation de moduix.

### Une figure cohérente pour les graphiques

TanStack garde la responsabilité des marques, des échelles, des interactions et des fonctions de
rappel. Composez le graphique avec `Chart.Header`, `Chart.Plot` et `Chart.Legend` pour obtenir une
structure `figure` cohérente.

TanStack gère aussi la navigation au clavier et le cycle de vie de l’infobulle. L’animation moduix
respecte la préférence pour la réduction des mouvements, et `motion={false}` la désactive.
</ChangelogNewsItem>

<ChangelogNewsItem>
  <LocalizationHero />

La documentation est maintenant disponible en anglais, en français et en russe. Les pages de
composants, les exemples et les recettes sont traduits partout.

### La documentation en trois langues

Vous pouvez lire un guide, copier un exemple et suivre une recette sans changer de langue.

La navigation, les métadonnées, les routes adaptées à chaque langue et les exemples copiables restent
alignés dans les trois langues.
</ChangelogNewsItem>

<ChangelogNewsItem>
  <V2MigrationHero />

Le système de composants utilise maintenant Ark UI pour l’état, les interactions et l’accessibilité
lorsqu’une primitive correspondante existe. moduix conserve ses CSS Modules, ses tokens de design et
ses deux modes d’installation.

### Ark UI gère le comportement des composants

Les composants qui disposent d’une primitive Ark UI l’utilisent pour l’état et les interactions. Ils
profitent aussi du comportement d’accessibilité fourni par Ark UI.

La composition publique et les propriétés de bas niveau suivent les contrats Ark. Installez le paquet
ou copiez le code source dans votre application si vous devez garder la main sur l’implémentation.
</ChangelogNewsItem>
