Utilisez `ScrollArea` comme racine. Placez `ScrollAreaViewport` autour de `ScrollAreaContent`,
ajoutez un `ScrollAreaScrollbar` et un `ScrollAreaThumb` pour chaque axe de défilement, puis ajoutez
`ScrollAreaCorner` lorsque les deux axes peuvent
déborder. Donnez à la racine une hauteur ou une taille de bloc limitée pour que le contenu puisse
défiler.

## Composition

Chaque axe de défilement nécessite sa propre `ScrollAreaScrollbar` avec un `ScrollAreaThumb`. La
barre verticale est utilisée par défaut ; définissez `orientation="horizontal"` pour un axe
horizontal. Gardez `ScrollAreaViewport` autour de `ScrollAreaContent` et conservez une arborescence complète et
indépendante pour les zones imbriquées.

Utilisez `ScrollAreaRootProvider` avec `useScrollArea()` lorsque des contrôles externes
doivent accéder à l’API de défilement. Passez le store renvoyé à `ScrollAreaRootProvider` et ne
rendez pas `ScrollArea` et `ScrollAreaRootProvider` pour le même store. Dans Solid, lisez et utilisez le store
via l’accesseur renvoyé par `useScrollArea()`.

## Anatomie

```text
ScrollArea
├─ ScrollAreaViewport
│  └─ ScrollAreaContent
│     └─ children
├─ ScrollAreaScrollbar
│  └─ ScrollAreaThumb
└─ ScrollAreaCorner

ScrollAreaRootProvider
└─ même arborescence reliée à un store useScrollArea()
```

| Partie                           | Rôle                                                               |
| -------------------------------- | ------------------------------------------------------------------ |
| `ScrollArea`                     | Racine qui gère l’état du défilement et le positionnement.         |
| `ScrollAreaRootProvider`        | Relie les parties à l’état créé avec `useScrollArea()`.           |
| `ScrollAreaViewport`            | Conteneur de défilement natif et cible du focus.                   |
| `ScrollAreaContent`             | Enveloppe interne mesurée par Ark UI.                              |
| `ScrollAreaScrollbar`           | Piste de défilement stylisée pour un axe.                          |
| `ScrollAreaThumb`               | Curseur déplaçable dans une piste.                                 |
| `ScrollAreaCorner`              | Remplit l’intersection lorsque les deux axes débordent.            |

## Styles

Le tableau des variables CSS s’applique aux paquets CSS Modules. Les paquets Tailwind utilisent
leurs utilitaires natifs et les remplacements `className` ou `class` fournis par le consommateur.
Définissez les variables CSS sur la racine pour modifier l’épaisseur des barres, la couleur du curseur
ou la profondeur du fondu. Le viewport hérite du `border-radius` de la racine : une racine arrondie
arrondit aussi le contenu découpé et l’anneau de focus.

### Points d’accroche CSS

| Partie | `data-slot` |
| --- | --- |
| `ScrollArea` | `scroll-area-root` |
| `ScrollAreaRootProvider` | `scroll-area-root-provider` |
| `ScrollAreaViewport` | `scroll-area-viewport` |
| `ScrollAreaContent` | `scroll-area-content` |
| `ScrollAreaScrollbar` | `scroll-area-scrollbar` |
| `ScrollAreaThumb` | `scroll-area-thumb` |
| `ScrollAreaCorner` | `scroll-area-corner` |

- La propriété `fade` ajoute `data-fade`, tandis que `variant` ajoute
  `data-variant="hover" | "always"` à `ScrollArea` et `ScrollAreaRootProvider`.
- Ark ajoute `data-scope="scroll-area"` et `data-part` à chaque partie.
- `data-overflow-x` et `data-overflow-y` apparaissent lorsque le contenu mesuré déborde sur l’axe
  correspondant.
- `data-at-top`, `data-at-bottom`, `data-at-left` et `data-at-right` sont disponibles sur
  `ScrollAreaViewport`.
- `data-orientation="vertical"` et `data-orientation="horizontal"` sont disponibles sur les
  barres de défilement et les curseurs.
- `data-hover` et `data-dragging` sont disponibles sur les parties de barre et les curseurs ;
  `data-scrolling` est disponible sur les parties de barre.
- Les variables racines Ark `--corner-width`, `--corner-height`, `--thumb-width` et `--thumb-height`
  pilotent le décalage de l’angle et les dimensions du curseur. Les variables de viewport Ark
  `--scroll-area-overflow-x-start`, `--scroll-area-overflow-x-end`,
  `--scroll-area-overflow-y-start` et `--scroll-area-overflow-y-end` indiquent les distances par
  rapport aux bords.

## Référence de l’API

| Prop | Type | Défaut |
| --- | --- | --- |
| `variant` | `'hover' \| 'always'` | `'hover'` |
| `fade` | `boolean` | `false` |
| `asChild` | `boolean` | `false` |
