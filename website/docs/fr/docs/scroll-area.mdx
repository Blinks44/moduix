## Exemple de base

ScrollArea est disponible pour React et Solid, dans les paquets CSS Modules comme dans les variantes
Tailwind. L’aperçu de cette page utilise React et CSS Modules ; les onglets de code montrent le code
natif correspondant au même contrat public.

Utilisez `ScrollArea` comme racine. Placez `Viewport` autour de `Content`, ajoutez un `Scrollbar`
et un `Thumb` pour chaque axe de défilement, puis ajoutez `Corner` lorsque les deux axes peuvent
déborder. Donnez à la racine une hauteur ou une taille de bloc limitée pour que le contenu puisse

## Anatomie

```text
ScrollArea / ScrollArea.Root
├─ ScrollArea.Viewport
│  └─ ScrollArea.Content
│     └─ children
├─ ScrollArea.Scrollbar
│  └─ ScrollArea.Thumb
└─ ScrollArea.Corner

ScrollArea.RootProvider
└─ même arborescence reliée à un store useScrollArea()
```

| Partie                           | Rôle                                                               |
| -------------------------------- | ------------------------------------------------------------------ |
| `ScrollArea` / `ScrollArea.Root` | Racine qui gère l’état du défilement et le positionnement.         |
| `ScrollArea.RootProvider`        | Relie les parties à l’état créé avec `useScrollArea()`.           |
| `ScrollArea.Viewport`            | Conteneur de défilement natif et cible du focus.                   |
| `ScrollArea.Content`             | Enveloppe interne mesurée par Ark UI.                              |
| `ScrollArea.Scrollbar`           | Piste de défilement stylisée pour un axe.                          |
| `ScrollArea.Thumb`               | Curseur déplaçable dans une piste.                                 |
| `ScrollArea.Corner`              | Remplit l’intersection lorsque les deux axes débordent.            |

## Composition

Chaque axe de défilement nécessite sa propre `ScrollArea.Scrollbar` avec un `ScrollArea.Thumb`. La
barre verticale est utilisée par défaut ; définissez `orientation="horizontal"` pour un axe
horizontal. Gardez `Viewport` autour de `Content` et conservez une arborescence complète et
indépendante pour les zones imbriquées.

Utilisez `ScrollArea.RootProvider` avec `ScrollArea.useScrollArea()` lorsque des contrôles externes
doivent accéder à l’API de défilement. Passez le store renvoyé à `RootProvider` et ne rendez pas
`ScrollArea` et `ScrollArea.RootProvider` pour le même store. Dans Solid, lisez et utilisez le store
via l’accesseur renvoyé par `useScrollArea()`.

## Styles

Le tableau des variables CSS s’applique aux paquets CSS Modules. Les paquets Tailwind utilisent
leurs utilitaires natifs et les remplacements `className` ou `class` fournis par le consommateur.
Utilisez les variables CSS sur la racine pour modifier l’épaisseur des barres, l’anneau de focus ou
la surface sans remplacer la structure.

### Points d’accroche CSS

- moduix ajoute des points d’accroche `data-slot` stables avec les valeurs `scroll-area-root`,
  `scroll-area-root-provider`, `scroll-area-viewport`, `scroll-area-content`,
  `scroll-area-scrollbar`, `scroll-area-thumb` et `scroll-area-corner`.
- La propriété `fade` ajoute `data-fade`, tandis que `variant` ajoute
  `data-variant="hover" | "always"` à `ScrollArea` et `ScrollArea.RootProvider`.
- Ark ajoute `data-scope="scroll-area"` et `data-part` à chaque partie.
- `data-overflow-x` et `data-overflow-y` apparaissent lorsque le contenu mesuré déborde sur l’axe
  correspondant.
- `data-at-top`, `data-at-bottom`, `data-at-left` et `data-at-right` sont disponibles sur le
  `Viewport`.
- `data-orientation="vertical"` et `data-orientation="horizontal"` sont disponibles sur les
  barres de défilement et les curseurs.
- `data-hover` et `data-dragging` sont disponibles sur les parties de barre et les curseurs ;
  `data-scrolling` est disponible sur les parties de barre.
- Les variables racines Ark `--corner-width`, `--corner-height`, `--thumb-width` et `--thumb-height`
  pilotent le décalage de l’angle et les dimensions du curseur. Les variables de viewport Ark
  `--scroll-area-overflow-x-start`, `--scroll-area-overflow-x-end`,
  `--scroll-area-overflow-y-start` et `--scroll-area-overflow-y-end` indiquent les distances par
  rapport aux bords.
