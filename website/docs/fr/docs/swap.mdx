Utilisez `Swap` lorsqu’un élément de l’interface doit basculer entre deux états visuels, par exemple
une icône qui change après une action. Passez la valeur booléenne courante à `swap` : `false` affiche
l’indicateur `off` et `true` affiche l’indicateur `on`.

## Exemples

### Préréglages d’animation

Choisissez un préréglage intégré, puis activez le bouton pour voir la transition sélectionnée. La
valeur courante et les boutons de sélection sont affichés sous la démonstration.

### Animation personnalisée

Passez un nom personnalisé à `animation` et ciblez `data-animation` sur la racine ainsi que les
attributs `data-state` d’Ark sur les indicateurs. Le préréglage `bounce` ci-dessous est écrit en CSS
ordinaire. Une animation personnalisée doit définir son entrée et sa sortie, avec une règle de secours
pour la réduction des mouvements.

<Example name="swap/custom-animation" />

### Root Provider

Créez l’état de `Swap` séparément avec `useSwap()`, puis transmettez-le à `SwapRootProvider`
via la propriété `value`. Cet exemple utilise également `asChild`, de sorte que le bouton sémantique
devient la racine rendue de `Swap`.

## Composition

`Swap` est purement visuel. L’état, l’interaction, le focus et le nom accessible doivent rester sur
le contrôle sémantique environnant. Pour les indicateurs composés uniquement d’icônes, utilisez
`aria-hidden="true"`. Placez les deux indicateurs directement dans la racine afin qu’ils partagent une
cellule de grille et que les préréglages intégrés restent limités à cette instance de `Swap`.

Par défaut, `Swap` utilise l’animation `scale`. Passez `fade`, `scale`, `rotate` ou `flip` à
`animation`, ou utilisez un nom personnalisé et définissez son CSS avec `data-animation` sur la racine
et les attributs `data-state` d’Ark sur les indicateurs. Lorsque l’état doit être créé en dehors de
l’arbre rendu, passez `useSwap()` à `SwapRootProvider` et ne rendez pas une autre racine pour ce
même état. Avec `asChild`, fournissez exactement un enfant sémantique.

## Anatomie

```text
Swap
├─ SwapIndicator type="off"
└─ SwapIndicator type="on"

SwapRootProvider
└─ même arbre d’indicateurs relié à un état créé avec useSwap()
```

| Partie               | Rôle                                                               |
| -------------------- | ------------------------------------------------------------------ |
| `Swap` | Fournit l’état `swap` et superpose les deux états visuels.         |
| `SwapRootProvider`  | Relie les parties à l’état créé avec `useSwap()`.             |
| `SwapIndicator`     | Affiche l’état `on` ou `off` sélectionné par la propriété `type`.  |

## Styles

Dans les variantes CSS Modules, `--moduix-swap-transition` règle la durée des préréglages intégrés. Les
variantes Tailwind utilisent des classes utilitaires natives et les classes du consommateur. Pour un
autre mouvement, passez un nom d’animation personnalisé : il désactive les préréglages intégrés, et vous
pouvez toujours réutiliser `--moduix-swap-transition` dans votre CSS.

Ark fige la mise en page avec des styles inline : la racine reçoit `display: inline-grid`, et chaque
indicateur reçoit `grid-area: 1 / 1` et `display: inline-flex`. Les remplacements de `display` et
`grid-area` par des classes sont sans effet dans les deux variantes ; modifiez plutôt ces propriétés
via la prop `style` (par exemple `style={{ display: 'grid' }}`).

Dans les variantes Tailwind, le préréglage flip applique `data-[animation=flip]:[perspective:24rem]`
sur la racine, qui l’emporte sur un simple utilitaire `perspective` du consommateur ; répétez donc ce
variant documenté (par exemple `data-[animation=flip]:[perspective:32rem]`) pour le remplacer.

### Points d’accroche CSS

| Partie | `data-slot` |
| --- | --- |
| `Swap` | `swap-root` |
| `SwapRootProvider` | `swap-root-provider` |
| `SwapIndicator` | `swap-indicator` |

- `animation` est exposée sous forme de `data-animation` sur `Swap` et `SwapRootProvider`.
- Avec CSS Modules, les préréglages intégrés ciblent uniquement les enfants directs `SwapIndicator` de
  leur racine. Les préréglages Tailwind lisent l’ancêtre `group/swap` le plus proche : n’imbriquez pas
  un `Swap` dans un autre.
- Ark ajoute `data-scope="swap"` et `data-part="root" | "indicator"`.
- Ark ajoute `data-state="open" | "closed"` aux indicateurs. moduix utilise ces attributs pour ses
  animations intégrées et personnalisées.

## Référence de l’API

`Swap` ne gère pas les interactions : le contrôle qui l’entoure reste responsable du clavier et des clics.

| Prop | Type | Défaut |
| --- | --- | --- |
| `swap` | `boolean` | `false` |
| `animation` | `SwapAnimation` | `'scale'` |
| `type` (SwapIndicator) | `'on'` / `'off'` | — |
