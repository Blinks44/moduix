une icône qui change après une action. Passez la valeur booléenne courante à `swap` : `false` affiche
l’indicateur `off` et `true` affiche l’indicateur `on`.

## Anatomie

```text
Swap / Swap.Root
├─ Swap.Indicator type="off"
└─ Swap.Indicator type="on"

Swap.RootProvider
└─ même arbre d’indicateurs relié à un état créé avec Swap.useSwap()
```

| Partie               | Rôle                                                               |
| -------------------- | ------------------------------------------------------------------ |
| `Swap` / `Swap.Root` | Fournit l’état `swap` et superpose les deux états visuels.         |
| `Swap.RootProvider`  | Relie les parties à l’état créé avec `Swap.useSwap()`.             |
| `Swap.Indicator`     | Affiche l’état `on` ou `off` sélectionné par la propriété `type`.  |

## Composition

`Swap` est purement visuel. L’état, l’interaction, le focus et le nom accessible doivent rester sur
le contrôle sémantique environnant. Pour les indicateurs composés uniquement d’icônes, utilisez
`aria-hidden="true"`. Placez les deux indicateurs directement dans la racine afin qu’ils partagent une
cellule de grille et que les préréglages intégrés restent limités à cette instance de `Swap`.

Par défaut, `Swap` utilise l’animation `scale`. Passez `fade`, `scale`, `rotate` ou `flip` à
`animation`, ou utilisez un nom personnalisé et définissez son CSS avec `data-animation` sur la racine
et les attributs `data-state` d’Ark sur les indicateurs. Lorsque l’état doit être créé en dehors de
l’arbre rendu, passez `Swap.useSwap()` à `Swap.RootProvider` et ne rendez pas une autre racine pour ce
même état. Avec `asChild`, fournissez exactement un enfant sémantique.

## Styles

Les préréglages intégrés utilisent les propriétés CSS ci-dessous dans les variantes CSS Modules. Les
variantes Tailwind utilisent des classes utilitaires natives et les classes du consommateur. Un nom
d’animation personnalisé désactive les préréglages intégrés, mais vous pouvez toujours réutiliser
`--moduix-swap-transition` dans votre CSS.

Ark fige la mise en page avec des styles inline : la racine reçoit `display: inline-grid`, et chaque
indicateur reçoit `grid-area: 1 / 1` et `display: inline-flex`. Les remplacements de `display` et
`grid-area` par des classes sont sans effet dans les deux variantes ; modifiez plutôt ces propriétés
via la prop `style` (par exemple `style={{ display: 'grid' }}`).

Dans les variantes Tailwind, le préréglage flip applique `data-[animation=flip]:[perspective:24rem]`
sur la racine, qui l’emporte sur un simple utilitaire `perspective` du consommateur ; répétez donc ce
variant documenté (par exemple `data-[animation=flip]:[perspective:32rem]`) pour le remplacer, tandis
que la variante CSS Modules expose plutôt `--moduix-swap-flip-perspective`.

### Points d’accroche CSS

- `Swap.Root` utilise `data-slot="swap-root"`.
- `Swap.RootProvider` utilise `data-slot="swap-root-provider"`.
- `Swap.Indicator` utilise `data-slot="swap-indicator"`.
- `animation` est exposée sous forme de `data-animation` sur `Swap` et `Swap.RootProvider`.
- Les préréglages intégrés ciblent uniquement les enfants directs `Swap.Indicator` de leur racine.
- Ark ajoute `data-scope="swap"` et `data-part="root" | "indicator"`.
- Ark ajoute `data-state="open" | "closed"` aux indicateurs. moduix utilise ces attributs pour ses
  animations intégrées et personnalisées.
