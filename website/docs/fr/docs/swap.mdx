## Exemple de base

Utilisez `Swap` lorsqu’un élément de l’interface doit basculer entre deux états visuels, par exemple
une icône qui change après une action. Passez la valeur booléenne courante à `swap` : `false` affiche
l’indicateur `off` et `true` l’indicateur `on`. Le contrôle englobant reste responsable de l’interaction
et du nom accessible.

## Anatomie

```text
Swap / Swap.Root
├─ Swap.Indicator type="off"
└─ Swap.Indicator type="on"
```

| Partie                | Rôle                                                                  |
| --------------------- | --------------------------------------------------------------------- |
| `Swap` / `Swap.Root`  | Fournit l’état Ark `swap` et superpose les deux états visuels.        |
| `Swap.RootProvider`   | Fournit l’état créé avec `Swap.useSwap()` en dehors du sous-arbre.    |
| `Swap.Indicator`      | Affiche l’état `on` ou `off` sélectionné par la propriété `type`.     |

Placez les deux indicateurs directement dans la racine. Ils partagent une cellule de grille, et les
préréglages d’animation intégrés restent limités à cette instance de `Swap`.

## Composition

### Composition recommandée

`Swap` est une primitive visuelle, pas un bouton ni un interrupteur. Placez-le dans un bouton, un lien
ou un élément sémantique qui présente un statut. Laissez l’état, les gestionnaires d’événements, le
focus et le nom accessible au parent. Si les indicateurs contiennent uniquement des icônes, ajoutez-leur
`aria-hidden="true"`.

### Quand utiliser une animation personnalisée

Utilisez `animation` pour choisir l’un des préréglages intégrés : `fade`, `scale`, `rotate` ou `flip`.
La propriété accepte également un nom personnalisé. moduix l’inscrit dans `data-animation` et n’applique
aucune animation intégrée. Vous pouvez donc définir la transition en CSS à partir des attributs
`data-state` d’Ark.

### Propriétés par défaut

| Propriété       | Valeur par défaut | Description                                                         |
| --------------- | ----------------- | ------------------------------------------------------------------- |
| `swap`          | `false`           | Affiche l’indicateur `off`.                                        |
| `animation`     | `scale`           | Utilise le préréglage moduix combinant fondu et mise à l’échelle.  |
| `lazyMount`     | `false`           | Monte immédiatement les deux indicateurs.                         |
| `unmountOnExit` | `false`           | Conserve l’indicateur monté après son animation de sortie.         |

### Comportement

- `swap` est contrôlé. `Swap` ne réagit pas de lui-même au survol ou aux clics et rend un élément `span`
  par défaut.
- Presence d’Ark ajoute `data-state="open" | "closed"` aux indicateurs afin que le CSS distingue leur
  entrée et leur sortie. Utilisez `lazyMount` ou `unmountOnExit` pour contrôler le moment où les
  indicateurs inactifs sont ajoutés au DOM ou retirés.
- `Swap.RootProvider` accepte l’état renvoyé par `Swap.useSwap()`. `useSwapContext()` permet à un
  descendant de lire l’état du fournisseur le plus proche.
- `asChild` est disponible sur chaque partie rendue. Fournissez exactement un enfant sémantique afin
  qu’Ark puisse lui transmettre ses propriétés et sa ref.

## Styles

Les préréglages intégrés utilisent les propriétés CSS listées ci-dessous. Un nom d’animation personnalisé
désactive ces préréglages, mais vous pouvez toujours réutiliser `--moduix-swap-transition` dans votre CSS.

### Propriétés CSS

### Points d’accroche CSS

- `Swap.Root` utilise `data-slot="swap-root"`.
- `Swap.RootProvider` utilise `data-slot="swap-root-provider"`.
- `Swap.Indicator` utilise `data-slot="swap-indicator"`.
- `animation` est exposée sous forme de `data-animation` sur `Swap` et `Swap.RootProvider`.
- Les préréglages intégrés ciblent uniquement les enfants directs `Swap.Indicator` de leur racine.
- Ark ajoute `data-scope="swap"` et `data-part="root" | "indicator"`.
- Ark ajoute `data-state="open" | "closed"` aux indicateurs. moduix utilise ces attributs pour ses
  animations intégrées et personnalisées.
