# TanStack Form

[TanStack Form](https://tanstack.com/form/latest) fournit un état de formulaire typé et sans interface,
avec des adaptateurs natifs pour chaque framework pris en charge. Ce guide relie cet état aux composants Moduix.

## Relier les composants

Les champs TanStack Form utilisent des valeurs contrôlées. Lisez la valeur courante, transmettez-la au
composant Moduix, puis envoyez la suivante à `field.handleChange`.

| Composant           | Correspondance                                                        |
| ------------------- | --------------------------------------------------------------------- |
| `Input`, `Textarea` | Transmettez la valeur scalaire et mettez-la à jour depuis l’événement input. |
| `Select`            | Convertissez la valeur scalaire vers le tableau de chaînes d’Ark.     |
| `Combobox`          | Reliez la valeur sélectionnée et gardez le filtrage séparé.           |
| `Checkbox`          | Convertissez `details.checked === true` en valeur booléenne.          |

Définissez tous les champs dans `defaultValues`. Transmettez `handleBlur` depuis la véritable limite
d’interaction et conservez le `HiddenSelect` ou `HiddenInput` requis dans la composition Moduix.

## Validation et réinitialisation

Utilisez les validateurs de champ pour les règles locales et ceux du formulaire pour les schémas ou
les règles entre champs. Transmettez `!field.state.meta.isValid` à `Field invalid`, puis affichez les
erreurs avec `Field.ErrorText` après le cycle de validation choisi.

Ajoutez `noValidate` uniquement lorsque TanStack Form gère les erreurs visibles. Appelez
`form.reset()` afin de réinitialiser ensemble l’état et les contrôles Moduix.

## Champs répétés et erreurs du serveur

Utilisez un champ en mode tableau pour ajouter, supprimer et réordonner des éléments. Donnez à chaque
ligne un identifiant applicatif stable pour le rendu indexé et gardez l’index uniquement dans le nom
du champ imbriqué.

Depuis un validateur asynchrone du formulaire, renvoyez `fields` pour les erreurs liées à une valeur et
le message facultatif `form` pour une erreur générale. Le rendu habituel du champ affiche alors les
résultats côté client et côté serveur au même endroit.

## Focus et comportement

- Utilisez `onSubmitInvalid` pour focaliser le premier contrôle visible marqué `aria-invalid="true"`.
- Dans React, lisez `field.state`. Dans Solid, lisez `field().state`.
- Dans React, les valeurs d’abonnement sont directes. Dans Solid, lisez-les depuis l’accesseur.
- Utilisez l’événement input natif pour les champs texte Solid et convertissez les détails Ark explicitement.
- Appelez `form.handleSubmit()` depuis le gestionnaire du formulaire natif après `preventDefault()`.
