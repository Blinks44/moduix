## Référence de l’API

Ark UI ne fournit pas de primitive `aspect-ratio` dédiée. moduix construit ce composant à partir de la
[fabrique Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) officielle et suit les recommandations d’Ark pour la
[composition](https://ark-ui.com/docs/guides/composition), la [mise en forme](https://ark-ui.com/docs/guides/styling) et l’utilisation de
[ref](https://ark-ui.com/docs/guides/ref).

## Exemple de base

Commencez par `AspectRatio`. Définissez la largeur ou la largeur maximale sur l’élément racine, puis transmettez à `ratio`
un nombre fini strictement positif. Les enfants directs `img`, `video`, `iframe`, `canvas` et `svg` remplissent automatiquement
le cadre. Définissez `object-fit` sur les images et les vidéos pour choisir entre le recadrage et l’affichage complet du contenu.

## Composition

### Composition recommandée

Utilisez `AspectRatio` pour la plupart des conteneurs de médias. Placez sur la racine les classes qui définissent les dimensions,
le rayon et la mise en page. `AspectRatio.Root` expose le même élément racine pour conserver une API cohérente dans la bibliothèque.

- `ratio` est obligatoire et doit être un nombre fini strictement positif pour produire un comportement CSS valide
- `asChild` utilise la composition de la fabrique Ark et nécessite exactement un élément React
- les enfants directs `img`, `video`, `iframe`, `canvas` et `svg` remplissent automatiquement le cadre ; définissez
  `object-fit` sur les images et les vidéos pour choisir entre recadrer le contenu et l’afficher en entier
- `className` applique directement les styles et les dimensions à la racine
- `--moduix-aspect-ratio-radius` définit le rayon des coins du cadre par défaut

### Quand ajouter un conteneur extérieur

Encapsulez `AspectRatio` dans un élément extérieur si les ombres, les anneaux de focus ou les éléments décoratifs doivent dépasser
du cadre. Conservez le découpage sur la racine. Si le rapport doit changer selon la largeur de l’écran, redéfinissez
`aspect-ratio` dans votre CSS.

### Propriétés par défaut

| Paramètre | Par défaut | Valeurs / remarques |
| ------------------------------ | ------------------------- | ------------------------------------ |
| `ratio` | - | Nombre fini strictement positif obligatoire |
| `className` | `undefined` | Applique les styles et les dimensions à la racine |
| `style` | `undefined` | Peut remplacer `aspect-ratio` directement |
| `asChild` | `undefined` | Composition via la fabrique Ark |
| `--moduix-aspect-ratio-radius` | `var(--moduix-radius-md)` | Longueur CSS ou valeur de token |

### Comportement

- La racine reçoit les attributs `data-scope="aspect-ratio"`, `data-part="root"` et
  `data-slot="aspect-ratio-root"`.
- La racine est un élément de type bloc et utilise `box-sizing: border-box`, y compris lorsque `asChild` change l’élément rendu.
- `position: relative` est appliqué intentionnellement à la racine. Il permet d’utiliser des enfants positionnés en absolu qui
  remplissent le conteneur, comme `Image fill` de Next.js.
- Les enfants directs `iframe` remplissent le cadre sans la bordure par défaut du navigateur.
- Les anciennes valeurs prédéfinies (`square`, `video`, `portrait`, `photo`) ont été supprimées lors de la migration vers Ark.
  Utilisez des valeurs numériques telles que `1`, `16 / 9`, `9 / 16` et `4 / 3`.

### Points d’accroche CSS

- `data-scope="aspect-ratio"` et `data-part="root"` servent de points d’accroche de la racine, conformément à Ark.
- `data-slot="aspect-ratio-root"` est le point d’accroche stable de la racine moduix.
- Placez les styles de largeur, de largeur maximale et de mise en page sur la racine. Si le rapport doit changer selon la largeur
  de l’écran, redéfinissez `aspect-ratio` dans votre CSS.
- Les médias directs utilisent `box-sizing: border-box`. Les images et les vidéos conservent leur valeur `object-fit`, afin que
  vous puissiez choisir entre recadrer le contenu et l’afficher en entier.
- `overflow: hidden` est intentionnel. Si un élément décoratif doit dépasser du cadre, placez-le dans un conteneur extérieur
  au lieu de supprimer le rognage de la racine.
