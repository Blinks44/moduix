## Anatomie

```text
SignaturePad / SignaturePad.Root
├─ SignaturePad.Label
├─ SignaturePad.Canvas (composition prête à l’emploi de moduix)
│  └─ SignaturePad.Control
│     ├─ SignaturePad.Segment
│     ├─ SignaturePad.ClearTrigger
│     └─ SignaturePad.Guide
└─ SignaturePad.HiddenInput value={serializedPaths} (explicite)

SignaturePad.RootProvider
└─ même arbre de parties connecté à l’état de useSignaturePad()
```

| Partie                                  | Rôle                                                                                     |
| --------------------------------------- | ---------------------------------------------------------------------------------------- |
| `SignaturePad` / `SignaturePad.Root`    | Gère les tracés, les options de dessin, le nom du champ, les identifiants et les fonctions de rappel. |
| `SignaturePad.RootProvider`             | Rend le même arbre de parties à partir de l’état créé avec `useSignaturePad()`.          |
| `SignaturePad.Label`                    | Associe le libellé visible à la zone de dessin et au champ natif masqué.                 |
| `SignaturePad.Canvas`                   | Surface prête à l’emploi qui rend les parties standard et transmet les propriétés et le `ref` de `Control`. |
| `SignaturePad.Control`                  | Zone de dessin au pointeur et au toucher, pouvant recevoir le focus.                     |
| `SignaturePad.Segment`                  | Calque SVG pour les traits enregistrés et le trait en cours.                             |
| `SignaturePad.ClearTrigger`             | Bouton natif qui efface les tracés. Ark le masque lorsque le champ est vide ou pendant le dessin. |
| `SignaturePad.Guide`                    | Ligne repère non interactive dans la zone de dessin.                                    |

## Composition

### Composition recommandée

Pour la composition standard, utilisez `Label` et `Canvas`. `Canvas` conserve la cible de focus
d’Ark, la capture du pointeur, le comportement accessible du bouton d’effacement et le rendu SVG,
sans répéter le balisage de la surface de dessin. Il transmet les propriétés et le `ref` de `Control`.
`Canvas` utilise une arborescence d’enfants fixe. Utilisez donc les parties de plus bas niveau si vous
avez besoin d’une autre structure.

### Quand créer une composition personnalisée

Utilisez explicitement les parties `Control`, `Segment`, `ClearTrigger` et `Guide` lorsque vous devez
modifier leur structure, remplacer l’icône ou utiliser `asChild`. Utilisez `paths` en mode contrôlé
lorsque l’application doit restaurer, effacer, enregistrer automatiquement ou valider la signature en
dehors du composant. Utilisez `RootProvider` avec `useSignaturePad()` lorsque l’état doit
être créé en dehors de l’arborescence rendue ou que des contrôles externes doivent accéder directement
à `paths`, `clear()` ou `getDataUrl()`.

Pour lire l’état depuis l’arborescence du composant, utilisez `SignaturePad.Context` ou
`useSignaturePadContext()` pour les besoins avancés.

Transmettez `name` lorsque la signature doit être incluse dans la soumission native, puis composez
explicitement `SignaturePad.HiddenInput` avec une `value` sérialisée. Lisez les tracés courants avec
`useSignaturePadContext()`.

Utilisez `drawing` pour personnaliser chaque trait. `drawing.size` modifie son épaisseur,
`drawing.simulatePressure` contrôle la simulation de pression et `drawing.fill` définit sa couleur.
`drawing.fill` doit contenir une couleur CSS valide. Ark n’accepte pas de variable CSS pour cette
option. Pour utiliser un token du thème, ne définissez pas `fill` et redéfinissez plutôt
`--moduix-signature-pad-stroke-color`.

### Propriétés par défaut

| Propriété        | Valeur par défaut                     | Remarques                                                        |
| ---------------- | ------------------------------------- | ---------------------------------------------------------------- |
| `defaultPaths`   | -                                     | Tableau initial de tracés SVG non contrôlé.                       |
| `paths`          | -                                     | Tableau contrôlé de tracés SVG. Utilisez-le avec `onDraw(details)`. |
| `drawing`        | `{ size: 2, simulatePressure: false }` | Options de dessin Zag. `fill` doit contenir une couleur CSS valide. |
| `name`           | -                                     | Nom du champ de formulaire natif.                                |
| `disabled`       | -                                     | Désactive le dessin et l’interaction avec le bouton d’effacement. |
| `readOnly`       | -                                     | Empêche le dessin et désactive le bouton d’effacement.            |
| `required`       | -                                     | Rend le libellé et le champ masqué obligatoires.                  |
| `ids`            | -                                     | Identifiants stables de la racine, de la zone de dessin, du champ masqué et du libellé. |
| `translations`   | Valeurs Ark par défaut                | Libellés accessibles de la zone de dessin et du bouton d’effacement. |

La zone de dessin standard mesure `17.5rem` sur `10rem`, soit environ `280px` sur `160px` avec
l’échelle de tokens par défaut. Redéfinissez `--moduix-signature-pad-width`,
`--moduix-signature-pad-height` ou les variables plus précises
`--moduix-signature-pad-control-*` pour modifier sa taille. La hauteur minimale par défaut suit la
hauteur configurée de la zone de dessin ; une hauteur inférieure est donc bien prise en compte.

### Comportement

Utilisez `defaultPaths` pour définir une signature initiale non contrôlée. Utilisez `paths` avec
`onDraw(details)` lorsque la signature doit rester dans l’état de l’application. `onDraw(details)`
s’exécute pendant le dessin et lorsque les tracés enregistrés changent. `details.paths` contient les
traits terminés, tandis que `details.currentPath` contient le trait en cours.

`onDrawEnd(details)` s’exécute à la fin d’un trait ou lorsque la signature est effacée. Sa méthode
`details.getDataUrl(type, quality?)` prend en charge `image/png`, `image/jpeg` et `image/svg+xml`.
Elle renvoie une chaîne vide lorsque la signature est vide.

Définissez `name` sur la racine lorsque le formulaire doit être soumis nativement et ajoutez
explicitement `SignaturePad.HiddenInput value={serializedPaths}`. Enveloppez le composant dans
`Field.Root` lorsque le texte d’aide, le
message d’erreur, l’état obligatoire (`required`) ou l’état désactivé (`disabled`) doivent être partagés avec le reste du formulaire.
L’état `invalid` de `Field` gère les messages et les descriptions du champ, mais n’ajoute pas
`data-invalid` aux parties de Signature Pad.

`Control` peut recevoir le focus au clavier et fournit `role="application"` avec
`aria-roledescription="signature pad"`. Le dessin s’effectue au pointeur ou au toucher, et non avec
les touches fléchées. `ClearTrigger` est un bouton natif, son activation avec Entrée ou Espace conserve
donc le comportement standard d’un bouton. En lecture seule, moduix désactive le bouton d’effacement
pour éviter toute modification accidentelle de la signature affichée.

### Points d’accroche CSS

Utilisez `className` sur toute partie exportée pour appliquer des styles locaux. moduix ajoute
également des attributs `data-slot` stables :

| Partie                                  | `data-slot`                   |
| --------------------------------------- | ----------------------------- |
| `SignaturePad` / `SignaturePad.Root`    | `signature-pad-root`          |
| `SignaturePad.RootProvider`             | `signature-pad-root-provider` |
| `SignaturePad.Label`                    | `signature-pad-label`         |
| `SignaturePad.Control`                  | `signature-pad-control`       |
| `SignaturePad.Segment`                  | `signature-pad-segment`       |
| `SignaturePad.Guide`                    | `signature-pad-guide`         |
| `SignaturePad.ClearTrigger`             | `signature-pad-clear-trigger` |

Les attributs Ark restent disponibles pour cibler les styles. `Root`, `Label`, `Control`, `Segment`,
`Guide`, `ClearTrigger` et les tracés internes du segment fournissent `data-scope="signature-pad"` et
`data-part`. `data-disabled` apparaît sur la racine, le libellé, la zone de dessin et la ligne repère,
tandis que `data-required` apparaît sur le libellé.
