## Anatomie

```text
SignaturePad / SignaturePad.Root
├─ SignaturePad.Label
├─ SignaturePad.Canvas (composition prête à l’emploi de moduix)
│  └─ SignaturePad.Control
│     ├─ SignaturePad.Segment
│     ├─ SignaturePad.ClearTrigger
│     └─ SignaturePad.Guide
└─ SignaturePad.HiddenInput value={serializedPaths} (explicite)

SignaturePad.RootProvider
└─ même arbre de parties connecté à l’état de useSignaturePad()
```

| Partie                               | Rôle                                                                    |
| ------------------------------------ | ----------------------------------------------------------------------- |
| `SignaturePad` / `SignaturePad.Root` | Gère les tracés, les options de dessin, le nom du champ, les identifiants et les rappels. |
| `SignaturePad.HiddenInput`           | Champ natif d’Ark à composer explicitement.                             |
| `SignaturePad.RootProvider`          | Rend le même arbre de parties à partir de l’état créé avec `useSignaturePad()`. |
| `SignaturePad.Label`                 | Associe le libellé visible à la zone de dessin et au champ masqué.      |
| `SignaturePad.Canvas`                | Surface prête à l’emploi qui rend les parties standard et transmet les propriétés de `Control`. |
| `SignaturePad.Control`               | Zone de dessin au pointeur et au toucher, pouvant recevoir le focus.     |
| `SignaturePad.Segment`               | Calque SVG pour les traits enregistrés et le trait en cours.            |
| `SignaturePad.ClearTrigger`          | Bouton natif qui efface les tracés.                                     |
| `SignaturePad.Guide`                 | Ligne repère non interactive dans la zone de dessin.                    |

## Composition

Pour la composition standard, utilisez `Label` et `Canvas`. `Canvas` utilise une arborescence
d’enfants fixe ; utilisez donc `Control`, `Segment`, `ClearTrigger` et `Guide` si la structure de
la zone de dessin ou le bouton d’effacement doit changer.

`SignaturePad.HiddenInput` n’est pas rendu automatiquement. Ajoutez-le explicitement et transmettez
une valeur sérialisée, généralement lue avec `SignaturePad.Context` ou
`useSignaturePadContext()`, lorsque la signature doit être envoyée par un formulaire natif.

Utilisez `defaultPaths` pour un état local non contrôlé. Utilisez `paths` avec
`onDraw(details)` lorsque l’application possède les données de la signature. Utilisez
`RootProvider` avec `useSignaturePad()` lorsque l’état doit être créé en dehors de l’arborescence
rendue ou que des contrôles externes doivent accéder à `paths`, `clear()` ou `getDataUrl()`.

### Points d’accroche CSS

Utilisez `className` dans React ou `class` dans Solid sur toute partie exportée pour appliquer des
styles locaux. moduix ajoute également des attributs `data-slot` stables :

| Partie                               | `data-slot`                   |
| ------------------------------------ | ----------------------------- |
| `SignaturePad` / `SignaturePad.Root` | `signature-pad-root`          |
| `SignaturePad.RootProvider`          | `signature-pad-root-provider` |
| `SignaturePad.Label`                 | `signature-pad-label`          |
| `SignaturePad.Control`               | `signature-pad-control`        |
| `SignaturePad.Segment`               | `signature-pad-segment`        |
| `SignaturePad.Guide`                 | `signature-pad-guide`          |
| `SignaturePad.ClearTrigger`          | `signature-pad-clear-trigger` |

Les attributs Ark restent disponibles pour cibler les styles. `Root`, `Label`, `Control`, `Segment`,
`Guide`, `ClearTrigger` et les tracés internes du segment fournissent `data-scope="signature-pad"`
et `data-part` ; `data-disabled` apparaît sur la racine, le libellé, la zone de dessin et la ligne
repère, tandis que `data-required` apparaît sur le libellé.
