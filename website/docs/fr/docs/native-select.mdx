## Référence de l’API

`NativeSelect` encapsule le composant Ark UI
[Field.Select](https://ark-ui.com/docs/components/field) et rend un véritable élément HTML `<select>`.
Son apparence reprend le même langage visuel que `Select`, composant personnalisable, comme le composant
[Native Select](https://chakra-ui.com/docs/components/native-select) de Chakra UI. moduix conserve une API
publique réduite à un seul composant.

## Choisir le bon composant

Utilisez `NativeSelect` pour des listes d’options simples lorsque vous souhaitez conserver la saisie automatique du navigateur,
la réinitialisation du formulaire, le comportement clavier natif et l’interface de sélection native sur mobile. Préférez
[`Select`](/docs/select) lorsqu’il vous faut un menu déroulant personnalisable, les API de collection, des options riches,
l’effacement, l’affichage de plusieurs valeurs sélectionnées ou le contrôle programmatique de l’ouverture.

## Anatomie

`NativeSelect` conserve le véritable élément `<select>` comme contrôle de formulaire et lui ajoute l’icône non interactive
`ChevronDownIcon` de moduix pour rester visuellement cohérent avec `Select`.

```text
NativeSelect
└─ span[data-scope="native-select"][data-part="control"]
   ├─ select[data-scope="field"][data-part="select"][data-slot="native-select-root"]
   │  ├─ option
   │  └─ optgroup
   └─ span[data-scope="native-select"][data-part="indicator"]
      └─ ChevronDownIcon
```

| Partie         | Rôle                                                |
| -------------- | --------------------------------------------------- |
| `NativeSelect` | Élément `<select>` natif stylisé avec indicateur visuel. |

## Composition

### Composition recommandée

Utilisez la forme abrégée `NativeSelect` avec des enfants natifs et les propriétés d’un composant contrôlé ou non contrôlé.
Placez-le dans `Field.Root` lorsque le contrôle doit afficher un libellé, une description, un message d’erreur ou partager
les états `required`, `invalid` et `disabled`.

`NativeSelect.Root` est un alias conservé pour la compatibilité. Dans le code de l’application, utilisez plutôt `NativeSelect`.

### Quand créer une composition personnalisée

Passez à `Select` si l’application doit contrôler le rendu des options, le positionnement du menu, l’état de la collection
ou des indicateurs personnalisés. Gardez `NativeSelect` lorsque vous souhaitez laisser le navigateur gérer la sélection.

### Propriétés par défaut

| Propriété      | Valeur par défaut          | Remarques                                                     |
| -------------- | -------------------------- | ------------------------------------------------------------- |
| `value`        | -                              | Valeur en mode contrôlé                                      |
| `defaultValue` | -                              | Valeur initiale en mode non contrôlé                         |
| `onChange`     | -                              | Événement natif `ChangeEvent<HTMLSelectElement>`             |
| `multiple`     | `false`                        | Active la sélection de plusieurs options                     |
| `size`         | valeur par défaut du navigateur | Nombre de lignes visibles, pas une variante visuelle de taille |
| `disabled`     | `false`                        | État désactivé                                               |
| `controlProps` | -                              | Propriétés du conteneur externe                              |
| `asChild`      | `false`                        | Composition Ark ; l’enfant doit rester un `<select>`         |

### Comportement

- La référence pointe vers le véritable `HTMLSelectElement`.
- La soumission du formulaire, la saisie automatique, la réinitialisation, la validation `required`, la gestion des options
  et le comportement clavier natif sont conservés.
- Avec `multiple` ou une valeur de `size` supérieure à un, le navigateur définit la hauteur intrinsèque de la liste.
- `Field.Root` fournit les identifiants et `aria-describedby`, et transmet l’état invalide ainsi que les autres états natifs du champ.
- Avec `asChild`, l’enfant doit rester un élément HTML `<select>` sémantique.
- L’élément HTML `<select>` ne prend pas en charge le mode lecture seule.
- L’icône `ChevronDownIcon` aligne le contrôle fermé sur `Select`. Le navigateur reste responsable de l’apparence du menu déroulant.

## Styles

### Propriétés CSS

`NativeSelect` utilise les mêmes variables `--moduix-select-*` au niveau du contrôle que `Select`. Les deux composants
partagent ainsi leurs dimensions, l’espacement de l’indicateur, les bordures, les couleurs, le rayon, l’anneau de focus,
l’opacité à l’état désactivé et les transitions. L’espacement interne par défaut et la géométrie de l’indicateur suivent
l’échelle d’espacement commune de 4 px.

### Sélecteurs CSS utiles

- `className` applique les styles à l’élément `<select>` réel. Utilisez `controlProps.className` pour le conteneur externe.
- Placez dans `controlProps.style` les variables `--moduix-select-*` qui agissent sur l’indicateur, afin qu’elles soient
  héritées à la fois par l’élément `<select>` et par l’indicateur.
- `data-scope="field"` et `data-part="select"` préservent le contrat de styles d’Ark Field.
- `data-slot="native-select-root"` est le sélecteur moduix stable de l’élément `<select>`.
- `data-slot="native-select-control"` et `data-slot="native-select-indicator"` ciblent le conteneur interne et l’icône.
- Les sélecteurs natifs `:focus-visible`, `:disabled`, `[aria-invalid="true"]`, `[multiple]` et `[size]` gèrent les états visuels.
