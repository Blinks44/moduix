## Référence de l’API

`NativeSelect` est un composant stylisé basé sur [`FieldSelect` d’Ark UI](https://ark-ui.com/docs/components/field).
Il rend un véritable élément HTML `<select>` : le navigateur reste donc responsable de l’affichage des options,
de la navigation au clavier, de la soumission et de la réinitialisation du formulaire, du remplissage automatique
et de la validation.

## Choisir le bon composant

Utilisez `NativeSelect` pour des listes d’options simples lorsque vous souhaitez conserver le comportement natif du navigateur,
notamment le remplissage automatique, la réinitialisation du formulaire, la navigation au clavier et l’interface de sélection
propre à la plateforme sur mobile. Préférez [`Select`](/docs/select) lorsqu’il vous faut une fenêtre contextuelle personnalisée,
les API de collection, des options riches, une action d’effacement ou le contrôle programmatique de la fenêtre.

## Anatomie

`NativeSelect` rend le véritable `<select>` dans un conteneur externe `<span>`. En mode sélection unique et fenêtre fermée,
il ajoute l’icône décorative `ChevronDownIcon`. Elle est masquée avec `multiple` ou `size > 1`, lorsque le navigateur affiche une liste.

```text
NativeSelect
└─ span[data-scope="native-select"][data-part="control"][data-slot="native-select-control"]
   ├─ select[data-scope="field"][data-part="select"][data-slot="native-select-root"]
   │  ├─ option
   │  └─ optgroup
   └─ span[data-scope="native-select"][data-part="indicator"][data-slot="native-select-indicator"]
      └─ ChevronDownIcon
```

| Partie | Rôle |
| ------ | ---- |
| `NativeSelect` | Composant racine public. Rend le `<select>` natif et l’indicateur décoratif. |

## Composition

En React, construisez un select non contrôlé avec la prop native `defaultValue`. En Solid, transmettez
l’attribut natif `selected` à l’`<option>` qui doit être présélectionnée : une prop `defaultValue` sur le
`NativeSelect` Solid n’a aucun effet. Utilisez `value` avec `onChange` lorsque l’état de l’application
possède la valeur courante. Placez `NativeSelect` dans `Field` lorsque le libellé, le texte associé, la validation ou
l’état `disabled` doivent être partagés avec le contrôle. Les éléments de `Field` relient ce contenu au select natif, tandis
que le navigateur continue de gérer la sélection des options. Avec `multiple` ou `size > 1`, le navigateur gère l’interaction
avec la liste et l’indicateur décoratif est masqué. `asChild` peut remplacer le select rendu, mais l’enfant doit rester un seul
élément HTML `<select>` sémantique.

## Styles

`NativeSelect` réutilise les variables `--moduix-select-*` des variantes CSS Modules de `Select`. Vous pouvez ainsi régler de
manière cohérente les dimensions, l’espacement de l’indicateur, les bordures, les couleurs, le rayon, l’anneau de focus,
l’opacité à l’état désactivé et les transitions. Les variantes Tailwind utilisent des classes utilitaires natives et les classes
transmises par l’utilisateur.

### Points d’accroche CSS

- En React, utilisez `className` sur le select et, en Solid, `class`. Utilisez `controlProps.className` ou `controlProps.class`
  pour le conteneur externe `<span>`.
- Placez dans `controlProps.style` les variables `--moduix-select-*` liées à l’indicateur lorsqu’elles doivent être héritées à
  la fois par l’élément `<select>` et par l’indicateur.
- `data-scope="field"` et `data-part="select"` préservent le contrat de styles d’Ark Field.
- `data-slot="native-select-root"` est le sélecteur moduix stable de l’élément `<select>`.
- `data-slot="native-select-control"` et `data-slot="native-select-indicator"` ciblent le conteneur interne et l’icône.
- Les pseudo-classes et attributs natifs `:focus-visible`, `:disabled`, `[aria-invalid="true"]`, `[multiple]` et `[size]`
  gèrent les états visuels.
