## Référence de l’API

`NativeSelect` est un composant stylisé basé sur [`Field.Select` d’Ark UI](https://ark-ui.com/docs/components/field).
Il rend un véritable élément HTML `<select>` : le navigateur reste donc responsable de l’affichage des options,
de la navigation au clavier, de la soumission et de la réinitialisation du formulaire, du remplissage automatique
et de la validation.

## Choisir le bon composant

Utilisez `NativeSelect` pour des listes d’options simples lorsque vous souhaitez conserver le comportement natif du navigateur,
notamment le remplissage automatique, la réinitialisation du formulaire, la navigation au clavier et l’interface de sélection
propre à la plateforme sur mobile. Préférez [`Select`](/docs/select) lorsqu’il vous faut une fenêtre contextuelle personnalisée,
les API de collection, des options riches, une action d’effacement ou le contrôle programmatique de la fenêtre.

## Anatomie

`NativeSelect` rend le véritable `<select>` dans un conteneur externe. En mode sélection unique et fenêtre fermée, il ajoute
l’icône décorative `ChevronDownIcon`. Elle est masquée avec `multiple` ou `size > 1`, lorsque le navigateur affiche une liste.

```text
NativeSelect / NativeSelect.Root
└─ span[data-scope="native-select"][data-part="control"][data-slot="native-select-control"]
   ├─ select[data-scope="field"][data-part="select"][data-slot="native-select-root"]
   │  ├─ option
   │  └─ optgroup
   └─ span[data-scope="native-select"][data-part="indicator"][data-slot="native-select-indicator"]
      └─ ChevronDownIcon
```

| Partie                              | Rôle                                                                    |
| ---------------------------------- | ----------------------------------------------------------------------- |
| `NativeSelect` / `NativeSelect.Root` | Composant racine public. Rend le `<select>` natif et l’indicateur décoratif. |

## Composition

### Composition recommandée

Utilisez `NativeSelect` directement pour un contrôle simple. Ajoutez des éléments natifs `option` et `optgroup` comme enfants.
Placez-le dans `Field.Root` lorsque le contrôle doit afficher un libellé, une description, un message d’erreur ou partager
les états `required`, `invalid` et `disabled`.
Donnez-lui un nom accessible avec `Field.Label`, un élément `<label>`, `aria-label` ou `aria-labelledby`.

`NativeSelect.Root` est un alias conservé pour la compatibilité. Dans le code de l’application, utilisez plutôt `NativeSelect`.

### Quand créer une composition personnalisée

Passez à `Select` si l’application doit contrôler l’affichage des options, utiliser une collection, ajouter une action
d’effacement ou contrôler programmatiquement la fenêtre. Gardez `NativeSelect` lorsque vous souhaitez laisser le navigateur
gérer la sélection.

### Propriétés par défaut

| Propriété      | Valeur par défaut             | Remarques                                                                    |
| -------------- | ----------------------------- | ---------------------------------------------------------------------------- |
| `value`        | -                             | Valeur en mode contrôlé.                                                     |
| `defaultValue` | -                             | Valeur initiale en mode non contrôlé.                                        |
| `onChange`     | -                             | Événement natif `ChangeEvent<HTMLSelectElement>`.                            |
| `multiple`     | `false`                       | Active la sélection native de plusieurs options.                             |
| `size`         | valeur par défaut du navigateur | Nombre de lignes visibles, pas une variante visuelle de taille.              |
| `disabled`     | `false`                       | Désactive le contrôle.                                                        |
| `controlProps` | -                             | Propriétés du `<span>` externe, notamment pour son style.                    |
| `asChild`      | `false`                       | Composition Ark ; l’enfant doit rester un élément `<select>` sémantique.     |

### Comportement

- La `ref` pointe vers le véritable `HTMLSelectElement`.
- La soumission du formulaire, la saisie automatique, la réinitialisation, la validation `required`, la gestion des options
  et le comportement clavier natif sont conservés.
- Avec `multiple` ou une valeur de `size` supérieure à un, le navigateur définit la hauteur de la liste et gère son apparence
  ainsi que ses interactions.
- `Field.Root` relie le libellé, le texte associé et le message d’erreur au `<select>`, et fournit les identifiants,
  `aria-describedby`, `aria-invalid`, `disabled` et `required`.
- Avec `asChild`, passez un seul élément HTML `<select>` sémantique comme enfant.
- L’élément HTML `<select>` ne prend pas en charge le mode lecture seule.
- L’icône `ChevronDownIcon` est décorative et masquée pour les listes ; le navigateur reste responsable de l’apparence de la fenêtre.

## Styles

### Propriétés CSS

`NativeSelect` réutilise les mêmes variables `--moduix-select-*` que `Select`. Vous pouvez ainsi régler de manière cohérente
les dimensions, l’espacement de l’indicateur, les bordures, les couleurs, le rayon, l’anneau de focus, l’opacité à l’état
désactivé et les transitions. L’espacement interne par défaut et la géométrie de l’indicateur suivent l’échelle commune de 4 px.

### Points d’accroche CSS

- `className` applique les styles au véritable `<select>`. Utilisez `controlProps.className` pour le conteneur externe.
- Placez dans `controlProps.style` les variables `--moduix-select-*` liées à l’indicateur lorsqu’elles doivent être
  héritées à la fois par l’élément `<select>` et par l’indicateur.
- `data-scope="field"` et `data-part="select"` préservent le contrat de styles d’Ark Field.
- `data-slot="native-select-root"` est le sélecteur moduix stable de l’élément `<select>`.
- `data-slot="native-select-control"` et `data-slot="native-select-indicator"` ciblent le conteneur interne et l’icône.
- Les pseudo-classes et attributs natifs `:focus-visible`, `:disabled`, `[aria-invalid="true"]`, `[multiple]` et `[size]`
  gèrent les états visuels.
