## Choisir le bon composant

Utilisez `Dialog` pour les formulaires, les confirmations, les détails et les autres tâches qui
doivent garder l’utilisateur sur la page courante. Préférez `Drawer` lorsque le panneau doit rester
attaché au bord de la fenêtre ou pouvoir être déplacé.

## Anatomie

```text
Dialog / Dialog.Root
├─ Dialog.Trigger
└─ Contenu superposé (rendu automatiquement dans un portail)
   ├─ Dialog.Backdrop (facultatif)
   └─ Dialog.Positioner
      └─ Dialog.Content
         ├─ Dialog.CloseTrigger ou Dialog.CloseIcon
         ├─ Dialog.Title
         ├─ Dialog.Description
         ├─ Dialog.Header (aide de mise en page moduix)
         ├─ Dialog.Body (aide de mise en page moduix)
         └─ Dialog.Footer (aide de mise en page moduix)

Dialog.RootProvider
└─ même arbre de parties relié à l’état fourni par useDialog() de moduix

Dialog.Context
└─ fonction de rendu qui reçoit l’état et les méthodes actuels du dialogue
```

| Partie                    | Rôle                                                               |
| ------------------------ | ------------------------------------------------------------------ |
| `Dialog` / `Dialog.Root` | Gère l’état d’ouverture, le focus et la fermeture du dialogue.      |
| `Dialog.RootProvider`    | Relie les parties à l’état créé avec `useDialog()`.                |
| `Dialog.Trigger`         | Ouvre le dialogue.                                                   |
| `Dialog.Backdrop`        | Couche d’arrière-plan facultative du dialogue modal.                |
| `Dialog.Positioner`      | Positionne le contenu du dialogue.                                  |
| `Dialog.Content`         | Contient la surface visible du dialogue.                            |
| `Dialog.Title`           | Donne au dialogue un titre accessible.                              |
| `Dialog.Description`     | Ajoute un texte complémentaire accessible.                          |
| `Dialog.CloseTrigger`    | Ferme le dialogue.                                                   |
| `Dialog.CloseIcon`       | Aide moduix qui associe un bouton de fermeture au dialogue.          |
| `Dialog.Header`          | Aide de mise en page moduix pour l’en-tête.                         |
| `Dialog.Body`            | Aide de mise en page moduix pour le contenu principal.              |
| `Dialog.Footer`          | Aide de mise en page moduix pour les actions.                       |
| `Dialog.Context`         | Rend les enfants avec l’état et les méthodes actuels du dialogue.   |

Importez `useDialog()` lorsque l’état doit vivre en dehors de l’arbre rendu du dialogue. Lisez-le ou
mettez-le à jour avec `Dialog.Context` ou `useDialogContext()` depuis le paquet correspondant.

## Composition

Par défaut, `Dialog` gère son état d’ouverture. Utilisez `open` avec `onOpenChange(details)` lorsque
cet état appartient à une autre partie de l’application. Si l’état doit être créé en dehors de
l’arbre du dialogue, créez un seul store avec `useDialog()` et transmettez-le à
`Dialog.RootProvider` ; ne rendez pas une autre racine pour ce même store.

La racine place automatiquement `Dialog.Backdrop` et `Dialog.Positioner` dans un portail. Définissez
`portalled={false}` pour les conserver dans l’arbre courant, ou transmettez `portalRef` pour choisir
un conteneur personnalisé. Gardez l’arbre des parties explicite et utilisez `Dialog.Header`,
`Dialog.Body` et `Dialog.Footer` uniquement lorsque leurs aides de mise en page conviennent à la
composition.

## Styles

Utilisez `className` en React ou `class` en Solid sur les parties exportées pour appliquer les styles
structurels. Pour les styles liés à l’état, privilégiez les attributs de données Ark comme
`data-state` et `data-has-nested`, ainsi que les sélecteurs `data-slot` de moduix. Les variantes
Tailwind se personnalisent avec des utilitaires et des classes supplémentaires ; les variables ci-
dessous concernent les variantes CSS Modules. Les attributs de données et les sélecteurs `data-slot`
sont communs aux deux approches.

### Points d’accroche CSS

- Valeurs `data-slot` de moduix : `dialog-trigger`, `dialog-backdrop`, `dialog-positioner`,
  `dialog-content`, `dialog-title`, `dialog-description`, `dialog-close-trigger`,
  `dialog-close-icon`, `dialog-header`, `dialog-body` et `dialog-footer`.
- Attributs Ark : `data-scope="dialog"` et
  `data-part="trigger|backdrop|positioner|content|title|description|close-trigger"`.
- Attributs d’état : `data-state="open|closed"`, `data-has-nested`, `data-nested`, `data-current`
  et `data-value`.
- Variables d’exécution : `--layer-index` et `--nested-layer-count`.
- `Dialog.CloseIcon` est positionné par rapport à l’angle de `Dialog.Content`, son placement ne
  dépend donc pas de `Dialog.Header`.
