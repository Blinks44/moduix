## Référence de l’API

Ark UI ne fournit pas de primitive `Skeleton` dédiée. moduix construit `Skeleton` à partir de la
[fabrique Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) officielle et suit les recommandations
d’Ark pour la [composition](https://ark-ui.com/docs/guides/composition), les
[styles](https://ark-ui.com/docs/guides/styling) et les [refs](https://ark-ui.com/docs/guides/ref).

## Anatomie

`Skeleton` ne comporte qu’une seule partie visuelle. La mise en page se fait dans le balisage qui l’entoure.

```text
Skeleton.Root
└─ children (facultatifs, affichés lorsque loading={false})
```

| Partie                        | Rôle                                                                                                                  |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `Skeleton` / `Skeleton.Root` | Bloc d’attente. Rend par défaut un élément de la fabrique Ark ; avec `asChild`, un autre élément sémantique peut devenir la racine. |

## Composition

### Composition recommandée

Utilisez directement `Skeleton` pour les lignes de texte, les cartes, les avatars et les espaces réservés aux
médias. Pendant le chargement, il affiche un bloc décoratif. Avec `loading={false}`, il affiche ses enfants dans
le même élément racine.

La variante par défaut est `variant="pulse"`, qui anime l’espace réservé. Utilisez `variant="none"` pour obtenir
un espace réservé statique. L’animation est également désactivée lorsque les préférences de l’utilisateur demandent
de réduire les mouvements.

### Quand créer une composition personnalisée

Utilisez `asChild` si la racine doit être un élément sémantique autre que `div`. Dans ce mode, l’enfant devient la
racine et doit donc être un unique élément sémantique.

Pour les dimensions courantes, utilisez `width`, `height`, `boxSize` et `borderRadius`. Pour les surfaces plus
Pour une apparence plus spécifique, utilisez `className`, `style` ou les variables CSS publiques.

### Propriétés par défaut

| Propriété       | Par défaut                             | Remarques                                                                                                                        |
| --------------- | -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `loading`       | `true`                                 | Active les styles d’attente ou affiche normalement les enfants.                                                                 |
| `variant`       | `pulse`                                | Accepte `pulse` et `none`.                                                                                                       |
| `height`        | `var(--moduix-spacing-4)` (pendant le chargement) | Le CSS définit la hauteur standard de l’espace réservé pendant le chargement. Le contenu chargé conserve sa hauteur naturelle si aucune hauteur n’est fixée. |
| `width`         | `100%`                                 | Le CSS définit la largeur standard de la racine. Les valeurs numériques sont converties en `px`.                                |
| `boxSize`       | Non défini                          | Définit simultanément la largeur et la hauteur. Une valeur explicite de `width` ou `height` reste prioritaire pour l’axe concerné. |
| `borderRadius`  | `var(--moduix-skeleton-border-radius, var(--moduix-radius-md))` | Les valeurs numériques sont converties en `px` ; les styles inline restent prioritaires. |

### Comportement

- `Skeleton.Root` désigne le même composant que `Skeleton` ; cet alias assure la cohérence de l’espace de noms.
- Les refs sont transmises à l’élément racine.
- `loading={true}` définit `aria-hidden`, `data-state="loading"` et `data-loading`, sauf si vous définissez explicitement `aria-hidden`.
- `loading={false}` définit `data-state="loaded"` et laisse les enfants utiliser leur hauteur naturelle si `height`,
  `boxSize` et `style.height` ne sont pas définis.
- `variant` agit uniquement sur les styles ; aucun minuteur interne ni gestion d’état n’est ajouté.
- `Skeleton` est décoratif et n’annonce pas le chargement. Définissez `aria-busy` sur la zone qui porte l’état de
  chargement, ou utilisez `Spinner` lorsqu’un statut de chargement doit être annoncé dans le flux.

## Styles

`Skeleton` expose des attributs de partie et d’état inspirés d’Ark ainsi que des variables publiques
`--moduix-skeleton-*` pour sa couleur, son rayon, sa hauteur et son animation.

### Sélecteurs et attributs de style

- `[data-scope="skeleton"][data-part="root"]` cible l’élément racine exporté.
- `data-slot="skeleton-root"` est le sélecteur stable de moduix pour cet élément.
- `data-state="loading"` et `data-state="loaded"` reflètent la propriété `loading`.
- `data-variant="pulse"` et `data-variant="none"` reflètent la variante choisie.
- `data-loading` n’est présent que lorsque les styles d’attente sont actifs.
