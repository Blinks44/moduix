## Quand l’utiliser

Utilisez `Format.Number` pour afficher un nombre selon les conventions de la locale : séparateurs de milliers,
devises, pourcentages, unités ou notation compacte. Le composant sert uniquement à l’affichage ; pour une valeur
modifiable, utilisez `NumberInput` de moduix.

Importez `Format` directement depuis Ark UI :

```tsx
import { Format } from '@ark-ui/react';
```

## Devise, pourcentage et notation compacte

`Format.Number` accepte les options standard de `Intl.NumberFormat`. Pour une devise, utilisez `style="currency"`
avec son code ; pour un pourcentage, passez une fraction avec `style="percent"` ; `notation="compact"` convient aux
indicateurs d’un tableau de bord.

Une valeur de pourcentage est une fraction : passez `0.0642` pour 6,42 %, et non `6.42`. Utilisez
`minimumFractionDigits` et `maximumFractionDigits` lorsque les valeurs doivent avoir la même précision.

## Locale et unités

`Format.Number` récupère la locale depuis `LocaleProvider`. moduix réexporte ce fournisseur : utilisez-le pour
définir la locale une seule fois dans toute l’interface.

```tsx
import { Format } from '@ark-ui/react';
import { LocaleProvider } from '@moduix/react/locale';

export function LocalizedPrice() {
  return (
    <LocaleProvider locale="de-DE">
      <Format.Number currency="EUR" style="currency" value={1234.5} />
    </LocaleProvider>
  );
}
```

Pour les mesures, utilisez `style="unit"` avec une `unit` prise en charge, comme `kilometer`, `celsius` ou
`megabyte`. `unitDisplay` contrôle la forme d’affichage de l’unité.

## Utilisation avec moduix

Placez `Format.Number` près du libellé, du statut ou de l’indicateur qu’il décrit. Utilisez les composants moduix
`Card`, `Stack`, `Text` et ceux dédiés à l’affichage des données pour la hiérarchie ; ne créez pas de composant juste
pour appeler un formateur. Pour les montants modifiables, `NumberInput` gère le formatage et l’analyse avec son API
`formatOptions`.

## Responsabilités

Ark UI gère le formatage des nombres et l’API `Format.Number`. moduix fournit les composants d’interface qui
l’accompagnent et réexporte `LocaleProvider`, mais ne réexporte pas `Format.Number`.
