`Format.Number` formate une valeur numérique selon les règles `Intl.NumberFormat` du navigateur. C’est un formateur en
lecture seule, pas un champ de saisie.

## Référence de l’API

<PrimitiveReference href="https://ark-ui.com/docs/utilities/format-number" />

Importez l’utilitaire depuis le paquet Ark UI correspondant à votre framework :

## Exemple de base

Passez un nombre à `value`. Sans option de formatage, le résultat suit la locale active. `Format.Number` ne rend que
du texte : ajoutez vous-même le libellé et la structure qui l’entourent.

L’aperçu utilise React, car le site de documentation fonctionne avec React. Les onglets Solid et Vue
contiennent les versions natives du même exemple.

## Options de formatage

`Format.Number` accepte les options standard de `Intl.NumberFormatOptions`, notamment `style`, `currency`, `unit`,
`unitDisplay`, `notation` et les options qui contrôlent le nombre de décimales.

`style="percent"` multiplie la valeur par 100 : passez `0.0642` pour afficher `6.4%` avec
`maximumFractionDigits={1}`. Pour conserver un nombre fixe de décimales, définissez à la fois
`minimumFractionDigits` et `maximumFractionDigits`. Utilisez `notation="compact"` pour abréger les grandes valeurs
et `style="unit"` avec une valeur `unit` prise en charge pour les mesures.

## Locale

`LocaleProvider` fournit la locale à `Format.Number` et aux autres formateurs Ark dans son sous-arbre. Sans fournisseur,
la locale par défaut est `en-US`. Importez le fournisseur depuis le package Ark correspondant au framework.
