## Quand l’utiliser

`Format.Number` sert à afficher des valeurs numériques non modifiables. Il respecte les conventions de la locale active
pour les séparateurs, les devises, les pourcentages, les unités et la notation compacte. Pour une valeur modifiable,
utilisez le composant `NumberInput` de moduix.

Importez `Format` directement depuis Ark UI :

```tsx
import { Format } from '@ark-ui/react';
```

## Exemple de base

Passez un nombre à `value`. Sans option de formatage, le composant suit le comportement par défaut de
`Intl.NumberFormat` pour la locale active. Sans `LocaleProvider`, Ark utilise `en-US`.

`Format.Number` ne rend que du texte. Placez-le près d’un libellé ou d’un autre élément qui explique le sens de la
valeur. Dans cet exemple, `Card` et `Stack` fournissent le contexte et la hiérarchie visuelle.

## Devise, pourcentage et notation compacte

`Format.Number` accepte les options standard de `Intl.NumberFormat`. Pour un montant, utilisez `style="currency"` et
définissez `currency` avec le code de la devise. Pour un pourcentage, utilisez `style="percent"`. Utilisez
`notation="compact"` lorsque l’espace est limité, notamment dans un tableau de bord.

Pour 6,42 %, passez la fraction `0.0642` ; `6.42` sera formaté comme 642 %. Pour conserver les deux décimales,
définissez `maximumFractionDigits={2}`. Utilisez `minimumFractionDigits` et
`maximumFractionDigits` si le nombre de décimales doit rester constant.

## Locale et unités

`Format.Number` récupère la locale depuis `LocaleProvider`. moduix réexporte ce fournisseur depuis
`@moduix/react/locale`. Utilisez-le autour de la partie de l’interface qui partage cette locale.

```tsx
import { Format } from '@ark-ui/react';
import { LocaleProvider } from '@moduix/react/locale';

export function LocalizedPrice() {
  return (
    <LocaleProvider locale="de-DE">
      <Format.Number currency="EUR" style="currency" value={1234.5} />
    </LocaleProvider>
  );
}
```

Pour formater une mesure, utilisez `style="unit"` avec une valeur `unit` prise en charge, comme `kilometer`, `celsius`
ou `megabyte`. Définissez `unitDisplay` sur `"narrow"`, `"short"` ou `"long"` pour choisir la forme d’affichage de
l’unité.

## Utilisation avec moduix

Placez `Format.Number` près du libellé, du statut ou de l’indicateur auquel la valeur se rapporte. Utilisez les
composants moduix `Card`, `Stack`, `Text` et ceux dédiés à l’affichage des données pour structurer l’interface. Il n’est
pas nécessaire de créer un composant uniquement pour appeler le formateur. Pour les montants modifiables, utilisez
`NumberInput` : sa prop `formatOptions` contrôle le format d’affichage et l’interprétation de la saisie.

## Responsabilités

Ark UI fournit `Format.Number` et la logique de formatage des nombres. moduix réexporte `LocaleProvider` et fournit les
composants qui structurent l’interface. `Format.Number` n’est pas réexporté par moduix : importez donc `Format` depuis
Ark UI.
