## Anatomie

```text
Tour
└─ Éléments superposés (rendus dans un portail par défaut)
   ├─ Tour.Backdrop
   ├─ Tour.Spotlight
   └─ Tour.Positioner
      └─ Tour.Content
         ├─ Tour.Arrow
         ├─ Tour.CloseIcon / Tour.CloseTrigger
         ├─ Tour.Body
         │  ├─ Tour.Title
         │  ├─ Tour.Description
         │  └─ Tour.ProgressText
         └─ Tour.Control
            ├─ Tour.ActionList
            └─ Tour.Actions
               └─ Tour.ActionTrigger[action]
```

| Partie | Rôle |
| --- | --- |
| `Tour` | Composant racine associé à un objet `UseTourReturn`. `Tour.Root` est un alias. |
| `Tour.Backdrop` / `Tour.Spotlight` | Voile d’arrière-plan facultatif et mise en évidence de la cible active. |
| `Tour.Positioner` / `Tour.Content` | Positionnent et affichent la boîte de dialogue `alertdialog` d’Ark. |
| `Tour.Arrow` | Affiche par défaut l’`ArrowTip` de moduix pour les étapes de type infobulle. |
| `Tour.CloseIcon` | Bouton de fermeture accessible avec une icône. Utilisez `CloseTrigger` pour votre propre balisage. |
| `Tour.Body` | Conteneur moduix défilant pour le titre, la description et le texte de progression. |
| `Tour.Control` / `Tour.ActionList` | Rangée d’actions recommandée et actions de l’étape en cours. |
| `Tour.Actions` / `Tour.ActionTrigger` | Interface d’actions personnalisée qui conserve chaque objet d’action Ark. |

## Composition

### Composition recommandée

`Tour` rend automatiquement `Backdrop`, `Spotlight` et `Positioner` dans un portail. Définissez
`portalled={false}` uniquement si la couche superposée doit rester dans le flux de la page, ou passez
`portalRef` pour l’afficher dans un conteneur précis. Gardez les parties structurelles explicites.
Ajoutez `Tour.ActionList` lorsque les actions déclarées dans `steps` conviennent à votre interface :
il rend les actions de l’étape en cours.

### Quand personnaliser l’interface

Utilisez `Tour.Actions` et `Tour.ActionTrigger` lorsqu’une action demande son propre balisage. Ils
préservent la navigation, la fermeture et l’état désactivé gérés par Ark, tout en vous laissant
rendre vos propres contrôles. Ajoutez `onStepChange`, `onStepsChange` ou `onStatusChange` à
`useTour` si une autre partie de l’interface ou votre outil d’analyse doit réagir au tour. À
l’intérieur de l’arbre, les exports moduix `useTourContext` et `Tour.Context` donnent accès à
l’étape active et aux méthodes de navigation.

### Propriétés par défaut

La couche superposée rendue dans le portail est montée à la première ouverture, puis démontée après
son animation de fermeture. Définissez `unmountOnExit={false}` pour la conserver après la première
ouverture. Ne placez les deux propriétés de cycle de vie à `false` que si elle doit être rendue dès
le départ.

| Propriété | Valeur par défaut | Remarques |
| --- | --- | --- |
| `closeOnEscape` | `true` | La touche Échap ferme le tour. |
| `closeOnInteractOutside` | `true` | Une interaction hors du tour le ferme, sauf désactivation. |
| `keyboardNavigation` | `true` | Les flèches gauche et droite parcourent les étapes disponibles. |
| `preventInteraction` | `false` | Définissez `true` pour bloquer la page tant que le tour est ouvert. |
| `spotlightOffset` | `{ x: 10, y: 10 }` | Agrandit la zone mise en évidence autour de la cible. |
| `spotlightRadius` | `4` | Arrondit les coins de la mise en évidence. |
| `lazyMount` | `true` | Diffère le rendu de la couche jusqu’à la première ouverture. |
| `unmountOnExit` | `true` | Démonte la couche après l’animation de fermeture. |

### Comportement et accessibilité

`Tour.Title` fournit le nom accessible de la boîte de dialogue d’alerte et `Tour.Description` sa
description. Ark gère le focus à l’ouverture et à la fermeture, Échap, les interactions extérieures,
et la navigation avec les flèches gauche et droite. Laissez `keyboardNavigation` activé, sauf si une
étape utilise volontairement ces touches. En interface RTL, Ark inverse la navigation gauche et
droite.

### Hooks de style

Utilisez les attributs moduix `data-slot`, par exemple `tour-content`, `tour-body` et
`tour-action-trigger`, pour appliquer des styles locaux. Ark fournit aussi `data-scope="tour"`,
`data-part`, `data-state`, `data-type`, `data-placement`, `data-side`, `data-step` et
`data-disabled`, ainsi que les variables d’exécution `--tour-layer`, `--tour-z-index`,
`--available-width`, `--available-height`, `--transform-origin` et les variables de flèche. Passez
`className` à `Tour.ActionList` pour styliser chaque déclencheur créé. La feuille de style raccourcit
les animations de la couche superposée et retire les transitions des boutons d’action lorsque
l’utilisateur préfère réduire les animations.
