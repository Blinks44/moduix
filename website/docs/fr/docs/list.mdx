Ark UI ne fournit pas de primitive de liste dédiée. moduix construit ce composant avec la [fabrique officielle d’Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory)
et suit ses recommandations pour la [composition](https://ark-ui.com/docs/guides/composition), les
[styles](https://ark-ui.com/docs/guides/styling) et la [gestion des refs](https://ark-ui.com/docs/guides/ref).

## Anatomie

La composition habituelle est simple :

```text
List / List.Root
└─ List.Item | li
```

| Partie               | Rôle                                                                                              |
| -------------------- | ------------------------------------------------------------------------------------------------- |
| `List` / `List.Root` | Racine sémantique de la liste. Contrôle les marqueurs, l’espacement, la taille et la tonalité.       |
| `List.Item`          | Partie facultative basée sur le modèle Ark, qui fournit un slot `li` stable et prend en charge `asChild`. |

## Composition

### Composition recommandée

Utilisez `<List>` pour les listes non ordonnées et `as="ol"` pour les listes ordonnées. N’utilisez `asChild`
que pour remplacer `List` par un unique élément sémantique `<ul>` ou `<ol>`, ou `List.Item` par un unique
élément sémantique `<li>`.

### Quand créer une composition personnalisée

`List` ne fournit ni machine à états interne, ni utilitaires pour les structures imbriquées, ni API de rendu des
marqueurs. Pour styliser les éléments dans les cas courants, utilisez `className` et le CSS natif, par exemple
`li::marker`. Réservez `asChild` à un composant de votre application qui transmet sa ref et ses props et rend
l’élément sémantique requis.

Les éléments doivent rester des enfants directs de la liste. L’espacement intégré et le style des marqueurs ne
s’appliquent qu’à ces éléments.

### Propriétés par défaut

| Prop      | Valeur par défaut    | Remarques                                                                                       |
| --------- | -------------------- | ----------------------------------------------------------------------------------------------- |
| `gap`     | `sm`                 | Espacement entre les enfants directs de la liste.                                      |
| `size`    | `md`                 | Token de taille typographique.                                                         |
| `tone`    | `default`            | Couleur sémantique du texte et des marqueurs.                                           |
| `marker`  | mode `auto` sémantique | `disc` pour `ul`, marqueurs natifs du navigateur pour `ol`, ou `none`.              |
| `as`      | `ul`                 | Choisit l’élément natif de la liste : `ul` ou `ol`.                                     |
| `asChild` | `false`              | Remplace l’élément sémantique de la liste par un unique enfant fourni par votre code.  |

### Comportement

- Les props natives des listes ordonnées, comme `start`, `reversed` et `type`, sont disponibles avec `as="ol"`.
- Utilisez `marker="none"` pour masquer les marqueurs tout en conservant la sémantique de liste. Lorsque les
  marqueurs sont désactivés, `List` ajoute `role="list"`, sauf si vous remplacez explicitement `role`.
- `List.Item` est facultatif. Utilisez de simples éléments `li` si le slot exporté ne vous est pas utile.

### Points d’accroche CSS

`List` expose un ensemble réduit de points d’accroche CSS publics :

- racine : `data-scope="list"`, `data-part="root"`, `data-slot="list-root"`
- élément : `data-scope="list"`, `data-part="item"`, `data-slot="list-item"`
- `data-gap="xs" | "sm" | "md" | "lg" | "xl" | "2xl"` pour cibler les styles liés à l’espacement
- `data-marker="auto" | "disc" | "decimal" | "none"` pour cibler les styles liés aux marqueurs
- `data-size="xs" | "sm" | "md" | "lg" | "xl"` pour cibler les styles liés à la taille typographique
- `data-tone="default" | "muted" | "subtle" | "primary" | "destructive"` pour les couleurs sémantiques
- le sélecteur natif `li::marker` pour remplacer la couleur ou l’épaisseur du marqueur
