## Choisir le bon composant

Choisissez `ColorPicker` lorsque les utilisateurs doivent sélectionner ou ajuster précisément une couleur. Choisissez
`Input` lorsqu’ils doivent seulement saisir une valeur connue, sans modifier directement la couleur.

```text
ColorPicker
├─ ColorPicker.Label
├─ ColorPicker.Control
│  ├─ ColorPicker.ChannelInput[channel]
│  └─ ColorPicker.Trigger
│     ├─ ColorPicker.TransparencyGrid
│     └─ ColorPicker.ValueSwatch
├─ Sous-arbre du popup (rendu automatiquement dans un portail)
│  └─ ColorPicker.Positioner
│     └─ ColorPicker.Content
│        ├─ ColorPicker.Area
│        │  ├─ ColorPicker.AreaBackground
│        │  └─ ColorPicker.AreaThumb
│        ├─ ColorPicker.EyeDropperTrigger
│        ├─ ColorPicker.ChannelSlider[channel]
│        │  ├─ ColorPicker.TransparencyGrid
│        │  ├─ ColorPicker.ChannelSliderTrack
│        │  └─ ColorPicker.ChannelSliderThumb
│        ├─ ColorPicker.SwatchGroup
│        │  └─ ColorPicker.SwatchTrigger[value]
│        │     └─ ColorPicker.Swatch[value]
│        │        └─ ColorPicker.SwatchIndicator
│        └─ ColorPicker.View[format]
│           └─ ColorPicker.ChannelInput[channel]
└─ champ natif (automatique)
```

| Partie                           | Rôle |
| -------------------------------- | ---- |
| `ColorPicker`                    | Gère la valeur et le format de la couleur, l’état du popup et l’intégration au formulaire. |
| `ColorPicker.Control`            | Regroupe les champs visibles et le déclencheur. |
| `ColorPicker.Trigger`            | Bouton qui ouvre le popup et affiche par défaut la pastille de la couleur actuelle. |
| `ColorPicker.Content`             | Contenu du popup Ark. |
| `ColorPicker.Area`               | Surface bidimensionnelle pour choisir la couleur. |
| `ColorPicker.ChannelSlider`      | Contrôle unidimensionnel de la teinte, du canal alpha ou d’un autre canal. |
| `ColorPicker.Sliders`            | Paire prête à l’emploi de curseurs pour la teinte et le canal alpha. |
| `ColorPicker.ChannelInput`       | Champ texte ou numérique pour un canal de couleur donné. |
| `ColorPicker.SwatchTrigger`      | Bouton qui permet de sélectionner une couleur prédéfinie. |
| `ColorPicker.ValueSwatch`        | Affiche un aperçu de la couleur actuelle. |

`ColorPicker.RootProvider`, `parseColor`, `useColorPicker` et `useColorPickerContext` couvrent les scénarios avancés
habituels de gestion d’état. Importez directement les types auxiliaires d’Ark uniquement si nécessaire.

## Composition

Le composant racine rend automatiquement `Positioner` dans un portail. Utilisez `portalled={false}` pour un rendu intégré
ou transmettez `portalRef` pour utiliser un conteneur personnalisé. Les éléments de structure restent explicites et
peuvent être stylés séparément.

### Composition recommandée

Pour un sélecteur affiché dans un popup, gardez `ColorPicker.Positioner` et `ColorPicker.Content` explicites. `Content`
est la partie Ark qui contient le popup ; le composant racine ne gère que le portail.

Laissez `Trigger`, `Area`, `ChannelSlider` et `SwatchTrigger` sans enfants pour utiliser leur composition visuelle par
défaut. Pour la paire habituelle de curseurs de teinte et de canal alpha, utilisez `ColorPicker.Sliders`. Stylez les
canaux avec `data-channel` ou les variables CSS, et n’ajoutez des enfants que pour personnaliser la structure d’une
partie. Ajoutez `data-fit-content` lorsque la taille du déclencheur doit suivre son contenu, par exemple une pastille
accompagnée de `ValueText`.

Pour inclure la couleur dans l’envoi et la réinitialisation natifs du formulaire, transmettez `name` à `ColorPicker`.
Le composant rend et synchronise automatiquement le champ natif : `FormData` et `form.reset()` ne demandent aucune
configuration supplémentaire.

### Quand créer une composition personnalisée

Utilisez `inline` sur `ColorPicker` lorsque la zone, les curseurs, les champs et les pastilles doivent rester visibles
dans un panneau plutôt que dans un popup. Utilisez `ColorPicker.View` pour n’afficher que les champs d’un format à la fois.

Utilisez `useColorPicker` avec `ColorPicker.RootProvider` lorsque l’état doit être géré en dehors du sous-arbre rendu.
Ne rendez pas `Root` et `RootProvider` pour une même instance d’état.

Utilisez `asChild` sur les parties Ark exportées lorsqu’un autre élément sémantique doit devenir le nœud DOM.
L’enfant doit rester unique et conserver le comportement requis pour le focus et les interactions.

### Propriétés par défaut

Par défaut, le contenu du popup rendu dans un portail est monté à la première ouverture, puis démonté après l’animation
de sortie. Définissez `unmountOnExit={false}` pour le conserver après cette première ouverture. Désactivez les deux
propriétés du cycle de vie uniquement lorsqu’un rendu initial immédiat est nécessaire.

| Surface / propriété                         | Valeur par défaut | Remarques |
| ------------------------------------------- | ----------------- | --------- |
| `defaultValue`                              | `parseColor("#000000")` | Valeur de couleur Ark standard. |
| `defaultFormat`                             | `"rgba"` | Format Ark standard. |
| largeur de `ColorPicker.Content`            | `16rem` | Évite que le popup se réduise à la largeur de la pastille du déclencheur. |
| `ColorPicker.EyeDropperTrigger`             | icône de pipette moduix | Utilisée en l’absence d’enfants. |
| enfants de `ColorPicker.Trigger`            | pastille actuelle | Affiche `TransparencyGrid` et `ValueSwatch`. |
| enfants de `ColorPicker.Area`               | arrière-plan et curseur | Utilisés en l’absence d’enfants. |
| enfants de `ColorPicker.ChannelSlider`      | piste et curseur | Les curseurs alpha rendent aussi `TransparencyGrid`. |
| `ColorPicker.Sliders`                       | paire de curseurs de teinte et de canal alpha | Stylez avec `data-channel` ou les variables CSS. |
| enfants de `ColorPicker.SwatchTrigger`      | pastille et indicateur | Utilisent la valeur `value` du déclencheur. |
| `ColorPicker.SwatchIndicator`               | icône de validation moduix | Utilisée en l’absence d’enfants. |
| largeur de `ColorPicker`                    | `16rem` (max. `100%`) | Largeur standard du composant racine stylé. |

### Comportement

- `value` et `defaultValue` utilisent des objets Ark `Color`. Pour fournir une valeur sous forme de chaîne, utilisez `parseColor()`.
- `onValueChange(details)` et `onValueChangeEnd(details)` conservent les objets `details` d’Ark.
- `onFormatChange(details)` et `onOpenChange(details)` conservent les objets `details` d’Ark.
- `ids` est transmis à Ark pour partager les identifiants d’accessibilité dans les compositions personnalisées.
- L’état de `Field` et `Fieldset` peut être transmis avec les propriétés du composant racine compatibles avec Ark : `disabled`, `invalid`, `required` et `readOnly`.
- Utilisez `positioning`, `initialFocusEl` et `openAutoFocus` lorsque le placement ou le focus doit s’adapter au contexte.
- `lazyMount` et `unmountOnExit` valent `true` par défaut ; `present` et `onExitComplete` conservent le cycle de présence
  Ark pour contrôler le montage ou l’animation de sortie.
- Toutes les parties DOM Ark conservent `asChild`.

### Points d’accroche CSS

Utilisez la partie qui contrôle l’aspect visuel concerné :

- `ColorPicker` pour la largeur, les espacements, la couleur générale et l’opacité de l’état désactivé ;
- `ColorPicker.Control`, `ChannelInput`, `Trigger`, `FormatSelect` et `FormatTrigger` pour les éléments visibles du champ ;
- `ColorPicker.Positioner` et `ColorPicker.Content` pour les couches, la largeur, les espacements, l’arrondi, l’ombre
  et les animations d’état du popup ;
- `ColorPicker.Area`, `AreaBackground` et `AreaThumb` pour la surface de couleur bidimensionnelle ;
- `ColorPicker.ChannelSlider`, `ChannelSliderTrack`, `ChannelSliderThumb` et `Sliders` pour les curseurs de teinte,
  de canal alpha et des autres canaux ;
- `ColorPicker.SwatchGroup`, `SwatchTrigger`, `Swatch` et `SwatchIndicator` pour les grilles de pastilles de couleurs prédéfinies ;
- `ColorPicker.ValueSwatch`, `ValueText`, `View` et `TransparencyGrid` pour l’affichage de la valeur et les mises en page adaptées au format.

Les principaux hooks d’état sont `data-state`, `data-focus`, `data-invalid`, `data-disabled`, `data-readonly`,
`data-required`, `data-channel`, `data-orientation`, `data-value`, `data-placement` et `data-side`. Les variables Ark
disponibles à l’exécution comprennent `--color`, `--value`, `--available-width`, `--available-height` et `--transform-origin`.

Lorsque `prefers-reduced-motion` est activé, les animations d’ouverture et de fermeture du popup durent 1 ms. Ark peut
ainsi terminer son cycle de sortie sans mouvement visible.
