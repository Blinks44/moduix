## Rôle de `LocaleProvider`

`LocaleProvider` définit une locale et un sens d’écriture pour une partie de l’application. Les utilitaires de formatage
Ark et les composants qui tiennent compte de la locale lisent ce contexte pour formater les valeurs et choisir le sens du
texte. Sans provider, Ark utilise `en-US` et le sens de gauche à droite (`ltr`).

moduix réexporte le provider et son hook de contexte depuis une entrée publique dédiée :

```tsx
import { LocaleProvider, useLocaleContext } from '@moduix/react/locale';
```

## Lire le contexte de locale

`useLocaleContext` renvoie `locale` et `dir` depuis le provider le plus proche. Utilisez ces valeurs dans votre contenu
lorsqu’il doit reprendre la même locale ou le même sens d’écriture que le reste de la zone localisée.

## Langue et direction du document

`LocaleProvider` déduit la direction utilisée par Ark à partir de la locale, mais il ne modifie pas les attributs HTML
du document. Si toute l’application utilise une même locale, définissez les valeurs correspondantes de `lang` et
`dir` sur la racine du document, en particulier pour une langue qui s’écrit de droite à gauche.

```tsx
import type { ReactNode } from 'react';
import { LocaleProvider } from '@moduix/react/locale';

export function Document({ children }: { children: ReactNode }) {
  return (
    <html dir="rtl" lang="ar">
      <body>
        <LocaleProvider locale="ar-EG">{children}</LocaleProvider>
      </body>
    </html>
  );
}
```

Pour une zone plus petite avec un sens d’écriture différent, définissez sa valeur `lang` et appliquez à sa racine la
valeur `dir` renvoyée par `useLocaleContext`. Consultez [De droite à gauche (RTL)](/docs/rtl) pour les conseils de mise
en page, de portails et d’icônes directionnelles.

## Utilisation avec moduix

Placez un seul `LocaleProvider` autour de la partie de l’interface qui partage une locale. Les utilitaires `Format`
et les primitives Ark qui tiennent compte de la locale lisent alors le même contexte.

`Format.Number`, `Format.Time` et les autres utilitaires `Format` restent importés depuis Ark. moduix fournit les
composants d’interface et réexporte le contexte de locale ; il n’ajoute pas de seconde API de formatage.

## Responsabilités

Ark UI gère la résolution de la locale, la direction du texte et l’API du provider. moduix réexporte
`LocaleProvider` et `useLocaleContext` depuis `@moduix/react/locale` via son entrée publique dédiée.
