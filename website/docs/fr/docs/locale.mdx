`LocaleProvider` fournit une locale et sa direction d’écriture à un sous-arbre. Les formateurs Ark et le contenu
localisé utilisent ce contexte.

## Référence de l’API

<PrimitiveReference href="https://ark-ui.com/docs/utilities/locale" />

Importez l’utilitaire depuis le paquet moduix correspondant, qui réexporte le provider de locale
d’Ark UI :

<Tabs
  groupId="framework"
  values={[
    { label: 'React', value: 'react' },
    { label: 'Solid', value: 'solid' },
  ]}
  className="docs-tabs"
>
  <Tab value="react">

```tsx
import { LocaleProvider, useLocaleContext } from '@moduix/react/locale';
```

  </Tab>
  <Tab value="solid">

```tsx
import { LocaleProvider, useLocaleContext } from '@moduix/solid/locale';
```

  </Tab>
</Tabs>

`Format.Number`, `Format.Time` et les autres utilitaires `Format` restent importés depuis `@ark-ui/react` ou
`@ark-ui/solid`.

`LocaleProvider` accepte une chaîne de locale au format BCP 47, par exemple `fr-FR`. Sans provider, Ark utilise `en-US`
et `ltr`.

## Lire le contexte de locale

`useLocaleContext` renvoie `locale` et `dir` depuis le provider le plus proche. Utilisez ces valeurs lorsque votre propre
structure doit reprendre la même langue et la même direction que les composants qui tiennent compte de la locale. React
lit directement les valeurs ; Solid les lit via un accessor.

## Définir la langue et la direction du document

`LocaleProvider` déduit la direction `dir` d’Ark à partir de la locale, mais ne modifie pas les attributs natifs `lang`
et `dir` du document. Si toute l’application utilise une même direction, définissez les deux attributs sur la racine du
document :

<div className="docs-reference">
  <Tabs
    groupId="framework"
    values={[
      { label: 'React', value: 'react' },
      { label: 'Solid', value: 'solid' },
    ]}
    className="docs-tabs"
  >
    <Tab value="react">

```tsx pure file="../../../src/components/examples/locale/document.tsx"
```

    </Tab>
    <Tab value="solid">

<CodeBlockRuntime lang="tsx" code={localeSolidDocument} />

    </Tab>
  </Tabs>
</div>

Pour une zone RTL dans une application LTR, définissez `lang` et la valeur correspondante de `dir` sur la racine de
cette zone, comme dans l’exemple de contexte. Si les utilisateurs peuvent passer d’une locale LTR à une locale RTL sans
recharger la page, mettez à jour les attributs du document en même temps que `locale`. Consultez [De droite à gauche
(RTL)](/docs/rtl) pour les portails, les propriétés CSS logiques et les icônes directionnelles.
