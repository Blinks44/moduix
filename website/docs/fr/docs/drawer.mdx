## Choisir le bon composant

Utilisez `Drawer` pour un panneau qui glisse depuis le bord de la fenêtre. Il convient à la
navigation, aux formulaires, aux panneaux bas mobiles et aux scénarios où l'utilisateur doit faire
glisser le panneau ou passer d'un point d'ancrage à un autre. Choisissez `Dialog` pour une surface
centrée qui n'a pas besoin d'être déplacée.

## Anatomie

```text
Drawer / Drawer.Root
├─ Drawer.Trigger
├─ Drawer.SwipeArea (facultatif)
├─ Drawer.Backdrop
└─ Drawer.Positioner
   └─ Drawer.Content
      ├─ Drawer.Grabber
      │  └─ Drawer.GrabberIndicator
      ├─ Drawer.Header (aide de mise en page facultative)
      │  ├─ Drawer.Title
      │  ├─ Drawer.Description
      │  └─ Drawer.CloseIcon (aide facultative)
      ├─ Drawer.Body (aide de mise en page facultative)
      └─ Drawer.Footer (aide de mise en page facultative)

Drawer.RootProvider
└─ même arborescence de parties connectée à un store useDrawer()
```

| Partie | Rôle |
| --- | --- |
| `Drawer` / `Drawer.Root` | Partie racine qui gère l'état d'ouverture, les points d'ancrage et le balayage. |
| `Drawer.RootProvider` | Connecte les parties à l'état créé avec `useDrawer()`. |
| `Drawer.Trigger` | Ouvre le panneau. |
| `Drawer.SwipeArea` | Zone facultative au bord de l'écran qui ouvre le panneau par balayage. |
| `Drawer.Backdrop` | Calque modal. |
| `Drawer.Positioner` | Positionne le contenu du panneau. |
| `Drawer.Content` | Surface interactive du panneau. |
| `Drawer.Grabber` | Conteneur de la poignée de déplacement. |
| `Drawer.GrabberIndicator` | Indicateur visuel dans la poignée. |
| `Drawer.Title` | Nom accessible du panneau. |
| `Drawer.Description` | Description accessible du panneau. |
| `Drawer.CloseTrigger` | Ferme le panneau. |
| `Drawer.CloseIcon` | Contrôle de fermeture moduix composé avec `CloseTrigger`. |
| `Drawer.Stack` | Coordonne les panneaux imbriqués et les surfaces décalées. |
| `Drawer.Indent` | Surface qui recule lorsqu'un panneau empilé s'ouvre. |
| `Drawer.IndentBackground` | Arrière-plan derrière une surface décalée. |
| `Drawer.Header`, `Drawer.Body`, `Drawer.Footer` | Aides de mise en page facultatives sans état propre. |

## Composition

Par défaut, `Drawer` gère son état et rend `Backdrop` et `Positioner` dans un portail. Gardez ces
parties structurelles explicites. Définissez `portalled={false}` pour les rendre dans l'arborescence
actuelle, ou transmettez `portalRef` pour utiliser un conteneur personnalisé.

Lorsque l'état doit être créé en dehors de l'arborescence du panneau, créez un store avec
`useDrawer()` et transmettez-le à un seul `Drawer.RootProvider`. Ne rendez pas `Drawer` ou
`Drawer.Root` pour ce même store. Les panneaux imbriqués utilisent des stores et des arborescences
`RootProvider` distincts afin de conserver leur propre état d'ouverture et de focus.

Regroupez dans `Drawer.Stack` les surfaces qui doivent se déplacer ensemble, puis associez
`Drawer.IndentBackground` et `Drawer.Indent`. Utilisez `asChild` pour un hôte personnalisé du trigger
ou de la fermeture : React reçoit un seul enfant pouvant recevoir le focus, tandis que Solid utilise
une fonction de rendu qui diffuse `props()` sur l'enfant. Les callbacks Ark reçoivent des objets de
détails, comme `details.open`, `details.snapPoint` et `details.value`.

## Styles

Utilisez `className` dans React ou `class` dans Solid sur les parties exportées pour les styles
structurels. Pour les styles liés à l'état, préférez les attributs de données d'Ark tels que
`data-state`, `data-swipe-direction` et `data-dragging`, avec les sélecteurs `data-slot` de moduix.
Les variantes Tailwind utilisent des utilitaires natifs et les classes du consommateur ; les
variables ci-dessous personnalisent les variantes CSS Modules. Les attributs de données et les hooks
`data-slot` sont communs aux deux modes de style.

### Points d’accroche CSS

- valeurs `data-slot` de moduix : `drawer-trigger`, `drawer-backdrop`, `drawer-positioner`, `drawer-content`,
  `drawer-grabber`, `drawer-grabber-indicator`, `drawer-title`, `drawer-description`,
  `drawer-close-trigger`, `drawer-close-icon`, `drawer-swipe-area`, `drawer-indent`,
  `drawer-indent-background`, `drawer-header`, `drawer-body` et `drawer-footer`.
- `Drawer.Content` écrit `data-variant="island"` lorsque sa présentation en îlot est active.
- hooks des parties Ark : `data-scope="drawer"` avec `data-part`.
- hooks d'état : `data-state="open|closed"`, `data-swipe-direction`, `data-swiping`,
  `data-dragging`, `data-expanded`, `data-current`, `data-value`, `data-disabled`,
  `data-nested-drawer-open` et `data-nested-drawer-swiping`.
- variables d'exécution : `--drawer-translate`, `--drawer-translate-x`, `--drawer-translate-y`,
  `--drawer-snap-point-offset-x`, `--drawer-snap-point-offset-y`, `--drawer-swipe-movement-x`,
  `--drawer-swipe-movement-y`, `--drawer-swipe-progress`, `--drawer-swipe-strength`,
  `--drawer-height`, `--drawer-frontmost-height`, `--nested-drawers`, `--nested-layer-count`
  et `--layer-index`.
