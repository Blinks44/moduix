# Réinitialisation du mot de passe

Permettez à l’utilisateur de choisir un nouveau mot de passe après avoir ouvert un lien de
réinitialisation vérifié. La validation native garantit que les deux champs sont remplis ; vérifiez
que les mots de passe correspondent dans votre gestionnaire `onSubmit`.

## Utilisation dans une route

Affichez `ResetPassword` dans la route atteinte depuis un lien de réinitialisation vérifié et
transmettez-lui le véritable gestionnaire d’envoi. Remplacez le lien `/sign-in` par la route de votre
application.

Vérifiez le jeton de réinitialisation sur le serveur avant d’accepter le mot de passe. Présentez un
jeton expiré ou déjà utilisé comme un état au niveau de la route, avec un lien permettant de demander
un nouvel e-mail. Pendant l’envoi, désactivez les requêtes en double, validez le champ de confirmation
et associez au formulaire une erreur serveur qui peut être affichée sans risque. Après la réussite,
invalidez le jeton et dirigez l’utilisateur vers la connexion ou une session authentifiée selon
votre politique.
