## Référence de l’API

`Typeset` applique un rythme de lecture cohérent au HTML sémantique contenu dans son périmètre. Il ne
rend ni n’analyse le Markdown, ne filtre pas le contenu non fiable et ne définit pas la largeur du
texte. Ces choix restent du ressort de l’application.

moduix construit `Typeset` avec la
[factory d’Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory). `Typeset` et
`Typeset.Scroll` acceptent donc les attributs natifs d’un `div`, les refs et la composition via
`asChild`.

Le contrat CSS-first de Typeset suit l’approche présentée dans
[shadcn/typeset](https://ui.shadcn.com/docs/typeset). Comme dans cette référence, trois variables
contrôlent le rythme, tandis que le rendu du contenu et sa largeur restent à la charge de
l’application ; moduix ajoute des composants natifs pour React et Solid ainsi que `Typeset.Scroll`.

## Anatomie

```text
Typeset / Typeset.Root
└─ Typeset.Scroll (facultatif)
```

| Partie | Rôle |
| --- | --- |
| `Typeset` / `Typeset.Root` | Conteneur racine qui applique les styles aux descendants sémantiques. |
| `Typeset.Scroll` | Zone de défilement horizontal focusable pour un bloc rendu large. |

## Composition

`Typeset` ne gère aucun état, n’analyse ni ne filtre le contenu et n’en définit pas la largeur.
Gardez les éléments sémantiques rendus dans la racine, utilisez `asChild` lorsque celle-ci doit être
un `article` ou une `section`, et composez `Typeset.Scroll` autour d’un bloc large qui doit défiler
plutôt que se comprimer. Ajoutez `.not-typeset` ou `data-not-typeset` à un sous-arbre appartenant à
l’application lorsqu’il doit conserver sa propre mise en forme. Une zone de défilement destinée aux
utilisateurs doit avoir un nom accessible ; `Typeset.Scroll` peut recevoir le focus au clavier par
défaut.

Utilisez `--moduix-typeset-size`, `--moduix-typeset-leading` et `--moduix-typeset-flow` pour régler
le rythme de lecture. Les variables de police sont facultatives ; les couleurs, bordures et rayons
viennent du thème moduix actif. Les règles des éléments se trouvent dans la couche
`moduix.components` et utilisent des sélecteurs `:where()` peu spécifiques, donc le CSS ordinaire de
l’application peut remplacer certains éléments sans `!important`.

Utilisez `className` dans React et `class` dans Solid pour les styles structurels des parties
exportées. Les variantes Tailwind utilisent les utilitaires natifs et les classes de l’application ;
les variables ci-dessous personnalisent les variantes CSS Modules.

### Points d’accroche CSS

- `data-slot="typeset"` cible le conteneur racine.
- `data-slot="typeset-scroll"` cible la zone de débordement facultative et son état au focus.
- `[data-scope="typeset"][data-part="root"]` et `[data-part="scroll"]` fournissent des points
  d’accroche stables pour les parties du composant.
