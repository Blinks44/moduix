`Format.Time` transforme une valeur horaire en texte selon la locale, en React comme en Solid. Les deux frameworks
utilisent les mêmes paramètres.

## Options de formatage

Le format par défaut est sur 24 heures. Utilisez `format="12h"` pour un affichage sur 12 heures, `withSeconds` pour
ajouter les secondes, et `amLabel` ou `pmLabel` pour remplacer les libellés de période en affichage sur 12 heures.

qu’elles existent dans les données source.

## Locale et valeurs Date

`Format.Time` lit la locale du `LocaleProvider` le plus proche. Sans fournisseur, Ark UI utilise `en-US`. Utilisez un
`Date` lorsque la valeur représente un instant précis, par exemple un horodatage reçu d’une API. Pour un `Date`, l’heure
affichée dépend du fuseau horaire local de l’environnement d’exécution. `LocaleProvider` définit la locale, pas le fuseau
horaire.

Conservez les heures civiles d’un planning sous forme de chaînes. Ne passez un `Date` que si la conversion de fuseau est
prévue.
