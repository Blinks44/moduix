## Quand l’utiliser

Utilisez `Format.Time` pour afficher une heure selon la locale active, par exemple dans un planning, un flux d’activité,
des horaires de support ou tout autre élément de l’interface. Le composant accepte un objet `Date` ou une chaîne au
format `HH:mm` ou `HH:mm:ss`.

Utilisez une chaîne pour une heure de planning qui ne doit pas changer selon le fuseau horaire. Utilisez un `Date` lorsque
la valeur représente un instant précis.

Importez `Format` directement depuis Ark UI :

```tsx
import { Format } from '@ark-ui/react';
```

## Format sur 12 heures, secondes et libellés AM/PM

`Format.Time` utilise le format sur 24 heures par défaut. Passez `format="12h"` pour utiliser le format sur 12 heures.
Activez `withSeconds` lorsque les secondes comptent réellement, par exemple dans un indicateur de synchronisation. En
format sur 12 heures, `amLabel` et `pmLabel` remplacent les libellés de période de la journée par défaut.

## Locale et valeurs Date

`Format.Time` récupère la locale depuis `LocaleProvider`. moduix réexporte ce fournisseur : utilisez-le pour définir
la locale une seule fois dans toute l’interface.

```tsx
import { Format } from '@ark-ui/react';
import { LocaleProvider } from '@moduix/react/locale';

export function LocalizedTime() {
  return (
    <LocaleProvider locale="fr-FR">
      <Format.Time value="17:15" />
    </LocaleProvider>
  );
}
```

Utilisez un `Date` lorsque vous disposez déjà d’une valeur date-heure précise, par exemple un horodatage reçu d’une API :

```tsx
import { Format } from '@ark-ui/react';

export function UpdatedAt({ value }: { value: Date }) {
  return <Format.Time value={value} />;
}
```

Pour un `Date`, `Format.Time` affiche l’heure dans le fuseau horaire local de l’environnement d’exécution.
`LocaleProvider` définit la locale, mais pas le fuseau horaire. N’utilisez donc pas `Date` pour une heure de planning si
aucune conversion n’est prévue.

## Utilisation avec moduix

`Format.Time` ne rend que du texte. Utilisez `Card`, `Stack`, `Text` et les composants de statut de moduix pour expliquer
ce que représente l’heure. Ne créez pas de composant uniquement pour appeler le formateur.

## Responsabilités

Ark UI gère le formatage de l’heure et l’API `Format.Time`. moduix fournit les composants d’interface qui l’accompagnent
et réexporte `LocaleProvider`, mais ne réexporte pas `Format.Time`.
