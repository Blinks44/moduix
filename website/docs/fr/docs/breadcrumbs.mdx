## Référence de l’API

Ark UI ne fournit pas de primitive dédiée pour les fils d’Ariane. moduix construit ce composant à l’aide de l’outil officiel
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) et suit les recommandations d’Ark pour la
[composition](https://ark-ui.com/docs/guides/composition), les [styles](https://ark-ui.com/docs/guides/styling) et les
[refs](https://ark-ui.com/docs/guides/ref).

## Exemple de base

Utilisez `Breadcrumbs.Path` lorsque l’application sait déjà quel chemin afficher. Le composant génère la liste ordonnée,
les éléments, les liens, la page actuelle et les séparateurs à partir d’un petit tableau `items`.

## Anatomie

`Breadcrumbs` expose ses parties dans un espace de noms conforme au modèle d’Ark.

```text
Breadcrumbs / Breadcrumbs.Root
└─ Breadcrumbs.List
   ├─ Breadcrumbs.Item
   │  └─ Breadcrumbs.Link
   ├─ Breadcrumbs.Separator
   └─ Breadcrumbs.Item
      └─ Breadcrumbs.Page
```

| Partie                              | Rôle                                                               |
| ----------------------------------- | ------------------------------------------------------------------ |
| `Breadcrumbs` / `Breadcrumbs.Root` | Zone de navigation racine avec un `aria-label` par défaut.         |
| `Breadcrumbs.List`                 | Liste ordonnée des segments du fil d’Ariane.                       |
| `Breadcrumbs.Item`                 | Élément de liste qui enveloppe un segment.                         |
| `Breadcrumbs.Link`                 | Ancre stylisée pour les segments navigables ; prend en charge `asChild`. |
| `Breadcrumbs.Page`                 | Texte de la page actuelle avec `aria-current="page"`.             |
| `Breadcrumbs.Separator`            | Séparateur visuel sans rôle sémantique, masqué pour les technologies d’assistance. |
| `Breadcrumbs.Ellipsis`             | Marqueur compact pour un déclencheur de menu qui affiche les segments masqués. |

`Breadcrumbs.Path` est un raccourci fourni par moduix. Il génère `Breadcrumbs.List`, `Breadcrumbs.Item`, `Breadcrumbs.Link`,
`Breadcrumbs.Page` et `Breadcrumbs.Separator` à partir d’un tableau `items`.

## Composition

### Composition recommandée

Utilisez `Breadcrumbs.Path` pour les fils d’Ariane simples composés de liens. Le dernier élément devient la page actuelle.
Un chevron sépare les éléments par défaut, et `separator` le remplace dans chaque intervalle visible. Le raccourci génère
lui-même ses enfants et n’accepte donc ni `children` ni `asChild`. Les propriétés natives de la liste ordonnée et la ref
sont transmises au `Breadcrumbs.List` généré.

### Quand créer une composition personnalisée

Utilisez les parties explicites lorsque vous avez besoin de liens gérés par le routeur de votre framework, de segments
intermédiaires masqués ou d’un balisage différent selon les éléments. `asChild` d’Ark permet d’utiliser ces liens du routeur.
L’enfant doit être un seul lien sémantique qui conserve les `href`, le focus et le comportement clavier attendus.

Associez le composant à `Menu` lorsque les segments intermédiaires doivent être masqués derrière un déclencheur affichant
des points de suspension. Conservez la structure de `Menu` explicite : `Menu.Positioner`, `Menu.Content` et
`Menu.Item asChild`. Menu gère la frontière du portail.

### Propriétés par défaut

| Partie                              | Valeur par défaut | Remarques                                                    |
| ----------------------------------- | ----------------- | ------------------------------------------------------------ |
| `Breadcrumbs` / `Breadcrumbs.Root` | -                 | Aucun comportement supplémentaire par défaut ; les valeurs d’Ark s’appliquent. |
| `Breadcrumbs.Path`                 | chevron           | Utilise des chevrons entre les éléments si `separator` n’est pas défini. |

### Comportement

- `Breadcrumbs` affiche un repère `nav` dont l’`aria-label` par défaut vaut `"Breadcrumb"`.
- `Breadcrumbs.Path` génère une liste ordonnée à partir de `items` ; le dernier élément est toujours la page actuelle.
- `Breadcrumbs.Path` transmet les propriétés natives de la liste ordonnée et la ref, mais ses enfants sont générés et fixes.
  Il ne prend donc pas en charge `children` ni `asChild`.
- `Breadcrumbs.Separator` est purement visuel et masqué pour les technologies d’assistance.
- `Breadcrumbs.Ellipsis` est masqué pour les technologies d’assistance, car le déclencheur porte le libellé.
- Placez le libellé accessible du chemin condensé sur `Menu.Trigger`.
- Tout élément visible du fil d’Ariane peut rétrécir lorsque l’espace manque. La page actuelle reste la cible principale de
  la troncature grâce à `--moduix-breadcrumbs-item-max-width`.
- Breadcrumbs ne possède aucune propriété contrôlée, aucun callback, hook de contexte, `RootProvider`, id, `HiddenInput`
  ou intégration avec l’état d’un formulaire, car il ne gère ni état interactif ni état de formulaire.

## Styles

Chaque partie exportée expose les attributs `data-scope="breadcrumbs"` et `data-part` du modèle Ark, ainsi que les hooks
moduix stables `data-slot`. Les variables publiques `--moduix-breadcrumbs-*` contrôlent la mise en page, les styles du texte,
l’anneau de focus, les séparateurs et la taille des points de suspension.

### Sélecteurs de style

- `data-scope="breadcrumbs"` est présent sur chaque partie exportée.
- Les valeurs `data-part="root"`, `list`, `item`, `link`, `page`, `separator` et `ellipsis` suivent le contrat Ark factory
  utilisé par ce composant.
- Les valeurs `data-slot="breadcrumbs-root"`, `breadcrumbs-list`, `breadcrumbs-item`, `breadcrumbs-link`, `breadcrumbs-page`,
  `breadcrumbs-separator` et `breadcrumbs-ellipsis` restent des sélecteurs moduix stables.
- `Breadcrumbs.Link`, `Breadcrumbs.Page` et `Breadcrumbs.Ellipsis` utilisent le même espacement intérieur horizontal défini
  par `--moduix-breadcrumbs-item-padding-x`.
- Les parties visibles de `Breadcrumbs.Item` peuvent rétrécir pour que le fil d’Ariane tienne sur une ligne. La dernière
  partie visible reste la cible principale de la troncature et utilise `--moduix-breadcrumbs-item-max-width`.
