## Anatomie

`Breadcrumbs` expose ses parties dans un espace de noms inspiré du modèle d’Ark.

```text
Breadcrumbs / Breadcrumbs.Root
└─ Breadcrumbs.List
   ├─ Breadcrumbs.Item
   │  └─ Breadcrumbs.Link
   ├─ Breadcrumbs.Separator
   └─ Breadcrumbs.Item
      └─ Breadcrumbs.Page
```

| Partie                              | Rôle                                                               |
| ----------------------------------- | ------------------------------------------------------------------ |
| `Breadcrumbs` / `Breadcrumbs.Root` | Zone de navigation avec un `aria-label` par défaut.               |
| `Breadcrumbs.List`                 | Liste ordonnée des segments du fil d’Ariane.                       |
| `Breadcrumbs.Item`                 | Élément de liste qui contient un segment.                          |
| `Breadcrumbs.Link`                 | Ancre stylisée pour les segments navigables ; prend en charge `asChild`. |
| `Breadcrumbs.Page`                 | Texte de la page actuelle avec `aria-current="page"`.             |
| `Breadcrumbs.Separator`            | Séparateur visuel, sans rôle sémantique, masqué pour les technologies d’assistance. |
| `Breadcrumbs.Ellipsis`             | Marqueur compact pour un déclencheur de menu qui révèle les segments masqués. |

`Breadcrumbs.Path` est un raccourci fourni par moduix. Il génère `Breadcrumbs.List`, `Breadcrumbs.Item`, `Breadcrumbs.Link`,
`Breadcrumbs.Page` et `Breadcrumbs.Separator` à partir d’un tableau `items`.

## Composition

### Composition recommandée

Utilisez `Breadcrumbs.Path` pour les fils d’Ariane simples dont les pages parentes sont des liens. Le dernier élément devient
la page actuelle, un chevron sépare les éléments par défaut et `separator` le remplace dans chaque intervalle visible.
Le raccourci génère lui-même ses enfants et n’accepte donc ni `children` ni `asChild`. Les propriétés natives de la liste
ordonnée et la ref sont transmises au `Breadcrumbs.List` généré.

### Quand créer une composition personnalisée

Utilisez les parties explicites lorsque vous avez besoin de liens gérés par le routeur de votre framework, de segments
intermédiaires masqués ou d’un balisage différent pour certains éléments. `asChild` d’Ark permet de remplacer
`Breadcrumbs.Link` par ce lien. L’enfant doit être un seul lien sémantique qui conserve son `href`, sa gestion du focus
et son comportement clavier.

Associez les parties de Breadcrumbs à `Menu` lorsque les segments intermédiaires doivent être masqués derrière un déclencheur
affichant des points de suspension. Conservez la structure de `Menu` explicite : `Menu.Positioner`, `Menu.Content` et
`Menu.Item asChild`. Le composant `Menu` gère le rendu du contenu dans un portail.

### Propriétés par défaut

| Composant                          | Valeur par défaut | Remarques                                                    |
| ----------------------------------- | ----------------- | ------------------------------------------------------------ |
| `Breadcrumbs` / `Breadcrumbs.Root` | Aucun             | Aucun comportement supplémentaire par défaut ; les valeurs d’Ark s’appliquent. |
| `Breadcrumbs.Path`                 | chevron           | Utilise des chevrons entre les éléments si `separator` n’est pas défini. |

### Comportement

- `Breadcrumbs` rend une zone de navigation `nav` dont l’`aria-label` vaut `"Breadcrumb"` par défaut.
- `Breadcrumbs.Path` génère une liste ordonnée à partir de `items` ; le dernier élément est toujours la page actuelle.
- Tous les éléments sauf le dernier sont rendus comme des `Breadcrumbs.Link` ; fournissez un `href` aux éléments qui
  doivent être navigables et laissez le dernier sans `href`.
- `Breadcrumbs.Path` transmet les propriétés natives de la liste ordonnée et la ref, mais ses enfants sont générés et fixes.
  Il ne prend donc pas en charge `children` ni `asChild`.
- `Breadcrumbs.Separator` est purement visuel et masqué pour les technologies d’assistance.
- `Breadcrumbs.Ellipsis` est purement visuel et masqué pour les technologies d’assistance ; placez-le dans un déclencheur
  `Menu` et ajoutez le libellé accessible du chemin condensé sur `Menu.Trigger`.
- Les éléments visibles peuvent rétrécir lorsque l’espace manque. La page actuelle reste la première cible de la troncature
  grâce à `--moduix-breadcrumbs-item-max-width`.
- Breadcrumbs ne possède aucune propriété contrôlée, aucun callback, hook de contexte, `RootProvider`, id, `HiddenInput`
  ou intégration avec l’état d’un formulaire, car il ne gère ni état interactif ni état de formulaire.

## Styles

Chaque partie exportée expose un sélecteur `data-slot` stable de moduix. Les variables publiques `--moduix-breadcrumbs-*` contrôlent la mise en page, la typographie,
l’anneau de focus, les séparateurs et la taille des points de suspension.

### Propriétés CSS

<CssPropertiesSection properties={BreadcrumbsDocs.breadcrumbsCssProperties} />

### Sélecteurs de style

- Les valeurs `data-slot="breadcrumbs-root"`, `breadcrumbs-list`, `breadcrumbs-item`, `breadcrumbs-link`, `breadcrumbs-page`,
  `breadcrumbs-separator` et `breadcrumbs-ellipsis` constituent des sélecteurs moduix stables.
- `Breadcrumbs.Link`, `Breadcrumbs.Page` et `Breadcrumbs.Ellipsis` partagent l’espacement intérieur horizontal défini par
  `--moduix-breadcrumbs-item-padding-x`.
- Les éléments visibles de `Breadcrumbs.Item` peuvent rétrécir pour que le fil d’Ariane tienne sur une ligne. Le dernier
  élément visible reste la première cible de la troncature et utilise `--moduix-breadcrumbs-item-max-width`.
