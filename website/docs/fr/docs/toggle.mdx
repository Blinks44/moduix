## Référence de l’API

`Toggle` enveloppe le composant primitif Toggle d’Ark UI et ajoute les propriétés visuelles moduix pour les variantes et les tailles.
Importez-le depuis `@moduix/react/toggle`, `@moduix/solid/toggle` ou `@moduix/vue/toggle`.

<PrimitiveReference href="https://ark-ui.com/docs/components/toggle" />

## Choisir le bon composant

Utilisez `Toggle` lorsque le contrôle doit se comporter comme un bouton et indiquer s’il est activé.

- Choisissez **`Toggle`** pour les favoris, l’enregistrement d’éléments, la mise en forme et les actions compactes d’une barre d’outils.
- Choisissez **`Switch`** pour les réglages qui s’activent ou se désactivent, présentés comme des préférences.
- Choisissez **`Checkbox`** pour les sélections envoyées avec une liste ou un formulaire.
- Choisissez **`ToggleGroup`** lorsque plusieurs toggles doivent partager un même modèle de sélection.

## Anatomie

```text
Toggle
└─ ToggleIndicator (facultatif)

ToggleContext (lecteur d’état, pas une partie du DOM)
```

| Partie | Rôle |
| ------ | --- |
| `Toggle` | Partie racine qui gère l’état activé, le focus, la désactivation et la composition `asChild`. |
| `ToggleIndicator` | Partie facultative qui affiche le contenu activé et son `fallback` lorsque le toggle est désactivé. |
| `ToggleContext` | Lit l’état du toggle le plus proche pour les descendants personnalisés ; il ne rend pas de partie du DOM. |

## Composition

Utilisez `defaultPressed` pour un toggle non contrôlé, ou passez `pressed` avec `onPressedChange` lorsque l’état
appartient à l’application. Utilisez `ToggleIndicator` lorsque
le contenu du bouton change selon son état. Pour les descendants personnalisés qui doivent lire cet état, utilisez
`ToggleContext` ou `useToggleContext()` depuis le package correspondant. Utilisez `asChild` lorsqu’un autre bouton
doit porter le comportement du toggle. Dans Solid, `asChild` reçoit une fonction de rendu ; dans React, il reçoit
un seul enfant compatible avec un bouton ; dans Vue, il utilise un seul enfant compatible avec un bouton dans le slot
par défaut. Dans Vue, utilisez `v-model:pressed` pour la valeur contrôlée, le slot nommé `fallback` avec
`ToggleIndicator` et le slot `ToggleContext` lorsqu’un descendant personnalisé doit lire l’état courant.
L’événement `@pressed-change` transmet la nouvelle valeur booléenne pour traiter le changement sans liaison
avec `v-model:pressed`.

## Styles

Utilisez `className` dans React ou `class` dans Solid et Vue sur les parties exportées. Dans les paquets CSS Modules,
définissez les variables de couleur `--moduix-toggle-*` sur un toggle, sur
`[data-slot='toggle-root'][data-variant='<variant>']` pour styliser une variante, ou sur un conteneur comme
`ToggleGroup`. Les tailles, l’espacement, l’arrondi et la typographie viennent des tokens foundation ; modifiez-les avec
une classe. Les paquets Tailwind utilisent à la place les utilitaires natifs et les classes du consommateur.

### Points d’accroche CSS

- Sélecteurs `data-slot` stables : `toggle-root` et `toggle-indicator`.
- Sélecteurs des parties Ark UI : `data-scope="toggle"` et `data-part="root" | "indicator"`.
- Sélecteurs d’état Ark UI : `data-state="on" | "off"`, `data-pressed` et `data-disabled`.
- Sélecteurs moduix : `data-variant` et `data-size`, notamment `icon-sm`, `icon-md` et `icon-lg`.
- Les icônes enfants directes et celles de `ToggleIndicator` mesurent 16px par défaut. Une classe sur l’icône, comme
  `size-5` dans Tailwind, remplace cette taille.
