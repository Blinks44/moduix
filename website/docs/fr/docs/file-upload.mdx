## Exemple de base

Commencez par `FileUpload` comme composant racine. Ajoutez un `Label`, puis choisissez un `Trigger` ou une `Dropzone`.
Utilisez `Items` pour afficher les fichiers acceptés. La racine ajoute automatiquement l’input natif du formulaire.
`Items` utilise une vignette uniquement lorsque le navigateur signale un type MIME `image/*` ; sinon, il affiche
l’aperçu générique des fichiers.

## Anatomie

```text
FileUpload / FileUpload.Root
├─ FileUpload.Label
├─ FileUpload.Dropzone
│  ├─ FileUpload.DropzoneIcon
│  └─ FileUpload.Trigger
├─ FileUpload.ItemGroup[type]
│  ├─ FileUpload.Items
│  └─ FileUpload.Context
│     └─ FileUpload.Item[file]
│        ├─ FileUpload.ItemPreview[type]
│        │  ├─ FileUpload.ItemPreviewImage
│        │  └─ FileUpload.ItemPreviewIcon
│        ├─ FileUpload.ItemName
│        ├─ FileUpload.ItemMetadata[file]
│        ├─ FileUpload.ItemSizeText
│        └─ FileUpload.ItemDeleteTrigger
├─ FileUpload.ClearTrigger
└─ native input (automatic)
```

| Partie | Rôle |
| -------------------------------- | ------------------------------------------------------------------------ |
| `FileUpload` / `FileUpload.Root` | Gère l’état des fichiers, la validation, le glisser-déposer, le collage et l’intégration aux formulaires. |
| `FileUpload.RootProvider` | Construit l’arbre de téléversement à partir de l’état renvoyé par le hook Ark `useFileUpload`. |
| `FileUpload.Label` | Libellé accessible pour l’input masqué et les contrôles de téléversement. |
| `FileUpload.Dropzone` | Zone de glisser-déposer. Passez `disableClick` lorsqu’elle contient un déclencheur imbriqué. |
| `FileUpload.DropzoneIcon` | Icône de téléversement décorative pour une dropzone. |
| `FileUpload.Trigger` | Bouton qui ouvre le sélecteur de fichiers natif. |
| `FileUpload.ItemGroup` | Conteneur de liste pour les fichiers acceptés ou rejetés. |
| `FileUpload.Items` | Cartes prêtes à l’emploi pour les images et lignes pour les autres fichiers, avec aperçus, métadonnées et boutons de suppression. |
| `FileUpload.Context` | Contexte avec render prop compatible avec Ark pour créer des lignes de fichiers personnalisées. |
| `FileUpload.Item` | Ligne de fichier. Transmettez l’objet actuel `file`. |
| `FileUpload.ItemPreview` | Emplacement d’aperçu choisi selon le type MIME. |
| `FileUpload.ItemPreviewImage` | Aperçu d’image à l’intérieur de `ItemPreview`. |
| `FileUpload.ItemPreviewIcon` | Icône de fichier générique pour l’aperçu de secours dans `ItemPreview`. |
| `FileUpload.ItemName` | Nom du fichier. |
| `FileUpload.ItemMetadata` | Type et taille localisée du fichier. Passez l’objet `file` actuel. |
| `FileUpload.ItemSizeText` | Taille du fichier au format localisé. |
| `FileUpload.ItemDeleteTrigger` | Supprime un fichier. Utilise par défaut l’icône de corbeille moduix. |
| `FileUpload.ClearTrigger` | Efface les fichiers sélectionnés. Utilise par défaut l’icône de fermeture moduix. |

## Composition

### Composition recommandée

Gardez l’arbre des parties Ark visible dans votre balisage. Utilisez `Trigger` pour un contrôle de téléversement compact
et `Dropzone` pour une zone de glisser-déposer. Si `Trigger` est imbriqué dans `Dropzone`, passez `disableClick` à
`Dropzone` afin que le sélecteur de fichiers natif ne s’ouvre qu’une seule fois.

La racine ajoute toujours l’input natif du formulaire. Utilisez `Items` pour une liste compacte de fichiers acceptés. Si
vous créez des lignes personnalisées, lisez les fichiers acceptés depuis `FileUpload.Context.acceptedFiles` et les fichiers
rejetés depuis `FileUpload.Context.rejectedFiles`.

Importez `FileUpload.Context`, `useFileUpload()` et `useFileUploadContext()` depuis `@moduix/react` lorsque vous avez besoin
d’un accès avancé à l’état. Ce sont des réexportations directes d’Ark, donc les objets `details` des callbacks et le contrat
d’état restent inchangés.

### Quand créer une composition personnalisée

`Items` affiche les images sous forme de cartes verticales compactes et les autres fichiers sous forme de lignes horizontales
avec leurs métadonnées. Utilisez la composition explicite de `Context` pour créer des lignes personnalisées. `ItemPreview.type`
définit une condition fondée sur une expression régulière, pas une liste de priorités ; affichez donc un seul aperçu pour chaque
fichier. Par exemple, utilisez `file.type.startsWith("image/")` pour sélectionner `ItemPreviewImage`. Pour les autres fichiers,
affichez `ItemPreviewIcon`, puis composez `ItemName`, `ItemMetadata file={file}` et `ItemDeleteTrigger`. Utilisez `asChild`
uniquement lorsque l’enfant est un seul élément sémantique qui peut conserver le comportement requis d’un bouton, d’un libellé
ou d’un input.

### Propriétés par défaut

| Propriété | Par défaut | Remarques |
| --------------------- | ------------ | ----------------------------------------------------------------- |
| `allowDrop` | `true` | Autorise le glisser-déposer sur `Dropzone`. |
| `maxFiles` | `1` | Augmentez cette valeur ou supprimez la limite pour accepter plusieurs fichiers ou dossiers. |
| `minFileSize` | `0` | Taille minimale du fichier accepté, en octets. |
| `maxFileSize` | `∞` | Taille maximale du fichier accepté, en octets. |
| `preventDocumentDrop` | `true` | Empêche une navigation accidentelle lorsqu’un fichier est déposé en dehors de la zone cible. |
| `locale` | `en-US` | Paramètre régional utilisé pour formater la taille des fichiers. |

### Comportement

`acceptedFiles`, `defaultAcceptedFiles` et `onFileChange(details)` suivent le modèle d’état contrôlé ou non contrôlé d’Ark.
`onFileAccept(details)` et `onFileReject(details)` reçoivent les objets `details` d’origine transmis par Ark. `Field.Root`
et `Fieldset.Root` peuvent fournir l’état disabled, invalid, required et read-only. Utilisez `ids` lorsque des libellés ou
des descriptions distincts ont besoin d’associations d’accessibilité stables.

### Points d’accroche CSS

Utilisez des slots moduix stables, comme `[data-slot="file-upload-dropzone"]`,
`[data-slot="file-upload-item"]` et `[data-slot="file-upload-item-delete-trigger"]`.
Ark expose également `data-scope="file-upload"`, `data-part` pour les parties et les attributs d’état tels que
`data-disabled`, `data-readonly`, `data-invalid`, `data-required`, `data-dragging` et `data-type`.
