## Référence de l’API

<PrimitiveReference href="https://ark-ui.com/docs/components/file-upload" />

`FileUpload` est disponible depuis `@moduix/react/file-upload`. Le composant ainsi que les hooks `useFileUpload` et
`useFileUploadContext` sont également exportés par `@moduix/react`.

Le même composant est disponible depuis `@moduix/solid/file-upload`, `@moduix/react-tailwind/file-upload` et
`@moduix/solid-tailwind/file-upload`. Les quatre variantes exposent les mêmes parties et le même modèle d’état.
Choisissez le paquet correspondant à votre framework et à votre solution de styles.

## Choisir le bon composant

Utilisez `FileUpload` lorsque l’application doit conserver les fichiers sélectionnés dans son état,
afficher une zone de dépôt ou gérer un flux d’envoi. Un `Input` avec `type="file"` suffit pour un
sélecteur natif dans un formulaire simple.

## Exemple de base


Commencez par utiliser `FileUpload` comme composant racine. Ajoutez un `FileUploadLabel`, puis utilisez `FileUploadTrigger` pour un contrôle
compact ou `FileUploadDropzone` pour le glisser-déposer. Ajoutez explicitement `FileUploadHiddenInput` pour
ouvrir le sélecteur natif. Placez `FileUploadItems` dans `FileUploadItemGroup` pour afficher les fichiers acceptés. `FileUploadItems` affiche une vignette uniquement lorsque le fichier
possède un type MIME `image/*` ; les autres fichiers utilisent un aperçu générique.

## Anatomie

```text
FileUpload / FileUploadRootProvider
├─ FileUploadLabel
├─ FileUploadDropzone (facultatif)
│  ├─ FileUploadDropzoneIcon
│  └─ FileUploadTrigger
├─ FileUploadTrigger (sans `FileUploadDropzone`)
├─ FileUploadItemGroup[type]
│  ├─ FileUploadItems
│  └─ FileUploadContext
│     └─ FileUploadItem[file]
│        ├─ FileUploadItemPreview[type]
│        │  ├─ FileUploadItemPreviewImage
│        │  └─ FileUploadItemPreviewIcon
│        ├─ FileUploadItemName
│        ├─ FileUploadItemMetadata[file]
│        ├─ FileUploadItemSizeText
│        └─ FileUploadItemDeleteTrigger
├─ FileUploadClearTrigger
└─ FileUploadHiddenInput (explicite)
```

| Partie | Rôle |
| -------------------------------- | ------------------------------------------------------------------------ |
| `FileUpload` / `FileUploadRootProvider` | Gère l’état des fichiers, la validation, le glisser-déposer, le collage et l’intégration aux formulaires. |
| `FileUploadHiddenInput` | Champ natif d’Ark ; composition explicite décrite ci-dessous. |
| `FileUploadRootProvider` | Relie l’arbre du composant à l’état renvoyé par le hook `useFileUpload`. |
| `FileUploadLabel` | Libellé accessible pour le champ de fichier masqué et les contrôles de téléversement. |
| `FileUploadDropzone` | Zone de dépôt. Passez `disableClick` si elle contient un `FileUploadTrigger` imbriqué, afin de ne pas ouvrir deux fois le sélecteur. |
| `FileUploadDropzoneIcon` | Icône de téléversement décorative pour une `FileUploadDropzone`. |
| `FileUploadTrigger` | Bouton qui ouvre le sélecteur de fichiers natif. |
| `FileUploadItemGroup` | Liste des fichiers acceptés ou rejetés. |
| `FileUploadItems` | Composant prêt à l’emploi qui affiche des cartes pour les images et des lignes pour les autres fichiers, avec aperçu, métadonnées et suppression. |
| `FileUploadContext` | Contexte compatible avec Ark et basé sur une fonction de rendu pour créer des lignes personnalisées. |
| `FileUploadItem` | Ligne de fichier. Transmettez-lui l’objet `file` courant. |
| `FileUploadItemPreview` | Emplacement d’aperçu affiché selon le type MIME du fichier. |
| `FileUploadItemPreviewImage` | Aperçu d’image à l’intérieur de `FileUploadItemPreview`. |
| `FileUploadItemPreviewIcon` | Icône de fichier générique pour un aperçu de secours dans `FileUploadItemPreview`. |
| `FileUploadItemName` | Nom du fichier. |
| `FileUploadItemMetadata` | Type du fichier et taille formatée selon la locale. Passez-lui l’objet `file` courant. |
| `FileUploadItemSizeText` | Taille du fichier formatée selon la locale. |
| `FileUploadItemDeleteTrigger` | Supprime un fichier. Utilise par défaut l’icône de corbeille moduix. |
| `FileUploadClearTrigger` | Efface les fichiers sélectionnés. Utilise par défaut l’icône de fermeture moduix. |

## Composition

`FileUpload` conserve l’état des fichiers en interne par défaut. Utilisez `defaultAcceptedFiles` pour une valeur initiale
non contrôlée, ou associez `acceptedFiles` à `onFileChange(details)` lorsque l’application possède cet état. Utilisez
`useFileUpload()` avec `FileUploadRootProvider` lorsque l’état ou les méthodes doivent être créés en dehors de l’arbre rendu.

Ajoutez explicitement `FileUploadHiddenInput` dans `FileUpload` ou `FileUploadRootProvider`, même hors d’un formulaire, car `FileUploadTrigger` l’utilise
pour ouvrir le sélecteur natif. Définissez `name` sur la racine pour la soumission native du formulaire. Si `FileUploadTrigger` est imbriqué
dans `FileUploadDropzone`, passez `disableClick` afin que le sélecteur ne s’ouvre qu’une seule fois.

Utilisez `FileUploadItems` dans `FileUploadItemGroup` pour les lignes de fichiers par défaut. Pour créer vos propres lignes, rendez
`FileUploadContext` et choisissez un seul aperçu par fichier depuis `acceptedFiles` ou `rejectedFiles`.

## Styles

Utilisez `className` en React ou `class` en Solid sur les parties exportées pour les styles structurels. Les variantes Tailwind

### Points d’accroche CSS

Utilisez des slots moduix stables, comme `[data-slot="file-upload-dropzone"]`,
`[data-slot="file-upload-item"]` et `[data-slot="file-upload-item-delete-trigger"]`.
Ark expose également `data-scope="file-upload"`, `data-part` pour les parties et les attributs d’état tels que
`data-disabled`, `data-readonly`, `data-invalid`, `data-required`, `data-dragging` et `data-type`.
