# List Collection

Une `ListCollection` est une structure de données construite à partir d'un tableau d'éléments. Elle
ne rend pas de liste et ne fournit ni la sélection ni le comportement au clavier. Utilisez-la comme
source de données pour `Select`, `Combobox` et `Listbox`, ou pour construire votre propre interface.

Cette page fait partie de la documentation moduix, mais `ListCollection` est un utilitaire d'Ark UI.
Elle n'est pas réexportée par `@moduix/react`.

## Référence de l'API

<PrimitiveReference href="https://ark-ui.com/docs/collections/list-collection" />

Une collection associe chaque élément à une valeur et à un texte d'affichage. Elle peut aussi
indiquer les éléments désactivés, regrouper les éléments, rechercher par texte, parcourir les
valeurs et créer une nouvelle collection sans modifier l'originale.

Importez les utilitaires directement depuis Ark UI :

```tsx
import { createListCollection, useListCollection } from '@ark-ui/react/collection';
```

## Créer une collection

Lorsque les éléments possèdent les propriétés `label` et `value`, Ark les utilise automatiquement. La
propriété optionnelle `disabled` est également prise en compte :

```tsx
const fruits = [
  { label: 'Apple', value: 'apple' },
  { label: 'Banana', value: 'banana' },
  { label: 'Blueberry', value: 'blueberry' },
];

const collection = createListCollection({
  items: fruits,
});
```

Passez la collection à un composant basé sur Ark et affichez ses éléments à partir de
`collection.items`. L'exemple exécutable ci-dessous reprend le même principe avec `Select`.

Conservez une collection statique en dehors du composant lorsque ses éléments ne changent pas. Si
les éléments viennent de props, de l'état React ou d'une requête, utilisez `useMemo` autour de
`createListCollection` pour ne créer une nouvelle collection que lorsque les éléments changent.
Utilisez `useListCollection` lorsque le filtrage ou les mises à jour font partie de l'état React.

## Éléments personnalisés

Si vos données utilisent d'autres noms de propriétés, indiquez à la collection comment obtenir la
valeur, le texte affiché et l'état désactivé :

```tsx
type Team = {
  id: number;
  name: string;
  archived: boolean;
};

const customTeams: Team[] = [
  { id: 1, name: 'Platform', archived: false },
  { id: 2, name: 'Legacy', archived: true },
];

const collection = createListCollection<Team>({
  items: customTeams,
  itemToValue: (item) => String(item.id),
  itemToString: (item) => item.name,
  isItemDisabled: (item) => item.archived,
});
```

Les valeurs de la collection sont des chaînes. Convertissez les identifiants numériques lorsque
vous adaptez vos données métier à la collection. Par défaut, `itemToValue`, `itemToString` et
`isItemDisabled` lisent respectivement `value`, `label` et `disabled`.

| Option           | Rôle                                                                  |
| ---------------- | --------------------------------------------------------------------- |
| `items`          | Éléments à inclure. Accepte tout itérable.                            |
| `itemToValue`    | Renvoie la valeur chaîne utilisée par la collection et ses composants. |
| `itemToString`   | Renvoie le texte affiché et utilisé pour la recherche.                |
| `isItemDisabled` | Indique si un élément est désactivé.                                  |
| `groupBy`        | Renvoie une clé de groupe pour chaque élément.                        |
| `groupSort`      | Trie les groupes avec un comparateur, un ordre explicite, `'asc'` ou `'desc'`. |

## Lire et rechercher

Utilisez ces méthodes pour consulter les éléments et passer des objets aux valeurs chaîne, et
inversement.

| API                                 | Résultat                                                         |
| ----------------------------------- | ---------------------------------------------------------------- |
| `collection.items`                  | Éléments dans l'ordre courant de la collection.                  |
| `collection.size`                   | Nombre d'éléments.                                               |
| `getValues(items?)`                 | Valeurs de tous les éléments ou des éléments fournis.            |
| `find(value)` / `findMany(values)`  | L'élément d'une valeur ou les éléments de plusieurs valeurs.     |
| `at(index)`                         | Élément à l'index indiqué, ou `null`.                            |
| `indexOf(value)`                    | Index dans la collection, ou `-1` si la valeur est introuvable.  |
| `has(value)` / `hasItem(item)`      | Indique si une valeur ou un élément est présent.                 |
| `getItemValue(item)`                | Valeur chaîne normalisée de l'élément.                            |
| `stringifyItem(item)`               | Texte d'affichage d'un élément.                                   |
| `stringify(value)`                  | Texte d'affichage d'une valeur.                                  |
| `stringifyItems(items, separator?)` | Texte d'affichage de plusieurs éléments, assemblé avec le séparateur. |
| `stringifyMany(values, separator?)` | Texte d'affichage de plusieurs valeurs, assemblé avec le séparateur.  |
| `getItemDisabled(item)`             | État désactivé normalisé de l'élément.                            |
| `group()`                           | Paires `[groupKey, items]` selon les options de regroupement.     |

```tsx
collection.find('product'); // { label: 'Product', value: 'product' }
collection.stringify('product'); // 'Product'
collection.has('unknown'); // false
```

## Parcourir la collection

Utilisez ces propriétés et méthodes pour parcourir les éléments disponibles ou trier des valeurs
selon l'ordre de la collection :

```tsx
collection.firstValue; // 'platform'
collection.lastValue; // 'product' - disabled items are skipped
collection.getNextValue('platform'); // 'product'
collection.getPreviousValue('design'); // 'product'
collection.getValueRange('platform', 'product'); // ['platform', 'product']
collection.sort(['design', 'platform']); // ['platform', 'design']
```

`firstValue`, `lastValue`, `getNextValue`, `getPreviousValue` et `getValueRange` ignorent les
éléments désactivés. Les méthodes de déplacement vers l'élément suivant ou précédent acceptent un
`step` facultatif et un indicateur `clamp`. Lorsque `clamp` est désactivé, dépasser une extrémité
renvoie `null`.
`getValueRange` renvoie les valeurs dans l'ordre de la collection, quel que soit l'ordre des bornes.

`compareValue(a, b)` compare deux valeurs selon l'ordre de la collection. `isEqual(other)` compare
les tableaux d'éléments de deux collections. Une collection peut être parcourue avec `for...of`.
`toString()` renvoie une représentation compacte de ses éléments, tandis que `toJSON()` renvoie sa
taille ainsi que ses première et dernière valeurs.

La méthode `search(query, options)` recherche par préfixe pour les interfaces de saisie au clavier
et ignore les éléments désactivés. Conservez l'état de recherche entre les appels :

```tsx
const searchState = { keysSoFar: '', timer: -1 };

const nextValue = collection.search('p', {
  state: searchState,
  currentValue: null,
  timeout: 350,
});
```

Dans un composant React, placez `searchState` dans un `useRef` afin qu'il survive aux nouveaux
rendus.

## Mises à jour immuables

Les méthodes de mise à jour renvoient une nouvelle collection. Conservez le résultat si vous voulez
garder la modification ; la collection d'origine reste inchangée.

```tsx
const nextCollection = collection
  .append({ label: 'Support', value: 'support' })
  .remove('design')
  .reorder(0, 1);
```

| API                                      | Fonctionnement                                      |
| ---------------------------------------- | --------------------------------------------------- |
| `copy(items?)` / `setItems(items)`       | Copie la collection ou remplace tous les éléments.  |
| `update(value, item)`                    | Remplace un élément existant.                       |
| `upsert(value, item, mode?)`             | Met à jour un élément ou l'ajoute à une extrémité. |
| `insert(index, ...items)`                | Insère des éléments à l'index indiqué.              |
| `insertBefore(value, ...items)`          | Insère des éléments avant une valeur.               |
| `insertAfter(value, ...items)`           | Insère des éléments après une valeur.               |
| `prepend(...items)` / `append(...items)` | Ajoute des éléments au début ou à la fin.           |
| `filter(predicate)`                      | Renvoie une collection contenant les éléments retenus. |
| `remove(...itemsOrValues)`               | Supprime des éléments ou des valeurs.               |
| `move(value, index)`                     | Déplace une valeur vers un index.                   |
| `moveBefore(value, ...values)`           | Déplace les valeurs fournies avant une valeur cible. |
| `moveAfter(value, ...values)`            | Déplace les valeurs fournies après une valeur cible. |
| `reorder(from, to)`                      | Déplace un élément entre deux index numériques.    |

`upsert` accepte `mode: 'append' | 'prepend'` lorsque la valeur n'existe pas.

## État React

Utilisez `useListCollection` lorsque le filtrage ou les mises à jour de la collection doivent
suivre l'état React :

```tsx
import { useFilter } from '@ark-ui/react/locale';
import { useListCollection } from '@ark-ui/react/collection';

const teams = [
  { label: 'Platform', value: 'platform' },
  { label: 'Product', value: 'product' },
  { label: 'Design', value: 'design' },
];

function useTeams() {
  const { contains } = useFilter({ sensitivity: 'base' });

  return useListCollection({
    initialItems: teams,
    filter: contains,
    limit: 20,
  });
}
```

Le hook renvoie la `collection` active et les méthodes de filtrage et de mise à jour :
`filter`, `set`, `reset`, `clear`, `insert`, `insertBefore`, `insertAfter`, `remove`, `move`,
`moveBefore`, `moveAfter`, `reorder`, `append`, `prepend`, `update` et `upsert`.

Appelez `filter('')` pour réafficher tous les éléments. Appelez `reset()` pour restaurer
`initialItems`. La fonction `filter` reçoit le texte d'affichage d'un élément et le texte du filtre.
Pour effectuer une recherche adaptée à la langue, utilisez une fonction telle que `contains`,
renvoyée par `useFilter` d'Ark UI, comme dans l'exemple ci-dessus.

Conservez une `createListCollection` statique en dehors du composant lorsque les éléments ne
changent jamais. Utilisez le hook lorsque React doit gérer le filtrage ou les modifications de la
collection.
