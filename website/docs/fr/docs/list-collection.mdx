# List Collection

`ListCollection` est l'utilitaire de données d'Ark UI pour les éléments provenant d'un tableau. Il
associe à chaque élément une valeur chaîne et un texte d'affichage, et fournit des méthodes de
recherche, de parcours, de filtrage, de regroupement et de mise à jour immuable. Il ne rend aucun
élément et ne gère ni la sélection ni les interactions au clavier. `Select`, `Combobox` et `Listbox`
l'utilisent comme source de données.

## Référence de l'API

<PrimitiveReference href="https://ark-ui.com/docs/collections/list-collection" />

`ListCollection` n'est pas un composant Moduix et n'est réexporté par aucun package Moduix.

Conservez une collection statique en dehors du composant. Lorsque les éléments viennent des props,
de l'état ou d'une requête, ne recréez la collection que lorsque les données sources changent.
Lorsque le filtrage ou les mises à jour doivent suivre l'état du framework, utilisez le hook
dynamique présenté ci-dessous.
Dans React, utilisez `useMemo`; dans Solid, utilisez `createMemo` lorsque les données sources sont réactives.

## Formes d'éléments personnalisées

Utilisez `itemToValue`, `itemToString` et `isItemDisabled` lorsque vos données n'utilisent pas les
noms de propriétés par défaut. Les valeurs d'une collection sont toujours des chaînes, convertissez
donc explicitement les identifiants numériques :

```tsx
type Team = {
  id: number;
  name: string;
  archived: boolean;
};

const collection = createListCollection<Team>({
  items: [
    { id: 1, name: 'Platform', archived: false },
    { id: 2, name: 'Legacy', archived: true },
  ],
  itemToValue: (item) => String(item.id),
  itemToString: (item) => item.name,
  isItemDisabled: (item) => item.archived,
});
```

| Option           | Rôle                                                         |
| ---------------- | ------------------------------------------------------------ |
| `items`          | Éléments à inclure. Accepte un itérable ou un itérable en lecture seule. |
| `itemToValue`    | Renvoie la valeur chaîne d'un élément.                       |
| `itemToString`   | Renvoie le texte d'affichage et de recherche.                 |
| `isItemDisabled` | Indique si un élément est désactivé.                          |
| `groupBy`        | Renvoie la clé de groupe d'un élément.                        |
| `groupSort`      | Trie les groupes avec un comparateur, un ordre explicite, `'asc'` ou `'desc'`. |

## Consulter et parcourir

Utilisez la collection pour convertir les objets en valeurs et inversement, inspecter leur ordre ou
parcourir les éléments activés :

| API                                | Résultat                                                     |
| ---------------------------------- | ------------------------------------------------------------ |
| `collection.items` / `collection.size` | Éléments courants et nombre d'éléments.                   |
| `getValues(items?)`                | Valeurs de tous les éléments ou d'une sélection.             |
| `find(value)` / `findMany(values)` | Un ou plusieurs éléments correspondant à une valeur.        |
| `at(index)` / `indexOf(value)`     | Élément par index ou index par valeur.                       |
| `has(value)` / `hasItem(item)`     | Indique si une valeur ou un élément existe.                  |
| `getItemValue(item)`               | Valeur chaîne normalisée d'un élément.                       |
| `stringifyItem(item)` / `stringify(value)` | Texte d'affichage d'un élément ou d'une valeur.      |
| `getItemDisabled(item)`            | État désactivé normalisé.                                    |
| `group()`                          | Paires `[groupKey, items]` selon les options de regroupement. |

```tsx
const teamCollection = createListCollection({
  items: [
    { label: 'Platform', value: 'platform' },
    { label: 'Product', value: 'product' },
  ],
});

teamCollection.find('product'); // { label: 'Product', value: 'product' }
teamCollection.stringify('product'); // 'Product'
teamCollection.getNextValue('platform'); // 'product'
teamCollection.has('unknown'); // false
```

`firstValue`, `lastValue`, `getNextValue`, `getPreviousValue` et `getValueRange` suivent l'ordre de
la collection et ignorent les éléments désactivés. Les méthodes de parcours acceptent un `step` et
un indicateur `clamp` facultatifs. `sort(values)` trie les valeurs selon l'ordre de la collection et
`compareValue(a, b)` compare deux valeurs selon cet ordre.

Pour le comportement typeahead, appelez `search(queryString, options)` avec un état de recherche
stable :

```tsx
const searchState = { keysSoFar: '', timer: -1 };

const nextValue = collection.search('p', {
  state: searchState,
  currentValue: null,
  timeout: 350,
});
```

Conservez `searchState` pendant toute l'interaction. Dans React, `useRef` est un emplacement adapté.
Dans Solid, gardez le même objet dans le composant ou dans un autre stockage stable.

## Collections dynamiques

Utilisez `useListCollection` lorsque la collection est filtrée ou mise à jour depuis l'état du
composant. Le callback `filter` reçoit le texte affiché de l'élément, le texte actuel du filtre et
l'élément lui-même. `limit` peut limiter le nombre d'éléments conservés pour les grands ensembles de
données.

L'exemple utilise `Listbox` avec un champ de filtre séparément étiqueté. Définissez
`typeahead={false}` lorsque ce champ gère le filtrage, et affichez un état vide lorsqu'aucun élément
ne correspond.

Dans React, `collection` est une `ListCollection`. Dans Solid, c'est un accessor : appelez donc
`collection()` pour le passer à un composant ou lisez `collection().items` dans une boucle `<For>`.
Le hook expose `filter`, `set`, `reset`, `clear`, `insert`, `insertBefore`, `insertAfter`, `remove`,
`move`, `moveBefore`, `moveAfter`, `reorder`, `append`, `prepend`, `update` et `upsert`.

Appelez `filter('')` pour restaurer tous les éléments et `reset()` pour restaurer `initialItems`.

## Mises à jour immuables

Les méthodes de mise à jour de `ListCollection` renvoient une nouvelle collection. Conservez la
valeur renvoyée si la modification doit devenir la collection suivante :

```tsx
const nextCollection = collection
  .append({ label: 'Support', value: 'support' })
  .remove('design')
  .reorder(0, 1);
```

| API                                      | Fonctionnement                                      |
| ---------------------------------------- | --------------------------------------------------- |
| `copy(items?)` / `setItems(items)`       | Copie la collection ou remplace tous les éléments.  |
| `update(value, item)`                    | Remplace un élément existant.                       |
| `upsert(value, item, mode?)`             | Met à jour un élément ou l'ajoute à une extrémité.  |
| `insert(index, ...items)`                | Insère des éléments à un index.                     |
| `insertBefore` / `insertAfter`           | Insère des éléments autour d'une valeur.            |
| `prepend` / `append`                     | Ajoute des éléments au début ou à la fin.           |
| `filter(predicate)` / `remove(...)`      | Garde les éléments correspondants ou supprime des éléments et des valeurs. |
| `move` / `moveBefore` / `moveAfter`       | Déplace une ou plusieurs valeurs.                   |
| `reorder(from, to)`                      | Déplace un élément entre deux index numériques.     |

`upsert` accepte `mode: 'append' | 'prepend'` lorsque la valeur n'existe pas. La collection d'origine
reste inchangée.

## Intégration et accessibilité

Utilisez `Select`, `Combobox` ou `Listbox` lorsque vous avez besoin de leur sélection, gestion du
focus, navigation au clavier et comportement ARIA intégrés. La collection ne fournit que les
données. Pour une interface personnalisée, implémentez dans la couche UI le nom accessible, les
interactions au clavier, les rôles, les états et les messages pour les éléments vides ou désactivés.
