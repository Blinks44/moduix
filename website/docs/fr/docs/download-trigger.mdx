## Fonctionnement

`DownloadTrigger` est un utilitaire Ark UI qui affiche par défaut un bouton natif et lance le téléchargement lorsque
l’utilisateur l’active. La prop `data` accepte le contenu du fichier : une chaîne, un `Blob`, un `File` ou une fonction
qui renvoie l’une de ces valeurs directement ou via une promesse. Une chaîne est traitée comme le
contenu du fichier, et non comme une URL à récupérer. Pour télécharger une ressource distante, récupérez-la dans votre
application et renvoyez `await response.blob()` depuis la fonction passée à `data`.

Importez cet utilitaire générique directement depuis Ark UI. Il n’est pas réexporté par `@moduix/react` :

```tsx
import { DownloadTrigger } from '@ark-ui/react/download-trigger';
```

## Générer les données à la demande

Passez une fonction lorsque le fichier doit être créé avant le téléchargement. Ark l’appelle après l’activation du
déclencheur. Si elle renvoie une promesse, Ark attend sa résolution avant d’enregistrer le fichier.


`DownloadTrigger` n’expose ni état de chargement ni gestionnaire d’erreur. Si la génération peut prendre du temps, suivez
son état dans votre application et gérez les erreurs dans la fonction passée à `data`. Désactivez ou remplacez le
déclencheur pendant l’opération.

## Choisir les métadonnées du fichier

Faites correspondre l’extension de `fileName` au contenu et indiquez le type MIME associé avec `mimeType`, par exemple
`application/json`, `text/csv`, `image/svg+xml` ou `application/pdf`. Si vous renvoyez un `Blob` ou un `File`, gardez
également sa propriété `type` cohérente avec `mimeType`.

## Utilisation avec moduix

`DownloadTrigger` n’applique aucun style. Composez-le avec `asChild` et un `Button` moduix pour que l’action s’intègre
au reste de l’interface. Pour télécharger une image produite par le composant moduix `QrCode`, consultez la page
[`QrCode`](/docs/qr-code) et utilisez `QrCode.DownloadTrigger`. Il récupère l’image auprès du QR code parent et
l’exporte pour vous.

## Ce qui vient d’Ark UI

Ark UI fournit le comportement générique de téléchargement ainsi que l’API `data`, `fileName` et `mimeType`. moduix
montre comment associer cet utilitaire à ses composants, mais ne fournit pas d’export générique `DownloadTrigger` et
n’ajoute aucun style au composant Ark.
