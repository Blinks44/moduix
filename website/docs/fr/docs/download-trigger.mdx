Utilisez `DownloadTrigger` d’Ark UI pour transformer des données de fichier en téléchargement dans le navigateur.
Associez-le à un `Button` moduix lorsque l’action doit s’intégrer au reste de votre interface.

`DownloadTrigger` n’expose ni état de chargement ni gestionnaire d’erreur. Si la génération prend du temps, gérez cet
état dans votre application, désactivez ou remplacez le déclencheur pendant l’opération et traitez les erreurs dans la
fonction passée à `data`. Pour télécharger une ressource distante, récupérez-la dans votre application et renvoyez
`response.blob()`. Une chaîne est traitée comme le contenu du fichier, et non comme une URL.

## Métadonnées du fichier

Faites correspondre l’extension de `fileName` au contenu et définissez le `mimeType` associé, par exemple
`application/json`, `text/csv`, `image/svg+xml` ou `application/pdf`. Si vous renvoyez un `Blob` ou un `File`, veillez
également à ce que sa propriété `type` corresponde au type MIME demandé.

## Composition

Par défaut, `DownloadTrigger` rend un bouton natif. Utilisez `asChild` lorsqu’un `Button` moduix doit posséder l’élément
bouton et ses états. React utilise une prop `asChild` booléenne avec un élément enfant ; Solid utilise une prop `asChild`
sous forme de fonction de rendu. Dans les deux cas, le DOM contient un seul bouton accessible.

Pour les images QR, utilisez `QrCode.DownloadTrigger` sur la page [QrCode](/docs/qr-code). Il récupère l’image du QR code
le plus proche et l’exporte avec les métadonnées de fichier requises.
