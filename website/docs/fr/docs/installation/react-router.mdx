# React Router

Cette page concerne React Router en mode Framework. Si votre application utilise déjà ce mode, ajoutez moduix en
suivant les étapes ci-dessous. Pour les modes Data ou Declarative, suivez la [configuration Vite](/docs/installation/vite) : les imports moduix restent identiques.

## Installer le paquet

<PackageManagerTabs command="install @moduix/react @ark-ui/react" />

En mode Framework, React Router rend les modules de route dans `app/root.tsx`. Importez-y une seule fois la feuille de
style de base :

```tsx title="app/root.tsx"
import '@moduix/react/style.css';
```

Déclarez la route dans `app/routes.ts` :

```tsx title="app/routes.ts"
import { type RouteConfig, index } from '@react-router/dev/routes';

export default [index('routes/home.tsx')] satisfies RouteConfig;
```

Utilisez un composant moduix dans le module de route :

```tsx title="app/routes/home.tsx"
import { Button } from '@moduix/react/button';

export default function Home() {
  return <Button>Continue</Button>;
}
```

La route d’index est accessible à l’adresse `/`. Ouvrez cette adresse après avoir lancé le serveur de développement.

## Installer avec la CLI shadcn

Choisissez cette méthode si vous voulez conserver le code source et les styles des composants dans votre dépôt.
Commencez par suivre la [configuration de la CLI shadcn](/docs/quick-start#installer-avec-la-cli-shadcn). Le modèle
React Router standard place le code de l’application dans `app`. Associez donc `@/*` à `app/*`, et non à `src/*` :

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./app/*"]
    }
  }
}
```

Le mode Framework utilise Vite. Rendez le même alias disponible pour le bundler en suivant la [configuration Vite](/docs/installation/vite#installer-avec-la-cli-shadcn) et en remplaçant `./src` par `./app`. Conservez le plugin React Router et les autres réglages Vite déjà présents dans votre projet.

Après la génération des fichiers, remplacez l’import de la feuille de style du paquet dans `app/root.tsx` par celui de
la feuille générée :

```tsx title="app/root.tsx"
import '@/lib/moduix/styles/style.css';
```

N’importez pas les deux feuilles de style. Avec cette méthode, la feuille générée fournit les styles de base.

## Vérifier

Lancez le serveur de développement et ouvrez `/`. La page doit être rendue côté serveur, s’hydrater sans divergence et
conserver le fonctionnement des composants interactifs après l’hydratation. Pendant le rendu, ne faites pas dépendre le
balisage des objets globaux du navigateur.

Consultez le [guide d’installation de React Router](https://reactrouter.com/start/framework/installation) et le
[guide du routage](https://reactrouter.com/start/framework/routing) pour la configuration complète du framework.
