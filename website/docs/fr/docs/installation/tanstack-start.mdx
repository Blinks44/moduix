# TanStack Start

Cette page suppose que vous disposez déjà d’une application TanStack Start. TanStack Start rend l’arbre des routes
côté serveur, puis l’hydrate dans le navigateur. moduix fonctionne avec Vite comme avec Rsbuild. Dans la configuration
standard, la directive `use client` n’est pas nécessaire.

## Installer comme paquet

<PackageManagerTabs command="install @moduix/react @ark-ui/react" />

Importez une seule fois la feuille de style de base dans la route racine. Dans un projet TanStack Start standard, cette
route se trouve dans `src/routes/__root.tsx` :

```tsx title="src/routes/__root.tsx"
import '@moduix/react/style.css';
```

Utilisez un composant moduix dans une route :

```tsx title="src/routes/index.tsx"
import { createFileRoute } from '@tanstack/react-router';
import { Button } from '@moduix/react/button';

export const Route = createFileRoute('/')({
  component: Home,
});

function Home() {
  return <Button>Continue</Button>;
}
```

## Installer avec la CLI shadcn

Choisissez cette méthode si vous voulez conserver le code source et les styles des composants dans votre dépôt.
Commencez par suivre la [configuration de la CLI shadcn](/docs/quick-start#installer-avec-la-cli-shadcn).

TanStack Start ne configure pas d’alias de chemins par défaut. Si votre starter associe déjà `@/*` à `src/*`,
conservez cet alias. Sinon, ajoutez-le au fichier `tsconfig.json` à la racine du projet :

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Configurez ensuite le même alias pour votre bundler. Pour Vite, consultez le [guide TanStack Start sur les alias de chemins](https://tanstack.com/start/latest/docs/framework/react/guide/path-aliases).
Rsbuild lit automatiquement le champ `paths` du `tsconfig.json` racine.

Remplacez l’import de la feuille de style du paquet dans la route racine par la feuille de style générée. N’importez pas
les deux feuilles :

```tsx title="src/routes/__root.tsx"
import '@/lib/moduix/styles/style.css';
```

## Vérifier l’intégration

Lancez le serveur de développement et ouvrez `/`. L’intégration fonctionne lorsque les styles moduix sont appliqués dès
le rendu côté serveur, que la page s’hydrate sans divergence et que le bouton réagit aux clics. Évitez d’utiliser des API
du navigateur ou des valeurs susceptibles de différer entre le serveur et le navigateur dans le code exécuté lors du
rendu serveur.

Pour la configuration complète de TanStack Start, consultez les guides [Getting Started](https://tanstack.com/start/latest/docs/framework/react/getting-started)
et [Build from Scratch](https://tanstack.com/start/latest/docs/framework/react/build-from-scratch).
