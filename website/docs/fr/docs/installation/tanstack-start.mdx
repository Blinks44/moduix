# TanStack Start

Ce guide part d’une application TanStack Start existante, configurée pour React ou Solid. Start peut
utiliser Vite ou Rsbuild, rend l’arbre des routes côté serveur, puis l’hydrate dans le navigateur ;
dans une configuration standard, moduix ne nécessite pas de directive `use client`.

## Choisir votre configuration

- **Framework :** React ou Solid avec l’adaptateur TanStack Start correspondant.
- **Styles :** CSS Modules ou Tailwind CSS v4.
- **Distribution :** paquet ou code source copié avec la CLI shadcn.

Commencez par la [configuration du paquet](/docs/quick-start#installer-le-paquet) ou la
[configuration shadcn](/docs/quick-start#installer-avec-la-cli-shadcn) commune à votre approche de
style. Les exemples utilisent les imports des paquets CSS Modules ; l’emplacement de la route racine,
les alias, le SSR et les vérifications d’hydratation restent identiques avec le paquet ou le registre
Tailwind correspondant.

La configuration du paquet ci-dessous utilise CSS Modules et inclut la réinitialisation de moduix. Si vous
utilisez plutôt les commandes du registre Tailwind, conservez la feuille de styles globale configurée dans le
[Démarrage rapide](/docs/quick-start#installer-le-paquet).

<Tabs groupId="framework">
  <Tab label="React" value="react">

```tsx title="src/routes/__root.tsx"

```

  </Tab>
  <Tab label="Solid" value="solid">

```tsx title="src/routes/__root.tsx"

import '@moduix/solid/style.css';
```

  </Tab>
</Tabs>

Utilisez ensuite un composant dans une route :

<Tabs groupId="framework">
  <Tab label="React" value="react">

```tsx title="src/routes/index.tsx"
import { createFileRoute } from '@tanstack/react-router';
import { Button } from '@moduix/react/button';

export const Route = createFileRoute('/')({
  component: Home,
});

function Home() {
  return <Button>Continue</Button>;
}
```

  </Tab>
  <Tab label="Solid" value="solid">

```tsx title="src/routes/index.tsx"

import { Button } from '@moduix/solid/button';

export const Route = createFileRoute('/')({
  component: Home,

  return <Button>Continue</Button>;
}
```

</Tabs>

## Installation avec la CLI shadcn

Effectuez la [configuration initiale de la CLI shadcn](/docs/quick-start#installer-avec-la-cli-shadcn).
Si le projet ne fait pas déjà pointer `@/*` vers `src/*`, ajoutez cet alias au fichier
`tsconfig.json` racine :

```json title="tsconfig.json"
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Le même alias doit être accessible au bundler. Rsbuild reprend directement les chemins TypeScript ;
avec Vite, suivez le guide de TanStack Start consacré aux alias de chemins pour
[React](https://tanstack.com/start/latest/docs/framework/react/guide/path-aliases) ou
[Solid](https://tanstack.com/start/latest/docs/framework/solid/guide/path-aliases). Ajoutez ensuite le
composant :

<Tabs groupId="framework">
  <Tab label="React" value="react">

<ShadcnInstallOptions options={[{ label: 'CSS Modules', command: 'shadcn@latest add @moduix-react/button' }, { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-react-tailwind/button' }]} />

  </Tab>
  <Tab label="Solid" value="solid">

<ShadcnInstallOptions options={[{ label: 'CSS Modules', command: 'shadcn@latest add @moduix-solid/button' }, { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-solid-tailwind/button' }]} />

  </Tab>
</Tabs>

Dans la route racine, remplacez la feuille de styles du paquet par le fichier généré :

```tsx title="src/routes/__root.tsx"
import '@/lib/moduix/styles/style.css';
```

## Vérification

Démarrez le serveur de développement et ouvrez `/`. La page rendue côté serveur doit déjà inclure les
styles moduix, puis s’hydrater sans divergence. Évitez dans le rendu serveur les API réservées au
navigateur et les valeurs susceptibles de différer entre le serveur et le client.

Poursuivez avec les guides officiels de TanStack Start pour
[React](https://tanstack.com/start/latest/docs/framework/react/getting-started) ou
[Solid](https://tanstack.com/start/latest/docs/framework/solid/getting-started).
