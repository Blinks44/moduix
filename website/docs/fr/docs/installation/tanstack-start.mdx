# TanStack Start

Les exemples ci-dessous utilisent les paquets CSS Modules, qui proposent le catalogue complet. Pour
un composant disponible avec Tailwind, suivez la [configuration du paquet Tailwind](/docs/quick-start#configurer-le-paquet-tailwind)
et choisissez le paquet ou le registre React ou Solid correspondant.

TanStack Start propose des environnements natifs pour React et Solid et fonctionne avec Vite ou
Rsbuild. L’arbre des routes est rendu côté serveur, puis hydraté dans le navigateur ; dans une
configuration standard, moduix ne nécessite pas de directive `use client`.

## Installer le paquet

Installez le paquet qui correspond au framework de votre application :

<PackageManagerTabs command="install @moduix/solid @ark-ui/solid solid-js" />

Importez une seule fois la feuille de styles de base depuis `src/routes/__root.tsx` :

<Tabs groupId="framework">
  <Tab label="React" value="react">

```tsx title="src/routes/__root.tsx"
import '@moduix/react/style.css';
```

  </Tab>
  <Tab label="Solid" value="solid">

```tsx title="src/routes/__root.tsx"
import '@moduix/solid/style.css';
```

  </Tab>
</Tabs>

Utilisez ensuite un composant dans une route :

<Tabs groupId="framework">
  <Tab label="React" value="react">

```tsx title="src/routes/index.tsx"
import { createFileRoute } from '@tanstack/react-router';
import { Button } from '@moduix/react/button';

export const Route = createFileRoute('/')({
  component: Home,
});

function Home() {
  return <Button>Continue</Button>;
}
```

  </Tab>
  <Tab label="Solid" value="solid">

```tsx title="src/routes/index.tsx"
import { createFileRoute } from '@tanstack/solid-router';
import { Button } from '@moduix/solid/button';

export const Route = createFileRoute('/')({
  component: Home,
});

function Home() {
  return <Button>Continue</Button>;
}
```

  </Tab>
</Tabs>

## Installer avec la CLI shadcn

Effectuez la [configuration initiale de la CLI shadcn](/docs/quick-start#installation-avec-la-cli-shadcn).
Si le projet ne fait pas déjà pointer `@/*` vers `src/*`, ajoutez cet alias au fichier
`tsconfig.json` racine :

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Le même alias doit être accessible au bundler. Rsbuild reprend directement les chemins TypeScript ;
avec Vite, suivez le guide de TanStack Start consacré aux alias. Ajoutez ensuite le composant :

<Tabs groupId="framework">
  <Tab label="React" value="react">

<PackageManagerTabs command="shadcn@latest add @moduix-react/button" dlx />

  </Tab>
  <Tab label="Solid" value="solid">

<PackageManagerTabs command="shadcn@latest add @moduix-solid/button" dlx />

  </Tab>
</Tabs>

Dans la route racine, remplacez la feuille de styles du paquet par le fichier généré :

```tsx title="src/routes/__root.tsx"
import '@/lib/moduix/styles/style.css';
```

## Vérifier l’installation

Démarrez le serveur de développement et ouvrez `/`. La page rendue côté serveur doit déjà inclure les
styles moduix, puis s’hydrater sans divergence. Évitez dans le rendu serveur les API réservées au
navigateur et les valeurs susceptibles de différer entre le serveur et le client.

Poursuivez avec les guides officiels de TanStack Start pour
[React](https://tanstack.com/start/latest/docs/framework/react/getting-started) ou
[Solid](https://tanstack.com/start/latest/docs/framework/solid/getting-started).
