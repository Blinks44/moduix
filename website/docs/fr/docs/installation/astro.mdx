# Astro

Ce guide part d’un projet Astro existant dans lequel l’intégration officielle de React, Solid ou Vue
est déjà configurée. Par défaut, Astro produit du HTML statique ; ajoutez une directive `client:*`
lorsqu’un composant doit devenir interactif dans le navigateur.

## Choisir votre configuration

- **Framework :** React, Solid ou Vue avec l’intégration Astro officielle correspondante.
- **Styles :** CSS Modules ou Tailwind CSS v4.
- **Distribution :** paquet ou code source copié avec la CLI shadcn.

Le guide de démarrage rapide détaille le [choix du paquet](/docs/quick-start#installer-le-paquet) et
la [configuration shadcn](/docs/quick-start#installer-avec-la-cli-shadcn).

Les exemples ci-dessous utilisent CSS Modules et la réinitialisation moduix. Omettez cette dernière
si l’application possède déjà un équivalent. Pour Tailwind, installez le paquet correspondant avec
le suffixe `-tailwind` et importez la feuille de styles Tailwind de l’application au même point
d’entrée, après l’avoir configurée selon le guide de démarrage rapide.

Installez le paquet adapté au framework ainsi que la dépendance Ark UI correspondante :

Importez une seule fois la feuille de styles de base dans une mise en page partagée :

```astro title="src/layouts/Layout.astro"
import '@moduix/react/reset.css';
import '@moduix/react/style.css';

  <body><slot /></body>
</html>
```

  </Tab>
  <Tab label="Solid" value="solid">

```astro title="src/layouts/Layout.astro"

import '@moduix/solid/reset.css';

---

<html lang="en">
  <body><slot /></body>
</html>
```

  </Tab>
  <Tab label="Vue" value="vue">

```astro title="src/layouts/Layout.astro"

import '@moduix/vue/reset.css';

<html lang="en">
```

  </Tab>

Créez ensuite un composant dans le framework choisi :

<Tabs groupId="framework">
  <Tab label="React" value="react">

```tsx title="src/components/ContinueButton.tsx"
import { Button } from '@moduix/react/button';

export function ContinueButton() {
  return <Button>Continue</Button>;
}
```

  </Tab>
  <Tab label="Solid" value="solid">

```tsx title="src/components/ContinueButton.tsx"
import { Button } from '@moduix/solid/button';

export function ContinueButton() {
  return <Button>Continue</Button>;
}
```

  </Tab>
  <Tab label="Vue" value="vue">

```vue title="src/components/ContinueButton.vue"
<script setup lang="ts">
import { Button } from '@moduix/vue/button';
</script>

<template>
  <Button>Continue</Button>
</template>
```

  </Tab>
</Tabs>

Importez-le directement dans une page Astro et ajoutez une directive client :

<Tabs groupId="framework">
  <Tab label="React / Solid" value="react-solid">

```astro title="src/pages/index.astro"
---
import Layout from '../layouts/Layout.astro';
import { ContinueButton } from '../components/ContinueButton';
---

<Layout>
  <ContinueButton client:load />
</Layout>
```

  </Tab>
  <Tab label="Vue" value="vue">

```astro title="src/pages/index.astro"
---
import Layout from '../layouts/Layout.astro';
import ContinueButton from '../components/ContinueButton.vue';
---

<Layout>
  <ContinueButton client:load />
</Layout>
```

  </Tab>
</Tabs>

Sans directive `client:*`, Astro envoie du HTML statique sans le JavaScript client du composant.
Utilisez `client:load` pour un contrôle visible immédiatement, `client:idle` si l’interaction peut
attendre et `client:visible` pour un composant situé plus bas dans la page. Les composants interactifs
comme `Dialog`, `Menu` et `Select` ont besoin d’une directive client.

## Installation avec la CLI shadcn

Effectuez la [configuration initiale de la CLI shadcn](/docs/quick-start#installer-avec-la-cli-shadcn),
faites pointer `@/*` vers `src/*` dans `tsconfig.json`, puis ajoutez le composant adapté au framework :

<Tabs groupId="framework">
  <Tab label="React" value="react">

<ShadcnInstallOptions options={[{ label: 'CSS Modules', command: 'shadcn@latest add @moduix-react/button' }, { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-react-tailwind/button' }]} />

  </Tab>
  <Tab label="Solid" value="solid">

<ShadcnInstallOptions options={[{ label: 'CSS Modules', command: 'shadcn@latest add @moduix-solid/button' }, { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-solid-tailwind/button' }]} />

  </Tab>
  <Tab label="Vue" value="vue">

<ShadcnInstallOptions options={[{ label: 'CSS Modules', command: 'shadcn@latest add @moduix-vue/button' }, { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-vue-tailwind/button' }]} />

  </Tab>
</Tabs>

Pour CSS Modules, importez `@/lib/moduix/styles/style.css` depuis `src/layouts/Layout.astro`
et configurez la réinitialisation selon le guide de démarrage rapide. Pour Tailwind, chargez les
styles de base générés dans la feuille Tailwind et importez cette feuille depuis le layout. Dans le
composant de votre framework, remplacez l’import de Button par `@/components/ui/button` ; gardez
ce composant directement importé dans la page Astro.

## Vérification

La page doit contenir du HTML rendu côté serveur et déjà mis en forme, puis le composant doit réagir
une fois la directive client exécutée.

Consultez le guide Astro sur les [composants de framework](https://docs.astro.build/en/guides/framework-components/),
ainsi que les intégrations officielles pour [React](https://docs.astro.build/en/guides/integrations-guide/react/)
et [Solid](https://docs.astro.build/en/guides/integrations-guide/solid-js/) / [Vue](https://docs.astro.build/en/guides/integrations-guide/vue/).
