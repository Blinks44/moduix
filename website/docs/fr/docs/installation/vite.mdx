# Vite

Ce guide part du principe que vous disposez déjà d’une application créée à partir du modèle React ou React + TypeScript
de Vite. Pour démarrer un nouveau projet, consultez d’abord le [guide de démarrage de Vite](https://vite.dev/guide/).

## Installer moduix en tant que paquet

<PackageManagerTabs command="install @moduix/react @ark-ui/react" />

Importez une seule fois la feuille de style de base depuis `src/main.tsx` :

```tsx title="src/main.tsx"
import '@moduix/react/style.css';
```

Importez ensuite les composants depuis leurs sous-chemins de paquet :

```tsx title="src/App.tsx"
import { Button } from '@moduix/react/button';

export function App() {
  return <Button>Continue</Button>;
}
```

## Installer avec la CLI shadcn

Terminez la [configuration de la CLI shadcn](/docs/quick-start#installer-avec-la-cli-shadcn), puis définissez l’alias
`@/*` vers `src/*`. Dans le modèle TypeScript de Vite, la configuration est répartie entre `tsconfig.json` et
`tsconfig.app.json`. Ajoutez l’alias dans les deux fichiers et configurez le même alias pour Vite dans
`vite.config.ts`.

Ajoutez ces propriétés à l’objet `compilerOptions` existant dans `tsconfig.json` :

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Ajoutez les mêmes propriétés à `compilerOptions` dans `tsconfig.app.json` :

```json title="tsconfig.app.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Ajoutez ensuite l’alias correspondant dans `vite.config.ts`. Vite attend un chemin absolu pour la cible de l’alias :
dans cet exemple, `@` pointe donc vers le répertoire `src` de l’application.

Cette configuration importe `node:url`. Si votre projet ne contient pas encore les types Node.js, ajoutez-les comme
dépendance de développement :

<PackageManagerTabs command="install -D @types/node" />

```ts title="vite.config.ts"
import { fileURLToPath, URL } from 'node:url';
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';

export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url)),
    },
  },
});
```

Une fois l’alias configuré, ajoutez un composant depuis le registre moduix :

<PackageManagerTabs command="shadcn@latest add @moduix-react/button" dlx />

Dans `src/main.tsx`, remplacez la feuille de style du paquet par la feuille générée. N’importez pas les deux :

```tsx title="src/main.tsx"
import '@/lib/moduix/styles/style.css';
```

Importez le composant généré depuis les sources de votre application :

```tsx title="src/App.tsx"
import { Button } from '@/components/moduix/button';

export function App() {
  return <Button>Continue</Button>;
}
```

## Vérifier la configuration

Lancez le serveur de développement Vite. Avec l’installation du paquet, le bouton importé depuis
`@moduix/react/button` doit s’afficher avec les styles moduix. Avec la CLI shadcn, l’éditeur et la compilation doivent
résoudre sans erreur la feuille de style générée et le composant importé depuis `@/components/moduix/button`.

Consultez le [guide Vite](https://vite.dev/guide/) pour la configuration complète du framework.
