# Vite

Ce guide part d’une application existante, créée avec un modèle Vite pour React, React + TypeScript,
Solid ou Solid + TypeScript.

## Choisir votre configuration

- **Framework :** React ou Solid avec le plugin Vite correspondant.
- **Styles :** CSS Modules ou Tailwind CSS v4.
- **Distribution :** paquet ou code source copié avec la CLI shadcn.

Commencez par la [configuration du paquet](/docs/quick-start#installer-le-paquet) ou la
[configuration shadcn](/docs/quick-start#installer-avec-la-cli-shadcn) commune à votre approche de
style. Les exemples utilisent les imports des paquets CSS Modules ; les points d’entrée Vite et la
configuration des alias restent identiques avec le paquet ou le registre Tailwind correspondant.

Toutes les commandes de paquet et tous les imports de feuilles de style présentés ci-dessous concernent
CSS Modules. Utilisez la réinitialisation de moduix présentée ci-dessous ou une réinitialisation correcte de votre application.
Avec Tailwind, conservez la feuille globale configurée dans le Démarrage rapide.

## Installation avec la CLI shadcn

Effectuez la [configuration initiale de la CLI shadcn](/docs/quick-start#installer-avec-la-cli-shadcn),
puis faites pointer `@/*` vers `src/*`. Les modèles TypeScript de Vite répartissent leur
configuration entre `tsconfig.json` et un fichier propre à l’application. Ajoutez l’alias aux deux :

```json title="tsconfig.json"
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Reprenez ces valeurs dans `compilerOptions` de `tsconfig.app.json`, puis ajoutez à Vite l’alias adapté
au framework. Comme l’exemple importe `node:url`, installez les types Node.js s’ils ne sont pas déjà
présents :

<PackageManagerTabs command="install -D @types/node" />

<Tabs groupId="framework">
  <Tab label="React" value="react">

```ts title="vite.config.ts"
import { fileURLToPath, URL } from 'node:url';
import react from '@vitejs/plugin-react';
import { defineConfig } from 'vite';

export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url)),
    },
  },
});
```

<ShadcnInstallOptions options={[{ label: 'CSS Modules', command: 'shadcn@latest add @moduix-react/button' }, { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-react-tailwind/button' }]} />

  </Tab>

```ts title="vite.config.ts"
import { fileURLToPath, URL } from 'node:url';
```

## Vérification

Démarrez Vite. Avec le paquet, le composant importé depuis le paquet moduix choisi doit être mis en
forme. Avec shadcn, la feuille de styles générée et l’import `@/components/ui/button` doivent être
résolus dans l’éditeur comme pendant la compilation.

Consultez le [guide officiel de Vite](https://vite.dev/guide/) pour créer un projet et choisir un modèle.
