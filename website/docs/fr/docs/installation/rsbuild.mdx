# Rsbuild

Ce guide part du principe que vous disposez déjà d’une application React construite avec Rsbuild. Si vous partez de
zéro, suivez d’abord le [démarrage rapide de Rsbuild](https://rsbuild.rs/guide/start/quick-start). Rsbuild prend
automatiquement en compte les alias de chemins TypeScript. Avec la CLI shadcn, vous n’avez donc pas besoin de
dupliquer cet alias dans `resolve.alias`.

## Installer le paquet

<PackageManagerTabs command="install @moduix/react @ark-ui/react" />

Importez la feuille de style commune une seule fois depuis le point d’entrée de l’application :

```tsx title="src/index.tsx"
import '@moduix/react/style.css';
```

Importez ensuite chaque composant depuis le sous-chemin correspondant du paquet :

```tsx title="src/App.tsx"
import { Button } from '@moduix/react/button';

export function App() {
  return <Button>Continue</Button>;
}
```

## Installer avec la CLI shadcn

Suivez d’abord la [configuration de la CLI shadcn](/docs/quick-start#installer-avec-la-cli-shadcn), puis ajoutez
l’alias de chemin `@/*` dans `tsconfig.json` :

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Rsbuild lit automatiquement `compilerOptions.paths` ; il est donc inutile de recopier cet alias dans `resolve.alias`
de `rsbuild.config.ts`. Remplacez l’import de la feuille de style du paquet par la feuille générée ci-dessous.
N’importez pas les deux feuilles en même temps :

```tsx title="src/index.tsx"
import '@/lib/moduix/styles/style.css';
```

## Vérifier

Lancez le serveur de développement Rsbuild. L’intégration fonctionne lorsque le composant s’affiche avec les styles
moduix et que TypeScript comme Rsbuild résolvent correctement `@/components/moduix/*`.

Pour obtenir la configuration complète de Rsbuild, notamment pour créer une application React, consultez le [démarrage rapide de
Rsbuild](https://rsbuild.rs/guide/start/quick-start) et le [guide React](https://rsbuild.rs/guide/framework/react).
