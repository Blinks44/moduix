# Rsbuild

Ce guide part d’une application Rsbuild déjà configurée pour React, Solid ou Vue. Rsbuild prend en compte
les alias TypeScript, il est donc inutile de les répéter dans `resolve.alias` pour utiliser shadcn.

## Choisir votre configuration

- **Framework :** React, Solid ou Vue avec le plugin Rsbuild correspondant.
- **Styles :** CSS Modules ou Tailwind CSS v4.
- **Distribution :** paquet ou code source copié avec la CLI shadcn.

Le guide de démarrage rapide détaille le [choix du paquet](/docs/quick-start#installer-le-paquet) et
la [configuration shadcn](/docs/quick-start#installer-avec-la-cli-shadcn).

Les exemples ci-dessous utilisent CSS Modules et la réinitialisation moduix. Omettez cette dernière
si l’application possède déjà un équivalent. Pour Tailwind, installez le paquet correspondant avec
le suffixe `-tailwind` et importez la feuille de styles Tailwind de l’application au même point
d’entrée, après l’avoir configurée selon le guide de démarrage rapide.

## Installation avec la CLI shadcn

Commencez par la [configuration de la CLI shadcn](/docs/quick-start#installer-avec-la-cli-shadcn),
puis faites pointer `@/*` vers `src/*` dans `tsconfig.json` :

```json title="tsconfig.json"
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Rsbuild lit automatiquement `compilerOptions.paths`. Ajoutez ensuite le composant adapté au
framework :

  <Tab label="Vue" value="vue">

<ShadcnInstallOptions options={[{ label: 'CSS Modules', command: 'shadcn@latest add @moduix-vue/button' }, { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-vue-tailwind/button' }]} />

  </Tab>
</Tabs>

Remplacez l’import de la feuille de styles du paquet par celui du fichier généré ; n’importez pas les
deux :

```tsx title="src/index.tsx"
import '@/lib/moduix/styles/style.css';
```

L’import de styles ci-dessus concerne CSS Modules. Pour Tailwind, chargez les styles de base générés
dans votre feuille Tailwind existante selon le [guide de démarrage rapide](/docs/quick-start#installer-avec-la-cli-shadcn),
puis importez cette feuille au même point d’entrée. Remplacez l’import du composant depuis le paquet
par `@/components/ui/button`.

## Vérification

Démarrez le serveur de développement. Le composant moduix doit être mis en forme, et TypeScript comme
Rsbuild doivent résoudre `@/components/ui/*` après une installation depuis le registre.

Consultez le guide Rsbuild pour [React](https://rsbuild.rs/guide/framework/react) ou la documentation
officielle du [plugin Solid](https://rsbuild.rs/plugins/list/plugin-solid), [Vue](https://rsbuild.rs/guide/framework/vue).
