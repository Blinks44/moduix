# Rsbuild

Ce guide part d’une application Rsbuild déjà configurée pour React ou Solid. Rsbuild prend en compte
les alias TypeScript, il est donc inutile de les répéter dans `resolve.alias` pour utiliser shadcn.

## Choisir votre configuration

- **Framework :** React ou Solid avec le plugin Rsbuild correspondant.
- **Styles :** CSS Modules ou Tailwind CSS v4.
- **Distribution :** paquet ou code source copié avec la CLI shadcn.

Commencez par la [configuration du paquet](/docs/quick-start#installer-le-paquet) ou la
[configuration shadcn](/docs/quick-start#installer-avec-la-cli-shadcn) commune à votre approche de
style. Les exemples utilisent les imports des paquets CSS Modules ; les points d’entrée Rsbuild et la
gestion des alias TypeScript restent identiques avec le paquet ou le registre Tailwind correspondant.

Toutes les commandes de paquet et tous les imports de feuilles de style présentés ci-dessous concernent
CSS Modules. Utilisez la réinitialisation de moduix présentée ci-dessous ou une réinitialisation correcte de votre application.
Avec Tailwind, conservez la feuille globale configurée dans le Démarrage rapide.

## Installation avec la CLI shadcn

Commencez par la [configuration de la CLI shadcn](/docs/quick-start#installer-avec-la-cli-shadcn),
puis faites pointer `@/*` vers `src/*` dans `tsconfig.json` :

```json title="tsconfig.json"
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Rsbuild lit automatiquement `compilerOptions.paths`. Ajoutez ensuite le composant adapté au
framework :

<Tabs groupId="framework">
  <Tab label="React" value="react">

<ShadcnInstallOptions options={[{ label: 'CSS Modules', command: 'shadcn@latest add @moduix-react/button' }, { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-react-tailwind/button' }]} />

  </Tab>
  <Tab label="Solid" value="solid">

<ShadcnInstallOptions options={[{ label: 'CSS Modules', command: 'shadcn@latest add @moduix-solid/button' }, { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-solid-tailwind/button' }]} />

  </Tab>
</Tabs>

Remplacez l’import de la feuille de styles du paquet par celui du fichier généré ; n’importez pas les
deux :

```tsx title="src/index.tsx"
import '@/lib/moduix/styles/style.css';
```

## Vérification

Démarrez le serveur de développement. Le composant moduix doit être mis en forme, et TypeScript comme
Rsbuild doivent résoudre `@/components/ui/*` après une installation depuis le registre.

Consultez le guide Rsbuild pour [React](https://rsbuild.rs/guide/framework/react) ou la documentation
officielle du [plugin Solid](https://rsbuild.rs/plugins/list/plugin-solid).
