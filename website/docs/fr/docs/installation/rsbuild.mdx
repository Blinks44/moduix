# Rsbuild

Les exemples ci-dessous utilisent les paquets CSS Modules, qui proposent le catalogue complet. Pour
un composant disponible avec Tailwind, suivez la [configuration du paquet Tailwind](/docs/quick-start#configurer-le-paquet-tailwind)
et choisissez le paquet ou le registre React ou Solid correspondant.

Ce guide part d’une application Rsbuild déjà configurée pour React ou Solid. Rsbuild prend en compte
les alias TypeScript, il est donc inutile de les répéter dans `resolve.alias` pour utiliser shadcn.

## Configurer le framework

  <Tab label="Solid" value="solid">

L’intégration Solid officielle de Rsbuild repose sur les plugins Solid et Babel :

<PackageManagerTabs command="install -D @rsbuild/plugin-solid @rsbuild/plugin-babel" />

```ts title="rsbuild.config.ts"
import { pluginBabel } from '@rsbuild/plugin-babel';
import { pluginSolid } from '@rsbuild/plugin-solid';
import { defineConfig } from '@rsbuild/core';

export default defineConfig({
  plugins: [
    pluginBabel({
      include: /\.(?:jsx|tsx)$/,
    }),
    pluginSolid(),
  ],
});
```

## Installer avec la CLI shadcn

Commencez par la [configuration de la CLI shadcn](/docs/quick-start#installation-avec-la-cli-shadcn),
puis faites pointer `@/*` vers `src/*` dans `tsconfig.json` :

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Rsbuild lit automatiquement `compilerOptions.paths`. Ajoutez ensuite le composant adapté au
framework :

<Tabs groupId="framework">
  <Tab label="React" value="react">

<PackageManagerTabs command="shadcn@latest add @moduix-react/button" dlx />

  </Tab>
  <Tab label="Solid" value="solid">

<PackageManagerTabs command="shadcn@latest add @moduix-solid/button" dlx />

  </Tab>
</Tabs>

Remplacez l’import de la feuille de styles du paquet par celui du fichier généré ; n’importez pas les
deux :

```tsx title="src/index.tsx"
import '@/lib/moduix/styles/style.css';
```

## Vérifier l’installation

Démarrez le serveur de développement. Le composant moduix doit être mis en forme, et TypeScript comme
Rsbuild doivent résoudre `@/components/ui/*` après une installation depuis le registre.

Consultez le guide Rsbuild pour [React](https://rsbuild.rs/guide/framework/react) ou la documentation
officielle du [plugin Solid](https://rsbuild.rs/plugins/list/plugin-solid).
