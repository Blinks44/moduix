## Choisir le bon composant

Utilisez `Checkbox` lorsque l’utilisateur peut sélectionner une ou plusieurs options indépendantes
dans un formulaire, un panneau de réglages ou une liste de filtres. Utilisez `RadioGroup` lorsqu’un
seul choix est possible, et `Switch` lorsqu’un réglage doit s’appliquer immédiatement.

## Exemple de base


Composez une case à cocher avec les parties Ark. Laissez `CheckboxControl` vide pour utiliser les
icônes intégrées de moduix pour les états coché et indéterminé. Ajoutez `CheckboxLabel` pour le
libellé visible et `CheckboxHiddenInput` pour l’interaction et le formulaire natifs.

## Anatomie

```text
Checkbox
├─ CheckboxControl
│  ├─ CheckboxIndicator
│  └─ CheckboxIndicator[indeterminate] (facultatif)
├─ CheckboxLabel
└─ CheckboxHiddenInput (explicite)

CheckboxRootProvider
└─ même arbre de parties relié à l’état fourni par useCheckbox()

CheckboxGroup
└─ Checkbox[value]
   ├─ CheckboxControl
   ├─ CheckboxLabel
   └─ CheckboxHiddenInput
```

| Partie                        | Rôle                                                                                       |
| ----------------------------- | ------------------------------------------------------------------------------------------ |
| `Checkbox`                    | Gère l’état d’une case à cocher et rend le `label` qui l’enveloppe.                        |
| `CheckboxHiddenInput`         | Champ natif d’Ark ; ajoutez-le explicitement dans la racine.                               |
| `CheckboxRootProvider`        | Relie les parties à un état Ark créé en dehors de l’arbre rendu.                           |
| `CheckboxControl`             | Partie visible ; vide, elle affiche les icônes d’état intégrées.                           |
| `CheckboxIndicator`           | Emplacement facultatif pour une icône personnalisée. Passez `indeterminate` pour cet état. |
| `CheckboxLabel`               | Libellé visible de la case à cocher.                                                       |
| `CheckboxGroup`               | Gère les valeurs sélectionnées de plusieurs cases à cocher.                                |

## Composition

`CheckboxHiddenInput` est le champ natif d’Ark. Ajoutez-le explicitement dans `Checkbox` ou
`CheckboxRootProvider`, même en dehors d’un formulaire : il assure le focus natif, les interactions
au clavier, l’accessibilité et la participation au formulaire. Pour une case seule, définissez
`name` et `value` sur la racine ; pour un groupe, définissez `name` sur `CheckboxGroup` et `value`
sur chaque `Checkbox`.

`CheckboxGroup` gère un tableau de valeurs sélectionnées, et chaque enfant est un `Checkbox`
avec son propre `value`. Laissez `CheckboxControl` vide pour utiliser les icônes intégrées de
moduix. Ajoutez `CheckboxIndicator` dans `CheckboxControl` uniquement pour une icône personnalisée.

Lorsque l’état doit être créé en dehors de l’arbre rendu, créez-le avec `useCheckbox()` et transmettez
le store à `CheckboxRootProvider`. Ne rendez pas `Checkbox` ou `CheckboxRootProvider` pour ce même store.

## Styles

Utilisez `className` dans React ou `class` dans Solid et Vue sur les parties exportées pour les styles
structurels. Pour les styles liés à l’état, préférez les attributs de données d’Ark comme `data-state`,
`data-disabled` et `data-invalid`, avec les sélecteurs `data-slot` de moduix. Les variantes Tailwind
utilisent les utilitaires natifs et les classes du consommateur ; les variables ci-dessous personnalisent
les variantes CSS Modules. Les attributs de données et les hooks `data-slot` sont communs aux deux
approches de style.

### Points d’accroche CSS

- `Checkbox` expose `data-slot="checkbox-root"`, `data-size` et les attributs d’état Ark comme `data-state`, `data-active`, `data-disabled`, `data-readonly`, `data-invalid`, `data-required`, `data-hover`, `data-focus` et `data-focus-visible`.
- `CheckboxRootProvider` expose `data-slot="checkbox-root-provider"` et le même contrat de style que la racine.
- `CheckboxControl` expose `data-slot="checkbox-control"` et les attributs d’état Ark, notamment `data-state="checked" | "indeterminate" | "unchecked"` et `data-active`.
- `CheckboxIndicator` expose `data-slot="checkbox-indicator"` et hérite des attributs d’état de Checkbox.
- `CheckboxLabel` expose `data-slot="checkbox-label"` et les attributs d’état de Checkbox.
- `CheckboxGroup` expose `data-slot="checkbox-group"`.
