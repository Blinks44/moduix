Utilisez `Checkbox` pour sélectionner une ou plusieurs options indépendantes dans les formulaires,
les réglages et les listes de filtres. Choisissez `RadioGroup` lorsqu’un seul choix est possible,
ou `Switch` lorsqu’un réglage doit s’appliquer immédiatement.

## Anatomie

```text
Checkbox.Root
├─ Checkbox.Control
│  ├─ Checkbox.Indicator
│  └─ Checkbox.Indicator[indeterminate] (optional)
├─ Checkbox.Label
└─ native input (automatic)

Checkbox.RootProvider
└─ same part tree connected to useCheckbox()

Checkbox.Group
└─ Checkbox.Root[value]
   ├─ Checkbox.Control
   ├─ Checkbox.Label
   └─ the native form input
```

| Partie                        | Rôle                                                                                                      |
| ----------------------------- | --------------------------------------------------------------------------------------------------------- |
| `Checkbox` / `Checkbox.Root`  | Gère l’état d’une case à cocher et rend le `label` qui l’enveloppe.                                      |
| `Checkbox.RootProvider`       | Relie les parties à un état Ark créé hors du sous-arbre rendu.                                           |
| `Checkbox.Control`            | La partie visible de la case à cocher. Sans enfant, elle affiche les indicateurs intégrés.               |
| `Checkbox.Indicator`          | Slot facultatif pour une icône personnalisée. Utilisez `indeterminate` pour cet état.                    |
| `Checkbox.Label`              | Le libellé visible de la case à cocher.                                                                  |
| `Checkbox.Group`              | Partage les valeurs sélectionnées entre plusieurs cases à cocher.                                        |

## Composition

### Composition recommandée

Gardez l’arborescence des parties Ark dans votre balisage. `Checkbox.Root` accepte les props habituelles du composant racine Ark, telles que
`checked`, `defaultChecked`, `onCheckedChange(details)`, `disabled`, `readOnly`, `invalid`, `required`,
`name`, `value`, `form`, `ids` et `asChild`.

`Checkbox.Group` accepte `value`, `defaultValue`, `onValueChange(value)`, `disabled`, `readOnly`,
`invalid`, `maxSelectedValues` et `name`.

`Checkbox.Control` est le raccourci pratique de moduix. Laissez-le vide pour utiliser les icônes
intégrées, ou transmettez des enfants pour créer un indicateur personnalisé. `size` est la seule
prop propre à moduix sur `Checkbox.Root` et `Checkbox.RootProvider`.

### Quand créer une composition personnalisée

Utilisez `Checkbox.RootProvider` lorsque l’état de la case à cocher est créé hors du sous-arbre rendu.
moduix réexporte `useCheckbox()` pour ce cas. `Checkbox.Context`, `useCheckboxContext()`,
`useCheckboxGroup()` et `useCheckboxGroupContext()` donnent accès à l’état Ark pour des compositions
plus avancées. Ne rendez `Checkbox.Indicator` explicitement que pour une icône personnalisée ou une
autre disposition de l’indicateur.

### Propriétés par défaut

| Élément                       | Valeur par défaut | Remarques                                                        |
| ----------------------------- | ----------------- | ---------------------------------------------------------------- |
| `Checkbox` / `Checkbox.Root` | -                 | Aucun comportement supplémentaire, les valeurs Ark s’appliquent. |
| `size`                       | `md`              | S’applique à `Checkbox.Root` et `Checkbox.RootProvider`.         |

### Comportement

Le composant racine ajoute automatiquement un champ natif, afin que la case à cocher participe à la
validation, à la réinitialisation et à l’envoi du formulaire. Pour une case à cocher seule,
transmettez `name` et `value` à `Checkbox.Root`. Pour un groupe, transmettez `name` à
`Checkbox.Group` et `value` à chaque `Checkbox.Root`.

Si vous migrez depuis shadcn, `Checkbox.Control` inclut déjà la présentation d’icône par défaut. Le
contrôle et le libellé restent explicites dans l’arborescence ; le champ masqué reste interne.

`Checkbox.Root` d’Ark rend un `label`. Avec `asChild`, son enfant direct doit aussi être un `label`
sémantique ; sans cela, la case à cocher n’a plus de libellé de formulaire valide.

Lorsque `readOnly` est défini, moduix reflète aussi cet état avec `aria-readonly` sur le champ natif
automatique, tandis qu’Ark bloque l’interaction.

La ref pointe vers la partie DOM Ark correspondante. Pour basculer une case à cocher qui a le focus,
appuyez sur <kbd>Espace</kbd>.

### Points d’accroche CSS

- `Checkbox.Root` fournit `data-slot="checkbox-root"`, `data-size` et les attributs d’état Ark tels que `data-state`, `data-disabled`, `data-readonly`, `data-invalid`, `data-required`, `data-hover`, `data-focus` et `data-focus-visible`.
- `Checkbox.RootProvider` fournit `data-slot="checkbox-root-provider"` et le même contrat de style que le composant racine.
- `Checkbox.Control` fournit `data-slot="checkbox-control"` et les attributs d’état Ark, notamment `data-state="checked" | "indeterminate" | "unchecked"`.
- `Checkbox.Indicator` fournit `data-slot="checkbox-indicator"` et hérite des attributs d’état de la case à cocher d’Ark.
- `Checkbox.Label` fournit `data-slot="checkbox-label"` et les attributs d’état de la case à cocher d’Ark.
- `Checkbox.Group` fournit `data-slot="checkbox-group"`.
