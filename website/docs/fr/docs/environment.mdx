## Quand l’utiliser

Utilisez `EnvironmentProvider` lorsqu’un composant est rendu dans un environnement DOM différent du `document`
principal de la page, par exemple dans une iframe, un Shadow DOM ou une fenêtre Electron. Ark UI s’appuie sur cet
environnement pour rechercher les éléments et leurs identifiants, gérer le focus et utiliser le bon document.

Importez le composant et son hook de contexte directement depuis Ark UI :

```tsx
import { EnvironmentProvider, useEnvironmentContext } from '@ark-ui/react/environment';
```

## Mise en place

Placez le `EnvironmentProvider` autour de la partie de l’arbre React rendue dans l’environnement personnalisé. Sans
`value`, il détecte automatiquement l’environnement dans lequel il est rendu. `useEnvironmentContext` expose des
fonctions pour obtenir cette racine ainsi que son `Document` et sa `Window`.

L’aperçu s’exécute dans le document principal de la page, qui est donc la racine détectée par `EnvironmentProvider`. Si votre
application rend son contenu dans une iframe ou un Shadow DOM, transmettez à `value` la racine qui contient ce
sous-arbre.

## Racines personnalisées

`value` accepte directement une racine ou une fonction qui en renvoie une. Utilisez la forme fonctionnelle lorsque la
racine n’est pas disponible au premier rendu, par exemple pendant le chargement d’une iframe ou avant la création du
Shadow DOM.

```tsx
import { EnvironmentProvider } from '@ark-ui/react/environment';
import { Button } from '@moduix/react/button';
import { createPortal } from 'react-dom';
import { useEffect, useRef, useState } from 'react';

export function ShadowDomSettings() {
  const hostRef = useRef<HTMLDivElement>(null);
  const [shadowRoot, setShadowRoot] = useState<ShadowRoot | null>(null);

  useEffect(() => {
    const host = hostRef.current;
    if (!host) return;
    setShadowRoot(host.shadowRoot ?? host.attachShadow({ mode: 'open' }));
  }, []);

  return (
    <>
      <div ref={hostRef} />
      {shadowRoot
        ? createPortal(
            <EnvironmentProvider value={shadowRoot}>
              <Button type="button">Save settings</Button>
            </EnvironmentProvider>,
            shadowRoot,
          )
        : null}
    </>
  );
}
```

`EnvironmentProvider` indique seulement à Ark UI quelle racine utiliser pour ses API DOM. Il ne déplace pas le contenu React dans
une iframe ou un Shadow DOM. Votre application ou la bibliothèque qui gère l’iframe contrôle toujours le point de
montage et les portails. Ce composant doit être rendu dans le même environnement que le sous-arbre qu’il configure.

## Utiliser `Frame`

Le composant `Frame` d’Ark rend ses enfants dans une iframe et fournit à Ark UI le `document` de cette iframe. Placez
les composants moduix directement dans `Frame` : il n’est pas nécessaire d’ajouter un autre `EnvironmentProvider`.

```tsx
import { Frame } from '@ark-ui/react/frame';
import { Button } from '@moduix/react/button';

export function IframeAction() {
  return (
    <Frame title="Account settings">
      <Button type="button">Save settings</Button>
    </Frame>
  );
}
```

## Utiliser moduix

Utilisez les composants moduix dans `EnvironmentProvider` comme d’habitude. Enveloppez tout le sous-arbre une seule
fois au lieu de configurer chaque composant. Dialog, Menu, Popover et les autres composants fondés sur Ark pourront
alors gérer le focus et leurs relations DOM dans la bonne racine.

`EnvironmentProvider` ne copie pas les styles dans une iframe ou un Shadow DOM. Chargez aussi les styles moduix dans cet
environnement pour que les composants conservent leur apparence.

## Qui fait quoi

`EnvironmentProvider` et `useEnvironmentContext` font partie de l’API Ark UI. moduix ne les réexporte pas. Cette page
explique comment les utiliser avec les composants moduix ; consultez la référence Ark UI pour connaître l’API complète.
