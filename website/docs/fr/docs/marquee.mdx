## Exemple de base


Utilisez la forme courte `Marquee` comme racine, puis composez explicitement `MarqueeViewport`, `MarqueeContent` et `MarqueeItem` à
l’intérieur. Si le contenu défilant transmet une information, ajoutez un libellé avec `aria-label` ou
`translations.root`. `Marquee` fournit le comportement et les styles d’animation nécessaires, mais ne définit ni le style
des éléments ni celui du cadre. Dans l’exemple, le style des éléments et la largeur de la racine sont définis séparément.

## Anatomie

```text
Marquee
├─ MarqueeEdge (facultatif)
├─ MarqueeViewport
│  └─ MarqueeContent
│     └─ MarqueeItem
└─ MarqueeEdge (facultatif)

MarqueeRootProvider
└─ même arbre de parties, relié à l’état créé par useMarquee() de moduix
```

| Partie                       | Rôle                                                                                              |
| ---------------------------- | ------------------------------------------------------------------------------------------------- |
| `Marquee`   | État du composant, libellés, identifiants, orientation, état de pause et variables CSS.            |
| `MarqueeRootProvider`       | Rend l’arbre du composant à partir de l’état renvoyé par `useMarquee()`.                           |
| `MarqueeViewport`           | Zone d’affichage qui masque ce qui dépasse du contenu défilant.                                   |
| `MarqueeContent`            | Conteneur du contenu animé. Ark le duplique si nécessaire.                                         |
| `MarqueeItem`               | Élément individuel du contenu.                                                                    |
| `MarqueeEdge`               | Dégradé facultatif qui fait disparaître le contenu au bord. `side` en choisit le côté.           |
| `MarqueeContext`            | Accès avancé au contexte du composant `Marquee` qui l’englobe.                                   |

## Composition

Utilisez `Marquee` avec les parties explicites `MarqueeViewport`, `MarqueeContent` et `MarqueeItem`. Ajoutez `MarqueeEdge` dans la même
racine lorsque le contenu doit se fondre dans l’arrière-plan de la page ; chaque bordure doit recevoir un `side`.

Utilisez `defaultPaused` pour définir l’état initial sans contrôle externe. Si une autre partie de l’application gère
la lecture, utilisez `paused` avec `onPauseChange(details)`. Pour des commandes situées en dehors de l’arbre, créez
l’état avec `useMarquee()` et transmettez-le à `MarqueeRootProvider` ; ne rendez pas `Marquee` et `MarqueeRootProvider` pour
le même état. Les commandes placées dans l’arbre peuvent lire l’API courante avec `MarqueeContext` ou
`useMarqueeContext()`.

## Exemples

### Remplissage automatique

Utilisez `autoFill` lorsque le contenu ne suffit pas à remplir la zone d’affichage. `spacing` définit l’espace entre
les copies du contenu.

<Example name="marquee/auto-fill" />

### Fondu sur les bords

Ajoutez `MarqueeEdge` sur les côtés où le contenu doit se fondre dans l’arrière-plan de la page. Cette partie est
décorative et n’intercepte pas les événements de pointeur.

<Example name="marquee/edges" />

### Boucles limitées

Définissez `loopCount` pour limiter le nombre de boucles. `onLoopComplete` est appelé après chaque boucle et
`onComplete` après la dernière.

<Example name="marquee/finite-loops" />

### Pause lors des interactions

Utilisez `pauseOnInteraction` pour mettre le composant en pause lorsque l’utilisateur le survole ou place le focus
dans son contenu.

Un marquee défile en continu : les lecteurs d’écran ne peuvent pas lire de manière fiable un contenu en mouvement et
l’animation elle-même peut être gênante. Considérez le contenu comme non essentiel : attribuez un libellé descriptif,
offrez un moyen de le mettre en pause (`pauseOnInteraction` ou des contrôles pause/reprise explicites) et ne placez
jamais d’informations critiques uniquement dans un marquee.

<Example name="marquee/pause-on-interaction" />

### Root Provider

Utilisez `useMarquee()` de moduix avec `MarqueeRootProvider` lorsque des commandes externes doivent mettre le
défilement en pause, le reprendre ou le relancer.

<Example name="marquee/programmatic-control" />

### Sens inverse

Utilisez `reverse` lorsque le contenu doit se déplacer dans le sens opposé à celui indiqué par `side`, sans modifier
l’orientation.

<Example name="marquee/reverse" />

### De droite à gauche

Placez le composant dans un `LocaleProvider` configuré avec une locale RTL. Les côtés logiques `start` et `end`
suivent alors la direction du texte.

<Example name="marquee/rtl" />

### Vitesse

Réglez le mouvement avec `speed`, exprimé en pixels par seconde. Une vitesse plus faible facilite la lecture.

<Example name="marquee/speed" />

### Orientation verticale

Définissez `side="top"` ou `side="bottom"` pour faire défiler le contenu verticalement. Par défaut, une racine
verticale mesure `15rem` de haut, ce qui donne à la zone d’affichage une hauteur stable ; définissez `height` avec une
classe pour la modifier.

<Example name="marquee/vertical" />

## Styles

Marquee inclut les images clés nécessaires à l’animation du contenu. Utilisez les attributs d’état Ark pour les styles
liés au comportement et choisissez le modèle de personnalisation de votre variante de registre :

- Variantes CSS Modules : utilisez `--moduix-marquee-edge-color` et `--moduix-marquee-edge-size` pour le fondu des
  bords, et `className` (React) ou `class` (Solid et Vue) pour les dimensions, la couleur et le style des éléments.
- Variantes Tailwind : utilisez `className` (React) ou `class` (Solid et Vue) avec des utilitaires Tailwind pour les mêmes
  aspects. Marquee n’expose aucune API de variables CSS dans les paquets Tailwind.

`Marquee` est transparent par défaut, hérite de la couleur du texte et n’ajoute ni bordure, ni arrière-plan, ni marge intérieure, ni arrondi. Si vous
avez besoin d’un conteneur avec un fond ou une bordure, définissez-le dans le CSS de votre application.

### Points d’accroche CSS

- `data-slot="marquee-root"`, `marquee-root-provider`, `marquee-viewport`, `marquee-content`, `marquee-item` et `marquee-edge`.
- Attributs Ark : `data-scope="marquee"`, `data-part="root|viewport|content|item|edge"`, `data-state="paused|idle"`, `data-orientation`, `data-side`, `data-index`, `data-paused`, `data-reverse` et `data-clone`.
- Variables CSS Ark : `--marquee-duration`, `--marquee-spacing`, `--marquee-delay`, `--marquee-loop-count` et `--marquee-translate`.
