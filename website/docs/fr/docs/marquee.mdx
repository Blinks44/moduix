## Exemple de base

Marquee est disponible pour React et Solid dans les packages CSS Modules et Tailwind. L’aperçu de cette page
utilise le package React avec CSS Modules ; les onglets de framework présentent le code natif du même contrat public.

Utilisez la forme courte `Marquee` comme racine, puis composez explicitement `Viewport`, `Content` et `Item` à
l’intérieur. Si le contenu défilant transmet une information, ajoutez un libellé avec `aria-label` ou
`translations.root`. `Marquee` fournit le comportement et les styles d’animation nécessaires, mais ne définit ni le style
des éléments ni celui du cadre. Dans l’exemple, le style des éléments et la largeur de la racine sont définis séparément.

## Anatomie

```text
Marquee / Marquee.Root
├─ Marquee.Edge (facultatif)
├─ Marquee.Viewport
│  └─ Marquee.Content
│     └─ Marquee.Item
└─ Marquee.Edge (facultatif)

Marquee.RootProvider
└─ même arbre de parties, relié à l’état créé par useMarquee() de moduix
```

| Partie                       | Rôle                                                                                              |
| ---------------------------- | ------------------------------------------------------------------------------------------------- |
| `Marquee` / `Marquee.Root`   | État du composant, libellés, identifiants, orientation, état de pause et variables CSS.            |
| `Marquee.RootProvider`       | Rend l’arbre du composant à partir de l’état renvoyé par `useMarquee()`.                           |
| `Marquee.Viewport`           | Zone d’affichage qui masque ce qui dépasse du contenu défilant.                                   |
| `Marquee.Content`            | Conteneur du contenu animé. Ark le duplique si nécessaire.                                         |
| `Marquee.Item`               | Élément individuel du contenu.                                                                    |
| `Marquee.Edge`               | Dégradé facultatif qui fait disparaître le contenu au bord. `side` en choisit le côté.           |
| `Marquee.Context`            | Accès avancé au contexte du composant `Marquee` qui l’englobe.                                   |

## Composition

Utilisez `Marquee` avec les parties explicites `Viewport`, `Content` et `Item`. Ajoutez `Marquee.Edge` dans la même
racine lorsque le contenu doit se fondre dans l’arrière-plan de la page ; chaque bordure doit recevoir un `side`.

Utilisez `defaultPaused` pour définir l’état initial sans contrôle externe. Si une autre partie de l’application gère
la lecture, utilisez `paused` avec `onPauseChange(details)`. Pour des commandes situées en dehors de l’arbre, créez
l’état avec `useMarquee()` et transmettez-le à `Marquee.RootProvider` ; ne rendez pas `Marquee` et `RootProvider` pour
le même état. Les commandes placées dans l’arbre peuvent lire l’API courante avec `Marquee.Context` ou
`useMarqueeContext()`.

## Styles

Marquee inclut les images clés nécessaires à l’animation du contenu. Utilisez `className` pour les dimensions et le
style des éléments, les variables CSS pour les dimensions, la couleur, l’espacement et le fondu des bords, et les
attributs d’état Ark pour les styles liés au comportement.

`Marquee` est transparent par défaut et n’ajoute ni bordure, ni arrière-plan, ni marge intérieure, ni arrondi. Si vous
avez besoin d’un conteneur avec un fond ou une bordure, définissez-le dans le CSS de votre application.

### Points d’accroche CSS

- `data-slot="marquee-root"`, `marquee-root-provider`, `marquee-viewport`, `marquee-content`, `marquee-item` et `marquee-edge`.
- Attributs Ark : `data-scope="marquee"`, `data-part="root|viewport|content|item|edge"`, `data-state="paused|idle"`, `data-orientation`, `data-side`, `data-index`, `data-paused`, `data-reverse` et `data-clone`.
- Variables CSS Ark : `--marquee-duration`, `--marquee-spacing`, `--marquee-delay`, `--marquee-loop-count` et `--marquee-translate`.
