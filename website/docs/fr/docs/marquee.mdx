## Anatomie

```text
Marquee / Marquee.Root
├─ Marquee.Edge
├─ Marquee.Viewport
│  └─ Marquee.Content
│     └─ Marquee.Item
└─ Marquee.Edge

Marquee.RootProvider
└─ même arbre de parties, relié à l’état créé par `useMarquee()` de moduix
```

| Partie                       | Rôle                                                                                              |
| ---------------------------- | ------------------------------------------------------------------------------------------------- |
| `Marquee` / `Marquee.Root`   | État du composant, libellés, identifiants, orientation, état de pause et variables CSS.            |
| `Marquee.RootProvider`       | Rend l’arbre du composant à partir de l’état renvoyé par `useMarquee()`.                           |
| `Marquee.Viewport`           | Zone d’affichage qui masque ce qui dépasse du contenu défilant.                                   |
| `Marquee.Content`            | Conteneur du contenu animé. Ark le clone si nécessaire.                                           |
| `Marquee.Item`               | Élément individuel du contenu.                                                                    |
| `Marquee.Edge`               | Dégradé facultatif qui fait disparaître le contenu au bord. `side` en choisit le côté.           |

## Composition

### Composition recommandée

Utilisez la forme courte `Marquee` et gardez l’arbre des parties Ark explicite. La bibliothèque fournit les images clés
de l’animation et les attributs d’état ; le style des éléments et de la racine reste à la charge du CSS de votre application.

### Quand créer une composition personnalisée

Ajoutez `Marquee.Edge` lorsque le contenu doit se fondre dans l’arrière-plan de la page. Utilisez
`useMarquee()` de moduix avec `Marquee.RootProvider` lorsque des commandes externes doivent appeler `pause()`,
`resume()`, `togglePause()` ou `restart()`. N’utilisez pas `Marquee` et `Marquee.RootProvider` avec le même objet d’état.

Utilisez `asChild` sur les parties Ark si vous devez remplacer l’élément rendu. L’élément de remplacement doit être
sémantiquement adapté et rester l’unique enfant. Utilisez `ids` lorsqu’une composition personnalisée nécessite des
identifiants stables pour la racine, la zone d’affichage ou le contenu.

### Props et callbacks

| Prop                 | Valeur par défaut | Remarques                                                                                 |
| -------------------- | ----------------- | ----------------------------------------------------------------------------------------- |
| `side`               | `start`           | Valeurs possibles : `start`, `end`, `top` et `bottom`. Les deux dernières activent l’orientation verticale. |
| `speed`              | `50`              | Vitesse en pixels par seconde. Ark calcule la durée à partir de la taille du contenu.                    |
| `spacing`            | `1rem`            | Espace entre les copies du contenu et les éléments.                                                      |
| `delay`              | `0`               | Délai avant le début de l’animation, en secondes.                                                        |
| `loopCount`          | `0`               | Nombre de boucles. `0` signifie que le défilement est infini.                                             |
| `autoFill`           | `false`           | Répète le contenu jusqu’à remplir la zone d’affichage.                                                    |
| `pauseOnInteraction` | `false`           | Met en pause au survol ou lorsque le contenu reçoit le focus. Recommandé pour le contenu à lire.         |
| `reverse`            | `false`           | Inverse le sens de l’animation sans modifier `side`.                                                      |
| `defaultPaused`      | `false`           | État de pause initial du composant non contrôlé.                                                         |
| `paused`             | -                 | État de pause contrôlé. À associer à `onPauseChange`.                                                     |
| `onPauseChange`      | -                 | Reçoit les détails Ark sur l’état de pause.                                                              |
| `onLoopComplete`     | -                 | Appelé après chaque boucle.                                                                              |
| `onComplete`         | -                 | Appelé après la dernière boucle lorsque `loopCount` limite le nombre de répétitions.                     |
| `translations`       | -                 | Libellé localisé de la racine. Utilisez-le ou fournissez `aria-label`.                                    |
| `ids`                | -                 | Identifiants stables de la racine, de la zone d’affichage et des instances de contenu.                   |
| `asChild`            | -                 | Disponible sur chaque partie Ark pour remplacer l’élément rendu.                                         |
| `Marquee.Edge side`  | -                 | Côté obligatoire : `start`, `end`, `top` ou `bottom`.                                                     |
| `RootProvider.value` | -                 | Objet `UseMarqueeReturn` obligatoire renvoyé par `useMarquee()`.                                         |

### Comportement

Utilisez `paused` avec `onPauseChange(details)` pour contrôler le défilement depuis l’état React. Utilisez
`loopCount`, `onLoopComplete` et `onComplete` lorsque le défilement doit s’arrêter après un nombre défini de boucles.
Les callbacks conservent les signatures d’origine d’Ark.

Ark expose le composant comme une région nommée et masque le contenu cloné aux technologies d’assistance. Fournissez
un `aria-label` pertinent ou `translations.root`. Activez `pauseOnInteraction` si le contenu est interactif ou doit
rester lisible, et n’utilisez pas le composant pour afficher une information critique.

Il n’y a pas de déplacement automatique du focus ni de navigation au clavier avec les flèches. Lorsque
`pauseOnInteraction` est activé, le focus met le composant en pause et sa perte relance le défilement.

Si l’utilisateur a activé la réduction des animations, moduix désactive l’animation du contenu tout en le laissant
accessible.

## Styles

Marquee s’appuie sur les images clés fournies par la bibliothèque pour animer le contenu. Personnalisez les dimensions
et l’apparence avec les variables CSS et les classes des parties, tout en conservant les attributs d’état Ark pour
styliser le comportement.

### Points de personnalisation

- `data-slot="marquee-root"`, `marquee-root-provider`, `marquee-viewport`, `marquee-content`, `marquee-item` et `marquee-edge`.
- Attributs Ark : `data-scope="marquee"`, `data-part="root|viewport|content|item|edge"`, `data-state="paused|idle"`, `data-orientation`, `data-side`, `data-index`, `data-paused`, `data-reverse` et `data-clone`.
- Variables CSS Ark : `--marquee-duration`, `--marquee-spacing`, `--marquee-delay`, `--marquee-loop-count` et `--marquee-translate`.
