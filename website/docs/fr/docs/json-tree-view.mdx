## Utilisation

<Usage />

Transmettez via `data` n’importe quelle valeur JavaScript de type JSON ou comparable, puis affichez
`<JsonTreeViewTree />` à l’intérieur du composant. `JsonTreeView` génère automatiquement les nœuds des objets, des
tableaux et des valeurs. moduix gère le style des lignes, l’indentation, les états du focus et l’icône d’ouverture
par défaut.

L’exemple ouvre d’emblée deux niveaux. Utilisez `defaultExpandedDepth` pour choisir la partie d’une réponse ou d’une
configuration à afficher au premier rendu.

## Choisir le bon composant

Utilisez `JsonTreeView` lorsque vous disposez déjà d’une valeur JavaScript à inspecter et que vous ne voulez pas
écrire de rendu récursif. Choisissez `TreeView` lorsque vous contrôlez le modèle des nœuds et devez gérer les
libellés, les icônes, les liens, le renommage ou le contenu personnalisé des branches.

## Exemples

### Aperçus compacts

Utilisez `maxPreviewItems` pour limiter les aperçus d’objets et de tableaux, et `collapseStringsAfterLength` pour
raccourcir les chaînes longues. L’utilisateur peut ouvrir un nœud pour consulter sa valeur complète.

<Example name="json-tree-view/compact-previews" />

### Rendu personnalisé des valeurs

Passez `renderValue` à `JsonTreeViewTree` pour remplacer l’affichage d’une valeur. Renvoyez `undefined`
pour garder le rendu par défaut. Dans cet exemple, les URL deviennent des liens.

## Composition

Gardez `JsonTreeViewTree` comme enfant de `JsonTreeView` ou de `JsonTreeViewRootProvider` : il affiche les nœuds JSON
générés. Lorsque des contrôles externes gèrent l’état de l’arbre, créez `useJsonTreeView` à partir du package
correspondant au framework et transmettez son état à `JsonTreeViewRootProvider`, puis affichez `JsonTreeViewTree` à l’intérieur.
Utilisez `expandedValue`, `selectedValue`, `checkedValue` ou `focusedValue` en mode contrôlé uniquement lorsque
l’état appartient à l’application. Ne rendez pas `JsonTreeView` et `JsonTreeViewRootProvider` pour le même état.

## Styles

Utilisez `className` en React, ou `class` en Solid et Vue, sur `JsonTreeView`, `JsonTreeViewRootProvider` ou `JsonTreeViewTree` pour modifier localement la
mise en page. Les variantes Tailwind utilisent des classes utilitaires et les classes de l’application ; les
variantes CSS Modules utilisent leurs styles et les tokens de base.

Lorsque `arrow` est omis, `JsonTreeViewTree` utilise le `ChevronRightIcon` fourni par moduix en React et Solid. En
Vue, fournissez votre propre icône via le slot nommé `#arrow` si la vue d’inspection utilise un autre indicateur
d’ouverture.

Les nœuds générés conservent les attributs Ark `data-scope="json-tree-view"` et `data-part`.

`JsonTreeViewTree` transmet la prop Ark `indentGuide` lorsque vous activez les guides d’indentation. moduix ne
style pas les éléments `[data-part='branch-indent-guide']` générés ; ciblez cet attribut avec vos propres styles
lorsque les guides sont activés.

En Vue, utilisez le slot nommé `#indentGuide` pour personnaliser le contenu des guides.

Le composant utilise directement les tokens de base, sans couche de variables
`--moduix-json-tree-view-*`. Ajoutez une classe ou ciblez les attributs des parties Ark lorsqu’une vue
d’inspection a besoin d’un style différent.

## Clavier

| Touche | Action |
| --- | --- |
| `ArrowDown` / `ArrowUp` | Déplace le focus vers la ligne suivante ou précédente. |
| `ArrowRight` / `ArrowLeft` | Ouvre ou ferme l’objet ou le tableau ayant le focus. |
| `Home` / `End` | Déplace le focus vers la première ou la dernière ligne. |

## Référence de l’API

| Prop | Type | Défaut | Description |
| --- | --- | --- | --- |
| `data` | `unknown` | — | Valeur JSON à afficher. |
| `defaultExpandedDepth` | `number` | — | Nombre de niveaux dépliés au départ. |
| `quotesOnKeys` | `boolean` | `false` | Entoure les clés d’objet de guillemets. |
| `maxPreviewItems` | `number` | — | Nombre d’éléments affichés dans un aperçu replié. |
| `collapseStringsAfterLength` | `number` | — | Tronque les chaînes au-delà de ce nombre de caractères. |
| `groupArraysAfterLength` | `number` | — | Regroupe les longs tableaux en plages de cette taille. |
| `showNonenumerable` | `boolean` | `false` | Affiche les propriétés non énumérables. |
