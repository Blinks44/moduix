## Référence de l’API

`Sidebar` est la mise en page moduix dédiée à la navigation d’une application. Elle associe des
parties de navigation au composant [Ark UI Splitter](https://ark-ui.com/docs/components/splitter),
qui fournit le redimensionnement, l’état replié, les interactions au clavier et l’accessibilité.
L’état et les callbacks exposés suivent le contrat de `Splitter`.

<PrimitiveReference href="https://ark-ui.com/docs/components/splitter" />

## Choisir le bon composant

- Choisissez **`Sidebar`** pour une navigation qui doit être redimensionnable, se replier en barre
  d’icônes et rester à côté du contenu principal.
- Choisissez **`Splitter`** lorsque vous avez besoin de panneaux redimensionnables génériques, plutôt
  que d’un panneau de navigation et d’une zone de contenu principale.

## Exemple de base


Composez le panneau de navigation, la poignée de redimensionnement et la zone de contenu principale
comme enfants directs de la racine. Les identifiants et contraintes par défaut conviennent à la mise
en page classique avec une barre latérale à gauche. Enveloppez les boutons de navigation réduits à
une icône dans `SidebarTooltip` pour conserver leurs libellés après le repli.

```text
│  ├─ SidebarContent
│  │  └─ SidebarGroup
│  │     ├─ SidebarGroupHeader
│  │     │  ├─ SidebarGroupLabel
│  │     │  └─ SidebarGroupAction
│  │     └─ SidebarNavigationList
│  │        └─ SidebarNavigationItem
│  │           ├─ SidebarNavigationButton
│  │           ├─ SidebarNavigationBadge (facultatif)
│  │           ├─ SidebarExpandedContent
│  │           ├─ SidebarCollapsedContent
│  │           └─ SidebarNavigationSubList
│  │              └─ SidebarNavigationSubItem

│  │                 └─ SidebarNavigationBadge (facultatif)

│     └─ SidebarSeparator

├─ SidebarTrigger
└─ SidebarInset[id="content"]
```

| Partie | Rôle |
| --- | --- |
| `Sidebar` | Racine Ark Splitter avec les réglages d’une barre à deux panneaux. |
| `SidebarPanel` | Panneau de navigation repliable, avec l’identifiant `"sidebar"` par défaut. |
| `SidebarInset` | Panneau de contenu principal, avec l’identifiant `"content"` par défaut. |
| `SidebarResizeTrigger` | Ligne de poignée accessible pour le redimensionnement à la souris ou au clavier ; elle rend par défaut le `SplitterResizeTriggerIndicator` partagé, et des enfants personnalisés le remplacent. |
| `SidebarTrigger` | Contrôle latéral pour replier ou déplier le panneau. |
| `SidebarHeader` | Zone supérieure qui ne défile pas. |
| `SidebarContent` | Zone centrale défilante. |
| `SidebarFooter` | Zone inférieure qui ne défile pas. |
| `SidebarGroup` | Section de navigation sémantique. |
| `SidebarNavigationButton` | Bouton ou lien `asChild` avec les états active et size. |
| `SidebarNavigationBadge` | Compteur facultatif placé à côté d’un bouton de navigation simple ou imbriqué. |
| `SidebarExpandedContent` | Contenu affiché lorsque le panneau est déplié. |
| `SidebarCollapsedContent` | Contenu affiché lorsque le panneau est replié. |
| `SidebarTooltip` | Aide de libellé repliée avec positionnement adapté au côté. |
| `SidebarNavigationSubList` | Liste de navigation imbriquée. |

## Composition

`Sidebar` possède l’état de mise en page du Splitter, tandis que `Collapsible`, `Menu` et
`SidebarTooltip` possèdent chacun leur propre état. Gardez `SidebarPanel`, `SidebarResizeTrigger`, `SidebarTrigger` et
`SidebarInset` comme enfants directs, dans l’ordre visuel: `SidebarPanel` en premier à gauche, `SidebarInset` en premier
à droite. `SidebarExpandedContent` et `SidebarCollapsedContent` ne font que changer la branche visible. Ils servent
à associer des liens `Collapsible` dans la vue étendue et un `Menu` dans la barre repliée, sans
déplacer l’état dans Sidebar. Pour conserver la largeur, contrôlez `size`, mettez-le à jour dans
`onResize(details)` et enregistrez la valeur finale dans `onResizeEnd(details)`. Dans Solid, `asChild`
utilise une fonction de rendu qui reçoit les props fusionnées.
Dans Vue, utilisez `as-child` avec un seul élément dans le slot par défaut et une référence de template pour accéder à l’instance du composant.
Pour contrôler les dimensions, utilisez `v-model:size` ou gérez `@resize` ; enregistrez la valeur finale avec `@resize-end`.
Placez `SidebarNavigationBadge` après un `SidebarNavigationButton` ou un `SidebarNavigationSubButton` simple. Le composant
réserve l’espace nécessaire au compteur et disparaît avec les autres icônes dans la barre compacte.

`useSidebar()` du package du framework correspondant expose l’état de la barre via `collapsed`, `side`
et `state`, plus un callback `toggleSidebar()`. Dans Solid, ce sont des accessors lus comme
`collapsed()` et compagnie. Le hook lit le contexte Splitter créé par `Sidebar`, donc
utilisez-le uniquement à l’intérieur de l’arborescence de la barre.
Dans Vue, les valeurs d’état sont des refs : lisez `collapsed.value`, `side.value` et
`state.value` dans le script ; Vue accède automatiquement à leur valeur dans les templates.

Avec Ark Vue 5.39.3 / Zag 1.45.0, le premier repli en mode contrôlé peut mettre à jour `size`
sans émettre `@collapse`. Le modèle et `useSidebar().collapsed` reflètent toutefois le nouvel état.

## Exemples

### Navigation imbriquée

Utilisez `SidebarExpandedContent` pour les liens imbriqués affichés dans le panneau et `SidebarCollapsedContent`
pour les mêmes liens dans un menu contextuel. Les deux branches restent composées par l’application.

<Example name="sidebar/nested-navigation" />

### Zone de défilement personnalisée

Le défilement natif est utilisé par défaut. Placez `ScrollArea` dans `SidebarContent` pour ajouter
une barre de défilement stylisée ou un fondu sur le bord, et faites de son viewport le seul conteneur
de défilement.

<Example name="sidebar/custom-scroll-area" />

### Mise en page persistante sur ordinateur

Conservez la largeur de la barre latérale dans l’état de l’application ou dans le stockage. Contrôlez
`size` pendant le redimensionnement et enregistrez la valeur finale dans `onResizeEnd(details)`.

<Example name="sidebar/persisted-layout" />

### Structure complète de l’application

Combinez la recherche, les actions de groupe, les badges, la navigation imbriquée, le menu de la
barre repliée et le menu du compte dans une même structure. Chaque primitive imbriquée conserve son
propre état et sa gestion du focus.

<Example name="sidebar/nested-navigation-and-account-menu" />

### Barre latérale à droite

Passez `side="right"` et rendez `SidebarInset`, `SidebarTrigger`, `SidebarResizeTrigger` et `SidebarPanel` dans cet ordre.
Sidebar ajuste automatiquement la configuration des panneaux, les identifiants, le placement et la
direction du chevron.

<Example name="sidebar/right-sidebar" />

### Sélection d’un espace de travail

Utilisez `SelectTrigger asChild` avec `SidebarNavigationButton`. Placez la valeur sélectionnée
dans `SidebarLabel`, gardez `SelectIndicator` comme enfant direct du trigger et marquez l’ancre
visuelle compacte avec `data-sidebar-icon`.

<Example name="sidebar/workspace-select" />

### Personnalisation avancée

Définissez une taille initiale explicite et composez d’autres primitives dans la structure lorsque
la largeur initiale par défaut ne convient pas.

## Styles

Chaque partie sémantique accepte `className` en React et `class` en Solid et Vue et expose un hook stable
`data-slot="sidebar-*"`. `SidebarPanel` ajoute `data-state="expanded"` ou `"collapsed"`, tandis
que les parties de mise en page exposent `data-side`. `SidebarNavigationButton` et `SidebarNavigationSubButton`
exposent `data-active`, et `SidebarNavigationButton` expose aussi `data-size`.

Lorsque la barre est repliée, les libellés et titres de groupe sortent de la mise en page visuelle
tout en restant accessibles aux technologies d’assistance. Les listes imbriquées, champs, actions,
badges et indicateurs sont masqués pour garder la barre d’icônes compacte. Marquez les ancres
visuelles non-SVG, comme `Avatar` ou une marque, avec `data-sidebar-icon`.

La largeur des panneaux appartient à l’état d’Ark, pas au CSS visuel. Remplacez `defaultSize` ou
contrôlez `size` pour définir la largeur courante. Les couleurs viennent des tokens sidebar de la
fondation (`--moduix-color-sidebar`, `--moduix-color-sidebar-foreground`,
`--moduix-color-sidebar-accent`, `--moduix-color-sidebar-accent-foreground`,
`--moduix-color-sidebar-border` et `--moduix-color-sidebar-ring`) : thèmes et presets restylent
toutes les barres latérales à la fois. La racine conserve `--moduix-sidebar-width`,
`--moduix-sidebar-height` et `--moduix-sidebar-trigger-offset-y` ; modifiez les espacements, le
rayon, l’ombre ou la taille des éléments avec une classe sur la partie.

Placez le texte de navigation dans `SidebarLabel`, y compris dans `SidebarNavigationSubButton`, pour
que les libellés longs soient tronqués et quittent la barre repliée.

### Points d’accroche CSS

Les parties de la coque Sidebar exposent aussi `data-scope="sidebar"` et `data-part`. `SidebarInput`
et `SidebarSeparator` conservent les scopes de leurs primitives, tandis que les parties basées sur
Ark conservent les attributs d’état du Splitter, notamment `data-focus`, `data-dragging`,
`data-disabled` et `data-orientation`.
