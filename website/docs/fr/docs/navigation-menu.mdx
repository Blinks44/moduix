## Référence de l’API

Ark UI ne publie pas encore de documentation dédiée à Navigation Menu. Le composant suit le [code source React d’Ark](https://github.com/chakra-ui/ark/tree/main/packages/react/src/components/navigation-menu) et en conserve les parties ainsi que le modèle d’état.

## Choisir le bon composant

Utilisez `NavigationMenu` pour la navigation principale d’un produit ou d’un site lorsque quelques liens associés doivent être regroupés avec des panneaux dépliables.

- Choisissez **`NavigationMenu`** lorsqu’un élément de premier niveau peut ouvrir un panneau compact contenant des liens associés.
- Choisissez **`Menu`** pour les actions contextuelles, pas pour la navigation vers une destination.
- Choisissez **`Tabs`** lorsque chaque contrôle sélectionné affiche le panneau de contenu correspondant sur la page courante.

## Anatomie

```text
NavigationMenu
├─ NavigationMenu.List
│  ├─ NavigationMenu.Item[value]
│  │  └─ NavigationMenu.Link
│  └─ NavigationMenu.Item[value]
│     ├─ NavigationMenu.Trigger
│     └─ NavigationMenu.Content
│        ├─ NavigationMenu.Indicator > NavigationMenu.Arrow (facultatif sans Viewport)
│        └─ NavigationMenu.Link
└─ NavigationMenu.ViewportPositioner (facultatif)
   ├─ NavigationMenu.Indicator > NavigationMenu.Arrow (facultatif avec Viewport)
   └─ NavigationMenu.Viewport

NavigationMenu.RootProvider
└─ même arbre de parties relié à l’état géré par useNavigationMenu()

NavigationMenu.Context
└─ accès avancé à l’état courant de la navigation via une fonction de rendu
```

| Partie | Rôle |
| --- | --- |
| `NavigationMenu` | Racine `nav` qui contrôle l’élément ouvert, les délais, le focus et la direction. |
| `NavigationMenu.RootProvider` | Relie les parties à un store créé avec `useNavigationMenu()`. |
| `NavigationMenu.Context` | Donne un accès avancé à l’état courant via une fonction de rendu. |
| `NavigationMenu.List` | Regroupe les éléments de navigation de premier niveau. |
| `NavigationMenu.Item` | Impose une `value` et l’associe au déclencheur, au lien et au contenu de l’élément. |
| `NavigationMenu.Trigger` | Bouton qui ouvre le panneau de l’élément. |
| `NavigationMenu.Content` | Panneau dépliable de l’élément ; peut être rendu dans un `Viewport` partagé. |
| `NavigationMenu.Link` | Lien de navigation, y compris les destinations directes de premier niveau. |
| `NavigationMenu.Indicator` / `NavigationMenu.Arrow` | Repère visuel facultatif dans un contenu autonome ou un `Viewport` partagé. |
| `NavigationMenu.ItemIndicator` | Indicateur visuel facultatif pour l’élément courant. |
| `NavigationMenu.ViewportPositioner` | Positionne un `Viewport` partagé facultatif. |
| `NavigationMenu.Viewport` | Surface partagée animée pour le contenu ouvert. |

## Composition

### Composition recommandée

Gardez les parties Ark explicites dans votre balisage. Attribuez une `value` stable à chaque `NavigationMenu.Item`. Le `Trigger` et le `Content` associés réutilisent automatiquement cette valeur. Utilisez `NavigationMenu.Link` pour les destinations directes comme pour les liens à l’intérieur d’un panneau dépliable.

Le composant racine accepte les propriétés Ark `value`, `defaultValue`, `onValueChange(details)`, `openDelay`, `closeDelay`, `orientation`, `disableClickTrigger`, `disableHoverTrigger`, `disablePointerLeaveClose`, `ids`, `lazyMount` et `unmountOnExit`.

### Quand créer une composition personnalisée

Utilisez `asChild` sur `NavigationMenu.Trigger` ou `NavigationMenu.Link` lorsqu’un lien de routeur ou un autre élément sémantique doit recevoir le comportement d’Ark. L’enfant doit rester un unique élément interactif pouvant recevoir le focus.

Ajoutez `NavigationMenu.ViewportPositioner` et `NavigationMenu.Viewport` lorsque plusieurs panneaux doivent s’ouvrir dans une seule zone animée. Si le déclencheur actif doit être relié visuellement à son panneau, placez un `Indicator` avec un `Arrow` avant le `Viewport` dans `ViewportPositioner`. Le viewport mesure chaque panneau et anime sa largeur et sa hauteur lorsque vous passez d’un déclencheur à l’autre. Sans viewport partagé, `Content` reste à côté de son `Item`, sous la forme d’un panneau dépliable compact, et peut contenir son propre `Indicator`.

Utilisez `useNavigationMenu()` avec `NavigationMenu.RootProvider` lorsque l’état de navigation doit être géré en dehors de l’arbre de composants rendu. Utilisez `NavigationMenu.Context` ou `useNavigationMenuContext()` lorsque l’interface environnante doit lire cet état.

### Comportement

- `onValueChange` reçoit l’objet de détails d’Ark ; `details.value` identifie l’élément actuellement ouvert.
- `NavigationMenu` rend un `nav` sémantique. Ark gère les attributs ARIA des panneaux dépliables, les interactions au survol et au clic, ainsi que la navigation au clavier.
- `Content` et `Viewport` conservent les attributs de présence d’Ark. `lazyMount` et `unmountOnExit` fonctionnent avec l’animation de sortie par défaut.
- L’enveloppe n’ajoute ni icône de déclencheur ni `Viewport`. Ajoutez-les uniquement lorsque votre composition en a besoin.
- Les flèches sont facultatives et ne font pas partie de la composition de base recommandée.

### Sélecteurs CSS utiles

- `NavigationMenu` définit la largeur de la racine, la couleur du texte et sa position dans la mise en page.
- `NavigationMenu.List` définit l’espacement et l’orientation des éléments de premier niveau.
- `NavigationMenu.Trigger` et `NavigationMenu.Link` permettent de styliser les contrôles de navigation, l’état courant et le focus.
- `NavigationMenu.Content` permet de styliser les surfaces des panneaux dépliables et leurs liens.
- `NavigationMenu.Indicator`, `ItemIndicator` et `Arrow` permettent de styliser les décorations facultatives de l’état actif.
- `NavigationMenu.ViewportPositioner` et `Viewport` permettent de styliser une zone de panneau partagée et animée.

Les principaux hooks publics sont `data-slot="navigation-menu-root"`, `data-slot="navigation-menu-root-provider"`, `data-slot="navigation-menu-list"`, `data-slot="navigation-menu-item"`, `data-slot="navigation-menu-trigger"`, `data-slot="navigation-menu-content"`, `data-slot="navigation-menu-link"`, `data-slot="navigation-menu-indicator"`, `data-slot="navigation-menu-item-indicator"`, `data-slot="navigation-menu-arrow"`, `data-slot="navigation-menu-viewport-positioner"` et `data-slot="navigation-menu-viewport"`.

Les hooks Ark utiles comprennent `data-scope="navigation-menu"`, `data-part`, `data-state`, `data-current`, `data-disabled`, `data-orientation` et `data-motion`. À l’exécution, Ark définit `--trigger-x`, `--trigger-y`, `--trigger-width`, `--trigger-height`, `--viewport-x`, `--viewport-y`, `--viewport-width` et `--viewport-height`.
