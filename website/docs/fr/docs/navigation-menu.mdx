## Choisir le bon composant

Utilisez `NavigationMenu` pour la navigation principale d’un site ou d’un produit lorsque certains
éléments de premier niveau ouvrent des groupes de destinations associées.

- Choisissez **`NavigationMenu`** lorsqu’un élément de premier niveau peut afficher un groupe de liens associés.
- Choisissez **`Menu`** pour les actions contextuelles plutôt que pour la navigation.
- Choisissez **`Tabs`** lorsque chaque contrôle sélectionné change le contenu affiché dans une zone de la page courante.

## Anatomie

```text
NavigationMenu / NavigationMenu.Root
├─ NavigationMenu.List
│  ├─ NavigationMenu.Item[value]
│  │  └─ NavigationMenu.Link
│  └─ NavigationMenu.Item[value]
│     ├─ NavigationMenu.Trigger
│     ├─ NavigationMenu.ItemIndicator (facultatif)
│     └─ NavigationMenu.Content
│        └─ NavigationMenu.Link
│  └─ NavigationMenu.Indicator > NavigationMenu.Arrow (facultatif)
└─ NavigationMenu.ViewportPositioner (facultatif)
   └─ NavigationMenu.Viewport

NavigationMenu.RootProvider
└─ même arbre de parties relié à l’état créé avec useNavigationMenu()

NavigationMenu.Context
└─ accès avancé à l’état courant de la navigation via une fonction de rendu
```

| Partie | Rôle |
| --- | --- |
| `NavigationMenu` / `NavigationMenu.Root` | Élément `nav` racine qui gère l’élément ouvert, les délais, le focus et l’orientation. |
| `NavigationMenu.RootProvider` | Relie les parties à l’état créé avec `useNavigationMenu()`. |
| `NavigationMenu.Context` | Expose l’état courant de la navigation via une fonction de rendu. |
| `NavigationMenu.List` | Regroupe les éléments de navigation de premier niveau. |
| `NavigationMenu.Item` | Requiert une valeur `value` unique et relie le déclencheur, le contenu et les liens de l’élément. |
| `NavigationMenu.Trigger` | Bouton qui ouvre ou ferme le panneau dépliable de l’élément. |
| `NavigationMenu.Content` | Panneau dépliable de l’élément. Il peut s’afficher à côté de l’élément ou dans une zone `Viewport` partagée. |
| `NavigationMenu.Link` | Lien vers une destination directe ou lien à l’intérieur d’un panneau dépliable. |
| `NavigationMenu.ItemIndicator` | Marqueur visuel facultatif de l’élément courant. |
| `NavigationMenu.Indicator` | Repère facultatif du déclencheur actif ; placez-le dans `List`. Utilisez `Arrow` avec une zone `Viewport` partagée. |
| `NavigationMenu.ViewportPositioner` | Positionne une zone `Viewport` partagée. |
| `NavigationMenu.Viewport` | Zone animée partagée pour le contenu actuellement ouvert. |

## Composition

Utilisez `defaultValue` pour un menu non contrôlé. Lorsqu’une autre partie de l’application gère
l’élément ouvert, transmettez `value` et `onValueChange(details)` ; `details.value` contient la valeur
de l’élément ouvert ou une chaîne vide lorsque tous les panneaux sont fermés. Utilisez
`NavigationMenu.RootProvider` avec `useNavigationMenu()` lorsque le store doit être créé en dehors de
l’arbre rendu. Transmettez le store obtenu à `RootProvider` et ne rendez pas une autre racine pour ce
store. React expose le store comme un objet, tandis que Solid donne accès à son état réactif au moyen
de la fonction retournée.

Ajoutez `ViewportPositioner` et `Viewport` lorsque plusieurs panneaux doivent partager une même zone
animée. Placez `Indicator` dans `List` et ajoutez-y `Arrow` uniquement avec une zone `Viewport`
partagée. Sans zone `Viewport` partagée, `Content` s’affiche à côté de son `Item`. Utilisez `asChild`
pour les liens de routeur ou les déclencheurs personnalisés uniquement si l’enfant reste un seul élément
interactif pouvant recevoir le focus.

## Styles

Utilisez `className` dans React ou `class` dans Solid sur les parties exportées pour les styles
structurels. Pour les styles liés à l’état, privilégiez les attributs de données Ark comme `data-state`,
`data-current` et `data-orientation`, avec les sélecteurs moduix `data-slot`. Les variantes Tailwind
utilisent des utilitaires natifs et les classes du consommateur ; les variables ci-dessous personnalisent
les variantes CSS Modules. Les attributs de données et les points d’accroche `data-slot` sont communs
aux deux modes de style.

### Points d’accroche CSS

Ciblez la partie responsable de l’aspect que vous souhaitez modifier :

- `NavigationMenu` pour la largeur de la racine, la couleur du texte et sa position dans la mise en page
- `NavigationMenu.List` pour l’espacement et l’orientation des éléments de premier niveau
- `NavigationMenu.Trigger` et `NavigationMenu.Link` pour les contrôles de navigation, l’état courant et le focus
- `NavigationMenu.Content` pour l’apparence des panneaux dépliables et de leurs liens
- `NavigationMenu.Indicator` et `ItemIndicator` pour les décorations facultatives de l’état actif ; utilisez `Arrow` avec une zone `Viewport` partagée
- `NavigationMenu.ViewportPositioner` et `Viewport` pour une zone de panneau partagée et animée

Les principaux points d’accroche publics sont `data-slot="navigation-menu-root"`,
`data-slot="navigation-menu-root-provider"`, `data-slot="navigation-menu-list"`,
`data-slot="navigation-menu-item"`, `data-slot="navigation-menu-trigger"`,
`data-slot="navigation-menu-content"`, `data-slot="navigation-menu-link"`,
`data-slot="navigation-menu-indicator"`, `data-slot="navigation-menu-item-indicator"`,
`data-slot="navigation-menu-arrow"`, `data-slot="navigation-menu-viewport-positioner"` et
`data-slot="navigation-menu-viewport"`.

Parmi les attributs Ark utiles figurent `data-scope="navigation-menu"`, `data-part`, `data-state`,
`data-current`, `data-disabled`, `data-orientation` et `data-motion`. À l’exécution, Ark définit les
variables `--trigger-x`, `--trigger-y`, `--trigger-width`, `--trigger-height`, `--viewport-x`,
`--viewport-y`, `--viewport-width` et `--viewport-height`.
