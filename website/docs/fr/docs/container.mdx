## Référence de l’API

Ark UI ne fournit pas de primitive `container` dédiée. Dans moduix, ce composant est construit à l’aide de la
[fabrique Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) et suit les recommandations d’Ark pour
la [composition](https://ark-ui.com/docs/guides/composition), le [style](https://ark-ui.com/docs/guides/styling) et
les [refs](https://ark-ui.com/docs/guides/ref).

## Exemple de base

Utilisez `Container` lorsque vous devez limiter la largeur du texte pour le rendre plus agréable à lire. Le composant
centre la colonne de contenu, ajoute un espacement intérieur horizontal adaptatif et ne gère pas les espacements verticaux.

## Anatomie

`Container` se limite volontairement à un composant racine construit avec la composition de la fabrique Ark.

```text
Container / Container.Root
└─ enfants
```

| Partie                         | Rôle                                                                                  |
| ------------------------------ | ------------------------------------------------------------------------------------- |
| `Container` / `Container.Root` | Enveloppe racine. Définit la largeur du contenu et l’espacement intérieur horizontal. |

## Composition

### Composition recommandée

Utilisez `Container` pour les structures de page, le corps des articles, les sections de documentation, les écrans de
réglages et toute mise en page qui doit présenter une colonne de contenu centrée avec des espacements latéraux prévisibles.

`Container.Root` désigne le même composant, exposé comme un alias d’espace de noms aligné sur le modèle d’Ark.

Utilisez `size` pour choisir la largeur du contenu et `gutter` pour définir l’espacement par rapport aux bords. Utilisez
`asChild` lorsque l’enveloppe doit également être un élément sémantique tel que `main`, `section` ou `article`.
`asChild` attend exactement un enfant sémantique. La ref pointe alors vers cet enfant, et non vers le `div` par défaut.

### Quand créer une composition personnalisée

`Container` se limite volontairement à son composant racine. Il n’a pas de sous-parties, de propriétés de slot ni
d’outils de mise en page imbriqués.

Pour l’adapter localement :

- passez `className` pour appliquer des styles locaux à la mise en page ou au bloc ;
- surchargez les variables `--moduix-container-*` si la page a besoin d’une autre largeur ou d’une autre formule de calcul de l’espacement ;
- utilisez `asChild` lorsqu’un autre élément doit constituer le nœud DOM ;
- composez-le avec `Bleed` lorsqu’un enfant doit dépasser les limites de la colonne de texte.

### Propriétés par défaut

| Propriété  | Valeur par défaut | Valeurs / remarques                                      |
| ---------- | ----------------- | -------------------------------------------------------- |
| `size`     | `lg`              | `xs` (40rem), `sm` (48rem), `md` (64rem), `lg` (72rem), `xl` (90rem), `full` (sans largeur maximale) |
| `gutter`   | `md`              | `none`, `sm`, `md`, `lg`                                 |
| `asChild`  | `false`           | Composition avec l’Ark factory                           |

### Comportement

- `Container` ne gère pas les espacements verticaux. Ajoutez-les à l’extérieur du composant ou sur ses enfants.
- `size="full"` supprime uniquement la largeur maximale. L’espacement intérieur horizontal choisi reste appliqué, sauf avec
  `gutter="none"`.
- Le composant racine expose `data-scope="container"`, `data-part="root"`, `data-slot="container-root"`,
  `data-size` et `data-gutter`. Vous pouvez les utiliser pour le style et les tests.

## Styles

Utilisez les variables CSS sur le composant racine si l’enveloppe de page a besoin d’une autre formule pour les espacements
ou d’une autre échelle de largeur. Utilisez `className` pour les styles locaux du bloc, par exemple pour ajouter des
espacements intérieurs, des bordures ou un arrière-plan.

### Points d’accroche CSS

- `Container` et `Container.Root` exposent `data-slot="container-root"` sur le composant racine.
- `data-scope="container"` et `data-part="root"` fournissent des points d’accroche alignés sur Ark pour le composant racine.
- `data-size` sélectionne le préréglage de largeur : `xs`, `sm`, `md`, `lg`, `xl`, `full`.
- `data-gutter` sélectionne le préréglage d’espacement : `none`, `sm`, `md`, `lg`.
- Les variables `--moduix-container-*` contrôlent uniquement l’espacement horizontal et le calcul de la largeur maximale.
  L’espacement vertical et la disposition des enfants relèvent du CSS de mise en page environnant.
