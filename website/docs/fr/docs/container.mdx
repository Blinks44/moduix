## Référence de l’API

Ark UI ne fournit pas de primitive `container` dédiée. Dans moduix, `Container` est construit avec la
[fabrique officielle d’Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) et suit les recommandations d’Ark pour
la [composition](https://ark-ui.com/docs/guides/composition), le [style](https://ark-ui.com/docs/guides/styling) et
la [transmission des refs](https://ark-ui.com/docs/guides/ref).

## Anatomie

`Container` rend un seul élément racine et n’ajoute aucune enveloppe supplémentaire.

```text
Container / Container.Root
└─ enfants
```

| Partie                         | Rôle                                                                                  |
| ----------------------------- | ------------------------------------------------------------------------------------- |
| `Container` / `Container.Root` | Élément racine de mise en page. Centre le contenu et gère sa largeur ainsi que ses espacements horizontaux. |

## Composition

`Container` ne gère aucun état et ne comporte aucune sous-partie à coordonner. Utilisez-le comme racine et placez
directement le contenu de la page ou de la section à l’intérieur. `Container.Root` est un alias de cette même racine,
utile lorsque cette notation s’accorde mieux avec le reste de votre composition.

Utilisez `asChild` lorsqu’un élément sémantique doit devenir la racine rendue. Fournissez exactement un enfant : React
imbrique cet élément dans `Container`, tandis que Solid utilise la forme avec fonction de rendu
`asChild={(props) => <main {...props()} />}`. Placez `Bleed` dans `Container` lorsqu’un seul enfant doit dépasser la
colonne de texte contrainte.

## Styles

Pour les packages CSS Modules, surchargez les variables CSS sur la racine lorsqu’une enveloppe de page a besoin d’une
autre largeur ou de valeurs d’espacement différentes. Les packages Tailwind utilisent des utilitaires et les classes du
consommateur à la place de ces variables. Utilisez `className` en React ou `class` en Solid pour les styles locaux du
bloc, comme le padding, les bordures ou les arrière-plans.

### Propriétés CSS

<CssPropertiesSection properties={ContainerDocs.containerOverrideCssProperties} />

Ces variables s’appliquent aux packages CSS Modules. Les packages Tailwind exposent les mêmes choix `size` et `gutter`
avec des utilitaires.

### Points d’accroche CSS

- `Container` et `Container.Root` exposent `data-slot="container-root"` sur la racine.
- `data-scope="container"` et `data-part="root"` suivent les conventions de style d’Ark.
- `data-size` sélectionne la largeur : `xs`, `sm`, `md`, `lg`, `xl`, `full`.
- `data-gutter` sélectionne l’espacement latéral : `none`, `sm`, `md`, `lg`.
- Les variables `--moduix-container-*` contrôlent les espacements horizontaux et le calcul de `max-width` pour CSS
  Modules. Les espacements verticaux et la disposition des enfants restent gérés par la mise en page environnante.
