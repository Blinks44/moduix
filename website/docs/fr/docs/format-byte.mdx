## Quand l’utiliser

Utilisez `Format.Byte` lorsque vous disposez d’un nombre d’octets, mais devez afficher une taille compréhensible :
taille d’un fichier à envoyer ou à télécharger, quota de stockage ou valeur de télémétrie. Passez ce nombre dans
`value`. Le formateur choisit automatiquement une unité adaptée, comme `kB`, `MB` ou `GB`.

Importez `Format` directement depuis Ark UI :

```tsx
import { Format } from '@ark-ui/react';
```

## Systèmes décimal et binaire

La propriété `unitSystem` définit la base de conversion : `decimal` utilise des multiples de 1000, tandis que `binary`
utilise des multiples de 1024. Choisissez explicitement le système lorsque le produit distingue la capacité annoncée
d’un disque de ses valeurs techniques de stockage.

## Locale et options d’affichage

`Format.Byte` utilise la locale du `LocaleProvider` le plus proche. Sans provider, Ark utilise `en-US`. moduix réexporte
ce provider depuis `@moduix/react/locale`, vous pouvez donc le placer autour de la partie localisée de l’interface :

```tsx
import { Format } from '@ark-ui/react';
import { LocaleProvider } from '@moduix/react/locale';

export function LocalizedFileSize() {
  return (
    <LocaleProvider locale="fr-FR">
      <Format.Byte value={1_450.45} />
    </LocaleProvider>
  );
}
```

Utilisez `unit="byte"` pour un nombre d’octets, ou `unit="bit"` lorsque `value` représente un nombre de bits.
`unitDisplay="narrow"`, `"short"` ou `"long"` contrôle la forme d’affichage de l’unité. `precision` définit le
nombre de chiffres significatifs, avec 3 par défaut. `unitSystem` vaut `decimal` par défaut, `unit` vaut `byte` et
`unitDisplay` vaut `short`. Les libellés d’unités dépendent de la locale. Pour comparer plusieurs tailles de fichier,
utilisez le même système d’unités, le même style et la même précision.

## Utilisation avec moduix

`Format.Byte` n’ajoute ni libellé, ni espacement, ni autre élément d’interface. Utilisez les composants moduix `Card`,
`Stack`, `Text` et les composants de statut pour expliquer ce que représente la taille. Si vous avez seulement besoin
du texte formaté, aucun composant moduix supplémentaire n’est nécessaire.

## Responsabilités

`Format.Byte` et son API appartiennent à Ark UI. moduix fournit les composants d’interface autour et réexporte
`LocaleProvider` depuis `@moduix/react/locale`, mais ne réexporte pas `Format.Byte`.
