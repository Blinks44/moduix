`Format.Byte` transforme un nombre d’octets en texte lisible. Importez-le depuis le package Ark correspondant à votre
framework.

## Exemple de base

Passez le nombre d’octets dans `value`. `Format.Byte` ne rend que le texte formaté : placez-le donc près d’un libellé
ou d’un autre élément qui explique la valeur. Les exemples utilisent un paragraphe pour une valeur et une liste de
définitions lorsque plusieurs valeurs partagent le même contexte.

L’aperçu utilise la source React, car l’application de documentation est basée sur React. L’onglet Solid contient la
source Solid native pour le même résultat et la même API.

## Systèmes décimal et binaire

Utilisez `unitSystem="decimal"` pour des multiples de 1000 et `unitSystem="binary"` pour des multiples de 1024.
Choisissez le système explicitement lorsque le produit distingue la capacité annoncée d’un disque de ses valeurs
techniques de stockage.

## Options

| Propriété | Valeurs | Valeur par défaut | Rôle |
| --- | --- | --- | --- |
| `value` | `number` | obligatoire | Nombre d’octets à formater. |
| `unit` | `'byte'` ou `'bit'` | `'byte'` | Unité représentée par `value`. |
| `unitDisplay` | `'short'`, `'narrow'` ou `'long'` | `'short'` | Forme d’affichage du libellé. |
| `unitSystem` | `'decimal'` ou `'binary'` | `'decimal'` | Base utilisée pour mettre la valeur à l’échelle. |

Le type public actuel `FormatByteProps` ne contient pas `precision`, `locale` ni `sizes`. Utilisez `LocaleProvider` pour
changer la locale et limitez la configuration du composant aux props listées ci-dessus.
