Partez de ce bloc pour un outil interne. Cliquez sur **New project**, remplissez le formulaire et
envoyez-le : le dialogue se ferme, le projet apparaît en tête du tableau, les cartes de statistiques
se mettent à jour et une notification confirme le changement.

Le bloc combine `Sidebar` pour la navigation, `Dialog` avec `Field`, `Input` et `Select` pour le
formulaire, `Table` et `Badge` pour la liste, et `Toast` pour le retour. Il s’agit d’une composition
prête à copier, pas d’un composant `ProjectsDashboard` exporté par moduix.

## Connecter vos données

L’exemple garde les projets dans un état local pour fonctionner sans serveur. Dans votre
application, chargez la liste depuis votre API et envoyez-lui les données du formulaire dans
`createProject`. Fermez le dialogue et affichez la notification de succès une fois la requête
terminée ; en cas d’échec, affichez une notification `error` avec le même `toaster`.

Remplacez l’ancre `#projects` et les autres liens de démonstration par les routes de votre
application. Si votre routeur fournit un composant de lien, utilisez-le avec
`SidebarNavigationButton` et la prop `asChild`. Les parties `Sidebar` sont décrites dans la
[documentation de Sidebar](/docs/sidebar).

## Comportement du formulaire

| Partie               | Comportement                                                                                                         |
| -------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `Field required`     | Rend le champ obligatoire : le navigateur bloque l’envoi d’un formulaire vide et place le focus sur le premier champ invalide. |
| `Select name`        | `SelectHiddenSelect` rend un `select` natif, si bien que le statut choisi figure dans `FormData`.                   |
| `Dialog open`        | Le dialogue est contrôlé : le formulaire ne le ferme qu’après un envoi réussi.                                       |
| `DialogCloseTrigger` | **Cancel** ferme le dialogue sans modifier la liste ; Échap et un clic sur l’arrière-plan font de même.              |

## Comportement adaptatif

`Sidebar` ne fournit pas de tiroir mobile. Sur les petits écrans, composez un `Drawer` ou un autre
panneau superposé avec votre navigation. La feuille de style de l’exemple passe les cartes de
statistiques sur une colonne sous `40rem`, et `TableScrollArea` permet de faire défiler le tableau
horizontalement.
