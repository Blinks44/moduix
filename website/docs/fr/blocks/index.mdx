# Blocs

Les blocs sont des compositions à intégrer dans votre application pour des interfaces et des parcours
courants. Consultez l’aperçu et le code, puis installez le bloc avec une seule commande shadcn.
Le registre ajoute le bloc, son CSS, les composants UI nécessaires et les dépendances supplémentaires.

Chaque bloc dispose de code natif React, Solid et Vue. Choisissez des composants UI CSS Modules
ou Tailwind à l’installation ; la mise en page du bloc utilise le même CSS Module dans les deux
variantes. Les aperçus utilisent React avec CSS Modules. Les routes, les appels API,
l’authentification et vos données restent dans votre application.
