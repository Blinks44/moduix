# Carte avec effet parallaxe

Cette composition associe `CardBackground`, un petit gestionnaire de pointeur et des transformations CSS
pour créer une carte avec une image couvrant tout le fond et une légère inclinaison 3D. Il s’agit d’une
composition applicative prête à copier, et non d’un composant `ParallaxCard` exporté par moduix.

`CardBackground` place l’image derrière le contenu de la carte. Le dégradé et le contraste du texte sont
définis dans le fichier CSS de l’exemple, afin que vous puissiez les adapter à l’image choisie. L’inclinaison
ne s’active que sur les appareils dotés d’un pointeur précis prenant en charge le survol. Si ce pointeur
n’est pas disponible ou si la personne préfère réduire les animations, la carte reste immobile.

L’aperçu interactif utilise le paquet React. Les onglets de code présentent des implémentations natives pour React, Solid et Vue avec les mêmes styles.

## Utiliser la composition dans votre application

Après l’installation du bloc :

- remplacez l’URL de l’image et le texte visible par votre contenu ;
- laissez `alt=""` sur l’image placée dans `CardBackground`, puisqu’elle est décorative. Si l’image apporte
  une information, utilisez `CardMedia` et fournissez un texte alternatif ;
- considérez l’inclinaison comme un effet visuel. La carte doit rester lisible et utilisable sans survol ni
  animation ;
- ajoutez un véritable lien ou bouton si la carte déclenche une action. Utilisez `Card asChild` lorsque
  toute la carte est un seul lien sans contrôle imbriqué, ou `CardLink` dans `CardTitle` lorsque la carte
  contient aussi des actions distinctes.
