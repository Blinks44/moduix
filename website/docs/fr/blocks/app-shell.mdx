## Ajoutez votre contenu

Importez le composant copié `AppShell` dans une page placée à côté de `app-shell.tsx` (ou
`app-shell.vue` ou `app-shell.svelte`). Le contenu est rendu dans `<main>`. Le bloc inclut sa feuille de style commune
et le dossier `icons`.

<FrameworkCode
  name="app-shell-route"
  sources={{ react: routeReact, solid: routeSolid, vue: routeVue, svelte: routeSvelte }}
/>

L’exemple utilise un état local. Dans votre application, déduisez `page` de la route active et
remplacez les boutons de navigation par les liens de votre routeur. Conservez `aria-current="page"`
sur le lien actif. Remplacez le nom de l’espace de travail, les liens et les informations du profil
dans le code copié. `AppShell` est une composition que vous pouvez modifier, pas un composant
exporté par le paquet moduix.

## Navigation Vue et Svelte

Les blocs Vue et Svelte incluent `app-shell-navigation.vue` et `app-shell-navigation.svelte` pour partager la navigation entre la barre latérale
et le menu mobile. La CLI l’installe à côté de `app-shell.vue` ou `app-shell.svelte`. Avec Svelte, `AppShell` reçoit `children` sous forme de snippet et signale la navigation par le callback `onnavigate`.

## Comportement adaptatif

| Zone | Comportement |
| --- | --- |
| Grand écran | Barre latérale de 240 px, en-tête de 56 px et zone de contenu avec des marges intérieures de 32 px. |
| Largeur inférieure à 48rem | La barre latérale laisse place à un bouton qui ouvre `Drawer`. Le seuil dépend de la largeur du conteneur de l’application. |
| Navigation mobile | Le choix d’une page ferme le menu. Échap, le bouton de fermeture et un clic sur le fond le ferment aussi ; le focus revient au bouton d’ouverture. |
| Thème | Le bouton change le thème de cette structure et de son menu mobile. Le thème environnant est hérité jusqu’au premier changement. |

Le menu utilise un portail placé dans la structure pour conserver son thème. Évitez les ancêtres
qui appliquent une transformation ou rognent le contenu. Pour gérer le thème de toute l’application,
déplacez cet état dans votre fournisseur de thème et utilisez son conteneur de portail, comme indiqué
dans le [démarrage rapide](/docs/quick-start).

Pour une application complète de gestion de projets, utilisez un [projet de démarrage Vite](/docs/starters).
