# Панель управления с боковой навигацией

Используйте этот блок как основу для десктопной оболочки приложения. Он объединяет `Sidebar`,
`Collapsible` и `Menu`: ширину навигации можно менять, панель можно сворачивать, группу Projects
можно раскрывать, а в нижней части панели находится меню рабочего пространства. В основной области
показан небольшой обзор с карточками показателей, чтобы было понятно, куда добавить содержимое
приложения.

Ширину панели можно менять перетаскиванием разделителя или с клавиатуры. `SidebarTrigger`
сворачивает и разворачивает панель, а `SidebarTooltip` показывает подписи пунктов, когда панель
сведена к узкой полосе с иконками.

Это готовая композиция для копирования, а не отдельный компонент `SidebarDashboard`, экспортируемый
moduix. Установите блок, затем замените демонстрационные ссылки,
подписи и данные панели.

Превью работает на React. Во вкладках приведён код для React, Solid и Vue с общей таблицей стилей.

## Используйте блок в приложении

Замените якоря `#overview`, `#website` и другие демонстрационные ссылки маршрутами приложения. Если
роутер предоставляет компонент ссылки, используйте его с `SidebarNavigationButton` или
`SidebarNavigationSubButton` и пропом `asChild`, чтобы роутер управлял навигацией. Помечайте
активный маршрут через `aria-current="page"`. Части `Sidebar` описаны в
[документации Sidebar](/docs/sidebar).

Используйте `SidebarTooltip` для кнопок навигации с иконками, чтобы в свёрнутом состоянии у них
оставались подписи. Для вложенных групп используйте `Collapsible`, а для действий рабочего
пространства - `Menu`. Свяжите кнопку `New project` с настоящим сценарием создания проекта, а
статические показатели и сообщение в основной области замените данными приложения.

## Адаптивное поведение

Блок рассчитан на десктопный макет. `Sidebar` не предоставляет мобильную выдвижную панель и не
выбирает за вас адаптивную модель навигации. На небольших экранах добавьте `Drawer` или другой
оверлей, используя подходящую приложению структуру навигации. CSS примера только переводит
карточки показателей в одну колонку при ширине меньше `40rem`.

## Сохранение ширины панели

В примере используется стандартная ширина панели, которая не сохраняется между посещениями. Если
приложению нужно запоминать ширину на десктопе, управляйте `Sidebar` через `size`, обновляйте это
значение в `onResize(details)` во время изменения ширины, а окончательное значение сохраняйте из
`onResizeEnd(details)`. В SSR-приложении читайте хранилище браузера после гидратации и оставляйте
рабочее значение по умолчанию для первого рендера.
