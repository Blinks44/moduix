# Галерея с автопрокруткой

Используйте этот блок для основного контента, который должен переключаться автоматически, но при этом оставаться
под управлением пользователя. В нём `Carousel` показывает соседние слайды частично, выводит текст поверх изображения,
добавляет стрелки навигации и заполняющийся индикатор для каждого интервала автопрокрутки.

Превью работает на React. Во вкладках приведён код для React, Solid и Vue с общей таблицей стилей.

## Используйте блок в приложении

Скопированный блок можно сразу адаптировать:

- Замените данные `slides` своими изображениями, категориями, заголовками, описаниями и альтернативным текстом.
  Сохраняйте стабильные значения `id` и поддерживайте `slideCount` равным `slides.length`.
- Измените `aria-label`, чтобы он описывал назначение вашей карусели, а не демонстрационного примера.
- Синхронизируйте `autoplay.delay` и длительность анимации прогресса. В блоке используются `3500` миллисекунд и
  CSS-анимация `3.5s`, поэтому индикатор заполняется как раз к появлению следующего слайда.
- Перед публикацией замените ссылки Unsplash. Используйте источник изображений, которым управляет ваше приложение и
  который соответствует его требованиям к загрузке, кэшированию и содержимому.

Настройте `slidesPerPage`, `spacing` и `padding`, чтобы изменить видимую часть соседнего слайда и отступы галереи
внутри контейнера.

## Как это работает

В React и Solid состояние карусели доступно через `CarouselContext`. В Vue используется `useCarousel`
с `CarouselRootProvider`. Состояние определяет активный слайд и предоставляет `pageSnapPoints` для
индикаторов прогресса. Текущий индикатор отмечен атрибутом `data-current`.

У каждого индикатора `overflow: visible`, поэтому прозрачная область `::after` увеличивает удобную зону нажатия у
тонкой линии прогресса. Видимое заполнение анимирует `width`, а не использует `scaleX`: так унаследованное скругление
сохраняется на переднем крае линии во время заполнения.

При нажатии на стрелку или индикатор вызывается `requestAnimationFrame(api.play)`. Ручная навигация приостанавливает
автопрокрутку, поэтому запуск в следующем кадре даёт карусели сначала завершить переход, а затем начать новый
интервал. Взаимодействие свайпом или горизонтальная прокрутка колёсиком мыши тоже ставят автопрокрутку на паузу. Если
после такого действия воспроизведение должно возобновляться автоматически, добавьте это в свою логику взаимодействия
или выведите `CarouselAutoplayTrigger`.

Ark приостанавливает автопрокрутку, пока документ скрыт. Блок отслеживает `visibilitychange` и вызывает публичный
метод `api.play()`, когда документ снова становится видимым.

## Доступность и анимация

Задайте корневому компоненту доступное имя через `aria-label` или `aria-labelledby`. Для содержательных изображений
пишите понятный `alt`, а для декоративных используйте `alt=""`, если вся информация уже есть в тексте слайда.
Оставляйте на экране кнопки перехода и индикаторы, чтобы пользователю не приходилось ждать таймер.

При включённом `prefers-reduced-motion: reduce` блок отключает переходы слайдов и анимацию индикатора. Таймер
автопрокрутки при этом продолжает переключать карусель. Если пользователю нужно останавливать автоматические
переходы, добавьте `CarouselAutoplayTrigger` или уберите свойство `autoplay`. Полное описание API и управления
автопрокруткой смотрите в [документации Carousel](/docs/carousel).
