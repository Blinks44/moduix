# Раскрывающаяся группа аватаров

Используйте этот блок для небольшой команды, когда место ограничено, но пользователям всё равно
нужно легко различать участников. Наведите указатель на аватар или переведите на него фокус, чтобы
раздвинуть группу и увидеть имя и роль участника.

Этот блок можно скопировать в приложение. Это не компонент `ExpandableAvatarGroup`, экспортируемый
moduix, а композиция на основе `Avatar` и `Tooltip`. Установите блок вместе с зависимостями,
затем замените демонстрационных участников данными из приложения.

Превью работает на React. Во вкладках приведён код для React, Solid и Vue с общей таблицей стилей.

## Настройка блока

Замените демонстрационный массив `members` данными из приложения и сохраняйте стабильный порядок
участников. Для каждого участника указывайте URL изображения из приложения.
`AvatarFallback` показывает инициалы, пока изображение загружается или недоступно. Части композиции описаны
в документации [Avatar](/docs/avatar) и [Tooltip](/docs/tooltip).

Каждый участник в блоке представлен нативной кнопкой. `TooltipTrigger asChild` позволяет подсказке
использовать эту кнопку без дополнительной обёртки, а `TooltipBody` показывает имя и роль участника.
В `aria-label` кнопки указаны оба значения, потому что у изображения задано `alt=""`, а подсказка
дополняет доступное имя, но не заменяет его. Текст подсказки должен быть коротким и необязательным
для понимания интерфейса.

Если нажатие на участника должно открывать страницу или выполнять действие, подключите это поведение
к кнопке или замените её подходящим семантическим элементом. Не убирайте доступное имя.

Используйте `role="group"` с понятной подписью для группы. Для большой команды показывайте только
нескольких первых участников и добавляйте кнопку `+N`, которая открывает полный список с поиском.

Вся анимация выполняется средствами CSS. Активная кнопка слегка приподнимается, а остальные кнопки
раздвигаются, освобождая для неё место. Правило `prefers-reduced-motion: reduce` в примере отключает
плавные переходы, но само перемещение выполняется сразу. Если политика доступности в приложении требует
полностью убрать это перемещение, задайте `transform: none` для состояний наведения и фокуса в этом
медиазапросе.
