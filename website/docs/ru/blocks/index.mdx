# Блоки

Блоки содержат готовые интерфейсы для типичных задач приложения.
Посмотрите превью и исходный код, затем установите блок одной командой shadcn. Registry добавит
сам блок, его CSS, нужные UI-компоненты и дополнительные зависимости.

У каждого блока есть нативный код для React, Solid и Vue. При установке можно выбрать UI-компоненты
на CSS Modules или Tailwind; раскладка блока использует общий CSS Module в обоих вариантах.
Живые превью используют React с CSS Modules. Маршруты, API, аутентификация и ваши данные остаются
в вашем приложении.
