`Format.Number` форматирует числовое значение по правилам браузерного `Intl.NumberFormat`. Это форматтер для чтения,
а не поле ввода.

## Справочник API

<PrimitiveReference href="https://ark-ui.com/docs/utilities/format-number" />

## Базовый пример

Передайте число в `value`. Если параметры форматирования не заданы, результат зависит от активной локали.
`Format.Number` выводит только текст, поэтому подпись и окружающую разметку нужно добавить самостоятельно.

Предпросмотр использует React, потому что сайт документации работает на React. Во вкладке Solid показана нативная
версия того же примера.

## Параметры форматирования

`Format.Number` принимает стандартные параметры `Intl.NumberFormatOptions`, включая `style`, `currency`, `unit`,
`unitDisplay`, `notation` и параметры количества знаков после запятой.

`style="percent"` умножает значение на 100: чтобы получить `6.4%`, передайте `0.0642` и
`maximumFractionDigits={1}`. Если количество знаков после запятой должно быть фиксированным, задайте одновременно
`minimumFractionDigits` и `maximumFractionDigits`. `notation="compact"` сокращает большие значения, а
`style="unit"` вместе с поддерживаемым `unit` подходит для измерений.

## Локаль

`LocaleProvider` передаёт локаль форматтеру `Format.Number` и другим форматтерам Ark в своём поддереве. Без
провайдера используется локаль `en-US`. Импортируйте провайдер из соответствующего пакета Ark.
