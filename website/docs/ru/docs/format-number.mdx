## Когда использовать

`Format.Number` предназначен для отображения числовых значений, которые нельзя редактировать. Он учитывает правила
активной локали: разделители разрядов и десятичный разделитель, формат валют, процентов, единиц измерения и
компактной записи. Для редактируемых значений используйте `NumberInput` из moduix.

Импортируйте `Format` напрямую из Ark UI:

```tsx
import { Format } from '@ark-ui/react';
```

## Базовый пример

Передайте число в `value`. Если не задавать параметры форматирования, компонент использует стандартные правила
`Intl.NumberFormat` для активной локали. Без `LocaleProvider` Ark использует `en-US`.

`Format.Number` выводит только текст. Разместите его рядом с подписью или другим элементом, который объясняет смысл
значения. В этом примере `Card` и `Stack` создают контекст и визуальную иерархию.

## Валюта, проценты и компактная запись

`Format.Number` принимает стандартные параметры `Intl.NumberFormat`. Для денежных значений задайте
`style="currency"` и передайте код валюты в параметре `currency`. Для процентов используйте `style="percent"`.
`notation="compact"` пригодится, когда в интерфейсе мало места, например в дашборде.

Значение для 6,42 % передаётся как дробь `0.0642`, а число `6.42` будет отображено как 642 %. Если нужно сохранить
два знака после запятой, задайте `maximumFractionDigits={2}`. Используйте `minimumFractionDigits` и
`maximumFractionDigits`, если количество знаков после запятой должно оставаться одинаковым.

## Локаль и единицы измерения

`Format.Number` получает локаль из `LocaleProvider`. moduix переэкспортирует провайдер из
`@moduix/react/locale`, поэтому провайдером можно обернуть часть интерфейса с общей локалью:

```tsx
import { Format } from '@ark-ui/react';
import { LocaleProvider } from '@moduix/react/locale';

export function LocalizedPrice() {
  return (
    <LocaleProvider locale="de-DE">
      <Format.Number currency="EUR" style="currency" value={1234.5} />
    </LocaleProvider>
  );
}
```

Для единиц измерения задайте `style="unit"` и поддерживаемое значение `unit`, например `kilometer`, `celsius` или
`megabyte`. С помощью `unitDisplay` со значением `"narrow"`, `"short"` или `"long"` выберите способ отображения
единицы.

## Использование с moduix

Размещайте `Format.Number` рядом с подписью, статусом или показателем, к которому относится значение. Для построения
интерфейса используйте `Card`, `Stack`, `Text` и компоненты moduix для отображения данных. Не создавайте отдельную
обёртку только для вызова форматтера. Для редактируемых сумм используйте `NumberInput`: его проп `formatOptions`
задаёт формат отображения и правила преобразования введённого текста в число.

## Границы ответственности

Ark UI предоставляет `Format.Number` и логику форматирования чисел. moduix переэкспортирует `LocaleProvider` и
компоненты для построения интерфейса. moduix не переэкспортирует `Format.Number`, поэтому `Format` нужно импортировать
из Ark UI.
