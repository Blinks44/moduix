## Анатомия

```text
createToaster()
└─ Toaster / Toast.Toaster (portalled to document.body by default)
   └─ Toast / Toast.Root
      ├─ Toast.Title
      ├─ Toast.Description
      ├─ Toast.ActionTrigger
      └─ Toast.CloseTrigger
```

| Часть                          | Назначение                                                                            |
| ------------------------------ | ------------------------------------------------------------------------------------- |
| `Toast` / `Toast.Root`         | Корень видимого уведомления. `Toast.Root` является алиасом `Toast` для совместимости. |
| `Toaster` / `Toast.Toaster`    | Выводит хранилище toaster и управляет группой уведомлений.                            |
| `Toast.Title`                  | Заголовок. Если дочерние элементы не переданы, использует `title` текущего уведомления. |
| `Toast.Description`            | Описание. Если дочерние элементы не переданы, использует `description` текущего уведомления. |
| `Toast.ActionTrigger`          | Кнопка действия, связанная с `toast.action.onClick`.                                 |
| `Toast.CloseTrigger`           | Кнопка закрытия. По умолчанию использует `CloseButton.Root`.                         |
| `Toast.Context`                | Контекстная часть для собственной композиции и прямого доступа к состоянию уведомления. |

## Композиция

По возможности создайте toaster вне тела компонента и передайте тот же экземпляр в `Toaster`.
Toaster управляет размещением, стеком, очередью, таймерами и фокусом. По умолчанию `Toaster`
выводит группу через портал в `document.body`; используйте `portalled={false}` или `portalRef`,
если группа должна находиться в другом контейнере. Отдельная обёртка `Portal` не нужна.

Для обычного уведомления используйте стандартный рендерер `Toaster`: он выводит заголовок, описание,
действие и кнопку закрытия. Для другой разметки или собственных элементов управления передайте
render prop, оставьте `Toast` или `Toast.Root` внешним элементом и соберите внутри его части.
Используйте `asChild` только с семантическим дочерним элементом-кнопкой, а `useToastContext()`
подключайте, когда собственному элементу нужен прямой доступ к текущему уведомлению.

### Хуки стилизации

На корневом элементе задавайте стили поверхности, границы, анимации и вариантов по типу. Для
внутренней типографики и элементов управления используйте `Toast.Title`, `Toast.Description`,
`Toast.ActionTrigger` и `Toast.CloseTrigger`.

Полезные селекторы Ark:

- `[data-scope='toast'][data-part='group']` на `Toaster`
- `[data-scope='toast'][data-part='root']` на `Toast`
- `[data-scope='toast'][data-part='title']` на `Toast.Title`
- `[data-scope='toast'][data-part='description']` на `Toast.Description`
- `[data-scope='toast'][data-part='action-trigger']` на `Toast.ActionTrigger`
- `[data-scope='toast'][data-part='close-trigger']` на `Toast.CloseTrigger`
- `--x`, `--y`, `--scale`, `--z-index`, `--height`, `--opacity` и `--gap` на `Toast`

Moduix также добавляет стабильные хуки: `data-slot="toast-toaster"`, `data-slot="toast-root"`,
`data-slot="toast-title"`, `data-slot="toast-description"`, `data-slot="toast-action-trigger"`
и `data-slot="toast-close-trigger"`.

При ширине окна до `40rem` группа уведомлений занимает всю ширину окна, а каждый корневой элемент
использует переменную Ark `--gap`, чтобы сохранить безопасные внутренние отступы.
