## Анатомия

```text
createToaster()
└─ ToastToaster (portalled to document.body by default)
   └─ Toast
      ├─ ToastTitle
      ├─ ToastDescription
      ├─ ToastActionTrigger
      └─ ToastCloseTrigger
```

| Часть                          | Назначение                                                                            |
| ------------------------------ | ------------------------------------------------------------------------------------- |
| `Toast`               | Корень видимого уведомления.                                      |
| `ToastToaster`        | Выводит хранилище toaster и управляет группой уведомлений.       |
| `ToastTitle`          | Заголовок. Если дочерние элементы не переданы, использует `title` текущего уведомления. |
| `ToastDescription`    | Описание. Если дочерние элементы не переданы, использует `description` текущего уведомления. |
| `ToastActionTrigger`  | Кнопка действия, связанная с `toast.action.onClick`.             |
| `ToastCloseTrigger`   | Кнопка закрытия. По умолчанию использует `CloseButton`.          |
| `ToastContext`        | Контекстная часть для собственной композиции и прямого доступа к состоянию уведомления. |

## Композиция

Создайте toaster один раз и передайте тот же экземпляр в `ToastToaster`. В Vue создавайте его внутри
`<script setup>`, чтобы у каждого экземпляра компонента было своё хранилище; общее для приложения
хранилище можно вынести в отдельный модуль. При серверном рендеринге создавайте отдельное хранилище
для каждого запроса. Хранилище управляет размещением, стеком, очередью, таймерами и фокусом.
По умолчанию `ToastToaster`
выводит группу через портал в `document.body`; используйте `portalled={false}` или `portalRef`,
если группа должна находиться в другом контейнере. Отдельная обёртка `Portal` не нужна.

Для обычного уведомления используйте стандартный рендерер `ToastToaster`: он выводит заголовок, описание,
действие и кнопку закрытия. Для другой разметки или собственных элементов управления передайте
render prop в React/Solid или основной scoped slot в Vue, оставьте `Toast` внешним элементом и
соберите внутри его части. Слот Vue получает параметры уведомления; `useToastContext()` возвращает
computed ref. Для `asChild` у кнопок действия и закрытия используйте семантический элемент-кнопку,
а `useToastContext()`
подключайте, когда собственному элементу нужен прямой доступ к текущему уведомлению.

В `@ark-ui/vue@5.39.2` свойство `asChild` у `Toast` переносит атрибуты корня на внутренний
вспомогательный элемент, а `ToastToaster` игнорирует `asChild`. Используйте их стандартные элементы
до исправления этих вариантов композиции в upstream. Композиция с `asChild` у заголовка,
описания, кнопки действия и кнопки закрытия поддерживается.

### Хуки стилизации

На корневом элементе задавайте стили поверхности, границы, анимации и вариантов по типу. Для
внутренней типографики и элементов управления используйте `ToastTitle`, `ToastDescription`,
`ToastActionTrigger` и `ToastCloseTrigger`.

Полезные селекторы Ark:

- `[data-scope='toast'][data-part='group']` на `ToastToaster`
- `[data-scope='toast'][data-part='root']` на `Toast`
- `[data-scope='toast'][data-part='title']` на `ToastTitle`
- `[data-scope='toast'][data-part='description']` на `ToastDescription`
- `[data-scope='toast'][data-part='action-trigger']` на `ToastActionTrigger`
- `[data-scope='toast'][data-part='close-trigger']` на `ToastCloseTrigger`
- `--x`, `--y`, `--scale`, `--z-index`, `--height`, `--opacity` и `--gap` на `Toast`

Moduix также добавляет стабильные хуки: `data-slot="toast-toaster"`, `data-slot="toast-root"`,
`data-slot="toast-title"`, `data-slot="toast-description"`, `data-slot="toast-action-trigger"`
и `data-slot="toast-close-trigger"`.

При ширине окна до `40rem` группа уведомлений занимает всю ширину окна, а каждый корневой элемент
использует переменную Ark `--gap`, чтобы сохранить безопасные внутренние отступы.
