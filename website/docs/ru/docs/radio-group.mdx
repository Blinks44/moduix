## Справочник API

`RadioGroup` следует примитиву radio-group из Ark UI и добавляет стили moduix, стабильные атрибуты
`data-slot` и вспомогательный компонент `Option`. Компонент экспортируется из
`@moduix/react/radio-group` и `@moduix/solid/radio-group`.

<PrimitiveReference href="https://ark-ui.com/docs/components/radio-group" />

## Какой компонент выбрать

Используйте `RadioGroup`, когда пользователь должен выбрать ровно один вариант из видимого списка,
например фреймворк, тариф или тип аккаунта. Для независимых вариантов используйте `Checkbox`, а для
настройки, которая применяется сразу, `Switch`.

## Анатомия

```text
RadioGroup / RadioGroup.Root
├─ RadioGroup.Label
├─ RadioGroup.Indicator (необязательно)
└─ RadioGroup.Item[value]
   ├─ RadioGroup.ItemControl
   ├─ RadioGroup.ItemText
   └─ RadioGroup.ItemHiddenInput (явно)

RadioGroup.RootProvider
└─ то же дерево частей, подключённое к useRadioGroup()

RadioGroup.Option
└─ Item + ItemControl + ItemText + ItemHiddenInput (фиксированная композиция)
```

| Часть                         | Назначение                                                        |
| ---------------------------- | ----------------------------------------------------------------- |
| `RadioGroup` / `.Root`       | Хранит значение, управляет клавиатурной навигацией, ориентацией и формами. |
| `RadioGroup.RootProvider`    | Подключает части к состоянию, созданному через `useRadioGroup()`. |
| `RadioGroup.Label`            | Доступная подпись группы.                                         |
| `RadioGroup.Item`             | Один вариант выбора; по умолчанию выводит `label`.                |
| `RadioGroup.Option`           | Упрощённый элемент с управлением, текстом и скрытым полем.         |
| `RadioGroup.ItemControl`      | Визуальное управление радиокнопкой с поддержкой `size` из moduix. |
| `RadioGroup.ItemText`         | Видимый текст варианта.                                           |
| `RadioGroup.ItemHiddenInput`  | Нативное поле формы для явной композиции `Item`.                  |
| `RadioGroup.Indicator`        | Необязательный индикатор активного элемента с переменными Ark.    |

## Композиция

Используйте `defaultValue` для неконтролируемой группы. Если выбранное значение хранит другая часть
приложения, используйте `value` и `onValueChange(details)`. Когда состояние нужно создать вне дерева
группы, используйте `RootProvider` с `useRadioGroup()` из соответствующего пакета. Не используйте
`RadioGroup` и `RadioGroup.RootProvider` для одного экземпляра состояния одновременно. В React
состояние читается как объект, а в Solid реактивное состояние читается через возвращённый accessor.

`RadioGroup.Option` уже содержит `ItemHiddenInput` в фиксированной композиции. При прямой композиции
`RadioGroup.Item` добавьте `RadioGroup.ItemHiddenInput` самостоятельно. Используйте явное дерево
частей, когда вложенным частям нужны собственное размещение или свойства, либо когда `asChild` должен
передать DOM-узел варианта другому элементу. В Solid `asChild` принимает render-функцию, а её прямым
дочерним элементом должен оставаться семантический `label`.

`Field.Root` предоставляет видимую подпись, вспомогательный текст и сообщение об ошибке, но не
передаёт своё состояние в `RadioGroup`. Передавайте `disabled`, `invalid`, `readOnly` и `required`
самой группе. `Fieldset.Root` передаёт вложенным группам состояние Ark `disabled` и `invalid`.

## Стилизация

Используйте `className` в React или `class` в Solid на экспортируемых частях для структурных стилей.
Для стилей состояний используйте атрибуты Ark, например `data-state`, `data-disabled` и
`data-orientation`, вместе с селекторами moduix `data-slot`. Варианты Tailwind используют нативные
утилиты и классы потребителя, а переменные ниже настраивают варианты CSS Modules. Атрибуты данных и
хуки `data-slot` общие для обоих способов стилизации.

### Хуки стилизации

- Анатомия Ark: `data-scope="radio-group"` и `data-part` на корне, подписи, варианте,
  управлении, тексте, скрытом поле и индикаторе.
- Состояния Ark: `data-state="checked|unchecked"`, `data-disabled`, `data-readonly`,
  `data-invalid`, `data-required`, `data-focus`, `data-focus-visible`, `data-hover`,
  `data-active` и `data-orientation`.
- Переменные индикатора Ark: `--transition-property`, `--left`, `--top`, `--width` и `--height`.
- Хуки moduix: `data-slot="radio-group-root"`, `radio-group-root-provider`,
  `radio-group-label`, `radio-group-item`, `radio-group-item-control`, `radio-group-item-text` и
  `radio-group-indicator`.
