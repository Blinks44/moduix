Используйте `RadioGroup`, когда пользователь должен выбрать ровно один вариант из видимого списка,
например фреймворк, тариф или тип аккаунта. Для независимых вариантов используйте `Checkbox`, а для
настройки, которая применяется сразу, `Switch`.

## Справочник API

`RadioGroup` следует примитиву radio-group из Ark UI и добавляет стили moduix, стабильные атрибуты
`data-slot` и вспомогательный компонент `Option`. Компонент импортируется из
`@moduix/react/radio-group`.

## Анатомия

```text
RadioGroup.Root
├─ RadioGroup.Label
├─ RadioGroup.Indicator
└─ RadioGroup.Item[value]
   ├─ RadioGroup.ItemControl
   ├─ RadioGroup.ItemText
   └─ RadioGroup.ItemHiddenInput (явно)

RadioGroup.RootProvider
└─ RadioGroup.* + useRadioGroup()

RadioGroup.Option
└─ RadioGroup.Item + ItemControl + ItemText + ItemHiddenInput (фиксированная композиция)
```

| Часть                         | Назначение                                                         |
| ---------------------------- | ------------------------------------------------------------------ |
| `RadioGroup` / `.Root`       | Хранит значение, управляет клавиатурной навигацией, ориентацией и формами. |
| `RadioGroup.RootProvider`    | Подключает части к состоянию, созданному через `useRadioGroup()`.  |
| `RadioGroup.Label`           | Доступная подпись группы.                                         |
| `RadioGroup.Item`            | Один вариант выбора, по умолчанию отображается как `label`.      |
| `RadioGroup.Option`          | Упрощённый элемент с элементом управления, текстом и скрытым полем ввода. |
| `RadioGroup.ItemControl`     | Визуальный элемент управления радиокнопки с поддержкой `size` из moduix. |
| `RadioGroup.ItemText`        | Видимый текст варианта.                                           |
| `RadioGroup.Indicator`       | Необязательный индикатор активного элемента с переменными размеров Ark. |

## Композиция

### Рекомендуемая композиция

`RadioGroup` является короткой формой `RadioGroup.Root`. Для обычного варианта с подписью
используйте `RadioGroup.Option`. Он принимает свойства элемента Ark, свойство `size` из moduix и
`className`. Класс применяется к базовому `Item`, поэтому к вложенным частям по-прежнему можно
настраивать через атрибуты `data-slot`.

### Когда нужна собственная композиция

Используйте `RadioGroup.RootProvider` вместе с `useRadioGroup()` из `@moduix/react`, когда состояние
нужно создать до отрисовки группы, разделить с элементами вне её дерева или читать в другой части
интерфейса. Передайте возвращённый объект состояния в `RootProvider` и не используйте `Root` и
`RootProvider` для одного экземпляра состояния одновременно.

Используйте явное дерево `Item`, когда вложенным частям нужны собственное размещение или классы, либо
когда `RadioGroup.Item asChild` должен использовать другой элемент как DOM-узел варианта. Прямым
дочерним элементом `Item` с `asChild` по-прежнему должен быть семантический `label`.

Для чтения состояния внутри дерева используйте `RadioGroup.Context`, `RadioGroup.ItemContext`,
`useRadioGroupContext()` или `useRadioGroupItemContext()` из `@moduix/react`.

### Свойства по умолчанию

| Свойство                           | По умолчанию | Примечания                                                        |
| ---------------------------------- | ------------ | ----------------------------------------------------------------- |
| `RadioGroup` / `RadioGroup.Root`   | -            | Применяются значения Ark, дополнительных настроек поведения moduix нет. |
| `RadioGroup.Option size`           | `md`         | Диаметр элемента управления и размер точки индикатора.            |
| `RadioGroup.ItemControl size`      | `md`         | Диаметр элемента управления moduix и размер точки индикатора.     |

### Особенности поведения

`RadioGroup.Root` принимает свойства Ark, в том числе `value`, `defaultValue`,
`onValueChange(details)`, `name`, `form`, `orientation`, `disabled`, `invalid`, `readOnly`,
`required`, `ids` и `asChild`. В обработчике изменения читайте выбранное значение из
`details.value`.

`RadioGroup.Option` включает нативное поле. При прямой композиции `RadioGroup.Item` добавьте
`RadioGroup.ItemHiddenInput` для нативной отправки, проверки и сброса. Передайте `name` корню, если
выбранное значение должно попасть в `FormData`.

Ark управляет контролируемым и неконтролируемым состоянием, WAI-ARIA-поведением, фокусом и
клавиатурной навигацией. Клавиша <kbd>Tab</kbd> переводит фокус на выбранный элемент или на первый,
если выбор ещё не сделан. <kbd>Space</kbd> выбирает элемент в фокусе, а клавиши со стрелками
перемещают фокус и выбирают следующий или предыдущий вариант.

`Field.Root` предоставляет видимую подпись, вспомогательный текст и сообщение об ошибке, но не передаёт
состояние в `RadioGroup`. Передавайте `disabled`, `invalid`, `readOnly` и `required` самой группе.
`Fieldset.Root` передаёт вложенным группам своё состояние Ark `disabled` и `invalid`.

Каждая стилизуемая часть передаёт `ref` соответствующей DOM-части Ark, включая `ItemHiddenInput`.

## Стилизация

Стилизуйте `RadioGroup` через `className`, стабильные атрибуты `data-slot="radio-group-*"`, атрибуты
Ark `data-scope`, `data-part` и `data-state`, а также публичные CSS-переменные `--moduix-radio-*`,
перечисленные ниже.

### Точки стилизации

- Атрибуты анатомии Ark: `data-scope="radio-group"` и `data-part` у root, label, item, item-control,
  item-text, item-hidden-input и indicator.
- Атрибуты состояний Ark: `data-state="checked|unchecked"`, `data-disabled`, `data-readonly`,
  `data-invalid`, `data-required`, `data-focus`, `data-focus-visible`, `data-hover`, `data-active`
  и `data-orientation`.
- Переменные индикатора Ark: `--transition-property`, `--left`, `--top`, `--width` и `--height`.
- Атрибуты moduix: `data-slot="radio-group-root"`, `radio-group-root-provider`, `radio-group-label`,
  `radio-group-item`, `radio-group-item-control`, `radio-group-item-text`, `radio-group-item-hidden-input` и
  `radio-group-indicator`.
