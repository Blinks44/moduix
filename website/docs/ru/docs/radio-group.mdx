## Анатомия

```text
RadioGroup.Root
├─ RadioGroup.Label
├─ RadioGroup.Indicator (optional)
└─ RadioGroup.Item[value]
   ├─ RadioGroup.ItemControl
   ├─ RadioGroup.ItemText
   └─ the native form input

RadioGroup.RootProvider
└─ same item tree connected to a useRadioGroup() store

RadioGroup.Option
└─ RadioGroup.Item + ItemControl + ItemText + native input (automatic)
```

| Часть                      | Назначение                                                        |
| ------------------------- | ----------------------------------------------------------------- |
| `RadioGroup` / `.Root`    | Хранит состояние значения, клавиатурную навигацию, ориентацию и формы. |
| `RadioGroup.RootProvider` | Подключает части к состоянию, созданному Ark `useRadioGroup()`.  |
| `RadioGroup.Label`        | Доступная подпись для группы.                                     |
| `RadioGroup.Item`         | Один выбираемый вариант; по умолчанию отрисовывает `label`.       |
| `RadioGroup.Option`       | Упрощённый элемент с контролом, текстом и скрытым полем ввода.    |
| `RadioGroup.ItemControl`  | Визуальный контрол радиокнопки; поддерживает свойство moduix `size`. |
| `RadioGroup.ItemText`     | Видимый текст варианта.                                           |
| `RadioGroup.Indicator`    | Необязательный индикатор активного элемента с переменными измерений Ark. |

## Композиция

### Рекомендуемая композиция

Используйте `RadioGroup` как короткую форму для `RadioGroup.Root`, а `RadioGroup.Option` - для подписанных элементов. Option принимает свойства элемента Ark, `size` и `className`; его класс применяется к базовому `Item`, поэтому вложенные части остаются доступными через хуки `data-slot`.

### Когда нужна собственная композиция

Используйте `RadioGroup.RootProvider` вместе с `useRadioGroup()` из `@moduix/react`, когда состояние должно создаваться вне отрисованного дерева группы. Используйте явное дерево `Item`, когда пользовательская раскладка или `RadioGroup.Item asChild` должны владеть DOM-узлом элемента; прямой дочерний элемент всё равно должен быть семантичным `label`.

### Свойства по умолчанию

| Свойство                      | По умолчанию | Примечания                                                  |
| ----------------------------- | ------------ | ----------------------------------------------------------- |
| `RadioGroup.Option size`      | `md`         | Диаметр упрощённого контрола и масштаб точки индикатора.    |
| `RadioGroup.ItemControl size` | `md`         | Диаметр контрола только для moduix и масштаб точки индикатора. |

### Особенности поведения

`RadioGroup.Root` принимает свойства Ark, такие как `value`, `defaultValue`, `onValueChange(details)`, `name`, `form`, `orientation`, `disabled`, `invalid`, `readOnly`, `required`, `ids` и `asChild`.

Каждый `RadioGroup.Item` автоматически отрисовывает нативное поле ввода для отправки формы, валидации и сброса. Ark управляет контролируемым и неконтролируемым состоянием значения, roving focus, клавиатурной навигацией и формой обратного вызова `onValueChange(details)`.

`Field.Root` предоставляет видимую подпись, вспомогательный текст и сообщение об ошибке, но не передаёт своё состояние в `RadioGroup`. Передавайте `disabled`, `invalid`, `readOnly` и `required` самой группе. `Fieldset.Root` передаёт вложенным группам радиокнопок своё состояние Ark `disabled` и `invalid`. `Item` и `Option` автоматически сохраняют поведение нативной отправки и сброса формы.

## Стилизация

Стилизуйте `RadioGroup` через `className`, стабильные хуки `data-slot="radio-group-*"`, `data-scope`, `data-part`, `data-state` Ark и описанные ниже публичные CSS-переменные `--moduix-radio-*`.

### Хуки стилизации

- Хуки анатомии Ark: `data-scope="radio-group"` и `data-part` на root, label, item, item-control, item-text, item-hidden-input и indicator.
- Хуки состояний Ark: `data-state="checked|unchecked"`, `data-disabled`, `data-readonly`, `data-invalid`, `data-required`, `data-focus`, `data-focus-visible`, `data-hover`, `data-active` и `data-orientation`.
- Переменные индикатора Ark: `--transition-property`, `--left`, `--top`, `--width` и `--height`.
- Хуки moduix: `data-slot="radio-group-root"`, `radio-group-label`, `radio-group-item`, `radio-group-item-control`, `radio-group-item-text`, `radio-group-item-hidden-input` и `radio-group-indicator`.
