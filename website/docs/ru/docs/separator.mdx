## Справочник API

В Ark UI нет отдельного примитива для разделителей. moduix создаёт этот компонент с помощью официальной
[фабрики Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[ref](https://ark-ui.com/docs/guides/ref).

Свойства `orientation`, `variant` и `size` соответствуют привычной модели `Separator` из Chakra UI. См. [документацию
Chakra UI по компоненту Separator](https://chakra-ui.com/docs/components/separator), которая послужила основой для этого API.

## Анатомия

У `Separator` одна корневая часть.

```text
Separator / Separator.Root
└─ root[data-scope="separator"][data-part="root"][data-slot="separator-root"]
```

| Часть                          | Назначение                                                                |
| ------------------------------ | ------------------------------------------------------------------------- |
| `Separator` / `Separator.Root` | Корневой элемент-разделитель. Задаёт ориентацию, метаданные доступности и визуальный стиль. |

Стилизуйте корневой элемент с помощью `className` и CSS-свойств `--moduix-separator-*`. Используйте
`asChild`, если разделитель должен отрисовываться на другом элементе.

## Композиция

### Рекомендуемая композиция

Для большинства разделителей используйте короткую форму `<Separator />`. Это тот же корневой компонент,
что и `<Separator.Root />`, поэтому их можно менять местами без изменения поведения.

### Когда нужна собственная композиция

Используйте `asChild`, только если нужно отрисовать разделитель на другом элементе. `Separator` уже рендерит
семантический разделитель. Передайте один дочерний элемент, который может принять объединённые атрибуты
`role`, ARIA и `data-*`, а также `className` и `ref`.

### Свойства по умолчанию

| Свойство       | По умолчанию | Примечания                                    |
| -------------- | ------------ | --------------------------------------------- |
| `orientation`  | `horizontal` | `horizontal`, `vertical`                     |
| `variant`      | `solid`      | `solid`, `dashed`, `dotted`                  |
| `size`         | `sm`         | `xs`, `sm`, `md`, `lg`                       |
| `asChild`      | `false`      | Композиция фабрики Ark с одним дочерним элементом |
| `role`         | `separator`  | Передайте `presentation` для декоративной линии |

### Особенности поведения

- Если роль компонента равна `separator`, `Separator` задаёт `aria-orientation` на основе `orientation`.
  Для другой роли, например `presentation`, компонент не добавляет `aria-orientation`, даже если вы передадите его вручную.
- Используйте `role="presentation"`, если линия нужна только для оформления и не сообщает вспомогательным технологиям о структуре.
- Горизонтальный разделитель по умолчанию занимает всю доступную ширину.
- Вертикальный разделитель по умолчанию имеет высоту `1em`, поэтому хорошо выравнивается со строчным текстом и компактными рядами действий.
- `Separator` не интерактивен и не имеет состояния, колбэков, режима отключения или управления фокусом.
- Если нужен только промежуток, используйте примитивы раскладки или токены отступов.

## Стилизация

`Separator` предоставляет селекторы корневой части в стиле Ark и набор CSS-свойств `--moduix-separator-*`
для цвета, стиля границы, толщины и длины, зависящей от ориентации.

### Хуки стилизации

- `data-scope="separator"` и `data-part="root"` определяют корневую часть в стиле Ark.
- `data-slot="separator-root"` - стабильный селектор moduix.
- `data-orientation="horizontal"` и `data-orientation="vertical"` позволяют настраивать стили для каждой оси.
- `data-size="xs|sm|md|lg"` и `data-variant="solid|dashed|dotted"` раскрывают визуальные настройки.
- `className` и `style` применяются непосредственно к корневому элементу разделителя.
