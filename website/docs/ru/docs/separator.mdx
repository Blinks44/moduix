## Использование

<Usage />

Используйте `Separator`, чтобы визуально обозначить границу между связанными разделами. По умолчанию
используются `orientation="horizontal"`, `variant="solid"` и `size="sm"`.

## Примеры

### Варианты

Используйте `variant`, чтобы выбрать сплошную, пунктирную или точечную линию.

<Example name="separator/variants" />

### Размеры

Используйте `size`, чтобы выбрать толщину разделителя, а при необходимости переопределите её
CSS-свойствами.

<Example name="separator/sizes" />

### Вертикальный

Используйте `orientation="vertical"` для групп элементов в строке, например навигационных ссылок.

<Example name="separator/vertical" />

### Декоративный

Используйте `role="presentation"` для линии, которая нужна только для оформления и не сообщает
вспомогательным технологиям о структуре.

<Example name="separator/decorative" />

### Пользовательский элемент

Используйте `asChild`, если конкретный элемент должен получить роль разделителя, хуки стилизации и
переданный `ref`. В остальных случаях используйте `<Separator />` напрямую.

<Example name="separator/custom-element" />

## Композиция

Свойства `orientation`, `variant` и `size` соответствуют привычной модели `Separator` из Chakra UI. См. [документацию
Chakra UI по компоненту Separator](https://chakra-ui.com/docs/components/separator), которая послужила основой для этого API.

`Separator` состоит только из корневого элемента, поэтому не хранит состояние и не требует
провайдера. Для обычного разделителя используйте `<Separator />`. Если разделитель должен
размещаться на другом элементе, используйте
`asChild` с одним дочерним элементом, который принимает объединённые свойства `role`, ARIA,
`data-*`, class и ref. В React и Vue дочерний элемент передаётся напрямую, а в Solid используется форма `asChild={(props) => <hr {...props()} />}`; в Svelte используется сниппет `asChild`: `{#snippet asChild(props)}<hr {...props()} />{/snippet}`.

## Стилизация

Используйте `className` в React или `class` в Solid, Vue и Svelte для корневого элемента. В вариантах с
Tailwind применяйте нативные utility-классы и классы потребителя, а CSS-свойства ниже относятся к
вариантам с CSS Modules. Атрибуты данных и хуки `data-slot` общие для обоих способов стилизации.

### CSS-переменные

Наведите на переменную или выберите её, чтобы увидеть её в превью.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `Separator` | `separator-root` |

- `data-scope="separator"` и `data-part="root"` определяют корневую часть в стиле Ark.
- `data-orientation="horizontal"` и `data-orientation="vertical"` позволяют настраивать стили для каждой оси.
- `data-size="xs|sm|md|lg"` и `data-variant="solid|dashed|dotted"` раскрывают визуальные настройки.
- `className` или `class`, а также `style` применяются непосредственно к корневому элементу.

## Справочник API

Также принимает нативные пропсы своего элемента и `asChild`.

| Проп | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Направление линии: `horizontal` или `vertical`. |
| `variant` | `'solid' \| 'dashed' \| 'dotted'` | `'solid'` | Стиль линии: `solid`, `dashed` или `dotted`. |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg'` | `'sm'` | Толщина линии, от `xs` до `lg`. |
