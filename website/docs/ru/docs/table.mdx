## Справочник API

В Ark UI нет отдельного примитива для таблиц. moduix собирает `Table` через официальную [фабрику Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по [композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и работе с [ref](https://ark-ui.com/docs/guides/ref).

Каждая часть по умолчанию рендерит соответствующий нативный HTML-элемент, принимает его свойства и
`className`, передаёт `ref` и поддерживает `asChild`. При использовании `asChild` передавайте один
семантический элемент. У `Table.Empty` есть особенность: это свойство заменяет только созданную
`td`-ячейку.

## Базовый пример

Если таблица может не поместиться по ширине, оберните её в `Table.ScrollArea`. Затем соберите `Table`
из `Table.Header`, `Table.Body`, `Table.Row` и соответствующих частей для заголовков и ячеек. Такой
вариант подходит для счётов, сводок и таблиц с данными только для чтения в административных интерфейсах.

## Анатомия

Стандартная композиция остаётся близкой к нативной разметке таблицы:

```text
Table.ScrollArea (optional)
└─ Table / Table.Root
   ├─ Table.ColumnGroup (optional)
   │  └─ Table.Column
   ├─ Table.Caption (optional)
   ├─ Table.Header
   │  └─ Table.Row
   │     └─ Table.ColumnHeader
   ├─ Table.Body
   │  ├─ Table.Row
   │  │  └─ Table.Cell
   │  └─ Table.Empty (optional)
   └─ Table.Footer (optional)
```

| Часть                  | Назначение                                                                 |
| ---------------------- | -------------------------------------------------------------------------- |
| `Table` / `Table.Root` | Нативный корневой элемент `table` с типографикой, разделителями и атрибутами состояния. |
| `Table.ScrollArea`     | Необязательный контейнер с рамкой и горизонтальной прокруткой.             |
| `Table.ColumnGroup`    | Нативный `colgroup` для задания ширины столбцов.                           |
| `Table.Column`         | Нативный `col` с поддержкой `htmlWidth`.                                   |
| `Table.Caption`        | Необязательная подпись над или под таблицей; положение задаёт `side`.      |
| `Table.Header`         | Нативный `thead` для заголовков столбцов.                                  |
| `Table.Body`           | Нативный `tbody` для строк с данными.                                      |
| `Table.Footer`         | Нативный `tfoot` для итоговых строк.                                       |
| `Table.Row`            | Нативный `tr` с разделителями.                                             |
| `Table.ColumnHeader`   | Нативный `th` с поддержкой `numeric`.                                      |
| `Table.Cell`           | Нативный `td` с поддержкой `numeric`.                                      |
| `Table.Empty`          | Готовая строка и ячейка для пустого состояния внутри `Table.Body`.         |

## Композиция

### Рекомендуемая композиция

Для большинства таблиц с данными только для чтения используйте семантические части и добавляйте
`Table.ScrollArea`, если нужна рамка с горизонтальной прокруткой.

Указывайте `numeric` у `Table.ColumnHeader` и `Table.Cell` для сумм, счётчиков, процентов, показателей задержки
и других числовых показателей. Используйте `Table.Caption` для краткого названия или описания, а
`Table.Footer` - для итогов. Свойства `striped`, `interactive`, `showColumnBorder`, `stickyHeader`,
`size` и `variant` меняют внешний вид, но не добавляют состояние таблицы.

### Когда нужна собственная композиция

Не используйте `Table.ScrollArea`, если родительский контейнер уже отвечает за прокрутку, отступы,
границы или фон. Оставьте `Table`, а оформление контейнера задайте в своей разметке или компоненте.

`Table` не управляет сортировкой, фильтрацией, выбором, пагинацией, виртуализацией или действиями
над строками. Это визуальная и семантическая основа для более сложных решений. Для управления
состоянием и отображением данных через TanStack Table используйте руководство [Data Table](/recipes/data-table).

### Свойства по умолчанию

Все части принимают нативные свойства соответствующего HTML-элемента, а также поддерживают
`className`, передачу `ref` и `asChild`, как описано выше.

| Компонент            | Свойство           | По умолчанию    | Примечание                                                        |
| -------------------- | ------------------ | --------------- | ----------------------------------------------------------------- |
| `Table`              | `interactive`      | `false`         | Подсвечивает строки тела при наведении.                           |
| `Table`              | `showColumnBorder` | `false`         | Добавляет границы между видимыми столбцами.                       |
| `Table`              | `size`             | `'md'`          | Поддерживает `'sm'`, `'md'` и `'lg'`.                              |
| `Table`              | `stickyHeader`     | `false`         | Закрепляет `Table.Header` внутри контейнера прокрутки.            |
| `Table`              | `striped`          | `false`         | Чередует фон строк тела, кроме пустых строк.                       |
| `Table`              | `variant`          | `'line'`        | Поддерживает `'line'` и `'outline'`.                              |
| `Table.Caption`      | `side`             | `'bottom'`      | Поддерживает `'top'` и `'bottom'`.                                |
| `Table.Column`       | `htmlWidth`        | -               | Передаёт значение нативному атрибуту `width` элемента `col`.      |
| `Table.ColumnHeader` | `numeric`          | `false`         | Выравнивает содержимое по концу строки и использует табличные цифры. |
| `Table.Cell`         | `numeric`          | `false`         | Выравнивает содержимое по концу строки и использует табличные цифры. |
| `Table.Empty`        | `colSpan`          | обязательное    | Должно совпадать с текущим числом столбцов.                       |
| `Table.Empty`        | `children`         | `'No results.'` | Текст по умолчанию, если содержимое не передано.                  |

### Особенности поведения

- `Table.Empty` отображает полноценную строку пустого состояния. Передайте количество столбцов через `colSpan`.
  Свойство `asChild` заменяет только созданную ячейку, поэтому передавайте один семантический `td`;
  для настройки самой строки соберите `Table.Row` и `Table.Cell` напрямую. Созданная строка
  получает `data-empty`, но на неё не распространяются чередование фона и интерактивные стили.
- Строки заголовка и тела имеют общий нижний разделитель, а у последней строки тела граница убирается.
- При `interactive` строки с данными подсвечиваются при наведении и сохраняют этот контекст, когда
  фокус с клавиатуры получает вложенный элемент управления.
- `Table.Caption` использует приглушённую типографику и отступы от краёв таблицы.

### Доступность

`Table` использует нативные элементы таблицы, поэтому задавайте стандартные HTML-атрибуты для
связей между заголовками и ячейками. Добавляйте `scope="col"` к заголовкам столбцов, используйте
`Table.Caption` для краткого доступного названия или описания, а для сложных таблиц связывайте
заголовки с ячейками через `id` и `headers`. `Table` не добавляет навигацию с клавиатуры, выбор
строк или управление фокусом.

## Стилизация

Настраивайте `Table` через `className`, публичные хуки `data-slot`, `data-scope` и `data-part`,
атрибуты `data-side` и `data-numeric`, а также перечисленные ниже CSS-переменные `--moduix-table-*`.

### Хуки стилизации

Используйте часть или атрибут, которые отвечают за нужное оформление:

- `className` у `Table.ScrollArea` - граница, радиус и фон всего контейнера;
- `className` у `Table` - типографика и ограничения ширины;
- `data-slot="table-root"`, `table-scroll-area`, `table-column-group`, `table-column`, `table-caption`,
  `table-header`, `table-body`, `table-footer`, `table-row`, `table-column-header`, `table-cell` и
  `table-empty` - выбор отдельных частей;
- `data-side="top" | "bottom"` у `Table.Caption` - положение подписи;
- `data-numeric` у `Table.ColumnHeader` и `Table.Cell` - числовые столбцы;
- `data-empty` у строки, созданной `Table.Empty`, - пустое состояние;
- `data-size`, `data-variant`, `data-striped`, `data-interactive`, `data-sticky-header` и
  `data-show-column-border` у `Table` - состояния корня;
- `data-sticky="start" | "end"` у `Table.ColumnHeader` и `Table.Cell` - закреплённые столбцы.
