## Справочник API

В Ark UI нет отдельного примитива для таблиц. moduix собирает `Table` через официальную [фабрику Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по [композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и работе с [ref](https://ark-ui.com/docs/guides/ref).

Каждая часть по умолчанию рендерит соответствующий нативный HTML-элемент, принимает его свойства,
`className` в React или `class` в Solid и Vue, передаёт `ref` и поддерживает `asChild`. При использовании
`asChild` передавайте один семантический элемент. У `TableEmpty` есть особенность: это свойство
заменяет только созданную `td`-ячейку.

## Базовый пример

Если таблица может не поместиться по ширине, оберните её в `TableScrollArea`. Затем соберите `Table`
из `TableHeader`, `TableBody`, `TableRow` и соответствующих частей для заголовков и ячеек. Такой
вариант подходит для счётов, сводок и таблиц с данными только для чтения в административных интерфейсах.

## Анатомия

Стандартная композиция остаётся близкой к нативной разметке таблицы:

```text
TableScrollArea (optional)
└─ Table
   ├─ TableColumnGroup (optional)
   │  └─ TableColumn
   ├─ TableCaption (optional)
   ├─ TableHeader
   │  └─ TableRow
   │     └─ TableColumnHeader
   ├─ TableBody
   │  ├─ TableRow
   │  │  └─ TableCell
   │  └─ TableEmpty (optional)
   └─ TableFooter (optional)
```

| Часть                  | Назначение                                                                 |
| ---------------------- | -------------------------------------------------------------------------- |
| `Table`           | Нативный корневой элемент `table` с типографикой, разделителями и атрибутами состояния. |
| `TableScrollArea`     | Необязательный контейнер с рамкой и горизонтальной прокруткой.             |
| `TableColumnGroup`    | Нативный `colgroup` для задания ширины столбцов.                           |
| `TableColumn`         | Нативный `col`. Ширину задаёт нативный атрибут `width`.                     |
| `TableCaption`        | Необязательная подпись над или под таблицей; положение задаёт `side`.      |
| `TableHeader`         | Нативный `thead` для заголовков столбцов.                                  |
| `TableBody`           | Нативный `tbody` для строк с данными.                                      |
| `TableFooter`         | Нативный `tfoot` для итоговых строк.                                       |
| `TableRow`            | Нативный `tr` с разделителями.                                             |
| `TableColumnHeader`   | Нативный `th` с поддержкой `numeric`.                                      |
| `TableCell`           | Нативный `td` с поддержкой `numeric`.                                      |
| `TableEmpty`          | Готовая строка и ячейка для пустого состояния внутри `TableBody`.         |

## Композиция

Используйте `TableScrollArea`, если таблице нужен контейнер с рамкой и горизонтальной прокруткой.
Не используйте его, если родительская разметка уже отвечает за прокрутку, отступы, границы или
фон, и разместите нативные части таблицы в своём контейнере.

`TableEmpty` создаёт полную строку пустого состояния внутри `TableBody`, поэтому обязательный
`colSpan` должен совпадать с текущим числом столбцов. Его `asChild` заменяет только созданную
`td`-ячейку; если нужно настроить саму строку, соберите напрямую `TableRow` и `TableCell`.
`Table` отвечает только за представление: сортировка, фильтрация, выбор, пагинация, виртуализация
и действия над строками относятся к композиции более высокого уровня, например [Data Table](/blocks/data-table).

### Доступность

`Table` использует нативные элементы таблицы, поэтому задавайте стандартные HTML-атрибуты для
связей между заголовками и ячейками. Добавляйте `scope="col"` к заголовкам столбцов, используйте
`TableCaption` для краткого доступного названия или описания, а для сложных таблиц связывайте
заголовки с ячейками через `id` и `headers`. `Table` не добавляет навигацию с клавиатуры, выбор
строк или управление фокусом.

## Примеры

### Подпись и итоговая строка

Используйте `TableCaption side="top"`, если подпись должна находиться перед данными, а
`TableFooter` - для итогов или сводных значений.

<Example name="table/caption-and-footer" />

### Группа столбцов и границы

Используйте `TableColumnGroup` и `TableColumn`, чтобы задать нативную ширину столбцов, а
`showColumnBorder` - когда границы между столбцами должны быть видимыми.

<Example name="table/column-group-and-borders" />

### Пустое состояние

Используйте `TableEmpty`, если в теле таблицы нет строк. Значение `colSpan` должно совпадать с
текущим числом столбцов.

<Example name="table/empty-state" />

### Внутри Card

Размещайте `TableScrollArea` в `CardBody`, если таблица должна находиться на поверхности карточки.

<Example name="table/inside-card" />

### Числовые столбцы

Указывайте `numeric` и в заголовке, и в ячейках, чтобы суммы, проценты и другие числовые показатели
выравнивались одинаково.

<Example name="table/numeric-columns" />

### Действия в строках с меню

Поместите действия для строки в последний столбец. `Menu` добавит компактный список команд, не
меняя нативную структуру таблицы.

<Example name="table/row-actions-with-menu" />

### Размеры

Используйте `size` для выбора плотности: он меняет отступы ячеек и размер шрифта. Чтобы добавить
внешнюю рамку без `TableScrollArea`, передайте `Table` класс с `border`.

<Example name="table/sizes" />

### Закрепление заголовка и столбца

Используйте `stickyHeader` у корня и `data-sticky="start" | "end"` у ячеек, чтобы при прокрутке
заголовок и важный столбец оставались видимыми. Закреплённые ячейки сохраняют цвет строки при
чередовании, наведении и фокусе.

<Example name="table/sticky-header-and-column" />

### Чередование фона строк

Используйте `striped`, чтобы строки длинной таблицы с данными только для чтения было легче различать.

<Example name="table/striped-rows" />

### С компонентом ScrollArea

Используйте `ScrollArea` напрямую, если нужны стилизованные полосы прокрутки по обеим осям,
эффект затухания или API области прокрутки. `TableScrollArea` - это более простой контейнер с
рамкой и горизонтальной прокруткой. Сохраняйте структуру `ScrollArea` явной, чтобы `Table` оставался
лёгкой обёрткой над нативной таблицей.

<Example name="table/with-scrollarea" />

### Расширенная настройка

Используйте собственный контейнер вместо `TableScrollArea`, если родительская разметка уже
отвечает за фон или прокрутку. При этом композиция нативных частей таблицы останется явной, а
оформление контейнера будет полностью под вашим контролем.

## Стилизация

Настраивайте `Table` через `className` в React или `class` в Solid и Vue, публичные хуки `data-slot`,
`data-scope` и `data-part`, атрибуты `data-side` и `data-numeric`, а также перечисленные ниже
CSS-переменные `--moduix-table-*`. Варианты Tailwind используют нативные utility-классы и классы
потребителя, а переменные ниже относятся к вариантам CSS Modules.

### Хуки стилизации

Используйте часть или атрибут, которые отвечают за нужное оформление:

- `className` у `TableScrollArea` - граница, радиус и фон всего контейнера;
- `className` у `Table` - типографика и ограничения ширины;
- `data-slot="table-root"`, `table-scroll-area`, `table-column-group`, `table-column`, `table-caption`,
  `table-header`, `table-body`, `table-footer`, `table-row`, `table-column-header`, `table-cell` и
  `table-empty` - выбор отдельных частей;
- `data-side="top" | "bottom"` у `TableCaption` - положение подписи;
- `data-numeric` у `TableColumnHeader` и `TableCell` - числовые столбцы;
- `data-empty` у строки, созданной `TableEmpty`, - пустое состояние;
- `data-size`, `data-striped`, `data-interactive`, `data-sticky-header` и
  `data-show-column-border` у `Table` - состояния корня;
- `data-sticky="start" | "end"` у `TableColumnHeader` и `TableCell` - закреплённые столбцы.
