## Справочник API

В Ark UI нет отдельного примитива для таблиц. moduix собирает `Table` через официальную [фабрику Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по [композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и работе с [ref](https://ark-ui.com/docs/guides/ref).

Каждая часть по умолчанию рендерит соответствующий нативный HTML-элемент, принимает его свойства,
`className` в React или `class` в Solid, передаёт `ref` и поддерживает `asChild`. При использовании
`asChild` передавайте один семантический элемент. У `Table.Empty` есть особенность: это свойство
заменяет только созданную `td`-ячейку.

## Анатомия

Стандартная композиция остаётся близкой к нативной разметке таблицы:

```text
Table.ScrollArea (optional)
└─ Table / Table.Root
   ├─ Table.ColumnGroup (optional)
   │  └─ Table.Column
   ├─ Table.Caption (optional)
   ├─ Table.Header
   │  └─ Table.Row
   │     └─ Table.ColumnHeader
   ├─ Table.Body
   │  ├─ Table.Row
   │  │  └─ Table.Cell
   │  └─ Table.Empty (optional)
   └─ Table.Footer (optional)
```

| Часть                  | Назначение                                                                 |
| ---------------------- | -------------------------------------------------------------------------- |
| `Table` / `Table.Root` | Нативный корневой элемент `table` с типографикой, разделителями и атрибутами состояния. |
| `Table.ScrollArea`     | Необязательный контейнер с рамкой и горизонтальной прокруткой.             |
| `Table.ColumnGroup`    | Нативный `colgroup` для задания ширины столбцов.                           |
| `Table.Column`         | Нативный `col` с поддержкой `htmlWidth`.                                   |
| `Table.Caption`        | Необязательная подпись над или под таблицей; положение задаёт `side`.      |
| `Table.Header`         | Нативный `thead` для заголовков столбцов.                                  |
| `Table.Body`           | Нативный `tbody` для строк с данными.                                      |
| `Table.Footer`         | Нативный `tfoot` для итоговых строк.                                       |
| `Table.Row`            | Нативный `tr` с разделителями.                                             |
| `Table.ColumnHeader`   | Нативный `th` с поддержкой `numeric`.                                      |
| `Table.Cell`           | Нативный `td` с поддержкой `numeric`.                                      |
| `Table.Empty`          | Готовая строка и ячейка для пустого состояния внутри `Table.Body`.         |

## Композиция

Используйте `Table.ScrollArea`, если таблице нужен контейнер с рамкой и горизонтальной прокруткой.
Не используйте его, если родительская разметка уже отвечает за прокрутку, отступы, границы или
фон, и разместите нативные части таблицы в своём контейнере.

`Table.Empty` создаёт полную строку пустого состояния внутри `Table.Body`, поэтому обязательный
`colSpan` должен совпадать с текущим числом столбцов. Его `asChild` заменяет только созданную
`td`-ячейку; если нужно настроить саму строку, соберите напрямую `Table.Row` и `Table.Cell`.
`Table` отвечает только за представление: сортировка, фильтрация, выбор, пагинация, виртуализация
и действия над строками относятся к композиции более высокого уровня, например [Data Table](/recipes/data-table).

### Доступность

`Table` использует нативные элементы таблицы, поэтому задавайте стандартные HTML-атрибуты для
связей между заголовками и ячейками. Добавляйте `scope="col"` к заголовкам столбцов, используйте
`Table.Caption` для краткого доступного названия или описания, а для сложных таблиц связывайте
заголовки с ячейками через `id` и `headers`. `Table` не добавляет навигацию с клавиатуры, выбор
строк или управление фокусом.

## Стилизация

Настраивайте `Table` через `className` в React или `class` в Solid, публичные хуки `data-slot`,
`data-scope` и `data-part`, атрибуты `data-side` и `data-numeric`, а также перечисленные ниже
CSS-переменные `--moduix-table-*`. Варианты Tailwind используют нативные utility-классы и классы
потребителя, а переменные ниже относятся к вариантам CSS Modules.

### Хуки стилизации

Используйте часть или атрибут, которые отвечают за нужное оформление:

- `className` у `Table.ScrollArea` - граница, радиус и фон всего контейнера;
- `className` у `Table` - типографика и ограничения ширины;
- `data-slot="table-root"`, `table-scroll-area`, `table-column-group`, `table-column`, `table-caption`,
  `table-header`, `table-body`, `table-footer`, `table-row`, `table-column-header`, `table-cell` и
  `table-empty` - выбор отдельных частей;
- `data-side="top" | "bottom"` у `Table.Caption` - положение подписи;
- `data-numeric` у `Table.ColumnHeader` и `Table.Cell` - числовые столбцы;
- `data-empty` у строки, созданной `Table.Empty`, - пустое состояние;
- `data-size`, `data-variant`, `data-striped`, `data-interactive`, `data-sticky-header` и
  `data-show-column-border` у `Table` - состояния корня;
- `data-sticky="start" | "end"` у `Table.ColumnHeader` и `Table.Cell` - закреплённые столбцы.
