## Справочник API

В Ark UI нет отдельного примитива для списка. moduix использует официальный
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory), чтобы собирать нативные элементы `ul`,
`ol` и `li`. Подробнее о базовой модели можно узнать в руководствах Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[передаче ref](https://ark-ui.com/docs/guides/ref).

## Какой компонент выбрать

Используйте `List` для статического сгруппированного контента: например, шагов, характеристик или метаданных.
Компонент сохраняет нативную семантику `ul` и `ol` и добавляет управление отступами, типографикой, цветом и
маркерами.

Если пользователю нужно перемещаться по списку с клавиатуры и выбирать один или несколько вариантов, используйте
[Listbox](/docs/listbox). `Listbox` управляет фокусом, коллекцией и выбором элементов.

## Базовый пример

`List` по умолчанию отрисовывает семантический `<ul>`. Используйте `ListItem`, если нужны стабильная часть
элемента и её хуки стилизации, или передавайте обычные `<li>`, когда дополнительная обёртка не нужна. Корневой
`List` управляет отступами, типографикой, цветом и маркерами. По умолчанию `ul` получает маркеры `disc`, а `ol` —
`decimal`; передайте `disc`, `decimal` или `none` в `marker`, чтобы задать их явно. С `asChild` передайте `marker`,
соответствующий дочернему элементу.

## Анатомия

```text
List
└─ ListItem | li
   └─ ListIndicator
```

| Часть                | Назначение                                                                                     |
| -------------------- | ----------------------------------------------------------------------------------------------- |
| `List`     | Семантический корень списка, который отрисовывает `ul` или `ol` и управляет маркерами, отступами, размером и цветом. |
| `ListItem` | Необязательная часть, которая отрисовывает `li`, передаёт нативные атрибуты и ref и поддерживает `asChild`.          |
| `ListIndicator` | Необязательный `span` в начале пункта для иконки вместо нативного маркера. |

## Композиция

Используйте `List` как корень. Его непосредственными дочерними элементами должны быть `ListItem`
или нативные `li`, поскольку отступы корня и стилизация маркеров рассчитаны на непосредственные элементы списка.
Используйте `ListItem`, если нужны его стабильный слот, `className`/`class` или `asChild`; в остальных случаях
достаточно обычного `li`. Используйте `asChild`, только когда компонент приложения отрисовывает один семантический
`ul`, `ol` или `li` и передаёт полученные props и ref. В Solid для этого используется вариант `asChild` с
render-функцией, а в Vue используется семантический элемент в слоте компонента. У `List` нет машины состояний и callback-
обработчиков, поэтому выбор с клавиатуры относится к `Listbox`.

### Пользовательский корень

Используйте `List asChild`, когда компонент приложения должен сам отрисовать семантический элемент списка. В React
он должен передать полученные props и ref одному `<ul>` или `<ol>`, в Solid нужно использовать вариант с
render-функцией, а в Vue передайте один семантический дочерний элемент.

### Нативные элементы

Используйте нативные `li`, если вам не нужна экспортируемая часть `ListItem`.

### Упорядоченный список

Используйте `as="ol"`, чтобы отрисовать упорядоченный список и сохранить стилизацию корневого элемента moduix.
Нативные свойства `start` и `reversed` передаются корневому элементу упорядоченного списка. Маркеры задаёт `marker`,
поэтому нативный атрибут `type` их не меняет; для букв или римских цифр задайте `list-style-type` классом.

Поместите вложенный `List` внутрь `ListItem`. Вложенный список начинается на один `gap` ниже текста пункта,
используя собственный `gap`, поэтому дополнительные отступы не нужны.

### С индикатором

Используйте `ListIndicator`, чтобы показать иконку вместо нативного маркера, и задайте корню `marker="none"`.
Пункт с индикатором становится flex-строкой: иконка получает размер `1em`, выравнивается по первой строке, а
длинный текст переносится рядом с ней, а не под неё.

### Расширенная настройка

Используйте `ListItem asChild`, когда пользовательский компонент должен сам отрисовать `<li>`. Он обязан передать
полученные props и ref и сохранить семантический элемент `<li>`. Во всех остальных случаях достаточно использовать

## Стилизация

Стилизуйте `List` с помощью свойства класса (`className` в React и `class` в Solid и Vue), экспортируемых атрибутов
`data-*` в стиле Ark и нативного `li::marker`. Варианты на CSS Modules построены на токенах foundation и не имеют
переменных компонента: класс на корневом элементе переопределяет стили из слоя компонентов.

### Хуки стилизации

`List` предоставляет следующие публичные хуки стилизации:

- корневой элемент: `data-scope="list"`, `data-part="root"`, `data-slot="list-root"`
- элемент: `data-scope="list"`, `data-part="item"`, `data-slot="list-item"`
- индикатор: `data-scope="list"`, `data-part="indicator"`, `data-slot="list-indicator"`
- `data-gap="xs" | "sm" | "md" | "lg" | "xl" | "2xl"` для стилей, связанных с отступами
- `data-marker="disc" | "decimal" | "none"` для стилей, связанных с маркерами
- `data-size="xs" | "sm" | "md" | "lg" | "xl"` для стилей размера типографики
- `data-tone="default" | "muted" | "primary" | "destructive"` для семантических цветов
- нативный селектор `li::marker` для переопределения цвета или толщины маркера
