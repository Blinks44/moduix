## Справочник API

В Ark UI нет отдельного примитива списка. В moduix этот компонент построен на официальной
[фабрике Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и использует подходы Ark к
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[передаче ref](https://ark-ui.com/docs/guides/ref).

## Анатомия

Типичная композиция выглядит так:

```text
List / List.Root
└─ List.Item | li
```

| Часть                 | Назначение                                                               |
| -------------------- | ------------------------------------------------------------------------ |
| `List` / `List.Root` | Семантический корень списка. Управляет маркерами, отступами, размером и тоном.                  |
| `List.Item`          | Необязательная часть по модели Ark, которая предоставляет стабильный слот `li` и поддержку `asChild`. |

## Композиция

### Рекомендуемая композиция

Используйте `<List>` для неупорядоченных списков, а `as="ol"`, когда нужен упорядоченный список.
Применяйте `asChild`, только если нужно заменить `List` одним семантическим элементом `<ul>` или `<ol>`,
либо `List.Item` одним семантическим элементом `<li>`.

### Когда нужна собственная композиция

`List` не предоставляет внутреннюю машину состояний, готовые средства для вложенных списков или API для
отрисовки маркеров. Для обычной стилизации элементов используйте `className` и нативный CSS, например
`li::marker`. Применяйте `asChild` только к компоненту из вашего приложения. Он должен передавать дальше ref
и пропы и отрисовывать нужный семантический элемент.

Элементы должны оставаться непосредственными дочерними элементами списка. Встроенные отступы и стилизация
маркеров применяются только к таким элементам.

### Свойства по умолчанию

| Проп      | По умолчанию     | Примечания                                                                |
| --------- | ---------------- | ------------------------------------------------------------------------- |
| `gap`     | `sm`             | Отступ между непосредственными дочерними элементами списка.                    |
| `size`    | `md`             | Размер текста из типографической шкалы.                                        |
| `tone`    | `default`        | Семантический цвет текста и маркеров.                                          |
| `marker`  | семантический режим `auto` | `disc` для `ul`, нативные маркеры браузера для `ol` или `none`.          |
| `as`      | `ul`             | Выбирает нативный элемент списка: `ul` или `ol`.                               |
| `asChild` | `false`          | Заменяет семантический элемент списка одним дочерним элементом из вашего кода. |

### Особенности поведения

- При `as="ol"` доступны нативные пропы упорядоченного списка, например `start`, `reversed` и `type`.
- Используйте `marker="none"`, чтобы скрыть маркеры и сохранить семантику списка. Когда маркеры отключены,
  `List` добавляет `role="list"`, если вы явно не передали другое значение `role`.
- `List.Item` необязателен. Используйте обычные элементы `li`, если отдельный слот `List.Item` вам не нужен.

### Хуки стилизации

`List` предоставляет небольшой набор публичных хуков стилизации:

- корневой элемент: `data-scope="list"`, `data-part="root"`, `data-slot="list-root"`
- элемент: `data-scope="list"`, `data-part="item"`, `data-slot="list-item"`
- `data-gap="xs" | "sm" | "md" | "lg" | "xl" | "2xl"` для стилей, связанных с отступами
- `data-marker="auto" | "disc" | "decimal" | "none"` для стилей, связанных с маркерами
- `data-size="xs" | "sm" | "md" | "lg" | "xl"` для стилей размера типографики
- `data-tone="default" | "muted" | "subtle" | "primary" | "destructive"` для семантических цветов
- нативный селектор `li::marker` для переопределения цвета или толщины маркера
