## Справочник API

В Ark UI нет отдельного примитива для списка. moduix использует Ark factory, чтобы собирать нативные элементы
`ul`, `ol` и `li`. Подробнее о базовой модели можно узнать в руководствах Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[передаче ref](https://ark-ui.com/docs/guides/ref).

## Какой компонент выбрать

Используйте `List` для статического сгруппированного контента: например, шагов, характеристик или метаданных.
Компонент сохраняет нативную семантику `ul` и `ol` и добавляет управление отступами, типографикой, цветом и
маркерами.

Если пользователю нужно перемещаться по списку с клавиатуры и выбирать один или несколько вариантов, используйте
[Listbox](/docs/listbox). `Listbox` управляет фокусом, коллекцией и выбором элементов.

## Базовый пример

`List` по умолчанию отрисовывает семантический `<ul>`. Используйте `List.Item`, если нужны стабильный слот
элемента и его хуки стилизации, или передавайте обычные `<li>`, когда дополнительная обёртка не нужна.
Корневой `List` управляет отступами, типографикой, цветом и маркерами.

## Анатомия

Обычная композиция проста:

```text
List / List.Root
└─ List.Item | li
```

| Часть                 | Назначение                                                                                             |
| -------------------- | ------------------------------------------------------------------------------------------------------ |
| `List` / `List.Root` | Семантический корень списка, который отрисовывает `ul` или `ol` и управляет маркерами, отступами, размером и цветом. |
| `List.Item`          | Необязательная часть, которая отрисовывает `li`, передаёт нативные атрибуты и ref и поддерживает `asChild`.          |

## Композиция

### Рекомендуемая композиция

Используйте `<List>` для неупорядоченного списка, а `<List as="ol">` для упорядоченного. Нативные свойства `ol`,
например `start`, `reversed` и `type`, передаются корневому элементу. Используйте `List.Item`, если нужны его
стабильные хуки стилизации или `asChild`. В остальных случаях достаточно обычных `li`.

### Когда нужна собственная композиция

Используйте `asChild` только с компонентом, который отрисовывает один семантический элемент и передаёт ему
полученные props и ref. Для корня это должен быть `ul` или `ol`, а для элемента списка - `li`.

`List` не содержит машины состояний, средств для управления вложенными списками или отдельного API для отрисовки
маркеров. Для обычной стилизации элементов используйте `className` и нативный CSS, например `li::marker`.

Элементы должны оставаться непосредственными дочерними элементами списка. Встроенные отступы и стилизация маркеров
применяются только к непосредственным элементам списка.

### Свойства по умолчанию

Ниже перечислены свойства корневого `List`. `List.Item` принимает нативные свойства `li`, а также `className` и
`asChild`.

| Свойство  | По умолчанию            | Примечания                                                                                                      |
| --------- | ----------------------- | --------------------------------------------------------------------------------------------------------------- |
| `gap`     | `sm`                    | Расстояние между непосредственными элементами списка.                                                           |
| `size`    | `md`                    | Размер текста по типографической шкале.                                                                         |
| `tone`    | `default`               | Семантический цвет текста и маркеров.                                                                           |
| `marker`  | `auto` (семантический режим) | `auto` не нужно передавать явно: для `ul` используются маркеры `disc`, а для `ol` сохраняются стандартные маркеры браузера. Значения `disc`, `decimal` и `none` задают маркер явно. |
| `as`      | `ul`                    | Отрисовывает корень как нативный элемент `ul` или `ol`.                                                         |
| `asChild` | `false`                 | Использует один дочерний элемент из вашего кода как корневой семантический элемент списка.                     |

### Особенности поведения

- Нативные атрибуты корня передаются отрисованному `ul` или `ol`, а нативные атрибуты элемента списка передаются `List.Item`.
- Переданный ref указывает на отрисованный семантический корневой элемент или элемент списка.
- Используйте `marker="none"`, чтобы скрыть маркеры и сохранить семантику списка. В этом случае `List` добавляет
  `role="list"`, если вы явно не указали другое значение `role`.
- Отступы корня реализованы через flex `gap`, по умолчанию направление вертикальное. Если CSS меняет направление
  или включает перенос, `gap` продолжает работать по выбранной схеме.
- `List.Item` необязателен. Используйте обычные `li`, если отдельная часть списка вам не нужна.

### Хуки стилизации

`List` предоставляет следующие публичные хуки стилизации:

- корневой элемент: `data-scope="list"`, `data-part="root"`, `data-slot="list-root"`
- элемент: `data-scope="list"`, `data-part="item"`, `data-slot="list-item"`
- `data-gap="xs" | "sm" | "md" | "lg" | "xl" | "2xl"` для стилей, связанных с отступами
- `data-marker="auto" | "disc" | "decimal" | "none"` для стилей, связанных с маркерами
- `data-size="xs" | "sm" | "md" | "lg" | "xl"` для стилей размера типографики
- `data-tone="default" | "muted" | "subtle" | "primary" | "destructive"` для семантических цветов
- нативный селектор `li::marker` для переопределения цвета или толщины маркера
