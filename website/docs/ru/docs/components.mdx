# Компоненты

moduix предоставляет доступные и компонуемые компоненты для всех выпущенных адаптеров с общими CSS-токенами.
Каждая реализация сохраняет одинаковое публичное поведение и использует нативные API своей среды.
Многие интерактивные компоненты построены на примитивах Ark UI и явно раскрывают композицию.

Каталог ниже доступен во всех выпущенных адаптерах с CSS Modules. Tailwind-пакеты содержат компоненты
с завершённым нативным переносом стилей и постепенно приближаются к тому же каталогу. Выберите категорию,
затем откройте страницу компонента через боковую панель или поиск. На каждой странице есть пример
для копирования, публичная анатомия, точки настройки стилей и важные пояснения, если
они нужны именно для этого компонента.

## С чего начать

- Откройте [Быстрый старт](/docs/quick-start), чтобы выбрать между установкой пакета и копированием исходных
  файлов в проект.
- Прочитайте [Паттерны композиции](/docs/composition-patterns), прежде чем объединять части компонентов в обёртки
  приложения.
- Используйте [Темы](/docs/themes) и [Токены](/docs/tokens) для системных изменений внешнего вида. Алиасы
  компонентов оставляйте для осознанных локальных исключений.
- Начните с [Рецептов](/recipes), если нужен готовый для копирования паттерн интерфейса из нескольких компонентов.
