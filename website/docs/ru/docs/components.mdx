# Компоненты

moduix — это стилизованные, компонуемые обёртки над Ark UI с единым языком дизайн-токенов. Выберите подходящую
категорию ниже, а полный каталог ищите через сайдбар или поиск. На странице каждого компонента вы найдёте дерево
публичных частей, примеры, поведение, согласованное с Ark UI, и локальные CSS-переменные.

<ComponentGallery />

## Перед началом работы

- В [Быстром старте](/docs/quick-start) выберите установку через пакет или копирование исходного кода в проект.
- Прочитайте [Паттерны композиции](/docs/composition-patterns), прежде чем скрывать части компонентов в обёртках
  приложения.
- Используйте [Темы](/docs/themes) и [Токены](/docs/tokens) для системных изменений внешнего вида, а алиасы
  компонентов оставляйте для осознанных исключений.
- Начните с [Рецептов](/recipes), если вам нужен готовый паттерн интерфейса, а не отдельный примитив.
