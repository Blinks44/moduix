# Компоненты

moduix - это доступные и компонуемые React-компоненты с общими CSS-токенами. Многие интерактивные компоненты
построены на примитивах Ark UI, при этом их композиция явно представлена в публичном API. Выберите категорию ниже,
а затем откройте страницу нужного компонента через боковую панель или поиск. На каждой странице есть базовый пример,
который можно скопировать, описание публичных частей, особенностей поведения и доступных способов стилизации.

## С чего начать

- Откройте [Быстрый старт](/docs/quick-start), чтобы выбрать между установкой пакета и копированием исходных
  файлов в проект.
- Прочитайте [Паттерны композиции](/docs/composition-patterns), прежде чем объединять части компонентов в обёртки
  приложения.
- Используйте [Темы](/docs/themes) и [Токены](/docs/tokens) для системных изменений внешнего вида. Алиасы
  компонентов оставляйте для осознанных локальных исключений.
- Начните с [Рецептов](/recipes), если нужен готовый для копирования паттерн интерфейса из нескольких компонентов.
