## Анатомия

```text
HoverCard
├─ HoverCard.Trigger
└─ Поддерево всплывающего слоя (автоматически помещается в портал)
   └─ HoverCard.Positioner
      └─ HoverCard.Content
         ├─ HoverCard.Arrow
         │  └─ HoverCard.ArrowTip
         └─ содержимое

HoverCard.RootProvider
└─ то же дерево частей, связанное с состоянием moduix useHoverCard()
```

| Часть                      | Назначение                                                                    |
| -------------------------- | ----------------------------------------------------------------------------- |
| `HoverCard`                | Корневое состояние, задержки, позиционирование, ids, управление появлением и внешние взаимодействия. |
| `HoverCard.RootProvider`   | Отрисовывает то же дерево Hover Card на основе состояния moduix `useHoverCard()`.            |
| `HoverCard.Trigger`        | Элемент, реагирующий на наведение и фокус. Используйте `asChild` для ссылки или собственного семантического элемента. |
| `HoverCard.Positioner`     | Плавающий слой, предоставляющий CSS-переменные Ark для позиционирования.                    |
| `HoverCard.Content`        | Видимая поверхность всплывающего окна, которое закрывается при взаимодействии снаружи.       |
| `HoverCard.Arrow`          | Контейнер позиционируемой стрелки. По умолчанию отрисовывает `HoverCard.ArrowTip`.           |
| `HoverCard.ArrowTip`       | Наконечник стрелки, оформляемый с помощью переменных Ark для стрелки.                        |

Для совместимости доступен и `HoverCard.Root`. В коде приложения используйте короткую форму корневого
компонента `HoverCard`.

## Композиция

Корневой компонент автоматически помещает `HoverCard.Positioner` в портал. Установите `portalled={false}`, чтобы
оставить его в текущем дереве DOM, или передайте `portalRef`, чтобы выбрать другой контейнер. Оставляйте структурные
части явными: так позиционирование, содержимое и стрелку можно настраивать независимо.

### Когда нужна собственная композиция

Используйте `asChild` в `HoverCard.Trigger` для ссылки или собственной семантической кнопки.
Отрисовывайте `HoverCard.ArrowTip` напрямую только если нужно изменить его разметку. Используйте
`HoverCard.RootProvider` с moduix `useHoverCard()`, когда состоянием нужно делиться с элементами за пределами дерева карточки.
Для чтения состояния внутри дерева используйте `HoverCard.Context` или `useHoverCardContext()`.

### Свойства по умолчанию

По умолчанию содержимое оверлея в портале монтируется при первом открытии и удаляется после анимации закрытия.
Установите `unmountOnExit={false}`, чтобы не удалять его после первого открытия. Устанавливайте оба свойства жизненного
цикла в `false` только если содержимое нужно отрендерить сразу.

| Свойство               | По умолчанию | Примечания                                                                    |
| ---------------------- | ------------ | ----------------------------------------------------------------------------- |
| `closeDelay`           | `300`        | Задержка в мс между уходом указателя с триггера или содержимого и закрытием.  |
| `openDelay`            | `600`        | Задержка в мс между наведением на триггер и открытием.                         |
| `lazyMount`            | `true`       | Откладывает монтирование содержимого до первого открытия.                     |
| `unmountOnExit`        | `true`       | Удаляет содержимое после анимации закрытия.                                    |
| `skipAnimationOnMount` | `false`      | Не отключает начальную анимацию появления.                                    |

### Особенности поведения

`onOpenChange` получает объект `details` от Ark, например `{ open }`; читайте состояние через `details.open`. Для
нескольких триггеров используйте `Trigger value` и `onTriggerValueChange`. Свойство `ids` позволяет задать стабильные
идентификаторы для триггера, содержимого, `HoverCard.Positioner` и стрелки, чтобы корректно связать эти части для доступности.
Свойства Ark, управляющие присутствием, включая `present`, `immediate` и `onExitComplete`, передаются без изменений.

Если пользователь предпочитает меньше анимации, Hover Card отключает движение триггера и содержимого. Длинные слова
без пробелов переносятся внутри содержимого, а не выходят за границы карточки.

Используйте Hover Card только для дополнительных сведений и предпросмотров. Всё, что нужно для понимания или выполнения
задачи, должно быть доступно и без открытия карточки.

### Хуки стилизации

Каждая отрисовываемая часть принимает `className`. Кроме того, moduix добавляет атрибуты `data-slot="hover-card-*"` к
триггеру, `HoverCard.Positioner`, содержимому, стрелке и наконечнику. `HoverCard` и `HoverCard.RootProvider` только предоставляют
состояние и не создают DOM-элементы, поэтому у них нет собственных хуков стилизации. Ark добавляет к своим частям
`data-scope="hover-card"` и `data-part`. Для стилизации по состоянию используйте `data-state="open|closed"`,
`data-placement`, `data-side`, `data-value`, `data-current`, `data-nested` и `data-has-nested`.

На `HoverCard.Positioner` доступны `--reference-width`, `--reference-height`, `--available-width`,
`--available-height`, `--x`, `--y`, `--z-index` и `--transform-origin`. На `HoverCard.Content` доступны
`--layer-index` и `--nested-layer-count`; на `HoverCard.Arrow` доступны `--arrow-size`, `--arrow-size-half`,
`--arrow-background` и `--arrow-offset`.
