## Выбор подходящего компонента

Используйте `Tooltip` для коротких неинтерактивных подсказок. Выбирайте `Popover`, если во
всплывающем окне нужны более подробные сведения или действия. Используйте `HoverCard`, когда
триггер должен показывать дополнительный предпросмотр, например профиля или статьи.

## Базовый пример

Соберите карточку из явных частей Ark. `HoverCard.Trigger` открывает карточку, а
`HoverCard.Positioner` и `HoverCard.Content` задают её всплывающее содержимое. В базовой
композиции стрелка не используется.

## Анатомия

```text
HoverCard / HoverCard.Root
├─ HoverCard.Trigger
└─ Всплывающий слой (автоматически выводится через портал)
   └─ HoverCard.Positioner
      └─ HoverCard.Content
         ├─ HoverCard.Arrow
         │  └─ HoverCard.ArrowTip
         └─ содержимое

HoverCard.RootProvider
└─ то же дерево частей, связанное с состоянием moduix useHoverCard()
```

| Часть                          | Назначение                                                                    |
| ------------------------------ | ----------------------------------------------------------------------------- |
| `HoverCard` / `HoverCard.Root` | Управляет состоянием, жизненным циклом, задержками, позиционированием, идентификаторами и взаимодействием за пределами карточки. |
| `HoverCard.RootProvider`       | Подключает части к состоянию, созданному через `useHoverCard()`.              |
| `HoverCard.Context`            | Передаёт потомкам текущее состояние через render prop.                       |
| `HoverCard.Trigger`            | Интерактивный элемент, открывающий карточку при наведении или фокусе. Используйте `asChild`, чтобы передать роль триггера ссылке или другому семантическому элементу. |
| `HoverCard.Positioner`         | Позиционирует всплывающий слой и предоставляет CSS-переменные Ark.           |
| `HoverCard.Content`            | Видимая область карточки, которая закрывается при взаимодействии за её пределами. |
| `HoverCard.Arrow`              | Необязательная обёртка позиционируемой стрелки, по умолчанию выводящая `HoverCard.ArrowTip`. |
| `HoverCard.ArrowTip`           | Наконечник стрелки, оформляемый с помощью переменных Ark.                     |

`HoverCard` - короткая форма корневого компонента, а `HoverCard.Root` - её алиас в пространстве
имён. В коде приложения используйте короткую форму.

## Композиция

Корневой компонент автоматически выводит `HoverCard.Positioner` через портал. Передайте
`portalled={false}`, чтобы оставить его в текущем DOM-дереве, или укажите `portalRef`, чтобы
выбрать другой контейнер портала. Оставляйте структурные части явными, чтобы независимо
настраивать и стилизовать позиционер, содержимое и стрелку.

### Рекомендуемая композиция

В большинстве случаев используйте `HoverCard` вместе с `HoverCard.Trigger`,
`HoverCard.Positioner` и `HoverCard.Content`. Добавляйте `HoverCard.Arrow`, только если нужно
визуально связать окно с триггером.

### Когда нужна собственная композиция

Используйте `asChild` у `HoverCard.Trigger`, если триггером должна быть ссылка или другой
семантический элемент. Укажите одного потомка, который может получать фокус и сохранять поведение
триггера. Используйте `HoverCard.RootProvider` с `useHoverCard()`, когда
состоянием нужно делиться с элементами управления за пределами дерева карточки. Для чтения
состояния внутри дерева используйте `HoverCard.Context` или `useHoverCardContext()`. Отрисовывайте
`HoverCard.ArrowTip` напрямую только тогда, когда нужно изменить его разметку.

### Свойства по умолчанию

Содержимое, выводимое через портал, по умолчанию монтируется при первом открытии и удаляется после
анимации закрытия. Установите `unmountOnExit={false}`, чтобы оставить его смонтированным после
первого открытия. Устанавливайте оба свойства жизненного цикла в `false`, только если содержимое
нужно отрендерить сразу.

| Свойство               | По умолчанию | Примечания                                                                     |
| ---------------------- | ------------ | ------------------------------------------------------------------------------ |
| `openDelay`            | `600`        | Задержка перед открытием после наведения или получения фокуса триггером.        |
| `closeDelay`           | `300`        | Задержка перед закрытием после ухода с триггера или содержимого.               |
| `lazyMount`            | `true`       | Монтирует содержимое только после первого открытия.                            |
| `unmountOnExit`        | `true`       | Удаляет содержимое после анимации закрытия.                                    |
| `skipAnimationOnMount` | `false`      | Сохраняет начальную анимацию появления.                                        |
| `portalled`            | `true`       | Выводит позиционер через портал.                                               |
| `portalRef`            | `-`          | Задаёт пользовательский контейнер портала.                                     |
| `positioning`          | `-`          | Параметры позиционирования Ark.                                                |
| `ids`                  | `-`          | Стабильные идентификаторы триггера, содержимого, позиционера и стрелки.         |
| `defaultOpen`          | `-`          | Начальное открытое состояние в неконтролируемом режиме.                        |
| `open`                 | `-`          | Управляемое открытое состояние.                                                |
| `disabled`             | `false`      | Отключает взаимодействие с карточкой.                                          |

### Особенности поведения

- `onOpenChange(details)` получает объект, например `{ open }`. Читайте следующее состояние в
  `details.open`.
- Если несколько триггеров используют одно содержимое, задайте каждому `value` и используйте
  `onTriggerValueChange(details)`. Активный триггер доступен в `details.value`.
- `HoverCard.RootProvider`, `HoverCard.Context`, `useHoverCard` и `useHoverCardContext` доступны
  для расширенной работы с состоянием. Создайте состояние через `useHoverCard()`, если оно должно
  жить за пределами дерева карточки, а затем передайте его в `RootProvider` через свойство `value`.
- Свойства Ark, управляющие присутствием, включая `present`, `immediate` и `onExitComplete`,
  передаются без изменений.
- `HoverCard.Trigger` получает стандартные стили moduix только без `asChild`. Если используется
  `asChild`, стилизацией управляет дочерний элемент.
- Если пользователь предпочитает уменьшенное движение, анимация триггера и содержимого
  отключается. Длинные слова без пробелов переносятся внутри содержимого, а не выходят за границы
  карточки.
- Компонент Hover Card предназначен только для дополнительных предпросмотров. Всё необходимое для
  понимания или выполнения задачи должно оставаться доступным без открытия карточки.

### Точки для стилизации

У каждой отрисовываемой части можно задать `className`. Кроме того, moduix добавляет атрибуты
`data-slot="hover-card-*"` к триггеру, позиционеру, содержимому, стрелке и наконечнику стрелки.
`HoverCard` и `HoverCard.RootProvider` только предоставляют состояние и не создают DOM-элементы,
поэтому у них нет собственных точек стилизации. Ark добавляет к своим частям `data-scope="hover-card"`
и `data-part`. Для стилизации с учётом состояния используйте `data-state="open|closed"`,
`data-placement`, `data-side`, `data-value`, `data-current`, `data-nested` и `data-has-nested`.

`HoverCard.Positioner` предоставляет `--reference-width`, `--reference-height`, `--available-width`,
`--available-height`, `--x`, `--y`, `--z-index` и `--transform-origin`. `HoverCard.Content`
предоставляет `--layer-index` и `--nested-layer-count`. `HoverCard.Arrow` предоставляет
`--arrow-size`, `--arrow-size-half`, `--arrow-background` и `--arrow-offset`.
