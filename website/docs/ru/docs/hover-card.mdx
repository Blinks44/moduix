Соберите карточку из явных частей Ark. `HoverCardTrigger` открывает карточку, а
`HoverCardPositioner` и `HoverCardContent` задают её всплывающее содержимое. В базовой
композиции стрелка не используется. Поместите содержимое в `HoverCardBody`, если оно может
превысить доступную высоту: оно будет прокручиваться, а `HoverCardContent` останется
необрезанным для дополнительной стрелки.

## Выбор подходящего компонента

Используйте `Tooltip` для коротких неинтерактивных подсказок. Выбирайте `Popover`, если во
всплывающем окне нужны более подробные сведения или действия. Используйте `HoverCard`, когда
триггер должен показывать дополнительный предпросмотр, например профиля или статьи.

## Композиция

`HoverCard` управляет состоянием и по умолчанию выводит `HoverCardPositioner` через портал.
Передайте `portalled={false}` внутри другого слоя или укажите `portalRef` для собственного
контейнера. Используйте `HoverCardRootProvider` с `useHoverCard()`, если состояние должно жить
за пределами дерева карточки: React читает его как объект, Solid через accessor, а Vue напрямую
предоставляет реактивное состояние шаблону.

Оставляйте `HoverCardArrow` внутри `HoverCardContent`, а длинный предпросмотр помещайте в
`HoverCardBody`: `Content` сохраняет видимость стрелки, а `Body` становится областью прокрутки.
Используйте `asChild` с одним фокусируемым потомком, если триггером должна быть ссылка или другой
семантический элемент. Если несколько триггеров используют одно содержимое, задайте каждому
`value` и обновляйте внешнее содержимое через `onTriggerValueChange(details)`.

## Стилизация

`HoverCardTrigger` без `asChild` выглядит как встроенная ссылка основного цвета; подчёркивание
следует `currentColor`, поэтому класс с `color` меняет оба. `HoverCardContent` шириной 14–24rem и
высотой не больше 24rem в пределах доступного места. Анимация содержимого читает общие переменные
`--moduix-popup-motion-*`.

Используйте `className` в React или `class` в Solid и Vue на экспортируемых частях. Варианты Tailwind
используют нативные utility-классы и классы потребителя. Варианты CSS Modules построены на токенах
foundation и не имеют переменных компонента: класс на части переопределяет стили компонента из слоя.
Атрибуты состояния и хуки `data-slot` общие для обоих вариантов стилизации.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `HoverCardTrigger` | `hover-card-trigger` |
| `HoverCardPositioner` | `hover-card-positioner` |
| `HoverCardContent` | `hover-card-content` |
| `HoverCardArrow` | `hover-card-arrow` |
| `HoverCardArrowTip` | `hover-card-arrow-tip` |
| `HoverCardBody` | `hover-card-body` |

Moduix добавляет атрибуты `data-slot="hover-card-*"` к триггеру, позиционеру, содержимому, стрелке,
наконечнику стрелки и области содержимого. `HoverCard` и `HoverCardRootProvider` только
предоставляют состояние и не создают DOM-элементы, поэтому у них нет собственных точек стилизации. Ark добавляет к своим частям `data-scope="hover-card"`
и `data-part`. Для стилизации с учётом состояния используйте `data-state="open|closed"`,
`data-placement`, `data-side`, `data-value`, `data-current`, `data-nested` и `data-has-nested`.

`HoverCardPositioner` предоставляет `--reference-width`, `--reference-height`, `--available-width`,
`--available-height`, `--x`, `--y`, `--z-index` и `--transform-origin`. `HoverCardContent`
предоставляет `--layer-index` и `--nested-layer-count`. `HoverCardArrow` предоставляет
`--arrow-size`, `--arrow-size-half`, `--arrow-background` и `--arrow-offset`.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `Tab` | Фокус на триггере открывает карточку после задержки. |
| `Esc` | Закрывает карточку. |
