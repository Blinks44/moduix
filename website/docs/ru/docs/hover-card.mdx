## Выбор подходящего компонента

Используйте `Tooltip` для коротких неинтерактивных подсказок. Выбирайте `Popover`, если во
всплывающем окне нужны более подробные сведения или действия. Используйте `HoverCard`, когда
триггер должен показывать дополнительный предпросмотр, например профиля или статьи.

## Базовый пример

HoverCard доступен для React и Solid в вариантах CSS Modules и Tailwind. Превью на этой странице
работает на React CSS Modules, а во вкладках для фреймворков показан нативный код с тем же
публичным контрактом.

Соберите карточку из явных частей Ark. `HoverCard.Trigger` открывает карточку, а
`HoverCard.Positioner` и `HoverCard.Content` задают её всплывающее содержимое. В базовой
композиции стрелка не используется. Поместите содержимое в `HoverCard.Body`, если оно может
превысить доступную высоту: оно будет прокручиваться, а `HoverCard.Content` останется
необрезанным для дополнительной стрелки.

## Анатомия

```text
HoverCard / HoverCard.Root
├─ HoverCard.Trigger
└─ Всплывающий слой (автоматически выводится через портал)
   └─ HoverCard.Positioner
      └─ HoverCard.Content
         ├─ HoverCard.Arrow
         │  └─ HoverCard.ArrowTip
         └─ HoverCard.Body
            └─ содержимое

HoverCard.RootProvider
└─ то же дерево частей, связанное с состоянием moduix useHoverCard()
```

| Часть                          | Назначение                                                                    |
| ------------------------------ | ----------------------------------------------------------------------------- |
| `HoverCard` / `HoverCard.Root` | Управляет состоянием, жизненным циклом, задержками, позиционированием, идентификаторами и взаимодействием за пределами карточки. |
| `HoverCard.RootProvider`       | Подключает части к состоянию, созданному через `useHoverCard()`.              |
| `HoverCard.Context`            | Передаёт потомкам текущее состояние через render prop.                       |
| `HoverCard.Trigger`            | Интерактивный элемент, открывающий карточку при наведении или фокусе. Используйте `asChild`, чтобы передать роль триггера ссылке или другому семантическому элементу. |
| `HoverCard.Positioner`         | Позиционирует всплывающий слой и предоставляет CSS-переменные Ark.           |
| `HoverCard.Content`            | Видимая область карточки, которая закрывается при взаимодействии за её пределами. |
| `HoverCard.Arrow`              | Необязательная обёртка позиционируемой стрелки, по умолчанию выводящая `HoverCard.ArrowTip`. |
| `HoverCard.ArrowTip`           | Наконечник стрелки, оформляемый с помощью переменных Ark.                     |
| `HoverCard.Body`               | Необязательная прокручиваемая область содержимого для ограниченных предпросмотров. |

`HoverCard` - короткая форма корневого компонента, а `HoverCard.Root` - её алиас в пространстве
имён. В коде приложения используйте короткую форму.

## Композиция

`HoverCard` управляет состоянием и по умолчанию выводит `HoverCard.Positioner` через портал.
Передайте `portalled={false}` внутри другого слоя или укажите `portalRef` для собственного
контейнера. Используйте `HoverCard.RootProvider` с `useHoverCard()`, если состояние должно жить
за пределами дерева карточки: React читает его как объект, а Solid через accessor.

Оставляйте `HoverCard.Arrow` внутри `HoverCard.Content`, а длинный предпросмотр помещайте в
`HoverCard.Body`: `Content` сохраняет видимость стрелки, а `Body` становится областью прокрутки.
Используйте `asChild` с одним фокусируемым потомком, если триггером должна быть ссылка или другой
семантический элемент. Если несколько триггеров используют одно содержимое, задайте каждому
`value` и обновляйте внешнее содержимое через `onTriggerValueChange(details)`.

## Стилизация

Для структурных стилей используйте `className` в React или `class` в Solid на экспортируемых
частях. Варианты Tailwind используют нативные utility-классы и классы потребителя, а переменные
ниже настраивают варианты CSS Modules. Атрибуты состояния и хуки `data-slot` общие для обоих
вариантов стилизации.

### Точки для стилизации

Moduix добавляет атрибуты `data-slot="hover-card-*"` к триггеру, позиционеру, содержимому, стрелке,
наконечнику стрелки и области содержимого. `HoverCard` и `HoverCard.RootProvider` только
предоставляют состояние и не создают DOM-элементы, поэтому у них нет собственных точек стилизации.
Ark добавляет к своим частям `data-scope="hover-card"`
и `data-part`. Для стилизации с учётом состояния используйте `data-state="open|closed"`,
`data-placement`, `data-side`, `data-value`, `data-current`, `data-nested` и `data-has-nested`.

`HoverCard.Positioner` предоставляет `--reference-width`, `--reference-height`, `--available-width`,
`--available-height`, `--x`, `--y`, `--z-index` и `--transform-origin`. `HoverCard.Content`
предоставляет `--layer-index` и `--nested-layer-count`. `HoverCard.Arrow` предоставляет
`--arrow-size`, `--arrow-size-half`, `--arrow-background` и `--arrow-offset`.
