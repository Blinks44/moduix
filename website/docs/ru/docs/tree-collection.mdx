# Tree Collection

Древовидная коллекция хранит иерархические данные для `TreeView` и собственных древовидных
интерфейсов. Она не рисует интерфейс и не управляет выбором, фокусом или клавиатурной навигацией.
Используйте её, чтобы создать типизированную иерархию, находить связи между узлами, обходить и
фильтровать дерево и получать новые версии коллекции без изменения исходной.

## Базовый пример

`label`, `children` и необязательное `disabled`. Корневой узел служит контейнером и не входит в
результат `getValues()`.

Используйте коллекцию как источник данных для `TreeView`. Отрисовывайте
`collection.rootNode.children` и передавайте каждой ветви её числовую позицию как `indexPath`.

## Запросы и навигация

`indexPath` хранит числовую позицию узла на каждом уровне ниже корня. Значения являются стабильными
идентификаторами: храните их в состоянии приложения, а индексный путь получайте заново, когда он
нужен для операции.

```tsx
const treePath = collection.getIndexPath('src/components/Tree.tsx')!; // [0, 1, 1]

collection.findNode('src');
collection.findNodes(['src', 'public']);
collection.at(treePath);
collection.getValue(treePath); // 'src/components/Tree.tsx'
collection.getValuePath(treePath); // ['src', 'src/components', 'src/components/Tree.tsx']
collection.getDepth('src/components/Tree.tsx'); // 3
collection.getValues(); // descendant values in traversal order
```

| API                              | Результат                                           |
| -------------------------------- | --------------------------------------------------- |
| `findNode(value, rootNode?)`     | Первый узел со значением или `undefined`.           |
| `findNodes(values, rootNode?)`   | Узлы для нескольких значений.                       |
| `getIndexPath(valueOrValuePath)` | Числовой путь для значения или явного пути значений. |
| `at(indexPath)`                  | Узел по индексному пути или `undefined`.            |
| `getValue(indexPath)`            | Значение по индексному пути или `undefined`.        |
| `getValuePath(indexPath)`        | Значения предков и целевого узла.                   |
| `getDepth(value)`                | Глубина узла ниже корня.                            |
| `getValues(rootNode?)`           | Значения потомков в порядке обхода.                |

Для нестандартной структуры используйте нормализованные методы доступа:

| API                          | Результат                                       |
| ---------------------------- | ---------------------------------------------- |
| `getNodeChildren(node)`      | Дочерние узлы.                                 |
| `getNodeChildrenCount(node)` | Известное число дочерних узлов или `undefined`. |
| `getNodeValue(node)`         | Значение узла.                                 |
| `stringifyNode(node)`        | Текст узла.                                    |
| `stringify(value)`           | Текст узла для значения или `null`.             |
| `getNodeDisabled(node)`      | Признак отключения.                            |
| `isRootNode(node)`           | Является ли узел корнем коллекции.              |
| `isSameNode(node, other)`    | Имеют ли два узла одно значение.                |

Перемещайтесь по дереву в порядке обхода или среди соседних узлов:

```tsx
collection.getFirstNode();
collection.getLastNode();
collection.getNextNode('src');
collection.getPreviousNode('README.md');

collection.getParentNode('src/components/Tree.tsx');
collection.getParentNodes('src/components/Tree.tsx');
collection.getDescendantNodes('src');
collection.getDescendantValues('src');

collection.getNextSibling(treePath);
collection.getPreviousSibling(treePath);
collection.getSiblingNodes(treePath);
collection.contains(collection.getIndexPath('src')!, treePath);
```

`getFirstNode`, `getLastNode`, `getNextNode` и `getPreviousNode` принимают `{ skip }`. Функция
получает `{ value, node, indexPath }` и исключает узел из обхода, если возвращает `true`. Передайте
`{ withBranch: true }` в `getDescendantNodes` или `getDescendantValues`, чтобы включить ветви.

`sort(values)` упорядочивает значения по их положению в дереве. `isEqual(other)` сравнивает
коллекции, а `toJSON()` возвращает значения потомков.

## Обход и фильтрация

Используйте `isBranchNode` и `getBranchValues`, чтобы работать с ветвями. `getBranchValues` также
принимает фильтр `depth` и ту же функцию `skip`, что и методы навигации.

```tsx
const src = collection.findNode('src');

if (src) collection.isBranchNode(src);
collection.getBranchValues();

const flatNodes = collection.flatten();
// Each result keeps the original node fields and adds _index, _parent, and _children.

collection.visit({
  onEnter(node, indexPath) {
    console.log(collection.getNodeValue(node), indexPath.length);

    if (collection.getNodeValue(node) === 'src') return 'skip';
  },
});
```

`visit` вызывает `onEnter` для каждого узла. Верните `'skip'`, чтобы пропустить потомков ветви, или
`'stop'`, чтобы завершить обход. `filter(predicate)` возвращает новую коллекцию, сохраняет
иерархию до найденных узлов и получает функцию-предикат с аргументами `(node, indexPath)`:

```tsx
const filteredTree = collection.filter((node) =>
  collection.stringifyNode(node).toLocaleLowerCase().includes('tree'),
);
```

## Неизменяемые обновления

Методы обновления возвращают новую коллекцию и не меняют исходную. Индексные пути относятся к одной
версии коллекции. После вставки, удаления, замены или перемещения узлов получите пути заново из
возвращённой коллекции и не используйте старые числовые пути.

```tsx
const buttonPath = collection.getIndexPath('src/components/Button.tsx')!;
const readmePath = collection.getIndexPath('README.md')!;
const srcPath = collection.getIndexPath('src')!;

const withFile = collection.insertAfter(buttonPath, [
  { value: 'src/components/Select.tsx', label: 'Select.tsx' },
]);
const withoutReadme = collection.remove([readmePath]);
const renamed = collection.replace(buttonPath, {
  value: 'src/components/Button.new.tsx',
  label: 'Button.new.tsx',
});
const moved = collection.move([readmePath], srcPath);
```

`insertBefore` и `insertAfter` возвращают `undefined`, если целевой путь недопустим. Проверяйте пути,
полученные из динамических данных, перед вызовом этих методов.

| API                         | Операция                                      |
| --------------------------- | --------------------------------------------- |
| `copy(rootNode)`            | Создать коллекцию из нового корня.            |
| `replace(indexPath, node)`  | Заменить один узел.                           |
| `remove(indexPaths)`        | Удалить одно или несколько поддеревьев.       |
| `insertBefore(path, nodes)` | Вставить соседей перед узлом.                 |
| `insertAfter(path, nodes)`  | Вставить соседей после узла.                  |
| `move(fromPaths, toPath)`   | Переместить поддеревья в другое место.        |
| `filter(predicate)`         | Вернуть отфильтрованное дерево.               |

Если коллекция отрисовывается через `TreeView`, сохраните результат обновления в состоянии, которое
владеет деревом, и отрисуйте его новый `rootNode`.
