# Tree Collection

## API

<PrimitiveReference href="https://ark-ui.com/docs/collections/tree-collection" />

Древовидная коллекция приводит иерархические данные к единой структуре для `TreeView` и
пользовательских древовидных интерфейсов. С её помощью можно находить узлы по значениям, получать
сведения о родителях и потомках, работать с индексными путями, обходить дерево и создавать новые
версии коллекции без изменения исходной.

```tsx
import { createFileTreeCollection, createTreeCollection } from '@moduix/react/tree-view';
```

## Создание коллекции

В стандартной структуре у узла есть поля `value`, `label`, `children` и необязательное поле
`disabled`:

```tsx
const tree = createTreeCollection({
  rootNode: {
    value: 'root',
    label: 'Project',
    children: [
      {
        value: 'src',
        label: 'src',
        children: [
          { value: 'button', label: 'Button.tsx' },
          { value: 'input', label: 'Input.tsx' },
        ],
      },
      { value: 'readme', label: 'README.md' },
    ],
  },
});
```

Корневой узел служит контейнером, поэтому `getValues()` его не возвращает. Передайте коллекцию
напрямую в `TreeView`, а узлы отрисуйте из `collection.rootNode.children`.

## Tree View

Коллекция хранит иерархию. `TreeView` управляет раскрытием ветвей, фокусом, клавиатурной
навигацией и выбором. Отрисовывайте каждую ветвь рекурсивно, передавая узел и индексный путь из
коллекции.

## Пользовательские узлы

Если у узлов другие имена полей, укажите с помощью функций, где искать нужные данные:

```tsx
type NavigationNode = {
  id: string;
  name: string;
  items?: NavigationNode[];
  unavailable?: boolean;
};

const navigation: NavigationNode = {
  id: 'root',
  name: 'Documentation',
  items: [
    {
      id: 'guides',
      name: 'Guides',
      items: [{ id: 'getting-started', name: 'Getting started' }],
    },
    { id: 'components', name: 'Components' },
  ],
};

const tree = createTreeCollection<NavigationNode>({
  rootNode: navigation,
  nodeToValue: (node) => node.id,
  nodeToString: (node) => node.name,
  nodeToChildren: (node) => node.items ?? [],
  nodeToChildrenCount: (node) => node.items?.length,
  isNodeDisabled: (node) => node.unavailable ?? false,
});
```

| Параметр              | Назначение                                                          |
| --------------------- | ------------------------------------------------------------------- |
| `rootNode`            | Корневой контейнер для всей иерархии.                              |
| `nodeToValue`         | Возвращает стабильное строковое значение узла.                     |
| `nodeToString`        | Возвращает отображаемый текст и текст для поиска.                  |
| `nodeToChildren`      | Возвращает дочерние узлы.                                          |
| `nodeToChildrenCount` | Возвращает известное число дочерних узлов, включая лениво загружаемые. |
| `isNodeDisabled`      | Возвращает, отключён ли узел.                                      |

## Поиск узлов

Используйте значения, чтобы находить узлы, а индексные пути, чтобы определять их положение. Индексный
путь описывает числовую позицию узла на каждом уровне дерева:

```tsx
const path = tree.getIndexPath('input')!; // [0, 1]
tree.at(path); // Input.tsx node
tree.getValue(path); // 'input'
tree.getValuePath(path); // ['src', 'input']
tree.getDepth('input'); // 2
```

| API                              | Результат                                                 |
| -------------------------------- | -------------------------------------------------------- |
| `findNode(value)`                | Первый узел с этим значением.                            |
| `findNodes(values)`              | Узлы для нескольких значений.                            |
| `getIndexPath(valueOrValuePath)` | Числовой путь для значения или явного пути значений.     |
| `at(indexPath)`                  | Узел по индексному пути.                                 |
| `getValue(indexPath)`            | Значение по индексному пути.                             |
| `getValuePath(indexPath)`        | Значения предков и целевое значение.                     |
| `getDepth(value)`                | Глубина узла ниже корня.                                 |
| `getValues(rootNode?)`           | Все значения потомков в порядке обхода.                  |
| `getNodeChildren(node)`          | Нормализованные дочерние узлы.                           |
| `getNodeChildrenCount(node)`     | Известное число дочерних узлов или `undefined`.          |
| `getNodeValue(node)`             | Нормализованное значение узла.                           |
| `stringifyNode(node)`            | Нормализованный текст узла.                              |
| `stringify(value)`               | Текст узла для значения или `null`, если узел не найден. |
| `getNodeDisabled(node)`          | Нормализованный признак отключения узла.                 |
| `isRootNode(node)`               | Является ли узел корнем коллекции.                       |
| `isSameNode(node, other)`        | Имеют ли два узла одно и то же значение.                  |

`sort(values)` сортирует значения в порядке их расположения в дереве. `isEqual(other)` сравнивает
коллекции, а `toJSON()` возвращает значения коллекции.

## Навигация

Переходите между узлами и получайте сведения об их родителях, предках и потомках:

```tsx
tree.getFirstNode();
tree.getLastNode();
tree.getNextNode('button');
tree.getPreviousNode('input');

tree.getParentNode('input'); // src node
tree.getParentNodes('input'); // ancestor nodes
tree.getDescendantNodes('src'); // Button.tsx and Input.tsx nodes
tree.getDescendantValues('src'); // ['button', 'input']
```

`getFirstNode`, `getLastNode`, `getNextNode` и `getPreviousNode` принимают объект опций с функцией
`skip`. Эта функция исключает указанные узлы из обхода.

Методы для соседних узлов работают с индексными путями:

```tsx
const path = tree.getIndexPath('button')!;

tree.getNextSibling(path);
tree.getPreviousSibling(path);
tree.getSiblingNodes(path);
```

`contains(parentPath, valuePath)` проверяет, содержит ли один индексный путь другой.
`getDescendantNodes` и `getDescendantValues` принимают `{ withBranch: true }`, чтобы возвращать
узлы ветвей вместе с листьями.

## Обход

Проверяйте, является ли узел ветвью, преобразуйте дерево в плоский список или посещайте каждый узел:

```tsx
const src = tree.findNode('src');

if (src) tree.isBranchNode(src);
tree.getBranchValues();
tree.flatten();
```

`flatten()` возвращает узлы с метаданными `_index`, `_parent` и `_children`. Это удобно для
виртуализированного или плоского представления дерева.

Используйте `visit`, когда нужно обработать каждый узел:

```tsx
tree.visit({
  onEnter(node, indexPath) {
    console.log(tree.getNodeValue(node), indexPath.length);

    if (tree.getNodeValue(node) === 'src') {
      return 'skip';
    }
  },
});
```

## Фильтрация

`filter` возвращает новое дерево с подходящими узлами и сохраняет иерархию, необходимую, чтобы до них
добраться:

```tsx
const filteredTree = tree.filter((node) =>
  tree.stringifyNode(node).toLocaleLowerCase().includes('input'),
);
```

Используйте возвращённую коллекцию для отрисовки. Исходное дерево не изменяется.

## Обновления

Каждое изменение неизменяемо: методы возвращают новую `TreeCollection`, а исходную коллекцию не
меняют. В примерах ниже все операции начинаются с `tree`. Чтобы объединить изменения в цепочку,
используйте коллекцию, возвращённую предыдущей операцией:

```tsx
const srcPath = tree.getIndexPath('src')!;
const buttonPath = tree.getIndexPath('button')!;
const readmePath = tree.getIndexPath('readme')!;

const withFile = tree.insertAfter(buttonPath, [{ value: 'select', label: 'Select.tsx' }]);

const withoutReadme = tree.remove([readmePath]);
const renamed = tree.replace(buttonPath, {
  value: 'button',
  label: 'Button.new.tsx',
});
const moved = tree.move([readmePath], srcPath);
```

Индексные пути описывают позиции в конкретной версии коллекции. После вставки, удаления, перестановки
или перемещения узлов отбросьте сохранённые пути. Перед следующей операцией получите их заново из
возвращённой коллекции. В состоянии приложения храните стабильные значения узлов, а не числовые пути.

`insertBefore` и `insertAfter` могут вернуть `undefined`, если целевой путь недопустим. Проверяйте
пути, полученные из динамических данных, перед вызовом метода.

| API                         | Операция                                             |
| --------------------------- | ---------------------------------------------------- |
| `copy(rootNode)`            | Создаёт коллекцию из заменяющего корня.              |
| `replace(indexPath, node)`  | Заменяет один узел.                                  |
| `remove(indexPaths)`        | Удаляет одно или несколько поддеревьев.              |
| `insertBefore(path, nodes)` | Вставляет соседние узлы перед узлом.                 |
| `insertAfter(path, nodes)`  | Вставляет соседние узлы после узла.                  |
| `move(fromPaths, toPath)`   | Перемещает поддеревья в другое место.                |
| `filter(predicate)`         | Возвращает отфильтрованное дерево.                   |

## Дерево файлов

Используйте `createFileTreeCollection`, если исходные данные уже представлены списком путей:

```tsx
const files = createFileTreeCollection([
  'src/components/Button.tsx',
  'src/components/Input.tsx',
  'src/utils/format.ts',
  'README.md',
]);

files.getBranchValues(); // ['src', 'components', 'utils']
```

Полную композицию `TreeView`, раскрытие, выбор, ленивую загрузку и рекурсивные узлы смотрите в
разделе [Tree View](/docs/tree-view). Для удалённых дочерних узлов используйте пример асинхронной
загрузки в этом разделе и обновляйте коллекцию только после успешного ответа.
