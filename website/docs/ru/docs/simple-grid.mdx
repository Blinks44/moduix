## Справочник API

`SimpleGrid` не является примитивом Ark UI. moduix предоставляет небольшой компонент раскладки,
построенный с помощью фабрики Ark. Он следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling)
и [ссылкам на элементы](https://ark-ui.com/docs/guides/ref). Его свойства `columns` и
`minChildWidth` заимствуют модель раскладки у [SimpleGrid](https://chakra-ui.com/docs/components/simple-grid)
из Chakra UI, но адаптивные свойства Chakra UI для стилизации здесь не поддерживаются.

## Базовый пример

`SimpleGrid` доступен для React и Solid в пакетах с CSS Modules и Tailwind. Предпросмотр на этой
странице работает на React с CSS Modules, а во вкладках показан нативный исходный код для того же
публичного контракта.

Используйте `minChildWidth`, если число равных колонок должно меняться вместе с доступной шириной.
Компонент использует `auto-fit` и `minmax()` из CSS Grid: числовые значения считаются пикселями,
а строки могут содержать любую корректную длину CSS.

Число колонок меняется вместе с шириной корневого элемента, а дочерние элементы остаются его
непосредственными элементами сетки. Если внутри дочернего элемента есть непереносимый контент,
добавьте для него `min-width: 0` или подходящее правило переполнения.

## Анатомия

`SimpleGrid` рендерит один корневой элемент CSS Grid и не добавляет обёртки вокруг дочерних элементов.

```text
SimpleGrid
└─ root[data-scope="simple-grid"][data-part="root"][data-slot="simple-grid-root"]
   └─ children
```

| Часть        | Назначение                                           |
| ------------ | ---------------------------------------------------- |
| `SimpleGrid` | Корневой элемент, создающий равные колонки CSS Grid. |

## Композиция

Используйте короткую форму `<SimpleGrid>` для корневого элемента; `SimpleGrid.Root` — равнозначный
алиас для совместимости. Выберите либо `minChildWidth` для автоматического числа колонок, либо
`columns` для фиксированного числа. Если передать оба свойства, `minChildWidth` имеет приоритет.

Используйте `asChild`, когда корневым элементом сетки должен быть семантический тег, например `ul`,
`section` или `nav`. Он требует ровно одного дочернего элемента, который становится отрендеренным
корнем. В React передавайте `asChild` как boolean, а в Solid используйте форму с функцией-рендерером,
которая возвращает этот элемент. Для именованных областей, колонок разной ширины или элементов,
занимающих несколько колонок, не передавайте свойства раскладки и задайте шаблон сетки в своём CSS.

## Стилизация

`SimpleGrid` не определяет собственных CSS-переменных. Свойства раскладки записываются в inline-стили
корневого элемента. Если `grid-template-columns` должен задаваться таблицей стилей, не передавайте
`columns` и `minChildWidth`.

Используйте `className` в React и `class` в Solid для структурной стилизации. Варианты Tailwind
используют обычные utility-классы и классы приложения; атрибуты данных и хук `data-slot` общие для
обоих вариантов стилизации.

### Хуки стилизации

- `className` или `class` стилизует отрендеренный корневой элемент: его ширину, расположение, фон и
  адаптивную раскладку.
- `data-scope="simple-grid"` и `data-part="root"` соответствуют соглашениям Ark о стилизации.
- `data-slot="simple-grid-root"` — стабильный селектор moduix для локального CSS.
- `columns`, `minChildWidth`, `gap`, `rowGap` и `columnGap` записывают inline-стили и имеют приоритет
  над объявлениями из классов приложения.
- `style` объединяется после этих свойств и является последним переопределением для экземпляра.
- Компонент не предоставляет хуков стилизации для состояния или анимации.
