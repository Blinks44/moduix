## Справочник API

`SimpleGrid` не является примитивом Ark UI. moduix предоставляет небольшой компонент раскладки,
построенный с помощью фабрики Ark. Он следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling)
и [ссылкам на элементы](https://ark-ui.com/docs/guides/ref). Его свойства `columns` и `minChildWidth`
заимствуют модель раскладки у [SimpleGrid](https://chakra-ui.com/docs/components/simple-grid) из Chakra UI,
но адаптивные свойства Chakra UI для стилизации здесь не поддерживаются.

## Базовый пример

Импортируйте `SimpleGrid` из `@moduix/react/simple-grid`. Используйте `minChildWidth`, если число
равных колонок должно меняться вместе с доступной шириной. Компонент использует `auto-fit` и
`minmax()` из CSS Grid: числовые значения считаются пикселями, а строки могут содержать любую
корректную длину CSS.

Число колонок меняется вместе с шириной корневого элемента, а дочерние элементы остаются его
непосредственными элементами сетки. Если внутри дочернего элемента есть непереносимый контент,
добавьте для него `min-width: 0` или подходящее правило переполнения.

## Анатомия

`SimpleGrid` рендерит один корневой элемент CSS Grid и не добавляет обёрток вокруг дочерних элементов.

```text
SimpleGrid
└─ root[data-scope="simple-grid"][data-part="root"][data-slot="simple-grid-root"]
   └─ children
```

| Часть        | Назначение                                           |
| ------------ | ---------------------------------------------------- |
| `SimpleGrid` | Корневой элемент, создающий равные колонки CSS Grid. |

## Композиция

### Рекомендуемая композиция

Используйте короткую форму `<SimpleGrid>` для корневого элемента. `SimpleGrid.Root` рендерит тот же
компонент и остаётся алиасом для совместимости.

Выберите один режим раскладки:

- `minChildWidth` позволяет браузеру автоматически разместить столько равных колонок, сколько
  помещается в доступную ширину.
- `columns` создаёт заданное число равных колонок.

Если элементам нужен визуальный интервал, задайте `gap`, `rowGap` или `columnGap`. Используйте
`asChild`, когда корневым элементом должен быть семантический тег, например `ul`, `section` или `nav`.
`asChild` требует ровно одного дочернего элемента, который становится корневым элементом.

### Когда нужна другая композиция

Перейдите на локальный CSS, если раскладке нужны именованные области, колонки разной ширины,
элементы, занимающие несколько колонок, или разные шаблоны при срабатывании медиазапросов и
контейнерных запросов. Не передавайте `columns` и `minChildWidth`, а задайте
`grid-template-columns` в таблице стилей.

### Свойства по умолчанию

| Свойство        | По умолчанию       | Примечания                                              |
| --------------- | ------------------ | ------------------------------------------------------- |
| `columns`       | `1`                | Конечное положительное целое число равных колонок       |
| `minChildWidth` | не задано          | CSS-длина; числа считаются пикселями                    |
| `gap`           | значение браузера  | CSS-длина; числа считаются пикселями                    |
| `rowGap`        | значение браузера  | CSS-длина; числа считаются пикселями                    |
| `columnGap`     | значение браузера  | CSS-длина; числа считаются пикселями                    |
| `asChild`       | `false`            | Композиция Ark с одним дочерним элементом               |
| `className`     | не задано          | Применяется к отрендеренному корневому элементу         |
| `style`         | не задано          | Применяется последним как переопределение экземпляра    |

### Особенности поведения

- Если не задан ни `columns`, ни `minChildWidth`, сетка содержит одну равную колонку.
- Если заданы оба свойства, `minChildWidth` имеет приоритет над `columns`.
- `columns={3}` создаёт три равные колонки и не добавляет обёртки вокруг дочерних элементов.
- `minChildWidth={160}` создаёт столько колонок, сколько помещается, и трактует число как `160px`.
- Числовое значение `columns` должно быть конечным положительным целым числом. Числовое значение
  `minChildWidth` должно быть конечным неотрицательным числом.
- Режим `auto-fit` предотвращает переполнение, если сетка становится уже `minChildWidth`.
- `gap`, `rowGap` и `columnGap` записываются в inline-стили только при передаче.
- `style` применяется последним и может переопределить любые сгенерированные стили, включая `display`,
  `gridTemplateColumns` и интервалы.
- `ref` указывает на фактически отрендеренный корневой элемент. При `asChild` он указывает на
  единственный дочерний элемент.
- Компонент не добавляет роли, подписи, поведение клавиатуры, управление фокусом, состояние или
  контекст провайдера. Семантические дочерние элементы нужно выбрать в своей разметке.

## Стилизация

`SimpleGrid` не определяет собственных CSS-переменных. Свойства раскладки записываются в inline-стили
корневого элемента. Если `grid-template-columns` должен задаваться таблицей стилей, не передавайте
`columns` и `minChildWidth`.

### Хуки стилизации

- `className` стилизует отрендеренный корневой элемент: его ширину, расположение, фон и адаптивную
  раскладку.
- `data-scope="simple-grid"` и `data-part="root"` соответствуют соглашениям Ark о стилизации.
- `data-slot="simple-grid-root"` - стабильный селектор moduix для локального CSS.
- `columns`, `minChildWidth`, `gap`, `rowGap` и `columnGap` записывают inline-стили и имеют приоритет
  над объявлениями из `className`.
- `style` объединяется после этих свойств и является последним переопределением для экземпляра.
- Компонент не предоставляет хуков стилизации для состояния или анимации.
