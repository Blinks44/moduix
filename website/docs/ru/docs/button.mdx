### Ref

Переданный ref указывает на отрисованный корневой элемент. Это позволяет программно установить на нём
фокус или измерить его. В Solid назначайте ref элементу, который создаётся внутри render-функции `asChild`:
ref на самом `Button` в этом случае не передаётся. В Vue template ref указывает на экземпляр компонента; используйте `$el`, чтобы получить
корневой элемент (с `asChild` это семантический дочерний элемент).

## Композиция

`Button` - односоставной корневой элемент на основе [Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory).
Используйте `asChild`, если итоговым DOM-узлом должен стать другой семантический элемент: в React передаётся
ровно один дочерний элемент, в Solid используется render-функция `asChild`, а Vue передаёт семантический элемент
как содержимое слота по умолчанию. Если Button компонует часть Ark, родитель сохраняет `data-scope` и `data-part`,
а Button - свои классы рецепта и стабильный `data-slot`.

Свойство `loading` отвечает только за состояние занятости и отключения; индикатор, текст и асинхронный жизненный
цикл остаются под контролем приложения. Для нативного корневого элемента по умолчанию используется
`type="button"`, но при `asChild` это значение не добавляется.

## Стилизация

Начните с готового варианта и размера. Для разовой настройки задайте публичные переменные
`--moduix-button-*` на кнопке через класс или встроенный стиль. Чтобы настроить один вариант во всём
приложении, задайте те же переменные на `[data-slot='button-root'][data-variant='<variant>']`. Эти
CSS-переменные относятся к пакетам с CSS Modules; в пакетах Tailwind используются обычные утилитарные классы
и классы приложения.

### CSS-переменные

Переменные сгруппированы по тому, что они меняют. Наведите на переменную или выберите её, чтобы увидеть её на кнопке.

### Хуки стилизации

Для пользовательских стилей передавайте корневому элементу `className` в React или `class` в Solid и Vue.
Эти атрибуты общие для обоих подходов к стилям.

| Атрибут                   | Когда присутствует                                                                  |
| ------------------------- | ----------------------------------------------------------------------------------- |
| `data-slot="button-root"` | Всегда. Стабильный селектор moduix.                                                 |
| `data-scope`, `data-part` | `button` и `root` у самостоятельного элемента; родитель Ark заменяет их своими.     |
| `data-variant`            | Всегда. Отражает проп `variant`.                                                    |
| `data-size`               | Всегда. Отражает проп `size`.                                                       |
| `data-loading`            | `loading` равен `true`.                                                             |
| `data-disabled`           | `disabled`, `aria-disabled="true"` или `loading`.                                   |

Самостоятельный Button при нажатии смещается вниз на 1px. Для варианта `link`, триггеров с `aria-haspopup`,
составных элементов с другим `data-slot` и при предпочтении уменьшенного движения смещение отключено.

## Клавиатура

Нативные кнопки сохраняют стандартное поведение браузера, а ссылка с `asChild` ведёт себя как
отрисованный элемент. У кнопок только со значком должно быть доступное имя.

## Справочник API

| Проп       | Тип             | По умолчанию | Описание |
| ---------- | --------------- | ------------ | --- |
| `variant`  | `ButtonVariant` | `'default'`  | Вид кнопки: `default`, `outline`, `secondary`, `destructive`, `destructive-outline`, `ghost` или `link`. |
| `size`     | `ButtonSize`    | `'md'`       | `xs`, `sm`, `md`, `lg`, `xl` или квадратные `icon-sm`, `icon-md`, `icon-lg` для кнопок с одной иконкой. |
| `loading`  | `boolean`       | `false`      | Задаёт `aria-busy` и блокирует нажатие. `Spinner` добавьте внутрь сами. |
| `asChild`  | `boolean`       | `false`      | Переносит стили и свойства Button на единственный дочерний элемент, например ссылку. |
| `disabled` | `boolean`       | `false`      | Отключает кнопку. |
