## Справочник API

В Ark UI нет отдельного примитива `button`. moduix создаёт этот компонент с помощью официального
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[работе с ref](https://ark-ui.com/docs/guides/ref).

## Анатомия

`Button` состоит из одной части.

```text
Button
└─ root[data-scope="button"][data-part="root"][data-slot="button-root"]
   └─ children
```

| Часть    | Назначение                                              |
| -------- | ------------------------------------------------------- |
| `Button` | Единый интерактивный корневой элемент со стилями moduix. |

## Композиция

`Button` - односоставной корневой элемент. Используйте `asChild`, если итоговым DOM-узлом должен владеть
другой семантический элемент: в React передаётся ровно один дочерний элемент, в Solid используется render-функция
`asChild`, а Vue передаёт семантический элемент как содержимое слота по умолчанию. Если Button компонует часть Ark,
родитель сохраняет `data-scope` и `data-part`, а Button - свои классы рецепта и стабильный `data-slot`.

Свойство `loading` отвечает только за состояние занятости и отключения (`data-loading`, `aria-busy` и
`data-disabled`); индикатор, текст и асинхронный жизненный цикл остаются под контролем приложения. Для
нативного корневого элемента по умолчанию используется `type="button"`, но при `asChild` это значение не
добавляется.

## Стилизация

Для пользовательских стилей передавайте корневому элементу `className` в React или `class` в Solid и Vue. Варианты
с CSS Modules используют перечисленные ниже переменные Button, а варианты на Tailwind - обычные утилиты и
классы приложения. Атрибуты состояния и хуки `data-slot` общие для обоих подходов.

### Хуки стилизации

- `data-slot="button-root"` - стабильный селектор moduix.
- У самостоятельного корневого элемента по умолчанию используются `data-scope="button"` и `data-part="root"`.
  Родитель Ark, который компонует Button, может заменить их значениями своей анатомии.
- `data-variant` и `data-size` показывают активные вариант и размер.
- `data-disabled` присутствует для нативных `disabled`, `aria-disabled="true"` и `loading`.
- `data-loading` присутствует, когда `loading={true}`.
- `[data-disabled]` управляет стилями отключённого состояния для нативных `disabled`, `aria-disabled="true"` и `loading`.
- В активных вариантах кнопки используется лёгкое смещение при нажатии. Для `link` меняется только прозрачность,
  а если пользователь предпочитает уменьшить движение, смещение отключается.
