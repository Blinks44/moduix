## Справочник API

В Ark UI нет отдельного примитива `button`. moduix создаёт этот компонент с помощью официального
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[работе с ref](https://ark-ui.com/docs/guides/ref).

## Анатомия

`Button` состоит из одной части.

```text
Button.Root
└─ root[data-scope="button"][data-part="root"][data-slot="button-root"]
   └─ children
```

| Часть                    | Роль                                                   |
| ------------------------ | ------------------------------------------------------ |
| `Button` / `Button.Root` | Интерактивный корневой элемент со стилями moduix.      |
| `Button`                 | Вызываемая форма `Button.Root`.                        |

## Композиция

### Рекомендуемая композиция

Для действий используйте нативный корневой элемент. По умолчанию он получает `type="button"`, поэтому
форма не отправится случайно. Если кнопка должна отправлять форму, явно задайте `type="submit"`.

### Свойства по умолчанию

| Свойство  | По умолчанию | Значения                                                                             |
| --------- | ------------ | ------------------------------------------------------------------------------------ |
| `loading` | `false`      | `boolean`                                                                            |
| `variant` | `default`    | `default`, `outline`, `secondary`, `destructive`, `destructive-outline`, `ghost`, `link` |
| `size`    | `md`         | `xs`, `sm`, `md`, `lg`, `xl`, `icon-sm`, `icon-md`, `icon-lg`                       |
| `type`    | `button`     | Только нативные корневые элементы                                                    |
| `asChild` | `false`      | Использует единственный дочерний элемент как корневой DOM-элемент                    |

### Когда нужен собственный элемент

Используйте `asChild`, когда существующий семантический элемент должен стать итоговым DOM-узлом. Ark
требует ровно одного дочернего элемента. Значение `type="button"` по умолчанию не добавляется к
элементу при использовании `asChild`.

Если `Dialog.Trigger`, `Menu.Trigger` или другая часть Ark компонует Button как дочерний элемент,
`data-scope` и `data-part` родительской части имеют приоритет на общем DOM-узле. Button сохраняет свои
классы стилей и стабильный `data-slot`, а Ark объединяет обработчики триггера и ref.

Для навигации используйте настоящий элемент `<a>`. Если использовать `asChild` с `disabled`, `loading`
или `aria-disabled="true"`, Button установит `aria-disabled`, применит стили отключённого состояния и
заблокирует активацию по клику. Нативный атрибут `disabled` к пользовательскому элементу не добавляется.

### Особенности поведения

- Нативные атрибуты, `style` и обработчики событий передаются корневому элементу. `className`
  объединяется со стилями moduix, а активация отключённой кнопки блокируется.
- Переданный ref указывает на отрисованный корневой элемент.
- Свойства `disabled`, `aria-disabled="true"` и `loading` устанавливают `data-disabled`.
- `loading` - это короткая запись для настройки состояния: она устанавливает `data-loading`, `aria-busy`
  и стили отключённого состояния, а текст кнопки и индикатор загрузки остаются под контролем приложения.
- Прямые дочерние элементы `svg` наследуют `currentColor` и используют `--moduix-button-icon-size`.
- Кнопка только со значком должна иметь доступное имя.
- API, специфичные для Chakra, например `colorPalette`, адаптивные свойства рецепта, `ButtonGroup` и
  управляемые свойства загрузки, намеренно не входят в контракт moduix с одним корневым элементом.

### Селекторы для стилизации

- `data-slot="button-root"` - стабильный селектор moduix.
- У самостоятельного корневого элемента по умолчанию используются `data-scope="button"` и `data-part="root"`. Родитель Ark, который компонует Button, может заменить их значениями своей анатомии.
- `data-variant` и `data-size` показывают активные вариант и размер.
- `data-disabled` присутствует для нативных `disabled`, `aria-disabled="true"` и `loading`.
- `data-loading` присутствует, когда `loading={true}`.
- `[data-disabled]` управляет стилями отключённого состояния для нативных `disabled`, `aria-disabled="true"` и `loading`.
- В активных вариантах кнопки используется лёгкое смещение при нажатии. Для `link` меняется только прозрачность, а если пользователь предпочитает уменьшить движение, смещение отключается.
