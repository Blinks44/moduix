## Выбор подходящего компонента

Используйте `Checkbox`, когда пользователь может выбрать один или несколько независимых вариантов
в форме, настройках или списке фильтров. Если нужно выбрать только один вариант, используйте
`RadioGroup`. Если настройка должна применяться сразу, используйте `Switch`.

## Базовый пример


Соберите флажок из частей Ark. Оставьте `CheckboxControl` пустым, чтобы использовать встроенные
иконки выбранного и неопределённого состояния от moduix. Добавьте `CheckboxLabel` для видимой
подписи и `CheckboxHiddenInput` для нативного взаимодействия и работы с формой.

## Анатомия

```text
Checkbox
├─ CheckboxControl
│  ├─ CheckboxIndicator
│  └─ CheckboxIndicator[indeterminate] (необязательно)
├─ CheckboxLabel
└─ CheckboxHiddenInput (явно)

CheckboxRootProvider
└─ то же дерево частей, подключённое к состоянию из useCheckbox()

CheckboxGroup
└─ Checkbox[value]
   ├─ CheckboxControl
   ├─ CheckboxLabel
   └─ CheckboxHiddenInput
```

| Часть                        | Назначение                                                                                 |
| ---------------------------- | ------------------------------------------------------------------------------------------ |
| `Checkbox`                   | Хранит состояние одного флажка и отрисовывает содержащий его `label`.                      |
| `CheckboxHiddenInput`        | Нативное поле Ark; добавляйте его явно внутрь корневого компонента.                        |
| `CheckboxRootProvider`       | Связывает части с состоянием Ark, созданным вне дерева компонентов.                        |
| `CheckboxControl`            | Видимая часть флажка; если оставить пустой, отображает встроенные иконки состояния.        |
| `CheckboxIndicator`          | Необязательный слот для собственной иконки. Для этого состояния передайте `indeterminate`. |
| `CheckboxLabel`              | Видимая подпись флажка.                                                                    |
| `CheckboxGroup`              | Управляет выбранными значениями нескольких флажков.                                        |

## Композиция

`CheckboxHiddenInput` - нативное поле Ark. Добавляйте его явно внутрь `Checkbox` или
`CheckboxRootProvider`, даже вне формы: оно отвечает за нативный фокус, работу с клавиатурой,
доступность и участие в форме. Для отдельного поля задайте `name` и `value` на корневом компоненте;
для группы задайте `name` на `CheckboxGroup`, а `value` - на каждом `Checkbox`.

`CheckboxGroup` хранит массив выбранных значений, а каждый дочерний элемент является
`Checkbox` со своим `value`. Оставьте `CheckboxControl` пустым, чтобы использовать встроенные
иконки moduix. Добавляйте `CheckboxIndicator` внутрь `CheckboxControl` только для собственной
иконки.

Если состояние нужно создать вне дерева компонентов, создайте его с помощью `useCheckbox()` и
передайте хранилище в `CheckboxRootProvider`. Не используйте для того же состояния `Checkbox` или
`CheckboxRootProvider`.

## Стилизация

Используйте `className` в React или `class` в Solid и Vue на экспортируемых частях для структурных стилей.
Для стилей состояний используйте атрибуты данных Ark, например `data-state`, `data-disabled` и
`data-invalid`, вместе с селекторами moduix `data-slot`. Варианты на Tailwind используют обычные
утилиты и классы потребителя; переменные ниже настраивают варианты с CSS Modules. Атрибуты данных и
хуки `data-slot` общие для обоих вариантов стилизации.

### Хуки стилизации

- `Checkbox` предоставляет `data-slot="checkbox-root"`, `data-size` и атрибуты состояния Ark, включая `data-state`, `data-active`, `data-disabled`, `data-readonly`, `data-invalid`, `data-required`, `data-hover`, `data-focus` и `data-focus-visible`.
- `CheckboxRootProvider` предоставляет `data-slot="checkbox-root-provider"` и тот же контракт стилизации корневого компонента.
- `CheckboxControl` предоставляет `data-slot="checkbox-control"` и атрибуты состояния Ark, включая `data-state="checked" | "indeterminate" | "unchecked"` и `data-active`.
- `CheckboxIndicator` предоставляет `data-slot="checkbox-indicator"` и наследует атрибуты состояния Checkbox Ark.
- `CheckboxLabel` предоставляет `data-slot="checkbox-label"` и атрибуты состояния Checkbox Ark.
- `CheckboxGroup` предоставляет `data-slot="checkbox-group"`.
