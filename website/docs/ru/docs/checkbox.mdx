Используйте `Checkbox`, когда пользователь может выбрать один или несколько независимых вариантов
в форме, настройках или списке фильтров. Если нужно выбрать только один вариант, используйте
`RadioGroup`. Если настройка должна применяться сразу, используйте `Switch`.

## Анатомия

```text
Checkbox.Root
├─ Checkbox.Control
│  ├─ Checkbox.Indicator
│  └─ Checkbox.Indicator[indeterminate] (optional)
├─ Checkbox.Label
└─ native input (automatic)

Checkbox.RootProvider
└─ same part tree connected to useCheckbox()

Checkbox.Group
└─ Checkbox.Root[value]
   ├─ Checkbox.Control
   ├─ Checkbox.Label
   └─ the native form input
```

| Часть                         | Назначение                                                                              |
| ---------------------------- | ---------------------------------------------------------------------------------------- |
| `Checkbox` / `Checkbox.Root` | Хранит состояние одного флажка и отрисовывает содержащий его `label`.                       |
| `Checkbox.RootProvider`      | Связывает части с состоянием Ark, созданным вне дерева компонентов.                         |
| `Checkbox.Control`           | Видимая часть флажка. Если оставить пустой, отображает встроенные иконки состояния.           |
| `Checkbox.Indicator`         | Необязательный слот для собственной иконки. Для неопределённого состояния передайте `indeterminate`. |
| `Checkbox.Label`             | Видимая подпись флажка.                                                                       |
| `Checkbox.Group`             | Управляет выбранными значениями нескольких флажков.                                          |

## Композиция

### Рекомендуемая композиция

Сохраняйте дерево частей Ark в разметке. `Checkbox.Root` принимает стандартные свойства корневого
компонента Ark, например `checked`, `defaultChecked`, `onCheckedChange(details)`, `disabled`,
`readOnly`, `invalid`, `required`, `name`, `value`, `form`, `ids` и `asChild`. Свойства `checked` и
`defaultChecked` могут иметь значение `true`, `false` или `"indeterminate"`.

`Checkbox.Group` принимает `value`, `defaultValue`, `onValueChange(value)`, `disabled`, `readOnly`,
`invalid`, `maxSelectedValues` и `name`.

`Checkbox.Control` - удобное сокращение moduix. Оставьте его пустым, чтобы использовать встроенные
иконки, или передайте дочерние элементы для собственного индикатора. `size` - единственное
дополнительное свойство moduix у `Checkbox.Root` и `Checkbox.RootProvider`.

### Когда нужна собственная композиция

Используйте `Checkbox.RootProvider`, если состояние флажка нужно хранить или изменять вне дерева
компонента. moduix экспортирует `useCheckbox()` из `@moduix/react/checkbox` для этого сценария.
Передайте полученное состояние в `Checkbox.RootProvider` через свойство `value`.
`Checkbox.Context`, `useCheckboxContext()`, `useCheckboxGroup()` и `useCheckboxGroupContext()` дают
доступ к состоянию Ark для более сложных композиций. Если состояние группы должно находиться вне
дерева компонентов, свяжите `useCheckboxGroup()` с `Checkbox.GroupProvider` из
`@ark-ui/react/checkbox`. Добавляйте
`Checkbox.Indicator` явно только тогда, когда нужна собственная иконка или нестандартная компоновка
индикатора.

### Свойства по умолчанию

| Компонент                     | Значение по умолчанию | Примечания                                            |
| ----------------------------- | -------------------- | ----------------------------------------------------- |
| `Checkbox` / `Checkbox.Root` | -                    | Дополнительное поведение не добавляется, используются настройки Ark. |
| `size`                       | `md`                 | Применяется к `Checkbox.Root` и `Checkbox.RootProvider`.             |

### Особенности поведения

`Checkbox.Root` и `Checkbox.RootProvider` всегда отрисовывают нативное поле, поэтому флажок может
участвовать в нативной валидации, сбросе и отправке формы. Чтобы отдельный флажок попал в данные
отправляемой формы, передайте `name` и `value` в `Checkbox.Root`. Для группы передайте `name` в
`Checkbox.Group`, а `value` - в каждый `Checkbox.Root`.

При миграции с shadcn `Checkbox.Control` уже содержит стандартное оформление иконки. В разметке
`Checkbox.Control` и `Checkbox.Label` остаются явными частями, а скрытое поле ввода создаётся внутри
компонента.

`Checkbox.Root` и `Checkbox.RootProvider` из Ark по умолчанию отрисовывают `label`. При использовании
`asChild` непосредственным дочерним элементом тоже должен быть семантический `label`, иначе у
флажка не будет корректной подписи.

При `readOnly` moduix отражает это состояние в `aria-readonly` автоматически созданного нативного
поля, а Ark по-прежнему блокирует взаимодействие.

`ref`, переданный части, указывает на соответствующий узел DOM Ark. Чтобы переключить флажок в
фокусе, нажмите <kbd>Space</kbd>.

### Хуки стилизации

- У `Checkbox.Root` есть `data-slot="checkbox-root"`, `data-size` и атрибуты состояния Ark, включая `data-state`, `data-active`, `data-disabled`, `data-readonly`, `data-invalid`, `data-required`, `data-hover`, `data-focus` и `data-focus-visible`.
- У `Checkbox.RootProvider` есть `data-slot="checkbox-root-provider"` и тот же контракт стилизации, что у корневого компонента.
- У `Checkbox.Control` есть `data-slot="checkbox-control"`, `data-state="checked" | "indeterminate" | "unchecked"` и `data-active`.
- У `Checkbox.Indicator` есть `data-slot="checkbox-indicator"` и атрибуты состояния флажка из Ark.
- У `Checkbox.Label` есть `data-slot="checkbox-label"` и атрибуты состояния флажка из Ark.
- У `Checkbox.Group` есть `data-slot="checkbox-group"`.
