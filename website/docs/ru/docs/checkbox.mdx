`Checkbox` позволяет выбирать один или несколько независимых вариантов в формах, настройках и
списках фильтров. Выбирайте `RadioGroup`, если доступен только один вариант, и `Switch`, если
изменение настройки должно применяться сразу.

## Базовый пример

Соберите флажок из частей Ark. В большинстве случаев `Checkbox.Control` сам отображает стандартные

`Checkbox.Label`. moduix автоматически добавляет нативный элемент формы.

## Анатомия

```text
Checkbox.Root
├─ Checkbox.Control
│  ├─ Checkbox.Indicator
│  └─ Checkbox.Indicator[indeterminate] (optional)
├─ Checkbox.Label
└─ native input (automatic)

Checkbox.RootProvider
└─ same part tree connected to useCheckbox()

Checkbox.Group
└─ Checkbox.Root[value]
   ├─ Checkbox.Control
   ├─ Checkbox.Label
   └─ the native form input
```

| Часть                         | Назначение                                                                              |
| ---------------------------- | ---------------------------------------------------------------------------------------- |
| `Checkbox` / `Checkbox.Root` | Хранит состояние одного флажка и отображает оборачивающий его `label`. |
| `Checkbox.RootProvider`      | Связывает части с состоянием Ark, созданным вне отрисованного поддерева. |
| `Checkbox.Control`           | Видимая часть флажка. Без дочерних элементов отображает встроенные индикаторы состояния. |
| `Checkbox.Indicator`         | Необязательный слот для собственной иконки. Для неопределённого состояния используйте `indeterminate`. |
| `Checkbox.Label`             | Видимая подпись флажка. |
| `Checkbox.Group`             | Хранит общие выбранные значения нескольких флажков. |

## Композиция

### Рекомендуемая композиция

Оставляйте дерево частей Ark в разметке. `Checkbox.Root` принимает стандартные пропы корневого компонента Ark, такие как `checked`,
`defaultChecked`, `onCheckedChange(details)`, `disabled`, `readOnly`, `invalid`, `required`,
`name`, `value`, `form`, `ids` и `asChild`.

`Checkbox.Group` принимает `value`, `defaultValue`, `onValueChange(value)`, `disabled`, `readOnly`,
`invalid`, `maxSelectedValues` и `name`.

`Checkbox.Control` - удобный вариант moduix по умолчанию. Оставьте его пустым, чтобы использовать
встроенные иконки, или передайте дочерние элементы для собственного индикатора. `size` - единственный
проп moduix у `Checkbox.Root` и `Checkbox.RootProvider`.

### Когда нужна собственная композиция

Используйте `Checkbox.RootProvider`, когда состояние флажка создаётся вне отрисованного поддерева. moduix
повторно экспортирует для этого `useCheckbox()`. `Checkbox.Context`, `useCheckboxContext()`,
`useCheckboxGroup()` и `useCheckboxGroupContext()` дают доступ к состоянию Ark для более сложных
композиций. Добавляйте `Checkbox.Indicator` явно, только если нужна собственная иконка или другая
компоновка индикатора.

### Свойства по умолчанию

| Компонент                     | Значение по умолчанию | Примечания                                            |
| ----------------------------- | -------------------- | ----------------------------------------------------- |
| `Checkbox` / `Checkbox.Root` | -                    | Нет дополнительных настроек поведения, применяются значения Ark. |
| `size`                       | `md`                 | Применяется к `Checkbox.Root` и `Checkbox.RootProvider`. |

### Особенности поведения

Корневой компонент автоматически добавляет нативный элемент формы, поэтому флажок участвует в
валидации, сбросе и отправке формы. Для отдельного флажка передайте `name` и `value` в
`Checkbox.Root`. Для группы передайте `name` в `Checkbox.Group`, а `value` - в каждый `Checkbox.Root`.

При переходе с shadcn `Checkbox.Control` уже содержит стандартное оформление иконки. В разметке
остаются явные части control и label, а скрытое поле ввода создаётся внутри компонента.

`Checkbox.Root` из Ark отображает `label`. При использовании `asChild` его непосредственным дочерним
элементом тоже должен быть семантический `label`, иначе у флажка не будет корректной подписи.

При `readOnly` moduix также добавляет `aria-readonly` к автоматически созданному нативному полю,
а Ark блокирует взаимодействие.

Ref указывает на соответствующую часть DOM Ark. Чтобы переключить флажок в фокусе, нажмите <kbd>Space</kbd>.

### Хуки стилизации

- `Checkbox.Root` предоставляет `data-slot="checkbox-root"`, `data-size` и атрибуты состояния Ark, такие как `data-state`, `data-disabled`, `data-readonly`, `data-invalid`, `data-required`, `data-hover`, `data-focus` и `data-focus-visible`.
- `Checkbox.RootProvider` предоставляет `data-slot="checkbox-root-provider"` и тот же контракт стилизации корневого компонента.
- `Checkbox.Control` предоставляет `data-slot="checkbox-control"` и атрибуты состояния Ark, включая `data-state="checked" | "indeterminate" | "unchecked"`.
- `Checkbox.Indicator` предоставляет `data-slot="checkbox-indicator"` и наследует атрибуты состояния checkbox из Ark.
- `Checkbox.Label` предоставляет `data-slot="checkbox-label"` и атрибуты состояния checkbox из Ark.
- `Checkbox.Group` предоставляет `data-slot="checkbox-group"`.
