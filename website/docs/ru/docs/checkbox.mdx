Используйте `Checkbox`, когда пользователь может выбрать один или несколько независимых вариантов
в форме, настройках или списке фильтров. Если нужно выбрать только один вариант, используйте
`RadioGroup`. Если настройка должна применяться сразу, используйте `Switch`.

## Анатомия

```text
Checkbox / Checkbox.Root
├─ Checkbox.Control
│  ├─ Checkbox.Indicator
│  └─ Checkbox.Indicator[indeterminate] (необязательно)
├─ Checkbox.Label
└─ Checkbox.HiddenInput (явно)

Checkbox.RootProvider
└─ то же дерево частей, подключённое к состоянию из useCheckbox()

Checkbox.Group
└─ Checkbox.Root[value]
   ├─ Checkbox.Control
   ├─ Checkbox.Label
   └─ Checkbox.HiddenInput
```

| Часть                         | Назначение                                                                            |
| ---------------------------- | ------------------------------------------------------------------------------------- |
| `Checkbox` / `Checkbox.Root` | Хранит состояние одного флажка и отрисовывает содержащий его `label`.                |
| `Checkbox.HiddenInput`       | Нативное поле Ark; добавляйте его явно внутрь корневого компонента.                   |
| `Checkbox.RootProvider`      | Связывает части с состоянием Ark, созданным вне дерева компонентов.                   |
| `Checkbox.Control`           | Видимая часть флажка; если оставить пустой, отображает встроенные иконки состояния.   |
| `Checkbox.Indicator`         | Необязательный слот для собственной иконки. Для этого состояния передайте `indeterminate`. |
| `Checkbox.Label`             | Видимая подпись флажка.                                                               |
| `Checkbox.Group`             | Управляет выбранными значениями нескольких флажков.                                  |

## Композиция

`Checkbox.HiddenInput` — нативное поле Ark. Добавляйте его явно внутрь `Checkbox.Root` или
`Checkbox.RootProvider`, даже вне формы: оно отвечает за нативный фокус, работу с клавиатурой,
доступность и участие в форме. Для отдельного поля задайте `name` и `value` на корневом компоненте;
для группы задайте `name` на `Checkbox.Group`, а `value` — на каждом `Checkbox.Root`.

`Checkbox.Group` хранит массив выбранных значений, а каждый дочерний элемент является
`Checkbox.Root` со своим `value`. Оставьте `Checkbox.Control` пустым, чтобы использовать встроенные
иконки moduix. Добавляйте `Checkbox.Indicator` внутрь `Checkbox.Control` только для собственной
иконки.

Если состояние нужно создать вне дерева компонентов, создайте его с помощью `useCheckbox()` и
передайте хранилище в `Checkbox.RootProvider`. Не используйте для того же состояния `Checkbox` или
`Checkbox.Root`.

## Стилизация

Используйте `className` в React или `class` в Solid на экспортируемых частях для структурных стилей.
Для стилей состояний используйте атрибуты данных Ark, например `data-state`, `data-disabled` и
`data-invalid`, вместе с селекторами moduix `data-slot`. Варианты на Tailwind используют обычные
утилиты и классы потребителя; переменные ниже настраивают варианты с CSS Modules. Атрибуты данных и
хуки `data-slot` общие для обоих вариантов стилизации.

### CSS-свойства

<CssPropertiesSection properties={CheckboxDocs.checkboxOverrideCssProperties} />

### Хуки стилизации

- `Checkbox.Root` предоставляет `data-slot="checkbox-root"`, `data-size` и атрибуты состояния Ark, включая `data-state`, `data-active`, `data-disabled`, `data-readonly`, `data-invalid`, `data-required`, `data-hover`, `data-focus` и `data-focus-visible`.
- `Checkbox.RootProvider` предоставляет `data-slot="checkbox-root-provider"` и тот же контракт стилизации корневого компонента.
- `Checkbox.Control` предоставляет `data-slot="checkbox-control"` и атрибуты состояния Ark, включая `data-state="checked" | "indeterminate" | "unchecked"` и `data-active`.
- `Checkbox.Indicator` предоставляет `data-slot="checkbox-indicator"` и наследует атрибуты состояния Checkbox Ark.
- `Checkbox.Label` предоставляет `data-slot="checkbox-label"` и атрибуты состояния Checkbox Ark.
- `Checkbox.Group` предоставляет `data-slot="checkbox-group"`.
