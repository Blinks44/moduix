## Какой компонент выбрать

`Accordion` подходит, когда несколько связанных разделов должны использовать общую навигацию с
клавиатуры и общее состояние. Для одного независимого раскрывающегося блока используйте
`Collapsible`.

## Базовый пример


Используйте `Accordion` как корневой компонент и задайте каждому элементу стабильное значение
`value`. Поместите интерактивный заголовок в триггер элемента, панель в часть содержимого, а её
внутреннее содержимое в тело элемента. Индикатор состояния необязателен и по умолчанию отображает
иконку плюса moduix.

React, Solid и Vue используют одинаковые плоские имена. Импортируйте `Accordion` как корневой
компонент, а каждую дополнительную часть отдельно, например `AccordionItem` и
`AccordionItemTrigger`. Одинаковые имена работают с npm-пакетами и исходниками из shadcn registry.

## Анатомия

```text
Accordion
└─ AccordionItem[value]
 ├─ AccordionItemTrigger
 │  ├─ label
 │  └─ AccordionItemIndicator (необязательно)
 └─ AccordionItemContent
    └─ AccordionItemBody
       └─ content

AccordionRootProvider
└─ то же дерево элементов, подключённое к состоянию из useAccordion()
```

| Часть                    | Назначение                                                                         |
| ------------------------ | ---------------------------------------------------------------------------------- |
| `Accordion`              | Корневая часть, управляющая состоянием и навигацией с клавиатуры.                  |
| `AccordionRootProvider`  | Подключает части к состоянию, созданному с помощью `useAccordion()`.                |
| `AccordionItem`          | Сворачиваемый элемент с обязательным стабильным значением `value`.                 |
| `AccordionItemTrigger`   | Кнопка, открывающая и закрывающая элемент.                                          |
| `AccordionItemIndicator` | Необязательный индикатор. Без содержимого moduix показывает иконку плюса.           |
| `AccordionItemContent`   | Раскрывающаяся панель с анимацией на основе измерений размера Ark.                  |
| `AccordionItemBody`      | Внутренняя обёртка moduix с отступами панели по умолчанию.                          |

## Композиция

Используйте `defaultValue` для неконтролируемого аккордеона. Если состояние хранится в другой части
приложения, передайте `value` и обработчик `onValueChange(details)`. Оба свойства используют тип
`string[]`, даже если открыть можно только один элемент.

Используйте `AccordionRootProvider` вместе с `useAccordion()` из пакета выбранного фреймворка, если
состояние аккордеона нужно создать вне дерева. Не добавляйте `Accordion` для того же состояния. В
React состояние читается как обычный объект, в Solid - через реактивную функцию доступа, а Vue
передаёт реактивное хранилище прямо в шаблон.

## Стилизация

Для структурных стилей передавайте экспортируемым частям `className` в React или `class` в Solid и Vue.
Состояния лучше оформлять через атрибуты данных Ark, например `data-state`, `data-disabled` и
`data-orientation`, вместе с селекторами `data-slot` moduix. Варианты на Tailwind настраиваются
обычными утилитами и пользовательскими классами; перечисленные ниже переменные относятся к
вариантам с CSS Modules. Атрибуты данных и селекторы `data-slot` общие для обоих подходов.

Задавайте отступы панели на `AccordionItemBody`, а не на `AccordionItemContent`, чтобы Ark мог
правильно измерять и анимировать панель.

### Хуки стилизации

- Стабильные селекторы `data-slot`: `accordion-root`, `accordion-root-provider`, `accordion-item`,
  `accordion-item-trigger`, `accordion-item-indicator`, `accordion-item-content` и
  `accordion-item-body`.
- Селекторы частей Ark: `data-scope="accordion"` и
  `data-part="root|item|item-trigger|item-indicator|item-content"`.
- Дополнительный селектор moduix: `data-part="item-body"` на части тела элемента.
- Селекторы состояния Ark: `data-state="open|closed"`, `data-disabled`, `data-focus`, `data-controls`
  и `data-orientation="horizontal|vertical"`.
- Переменные содержимого Ark: `--height` для вертикальной анимации и `--width` для горизонтальной анимации.
