## Какой компонент выбрать

`Accordion` подходит, когда несколько связанных разделов должны использовать общую навигацию с
клавиатуры и общее состояние. Для одного независимого раскрывающегося блока используйте
`Collapsible`.

## Базовый пример

Accordion доступен для React и Solid как в пакетах с CSS Modules, так и в вариантах на Tailwind.
Интерактивные примеры на этой странице используют React и CSS Modules, а вкладки с кодом показывают
нативную реализацию того же API для каждого фреймворка.

Используйте `Accordion` как корневой компонент и задайте каждому `Accordion.Item` стабильное
значение `value`. Поместите интерактивный заголовок в `Accordion.ItemTrigger`, панель в
`Accordion.ItemContent`, а её внутреннее содержимое в `Accordion.ItemBody`. `Accordion.ItemIndicator`
необязателен и по умолчанию отображает иконку плюса moduix.

`Accordion` является рекомендуемым корневым компонентом. Используйте `Accordion.Root`, если хотите
явно обозначить корневую часть в композиции.

## Анатомия

```text
Accordion / Accordion.Root
└─ Accordion.Item[value]
 ├─ Accordion.ItemTrigger
 │  ├─ label
 │  └─ Accordion.ItemIndicator (необязательно)
 └─ Accordion.ItemContent
    └─ Accordion.ItemBody
       └─ content

Accordion.RootProvider
└─ то же дерево элементов, подключённое к состоянию из useAccordion()
```

| Часть                          | Назначение                                                                                 |
| ------------------------------ | ------------------------------------------------------------------------------------------- |
| `Accordion` / `Accordion.Root` | Корневая часть, управляющая состоянием аккордеона и навигацией с клавиатуры.                |
| `Accordion.RootProvider`       | Подключает части к состоянию, созданному с помощью `useAccordion()`.                        |
| `Accordion.Item`               | Сворачиваемый элемент с обязательным стабильным значением `value`.                         |
| `Accordion.ItemTrigger`        | Кнопка, открывающая и закрывающая элемент.                                                  |
| `Accordion.ItemIndicator`      | Необязательный индикатор состояния. Если дочернее содержимое не задано, moduix показывает иконку плюса. |
| `Accordion.ItemContent`        | Раскрывающаяся панель с анимацией на основе измерений размера Ark.                          |
| `Accordion.ItemBody`           | Внутренняя обёртка moduix с отступами панели по умолчанию.                                  |

## Композиция

Используйте `defaultValue` для неконтролируемого аккордеона. Если состояние хранится в другой части
приложения, передайте `value` и обработчик `onValueChange(details)`. Оба свойства используют тип
`string[]`, даже если открыть можно только один элемент.

Используйте `Accordion.RootProvider` вместе с `useAccordion()` из пакета выбранного фреймворка, если
состояние аккордеона нужно создать вне дерева. Передайте полученное хранилище в `RootProvider` и не
добавляйте для того же состояния `Accordion` или `Accordion.Root`. В React состояние читается как
обычный объект, а в Solid — через реактивную функцию доступа.

## Стилизация

Для структурных стилей передавайте экспортируемым частям `className` в React или `class` в Solid.
Состояния лучше оформлять через атрибуты данных Ark, например `data-state`, `data-disabled` и
`data-orientation`, вместе с селекторами `data-slot` moduix. Варианты на Tailwind настраиваются
обычными утилитами и пользовательскими классами; перечисленные ниже переменные относятся к
вариантам с CSS Modules. Атрибуты данных и селекторы `data-slot` общие для обоих подходов.

Задавайте отступы панели на `Accordion.ItemBody`, а не на `Accordion.ItemContent`, чтобы Ark мог
правильно измерять и анимировать панель.

### Хуки стилизации

- Стабильные селекторы `data-slot`: `accordion-root`, `accordion-root-provider`, `accordion-item`,
  `accordion-item-trigger`, `accordion-item-indicator`, `accordion-item-content` и
  `accordion-item-body`.
- Селекторы частей Ark: `data-scope="accordion"` и
  `data-part="root|item|item-trigger|item-indicator|item-content"`.
- Дополнительный селектор moduix: `data-part="item-body"` на `Accordion.ItemBody`.
- Селекторы состояния Ark: `data-state="open|closed"`, `data-disabled`, `data-focus`, `data-controls`
  и `data-orientation="horizontal|vertical"`.
- Переменные содержимого Ark: `--height` для вертикальной анимации и `--width` для горизонтальной анимации.
