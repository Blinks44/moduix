## Базовый пример

`Accordion` группирует связанные разделы под раскрываемыми заголовками. Он подходит для часто
задаваемых вопросов, групп настроек и фильтров, когда нужно сравнивать разделы. Для одного
самостоятельного раскрываемого блока используйте `Collapsible`.

Используйте `Accordion` с частями в стиле Ark: `Accordion.Item`, `Accordion.ItemTrigger`,
`Accordion.ItemIndicator`, `Accordion.ItemContent` и `Accordion.ItemBody`.

## Анатомия

```text
Accordion.Root
└─ Accordion.Item[value]
 ├─ Accordion.ItemTrigger
 │  ├─ label
 │  └─ Accordion.ItemIndicator (необязательно)
 └─ Accordion.ItemContent
    └─ Accordion.ItemBody
       └─ content

Accordion.RootProvider
└─ то же дерево элементов, подключённое к хранилищу useAccordion()
```

| Часть                          | Назначение                                                                                |
| ------------------------------ | ----------------------------------------------------------------------------------------- |
| `Accordion` / `Accordion.Root` | Управляет состоянием аккордеона и поведением клавиатуры.                                  |
| `Accordion.RootProvider`       | Подключает части к состоянию, которое создаёт `useAccordion()`.                            |
| `Accordion.Item`               | Один сворачиваемый элемент с обязательным `value`.                                        |
| `Accordion.ItemTrigger`        | Интерактивная кнопка, открывающая или закрывающая элемент.                                |
| `Accordion.ItemIndicator`      | Визуальный индикатор открытия и закрытия. Если дочерние элементы не переданы, по умолчанию отображает иконку плюса moduix. |
| `Accordion.ItemContent`        | Сворачиваемая область содержимого, сохраняющая поведение анимации размера Ark.            |
| `Accordion.ItemBody`           | Обёртка с внутренними отступами по умолчанию для содержимого панели.                      |

## Композиция

### Рекомендуемая композиция

`Accordion` управляет навигацией с клавиатуры, перемещением фокуса и состоянием открытых элементов.
Используйте его с `value`, `defaultValue`, `onValueChange(details)`, `onFocusChange(details)`,
`multiple`, `collapsible`, `orientation`, `lazyMount`, `unmountOnExit` и `ids`.

Для стандартной композиции Ark используйте `Accordion`, `Accordion.Item`,
`Accordion.ItemTrigger`, `Accordion.ItemIndicator`, `Accordion.ItemContent` и
`Accordion.ItemBody`.

### Когда нужна собственная композиция

`value` и `defaultValue` всегда являются массивами, в том числе в режиме с единственным открытым
элементом. `onValueChange` соответствует сигнатуре колбэка Ark и передаёт текущие значения элементов
в `details.value`.

Используйте `Accordion.RootProvider` вместе с `useAccordion()` из `@moduix/react`, если состояние
аккордеона нужно создать вне отрисованного поддерева.

Используйте `Accordion.Context`, `Accordion.ItemContext`, `useAccordionContext()` и
`useAccordionItemContext()` из moduix, если окружающему интерфейсу нужно прочитать состояние корня
или отдельного элемента. Состояние элемента содержит булевы значения Ark `expanded`, `focused` и
`disabled`.

`Accordion.Item` требует стабильного `value`. Задайте `disabled`, если раздел должен оставаться
видимым, но недоступным.

`Accordion.ItemIndicator` необязателен. Если дочерние элементы не переданы, moduix отображает
`PlusIcon`; содержимое индикатора можно полностью заменить.

Используйте `asChild`, только если итоговый DOM-узел должен принадлежать другому элементу. Сохраняйте
дерево частей Ark видимым, а не скрывайте его за вспомогательными обёртками.

### Свойства по умолчанию

| Свойство              | По умолчанию | Примечания                                                            |
| --------------------- | ------------ | --------------------------------------------------------------------- |
| `collapsible`         | `false`      | Один развёрнутый элемент остаётся открытым, пока не будет выбран другой. |
| `lazyMount`           | `false`      | Сразу монтирует содержимое элемента.                                  |
| `multiple`            | `false`      | По умолчанию разрешает один развёрнутый элемент.                      |
| `orientation`         | `vertical`   | Использует вертикальное расположение и клавиатурную навигацию.        |
| `unmountOnExit`       | `false`      | Сохраняет свёрнутое содержимое смонтированным.                        |
| `value`/`defaultValue` | `[]`        | Значения — массивы строк, в том числе в режиме с единственным открытым элементом. |

### Особенности поведения

Задавайте отступы на `Accordion.ItemBody`, а не на `Accordion.ItemContent`. Переменные размеров Ark
управляют анимацией открытия и закрытия: `--height` для вертикальных и `--width` для горизонтальных
аккордеонов.

Каждый триггер — нативная кнопка, связанная с содержимым через `aria-expanded`, `aria-controls` и
соответствующую подпись области содержимого. `Enter` или `Space` переключает элемент. В вертикальной
ориентации `ArrowDown` и `ArrowUp` перемещают фокус между триггерами, а в горизонтальной используются
`ArrowRight` и `ArrowLeft`. `Home` и `End` переводят фокус к первому и последнему триггеру.

Каждая стилизованная часть передаёт ref и поддерживает `asChild`, если другой семантический элемент
должен отрисовать итоговый узел. Замена триггера должна оставаться доступной с клавиатуры и сохранять
семантику кнопки.

Если пользователь включает уменьшение движения, Accordion отключает переходы триггера и индикатора,
а анимация панели становится практически мгновенной, сохраняя корректный жизненный цикл Ark.

## Стилизация

Используйте `className` на экспортируемых частях для структурной стилизации. Для стилизации по
состоянию используйте атрибуты данных Ark (`data-state`, `data-disabled`, `data-orientation`) и хуки
`data-slot` moduix.

### CSS-свойства

<CssPropertiesSection properties={AccordionDocs.accordionOverrideCssProperties} />

### Хуки стилизации

- Селекторы `data-slot="accordion-root"`, `accordion-root-provider`, `accordion-item`,
  `accordion-item-trigger`, `accordion-item-indicator`, `accordion-item-content` и
  `accordion-item-body`.
- Хуки анатомии Ark: `data-scope="accordion"` и `data-part="root|item|item-trigger|item-indicator|item-content"`.
- Хук удобной части moduix: `data-part="item-body"` на `Accordion.ItemBody`.
- Хуки состояния Ark: `data-state="open|closed"`, `data-disabled`, `data-focus`,
  `data-controls` и `data-orientation="horizontal|vertical"`.
- Переменные содержимого Ark: `--height` для вертикальной анимации и `--width` для горизонтальной анимации.
