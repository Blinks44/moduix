## Какой компонент выбрать

`Accordion` подходит, когда несколько связанных разделов должны использовать общую навигацию с
клавиатуры и общее состояние. Для одного независимого раскрывающегося блока используйте
`Collapsible`.

## Базовый пример

Используйте `Accordion` как корневой компонент и задайте каждому `Accordion.Item` стабильное
значение `value`. Поместите интерактивный заголовок в `Accordion.ItemTrigger`, панель в
`Accordion.ItemContent`, а её внутреннее содержимое в `Accordion.ItemBody`. `Accordion.ItemIndicator`
необязателен и по умолчанию отображает иконку плюса moduix.

`Accordion` является рекомендуемым корневым компонентом. Используйте `Accordion.Root`, если хотите
явно обозначить корневую часть в композиции.

## Анатомия

```text
Accordion / Accordion.Root
└─ Accordion.Item[value]
 ├─ Accordion.ItemTrigger
 │  ├─ label
 │  └─ Accordion.ItemIndicator (необязательно)
 └─ Accordion.ItemContent
    └─ Accordion.ItemBody
       └─ content

Accordion.RootProvider
└─ то же дерево элементов, подключённое к состоянию из useAccordion()
```

| Часть                          | Назначение                                                                                 |
| ------------------------------ | ------------------------------------------------------------------------------------------- |
| `Accordion` / `Accordion.Root` | Корневая часть, управляющая состоянием аккордеона и навигацией с клавиатуры.                |
| `Accordion.RootProvider`       | Подключает части к состоянию, созданному с помощью `useAccordion()`.                        |
| `Accordion.Item`               | Сворачиваемый элемент с обязательным стабильным значением `value`.                         |
| `Accordion.ItemTrigger`        | Кнопка, открывающая и закрывающая элемент.                                                  |
| `Accordion.ItemIndicator`      | Необязательный индикатор состояния. Если дочернее содержимое не задано, moduix показывает иконку плюса. |
| `Accordion.ItemContent`        | Раскрывающаяся панель с анимацией на основе измерений размера Ark.                          |
| `Accordion.ItemBody`           | Внутренняя обёртка moduix с отступами панели по умолчанию.                                  |

## Композиция

### Рекомендуемая композиция

`Accordion` управляет состоянием элементов и навигацией с клавиатуры. Начните с `Accordion`,
`Accordion.Item`, `Accordion.ItemTrigger`, `Accordion.ItemContent` и `Accordion.ItemBody`. Добавьте
`Accordion.ItemIndicator`, если нужен визуальный признак состояния.

К свойствам корневого компонента относятся `defaultValue`, `value`, `onValueChange(details)`,
`onFocusChange(details)`, `multiple`, `collapsible`, `disabled`, `orientation`, `lazyMount`,
`unmountOnExit`, `hideMode` и `ids`.

Используйте `defaultValue` для неконтролируемого аккордеона. Если состояние хранится в другой части
приложения, передайте `value` и обработчик `onValueChange(details)`. Оба свойства используют тип
`string[]`, даже если открыть можно только один элемент.

### Когда нужна своя композиция

Перейдите к отдельной композиции, если состояние нужно создавать за пределами дерева, если другая
часть интерфейса должна читать или изменять его или если для части нужен другой семантический
элемент.

Используйте `Accordion.RootProvider` вместе с `useAccordion()` из `@moduix/react`, если состояние
аккордеона нужно создать вне дерева, которое он рендерит. Передайте в `RootProvider` значение,
возвращённое `useAccordion()`, и не добавляйте к нему `Accordion` или `Accordion.Root`.

Используйте `Accordion.Context`, `Accordion.ItemContext`, `useAccordionContext()` и
`useAccordionItemContext()` из moduix, если другой части интерфейса нужен доступ к состоянию корня
или элемента. Состояние элемента включает логические свойства Ark `expanded`, `focused` и `disabled`.

Задайте `disabled` корневому компоненту, чтобы отключить все элементы. Задайте его отдельному
`Accordion.Item`, чтобы отключить только этот элемент и оставить его видимым.

`Accordion.Item` требует стабильного значения `value`. `Accordion.ItemIndicator` необязателен: если
дочернее содержимое не передано, moduix отображает `PlusIcon`, а при необходимости его можно
полностью заменить.

Используйте `asChild`, только если итоговый DOM-узел должен принадлежать другому элементу. Оставляйте
структуру частей Ark явной и не скрывайте её за вспомогательными обёртками.

### Свойства по умолчанию

| Свойство              | По умолчанию | Примечания                                                                                |
| --------------------- | ------------ | ----------------------------------------------------------------------------------------- |
| `collapsible`         | `false`      | Открытый элемент нельзя закрыть, не открыв другой.                                        |
| `disabled`            | `false`      | Корневой компонент или элемент остаётся видимым, но недоступен для взаимодействия.         |
| `hideMode`            | `display-none` | Определяет, как скрывать смонтированное закрытое содержимое. `activity` требует React 19. |
| `lazyMount`           | `false`      | Монтирует содержимое всех элементов при первом рендере.                                  |
| `multiple`            | `false`      | Одновременно можно открыть только один элемент.                                          |
| `orientation`         | `vertical`   | Использует вертикальное расположение и соответствующую навигацию с клавиатуры.           |
| `unmountOnExit`       | `false`      | Оставляет содержимое смонтированным после закрытия.                                      |
| `value`/`defaultValue` | не задано   | Управляемые или начальные значения открытых элементов. Всегда используйте `string[]`.      |

### Особенности поведения

Размещайте отступы на `Accordion.ItemBody`, а не на `Accordion.ItemContent`, чтобы Ark мог правильно
измерить панель. Ark предоставляет переменную `--height` для вертикальной анимации содержимого и
`--width` для горизонтальной.

Каждый триггер является нативной кнопкой. Ark связывает её с панелью через `aria-expanded` и
`aria-controls` и добавляет панели соответствующий `aria-labelledby`. Клавиши `Enter` и `Space`
открывают закрытый элемент, а при включённом `collapsible` также закрывают открытый. В вертикальной
ориентации `ArrowDown` и `ArrowUp` перемещают фокус между триггерами. В горизонтальной ориентации
используйте `ArrowRight` и `ArrowLeft`. `Home` и `End` переводят фокус на первый и последний триггер.

Каждая стилизуемая часть пробрасывает ref и поддерживает `asChild`, если другой семантический элемент
должен отвечать за итоговый DOM-узел. Пользовательский триггер должен оставаться доступным с клавиатуры и
вести себя как кнопка.

При включённом `lazyMount` закрытое содержимое монтируется только после первого открытия. Добавьте
`unmountOnExit`, чтобы удалять его из DOM после закрытия. `hideMode="activity"` сохраняет смонтированное
содержимое в скрытом режиме `Activity` React 19 и приостанавливает его эффекты.

Если пользователь предпочитает уменьшить движение, Accordion отключает переходы триггера и индикатора,
а анимация панели становится практически мгновенной, сохраняя жизненный цикл Ark.

## Стилизация

Используйте `className` у экспортируемых частей для структурных стилей. Для стилей, зависящих от
состояния, предпочитайте атрибуты данных Ark, например `data-state`, `data-disabled` и
`data-orientation`, вместе с селекторами `data-slot` библиотеки moduix.

### Хуки стилизации

- Стабильные селекторы `data-slot`: `accordion-root`, `accordion-root-provider`, `accordion-item`,
  `accordion-item-trigger`, `accordion-item-indicator`, `accordion-item-content` и
  `accordion-item-body`.
- Селекторы частей Ark: `data-scope="accordion"` и
  `data-part="root|item|item-trigger|item-indicator|item-content"`.
- Дополнительный селектор moduix: `data-part="item-body"` на `Accordion.ItemBody`.
- Селекторы состояния Ark: `data-state="open|closed"`, `data-disabled`, `data-focus`, `data-controls`
  и `data-orientation="horizontal|vertical"`.
- Переменные содержимого Ark: `--height` для вертикальной анимации и `--width` для горизонтальной анимации.
