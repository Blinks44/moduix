## Базовый пример

`Accordion` объединяет связанное содержимое в раскрывающиеся разделы. Он подходит для FAQ, групп
настроек и фильтров, если пользователям нужно сравнивать несколько разделов. Для одного независимого
раскрывающегося блока используйте `Collapsible`.

Используйте `Accordion` со следующими частями в стиле Ark: `Accordion.Item`, `Accordion.ItemTrigger`,
`Accordion.ItemIndicator`, `Accordion.ItemContent` и `Accordion.ItemBody`.

## Анатомия

```text
Accordion.Root
└─ Accordion.Item[value]
 ├─ Accordion.ItemTrigger
 │  ├─ label
 │  └─ Accordion.ItemIndicator (необязательно)
 └─ Accordion.ItemContent
    └─ Accordion.ItemBody
       └─ content

Accordion.RootProvider
└─ то же дерево элементов, подключённое к хранилищу useAccordion()
```

| Часть                          | Назначение                                                                                |
| ------------------------------ | ----------------------------------------------------------------------------------------- |
| `Accordion` / `Accordion.Root` | Управляет состоянием аккордеона и взаимодействием с клавиатурой.                           |
| `Accordion.RootProvider`       | Подключает части к состоянию, созданному с помощью `useAccordion()`.                        |
| `Accordion.Item`               | Сворачиваемый элемент с обязательным `value`.                                               |
| `Accordion.ItemTrigger`        | Интерактивная кнопка, открывающая или закрывающая элемент.                                 |
| `Accordion.ItemIndicator`      | Показывает состояние элемента. Если дочернее содержимое не задано, по умолчанию отображает иконку плюса moduix. |
| `Accordion.ItemContent`        | Раскрывающаяся область содержимого с анимацией размера Ark.                                 |
| `Accordion.ItemBody`           | Внутренняя обёртка, задающая отступы содержимого панели по умолчанию.                       |

## Композиция

### Рекомендуемая композиция

`Accordion` управляет навигацией с клавиатуры, перемещением фокуса и состоянием открытых элементов.
Используйте его с `value`, `defaultValue`, `onValueChange(details)`, `onFocusChange(details)`,
`multiple`, `collapsible`, `orientation`, `lazyMount`, `unmountOnExit` и `ids`.

Для стандартной композиции Ark используйте `Accordion`, `Accordion.Item`, `Accordion.ItemTrigger`,
`Accordion.ItemIndicator`, `Accordion.ItemContent` и `Accordion.ItemBody`.

### Своя композиция

Выберите этот вариант, если состояние нужно создать за пределами дерева аккордеона, если другим
частям интерфейса нужен доступ к нему или если необходимо заменить стандартные части.

`value` и `defaultValue` всегда являются массивами, даже в режиме с одним открытым элементом.
`onValueChange` сохраняет сигнатуру колбэка Ark и передаёт текущие значения элементов в
`details.value`.

Используйте `Accordion.RootProvider` вместе с `useAccordion()` из `@moduix/react`, если состояние
аккордеона нужно создать вне дерева, которое он рендерит.

Используйте `Accordion.Context`, `Accordion.ItemContext`, `useAccordionContext()` и
`useAccordionItemContext()` из moduix, если другим частям интерфейса нужен доступ к состоянию корня
или отдельного элемента. Состояние элемента включает логические свойства Ark `expanded`, `focused` и
`disabled`.

`Accordion.Item` требует стабильного `value`. Задайте элементу `disabled`, если его раздел должен
оставаться видимым, но быть недоступным для взаимодействия.

`Accordion.ItemIndicator` необязателен. Если дочернее содержимое не задано, moduix отображает
`PlusIcon`; при этом содержимое индикатора можно полностью заменить.

Используйте `asChild`, только если итоговый DOM-узел должен принадлежать другому элементу. Оставляйте
структуру частей Ark явной и не прячьте её за вспомогательными обёртками.

### Свойства по умолчанию

| Свойство              | По умолчанию | Примечания                                                            |
| --------------------- | ------------ | --------------------------------------------------------------------- |
| `collapsible`          | `false`    | Не позволяет закрыть открытый элемент, не открыв другой.                    |
| `lazyMount`            | `false`    | Монтирует содержимое элемента при монтировании аккордеона.                  |
| `multiple`              | `false`    | Разрешает одновременно открыть только один элемент.                         |
| `orientation`          | `vertical` | Использует вертикальную раскладку и навигацию с клавиатуры.                  |
| `unmountOnExit`         | `false`    | Оставляет свёрнутое содержимое в DOM.                                       |
| `value`/`defaultValue`  | `[]`       | Значения - массивы строк, даже в режиме с одним открытым элементом.         |

### Особенности поведения

Размещайте отступы на `Accordion.ItemBody`, а не на `Accordion.ItemContent`. Переменные размеров Ark
управляют анимацией открытия и закрытия: `--height` используется для вертикальных, а `--width` - для
горизонтальных аккордеонов.

Каждый триггер - нативная кнопка, связанная с содержимым через `aria-expanded`, `aria-controls` и
соответствующую подпись. Нажатие `Enter` или `Space` переключает состояние элемента. В вертикальной
ориентации `ArrowDown` и `ArrowUp` перемещают фокус между триггерами, а в горизонтальной используются
`ArrowRight` и `ArrowLeft`. `Home` и `End` переводят фокус на первый и последний триггер.

Каждая стилизуемая часть пробрасывает ref и поддерживает `asChild`, если другой семантический элемент
должен отвечать за итоговый DOM-узел. Если вы заменяете триггер, он должен оставаться доступным с
клавиатуры и сохранять поведение кнопки.

Если пользователь предпочитает уменьшить движение, Accordion отключает переходы триггера и индикатора,
а анимация панели становится практически мгновенной и сохраняет жизненный цикл Ark.

## Стилизация

Используйте `className` на экспортируемых частях, чтобы изменить структуру. Для стилей, зависящих от
состояния, предпочитайте атрибуты данных Ark (`data-state`, `data-disabled`, `data-orientation`) и
селекторы `data-slot` moduix.

### Хуки стилизации

- Стабильные селекторы `data-slot`: `accordion-root`, `accordion-root-provider`, `accordion-item`,
  `accordion-item-trigger`, `accordion-item-indicator`, `accordion-item-content` и
  `accordion-item-body`.
- Селекторы частей Ark: `data-scope="accordion"` и `data-part="root|item|item-trigger|item-indicator|item-content"`.
- Дополнительный селектор moduix: `data-part="item-body"` на `Accordion.ItemBody`.
- Селекторы состояния Ark: `data-state="open|closed"`, `data-disabled`, `data-focus`,
  `data-controls` и `data-orientation="horizontal|vertical"`.
- Переменные содержимого Ark: `--height` для вертикальной анимации и `--width` для горизонтальной анимации.
