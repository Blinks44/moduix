## Использование

<Usage />

Используйте `Accordion` как корневой компонент и задайте каждому элементу стабильное значение
`value`. Поместите интерактивный заголовок в триггер элемента, панель в часть содержимого, а её
внутреннее содержимое в тело элемента. Индикатор состояния необязателен и по умолчанию отображает
шеврон, который поворачивается при открытии. Оборачивайте каждый триггер в заголовок (в примерах
`h3`), чтобы пользователи скринридеров могли переходить между разделами.

## Какой компонент выбрать

`Accordion` подходит, когда несколько связанных разделов должны использовать общую навигацию с
клавиатуры и общее состояние. Для одного независимого раскрывающегося блока используйте
`Collapsible`.

## Примеры

### Несколько открытых элементов

Установите `multiple`, если одновременно должны оставаться открытыми несколько разделов.

<Example name="accordion/multiple" />

### Сворачиваемый режим

Включите `collapsible`, чтобы открытый элемент можно было закрыть, не открывая другой.

<Example name="accordion/collapsible" />

### Отключённый элемент

Задайте элементу `disabled`, если он должен оставаться видимым в списке, но быть недоступным для взаимодействия.

<Example name="accordion/disabled-item" />

### Горизонтальный вариант

Установите `orientation="horizontal"`, чтобы расположить аккордеон в ряд и включить горизонтальную
навигацию с клавиатуры.

<Example name="accordion/horizontal" />

### Управляемое состояние

Передайте `value` и `onValueChange` (`v-model` во Vue, `bind:value` в Svelte), если открытые элементы зависят от маршрута,
фильтров или соседнего интерфейса. `value` всегда массив значений элементов, даже без `multiple`. Подробнее в разделе [Управляйте состоянием из приложения](/docs/composition-patterns#controlled-state).

<Example name="accordion/controlled" />

### Ленивое монтирование

Сочетайте `lazyMount` и `unmountOnExit`, если скрытое содержимое панели дорого рендерить и его нужно
удалять из DOM после закрытия. В React 19 вместо этого можно использовать `hideMode="activity"`,
если содержимое должно оставаться смонтированным, но его эффекты нужно приостанавливать в скрытом состоянии.

<Example name="accordion/lazy-mount" />

### Со слайдером

В содержимое аккордеона можно поместить другой составной виджет на базе Ark, например `Slider`.
Оставляйте структуру частей каждого примитива явной, чтобы нужный компонент сам обрабатывал клавиатуру
и управлял скрытыми полями формы.

<Example name="accordion/with-slider" />

### Root Provider

Используйте `useAccordion()` из пакета выбранного фреймворка вместе с `AccordionRootProvider`, если
состояние нужно создать вне дерева аккордеона. Не добавляйте `Accordion` для того же состояния. Подробнее в разделе [Выносите состояние за пределы дерева](/docs/composition-patterns#root-provider).

<Example name="accordion/root-provider" />

### Сборка из частей

Тот же аккордеон, что в Basic, но без `AccordionItemBody` и с явной иконкой индикатора:
`AccordionItemIndicator` рисует шеврон по умолчанию, только когда у него нет дочерних элементов, а

## Композиция

Используйте `defaultValue` для неконтролируемого аккордеона. Если состояние хранится в другой части
приложения, передайте `value` и обработчик `onValueChange(details)`. Оба свойства используют тип
`string[]`, даже если открыть можно только один элемент.

Используйте `AccordionRootProvider` вместе с `useAccordion()` из пакета выбранного фреймворка, если
состояние аккордеона нужно создать вне дерева. Не добавляйте `Accordion` для того же состояния. В
React состояние читается как обычный объект, в Solid - через реактивную функцию доступа, Vue
передаёт реактивное хранилище прямо в шаблон, а Svelte возвращает функцию-геттер, поэтому
состояние читается через `accordion().value`.

## Стилизация

Для структурных стилей передавайте экспортируемым частям `className` в React или `class` в Solid, Vue и Svelte.
Состояния лучше оформлять через атрибуты данных Ark, например `data-state`, `data-disabled` и
`data-orientation`, вместе с селекторами `data-slot` moduix. Варианты на Tailwind настраиваются
обычными утилитами и пользовательскими классами; перечисленные ниже переменные относятся к
вариантам с CSS Modules. Атрибуты данных и селекторы `data-slot` общие для обоих подходов.

Задавайте отступы панели на `AccordionItemBody`, а не на `AccordionItemContent`, чтобы Ark мог
правильно измерять и анимировать панель.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `Accordion` | `accordion-root` |
| `AccordionRootProvider` | `accordion-root-provider` |
| `AccordionItem` | `accordion-item` |
| `AccordionItemTrigger` | `accordion-item-trigger` |
| `AccordionItemIndicator` | `accordion-item-indicator` |
| `AccordionItemContent` | `accordion-item-content` |
| `AccordionItemBody` | `accordion-item-body` |

- Селекторы частей Ark: `data-scope="accordion"` и
  `data-part="root|item|item-trigger|item-indicator|item-content"`.
- Дополнительный селектор moduix: `data-part="item-body"` на части тела элемента.
- Селекторы состояния Ark: `data-state="open|closed"`, `data-disabled`, `data-focus`, `data-controls`
  и `data-orientation="horizontal|vertical"`.
- Переменные содержимого Ark: `--height` для вертикальной анимации и `--width` для горизонтальной анимации.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `Enter` / `Space` | Открывает или закрывает пункт в фокусе. |
| `ArrowDown` / `ArrowUp` | Переводит фокус на следующий или предыдущий заголовок. |
| `Home` / `End` | Переводит фокус на первый или последний заголовок. |

## Справочник API

| Проп | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `value` | `string[]` | — | Раскрытые элементы в управляемом режиме. |
| `defaultValue` | `string[]` | — | Изначально раскрытые элементы. |
| `onValueChange` | `(details: ValueChangeDetails) => void` | — | Вызывается при раскрытии и сворачивании элементов. |
| `multiple` | `boolean` | `false` | Разрешает держать открытыми несколько элементов. |
| `collapsible` | `boolean` | `false` | Разрешает закрыть открытый элемент в одиночном режиме. |
| `disabled` | `boolean` | `false` | Отключает элемент управления. |
| `orientation` | `'horizontal' \| 'vertical'` | `'vertical'` | Направление стрелок: `vertical` или `horizontal`. |
| `lazyMount` | `boolean` | `false` | Монтирует содержимое при первом открытии. |
| `unmountOnExit` | `boolean` | `false` | Удаляет содержимое после закрытия. |
| `onFocusChange` | `(details: FocusChangeDetails) => void` | — | Вызывается, когда фокус переходит на другой триггер. |
