## Когда использовать

Используйте `Format.RelativeTime`, когда важнее, сколько времени прошло или осталось до события, чем точная отметка
времени: в лентах активности, статусах сохранения, дедлайнах и списках предстоящих событий. Передайте объект `Date`
в `value`. Во время рендера Ark сравнивает дату с текущим временем, выбирает подходящую единицу, от секунд до лет,
и форматирует результат через `Intl.RelativeTimeFormat`.

По умолчанию `numeric` имеет значение `"always"`, поэтому результат будет числовым, например «через 12 минут» или
«1 день назад». Укажите `numeric="auto"`, чтобы использовать естественные формулировки вроде «завтра» и «вчера».

Импортируйте `Format` напрямую из Ark UI:

```tsx
import { Format } from '@ark-ui/react';
```

## Локаль

`Format.RelativeTime` получает локаль из `LocaleProvider`. Если провайдер не задан, Ark использует `en-US`. moduix
переэкспортирует `LocaleProvider`, поэтому одним провайдером можно задать локаль для относительного времени и других
компонентов, учитывающих локаль:

```tsx
import { Format } from '@ark-ui/react';
import { LocaleProvider } from '@moduix/react/locale';

const lastUpdatedAt = new Date(Date.now() - 24 * 60 * 60 * 1000);

export function LocalizedUpdate() {
  return (
    <LocaleProvider locale="fr-FR">
      <Format.RelativeTime numeric="auto" value={lastUpdatedAt} />
    </LocaleProvider>
  );
}
```

## Параметры отображения

`Format.RelativeTime` принимает стандартные параметры `Intl.RelativeTimeFormatOptions`. Чаще всего нужны следующие:

| Параметр  | Значения                                   | Назначение                                  |
| --------- | ------------------------------------------ | ------------------------------------------- |
| `numeric` | `"always"` (по умолчанию), `"auto"`       | Числа или естественные формулировки.        |
| `style`   | `"long"` (по умолчанию), `"short"`, `"narrow"` | Длина результата.                         |

Единицу времени и число отдельно передавать не нужно. Компонент вычисляет их по объекту `Date`, переданному в
`value`.

## Обновление со временем

`Format.RelativeTime` не запускает таймер. Компонент вычисляет строку во время рендера и не меняет её, пока приложение
не отрендерит его снова. Если подпись должна оставаться актуальной, обеспечьте повторный рендер с подходящей для
интерфейса частотой. Для длительности или обратного отсчёта, которые должны обновляться постоянно, используйте
[`Timer`](/docs/timer).

## Использование с moduix

`Format.RelativeTime` выводит только текст, без элемента-обёртки. Поместите его в компонент компоновки, статуса или
отображения данных, который поясняет, к чему относится относительное время. В примерах на этой странице для такого
контекста используются `Card` и `Stack` из moduix.

Форматирование выполняет Ark UI, поэтому `Format.RelativeTime` импортируется из `@ark-ui/react`. moduix предоставляет
компоненты интерфейса и переэкспортирует `LocaleProvider`, но не переэкспортирует `Format.RelativeTime`.
