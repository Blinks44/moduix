## Когда использовать

Используйте `Format.RelativeTime`, когда важнее, сколько времени прошло или осталось, а не точная дата: в лентах
событий, статусах сохранения, сроках и предстоящих событиях. Он принимает `Date`, сравнивает его с текущим временем
во время рендера и возвращает текст вроде «через 12 минут» или «вчера».

Импортируйте `Format` напрямую из Ark UI:

```tsx
import { Format } from '@ark-ui/react';
```

## Базовый пример

Используйте `numeric="auto"`, когда естественные слова вроде «завтра» и «вчера» понятнее числа. Размещайте
отформатированный текст рядом со статусом или событием, которое он описывает.

## Локаль и обновление

`Format.RelativeTime` получает локаль из `LocaleProvider`. moduix переэкспортирует этот провайдер, поэтому его можно
использовать как единый провайдер локали для всего интерфейса:

```tsx
import { Format } from '@ark-ui/react';
import { LocaleProvider } from '@moduix/react/locale';

const lastUpdatedAt = new Date(Date.now() - 24 * 60 * 60 * 1000);

export function LocalizedUpdate() {
  return (
    <LocaleProvider locale="fr-FR">
      <Format.RelativeTime numeric="auto" value={lastUpdatedAt} />
    </LocaleProvider>
  );
}
```

Форматтер вычисляет текст во время рендера React и не обновляет его сам по мере течения времени. Если надпись должна
оставаться актуальной, выполняйте повторный рендер компонента с нужной частотой; для динамического обратного отсчёта
используйте `Timer`.

## Использование с moduix

`Format.RelativeTime` выводит только текст. Используйте `Card`, `Stack`, `Text` и компоненты статуса moduix, чтобы
показать, к какому событию относится время. Не создавайте отдельный компонент только для вызова форматтера.

## Границы ответственности

Ark UI отвечает за форматирование относительного времени и API `Format.RelativeTime`. moduix предоставляет
компоненты интерфейса и переэкспортирует `LocaleProvider`, но не переэкспортирует `Format.RelativeTime`.
