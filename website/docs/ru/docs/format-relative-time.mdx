## Когда использовать

Используйте `Format.RelativeTime`, когда расстояние от текущего момента важнее точной отметки времени: в лентах
активности, статусах сохранения, дедлайнах и списках предстоящих событий. Передайте объект `Date` в `value`. Во
время рендера Ark вычисляет разницу, выбирает единицу от секунд до лет и форматирует результат через
`Intl.RelativeTimeFormat`.

Форматтер выводит только текст. Добавьте его в разметку, которая объясняет значение. Если значение представляет
момент времени, используйте семантический элемент `<time>` и передайте его точное значение в формате ISO через
`dateTime`.

## Краткий формат

Укажите `style="short"`, когда место ограничено, например в компактной строке статуса. `style="narrow"` дает самый
короткий вариант, если окружающая интерфейсная разметка уже объясняет смысл. Оставляйте точную отметку времени в
`dateTime`, если человеку может понадобиться ее проверить.

`Format.RelativeTime` принимает все стандартные параметры `Intl.RelativeTimeFormatOptions` в дополнение к `value`:

| Параметр        | Значения                                                 | Назначение                                  |
| --------------- | -------------------------------------------------------- | ------------------------------------------- |
| `localeMatcher` | `"best fit"` (по умолчанию), `"lookup"`                | Выбрать алгоритм сопоставления локали.      |
| `numeric`       | `"always"` (по умолчанию), `"auto"`                    | Использовать числа или естественные слова.  |
| `style`         | `"long"` (по умолчанию), `"short"`, `"narrow"`        | Управлять длиной результата.                |

Единица времени и числовое расстояние вычисляются по объекту `Date`, поэтому отдельно передавать их не нужно.

## Локаль

`Format.RelativeTime` получает локаль из ближайшего Ark `LocaleProvider`. Если провайдер не задан, используется
`en-US`. Импортируйте провайдер из соответствующего пакета Ark.

## Обновление со временем

`Format.RelativeTime` вычисляет текст во время рендера и не запускает таймер. Подпись вроде «2 минуты назад» не
изменится, пока приложение не отрендерит ее снова. Запускайте обновления через состояние приложения с частотой,
подходящей интерфейсу. Для постоянно обновляемой длительности или обратного отсчета используйте
[`Timer`](/docs/timer).
