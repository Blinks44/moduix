## Когда использовать

Используйте `DownloadTrigger`, когда по действию пользователя нужно скачать URL, `Blob`, `File` или сгенерированный
текст. Передайте данные, имя файла и MIME-тип; данные также может вернуть асинхронная функция.

Импортируйте утилиту напрямую из Ark UI: moduix не предоставляет для неё обёртку.

```tsx
import { DownloadTrigger } from '@ark-ui/react/download-trigger';
```

## Базовый пример

Передайте строку, `Blob` или `File` в `data`, затем укажите `fileName` и `mimeType`. Используйте `asChild`, чтобы
сохранить внешний вид и семантику кнопки moduix.

## Генерация по запросу

Если экспорт нужно подготовить, передайте функцию, которая возвращает данные или промис. Ark UI вызовет её только
после нажатия, поэтому экспорт не создаётся при первоначальном рендеринге.

Пусть эта функция занимается только подготовкой файла. Состоянием загрузки, проверкой данных и сообщениями об
ошибках управляйте в приложении; при необходимости отключайте или заменяйте триггер.

## Метаданные файла

Подберите расширение под данные и укажите соответствующий MIME-тип: например, `application/json`, `text/csv`,
`image/svg+xml` или `application/pdf`. Тогда браузер и операционная система корректно распознают скачанный файл.

## Использование с moduix

`DownloadTrigger` намеренно не стилизуется. Используйте его с `asChild` и кнопкой moduix, чтобы действие выглядело
так же, как остальные элементы интерфейса. Для изображения QR-кода, созданного компонентом moduix `QrCode`, выберите
`QrCode.DownloadTrigger`: он уже умеет экспортировать это изображение.

## Границы ответственности

Ark UI отвечает за скачивание, включая API `data`, `fileName` и `mimeType`. moduix показывает, как использовать
утилиту со своими компонентами, но не переэкспортирует и не стилизует этот триггер.
