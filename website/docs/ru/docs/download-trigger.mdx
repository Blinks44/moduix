## Что делает компонент

`DownloadTrigger` представляет собой утилиту Ark UI. По умолчанию она создаёт нативную кнопку и запускает скачивание,
когда пользователь активирует её. В `data` передают содержимое файла: строку, `Blob`, `File` или функцию, которая
возвращает одно из этих значений сразу либо через промис. Строка считается содержимым файла, а не URL для загрузки. Чтобы
скачать удалённый ресурс, сначала получите его в приложении и верните из функции, переданной в `data`, результат
`await response.blob()`.

Общую утилиту нужно импортировать напрямую из Ark UI. В `@moduix/react` она не переэкспортируется:

```tsx
import { DownloadTrigger } from '@ark-ui/react/download-trigger';
```

## Генерация по запросу

Передайте функцию, если файл нужно подготовить перед скачиванием. Ark вызовет её после активации триггера. Если
функция вернёт промис, Ark дождётся его выполнения и только потом сохранит файл.

У `DownloadTrigger` нет собственного состояния загрузки и обработчика ошибок. Если генерация может занять время,
храните её состояние в приложении и обрабатывайте ошибки внутри функции, переданной в `data`. На время операции
отключайте или заменяйте триггер.

## Метаданные файла

Укажите в `fileName` расширение, соответствующее содержимому, и задайте соответствующий `mimeType`: например,
`application/json`, `text/csv`, `image/svg+xml` или `application/pdf`. Если возвращаете `Blob` или `File`, значение
его `type` тоже должно совпадать с `mimeType`.

## Использование с moduix

У `DownloadTrigger` нет собственных стилей. Используйте `asChild` и кнопку moduix, чтобы действие соответствовало
остальному интерфейсу. Если нужно скачать изображение, созданное компонентом moduix `QrCode`, откройте страницу
[`QrCode`](/docs/qr-code) и используйте `QrCode.DownloadTrigger`. Он сам получает изображение из ближайшего QR-кода и
экспортирует его.

## Что относится к Ark UI

За общее поведение скачивания и API `data`, `fileName` и `mimeType` отвечает Ark UI. moduix показывает, как сочетать
эту утилиту со своими компонентами, но не предоставляет общий экспорт `DownloadTrigger` и не добавляет стили к
компоненту Ark.
