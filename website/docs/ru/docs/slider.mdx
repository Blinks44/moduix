## Выбор подходящего компонента

Используйте `Slider`, когда пользователю нужно выбрать числовое значение в заданных границах с помощью указателя
или клавиатуры.

- Выберите **`Slider`** для громкости, яркости, бюджета, пороговых значений и диапазонов с несколькими ползунками.
- Выберите **`Input`** или **`NumberInput`**, если значение нужно точно ввести с клавиатуры, а не выбирать перетаскиванием.
- Выберите **`ProgressLinear`** или **`ProgressCircular`**, если значение нужно только показать.

## Анатомия

```text
Slider
├─ SliderLabel
├─ SliderValueText
├─ SliderControl
│  ├─ SliderTrack
│  │  └─ SliderRange
│  └─ SliderThumb[index]
│     ├─ SliderDraggingIndicator
│     └─ SliderHiddenInput
└─ SliderMarkerGroup
   └─ SliderMarker[value]
```

| Часть                                  | Назначение                                                       |
| -------------------------------------- | ---------------------------------------------------------------- |
| `Slider` / `Slider`               | Стилизованный корневой элемент Ark для управляемого и неуправляемого состояния. |
| `SliderHiddenInput` | Нативное поле Ark; правила явной композиции описаны ниже. |
| `SliderRootProvider`                  | Корневой элемент, подключённый к состоянию `useSlider`, созданному отдельно.    |
| `SliderLabel`                         | Видимая подпись группы.                                                        |
| `SliderValueText`                     | Текст текущего значения, который формирует Ark.                               |
| `SliderControl`                       | Область взаимодействия с указателем.                                          |
| `SliderTrack`                         | Полная визуальная дорожка.                                                     |
| `SliderRange`                         | Заполненная часть от точки отсчёта до текущего значения.                       |
| `SliderThumb`                         | Ползунок, который можно сфокусировать.                                        |
| `SliderThumbs`                        | Вспомогательный компонент moduix, создающий ползунок для каждого значения.      |
| `SliderMarkerGroup` / `SliderMarker` | Необязательная группа отметок и отдельная отметка.                             |
| `SliderDraggingIndicator`             | Необязательное всплывающее значение во время перетаскивания.                   |

## Композиция

Используйте `SliderThumbs` для стандартной композиции с одним ползунком на каждое значение:
компонент также добавляет по одному `SliderHiddenInput` на каждый ползунок. Если ползунку
нужны своё содержимое, доступное имя или определённый порядок, используйте `SliderThumb`
явно и вложите в него один `SliderHiddenInput`. Для отправки формы задайте `name` на корневом
компоненте.

Для управляемого состояния сохраняйте `details.value` из `onValueChange` или
`onValueChangeEnd`. Используйте `useSliderContext` во вложенных компонентах, чтобы читать
состояние. Если состояние нужно создать вне дерева, создайте его через `useSlider` и передайте
в `SliderRootProvider`; не создавайте второй корневой компонент для того же store. В React
store читается как объект, а в Solid через возвращённый реактивный accessor. Корневое значение
называется `Slider`.

### Хуки стилизации

Ark добавляет `data-scope="slider"` и `data-part` ко всем отрендеренным частям. moduix также добавляет
значения `data-slot`: `slider-root`, `slider-root-provider`, `slider-label`, `slider-value-text`,
`slider-control`, `slider-track`, `slider-range`, `slider-thumb`,
`slider-marker-group`, `slider-marker` и `slider-dragging-indicator`.

К важным атрибутам состояния Ark относятся `data-orientation`, `data-disabled`, `data-invalid`,
`data-focus`, `data-dragging`, `data-state` у отметок и `data-state="open | closed"` индикатора
перетаскивания. CSS-переменные Ark, которые используются во время работы: `--slider-thumb-width`, `--slider-thumb-height`,
`--slider-thumb-transform`, `--slider-range-start`, `--slider-range-end`, `--translate-x` и `--translate-y`.

moduix добавляет `data-readonly` к `Slider`, когда задано свойство `readOnly`. В состоянии ошибки по умолчанию
дорожка, выбранный диапазон, ползунок и активные отметки окрашиваются деструктивным цветом.
Их можно переопределить по отдельности через `--moduix-slider-track-border-color-invalid`,
`--moduix-slider-range-bg-invalid`, `--moduix-slider-thumb-border-color-invalid`,
`--moduix-slider-thumb-focus-ring-color-invalid` и `--moduix-slider-marker-dot-bg-active-invalid`.

Стандартное кольцо фокуса ползунка использует `:focus-visible` при навигации с клавиатуры и `data-dragging` Ark
во время перетаскивания. После отпускания указателя оно исчезает.
