## Выбор подходящего компонента

Используйте `Slider`, когда пользователю нужно выбрать числовое значение в заданных границах с помощью указателя
или клавиатуры.

- Выберите **`Slider`** для громкости, яркости, бюджета, пороговых значений и диапазонов с несколькими ползунками.
- Выберите **`Input`** или **`NumberInput`**, если значение нужно точно ввести с клавиатуры, а не выбирать перетаскиванием.
- Выберите **`ProgressLinear`** или **`ProgressCircular`**, если значение нужно только показать.

## Анатомия

```text
Slider / Slider.Root
├─ Slider.Label
├─ Slider.ValueText
├─ Slider.Control
│  ├─ Slider.Track
│  │  └─ Slider.Range
│  └─ Slider.Thumbs
│     └─ Slider.Thumb[index]
│        ├─ Slider.DraggingIndicator
│        └─ нативное поле ввода (автоматически)
└─ Slider.MarkerGroup
   └─ Slider.Marker[value]
```

| Часть                                  | Назначение                                                       |
| -------------------------------------- | ---------------------------------------------------------------- |
| `Slider` / `Slider.Root`               | Стилизованный корневой элемент Ark для управляемого и неуправляемого состояния. |
| `Slider.RootProvider`                  | Корневой элемент, подключённый к состоянию `useSlider`, созданному отдельно.    |
| `Slider.Label`                         | Видимая подпись группы.                                                        |
| `Slider.ValueText`                     | Текст текущего значения, который формирует Ark.                               |
| `Slider.Control`                       | Область взаимодействия с указателем.                                          |
| `Slider.Track`                         | Полная визуальная дорожка.                                                     |
| `Slider.Range`                         | Заполненная часть от точки отсчёта до текущего значения.                       |
| `Slider.Thumb`                         | Ползунок, который можно сфокусировать.                                        |
| `Slider.Thumbs`                        | Вспомогательный компонент moduix, создающий ползунок для каждого значения.      |
| `Slider.MarkerGroup` / `Slider.Marker` | Необязательная группа отметок и отдельная отметка.                             |
| `Slider.DraggingIndicator`             | Необязательное всплывающее значение во время перетаскивания.                   |

## Композиция

### Рекомендуемая композиция

Используйте дерево частей Ark: корневой элемент, подпись, при необходимости текст значения, область управления, дорожку,
заполненный диапазон и `Slider.Thumbs`. Компонент создаёт по одному ползунку на каждое значение, а каждый ползунок
автоматически добавляет нативное поле ввода для формы.

`Slider` - короткая запись для корня, эквивалентная `Slider.Root`.

### Когда нужна собственная композиция

Используйте `asChild`, если часть должна рендериться в вашем элементе. Внутри должен оставаться один семантический
дочерний элемент, который принимает свойства Ark. Если отдельным ползункам нужны свои дочерние элементы, доступные имена
или определённый порядок, используйте `Slider.Thumb` явно: нативное поле ввода при этом сохраняется. Для расширенного доступа
к состоянию используйте `Slider.Context` или `useSliderContext`, чтобы читать состояние под корневым элементом. Если состояние
нужно создать вне дерева слайдера, импортируйте `useSlider` из `@moduix/react/slider` и используйте его с
`Slider.RootProvider`.

### Свойства по умолчанию

| Свойство                 | По умолчанию  | Примечания                                                                 |
| ------------------------ | ------------- | -------------------------------------------------------------------------- |
| `defaultValue`           | `[min]`       | Ark хранит значения в виде `number[]`.                                    |
| `orientation`            | `horizontal`  | `vertical` переключает вертикальную ориентацию.                           |
| `min`                    | `0`           | Нижняя граница.                                                            |
| `max`                    | `100`         | Верхняя граница.                                                           |
| `step`                   | `1`           | Шаг для указателя и клавиатуры.                                            |
| `largeStep`              | `10 * step`   | Шаг для Page Up, Page Down и Shift + стрелки.                              |
| `minStepsBetweenThumbs`  | `0`           | Минимальное число шагов между ползунками диапазона.                       |
| `origin`                 | `start`       | Точка, от которой заполняется диапазон с одним значением.                  |
| `thumbAlignment`         | `contain`     | Используйте `center`, чтобы ползунок выходил за края дорожки.              |
| `thumbCollisionBehavior` | `none`        | Используйте `push` или `swap`, чтобы изменить поведение при встрече.       |
| `thumbSize`              | измеряется    | Переопределяет размеры ползунка, измеренные Ark.                           |

`value`, `defaultValue`, `onValueChange(details)` и `onValueChangeEnd(details)` используют объекты details Ark.
Читайте массив из `details.value`. `onFocusChange(details)` сообщает, какой ползунок получил фокус. Если `defaultValue`
не задан, начальное значение равно `[min]`, то есть по умолчанию `[0]`. Используйте `ids`, если другим элементам нужны
стабильные идентификаторы частей слайдера.

### Особенности поведения

`Slider` реализует паттерн слайдера WAI-ARIA из Ark. У каждого ползунка должно быть доступное имя, заданное через
`Slider.Label`, `aria-label` или `aria-labelledby`. В горизонтальном слайдере работают стрелки влево и вправо, в
вертикальном - вверх и вниз. `Page Up`, `Page Down` и `Shift + ArrowUp` или `Shift + ArrowDown` используют `largeStep`
(по умолчанию `10 * step`). `Home` и `End` устанавливают минимальное и максимальное значения активного ползунка.

Каждый `Slider.Thumb` автоматически добавляет скрытое нативное поле ввода. Оно участвует в отправке формы и синхронизируется
при её сбросе. `id`, `asChild`, `disabled`, `invalid`, `readOnly`, `name`, `form`, `ids`, `aria-label`, `aria-labelledby`
и `getAriaValueText(details)` без изменений передаются в Ark.

### Хуки стилизации

Ark добавляет `data-scope="slider"` и `data-part` ко всем отрендеренным частям. moduix также добавляет
значения `data-slot`: `slider-root`, `slider-root-provider`, `slider-label`, `slider-value-text`,
`slider-control`, `slider-track`, `slider-range`, `slider-thumb`, `slider-hidden-input`,
`slider-marker-group`, `slider-marker` и `slider-dragging-indicator`.

К важным атрибутам состояния Ark относятся `data-orientation`, `data-disabled`, `data-invalid`,
`data-focus`, `data-dragging`, `data-state` у отметок и `data-state="open | closed"` индикатора
перетаскивания. CSS-переменные Ark, которые используются во время работы: `--slider-thumb-width`, `--slider-thumb-height`,
`--slider-thumb-transform`, `--slider-range-start`, `--slider-range-end`, `--translate-x` и `--translate-y`.

moduix добавляет `data-readonly` к `Slider`, когда задано свойство `readOnly`. В состоянии ошибки по умолчанию
дорожка, выбранный диапазон, ползунок и активные отметки окрашиваются деструктивным цветом.
Их можно переопределить по отдельности через `--moduix-slider-track-border-color-invalid`,
`--moduix-slider-range-bg-invalid`, `--moduix-slider-thumb-border-color-invalid`,
`--moduix-slider-thumb-focus-ring-color-invalid` и `--moduix-slider-marker-dot-bg-active-invalid`.

Стандартное кольцо фокуса ползунка использует `:focus-visible` при навигации с клавиатуры и `data-dragging` Ark
во время перетаскивания. После отпускания указателя оно исчезает.
