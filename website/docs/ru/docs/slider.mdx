## Использование

<Usage />

`SliderThumbs` создаёт по одному ползунку с нативным полем на значение. Для своего содержимого ползунка
используйте `SliderThumb` явно и вложите в него `SliderHiddenInput`.

## Выбор подходящего компонента

Используйте `Slider`, когда пользователю нужно выбрать числовое значение в заданных границах с помощью указателя
или клавиатуры.

- Выберите **`Slider`** для громкости, яркости, бюджета, пороговых значений и диапазонов с несколькими ползунками.
- Выберите **`Input`** или **`NumberInput`**, если значение нужно точно ввести с клавиатуры, а не выбирать перетаскиванием.
- Выберите **`ProgressLinear`** или **`ProgressCircular`**, если значение нужно только показать.

## Примеры

### Диапазон

Передайте массив, содержащий по одному значению на каждый ползунок. `SliderThumbs` создаст соответствующие ползунки
и скрытые поля ввода для формы.

<Example name="slider/range" width="sm" />

### Деления

Используйте `SliderMarkerGroup` и `SliderMarker`, чтобы добавить отметки на дорожку. Ark добавляет к отметкам
`data-state="under-value | at-value | over-value"`, который можно использовать в стилях.

<Example name="slider/marks" width="sm" />

### Шаг

Используйте `step` для дробного или более точного шага.

<Example name="slider/step" width="sm" />

### Минимум и максимум

Задайте `min` и `max`, если диапазон слайдера не начинается с `0` или не заканчивается на `100`.

<Example name="slider/min-and-max" width="sm" />

### Вертикальный

Задайте `orientation="vertical"` и явно задайте корневому элементу высоту.

<Example name="slider/vertical" />

### Вертикальный с делениями

В вертикальной ориентации отметки выравниваются по дорожке и используют те же атрибуты состояния.

<Example name="slider/vertical-with-marks" />

### Центр как точка отсчёта

Задайте `origin="center"`, если значение представляет положительное или отрицательное смещение, например баланс относительно нуля.

<Example name="slider/center-origin" width="sm" />

### Отключённый

Используйте `disabled`, чтобы оставить значение видимым, но отключить взаимодействие.

<Example name="slider/disabled" width="sm" />

### Только для чтения

Используйте `readOnly`, если значение должно оставаться видимым, а ползунок - доступным для фокуса, но изменять его нельзя.
В этом состоянии moduix использует курсор по умолчанию, поэтому слайдер не выглядит интерактивным.

<Example name="slider/read-only" width="sm" />

### Некорректное значение

Используйте `invalid`, если выбранное значение не проходит проверку. Дорожка, диапазон и ползунок получают состояние
ошибки, но остаются интерактивными.

<Example name="slider/invalid" width="sm" />

### Форма

Задайте `name` и вложите `SliderHiddenInput` в каждый явный ползунок, чтобы отправлять текущее значение.

<Example name="slider/form" width="sm" />

### Выравнивание ползунка

Используйте `thumbAlignment="center"`, если ползунок должен выходить за края дорожки.

<Example name="slider/thumb-alignment" width="sm" />

### Столкновение ползунков

Используйте `thumbCollisionBehavior`, чтобы задать поведение ползунков диапазона при встрече. Значение `none` (по умолчанию)
не позволяет одному ползунку пройти дальше другого, `push` двигает второй ползунок, а `swap` меняет их местами.

<Example name="slider/thumb-collision" width="sm" />

### Перекрытие ползунков

Используйте `minStepsBetweenThumbs`, чтобы задать минимальный зазор между ползунками диапазона. Фактический зазор равен
`minStepsBetweenThumbs * step`.

<Example name="slider/thumb-overlap" width="sm" />

### Индикатор перетаскивания

Поместите `SliderDraggingIndicator` внутрь ползунка, чтобы показывать его текущее значение при перетаскивании.

<Example name="slider/dragging-indicator" width="sm" />

### События изменения

Используйте `onValueChange` (или событие Vue `value-change`; в Svelte те же свойства-колбэки), чтобы обновлять интерфейс во время
взаимодействия, а `onValueChangeEnd` (или `value-change-end`) - когда перетаскивание или
взаимодействие с клавиатурой завершено.

<Example name="slider/change-events" width="sm" />

### Управляемое состояние

Управляйте слайдером из состояния выбранного фреймворка, сохраняя массив из `details.value`; во
Vue для управляемого контракта можно связать `v-model` с ref, а в Svelte использовать `bind:value`.

<Example name="slider/controlled" width="sm" />

### Контекст

Используйте `useSliderContext` из moduix внутри дочернего компонента, если ему нужно читать состояние слайдера, например
`value`, `dragging` или состояние фокуса.

<Example name="slider/context" width="sm" />

### Root Provider

Используйте `useSlider` из moduix с `SliderRootProvider`, если состояние нужно создать вне дерева, в котором отображаются
части слайдера. Рендерьте эти части внутри `SliderRootProvider` и не добавляйте второй корень для того же состояния.

<Example name="slider/root-provider" width="sm" />

## Композиция

Используйте `SliderThumbs` для стандартной композиции с одним ползунком на каждое значение:
компонент также добавляет по одному `SliderHiddenInput` на каждый ползунок. Если ползунку
нужны своё содержимое, доступное имя или определённый порядок, используйте `SliderThumb`
явно и вложите в него один `SliderHiddenInput`. Для отправки формы задайте `name` на корневом
компоненте.

Для управляемого состояния сохраняйте `details.value` из `onValueChange` или
`onValueChangeEnd`; во Vue для того же контракта можно связать `v-model` с ref, а в Svelte использовать `bind:value`. Используйте
`useSliderContext` во вложенных компонентах, чтобы читать состояние. Если состояние нужно создать
вне дерева, создайте его через `useSlider` и передайте в `SliderRootProvider`; не создавайте
второй корневой компонент для того же хранилища. В React хранилище читается как объект, в Solid через
возвращённый реактивный accessor, во Vue реактивное хранилище доступно прямо в шаблоне, а в Svelte хук возвращает геттер: состояние читается через `slider().value`.

## Стилизация

Настраивайте внешний вид `Slider` через `className` (React) или `class` (Solid, Vue, Svelte), атрибуты Ark, стабильные точки настройки `data-slot="slider-*"`,
CSS-переменные Ark и публичные CSS-переменные moduix ниже.

### CSS-переменные

Наведите на переменную или выберите её, чтобы увидеть её в превью.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `Slider` | `slider-root` |
| `SliderRootProvider` | `slider-root-provider` |
| `SliderLabel` | `slider-label` |
| `SliderValueText` | `slider-value-text` |
| `SliderControl` | `slider-control` |
| `SliderTrack` | `slider-track` |
| `SliderRange` | `slider-range` |
| `SliderThumb` | `slider-thumb` |
| `SliderMarkerGroup` | `slider-marker-group` |
| `SliderMarker` | `slider-marker` |
| `SliderDraggingIndicator` | `slider-dragging-indicator` |

Ark добавляет `data-scope="slider"` и `data-part` ко всем отрендеренным частям.

К важным атрибутам состояния Ark относятся `data-orientation`, `data-disabled`, `data-invalid`,
`data-focus`, `data-dragging`, `data-state` у отметок и `data-state="open | closed"` индикатора
перетаскивания. CSS-переменные Ark, которые используются во время работы: `--slider-thumb-width`, `--slider-thumb-height`,
`--slider-thumb-transform`, `--slider-range-start`, `--slider-range-end`, `--translate-x` и `--translate-y`.

moduix добавляет `data-readonly` к `Slider`, когда задано свойство `readOnly`. В состоянии ошибки по умолчанию
дорожка, выбранный диапазон, ползунок и активные отметки окрашиваются деструктивным цветом.

Горизонтальный `Slider` ставит `SliderLabel` и `SliderValueText` в одну строку над элементом управления и
занимает всю ширину контейнера. Вертикальный `Slider` имеет высоту `12rem`; чтобы изменить размер, задайте
`width` или `height` корню.

Стандартное кольцо фокуса ползунка использует `:focus-visible` при навигации с клавиатуры и `data-dragging` Ark
во время перетаскивания. После отпускания указателя оно исчезает.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `ArrowRight` / `ArrowUp` | Увеличивает значение на шаг. |
| `ArrowLeft` / `ArrowDown` | Уменьшает значение на шаг. |
| `PageUp` / `PageDown`, `Shift` + стрелки | Меняет значение на большой шаг. |
| `Home` / `End` | Ставит минимум или максимум. |

## Справочник API

| Проп | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `value` | `number[]` | — | Значения бегунков в управляемом режиме, по числу на бегунок. |
| `defaultValue` | `number[]` | — | Начальные значения бегунков. |
| `onValueChange` | `(details: ValueChangeDetails) => void` | — | Вызывается при изменении значения. |
| `onValueChangeEnd` | `(details: ValueChangeDetails) => void` | — | Вызывается, когда пользователь закончил менять значение. |
| `min` | `number` | `0` | Минимальное значение. |
| `max` | `number` | `100` | Максимальное значение. |
| `step` | `number` | `1` | Шаг между значениями. |
| `largeStep` | `number` | `10 * step` | Шаг для Shift со стрелками и Page Up или Page Down. |
| `minStepsBetweenThumbs` | `number` | `0` | Минимальное расстояние между бегунками, в шагах. |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Направление: `horizontal` или `vertical`. |
| `origin` | `'start' \| 'center' \| 'end'` | `'start'` | Откуда начинается заливка: `start`, `center` или `end`. |
| `thumbCollisionBehavior` | `'none' \| 'push' \| 'swap'` | `'none'` | Что делают бегунки при встрече: `none`, `push` или `swap`. |
| `getAriaValueText` | `(details: ValueTextDetails) => string` | — | Возвращает понятный текст значения для экранных дикторов. |
| `name` | `string` | — | Имя поля формы для бегунков. |
| `disabled` | `boolean` | `false` | Отключает элемент управления. |
| `readOnly` | `boolean` | `false` | Показывает значение, но не даёт его менять. |
| `invalid` | `boolean` | `false` | Помечает поле как невалидное. |
| `required` | `boolean` | `false` | Требует значение перед отправкой формы. |
| `aria-label` | `string[]` | — | Доступное имя каждого бегунка. |
| `aria-labelledby` | `string[]` | — | Id элементов, подписывающих каждый бегунок. |
| `form` | `string` | — | Id формы, к которой относится внутренний input. |
| `onFocusChange` | `(details: FocusChangeDetails) => void` | — | Вызывается, когда фокус переходит на другой бегунок. |
| `thumbAlignment` | `'contain' \| 'center'` | `'contain'` | Держит бегунки внутри дорожки (`contain`) или по центру значения (`center`). |
| `thumbSize` | `{ width: number; height: number }` | — | Размер бегунка, нужен для выравнивания `contain` при серверном рендеринге. |
