## Использование

Используйте `AspectRatio` как корневой элемент адаптивного контейнера. По умолчанию он занимает всю доступную
ширину родительского контейнера. Если размер нужно ограничить или изменить, задайте корневому элементу `width`
или `max-width`, а в `ratio` передайте отношение ширины к высоте.
По умолчанию `ratio` равен `1`; отсутствующее или некорректное значение (ноль, отрицательное, `NaN`, `Infinity`) тоже даёт `1`.

`AspectRatio` управляет только соотношением сторон. Размеры и оформление дочерних элементов задавайте явно:
например, укажите изображению полную ширину и высоту вместе с `object-fit`. Обрезку и радиус добавляйте корневому
элементу только там, где они нужны композиции.

## Примеры

### Карточки

Одинаковое соотношение сторон у медиаконтента помогает выровнять карточки в списке, даже если исходные изображения
имеют разные размеры.

<Example name="aspect-ratio/card-grid" />

### Встроенное содержимое

Оберните видео или другой встроенный элемент в `AspectRatio`, чтобы размер контейнера не менялся во время загрузки
внешнего содержимого.

<Example name="aspect-ratio/embedded-content" />

### Миграция с shadcn

При переходе с shadcn задайте `AspectRatio` ширину, обрезку и радиус, а размер вложенного медиаконтента укажите явно.
Такой же корневой компонент подходит для `Image` из Next.js с `fill`.

<Example name="aspect-ratio/migrating-from-shadcn" />

### Расширенная настройка

Используйте `asChild`, если корневым элементом должен быть семантический тег, например `figure`. Фабрика Ark
передаёт свойства компонента его единственному дочернему элементу.

## Композиция

Импортируйте `AspectRatio` из пакета, соответствующего фреймворку и способу стилизации: для CSS Modules это
`@moduix/react/aspect-ratio`, `@moduix/solid/aspect-ratio` или `@moduix/vue/aspect-ratio`, а для Tailwind - по
соответствующему пути `@moduix/react-tailwind/aspect-ratio`, `@moduix/solid-tailwind/aspect-ratio` или
`@moduix/vue-tailwind/aspect-ratio`.

`AspectRatio` отвечает только за раскладку и не владеет состоянием. У
компонента одна корневая часть, и дополнительные части не нужно комбинировать. Используйте `asChild` только если
отрисованным корневым элементом должен владеть другой семантический элемент: передайте ровно одного дочернего
элемента в React или используйте показанную в примере «Расширенная настройка» функцию рендера Solid. Во Vue
используйте атрибут `as-child` с одним дочерним элементом. Размеры,
вписывание, границы, радиус и обрезка дочернего содержимого остаются ответственностью приложения.

В Solid передавайте `ref` элементу, созданному внутри функции рендера для `asChild`. Сам компонент
`AspectRatio` не передаёт `ref` по этому пути композиции.

## Стилизация

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `AspectRatio` | `aspect-ratio-root` |

- `data-scope="aspect-ratio"` и `data-part="root"` служат согласованными с Ark селекторами для корневого элемента.
- Задавайте ширину, максимальную ширину и стили раскладки на корневом элементе. Если при определённой ширине экрана
  нужно другое соотношение сторон, переопределите `aspect-ratio` в своём CSS.
- Компонент не оформляет дочернее содержимое. Задавайте размеры медиаконтента и `object-fit` непосредственно
  дочернему элементу.
- Содержимое выше рамки не растягивает её, а выходит за её пределы. Добавляйте `overflow: hidden` и радиус
  корневому элементу там, где содержимое нужно обрезать.

## Справочник API

Также принимает нативные пропсы своего элемента и `asChild`.

| Проп | Тип | По умолчанию |
| --- | --- | --- |
| `ratio` | `number` | `1` |
