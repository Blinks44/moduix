## Справочник API

В Ark UI нет отдельного примитива `aspect-ratio`. В moduix этот компонент создан с помощью официальной
[фабрики Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и соответствует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[работе с ref](https://ark-ui.com/docs/guides/ref).

## Базовый пример

Начните с `AspectRatio`. Задайте ширину или максимальную ширину самому корневому элементу и передайте в `ratio`
конечное положительное число. Прямые дочерние элементы `img`, `video`, `iframe`, `canvas` и `svg`
автоматически заполняют контейнер. Для изображений и видео задайте `object-fit`, если нужно обрезать содержимое
или вписать его целиком.

## Анатомия

```text
AspectRatio / AspectRatio.Root
└─ media | iframe | canvas | svg | custom content
```

| Часть                              | Назначение                                      |
| ---------------------------------- | ----------------------------------------------- |
| `AspectRatio` / `AspectRatio.Root` | Адаптивный контейнер, который обрезает содержимое. |

## Композиция

### Рекомендуемая композиция

Используйте `AspectRatio` для большинства контейнеров с медиаконтентом. Задавайте размеры, радиус скругления и классы
раскладки на самом корневом элементе. `AspectRatio.Root` предоставляет тот же корневой элемент для единообразия API библиотеки.

- `ratio` обязателен и должен быть конечным положительным числом, чтобы CSS работал корректно
- `asChild` использует композицию фабрики Ark и требует ровно одного элемента React
- прямые дочерние элементы `img`, `video`, `iframe`, `canvas` и `svg` автоматически заполняют контейнер; задайте
  `object-fit` для изображений и видео, чтобы выбрать между обрезкой и вписыванием содержимого целиком
- `className` стилизует корневой элемент и задаёт его размеры
- `--moduix-aspect-ratio-radius` управляет радиусом скругления контейнера по умолчанию

### Когда нужна внешняя обёртка

Оберните `AspectRatio` во внешний элемент, если тени, индикаторы фокуса или декоративные элементы должны выходить за
пределы обрезаемой области. Оставьте обрезку на корневом элементе. Если при определённой ширине экрана нужно другое
соотношение сторон, переопределите `aspect-ratio` в своём CSS.

### Свойства по умолчанию

| Параметр                        | По умолчанию              | Значения / примечания                    |
| ------------------------------- | ------------------------- | ---------------------------------------- |
| `ratio`                         | -                         | Обязательное конечное положительное число |
| `className`                     | `undefined`               | Стилизует корневой элемент и задаёт его размеры |
| `style`                         | `undefined`               | Может напрямую переопределить `aspect-ratio` |
| `asChild`                       | `undefined`               | Композиция через фабрику Ark              |
| `--moduix-aspect-ratio-radius`  | `var(--moduix-radius-md)` | Значение длины CSS или токен              |

### Особенности поведения

- Корневой элемент получает атрибуты `data-scope="aspect-ratio"`, `data-part="root"` и
  `data-slot="aspect-ratio-root"`.
- Корневой элемент блочный и использует `border-box`. Это сохраняется и при использовании `asChild`, когда меняется
  HTML-элемент.
- `position: relative` задан намеренно. Он позволяет использовать дочерние элементы с абсолютным позиционированием,
  которые заполняют контейнер, например Next.js `Image fill`.
- Прямые дочерние `iframe` заполняют контейнер без стандартной рамки браузера.
- Ранее компонент поддерживал строковые пресеты (`square`, `video`, `portrait`, `photo`), но после миграции на Ark они
  были удалены. Используйте числовые значения: `1`, `16 / 9`, `9 / 16` и `4 / 3`.

### Хуки стилизации

- `data-scope="aspect-ratio"` и `data-part="root"` служат стандартными хуками стилизации корневого элемента в Ark.
- `data-slot="aspect-ratio-root"` - стабильный хук стилизации корневого элемента moduix.
- Задавайте ширину, максимальную ширину и стили раскладки на самом корневом элементе. Если при определённой ширине экрана
  нужно другое соотношение сторон, переопределите `aspect-ratio` в своём CSS.
- Прямой медиаконтент использует `border-box`. Изображения и видео сохраняют своё значение `object-fit`, поэтому вы сами
  выбираете между обрезкой и вписыванием содержимого целиком.
- `overflow: hidden` задан намеренно. Если декоративный элемент должен выходить за пределы контейнера, поместите его во
  внешнюю обёртку, а не убирайте обрезку корневого элемента.
