## Справочник API

В Ark UI нет отдельного примитива `aspect-ratio`. В moduix этот компонент построен на официальной
[фабрике Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[работе с ref](https://ark-ui.com/docs/guides/ref).

## Базовый пример

Используйте `AspectRatio` как корневой элемент адаптивного контейнера. По умолчанию он занимает всю доступную
ширину родительского контейнера. Если размер нужно ограничить или изменить, задайте корневому элементу `width`
или `max-width`, а в `ratio` передайте конечное положительное число.

Прямые дочерние элементы `img`, `video`, `iframe`, `canvas` и `svg` автоматически заполняют контейнер. Для остальных
элементов размер не задаётся автоматически, поэтому добавьте необходимые стили. Для изображений и видео используйте
`object-fit`, чтобы выбрать между обрезкой содержимого и его вписыванием в контейнер.


| Часть                              | Назначение                                      |
| ---------------------------------- | ----------------------------------------------- |
| `AspectRatio` / `AspectRatio.Root` | Адаптивный контейнер, который обрезает содержимое. |

## Композиция

### Рекомендуемая композиция

В большинстве случаев используйте `AspectRatio` для контейнеров с медиаконтентом. Задавайте ширину, радиус
скругления и стили раскладки на корневом элементе. `AspectRatio.Root` предоставляет тот же корневой элемент
через пространство имён, чтобы API оставался единообразным с остальными компонентами библиотеки. Корневой
элемент также принимает стандартные свойства `div`, поддерживаемые фабрикой Ark.

- `ratio` обязателен и должен быть конечным положительным числом. Недопустимое значение вызывает `RangeError`.
- `asChild` использует композицию фабрики Ark и требует ровно одного элемента React.
- Прямые дочерние элементы `img`, `video`, `iframe`, `canvas` и `svg` автоматически заполняют контейнер. Задайте
  `object-fit` для изображений и видео, чтобы выбрать между обрезкой и вписыванием содержимого целиком.
- Остальные дочерние элементы не получают размер автоматически. Задайте им необходимые стили.
- `className` применяет стили и задаёт размеры корневого элемента.
- `--moduix-aspect-ratio-radius` управляет радиусом скругления контейнера по умолчанию.

### Когда нужна внешняя обёртка

Используйте внешнюю обёртку, если тени, кольцо фокуса или декоративные элементы должны выходить за пределы
обрезаемой области. Само обрезание оставьте на корневом элементе. Чтобы менять соотношение сторон при разных
ширинах экрана, переопределите `aspect-ratio` в своём CSS.

### Свойства по умолчанию

| Параметр                       | По умолчанию              | Значения / примечания                           |
| ------------------------------ | ------------------------- | ----------------------------------------------- |
| `ratio`                        | -                         | Обязательное конечное положительное число       |
| `className`                    | `undefined`               | Стилизует корневой элемент и задаёт его размеры |
| `style`                        | `undefined`               | Может напрямую переопределить `aspect-ratio`    |
| `asChild`                      | `undefined`               | Композиция через фабрику Ark                    |
| Стандартные свойства `div`     | -                         | Передаются отрисованному корневому элементу    |
| `--moduix-aspect-ratio-radius` | `var(--moduix-radius-md)` | Значение длины CSS или токен                    |

### Особенности поведения

- Корневой элемент получает атрибуты `data-scope="aspect-ratio"`, `data-part="root"` и
  `data-slot="aspect-ratio-root"`.
- Корневой элемент блочный и использует `box-sizing: border-box`. Это сохраняется и при использовании `asChild`,
  когда меняется HTML-элемент.
- Переданный `ref` указывает на отрисованный корневой элемент, а при использовании `asChild` указывает на единственный
  дочерний элемент.
- `position: relative` задан намеренно. Он позволяет использовать дочерние элементы с абсолютным позиционированием,
  которые заполняют контейнер, например `Image` из Next.js с `fill`.
- Прямые дочерние `iframe` заполняют контейнер без стандартной рамки браузера.
- Ранее компонент поддерживал строковые пресеты (`square`, `video`, `portrait`, `photo`), но после миграции на Ark
  они были удалены. Используйте числовые значения: `1`, `16 / 9`, `9 / 16` и `4 / 3`.

### Доступность

`AspectRatio` отвечает только за раскладку. Компонент не добавляет роль, не управляет состоянием и не меняет
поведение дочерних элементов с точки зрения доступности. Если содержимому нужен семантический элемент, например
`figure`, используйте `asChild`. Для информативных изображений указывайте содержательный `alt`, а для встроенного
содержимого, например `iframe`, задавайте `title`.

### Атрибуты для стилизации

- `data-scope="aspect-ratio"` и `data-part="root"` служат селекторами для стилизации, согласованными с Ark, на корневом элементе.
- `data-slot="aspect-ratio-root"` - стабильный селектор moduix для корневого элемента.
- Задавайте ширину, максимальную ширину и стили раскладки на корневом элементе. Если при определённой ширине экрана
  нужно другое соотношение сторон, переопределите `aspect-ratio` в своём CSS.
- Прямой медиаконтент использует `box-sizing: border-box`. Изображения и видео сохраняют своё значение `object-fit`,
  поэтому вы сами выбираете между обрезкой и вписыванием содержимого целиком.
- `overflow: hidden` задан намеренно. Если декоративный элемент должен выходить за пределы контейнера, поместите его
  во внешнюю обёртку, а не убирайте обрезку корневого элемента.
