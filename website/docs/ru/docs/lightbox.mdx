## Справочник API

<PrimitiveReference href="https://ark-ui.com/docs/components/dialog" />

В Ark UI нет отдельного примитива `lightbox`. В moduix этот компонент построен поверх `Dialog` из
Ark UI. Он следует рекомендациям Ark по [композиции](https://ark-ui.com/docs/guides/composition),
[стилизации](https://ark-ui.com/docs/guides/styling) и работе с
[ref](https://ark-ui.com/docs/guides/ref), а `Dialog` определяет всё поведение компонента.

## Выбор подходящего компонента

Используйте `Lightbox`, если оверлей в основном нужен для просмотра изображений или другого медиаконтента.

- Выбирайте **`Lightbox`** для увеличенного просмотра изображений, галерей товаров и модальных окон для просмотра медиа.
- Выбирайте **`Dialog`** для обычного интерфейса приложения, например форм, действий или смешанного содержимого.
- Поместите **`Carousel` внутрь `Lightbox.Gallery`**, если для просмотра нужны слайды и стрелки навигации.

## Анатомия

```text
Lightbox / Lightbox.Root
├─ Lightbox.Trigger
├─ Lightbox.Bind
└─ Поддерево оверлея (автоматически рендерится в портале)
   ├─ Lightbox.Backdrop
   └─ Lightbox.Positioner
      ├─ Lightbox.CloseTrigger или Lightbox.CloseIcon
      └─ Lightbox.Content
         ├─ Lightbox.Header (необязательно)
         │  ├─ Lightbox.Title
         │  └─ Lightbox.Description
         ├─ Lightbox.Body
         │  └─ Lightbox.Image
         └─ Lightbox.Footer (необязательно)

Lightbox.RootProvider
└─ то же дерево частей, связанное с useLightbox()
```

| Часть | Назначение |
| ---------------------------- | ------------------------------------------------------------------------------------ |
| `Lightbox` / `Lightbox.Root` | Корневой элемент Dialog из Ark UI. Он управляет открытием, жизненным циклом фокуса, закрытием и доступностью. |
| `Lightbox.RootProvider` | Провайдер состояния, созданного с помощью `useLightbox()`. |
| `Lightbox.Trigger` | Триггер Ark. С `asChild` можно передать собственную семантическую кнопку или ссылку. |
| `Lightbox.Backdrop` | Модальная подложка с атрибутом Ark `data-state` и переменными слоёв. |
| `Lightbox.Positioner` | Фиксированный контейнер оверлея, выровненный по центру. |
| `Lightbox.Content` | Узел, в котором находится содержимое диалога Ark. |
| `Lightbox.Title` | Необязательный доступный заголовок. |
| `Lightbox.Description` | Необязательное доступное описание. |
| `Lightbox.CloseTrigger` | Низкоуровневый триггер закрытия Ark. |
| `Lightbox.CloseIcon` | Упрощённый вариант, который объединяет `CloseButton.Root` и триггер закрытия Ark. |
| `Lightbox.Header` / `Body` | Необязательные компоненты для размещения текста и медиа внутри содержимого. |
| `Lightbox.Footer` | Необязательный компонент для действий или статуса под медиа. |
| `Lightbox.Image` | Стилизованный нативный элемент изображения, передающий ref элемента `HTMLImageElement`. |
| `Lightbox.Gallery` | Контейнер для компоновки и стилизации `Carousel`. |
| `Lightbox.Bind` | Компонент без собственного DOM, связывающий внешнюю разметку изображения с корнем. |

## Композиция

Корневой компонент по умолчанию рендерит `Backdrop` и `Positioner` через портал. Задайте
`portalled={false}`, чтобы отрисовать их в обычном потоке, или передайте `portalRef`, чтобы выбрать
свой контейнер. Структурные части остаются явными, и их можно стилизовать отдельно.

### Рекомендуемая композиция

Не скрывайте структуру оверлея. `Lightbox.Content` является фактической частью содержимого Ark.
Он не создаёт автоматически подложку, позиционер, изображение, галерею или кнопку закрытия.

Используйте `Lightbox.Image` для одного изображения. Компонент рендерит нативный `<img>`, принимает
обычные свойства изображения и передаёт ref элемента `HTMLImageElement`. `Lightbox.Header`, `Body`
и `Footer` являются необязательными компонентами, которые визуально разделяют текст, медиа и действия.

Оберните `Carousel` в `Lightbox.Gallery`, если у вас есть готовая коллекция изображений. Этот
контейнер задаёт область просмотра lightbox, выравнивание стрелок, размер медиа и расположение
индикаторов, а `Carousel` по-прежнему управляет всеми слайдами.

Разместите `Lightbox.CloseIcon` рядом с `Lightbox.Content` внутри `Lightbox.Positioner`, если кнопку
нужно закрепить в углу области просмотра. Внутри `Lightbox.Content` она наследует трансформации
содержимого во время анимации появления и исчезновения.

### Когда нужна собственная композиция

Выводите пользовательское содержимое прямо внутри `Lightbox.Content`, если это не отдельное изображение и не
галерея `Carousel`. Используйте `Lightbox.Bind` для внешней разметки, в которую нельзя добавить
`Lightbox.Trigger`. Если изображения уже представлены структурированным массивом, используйте явные
триггеры и `Lightbox.Gallery`.

### Свойства по умолчанию

Содержимое оверлея в портале по умолчанию монтируется лениво и удаляется после анимации закрытия.
Установите `unmountOnExit={false}`, чтобы не удалять его после первого открытия. Отключайте оба свойства
жизненного цикла только тогда, когда содержимое нужно отрендерить сразу при загрузке страницы.

| Свойство | По умолчанию | Примечания |
| ------------------------ | ------------ | ------------------------------------------------------------------------ |
| `closeOnEscape` | `true` | Наследуется от Dialog из Ark UI. |
| `closeOnInteractOutside` | `true` | Наследуется от Dialog из Ark UI. |
| `defaultOpen` | `false` | Начальное состояние в неуправляемом режиме. |
| `modal` | `true` | Блокирует взаимодействие с фоном и скрывает расположенное под lightbox содержимое. |
| `preventScroll` | `true` | Блокирует прокрутку страницы, пока lightbox открыт. |
| `role` | `"dialog"` | Для доступного имени задайте `aria-label` или используйте `Lightbox.Title`. Свойство `ids` только делает связи между элементами стабильными. |
| `trapFocus` | `true` | Удерживает клавиатурный фокус внутри lightbox, пока он открыт. |
| `lazyMount` | `true` | Откладывает монтирование тяжёлого медиаконтента до первого открытия. |
| `unmountOnExit` | `true` | Удаляет узлы оверлея после анимации закрытия. |

### Особенности поведения

`onOpenChange` и `onTriggerValueChange` получают объект `details` в формате Ark. Для управляемого
состояния открытия читайте `details.open`, а для галерей с несколькими триггерами
`details.value`.

Используйте `useLightbox()` с `Lightbox.RootProvider`, когда элементы управления находятся за пределами
корневого компонента. В дочерних компонентах состояние диалога доступно через
`useLightboxContext()`. Оба API экспортируются из `@moduix/react` и доступны в пространстве имён
`Lightbox`.

`Lightbox.Image closeOnClick` закрывает оверлей по клику на изображение. `Lightbox.Bind` связывает
разметку из CMS или стороннего сервиса с lightbox, когда её нельзя обернуть в `Lightbox.Trigger`.
Компонент нужно отрендерить внутри `Lightbox`; выбранное изображение он передаёт через
`onImageSelect(details)`. В объекте `details` есть `src`, необязательный `alt` и исходный
`HTMLImageElement` в свойстве `element`. Свойство `selector` обязательно и должно указывать на
семантическую кнопку или ссылку, чтобы каждый предпросмотр был доступен с клавиатуры.

Остальные свойства `Dialog` передаются без изменений. В их числе `id`, `ids`, `initialFocusEl`,
`finalFocusEl`, `persistentElements`, `restoreFocus`, `present`, `immediate`,
`skipAnimationOnMount` и колбэки внешнего взаимодействия.

## Примеры

### Привязка содержимого CMS

Используйте `Lightbox.Bind`, если изображения для предпросмотра приходят из CMS или сторонней разметки,
которую вы не выводите напрямую через `Lightbox.Trigger`. Укажите контейнер с помощью `rootRef` или
`rootSelector`, задайте `selector` и обработайте объект `{ src, alt, element }` в `onImageSelect`.
`Bind` открывает родительский Lightbox, но не рендерит элементы оверлея. Поэтому подложка, содержимое,
элементы закрытия и раскладка изображения остаются под вашим контролем. Компонент ищет источник
сначала в `data-lightbox-src`, затем в `currentSrc` и после этого в `src`. Источник предзагружается
при наведении указателя или фокусе с клавиатуры. В `selector` указывайте семантическую кнопку или
ссылку, чтобы её активация с клавиатуры вызывала клик, открывающий Lightbox. Если сервер уже возвращает
структурированный массив изображений, используйте описанную выше композицию

### Точки для стилизации

- Слоты moduix: `lightbox-trigger`, `lightbox-backdrop`, `lightbox-positioner`, `lightbox-content`,
  `lightbox-title`, `lightbox-description`, `lightbox-close-trigger`, `lightbox-close-icon`,
  `lightbox-header`, `lightbox-body`, `lightbox-footer`, `lightbox-image` и `lightbox-gallery`.
- Атрибуты состояния и анатомии Ark: `data-scope="dialog"`, `data-part`,
  `data-state="open|closed"`, `data-nested`, `data-has-nested`, `--layer-index` и
  `--nested-layer-count`.
- Локальные точки настройки: `Lightbox.Image` добавляет `data-slot="lightbox-image"` и, если
  включено закрытие по клику, `data-close-on-click`. `Lightbox.Gallery` добавляет
  `data-slot="lightbox-gallery"` и стилизует вложенные слоты Carousel.
- Анимация зависит от атрибута Ark `data-state`. Используйте `present`, только если управление
  анимацией в JavaScript должно сохранять содержимое смонтированным.
- При `prefers-reduced-motion: reduce` подложка и содержимое используют анимацию длительностью 1 мс.
  Это сохраняет очистку после закрытия, но убирает видимое движение.
