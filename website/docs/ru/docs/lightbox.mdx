## Справочник API

<PrimitiveReference href="https://ark-ui.com/docs/components/dialog" />

В Ark UI нет отдельного примитива `lightbox`. В moduix этот компонент построен на основе `Dialog`
из Ark UI. Он следует рекомендациям Ark по [композиции](https://ark-ui.com/docs/guides/composition),
[стилизации](https://ark-ui.com/docs/guides/styling) и работе с
[ref](https://ark-ui.com/docs/guides/ref), поэтому `Dialog` определяет его поведение.

## Выбор подходящего компонента

Используйте `Lightbox`, если в модальном окне нужно в основном просматривать изображения или другой медиаконтент.

- Выбирайте **`Lightbox`** для увеличенного просмотра изображений, галерей товаров и другого медиаконтента.
- Выбирайте **`Dialog`** для обычного интерфейса приложения, например форм, действий или смешанного содержимого.
- Поместите **`Carousel` внутрь `Lightbox.Gallery`**, если для просмотра нужны слайды и стрелки навигации.

## Анатомия

```text
Lightbox / Lightbox.Root
├─ Lightbox.Trigger
├─ Lightbox.Bind
└─ Поддерево модального окна (автоматически выводится через портал)
   ├─ Lightbox.Backdrop
   └─ Lightbox.Positioner
      ├─ Lightbox.CloseTrigger или Lightbox.CloseIcon
      └─ Lightbox.Content
         ├─ Lightbox.Header (необязательно)
         │  ├─ Lightbox.Title
         │  └─ Lightbox.Description
         ├─ Lightbox.Body
         │  └─ Lightbox.Image
         └─ Lightbox.Footer (необязательно)

Lightbox.RootProvider
└─ то же дерево частей, связанное с useLightbox()
```

| Часть | Назначение |
| ---------------------------- | ------------------------------------------------------------------------------------ |
| `Lightbox` / `Lightbox.Root` | Корневой компонент Dialog из Ark UI. Он управляет состоянием открытия, фокусом, закрытием и доступностью. |
| `Lightbox.RootProvider` | Провайдер состояния, созданного с помощью `useLightbox()`. |
| `Lightbox.Trigger` | Триггер Ark. С `asChild` можно передать семантическую кнопку или ссылку. |
| `Lightbox.Backdrop` | Модальная подложка с атрибутом Ark `data-state` и переменными слоя. |
| `Lightbox.Positioner` | Фиксированный контейнер, центрирующий содержимое модального окна. |
| `Lightbox.Content` | Узел с содержимым диалога Ark UI. |
| `Lightbox.Title` | Необязательный доступный заголовок. |
| `Lightbox.Description` | Необязательное доступное описание. |
| `Lightbox.CloseTrigger` | Низкоуровневый триггер закрытия Ark UI. |
| `Lightbox.CloseIcon` | Упрощённый вариант, объединяющий `CloseButton.Root` с триггером закрытия Ark UI. |
| `Lightbox.Header` / `Body` | Необязательные компоненты для размещения текста и медиа. |
| `Lightbox.Footer` | Необязательный компонент для действий или статуса под медиа. |
| `Lightbox.Image` | Стилизованный `<img>`, передающий ref нативного элемента `HTMLImageElement`. |
| `Lightbox.Gallery` | Контейнер для компоновки и стилизации `Carousel`. |
| `Lightbox.Bind` | Компонент без собственного DOM, связывающий внешнюю разметку с корнем. |

## Композиция

По умолчанию корневой компонент выводит `Backdrop` и `Positioner` через портал. Задайте
`portalled={false}`, чтобы вывести их в текущем дереве, или передайте `portalRef`, чтобы выбрать
свой контейнер. Структурные части остаются явными, и их можно стилизовать отдельно.

### Рекомендуемая композиция

Явно описывайте структуру модального окна. `Lightbox.Content` является частью содержимого Ark UI.
Он не создаёт автоматически подложку, контейнер позиционирования, изображение, галерею или кнопку закрытия.

Используйте `Lightbox.Image` для одного изображения. Компонент выводит нативный `<img>`, принимает
его обычные свойства и передаёт ref элемента `HTMLImageElement`. `Lightbox.Header`, `Body` и
`Footer` помогают визуально разделить текст, медиа и действия.

Оберните `Carousel` в `Lightbox.Gallery`, если у вас есть готовая коллекция изображений. `Gallery`
задаёт область просмотра, выравнивание стрелок, размеры медиа и расположение индикаторов, а
`Carousel` по-прежнему управляет слайдами.

Разместите `Lightbox.CloseIcon` рядом с `Lightbox.Content` внутри `Lightbox.Positioner`, если кнопку
нужно закрепить в углу окна просмотра. Внутри `Lightbox.Content` она следует за трансформациями
содержимого во время анимации появления и исчезновения.

### Когда нужна собственная композиция

Выводите пользовательское содержимое прямо внутри `Lightbox.Content`, если это не отдельное изображение
и не галерея `Carousel`. Используйте `Lightbox.Bind` для внешней разметки, в которую нельзя добавить
`Lightbox.Trigger`. Если изображения уже представлены структурированным массивом, используйте явные
триггеры и поместите `Carousel` внутрь `Lightbox.Gallery`.

### Свойства по умолчанию

Содержимое в портале по умолчанию создаётся только при первом открытии и удаляется после анимации
закрытия. Установите `unmountOnExit={false}`, чтобы оставить его в DOM после первого открытия.
Отключайте `lazyMount` и `unmountOnExit` только тогда, когда содержимое нужно создать сразу при загрузке страницы.

| Свойство | По умолчанию | Примечания |
| ------------------------ | ------------ | ------------------------------------------------------------------------ |
| `closeOnEscape` | `true` | Наследуется от Dialog из Ark UI. |
| `closeOnInteractOutside` | `true` | Наследуется от Dialog из Ark UI. |
| `defaultOpen` | `false` | Начальное состояние в неуправляемом режиме. |
| `modal` | `true` | Блокирует взаимодействие с фоном и скрывает содержимое под модальным окном. |
| `preventScroll` | `true` | Блокирует прокрутку страницы, пока окно просмотра открыто. |
| `role` | `"dialog"` | Для доступного имени задайте `aria-label` или используйте `Lightbox.Title`. Свойство `ids` только делает связи между элементами стабильными. |
| `trapFocus` | `true` | Удерживает клавиатурный фокус внутри модального окна, пока оно открыто. |
| `lazyMount` | `true` | Откладывает создание тяжёлого медиаконтента до первого открытия. |
| `unmountOnExit` | `true` | Удаляет узлы модального окна после анимации закрытия. |

### Особенности поведения

`onOpenChange` и `onTriggerValueChange` получают объект `details` в формате Ark UI. Для управления
открытием читайте `details.open`, а для галереи с несколькими триггерами `details.value`.

Используйте `useLightbox()` с `Lightbox.RootProvider`, когда элементы управления находятся за пределами
корневого компонента. В дочерних компонентах читайте состояние диалога через `useLightboxContext()`.
Оба API экспортируются из `@moduix/react` и доступны в пространстве имён `Lightbox`.

`Lightbox.Image closeOnClick` закрывает окно просмотра по клику на изображение. `Lightbox.Bind`
связывает разметку из CMS или стороннего сервиса с Lightbox, когда её нельзя обернуть в
`Lightbox.Trigger`. Компонент нужно разместить внутри `Lightbox`; выбранное изображение он передаёт
через `onImageSelect(details)`. В объекте `details` есть `src`, необязательный `alt` и исходный
`HTMLImageElement` в свойстве `element`. Свойство `selector` обязательно и должно указывать на
семантическую кнопку или ссылку, чтобы окно просмотра можно было открыть с клавиатуры.

Остальные свойства `Dialog` передаются без изменений. В их числе `id`, `ids`, `initialFocusEl`,
`finalFocusEl`, `persistentElements`, `restoreFocus`, `present`, `immediate`,
`skipAnimationOnMount` и колбэки внешнего взаимодействия.

## Примеры

### Привязка содержимого из CMS

Используйте `Lightbox.Bind`, если изображения для просмотра приходят из CMS или сторонней разметки,
которую вы не выводите напрямую через `Lightbox.Trigger`. Укажите контейнер с помощью `rootRef` или
`rootSelector`, задайте `selector` и обработайте объект `{ src, alt, element }` в `onImageSelect`.
`Bind` открывает родительский Lightbox, но не создаёт элементы модального окна. Поэтому подложка,
содержимое, элементы закрытия и раскладка изображения остаются под вашим контролем. Компонент ищет
источник сначала в `data-lightbox-src`, затем в `currentSrc` и после этого в `src`, а при наведении
указателя или фокусе с клавиатуры заранее загружает найденное изображение. В `selector` указывайте
семантическую кнопку или ссылку, чтобы её можно было активировать с клавиатуры и открыть Lightbox.
Если сервер уже возвращает структурированный массив изображений, используйте описанную выше
композицию `Lightbox.Gallery + Carousel`.

### Хуки стилизации

- Слоты moduix: `lightbox-trigger`, `lightbox-backdrop`, `lightbox-positioner`, `lightbox-content`,
  `lightbox-title`, `lightbox-description`, `lightbox-close-trigger`, `lightbox-close-icon`,
  `lightbox-header`, `lightbox-body`, `lightbox-footer`, `lightbox-image` и `lightbox-gallery`.
- Атрибуты состояния и анатомии Ark: `data-scope="dialog"`, `data-part`,
  `data-state="open|closed"`, `data-nested`, `data-has-nested`, `--layer-index` и
  `--nested-layer-count`.
- Локальные точки настройки: `Lightbox.Image` добавляет `data-slot="lightbox-image"` и, если
  включено закрытие по клику, `data-close-on-click`. `Lightbox.Gallery` добавляет
  `data-slot="lightbox-gallery"` и стилизует вложенные слоты Carousel.
- Анимация зависит от атрибута Ark `data-state`. Используйте `present`, только если управление
  анимацией в JavaScript должно оставлять содержимое в DOM.
- При `prefers-reduced-motion: reduce` подложка и содержимое используют анимацию длительностью 1 мс.
  Так сохраняется корректное удаление узлов после закрытия, но видимого движения нет.
