## Справочник API

<PrimitiveReference href="https://ark-ui.com/docs/components/dialog" />

В Ark UI нет отдельного примитива `lightbox`. moduix строит этот компонент на основе `Dialog` из Ark UI,
следует рекомендациям Ark по [композиции](https://ark-ui.com/docs/guides/composition),
[стилизации](https://ark-ui.com/docs/guides/styling) и
[ref](https://ark-ui.com/docs/guides/ref), а `Dialog` остаётся источником истины для поведения.

## Выбор подходящего компонента

Используйте `Lightbox`, когда оверлей нужен главным образом для просмотра изображения или медиаконтента.

- Выбирайте **`Lightbox`** для увеличенного просмотра изображений, галерей товаров и модальных поверхностей, где медиа играет главную роль.
- Выбирайте **`Dialog`**, если поверхность содержит обычный интерфейс приложения: формы, действия или смешанное содержимое.
- Компонуйте **`Carousel` внутри `Lightbox.Gallery`**, если для просмотра нужны слайды или стрелки.

## Анатомия

```text
Lightbox / Lightbox.Root
├─ Lightbox.Trigger
├─ Lightbox.Bind
└─ Поддерево оверлея (автоматически портируется)
   ├─ Lightbox.Backdrop
   └─ Lightbox.Positioner
      ├─ Lightbox.CloseTrigger или Lightbox.CloseIcon
      └─ Lightbox.Content
         ├─ Lightbox.Header (необязательно)
         │  ├─ Lightbox.Title
         │  └─ Lightbox.Description
         ├─ Lightbox.Body
         │  └─ Lightbox.Image
         └─ Lightbox.Footer (необязательно)

Lightbox.RootProvider
└─ то же дерево частей, подключённое к useLightbox()
```

| Часть                         | Назначение                                                                           |
| ---------------------------- | ------------------------------------------------------------------------------------ |
| `Lightbox` / `Lightbox.Root` | Корневой элемент Ark Dialog: хранит состояние открытия, жизненный цикл фокуса, закрытие и доступность. |
| `Lightbox.RootProvider`      | Провайдер для состояния, созданного с `useLightbox()`.                               |
| `Lightbox.Trigger`           | Триггер Ark. Используйте `asChild` для пользовательских семантических кнопок или ссылок. |
| `Lightbox.Backdrop`          | Модальная подложка с `data-state` Ark и переменными слоёв.                           |
| `Lightbox.Positioner`        | Фиксированный контейнер оверлея по центру.                                           |
| `Lightbox.Content`           | Фактический узел содержимого диалога Ark.                                            |
| `Lightbox.Title`             | Необязательный доступный заголовок.                                                  |
| `Lightbox.Description`       | Необязательное доступное описание.                                                   |
| `Lightbox.CloseTrigger`      | Низкоуровневый триггер закрытия Ark.                                                 |
| `Lightbox.CloseIcon`         | Сокращение moduix: `CloseButton.Root` поверх триггера закрытия Ark.                  |
| `Lightbox.Header` / `Body`   | Необязательные помощники компоновки для текстовой и медиазоны в содержимом.          |
| `Lightbox.Footer`            | Необязательный помощник компоновки для действий или статуса под медиа.                |
| `Lightbox.Image`             | Стилизованное нативное изображение с ref типа `HTMLImageElement`.                    |
| `Lightbox.Gallery`           | Граница компоновки и стилизации для составленного `Carousel`.                        |
| `Lightbox.Bind`              | Невидимая часть поведения, привязывающая внешнюю разметку изображения к корню.        |

## Композиция

Корневой элемент автоматически портирует `Backdrop` и `Positioner`. Используйте `portalled={false}` для встроенного рендеринга и `portalRef` для пользовательского контейнера; структурные части остаются явными и доступными для стилизации.

### Рекомендуемая композиция

Сохраняйте структуру оверлея явной. `Lightbox.Content` - настоящая часть содержимого Ark; он не
отрисовывает за вас подложку, позиционер, изображение, галерею или кнопку закрытия.

Используйте `Lightbox.Image` для одного изображения. Он отрисовывает нативный `<img>`, принимает
нативные пропы изображения и передаёт ref элементу `HTMLImageElement`. `Lightbox.Header`, `Body` и
`Footer` - необязательные помощники компоновки, когда текст, медиа и действия должны быть визуально разделены.

Используйте `Lightbox.Gallery` вокруг `Carousel` для известной коллекции изображений. Он задаёт
характерные для lightbox область просмотра, выравнивание стрелок, размер медиа и раскладку индикаторов,
а `Carousel` продолжает отвечать за поведение всех слайдов.

Отрисовывайте `Lightbox.CloseIcon` рядом с `Lightbox.Content` внутри `Lightbox.Positioner`, если он
должен быть закреплён в углу области просмотра. Внутри `Lightbox.Content` он наследует трансформации
содержимого во время анимации появления и исчезновения.

### Когда нужна собственная композиция

Отрисовывайте пользовательское содержимое прямо внутри `Lightbox.Content`, если это не одиночный
медиакадр и не галерея `Carousel`. Используйте `Lightbox.Bind` только когда исходная разметка не
может отрисовать `Lightbox.Trigger`; для структурированных массивов используйте явные триггеры и `Lightbox.Gallery`.

### Свойства по умолчанию

Содержимое портированного оверлея по умолчанию лениво монтируется и размонтируется после анимации
закрытия. Установите `unmountOnExit={false}`, чтобы сохранить его после первого открытия; устанавливайте
оба пропа жизненного цикла в `false`, только когда нужен начальный рендеринг без задержки.

| Проп                     | По умолчанию | Примечания                                                               |
| ------------------------ | ------------ | ------------------------------------------------------------------------ |
| `closeOnEscape`          | `true`       | Наследуется от Ark Dialog.                                               |
| `closeOnInteractOutside` | `true`       | Наследуется от Ark Dialog.                                               |
| `defaultOpen`            | `false`      | Начальное состояние в неуправляемом режиме.                              |
| `modal`                  | `true`       | Блокирует внешнее взаимодействие и скрывает содержимое под lightbox.     |
| `preventScroll`          | `true`       | Блокирует прокрутку страницы, пока lightbox открыт.                      |
| `role`                   | `"dialog"`   | Для доступного имени используйте `aria-label` или `Lightbox.Title`; `ids` лишь делает связи стабильными. |
| `trapFocus`              | `true`       | Удерживает клавиатурный фокус внутри lightbox, пока он открыт.           |
| `lazyMount`              | `true`       | Откладывает тяжёлый медиаверлей до первого открытия.                     |
| `unmountOnExit`          | `true`       | Удаляет узлы оверлея после анимации закрытия.                            |

### Особенности поведения

`onOpenChange` и `onTriggerValueChange` сохраняют формы колбэков Ark с объектом `details`.
Для управляемого состояния открытия читайте `details.open`, а для галерей с несколькими триггерами - `details.value`.

Используйте `useLightbox()` с `Lightbox.RootProvider`, когда элементы управления находятся вне
отрисованного корня. Состояние диалога в дочерних компонентах доступно через `useLightboxContext()`.
Оба API экспортируются из `@moduix/react` и пространства имён `Lightbox`.

`Lightbox.Image closeOnClick` - поддерживаемое сокращение для предпросмотра, когда само изображение
должно закрывать оверлей. `Lightbox.Bind` - невидимый помощник привязки для разметки CMS или сторонних
систем, которую нельзя обернуть в `Lightbox.Trigger`. Его необходимо отрисовывать внутри `Lightbox`;
выбранное изображение передаётся через `onImageSelect(details)`. Details содержит `src`, необязательный
`alt` и исходный `HTMLImageElement` в `element`. `selector` обязателен и должен соответствовать
семантической кнопке или ссылке, чтобы каждый предпросмотр был доступен с клавиатуры.

Другие унаследованные пропы `Dialog` передаются без изменений, включая `id`, `ids`, `initialFocusEl`,
`finalFocusEl`, `persistentElements`, `restoreFocus`, `present`, `immediate`,
`skipAnimationOnMount` и колбэки внешнего взаимодействия.

## Примеры

### Привязка содержимого CMS

Используйте `Lightbox.Bind`, если просматриваемые изображения поступают из CMS или сторонней разметки,
которую вы не отрисовываете напрямую через `Lightbox.Trigger`. Укажите контейнер с `rootRef` или
`rootSelector`, выберите `selector` и обработайте определённый `{ src, alt, element }` через
`onImageSelect`. `Bind` открывает родительский Lightbox, но не отрисовывает структуру оверлея, поэтому
подложка, содержимое, элементы закрытия и раскладка изображения остаются полностью компонуемыми. Он читает
`data-lightbox-src`, затем `currentSrc`, затем `src` и предзагружает этот источник при наведении указателя
или фокусе с клавиатуры. Используйте семантическую кнопку или ссылку в качестве совпадающего `selector`,
чтобы нативная активация с клавиатуры вызывала клик, открывающий Lightbox. Если сервер уже возвращает
настоящий массив изображений, предпочитайте описанную выше композицию `Lightbox.Gallery + Carousel`.

### Хуки стилизации

- Слоты moduix: `lightbox-trigger`, `lightbox-backdrop`, `lightbox-positioner`,
  `lightbox-content`, `lightbox-title`, `lightbox-description`, `lightbox-close-trigger`,
  `lightbox-close-icon`, `lightbox-header`, `lightbox-body`, `lightbox-footer`, `lightbox-image`
  и `lightbox-gallery`.
- Хуки состояния и анатомии Ark: `data-scope="dialog"`, `data-part`, `data-state="open|closed"`,
  `data-nested`, `data-has-nested`, `--layer-index` и `--nested-layer-count`.
- Локальные хуки: `Lightbox.Image` предоставляет `data-slot="lightbox-image"` и необязательный
  `data-close-on-click`; `Lightbox.Gallery` предоставляет `data-slot="lightbox-gallery"` и стилизует
  вложенные слоты Carousel.
- Анимация определяется Ark `data-state`; используйте `present`, только когда управление анимацией в JavaScript
  должно сохранять содержимое смонтированным.
- При `prefers-reduced-motion: reduce` подложка и содержимое используют анимацию длительностью 1 мс:
  очистка после закрытия сохраняется, но видимого движения нет.
