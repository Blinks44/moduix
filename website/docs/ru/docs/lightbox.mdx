## Использование

<Usage />

Явно соберите структуру диалога Ark UI из `Lightbox`, `LightboxTrigger`,
`LightboxBackdrop`, `LightboxPositioner` и `LightboxContent`. С помощью `asChild` передайте
один семантический элемент, который открывает окно просмотра.

## Выбор подходящего компонента

Используйте `Lightbox`, если в модальном окне нужно в основном просматривать изображения или другой медиаконтент.

- Выбирайте **`Lightbox`** для увеличенного просмотра изображений, галерей товаров и другого медиаконтента.
- Выбирайте **`Dialog`** для обычного интерфейса приложения, например форм, действий или смешанного содержимого.
- Поместите **`Carousel` внутрь `LightboxGallery`**, если для просмотра нужны слайды и стрелки навигации.

## Примеры

### Галерея

Если CMS или API возвращает структурированный массив изображений, храните выбранное изображение и
текущую страницу `Carousel` в состоянии React, Solid или Vue, а сам `Carousel` поместите внутрь
`LightboxGallery`. Используйте `LightboxTrigger.value`, чтобы выбрать начальный слайд, и
синхронизируйте страницу `Carousel` во время навигации.

<Example name="lightbox/gallery" />

### Несколько триггеров

Используйте `LightboxTrigger.value` и `onTriggerValueChange(details)` для миниатюр галереи.
Компонент не создаёт скрытый реестр изображений.

<Example name="lightbox/multiple-triggers" />

### Закрытие по клику на изображение

Используйте `LightboxImage closeOnClick`, если клик по изображению должен закрывать окно просмотра.
Иконка закрытия остаётся доступной и сохраняет стандартную семантику Ark UI.

<Example name="lightbox/click-to-close-image" />

### Немодальный режим

Задайте `modal={false}`, если страница должна оставаться интерактивной во время просмотра. В этом
режиме Ark отключает удержание фокуса и блокировку прокрутки. Не добавляйте `LightboxBackdrop`, чтобы
действия на фоне оставались доступными, пока изображение открыто.

<Example name="lightbox/non-modal" />

### Привязка содержимого из CMS

Используйте `LightboxBind`, если изображения приходят из CMS или сторонней разметки, которую нельзя
вывести напрямую через `LightboxTrigger`. Укажите контейнер через `rootRef` или `rootSelector`,
задайте `selector` и обработайте `{ src, alt, element }` в `onImageSelect`. `LightboxBind` открывает родительский
Lightbox, но не создаёт его подложку, содержимое и элементы закрытия. Источник читается из
`data-lightbox-src`, затем `currentSrc` и `src`, а найденное изображение заранее загружается при
наведении указателя или фокусе с клавиатуры. В `selector` указывайте семантическую кнопку или ссылку,
чтобы открытие работало с клавиатуры. Для структурированного массива изображений используйте
композицию `LightboxGallery + Carousel`.

<Example name="lightbox/bind-cms-content" />

### Пользовательская стилизация

Передайте классы фону, содержимому и кнопке закрытия и переопределите их токены, если медиаконтенту
нужен собственный вид.

<Example name="lightbox/custom-styling" />

### Управляемое состояние

Используйте callback `onOpenChange(details)` из Ark UI, если состояние Lightbox нужно синхронизировать
с состоянием приложения на React или Solid. Во Vue используйте `v-model:open`. Подробнее в разделе [Управляйте состоянием из приложения](/docs/composition-patterns#controlled-state).

<Example name="lightbox/controlled" />

### Фокус и идентификаторы

Используйте `initialFocusEl`, `finalFocusEl` и `ids`, если нужны явные цели фокуса или стабильные
идентификаторы для внешних связей доступности. После закрытия целевая кнопка подсвечивается, поэтому
возврат фокуса легко заметить.

<Example name="lightbox/focus-and-ids" />

### Root Provider

Создайте состояние через `useLightbox()`, если кнопка открытия находится за пределами корневого
компонента. В дочернем компоненте читайте состояние через `useLightboxContext()`. Внешняя кнопка
остаётся обычным компонентом `Button` из moduix. Подробнее в разделе [Выносите состояние за пределы дерева](/docs/composition-patterns#root-provider).

<Example name="lightbox/root-provider-and-context" />

### Сборка из частей

Тот же Lightbox, что в Basic, но без `LightboxCloseIcon`: `LightboxCloseTrigger` оборачивает
`CloseButton` с явной иконкой и классом, который закрепляет кнопку в углу. `LightboxBody` остаётся,
потому что задаёт анимацию открытия и закрытия изображения.

## Композиция

В Ark UI нет отдельного примитива `lightbox`. В moduix этот компонент построен на основе `Dialog`,
следует рекомендациям Ark по [композиции](https://ark-ui.com/docs/guides/composition),
[стилизации](https://ark-ui.com/docs/guides/styling) и работе с
[ref](https://ark-ui.com/docs/guides/ref), а поведение определяется контрактом `Dialog`.

`Lightbox` управляет состоянием `Dialog`, а `LightboxBackdrop`, `LightboxPositioner` и `LightboxContent` остаются явными.
По умолчанию части окна выводятся через портал. Используйте `portalled={false}`, чтобы оставить их
на месте, или `portalRef`, чтобы выбрать контейнер. Размещайте `LightboxCloseIcon` внутри `LightboxContent`,
но вне `LightboxBody`, чтобы кнопка была доступна скринридерам и входила в область удержания фокуса.
Content плавно появляется и исчезает, а Body меняет масштаб и положение; кнопка остаётся в углу окна.
Без Body содержимое анимируется только изменением прозрачности.
Для `asChild` передавайте один семантический элемент. В Solid это render-функция, получающая его props,
а в Vue передавайте булево свойство `as-child` и элемент в слоте.

В галереях храните выбранное изображение и страницу `Carousel` в состоянии приложения. Передавайте
ключ изображения в `LightboxTrigger value` и обновляйте состояние из `onTriggerValueChange(details)`
или callback страницы `Carousel`. Используйте `LightboxRootProvider` с `useLightbox()`, если состояние или
кнопка открытия находятся за пределами корня, а в дочерних компонентах читайте его через
`useLightboxContext()`. `LightboxBind` не выводит разметку и только выбирает изображение во внешнем DOM, поэтому
остальные части Lightbox нужно собрать явно. `LightboxImage closeOnClick` закрывает окно после клика по изображению.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `LightboxTrigger` | `lightbox-trigger` |
| `LightboxBackdrop` | `lightbox-backdrop` |
| `LightboxPositioner` | `lightbox-positioner` |
| `LightboxContent` | `lightbox-content` |
| `LightboxTitle` | `lightbox-title` |
| `LightboxDescription` | `lightbox-description` |
| `LightboxCloseTrigger` | `lightbox-close-trigger` |
| `LightboxCloseIcon` | `lightbox-close-icon` |
| `LightboxImage` | `lightbox-image` |
| `LightboxGallery` | `lightbox-gallery` |
| `LightboxHeader` | `lightbox-header` |
| `LightboxBody` | `lightbox-body` |
| `LightboxFooter` | `lightbox-footer` |

- Атрибуты состояния и анатомии Ark: `data-scope="dialog"`, `data-part`, `data-state="open|closed"`,
  `data-nested`, `data-has-nested`, `--layer-index` и `--nested-layer-count`.
- Локальные точки настройки: `LightboxImage` добавляет `data-slot="lightbox-image"` и, если
  включено закрытие по клику, `data-close-on-click`. `LightboxGallery` добавляет
  `data-slot="lightbox-gallery"` и стилизует вложенные слоты Carousel.
- Анимация зависит от атрибута Ark `data-state`. Используйте `present`, только если управление
  анимацией в JavaScript должно оставлять содержимое в DOM.
- При `prefers-reduced-motion: reduce` анимации подложки и содержимого отключаются; после закрытия
  узлы по-прежнему корректно удаляются.
- Цвета, отступы и типографика берутся из токенов foundation. Чтобы изменить их для одного
  лайтбокса, добавьте класс на нужную часть. Подложка читает общие `--moduix-backdrop-bg` и
  `--moduix-backdrop-filter`, анимация содержимого — `--moduix-popup-motion-*` на `LightboxContent`,
  а `LightboxCloseIcon` — переменные `--moduix-close-button-*`.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `Enter` / `Space` | Открывает с кнопки в фокусе. |
| `Tab` / `Shift+Tab` | Перемещает фокус между элементами; пока открыто, фокус не выходит наружу. |
| `Esc` | Закрывает и возвращает фокус на кнопку. |

## Справочник API

`Lightbox` принимает те же пропсы, что и `Dialog`. `LightboxImage` добавляет `closeOnClick` (`boolean`, по умолчанию `false`).

| Проп | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `open` | `boolean` | — | Состояние открытия в управляемом режиме. |
| `defaultOpen` | `boolean` | `false` | Начальное состояние открытия, если оно не управляется извне. |
| `onOpenChange` | `(details: OpenChangeDetails) => void` | — | Вызывается при открытии и закрытии. |
| `modal` | `boolean` | `true` | Блокирует взаимодействие снаружи и скрывает остальную страницу от вспомогательных технологий. |
| `role` | `'dialog' \| 'alertdialog'` | `'dialog'` | `dialog` или `alertdialog` для срочных подтверждений. |
| `closeOnEscape` | `boolean` | `true` | Закрывается по Escape. |
| `closeOnInteractOutside` | `boolean` | `true` | Закрывается по клику снаружи. |
| `trapFocus` | `boolean` | `true` | Удерживает фокус внутри, пока открыто. |
| `preventScroll` | `boolean` | `true` | Блокирует прокрутку страницы, пока открыто. |
| `initialFocusEl` | `() => HTMLElement \| null \| false` | — | Возвращает элемент, который получает фокус при открытии. |
| `finalFocusEl` | `() => HTMLElement \| null` | — | Возвращает элемент, который получает фокус при закрытии. |
| `lazyMount` | `boolean` | `true` | Монтирует содержимое при первом открытии. |
| `unmountOnExit` | `boolean` | `true` | Удаляет содержимое после закрытия. |
| `portalled` | `boolean` | `true` | Отрисовывает окно в портале в конце `body`. |
