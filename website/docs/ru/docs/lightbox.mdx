## Справочник API

<PrimitiveReference href="https://ark-ui.com/docs/components/dialog" />

В Ark UI нет отдельного примитива `lightbox`. В moduix этот компонент построен на основе `Dialog`,
следует рекомендациям Ark по [композиции](https://ark-ui.com/docs/guides/composition),
[стилизации](https://ark-ui.com/docs/guides/styling) и работе с
[ref](https://ark-ui.com/docs/guides/ref), а поведение определяется контрактом `Dialog`.

## Выбор подходящего компонента

Используйте `Lightbox`, если в модальном окне нужно в основном просматривать изображения или другой медиаконтент.

- Выбирайте **`Lightbox`** для увеличенного просмотра изображений, галерей товаров и другого медиаконтента.
- Выбирайте **`Dialog`** для обычного интерфейса приложения, например форм, действий или смешанного содержимого.
- Поместите **`Carousel` внутрь `LightboxGallery`**, если для просмотра нужны слайды и стрелки навигации.

## Анатомия

```text
Lightbox
├─ LightboxTrigger
├─ LightboxBind
└─ Поддерево модального окна (автоматически выводится через портал)
   ├─ LightboxBackdrop
   └─ LightboxPositioner
      ├─ LightboxCloseTrigger или LightboxCloseIcon
      └─ LightboxContent
         ├─ LightboxHeader (необязательно)
         │  ├─ LightboxTitle
         │  └─ LightboxDescription
         ├─ LightboxBody
         │  └─ LightboxImage
         └─ LightboxFooter (необязательно)

LightboxRootProvider
└─ то же дерево частей, связанное с useLightbox()
```

| Часть | Назначение |
| ---------------------------- | ------------------------------------------------------------------------------------ |
| `Lightbox` | Корневой компонент Dialog из Ark UI. Он управляет состоянием открытия, фокусом, закрытием и доступностью. |
| `LightboxRootProvider` | Провайдер состояния, созданного с помощью `useLightbox()`. |
| `LightboxTrigger` | Триггер Ark. С `asChild` можно передать семантическую кнопку или ссылку. |
| `LightboxBackdrop` | Модальная подложка с атрибутом Ark `data-state` и переменными слоя. |
| `LightboxPositioner` | Фиксированный контейнер, центрирующий содержимое модального окна. |
| `LightboxContent` | Узел с содержимым диалога Ark UI. |
| `LightboxTitle` | Необязательный доступный заголовок. |
| `LightboxDescription` | Необязательное доступное описание. |
| `LightboxCloseTrigger` | Низкоуровневый триггер закрытия Ark UI. |
| `LightboxCloseIcon` | Упрощённый вариант, объединяющий `CloseButton` с триггером закрытия Ark UI. |
| `LightboxHeader` / `LightboxBody` | Необязательные компоненты для размещения текста и медиа. |
| `LightboxFooter` | Необязательный компонент для действий или статуса под медиа. |
| `LightboxImage` | Стилизованный `<img>`, передающий ref нативного элемента `HTMLImageElement`. |
| `LightboxGallery` | Контейнер для компоновки и стилизации `Carousel`. |
| `LightboxBind` | Компонент без собственного DOM, связывающий внешнюю разметку с корнем. |

## Композиция

`Lightbox` управляет состоянием `Dialog`, а `Backdrop`, `Positioner` и `Content` остаются явными.
По умолчанию части окна выводятся через портал. Используйте `portalled={false}`, чтобы оставить их
на месте, или `portalRef`, чтобы выбрать контейнер. Размещайте `CloseIcon` рядом с `Content` внутри
`Positioner`, если кнопку нужно закрепить относительно окна, а не перемещать вместе с содержимым.
Для `asChild` передавайте один семантический элемент. В Solid это render-функция, получающая его props.

В галереях храните выбранное изображение и страницу `Carousel` в состоянии приложения. Передавайте
ключ изображения в `LightboxTrigger value` и обновляйте состояние из `onTriggerValueChange(details)`
или callback страницы `Carousel`. Используйте `LightboxRootProvider` с `useLightbox()`, если состояние или
кнопка открытия находятся за пределами корня, а в дочерних компонентах читайте его через
`useLightboxContext()`. `Bind` не выводит разметку и только выбирает изображение во внешнем DOM, поэтому
остальные части Lightbox нужно собрать явно. `Image closeOnClick` закрывает окно после клика по изображению.

## Примеры

### Привязка содержимого из CMS

Используйте `LightboxBind`, если изображения приходят из CMS или сторонней разметки, которую нельзя
вывести напрямую через `LightboxTrigger`. Укажите контейнер через `rootRef` или `rootSelector`,
задайте `selector` и обработайте `{ src, alt, element }` в `onImageSelect`. `Bind` открывает родительский
Lightbox, но не создаёт его подложку, содержимое и элементы закрытия. Источник читается из
`data-lightbox-src`, затем `currentSrc` и `src`, а найденное изображение заранее загружается при
наведении указателя или фокусе с клавиатуры. В `selector` указывайте семантическую кнопку или ссылку,
чтобы открытие работало с клавиатуры. Для структурированного массива изображений используйте
композицию `LightboxGallery + Carousel`.

### Хуки стилизации

- Слоты moduix: `lightbox-trigger`, `lightbox-backdrop`, `lightbox-positioner`,
  `lightbox-content`, `lightbox-title`, `lightbox-description`, `lightbox-close-trigger`,
  `lightbox-close-icon`, `lightbox-header`, `lightbox-body`, `lightbox-footer`, `lightbox-image`
  и `lightbox-gallery`.
- Атрибуты состояния и анатомии Ark: `data-scope="dialog"`, `data-part`, `data-state="open|closed"`,
  `data-nested`, `data-has-nested`, `--layer-index` и `--nested-layer-count`.
- Локальные точки настройки: `LightboxImage` добавляет `data-slot="lightbox-image"` и, если
  включено закрытие по клику, `data-close-on-click`. `LightboxGallery` добавляет
  `data-slot="lightbox-gallery"` и стилизует вложенные слоты Carousel.
- Анимация зависит от атрибута Ark `data-state`. Используйте `present`, только если управление
  анимацией в JavaScript должно оставлять содержимое в DOM.
- При `prefers-reduced-motion: reduce` подложка и содержимое используют анимацию длительностью 1 мс.
  Так сохраняется корректное удаление узлов после закрытия, но видимого движения нет.
