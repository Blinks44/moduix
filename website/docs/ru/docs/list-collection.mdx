# List Collection

`ListCollection` - это структура данных, построенная на основе массива элементов. Она не отображает
список и не отвечает за выбор элементов или управление с клавиатуры. Используйте её как источник
данных для `Select`, `Combobox` и `Listbox` или для своей интерфейсной части.

Хотя эта страница находится в документации moduix, `ListCollection` - это утилита Ark UI. Moduix не
реэкспортирует её из `@moduix/react`.

## Справочник API

<PrimitiveReference href="https://ark-ui.com/docs/collections/list-collection" />

Коллекция связывает каждый элемент со значением и текстом для отображения. Она также умеет учитывать
отключённые элементы, объединять элементы в группы, искать по тексту, перемещаться между значениями и
создавать обновлённые коллекции, не изменяя исходную.

Импортируйте вспомогательные функции напрямую из Ark UI:

```tsx
import { createListCollection, useListCollection } from '@ark-ui/react/collection';
```

## Создать коллекцию

Если у элементов есть свойства `label` и `value`, Ark использует их автоматически. Необязательное
свойство `disabled` также учитывается:

```tsx
const fruits = [
  { label: 'Apple', value: 'apple' },
  { label: 'Banana', value: 'banana' },
  { label: 'Blueberry', value: 'blueberry' },
];

const collection = createListCollection({
  items: fruits,
});
```

Передайте коллекцию компоненту на базе Ark UI и отрисуйте элементы из `collection.items`. В
работающем примере ниже показан тот же подход с `Select`.

Храните статическую коллекцию за пределами компонента, если её элементы не меняются. Если данные
приходят через свойства компонента, состояние или запрос, оберните `createListCollection` в
`useMemo`, чтобы новая коллекция создавалась только при изменении элементов. Используйте
`useListCollection`, если фильтрация или изменения должны быть частью состояния React.

## Свои элементы

Если в данных используются другие названия свойств, укажите, как получить из элемента значение,
текст для отображения и признак отключения:

```tsx
type Team = {
  id: number;
  name: string;
  archived: boolean;
};

const customTeams: Team[] = [
  { id: 1, name: 'Platform', archived: false },
  { id: 2, name: 'Legacy', archived: true },
];

const collection = createListCollection<Team>({
  items: customTeams,
  itemToValue: (item) => String(item.id),
  itemToString: (item) => item.name,
  isItemDisabled: (item) => item.archived,
});
```

Значения коллекции - строки. Преобразуйте числовые идентификаторы в строки, когда переносите
данные приложения в коллекцию. По умолчанию `itemToValue`, `itemToString` и `isItemDisabled`
читают свойства `value`, `label` и `disabled`.

| Параметр         | Назначение                                                               |
| ---------------- | ------------------------------------------------------------------------ |
| `items`          | Элементы коллекции. Принимает любой итерируемый объект.                 |
| `itemToValue`    | Возвращает строковое значение, которое используют коллекция и компоненты. |
| `itemToString`   | Возвращает текст для отображения и поиска.                               |
| `isItemDisabled` | Возвращает признак отключённого элемента.                               |
| `groupBy`        | Возвращает ключ группы для каждого элемента.                             |
| `groupSort`      | Сортирует группы функцией сравнения, массивом с заданным порядком или `'asc'` и `'desc'`. |

## Получение данных и поиск

Эти методы помогают получать элементы и преобразовывать объекты элементов в строковые значения и
обратно.

| API                                 | Результат                                                         |
| ----------------------------------- | ----------------------------------------------------------------- |
| `collection.items`                  | Элементы в текущем порядке коллекции.                              |
| `collection.size`                   | Количество элементов.                                             |
| `getValues(items?)`                 | Значения всех элементов или переданных элементов.                 |
| `find(value)` / `findMany(values)`  | Элемент для одного значения или элементы для нескольких значений. |
| `at(index)`                         | Элемент по индексу или `null`.                                    |
| `indexOf(value)`                    | Индекс в коллекции или `-1`, если значение не найдено.             |
| `has(value)` / `hasItem(item)`      | Наличие значения или элемента.                                    |
| `getItemValue(item)`                | Нормализованное строковое значение элемента.                      |
| `stringifyItem(item)`               | Текст для отображения элемента.                                  |
| `stringify(value)`                  | Текст для отображения значения.                                  |
| `stringifyItems(items, separator?)` | Объединённый текст нескольких элементов.                          |
| `stringifyMany(values, separator?)` | Объединённый текст нескольких значений.                            |
| `getItemDisabled(item)`             | Нормализованный признак отключения элемента.                      |
| `group()`                           | Пары `[groupKey, items]` с настроенными параметрами группировки.   |

```tsx
collection.find('product'); // { label: 'Product', value: 'product' }
collection.stringify('product'); // 'Product'
collection.has('unknown'); // false
```

## Перемещение по коллекции

Используйте эти свойства и методы, чтобы переходить между доступными элементами или сортировать
значения в порядке коллекции:

```tsx
collection.firstValue; // 'platform'
collection.lastValue; // 'product' - disabled items are skipped
collection.getNextValue('platform'); // 'product'
collection.getPreviousValue('design'); // 'product'
collection.getValueRange('platform', 'product'); // ['platform', 'product']
collection.sort(['design', 'platform']); // ['platform', 'design']
```

`firstValue`, `lastValue`, `getNextValue`, `getPreviousValue` и `getValueRange` пропускают
отключённые элементы. Методы перехода к следующему и предыдущему элементу принимают необязательные
`step` и флаг `clamp`. Без ограничения переход за край коллекции возвращает `null`.
`getValueRange` возвращает значения в порядке коллекции независимо от того, в каком порядке переданы
границы.

`compareValue(a, b)` сравнивает два значения по порядку коллекции. `isEqual(other)` сравнивает
массивы элементов двух коллекций. Коллекцию можно перебирать через `for...of`. Метод `toString()`
возвращает компактное представление её элементов, а `toJSON()` - её размер, первое и последнее
значения.

Метод `search(query, options)` выполняет поиск по началу текста при наборе с клавиатуры и пропускает
отключённые элементы. Сохраняйте состояние поиска между вызовами:

```tsx
const searchState = { keysSoFar: '', timer: -1 };

const nextValue = collection.search('p', {
  state: searchState,
  currentValue: null,
  timeout: 350,
});
```

В React-компоненте храните `searchState` в `useRef`, чтобы состояние сохранялось между рендерами.

## Неизменяемые обновления

Методы обновления возвращают новую коллекцию и не меняют исходную. Сохраните результат, если хотите
использовать обновлённую коллекцию:

```tsx
const nextCollection = collection
  .append({ label: 'Support', value: 'support' })
  .remove('design')
  .reorder(0, 1);
```

| API                                      | Операция                                          |
| ---------------------------------------- | ------------------------------------------------- |
| `copy(items?)` / `setItems(items)`       | Копирует коллекцию или заменяет все элементы.     |
| `update(value, item)`                    | Заменяет существующий элемент.                   |
| `upsert(value, item, mode?)`             | Обновляет элемент или добавляет его с выбранного края. |
| `insert(index, ...items)`                | Вставляет элементы по индексу.                   |
| `insertBefore(value, ...items)`          | Вставляет элементы перед значением.              |
| `insertAfter(value, ...items)`           | Вставляет элементы после значения.               |
| `prepend(...items)` / `append(...items)` | Добавляет элементы в начало или конец.           |
| `filter(predicate)`                      | Возвращает коллекцию только с подходящими элементами. |
| `remove(...itemsOrValues)`               | Удаляет элементы или значения.                   |
| `move(value, index)`                     | Перемещает значение по индексу.                  |
| `moveBefore(value, ...values)`           | Перемещает переданные значения перед целевым значением. |
| `moveAfter(value, ...values)`            | Перемещает переданные значения после целевого значения. |
| `reorder(from, to)`                      | Перемещает элемент между числовыми индексами.    |

`upsert` принимает `mode: 'append' | 'prepend'`, если такого значения ещё нет.

## Состояние React

Используйте `useListCollection`, если фильтрация или обновления коллекции должны управляться
состоянием React:

```tsx
import { useFilter } from '@ark-ui/react/locale';
import { useListCollection } from '@ark-ui/react/collection';

const teams = [
  { label: 'Platform', value: 'platform' },
  { label: 'Product', value: 'product' },
  { label: 'Design', value: 'design' },
];

function useTeams() {
  const { contains } = useFilter({ sensitivity: 'base' });

  return useListCollection({
    initialItems: teams,
    filter: contains,
    limit: 20,
  });
}
```

Хук возвращает активную `collection` и методы для фильтрации и обновления:
`filter`, `set`, `reset`, `clear`, `insert`, `insertBefore`, `insertAfter`, `remove`, `move`,
`moveBefore`, `moveAfter`, `reorder`, `append`, `prepend`, `update` и `upsert`.

Вызовите `filter('')`, чтобы снова показать все элементы. Вызовите `reset()`, чтобы восстановить
`initialItems`. Функция `filter` получает текст элемента и текущий текст фильтра. Для поиска с
учётом правил языка передайте функцию поиска, например `contains` из `useFilter` Ark UI, как в
примере выше.

Храните статическую `createListCollection` за пределами компонента, если элементы никогда не
меняются. Используйте хук, когда фильтрацией или изменениями коллекции должен управлять React.
