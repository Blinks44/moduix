# List Collection

`ListCollection` - это утилита данных Ark UI для элементов на основе массива. Она сопоставляет
каждому элементу строковое значение и текст для отображения, а также предоставляет поиск,
навигацию, фильтрацию, группировку и неизменяемые обновления. Утилита ничего не отображает и не
отвечает за выбор элементов или управление с клавиатуры. Её используют `Select`, `Combobox` и
`Listbox`.

## Нестандартная структура элементов

Используйте `itemToValue`, `itemToString` и `isItemDisabled`, если данные не соответствуют именам
свойств по умолчанию. Значения коллекции всегда являются строками, поэтому числовые идентификаторы
нужно преобразовывать явно:

```tsx
type Team = {
  id: number;
  name: string;
  archived: boolean;
};

const collection = createListCollection<Team>({
  items: [
    { id: 1, name: 'Platform', archived: false },
    { id: 2, name: 'Legacy', archived: true },
  ],
  itemToValue: (item) => String(item.id),
  itemToString: (item) => item.name,
  isItemDisabled: (item) => item.archived,
});
```

| Параметр         | Назначение                                                   |
| ---------------- | ------------------------------------------------------------ |
| `items`          | Элементы коллекции. Принимает итерируемый или readonly итерируемый объект. |
| `itemToValue`    | Возвращает строковое значение элемента.                      |
| `itemToString`   | Возвращает текст для отображения и поиска.                   |
| `isItemDisabled` | Возвращает признак отключённого элемента.                    |
| `groupBy`        | Возвращает ключ группы для элемента.                         |
| `groupSort`      | Сортирует группы компаратором, заданным порядком, `'asc'` или `'desc'`. |

## Получение данных и навигация

Используйте коллекцию, чтобы преобразовывать объекты элементов в значения и обратно, проверять
порядок или перемещаться между доступными элементами:

| API                                | Результат                                                     |
| ---------------------------------- | ------------------------------------------------------------- |
| `collection.items` / `collection.size` | Текущие элементы и их количество.                         |
| `getValues(items?)`                | Значения всех или выбранных элементов.                       |
| `find(value)` / `findMany(values)` | Один элемент или несколько элементов по значению.            |
| `at(index)` / `indexOf(value)`     | Элемент по индексу или индекс по значению.                    |
| `has(value)` / `hasItem(item)`     | Наличие значения или элемента.                               |
| `getItemValue(item)`               | Нормализованное строковое значение элемента.                  |
| `stringifyItem(item)` / `stringify(value)` | Текст элемента или значения для отображения.          |
| `getItemDisabled(item)`            | Нормализованный признак отключения.                          |
| `group()`                          | Пары `[groupKey, items]` с настройками группировки.           |

```tsx
const teamCollection = createListCollection({
  items: [
    { label: 'Platform', value: 'platform' },
    { label: 'Product', value: 'product' },
  ],
});

teamCollection.find('product'); // { label: 'Product', value: 'product' }
teamCollection.stringify('product'); // 'Product'
teamCollection.getNextValue('platform'); // 'product'
teamCollection.has('unknown'); // false
```

`firstValue`, `lastValue`, `getNextValue`, `getPreviousValue` и `getValueRange` используют порядок
коллекции и пропускают отключённые элементы. Методы навигации принимают необязательные `step` и
флаг `clamp`. `sort(values)` упорядочивает значения по коллекции, а `compareValue(a, b)` сравнивает
два значения в этом порядке.

Для поведения typeahead вызывайте `search(queryString, options)` со стабильным состоянием поиска:

```tsx
const searchState = { keysSoFar: '', timer: -1 };

const nextValue = collection.search('p', {
  state: searchState,
  currentValue: null,
  timeout: 350,
});
```

Храните `searchState` в течение всего взаимодействия. В React для этого удобно использовать
`useRef`. В Solid оставьте тот же объект в области компонента или в другом стабильном хранилище.

## Динамические коллекции

Используйте `useListCollection`, если коллекция фильтруется или обновляется из состояния
компонента. Callback `filter` получает текст элемента, текущий текст фильтра и сам элемент.
Параметр `limit` ограничивает количество элементов в коллекции, что полезно для больших наборов
данных.

В примере `Listbox` использует отдельное подписанное поле фильтра. Установите `typeahead={false}`,
если фильтрацией управляет это поле, и отображайте пустое состояние, когда совпадений нет.

В React `collection` - это `ListCollection`. В Solid это accessor, поэтому при передаче коллекции
компоненту или чтении `collection().items` в цикле `<For>` вызывайте `collection()`. Хук предоставляет
`filter`, `set`, `reset`, `clear`, `insert`, `insertBefore`, `insertAfter`, `remove`, `move`,
`moveBefore`, `moveAfter`, `reorder`, `append`, `prepend`, `update` и `upsert`.

Вызовите `filter('')`, чтобы вернуть все элементы, и `reset()`, чтобы восстановить `initialItems`.

## Неизменяемые обновления

Методы обновления `ListCollection` возвращают новую коллекцию. Сохраните результат, если изменение
должно стать следующей коллекцией:

```tsx
const nextCollection = collection
  .append({ label: 'Support', value: 'support' })
  .remove('design')
  .reorder(0, 1);
```

| API                                      | Операция                                          |
| ---------------------------------------- | ------------------------------------------------- |
| `copy(items?)` / `setItems(items)`       | Копирует коллекцию или заменяет все элементы.     |
| `update(value, item)`                    | Заменяет существующий элемент.                   |
| `upsert(value, item, mode?)`             | Обновляет элемент или добавляет его с края.       |
| `insert(index, ...items)`                | Вставляет элементы по индексу.                    |
| `insertBefore` / `insertAfter`           | Вставляет элементы относительно значения.        |
| `prepend` / `append`                     | Добавляет элементы в начало или конец.           |
| `filter(predicate)` / `remove(...)`      | Оставляет подходящие элементы или удаляет элементы и значения. |
| `move` / `moveBefore` / `moveAfter`       | Перемещает одно или несколько значений.          |
| `reorder(from, to)`                      | Перемещает элемент между числовыми индексами.    |

`upsert` принимает `mode: 'append' | 'prepend'`, если такого значения ещё нет. Исходная коллекция
не изменяется.

## Интеграция и доступность

Используйте `Select`, `Combobox` или `Listbox`, если нужны встроенные выбор, фокус, управление с
клавиатуры и ARIA-поведение. Коллекция предоставляет только данные. При создании собственного
интерфейса реализуйте на уровне UI доступное имя, клавиатурное управление, роли, состояния, а также
сообщения о пустом или отключённом элементе.
