Используйте `TooltipTrigger` для элемента, который открывает подсказку, а `TooltipBody` для её
содержимого. `TooltipBody` объединяет `TooltipPositioner` и `TooltipContent`. У триггера должно
быть собственное доступное имя. Содержимое подсказки дополняет интерфейс и не заменяет видимый
текст или `aria-label`.

## Выбор подходящего компонента

Используйте `Tooltip`, чтобы показывать короткую дополнительную информацию при наведении или
когда триггер получает фокус.

- Выбирайте **`Tooltip`** для коротких подписей и некликабельных контекстных подсказок.
- Выбирайте **`Popover`**, если во всплывающем элементе нужны подробное содержимое, действия или элементы формы.
- Выбирайте **`HoverCard`**, если нужно показать дополнительный предпросмотр, связанный с триггером.

## Композиция

Для стандартной композиции `Trigger` и содержимого используйте `TooltipBody`: он объединяет
`TooltipPositioner` и `TooltipContent`. Используйте эти части явно, если им нужны независимые
стили или структура. Корневой компонент владеет состоянием: `defaultOpen` подходит для
неконтролируемой подсказки, а `open` вместе с `onOpenChange(details)` используется, когда состояние
хранится в другой части приложения. Используйте `TooltipRootProvider` с `useTooltip()`, если
хранилище создаётся за пределами дерева, а `TooltipContext` или `useTooltipContext()`, если
состояние нужно потомку. `asChild` принимает один доступный для фокуса элемент, а в Solid
используется функция рендеринга. `TooltipDisabledTrigger` предназначен для одного отключённого
нативного элемента. Портал включён по умолчанию, поэтому задавайте `portalled={false}` или
передавайте `portalRef` только при необходимости ограничить подсказку конкретной DOM-областью.
В Vue используйте `v-model:open` для контролируемого состояния и kebab-case-события, например
`@open-change`.

По умолчанию содержимое монтируется при первом открытии и удаляется после анимации закрытия.
Задайте `unmountOnExit` значение `false`, чтобы сохранить его после первого открытия;
для монтирования сразу задайте также `lazyMount` значение `false`. В Vue эти параметры
передаются как `:unmount-on-exit="false"` и `:lazy-mount="false"`.

## Стилизация

`TooltipTrigger` без `asChild` выглядит как кнопка с обводкой; если несколько триггеров со значением
делят одну подсказку, состояние открытия показывает только текущий. `TooltipContent` шириной не
больше 20rem в пределах доступного места, переносит длинные строки без пробелов и растёт по высоте
вместе с текстом. Анимация содержимого читает общие переменные `--moduix-popup-motion-*` и
пропускается, когда Ark мгновенно переключает подсказку между триггерами (`data-instant`) или
пользователь предпочитает уменьшенное движение.

Используйте `className` в React или `class` в Solid и Vue на экспортируемых частях. Варианты Tailwind
используют нативные utility-классы и классы потребителя. Варианты CSS Modules построены на токенах
foundation и не имеют переменных компонента: класс на части переопределяет стили компонента из слоя.
Атрибуты состояния и хуки `data-slot` общие для обоих вариантов стилизации.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `TooltipTrigger` | `tooltip-trigger` |
| `TooltipDisabledTrigger` | `tooltip-disabled-trigger` |
| `TooltipPositioner` | `tooltip-positioner` |
| `TooltipContent` | `tooltip-content` |
| `TooltipArrow` | `tooltip-arrow` |
| `TooltipArrowTip` | `tooltip-arrow-tip` |

- `TooltipBody` не создаёт DOM-узел. При явной композиции стилизуйте отдельно
  `TooltipPositioner` и `TooltipContent`.
- `TooltipTrigger` отвечает за оформление триггера, состояния при наведении и открытии, а также за
  стили фокуса.
- `TooltipDisabledTrigger` отвечает за обёртку отключённого элемента управления и его прямого
  отключённого потомка.
- `TooltipPositioner` отвечает за ограничения плавающего позиционирования.
- `TooltipContent` отвечает за оформление всплывающей поверхности.
- `TooltipArrow` и `TooltipArrowTip` отвечают за размер, фон и обводку стрелки.

Ark также добавляет к соответствующим частям `data-scope="tooltip"`, `data-part`,
`data-state="open" | "closed"`, `data-value`, `data-current`, `data-expanded`, `data-instant`,
`data-placement` и `data-side`. Positioner предоставляет CSS-переменные времени выполнения, в том
числе `--available-width`, `--available-height`, `--reference-width`, `--reference-height`, `--x`,
`--y`, `--z-index` и `--transform-origin`.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `Tab` | Фокус на триггере показывает подсказку. |
| `Esc` | Скрывает подсказку. |
