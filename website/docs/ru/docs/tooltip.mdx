## Выбор подходящего компонента

Используйте `Tooltip`, чтобы показывать короткую дополнительную информацию при наведении или
когда триггер получает фокус.

- Выбирайте **`Tooltip`** для коротких подписей и некликабельных контекстных подсказок.
- Выбирайте **`Popover`**, если во всплывающем элементе нужны подробное содержимое, действия или элементы формы.
- Выбирайте **`HoverCard`**, если нужно показать дополнительный предпросмотр, связанный с триггером.

## Базовый пример

Используйте `Tooltip.Trigger` для элемента, который открывает подсказку, а `Tooltip.Body` для её
содержимого. `Tooltip.Body` - удобная обёртка над `Tooltip.Positioner` и `Tooltip.Content`.
У самого триггера должно быть доступное имя. Содержимое подсказки дополняет интерфейс и не заменяет
видимый текст или `aria-label`.

## Анатомия

```text
Tooltip / Tooltip.Root
├─ Tooltip.Trigger
└─ Поддерево всплывающего содержимого (автоматически выводится через портал)
   └─ Tooltip.Positioner
      └─ Tooltip.Content
         └─ содержимое
```

Добавьте `Tooltip.Arrow` первым потомком содержимого, если всплывающий элемент должен указывать на
триггер. `Tooltip.Arrow` по умолчанию выводит `Tooltip.ArrowTip`.

```text
Tooltip / Tooltip.Root
├─ Tooltip.Trigger
└─ Поддерево всплывающего содержимого (автоматически выводится через портал)
   └─ Tooltip.Positioner
      └─ Tooltip.Content
         ├─ Tooltip.Arrow
         │  └─ Tooltip.ArrowTip
         └─ содержимое
```

| Часть | Назначение |
| --- | --- |
| `Tooltip` / `Tooltip.Root` | Управляет состоянием подсказки, открытием и закрытием, задержками, позиционированием и жизненным циклом. |
| `Tooltip.RootProvider` | Отображает подсказку из объекта состояния `useTooltip()`, созданного за пределами дерева. |
| `Tooltip.Context` | Передаёт текущее состояние пользовательским потомкам через render prop. |
| `Tooltip.Body` | Удобная обёртка, которая одновременно выводит `Tooltip.Positioner` и `Tooltip.Content`. |
| `Tooltip.Trigger` | Интерактивный элемент, открывающий подсказку при наведении или фокусе. |
| `Tooltip.DisabledTrigger` | Доступная для фокуса обёртка для одного отключённого нативного элемента управления, которому нужно пояснение. |
| `Tooltip.Positioner` | Позиционирует содержимое и предоставляет переменные позиционирования Ark. |
| `Tooltip.Content` | Видимая поверхность подсказки. |
| `Tooltip.Arrow` | Необязательная позиционируемая обёртка стрелки, по умолчанию выводящая `Tooltip.ArrowTip`. |
| `Tooltip.ArrowTip` | Видимый наконечник стрелки. |

## Композиция

По умолчанию корневой компонент выводит `Positioner` через портал. Передайте `portalled={false}`,
чтобы оставить его в текущем DOM-дереве, или укажите `portalRef`, чтобы выбрать свой контейнер
портала. Структурные части остаются явными и доступными для стилизации.

### Рекомендуемая композиция

Для большинства подсказок используйте `Tooltip.Trigger` вместе с `Tooltip.Body`. API
позиционирования остаётся у корневого компонента, а содержимое разворачивается в
`Tooltip.Positioner` и `Tooltip.Content`. Явные части Ark доступны, когда структурой нужно
управлять вручную.

При миграции с shadcn `Tooltip.Body` ближе всего к обычному шагу `TooltipContent` в moduix.

### Когда нужна собственная композиция

Используйте `asChild` у `Tooltip.Trigger`, если триггером должна быть кнопка moduix `Button`, ссылка
или другой семантический элемент управления. Потомок должен оставаться одним доступным для фокуса
элементом, который поддерживает взаимодействие триггера.

Используйте `Tooltip.DisabledTrigger` вокруг одного отключённого нативного элемента управления,
которому нужно краткое пояснение. Задайте обёртке собственное доступное имя. Она может получать
фокус, пока отключённый потомок остаётся неинтерактивным, поэтому пояснение доступно пользователям
клавиатуры и указателя.

Используйте `positioning` у `Tooltip`, чтобы настроить размещение, стратегию, отступ, обработку
выхода за границы и другие параметры позиционирования Ark. Используйте явные
`Tooltip.Positioner` и `Tooltip.Content`, если нужны отдельные стили для Positioner или более
точный контроль над структурой в стиле Ark. Используйте `ids`, когда разным частям подсказки нужны
стабильные общие идентификаторы.

### Свойства по умолчанию

Содержимое, выводимое через портал, по умолчанию монтируется при первом открытии и удаляется после
анимации закрытия. Установите `unmountOnExit={false}`, чтобы сохранять его после первого открытия.
Устанавливайте оба свойства жизненного цикла в `false`, только если содержимое должно отображаться
сразу.

| Свойство | По умолчанию | Примечания |
| --- | --- | --- |
| `openDelay` | `400` | Задержка перед открытием при наведении или фокусе. |
| `closeDelay` | `150` | Задержка перед закрытием после ухода указателя или фокуса. |
| `closeOnClick` | `true` | Закрывает подсказку при нажатии на триггер. |
| `closeOnEscape` | `true` | Закрывает подсказку при нажатии Escape. |
| `closeOnPointerDown` | `true` | Закрывает подсказку при нажатии указателя. |
| `closeOnScroll` | `true` | Закрывает подсказку при прокрутке. |
| `interactive` | `false` | Оставляет подсказку открытой, пока указатель находится над её содержимым. |
| `lazyMount` | `true` | Монтирует содержимое только после первого открытия. |
| `unmountOnExit` | `true` | Удаляет содержимое после анимации закрытия. |
| `skipAnimationOnMount` | `false` | Сохраняет первую анимацию появления. |
| `portalled` | `true` | Выводит Positioner через портал. |
| `portalRef` | `-` | Указывает пользовательский контейнер портала. |
| `positioning` | `-` | Параметры позиционирования Ark. |
| `ids` | `-` | Стабильные идентификаторы частей подсказки. |
| `defaultOpen` | `-` | Начальное состояние при неконтролируемом использовании. |
| `open` | `-` | Управляемое состояние открытия. |
| `disabled` | `false` | Отключает взаимодействие с подсказкой. |

### Особенности поведения

- `onOpenChange(details)` получает объект. Читайте новое состояние открытия из `details.open`.
- `defaultOpen` задаёт начальное состояние при неконтролируемом использовании. `disabled`
  отключает взаимодействие с подсказкой, не меняя семантику самого триггера.
- Свойства присутствия Ark, такие как `present`, `immediate`, `onExitComplete`, `lazyMount` и
  `unmountOnExit`, передаются без изменений.
- `Tooltip.RootProvider`, `Tooltip.Context`, `useTooltip` и `useTooltipContext` доступны из
  `@moduix/react` для расширенного доступа к состоянию. Используйте провайдер и `useTooltip`, если
  состояние создаётся за пределами дерева подсказки.
- `Tooltip.Trigger` получает стандартное оформление триггера moduix, только если не используется
  `asChild`. При `asChild` за стилизацию отвечает дочерний элемент.
- `Tooltip.DisabledTrigger` рассчитан на одного прямого отключённого потомка. Используйте его
  вместо повторения обёртки, доступной для фокуса, `tabIndex` и правила `pointer-events` для каждого
  отключённого элемента управления.
- `Tooltip.Body` передаёт свойства, потомков и ref в `Tooltip.Content`. Он не добавляет отдельную
  DOM-часть или собственный API позиционирования.
- `Tooltip.Content` отвечает за видимую поверхность и `z-index`. `Tooltip.Positioner` отвечает за
  плавающее позиционирование и предоставляет переменные Ark, например `--available-width`,
  `--available-height` и `--transform-origin`.
- Ark добавляет `data-state="open" | "closed"` к триггеру и содержимому. При использовании значений
  триггеров он также добавляет к триггеру `data-value`, `data-current` и `data-expanded`. Содержимое
  получает атрибуты позиционирования, например `data-placement` и `data-side`.
- Переходы триггера и анимации содержимого отключаются, если пользователь предпочитает уменьшить
  количество движения.
- Содержимое подсказки переносит длинные неразрывные строки. Для длинного или интерактивного
  содержимого используйте `Popover` или `HoverCard`, а не превращайте подсказку в прокручиваемую
  область.

### Точки для стилизации

Стилизуйте часть, которая отвечает за нужный визуальный элемент:

- `Tooltip.Body` не создаёт DOM-узел. При явной композиции стилизуйте отдельно
  `Tooltip.Positioner` и `Tooltip.Content`.
- `Tooltip.Trigger` отвечает за оформление триггера, состояния при наведении и открытии, а также за
  стили фокуса.
- `Tooltip.DisabledTrigger` отвечает за обёртку отключённого элемента управления и его прямого
  отключённого потомка.
- `Tooltip.Positioner` отвечает за ограничения плавающего позиционирования.
- `Tooltip.Content` отвечает за оформление всплывающей поверхности.
- `Tooltip.Arrow` и `Tooltip.ArrowTip` отвечают за размер, фон и обводку стрелки.

Основные публичные точки привязки: `data-slot="tooltip-trigger"`,
`data-slot="tooltip-positioner"`, `data-slot="tooltip-content"`,
`data-slot="tooltip-disabled-trigger"`, `data-slot="tooltip-arrow"` и
`data-slot="tooltip-arrow-tip"`.

Ark также добавляет к соответствующим частям `data-scope="tooltip"`, `data-part`,
`data-state="open" | "closed"`, `data-value`, `data-current`, `data-expanded`, `data-instant`,
`data-placement` и `data-side`. Positioner предоставляет CSS-переменные времени выполнения, в том
числе `--available-width`, `--available-height`, `--reference-width`, `--reference-height`, `--x`,
`--y`, `--z-index` и `--transform-origin`.
