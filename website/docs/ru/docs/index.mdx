# moduix

moduix - стилизованная система React-компонентов на базе [Ark UI](https://ark-ui.com/). Она сочетает
доступные интерактивные примитивы Ark с продуманными настройками по умолчанию, явной композицией и системой
CSS-токенов, рассчитанной на продуктовые интерфейсы.

Чтобы попробовать библиотеку прямо сейчас, выберите способ установки в [Быстром старте](/docs/quick-start),
добавьте `Button` в приложение, а затем вернитесь сюда, если захотите разобраться в устройстве системы.

Визуальный язык и модель распространения исходного кода [вдохновлены shadcn/ui](https://ui.shadcn.com/):
компоненты должны выглядеть продуманно без дополнительной настройки, а их исходный код - оставаться понятным и
легко адаптироваться в вашем приложении.

## Выберите модель владения

Выберите npm-пакет, если хотите получать обновления через менеджер пакетов. Выберите реестр shadcn,
если исходный код компонентов, стили и вспомогательные утилиты должны храниться в вашем репозитории.

| Способ работы | Импорты | Лучше всего подходит для |
| --- | --- | --- |
| npm-пакет | `@moduix/react/*` | Централизованных обновлений и минимального объёма кода в приложении. |
| Реестр shadcn с исходным кодом в проекте | `@/components/moduix/*` | Полного контроля над исходным кодом и осознанных локальных изменений. |

В обоих случаях доступны одни и те же контракты компонентов и система токенов. В [Быстром старте](/docs/quick-start)
описана полная настройка для каждого варианта.

## Что означает «на базе Ark»

Сложные компоненты сохраняют модель Ark UI: именованные части, контролируемое и неконтролируемое состояние,
объекты `details`, передаваемые в колбэки, провайдеры контекста, композицию `asChild`, нативные элементы форм
и атрибуты состояния. moduix добавляет стили, значения по умолчанию, удобные композиции и стабильные хуки
`data-slot`, не скрывая структуру примитивов, необходимую для сложных продуктовых сценариев.

Ark UI остаётся источником истины для поведения взаимодействий и доступности. moduix добавляет поверх него
продуктовый слой с выверенными решениями по умолчанию.

## Что означает «вдохновлён shadcn»

Это практическое, а не косметическое вдохновение:

- проработанные значения по умолчанию, которые выглядят целостно ещё до настройки;
- понятная композиция вместо обёрток с избыточной конфигурацией;
- доступные CSS-переменные и исходный код, которые легко изучать;
- реестр shadcn для установки исходного кода в проект;
- документация, которая сначала показывает основной путь и не скрывает низкоуровневые возможности.

moduix не требует Tailwind CSS и не заменяет анатомию Ark контрактами обёрток, специфичными для shadcn.
Основой стилизации остаются нативный CSS и CSS Modules.

## Контракт стилизации

По умолчанию высота основных элементов управления - `36px`, а строк всплывающих списков - `32px`;
за это отвечают `--moduix-size-md` и `--moduix-size-sm`. Ту же шкалу используют поля ввода, кнопки,
триггеры Select и Combobox, элементы выбора даты, пагинация, пункты меню и связанные компоненты.

Цвета, интервалы, скругления, типографика, индикаторы фокуса, анимация, тени и решения для отдельных
компонентов задаются пользовательскими CSS-свойствами. Переопределите семантический токен, чтобы изменить
всю систему, общий токен семейства - чтобы настроить связанные компоненты, или переменную
`--<component>-*` для одного локального исключения. Полная иерархия описана в [Токенах](/docs/tokens),
а готовые пресеты - в [Темах](/docs/themes).

## Благодарности

moduix возможен благодаря работе и идеям этих проектов:

- [Ark UI](https://ark-ui.com/) - за доступные примитивы на базе конечных автоматов, которые формируют основу поведения.
- [Chakra UI](https://chakra-ui.com/) - за согласованную с Ark эргономику композиции и мастерство дизайн-системы,
  которые продолжают влиять на moduix.
- [shadcn/ui](https://ui.shadcn.com/) - за распространение открытого кода, красивые значения по умолчанию и стиль
  документации, ориентированный на практическое владение кодом.
- [UnoCSS](https://unocss.dev/) и [Tailwind CSS](https://tailwindcss.com/) - за основу дополнительного reset.
- [Rstack](https://rstack.rs/) - за экосистему на Rust: Rspress для документации, Rslib для сборки библиотеки и Rstest
  для тестов.
- [VoidZero](https://voidzero.dev/) - за инструменты JavaScript, используемые во всём рабочем пространстве.
