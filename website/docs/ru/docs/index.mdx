# moduix

moduix — библиотека нативных компонентов для React и Solid на базе [Ark UI](https://ark-ui.com/).
Она объединяет доступные интерактивные примитивы Ark, продуманные значения по умолчанию, явную
композицию и общую систему дизайн-токенов.

Начните с [Быстрого старта](/docs/quick-start): выберите способ установки и добавьте первый компонент.

## Выберите модель владения

Выберите npm-пакет, если хотите получать обновления через менеджер пакетов. Выберите реестр shadcn, если
исходный код компонентов, стили и вспомогательные утилиты должны храниться в вашем репозитории.

| Способ установки | Импорты | Подходит, если |
| --- | --- | --- |
| npm-пакет | `@moduix/react/*` или `@moduix/solid/*` | Нужны централизованные обновления и минимум кода, за который отвечает приложение. |
| Реестр shadcn с исходным кодом в проекте | `@/components/ui/*` | Нужен прямой контроль над исходным кодом и локальными изменениями. |

Оба способа дают одинаковый API, нативный для выбранного фреймворка, и общую систему токенов.
Фреймворк и подход к стилям можно выбирать независимо от места хранения исходного кода:

React- и Solid-пакеты на CSS Modules содержат полный каталог компонентов. Tailwind-пакеты
пополняются по одному компоненту; перед выбором проверьте доступность на странице компонента.
В [Быстром старте](/docs/quick-start) описана полная настройка каждого варианта.

## Поддерживаемые версии

Диапазон поддерживаемых версий задаётся peer-зависимостями пакетов:

| Технология | Поддерживаемые версии | Используется в |
| ---------- | --------------------- | ------------- |
| React и React DOM | 18 и 19 | `@moduix/react`, `@moduix/react-tailwind` |
| Solid | 1.9 и последующие версии 1.x | `@moduix/solid`, `@moduix/solid-tailwind` |
| Tailwind CSS | 4.x | Только Tailwind-пакеты и реестры |
| Ark UI | `^5.37.2` | Соответствующий пакет для React или Solid |

Менеджер пакетов проверит эти диапазоны при установке. Пакетам на CSS Modules Tailwind CSS не нужен.

## Что означает «на базе Ark»

Сложные компоненты сохраняют модель Ark UI: именованные части, управляемое и неуправляемое состояние,
объекты с данными события в функциях обратного вызова, провайдеры контекста, композицию `asChild`,
нативные элементы форм и атрибуты состояния. moduix добавляет стили компонентов, продуманные значения
по умолчанию, удобные композиции и стабильные атрибуты `data-slot`, не скрывая структуру примитивов,
необходимую для сложных продуктовых сценариев.

Ark UI остаётся источником истины для поведения взаимодействий и доступности. moduix отвечает за продуктовый слой:
стили, значения по умолчанию и удобные решения для типовых сценариев.

## Что означает «вдохновлён shadcn»

Идеи shadcn проявляются здесь в практических решениях:

- проработанные значения по умолчанию, которые выглядят целостно ещё до настройки;
- понятная композиция, открытые CSS-переменные и исходный код, которые легко изучать;
- реестр shadcn для установки исходного кода в проект.

Это влияние не связывает CSS Modules с Tailwind и не заменяет анатомию Ark специфичными для shadcn
обёртками. Tailwind-пакеты доступны для уже перенесённых компонентов.

## Как работают стили

Полные пакеты для React и Solid используют CSS Modules — обычные CSS-файлы с локальной областью
действия классов. npm-пакет поставляет стили вместе с каждой точкой входа, а реестр копирует те же
исходники и файлы `.module.css` в ваш репозиторий.

Tailwind-пакеты выражают те же визуальные значения по умолчанию утилитарными классами и используют
Preflight вместо необязательного сброса стилей moduix. Оба подхода используют общие семантические цвета,
отдельные глобальные токены, анимации и поведение компонентов:

- один раз импортируйте `style.css`, чтобы подключить общие токены и базовые стили;
- используйте `className` в React или `class` в Solid у корневого элемента и именованных частей;
- обращайтесь к стабильным атрибутам `data-slot` и атрибутам состояния Ark, когда нужно стилизовать конкретное состояние;
- переопределяйте переменные `--moduix-*`, чтобы настроить тему и общие визуальные решения.

В пакетах на CSS Modules цвета, интервалы, скругления, типографика, индикаторы фокуса, анимация,
тени и решения для отдельных компонентов задаются пользовательскими CSS-свойствами. Переопределите
семантический токен, чтобы изменить всю систему, общий токен семейства — чтобы настроить связанные
компоненты, или переменную `--<component>-*` для одного локального исключения. Tailwind-варианты
используют семантические утилиты и пользовательские классы, а не повторяют этот API компонентных
переменных. Выберите CSS Modules, если Tailwind не должен быть зависимостью, или Tailwind, если
утилитарные классы должны оставаться доступными для изменения вместе со скопированным кодом. Полная
иерархия описана в [Токенах](/docs/tokens), а готовые пресеты — в [Темах](/docs/themes).

## Благодарности

moduix существует благодаря работе и идеям этих проектов:

- [Ark UI](https://ark-ui.com/) - за доступные примитивы на базе конечных автоматов, которые формируют основу поведения.
- [Chakra UI](https://chakra-ui.com/) - за согласованную с Ark эргономику композиции и мастерство дизайн-системы,
  которые продолжают влиять на moduix.
- [shadcn/ui](https://ui.shadcn.com/) - за распространение открытого кода, красивые значения по умолчанию и стиль
  документации, ориентированный на практическое владение кодом.
- [UnoCSS](https://unocss.dev/) и [Tailwind CSS](https://tailwindcss.com/) - за основу дополнительного reset.
- [Rstack](https://rstack.rs/) - за экосистему на Rust: Rspress для документации, Rslib для сборки библиотеки и Rstest
  для тестов.
- [VoidZero](https://voidzero.dev/) - за инструменты JavaScript, используемые во всём рабочем пространстве.
