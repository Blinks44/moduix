# moduix

moduix - библиотека доступных компонентов для React, Solid и Vue. [Ark UI](https://ark-ui.com/)
отвечает за управление с клавиатуры, фокус и ARIA-семантику, а moduix добавляет стили, дизайн-токены
и готовые композиции. Каждый пакет использует свойства, события и реактивность своего фреймворка.

Чтобы добавить первый компонент, откройте [Быстрый старт](/docs/quick-start).

## Как устроен moduix

| Слой | Чем обеспечен | Что можно менять |
| ---- | ------------- | ---------------- |
| Поведение | Ark UI | Собирать компонент из частей, управлять состоянием, использовать `asChild`, провайдеры и контекстные хуки Ark. |
| Стили | CSS Modules или Tailwind CSS | Переопределять токены `--moduix-*`, добавлять классы, обращаться к атрибутам `data-slot`. |
| Исходный код | npm-пакет или реестр shadcn | Обновлять через менеджер пакетов или править скопированный код в своём приложении. |

## Выберите вариант установки

Каждый выбор не зависит от остальных. Все сочетания разобраны в [Быстром старте](/docs/quick-start).

| Выбор | Варианты | Когда подходит |
| ----- | -------- | -------------- |
| Фреймворк | React, Solid, Vue | Тот, на котором написано ваше приложение. Компоненты и части называются одинаково во всех трёх. |
| Стили | CSS Modules, Tailwind CSS | CSS Modules, если в приложении нет Tailwind; Tailwind CSS v4, если стили пишутся утилитами. |
| Установка | Пакет, shadcn CLI | Пакет, чтобы обновляться через менеджер пакетов; shadcn CLI, чтобы скопировать код и править его. |

Пакеты называются `@moduix/<framework>` и `@moduix/<framework>-tailwind`, например
`@moduix/vue-tailwind`. API пакета и его реестра совпадает.

## Поддерживаемые версии

Диапазон поддерживаемых версий задаётся peer-зависимостями пакетов:

| Технология | Поддерживаемые версии | Используется в |
| ---------- | --------------------- | ------------- |
| React и React DOM | 18 и 19 | `@moduix/react`, `@moduix/react-tailwind` |
| Solid | 1.9 и последующие версии 1.x | `@moduix/solid`, `@moduix/solid-tailwind` |
| Vue | 3.5 и последующие версии 3.x | `@moduix/vue`, `@moduix/vue-tailwind` |
| Tailwind CSS | 4.x | Только Tailwind-пакеты и реестры |
| Ark UI | `^5.39.3` | Соответствующий пакет для React, Solid или Vue |

Менеджер пакетов проверит эти диапазоны при установке. Пакетам на CSS Modules Tailwind CSS не нужен.

## Стили

Оба варианта стилей используют общие семантические цвета, токены, анимации и поведение компонентов.
Один раз импортируйте `style.css` с токенами и базовыми стилями, а дальше:

- передавайте `className` в React или `class` в Solid и Vue любому корню или части;
- обращайтесь к `data-slot` и атрибутам состояния Ark, например `data-state`, чтобы стилизовать состояния;
- переопределяйте токены `--moduix-*`, чтобы изменить тему всей библиотеки.

В пакетах на CSS Modules есть ещё переменные `--moduix-<component>-*`, например `--moduix-button-*`,
для настройки одного компонента. Tailwind-пакеты вместо них используют утилитарные классы. Иерархия
токенов описана в [Токенах](/docs/tokens), готовые пресеты - в [Темах](/docs/themes), переопределение
стилей - в [Стилизации](/docs/styling).
