# moduix

moduix - библиотека стилизованных компонентов на базе [Ark UI](https://ark-ui.com/). Она объединяет
доступные интерактивные примитивы Ark, продуманные значения по умолчанию, явную композицию и CSS Modules,
использующие общую систему дизайн-токенов.

Чтобы попробовать библиотеку, выберите способ установки в [Быстром старте](/docs/quick-start), добавьте
`Button` в приложение и вернитесь сюда, когда захотите разобраться в устройстве системы.

Визуальный язык и модель владения исходным кодом [вдохновлены shadcn/ui](https://ui.shadcn.com/): компоненты
должны хорошо выглядеть без дополнительной настройки, а их исходный код - оставаться понятным и легко
адаптироваться в приложении.

## Выберите модель владения

Выберите npm-пакет, если хотите получать обновления через менеджер пакетов. Выберите реестр shadcn, если
исходный код компонентов, стили и вспомогательные утилиты должны храниться в вашем репозитории.

| Способ установки | Импорты | Подходит, если |
| --- | --- | --- |
| npm-пакет | `@moduix/react/*` | Нужны централизованные обновления и минимум кода, за который отвечает приложение. |
| Реестр shadcn с исходным кодом в проекте | `@/components/moduix/*` | Нужен прямой контроль над исходным кодом и локальными изменениями. |

Оба способа дают одни и те же контракты компонентов, стили на основе CSS Modules и систему токенов. В [Быстром старте](/docs/quick-start)
описана полная настройка каждого варианта.

## Что означает «на базе Ark»

Сложные компоненты сохраняют модель Ark UI: именованные части, управляемое и неуправляемое состояние,
`details`-объекты в колбэках, провайдеры контекста, композицию `asChild`, нативные элементы форм и атрибуты
состояния. moduix добавляет стили компонентов, продуманные значения по умолчанию, удобные композиции и стабильные
хуки `data-slot`, не скрывая структуру примитивов, необходимую для сложных продуктовых сценариев.

Ark UI остаётся источником истины для поведения взаимодействий и доступности. moduix отвечает за продуктовый слой:
стили, значения по умолчанию и удобные решения для типовых сценариев.

## Что означает «вдохновлён shadcn»

Идеи shadcn проявляются здесь в практических решениях:

- проработанные значения по умолчанию, которые выглядят целостно ещё до настройки;
- понятная композиция вместо обёрток с избыточной конфигурацией;
- открытые CSS-переменные и исходный код, которые легко изучать;
- реестр shadcn для установки исходного кода в проект;
- документация, которая сначала показывает основной путь и не скрывает низкоуровневые возможности.

moduix не требует Tailwind CSS и не заменяет анатомию Ark контрактами обёрток, специфичными для shadcn.
Стили компонентов построены на CSS Modules и общих CSS-токенах.

## Как работают стили

moduix использует CSS Modules для стилей компонентов. CSS Modules - это обычные CSS-файлы с локальной областью
действия классов, поэтому селекторы компонента не влияют на остальную часть приложения.

При установке через npm стили поставляются вместе с импортируемыми компонентами. При установке через реестр shadcn
CLI копирует в ваш репозиторий те же исходники компонентов и файлы `.module.css`. В обоих случаях действует один
контракт стилизации:

- один раз импортируйте `style.css`, чтобы подключить общие токены и базовые стили;
- используйте `className` у корневого элемента и именованных частей для локальных селекторов;
- обращайтесь к стабильным атрибутам `data-slot` и атрибутам состояния Ark, когда нужно стилизовать конкретное состояние;
- переопределяйте переменные `--moduix-*`, чтобы настроить тему и общие визуальные решения.

В приложении по-прежнему можно использовать обычный CSS, Tailwind CSS или другой инструмент для макета и других
стилей приложения. Чтобы изменить CSS самого компонента, выберите установку через реестр shadcn.

## Контракт стилизации

В стандартной шкале высота основных элементов управления - `36px`, а строк всплывающих списков - `32px`.
За это отвечают `--moduix-size-md` и `--moduix-size-sm`. Ту же шкалу используют поля ввода, кнопки,
триггеры Select и Combobox, элементы выбора даты, пагинация, пункты меню и связанные компоненты.

Цвета, интервалы, скругления, типографика, индикаторы фокуса, анимация, тени и решения для отдельных компонентов
задаются пользовательскими CSS-свойствами. Переопределите семантический токен, чтобы изменить всю систему, общий
токен семейства - чтобы настроить связанные компоненты, или переменную `--<component>-*` для одного локального
исключения. Полная иерархия описана в [Токенах](/docs/tokens), а готовые пресеты - в [Темах](/docs/themes).

## Благодарности

moduix существует благодаря работе и идеям этих проектов:

- [Ark UI](https://ark-ui.com/) - за доступные примитивы на базе конечных автоматов, которые формируют основу поведения.
- [Chakra UI](https://chakra-ui.com/) - за согласованную с Ark эргономику композиции и мастерство дизайн-системы,
  которые продолжают влиять на moduix.
- [shadcn/ui](https://ui.shadcn.com/) - за распространение открытого кода, красивые значения по умолчанию и стиль
  документации, ориентированный на практическое владение кодом.
- [UnoCSS](https://unocss.dev/) и [Tailwind CSS](https://tailwindcss.com/) - за основу дополнительного reset.
- [Rstack](https://rstack.rs/) - за экосистему на Rust: Rspress для документации, Rslib для сборки библиотеки и Rstest
  для тестов.
- [VoidZero](https://voidzero.dev/) - за инструменты JavaScript, используемые во всём рабочем пространстве.
