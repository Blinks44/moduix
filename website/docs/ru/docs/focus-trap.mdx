## Когда использовать

Используйте `FocusTrap`, если пользовательская интерактивная область должна удерживать фокус, пока пользователь не
завершит действие или не выйдет из сценария. Утилита подходит для интерфейсов, похожих на модальные, если в moduix
нет готового компонента для такого случая.

Для обычного модального окна используйте `Dialog` или `Drawer` из moduix. Они уже удерживают и возвращают фокус,
блокируют прокрутку, поддерживают закрытие и добавляют нужную семантику доступности. Не добавляйте `FocusTrap` в их
содержимое.

Импортируйте утилиту напрямую из Ark UI:

```tsx
import { FocusTrap } from '@ark-ui/react/focus-trap';
```

## Базовый пример

Управляйте ловушкой через `disabled`. Когда начинается режим проверки, фокус переходит к элементу, который возвращает
`initialFocus`. После завершения ловушка отключается и по умолчанию возвращает фокус кнопке, запустившей сценарий.

## Жизненный цикл фокуса

По умолчанию при активации ловушка переводит фокус на первый элемент, доступный по Tab. С `initialFocus` можно
выбрать более подходящую начальную точку: например, главное поле ввода или основное действие. Также учитывается
элемент с атрибутом `autofocus`.

Если внутри нет элементов, доступных по Tab, передайте `fallbackFocus` и добавьте целевому элементу `tabIndex={-1}`:
тогда он сможет получить фокус программно. Устанавливайте `returnFocusOnDeactivate={false}` только если другая часть
сценария сама управляет фокусом после отключения ловушки. `setReturnFocus` позволяет указать элемент, который получит
фокус в конце.

## Чего Focus Trap не делает

`FocusTrap` удерживает фокус только при навигации с клавиатуры. Он не создаёт подложку, слой в портале, диалоговую
роль, доступное имя, обработку Escape, блокировку прокрутки или логику закрытия. Для пользовательской области всё это
нужно реализовать отдельно; если подходит готовая модель взаимодействия, выбирайте `Dialog` или `Drawer`.

## Использование с moduix

Оберните пользовательскую область moduix один раз и сделайте навигацию с клавиатуры понятной: добавьте видимое
действие, которое отключает ловушку, логичный заголовок и описание. Не удерживайте фокус в содержимом, которое
пользователь не может закрыть. Кнопки, поля ввода и другие элементы moduix внутри ловушки работают как обычно.

## Границы ответственности

Ark UI отвечает за удержание фокуса и API его жизненного цикла. moduix показывает, как использовать утилиту со
своими компонентами, но не переэкспортирует и не стилизует `FocusTrap`.
