## Как выбрать подходящий компонент

`FocusTrap` относится к низкоуровневым утилитам управления фокусом. Используйте его, если приложение само отвечает за
разметку интерактивной области и фокус при навигации с клавиатуры должен оставаться внутри неё, пока пользователь не
завершит действие или явно не выйдет из этого сценария.

Для модального окна используйте `Dialog`, а для модальной панели, прикреплённой к краю экрана, `Drawer`. Оба
компонента уже управляют удержанием и возвратом фокуса, блокировкой прокрутки, закрытием и семантикой диалога. Не
добавляйте `FocusTrap` внутрь этих компонентов.

`FocusTrap` входит в Ark UI, поэтому импортируйте его оттуда. moduix не переэкспортирует и не стилизует эту утилиту:

```tsx
import { FocusTrap } from '@ark-ui/react/focus-trap';
```

Если эти пакеты ещё не установлены в приложении, добавьте их:

```bash
pnpm add @ark-ui/react @moduix/react
```

## Жизненный цикл фокуса

### Как выбрать начальный фокус

По умолчанию при активации фокус переходит на первый элемент, на который можно перейти клавишей `Tab`. Также
учитывается элемент с атрибутом `autofocus`; в React ему соответствует свойство `autoFocus`. Используйте
`initialFocus`, если сначала нужно сфокусировать другой элемент, например основное поле ввода или главное действие.

Укажите `initialFocus={false}`, если при активации не нужно менять фокус. В этом случае `fallbackFocus` также не
используется.

### Если в области нет элементов для перехода по Tab

Если внутри области нет элементов, на которые можно перейти клавишей `Tab`, передайте `fallbackFocus`. У целевого
элемента должен быть `tabIndex={-1}`, чтобы Ark мог сфокусировать его программно. Если `initialFocus` не установлен в
`false`, при активации будет выброшена ошибка, когда Ark не найдёт ни доступного элемента, ни запасной цели.

### Как вернуть фокус

По умолчанию фокус возвращается на элемент, который был сфокусирован до активации `FocusTrap`. Укажите
`returnFocusOnDeactivate={false}`, если после отключения другая часть сценария сама отвечает за фокус. Свойство
`setReturnFocus` позволяет заменить стандартную цель элементом или функцией, которая возвращает нужный элемент. Также
можно передать `false`, чтобы не восстанавливать фокус.

Колбэки `onActivate` и `onDeactivate` вызываются до того, как Ark переведёт фокус на следующую цель. Используйте их
для побочных действий, а не вместо управления жизненным циклом фокуса.

### Портальное содержимое

Если интерактивное содержимое рендерится в портале за пределами области, передайте в `persistentElements` функции, которые
возвращают эти элементы, чтобы Ark считал содержимое частью ловушки. По возможности размещайте связанные элементы,
доступные по Tab, внутри самой области.

### Как использовать собственный корневой элемент

По умолчанию `FocusTrap` рендерит обёртку вокруг дочернего содержимого. Укажите `asChild`, чтобы передать поведение
ловушки одному дочернему элементу и использовать его как контейнер. В качестве дочернего элемента используйте один
семантически подходящий элемент.

## Чего не делает FocusTrap

`FocusTrap` управляет только фокусом при навигации с клавиатуры. Он не создаёт подложку или портал, не добавляет роль
диалога и доступное имя, не делает остальную страницу недоступной для взаимодействия, не запрещает прокрутку, не
обрабатывает Escape и не закрывает область при взаимодействии снаружи.

Если пользовательская область должна быть модальной, реализуйте эти поведения отдельно или используйте `Dialog` либо
`Drawer`, если их готовая модель взаимодействия подходит для задачи.

## Использование с moduix

Размещайте внутри ловушки `Card`, `Button`, `Stack` и другие компоненты moduix как обычно. Добавьте понятные заголовок
и описание области, а также видимое действие, которое отключает удержание фокуса. Не удерживайте фокус в содержимом,
которое пользователь не может закрыть.

Если область является модальным окном или выдвижной панелью, используйте соответствующий компонент moduix вместо того,
чтобы собирать модальное поведение вокруг `FocusTrap`.

## Границы ответственности

Ark UI отвечает за `FocusTrap` и API жизненного цикла фокуса. moduix предоставляет окружающие компоненты и показывает,
как их сочетать, но не переэкспортирует и не стилизует `FocusTrap`.
