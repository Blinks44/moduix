## Выбор подходящего компонента

Используйте `AngleSlider`, когда пользователю нужно задать направление или угол поворота на
круговом диске.

- Выбирайте **`AngleSlider`** для поворота, направления, ориентации прожектора и других угловых значений.
- Выбирайте **`Slider`**, если значение удобнее задавать на линейной шкале.
- Выбирайте **`NumberInput`**, если точный ввод градусов важнее прямого взаимодействия с диском.

## Базовый пример

AngleSlider доступен для React и Solid в вариантах с CSS Modules и Tailwind. Превью на этой

## Анатомия

```text
AngleSlider / AngleSlider.Root
├─ AngleSlider.Label
├─ AngleSlider.Dial
│  └─ AngleSlider.Thumb
├─ AngleSlider.Marks (необязательно)
│  └─ AngleSlider.Marker[value]
├─ AngleSlider.ValueText
└─ AngleSlider.HiddenInput (явно)

AngleSlider.RootProvider
└─ same part tree connected to a useAngleSlider() store
```

| Часть                              | Назначение                                                            |
| ---------------------------------- | --------------------------------------------------------------------- |
| `AngleSlider` / `AngleSlider.Root` | Стилизованный корневой компонент, который хранит состояние слайдера.  |
| `AngleSlider.RootProvider`         | Подключает части к состоянию, созданному через `useAngleSlider()`.    |
| `AngleSlider.Label`                | Связывает видимую подпись со слайдером.                               |
| `AngleSlider.Control`              | Задаёт круглую область для взаимодействия указателем.                 |
| `AngleSlider.Dial`                 | Удобная композиция из `Control` и `Thumb`.                            |
| `AngleSlider.Thumb`                | Фокусируемый бегунок, показывающий текущий угол.                      |
| `AngleSlider.MarkerGroup`          | Содержит необязательные опорные маркеры.                              |
| `AngleSlider.Marker`               | Размещает числовой маркер вокруг диска.                               |
| `AngleSlider.Marks`                | Создаёт маркеры по массиву `values`.                                  |
| `AngleSlider.ValueText`             | Показывает текущее значение в градусах.                               |
| `AngleSlider.HiddenInput`           | Нативное поле формы; добавляйте его явно для отправки значения.       |

## Композиция

Используйте `defaultValue` для неконтролируемого слайдера, а `value` вместе с
`onValueChange(details)` — когда состоянием угла управляет другая часть приложения. Используйте
`AngleSlider.RootProvider` с `useAngleSlider()` из соответствующего пакета только тогда, когда
store нужно создать вне дерева слайдера; не рендерите `Root` и `RootProvider` для одного состояния.
В Solid состояние store читается через функцию-аксессор, например `angleSlider().value`.

`Dial` и `Marks` — удобные составные компоненты. Используйте `Control` с `Thumb` или
`MarkerGroup` с `Marker`, если нужны собственные дочерние элементы, другой порядок частей или
индивидуальные свойства маркеров. Для нативной формы явно добавляйте `HiddenInput`. Укажите `name`
в корневом компоненте для формы в том же дереве или `form` в `HiddenInput`, если форма находится
отдельно.

## Стилизация

Используйте `className` в React или `class` в Solid для структурных стилей экспортируемых частей.
Для стилей состояний предпочитайте атрибуты Ark — `data-state`, `data-disabled`, `data-invalid` и
`data-readonly` — вместе с селекторами moduix `data-slot`. Варианты на Tailwind настраиваются
обычными утилитами и пользовательскими классами; перечисленные ниже переменные компонента относятся
к вариантам с CSS Modules. Вычисляемые во время работы переменные Ark и указанные хуки доступны в
обоих подходах.

### Хуки стилизации

- Стабильные селекторы `data-slot`: `angle-slider-root`, `angle-slider-root-provider`,
  `angle-slider-label`, `angle-slider-control`, `angle-slider-thumb`, `angle-slider-marker-group`,
  `angle-slider-marker` и `angle-slider-value-text`.
- Селекторы частей Ark используют `data-scope="angle-slider"` и `data-part`.
- `AngleSlider.Marks` создаёт те же хуки маркеров, что и явные части `MarkerGroup` и `Marker`.
- Для стилизации доступны переменные корня `--value` и `--angle`, а также переменные маркеров
  `--marker-value` и `--marker-display-value`.
- При включённом предпочтении пользователя уменьшать движение анимация бегунка отключается.
