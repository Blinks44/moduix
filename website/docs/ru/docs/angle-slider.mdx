## Выбор подходящего компонента

Используйте `AngleSlider`, когда пользователю нужно задать направление или поворот на круговом регуляторе.

- Выберите **`AngleSlider`** для поворота, курса, направления прожектора и других угловых значений.
- Выберите **`Slider`**, если значение проще задавать на линейной шкале.
- Выберите **`NumberInput`**, если точный ввод значения в градусах важнее прямого взаимодействия.

## Анатомия

```text
AngleSlider.Root
├─ AngleSlider.Label
├─ AngleSlider.Control
│  ├─ AngleSlider.MarkerGroup
│  │  └─ AngleSlider.Marker[value]
│  └─ AngleSlider.Thumb
└─ AngleSlider.ValueText
```

| Часть                              | Назначение                                                              |
| ---------------------------------- | ----------------------------------------------------------------------- |
| `AngleSlider` / `AngleSlider.Root` | Предоставляет управляемое или неуправляемое состояние слайдера.         |
| `AngleSlider.RootProvider`         | Подключает состояние Ark, созданное вне дерева слайдера.                |
| `AngleSlider.Label`                | Связывает видимую подпись со слайдером.                                 |
| `AngleSlider.Control`              | Предоставляет круглую область для взаимодействия указателем.            |
| `AngleSlider.Dial`                 | Вспомогательная обёртка, отрисовывающая `Control` и `Thumb`.             |
| `AngleSlider.MarkerGroup`          | Содержит необязательные опорные маркеры.                                |
| `AngleSlider.Marker`               | Размещает числовой маркер и показывает его отношение к текущему значению.|
| `AngleSlider.Marks`                | Вспомогательная обёртка для `MarkerGroup` и элементов `Marker`.          |
| `AngleSlider.Thumb`                | Фокусируемый бегунок, показывающий текущий угол.                        |
| `AngleSlider.ValueText`            | Показывает текущее значение в градусах.                                 |

## Композиция

### Рекомендуемая композиция

Начните с `Dial` и добавьте только нужные части:

- добавьте `Label` или `aria-label`, чтобы задать элементу доступное имя
- добавьте `Marks`, если пользователям нужны опорные точки вокруг регулятора
- добавьте `ValueText`, если числовое значение угла должно оставаться видимым
- укажите `name`, если угол должен передаваться при отправке нативной формы
- укажите `form`, если нативное поле относится к форме, которая не содержит слайдер

### Когда нужна собственная композиция

Используйте отдельные части `Control`, `Thumb`, `MarkerGroup` и `Marker`, если нужны пользовательские
дочерние элементы, индивидуальные свойства маркеров или другой порядок. Используйте `useAngleSlider()` из
`@moduix/react` вместе с `AngleSlider.RootProvider`, если состояние должно быть доступно за пределами дерева
слайдера. Для чтения контекста используйте `AngleSlider.Context` и `useAngleSliderContext()` из moduix. Не
используйте `Root` и `RootProvider` для одного экземпляра состояния.

DOM-части Ark поддерживают `asChild`. Передайте один совместимый дочерний элемент, который сохраняет
обработку клавиатуры, фокуса, ARIA и указателя. `Dial` и `Marks` всегда отрисовывают фиксированную
композицию из нескольких частей, поэтому не принимают `asChild`. С `Root` или `RootProvider` используйте
контейнер, способный вместить внутреннее скрытое поле ввода и части слайдера. Используйте `ids` на `Root`,
если составным элементам нужны стабильные общие идентификаторы. `ref` передаётся в DOM-элемент, который
отрисовывает соответствующая обёрнутая часть Ark.

### Свойства по умолчанию

| Свойство       | По умолчанию | Примечания                                      |
| -------------- | ------------ | ----------------------------------------------- |
| `defaultValue` | `0`          | Начальный угол в неуправляемом режиме            |
| `step`         | `1`          | Шаг изменения с клавиатуры и указателем         |
| `disabled`     | `false`      | Запрещает фокус и взаимодействие                 |
| `readOnly`     | `false`      | Оставляет значение видимым, но запрещает изменение|
| `invalid`      | `false`      | Сообщает о недопустимом состоянии для ARIA и стилей|

### Особенности поведения

- `value` содержит одно число. `onValueChange(details)` и `onValueChangeEnd(details)` получают
  объект callback Ark с полями `details.value` и `details.valueAsDegree`.
- Бегунок поддерживает клавиатурное поведение слайдера Ark и перетаскивание указателем по круговой области.
- `AngleSlider.Marks` создаёт тот же DOM маркеров и те же хуки стилизации, что и явная композиция
  `MarkerGroup` и `Marker`.
- `Root` и `RootProvider` автоматически создают скрытое нативное поле формы. Укажите `name` для
  отправки формы, а `form` для внешней формы-владельца. Сброс формы возвращает неуправляемый `Root`
  к `defaultValue`, а `RootProvider` к значению, которое было у него при монтировании. При
  управляемом состоянии итоговое значение по-прежнему задаёт внешний код.
- `ValueText` показывает строку с градусами от Ark, если не переданы пользовательские дочерние элементы.
- Для стилизации доступны `data-disabled`, `data-invalid`, `data-readonly`, `data-state` маркера,
  `--value`, `--angle`, `--marker-value` и `--marker-display-value`.

## Стилизация

Стилизуйте компонент с помощью `className`, стабильных хуков `data-slot="angle-slider-*"`, атрибутов Ark
`data-scope="angle-slider"` / `data-part`, атрибутов состояния и публичных CSS-переменных ниже.

### CSS-свойства

<CssPropertiesSection properties={AngleSliderDocs.angleSliderCssProperties} />

### Хуки стилизации

- `data-slot="angle-slider-root"` и `data-slot="angle-slider-root-provider"` задают общую разметку.
- `data-slot="angle-slider-control"` отвечает за круговой регулятор и получает `data-disabled`, `data-invalid`
  и `data-readonly`.
- `data-slot="angle-slider-thumb"` отвечает за фокусируемый поворотный индикатор и может выбираться через
  `:focus-visible`.
- `data-slot="angle-slider-marker"` предоставляет `data-value` и
  `data-state="under-value | at-value | over-value"`.
- `AngleSlider.Marks` создаёт те же хуки `data-slot="angle-slider-marker-group"` и
  `data-slot="angle-slider-marker"`, что и явные части маркеров.
- Корневые переменные Ark `--value` и `--angle`, а также переменные маркеров `--marker-value` и
  `--marker-display-value` остаются доступными.
- Цвета кольца при наведении и нажатии применяются только к интерактивному регулятору. Если
  пользователь предпочитает уменьшить движение, переходы бегунка отключаются.
