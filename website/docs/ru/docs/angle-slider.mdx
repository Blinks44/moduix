## Выбор подходящего компонента

Используйте `AngleSlider`, когда пользователю нужно задать направление или угол поворота на
круговом диске.

- Выбирайте **`AngleSlider`** для поворота, направления, ориентации прожектора и других угловых значений.
- Выбирайте **`Slider`**, если значение удобнее задавать на линейной шкале.
- Выбирайте **`NumberInput`**, если точный ввод градусов важнее прямого взаимодействия с диском.

## Базовый пример


Начните с `AngleSliderDial`: он объединяет круговой трек, центрированное значение и бегунок. Трек заполняется
сверхи по мере роста угла. `AngleSlider` принимает
один угол от 0 до 360 градусов. По возможности добавляйте видимую `AngleSliderLabel`. Если у диска нет
видимой подписи, добавьте `aria-label` в корневой компонент.

## Анатомия

```text
AngleSlider
├─ AngleSliderLabel
├─ AngleSliderDial
│  ├─ AngleSliderMarks (необязательно)
│  │  └─ AngleSliderMarker[value]
│  ├─ AngleSliderValueText
│  └─ AngleSliderThumb
└─ AngleSliderHiddenInput (явно)

AngleSliderRootProvider
└─ same part tree connected to a useAngleSlider() store
```

| Часть                              | Назначение                                                            |
| ---------------------------------- | --------------------------------------------------------------------- |
| `AngleSlider` | Стилизованный корневой компонент, который хранит состояние слайдера.  |
| `AngleSliderRootProvider`         | Подключает части к состоянию, созданному через `useAngleSlider()`.    |
| `AngleSliderLabel`                | Связывает видимую подпись со слайдером.                               |
| `AngleSliderControl`              | Задаёт круглую область для взаимодействия указателем.                 |
| `AngleSliderDial`                 | Удобная композиция из `Control`, центрированной `ValueText` и `Thumb`. |
| `AngleSliderThumb`                | Фокусируемый круглый бегунок, движущийся по треку в соответствии с текущим углом. |
| `AngleSliderMarkerGroup`          | Содержит необязательные опорные маркеры.                              |
| `AngleSliderMarker`               | Размещает числовой маркер вокруг диска.                               |
| `AngleSliderMarks`                | Создаёт маркеры по массиву `values`.                                  |
| `AngleSliderValueText`             | Показывает текущее значение в градусах; `AngleSliderDial` центрирует его в диске. |
| `AngleSliderHiddenInput`           | Нативное поле формы; добавляйте его явно для отправки значения.       |

## Композиция

Используйте `defaultValue` для неконтролируемого слайдера, а `value` вместе с
`onValueChange(details)` - когда состоянием угла управляет другая часть приложения. Используйте
`AngleSliderRootProvider` с `useAngleSlider()` из соответствующего пакета только тогда, когда
store нужно создать вне дерева слайдера; не рендерите корневой компонент и `AngleSliderRootProvider`
для одного состояния.
В Solid состояние store читается через функцию-аксессор, например `angleSlider().value`.

`AngleSliderDial` и `AngleSliderMarks` - удобные составные компоненты. Используйте `AngleSliderControl` с `AngleSliderThumb` или
`AngleSliderMarkerGroup` с `AngleSliderMarker`, если нужны собственные дочерние элементы, другой порядок частей или
индивидуальные свойства маркеров. Для нативной формы явно добавляйте `AngleSliderHiddenInput`. Укажите `name`
в корневом компоненте для формы в том же дереве или `form` в `AngleSliderHiddenInput`, если форма находится
отдельно.

## Примеры

### Управляемое состояние

Используйте управляемое состояние, когда угол должен синхронизироваться с состоянием приложения.

<Example name="angle-slider/controlled" />

### Отключённый режим

Используйте `disabled`, когда элемент управления должен быть недоступен, не получать фокус и не
реагировать на взаимодействие.

<Example name="angle-slider/disabled" />

### В форме

Добавьте `AngleSliderHiddenInput` и `name`, чтобы включить угол в нативную отправку формы. Кнопка
Reset показывает встроенный в Ark сброс формы. Укажите `form` в `AngleSliderHiddenInput`, если форма
не является предком слайдера.

<Example name="angle-slider/form" />

### Недопустимое значение

Используйте `invalid`, когда выбранный угол не проходит проверку. Диск получит стили ошибки и
соответствующее состояние ARIA, не меняя модель взаимодействия.

<Example name="angle-slider/invalid" />

### Только для чтения

Используйте `readOnly`, когда текущее значение должно оставаться видимым и доступным для фокуса,
но не должно изменяться.

<Example name="angle-slider/read-only" />

### Root Provider

Используйте `useAngleSlider()` из соответствующего пакета вместе с `AngleSliderRootProvider`, если
другому компоненту нужен прямой доступ к тому же автомату состояний. Внешнее состояние можно
использовать для управления соседним интерфейсом.

<Example name="angle-slider/root-provider" />

### Шаги

Используйте `step`, чтобы привязать взаимодействие указателем и клавиатурой к фиксированным угловым
интервалам.

<Example name="angle-slider/steps" />

### С маркерами

Используйте `AngleSliderMarks`, когда на диске нужны основные угловые отметки и не хочется
повторять `AngleSliderMarkerGroup` и `AngleSliderMarker`. `AngleSliderDial` сохраняет вместе композицию `AngleSliderControl` и
`AngleSliderThumb`.

<Example name="angle-slider/with-marks" />

### Расширенная настройка

Используйте явные части вместо `AngleSliderDial` и `AngleSliderMarks`, если диску нужна собственная
композиция маркеров или дополнительные дочерние элементы внутри области управления.

## Стилизация

Используйте `className` в React и `class` в Solid или Vue для структурных стилей экспортируемых частей.
Для стилей состояний предпочитайте атрибуты Ark - `data-state`, `data-disabled`, `data-invalid` и
`data-readonly` - вместе с селекторами moduix `data-slot`. Варианты на Tailwind настраиваются
обычными утилитами и пользовательскими классами; перечисленные ниже переменные компонента относятся
к вариантам с CSS Modules. Вычисляемые во время работы переменные Ark и указанные хуки доступны в
обоих подходах.

### Хуки стилизации

- Стабильные селекторы `data-slot`: `angle-slider-root`, `angle-slider-root-provider`,
  `angle-slider-label`, `angle-slider-control`, `angle-slider-thumb`, `angle-slider-marker-group`,
  `angle-slider-marker` и `angle-slider-value-text`.
- Селекторы частей Ark используют `data-scope="angle-slider"` и `data-part`.
- `AngleSliderMarks` создаёт те же хуки маркеров, что и явные части `AngleSliderMarkerGroup` и `AngleSliderMarker`.
- Для стилизации доступны переменные корня `--value` и `--angle`, а также переменные маркеров
  `--marker-value` и `--marker-display-value`.
- При включённом предпочтении пользователя уменьшать движение анимация бегунка отключается.
