## Выбор подходящего компонента

Используйте `AngleSlider`, когда пользователю нужно задать направление или угол поворота с помощью кругового
регулятора.

- Выберите **`AngleSlider`** для поворота объекта, задания курса, направления прожектора и других угловых значений.
- Выберите **`Slider`**, если значение удобнее выбирать на линейной шкале.
- Выберите **`NumberInput`**, если важнее ввести точное значение в градусах, чем выбирать его напрямую.

## Анатомия

```text
AngleSlider.Root
├─ AngleSlider.Label
├─ AngleSlider.Control
│  ├─ AngleSlider.MarkerGroup
│  │  └─ AngleSlider.Marker[value]
│  └─ AngleSlider.Thumb
├─ AngleSlider.ValueText
└─ AngleSlider.HiddenInput (явно)
```

| Часть                              | Назначение                                                                  |
| ---------------------------------- | --------------------------------------------------------------------------- |
| `AngleSlider` / `AngleSlider.Root` | Стилизованный корневой компонент, который хранит состояние слайдера.       |
| `AngleSlider.HiddenInput` | Нативное поле Ark; правила явной композиции описаны ниже. |
| `AngleSlider.RootProvider`         | Подключает части к состоянию Ark, созданному вне дерева компонента.         |
| `AngleSlider.Label`                | Связывает видимую подпись со слайдером.                                     |
| `AngleSlider.Control`              | Задаёт круглую область для взаимодействия указателем.                       |
| `AngleSlider.Dial`                 | Сочетает `Control` и `Thumb`; принимает дочерние элементы.                  |
| `AngleSlider.MarkerGroup`          | Содержит необязательные опорные маркеры.                                    |
| `AngleSlider.Marker`               | Размещает числовой маркер и показывает его отношение к текущему значению.   |
| `AngleSlider.Marks`                | Удобная композиция, создающая маркеры по массиву `values`.                  |
| `AngleSlider.Thumb`                | Фокусируемый бегунок, показывающий текущий угол.                            |
| `AngleSlider.ValueText`            | Показывает текущее значение в градусах.                                     |

Явно добавьте `AngleSlider.HiddenInput` внутрь `Root` или `RootProvider`, если значение должно
участвовать в нативной форме.

## Композиция

### Нативное поле формы

`AngleSlider.HiddenInput` — нативное поле Ark, экспортируемое без обёртки. Добавьте его явно внутрь
`AngleSlider` или `AngleSlider.RootProvider`: корневой компонент не создаёт его автоматически.
Задайте `name` на корневом компоненте, чтобы значение отправлялось с формой.

Если форма находится вне дерева компонента, задайте `form` непосредственно на `HiddenInput`.

### Рекомендуемая композиция

Начните с `Dial` и добавляйте только нужные части:

- добавьте `Label` или `aria-label`, чтобы задать элементу доступное имя
- добавьте `Marks`, если пользователям нужны опорные точки вокруг регулятора
- добавьте `ValueText`, если числовое значение угла должно оставаться видимым
- укажите `name`, если значение угла должно попасть в данные нативной формы
- укажите `form`, если поле формы относится к форме, расположенной вне дерева слайдера

### Когда нужна собственная композиция

Используйте отдельные части `Control`, `Thumb`, `MarkerGroup` и `Marker`, если нужны свои дочерние элементы,
особые свойства отдельных маркеров или другой порядок. Создайте состояние с помощью `useAngleSlider()` из
`@moduix/react/angle-slider` и передайте его в `AngleSlider.RootProvider`, если состояние должно быть доступно
за пределами дерева слайдера. Чтобы получить состояние во вложенном компоненте, используйте `AngleSlider.Context`
или `useAngleSliderContext()` из `@moduix/react/angle-slider`. Не используйте `Root` и `RootProvider` для одного
экземпляра состояния.

DOM-части Ark поддерживают `asChild`. Передайте один совместимый дочерний элемент, который сохраняет обработку
клавиатуры, фокуса, ARIA и указателя. `Dial` и `Marks` всегда отрисовывают фиксированную композицию из нескольких
частей, поэтому `asChild` для них недоступен. В `Root` или `RootProvider` используйте контейнер, способный
вместить внутреннее скрытое поле ввода и части слайдера. Используйте `ids` на `Root`, если составным элементам
нужны стабильные общие идентификаторы. `ref` передаётся в DOM-элемент, который отрисовывает соответствующая
обёрнутая часть Ark.

### Свойства по умолчанию

| Свойство       | По умолчанию | Примечания                                            |
| -------------- | ------------ | ----------------------------------------------------- |
| `defaultValue` | `0`          | Начальный угол в неуправляемом режиме                 |
| `step`         | `1`          | Шаг изменения при работе с клавиатурой и указателем   |
| `disabled`     | `false`      | Запрещает фокус и взаимодействие                      |
| `readOnly`     | `false`      | Оставляет значение видимым, но запрещает его менять   |
| `invalid`      | `false`      | Передаёт состояние ошибки в ARIA и стили              |

### Особенности поведения

- `value` содержит одно число. `onValueChange(details)` и `onValueChangeEnd(details)` получают объект с деталями
  от Ark. Числовое значение находится в `details.value`, а строка с градусами - в `details.valueAsDegree`.
- Бегунок поддерживает клавиатурное поведение слайдера Ark и перетаскивание указателем по круговой области.
- `AngleSlider.Marks` создаёт тот же DOM маркеров и те же хуки стилизации, что и явная композиция `MarkerGroup` и
  `Marker`.
- Явно добавьте `AngleSlider.HiddenInput`. Укажите `name`, чтобы включить угол в данные формы, а
  `form` - чтобы связать поле с внешней формой. Синхронизацией нативного сброса управляет Ark.
- `ValueText` показывает строку с градусами, которую формирует Ark, если не переданы пользовательские дочерние
  элементы.
- Для стилизации доступны `data-disabled`, `data-invalid`, `data-readonly`, `data-state` маркера,
  `--value`, `--angle`, `--marker-value` и `--marker-display-value`.

## Стилизация

Настраивайте внешний вид компонента с помощью `className`, стабильных хуков `data-slot="angle-slider-*"`, атрибутов Ark
`data-scope="angle-slider"` / `data-part`, атрибутов состояния и публичных CSS-переменных ниже.

### CSS-свойства

### Хуки стилизации

- `data-slot="angle-slider-root"` и `data-slot="angle-slider-root-provider"` отвечают за общую разметку.
- `data-slot="angle-slider-control"` стилизует круговой регулятор и получает `data-disabled`, `data-invalid`
  и `data-readonly`.
- `data-slot="angle-slider-thumb"` обозначает фокусируемый поворотный индикатор, который можно выбирать через
  `:focus-visible`.
- `data-slot="angle-slider-marker"` предоставляет `data-value` и
  `data-state="under-value | at-value | over-value"`.
- `AngleSlider.Marks` создаёт те же хуки `data-slot="angle-slider-marker-group"` и
  `data-slot="angle-slider-marker"`, что и явные части маркеров.
- Корневые переменные Ark `--value` и `--angle`, а также переменные маркеров `--marker-value` и
  `--marker-display-value` остаются доступными.
- Цвета кольца при наведении и нажатии применяются только к интерактивному регулятору. В режиме уменьшения
  движения переходы бегунка отключаются.
