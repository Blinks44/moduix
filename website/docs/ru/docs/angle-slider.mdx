Начните с `AngleSliderDial`: он объединяет круговой трек, центрированное значение и бегунок. Трек заполняется
сверхи по мере роста угла. `AngleSlider` принимает
один угол от 0 до 360 градусов. По возможности добавляйте видимую `AngleSliderLabel`. Если у диска нет
видимой подписи, добавьте `aria-label` в корневой компонент.

## Выбор подходящего компонента

Используйте `AngleSlider`, когда пользователю нужно задать направление или угол поворота на
круговом диске.

- Выбирайте **`AngleSlider`** для поворота, направления, ориентации прожектора и других угловых значений.
- Выбирайте **`Slider`**, если значение удобнее задавать на линейной шкале.
- Выбирайте **`NumberInput`**, если точный ввод градусов важнее прямого взаимодействия с диском.

## Композиция

Используйте `defaultValue` для неконтролируемого слайдера, а `value` вместе с
`onValueChange(details)` - когда состоянием угла управляет другая часть приложения. Используйте
`AngleSliderRootProvider` с `useAngleSlider()` из соответствующего пакета только тогда, когда
store нужно создать вне дерева слайдера; не рендерите корневой компонент и `AngleSliderRootProvider`
для одного состояния.
В Solid состояние store читается через функцию-аксессор, например `angleSlider().value`.

`AngleSliderDial` и `AngleSliderMarks` - удобные составные компоненты. Используйте `AngleSliderControl` с `AngleSliderThumb` или
`AngleSliderMarkerGroup` с `AngleSliderMarker`, если нужны собственные дочерние элементы, другой порядок частей или
индивидуальные свойства маркеров. Для нативной формы явно добавляйте `AngleSliderHiddenInput`. Укажите `name`
в корневом компоненте для формы в том же дереве или `form` в `AngleSliderHiddenInput`, если форма находится
отдельно.

## Стилизация

Используйте `className` в React и `class` в Solid или Vue для структурных стилей экспортируемых частей.
Для стилей состояний предпочитайте атрибуты Ark - `data-state`, `data-disabled`, `data-invalid` и
`data-readonly` - вместе с селекторами moduix `data-slot`. Варианты на Tailwind настраиваются
обычными утилитами и пользовательскими классами; перечисленные ниже переменные компонента относятся
к вариантам с CSS Modules. Вычисляемые во время работы переменные Ark и указанные хуки доступны в
обоих подходах.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `AngleSlider` | `angle-slider-root` |
| `AngleSliderLabel` | `angle-slider-label` |
| `AngleSliderRootProvider` | `angle-slider-root-provider` |
| `AngleSliderControl` | `angle-slider-control` |
| `AngleSliderThumb` | `angle-slider-thumb` |
| `AngleSliderMarkerGroup` | `angle-slider-marker-group` |
| `AngleSliderMarker` | `angle-slider-marker` |
| `AngleSliderValueText` | `angle-slider-value-text` |

- Селекторы состояния Ark: `data-disabled`, `data-invalid` и `data-readonly` на корне, подписи, контроле и бегунке.

- Селекторы частей Ark используют `data-scope="angle-slider"` и `data-part`.
- `AngleSliderMarks` создаёт те же хуки маркеров, что и явные части `AngleSliderMarkerGroup` и `AngleSliderMarker`.
- Для стилизации доступны переменные корня `--value` и `--angle`, а также переменные маркеров
  `--marker-value` и `--marker-display-value`.
- При включённом предпочтении пользователя уменьшать движение анимация бегунка отключается.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `ArrowRight` / `ArrowDown` | Увеличивает угол на шаг. |
| `ArrowLeft` / `ArrowUp` | Уменьшает угол на шаг. |
| `Shift` + стрелки | Меняет угол на большой шаг. |
| `Home` / `End` | Ставит угол 0 или 360. |
