## Использование

<Usage />

Создайте группу из `Fieldset`, `FieldsetLegend`, связанных элементов управления и, если нужно, поясняющего текста или
сообщения об ошибке. `Fieldset` является корневым компонентом группы.

## Выбор подходящего компонента

Используйте `Fieldset`, когда несколько связанных элементов управления нужно объединить в одну группу с общим
заголовком, например для контактных данных или настроек уведомлений. `Field` подходит, когда у одного элемента
управления должны быть собственные метка, поясняющий текст и сообщение об ошибке.

## Примеры

### Field

Используйте вложенные компоненты `Field`, если для каждого элемента управления нужно отдельно задать метку, поясняющий текст
или сообщение об ошибке в дополнение к общему заголовку группы.

<Example name="fieldset/field" />

### Checkbox

Используйте заголовок fieldset, чтобы задать общее имя группе связанных флажков. Добавляйте
`CheckboxHiddenInput` в каждый флажок, которому нужны нативный фокус, отправка и сброс формы.

<Example name="fieldset/checkbox" />

### Input с Select

Объедините `Select` с кодом страны и `Input` для номера телефона под одним заголовком, если вместе они составляют один номер.

<Example name="fieldset/input-with-select" />

### Отключённое состояние

Установите `disabled` у корневого компонента. Браузер отключит нативные элементы управления, а совместимые с Ark компоненты
получат это состояние из контекста `fieldset`.

<Example name="fieldset/disabled" />

### Недопустимое состояние

Установите `invalid` у `Fieldset`, чтобы пометить всю группу как невалидную и показать общее сообщение об ошибке. Установите
`invalid` также у вложенных компонентов `Field`, если отдельным элементам управления нужны собственные невалидные стили и
ARIA-состояние.

<Example name="fieldset/invalid" />

### Root Provider

Создайте состояние fieldset вне JSX-дерева с помощью `useFieldset` и передайте его в `FieldsetRootProvider`, если им должны
пользоваться соседние элементы управления или повторно используемые компоненты. Подробнее в разделе [Выносите состояние за пределы дерева](/docs/composition-patterns#root-provider).

## Композиция

Оставьте внутри корневого компонента один видимый `FieldsetLegend`, а связанные элементы управления и их части `Field`
разместите в той же композиции. Установите `invalid` у корня для общей ошибки и у вложенных `Field`, если отдельным
элементам управления нужно собственное состояние валидации. Отключённый fieldset передаёт состояние нативным элементам
управления и совместимым с Ark дочерним компонентам.

Используйте `useFieldset` из соответствующего пакета (`@moduix/react` или `@moduix/solid`) вместе с
`FieldsetRootProvider`, если состояние нужно создать вне дерева или разделить с соседними элементами управления.
Для чтения состояния в дочернем компоненте используйте `FieldsetContext` или `useFieldsetContext()`. Не размещайте
`Fieldset` вместе с `FieldsetRootProvider` для одного хранилища. Чтобы заменить HTML-элемент части, используйте
`asChild` с одним семантическим дочерним элементом.

## Стилизация

Корень сбрасывает рамку, внешние и внутренние отступы, которые браузер задаёт `fieldset`, и занимает всю
ширину контейнера. Отключённый `Fieldset` приглушает всю группу один раз: `Field` и `Input` внутри него
не приглушаются повторно. `invalid` не рисует рамку вокруг группы: покажите ошибку через
`FieldsetErrorText` и отметьте нужные элементы управления через их собственный `Field`.

Используйте `className` в React или `class` в Solid, Vue и Svelte на экспортируемых частях. Варианты на Tailwind
используют нативные утилиты и классы потребителя. Варианты на CSS Modules построены на токенах foundation
и не имеют переменных компонента: класс на части перекрывает стили компонента из слоя.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `Fieldset` | `fieldset-root` |
| `FieldsetRootProvider` | `fieldset-root-provider` |
| `FieldsetLegend` | `fieldset-legend` |
| `FieldsetHelperText` | `fieldset-helper-text` |
| `FieldsetErrorText` | `fieldset-error-text` |

Для каждой части DOM Ark добавляет атрибуты `data-scope="fieldset"` и `data-part`, соответствующие анатомии. Корневой
компонент и заголовок получают `data-disabled` и `data-invalid`; moduix также добавляет атрибуты `data-slot="fieldset-*"`.

## Справочник API

| Проп | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `invalid` | `boolean` | `false` | Помечает группу невалидной и показывает `FieldsetErrorText`. |
| `disabled` | `boolean` | `false` | Отключает все элементы управления в группе. |
| `asChild` | `boolean` | `false` | Отрисовывает корень через единственный дочерний элемент. |
