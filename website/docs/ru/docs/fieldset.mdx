## Выбор подходящего компонента

Используйте `Fieldset`, когда несколько связанных элементов управления нужно объединить в одну группу с общим
заголовком, например для контактных данных или настроек уведомлений. `Field` подходит, когда у одного элемента
управления должны быть собственные метка, поясняющий текст и сообщение об ошибке.

## Анатомия

```text
Fieldset.Root | Fieldset.RootProvider
├─ Fieldset.Legend
├─ grouped controls
├─ Fieldset.HelperText (optional)
└─ Fieldset.ErrorText (optional)
```

| Часть                        | Назначение                                                                                         |
| ---------------------------- | -------------------------------------------------------------------------------------------------- |
| `Fieldset` / `Fieldset.Root` | Создаёт состояние и добавляет в DOM нативный элемент `fieldset`.                                  |
| `Fieldset.RootProvider`      | Добавляет в DOM нативный `fieldset` с состоянием, созданным через `useFieldset`.                   |
| `Fieldset.Context`           | Даёт дочерним компонентам доступ к состоянию группы и не добавляет отдельный элемент в DOM.       |
| `Fieldset.Legend`            | Нативный `legend`, задающий доступное имя группы.                                                  |
| `Fieldset.HelperText`        | Поясняющий текст, связанный с корнем через `aria-describedby`.                                     |
| `Fieldset.ErrorText`         | Сообщение об ошибке, объявляемое через `aria-live="polite"`; выводится только когда `invalid` равно `true`. |

## Композиция

Оставьте внутри корневого компонента один видимый `Fieldset.Legend`, а связанные элементы управления и их части `Field`
разместите в той же композиции. Установите `invalid` у корня для общей ошибки и у вложенных `Field`, если отдельным
элементам управления нужно собственное состояние валидации. Отключённый fieldset передаёт состояние нативным элементам
управления и совместимым с Ark дочерним компонентам.

Используйте `useFieldset` из соответствующего пакета (`@moduix/react` или `@moduix/solid`) вместе с
`Fieldset.RootProvider`, если состояние нужно создать вне дерева или разделить с соседними элементами управления.
Для чтения состояния в дочернем компоненте используйте `Fieldset.Context` или `useFieldsetContext()`. Не размещайте
`Fieldset.Root` вместе с `Fieldset.RootProvider` для одного хранилища. Чтобы заменить HTML-элемент части, используйте
`asChild` с одним семантическим дочерним элементом.

### Хуки стилизации

Для каждой части DOM Ark добавляет атрибуты `data-scope="fieldset"` и `data-part`, соответствующие анатомии. Корневой
компонент и заголовок получают `data-disabled` и `data-invalid`; moduix также добавляет атрибуты `data-slot="fieldset-*"`.
Используйте `className` в React или `class` в Solid для локальных переопределений. В пакетах CSS Modules переменные
`--moduix-fieldset-*` позволяют настраивать тему, а в Tailwind-пакетах для этого используются классы-утилиты и классы
потребителя.
