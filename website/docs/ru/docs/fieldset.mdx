## Выбор подходящего компонента

Используйте `Fieldset`, когда несколько связанных элементов управления нужно объединить в одну группу с общим
заголовком, например для контактных данных или настроек уведомлений. `Field` подходит, когда у одного элемента
управления должны быть собственные метка, поясняющий текст и сообщение об ошибке.

## Базовый пример

Создайте группу из `Fieldset`, `Fieldset.Legend`, связанных элементов управления и, если нужно, поясняющего текста или
сообщения об ошибке. Короткая запись `<Fieldset>` равнозначна `<Fieldset.Root>`. Форма с `.Root` остаётся доступной для
совместимости с API Ark.

## Анатомия

```text
Fieldset.Root | Fieldset.RootProvider
├─ Fieldset.Legend
├─ grouped controls
├─ Fieldset.HelperText (optional)
└─ Fieldset.ErrorText (optional)
```

| Часть                        | Назначение                                                                                         |
| ---------------------------- | -------------------------------------------------------------------------------------------------- |
| `Fieldset` / `Fieldset.Root` | Создаёт состояние и добавляет в DOM нативный элемент `fieldset`.                                  |
| `Fieldset.RootProvider`      | Добавляет в DOM нативный `fieldset` с состоянием, созданным через `useFieldset`.                   |
| `Fieldset.Context`           | Даёт дочерним компонентам доступ к состоянию группы и не добавляет отдельный элемент в DOM.       |
| `Fieldset.Legend`            | Нативный `legend`, задающий доступное имя группы.                                                  |
| `Fieldset.HelperText`        | Поясняющий текст, связанный с корнем через `aria-describedby`.                                     |
| `Fieldset.ErrorText`         | Сообщение об ошибке, объявляемое через `aria-live="polite"`; выводится только когда `invalid` равно `true`. |

## Композиция

### Рекомендуемая композиция

Оставьте внутри корневого компонента ровно один видимый `Fieldset.Legend`, желательно перед элементами управления.
Передавайте `disabled`, `invalid` и `id` непосредственно корневому компоненту. Ark использует `legend` как доступное
имя группы, а поясняющий текст и активное сообщение об ошибке связывает с `fieldset` через `aria-describedby`.

`Fieldset.Root`, `Fieldset.RootProvider`, `Fieldset.Legend`, `Fieldset.HelperText` и `Fieldset.ErrorText` передают `ref`
своим DOM-элементам. Используйте `asChild` с одним семантическим дочерним элементом, если нужно заменить HTML-элемент,
который выводит отдельная часть компонента.

### Когда нужна собственная композиция

Используйте `useFieldset` из `@moduix/react` вместе с `Fieldset.RootProvider`, когда состояние нужно создать вне JSX-дерева
или передать соседним элементам управления и повторно используемым дочерним компонентам. Вызовите `useFieldsetContext()`
или передайте render-функцию в `Fieldset.Context` в дочернем компоненте, которому нужен доступ к этому состоянию. Не размещайте `Fieldset.Root` вместе
с `Fieldset.RootProvider` для одного экземпляра состояния.

### Свойства по умолчанию

| Часть             | Свойство  | По умолчанию |
| ----------------- | --------- | ------------ |
| `Fieldset.Root`   | `disabled` | `false`     |
| `Fieldset.Root`   | `invalid`  | `false`     |

### Особенности поведения

- `Fieldset.Legend` выводит нативный `legend`, а не дополнительную обёртку.
- Браузер отключает нативные элементы управления внутри `fieldset` с `disabled`.
- Вложенные в `fieldset` компоненты Ark `Field` наследуют состояние `disabled`. Устанавливайте `invalid` на компонентах
  `Field`, когда отдельным элементам управления также нужны невалидное состояние и соответствующие ARIA-атрибуты.
- `Fieldset.ErrorText` не добавляется в DOM, пока `invalid` не станет равным `true`.
- Длинные заголовки, поясняющий текст и сообщения об ошибках переносятся внутри `fieldset` и не выходят за его границы.
- `useFieldsetContext()` и `Fieldset.Context` предоставляют дочерним компонентам то же состояние Ark, что и `useFieldset`.
- Fieldset сам по себе не хранит значение, не управляет навигацией с клавиатуры или функциями обратного вызова и не добавляет собственный `HiddenInput`.
- Устаревший проп `render` и плоские экспорты, такие как `FieldsetLegend`, не поддерживаются. Используйте `asChild`
  и части из пространства имён.

### Хуки стилизации

Для каждой части DOM Ark добавляет атрибуты `data-scope="fieldset"` и `data-part`, соответствующие анатомии. Корневой
компонент и заголовок получают `data-disabled` и `data-invalid`; moduix также добавляет атрибуты `data-slot="fieldset-*"`.
Используйте `className` для локальных переопределений, а переменные `--moduix-fieldset-*` для настройки темы, например
отступов вокруг заголовка и границ корневого компонента.
