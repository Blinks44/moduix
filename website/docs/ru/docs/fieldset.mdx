## Выбор подходящего компонента

Используйте `Fieldset`, когда несколько связанных элементов формы образуют одну группу и должны иметь общий заголовок,
например контактные данные или настройки уведомлений. `Field` подходит для одного элемента управления, которому нужны
метка, описание и сообщение об ошибке.

## Базовый пример

Создайте группу с помощью `Fieldset`, `Fieldset.Legend`, связанных элементов управления и, при необходимости, поясняющего
текста или сообщения об ошибке. Короткая запись `<Fieldset>` равнозначна `<Fieldset.Root>`, который также доступен для
совместимости с API Ark.

## Анатомия

```text
Fieldset.Root | Fieldset.RootProvider
├─ Fieldset.Legend
├─ grouped controls
├─ Fieldset.HelperText (optional)
└─ Fieldset.ErrorText (optional)
```

| Часть                        | Назначение                                                                                         |
| ---------------------------- | -------------------------------------------------------------------------------------------------- |
| `Fieldset` / `Fieldset.Root` | Создаёт состояние и добавляет в DOM нативный элемент `fieldset`.                                  |
| `Fieldset.RootProvider`      | Добавляет в DOM нативный `fieldset` с состоянием, созданным через `useFieldset`.                   |
| `Fieldset.Legend`            | Нативный `legend`, задающий имя группы для вспомогательных технологий.                            |
| `Fieldset.HelperText`        | Поясняющий текст, связанный с корнем через `aria-describedby`.                                     |
| `Fieldset.ErrorText`         | Сообщение об ошибке, которое объявляется без прерывания текущего действия и появляется, когда `invalid` равно `true`. |

## Композиция

### Рекомендуемая композиция

Оставьте внутри корневого компонента один видимый `Fieldset.Legend`, желательно перед элементами управления. Передавайте
`disabled`, `invalid` и `id` непосредственно корневому компоненту. Ark связывает с fieldset заголовок, поясняющий текст,
если он есть, и текущее сообщение об ошибке.

`Fieldset.Root`, `Fieldset.RootProvider`, `Fieldset.Legend`, `Fieldset.HelperText` и `Fieldset.ErrorText` передают ref
своим DOM-элементам. Используйте `asChild` с одним семантическим дочерним элементом, если нужно заменить HTML-элемент,
который выводит часть компонента.

### Когда нужна собственная композиция

Используйте `useFieldset` из `@moduix/react` вместе с `Fieldset.RootProvider`, когда состояние нужно создать вне JSX-дерева
или разделить с соседними элементами управления и повторно используемыми компонентами. Используйте `useFieldsetContext()`
или `Fieldset.Context` в дочернем компоненте, которому нужно прочитать это состояние. Не используйте `Fieldset.Root` вместе
с `Fieldset.RootProvider` для одного экземпляра состояния.

### Свойства по умолчанию

| Часть             | Свойство  | По умолчанию |
| ----------------- | --------- | ------------ |
| `Fieldset.Root`   | `disabled` | `false`     |
| `Fieldset.Root`   | `invalid`  | `false`     |

### Особенности поведения

- `Fieldset.Legend` выводит нативный `legend`, а не дополнительную обёртку.
- Браузер отключает нативные элементы управления внутри отключённого fieldset.
- Вложенные в fieldset компоненты Ark `Field` наследуют состояние `disabled`. Устанавливайте `invalid` на компонентах
  `Field`, когда отдельным элементам управления также нужны невалидное состояние и соответствующие ARIA-атрибуты.
- `Fieldset.ErrorText` не добавляется в DOM, пока `invalid` не станет равным `true`.
- Длинные заголовки, поясняющий текст и сообщения об ошибках переносятся внутри fieldset и не выходят за его границы.
- `useFieldsetContext()` и `Fieldset.Context` предоставляют дочерним компонентам то же состояние Ark, что и `useFieldset`.
- Fieldset не управляет значением, навигацией с клавиатуры, callback-функциями или собственным `HiddenInput`.
- Устаревший проп `render` и плоские экспорты, такие как `FieldsetLegend`, не поддерживаются. Используйте `asChild`
  и части из пространства имён.

### Хуки стилизации

Каждая часть DOM получает атрибуты Ark `data-scope="fieldset"` и `data-part`, соответствующие анатомии. Корневой компонент и
заголовок получают `data-disabled` и `data-invalid`; moduix также добавляет атрибуты `data-slot="fieldset-*"`.
Используйте `className` для локальных изменений, а переменные `--moduix-fieldset-*` для настройки темы, особенно токенов
отступа заголовка и границы корневого компонента.
