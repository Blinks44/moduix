## Справочник API

Компонент `Input` основан на стилизованном [`Field.Input` из Ark UI](https://ark-ui.com/docs/components/field). Он следует рекомендациям Ark по [композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и [передаче ref](https://ark-ui.com/docs/guides/ref). Компонент отрисовывает нативный однострочный `<input>` и сохраняет стандартное поведение браузера в формах и API событий React.

Используйте `Field`, если полю нужны метка, поясняющий текст или сообщение об ошибке, автоматически
созданные идентификаторы или общее состояние.

## Выбор подходящего компонента

- Используйте **`Input`** для обычного однострочного поля ввода.
- Используйте **`InputGroup`**, если к полю нужно добавить префикс, суффикс, дополнительный текст или действие в одной строке.
- Используйте **`PasswordInput`** для поля пароля с переключателем видимости.
- Используйте **`NumberInput`**, если нужен числовой ввод с изменением значения по шагам и соответствующими кнопками.
- Используйте **`Textarea`** для многострочного текста.
- Используйте **`Editable`**, если значение сначала должно отображаться как текст, а затем переходить в режим редактирования.

## Базовый пример

## Анатомия

```text
Field (необязательная оболочка)
└─ Input / Input.Root
```

| Часть                   | Назначение                                                                  |
| ----------------------- | --------------------------------------------------------------------------- |
| `Input` / `Input.Root` | Стилизованная версия `Field.Input` из Ark UI, которая отрисовывает нативный однострочный `<input>`. |

`Input.Root` и `Input` ссылаются на один и тот же компонент и отрисовывают одинаковый элемент
управления.

## Композиция

### Рекомендуемая композиция

Используйте `Input` внутри `Field`, если полю нужны доступная метка, пояснение, сообщение об
ошибке, автоматически созданные идентификаторы или общее состояние `disabled`, `invalid`,
`required` или `readOnly`. `Fieldset` может отключить сразу несколько вложенных полей.

Передавайте в `Input` нативные свойства `<input>` и обработчики событий. В управляемом поле
передавайте `value` и обновляйте его в `onChange(event)`, а в неуправляемом используйте
`defaultValue`.

### Когда нужна собственная композиция

Используйте `asChild` только тогда, когда другой элемент, совместимый с полем ввода, должен стать
фактическим DOM-узлом. Передавайте ровно один семантически корректный дочерний элемент, на который
можно поставить фокус. Ark
объединит в нём свойства компонента и `Field`, класс и `ref`.

Если элемент нельзя использовать как `<input>`, выберите компонент с подходящим примитивом Ark, а
не пытайтесь передать его через `Input`.

### Свойства по умолчанию

| Свойство   | По умолчанию | Примечания                                                                |
| ---------- | ------------ | ------------------------------------------------------------------------- |
| `size`     | `md`         | Визуальный размер: `xs`, `sm`, `md`, `lg` или `xl`.                      |
| `htmlSize` | Не задано    | Задаёт значение нативного `input[size]` в символах. По умолчанию ширина поля рассчитывается по этому значению. |
| `asChild`  | `false`      | При включении передаёт свойства одному семантическому дочернему элементу через Ark Slot.      |

### Особенности поведения

- `ref` указывает на настоящий `HTMLInputElement`, поэтому библиотека форм может перевести поле в
  фокус после неудачной отправки формы.
- `HiddenInput` не нужен: `Input` уже является нативным элементом управления формы.
- Ark `Field` предоставляет `aria-describedby`, `aria-invalid`, идентификаторы и свойства состояния.
- `Input` не хранит значение и не управляет его валидностью, фокусом или навигацией с клавиатуры.

контекста `Field` идентификаторы не создаются автоматически, а поясняющий текст и сообщение об
ошибке не связываются с полем.

### Хуки стилизации

- `data-slot="input-root"`
- `data-size="xs" | "sm" | "md" | "lg" | "xl"`
- `data-scope="field"` и `data-part="input"`
- `data-invalid`, `data-required` и `data-readonly` Ark внутри `Field`
- нативные `:disabled`, `:read-only`, `:focus-visible` и `[aria-invalid="true"]`
