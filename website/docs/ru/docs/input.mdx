## Справочник API

Компонент `Input` основан на стилизованном [`FieldInput` из Ark UI](https://ark-ui.com/docs/components/field). Он следует рекомендациям Ark по [композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и [передаче ref](https://ark-ui.com/docs/guides/ref). Компонент отрисовывает нативный однострочный `<input>` и сохраняет стандартное поведение браузера в формах и нативный API событий каждого фреймворка.

Используйте `Field`, если полю нужны метка, поясняющий текст или сообщение об ошибке, автоматически
созданные идентификаторы или общее состояние.

## Выбор подходящего компонента

- Используйте **`Input`** для обычного однострочного поля ввода.
- Используйте **`InputGroup`**, если к полю нужно добавить префикс, суффикс, дополнительный текст или действие в одной строке.
- Используйте **`PasswordInput`** для поля пароля с переключателем видимости.
- Используйте **`NumberInput`**, если нужен числовой ввод с изменением значения по шагам и соответствующими кнопками.
- Используйте **`Textarea`** для многострочного текста.
- Используйте **`Editable`**, если значение сначала должно отображаться как текст, а затем переходить в режим редактирования.

## Анатомия

```text
Field (необязательная оболочка)
└─ Input
```

| Часть                   | Назначение                                                                  |
| ----------------------- | --------------------------------------------------------------------------- |
| `Input`                 | Стилизованная версия `FieldInput` из Ark UI, которая отрисовывает нативный однострочный `<input>`. |

## Композиция

`Field` владеет меткой, поясняющим текстом или сообщением об ошибке, автоматически созданными
идентификаторами и общим состоянием `disabled`, `invalid`, `required` или `readOnly`. `Input` остаётся
нативным элементом: в управляемом поле React используйте `value` и `onChange(event)`, а в Vue
используйте `v-model`. Для неуправляемого поля в React задайте `defaultValue`. Компонент не управляет валидацией, фокусом
или навигацией с клавиатуры.

Во Vue задавайте начальное значение через `v-model` и сбрасывайте связанное состояние в обработчике
сброса формы: нативный сброс не вызывает событие ввода. Сейчас Ark очищает нативный `defaultValue`,
если модель не задана, поэтому до исправления используйте `v-model` для начальных значений.

Для автономного поля задайте доступное имя самостоятельно. Используйте `asChild` только с одним
фокусируемым элементом, совместимым с полем ввода: Ark объединит в этом DOM-узле свойства `Input` и
`Field`, класс и `ref`.

## Стилизация

`Input size="md"` и `FieldInput` имеют одинаковое оформление по умолчанию. Оба получают контекст
`Field`; `Input` добавляет визуальные размеры и `htmlSize`, а `FieldInput` сохраняет нативный
числовой `size`. Внутри отключённого moduix `Field` или `FieldRootProvider` прозрачность
применяется один раз, на корневом элементе.

Используйте `className` в React и `class` в Solid и Vue, чтобы стилизовать `Input`. Варианты с CSS Modules
поддерживают переменные ниже, а варианты на Tailwind используют нативные utility-классы и классы
потребителя. Для стилей состояний используйте общие data-атрибуты и нативные селекторы состояния.

### Хуки стилизации

- `data-slot="input-root"`
- `data-size="xs" | "sm" | "md" | "lg" | "xl"`
- `data-scope="field"` и `data-part="input"`
- `data-invalid`, `data-required` и `data-readonly` Ark внутри `Field`
- нативные `:disabled`, `:read-only`, `:focus-visible` и `[aria-invalid="true"]`
