## Справочник API

`Input` представляет собой стилизованный компонент на основе [Ark Field.Input](https://ark-ui.com/docs/components/field). Он следует рекомендациям Ark по [композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и работе с [ref](https://ark-ui.com/docs/guides/ref). Компонент отрисовывает нативный однострочный `<input>`, сохраняя поведение браузера в формах и стандартные события React.

Используйте `Field`, если полю нужны метка, поясняющий текст или текст ошибки, автоматически созданные идентификаторы либо общее состояние.

## Выбор подходящего компонента

- Используйте **`Input`** для обычного однострочного поля ввода.
- Используйте **`InputGroup`**, если к полю нужно добавить префикс, суффикс, текст или действие в одной строке.
- Используйте **`PasswordInput`** для поля пароля с переключателем видимости.
- Используйте **`NumberInput`**, если нужен числовой ввод с изменением значения по шагам.
- Используйте **`Textarea`** для многострочного текста.
- Используйте **`Editable`**, если значение сначала должно отображаться как текст, а затем переходить в режим редактирования.

## Базовое использование

Поместите `Input` в `Field`, если полю нужны метка, пояснение или сообщение об ошибке. `Field` связывает эти элементы с полем и предоставляет его идентификаторы и состояние.

## Композиция

### Рекомендуемая композиция

Используйте `Input` внутри `Field`, чтобы связать поле с меткой, пояснением или текстом ошибки,
получить идентификаторы и задать общее состояние `disabled`, `invalid`, `required` или `readOnly`.
`Fieldset` может отключить сразу несколько вложенных полей.

Передавайте в `Input` нативные свойства и события поля. В управляемом поле передавайте `value` и
обновляйте его в `onChange(event)`, а в неуправляемом задавайте `defaultValue`.

### Когда нужна собственная композиция

Используйте `asChild` только тогда, когда другой элемент, совместимый с полем ввода, должен стать
фактическим DOM-узлом. Передавайте ровно один семантический фокусируемый дочерний элемент. Ark
объединит в нём свойства компонента и поля, класс и ref.

Если элемент несовместим с полем ввода, используйте компонент с подходящим примитивом Ark, а не
пытайтесь передать его через `Input`.

### Свойства по умолчанию

| Свойство   | По умолчанию | Примечания                                                                |
| ---------- | ------------ | ------------------------------------------------------------------------- |
| `size`     | `md`         | Визуальный размер: `xs`, `sm`, `md`, `lg` или `xl`.                      |
| `htmlSize` | Не задано    | Задаёт значение нативного `input[size]` в символах. По умолчанию ширина поля соответствует этому значению. |
| `asChild`  | `false`      | При значении `true` передаёт свойства одному семантическому дочернему элементу через Ark Slot.      |

### Особенности поведения

- `ref` указывает на настоящий `HTMLInputElement`.
- `HiddenInput` не нужен, поскольку `Input` - нативный элемент управления формы.
- Ark `Field` предоставляет `aria-describedby`, `aria-invalid`, идентификаторы и свойства состояния.
- `Input` не хранит значение и не управляет валидностью, фокусом или навигацией с клавиатуры.

`Field` необязателен. Если `Input` используется отдельно, явно задайте доступное имя с помощью
метки, `aria-label` или `aria-labelledby`. Нативные свойства по-прежнему работают, но без
контекста `Field` идентификаторы не создаются автоматически и поясняющий текст с текстом ошибки

### Хуки стилизации

- `data-slot="input-root"`
- `data-size="xs" | "sm" | "md" | "lg" | "xl"`
- `data-scope="field"` и `data-part="input"`
- `data-invalid`, `data-required` и `data-readonly` Ark внутри `Field`
- нативные `:disabled`, `:read-only`, `:focus-visible` и `[aria-invalid="true"]`
