## Использование

<Usage />

Явно соберите части Ark UI. `FloatingPanelPositioner` применяет рассчитанные Ark значения позиции
и размера, а `FloatingPanelContent` представляет видимую поверхность окна. Заголовок становится
областью перетаскивания, а `FloatingPanelResizeTriggerGroup` добавляет ручки изменения размера по краям панели.

React, Solid и Vue используют одинаковые плоские имена компонентов. В Vue части компонента
соединяются через слоты, а для управляемых состояний открытия, позиции или размера используется `v-model`.

## Выбор подходящего компонента

Используйте `FloatingPanel` для плавающего немодального рабочего окна, например инспектора, панели
свойств или служебного окна. Для компактного содержимого, привязанного к триггеру, используйте
`Popover`, для модальных задач `Dialog`, а для панели у края окна с жестами или точками привязки `Drawer`.

## Композиция

Используйте `FloatingPanel` для локального состояния. Оставьте `FloatingPanelPositioner` и `FloatingPanelContent` явными,
оберните заголовок в `FloatingPanelDragTrigger` и добавьте `FloatingPanelTitle` для доступного имени. `FloatingPanelPositioner` по умолчанию
выводится через портал. Установите `portalled={false}` или передайте `portalRef`, если панель должна
находиться в другом контейнере.

Если состояние должно находиться за пределами дерева панели, создайте его через
`useFloatingPanel()` и передайте в `FloatingPanelRootProvider`. Не используйте `FloatingPanel` и
`FloatingPanelRootProvider` для одного экземпляра состояния. `position` и `size` управляются независимо. Используйте
`FloatingPanelResizeTriggerGroup axes` или отдельные `FloatingPanelResizeTrigger`, только если стандартный набор ручек не подходит.
Для `asChild` передавайте один семантически подходящий дочерний элемент. В Vue поместите дочерний элемент
в слот, а в Solid передайте функцию рендера.

`FloatingPanelDragIndicator`, `FloatingPanelCloseIcon`, `FloatingPanelFooter` и
`FloatingPanelResizeTriggerGroup` являются вспомогательными частями moduix. Они дополняют
структурные части Ark UI, но не заменяют их.

## Стилизация

`FloatingPanelTrigger` не стилизован: оборачивайте `Button` через `asChild`. Размер панели берётся из
состояния Ark, поэтому задавайте `defaultSize`, `minSize` и `maxSize` на корне, а не CSS-размеры на
`FloatingPanelContent`. Анимация содержимого читает общие переменные `--moduix-popup-motion-*`.

Используйте `className` в React или `class` в Solid и Vue на экспортируемых частях. Варианты на Tailwind
используют нативные утилиты и классы потребителя. Варианты на CSS Modules построены на токенах foundation
и не имеют переменных компонента: класс на части перекрывает стили компонента из слоя.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `FloatingPanelTrigger` | `floating-panel-trigger` |
| `FloatingPanelPositioner` | `floating-panel-positioner` |
| `FloatingPanelContent` | `floating-panel-content` |
| `FloatingPanelDragTrigger` | `floating-panel-drag-trigger` |
| `FloatingPanelHeader` | `floating-panel-header` |
| `FloatingPanelTitle` | `floating-panel-title` |
| `FloatingPanelControl` | `floating-panel-control` |
| `FloatingPanelStageTrigger` | `floating-panel-stage-trigger` |
| `FloatingPanelCloseTrigger` | `floating-panel-close-trigger` |
| `FloatingPanelCloseIcon` | `floating-panel-close-icon` |
| `FloatingPanelBody` | `floating-panel-body` |
| `FloatingPanelFooter` | `floating-panel-footer` |
| `FloatingPanelResizeTrigger` | `floating-panel-resize-trigger` |
| `FloatingPanelDragIndicator` | `floating-panel-drag-indicator` |

Части Ark UI сохраняют `data-scope="floating-panel"` и значения `data-part`. moduix добавляет
`data-slot="floating-panel-*"` к отрисованным обёрткам. Используйте `data-state="open|closed"`,
`data-dragging`, `data-disabled`, `data-stage`, `data-topmost`, `data-behind`, `data-minimized`,
`data-maximized`, `data-staged` и `data-axis` для стилизации состояния соответствующих частей. `FloatingPanelFooter` повторяет `data-minimized` содержимого.

`FloatingPanelPositioner` предоставляет переменные Ark `--width`, `--height`, `--x`, `--y` и `--z-index`.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `Enter` / `Space` | Открывает с кнопки в фокусе. |
| `Esc` | Закрывает панель. |

## Справочник API

| Проп | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `open` | `boolean` | — | Состояние открытия в управляемом режиме. |
| `defaultOpen` | `boolean` | `false` | Начальное состояние открытия, если оно не управляется извне. |
| `onOpenChange` | `(details: OpenChangeDetails) => void` | — | Вызывается при открытии и закрытии. |
| `size` | `{ width: number; height: number }` | — | Размер панели в управляемом режиме. |
| `defaultSize` | `{ width: number; height: number }` | — | Начальный размер панели. |
| `minSize` | `{ width: number; height: number }` | — | Минимальный размер при изменении. |
| `maxSize` | `{ width: number; height: number }` | — | Максимальный размер при изменении. |
| `position` | `{ x: number; y: number }` | — | Положение панели в управляемом режиме. |
| `defaultPosition` | `{ x: number; y: number }` | — | Начальное положение панели. |
| `getAnchorPosition` | `(details: AnchorPositionDetails) => Point` | — | Возвращает, где открывается панель, например рядом с триггером. |
| `draggable` | `boolean` | `true` | Разрешает перемещать панель. |
| `resizable` | `boolean` | `true` | Разрешает менять размер панели. |
| `lockAspectRatio` | `boolean` | `false` | Сохраняет пропорции при изменении размера. |
| `getBoundaryEl` | `() => HTMLElement \| null` | — | Возвращает элемент, за пределы которого панель не выходит. |
| `closeOnEscape` | `boolean` | `true` | Закрывается по Escape. |
| `persistRect` | `boolean` | `true` | Сохраняет размер и положение после закрытия. |
| `gridSize` | `number` | `1` | Шаг сетки в пикселях при перемещении и изменении размера. |
| `lazyMount` | `boolean` | `true` | Монтирует содержимое при первом открытии. |
| `unmountOnExit` | `boolean` | `true` | Удаляет содержимое после закрытия. |
| `translations` | `IntlTranslations` | — | Переведённые строки для подписей доступности. |
| `strategy` | `'absolute' \| 'fixed'` | `'fixed'` | CSS-позиционирование: `fixed` или `absolute`. |
| `allowOverflow` | `boolean` | `true` | Разрешает частично вытаскивать панель за границу. |
| `initialFocusEl` | `() => HTMLElement \| null \| false` | — | Возвращает элемент, который получает фокус при открытии. |
| `finalFocusEl` | `() => HTMLElement \| null` | — | Возвращает элемент, который получает фокус при закрытии. |
| `restoreFocus` | `boolean` | `true` | Возвращает фокус на прежний элемент при закрытии. |
| `disabled` | `boolean` | — | Отключает элемент управления. |
| `onPositionChange` | `(details: PositionChangeDetails) => void` | — | Вызывается во время перетаскивания. |
| `onPositionChangeEnd` | `(details: PositionChangeDetails) => void` | — | Вызывается в конце перетаскивания. |
| `onSizeChange` | `(details: SizeChangeDetails) => void` | — | Вызывается во время изменения размера. |
| `onSizeChangeEnd` | `(details: SizeChangeDetails) => void` | — | Вызывается в конце изменения размера. |
| `onStageChange` | `(details: StageChangeDetails) => void` | — | Вызывается при сворачивании, разворачивании и восстановлении. |
