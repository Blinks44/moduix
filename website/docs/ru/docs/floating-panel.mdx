## Выбор подходящего компонента

Используйте `FloatingPanel` для плавающей немодальной рабочей области, например инспектора или панели инструментов.
`Popover` подходит для компактного содержимого, привязанного к триггеру, `Dialog` для модальных сценариев, а `Drawer`
для панелей, прикреплённых к краю экрана и поддерживающих жесты или точки привязки.

## Базовый пример

Явно соберите структуру Ark. `FloatingPanel.Positioner` управляет рассчитанными Ark значениями позиции и размера, а
`FloatingPanel.Content` представляет поверхность панели, которую можно перетаскивать и изменять в размере.

## Анатомия

```text
FloatingPanel / FloatingPanel.Root
├─ FloatingPanel.Trigger
└─ Overlay subtree (automatically portalled)
   └─ FloatingPanel.Positioner
      └─ FloatingPanel.Content
         ├─ FloatingPanel.DragTrigger
         │  └─ FloatingPanel.Header
         │     ├─ FloatingPanel.Title
         │     │  └─ FloatingPanel.DragIndicator (optional)
         │     └─ FloatingPanel.Control
         │        ├─ FloatingPanel.StageTrigger
         │        └─ FloatingPanel.CloseTrigger / CloseIcon
         ├─ FloatingPanel.Body
         ├─ FloatingPanel.Footer
         └─ FloatingPanel.ResizeTrigger / ResizeTriggerGroup
```

| Часть                                      | Назначение                                                                  |
| ------------------------------------------ | --------------------------------------------------------------------------- |
| `FloatingPanel` / `FloatingPanel.Root`     | Хранит состояние открытия, позиции, размера, перетаскивания, изменения размера и режима панели. |
| `FloatingPanel.Trigger`                    | Открывает панель или переключает её состояние.                              |
| `FloatingPanel.Positioner`                 | Применяет рассчитанные Ark значения позиции, размера, трансформации и z-index. |
| `FloatingPanel.Content`                    | Видимая область плавающего окна.                                            |
| `FloatingPanel.DragTrigger`                | Определяет область, за которую можно перетаскивать панель, обычно заголовок. |
| `FloatingPanel.Header`                     | Часть Ark для заголовка и рекомендуемая обёртка для ручки перетаскивания.    |
| `FloatingPanel.Title`                      | Задаёт доступное имя панели.                                                |
| `FloatingPanel.Control`                    | Объединяет элементы управления режимом панели и её закрытием.               |
| `FloatingPanel.StageTrigger`              | Переключает на `default`, `minimized` или `maximized`.                  |
| `FloatingPanel.CloseTrigger` / `CloseIcon` | Закрывает панель.                                                            |
| `FloatingPanel.Body`                       | Область с прокручиваемым содержимым.                                         |
| `FloatingPanel.Footer`                     | Необязательная нижняя область для вторичных действий или текста состояния.   |
| `FloatingPanel.ResizeTrigger`              | Ручка изменения размера по одной оси Ark.                                   |
| `FloatingPanel.ResizeTriggerGroup`         | Вспомогательная часть moduix для вывода всех или выбранных ручек изменения размера. |
| `FloatingPanel.RootProvider`               | Подключает части к состоянию, созданному с помощью `FloatingPanel.useFloatingPanel()`. |

`FloatingPanel.DragIndicator`, `FloatingPanel.CloseIcon`, `FloatingPanel.Footer` и
`FloatingPanel.ResizeTriggerGroup` являются вспомогательными частями moduix. Они дополняют
структурные части Ark, но не заменяют их.

## Композиция

Корневой компонент автоматически помещает `Positioner` в портал. Установите `portalled={false}`, чтобы отрисовать панель
в текущем месте, или используйте `portalRef`, чтобы выбрать пользовательский контейнер. Структурные части при этом
остаются явными, и их можно стилизовать отдельно.

### Рекомендуемая композиция

Используйте `FloatingPanel` для управления состоянием и поведением. Явно отрисуйте `Positioner` и `Content`, а затем
оберните заголовок в `DragTrigger`, чтобы перетаскивание начиналось из предсказуемой области.

Используйте `StageTrigger` с `stage="minimized"`, `stage="maximized"` и `stage="default"`, чтобы вывести встроенные
кнопки с иконками для сворачивания, разворачивания и восстановления панели. Ark скрывает кнопку восстановления, пока
панель не свёрнута или не развёрнута. Если для триггера или элемента управления задан `asChild`, передайте один
семантически подходящий дочерний элемент. Стандартные иконки moduix добавляются только при использовании стандартной кнопки Ark.

### Когда нужна собственная композиция

Применяйте `className` непосредственно к любой экспортируемой части. Используйте `asChild` ровно с одним семантическим
дочерним элементом для собственных триггеров открытия, закрытия или смены режима. Передайте `axes` в `ResizeTriggerGroup`,
чтобы вывести только нужные ручки, или используйте отдельные части `ResizeTrigger`, если для каждой оси нужны свои стили.

Используйте `FloatingPanel.Context` или `FloatingPanel.useFloatingPanelContext()` внутри дерева панели. Если состояние
создаётся за пределами этого дерева, создайте его через `FloatingPanel.useFloatingPanel()` и передайте в `RootProvider`.
Не используйте `Root` и `RootProvider` для одного экземпляра состояния.

### Свойства по умолчанию

По умолчанию содержимое панели монтируется только при первом открытии, а после анимации закрытия удаляется из DOM. Установите
`unmountOnExit={false}`, чтобы не удалять его после первого открытия. Задавайте оба свойства жизненного цикла как `false`
только когда панель нужно отрисовать сразу.

| Свойство                | По умолчанию | Примечания                                                                        |
| ----------------------- | ------------ | --------------------------------------------------------------------------------- |
| `closeOnEscape`         | `true`       | Закрывает сфокусированную панель, находящуюся поверх остальных; задайте `false`, чтобы отключить. |
| `persistRect`           | `true`       | Сохраняет последнюю позицию и размер во время анимации закрытия.                  |
| `draggable`             | Ark          | Передаётся в Ark без изменений; Ark по умолчанию задаёт `true`.                  |
| `resizable`             | Ark          | Передаётся в Ark без изменений; Ark по умолчанию задаёт `true`.                  |
| `strategy`              | Ark          | Передаётся в Ark без изменений; Ark по умолчанию использует фиксированное позиционирование. |
| Параметры монтирования | moduix       | `lazyMount` и `unmountOnExit` по умолчанию имеют значение `true`; остальные параметры передаются дальше. |

### Особенности поведения

- `onOpenChange(details)` передаёт значение `details.open`.
- `onPositionChange(details)` и `onPositionChangeEnd(details)` передают `details.position`.
- `onSizeChange(details)` и `onSizeChangeEnd(details)` передают `details.size`.
- `onStageChange(details)` передаёт объект `details` Ark с данными о режиме панели.
- `position` и `size` управляются независимо. Для неуправляемой инициализации используйте `defaultPosition` и `defaultSize`.
- `getAnchorPosition(details)` вычисляет начальную позицию на основе прямоугольника триггера.
- При нажатии Escape Ark обрабатывает событие в сфокусированном `Content` верхней панели. Используйте `autoFocus`, если
  панель должна получать фокус сразу после открытия.
- `ids`, `translations`, `getBoundaryEl`, `lockAspectRatio` и `gridSize` передаются в Ark без изменений.
- `Content` имеет `role="dialog"`. При фокусе клавиши со стрелками перемещают панель с шагом `gridSize` и учитывают `dir`.
  Для явной передачи фокуса используйте `initialFocusEl`, `finalFocusEl` и `restoreFocus`.
- Установите `persistRect` в `false`, если не нужно сохранять последнюю позицию и размер. По умолчанию используется `true`,
  чтобы анимация закрытия могла использовать эти значения.
- Панель немодальная: она не удерживает фокус и не блокирует взаимодействие за её пределами.

### Точки для стилизации

Части Ark сохраняют `data-scope="floating-panel"` и соответствующие значения `data-part`. moduix добавляет
`data-slot="floating-panel-*"` к обёрткам. Для стилизации по состоянию используйте
`data-state="open|closed"`, `data-dragging`, `data-disabled`, `data-stage`, `data-topmost`, `data-behind`, `data-minimized`,
`data-maximized`, `data-staged` и `data-axis`.

`Positioner` предоставляет `--width`, `--height`, `--x`, `--y`, `--reference-width`,
`--reference-height`, `--available-width`, `--available-height`, `--z-index` и `--transform-origin`.
Храните логику размеров и трансформации в переменных Ark, которые обновляются во время работы,
вместо того чтобы дублировать измерения в коде приложения.
