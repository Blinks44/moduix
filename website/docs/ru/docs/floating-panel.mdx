## Выбор подходящего компонента

Используйте `FloatingPanel` для плавающего немодального окна, например инспектора, панели свойств или служебного
окна. Для компактного содержимого, привязанного к триггеру, подходит `Popover`. `Dialog` используйте для модальных
задач, а `Drawer` - для панели, прикреплённой к краю окна и поддерживающей жесты или точки привязки.

## Базовый пример

Явно соберите части Ark UI. `FloatingPanel.Positioner` применяет рассчитанные Ark значения позиции и размера,
а `FloatingPanel.Content` представляет видимую поверхность окна. Заголовок становится областью перетаскивания,
а `ResizeTriggerGroup` добавляет ручки изменения размера по краям панели.

## Анатомия

```text
FloatingPanel / FloatingPanel.Root
├─ FloatingPanel.Trigger
└─ Дерево оверлея (автоматически помещается в портал)
   └─ FloatingPanel.Positioner
      └─ FloatingPanel.Content
         ├─ FloatingPanel.DragTrigger
         │  └─ FloatingPanel.Header
         │     ├─ FloatingPanel.Title
         │     │  └─ FloatingPanel.DragIndicator (необязательно)
         │     └─ FloatingPanel.Control
         │        ├─ FloatingPanel.StageTrigger
         │        └─ FloatingPanel.CloseTrigger / CloseIcon
         ├─ FloatingPanel.Body
         ├─ FloatingPanel.Footer
         └─ FloatingPanel.ResizeTrigger / ResizeTriggerGroup
```

| Часть                                      | Назначение                                                                    |
| ------------------------------------------ | ----------------------------------------------------------------------------- |
| `FloatingPanel` / `FloatingPanel.Root`     | Управляет состоянием открытия, позицией, размером, перетаскиванием и режимом окна. |
| `FloatingPanel.Trigger`                    | Открывает панель или переключает её состояние.                               |
| `FloatingPanel.Positioner`                 | Применяет рассчитанные Ark значения позиции, размера, трансформации и z-index. |
| `FloatingPanel.Content`                    | Видимая поверхность плавающего окна.                                         |
| `FloatingPanel.DragTrigger`                | Задаёт область, за которую можно перетаскивать панель, обычно заголовок.       |
| `FloatingPanel.Header`                     | Часть Ark для заголовка и рекомендуемая обёртка для области перетаскивания.    |
| `FloatingPanel.Title`                      | Задаёт доступное имя панели.                                                  |
| `FloatingPanel.Control`                    | Группирует кнопки смены режима и закрытия.                                    |
| `FloatingPanel.StageTrigger`               | Переключает режим `default`, `minimized` или `maximized`.                     |
| `FloatingPanel.CloseTrigger` / `CloseIcon` | Закрывает панель.                                                             |
| `FloatingPanel.Body`                       | Основная область содержимого с прокруткой.                                    |
| `FloatingPanel.Footer`                     | Необязательная нижняя область для вторичных действий или статуса.             |
| `FloatingPanel.ResizeTrigger`              | Ручка изменения размера для одной оси Ark.                                   |
| `FloatingPanel.ResizeTriggerGroup`         | Вспомогательная часть moduix, которая выводит все или выбранные ручки.         |
| `FloatingPanel.RootProvider`               | Подключает части к состоянию, созданному через `FloatingPanel.useFloatingPanel()`. |

`FloatingPanel.DragIndicator`, `FloatingPanel.CloseIcon`, `FloatingPanel.Footer` и
`FloatingPanel.ResizeTriggerGroup` - вспомогательные части moduix. Они дополняют структурные
части Ark, но не заменяют их.

## Композиция

`FloatingPanel` и `FloatingPanel.RootProvider` настраивают вывод `Positioner`. По умолчанию он помещается
в портал. Установите `portalled={false}`, чтобы вывести его в текущем дереве, или передайте `portalRef`, чтобы выбрать
другой контейнер. Структурные части остаются явными, и каждую из них можно стилизовать отдельно.

### Рекомендуемая композиция

Используйте `FloatingPanel` для управления состоянием и поведением. Оставьте `Positioner` и `Content` явными,
а `Header` оберните в `DragTrigger`, чтобы перетаскивание начиналось из понятной области. Добавьте
`FloatingPanel.Title`, чтобы задать окну доступное имя.

Используйте `StageTrigger` со значениями `stage="minimized"`, `stage="maximized"` и `stage="default"`, чтобы получить
стандартные кнопки сворачивания, разворачивания и восстановления панели. Ark показывает кнопку восстановления только
для свёрнутой или развёрнутой панели. Если для триггера или элемента управления задан `asChild`, передайте ровно один
семантически подходящий дочерний элемент. Стандартные иконки moduix добавляются только при рендеринге обычной кнопки Ark.

### Когда нужна собственная композиция

Применяйте `className` непосредственно к любой экспортируемой части. Используйте `asChild` с одним семантически
подходящим дочерним элементом, если нужно заменить триггер, кнопку закрытия, кнопку смены режима или другой элемент
другим компонентом. Передайте `axes` в `ResizeTriggerGroup`, чтобы вывести только нужные ручки, или используйте
отдельные части `ResizeTrigger`, если для каждой оси нужны свои расположение и стили.

Используйте `FloatingPanel.Context` или `FloatingPanel.useFloatingPanelContext()` внутри дерева панели. Если состояние
создаётся за пределами этого дерева, создайте его через `FloatingPanel.useFloatingPanel()` и передайте в `RootProvider`.
Не используйте `Root` и `RootProvider` для одного экземпляра состояния.

### Свойства по умолчанию

Корневой компонент moduix монтирует содержимое в портале только при первом открытии и удаляет его после анимации
закрытия. Установите `unmountOnExit={false}`, чтобы оставить содержимое смонтированным после первого открытия.
Устанавливайте оба параметра жизненного цикла в `false`, только если нужен первоначальный рендеринг без ожидания открытия.

| Свойство         | По умолчанию | Примечания                                                                    |
| ---------------- | ------------ | ----------------------------------------------------------------------------- |
| `allowOverflow`  | `true`       | Разрешает панели выходить за границы во время перетаскивания. Вместе с `getBoundaryEl` задайте `false`, чтобы ограничить панель. |
| `closeOnEscape`  | `true`       | Закрывает сфокусированную верхнюю панель при нажатии Escape.                 |
| `defaultOpen`    | `false`      | При первом рендеринге панель закрыта.                                         |
| `draggable`      | `true`       | Панель можно перетаскивать.                                                   |
| `gridSize`       | `1`          | Шаг перемещения стрелками и сетки привязки.                                   |
| `lazyMount`      | `true`       | moduix откладывает монтирование содержимого до первого открытия.             |
| `persistRect`    | `true`       | Сохраняет последнюю позицию и размер во время анимации закрытия.              |
| `resizable`      | `true`       | Размер панели можно изменять.                                                  |
| `strategy`       | `fixed`      | Ark позиционирует панель относительно окна просмотра.                         |
| `unmountOnExit`  | `true`       | Удаляет содержимое после анимации закрытия.                                    |

### Особенности поведения

- `onOpenChange(details)` передаёт новое состояние в `details.open`.
- `onPositionChange(details)` и `onPositionChangeEnd(details)` передают позицию в `details.position`.
- `onSizeChange(details)` и `onSizeChangeEnd(details)` передают размер в `details.size`.
- `onStageChange(details)` передаёт объект деталей Ark с новым режимом панели.
- `position` и `size` управляются независимо. Для неуправляемой инициализации используйте `defaultPosition` и `defaultSize`.
- `getAnchorPosition(details)` может вычислить начальную позицию по прямоугольнику триггера.
- У `Content` есть `role="dialog"`. Добавьте `Title` или задайте окну другое доступное имя.
- Используйте `autoFocus` на `Content`, если панель должна получать фокус сразу после открытия. Для явной передачи фокуса
  используйте `initialFocusEl`, `finalFocusEl` и `restoreFocus`.
- Когда `Content` получает фокус, клавиши со стрелками перемещают панель с шагом `gridSize` с учётом `dir`.
- `ids`, `translations`, `getBoundaryEl`, `lockAspectRatio` и `gridSize` передаются в Ark без изменений. Допустимые
  режимы панели: `default`, `minimized` и `maximized`.
- Ark обрабатывает Escape в сфокусированном `Content` верхней панели. Установите `closeOnEscape={false}`, чтобы отключить это поведение.
- Панель немодальная: она не удерживает фокус, не блокирует прокрутку и не мешает взаимодействию за её пределами.

### Хуки стилизации

Части Ark сохраняют `data-scope="floating-panel"` и значения `data-part`. moduix добавляет
`data-slot="floating-panel-*"` к отрисованным обёрткам. Для стилизации по состоянию используйте на соответствующих
частях `data-state="open|closed"`, `data-dragging`, `data-disabled`, `data-stage`, `data-topmost`, `data-behind`,
`data-minimized`, `data-maximized`, `data-staged` и `data-axis`.

`Positioner` предоставляет `--width`, `--height`, `--x`, `--y`, `--reference-width`, `--reference-height`,
`--available-width`, `--available-height`, `--z-index` и `--transform-origin`. Используйте переменные Ark, которые
обновляются во время работы, для размеров и трансформации вместо того, чтобы дублировать измерения в коде приложения.
