## Выбор подходящего компонента

Используйте `FloatingPanel` для плавающего немодального рабочего окна, например инспектора, панели
свойств или служебного окна. Для компактного содержимого, привязанного к триггеру, используйте
`Popover`, для модальных задач `Dialog`, а для панели у края окна с жестами или точками привязки `Drawer`.

## Базовый пример

FloatingPanel доступен для React и Solid в пакетах CSS Modules и Tailwind. Превью использует пакет
React CSS Modules, а вкладки выбора фреймворка показывают нативный исходный код для того же публичного
контракта.

Явно соберите части Ark UI. `FloatingPanel.Positioner` применяет рассчитанные Ark значения позиции
и размера, а `FloatingPanel.Content` представляет видимую поверхность окна. Заголовок становится
областью перетаскивания, а `ResizeTriggerGroup` добавляет ручки изменения размера по краям панели.

## Анатомия

```text
FloatingPanel / FloatingPanel.Root
├─ FloatingPanel.Trigger
└─ Дерево оверлея (автоматически помещается в портал)
   └─ FloatingPanel.Positioner
      └─ FloatingPanel.Content
         ├─ FloatingPanel.DragTrigger
         │  └─ FloatingPanel.Header
         │     ├─ FloatingPanel.Title
         │     │  └─ FloatingPanel.DragIndicator (необязательно)
         │     └─ FloatingPanel.Control
         │        ├─ FloatingPanel.StageTrigger
         │        └─ FloatingPanel.CloseTrigger / CloseIcon
         ├─ FloatingPanel.Body
         ├─ FloatingPanel.Footer
         └─ FloatingPanel.ResizeTrigger / ResizeTriggerGroup
```

| Часть                                      | Назначение                                                               |
| ------------------------------------------ | ------------------------------------------------------------------------ |
| `FloatingPanel` / `FloatingPanel.Root`     | Управляет состоянием открытия, позицией, размером, перетаскиванием и режимом окна. |
| `FloatingPanel.Trigger`                    | Открывает панель или переключает её состояние.                           |
| `FloatingPanel.Positioner`                 | Применяет рассчитанные Ark значения позиции, размера, трансформации и z-index. |
| `FloatingPanel.Content`                    | Видимая поверхность плавающего окна.                                    |
| `FloatingPanel.DragTrigger`                | Задаёт область, за которую можно перетаскивать панель, обычно заголовок.   |
| `FloatingPanel.Header`                     | Часть Ark для заголовка и обёртка области перетаскивания.                 |
| `FloatingPanel.Title`                      | Задаёт доступное имя панели.                                             |
| `FloatingPanel.Control`                    | Группирует кнопки смены режима и закрытия.                               |
| `FloatingPanel.StageTrigger`               | Переключает режимы `default`, `minimized` и `maximized`.                  |
| `FloatingPanel.CloseTrigger` / `CloseIcon` | Закрывает панель.                                                        |
| `FloatingPanel.Body`                       | Основная область содержимого с прокруткой.                               |
| `FloatingPanel.Footer`                     | Необязательная нижняя область для действий или статуса.                  |
| `FloatingPanel.ResizeTrigger`              | Ручка изменения размера для одной оси Ark.                              |
| `FloatingPanel.ResizeTriggerGroup`         | Выводит все или выбранные ручки изменения размера.                       |
| `FloatingPanel.RootProvider`               | Подключает части к состоянию из `FloatingPanel.useFloatingPanel()`.       |

`FloatingPanel.DragIndicator`, `FloatingPanel.CloseIcon`, `FloatingPanel.Footer` и
`FloatingPanel.ResizeTriggerGroup` являются вспомогательными частями moduix. Они дополняют
структурные части Ark UI, но не заменяют их.

## Композиция

Используйте `FloatingPanel` для локального состояния. Оставьте `Positioner` и `Content` явными,
оберните заголовок в `DragTrigger` и добавьте `Title` для доступного имени. `Positioner` по умолчанию
выводится через портал. Установите `portalled={false}` или передайте `portalRef`, если панель должна
находиться в другом контейнере.

Если состояние должно находиться за пределами дерева панели, создайте его через
`FloatingPanel.useFloatingPanel()` и передайте в `RootProvider`. Не используйте `FloatingPanel` и
`RootProvider` для одного экземпляра состояния. `position` и `size` управляются независимо. Используйте
`ResizeTriggerGroup axes` или отдельные `ResizeTrigger`, только если стандартный набор ручек не подходит.
Для `asChild` передавайте один семантически подходящий дочерний элемент; в Solid используется форма
с render-функцией.

### Точки стилизации

Части Ark UI сохраняют `data-scope="floating-panel"` и значения `data-part`. moduix добавляет
`data-slot="floating-panel-*"` к отрисованным обёрткам. Используйте `data-state="open|closed"`,
`data-dragging`, `data-disabled`, `data-stage`, `data-topmost`, `data-behind`, `data-minimized`,
`data-maximized`, `data-staged` и `data-axis` для стилизации состояния соответствующих частей.

`Positioner` предоставляет `--width`, `--height`, `--x`, `--y`, `--reference-width`,
`--reference-height`, `--available-width`, `--available-height`, `--z-index` и `--transform-origin`.
Для размеров и трансформаций используйте переменные Ark, обновляемые во время работы, а не дублируйте измерения
в коде приложения.
