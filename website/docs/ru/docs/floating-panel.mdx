## Выбор подходящего компонента

Используйте `FloatingPanel` для плавающего немодального рабочего окна, например инспектора, панели
свойств или служебного окна. Для компактного содержимого, привязанного к триггеру, используйте
`Popover`, для модальных задач `Dialog`, а для панели у края окна с жестами или точками привязки `Drawer`.

## Базовый пример


Явно соберите части Ark UI. `FloatingPanelPositioner` применяет рассчитанные Ark значения позиции
и размера, а `FloatingPanelContent` представляет видимую поверхность окна. Заголовок становится
областью перетаскивания, а `FloatingPanelResizeTriggerGroup` добавляет ручки изменения размера по краям панели.

React, Solid и Vue используют одинаковые плоские имена компонентов. В Vue части компонента
соединяются через слоты, а для управляемых состояний открытия, позиции или размера используется `v-model`.

├─ FloatingPanelTrigger
└─ Дерево оверлея (автоматически помещается в портал)

      └─ FloatingPanelContent

         │     │  └─ FloatingPanelDragIndicator (необязательно)
         │     └─ FloatingPanelControl
         │        ├─ FloatingPanelStageTrigger
         │        └─ FloatingPanelCloseTrigger / FloatingPanelCloseIcon
         ├─ FloatingPanelBody
         ├─ FloatingPanelFooter
         └─ FloatingPanelResizeTrigger / FloatingPanelResizeTriggerGroup

| Часть                                      | Назначение                                                               |
| ------------------------------------------ | ------------------------------------------------------------------------ |
| `FloatingPanel`                           | Управляет состоянием открытия, позицией, размером, перетаскиванием и режимом окна. |
| `FloatingPanelTrigger`                    | Открывает панель или переключает её состояние.                           |
| `FloatingPanelPositioner`                 | Применяет рассчитанные Ark значения позиции, размера, трансформации и z-index. |
| `FloatingPanelContent`                    | Видимая поверхность плавающего окна.                                    |
| `FloatingPanelDragTrigger`                | Задаёт область, за которую можно перетаскивать панель, обычно заголовок.   |
| `FloatingPanelHeader`                     | Часть Ark для заголовка и обёртка области перетаскивания.                 |
| `FloatingPanelTitle`                      | Задаёт доступное имя панели.                                             |
| `FloatingPanelControl`                    | Группирует кнопки смены режима и закрытия.                               |
| `FloatingPanelStageTrigger`               | Переключает режимы `default`, `minimized` и `maximized`.                  |
| `FloatingPanelCloseTrigger` / `FloatingPanelCloseIcon` | Закрывает панель.                                             |
| `FloatingPanelBody`                       | Основная область содержимого с прокруткой.                               |
| `FloatingPanelFooter`                     | Необязательная нижняя область для действий или статуса.                  |
| `FloatingPanelResizeTrigger`              | Ручка изменения размера для одной оси Ark.                              |
| `FloatingPanelResizeTriggerGroup`         | Выводит все или выбранные ручки изменения размера.                       |
| `FloatingPanelRootProvider`               | Подключает части к состоянию из `useFloatingPanel()`.       |

`FloatingPanelDragIndicator`, `FloatingPanelCloseIcon`, `FloatingPanelFooter` и
`FloatingPanelResizeTriggerGroup` являются вспомогательными частями moduix. Они дополняют
структурные части Ark UI, но не заменяют их.

## Композиция

Используйте `FloatingPanel` для локального состояния. Оставьте `FloatingPanelPositioner` и `FloatingPanelContent` явными,
оберните заголовок в `FloatingPanelDragTrigger` и добавьте `FloatingPanelTitle` для доступного имени. `FloatingPanelPositioner` по умолчанию
выводится через портал. Установите `portalled={false}` или передайте `portalRef`, если панель должна
находиться в другом контейнере.

Если состояние должно находиться за пределами дерева панели, создайте его через
`useFloatingPanel()` и передайте в `FloatingPanelRootProvider`. Не используйте `FloatingPanel` и
`FloatingPanelRootProvider` для одного экземпляра состояния. `position` и `size` управляются независимо. Используйте
`FloatingPanelResizeTriggerGroup axes` или отдельные `FloatingPanelResizeTrigger`, только если стандартный набор ручек не подходит.
Для `asChild` передавайте один семантически подходящий дочерний элемент. В Vue поместите дочерний элемент
в слот, а в Solid передайте функцию рендера.

### Ограничение контейнером

Передайте `getBoundaryEl` и установите `allowOverflow={false}`, чтобы панель оставалась внутри

### Контекст

Используйте `FloatingPanelContext` или `useFloatingPanelContext`, чтобы читать состояние и методы
панели внутри дерева компонентов. Vue получает значение контекста через scoped slot, а Solid
предоставляет его как accessor-функцию.

<Example name="floating-panel/context" />

### Управляемое открытие

Используйте `open` вместе с `onOpenChange`, если состояние приложения должно управлять видимостью панели.

<Example name="floating-panel/controlled-open" />

### Управляемая позиция

Управляйте `position`, если другой части приложения нужны текущие координаты панели.

<Example name="floating-panel/controlled-position" />

### Управляемый размер

Управляйте `size`, если интерфейсу нужно сохранять или показывать текущие размеры панели.

<Example name="floating-panel/controlled-size" />

### Закрытие по Escape

`closeOnEscape` включён по умолчанию. Добавьте `autoFocus` к `FloatingPanelContent`, чтобы Escape работал сразу

<Example name="floating-panel/escape-dismiss" />

### Ленивое монтирование

Используйте `lazyMount` и `unmountOnExit`, если содержимое должно монтироваться при первом открытии
и удаляться после анимации закрытия.

### FloatingPanelRootProvider

Используйте `useFloatingPanel` вместе с `FloatingPanelRootProvider`, если элементам управления за
пределами дерева панели нужны методы `minimize`, `maximize` и `setOpen`. В Solid состояние хранилища
читается через accessor-функцию.

## Стилизация

`FloatingPanelTrigger` не стилизован: оборачивайте `Button` через `asChild`. Размер панели берётся из
состояния Ark, поэтому задавайте `defaultSize`, `minSize` и `maxSize` на корне, а не CSS-размеры на
`FloatingPanelContent`. Анимация содержимого читает общие переменные `--moduix-popup-motion-*`.

Используйте `className` в React или `class` в Solid и Vue на экспортируемых частях. Варианты на Tailwind
используют нативные утилиты и классы потребителя. Варианты на CSS Modules построены на токенах foundation
и не имеют переменных компонента: класс на части перекрывает стили компонента из слоя.

### Точки стилизации

Части Ark UI сохраняют `data-scope="floating-panel"` и значения `data-part`. moduix добавляет
`data-slot="floating-panel-*"` к отрисованным обёрткам. Используйте `data-state="open|closed"`,
`data-dragging`, `data-disabled`, `data-stage`, `data-topmost`, `data-behind`, `data-minimized`,
`data-maximized`, `data-staged` и `data-axis` для стилизации состояния соответствующих частей.
`FloatingPanelFooter` повторяет `data-minimized` содержимого.

`FloatingPanelPositioner` предоставляет переменные Ark `--width`, `--height`, `--x`, `--y` и `--z-index`.
