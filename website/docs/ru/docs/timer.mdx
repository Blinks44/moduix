## Базовый пример

`Timer.Segments` проще всего использовать для классического отображения времени с разделителями `:`. По умолчанию
компонент показывает часы, минуты и секунды. Передайте `types`, чтобы выбрать другой набор единиц. Если нужны
подписи единиц, собственные разделители или отдельная стилизация каждой части, используйте полную композицию с
`Timer.Area`, `Timer.Item` и `Timer.Separator`.

`Timer.Segments` поддерживает все свойства `Timer.Area`, кроме `children` и `asChild`, и пробрасывает ref области.
Компонент сам создаёт элементы и разделители, поэтому для замены корневого элемента или собственных дочерних
элементов используйте `Timer.Area`.

## Анатомия

```text
Timer.Root
├─ Timer.Area
│  ├─ Timer.Item
│  └─ Timer.Separator
└─ Timer.Control
   └─ Timer.ActionTrigger

Timer.RootProvider
└─ то же дерево, подключённое к состоянию из `useTimer()`

Timer.Segments
└─ Timer.Area со стандартными элементами Timer.Item и Timer.Separator
```

| Элемент                 | Назначение                                                               |
| ----------------------- | ------------------------------------------------------------------------ |
| `Timer` / `Timer.Root`  | Управляет состоянием таймера Ark, его ID, интервалом и обратными вызовами. |
| `Timer.RootProvider`    | Подключает элементы к состоянию, созданному с помощью `useTimer()`.      |
| `Timer.Segments`        | Собирает стандартные единицы времени и разделители.                      |
| `Timer.Area`            | Группирует отображаемые значения времени.                                |
| `Timer.Item`            | Отображает одну отформатированную единицу времени, например `hours`, `minutes` или `seconds`. |
| `Timer.Separator`       | Отображает разделитель между единицами времени.                          |
| `Timer.Control`         | Группирует триггеры действий.                                             |
| `Timer.ActionTrigger`   | Запускает действие `start`, `pause`, `resume`, `reset` или `restart`.    |

## Композиция

### Рекомендуемая композиция

`Timer` является сокращённым вариантом корневого компонента и эквивалентен `Timer.Root`. Используйте
`Timer.Segments`, чтобы вывести часы, минуты и секунды без ручного повторения элементов и разделителей. Если нужен
другой набор единиц, передайте `types`.

Используйте `targetMs`, чтобы задать значение, при достижении которого таймер завершится. Свойство `startMs`
задаёт начальное значение, поэтому с его помощью можно начать отсчёт не с нуля. Для обратного отсчёта задайте
`countdown` и `startMs`.

### Когда нужна собственная композиция

Используйте `Timer.RootProvider` с `useTimer()`, когда состояние таймера нужно создать отдельно от разметки, которая
его отображает. Используйте `Timer.Context` или `useTimerContext()`, если другим элементам интерфейса нужен доступ
к `running`, `paused`, `time`, `formattedTime`, `progressPercent` или программным методам `start()`, `pause()`,
`resume()`, `reset()` и `restart()`.

Для обновления чаще одного раза в секунду уменьшите `interval`. Не делайте его меньше необходимого: Ark по
умолчанию использует интервал `1000` миллисекунд.

### Свойства по умолчанию

| Свойство          | По умолчанию | Примечания                                                        |
| ----------------- | ------------ | ----------------------------------------------------------------- |
| `autoStart`       | `false`      | Запускает таймер при монтировании.                                |
| `countdown`       | `false`      | Ведёт отсчёт вниз, а не вверх.                                    |
| `startMs`         | `0`          | Начальное прошедшее или оставшееся время в миллисекундах.          |
| `targetMs`        | -            | Значение, при достижении которого таймер завершается.             |
| `interval`        | `1000`       | Интервал тиков в миллисекундах.                                   |
| `ids`             | генерируются | Переопределяет сгенерированные ID корневого элемента и области.   |
| `translations`    | встроенные   | Настраивает доступное имя области, в том числе через `areaLabel`. |
| `onTick(details)` | -            | Вызывается после каждого обновления таймера.                      |
| `onComplete()`    | -            | Вызывается при завершении таймера.                                |

### Особенности поведения

По умолчанию `Timer.ActionTrigger` создаёт кнопку, поэтому клавиатурное взаимодействие работает как у обычной
кнопки. Ark скрывает действия `start`, `pause`, `resume` и `reset`, если они недоступны в текущем состоянии. Если
добавить `restart`, он остаётся доступным. Для таймера не нужна составная клавиатурная навигация и перемещение
фокуса между элементами.

Компоненты Ark, которые экспортирует moduix, в том числе `Timer.Root`, `Timer.RootProvider`, `Timer.Area`,
`Timer.Item`, `Timer.Separator`, `Timer.Control` и `Timer.ActionTrigger`, поддерживают `asChild` благодаря
полиморфной композиции Ark. При замене элемента сохраняйте корректную HTML-семантику, особенно для
`Timer.ActionTrigger`. `Timer.Segments` намеренно не поддерживает `asChild`, поскольку сам создаёт область и
дочерние элементы.

`Timer.Item` сохраняет атрибуты Ark `data-scope="timer"`, `data-part="item"`, `data-type` и `--value`.
`Timer.Segments` предназначен только для стандартных элементов и разделителей, поэтому подписи единиц нужно
добавлять отдельной композицией вокруг `Timer.Item`. moduix добавляет центрирование корневого контейнера, перенос
области времени при нехватке места, стабильные селекторы `data-slot`, размеры SVG-иконок внутри триггеров действий
и значения CSS по умолчанию, не меняя машину состояний таймера Ark.

### Селекторы и атрибуты стиля

- Селекторы `data-slot="timer-root"`, `timer-root-provider`, `timer-area`, `timer-item`,
  `timer-separator`, `timer-control` и `timer-action-trigger`.
- Атрибуты анатомии Ark: `data-scope="timer"` и
  `data-part="root|area|item|separator|control|action-trigger"`.
- `Timer.Item` предоставляет `data-type` и переменную CSS `--value`, которую обновляет Ark.
- Ark добавляет атрибут `hidden` к триггерам действий, недоступным в текущем состоянии таймера.
