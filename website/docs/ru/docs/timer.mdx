`TimerSegments` проще всего использовать для классического отображения времени с разделителями `:`. По умолчанию
компонент показывает часы, минуты и секунды. Передайте `types`, чтобы выбрать другой набор единиц. Если нужны
подписи единиц, собственные разделители или отдельная стилизация каждой части, используйте полную композицию с
`TimerArea`, `TimerItem` и `TimerSeparator`.

`TimerSegments` поддерживает все свойства `TimerArea`, кроме `children` и `asChild`, и пробрасывает ref области.
Компонент сам создаёт элементы и разделители, поэтому для замены корневого элемента или собственных дочерних
элементов используйте `TimerArea`.

## Композиция

`Timer` управляет состоянием таймера. `TimerSegments` сам создаёт части `TimerArea`,
`TimerItem` и `TimerSeparator`, поэтому для подписей единиц, собственных разделителей или отдельной разметки
используйте полную композицию с `TimerArea`.

Используйте `TimerRootProvider` с `useTimer()`, когда состояние нужно создать отдельно от отображаемого дерева.
`TimerContext` и `useTimerContext()` подходят, если другим элементам интерфейса нужны состояние или методы таймера.
В Solid состояние и контекст читаются через реактивные функции, поэтому обращайтесь к ним как к `timer()` и
`api()`. В Vue refs автоматически разворачиваются в шаблонах, а в коде `<script>` используются через `.value`.

В установленной версии Ark UI `TimerItem` заменяет дочернее содержимое отформатированным значением до обработки
`asChild`, поэтому переданный элемент теряется в Vue и React. До исправления в Ark используйте стандартный
элемент `TimerItem`; примеры выше используют этот рабочий вариант композиции.

## Стилизация

Передайте `className` в React или `class` в Solid и Vue на любую экспортируемую часть. Варианты Tailwind
используют утилиты и классы приложения. Варианты CSS Modules построены на токенах foundation и не имеют
собственных переменных: класс на части или селектор по `data-slot` переопределяет стили компонента из слоя.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `Timer` | `timer-root` |
| `TimerRootProvider` | `timer-root-provider` |
| `TimerArea` | `timer-area` |
| `TimerItem` | `timer-item` |
| `TimerSeparator` | `timer-separator` |
| `TimerControl` | `timer-control` |
| `TimerActionTrigger` | `timer-action-trigger` |

- Атрибуты анатомии Ark: `data-scope="timer"` и
  `data-part="root|area|item|separator|control|action-trigger"`.
- `TimerItem` предоставляет `data-type` и переменную CSS `--value`, которую обновляет Ark.
- Ark добавляет атрибут `hidden` к триггерам действий, недоступным в текущем состоянии таймера.
