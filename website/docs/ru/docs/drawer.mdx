## Выбор подходящего компонента

Используйте `Drawer` для панели у края экрана, которой нужны жесты свайпа, точки привязки или поведение мобильного
bottom sheet. Используйте `Dialog`, когда поверхность должна оставаться по центру и не требует перетаскивания.

## Анатомия

```text
Drawer.Root
├─ Drawer.Trigger
├─ Drawer.SwipeArea (optional)
├─ Drawer.Backdrop
└─ Drawer.Positioner
   └─ Drawer.Content
      ├─ Drawer.Grabber
      │  └─ Drawer.GrabberIndicator
      ├─ Drawer.Title
      ├─ Drawer.Description
      └─ Drawer.CloseTrigger
```

| Часть                     | Назначение                                          |
| ------------------------- | --------------------------------------------------- |
| `Drawer` / `Drawer.Root`  | Управляет состоянием панели, точками привязки и жестами свайпа. |
| `Drawer.Trigger`          | Открывает панель.                                    |
| `Drawer.Backdrop`         | Модальный фоновый слой.                              |
| `Drawer.Positioner`       | Плавающий позиционер содержимого панели.             |
| `Drawer.Content`          | Контейнер поверхности панели.                        |
| `Drawer.Grabber`          | Контейнер ручки перетаскивания для жестов свайпа.     |
| `Drawer.GrabberIndicator` | Визуальный индикатор внутри ручки.                   |
| `Drawer.CloseTrigger`     | Закрывает панель.                                    |
| `Drawer.SwipeArea`        | Необязательная область у края для открытия свайпом.  |
| `Drawer.Stack`            | Координирует вложенные панели и панели с отступом.   |
| `Drawer.Indent`           | Поверхность, отступающая при открытии панели в стеке. |
| `Drawer.IndentBackground` | Фон за поверхностью с отступом.                      |
| `Drawer.Header`           | Необязательный помощник компоновки области заголовка. |
| `Drawer.Body`             | Необязательная гибкая область содержимого.           |
| `Drawer.Footer`           | Необязательный помощник компоновки действий.         |
| `Drawer.CloseIcon`        | Стилизованный элемент закрытия.                      |
| `Drawer.RootProvider`     | Подключает части к состоянию, созданному через `useDrawer()`. |

`Drawer.Header`, `Drawer.Body`, `Drawer.Footer` и `Drawer.CloseIcon` - необязательные помощники компоновки и
визуального оформления moduix. Они не заменяют и не скрывают структурные части Ark.

## Композиция

Корневой компонент автоматически переносит `Backdrop` и `Positioner` в портал. Панель в портале использует область
просмотра, поэтому размер предпросмотра влияет только на триггер. Для встроенного рендеринга используйте
`portalled={false}`, а для собственного контейнера - `portalRef`; структурные части остаются явными и доступными для стилизации.

### Рекомендуемая композиция

Используйте `Drawer` для состояния и поведения. Рендерите `Backdrop`, `Positioner` и `Content` явно, затем поместите
`Grabber` и `GrabberIndicator` внутрь содержимого, если для перетаскивания нужна видимая ручка.

Используйте `asChild`, чтобы скомпоновать `Drawer.Trigger` или `Drawer.CloseTrigger` с `Button`. Дочерним должен быть
единственный семантический элемент, способный получать фокус.

Колбэки сохраняют объекты сведений Ark:

- `onOpenChange(details)` → `details.open`
- `onSnapPointChange(details)` → `details.snapPoint`
- `onTriggerValueChange(details)` → `details.value` и `details.triggerElement`

### Когда нужна собственная композиция

Передавайте `className` непосредственно любой экспортируемой части. Для внешнего состояния импортируйте `useDrawer`
из `@moduix/react` и подключите это состояние через `Drawer.RootProvider`. Не сочетайте `Drawer` и
`Drawer.RootProvider` для одного экземпляра. Для расширенной композиции из `@moduix/react` также доступны
`useDrawerContext`, `useDrawerStackContext` и `Drawer.Context`.

Оберните согласованные поверхности с отступом в `Drawer.Stack`, затем отрендерите `Drawer.IndentBackground` и
`Drawer.Indent`.

### Свойства по умолчанию

По умолчанию содержимое оверлея в портале монтируется лениво и размонтируется после анимации выхода. Задайте
`unmountOnExit={false}`, чтобы сохранять его после первого открытия; отключайте оба свойства жизненного цикла только
когда нужен немедленный первоначальный рендеринг.

| Свойство                 | По умолчанию | Примечания                                           |
| ------------------------ | ---------- | ------------------------------------------------------ |
| `modal`                  | `true`     | Скрывает содержимое страницы и блокирует внешнее взаимодействие. |
| `swipeDirection`         | `"down"`   | По умолчанию открывается снизу.                        |
| `snapPoints`             | `[1]`      | Использует полный размер, если точки привязки не заданы. |
| `closeOnEscape`          | `true`     | Сохраняет закрытие по Escape из Ark.                   |
| `closeOnInteractOutside` | `true`     | Закрывает модальную панель при внешнем взаимодействии. |
| `preventDragOnScroll`    | `true`     | Не начинает перетаскивание из прокручиваемых дочерних элементов. |
| `preventScroll`          | `true`     | Предотвращает фоновую прокрутку, пока панель открыта.   |
| `restoreFocus`           | `true`     | Возвращает фокус предыдущему активному элементу.       |
| `trapFocus`              | `true`     | Удерживает фокус внутри модального содержимого.        |
| `lazyMount`              | `true`     | Значение moduix по умолчанию, отличающееся от `false` в Ark. |
| `unmountOnExit`          | `true`     | Значение moduix по умолчанию, отличающееся от `false` в Ark. |
| `Content draggable`      | `true`     | Ручка сохраняет перетаскивание, даже если содержимое его не поддерживает. |
| `closeThreshold`         | `0.25`     | Доля расстояния свайпа, необходимая для закрытия.      |
| `snapToSequentialPoints` | `false`    | Перемещается по точкам привязки по одному шагу.        |
| `swipeVelocityThreshold` | `700`      | Порог скорости свайпа для закрытия.                    |
| `role`                   | `"dialog"` | Для срочного блокирующего содержимого задайте `"alertdialog"`. |

### Особенности поведения

- Публичные значения направления логические: `up`, `down`, `start` и `end`. Для стилизации Ark предоставляет через
  `data-swipe-direction` вычисленные физические значения `left` или `right`.
- `Content draggable={false}` отключает перетаскивание из содержимого, сохраняя ручку активной.
- `Content variant="island"` добавляет отступ от области просмотра, скругляет все углы содержимого и убирает выход за
  границу при перетаскивании для отделённой поверхности панели.
- `data-no-drag` не позволяет начать жест перетаскивания внутри заданного поддерева.
- Модальный фон остаётся полностью видимым при перетаскивании между точками привязки и исчезает после начала закрытия.
- `ids` настраивает идентификаторы доступности для композиции между частями.
- `stack` принимает внешнее хранилище стека панелей Ark для визуализации стека на уровне приложения.
- `immediate` и `skipAnimationOnMount` настраивают время присутствия Ark, когда нужна собственная анимация.
- `present`, `lazyMount`, `unmountOnExit` и `onExitComplete` управляют жизненным циклом рендеринга. В moduix
  `lazyMount` и `unmountOnExit` по умолчанию равны `true`, чтобы анимации выхода завершались без первоначального
  рендеринга скрытых панелей.
- При `prefers-reduced-motion: reduce` анимации появления, выхода и стека выполняются за 1 мс; при этом сохраняется
  завершение жизненного цикла Ark.
- Ark сохраняет удержание фокуса диалога, обработку Escape, связи заголовка и описания и восстановление фокуса.

### Немодальный режим

Задайте `modal={false}`, когда страница должна оставаться интерактивной и прокручиваемой при открытой панели. На
сенсорных устройствах отключите перетаскивание `Content` и используйте Header как `Grabber`: это не позволит одному
вертикальному жесту одновременно перемещать панель и страницу. Добавьте `data-no-drag` каждому интерактивному элементу
Header, например кнопке закрытия. Если перетаскиваться должно всё содержимое, задайте `preventScroll={true}`: внешние
элементы управления останутся интерактивными, но фоновая прокрутка будет заблокирована до закрытия панели.

- Слоты moduix: `drawer-trigger`, `drawer-backdrop`, `drawer-positioner`, `drawer-content`,
  `drawer-grabber`, `drawer-grabber-indicator`, `drawer-title`, `drawer-description`,
