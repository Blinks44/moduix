## Как выбрать компонент

Используйте `Drawer` для панели, которая выезжает от края окна. Компонент подходит для навигации,
форм, мобильных нижних панелей и сценариев, где панель нужно перетаскивать или переводить между
точками привязки. Выбирайте `Dialog`, если поверхность должна оставаться по центру и её не нужно
перетаскивать.

## Анатомия

```text
Drawer
├─ DrawerTrigger
├─ DrawerSwipeArea (необязательно)
├─ DrawerBackdrop
└─ DrawerPositioner
   └─ DrawerContent
      ├─ DrawerGrabber
      │  └─ DrawerGrabberIndicator
      ├─ DrawerHeader (необязательный помощник для компоновки)
      │  ├─ DrawerTitle
      │  ├─ DrawerDescription
      │  └─ DrawerCloseIcon (необязательный помощник)
      ├─ DrawerBody (необязательный помощник для компоновки)
      └─ DrawerFooter (необязательный помощник для компоновки)

DrawerRootProvider
└─ то же дерево частей, подключённое к хранилищу useDrawer()
```

| Часть | Назначение |
| --- | --- |
| `Drawer` | Корневая часть, которая хранит состояние открытия, точки привязки и поведение свайпа. |
| `DrawerRootProvider` | Подключает части к состоянию, созданному через `useDrawer()`. |
| `DrawerTrigger` | Открывает панель. |
| `DrawerSwipeArea` | Необязательная область у края экрана, открывающая панель свайпом. |
| `DrawerBackdrop` | Модальный фон. |
| `DrawerPositioner` | Размещает содержимое панели. |
| `DrawerContent` | Интерактивная поверхность панели. |
| `DrawerGrabber` | Контейнер ручки для перетаскивания. |
| `DrawerGrabberIndicator` | Визуальный индикатор внутри ручки. |
| `DrawerTitle` | Доступное имя панели. |
| `DrawerDescription` | Доступное описание панели. |
| `DrawerCloseTrigger` | Закрывает панель. |
| `DrawerCloseIcon` | Кнопка закрытия moduix, собранная из `DrawerCloseTrigger`. |
| `DrawerStack` | Координирует вложенные панели и поверхности с отступом. |
| `DrawerIndent` | Поверхность, которая отодвигается при открытии панели из стека. |
| `DrawerIndentBackground` | Фон за поверхностью с отступом. |
| `DrawerHeader`, `DrawerBody`, `DrawerFooter` | Необязательные помощники для компоновки без собственного состояния. |

## Композиция

По умолчанию `Drawer` хранит состояние сам и рендерит `DrawerBackdrop` и `DrawerPositioner` через портал.
Оставляйте эти структурные части явными. Укажите `portalled={false}`, чтобы отрисовать их внутри
текущего дерева, или передайте `portalRef` для собственного контейнера.

Если состояние нужно создать за пределами дерева панели, создайте одно хранилище через `useDrawer()`
и передайте его в один `DrawerRootProvider`. Не используйте для этого же хранилища `Drawer`.
Для вложенных панелей создавайте отдельные хранилища и деревья `DrawerRootProvider`, чтобы
каждая панель сохраняла собственное состояние открытия и фокуса.

Поместите поверхности, которые должны двигаться вместе, в `DrawerStack`, а затем объедините
`DrawerIndentBackground` и `DrawerIndent`. Для собственного элемента триггера или закрытия
используйте `asChild`: в React передаётся один доступный для фокуса дочерний элемент, а в Solid
рендер-функция должна передать ему `props()`. Обработчики Ark получают объект деталей, например
`details.open`, `details.snapPoint` и `details.value`.

## Стилизация

Используйте `className` в React или `class` в Solid на экспортируемых частях для структурных
стилей. Для стилей по состоянию предпочитайте атрибуты данных Ark, например `data-state`,
`data-swipe-direction` и `data-dragging`, вместе с селекторами moduix `data-slot`. Варианты Tailwind
используют нативные utility-классы и классы потребителя, а приведённые ниже переменные настраивают
варианты CSS Modules. Атрибуты данных и хуки `data-slot` общие для обоих вариантов стилизации.

### CSS-свойства

### Хуки стилизации

- значения moduix `data-slot`: `drawer-trigger`, `drawer-backdrop`, `drawer-positioner`, `drawer-content`,
  `drawer-grabber`, `drawer-grabber-indicator`, `drawer-title`, `drawer-description`,
  `drawer-close-trigger`, `drawer-close-icon`, `drawer-swipe-area`, `drawer-indent`,
  `drawer-indent-background`, `drawer-header`, `drawer-body` и `drawer-footer`.
- `DrawerContent` записывает `data-variant="island"`, когда включено островное представление.
- хуки частей Ark: `data-scope="drawer"` вместе с `data-part`.
- хуки состояния: `data-state="open|closed"`, `data-swipe-direction`, `data-swiping`,
  `data-dragging`, `data-expanded`, `data-current`, `data-value`, `data-disabled`,
  `data-nested-drawer-open` и `data-nested-drawer-swiping`.
- runtime-переменные: `--drawer-translate`, `--drawer-translate-x`, `--drawer-translate-y`,
  `--drawer-snap-point-offset-x`, `--drawer-snap-point-offset-y`, `--drawer-swipe-movement-x`,
  `--drawer-swipe-movement-y`, `--drawer-swipe-progress`, `--drawer-swipe-strength`,
  `--drawer-height`, `--drawer-frontmost-height`, `--nested-drawers`, `--nested-layer-count`
  и `--layer-index`.
