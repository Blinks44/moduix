## Выбор подходящего компонента

Используйте `Drawer` для панели, которая выезжает от края экрана. Компонент подходит для навигации, форм, мобильных
нижних панелей и сценариев, где панель нужно перетаскивать или переводить из одной точки привязки в другую. Выбирайте
`Dialog`, если окно должно оставаться по центру и его не нужно перетаскивать.

## Базовый пример

Соберите панель из структурных частей Ark UI. В этом примере она открывается на компактной точке привязки, а затем её
можно перетащить на полную высоту. `Drawer.Content` отвечает за интерактивную область, `Drawer.Positioner` размещает
её, а `Drawer.Backdrop` добавляет модальный фон.

## Анатомия

```text
Drawer.Root
├─ Drawer.Trigger
├─ Drawer.SwipeArea (необязательно)
├─ Drawer.Backdrop
└─ Drawer.Positioner
   └─ Drawer.Content
      ├─ Drawer.Grabber
      │  └─ Drawer.GrabberIndicator
      ├─ Drawer.Title
      ├─ Drawer.Description
      └─ Drawer.CloseTrigger
```

| Часть                     | Назначение                                                        |
| ------------------------- | ------------------------------------------------------------ |
| `Drawer` / `Drawer.Root`  | Хранит состояние панели, её точки привязки и поведение свайпа.   |
| `Drawer.Trigger`          | Открывает панель.                                            |
| `Drawer.Backdrop`         | Модальный фон.                                               |
| `Drawer.Positioner`       | Размещает содержимое панели.                                 |
| `Drawer.Content`          | Интерактивная область панели.                                     |
| `Drawer.Grabber`          | Контейнер ручки для перетаскивания.                          |
| `Drawer.GrabberIndicator` | Визуальный индикатор внутри ручки.                           |
| `Drawer.CloseTrigger`     | Закрывает панель.                                            |
| `Drawer.SwipeArea`        | Необязательная область у края экрана для открытия свайпом.        |
| `Drawer.Stack`            | Координирует вложенные панели и поверхности с отступом.      |
| `Drawer.Indent`           | Поверхность, которая отодвигается при открытии панели из стека. |
| `Drawer.IndentBackground` | Фон за поверхностью с отступом.                                   |
| `Drawer.Header`           | Необязательный помощник для компоновки заголовка.                 |
| `Drawer.Body`             | Необязательная гибкая область содержимого.                   |
| `Drawer.Footer`           | Необязательный помощник для компоновки действий.                  |
| `Drawer.CloseIcon`        | Стилизованный элемент управления закрытием.                       |
| `Drawer.RootProvider`     | Подключает части к состоянию, созданному через `useDrawer()`.     |

`Drawer.Header`, `Drawer.Body`, `Drawer.Footer` и `Drawer.CloseIcon` - необязательные помощники moduix для компоновки и
оформления. Они не заменяют и не скрывают структурные части Ark.

`Drawer` и `Drawer.Root` - равнозначные корневые компоненты. В коде приложения используйте короткую форму `<Drawer>`,
а `Drawer.Root` пригодится, если вы предпочитаете записывать компоненты через пространство имён.

## Композиция

Корневой компонент автоматически помещает `Backdrop` и `Positioner` в портал. Панель в портале позиционируется
относительно окна просмотра, поэтому размер предпросмотра влияет только на триггер. Используйте `portalled={false}`
для обычной отрисовки в текущем дереве или передайте `portalRef`, чтобы выбрать свой контейнер. Структурные части
остаются явными и их можно стилизовать.

### Рекомендуемая композиция

Используйте `Drawer` как корневой компонент, если он должен сам управлять состоянием и поведением. Явно отрендерите
`Backdrop`, `Positioner` и `Content`, а затем поместите `Grabber` и `GrabberIndicator` внутрь `Content`, если нужна
видимая ручка для перетаскивания.

Используйте `asChild`, чтобы объединить `Drawer.Trigger` или `Drawer.CloseTrigger` с `Button`. Дочерним элементом
должен быть один семантический элемент, который может получить фокус.

Колбэки Ark передают объект `details`:

- `onOpenChange(details)` → `details.open`
- `onSnapPointChange(details)` → `details.snapPoint`
- `onTriggerValueChange(details)` → `details.value` и `details.triggerElement`

### Когда нужна собственная композиция

Передавайте `className` напрямую любой экспортируемой части. Если состояние должно находиться за пределами дерева
панели, импортируйте `useDrawer` из `@moduix/react` и передайте его результат в `Drawer.RootProvider`. Не используйте
`Drawer` и `Drawer.RootProvider` для одного и того же состояния. Для сложной композиции `@moduix/react` также экспортирует
`useDrawerContext`, `useDrawerStackContext` и `Drawer.Context`.

Объедините в `Drawer.Stack` поверхности, которые должны перемещаться вместе, затем отрендерите
`Drawer.IndentBackground` и `Drawer.Indent`.

### Свойства по умолчанию

По умолчанию содержимое оверлея в портале монтируется только при первом открытии и размонтируется после анимации
закрытия. Установите `unmountOnExit={false}`, чтобы оставить его в DOM после первого открытия. Отключайте оба свойства
жизненного цикла только если содержимое нужно отрендерить сразу при загрузке.

| Свойство                 | По умолчанию | Примечания                                                        |
| ------------------------ | ------------ | ----------------------------------------------------------------- |
| `modal`                  | `true`       | Скрывает страницу и блокирует взаимодействие за пределами панели. |
| `swipeDirection`         | `"down"`     | По умолчанию открывает панель снизу.                              |
| `snapPoints`             | `[1]`        | Использует всю высоту, если точки привязки не заданы.             |
| `closeOnEscape`          | `true`       | Позволяет закрывать панель клавишей Escape.                       |
| `closeOnInteractOutside` | `true`       | Закрывает модальную панель при взаимодействии за её пределами.   |
| `preventDragOnScroll`    | `true`       | Не позволяет начинать перетаскивание из прокручиваемого содержимого. |
| `preventScroll`          | `true`       | Блокирует прокрутку фона, пока панель открыта.                    |
| `restoreFocus`           | `true`       | Возвращает фокус элементу, который был активен до открытия.       |
| `trapFocus`              | `true`       | Удерживает фокус внутри модального содержимого.                  |
| `lazyMount`              | `true`       | Значение по умолчанию в moduix, в Ark по умолчанию `false`.       |
| `unmountOnExit`          | `true`       | Значение по умолчанию в moduix, в Ark по умолчанию `false`.       |
| `Drawer.Content draggable` | `true`       | Перетаскивание из содержимого включено. Если задать `false`, панель можно будет двигать только за ручку. |
| `closeThreshold`         | `0.25`       | Доля расстояния свайпа, необходимая для закрытия панели.         |
| `snapToSequentialPoints` | `false`      | Переходит между точками привязки по одному шагу.                  |
| `swipeVelocityThreshold` | `700`        | Порог скорости свайпа, при котором панель закрывается.            |
| `role`                   | `"dialog"`  | Установите `"alertdialog"` для срочного блокирующего содержимого. |

### Особенности поведения

- В API направления задаются логически: `up`, `down`, `start` и `end`. Для стилизации Ark записывает в
  `data-swipe-direction` фактическое направление `left` или `right`.
- `Drawer.Content draggable={false}` отключает перетаскивание из содержимого, но оставляет ручку активной.
- `Drawer.Content variant="island"` добавляет отступ от краёв окна, скругляет все углы и убирает расширение фона,
  которое используется при перетаскивании за край.
- `data-no-drag` запрещает начинать жест перетаскивания внутри заданного поддерева.
- Модальный фон остаётся полностью видимым, пока панель перемещается между точками привязки, и исчезает, когда начинается закрытие.
- `ids` задаёт идентификаторы для доступности, когда части панели собраны в разных деревьях.
- `Drawer.CloseIcon` по умолчанию задаёт доступную метку `Close drawer`. Передайте свой `aria-label`,
  если в конкретном контексте нужен другой текст.
- `Drawer.Content` передаёт `ref` на поверхность диалога. Это удобно, если нужно измерить панель или
  программно перевести на неё фокус.
- `stack` принимает внешнее хранилище стека Ark, чтобы управлять визуальными эффектами стека на уровне приложения.
- `immediate` и `skipAnimationOnMount` управляют моментом монтирования и размонтирования панели в Ark, если анимацией
  управляете самостоятельно.
- `present`, `lazyMount`, `unmountOnExit` и `onExitComplete` управляют жизненным циклом рендера. В moduix параметры
  `lazyMount` и `unmountOnExit` по умолчанию равны `true`: анимации выхода успевают завершиться, а скрытые панели не
  рендерятся при первой загрузке.
- При `prefers-reduced-motion: reduce` анимации появления, выхода и стека длятся 1 мс, но Ark всё равно корректно
  завершает жизненный цикл.
- Ark сохраняет стандартное поведение диалога: удерживает фокус, обрабатывает Escape, связывает заголовок с описанием
  и возвращает фокус после закрытия.

### Немодальный режим

Задайте `modal={false}`, если пользователь должен взаимодействовать со страницей и прокручивать её при открытой панели.
На сенсорных устройствах отключите перетаскивание у `Content` и используйте `Header` как `Grabber`: вертикальный жест
тогда не будет одновременно двигать панель и страницу. Добавьте `data-no-drag` каждому интерактивному элементу в
`Header`, например кнопке закрытия. Если панель должна перетаскиваться за любое место содержимого, оставьте его
перетаскиваемым и включите `preventScroll={true}`. Элементы управления за пределами панели останутся доступными, но
прокрутка страницы будет заблокирована на время её открытия.

### Хуки стилизации

- Значения `data-slot`, которые добавляет moduix: `drawer-trigger`, `drawer-backdrop`, `drawer-positioner`, `drawer-content`,
  `drawer-grabber`, `drawer-grabber-indicator`, `drawer-title`, `drawer-description`,
  `drawer-close-trigger`, `drawer-close-icon`, `drawer-swipe-area`, `drawer-indent`,
  `drawer-indent-background`, `drawer-header`, `drawer-body` и `drawer-footer`.
- `Drawer.Content` записывает `data-variant="island"`, когда активно представление island.
- Атрибуты частей Ark: `data-scope="drawer"` с `data-part`.
- Атрибуты состояния: `data-state="open|closed"`, `data-swipe-direction`, `data-swiping`,
  `data-dragging`, `data-expanded`, `data-current`, `data-value`, `data-disabled`,
  `data-nested-drawer-open` и `data-nested-drawer-swiping`.
- Переменные во время выполнения: `--drawer-translate`, `--drawer-translate-x`, `--drawer-translate-y`,
  `--drawer-snap-point-offset-x`, `--drawer-snap-point-offset-y`,
  `--drawer-swipe-movement-x`, `--drawer-swipe-movement-y`, `--drawer-swipe-progress`,
  `--drawer-swipe-strength`, `--drawer-height`, `--drawer-frontmost-height`,
  `--nested-drawers`, `--nested-layer-count` и `--layer-index`.
