## Использование

<Usage />

Соберите панель из структурных частей Ark. В этом примере она открывается на компактной точке
привязки, а затем её можно перетащить на полную высоту. `DrawerContent` отвечает за интерактивную
поверхность, `DrawerPositioner` размещает её, а `DrawerBackdrop` добавляет модальный фон.

## Как выбрать компонент

Используйте `Drawer` для панели, которая выезжает от края окна. Компонент подходит для навигации,
форм, мобильных нижних панелей и сценариев, где панель нужно перетаскивать или переводить между
точками привязки. Выбирайте `Dialog`, если поверхность должна оставаться по центру и её не нужно
перетаскивать.

## Примеры

### Направление свайпа

Используйте логические значения `start` и `end` для боковых панелей, чтобы один и тот же код
работал в LTR и RTL. Для верхней панели используйте `up`, для нижней - `down`.

<Example name="drawer/swipe-direction" />

### Размеры

Задайте `size` на `DrawerContent`: `sm`, `md` (по умолчанию), `lg` или `xl`, чтобы выбрать ширину
боковой панели `start` или `end`: 18rem, 22rem, 28rem или 36rem. На узком экране панель всё равно
оставляет зазор у противоположного края. Верхняя и нижняя панели занимают всю ширину, а их высоту
задают точки привязки.

<Example name="drawer/sizes" />

### Точки привязки

Задайте промежуточные позиции в корневом компоненте и выберите начальную позицию через
`defaultSnapPoint`.

<Example name="drawer/snap-points" />

### Прокручиваемое содержимое

Поместите длинный контент в `DrawerBody`. Используйте `ScrollArea`, если панели нужен отдельный
контейнер прокрутки, а ручка и заголовок должны оставаться на месте.

<Example name="drawer/scrollable" />

### Плавающая ручка

Разместите `DrawerGrabber` над поверхностью, если ручка должна выглядеть отдельным элементом.
В этом примере между ручкой и краем панели оставлено 10px.

<Example name="drawer/floating-grabber" />

### Управление перетаскиванием

Добавьте `data-no-drag` на интерактивные области, которые не должны запускать перетаскивание.
Укажите `draggable={false}` на `DrawerContent`, если панель должна двигаться только за ручку.

<Example name="drawer/drag-controls" />

### Фон с отступом

`DrawerStack` использует состояние стека и прогресс свайпа Ark, чтобы перемещать
`DrawerIndentBackground` и `DrawerIndent` вместе.

<Example name="drawer/indent-background" />

### Островная панель

Укажите `variant="island"` на `DrawerContent`, если компактная панель должна располагаться с
отступом внутри окна, а не визуально выходить за край, откуда она открывается.

<Example name="drawer/island" />

### Немодальная панель

Укажите `modal={false}`, если страница должна оставаться доступной для взаимодействия, пока панель
открыта. В этом примере ручка отвечает за перетаскивание, а `ScrollArea` содержит длинный контент.

<Example name="drawer/non-modal" />

### Вложенные панели

Используйте отдельные экземпляры Ark `useDrawer` и отдельные деревья moduix
`DrawerRootProvider` для вложенных панелей. Тогда каждая панель сохраняет собственное состояние
открытия и жизненный цикл фокуса.

<Example name="drawer/nested" />

### Несколько триггеров

Задайте каждому триггеру `value`, чтобы использовать одну панель для списка. Callback сообщает,
какой триггер активен.

<Example name="drawer/multiple-triggers" />

### Управляемый режим

Читайте `details.open` в callback Ark. Callback получает объект деталей, а не логическое значение напрямую. Подробнее в разделе [Управляйте состоянием из приложения](/docs/composition-patterns#controlled-state).

<Example name="drawer/controlled" />

### Root Provider

Используйте экспорт moduix `useDrawer`, если кнопки за пределами дерева панели должны открывать её
или менять её точки привязки. Подробнее в разделе [Выносите состояние за пределы дерева](/docs/composition-patterns#root-provider).

<Example name="drawer/root-provider" />

### Сборка из частей

Тот же Drawer, что в Basic, но без `DrawerHeader`, `DrawerBody`, `DrawerFooter` и
`DrawerCloseIcon`: обычные элементы раскладки и `DrawerCloseTrigger` вокруг `CloseButton` с явной
иконкой. Начинайте с него, если дизайн меняет раскладку или кнопку закрытия.

## Композиция

По умолчанию `Drawer` хранит состояние сам и рендерит `DrawerBackdrop` и `DrawerPositioner` через портал.
Оставляйте эти структурные части явными. Укажите `portalled={false}`, чтобы отрисовать их внутри
текущего дерева, или передайте `portalRef` для собственного контейнера.

Если состояние нужно создать за пределами дерева панели, создайте одно хранилище через `useDrawer()`
и передайте его в один `DrawerRootProvider`. Не используйте для этого же хранилища `Drawer`.
Для вложенных панелей создавайте отдельные хранилища и деревья `DrawerRootProvider`, чтобы
каждая панель сохраняла собственное состояние открытия и фокуса.

Поместите поверхности, которые должны двигаться вместе, в `DrawerStack`, а затем объедините
`DrawerIndentBackground` и `DrawerIndent`. Для собственного элемента триггера или закрытия
используйте `asChild`: в React передаётся один доступный для фокуса дочерний элемент, в Solid
рендер-функция должна передать ему `props()`, а во Vue используется атрибут `as-child` с одним
дочерним элементом. Обработчики Ark получают объект деталей, например
`details.open`, `details.snapPoint` и `details.value`.

## Стилизация

Используйте `className` в React или `class` в Solid и Vue на экспортируемых частях для структурных
стилей. Для стилей по состоянию предпочитайте атрибуты данных Ark, например `data-state`,
`data-swipe-direction` и `data-dragging`, вместе с селекторами moduix `data-slot`. Варианты Tailwind
используют нативные utility-классы и классы потребителя, а приведённые ниже переменные настраивают
варианты CSS Modules. Атрибуты данных и хуки `data-slot` общие для обоих вариантов стилизации.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `DrawerTrigger` | `drawer-trigger` |
| `DrawerBackdrop` | `drawer-backdrop` |
| `DrawerPositioner` | `drawer-positioner` |
| `DrawerContent` | `drawer-content` |
| `DrawerGrabber` | `drawer-grabber` |
| `DrawerGrabberIndicator` | `drawer-grabber-indicator` |
| `DrawerTitle` | `drawer-title` |
| `DrawerDescription` | `drawer-description` |
| `DrawerCloseTrigger` | `drawer-close-trigger` |
| `DrawerCloseIcon` | `drawer-close-icon` |
| `DrawerSwipeArea` | `drawer-swipe-area` |
| `DrawerIndent` | `drawer-indent` |
| `DrawerIndentBackground` | `drawer-indent-background` |
| `DrawerHeader` | `drawer-header` |
| `DrawerBody` | `drawer-body` |
| `DrawerFooter` | `drawer-footer` |

- `DrawerContent` записывает `data-size` (по умолчанию `md`) и `data-variant="island"`, когда
  включено островное представление.
- хуки частей Ark: `data-scope="drawer"` вместе с `data-part`.
- хуки состояния: `data-state="open|closed"`, `data-swipe-direction`, `data-swiping`,
  `data-dragging`, `data-expanded`, `data-current`, `data-value`, `data-disabled`,
  `data-nested-drawer-open` и `data-nested-drawer-swiping`.
- runtime-переменные: `--drawer-translate`, `--drawer-translate-x`, `--drawer-translate-y`,
  `--drawer-snap-point-offset-x`, `--drawer-snap-point-offset-y`, `--drawer-swipe-movement-x`,
  `--drawer-swipe-movement-y`, `--drawer-swipe-progress`, `--drawer-swipe-strength`,
  `--drawer-height`, `--drawer-frontmost-height`, `--nested-drawers`, `--nested-layer-count`
  и `--layer-index`.
- `DrawerTrigger` и `DrawerCloseTrigger` не стилизованы. Соберите их через `asChild` с `Button` или
  задайте стили нативной кнопке классом.
- Цвета, границы, отступы и типографика берутся из токенов foundation. Чтобы изменить их для одного
  drawer, повесьте класс на нужную часть. Подложка читает общие `--moduix-backdrop-bg` и
  `--moduix-backdrop-filter`.
- Высота верхнего и нижнего drawer ограничена `max-height: 80dvh`; другое значение задайте классом
  на `DrawerContent`.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `Enter` / `Space` | Открывает с кнопки в фокусе. |
| `Tab` / `Shift+Tab` | Перемещает фокус между элементами; пока открыто, фокус не выходит наружу. |
| `Esc` | Закрывает и возвращает фокус на кнопку. |

## Справочник API

Пропсы `Drawer`. `size` (`'sm' | 'md' | 'lg' | 'xl'`, по умолчанию `'md'`) и `variant` (`'island'`) задаются на `DrawerContent`.

| Проп | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `open` | `boolean` | — | Состояние открытия в управляемом режиме. |
| `defaultOpen` | `boolean` | `false` | Начальное состояние открытия, если оно не управляется извне. |
| `onOpenChange` | `(details: OpenChangeDetails) => void` | — | Вызывается при открытии и закрытии. |
| `swipeDirection` | `'up' \| 'down' \| 'start' \| 'end'` | `'down'` | Направление свайпа для закрытия: `up`, `down`, `start` или `end`. |
| `snapPoints` | `(number \| string)[]` | `[1]` | Высоты, на которых может остановиться панель: доли или CSS-длины. |
| `snapPoint` | `number \| string \| null` | — | Активная точка в управляемом режиме. |
| `defaultSnapPoint` | `number \| string \| null` | `1` | Начальная точка остановки. |
| `onSnapPointChange` | `(details: SnapPointChangeDetails) => void` | — | Вызывается, когда панель встаёт на другую точку. |
| `snapToSequentialPoints` | `boolean` | `false` | Переходит на соседнюю точку, не перескакивая при быстром свайпе. |
| `closeThreshold` | `number` | `0.25` | Какую долю высоты нужно протянуть, чтобы закрыть. |
| `modal` | `boolean` | `true` | Блокирует взаимодействие снаружи и скрывает остальную страницу от вспомогательных технологий. |
| `closeOnEscape` | `boolean` | `true` | Закрывается по Escape. |
| `closeOnInteractOutside` | `boolean` | `true` | Закрывается по клику снаружи. |
| `lazyMount` | `boolean` | `true` | Монтирует содержимое при первом открытии. |
| `unmountOnExit` | `boolean` | `true` | Удаляет содержимое после закрытия. |
| `trapFocus` | `boolean` | `true` | Удерживает фокус внутри, пока открыто. |
| `preventScroll` | `boolean` | `true` | Блокирует прокрутку страницы, пока открыто. |
| `initialFocusEl` | `() => MaybeElement \| false` | — | Возвращает элемент, который получает фокус при открытии. |
| `finalFocusEl` | `() => MaybeElement` | — | Возвращает элемент, который получает фокус при закрытии. |
| `restoreFocus` | `boolean` | `true` | Возвращает фокус на прежний элемент при закрытии. |
| `role` | `'dialog' \| 'alertdialog'` | `'dialog'` | `dialog` или `alertdialog` для срочных подтверждений. |
| `triggerValue` | `string \| null` | — | Активный триггер в управляемом режиме, если у окна несколько триггеров. |
| `defaultTriggerValue` | `string \| null` | — | Изначально активный триггер. |
| `onTriggerValueChange` | `(details: TriggerValueChangeDetails) => void` | — | Вызывается, когда активным становится другой триггер. |
| `swipeVelocityThreshold` | `number` | `700` | Скорость свайпа для закрытия, в пикселях в секунду. |
| `preventDragOnScroll` | `boolean` | `true` | Прокручивает внутреннее содержимое вместо перетаскивания панели. |
| `stack` | `DrawerStack` | — | Общее хранилище для оформления стопки панелей. |
