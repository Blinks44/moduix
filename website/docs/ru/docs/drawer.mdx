## Выбор подходящего компонента

Используйте `Drawer` для панели, закреплённой у края экрана, если её нужно открывать свайпом, перемещать между точками
привязки или использовать как нижнюю панель на мобильном устройстве. Выбирайте `Dialog`, если окно должно оставаться
по центру и его не нужно перетаскивать.

## Базовое использование

Соберите Drawer из структурных частей Ark и укажите их явно. В этом примере панель открывается на компактной точке
привязки, а затем её можно перетащить на полную высоту. `Drawer.Content` отвечает за интерактивную поверхность,
`Drawer.Positioner` размещает её, а `Drawer.Backdrop` добавляет модальный фон.

## Анатомия

```text
Drawer.Root
├─ Drawer.Trigger
├─ Drawer.SwipeArea (optional)
├─ Drawer.Backdrop
└─ Drawer.Positioner
   └─ Drawer.Content
      ├─ Drawer.Grabber
      │  └─ Drawer.GrabberIndicator
      ├─ Drawer.Title
      ├─ Drawer.Description
      └─ Drawer.CloseTrigger
```

| Часть                     | Назначение                                                   |
| ------------------------- | ------------------------------------------------------------ |
| `Drawer` / `Drawer.Root`  | Управляет состоянием, точками привязки и поведением панели.  |
| `Drawer.Trigger`          | Открывает панель.                                            |
| `Drawer.Backdrop`         | Модальный фон.                                               |
| `Drawer.Positioner`       | Размещает содержимое панели.                                 |
| `Drawer.Content`          | Интерактивная поверхность панели.                            |
| `Drawer.Grabber`          | Контейнер ручки для перетаскивания.                          |
| `Drawer.GrabberIndicator` | Визуальный индикатор внутри ручки.                           |
| `Drawer.CloseTrigger`     | Закрывает панель.                                            |
| `Drawer.SwipeArea`        | Необязательная область у края экрана для открытия свайпом.   |
| `Drawer.Stack`            | Координирует вложенные панели и поверхности с отступом.      |
| `Drawer.Indent`           | Поверхность, которая отодвигается при открытии панели из стека. |
| `Drawer.IndentBackground` | Фон за поверхностью с отступом.                              |
| `Drawer.Header`           | Необязательная часть для компоновки заголовка.               |
| `Drawer.Body`             | Необязательная гибкая область содержимого.                   |
| `Drawer.Footer`           | Необязательная часть для компоновки действий.                |
| `Drawer.CloseIcon`        | Стилизованная кнопка закрытия.                               |
| `Drawer.RootProvider`     | Подключает части к состоянию, созданному с помощью `useDrawer()`. |

`Drawer.Header`, `Drawer.Body`, `Drawer.Footer` и `Drawer.CloseIcon` - необязательные части moduix, которые помогают с
компоновкой и оформлением. Они не заменяют и не скрывают структурные части Ark.

## Композиция

Корневой компонент автоматически рендерит `Backdrop` и `Positioner` через портал. Панель, отрисованная в портале,
позиционируется относительно области просмотра, поэтому размер предпросмотра влияет только на триггер. Используйте
`portalled={false}`, чтобы отрисовать панель без портала, или `portalRef`, чтобы указать свой контейнер. Структурные
части остаются явными и поддерживают стилизацию.

### Рекомендуемая композиция

Используйте `Drawer` для управления состоянием и поведением. Явно отрендерите `Backdrop`, `Positioner` и `Content`,
затем поместите `Grabber` и `GrabberIndicator` внутрь `Content`, если при перетаскивании должна быть видна ручка.

Используйте `asChild`, чтобы объединить `Drawer.Trigger` или `Drawer.CloseTrigger` с `Button`. Дочерним элементом
должен быть один семантический элемент, который может получить фокус.

Колбэки Ark передают объект `details`:

- `onOpenChange(details)` → `details.open`
- `onSnapPointChange(details)` → `details.snapPoint`
- `onTriggerValueChange(details)` → `details.value` и `details.triggerElement`

### Когда нужна собственная композиция

Передавайте `className` напрямую любой экспортируемой части. Если состояние хранится снаружи, импортируйте `useDrawer`
из `@moduix/react` и подключите это состояние к `Drawer.RootProvider`. Не используйте `Drawer` и `Drawer.RootProvider`
для одного экземпляра. Для сложной композиции `@moduix/react` также экспортирует `useDrawerContext`,
`useDrawerStackContext` и `Drawer.Context`.

Объедините в `Drawer.Stack` поверхности, которые должны отступать вместе, затем отрендерите `Drawer.IndentBackground`
и `Drawer.Indent`.

### Свойства по умолчанию

По умолчанию содержимое оверлея в портале монтируется при необходимости и размонтируется после анимации закрытия.
Установите `unmountOnExit={false}`, чтобы оставить его смонтированным после первого открытия. Отключайте оба свойства
жизненного цикла только если содержимое нужно отрендерить сразу при загрузке.

| Свойство                 | По умолчанию | Примечания                                                        |
| ------------------------ | ------------ | ----------------------------------------------------------------- |
| `modal`                  | `true`       | Скрывает страницу и блокирует взаимодействие за пределами панели. |
| `swipeDirection`         | `"down"`     | По умолчанию открывает панель снизу.                              |
| `snapPoints`             | `[1]`        | Использует всю высоту, если точки привязки не заданы.             |
| `closeOnEscape`          | `true`       | Позволяет закрывать панель клавишей Escape.                       |
| `closeOnInteractOutside` | `true`       | Закрывает модальную панель при взаимодействии за её пределами.   |
| `preventDragOnScroll`    | `true`       | Не позволяет начинать перетаскивание из прокручиваемого содержимого. |
| `preventScroll`          | `true`       | Блокирует прокрутку фона, пока панель открыта.                    |
| `restoreFocus`           | `true`       | Возвращает фокус элементу, который был активен до открытия.       |
| `trapFocus`              | `true`       | Удерживает фокус внутри модального содержимого.                  |
| `lazyMount`              | `true`       | Значение по умолчанию в moduix, в Ark по умолчанию `false`.       |
| `unmountOnExit`          | `true`       | Значение по умолчанию в moduix, в Ark по умолчанию `false`.       |
| `Content draggable`      | `true`       | Ручка позволяет перетаскивать панель, даже если содержимое нельзя перетаскивать. |
| `closeThreshold`         | `0.25`       | Доля расстояния свайпа, необходимая для закрытия панели.         |
| `snapToSequentialPoints` | `false`      | Переходит между точками привязки по одному шагу.                  |
| `swipeVelocityThreshold` | `700`        | Порог скорости свайпа, при котором панель закрывается.            |
| `role`                   | `"dialog"`  | Установите `"alertdialog"` для срочного блокирующего содержимого. |

### Особенности поведения

- Публичные значения направления логические: `up`, `down`, `start` и `end`. Для стилизации Ark записывает в
  `data-swipe-direction` вычисленные физические значения `left` или `right`.
- `Content draggable={false}` отключает перетаскивание за содержимое, но оставляет ручку активной.
- `Content variant="island"` добавляет отступ от области просмотра, скругляет все углы содержимого и не даёт ему
  выходить за границу при перетаскивании. Это удобно для отдельной поверхности панели.
- `data-no-drag` запрещает начинать жест перетаскивания внутри заданного поддерева.
- Модальный фон остаётся полностью видимым, пока панель перемещается между точками привязки, и исчезает, когда начинается закрытие.
- `ids` настраивает идентификаторы доступности при композиции частей, расположенных отдельно.
- `stack` принимает внешнее хранилище стека панелей Ark, чтобы управлять визуализацией стека на уровне приложения.
- `immediate` и `skipAnimationOnMount` управляют монтированием и размонтированием панели в Ark, когда анимацией управляет приложение.
- `present`, `lazyMount`, `unmountOnExit` и `onExitComplete` управляют жизненным циклом рендера. В moduix параметры
  `lazyMount` и `unmountOnExit` по умолчанию равны `true`, чтобы анимации выхода успевали завершиться, а скрытые панели
  не рендерились при первой загрузке.
- При `prefers-reduced-motion: reduce` анимации появления, выхода и стека длятся 1 мс, но цикл жизни Ark завершается корректно.
- Ark сохраняет поведение диалога: удерживает фокус, обрабатывает Escape, связывает заголовок с описанием и возвращает фокус.

### Немодальный режим

Задайте `modal={false}`, если страница должна оставаться интерактивной и прокручиваемой при открытой панели. На
сенсорных устройствах отключите перетаскивание у `Content` и используйте `Header` в качестве `Grabber`. Тогда один
вертикальный жест не будет одновременно перемещать панель и страницу. Добавьте `data-no-drag` каждому интерактивному
элементу `Header`, например кнопке закрытия. Если перетаскиваться должно всё содержимое, задайте
`preventScroll={true}`. Внешние элементы управления останутся интерактивными, но прокрутка фона будет заблокирована,
пока панель открыта.

- Слоты moduix: `drawer-trigger`, `drawer-backdrop`, `drawer-positioner`, `drawer-content`,
