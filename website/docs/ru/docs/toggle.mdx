## Выбор подходящего компонента

Используйте `Toggle`, когда элемент управления должен работать как кнопка и показывать нажатое состояние.

- Выберите **`Toggle`** для добавления в избранное, сохранения элементов, форматирования и компактных действий на панели инструментов.
- Выберите **`Switch`** для настроек, которые включаются и выключаются и выглядят как отдельные пункты списка настроек.
- Выберите **`Checkbox`** для выбора значений в списке или форме с последующей отправкой.
- Выберите **`ToggleGroup`**, когда несколькими кнопками `Toggle` нужно управлять как единым набором вариантов.

## Анатомия

```text
Toggle / Toggle.Root
└─ Toggle.Indicator (необязательно)

Toggle.Context (читает состояние, но не создаёт часть DOM)
```

| Часть                     | Назначение                                                                |
| ------------------------- | ------------------------------------------------------------------------- |
| `Toggle` / `Toggle.Root`  | Корневая кнопка с двумя состояниями. Управляет состояниями нажатия, фокуса и отключения, а также композицией через `asChild`. |
| `Toggle.Indicator`        | Показывает содержимое в нажатом состоянии и необязательный `fallback`, когда кнопка не нажата.                      |
| `Toggle.Context`          | Читает состояние ближайшего `Toggle` для пользовательских потомков, но сам не создаёт элемент в DOM.              |

## Композиция

### Рекомендуемая композиция

Используйте `Toggle` как корневой компонент в обычном случае. Переданный `ref` указывает на кнопку, отрисованную Ark.
Компонент поддерживает `pressed`, `defaultPressed`, `onPressedChange(pressed)`, `disabled`, `asChild` и обычные
атрибуты кнопки.

`Toggle.Indicator` необязателен. Используйте его, если содержимое кнопки должно меняться в зависимости от того,
нажата она или нет.

### Когда нужна собственная композиция

Используйте `asChild`, если поведение `Toggle` нужно применить к другой кнопке. Передавайте одного
потомка, совместимого с кнопкой, чтобы Ark мог добавить ему необходимые свойства и поведение.

Если пользовательскому потомку нужно прочитать состояние, используйте `Toggle.Context` или `useToggleContext()` из
`@moduix/react/toggle`. Оба читают состояние ближайшего `Toggle` без прямого импорта Ark.

Вместо ручной координации отдельных `Toggle` используйте `ToggleGroup`, если несколько кнопок образуют один набор
вариантов.

### Свойства по умолчанию

| Свойство  | По умолчанию | Примечания                                                              |
| --------- | ------------ | ----------------------------------------------------------------------- |
| `variant` | `default`    | Визуальный стиль moduix: `default` с фоном вторичного цвета, `outline` с рамкой или прозрачный `ghost`. |
| `size`    | `md`         | Отступы для `Toggle` с текстом или квадратные размеры для `Toggle` только с иконкой.                    |

### Особенности поведения

- `Toggle` только с иконкой должен иметь доступное имя, например `aria-label="Favorite"`.
- `disabled` сохраняет текущее визуальное состояние, но предотвращает взаимодействие.
- Ark предоставляет атрибуты `data-state="on" | "off"`, `data-pressed` и `data-disabled` для стилизации.
- Ark Toggle не предоставляет `RootProvider` или скрытое поле формы.
- `Toggle.Context` и `useToggleContext()` доступны из `@moduix/react/toggle`.
- Устаревшие свойства `render` и `nativeButton` не входят в API на базе Ark, используйте `asChild`.
- `ref`, переданный в `Toggle` или `Toggle.Root`, указывает на отрисованную кнопку. В `Toggle.Indicator` `ref`
  указывает на отрисованный элемент индикатора.

## Стилизация

`Toggle` предоставляет стилизованный корневой элемент, необязательную часть `Indicator` и полный набор токенов
`--moduix-toggle-*` для вариантов, размеров, кольца фокуса, отступов и размера иконок.

### Хуки стилизации

- `data-slot="toggle-root"` - стабильный селектор корневого элемента.
- `data-slot="toggle-indicator"` - стабильный селектор для `Toggle.Indicator`.
- `data-scope="toggle"` и `data-part="root" | "indicator"` предоставляются Ark UI.
- `data-state="on" | "off"` отражает нажатое состояние корневого элемента и индикатора.
- `data-pressed` присутствует, когда `Toggle` нажат.
- `data-variant` отражает визуальный вариант moduix.
- `data-size` отражает размер moduix, включая `icon-sm`, `icon-md` и `icon-lg`.
- `data-disabled` управляет стилями отключённого состояния; Ark также сохраняет нативный атрибут `disabled`.
- Прямые дочерние иконки и иконки внутри `Toggle.Indicator` получают размер через
  `--moduix-toggle-icon-size`.
