## Справочник API

`Toggle` оборачивает примитив Toggle из Ark UI и добавляет визуальные свойства moduix для вариантов и размеров.
Импортируйте его из `@moduix/react/toggle` или `@moduix/solid/toggle`.

<PrimitiveReference href="https://ark-ui.com/docs/components/toggle" />

## Выбор подходящего компонента

Используйте `Toggle`, когда элемент управления должен работать как кнопка и показывать нажатое состояние.

- Выберите **`Toggle`** для добавления в избранное, сохранения элементов, форматирования и компактных действий на панели инструментов.
- Выберите **`Switch`** для настроек, которые включаются и выключаются и выглядят как отдельные пункты списка настроек.
- Выберите **`Checkbox`** для выбора значений в списке или форме с последующей отправкой.
- Выберите **`ToggleGroup`**, когда несколькими кнопками нужно управлять как единым набором вариантов.

## Анатомия

```text
Toggle / Toggle.Root
└─ Toggle.Indicator (необязательно)

Toggle.Context (читает состояние, но не создаёт часть DOM)
```

| Часть | Назначение |
| ----- | ---------- |
| `Toggle` / `Toggle.Root` | Корневая часть, которая управляет состоянием нажатия, фокусом, отключением и композицией через `asChild`. |
| `Toggle.Indicator` | Необязательная часть, которая показывает содержимое в нажатом состоянии и `fallback`, когда кнопка не нажата. |
| `Toggle.Context` | Читает состояние ближайшего `Toggle` для пользовательских потомков, но не создаёт часть DOM. |

## Композиция

`Toggle` является сокращённой формой `Toggle.Root`. Используйте `defaultPressed` для неконтролируемого
состояния или передавайте `pressed` вместе с `onPressedChange`, если значение хранится в состоянии приложения.
Используйте `Toggle.Indicator`, когда содержимое кнопки меняется вместе с состоянием нажатия. Для пользовательских
потомков, которым нужно это состояние, используйте `Toggle.Context` или `useToggleContext()` из соответствующего
пакета. Используйте `asChild`, если другая кнопка должна стать носителем поведения `Toggle`. В Solid `asChild` принимает
render-функцию, а в React один потомок, совместимый с кнопкой.

## Стилизация

Используйте `className` в React или `class` в Solid для структурных стилей экспортируемых частей. Варианты Tailwind
используют нативные утилиты и классы потребителя. Варианты с CSS Modules дополнительно предоставляют токены
`--moduix-toggle-*` для вариантов, размеров, кольца фокуса, отступов и размера иконок.

### Хуки стилизации

- Стабильные селекторы `data-slot`: `toggle-root` и `toggle-indicator`.
- Селекторы частей Ark UI: `data-scope="toggle"` и `data-part="root" | "indicator"`.
- Состояния Ark UI: `data-state="on" | "off"`, `data-pressed` и `data-disabled`.
- Селекторы moduix: `data-variant` и `data-size`, включая `icon-sm`, `icon-md` и `icon-lg`.
- Прямые дочерние иконки и иконки внутри `Toggle.Indicator` получают размер через
  `--moduix-toggle-icon-size` в варианте с CSS Modules.
