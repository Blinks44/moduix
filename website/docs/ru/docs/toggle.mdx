Используйте `Toggle` в обычном случае, сохраняя поведение Ark для состояния нажатия.

## Выбор подходящего компонента

Используйте `Toggle`, когда элемент управления должен работать как кнопка и показывать нажатое состояние.

- Выберите **`Toggle`** для добавления в избранное, сохранения элементов, форматирования и компактных действий на панели инструментов.
- Выберите **`Switch`** для настроек, которые включаются и выключаются и выглядят как отдельные пункты списка настроек.
- Выберите **`Checkbox`** для выбора значений в списке или форме с последующей отправкой.
- Выберите **`ToggleGroup`**, когда несколькими кнопками нужно управлять как единым набором вариантов.

## Композиция

`Toggle` оборачивает примитив Toggle из Ark UI и добавляет визуальные свойства moduix для вариантов и размеров.
Импортируйте его из `@moduix/react/toggle`, `@moduix/solid/toggle` или `@moduix/vue/toggle`.

Используйте `defaultPressed` для неконтролируемого состояния или передавайте `pressed` вместе с
`onPressedChange`, если значение хранится в состоянии приложения. Используйте `ToggleIndicator`, когда содержимое
кнопки меняется вместе с состоянием нажатия. Для пользовательских потомков, которым нужно это состояние,
используйте `ToggleContext` или `useToggleContext()` из соответствующего
пакета. Используйте `asChild`, если другая кнопка должна стать носителем поведения `Toggle`. В Solid `asChild` принимает
функцию рендера. В React передавайте один дочерний элемент, совместимый с кнопкой, а в Vue помещайте
такой элемент в слот по умолчанию.
В Vue используйте `v-model:pressed` для управляемого значения, именованный слот `fallback` с `ToggleIndicator` и слот
`ToggleContext`, если пользовательскому потомку нужно текущее состояние. Событие `@pressed-change`
передаёт новое булево значение, если вы хотите обработать изменение без привязки через `v-model:pressed`.

## Стилизация

Используйте `className` в React или `class` в Solid и Vue на экспортируемых частях. В пакетах с CSS Modules задавайте
цветовые переменные `--moduix-toggle-*` на переключателе, на `[data-slot='toggle-root'][data-variant='<variant>']`, чтобы
изменить один вариант, или на контейнере, например `ToggleGroup`. Размеры, отступы, скругление и типографика берутся из
токенов foundation; меняйте их классом. Пакеты Tailwind вместо этого используют нативные утилиты и классы потребителя.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `Toggle` | `toggle-root` |
| `ToggleIndicator` | `toggle-indicator` |

- Селекторы частей Ark UI: `data-scope="toggle"` и `data-part="root" | "indicator"`.
- Состояния Ark UI: `data-state="on" | "off"`, `data-pressed` и `data-disabled`.
- Селекторы moduix: `data-variant` и `data-size`, включая `icon-sm`, `icon-md` и `icon-lg`.
- Прямые дочерние иконки и иконки внутри `ToggleIndicator` по умолчанию 16px. Класс на иконке, например `size-5`
  в Tailwind, переопределяет этот размер.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `Enter` / `Space` | Переключает нажатое состояние. |

## Справочник API

| Проп | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `pressed` | `boolean` | — | Нажатое состояние в управляемом режиме. |
| `defaultPressed` | `boolean` | `false` | Начальное нажатое состояние. |
| `onPressedChange` | `(pressed: boolean) => void` | — | Вызывается с новым состоянием. |
| `variant` | `'default' \| 'outline' \| 'ghost'` | `'default'` | Вид: `default`, `outline` или `ghost`. |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'icon-sm' \| 'icon-md' \| 'icon-lg'` | `'md'` | `xs`, `sm`, `md`, `lg` или квадратные `icon-sm`, `icon-md`, `icon-lg`. |
| `disabled` | `boolean` | `false` | Отключает переключатель. |
| `asChild` | `boolean` | `false` | Переносит стили и поведение на единственный дочерний элемент. |
