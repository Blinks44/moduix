# Анимации

moduix предоставляет общие токены анимации для плавающего и модального содержимого. Задайте их один раз, чтобы
все поддерживаемые всплывающие панели использовали одну и ту же длительность и кривую, а также одинаковые эффекты
затухания, масштабирования или сдвига. Если одному компоненту нужна другая анимация, переопределите его локальные переменные.

Компоненты используют атрибуты `data-state` от Ark, чтобы выбирать анимации появления и исчезновения. Когда
содержимое закрывается, Ark оставляет его в DOM до завершения анимации исчезновения.

Общие токены `--moduix-duration-*`, `--moduix-ease-*`, `--moduix-transition-*` и `--moduix-scale-*` используются
во многих частях системы. Если во всём проекте нужно изменить только анимацию всплывающего содержимого, используйте
`--moduix-popup-motion-*`.

Если в операционной системе включён режим уменьшения движения, общие токены длительности меняются на `0.01ms`, а
общие анимации пульсации, затухания, сдвига и вращения отключаются. Компоненты с особой непрерывной анимацией,
например `Marquee` и `Progress` в состоянии `indeterminate`, обрабатывают `prefers-reduced-motion` отдельно.

## Выберите API анимации

### Общая анимация всплывающих панелей

Используйте `*-starting-*` для появления и `*-ending-*` для исчезновения. Общие переменные применяются к следующим
частям с именем `Content`: `Popover.Content`, `Menu.Content`, `Tooltip.Content`, `HoverCard.Content`, `FloatingPanel.Content`,
`Dialog.Content`, `CommandPalette.Content`, `Lightbox.Content`, `Tour.Content`, `NavigationMenu.Content`,
`Select.Content`, `Combobox.Content`, `DatePicker.Content` и `ColorPicker.Content`.

Например, так всё поддерживаемое содержимое появляется слева и уходит влево с одной кривой:

```css
:root {
  --moduix-popup-motion-duration: 220ms;
  --moduix-popup-motion-easing: cubic-bezier(0.22, 1, 0.36, 1);
  --moduix-popup-motion-starting-opacity: 0;
  --moduix-popup-motion-ending-opacity: 0;
  --moduix-popup-motion-starting-scale: 1;
  --moduix-popup-motion-ending-scale: 1;
  --moduix-popup-motion-starting-translate-x: -0.75rem;
  --moduix-popup-motion-ending-translate-x: -0.75rem;
}
```

Для всплывающих компонентов, которые обычно рендерятся через портал, задавайте переменные на `:root`. Если
переменная задана только на локальной обёртке, она не попадёт к содержимому, которое рендерится в `document.body`.
При `portalled={false}` такая переменная сработает и на локальной обёртке.

### Локальные переопределения

Переменные самого компонента имеют приоритет над общими значениями. Используйте их для локального исключения из
общего правила и добавляйте класс к визуальной части из таблицы. Компоненты, привязанные к триггеру, сохраняют
`transform-origin` Ark, поэтому рецепты с масштабированием по-прежнему раскрываются в сторону триггера.

| Поверхность | Применяйте класс к | Переменные анимации |
| --- | --- | --- |
| Popover | `Popover.Content` | `--moduix-popover-transition`, `--moduix-popover-content-*` |
| Menu | `Menu.Content` | `--moduix-menu-transition`, `--moduix-menu-popup-*` |
| Tooltip | `Tooltip.Content` | `--moduix-tooltip-transition`, `--moduix-tooltip-popup-*` |
| Hover Card | `HoverCard.Content` | `--moduix-hover-card-transition`, `--moduix-hover-card-content-*` |
| Floating Panel | `FloatingPanel.Content` | `--moduix-floating-panel-transition`, `--moduix-floating-panel-*` |
| Dialog | `Dialog.Content` | `--moduix-dialog-transition`, `--moduix-dialog-content-*` |
| Command Palette | `CommandPalette.Content` | `--moduix-command-palette-transition`, `--moduix-command-palette-content-*` |
| Lightbox | `Lightbox.Content` | `--moduix-lightbox-transition`, `--moduix-lightbox-content-*` |
| Tour | `Tour.Content` | `--moduix-tour-transition`, `--moduix-tour-content-*` |
| Navigation Menu | `NavigationMenu.Content` | `--moduix-navigation-menu-transition`, `--moduix-navigation-menu-content-*` |
| Select | `Select.Content` | `--moduix-select-transition`, `--moduix-select-content-*` |
| Combobox | `Combobox.Content` | `--moduix-combobox-transition`, `--moduix-combobox-content-*` |
| Date Picker | `DatePicker.Content` | `--moduix-date-picker-transition`, `--moduix-date-picker-content-*` |
| Color Picker | `ColorPicker.Content` | `--moduix-color-picker-transition`, `--moduix-color-picker-content-*` |

Если `NavigationMenu` использует `Viewport`, общие токены также влияют на размеры области и направленное движение
содержимого. Для настройки самой области используйте `--moduix-navigation-menu-viewport-*`.

`Dialog`, `CommandPalette`, `Lightbox` и `Tour` также предоставляют переменные `*-backdrop-*` для части `Backdrop`.
Фоны используют собственную переменную transition и анимируют только `opacity` и `blur`, без общих значений
масштаба и сдвига. Содержимое всплывающих панелей может анимировать `opacity`, `scale` и `translate-x` или
`translate-y`. Для размытия используйте CSS-фильтры, например `blur(4px)` или `none`.

### Анимация состояний

У этих компонентов отдельные системы анимации, поэтому они не принимают `--moduix-popup-motion-*`:

| Компонент | Визуальная часть | Поддерживаемая настройка |
| --- | --- | --- |
| Accordion | `Accordion.ItemContent` | `--moduix-accordion-item-content-transition`, `--moduix-accordion-item-content-open-opacity`, `--moduix-accordion-item-content-closed-opacity` |
| Collapsible | `Collapsible.Content` | `--moduix-collapsible-content-transition`, `--moduix-collapsible-content-open-opacity`, `--moduix-collapsible-content-closed-opacity` |
| Drawer | `Drawer.Content` и `Drawer.Backdrop` | `--moduix-drawer-transition`, `--moduix-drawer-backdrop-transition`; направление и перетаскивание управляют трансформацией |
| Swap | `Swap.Indicator` | `--moduix-swap-transition` и отдельные переменные opacity и scale для появления и исчезновения |
| Tree View | `TreeView.BranchContent` | `--moduix-tree-view-transition`, `--moduix-tree-view-content-transition-duration` |

`Toast` использует служебные переменные Ark для размещения уведомлений в стопке и закрытия. Не меняйте `--x`, `--y`,
`--scale`, `--height` и `--opacity`. Рецепты с этой страницы не относятся к API `Toast`.

## Готовые рецепты

Выбирайте анимацию по назначению и повторяйте один и тот же рецепт для похожих компонентов:

| Задача продукта | Начните с |
| --- | --- |
| Спокойное появление без намёка на направление | Затухание |
| Панель появляется с ближайшего края | Сдвиг в соответствующем направлении |
| Меню или средство выбора, привязанное к триггеру, открывается от него | Масштабирование или подъём |
| Короткое дружелюбное подтверждение | Мягкое появление, используйте умеренно |

Задайте эти переменные на `:root`, чтобы применить рецепт ко всему поддерживаемому содержимому всплывающих панелей. Для
одного исключения используйте переменные компонента из таблицы выше.

### Затухание

```css
:root {
  --moduix-popup-motion-starting-opacity: 0;
  --moduix-popup-motion-ending-opacity: 0;
  --moduix-popup-motion-starting-scale: 1;
  --moduix-popup-motion-ending-scale: 1;
  --moduix-popup-motion-starting-translate-y: 0;
  --moduix-popup-motion-ending-translate-y: 0;
}
```

### Сдвиг вверх

```css
:root {
  --moduix-popup-motion-starting-opacity: 0;
  --moduix-popup-motion-ending-opacity: 0;
  --moduix-popup-motion-starting-scale: 1;
  --moduix-popup-motion-ending-scale: 1;
  --moduix-popup-motion-starting-translate-y: 0.75rem;
  --moduix-popup-motion-ending-translate-y: 0.75rem;
}
```

### Сдвиг вниз

```css
:root {
  --moduix-popup-motion-starting-opacity: 0;
  --moduix-popup-motion-ending-opacity: 0;
  --moduix-popup-motion-starting-scale: 1;
  --moduix-popup-motion-ending-scale: 1;
  --moduix-popup-motion-starting-translate-y: -0.75rem;
  --moduix-popup-motion-ending-translate-y: -0.75rem;
}
```

### Сдвиг влево

```css
:root {
  --moduix-popup-motion-starting-opacity: 0;
  --moduix-popup-motion-ending-opacity: 0;
  --moduix-popup-motion-starting-scale: 1;
  --moduix-popup-motion-ending-scale: 1;
  --moduix-popup-motion-starting-translate-x: 0.75rem;
  --moduix-popup-motion-ending-translate-x: 0.75rem;
}
```

### Сдвиг вправо

```css
:root {
  --moduix-popup-motion-starting-opacity: 0;
  --moduix-popup-motion-ending-opacity: 0;
  --moduix-popup-motion-starting-scale: 1;
  --moduix-popup-motion-ending-scale: 1;
  --moduix-popup-motion-starting-translate-x: -0.75rem;
  --moduix-popup-motion-ending-translate-x: -0.75rem;
}
```

### Масштабирование

```css
:root {
  --moduix-popup-motion-starting-opacity: 0;
  --moduix-popup-motion-ending-opacity: 0;
  --moduix-popup-motion-starting-scale: 0.94;
  --moduix-popup-motion-ending-scale: 0.94;
}
```

### Подъём

```css

  --moduix-popup-motion-starting-opacity: 0;

  --moduix-popup-motion-ending-scale: 0.96;
  --moduix-popup-motion-starting-translate-y: 0.5rem;
```


```css

  --moduix-popup-motion-starting-opacity: 0;
  --moduix-popup-motion-ending-opacity: 0;

```

Используйте этот рецепт, чтобы добавить дружелюбный акцент короткому меню, `Tooltip` или окну подтверждения.

## Рецепты для компонентов

### Эффект стекла

Для модального фона добавьте первый класс к `Dialog.Backdrop`, а второй к `Dialog.Content`. Для других модальных
компонентов замените `dialog` на `command-palette`, `lightbox` или `tour`.

```css
.glassFocusBackdrop {
  --moduix-dialog-backdrop-transition: 220ms var(--moduix-ease-out);
  --moduix-dialog-backdrop-starting-opacity: 0;
  --moduix-dialog-backdrop-ending-opacity: 0;
  --moduix-dialog-backdrop-starting-blur: none;
  --moduix-dialog-backdrop-ending-blur: none;
}

.glassFocusContent {
  --moduix-dialog-transition: 220ms cubic-bezier(0.22, 1, 0.36, 1);
  --moduix-dialog-content-starting-opacity: 0;
  --moduix-dialog-content-ending-opacity: 0;
  --moduix-dialog-content-starting-scale: 0.96;
  --moduix-dialog-content-ending-scale: 0.98;
  --moduix-dialog-content-starting-translate-y: 0.75rem;
  --moduix-dialog-content-ending-translate-y: 0.75rem;
}
```

### Мягкое масштабирование

Этот рецепт добавляет мягкое масштабирование содержимому средства выбора. Добавьте класс к `Select.Content`. Для
`Combobox`, `ColorPicker` или `DatePicker` замените префикс `select` на `combobox`, `color-picker` или `date-picker`.

```css
.softScalePicker {
  --moduix-select-transition: 180ms cubic-bezier(0.22, 1, 0.36, 1);
  --moduix-select-content-closed-opacity: 0;
  --moduix-select-content-closed-scale: 0.96;
}
```

### Плавное раскрытие

Добавьте этот класс к `Accordion.ItemContent`. Для `Collapsible.Content` вместо него используйте префикс
`--moduix-collapsible-content-*`.

```css
.relaxedDisclosure {
  --moduix-accordion-item-content-transition: 240ms var(--moduix-ease-out);
  --moduix-accordion-item-content-closed-opacity: 0;
}
```

### Выразительная смена

Добавьте этот класс к `Swap.Indicator`, если уходящий элемент должен мягко отступить, а следующий появиться
заметнее.

```css
.emphasizedSwap {
  --moduix-swap-transition: 180ms cubic-bezier(0.22, 1, 0.36, 1);
  --moduix-swap-enter-starting-opacity: 0;
  --moduix-swap-enter-starting-scale: 0.82;
  --moduix-swap-exit-ending-opacity: 0;
  --moduix-swap-exit-ending-scale: 1.08;
}
```

## Правила использования

- Размещайте локальные переменные анимации на визуальной части, которая отвечает за анимацию. Общие переменные
  всплывающих панелей задавайте на `:root`, если оверлей по умолчанию рендерится через портал.
- Сохраняйте значения для появления и исчезновения симметричными, если асимметрия не задумана специально.
- Для чистого затухания или сдвига задавайте масштаб `1`.
- Используйте `--moduix-popup-motion-*` для общего правила во всём проекте. Локальные переменные компонента
  оставляйте для исключений.
- Не переопределяйте трансформации `Drawer` и служебные переменные раскладки `Toast`. Они связаны с состоянием
  взаимодействия и закрытия.
- Анимация исчезновения работает из коробки. Используйте `present`, только если JavaScript должен явно управлять
  наличием части в DOM. Обычным CSS-рецептам это не нужно.
