## Базовый пример

Компонент NumberInput доступен для React и Solid в вариантах с CSS Modules и Tailwind. Для CSS Modules импортируйте
его из `@moduix/react/number-input` или `@moduix/solid/number-input`, а для Tailwind CSS используйте соответствующие
пути `@moduix/react-tailwind/number-input` или `@moduix/solid-tailwind/number-input`. Визуальный предпросмотр на этой
странице использует пакет React CSS Modules, а вкладки показывают нативный исходный код для того же публичного API.

Используйте `NumberInput` как корневой компонент, а `NumberInput.Field` для стандартного поля с кнопками увеличения
и уменьшения значения. Задайте полю доступное имя с помощью `NumberInput.Label`, `aria-label` или `aria-labelledby`.

## Анатомия

```text
NumberInput / NumberInput.Root
├─ NumberInput.Label
├─ NumberInput.Scrubber (необязательно)
├─ NumberInput.Field (рекомендуемая короткая форма)
│  └─ отображает NumberInput.Control
│     ├─ NumberInput.DecrementTrigger
│     ├─ NumberInput.Input
│     └─ NumberInput.IncrementTrigger
└─ NumberInput.ValueText (необязательно)

NumberInput.RootProvider
└─ то же дерево частей, подключённое к состоянию, созданному с помощью `useNumberInput()`
```

| Часть | Назначение |
| --- | --- |
| `NumberInput` / `NumberInput.Root` | Управляет состоянием числового поля, разбором введённого значения, форматированием и поведением клавиатуры. |
| `NumberInput.RootProvider` | Подключает части к состоянию, созданному с помощью `useNumberInput()`. |
| `NumberInput.Context` | Предоставляет форматированное и числовое представление значения, а также императивные методы работы с состоянием. |
| `NumberInput.Label` | Доступная подпись управляемого поля. |
| `NumberInput.Scrubber` | Необязательная зона перетаскивания, которая изменяет значение при движении указателя. |
| `NumberInput.Control` | Объединяет поле ввода и кнопки увеличения и уменьшения значения. |
| `NumberInput.Field` | Удобная часть, которая отображает стандартный контрол и группу кнопок. |
| `NumberInput.DecrementTrigger` | Кнопка уменьшения текущего значения. Если дочерний элемент не задан, отображает значок минуса moduix. |
| `NumberInput.Input` | Редактируемое текстовое поле для числа под управлением Ark UI. |
| `NumberInput.IncrementTrigger` | Кнопка увеличения текущего значения. Если дочерний элемент не задан, отображает значок плюса moduix. |
| `NumberInput.ValueText` | Текстовый элемент только для чтения с форматированным значением. |

## Композиция

Используйте `NumberInput.Field` для стандартного контрола из трёх частей. Храните `value` и `defaultValue` в виде строк,
а в управляемом поле передавайте в состояние `details.value` из `onValueChange`. Если состояние нужно создать вне
дерева отображаемых частей, вызовите `useNumberInput()` и передайте соответствующее хранилище в
`NumberInput.RootProvider`. Не отображайте `NumberInput` или `NumberInput.Root` для того же хранилища. В React свойства
хранилища читаются напрямую, а в Solid через возвращаемый аксессор.

Используйте `NumberInput.Control` с отдельными частями, если нужно изменить порядок кнопок, значки или стили поля.
Добавляйте `NumberInput.Scrubber` рядом с полем для изменения значения перетаскиванием. Используйте
`NumberInput.Context` только когда другой элемент, например скрытое поле формы, должен получить форматированное или
числовое значение `valueAsNumber`.

## Стилизация

Используйте `className` в React или `class` в Solid для структурных стилей экспортируемых частей. Варианты Tailwind
используют нативные utility-классы и классы потребителя, а CSS-переменные ниже настраивают варианты CSS Modules.
Атрибуты данных и хуки `data-slot` общие для обоих вариантов стилизации.

### Хуки стилизации

- Стабильные селекторы `data-slot`: `number-input-root`, `number-input-root-provider`, `number-input-label`,
  `number-input-scrubber`, `number-input-control`, `number-input-decrement-trigger`, `number-input-input`,
  `number-input-increment-trigger` и `number-input-value-text`.
- Атрибуты состояния Ark: `data-disabled`, `data-invalid`, `data-focus` и `data-scrubbing`.
- Атрибуты частей Ark: `data-scope="number-input"` и значения `data-part`, соответствующие анатомии Ark.
