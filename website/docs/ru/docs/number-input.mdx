## Анатомия

```text
NumberInput.Root
├─ NumberInput.Label
├─ NumberInput.Scrubber (необязательно)
├─ NumberInput.Field (рекомендуемая короткая форма)
│  └─ отображает NumberInput.Control
│     ├─ NumberInput.DecrementTrigger
│     ├─ NumberInput.Input
│     └─ NumberInput.IncrementTrigger
└─ NumberInput.ValueText (необязательно)

NumberInput.RootProvider
└─ то же дерево частей, подключённое к состоянию, созданному с помощью `useNumberInput()`
```

| Часть | Назначение |
| ---------------------------------- | ---------------------------------------------------------------------- |
| `NumberInput` / `NumberInput.Root` | Управляет состоянием числового поля, разбором введённого значения, форматированием и поведением клавиатуры. |
| `NumberInput.RootProvider`         | Подключает части к состоянию, созданному с помощью `useNumberInput()`.                                      |
| `NumberInput.Context`              | Предоставляет форматированное и числовое представление значения, а также императивные методы работы с состоянием. |
| `NumberInput.Label`                | Подпись поля, которую используют вспомогательные технологии.                                                 |
| `NumberInput.Scrubber`             | Необязательная зона перетаскивания, которая изменяет значение при движении указателя.                        |
| `NumberInput.Control`              | Объединяет поле ввода и кнопки увеличения и уменьшения значения.                                               |
| `NumberInput.Field`                | Удобная часть, которая отображает стандартный `NumberInput.Control` и группу кнопок.                           |
| `NumberInput.DecrementTrigger`     | Уменьшает текущее значение. Если дочерний элемент не задан, по умолчанию отображает значок минуса moduix.     |
| `NumberInput.Input`                | Редактируемое текстовое поле для числа под управлением Ark UI.                                                |
| `NumberInput.IncrementTrigger`     | Увеличивает текущее значение. Если дочерний элемент не задан, по умолчанию отображает значок плюса moduix.   |
| `NumberInput.ValueText`            | Текстовый элемент только для чтения с форматированным значением.                                             |

## Композиция

### Рекомендуемая композиция

`NumberInput` обрабатывает введённое значение, проверяет границы, изменяет значение с клавиатуры, повторяет изменение,
пока кнопка удерживается, поддерживает перетаскивание и форматирование. Включайте `allowMouseWheel`, если в вашем
сценарии значение должно изменяться колёсиком мыши. Для стандартного набора частей используйте `NumberInput.Field`.

Задайте полю доступное имя с помощью `NumberInput.Label`, `aria-label` или `aria-labelledby`. Добавьте
`NumberInput.ValueText`, если форматированное значение нужно показывать не только внутри поля ввода.

Храните `value` и `defaultValue` в виде строк. Ark сообщает об изменениях через `onValueChange(details)`, где
`details.value` содержит строковое значение, а `details.valueAsNumber` - его числовое представление.

### Когда нужна собственная композиция

Используйте `NumberInput.Control` с отдельными частями, если стандартный `NumberInput.Field` не подходит из-за порядка
кнопок, значков или стилей поля. Добавьте `NumberInput.Scrubber` рядом с полем, если пользователи должны менять значение
перетаскиванием.

### Свойства по умолчанию

| Свойство                       | По умолчанию             | Назначение                                                               |
| ------------------------------ | ------------------------ | ------------------------------------------------------------------------ |
| `allowOverflow`                | `true`                   | Разрешает введённому значению выходить за `min` и `max`.                 |
| `clampValueOnBlur`             | `true`                   | Ограничивает значение до `min` или `max` при потере фокуса.              |
| `focusInputOnChange`           | `true`                   | Сохраняет фокус поля после изменения значения кнопкой.                   |
| `inputMode`                    | `'decimal'`              | Показывает подходящую для десятичных чисел клавиатуру на мобильных устройствах, где это поддерживается. |
| `largeStep`                    | `10 * step`              | Величина изменения при нажатии `Shift` вместе со стрелкой.              |
| `locale`                       | `'en-US'`                | Локаль, используемая для форматирования значения.                       |
| `max`                          | `Number.MAX_SAFE_INTEGER` | Максимальное значение.                                                   |
| `min`                          | `Number.MIN_SAFE_INTEGER` | Минимальное значение.                                                    |
| `spinOnPress`                  | `true`                   | Повторяет изменение, пока кнопка увеличения или уменьшения удерживается. |
| `step`                         | `1`                      | Величина, на которую значение изменяется за один шаг.                    |
| `smallStep`                    | `step / 10`              | Величина изменения при нажатии `Alt` вместе со стрелкой.                 |
| `NumberInput.Field`            | -                        | Отображает стандартные `NumberInput.Control`, поле ввода и группу кнопок. |
| `NumberInput.DecrementTrigger` | -                        | Отображает значок минуса moduix, если дочерний элемент не задан.         |
| `NumberInput.IncrementTrigger` | -                        | Отображает значок плюса moduix, если дочерний элемент не задан.          |

### Особенности поведения

- Используйте `formatOptions` вместе с `Intl.NumberFormat` для локализованного форматирования и отображения валюты. Если
  нужна другая локаль, задайте её через `locale`.
- Используйте `translations.incrementLabel`, `translations.decrementLabel` и `translations.valueText`, чтобы задать
  локализованные подписи для вспомогательных технологий и текст значения.
- Свойства `min`, `max`, `step`, `allowOverflow`, `clampValueOnBlur`, `spinOnPress`, `inputMode` и `allowMouseWheel`
  напрямую передаются Ark.
- `largeStep` задаёт изменение при нажатии `Shift` вместе со стрелкой, а `smallStep` - при нажатии `Alt` вместе со
  стрелкой. Клавиши `Home` и `End` устанавливают минимальное и максимальное значения.
- `onValueInvalid(details)` сообщает, что значение вышло за настроенные границы. В `details` причина указывается как
  `rangeUnderflow` или `rangeOverflow`.
- Установите `clampValueOnBlur={false}`, если введённое значение за пределами `min` или `max` должно оставаться без
  изменений после потери фокуса.
- `onValueCommit(details)` срабатывает, когда значение фиксируется при потере фокуса или после нажатия Enter.
  Используйте `onFocusChange`, чтобы отслеживать смену фокуса, а `ids` - если внешним подписям или описаниям нужны
  стабильные идентификаторы.
- Части Ark поддерживают `asChild`, чтобы использовать выбранный вами элемент. `NumberInput.Field` намеренно
  отображает фиксированную структуру из трёх частей и передаёт `ref` в `NumberInput.Control`.
- `useNumberInput`, `useNumberInputContext` и `NumberInput.Context` доступны из `@moduix/react`.
- `name` и `form` передаются видимому полю ввода с ролью `spinbutton` для нативной отправки формы. Добавляйте скрытый
  нативный input через `NumberInput.Context` с `context.valueAsNumber`, только если форме нужно числовое представление
  значения, а не отображаемая строка.
