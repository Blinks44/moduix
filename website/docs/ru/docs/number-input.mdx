## Выбор подходящего компонента

Используйте `NumberInput`, когда пользователи вводят числовые значения, требующие пошагового изменения,
ограничения диапазона и форматирования. Для произвольного текста используйте `Input`, а для выбора точки
на визуальном диапазоне - `Slider`.

## Базовый пример

Для CSS Modules импортируйте компонент из `@moduix/react/number-input`,
`@moduix/solid/number-input` или `@moduix/vue/number-input`. Для Tailwind CSS используйте соответствующие пути
`@moduix/react-tailwind/number-input`, `@moduix/solid-tailwind/number-input` или
`@moduix/vue-tailwind/number-input`.

Используйте `NumberInput` как корневой компонент, а `NumberInputField` для стандартного поля с кнопками увеличения
и уменьшения значения. Задайте полю доступное имя с помощью `NumberInputLabel`, `aria-label` или `aria-labelledby`.

## Анатомия

```text
NumberInput
├─ NumberInputLabel
├─ NumberInputScrubber (необязательно)
├─ NumberInputField (рекомендуемая короткая форма)
│  └─ отображает NumberInputControl
│     ├─ NumberInputDecrementTrigger
│     ├─ NumberInputInput
│     └─ NumberInputIncrementTrigger
└─ NumberInputValueText (необязательно)

NumberInputRootProvider
└─ то же дерево частей, подключённое к состоянию, созданному с помощью `useNumberInput()`
```

| Часть | Назначение |
| --- | --- |
| `NumberInput` | Управляет состоянием числового поля, разбором введённого значения, форматированием и поведением клавиатуры. |
| `NumberInputRootProvider` | Подключает части к состоянию, созданному с помощью `useNumberInput()`. |
| `NumberInputContext` | Предоставляет форматированное и числовое представление значения, а также императивные методы работы с состоянием. |
| `NumberInputLabel` | Доступная подпись управляемого поля. |
| `NumberInputScrubber` | Необязательная зона перетаскивания, которая изменяет значение при движении указателя. |
| `NumberInputControl` | Объединяет поле ввода и кнопки увеличения и уменьшения значения. |
| `NumberInputField` | Удобная часть, которая отображает стандартный контрол и группу кнопок. |
| `NumberInputDecrementTrigger` | Кнопка уменьшения текущего значения. Если дочерний элемент не задан, отображает значок минуса moduix. |
| `NumberInputInput` | Редактируемое текстовое поле для числа под управлением Ark UI. |
| `NumberInputIncrementTrigger` | Кнопка увеличения текущего значения. Если дочерний элемент не задан, отображает значок плюса moduix. |
| `NumberInputValueText` | Текстовый элемент только для чтения с форматированным значением. |

## Композиция

Используйте `NumberInputField` для стандартного контрола из трёх частей. Храните `value` и `defaultValue` в виде строк,
а в управляемом поле передавайте в состояние `details.value` из `onValueChange`. Если состояние нужно создать вне
дерева отображаемых частей, вызовите `useNumberInput()` и передайте соответствующее хранилище в
`NumberInputRootProvider`. Не отображайте `NumberInput` или `NumberInputRootProvider` для того же хранилища. В React свойства состояния читаются напрямую. В Solid вызывайте возвращаемую функцию доступа, а в Vue читайте реактивное состояние непосредственно в шаблоне.

Используйте `NumberInputControl` с отдельными частями, если нужно изменить порядок кнопок, значки или стили поля.
Добавляйте `NumberInputScrubber` рядом с полем для изменения значения перетаскиванием. Используйте
`NumberInputContext` только когда другой элемент, например скрытое поле формы, должен получить форматированное или
числовое значение `valueAsNumber`.

## Примеры

### Управляемое состояние

Храните управляемое состояние в виде строки и используйте `details.value` в `onValueChange`.

<Example name="number-input/controlled" />

### Отключённое состояние и только для чтения

Используйте `disabled`, чтобы запретить любое взаимодействие. Используйте `readOnly`, если значение должно оставаться
доступным для выбора, но не должно редактироваться.

<Example name="number-input/disabled-and-read-only" />

### Field

Используйте `Field`, если состояние формы, вспомогательный и текст ошибки, а также метаданные доступности должны быть
общими для поля.

<Example name="number-input/field" />

### Форматирование

Передайте `formatOptions`, чтобы форматировать отображаемое значение с помощью `Intl.NumberFormat`.

<Example name="number-input/formatting" />

### Минимум и максимум

Используйте `min`, `max` и `step`, чтобы задать диапазон и шаг изменений с клавиатуры, кнопками и скраббером. По
умолчанию значение ограничивается при потере фокуса. Установите `clampValueOnBlur={false}`, если введённое значение
за пределами диапазона должно оставаться видимым после потери фокуса.

<Example name="number-input/min-and-max" />

### Колесо мыши

Включайте `allowMouseWheel`, если изменение значения колёсиком мыши подходит вашему сценарию.

<Example name="number-input/mouse-wheel" />

### Нативная отправка формы

Задайте `name`, чтобы включить видимое текстовое поле со смыслом `spinbutton` в отправку нативной формы. `NumberInput`
отправляет отображаемое строковое значение. Используйте `NumberInputContext` для второго скрытого поля только если
форме нужно числовое представление значения.

<Example name="number-input/form-submission" />

### Точность

Используйте `formatOptions` с `Intl.NumberFormatOptions`, если для отображаемого значения нужно фиксированное число
знаков после запятой.

<Example name="number-input/precision" />

### Root Provider

Используйте `useNumberInput()` с `NumberInputRootProvider`, если состояние нужно создать вне дерева отображаемых частей.

<Example name="number-input/root-provider" />

### Изменение перетаскиванием

Перетаскивайте `NumberInputScrubber` влево или вправо, чтобы изменить значение.

<Example name="number-input/scrubbing" />

### Размеры

Проп `size` на корне задаёт высоту и размер текста, как у `Input`. По умолчанию `md`.

<Example name="number-input/sizes" />

### Текст значения

Используйте `NumberInputValueText`, если форматированное значение нужно показывать не только в редактируемом поле.

<Example name="number-input/value-text" />

### Расширенная настройка

Соберите низкоуровневые части вместо `NumberInputField`, если нужно изменить значки кнопок или стили поля. Передайте
`translations`, если собственное содержимое кнопок требует локализованных подписей для вспомогательных технологий.

## Стилизация

Используйте `className` в React или `class` в Solid и Vue для структурных стилей экспортируемых частей. Варианты Tailwind
используют нативные utility-классы и классы потребителя, а CSS-переменные ниже настраивают варианты CSS Modules.
Атрибуты данных и хуки `data-slot` общие для обоих вариантов стилизации.

### CSS-свойства

### Хуки стилизации

- Стабильные селекторы `data-slot`: `number-input-root`, `number-input-root-provider`, `number-input-label`,
  `number-input-scrubber`, `number-input-control`, `number-input-decrement-trigger`, `number-input-input`,
  `number-input-increment-trigger` и `number-input-value-text`.
- Атрибуты состояния Ark: `data-disabled`, `data-invalid`, `data-focus` и `data-scrubbing`.
- Атрибуты частей Ark: `data-scope="number-input"` и значения `data-part`, соответствующие анатомии Ark.
