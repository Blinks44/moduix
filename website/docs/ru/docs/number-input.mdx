## Анатомия

```text
NumberInput.Root
├─ NumberInput.Label
├─ NumberInput.Scrubber (необязательно)
├─ NumberInput.Field (рекомендуется)
├─ NumberInput.Control
│  ├─ NumberInput.DecrementTrigger
│  ├─ NumberInput.Input
│  └─ NumberInput.IncrementTrigger
└─ NumberInput.ValueText (необязательно)

NumberInput.RootProvider
└─ то же дерево частей, подключённое к состоянию, созданному с помощью `useNumberInput()`
```

| Часть | Назначение |
| ---------------------------------- | ---------------------------------------------------------------------- |
| `NumberInput` / `NumberInput.Root` | Управляет состоянием числового поля, разбором введённого значения, форматированием и поведением клавиатуры. |
| `NumberInput.RootProvider`         | Подключает части к состоянию, созданному с помощью `useNumberInput()`.                                      |
| `NumberInput.Context`              | Предоставляет форматированное и числовое представление значения, а также императивные методы работы с состоянием. |
| `NumberInput.Label`                | Доступная подпись, связанная с полем, которым управляет компонент.                                           |
| `NumberInput.Scrubber`             | Необязательная зона перетаскивания, которая изменяет значение при движении указателя.                        |
| `NumberInput.Control`              | Контейнер для поля и кнопок увеличения и уменьшения значения.                                                |
| `NumberInput.Field`                | Отображает стандартный `Control`, поле ввода и группу кнопок.                                                  |
| `NumberInput.DecrementTrigger`     | Кнопка, уменьшающая текущее значение. Если дочерний элемент не задан, по умолчанию отображает значок минуса moduix. |
| `NumberInput.Input`                | Редактируемое текстовое поле для числа под управлением Ark UI.                                                |
| `NumberInput.IncrementTrigger`     | Кнопка, увеличивающая текущее значение. Если дочерний элемент не задан, по умолчанию отображает значок плюса moduix. |
| `NumberInput.ValueText`            | Текстовый элемент только для чтения с форматированным значением.                                             |

## Композиция

### Рекомендуемая композиция

`NumberInput` обрабатывает разбор значения, проверку диапазона, изменение значения с клавиатуры, повторное изменение
при удержании кнопки, перетаскивание и форматирование. Включайте `allowMouseWheel`, если изменение значения колёсиком
мыши нужно в вашем сценарии. Для стандартного набора видимых частей используйте `NumberInput.Field`.

Передавайте `value` и `defaultValue` как строки. Ark сообщает об изменениях через `onValueChange(details)`, где
`details.value` содержит строковое значение, а `details.valueAsNumber` - число после разбора.

### Когда нужна собственная композиция

Используйте `NumberInput.Control` с отдельными частями, если нужно изменить порядок кнопок, значки или стили поля
по сравнению со стандартным `NumberInput.Field`. Добавьте `NumberInput.Scrubber` рядом с полем, чтобы менять значение
перетаскиванием.

### Свойства по умолчанию

| Свойство | По умолчанию | Примечания |
| ---------------------------------- | ------- | ------------------------------------------------------------ |
| `NumberInput` / `NumberInput.Root` | - | Дополнительных настроек поведения нет, применяются значения Ark по умолчанию. |
| `NumberInput.Field` | - | Отображает стандартные `Control`, поле ввода и группу кнопок. |
| `NumberInput.DecrementTrigger` | - | Отображает значок минуса moduix, если дочерний элемент не задан. |
| `NumberInput.IncrementTrigger` | - | Отображает значок плюса moduix, если дочерний элемент не задан. |

### Особенности поведения

- Для форматирования локализованных чисел используйте `formatOptions`, а не `format`.
- Используйте `translations.incrementLabel`, `translations.decrementLabel` и `translations.valueText`, чтобы задать доступные подписи на нужном языке.
- `min`, `max`, `step`, `allowOverflow`, `clampValueOnBlur`, `spinOnPress`, `inputMode` и `allowMouseWheel` передаются в Ark без изменений.
- `onValueInvalid(details)` сообщает `rangeUnderflow` или `rangeOverflow`, когда значение превышает настроенные границы.
- Установите `clampValueOnBlur={false}`, если введённые значения за пределами `min` или `max` должны оставаться неизменными при потере фокуса.
- Используйте `ids`, когда внешним меткам или описаниям требуются стабильные идентификаторы элементов.
- Части Ark поддерживают `asChild` для использования собственного элемента. `NumberInput.Field` намеренно
  отображает фиксированную структуру из трёх частей и передаёт `ref` в `NumberInput.Control`.
- `useNumberInput`, `useNumberInputContext` и `NumberInput.Context` экспортируются из `@moduix/react`.
- `name` и `form` передаются видимому числовому полю с ролью `spinbutton` для нативной отправки формы. Рендерьте скрытый
  нативный input через `NumberInput.Context` с `context.valueAsNumber`, только если форме нужно числовое значение
  после разбора, а не отображаемая строка.
