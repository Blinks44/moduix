Используйте `NumberInput` как корневой компонент, а `NumberInputField` для стандартного поля с кнопками увеличения
и уменьшения значения. Задайте полю доступное имя с помощью `NumberInputLabel`, `aria-label` или `aria-labelledby`.

## Выбор подходящего компонента

Используйте `NumberInput`, когда пользователи вводят числовые значения, требующие пошагового изменения,
ограничения диапазона и форматирования. Для произвольного текста используйте `Input`, а для выбора точки
на визуальном диапазоне - `Slider`.

Используйте `Field`, если состояние формы, вспомогательный и текст ошибки, а также метаданные доступности должны быть
общими для поля.

<Example name="number-input/field" />

### Форматирование

Передайте `formatOptions`, чтобы форматировать отображаемое значение с помощью `Intl.NumberFormat`.

<Example name="number-input/formatting" />

### Минимум и максимум

Используйте `min`, `max` и `step`, чтобы задать диапазон и шаг изменений с клавиатуры, кнопками и скраббером. По
умолчанию значение ограничивается при потере фокуса. Установите `clampValueOnBlur={false}`, если введённое значение
за пределами диапазона должно оставаться видимым после потери фокуса.

<Example name="number-input/min-and-max" />

### Колесо мыши

Включайте `allowMouseWheel`, если изменение значения колёсиком мыши подходит вашему сценарию.

<Example name="number-input/mouse-wheel" />

### Нативная отправка формы

Задайте `name`, чтобы включить видимое текстовое поле со смыслом `spinbutton` в отправку нативной формы. `NumberInput`

форме нужно числовое представление значения.

### Точность

Используйте `formatOptions` с `Intl.NumberFormatOptions`, если для отображаемого значения нужно фиксированное число

## Композиция

Используйте `NumberInputField` для стандартного контрола из трёх частей. Храните `value` и `defaultValue` в виде строк,
а в управляемом поле передавайте в состояние `details.value` из `onValueChange`. Если состояние нужно создать вне
дерева отображаемых частей, вызовите `useNumberInput()` и передайте соответствующее хранилище в
`NumberInputRootProvider`. Не отображайте `NumberInput` или `NumberInputRootProvider` для того же хранилища. В React свойства состояния читаются напрямую. В Solid вызывайте возвращаемую функцию доступа, а в Vue читайте реактивное состояние непосредственно в шаблоне.

Используйте `NumberInputControl` с отдельными частями, если нужно изменить порядок кнопок, значки или стили поля.
Добавляйте `NumberInputScrubber` рядом с полем для изменения значения перетаскиванием. Используйте
`NumberInputContext` только когда другой элемент, например скрытое поле формы, должен получить форматированное или
числовое значение `valueAsNumber`.

## Стилизация

Используйте `className` в React или `class` в Solid и Vue для структурных стилей экспортируемых частей. Варианты Tailwind
используют нативные utility-классы и классы потребителя, а CSS-переменные ниже настраивают варианты CSS Modules.
Атрибуты данных и хуки `data-slot` общие для обоих вариантов стилизации.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `ArrowUp` / `ArrowDown` | Увеличивает или уменьшает на шаг. |
| `Shift` + arrows | Меняет на большой шаг, по умолчанию 10 шагов. |
| `Home` / `End` | Ставит минимум или максимум. |
| `Enter` | Подтверждает введённое значение. |
