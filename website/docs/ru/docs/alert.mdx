## Справочник API

В Ark UI нет отдельного примитива `alert`. moduix собирает `Alert` с помощью официальной
[фабрики Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory), следуя рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[работе с ref](https://ark-ui.com/docs/guides/ref).

Импортируйте `Alert` из `@moduix/react/alert`. Вызов `Alert` и обращение к `Alert.Root` дают одну и
ту же корневую часть. Остальные публичные части: `Alert.Indicator`, `Alert.Content`, `Alert.Title`,
`Alert.Description` и `Alert.Actions`.

Каждая часть принимает стандартные свойства своего HTML-элемента, включая `className` и `asChild`,
а переданный ref указывает на отрисованный элемент.

## Выбор подходящего компонента

Используйте `Alert`, если сообщение должно входить в разметку страницы и занимать место в обычном
потоке документа.

- Используйте **`Alert`** для встроенных обновлений статуса, результатов проверки и системной обратной связи в формах, панелях или содержимом страницы.
- Используйте **`Toast`** для временных уведомлений, которые отображаются поверх страницы, не занимают место в потоке документа и закрываются автоматически.

## Анатомия

Для компактного сообщения поместите `Alert.Title` и `Alert.Description` прямо в корневой элемент.
Если рядом с индикатором нужно сгруппировать текст и элементы управления, поместите их в
`Alert.Content`.

```text
Alert / Alert.Root
├─ Alert.Indicator (optional)
├─ Alert.Title
├─ Alert.Description
└─ Alert.Content (optional)
   ├─ Alert.Title
   ├─ Alert.Description
   ├─ Alert.Actions (optional)
   └─ Extra custom blocks
```

| Часть                  | Назначение                                                               | `data-part`   |
| ---------------------- | ------------------------------------------------------------------------ | ------------- |
| `Alert` / `Alert.Root` | Корневой элемент. Применяет стили статуса и автоматически задаёт семантику области обновлений. | `root`        |
| `Alert.Indicator`      | Необязательный визуальный ориентир. Вложенные SVG-иконки получают единый размер. | `indicator`   |
| `Alert.Content`        | Необязательная колонка для группировки текста и действий.                | `content`     |
| `Alert.Title`          | Заголовок сообщения. По умолчанию рендерится как `p`.                     | `title`       |
| `Alert.Description`    | Дополнительный текст сообщения.                                           | `description` |
| `Alert.Actions`        | Необязательная строка действий с переносом внутри `Content`.              | `actions`     |

## Композиция

### Рекомендуемая композиция

Для обычного встроенного сообщения составьте `<Alert>` из `Alert.Title` и `Alert.Description`.

С помощью `status` выберите тип сообщения: `info`, `success`, `warning` или `error`.

Добавьте `Alert.Indicator`, если нужен явный визуальный ориентир. Действия остаются обычным
содержимым: поместите их в `Alert.Content`. Компонент не создаёт кнопки и специальные слоты для
действий.

### Когда нужна собственная композиция

Добавьте `Alert.Content`, если заголовок, описание и дополнительные элементы управления должны
оставаться в одной колонке рядом с индикатором. Используйте `Alert.Actions` для строки действий с
переносом внутри этой колонки. При использовании `asChild` передайте ровно один семантически
подходящий дочерний элемент, который будет отвечать за отрисованный DOM-узел.

Если в структуре заголовков документа нужен другой элемент, используйте `Alert.Title asChild`:

```tsx
<Alert.Title asChild>
  <h2>Billing issue</h2>
</Alert.Title>
```

### Свойства по умолчанию

| Свойство | По умолчанию | Значения и примечания                                             |
| -------- | ------------ | ----------------------------------------------------------------- |
| `status` | `info`       | `info`, `success`, `warning`, `error`                             |
| `role`   | Автоматически | По умолчанию `role="status"`; при `status="error"` используется `role="alert"` |

### Особенности поведения

- `Alert.Root` по умолчанию использует `role="status"` и переключается на `role="alert"` при `status="error"`.
- `role="status"` обычно сообщает об обновлении ненавязчиво, а `role="alert"` объявляет его сразу. Если сообщение должно быть озвучено, сначала добавьте `Alert` в документ, а затем обновите его текст. Текст, присутствующий уже при загрузке страницы, может не быть озвучен.
- Переопределите `role`, если `Alert` служит статическим информационным блоком, а не сообщает об изменении. Для второстепенной статической информации используйте `role="note"`.
- Для `Alert.Indicator` по умолчанию задано `aria-hidden="true"`.
- Основной смысл сообщения должен быть в заголовке или описании, поскольку индикатор скрыт от вспомогательных технологий.
- `Alert.Title` по умолчанию рендерится как `p`. Используйте `asChild` из Ark, если заголовку нужен другой HTML-элемент.
- `Alert.Content` необязателен. Используйте его, если заголовок, описание и дополнительные элементы управления должны находиться в одной колонке рядом с индикатором.
- `Alert.Actions` необязателен. Используйте его, если кнопки или ссылки должны использовать стандартные стили строки действий с переносом.
- Компонент отвечает только за отображение. Он не управляет состоянием закрытия, фокусом и поведением клавиатуры для действий, которые вы в него добавляете.

## Стилизация

Используйте `className` на корневой части или отдельных частях для локальных стилей. Задавайте
переменные `--moduix-alert-*` на корневом элементе, если уведомлению нужна локальная тема.

Общие переменные `--moduix-alert-bg`, `--moduix-alert-border-color`, `--moduix-alert-color` и
`--moduix-alert-indicator-color` действуют для всех статусов. Используйте соответствующие
переменные `--moduix-alert-<status>-*`, если нужно изменить только один статус.

Встроенные статусы также используют общие токены палитры:

| Статус    | Общий токен                  | По умолчанию                 |
| --------- | ---------------------------- | ---------------------------- |
| `info`    | `--moduix-color-card`        | карточная поверхность темы   |
| `success` | `--moduix-color-success`     | `oklch(0.627 0.194 149.214)` |
| `warning` | `--moduix-color-warning`     | `oklch(0.795 0.184 86.047)`  |
| `error`   | `--moduix-color-destructive` | деструктивный цвет темы      |

### Селекторы для стилизации

- Стабильные селекторы `data-slot`: `alert-root`, `alert-indicator`, `alert-content`, `alert-title`, `alert-description` и `alert-actions`
- Селекторы в стиле Ark: `data-scope="alert"` с `data-part="root"`, `indicator`, `content`, `title`, `description` или `actions`
- `Alert.Root` записывает выбранный статус в `data-status`
