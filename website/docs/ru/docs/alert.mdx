## Справочник API

В Ark UI нет отдельного примитива `alert`. moduix собирает `Alert` с помощью официальной
[фабрики Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory), следуя рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[работе с ref](https://ark-ui.com/docs/guides/ref).

Импортируйте `Alert` из `@moduix/react/alert`, `@moduix/solid/alert` или `@moduix/vue/alert`.
`Alert` — корневая часть. Остальные публичные части: `AlertIndicator`, `AlertContent`,
`AlertTitle`, `AlertDescription` и `AlertActions`.

Каждая часть принимает стандартные свойства своего HTML-элемента, включая `className`/`class` и
`asChild`, а переданный ref указывает на отрисованный элемент. По умолчанию `status` равен `info` и
влияет только на визуальное оформление. Добавьте `role="status"` или `role="alert"`, если сообщение,
которое добавляется или обновляется динамически, должно стать live-областью. `AlertIndicator` скрыт
от вспомогательных технологий, поэтому основной смысл сообщения должен быть в заголовке или описании.

## Выбор подходящего компонента

Используйте `Alert`, если сообщение должно входить в разметку страницы и занимать место в обычном
потоке документа.

- Используйте **`Alert`** для встроенных обновлений статуса, результатов проверки и системной обратной связи в формах, панелях или содержимом страницы.
- Используйте **`Toast`** для временных уведомлений, которые отображаются поверх страницы, не занимают место в потоке документа и закрываются автоматически.

## Анатомия

Поместите содержимое сообщения в `AlertContent`. `AlertIndicator` необязателен и располагается
рядом с этим содержимым, когда помогает быстрее понять тип сообщения.

```text
Alert
├─ AlertIndicator (optional)
└─ AlertContent
   ├─ AlertTitle
   ├─ AlertDescription
   ├─ AlertActions (optional)
   └─ Extra custom blocks
```

| Часть              | Назначение                                                               | `data-part`   |
| ------------------ | ------------------------------------------------------------------------ | ------------- |
| `Alert`            | Корневой элемент. Применяет стили статуса.                                 | `root`        |
| `AlertIndicator`   | Необязательный визуальный ориентир. Вложенные SVG-иконки получают единый размер. | `indicator`   |
| `AlertContent`     | Обязательная колонка для содержимого сообщения и действий.                | `content`     |
| `AlertTitle`       | Заголовок сообщения. По умолчанию рендерится как `p`.                     | `title`       |
| `AlertDescription` | Дополнительный текст сообщения.                                           | `description` |
| `AlertActions`     | Необязательная строка действий с переносом внутри `Content`.              | `actions`     |

## Композиция

`Alert` отвечает только за отображение: компонент, который его рендерит, владеет состоянием видимости
и закрытия. `Alert` не управляет фокусом и поведением клавиатуры для кнопок и ссылок, которые вы в него
помещаете. `AlertContent` обязателен: он содержит заголовок, описание, элементы управления и другое
содержимое сообщения. Для стандартной строки действий с переносом поместите элементы управления в
`AlertActions`.

Если заголовку нужен другой семантический элемент, используйте `AlertTitle asChild` и передайте ровно
один семантически подходящий дочерний элемент. В Solid для `asChild` используется функция рендера - она
показана в примере «Другой уровень заголовка». Во Vue используется атрибут `as-child` с одним дочерним
элементом.

## Стилизация

Используйте `className` или `class` на корневой части и её частях для локальных стилей. Варианты на
Tailwind настраиваются обычными утилитами и пользовательскими классами. В вариантах с CSS Modules
задавайте переменные `--moduix-alert-*` на корневом элементе, если уведомлению нужна локальная тема.

В CSS Modules общие переменные `--moduix-alert-bg`, `--moduix-alert-border-color`,
`--moduix-alert-color` и `--moduix-alert-indicator-color` действуют для всех статусов. Используйте
соответствующие переменные `--moduix-alert-<status>-*`, если нужно изменить только один статус.

Встроенные статусы также используют общие токены палитры:

| Статус    | Общий токен                  | По умолчанию                 |
| --------- | ---------------------------- | ---------------------------- |
| `info`    | `--moduix-color-card`        | карточная поверхность темы   |
| `success` | `--moduix-color-success`     | `oklch(0.627 0.194 149.214)` |
| `warning` | `--moduix-color-warning`     | `oklch(0.795 0.184 86.047)`  |
| `error`   | `--moduix-color-destructive` | деструктивный цвет темы      |

### Селекторы для стилизации

- Стабильные селекторы `data-slot`: `alert-root`, `alert-indicator`, `alert-content`, `alert-title`, `alert-description` и `alert-actions`
- Селекторы в стиле Ark: `data-scope="alert"` с `data-part="root"`, `indicator`, `content`, `title`, `description` или `actions`
- `Alert` записывает выбранный статус в `data-status`
