## Базовый пример

Используйте `Steps` с параметром `count`, списком `Steps.List`, элементом `Steps.Item` для каждого шага,
соответствующими панелями `Steps.Content` и встроенными кнопками перехода назад и вперёд. Индексы шагов
начинаются с нуля. Например, при `count={3}` используйте индексы `0`, `1` и `2`. Когда значение шага
достигает `count`, показывается `Steps.CompletedContent`.

Экспорт `Steps` по умолчанию является корневым компонентом. Используйте `Steps.Root`, если хотите явно указать
имя корневой части.

## Анатомия

```text
Steps
├─ Steps.Progress (необязательно)
├─ Steps.List
│  └─ Steps.Item[index]
│     ├─ Steps.Trigger
│     │  └─ Steps.Indicator
│     └─ Steps.Separator
├─ Steps.Content[index]
├─ Steps.CompletedContent
├─ Steps.PrevTrigger
└─ Steps.NextTrigger

Steps.RootProvider
└─ то же дерево частей, подключённое к состоянию Steps.useSteps()
```

| Часть                              | Назначение                                                                           |
| ---------------------------------- | ------------------------------------------------------------------------------------ |
| `Steps` / `Steps.Root`           | Управляет состоянием шагов, ориентацией, навигацией, валидацией и ID.                 |
| `Steps.RootProvider`               | Подключает части к состоянию, созданному с помощью `Steps.useSteps()`.                |
| `Steps.Progress`                   | Необязательная визуальная полоса прогресса на основе корневой переменной Ark `--percent`. |
| `Steps.List`                       | Список вкладок с триггерами шагов.                                                    |
| `Steps.Item`                       | Элемент шага с обязательным индексом, отсчитываемым от нуля.                          |
| `Steps.Trigger`                    | Триггер вкладки для шага; поддерживает `asChild` для пользовательских семантических элементов. |
| `Steps.Indicator`                  | Визуальный маркер шага. По умолчанию показывает `index + 1` или иконку галочки после завершения. |
| `Steps.Separator`                  | Декоративный соединитель между шагами.                                              |
| `Steps.Content`                    | Панель содержимого шага, сопоставленная по `index`.                                 |
| `Steps.CompletedContent`           | Панель, которая показывается, когда текущее значение шага равно `count`.             |
| `Steps.PrevTrigger` / `NextTrigger` | Кнопки, вызывающие встроенные действия Ark для перехода назад и вперёд.              |

Используйте `Steps.useSteps()` с `Steps.RootProvider`, если состояние нужно создать за пределами дерева частей
`Steps`. `useStepsContext`, `useStepsItemContext`, `Steps.Context` и `Steps.ItemContext` также экспортируются из
`@moduix/react` как низкоуровневые API в стиле Ark.

## Композиция

### Рекомендуемая композиция

`Steps` управляет машиной состояний. Передавайте корневому компоненту `count`, `defaultStep`, `step`,
`onStepChange(details)`, `onStepComplete`, `linear`, `isStepValid`, `isStepSkippable`, `onStepInvalid(details)`,
`orientation` и `ids`. Для каждого элемента и панели используйте соответствующие индексы, отсчитываемые от нуля.
Активные шаги имеют индексы от `0` до `count - 1`, а значение `count` означает завершение процесса.

Используйте `Steps.RootProvider` вместе с `Steps.useSteps()`, когда элементам управления за пределами дерева
`Steps` нужно работать с тем же состоянием. Возвращаемый объект предоставляет `value`, `setStep`,
`goToNextStep`, `goToPrevStep`, `resetStep`, `percent` и `getItemState` для чтения состояния элементов. Не используйте
`Steps.Root` и `Steps.RootProvider` для одного и того же состояния.

### Когда нужна собственная композиция

Используйте `asChild` на `Steps.Trigger`, `Steps.PrevTrigger` или `Steps.NextTrigger`, когда вместо стандартной
кнопки нужна ссылка, ссылка из роутера или кнопка вашей дизайн-системы. Передавайте ровно один семантический
дочерний элемент, чтобы Ark мог добавить ему ARIA-свойства, поведение клавиатуры и поддержку фокуса.

У `Steps.Indicator` есть одно дополнение moduix: если у него нет содержимого, он показывает `index + 1` для
незавершённых и текущего шагов, а для завершённых шагов использует общую иконку галочки. Передайте содержимое,
чтобы полностью управлять маркером.

### Свойства по умолчанию

| Свойство      | По умолчанию | Примечания                                                                                 |
| ------------- | ------------ | ------------------------------------------------------------------------------------------ |
| `orientation` | `horizontal` | Ориентация корневого компонента. Для вертикальной навигации по шагам используйте `vertical`. |
| `linear`      | `false`      | Задайте `true`, чтобы пользователь проходил шаги по порядку, не переходя к произвольным шагам. |
| `count`       | `1`          | Общее количество шагов. Завершённое состояние обозначается значением `count`.              |
| `defaultStep` | `0`          | Начальное значение в неконтролируемом режиме. Передайте `count`, чтобы сразу показать завершение. |

### Особенности поведения

- `step`, `defaultStep`, `details.step` и `Steps.Item index` используют значения Ark с отсчётом от нуля. Индексы активных шагов находятся в диапазоне от `0` до `count - 1`, а `count` означает завершение.
- В линейном сценарии `onStepInvalid(details)` сообщает заблокированный `details.step`, действие `details.action` (`'next'` или `'set'`) и необязательный `details.targetStep`.
- `Steps.Content` использует `role="tabpanel"` и скрывается, когда его шаг не является текущим. `Steps.CompletedContent` показывается, когда текущее значение равно `count`.
- `Steps.List` использует `role="tablist"` с `aria-orientation`, а триггеры используют `role="tab"` и `aria-controls`.
- `Steps.PrevTrigger` и `Steps.NextTrigger` становятся недоступными, когда Ark сообщает, что предыдущего или следующего шага нет.
- С помощью `ids` можно задать стабильные ID корня, списка, триггеров и содержимого, если этого требует окружающая композиция.
- `Steps.Progress` является визуальной полосой, которая использует переменную Ark `--percent`. Если прогресс должен быть озвучен, добавьте видимый текст или текст для скринридера.

### Хуки стилизации

Полезные публичные хуки:

- `className` у `Steps`, `Steps.RootProvider`, `Steps.List`, `Steps.Item`, `Steps.Trigger`, `Steps.Indicator`, `Steps.Separator`, `Steps.Content`, `Steps.CompletedContent`, `Steps.PrevTrigger`, `Steps.NextTrigger` и `Steps.Progress`
- `data-slot="steps-root"`, `steps-root-provider`, `steps-list`, `steps-item`, `steps-trigger`, `steps-indicator`, `steps-separator`, `steps-content`, `steps-completed-content`, `steps-prev-trigger`, `steps-next-trigger` и `steps-progress`
- Ark `data-scope="steps"` и значения `data-part` для каждой примитивной части
- `data-orientation="horizontal" | "vertical"` у корня, списка, элемента, триггера, содержимого и разделителя
- `data-current`, `data-complete` и `data-incomplete` у индикатора, разделителя и триггера
- `data-state="open" | "closed"` у триггеров и панелей содержимого
- `data-complete` у `Steps.Progress`
- переменная Ark `--percent` на корневом компоненте, которую использует `Steps.Progress`
