## Базовый пример

`Steps` доступен для React и Solid в пакетах с CSS Modules и Tailwind. Пример ниже использует
пакет React CSS Modules, а во вкладках показан нативный код для обоих фреймворков.

Используйте `Steps` с параметром `count`, списком `Steps.List`, содержащим по одному
`Steps.Item` для каждого шага, соответствующими панелями `Steps.Content` и встроенными кнопками
перехода назад и вперёд. Индексы шагов начинаются с нуля. Например, `count={3}` использует
индексы `0`, `1` и `2`. Когда значение шага достигает `count`, показывается
`Steps.CompletedContent`.

Экспорт `Steps` является корневым компонентом. Используйте `Steps.Root`, если хотите явно указать
имя корневой части.

## Анатомия

```text
Steps
├─ Steps.Progress (optional)
├─ Steps.List
│  └─ Steps.Item[index]
│     ├─ Steps.Trigger
│     │  └─ Steps.Indicator
│     └─ Steps.Separator
├─ Steps.Content[index]
├─ Steps.CompletedContent
├─ Steps.PrevTrigger
└─ Steps.NextTrigger

Steps.RootProvider
└─ same part tree connected to a Steps.useSteps() store
```

| Часть                              | Назначение                                                                         |
| ---------------------------------- | ---------------------------------------------------------------------------------- |
| `Steps` / `Steps.Root`             | Корневая машина состояния шагов, ориентации, навигации, валидации и идентификаторов. |
| `Steps.RootProvider`               | Подключает части к состоянию, созданному через `Steps.useSteps()`.                 |
| `Steps.Progress`                   | Необязательная полоса прогресса на основе корневой переменной Ark `--percent`.     |
| `Steps.List`                       | Список вкладок с триггерами шагов.                                                  |
| `Steps.Item`                       | Шаг с обязательным индексом `index`, отсчитываемым от нуля.                        |
| `Steps.Trigger`                    | Триггер вкладки; поддерживает `asChild` для семантических элементов.              |
| `Steps.Indicator`                  | Маркер шага, по умолчанию с номером или иконкой галочки.                            |
| `Steps.Separator`                  | Декоративный соединитель между шагами.                                              |
| `Steps.Content`                    | Панель содержимого шага, связанная с `index`.                                       |
| `Steps.CompletedContent`           | Панель, показываемая, когда текущее значение шага равно `count`.                    |
| `Steps.PrevTrigger` / `NextTrigger` | Кнопки, связанные с действиями Ark для перехода назад и вперёд.                    |

## Композиция

Используйте `Steps` или `Steps.Root` как владельца состояния. У каждого `Steps.Item` и
соответствующего `Steps.Content` должен быть одинаковый индекс `index`, отсчитываемый от нуля;
`count` задаёт общее количество шагов, а его значение обозначает завершение. Используйте
`Steps.RootProvider` только с хранилищем от `Steps.useSteps()`, когда состояние нужно создать вне
дерева частей. Не используйте корневой компонент и provider для одного и того же хранилища.

`Steps.Trigger`, `Steps.PrevTrigger` и `Steps.NextTrigger` поддерживают `asChild`. Передайте один
семантический дочерний элемент, если контрол должен отображаться как ссылка, роутерная ссылка или
кнопка дизайн-системы. Если у `Steps.Indicator` нет дочерних элементов, он выводит номер шага или
общую иконку галочки для завершённого шага; передайте содержимое, чтобы управлять маркером вручную.

## Стилизация

Стилизуйте `Steps` через `className` в React или `class` в Solid, атрибуты Ark `data-scope="steps"`
и `data-part`, атрибуты состояния Ark, хуки moduix `data-slot` и публичные CSS-переменные
`--moduix-steps-*`, перечисленные ниже.

### Хуки стилизации

Доступные публичные хуки:

- `className` в React или `class` в Solid у `Steps`, `Steps.RootProvider`, `Steps.List`, `Steps.Item`, `Steps.Trigger`, `Steps.Indicator`, `Steps.Separator`, `Steps.Content`, `Steps.CompletedContent`, `Steps.PrevTrigger`, `Steps.NextTrigger` и `Steps.Progress`
- `data-slot="steps-root"`, `steps-root-provider`, `steps-list`, `steps-item`, `steps-trigger`, `steps-indicator`, `steps-separator`, `steps-content`, `steps-completed-content`, `steps-prev-trigger`, `steps-next-trigger` и `steps-progress`
- Значения `data-scope="steps"` и `data-part` от Ark для каждой примитивной части
- `data-orientation="horizontal" | "vertical"` у корня, списка, шага, триггера, содержимого и разделителя
- `data-current`, `data-complete` и `data-incomplete` на поверхностях состояния индикатора, разделителя и триггера
- `data-state="open" | "closed"` у триггеров и панелей содержимого
- `data-complete` у `Steps.Progress`
- Переменная Ark `--percent` у корня, используемая `Steps.Progress`
