## Выбор подходящего компонента

Используйте `PasswordInput`, если нужно по умолчанию скрывать одно конфиденциальное значение и при необходимости
позволить пользователю его показать.

- Выберите **`Input`** для обычных однострочных значений без кнопки показа.
- Выберите **`PasswordInput`** для паролей, ключей API и других конфиденциальных строк.
- Выберите **`InputGroup`**, если полю нужно произвольное встроенное действие, не связанное с показом пароля.

## Базовый пример

Для обычного поля пароля используйте `PasswordInput.Field`. Он добавляет поле ввода и кнопку показа с иконками
moduix по умолчанию, а Ark UI управляет состоянием и доступностью.

## Анатомия

```tsx
<PasswordInput>
  <PasswordInput.Label />
  <PasswordInput.Field />
</PasswordInput>
```

Чтобы изменить структуру, замените `PasswordInput.Field` отдельными частями Ark:

```tsx
<PasswordInput>
  <PasswordInput.Label />
  <PasswordInput.Control>
    <PasswordInput.Input />
    <PasswordInput.VisibilityTrigger>
      <PasswordInput.Indicator />
    </PasswordInput.VisibilityTrigger>
  </PasswordInput.Control>
</PasswordInput>
```

| Часть                                  | Роль                                                                            |
| -------------------------------------- | ------------------------------------------------------------------------------ |
| `PasswordInput` / `PasswordInput.Root` | Управляет видимостью пароля и состоянием поля.                                  |
| `PasswordInput.RootProvider`           | Отображает корневую часть на основе объекта состояния `usePasswordInput`.       |
| `PasswordInput.Label`                  | Подписывает поле и отражает состояния required, disabled, invalid и readOnly.  |
| `PasswordInput.Field`                  | Собирает стандартную композицию: контейнер, поле ввода, кнопку показа и индикатор. |
| `PasswordInput.Control`                | Объединяет поле ввода и кнопку показа.                                         |
| `PasswordInput.Input`                  | Нативное поле ввода, у которого `type` меняется между `password` и `text`.     |
| `PasswordInput.VisibilityTrigger`      | Кнопка, которая показывает или скрывает значение.                             |
| `PasswordInput.Indicator`              | Показывает содержимое для видимого или скрытого состояния; moduix добавляет иконки по умолчанию. |

## Композиция

### Рекомендуемая композиция

Используйте `PasswordInput.Field` для стандартного контейнера, поля ввода, кнопки показа и индикатора. Параметры
корневого компонента, такие как видимость, состояние формы, идентификаторы, локализация подписей и настройки
менеджеров паролей, передавайте в `PasswordInput`.

### Когда нужна собственная композиция

Используйте `Control`, `Input`, `VisibilityTrigger` и `Indicator` напрямую, если нужно изменить структуру, заменить
иконки или отдельно стилизовать части. Используйте `asChild` только в случае, когда часть должна отрисовать другой
семантический элемент.

### Свойства по умолчанию

| Свойство или часть                  | По умолчанию         | Описание                                                               |
| ------------------------------------ | -------------------- | --------------------------------------------------------------------- |
| `autoComplete`                      | `"current-password"` | Передаётся в поле ввода; по умолчанию используется `current-password`. |
| `defaultVisible`                    | не задано            | Поле скрыто при первом отображении; свойство задаёт начальную видимость в неконтролируемом режиме. |
| `visible`                           | не задано            | Управляет видимостью, если свойство передано.                         |
| `PasswordInput.Field`               | -                    | Стандартная композиция видимых частей; передаёт параметры контейнера. |
| `onVisibilityChange`                | -                    | Получает объект с деталями Ark; используйте `details.visible`. |
| `translations.visibilityTrigger`    | значение Ark         | Функция, которая возвращает локализованную подпись кнопки показа.     |
| `ignorePasswordManagers`            | `false`              | Добавляет атрибуты, позволяющие поддерживаемым менеджерам паролей игнорировать поле. |

### Особенности поведения

- Чтобы управлять видимостью, передайте `visible` вместе с `onVisibilityChange(details)`.
- Чтобы управлять значением поля или задать его начальное значение, передайте в `PasswordInput.Input` нативные
  свойства `value`, `defaultValue`, `placeholder` и `onChange`.
- Передавайте в `PasswordInput` корневые свойства `name`, `required`, `disabled`, `readOnly`, `invalid`, `ids` и
  `translations`.
- `PasswordInput.Input` является нативным элементом `input`, поэтому участвует в отправке и сбросе формы. Задайте
  `name` на `PasswordInput`; этот примитив не создаёт отдельную скрытую часть `HiddenInput`.
- Используйте `usePasswordInput` с `PasswordInput.RootProvider`, если другому компоненту нужен доступ к тому же
  состоянию видимости за пределами дерева отрисовки.
- Части `PasswordInput.Input`, `PasswordInput.VisibilityTrigger` и `PasswordInput.Indicator` предоставляют атрибут
  `data-state="visible" | "hidden"` для стилизации.

## Стилизация

`PasswordInput` оформляет оболочку контейнера, область ввода и кнопку показа с помощью переменных
`--moduix-password-input-*`, дополняющих общие стили `Input`.

### Хуки стилизации

- Корневая часть и провайдер корня предоставляют `data-slot="password-input-root"` и
  `data-slot="password-input-root-provider"`.
- У частей Ark есть атрибут `data-scope="password-input"` и значения `data-part` для `root`, `label`, `control`,
  `input`, `visibility-trigger` и `indicator`.
- Для стилей видимости используйте `data-state="visible" | "hidden"` на `input`, `trigger` и `indicator`. Для
  стилей состояний используйте `data-disabled`, `data-invalid`, `data-readonly` и `data-required` на тех частях,
  где Ark их добавляет. Контейнер получает `data-disabled`, `data-invalid` и `data-readonly`, которые нужны для
  стилизации оболочки поля.
- Ark не добавляет CSS-переменные, специфичные для этого компонента. moduix предоставляет
  `--moduix-password-input-*` для настройки внешнего вида.
