## Выбор подходящего компонента

Используйте `PasswordInput` для одного конфиденциального значения, которое по умолчанию скрыто, но может быть
показано пользователем.

- Выберите **`Input`** для обычных текстовых полей без переключателя видимости.
- Выберите **`PasswordInput`** для паролей, ключей API и других защищенных строк.
- Выберите **`InputGroup`**, если для поля требуется настраиваемое встроенное действие, не связанное с видимостью пароля.

## Базовое использование

Используйте `PasswordInput.Field` для стандартного поля и переключателя видимости. Компонент добавляет иконки
moduix по умолчанию, сохраняя управление состоянием и поведение доступности Ark.

## Анатомия

```tsx
<PasswordInput>
  <PasswordInput.Label />
  <PasswordInput.Field />
</PasswordInput>
```

Для расширенной настройки замените `PasswordInput.Field` явными частями Ark:

```tsx
<PasswordInput>
  <PasswordInput.Label />
  <PasswordInput.Control>
    <PasswordInput.Input />
    <PasswordInput.VisibilityTrigger>
      <PasswordInput.Indicator />
    </PasswordInput.VisibilityTrigger>
  </PasswordInput.Control>
</PasswordInput>
```

| Часть                               | Роль                                                                            |
| -------------------------------------- | ------------------------------------------------------------------------------ |
| `PasswordInput` / `PasswordInput.Root` | Управляет видимостью пароля и состоянием поля.                                 |
| `PasswordInput.RootProvider`           | Создаёт корневую часть на основе объекта состояния `usePasswordInput`.       |
| `PasswordInput.Label`                  | Подписывает поле и отражает состояния required, disabled, invalid и readOnly. |
| `PasswordInput.Field`                  | Отображает стандартную композицию: элемент управления, поле ввода, переключатель видимости и индикатор. |
| `PasswordInput.Control`                | Объединяет поле ввода и переключатель видимости.                              |
| `PasswordInput.Input`                  | Нативное поле ввода; его `type` переключается между `password` и `text`.      |
| `PasswordInput.VisibilityTrigger`      | Кнопка для переключения видимости.                                            |
| `PasswordInput.Indicator`              | Показывает содержимое для видимого или скрытого состояния; moduix добавляет иконки по умолчанию. |

## Композиция

### Рекомендуемая композиция

Используйте `PasswordInput.Field` для стандартных элемента управления, поля ввода, переключателя видимости и
индикатора. Параметры состояния видимости, состояния формы, идентификаторов, переводов и менеджеров паролей
передавайте в `PasswordInput`.

### Когда нужна собственная композиция

Используйте `Control`, `Input`, `VisibilityTrigger` и `Indicator` напрямую, если нужна другая структура, иконки или
стилизация отдельных частей. Используйте `asChild` только если часть должна отрендерить конкретный семантический
элемент.

### Свойства по умолчанию

| Свойство или часть                  | По умолчанию         | Описание                                                               |
| ------------------------------------ | -------------------- | --------------------------------------------------------------------- |
| `autoComplete`                      | `"current-password"` | Передаётся в поле ввода; по умолчанию используется `current-password`. |
| `defaultVisible`                    | `false`              | Начальная видимость в неконтролируемом режиме.                        |
| `visible`                           | не задано            | Управляет видимостью, если свойство передано.                         |
| `PasswordInput.Field`               | -                    | Стандартная композиция видимых частей; передаёт свойства управления.  |
| `onVisibilityChange`                | -                    | Вызывается с объектом Ark; значение доступно в `details.visible`.      |
| `translations.visibilityTrigger`    | значение Ark         | Функция для локализации подписей кнопки видимости.                    |
| `ignorePasswordManagers`            | `false`              | Добавляет подсказки, чтобы менеджеры паролей не показывали свои элементы поверх поля. |

### Особенности поведения

- Управляйте видимостью с помощью `visible` и `onVisibilityChange(details)`.
- Чтобы управлять значением поля, передайте нативные `value` и `onChange` в `PasswordInput.Input`.
- Передавайте корневые свойства `name`, `required`, `disabled`, `readOnly`, `invalid`, `ids` и `translations`
  в `PasswordInput`.
- Используйте `usePasswordInput` с `PasswordInput.RootProvider`, когда соседнему компоненту требуется доступ к тому
  же состоянию видимости за пределами дерева отрисовки.
- `PasswordInput.Input`, `PasswordInput.VisibilityTrigger` и `PasswordInput.Indicator` предоставляют атрибут
  `data-state="visible" | "hidden"` для стилизации.

## Стилизация

`PasswordInput` оформляет оболочку элемента управления, область текста и переключатель видимости с помощью токенов
`--moduix-password-input-*`, дополняющих общие стили `Input`.

### Хуки стилизации

- Корневая часть и корневой провайдер предоставляют `data-slot="password-input-root"` и
  `data-slot="password-input-root-provider"`.
- Части Ark сохраняют атрибут `data-scope="password-input"` и значения `data-part` для `root`, `label`, `control`,
  `input`, `visibility-trigger` и `indicator`.
- Для стилизации состояний используйте `data-state="visible" | "hidden"` на `input`, `trigger` и `indicator`, а
  также `data-disabled`, `data-invalid`, `data-readonly` и `data-required`, если их предоставляет Ark.
- Ark не предоставляет специфичных для компонента CSS-переменных, доступных во время выполнения; moduix добавляет
  `--moduix-password-input-*` для визуальных настроек по умолчанию.
