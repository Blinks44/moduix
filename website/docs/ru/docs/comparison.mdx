# moduix и shadcn/ui, Park UI, Chakra UI

Все четыре библиотеки дают готовые стилизованные и доступные компоненты. Они различаются тем, какие
фреймворки поддерживают, какие примитивы отвечают за поведение, как написаны стили и как код попадает в
приложение. Сравнение проверено в октябре 2026 года; актуальное состояние смотрите в документации
каждого проекта.

## Коротко

| | moduix | [shadcn/ui](https://ui.shadcn.com/) | [Park UI](https://park-ui.com/) | [Chakra UI](https://chakra-ui.com/) |
| --- | --- | --- | --- | --- |
| Фреймворки | React, Solid, Vue | React; для других фреймворков есть порты сообщества | React, Solid | React |
| Поведение | Ark UI | Radix UI или Base UI | Ark UI | Zag.js, машины состояний, на которых построен Ark UI |
| Стилизация | CSS Modules или Tailwind CSS v4 | Tailwind CSS | Panda CSS | Emotion во время выполнения |
| Установка | npm-пакет или реестр для shadcn CLI | shadcn CLI | Копирование исходников в проект | npm-пакет |
| Рантайм стилей | Нет | Нет | Нет | Emotion |

## Когда выбирать moduix

- **Несколько приложений на разных фреймворках.** В React, Solid и Vue одинаковые имена компонентов,
  части, токены и стили, поэтому одна дизайн-система покрывает все проекты.
- **Нужно владеть исходниками, как в shadcn, но без привязки к одной системе стилей.** Те же компоненты
  есть на обычных CSS Modules и на Tailwind CSS v4, с общей системой токенов.
- **Хочется выбирать способ владения в каждом проекте.** Можно поставить npm-пакет и получать
  обновления или скопировать исходники через shadcn CLI, если их нужно менять.
- **Нужен большой каталог Ark UI с готовыми стилями.** Date picker, color picker, combobox, tree view,
  tags input и другие сложные компоненты готовы к использованию.

## Когда лучше выбрать другое

- **У вас React и Tailwind CSS, и важна самая большая экосистема.** У shadcn/ui намного больше тем,
  реестров сообщества, уроков и примеров.
- **Проект уже использует Panda CSS.** Park UI сделан под него.
- **В React удобнее style props и объект темы во время выполнения.** Chakra UI построен вокруг этой модели.
- **Нужно большое сообщество и много мейнтейнеров.** moduix молодой проект, и его сообщество пока
  меньше, чем у этих библиотек.

## Переход с shadcn/ui

moduix может работать рядом с существующими компонентами shadcn/ui, пока вы заменяете их по одному.
Подробнее в разделе [Миграция с shadcn](/docs/migrate-from-shadcn).
