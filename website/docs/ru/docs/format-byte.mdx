## Базовый пример

Передайте в `value` число байтов. `Format.Byte` выводит только отформатированный текст, поэтому разместите его рядом
с подписью или другим элементом, который объясняет значение. В примерах для одного значения используется абзац, а
для нескольких значений с общим контекстом - список определений.

Предпросмотр использует React, потому что документация работает на React. Во вкладках Solid и Vue
показаны нативные исходники с тем же результатом и API.

## Параметры

| Свойство | Значения | По умолчанию | Назначение |
| --- | --- | --- | --- |
| `value` | `number` | обязательный | Число байтов для форматирования. |
| `unit` | `'byte'` или `'bit'` | `'byte'` | Единица, которую представляет `value`. |
| `unitDisplay` | `'short'`, `'narrow'` или `'long'` | `'short'` | Способ записи названия единицы. |
| `unitSystem` | `'decimal'` или `'binary'` | `'decimal'` | Основа пересчёта значения. |

В текущем публичном типе `FormatByteProps` нет параметров `precision`, `locale` и `sizes`. Для смены локали используйте
`LocaleProvider`, а для настройки форматтера - только перечисленные выше свойства.
