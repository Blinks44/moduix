## Когда использовать

Используйте `Format.Byte`, когда у вас есть число байтов, но пользователю нужно показать понятный размер файла:
размер загрузки или скачивания, квоту хранилища или значение телеметрии. Передайте в `value` количество байтов.
Форматтер автоматически выберет подходящую единицу, например `kB`, `MB` или `GB`.

Импортируйте `Format` напрямую из Ark UI:

```tsx
import { Format } from '@ark-ui/react';
```

## Десятичная и двоичная системы

Свойство `unitSystem` задаёт основу пересчёта: `decimal` увеличивает единицы в 1000 раз, а `binary` - в 1024 раза.
Выбирайте систему явно, если продукт отдельно показывает заявленную ёмкость диска и технические значения хранения.

## Локаль и параметры отображения

`Format.Byte` берёт локаль из ближайшего `LocaleProvider`. Если провайдер не задан, Ark использует `en-US`. moduix
переэкспортирует его из `@moduix/react/locale`, поэтому провайдер удобно разместить вокруг локализованной части
интерфейса:

```tsx
import { Format } from '@ark-ui/react';
import { LocaleProvider } from '@moduix/react/locale';

export function LocalizedFileSize() {
  return (
    <LocaleProvider locale="fr-FR">
      <Format.Byte value={1_450.45} />
    </LocaleProvider>
  );
}
```

`unit="byte"` используется для количества байтов, а `unit="bit"` - для количества битов. Параметр `unitDisplay`
задаёт краткую (`short`), компактную (`narrow`) или полную (`long`) форму записи единицы. `precision` задаёт число
значащих цифр, по умолчанию их 3. `unitSystem` по умолчанию равен `decimal`, `unit` - `byte`, а `unitDisplay` -
`short`. Названия единиц зависят от локали. Для связанных размеров файлов используйте одну и ту же систему единиц,
формат записи и точность, чтобы их было проще сравнивать.

## Использование с moduix

`Format.Byte` не добавляет подпись, отступы и другие элементы интерфейса. Используйте `Card`, `Stack`, `Text` и
компоненты статуса moduix, чтобы пояснить, что означает размер. Если нужен только отформатированный текст, дополнительные
компоненты moduix не нужны.

## Границы ответственности

За форматирование байтов и API `Format.Byte` отвечает Ark UI. moduix предоставляет компоненты интерфейса и
переэкспортирует `LocaleProvider` из `@moduix/react/locale`, но не переэкспортирует `Format.Byte`.
