## Выбор подходящего компонента

- Выберите **`Input`** для обычных текстовых значений.
- Выберите **`DateInput`**, когда пользователям нужно вводить дату с клавиатуры по отдельным сегментам.
- Выберите **`DatePicker`**, когда пользователям нужен встроенный или всплывающий календарь. `DateInput` рассчитан
  на ввод с клавиатуры и не включает календарь.

## Базовый пример

Поместите `DateInput.Segments` внутрь `DateInput.Control`, чтобы получить группу сегментов даты с учётом текущей
локали. Ark UI управляет порядком сегментов, вводом с клавиатуры, фокусом, плейсхолдерами и синхронизацией с формой.
moduix добавляет стилизованные части и скрытые нативные поля, поэтому стандартная композиция остаётся компактной.

## Анатомия

```text
DateInput.Root
├─ DateInput.Label
├─ DateInput.Control
│  ├─ DateInput.Segments
│  └─ DateInput.Separator (необязательно, для диапазонов)
└─ скрытые нативные поля (автоматически)

Расширенная настройка:

DateInput.SegmentGroup
└─ DateInput.SegmentContext
   └─ DateInput.Segment

DateInput.RootProvider
└─ то же дерево частей, подключённое к состоянию, созданному через `useDateInput()`
```

| Часть                          | Назначение                                                              |
| ------------------------------ | ----------------------------------------------------------------------- |
| `DateInput` / `DateInput.Root` | Отвечает за значения дат, форматирование с учётом локали, фокус сегментов и валидацию. |
| `DateInput.RootProvider`       | Подключает части к состоянию из `useDateInput()`.                                  |
| `DateInput.Label`              | Подпись поля даты, доступная вспомогательным технологиям.                           |
| `DateInput.Control`            | Визуальная рамка вокруг одной или нескольких групп сегментов.                       |
| `DateInput.SegmentGroup`       | Объединяет сегменты для одного индекса даты.                                       |
| `DateInput.Segment`            | Редактируемый или фиксированный сегмент, предоставляемый Ark UI.                    |
| `DateInput.Segments`           | Отображает одну группу сегментов с учётом локали для стандартного сценария.         |
| `DateInput.Separator`          | Текстовый разделитель между группами диапазона.                                    |
| `DateInput.Context`            | Даёт доступ к текущему состоянию поля без собственной разметки.                    |
| `DateInput.SegmentContext`     | Вспомогательный компонент Ark UI для отображения сегментов с учётом локали.         |

## Композиция

### Рекомендуемая композиция

Используйте сокращённую запись `DateInput`, а не `DateInput.Root`. Поместите `DateInput.Segments` внутрь
`DateInput.Control`, чтобы получить стандартную группу сегментов с учётом локали.

Корневой компонент автоматически добавляет скрытые нативные поля, необходимые для отправки и сброса формы. Передайте
`name` для одной даты или общее базовое имя для диапазона. Для диапазона отрисуйте две группы
`DateInput.Segments` с индексами `0` и `1`. При общем `name="date"` имена отправляемых полей будут `date[0]` и
`date[1]`. Чтобы задать разные базовые имена, передайте в `names` кортеж из двух элементов, например
`names={['check-in', 'check-out']}`. В этом случае имена полей будут `check-in[0]` и `check-out[1]`.

### Когда нужна своя композиция

Используйте `DateInput.SegmentGroup`, `DateInput.SegmentContext` и `DateInput.Segment` напрямую, когда
классы сегментов или способ их отображения должны зависеть от типа сегмента. Используйте `asChild` для частей Ark UI,
если нужен собственный элемент-обёртка. Передаваемый дочерний элемент должен быть единственным и подходить по семантике.
Используйте `ids`, когда внешнюю подпись или вспомогательный текст нужно связать с полем по стабильным идентификаторам.

### Свойства по умолчанию

| Свойство                          | По умолчанию  | Примечания                                                           |
| --------------------------------- | ------------- | -------------------------------------------------------------------- |
| `DateInput` / `DateInput.Root`    | -             | Дополнительных поведенческих значений по умолчанию нет, используются значения Ark UI. |
| `DateInput.Segments`              | -             | Отображает одну группу сегментов с учётом локали для одного индекса.                  |
| `DateInput.names`                 | -             | Два базовых имени для полей диапазона, индексы добавляет Ark UI.                      |
| `DateInput.Separator.aria-hidden` | `true`        | Текст разделителя скрыт от вспомогательных технологий.                              |
| `DateInput.Separator.role`        | `presentation` | Исключает разделитель диапазона из дерева доступности.                               |

### Особенности поведения

- Значения имеют форму `DateInputDateValue[]` и основаны на типах `@internationalized/date`; это не строки.
- `onValueChange(details)` передаёт объект `details` Ark UI с полями `details.value` и `details.valueAsString`.
- `focused`, `defaultFocused` и `onFocusChange(details)` управляют фокусом корневого компонента.
- `placeholderValue`, `defaultPlaceholderValue` и `onPlaceholderChange(details)` задают дату для пустых сегментов.
- `selectionMode="range"` включает группы сегментов с индексами и автоматически добавляемые нативные поля.
- `shouldForceLeadingZeros` определяет, нужно ли дополнять числовые сегменты ведущими нулями.
- `min`, `max` и `isDateUnavailable` проверяют допустимость дат, а `invalid` задаёт состояние ошибки.
- `locale`, `timeZone`, `hourCycle`, `granularity`, `formatter`, `format`, `translations`, `dir` и
  `createCalendar` передаются в Ark UI. Если нужен только ввод времени, используйте форматтер, настроенный на время,
  с `granularity="minute"` или `"second"`.
- Импортируйте `useDateInput()`, `useDateInputContext()` и `DateInputDateValue` из `@moduix/react`.
  Используйте `DateInput.Context` или `useDateInputContext()`, чтобы получить состояние внутри дерева компонентов,
  а `DateInput.SegmentContext` - для собственной разметки сегментов. Прямые импорты Ark UI нужны только для
  низкоуровневых типов и вспомогательных функций, которые moduix не экспортирует.

### Хуки стилизации

- `data-slot="date-input-root"` на корневом компоненте.
- `data-slot="date-input-label"` на метке.
- `data-slot="date-input-control"` на визуальной рамке.
- `data-slot="date-input-segment-group"` на каждой группе сегментов.
- `data-slot="date-input-segment"` на редактируемых и неизменяемых сегментах.
- `data-slot="date-input-hidden-input"` на скрытом нативном поле ввода.
- `data-slot="date-input-separator"` на разделителе диапазона, который предоставляет moduix.
- Атрибуты состояния Ark UI включают `data-disabled`, `data-readonly`, `data-invalid` и `data-focus` на
  `DateInput.Control` и группах сегментов, а также `data-type`, `data-editable` и `data-placeholder-shown`.
