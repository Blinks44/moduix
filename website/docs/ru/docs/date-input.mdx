## Выбор подходящего компонента

- Выберите **`Input`** для обычных текстовых значений.
- Выберите **`DateInput`**, когда пользователям нужно редактировать дату с клавиатуры и отправлять значение через нативную форму.
- Выберите **`DatePicker`**, когда пользователям нужен календарь во всплывающем окне. `DateInput` ориентирован
  на ввод с клавиатуры и не включает календарь.

## Базовый пример

Используйте `DateInput.Segments`, чтобы отобразить сегменты даты в порядке, заданном текущей локалью. Ark UI
отвечает за порядок сегментов, редактирование с клавиатуры, фокус, плейсхолдеры и синхронизацию с формой.
moduix предоставляет стилизованные части и избавляет от повторяющегося кода, который нужен в стандартном сценарии.

## Анатомия

```text
DateInput.Root
├─ DateInput.Label
├─ DateInput.Control
│  └─ DateInput.Segments
└─ нативные поля ввода (автоматически)

Расширенная настройка:

DateInput.SegmentGroup
└─ DateInput.SegmentContext
   └─ DateInput.Segment

DateInput.RootProvider
└─ то же дерево частей, подключённое к состоянию, созданному через `useDateInput()`
```

| Часть                          | Назначение                                                              |
| ------------------------------ | ----------------------------------------------------------------------- |
| `DateInput` / `DateInput.Root` | Управляет значением даты, форматированием по локали, фокусом сегментов и валидацией. |
| `DateInput.RootProvider`       | Подключает части к состоянию, созданному через `useDateInput()`.         |
| `DateInput.Label`              | Подпись поля, доступная вспомогательным технологиям.                    |
| `DateInput.Control`            | Визуальная рамка вокруг одной или нескольких групп сегментов.           |
| `DateInput.SegmentGroup`       | Группирует сегменты для одного индекса даты.                            |
| `DateInput.Segment`            | Редактируемый сегмент или неизменяемая часть даты, которую возвращает Ark UI. |
| `DateInput.Segments`           | Отображает одну группу сегментов с учетом локали в стандартном сценарии. |
| `DateInput.Separator`          | Текстовый разделитель между группами диапазона.                         |
| `DateInput.Context`            | Доступ к текущему состоянию поля без добавления разметки.               |
| `DateInput.SegmentContext`     | Вспомогательная часть Ark UI для отображения сегментов с учетом локали.   |

## Композиция

### Рекомендуемая композиция

Используйте `DateInput` в сокращенной записи вместо `DateInput.Root`. Поместите `DateInput.Segments` внутрь
`DateInput.Control`, чтобы получить стандартную группу сегментов с учетом локали.

Корневой компонент автоматически добавляет нативные поля для отправки и сброса формы. Для диапазона используйте
индексированные `DateInput.Segments`. При общем `name="date"` имена отправляемых полей будут `date[0]` и `date[1]`.
Чтобы задать разные базовые имена, передайте двухэлементный кортеж `names`, например
`names={['check-in', 'check-out']}`. В этом случае имена полей будут `check-in[0]` и `check-out[1]`.

### Когда нужна собственная композиция

Используйте `DateInput.SegmentGroup`, `DateInput.SegmentContext` и `DateInput.Segment` напрямую, когда
классы сегментов или их отображение должны зависеть от типа сегмента.
Используйте `asChild` для частей Ark UI, если нужно заменить элемент-оболочку. Передаваемый потомок должен быть
одним семантически подходящим элементом.
Используйте `ids`, когда внешняя подпись, вспомогательный текст или другой компонент должны использовать одни и те же ID.

### Свойства по умолчанию

| Свойство                          | По умолчанию  | Примечания                                                           |
| --------------------------------- | ------------- | -------------------------------------------------------------------- |
| `DateInput` / `DateInput.Root`    | -             | Локальных поведенческих значений по умолчанию нет, действуют настройки Ark UI. |
| `DateInput.Segments`              | -             | Отображает одну группу сегментов с учетом локали для одного индекса.  |
| `DateInput.names`                 | -             | Два базовых имени для полей диапазона, Ark UI добавляет индексы.      |
| `DateInput.Separator.aria-hidden` | `true`        | Текст разделителя скрыт от вспомогательных технологий.               |
| `DateInput.Separator.role`        | `presentation` | Исключает разделители диапазона из дерева доступности.                |

### Особенности поведения

- Значения представлены массивом объектов `DateInputDateValue[]` из Ark и `@internationalized/date`, а не строками.
- `onValueChange(details)` передает объект `details` Ark UI с полями `details.value` и `details.valueAsString`.
- `focused`, `defaultFocused` и `onFocusChange(details)` управляют фокусом корневого компонента.
- `placeholderValue`, `defaultPlaceholderValue` и `onPlaceholderChange(details)` управляют датой для пустых сегментов.
- `selectionMode="range"` включает группы сегментов с индексами и автоматически добавляемые нативные поля.
- `shouldForceLeadingZeros` определяет, дополняются ли числовые сегменты ведущими нулями.
- `min`, `max` и `isDateUnavailable` проверяют введенные даты.
- `locale`, `timeZone`, `hourCycle`, `granularity`, `formatter`, `format`, `translations`, `dir` и
  `createCalendar` передаются в Ark UI. Если нужно вводить только время, используйте форматтер, настроенный на
  `granularity="minute"` или `"second"`.
- Импортируйте `useDateInput()`, `useDateInputContext()` и `DateInputDateValue` из `@moduix/react`.
  Используйте `DateInput.Context` или `useDateInputContext()`, чтобы получить состояние внутри дерева компонентов,
  а `DateInput.SegmentContext` для работы с сегментами. Прямые импорты Ark UI нужны только для низкоуровневых типов
  и вспомогательных функций, которые moduix не экспортирует.

### Хуки стилизации

- `data-slot="date-input-root"` на корневом компоненте.
- `data-slot="date-input-label"` на метке.
- `data-slot="date-input-control"` на визуальной рамке.
- `data-slot="date-input-segment-group"` на каждой группе сегментов.
- `data-slot="date-input-segment"` на редактируемых и неизменяемых сегментах.
- `data-slot="date-input-hidden-input"` на скрытом нативном поле ввода.
- `data-slot="date-input-separator"` на разделителе диапазона, который предоставляет moduix.
- Атрибуты состояния Ark UI включают `data-disabled`, `data-readonly`, `data-invalid` и `data-focus` на
  `DateInput.Control` и группах сегментов, а также `data-type`, `data-editable` и `data-placeholder-shown`.
