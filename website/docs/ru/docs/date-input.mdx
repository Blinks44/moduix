## Выбор подходящего компонента

- Выберите **`Input`** для обычных текстовых значений.
- Выберите **`DateInput`**, когда пользователям нужно вводить дату с клавиатуры по отдельным сегментам.
- Выберите **`DatePicker`**, когда нужен встроенный или всплывающий календарь. `DateInput` рассчитан
  на ввод с клавиатуры и не содержит календаря.

## Анатомия

```text
DateInput / DateInput.Root
├─ DateInput.Label
├─ DateInput.Control
│  ├─ DateInput.Segments
│  └─ DateInput.Separator (необязательно, для диапазонов)
└─ DateInput.HiddenInput[index] (явно, по одному на отправляемую дату)

Расширенная настройка:

DateInput.SegmentGroup
└─ DateInput.SegmentContext
   └─ DateInput.Segment

DateInput.RootProvider
└─ то же дерево частей, подключённое к состоянию из useDateInput()
```

| Часть | Назначение |
| ---- | ---- |
| `DateInput` / `DateInput.Root` | Отвечает за значения дат, форматирование с учётом локали, фокус сегментов и валидацию. |
| `DateInput.HiddenInput` | Нативное поле Ark, которое для отправки формы нужно добавить явно. |
| `DateInput.RootProvider` | Подключает части к состоянию из `useDateInput()`. |
| `DateInput.Label` | Подпись поля даты, доступная вспомогательным технологиям. |
| `DateInput.Control` | Визуальная рамка вокруг одной или нескольких групп сегментов. |
| `DateInput.SegmentGroup` | Объединяет сегменты для одного индекса даты. |
| `DateInput.Segment` | Редактируемый или фиксированный сегмент, предоставляемый Ark UI. |
| `DateInput.Segments` | Отображает одну группу сегментов с учётом локали для обычного сценария. |
| `DateInput.Separator` | Текстовый разделитель между группами диапазона. |
| `DateInput.Context` | Даёт доступ к текущему состоянию поля без собственной разметки. |
| `DateInput.SegmentContext` | Помогает отображать сегменты с учётом локали. |

## Композиция

Для обычного поля используйте `DateInput` с `DateInput.Control` и `DateInput.Segments`. Оставьте состояние
неконтролируемым через `defaultValue`, управляйте им через `value` и `onValueChange(details)` или создайте
его с помощью `useDateInput()` и подключите части через `DateInput.RootProvider`. Значения имеют форму
`DateInputDateValue[]` из `@internationalized/date`, а не строк.

`DateInput.HiddenInput` нужно добавлять явно: корневой компонент не создаёт нативные поля. Добавьте по одному
скрытому полю на каждую отправляемую дату, а для диапазона используйте соответствующие значения `index`.
Используйте `DateInput.SegmentGroup`, `DateInput.SegmentContext` и `DateInput.Segment` только тогда, когда
стандартного отображения `DateInput.Segments` недостаточно.

## Стилизация

В React используйте `className`, а в Solid `class` на экспортируемых частях для структурных стилей. Варианты
Tailwind используют обычные utility-классы и классы потребителя. Варианты CSS Modules также предоставляют
перечисленные ниже переменные компонентов. Атрибуты данных и хуки `data-slot` общие для обоих вариантов.

### CSS-свойства

<CssPropertiesSection properties={DateInputDocs.dateInputOverrideCssProperties} />

### Хуки стилизации

- Стабильные селекторы `data-slot`: `date-input-root`, `date-input-root-provider`, `date-input-label`,
  `date-input-control`, `date-input-segment-group`, `date-input-segment` и `date-input-separator`.
- Селекторы частей Ark UI используют `data-scope="date-input"` и соответствующие значения `data-part`.
- Атрибуты состояния Ark UI включают `data-disabled`, `data-readonly`, `data-invalid` и `data-focus` на
  control и группах сегментов, а также `data-type`, `data-editable` и `data-placeholder-shown` на сегментах.
