## Справочник API

В Ark UI нет отдельного примитива `bleed`. В moduix компонент `Bleed` построен на официальной
[фабрике Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[работе с ref](https://ark-ui.com/docs/guides/ref).

Используйте [Container](/docs/container), чтобы ограничить ширину основного макета. Размещайте `Bleed` внутри,
если за границы контейнера должен выйти только медиаблок, фон, разделитель или баннер.

## Базовый пример

Используйте поведение по умолчанию `inline="full"`, когда медиаблок, баннер или акцент секции должен растянуться
до краёв окна браузера, оставаясь в обычном потоке документа.

## Анатомия

`Bleed` отрисовывает один корневой элемент в соответствии с соглашениями Ark. К этому элементу применяются
отрицательные внешние отступы по строчной и/или блочной оси.

```text
Bleed.Root
└─ root[data-scope="bleed"][data-part="root"][data-slot="bleed-root"]
   └─ children
```

| Часть                  | Роль                                                                                     |
| ---------------------- | ---------------------------------------------------------------------------------------- |
| `Bleed` / `Bleed.Root` | Корневая обёртка, которая позволяет содержимому выходить за пределы по строчной и блочной оси. |
| `Bleed`                | Короткая форма `Bleed.Root`, которую можно использовать напрямую как компонент.          |

## Композиция

### Рекомендуемая композиция

Используйте короткую форму `Bleed`, если макету нужна одна обёртка с управляемыми отрицательными отступами.
`Bleed.Root` предоставляет тот же корневой компонент в пространстве имён, что удобно для кода в стиле Ark.
Это основной вариант для полноширинных медиа, фонов вложенных секций, разделителей и баннеров внутри
центрированных оболочек или оболочек с внутренними отступами.

### Когда нужна собственная композиция

Используйте `className` и локальные переопределения `--moduix-bleed-*`, если боковой панели, вложенной области
прокрутки или оболочке приложения нужно растягивать содержимое относительно собственных границ, а не окна браузера.

### Свойства по умолчанию

| Свойство    | По умолчанию | Значения / примечания                          |
| ----------- | ------------ | ----------------------------------------------- |
| `inline`    | `full`       | `none`, `xs`, `sm`, `md`, `lg`, `xl`, `full`    |
| `block`     | `none`       | `none`, `xs`, `sm`, `md`, `lg`, `xl`            |
| `asChild`   | `false`      | Композиция Ark factory                          |
| `className` | -            | Применяется к корневому элементу                |

### Особенности поведения

- `Bleed.Root` создаёт ровно один корневой элемент и передаёт ему свойства для `div`, поддерживаемые фабрикой Ark.
- `ref` указывает на отрисованный корневой элемент. С `asChild` он указывает на единственный дочерний элемент.
- `asChild` требует одного семантического дочернего элемента, который принимает DOM-свойства и ref.
- Используйте `inline`, чтобы выйти за внутренние отступы по строчной оси. Добавляйте `block`, если поверхности
  нужно выйти за отступы и по блочной оси. Эти логические оси следуют режиму письма документа.
- Старое свойство `as` было удалено при миграции на Ark. Используйте `asChild`, когда DOM-узлом должен владеть семантический элемент.
- Используйте одно из фиксированных значений шкалы, если содержимому нужно выйти только за внутренние отступы
  контейнера, а не дойти до края окна браузера.
- `inline="full"` рассчитывается относительно окна браузера, поэтому во вложенных оболочках могут понадобиться
  локальные переопределения `--moduix-bleed-inline-full` и `--moduix-bleed-inline-full-size`.
- Предки с `overflow: hidden` или `overflow: clip` могут обрезать bleed.
- В отличие от примитива компоновки Chakra, moduix намеренно предлагает режимы `inline` и `block`, основанные
  на токенах, вместо отдельных свойств `inlineStart`, `inlineEnd`, `blockStart` и `blockEnd`.

## Стилизация

`Bleed` предоставляет несколько CSS-переменных и стабильные data-атрибуты на корневом элементе. Переменные
позволяют настроить расстояние выхода за границы, а `className` - оформить саму поверхность.

### CSS-свойства

<CssPropertiesSection properties={BleedDocs.bleedCssProperties} />

### Хуки стилизации

- `data-scope="bleed"` и `data-part="root"` служат хуками стилизации, согласованными с Ark, на экспортируемом корневом элементе.
- `data-slot="bleed-root"` - стабильный селектор moduix на экспортируемом корневом элементе.
- `data-inline` показывает текущий режим по строчной оси: `none`, `xs`, `sm`, `md`, `lg`, `xl` или `full`.
- `data-block` показывает текущий режим по блочной оси: `none`, `xs`, `sm`, `md`, `lg` или `xl`.
- Публичный CSS API `--moduix-bleed-*` включает значения фиксированной шкалы и расчёт ширины до краёв окна
  браузера, который используется при `inline="full"`.
