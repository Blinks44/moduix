## Справочник API

В Ark UI нет отдельного примитива `bleed`. В moduix компонент `Bleed` построен на официальной
[фабрике Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[работе с ref](https://ark-ui.com/docs/guides/ref).

Используйте [Container](/docs/container), чтобы сохранить удобную для чтения ширину основного содержимого.
Размещайте внутри него `Bleed`, если за границы контейнера должен выйти только медиаблок, фон, разделитель или баннер.

## Базовый пример

Значение `inline="full"` по умолчанию позволяет медиаблоку, баннеру или декоративному элементу секции растянуться
до краёв окна браузера и при этом остаться в обычном потоке документа.

<style>{`
      .bleed-demo-container {
        display: flex;
        inline-size: 100%;
        flex-direction: column;
        gap: var(--moduix-spacing-4);
        padding: var(--moduix-spacing-4);

      }

      .bleed-demo-surface {

    `}</style>

## Анатомия

`Bleed` отрисовывает один корневой элемент в соответствии с соглашениями Ark. Он применяет отрицательные внешние
отступы по строчной и/или блочной оси и не добавляет внутреннюю обёртку.

```text
Bleed.Root
└─ root[data-scope="bleed"][data-part="root"][data-slot="bleed-root"]
   └─ children
```

| Часть                  | Назначение                                                          |
| ---------------------- | ------------------------------------------------------------------- |
| `Bleed` / `Bleed.Root` | Корневой компонент, который позволяет содержимому выйти по строчной и блочной оси. |
| `Bleed`                | Короткая форма `Bleed.Root`, которую можно использовать напрямую.  |

## Композиция

### Рекомендуемая композиция

Используйте короткую форму `Bleed`, если макету нужна одна корневая обёртка с управляемыми отрицательными отступами.
`Bleed.Root` предоставляет тот же компонент через пространство имён, следуя соглашениям Ark.
Обе формы подходят для полноширинных медиа, фонов секций, разделителей и баннеров внутри центрированных контейнеров
или контейнеров с внутренними отступами.

### Когда нужна собственная композиция

Используйте `className` и локальные переопределения `--moduix-bleed-*`, если боковой панели, вложенной области
прокрутки или контейнеру приложения нужно растягивать содержимое относительно собственных границ, а не окна браузера.

### Свойства по умолчанию

| Свойство    | По умолчанию | Значения / примечания                       |
| ----------- | ------------ | ------------------------------------------- |
| `inline`    | `full`       | `none`, `xs`, `sm`, `md`, `lg`, `xl`, `full` |
| `block`     | `none`       | `none`, `xs`, `sm`, `md`, `lg`, `xl`        |
| `asChild`   | `false`      | Композиция фабрики Ark                      |
| `className` | не задано   | Применяется к корневому элементу            |

### Особенности поведения

- `Bleed.Root` создаёт ровно один корневой элемент и принимает свойства `div`, поддерживаемые фабрикой Ark.
- `ref` указывает на отрисованный корневой элемент. С `asChild` он указывает на единственный дочерний элемент.
- `asChild` требует ровно одного семантического дочернего элемента, который принимает DOM-свойства и ref.
- Используйте `inline`, чтобы выйти за внутренние отступы по строчной оси. Добавляйте `block`, если поверхности
  нужно выйти за отступы и по блочной оси. Эти логические оси следуют режиму письма документа.
- Используйте одно из фиксированных значений шкалы, если содержимому нужно выйти только за внутренние отступы
  контейнера, а не дойти до края окна браузера.
- `inline="full"` рассчитывается относительно окна браузера, поэтому во вложенных оболочках могут понадобиться
  локальные переопределения `--moduix-bleed-inline-full` и `--moduix-bleed-inline-full-size`.
- Предки с `overflow: hidden` или `overflow: clip` могут обрезать выход за границы.
- `Bleed` отвечает только за визуальное оформление. Он не управляет состоянием, не добавляет ARIA-поведение,
  обработку клавиатуры или фокуса и не переносит содержимое в портал.

## Стилизация

`Bleed` предоставляет CSS-переменные и стабильные data-атрибуты на корневом элементе. Переменные позволяют настроить
величину выхода за границы, а `className` - оформить саму поверхность.

### CSS-свойства

<CssPropertiesSection properties={BleedDocs.bleedCssProperties} />

### Хуки стилизации

- `data-scope="bleed"` и `data-part="root"` служат хуками стилизации, согласованными с Ark, на экспортируемом корневом элементе.
- `data-slot="bleed-root"` - стабильный селектор moduix на экспортируемом корневом элементе.
- `data-inline` показывает текущий режим выхода по строчной оси: `none`, `xs`, `sm`, `md`, `lg`, `xl` или `full`.
- `data-block` показывает текущий режим выхода по блочной оси: `none`, `xs`, `sm`, `md`, `lg` или `xl`.
- Публичный CSS API `--moduix-bleed-*` включает значения фиксированной шкалы и расчёт ширины до краёв окна
  браузера, который используется при `inline="full"`.
