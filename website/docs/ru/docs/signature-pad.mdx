## Анатомия

```text
SignaturePad / SignaturePad.Root
├─ SignaturePad.Label
├─ SignaturePad.Canvas (готовая композиция moduix)
│  └─ SignaturePad.Control
│     ├─ SignaturePad.Segment
│     ├─ SignaturePad.ClearTrigger
│     └─ SignaturePad.Guide
└─ скрытое нативное поле (добавляется автоматически)

SignaturePad.RootProvider
└─ то же дерево частей, подключённое к состоянию useSignaturePad()
```

| Часть                                | Назначение                                                                    |
| ------------------------------------ | ----------------------------------------------------------------------------- |
| `SignaturePad` / `SignaturePad.Root` | Хранит пути, параметры рисования, имя поля формы, идентификаторы и колбэки.    |
| `SignaturePad.RootProvider`          | Выводит то же дерево частей из состояния, созданного через `useSignaturePad()`. |
| `SignaturePad.Label`                 | Связывает видимую подпись с областью рисования и скрытым полем формы.         |
| `SignaturePad.Canvas`                | Готовая область рисования с основными частями; передаёт свойства `Control` и `ref`. |
| `SignaturePad.Control`               | Область рисования указателем или касанием, доступная для фокуса.              |
| `SignaturePad.Segment`               | SVG-слой для сохранённых штрихов и текущего незавершённого штриха.            |
| `SignaturePad.ClearTrigger`          | Нативная кнопка очистки путей. Ark скрывает её, пока поле пусто или идёт рисование. |
| `SignaturePad.Guide`                 | Неинтерактивная линия для подписи внутри области рисования.                  |

## Композиция

### Рекомендуемая композиция

В обычной композиции используйте `Label` и `Canvas`. `Canvas` сохраняет элемент, который получает
фокус в Ark, захват указателя, доступное поведение кнопки очистки и SVG-отрисовку, избавляя от
повторяющейся разметки области рисования. Он передаёт свойства `Control` и `ref`. У `Canvas`
фиксированный набор дочерних частей, поэтому для другой структуры используйте отдельные части.

### Когда нужна собственная композиция

Используйте отдельные `Control`, `Segment`, `ClearTrigger` и `Guide`, если нужно изменить их
структуру, заменить иконку или применить `asChild`. Используйте управляемый `paths`, если приложение
должно восстанавливать, очищать, автоматически сохранять или проверять подпись, храня её в своём
состоянии. Используйте `RootProvider` вместе с `useSignaturePad()`, когда состояние нужно создать
вне выводимого дерева или внешним элементам нужен прямой доступ к `paths`, `clear()` или
`getDataUrl()`.

Для расширенного чтения состояния внутри дерева доступны `SignaturePad.Context` и
`useSignaturePadContext()`.

Передайте `name`, если подпись должна попасть в нативную отправку формы. moduix автоматически
добавляет скрытое нативное поле и по умолчанию сериализует пути как `paths.join(' ')`. Передайте
`getFormValue(paths)`, если нужен другой формат.

Используйте `drawing`, чтобы настроить каждый штрих. `drawing.size` меняет его толщину,
`drawing.simulatePressure` управляет имитацией давления, а `drawing.fill` задаёт цвет штриха.
`drawing.fill` должен быть строкой с допустимым CSS-цветом. Ark не принимает переменную CSS в этой
опции. Чтобы использовать токен темы, не задавайте `fill`, а переопределите
`--moduix-signature-pad-stroke-color`.

### Свойства по умолчанию

| Свойство        | По умолчанию                          | Примечания                                                        |
| --------------- | ------------------------------------- | ----------------------------------------------------------------- |
| `defaultPaths`  | -                                     | Исходный неуправляемый массив SVG-путей.                         |
| `paths`         | -                                     | Управляемый массив SVG-путей. Используйте вместе с `onDraw(details)`. |
| `drawing`       | `{ size: 2, simulatePressure: false }` | Параметры штриха Zag. `fill` должен быть допустимым CSS-цветом.   |
| `name`          | -                                     | Имя поля нативной формы.                                          |
| `getFormValue`  | `paths.join(' ')`                     | Пользовательская сериализация автоматически добавляемого поля.  |
| `disabled`      | -                                     | Отключает рисование и взаимодействие с кнопкой очистки.           |
| `readOnly`      | -                                     | Запрещает рисование и отключает кнопку очистки.                   |
| `required`      | -                                     | Делает подпись и скрытое поле обязательными.                      |
| `ids`           | -                                     | Стабильные идентификаторы корня, области рисования, скрытого поля и подписи. |
| `translations`  | Значения Ark по умолчанию             | Доступные подписи для области рисования и кнопки очистки.         |

Стандартная область рисования имеет размер `17.5rem` на `10rem`, то есть примерно `280px` на
`160px` при стандартном масштабе токенов. Чтобы изменить её размер, переопределите
`--moduix-signature-pad-width`, `--moduix-signature-pad-height` или более конкретные переменные
`--moduix-signature-pad-control-*`. Минимальная высота по умолчанию следует высоте области рисования,
поэтому меньшая высота действительно применяется.

### Особенности поведения

Используйте `defaultPaths` для начальной неуправляемой подписи. Используйте `paths` вместе с
`onDraw(details)`, когда подпись должна храниться в состоянии приложения. `onDraw(details)`
срабатывает во время рисования и при изменении сохранённых путей. `details.paths` содержит только
завершённые штрихи, а `details.currentPath` содержит текущий штрих.

`onDrawEnd(details)` срабатывает после завершения штриха или очистки подписи. Метод
`details.getDataUrl(type, quality?)` поддерживает `image/png`, `image/jpeg` и `image/svg+xml` и
возвращает пустую строку для пустой подписи.

Задайте `name` корню, когда нужна нативная отправка формы. Скрытое поле добавляется автоматически.
Передайте `getFormValue(paths)`, если форме нужна собственная сериализация. Оберните компонент в
`Field.Root`, когда текст-подсказка, текст ошибки, обязательность или отключённое состояние должны
быть общими с остальным интерфейсом формы. Состояние `invalid` у `Field` управляет сообщениями и
описаниями поля, но не добавляет `data-invalid` к частям `SignaturePad`.

`Control` получает фокус с клавиатуры и предоставляет `role="application"` с
`aria-roledescription="signature pad"`. Рисование выполняется указателем или касанием, клавиши-
стрелки для него не используются. `ClearTrigger` является нативной кнопкой, поэтому Enter и Space
сохраняют стандартную активацию кнопки. В режиме только для чтения moduix отключает кнопку
очистки, чтобы отображаемую подпись нельзя было случайно изменить.

### Хуки стилизации

Используйте `className` на любой экспортируемой части для локальной стилизации. moduix также
добавляет стабильные атрибуты `data-slot`:

| Часть                                | `data-slot`                   |
| ------------------------------------ | ----------------------------- |
| `SignaturePad` / `SignaturePad.Root` | `signature-pad-root`          |
| `SignaturePad.RootProvider`          | `signature-pad-root-provider` |
| `SignaturePad.Label`                 | `signature-pad-label`         |
| `SignaturePad.Control`               | `signature-pad-control`       |
| `SignaturePad.Segment`               | `signature-pad-segment`       |
| `SignaturePad.Guide`                 | `signature-pad-guide`         |
| `SignaturePad.ClearTrigger`          | `signature-pad-clear-trigger` |

Атрибуты Ark остаются доступны для точечной стилизации. `Root`, `Label`, `Control`, `Segment`,
`Guide`, `ClearTrigger` и внутренние пути сегмента предоставляют `data-scope="signature-pad"` и
`data-part`. Атрибут `data-disabled` появляется на корне, подписи, области рисования и линии
ориентира, а `data-required` появляется на подписи.
