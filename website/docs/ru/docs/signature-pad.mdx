## Базовый пример

SignaturePad доступен для React и Solid в пакетах CSS Modules и Tailwind. Предпросмотр на этой
странице использует пакет React CSS Modules, а вкладки показывают нативный код для того же
публичного контракта.

с частями Ark `Control`, `Segment`, `ClearTrigger` и `Guide`, а также со стандартной кнопкой

## Анатомия

```text
SignaturePad / SignaturePad.Root
├─ SignaturePad.Label
├─ SignaturePad.Canvas (готовая композиция moduix)
│  └─ SignaturePad.Control
│     ├─ SignaturePad.Segment
│     ├─ SignaturePad.ClearTrigger
│     └─ SignaturePad.Guide
└─ SignaturePad.HiddenInput value={serializedPaths} (явно)

SignaturePad.RootProvider
└─ то же дерево частей, подключённое к состоянию useSignaturePad()
```

| Часть                                | Назначение                                                                    |
| ------------------------------------ | ----------------------------------------------------------------------------- |
| `SignaturePad` / `SignaturePad.Root` | Хранит пути, параметры рисования, имя поля формы, идентификаторы и колбэки.    |
| `SignaturePad.HiddenInput`           | Нативное поле Ark, которое нужно добавлять явно.                              |
| `SignaturePad.RootProvider`          | Выводит то же дерево частей из состояния, созданного через `useSignaturePad()`. |
| `SignaturePad.Label`                 | Связывает видимую подпись с областью рисования и скрытым полем формы.         |
| `SignaturePad.Canvas`                | Готовая область рисования со стандартными частями; передаёт свойства `Control`. |
| `SignaturePad.Control`               | Область рисования указателем или касанием, доступная для фокуса.              |
| `SignaturePad.Segment`               | SVG-слой для сохранённых штрихов и текущего незавершённого штриха.            |
| `SignaturePad.ClearTrigger`          | Нативная кнопка очистки путей.                                                |
| `SignaturePad.Guide`                 | Неинтерактивная линия для подписи внутри области рисования.                  |

## Композиция

Для стандартной композиции используйте `Label` и `Canvas`. У `Canvas` фиксированный набор
дочерних частей, поэтому переходите к `Control`, `Segment`, `ClearTrigger` и `Guide`, если нужно
изменить структуру области рисования или кнопку очистки.

`SignaturePad.HiddenInput` не создаётся автоматически. Добавьте его явно и передайте
сериализованное значение, обычно полученное через `SignaturePad.Context` или
`useSignaturePadContext()`, когда подпись должна отправляться нативной формой.

Используйте `defaultPaths` для локального неуправляемого состояния. Используйте `paths` вместе с
`onDraw(details)`, когда состояние подписи принадлежит приложению. Используйте `RootProvider` с
`useSignaturePad()`, когда состояние нужно создать вне выводимого дерева или внешним элементам
нужен доступ к `paths`, `clear()` или `getDataUrl()`.

### Хуки стилизации

Используйте `className` в React или `class` в Solid на любой экспортируемой части для локальной
стилизации. moduix также добавляет стабильные атрибуты `data-slot`:

| Часть                                | `data-slot`                   |
| ------------------------------------ | ----------------------------- |
| `SignaturePad` / `SignaturePad.Root` | `signature-pad-root`          |
| `SignaturePad.RootProvider`          | `signature-pad-root-provider` |
| `SignaturePad.Label`                 | `signature-pad-label`         |
| `SignaturePad.Control`               | `signature-pad-control`        |
| `SignaturePad.Segment`               | `signature-pad-segment`        |
| `SignaturePad.Guide`                 | `signature-pad-guide`          |
| `SignaturePad.ClearTrigger`          | `signature-pad-clear-trigger` |

Атрибуты Ark остаются доступны для точечной стилизации. `Root`, `Label`, `Control`, `Segment`,
`Guide`, `ClearTrigger` и внутренние пути сегмента предоставляют `data-scope="signature-pad"` и
`data-part`; атрибут `data-disabled` появляется на корне, подписи, области рисования и линии
ориентира, а `data-required` появляется на подписи.
