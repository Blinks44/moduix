## Базовый пример


Для большинства случаев начните с `SignaturePadCanvas`. Он выводит стандартную область рисования
с частями Ark `SignaturePadControl`, `SignaturePadSegment`, `SignaturePadClearTrigger` и

## Анатомия

```text
SignaturePad
├─ SignaturePadLabel
├─ SignaturePadCanvas (готовая композиция moduix)
│  └─ SignaturePadControl
│     ├─ SignaturePadSegment
│     ├─ SignaturePadClearTrigger
│     └─ SignaturePadGuide
└─ SignaturePadHiddenInput value={serializedPaths} (явно)

SignaturePadRootProvider
└─ то же дерево частей, подключённое к состоянию useSignaturePad()
```

| Часть                                | Назначение                                                                    |
| ------------------------------------ | ----------------------------------------------------------------------------- |
| `SignaturePad`             | Хранит пути, параметры рисования, имя поля формы, идентификаторы и колбэки.    |
| `SignaturePadHiddenInput`  | Нативное поле Ark, которое нужно добавлять явно.                              |
| `SignaturePadRootProvider` | Выводит то же дерево частей из состояния, созданного через `useSignaturePad()`. |
| `SignaturePadLabel`        | Связывает видимую подпись с областью рисования и скрытым полем формы.         |
| `SignaturePadCanvas`       | Готовая область рисования со стандартными частями; передаёт свойства `SignaturePadControl`. |
| `SignaturePadControl`      | Область рисования указателем или касанием, доступная для фокуса.              |
| `SignaturePadSegment`      | SVG-слой для сохранённых штрихов и текущего незавершённого штриха.            |
| `SignaturePadClearTrigger` | Нативная кнопка очистки путей.                                                |
| `SignaturePadGuide`        | Неинтерактивная линия для подписи внутри области рисования.                  |

## Композиция

Для стандартной композиции используйте `SignaturePadLabel` и `SignaturePadCanvas`. У
`SignaturePadCanvas` фиксированный набор дочерних частей, поэтому переходите к `SignaturePadControl`,
`SignaturePadSegment`, `SignaturePadClearTrigger` и `SignaturePadGuide`, если нужно
изменить структуру области рисования или кнопку очистки.

`SignaturePadHiddenInput` не создаётся автоматически. Добавьте его явно и передайте
сериализованное значение, обычно полученное через `SignaturePadContext` или
`useSignaturePadContext()`, когда подпись должна отправляться нативной формой.

Используйте `defaultPaths` для локального неуправляемого состояния. Используйте `paths` вместе с
`onDraw(details)`, когда состояние подписи принадлежит приложению. Используйте `SignaturePadRootProvider` с
`useSignaturePad()`, когда состояние нужно создать вне выводимого дерева или внешним элементам
нужен доступ к `paths`, `clear()` или `getDataUrl()`. В Vue управляйте путями через
`v-model:paths` и получайте сведения о рисовании в обработчиках `@draw` или `@draw-end`.

В Ark Vue 5.39.3 значение `drawEnd.paths` в управляемом режиме может содержать предыдущие пути.
`v-model:paths` получает завершённые штрихи.

В отличие от Ark, moduix скрывает `SignaturePadClearTrigger`, когда `readOnly` приходит из корня, окружающего
`Field` или `useSignaturePad()`, предотвращая необратимую очистку, тогда как программный `clear()`
остаётся доступным.

## Примеры

### Управляемое состояние

Используйте управляемый `paths`, чтобы хранить подпись в состоянии приложения и связывать её с
кнопками сброса или логикой автосохранения.

<Example name="signature-pad/controlled" />

### Рисование

Передайте `drawing`, если нужно изменить толщину или цвет штриха либо поведение имитации давления.
Значение по умолчанию в рантайме - `{ size: 2, simulatePressure: false }` (на странице документации
Ark показано `simulatePressure: true`), поэтому имитация давления включается явно.

<Example name="signature-pad/drawing" />

### Поле формы

Используйте `Field` вокруг `SignaturePad`, когда текст-подсказка, текст ошибки, обязательность или
сообщение о некорректном значении относятся к одному элементу формы.

<Example name="signature-pad/field" />

### Сериализация формы

Сериализуйте в потребителе значение для `SignaturePadHiddenInput`, когда серверу нужен другой
формат. В этом примере отправляется JSON-массив.

<Example name="signature-pad/form-serialization" />

### Предпросмотр изображения

Используйте `onDrawEnd`, чтобы экспортировать подпись и показать её перед сохранением.

<Example name="signature-pad/image-preview" />

### Root Provider

Создайте состояние с помощью `useSignaturePad()` и передайте его в `SignaturePadRootProvider`, когда элементам
вне выводимого дерева нужен прямой доступ к `paths`, `clear()` или `getDataUrl()`.

<Example name="signature-pad/root-provider" />

### Расширенная настройка

Используйте отдельные части вместо `SignaturePadCanvas`, если нужно управлять деревом частей рисования или
предоставить собственную кнопку очистки.

<Example name="signature-pad/advanced-customization" />

### Хуки стилизации

Используйте `className` в React или `class` в Solid и Vue на любой экспортируемой части для локальной
стилизации. moduix также добавляет стабильные атрибуты `data-slot`:

| Часть                                | `data-slot`                   |
| ------------------------------------ | ----------------------------- |
| `SignaturePad`             | `signature-pad-root`          |
| `SignaturePadRootProvider` | `signature-pad-root-provider` |
| `SignaturePadLabel`        | `signature-pad-label`         |
| `SignaturePadControl`      | `signature-pad-control`        |
| `SignaturePadSegment`      | `signature-pad-segment`        |
| `SignaturePadGuide`        | `signature-pad-guide`          |
| `SignaturePadClearTrigger` | `signature-pad-clear-trigger` |

Атрибуты Ark остаются доступны для точечной стилизации. `SignaturePad`, `SignaturePadLabel`,
`SignaturePadControl`, `SignaturePadSegment`, `SignaturePadGuide`, `SignaturePadClearTrigger` и
внутренние пути сегмента предоставляют `data-scope="signature-pad"` и
`data-part`; атрибут `data-disabled` появляется на корне, подписи, области рисования и линии
ориентира, а `data-required` появляется на подписи.
