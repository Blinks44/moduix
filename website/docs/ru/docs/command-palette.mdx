## Справочник API

В Ark UI нет отдельного примитива `command-palette`. moduix собирает этот компонент с помощью официальной
[фабрики Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory), следуя рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[работе с ref](https://ark-ui.com/docs/guides/ref). За основу взяты Ark [`Dialog`](https://ark-ui.com/docs/components/dialog)
и Ark [`Combobox`](https://ark-ui.com/docs/components/combobox), которые вместе обеспечивают поведение палитры.

## Базовый пример

Используйте `CommandPalette.Panel` как стандартный каркас диалога и поместите внутрь него `CommandPalette.Combobox`.
`CommandPalette.Search` добавляет строку поиска в виде поля ввода. После начала ввода в ней появляется кнопка очистки,
которая удаляет поисковый запрос. Коллекция при этом объявляется отдельно от дерева компонентов, как в примерах Ark Combobox.

      │        ├─ CommandPalette.ItemMeta

| `CommandPalette.Header` / `Title` / `Description`                     | Необязательные элементы оформления, заголовка и описания Ark Dialog.                   |
| `CommandPalette.Body`                                                 | Контейнер области Combobox внутри содержимого диалога.                                  |
| `CommandPalette.Combobox`                                             | Корневой компонент Ark Combobox для поиска и выбора команд.                             |
| `CommandPalette.Control`                                              | Контейнер Ark Combobox вокруг поля поиска и кнопки очистки.                             |
| `CommandPalette.Input`                                                | Поле ввода Ark Combobox.                                                                |
| `CommandPalette.Search`                                               | Готовая строка поиска, объединяющая `Control`, `Input` и `ClearTrigger`.                |
| `CommandPalette.ClearTrigger`                                         | Очищает поисковый запрос и отображается, пока он не пуст.                               |
| `CommandPalette.List`                                                 | Список результатов Ark Combobox со встроенным `ScrollArea` из moduix.                   |
| `CommandPalette.Empty`                                                | Состояние, которое отображается, когда результатов Ark Combobox нет.                    |
| `CommandPalette.ItemGroup` / `ItemGroupLabel`                         | Сгруппированные разделы результатов Ark Combobox.                                       |
| `CommandPalette.Item`                                                 | Элемент Ark Combobox с состояниями подсветки, выбора и отключения.                      |

| `CommandPalette.ItemIcon`, `ItemLabel`, `ItemDescription`, `ItemMeta` | Дополнительные визуальные части moduix для строк команд и метаданных справа.             |

## Композиция

Корневой компонент автоматически помещает `Backdrop` и `Positioner` в портал. Чтобы отобразить их в текущем дереве,
используйте `portalled={false}`, а для собственного контейнера передайте `portalRef`. Структурные части остаются
явными, поэтому их можно стилизовать по отдельности.

### Рекомендуемая композиция

Используйте `useListCollection` с `itemToString`, `itemToValue` и `groupBy`, а в обработчике
`onInputValueChange` компонента `CommandPalette.Combobox` вызывайте `filter(details.inputValue)`. Для стандартного
каркаса поверх остального интерфейса используйте `CommandPalette.Panel`, а для строки поиска с кнопкой очистки
`CommandPalette.Search`.

### Когда нужна собственная композиция

Используйте `Backdrop`, `Positioner`, `Content`, `Header`, `Body`, `Control`, `Input` и `ClearTrigger` напрямую,
если нужна своя структура оверлея или собственные элементы поиска. Задайте `closeOnSelect={false}` на
`CommandPalette.Combobox`, если после выбора команды палитра должна остаться открытой. Чтобы задать палитре доступное
имя, добавьте `aria-label` на корневой компонент. Если нужен видимый заголовок диалога, используйте
`CommandPalette.Title`. `CommandPalette.ItemIndicator` по умолчанию показывает иконку галочки; его можно разместить
в конце строки рядом с `ItemMeta`. Используйте `CommandPalette.RootProvider`, если состояние диалога создаётся снаружи
через Ark `useDialog`. Расширенные API провайдера и контекста Combobox при необходимости импортируйте напрямую из
`@ark-ui/react/combobox`. Остальные свойства корневого Ark Dialog, включая `ids`, `initialFocusEl`, `finalFocusEl`,
`present` и `onExitComplete`, сохраняют исходные контракты. `ref` частей передаётся соответствующим DOM-элементам Ark.
Палитра команд не рендерит `HiddenInput`, потому что предназначена для запуска действий, а не для работы с формой.

### Свойства по умолчанию

По умолчанию содержимое оверлея в портале монтируется по требованию и размонтируется после анимации закрытия.
Задайте `unmountOnExit={false}`, чтобы сохранить его после первого открытия. Задайте `lazyMount={false}` и
`unmountOnExit={false}` только в том случае, если содержимое должно отрендериться сразу.

| Свойство                                    | По умолчанию    | Примечания                                                                        |
| ------------------------------------------- | --------------- | -------------------------------------------------------------------------------- |
| `CommandPalette.shortcut`                   | `false`         | Передайте `alt+k` или другое сочетание из модификатора и клавиши, чтобы включить обработчик. |
| `CommandPalette.shortcutTarget`             | `document`      | Используется только при включённом `shortcut`; `null` не регистрирует обработчик. |
| `CommandPalette.lazyMount`                  | `true`          | Откладывает создание DOM диалога до открытия палитры.                            |
| `CommandPalette.unmountOnExit`              | `true`          | Сохраняет DOM на время анимации выхода, затем размонтирует его.                   |
| `CommandPalette.Combobox.open`              | `true`          | Оставляет список результатов видимым, пока диалог смонтирован.                    |
| `CommandPalette.Combobox.inputBehavior`     | `autohighlight` | Подсвечивает первую подходящую команду по мере ввода.                             |
| `CommandPalette.Combobox.selectionBehavior` | `preserve`      | Сохраняет введённый запрос вместо замены выбранным элементом.                    |
| `CommandPalette.Combobox.disableLayer`      | `true`          | Не добавляет дополнительный слой для закрытия внутри диалога.                    |
| `CommandPalette.Combobox.closeOnSelect`     | `true`          | Также закрывает диалог после выбора в Ark Combobox.                              |

### Особенности поведения

Глобальное сочетание клавиш нужно включить явно, поскольку страницы документации и сложные приложения могут одновременно
отображать несколько палитр. Оно состоит из одного модификатора и одной клавиши, например `mod+k`, `ctrl+1`, `meta+k`
или `alt+k`. Поддерживаются алиасы `mod`, `ctrl` / `control`, `meta` / `cmd` / `command` и `alt` / `option`. Обработчик
игнорирует повторные события `keydown` и цели `input`, `textarea`, `select` и `contenteditable`, пока палитра закрыта.
Если палитра уже открыта, то же сочетание её закроет. Для документации рекомендуется `alt+k`, поскольку поиск использует
`Cmd+K`. Модификатор `mod` принимает Meta или Control, поэтому компонент не зависит от платформы.
`CommandPalette.ClearTrigger` очищает `inputValue`, а не выбранное значение Combobox, и скрыт, пока поисковый запрос пуст.
`CommandPalette` сохраняет Ark `onOpenChange(details)`, а `CommandPalette.Combobox` передаёт объекты `details` в
колбэки Ark Combobox, включая `onInputValueChange(details)`, `onSelect(details)` и `onValueChange(details)`.

Задавайте CSS-переменные для триггера, фона, содержимого, списка и элементов, если палитру нужно подстроить под плотный
интерфейс рабочего инструмента или фирменный стиль оверлея. Для изменения компоновки или слоёв используйте структурные части.

### Хуки стилизации

- Экспортируемые визуальные части предоставляют стабильные хуки `data-slot`: `command-palette-trigger`, `command-palette-backdrop`, `command-palette-positioner`, `command-palette-content`, `command-palette-list`, `command-palette-scroll-area`, `command-palette-scrollbar` и `command-palette-item`.
- Хуки состояния Ark Dialog включают `data-scope="dialog"`, `data-part` и `data-state="open" | "closed"` на фоне и содержимом.
- Хуки состояния Ark Combobox включают `data-scope="combobox"`, `data-part`, `data-state`, `data-highlighted`, `data-disabled`, `data-invalid` и `data-empty`.
- Анимация привязана к `data-state` Ark; устаревшие `data-starting-style`, `data-ending-style` и `data-open` не входят в контракт command-palette.
