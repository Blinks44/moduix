## Справочник API

В Ark UI нет отдельного примитива `command-palette`. `CommandPalette` объединяет Ark
[`Dialog`](https://ark-ui.com/docs/components/dialog) и
[`Combobox`](https://ark-ui.com/docs/components/combobox), а также добавляет стандартный каркас палитры и
строку поиска. Компонент следует рекомендациям Ark по [композиции](https://ark-ui.com/docs/guides/composition),
[стилизации](https://ark-ui.com/docs/guides/styling) и [работе с ref](https://ark-ui.com/docs/guides/ref).

## Базовый пример

Используйте `CommandPalette.Panel` для стандартной структуры диалога. Он сам отрисовывает фон, контейнер позиционирования,
содержимое и основную область. Поместите внутрь `CommandPalette.Combobox`, передайте ему коллекцию и выведите
отфильтрованные команды в `CommandPalette.List`. `CommandPalette.Search` добавляет поле ввода и кнопку очистки,
которая появляется после ввода запроса.

```text

├─ CommandPalette.Trigger
└─ Содержимое оверлея, автоматически помещаемое в портал
   ├─ CommandPalette.Backdrop
   └─ CommandPalette.Positioner
      └─ CommandPalette.Content
         ├─ CommandPalette.Header
         │  ├─ CommandPalette.Title
         │  └─ CommandPalette.Description
         └─ CommandPalette.Body
            └─ CommandPalette.Combobox
               ├─ CommandPalette.Control
               │  ├─ CommandPalette.Input
               │  └─ CommandPalette.ClearTrigger
               ├─ CommandPalette.List
               │  ├─ CommandPalette.Empty
               │  └─ CommandPalette.ItemGroup
               │     ├─ CommandPalette.ItemGroupLabel
               │     └─ CommandPalette.Item
               │        ├─ CommandPalette.ItemIcon
               │        ├─ CommandPalette.ItemText
               │        │  ├─ CommandPalette.ItemLabel
               │        │  └─ CommandPalette.ItemDescription
               │        ├─ CommandPalette.ItemMeta
               │        └─ CommandPalette.ItemIndicator
               └─ CommandPalette.Footer
                  └─ CommandPalette.Kbd

CommandPalette.Panel
└─ сокращённая композиция для Backdrop, Positioner, Content и Body

└─ то же дерево, подключённое к состоянию из useDialog()
```

| `CommandPalette.Content` | Содержимое диалога и визуальная поверхность палитры. |

| `CommandPalette.Header` / `Title` / `Description` | Необязательные элементы компоновки, заголовка и описания Ark Dialog. |
| `CommandPalette.Body` | Контейнер области Combobox внутри диалога. |
| `CommandPalette.Combobox` | Корневой компонент Ark Combobox для поиска и выбора команд. |
| `CommandPalette.Control` | Объединяет поле поиска и кнопку очистки. |
| `CommandPalette.Input` | Поле ввода Ark Combobox. |
| `CommandPalette.Search` | Готовая строка поиска с `Control`, `Input` и `ClearTrigger`. Также добавляет полю ввода доступное имя по умолчанию. Для настройки вложенных частей используйте `controlProps` и `clearTriggerProps`. |
| `CommandPalette.ClearTrigger` | Очищает поисковый запрос и скрыта, пока поле пустое. |
| `CommandPalette.List` | Список результатов Ark Combobox, обёрнутый во встроенный `ScrollArea` из moduix. |
| `CommandPalette.Empty` | Сообщение, которое показывается, если после фильтрации результатов нет. |
| `CommandPalette.ItemGroup` / `ItemGroupLabel` | Группы результатов команд и их заголовки. |
| `CommandPalette.Item` | Строка команды с состояниями подсветки, выбора и отключения. |
| `CommandPalette.ItemText` | Контейнер для названия и описания команды. |
| `CommandPalette.ItemIndicator` | Индикатор выбранного состояния с иконкой галочки по умолчанию. |
| `CommandPalette.ItemIcon`, `ItemLabel`, `ItemDescription`, `ItemMeta` | Визуальные части для иконки, текста, описания и метаданных справа. |
| `CommandPalette.Separator` | Визуальный разделитель между группами команд. |
| `CommandPalette.Footer` / `Kbd` | Нижняя область и обёртка `Kbd` из moduix для обозначения сочетаний клавиш. |

## Композиция

Корневой компонент автоматически помещает `Backdrop` и `Positioner` в портал. Чтобы отрисовать их в текущем
дереве, задайте `portalled={false}`, а для собственного контейнера передайте `portalRef`. Не добавляйте отдельную
обёртку `Portal`. Структурные части остаются явными, поэтому их можно стилизовать по отдельности.

### Рекомендуемая композиция

Для объектов команд используйте `useListCollection` из `@ark-ui/react/collection`. Задайте `itemToString` и
`itemToValue`, чтобы коллекция знала, какие данные использовать для поиска и как идентифицировать команду. Если
команды нужно разделить на группы, добавьте `groupBy`. В `onInputValueChange` вызывайте
`filter(details.inputValue)`, чтобы обновлять список результатов. Если коллекция хранится вне палитры, при закрытии
диалога сбрасывайте фильтр вызовом `filter('')`. Тогда при следующем открытии пользователь снова увидит полный список.
`Panel` и `Search` сокращают стандартную разметку диалога и поиска, не скрывая логику коллекции и отрисовки.

### Когда нужна собственная композиция

Рендерите `Backdrop`, `Positioner`, `Content`, `Header`, `Body`, `Control`, `Input` и `ClearTrigger` напрямую,
если нужна нестандартная структура диалога или свои элементы поиска. Задайте `closeOnSelect={false}` на
`CommandPalette.Combobox`, если после выбора команды палитра должна остаться открытой. Части на базе Ark сохраняют
поведение `asChild` и передачу `ref`. Добавьте `aria-label` на
корневой компонент или используйте `CommandPalette.Title`, если нужен видимый заголовок. `Search` добавляет полю
ввода доступное имя по умолчанию. При использовании `CommandPalette.Input` напрямую укажите собственное имя через
`aria-label` или свяжите поле с заголовком. `CommandPalette.ItemIndicator` по умолчанию показывает иконку галочки;
его можно разместить в конце строки рядом с `ItemMeta`.

Если состояние диалога нужно хранить отдельно, создайте его с помощью `useDialog` из `@moduix/react/dialog` и
передайте полученный объект в `value` компонента `CommandPalette.RootProvider`. Чтобы дочерний компонент мог читать
или изменять это состояние, используйте `useDialogContext` из того же пакета. Расширенные API провайдера и
контекста Combobox импортируйте напрямую из `@ark-ui/react/combobox`, потому что `CommandPalette` их не экспортирует.

Остальные свойства Ark Dialog, включая `modal`, `closeOnEscape`, `closeOnInteractOutside`, `ids`, `initialFocusEl`,
`finalFocusEl`, `present`, `skipAnimationOnMount` и `onExitComplete`, сохраняют исходные контракты. `ref` передаётся соответствующей части
Ark DOM. Компонент не рендерит `HiddenInput`, поскольку палитра запускает действия, а не является элементом формы.
Если нужна нативная отправка формы или функциональность, не относящаяся к палитре команд, используйте отдельный
[Combobox](/docs/combobox).

### Свойства по умолчанию

Содержимое оверлея по умолчанию монтируется по требованию и размонтируется после анимации закрытия. До первого
открытия его нет в DOM, а после закрытия оно удаляется. Задайте `unmountOnExit={false}`, чтобы сохранить содержимое
после первого открытия. Устанавливайте одновременно `lazyMount={false}` и `unmountOnExit={false}` только при
необходимости отрисовать содержимое сразу.

| Свойство | По умолчанию | Примечания |
| --- | --- | --- |
| `CommandPalette.portalled` | `true` | Помещает `Backdrop` и `Positioner` в портал. Для обычной отрисовки задайте `false`. |
| `CommandPalette.portalRef` | `-` | Задаёт собственный контейнер для содержимого в портале. |
| `CommandPalette.shortcut` | `false` | Передайте `alt+k` или другое поддерживаемое сочетание модификатора и клавиши, чтобы включить обработчик. |
| `CommandPalette.shortcutTarget` | `document` | Используется только при включённом `shortcut`. Значение `null` отключает регистрацию обработчика. |
| `CommandPalette.lazyMount` | `true` | Откладывает создание DOM диалога до открытия палитры. |
| `CommandPalette.unmountOnExit` | `true` | Оставляет содержимое в DOM на время анимации выхода, затем удаляет его. |
| `CommandPalette.Combobox.open` | `true` | Оставляет список результатов видимым, пока диалог смонтирован. |
| `CommandPalette.Combobox.inputBehavior` | `autohighlight` | Подсвечивает первую подходящую команду по мере ввода. |
| `CommandPalette.Combobox.selectionBehavior` | `preserve` | Сохраняет введённый запрос вместо замены его выбранной командой. |
| `CommandPalette.Combobox.disableLayer` | `true` | Не регистрирует внутри диалога дополнительный слой, отвечающий за закрытие. |
| `CommandPalette.Combobox.closeOnSelect` | `true` | Закрывает палитру после выбора элемента. |

### Особенности поведения

Глобальное сочетание клавиш нужно включать явно, потому что приложение может одновременно отображать несколько
палитр. Оно должно состоять ровно из одного модификатора и одной клавиши, например `mod+k`, `ctrl+1`, `meta+k` или
`alt+k`. Поддерживаются алиасы `mod`, `ctrl` / `control`, `meta` / `cmd` / `command` и `alt` / `option`.
`mod` срабатывает и для Meta, и для Control, поэтому одно значение подходит для разных платформ. Shift не поддерживается.

Обработчик игнорирует повторные события `keydown`, события во время композиции текста и события от элементов
`input`, `textarea`, `select` и элементов с атрибутом `contenteditable`, пока палитра закрыта. Если палитра открыта,
то же сочетание её закрывает.
Для документации рекомендуется `alt+k`, поскольку поиск на сайте использует `Cmd+K`.

Внутри палитры стрелки перемещают подсветку, `Home` и `End` переходят к первому и последнему элементу, `Enter`
выбирает подсвеченный элемент, а `Escape` закрывает диалог. `CommandPalette.ClearTrigger` очищает `inputValue`, а
не выбранное значение Combobox, и скрыта, пока поисковый запрос пуст. Колбэк `onOpenChange(details)` компонента
`CommandPalette` и колбэки Combobox, включая `onInputValueChange(details)`, `onSelect(details)` и
`onValueChange(details)`, получают объекты `details` того же формата, что и в Ark.

## Стилизация

Используйте CSS-переменные для триггера, фона, содержимого, списка и элементов, если палитру нужно подстроить под
интерфейс с высокой плотностью элементов или фирменный стиль оверлея. Для изменения компоновки или слоёв используйте структурные
части. `CommandPalette.List` остаётся прокручиваемым, но не отрисовывает видимую полосу прокрутки.

### Хуки стилизации

- Экспортируемые части предоставляют стабильные хуки `data-slot`, включая `command-palette-trigger`, `command-palette-backdrop`, `command-palette-positioner`, `command-palette-content`, `command-palette-title`, `command-palette-description`, `command-palette-header`, `command-palette-body`, `command-palette-combobox`, `command-palette-control`, `command-palette-input`, `command-palette-clear-trigger`, `command-palette-list`, `command-palette-scroll-area`, `command-palette-scroll-viewport`, `command-palette-scroll-content`, `command-palette-empty`, `command-palette-item-group`, `command-palette-item-group-label`, `command-palette-item`, `command-palette-item-text`, `command-palette-item-indicator`, `command-palette-item-icon`, `command-palette-item-label`, `command-palette-item-description`, `command-palette-item-meta`, `command-palette-separator`, `command-palette-footer` и `command-palette-kbd`.
- Хуки состояния Ark Dialog включают `data-scope="dialog"`, `data-part` и `data-state="open" | "closed"` у таких частей диалога, как триггер, фон и содержимое.
- Хуки состояния Ark Combobox включают `data-scope="combobox"`, `data-part`, `data-state`, `data-highlighted`, `data-disabled`, `data-invalid` и `data-empty` там, где они применимы.
- Анимация привязана к `data-state` Ark. Устаревшие атрибуты `data-starting-style`, `data-ending-style` и `data-open` не входят в контракт command-palette.
