## Справочник API

В Ark UI нет отдельного примитива `command-palette`. `CommandPalette` объединяет Ark
[`Dialog`](https://ark-ui.com/docs/components/dialog) и
[`Combobox`](https://ark-ui.com/docs/components/combobox), а также добавляет стандартный каркас палитры и
строку поиска. Компонент следует рекомендациям Ark по [композиции](https://ark-ui.com/docs/guides/composition),
[стилизации](https://ark-ui.com/docs/guides/styling) и [работе с ref](https://ark-ui.com/docs/guides/ref).

## Анатомия

```text
CommandPalette
├─ CommandPaletteTrigger
└─ Содержимое оверлея, автоматически помещаемое в портал
   ├─ CommandPaletteBackdrop
   └─ CommandPalettePositioner
      └─ CommandPaletteContent
         ├─ CommandPaletteHeader
         │  ├─ CommandPaletteTitle
         │  └─ CommandPaletteDescription
         └─ CommandPaletteCombobox
            ├─ CommandPaletteControl
            │  ├─ CommandPaletteInput
            │  └─ CommandPaletteClearTrigger
            ├─ CommandPaletteList
            │  ├─ CommandPaletteEmpty
            │  └─ CommandPaletteItemGroup
            │     ├─ CommandPaletteItemGroupLabel
            │     └─ CommandPaletteItem
            │        ├─ CommandPaletteItemIcon
            │        ├─ CommandPaletteItemText
            │        │  ├─ CommandPaletteItemLabel
            │        │  └─ CommandPaletteItemDescription
            │        ├─ CommandPaletteItemMeta
            │        └─ CommandPaletteItemIndicator
            └─ CommandPaletteFooter
               └─ CommandPaletteKbd

CommandPalettePanel
└─ сокращённая композиция для CommandPaletteBackdrop, CommandPalettePositioner и CommandPaletteContent

CommandPaletteRootProvider
└─ то же дерево, подключённое к состоянию из useDialog()
```

| Часть | Назначение |
| --- | --- |
| `CommandPalette` | Управляет состоянием Ark Dialog и необязательным обработчиком глобального сочетания клавиш. |
| `CommandPaletteRootProvider` | Подключает части палитры к состоянию диалога, созданному вне дерева компонентов. Принимает тот же проп `shortcut`. |
| `CommandPaletteTrigger` | Открывает палитру. Не стилизован: используйте `asChild` с `Button` или своим элементом. |
| `CommandPaletteBackdrop` | Фон Ark Dialog с состоянием анимации в `data-state`. |
| `CommandPalettePositioner` | Размещает диалог в области просмотра и не даёт его содержимому выйти за её пределы. |
| `CommandPaletteContent` | Содержимое диалога и визуальная поверхность палитры. |
| `CommandPalettePanel` | Готовый каркас со стандартными `CommandPaletteBackdrop`, `CommandPalettePositioner` и `CommandPaletteContent`. |
| `CommandPaletteHeader` / `CommandPaletteTitle` / `CommandPaletteDescription` | Необязательные элементы компоновки, заголовка и описания Ark Dialog. |
| `CommandPaletteCombobox` | Корневой компонент Ark Combobox для поиска и выбора команд. |
| `CommandPaletteControl` | Объединяет поле поиска и кнопку очистки. |
| `CommandPaletteInput` | Поле ввода Ark Combobox. |
| `CommandPaletteSearch` | Готовая строка поиска с `CommandPaletteControl`, декоративной иконкой поиска, `CommandPaletteInput` и `CommandPaletteClearTrigger`. Также добавляет полю ввода доступное имя по умолчанию. Если части нужно настраивать по отдельности, используйте явную композицию. |
| `CommandPaletteClearTrigger` | Очищает поисковый запрос и скрыта, пока поле пустое. |
| `CommandPaletteList` | Список результатов Ark Combobox, обёрнутый во встроенный `ScrollArea` из moduix. |
| `CommandPaletteEmpty` | Сообщение, которое показывается, если после фильтрации результатов нет. |
| `CommandPaletteItemGroup` / `CommandPaletteItemGroupLabel` | Группы результатов команд и их заголовки. |
| `CommandPaletteItem` | Строка команды с состояниями подсветки, выбора и отключения. |
| `CommandPaletteItemText` | Контейнер для названия и описания команды. |
| `CommandPaletteItemIndicator` | Индикатор выбранного состояния с иконкой галочки по умолчанию. |
| `CommandPaletteItemIcon`, `CommandPaletteItemLabel`, `CommandPaletteItemDescription`, `CommandPaletteItemMeta` | Визуальные части для иконки, текста, описания и метаданных справа. |
| `CommandPaletteSeparator` | Визуальный разделитель между группами команд. |
| `CommandPaletteFooter` / `CommandPaletteKbd` | Нижняя область и обёртка `Kbd` из moduix для обозначения сочетаний клавиш. |

## Композиция

Корневой компонент владеет состоянием Dialog и автоматически помещает `CommandPaletteBackdrop` и `CommandPalettePositioner` в портал.
Чтобы отрисовать их в текущем дереве, задайте `portalled={false}`, а для собственного контейнера передайте
`portalRef`. Для обычной структуры используйте `CommandPalettePanel` и `CommandPaletteSearch`, а при нестандартной разметке диалога или
поиска рендерите структурные части напрямую.

Храните фильтрацию коллекции рядом с владельцем `CommandPaletteCombobox`: настройте `useListCollection` с помощью
`itemToString`, `itemToValue` и `groupBy`, а в `onInputValueChange` вызывайте `filter(details.inputValue)`.
Если коллекция хранится вне палитры, сбрасывайте фильтр при закрытии. Задайте `closeOnSelect={false}`, чтобы
палитра оставалась открытой после действия, или используйте `CommandPaletteRootProvider` с `useDialog` из соответствующего
framework-пакета, если состояние диалога создаётся вне дерева компонентов.

## Примеры

### Управляемое состояние открытия

Используйте управляемое свойство `open`, если остальному интерфейсу тоже нужно управлять видимостью палитры.
В этом примере внешний фильтр коллекции сбрасывается при закрытии палитры.

<Example name="command-palette/controlled-open-state" />

### Включение глобального сочетания клавиш

Задайте `shortcut="alt+k"` у `CommandPalette` или `CommandPaletteRootProvider`, чтобы зарегистрировать глобальное переключение палитры. Это единственный просмотр
на странице, в котором регистрируется `Alt+K`.

<Example name="command-palette/enable-the-global-shortcut" />

### Действия элемента

Обрабатывайте `onSelect(details)`, чтобы запускать команду. При значении `closeOnSelect` по умолчанию палитра
закрывается после выполнения выбранного действия.

<Example name="command-palette/item-actions" />

### Расширенная настройка

Используйте явные части диалога и поиска, если палитре нужны собственный заголовок или нестандартная строка
поиска. В примере сохраняется поведение Ark Dialog и Combobox, а готовые помощники `CommandPalettePanel` и `CommandPaletteSearch` заменяются
явной разметкой.

## Стилизация

Стили частей построены на токенах foundation. Чтобы их изменить, добавьте класс на нужную часть, например
на `CommandPalettePanel` или `CommandPaletteItem`. Две переменные покрывают значения, которые одним классом
не заменить, потому что их дополнительно ограничивает область просмотра. Фон следует общим токенам
`--moduix-backdrop-bg` и `--moduix-backdrop-filter`, анимация содержимого следует общим токенам
`--moduix-popup-motion-*`. `CommandPaletteList` остаётся прокручиваемым, но не показывает видимую полосу
прокрутки.

### Хуки стилизации

- Экспортируемые части предоставляют стабильные хуки `data-slot`, включая `command-palette-trigger`, `command-palette-backdrop`, `command-palette-positioner`, `command-palette-content`, `command-palette-title`, `command-palette-description`, `command-palette-header`, `command-palette-combobox`, `command-palette-control`, `command-palette-input`, `command-palette-clear-trigger`, `command-palette-list`, `command-palette-empty`, `command-palette-item-group`, `command-palette-item-group-label`, `command-palette-item`, `command-palette-item-text`, `command-palette-item-indicator`, `command-palette-item-icon`, `command-palette-item-label`, `command-palette-item-description`, `command-palette-item-meta`, `command-palette-separator`, `command-palette-footer` и `command-palette-kbd`.
- `CommandPaletteList` рендерит `ScrollArea`, поэтому части прокрутки сохраняют хуки `scroll-area-root`, `scroll-area-viewport` и `scroll-area-content`; обращайтесь к ним внутри `[data-slot='command-palette-list']`.
- Хуки состояния Ark Dialog включают `data-scope="dialog"`, `data-part` и `data-state="open" | "closed"` у таких частей диалога, как триггер, фон и содержимое.
- Хуки состояния Ark Combobox включают `data-scope="combobox"`, `data-part`, `data-state`, `data-highlighted`, `data-disabled`, `data-invalid` и `data-empty` там, где они применимы.
- Анимация привязана к `data-state` Ark. Устаревшие атрибуты `data-starting-style`, `data-ending-style` и `data-open` не входят в контракт command-palette.
