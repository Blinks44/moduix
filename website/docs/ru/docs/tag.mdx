## Справочник API

В Ark UI нет отдельного примитива `tag`. moduix собирает этот компонент с помощью официальной
[фабрики Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[ссылкам на DOM-элементы](https://ark-ui.com/docs/guides/ref).

## Выбор подходящего компонента

Используйте `Tag`, когда интерфейс показывает значение или элемент, относящийся к текущему
состоянию интерфейса и при необходимости поддерживающий локальное действие, например удаление.

- Выбирайте **`Badge`** для коротких метаданных: статуса, категории, версии или количества.
- Выбирайте **`Tag`** для выбранных значений, фильтров, назначений или меток, которые являются частью текущего состояния интерфейса.

## Анатомия

Используйте `Tag` как корневой элемент.

```text
Tag
├─ TagStartElement (необязательно)
├─ TagLabel
└─ TagEndElement (необязательно)
   └─ TagCloseTrigger (необязательно)
```

| Часть              | Роль                                                                                     |
| ------------------ | ---------------------------------------------------------------------------------------- |
| `Tag`              | Корневой элемент. Задаёт разметку метки, границу, размер, вариант и композицию через `asChild`. |
| `TagLabel`        | Обёртка видимого значения и граница обрезки.                                             |
| `TagStartElement` | Необязательная область слева для значка, аватара или индикатора состояния.                |
| `TagEndElement`   | Необязательная область справа для значка или действия.                                   |
| `TagCloseTrigger` | Необязательная кнопка для удаления метки.                                                |

## Композиция

`Tag` отвечает только за отображение и не хранит выбранные или удалённые значения. Храните список
в родительском компоненте, изменяйте его из `TagCloseTrigger` и размещайте этот триггер внутри
`TagEndElement`.

Используйте `asChild`, только когда корневой элемент или триггер удаления должен заменить элемент
по умолчанию. Единственный дочерний элемент становится DOM-узлом и должен задавать нужную
семантику. В частности, `TagCloseTrigger asChild` требует явного элемента управления закрытием
и доступного имени.

## Стилизация

Начните со встроенного варианта. В CSS Modules можно изменять публичные переменные или переопределять
экспортированные части через `className` в React и `class` в Solid. В Tailwind используйте нативные
классы Tailwind на экспортированных частях. Атрибуты данных и хуки `data-slot` общие для обоих вариантов.

### CSS-переменные

<div className="docs-reference">

### Хуки стилизации

- Экспортированные части создают `data-scope="tag"` и `data-part="root" | "label" | "start-element" | "end-element" | "close-trigger"`.
- `data-slot="tag-root"`, `data-slot="tag-label"`, `data-slot="tag-start-element"`, `data-slot="tag-end-element"` и `data-slot="tag-close-trigger"` являются стабильными селекторами moduix.
- `Tag` записывает выбранные размер и вариант в `data-size` и `data-variant`.
- `TagCloseTrigger` создаёт `data-disabled` для отключённых состояний или `aria-disabled` и наследует цвет метки.
