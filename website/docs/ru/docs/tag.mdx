## Справочник API

В Ark UI нет отдельного примитива `tag`. В moduix компонент построен на официальной [фабрике Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по [композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и работе с [ref](https://ark-ui.com/docs/guides/ref).

## Выбор подходящего компонента

Используйте `Tag`, когда интерфейс показывает значение или объект, который входит в его текущее
состояние и может потребовать отдельного действия, например удаления.

- Выбирайте **`Badge`**, если нужно показать краткие метаданные: статус, категорию, версию или количество.
- Выбирайте **`Tag`**, если значение выбрано пользователем или относится к изменяемому состоянию интерфейса: фильтр, назначение или метка.

## Анатомия

Корневой компонент также доступен как `Tag.Root`. Короткие формы `<Tag>` и `<Tag.Root>` эквивалентны.

```text
Tag / Tag.Root
├─ Tag.StartElement (optional)
├─ Tag.Label
└─ Tag.EndElement (optional)
   └─ Tag.CloseTrigger (optional)
```

| Часть              | Назначение                                                                              |
| ------------------ | --------------------------------------------------------------------------------------- |
| `Tag` / `Tag.Root` | Корневой элемент. Задаёт разметку, границу, размер, вариант и композицию `asChild`.      |
| `Tag.Label`        | Обёртка видимого значения и граница обрезки длинного текста.                            |
| `Tag.StartElement` | Необязательная область перед текстом для значка, аватара или индикатора состояния.       |
| `Tag.EndElement`   | Необязательная область после текста для значка или действия.                            |
| `Tag.CloseTrigger` | Необязательная кнопка для удаления метки.                                               |

## Композиция

### Рекомендуемая композиция

Для простой метки достаточно `Tag` с `Tag.Label`. Храните видимое значение в `Tag.Label`, а
`Tag.StartElement` и `Tag.EndElement` используйте для встроенного содержимого. Если метку можно
удалить, поместите `Tag.CloseTrigger` внутрь `Tag.EndElement`.

Все экспортируемые части пробрасывают `ref` и `className`, а также принимают стандартные свойства
своего DOM-элемента.

### Когда нужна собственная композиция

Используйте `asChild` у корневого компонента, если вместо стандартного `span` нужен семантический
элемент, например `button` или ссылка. Передайте ровно один дочерний элемент. Он станет корневым
DOM-узлом и будет отвечать за собственную семантику и взаимодействие.

Используйте `Tag.CloseTrigger asChild`, только если действию удаления нужен собственный
семантический дочерний элемент. В этом режиме передайте значок и доступное имя самостоятельно:
стандартный значок удаления не отображается.

### Свойства по умолчанию

| Компонент          | Свойство     | По умолчанию | Примечание                                                                            |
| ------------------ | ------------ | ------------ | ------------------------------------------------------------------------------------- |
| `Tag`              | `variant`    | `default`    | `default`, `secondary`, `outline`, `ghost`, `destructive`                    |
| `Tag`              | `size`       | `md`         | `sm`, `md`                                                                         |
| `Tag`              | `asChild`    | `false`      | Заменяет стандартный `span` одним дочерним элементом.                               |
| `Tag.CloseTrigger` | `type`       | `button`     | Применяется к стандартной кнопке и предотвращает случайную отправку формы.            |
| `Tag.CloseTrigger` | `asChild`    | `false`      | Заменяет стандартный `button`; дочерний элемент должен содержать действие удаления.  |
| `Tag.CloseTrigger` | `children`   | значок удаления | Используется без `asChild`; собственное содержимое заменяет стандартный значок.    |
| `Tag.CloseTrigger` | `aria-label` | `Remove tag` | Используется без собственного содержимого, `aria-labelledby` и `asChild`.          |

### Особенности поведения

- `Tag` не хранит и не изменяет состояние выбранных, удалённых или перемещённых значений. Список и обработчик его обновления принадлежат родительскому компоненту.
- `Tag.CloseTrigger` добавляется явно. У корневого компонента нет свойства `onClose`.
- Встроенные варианты используют те же цветовые роли, что и `Badge`; `Tag` дополнительно даёт анатомию метки и необязательное действие удаления.
- Если рядом несколько удаляемых меток, задайте каждой кнопке удаления точное доступное имя.
- Без собственного содержимого `Tag.CloseTrigger` использует значок удаления moduix и резервное имя `Remove tag`. Если передать собственное содержимое без имени, общий `CloseButton` использует резервное имя `Close`.
- Отключённая кнопка удаления или кнопка с `aria-disabled` получает `data-disabled` и не вызывает обработчик клика.
- `asChild` следует композиции Ark и требует ровно одного дочернего элемента. Для `Tag.CloseTrigger asChild` также нужен явный семантический дочерний элемент.

## Стилизация

Сначала выбирайте встроенный вариант. Для разовых изменений размера или цвета используйте локальные
CSS-переменные или переопределение через `className`. Общие цветовые переменные компонента имеют
приоритет над переменными отдельных вариантов.

### Атрибуты для стилизации

- Экспортируемые части получают `data-scope="tag"` и значения `data-part="root" | "label" | "start-element" | "end-element" | "close-trigger"`.
- `data-slot="tag-root"`, `data-slot="tag-label"`, `data-slot="tag-start-element"`, `data-slot="tag-end-element"` и `data-slot="tag-close-trigger"` - стабильные селекторы moduix.
- `Tag` записывает выбранные размер и вариант в `data-size` и `data-variant`.
- `Tag.CloseTrigger` получает `data-disabled` в отключённом состоянии или при `aria-disabled` и наследует цвет метки.
