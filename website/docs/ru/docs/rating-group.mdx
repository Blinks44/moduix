## Анатомия

```text
RatingGroup / RatingGroup.Root
├─ RatingGroup.Label
└─ RatingGroup.Control
   ├─ RatingGroup.Items
   │  └─ RatingGroup.Item[index]
   │     └─ RatingGroup.ItemIndicator
   ├─ RatingGroup.Context
   │  └─ RatingGroup.Item[index]
   │     └─ RatingGroup.ItemIndicator
   └─ RatingGroup.HiddenInput (явно)

RatingGroup.RootProvider
└─ то же дерево частей, подключённое к состоянию moduix из useRatingGroup()
```

| Часть                               | Назначение                                                        |
| ---------------------------------- | ----------------------------------------------------------------- |
| `RatingGroup` / `RatingGroup.Root` | Хранит состояние оценки, управляет клавиатурной навигацией, фокусом и интеграцией с формами. |
| `RatingGroup.HiddenInput`          | Нативное поле Ark, которое нужно добавить явно.                  |
| `RatingGroup.RootProvider`          | Подключает части к состоянию, созданному с помощью `useRatingGroup()`. |
| `RatingGroup.Context`               | Даёт доступ к текущему состоянию корня через render prop.        |
| `RatingGroup.ItemContext`           | Даёт доступ к текущему состоянию элемента через render prop.     |
| `RatingGroup.Label`                 | Доступная подпись группы рейтинга.                                |
| `RatingGroup.Control`               | Объединяет интерактивные элементы рейтинга.                       |
| `RatingGroup.Items`                 | Создаёт элемент для каждого значения и добавляет звезду по умолчанию. |
| `RatingGroup.Item`                  | Один выбираемый элемент рейтинга, которому нужен числовой `index`. |
| `RatingGroup.ItemIndicator`         | Стандартный визуальный индикатор moduix для элемента.             |

## Композиция

Используйте `RatingGroup.Items` для стандартного дерева элементов, создаваемого автоматически. Чтобы
заменить повторяющийся значок, передайте свой `RatingGroup.ItemIndicator` дочерним элементом. После
`Items` компонент не добавляет `RatingGroup.HiddenInput` автоматически, поэтому разместите его явно
внутри корневого компонента или `RatingGroup.RootProvider`; задайте `name` на корне, если значение
должно отправляться нативной формой.

Для собственного дерева элементов используйте `RatingGroup.Context` вместе с `RatingGroup.Item`.
Если хранилище нужно создать вне дерева, используйте `RatingGroup.RootProvider` и
`useRatingGroup()`. В React состояние читается как объект, а в Solid реактивное состояние доступно
через возвращаемую функцию.

## Стилизация

Используйте `className` в React или `class` в Solid на экспортируемых частях для структурных
стилей. Ark также предоставляет атрибуты `data-scope="rating-group"` и `data-part`. Для стилей по состоянию используйте атрибуты данных, например `data-disabled`,
`data-readonly`, `data-checked`, `data-highlighted` и `data-half`, вместе с хуками `data-slot` moduix.
Варианты Tailwind используют нативные utility-классы и классы потребителя, а варианты CSS Modules
также предоставляют зарегистрированные переменные `--moduix-rating-group-*`.

### Хуки стилизации

- `data-slot="rating-group-root"` и `data-slot="rating-group-root-provider"`
- `data-slot="rating-group-label"`
- `data-slot="rating-group-control"`
- `data-slot="rating-group-item"`
- `data-slot="rating-group-item-indicator"`
- `data-slot="rating-group-item-indicator-bg"` и `data-slot="rating-group-item-indicator-fg"`
- `data-size="xs" | "sm" | "md" | "lg" | "xl"` на корневом компоненте или root provider
- Атрибуты label Ark: `data-disabled` и `data-required`
- Атрибуты control Ark: `data-disabled` и `data-readonly`
- Атрибуты item Ark: `data-checked`, `data-highlighted`, `data-half`, `data-disabled` и `data-readonly`
