## Выбор подходящего компонента

Используйте `RatingGroup`, когда пользователю нужно выбрать числовую оценку в ряду звёзд или других повторяющихся значков.

## Базовый пример


Используйте `RatingGroup` как корневой компонент и добавьте `RatingGroupLabel`,
`RatingGroupControl` и `RatingGroupItems` для стандартного рейтинга со звёздами. Если значение
должно отправляться нативной формой, явно добавьте `RatingGroupHiddenInput`.

## Анатомия

```text
RatingGroup
├─ RatingGroupLabel
└─ RatingGroupControl
   ├─ RatingGroupItems
   │  └─ RatingGroupItem[index]
   │     └─ RatingGroupItemIndicator
   ├─ RatingGroupContext
   │  └─ RatingGroupItem[index]
   │     └─ RatingGroupItemIndicator
   └─ RatingGroupHiddenInput (явно)

RatingGroupRootProvider
└─ то же дерево частей, подключённое к состоянию moduix из useRatingGroup()
```

| Часть                               | Назначение                                                        |
| ---------------------------------- | ----------------------------------------------------------------- |
| `RatingGroup`                    | Хранит состояние оценки, управляет клавиатурной навигацией, фокусом и интеграцией с формами. |
| `RatingGroupHiddenInput`          | Нативное поле Ark, которое нужно добавить явно.                  |
| `RatingGroupRootProvider`          | Подключает части к состоянию, созданному с помощью `useRatingGroup()`. |
| `RatingGroupContext`               | Даёт доступ к текущему состоянию корня через render prop.        |
| `RatingGroupItemContext`           | Даёт доступ к текущему состоянию элемента через render prop.     |
| `RatingGroupLabel`                 | Доступная подпись группы рейтинга.                                |
| `RatingGroupControl`               | Объединяет интерактивные элементы рейтинга.                       |
| `RatingGroupItems`                 | Создаёт элемент для каждого значения и добавляет звезду по умолчанию. |
| `RatingGroupItem`                  | Один выбираемый элемент рейтинга, которому нужен числовой `index`. |
| `RatingGroupItemIndicator`         | Стандартный визуальный индикатор moduix для элемента.             |

## Композиция

Используйте `RatingGroupItems` для стандартного дерева элементов, создаваемого автоматически. Чтобы
заменить повторяющийся значок, передайте свой `RatingGroupItemIndicator` дочерним элементом. После
`Items` компонент не добавляет `RatingGroupHiddenInput` автоматически, поэтому разместите его явно
внутри корневого компонента или `RatingGroupRootProvider`; задайте `name` на корне, если значение
должно отправляться нативной формой.

Для собственного дерева элементов используйте `RatingGroupContext` вместе с `RatingGroupItem`.
Если хранилище нужно создать вне дерева, используйте `RatingGroupRootProvider` и
`useRatingGroup()`. В React состояние доступно как объект. В Solid вызывайте возвращаемую функцию, а в Vue читайте
реактивное состояние непосредственно в шаблоне.

## Примеры

### Управляемое состояние

Используйте `value` вместе с `useState` в React, `createSignal` в Solid или `ref` и `v-model` в Vue,
когда оценка зависит от другого состояния, влияет на соседний интерфейс или должна сбрасываться
родителем.

<Example name="rating-group/controlled" />

### Пользовательский значок

Передайте свой `RatingGroupItemIndicator` дочерним элементом `RatingGroupItems`, если всем
элементам нужен один и тот же значок. Индикатор сохраняет атрибуты состояния Ark `data-highlighted`
и `data-half`, которые можно использовать для стилизации.

<Example name="rating-group/custom-icon" />

### Отключённое состояние и режим только для чтения

Используйте `disabled`, чтобы отключить взаимодействие. Используйте `readOnly`, чтобы оставить
оценку видимой, но запретить её изменение.

<Example name="rating-group/disabled-and-readonly" />

### Field

Оберните рейтинг в `Field`, если текст подсказки или валидации должен быть связан с его
`RatingGroupHiddenInput`. Ark наследует от поля свойства `disabled`, `readOnly` и `required`, а
состояние валидации по-прежнему принадлежит `Field` и коду приложения.

<Example name="rating-group/field" />

### Формы

Передайте `name` и явно добавьте `RatingGroupHiddenInput`, если выбранная оценка должна попасть в
`FormData`.

<Example name="rating-group/forms" />

### Оценка с половинами

Установите `allowHalf`, чтобы включить выбор с шагом в половину и отображение половины звезды.

<Example name="rating-group/half-rating" />

### Размеры

Используйте свойство `size` moduix, если рейтинг должен сохранять поведение Ark при другой
визуальной плотности.

<Example name="rating-group/sizes" />

### Расширенная композиция

Используйте `RatingGroupRootProvider` вместе с `useRatingGroup()`, если состояние рейтинга нужно
создать вне дерева. Используйте `RatingGroupContext`, когда `RatingGroupItems` недостаточно и
нужно вывести каждый элемент самостоятельно.

<Example name="rating-group/advanced-customization" />

## Стилизация

Используйте `className` в React или `class` в Solid и Vue на экспортируемых частях для структурных
стилей. Ark также предоставляет атрибуты `data-scope="rating-group"` и `data-part`. Для стилей по состоянию используйте атрибуты данных, например `data-disabled`,
`data-readonly`, `data-checked`, `data-highlighted` и `data-half`, вместе с хуками `data-slot` moduix.
Варианты Tailwind используют нативные utility-классы и классы потребителя, а варианты CSS Modules
также предоставляют зарегистрированные переменные `--moduix-rating-group-*`.

### Хуки стилизации

- `data-slot="rating-group-root"` и `data-slot="rating-group-root-provider"`
- `data-slot="rating-group-label"`
- `data-slot="rating-group-control"`
- `data-slot="rating-group-item"`
- `data-slot="rating-group-item-indicator"`
- `data-slot="rating-group-item-indicator-bg"` и `data-slot="rating-group-item-indicator-fg"`
- `data-size="xs" | "sm" | "md" | "lg" | "xl"` на корневом компоненте или root provider
- Атрибуты label Ark: `data-disabled` и `data-required`
- Атрибуты control Ark: `data-disabled` и `data-readonly`
- Атрибуты item Ark: `data-checked`, `data-highlighted`, `data-half`, `data-disabled` и `data-readonly`
