## Анатомия

```text
RatingGroup / RatingGroup.Root
├─ RatingGroup.Label
└─ RatingGroup.Control
   ├─ RatingGroup.Items (рекомендуемый вариант)
   │  └─ RatingGroup.Item[index]
   │     └─ RatingGroup.ItemIndicator
   ├─ RatingGroup.Context (расширенный вариант, необязательно)
   │  └─ RatingGroup.Item[index]
   │     └─ RatingGroup.ItemIndicator
   └─ скрытое нативное поле формы (добавляется автоматически)

RatingGroup.RootProvider
└─ та же структура, подключённая к состоянию moduix из useRatingGroup()
```

| Часть                               | Назначение                                                     |
| ---------------------------------- | -------------------------------------------------------------- |
| `RatingGroup` / `RatingGroup.Root` | Хранит состояние оценки, управляет клавиатурной навигацией, фокусом и интеграцией с формами. |
| `RatingGroup.RootProvider`         | Подключает части к состоянию, созданному через `useRatingGroup()`.                         |
| `RatingGroup.Context`              | Даёт доступ к текущему состоянию корня через render prop.                                  |
| `RatingGroup.ItemContext`          | Даёт доступ к текущему состоянию элемента через render prop.                               |
| `RatingGroup.Label`                | Доступная подпись группы рейтинга.                                                         |
| `RatingGroup.Control`              | Объединяет интерактивные элементы рейтинга.                                                |
| `RatingGroup.Items`                | Создаёт элементы для каждого значения и добавляет звезду по умолчанию.                     |
| `RatingGroup.Item`                 | Один выбираемый элемент рейтинга; требует числовой `index`.                                |
| `RatingGroup.ItemIndicator`        | Стандартный визуальный индикатор moduix, который учитывает состояние элемента.             |

## Композиция

### Рекомендуемая композиция

`RatingGroup` - сокращённая форма `RatingGroup.Root`. Компонент хранит состояние оценки, управляет
фокусом, подписями и интеграцией с формами, а также обрабатывает взаимодействие с клавиатурой и указателем. Для стандартного ряда звёзд
добавьте `RatingGroup.Items`: он создаёт элемент для каждого значения до `count` и добавляет звезду
по умолчанию. Корневой компонент также автоматически добавляет синхронизированное нативное поле
формы. Чтобы заменить значок, сохранив прежнее поведение, передайте свой
`RatingGroup.ItemIndicator` дочерним элементом `RatingGroup.Items`.

### Когда нужна собственная композиция

Используйте `RatingGroup.Context` или `RatingGroup.ItemContext`, когда нужно вывести собственное
дерево элементов или построить визуальное представление на основе состояния корня или элемента.
В пользовательском компоненте для доступа к этому состоянию используйте
`useRatingGroupContext()` или `useRatingGroupItemContext()` из `@moduix/react`. Используйте
`RatingGroup.RootProvider` с `useRatingGroup()`, когда состояние рейтинга нужно создать вне
отрисовываемого дерева.

DOM-части Ark, доступные через компонент, поддерживают `asChild`. Оставляйте непосредственный
дочерний элемент единственным семантическим элементом, способным сохранить фокус и взаимодействие
этой части. `RatingGroup.ItemIndicator` - удобная визуальная обёртка moduix, а не замена DOM-части Ark.

### Свойства по умолчанию

| Элемент                       | По умолчанию | Примечания                                               |
| ----------------------------- | ------------ | -------------------------------------------------------- |
| `count`                       | `5`          | Количество элементов рейтинга.                           |
| `size`                        | `md`         | Размер moduix: `xs`, `sm`, `md`, `lg` или `xl`.          |
| `RatingGroup.Items`           | -            | Создаёт элементы от `1` до `count`.                      |
| `RatingGroup.ItemIndicator`   | звезда       | По умолчанию показывает две наложенные звёзды: фоновую и активную. |

### Особенности поведения

- `value` и `defaultValue` - числа. Используйте `defaultValue` для неконтролируемого рейтинга.
- `onValueChange(details)` получает детали Ark; выбранное значение находится в `details.value`.
- `onHoverChange(details)` получает детали наведения Ark; их можно использовать для предпросмотра и
  связанного интерфейса.
- `allowHalf` включает выбор с шагом в половину и отображение половины звезды.
- `autoFocus` переводит фокус на рейтинг сразу после монтирования.
- `name`, `form` и `required` применяются к нативному полю формы, которое корневой компонент
  добавляет автоматически.
- Ark обрабатывает `disabled` и `readOnly` и отражает эти состояния через атрибуты данных.
- Ark управляет клавиатурной навигацией: `ArrowRight` и `ArrowLeft` перемещают фокус между
  элементами, а `Enter` выбирает элемент в фокусе. При `allowHalf` стрелки также перемещают фокус
  с шагом в половину.
- Используйте `ids`, чтобы задавать предсказуемые идентификаторы для составной разметки, а
  `translations` - чтобы переопределить локализованные сообщения Ark для доступности.

У `Root`, `RootProvider`, `Label`, `Control` и `Item` ref указывает на соответствующую DOM-часть
Ark. `ItemIndicator` передаёт ref своей визуальной обёртке.

## Стилизация

Стилизуйте `RatingGroup` с помощью `className`, атрибутов Ark `data-scope="rating-group"` и `data-part`,
атрибутов состояния Ark, хуков moduix `data-slot` и зарегистрированных CSS-переменных
`--moduix-rating-group-*`.

### Хуки стилизации

- `data-slot="rating-group-root"` и `data-slot="rating-group-root-provider"`
- `data-slot="rating-group-label"`
- `data-slot="rating-group-control"`
- `data-slot="rating-group-item"`
- `data-slot="rating-group-item-indicator"`
- `data-slot="rating-group-item-indicator-bg"` и `data-slot="rating-group-item-indicator-fg"`
- `data-slot="rating-group-hidden-input"`
- `data-size="xs" | "sm" | "md" | "lg" | "xl"` на `RatingGroup.Root` или `RatingGroup.RootProvider`
- Атрибуты подписи Ark: `data-disabled` и `data-required`
- Атрибуты контрола Ark: `data-disabled` и `data-readonly`
- Атрибуты элемента Ark: `data-checked`, `data-highlighted`, `data-half`, `data-disabled` и `data-readonly`
