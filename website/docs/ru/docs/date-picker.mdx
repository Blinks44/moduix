## Выбор подходящего компонента

- Выберите **`Input`** для обычного текстового ввода даты, если календарь не нужен.
- Выберите **`DateInput`**, если пользователям нужно редактировать сегменты даты с клавиатуры.
- Выберите **`DatePicker`**, если пользователям нужно редактируемое поле даты и всплывающий или встроенный календарь.

## Анатомия

```text
DatePicker / DatePicker.Root
├─ DatePicker.Label
├─ DatePicker.Control
│  ├─ DatePicker.Input
│  ├─ DatePicker.ClearTrigger
│  └─ DatePicker.Trigger
├─ DatePicker.Field / DatePicker.RangeField (готовые элементы управления)
├─ Поддерево всплывающего календаря (корневой компонент автоматически помещает его в портал)
│  └─ DatePicker.Positioner
│     └─ DatePicker.Content
│        ├─ DatePicker.View[view="day" | "month" | "year"]
│        │  ├─ DatePicker.ViewControl
│        │  │  ├─ DatePicker.PrevTrigger
│        │  │  ├─ DatePicker.ViewTrigger / DatePicker.RangeText
│        │  │  └─ DatePicker.NextTrigger
│        │  ├─ DatePicker.DayTable (готовая таблица дней)
│        │  └─ DatePicker.Table
│        │     ├─ DatePicker.TableHead / TableBody / TableRow
│        │     ├─ DatePicker.TableHeader
│        │     ├─ DatePicker.TableCell
│        │     ├─ DatePicker.TableCellTrigger
│        │     ├─ DatePicker.WeekNumberHeaderCell
│        │     └─ DatePicker.WeekNumberCell
│        ├─ DatePicker.MonthSelect / DatePicker.YearSelect
│        └─ DatePicker.PresetTrigger
├─ DatePicker.ValueText (необязательный текст с выбранными значениями)
└─ DatePicker.Context

DatePicker.RootProvider
└─ то же дерево частей, подключённое к хранилищу useDatePicker()
```

| Часть                             | Роль                                                               |
| --------------------------------- | ------------------------------------------------------------------ |
| `DatePicker` / `DatePicker.Root`  | Корень, который управляет значением, представлением, открытием, локалью, валидацией и формой. |
| `DatePicker.RootProvider`         | Отображает части, используя состояние из `useDatePicker()`.       |
| `DatePicker.Label`                | Доступное имя поля даты.                                           |
| `DatePicker.Control`              | Обёртка поля для собственной раскладки ввода.                      |
| `DatePicker.Field`                | Готовое поле с вводом, очисткой и открытием календаря.             |
| `DatePicker.RangeField`           | Готовое поле диапазона с индексированными началами и концами.     |
| `DatePicker.Input`                | Редактируемый ввод даты, участвующий в отправке формы.             |
| `DatePicker.Trigger`              | Открывает календарь.                                               |
| `DatePicker.ClearTrigger`         | Очищает текущее значение.                                          |
| `DatePicker.Positioner`           | Позиционирует всплывающий календарь.                               |
| `DatePicker.Content`              | Контейнер календаря во всплывающем или встроенном режиме.         |
| `DatePicker.View`                 | Представление дня, месяца или года.                                |
| `DatePicker.ViewControl`          | Заголовок с навигацией по календарю.                                |
| `DatePicker.PrevTrigger`          | Переходит к предыдущему месяцу, году или десятилетию.              |
| `DatePicker.NextTrigger`          | Переходит к следующему месяцу, году или десятилетию.               |
| `DatePicker.ViewTrigger`          | Переключает представление календаря.                               |
| `DatePicker.RangeText`            | Показывает видимый диапазон дат в заголовке.                        |
| `DatePicker.ValueText`            | Показывает выбранные значения.                                     |
| `DatePicker.DayTable`             | Готовая таблица представления дней.                                |
| `DatePicker.Table*`               | Части для собственной таблицы календаря.                           |
| `DatePicker.WeekNumberHeaderCell` | Заголовок столбца с номерами недель.                               |
| `DatePicker.WeekNumberCell`       | Ячейка с номером недели.                                           |
| `DatePicker.MonthSelect`          | Нативный список месяца, связанный с активной датой.                |
| `DatePicker.YearSelect`           | Нативный список года, связанный с активной датой.                  |
| `DatePicker.PresetTrigger`        | Кнопка готового диапазона.                                         |
| `DatePicker.Context`              | Доступ к состоянию календаря без собственного DOM-элемента.        |

## Композиция

Используйте `DatePicker.Field` для обычного поля одной даты, `DatePicker.RangeField` для диапазона,
а `DatePicker.DayTable` внутри представления дней. Используйте `DatePicker.RootProvider` вместе с
`useDatePicker()`, когда состояние нужно разделить с элементами вне дерева корня.

Для собственной раскладки поля или таблицы календаря напрямую комбинируйте `Control`, `Input`,
`Trigger`, `ClearTrigger` и части `Table*`. Читайте `weekDays`, `weeks` и вспомогательные методы
таблицы через `DatePicker.Context`. В режиме выбора нескольких дат выводите выбранные значения
через `Context`, потому что один ввод не может представить весь список, и вызывайте `setValue()`
при удалении значения.

Корень автоматически помещает всплывающий календарь в портал. Используйте `portalled={false}` для
текущего DOM-поддерева, `portalRef` для своего контейнера или `inline`, чтобы оставить `Content`
в обычном потоке документа.

## Стилизация

Используйте `className` в React и `class` в Solid на экспортируемых частях для структурных стилей.
Варианты Tailwind используют нативные utility-классы и классы потребителя, а варианты CSS Modules
предоставляют переменные ниже. Оба подхода используют атрибуты состояния Ark и хуки `data-slot`
moduix.

### Хуки стилизации

Используйте следующие хуки `data-slot` для стилизации отдельных частей:

- `date-picker-root`, `date-picker-root-provider`, `date-picker-label`, `date-picker-control` и `date-picker-input`.
- `date-picker-trigger`, `date-picker-clear-trigger` и `date-picker-value-text`.
- `date-picker-positioner`, `date-picker-content`, `date-picker-view` и `date-picker-view-control`.
- `date-picker-view-trigger`, `date-picker-prev-trigger`, `date-picker-next-trigger` и `date-picker-range-text`.
- `date-picker-table-*`, `date-picker-table-cell-trigger`, `date-picker-week-number-header-cell` и `date-picker-week-number-cell`.
- `date-picker-month-select`, `date-picker-year-select` и `date-picker-preset-trigger`.

Атрибуты состояния Ark включают `data-state`, `data-disabled`, `data-readonly`, `data-invalid`,
`data-focus`, `data-selected`, `data-today`, `data-unavailable`, `data-outside-range`,
`data-in-range`, `data-range-start`, `data-range-end`, `data-in-hover-range`,
`data-hover-range-start`, `data-hover-range-end` и `data-view`.
