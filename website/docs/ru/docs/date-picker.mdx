Используйте `DatePicker` как корневой компонент, `DatePickerField` для стандартного поля и
`DatePickerDayTable`, `DatePickerMonthTable` и `DatePickerYearTable` для представлений календаря.
Каждая таблица выводит свой заголовок, поэтому переключатель представления работает сразу. Когда
календарь должен быть всплывающим, явно добавьте `DatePickerPositioner` и `DatePickerContent`.

## Выбор подходящего компонента

- Выберите **`Input`** для обычного текстового ввода даты, если календарь не нужен.
- Выберите **`DateInput`**, если пользователям нужно редактировать сегменты даты с клавиатуры.
- Выберите **`DatePicker`**, если пользователям нужно редактируемое поле даты и всплывающий или встроенный календарь.

## Примеры

### Управляемое состояние

Управляйте выбранным `DateValue[]`, обновляя его через `details.value`. В Vue для управляемого
значения используйте `v-model`.

<Example name="date-picker/controlled" />

### Представление по умолчанию и фиксированное число недель

Используйте `defaultView`, чтобы открыть другое представление. Добавьте `fixedWeeks`, чтобы высота
представления дней оставалась постоянной в шесть строк при переходе между месяцами.

<Example name="date-picker/default-view-and-fixed-weeks" />

### Состояние поля

`DatePicker` получает состояние поля из Ark. Если компонент не вложен в `Field`, задайте на корне
`invalid`, `disabled`, `readOnly` и `required`.

<Example name="date-picker/field-state" />

### Форма

Передайте `name`, чтобы включить выбранную дату в отправку нативной формы. `DatePickerField`
добавляет локализованный шаблон ввода и подписи действий, если их не переопределить.

<Example name="date-picker/form" />

### Встроенный календарь и номера недель

Задайте `inline`, чтобы календарь остался в потоке документа. Встроенный календарь отображает
`DatePickerContent` напрямую, без `DatePickerPositioner`. Номера недель включаются свойством
`showWeekNumbers` на корне: `DatePickerDayTable` читает его и добавляет столбец.

<Example name="date-picker/inline-and-week-numbers" />

### Локаль и формат

Параметры `locale`, `startOfWeek`, `format` и `parse` передаются в Ark.

<Example name="date-picker/locale-and-format" />

### Минимальная, максимальная и недоступные даты

Используйте `min`, `max` и `isDateUnavailable` для правил валидации, которые должны влиять и на
ввод, и на ячейки календаря.

<Example name="date-picker/min-max-and-unavailable" />

### Выбор месяца и года

Используйте `DatePickerMonthSelect` и `DatePickerYearSelect` для нативных списков, связанных с
активной датой. Используйте `DatePickerContext` только для другой собственной компоновки
заголовка или календаря.

<Example name="date-picker/month-year-select" />

### Выбор месяца

Задайте `defaultView="month"` и `minView="month"`, чтобы пользователь выбирал только месяц.
Используйте `format` и `parse`, если ввод должен принимать строку с месяцем и годом.

<Example name="date-picker/month-picker" />

### Несколько дат

Используйте `selectionMode="multiple"` и при необходимости ограничьте число выбранных дат через
`maxSelectedDates`. Выводите выбранные даты через `DatePickerContext` и вызывайте
`datePicker.setValue()` при удалении даты.

<Example name="date-picker/multiple" />

### Несколько месяцев

Задайте `numOfMonths`, когда пользователю нужно видеть несколько месяцев при выборе дат. Выведите
по `DatePickerDayTable` на каждый месяц и передайте второй таблице `offset={1}`.

<Example name="date-picker/multiple-months" />

### Предустановки

`DatePickerPresetTrigger` принимает имена готовых диапазонов, например `last7Days`, или собственный
`DateValue[]`. Используйте режим диапазона и два индексированных ввода, чтобы показать обе даты.

<Example name="date-picker/presets" />

### Диапазон

Используйте `selectionMode="range"` с двумя значениями. Ark управляет наведением, началом и концом
диапазона, а также форматированием ввода. Для диапазона нужны два индексированных ввода.

<Example name="date-picker/range" />

### Root Provider

Используйте `useDatePicker()` из пакета выбранного фреймворка вместе с `DatePickerRootProvider`,
когда состояние календаря нужно разделить с элементами вне дерева корня.

<Example name="date-picker/root-provider" />

### Выбрать сегодня

Используйте `DatePickerContext`, когда соседнему элементу нужно вызвать вспомогательный метод,
например `selectToday()`.

<Example name="date-picker/select-today" />

### Дата и время

Храните время в выбранном значении через объекты `CalendarDateTime`. Объедините календарь с
`DateInput`, настроенным на ввод минут, чтобы оба элемента редактировали одно значение.

<Example name="date-picker/with-time" />

### Выбор года

Задайте `defaultView="year"`, `minView="year"` и `maxView="year"`, чтобы пользователь выбирал
только год. Используйте `DatePickerRangeText` в заголовке, поскольку у представления года нет более высокого
уровня для переключения.

<Example name="date-picker/year-picker" />

### Сборка из частей

Тот же выбор даты, что в Basic, но без `DatePickerField` и помощников для таблиц: поле содержит ввод,
кнопку очистки и триггер, а каждый вид рисует свою шапку и сетку из `DatePickerContext`. Кнопки
получают явные иконки. Начинайте с него, если полю или ячейкам календаря нужна своя отрисовка,
например класс или дополнительное содержимое у отдельных дней.

<Example name="date-picker/build-from-parts" />

## Композиция

Используйте `DatePickerField` для обычного поля одной даты, `DatePickerRangeField` для диапазона,
а `DatePickerDayTable`, `DatePickerMonthTable` и `DatePickerYearTable` внутри соответствующих
представлений. Передайте таблице `showHeader={false}`, если заголовок собран отдельно. Используйте `DatePickerRootProvider` вместе с
`useDatePicker()`, когда состояние нужно разделить с элементами вне дерева корня.

Для собственной раскладки поля или таблицы календаря напрямую комбинируйте `DatePickerControl`,
`DatePickerInput`, `DatePickerTrigger`, `DatePickerClearTrigger` и части `DatePickerTable*`.
Читайте `weekDays`, `weeks` и вспомогательные методы таблицы через `DatePickerContext`. В режиме
выбора нескольких дат выводите выбранные значения через `DatePickerContext`, потому что один ввод
не может представить весь список, и вызывайте `setValue()`
при удалении значения.

Корень автоматически помещает всплывающий календарь в портал. Используйте `portalled={false}` для
текущего DOM-поддерева, `portalRef` для своего контейнера или `inline`, чтобы оставить `DatePickerContent`
в обычном потоке документа.

## Стилизация

Используйте `className` в React, `class` в Solid и `class` в Vue на экспортируемых частях для структурных стилей.
Варианты Tailwind используют нативные utility-классы и классы потребителя, а варианты CSS Modules
предоставляют переменные ниже. Оба подхода используют атрибуты состояния Ark и хуки `data-slot`
moduix.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `ArrowLeft` / `ArrowRight` / `ArrowUp` / `ArrowDown` | Перемещает фокус на день или неделю в календаре. |
| `PageUp` / `PageDown` | Переходит к предыдущему или следующему месяцу; с Shift к году. |
| `Home` / `End` | Переходит к началу или концу недели. |
| `Enter` / `Space` | Выбирает дату в фокусе. |
| `Esc` | Закрывает календарь. |
