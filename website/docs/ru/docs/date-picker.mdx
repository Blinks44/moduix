## Выбор подходящего компонента

- Выберите **`Input`** для обычного текстового ввода даты, если календарь не нужен.
- Выберите **`DateInput`**, если пользователям нужно редактировать сегменты даты с клавиатуры.
- Выберите **`DatePicker`**, если пользователям нужно редактируемое поле даты и всплывающий или встроенный календарь.

## Базовый пример

`DatePicker` использует состояние и поведение календаря Ark UI, а для распространённых сценариев предоставляет
готовые части. Используйте `DatePicker.Field` для стандартного поля с вводом и действиями, а
`DatePicker.DayTable` для таблицы дней.

## Композиция

### Рекомендуемая композиция

Используйте `DatePicker.Field` для стандартного поля одной даты, `DatePicker.RangeField` для поля диапазона, а
`DatePicker.DayTable` для таблицы дней. Корневой компонент автоматически помещает `Positioner` в портал.
Используйте `portalled={false}`, чтобы оставить всплывающее окно в текущем DOM-поддереве, или `portalRef`, чтобы
указать другой контейнер. Задайте `inline`, если календарь должен оставаться в обычном потоке документа. Части
всплывающего календаря остаются явными, поэтому их можно стилизовать отдельно.

### Когда нужна своя композиция

Используйте `DatePicker.Control`, `DatePicker.Input`, `DatePicker.Trigger`, `DatePicker.ClearTrigger` и низкоуровневые
части `Table*` напрямую, когда нужна другая структура поля или сетки календаря. Используйте `DatePicker.Context`,
если собственной разметке нужно состояние календаря: `weekDays`, `weeks`, `getMonthsGrid()`, `getYearsGrid()`,
`getOffset()` или вспомогательные действия. Используйте `asChild` для другой семантической оболочки части, а `ids`,
если внешняя подпись или вспомогательный текст должны использовать стабильные ID компонента.

### Свойства по умолчанию

По умолчанию содержимое всплывающего календаря монтируется при первом открытии и удаляется после анимации закрытия.
Задайте `lazyMount={false}`, чтобы рендерить его сразу, или `unmountOnExit={false}`, чтобы оставить его в DOM после
первого открытия.

| Свойство                                 | По умолчанию       | Примечания                                        |
| ---------------------------------------- | ------------------ | ------------------------------------------------- |
| `DatePicker.Field.placeholder`           | шаблон даты Ark для локали | Заменяет автоматически созданный плейсхолдер поля.              |
| `DatePicker.Field.clearLabel`            | перевод Ark UI             | Заменяет подпись кнопки очистки.                                |
| `DatePicker.Field.triggerLabel`          | перевод Ark UI             | Заменяет подпись кнопки открытия.                               |
| `DatePicker.RangeField.startPlaceholder` | шаблон даты Ark для локали | Заменяет плейсхолдер поля для начальной даты диапазона.          |
| `DatePicker.RangeField.endPlaceholder`   | шаблон даты Ark для локали | Заменяет плейсхолдер поля для конечной даты диапазона.          |
| `DatePicker.DayTable.showHeader`         | `true`                     | Показывает кнопки предыдущего месяца, выбора представления и следующего месяца. |
| `DatePicker.DayTable.showWeekNumbers`    | `false`                    | Показывает заголовок и ячейки с номерами недель.                |
| `DatePicker.openOnClick`                 | `false`                    | Открывает календарь при нажатии на поле.                        |
| `DatePicker.closeOnSelect`               | `true`                     | Закрывает календарь после выбора; не действует в режиме нескольких дат. |

### Особенности поведения

`value`, `defaultValue` и `onValueChange(details)` используют массив `DateValue[]` из Ark. Из объекта `details` можно
получить `details.value`, `details.valueAsString` и `details.view`: выбранное значение, его отформатированное
представление и текущую панель. Импортируйте `DatePicker.Context`, `useDatePicker` и `useDatePickerContext` из
`@moduix/react`; при необходимости импортируйте `parseDate` и типы дат из `@ark-ui/react/date-picker`.
Стандартная ширина корневого компонента и всплывающего окна составляет `18.75rem` (300 px), а для диапазона используется
ширина `24rem` (384 px), чтобы иконки действий не перекрывали значения дат. Если нужна более широкая композиция,
переопределите `--moduix-date-picker-width` или `--moduix-date-picker-content-width`. Поскольку содержимое
окна рендерится в портале, задавайте переменные его размера на `DatePicker.Content` или другом элементе внутри дерева
всплывающего календаря, а не только на `DatePicker`.

`open`, `defaultOpen` и `onOpenChange(details)` управляют состоянием всплывающего окна. `view`, `defaultView`,
`minView`, `maxView` и `onViewChange(details)` управляют активной панелью календаря. Задайте `openOnClick`, чтобы
открывать календарь при нажатии на поле. `closeOnSelect` закрывает календарь после полного выбора и не действует в
режиме нескольких дат. Если композиция рендерит только одну панель, укажите это представление одновременно в `minView`
и `maxView`.

Внутри `Field` или `Fieldset` moduix компонент `DatePicker` наследует значения `disabled` и `invalid` из контекста.
`Field` также передаёт `readOnly` и `required`. Свойства, заданные непосредственно на `DatePicker`, имеют приоритет.
`DatePicker.Field` всегда использует индекс поля `0`. `DatePicker.RangeField` резервирует индексы `0` и `1` для полей
начальной и конечной даты. Для другой структуры полей используйте `Control` и `Input` напрямую.

Используйте `selectionMode="single"`, `"range"` или `"multiple"`. `maxSelectedDates` применяется только к
множественному выбору. `numOfMonths`, `fixedWeeks` и `showWeekNumbers` изменяют таблицу календаря.

Для недоступных дат используйте `min`, `max` и `isDateUnavailable(date, locale)`, чтобы эти ограничения применялись
и к полю, и к ячейкам календаря. Настройте локаль и форматирование с помощью `locale`, `timeZone`, `startOfWeek`,
`format`, `parse`, `translations` и `createCalendar`.

### Хуки стилизации

Используйте эти атрибуты `data-slot`, чтобы обращаться к отдельным частям компонента:

- `data-slot="date-picker-root"` на корневом компоненте.
- `data-slot="date-picker-root-provider"` на корневом компоненте провайдера.
- `data-slot="date-picker-label"` на подписи поля.
- `data-slot="date-picker-control"` на обёртке поля, `DatePicker.Field` и `DatePicker.RangeField`.
- `data-slot="date-picker-input"` на редактируемом поле.
- `data-slot="date-picker-trigger"` и `data-slot="date-picker-clear-trigger"` на действиях поля.
- `data-slot="date-picker-value-text"` на тексте с выбранными значениями.
- `data-slot="date-picker-positioner"` и `data-slot="date-picker-content"` на всплывающем слое.
- `data-slot="date-picker-range-text"` на тексте с видимым диапазоном дат.
- `data-slot="date-picker-view"`, `date-picker-view-control`, `date-picker-view-trigger`,
  `date-picker-prev-trigger` и `date-picker-next-trigger` на навигации календаря.
- `data-slot="date-picker-table-*"` на частях таблицы и `data-slot="date-picker-table-cell-trigger"` на ячейках.
- `data-slot="date-picker-week-number-header-cell"` и `data-slot="date-picker-week-number-cell"` на ячейках
  с номерами недель.
- `data-slot="date-picker-month-select"` и `data-slot="date-picker-year-select"` на нативных списках выбора.
- `data-slot="date-picker-preset-trigger"` на кнопках предустановленных диапазонов.

Атрибуты состояния Ark включают `data-state`, `data-disabled`, `data-readonly`, `data-invalid`,
`data-focus`, `data-selected`, `data-today`, `data-unavailable`, `data-outside-range`,
`data-in-range`, `data-range-start`, `data-range-end`, `data-in-hover-range`,
`data-hover-range-start`, `data-hover-range-end` и `data-view`.
