## Выбор подходящего компонента

- Выберите **`Input`** для обычного текстового ввода даты, если календарь не нужен.
- Выберите **`DateInput`**, если пользователям нужно редактировать сегменты даты с клавиатуры.
- Выберите **`DatePicker`**, если пользователям нужны редактируемое поле даты и всплывающий или встроенный календарь.

## Базовый пример

`DatePicker` сохраняет состояние даты и поведение календаря Ark, а для типичного сценария предоставляет готовые
части. Используйте `DatePicker.Field` для стандартного поля даты и `DatePicker.DayTable` для таблицы дней.

## Анатомия

```text
DatePicker
├─ DatePicker.Label
├─ DatePicker.Control
│  ├─ DatePicker.Input
│  ├─ DatePicker.ClearTrigger
│  └─ DatePicker.Trigger
├─ DatePicker.Field / DatePicker.RangeField (готовые поля)
├─ Поддерево всплывающего календаря (автоматически переносится в портал)
│  └─ DatePicker.Positioner
│     └─ DatePicker.Content
│        ├─ DatePicker.View[view="day" | "month" | "year"]
│        │  ├─ DatePicker.ViewControl
│        │  │  ├─ DatePicker.PrevTrigger
│        │  │  ├─ DatePicker.ViewTrigger / DatePicker.RangeText
│        │  │  └─ DatePicker.NextTrigger
│        │  ├─ DatePicker.DayTable (готовая таблица дней)
│        │  └─ DatePicker.Table
│        │     ├─ DatePicker.TableHead / TableBody / TableRow
│        │     ├─ DatePicker.TableHeader
│        │     ├─ DatePicker.TableCell
│        │     └─ DatePicker.TableCellTrigger
│        ├─ DatePicker.MonthSelect / DatePicker.YearSelect
│        └─ DatePicker.PresetTrigger
├─ DatePicker.ValueText (необязательная сводка выбранного значения)
└─ DatePicker.Context
```

| Часть                            | Назначение                                                       |
| -------------------------------- | ---------------------------------------------------------------- |
| `DatePicker` / `DatePicker.Root` | Управляет значением, представлением, состоянием открытия, локалью, валидацией и контекстом формы. |
| `DatePicker.RootProvider`        | Рендерит части, используя состояние из `useDatePicker()`.                                      |
| `DatePicker.Label`               | Подпись поля, доступная вспомогательным технологиям.                                             |
| `DatePicker.Control`             | Обёртка поля, которая получает атрибуты состояния Ark.                                            |
| `DatePicker.Field`               | Готовое поле с вводом даты, очисткой и открытием календаря.                                       |
| `DatePicker.RangeField`          | Готовое поле диапазона с индексированными полями начала и конца.                                  |
| `DatePicker.Input`               | Редактируемое поле даты, участвующее в отправке формы.                                            |
| `DatePicker.Trigger`             | Открывает календарь и по умолчанию использует иконку календаря.                                  |
| `DatePicker.ClearTrigger`        | Очищает текущее значение и по умолчанию использует иконку закрытия.                               |
| `DatePicker.Positioner`          | Плавающий слой с CSS-переменными позиционирования Ark.                                            |
| `DatePicker.Content`             | Контейнер календаря во всплывающем или встроенном режиме.                                         |
| `DatePicker.View`                | Панель дней, месяцев или лет.                                                                      |
| `DatePicker.ValueText`           | Сводка выбранных значений с необязательной подсказкой или render prop.                              |
| `DatePicker.DayTable`            | Стандартная таблица дней, построенная на основе контекста Ark.                                    |
| `DatePicker.Table*`              | Низкоуровневые части таблицы календаря для собственной разметки.                                   |
| `DatePicker.MonthSelect`         | Нативный выбор месяца, связанный с датой в фокусе.                                                 |
| `DatePicker.YearSelect`          | Нативный выбор года, связанный с датой в фокусе.                                                   |
| `DatePicker.PresetTrigger`       | Кнопка предустановленного диапазона.                                                               |

## Композиция

### Рекомендуемая композиция

Используйте `DatePicker.Field` для стандартного поля одной даты, `DatePicker.RangeField` для полей диапазона, а
`DatePicker.DayTable` для таблицы дней. Корневой компонент автоматически рендерит `Positioner` в портале.
Используйте `portalled={false}`, чтобы оставить всплывающее окно в текущем DOM-поддереве, или `portalRef`, чтобы
указать другой контейнер. Задайте `inline`, если календарь должен оставаться в обычном потоке документа. Части
всплывающего календаря остаются явными, поэтому их можно стилизовать отдельно.

### Когда нужна своя композиция

Используйте `DatePicker.Control`, `DatePicker.Input`, `DatePicker.Trigger`, `DatePicker.ClearTrigger` и низкоуровневые
части `Table*` напрямую, когда нужна другая структура поля или сетки календаря. Используйте `DatePicker.Context`,
если собственной разметке нужно состояние календаря: `weekDays`, `weeks`, `getMonthsGrid()`, `getYearsGrid()`,
`getOffset()` или вспомогательные действия.

### Свойства по умолчанию

По умолчанию содержимое всплывающего календаря монтируется при первом открытии и размонтируется после анимации
закрытия. Задайте `lazyMount={false}`, чтобы рендерить его сразу, или `unmountOnExit={false}`, чтобы не размонтировать
его после первого открытия.

| Свойство                                 | По умолчанию       | Примечания                                        |
| ---------------------------------------- | ------------------ | ------------------------------------------------- |
| `DatePicker.Field.placeholder`           | шаблон даты Ark для локали | Заменяет автоматически созданную подсказку поля.                |
| `DatePicker.Field.clearLabel`            | перевод Ark                | Заменяет подпись кнопки очистки.                                |
| `DatePicker.Field.triggerLabel`          | перевод Ark                | Заменяет подпись кнопки открытия.                               |
| `DatePicker.RangeField.startPlaceholder` | шаблон даты Ark для локали | Заменяет подсказку поля начала диапазона.                       |
| `DatePicker.RangeField.endPlaceholder`   | шаблон даты Ark для локали | Заменяет подсказку поля конца диапазона.                        |
| `DatePicker.DayTable.showHeader`         | `true`                     | Показывает кнопки перехода, выбора представления и возврата перед таблицей. |
| `DatePicker.DayTable.showWeekNumbers`    | `false`                    | Показывает заголовок и ячейки с номерами недель.                |

### Особенности поведения

`value`, `defaultValue` и `onValueChange(details)` используют формат `DateValue[]` Ark. Импортируйте
`DatePicker.Context`, `useDatePicker` и `useDatePickerContext` из `@moduix/react`; при необходимости импортируйте
`parseDate` и типы дат из `@ark-ui/react/date-picker`. Стандартная ширина корневого компонента и всплывающего окна
составляет `18.75rem` (300 px). Если нужна более широкая композиция, переопределите
`--moduix-date-picker-width` или `--moduix-date-picker-content-width`.
Поскольку содержимое окна рендерится в портале, задавайте переменные его размера на `DatePicker.Content` или другом
элементе внутри дерева всплывающего календаря, а не только на `DatePicker`.

`open`, `defaultOpen` и `onOpenChange(details)` управляют состоянием всплывающего окна. `view`, `defaultView`,
`minView`, `maxView` и `onViewChange(details)` управляют активной панелью календаря. Если композиция рендерит только
одну панель, укажите этот вид одновременно в `minView` и `maxView`.

Внутри `Field` или `Fieldset` moduix компонент `DatePicker` получает значения `disabled` и `invalid` из контекста.
`Field` также передаёт `readOnly` и `required`. Свойства, заданные непосредственно на `DatePicker`, имеют приоритет.
`DatePicker.Field` всегда использует индекс поля `0`. `DatePicker.RangeField` резервирует индексы `0` и `1` для полей
начала и конца. Для другой структуры полей используйте `Control` и `Input` напрямую.

Используйте `selectionMode="single"`, `"range"` или `"multiple"`. `maxSelectedDates` применяется только к
множественному выбору. `numOfMonths`, `fixedWeeks` и `showWeekNumbers` изменяют таблицу календаря.

Для недоступных дат используйте `min`, `max` и `isDateUnavailable(date, locale)`, чтобы эти ограничения применялись
и к полю, и к ячейкам календаря. Для локализации используйте
`locale`, `timeZone`, `format`, `parse`, `translations` и `createCalendar`.

### Хуки стилизации

Используйте эти `data-slot`, чтобы обращаться к отдельным частям компонента:

- `data-slot="date-picker-root"` на корневом компоненте.
- `data-slot="date-picker-root-provider"` на корневом компоненте провайдера.
- `data-slot="date-picker-label"` на подписи поля.
- `data-slot="date-picker-control"` на обёртке поля, `DatePicker.Field` и `DatePicker.RangeField`.
- `data-slot="date-picker-input"` на редактируемом поле.
- `data-slot="date-picker-trigger"` и `data-slot="date-picker-clear-trigger"` на действиях поля.
- `data-slot="date-picker-value-text"` на сводках выбранного значения.
- `data-slot="date-picker-positioner"` и `data-slot="date-picker-content"` на плавающем слое.
- `data-slot="date-picker-view"`, `date-picker-view-control`, `date-picker-view-trigger`,
  `date-picker-prev-trigger` и `date-picker-next-trigger` на навигации календаря.
- `data-slot="date-picker-table-*"` на частях таблицы и `data-slot="date-picker-table-cell-trigger"` на ячейках.
- `data-slot="date-picker-week-number-*"` на ячейках с номерами недель.
- `data-slot="date-picker-month-select"` и `data-slot="date-picker-year-select"` на нативных списках выбора.
- `data-slot="date-picker-preset-trigger"` на кнопках предустановленных диапазонов.

Атрибуты состояния Ark включают `data-state`, `data-disabled`, `data-readonly`, `data-invalid`,
`data-focus`, `data-selected`, `data-today`, `data-unavailable`, `data-outside-range`,
`data-in-range`, `data-range-start`, `data-range-end`, `data-in-hover-range`,
`data-hover-range-start`, `data-hover-range-end` и `data-view`.
