## Выбор подходящего компонента

Используйте `Combobox`, когда пользователю нужно выбрать значение из известного списка и найти подходящий вариант с помощью ввода.
Если список фиксирован и редактируемое поле не требуется, используйте `Select`.

## Базовый пример


Создайте коллекцию Ark с помощью `useListCollection` и передайте её в `Combobox`. Структуру списка задайте явно.
Для обычных вариантов используйте `Combobox.Option`, а если нужна нестандартная разметка, используйте `Combobox.Item`.

## Анатомия

```text
Combobox / Combobox.Root[collection]
├─ Combobox.Label
├─ Combobox.Control
│  ├─ Combobox.Input
│  ├─ Combobox.ClearTrigger
│  └─ Combobox.Trigger
└─ Поддерево всплывающего списка (автоматически помещается в портал)
 └─ Combobox.Positioner
    └─ Combobox.Content
       ├─ Combobox.Empty
       ├─ Combobox.Status
       ├─ Combobox.List
       │  ├─ Combobox.Option[item]
       │  └─ Combobox.Item[item]
       │     ├─ Combobox.ItemText
       │     └─ Combobox.ItemIndicator
       └─ Combobox.ItemGroup
          ├─ Combobox.ItemGroupLabel
          └─ Combobox.Item
```

| Часть                        | Назначение                                                         |
| ---------------------------- | ------------------------------------------------------------------ |
| `Combobox` / `Combobox.Root` | Управляет состоянием Combobox, фильтрацией, подсветкой и выбранными значениями. |
| `Combobox.Control`           | Обёртка для поля ввода и кнопок действий.                          |
| `Combobox.Input`             | Поле, в котором пользователь ищет и выбирает вариант.              |
| `Combobox.Trigger`           | Открывает и закрывает список вариантов.                            |
| `Combobox.ClearTrigger`      | Очищает выбранное значение и/или текст в поле.                     |
| `Combobox.Positioner`        | Позиционирует всплывающий список.                                  |
| `Combobox.Content`           | Контейнер содержимого списка.                                      |
| `Combobox.Status`            | Стилизованный контейнер для сообщений приложения о загрузке, ошибке или подсказке. |
| `Combobox.List`              | Обёртка списка вариантов.                                          |
| `Combobox.Option`            | Готовая строка для простого варианта, с текстом и индикатором.     |
| `Combobox.Item`              | Выбираемая строка списка.                                          |
| `Combobox.ItemText`          | Слот текста элемента.                                               |
| `Combobox.ItemIndicator`     | Слот индикатора выбранного состояния.                              |
| `Combobox.Context`           | Доступ к состоянию Combobox без добавления элементов в DOM.        |
| `Combobox.ItemContext`       | Доступ к состоянию текущего элемента без добавления элементов в DOM. |

`Combobox.RootProvider` использует ту же стилизацию корневого компонента для состояния, созданного через `useCombobox` из moduix.
Состояние Combobox внутри дерева можно получить через `Combobox.Context` или `useComboboxContext`, а состояние элемента - через
`Combobox.ItemContext` или `useComboboxItemContext`.

## Композиция

Для статических элементов используйте `createListCollection`, а для фильтрации и обновления коллекции
используйте `useListCollection`. Для объектов задайте `itemToString` и `itemToValue`.

Корневой компонент автоматически помещает `Positioner` в портал, но `Positioner` и `Content` остаются
явными частями композиции. Укажите `portalled={false}`, чтобы оставить список в текущем дереве, или передайте
`portalRef` для конкретного контейнера. Для простых строк используйте `Combobox.Option`, а для сложных строк
с `asChild` используйте `Combobox.Item`.

Храните `value` в состоянии приложения, если оно нужно другим частям интерфейса. Когда состояние создаётся
за пределами дерева, передайте `useCombobox` в `Combobox.RootProvider`. В режиме множественного выбора теги
и другое представление значений принадлежат приложению; если они должны находиться в одном поле, используйте
композицию с `TagsInput`. `Combobox.Status` также отвечает только за сообщения приложения и не управляет
состоянием загрузки или ошибки.

## Стилизация

Используйте `className` в React и `class` в Solid для структурных стилей экспортируемых частей.
Варианты Tailwind используют обычные utility-классы и классы приложения, а CSS-переменные ниже настраивают
варианты CSS Modules. Атрибуты состояния и `data-slot` общие для обоих вариантов стилизации.

### CSS-свойства

<CssPropertiesSection properties={ComboboxDocs.comboboxOverrideCssProperties} />

### Хуки стилизации

- Части Ark сохраняют `data-scope="combobox"` и значения `data-part`. moduix добавляет к стилизованным
  частям стабильные хуки `data-slot`.
- Стабильные слоты включают `combobox-root`, `combobox-root-provider`, `combobox-label`,
  `combobox-control`, `combobox-input`, `combobox-clear-trigger`, `combobox-trigger`,
  `combobox-positioner`, `combobox-content`, `combobox-empty`, `combobox-status`, `combobox-list`,
  `combobox-item-group`, `combobox-item-group-label`, `combobox-item`, `combobox-item-text` и
  `combobox-item-indicator`. `Combobox.Option` переиспользует слоты элемента, не добавляя собственного
  отдельного хука стилизации.
- Атрибуты состояния Ark включают `data-state="open|closed"`, `data-focus`, `data-invalid`, `data-disabled`,
  `data-highlighted`, `data-empty`, `data-placement` и `data-side`.
- Переменные позиционирования Ark включают `--reference-width`, `--available-width`, `--available-height`,
  `--transform-origin`, `--z-index` и `--layer-index`. Общая тема задаёт нейтральные начальные значения для инструментов
  разработки и содержимого без позиционирования, а Ark заменяет их измеренными значениями на `Positioner`.
