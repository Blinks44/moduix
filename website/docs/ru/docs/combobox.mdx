Создайте коллекцию Ark с помощью `useListCollection` и передайте её в `Combobox`. Структуру списка задайте явно.
Для обычных вариантов используйте `ComboboxOption`, а если нужна нестандартная разметка, используйте `ComboboxItem`.
Колбэк `onInputValueChange` получает объект `details` от Ark.
Примеры для Vue используют нативные SFC с `script setup`, refs, слотами и `v-model`, когда это предусмотрено контрактом компонента.

## Выбор подходящего компонента

Используйте `Combobox`, когда пользователю нужно выбрать значение из известного списка и найти подходящий вариант с помощью ввода.
Если список фиксирован и редактируемое поле не требуется, используйте `Select`.

## Примеры

### Асинхронный поиск

Заменяйте элементы коллекции результатами асинхронного запроса и показывайте `ComboboxStatus`, пока запрос выполняется.
Используйте `details.reason`, чтобы отличать пользовательский ввод от программного изменения поля. Если поле пустое,
показывайте статус `Start typing to search…`, чтобы список не оставался пустым.

### Автоматическая подсветка

Задайте `inputBehavior="autohighlight"`, чтобы при вводе выделять первый подходящий элемент и выбирать его клавишей Enter
без дополнительного нажатия клавиши со стрелкой.

<Example name="combobox/auto-highlight" />

### Управляемое состояние

Управляйте массивом выбранных строк и получайте новое значение из `details.value`.

<Example name="combobox/controlled" />

### Создание значения

Сочетайте `allowCustomValue` с изменением коллекции, чтобы показывать временный элемент «Создать», а после выбора
заменяйте его временное значение на введённый пользователем текст.

<Example name="combobox/creatable" />

### Пользовательские объекты и группировка

Настройте в коллекции преобразование объектов в подписи и значения, затем отображайте группы Ark через `collection.group()`.
Подписи групп остаются у верхнего края всплывающего списка при прокрутке результатов.

<Example name="combobox/custom-objects-and-grouping" />

### Динамическое изменение

Формируйте коллекцию из текущего ввода, если предложения появляются только после начала ввода. Проверяйте
`details.reason`, чтобы не перестраивать её после изменения поля, вызванного выбором.

<Example name="combobox/dynamic" />

### Встроенное автодополнение

Задайте `inputBehavior="autocomplete"` и фильтруйте с помощью `startsWith`, чтобы подставлять в поле первый подходящий
вариант и сохранять клавиатурную навигацию Ark.

<Example name="combobox/inline-autocomplete" />

### Ограничение результатов

Задайте `limit` в `useListCollection`, если полный набор совпадений не нужен или его трудно просматривать во всплывающем списке.
Фильтрация всё равно выполняется по всей исходной коллекции.

<Example name="combobox/limit-results" />

### Множественный выбор

Включите `multiple` и отображайте выбранные объекты из управляемого `value`. Теги нужно отрисовать на стороне приложения.
Если они должны находиться в одной оболочке поля, скомпонуйте `Combobox` с `TagsInput`.

<Example name="combobox/multiple" />

### Root Provider

Создавайте состояние через `useCombobox` из moduix, когда внешним элементам управления нужны императивные методы или общее
состояние до отображения корневого компонента. `ComboboxRootProvider` сохраняет стили корня moduix и настройки портала.

<Example name="combobox/root-provider" />

### Виртуализация

Для больших коллекций отображайте только видимые строки с помощью TanStack Virtual. В React используйте
`@tanstack/react-virtual`, в Solid - `@tanstack/solid-virtual`, а в Vue - `@tanstack/vue-virtual`,
затем свяжите клавиатурную навигацию Ark с `scrollToIndexFn`. Сохраняйте `aria-setsize` и
`aria-posinset` у виртуализированных строк.

<Example name="combobox/virtualized" />

### Вместе с TagsInput

Используйте `Combobox` вместе с `TagsInput`, если пользователю нужны отфильтрованные предложения, а выбранные значения должны
находиться в одном редактируемом поле с тегами.

<Example name="combobox/with-tags-input" />

### Расширенная настройка

Используйте полную композицию элемента, если ему нужен собственный семантический элемент или макет. В этом примере
каждый результат отображается как ссылка через `ComboboxItem asChild`.

## Композиция

Для статических элементов используйте `createListCollection`, а для фильтрации и обновления коллекции
используйте `useListCollection`. Для объектов задайте `itemToString` и `itemToValue`.

`Combobox` автоматически помещает `ComboboxPositioner` в портал, но `ComboboxPositioner` и `ComboboxContent` остаются
явными частями композиции. Укажите `portalled={false}`, чтобы оставить список в текущем дереве, или передайте
`portalRef` для конкретного контейнера. Для простых строк используйте `ComboboxOption`, а для сложных строк
с `asChild` используйте `ComboboxItem`.

Храните `value` в состоянии приложения, если оно нужно другим частям интерфейса. Когда состояние создаётся
за пределами дерева, передайте `useCombobox` в `ComboboxRootProvider`. В режиме множественного выбора теги
и другое представление значений принадлежат приложению; если они должны находиться в одном поле, используйте
композицию с `TagsInput`. `ComboboxStatus` также отвечает только за сообщения приложения и не управляет
состоянием загрузки или ошибки.

## Стилизация

Используйте `className` в React и `class` в Solid и Vue для структурных стилей экспортируемых частей.
Варианты Tailwind используют обычные utility-классы и классы приложения, а CSS-переменные ниже настраивают
варианты CSS Modules. Атрибуты состояния и `data-slot` общие для обоих вариантов стилизации.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `Combobox` | `combobox-root` |
| `ComboboxRootProvider` | `combobox-root-provider` |
| `ComboboxLabel` | `combobox-label` |
| `ComboboxControl` | `combobox-control` |
| `ComboboxInput` | `combobox-input` |
| `ComboboxClearTrigger` | `combobox-clear-trigger` |
| `ComboboxTrigger` | `combobox-trigger` |
| `ComboboxPositioner` | `combobox-positioner` |
| `ComboboxContent` | `combobox-content` |
| `ComboboxEmpty` | `combobox-empty` |
| `ComboboxStatus` | `combobox-status` |
| `ComboboxList` | `combobox-list` |
| `ComboboxItemGroup` | `combobox-item-group` |
| `ComboboxItemGroupLabel` | `combobox-item-group-label` |
| `ComboboxItem` | `combobox-item` |
| `ComboboxItemText` | `combobox-item-text` |
| `ComboboxItemIndicator` | `combobox-item-indicator` |

- Части Ark сохраняют `data-scope="combobox"` и значения `data-part`. moduix добавляет к стилизованным
  частям стабильные хуки `data-slot`.
- `ComboboxOption` переиспользует слоты элемента, не добавляя собственного
  отдельного хука стилизации.
- Атрибуты состояния Ark включают `data-state="open|closed"`, `data-focus`, `data-invalid`, `data-disabled`,
  `data-highlighted`, `data-empty`, `data-placement` и `data-side`.
- Переменные позиционирования Ark включают `--reference-width`, `--available-width`, `--available-height`,
  `--transform-origin`, `--z-index` и `--layer-index`. Общая тема задаёт нейтральные начальные значения для инструментов
  разработки и содержимого без позиционирования, а Ark заменяет их измеренными значениями на `Positioner`.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `ArrowDown` / `ArrowUp` | Открывает список и подсвечивает следующую или предыдущую опцию. |
| `Home` / `End` | Подсвечивает первую или последнюю опцию. |
| `Enter` | Выбирает подсвеченную опцию. |
| `Esc` | Закрывает список. |
