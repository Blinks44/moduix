## Выбор подходящего компонента

Используйте `Combobox`, когда пользователю нужно выбрать значение из известного списка и найти подходящий вариант с помощью ввода.
Если список фиксирован и редактируемое поле не требуется, используйте `Select`.

## Базовый пример

Создайте коллекцию Ark с помощью `useListCollection` и передайте её в `Combobox`. Структуру списка задайте явно.
Для обычных вариантов используйте `Combobox.Option`, а если нужна нестандартная разметка, используйте `Combobox.Item`.
Колбэк `onInputValueChange` получает объект `details` от Ark.

## Анатомия

```text
Combobox / Combobox.Root[collection]
├─ Combobox.Label
├─ Combobox.Control
│  ├─ Combobox.Input
│  ├─ Combobox.ClearTrigger
│  └─ Combobox.Trigger
└─ Поддерево всплывающего списка (автоматически помещается в портал)
 └─ Combobox.Positioner
    └─ Combobox.Content
       ├─ Combobox.Empty
       ├─ Combobox.Status
       ├─ Combobox.List
       │  ├─ Combobox.Option[item]
       │  └─ Combobox.Item[item]
       │     ├─ Combobox.ItemText
       │     └─ Combobox.ItemIndicator
       └─ Combobox.ItemGroup
          ├─ Combobox.ItemGroupLabel
          └─ Combobox.Item
```

| Часть                        | Назначение                                                         |
| ---------------------------- | ------------------------------------------------------------------ |
| `Combobox` / `Combobox.Root` | Управляет состоянием Combobox, фильтрацией, подсветкой и выбранными значениями. |
| `Combobox.Control`           | Обёртка для поля ввода и кнопок действий.                          |
| `Combobox.Input`             | Поле, в котором пользователь ищет и выбирает вариант.              |
| `Combobox.Trigger`           | Открывает и закрывает список вариантов.                            |
| `Combobox.ClearTrigger`      | Очищает выбранное значение и/или текст в поле.                     |
| `Combobox.Positioner`        | Позиционирует всплывающий список.                                  |
| `Combobox.Content`           | Контейнер содержимого списка.                                      |
| `Combobox.Status`            | Стилизованный контейнер для сообщений приложения о загрузке, ошибке или подсказке. |
| `Combobox.List`              | Обёртка списка вариантов.                                          |
| `Combobox.Option`            | Готовая строка для простого варианта, с текстом и индикатором.     |
| `Combobox.Item`              | Выбираемая строка списка.                                          |
| `Combobox.ItemText`          | Слот текста элемента.                                               |
| `Combobox.ItemIndicator`     | Слот индикатора выбранного состояния.                              |
| `Combobox.Context`           | Доступ к состоянию Combobox без добавления элементов в DOM.        |
| `Combobox.ItemContext`       | Доступ к состоянию текущего элемента без добавления элементов в DOM. |

`Combobox.RootProvider` использует ту же стилизацию корневого компонента для состояния, созданного через `useCombobox` из moduix.
Состояние Combobox внутри дерева можно получить через `Combobox.Context` или `useComboboxContext`, а состояние элемента - через
`Combobox.ItemContext` или `useComboboxItemContext`.

## Композиция

Корневой компонент автоматически помещает `Positioner` в портал. Укажите `portalled={false}`, чтобы список рендерился в текущем
дереве, или передайте `portalRef`, чтобы выбрать контейнер. При этом `Positioner` и `Content` нужно добавлять явно, и каждую
часть можно стилизовать отдельно.

### Рекомендуемая композиция

Для статических данных используйте `createListCollection`. Если фильтрация или другие обновления меняют коллекцию,
используйте `useListCollection`. Для объектов задайте `itemToString` и `itemToValue`.

Оставляйте `Combobox.Positioner` и `Combobox.Content` в JSX. `Content` - это часть Ark, отвечающая за содержимое;
корневой компонент управляет только контейнером, в котором оно будет отрисовано.

Если такая структура списка повторяется, вынесите её в небольшой локальный вспомогательный компонент.
Для простых вариантов используйте `Combobox.Option`, а `Combobox.Item` - для ссылок, сложных вариантов или нестандартного размещения индикатора:

```tsx
function FruitComboboxPopup({ items }: { items: Array<{ label: string; value: string }> }) {
  return (
    <Combobox.Positioner>
      <Combobox.Content>
        <Combobox.Empty>No fruits found.</Combobox.Empty>
        <Combobox.List>
          {items.map((item) => (
            <Combobox.Option key={item.value} item={item}>
              {item.label}
            </Combobox.Option>
          ))}
        </Combobox.List>
      </Combobox.Content>
    </Combobox.Positioner>
  );
}
```

### Когда нужна собственная композиция

Используйте управляемое `value` и колбэки Ark с объектом `details`, когда другим частям интерфейса нужны выбранные значения.
Если состояние нужно создать за пределами отображаемого дерева, создайте его через `useCombobox` из moduix и передайте
результат в `Combobox.RootProvider`. Для состояния элемента используйте `Combobox.ItemContext` или `useComboboxItemContext`.
Из Ark импортируйте только помощники коллекций и типы, которых нет в moduix.

В режиме множественного выбора у `Combobox` нет собственного API для чипов. Отображайте теги или другое представление значений
из управляемого состояния, а за выбор по-прежнему отвечает свойство `multiple`.

В Ark нет отдельной части для статуса Combobox. `Combobox.Status` из moduix - стилизованный `div` для сообщений приложения
о загрузке, ошибке или подсказке. Он не управляет состоянием загрузки или ошибки и не добавляет ARIA-роль.

### Свойства по умолчанию

По умолчанию содержимое в портале монтируется при первом открытии и удаляется после анимации закрытия.
Задайте `unmountOnExit={false}`, чтобы сохранить его после первого открытия. Устанавливайте оба свойства жизненного цикла
в `false`, только если содержимое нужно отобразить сразу.

| Элемент                            | По умолчанию          | Примечания                                                             |
| ---------------------------------- | --------------------- | ---------------------------------------------------------------------- |
| `Combobox.Trigger`                 | шеврон moduix         | Используется, если дочерние элементы не переданы.                     |
| `Combobox.ClearTrigger`            | иконка закрытия moduix | Используется, если дочерние элементы не переданы.                    |
| `Combobox.ItemIndicator`           | иконка-галочка moduix | Используется, если дочерние элементы не переданы.                    |
| `Combobox.Option.indicator`        | иконка-галочка        | Передайте `false`, чтобы скрыть её, или React-узел, чтобы заменить.   |
| `Combobox` `portalled`              | `true`                | Автоматически помещает `Positioner` в портал.                         |
| `Combobox` `portalRef`              | -                     | Необязательный контейнер для портала.                                 |
| `Combobox` `lazyMount`              | `true`                | Монтирует содержимое списка при первом открытии.                       |
| `Combobox` `unmountOnExit`          | `true`                | Удаляет содержимое списка после анимации закрытия.                     |
| ширина `Combobox`                  | `16rem` (макс. `100%`) | Ширина стилизованного корневого компонента по умолчанию.              |
| переменные `Combobox.Positioner`   | переменные Ark во время выполнения | Использует `--reference-width`, `--available-height`, `--transform-origin`. |

### Особенности поведения

- Свойство `collection` обязательно.
- `value` и `defaultValue` - массивы строк, даже при одиночном выборе.
- Текущие значения в `onValueChange(details)` находятся в `details.value`.
- Текст поля в `onInputValueChange(details)` находится в `details.inputValue`, а причина изменения - в
  `details.reason`.
- `onOpenChange`, `onHighlightChange` и `onSelect` получают объекты `details` в формате Ark.
- Все DOM-части Ark поддерживают `asChild`. Исключение - `Combobox.Option`: это вспомогательная обёртка
  для простых строк, и `asChild` ей недоступен.
- `Combobox.Input asChild` сохраняет поведение поля Ark, но не добавляет дочернему элементу стандартный
  класс визуального оформления поля.
- В текущей версии Ark для Combobox нет части `HiddenInput`. Для встроенной отправки формы Ark используйте
  корневые свойства `name` и `form`.
- `Combobox.RootProvider` сохраняет стили корневого компонента moduix и настройки портала для созданного снаружи состояния Ark.
  Для работы с провайдером и контекстом используйте `useCombobox`, `Combobox.Context`, `useComboboxContext`,
  `Combobox.ItemContext` и `useComboboxItemContext` из moduix.
- Состояние `Field.Root` из Ark по-прежнему передаётся через контекст. Используйте основанный на Ark `Field.Root` из moduix,
  если комбобокс должен наследовать состояние поля. Свойства `readOnly` и `required` сохраняют поведение Ark.
- Используйте `ids`, когда части компонента собраны отдельно и им нужны общие идентификаторы доступности. `lazyMount` и
  `unmountOnExit` по умолчанию равны `true`, а `present` позволяет управлять присутствием по модели Ark для анимации закрытия.
- `selectionBehavior` и `closeOnSelect` передаются в Ark без изменений. В режиме множественного выбора Ark очищает поле после выбора.

Сохраняйте API moduix в стиле Ark и явно сопоставляйте распространённые возможности shadcn:

### Хуки стилизации

- Части Ark сохраняют `data-scope="combobox"` и значения `data-part`. moduix добавляет к стилизованным
  частям стабильные хуки `data-slot`.
- Стабильные слоты включают `combobox-root`, `combobox-root-provider`, `combobox-label`,
  `combobox-control`, `combobox-input`, `combobox-clear-trigger`, `combobox-trigger`,
  `combobox-positioner`, `combobox-content`, `combobox-empty`, `combobox-status`, `combobox-list`,
  `combobox-item-group`, `combobox-item-group-label`, `combobox-item`, `combobox-item-text` и
  `combobox-item-indicator`. `Combobox.Option` переиспользует слоты элемента, не добавляя собственного
  отдельного хука стилизации.
- Атрибуты состояния Ark включают `data-state="open|closed"`, `data-focus`, `data-invalid`, `data-disabled`,
  `data-highlighted`, `data-empty`, `data-placement` и `data-side`.
- Переменные позиционирования Ark включают `--reference-width`, `--available-width`, `--available-height`,
  `--transform-origin`, `--z-index` и `--layer-index`. Общая тема задаёт нейтральные начальные значения для инструментов
  разработки и содержимого без позиционирования, а Ark заменяет их измеренными значениями на `Positioner`.
