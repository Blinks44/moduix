## Выбор подходящего компонента

Используйте `Popover` для компактного интерактивного содержимого, которое открывается по триггеру.
Для коротких неинтерактивных подсказок подходит `Tooltip`, а для крупных сценариев, требующих
полного внимания пользователя, используйте `Dialog`.

## Анатомия

```text
Popover / Popover.Root
├─ Popover.Anchor (необязательно)
├─ Popover.Trigger
│  └─ Popover.Indicator (необязательно)
└─ Поддерево оверлея (автоматически переносится в портал)
   └─ Popover.Positioner
      └─ Popover.Content
         ├─ Popover.Arrow
         │  └─ Popover.ArrowTip
         ├─ Popover.Header
         │  ├─ Popover.Title
         │  └─ Popover.Description
         ├─ Popover.Body
         ├─ Popover.Footer
         └─ Popover.CloseTrigger / Popover.CloseIcon

Popover.RootProvider
└─ то же дерево частей, связанное с состоянием moduix из usePopover()

Popover.Context
└─ render prop с текущим состоянием всплывающего окна
```

| Часть                         | Назначение                                                          |
| ----------------------------- | ------------------------------------------------------------------- |
| `Popover` / `Popover.Root`    | Управляет состоянием, открытием и закрытием, фокусом, закрытием при внешнем взаимодействии и позиционированием. |
| `Popover.RootProvider`        | Подключает части к состоянию, созданному через `usePopover()`.      |
| `Popover.Context`             | Передаёт потомкам текущее состояние через render prop.              |
| `Popover.Anchor`              | Необязательный элемент, относительно которого выполняется позиционирование. |
| `Popover.Trigger`             | Кнопка, открывающая и закрывающая окно; для триггера можно задать `value`. |
| `Popover.Indicator`           | Необязательный индикатор состояния триггера.                        |
| `Popover.Positioner`          | Плавающий слой, который предоставляет CSS-переменные Ark для позиционирования. |
| `Popover.Content`             | Видимая интерактивная область всплывающего окна.                    |
| `Popover.Arrow` / `ArrowTip`  | Необязательная позиционируемая стрелка и её видимый наконечник.     |
| `Popover.Title`               | Доступный заголовок, связанный с содержимым.                        |
| `Popover.Description`         | Доступное описание, связанное с содержимым.                         |
| `Popover.CloseTrigger`        | Низкоуровневый триггер, закрывающий окно.                            |
| `Popover.CloseIcon`           | Вспомогательная часть moduix, которая объединяет триггер закрытия Ark и кнопку с иконкой. |
| `Popover.Header` / `Body`     | Вспомогательные обёртки moduix для структуры и стабильных слотов.   |
| `Popover.Footer`              | Вспомогательная обёртка moduix для строки действий со стабильным слотом. |

В коде приложения используйте короткую форму `Popover`. Явная форма `Popover.Root` пригодится,
если имя корневого компонента помогает лучше понять структуру.

## Композиция

`Popover` и `Popover.Root` по умолчанию размещают `Positioner` в портале. Установите
`portalled={false}`, чтобы оставить его в текущем DOM-дереве, или передайте `portalRef`, чтобы
выбрать контейнер портала. При использовании `Popover.RootProvider` настройте `portalled` в
`usePopover()` и передавайте провайдеру только `portalRef`. Оставляйте структурные части явными,
чтобы настраивать и стилизовать их независимо.

### Рекомендуемая композиция

В обычном случае используйте `Popover` вместе с `Popover.Trigger`, `Popover.Positioner` и
`Popover.Content`. Размещение, обработку коллизий и смещения настраивайте через свойство
`positioning` корневого компонента. Установите `positioning.sameWidth`, если ширина окна должна
совпадать с шириной элемента, относительно которого оно позиционируется.

### Когда нужна собственная композиция

Используйте `Anchor`, когда положение окна должен определять другой элемент, а не триггер.
Используйте `asChild` ровно с одним семантически подходящим дочерним элементом, если хотите
передать своей разметке роль триггера, якоря, содержимого или триггера закрытия. Установите
`portalled={false}`, если окно находится внутри другого оверлея и должно оставаться в его
DOM-дереве.

`lazyMount` и `unmountOnExit` уже включены по умолчанию. Меняйте эти свойства, только если
содержимое нужно монтировать сразу или не удалять из DOM после закрытия.

### Свойства по умолчанию

По умолчанию содержимое окна монтируется при первом открытии и удаляется после анимации закрытия.
Установите `unmountOnExit={false}`, чтобы оставить его смонтированным после первого открытия.
Устанавливайте оба свойства жизненного цикла в `false`, только если содержимое нужно отрисовать
сразу.

| Свойство                  | По умолчанию | Примечания                                                        |
| ------------------------- | ------------ | ----------------------------------------------------------------- |
| `autoFocus`               | `true`       | Переводит фокус на первый доступный для фокусировки элемент при открытии окна. |
| `closeOnEscape`           | `true`       | Закрывает окно при нажатии Escape.                                |
| `closeOnInteractOutside`  | `true`       | Закрывает окно при взаимодействии за его пределами.              |
| `lazyMount`               | `true`       | Откладывает монтирование содержимого до первого открытия.         |
| `modal`                   | `false`      | Удерживает фокус в окне, блокирует прокрутку и скрывает внешнее содержимое от вспомогательных технологий. |
| `portalled`               | `true`       | Рендерит позиционер через портал.                                 |
| `portalRef`               | `-`          | Задаёт контейнер пользовательского портала.                       |
| `skipAnimationOnMount`    | `false`      | Сохраняет начальную анимацию появления.                           |
| `unmountOnExit`           | `true`       | Удаляет содержимое после анимации закрытия.                       |
| `defaultOpen`             | `-`          | Начальное открытое состояние в неконтролируемом режиме.           |
| `open`                    | `-`          | Управляемое открытое состояние.                                   |
| `ids`                     | `-`          | Стабильные идентификаторы триггера, содержимого, заголовка, описания, якоря и триггера закрытия. |
| `initialFocusEl`           | `-`          | Функция, возвращающая элемент для фокуса при открытии окна.       |
| `positioning`             | `-`          | Параметры плавающего позиционирования Ark.                        |
| `present`                 | `-`          | Управляет присутствием при анимациях, которыми управляет JavaScript. |

### Особенности поведения

- Refs указывают на базовые DOM-части Ark. `Trigger` и `CloseTrigger` указывают на кнопки, а
  `Anchor`, `Positioner`, `Content`, `Arrow`, `ArrowTip`, `Title`, `Description`, `Indicator`,
  `Header`, `Body` и `Footer` передают ссылки на соответствующие отрисованные элементы.
- В `onOpenChange` передаётся объект с деталями, например `{ open }`. Следующее состояние открытия
  читайте в `details.open`, а не в отдельном позиционном аргументе.
- Если несколько триггеров используют одно окно, задайте каждому `value` и обрабатывайте
  `onTriggerValueChange(details)`. Активный триггер доступен в `details.value`, а Ark отмечает его
  атрибутом `data-current`.
- Свойство `modal` имеет логический тип. При значении `true` оно удерживает фокус внутри окна,
  блокирует прокрутку, запрещает взаимодействие с внешним содержимым и скрывает его от вспомогательных
  технологий. В модальном режиме Popover всегда рендерится через портал, даже если корневому компоненту
  передано `portalled={false}`.
- Используйте `Popover.Title`, чтобы задать всплывающему окну доступное имя, а `Popover.Description`
  для поясняющего текста. Ark связывает эти части с `Content` через их идентификаторы.
- Создайте внешнее состояние с помощью `usePopover()` и передайте его в `Popover.RootProvider`.
  Также настройте `portalled` в `usePopover()`; не оборачивайте один экземпляр состояния в
  `Popover` или `Popover.Root`.
- `Popover.Context` и `usePopoverContext()` дают потомкам доступ к тому же состоянию Ark. Хук
  удобен для дочернего компонента, которому нужно состояние, а `Popover.Context` используйте,
  когда понятнее читать его через render prop.
- `Popover.Arrow` по умолчанию выводит `ArrowTip`. Добавляйте `ArrowTip` явно, только если нужно
  изменить его.
- `Popover.CloseIcon` по умолчанию использует `aria-label="Close popover"` и располагается в
  углу содержимого. Передайте собственное доступное имя, если для действия нужна другая формулировка.
- По умолчанию окно закрывается по Escape и при взаимодействии за его пределами. Колбэки этих
  событий получают объекты событий Ark без изменений, а каждое поведение можно отключить отдельно.
- Используйте `ids`, когда отдельно составленным частям нужны стабильные идентификаторы триггера,
  содержимого, заголовка, описания, якоря или триггера закрытия.
- CSS-анимация закрытия запускается по состоянию Ark `data-state="closed"`. Используйте
  `present`, когда жизненным циклом присутствия управляет JavaScript.
- Если содержимое может быть выше доступной области, поместите прокручиваемую часть в
  `Popover.Body`.

### Хуки стилизации

Каждая отрисованная часть принимает `className`. Части Ark сохраняют `data-scope="popover"` и
значения `data-part`, а moduix добавляет `data-slot="popover-*"` к отрисованным обёрткам.
`Popover` и `Popover.RootProvider` предоставляют состояние, но не создают DOM-элементы. Для
стилизации с учётом состояния используйте `data-state="open|closed"`, `data-placement`, `data-side`,
`data-value`, `data-nested`, `data-has-nested`, `data-expanded` и `data-current`, если несколько
триггеров с `value` используют одно окно.

`Positioner` предоставляет `--reference-width`, `--reference-height`, `--available-width`,
`--available-height`, `--x`, `--y`, `--z-index` и `--transform-origin`. `Content` предоставляет
`--layer-index` и `--nested-layer-count`, а `Arrow` предоставляет переменные измерений стрелки
Ark. Длинные строки без пробелов переносятся внутри содержимого, а анимация отключается, если
пользователь предпочитает уменьшенное движение.
