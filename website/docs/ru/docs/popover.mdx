## Какой компонент выбрать

Используйте `Popover` для компактного интерактивного содержимого, которое открывается по триггеру.
Для коротких неинтерактивных подсказок подходит `Tooltip`, а для крупных сценариев, требующих
полного внимания пользователя, используйте `Dialog`.

## Базовый пример

Используйте `Popover` как корневой компонент, а остальные части импортируйте напрямую, например
`PopoverTrigger` и `PopoverContent`. Эти плоские имена одинаковы в npm-пакетах и исходниках
shadcn-реестра. Настройте позиционирование на корневом компоненте, а `asChild` используйте, если
триггером должна быть ваша кнопка.

## Анатомия

```text
Popover
├─ PopoverAnchor (необязательно)
├─ PopoverTrigger
│  └─ PopoverIndicator (необязательно)
└─ Поддерево оверлея (автоматически переносится в портал)
   └─ PopoverPositioner
      └─ PopoverContent
         ├─ PopoverArrow
         │  └─ PopoverArrowTip
         ├─ PopoverHeader
         │  ├─ PopoverTitle
         │  └─ PopoverDescription
         ├─ PopoverBody
         ├─ PopoverFooter
         └─ PopoverCloseTrigger / PopoverCloseIcon

PopoverRootProvider
└─ то же дерево частей, связанное с состоянием moduix из usePopover()

PopoverContext
└─ render prop с текущим состоянием всплывающего окна
```

| Часть                         | Назначение                                                          |
| ----------------------------- | ------------------------------------------------------------------- |
| `Popover`    | Управляет состоянием, открытием и закрытием, фокусом, закрытием при внешнем взаимодействии и позиционированием. |
| `PopoverRootProvider`        | Подключает части к состоянию, созданному через `usePopover()`.      |
| `PopoverContext`             | Передаёт потомкам текущее состояние через render prop.              |
| `PopoverAnchor`              | Необязательный элемент, относительно которого выполняется позиционирование. |
| `PopoverTrigger`             | Кнопка, открывающая и закрывающая окно; для триггера можно задать `value`. |
| `PopoverIndicator`           | Необязательный индикатор состояния триггера.                        |
| `PopoverPositioner`          | Плавающий слой с CSS-переменными Ark для позиционирования.          |
| `PopoverContent`             | Видимая интерактивная область всплывающего окна.                    |
| `PopoverArrow` / `PopoverArrowTip`  | Необязательная позиционируемая стрелка и её видимый наконечник.     |
| `PopoverTitle`               | Доступный заголовок, связанный с содержимым.                        |
| `PopoverDescription`         | Доступное описание, связанное с содержимым.                         |
| `PopoverCloseTrigger`        | Низкоуровневый триггер, закрывающий окно.                            |
| `PopoverCloseIcon`            | Вспомогательная часть moduix, объединяющая триггер закрытия Ark и кнопку с иконкой. |
| `PopoverHeader` / `PopoverBody`      | Вспомогательные обёртки moduix со стабильными слотами.              |
| `PopoverFooter`               | Вспомогательная обёртка moduix для строки действий.                 |

## Композиция

Оставляйте `PopoverPositioner` и `PopoverContent` явными, чтобы структуру оверлея было удобно
стилизовать. `PopoverPositioner` по умолчанию размещается в портале. Установите `portalled={false}` для
размещения в текущем DOM-дереве или передайте `portalRef` для собственного контейнера портала. При
использовании `PopoverRootProvider` настройте `portalled` в `usePopover()` и передайте store
провайдеру. Один и тот же store нельзя одновременно подключать через `Popover` и
`PopoverRootProvider`.

Используйте `PopoverAnchor`, когда позиционирование должен определять другой элемент. Применяйте `asChild`
с одним семантически подходящим дочерним элементом, если ваша разметка должна отрисовать триггер,
якорь или триггер закрытия. Для вложенного Popover установите `portalled={false}` на корневой части,
чтобы он оставался внутри родительского оверлея. Если несколько триггеров используют одно окно,
задайте каждому `value` и обновляйте содержимое через `onTriggerValueChange(details)`.

### Отложенное монтирование

Используйте `lazyMount` и `unmountOnExit`, когда содержимое должно находиться в DOM только во

<Example name="popover/lazy-mount" />

### Модальный режим

Включайте модальный режим, когда пользователь должен оставаться внутри окна. Он удерживает фокус
и скрывает внешнее содержимое от вспомогательных технологий. Используйте `initialFocusEl`, чтобы
выбрать первый элемент для фокуса.

### Несколько триггеров

`portalled={false}`, чтобы он оставался внутри родительского оверлея и участвовал в его слоях.

### Позиционирование

Передавайте параметры позиционирования Ark через свойство `positioning` корневого компонента.

### Root Provider

Используйте `usePopover()` вместе с `PopoverRootProvider`, когда внешние по отношению к дереву

Установите `positioning.sameWidth`, если содержимое должно совпадать по ширине с триггером.

### Со стрелкой

Добавьте `PopoverArrow`, если окно должно визуально указывать на элемент, относительно которого

### Расширенная настройка

Собирайте окно из низкоуровневых частей, когда вспомогательные части moduix не подходят к разметке.

## Стилизация

`PopoverTrigger` и `PopoverCloseTrigger` без `asChild` выглядят как кнопки с обводкой.
`PopoverContent` шириной 16–28rem и высотой не больше 24rem в пределах доступного места; с прямым
дочерним `PopoverBody` прокручивается тело. `PopoverBody` получает отступ после `PopoverHeader`, а
`PopoverFooter` — от содержимого над ним. Анимация содержимого читает общие переменные
`--moduix-popup-motion-*`.

Используйте `className` в React или `class` в Solid и Vue на экспортируемых частях. Варианты Tailwind
используют нативные utility-классы и классы потребителя. Варианты CSS Modules построены на токенах
foundation и не имеют переменных компонента: класс на части переопределяет стили компонента из слоя.
Атрибуты состояния и хуки `data-slot` общие для обоих вариантов стилизации.

### Точки стилизации

Каждая отрисованная часть принимает `className` или `class`. Части Ark сохраняют `data-scope="popover"`
и значения `data-part`, а moduix добавляет к обёрткам стабильные `data-slot="popover-*"`. `Popover`
и `PopoverRootProvider` предоставляют состояние, но не создают DOM-элементы. Для стилей, зависящих
от состояния, используйте `data-state="open|closed"`, `data-placement`, `data-side`, `data-value`,
`data-nested`, `data-has-nested`, `data-expanded` и `data-current` для нескольких триггеров с `value`.

`PopoverPositioner` предоставляет `--reference-width`, `--reference-height`, `--available-width`,
`--available-height`, `--x`, `--y`, `--z-index` и `--transform-origin`. `PopoverContent` предоставляет
`--layer-index` и `--nested-layer-count`, а `PopoverArrow` предоставляет переменные измерения стрелки Ark.
Содержимое переносит длинные строки без пробелов и отключает анимацию, если пользователь предпочитает
уменьшить движение.
