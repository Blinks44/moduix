## Выбор подходящего компонента

Используйте `Popover` для компактного интерактивного содержимого, связанного с триггером. Используйте `Tooltip` для неинтерактивных подсказок, а `Dialog` - для крупных сценариев, которые прерывают текущую задачу.

## Анатомия

```text
Popover / Popover.Root
├─ Popover.Anchor (optional)
├─ Popover.Trigger
│  └─ Popover.Indicator (optional)
└─ Overlay subtree (automatically portalled)
   └─ Popover.Positioner
      └─ Popover.Content
         ├─ Popover.Arrow
         │  └─ Popover.ArrowTip
         ├─ Popover.Header
         │  ├─ Popover.Title
         │  └─ Popover.Description
         ├─ Popover.Body
         ├─ Popover.Footer
         └─ Popover.CloseTrigger / Popover.CloseIcon
```

| Часть                         | Назначение                                                           |
| ----------------------------- | -------------------------------------------------------------------- |
| `Popover` / `Popover.Root`    | Управляет состоянием, жизненным циклом, закрытием, фокусом и позиционированием всплывающего окна. |
| `Popover.RootProvider`        | Отрисовывает дерево Popover на основе состояния, возвращённого `usePopover`. |
| `Popover.Context`             | Получает текущее состояние через `render prop` потомка.             |
| `Popover.Anchor`              | Необязательный пользовательский элемент, относительно которого выполняется позиционирование. |
| `Popover.Trigger`             | Кнопка, открывающая и закрывающая всплывающее окно; может получать `value` триггера. |
| `Popover.Indicator`           | Необязательный индикатор состояния триггера.                         |
| `Popover.Positioner`          | Плавающий слой, предоставляющий CSS-переменные позиционирования Ark. |
| `Popover.Content`             | Интерактивная область всплывающего окна.                             |
| `Popover.Arrow` / `ArrowTip`  | Необязательная позиционируемая стрелка и её видимый наконечник.      |
| `Popover.Title`               | Доступный заголовок, связанный с содержимым.                         |
| `Popover.Description`         | Доступное описание, связанное с содержимым.                          |
| `Popover.CloseTrigger`        | Низкоуровневый триггер, закрывающий всплывающее окно.                |
| `Popover.CloseIcon`           | Готовая кнопка закрытия с одной иконкой, построенная на триггере закрытия Ark. |
| `Popover.Header` / `Body`     | Обёртки для компоновки moduix со стабильными слотами.                |
| `Popover.Footer`              | Обёртка строки действий moduix со стабильным слотом.                 |

## Композиция

Корневой компонент автоматически помещает `Positioner` в портал. Используйте `portalled={false}`, чтобы отрисовать его в текущем контейнере, или `portalRef`, чтобы указать пользовательский контейнер портала. Структурные части остаются явными, и их можно стилизовать.

### Рекомендуемая композиция

Сохраняйте `Popover.Positioner` и `Popover.Content` явными. Компонент `Popover` эквивалентен `Popover.Root`. Настраивайте размещение, обработку коллизий и смещения через `positioning`. Чтобы ширина окна совпадала с шириной элемента, относительно которого оно позиционируется, установите `positioning.sameWidth`.

### Когда нужна собственная композиция

Используйте `Anchor`, когда элемент, относительно которого нужно позиционировать окно, отличается от триггера. Используйте `asChild` ровно с одним семантическим потомком, если хотите подставить свой элемент вместо триггера, якоря, содержимого или триггера закрытия. Установите `portalled={false}`, когда всплывающее окно внутри другого оверлея должно рендериться в текущем контейнере. Используйте `lazyMount` и `unmountOnExit`, только если действительно нужны отложенное монтирование и удаление после анимации закрытия.

### Свойства по умолчанию

По умолчанию содержимое оверлея в портале монтируется при первом открытии и удаляется после анимации закрытия. Установите `unmountOnExit={false}`, чтобы оставить его смонтированным после первого открытия. Устанавливайте оба свойства жизненного цикла в `false`, только если содержимое нужно отрисовать сразу.

| Свойство                | По умолчанию | Примечания                                                          |
| ----------------------- | ------------ | ------------------------------------------------------------------- |
| `autoFocus`             | `true`       | Переводит фокус на первый элемент, на который можно перевести фокус, при открытии окна. |
| `closeOnEscape`         | `true`       | Закрывает окно при нажатии Escape.                                  |
| `closeOnInteractOutside`| `true`       | Закрывает окно при взаимодействии за его пределами.                 |
| `lazyMount`             | `true`       | Откладывает монтирование содержимого до первого открытия.           |
| `modal`                 | `false`      | Включает удержание фокуса внутри окна, блокировку прокрутки и изоляцию внешнего содержимого. |
| `portalled`             | `true`       | Помещает позиционер в портал и сохраняет стандартное для Ark поведение клавиши Tab. |
| `portalRef`             | -            | Указывает пользовательский контейнер портала.                       |
| `skipAnimationOnMount`  | `false`      | Сохраняет анимацию появления при первом монтировании.               |
| `unmountOnExit`         | `true`       | Удаляет содержимое всплывающего окна после анимации закрытия.       |
| `defaultOpen`           | -            | Начальное неуправляемое открытое состояние.                          |
| `open`                  | -            | Управляемое открытое состояние.                                      |
| `ids`                   | -            | Стабильные идентификаторы для триггера, содержимого, заголовка, описания и якорного элемента. |
| `initialFocusEl`        | -            | Функция, возвращающая элемент для фокуса при открытии.               |
| `positioning`           | -            | Параметры плавающего позиционирования Ark.                           |
| `present`               | -            | Управляет присутствием при анимациях, которыми управляет JavaScript. |

### Особенности поведения

- Refs указывают на базовые DOM-части Ark: `Trigger` и `CloseTrigger` - на кнопки, а `Anchor`, `Positioner`, `Content`, `Arrow`, `ArrowTip`, `Title`, `Description`, `Indicator`, `Header`, `Body` и `Footer` - на соответствующие отрисованные элементы.
- `onOpenChange` получает `{ open }`; обратный вызов получает объект, а не отдельный позиционный аргумент.
- Свойство `modal` имеет тип boolean. При значении `true` оно удерживает фокус внутри окна, блокирует прокрутку, запрещает взаимодействие с внешним содержимым и изолирует его от программ чтения с экрана. Модальное всплывающее окно всегда рендерится через портал, даже если передано `portalled={false}`.
- Передавайте объект, возвращённый `usePopover`, в `RootProvider`. Не оборачивайте это же состояние в `Root`.
- `Popover.Context` и `usePopoverContext` дают потомкам доступ к текущему состоянию Ark. Хук экспортируется из `@moduix/react`; используйте `Context`, если с `render prop` состояние читать понятнее.
- Используйте `usePopover`, чтобы управлять состоянием вне отрисованного дерева, и передавайте полученный объект в `RootProvider`.
- По умолчанию `Popover.Arrow` отрисовывает `ArrowTip`; добавляйте `ArrowTip` явно, только если его нужно настроить.
- Ark по умолчанию закрывает окно при нажатии Escape и при взаимодействии за его пределами. Эти способы закрытия можно отключить независимо.
- Используйте `ids`, когда нужны стабильные идентификаторы триггера, содержимого, заголовка, описания, якорного элемента или триггера закрытия.
- CSS-анимация закрытия привязана к состоянию Ark `data-state="closed"`. Используйте `present` для жизненного цикла, которым управляет JavaScript.
- Для содержимого, которое может превышать доступную высоту, разместите прокручиваемую область в `Popover.Body`.

### Хуки стилизации

Части Ark сохраняют `data-scope="popover"` и значения `data-part`. Каждая экспортируемая отрисованная часть принимает `className`, а moduix добавляет `data-slot="popover-*"` к отрисованным обёрткам. Используйте `data-state="open|closed"`, `data-placement`, `data-side`, `data-nested`, `data-has-nested` и `data-expanded`, чтобы стилизовать части с учётом состояния. Если у нескольких триггеров есть `value`, используйте `data-current`, чтобы стилизовать только триггер, открывший всплывающее окно.

`Positioner` предоставляет `--reference-width`, `--reference-height`, `--available-width`, `--available-height`, `--x`, `--y`, `--z-index` и `--transform-origin`. `Content` предоставляет `--layer-index` и `--nested-layer-count`; `Arrow` предоставляет переменные измерений стрелки Ark. Длинные строки без пробелов переносятся внутри содержимого, а анимация отключается, если пользователь предпочитает уменьшенное движение.
