## Какой компонент выбрать

Используйте `Popover` для компактного интерактивного содержимого, которое открывается по триггеру.
Для коротких неинтерактивных подсказок подходит `Tooltip`, а для крупных сценариев, требующих
полного внимания пользователя, используйте `Dialog`.

## Анатомия

```text
Popover / Popover.Root
├─ Popover.Anchor (необязательно)
├─ Popover.Trigger
│  └─ Popover.Indicator (необязательно)
└─ Поддерево оверлея (автоматически переносится в портал)
   └─ Popover.Positioner
      └─ Popover.Content
         ├─ Popover.Arrow
         │  └─ Popover.ArrowTip
         ├─ Popover.Header
         │  ├─ Popover.Title
         │  └─ Popover.Description
         ├─ Popover.Body
         ├─ Popover.Footer
         └─ Popover.CloseTrigger / Popover.CloseIcon

Popover.RootProvider
└─ то же дерево частей, связанное с состоянием moduix из usePopover()

Popover.Context
└─ render prop с текущим состоянием всплывающего окна
```

| Часть                         | Назначение                                                          |
| ----------------------------- | ------------------------------------------------------------------- |
| `Popover` / `Popover.Root`    | Управляет состоянием, открытием и закрытием, фокусом, закрытием при внешнем взаимодействии и позиционированием. |
| `Popover.RootProvider`        | Подключает части к состоянию, созданному через `usePopover()`.      |
| `Popover.Context`             | Передаёт потомкам текущее состояние через render prop.              |
| `Popover.Anchor`              | Необязательный элемент, относительно которого выполняется позиционирование. |
| `Popover.Trigger`             | Кнопка, открывающая и закрывающая окно; для триггера можно задать `value`. |
| `Popover.Indicator`           | Необязательный индикатор состояния триггера.                        |
| `Popover.Positioner`          | Плавающий слой с CSS-переменными Ark для позиционирования.          |
| `Popover.Content`             | Видимая интерактивная область всплывающего окна.                    |
| `Popover.Arrow` / `ArrowTip`  | Необязательная позиционируемая стрелка и её видимый наконечник.     |
| `Popover.Title`               | Доступный заголовок, связанный с содержимым.                        |
| `Popover.Description`         | Доступное описание, связанное с содержимым.                         |
| `Popover.CloseTrigger`        | Низкоуровневый триггер, закрывающий окно.                            |
| `Popover.CloseIcon`            | Вспомогательная часть moduix, объединяющая триггер закрытия Ark и кнопку с иконкой. |
| `Popover.Header` / `Body`      | Вспомогательные обёртки moduix со стабильными слотами.              |
| `Popover.Footer`               | Вспомогательная обёртка moduix для строки действий.                 |

В коде приложения используйте короткую форму `Popover`. Явная форма `Popover.Root` пригодится,
если имя корневой части помогает лучше понять композицию.

## Композиция

Оставляйте `Popover.Positioner` и `Popover.Content` явными, чтобы структуру оверлея было удобно
стилизовать. `Positioner` по умолчанию размещается в портале. Установите `portalled={false}` для
размещения в текущем DOM-дереве или передайте `portalRef` для собственного контейнера портала. При
использовании `Popover.RootProvider` настройте `portalled` в `usePopover()` и передайте store
провайдеру. Один и тот же store нельзя одновременно подключать через `Popover` или `Popover.Root`.

Используйте `Anchor`, когда позиционирование должен определять другой элемент. Применяйте `asChild`
с одним семантически подходящим дочерним элементом, если ваша разметка должна отрисовать триггер,
якорь или триггер закрытия. Для вложенного Popover установите `portalled={false}` на корневой части,
чтобы он оставался внутри родительского оверлея. Если несколько триггеров используют одно окно,
задайте каждому `value` и обновляйте содержимое через `onTriggerValueChange(details)`.

## Стилизация

Для структурных стилей используйте `className` в React и `class` в Solid на экспортируемых частях.
Варианты Tailwind используют нативные utility-классы и классы потребителя. CSS-переменные ниже
настраивают варианты CSS Modules, а атрибуты Ark и `data-slot` moduix общие для обоих вариантов.

### CSS Properties

Используйте публичные переменные ниже, чтобы настроить Popover без замены его структуры.

### Точки стилизации

Каждая отрисованная часть принимает `className` или `class`. Части Ark сохраняют `data-scope="popover"`
и значения `data-part`, а moduix добавляет к обёрткам стабильные `data-slot="popover-*"`. `Popover`
и `Popover.RootProvider` предоставляют состояние, но не создают DOM-элементы. Для стилей, зависящих
от состояния, используйте `data-state="open|closed"`, `data-placement`, `data-side`, `data-value`,
`data-nested`, `data-has-nested`, `data-expanded` и `data-current` для нескольких триггеров с `value`.

`Positioner` предоставляет `--reference-width`, `--reference-height`, `--available-width`,
`--available-height`, `--x`, `--y`, `--z-index` и `--transform-origin`. `Content` предоставляет
`--layer-index` и `--nested-layer-count`, а `Arrow` предоставляет переменные измерения стрелки Ark.
Содержимое переносит длинные строки без пробелов и отключает анимацию, если пользователь предпочитает
уменьшить движение.
