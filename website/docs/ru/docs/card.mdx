## Справочник API

В Ark UI нет отдельного примитива Card. В moduix Card построен на официальной
[фабрике Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[работе с ref](https://ark-ui.com/docs/guides/ref).

## Анатомия

```text
Card.Root
├─ Card.Background (необязательная часть moduix)
├─ Card.Media (необязательная часть moduix)
├─ Card.Header
│  ├─ Card.Title
│  ├─ Card.Description
│  └─ Card.Action (необязательная часть moduix)
├─ Card.Body
└─ Card.Footer (необязательно)
```

`Card` и `Card.Root` обозначают один и тот же корневой компонент.

| Часть                | Назначение                                                                                  |
| -------------------- | -------------------------------------------------------------------------------------------- |
| `Card` / `Card.Root` | Корневой контейнер со свойствами `size`, `variant` и `asChild`.                              |
| `Card.Background`    | Необязательный фоновый слой на всю карточку для декоративного медиа.                        |
| `Card.Media`         | Необязательная обёртка для медиа от края до края, которая аккуратно обрезает верхние углы.   |
| `Card.Header`        | Разметка заголовка, описания и необязательного действия в конце строки.                     |
| `Card.Body`          | Основная область содержимого.                                                               |
| `Card.Footer`        | Нижняя строка для действий или метаданных; при необходимости содержимое переносится.        |
| `Card.Title`         | Заголовок. По умолчанию рендерит `h3`; для другого уровня используйте `asChild`.             |
| `Card.Description`   | Дополнительный текст под заголовком.                                                         |
| `Card.Action`        | Слот для действия в заголовке.                                                              |
| `Card.Link`          | Ссылка с расширенной областью нажатия для карточки с навигацией и отдельными действиями.    |

## Композиция

### Рекомендуемая композиция

Начните с `<Card />`, затем добавьте `Card.Header`, `Card.Title`, `Card.Description`, `Card.Body` и
`Card.Footer`. Используйте `Card.Media` для начального медиа, которое должно доходить до краёв карточки
с единым обрезанием. `Card.Background` подходит для декоративного изображения на заднем плане всей
карточки; градиент и контраст текста задайте в стилях приложения.
По умолчанию корневой компонент использует `size="md"` и `variant="outline"`.

### Когда нужна собственная композиция

Используйте `asChild`, если семантический дочерний элемент должен стать DOM-узлом части. В композиции Ark
допускается ровно один дочерний элемент. Если корень становится ссылкой, не помещайте внутрь кнопки, поля ввода
или другие ссылки.

Используйте `Card.Link` внутри заголовка, когда карточка должна вести на другую страницу, но при этом содержать
отдельные элементы управления. Видимая ссылка остаётся в заголовке, а область нажатия расширяется на всю карточку,
не перекрывая остальные интерактивные элементы. `Card.Action` отвечает только за расположение и не создаёт
ARIA-связей.

| Ситуация                                                                                  | Рекомендуемый API                                                   |
| ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| Вся карточка является одной ссылкой и не содержит вложенных элементов управления.         | `Card asChild` с корневым элементом `<a>`                           |
| Карточка ведёт на другую страницу, но также содержит кнопки, меню или другие действия.    | `Card.Link` внутри `Card.Title`, при необходимости с `Card.Action`  |
| Карточка только объединяет содержимое и не используется для навигации.                    | Обычная композиция `Card` без специальной ссылки                    |

### Свойства по умолчанию

| Часть       | Свойство  | По умолчанию | Значения                               |
| ----------- | --------- | ------------ | -------------------------------------- |
| `Card.Root` | `size`    | `'md'`       | `'sm' \| 'md' \| 'lg'`                 |
| `Card.Root` | `variant` | `'outline'`  | `'elevated' \| 'outline' \| 'subtle'` |

### Особенности поведения

- По умолчанию корневой компонент рендерит неинтерактивный `div` и передаёт ему ref.
- Все части принимают нативные свойства, `className`, `style` и `asChild` фабрики Ark.
- `Card.Media` - необязательная готовая обёртка. Не используйте её, если медиа нужно оформить самостоятельно
  или оно находится не в верхней части карточки.
- `Card.Background` - необязательная готовая обёртка для декоративного изображения на заднем плане всей карточки.
  Оставляйте у такого изображения `alt=""`; если изображение несёт смысловую нагрузку, используйте `Card.Media`.
- `Card.Title` по умолчанию рендерит `h3`.
- Интерактивные корневые элементы, созданные с `asChild`, и `Card.Link` получают одинаковое настраиваемое кольцо `:focus-visible`.
- Card не управляет состоянием, колбэками, поведением клавиатуры, провайдером, контекстом или скрытым полем ввода.
- `Card.Body` сбрасывает внешние отступы первого и последнего непосредственных дочерних элементов.
- `--moduix-card-spacing`, `--moduix-card-spacing-sm` и `--moduix-card-spacing-lg` управляют общими внутренними
  отступами и интервалами между разделами, не заменяя более точечные переопределения `--moduix-card-*`.

### Атрибуты для стилизации

- Каждая часть предоставляет `data-scope="card"` и соответствующий `data-part`.
- Стабильные атрибуты moduix: `data-slot="card-root"`, `card-background`, `card-media`, `card-header`, `card-body`,
  `card-footer`, `card-title`, `card-description`, `card-action` и `card-link`.
- Корневой компонент предоставляет `data-size="sm | md | lg"` и
  `data-variant="elevated | outline | subtle"`.
- Общие переопределения `--moduix-card-bg`, `--moduix-card-color`, `--moduix-card-border-*` и
  `--moduix-card-shadow` имеют приоритет над соответствующими переменными отдельных вариантов.
- Card не имеет атрибутов интерактивного состояния, поскольку не управляет состоянием и поведением.
