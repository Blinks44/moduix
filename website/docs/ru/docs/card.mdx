Используйте `Card` как корневой компонент и добавляйте только нужные части. Импортируйте каждую
часть напрямую, например `CardHeader` и `CardTitle`. Те же имена работают с npm-пакетами и
исходниками registry shadcn.

## Композиция

Card не управляет состоянием, колбэками, провайдером, контекстом, поведением клавиатуры или скрытым
полем ввода. Для обычного содержимого используйте только нужные части. `asChild` позволяет передать
владение корневым элементом или другой частью семантическому элементу; он должен вернуть ровно один
дочерний элемент, который принимает объединённые свойства. В Solid `asChild` использует функцию рендера,
например `asChild={(props) => <a {...props()} />}`.

Если вся карточка является одной ссылкой без вложенных элементов управления, соберите корень через
`asChild`. Если в карточке есть кнопки или другие действия, поместите `CardLink` внутрь `CardTitle`,
а эти элементы управления - в `CardAction`: расширенная область клика ссылки не перекроет остальные
интерактивные элементы. Используйте `CardMedia` для информативного медиа в начале карточки, а
`CardBackground` - для декоративного фона за содержимым. Для фонового изображения оставляйте пустой
`alt`, а наложение и контраст текста настраивайте в приложении.

## Стилизация

Используйте `className` в React или `class` в Solid и Vue на экспортируемых частях для структурных стилей.
Варианты Tailwind используют нативные утилиты и классы приложения; CSS-свойства ниже настраивают
варианты CSS Modules. Атрибуты данных и хуки `data-slot` общие для обоих вариантов стилизации.

### CSS-переменные

Наведите на переменную или выберите её, чтобы увидеть её в превью.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `Card` | `card-root` |
| `CardHeader` | `card-header` |
| `CardBody` | `card-body` |
| `CardMedia` | `card-media` |
| `CardBackground` | `card-background` |
| `CardFooter` | `card-footer` |
| `CardTitle` | `card-title` |
| `CardDescription` | `card-description` |
| `CardAction` | `card-action` |
| `CardLink` | `card-link` |

- Каждая часть предоставляет `data-scope="card"` и соответствующий `data-part`.
- Корневой компонент предоставляет `data-size="sm | md | lg"` и `data-variant="elevated | outline | subtle"`.
- CSS-переменные переопределяют любой вариант. Чтобы настроить один вариант во всём приложении,
  задайте их на `[data-slot='card-root'][data-variant='<variant>']`.
- У каждой секции одинаковый отступ сверху, у последней он есть и снизу. В Tailwind нижний отступ
  меняется через `last:pb-*` на секции или `[--card-spacing:…]` на корне.
- Card не имеет атрибутов интерактивного состояния, поскольку не управляет состоянием и поведением.

## Справочник API

Также принимает нативные пропсы своего элемента и `asChild`.

| Проп | Тип | По умолчанию |
| --- | --- | --- |
| `variant` | `'outline' \| 'elevated' \| 'subtle'` | `'outline'` |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` |
