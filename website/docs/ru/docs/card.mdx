## Справочник API

В Ark UI нет отдельного примитива Card. Компонент Card в moduix построен на официальной
[фабрике Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[работе с ref](https://ark-ui.com/docs/guides/ref).

## Базовый пример

Card доступен для React и Solid во всех пакетах CSS Modules и Tailwind. Визуальный пример на этой
странице использует пакет React CSS Modules, а вкладки фреймворков показывают нативный исходный код
для того же публичного контракта.

Используйте `Card` как корневой компонент и добавляйте только нужные части. `Card.Root` — это
псевдоним того же корня, если вы хотите явно указать его в композиции.

В [Быстром старте](/docs/quick-start) описаны установка пакета, настройка registry и выбор варианта
стилизации.

## Анатомия

```text
Card / Card.Root
├─ Card.Background (необязательный помощник moduix)
├─ Card.Media (необязательный помощник moduix)
├─ Card.Header
│  ├─ Card.Title
│  ├─ Card.Description
│  └─ Card.Action (необязательный помощник moduix)
├─ Card.Body
└─ Card.Footer (необязательно)
```

`Card` и `Card.Root` обозначают один и тот же корневой компонент.

| Часть                | Назначение                                                                                |
| -------------------- | ------------------------------------------------------------------------------------------ |
| `Card` / `Card.Root` | Корневой контейнер со свойствами `size`, `variant` и `asChild`.                            |
| `Card.Background`    | Необязательный фоновый слой на всю карточку для декоративного медиа.                      |
| `Card.Media`         | Необязательная обёртка для медиа на всю ширину с единым скруглением верхних углов.        |
| `Card.Header`        | Контейнер для заголовка, описания и необязательного действия справа.                      |
| `Card.Body`          | Основная область содержимого.                                                              |
| `Card.Footer`        | Нижняя строка для действий или метаданных. При необходимости содержимое переносится.     |
| `Card.Title`         | Заголовок, по умолчанию рендерится как `h3`; для другого уровня используйте `asChild`.   |
| `Card.Description`   | Дополнительный текст под заголовком.                                                       |
| `Card.Action`        | Слот для действия в заголовке.                                                             |
| `Card.Link`          | Ссылка с расширенной областью клика, которая не перекрывает остальные элементы управления. |

## Композиция

Card не управляет состоянием, колбэками, провайдером, контекстом, поведением клавиатуры или скрытым
полем ввода. Для обычного содержимого используйте только нужные части. `asChild` позволяет передать
владение корневым элементом или другой частью семантическому элементу; он должен вернуть ровно один
дочерний элемент, который принимает объединённые свойства. В Solid `asChild` использует функцию рендера,
например `asChild={(props) => <a {...props()} />}`.

Если вся карточка является одной ссылкой без вложенных элементов управления, соберите корень через
`asChild`. Если в карточке есть кнопки или другие действия, поместите `Card.Link` внутрь `Card.Title`,
а эти элементы управления — в `Card.Action`: расширенная область клика ссылки не перекроет остальные
интерактивные элементы. Используйте `Card.Media` для информативного медиа в начале карточки, а
`Card.Background` — для декоративного фона за содержимым. Для фонового изображения оставляйте пустой
`alt`, а наложение и контраст текста настраивайте в приложении.

## Стилизация

Используйте `className` в React или `class` в Solid на экспортируемых частях для структурных стилей.
Варианты Tailwind используют нативные утилиты и классы приложения; CSS-свойства ниже настраивают
варианты CSS Modules. Атрибуты данных и хуки `data-slot` общие для обоих вариантов стилизации.

### CSS-свойства

<CssPropertiesSection properties={CardDocs.cardOverrideCssProperties} />

### Хуки стилизации

- Каждая часть предоставляет `data-scope="card"` и соответствующий `data-part`.
- Стабильные хуки moduix: `data-slot="card-root"`, `card-background`, `card-media`, `card-header`, `card-body`,
  `card-footer`, `card-title`, `card-description`, `card-action` и `card-link`.
- Корневой компонент предоставляет `data-size="sm | md | lg"` и `data-variant="elevated | outline | subtle"`.
- Общие переопределения `--moduix-card-bg`, `--moduix-card-color`, `--moduix-card-border-*` и
  `--moduix-card-shadow` имеют приоритет над соответствующими переменными отдельных вариантов.
- Card не имеет атрибутов интерактивного состояния, поскольку не управляет состоянием и поведением.
