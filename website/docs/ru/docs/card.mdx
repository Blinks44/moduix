## Справочник API

В Ark UI нет отдельного примитива Card. Компонент Card в moduix построен на официальной
[фабрике Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[работе с ref](https://ark-ui.com/docs/guides/ref).

## Базовый пример

Используйте `<Card />` как корневой компонент, затем добавьте нужные части из пространства имён `Card`.

Если вы знакомы с shadcn/ui, структура будет привычной. В moduix `Card.Body` выполняет роль `CardContent`
из shadcn, а остальные части также находятся в пространстве имён `Card`.

## Анатомия

```text
Card.Root
├─ Card.Background (необязательная часть moduix)
├─ Card.Media (необязательная часть moduix)
├─ Card.Header
│  ├─ Card.Title
│  ├─ Card.Description
│  └─ Card.Action (необязательная часть moduix)
├─ Card.Body
└─ Card.Footer (необязательно)
```

`Card` и `Card.Root` обозначают один и тот же корневой компонент.

| Часть                | Назначение                                                                                  |
| -------------------- | -------------------------------------------------------------------------------------------- |
| `Card` / `Card.Root` | Корневой контейнер со свойствами `size`, `variant` и `asChild`.                              |
| `Card.Background`    | Фоновый слой на всю карточку для декоративного изображения или другого медиаконтента.         |
| `Card.Media`         | Обёртка для медиа на всю ширину карточки с единым скруглением верхних углов.                  |
| `Card.Header`        | Контейнер для заголовка, описания и необязательного действия справа.                         |
| `Card.Body`          | Основная область содержимого.                                                               |
| `Card.Footer`        | Нижняя строка для действий или метаданных. При необходимости содержимое переносится.        |
| `Card.Title`         | Заголовок, по умолчанию рендерится как `h3`. Для другого уровня используйте `asChild`.       |
| `Card.Description`   | Дополнительный текст под заголовком.                                                         |
| `Card.Action`        | Слот для действия в заголовке.                                                              |
| `Card.Link`          | Ссылка с расширенной областью клика, которая не перекрывает остальные элементы управления. |

## Композиция

### Рекомендуемая композиция

Начните с `<Card />` и добавьте только нужные части. Обычно карточка состоит из `Card.Header`,
`Card.Title`, `Card.Description`, `Card.Body` и `Card.Footer`. Используйте `Card.Media` для изображения или другого
медиа в верхней части карточки, которое должно доходить до её краёв с единым скруглением верхних углов.
`Card.Background` размещает декоративное изображение за содержимым карточки. Наложение и контраст текста настройте
в стилях приложения.

По умолчанию корневой компонент использует `size="md"` и `variant="outline"`.

### Когда нужна собственная композиция

Используйте `asChild`, если семантический дочерний элемент должен стать DOM-узлом части. В композиции Ark
должен быть ровно один дочерний элемент, который умеет принимать объединённые свойства и ref. Если корень
становится ссылкой, не помещайте внутрь кнопки, поля ввода или другие ссылки.

Используйте `Card.Link` внутри `Card.Title`, если карточка должна вести на другую страницу и при этом содержать
отдельные элементы управления. Видимая ссылка остаётся в заголовке, а область клика расширяется на всю карточку,
не перекрывая остальные интерактивные элементы. `Card.Action` меняет только расположение и не создаёт ARIA-связи.

| Ситуация                                                                                  | Рекомендуемый API                                                   |
| ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| Вся карточка является одной ссылкой и не содержит вложенных элементов управления. | `Card asChild` с корневым элементом `<a>`                           |
| Карточка ведёт на другую страницу, но содержит отдельные действия.                | `Card.Link` внутри `Card.Title`, при необходимости с `Card.Action`  |
| Карточка только объединяет содержимое и не используется для навигации.             | Обычная композиция `Card` без специальной ссылки                    |

### Свойства по умолчанию

| Часть       | Свойство  | По умолчанию | Значения                               |
| ----------- | --------- | ------------ | -------------------------------------- |
| `Card.Root` | `size`    | `'md'`       | `'sm' \| 'md' \| 'lg'`                 |
| `Card.Root` | `variant` | `'outline'`  | `'elevated' \| 'outline' \| 'subtle'` |

### Особенности поведения

- По умолчанию корневой компонент создаёт неинтерактивный `div` и передаёт `ref` созданному элементу.
- Все части принимают нативные свойства, `className`, `style` и `asChild` фабрики Ark.
- `Card.Media` необязателен. Не используйте его, если медиа нужно оформить самостоятельно или оно находится
  не в верхней части карточки.
- `Card.Background` подходит для декоративного медиа за содержимым карточки. У фонового изображения оставляйте
  пустой `alt`; если изображение несёт смысловую нагрузку, используйте `Card.Media`.
- `Card.Title` по умолчанию рендерит `h3`.
- Интерактивные корневые элементы, созданные с `asChild`, и `Card.Link` получают одинаковое настраиваемое кольцо
  фокуса `:focus-visible`.
- Card не управляет состоянием, колбэками, поведением клавиатуры, провайдером, контекстом или скрытым полем ввода.
- `Card.Body` убирает верхний внешний отступ у первого непосредственного дочернего элемента и нижний отступ у последнего.
- `--moduix-card-spacing`, `--moduix-card-spacing-sm` и `--moduix-card-spacing-lg` задают общие внутренние
  отступы и интервалы между разделами и имеют приоритет над соответствующими резервными значениями отступов для размеров.

### CSS-свойства

### Атрибуты для стилизации

- Каждая часть предоставляет `data-scope="card"` и соответствующий `data-part`.
- Стабильные атрибуты moduix: `data-slot="card-root"`, `card-background`, `card-media`, `card-header`, `card-body`,
  `card-footer`, `card-title`, `card-description`, `card-action` и `card-link`.
- Корневой компонент предоставляет `data-size="sm | md | lg"` и
  `data-variant="elevated | outline | subtle"`.
- Общие переопределения `--moduix-card-bg`, `--moduix-card-color`, `--moduix-card-border-*` и
  `--moduix-card-shadow` имеют приоритет над соответствующими переменными отдельных вариантов.
- Card не имеет атрибутов интерактивного состояния, поскольку не управляет состоянием и поведением.
