# Обновление и миграция

Способ обновления зависит от того, где находится исходный код компонента. Пользователи пакета
обновляют зависимости, а пользователи реестра просматривают и объединяют изменения с кодом приложения.

| Способ установки | Где находится код | Как обновлять |
| --- | --- | --- |
| npm-пакет | В `node_modules` | Обновить соответствующие пакеты Moduix и Ark UI. |
| Реестр shadcn | В репозитории приложения | Просмотреть diff реестра и объединить его с локальными изменениями. |

Для перехода существующего shadcn-приложения используйте руководство
[Миграция с shadcn](/docs/migrate-from-shadcn).

## Определите установленный адаптер

Учитывайте и фреймворк, и способ стилизации:

| Среда | CSS Modules | Tailwind CSS |
| --- | --- | --- |
| React | `@moduix/react` | `@moduix/react-tailwind` |
| Solid | `@moduix/solid` | `@moduix/solid-tailwind` |

Не обновляйте похожий адаптер, который приложение не использует. Пока порты продолжаются, каталог
Tailwind-пакетов может быть меньше каталога CSS Modules.

к релизу, а не обновляйте оба пакета вслепую. После установки проверьте lockfile.

## Обновите компоненты из реестра

Компоненты из реестра копируются в приложение и не меняются при обновлении пакета. Выберите namespace,
который соответствует обоим параметрам:

| Среда | Реестр CSS Modules | Реестр Tailwind |
| --- | --- | --- |
| React | `@moduix-react` | `@moduix-react-tailwind` |
| Solid | `@moduix-solid` | `@moduix-solid-tailwind` |

Сначала просмотрите компонент, не изменяя локальные файлы:

<PackageManagerTabs command="shadcn@latest view @moduix-react/button" dlx />

<PackageManagerTabs command="shadcn@latest add @moduix-react/button --dry-run" dlx />

<PackageManagerTabs command="shadcn@latest add @moduix-react/button --diff" dlx />

Замените namespace на установленный адаптер, а `button` на нужный элемент. Diff может включать общие
foundation-файлы и зависимости реестра, поэтому просматривайте его полностью.

После проверки выполните обновление в отдельной ветке или чистом рабочем дереве:

<PackageManagerTabs command="shadcn@latest add @moduix-react/button" dlx />

Не используйте `--overwrite`, пока не решите, как сохранить локальные изменения. Объедините обновления
поведения, доступности и стилей с решениями своего продукта.

## Обновите стили и пресеты

Пакетные стили и пресеты обновляются вместе с пакетом. Foundation- и preset-файлы из реестра нужно
просматривать как обычные элементы реестра.

Подключайте созданный конфигурацией реестра foundation stylesheet один раз:

```tsx
import '@/lib/moduix/styles/style.css';
```

Стили приложения должны загружаться после foundation и пресета. Если релиз меняет токены, плотность,
цвета или анимацию, проверьте разделы [Темы](/docs/themes), [Токены](/docs/tokens) и
[Анимации](/docs/animations).

## Проверьте обновление

- Просмотрите `package.json` и lockfile вместе.
- Запустите форматирование, lint, typecheck и тесты приложения.
- Проверьте компоненты и сценарии, названные в Changelog.
- При необходимости проверьте клавиатуру, возврат фокуса, порталы и сокращенную анимацию.
- Перед выпуском сопоставьте локальные изменения реестра с полным upstream diff.
