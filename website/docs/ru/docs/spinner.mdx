## Справочник API

В Ark UI нет отдельного компонента Spinner. moduix строит `Spinner` с помощью фабрики `ark.span` из Ark UI
и предоставляет небольшой API вокруг одного корневого элемента. Компонент следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[передаче ref](https://ark-ui.com/docs/guides/ref).

## Базовый пример

Используйте `Spinner` для кратковременных состояний загрузки в кнопках, строках статуса и небольших блоках,
где контент ещё не появился. По умолчанию компонент сообщает ассистивным технологиям о загрузке: у корневого
элемента есть `role="status"` и запасное имя `aria-label="Loading"`. Это буквальная английская строка `Loading`,
поэтому в интерфейсе на другом языке задайте локализованный `aria-label` или используйте `aria-labelledby`.

## Анатомия

У `Spinner` есть только один публичный корневой элемент. В обычном режиме moduix сам добавляет внутреннюю
обёртку индикатора и стандартное кольцо. Это DOM-узлы и точки привязки для CSS, а не отдельные React-компоненты.
Собственное содержимое через `children` заменяет кольцо, а `asChild` заменяет корневой элемент и оставляет
разметку индикатора на дочернем элементе.

```text
Spinner / Spinner.Root
└─ root[data-scope="spinner"][data-part="root"][data-slot="spinner-root"][data-size]
   └─ indicator[data-scope="spinner"][data-part="indicator"][data-slot="spinner-indicator"]
      └─ ring[data-scope="spinner"][data-part="ring"][data-slot="spinner-ring"] (только по умолчанию)
```

| Часть               | Назначение                                                                                  |
| ------------------- | ------------------------------------------------------------------------------------------- |
| `Spinner` / `Spinner.Root` | Публичный корневой элемент. Принимает `size`, `decorative`, `asChild`, `children` и нативные свойства `span`. |
| indicator                   | Внутренняя вращающаяся обёртка, которая отвечает за размер и анимацию индикатора.               |
| ring                        | Внутреннее стандартное кольцо. Не создаётся, если передано собственное `children`.             |

## Композиция

### Рекомендуемая композиция

В большинстве случаев достаточно короткой формы `<Spinner />`. Она отображает стандартное кольцо и сообщает
ассистивным технологиям о состоянии загрузки без дополнительной разметки.

- Используйте `size` для изменения плотности.
- Используйте `decorative`, если видимый текст рядом со `Spinner` уже сообщает о загрузке.
- Используйте `aria-label` или `aria-labelledby`, если статусу нужно более конкретное имя, чем `"Loading"`.
- Показывайте `Spinner` на основе состояния загрузки в приложении. Компонент не запускает и не останавливает
  саму операцию и не управляет её состоянием.

### Когда нужна собственная композиция

Передайте собственное содержимое через `children`, если стандартное кольцо не подходит, но нужно сохранить
стандартный корень, размер и вращающуюся обёртку.

Используйте `asChild`, только если другой компонент должен создавать сам корневой DOM-элемент. Передайте ровно
один неинтерактивный дочерний элемент. В этом режиме встроенные обёртка индикатора и кольцо не создаются, поэтому
дочерний элемент должен сам содержать разметку визуального индикатора.

### Свойства по умолчанию

| Свойство     | По умолчанию | Примечания                                                                 |
| ------------ | ------------ | -------------------------------------------------------------------------- |
| `size`            | `'md'`       | Принимает `'inherit' \| 'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`. Значение `inherit` использует `1em`.          |
| `decorative`      | `false`      | Для обычного корня задаёт `role="presentation"` и `aria-hidden="true"`; с `asChild` сохраняет семантику ребёнка. |
| `asChild`         | `false`      | Передаёт свойства корня единственному дочернему элементу.                                                   |
| `aria-label`      | `'Loading'`  | Используется, если `Spinner` не декоративный и `aria-labelledby` не задан.                                  |
| `aria-labelledby` | не задано    | Используйте, чтобы связать статус с видимым текстом в другом месте страницы.                               |

### Особенности поведения

- По умолчанию корневой элемент имеет тег `span` и атрибуты `data-scope="spinner"`, `data-part="root"`,
  `data-slot="spinner-root"` и `data-size`.
- `Spinner.Root` - псевдоним совместимости для `Spinner`; в новом коде используйте `Spinner`.
- Недекоративный `Spinner` получает `role="status"`.
- `decorative={true}` скрывает обычный корень от ассистивных технологий. С `asChild` компонент не добавляет роль
  и свойства подписи, поэтому пользовательский дочерний элемент сохраняет собственную семантику.
- Spinner сам задаёт семантику статуса и атрибуты `data-scope`, `data-part`, `data-slot` и `data-size`. Переданные
  конфликтующие нативные свойства их не заменяют.
- Вращающаяся обёртка использует `data-scope="spinner"`, `data-part="indicator"` и `data-slot="spinner-indicator"`.
- Собственное `children` заменяет только стандартное кольцо. Встроенная обёртка по-прежнему отвечает за размер и вращение.
- При `asChild` дочерний элемент становится корнем и должен сам отрисовать необходимый визуальный индикатор.
- `size="inherit"` задаёт размер `1em`, а остальные значения записываются в `data-size` корневого элемента.
- Spinner продолжает вращаться даже при `prefers-reduced-motion: reduce`, поскольку анимация служит визуальным
  признаком загрузки.

## Стилизация

Стилизуйте `Spinner` с помощью `className`, селекторов Ark `data-scope` / `data-part`, стабильных хуков `data-slot`,
`data-size` и публичных переменных `--moduix-spinner-*`, перечисленных в CSS API.

### Хуки стилизации

- `[data-scope="spinner"][data-part="root"]` выбирает корневой элемент в соответствии с анатомией Ark.
- `[data-scope="spinner"][data-part="indicator"]` выбирает вращающуюся внутреннюю обёртку.
- `[data-scope="spinner"][data-part="ring"]` выбирает только стандартное кольцо.
- `data-slot="spinner-root"` - стабильный селектор moduix для отрисованного корня.
- `data-slot="spinner-indicator"` - стабильный селектор moduix для вращающейся внутренней обёртки.
- `data-slot="spinner-ring"` выбирает только стандартное кольцо.
- `Spinner` записывает в корень `data-size="inherit" | "xs" | "sm" | "md" | "lg" | "xl"`.
- `className` применяется к отрисованному корню. При `asChild` это единственный дочерний элемент. При необходимости
  выбирайте индикатор или кольцо дочерними селекторами.
