## Справочник API

В Ark UI нет отдельного компонента Spinner. moduix строит `Spinner` с помощью фабрики `ark.span` из Ark UI
и предоставляет небольшой API вокруг одного корневого элемента. Компонент следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[передаче ref](https://ark-ui.com/docs/guides/ref).

## Базовый пример

Используйте `Spinner` для кратковременных состояний загрузки в кнопках, строках статуса и небольших блоках,
где контент ещё не появился. По умолчанию компонент сообщает ассистивным технологиям о загрузке: у корневого
элемента есть `role="status"` и запасное имя `aria-label="Loading"`. Это буквальная английская строка `Loading`,
поэтому в интерфейсе на другом языке задайте локализованный `aria-label` или используйте `aria-labelledby`.

При `prefers-reduced-motion: reduce` спиннер перестаёт вращаться: токен foundation
`--moduix-animation-spin` преобразуется в `none`. Чтобы оставить вращение у конкретного спиннера, задайте
`animation` для его `[data-slot="spinner-indicator"]` в своём классе.

Задайте `decorative`, когда видимый текст уже описывает загрузку: корень получает `aria-hidden="true"`, без
`role` и запасного имени.

## Анатомия

У `Spinner` есть только один публичный корневой элемент. В обычном режиме moduix сам добавляет внутреннюю
обёртку индикатора и стандартное кольцо. Это DOM-узлы и точки привязки для CSS, а не отдельно экспортируемые компоненты.
Собственное содержимое через `children` заменяет кольцо, а `asChild` заменяет корневой элемент и оставляет
разметку индикатора на дочернем элементе.

```text
Spinner
└─ root[data-scope="spinner"][data-part="root"][data-slot="spinner-root"][data-size]
   └─ indicator[data-scope="spinner"][data-part="indicator"][data-slot="spinner-indicator"]
      └─ ring[data-scope="spinner"][data-part="ring"][data-slot="spinner-ring"] (только по умолчанию)
```

| Часть               | Назначение                                                                                  |
| ------------------- | ------------------------------------------------------------------------------------------- |
| `Spinner`                   | Публичный корневой элемент. Принимает `size`, `decorative`, `asChild`, `children` и нативные свойства `span`. |
| indicator                   | Внутренняя вращающаяся обёртка, которая отвечает за размер и анимацию индикатора.               |
| ring                        | Внутреннее стандартное кольцо. Не создаётся, если передано собственное `children`.             |

## Композиция

`Spinner` только отображает состояние загрузки, которым владеет приложение: компонент не запускает,
не останавливает и не изменяет представленную операцию. Отрисовывайте его на основе состояния, где
уже хранится информация об этой операции.

Передайте собственное `children`, чтобы заменить стандартное кольцо и сохранить обычный корень,
размер и вращающуюся обёртку индикатора. Используйте `asChild`, только если другой компонент должен
владеть корневым элементом: в этом режиме встроенные индикатор и кольцо не создаются, поэтому ровно
один неинтерактивный дочерний элемент должен содержать разметку визуального индикатора.

### Пользовательский индикатор

Передайте собственное содержимое через `children`, если стандартное кольцо нужно заменить, но размер и семантика
статуса должны остаться прежними.

### В кнопке

Оставьте `Spinner` декоративным, если текст кнопки уже объясняет действие. В примере `aria-busy` передаётся кнопке,
а подпись под ней нужна только для демонстрации текущего состояния.

<Example name="spinner/button" />

### Загрузка с текстом

Используйте `decorative`, когда видимый текст рядом со `Spinner` уже объясняет, что происходит.

### Размеры

Используйте небольшие размеры внутри компактных элементов управления, а большие - для самостоятельных состояний загрузки.

### Собственный корневой элемент

Используйте `asChild`, когда другой компонент должен владеть корневым элементом. Дочерний элемент получает атрибуты
и имя класса корня Spinner и должен сам отрисовать визуальный индикатор.

## Стилизация

Стилизуйте `Spinner` с помощью `className` в React, `class` в Solid и Vue, селекторов Ark `data-scope` / `data-part`,
стабильных хуков `data-slot`, `data-size` и публичных переменных `--moduix-spinner-*`, перечисленных в CSS API.
Эти переменные доступны в пакетах CSS Modules; пакеты Tailwind используют классы-утилиты и пользовательские классы,
а не дублируют слой переменных CSS Modules.

### Хуки стилизации

- `[data-scope="spinner"][data-part="root"]` выбирает корневой элемент в соответствии с анатомией Ark.
- `[data-scope="spinner"][data-part="indicator"]` выбирает вращающуюся внутреннюю обёртку.
- `[data-scope="spinner"][data-part="ring"]` выбирает только стандартное кольцо.
- `data-slot="spinner-root"` - стабильный селектор moduix для отрисованного корня.
- `data-slot="spinner-indicator"` - стабильный селектор moduix для вращающейся внутренней обёртки.
- `data-slot="spinner-ring"` выбирает только стандартное кольцо.
- `Spinner` записывает в корень `data-size="inherit" | "xs" | "sm" | "md" | "lg" | "xl"`.
- `className` или `class` применяется к отрисованному корню. При `asChild` это единственный дочерний элемент.
  При необходимости выбирайте индикатор или кольцо дочерними селекторами.
