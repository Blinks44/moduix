## Выбор подходящего компонента

Используйте `Switch` для настроек, которые применяются сразу после изменения. Переключатель управляет
одним булевым значением.

- Выбирайте **`Switch`** для таких настроек, как уведомления, напоминания или включение функций приложения.
- Выбирайте **`Checkbox`**, когда пользователь выбирает значение для отправки вместе с формой, а не сразу меняет настройку.
- Выбирайте **`RadioGroup`**, когда пользователь должен выбрать один вариант из нескольких взаимоисключающих значений.

## Базовый пример

Базовый переключатель состоит из корневого элемента, визуальной дорожки и подписи. Дорожка автоматически получает
стандартный бегунок, а корневой элемент добавляет скрытое поле формы для нативного поведения формы.

## Анатомия

```text
Switch / Switch.Root
├─ Switch.Control
│  └─ Switch.Thumb
├─ Switch.Label
└─ скрытое поле формы (добавляется автоматически)
```

| Часть                         | Назначение                                                                 |
| ----------------------------- | -------------------------------------------------------------------------- |
| `Switch` / `Switch.Root`      | Корневой элемент `label`. Хранит состояние, ID, свойства формы и `size`.   |
| `Switch.RootProvider`         | Корневой элемент с состоянием, созданным через `useSwitch()`.              |
| `Switch.Control`              | Визуальная дорожка и цель для кольца фокуса. По умолчанию добавляет бегунок. |
| `Switch.Thumb`                | Подвижный бегунок для стандартного вида или пользовательского содержимого. |
| `Switch.Label`                | Подпись, связанная с переключателем через Ark.                             |

`Switch` и `Switch.Root` - два имени одного и того же корневого компонента. `Switch.Context`,
`useSwitchContext` и `useSwitch` экспортируются из `@moduix/react` вместе с компонентом.

## Композиция

### Рекомендуемая композиция

В обычном случае используйте короткую форму `<Switch>`, поместив внутрь `Switch.Control` и `Switch.Label`.
Корневой элемент сам добавляет скрытое поле формы, но не добавляет видимые части переключателя.

Если у `Switch.Control` нет дочерних элементов, он добавляет стандартный `Switch.Thumb`. Добавьте
`Switch.Thumb` явно, когда бегунку нужны пользовательское содержимое или собственная стилизация.

### Когда нужна собственная композиция

Используйте `asChild`, когда нужно самостоятельно передать корневой DOM-элемент. Его непосредственный потомок
должен быть единственным элементом, совместимым с `label`, чтобы у переключателя сохранилось доступное имя.

Используйте `Switch.Context` или `useSwitchContext`, когда соседнему интерфейсу нужно читать состояние переключателя.
Используйте `useSwitch` вместе с `Switch.RootProvider`, когда состояние создаётся и управляется вне дерева
переключателя. Не рендерите `Switch` и `Switch.RootProvider` для одного экземпляра состояния.

### Свойства по умолчанию

| Свойство    | По умолчанию | Примечания                                           |
| ----------- | ------------ | ---------------------------------------------------- |
| `size`      | `md`         | Дополнение moduix: `xs`, `sm`, `md`, `lg`, `xl`.     |
| `value`     | `on`         | Значение скрытого поля при отправке формы.           |
| `children`  | `undefined`  | Явно соберите видимые части компонента.              |
| `className` | `undefined`  | Передаётся корневому элементу `label`.               |

### Особенности поведения

- Для неуправляемого режима используйте `defaultChecked`. Для управляемого режима используйте `checked` вместе с `onCheckedChange(details)`.
- `onCheckedChange` получает объект с деталями. Новое булево состояние находится в `details.checked`.
- Корневой элемент всегда добавляет скрытое нативное поле формы. Свойства `name`, `value`, `form` и `required` настраивают его участие в форме. Для неуправляемого переключателя сброс формы возвращает исходное состояние.
- `readOnly` сохраняет текущее состояние и устанавливает `aria-readonly="true"` на нативном элементе управления.
- Дорожка и ползунок отключают переходы, если пользователь предпочитает уменьшенное движение (`prefers-reduced-motion`).
- Для сложной логики чтения состояния используйте `Switch.Context` или `useSwitchContext`. Если владельцу состояния нужно находиться вне дерева переключателя, используйте `useSwitch` вместе с `Switch.RootProvider`.
- При использовании `asChild` дочерний элемент должен оставаться единственным семантическим элементом, совместимым с `label`.

## Стилизация

Стилизуйте `Switch` с помощью `className`, публичных хуков `data-slot`, атрибутов состояния Ark и публичных
CSS-переменных `--moduix-switch-*`, показанных ниже.

### Хуки стилизации

- `Switch` и `Switch.RootProvider` предоставляют `data-slot="switch-root"` / `data-slot="switch-root-provider"` и добавляют атрибут `data-size` от moduix.
- `Switch.Control` предоставляет `data-slot="switch-control"` и получает атрибуты состояния Ark, включая `data-state`, `data-focus-visible`, `data-hover`, `data-active`, `data-disabled`, `data-readonly`, `data-invalid` и `data-required`.
- `Switch.Thumb` предоставляет `data-slot="switch-thumb"` и получает те же атрибуты состояния Ark для движения ползунка и стилизации пользовательского содержимого.
- `Switch.Label` предоставляет `data-slot="switch-label"` для переопределения типографики.
- Нативное поле формы предоставляет `data-slot="switch-hidden-input"` для проверки, но должно оставаться визуально скрытым средствами Ark.
