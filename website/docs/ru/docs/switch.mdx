Базовый переключатель состоит из корня, визуальной дорожки, подписи и явного `SwitchHiddenInput` для нативного
взаимодействия и работы с формой. Если у дорожки нет дочерних элементов, она получает стандартный бегунок.

## Выбор подходящего компонента

Используйте `Switch` для настройки, которая применяется сразу после изменения. Переключатель представляет одно
булево значение.

- Выбирайте **`Switch`** для таких настроек, как уведомления, напоминания или функции приложения.
- Выбирайте **`Checkbox`**, когда значение нужно отправить вместе с формой,
  а не применить сразу как настройку.
- Выбирайте **`RadioGroup`**, когда пользователь должен выбрать один вариант из нескольких взаимоисключающих значений.

## Композиция

Явно добавляйте `SwitchHiddenInput` внутрь `Switch` или `SwitchRootProvider`, даже если
переключатель находится не в форме. Это нативное поле, которое Ark использует для фокуса, работы с клавиатурой,
доступности и отправки формы.

Если у `SwitchControl` нет дочерних элементов, он добавляет стандартный `SwitchThumb`. Добавляйте `SwitchThumb`
явно только при необходимости настроить содержимое или стили бегунка.

Используйте `SwitchContext` или `useSwitchContext`, когда соседнему интерфейсу нужно читать состояние переключателя. Используйте
`useSwitch` вместе с `SwitchRootProvider`, когда состояние нужно создать вне дерева переключателя.
Не рендерите `Switch` и `SwitchRootProvider` для одного экземпляра состояния.

При использовании `asChild` передавайте один семантический элемент, совместимый с `label`, чтобы Ark сохранял
доступность переключателя.

## Стилизация

Стилизуйте `Switch` с помощью `className` в React или `class` в Solid и Vue, публичных хуков `data-slot` и атрибутов состояния Ark,
а также публичных CSS-переменных `--moduix-switch-*`, показанных ниже. Варианты Tailwind настраиваются
обычными утилитами и пользовательскими классами. Переменные ниже относятся к CSS Modules, а атрибуты данных
общие для обоих подходов.

Ползунок получает размер и положение от бокса контрола, поэтому переопределение `width` или `height`
у `SwitchControl` (классом в CSS Modules, утилитами `w-*` и `h-*` в Tailwind) сохраняет его квадратным
и прижатым к обоим краям. Направление справа налево задаёт Ark: внутри RTL [`LocaleProvider`](/docs/rtl)
Ark ставит `dir` на каждую часть, и ползунок в состоянии checked уходит к концу строки.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `Switch` | `switch-root` |
| `SwitchRootProvider` | `switch-root-provider` |
| `SwitchControl` | `switch-control` |
| `SwitchThumb` | `switch-thumb` |
| `SwitchLabel` | `switch-label` |

- `Switch` и `SwitchRootProvider` предоставляют `data-slot="switch-root"` /
  `data-slot="switch-root-provider"` и добавляют атрибут `data-size` от moduix.
- `SwitchControl` предоставляет `data-slot="switch-control"` и получает атрибуты состояния Ark, включая
  `data-state`, `data-focus`, `data-focus-visible`, `data-hover`, `data-active`, `data-disabled`, `data-readonly`,
  `data-invalid` и `data-required`.
