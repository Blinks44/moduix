Используйте `ProgressCircularRing`, чтобы отобразить стандартный круг с фоновой дорожкой и дугой
прогресса. Добавьте `ProgressCircularValueText`, чтобы показать текущее значение. В примере

с названием задачи, совпадающим с видимой меткой.

## Выбор подходящего компонента

Используйте `ProgressCircular` для компактной индикации прогресса в тексте, карточках, бейджах на
панели инструментов и небольших дашбордах. Выбирайте `ProgressLinear`, если прогресс удобнее
сравнивать с горизонтальной шкалой.

## Примеры

### Управляемое состояние

Храните `value` в состоянии приложения, когда прогресс должен синхронизироваться с другим
элементом управления или внешней задачей.

<Example name="progress-circular/controlled" />

### Неопределённый прогресс

Установите `defaultValue={null}` или `value={null}`, когда задача выполняется, но её прогресс пока
нельзя измерить.

<Example name="progress-circular/indeterminate" />

### Минимум и максимум

Используйте `min` и `max`, чтобы отображать значения в диапазоне, отличном от стандартного диапазона
от `0` до `100`.

<Example name="progress-circular/min-max" />

### Текст значения

Используйте `ProgressCircularContext` вместе с `translations.value(details)`, если видимому значению нужна
формулировка, связанная с конкретной задачей. Передайте `progress.valueAsString` в качестве
дочернего элемента `ProgressCircularValueText`, чтобы видимый текст совпадал с доступным текстом значения.

<Example name="progress-circular/value-text" />

### Root Provider

Создайте хранилище состояния через `useProgress()` и передайте его в `ProgressCircularRootProvider`, если
другому компоненту нужно читать или изменять прогресс за пределами отрисованного дерева.

<Example name="progress-circular/root-provider" />

### Представления состояния

Используйте `ProgressCircularView`, если вспомогательный текст или интерфейс должны меняться
вместе с состоянием прогресса Ark.

<Example name="progress-circular/state-views" />

## Композиция

Используйте `ProgressCircularRing`, когда достаточно стандартного круга: он объединяет `ProgressCircularCircle`,
`ProgressCircularCircleTrack` и `ProgressCircularCircleRange`, но не выводит и не центрирует `ProgressCircularValueText`. Если значение должно быть
в центре, явно соберите композицию из метки, круга и текста значения.

Используйте `defaultValue`, когда состояние прогресса принадлежит компоненту. Используйте `value`
с `onValueChange(details)`, когда состоянием владеет приложение. Установите `defaultValue={null}`
или `value={null}` для неопределённого прогресса. Если состояние нужно создать за пределами
отрисованного дерева, вызовите `useProgress()` и передайте хранилище состояния в
`ProgressCircularRootProvider`, не создавая для того же хранилища ещё один корень.

## Стилизация

Используйте `className` в React и `class` в Solid и Vue на экспортируемых частях для структурной
стилизации. Варианты Tailwind используют нативные утилитарные классы и пользовательские классы. Варианты с
CSS Modules предоставляют переменные ниже. Для стилей, зависящих от состояния, используйте
атрибуты данных Ark, SVG-переменные Ark и хуки `data-slot` moduix.

В неопределённом состоянии вращается дуга в четверть окружности. Если пользователь предпочитает
уменьшить анимацию, дуга не использует переходы и остаётся на месте. Чтобы задать неопределённому
прогрессу отдельный цвет, стилизуйте `ProgressCircularCircleRange` через `[data-state='indeterminate']`.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `ProgressCircular` | `progress-circular-root` |
| `ProgressCircularRootProvider` | `progress-circular-root-provider` |
| `ProgressCircularLabel` | `progress-circular-label` |
| `ProgressCircularValueText` | `progress-circular-value-text` |
| `ProgressCircularCircle` | `progress-circular-circle` |
| `ProgressCircularCircleTrack` | `progress-circular-circle-track` |
| `ProgressCircularCircleRange` | `progress-circular-circle-range` |
| `ProgressCircularView` | `progress-circular-view` |

- `ProgressCircularRing` использует те же `data-slot`, `className`/`class`, ref и переменные размера и
  толщины `--moduix-progress-circular-*`, что и `ProgressCircularCircle`.
- Атрибуты Ark: `data-scope="progress"`, `data-part`, `data-state="indeterminate|loading|complete"`,
  `data-orientation`, `data-value` и `data-max`.
- Переменные Ark для круга: `--size`, `--thickness`, `--radius`, `--circumference`, `--percent` и
  `--offset`.
