## Выбор подходящего компонента

Используйте `ProgressCircular` для компактной индикации прогресса в тексте, карточках, бейджах на
панели инструментов и небольших дашбордах. Выбирайте `ProgressLinear`, если прогресс удобнее
сравнивать с горизонтальной шкалой.

## Анатомия

```text
ProgressCircular
├─ ProgressCircularLabel
├─ ProgressCircularCircle
│  ├─ ProgressCircularCircleTrack
│  └─ ProgressCircularCircleRange
├─ ProgressCircularRing
│  └─ fixed ProgressCircularCircle, ProgressCircularCircleTrack, and ProgressCircularCircleRange subtree
├─ ProgressCircularValueText
└─ ProgressCircularView

ProgressCircularRootProvider
└─ same part tree connected to useProgress()
```

| Часть                                         | Назначение                                                                        |
| --------------------------------------------- | --------------------------------------------------------------------------------- |
| `ProgressCircular`  | Отвечает за состояние прогресса, форматирование и создаваемые идентификаторы.    |
| `ProgressCircularRootProvider`               | Подключает части к состоянию, созданному `useProgress()`.        |
| `ProgressCircularContext`                    | Передаёт текущее состояние в функцию, переданную как дочерний элемент.           |
| `ProgressCircularLabel`                      | Добавляет видимый контекст к индикатору прогресса.                                |
| `ProgressCircularRing`                       | Удобная часть, которая сама отрисовывает стандартные круг, дорожку и дугу.        |
| `ProgressCircularCircle`                     | SVG-элемент индикатора с ролью `progressbar` и ARIA-атрибутами значения от Ark.   |
| `ProgressCircularCircleTrack`               | Фоновый круг.                                                                     |
| `ProgressCircularCircleRange`                | Передняя дуга, отражающая текущий прогресс или неопределённое состояние.           |
| `ProgressCircularValueText`                  | Показывает форматированное значение и сообщает об изменениях.                    |
| `ProgressCircularView`                       | Показывает содержимое в состояниях `indeterminate`, `loading` или `complete`.     |

## Композиция

`ProgressCircular` является сокращённой формой `ProgressCircular`. Используйте
`ProgressCircularRing`, когда достаточно стандартного круга: он объединяет `ProgressCircularCircle`,
`ProgressCircularCircleTrack` и `ProgressCircularCircleRange`, но не выводит и не центрирует `ProgressCircularValueText`. Если значение должно быть
в центре, явно соберите композицию из метки, круга и текста значения.

Используйте `defaultValue`, когда состояние прогресса принадлежит компоненту. Используйте `value`
с `onValueChange(details)`, когда состоянием владеет приложение. Установите `defaultValue={null}`
или `value={null}` для неопределённого прогресса. Если состояние нужно создать за пределами
отрисованного дерева, вызовите `useProgress()` и передайте хранилище состояния в
`ProgressCircularRootProvider`, не создавая для того же хранилища ещё один корень.

## Стилизация

Используйте `className` в React и `class` в Solid на экспортируемых частях для структурной
стилизации. Варианты Tailwind используют нативные утилитарные классы и пользовательские классы. Варианты с
CSS Modules предоставляют переменные ниже. Для стилей, зависящих от состояния, используйте
атрибуты данных Ark, SVG-переменные Ark и хуки `data-slot` moduix.

Используйте `--moduix-progress-circular-range-indeterminate-bg`, чтобы задать для неопределённого
прогресса отдельный семантический цвет. Если пользователь предпочитает уменьшить анимацию, дуга
не вращается и не использует переходы. Задайте
`--moduix-progress-circular-range-indeterminate-reduced-motion-dasharray`, чтобы сохранить
заметный статичный сигнал.

### Хуки для стилизации

- `data-slot="progress-circular-root"`, `data-slot="progress-circular-root-provider"`,
  `data-slot="progress-circular-label"`, `data-slot="progress-circular-circle"`,
  `data-slot="progress-circular-circle-track"`, `data-slot="progress-circular-circle-range"`,
  `data-slot="progress-circular-value-text"` и `data-slot="progress-circular-view"`.
- `ProgressCircularRing` использует те же `data-slot`, `className`, ref и переменные размера и
  толщины `--moduix-progress-circular-*`, что и `ProgressCircularCircle`.
- Атрибуты Ark: `data-scope="progress"`, `data-part`, `data-state="indeterminate|loading|complete"`,
  `data-orientation`, `data-value` и `data-max`.
- Переменные Ark для круга: `--size`, `--thickness`, `--radius`, `--circumference`, `--percent` и
  `--offset`.
