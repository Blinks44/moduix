## Выбор подходящего компонента

Используйте `ProgressCircular` для компактной индикации прогресса в тексте, карточках, бейджах на
панели инструментов и небольших дашбордах. Выбирайте `ProgressLinear`, если прогресс удобнее
сравнивать с горизонтальной шкалой.

## Базовый пример

Используйте `ProgressCircular.Ring`, чтобы отобразить стандартный круг с фоновой дорожкой и дугой
прогресса. Добавьте `ProgressCircular.ValueText`, чтобы показать текущее значение. В этом примере
внешний контейнер размещает текст значения в центре круга. Укажите для `Ring` атрибут `aria-label`
с названием задачи. Метка должна соответствовать видимому тексту.

## Анатомия

```text
ProgressCircular / ProgressCircular.Root
├─ ProgressCircular.Label
├─ ProgressCircular.Circle
│  ├─ ProgressCircular.CircleTrack
│  └─ ProgressCircular.CircleRange
├─ ProgressCircular.Ring
│  └─ fixed Circle, CircleTrack, and CircleRange subtree
├─ ProgressCircular.ValueText
└─ ProgressCircular.View

ProgressCircular.RootProvider
└─ same part tree connected to ProgressCircular.useProgress()
```

| Часть                                         | Назначение                                                                        |
| --------------------------------------------- | --------------------------------------------------------------------------------- |
| `ProgressCircular` / `ProgressCircular.Root`  | Отвечает за состояние прогресса, форматирование и создаваемые идентификаторы.      |
| `ProgressCircular.RootProvider`               | Подключает части к состоянию, созданному `ProgressCircular.useProgress()`.         |
| `ProgressCircular.Context`                    | Передаёт текущее состояние в функцию, переданную как дочерний элемент.             |
| `ProgressCircular.Label`                      | Добавляет видимый контекст к индикатору прогресса.                                 |
| `ProgressCircular.Ring`                       | Удобная часть, которая сама отрисовывает стандартные круг, дорожку и дугу.         |
| `ProgressCircular.Circle`                     | SVG-элемент индикатора с ролью `progressbar` и ARIA-атрибутами значения от Ark.    |
| `ProgressCircular.CircleTrack`                | Фоновый круг.                                                                      |
| `ProgressCircular.CircleRange`                | Передняя дуга, отражающая текущий прогресс или неопределённое состояние.            |
| `ProgressCircular.ValueText`                  | Показывает форматированное значение и сообщает об изменениях.                     |
| `ProgressCircular.View`                      | Показывает содержимое в состояниях `indeterminate`, `loading` или `complete`.      |

## Композиция

### Рекомендуемая композиция

`ProgressCircular` - сокращённая форма корневого компонента, эквивалентная
`ProgressCircular.Root`. Для стандартного круга используйте `ProgressCircular.Ring`: он сам
добавляет `Circle`, `CircleTrack` и `CircleRange`. `Ring` принимает `className`, ARIA-свойства и
те же CSS-переменные, что и `Circle`.

Для неконтролируемого прогресса используйте `defaultValue`. Для управляемого передайте `value` и
`onValueChange(details)`. Установите `defaultValue={null}` или `value={null}`, если прогресс пока
нельзя измерить.

### Когда нужна собственная композиция

Используйте `translations.value(details)`, чтобы задать доступное имя, которое Ark передаёт кругу,
если у `Ring` или `Circle` нет явного `aria-label`. Эта настройка меняет только доступное имя.
Чтобы тот же текст был виден в интерфейсе, отрисуйте `ValueText` внутри
`ProgressCircular.Context` и передайте ему `progress.valueAsString` как дочерний элемент. Чтобы
разместить значение в центре круга, оберните круг и текст в подходящий элемент разметки.

Используйте `Circle`, `CircleTrack` и `CircleRange`, когда нужно изменить SVG-структуру или
воспользоваться композицией Ark через `asChild`. Используйте `ids`, если в собственной структуре
нужны стабильные явные идентификаторы корня, метки или круга. Используйте
`ProgressCircular.useProgress()` с `RootProvider`, если состояние нужно создать за пределами
отрисованного дерева или разделить его с другим компонентом. Используйте
`ProgressCircular.useProgressContext()` ниже корня или провайдера, когда пользовательскому
компоненту нужен доступ к текущему состоянию. Импортируйте Ark напрямую только для интеграций,
которые нельзя построить на API moduix.

### Свойства по умолчанию

| Свойство         | По умолчанию           | Примечания                                                    |
| ---------------- | ---------------------- | ------------------------------------------------------------- |
| `defaultValue`   | `50`                   | Начальное значение в неконтролируемом режиме.                 |
| `min`            | `0`                    | Минимальное значение для процента и ARIA-значения.            |
| `max`            | `100`                  | Максимальное значение для процента и ARIA-значения.           |
| `formatOptions`  | `{ style: 'percent' }` | Определяет форматирование `ValueText`.                       |
| `locale`         | `'en-US'`              | Локаль, которую использует `Intl.NumberFormat`.               |
| `orientation`    | `'horizontal'`         | Ориентация Ark. Для кругового индикатора обычно оставляйте `horizontal`. |

### Особенности поведения

`ProgressCircular.Circle` получает от Ark роль `progressbar` и ARIA-атрибуты значения.
`ProgressCircular.Label` добавляет видимый контекст, но автоматически не задаёт доступное имя
круга. Передайте `Ring` или `Circle` атрибут `aria-label` или `aria-labelledby` с названием задачи.
Ark также задаёт SVG-переменные радиуса, длины окружности, процента и смещения штриха.

Все экспортируемые части Ark, кроме `Ring`, поддерживают `asChild` через полиморфную композицию.
Если вы заменяете отрисованный элемент, сохраните его семантику и роль `progressbar` у круга.

`ProgressCircular.ValueText` сообщает об изменениях через `aria-live="polite"`. Оставляйте видимую
метку в дереве либо задавайте `aria-label` или `aria-labelledby`, если композиция не включает
`ProgressCircular.Label`.

## Стилизация

Используйте `className` на экспортируемых частях, чтобы менять структуру и внешний вид. Для стилей,
зависящих от состояния, используйте атрибуты данных Ark, SVG-переменные Ark и хуки `data-slot`
moduix.

Используйте `--moduix-progress-circular-range-indeterminate-bg`, чтобы задать для неопределённого
прогресса отдельный семантический цвет. Если пользователь предпочитает уменьшить анимацию, дуга не
вращается и не использует переходы. Задайте `--moduix-progress-circular-range-indeterminate-reduced-motion-dasharray`,
чтобы сохранить заметный статичный сигнал.

### Хуки для стилизации

- `data-slot="progress-circular-root"`, `data-slot="progress-circular-root-provider"`,
  `data-slot="progress-circular-label"`, `data-slot="progress-circular-circle"`,
  `data-slot="progress-circular-circle-track"`, `data-slot="progress-circular-circle-range"`,
  `data-slot="progress-circular-value-text"` и `data-slot="progress-circular-view"`.
- `ProgressCircular.Ring` использует те же `data-slot`, `className`, ref и переменные размера и
  толщины `--moduix-progress-circular-*`, что и `ProgressCircular.Circle`.
- Атрибуты Ark: `data-scope="progress"`, `data-part`, `data-state="indeterminate|loading|complete"`,
  `data-orientation`, `data-value` и `data-max`.
- Переменные Ark для круга: `--size`, `--thickness`, `--radius`, `--circumference`, `--percent` и
  `--offset`.
