## Выбор подходящего компонента

Используйте `ProgressCircular` для компактной индикации прогресса в тексте, карточках, бейджах на
панели инструментов и небольших дашбордах. Выбирайте `ProgressLinear`, если прогресс удобнее
сравнивать с горизонтальной шкалой.

## Базовый пример

`ProgressCircular` доступен для React и Solid в вариантах с CSS Modules и Tailwind. Пример на этой
странице использует React и CSS Modules, а вкладки React и Solid показывают нативный исходный код для
того же публичного контракта.

Используйте `ProgressCircular.Ring`, чтобы отобразить стандартный круг с фоновой дорожкой и дугой
прогресса. Добавьте `ProgressCircular.ValueText`, чтобы показать текущее значение. В примере

## Анатомия

```text
ProgressCircular / ProgressCircular.Root
├─ ProgressCircular.Label
├─ ProgressCircular.Circle
│  ├─ ProgressCircular.CircleTrack
│  └─ ProgressCircular.CircleRange
├─ ProgressCircular.Ring
│  └─ fixed Circle, CircleTrack, and CircleRange subtree
├─ ProgressCircular.ValueText
└─ ProgressCircular.View

ProgressCircular.RootProvider
└─ same part tree connected to ProgressCircular.useProgress()
```

| Часть                                         | Назначение                                                                        |
| --------------------------------------------- | --------------------------------------------------------------------------------- |
| `ProgressCircular` / `ProgressCircular.Root`  | Отвечает за состояние прогресса, форматирование и создаваемые идентификаторы.    |
| `ProgressCircular.RootProvider`               | Подключает части к состоянию, созданному `ProgressCircular.useProgress()`.        |
| `ProgressCircular.Context`                    | Передаёт текущее состояние в функцию, переданную как дочерний элемент.           |
| `ProgressCircular.Label`                      | Добавляет видимый контекст к индикатору прогресса.                                |
| `ProgressCircular.Ring`                       | Удобная часть, которая сама отрисовывает стандартные круг, дорожку и дугу.        |
| `ProgressCircular.Circle`                     | SVG-элемент индикатора с ролью `progressbar` и ARIA-атрибутами значения от Ark.   |
| `ProgressCircular.CircleTrack`               | Фоновый круг.                                                                     |
| `ProgressCircular.CircleRange`                | Передняя дуга, отражающая текущий прогресс или неопределённое состояние.           |
| `ProgressCircular.ValueText`                  | Показывает форматированное значение и сообщает об изменениях.                    |
| `ProgressCircular.View`                       | Показывает содержимое в состояниях `indeterminate`, `loading` или `complete`.     |

## Композиция

`ProgressCircular` является сокращённой формой `ProgressCircular.Root`. Используйте
`ProgressCircular.Ring`, когда достаточно стандартного круга: он объединяет `Circle`,
`CircleTrack` и `CircleRange`, но не выводит и не центрирует `ValueText`. Если значение должно быть
в центре, явно соберите композицию из метки, круга и текста значения.

Используйте `defaultValue`, когда состояние прогресса принадлежит компоненту. Используйте `value`
с `onValueChange(details)`, когда состоянием владеет приложение. Установите `defaultValue={null}`
или `value={null}` для неопределённого прогресса. Если состояние нужно создать за пределами
отрисованного дерева, вызовите `ProgressCircular.useProgress()` и передайте хранилище состояния в
`ProgressCircular.RootProvider`, не создавая для того же хранилища ещё один корень.

## Стилизация

Используйте `className` в React и `class` в Solid на экспортируемых частях для структурной
стилизации. Варианты Tailwind используют нативные утилитарные классы и пользовательские классы. Варианты с
CSS Modules предоставляют переменные ниже. Для стилей, зависящих от состояния, используйте
атрибуты данных Ark, SVG-переменные Ark и хуки `data-slot` moduix.

Используйте `--moduix-progress-circular-range-indeterminate-bg`, чтобы задать для неопределённого
прогресса отдельный семантический цвет. Если пользователь предпочитает уменьшить анимацию, дуга
не вращается и не использует переходы. Задайте
`--moduix-progress-circular-range-indeterminate-reduced-motion-dasharray`, чтобы сохранить
заметный статичный сигнал.

### Хуки для стилизации

- `data-slot="progress-circular-root"`, `data-slot="progress-circular-root-provider"`,
  `data-slot="progress-circular-label"`, `data-slot="progress-circular-circle"`,
  `data-slot="progress-circular-circle-track"`, `data-slot="progress-circular-circle-range"`,
  `data-slot="progress-circular-value-text"` и `data-slot="progress-circular-view"`.
- `ProgressCircular.Ring` использует те же `data-slot`, `className`, ref и переменные размера и
  толщины `--moduix-progress-circular-*`, что и `ProgressCircular.Circle`.
- Атрибуты Ark: `data-scope="progress"`, `data-part`, `data-state="indeterminate|loading|complete"`,
  `data-orientation`, `data-value` и `data-max`.
- Переменные Ark для круга: `--size`, `--thickness`, `--radius`, `--circumference`, `--percent` и
  `--offset`.
