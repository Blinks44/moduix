## Выбор подходящего компонента

Используйте `ProgressCircular` для компактного индикатора в строке, карточке, бейдже на панели инструментов или небольшом дашборде. Выбирайте `ProgressLinear`, если пользователю важно сопоставить прогресс с горизонтальной шкалой.

## Базовый пример

Используйте `ProgressCircular.Ring` для стандартного SVG-круга, фоновой дорожки и дуги прогресса. Добавьте `ProgressCircular.ValueText`, если текущее значение должно быть видно пользователю. В этом примере внешний контейнер размещает значение в центре круга. Задайте `Ring` атрибут `aria-label`, который описывает задачу и соответствует видимой метке.

## Анатомия

```text
ProgressCircular / ProgressCircular.Root
├─ ProgressCircular.Label
├─ ProgressCircular.Circle
│  ├─ ProgressCircular.CircleTrack
│  └─ ProgressCircular.CircleRange
├─ ProgressCircular.Ring
│  └─ fixed Circle, CircleTrack, and CircleRange subtree
├─ ProgressCircular.ValueText
└─ ProgressCircular.View

ProgressCircular.RootProvider
└─ same part tree connected to ProgressCircular.useProgress()
```

| Часть                                         | Назначение                                                              |
| --------------------------------------------- | ----------------------------------------------------------------------- |
| `ProgressCircular` / `ProgressCircular.Root`  | Управляет состоянием прогресса, форматированием и идентификаторами.      |
| `ProgressCircular.RootProvider`               | Подключает части к состоянию, созданному `ProgressCircular.useProgress()`. |
| `ProgressCircular.Context`                    | Передаёт текущее состояние прогресса в дочернюю функцию.                  |
| `ProgressCircular.Label`                      | Добавляет видимый контекст к индикатору прогресса.                         |
| `ProgressCircular.Ring`                       | Сокращённая запись для стандартного круга, дорожки и дуги прогресса.       |
| `ProgressCircular.Circle`                     | SVG-поверхность индикатора с ролью и ARIA-атрибутами значения.             |
| `ProgressCircular.CircleTrack`                | Фоновый круг.                                                             |
| `ProgressCircular.CircleRange`                | Передний круг, отражающий текущий процент или состояние.                  |
| `ProgressCircular.ValueText`                  | Показывает форматированное значение.                                      |
| `ProgressCircular.View`                       | Показывает содержимое для `indeterminate`, `loading` или `complete`.       |

## Композиция

### Рекомендуемая композиция

`ProgressCircular` - сокращённая форма корневого компонента, эквивалентная `ProgressCircular.Root`. Используйте `ProgressCircular.Ring` для стандартного круга, дорожки и дуги прогресса. Он принимает `className`, свойства ARIA и те же CSS-переменные, что и `ProgressCircular.Circle`.

Используйте `defaultValue` для неконтролируемого прогресса. Для управляемого прогресса передайте `value` и `onValueChange(details)`. Установите `defaultValue={null}` или `value={null}`, когда завершение задачи неизвестно.

### Когда нужна собственная композиция

Используйте `translations.value(details)`, чтобы настроить доступное имя, которое Ark генерирует для `Ring` или `Circle`, если у них нет явного `aria-label`. Чтобы показать этот же текст в интерфейсе, отрисуйте `ValueText` внутри `ProgressCircular.Context` и передайте `progress.valueAsString` в качестве дочернего элемента. Если значение должно быть в центре круга, оберните круг и текст в любой подходящий элемент раскладки.

Используйте `Circle`, `CircleTrack` и `CircleRange`, когда нужно изменить SVG-структуру или воспользоваться композицией Ark через `asChild`. Используйте `ids`, когда метке, кругу или окружающей раскладке нужны стабильные явные идентификаторы в более сложном дереве. Используйте `ProgressCircular.useProgress()` с `RootProvider`, когда другой компонент должен создать или изменять состояние за пределами отрисованного дерева. Используйте `ProgressCircular.useProgressContext()` ниже корня или провайдера, когда пользовательскому компоненту нужен доступ к текущему состоянию. Прямые импорты Ark оставляйте для интеграций, которые нельзя построить через API moduix.

### Свойства по умолчанию

| Свойство         | По умолчанию           | Примечания                                                |
| ---------------- | ---------------------- | --------------------------------------------------------- |
| `defaultValue`   | `50`                   | Начальное значение для неконтролируемого прогресса.        |
| `min`            | `0`                    | Минимум, используемый для процента и ARIA-значения.        |
| `max`            | `100`                  | Максимум, используемый для процента и ARIA-значения.       |
| `formatOptions`  | `{ style: 'percent' }` | Параметры форматирования `ValueText`.                     |
| `locale`         | `'en-US'`              | Локаль для `Intl.NumberFormat`.                           |

### Особенности поведения

`ProgressCircular.Circle` получает от Ark роль индикатора прогресса и ARIA-атрибуты значения. Передайте `Ring` или `Circle` атрибут `aria-label`, который называет задачу. `ProgressCircular.Label` добавляет видимый контекст, но автоматически не связывает его с кругом. Ark также управляет SVG-переменными радиуса, длины окружности, процента и смещения штриха.

Все части Ark, кроме `Ring`, поддерживают `asChild` через полиморфную композицию. Сохраняйте семантику заменяемых дочерних элементов и роль индикатора прогресса на круге.

`ProgressCircular.ValueText` сообщает об изменениях через `aria-live="polite"`. Оставляйте видимую метку в дереве либо задавайте `aria-label`/`aria-labelledby`, если композиция не включает `ProgressCircular.Label`.

## Стилизация

Используйте `className` на экспортируемых частях для структурных изменений стилей. Для стилей, зависящих от состояния, используйте атрибуты данных Ark, SVG-переменные Ark и хуки `data-slot` moduix.

Используйте `--moduix-progress-circular-range-indeterminate-bg`, чтобы выделить неопределённый прогресс отдельным семантическим цветом. Если пользователь предпочитает меньше движения, дуга не вращается и не использует переходы. Используйте переменную шаблона штрихов для этого режима, чтобы сохранить статичный визуальный сигнал.

### Хуки стилизации

- `data-slot="progress-circular-root"`, `progress-circular-root-provider`, `progress-circular-label`, `progress-circular-circle`, `progress-circular-circle-track`, `progress-circular-circle-range`, `progress-circular-value-text` и `progress-circular-view`.
- `ProgressCircular.Ring` использует те же `data-slot`, `className`, ref и переменные размера и толщины `--moduix-progress-circular-*`, что и `ProgressCircular.Circle`.
- Хуки Ark: `data-scope="progress"`, `data-part`, `data-state="indeterminate|loading|complete"`, `data-orientation`, `data-value` и `data-max`.
- Переменные круга Ark: `--size`, `--thickness`, `--radius`, `--circumference`, `--percent` и `--offset`.
