## Справочник API

Ark UI не предоставляет отдельного примитива для breadcrumbs. В moduix этот компонент собран с помощью официального
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилям](https://ark-ui.com/docs/guides/styling) и работе с
[ref](https://ark-ui.com/docs/guides/ref).

## Анатомия

Компонент экспортирует все части через пространство имён в стиле Ark.

```text
Breadcrumbs / Breadcrumbs.Root
└─ Breadcrumbs.List
   ├─ Breadcrumbs.Item
   │  └─ Breadcrumbs.Link
   ├─ Breadcrumbs.Separator
   └─ Breadcrumbs.Item
      └─ Breadcrumbs.Page
```

| Часть                              | Роль                                                               |
| ---------------------------------- | ------------------------------------------------------------------ |
| `Breadcrumbs` / `Breadcrumbs.Root` | Область навигации с `aria-label` по умолчанию.                     |
| `Breadcrumbs.List`                 | Упорядоченный список сегментов пути.                               |
| `Breadcrumbs.Item`                 | Элемент списка, содержащий один сегмент.                           |
| `Breadcrumbs.Link`                 | Стилизованная ссылка для сегментов, по которым можно перейти; поддерживает `asChild`. |
| `Breadcrumbs.Page`                 | Текст текущей страницы с `aria-current="page"`.                   |
| `Breadcrumbs.Separator`            | Визуальный разделитель без семантической роли, скрытый от вспомогательных технологий. |
| `Breadcrumbs.Ellipsis`             | Компактный маркер для кнопки меню, открывающей скрытые сегменты.   |

`Breadcrumbs.Path` - удобное сокращение от moduix. Оно создаёт `Breadcrumbs.List`, `Breadcrumbs.Item`,
`Breadcrumbs.Link`, `Breadcrumbs.Page` и `Breadcrumbs.Separator` на основе массива `items`.

## Композиция

### Рекомендуемая композиция

Используйте `Breadcrumbs.Path` для простых цепочек, где предыдущие страницы представлены ссылками. Последний элемент
становится текущей страницей, между элементами по умолчанию отображается шеврон, а `separator` заменяет его в каждом
видимом промежутке. Это сокращение само создаёт дочерние элементы, поэтому не принимает `children` и `asChild`.
Нативные свойства упорядоченного списка и ref передаются созданному `Breadcrumbs.List`.

### Когда нужна собственная композиция

Перейдите к отдельным частям, если нужны ссылки из роутера фреймворка, скрытые средние сегменты или своя разметка для
отдельных элементов. С помощью Ark `asChild` можно отрисовать такую ссылку вместо `Breadcrumbs.Link`. Внутри должен
быть один семантически корректный элемент ссылки, который сохраняет `href`, фокусировку и клавиатурное поведение.

Объедините части `Breadcrumbs` с `Menu`, если средние сегменты нужно скрыть за триггером с многоточием. Структура меню
должна оставаться явной: `Menu.Positioner`, `Menu.Content` и `Menu.Item asChild`. Компонент `Menu` сам размещает
всплывающее содержимое через портал.

### Свойства по умолчанию

| Компонент                          | По умолчанию | Примечания                                             |
| ---------------------------------- | ------------ | ------------------------------------------------------ |
| `Breadcrumbs` / `Breadcrumbs.Root` | Нет          | Дополнительных поведенческих настроек нет, действуют настройки Ark. |
| `Breadcrumbs.Path`                 | Шеврон       | Если `separator` не задан, между элементами используются шевроны. |

### Особенности поведения

- `Breadcrumbs` создаёт область навигации `nav`; по умолчанию у неё `aria-label="Breadcrumb"`.
- `Breadcrumbs.Path` формирует упорядоченный список из `items`; последний элемент всегда становится текущей страницей.
- Все элементы, кроме последнего, становятся `Breadcrumbs.Link`. Для элементов, по которым нужно переходить, задайте
  `href`, а у последнего элемента его не указывайте.
- `Breadcrumbs.Path` передаёт нативные свойства упорядоченного списка и ref, но сам создаёт дочерние элементы, поэтому
  не поддерживает `children` и `asChild`.
- `Breadcrumbs.Separator` служит только для оформления и скрыт от вспомогательных технологий.
- `Breadcrumbs.Ellipsis` служит только для оформления и скрыт от вспомогательных технологий. Поместите его внутрь
  триггера `Menu`, а доступную метку свёрнутой цепочки задайте на `Menu.Trigger`.
- Видимые сегменты могут сжиматься, если ширины не хватает. Для текущей страницы действует основной лимит усечения
  `--moduix-breadcrumbs-item-max-width`.
- У Breadcrumbs нет управляемых свойств, колбэков, хуков контекста, `RootProvider`, ids, `HiddenInput` или интеграций
  с состоянием формы, потому что компонент не управляет интерактивным состоянием и состоянием формы.

## Стилизация

У каждой экспортируемой части есть стабильный селектор `data-slot` от moduix. Публичные переменные `--moduix-breadcrumbs-*` отвечают за разметку, типографику,
кольцо фокуса, разделители и размер многоточия.

### CSS-свойства

<CssPropertiesSection properties={BreadcrumbsDocs.breadcrumbsCssProperties} />

### Селекторы для стилизации

- Значения `data-slot="breadcrumbs-root"`, `breadcrumbs-list`, `breadcrumbs-item`, `breadcrumbs-link`, `breadcrumbs-page`,
  `breadcrumbs-separator` и `breadcrumbs-ellipsis` служат стабильными селекторами moduix.
- `Breadcrumbs.Link`, `Breadcrumbs.Page` и `Breadcrumbs.Ellipsis` используют общий горизонтальный внутренний отступ из
  `--moduix-breadcrumbs-item-padding-x`.
- Видимые элементы `Breadcrumbs.Item` могут сжиматься, чтобы цепочка помещалась в одну строку. Последний видимый элемент
  остаётся главной целью усечения и использует `--moduix-breadcrumbs-item-max-width`.
