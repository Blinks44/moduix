## Использование

<UsageCode

<PropChips
  items={[

Используйте `BreadcrumbsPath`, если у вас уже есть список сегментов пути. На основе обязательных пропсов `links` и `page`
компонент создаёт упорядоченный список, элементы, ссылки, текущую страницу и разделители.

В React, Solid и Vue используются одинаковые плоские имена значений. Импортируйте `Breadcrumbs` как корень и импортируйте
каждую дополнительную часть напрямую, например `BreadcrumbsPath` и `BreadcrumbsLink`. Эти же имена работают и в пакетах
npm, и в исходниках реестра shadcn.

## Примеры

### Пользовательский разделитель

Используйте `BreadcrumbsPath`, если во всех видимых промежутках нужен один и тот же значок или символ вместо шеврона
по умолчанию.

<Example name="breadcrumbs/custom-separator" />

### Ссылка из роутера

Используйте Ark `asChild`, чтобы встроить в `Breadcrumbs` ссылку, которую создаёт роутер приложения.

<Example name="breadcrumbs/framework-link" />

### Свёрнутая цепочка

Используйте отдельные части `Breadcrumbs` вместе с `Menu`, если средние сегменты нужно скрывать и показывать по запросу.
Взаимодействием управляют триггер и содержимое меню, поэтому в примере используются отдельные части, а не
`BreadcrumbsPath`.

<Example name="breadcrumbs/collapsed-path" />

### Длинная метка текущей страницы

Передайте узел через проп `page`, если текущей странице нужны дополнительные атрибуты, например `title`. Предшествующие сегменты тоже могут сжиматься, поэтому длинные промежуточные подписи с меньшей
вероятностью приведут к переполнению цепочки.

<Example name="breadcrumbs/long-current-label" />

### Сборка из частей

Та же цепочка, что в Basic, но без `BreadcrumbsPath`: `BreadcrumbsList` содержит по одному
`BreadcrumbsItem` на ссылку, `BreadcrumbsSeparator` с явной иконкой между ними и `BreadcrumbsPage` для
текущей страницы. Начинайте с него, если пунктам нужны ссылки роутера, дополнительная разметка или
разные разделители.

## Композиция

`Breadcrumbs` не владеет интерактивным состоянием или состоянием формы, поэтому у него нет управляемых свойств,
колбэков, хуков контекста или `RootProvider`. Состоянием свёрнутой цепочки управляет составной `Menu`, а навигация
роутера остаётся ответственностью компонента-ссылки приложения.

Используйте `BreadcrumbsPath` для цепочки с обычными ссылками. Он сам управляет дочерними элементами списка,
рендерит каждый элемент `links` как ссылку, рендерит `page` как текущую страницу и не принимает `children` или `asChild`. Если нужны ссылки роутера,
скрытые средние сегменты или другая разметка, используйте отдельные части. Для ссылки роутера передайте в
`BreadcrumbsLink asChild` один семантически корректный дочерний элемент, чтобы сохранить ожидаемые `href`, фокус и
клавиатурное поведение.

Для свёрнутой цепочки поместите `BreadcrumbsEllipsis` внутрь `MenuTrigger`, а части `Positioner`, `Content` и
`Item asChild` меню оставьте явными. `BreadcrumbsEllipsis` отвечает только за отображение; доступная метка и
взаимодействие принадлежат триггеру. Нативная `button`, которая напрямую оборачивает `BreadcrumbsEllipsis`,
получает стили триггера (сброс, курсор-указатель, цвет при наведении и кольцо фокуса), поэтому своих стилей ей не нужно.

## Стилизация

Используйте `className` в React или `class` в Solid и Vue на экспортируемых частях для структурных стилей. Варианты на
Tailwind используют нативные классы Tailwind и классы приложения; справочник CSS-переменных ниже относится к вариантам
с CSS Modules. Для стилей, зависящих от состояния, используйте атрибуты данных Ark вместе с селекторами `data-slot`
moduix.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `Breadcrumbs` | `breadcrumbs-root` |
| `BreadcrumbsList` | `breadcrumbs-list` |
| `BreadcrumbsItem` | `breadcrumbs-item` |
| `BreadcrumbsLink` | `breadcrumbs-link` |
| `BreadcrumbsPage` | `breadcrumbs-page` |
| `BreadcrumbsSeparator` | `breadcrumbs-separator` |
| `BreadcrumbsEllipsis` | `breadcrumbs-ellipsis` |

- В вариантах с CSS Modules `BreadcrumbsLink`, `BreadcrumbsPage` и `BreadcrumbsEllipsis` используют общий
  горизонтальный внутренний отступ `--moduix-breadcrumbs-item-padding-x`.
- Видимые элементы `BreadcrumbsItem` могут сжиматься, чтобы цепочка помещалась в одну строку. В вариантах с CSS
  Modules последний видимый элемент остаётся главной целью усечения и использует `--moduix-breadcrumbs-item-max-width`.
- Ссылки, разделители и многоточие наследуют цвет текста корня. Задайте `color` у `Breadcrumbs` (или
  `--moduix-breadcrumbs-color` в вариантах с CSS Modules), чтобы перекрасить всю цепочку; текущая страница сохраняет свой цвет.

## Справочник API

Пропсы `BreadcrumbsPath`. Отдельные части принимают нативные пропсы своих элементов.

| Проп | Тип | По умолчанию |
| --- | --- | --- |
| `links` | `readonly { href: string; label: ReactNode }[]` | — |
| `page` | `ReactNode` | — |
| `separator` | `ReactNode` | chevron |
