## Справочник API

Ark UI не предоставляет отдельный примитив для breadcrumbs. В moduix этот компонент собран с помощью официального
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory), а его [композиция](https://ark-ui.com/docs/guides/composition),
[стилизация](https://ark-ui.com/docs/guides/styling) и работа с [ref](https://ark-ui.com/docs/guides/ref) соответствуют
рекомендациям Ark.

## Базовый пример

Используйте `Breadcrumbs.Path`, если приложение уже знает, какую цепочку нужно показать. Компонент сам создаёт
упорядоченный список, элементы, ссылки, текущую страницу и разделители на основе небольшого массива `items`.

## Анатомия

`Breadcrumbs` предоставляет части компонента в пространстве имён в стиле Ark.

```text
Breadcrumbs / Breadcrumbs.Root
└─ Breadcrumbs.List
   ├─ Breadcrumbs.Item
   │  └─ Breadcrumbs.Link
   ├─ Breadcrumbs.Separator
   └─ Breadcrumbs.Item
      └─ Breadcrumbs.Page
```

| Часть                              | Роль                                                               |
| ---------------------------------- | ------------------------------------------------------------------ |
| `Breadcrumbs` / `Breadcrumbs.Root` | Корневая область навигации с `aria-label` по умолчанию.            |
| `Breadcrumbs.List`                 | Упорядоченный список сегментов цепочки.                            |
| `Breadcrumbs.Item`                 | Обёртка сегмента в списке.                                         |
| `Breadcrumbs.Link`                 | Стилизованная ссылка для сегментов, по которым можно перейти; поддерживает `asChild`. |
| `Breadcrumbs.Page`                 | Текст текущей страницы с `aria-current="page"`.                   |
| `Breadcrumbs.Separator`            | Визуальный разделитель без семантической нагрузки, скрытый от вспомогательных технологий. |
| `Breadcrumbs.Ellipsis`             | Компактный маркер для триггера меню со скрытыми сегментами.         |

`Breadcrumbs.Path` - сокращённый вариант от moduix. Он создаёт `Breadcrumbs.List`, `Breadcrumbs.Item`,
`Breadcrumbs.Link`, `Breadcrumbs.Page` и `Breadcrumbs.Separator` на основе массива `items`.

## Композиция

### Рекомендуемая композиция

Используйте `Breadcrumbs.Path` для простых цепочек из ссылок. Последний элемент становится текущей страницей.
Между элементами по умолчанию отображается шеврон, а `separator` заменяет его во всех видимых промежутках.
Сокращённый вариант сам создаёт дочерние элементы, поэтому не принимает `children` и `asChild`. Нативные свойства
упорядоченного списка и ref передаются созданному `Breadcrumbs.List`.

### Когда нужна собственная композиция

Используйте отдельные части, если нужны ссылки, которые предоставляет роутер приложения, скрытые средние сегменты или разная разметка для
конкретных элементов. С помощью Ark `asChild` можно подключить такую ссылку. Дочерним элементом должна быть одна
семантическая ссылка, которая сохраняет ожидаемые `href`, фокус и поведение клавиатуры.

Сочетайте Breadcrumbs с `Menu`, если средние сегменты нужно скрыть за триггером с многоточием. Структура меню должна
оставаться явной: `Menu.Positioner`, `Menu.Content` и `Menu.Item asChild`. За границу портала отвечает Menu.

### Свойства по умолчанию

| Поверхность                        | По умолчанию | Примечания                                             |
| ---------------------------------- | ------------ | ------------------------------------------------------ |
| `Breadcrumbs` / `Breadcrumbs.Root` | -            | Дополнительных поведенческих значений по умолчанию нет, применяются значения Ark. |
| `Breadcrumbs.Path`                 | шеврон       | Использует шевроны между элементами, если не задан `separator`. |

### Особенности поведения

- `Breadcrumbs` создаёт навигационный ориентир `nav`, а `aria-label` по умолчанию равен `"Breadcrumb"`.
- `Breadcrumbs.Path` формирует упорядоченный список из `items`; последний элемент всегда становится текущей страницей.
- `Breadcrumbs.Path` передаёт нативные свойства упорядоченного списка и ref, но сам создаёт дочерние элементы, поэтому
  не поддерживает `children` и `asChild`.
- `Breadcrumbs.Separator` служит только для оформления и скрыт от вспомогательных технологий.
- `Breadcrumbs.Ellipsis` скрыт от вспомогательных технологий, потому что доступная метка находится у триггера.
- Для свёрнутой цепочки задайте доступную метку на `Menu.Trigger`.
- При нехватке места любой видимый сегмент может сжиматься. Текущая страница остаётся основной целью усечения благодаря
  `--moduix-breadcrumbs-item-max-width`.
- У Breadcrumbs нет управляемых свойств, колбэков, хуков контекста, `RootProvider`, ids, `HiddenInput` или интеграций
  с состоянием формы, потому что компонент не управляет интерактивным состоянием и состоянием формы.

## Стилизация

Каждая экспортируемая часть содержит атрибуты `data-scope="breadcrumbs"` и `data-part` в стиле Ark, а также стабильный
хук moduix `data-slot`. Публичные переменные `--moduix-breadcrumbs-*` управляют расположением, стилями текста, кольцом
фокуса, разделителями и размером многоточия.

### Хуки стилизации

- `data-scope="breadcrumbs"` присутствует на каждой экспортируемой части.
- `data-part="root"`, `list`, `item`, `link`, `page`, `separator` и `ellipsis` следуют контракту Ark factory, который
  использует этот компонент.
- `data-slot="breadcrumbs-root"`, `breadcrumbs-list`, `breadcrumbs-item`, `breadcrumbs-link`, `breadcrumbs-page`,
  `breadcrumbs-separator` и `breadcrumbs-ellipsis` служат стабильными селекторами moduix.
- `Breadcrumbs.Link`, `Breadcrumbs.Page` и `Breadcrumbs.Ellipsis` используют общий горизонтальный внутренний отступ из
  `--moduix-breadcrumbs-item-padding-x`.
- Видимые части `Breadcrumbs.Item` могут сжиматься, чтобы цепочка помещалась в одну строку. Последняя видимая часть
  остаётся главной целью усечения и использует `--moduix-breadcrumbs-item-max-width`.
