## Справочник API

Ark UI не предоставляет отдельного примитива для Breadcrumbs. В moduix этот компонент собран с помощью официального
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилям](https://ark-ui.com/docs/guides/styling) и работе с
[ref](https://ark-ui.com/docs/guides/ref).

## Базовый пример


Используйте `BreadcrumbsPath`, если у вас уже есть список сегментов пути. На основе обязательных пропсов `links` и `page`
компонент создаёт упорядоченный список, элементы, ссылки, текущую страницу и разделители.

В React и Solid используются одинаковые плоские имена значений. Импортируйте `Breadcrumbs` как корень и импортируйте
каждую дополнительную часть напрямую, например `BreadcrumbsPath` и `BreadcrumbsLink`. Эти же имена работают и в пакетах
npm, и в исходниках реестра shadcn.

## Анатомия

```text
Breadcrumbs
└─ BreadcrumbsList
   ├─ BreadcrumbsItem
   │  └─ BreadcrumbsLink
   ├─ BreadcrumbsSeparator
   └─ BreadcrumbsItem
      └─ BreadcrumbsPage
```

| Часть                  | Назначение                                                       |
| ---------------------- | ---------------------------------------------------------------- |
| `Breadcrumbs`          | Область навигации с `aria-label` по умолчанию.                    |
| `BreadcrumbsList`      | Упорядоченный список сегментов пути.                              |
| `BreadcrumbsItem`      | Элемент списка, содержащий один сегмент.                          |
| `BreadcrumbsLink`      | Стилизованная ссылка для сегментов, по которым можно перейти; поддерживает `asChild`. |
| `BreadcrumbsPage`      | Текст текущей страницы с `aria-current="page"`.                  |
| `BreadcrumbsSeparator` | Визуальный разделитель, скрытый от вспомогательных технологий.   |
| `BreadcrumbsEllipsis`  | Компактный маркер для кнопки меню, открывающей скрытые сегменты.  |

`BreadcrumbsPath` - сокращённый API moduix. Он создаёт `BreadcrumbsList`, `BreadcrumbsItem`,
`BreadcrumbsLink`, `BreadcrumbsPage` и `BreadcrumbsSeparator` на основе пропсов `links` и `page`.

## Композиция

`Breadcrumbs` не владеет интерактивным состоянием или состоянием формы, поэтому у него нет управляемых свойств,
колбэков, хуков контекста или `RootProvider`. Состоянием свёрнутой цепочки управляет составной `Menu`, а навигация
роутера остаётся ответственностью компонента-ссылки приложения.

Используйте `BreadcrumbsPath` для цепочки с обычными ссылками. Он сам управляет дочерними элементами списка,
рендерит каждый элемент `links` как ссылку, рендерит `page` как текущую страницу и не принимает `children` или `asChild`. Если нужны ссылки роутера,
скрытые средние сегменты или другая разметка, используйте отдельные части. Для ссылки роутера передайте в
`BreadcrumbsLink asChild` один семантически корректный дочерний элемент, чтобы сохранить ожидаемые `href`, фокус и
клавиатурное поведение.

Для свёрнутой цепочки поместите `BreadcrumbsEllipsis` внутрь `MenuTrigger`, а части `Positioner`, `Content` и
`Item asChild` меню оставьте явными. `BreadcrumbsEllipsis` отвечает только за отображение; доступная метка и
взаимодействие принадлежат триггеру.

## Стилизация

Используйте `className` в React или `class` в Solid на экспортируемых частях для структурных стилей. Варианты на
Tailwind используют нативные классы Tailwind и классы приложения; справочник CSS-переменных ниже относится к вариантам
с CSS Modules. Для стилей, зависящих от состояния, используйте атрибуты данных Ark вместе с селекторами `data-slot`
moduix.

### CSS-свойства

<CssPropertiesSection properties={BreadcrumbsDocs.breadcrumbsCssProperties} />

### Хуки стилизации

- `data-slot="breadcrumbs-root"`, `breadcrumbs-list`, `breadcrumbs-item`, `breadcrumbs-link`, `breadcrumbs-page`,
  `breadcrumbs-separator` и `breadcrumbs-ellipsis` - стабильные селекторы moduix.
- В вариантах с CSS Modules `BreadcrumbsLink`, `BreadcrumbsPage` и `BreadcrumbsEllipsis` используют общий
  горизонтальный внутренний отступ `--moduix-breadcrumbs-item-padding-x`.
- Видимые элементы `BreadcrumbsItem` могут сжиматься, чтобы цепочка помещалась в одну строку. В вариантах с CSS
  Modules последний видимый элемент остаётся главной целью усечения и использует `--moduix-breadcrumbs-item-max-width`.
