## Справочник API

В Ark UI нет отдельного примитива split button. moduix собирает этот компонент с помощью официальной
[фабрики Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory), следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[работе с ref](https://ark-ui.com/docs/guides/ref), а поведение меню берёт из
[Ark Menu](https://ark-ui.com/docs/components/menu).

## Как выбрать компонент

Используйте `SplitButton`, когда одно действие должно быть доступно сразу, а связанные дополнительные действия
можно поместить в меню. Для одного действия подойдёт `Button`. Если все действия равнозначны, используйте `Menu`.

## Анатомия

```text
SplitButton
├─ SplitButton.Action
├─ SplitButton.Trigger
└─ Ветка всплывающего меню (по умолчанию в портале)
   └─ SplitButton.Positioner
      └─ SplitButton.Content
         ├─ Menu.Item
         ├─ Menu.Separator
         └─ другие общие части Menu
```

| Часть                             | Назначение                                                               |
| -------------------------------- | ------------------------------------------------------------------------ |
| `SplitButton`                    | Управляет состоянием меню Ark и объединяет две кнопки в семантическую группу. |
| `SplitButton.Action`             | Основная кнопка. По умолчанию получает корневые `variant` и `size`.     |
| `SplitButton.Trigger`            | Триггер меню Ark в виде кнопки moduix; без содержимого показывает шеврон. |
| `SplitButton.Positioner`         | Размещает всплывающее меню Ark и предоставляет его переменные позиционирования. |
| `SplitButton.Content`            | Контейнер содержимого меню Ark для общих частей `Menu.*`.               |

## Композиция

По умолчанию `SplitButton` помещает `Positioner` меню в портал. Установите `portalled={false}`, чтобы оставить меню
в текущем контейнере, или передайте `portalRef`, чтобы выбрать контейнер для портала. `Positioner` и `Content`
остаются явными и доступными для стилизации.

### Рекомендуемая композиция

`SplitButton` передаёт свойства `Menu.Root` от Ark, включая `open`, `defaultOpen`, `onOpenChange(details)`,
`onSelect(details)`, `closeOnSelect`, `positioning`, `ids`, `lazyMount`, `unmountOnExit` и `typeahead`.

Используйте `SplitButton.Action` для основного действия. Дополнительные действия размещайте в
`SplitButton.Content`, используя общие части `Menu.Item`, `Menu.Separator`, `Menu.ItemGroup`,
`Menu.CheckboxItem` и `Menu.RadioItem`.

### Когда нужна ручная настройка

Используйте `asChild` на `SplitButton.Action`, когда основное действие должно быть ссылкой или другим совместимым
элементом.

Передавайте собственное видимое содержимое через `children` у `SplitButton.Trigger`. Внутри триггера остаётся одна
встроенная кнопка `Button`, поэтому поведение триггера Ark Menu и стили moduix применяются к одному элементу.

Укажите `positioning` на `SplitButton`, чтобы управлять положением всплывающего меню. Оставляйте
`SplitButton.Positioner` и `SplitButton.Content` явными, если нужно настроить или стилизовать меню, не переписывая
компонент целиком.

Если нужен расширенный доступ к состоянию меню, используйте `Menu.RootProvider` и `useMenu()` из общего API `Menu`,
а не добавляйте отдельные обёртки состояния для split button.

### Свойства по умолчанию

| Компонент              | Свойство      | Значение по умолчанию                 | Примечание                                              |
| ---------------------- | ------------- | ------------------------------------- | ------------------------------------------------------- |
| `SplitButton`          | `variant`     | `'default'`                           | Общее значение для `Action` и `Trigger`.                |
| `SplitButton`          | `size`        | `'md'`                                | Общее значение для `Action` и `Trigger`.                |
| `SplitButton`          | `positioning` | `{ placement: 'bottom-end', gutter: 4 }` | Выравнивает меню по краю триггера.                      |
| `SplitButton`          | `aria-label`  | -                                     | Задаёт доступное имя группы связанных кнопок.           |
| `SplitButton`          | `aria-labelledby` | -                                  | Ссылается на элемент, который задаёт имя группы.        |
| `SplitButton.Trigger`  | `aria-label`  | `'More actions'` для одной иконки     | При необходимости замените на более точное имя.        |
| `SplitButton.Trigger`  | `children`    | `ChevronDownIcon`                     | Замените, если триггеру нужно своё видимое содержимое.  |

### Особенности поведения

- `SplitButton` выводит обе кнопки в контейнере с `role="group"`. Если окружающий текст не объясняет назначение
  группы, задайте ей доступное имя через `aria-label` или `aria-labelledby`.
- Все экспортируемые части, которые выводят DOM-элементы, передают `ref` на соответствующий элемент.
- `SplitButton.Action` следует общему контракту `asChild` компонента `Button` из moduix.
- `SplitButton.Trigger` выводит кнопку moduix как элемент триггера Ark Menu. Она сохраняет
  `data-slot="split-button-trigger"` и получает ARIA-атрибуты и атрибуты состояния Ark, включая `aria-expanded`,
  `aria-controls` и `data-state`. Собственное содержимое триггера передаётся через `children`, без второго слоя
  `asChild`.
- `SplitButton.Positioner` получает CSS-переменные Ark Menu, например `--reference-width`, `--available-height`,
  `--x`, `--y`, `--z-index` и `--transform-origin`.
- `lazyMount` и `unmountOnExit` сохраняют значения по умолчанию `Menu`: содержимое меню монтируется по необходимости
  и удаляется после анимации закрытия.
- Корневой `variant` не поддерживает вариант `link` у `Button`, поскольку составная группа ссылок не образует
  цельный элемент управления.
- Корневой `size` не поддерживает размеры кнопок только с иконкой, поскольку в обычном варианте основное действие
  должно иметь видимую подпись.

## Стилизация

Внешний вид `SplitButton` задают стили moduix `Button` и `Menu`, а дополнительные слоты отвечают за оформление
объединённых кнопок.

Разделитель между кнопками и горизонтальные внутренние отступы триггера настраиваются переменными
`--moduix-split-button-separator-*` и `--moduix-split-button-trigger-padding-x-*`. По умолчанию они используют
общие токены границ и отступов, поэтому пресеты плотности остаются согласованными с `Button`, а `Menu` продолжает
отвечать за стилизацию пунктов всплывающего меню.

### Селекторы для стилизации

- `data-scope="split-button"` и `data-part="root"` можно использовать для стилизации обёртки с `role="group"`.
- `data-slot="split-button-root"` можно использовать для стилизации обёртки группы.
- `data-slot="split-button-action"` можно использовать для стилизации стороны основного действия.
- `data-slot="split-button-trigger"` можно использовать для стилизации стороны триггера выпадающего меню.
- `data-slot="split-button-positioner"` можно использовать для стилизации обёртки `SplitButton.Positioner`.
- `data-slot="split-button-content"` можно использовать для стилизации поверхности содержимого Ark Menu.
- `SplitButton.Trigger` выводится через общий элемент `Button` и получает ARIA-атрибуты и атрибуты состояния триггера
  Ark Menu, включая `data-state="open" | "closed"`.
- `SplitButton.Content` получает атрибуты содержимого Ark Menu, включая `data-state`, `data-side`, `data-placement`,
  `data-nested` и `data-has-nested`.
