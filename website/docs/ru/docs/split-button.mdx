Используйте `<SplitButton>` как корневой компонент и оставляйте структуру меню явной:
`SplitButtonAction`, `SplitButtonTrigger`, `SplitButtonPositioner` и `SplitButtonContent`.
Основное действие использует тот же контракт `onClick`, что и `Button`.

## Как выбрать компонент

Используйте `SplitButton`, когда одно действие должно быть доступно сразу, а связанные альтернативы можно
поместить в меню. Для одного действия подойдёт `Button`. Если все действия равнозначны, используйте `Menu`.

## Композиция

`SplitButton` объединяет основное действие `SplitButtonAction` и `SplitButtonTrigger`. Оставляйте дерево всплывающего меню явным:
`SplitButtonPositioner` → `SplitButtonContent`, а общие части `MenuItem` и `MenuItemGroup` размещайте внутри `SplitButtonContent`. Позиционер автоматически
рендерится в портале; используйте `portalled={false}` или `portalRef`, только если меню должно находиться
в другом контейнере. Корневые `size` и `variant` задают значения по умолчанию для обеих кнопок. Корень
рендерит семантический `role="group"`; задайте `aria-label` или `aria-labelledby`, если окружающий
контекст ещё не идентифицирует группу.

По умолчанию состоянием меню управляет сам компонент. Передайте `open` и `onOpenChange(details)`, если состояние
должно принадлежать другой части приложения. Для расширенного доступа к состоянию используйте общий API `Menu`,
а не добавляйте отдельную обёртку состояния для split button. Используйте `SplitButtonAction asChild` для ссылки; собственное
содержимое триггера передавайте через `children`, чтобы триггер меню Ark и кнопка moduix оставались одним элементом.

В Vue используйте `@click` для основного действия, `@open-change` или `v-model:open` для состояния меню и стандартный слот для содержимого триггера.

`SplitButtonPositioner` оборачивает портал, поэтому `$el` его ссылки на компонент Vue указывает на узел-якорь портала. Сам позиционируемый элемент имеет атрибут `data-slot="split-button-positioner"`.

## Стилизация

Для структурных стилей передавайте экспортируемым частям `className` в React или `class` в Solid и Vue. Варианты на
Tailwind настраиваются обычными утилитами и пользовательскими классами; перечисленные ниже переменные относятся
к вариантам с CSS Modules. Атрибуты данных и хуки `data-slot` общие для обоих способов стилизации.

Объединённый вид создают общие стили `Button` и `Menu` вместе со слотами SplitButton. Залитые варианты рисуют
разделитель в `::before` триггера, у outline-вариантов его роль играет общая рамка. Цвет разделителя задаёт
`--moduix-split-button-separator-color`, а внутренние отступы триггера меняются классом на `SplitButtonTrigger`.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `SplitButton` | `split-button-root` |
| `SplitButtonAction` | `split-button-action` |
| `SplitButtonTrigger` | `split-button-trigger` |
| `SplitButtonPositioner` | `split-button-positioner` |
| `SplitButtonContent` | `split-button-content` |

- `data-scope="split-button"` и `data-part="root"` задают семантическую группу.
- `SplitButtonTrigger` получает атрибуты состояния Ark Menu, включая `aria-expanded`, `aria-controls` и `data-state`.
- `SplitButtonContent` получает атрибуты Ark Menu, включая `data-state`, `data-side`, `data-placement`,
  `data-nested` и `data-has-nested`.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `Tab` / `Shift+Tab` | Перемещает фокус между действием и кнопкой меню. |
| `Enter` / `Space` | Запускает действие или открывает меню с кнопки меню. |
| `ArrowDown` / `ArrowUp` | Открывает меню с кнопки меню и перемещает между пунктами. |
| `Escape` | Закрывает меню и возвращает фокус на кнопку меню. |
