Передайте коллекцию в `Select`, используйте `SelectField` для стандартного видимого поля и явно опишите структуру всплывающего окна. Свойство `clearLabel` добавляет доступную кнопку очистки. Явно добавьте `SelectHiddenSelect`, когда нужны нативная отправка, автозаполнение, валидация и сброс.

## Выбор подходящего компонента

Используйте `Select`, когда пользователю нужно выбрать значение из фиксированной коллекции, а
триггер нельзя редактировать. Если ввод текста помогает искать или создавать значение, используйте
`Combobox`.

## Композиция

`SelectField` объединяет `SelectControl`, `SelectTrigger`, `SelectValueText` и стандартный `SelectIndicator`. Передайте `clearLabel`, чтобы добавить подписанную кнопку очистки, или используйте явные части, когда разметку триггера нужно стилизовать независимо. Оставляйте `SelectPositioner`, `SelectContent` и элементы коллекции в одном дереве Select. Для обычных строк используйте `SelectOption`: он рендерит `SelectItem` с `SelectItemText` и `SelectItemIndicator`. Передайте `indicator={false}`, чтобы скрыть галочку, или иконку, чтобы её заменить, а для строк с особой структурой используйте `SelectItem`.

Явно добавьте `SelectHiddenSelect` внутрь `Select` или `SelectRootProvider`, если выбор должен участвовать в нативной отправке формы, валидации, автозаполнении или сбросе. Корневой компонент не создаёт его автоматически. `Positioner` по умолчанию размещается через портал: для рендера в обычном потоке укажите `portalled={false}`, а для собственного контейнера используйте `portalRef`.

Используйте `useSelect` вместе с `SelectRootProvider`, когда состояние нужно разделить с элементами за пределами дерева Select. В React возвращается объект, в Solid реактивный accessor, а во Vue ref.

## Стилизация

Стилизуйте Select через `className` в React, `class` в Solid и Vue, стабильные хуки `data-slot="select-*"` и атрибуты Ark. Варианты Tailwind используют нативные utility-классы и классы потребителя. Варианты CSS Modules оставляют пять переменных размеров, перечисленных ниже; цвета, границы, кольцо фокуса, отступы пунктов и анимация берутся из токенов foundation и общих переменных `--moduix-popup-*`, поэтому переопределяйте их классом на нужной части.

Его свойство `indicator` передаёт
дочерний элемент в существующий слот индикатора. `SelectOption` использует слоты пункта и не
добавляет собственный хук стилизации.

- Анатомия Ark использует `data-scope="select"` и `data-part`.
- Для состояний доступны `data-state="open" | "closed"`, `data-focus`, `data-invalid`,
  `data-disabled`, `data-readonly`, `data-required`, `data-placeholder-shown`,
  `data-highlighted`, а для элементов списка - `data-state="checked" | "unchecked"`.
- `SelectPositioner` предоставляет `--reference-width`, `--reference-height`, `--available-width`,
  `--available-height`, `--x`, `--y`, `--z-index` и `--transform-origin`.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `Enter` / `Space` / `ArrowDown` | Открывает список с кнопки. |
| `ArrowDown` / `ArrowUp` | Подсвечивает следующую или предыдущую опцию. |
| `Enter` | Выбирает подсвеченную опцию. |
| `Esc` | Закрывает список. |
| Буквы | Подсвечивает опцию, которая начинается с набранного текста. |
