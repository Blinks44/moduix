## Выбор подходящего компонента

Используйте `Select`, когда пользователю нужно выбрать значение из фиксированной коллекции, а
триггер нельзя редактировать. Если ввод текста помогает искать или создавать значение, используйте
`Combobox`.

## Анатомия

```text
Select
├─ SelectLabel
├─ SelectControl / SelectField
│  ├─ SelectTrigger
│  │  ├─ SelectValueText
│  ├─ SelectClearTrigger
│  └─ SelectIndicator
├─ Поддерево оверлея (портируется автоматически)
│  └─ SelectPositioner
│     └─ SelectContent
│        ├─ SelectList
│        └─ SelectItemGroup
│           ├─ SelectItemGroupLabel
│           └─ SelectItem[item]
│              ├─ SelectItemText
│              │  └─ SelectItemTextContent
│              │     ├─ SelectItemTextIcon
│              │     └─ SelectItemTextLabel
│              └─ SelectItemIndicator
└─ SelectHiddenSelect (явно)
```

| Часть                     | Назначение                                                               |
| ------------------------- | ------------------------------------------------------------------------ |
| `Select`                  | Корневое состояние, коллекция, выбор, жизненный цикл всплывающего окна и данные формы. |
| `SelectHiddenSelect`      | Нативное поле Ark; правила явной композиции описаны ниже.                       |
| `SelectRootProvider`      | Рендерит дерево Select на основе состояния, возвращённого `useSelect`.          |
| `SelectContext`           | Корневой контекст для чтения расширенного состояния.                             |
| `SelectItemContext`       | Контекст элемента для чтения расширенного состояния.                            |
| `SelectLabel`            | Доступная подпись, с которой связаны триггер и нативный элемент формы.   |
| `SelectControl`          | Обёртка видимого поля, которая отражает состояния фокуса, ошибки и открытого списка. |
| `SelectField`            | Вспомогательный компонент moduix для стандартного поля, триггера и действий. |
| `SelectTrigger`          | Кнопка, открывающая всплывающее окно и обрабатывающая ввод с клавиатуры. |
| `SelectValueText`        | Плейсхолдер или подписи выбранных элементов.                             |
| `SelectClearTrigger`     | Кнопка, очищающая текущее значение.                                     |
| `SelectIndicator`        | Индикатор триггера со стандартной иконкой стрелки moduix.               |
| `SelectPositioner`       | Плавающий слой, который предоставляет CSS-переменные Ark для позиционирования. |
| `SelectContent`           | Содержимое всплывающего окна и контейнер listbox.                       |
| `SelectList`              | Необязательная обёртка списка для виртуализации или собственной разметки. |
| `SelectItemGroup`         | Обёртка группы связанных элементов коллекции.                           |
| `SelectItemGroupLabel`   | Подпись группы коллекции.                                                |
| `SelectItem`              | Выбираемая строка. Передайте элемент коллекции через `item`.             |
| `SelectItemText`          | Текст для отображения и доступности.                                    |
| `SelectItemTextContent`   | Вспомогательный компонент для разметки сложного текста элемента.        |
| `SelectItemTextIcon`      | Обёртка для иконки в тексте элемента.                                   |
| `SelectItemTextLabel`     | Обёртка для подписи в тексте элемента.                                  |
| `SelectItemIndicator`     | Индикатор выбранного состояния со стандартной иконкой галочки moduix.    |

## Композиция

`SelectField` объединяет `SelectControl`, `SelectTrigger`, `SelectValueText` и стандартный `SelectIndicator`. Передайте `clearLabel`, чтобы добавить подписанную кнопку очистки, или используйте явные части, когда разметку триггера нужно стилизовать независимо. Оставляйте `SelectPositioner`, `SelectContent` и элементы коллекции в одном дереве Select.

Явно добавьте `SelectHiddenSelect` внутрь `Select` или `SelectRootProvider`, если выбор должен участвовать в нативной отправке формы, валидации, автозаполнении или сбросе. Корневой компонент не создаёт его автоматически. `Positioner` по умолчанию размещается через портал: для рендера в обычном потоке укажите `portalled={false}`, а для собственного контейнера используйте `portalRef`.

Используйте `useSelect` вместе с `SelectRootProvider`, когда состояние нужно разделить с элементами за пределами дерева Select. В React возвращается объект, а в Solid реактивный accessor.

## Стилизация

Стилизуйте Select через `className` в React или `class` в Solid, стабильные хуки `data-slot="select-*"`, атрибуты Ark и публичные CSS-переменные `--moduix-select-*`. Варианты Tailwind используют нативные utility-классы и классы потребителя, а варианты CSS Modules используют переменные, описанные ниже.

### Хуки стилизации

`SelectField` создаёт существующие слоты `select-control`, `select-trigger`, `select-value-text`,
`select-indicator` и необязательный `select-clear-trigger`. Его свойство `indicator` передаёт
дочерний элемент в существующий слот индикатора. Вспомогательные компоненты текста элемента
предоставляют слоты `select-item-text-content`, `select-item-text-icon` и `select-item-text-label`.

- Корни предоставляют `data-slot="select-root"` и `data-slot="select-root-provider"`.
- Анатомия Ark использует `data-scope="select"` и `data-part`.
- Для состояний доступны `data-state="open" | "closed"`, `data-focus`, `data-invalid`,
  `data-disabled`, `data-readonly`, `data-required`, `data-placeholder-shown`,
  `data-highlighted`, а для элементов списка - `data-state="checked" | "unchecked"`.
- `SelectPositioner` предоставляет `--reference-width`, `--reference-height`, `--available-width`,
  `--available-height`, `--x`, `--y`, `--z-index` и `--transform-origin`.
