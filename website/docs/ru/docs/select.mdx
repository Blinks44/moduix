## Выбор подходящего компонента

Используйте `Select`, когда пользователю нужно выбрать значение из фиксированной коллекции, а
триггер нельзя редактировать. Если ввод текста помогает искать или создавать значение, используйте
`Combobox`.

## Композиция

Корневой компонент автоматически размещает `Positioner` через портал. Укажите `portalled={false}`
для рендера без портала, а `portalRef` используйте для собственного контейнера. `Positioner` и
`Content` остаются явными и доступными для стилизации.

### Рекомендуемая композиция

`Select.Field` создаёт `Control`, `Trigger`, `ValueText` и стандартный индикатор. Передайте
`clearLabel`, чтобы добавить подписанную кнопку очистки, или `indicator={<Icon />}`, чтобы заменить
только иконку стрелки. Объявляйте `Positioner`, `Content` и элементы списка непосредственно в
композиции.

`Select` - краткая форма корневого компонента. `Select.Root` делает то же самое и доступен как
эквивалентный член пространства имён.

### Когда нужна собственная композиция

Соберите `Control`, `Trigger` и визуальные части вручную, если их нужно независимо компоновать и
стилизовать. `asChild` требует одного семантического контейнера, который может принять свойства Ark
и отрисовать дочерние элементы. Используйте `div` или `section`, а не
интерактивный элемент вроде `button`. `Select.List` пригодится для собственной обёртки списка и
виртуализации.

### Свойства по умолчанию

По умолчанию содержимое всплывающего окна монтируется только при первом открытии и удаляется после
анимации закрытия. Установите `unmountOnExit={false}`, чтобы сохранить его после первого открытия.
Устанавливайте оба свойства жизненного цикла в `false`, только если нужен немедленный начальный
рендеринг.

| Свойство                | По умолчанию | Примечания                                                        |
| ----------------------- | ------------ | ----------------------------------------------------------------- |
| `closeOnSelect`         | `true`       | Закрывает всплывающее окно после выбора элемента.                |
| `composite`             | `true`       | Включает клавиатурную навигацию по listbox.                      |
| `defaultValue`          | `[]`         | Массив строк, в том числе при одиночном выборе.                  |
| `lazyMount`             | `true`       | Откладывает монтирование содержимого до открытия.               |
| `loopFocus`             | `false`      | По умолчанию стрелочная навигация не переходит с конца в начало. |
| `multiple`              | `false`      | При включении разрешает выбирать несколько значений.             |
| `unmountOnExit`         | `true`       | Удаляет содержимое после анимации закрытия.                      |
| `ValueText.placeholder` | -            | Текст при пустом массиве значений.                               |

### Особенности поведения

`value` и `defaultValue` задаются массивами строк, в том числе при одиночном выборе. Колбэк
`onValueChange(details)` предоставляет выбранные ключи в `details.value`, а элементы коллекции - в
`details.items`. Колбэки `onOpenChange(details)`, `onHighlightChange(details)` и `onSelect(details)`
получают объекты details из Ark UI без изменений.

Используйте `Select.useSelect` вместе с `Select.RootProvider`, когда состояние нужно читать за
пределами дерева Select. Для чтения состояния внутри дерева доступны `Select.Context`,
`Select.ItemContext`, `Select.useSelectContext` и `Select.useSelectItemContext`. `Field.Root` и
`Fieldset.Root` передают через контекст Ark состояния `disabled`, `invalid`, `required` и
`read-only`.

`Select.HiddenSelect` сохраняет нативную валидацию браузера, автозаполнение, сброс формы и
прогрессивное улучшение. Для виртуализированной коллекции, где нежелательно рендерить все нативные
опции, реализуйте интеграцию с формой на уровне приложения.

Если пользователь включил уменьшение движения, Select отключает переходы триггера и анимацию
открытия и закрытия всплывающего окна. Выбор, возврат фокуса и жизненный цикл монтирования не
меняются.

атрибутов Ark и публичных CSS-переменных `--moduix-select-*`.

### Хуки стилизации

`Select.Field` создаёт существующие слоты `select-control`, `select-trigger`, `select-value-text`,
`select-indicator` и необязательный `select-clear-trigger`. Его свойство `indicator` передаёт
дочерний элемент в существующий слот индикатора. Вспомогательные компоненты текста элемента
предоставляют слоты `select-item-text-content`, `select-item-text-icon` и `select-item-text-label`.

- Корни предоставляют `data-slot="select-root"` и `data-slot="select-root-provider"`.
- Анатомия Ark использует `data-scope="select"` и `data-part`.
- Для состояний доступны `data-state="open" | "closed"`, `data-focus`, `data-invalid`,
  `data-disabled`, `data-readonly`, `data-required`, `data-placeholder-shown`,
  `data-highlighted`, а для элементов списка - `data-state="checked" | "unchecked"`.
- `Select.Positioner` предоставляет `--reference-width`, `--reference-height`, `--available-width`,
  `--available-height`, `--x`, `--y`, `--z-index` и `--transform-origin`.
