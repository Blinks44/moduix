## Использование

<Usage />

Передайте коллекцию в `Select`, используйте `SelectField` для стандартного видимого поля и явно опишите структуру всплывающего окна. Свойство `clearLabel` добавляет доступную кнопку очистки. Явно добавьте `SelectHiddenSelect`, когда нужны нативная отправка, автозаполнение, валидация и сброс.

## Выбор подходящего компонента

Используйте `Select`, когда пользователю нужно выбрать значение из фиксированной коллекции, а
триггер нельзя редактировать. Если ввод текста помогает искать или создавать значение, используйте
`Combobox`.

## Композиция

`SelectField` объединяет `SelectControl`, `SelectTrigger`, `SelectValueText` и стандартный `SelectIndicator`. Передайте `clearLabel`, чтобы добавить подписанную кнопку очистки, или используйте явные части, когда разметку триггера нужно стилизовать независимо. Оставляйте `SelectPositioner`, `SelectContent` и элементы коллекции в одном дереве Select. Для обычных строк используйте `SelectOption`: он рендерит `SelectItem` с `SelectItemText` и `SelectItemIndicator`. Передайте `indicator={false}`, чтобы скрыть галочку, или иконку, чтобы её заменить, а для строк с особой структурой используйте `SelectItem`.

Явно добавьте `SelectHiddenSelect` внутрь `Select` или `SelectRootProvider`, если выбор должен участвовать в нативной отправке формы, валидации, автозаполнении или сбросе. Корневой компонент не создаёт его автоматически. `Positioner` по умолчанию размещается через портал: для рендера в обычном потоке укажите `portalled={false}`, а для собственного контейнера используйте `portalRef`.

Используйте `useSelect` вместе с `SelectRootProvider`, когда состояние нужно разделить с элементами за пределами дерева Select. В React возвращается объект, в Solid реактивный accessor, во Vue ref, а в Svelte геттер.

## Стилизация

Стилизуйте Select через `className` (React) или `class` (Solid, Vue, Svelte), стабильные хуки `data-slot="select-*"` и атрибуты Ark. Варианты Tailwind используют нативные utility-классы и классы потребителя. Варианты CSS Modules оставляют пять переменных размеров, перечисленных ниже; цвета, границы, кольцо фокуса, отступы пунктов и анимация берутся из токенов foundation и общих переменных `--moduix-popup-*`, поэтому переопределяйте их классом на нужной части.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `Select` | `select-root` |
| `SelectRootProvider` | `select-root-provider` |
| `SelectLabel` | `select-label` |
| `SelectControl` | `select-control` |
| `SelectTrigger` | `select-trigger` |
| `SelectValueText` | `select-value-text` |
| `SelectClearTrigger` | `select-clear-trigger` |
| `SelectIndicator` | `select-indicator` |
| `SelectPositioner` | `select-positioner` |
| `SelectContent` | `select-content` |
| `SelectList` | `select-list` |
| `SelectItemGroup` | `select-item-group` |
| `SelectItemGroupLabel` | `select-item-group-label` |
| `SelectItem` | `select-item` |
| `SelectItemText` | `select-item-text` |
| `SelectItemIndicator` | `select-item-indicator` |

Его свойство `indicator` передаёт
дочерний элемент в существующий слот индикатора. `SelectOption` использует слоты пункта и не
добавляет собственный хук стилизации.

- Анатомия Ark использует `data-scope="select"` и `data-part`.
- Для состояний доступны `data-state="open" | "closed"`, `data-focus`, `data-invalid`,
  `data-disabled`, `data-readonly`, `data-required`, `data-placeholder-shown`,
  `data-highlighted`, а для элементов списка - `data-state="checked" | "unchecked"`.
- `SelectPositioner` предоставляет `--reference-width`, `--reference-height`, `--available-width`,
  `--available-height`, `--x`, `--y`, `--z-index` и `--transform-origin`.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `Enter` / `Space` / `ArrowDown` | Открывает список с кнопки. |
| `ArrowDown` / `ArrowUp` | Подсвечивает следующую или предыдущую опцию. |
| `Enter` | Выбирает подсвеченную опцию. |
| `Esc` | Закрывает список. |
| Буквы | Подсвечивает опцию, которая начинается с набранного текста. |

## Справочник API

| Проп | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `collection` | `ListCollection<T>` | — | Элементы из `createListCollection()`. |
| `value` | `string[]` | — | Выбранные значения в управляемом режиме. |
| `defaultValue` | `string[]` | — | Начальные значения, если выбор не управляется извне. |
| `onValueChange` | `(details: ValueChangeDetails) => void` | — | Вызывается при изменении выбранных значений. |
| `multiple` | `boolean` | `false` | Разрешает выбрать несколько значений. |
| `closeOnSelect` | `boolean` | `true` | Закрывает список после выбора элемента. |
| `deselectable` | `boolean` | `false` | Повторный клик по выбранному элементу снимает выбор. Только для одиночного выбора. |
| `loopFocus` | `boolean` | `false` | Навигация с клавиатуры переходит с последнего элемента на первый. |
| `positioning` | `PositioningOptions` | — | Расположение, отступ и другие настройки позиции списка. |
| `open` | `boolean` | — | Открыт ли список, в управляемом режиме. |
| `onOpenChange` | `(details: OpenChangeDetails) => void` | — | Вызывается при открытии и закрытии списка. |
| `lazyMount` | `boolean` | `true` | Монтирует содержимое списка при первом открытии. |
| `unmountOnExit` | `boolean` | `true` | Удаляет содержимое списка после закрытия. |
| `name` | `string` | — | Имя поля формы у скрытого нативного select. |
| `disabled` | `boolean` | `false` | Отключает выбор. |
| `readOnly` | `boolean` | `false` | Показывает значение, но не даёт его менять. |
| `invalid` | `boolean` | `false` | Помечает поле как невалидное. |
| `required` | `boolean` | `false` | Требует выбрать значение перед отправкой формы. |
| `translations` | `IntlTranslations` | — | Переведённые строки для подписей доступности. |
| `form` | `string` | — | Id формы, к которой относится скрытый select. |
| `autoComplete` | `string` | — | Подсказка автозаполнения браузера для скрытого select. |
| `onSelect` | `(details: SelectionDetails) => void` | — | Вызывается при выборе элемента. |
| `onHighlightChange` | `(details: HighlightChangeDetails<T>) => void` | — | Вызывается при смене подсвеченного элемента. |
| `highlightedValue` | `string \| null` | — | Подсвеченный элемент в управляемом режиме. |
| `defaultHighlightedValue` | `string \| null` | — | Элемент, подсвеченный при открытии списка. |
| `defaultOpen` | `boolean` | — | Начальное состояние открытия, если оно не управляется извне. |
| `scrollToIndexFn` | `(details: ScrollToIndexDetails) => void` | — | Прокручивает виртуализированный список к индексу элемента. |
| `composite` | `boolean` | `true` | Укажите `false`, если select находится внутри другого составного виджета, например вкладок. |
| `onPointerDownOutside` | `(event: PointerDownOutsideEvent) => void` | — | Вызывается при нажатии указателя вне списка. |
| `onFocusOutside` | `(event: FocusOutsideEvent) => void` | — | Вызывается, когда фокус уходит из списка. |
| `onInteractOutside` | `(event: InteractOutsideEvent) => void` | — | Вызывается при любом взаимодействии вне списка. |
