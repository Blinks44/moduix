Оберните в `<Typeset>` HTML, который уже подготовил ваш рендерер. Используйте `asChild`, только
когда внешний контейнер должен быть семантическим элементом, например `article` или `section`.
Оставьте списки обычными `<ul>` и `<ol>`: Typeset сам задаст их маркеры и интервалы без utility-
классов.

## Примеры

### Исключение элементов интерфейса

Исключите вложенный фрагмент, если у него свой визуальный стиль, например встроенный элемент
управления или карточка. И `.not-typeset`, и `data-not-typeset` исключают отмеченный элемент со всем
содержимым, включая вложенный корень `Typeset`.

<Example name="typeset/excluded-subtree" />

### Расширения Markdown

Списки задач, раскрывающиеся блоки `details`, списки определений и сноски GFM используют те же
токены и интервалы между блоками, что и основные HTML-элементы.

<Example name="typeset/markdown-extensions" />

### Ритм чтения

Настройте CSS-переменные, когда для раздела нужен более свободный или плотный ритм чтения без новых
свойств компонента.

<Example name="typeset/reading-rhythm" />

### Прокручиваемая таблица

Оберните таблицу, созданную вашим рендерером, в `TypesetScroll`, если она должна сохранить ширину и
прокручиваться в узком контейнере. Дайте области прокрутки доступное имя, которое описывает таблицу
внутри неё.

<Example name="typeset/scrollable-table" />

### Потоковое содержимое

Для потока сообщений используйте более плотный ритм. Каждый новый блок добавляет только свой
интервал, поэтому уже показанное содержимое остаётся на месте по мере роста потока.

## Композиция

`Typeset` задаёт единый ритм чтения семантическому HTML внутри своего контейнера. Он не разбирает и
не рендерит Markdown, не фильтрует небезопасный контент и не задаёт ширину текста. Всё это остаётся
за приложением.

В Vue используйте нативный атрибут `tabindex`, чтобы изменить порядок фокуса области прокрутки.
Отрендеренный элемент доступен через `$el` в ref компонента.

CSS-first контракт Typeset следует подходу из [документации shadcn/typeset](https://ui.shadcn.com/docs/typeset).
Как и там, ритм чтения задают три переменные, а рендеринг контента и его ширина остаются
ответственностью приложения. moduix добавляет нативные компоненты для React, Solid и Vue,
а также `TypesetScroll`.

`Typeset` не владеет состоянием, не разбирает и не фильтрует контент и не задаёт его размер.
Помещайте отрендеренные семантические элементы внутрь корня, используйте `asChild`, когда корень
должен быть `article` или `section`, и добавляйте `TypesetScroll` вокруг широкого блока, который
лучше прокручивать, чем сжимать. Держите `TypesetScroll` внутри границы `Typeset`:
интервалы потока и расширение таблиц для обёрнутого блока задают правила элементов Typeset. Если вложенный фрагмент принадлежит приложению и должен иметь свой
стиль, добавьте к нему `.not-typeset` или `data-not-typeset`. Пользовательская область прокрутки
должна иметь доступное имя, а `TypesetScroll` по умолчанию доступен для фокуса с клавиатуры.

## Стилизация

### CSS-переменные

Наведите на переменную или выберите её, чтобы увидеть её в превью.

<CssPropertiesSection properties={TypesetDocs.typesetOverrideCssProperties}>
  <AnatomyScene />
</CssPropertiesSection>

Ритм чтения задают `--moduix-typeset-size`, `--moduix-typeset-leading` и
`--moduix-typeset-flow`. Переменные шрифта необязательны, а цвета, границы и радиус берутся из
активной темы moduix. Правила элементов находятся в каскадном слое `components`, а дефолты
переменных - в слое `base`; они используют низкоспецифичные селекторы `:where()`, поэтому обычный CSS
приложения может переопределять отдельные элементы без `!important`.

Для структурных стилей используйте `className` в React и `class` в Solid и Vue. Варианты CSS Modules
и Tailwind поставляют один и тот же CSS Module; Tailwind объединяет классы через `cn`, оставляя
класс потребителя последним, поэтому шесть CSS-переменных работают в обоих вариантах.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `Typeset` | `typeset` |
| `TypesetScroll` | `typeset-scroll` |

- `[data-scope="typeset"][data-part="root"]` и `[data-part="scroll"]` дают стабильные хуки для
  частей компонента.
