## Справочник API

`Typeset` задаёт единый ритм чтения семантическому HTML внутри своего контейнера. Он не разбирает и
не рендерит Markdown, не фильтрует небезопасный контент и не задаёт ширину текста. Всё это остаётся
за приложением.

`Typeset` и `Typeset.Scroll` построены с помощью
[фабрики Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory), поэтому поддерживают
нативные свойства `div`, ref и композицию через `asChild`.

## Базовый пример

Оберните в `<Typeset>` HTML, который уже подготовил ваш рендерер. Используйте `asChild`, только
когда внешний контейнер должен быть семантическим элементом, например `article` или `section`.
Оставьте списки обычными `<ul>` и `<ol>`: Typeset сам задаст их маркеры и интервалы без utility-классов.

## Анатомия

```text
Typeset
└─ Typeset.Scroll (необязательно)
```

| Часть | Назначение |
| --- | --- |
| `Typeset` / `Typeset.Root` | Корневой контейнер, который стилизует семантические дочерние элементы. |
| `Typeset.Scroll` | Фокусируемая область с горизонтальной прокруткой для широкого отрендеренного блока. |

## Композиция

### Рекомендуемая композиция

Разбирайте Markdown, фильтруйте небезопасный контент, рендерьте его и задавайте ширину текста в
приложении. `Typeset` только оформляет дочерние элементы внутри корня и намеренно не имеет свойства
для ширины. Оберните широкую таблицу или другой блок в `Typeset.Scroll`, если его лучше прокручивать
по горизонтали.

### Когда нужна собственная композиция

Если части содержимого нужен свой визуальный стиль, используйте семантическую разметку напрямую, а
затем добавьте `.not-typeset` или `data-not-typeset`, чтобы исключить этот элемент и всё его
содержимое. Для каждой пользовательской области `Typeset.Scroll` укажите `aria-label` или
`aria-labelledby`. Если у области есть доступное имя, moduix добавит `role="region"`, если только вы
не задали другую роль. При необходимости можно передать и свой `tabIndex`.

### Свойства по умолчанию

| Часть | По умолчанию | Примечания |
| --- | --- | --- |
| `Typeset` | `div` | Используйте `asChild` ровно с одним семантическим дочерним элементом, чтобы отрендерить другой контейнер. |
| `Typeset.Scroll` | `div`, `tabIndex={0}` | Фокус по умолчанию позволяет прокручивать с клавиатуры широкую статическую таблицу. Укажите доступное имя для пользовательской области прокрутки, чтобы добавить ей `role="region"`. |

### Особенности поведения

Корневой `Typeset` не управляет состоянием, взаимодействием с клавиатуры, элементами формы и не
создаёт скрытых полей. У `Typeset.Scroll` по умолчанию есть фокус, поэтому браузер может прокручивать
широкий статический блок. Стили добавляют интервал перед отрендеренными блоками и не используют
`:last-child`, `:has()` и `:empty`, поэтому новые элементы потока не меняют разметку уже показанного
содержимого.

Ритм чтения задают `--moduix-typeset-size`, `--moduix-typeset-leading` и
`--moduix-typeset-flow`. Переменные шрифта необязательны, а цвета, границы и радиус берутся из
активной темы moduix. Правила элементов находятся в слое `moduix.components` и используют
низкоспецифичные селекторы `:where()`, поэтому обычный CSS приложения может переопределять отдельные
элементы без `!important`.

### Хуки стилизации

- `data-slot="typeset"` выбирает корневой контейнер.
- `data-slot="typeset-scroll"` выбирает необязательную обёртку переполнения и её состояние при фокусе.
- `[data-scope="typeset"][data-part="root"]` и `[data-part="scroll"]` дают стабильные хуки для
  частей компонента.
