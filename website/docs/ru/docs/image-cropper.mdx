## Анатомия

```tsx
<ImageCropper>
  <ImageCropper.Viewport>
    <ImageCropper.Image />
    <ImageCropper.CropArea />
  </ImageCropper.Viewport>
</ImageCropper>
```

| Часть                                | Назначение                                                                               |
| ------------------------------------ | ---------------------------------------------------------------------------------------- |
| `ImageCropper` / `ImageCropper.Root` | Корневой компонент, который хранит состояние кадрирования, преобразования, ARIA-метки и обновляемые во время работы CSS-переменные. |
| `ImageCropper.RootProvider`          | Корневой компонент, использующий экземпляр `useImageCropper`, созданный вне дерева компонентов.                              |
| `ImageCropper.Viewport`              | Область, в которой можно перемещать изображение; всё за её границами скрывается.                                            |
| `ImageCropper.Image`                 | Элемент изображения, к которому Ark применяет преобразования.                                                               |
| `ImageCropper.Selection`             | Область кадрирования, которая получает фокус и реагирует на клавиатуру.                                                     |
| `ImageCropper.Grid`                  | Горизонтальные или вертикальные линии сетки кадрирования.                                                                   |
| `ImageCropper.Handle`                | Маркер изменения размера для каждой позиции из `ImageCropper.handles`.                                                      |
| `ImageCropper.CropArea`              | Готовая область кадрирования с обеими сетками и всеми маркерами изменения размера.                                         |

## Композиция

### Рекомендуемая композиция

В большинстве случаев используйте `ImageCropper.CropArea`. Он сохраняет дерево частей Ark и избавляет от повторяющейся
разметки области кадрирования, сеток и маркеров. Передавайте `className`, `gridClassName` или `handleClassName`, чтобы
стилизовать эти части. `CropArea` сам создаёт дочернюю структуру, поэтому при другой структуре соберите компонент из
явных частей `Selection`, `Grid` и `Handle`. В этом случае не используйте для `CropArea` свойства `children` и `asChild`.

### Когда нужна собственная композиция

Используйте `ImageCropper.Context` для панели инструментов внутри корневого компонента. Если панели инструментов,
предварительному просмотру кадра или форме нужен API кадрирования за пределами дерева компонентов, создайте экземпляр
moduix `useImageCropper` и передайте его в `ImageCropper.RootProvider`. Для одного экземпляра состояния используйте
либо `Root`, либо `RootProvider`, но не оба компонента сразу.

### Свойства по умолчанию

| Свойство                | По умолчанию                             | Примечания                                                              |
| ----------------------- | ---------------------------------------- | ----------------------------------------------------------------------- |
| `cropShape`              | `"rectangle"`                            | Используйте `"circle"` для кадрирования аватаров.                       |
| `defaultZoom`            | `1`                                      | Начальный масштаб изображения.                                          |
| `defaultRotation`        | `0`                                      | Начальный поворот изображения в градусах.                               |
| `defaultFlip`            | `{ horizontal: false, vertical: false }` | Начальное состояние горизонтального и вертикального отражения.          |
| `minZoom`                | `1`                                      | Минимальный коэффициент масштабирования.                                |
| `maxZoom`                | `5`                                      | Максимальный коэффициент масштабирования.                               |
| `minWidth` / `minHeight` | `40`                                     | Минимальный размер области кадрирования.                                 |
| `fixedCropArea`          | `false`                                  | Закрепляет область: пользователь перемещает изображение под ней.         |

### Особенности поведения

Ark берёт на себя перетаскивание указателем, панорамирование, масштабирование колесом мыши и жестом, управление с клавиатуры,
генерацию идентификаторов, ARIA-метки и функции для получения результата кадрирования. Клавиши со стрелками перемещают
область кадрирования, `Alt` со стрелкой изменяет её размер, `Shift` и `Ctrl`/`Cmd` используют заданный шаг перемещения,
а `+` / `-` изменяют масштаб. В управляемом режиме обратные вызовы `onCropChange`, `onZoomChange`, `onRotationChange`
и `onFlipChange` получают объекты `details` от Ark.

### Селекторы для стилизации

Для стилизации используйте стабильные значения `data-slot`: `image-cropper-root`, `image-cropper-viewport`,
`image-cropper-image`, `image-cropper-selection`, `image-cropper-grid` и
`image-cropper-handle`. Ark также предоставляет `data-scope="image-cropper"`, значения `data-part`,
`data-fixed`, `data-shape`, `data-pinch`, `data-ready`, `data-disabled`, `data-measured`,
`data-dragging`, `data-panning`, `data-axis` и `data-position`.

Ark записывает в корневой элемент `--crop-width`, `--crop-height`, `--crop-x`, `--crop-y`, `--image-zoom`,
`--image-rotation`, `--image-offset-x` и `--image-offset-y`. Это значения только для чтения, которые можно использовать
для синхронизации собственного интерфейса. Не переопределяйте их, а для визуальной настройки используйте описанные выше
свойства `--moduix-image-cropper-*`.
