## Базовый пример

Используйте `ImageCropper` вместе с `Viewport`, `Image` и `CropArea`. Передайте URL изображения в
`ImageCropper.Image`. Компонент `CropArea` сам добавит область кадрирования, линии сетки и маркеры
изменения размера.

Если вы вызываете `getCroppedImage()` для изображения с другого домена, сервер изображения должен
разрешать CORS, а в `ImageCropper.Image` нужно передать `crossOrigin="anonymous"`. В примерах это
уже настроено для изображения с Unsplash.

## Анатомия

```tsx
<ImageCropper>
  <ImageCropper.Viewport>
    <ImageCropper.Image />
    <ImageCropper.CropArea />
  </ImageCropper.Viewport>
</ImageCropper>
```

| Часть                                | Назначение                                                                                  |
| ------------------------------------ | ------------------------------------------------------------------------------------------- |
| `ImageCropper` / `ImageCropper.Root` | Корневой компонент, который управляет состоянием кадрирования и преобразований, ARIA-атрибутами и CSS-переменными, обновляемыми во время работы. |
| `ImageCropper.RootProvider`          | Корневой компонент, связанный с экземпляром `useImageCropper`, созданным вне дерева компонентов. |
| `ImageCropper.Viewport`              | Область просмотра, в которой можно панорамировать изображение; всё за её границами скрывается. |
| `ImageCropper.Image`                 | Элемент изображения, к которому Ark применяет преобразования.                              |
| `ImageCropper.Selection`             | Фокусируемая область кадрирования и цель для управления с клавиатуры. При `fixedCropArea` она исключается из порядка перехода по Tab. |
| `ImageCropper.Grid`                  | Неинтерактивная горизонтальная или вертикальная линия сетки. Требуется `axis`.              |
| `ImageCropper.Handle`                | Маркер изменения размера для позиции из `ImageCropper.handles`. Требуется `position`.       |
| `ImageCropper.CropArea`              | Готовая область кадрирования с обеими сетками и всеми маркерами изменения размера. Не принимает `children` и `asChild`. |

## Композиция

### Рекомендуемая композиция

Для обычного сценария используйте `ImageCropper.CropArea`. Компонент сам выводит обе линии сетки и
все маркеры изменения размера, поэтому повторять эту разметку не нужно. Передавайте `className`,
`gridClassName` или `handleClassName`, чтобы стилизовать соответствующие части. `CropArea` сам
создаёт дочернюю структуру, поэтому не передавайте ему `children` и `asChild`.

### Когда нужна собственная композиция

Для элементов управления внутри корневого компонента используйте `ImageCropper.Context` или
`useImageCropperContext`. Если панели инструментов, предварительному просмотру или логике формы нужен
экземпляр компонента за пределами дерева компонентов, создайте его с помощью `useImageCropper` и
передайте в `ImageCropper.RootProvider`. Для одного экземпляра состояния используйте только один из
вариантов: `Root` или `RootProvider`.

### Свойства по умолчанию

| Свойство                | По умолчанию                             | Примечания                                                        |
| ----------------------- | ---------------------------------------- | ----------------------------------------------------------------- |
| `aspectRatio`           | не задано                                | Область кадрирования можно свободно изменять.                    |
| `cropShape`             | `"rectangle"`                            | Используйте `"circle"` для аватаров.                             |
| `initialCrop`           | вычисляется                              | Ark вычисляет начальную область по размеру области просмотра и соотношению сторон. |
| `defaultZoom`            | `1`                                      | Начальный масштаб изображения.                                   |
| `defaultRotation`        | `0`                                      | Начальный поворот изображения в градусах.                        |
| `defaultFlip`            | `{ horizontal: false, vertical: false }` | Начальное состояние горизонтального и вертикального отражения.   |
| `minZoom`               | `1`                                      | Минимальный коэффициент масштабирования.                         |
| `maxZoom`               | `5`                                      | Максимальный коэффициент масштабирования.                        |
| `minWidth` / `minHeight` | `40`                                   | Минимальный размер области кадрирования в пикселях.               |
| `maxWidth` / `maxHeight` | `Infinity`                             | Максимальный размер области кадрирования в пикселях.              |
| `nudgeStep`             | `1`                                      | Шаг перемещения области стрелками клавиатуры в пикселях.          |
| `nudgeStepShift`        | `10`                                     | Шаг перемещения при нажатой клавише `Shift`.                      |
| `nudgeStepCtrl`         | `50`                                     | Шаг перемещения при нажатой клавише `Ctrl` или `Cmd`.              |
| `fixedCropArea`         | `false`                                  | Фиксирует размер и положение области кадрирования.               |

### Особенности поведения

Компонент измеряет область кадрирования после загрузки изображения. Перетаскивайте маркеры, чтобы
изменить размер области, и изображение в области просмотра, чтобы панорамировать его. Клавиши со
стрелками перемещают область, `Alt` со стрелкой изменяет её размер, `Shift` и `Ctrl`/`Cmd` используют
соответствующие свойства шага перемещения, а `+` и `-` изменяют масштаб. При включённом
`fixedCropArea` область остаётся на месте, а пользователь панорамирует изображение в области просмотра.
Область исключается из порядка перехода по Tab.

Корневой компонент имеет роль `role="group"`, а интерактивная область кадрирования получает
`role="slider"`. Задайте корневому компоненту доступное имя через `aria-label` или настройте свойство
Ark `translations`. В управляемом режиме обратные вызовы `onCropChange`, `onZoomChange`,
`onRotationChange` и `onFlipChange` получают объекты `details` от Ark, например `details.crop`,
`details.zoom`, `details.rotation` и `details.flip`.

### Селекторы для стилизации

Для локальной стилизации используйте стабильные значения `data-slot`: `image-cropper-root`,
`image-cropper-root-provider`, `image-cropper-viewport`, `image-cropper-image`,
`image-cropper-selection`, `image-cropper-grid` и `image-cropper-handle`. Ark также предоставляет
`data-scope="image-cropper"`, `data-part` и атрибуты состояния на соответствующих частях, включая
`data-fixed`, `data-shape`, `data-pinch`, `data-ready`, `data-disabled`, `data-measured`,
`data-dragging`, `data-panning`, `data-axis` и `data-position`.

Ark записывает в корневой элемент `--crop-width`, `--crop-height`, `--crop-x`, `--crop-y`,
`--image-zoom`, `--image-rotation`, `--image-offset-x` и `--image-offset-y`. Это значения только
для чтения, отражающие текущее состояние и подходящие для синхронизации собственного
интерфейса. Не переопределяйте их. Для визуальной настройки используйте описанные выше свойства
`--moduix-image-cropper-*`.
