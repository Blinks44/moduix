## Базовый пример

Используйте `ImageCropper` вместе с `ImageCropperViewport`, `ImageCropperImage` и
`ImageCropperCropArea`. Передайте URL изображения в `ImageCropperImage`. Компонент
`ImageCropperCropArea` сам добавит область кадрирования, линии сетки и маркеры изменения размера.

<Example name="image-cropper/basic" />

Если вы вызываете `getCroppedImage()` для изображения с другого домена, сервер изображения должен
разрешать CORS, а в `ImageCropperImage` нужно передать `crossOrigin="anonymous"`. В примерах это
уже настроено для изображения с Unsplash.

## Анатомия

```tsx
<ImageCropper>
  <ImageCropperViewport>
    <ImageCropperImage />
    <ImageCropperCropArea />
  </ImageCropperViewport>
</ImageCropper>
```

| Часть                                | Назначение                                                                                  |
| ------------------------------------ | ------------------------------------------------------------------------------------------- |
| `ImageCropper`                    | Корневой компонент, который управляет состоянием кадрирования и преобразований, ARIA-атрибутами и CSS-переменными, обновляемыми во время работы. |
| `ImageCropperRootProvider`          | Корневой компонент, связанный с экземпляром `useImageCropper`, созданным вне дерева компонентов. |
| `ImageCropperViewport`              | Область просмотра, в которой можно панорамировать изображение; всё за её границами скрывается. |
| `ImageCropperImage`                 | Элемент изображения, к которому Ark применяет преобразования.                              |
| `ImageCropperSelection`             | Фокусируемая область кадрирования и цель для управления с клавиатуры. При `fixedCropArea` она остаётся в фокусе, а стрелки сдвигают изображение. |
| `ImageCropperGrid`                  | Неинтерактивная горизонтальная или вертикальная линия сетки. Требуется `axis`.              |
| `ImageCropperHandle`                | Маркер изменения размера для позиции из `ImageCropperHandles`. Требуется `position`.       |
| `ImageCropperCropArea`              | Готовая область кадрирования с обеими сетками и всеми маркерами изменения размера. Не принимает `children` и `asChild`. |

## Композиция

Используйте `ImageCropperCropArea` для стандартной области кадрирования. Она сама создаёт две сетки
и все маркеры изменения размера, поэтому не принимает `children` и `asChild`. Для стилизации
области и созданных частей используйте `className`, `gridClassName` и `handleClassName`.

Для элементов управления внутри корневого компонента используйте `ImageCropperContext`. Создайте
`useImageCropper()` и передайте его в `ImageCropperRootProvider`, если панели инструментов,
предварительному просмотру или логике формы нужен экземпляр кадрирования за пределами дерева
компонентов. Для одного экземпляра состояния выбирайте либо `ImageCropper`, либо
`ImageCropperRootProvider`. Примеры Vue используют нативные SFC с теми же частями, событиями и управляемым состоянием.

Используйте управляемые `zoom`, `rotation` или `flip` с соответствующим обратным вызовом, если
состоянием владеет другая часть приложения. Ark передаёт новое значение в объекте `details`.
`fixedCropArea` фиксирует область, а область просмотра становится поверхностью для панорамирования.

## Примеры

### Соотношение сторон

Задайте `aspectRatio`, чтобы сохранять фиксированное соотношение ширины и высоты области. Если
пользователь выбирает формат результата, меняйте это свойство из состояния React, Solid или Vue.

<Example name="image-cropper/aspect-ratio" />

### Круглое кадрирование

Используйте `cropShape="circle"` вместе с `aspectRatio={1}` для аватаров и изображений профиля.

<Example name="image-cropper/circle-crop" />

### Управляемый масштаб

Используйте управляемые `zoom` и `onZoomChange`, если кнопки или другая часть интерфейса должны
изменять или показывать текущий масштаб. Ограничьте диапазон с помощью `minZoom` и `maxZoom`.

<Example name="image-cropper/controlled-zoom" />

### Предварительный просмотр кадра

Вызовите `getCroppedImage()` у экземпляра `useImageCropper`, чтобы получить готовый результат.
С параметром `{ output: 'dataUrl' }` метод возвращает data URL, который можно передать в `src`
элемента `img`. Используйте `getCropData()`, если нужны только координаты кадрирования и данные
о преобразованиях.

<Example name="image-cropper/crop-preview" />

### События

Подпишитесь на `onCropChange` и `onZoomChange`, чтобы показывать текущие данные кадрирования или
синхронизировать их с другими элементами интерфейса.

<Example name="image-cropper/events" />

### Фиксированная область кадрирования

Включите `fixedCropArea`, если область кадрирования должна сохранять размер и положение, пока
пользователь панорамирует изображение под ней.

<Example name="image-cropper/fixed-crop-area" />

### Начальная область кадрирования

Передайте `initialCrop`, чтобы открыть компонент с заранее заданным прямоугольником кадрирования в
координатах области просмотра и пикселях.

<Example name="image-cropper/initial-crop" />

### Минимальный и максимальный размер

Ограничьте размер области кадрирования с помощью `minWidth`, `minHeight`, `maxWidth` и `maxHeight`.

<Example name="image-cropper/min-and-max-size" />

### Root Provider

Используйте `ImageCropperRootProvider` с экземпляром `useImageCropper`, если панель инструментов или
другой сценарий должны управлять кадрированием за пределами дерева его компонентов.

<Example name="image-cropper/root-provider" />

### Поворот, отражение и сброс

Используйте `ImageCropperContext`, чтобы подключить к панели инструментов действия масштабирования,
поворота, отражения и сброса. В этом примере состояние поворота и отражения контролируется из React, Solid или Vue.

<Example name="image-cropper/rotation-flip-and-reset" />

### Расширенная настройка

Замените `ImageCropperCropArea` на отдельные части `ImageCropperSelection`, `ImageCropperGrid` и
`ImageCropperHandle`, если области кадрирования нужна другая структура или собственные дочерние
элементы. Для `ImageCropperGrid` требуется `axis`, а для `ImageCropperHandle` требуется `position`.

<Example name="image-cropper/advanced-customization" />

## Стилизация

Корень шириной 32rem и сжимается вместе с контейнером. Область просмотра сохраняет пропорции 8:5 и
показывает шахматный фон там, где её не закрывает изображение. Изображение сохраняет собственные
пропорции: оно уменьшается до размеров области и остаётся по центру, поэтому кадр всегда совпадает с
видимыми пикселями.

Используйте `className` в React или `class` в Solid и Vue на экспортируемых частях. Варианты Tailwind
используют нативные утилиты и пользовательские классы. Варианты CSS Modules построены на токенах
foundation и не имеют переменных компонента: класс на части переопределяет стили компонента из слоя,
например другие `aspect-ratio` или `height` области просмотра. Data-атрибуты и значения `data-slot`
общие для обоих способов стилизации.

### Селекторы для стилизации

Для локальной стилизации используйте стабильные значения `data-slot`: `image-cropper-root`,
`image-cropper-root-provider`, `image-cropper-viewport`, `image-cropper-image`,
`image-cropper-selection`, `image-cropper-grid` и `image-cropper-handle`. Ark также предоставляет
`data-scope="image-cropper"`, `data-part` и атрибуты состояния на соответствующих частях, включая
`data-fixed`, `data-shape`, `data-pinch`, `data-ready`, `data-disabled`, `data-measured`,
`data-dragging`, `data-panning`, `data-axis` и `data-position`.

Ark записывает в корневой элемент `--crop-width`, `--crop-height`, `--crop-x`, `--crop-y`,
`--image-zoom`, `--image-rotation`, `--image-offset-x` и `--image-offset-y`. Это значения только
для чтения, отражающие текущее состояние и подходящие для синхронизации собственного
интерфейса. Не переопределяйте их.
