## Когда использовать

`LocaleProvider` задаёт локаль и направление текста для части приложения. Форматтеры Ark и примитивы, учитывающие
локаль, используют этот контекст для форматирования значений и выбора направления. Без провайдера Ark использует
`en-US` и направление слева направо (`ltr`).

moduix переэкспортирует провайдер и хук контекста из единой точки входа:

```tsx
import { LocaleProvider, useLocaleContext } from '@moduix/react/locale';
```

## Направление и язык документа

`LocaleProvider` вычисляет значение `dir` для Ark по локали, но не задаёт атрибуты документа. Для всего
локализованного приложения, особенно на языках с письмом справа налево, задавайте `lang` и `dir` на корневом
элементе документа.

```tsx
import type { ReactNode } from 'react';
import { LocaleProvider } from '@moduix/react/locale';

export function Document({ children }: { children: ReactNode }) {
  return (
    <html dir="rtl" lang="ar">
      <body>
        <LocaleProvider locale="ar-EG">{children}</LocaleProvider>
      </body>
    </html>
  );
}
```

Для небольшого участка интерфейса с другим направлением текста получите `dir` через `useLocaleContext` и задайте его
корневому элементу этого участка. Подробнее о компоновке, порталах и направленных иконках - в разделе
[справа налево (RTL)](/docs/rtl).

## Использование с moduix

Разместите `LocaleProvider` один раз вокруг части интерфейса с общей локалью. Утилиты `Format` и примитивы Ark,
учитывающие локаль, получат единый контекст.

`Format.Number`, `Format.Time` и другие утилиты `Format` по-прежнему импортируются из Ark. moduix предоставляет
компоненты интерфейса и переэкспортирует контекст локали, но не создаёт отдельный API для форматирования.

## Границы ответственности

Ark UI отвечает за определение локали, направления текста и API провайдера. moduix переэкспортирует
`LocaleProvider` и `useLocaleContext` из `@moduix/react/locale` через стабильную точку входа.
