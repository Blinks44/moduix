## Что делает `LocaleProvider`

`LocaleProvider` задаёт локаль и направление текста для части приложения. Форматтеры Ark и компоненты, учитывающие
локаль, читают этот контекст при форматировании значений и выборе направления. Без провайдера Ark использует
`en-US` и направление слева направо (`ltr`).

moduix переэкспортирует провайдер и хук контекста через отдельную публичную точку входа:

```tsx
import { LocaleProvider, useLocaleContext } from '@moduix/react/locale';
```

## Чтение контекста локали

`useLocaleContext` возвращает `locale` и `dir` из ближайшего провайдера. Используйте эти значения в собственном
контенте, если ему нужны та же локаль или то же направление текста, что и остальной части локализованной области.

## Язык и направление документа

`LocaleProvider` вычисляет направление для Ark на основе локали, но не меняет HTML-атрибуты документа. Если всё
приложение использует одну локаль, задайте соответствующие значения `lang` и `dir` на корневом элементе документа,
особенно для языка с письмом справа налево.

```tsx
import type { ReactNode } from 'react';
import { LocaleProvider } from '@moduix/react/locale';

export function Document({ children }: { children: ReactNode }) {
  return (
    <html dir="rtl" lang="ar">
      <body>
        <LocaleProvider locale="ar-EG">{children}</LocaleProvider>
      </body>
    </html>
  );
}
```

Для небольшого участка с другим направлением текста укажите на его корневом элементе нужный `lang` и значение `dir`,
полученное через `useLocaleContext`. Подробнее о компоновке, порталах и направленных иконках читайте в разделе
[«Справа налево» (RTL)](/docs/rtl).

## Использование с moduix

Оберните один раз `LocaleProvider` вокруг части интерфейса, в которой используется одна локаль. Утилиты `Format` и
примитивы Ark, учитывающие локаль, будут читать общий контекст.

`Format.Number`, `Format.Time` и другие утилиты `Format` по-прежнему импортируются из Ark UI. moduix предоставляет
компоненты интерфейса и переэкспортирует контекст локали, но не добавляет отдельный API форматирования.

## Границы ответственности

Ark UI отвечает за определение локали, направления текста и API провайдера. moduix переэкспортирует
`LocaleProvider` и `useLocaleContext` в публичном модуле `@moduix/react/locale`.
