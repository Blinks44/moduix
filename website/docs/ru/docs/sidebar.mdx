## Справочник API

`Sidebar` - компонент moduix для компоновки навигации приложения. Он объединяет навигационные
части с [Ark UI Splitter](https://ark-ui.com/docs/components/splitter), который отвечает за
изменение размера, сворачивание, работу с клавиатурой и доступность. Состояние и колбэки
соответствуют контракту `Splitter`.

<PrimitiveReference href="https://ark-ui.com/docs/components/splitter" />

## Выбор подходящего компонента

- Выбирайте **`Sidebar`**, если навигация должна менять ширину, сворачиваться в ряд иконок и
  располагаться рядом с основным содержимым.
- Выбирайте **`Splitter`**, если нужны обычные изменяемые по размеру панели, а не панель навигации
  и основная область содержимого.

`Sidebar` доступен для React и Solid во всех пакетах CSS Modules и Tailwind. Интерактивный пример

## Анатомия

```text
Sidebar / Sidebar.Root
├─ Sidebar.Panel[id="sidebar"]
│  ├─ Sidebar.Header
│  │  ├─ Sidebar.Label
│  │  └─ Sidebar.Input
│  ├─ Sidebar.Content
│  │  └─ Sidebar.Group
│  │     ├─ Sidebar.GroupLabel
│  │     ├─ Sidebar.GroupAction
│  │     └─ Sidebar.NavigationList
│  │        └─ Sidebar.NavigationItem
│  │           ├─ Sidebar.ExpandedContent
│  │           ├─ Sidebar.CollapsedContent
│  │           ├─ Sidebar.NavigationAction
│  │           ├─ Sidebar.NavigationBadge
│  │           └─ Sidebar.NavigationSubList
│  │              └─ Sidebar.NavigationSubItem
│  │                 └─ Sidebar.NavigationSubButton
│  └─ Sidebar.Footer
│     └─ Sidebar.Separator
├─ Sidebar.ResizeTrigger
├─ Sidebar.Trigger
└─ Sidebar.Inset[id="content"]
```

| Часть | Назначение |
| --- | --- |
| `Sidebar` / `Sidebar.Root` | Корень Ark Splitter с настройками для двух панелей. |
| `Sidebar.Panel` | Сворачиваемая панель навигации с id `"sidebar"` по умолчанию. |
| `Sidebar.Inset` | Основная область содержимого с id `"content"` по умолчанию. |
| `Sidebar.ResizeTrigger` | Доступная ручка изменения размера мышью и клавиатурой. |
| `Sidebar.Trigger` | Управление сворачиванием и разворачиванием панели. |
| `Sidebar.Header` | Непрокручиваемая верхняя область. |
| `Sidebar.Content` | Прокручиваемая центральная область. |
| `Sidebar.Footer` | Непрокручиваемая нижняя область. |
| `Sidebar.Group` | Семантическая секция навигации. |
| `Sidebar.NavigationButton` | Кнопка или ссылка через `asChild` с состояниями active и size. |
| `Sidebar.ExpandedContent` | Содержимое при развернутой панели. |
| `Sidebar.CollapsedContent` | Содержимое при свернутой панели. |
| `Sidebar.Tooltip` | Подпись для свернутого режима с учетом стороны панели. |
| `Sidebar.NavigationSubList` | Вложенный список навигации. |

## Композиция

`Sidebar` владеет состоянием раскладки Splitter, а вложенные `Collapsible`, всплывающие `Menu` и
`Sidebar.Tooltip` управляют каждый своим состоянием. Оставляйте `Panel`, `ResizeTrigger`, `Trigger`
и `Inset` прямыми потомками и располагайте их визуально: для левой панели сначала `Panel`, для
правой сначала `Inset`. `ExpandedContent` и `CollapsedContent` только переключают видимые ветки,
поэтому через них удобно сочетать обычные ссылки `Collapsible` и свернутое меню `Menu`, не перенося
состояние в Sidebar. Для сохранения ширины управляйте `size`, обновляйте его в `onResize(details)`
и сохраняйте итоговое значение в `onResizeEnd(details)`. В Solid `asChild` использует render-функцию,
получающую объединенные props.

## Стилизация

Каждая семантическая часть принимает `className` в React и `class` в Solid и предоставляет стабильный
хук `data-slot="sidebar-*"`. `Sidebar.Panel` добавляет `data-state="expanded"` или `"collapsed"`,
а части раскладки получают `data-side`. `NavigationButton` и `NavigationSubButton` получают
`data-active`, а `NavigationButton` также `data-size`.

В свернутом режиме подписи и названия групп визуально скрываются, но остаются доступны ассистивным
технологиям. Вложенные списки, поля, действия, бейджи и индикаторы скрываются, чтобы ряд иконок
оставался компактным. Отмечайте несамостоятельные SVG-якоря, например `Avatar` или логотип,
атрибутом `data-sidebar-icon`.

Ширина панелей является состоянием Ark, а не визуальным CSS. Переопределяйте `defaultSize` или
управляемый `size` для текущей ширины. Публичные переменные `--moduix-sidebar-*` отвечают за
внутренние отступы, размеры элементов, цвета и смещение триггера.

### Хуки стилизации

Части оболочки Sidebar также предоставляют `data-scope="sidebar"` и `data-part`. `Sidebar.Input` и
`Sidebar.Separator` сохраняют scope базовых примитивов, а части на базе Ark сохраняют атрибуты
состояния Splitter, включая `data-focus`, `data-dragging`, `data-disabled` и `data-orientation`.
