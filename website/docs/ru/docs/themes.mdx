# Темы

Темы moduix представляют собой слои CSS-токенов. `Calm` задаёт значения основы по умолчанию, а `Dense`,
`Soft` и `Contrast` предлагают дополнительные визуальные направления. Пресет может изменить
палитру, радиусы, интервалы, плотность элементов управления и тени, не меняя API компонентов и
не требуя провайдера или отдельного механизма для работы темы.
Все выпущенные адаптеры используют одинаковые файлы тем и общий контракт токенов.

## Выберите пресет

| Пресет   | Основной элемент / строка списка | Подойдёт для                                                                        |
| -------- | -------------------------------- | ----------------------------------------------------------------------------------- |
| Calm     | 36px / 32px                      | Большинства продуктовых интерфейсов с нейтральным ритмом и спокойными поверхностями. |
| Dense    | 34px / 30px                      | Админ-панелей и инструментов с большим объёмом данных, где важно уместить больше информации. |
| Soft     | 40px / 34px                      | Просторных или сенсорных сценариев с округлыми поверхностями и более тёплым акцентом. |
| Contrast | 36px / 32px                      | Интерфейсов, которым нужны чёткие границы и хорошо заметное отделение фокуса.       |

В таблице указана высота основных элементов управления и строк всплывающих списков для каждого
пресета. Используйте предпросмотр, чтобы сравнить плотность, поверхности и стили фокуса на настоящих
компонентах moduix.

Название пресета описывает визуальное направление, но не гарантирует доступность. Перед выпуском
проверьте на собственном контенте и с переопределениями приложения контраст текста, видимость
фокуса, масштабирование и размер интерактивных областей.

## Как работают слои

Базовый файл стилей задаёт полный контракт токенов и значения `Calm` по умолчанию. Пресет
переопределяет отдельные значения, а приложение затем может изменить только решения, относящиеся
к его продукту. Компоненты используют семантические и компонентные алиасы, поэтому изменение
палитры или плотности распространяется на связанные элементы управления, а не превращается в
набор разовых правил.

```text
foundation tokens → optional preset → application overrides → component aliases
```

Файлы пресетов содержат только свои переопределения, поэтому их легко изучить и удалить. В
разделе [Токены](/docs/tokens) перечислены переменные, которые входят в публичный набор для
темизации.

## Использование с npm-пакетом

Один раз импортируйте основу, затем нужный пресет. Если пользователь сможет переключаться между
несколькими пресетами, заранее загрузите CSS каждого из них. `Calm` использует значения основы,
поэтому отдельного файла `calm.css` нет.

Задайте `data-moduix-theme` и цветовую схему на `<html>`, чтобы они применялись к обычному содержимому
и компонентам в порталах. Для светлого режима `data-moduix-color-scheme` можно не указывать.

## Использование с реестром

Пресеты не зависят от фреймворка, поэтому один и тот же URL общего реестра подходит для React
и Solid с любым способом стилизации. CLI скопирует CSS-файл в проект:

<PackageManagerTabs command="shadcn@latest add https://moduix.dev/r/foundation/theme-dense.json" dlx />

```tsx
import '@/lib/moduix/styles/style.css';
import '@/lib/moduix/presets/dense.css';
```

```html
<html data-moduix-theme="dense"></html>
```

Замените `dense` на `soft` или `contrast`, чтобы использовать другой пресет. Если пользователь
может переключаться между пресетами, установите и импортируйте каждый доступный для выбора пресет.

При использовании Tailwind размещайте эти импорты перед `@import 'tailwindcss'`, как показано в
[настройке Tailwind-пакета](/docs/quick-start#tailwind-css). Сброс стилей moduix здесь
не нужен.

## Переключение тем во время выполнения

Переключение темы меняет только атрибут `data-moduix-theme`. Храните выбранное имя на элементе
документа, чтобы обычное содержимое и оверлеи, отрисованные через портал, получали одни и те же
токены. Сохраняйте имя, только если продукту нужно запоминать выбор пользователя.

```tsx
type Theme = 'calm' | 'dense' | 'soft' | 'contrast';

function setTheme(theme: Theme) {
  document.documentElement.dataset.moduixTheme = theme;
}
```

Значение `calm` оставляет значения основы без изменений. CSS каждого другого доступного пресета
должен быть загружен заранее. Если продукт запоминает выбор, сохраните его и примените до первого
отображения, чтобы при запуске не было заметной смены темы.

## Настройка пресета

Пресет представляет собой только слой CSS-переменных. Загрузите собственный файл стилей после пресета и
переопределите нужные значения. Семантические токены подходят для решений уровня всего продукта,
а алиасы компонентов используйте для осознанных исключений.

```css
[data-moduix-theme='soft'] {
  --moduix-primary: oklch(0.5 0.17 285);
  --moduix-radius: 0.875rem;
}
```

## Создание пользовательской темы

Если готовые пресеты не подходят, создайте файл стилей, который загружается после основы, и
используйте новое значение `data-moduix-theme`. Начните с токенов, определяющих визуальное
направление. Неуказанные токены сохранят значения основы. Добавляйте токены размеров или
интервалов, только если тема намеренно меняет плотность. Используйте пресет как ориентир, если
хотите полностью заменить палитру, интервалы и тени.
