# Темы

Темы представляют собой слои CSS-токенов. `Calm` используется по умолчанию, а `Dense`, `Soft` и
`Contrast` подключаются по желанию и меняют палитру, радиусы, отступы, плотность и тени без
изменения API компонентов.

<ThemePresets />

## Выберите пресет

Размеры показывают высоту основных элементов управления и строк всплывающих списков в каждом пресете.

| Пресет   | Элемент / строка списка | Подойдёт для                                                                      |
| -------- | ----------------------- | --------------------------------------------------------------------------------- |
| Calm     | 36px / 32px             | Обычных экранов приложения с нейтральными цветами и стандартными отступами.       |
| Dense    | 34px / 30px             | Админ-панелей и таблиц данных с компактными отступами и синими акцентами.         |
| Soft     | 40px / 34px             | Интерфейсов с крупными элементами, скруглёнными углами и фиолетовыми акцентами.   |
| Contrast | 36px / 32px             | Интерфейсов с более заметными границами и индикаторами фокуса.                    |

:::info Проверьте на своём контенте
Название пресета описывает визуальное направление, но не гарантирует доступность. Перед выпуском
проверьте контраст текста, видимость фокуса, масштабирование и размер интерактивных областей.
:::

## Как работают слои

Основа задаёт полный контракт токенов и значения `Calm`. Пресет переопределяет отдельные значения,
приложение меняет только свои решения, а компоненты читают получившиеся алиасы.

```text
foundation tokens → optional preset → application overrides → component aliases
```

## Использование с реестром

Пресеты используют общий реестр основы для всех фреймворков и способов стилизации. Установите
каждый пресет, который хотите предложить пользователям.

<PackageManagerTabs command="shadcn@latest add https://moduix.dev/r/foundation/theme-dense.json" dlx />

```tsx
import '@/lib/moduix/styles/style.css';
import '@/lib/moduix/presets/dense.css';
```

## Переключение тем во время выполнения

Сначала загрузите пресеты, между которыми можно выбирать. Применяйте выбор на `html`, чтобы
содержимое в порталах получало те же токены.

```ts
document.documentElement.dataset.moduixTheme = 'soft';
document.documentElement.dataset.moduixColorScheme = 'dark';
```

## Настройка пресета

Подключите переопределения продукта после пресета. Меняйте семантические токены для решений, общих
для нескольких компонентов.

```css
[data-moduix-theme='soft'] {
  --moduix-primary: oklch(0.5 0.17 285);
  --moduix-radius: 0.875rem;
}
```

## Создание пользовательской темы

Начните с основы и добавьте именованный слой CSS. Не указанные значения останутся такими же, как
в основе.

Чтобы подобрать значения визуально или перенести тему shadcn, откройте [конструктор темы](/docs/theme-builder).

```css
/* brand.css · подключается после основы */
[data-moduix-theme='brand'] {
  --moduix-primary: oklch(0.5 0.17 250);
  --moduix-radius: 0.75rem;
}

/* Примените на html: data-moduix-theme="brand" */
```
