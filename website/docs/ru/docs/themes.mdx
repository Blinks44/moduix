# Темы

Темы moduix — это обычные CSS-слои с токенами. `Calm` — сбалансированная основа, а `Dense`, `Soft` и `Contrast` —
варианты для других визуальных задач. Пресет может изменить палитру, радиусы, интервалы, плотность контролов и тени,
не затрагивая API компонентов и не добавляя рантайм темы.

## Выберите пресет

| Пресет | Контролы / строки списка | Лучше всего подойдёт для |
| --- | --- | --- |
| Calm | 36px / 32px | Большинства продуктовых интерфейсов с нейтральным ритмом и спокойными поверхностями. |
| Dense | 34px / 30px | Инструментов с большим объёмом данных, где важна плотность информации на экране. |
| Soft | 40px / 34px | Просторных интерфейсов или интерфейсов для сенсорного управления с более тёплым характером. |
| Contrast | 36px / 32px | Интерфейсов, где нужны более чёткие границы и заметное отделение фокуса. |

В демо используются реальные контролы moduix. Откройте Select и перемещайтесь по полям с клавиатуры, чтобы
сопоставить плотность триггеров, высоту строк списка, метки, поверхности и поведение фокуса. Названия пресетов
описывают визуальное направление, но не гарантируют доступность. Перед выпуском проверьте на собственном контенте
и с переопределениями приложения контраст текста, видимость фокуса, масштабирование и размер интерактивных областей.

## Как работают слои

Базовый файл стилей задаёт полный контракт токенов и значения `Calm` по умолчанию. Пресет выборочно меняет этот
контракт, а приложение затем переопределяет только решения, связанные с брендом. Компоненты используют семантические
и компонентные алиасы, поэтому изменение палитры или плотности распространяется на связанные контролы, а не
превращается в набор разовых правил.

```text
foundation tokens → optional preset → application overrides → component aliases
```

CSS каждого пресета остаётся небольшим, понятным и легко удаляется. В разделе [Токены](/docs/tokens) перечислены
переменные, которые входят в публичный набор для темизации.

## Использование с npm-пакетом

Сначала импортируйте основу, затем один пресет. Укажите `data-moduix-theme` на `<html>`, чтобы компоненты,
отрисованные через портал, наследовали те же токены. Для тёмной палитры moduix задайте на этом элементе
`data-moduix-color-scheme="dark"`.

```tsx
import '@moduix/react/style.css';
import '@moduix/react/presets/soft.css';
```

```html
<html data-moduix-theme="soft" data-moduix-color-scheme="dark"></html>
```

Вместо `soft.css` выберите один из этих путей:

```text
@moduix/react/presets/dense.css
@moduix/react/presets/contrast.css
```

## Использование с реестром

Установите один пресет с исходным кодом в проекте, затем импортируйте созданный CSS после базового файла стилей.

```bash
npx shadcn@latest add @moduix-react/theme-dense
```

```tsx
import '@/lib/moduix/styles/style.css';
import '@/lib/moduix/presets/dense.css';
```

```html
<html data-moduix-theme="dense"></html>
```

Замените `dense` на `soft` или `contrast`, чтобы использовать другой пресет.

## Переключение тем во время выполнения

Храните выбранную тему на элементе документа, чтобы обычное содержимое и оверлеи в портале получали одни и те же
токены. Сохраняйте её имя, только если продукту нужно запоминать этот выбор.

```tsx
function setTheme(theme: 'calm' | 'dense' | 'soft' | 'contrast') {
  document.documentElement.dataset.moduixTheme = theme;
  localStorage.setItem('moduix-theme', theme);
}
```

Примените сохранённое значение до отрисовки приложения, чтобы при запуске не было заметной смены темы.

## Настройка пресета

Пресет — это только слой CSS-переменных. Переопределите его в собственном файле стилей, который загружается после
пресета. Семантические токены меняйте для решений уровня системы, а алиасы компонентов — только для осознанных
исключений.

```css
[data-moduix-theme='soft'] {
  --moduix-primary: oklch(0.5 0.17 285);
  --moduix-radius: 0.875rem;
}
```

## Создание пользовательской темы

Создайте файл стилей, который загружается после основы, и укажите имя темы на `<html>`. Сначала задайте токены,
определяющие визуальное направление: неуказанные токены сохранят значения основы. Добавляйте токены размеров или
интервалов, только если тема намеренно меняет плотность. Используйте пресет как ориентир, если хотите заменить
палитру, интервалы и тени целиком.

```tsx
import '@moduix/react/style.css';
import './brand.css';
```

```css
/* brand.css */
[data-moduix-theme='brand'] {
  --moduix-background: oklch(0.98 0.01 260);
  --moduix-foreground: oklch(0.2 0.02 260);
  --moduix-card: oklch(1 0 0);
  --moduix-card-foreground: oklch(0.2 0.02 260);
  --moduix-primary: oklch(0.5 0.18 260);
  --moduix-primary-foreground: oklch(0.99 0.002 260);
  --moduix-border: oklch(0.86 0.02 260);
  --moduix-input: oklch(0.82 0.025 260);
  --moduix-ring: oklch(0.58 0.15 260);
  --moduix-radius: 0.875rem;
  --moduix-size-sm: 2rem;
  --moduix-size-md: 2.25rem;
}

[data-moduix-theme='brand'][data-moduix-color-scheme='dark'] {
  --moduix-background: oklch(0.17 0.02 260);
  --moduix-foreground: oklch(0.97 0.004 260);
  --moduix-card: oklch(0.22 0.024 260);
  --moduix-card-foreground: oklch(0.97 0.004 260);
  --moduix-primary: oklch(0.78 0.13 260);
  --moduix-primary-foreground: oklch(0.18 0.024 260);
  --moduix-border: oklch(0.76 0.03 260 / 0.28);
  --moduix-input: oklch(0.76 0.03 260 / 0.34);
  --moduix-ring: oklch(0.74 0.12 260);
}
```

```html
<html data-moduix-theme="brand" data-moduix-color-scheme="dark"></html>
```

Справочник системных токенов есть в разделе [Токены](/docs/tokens), а переключатель светлого и тёмного режима,
которым управляет приложение, описан в разделе [Тёмный режим](/docs/dark-mode).
