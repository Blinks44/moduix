# Менеджер загрузки файлов

Добавьте продуманную поверхность для вложений с перетаскиванием, нативным выбором файла, ограничениями файлов и понятной
обратной связью, когда файл не принят. Рецепт управляет только локальным списком: подключите собственную мутацию загрузки
там, где продукту нужно отправлять файлы на сервер.

## Подключение загрузки

`FileUpload` хранит выбранные файлы в локальном состоянии. Добавьте `onFileChange` к корневому элементу, когда
маршруту нужно передать `details.acceptedFiles` в действие формы или мутацию загрузки. Храните состояние прогресса
и завершения рядом с этим настоящим запросом, а не имитируйте его в рецепте.

Клиентская валидация улучшает обратную связь, но сервер должен повторно проверить тип, размер, содержимое и
авторизацию файла. Считайте выбранный `File` недоверенным входным значением.

| Состояние загрузки | Что показать пользователю |
| ------------------ | ------------------------- |
| Выбран | Имя файла, размер, действие удаления и явную загрузку или отправку формы. |
| Загружается | Прогресс, если он известен, подпись об ожидании и отключённую повторную отправку. |
| Ошибка | Сообщение сервера, когда его можно безопасно показать, а также действия повтора и удаления. |
| Завершено | Устойчивое состояние успеха с идентификатором сохранённого сервером файла. |

Если файлы загружаются сразу после выбора, сохраняйте назначенный приложением идентификатор каждого запроса, чтобы
повторная попытка обновляла ту же строку, а удаление одного файла не отменяло остальные.
