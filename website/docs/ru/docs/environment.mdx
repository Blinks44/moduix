`EnvironmentProvider` сообщает Ark UI, какой DOM-корень, `Document` и `Window` использовать для компонентов на базе Ark. Он нужен, когда дерево компонентов отображается не в основном документе страницы.

## Базовая настройка

Оберните провайдером всё поддерево, относящееся к нужному окружению. Без `value` провайдер определяет окружение, в котором отображается сам. Используйте `useEnvironmentContext`, если коду приложения нужны корневой узел, документ или окно.

В предпросмотре используется основной документ, поэтому провайдер автоматически находит `document`. В Solid `useEnvironmentContext()` возвращает accessor, поэтому сначала вызовите его, а затем обращайтесь к `getRootNode`, `getDocument` или `getWindow`.

## Использование собственного корневого узла

Передайте через `value` объект `Document`, `ShadowRoot` или другой корневой узел, которым управляет приложение. Провайдер не создаёт корневой узел, не переносит содержимое и не создаёт portal. Приложение само монтирует поддерево в нужный корень и передаёт тот же корень в `EnvironmentProvider`.

Используйте функциональную форму `value`, если корневой узел недоступен во время первого рендера, например пока загружается iframe или ещё не создан Shadow DOM.

Для этого примера нужны только API окружения Ark, `Button` из выбранного пакета moduix и API порталов фреймворка. Если фреймворк разделяет серверный и клиентский рендеринг, запускайте пример в клиентском компоненте:

## Iframe

Если вы используете `Frame` из Ark UI, размещайте вложенные компоненты прямо внутри него. `Frame` создаёт точку
монтирования iframe и передаёт его документ в Ark UI, поэтому дополнительный `EnvironmentProvider` не нужен. Настройка
стилей, жизненного цикла и безопасности iframe описана на странице [Frame](/docs/frame).
