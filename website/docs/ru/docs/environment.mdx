## Когда нужен `EnvironmentProvider`

Используйте `EnvironmentProvider`, если компонент отображается в другом DOM-окружении, а не в основном `document`
страницы. Например, в iframe, Shadow DOM или окне Electron. Ark UI использует это окружение, чтобы находить элементы
и идентификаторы, управлять фокусом и работать с нужным документом.

Импортируйте провайдер и его хук контекста напрямую из Ark UI:

```tsx
import { EnvironmentProvider, useEnvironmentContext } from '@ark-ui/react/environment';
```

## Базовая настройка

Оберните провайдером часть дерева React, которая отображается в нестандартном окружении. Если не передать `value`,
провайдер автоматически определит окружение, в котором он отображается. `useEnvironmentContext` возвращает функции
для доступа к этому корневому узлу, его `Document` и `Window`.

## Нестандартные корневые узлы

В `value` можно передать корневой узел напрямую или функцию, которая его возвращает. Функция пригодится, если узел
недоступен во время первого рендера, например пока загружается iframe или ещё не создан Shadow DOM.

```tsx
import { EnvironmentProvider } from '@ark-ui/react/environment';
import { Button } from '@moduix/react/button';
import { createPortal } from 'react-dom';
import { useEffect, useRef, useState } from 'react';

export function ShadowDomSettings() {
  const hostRef = useRef<HTMLDivElement>(null);
  const [shadowRoot, setShadowRoot] = useState<ShadowRoot | null>(null);

  useEffect(() => {
    const host = hostRef.current;
    if (!host) return;
    setShadowRoot(host.shadowRoot ?? host.attachShadow({ mode: 'open' }));
  }, []);

  return (
    <>
      <div ref={hostRef} />
      {shadowRoot
        ? createPortal(
            <EnvironmentProvider value={shadowRoot}>
              <Button type="button">Save settings</Button>
            </EnvironmentProvider>,
            shadowRoot,
          )
        : null}
    </>
  );
}
```

Провайдер только сообщает Ark UI, какой корневой узел использовать для работы с DOM. Он не переносит React-контент
в iframe или Shadow DOM. Точку монтирования и порталы по-прежнему настраивает приложение или библиотека для iframe.
Провайдер должен находиться в том же окружении, что и настраиваемое поддерево.

## Использование `Frame`

Компонент `Frame` из Ark отображает дочерние элементы внутри iframe и передаёт Ark UI `document` этого iframe.
Размещайте компоненты moduix прямо внутри `Frame`, дополнительный `EnvironmentProvider` не нужен:

```tsx
import { Frame } from '@ark-ui/react/frame';
import { Button } from '@moduix/react/button';

export function IframeAction() {
  return (
    <Frame title="Account settings">
      <Button type="button">Save settings</Button>
    </Frame>
  );
}
```

## Использование с moduix

Используйте компоненты moduix внутри `EnvironmentProvider` как обычно. Оберните всё поддерево один раз вместо того,
чтобы настраивать каждый компонент отдельно. Тогда Dialog, Menu, Popover и другие компоненты на базе Ark смогут
управлять фокусом и DOM-связями в правильном корневом узле.

Провайдер не подключает CSS в iframe или Shadow DOM. Подключите стили moduix и в это окружение, чтобы компоненты
сохранили свой внешний вид.

## Кто за что отвечает

`EnvironmentProvider` и `useEnvironmentContext` относятся к API Ark UI. moduix не переэкспортирует их. На этой
странице показано, как использовать их вместе с компонентами moduix; полный API смотрите в справочнике Ark UI.
