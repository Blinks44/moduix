## Анатомия

```text
Avatar.Root | Avatar.RootProvider
├─ Avatar.Fallback
└─ Avatar.Image
```

| Компонент                | Назначение                                                                |
| ------------------------ | ------------------------------------------------------------------------- |
| `Avatar` / `Avatar.Root` | Создаёт корневой элемент и хранит состояние аватара Ark UI.                         |
| `Avatar.RootProvider`    | Подключает состояние Ark UI, созданное за пределами дерева аватара.                 |
| `Avatar.Fallback`        | Показывает переданное потребителем содержимое, пока изображение не загрузится.       |
| `Avatar.Image`           | Показывает изображение после успешной загрузки.                                    |

## Композиция

### Рекомендуемая композиция

В обычном случае используйте `Avatar`. Вариант `Avatar.Root` пригодится, если нужен явный корневой компонент,
как в API Ark. `onStatusChange(details)` сообщает о состоянии загрузки, которым управляет Ark, а `ids`
позволяет задать стабильные идентификаторы для корневого элемента, изображения и резервного содержимого.
Все части DOM передают `ref` дальше и поддерживают свойство Ark `asChild`.

`Avatar.Image` создаёт обычный элемент `img`. Укажите содержательный текст `alt`, если изображение
помогает идентифицировать пользователя. Используйте `alt=""`, если окружающая ссылка или кнопка уже
имеет доступное имя.

Передавайте содержимое `Avatar.Fallback` явно. Это могут быть инициалы, иконка или другой компактный
маркер, подходящий для приложения-потребителя.

### Когда нужна своя композиция

Используйте `useAvatar` из `@moduix/react` вместе с `Avatar.RootProvider`, если состояние нужно создать
за пределами дерева аватара. Передайте это состояние в `Avatar.RootProvider`. Не оборачивайте один и тот
же экземпляр состояния в `Avatar.Root` и `Avatar.RootProvider` одновременно.

Для компонента изображения из фреймворка используйте `useAvatarContext()` из `@moduix/react` и сохраните
управление скрытым и видимым состоянием, которое предоставляет Ark. Более редкие API контекста и
псевдонимы типов Ark импортируйте напрямую из `@ark-ui/react/avatar`.

Используйте `asChild` с одним семантически подходящим дочерним элементом, если ссылка, кнопка или компонент
фреймворка должны управлять DOM-узлом соответствующей части.

### Свойства по умолчанию

| Компонент                                      | Свойство | Визуальное значение по умолчанию | Значения                      |
| ---------------------------------------------- | -------- | -------------------------------- | ----------------------------- |
| `Avatar` / `Avatar.Root`, `Avatar.RootProvider` | `size`   | `md`                             | `xs`, `sm`, `md`, `lg`, `xl`  |

Если `size` не указан, Avatar использует визуальные токены `md`, но не добавляет `data-size`. Передайте
`size="md"`, если селекторам нужен этот атрибут.

### Особенности поведения

- Ark управляет атрибутом `data-state="visible" | "hidden"` на `Avatar.Image` и `Avatar.Fallback`.
- `Avatar.Fallback` показывает только содержимое, переданное потребителем.
- `onStatusChange` получает объект с полем `details.status`, которое принимает значение `loaded` или `error`.
- Если изображения нет или его не удалось загрузить, резервное содержимое остаётся видимым.
- В `Avatar.RootProvider` нужно передать значение, которое возвращает `useAvatar`.
- `useAvatar` и `useAvatarContext` экспортируются из `@moduix/react`.
- `Avatar.Context` также экспортируется из `@moduix/react`. Псевдонимы типов Ark остаются доступны из `@ark-ui/react/avatar`.
- moduix добавляет только визуальные настройки по умолчанию, стабильные атрибуты `data-slot`, CSS-переменные и `size`.

## Стилизация

Для изменения внешнего вида используйте `className` и CSS-переменные moduix. Используйте атрибуты `data-*`,
которые задаёт Ark, если стиль зависит от состояния изображения.

### CSS-свойства

<CssPropertiesSection properties={AvatarDocs.avatarCssProperties} />

### Хуки стилизации

- `data-slot="avatar-root"`, `avatar-root-provider`, `avatar-image` и `avatar-fallback`.
- Атрибуты анатомии Ark: `data-scope="avatar"` и
  `data-part="root" | "image" | "fallback"`.
- Состояние изображения, которым управляет Ark: `data-state="visible" | "hidden"` на `Avatar.Image` и
  `Avatar.Fallback`.
- Атрибут размера moduix: `data-size="xs" | "sm" | "md" | "lg" | "xl"` на
  `Avatar.Root` и `Avatar.RootProvider`, когда передан `size`.
