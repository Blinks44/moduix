## Анатомия

```text
Avatar.Root | Avatar.RootProvider
├─ Avatar.Fallback
└─ Avatar.Image
```

| Компонент                | Назначение                                                                |
| ------------------------ | ------------------------------------------------------------------------- |
| `Avatar` / `Avatar.Root` | Создаёт и хранит состояние аватара Ark UI.                                |
| `Avatar.RootProvider`    | Отображает аватар на основе состояния Ark UI, созданного вне компонента.   |
| `Avatar.Fallback`        | Показывает инициалы, иконку или другое содержимое до загрузки изображения. |
| `Avatar.Image`           | Показывает изображение после успешной загрузки.                            |

## Композиция

### Рекомендуемая композиция

В обычном случае используйте `Avatar`. `Avatar.Root` остаётся доступен, если вам нужно явно обращаться
к пространству имён, соответствующему Ark. `onStatusChange(details)` сообщает о состоянии загрузки, которым
управляет Ark, а `ids` задаёт стабильные идентификаторы для корневого элемента, изображения и резервного
содержимого. Все DOM-части пробрасывают `ref` и поддерживают Ark `asChild`.

`Avatar.Image` создаёт элемент `img`, поэтому укажите содержательный текст `alt`, если изображение
идентифицирует пользователя. Используйте `alt=""`, если окружающая ссылка или кнопка уже задаёт доступное имя.

В распространённом случае `Avatar.Fallback name="Alex T."` берёт первую графему первого и последнего
слова из `name`. Поэтому инициалы корректно работают с именами на разных языках и эмодзи. Передайте
дочерние элементы, если нужно пользовательское резервное содержимое. Явные дочерние элементы имеют
приоритет над `name`.

### Когда нужно изменить композицию

Используйте `useAvatar` из `@moduix/react` вместе с `Avatar.RootProvider`, если состояние нужно создать
отдельно от самого аватара. Не используйте `Avatar.Root` и `Avatar.RootProvider` одновременно для одного
экземпляра состояния.

Для компонента изображения из фреймворка используйте `useAvatarContext()` из `@moduix/react` и сохраните
логику Ark, которая управляет скрытым и видимым состоянием. Более специфичные API контекста и псевдонимы
типов Ark импортируйте напрямую из `@ark-ui/react/avatar`.

Используйте `asChild` с одним семантическим дочерним элементом, если ссылка, кнопка или компонент фреймворка
должны управлять DOM-узлом части.

### Свойства по умолчанию

| Компонент                                      | Свойство | Визуальное значение по умолчанию | Значения                      |
| ---------------------------------------------- | -------- | -------------------------------- | ----------------------------- |
| `Avatar` / `Avatar.Root`, `Avatar.RootProvider` | `size`   | `md`                             | `xs`, `sm`, `md`, `lg`, `xl`  |

Если `size` не указан, Avatar использует визуальные токены `md`, но не добавляет `data-size`. Передайте
`size="md"`, если селекторам нужен этот атрибут.

### Особенности поведения

- Ark управляет атрибутом `data-state="visible" | "hidden"` на `Avatar.Image` и `Avatar.Fallback`.
- `Avatar.Fallback` строит инициалы по первой Unicode-графеме первого и последнего слова `name`,
  только если дочерние элементы не переданы.
- `Avatar.Fallback` показывает встроенную декоративную иконку пользователя, если дочерних элементов нет
  и из `name` нельзя получить инициалы.
- `onStatusChange` получает объект с деталями. Текущее состояние находится в `details.status`.
- Если изображения нет или его не удалось загрузить, резервное содержимое остаётся видимым.
- В `Avatar.RootProvider` нужно передать значение, которое возвращает `useAvatar`.
- `useAvatar` и `useAvatarContext` экспортируются из `@moduix/react`.
- `Avatar.Context` также экспортируется из `@moduix/react`. Псевдонимы типов Ark остаются доступны из `@ark-ui/react/avatar`.
- moduix добавляет только визуальные значения по умолчанию, стабильные атрибуты `data-slot`, CSS-переменные и `size`.

## Стилизация

Для изменения внешнего вида используйте `className` и CSS-переменные moduix. Используйте атрибуты `data-*`,
которые задаёт Ark, если стиль зависит от состояния изображения.

### CSS-свойства

<CssPropertiesSection properties={AvatarDocs.avatarCssProperties} />

### Хуки стилизации

- `data-slot="avatar-root"`, `avatar-root-provider`, `avatar-image`, `avatar-fallback` и
  `avatar-fallback-icon`.
- Атрибуты анатомии Ark: `data-scope="avatar"` и
  `data-part="root" | "image" | "fallback"`.
- Состояние изображения, которым управляет Ark: `data-state="visible" | "hidden"` на `Avatar.Image` и
  `Avatar.Fallback`.
- Атрибут размера moduix: `data-size="xs" | "sm" | "md" | "lg" | "xl"` на
  `Avatar.Root` и `Avatar.RootProvider`, когда передан `size`.
