## Базовый пример

Avatar доступен для React и Solid в вариантах с CSS Modules и Tailwind. Предпросмотр на этой странице
использует пакет React с CSS Modules, а во вкладках показан нативный код для обоих фреймворков с тем
же публичным контрактом.

Используйте вместе `Avatar`, `Avatar.Fallback` и `Avatar.Image`. Не убирайте `Avatar.Fallback` из
дерева, чтобы Ark UI мог переключаться между ним и изображением при изменении состояния загрузки.

## Анатомия

```text
Avatar.Root | Avatar.RootProvider
├─ Avatar.Fallback
└─ Avatar.Image
```

| Часть                    | Назначение                                                             |
| ------------------------ | ---------------------------------------------------------------------- |
| `Avatar` / `Avatar.Root` | Создаёт корневой элемент и хранит состояние аватара Ark UI.            |
| `Avatar.RootProvider`    | Подключает состояние Ark UI, созданное за пределами компонента.        |
| `Avatar.Fallback`        | Показывает переданное потребителем содержимое до загрузки изображения.  |
| `Avatar.Image`           | Показывает изображение после успешной загрузки.                        |

## Композиция

Размещайте `Avatar.Fallback` и `Avatar.Image` внутри одного корневого компонента, чтобы Ark мог
переключать их видимость. Если состояние должно принадлежать другой части приложения, создайте его
с помощью `useAvatar()` из пакета нужного фреймворка и напрямую передайте в `Avatar.RootProvider`;
не добавляйте для того же хранилища ещё один корневой компонент. В React хранилище передаётся как
объект, а в Solid — через реактивную функцию доступа. Для пользовательского рендера изображения используйте
`useAvatarContext()` и сохраняйте состояния `hidden` и `visible`, которые возвращает
`getImageProps()`. Применяйте `asChild` только с одним семантически подходящим дочерним элементом,
если другой элемент должен владеть корневым DOM-узлом.

## Стилизация

Для структурных стилей используйте `className` в React или `class` в Solid на экспортируемых частях.
Варианты Tailwind используют обычные утилитарные классы и классы потребителя; приведённый ниже список
CSS-переменных относится к вариантам с CSS Modules. Если стиль зависит от состояния изображения,
используйте атрибуты данных Ark вместе с селекторами `data-slot` moduix.

### CSS-свойства

<CssPropertiesSection properties={AvatarDocs.avatarCssProperties} />

### Хуки стилизации

- `data-slot="avatar-root"`, `avatar-root-provider`, `avatar-image` и `avatar-fallback`.
- Атрибуты анатомии Ark: `data-scope="avatar"` и
  `data-part="root" | "image" | "fallback"`.
- Состояние изображения Ark: `data-state="visible" | "hidden"` на `Avatar.Image` и
  `Avatar.Fallback`.
- Состояние размера moduix: `data-size="xs" | "sm" | "md" | "lg" | "xl"` на
  `Avatar.Root` и `Avatar.RootProvider`, если передан `size`.
