## Справочник API

В Ark UI нет отдельного примитива для группировки поля ввода. moduix собирает этот компонент с помощью официальной
[фабрики Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory), следуя рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[работе с ref](https://ark-ui.com/docs/guides/ref).

## Выбор подходящего компонента

- Выберите **`Input`** для обычного однострочного поля.
- Выберите **`InputGroup`** для встроенных префиксов, суффиксов, текста или действий.
- Выберите **`Editable`** для текста, который сначала отображается только для чтения, а затем переходит в режим редактирования.
- Выберите **`PasswordInput`** для готовой композиции, которая управляет видимостью пароля.
- Выберите **`NumberInput`**, если поле должно работать с числовыми значениями.

## Анатомия

```text
InputGroup / InputGroup.Root
├─ InputGroup.Addon (optional)
├─ InputGroup.Input
├─ InputGroup.Text (optional)
└─ InputGroup.Button (optional)
```

| Часть                            | Назначение                                                          |
| -------------------------------- | ------------------------------------------------------------------- |
| `InputGroup` / `InputGroup.Root` | Корневой элемент фабрики Ark, который отвечает за структуру, границу, фокус и размер группы. |
| `InputGroup.Input`               | Нативное поле ввода на основе Ark, которое хранит значение формы.                         |
| `InputGroup.Addon`               | Префикс или суффикс с заливкой.                                                            |
| `InputGroup.Text`                | Встроенный текст без заливки.                                                              |
| `InputGroup.Button`              | Нативная кнопка действия с общим оформлением группы.                                       |

## Композиция

### Рекомендуемая композиция

Используйте ровно один `InputGroup.Input`. Размещайте перед ним или после него дополнения, текст и кнопки. Если полю
нужны метка, поясняющий текст, сообщение об ошибке, идентификаторы или общее состояние, поместите группу внутрь `Field`.

`InputGroup.Input` использует нативные события элемента input. Для управления его значением передавайте `value` и
`onChange(event)`. Размер, заданный у корневого элемента, автоматически получают поле ввода и кнопка.

### Когда нужна нестандартная композиция

`InputGroup`, `InputGroup.Addon` и `InputGroup.Text` поддерживают `asChild` из Ark. Дочерний элемент корня должен
быть контейнером. Элементы, переданные в `InputGroup.Addon` и `InputGroup.Text`, должны оставаться декоративными и принимать переданные
свойства и ref.

Для действий используйте `InputGroup.Button`, а не превращайте дополнительный элемент в интерактивный. Добавляйте
`role="group"` и доступное имя только тогда, когда сама группа должна иметь семантику группы.

### Свойства по умолчанию

| Часть / свойство            | По умолчанию          |
| --------------------------- | --------------------- |
| `InputGroup.size`           | `md`                  |
| `InputGroup.Input.size`     | наследуется от корня  |
| `InputGroup.Button.size`    | наследуется от корня  |
| `InputGroup.Button.variant` | `ghost`               |
| `InputGroup.Button.type`    | `button`              |

### Особенности поведения

- `ref` поля ввода указывает на настоящий `HTMLInputElement`.
- Корневой элемент не управляет значением и валидацией, не задаёт ARIA-идентификаторы, не предоставляет хуки контекста
  и не рендерит `HiddenInput`.
- Оформление корневого элемента для состояний `invalid`, `disabled` и `readOnly` определяется состоянием вложенного поля.

### Точки стилизации

- `data-slot="input-group-root"` и `data-size`
- `data-scope="input-group"` и `data-part="root" | "addon" | "text"` на частях фабрики Ark
- `data-slot="input-root"` вместе с атрибутами состояния поля Ark
- `data-slot="input-group-addon"`
- `data-slot="input-group-text"`
- `data-slot="input-group-button"` у кнопки действия в группе
- вложенные состояния `data-invalid`, `aria-invalid`, `disabled` и `readOnly` через `:has(...)` на корневом элементе

Точки стилизации `data-slot`, `data-scope`, `data-part` и `data-size`, которые задаёт компонент, остаются неизменными,
даже если вы передаёте собственные свойства. `className` объединяется со стилями компонента.
