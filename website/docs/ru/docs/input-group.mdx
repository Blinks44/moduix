Интерактивное

Используйте `InputGroup` как корневой компонент и добавляйте к единственному
`InputGroupInput` только необходимые части `InputGroupAddon`, `InputGroupText` или `InputGroupButton`.

## Какой компонент выбрать

- Используйте **`Input`** для обычного однострочного поля.
- Используйте **`InputGroup`**, если в поле нужно разместить префикс, суффикс или действие.
- Используйте **`PasswordInput`** для поля пароля с переключателем видимости.
- Используйте **`NumberInput`** для числового поля с шагом изменения.
- Используйте **`Textarea`** для многострочного текста.
- Используйте **`Editable`**, если текст сначала должен отображаться как значение, а затем переходить в режим редактирования.

## Примеры

### Отключённое состояние

Передайте `disabled` нативному полю. Связанные кнопки отключайте отдельно, если они тоже должны
быть недоступны.

<Example name="input-group/disabled" />

### Состояние поля

Задайте `invalid` у `Field`, если проверка не пройдена. Ark передаст это состояние и нужные
ARIA-атрибуты в `InputGroupInput`, а группа отразит состояние поля.

<Example name="input-group/field-state" />

### Префикс и суффикс

Используйте `InputGroupAddon` для префикса или суффикса с заливкой, а `InputGroupText` - для встроенного текста без заливки.

<Example name="input-group/prefix-and-suffix" />

### Размеры

Задайте `size` один раз у корневого элемента, чтобы поле, дополнение, текст и кнопка оставались выровнены.

<Example name="input-group/sizes" />

### С действием

Используйте `InputGroupButton` для действия, связанного со значением поля. В этом примере поле
управляемое, а кнопка `Send` становится доступной только после ввода значения.

<Example name="input-group/with-action" />

### Многострочное поле

Используйте `InputGroupTextarea` для многострочного ввода, например в форме сообщения. Он рендерит
`Textarea` moduix без собственной рамки, наследует размер группы, если не задан свой `size`, и
сохраняет состояние Ark Field и `autoresize`. Панель действий добавляется через `InputGroupAddon align="block"`
с обычным `Button`.

<Example name="input-group/textarea" />

### Кнопка очистки

Используйте `InputGroupClearTrigger` для очистки поля: у кнопки уже есть крестик и доступная подпись.
Она наследует размер группы и по умолчанию использует `type="button"`. Очистку значения и возврат
фокуса задайте в `onClick` (в Vue используйте `@click`), а кнопку показывайте только при непустом значении.
Автоматической очистки и скрытия нет. Для отключённого поля или поля только для чтения отключайте
кнопку отдельно. Передайте `aria-label` на нужном языке или `aria-labelledby`; дочернее содержимое
заменяет стандартную иконку.
Компактная область наведения оформлена так же, как кнопки очистки в Select и Combobox.

<Example name="input-group/clear-trigger" />

### Расширенная настройка

Используйте `asChild`, если вместо стандартного `div` нужен собственный контейнер. Группа сохранит
оформление и контекст размера, а дочерний элемент должен остаться семантическим контейнером для разметки.

## Композиция

`InputGroup` является композицией moduix, а не отдельным примитивом Ark UI. Он объединяет элементы
фабрики Ark с компонентами moduix `Input` и `Button`, построенными на Ark. Композиция
соответствует рекомендациям Ark по [композиции](https://ark-ui.com/docs/guides/composition),
[стилизации](https://ark-ui.com/docs/guides/styling) и [работе с ref](https://ark-ui.com/docs/guides/ref).

В каждой группе оставляйте ровно один `InputGroupInput`. Вложенное поле отвечает за значение,
поведение формы, состояние валидации и `ref`, поэтому управляемые и неуправляемые свойства
задавайте на нём, а метку и сообщения валидации размещайте в `Field`. Размер корневого элемента
наследуют `InputGroupInput` и `InputGroupButton`; для кнопок по умолчанию используется
`type="button"`, но состояние `disabled` от `Field` они не наследуют. В React для управляемого
поля используйте `onChange`, в Solid - `onInput`, а в Vue - `v-model`.

Используйте `InputGroupAddon` и `InputGroupText` для неинтерактивного содержимого, а `InputGroupButton` - для действий. Корень,
`InputGroupAddon` и `InputGroupText` поддерживают `asChild` с одним семантическим дочерним элементом, принимающим
объединённые свойства и `ref`. Используйте `Editable`, если значение должно переключаться между
режимами просмотра и редактирования.

Задайте `align="block"` у `InputGroupAddon` или `InputGroupText`, чтобы разместить его строкой
на всю ширину над контролом или под ним, а не сбоку; положение определяется порядком в DOM.
Группа с block-аддоном содержит один контрол и только block-аддоны, поэтому боковое содержимое
кладите внутрь block-аддона. Используйте там обычный `Button`: `InputGroupButton` растягивается на
всю высоту группы и предназначен для действий рядом с контролом.

## Стилизация

Для структурных стилей передавайте экспортируемым частям `className` в React или `class` в Solid и Vue.
Состояния лучше оформлять через атрибуты данных Ark, например `data-invalid`, `data-disabled` и
`data-readonly`, вместе с селекторами `data-slot` moduix. Варианты на Tailwind настраиваются
обычными утилитами и пользовательскими классами. Варианты с CSS Modules построены на токенах
foundation и открывают только три переменные ниже; цвета, отступы и типографику меняйте обычным
классом на части — он сильнее слоёв стилей компонента. Атрибуты данных и селекторы `data-slot`
общие для обоих подходов.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `InputGroup` | `input-group-root` |
| `InputGroupAddon` | `input-group-addon` |
| `InputGroupText` | `input-group-text` |
| `InputGroupButton` | `input-group-button` |
| `InputGroupClearTrigger` | `input-group-clear-trigger` |

- `data-slot="input-group-root"` и `data-size="xs" | "sm" | "md" | "lg" | "xl"` на корне
- `data-scope="input-group"` и `data-part="root" | "addon" | "text"` на частях фабрики Ark
- `data-slot="input-root"` вместе с атрибутами состояния поля Ark
- `data-align="inline" | "block"` у `InputGroupAddon` и `InputGroupText`
- `data-slot="textarea-root"` и атрибуты состояния Ark Field textarea у `InputGroupTextarea`
- вложенные состояния `data-invalid`, `aria-invalid="true"` и `data-disabled`/`:disabled` отражаются на корне через `:has(...)`

Слоты и атрибуты `data-slot`, `data-scope`, `data-part` и `data-size`, которыми управляет
компонент, остаются неизменными, даже если вы передаёте собственные свойства. `className` в React
и `class` в Solid и Vue объединяются со стилями компонента.

## Справочник API

Пропсы `InputGroup`. `InputGroupAddon` принимает `align` (`'inline' | 'block'`, по умолчанию `'inline'`).

| Проп | Тип | По умолчанию |
| --- | --- | --- |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` |
| `asChild` | `boolean` | `false` |
