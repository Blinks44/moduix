## Справочник API

`InputGroup` является композицией moduix, а не отдельным примитивом Ark UI. Он объединяет элементы
фабрики Ark с компонентами moduix `Input` и `Button`, построенными на Ark. Композиция
соответствует рекомендациям Ark по [композиции](https://ark-ui.com/docs/guides/composition),
[стилизации](https://ark-ui.com/docs/guides/styling) и [работе с ref](https://ark-ui.com/docs/guides/ref).

## Выбор подходящего компонента

- Используйте **`Input`** для обычного однострочного поля.
- Используйте **`InputGroup`**, если в поле нужно разместить префикс, суффикс или действие.
- Используйте **`PasswordInput`** для поля пароля с переключателем видимости.
- Используйте **`NumberInput`** для числового поля с шагом изменения.
- Используйте **`Textarea`** для многострочного текста.
- Используйте **`Editable`**, если текст сначала должен отображаться как значение, а затем переходить в режим редактирования.

## Анатомия

```text
InputGroup / InputGroup.Root
├─ InputGroup.Addon (optional)
├─ InputGroup.Input
├─ InputGroup.Text (optional)
└─ InputGroup.Button (optional)
```

| Часть                            | Назначение                                                   |
| -------------------------------- | ------------------------------------------------------------ |
| `InputGroup` / `InputGroup.Root` | Общая разметка, граница, кольцо фокуса и контекст размера.   |
| `InputGroup.Input`               | Нативный `<input>`, который содержит значение формы.        |
| `InputGroup.Addon`               | Префикс или суффикс с заливкой.                              |
| `InputGroup.Text`                | Встроенный текст без заливки.                                |
| `InputGroup.Button`              | Кнопка действия, связанного с полем.                        |

## Композиция

### Рекомендуемая композиция

Используйте ровно один `InputGroup.Input`. Размещайте `Addon`, `Text` или `Button` перед полем или
после него. Поместите группу в `Field`, если полю нужны метка, поясняющий текст, сообщение об
ошибке, сгенерированные идентификаторы или общее состояние.

`InputGroup.Input` остается нативным полем. Для управляемого поля передавайте `value` и обновляйте
его в `onChange(event)`. Для неуправляемого поля используйте `defaultValue`. Размер, заданный у
корневого элемента, наследуют `InputGroup.Input` и `InputGroup.Button`; остальные части
подстраиваются под ту же визуальную плотность.

### Когда нужна нестандартная композиция

Корневой элемент, `InputGroup.Addon` и `InputGroup.Text` поддерживают `asChild` из Ark. При
использовании этой опции передавайте ровно один дочерний элемент. Дочерний элемент корня должен
оставаться семантическим контейнером для разметки. Дочерний элемент `Addon` или `Text` должен
оставаться декоративным и принимать переданные свойства и ref.

Для действий используйте `InputGroup.Button`, а не делайте `Addon` интерактивным.
Добавляйте `role="group"` и доступное имя только тогда, когда автономная композиция должна
объявляться группой.

### Свойства по умолчанию

| Часть / свойство            | По умолчанию          |
| --------------------------- | --------------------- |
| `InputGroup.size`           | `md`                  |
| `InputGroup.Input.size`     | наследуется от корня  |
| `InputGroup.Button.size`    | наследуется от корня  |
| `InputGroup.Button.variant` | `ghost`               |
| `InputGroup.Button.type`    | `button`              |

### Особенности поведения

- `ref` у `InputGroup.Input` указывает на настоящий `HTMLInputElement`.
- Корневой элемент служит пассивным контейнером. Он не управляет значением и валидацией, не генерирует ARIA-идентификаторы, не предоставляет хуки контекста и не рендерит `HiddenInput`.
- Оформление корня для состояний `invalid`, `disabled` и `readOnly` определяется состоянием вложенного поля.
- Кнопки не наследуют `disabled` от `Field`. Если действие должно быть недоступно, отключайте каждую кнопку отдельно.

### Хуки стилизации

- `data-slot="input-group-root"` и `data-size="xs" | "sm" | "md" | "lg" | "xl"` на корне
- `data-scope="input-group"` и `data-part="root" | "addon" | "text"` на частях фабрики Ark
- `data-slot="input-root"` вместе с атрибутами состояния поля Ark
- `data-slot="input-group-addon"`
- `data-slot="input-group-text"`
- `data-slot="input-group-button"` у кнопки действия в группе
- вложенные состояния `data-invalid`, `aria-invalid="true"`, `data-disabled`/`:disabled` и `data-readonly`/`:read-only` отражаются на корне через `:has(...)`

Слоты и атрибуты `data-slot`, `data-scope`, `data-part` и `data-size`, которыми управляет
компонент, остаются неизменными, даже если вы передаёте собственные свойства. `className` всегда
объединяется со стилями компонента.
