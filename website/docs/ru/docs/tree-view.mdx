## Анатомия

```text
TreeView / TreeView.Root
├─ TreeView.Label
└─ TreeView.Tree
   └─ TreeView.Node или TreeView.NodeProvider
      ├─ TreeView.Branch
      │  ├─ TreeView.BranchControl
      │  │  ├─ TreeView.BranchIndicator
      │  │  └─ TreeView.BranchText
      │  └─ TreeView.BranchContent
      │     ├─ TreeView.BranchIndentGuide
      │     └─ вложенные узлы
      └─ TreeView.Item
         └─ TreeView.ItemText
```

| Часть | Роль |
| --- | --- |
| `TreeView` / `TreeView.Root` | Управляет коллекцией, выбором, раскрытием, фокусом, отметками и переименованием. |
| `TreeView.RootProvider` | Подключает части к экземпляру `useTreeView`. |
| `TreeView.Label` | Задаёт дереву доступное имя. |
| `TreeView.Tree` | Контейнер ARIA-дерева. |
| `TreeView.Node` | Удобный provider с `{ node, indexPath, state }`. |
| `TreeView.NodeProvider` | Низкоуровневая граница контекста Ark для пользовательской композиции. |
| `TreeView.Branch*` | Раскрываемый узел, триггер, индикатор, метка и потомки. |
| `TreeView.Item*` | Конечный элемент дерева и необязательный индикатор выбранного состояния. |
| `TreeView.NodeCheckbox*` | Элемент управления дерева с флажками и индикатор отмеченного или промежуточного состояния. |
| `TreeView.NodeRenameInput` | Встроенное поле ввода, отображаемое при переименовании узла. |

## Композиция

### Рекомендуемый путь

Используйте `TreeView.Node` для обычных рекурсивных рендереров. Его колбэк рендеринга получает текущие `node`, `indexPath` и состояние узла Ark `state`, поэтому может выбирать разметку ветви или элемента без отдельного компонента контекста. `NodeProvider` остаётся доступным, когда пользовательскому дереву компонентов нужен прямой контроль.

### Выделенный триггер раскрытия

По умолчанию `BranchControl` раскрывает всю строку. При рендеринге отдельного `BranchTrigger` установите `role="none"` у `BranchControl`, чтобы триггер не был вложен в другой интерактивный элемент дерева.

### Ссылки и другие семантические конечные элементы

Используйте `asChild` у `TreeView.Item` для одного семантического потомка, например ссылки. Заменяющий элемент должен принимать свойства Ark и сохранять поведение клавиатуры и фокуса.

### Состояние и поведение клавиатуры

Ark управляет паттерном дерева WAI-ARIA: перемещающимся фокусом, навигацией стрелками, Home/End, поиском по вводу, выбором, отметками, отключёнными узлами, асинхронной загрузкой и клавишами переименования. Управляйте `expandedValue`, `selectedValue`, `checkedValue` и `focusedValue` через их колбэки с объектом `details` Ark.

| Свойство | По умолчанию | Примечания |
| --- | --- | --- |
| `selectionMode` | `"single"` | Используйте `"multiple"` для выбора диапазона и выбора с клавишами-модификаторами. |
| `expandOnClick` | `true` | Нажатие на строку ветви раскрывает или сворачивает её. |
| `typeahead` | `true` | Использует `nodeToString` из коллекции. |
| `lazyMount` | `false` | Откладывает рендеринг содержимого ветви до её первого раскрытия. |
| `unmountOnExit` | `false` | Удаляет закрытое содержимое после жизненного цикла закрытия. |

### Переименование и виртуализация

Включите встроенное переименование через `canRename`, рендерите `NodeRenameInput`, пока `state.renaming` равно true, и обновляйте коллекцию в `onRenameComplete`. ## Стилизация

Используйте `className` в экспортируемых частях для структурной стилизации. Части ветви предоставляют `data-state="open|closed"`, части с флажком - `data-state="checked|unchecked|indeterminate"`, а части узла - `data-focus`, `data-selected`, `data-disabled`, `data-loading`, `data-renaming`, `data-depth`, `data-path` и `data-value`. Обёртка учитывает переменные отступа Ark `--depth` и измерения сворачивания `--height`, а также отключает анимацию ветвей при настройке предпочтения уменьшенного движения.
