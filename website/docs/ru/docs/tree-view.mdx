`TreeView.Node` передаёт в рекурсивный рендерер текущие `node`, `indexPath` и `state`, поэтому можно
вывести ветку или конечный узел без повторной настройки провайдера и контекста на каждом уровне.

## Анатомия

```text
TreeView / TreeView.Root
├─ TreeView.Label
└─ TreeView.Tree
   └─ TreeView.Node или TreeView.NodeProvider
      ├─ TreeView.Branch
      │  ├─ TreeView.BranchControl
      │  │  ├─ TreeView.BranchIndicator
      │  │  └─ TreeView.BranchText
      │  └─ TreeView.BranchContent
      │     ├─ TreeView.BranchIndentGuide
      │     └─ вложенные узлы
      └─ TreeView.Item
         └─ TreeView.ItemText
```

| Часть                            | Назначение                                                            |
| -------------------------------- | --------------------------------------------------------------------- |
| `TreeView` / `TreeView.Root`     | Хранит коллекцию и управляет раскрытием, выбором, фокусом, флажками и переименованием. |
| `TreeView.RootProvider`          | Связывает части дерева с экземпляром, созданным через `useTreeView`. |
| `TreeView.Label`                 | Задаёт доступное имя дерева.                                         |
| `TreeView.Tree`                  | Создаёт контейнер дерева с ARIA-разметкой.                           |
| `TreeView.Node`                  | Упрощённый провайдер с `{ node, indexPath, state }`.                 |
| `TreeView.NodeProvider`          | Низкоуровневая граница контекста Ark для нестандартной композиции.   |
| `TreeView.Branch*`               | Раскрываемый узел, его элемент управления, индикатор, текст и содержимое. |
| `TreeView.Item*`                 | Конечный узел и необязательный индикатор выбранного состояния.       |
| `TreeView.NodeCheckbox*`         | Флажок и индикатор отмеченного или частично отмеченного состояния.   |
| `TreeView.NodeRenameInput`       | Поле ввода, которое появляется при переименовании узла.              |

## Композиция

### Рекомендуемая композиция

Для обычного рекурсивного рендерера используйте `TreeView.Node`. Его дочерняя функция получает
текущие `node`, `indexPath` и состояние узла Ark, а затем возвращает разметку ветки или конечного
узла. Структура частей остаётся явной, но не приходится заново подключать контекст.

### Когда нужен NodeProvider

Используйте `TreeView.NodeProvider`, если вашему рекурсивному компоненту нужен прямой доступ к
контексту узла. Это низкоуровневая альтернатива `TreeView.Node`, а не дополнительная обёртка вокруг него.

### Строка ветки и отдельная кнопка

По умолчанию `BranchControl` раскрывает или сворачивает ветку при клике по всей строке. Если нужна
отдельная кнопка `BranchTrigger`, задайте для `BranchControl` `role="none"`, чтобы не вкладывать один
интерактивный элемент дерева в другой.

### Конечные элементы в виде ссылок

Используйте `asChild` у `TreeView.Item`, когда конечный узел должен состоять из одного семантического
элемента, например ссылки. Этот элемент должен принимать props Ark, чтобы не нарушить фокус и
клавиатурное управление.

### Состояние и клавиатурная навигация

Ark UI реализует паттерн дерева WAI-ARIA. Пользователь перемещается по нему стрелками, клавишами Home
и End и поиском по мере ввода, поэтому вручную управлять фокусом обычно не нужно. Передавайте
`expandedValue`, `selectedValue`, `checkedValue` или `focusedValue` только если это состояние должно
храниться в вашем приложении, и добавляйте соответствующий callback.

| Prop            | По умолчанию | Что делает                                                     |
| --------------- | ------------ | -------------------------------------------------------------- |
| `selectionMode` | `"single"`   | Выберите `"multiple"` для выбора с модификаторами и диапазонами. |
| `expandOnClick` | `true`       | Клик по строке ветки раскрывает или сворачивает её.           |
| `typeahead`     | `true`       | Ищет по тексту, который возвращает `nodeToString` коллекции.  |
| `lazyMount`     | `false`      | Создаёт содержимое ветки только при её первом раскрытии.      |
| `unmountOnExit` | `false`      | Удаляет закрытое содержимое после завершения анимации.        |

### Переименование и большие деревья

Чтобы разрешить переименование, передайте `canRename`, выводите `NodeRenameInput`, пока
`state.renaming` равно `true`, и обновляйте коллекцию в `onRenameComplete`. Для виртуализированного
дерева создайте состояние через `useTreeView`, подключите его с помощью `RootProvider`, отрисовывайте
плоский результат `getVisibleNodes()` и передайте `scrollToIndexFn`, чтобы клавиатурная навигация
прокручивала список до нужного узла. Moduix не добавляет отдельный API для виртуализации.

## Стилизация

Используйте `className` у любой экспортируемой части для структурной стилизации. Части веток имеют
`data-state="open|closed"`, части флажков имеют
`data-state="checked|unchecked|indeterminate"`, а части узлов имеют `data-focus`,
`data-selected`, `data-disabled`, `data-loading`, `data-renaming`, `data-depth`, `data-path` и
`data-value`. Обёртка использует переменные Ark `--depth` для отступов и `--height` для высоты при
сворачивании, а также отключает анимацию веток при предпочтении уменьшенного движения.
