## Использование

<UsageCode
  react={'const collection = createTreeCollection({ rootNode, nodeToValue: (n) => n.id, nodeToString: (n) => n.name });\n\n<TreeView collection={collection} defaultExpandedValue={[\'src\']} selectionMode="multiple">\n  <TreeViewTree>\n    {collection.rootNode.children.map((node, index) => (\n      <FileTreeNode key={node.id} node={node} indexPath={[index]} />\n    ))}\n  </TreeViewTree>\n</TreeView>'}

Создайте коллекцию данных с помощью `createTreeCollection`, затем передайте её в `TreeView`.
`TreeViewNode` передаёт в рекурсивный рендерер текущие `node`, `indexPath` и `state`, поэтому можно
вывести ветку или конечный узел, сохранив явную структуру частей.

React, Solid и Vue используют одинаковые плоские имена TreeView; вкладки ниже сохраняют нативную композицию каждого фреймворка.

## Примеры

### Ссылки

Используйте `asChild` у `TreeViewItem`, когда конечный узел должен быть одним семантическим
элементом, например ссылкой. Этот элемент должен принимать props Ark, чтобы сохранить фокус и
клавиатурное управление.

<Example name="tree-view/links" />

### Асинхронная загрузка

Если у ветки известно значение `childrenCount`, загрузите дочерние узлы через `loadChildren`. В
`onLoadChildrenComplete` замените коллекцию в состоянии приложения значением `details.collection`.

<Example name="tree-view/async-loading" />

### Дерево с флажками

Разместите `TreeViewNodeCheckbox` и в элементах управления ветками, и в конечных узлах. Индикатор по
умолчанию уже отображает отмеченное и частично отмеченное состояния.

В Vue слот по умолчанию задаёт значок отмеченного состояния, а именованные слоты
`indeterminate` и `fallback` задают значки частично отмеченного и неотмеченного состояний. Для настройки
этих состояний используются слоты, а не props.

<Example name="tree-view/checkboxes" />

### Значки файлов

Помещайте декоративные значки файлов и папок внутрь `TreeViewBranchText` и `TreeViewItemText`. Оставьте
`TreeViewBranchIndicator` отдельным элементом, чтобы он отвечал только за раскрытие и сворачивание.

<Example name="tree-view/file-icons" />

### Множественный выбор

Задайте `selectionMode="multiple"`. Используйте Ctrl или ⌘, чтобы добавлять и убирать отдельные
элементы, и Shift, чтобы расширять диапазон выбора. В примере выбранные значения хранятся в состоянии
приложения.

<Example name="tree-view/controlled-selection" />

### Root provider

Создайте состояние дерева через `useTreeView`, если кнопкам и другим элементам вне дерева нужны
методы вроде `expand()` или `collapse()`. Передайте состояние в `TreeViewRootProvider`, а не создавайте второй
`TreeView`. Пример также показывает низкоуровневую композицию узла: каждый узел использует
`TreeViewNodeProvider` и читает состояние из `TreeViewNodeContext` вместо сокращения `TreeViewNode`.

## Композиция

Для рекурсивного рендера используйте `TreeViewNode`. Он передаёт `node`, `indexPath` и текущее
состояние узла, а вы выбираете части `TreeViewBranch` или `TreeViewItem`. Если вашему рекурсивному компоненту нужен
прямой доступ к контексту узла, используйте `TreeViewNodeProvider`. Когда состояние дерева должно быть доступно внешним элементам управления, создайте его через
`useTreeView` и передайте в `TreeViewRootProvider`; не создавайте второй root для того же хранилища.
Если у ветки есть отдельный `TreeViewBranchTrigger`, задайте `role="none"` для `TreeViewBranchControl`.

В Vue `TreeViewNode` передаёт данные для рендера через слот по умолчанию с параметрами.
Управляйте значениями через `v-model:expanded-value`, `v-model:selected-value`,
`v-model:checked-value` и `v-model:focused-value`; события вроде `@selection-change` сохраняют
объекты с подробностями Ark. Если коллекция может заменяться, храните её в `shallowRef`, чтобы
Vue сохранял экземпляр класса.

## Анатомия

```text
TreeView
├─ TreeViewLabel
└─ TreeViewTree
   └─ TreeViewNode или TreeViewNodeProvider
      ├─ TreeViewBranch
      │  ├─ TreeViewBranchControl
      │  │  ├─ TreeViewBranchIndicator
      │  │  └─ TreeViewBranchText
      │  ├─ TreeViewBranchTrigger (опционально, отдельный триггер)
      │  └─ TreeViewBranchContent
      │     ├─ TreeViewBranchIndentGuide
      │     └─ вложенные узлы
      └─ TreeViewItem
         └─ TreeViewItemText
```

| Часть                            | Назначение                                                            |
| -------------------------------- | --------------------------------------------------------------------- |
| `TreeView`                  | Хранит коллекцию и управляет раскрытием, выбором, фокусом, флажками и переименованием. |
| `TreeViewRootProvider`          | Связывает части дерева с экземпляром, созданным через `useTreeView`. |
| `TreeViewLabel`                 | Задаёт доступное имя дерева.                                         |
| `TreeViewTree`                  | Создаёт контейнер дерева с ARIA-разметкой.                           |
| `TreeViewNode`                  | Упрощённый провайдер с `{ node, indexPath, state }`.                 |
| `TreeViewNodeProvider`          | Низкоуровневая граница контекста Ark для нестандартной композиции.   |
| `TreeViewBranch*`               | Раскрываемый узел, его элемент управления, индикатор, текст и содержимое. |
| `TreeViewItem*`                 | Конечный узел и необязательный индикатор выбранного состояния.       |
| `TreeViewNodeCheckbox*`         | Флажок и индикатор отмеченного или частично отмеченного состояния.   |
| `TreeViewNodeRenameInput`       | Поле ввода, которое появляется при переименовании узла.              |

## Стилизация

Используйте `className` в React, `class` в Solid или `class` в Vue на любой экспортируемой части для структурной
стилизации. Части ветки имеют `data-state="open|closed"`, части флажка имеют
`data-state="checked|unchecked|indeterminate"`, а части узлов имеют `data-focus`, `data-selected`,
`data-disabled`, `data-loading`, `data-renaming`, `data-depth`, `data-path` и `data-value`. Обёртка
использует переменные Ark `--depth` для отступов и `--height` для высоты при сворачивании, а также
отключает анимацию веток при предпочтении уменьшенного движения.

Варианты Tailwind используют нативные utility-классы и классы приложения. Варианты с CSS Modules берут
цвета, отступы и типографику из токенов foundation и выносят в CSS-переменные только ширину корня и шаг
отступа вложенности; остальное переопределяйте классом на части.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `ArrowDown` / `ArrowUp` | Переводит фокус на следующий или предыдущий видимый узел. |
| `ArrowRight` | Открывает закрытую ветку или переходит внутрь открытой. |
| `ArrowLeft` | Закрывает открытую ветку или переходит к родителю. |
| `Home` / `End` | Переводит фокус на первый или последний узел. |
| `Enter` / `Space` | Выбирает узел или переключает ветку. |
| `*` | Открывает все соседние ветки. |
| `F2` | Начинает переименование, если это разрешает canRename. |
