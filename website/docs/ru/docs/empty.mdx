## Справочник API

Ark UI не предоставляет отдельный примитив пустого состояния. moduix строит этот компонент с помощью официальной
[фабрики Ark](https://ark-ui.com/react/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/react/docs/guides/composition), [стилизации](https://ark-ui.com/react/docs/guides/styling) и
[ref](https://ark-ui.com/react/docs/guides/ref). [Empty State из Chakra](https://chakra-ui.com/docs/components/empty-state)
подтверждает явную композицию; в отличие от Chakra, moduix оставляет необязательные `Empty.Icon` и
`Empty.Actions` соседними частями корневого компонента, чтобы их можно было свободно размещать.

## Анатомия

```text
Empty
├─ Empty.Icon (необязательно)
├─ Empty.Content
│  ├─ Empty.Title
│  └─ Empty.Description
└─ Empty.Actions (необязательно)
```

| Часть                  | Назначение                                                          |
| ---------------------- | ------------------------------------------------------------------- |
| `Empty` / `Empty.Root` | Корневая поверхность, которая задаёт отступы, границу, фон и выравнивание. |
| `Empty.Icon`           | Необязательный контейнер для иконки или небольшого визуального элемента. |
| `Empty.Content`        | Группирует текстовое содержимое с более компактными внутренними отступами. |
| `Empty.Title`          | Основной заголовок пустого состояния.                               |
| `Empty.Description`    | Блок дополнительного описания для одного или нескольких текстовых узлов. |
| `Empty.Actions`        | Необязательная строка с переносом для действий.                     |

## Композиция

### Рекомендуемая композиция

Для большинства пустых состояний используйте экспортируемые части:

- `Empty` для поверхности и центрированного макета
- `Empty.Content` для набора текста
- `Empty.Title` для заголовка
- `Empty.Description` для поясняющего текста
- `Empty.Icon` и `Empty.Actions` только тогда, когда они действительно нужны

Такой подход сохраняет обычный сценарий явным и оставляет место для более содержательных описаний, ссылок или пользовательских
кнопок без добавления конфигурационного API.

### Когда нужна собственная композиция

`Empty` не скрывает низкоуровневый слой примитива. Настройка обычно означает изменение структуры
обычной композицией компонентов:

- не использовать `Empty.Icon` или `Empty.Actions`
- добавить более сложную разметку внутрь `Empty.Description`
- изменить окружающий ориентир или уровень заголовка через `Empty asChild` и `Empty.Title asChild`
- применить `className` и переменные `--moduix-empty-*` к частям, отвечающим за соответствующее визуальное свойство

### Свойства по умолчанию

| Поверхность            | По умолчанию | Примечания                                              |
| ---------------------- | ------------ | ------------------------------------------------------- |
| `Empty` / `Empty.Root` | -            | Дополнительных поведенческих значений по умолчанию нет; применяются значения Ark. |

### Особенности поведения

- `Empty.Title` по умолчанию отрисовывает `h3` и принимает `asChild` фабрики Ark для управления
  структурой документа.
- `Empty.Description` отрисовывает `div`, а не `p`, поэтому может безопасно содержать блочное содержимое.
- Каждая часть передаёт свой ref отрисованному DOM-элементу и принимает `asChild` фабрики Ark с
  единственным семантически корректным потомком.
- Части отрисовывают `data-scope="empty"` и соответствующие атрибуты `data-part` для стилизации в стиле Ark,
  а также стабильные хуки `data-slot="empty-*"` для переопределений moduix.
- `Empty.Actions` центрирует потомков и переносит их на новую строку, поэтому парные действия и длинные прямые подписи кнопок или ссылок
  остаются читаемыми в узких макетах.
- `Empty` носит презентационный характер: выбирайте окружающий ориентир, `role` или поведение живой области только тогда,
  когда этого требует контекст экрана. Указывайте `aria-hidden` для декоративных иконок; содержательным иконкам задавайте доступное имя.

## Стилизация

Стилизуйте `Empty` через `className`, селекторы Ark `data-scope="empty"` / `data-part`, стабильные
хуки `data-slot="empty-*"` и приведённые ниже публичные CSS-переменные `--moduix-empty-*`.

### Хуки стилизации

Выбирайте часть, отвечающую за соответствующее визуальное свойство:

- `[data-scope="empty"][data-part="root"]` / `data-slot="empty-root"` для переопределений макета поверхности, границы,
  фона и тени
- `[data-scope="empty"][data-part="icon"]` / `data-slot="empty-icon"` для размера контейнера иконки,
  отступов и цветов
- `[data-scope="empty"][data-part="content"]` / `data-slot="empty-content"` для ширины и интервалов
  набора текста
- `[data-scope="empty"][data-part="title"]` и
  `[data-scope="empty"][data-part="description"]` для типографики
- `[data-scope="empty"][data-part="actions"]` / `data-slot="empty-actions"` для интервалов
  и выравнивания строки действий
