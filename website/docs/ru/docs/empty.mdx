## Справочник API

В Ark UI нет отдельного примитива для пустых состояний. `moduix` создаёт `Empty` с помощью официальной
[фабрики Ark](https://ark-ui.com/react/docs/guides/composition#the-ark-factory) и следует рекомендациям
Ark по [композиции](https://ark-ui.com/react/docs/guides/composition),
[стилизации](https://ark-ui.com/react/docs/guides/styling) и [работе с ref](https://ark-ui.com/react/docs/guides/ref).
Структура компонента также опирается на [Empty State в Chakra UI](https://chakra-ui.com/docs/components/empty-state).
В отличие от Chakra UI, `moduix` предоставляет `Empty.Icon` и `Empty.Actions` как части, размещаемые
непосредственно в корневом компоненте рядом с `Empty.Content`. Поэтому их можно располагать в нужном
для экрана порядке.

## Базовый пример

## Анатомия

```text
Empty / Empty.Root
├─ Empty.Icon (необязательно)
├─ Empty.Content
│  ├─ Empty.Title
│  └─ Empty.Description
└─ Empty.Actions (необязательно)
```

| Часть                  | Назначение                                                                            |
| ---------------------- | ------------------------------------------------------------------------------------- |
| `Empty` / `Empty.Root` | Корневой контейнер с отступами, границей, фоном и выравниванием.                       |
| `Empty.Icon`           | Необязательный контейнер для иконки или другого небольшого визуального элемента.      |
| `Empty.Content`        | Объединяет заголовок и описание с небольшими расстояниями между ними.                  |
| `Empty.Title`          | Основной заголовок пустого состояния.                                                 |
| `Empty.Description`    | Дополнительное содержимое под заголовком. Может включать абзацы, ссылки и другую блочную разметку. |
| `Empty.Actions`        | Необязательный ряд действий. Элементы переносятся, если не помещаются в одну строку.    |

## Композиция

### Рекомендуемая композиция

В большинстве случаев достаточно таких экспортируемых частей:

- `Empty` для контейнера и центрирования содержимого
- `Empty.Content` для текстового блока
- `Empty.Title` для заголовка
- `Empty.Description` для поясняющего содержимого
- `Empty.Icon` и `Empty.Actions`, когда они действительно нужны

Так обычная структура остаётся понятной, а при необходимости в неё легко добавить ссылки,
более подробный текст или свои кнопки. Собирайте эти части обычным JSX, без отдельной конфигурации.

### Когда нужна собственная композиция

Если стандартную структуру нужно изменить, напрямую собирайте части компонента с помощью JSX:

- не добавляйте `Empty.Icon` или `Empty.Actions`
- добавляйте более сложное блочное содержимое внутрь `Empty.Description`
- используйте свойство `asChild` у `Empty` или `Empty.Title`, если окружающему разделу нужен другой
  семантический элемент или уровень заголовка
- применяйте `className` и переменные `--moduix-empty-*` к частям, которые отвечают за нужное визуальное свойство

### Свойства по умолчанию

| Часть                  | Элемент по умолчанию | Примечания                                                               |
| ---------------------- | -------------------- | ------------------------------------------------------------------------ |
| `Empty` / `Empty.Root` | `div`                | Корневой элемент отвечает только за представление и не добавляет роль или состояние. |
| `Empty.Title`          | `h3`                 | Если нужен другой уровень заголовка, используйте `asChild`.              |
| `Empty.Description`    | `div`                | Может содержать абзацы, ссылки и другую блочную разметку.                |

### Особенности поведения

- Каждая часть передаёт `ref` отрендеренному DOM-элементу и поддерживает `asChild` фабрики Ark.
  Передавайте ровно один семантически подходящий дочерний элемент, который может получить свойства и `ref` части.
- Каждая часть добавляет `data-scope="empty"` и соответствующий атрибут `data-part` для стилизации
  по правилам Ark, а также стабильный атрибут `data-slot="empty-*"` для переопределений moduix.
- `Empty.Actions` центрирует дочерние элементы и переносит их при необходимости. Поэтому парные
  действия и длинные подписи кнопок или ссылок остаются читаемыми в узких макетах.
- `Empty` отвечает только за внешний вид. Компонент не добавляет семантическую область, роль,
  поведение `aria-live` или управление фокусом. Добавьте нужную семантику в окружающий интерфейс.
  Для декоративных иконок используйте `aria-hidden`, а для содержательных задайте доступное имя.

## Стилизация

Настраивайте внешний вид `Empty` с помощью `className`, селекторов Ark по атрибутам
`data-scope="empty"` / `data-part`, стабильных атрибутов `data-slot="empty-*"` и публичных
CSS-переменных `--moduix-empty-*`, перечисленных ниже.

### Точки для стилизации

Выбирайте часть, которая отвечает за нужное визуальное свойство:

- `[data-scope="empty"][data-part="root"]` или `[data-slot="empty-root"]` для макета контейнера,
  границы, фона и переопределения тени
- `[data-scope="empty"][data-part="icon"]` или `[data-slot="empty-icon"]` для размера контейнера
  иконки, внутренних отступов и цветов
- `[data-scope="empty"][data-part="content"]` или `[data-slot="empty-content"]` для ширины
  текстового блока и расстояний между его элементами
- `[data-scope="empty"][data-part="title"]` или `[data-slot="empty-title"]`, а также
  `[data-scope="empty"][data-part="description"]` или `[data-slot="empty-description"]` для типографики
- `[data-scope="empty"][data-part="actions"]` или `[data-slot="empty-actions"]` для расстояний
  и выравнивания ряда действий
