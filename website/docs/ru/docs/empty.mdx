## Использование

Начните с `<Empty />` и добавьте нужные части компонента. Добавляйте `EmptyIcon` и `EmptyActions`
только если к пустому состоянию нужна визуальная подсказка или понятное действие.

## Примеры

### Без действий

Не добавляйте `EmptyActions`, если состояние носит информационный характер и не требует немедленного действия.

<Example name="empty/without-actions" />

### Без иконки

Иконка необязательна, поэтому состояние только с текстом остаётся компактным.

<Example name="empty/without-icon" />

### Расширенная настройка

Используйте свойство `asChild` у `Empty`, если пустое состояние должно отрисовываться семантическим
контейнером, например `section`. Если нужен другой уровень заголовка, используйте `asChild` у
`EmptyTitle`. Компонент рендерит `EmptyDescription` как `div`, поэтому в нём можно размещать абзацы,
ссылки и другую блочную разметку.

## Композиция

`EmptyIcon` и `EmptyActions` необязательны и находятся на одном уровне с `EmptyContent`, поэтому их можно расположить в нужном экрану порядке.

Собирайте `Empty` из частей, расположенных непосредственно внутри корневого компонента.
`EmptyContent` объединяет заголовок и описание, а `EmptyIcon` и `EmptyActions` являются
необязательными соседними частями. Их можно опустить или переставить в соответствии с экраном.
`Empty` отвечает только за представление и не управляет состоянием приложения или поведением
`aria-live`.

Используйте `asChild` у `Empty` или `EmptyTitle`, если разделу нужен семантический контейнер или
другой уровень заголовка. Передавайте ровно один дочерний элемент, чтобы часть могла передать ему
свои свойства и `ref`. В Vue ref компонента предоставляет отрисованный host через `$el`. Нужную
роль, область, управление фокусом или `aria-live` добавляйте в окружающем интерфейсе.

## Анатомия

```text
Empty
├─ EmptyIcon (необязательно)
├─ EmptyContent
│  ├─ EmptyTitle
│  └─ EmptyDescription
└─ EmptyActions (необязательно)
```

| Часть                  | Назначение                                                                            |
| ---------------------- | ------------------------------------------------------------------------------------- |
| `Empty`               | Корневой контейнер с отступами, границей, фоном и выравниванием.                       |
| `EmptyIcon`           | Необязательный контейнер для иконки или другого небольшого визуального элемента.      |
| `EmptyContent`        | Объединяет заголовок и описание с небольшими расстояниями между ними.                 |
| `EmptyTitle`          | Основной заголовок пустого состояния.                                                 |
| `EmptyDescription`    | Дополнительное содержимое под заголовком. Может включать абзацы, ссылки и другую блочную разметку. |
| `EmptyActions`        | Необязательный ряд действий. Элементы переносятся, если не помещаются в одну строку.    |

## Стилизация

Настраивайте внешний вид `Empty` с помощью `className` в React или `class` в Solid и Vue, селекторов
Ark по атрибутам `data-scope="empty"` / `data-part` и стабильных атрибутов `data-slot="empty-*"`.
Пакеты CSS Modules предоставляют переменные `--moduix-empty-*` ниже для поверхности корня, чтобы тема
могла перенастроить все пустые состояния сразу. Остальные части стилизуйте классом: он перекрывает
слоистые стили компонента.

### Хуки стилизации

Выбирайте часть, которая отвечает за нужное визуальное свойство:

- `[data-scope="empty"][data-part="root"]` или `[data-slot="empty-root"]` для макета контейнера,
  границы, фона и переопределения тени
- `[data-scope="empty"][data-part="icon"]` или `[data-slot="empty-icon"]` для размера контейнера
  иконки, внутренних отступов и цветов
- `[data-scope="empty"][data-part="content"]` или `[data-slot="empty-content"]` для ширины
  текстового блока и расстояний между его элементами
- `[data-scope="empty"][data-part="title"]` или `[data-slot="empty-title"]`, а также
  `[data-scope="empty"][data-part="description"]` или `[data-slot="empty-description"]` для типографики
- `[data-scope="empty"][data-part="actions"]` или `[data-slot="empty-actions"]` для расстояний
  и выравнивания ряда действий
