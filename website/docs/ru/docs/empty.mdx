## Справочник API

В Ark UI нет отдельного примитива для пустых состояний. `moduix` собирает `Empty` с помощью официальной
[фабрики Ark](https://ark-ui.com/react/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/react/docs/guides/composition), [стилизации](https://ark-ui.com/react/docs/guides/styling) и
[работе с ref](https://ark-ui.com/react/docs/guides/ref). Явная композиция основана на подходе
[Empty State из Chakra UI](https://chakra-ui.com/docs/components/empty-state). В отличие от Chakra UI,
`moduix` экспортирует необязательные `Empty.Icon` и `Empty.Actions` как соседние части корневого
компонента, поэтому их можно размещать в нужном порядке.

## Анатомия

```text
Empty
├─ Empty.Icon (необязательно)
├─ Empty.Content
│  ├─ Empty.Title
│  └─ Empty.Description
└─ Empty.Actions (необязательно)
```

| Часть                  | Назначение                                                          |
| ---------------------- | ------------------------------------------------------------------- |
| `Empty` / `Empty.Root` | Корневой контейнер, который задаёт отступы, границу, фон и выравнивание. |
| `Empty.Icon`           | Необязательный контейнер для иконки или небольшого визуального элемента. |
| `Empty.Content`        | Объединяет заголовок и описание с компактными интервалами между ними.   |
| `Empty.Title`          | Основной заголовок пустого состояния.                                  |
| `Empty.Description`    | Блок поясняющего текста, состоящий из одного или нескольких элементов. |
| `Empty.Actions`        | Необязательный ряд действий с переносом на новую строку.               |

## Композиция

### Рекомендуемая композиция

В большинстве случаев используйте экспортируемые части:

- `Empty` для контейнера и центрирования содержимого
- `Empty.Content` для текстового блока
- `Empty.Title` для заголовка
- `Empty.Description` для поясняющего текста
- `Empty.Icon` и `Empty.Actions` только тогда, когда они действительно нужны

Так структура обычного сценария остаётся понятной, а для более подробного описания, ссылок или
собственных кнопок не требуется отдельный конфигурационный API.

### Когда нужна собственная композиция

`Empty` напрямую предоставляет свои части, поэтому структуру можно менять обычной композицией
компонентов:

- не добавлять `Empty.Icon` или `Empty.Actions`
- добавить более сложную разметку внутрь `Empty.Description`
- изменить родительскую семантическую область или уровень заголовка через `Empty asChild` и `Empty.Title asChild`
- применить `className` и переменные `--moduix-empty-*` к частям, которые отвечают за нужное визуальное свойство

### Свойства по умолчанию

| Поверхность            | По умолчанию | Примечания                                              |
| ---------------------- | ------------ | ------------------------------------------------------- |
| `Empty` / `Empty.Root` | -            | Компонент не добавляет специального поведения, применяются значения Ark. |

### Особенности поведения

- `Empty.Title` по умолчанию рендерит `h3`. Используйте `asChild` фабрики Ark, если для структуры
  документа нужен другой уровень заголовка.
- `Empty.Description` рендерит `div`, а не `p`, поэтому может безопасно содержать блочную разметку.
- Каждая часть передаёт `ref` отрендеренному DOM-элементу и принимает `asChild` фабрики Ark с
  одним семантически корректным дочерним элементом.
- Каждая часть добавляет `data-scope="empty"` и соответствующий атрибут `data-part` для стилизации
  в стиле Ark, а также стабильные хуки `data-slot="empty-*"` для переопределений moduix.
- `Empty.Actions` центрирует дочерние элементы и переносит их при необходимости. Поэтому парные
  действия и длинные подписи кнопок или ссылок остаются читаемыми в узких макетах.
- `Empty` отвечает только за представление и не добавляет семантическую область, `role` или поведение
  live region. Добавляйте эти семантические атрибуты, если они нужны окружающему экрану. Для
  декоративных иконок используйте `aria-hidden`, а содержательным иконкам задавайте доступное имя.

## Стилизация

Настраивайте внешний вид `Empty` с помощью `className`, селекторов Ark `data-scope="empty"` / `data-part`,
стабильных хуков `data-slot="empty-*"` и публичных CSS-переменных `--moduix-empty-*`, перечисленных ниже.

### Хуки стилизации

Выбирайте часть компонента, которая отвечает за нужное визуальное свойство:

- `[data-scope="empty"][data-part="root"]` / `data-slot="empty-root"` для макета контейнера, границы,
  фона и тени
- `[data-scope="empty"][data-part="icon"]` / `data-slot="empty-icon"` для размера контейнера иконки,
  отступов и цветов
- `[data-scope="empty"][data-part="content"]` / `data-slot="empty-content"` для ширины текстового блока
  и интервалов между его элементами
- `[data-scope="empty"][data-part="title"]` и
  `[data-scope="empty"][data-part="description"]` для типографики
- `[data-scope="empty"][data-part="actions"]` / `data-slot="empty-actions"` для интервалов
  и выравнивания ряда действий
