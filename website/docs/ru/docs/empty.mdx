## Справочник API

В Ark UI нет отдельного примитива для пустых состояний. `moduix` создаёт `Empty` с помощью официальной
[фабрики Ark](https://ark-ui.com/react/docs/guides/composition#the-ark-factory) и следует рекомендациям
Ark по [композиции](https://ark-ui.com/react/docs/guides/composition),
[стилизации](https://ark-ui.com/react/docs/guides/styling) и [работе с ref](https://ark-ui.com/react/docs/guides/ref).
Структура компонента также опирается на [Empty State в Chakra UI](https://chakra-ui.com/docs/components/empty-state).
В отличие от Chakra UI, `moduix` предоставляет `Empty.Icon` и `Empty.Actions` как части, размещаемые
непосредственно в корневом компоненте рядом с `Empty.Content`. Поэтому их можно располагать в нужном
для экрана порядке.

## Анатомия

```text
Empty / Empty.Root
├─ Empty.Icon (необязательно)
├─ Empty.Content
│  ├─ Empty.Title
│  └─ Empty.Description
└─ Empty.Actions (необязательно)
```

| Часть                  | Назначение                                                                            |
| ---------------------- | ------------------------------------------------------------------------------------- |
| `Empty` / `Empty.Root` | Корневой контейнер с отступами, границей, фоном и выравниванием.                       |
| `Empty.Icon`           | Необязательный контейнер для иконки или другого небольшого визуального элемента.      |
| `Empty.Content`        | Объединяет заголовок и описание с небольшими расстояниями между ними.                 |
| `Empty.Title`          | Основной заголовок пустого состояния.                                                 |
| `Empty.Description`    | Дополнительное содержимое под заголовком. Может включать абзацы, ссылки и другую блочную разметку. |
| `Empty.Actions`        | Необязательный ряд действий. Элементы переносятся, если не помещаются в одну строку.    |

## Композиция

Собирайте `Empty` из частей, расположенных непосредственно внутри корневого компонента.
`Empty.Content` объединяет заголовок и описание, а `Empty.Icon` и `Empty.Actions` являются
необязательными соседними частями. Их можно опустить или переставить в соответствии с экраном.
`Empty` отвечает только за представление и не управляет состоянием приложения или поведением
`aria-live`.

Используйте `asChild` у `Empty` или `Empty.Title`, если разделу нужен семантический контейнер или
другой уровень заголовка. Передавайте ровно один дочерний элемент, чтобы часть могла передать ему
свои свойства и `ref`. Нужную роль, область, управление фокусом или `aria-live` добавляйте в
окружающем интерфейсе.

## Стилизация

Настраивайте внешний вид `Empty` с помощью `className`, селекторов Ark по атрибутам
`data-scope="empty"` / `data-part`, стабильных атрибутов `data-slot="empty-*"` и публичных
CSS-переменных `--moduix-empty-*`, перечисленных ниже.

### Точки для стилизации

Выбирайте часть, которая отвечает за нужное визуальное свойство:

- `[data-scope="empty"][data-part="root"]` или `[data-slot="empty-root"]` для макета контейнера,
  границы, фона и переопределения тени
- `[data-scope="empty"][data-part="icon"]` или `[data-slot="empty-icon"]` для размера контейнера
  иконки, внутренних отступов и цветов
- `[data-scope="empty"][data-part="content"]` или `[data-slot="empty-content"]` для ширины
  текстового блока и расстояний между его элементами
- `[data-scope="empty"][data-part="title"]` или `[data-slot="empty-title"]`, а также
  `[data-scope="empty"][data-part="description"]` или `[data-slot="empty-description"]` для типографики
- `[data-scope="empty"][data-part="actions"]` или `[data-slot="empty-actions"]` для расстояний
  и выравнивания ряда действий
