## Выбор подходящего компонента

Используйте `Tabs`, чтобы переключаться между связанными представлениями в одной области страницы. Выбранная вкладка
показывает соответствующую панель, а остальные скрываются.

- Выберите **`Tabs`**, если каждая вкладка должна показывать связанную с ней панель содержимого.
- Выберите **`Accordion`**, если разделы должны располагаться друг под другом и раскрываться независимо.
- Выберите **`ToggleGroup`**, если элемент управления меняет состояние или режим, но не отвечает за содержимое панелей.

## Анатомия

```text
Tabs
├─ Tabs.List
│  ├─ Tabs.Trigger[value]
│  ├─ Tabs.Trigger[value]
│  └─ Tabs.Indicator
└─ Tabs.Content[value]

Tabs.RootProvider
└─ Tabs.* + useTabs()

Tabs.Context
└─ render prop
```

| Часть               | Назначение                                                        |
| ------------------- | ----------------------------------------------------------------- |
| `Tabs`              | Корневой компонент, который управляет выбранным значением, фокусом, ориентацией и режимом. |
| `Tabs.RootProvider` | Подключает части к состоянию, созданному через `useTabs()` в moduix. |
| `Tabs.Context`      | Передаёт текущее состояние вкладок через render prop.             |
| `Tabs.List`         | Объединяет вкладки и управляет перемещением фокуса между ними.    |
| `Tabs.Trigger`      | Интерактивная вкладка или элемент-носитель `asChild` с обязательным значением. |
| `Tabs.Indicator`    | Необязательный индикатор выбранной вкладки.                      |
| `Tabs.Content`      | Панель содержимого, связанная с вкладкой через совпадающее значение. |

## Композиция

### Рекомендуемая композиция

В обычном случае используйте `<Tabs>`. Компонент управляет клавиатурной навигацией, перемещением фокуса и
выбранным значением. Укажите `defaultValue`, чтобы задать начальную вкладку, или передайте `value` вместе с
`onValueChange(details)`, если выбранное значение должно храниться в состоянии React. Новое значение находится в
`details.value`.

Корневой компонент также принимает `onFocusChange(details)`, `activationMode`, `orientation`, `loopFocus`,
`deselectable`, `lazyMount`, `unmountOnExit`, `ids` и `navigate`, передавая их в Ark UI.

Сохраняйте структуру частей явной. `Tabs.List` объединяет вкладки, но не создаёт индикатор автоматически. Если
нужно визуально выделить выбранную вкладку, добавьте `Tabs.Indicator`.

### Когда нужна собственная композиция

Используйте `asChild` у `Tabs.Trigger`, если вкладка должна отображаться как ссылка или компонент вашего
маршрутизатора. Дочерний элемент должен быть единственным семантическим элементом и сохранять клавиатурное
поведение, фокус и ARIA-атрибуты Ark.

Используйте `useTabs()` или `Tabs.useTabs()` вместе с `Tabs.RootProvider`, если состояние вкладок нужно создать вне
дерева компонентов либо читать или изменять из соседнего элемента интерфейса. Не оборачивайте тот же экземпляр
состояния в другой корневой компонент `Tabs`.

Используйте `Tabs.Context` для функции рендера (`render prop`) или `useTabsContext()`, чтобы прочитать текущее
состояние из потомков `Tabs` или `Tabs.RootProvider`.

### Свойства по умолчанию

| Свойство              | По умолчанию | Примечание                                                               |
| --------------------- | ------------ | ------------------------------------------------------------------------ |
| `Tabs.variant`        | `default`    | Вариант оформления: `default` или `line`.                               |
| `Tabs.activationMode` | `automatic`  | В фокусе вкладка выбирается автоматически; `manual` требует активации.  |
| `Tabs.orientation`    | `horizontal` | Для горизонтальных вкладок используются стрелки влево/вправо, для вертикальных вверх/вниз. |
| `Tabs.loopFocus`      | `true`       | После последней вкладки фокус переходит к первой.                       |
| `Tabs.lazyMount`      | `false`      | Монтирует панель только после первого выбора вкладки.                    |
| `Tabs.unmountOnExit`  | `false`      | Размонтирует неактивные панели, обычно вместе с `lazyMount`.             |

### Особенности поведения

- `Tabs.Trigger` и `Tabs.Content` связываются одинаковыми строковыми значениями свойства `value`.
- В режиме `activationMode="automatic"` перемещение фокуса выбирает вкладку. В режиме `manual` фокус сначала перемещается, а вкладка выбирается после активации.
- `onValueChange` получает объект `details` из Ark UI. Выбранное значение находится в `details.value`.
- Отключённая `Tabs.Trigger` остаётся видимой, но не получает фокус и не может быть выбрана.
- `variant="line"` работает только для горизонтальных вкладок. Вертикальные `Tabs` и `Tabs.RootProvider` используют заполненный вариант `default`.
- Ark UI управляет ARIA-атрибутами, связями вкладок и панелей, клавиатурной навигацией, перемещением фокуса и поведением отключённых вкладок.

## Стилизация

Настраивайте `Tabs` через `className`, стабильные точки подключения `data-slot="tabs-*"`, атрибуты Ark `data-scope`
и `data-part`, атрибут `data-variant` корневого элемента и публичные CSS-переменные `--moduix-tabs-*`, перечисленные
ниже.

### Точки подключения для стилей

Настраивайте ту часть, которая отвечает за нужный визуальный элемент:

- `Tabs` отвечает за ширину, общий интервал, ориентацию и переопределения варианта
- `Tabs.List` отвечает за оформление списка, границы, фон и отступы вокруг индикатора
- `Tabs.Trigger` отвечает за расположение подписи, интервал рядом со значком, выбранное и отключённое состояния, а также фокус
- `Tabs.Indicator` отвечает за цвет, размер и анимацию индикатора
- `Tabs.Content` отвечает за фон панели, внутренние отступы и оформление фокуса

Основные публичные точки подключения: `data-slot="tabs-root"`, `data-slot="tabs-root-provider"`,
`data-slot="tabs-list"`, `data-slot="tabs-trigger"`, `data-slot="tabs-indicator"` и
`data-slot="tabs-content"`.

Полезные атрибуты Ark: `data-scope="tabs"`, `data-part`, `data-orientation`, `data-selected`, `data-disabled`,
`data-focus`, а также переменные позиционирования индикатора `--left`, `--top`, `--width`, `--height` и
`--transition-property`.
