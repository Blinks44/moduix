## Использование

<Usage />

Начните с `Tabs` и задайте одинаковое значение `value` для каждой пары `TabsTrigger` и
`TabsContent`. Добавьте `TabsIndicator`, если выбранную вкладку нужно отметить визуально.

## Какой компонент выбрать

Используйте `Tabs`, чтобы переключаться между связанными представлениями в одной области страницы.
При выборе вкладки открывается соответствующая панель, а остальные панели скрываются.

- Выбирайте **`Tabs`**, когда каждая вкладка должна открывать одну связанную с ней панель.
- Выбирайте **`Accordion`**, когда разделы должны оставаться расположенными друг под другом и открываться независимо.
- Выбирайте **`ToggleGroup`**, когда элемент управления меняет состояние или режим, но не показывает содержимое панели.

## Примеры

### Вариант с линией

Используйте `variant="line"`, если индикатор должен располагаться на активном краю, а не заполнять
выбранную вкладку. У горизонтальных вкладок линия идёт под списком, у вертикальных по его краю
со стороны панели.

<Example name="tabs/line" width="lg" />

### Размеры

Задайте `size` у `Tabs` или `TabsRootProvider`: `sm`, `md` (по умолчанию) или `lg`. Тогда список
вкладок получает высоту `Button` или `Input` того же размера, как `SegmentGroup`.

<Example name="tabs/sizes" width="lg" />

### Растянутые вкладки

Передайте `fitted` в `Tabs` или `TabsRootProvider`, чтобы горизонтальный список вкладок занял всю
ширину корня и поделил её поровну между триггерами. Вертикальные вкладки его игнорируют.

<Example name="tabs/fitted" width="lg" />

### Вертикальная ориентация

Используйте `orientation="vertical"`, если список вкладок должен располагаться рядом с активной
панелью. Список занимает до `12rem`, а в узком контейнере не больше 40% ширины корня.

<Example name="tabs/vertical" width="lg" />

### Собственные значки

Размещайте значки и подписи непосредственно внутри `TabsTrigger`.

<Example name="tabs/custom-icons" width="lg" />

### Отключённая вкладка

Отключите вкладку, если она должна оставаться видимой, но пока недоступна.

<Example name="tabs/disabled-tab" width="lg" />

### Ссылки

Используйте `asChild`, если триггеры вкладок должны отображаться как ссылки, которыми управляет
ваш роутер.

<Example name="tabs/links" width="lg" />

### Ручная активация

Установите `activationMode="manual"`, если стрелки должны перемещать фокус, не меняя выбранную
вкладку. Активируйте её кликом, клавишей Enter или пробелом.

<Example name="tabs/manual-activation" width="lg" />

### Ленивое монтирование

Используйте `lazyMount`, если неактивные панели не должны монтироваться до выбора. Добавьте
`unmountOnExit`, чтобы после ухода с вкладки удалять их из DOM.

<Example name="tabs/lazy-mount" width="lg" />

### Управляемое состояние

Управляйте выбранной вкладкой через состояние приложения, если активной панели нужно синхронизироваться
с другими элементами интерфейса.

<Example name="tabs/controlled-value" width="lg" />

### Root Provider

Создайте состояние вкладок через `useTabs()`, если оно должно существовать до отображения дерева
частей или если соседнему интерфейсу нужно читать выбранное значение.

## Композиция

Используйте `defaultValue` для неконтролируемого компонента. Если выбором управляет другая часть
приложения, передайте `value` и `onValueChange(details)`, а выбранное значение прочитайте из
`details.value`.

В Vue используйте `v-model` для управляемого выбора и `@value-change` для получения того же объекта
с данными события. `TabsContext` передаёт состояние через scoped slot по умолчанию.

Используйте `TabsRootProvider` вместе с `useTabs()`, если состояние нужно создать вне дерева
компонента или разделить с соседним интерфейсом. Передайте хранилище в `TabsRootProvider` и не
создавайте для него ещё один корень `Tabs`. Для ссылки или компонента роутера используйте
`asChild` на `TabsTrigger`, а `TabsIndicator` добавляйте явно: `TabsList` не создаёт его
автоматически.

## Стилизация

Используйте `className` в React или `class` в Solid и Vue на экспортируемых частях для структурных
стилей. Для стилей состояний предпочитайте атрибуты Ark, такие как `data-selected`,
`data-disabled` и `data-orientation`, вместе с селекторами moduix `data-slot`. Варианты на Tailwind
используют нативные утилиты и классы потребителя, а переменные ниже настраивают варианты с CSS Modules.

### CSS-переменные

Наведите на переменную или выберите её, чтобы увидеть её в превью. Меняйте значения контролами и копируйте готовый CSS.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `Tabs` | `tabs-root` |
| `TabsRootProvider` | `tabs-root-provider` |
| `TabsList` | `tabs-list` |
| `TabsTrigger` | `tabs-trigger` |
| `TabsIndicator` | `tabs-indicator` |
| `TabsContent` | `tabs-content` |

Выбирайте часть, которая отвечает за нужный визуальный аспект:

- `Tabs` для ширины, общего расстояния, ориентации и переопределений на уровне варианта
- `TabsList` для фона, границ, оформления списка и расстояния вокруг индикатора
- `TabsTrigger` для раскладки подписи, расстояния до значка, выбранного и отключённого состояний, а также фокуса
- `TabsIndicator` для цвета, размера и переходов индикатора; задайте на нём Ark-переменные
  `--transition-duration` и `--transition-timing-function`, чтобы изменить движение
- `TabsContent` для поверхности панели, внутренних отступов и стилей фокуса

Полезные хуки Ark: `data-scope="tabs"`, `data-part`, `data-orientation`, `data-selected`,
`data-disabled`, `data-focus`, а также переменные индикатора `--left`, `--top`, `--width`,
`--height` и `--transition-property`.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `ArrowLeft` / `ArrowRight` | Переходит к предыдущей или следующей вкладке; ArrowUp и ArrowDown в вертикальном режиме. |
| `Home` / `End` | Переходит к первой или последней вкладке. |
| `Enter` / `Space` | Выбирает вкладку в фокусе, если activationMode равен manual. |
| `Tab` | Переводит фокус из списка вкладок в активную панель. |

## Справочник API

| Проп | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `value` | `string \| null` | — | Выбранная вкладка в управляемом режиме. |
| `defaultValue` | `string \| null` | — | Изначально выбранная вкладка. |
| `onValueChange` | `(details: ValueChangeDetails) => void` | — | Вызывается при выборе другой вкладки. |
| `variant` | `'default' \| 'line'` | `'default'` | Вид: `default` или `line`. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Размер: `sm`, `md` или `lg`. |
| `fitted` | `boolean` | `false` | Растягивает триггеры на всю ширину поровну. |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Раскладка и направление стрелок: `horizontal` или `vertical`. |
| `activationMode` | `'automatic' \| 'manual'` | `'automatic'` | `automatic` выбирает при фокусе, `manual` ждёт Enter или Space. |
| `loopFocus` | `boolean` | `true` | Навигация с клавиатуры переходит с последнего элемента на первый. |
| `deselectable` | `boolean` | `false` | Клик по активной вкладке снимает выбор. |
| `lazyMount` | `boolean` | `false` | Монтирует содержимое при первом открытии. |
| `unmountOnExit` | `boolean` | `false` | Удаляет содержимое после закрытия. |
| `translations` | `IntlTranslations` | — | Переведённые строки для подписей доступности. |
| `onFocusChange` | `(details: FocusChangeDetails) => void` | — | Вызывается, когда фокус переходит на другой триггер. |
| `composite` | `boolean` | — | Укажите `false`, если компонент находится внутри другого составного виджета, например вкладок. |
| `navigate` | `((details: NavigateDetails) => void) \| null` | — | Переходит по триггеру-ссылке, выбранному с клавиатуры. |
