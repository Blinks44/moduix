`Frame` рендерит свои дочерние элементы внутри документа iframe. Всегда задавайте содержательный `title`: он становится
доступным именем iframe. В примере через `head` также передаётся элемент `<style>`, потому что стили родительского
документа не проникают внутрь iframe.

## Стили содержимого и размер

Проп `head` принимает JSX-содержимое и добавляет его в `<head>` iframe. Используйте его для стилей, шрифтов и
метаданных. Таблицы стилей, необходимые вложенному интерфейсу, также нужно передать через этот проп.

`Frame` отслеживает размер смонтированного содержимого и записывает его в пикселях в CSS-переменные `--width` и
`--height` на элементе iframe. Используйте `block-size: var(--height, 10rem)`, если iframe должен расти вместе с
содержимым. Переменную `--width` можно использовать так же для inline-размера.

## Колбэки жизненного цикла

Используйте `onMount` и `onUnmount` для ресурсов, которыми управляет встроенный интерфейс. Оба колбэка вызываются без
аргументов. С помощью `ref` приложение может получить доступ к документу iframe, если это нужно для настройки.

Добавляйте только скрипты, которыми управляет ваше приложение. Для стилей и метаданных используйте `head`.

## Статические HTML-документы

Используйте `srcDoc` в React или `srcdoc` в Solid и Vue, когда iframe должен начинаться с готового HTML-документа, а не с
элементов, отрендеренных фреймворком. Это нативные варианты записи одного и того же атрибута iframe в каждом фреймворке.

Для недоверенного HTML задайте нативный атрибут `sandbox` и оставьте только необходимые содержимому разрешения. Не
добавляйте одновременно `allow-scripts` и `allow-same-origin` для недоверенного содержимого.
