## Когда использовать

Используйте `Frame`, чтобы показать в iframe превью или встроенный интерфейс, которым управляет приложение. Документ
iframe остаётся отдельным от окружающего интерфейса. Компонент принимает нативные атрибуты iframe и рендерит
React-элементы внутри фрейма.

Импортируйте `Frame` напрямую из Ark UI:

```tsx
import { Frame } from '@ark-ui/react';
```

## Стили внутри фрейма

У iframe свой документ, поэтому стили родительской страницы не применяются к его содержимому автоматически. Передайте
React-элементы через `head`, чтобы добавить в документ iframe стили, шрифты или метаданные.

## srcDoc и безопасность

Используйте `srcDoc`, если фрейм должен начаться с полноценного HTML-документа, а не с React-элементов:

```tsx
import { Frame } from '@ark-ui/react';

const previewDocument = '<!doctype html><html><body><main><h1>Release notes</h1></main></body></html>';

export function StaticPreview() {
  return <Frame sandbox="" srcDoc={previewDocument} title="Release notes preview" />;
}
```

Считайте `srcDoc` HTML-кодом, которым управляет ваше приложение. Для недоверенного содержимого используйте нативный
атрибут `sandbox` и выдавайте превью только необходимые разрешения. Не сочетайте `allow-scripts` и
`allow-same-origin` для недоверенного содержимого: так оно может снять собственные ограничения песочницы.

## Использование с moduix

Используйте `Card`, `Stack` и компоненты статуса moduix вокруг `Frame`, чтобы дать встроенному превью заголовок и
контекст. Стили внутри iframe должны быть самодостаточными: он не наследует стили родительской страницы.

## Границы ответственности

Ark UI отвечает за компонент `Frame` и жизненный цикл iframe. moduix предоставляет компоненты интерфейса, но не
переэкспортирует `Frame`.
