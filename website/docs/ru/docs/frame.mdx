## Когда использовать Frame

Используйте `Frame`, когда React-содержимое должно отображаться в iframe, которым управляет ваше приложение. Это
подходит для живого превью, холста редактора или встроенного рабочего пространства. У iframe отдельный документ,
поэтому его DOM и стили изолированы от страницы, в которую он встроен. `Frame` передаёт нативные атрибуты iframe и
рендерит его React-элементы внутри этого документа.

`Frame` предоставляет Ark UI, а не moduix:

```tsx
import { Frame } from '@ark-ui/react';
```

Всегда задавайте содержательный `title`, чтобы пользователи вспомогательных технологий понимали назначение iframe.

фокусом работают в нужном документе, если внутри превью используются компоненты Ark UI. Внутри `Frame` можно напрямую
размещать такие компоненты, как `Button`, `Dialog` и `Popover`.

## Стили внутри iframe

У iframe свой документ, поэтому стили родительской страницы не применяются к его содержимому автоматически. Передайте
React-узлы через проп `head`, чтобы добавить в документ iframe стили, шрифты или метаданные.

нужные им стили. CSS родительской страницы не проникает внутрь iframe.

## Колбэки жизненного цикла

Используйте `onMount` и `onUnmount`, чтобы подготовить и освободить ресурсы встроенного интерфейса. Эти колбэки не
получают аргументов. Например, с помощью `ref` можно получить доступ к документу iframe и добавить скрипт, которым
управляет ваше приложение:

```tsx
import { useRef } from 'react';
import { Frame } from '@ark-ui/react';

export function ScriptedPreview() {
  const frameRef = useRef<HTMLIFrameElement>(null);

  return (
    <Frame
      ref={frameRef}
      title="Interactive preview"
      onMount={() => {
        const frameDocument = frameRef.current?.contentDocument;
        if (!frameDocument) return;

        const script = frameDocument.createElement('script');
        script.textContent = 'document.body.dataset.ready = "true";';
        frameDocument.body.append(script);
      }}
      onUnmount={() => {
        // Release application-owned listeners and other resources here.
      }}
    >
      <main>Interactive preview</main>
    </Frame>
  );
}
```

Добавляйте только те скрипты, которыми управляет ваше приложение. Для стилей и метаданных используйте проп `head`.

## Размер содержимого

`Frame` отслеживает размер отрендеренного содержимого и записывает его в CSS-переменные `--width` и `--height` на
элементе iframe. Значения указаны в пикселях и обновляются при изменении размера содержимого. Используйте эти
переменные, если iframe должен расти вместе с содержимым:

```tsx
<Frame
  title="Release preview"
  style={{
    blockSize: 'var(--height, 10rem)',
    inlineSize: '100%',
  }}
>
  <main>Release preview</main>
</Frame>
```

Если превью должно оставаться в области фиксированного размера, задайте явную высоту, как в базовом примере.

## `srcDoc` и безопасность

Используйте `srcDoc`, когда iframe должен начинаться с готового HTML-документа, а не с React-элементов:

```tsx
import { Frame } from '@ark-ui/react';

const previewDocument = '<!doctype html><html><body><main><h1>Release notes</h1></main></body></html>';

export function StaticPreview() {
  return <Frame sandbox="" srcDoc={previewDocument} title="Release notes preview" />;
}
```

Считайте значение `srcDoc` HTML-кодом, которым полностью управляет ваше приложение. Для недоверенного содержимого
используйте нативный атрибут `sandbox` и оставляйте только те разрешения, которые нужны превью. Не сочетайте
`allow-scripts` и `allow-same-origin` для недоверенного содержимого: в таком случае оно может снять собственные
ограничения песочницы.

## Использование с moduix

`Frame` относится к Ark UI и не переэкспортируется из moduix. Если превью нужны заголовок, разметка или статус,
оберните `Frame` в компоненты moduix, например `Card`, `Stack` или `Badge`. В примерах выше эта внешняя часть
находится в документе страницы, а само превью рендерится внутри iframe.

Если компоненты moduix должны находиться внутри iframe, передайте их стили через `head` или подключите таблицу стилей
по URL, доступному из iframe. Содержимое iframe должно быть самодостаточным.

## Ответственность

Ark UI предоставляет компонент `Frame`, управляет жизненным циклом iframe, окружением вложенных компонентов Ark и
переменными размера содержимого. moduix предоставляет окружающие компоненты интерфейса и показывает, как сочетать их с
`Frame`, но не переэкспортирует `Frame`.
