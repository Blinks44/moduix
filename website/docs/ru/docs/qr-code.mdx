## Анатомия

```text
QrCode / QrCode.Root
├─ QrCode.Frame
│  └─ QrCode.Pattern
├─ QrCode.Overlay
└─ QrCode.DownloadTrigger

QrCode.RootProvider
└─ то же дерево частей, подключённое к useQrCode() из @moduix/react
```

| Часть                     | Назначение                                                               |
| ------------------------- | ------------------------------------------------------------------------ |
| `QrCode` / `QrCode.Root` | Хранит кодируемое значение и параметры генерации, предоставляет состояние QR-кода. |
| `QrCode.RootProvider`    | Подключает части к объекту состояния, созданному через `useQrCode()` вне дерева.       |
| `QrCode.Frame`           | SVG-элемент с созданным QR-кодом.                                        |
| `QrCode.Pattern`         | SVG-путь, который рисует модули QR-кода.                                 |
| `QrCode.Overlay`         | Содержимое по центру поверх QR-кода.                                     |
| `QrCode.DownloadTrigger` | Кнопка, скачивающая текущий QR-код как изображение.                      |

## Композиция

### Рекомендуемая композиция

`QrCode` является короткой формой `QrCode.Root`. Используйте любой из вариантов, оставляя
`QrCode.Frame` и `QrCode.Pattern` явными. Для неконтролируемого QR-кода задайте `defaultValue`. Если
значение приходит из состояния приложения, используйте вместо этого `value` и
`onValueChange(details)`.

Добавляйте `QrCode.Overlay`, только если закрытая область достаточно мала и код остаётся
считываемым. Для наложения задайте `encoding={{ ecc: 'H' }}` и проверьте итоговый код сканерами,
которыми пользуются ваши пользователи.

### Когда нужна собственная композиция

Используйте `QrCode.RootProvider`, если состояние QR-кода нужно создать вне отрисовываемого дерева
или если внешним элементам управления нужен доступ к API QR-кода. Создайте состояние через
`useQrCode()` из `@moduix/react/qr-code`, затем передайте его в `RootProvider`. Если потомку нужно
текущее значение или API QR-кода, используйте `QrCode.Context` или `useQrCodeContext()`. Для одного
объекта состояния не используйте одновременно `QrCode` и `QrCode.RootProvider`.

Используйте `asChild` на части Ark только тогда, когда итоговый DOM-узел должен принадлежать
другому элементу. Передавайте один семантически подходящий дочерний элемент. Свойство `ids` пригодится
для стабильных идентификаторов корневого элемента и рамки в собственной композиции.

### Основные свойства

Ниже перечислены свойства, которые нужны большинству пользователей. Каждая часть также принимает
соответствующие DOM-свойства, включая `className` и `asChild`, если они поддерживаются. Полный API
Ark смотрите в справочнике.

| Часть           | Свойство        | Назначение                                                               |
| --------------- | --------------- | ------------------------------------------------------------------------ |
| Root            | `defaultValue`  | Начальное значение для неконтролируемого режима.                         |
| Root            | `value`         | Значение для управляемого режима.                                        |
| Root            | `onValueChange` | Получает исходный объект `details` от Ark. Новое значение находится в `details.value`. |
| Root            | `encoding`      | Параметры генератора, например `ecc` и `boostEcc`.                       |
| Root            | `pixelSize`     | Размер пикселя, передаваемый генератору QR-кода.                         |
| Root            | `id`            | Стабильный идентификатор машины, передаваемый в Ark.                     |
| Root            | `ids`           | Стабильные идентификаторы корневого элемента и рамки.                    |
| RootProvider    | `value`         | Обязательный объект состояния, возвращённый `useQrCode()`.               |
| DownloadTrigger | `fileName`      | Обязательное имя скачиваемого файла.                                     |
| DownloadTrigger | `mimeType`      | Обязательный тип изображения, например `image/png` или `image/svg+xml`.  |
| DownloadTrigger | `quality`       | Необязательное качество изображения, передаваемое генератору.            |

### Особенности поведения

В управляемом режиме `onValueChange(details)` синхронизирует значение с состоянием QR-кода. Это
исходный объект `details` от Ark, поэтому новое закодированное значение нужно читать из
`details.value`.

`QrCode.Context` и `useQrCodeContext()` предоставляют потомкам ближайший API QR-кода. В нём есть
текущее `value`, метод `setValue` и `getDataUrl()` для создания URL данных.

QR-код не является полем формы и не добавляет скрытое поле. У него нет специальной навигации
стрелками или перемещения фокуса внутри компонента. `QrCode.DownloadTrigger` является нативной
кнопкой, поэтому сохраняет обычное поведение кнопки: фокус, активацию с клавиатуры и отключённое
состояние.

SVG является визуальным содержимым. Если QR-код передаёт информацию, добавьте в `QrCode.Frame`
`role="img"` и `aria-label`. Если он повторяет расположенный рядом текст, оставьте этот текст и
добавьте для рамки `aria-hidden="true"`.

### Коррекция ошибок

С помощью `encoding.ecc` выберите, какой объём повреждённых данных QR-код сможет восстановить.
Высокие уровни полезны, если наложение закрывает часть кода или код может быть поцарапан либо
искажён.

- `L`: восстанавливает до 7% повреждённых данных.
- `M`: восстанавливает до 15%.
- `Q`: восстанавливает до 25%.
- `H`: восстанавливает до 30%.

## Стилизация

Moduix добавляет стили на основе токенов для размера и отступов QR-кода, заливки, наложения и кнопки
скачивания. Используйте `className` для стилей конкретного компонента, а стабильные атрибуты
`data-slot` для общих селекторов. Полный список публичных переменных приведён в таблице CSS Variables.

Ark также задаёт в корневом элементе во время выполнения переменные `--qrcode-pixel-size`,
`--qrcode-width` и `--qrcode-height`. Они описывают размеры созданной рамки и могут пригодиться для
собственных стилей.

### Атрибуты для стилизации

- `QrCode.Root` -> `data-slot="qr-code-root"`
- `QrCode.RootProvider` -> `data-slot="qr-code-root-provider"`
- `QrCode.Frame` -> `data-slot="qr-code-frame"`
- `QrCode.Pattern` -> `data-slot="qr-code-pattern"`
- `QrCode.Overlay` -> `data-slot="qr-code-overlay"`
- `QrCode.DownloadTrigger` -> `data-slot="qr-code-download-trigger"`
- Атрибуты Ark: `data-scope="qr-code"` и `data-part="root|frame|pattern|overlay|download-trigger"`
