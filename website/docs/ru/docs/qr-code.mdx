## Использование

<Usage />

Используйте `QrCode` в обычном сценарии. Передайте содержимое для кодирования через `defaultValue`,
затем явно отрисуйте `QrCodeFrame` и `QrCodePattern`, чтобы показать созданный SVG. Если QR-код
передаёт информацию, задайте для `QrCodeFrame` доступное имя.

## Примеры

### Заливка

По умолчанию модули QR-кода используют `currentColor`. Измените заливку SVG через `style` или класс
на `QrCodeFrame` либо задайте цвет текста родителю.

<Example name="qr-code/fill" />

### Наложение

Используйте `QrCodeOverlay` для компактного логотипа или текстовой отметки. Задайте высокий
уровень коррекции ошибок и оставьте наложение достаточно маленьким, чтобы сканеры продолжали
распознавать код.

<Example name="qr-code/overlay" />

### Коррекция ошибок

Используйте `encoding.ecc`, чтобы выбрать объём повреждений, который QR-код сможет восстановить.
Более высокие уровни подходят, если часть кода закрывает наложение или код может быть поцарапан
или искажён.

- `L`: восстанавливает до 7% повреждённых данных.
- `M`: до 15%.
- `Q`: до 25%.
- `H`: до 30%.

<Example name="qr-code/error-correction" />

### Скачивание

Добавьте `QrCodeDownloadTrigger`, если пользователям нужно сохранить QR-код как изображение.
Укажите в триггере и `fileName`, и `mimeType`.

<Example name="qr-code/download" />

### Поле ввода

Свяжите `value` с текстовым полем, если пользователям нужно вводить или редактировать содержимое,
закодированное в QR-коде. Задайте для frame доступное имя, объясняющее, что представляет код.

<Example name="qr-code/input" />

### Управляемое значение

Управляйте `value`, если QR-код должен следовать выбранному адресу или другой части состояния
приложения. Подробнее в разделе [Управляйте состоянием из приложения](/docs/composition-patterns#controlled-state).

<Example name="qr-code/controlled" />

### Root Provider

Создайте состояние QR-кода через `useQrCode()`, если его нужно разделить с контролами за пределами
дерева QR-кода, затем передайте состояние в `QrCodeRootProvider`. Подробнее в разделе [Выносите состояние за пределы дерева](/docs/composition-patterns#root-provider).

## Композиция

Используйте `defaultValue` для неконтролируемого QR-кода. Если значение хранится в состоянии
приложения, передайте `value` и `onValueChange(details)`, а новое значение читайте из
`details.value`. Создайте состояние через `useQrCode()` из соответствующего фреймворку пакета и
передайте его в `QrCodeRootProvider`, если состояние должно использоваться за пределами дерева
QR-кода. Не создавайте для одного хранилища одновременно `QrCode` и `QrCodeRootProvider`.

Используйте `QrCodeContext` или `useQrCodeContext()`, когда потомку нужен текущий API QR-кода.
Добавляйте `QrCodeOverlay` только при достаточном уровне коррекции ошибок для закрытой области и
проверяйте итоговый код сканерами, которыми пользуются ваши пользователи.

## Стилизация

Используйте `className` в React или `class` в Solid и Vue на экспортируемых частях для структурных
стилей. Варианты Tailwind используют нативные утилиты и классы потребителя, а переменные ниже
настраивают варианты CSS Modules. Атрибуты данных и хуки `data-slot` общие для обоих вариантов
стилизации.

Панель CSS Variables содержит полный набор публичных переменных. Ark также задаёт на корневом
элементе во время работы `--qrcode-pixel-size`, `--qrcode-width` и `--qrcode-height`.

## Справочник API

| Проп | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `value` | `string` | — | Кодируемое значение в управляемом режиме. |
| `defaultValue` | `string` | — | Начальное значение, если оно не управляется извне. |
| `onValueChange` | `(details: ValueChangeDetails) => void` | — | Вызывается при изменении значения. |
| `encoding` | `QrCodeGenerateOptions` | — | Параметры кодирования, например уровень коррекции ошибок. |
| `pixelSize` | `number` | — | Размер одного модуля QR в пикселях. |
