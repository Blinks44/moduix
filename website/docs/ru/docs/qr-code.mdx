## Базовый пример

QrCode доступен для React и Solid в пакетах CSS Modules и Tailwind. Превью на этой странице
использует пакет React CSS Modules, а во вкладках фреймворков показан нативный исходный код для

затем явно отрисуйте `QrCode.Frame` и `QrCode.Pattern`, чтобы показать созданный SVG. Если QR-код
передаёт информацию, задайте для `QrCode.Frame` доступное имя.

## Анатомия

```text
QrCode / QrCode.Root
├─ QrCode.Frame
│  └─ QrCode.Pattern
├─ QrCode.Overlay
└─ QrCode.DownloadTrigger

QrCode.RootProvider
└─ то же дерево частей, подключённое к хранилищу useQrCode()
```

| Part                     | Назначение                                                            |
| ------------------------ | --------------------------------------------------------------------- |
| `QrCode` / `QrCode.Root` | Хранит кодируемое значение и параметры генерации, предоставляет состояние QR-кода. |
| `QrCode.RootProvider`    | Подключает части к состоянию, созданному через `useQrCode()`.          |
| `QrCode.Frame`           | SVG-элемент, содержащий созданный QR-код.                              |
| `QrCode.Pattern`         | SVG-путь, который рисует модули QR-кода.                               |
| `QrCode.Overlay`         | Содержимое, отображаемое по центру QR-кода.                            |
| `QrCode.DownloadTrigger` | Кнопка для скачивания текущего QR-кода как изображения.                |

## Композиция

Используйте `defaultValue` для неконтролируемого QR-кода. Если значение хранится в состоянии
приложения, передайте `value` и `onValueChange(details)`, а новое значение читайте из
`details.value`. Создайте состояние через `useQrCode()` из соответствующего фреймворку пакета и
передайте его в `QrCode.RootProvider`, если состояние должно использоваться за пределами дерева
QR-кода. Не создавайте для одного хранилища одновременно `QrCode` и `QrCode.RootProvider`.

Используйте `QrCode.Context` или `useQrCodeContext()`, когда потомку нужен текущий API QR-кода.
Добавляйте `QrCode.Overlay` только при достаточном уровне коррекции ошибок для закрытой области и
проверяйте итоговый код сканерами, которыми пользуются ваши пользователи.

### Коррекция ошибок

Используйте `encoding.ecc`, чтобы выбрать объём повреждений, который QR-код сможет восстановить.
Более высокие уровни подходят, если часть кода закрывает наложение или код может быть поцарапан
или искажён.

- `L`: восстанавливает до 7% повреждённых данных.
- `M`: до 15%.
- `Q`: до 25%.
- `H`: до 30%.

## Стилизация

Используйте `className` в React или `class` в Solid на экспортируемых частях для структурных
стилей. Варианты Tailwind используют нативные утилиты и классы потребителя, а переменные ниже
настраивают варианты CSS Modules. Атрибуты данных и хуки `data-slot` общие для обоих вариантов
стилизации.

Панель CSS Variables содержит полный набор публичных переменных. Ark также задаёт на корневом
элементе во время работы `--qrcode-pixel-size`, `--qrcode-width` и `--qrcode-height`.

### Атрибуты для стилизации

- Стабильные селекторы `data-slot`: `qr-code-root`, `qr-code-root-provider`, `qr-code-frame`,
  `qr-code-pattern`, `qr-code-overlay` и `qr-code-download-trigger`.
- Селекторы частей Ark: `data-scope="qr-code"` и
  `data-part="root|frame|pattern|overlay|download-trigger"`.
