# Справа налево (RTL)

RTL-интерфейсу нужны две согласованные настройки: нативные атрибуты `lang` и `dir` для браузерной
раскладки и Moduix `LocaleProvider` для поведения Ark с учетом локали. Задавайте их на самом верхнем
уровне, которому принадлежит язык.

## Настройте документ

Для RTL-локали всего приложения укажите `lang` и `dir` на `<html>`:

```html
<html lang="ar" dir="rtl"></html>
```

Оберните приложение в provider нативного адаптера:

<Tabs groupId="framework">
  <Tab label="React" value="react">

```tsx
import { LocaleProvider } from '@moduix/react/locale';

<LocaleProvider locale="ar-EG">{children}</LocaleProvider>;
```

  </Tab>
  <Tab label="Solid" value="solid">

```tsx
import { LocaleProvider } from '@moduix/solid/locale';

<LocaleProvider locale="ar-EG">{props.children}</LocaleProvider>;
```

  </Tab>
</Tabs>

`LocaleProvider` определяет направление Ark по локали, но не меняет нативные атрибуты документа. При
смене языка без перезагрузки обновляйте `lang`, `dir` и локаль provider одновременно.

## Ограничьте RTL отдельной областью

Для RTL-области внутри LTR-приложения задайте `lang` и `dir` на ее корне и оберните компоненты Moduix
в `LocaleProvider`.

<CodeBlockRuntime lang="tsx" code={reactSection} />

  </Tab>
  <Tab label="Solid" value="solid">

Коллекция импортируется из соответствующего адаптера Ark UI, а Select, Button и LocaleProvider из
соответствующего адаптера Moduix. Отдельное RTL-свойство компонентам не требуется.

## Учтите порталы и смешанное направление

Портальное содержимое наследует CSS-направление от целевого контейнера, а не от триггера. Для локали
всего приложения используйте направление документа. Для отдельной области создайте portal-контейнер
внутри RTL-поддерева.

Для смешанного содержимого:

- используйте `dir="auto"` для текста с неизвестным направлением;
- задавайте `dir="ltr"` адресам электронной почты, URL, кодам и телефонным номерам;
- сохраняйте направление приложения на внешнем контейнере.

## Используйте логические свойства

Если правило зависит от направления чтения, выбирайте логические свойства:

```css
.item {
  padding-inline: var(--moduix-spacing-4);
  border-inline-start: var(--moduix-border-width-sm) solid var(--moduix-color-border);
  text-align: start;
}
```

Оставляйте `left` и `right` только для физической геометрии, например координаты индикатора, границы
изменения размера или явного направления жеста. Зеркально отражайте только иконки с направленным
смыслом, но не play, check, download и логотипы.

## Проверьте RTL перед выпуском

- Поля с кнопками очистки и дополнительными действиями.
- Триггеры Select, Combobox и Date Picker.
- Портальные Dialog, Popover, Menu и Tooltip.
- Клавиатурную навигацию и видимый порядок фокуса.
- Арабский или иврит рядом с адресами, числами и кодами.
- Направленные иконки, жесты и выравнивание на узких экранах.
