## Справочник API

В Ark UI нет отдельного компонента `Text`. В moduix это типографический компонент, построенный на официальной
[фабрике Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory). Он следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[работе с `ref`](https://ark-ui.com/docs/guides/ref).

## Выбор подходящего компонента

Используйте `Text` для обычного и вспомогательного текста, встроенных акцентов и других текстовых элементов интерфейса,
которые должны соответствовать типографической шкале moduix.

- Выбирайте **`Heading`** для структуры документа и иерархии заголовков.
- Выбирайте **`Text`**, когда содержимое должно сохранять семантику абзаца или встроенного текста и использовать стили основного текста.
- Используйте локальный CSS, если нужно управлять разметкой форматированного текста, отступами или раскрытием усечённого текста.

## Анатомия

`Text` выводит один корневой элемент с помощью фабрики Ark через плоский корневой экспорт.

```text
Text
└─ текст или встроенное содержимое
```

| Часть                 | Назначение                                                       |
| --------------------- | ---------------------------------------------------------------- |
| `Text`              | Типографический корневой элемент с семантическим HTML и стабильными data-атрибутами. |

## Композиция

`Text` состоит только из корневого элемента и не владеет состоянием или дочерними частями. Используйте `<Text>`
для корня, `as` для поддерживаемого семантического элемента, а `asChild` только
когда один существующий элемент должен получить свойства и `ref` текста. Усечение ограничивает только отображение,
поэтому состояние раскрытия и управляющий элемент остаются в окружающем интерфейсе.

## Стилизация

Передайте `className` в React или `class` в Solid и Vue на `Text`. Варианты Tailwind используют
утилиты и классы приложения. Варианты CSS Modules построены на типографских токенах foundation и не
имеют собственных переменных: класс на корне переопределяет стили компонента из слоя.

### Хуки стилизации

- `data-scope="text"` и `data-part="root"` идентифицируют корневой элемент Ark.
- `data-slot="text-root"` - стабильный селектор moduix на корневом элементе компонента.
- `data-size` отражает вычисленный визуальный размер: `xs`, `sm`, `md`, `lg` или `xl`.
- `data-weight` отражает вычисленную насыщенность: `regular`, `medium`, `semibold` или `bold`.
- `data-tone` отражает активный вариант тона: `default`, `muted`, `primary` или `destructive`.
- `data-align` появляется, только когда `align` задан как `start`, `center`, `end`, `left`, `right` или `justify`. Без него `Text` наследует выравнивание контейнера.
- `data-truncate` появляется при активном однострочном усечении с многоточием.
- `data-line-clamp` появляется, когда `lineClamp` - положительное целое число; количество строк задаётся
  инлайн-стилем `-webkit-line-clamp`.
