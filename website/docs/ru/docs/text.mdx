## Справочник API

В Ark UI нет отдельного компонента `Text`. В moduix это типографический компонент, построенный на официальной
[фабрике Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory). Он следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[работе с `ref`](https://ark-ui.com/docs/guides/ref).

## Выбор подходящего компонента

Используйте `Text` для обычного и вспомогательного текста, встроенных акцентов и других текстовых элементов интерфейса,
которые должны соответствовать типографической шкале moduix.

- Выбирайте **`Heading`** для структуры документа и иерархии заголовков.
- Выбирайте **`Text`**, когда содержимое должно сохранять семантику абзаца или встроенного текста и использовать стили основного текста.
- Используйте локальный CSS, если нужно управлять разметкой форматированного текста, отступами или раскрытием усечённого текста.

## Анатомия

`Text` выводит один корневой элемент с помощью фабрики Ark. Варианты `<Text>` и `<Text.Root>` делают одно и то же.

```text
Text / Text.Root
└─ текст или встроенное содержимое
```

| Часть                 | Назначение                                                       |
| --------------------- | ---------------------------------------------------------------- |
| `Text` / `Text.Root` | Типографический корневой элемент с семантическим HTML и стабильными data-атрибутами. |

## Композиция

### Рекомендуемая композиция

Используйте краткую запись `<Text>` для обычного текста и подписей. Она эквивалентна `<Text.Root>`, по умолчанию
выводит `p` и передаёт `ref` на получившийся `HTMLElement`.

### Когда нужна собственная композиция

Используйте `as`, чтобы выбрать поддерживаемый встроенный HTML-элемент и изменить семантику. Используйте `asChild`,
если уже существующий элемент, например ссылка, должен стать корневым и получить класс moduix, стиль, data-атрибуты
и `ref`. Дочерний элемент должен быть единственным и принимать передаваемые свойства.

`Text` также принимает стандартные HTML-атрибуты корневого элемента, включая `className`, `style`, обработчики
событий и переданный `ref`.

### Значения по умолчанию

| Свойство    | По умолчанию                         | Примечания                                                    |
| ----------- | ------------------------------------ | ------------------------------------------------------------- |
| `as`        | `p`                                  | `p`, `span`, `small`, `strong`, `em` или `div`.               |
| `asChild`   | `false`                              | Использует единственный дочерний элемент как корневой.       |
| `size`      | Зависит от элемента                  | Для `small` по умолчанию `sm`; для остальных элементов `md`. |
| `weight`    | Зависит от элемента                  | Для `strong` по умолчанию `semibold`; для остальных `regular`. |
| `tone`      | `default`                            | `default`, `muted`, `subtle`, `primary` или `destructive`.   |
| `align`     | Не задано (визуально `start`)        | `start`, `center`, `end`, `left`, `right` или `justify`.     |
| `truncate`  | `false`                              | Усечение одной строки с многоточием через CSS.               |
| `lineClamp` | Не задано                            | Положительное целое число; некорректные значения отключают ограничение. |

### Особенности поведения

`Text` отвечает за оформление и семантику текста. Он не управляет состоянием, клавиатурными взаимодействиями или
раскрытием содержимого. `truncate` и `lineClamp` задают только визуальные CSS-ограничения. Кнопку или другой элемент
управления для показа полного текста нужно добавить отдельно.

Оформляйте `Text` с помощью `className`, data-атрибутов корневого элемента и публичных CSS-переменных
`--moduix-text-*`, перечисленных в справочнике CSS API.

### Хуки стилизации

- `data-scope="text"` и `data-part="root"` идентифицируют корневой элемент Ark.
- `data-slot="text-root"` - стабильный селектор moduix на корневом элементе компонента.
- `data-size` отражает вычисленный визуальный размер: `xs`, `sm`, `md`, `lg` или `xl`.
- `data-weight` отражает вычисленную насыщенность: `regular`, `medium`, `semibold` или `bold`.
- `data-tone` отражает активный вариант тона: `default`, `muted`, `subtle`, `primary` или `destructive`.
- `data-align` появляется, только когда `align` явно задан как `start`, `center`, `end`, `left`, `right` или `justify`.
- `data-truncate` появляется при активном однострочном усечении с многоточием.
- `data-line-clamp` появляется, когда `lineClamp` - положительное целое число. В этом случае `lineClamp` задаёт
  резервное количество строк. Укажите `--moduix-text-line-clamp`, чтобы переопределить его через публичный CSS API.
