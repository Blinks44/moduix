## Использование в маршруте

Рендерите `VerificationCode` после того, как приложение отправит код по электронной почте, и передайте ему настоящий обработчик
отправки. `onSubmit` получает нативное событие формы, поэтому прочитайте `new FormData(event.currentTarget)`
и проверьте значение `code` на сервере. Замените стандартную ссылку `/sign-in` маршрутом
своего приложения.

В превью намеренно нет сервера подтверждения. После шести цифр запускается его пустой обработчик отправки;
скопированный рецепт вместо этого запускает переданный вами обработчик.

Отключайте повторную проверку, пока ожидается выполнение запроса. Для недействительного кода сохраняйте введённые
цифры и прикрепляйте ошибку к полю; для просроченного кода объясняйте, что требуется новый код. Добавьте повторную отправку
после короткой задержки, объявляйте об отправке нового кода и позвольте серверу обеспечить фактическое ограничение частоты. Никогда не считайте обратный отсчёт на клиенте авторизацией.
