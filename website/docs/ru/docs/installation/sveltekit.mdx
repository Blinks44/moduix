# SvelteKit

В этом руководстве предполагается, что у вас уже есть приложение на SvelteKit 3, созданное через
`sv create`. SvelteKit рендерит Svelte-компоненты на сервере и гидратирует их в браузере.

## Выберите вариант настройки

- **Среда:** Svelte 5.29 или более поздняя версия из ветки 5.x, предоставляемая SvelteKit.
- **Стилизация:** CSS Modules или Tailwind CSS v4, уже настроенный в приложении.
- **Поставка:** пакет или исходный код, добавленный через shadcn CLI.

Выберите Svelte в общей [настройке пакета](/docs/quick-start#установить-как-пакет) или
[настройке shadcn](/docs/quick-start#установить-через-shadcn-cli). SvelteKit использует `@moduix/svelte` и
`@moduix/svelte-tailwind` либо пространства имён реестра `@moduix-svelte` и `@moduix-svelte-tailwind`.

Svelte-пакеты публикуют исходники `.svelte` с условием экспорта `svelte`. Vite-плагин SvelteKit
компилирует их вместе с приложением для сервера и браузера, включая CSS Modules компонентов, поэтому
дополнительная настройка Vite или SSR для пакета не нужна.

```svelte title="src/routes/+layout.svelte"

  import '@moduix/svelte/reset.css';

  let { children } = $props();

{@render children()}
```

## Установка через shadcn CLI

Выполните общую [настройку shadcn](/docs/quick-start#установить-через-shadcn-cli), выбрав пространство
имён Svelte для нужного варианта стилей. Оставьте `rsc: false`; используйте указанный здесь CLI
`shadcn` с реестром moduix.

Исходники из реестра импортируют общие файлы через `@/lib/moduix`, а SvelteKit предоставляет для
`src/lib` алиас `#lib`. Привяжите `@/*` к `src/*` в корневом `tsconfig.json` для TypeScript и CLI
и оставьте сгенерированную конфигурацию SvelteKit в `extends`:

```json title="tsconfig.json"
{
  "extends": "$app/tsconfig",
  "compilerOptions": {
    "strict": true,
    "paths": {
      "@/*": ["./src/*"]
    }
  },
  "include": ["src", "vite.config.ts"]
}
```

SvelteKit 3 читает конфигурацию из `sveltekit({...})` в `vite.config.ts`, а не из
`svelte.config.js`. Добавьте алиас для рантайма в конфигурацию Vite и сохраните текущие параметры
плагина:

```ts title="vite.config.ts"
import { fileURLToPath, URL } from 'node:url';
import { sveltekit } from '@sveltejs/kit/vite';
import { defineConfig } from 'vite';

export default defineConfig({
  plugins: [
    sveltekit({
      // Keep your adapter and other SvelteKit options here.
    }),
  ],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url)),
    },
  },
});
```

Для Tailwind перед добавлением компонента укажите `src/routes/layout.css` в поле `tailwind.css`
файла `components.json` и оставьте `tailwind.config` пустым для v4.

```svelte title="src/routes/+layout.svelte"
</div>

<style>
  .app-root {
    isolation: isolate;
  }
</style>
```

## Проверка

Запустите сервер разработки, затем соберите приложение для production и проверьте его в режиме
предпросмотра. Исходный ответ сервера должен содержать Accordion и его стили. В браузере компонент
должен гидратироваться без предупреждений и реагировать на клавиатуру и указатель. При установке
через реестр убедитесь, что импорты разрешаются в `src/components` и `src/lib`.

См. официальную документацию SvelteKit по [созданию проекта](https://svelte.dev/docs/kit/creating-a-project),
[конфигурации](https://svelte.dev/docs/kit/configuration) и
[адаптерам](https://svelte.dev/docs/kit/adapters).
