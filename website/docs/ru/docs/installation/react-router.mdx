# React Router

Эта инструкция посвящена React Router в режиме Framework. Если приложение уже работает в этом режиме, подключите
moduix по шагам ниже. Для режимов Data и Declarative используйте [настройку Vite](/docs/installation/vite): импорты
moduix останутся теми же.

## Выберите вариант настройки

- **Среда:** React в режиме Framework. Для режимов Data и Declarative используйте руководство по Vite.
- **Стилизация:** CSS Modules или Tailwind CSS v4.
- **Поставка:** пакет или исходный код, добавленный через shadcn CLI.

Сначала выполните общую [настройку пакета](/docs/quick-start#установить-как-пакет) или
[настройку shadcn](/docs/quick-start#установить-через-shadcn-cli) для выбранного варианта стилей. Ниже
показаны импорты пакета на CSS Modules; файлы React Router, алиасы, SSR и проверка гидратации остаются
такими же для Tailwind-пакета или реестра React.

Все показанные ниже команды установки пакетов и импорты таблиц стилей относятся к CSS Modules.
Используйте показанный ниже reset moduix или корректный собственный reset приложения. С Tailwind сохраняйте
глобальную таблицу стилей, настроенную в Быстром старте.

## Установка из пакета

<PackageManagerTabs command="install @moduix/react @ark-ui/react" />

В режиме Framework React Router отображает модули маршрутов внутри `app/root.tsx`. Один раз импортируйте туда базовые
стили:

```tsx title="app/root.tsx"
import '@moduix/react/reset.css';
import '@moduix/react/style.css';
```

Зарегистрируйте маршрут в `app/routes.ts`:

```tsx title="app/routes.ts"
import { type RouteConfig, index } from '@react-router/dev/routes';

export default [index('routes/home.tsx')] satisfies RouteConfig;
```

Используйте компонент moduix в модуле маршрута:

```tsx title="app/routes/home.tsx"
import { Button } from '@moduix/react/button';

export default function Home() {
  return <Button>Continue</Button>;
}
```

Индексный маршрут открывается по адресу `/`, поэтому после запуска сервера разработки перейдите на этот адрес.

## Установка через shadcn CLI

Выберите этот способ, если хотите хранить исходный код компонентов и стили в своём репозитории. Сначала завершите
[настройку shadcn CLI](/docs/quick-start#установить-через-shadcn-cli). В стандартном шаблоне React Router код
приложения находится в `app`, поэтому сопоставьте `@/*` с `app/*`, а не с `src/*`:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./app/*"]
    }
  }
}
```

Режим Framework использует Vite. Добавьте такой же алиас в конфигурацию сборщика по [инструкции для Vite](/docs/installation/vite#установка-через-shadcn-cli), заменив `./src` на `./app`. Сохраните плагин React Router и остальные настройки Vite, которые уже есть в проекте.

Добавьте Button из пространства имён для выбранного варианта стилизации:

<ShadcnInstallOptions options={[{ label: 'CSS Modules', command: 'shadcn@latest add @moduix-react/button' }, { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-react-tailwind/button' }]} />

После генерации файлов замените импорт таблицы стилей пакета в `app/root.tsx` на импорт сгенерированного файла:

```tsx title="app/root.tsx"
import '@/lib/moduix/styles/style.css';
```

Не подключайте обе таблицы стилей одновременно. В варианте с исходным кодом в репозитории базовой таблицей служит
сгенерированный файл.

## Проверка

Запустите сервер разработки и откройте `/`. Страница должна отрендериться на сервере, пройти гидратацию без
расхождений и сохранить работоспособность интерактивных компонентов после гидратации. Не меняйте разметку во время
рендеринга в зависимости от глобальных объектов браузера.

Полную настройку фреймворка смотрите в [руководстве по установке React Router](https://reactrouter.com/start/framework/installation) и [руководстве по маршрутизации](https://reactrouter.com/start/framework/routing).
