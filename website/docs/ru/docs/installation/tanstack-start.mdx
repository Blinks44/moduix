# TanStack Start

Руководство предполагает существующее приложение TanStack Start, настроенное для React или Solid.
Start может использовать Vite или Rsbuild, рендерит дерево маршрутов на сервере и гидратирует его в
браузере; в обычной конфигурации moduix не требует директивы `use client`.

## Выберите вариант настройки

- **Среда:** React или Solid с соответствующим адаптером TanStack Start.
- **Стилизация:** CSS Modules или Tailwind CSS v4.
- **Поставка:** пакет или исходный код, добавленный через shadcn CLI.

Сначала выполните общую [настройку пакета](/docs/quick-start#установить-как-пакет) или
[настройку shadcn](/docs/quick-start#установить-через-shadcn-cli) для выбранного варианта стилей. Ниже
показаны импорты пакетов на CSS Modules; расположение корневого маршрута, алиасы, SSR и проверка
гидратации не меняются при выборе соответствующего Tailwind-пакета или реестра.

Все показанные ниже команды установки пакетов и импорты таблиц стилей относятся к CSS Modules. С Tailwind сохраняйте глобальную
таблицу стилей, настроенную в Быстром старте.

## Установка через shadcn CLI

Выполните [первоначальную настройку shadcn CLI](/docs/quick-start#установить-через-shadcn-cli). Если в
стартовом проекте ещё нет алиаса `@/*` для `src/*`, добавьте его в корневой `tsconfig.json`:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Тот же алиас должен быть доступен сборщику. Rsbuild читает пути TypeScript автоматически, а для Vite
следуйте руководству TanStack Start по алиасам. Затем добавьте компонент:

<Tabs groupId="framework">
  <Tab label="React" value="react">

<ShadcnInstallOptions options={[{ label: 'CSS Modules', command: 'shadcn@latest add @moduix-react/button' }, { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-react-tailwind/button' }]} />

  </Tab>
  <Tab label="Solid" value="solid">

<ShadcnInstallOptions options={[{ label: 'CSS Modules', command: 'shadcn@latest add @moduix-solid/button' }, { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-solid-tailwind/button' }]} />

  </Tab>
</Tabs>

Замените импорт стилей из пакета на импорт сгенерированного файла в корневом маршруте:

```tsx title="src/routes/__root.tsx"
import '@/lib/moduix/styles/style.css';
```

## Проверка

Запустите сервер разработки и откройте `/`. Серверная версия страницы должна сразу получить стили
moduix, а гидратация должна пройти без расхождений. Не используйте в серверном рендеринге браузерные
API и значения, которые могут различаться на сервере и клиенте.

Продолжить настройку можно по официальным руководствам TanStack Start для
[React](https://tanstack.com/start/latest/docs/framework/react/getting-started) или
[Solid](https://tanstack.com/start/latest/docs/framework/solid/getting-started).
