# TanStack Start

Эта инструкция предполагает, что приложение TanStack Start уже создано. TanStack Start сначала рендерит дерево
маршрутов на сервере, а затем гидратирует его в браузере. moduix работает и с Vite, и с Rsbuild. В стандартной
конфигурации без React Server Components директива `use client` не нужна.

## Установить как пакет

<PackageManagerTabs command="install @moduix/react @ark-ui/react" />

Один раз импортируйте базовые стили в корневом маршруте. В стандартном проекте TanStack Start корневой маршрут
находится в `src/routes/__root.tsx`:

```tsx title="src/routes/__root.tsx"
import '@moduix/react/style.css';
```

Используйте компонент moduix в маршруте:

```tsx title="src/routes/index.tsx"
import { createFileRoute } from '@tanstack/react-router';
import { Button } from '@moduix/react/button';

export const Route = createFileRoute('/')({
  component: Home,
});

function Home() {
  return <Button>Continue</Button>;
}
```

## Установить через shadcn CLI

Выберите этот способ, если хотите хранить исходный код компонентов и стили в своём репозитории. Сначала завершите
[настройку shadcn CLI](/docs/quick-start#установить-через-shadcn-cli).

По умолчанию TanStack Start не настраивает алиасы путей. Если стартовый шаблон уже связывает `@/*` с `src/*`,
оставьте этот алиас. В противном случае добавьте его в корневой `tsconfig.json`:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Затем настройте тот же алиас в сборщике. Для Vite используйте [руководство TanStack Start по алиасам путей](https://tanstack.com/start/latest/docs/framework/react/guide/path-aliases).
Rsbuild автоматически читает `paths` из корневого `tsconfig.json`.

Замените импорт стилей пакета в корневом маршруте на сгенерированные стили. Не подключайте обе таблицы стилей:

```tsx title="src/routes/__root.tsx"
import '@/lib/moduix/styles/style.css';
```

## Проверьте интеграцию

Запустите сервер разработки и откройте `/`. Интеграция настроена правильно, если при первой отрисовке применяются
стили moduix, страница проходит гидратацию без расхождений, а кнопка реагирует на нажатия. Не обращайтесь к API
браузера и не выводите значения, которые могут отличаться на сервере и в браузере, в коде, выполняемом во время
серверного рендеринга.

Полную настройку TanStack Start см. в руководствах [«Начало работы»](https://tanstack.com/start/latest/docs/framework/react/getting-started)
и [«Создание проекта с нуля»](https://tanstack.com/start/latest/docs/framework/react/build-from-scratch).
