# TanStack Start

TanStack Start не зависит от конкретного сборщика и гидратирует компоненты маршрутов на клиенте. Поэтому компоненты
moduix работают в обычном дереве маршрутов без директивы `use client`. Поддерживаются и Vite, и Rsbuild.

## Установите пакет

<PackageManagerTabs command="install @moduix/react @ark-ui/react" />

Добавьте базовую таблицу стилей в глобальную таблицу стилей, уже загружаемую корневым маршрутом:

```css title="src/styles.css"
@import '@moduix/react/style.css';
```

Используйте компонент в маршруте:

```tsx title="src/routes/index.tsx"
import { createFileRoute } from '@tanstack/react-router';
import { Button } from '@moduix/react/button';

export const Route = createFileRoute('/')({
  component: Home,
});

function Home() {
  return <Button>Continue</Button>;
}
```

## Установка через shadcn CLI

Завершите [настройку shadcn CLI](/docs/quick-start#установить-через-shadcn-cli). Если стартовый шаблон уже связывает
`@/*` с `src/*`, оставьте этот алиас. В противном случае добавьте алиасы для TypeScript и используемого сборщика из
[настройки Vite](/docs/installation/vite#установка-через-shadcn-cli) или
[Rsbuild](/docs/installation/rsbuild#установка-через-shadcn-cli).

Замените импорт CSS пакета на сгенерированную таблицу стилей:

```css title="src/styles.css"
@import '@/lib/moduix/styles/style.css';
```

## Проверка

Настройка завершена, когда серверная страница гидратируется без расхождений, а интерактивный компонент отвечает
после гидратации. Как и в остальных частях TanStack Start, не выполняйте в серверном рендеринге код, предназначенный
только для браузера.

Полная настройка фреймворка приведена в [быстром старте TanStack Start](https://tanstack.com/start/latest/docs/framework/react/quick-start).
