# TanStack Start

В примерах ниже используются пакеты с CSS Modules, в которых доступен полный каталог компонентов.
Для компонентов на Tailwind выполните [настройку Tailwind-пакета](/docs/quick-start#настройте-tailwind-пакет)
и выберите пакет или реестр для React либо Solid.

TanStack Start поддерживает React и Solid и может собирать приложение с помощью Vite или Rsbuild.
Дерево маршрутов рендерится на сервере и гидратируется в браузере; в обычной конфигурации moduix не
требует директивы `use client`.

## Установка из пакета

Установите пакет для выбранного фреймворка:

  </Tab>
  <Tab label="Solid" value="solid">

<PackageManagerTabs command="install @moduix/solid @ark-ui/solid solid-js" />

  </Tab>

Один раз импортируйте основные стили из `src/routes/__root.tsx`:

<Tabs groupId="framework">
  <Tab label="React" value="react">

```tsx title="src/routes/__root.tsx"
import '@moduix/react/style.css';
```

  </Tab>
  <Tab label="Solid" value="solid">

```tsx title="src/routes/__root.tsx"
import '@moduix/solid/style.css';
```

  </Tab>
</Tabs>

Используйте компонент в маршруте:

<Tabs groupId="framework">
  <Tab label="React" value="react">

```tsx title="src/routes/index.tsx"
import { createFileRoute } from '@tanstack/react-router';
import { Button } from '@moduix/react/button';

export const Route = createFileRoute('/')({
  component: Home,
});

function Home() {
  return <Button>Continue</Button>;
}
```

  </Tab>
  <Tab label="Solid" value="solid">

```tsx title="src/routes/index.tsx"
import { createFileRoute } from '@tanstack/solid-router';
import { Button } from '@moduix/solid/button';

export const Route = createFileRoute('/')({
  component: Home,

}
```

  </Tab>
</Tabs>

## Установка через shadcn CLI

Выполните [первоначальную настройку shadcn CLI](/docs/quick-start#установка-через-shadcn-cli). Если в
стартовом проекте ещё нет алиаса `@/*` для `src/*`, добавьте его в корневой `tsconfig.json`:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Тот же алиас должен быть доступен сборщику. Rsbuild читает пути TypeScript автоматически, а для Vite
следуйте руководству TanStack Start по алиасам. Затем добавьте компонент:

<Tabs groupId="framework">
  <Tab label="React" value="react">

<PackageManagerTabs command="shadcn@latest add @moduix-react/button" dlx />

  </Tab>
  <Tab label="Solid" value="solid">

<PackageManagerTabs command="shadcn@latest add @moduix-solid/button" dlx />

  </Tab>
</Tabs>

Замените импорт стилей из пакета на импорт сгенерированного файла в корневом маршруте:

```tsx title="src/routes/__root.tsx"
import '@/lib/moduix/styles/style.css';
```

## Проверка

Запустите сервер разработки и откройте `/`. Серверная версия страницы должна сразу получить стили
moduix, а гидратация должна пройти без расхождений. Не используйте в серверном рендеринге браузерные
API и значения, которые могут различаться на сервере и клиенте.

Продолжить настройку можно по официальным руководствам TanStack Start для
[React](https://tanstack.com/start/latest/docs/framework/react/getting-started) или
[Solid](https://tanstack.com/start/latest/docs/framework/solid/getting-started).
