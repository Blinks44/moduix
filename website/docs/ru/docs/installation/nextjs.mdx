# Next.js

В App Router подключайте CSS moduix в корневом layout, а интерактивные компоненты размещайте внутри клиентской
границы.

## Установите пакет

<PackageManagerTabs command="install @moduix/react @ark-ui/react" />

Один раз импортируйте базовую таблицу стилей в корневом layout:

```tsx title="app/layout.tsx"
import '@moduix/react/style.css';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  );
}
```

Собирайте интерактивные компоненты moduix в клиентском компоненте:

```tsx title="app/continue-button.tsx"
'use client';

import { Button } from '@moduix/react/button';

export function ContinueButton() {
  return <Button>Continue</Button>;
}
```

Серверные компоненты могут рендерить обычную разметку вокруг этой границы. Вместо обработчиков событий передавайте
в клиентский компонент сериализуемые данные.

## Установка через shadcn CLI

Завершите [настройку shadcn CLI](/docs/quick-start#установить-через-shadcn-cli), указав `rsc: true`. Сохраните
стандартный алиас `@/*` из стартового шаблона Next.js и импортируйте сгенерированную базовую таблицу стилей из
корневого layout:

```tsx title="app/layout.tsx"
import '@/lib/moduix/styles/style.css';
```

При `rsc: true` shadcn CLI сохраняет директиву `use client`, уже указанную в исходном файле компонента реестра;
она не определяет сама, нужна ли директива компоненту. Добавьте директиву в собственную составную обёртку, если
она содержит состояние, эффекты или обработчики событий.

## Проверка

Настройка завершена, когда стили есть уже в первом ответе, а интерактивные компоненты не вызывают ошибок границы
между сервером и клиентом или гидратации.

См. руководства Next.js по [CSS](https://nextjs.org/docs/app/getting-started/css) и
[директиве `use client`](https://nextjs.org/docs/app/api-reference/directives/use-client).
