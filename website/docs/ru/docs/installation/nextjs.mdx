# Next.js

Руководство предполагает существующий Next.js-проект с App Router. Импортируйте базовые стили из
корневого `app/layout.tsx`, а директиву `'use client'` добавляйте только в те компоненты, которым
нужна клиентская логика.

## Выберите вариант настройки

- **Среда:** React с App Router в Next.js.
- **Стилизация:** CSS Modules или Tailwind CSS v4.
- **Поставка:** пакет или исходный код, добавленный через shadcn CLI.

Выбор пакета и настройка реестра описаны в Быстром старте: [пакеты](/docs/quick-start#установить-как-пакет)
и [shadcn CLI](/docs/quick-start#установить-через-shadcn-cli).

Примеры ниже используют CSS Modules и reset moduix. Если в приложении уже есть подходящий reset,
не импортируйте его повторно. Для Tailwind установите соответствующий пакет с суффиксом `-tailwind`
и в той же точке входа подключите файл стилей приложения, настроенный по Quick Start.

## Установка из пакета

<PackageManagerTabs command="install @moduix/react @ark-ui/react" />

Один раз импортируйте базовый файл стилей из файла `app/layout.tsx` в корне приложения:

```tsx title="app/layout.tsx"
import '@moduix/react/reset.css';
import '@moduix/react/style.css';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  );
}
```

Компоненты, которые только выводят разметку, можно оставить серверными. Добавьте директиву `'use client'` в собственный
компонент, если он использует состояние, эффекты, браузерные API или обработчики событий:

```tsx title="app/continue-button.tsx"
'use client';

import { useState } from 'react';
import { Button } from '@moduix/react/button';

export function ContinueButton() {
  const [isComplete, setIsComplete] = useState(false);

  return (
    <Button type="button" onClick={() => setIsComplete(true)}>
      {isComplete ? 'Done' : 'Continue'}
    </Button>
  );
}
```

Подключите клиентский компонент из серверного:

```tsx title="app/page.tsx"
import { ContinueButton } from './continue-button';

export default function Page() {
  return (
    <main>
      <ContinueButton />
    </main>
  );
}
```

Модули moduix с клиентской логикой содержат директиву `'use client'` и в пакете, и в исходниках реестра.
Серверный компонент может рендерить их с сериализуемыми props. Вашему компоненту нужна клиентская граница,
если он передаёт обработчики событий или функции рендеринга.

## Установка через shadcn CLI

Выберите этот способ, если хотите скопировать компоненты moduix в своё приложение. Завершите [настройку shadcn CLI](/docs/quick-start#установить-через-shadcn-cli) и укажите `"rsc": true` в `components.json`.

Сохраните стандартный алиас `@/*` из стартового шаблона Next.js. Если вы используете другие алиасы, обновите
`components.json` и пути к сгенерированным файлам. При этом способе импортируйте сгенерированный базовый файл стилей
из файла `app/layout.tsx` в корне приложения вместо `@moduix/react/style.css`:

<ShadcnInstallOptions options={[{ label: 'CSS Modules', command: 'shadcn@latest add @moduix-react/button' }, { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-react-tailwind/button' }]} />

```tsx title="app/layout.tsx"
import '@/lib/moduix/styles/style.css';
```

Импорт стилей выше относится к CSS Modules. Для Tailwind подключите сгенерированные базовые стили
в существующем файле Tailwind по [Quick Start](/docs/quick-start#установить-через-shadcn-cli),
а сам файл импортируйте в той же точке входа. Замените импорт компонента из пакета
на `@/components/ui/button`.

При `rsc: true` shadcn CLI сохраняет директиву `'use client'`, уже указанную в исходном файле компонента реестра. CLI
не определяет автоматически, нужна ли директива скопированному компоненту или вашей обёртке. Добавьте её в свою
обёртку, если она использует состояние, эффекты, браузерные API или обработчики событий.

## Проверка

Интеграция настроена правильно, если стили применяются уже при первой отрисовке, интерактивные компоненты работают
после гидратации, а Next.js не сообщает об ошибках на границе между сервером и клиентом и об ошибках гидратации.

См. руководства Next.js по [CSS](https://nextjs.org/docs/app/getting-started/css) и
[директиве `use client`](https://nextjs.org/docs/app/api-reference/directives/use-client).
