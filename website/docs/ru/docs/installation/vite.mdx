# Vite

В этом руководстве предполагается существующее приложение, созданное из шаблона Vite для React,
React + TypeScript, Vue, Vue + TypeScript, Solid или Solid + TypeScript.

## Выберите вариант настройки

- **Среда:** React, Solid или Vue с соответствующим плагином Vite.
- **Стилизация:** CSS Modules или Tailwind CSS v4.
- **Поставка:** пакет или исходный код, добавленный через shadcn CLI.

Выбор пакета и настройка реестра описаны в Быстром старте: [пакеты](/docs/quick-start#установить-как-пакет)
и [shadcn CLI](/docs/quick-start#установить-через-shadcn-cli).

Примеры ниже используют CSS Modules и reset moduix. Если в приложении уже есть подходящий reset,
не импортируйте его повторно. Для Tailwind установите соответствующий пакет с суффиксом `-tailwind`
и в той же точке входа подключите файл стилей приложения, настроенный по Quick Start.

## Установка через shadcn CLI

Выполните [первоначальную настройку shadcn CLI](/docs/quick-start#установить-через-shadcn-cli), затем
задайте алиас `@/*` для `src/*`. В шаблонах Vite для TypeScript настройки разделены между
`tsconfig.json` и конфигурацией приложения. Добавьте алиас в оба файла:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Добавьте тот же `paths` в `tsconfig.app.json` для проверки типов приложения. В Vite 8 и новее
включите встроенное разрешение путей TypeScript в существующей конфигурации. Сохраните плагин
фреймворка и остальные настройки:

<Tabs groupId="framework">
  <Tab label="React" value="react">

```ts title="vite.config.ts"
import react from '@vitejs/plugin-react';
import { defineConfig } from 'vite';

export default defineConfig({
  plugins: [react()],
  resolve: {
    tsconfigPaths: true,
  },
});
```

<ShadcnInstallOptions options={[{ label: 'CSS Modules', command: 'shadcn@latest add @moduix-react/button' }, { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-react-tailwind/button' }]} />

  </Tab>
  <Tab label="Solid" value="solid">

```ts title="vite.config.ts"
import { defineConfig } from 'vite';
import solid from 'vite-plugin-solid';

export default defineConfig({
  plugins: [solid()],
  resolve: {
    tsconfigPaths: true,
  },
});
```

<ShadcnInstallOptions options={[{ label: 'CSS Modules', command: 'shadcn@latest add @moduix-solid/button' }, { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-solid-tailwind/button' }]} />

  </Tab>
  <Tab label="Vue" value="vue">

```ts title="vite.config.ts"
import { defineConfig } from 'vite';
import vue from '@vitejs/plugin-vue';

export default defineConfig({
  plugins: [vue()],
  resolve: {
    tsconfigPaths: true,
  },
});
```

<ShadcnInstallOptions options={[{ label: 'CSS Modules', command: 'shadcn@latest add @moduix-vue/button' }, { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-vue-tailwind/button' }]} />

Для Vue сохраните `src/**/*.vue` в `include` конфигурации приложения: Vite использует её,
чтобы разрешать пути в SFC. В Vite 7 и более ранних версиях задайте явный
[`resolve.alias`](https://vite.dev/config/shared-options#resolve-alias).

Импортируйте сгенерированные основные стили из точки входа вместо стилей пакета.
Подключать оба файла не нужно:

<Tabs groupId="framework">
  <Tab label="React" value="react">

```tsx title="src/main.tsx"
import '@/lib/moduix/styles/style.css';
```

  </Tab>
  <Tab label="Solid" value="solid">

```tsx title="src/index.tsx"
import '@/lib/moduix/styles/style.css';
```

  </Tab>
  <Tab label="Vue" value="vue">

```ts title="src/main.ts"
import '@/lib/moduix/styles/style.css';
```

  </Tab>
</Tabs>

Импорт стилей выше относится к CSS Modules. Для Tailwind подключите сгенерированные базовые стили
в существующем файле Tailwind по [Quick Start](/docs/quick-start#установить-через-shadcn-cli),
а сам файл импортируйте в той же точке входа. Замените импорт компонента из пакета
на `@/components/ui/button`.

## Проверка

Запустите Vite. При установке из пакета компонент выбранного фреймворка должен отображаться со
стилями. При установке через shadcn редактор и сборщик должны разрешать сгенерированный файл стилей
и импорт `@/components/ui/button`.

Создание проекта и доступные шаблоны описаны в официальном [руководстве Vite](https://vite.dev/guide/).
