# Vite

Эта инструкция рассчитана на готовое приложение, созданное из шаблона Vite для React или React + TypeScript. Если вы
начинаете новый проект, сначала воспользуйтесь [руководством Vite](https://vite.dev/guide/).

## Установите moduix как пакет

<PackageManagerTabs command="install @moduix/react @ark-ui/react" />

Один раз подключите базовый файл стилей в `src/main.tsx`:

```tsx title="src/main.tsx"
import '@moduix/react/style.css';
```

Затем импортируйте компоненты из подпутей пакета:

```tsx title="src/App.tsx"
import { Button } from '@moduix/react/button';

export function App() {
  return <Button>Continue</Button>;
}
```

## Установите через shadcn CLI

Сначала выполните [настройку shadcn CLI](/docs/quick-start#установить-через-shadcn-cli), затем настройте алиас `@/*`
на `src/*`. В TypeScript-шаблоне Vite конфигурация разделена между `tsconfig.json` и `tsconfig.app.json`. Добавьте
алиас в оба файла и настройте такой же алиас для Vite в `vite.config.ts`.

Добавьте эти свойства в существующий объект `compilerOptions` файла `tsconfig.json`:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Добавьте те же свойства в `compilerOptions` файла `tsconfig.app.json`:

```json title="tsconfig.app.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Затем добавьте соответствующий алиас в `vite.config.ts`. Vite ожидает абсолютный путь к каталогу, на который указывает
алиас, поэтому в примере `@` ведёт в каталог `src` приложения:

Эта конфигурация использует `node:url`. Если в проекте ещё нет типов Node.js, установите их как зависимость для
разработки:

<PackageManagerTabs command="install -D @types/node" />

```ts title="vite.config.ts"
import { fileURLToPath, URL } from 'node:url';
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';

export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url)),
    },
  },
});
```

После настройки алиаса добавьте компонент из реестра moduix:

<PackageManagerTabs command="shadcn@latest add @moduix-react/button" dlx />

Вместо пакетного файла стилей подключите сгенерированный файл в `src/main.tsx`. Не подключайте оба файла
одновременно:

```tsx title="src/main.tsx"
import '@/lib/moduix/styles/style.css';
```

Импортируйте сгенерированный компонент из исходников приложения:

```tsx title="src/App.tsx"
import { Button } from '@/components/moduix/button';

export function App() {
  return <Button>Continue</Button>;
}
```

## Проверьте настройку

Запустите dev-сервер Vite. При установке пакета кнопка, импортированная из `@moduix/react/button`, должна отобразиться
со стилями moduix. При установке через shadcn CLI редактор и сборка должны без ошибок находить сгенерированный файл
стилей и компонент из `@/components/moduix/button`.

Полная настройка фреймворка приведена в [руководстве Vite](https://vite.dev/guide/).
