# Vite

В примерах ниже используются пакеты с CSS Modules, в которых доступен полный каталог компонентов.
Для компонентов на Tailwind выполните [настройку Tailwind-пакета](/docs/quick-start#tailwind-css)
и выберите пакет или реестр для React либо Solid.

В этом руководстве предполагается существующее приложение, созданное из шаблона Vite для React,
React + TypeScript, Solid или Solid + TypeScript.

## Установка через shadcn CLI

Выполните [первоначальную настройку shadcn CLI](/docs/quick-start#установка-через-shadcn-cli), затем
задайте алиас `@/*` для `src/*`. В шаблонах Vite для TypeScript настройки разделены между
`tsconfig.json` и конфигурацией приложения. Добавьте алиас в оба файла:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Добавьте те же значения `compilerOptions` в `tsconfig.app.json`, а затем настройте алиас в Vite для
выбранного фреймворка. В примере используется `node:url`, поэтому установите типы Node.js, если их
ещё нет в проекте:

<PackageManagerTabs command="install -D @types/node" />

<Tabs groupId="framework">
  <Tab label="React" value="react">

```ts title="vite.config.ts"
import { fileURLToPath, URL } from 'node:url';
import react from '@vitejs/plugin-react';
import { defineConfig } from 'vite';

export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url)),
    },
  },
});
```

<PackageManagerTabs command="shadcn@latest add @moduix-react/button" dlx />

  </Tab>
  <Tab label="Solid" value="solid">

```ts title="vite.config.ts"
import { fileURLToPath, URL } from 'node:url';
import { defineConfig } from 'vite';
import solid from 'vite-plugin-solid';

export default defineConfig({
  plugins: [solid()],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url)),
    },
  },
});
```

<PackageManagerTabs command="shadcn@latest add @moduix-solid/button" dlx />

  </Tab>
</Tabs>

## Проверка

Запустите Vite. При установке из пакета компонент выбранного фреймворка должен отображаться со
стилями. При установке через shadcn редактор и сборщик должны разрешать сгенерированный файл стилей
и импорт `@/components/ui/button`.

Создание проекта и доступные шаблоны описаны в официальном [руководстве Vite](https://vite.dev/guide/).
