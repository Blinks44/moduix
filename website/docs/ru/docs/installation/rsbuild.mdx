# Rsbuild

Эта инструкция рассчитана на готовое React-приложение, которое уже собирается с помощью Rsbuild. Если вы создаёте
проект с нуля, сначала воспользуйтесь [быстрым стартом Rsbuild](https://rsbuild.rs/guide/start/quick-start). Rsbuild
автоматически учитывает алиасы путей из TypeScript, поэтому при установке через shadcn CLI отдельно настраивать
`resolve.alias` не нужно.

## Установите пакет

<PackageManagerTabs command="install @moduix/react @ark-ui/react" />

Один раз импортируйте общий файл стилей в точке входа приложения:

```tsx title="src/index.tsx"
import '@moduix/react/style.css';
```

После этого импортируйте компоненты из соответствующих точек входа пакета:

```tsx title="src/App.tsx"
import { Button } from '@moduix/react/button';

export function App() {
  return <Button>Continue</Button>;
}
```

## Установка через shadcn CLI

Сначала выполните [настройку shadcn CLI](/docs/quick-start#установить-через-shadcn-cli), затем добавьте алиас пути
`@/*` в `tsconfig.json`:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Rsbuild автоматически читает `compilerOptions.paths`, поэтому дублировать этот алиас в `resolve.alias` файла
`rsbuild.config.ts` не нужно. Замените импорт пакетного файла стилей на сгенерированный файл ниже. Не подключайте
оба файла одновременно:

```tsx title="src/index.tsx"
import '@/lib/moduix/styles/style.css';
```

## Проверка

Запустите dev-сервер Rsbuild. Интеграция настроена правильно, если компонент отображается со стилями moduix, а
TypeScript и Rsbuild корректно находят `@/components/moduix/*`.

Полную инструкцию по настройке Rsbuild, включая создание React-приложения, см. в [быстром старте Rsbuild](https://rsbuild.rs/guide/start/quick-start)
и [руководстве по React](https://rsbuild.rs/guide/framework/react).
