# Rsbuild

В этом руководстве предполагается, что приложение Rsbuild уже настроено для React или Solid. Rsbuild
сам учитывает алиасы из TypeScript, поэтому для shadcn не нужно повторять `resolve.alias`.

## Выберите вариант настройки

- **Среда:** React или Solid с соответствующим плагином Rsbuild.
- **Стилизация:** CSS Modules или Tailwind CSS v4.
- **Поставка:** пакет или исходный код, добавленный через shadcn CLI.

Сначала выполните общую [настройку пакета](/docs/quick-start#установить-как-пакет) или
[настройку shadcn](/docs/quick-start#установить-через-shadcn-cli) для выбранного варианта стилей. Ниже
показаны импорты пакетов на CSS Modules; точки входа Rsbuild и обработка алиасов TypeScript не меняются
при выборе соответствующего Tailwind-пакета или реестра.

Все показанные ниже команды установки пакетов и импорты таблиц стилей относятся к CSS Modules. С Tailwind сохраняйте глобальную
таблицу стилей, настроенную в Быстром старте.

## Установка через shadcn CLI

Сначала выполните [первоначальную настройку shadcn CLI](/docs/quick-start#установить-через-shadcn-cli),
затем задайте алиас `@/*` для `src/*` в `tsconfig.json`:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Rsbuild автоматически читает `compilerOptions.paths`. Добавьте компонент для выбранного фреймворка:

<Tabs groupId="framework">
  <Tab label="React" value="react">

<ShadcnInstallOptions options={[{ label: 'CSS Modules', command: 'shadcn@latest add @moduix-react/button' }, { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-react-tailwind/button' }]} />

  </Tab>
  <Tab label="Solid" value="solid">

<ShadcnInstallOptions options={[{ label: 'CSS Modules', command: 'shadcn@latest add @moduix-solid/button' }, { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-solid-tailwind/button' }]} />

  </Tab>
</Tabs>

Замените импорт стилей из пакета на импорт сгенерированного файла. Подключать оба не нужно:

```tsx title="src/index.tsx"
import '@/lib/moduix/styles/style.css';
```

## Проверка

Запустите сервер разработки. Компонент moduix должен отображаться со стилями, а TypeScript и Rsbuild
должны разрешать пути `@/components/ui/*` после установки из реестра.

Настройка фреймворка описана в руководстве Rsbuild для [React](https://rsbuild.rs/guide/framework/react)
и официальной документации [плагина Solid](https://rsbuild.rs/plugins/list/plugin-solid).
