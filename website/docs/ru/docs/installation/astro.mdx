# Astro

В примерах ниже используются пакеты с CSS Modules, в которых доступен полный каталог компонентов.
Для компонентов на Tailwind выполните [настройку Tailwind-пакета](/docs/quick-start#tailwind-css)
и выберите пакет или реестр для React либо Solid.

Руководство предполагает существующий Astro-проект с уже настроенной официальной интеграцией React
или Solid. По умолчанию компонент превращается в статический HTML. Чтобы он работал в браузере,
добавьте директиву `client:*`.

## Установите пакет

Установите пакет для выбранного фреймворка и соответствующую зависимость Ark UI:

<Tabs groupId="framework">
  <Tab label="React" value="react">

<PackageManagerTabs command="install @moduix/react @ark-ui/react" />

  </Tab>
  <Tab label="Solid" value="solid">

<PackageManagerTabs command="install @moduix/solid @ark-ui/solid" />

  </Tab>
</Tabs>

Один раз импортируйте основные стили в общем макете:

<Tabs groupId="framework">
  <Tab label="React" value="react">

```astro title="src/layouts/Layout.astro"
---
import '@moduix/react/style.css';
---

<html lang="en">
  <body><slot /></body>
</html>
```

  </Tab>
  <Tab label="Solid" value="solid">

```astro title="src/layouts/Layout.astro"
---
import '@moduix/solid/style.css';
---

<html lang="en">
  <body><slot /></body>
</html>
```

  </Tab>
</Tabs>

Создайте компонент для выбранного фреймворка:

<Tabs groupId="framework">
  <Tab label="React" value="react">

```tsx title="src/components/ContinueButton.tsx"
import { Button } from '@moduix/react/button';

export function ContinueButton() {
  return <Button>Continue</Button>;
}
```

  </Tab>
  <Tab label="Solid" value="solid">

```tsx title="src/components/ContinueButton.tsx"
import { Button } from '@moduix/solid/button';

export function ContinueButton() {
  return <Button>Continue</Button>;
}
```

  </Tab>
</Tabs>

Импортируйте компонент непосредственно в страницу Astro и добавьте клиентскую директиву:

```astro title="src/pages/index.astro"
---
import { ContinueButton } from '../components/ContinueButton';
---

<ContinueButton client:load />
```

Без директивы `client:*` Astro отправит статический HTML без клиентского JavaScript компонента.
Используйте `client:load` для сразу доступных элементов управления, `client:idle`, если интерактивность
может подождать, и `client:visible` для компонентов ниже первого экрана. Таким компонентам, как
`Dialog`, `Menu` и `Select`, всегда нужна клиентская директива.

## Установка через shadcn CLI

Выполните [первоначальную настройку shadcn CLI](/docs/quick-start#установка-через-shadcn-cli), задайте
алиас `@/*` для `src/*` в `tsconfig.json` и импортируйте `@/lib/moduix/styles/style.css` в общем
макете. Затем добавьте компонент для выбранного фреймворка:

<Tabs groupId="framework">
  <Tab label="React" value="react">

<PackageManagerTabs command="shadcn@latest add @moduix-react/button" dlx />

  </Tab>
  <Tab label="Solid" value="solid">

<PackageManagerTabs command="shadcn@latest add @moduix-solid/button" dlx />

  </Tab>
</Tabs>

Импортируйте сгенерированный компонент непосредственно в файл `.astro`, а уже затем добавьте
директиву `client:*`. Astro разрешает клиентские директивы только для компонентов, импортированных
прямо в страницу.

## Проверка

До гидратации страница должна содержать оформленный серверный HTML, а после выполнения клиентской
директивы компонент должен реагировать на действия пользователя.

Подробнее — в руководстве Astro по [компонентам разных фреймворков](https://docs.astro.build/en/guides/framework-components/)
и официальных инструкциях для [React](https://docs.astro.build/en/guides/integrations-guide/react/)
и [Solid](https://docs.astro.build/en/guides/integrations-guide/solid-js/).
