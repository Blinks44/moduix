# Astro

Руководство предполагает существующий Astro-проект с уже настроенной официальной интеграцией React, Solid
или Vue. По умолчанию компонент превращается в статический HTML. Чтобы он работал в браузере,
добавьте директиву `client:*`.

## Выберите вариант настройки

- **Среда:** React, Solid или Vue с соответствующей официальной интеграцией Astro.
- **Стилизация:** CSS Modules или Tailwind CSS v4.
- **Поставка:** пакет или исходный код, добавленный через shadcn CLI.

Выбор пакета и настройка реестра описаны в Быстром старте: [пакеты](/docs/quick-start#установить-как-пакет)
и [shadcn CLI](/docs/quick-start#установить-через-shadcn-cli).

Примеры ниже используют CSS Modules и reset moduix. Если в приложении уже есть подходящий reset,
не импортируйте его повторно. Для Tailwind установите соответствующий пакет с суффиксом `-tailwind`
и в той же точке входа подключите файл стилей приложения, настроенный по Quick Start.

  </Tab>
  <Tab label="Solid" value="solid">

  </Tab>

```vue title="src/components/ContinueButton.vue"
</template>
```

  </Tab>

Импортируйте компонент непосредственно в страницу Astro и добавьте клиентскую директиву:

<Tabs groupId="framework">
  <Tab label="React / Solid" value="react-solid">

```astro title="src/pages/index.astro"
---
import Layout from '../layouts/Layout.astro';
import { ContinueButton } from '../components/ContinueButton';
---

<Layout>
  <ContinueButton client:load />
</Layout>
```

  </Tab>
  <Tab label="Vue" value="vue">

```astro title="src/pages/index.astro"
---
import Layout from '../layouts/Layout.astro';
import ContinueButton from '../components/ContinueButton.vue';
---

<Layout>
  <ContinueButton client:load />
</Layout>
```

  </Tab>
</Tabs>

Без директивы `client:*` Astro отправит статический HTML без клиентского JavaScript компонента.
Используйте `client:load` для сразу доступных элементов управления, `client:idle`, если интерактивность
может подождать, и `client:visible` для компонентов ниже первого экрана. Таким компонентам, как
`Dialog`, `Menu` и `Select`, всегда нужна клиентская директива.

## Установка через shadcn CLI

Выполните [первоначальную настройку shadcn CLI](/docs/quick-start#установить-через-shadcn-cli), задайте
алиас `@/*` для `src/*` в `tsconfig.json`, затем добавьте компонент для выбранного фреймворка:

<Tabs groupId="framework">
  <Tab label="React" value="react">

<ShadcnInstallOptions options={[{ label: 'CSS Modules', command: 'shadcn@latest add @moduix-react/button' }, { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-react-tailwind/button' }]} />

  </Tab>
  <Tab label="Solid" value="solid">

<ShadcnInstallOptions options={[{ label: 'CSS Modules', command: 'shadcn@latest add @moduix-solid/button' }, { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-solid-tailwind/button' }]} />

  </Tab>
  <Tab label="Vue" value="vue">

<ShadcnInstallOptions options={[{ label: 'CSS Modules', command: 'shadcn@latest add @moduix-vue/button' }, { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-vue-tailwind/button' }]} />

  </Tab>
</Tabs>

Для CSS Modules импортируйте `@/lib/moduix/styles/style.css` из `src/layouts/Layout.astro`;
подключите reset по Quick Start. Для Tailwind добавьте сгенерированные базовые стили в файл
Tailwind и импортируйте этот файл из layout. В компоненте-обёртке замените импорт Button
на `@/components/ui/button`; саму обёртку по-прежнему импортируйте непосредственно в страницу Astro.

## Проверка

До гидратации страница должна содержать оформленный серверный HTML, а после выполнения клиентской
директивы компонент должен реагировать на действия пользователя.

Подробности есть в руководстве Astro по [компонентам разных фреймворков](https://docs.astro.build/en/guides/framework-components/)
и официальных инструкциях для [React](https://docs.astro.build/en/guides/integrations-guide/react/)
и [Solid](https://docs.astro.build/en/guides/integrations-guide/solid-js/) / [Vue](https://docs.astro.build/en/guides/integrations-guide/vue/).
