# Astro

moduix представляет собой библиотеку компонентов для React. По умолчанию Astro рендерит React-компоненты в статический
HTML. Добавьте клиентскую директиву Astro `client:*`, если компонент должен стать интерактивным в браузере.

## Подключите React к Astro

В корне проекта выполните:

```bash
npx astro add react
```

Эта команда устанавливает и настраивает официальную интеграцию `@astrojs/react` для Astro.

## Установите moduix

Установите `@moduix/react` и объявленную peer-зависимость `@ark-ui/react`:

<PackageManagerTabs command="install @moduix/react @ark-ui/react" />

`@moduix/react` поддерживает React 18 и 19 и ожидает, что `react`, `react-dom` и `@ark-ui/react` установлены в проекте.
Команда `astro add react` обычно добавляет React и `react-dom`. Если вы подключали `@astrojs/react` вручную, перед
продолжением проверьте наличие этих пакетов.

Один раз импортируйте базовый файл стилей в общем макете:

```astro title="src/layouts/Layout.astro"
---
import '@moduix/react/style.css';
---

<html lang="en">
  <body><slot /></body>
</html>
```

Создайте React-компонент и импортируйте его непосредственно в страницу Astro:

```tsx title="src/components/ContinueButton.tsx"
import { Button } from '@moduix/react/button';

export function ContinueButton() {
  return <Button>Continue</Button>;
}
```

Добавьте `client:load`, чтобы компонент стал интерактивным сразу после загрузки страницы:

```astro title="src/pages/index.astro"
---
import { ContinueButton } from '../components/ContinueButton';
---

<ContinueButton client:load />
```

Без директивы `client:*` Astro выведет компонент как статический HTML и не отправит его JavaScript в браузер. Выбирайте
директиву по моменту, когда компонент должен стать интерактивным: `client:load` загружает его сразу, `client:idle`
ждёт свободного времени браузера, а `client:visible` загружает компонент после появления в области просмотра.
Статического серверного рендера недостаточно для `Dialog`, `Menu`, `Select` и других интерактивных компонентов.

## Установка через shadcn CLI

Завершите [настройку shadcn CLI](/docs/quick-start#установить-через-shadcn-cli). В `tsconfig.json` свяжите алиас `@/*`
с `src/*` и импортируйте `@/lib/moduix/styles/style.css` из общего макета. На странице Astro импортируйте
сгенерированный React-компонент непосредственно и добавьте ему директиву `client:*`. Astro принимает клиентскую
директиву только у компонента UI-фреймворка, который импортирован непосредственно в `.astro`-файл.

## Проверка

До гидратации на странице должна быть стилизованная разметка, созданная сервером. После выполнения клиентской директивы
компонент должен реагировать на действия пользователя.

Подробнее о доступных клиентских директивах читайте в [руководстве Astro по фронтенд-фреймворкам](https://docs.astro.build/en/guides/framework-components/). Ручная настройка интеграции React описана в [руководстве по `@astrojs/react`](https://docs.astro.build/en/guides/integrations-guide/react/).
