[Table of Contents](/docs/table-of-contents) синхронизирует навигацию с разделом, который сейчас
читает пользователь. Передайте ему нужные заголовки: компонент выделит текущий пункт и свяжет
каждый пункт с соответствующим заголовком.

### Главное

- Соберите область чтения с помощью `Toc.Content`, а навигацию - с помощью `Toc.Nav`. Каждый пункт
  должен указывать на стабильный ID одного заголовка.
- Используйте `Toc.Indicator` или `Toc.Rail`, чтобы показать иерархию. Добавляйте `Toc.RootProvider`,
  только если внешним элементам нужно использовать состояние оглавления.
</ChangelogNewsItem>

<ChangelogNewsItem>
  <NavigationMenuHero />

[Navigation Menu](/docs/navigation-menu) помогает организовать основную навигацию сайта или
продукта. Используйте прямые ссылки для переходов, а для связанных разделов добавляйте
раскрывающиеся панели.

### Главное

- Для прямых переходов используйте `NavigationMenu.Link`, а для группы связанных ссылок - пару
  `NavigationMenu.Trigger` и `NavigationMenu.Content`.
- Добавляйте `NavigationMenu.Viewport`, если несколько панелей должны анимироваться в общей области.
  Ark UI управляет клавиатурным взаимодействием, фокусом и открытым пунктом, а `Arrow` остаётся
  необязательным.
</ChangelogNewsItem>

<ChangelogNewsItem>
  <ChartHero />

[Chart](/docs/chart) добавляет доступную HTML-оболочку `figure` вокруг TanStack Charts. Опишите график
через TanStack, а затем используйте moduix для заголовка и описания, легенды, компактной подсказки
и настроек анимации. API конфигурации TanStack при этом не меняется.

### Главное

- Описывайте метки, шкалы, взаимодействия и колбэки в конфигурации TanStack, а затем собирайте её с
  `Chart.Header`, `Chart.Plot` и `Chart.Legend`.
- Клавиатурной навигацией и жизненным циклом подсказки по-прежнему управляет TanStack. Анимация
  moduix учитывает настройку «Уменьшение движения»; передайте `motion={false}`, чтобы отключить её.
</ChangelogNewsItem>

<ChangelogNewsItem>
  <LocalizationHero />

Теперь весь сайт документации доступен на русском и французском языках. Можно изучать компонент,
копировать пример и следовать рецепту, не переключаясь между языками.

### Главное

- Руководства по компонентам, установка, справочник API и рецепты доступны на русском и французском.
- Навигация, метаданные страниц, локализованные маршруты и копируемые примеры синхронизированы в
  английской, русской и французской версиях сайта.
</ChangelogNewsItem>

<ChangelogNewsItem>
  <V2MigrationHero />

v2 - это мажорный релиз. Компоненты, для которых есть соответствующий примитив Ark UI, используют
его для состояния, взаимодействия и доступности. При этом moduix сохраняет CSS Modules, дизайн-
токены и оба способа установки.

### Главное

- Ark UI отвечает за состояние, взаимодействие и доступность компонентов с соответствующим
  примитивом.
- Публичная композиция и низкоуровневые свойства следуют контрактам Ark. Компоненты можно установить
  из пакета или скопировать исходный код в приложение и поддерживать его самостоятельно.
</ChangelogNewsItem>

## Другие обновления

### v2.5.0 - 27 августа 2026 г.

- Добавлен `Sidebar` с изменяемой шириной и возможностью сворачивания для навигации по приложению.
- Фон дорожки `AngleSlider` теперь остаётся неизменным при наведении и нажатии.

### v2.4.0 - 25 августа 2026 г.

- Добавлен `JSON Tree View` для отображения вложенных данных JSON.
- Обновлены версии зависимостей пакета.

### v2.2.4 - 10 августа 2026 г.

- `DatePicker` теперь наследует `disabled` и `invalid` от `Field` и `Fieldset`, а `readOnly` и `required` - от `Field`.
- `DatePicker.Field` и `DatePicker.RangeField` сохраняют стабильные индексы полей, поэтому нативные значения формы остаются предсказуемыми.
- Диапазоны `DateInput` автоматически выводят нативные поля со стабильными индексами, сохраняя клавиатурное поведение и семантику доступности Ark.

### v2.2.3 - 24 июля 2026 г.

- Восстановлена совместимость с App Router в Next.js для копируемых компонентов с локальными клиентскими API.
- Стрелка Menu теперь аккуратно выровнена с границей всплывающего меню.

### v2.2.2 - 24 июля 2026 г.

- Исходный код пакета и пути зависимостей реорганизованы так, чтобы результат работы CLI shadcn оставался самодостаточным.

### v2.2.1 - 23 июля 2026 г.

- Добавлен отдельный вариант Drawer `island`; его подложка остаётся видимой между точками привязки.
- Добавлен файл со справочником переменных Ark UI для инструментов репозитория; в рантайме он не выполняется.

### v2.2.0 - 22 июля 2026 г.

- Публичные CSS-токены и каскадные слои помещены в пространство имён `moduix`.

### v2.1.0 - 21 июля 2026 г.

- Добавлены Typeset и пресеты тем Calm, Dense, Soft и Contrast.
- Уточнены основные элементы управления, плотность всплывающих меню, композиция Select и токены тем.

## Политика версий и поддержки

moduix следует семантическому версионированию. Мажорные релизы могут содержать критические изменения,
минорные добавляют обратно совместимые возможности, а патч-релизы содержат обратно совместимые
исправления.

Последняя мажорная версия активно поддерживается. v2 поддерживает React 18 и 19, а интеграция moduix
с Ark UI рассчитана на совместимые версии. Для каждого мажорного релиза на этой странице указаны
затронутые API, шаги миграции и особенности пакета или реестра.
