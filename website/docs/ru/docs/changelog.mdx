[Table of Contents](/docs/table-of-contents) помогает читателю ориентироваться в длинной статье.
Передайте заголовки, за которыми нужно следить: компонент подсветит текущий раздел, а ссылки
прокрутят страницу к нужному заголовку.

### Главное

- `Toc.Content` задаёт область статьи, а `Toc.Nav` — навигацию; каждому пункту соответствует
  стабильный ID заголовка.
- `Toc.Indicator` и `Toc.Rail` помогают показать иерархию, а `Toc.RootProvider` даёт внешним
  элементам доступ к тому же состоянию отслеживания.
</ChangelogNewsItem>

<ChangelogNewsItem>
  <NavigationMenuHero />

[Navigation Menu](/docs/navigation-menu) помогает выстроить основную навигацию продукта или сайта.
Используйте прямые ссылки для переходов, раскрывающиеся панели для связанных разделов, а
`NavigationMenu.Viewport` добавляйте, если панели должны сменять друг друга в одной анимированной
области.

### Главное

- Для прямых переходов используйте `NavigationMenu.Link`, а для группы связанных ссылок — пару
  `Trigger` и `Content`.
- Ark UI управляет клавиатурным взаимодействием, фокусом и открытым пунктом; `Viewport` и `Arrow`
  остаются необязательными для общей анимированной области.
</ChangelogNewsItem>

<ChangelogNewsItem>
  <ChartHero />

[Chart](/docs/chart) помогает добавлять в интерфейс доступные визуализации на базе TanStack Charts.
Создавайте линейные, областные, столбчатые, кольцевые и точечные диаграммы, а также тепловые карты с
готовыми настройками moduix для фигуры, легенды, подсказки и анимации, сохраняя API конфигурации
TanStack.

### Главное

- Описывайте метки, шкалы, взаимодействия и колбэки в конфигурации TanStack, а затем собирайте её с
  `Chart.Header`, `Chart.Plot` и `Chart.Legend`.
- Стандартные подсказка и анимация учитывают клавиатурную навигацию и настройку «Уменьшение
  движения»; передайте `motion={false}` для статичного рендера.
</ChangelogNewsItem>

- Навигация, метаданные страниц, локализованные маршруты и копируемые примеры синхронизированы в
  английской, русской и французской версиях сайта.
</ChangelogNewsItem>

<ChangelogNewsItem>
  <V2MigrationHero />

v2 - это мажорный релиз с новой основой для поведения и доступности компонентов. Компоненты с
отдельным примитивом теперь используют Ark UI, а moduix сохраняет нативные стили CSS и оба способа
установки.

### Главное

- За состояние, взаимодействие и доступность компонентов с отдельным примитивом теперь отвечают
  примитивы Ark UI.
- Публичная композиция и низкоуровневые свойства следуют контрактам Ark, а moduix сохраняет нативный
  CSS и оба способа установки: через пакет или копированием исходного кода.
</ChangelogNewsItem>

## Другие обновления

### v2.5.0 - 27 августа 2026 г.

- Добавлен изменяемый по ширине и сворачиваемый `Sidebar` для навигации по приложению.
- Фон дорожки `AngleSlider` теперь не меняется при наведении и нажатии.

### v2.4.0 - 25 августа 2026 г.

- Добавлен `JSON Tree View` для отображения вложенных данных JSON.
- Обновлены версии зависимостей пакета.

### v2.2.4 - 10 августа 2026 г.

- `DatePicker` теперь наследует `disabled` и `invalid` от `Field` и `Fieldset`, а `readOnly` и `required` - от `Field`.
- `DatePicker.Field` и `DatePicker.RangeField` сохраняют стабильные индексы полей, поэтому нативные значения формы остаются предсказуемыми.
- Поля диапазона `DateInput` автоматически рендерят нативные поля с индексами, сохраняя клавиатурное поведение и семантику доступности Ark.

### v2.2.3 - 24 июля 2026 г.

- Восстановлена совместимость с App Router в Next.js для копируемых компонентов с локальными клиентскими API.
- Стрелка Menu теперь аккуратно выровнена с границей всплывающего меню.

### v2.2.2 - 24 июля 2026 г.

- Исходный код пакета и пути зависимостей реорганизованы так, чтобы результат работы CLI shadcn оставался самодостаточным.

### v2.2.1 - 23 июля 2026 г.

- Добавлен отдельный вариант Drawer `island`; его подложка остаётся видимой между точками привязки.
- Добавлена справочная таблица переменных Ark UI без исполняемого в рантайме кода для инструментов репозитория.

### v2.2.0 - 22 июля 2026 г.

- Публичные CSS-токены и каскадные слои помещены в пространство имён `moduix`.

### v2.1.0 - 21 июля 2026 г.

- Добавлены Typeset и пресеты тем Calm, Dense, Soft и Contrast.
- Уточнены основные элементы управления, плотность всплывающих меню, композиция Select и токены тем.

## Политика версий и поддержки

moduix следует семантическому версионированию. Мажорные релизы могут содержать критические изменения,
минорные добавляют обратно совместимые возможности, а патч-релизы - обратно совместимые исправления.

Последняя мажорная версия активно поддерживается. v2 поддерживает React 18 и 19, а интеграция moduix
с Ark UI остаётся синхронизированной с актуальными версиями. Для каждого мажорного релиза на этой
странице указаны затронутые API, шаги миграции и особенности пакета или реестра.
