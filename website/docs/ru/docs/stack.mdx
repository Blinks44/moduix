## Справочник API

В Ark UI нет отдельного примитива `Stack`. В moduix этот компонент реализован на основе официальной
[фабрики Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[работе с ref](https://ark-ui.com/docs/guides/ref). Названия свойств раскладки взяты из документации
[Stack](https://chakra-ui.com/docs/components/stack) в Chakra UI.

## Анатомия

`Stack` отрисовывает один корневой flex-контейнер по модели фабрики Ark. Компонент управляет направлением,
промежутком, выравниванием, переносом элементов и простым адаптивным переключением направления. Остальные правила
раскладки задавайте в локальном CSS.

```text
Stack
└─ root[data-scope="stack"][data-part="root"][data-slot="stack-root"]
   └─ children
```

| Часть                  | Назначение                                                               |
| ---------------------- | ------------------------------------------------------------------------ |
| `Stack`                | Корневая flex-обёртка для направления, промежутка, выравнивания и расстояния между дочерними элементами. |

## Композиция

`Stack` не владеет управляемым состоянием и предоставляет один корневой элемент. Для обычного вывода `div` используйте
`<Stack>`. Свойство `fill` влияет на `Stack` как на flex-элемент, а не на его дочерние элементы. Добавляйте `Separator`
напрямую, если нужен разделитель, и используйте `asChild`, когда корневой элемент должен иметь семантический тег.

### Адаптивное направление

Используйте адаптивный `direction`, чтобы переключать раскладку с колонки на мобильных экранах на строку на больших.
Значение `desktop` начинает действовать с `640px`. Адаптивные значения работают по принципу mobile-first: без `mobile`
используется `column`, а без `desktop` сохраняется мобильное направление.

## Стилизация

`Stack` не определяет собственных CSS-переменных. `display: flex` и направление `column` по умолчанию задаются в
таблице стилей компонента (или утилитами `flex flex-col` в вариантах Tailwind), поэтому ваши классы могут их заменить,
в том числе адаптивным `flex-direction` в собственных media queries.

Используйте `className` в React или `class` в Solid и Vue для структурных стилей. Варианты Tailwind используют нативные
утилитарные классы и переопределения потребителя; атрибуты данных и хук `data-slot` общие для обоих вариантов стилизации.

### Хуки стилизации

- `className` или `class` задаёт стили единственному корневому элементу: ширину, внутренние отступы, границы, фон и другие свойства оформления.
- `data-scope="stack"` и `data-part="root"` соответствуют соглашениям Ark для стилизации.
- `data-slot="stack-root"` - стабильный селектор moduix для корневого элемента в локальном CSS.
- `direction` и `fill` применяются через таблицу стилей компонента или утилиты, поэтому классы потребителя могут их
  переопределить. `gap`, `align`, `justify` и `wrap` записываются встроенными стилями.
- `style` применяется последним и может переопределить встроенные `gap`, `alignItems`, `justifyContent` и `flexWrap`.
- В публичном контракте нет атрибутов состояния, CSS-переменных для анимации или объекта `slotProps`.
