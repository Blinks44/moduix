## Справочник API

В Ark UI нет отдельного примитива `Stack`. В moduix этот компонент реализован на основе официальной
[фабрики Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[работе с ref](https://ark-ui.com/docs/guides/ref). Названия свойств раскладки взяты из модели
[Stack](https://chakra-ui.com/docs/components/stack) в Chakra UI.

## Анатомия

`Stack` отрисовывает один корневой flex-контейнер по модели фабрики Ark. Компонент управляет направлением,
промежутком, выравниванием, переносом элементов и простым адаптивным переключением направления. Остальные правила
раскладки задавайте в локальном CSS.

```text
Stack / Stack.Root
└─ root[data-scope="stack"][data-part="root"][data-slot="stack-root"]
   └─ children
```

| Часть                  | Назначение                                                               |
| ---------------------- | ------------------------------------------------------------------------ |
| `Stack` / `Stack.Root` | Корневая flex-обёртка для направления, промежутка, выравнивания и расстояния между дочерними элементами. |

## Композиция

### Рекомендуемая композиция

Для обычного вывода `div` используйте короткую форму `<Stack>`. `Stack.Root` пригодится, когда рядом с составными
компонентами важно единообразное пространство имён.

Для типичной flex-раскладки используйте `direction`, `gap`, `align`, `justify` и `wrap`. Свойство `fill` позволяет
вложенному `Stack` расти как flex-элемент. Если нужен визуальный разделитель, добавьте `Separator` moduix
непосредственно в список дочерних элементов. Используйте `asChild`, чтобы корневым элементом стал семантический
элемент.

### Когда нужна собственная композиция

Перейдите на локальный CSS, если нужны несколько flex-контейнеров, разные значения `gap` на разных точках останова,
правила для отдельных элементов или более сложная адаптивность, чем встроенное переключение направления mobile/desktop.
CSS также будет понятнее, если набор свойств компонента становится слишком длинным.

Используйте `style` для разового переопределения публичных переменных `--moduix-stack-*` или вычисляемых flex-свойств.

### Свойства по умолчанию

| Свойство    | По умолчанию       | Примечания                                                               |
| ----------- | ------------------ | ------------------------------------------------------------------------ |
| `direction` | `column`           | `row`, `row-reverse`, `column`, `column-reverse` или объект `mobile/desktop` |
| `gap`       | значение браузера  | Значение CSS-длины (`number` = `px`)                                     |
| `align`     | значение браузера  | Любое допустимое значение `align-items`                                  |
| `justify`   | значение браузера  | Любое допустимое значение `justify-content`                              |
| `wrap`      | значение браузера  | Любое допустимое значение `flex-wrap`                                    |
| `fill`      | `initial`          | `true` задаёт `flex: 1 1 0`; `false` задаёт `flex: initial`              |
| `asChild`   | `false`            | Композиция фабрики Ark с одним семантическим дочерним элементом          |

### Особенности поведения

- `Stack` отрисовывает ровно один корневой элемент и передаёт ему DOM-свойства фабрики Ark.
- `direction={{ mobile, desktop }}` использует значение `desktop` начиная с `640px`. Если указано только одно
  значение, `Stack` использует его в обоих диапазонах.
- `direction` также принимает `row-reverse` и `column-reverse` для обратного визуального порядка.
- `fill` влияет на `Stack` как на flex-элемент, а не на его дочерние элементы.
- `Separator` - обычный дочерний элемент. Декоративным разделителям добавляйте `aria-hidden`.
- `gap`, `align`, `justify` и `wrap` записываются во встроенные стили только при явной передаче.
- `Stack` предоставляет `data-scope="stack"`, `data-part="root"` и `data-slot="stack-root"` для стилизации по
  соглашениям Ark.
- `Stack` не добавляет обёртки элементов, обработку клавиатуры, ARIA-семантику, контекст или управляемое состояние.

## Стилизация

### CSS-свойства

`Stack` предоставляет публичные CSS-переменные в корневом элементе. По умолчанию для них используются `column` и
`initial`; свойства `direction` и `fill` записывают встроенные значения только при передаче, а `style` может
переопределить их для конкретного экземпляра.

<div className="docs-reference">
  <Tabs
    values={[{ label: 'CSS-переменные', value: 'CSS-переменные' }]}
    className="docs-reference-tabs"
    contentItemClassName="docs-reference-panel"
  >
    <Tab>
      <StackDocs.StackCssPropertiesPanel />
    </Tab>
  </Tabs>
</div>

### Хуки стилизации

- `className` задаёт стили единственному корневому элементу: ширину, внутренние отступы, границы, фон и другие
  свойства оформления.
- `data-scope="stack"` и `data-part="root"` соответствуют соглашениям Ark для стилизации.
- `data-slot="stack-root"` - стабильный селектор moduix для корневого элемента в локальном CSS.
- `style` применяется последним и может переопределить вычисляемые `gap`, `alignItems`, `justifyContent`, `flexWrap`
  и любые переменные `--moduix-stack-*`, записанные свойствами.
- В публичном контракте нет атрибутов состояния, CSS-переменных для анимации или объекта `slotProps`.
