## Справочник API

`NativeSelect` оборачивает компонент Ark UI
[Field.Select](https://ark-ui.com/docs/components/field) и выводит настоящий HTML-элемент `<select>`.
Он использует тот же визуальный язык, что и настраиваемый `Select`, по аналогии с [Native Select]
(https://chakra-ui.com/docs/components/native-select) в Chakra UI. При этом moduix предоставляет единый
публичный API из одного компонента.

## Выбор подходящего компонента

Используйте `NativeSelect` для простых списков вариантов, если вам подходят автозаполнение браузера, сброс формы,
встроенное управление с клавиатуры и нативное меню выбора на мобильных устройствах. Выбирайте
[`Select`](/docs/select), когда нужны настраиваемое меню, API коллекций, сложные варианты, очистка,
отображение нескольких выбранных значений или программное управление меню.

## Анатомия

`NativeSelect` оставляет настоящий `<select>` элементом управления формой и добавляет
неинтерактивный значок `ChevronDownIcon` из moduix, чтобы внешний вид совпадал с `Select`.

```text
NativeSelect
└─ span[data-scope="native-select"][data-part="control"]
   ├─ select[data-scope="field"][data-part="select"][data-slot="native-select-root"]
   │  ├─ option
   │  └─ optgroup
   └─ span[data-scope="native-select"][data-part="indicator"]
      └─ ChevronDownIcon
```

| Часть          | Назначение                                                |
| -------------- | --------------------------------------------------------- |
| `NativeSelect` | Стилизованный нативный `<select>` с визуальным индикатором. |

## Композиция

### Рекомендуемая композиция

Используйте компактную форму `NativeSelect` с нативными дочерними элементами и обычными свойствами
управляемого или неуправляемого компонента. Оборачивайте его в `Field.Root`, если нужны видимая метка,
пояснение, сообщение об ошибке или общие состояния `required`, `invalid` и `disabled`.

`NativeSelect.Root` - псевдоним, сохранённый для обратной совместимости. В прикладном коде используйте `NativeSelect`.

### Когда нужна собственная композиция

Перейдите на `Select`, если приложению нужно управлять отображением вариантов, положением меню, состоянием коллекции
или собственными индикаторами. Оставьте `NativeSelect`, если выбором должен управлять браузер.

### Свойства по умолчанию

| Свойство       | По умолчанию       | Примечание                                                   |
| -------------- | ------------------ | ------------------------------------------------------------ |
| `value`        | -                  | Значение в управляемом режиме                                |
| `defaultValue` | -                  | Начальное значение в неуправляемом режиме                    |
| `onChange`     | -                  | Нативное событие `ChangeEvent<HTMLSelectElement>`            |
| `multiple`     | `false`            | Включает выбор нескольких вариантов                           |
| `size`         | значение браузера  | Количество видимых строк, а не визуальный размер компонента  |
| `disabled`     | `false`            | Отключённое состояние                                         |
| `controlProps` | -                  | Свойства внешнего контейнера                                 |
| `asChild`      | `false`            | Композиция Ark; дочерний элемент должен быть `<select>`      |

### Особенности поведения

- Ref указывает на настоящий `HTMLSelectElement`.
- Нативное поведение сохраняется: отправка формы, автозаполнение, сброс, проверка `required`, работа с вариантами и клавиатурой.
- При `multiple` и при нативном `size` больше единицы браузер задаёт естественную высоту списка.
- `Field.Root` передаёт идентификаторы и `aria-describedby`, а также состояние невалидности и другие нативные состояния поля.
- При использовании `asChild` дочерний элемент должен оставаться семантическим HTML-элементом `<select>`.
- HTML-элемент `<select>` не поддерживает режим только для чтения.
- Иконка `ChevronDownIcon` помогает согласовать закрытый список с `Select`. Вид открывающегося меню по-прежнему зависит от браузера.

## Стилизация

### CSS-свойства

`NativeSelect` использует те же переменные уровня элемента управления `--moduix-select-*`, что и `Select`, поэтому
оба компонента могут использовать общие размеры, отступы индикатора, границы, цвета, радиус, кольцо фокуса,
прозрачность отключённого состояния и переходы. Отступы по умолчанию и геометрия индикатора опираются на общую
шкалу с шагом 4 px.

### Точки для стилизации

- `className` задаёт стили настоящему элементу `<select>`. Для внешнего контейнера используйте `controlProps.className`.
- Передавайте в `controlProps.style` переменные `--moduix-select-*`, влияющие на индикатор, чтобы их наследовали и
  `<select>`, и индикатор.
- `data-scope="field"` и `data-part="select"` сохраняют контракт стилизации Ark Field.
- `data-slot="native-select-root"` - стабильный селектор moduix для элемента `<select>`.
- `data-slot="native-select-control"` и `data-slot="native-select-indicator"` используются для стилизации внутреннего
  контейнера и значка.
- Нативные селекторы `:focus-visible`, `:disabled`, `[aria-invalid="true"]`, `[multiple]` и `[size]` управляют
  визуальными состояниями.
