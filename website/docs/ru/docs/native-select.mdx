## Справочник API

`NativeSelect` - стилизованная обёртка над [`Field.Select` из Ark UI](https://ark-ui.com/docs/components/field).
Компонент выводит настоящий HTML-элемент `<select>`, поэтому браузер по-прежнему отвечает за отображение
опций, управление с клавиатуры, отправку формы, автозаполнение, проверку и сброс.

## Выбор подходящего компонента

Используйте `NativeSelect` для простых списков опций, если хотите сохранить стандартное поведение браузера:
автозаполнение, сброс формы, управление с клавиатуры и системное меню выбора на мобильных устройствах.
Выбирайте [`Select`](/docs/select), если нужно настраиваемое всплывающее меню, API коллекций, расширенное
содержимое опций, очистка или программное управление меню.

## Анатомия

`NativeSelect` выводит настоящий `<select>` внутри внешнего контейнера. В закрытом одиночном списке
добавляется декоративная иконка `ChevronDownIcon`; при `multiple` и `size > 1`, когда браузер показывает
список, иконка скрывается.

```text
NativeSelect / NativeSelect.Root
└─ span[data-scope="native-select"][data-part="control"][data-slot="native-select-control"]
   ├─ select[data-scope="field"][data-part="select"][data-slot="native-select-root"]
   │  ├─ option
   │  └─ optgroup
   └─ span[data-scope="native-select"][data-part="indicator"][data-slot="native-select-indicator"]
      └─ ChevronDownIcon
```

| Часть                              | Назначение                                                               |
| --------------------------------- | ------------------------------------------------------------------------ |
| `NativeSelect` / `NativeSelect.Root` | Публичный корневой компонент. Выводит нативный `<select>` и декоративный индикатор. |

## Композиция

### Рекомендуемая композиция

Используйте `NativeSelect` напрямую для простого поля. Внутрь добавляйте нативные элементы `option` и
`optgroup`. Оборачивайте его в `Field.Root`, если нужны видимая метка, пояснение, сообщение об ошибке или
общие состояния `required`, `invalid` и `disabled`.
Доступное имя можно задать с помощью `Field.Label`, обычного `<label>`, `aria-label` или `aria-labelledby`.

`NativeSelect.Root` - псевдоним, сохранённый для обратной совместимости. В прикладном коде используйте `NativeSelect`.

### Когда нужна собственная композиция

Перейдите на `Select`, если приложению нужны возможности вроде настраиваемого всплывающего меню, управления
коллекцией, расширенного отображения опций, отдельного действия очистки или программного управления меню. Оставьте
`NativeSelect`, если выбором должен управлять браузер.

### Свойства по умолчанию

| Свойство       | По умолчанию       | Примечание                                                                  |
| -------------- | ------------------ | --------------------------------------------------------------------------- |
| `value`        | -                  | Значение в управляемом режиме.                                             |
| `defaultValue` | -                  | Начальное значение в неуправляемом режиме.                                 |
| `onChange`     | -                  | Нативное событие `ChangeEvent<HTMLSelectElement>`.                          |
| `multiple`     | `false`            | Включает нативный множественный выбор.                                      |
| `size`         | значение браузера  | Количество видимых строк, а не визуальный размер компонента.               |
| `disabled`     | `false`            | Отключает поле.                                                             |
| `controlProps` | -                  | Свойства внешнего `<span>`, включая стили контейнера.                       |
| `asChild`      | `false`            | Композиция Ark; дочерний элемент должен оставаться семантическим `<select>`. |

### Особенности поведения

- `ref` указывает на настоящий `HTMLSelectElement`.
- Нативное поведение сохраняется: отправка формы, автозаполнение, сброс, проверка `required`, работа с опциями и клавиатурой.
- При `multiple` или нативном `size` больше единицы браузер определяет высоту списка и управляет его видом и взаимодействием.
- `Field.Root` связывает метку, пояснение и сообщение об ошибке с `<select>`, а также передаёт идентификаторы,
  `aria-describedby`, `aria-invalid`, `disabled` и `required`.
- При использовании `asChild` передавайте один семантический HTML-элемент `<select>`.
- HTML-элемент `<select>` не поддерживает режим только для чтения.
- `ChevronDownIcon` служит только для оформления и скрывается у списков; внешний вид открывающегося меню по-прежнему
  определяет браузер.

## Стилизация

### CSS-свойства

`NativeSelect` использует те же переменные `--moduix-select-*`, что и `Select`, поэтому размеры, отступы
индикатора, границы, цвета, радиус, кольцо фокуса, прозрачность отключённого состояния и переходы можно
настраивать одинаково. Отступы по умолчанию и геометрия индикатора опираются на общую шкалу с шагом 4 px.

### Хуки стилизации

- `className` задаёт стили самому `<select>`. Для внешнего `<span>` используйте `controlProps.className`.
- Передавайте в `controlProps.style` переменные `--moduix-select-*`, связанные с индикатором, если их должны
  унаследовать и `<select>`, и индикатор.
- `data-scope="field"` и `data-part="select"` сохраняют контракт стилизации Ark Field.
- `data-slot="native-select-root"` - стабильный селектор moduix для элемента `<select>`.
- `data-slot="native-select-control"` и `data-slot="native-select-indicator"` используются для стилизации внутреннего
  контейнера и значка.
- Нативные псевдоклассы и атрибуты `:focus-visible`, `:disabled`, `[aria-invalid="true"]`, `[multiple]` и `[size]`
  управляют визуальными состояниями.
