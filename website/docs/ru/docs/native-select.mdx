## Справочник API

`NativeSelect` это стилизованная обёртка над [`FieldSelect` из Ark UI](https://ark-ui.com/docs/components/field).
Компонент выводит настоящий HTML-элемент `<select>`, поэтому браузер по-прежнему отвечает за отображение
опций, управление с клавиатуры, отправку формы, автозаполнение, проверку и сброс.

## Выбор подходящего компонента

Используйте `NativeSelect` для простых списков опций, если хотите сохранить стандартное поведение браузера:
автозаполнение, сброс формы, управление с клавиатуры и системное меню выбора на мобильных устройствах.
Выбирайте [`Select`](/docs/select), если нужно настраиваемое всплывающее меню, API коллекций, расширенное
содержимое опций, очистка или программное управление меню.

## Анатомия

`NativeSelect` выводит настоящий `<select>` внутри внешнего контейнера `<span>`. В закрытом одиночном списке
добавляется декоративная иконка `ChevronDownIcon`; при `multiple` и `size > 1`, когда браузер показывает
список, иконка скрывается.

```text
NativeSelect
└─ span[data-scope="native-select"][data-part="control"][data-slot="native-select-control"]
   ├─ select[data-scope="field"][data-part="select"][data-slot="native-select-root"]
   │  ├─ option
   │  └─ optgroup
   └─ span[data-scope="native-select"][data-part="indicator"][data-slot="native-select-indicator"]
      └─ ChevronDownIcon
```

| Часть | Назначение |
| ----- | ---------- |
| `NativeSelect` | Публичный корневой компонент. Выводит нативный `<select>` и декоративный индикатор. |

## Композиция

В React неуправляемый select строится на нативной проп `defaultValue`. В Solid и Vue передавайте нативный атрибут
`selected` тому `<option>`, который должен быть выбран изначально: проп `defaultValue` у `NativeSelect` в Solid и
Vue не имеет эффекта. Используйте `value` вместе с `onChange` в React и Solid или `v-model` в Vue, когда текущее
значение хранится в состоянии приложения. Оборачивайте `NativeSelect` в `Field`, если метка, поясняющий текст,
проверка или состояние `disabled` должны быть общими для поля и элемента управления. Части `Field` связывают этот
контент с нативным select, а выбор опций по-прежнему остаётся под управлением браузера. При `multiple` или
`size > 1` браузер управляет взаимодействием со списком, поэтому декоративный индикатор скрывается. `asChild` может
заменить выводимый select, но дочерним элементом должен оставаться один семантический HTML-элемент `<select>`.

## Стилизация

`NativeSelect` читает те же переменные ширины, высоты, радиуса и размера индикатора, что и варианты `Select` с
CSS Modules, поэтому размеры обоих селектов меняются вместе. Цвета, границы, кольцо фокуса и анимация берутся из
токенов foundation; переопределяйте их классом. Варианты Tailwind используют нативные utility-классы и классы,
которые передаёт потребитель.

### CSS-свойства

Следующие переменные доступны в вариантах с CSS Modules. Отступы по умолчанию и геометрия индикатора опираются
на общую шкалу с шагом 4 px.

### Хуки стилизации

- В React используйте `className`, а в Solid и Vue `class` на самом select. Для внешнего контейнера `<span>` используйте
  `controlProps.className` или `controlProps.class`.
- Задавайте `--moduix-select-action-size` в `controlProps.style` (или на предке), чтобы ей следовали и отступ
  `<select>`, и индикатор.
- `data-scope="field"` и `data-part="select"` сохраняют контракт стилизации Ark Field.
- `data-slot="native-select-root"` это стабильный селектор moduix для элемента `<select>`.
- `data-slot="native-select-control"` и `data-slot="native-select-indicator"` используются для стилизации внутреннего
  контейнера и значка.
- Нативные псевдоклассы и атрибуты `:focus-visible`, `:disabled`, `[aria-invalid="true"]`, `[multiple]` и `[size]`
  управляют визуальными состояниями.
