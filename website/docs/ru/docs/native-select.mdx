## Справочник API

`NativeSelect` это стилизованная обёртка над [`Field.Select` из Ark UI](https://ark-ui.com/docs/components/field).
Компонент выводит настоящий HTML-элемент `<select>`, поэтому браузер по-прежнему отвечает за отображение
опций, управление с клавиатуры, отправку формы, автозаполнение, проверку и сброс.

## Выбор подходящего компонента

Используйте `NativeSelect` для простых списков опций, если хотите сохранить стандартное поведение браузера:
автозаполнение, сброс формы, управление с клавиатуры и системное меню выбора на мобильных устройствах.
Выбирайте [`Select`](/docs/select), если нужно настраиваемое всплывающее меню, API коллекций, расширенное
содержимое опций, очистка или программное управление меню.

## Анатомия

`NativeSelect` выводит настоящий `<select>` внутри внешнего контейнера `<span>`. В закрытом одиночном списке
добавляется декоративная иконка `ChevronDownIcon`; при `multiple` и `size > 1`, когда браузер показывает
список, иконка скрывается.

```text
NativeSelect / NativeSelect.Root
└─ span[data-scope="native-select"][data-part="control"][data-slot="native-select-control"]
   ├─ select[data-scope="field"][data-part="select"][data-slot="native-select-root"]
   │  ├─ option
   │  └─ optgroup
   └─ span[data-scope="native-select"][data-part="indicator"][data-slot="native-select-indicator"]
      └─ ChevronDownIcon
```

| Часть | Назначение |
| ----- | ---------- |
| `NativeSelect` / `NativeSelect.Root` | Публичный корневой компонент. Выводит нативный `<select>` и декоративный индикатор. |

## Композиция

Используйте `defaultValue` для неуправляемого select. Используйте `value` вместе с `onChange`, когда текущее
значение хранится в состоянии приложения. Оборачивайте `NativeSelect` в `Field.Root`, если метка, поясняющий
текст, проверка или состояние `disabled` должны быть общими для поля и элемента управления. Части `Field`
связывают этот контент с нативным select, а выбор опций по-прежнему остаётся под управлением браузера. При
`multiple` или `size > 1` браузер управляет взаимодействием со списком, поэтому декоративный индикатор скрывается.
`asChild` может заменить выводимый select, но дочерним элементом должен оставаться один семантический HTML-элемент
`<select>`.

## Стилизация

`NativeSelect` использует переменные `--moduix-select-*` из вариантов `Select` с CSS Modules, поэтому размеры,
отступы индикатора, границы, цвета, радиус, кольцо фокуса, прозрачность отключённого состояния и переходы можно
настраивать одинаково. Варианты Tailwind используют нативные utility-классы и классы, которые передаёт потребитель.

### CSS-свойства

Следующие переменные доступны в вариантах с CSS Modules. Отступы по умолчанию и геометрия индикатора опираются

### Хуки стилизации

- В React используйте `className`, а в Solid `class` на самом select. Для внешнего контейнера `<span>` используйте
  `controlProps.className` или `controlProps.class`.
- Передавайте в `controlProps.style` переменные `--moduix-select-*`, связанные с индикатором, если их должны
  унаследовать и `<select>`, и индикатор.
- `data-scope="field"` и `data-part="select"` сохраняют контракт стилизации Ark Field.
- `data-slot="native-select-root"` это стабильный селектор moduix для элемента `<select>`.
- `data-slot="native-select-control"` и `data-slot="native-select-indicator"` используются для стилизации внутреннего
  контейнера и значка.
- Нативные псевдоклассы и атрибуты `:focus-visible`, `:disabled`, `[aria-invalid="true"]`, `[multiple]` и `[size]`
  управляют визуальными состояниями.
