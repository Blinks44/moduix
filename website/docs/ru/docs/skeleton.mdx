## Справочник API

В Ark UI нет отдельного примитива `Skeleton`. moduix создаёт `Skeleton` на основе официальной
[фабрики Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[работе с ref](https://ark-ui.com/docs/guides/ref).

## Анатомия

`Skeleton` состоит из одной визуальной части. Компоновку задаёт окружающая разметка.

```text
Skeleton
└─ children (необязательно, отображаются при loading={false})
```

| Часть                        | Назначение                                                                                  |
| ---------------------------- | ------------------------------------------------------------------------------------------- |
| `Skeleton` | Блок-заполнитель. По умолчанию рендерит элемент фабрики Ark; с `asChild` корневым можно сделать другой семантический элемент. |

## Композиция

`Skeleton` не управляет состоянием загрузки. Область данных или страницы, которая владеет запросом, передаёт
`loading` и должна получать `aria-busy`; сам заполнитель служит только для оформления. Установите
`loading={false}` (в Vue используйте `:loading="false"`), чтобы показать дочерние элементы в том же корневом элементе.

`Skeleton` состоит из одной визуальной части, поэтому карточки, медиаобъекты и адаптивные раскладки следует
собирать в своей обёртке. `Stack` доступен в обоих вариантах стилизации; в Tailwind также можно использовать
нативные классы-утилиты flex и grid. Используйте `asChild`, только если нужен другой семантический корневой
элемент. В Solid в `asChild` передаётся функция рендера, а во Vue используется `as-child`
с одним семантическим элементом в слоте по умолчанию.

## Стилизация

Используйте `className` в React или `class` в Solid и Vue для структурных стилей и классов-утилит приложения.
Варианты Tailwind используют нативные классы-утилиты и классы приложения, а варианты с CSS Modules предоставляют
переменные ниже. Атрибуты состояния и хуки `data-slot` общие для обоих способов стилизации.

### Селекторы и атрибуты для стилизации

- `[data-scope="skeleton"][data-part="root"]` выбирает экспортируемый корневой элемент.
- `data-slot="skeleton-root"` - стабильный селектор moduix для корневого элемента.
- `data-state="loading"` и `data-state="loaded"` соответствуют свойству `loading`.
- `data-variant="pulse"` и `data-variant="none"` соответствуют выбранному варианту.
- `data-loading` присутствует только тогда, когда активны стили заполнителя.
