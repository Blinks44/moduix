## Справочник API

В Ark UI нет отдельного примитива `Skeleton`. moduix создаёт `Skeleton` на основе официальной
[фабрики Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[работе с ref](https://ark-ui.com/docs/guides/ref).

## Анатомия

`Skeleton` состоит из одной визуальной части. Компоновку задаёт окружающая разметка.

```text
Skeleton.Root
└─ children (необязательно, отображаются при loading={false})
```

| Часть                        | Назначение                                                                                  |
| ---------------------------- | ------------------------------------------------------------------------------------------- |
| `Skeleton` / `Skeleton.Root` | Блок-заполнитель. По умолчанию рендерит элемент фабрики Ark; с `asChild` корневым можно сделать другой семантический элемент. |

## Композиция

### Рекомендуемая композиция

Используйте `Skeleton` напрямую для строк текста, карточек, аватаров и медиа-заполнителей. Пока `loading`
имеет значение `true`, компонент показывает декоративный блок. При `loading={false}` он показывает дочерние
элементы в том же корневом элементе.

По умолчанию используется `variant="pulse"`, который добавляет анимацию пульсации. Если анимация не нужна,
используйте `variant="none"`. Если пользователь предпочитает уменьшить движение, компонент также отключает анимацию.

### Когда нужна собственная композиция

Используйте `asChild`, если корневым элементом должен быть семантический элемент, отличный от `div`. В этом
режиме дочерний элемент становится корневым, поэтому он должен быть единственным и семантическим.

Для распространённых размеров используйте `width`, `height`, `boxSize` и `borderRadius`. Для более
особого оформления применяйте `className`, `style` или публичные CSS-переменные.

### Свойства по умолчанию

| Свойство       | По умолчанию                          | Примечания                                                                                                    |
| -------------- | -------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `loading`      | `true`                                 | Управляет активностью стилей заполнителя или обычным показом дочерних элементов.                              |
| `variant`      | `pulse`                                | Поддерживает `pulse` и `none`.                                                                                |
| `height`       | `var(--moduix-spacing-4)` (во время загрузки) | CSS задаёт стандартную высоту заполнителя во время загрузки. Загруженное содержимое использует естественную высоту, если высота не задана. |
| `width`        | `100%`                                 | CSS задаёт стандартную ширину корня. Числовые значения свойства становятся `px`.                              |
| `boxSize`      | Не задано                            | Одновременно задаёт ширину и высоту. Явно заданные `width` и `height` имеют приоритет для соответствующей оси. |
| `borderRadius` | `var(--moduix-skeleton-border-radius, var(--moduix-radius-md))` | Числовые значения преобразуются в `px`; встроенные стили имеют приоритет. |

### Особенности поведения

- `Skeleton.Root` - тот же компонент, что и `Skeleton`; он предоставлен для единообразия пространства имён.
- `ref` пробрасывается в корневой элемент.
- `loading={true}` задаёт `aria-hidden`, `data-state="loading"` и `data-loading`, если вы явно не задали `aria-hidden`.
- `loading={false}` задаёт `data-state="loaded"` и позволяет дочерним элементам использовать естественную высоту, если не заданы `height`, `boxSize` или `style.height`.
- `variant` влияет только на стили; внутренние таймеры и управление состоянием не добавляются.
- `Skeleton` служит только для оформления и не сообщает о загрузке. Задавайте `aria-busy` для области, которая управляет состоянием загрузки, или используйте `Spinner`, когда нужно объявить встроенный статус.

## Стилизация

`Skeleton` предоставляет атрибуты частей и состояний в стиле Ark, а также публичные переменные
`--moduix-skeleton-*` для цвета, радиуса, высоты и анимации.

### Селекторы и атрибуты для стилизации

- `[data-scope="skeleton"][data-part="root"]` выбирает экспортируемый корневой элемент.
- `data-slot="skeleton-root"` - стабильный селектор moduix для корневого элемента.
- `data-state="loading"` и `data-state="loaded"` соответствуют свойству `loading`.
- `data-variant="pulse"` и `data-variant="none"` соответствуют выбранному варианту.
- `data-loading` присутствует только тогда, когда активны стили заполнителя.
