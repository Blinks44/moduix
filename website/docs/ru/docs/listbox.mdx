<UsageCode
  react={'const collection = createListCollection({ items: countries });\n\n<Listbox collection={collection} selectionMode="multiple" onValueChange={(details) => setValue(details.value)}>\n  <ListboxLabel>Countries</ListboxLabel>\n  <ListboxContent>\n    {collection.items.map((item) => (\n      <ListboxItem key={item.value} item={item}>\n        <ListboxItemText>{item.label}</ListboxItemText>\n        <ListboxItemIndicator />\n      </ListboxItem>\n    ))}\n  </ListboxContent>\n</Listbox>'}

Интерактивный

Передайте `collection`, отрисуйте `ListboxContent` и передайте каждый элемент коллекции в
`ListboxItem` через `item`. Добавьте `ListboxItemIndicator`, если строки должны показывать
выбранное состояние.

## Какой компонент выбрать

Используйте `Listbox`, когда варианты должны оставаться видимыми и пользователь выбирает элементы
из коллекции. Используйте `Select`, когда варианты должны открываться во всплывающем списке.
Используйте `Combobox`, когда пользователю нужен всплывающий список с полем для поиска или ввода
значения.

## Композиция

Используйте `defaultValue` для неконтролируемого выбора. Если выбранными значениями управляет другая
часть приложения, передайте `value` и обновляйте его из `onValueChange(details.value)`. Для
фильтрации задайте `typeahead={false}`, храните запрос в состоянии приложения и вызывайте функцию
`filter`, возвращённую `useListCollection`, из обработчика поля. `ListboxFilter` отвечает только за объединённый внешний
вид поля поиска, поэтому обработчик очистки должен сбрасывать и запрос, и фильтр коллекции.

Используйте `useListbox` из пакета выбранного фреймворка вместе с `ListboxRootProvider`, если
хранилище нужно создать вне отрисовываемого дерева. Передайте полученное хранилище в `ListboxRootProvider`
и не добавляйте для него второй `Listbox`. `ListboxInput` можно отрисовать напрямую,
если фильтру нужен отдельный контейнер, а `ListboxValueText` можно разместить после `ListboxContent`,
чтобы показывать сводку выбранных значений.

## Стилизация

Стилизуйте Listbox через `className` в React или `class` в Solid и Vue на экспортируемых частях.
Варианты Tailwind используют нативные utility-классы и классы потребителя. Варианты с CSS Modules берут
цвета, отступы и типографику из токенов foundation и выносят в CSS-переменные только ширину корня и
максимальную высоту содержимого; остальное переопределяйте классом на части. Пункты, подписи групп и
отступы списка также следуют общим переменным `--moduix-popup-item-*`, `--moduix-popup-group-label-*` и
`--moduix-popup-list-padding-y`.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `ArrowDown` / `ArrowUp` | Подсвечивает следующую или предыдущую опцию. |
| `Home` / `End` | Подсвечивает первую или последнюю опцию. |
| `Enter` / `Space` | Выбирает подсвеченную опцию. |
| `Ctrl+A` | Выбирает все опции в режиме multiple или extended. |
| Буквы | Подсвечивает опцию, которая начинается с набранного текста. |
