| `Listbox.Input`            | Поле фильтрации, обычно размещаемое внутри `Filter`.                                       |

| `Listbox.Content`          | Контейнер listbox, который принимает фокус и обеспечивает клавиатурную навигацию.          |
| `Listbox.Empty`            | Содержимое для пустой отфильтрованной коллекции.                                            |
| `Listbox.ItemGroup`        | Контейнер группы связанных элементов коллекции.                                            |
| `Listbox.ItemGroupLabel`   | Метка группы коллекции.                                                                     |
| `Listbox.Item`             | Выбираемая строка. Передавайте элемент коллекции через `item`.                              |
| `Listbox.ItemText`         | Текст для отображения и вспомогательных технологий.                                        |
| `Listbox.ItemTextContent`  | Необязательный помощник для размещения иконки и текста внутри `ItemText`.                   |
| `Listbox.ItemTextIcon`     | Необязательная обёртка иконки внутри `ItemTextContent`.                                    |
| `Listbox.ItemTextLabel`    | Метка внутри `ItemTextContent`, текст которой можно обрезать без поломки разметки.          |
| `Listbox.ItemIndicator`    | Индикатор выбранного элемента со стандартной иконкой галочки moduix.                       |
| `Listbox.ValueText`        | Сводка выбранных значений.                                                                  |

## Композиция

### Рекомендуемая композиция

Напрямую соберите дерево частей Ark: `Listbox` управляет коллекцией, `Listbox.Content` отвечает за фокус
и клавиатурную навигацию, а каждый `Listbox.Item` получает исходный элемент коллекции через `item`.
Добавляйте `Listbox.ItemIndicator`, если строкам нужно заранее зарезервировать место под индикатор выбора.

Для фильтрации поместите `Listbox.Input` в `Listbox.Filter` сразу перед `Listbox.Content`.
`Filter` добавляет стандартную иконку поиска и визуально объединяет поле с результатами в один блок с рамкой.

### Когда нужна собственная композиция

Используйте `asChild`, только если ваш пользовательский элемент сохраняет необходимую семантику listbox и
принимает свойства Ark. Используйте `ids`, когда частям listbox нужны стабильные идентификаторы для связи с
окружающей разметкой. Используйте `useListbox` из moduix вместе с `Listbox.RootProvider`, когда состоянием нужно
управлять за пределами отрисованного дерева. Для одного экземпляра состояния не создавайте одновременно
`Listbox.Root`. Отрисовывайте `Listbox.Input` напрямую, если поле фильтра должно быть визуально отделено от списка
или встроено в свою разметку.

### Свойства по умолчанию

| Проп                      | По умолчанию | Примечания                                                                 |
| ------------------------- | ------------ | -------------------------------------------------------------------------- |
| `collection`              | -            | Обязательная коллекция Ark. Создайте её через `createListCollection` или используйте вариант для сетки. |
| `defaultValue`            | `[]`         | Начальные выбранные значения в неуправляемом состоянии.                                             |
| `defaultHighlightedValue` | -            | Начальный активный элемент в неуправляемом состоянии.                                                |
| `deselectable`            | -            | Позволяет клавише `Escape` очистить непустой выбор.                                                   |
| `disabled`                | `false`      | Отключает весь listbox.                                                                            |
| `disallowSelectAll`       | `false`      | Отключает выбор с помощью `Cmd/Ctrl + A`.                                                          |
| `loopFocus`               | `false`      | Не позволяет навигации стрелками переходить с конца в начало.                                      |
| `orientation`             | `vertical`   | Задаёт расположение и направление стрелочных клавиш.                                               |
| `selectionMode`           | `single`     | Поддерживает `single`, `multiple` и `extended`.                                                     |
| `selectOnHighlight`       | `false`      | Автоматически выбирает активный элемент при навигации с клавиатуры.                                |
| `typeahead`               | `true`       | Включает поиск по вводу, если текстовый ввод не используется для фильтрации.                        |

### Особенности поведения

`value`, `defaultValue` и `onValueChange(details)` используют массивы строк. Читайте `details.value`
для выбранных ключей, а `details.items` - для выбранных элементов коллекции.

`highlightedValue`, `defaultHighlightedValue` и `onHighlightChange(details)` управляют перемещением
активного элемента. `onSelect(details)` вызывается при выборе элемента и передаёт его значение.

`useListbox`, `useListboxContext`, `useListboxItemContext`, `Listbox.Context` и
`Listbox.ItemContext` доступны из `@moduix/react` для сложных сценариев управления состоянием и отдельными элементами.
Ссылки `ref` передаются соответствующей части Ark. Ссылки `ref` корня и `RootProvider` указывают на отрисованные
элементы `div`. Используйте `ids`, когда частям listbox нужны стабильные идентификаторы для связи с окружающей
разметкой.

Listbox не создаёт нативный элемент управления формой для выбранных значений. Если выбор нужно отправить вместе
с формой, храните значение и логику сброса в модели формы.

`Listbox.Input` нужен только для фильтрации. Помещайте его в `Listbox.Filter` для стандартного поля поиска
или отрисовывайте напрямую для отдельного поля. Установите `typeahead={false}`, чтобы поиск по вводу не конфликтовал
с фильтрацией. Состоянием фильтра нужно управлять явно: показывайте `Listbox.ClearTrigger`, если запрос не пуст,
а в обработчике `onClick` очищайте запрос и фильтр коллекции.

Ark отвечает за ARIA-паттерн listbox, управление фокусом активного элемента, клавиатурную навигацию,
поиск по вводу, поведение клавиш `Home` и `End`, обработку отключённых элементов и стрелочные клавиши с учётом
ориентации. Если listbox нужна видимая метка, оставляйте `Listbox.Label` в дереве.

### Хуки стилизации

- Хуки анатомии Ark: `data-scope="listbox"` и `data-part` на корневом элементе, метке, поле ввода, содержимом,
  группе и метке группы, элементе, его тексте и индикаторе, тексте выбранных значений и пустом состоянии.
- Хуки состояния: `data-orientation`, `data-disabled`, `data-empty`, `data-layout`,
  `data-activedescendant`, `data-value`, `data-selected`, `data-state` и `data-highlighted`.
- Хуки moduix: `data-slot="listbox-root"`, `listbox-label`, `listbox-filter`,
  `listbox-filter-icon`, `listbox-input`, `listbox-clear-trigger`, `listbox-content`,
  `listbox-empty`, `listbox-item-group`, `listbox-item-group-label`, `listbox-item`,
  `listbox-item-text`, `listbox-item-text-content`, `listbox-item-text-icon`,
  `listbox-item-text-label`, `listbox-item-indicator` и `listbox-value-text`.
