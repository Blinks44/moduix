## Выбор подходящего компонента

Используйте `Listbox`, когда варианты должны оставаться видимыми, а пользователь выбирает их из коллекции.
Используйте `Select`, если варианты должны открываться во всплывающем окне. Выбирайте `Combobox`, если нужен
всплывающий список, управляемый полем ввода, для поиска или ввода значения.

## Базовый пример

Используйте `Listbox`, когда пользователю нужно выбрать один или несколько элементов из списка, который остаётся
открытым. Передайте `collection`, добавьте `Listbox.Content`, а исходный элемент коллекции передайте в `Listbox.Item`

## Композиция

### Рекомендуемая композиция

Соберите listbox напрямую из частей Ark. `Listbox` управляет коллекцией, `Listbox.Content` отвечает за фокус и
навигацию с клавиатуры, а каждый `Listbox.Item` получает исходный элемент коллекции через `item`. Добавьте
`Listbox.ItemIndicator`, если строкам нужно заранее зарезервировать место под индикатор выбора.

`Listbox` - это короткая форма корневого компонента, эквивалентная `Listbox.Root`. Для фильтрации поместите
`Listbox.Input` в `Listbox.Filter` сразу перед `Listbox.Content`. `Filter` добавляет стандартную иконку поиска и
визуально объединяет поле с результатами в одну поверхность с рамкой. Это только визуальная оболочка: состояние
запроса и фильтрацию коллекции нужно контролировать в своём коде.

### Когда нужна собственная композиция

Используйте `asChild`, только если ваш элемент сохраняет семантику listbox и принимает свойства Ark. Указывайте
`ids`, когда частям listbox нужны стабильные идентификаторы для интеграции с окружающей разметкой. Используйте
`useListbox` из `@moduix/react/listbox` вместе с `Listbox.RootProvider`, когда состояние нужно контролировать вне
отрисованного дерева. Для одного и того же экземпляра не рендерите `Listbox.Root` одновременно с `RootProvider`.
Отображайте `Listbox.Input` напрямую, если поле фильтра должно быть визуально отделено от списка или встроено в
свою разметку.

### Свойства по умолчанию

| Проп                      | По умолчанию | Примечания                                                                                   |
| ------------------------- | ------------ | -------------------------------------------------------------------------------------------- |
| `collection`              | -            | Обязательная коллекция Ark. Создайте её с помощью `createListCollection` или используйте коллекцию для сетки. |
| `defaultValue`            | `[]`         | Начальные выбранные значения, если состояние не контролируется.                              |
| `defaultHighlightedValue` | -            | Начальный активный элемент, если состояние не контролируется.                               |
| `deselectable`            | -            | Позволяет очистить непустой выбор клавишей `Escape`.                                         |
| `disabled`                | `false`      | Отключает весь listbox.                                                                       |
| `disallowSelectAll`       | `false`      | Запрещает выбирать все элементы с помощью `Cmd/Ctrl + A`.                                   |
| `loopFocus`               | `false`      | Не позволяет навигации стрелками переходить с последнего элемента на первый.                |
| `orientation`             | `vertical`   | Задаёт расположение элементов и направление навигации стрелками.                            |
| `selectionMode`           | `single`     | Поддерживает `single`, `multiple` и `extended`.                                               |
| `selectOnHighlight`       | `false`      | Выбирает элемент при перемещении на него с клавиатуры.                                       |
| `typeahead`               | `true`       | Включает поиск по вводимым символам, если текстовый ввод не используется для фильтрации.      |

### Особенности поведения

`value`, `defaultValue` и `onValueChange(details)` используют массивы строк. Используйте `details.value` для
чтения выбранных ключей, а `details.items` - для выбранных элементов коллекции.

`highlightedValue`, `defaultHighlightedValue` и `onHighlightChange(details)` управляют активным элементом во время
навигации. `onSelect(details)` вызывается при выборе элемента и передаёт его значение.

`useListbox`, `useListboxContext`, `useListboxItemContext`, `Listbox.Context` и `Listbox.ItemContext` доступны из
`@moduix/react/listbox` для сложных сценариев работы с состоянием и отдельными элементами. Свойство `ref`
передаётся соответствующей части Ark. Корневой компонент и `RootProvider` рендерят элементы `div`, поэтому их
`ref` указывает на эти элементы. Используйте `ids`, когда частям listbox нужны стабильные идентификаторы для связи
с окружающей разметкой.

Listbox не создаёт нативный элемент управления формой для выбранных значений. Если выбор нужно отправить вместе с
формой, храните его и логику сброса формы в модели формы.

`Listbox.Input` нужен только для фильтрации. Помещайте его в `Listbox.Filter` для стандартного поля поиска или
отрисовывайте напрямую для отдельного поля. Установите `typeahead={false}`, чтобы поиск по вводимым символам не
конфликтовал с фильтрацией. Состоянием фильтра нужно управлять явно: показывайте `Listbox.ClearTrigger`, если
запрос непуст, а в обработчике `onClick` очищайте запрос и фильтр коллекции.

Ark обеспечивает ARIA-паттерн listbox, управление фокусом активного элемента, клавиатурную навигацию, поиск по
вводимым символам, поведение клавиш `Home` и `End`, обработку отключённых элементов и навигацию стрелками с учётом
ориентации. Если listbox нужна видимая метка, оставляйте `Listbox.Label` в дереве.

## Стилизация

Стилизуйте `Listbox` через `className`, стабильные селекторы `data-slot="listbox-*"`, атрибуты Ark
`data-scope="listbox"` / `data-part`, атрибуты состояния и публичные CSS-переменные `--moduix-listbox-*`.

### Хуки стилизации

- Атрибуты анатомии Ark: `data-scope="listbox"` и `data-part` у корневого элемента, метки, поля ввода, содержимого,
  группы и метки группы, элемента, его текста и индикатора, текста выбранных значений и пустого состояния.
- Атрибуты состояния: `data-orientation`, `data-disabled`, `data-empty`, `data-layout`, `data-activedescendant`,
  `data-value`, `data-selected`, `data-state` и `data-highlighted`.
- Селекторы moduix: `data-slot="listbox-root"`, `listbox-root-provider`, `listbox-label`, `listbox-filter`,
  `listbox-filter-icon`, `listbox-input`, `listbox-clear-trigger`, `listbox-content`, `listbox-empty`,
  `listbox-item-group`, `listbox-item-group-label`, `listbox-item`, `listbox-item-text`,
  `listbox-item-text-content`, `listbox-item-text-icon`, `listbox-item-text-label`, `listbox-item-indicator` и
  `listbox-value-text`.
