## Какой компонент выбрать

Используйте `Listbox`, когда варианты должны оставаться видимыми и пользователь выбирает элементы
из коллекции. Используйте `Select`, когда варианты должны открываться во всплывающем списке.
Используйте `Combobox`, когда пользователю нужен всплывающий список с полем для поиска или ввода
значения.

## Анатомия

```text
Listbox / Listbox.Root
├─ Listbox.Label
├─ Listbox.Filter
│  ├─ Listbox.Input
│  └─ Listbox.ClearTrigger
├─ Listbox.Content
│  ├─ Listbox.Empty
│  ├─ Listbox.ItemGroup
│  │  ├─ Listbox.ItemGroupLabel
│  │  └─ Listbox.Item[item]
│  │     ├─ Listbox.ItemText
│  │     └─ Listbox.ItemIndicator
│  └─ Listbox.Item[item]
│     ├─ Listbox.ItemText
│     │  └─ Listbox.ItemTextContent (необязательно)
│     │     ├─ Listbox.ItemTextIcon (необязательно)
│     │     └─ Listbox.ItemTextLabel (необязательно)
│     └─ Listbox.ItemIndicator
└─ Listbox.ValueText

Listbox.RootProvider
└─ то же дерево элементов, подключённое к состоянию из useListbox()
```

| Часть                      | Назначение                                                                                   |
| -------------------------- | -------------------------------------------------------------------------------------------- |
| `Listbox` / `Listbox.Root` | Управляет коллекцией, выбранными значениями, подсвеченным элементом и режимом выбора.        |
| `Listbox.RootProvider`     | Отрисовывает дерево listbox из состояния, возвращённого `useListbox`.                        |
| `Listbox.Label`            | Подпись, задающая listbox доступное имя.                                                      |
| `Listbox.Filter`           | Визуальная обёртка для поля фильтра с иконкой поиска по умолчанию. Размещайте перед `Listbox.Content`. |
| `Listbox.Input`            | Поле фильтра, обычно размещаемое внутри `Filter`.                                            |
| `Listbox.ClearTrigger`     | Кнопка сброса запроса фильтра с иконкой закрытия по умолчанию.                               |
| `Listbox.Content`          | Фокусируемый контейнер listbox, управляющий навигацией с клавиатуры.                          |
| `Listbox.Empty`            | Содержимое, отображаемое, когда после фильтрации не осталось элементов.                       |
| `Listbox.ItemGroup`        | Обёртка для связанных элементов коллекции.                                                   |
| `Listbox.ItemGroupLabel`   | Подпись группы элементов коллекции.                                                          |
| `Listbox.Item`             | Выбираемый элемент. Передайте его элемент коллекции через `item`.                            |
| `Listbox.ItemText`         | Текст для отображения и доступности.                                                         |
| `Listbox.ItemTextContent`  | Необязательная обёртка для размещения иконки и текста внутри `ItemText`.                     |
| `Listbox.ItemTextIcon`     | Необязательная обёртка для иконки внутри `ItemTextContent`.                                 |
| `Listbox.ItemTextLabel`    | Обёртка текста внутри `ItemTextContent`, которая позволяет обрезать длинные подписи без нарушения разметки. |
| `Listbox.ItemIndicator`    | Индикатор выбора с иконкой галочки moduix по умолчанию.                                      |
| `Listbox.ValueText`        | Сводка выбранных значений.                                                                   |

## Композиция

Используйте `defaultValue` для неконтролируемого выбора. Если выбранными значениями управляет другая
часть приложения, передайте `value` и обновляйте его из `onValueChange(details.value)`. Для
фильтрации задайте `typeahead={false}`, храните запрос в состоянии приложения и вызывайте функцию
`filter`, возвращённую `useListCollection`, из обработчика поля. `Listbox.Filter` отвечает только за объединённый внешний
вид поля поиска, поэтому обработчик очистки должен сбрасывать и запрос, и фильтр коллекции.

Используйте `useListbox` из пакета выбранного фреймворка вместе с `Listbox.RootProvider`, если
хранилище нужно создать вне отрисовываемого дерева. Передайте полученное хранилище в `RootProvider`
и не добавляйте для него `Listbox` или `Listbox.Root`. `Listbox.Input` можно отрисовать напрямую,
если фильтру нужен отдельный контейнер, а `Listbox.ValueText` можно разместить после `Content`,
чтобы показывать сводку выбранных значений.

## Стилизация

Стилизуйте Listbox через `className` в React или `class` в Solid на экспортируемых частях. Варианты
Tailwind используют нативные utility-классы и классы потребителя, а варианты с CSS Modules используют
публичные CSS-переменные `--moduix-listbox-*`.

### CSS-свойства

<CssPropertiesSection properties={ListboxDocs.listboxOverrideCssProperties} />

### Хуки стилизации

- Хуки анатомии Ark: `data-scope="listbox"` и `data-part` на корне, подписи, поле, содержимом,
  группе элементов, подписи группы, элементе, тексте элемента, индикаторе, тексте выбранного
  значения и пустом состоянии.
- Хуки состояния: `data-orientation`, `data-disabled`, `data-empty`, `data-layout`,
  `data-activedescendant`, `data-value`, `data-selected`, `data-state` и `data-highlighted`.
- Хуки moduix: `data-slot="listbox-root"`, `listbox-root-provider`, `listbox-label`,
  `listbox-filter`, `listbox-filter-icon`, `listbox-input`, `listbox-clear-trigger`,
  `listbox-content`, `listbox-empty`, `listbox-item-group`, `listbox-item-group-label`,
  `listbox-item`, `listbox-item-text`, `listbox-item-text-content`, `listbox-item-text-icon`,
  `listbox-item-text-label`, `listbox-item-indicator` и `listbox-value-text`.
