## Какой компонент выбрать

Используйте `Listbox`, когда варианты должны оставаться видимыми и пользователь выбирает элементы
из коллекции. Используйте `Select`, когда варианты должны открываться во всплывающем списке.
Используйте `Combobox`, когда пользователю нужен всплывающий список с полем для поиска или ввода
значения.

## Анатомия

```text
Listbox
├─ ListboxLabel
├─ ListboxFilter
│  ├─ ListboxInput
│  └─ ListboxClearTrigger
├─ ListboxContent
│  ├─ ListboxEmpty
│  ├─ ListboxItemGroup
│  │  ├─ ListboxItemGroupLabel
│  │  └─ ListboxItem[item]
│  │     ├─ ListboxItemText
│  │     └─ ListboxItemIndicator
│  └─ ListboxItem[item]
│     ├─ ListboxItemText
│     │  └─ ListboxItemTextContent (необязательно)
│     │     ├─ ListboxItemTextIcon (необязательно)
│     │     └─ ListboxItemTextLabel (необязательно)
│     └─ ListboxItemIndicator
└─ ListboxValueText

ListboxRootProvider
└─ то же дерево элементов, подключённое к состоянию из useListbox()
```

| Часть                      | Назначение                                                                                   |
| -------------------------- | -------------------------------------------------------------------------------------------- |
| `Listbox` | Управляет коллекцией, выбранными значениями, подсвеченным элементом и режимом выбора.        |
| `ListboxRootProvider`     | Отрисовывает дерево listbox из состояния, возвращённого `useListbox`.                        |
| `ListboxLabel`            | Подпись, задающая listbox доступное имя.                                                      |
| `ListboxFilter`           | Визуальная обёртка для поля фильтра с иконкой поиска по умолчанию. Размещайте перед `ListboxContent`. |
| `ListboxInput`            | Поле фильтра, обычно размещаемое внутри `ListboxFilter`.                                            |
| `ListboxClearTrigger`     | Кнопка сброса запроса фильтра с иконкой закрытия по умолчанию.                               |
| `ListboxContent`          | Фокусируемый контейнер listbox, управляющий навигацией с клавиатуры.                          |
| `ListboxEmpty`            | Содержимое, отображаемое, когда после фильтрации не осталось элементов.                       |
| `ListboxItemGroup`        | Обёртка для связанных элементов коллекции.                                                   |
| `ListboxItemGroupLabel`   | Подпись группы элементов коллекции.                                                          |
| `ListboxItem`             | Выбираемый элемент. Передайте его элемент коллекции через `item`.                            |
| `ListboxItemText`         | Текст для отображения и доступности.                                                         |
| `ListboxItemTextContent`  | Необязательная обёртка для размещения иконки и текста внутри `ListboxItemText`.                     |
| `ListboxItemTextIcon`     | Необязательная обёртка для иконки внутри `ListboxItemTextContent`.                                 |
| `ListboxItemTextLabel`    | Обёртка текста внутри `ListboxItemTextContent`, которая позволяет обрезать длинные подписи без нарушения разметки. |
| `ListboxItemIndicator`    | Индикатор выбора с иконкой галочки moduix по умолчанию.                                      |
| `ListboxValueText`        | Сводка выбранных значений.                                                                   |

## Композиция

Используйте `defaultValue` для неконтролируемого выбора. Если выбранными значениями управляет другая
часть приложения, передайте `value` и обновляйте его из `onValueChange(details.value)`. Для
фильтрации задайте `typeahead={false}`, храните запрос в состоянии приложения и вызывайте функцию
`filter`, возвращённую `useListCollection`, из обработчика поля. `ListboxFilter` отвечает только за объединённый внешний
вид поля поиска, поэтому обработчик очистки должен сбрасывать и запрос, и фильтр коллекции.

Используйте `useListbox` из пакета выбранного фреймворка вместе с `ListboxRootProvider`, если
хранилище нужно создать вне отрисовываемого дерева. Передайте полученное хранилище в `ListboxRootProvider`
и не добавляйте для него второй `Listbox`. `ListboxInput` можно отрисовать напрямую,
если фильтру нужен отдельный контейнер, а `ListboxValueText` можно разместить после `ListboxContent`,
чтобы показывать сводку выбранных значений.

## Стилизация

Стилизуйте Listbox через `className` в React или `class` в Solid и Vue на экспортируемых частях.
Варианты Tailwind используют нативные utility-классы и классы потребителя. Варианты с CSS Modules берут
цвета, отступы и типографику из токенов foundation и выносят в CSS-переменные только ширину корня и
максимальную высоту содержимого; остальное переопределяйте классом на части. Пункты, подписи групп и
отступы списка также следуют общим переменным `--moduix-popup-item-*`, `--moduix-popup-group-label-*` и
`--moduix-popup-list-padding-y`.

### Хуки стилизации

- Хуки анатомии Ark: `data-scope="listbox"` и `data-part` на корне, подписи, поле, содержимом,
  группе элементов, подписи группы, элементе, тексте элемента, индикаторе, тексте выбранного
  значения и пустом состоянии.
- Хуки состояния: `data-orientation`, `data-disabled`, `data-empty`, `data-layout`,
  `data-activedescendant`, `data-value`, `data-selected`, `data-state` и `data-highlighted`.
- Хуки moduix: `data-slot="listbox-root"`, `listbox-root-provider`, `listbox-label`,
  `listbox-filter`, `listbox-filter-icon`, `listbox-input`, `listbox-clear-trigger`,
  `listbox-content`, `listbox-empty`, `listbox-item-group`, `listbox-item-group-label`,
  `listbox-item`, `listbox-item-text`, `listbox-item-text-content`, `listbox-item-text-icon`,
  `listbox-item-text-label`, `listbox-item-indicator` и `listbox-value-text`.
