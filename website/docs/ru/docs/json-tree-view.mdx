Адаптеры фреймворков сохраняют одинаковые плоские имена компонентов; в примере Vue используются нативный SFC и
именованные слоты.

Передайте через `data` любое JSON-подобное JavaScript-значение, а внутри компонента добавьте
`<JsonTreeViewTree />`. `JsonTreeView` сам создаёт узлы объектов, массивов и значений. moduix оформляет строки,
отступы, состояния фокуса и стрелку раскрытия по умолчанию.

В примере сразу раскрыты два уровня. С помощью `defaultExpandedDepth` задайте, какая часть ответа или конфигурации
должна быть видна при первом отображении.

## Какой компонент выбрать

Используйте `JsonTreeView`, если у вас уже есть JavaScript-значение и его нужно просмотреть, не реализуя
рекурсивный рендеринг вручную. Выбирайте `TreeView`, если вы сами управляете моделью узлов и хотите задавать
подписи, иконки, ссылки, переименование или содержимое ветвей.

## Примеры

### Компактные превью

Используйте `maxPreviewItems`, чтобы ограничить превью объектов и массивов. Параметр
`collapseStringsAfterLength` сокращает длинные строки, пока пользователь не раскроет узел и не посмотрит его
значение полностью.

## Композиция

Оставляйте `JsonTreeViewTree` дочерней частью `JsonTreeView` или `JsonTreeViewRootProvider`: она отображает
сгенерированные узлы JSON. Если состояние дерева принадлежит внешним элементам управления, создайте
`useJsonTreeView` из соответствующего фреймворк-пакета, передайте состояние в `JsonTreeViewRootProvider` и
выведите внутри него `JsonTreeViewTree`. Используйте управляемые `expandedValue`, `selectedValue`, `checkedValue` или
`focusedValue`, только когда состояние должно принадлежать приложению. Не используйте `JsonTreeView` и `JsonTreeViewRootProvider` для
одного состояния.

## Стилизация

Используйте `className` в React или `class` в Solid и Vue на `JsonTreeView`, `JsonTreeViewRootProvider` или `JsonTreeViewTree`, чтобы локально изменить
компоновку. Варианты Tailwind используют классы Tailwind и классы приложения. Варианты с CSS Modules используют
свои стили и базовые токены.

Если не передать `arrow`, `JsonTreeViewTree` использует `ChevronRightIcon` из moduix в React и Solid. В Vue
передайте собственную иконку через именованный слот `#arrow`, если для области просмотра нужна другая стрелка
раскрытия.

Сгенерированные узлы сохраняют атрибуты Ark `data-scope="json-tree-view"` и `data-part`.

`JsonTreeViewTree` пробрасывает проп Ark `indentGuide`, когда вы включаете направляющие отступов. moduix не
стилизует сгенерированные элементы `[data-part='branch-indent-guide']`; при включённых направляющих задайте им
стили самостоятельно через этот атрибут.

В Vue используйте именованный слот `#indentGuide`, чтобы задать свою разметку направляющих.

Компонент напрямую использует базовые токены и не вводит отдельный слой переменных
`--moduix-json-tree-view-*`. Если области просмотра нужно другое оформление, добавьте класс или обратитесь к
атрибутам частей Ark.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `JsonTreeView` | `json-tree-view-root` |
| `JsonTreeViewRootProvider` | `json-tree-view-root-provider` |
| `JsonTreeViewTree` | `json-tree-view-tree` |

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `ArrowDown` / `ArrowUp` | Переводит фокус на следующую или предыдущую строку. |
| `ArrowRight` / `ArrowLeft` | Открывает или закрывает объект или массив в фокусе. |
| `Home` / `End` | Переводит фокус на первую или последнюю строку. |
