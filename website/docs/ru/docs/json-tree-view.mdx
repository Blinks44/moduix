## Какой компонент выбрать

Используйте `JsonTreeView`, если у вас уже есть JavaScript-значение и его нужно просмотреть, не реализуя
рекурсивный рендеринг вручную. Выбирайте `TreeView`, если вы сами управляете моделью узлов и хотите задавать
подписи, иконки, ссылки, переименование или содержимое ветвей.

## Анатомия

```text
JsonTreeView
└─ JsonTreeViewTree
   └─ сгенерированные ветви и элементы JSON

JsonTreeViewRootProvider
└─ то же дерево, подключённое к состоянию useJsonTreeView
```

| Часть | Назначение |
| --- | --- |
| `JsonTreeView` | Хранит данные, сгенерированную коллекцию и состояние дерева Ark. |
| `JsonTreeViewRootProvider` | Подключает к частям состояние `useJsonTreeView`, созданное вне дерева. |
| `JsonTreeViewTree` | Отображает сгенерированные узлы объектов, массивов и значений. |

## Композиция

Оставляйте `JsonTreeViewTree` дочерней частью `JsonTreeView` или `JsonTreeView`: она отображает
сгенерированные узлы JSON. Если состояние дерева принадлежит внешним элементам управления, создайте
`useJsonTreeView` из соответствующего фреймворк-пакета, передайте состояние в `JsonTreeViewRootProvider` и
выведите внутри него `Tree`. Используйте управляемые `expandedValue`, `selectedValue`, `checkedValue` или
`focusedValue`, только когда состояние должно принадлежать приложению. Не используйте `Root` и `RootProvider` для
одного состояния.

## Стилизация

Используйте `className` в React или `class` в Solid на `Root`, `RootProvider` или `Tree`, чтобы локально изменить
компоновку. Варианты Tailwind используют классы Tailwind и классы приложения. Варианты с CSS Modules используют
свои стили и базовые токены.

Если не передать `arrow`, `JsonTreeViewTree` использует `ChevronRightIcon` из moduix. Передайте собственную иконку
через `arrow`, если для области просмотра нужна другая стрелка раскрытия.

Сгенерированные узлы сохраняют атрибуты Ark `data-scope="json-tree-view"` и `data-part`. moduix добавляет
стабильные селекторы `data-slot="json-tree-view-root"`, `json-tree-view-root-provider` и `json-tree-view-tree`.

`JsonTreeViewTree` пробрасывает проп Ark `indentGuide`, когда вы включаете направляющие отступов. moduix не
стилизует сгенерированные элементы `[data-part='branch-indent-guide']`; при включённых направляющих задайте им
стили самостоятельно через этот атрибут.

Компонент напрямую использует базовые токены и не вводит отдельный слой переменных
`--moduix-json-tree-view-*`. Если области просмотра нужно другое оформление, добавьте класс или обратитесь к
атрибутам частей Ark.
