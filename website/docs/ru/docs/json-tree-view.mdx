## Какой компонент выбрать

Используйте `JsonTreeView`, если у вас уже есть JavaScript-значение и его нужно просмотреть, не реализуя
рекурсивный рендеринг вручную. Выбирайте `TreeView`, если вы сами управляете моделью узлов и хотите задавать
подписи, иконки, ссылки, переименование или содержимое ветвей.

## Базовый пример

Передайте через `data` любое JSON-подобное JavaScript-значение, а внутри компонента добавьте
`<JsonTreeView.Tree />`. `JsonTreeView` сам создаёт узлы объектов, массивов и значений. moduix оформляет строки,
отступы, состояния фокуса и стрелку раскрытия по умолчанию.

В примере сразу раскрыты два уровня. С помощью `defaultExpandedDepth` задайте, какая часть ответа или конфигурации
должна быть видна при первом отображении.

## Анатомия

```text
JsonTreeView / JsonTreeView.Root
└─ JsonTreeView.Tree
   └─ сгенерированные ветви и элементы JSON
```

| Часть | Назначение |
| --- | --- |
| `JsonTreeView` / `JsonTreeView.Root` | Хранит данные, сгенерированную коллекцию и состояние дерева Ark. |
| `JsonTreeView.RootProvider` | Подключает состояние `useJsonTreeView`, созданное вне отображаемого дерева. |
| `JsonTreeView.Tree` | Отображает сгенерированные узлы объектов, массивов и значений. |

## Композиция

### Рекомендуемый вариант

Для обычного просмотрщика данных используйте сокращённую запись `<JsonTreeView>` вместе с
`<JsonTreeView.Tree />`. Она равнозначна `<JsonTreeView.Root>`, а `Tree` сам создаёт JSON-узлы.

### Когда нужна собственная разметка

Используйте `TreeView`, если приложение должно само определять, как отображать ветви и элементы. Если структура
узлов подходит, но отдельным значениям нужно другое представление, передайте `renderValue` в
`JsonTreeView.Tree`.

### RootProvider

Используйте `useJsonTreeView`, если кнопкам и другим элементам за пределами дерева нужно читать или менять его
состояние, например список раскрытых или выбранных узлов. Передайте полученное состояние в `RootProvider` и
выведите внутри него `Tree`. Не используйте `Root` и `RootProvider` для одного экземпляра состояния.

```tsx
import { JsonTreeView, useJsonTreeView } from '@moduix/react/json-tree-view';

function InspectResponse({ data }: { data: unknown }) {
  const tree = useJsonTreeView({ data });

  return (
    <JsonTreeView.RootProvider value={tree}>
      <JsonTreeView.Tree />
    </JsonTreeView.RootProvider>
  );
}
```

### Основные параметры

| Prop | Назначение |
| --- | --- |
| `defaultExpandedDepth` | Задаёт начальное число раскрытых уровней. |
| `maxPreviewItems` | Ограничивает число элементов в превью объектов и массивов. |
| `collapseStringsAfterLength` | Сокращает превью длинных строк, пока узел не раскрыт. |
| `groupArraysAfterLength` | Группирует элементы в превью длинных массивов. |
| `renderValue` | Заменяет стандартное отображение отдельных значений. |
| `translations` | Позволяет передать локализованные подписи и текст состояний для доступности. |

### Особенности поведения

Ark поддерживает объекты, массивы, примитивы и такие JavaScript-значения, как `Date`, `Map`, `Set`, `Error`,
функции и регулярные выражения. Компонент следует паттерну дерева WAI-ARIA: управляет перемещением фокуса,
навигацией стрелками, раскрытием и выбором. Если состояние должно храниться в приложении, управляйте
`expandedValue`, `selectedValue`, `checkedValue` или `focusedValue` и обновляйте его в обработчике соответствующего
изменения.

## Стилизация

Используйте `className` на `Root`, `RootProvider` или `Tree`, чтобы локально изменить компоновку. Если не передать
`arrow`, `JsonTreeView.Tree` использует `ChevronRightIcon` из moduix. Передайте собственную иконку через `arrow`,
если для области просмотра нужна другая стрелка раскрытия.

Сгенерированные узлы сохраняют атрибуты Ark `data-scope="json-tree-view"` и `data-part`. moduix добавляет
стабильные селекторы `data-slot="json-tree-view-root"`, `json-tree-view-root-provider` и
`json-tree-view-tree`.

Компонент напрямую использует базовые токены и не вводит отдельный слой переменных
`--moduix-json-tree-view-*`. Если области просмотра нужно другое оформление, добавьте `className` или обратитесь
к атрибутам частей Ark.
