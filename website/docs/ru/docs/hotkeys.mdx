## Когда использовать

Hotkeys помогает регистрировать команды с клавиатуры в Ark UI. Используйте его для таких действий, как сохранение черновика, открытие поиска или переход в другой раздел. `useHotkey` слушает события клавиатуры на уровне документа и удаляет свою регистрацию при размонтировании компонента.

Импортируйте хуки напрямую из Ark UI:

```tsx
import { useFormatHotkey, useHotkey, useHotkeys } from '@ark-ui/react';
```

## Простое сочетание

Используйте `mod`, чтобы одно сочетание работало и на macOS, и на Windows или Linux. После монтирования компонента `useFormatHotkey` покажет обозначение, принятое на платформе пользователя.

## Несколько сочетаний и последовательности

Используйте `useHotkeys`, когда на экране несколько команд или список команд формируется из данных. Хук принимает массив команд. Для каждой команды обязательны `hotkey` и `action`; добавьте `label`, `category` или `keywords`, если приложению нужны метаданные для команды.

Разделяйте клавиши в последовательности символом `>`, например `g > i`. По умолчанию у пользователя есть одна секунда, чтобы нажать следующую клавишу.

## Поля ввода и области действия

По умолчанию сочетания из одной клавиши не срабатывают, пока фокус находится в `input`, `textarea` или `select`. Сочетания с модификатором продолжают работать, поэтому `mod+S` может сохранять данные формы. Включайте одноклавишные сочетания в полях ввода только тогда, когда это действительно нужно:

```tsx
useHotkey({
  action: focusSearch,
  hotkey: '/',
  options: { enableOnFormTags: true },
});
```

Используйте `scopes`, чтобы ограничить команду частью приложения. Команда срабатывает только тогда, когда активна одна из её областей.

## Отдельное хранилище сочетаний

Создайте отдельное хранилище, если разным частям приложения нужны независимые команды или разные настройки по умолчанию. Храните его вне компонента или мемоизируйте. Если создавать хранилище во время рендера, оно будет пересоздаваться при каждом рендере и потеряет зарегистрированные команды.

```tsx
import { createHotkeyStore, useHotkey } from '@ark-ui/react';

const editorHotkeys = createHotkeyStore({
  activeScopes: ['editor'],
  sequenceTimeoutMs: 800,
});

function Editor() {
  const save = () => {
    // Save the current document.
  };

  useHotkey({
    action: save,
    hotkey: 'mod+S',
    scopes: ['editor'],
    store: editorHotkeys,
  });
}
```

Вызовите `editorHotkeys.setScope('preview')`, когда активная часть приложения меняется. Передавайте это же хранилище в `useHotkeys` или `useHotkey`, чтобы держать их команды в одном изолированном реестре.

## Отображение сочетания

`useFormatHotkey` возвращает форматтер для текущей платформы. Например, `mod+K` превращается в `⌘ K` на macOS и `Ctrl K` на других платформах. В приложении с SSR используйте этот хук внутри компонента, а не импортируйте `formatHotkey` напрямую во время рендера. Так серверная и браузерная разметка не разойдутся при гидрации.

## Дополнительные возможности

Используйте `enabled`, чтобы включать и выключать команду. В `enabled` можно передать функцию, если состояние нужно читать при каждом нажатии, не перерегистрируя команду. Задайте `options.eventType` как `'keyup'`, чтобы выполнять действие после отпускания клавиши. Если смысл взаимодействия зависит от зажатых клавиш, используйте `usePressedKeys` или `useIsKeyPressed`.

## Использование с moduix

Используйте `Kbd` из moduix, чтобы сочетание было легко распознать, и размещайте его рядом с соответствующим действием. `Card`, `Stack` и `Button` помогают связать подсказку с элементом управления. Эти компоненты отвечают только за отображение подсказки, а регистрацию сочетаний и события клавиатуры по-прежнему обрабатывает Ark UI Hotkeys.

## Что делает приложение

Hotkeys регистрирует команды, сопоставляет их с нажатиями, форматирует обозначения сочетаний и управляет областями действия. `useHotkeyRegistrations` возвращает зарегистрированные команды и их метаданные, поэтому палитру команд можно держать синхронизированной с реестром сочетаний. Побочные эффекты команд, интерфейс палитры, хранение данных и навигация остаются на стороне приложения.
