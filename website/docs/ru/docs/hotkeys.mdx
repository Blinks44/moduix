## Когда использовать

Используйте Hotkeys для команд с клавиатуры: сохранить черновик, открыть поиск или перейти в нужный раздел. Хук отслеживает нажатия на документе и снимает обработчик при размонтировании компонента.

Импортируйте хуки напрямую из Ark UI:

```tsx
import { useFormatHotkey, useHotkey, useHotkeys } from '@ark-ui/react';
```

## Базовый пример

Используйте `mod`, чтобы не выбирать между Control и Command. После монтирования `useFormatHotkey` покажет обозначение, принятое на платформе пользователя.

## Несколько сочетаний и последовательности

Используйте `useHotkeys`, если на экране несколько команд или команды приходят из данных. Последовательность записывается через `>`, например `g > i`. По умолчанию на неё отводится одна секунда.

## Поля ввода и области действия

Одноклавишные сочетания по умолчанию не срабатывают в `input`, `textarea` и `select`, а сочетания с модификатором продолжают работать. Включайте их в полях ввода только при необходимости:

```tsx
useHotkey({
  action: focusSearch,
  hotkey: '/',
  options: { enableOnFormTags: true },
});
```

Для независимых частей приложения создайте стабильное хранилище сочетаний вне компонента или мемоизируйте его. Области действия включают только команды для текущего раздела или палитры команд.

## Использование с moduix

Используйте `Kbd` из moduix, чтобы сочетание было легко распознать, и размещайте его рядом с действием. `Card`, `Stack` и `Button` помогают связать подсказку с элементом управления.

## Границы ответственности

Hotkeys регистрирует и форматирует сочетания клавиш. Палитру команд, хранение данных и навигацию приложение реализует само.
