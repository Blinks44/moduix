`Hotkeys` - утилита Ark UI для регистрации команд с клавиатуры. Она слушает события документа или
другого объекта, указанного через `target`, а приложение отвечает за действие команды и видимые
элементы управления.

## Зарегистрировать сочетание клавиш

Используйте `useHotkey` для одной команды. Команда регистрируется при монтировании компонента и
удаляется при его размонтировании. `mod` означает Command на macOS и Control на Windows и Linux,
поэтому одно и то же описание работает на всех платформах.

В `action` передаётся `KeyboardEvent`, поэтому при необходимости действие может разобрать событие.
Добавьте `options.preventDefault`, если сочетание намеренно заменяет команду браузера. Важное
действие должно оставаться доступным через видимую кнопку или другой доступный элемент управления.

## Зарегистрировать несколько сочетаний

Используйте `useHotkeys` с массивом `commands`, когда на экране несколько команд или они приходят из
данных. Для каждой команды обязательны `hotkey` и `action`; `id`, `label`, `description`, `category`
и `keywords` помогают обращаться к командам и передавать метаданные в палитру команд.

Разделяйте шаги последовательности символом `>`. Тайм-аут последовательности по умолчанию равен
1000 миллисекундам.

## Области действия и параметры

По умолчанию Hotkeys использует общее хранилище. Создайте стабильное хранилище через
`createHotkeyStore`, если части приложения нужны свои команды, настройки или активные области.
Создавайте его вне компонента или мемоизируйте в React, чтобы хранилище не пересоздавалось во время
рендера. Передавайте одно и то же хранилище в `useHotkey`, `useHotkeys`, `useHotkeyRegistrations` или
`useHotkeyStore`.

- `scopes` принимает строку или массив. Команда срабатывает, когда активна хотя бы одна из её
  областей. Используйте `store.setScope('preview')`, чтобы заменить активные области, или
  `addScope`, `removeScope` и `toggleScope`, чтобы изменить их.
- `enabled` принимает boolean или функцию. Функция проверяется в момент нажатия и позволяет читать
  актуальное состояние приложения без повторной регистрации команды.
- Для одноклавишных сочетаний `options.enableOnFormTags` по умолчанию равен `false`. Установите
  `true` или массив из `input`, `textarea` и `select`, только если сочетание должно работать во время
  ввода. Сочетания с модификатором и так работают в полях формы.
- Используйте `options.enableOnContentEditable` для редактируемых областей, `options.target` для
  поддерева DOM и `options.stopPropagation`, если действие должно остановить дальнейшее распространение
  события.
- Установите `options.eventType` в `'keyup'`, чтобы выполнять действие после отпускания клавиши, а
  `options.requireReset` - чтобы повторное событие не запускало команду до отпускания клавиши.
- `conflictBehavior` определяет поведение при одинаковых сочетаниях в одном хранилище: по умолчанию
  используется `'warn'`, а `'error'`, `'replace'` и `'allow'` дают более строгие или тихие варианты.
  Тайм-аут задаётся через `sequenceTimeoutMs`, общие настройки команд - через `defaultOptions`.

## Отобразить сочетание

Hotkeys не рисует подсказку. Используйте `useFormatHotkey` внутри компонента, чтобы показать сочетание
в обозначении текущей платформы: например, `mod+K` превращается в `⌘ K` на macOS и `Ctrl K` на других
платформах. В SSR-приложении выбирайте этот хук вместо прямого вызова `formatHotkey` во время рендера
компонента, чтобы начальная разметка на сервере и в браузере совпадала.

## Читать регистрации и состояние клавиш

Используйте дополнительные хуки, когда приложению нужно работать с реестром, а не только
зарегистрировать команду:

| Задача | API |
| --- | --- |
| Показать зарегистрированные команды в палитре | `useHotkeyRegistrations` |
| Дать пользователю записать новое сочетание | `useHotkeyRecorder` |
| Реагировать на зажатые клавиши во время другого взаимодействия | `usePressedKeys` или `useIsKeyPressed` |
| Узнать текущую платформу | `usePlatform` |

В Solid значения, которые возвращают эти хуки, являются accessors: используйте `registrations()`,
`pressedKeys()`, `isPressed()` и `platform()`. В React хуки возвращают текущее значение напрямую.
Записанное сочетание можно сохранить через `stop`, отменить через `cancel` или удалить через `clear`.

Hotkeys отвечает за регистрацию, сопоставление, форматирование, области и запись сочетаний. Побочные
эффекты, навигация, хранение данных, интерфейс палитры команд, управление фокусом и доступный способ
выполнить каждое важное действие без клавиатуры остаются в приложении.
