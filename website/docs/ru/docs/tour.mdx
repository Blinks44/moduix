## Базовый пример

Tour доступен для React и Solid в пакетах CSS Modules и Tailwind. Превью на этой странице использует пакет React
CSS Modules, а вкладки фреймворков показывают нативный исходный код с тем же публичным контрактом.

Создайте состояние тура через `useTour`, опишите шаги и передайте возвращённый объект в `Tour`. В примере сначала
открывается диалог, затем подсказка у элемента интерфейса, а в конце появляется плавающий шаг. Оставляйте части
композиции явными, чтобы при необходимости изменить их. `Tour.Body` прокручивает длинный текст внутри панели.

## Анатомия

```text
Tour / Tour.Root
└─ Поддерево оверлея (по умолчанию выводится в портал)
   ├─ Tour.Backdrop
   ├─ Tour.Spotlight
   └─ Tour.Positioner
      └─ Tour.Content
         ├─ Tour.Arrow
         ├─ Tour.CloseIcon / Tour.CloseTrigger
         ├─ Tour.Body
         │  ├─ Tour.Title
         │  ├─ Tour.Description
         │  └─ Tour.ProgressText
         └─ Tour.Control
            ├─ Tour.ActionList
            └─ Tour.Actions
               └─ Tour.ActionTrigger[action]
```

| Часть | Роль |
| --- | --- |
| `Tour` / `Tour.Root` | Корневой компонент, связанный с объектом, который возвращает `useTour`. |
| `Tour.Backdrop` / `Tour.Spotlight` | Необязательный фон и подсветка текущего целевого элемента. |
| `Tour.Positioner` / `Tour.Content` | Позиционируют и отображают элемент `alertdialog` из Ark. |
| `Tour.Arrow` | По умолчанию выводит `ArrowTip` из moduix для шагов с подсказкой. |
| `Tour.CloseIcon` / `Tour.CloseTrigger` | Доступное закрытие по умолчанию или собственная кнопка закрытия. |
| `Tour.Body` | Прокручиваемая обёртка moduix для заголовка, описания и текста прогресса. |
| `Tour.Control` / `Tour.ActionList` | Рекомендуемая строка действий и действия текущего шага. |
| `Tour.Actions` / `Tour.ActionTrigger` | Позволяют отрисовать свои действия, сохранив объекты действий Ark. |

## Композиция

Создайте состояние через `useTour` и передайте его в `Tour`. В Solid результат является accessor, поэтому для вызова
методов вроде `start()` и `next()` используйте `tour()`. Оставляйте структурные части явными и добавляйте `Title` и
`Description`, чтобы у `alertdialog` были доступные имя и описание. `Backdrop`, `Spotlight` и `Positioner` по
умолчанию выводятся в портал; используйте `portalled={false}` или `portalRef`, только если оверлей должен остаться в
разметке или попасть в определённый контейнер. Используйте `ActionList` для действий из `steps`, а для собственной
разметки заменяйте его на `Actions` с `ActionTrigger asChild`. По умолчанию `lazyMount` и `unmountOnExit` равны `true`;
передавайте колбэки в `useTour`, если внешний интерфейс или аналитика должны реагировать на смену шага или статуса.

### Хуки стилизации

Для локальной стилизации используйте атрибуты moduix `data-slot`, например `tour-content`, `tour-body` и
`tour-action-trigger`. Ark также добавляет `data-scope="tour"`, `data-part`, `data-state`, `data-type`,
`data-placement`, `data-side`, `data-step` и `data-disabled`, а также CSS-переменные `--tour-layer`, `--tour-z-index`,
`--available-width`, `--available-height`, `--transform-origin` и переменные стрелки. Передайте `className` в
`Tour.ActionList`, чтобы стилизовать каждый созданный триггер. Если пользователь уменьшил анимации в системе, стили
сокращают анимацию оверлея и убирают переходы у кнопок действий.
