## Анатомия

```text
Tour
└─ Поддерево оверлея (по умолчанию выводится в портал)
   ├─ TourBackdrop
   ├─ TourSpotlight
   └─ TourPositioner
      └─ TourContent
         ├─ TourArrow
         ├─ TourCloseIcon / TourCloseTrigger
         ├─ TourBody
         │  ├─ TourTitle
         │  ├─ TourDescription
         │  └─ TourProgressText
         └─ TourControl
            ├─ TourActionList
            └─ TourActions
               └─ TourActionTrigger[action]
```

| Часть | Роль |
| --- | --- |
| `Tour` | Корневой компонент, связанный с объектом, который возвращает `useTour`. |
| `TourBackdrop` / `TourSpotlight` | Необязательный фон и подсветка текущего целевого элемента. |
| `TourPositioner` / `TourContent` | Позиционируют и отображают элемент `alertdialog` из Ark. |
| `TourArrow` | По умолчанию выводит `TourArrowTip` из moduix для шагов с подсказкой. |
| `TourCloseIcon` / `TourCloseTrigger` | Доступное закрытие по умолчанию или собственная кнопка закрытия. |
| `TourBody` | Прокручиваемая обёртка moduix для заголовка, описания и текста прогресса. |
| `TourControl` / `TourActionList` | Рекомендуемая строка действий и действия текущего шага. |
| `TourActions` / `TourActionTrigger` | Позволяют отрисовать свои действия, сохранив объекты действий Ark. |

## Композиция

Создайте состояние через `useTour` и передайте его в `Tour`. В Solid результат является accessor, поэтому для вызова
методов вроде `start()` и `next()` используйте `tour()`. В Vue результат является ref: в шаблоне он раскрывается
автоматически, а в коде скрипта методы вызываются через `tour.value`. Оставляйте структурные части явными и добавляйте `TourTitle` и
`TourDescription`, чтобы у `alertdialog` были доступные имя и описание. `TourBackdrop`, `TourSpotlight` и `TourPositioner` по
умолчанию выводятся в портал; используйте `portalled={false}` или `portalRef`, только если оверлей должен остаться в
разметке или попасть в определённый контейнер. Используйте `TourActionList` для действий из `steps`, а для собственной
разметки заменяйте его на `TourActions` с `TourActionTrigger asChild`. По умолчанию `lazyMount` и `unmountOnExit` равны `true`;
передавайте колбэки в `useTour`, если внешний интерфейс или аналитика должны реагировать на смену шага или статуса.
В Vue задавайте колбэки состояния, например `onStepChange` и `onStatusChange`, в `useTour`;
событие `@exit-complete` на `Tour` сообщает о завершении анимации скрытия. Ark Vue сейчас объявляет
другие события корня, но не отправляет их для объекта состояния, созданного вне корня.

## Стилизация

Ширина `TourContent`: 20rem у шагов-подсказок, 26rem у диалоговых и 22rem у плавающих шагов, в пределах
окна и доступного места от Ark. Высота ограничена 24rem: помещайте текст шага в `TourBody`, чтобы он
прокручивался, а не выходил за панель. Плавающие шаги стоят в 1.5rem от края окна, заданного `placement`,
или в центре окна при `placement: 'center'`. Слои оверлея начинаются с токена `--moduix-z-tour`: фон,
подсветка и позиционер идут в этом порядке, выше диалогов и всплывающих окон, но ниже уведомлений. `TourCloseTrigger` без стилей, а `TourCloseIcon` это готовая кнопка
закрытия с иконкой. Анимация панели читает общие переменные `--moduix-popup-motion-*`, а анимации фона и
панели отключаются, если пользователь уменьшил движение в системе.

Передавайте `className` в React или `class` в Solid и Vue экспортируемым частям. Варианты Tailwind используют
обычные утилиты и классы потребителя. Варианты CSS Modules построены на токенах foundation и не имеют
переменных компонента: класс на части переопределяет стили компонента из слоя. Передайте `className` (или
`class`) в `TourActionList`, чтобы стилизовать каждый созданный триггер.

### Хуки стилизации

Основные публичные хуки: `data-slot="tour-backdrop"`, `tour-spotlight`, `tour-positioner`, `tour-content`,
`tour-arrow`, `tour-arrow-tip`, `tour-title`, `tour-description`, `tour-progress-text`, `tour-body`,
`tour-close-trigger`, `tour-close-icon`, `tour-control` и `tour-action-trigger`. Ark также добавляет
`data-scope="tour"`, `data-part`, `data-state`, `data-type`, `data-placement`, `data-side`, `data-step` и
`data-disabled`, а также переменные времени выполнения, включая `--tour-layer`, `--available-width`,
`--available-height`, `--transform-origin` и переменные стрелки.
