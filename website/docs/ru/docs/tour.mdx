## Базовый пример

Создайте состояние тура через `useTour`, опишите шаги и передайте возвращённый объект в `Tour`.
В примере сначала открывается диалог, затем подсказка у элемента интерфейса, а в конце появляется
плавающий шаг. Все элементы композиции остаются в JSX, поэтому их легко настроить при необходимости.
`Tour.Body` прокручивает длинный текст внутри панели.

## Анатомия

```text
Tour
└─ Поддерево оверлея (по умолчанию выводится в портал)
   ├─ Tour.Backdrop
   ├─ Tour.Spotlight
   └─ Tour.Positioner
      └─ Tour.Content
         ├─ Tour.Arrow
         ├─ Tour.CloseIcon / Tour.CloseTrigger
         ├─ Tour.Body
         │  ├─ Tour.Title
         │  ├─ Tour.Description
         │  └─ Tour.ProgressText
         └─ Tour.Control
            ├─ Tour.ActionList
            └─ Tour.Actions
               └─ Tour.ActionTrigger[action]
```

| Часть | Роль |
| --- | --- |
| `Tour` | Корневой компонент, получающий объект `UseTourReturn`. `Tour.Root` является его псевдонимом. |
| `Tour.Backdrop` / `Tour.Spotlight` | Необязательный фон и подсветка текущего целевого элемента. |
| `Tour.Positioner` / `Tour.Content` | Позиционируют и отображают элемент `alertdialog` из Ark. |
| `Tour.Arrow` | По умолчанию выводит `ArrowTip` из moduix для шагов с подсказкой. |
| `Tour.CloseIcon` | Кнопка закрытия с доступным именем и иконкой. Для своей разметки используйте `CloseTrigger`. |
| `Tour.Body` | Прокручиваемая обёртка moduix для заголовка, описания и текста прогресса. |
| `Tour.Control` / `Tour.ActionList` | Рекомендуемая строка действий и действия текущего шага. |
| `Tour.Actions` / `Tour.ActionTrigger` | Позволяют отрисовать свои действия, сохранив объекты действий Ark. |

## Композиция

### Рекомендуемая композиция

`Tour` автоматически выводит `Backdrop`, `Spotlight` и `Positioner` в портал. Укажите
`portalled={false}`, только если оверлей должен остаться в разметке страницы, или передайте
`portalRef`, чтобы отрисовать его в определённом контейнере. Оставляйте структурные части явными.
Добавьте `Tour.ActionList`, если вашему интерфейсу подходят действия из `steps`: он отрисует
действия текущего шага.

### Когда нужна своя разметка

Используйте `Tour.Actions` и `Tour.ActionTrigger`, когда для действия требуется своя разметка. Они
сохраняют поведение Ark: навигацию, закрытие и отключённое состояние, но позволяют отрисовать свои
элементы управления. Передайте в `useTour` `onStepChange`, `onStepsChange` или `onStatusChange`,
если на тур должен реагировать внешний интерфейс или система аналитики. Внутри дерева доступны
экспорты moduix `useTourContext` и `Tour.Context`: с их помощью можно получить активный шаг и
методы навигации.

### Свойства по умолчанию

Содержимое оверлея в портале монтируется при первом открытии и удаляется после анимации закрытия.
Укажите `unmountOnExit={false}`, чтобы сохранить его после первого открытия. Оба свойства
жизненного цикла стоит устанавливать в `false`, только если оверлей должен отрисоваться сразу.

| Свойство | По умолчанию | Примечание |
| --- | --- | --- |
| `closeOnEscape` | `true` | Клавиша Escape закрывает тур. |
| `closeOnInteractOutside` | `true` | Взаимодействие за пределами тура закрывает его, если это не отключено. |
| `keyboardNavigation` | `true` | Стрелки влево и вправо переключают доступные шаги. |
| `preventInteraction` | `false` | Укажите `true`, чтобы блокировать действия на странице, пока тур открыт. |
| `spotlightOffset` | `{ x: 10, y: 10 }` | Расширяет область подсветки вокруг целевого элемента. |
| `spotlightRadius` | `4` | Скругляет углы подсветки. |
| `lazyMount` | `true` | Не создаёт оверлей до первого открытия. |
| `unmountOnExit` | `true` | Удаляет оверлей после анимации закрытия. |

### Поведение и доступность

`Tour.Title` задаёт доступное имя диалогового окна, а `Tour.Description` добавляет описание. Ark
управляет фокусом при открытии и закрытии, обработкой Escape, взаимодействием за пределами тура и
навигацией стрелками влево и вправо. Не отключайте `keyboardNavigation`, если только шаг не
использует эти клавиши намеренно. В интерфейсе с направлением RTL Ark меняет навигацию влево и
вправо местами.

### Хуки стилизации

Для локальной стилизации используйте атрибуты moduix `data-slot`, например `tour-content`,
`tour-body` и `tour-action-trigger`. Ark также добавляет `data-scope="tour"`, `data-part`,
`data-state`, `data-type`, `data-placement`, `data-side`, `data-step` и `data-disabled`, а также
CSS-переменные `--tour-layer`, `--tour-z-index`, `--available-width`, `--available-height`,
`--transform-origin` и переменные стрелки. Передайте `className` в `Tour.ActionList`, чтобы
стилизовать каждый созданный триггер. Если пользователь уменьшил анимации в системе, стили
сокращают анимацию оверлея и убирают переходы у кнопок действий.
