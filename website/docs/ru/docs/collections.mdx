# Коллекции

Коллекции Ark UI — слой данных для интерфейсов со списками. Они описывают идентификаторы и подписи элементов,
недоступное состояние и порядок обхода, а компоненты moduix отображают доступное взаимодействие поверх этих данных.

Используйте коллекцию, если данные нужны `Select`, `Combobox`, `Listbox`, `TreeView` или собственному списку. Эти API
импортируются напрямую из Ark UI, а на связанных страницах показано, как подключить их к компонентам moduix.
