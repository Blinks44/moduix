# Коллекции

Коллекции - это структуры данных и хуки для интерфейсов со списками. Они хранят значения и подписи элементов,
признак недоступности, иерархию и состояние асинхронной загрузки в формате, который понимают компоненты Ark UI.
Сами коллекции не рисуют интерфейс: доступное взаимодействие с данными предоставляют компоненты moduix.

Используйте коллекцию с `Select`, `Combobox`, `Listbox`, `TreeView`, собственным списком или деревом. Вспомогательные
функции коллекций импортируются напрямую из Ark UI. В руководствах ниже показано, как создавать и обновлять
коллекции, подключать их к компонентам moduix и управлять загрузкой или выбором.
