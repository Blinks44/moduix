# Коллекции

Коллекции — слой данных для списочных компонентов Ark UI. Они не входят в набор стилизованных
компонентов moduix: при работе с `Select`, `Combobox`, `Listbox`, `TreeView` или пользовательскими
интерфейсами на основе коллекций импортируйте их напрямую из Ark UI.

Поскольку приложение использует Ark UI напрямую, добавьте пакет в прямые зависимости:

```bash
npm install @ark-ui/react
```

Все API коллекций в этом разделе доступны через точку входа для React:

```tsx
import { createListCollection } from '@ark-ui/react/collection';
```

Обычно сценарий выглядит так:

```text
элементы приложения → коллекция Ark → компонент moduix → выбор пользователя
```

Коллекция приводит к единому виду идентификаторы, текст, отключённое состояние и порядок обхода
элементов. Компонент moduix отображает доступный интерфейс и отвечает за фокус и выбор.

## Выбор коллекции

Выбирайте API по тому, как хранятся и обновляются данные:

- Начните с `createListCollection` для фиксированного массива вариантов.
- Используйте `useListCollection`, когда список нужно фильтровать или изменять из состояния React.
- Используйте `createTreeCollection` для вложенных данных.
- Используйте `useAsyncList`, когда загрузкой, фильтрацией, сортировкой или разбиением на страницы
  управляет сервер.
- Используйте `useListSelection` для выбора в пользовательском списке. Компоненты коллекций moduix
  уже управляют собственным состоянием выбора.

Коллекции нормализуют идентификатор и текст элементов, но не рендерят интерфейс. Передайте полученную
коллекцию в соответствующий компонент moduix:

- [Select](/docs/select)
- [Combobox](/docs/combobox)
- [Listbox](/docs/listbox)
- [Tree View](/docs/tree-view)

## Ответственность

Ark UI отвечает за эти API и их выпуск. moduix использует полученные объекты коллекций, не оборачивая
и не реэкспортируя их. На следующих страницах описаны сценарии для пользователей moduix; вверху
каждой страницы есть ссылка на соответствующую справку Ark.
