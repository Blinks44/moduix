## Справочник API

В Ark UI нет отдельного примитива `container`. В moduix `Container` создан с помощью официальной
[фабрики Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory), поэтому для него действуют рекомендации Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[передаче ref](https://ark-ui.com/docs/guides/ref).

## Базовый пример


Импортируйте `Container` из подходящего пакета: `@moduix/react/container`, `@moduix/solid/container` или
`@moduix/vue/container` для CSS Modules, а для Tailwind CSS используйте `@moduix/react-tailwind/container`,
`@moduix/solid-tailwind/container` или `@moduix/vue-tailwind/container`.

Используйте `Container` для центрированной колонки с читабельной шириной. Компонент добавляет адаптивные
горизонтальные отступы, а вертикальные интервалы остаются задачей внешней разметки.

## Анатомия

`Container` выводит один корневой элемент и не добавляет дополнительных обёрток.

```text
Container
└─ дочерние элементы
```

| Часть       | Назначение                                               |
| ----------- | -------------------------------------------------------- |
| `Container` | Корневой элемент разметки. Центрирует содержимое и задаёт его ширину и горизонтальные отступы. |

## Композиция

`Container` не управляет состоянием и не содержит дочерних частей, которые нужно согласовывать. Используйте его как
корень и размещайте содержимое страницы или секции непосредственно внутри.

Используйте `asChild`, когда семантический элемент должен стать отрисованным корнем. Передавайте ровно один дочерний
элемент: React и Vue делают его корнем `Container`, а в Solid используется форма с render-функцией
`asChild={(props) => <main {...props()} />}`. В Solid ref нужно назначать элементу внутри render-функции, потому что
ref на самом `Container` через `asChild` не передаётся; в Vue отрендерированный элемент доступен через `$el` у ref
компонента. Размещайте `Bleed` внутри `Container`, если только один дочерний блок должен выйти за пределы ограниченной
текстовой колонки.

## Стилизация

Для пакетов CSS Modules переопределяйте CSS-переменные на корневом элементе, если оболочке страницы нужны другие
значения ширины или отступов. Пакеты Tailwind вместо этих переменных используют utility-классы и классы потребителя.
Для локальных стилей блока, например фона, границ или внутренних отступов, используйте `className` в React, `class` в
Solid и `class` в Vue.

### CSS-свойства

<CssPropertiesSection properties={ContainerDocs.containerOverrideCssProperties} />

Эти переменные относятся к пакетам CSS Modules. В пакетах Tailwind те же варианты `size` и `gutter` задаются через
utility-классы.

### Хуки стилизации

- `Container` добавляет `data-slot="container-root"` на корневой элемент.
- `data-scope="container"` и `data-part="root"` соответствуют соглашениям Ark по стилизации.
- `data-size` выбирает предустановку ширины: `xs`, `sm`, `md`, `lg`, `xl`, `full`.
- `data-gutter` выбирает предустановку отступов: `none`, `sm`, `md`, `lg`.
- Переменные `--moduix-container-*` управляют горизонтальными отступами и расчётом `max-width` в CSS Modules.
  Вертикальные интервалы и расположение дочерних элементов задаются внешними стилями.
