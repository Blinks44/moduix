## Справочник API

В Ark UI нет отдельного компонента-контейнера. В moduix `Container` создан с помощью официальной
[фабрики Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory), поэтому для него действуют рекомендации Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[передаче ref](https://ark-ui.com/docs/guides/ref).

## Анатомия

`Container` выводит один корневой элемент и не добавляет дополнительных обёрток.

```text
Container / Container.Root
└─ дочерние элементы
```

| Часть                          | Назначение                                               |
| ------------------------------ | -------------------------------------------------------- |
| `Container` / `Container.Root` | Корневой элемент макета. Центрирует содержимое и задаёт его ширину и горизонтальные отступы. |

## Композиция

### Рекомендуемая композиция

Используйте `Container` для структуры страницы, текста статьи, разделов документации, экранов настроек и других
макетов, где нужна центрированная колонка содержимого с предсказуемыми отступами по краям.

`Container.Root` - это тот же компонент, доступный через пространство имён. Такая форма удобна, если нужно сохранить
единый стиль именования с другими компонентами Ark.

С помощью `size` выберите ширину содержимого, а с помощью `gutter` задайте горизонтальные отступы. Свойство
`asChild` заменяет стандартный `div` одним дочерним элементом. Выберите семантический элемент, например `main`,
`section` или `article`, если обёртка должна описывать структуру документа. Переданный `ref` указывает на
отрисованный корневой элемент, а при использовании `asChild` - на этот дочерний элемент.

`Container` также поддерживает стандартные свойства `<div>`, включая `className` и `style`.

### Когда нужна собственная композиция

`Container` состоит из одного корневого элемента: у него нет дополнительных частей, слотов или вложенных средств
компоновки.

В большинстве случаев достаточно одного из вариантов:

- передать `className`, чтобы задать локальные стили макета или блока;
- переопределить переменные `--moduix-container-*`, если нужны другие значения ширины или отступов;
- использовать `asChild`, когда другой элемент должен стать корневым DOM-узлом;
- объединить с `Bleed`, если дочерний элемент должен выйти за пределы ограниченной текстовой колонки.

### Свойства по умолчанию

| Свойство  | По умолчанию | Значения / примечания                |
| --------- | ------- | ------------------------------------ |
| `size`    | `lg`    | `xs` (40rem), `sm` (48rem), `md` (64rem), `lg` (72rem), `xl` (90rem), `full` (без ограничения максимальной ширины) |
| `gutter`  | `md`    | `none`, `sm`, `md`, `lg`                                                               |
| `asChild` | `false` | Заменяет корневой `div` одним дочерним элементом                                      |

### Особенности поведения

- `Container` не отвечает за вертикальные интервалы. Задавайте их снаружи компонента или на дочерних элементах.
- `size="full"` снимает только ограничение максимальной ширины. Выбранные отступы по краям сохраняются, если не
  указать `gutter="none"`.
- В расчёт `max-width` входят оба горизонтальных отступа, поэтому ограниченная оболочка сохраняет выбранные отступы.
- При использовании `asChild` передавайте ровно один дочерний элемент. В этом случае `ref` указывает на него.
- `Container` не добавляет ARIA-роли, подписи, управление фокусом или поведение клавиатуры. Используйте `asChild` с
  `main`, `section` или `article`, если обёртка должна иметь семантическое значение.
- На корневом элементе доступны `data-scope="container"`, `data-part="root"`, `data-slot="container-root"`,
  `data-size` и `data-gutter`. Их можно использовать для стилизации и тестов.

## Стилизация

Переопределяйте CSS-переменные на корневом элементе, если оболочке страницы нужны другие значения ширины или отступов.
Для локальных стилей блока, например фона, границ или внутренних отступов, используйте `className`.

### Хуки стилизации

- `Container` и `Container.Root` добавляют `data-slot="container-root"` на корневой элемент.
- `data-scope="container"` и `data-part="root"` соответствуют соглашениям Ark по стилизации.
- `data-size` выбирает предустановку ширины: `xs`, `sm`, `md`, `lg`, `xl`, `full`.
- `data-gutter` выбирает предустановку отступов: `none`, `sm`, `md`, `lg`.
- Переменные `--moduix-container-*` управляют только горизонтальными отступами и расчётом максимальной ширины.
  Вертикальные интервалы и расположение дочерних элементов задаются внешними стилями.
