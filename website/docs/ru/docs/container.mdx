## Справочник API

В Ark UI нет отдельного примитива `container`. В moduix этот компонент построен на официальной
[фабрике Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и соответствует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
работе с [ref](https://ark-ui.com/docs/guides/ref).

## Базовый пример

Используйте `Container`, когда нужно ограничить ширину текста и сделать его удобным для чтения. Компонент
центрирует колонку содержимого, добавляет адаптивные внутренние отступы по горизонтали и не управляет

## Анатомия

`Container` состоит только из корневого компонента и использует композицию фабрики Ark.

```text
Container / Container.Root
└─ дочерние элементы
```

| Часть                          | Назначение                                               |
| ------------------------------ | -------------------------------------------------------- |
| `Container` / `Container.Root` | Корневая обёртка. Задаёт ширину содержимого и горизонтальные внутренние отступы. |

## Композиция

### Рекомендуемая композиция

Используйте `Container` для каркаса страницы, текста статьи, разделов документации, экранов настроек и других
макетов, где нужна центрированная колонка содержимого с предсказуемыми отступами по краям.

`Container.Root` - тот же компонент, доступный как алиас пространства имён в стиле Ark.

С помощью `size` выберите ширину содержимого, а с помощью `gutter` задайте внутренние отступы по краям. Используйте
`asChild`, если обёртка одновременно должна быть семантическим элементом `main`, `section` или `article`. В
`asChild` нужно передать ровно один семантический дочерний элемент. В этом случае ref будет указывать на него,
а не на `div` по умолчанию.

### Когда нужна собственная композиция

`Container` намеренно ограничен корневым компонентом: в нём нет дополнительных частей, свойств для слотов или
вложенных помощников для компоновки.

Для локальной настройки достаточно:

- передать `className`, чтобы задать локальные стили макета или блока;
- переопределить переменные `--moduix-container-*`, если нужны другие значения ширины или формула расчёта отступов;
- использовать `asChild`, когда DOM-узлом должен быть другой элемент;
- объединить с `Bleed`, если дочерний элемент должен выйти за пределы ограниченной текстовой колонки.

### Свойства по умолчанию

| Свойство  | По умолчанию | Значения / примечания                |
| --------- | ------- | ------------------------------------ |
| `size`    | `lg`    | `xs` (40rem), `sm` (48rem), `md` (64rem), `lg` (72rem), `xl` (90rem), `full` (без ограничения максимальной ширины) |
| `gutter`  | `md`    | `none`, `sm`, `md`, `lg`             |
| `asChild` | `false` | Композиция фабрики Ark               |

### Особенности поведения

- `Container` не отвечает за вертикальные интервалы. Задавайте их снаружи компонента или на дочерних элементах.
- `size="full"` снимает только ограничение максимальной ширины. Выбранные горизонтальные внутренние отступы
  сохраняются, если не указать `gutter="none"`.
- На корневом элементе доступны `data-scope="container"`, `data-part="root"`, `data-slot="container-root"`,
  `data-size` и `data-gutter`. Их можно использовать для стилизации и тестов.

## Стилизация

Используйте CSS-переменные на корневом элементе, если для оболочки страницы нужны другие значения отступов или ширины.
`className` подойдёт для локальных стилей блока, например для внутренних отступов, границ или фона.

### Хуки стилизации

- `Container` и `Container.Root` добавляют `data-slot="container-root"` на корневой элемент.
- `data-scope="container"` и `data-part="root"` служат точками привязки для стилизации и соответствуют модели Ark.
- `data-size` выбирает предустановку ширины: `xs`, `sm`, `md`, `lg`, `xl`, `full`.
- `data-gutter` выбирает предустановку отступов: `none`, `sm`, `md`, `lg`.
- Переменные `--moduix-container-*` управляют только горизонтальными отступами и расчётом максимальной ширины.
  Вертикальные интервалы и расположение дочерних элементов задаются внешними стилями компоновки.
