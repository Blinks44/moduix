## Базовый пример


Используйте `Swap`, когда элемент интерфейса должен переключаться между двумя визуальными состояниями,
например когда иконка меняется после действия. Передайте текущее логическое значение в `swap`: при
`false` отображается индикатор `off`, а при `true` индикатор `on`.

## Анатомия

```text
Swap
├─ SwapIndicator type="off"
└─ SwapIndicator type="on"

SwapRootProvider
└─ то же дерево индикаторов, подключённое к состоянию из useSwap()
```

| Часть                | Назначение                                                        |
| -------------------- | ----------------------------------------------------------------- |
| `Swap` | Передаёт состояние `swap` и размещает оба визуальных состояния.  |
| `SwapRootProvider`  | Подключает части к состоянию, созданному через `useSwap()`. |
| `SwapIndicator`     | Отрисовывает состояние `on` или `off`, выбранное свойством `type`. |

## Композиция

`Swap` отвечает только за визуальное представление. Состояние, взаимодействие, фокус и доступное имя
оставьте у окружающего семантического элемента. Для индикаторов, содержащих только иконки, добавьте
`aria-hidden="true"`. Размещайте оба индикатора непосредственными дочерними элементами, чтобы они
использовали одну ячейку сетки, а встроенные рецепты оставались в пределах этого экземпляра `Swap`.

По умолчанию `Swap` использует анимацию `scale`. Передайте в `animation` `fade`, `scale`, `rotate` или
`flip`, либо задайте пользовательское имя и опишите CSS через `data-animation` корня и атрибуты
`data-state` индикаторов от Ark. Если состояние нужно создать вне дерева, передайте результат
`useSwap()` в `SwapRootProvider` и не создавайте для этого состояния ещё один корень. При
использовании `asChild` передавайте ровно один семантический дочерний элемент.

### Предустановки анимации

Выберите встроенный рецепт и активируйте кнопку, чтобы увидеть переход. Текущее значение и кнопки
выбора рецепта отображаются под демонстрацией.

### Пользовательская анимация

Передайте пользовательское имя `animation` и обращайтесь в CSS к `data-animation` корня и атрибуту
`data-state` индикаторов от Ark. Рецепт `bounce` ниже написан на обычном CSS. Пользовательский рецепт
должен описывать анимации появления и выхода и предусматривать вариант для пользователей, включивших
уменьшение анимации.

<Example name="swap/custom-animation" />

### Root Provider

Создайте состояние отдельно с помощью `useSwap()`, затем передайте его в `SwapRootProvider`
через свойство `value`. В этом примере используется `asChild`, поэтому семантическая кнопка становится
отрисованным корнем `Swap`.

## Стилизация

В вариантах с CSS Modules длительность встроенных рецептов задаёт `--moduix-swap-transition`. Варианты
на Tailwind используют нативные utility-классы и классы, заданные потребителем. Для другого движения
передайте собственное имя анимации: оно отключает встроенные рецепты, а в своём CSS по-прежнему можно
использовать `--moduix-swap-transition`.

Ark закрепляет раскладку inline-стилями: корень получает `display: inline-grid`, а каждый индикатор -
`grid-area: 1 / 1` и `display: inline-flex`. Переопределения `display` и `grid-area` через классы не
работают ни в одном из вариантов, поэтому меняйте эти свойства через свойство `style` (например,
`style={{ display: 'grid' }}`).

В вариантах Tailwind рецепт flip применяет к корню `data-[animation=flip]:[perspective:24rem]`, который
имеет более высокую специфичность, чем обычный utility-класс `perspective` приложения, поэтому, чтобы
его переопределить, повторите тот же задокументированный вариант (например,
`data-[animation=flip]:[perspective:32rem]`).

### Хуки стилизации

- `Swap` использует `data-slot="swap-root"`.
- `SwapRootProvider` использует `data-slot="swap-root-provider"`.
- `SwapIndicator` использует `data-slot="swap-indicator"`.
- `animation` доступно как `data-animation` на `Swap` и `SwapRootProvider`.
- В CSS Modules встроенные рецепты нацелены только на непосредственных потомков `SwapIndicator` своего
  корня. Рецепты Tailwind читают ближайшего предка `group/swap`, поэтому не вкладывайте один `Swap` в
  другой.
- Ark добавляет `data-scope="swap"` и `data-part="root" | "indicator"`.
- Ark добавляет индикаторам `data-state="open" | "closed"`. moduix использует эти атрибуты во
  встроенных и пользовательских рецептах анимации.
