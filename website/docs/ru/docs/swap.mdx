## Анатомия

```text
Swap / Swap.Root
├─ Swap.Indicator type="off"
└─ Swap.Indicator type="on"
```

| Часть                | Назначение                                                             |
| -------------------- | ---------------------------------------------------------------------- |
| `Swap` / `Swap.Root` | Хранит состояние Ark `swap` и накладывает друг на друга оба визуальных состояния. |
| `Swap.RootProvider`  | Получает состояние, созданное с помощью `Swap.useSwap()` за пределами поддерева. |
| `Swap.Indicator`     | Отрисовывает состояние `on` или `off` с атрибутами Presence. |

Размещайте оба индикатора непосредственно в корне. Тогда они используют одну ячейку сетки, а встроенные
рецепты анимации остаются в пределах этого Swap.

## Композиция

### Рекомендуемая композиция

Поручите `Swap` только визуальную замену. Поместите его в семантическую кнопку, ссылку или элемент статуса:
родительский элемент управляет событиями, фокусом и доступным именем. Помечайте индикаторы, состоящие только
из иконки, как `aria-hidden="true"`, а доступное имя задавайте самому элементу управления.

### Когда нужна собственная композиция

Используйте `animation`, чтобы выбрать включённые варианты `fade`, `scale`, `rotate` или `flip`. Свойство также
принимает пользовательское имя: moduix записывает его в `data-animation` и оставляет индикаторы без анимации,
чтобы потребительский CSS мог использовать атрибуты `data-state` Ark без конфликта с анимацией по умолчанию.

### Свойства по умолчанию

| Свойство        | По умолчанию | Примечания                                                                 |
| --------------- | ------------ | -------------------------------------------------------------------------- |
| `swap`          | `false`      | Выбирает индикатор `off`.                                                  |
| `animation`     | `scale`      | Пресет moduix с затуханием и масштабированием.                              |
| `lazyMount`     | `false`      | Откладывает монтирование неактивного индикатора до его первого показа.     |
| `unmountOnExit` | `false`      | Удаляет неактивный индикатор после завершающей анимации.                   |

### Особенности поведения

- `swap` управляется извне; `Swap` сам не реагирует на наведение или клики.
- Во время перехода каждый индикатор получает `data-state="open" | "closed"` от Ark.
- `Swap.RootProvider` принимает состояние из `Swap.useSwap()`, а `useSwapContext()` читает это состояние у потомка, когда оно нужно пользовательской композиции.
- `asChild` доступен для каждой части. Передавайте ровно один семантический дочерний элемент, чтобы он получил свойства Ark, ref и хуки стилизации moduix.

```css
  animation: swap-bounce-enter var(--moduix-swap-transition, var(--moduix-transition-slow));

  animation: swap-bounce-exit var(--moduix-swap-transition, var(--moduix-transition-slow));
}
```

## Стилизация

### CSS-свойства

<CssPropertiesSection properties={SwapDocs.swapOverrideCssProperties} />

### Хуки стилизации

- `Swap.Root` -> `data-slot="swap-root"`
- `Swap.RootProvider` -> `data-slot="swap-root-provider"`
- `Swap.Indicator` -> `data-slot="swap-indicator"`
- `animation` предоставляется как `data-animation` на `Swap` и `Swap.RootProvider`.
- Включённые рецепты анимации нацелены только на непосредственных потомков `Swap.Indicator` этого корня.
- Ark добавляет `data-scope="swap"` и `data-part="root" | "indicator"`.
- Ark добавляет `data-state="open" | "closed"` индикаторам; moduix использует эти атрибуты для включённых анимаций.
