## Использование

<Usage />

Используйте короткую форму `Marquee` и явно соберите внутри неё `MarqueeViewport`, `MarqueeContent` и `MarqueeItem`. Если движущееся
содержимое передаёт пользователю информацию, задайте метку через `aria-label` или `translations.root`. Компонент
`Marquee` отвечает за поведение и необходимые стили анимации, но не оформляет отдельные элементы и не добавляет
рамку. В примере отдельно заданы стили элементов и ограничение ширины корневого элемента.

## Примеры

### Скорость

Задайте скорость через `speed`, указав число пикселей в секунду. При меньшей скорости содержимое легче читать.

<Example name="marquee/speed" />

### Обратное направление

Используйте `reverse`, когда содержимое должно двигаться в обратном направлении относительно `side`, не меняя
ориентацию.

<Example name="marquee/reverse" />

### Вертикальная ориентация

Задайте `side="top"` или `side="bottom"`, чтобы прокручивать содержимое вертикально. По умолчанию высота
вертикального корневого элемента — `15rem`, поэтому область просмотра получает стабильную высоту; чтобы изменить её,
задайте `height` классом.

<Example name="marquee/vertical" />

### Автозаполнение

Используйте `autoFill`, если содержимое короче области просмотра. Параметр `spacing` задаёт расстояние между
повторяющимися копиями содержимого.

<Example name="marquee/auto-fill" />

### Затухание по краям

Добавьте `MarqueeEdge` с нужных сторон, чтобы содержимое плавно исчезало на фоне страницы. Эта часть декоративна
и не перехватывает события указателя.

<Example name="marquee/edges" />

### Пауза при взаимодействии

Используйте `pauseOnInteraction`, чтобы приостанавливать прокрутку, когда пользователь наводит указатель на компонент
или переводит фокус на его содержимое.

Бегущая строка движется постоянно, поэтому экранные дикторы не могут надёжно прочитать содержимое в движении, а само
движение может отвлекать или вредить. Считайте содержимое некритичным: задайте описательную подпись, предоставьте
способ поставить прокрутку на паузу (`pauseOnInteraction` или явные элементы управления паузой) и никогда не
размещайте важную информацию только внутри бегущей строки.

<Example name="marquee/pause-on-interaction" />

### Ограниченное число циклов

Задайте `loopCount`, чтобы ограничить число повторов. `onLoopComplete` вызывается после каждого цикла, а
`onComplete` после последнего.

<Example name="marquee/finite-loops" />

### Справа налево

Оберните бегущую строку в `LocaleProvider` с RTL-локалью. Тогда логические стороны `start` и `end` будут следовать
направлению текста.

<Example name="marquee/rtl" />

### Root Provider

Используйте `useMarquee()` из moduix вместе с `MarqueeRootProvider`, когда внешним элементам управления нужно
приостанавливать, возобновлять или перезапускать прокрутку.

<Example name="marquee/programmatic-control" />

## Композиция

Используйте `Marquee` с явными частями `MarqueeViewport`, `MarqueeContent` и `MarqueeItem`. Добавляйте `MarqueeEdge` внутрь того же
корня, если содержимое должно плавно исчезать на фоне страницы; для каждой границы нужно указать `side`.

Используйте `defaultPaused` для начального состояния без внешнего управления. Если воспроизведением управляет другая
часть приложения, передавайте `paused` и `onPauseChange(details)`. Для внешних элементов управления создайте состояние
через `useMarquee()` и передайте его в `MarqueeRootProvider`; не используйте `Marquee` и `MarqueeRootProvider` для одного
состояния. Элементы управления внутри дерева могут получить текущий API через `MarqueeContext` или
`useMarqueeContext()`.

## Стилизация

В `Marquee` уже есть ключевые кадры, необходимые для анимации содержимого. Используйте атрибуты состояния Ark для
стилей, зависящих от поведения, и выберите модель кастомизации вашего registry-варианта:

- Варианты CSS Modules: используйте `--moduix-marquee-edge-color` и `--moduix-marquee-edge-size` для затухания по
  краям, а `className` (React) или `class` (Solid, Vue и Svelte) для размеров, цвета и оформления элементов.
- Варианты Tailwind: используйте `className` (React) или `class` (Solid, Vue и Svelte) с утилитами Tailwind для тех же задач.
  В Tailwind-пакетах Marquee не предоставляет CSS-переменные.

По умолчанию `Marquee` прозрачен, наследует цвет текста и не добавляет границу, фон, внутренние отступы или скругление. Если нужен
контейнер с фоном или границей, задайте его оформление в CSS приложения.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `Marquee` | `marquee-root` |
| `MarqueeRootProvider` | `marquee-root-provider` |
| `MarqueeViewport` | `marquee-viewport` |
| `MarqueeContent` | `marquee-content` |
| `MarqueeItem` | `marquee-item` |
| `MarqueeEdge` | `marquee-edge` |

- Атрибуты Ark: `data-scope="marquee"`, `data-part="root|viewport|content|item|edge"`, `data-state="paused|idle"`, `data-orientation`, `data-side`, `data-index`, `data-paused`, `data-reverse` и `data-clone`.
- CSS-переменные Ark: `--marquee-duration`, `--marquee-spacing`, `--marquee-delay`, `--marquee-loop-count` и `--marquee-translate`.

## Справочник API

| Проп | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `speed` | `number` | `50` | Скорость прокрутки в пикселях в секунду. |
| `side` | `'start' \| 'end' \| 'top' \| 'bottom'` | `'start'` | Куда движется содержимое: `start`, `end`, `top` или `bottom`. |
| `spacing` | `string` | `'1rem'` | Расстояние между повторами, CSS-длина. |
| `autoFill` | `boolean` | `false` | Повторяет содержимое, пока оно не заполнит контейнер. |
| `reverse` | `boolean` | `false` | Разворачивает направление анимации. |
| `pauseOnInteraction` | `boolean` | `false` | Ставит на паузу при наведении и фокусе. |
| `paused` | `boolean` | — | Состояние паузы в управляемом режиме. |
| `defaultPaused` | `boolean` | `false` | Начальное состояние паузы, если оно не управляется извне. |
| `delay` | `number` | `0` | Задержка перед стартом анимации, в секундах. |
| `loopCount` | `number` | `0` | Число повторов; `0` значит бесконечно. |
| `onPauseChange` | `(details: PauseStatusDetails) => void` | — | Вызывается при паузе и возобновлении. |
| `onComplete` | `() => void` | — | Вызывается после последнего повтора, если задан `loopCount`. |
| `translations` | `IntlTranslations` | — | Переведённые строки для подписей доступности. |
| `onLoopComplete` | `() => void` | — | Вызывается после каждого повтора. |
