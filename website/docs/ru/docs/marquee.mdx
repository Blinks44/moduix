## Анатомия

```text
Marquee / Marquee.Root
├─ Marquee.Edge (необязательно)
├─ Marquee.Viewport
│  └─ Marquee.Content
│     └─ Marquee.Item
└─ Marquee.Edge (необязательно)

Marquee.RootProvider
└─ то же дерево частей, подключённое к состоянию, созданному useMarquee() из moduix
```

| Часть                       | Назначение                                                                  |
| -------------------------- | --------------------------------------------------------------------------- |
| `Marquee` / `Marquee.Root` | Состояние компонента, метки, идентификаторы, ориентация, состояние паузы и CSS-переменные. |
| `Marquee.RootProvider`     | Выводит дерево компонента на основе состояния, возвращённого `useMarquee()`.              |
| `Marquee.Viewport`         | Область просмотра, которая скрывает содержимое за своими границами.                      |
| `Marquee.Content`          | Обёртка анимированного содержимого. При необходимости Ark клонирует её.                  |
| `Marquee.Item`             | Отдельный элемент внутри содержимого.                                                     |
| `Marquee.Edge`             | Необязательный градиент, создающий эффект затухания у края. Передайте `side`, чтобы выбрать край. |
| `Marquee.Context`          | Доступ к контексту родительского компонента `Marquee` для расширенных сценариев.          |

## Композиция

### Рекомендуемая композиция

Используйте короткую форму `Marquee` и оставляйте дерево частей Ark явным. Библиотека добавляет ключевые кадры
анимации и атрибуты состояния, а оформление элементов и самого корневого элемента задаётся в CSS приложения.

### Когда нужна собственная композиция

Используйте `Marquee.Edge`, если содержимое должно плавно исчезать на фоне страницы. Используйте `useMarquee()`
из moduix с `Marquee.RootProvider`, когда внешним элементам управления нужны методы `pause()`, `resume()`,
`togglePause()` и `restart()`. Не используйте `Marquee` и `Marquee.RootProvider` для одного и того же состояния.

Используйте `Marquee.Context` или `useMarqueeContext()`, если элемент управления внутри дерева должен получить
доступ к текущему API. Используйте `useMarquee()` с `Marquee.RootProvider`, если состояние создаётся отдельно
или должно быть доступно элементам управления за пределами дерева.

Используйте `asChild` у частей Ark, если нужно заменить элемент, который они рендерят. Заменяющий элемент должен
быть семантически подходящим и единственным дочерним элементом. Передавайте `ids`, если пользовательской
композиции нужны стабильные идентификаторы корня, области просмотра или содержимого.

### Свойства по умолчанию

В таблице перечислены значения по умолчанию для корневого элемента. Для `Marquee.Edge` нужно указать `side`,
а `Marquee.RootProvider` требует `value`, полученное из `useMarquee()`.

| Свойство             | По умолчанию | Примечания                                                            |
| -------------------- | ------------ | --------------------------------------------------------------------- |
| `side`               | `start`      | Значения `start`, `end`, `top` и `bottom`; последние два задают вертикальную ориентацию. |
| `speed`              | `50`         | Скорость в пикселях в секунду. Ark вычисляет длительность по размеру содержимого.          |
| `spacing`            | `1rem`       | Расстояние между копиями содержимого и отдельными элементами.                            |
| `delay`              | `0`          | Задержка перед запуском анимации, в секундах.                                             |
| `loopCount`          | `0`          | Число повторов. `0` означает бесконечное воспроизведение.                                 |
| `autoFill`           | `false`      | Повторяет содержимое, пока оно не заполнит область просмотра.                             |
| `pauseOnInteraction` | `false`      | Ставит компонент на паузу при наведении или фокусе. Рекомендуется для содержимого, которое нужно прочитать. |
| `reverse`            | `false`      | Меняет направление анимации, не изменяя `side`.                                           |
| `defaultPaused`      | `false`      | Начальное состояние паузы для неуправляемого компонента.                                  |
| `paused`             | -            | Управляемое состояние паузы. Используйте вместе с `onPauseChange`.                        |
| `onPauseChange`      | -            | Получает сведения Ark о состоянии паузы.                                                  |
| `onLoopComplete`     | -            | Вызывается после каждого повтора.                                                         |
| `onComplete`         | -            | Вызывается после последнего повтора, если `loopCount` больше `0`.                          |
| `translations`       | -            | Локализованная метка корневого элемента через `translations.root`. Используйте её или `aria-label`. |
| `ids`                | -            | Стабильные идентификаторы корня, области просмотра и экземпляров содержимого.              |
| `asChild`            | -            | Поддерживается каждой частью Ark и позволяет заменить рендеримый элемент.                  |
| `Marquee.Edge side`  | -            | Обязательная сторона: `start`, `end`, `top` или `bottom`.                                 |
| `RootProvider.value` | -            | Обязательное значение `UseMarqueeReturn`, полученное из `useMarquee()`.                    |

### Особенности поведения

Для управляемого воспроизведения передайте `paused` и `onPauseChange(details)`. Свойство `defaultPaused` задаёт
только начальное состояние неуправляемого компонента. Передавайте `loopCount`, `onLoopComplete` и `onComplete`,
если прокрутка должна остановиться после заданного числа циклов. Сигнатуры колбэков такие же, как в Ark.

Ark задаёт корневому элементу роль именованного региона и скрывает клонированное содержимое от скринридеров и других
вспомогательных технологий. Передавайте понятный `aria-label` или `translations.root`. Включайте
`pauseOnInteraction`, если содержимое интерактивно или его нужно успеть прочитать, и не используйте компонент
для критически важной информации.

Компонент не перемещает фокус между элементами и не поддерживает навигацию стрелками. Если включён
`pauseOnInteraction`, фокус приостанавливает прокрутку, а потеря фокуса возобновляет её.

Если в системе включено уменьшение анимации, moduix отключает анимацию содержимого, но не скрывает его.

`ref` каждой обёртки передаётся фактическому DOM-элементу Ark.

## Стилизация

В `Marquee` уже есть ключевые кадры, необходимые для анимации содержимого. Используйте `className` для настройки
размеров и оформления элементов, CSS-переменные для размеров, цвета, расстояния и затухания по краям, а атрибуты
состояния Ark для стилей, зависящих от поведения.

По умолчанию `Marquee` прозрачен и не добавляет границу, фон, внутренние отступы или скругление. Если нужен
контейнер с фоном или границей, задайте его оформление в CSS приложения.

### Хуки стилизации

- `data-slot="marquee-root"`, `marquee-root-provider`, `marquee-viewport`, `marquee-content`, `marquee-item` и `marquee-edge`.
- Атрибуты Ark: `data-scope="marquee"`, `data-part="root|viewport|content|item|edge"`, `data-state="paused|idle"`, `data-orientation`, `data-side`, `data-index`, `data-paused`, `data-reverse` и `data-clone`.
- CSS-переменные Ark: `--marquee-duration`, `--marquee-spacing`, `--marquee-delay`, `--marquee-loop-count` и `--marquee-translate`.
