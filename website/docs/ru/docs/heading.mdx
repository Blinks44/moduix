## Справочник API

В Ark UI нет отдельного примитива для заголовков. `Heading` в moduix построен на официальной
[фабрике Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[передаче ref](https://ark-ui.com/docs/guides/ref).

## Анатомия

`Heading` выводит один нативный элемент заголовка. Формы `<Heading>` и `<Heading.Root>` эквивалентны.

```text
Heading / Heading.Root
└─ текст или встроенное содержимое
```

| Часть                      | Назначение                                                  |
| -------------------------- | ----------------------------------------------------------- |
| `Heading` / `Heading.Root` | Нативный семантический заголовок со стилями типографики moduix. |

## Композиция

`Heading` состоит только из корневого элемента и не управляет состоянием, поэтому ему не нужны провайдер
или связанные части. Используйте `<Heading>` или эквивалентную форму `<Heading.Root>`, передавайте `as`
для семантического уровня от `h1` до `h6`, а `size` задавайте отдельно, если визуальный акцент должен
отличаться. Если `size` не задан, элемент выбирает визуальный размер от `2xl` для `h1` до `xs` для `h6`,
а значение `weight` по умолчанию равно `semibold`. Используйте `asChild` только в случае, когда другой
семантический элемент заголовка должен стать итоговым DOM-узлом.

## Стилизация

Стилизуйте `Heading` с помощью `className` в React или `class` в Solid, data-атрибутов корневого элемента
и публичных переменных `--moduix-heading-*`, перечисленных в справочнике CSS ниже. Пакеты CSS Modules
предоставляют эти переменные, а Tailwind-пакеты используют нативные utility-классы и переопределения
классов потребителя.

### CSS-свойства

### Хуки стилизации

- `data-scope="heading"` и `data-part="root"` обозначают корневой элемент в соглашении Ark.
- `data-slot="heading-root"` - стабильный селектор moduix.
- `data-size` появляется, если `size` задан явно.
- `data-weight` содержит выбранное значение: `regular`, `medium`, `semibold` или `bold`.
- `Heading` сам задаёт эти атрибуты. Одноимённые свойства `data-*` не могут заменить контракт стилизации компонента.
- Используйте `className` или `class` для utility-классов потребителя и локальных переопределений стилей.
