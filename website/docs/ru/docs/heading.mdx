## Справочник API

В Ark UI нет отдельного примитива для заголовков. moduix реализует этот компонент с помощью официальной
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
работе с [ref](https://ark-ui.com/docs/guides/ref).

## Анатомия

`Heading` состоит только из корневого элемента. `Heading.Root` - тот же компонент в форме пространства
имён, принятой в Ark.

```text
Heading / Heading.Root
└─ text or inline content
```

| Часть                      | Назначение                                                  |
| -------------------------- | ----------------------------------------------------------- |
| `Heading` / `Heading.Root` | Нативный семантический заголовок со стилями типографики moduix. |

## Композиция

### Рекомендуемая композиция

Используйте `<Heading>` для `h1`. Чтобы выбрать другой семантический уровень, передайте `as="h2"`,
`as="h3"`, `as="h4"`, `as="h5"` или `as="h6"`:

```tsx
<Heading as="h2" size="2xl">
  Page title rendered as h2
</Heading>
```

Используйте `asChild` только если хотите передать DOM-узел дочернему семантическому элементу заголовка
и при этом сохранить props компонента, `className`, `data-*`-атрибуты и переданный ref.

### Когда нужна собственная композиция

Переопределяйте внешний вид с помощью `className` и публичных переменных `--moduix-heading-*`.
Если содержимое является обычным текстом или общей типографикой, а не заголовком документа, используйте `Text`.

### Свойства по умолчанию

| Элемент     | По умолчанию          | Значения и примечания                       |
| ----------- | --------------------- | ------------------------------------------- |
| element     | `h1`                  | Используйте `as` для `h2`-`h6`              |
| `size`      | зависит от элемента   | `xs`, `sm`, `md`, `lg`, `xl`, `2xl`         |
| `weight`    | `semibold`            | `regular`, `medium`, `semibold`, `bold`     |
| `asChild`   | `false`               | Композиция через Ark factory                |
| `className` | -                     | Применяется к корневому элементу заголовка  |

### Особенности поведения

- Размер по умолчанию определяется элементом: `h1 -> 2xl`, `h2 -> xl`, `h3 -> lg`, `h4 -> md`,
  `h5 -> sm` и `h6 -> xs`.
- Явно заданный `size` переопределяет это соответствие, но не меняет семантический уровень.
- Корневой компонент передаёт ref отрендеренному элементу заголовка.
- Нативные элементы заголовков уже имеют нужную семантику, поэтому дополнительные ARIA-атрибуты не нужны.
  Не передавайте в `asChild` элемент, который не является заголовком.
- `Heading` не управляет состоянием и не содержит колбэков, клавиатурного поведения, провайдеров или контекстных хуков.

### Хуки стилизации

- `data-scope="heading"` обозначает область компонента в соглашении Ark.
- `data-part="root"` обозначает единственную корневую часть.
- `data-slot="heading-root"` - стабильный селектор moduix.
- `data-size` появляется, если `size` задан явно.
- `data-weight` содержит выбранное значение: `regular`, `medium`, `semibold` или `bold`.
- `Heading` задаёт эти атрибуты сам. Одноимённые `data-*` props не могут заменить контракт стилизации компонента.
- Используйте `className` и переменные `--moduix-heading-*` для локальных изменений внешнего вида.
