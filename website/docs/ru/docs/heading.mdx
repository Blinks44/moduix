## Справочник API

В Ark UI нет отдельного примитива для заголовков. `Heading` в moduix построен на официальной
[фабрике Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[передаче ref](https://ark-ui.com/docs/guides/ref).

## Базовый пример

отличаться от семантического уровня, задайте `size` отдельно.

## Анатомия

`Heading` выводит один нативный элемент заголовка. Формы `<Heading>` и `<Heading.Root>` эквивалентны.

```text
Heading / Heading.Root
└─ текст или встроенное содержимое
```

| Часть                      | Назначение                                                  |
| -------------------------- | ----------------------------------------------------------- |
| `Heading` / `Heading.Root` | Нативный семантический заголовок со стилями типографики moduix. |

## Композиция

### Рекомендуемая композиция

Используйте `<Heading>` в обычном случае для `h1`. Чтобы выбрать другой семантический уровень,
передайте в `as` значение от `h2` до `h6`:

```tsx
import { Heading } from '@moduix/react/heading';

<Heading as="h2" size="2xl">
  Page title rendered as h2
</Heading>
```

Используйте `asChild` для композиции через фабрику, когда единственный дочерний семантический элемент
заголовка должен стать DOM-узлом. Он получит свойства компонента, значение `className`, атрибуты
`data-*` и переданный `ref`.

### Когда нужна собственная композиция

Для локальных изменений внешнего вида используйте `className` и публичные переменные
`--moduix-heading-*`. Для обычного, вспомогательного или встроенного текста используйте `Text`,
а не заголовок документа.

### Свойства по умолчанию

| Свойство    | По умолчанию          | Значения и примечания                       |
| ----------- | --------------------- | ------------------------------------------- |
| `as`        | `h1`                  | `h1`-`h6`                                   |
| `size`      | зависит от элемента   | `xs`, `sm`, `md`, `lg`, `xl`, `2xl`         |
| `weight`    | `semibold`            | `regular`, `medium`, `semibold`, `bold`     |
| `asChild`   | `false`               | Композиция через фабрику Ark                |
| `className` | -                     | Применяется к корневому элементу заголовка  |

### Особенности поведения

- Если `size` не задан, визуальный размер определяется элементом: `h1 -> 2xl`, `h2 -> xl`,
  `h3 -> lg`, `h4 -> md`, `h5 -> sm` и `h6 -> xs`.
- Явно заданный `size` переопределяет это соответствие, но не меняет семантический уровень.
- Корневой элемент передаёт `ref` итоговому элементу заголовка.
- Нативные элементы заголовков уже обеспечивают нужную семантику, поэтому дополнительные ARIA-атрибуты
  не нужны. Не передавайте в `asChild` дочерний элемент, который не является заголовком.
- `Heading` не управляет состоянием и не предоставляет колбэки, клавиатурные взаимодействия, провайдеры
  или контекстные хуки.

### Хуки стилизации

- `data-scope="heading"` и `data-part="root"` обозначают корневой элемент в соглашении Ark.
- `data-slot="heading-root"` - стабильный селектор moduix.
- `data-size` появляется, если `size` задан явно.
- `data-weight` содержит выбранное значение: `regular`, `medium`, `semibold` или `bold`.
- `Heading` сам задаёт эти атрибуты. Одноимённые свойства `data-*` не могут заменить контракт стилизации компонента.
- Используйте `className` и переменные `--moduix-heading-*` для локальных изменений внешнего вида.
