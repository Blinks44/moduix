## Выбор подходящего компонента

Используйте `Highlight`, чтобы выделить один или несколько поисковых запросов, не нарушая поток текста.

- Выбирайте **`Highlight`**, когда нужно выделить совпадения в существующем предложении или подписи.
- Выбирайте **`Text`**, когда всей строке нужно только типографическое оформление, без поиска совпадений.

## Анатомия

`Highlight` имеет только корневую часть, но её контракт применяется к каждому совпавшему нативному сегменту `<mark>`.
Несовпавший текст остаётся обычными текстовыми узлами в окружающем потоке.

```text
Highlight / Highlight.Root
└─ repeated <mark> segments for matched ranges inside the provided text
```

| Часть                          | Назначение                                                                  |
| ------------------------------ | --------------------------------------------------------------------------- |
| `Highlight` / `Highlight.Root` | Применяет стили moduix для `mark` к каждому совпавшему диапазону в переданном тексте. |

## Композиция

### Рекомендуемая композиция

Используйте короткую корневую форму `<Highlight>` внутри `Text`, `Heading`, элемента списка или другого
контейнера текста. Она равнозначна `<Highlight.Root>`.

### Когда нужна собственная композиция

`Highlight` намеренно рендерит нативные элементы `<mark>` для совпавших диапазонов и не предоставляет
рендерер фрагментов. Когда нужен другой элемент или рендеринг для каждого совпадения, скомпонуйте эту разметку
напрямую, а не добавляйте второй API рендеринга в `Highlight`.

### Свойства по умолчанию

| Свойство     | По умолчанию | Примечания                                                   |
| ------------ | ------------ | ------------------------------------------------------------ |
| `query`      | -            | Строка или массив строк с терминами для выделения.           |
| `text`       | -            | Обязательная полная исходная строка.                         |
| `ignoreCase` | `false`      | Делает поиск регистронезависимым.                            |
| `matchAll`   | `false` для строки; `true` для массива строк | Выделяет все совпадения. Для массива строк требуется `true`. |
| `exactMatch` | `false`      | Ограничивает поиск точными совпадениями целых слов.          |

### Особенности поведения

`className`, `style`, `title`, `id` и другие свойства элемента `mark` применяются к каждому совпавшему `<mark>`.
Если запросу ничего не соответствует, компонент рендерит только обычный текст без элемента `mark`.

У `Highlight` нет цели для ref, конечного автомата, обратных вызовов, интеграции с `Field`/`Fieldset`,
`HiddenInput`, `ids`, контекстных хуков или `RootProvider`.

`exactMatch` использует сопоставление Ark по границам слов JavaScript. Оно надёжно для латинских слов, но не
распознаёт кириллицу и некоторые другие не-ASCII-письменности как целые слова. Если это различие важно, перед
рендерингом используйте поисковый сопоставитель, учитывающий локаль.

## Стилизация

Используйте `className` для разовой стилизации `mark`, а переменные `--moduix-highlight-*` — когда один
визуальный приём должен оставаться единообразным в нескольких местах.

### Хуки стилизации

- Каждый совпавший `<mark>` получает `data-scope="highlight"` и `data-part="root"`.
- `data-slot="highlight-root"` — стабильный селектор moduix для каждого совпавшего `mark`.
- Компонент не создаёт обёртку, не имеет атрибутов состояния и не задаёт CSS-переменных Ark: он рендерит
  только обычный текст и совпавшие сегменты `<mark>`.
