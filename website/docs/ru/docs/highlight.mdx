## Использование

<Usage />

Передайте полный исходный текст в `text`, а искомый термин в `query`. Разместите `Highlight` внутри
текстового компонента или HTML-элемента, который отвечает за внешнюю разметку и семантику.

## Выбор подходящего компонента

Используйте `Highlight`, чтобы выделить поисковые термины внутри текста, у которого уже есть
семантический контейнер. Компонент выводит совпавшие фрагменты, но не добавляет собственную обёртку.

- Выбирайте **`Highlight`**, когда нужно выделить один или несколько терминов в готовом предложении, подписи или текстовом блоке.
- Выбирайте **`Text`**, когда всей строке нужно только типографическое оформление, без поиска совпадений.

## Примеры

### Игнорирование регистра

Включите `ignoreCase`, если регистр букв в исходном тексте не должен влиять на результат поиска.

<Example name="highlight/ignore-case" />

### Все совпадения

Включите `matchAll`, если нужно выделить каждое вхождение, а не только первое.

<Example name="highlight/match-all" />

### Точное совпадение

Включите `exactMatch`, если частичные совпадения дают слишком много лишних результатов. В этом
примере `box` совпадёт с отдельным словом, но не с `checkbox` и `combobox`. Поиск использует
границы слов JavaScript: для латинского текста они работают надёжно, но не распознают кириллицу и
некоторые другие системы письма как целые слова.

<Example name="highlight/exact-match" />

### Несколько запросов

Передайте массив строк, если нужно выделить несколько терминов в одном тексте. Для массива
`matchAll` по умолчанию равен `true`; значение `matchAll={false}` приводит к ошибке.

<Example name="highlight/multiple-queries" />

### Динамический запрос

Управляйте `query` состоянием React, Solid или Vue, чтобы выделять текущий термин во время поиска или
фильтрации видимого текста.

<Example name="highlight/dynamic-query" />

## Композиция

`Highlight` не хранит состояние и не создаёт обёртку для внешней разметки. Размещайте его внутри
готового текстового контейнера, например `Text`, заголовка, элемента списка или ячейки таблицы.
Управляйте `query` из родительского компонента, если поисковый запрос меняется. Для массива строк
`matchAll` должен оставаться равным `true`; если каждому совпадению нужен другой элемент или
интерактивное поведение, создайте такую разметку самостоятельно.

## Анатомия

У `Highlight` одна публичная корневая часть. Компонент возвращает фрагмент и не добавляет отдельную
обёртку. Каждый совпавший фрагмент становится нативным элементом `<mark>`, а текст без совпадений
остаётся обычным текстом в окружающей разметке.

Наведите на часть или выберите её, чтобы найти её в превью.

## Стилизация

Совпавшие фрагменты получают стандартные стили moduix для `<mark>`. Для локальной правки в React
используйте `className`, а в Solid и Vue `class`. Варианты CSS Modules также предоставляют
переменные `--moduix-highlight-*`; для Tailwind используйте utility-классы или классы потребителя.

### CSS-переменные

Наведите на переменную или выберите её, чтобы увидеть её в превью.

<CssPropertiesSection properties={HighlightDocs.highlightCssProperties}>
  <AnatomyScene />
</CssPropertiesSection>

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `Highlight` | `highlight-root` |

- Каждый совпавший `<mark>` получает `data-scope="highlight"` и `data-part="root"`.
- `data-slot="highlight-root"` является стабильным селектором moduix для каждого совпавшего `mark`.
- Такие свойства, как `className`/`class`, `style`, `title` и `data-*`, применяются к каждому совпавшему `<mark>`.
- Компонент не создаёт обёртку, не добавляет атрибут состояния и не задаёт CSS-переменных Ark.

## Справочник API

| Проп | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `text` | `string` | — | Текст, в котором ищутся совпадения. |
| `query` | `string \| string[]` | — | Слово или массив слов для выделения. |
| `ignoreCase` | `boolean` | `false` | Ищет без учёта регистра. |
| `matchAll` | `boolean` | `false` | Выделяет все совпадения, а не только первое. |
| `exactMatch` | `boolean` | `false` | Ищет только целые слова. |
