## Базовый пример

`Toc` является сокращённой формой `Toc.Root`. Передайте в него массив `items` с заголовками,
которые нужно отслеживать. Для каждого элемента укажите `value`, совпадающее с `id` заголовка, и
`depth`, соответствующий его семантическому уровню, например `2` для `<h2>`. Используйте тот же
объект в `Toc.Item`, а для `Toc.Link` укажите фрагмент с тем же `value`.


На обычной странице документа `scrollEl` можно не указывать: компонент будет наблюдать за областью
просмотра страницы. В примере ниже используется вложенный контейнер с прокруткой. Он передаётся в
`scrollEl`, поэтому отслеживание и переходы по ссылкам остаются внутри предпросмотра.

## Анатомия

```text
Toc / Toc.Root
├─ Toc.Content
└─ Toc.Nav
   ├─ Toc.Title
   └─ Toc.List
      ├─ Toc.Indicator (необязательно)
      └─ Toc.Item[item]
         └─ Toc.Link
            └─ Toc.Rail (необязательно)

Toc.RootProvider
└─ то же дерево частей, подключённое к useToc()
```

| Часть              | Назначение                                                                 |
| ------------------ | -------------------------------------------------------------------------- |
| `Toc` / `Toc.Root` | Корневая часть, создающая состояние отслеживания по списку элементов.      |
| `Toc.Content`      | Статья с заголовками, чьи ID совпадают со значениями элементов.             |
| `Toc.Nav`          | Область навигации, связанная с заголовком оглавления.                       |
| `Toc.Title`        | Доступное имя и видимый заголовок навигации.                                |
| `Toc.List`         | Список ссылок на заголовки и необязательного индикатора.                    |
| `Toc.Item`         | Пункт списка, связанный с заголовком, его уровнем и активным состоянием.    |
| `Toc.Link`         | Якорная ссылка на соответствующий заголовок на этой же странице.            |
| `Toc.Indicator`    | Ненавязчивый маркер, который следует за активным диапазоном списка.         |
| `Toc.RootProvider` | Подключает части к состоянию отслеживания, созданному вне дерева.           |
| `Toc.Rail`         | Необязательная SVG-ветка между соседними уровнями заголовков.              |

## Композиция

Передайте отдельный элемент для каждого отслеживаемого заголовка. Значения `item.value`, `id`
заголовка и фрагмент `Toc.Link` должны совпадать, а `depth` должен соответствовать семантическому
уровню заголовка. Если прокруткой управляет страница, не указывайте `scrollEl`; для отдельной
области чтения передайте в него контейнер с прокруткой.

В отличие от Ark UI, `autoScroll` по умолчанию равен `false` и в `Toc`, и в `useToc()`. Передавайте
`autoScroll`, чтобы включить его, только если автоматическое раскрытие активного элемента навигации
не может прокрутить родительский контейнер.

Используйте `Toc.RootProvider` вместе с `useToc()` только тогда, когда элементам вне дерева нужно
то же состояние отслеживания, например `activeIds` или `scrollTo`. В React состояние читается как
объект, а в Solid доступно через возвращаемую функцию доступа. Используйте `Toc.Context`, если
внешней композиции, такой как `Collapsible`, нужны активные элементы. Для ссылок роутера передайте
в `Toc.Link asChild` один семантический дочерний элемент `<a>`; в Solid передайте его через
функцию рендера, которую ожидает `asChild`. Выберите либо `Toc.Indicator` для маркера активного
диапазона, либо `Toc.Rail` для иерархии отдельных ссылок: не добавляйте оба в один список.

## Стилизация

Стилизуйте компонент через `className` в React или `class` в Solid, атрибуты Ark, хуки moduix
`data-slot` и публичные переменные `--moduix-table-of-contents-*`. Пакеты CSS Modules используют
эти переменные, а Tailwind-пакеты используют нативные utility-классы и классы потребителя для
переопределений.

### CSS-свойства

<CssPropertiesSection properties={TocDocs.tableOfContentsOverrideCssProperties} />

### Хуки стилизации

- `data-slot="toc-root"`, `toc-root-provider`, `toc-content`, `toc-nav`, `toc-title`, `toc-list`,
  `toc-item`, `toc-link`, `toc-indicator` и `toc-rail`
- Атрибуты Ark `data-scope="toc"` и `data-part` на частях примитива
- Атрибуты и переменные `Toc.Item`: `data-value`, `data-depth`, `data-active`, `data-first`,
  `data-last` и `--depth`; `Toc.Link` получает `data-value`, `data-active` и `aria-current`
- Переменные времени выполнения Ark `--top`, `--left`, `--width` и `--height` на корневом элементе
