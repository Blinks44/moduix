## Базовый пример

`Toc` является сокращённой формой `Toc.Root`. Передайте в него массив `items` с заголовками,
которые нужно отслеживать. Для каждого элемента укажите `value`, совпадающее с `id` заголовка, и
`depth`, соответствующий его семантическому уровню, например `2` для `<h2>`. Используйте тот же
объект в `Toc.Item`, а для `Toc.Link` укажите `href` вида `#${item.value}`.

На обычной странице документа `scrollEl` можно не указывать: компонент будет наблюдать за областью
просмотра страницы. В примере ниже используется вложенный контейнер с прокруткой. Он передаётся в
`scrollEl`, поэтому отслеживание и переходы по ссылкам не выходят за пределы предпросмотра.

## Анатомия

```text
Toc.Root (также доступен как Toc)
├─ Toc.Content
└─ Toc.Nav
   ├─ Toc.Title
   └─ Toc.List
      ├─ Toc.Indicator (необязательно)
      └─ Toc.Item[item]
         └─ Toc.Link
            └─ Toc.Rail (необязательно)

Toc.RootProvider
└─ то же дерево частей, подключённое к useToc()
```

| Часть              | Назначение                                                                 |
| ------------------ | -------------------------------------------------------------------------- |
| `Toc`              | Сокращённая форма `Toc.Root`, создающая состояние отслеживания по списку. |
| `Toc.Content`      | Статья с заголовками, чьи ID совпадают со значениями элементов.            |
| `Toc.Nav`          | Область навигации, связанная с заголовком оглавления.                      |
| `Toc.Title`        | Доступное имя и видимый заголовок навигации.                               |
| `Toc.List`         | Список ссылок на заголовки и необязательного индикатора.                  |
| `Toc.Item`         | Пункт списка, связанный с одним заголовком, его уровнем и активным состоянием. |
| `Toc.Link`         | Якорная ссылка на соответствующий заголовок на этой же странице.            |
| `Toc.Indicator`    | Ненавязчивый маркер, который следует за активным диапазоном списка.        |
| `Toc.RootProvider` | Подключает части к состоянию отслеживания, созданному вне дерева.          |
| `Toc.Rail`         | Необязательная SVG-ветка между соседними уровнями заголовков.              |

## Композиция

### Рекомендуемая композиция

Создайте отдельный элемент в `items` для каждого заголовка, который нужно отслеживать. В `value`
укажите ID заголовка без символа `#`, а в `depth` его семантический уровень, например `2` для
`<h2>` или `3` для `<h3>`. По умолчанию корень наблюдает за областью просмотра страницы. Если
контент прокручивается в отдельном контейнере, передайте его через `scrollEl`.

Корень предоставляет параметры Ark `activeIds`, `defaultActiveIds`, `onActiveChange(details)`,
`rootMargin`, `threshold`, `autoScroll`, `scrollBehavior` и `ids`. При изменении активных заголовков
`onActiveChange` получает `details.activeIds` и `details.activeItems`.

### Когда нужна собственная композиция

Используйте `asChild` на `Toc.Link`, если ссылку должен отрисовать компонент роутера. Передайте единственный
семантический элемент `<a>`, чтобы Ark смог добавить ему `aria-current`, обработчик клика и
свойства фокуса.

Создавайте состояние через `useToc()` и подключайте его с `Toc.RootProvider`, когда внешним
элементам управления нужны `activeIds`, `setActiveIds`, `scrollTo` или `getItemState`. Внутри дерева
то же состояние доступно через `Toc.Context` и хук `useTocContext()`.

### Свойства по умолчанию

| Свойство         | По умолчанию          | Примечание                                                           |
| ---------------- | --------------------- | -------------------------------------------------------------------- |
| `items`          | обязательно           | Передайте значения и семантические уровни отслеживаемых заголовков.  |
| `rootMargin`     | `-20px 0px -40% 0px`  | Настраивает эффективную область наблюдения.                          |
| `threshold`      | `0`                   | Активирует заголовок при пересечении области наблюдения.             |
| `autoScroll`     | `false`               | Значение moduix. Включайте после проверки прокрутки родительских контейнеров. |
| `scrollBehavior` | `smooth`              | Используется ссылками на заголовки, `scrollTo` и прокруткой списка.  |

### Особенности поведения

- Активные ссылки получают `aria-current="location"` и `data-active`.
- `Toc.Item` получает атрибуты и переменные `data-value`, `data-depth`, `data-active`, `data-first`, `data-last` и
  числовую переменную `--depth`. `Toc.Link` получает `data-value`, `data-active` и
  `aria-current` в активном состоянии.
- Индикатор использует измеряемые переменные Ark `--top` и `--height`. Пока активный диапазон
  пуст, индикатор скрыт.
- По умолчанию контент и закреплённая панель навигации располагаются рядом. При ширине меньше
  48rem они выстраиваются в одну колонку.
- Укажите у `Toc.Nav` `placement="left"` или `placement="right"`, чтобы выбрать сторону боковой
  панели на широком экране.
- В moduix автоматическая прокрутка списка оглавления выключена. Изменение активного заголовка
  не прокручивает родительский контейнер. Включайте `autoScroll` только для изолированной панели и
  после проверки её поведения при прокрутке.
- При включённой системной настройке «Уменьшение движения» отключаются плавная прокрутка CSS и
  переходы индикатора. Передайте `scrollBehavior="auto"`, если прокрутка, которую запускает Ark,
  тоже не должна анимироваться.

### Рекомендации для рабочего приложения

- Используйте глобально уникальные и стабильные ID заголовков. Значения `item.value`, `id`
  заголовка и фрагмент ссылки после `#` должны совпадать.
- В области чтения со своей прокруткой пусть за неё отвечает один элемент: передайте его через
  `scrollEl` и добавьте `overscroll-behavior: contain`, если прокрутка не должна переходить на
  страницу.
- На страницах документации и во встроенных областях чтения оставляйте `autoScroll` выключенным.
  Включайте его только после проверки, что показ активной ссылки не прокручивает родительский
  контейнер.
- Сопоставляйте `depth` с семантическими уровнями заголовков. Обычный список добавляет отступы
  вложенным элементам, а `Toc.Rail` используйте, когда визуальный соединитель помогает понять
  иерархию.
- Используйте `Toc.RootProvider`, только если элементам вне оглавления нужно то же состояние. В
  остальных случаях достаточно `Toc`.

### Rail

Поместите `Toc.Rail` внутрь каждой ссылки, чтобы нарисовать SVG-соединитель между соседними
уровнями заголовков. Передавайте текущую, предыдущую и следующую глубину из одного упорядоченного
массива `items`. Для активной ссылки Rail использует цвет индикатора. Не добавляйте
`Toc.Indicator` в тот же список.

## Стилизация

Стилизуйте компонент через `className`, атрибуты Ark, хуки moduix `data-slot` и публичные
переменные `--moduix-table-of-contents-*`.

### Хуки стилизации

- `data-slot="toc-root"`, `toc-root-provider`, `toc-content`, `toc-nav`, `toc-title`, `toc-list`,
  `toc-item`, `toc-link`, `toc-indicator` и `toc-rail`
- Атрибуты Ark `data-scope="toc"` и `data-part` на частях примитива
- Состояние `Toc.Item`: `data-value`, `data-depth`, `data-active`, `data-first`, `data-last` и
  `--depth`; `Toc.Link` получает `data-value`, `data-active` и `aria-current`
- Переменные времени выполнения Ark `--top`, `--left`, `--width` и `--height` на корневом элементе
