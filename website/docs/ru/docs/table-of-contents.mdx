## Базовый пример

Передайте в `items` заголовки, за которыми нужно следить. Значение `item.value` должно совпадать с `id` заголовка; тот же элемент передаётся в `Item` и `Link`. В примере используется собственная прокручиваемая область чтения, поэтому `scrollEl` удерживает отслеживание и переходы по ссылкам внутри предпросмотра.

## Анатомия

```text
Toc
├─ Toc.Content
└─ Toc.Nav
   ├─ Toc.Title
   └─ Toc.List
      ├─ Toc.Indicator (необязательно)
      └─ Toc.Item[item]
         └─ Toc.Link
            └─ Toc.Rail (необязательно)

Toc.RootProvider
└─ то же дерево частей, подключённое к useToc()
```

| Часть                                    | Назначение                                                        |
| ---------------------------------------- | ----------------------------------------------------------------- |
| `Toc`                        | Создаёт состояние Ark для отслеживания заголовков.                 |
| `Toc.Content`                | Содержит заголовки, чьи ID совпадают со значениями элементов.      |
| `Toc.Nav`                    | Область навигации, связанная с заголовком оглавления.              |
| `Toc.Title`                  | Видимый заголовок и доступное имя навигации.                       |
| `Toc.List`                   | Список ссылок на заголовки и необязательный индикатор.             |
| `Toc.Item`                   | Элемент заголовка с глубиной и атрибутами активного состояния Ark. |
| `Toc.Link`                   | Ссылка внутри страницы, прокручивающая до нужного заголовка.       |
| `Toc.Indicator`              | Ненавязчивый маркер, который следует за активным элементом списка. |
| `Toc.RootProvider`           | Подключает части к состоянию, созданному вне дерева.               |
| `Toc.Rail`                   | Необязательная SVG-линия между соседними уровнями заголовков.      |

## Композиция

### Рекомендуемая композиция

Создайте отдельный элемент для каждого заголовка, который нужно отслеживать. `value` - ID заголовка без `#`, а `depth` - уровень этого заголовка. По умолчанию корень следит за областью просмотра страницы; если контент прокручивается в отдельном контейнере, передайте его через `scrollEl`.

Ark управляет `activeIds`, `defaultActiveIds`, `onActiveChange(details)`, `rootMargin`, `threshold`, `autoScroll`, `scrollBehavior` и `ids`. Форма обратного вызова не меняется: доступны `details.activeIds` и `details.activeItems`.

### Когда нужна собственная композиция

Используйте `asChild` на `Toc.Link`, если ссылка маршрутизатора должна вести к разделу на той же странице. Оставьте единственный семантический элемент `<a>`, чтобы Ark передал ему `aria-current`, обработчик клика и свойства фокуса.

Используйте `useToc()` с `RootProvider`, когда внешним элементам управления нужны `activeIds`, `setActiveIds`, `scrollTo` или `getItemState`. Внутри дерева то же состояние доступно через `Toc.Context` и `useTocContext`.

### Свойства по умолчанию

| Свойство         | По умолчанию            | Примечание                                                |
| ---------------- | ----------------------- | --------------------------------------------------------- |
| `items`          | обязательно             | Передайте значения и уровни отслеживаемых заголовков.     |
| `rootMargin`     | `-20px 0px -40% 0px`   | Изменяет эффективную область наблюдения.                  |
| `threshold`      | `0`                     | Активирует заголовок при первом пересечении.              |
| `autoScroll`     | `false`                 | Включайте только после проверки, что он не прокручивает родительский контейнер. |
| `scrollBehavior` | `smooth`                | Используется ссылками, API и прокруткой списка.           |

### Особенности поведения

- Активные ссылки получают `aria-current="location"` и `data-active`.
- Элементы получают `data-depth`, `data-first`, `data-last` и числовую переменную `--depth`.
- Индикатор использует измеряемые переменные Ark `--top` и `--height` и скрыт, пока активный диапазон пуст.
- По умолчанию статья стоит рядом с закреплённой панелью навигации; при ширине меньше 48rem они выстраиваются в одну колонку.
- Укажите у `Toc.Nav` `placement="left"` или `placement="right"`, чтобы выбрать сторону боковой панели на широком экране.
- Moduix по умолчанию не прокручивает список навигации автоматически: отслеживание не сдвигает страницу или внешний контейнер. Включайте `autoScroll` только для изолированной панели навигации.
- При настройке «Уменьшение движения» отключаются CSS-плавная прокрутка и переходы индикатора. Если прокрутка, которую запускает Ark, тоже не должна анимироваться, передайте `scrollBehavior="auto"`.

### Рекомендации для рабочего приложения

- Используйте глобально уникальные и стабильные ID заголовков. Значения `item.value`, `id` заголовка и hash ссылки должны совпадать.
- За прокрутку встроенной области чтения должен отвечать один элемент: передайте его через `scrollEl` и добавьте `overscroll-behavior: contain`, если прокрутка не должна переходить на страницу.
- Для обычной страницы и встроенной области чтения оставляйте `autoScroll` выключенным. Включайте его только после проверки, что показ активной ссылки не прокручивает родительский контейнер.
- Сопоставляйте `depth` с семантическими уровнями заголовков. Обычный список добавляет отступы, а `Rail` используйте, когда визуальная связь между уровнями действительно помогает.
- Используйте `RootProvider`, только если тем же состоянием должны пользоваться элементы вне оглавления. В остальных случаях достаточно `Toc`.

### Хуки стилизации

- `data-slot="toc-root"`, `toc-root-provider`, `toc-content`, `toc-nav`, `toc-title`, `toc-list`, `toc-item`, `toc-link`, `toc-indicator` и `toc-rail`
- `data-scope="toc"` и `data-part` Ark на частях примитива с состоянием
- `data-active`, `data-depth`, `data-first`, `data-last` и `--depth` на элементах и ссылках
- Переменные времени выполнения Ark `--top`, `--left`, `--width` и `--height` на корне
