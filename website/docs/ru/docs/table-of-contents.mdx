## Использование

<Usage />

`Toc` является корневым компонентом плоского API. Передайте в него массив `items` с заголовками,
которые нужно отслеживать. Для каждого элемента укажите `value`, совпадающее с `id` заголовка, и
`depth`, соответствующий его семантическому уровню, например `2` для `<h2>`. Используйте тот же
объект в `TocItem`, а для `TocLink` укажите фрагмент с тем же `value`.

На обычной странице документа `scrollEl` можно не указывать: компонент будет наблюдать за областью
просмотра страницы. В примере ниже используется вложенный контейнер с прокруткой. Он передаётся в
`scrollEl`, поэтому отслеживание и переходы по ссылкам остаются внутри предпросмотра.

## Примеры

### Rail

Поместите `TocRail` внутрь каждой ссылки, чтобы нарисовать SVG-соединитель между соседними
уровнями заголовков. Передавайте текущую, предыдущую и следующую глубину из одного упорядоченного
массива `items`. Для активной ссылки Rail использует цвет индикатора. Не добавляйте
`TocIndicator` в тот же список.

<Example name="table-of-contents/rail" />

### С раскрываемой навигацией

Поместите список навигации внутрь `Collapsible`, если читателю нужно скрывать полное оглавление.
`TocContext` передаёт активный элемент в текст кнопки и кольцо прогресса, а ссылки по-прежнему
ведут в ту же область чтения.

<Example name="table-of-contents/with-collapsible" />

### Root Provider

Используйте `useToc()`, если другому элементу интерфейса нужно читать активные заголовки или
прокручивать область чтения. Подробнее в разделе [Выносите состояние за пределы дерева](/docs/composition-patterns#root-provider).

## Композиция

Передайте отдельный элемент для каждого отслеживаемого заголовка. Значения `item.value`, `id`
заголовка и фрагмент `TocLink` должны совпадать, а `depth` должен соответствовать семантическому
уровню заголовка. Если прокруткой управляет страница, не указывайте `scrollEl`; для отдельной
области чтения передайте в него контейнер с прокруткой.

В отличие от Ark UI, `autoScroll` по умолчанию равен `false` и в `Toc`, и в `useToc()`. Передавайте
`autoScroll`, чтобы включить его, только если автоматическое раскрытие активного элемента навигации
не может прокрутить родительский контейнер.

Используйте `TocRootProvider` вместе с `useToc()` только тогда, когда элементам вне дерева нужно
то же состояние отслеживания, например `activeIds` или `scrollTo`. В React состояние читается как
объект, а в Solid доступно через возвращаемую функцию доступа; в Vue реактивное состояние доступно
напрямую в шаблоне, а в Svelte `useToc()` возвращает геттер, поэтому читайте состояние через `toc().activeIds` и передавайте хуку `id` (например, `$props.id()`). Используйте `TocContext`, если внешней композиции, такой как `Collapsible`, нужны активные элементы. Для ссылок роутера передайте
в `TocLink asChild` один семантический дочерний элемент `<a>`; в Solid передайте его через
функцию рендера, которую ожидает `asChild`. Выберите либо `TocIndicator` для маркера активного
диапазона, либо `TocRail` для иерархии отдельных ссылок: не добавляйте оба в один список.

:::warning Ограничения upstream
В Ark UI Vue 5.39.3 и Zag 1.45.0 событие `activeChange` возвращает запрошенные ID при изменении
управляемого `activeIds`. `TocNav` по-прежнему использует ID корня, поэтому при рендеринге обеих
частей ID дублируются. Это ограничение описано в [Ark #4187](https://github.com/chakra-ui/ark/issues/4187).
:::

## Стилизация

Передайте `className` в React или `class` в Solid, Vue и Svelte на любую экспортируемую часть. Варианты Tailwind
используют утилиты и классы приложения. Варианты CSS Modules построены на токенах foundation и не имеют
собственных переменных: класс на части или селектор по `data-slot` переопределяет стили компонента из слоя.
Чтобы изменить колонку навигации, переопределите `grid-template-columns` у `Toc`.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `Toc` | `toc-root` |
| `TocRootProvider` | `toc-root-provider` |
| `TocContent` | `toc-content` |
| `TocNav` | `toc-nav` |
| `TocTitle` | `toc-title` |
| `TocList` | `toc-list` |
| `TocItem` | `toc-item` |
| `TocLink` | `toc-link` |
| `TocIndicator` | `toc-indicator` |
| `TocRail` | `toc-rail` |

- Атрибуты Ark `data-scope="toc"` и `data-part` на частях примитива
- Атрибуты и переменные `TocItem`: `data-value`, `data-depth`, `data-active`, `data-first`,
  `data-last` и `--depth`; `TocLink` получает `data-value`, `data-active` и `aria-current`
- Переменные времени выполнения Ark `--top`, `--left`, `--width` и `--height` на корневом элементе

## Справочник API

| Проп | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `items` | `TocItem[]` | — | Отслеживаемые заголовки, у каждого `value` (id заголовка) и `depth`. |
| `scrollEl` | `() => HTMLElement \| null` | — | Возвращает контейнер прокрутки; по умолчанию страница. |
| `rootMargin` | `string` | `'-20px 0px -40% 0px'` | Отступ IntersectionObserver, определяющий, когда заголовок активен. |
| `threshold` | `number \| number[]` | `0` | Порог IntersectionObserver. |
| `autoScroll` | `boolean` | `false` | Прокручивает список, чтобы активный пункт оставался видимым. |
| `scrollBehavior` | `ScrollBehavior` | `'smooth'` | Поведение прокрутки для `autoScroll`. |
| `activeIds` | `string[]` | — | Id активных заголовков в управляемом режиме. |
| `defaultActiveIds` | `string[]` | — | Изначально активные заголовки. |
| `onActiveChange` | `(details: ActiveChangeDetails) => void` | — | Вызывается при смене видимых заголовков. |
