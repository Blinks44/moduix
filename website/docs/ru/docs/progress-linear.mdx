## Анатомия

```text
ProgressLinear.Root
├─ ProgressLinear.Label
├─ ProgressLinear.ValueText
└─ ProgressLinear.Track
   └─ ProgressLinear.Range

ProgressLinear.RootProvider
└─ то же дерево частей, подключённое к ProgressLinear.useProgress()
```

| Часть                                     | Назначение                                                                            |
| ----------------------------------------- | ------------------------------------------------------------------------------------- |
| `ProgressLinear` / `ProgressLinear.Root`  | Управляет состоянием прогресса, форматированием и идентификаторами.                   |
| `ProgressLinear.RootProvider`             | Подключает части к состоянию, созданному `ProgressLinear.useProgress()`.              |
| `ProgressLinear.Context`                  | Передаёт текущее состояние функции, переданной как дочерний элемент.                 |
| `ProgressLinear.Label`                    | Видимая подпись полосы прогресса.                                                      |
| `ProgressLinear.ValueText`                | Показывает форматированное значение и сообщает об изменениях. Через `Context` можно вывести собственный текст. |
| `ProgressLinear.Track`                    | Полоса прогресса с ролью `progressbar` и ARIA-атрибутами значения.                     |
| `ProgressLinear.Range`                    | Заполненная часть, отражающая текущий прогресс.                                       |
| `ProgressLinear.View`                     | Показывает содержимое в состояниях `indeterminate`, `loading` или `complete`.          |

## Композиция

### Рекомендуемая композиция

`ProgressLinear` - сокращённая форма `ProgressLinear.Root`. Дочерние части остаются явными,
чтобы структура отрисованного компонента соответствовала Ark UI.

Используйте `defaultValue` для неуправляемого прогресса. Для управляемого прогресса передайте
`value` и `onValueChange(details)`. Для неопределённого прогресса передайте `defaultValue={null}`
или `value={null}`.

### Когда нужна собственная композиция

Используйте `ProgressLinear.RootProvider` вместе с `ProgressLinear.useProgress()`, если состояние
нужно создать вне дерева компонентов, которое будет его отображать.

Используйте `translations.value(details)`, чтобы получить собственную строку значения из состояния
Ark. Чтобы показать эту строку, передайте `state.valueAsString` из `ProgressLinear.Context` в
`ValueText`. `translations.value(details)` меняет строку в состоянии, но сам по себе не меняет
текст стандартного `ValueText`. Добавьте `aria-label` или `aria-labelledby` на `Track`, чтобы дать
полосе доступное имя, однозначно описывающее задачу. Это заменяет устаревшую схему с
`getAriaValueText` и дочерней функцией рендера.

Используйте `ids`, если в нестандартной структуре нужны стабильные явные идентификаторы для подписи,
полосы или окружающей разметки. Используйте `ProgressLinear.View`, если вспомогательный текст или
интерфейс должны переключаться вместе с состоянием прогресса Ark, вместо того чтобы вручную
проверять состояние вне компонента. Используйте `ProgressLinear.Context` или
`ProgressLinear.useProgressContext()` для доступа к состоянию внутри корня или провайдера. Прямой
импорт Ark нужен только для интеграций, которые нельзя построить на API moduix.

### Свойства по умолчанию

| Свойство         | По умолчанию           | Примечания                                                   |
| ---------------- | ---------------------- | ------------------------------------------------------------ |
| `defaultValue`   | `50`                   | Начальное значение в неуправляемом режиме.                   |
| `min`            | `0`                    | Минимальное значение для процента и ARIA-атрибутов.          |
| `max`            | `100`                  | Максимальное значение для процента и ARIA-атрибутов.         |
| `formatOptions`  | `{ style: 'percent' }` | Определяет форматирование `ValueText`.                       |
| `locale`         | `'en-US'`              | Локаль, которую использует `Intl.NumberFormat`.              |
| `orientation`    | `'horizontal'`         | Ориентация Ark. Для `vertical` задайте высоту.               |

### Особенности поведения

`ProgressLinear.Track` получает от Ark роль `progressbar` и ARIA-атрибуты значения. Корневой
элемент хранит состояние прогресса и предоставляет `data-state="indeterminate|loading|complete"`.
Ark добавляет `data-orientation` к корню, подписи, полосе и заполненной части, поэтому для
горизонтальной и вертикальной ориентации используется одно дерево частей.

Все экспортируемые части поддерживают `asChild` благодаря полиморфной композиции Ark. Если вы
заменяете отрисованный элемент, сохраните семантику нового элемента и роль `progressbar` у
`Track`.

`ProgressLinear.ValueText` сообщает об изменениях через `aria-live="polite"`. `ProgressLinear.Label`
даёт видимую подпись, но для доступного имени полосы добавьте `aria-label` или `aria-labelledby`
на `ProgressLinear.Track`. В RTL заполненная часть движется от начала строки, а направление
анимации неопределённого прогресса меняется на обратное.

- `data-slot="progress-linear-root"`, `progress-linear-root-provider`, `progress-linear-label`, `progress-linear-value-text`, `progress-linear-track`, `progress-linear-range` и `progress-linear-view`.
