## Выбор подходящего компонента

Используйте `ProgressLinear`, когда пользователю нужно видеть ход выполнения на линейной полосе.
Для компактного индикатора в карточке, на панели инструментов или в другом ограниченном пространстве
подойдёт `ProgressCircular`.

## Анатомия

```text
ProgressLinear / ProgressLinear.Root
├─ ProgressLinear.Label
├─ ProgressLinear.ValueText
├─ ProgressLinear.Track
│  └─ ProgressLinear.Range
└─ ProgressLinear.View

ProgressLinear.RootProvider
└─ same part tree connected to ProgressLinear.useProgress()
```

| Часть                                     | Назначение                                                                    |
| ----------------------------------------- | ----------------------------------------------------------------------------- |
| `ProgressLinear` / `ProgressLinear.Root`  | Хранит состояние прогресса и передаёт Ark форматирование, идентификаторы и другие свойства. |
| `ProgressLinear.RootProvider`             | Подключает части к хранилищу, которое возвращает `ProgressLinear.useProgress()`. |
| `ProgressLinear.Context`                  | Передаёт текущее состояние прогресса функции, переданной как дочерний элемент. |
| `ProgressLinear.Label`                    | Видимая подпись задачи. Она автоматически не становится доступным именем `Track`. |
| `ProgressLinear.ValueText`                | Показывает отформатированный процент и сообщает об изменениях. Через `Context` можно вывести свой текст. |
| `ProgressLinear.Track`                   | Основа полосы прогресса. Ark добавляет ей роль и ARIA-атрибуты значения.       |
| `ProgressLinear.Range`                   | Заполненная часть, отражающая текущий прогресс.                               |
| `ProgressLinear.View`                    | Показывает содержимое, только когда его `state` совпадает с текущим состоянием прогресса. |

## Композиция

### Рекомендуемая композиция

Для обычного сценария используйте `ProgressLinear` или `ProgressLinear.Root` как корневой элемент.
`ProgressLinear` - это сокращённая запись `ProgressLinear.Root`. Видимые части остаются явными,
поэтому вы сами управляете структурой разметки.

Используйте `defaultValue` для неуправляемого прогресса. В управляемом режиме передайте `value` и
`onValueChange(details)`, если приложение хранит текущее значение. Установите
`defaultValue={null}` или `value={null}`, когда задача выполняется, но её прогресс неизвестен.

`ProgressLinear.RootProvider` заменяет корневой элемент, когда состояние создано через
`ProgressLinear.useProgress()`. Не используйте `Root` вместе с `RootProvider`.

### Когда нужна собственная композиция

Используйте `ProgressLinear.RootProvider` вместе с `ProgressLinear.useProgress()`, если состояние
должен создать или контролировать родительский компонент либо другая часть приложения.

Используйте `translations.value(details)`, если сгенерированное доступное имя должно подробнее
описывать задачу. Ark использует возвращённую строку как сгенерированный `aria-label` для `Track`.
Стандартный `ValueText` при этом по-прежнему показывает отформатированный процент. Если свой текст
должен быть виден в интерфейсе, выведите `state.valueAsString` через `ProgressLinear.Context`.
Явно заданные `aria-label` или `aria-labelledby` на `Track` имеют приоритет.

Используйте `ids`, если нестандартной композиции нужны стабильные явные идентификаторы для подписи,
полосы или окружающей разметки. Используйте `ProgressLinear.View`, если вспомогательный текст или
интерфейс должен переключаться вместе с состоянием прогресса Ark, а не через дублирование проверок.
Используйте `ProgressLinear.Context` или `ProgressLinear.useProgressContext()`, если пользовательскому
интерфейсу нужен доступ к состоянию внутри корня или провайдера. Прямые импорты Ark нужны только
для интеграций, которые нельзя построить на API moduix.

### Свойства по умолчанию

| Свойство         | По умолчанию           | Примечания                                             |
| ---------------- | ---------------------- | ------------------------------------------------------ |
| `defaultValue`   | `50`                   | Начальное значение неуправляемого прогресса.           |
| `min`            | `0`                    | Минимум для процента и ARIA-значений.                  |
| `max`            | `100`                  | Максимум для процента и ARIA-значений.                 |
| `formatOptions`  | `{ style: 'percent' }` | Параметры форматирования `ValueText`.                 |
| `locale`         | `'en-US'`              | Локаль, передаваемая в `Intl.NumberFormat`.            |
| `orientation`    | `'horizontal'`         | Для `vertical` задайте высоту.                         |

### Особенности поведения

`ProgressLinear.Track` получает от Ark `role="progressbar"`, `aria-valuemin`, `aria-valuemax` и
`aria-valuenow`. Корневой элемент предоставляет `data-state="indeterminate|loading|complete"` и
`data-orientation`. Для неопределённого прогресса атрибут `aria-valuenow` не добавляется.

`ProgressLinear.Label` даёт видимый контекст, но автоматически не задаёт доступное имя для `Track`.
По умолчанию полоса получает сгенерированное имя на основе значения из `translations.value(details)`.
Чтобы задать имя задачи явно, передайте на `Track` `aria-label` или `aria-labelledby`.
`ProgressLinear.ValueText` сообщает об изменениях через `aria-live="polite"`.

Все отрисовываемые части поддерживают `asChild` благодаря полиморфной композиции Ark. Сохраняйте
семантику заменяемых элементов и роль `progressbar` у `Track`. Прогресс носит информационный
характер, поэтому компонент не поддерживает клавиатурное взаимодействие и управление фокусом.

Ark добавляет `data-orientation` к корню, подписи, полосе и заполненной части. В RTL заполнение
начинается с начала строки, а направление анимации неопределённого прогресса меняется на обратное.

## Стилизация

Используйте `className` на экспортируемых частях для структурной стилизации. Для стилей, зависящих
от состояния, используйте атрибуты данных Ark и хуки `data-slot` moduix.

Корневая часть имеет ширину `12rem` по умолчанию. В вертикальном режиме высота также составляет
`12rem`. Используйте публичные переменные `--moduix-progress-linear-*`, чтобы подстроить компонент
под свой макет.
