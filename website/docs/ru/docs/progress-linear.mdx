## Выбор подходящего компонента

Используйте `ProgressLinear`, когда пользователю нужно видеть ход выполнения на линейной полосе.
Для компактного индикатора в карточке, на панели инструментов или в другом ограниченном пространстве
подойдёт `ProgressCircular`.

## Анатомия

```text
ProgressLinear / ProgressLinear.Root
├─ ProgressLinear.Label
├─ ProgressLinear.ValueText
├─ ProgressLinear.Track
│  └─ ProgressLinear.Range
└─ ProgressLinear.View

ProgressLinear.RootProvider
└─ та же структура частей, подключённая к ProgressLinear.useProgress()
```

| Часть                                      | Назначение                                                                    |
| ------------------------------------------ | ----------------------------------------------------------------------------- |
| `ProgressLinear` / `ProgressLinear.Root`   | Хранит состояние прогресса и передаёт Ark форматирование, идентификаторы и другие свойства. |
| `ProgressLinear.RootProvider`              | Подключает части к хранилищу, которое возвращает `ProgressLinear.useProgress()`. |
| `ProgressLinear.Context`                   | Передаёт текущее состояние прогресса функции, переданной как дочерний элемент. |
| `ProgressLinear.Label`                     | Видимая подпись задачи. Она автоматически не становится доступным именем `Track`. |
| `ProgressLinear.ValueText`                 | Показывает отформатированный процент и сообщает об изменениях. Через `Context` можно вывести свой текст. |
| `ProgressLinear.Track`                     | Основа полосы прогресса. Ark добавляет ей роль и ARIA-атрибуты значения.       |
| `ProgressLinear.Range`                     | Заполненная часть, отражающая текущий прогресс.                               |
| `ProgressLinear.View`                      | Показывает содержимое, только когда его `state` совпадает с текущим состоянием прогресса. |

## Композиция

Используйте `defaultValue` для неуправляемого прогресса. В управляемом режиме передайте `value` и
`onValueChange(details)`, если приложение хранит текущее значение. Используйте `defaultValue={null}`
или `value={null}`, когда прогресс неизвестен. Если состояние создано через
`ProgressLinear.useProgress()`, отрисовывайте части внутри `ProgressLinear.RootProvider`, а не внутри
`ProgressLinear` или `ProgressLinear.Root`. Используйте `ProgressLinear.View` для содержимого,
зависящего от состояния, а `ProgressLinear.Context` для собственного текста, которому нужно текущее
состояние.

## Стилизация

Используйте `className` в React или `class` в Solid на экспортируемых частях для структурной
стилизации. Для стилей, зависящих от состояния, используйте атрибуты данных Ark и хуки `data-slot`
moduix. Варианты Tailwind используют нативные утилиты и классы потребителя, а переменные ниже
настраивают варианты CSS Modules.

Корневая часть имеет ширину `12rem` по умолчанию. В вертикальном режиме высота также составляет
`12rem`. Используйте публичные переменные `--moduix-progress-linear-*`, чтобы подстроить компонент
под свой макет.

### Хуки стилизации

- `data-slot="progress-linear-root"`, `progress-linear-root-provider`, `progress-linear-label`,
  `progress-linear-value-text`, `progress-linear-track`, `progress-linear-range` и
  `progress-linear-view`.
- Атрибуты Ark: `data-scope="progress"`, `data-part`, `data-state="indeterminate|loading|complete"`,
  `data-orientation="horizontal|vertical"`, `data-value` и `data-max`.
