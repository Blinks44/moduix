## Выбор подходящего компонента

Используйте `ProgressLinear`, когда пользователю нужно видеть ход выполнения на линейной полосе.
Для компактного индикатора в карточке, на панели инструментов или в другом ограниченном пространстве
подойдёт `ProgressCircular`.

## Базовый пример


Соберите индикатор из явных частей `ProgressLinearLabel`, `ProgressLinearValueText`, `ProgressLinearTrack` и `ProgressLinearRange`. Задайте для `ProgressLinearTrack`
доступное имя, которое описывает задачу.
React, Solid и Vue используют одинаковые плоские имена частей; во Vue применяются нативные `class`, слоты и `v-model`, когда они нужны.

## Анатомия

```text
ProgressLinear
├─ ProgressLinearLabel
├─ ProgressLinearValueText
├─ ProgressLinearTrack
│  └─ ProgressLinearRange
└─ ProgressLinearView

ProgressLinearRootProvider
└─ та же структура частей, подключённая к useProgress()
```

| Часть                                      | Назначение                                                                    |
| ------------------------------------------ | ----------------------------------------------------------------------------- |
| `ProgressLinear`   | Хранит состояние прогресса и передаёт Ark форматирование, идентификаторы и другие свойства. |
| `ProgressLinearRootProvider`              | Подключает части к хранилищу, которое возвращает `useProgress()`. |
| `ProgressLinearContext`                   | Передаёт текущее состояние прогресса функции, переданной как дочерний элемент. |
| `ProgressLinearLabel`                     | Видимая подпись задачи. Она автоматически не становится доступным именем `ProgressLinearTrack`. |
| `ProgressLinearValueText`                 | Показывает отформатированный процент и сообщает об изменениях. Через `ProgressLinearContext` можно вывести свой текст. |
| `ProgressLinearTrack`                     | Основа полосы прогресса. Ark добавляет ей роль и ARIA-атрибуты значения.       |
| `ProgressLinearRange`                     | Заполненная часть, отражающая текущий прогресс.                               |
| `ProgressLinearView`                      | Показывает содержимое, только когда его `state` совпадает с текущим состоянием прогресса. |

## Композиция

Используйте `defaultValue` для неуправляемого прогресса. В управляемом режиме передайте `value` и
`onValueChange(details)`, если приложение хранит текущее значение. Используйте `defaultValue={null}`
или `value={null}`, когда прогресс неизвестен. Если состояние создано через
`useProgress()`, отрисовывайте части внутри `ProgressLinearRootProvider`, а не внутри
`ProgressLinear`. Используйте `ProgressLinearView` для содержимого,
зависящего от состояния, а `ProgressLinearContext` для собственного текста, которому нужно текущее
состояние.
Во Vue для того же управляемого значения используйте `v-model`.

## Примеры

### Управляемое состояние

Храните `value` в состоянии, если прогресс должен синхронно меняться вместе с другим элементом
управления или внешней задачей.

<Example name="progress-linear/controlled" width="sm" />

### Неопределённый прогресс

Установите `defaultValue={null}` или `value={null}`, когда задача выполняется, но пока нельзя
определить, сколько уже сделано.

<Example name="progress-linear/indeterminate" width="sm" />

### Начальное значение

Используйте `defaultValue`, чтобы задать начальное значение неуправляемого прогресса.

<Example name="progress-linear/initial-value" width="sm" />

### Минимум и максимум

Используйте `min` и `max`, если диапазон прогресса отличается от стандартного диапазона от `0` до
`100`.

<Example name="progress-linear/min-max" width="sm" />

### Представления состояния

Используйте `ProgressLinearView`, если вспомогательный текст или интерфейс должен меняться вместе
с состоянием прогресса Ark.

<Example name="progress-linear/state-views" width="sm" />

### Текст значения

Используйте `ProgressLinearContext` с `translations.value(details)`, если отображаемому значению
нужна формулировка, связанная с конкретной задачей.

<Example name="progress-linear/value-text" width="sm" />

### Вертикальная ориентация

Установите `orientation="vertical"`, когда заполненная часть должна расти снизу вверх. В
вертикальном режиме высота по умолчанию составляет `12rem`. Если макету нужна другая высота,
задайте `height` на корневой части.

<Example name="progress-linear/vertical" />

### Расширенная настройка

Создайте состояние прогресса с помощью `useProgress()` в родительском компоненте,
а затем подключите его к частям через `ProgressLinearRootProvider`.

<Example name="progress-linear/root-provider" width="sm" />

## Стилизация

Используйте `className` в React или `class` в Solid и Vue на экспортируемых частях для структурной
стилизации. Для стилей, зависящих от состояния, используйте атрибуты данных Ark и хуки `data-slot`
moduix. Варианты Tailwind используют нативные утилиты и классы потребителя, а переменные ниже
настраивают варианты CSS Modules.

Корневая часть по умолчанию занимает всю ширину контейнера. В вертикальном режиме она шириной по
содержимому и высотой `12rem`. Задайте `width` или `height` на корневой части, чтобы подстроить
компонент под макет.
`--moduix-progress-linear-track-size` задаёт толщину полосы в обеих ориентациях. Неопределённый
прогресс проводит диапазон шириной 35% от начального края к конечному (в RTL справа налево); при
предпочтении уменьшенного движения диапазон стоит у начального края.

### Хуки стилизации

- `data-slot="progress-linear-root"`, `progress-linear-root-provider`, `progress-linear-label`,
