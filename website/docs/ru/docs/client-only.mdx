## Когда использовать `ClientOnly`

Используйте `ClientOnly` для части интерфейса, которой нужен доступ к DOM или к API браузера, недоступным на сервере:
например, `window`, `navigator`, хранилище, измерения размеров или библиотека, работающая только в браузере. При
серверном рендеринге компонент показывает `fallback`, а после гидратации вместо него выводит дочернее содержимое.

`ClientOnly` предоставляет Ark UI. moduix не оборачивает и не реэкспортирует эту утилиту, поэтому импортируйте её
напрямую:

```tsx
import { ClientOnly } from '@ark-ui/react/client-only';
```

Если Ark UI ещё не указан в зависимостях приложения, установите его:

```bash
pnpm add @ark-ui/react
```

## Как выбрать `fallback`

`fallback` видит пользователь во время серверного рендеринга и до завершения гидратации. Добавьте `Skeleton`,
статичную версию содержимого или другой полезный заполнитель примерно того же размера, что и интерфейс после
гидратации. Учтите все важные строки и элементы управления, чтобы готовый интерфейс не менял размер скачком. При
создании `fallback` не обращайтесь к глобальным объектам браузера.

## Доступ к API браузера только на клиенте

`ClientOnly` управляет моментом отрисовки своего содержимого, но не превращает SSR-компонент или модуль в
клиентский. Обращайтесь к `window`, `document`, `navigator`, `localStorage` и выполняйте измерения DOM только во
вложенном компоненте внутри `ClientOnly`, либо в эффекте или обработчике события. Не переносите такой код в
родительский компонент, который создаёт границу `ClientOnly`: он по-прежнему отрисовывается на сервере.

## Использование с moduix

Внутри поддерева `ClientOnly` компоненты moduix работают как обычно. В примере `Card` показывает данные из
браузера, а `Skeleton` сохраняет ту же структуру в `fallback`. Если компонент moduix уже умеет безопасно работать
на сервере, используйте его документированный API вместо отдельной границы `ClientOnly`.

## Кто отвечает за `ClientOnly`

За `ClientOnly`, его поведение при гидратации и свойство `fallback` отвечает Ark UI. moduix показывает, как сочетать
утилиту со своими компонентами, но не стилизует и не экспортирует её из пакета.
