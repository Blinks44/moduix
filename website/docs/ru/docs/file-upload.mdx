## Справочник API

`FileUpload` можно импортировать из `@moduix/react/file-upload`. Компонент и хуки `useFileUpload` и
`useFileUploadContext` также доступны из `@moduix/react`.

## Базовый пример

Начните с `FileUpload` как корневого компонента. Добавьте `Label`, а затем используйте `Trigger` для компактного
элемента управления или `Dropzone` для загрузки перетаскиванием. Поместите `Items` в `ItemGroup`, чтобы показывать
выбранные файлы. Корневой компонент автоматически рендерит скрытое нативное поле выбора файлов. `Items` показывает
миниатюру только для файлов с MIME-типом `image/*`; для остальных используется универсальное превью.

## Анатомия

```text
FileUpload / FileUpload.Root
├─ FileUpload.Label
├─ FileUpload.Dropzone (необязательно)
│  ├─ FileUpload.DropzoneIcon
│  └─ FileUpload.Trigger
├─ FileUpload.Trigger (если Dropzone не используется)
├─ FileUpload.ItemGroup[type]
│  ├─ FileUpload.Items
│  └─ FileUpload.Context
│     └─ FileUpload.Item[file]
│        ├─ FileUpload.ItemPreview[type]
│        │  ├─ FileUpload.ItemPreviewImage
│        │  └─ FileUpload.ItemPreviewIcon
│        ├─ FileUpload.ItemName
│        ├─ FileUpload.ItemMetadata[file]
│        ├─ FileUpload.ItemSizeText
│        └─ FileUpload.ItemDeleteTrigger
├─ FileUpload.ClearTrigger
└─ скрытое нативное поле выбора файлов (добавляется автоматически)
```

| Часть                            | Назначение                                                               |
| -------------------------------- | ------------------------------------------------------------------------ |
| `FileUpload` / `FileUpload.Root` | Хранит состояние файлов и отвечает за проверку, перетаскивание, вставку из буфера обмена и интеграцию с формами. |
| `FileUpload.RootProvider`        | Подключает дерево компонента к состоянию, возвращённому хуком `useFileUpload`.                              |
| `FileUpload.Label`               | Доступная метка для скрытого поля выбора файлов и элементов управления загрузкой.                            |
| `FileUpload.Dropzone`            | Область для перетаскивания файлов. Если внутри есть `Trigger`, передайте `disableClick`, чтобы не открывать окно выбора дважды. |
| `FileUpload.DropzoneIcon`        | Декоративная иконка загрузки для `Dropzone`.                                                                |
| `FileUpload.Trigger`             | Кнопка, открывающая системное окно выбора файлов.                                                          |
| `FileUpload.ItemGroup`           | Список принятых или отклонённых файлов.                                                                    |
| `FileUpload.Items`               | Готовый вывод списка: карточки изображений и строки для остальных файлов с превью, метаданными и кнопками удаления. |
| `FileUpload.Context`             | Контекст с функцией-рендерером, совместимый с Ark, для собственных строк файлов.                            |
| `FileUpload.Item`                | Строка файла. Передайте текущий объект `file`.                                                              |
| `FileUpload.ItemPreview`         | Слот для превью, которое показывается в зависимости от MIME-типа файла.                                    |
| `FileUpload.ItemPreviewImage`    | Превью изображения внутри `ItemPreview`.                                                                   |
| `FileUpload.ItemPreviewIcon`     | Универсальная иконка файла для запасного варианта превью в `ItemPreview`.                                   |
| `FileUpload.ItemName`            | Имя файла.                                                                                                  |
| `FileUpload.ItemMetadata`        | Тип и локализованный размер файла. Передайте текущий объект `file`.                                         |
| `FileUpload.ItemSizeText`        | Локализованный размер файла.                                                                                |
| `FileUpload.ItemDeleteTrigger`   | Удаляет один файл. По умолчанию показывает иконку корзины moduix.                                          |
| `FileUpload.ClearTrigger`        | Очищает выбранные файлы. По умолчанию показывает иконку закрытия moduix.                                   |

## Композиция

### Рекомендуемая композиция

Сохраняйте явное дерево частей Ark в разметке. Для компактного элемента управления используйте `Trigger`, а для области
перетаскивания файлов - `Dropzone`. Если `Trigger` вложен в `Dropzone`, передайте `disableClick`, чтобы системное окно
выбора файлов открылось только один раз.

Корневой компонент всегда рендерит скрытое нативное поле выбора файлов. Используйте `Items` внутри `ItemGroup` для
компактного списка выбранных файлов. Если нужны собственные строки, берите принятые файлы из
`FileUpload.Context.acceptedFiles`, а отклонённые - из `FileUpload.Context.rejectedFiles`.

Используйте `FileUpload.Context`, `useFileUpload()` и `useFileUploadContext()`, когда нужен расширенный доступ к
состоянию. Контекст и хуки напрямую реэкспортируются из Ark, поэтому формат `details` в колбэках и контракт состояния
не меняются.

### Когда нужна собственная композиция

`Items` показывает изображения в виде компактных вертикальных карточек, а остальные файлы - в виде горизонтальных строк
с метаданными. Для собственных строк используйте явную композицию `Context`. `ItemPreview.type` задаёт регулярное
выражение для проверки MIME-типа, а не список правил с приоритетом. Поэтому для каждого файла выводите ровно одно
превью. Например, используйте `file.type.startsWith("image/")`, чтобы выбрать `ItemPreviewImage`. Для остальных файлов
отобразите `ItemPreviewIcon`, затем добавьте `ItemName`, `ItemMetadata file={file}` и `ItemDeleteTrigger`. Используйте
`asChild` только тогда, когда дочерний элемент один и сохраняет требуемую семантику кнопки, метки или поля ввода.

### Свойства по умолчанию

| Свойство              | По умолчанию | Примечания                                                        |
| --------------------- | ------------ | ----------------------------------------------------------------- |
| `allowDrop`           | `true`       | Разрешает перетаскивать файлы в `Dropzone`.                                      |
| `maxFiles`            | `1`          | Увеличьте значение или уберите ограничение, чтобы принимать несколько файлов или папки целиком. |
| `minFileSize`         | `0`          | Минимальный размер принимаемого файла в байтах.                                  |
| `maxFileSize`         | `∞`          | Максимальный размер принимаемого файла в байтах.                                |
| `preventDocumentDrop` | `true`       | Не даёт браузеру перейти на другую страницу, если файл сбросили за пределами области загрузки. |
| `locale`              | `en-US`      | Локаль для форматирования размеров файлов.                                     |

### Особенности поведения

`acceptedFiles`, `defaultAcceptedFiles` и `onFileChange(details)` поддерживают модель управляемого и неуправляемого
состояния Ark. `onFileChange` вызывается при изменении значения, независимо от того, были ли файлы приняты или
отклонены. Колбэки `onFileAccept(details)` и `onFileReject(details)` получают исходные объекты `details` от Ark,
включая ошибки для отклонённых файлов. `Field.Root` и `Fieldset.Root` могут передавать состояния `disabled`, `invalid`,
`required` и `readOnly`. Используйте `ids`, если отдельным меткам или описаниям нужны стабильные связи для доступности.

### Хуки стилизации

Используйте стабильные слоты moduix, например `[data-slot="file-upload-dropzone"]`,
`[data-slot="file-upload-item"]` и `[data-slot="file-upload-item-delete-trigger"]`.
Ark также предоставляет `data-scope="file-upload"`, `data-part` для конкретной части и атрибуты состояния:
`data-disabled`, `data-readonly`, `data-invalid`, `data-required`, `data-dragging` и `data-type`.
