## Базовый пример

Начните с корневого `FileUpload`. Добавьте `Label`, а затем выберите `Trigger` или `Dropzone`. Чтобы показать принятые
файлы, используйте `Items`. Корневой компонент автоматически добавляет нативное поле формы. `Items` использует
миниатюру только тогда, когда браузер сообщает MIME-тип `image/*`; для остальных файлов используется универсальное превью.

## Анатомия

```text
FileUpload / FileUpload.Root
├─ FileUpload.Label
├─ FileUpload.Dropzone
│  ├─ FileUpload.DropzoneIcon
│  └─ FileUpload.Trigger
├─ FileUpload.ItemGroup[type]
│  ├─ FileUpload.Items
│  └─ FileUpload.Context
│     └─ FileUpload.Item[file]
│        ├─ FileUpload.ItemPreview[type]
│        │  ├─ FileUpload.ItemPreviewImage
│        │  └─ FileUpload.ItemPreviewIcon
│        ├─ FileUpload.ItemName
│        ├─ FileUpload.ItemMetadata[file]
│        ├─ FileUpload.ItemSizeText
│        └─ FileUpload.ItemDeleteTrigger
├─ FileUpload.ClearTrigger
└─ native input (automatic)
```

| Часть                            | Назначение                                                               |
| -------------------------------- | ------------------------------------------------------------------------ |
| `FileUpload` / `FileUpload.Root` | Управляет состоянием файлов, проверкой, перетаскиванием, вставкой и работой с формами. |
| `FileUpload.RootProvider`        | Строит дерево загрузки на основе состояния, возвращённого хуком Ark `useFileUpload`.   |
| `FileUpload.Label`               | Доступная метка для скрытого input и элементов управления загрузкой.                   |
| `FileUpload.Dropzone`            | Область для перетаскивания файлов. Если внутри есть отдельный триггер, передайте `disableClick`. |
| `FileUpload.DropzoneIcon`        | Декоративная иконка загрузки для Dropzone.                                             |
| `FileUpload.Trigger`             | Кнопка, открывающая системное окно выбора файлов.                                     |
| `FileUpload.ItemGroup`           | Контейнер списка принятых или отклонённых файлов.                                     |
| `FileUpload.Items`               | Готовые карточки изображений и строки файлов с превью, метаданными и кнопками удаления. |
| `FileUpload.Context`             | Совместимый с Ark render prop-контекст для собственных строк файлов.                  |
| `FileUpload.Item`                | Строка файла. Передайте текущий объект `file`.                                       |
| `FileUpload.ItemPreview`         | Слот для превью, выбранного по MIME-типу.                                             |
| `FileUpload.ItemPreviewImage`    | Превью изображения внутри `ItemPreview`.                                              |
| `FileUpload.ItemPreviewIcon`     | Универсальная иконка файла для запасного варианта превью в `ItemPreview`.              |
| `FileUpload.ItemName`            | Имя файла.                                                                             |
| `FileUpload.ItemMetadata`        | Тип и локализованный размер файла. Передайте текущий объект `file`.                   |
| `FileUpload.ItemSizeText`        | Локализованный размер файла.                                                           |
| `FileUpload.ItemDeleteTrigger`   | Удаляет один файл. По умолчанию показывает иконку корзины moduix.                     |
| `FileUpload.ClearTrigger`        | Очищает выбранные файлы. По умолчанию показывает иконку закрытия moduix.              |

## Композиция

### Рекомендуемая композиция

Сохраняйте дерево частей Ark в разметке. Для компактного элемента управления используйте `Trigger`, а для области
перетаскивания файлов `Dropzone`. Если `Trigger` вложен в `Dropzone`, передайте `Dropzone` свойство `disableClick`,
чтобы системное окно выбора файлов открылось только один раз.

Корневой компонент всегда добавляет нативное поле формы. Используйте `Items` для компактного списка принятых файлов.
Если нужны собственные строки, получайте принятые файлы из `FileUpload.Context.acceptedFiles`, а отклонённые из
`FileUpload.Context.rejectedFiles`.

Импортируйте `FileUpload.Context`, `useFileUpload()` и `useFileUploadContext()` из `@moduix/react`, когда нужен
расширенный доступ к состоянию. Это прямые реэкспорты Ark, поэтому объекты `details` в колбэках и контракт состояния
не меняются.

### Когда нужна собственная композиция

`Items` показывает изображения в виде компактных вертикальных карточек, а остальные файлы в виде горизонтальных строк
с метаданными. Используйте явную композицию `Context`, если нужны собственные строки. `ItemPreview.type` задаёт условие
на основе регулярного выражения, а не список приоритетов, поэтому для каждого файла нужно показать ровно одно превью.
Например, используйте `file.type.startsWith("image/")`, чтобы выбрать `ItemPreviewImage`. Для остальных файлов покажите
`ItemPreviewIcon`, затем добавьте `ItemName`, `ItemMetadata file={file}` и `ItemDeleteTrigger`. Используйте `asChild`,
только когда дочерний элемент является единственным семантическим элементом и сохраняет нужное поведение кнопки, метки
или input.

### Свойства по умолчанию

| Свойство              | По умолчанию | Примечания                                                        |
| --------------------- | ------------ | ----------------------------------------------------------------- |
| `allowDrop`           | `true`       | Разрешает перетаскивать файлы в `Dropzone`.                                      |
| `maxFiles`            | `1`          | Увеличьте значение или снимите ограничение, чтобы принимать несколько файлов или каталогов. |
| `minFileSize`         | `0`          | Минимальный размер принимаемого файла в байтах.                                  |
| `maxFileSize`         | `∞`          | Максимальный размер принимаемого файла в байтах.                                |
| `preventDocumentDrop` | `true`       | Предотвращает случайную навигацию, если файл сбросили за пределами цели.         |
| `locale`              | `en-US`      | Локаль для форматирования размера файла.                                       |

### Особенности поведения

`acceptedFiles`, `defaultAcceptedFiles` и `onFileChange(details)` работают по модели управляемого и неуправляемого
состояния Ark. `onFileAccept(details)` и `onFileReject(details)` получают исходные объекты `details` от Ark. `Field.Root`
и `Fieldset.Root` могут передавать состояния disabled, invalid, required и read-only. Используйте `ids`, если отдельным
меткам или описаниям нужны стабильные связи для доступности.

### Хуки стилизации

Выбирайте стабильные слоты moduix, например `[data-slot="file-upload-dropzone"]`,
`[data-slot="file-upload-item"]` и `[data-slot="file-upload-item-delete-trigger"]`.
Ark также предоставляет `data-scope="file-upload"`, `data-part` для конкретной части и атрибуты состояния:
`data-disabled`, `data-readonly`, `data-invalid`, `data-required`, `data-dragging` и `data-type`.
