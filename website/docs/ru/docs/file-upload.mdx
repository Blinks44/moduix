Начните с `FileUpload` как корневого компонента. Добавьте `FileUploadLabel`, а затем оберните `Button` в `FileUploadTrigger asChild` для компактного
элемента управления или `FileUploadDropzone` для загрузки перетаскиванием. Явно добавьте `FileUploadHiddenInput`, чтобы
открывать нативное окно выбора. Поместите `FileUploadItems` в `FileUploadItemGroup`, чтобы показывать выбранные файлы. `FileUploadItems` показывает
миниатюру только для файлов с MIME-типом `image/*`; для остальных используется универсальное превью.

## Выбор подходящего компонента

Используйте `FileUpload`, когда приложению нужно хранить выбранные файлы в состоянии, показывать
зону перетаскивания или управлять процессом загрузки. `Input` с `type="file"` достаточно для
нативного выбора файлов в простой форме.

## Примеры

### Допустимые типы файлов

С помощью `accept` ограничьте типы файлов и в системном окне выбора, и при перетаскивании. Можно указать MIME-типы или
расширения файлов.

<Example name="file-upload/accepted-file-types" />

### Очистка списка файлов

Используйте `FileUploadClearTrigger`, чтобы одним действием удалить все принятые файлы.

<Example name="file-upload/clear-trigger" />

### Управляемое состояние

Управляйте `acceptedFiles`, когда выбранные файлы должны быть синхронизированы с состоянием приложения или
многошаговым сценарием. Обновляйте значение из `onFileChange(details)`.

<Example name="file-upload/controlled" />

### Загрузка папки

Используйте `directory`, чтобы пользователь мог выбрать папку. В поддерживающих эту возможность браузерах относительный
путь каждого файла доступен через `file.webkitRelativePath`. Укажите достаточно большое значение `maxFiles` или не
задавайте его, если количество файлов в папке заранее неизвестно.

<Example name="file-upload/directory-upload" />

### Dropzone

Используйте `FileUploadDropzone` для загрузки перетаскиванием. Оставьте вложенный `FileUploadTrigger`, чтобы пользователь мог открыть окно
выбора файлов с клавиатуры.

<Example name="file-upload/dropzone" />

### Обработка ошибок

Используйте `onFileReject(details)`, чтобы показать сообщение, зависящее от логики приложения. Встроенные ограничения
задавайте на корневом компоненте, например с помощью `accept`, `maxFiles` и `maxFileSize`. Для дополнительной проверки
используйте `validate(file, details)`.

<Example name="file-upload/error-handling" />

### Превью файлов

В этом примере уже есть SVG-изображение и PDF, поэтому сразу видны оба варианта: карточка изображения и строка файла.
Блок превью в строке файла по умолчанию занимает квадрат 2,5rem, а длинные имена помещаются в одну строку. Удалите
один из элементов или добавьте свои файлы, чтобы проверить эти варианты на реальных данных.

<Example name="file-upload/file-previews" />

### Использование в форме

Передайте `name` корневому компоненту и добавьте `FileUploadHiddenInput`; выбранные файлы будут
участвовать в обычной отправке и сбросе формы.

<Example name="file-upload/form-usage" />

### Начальные файлы

Используйте `defaultAcceptedFiles`, чтобы заранее добавить файлы, а затем передать управление выбором компоненту.

<Example name="file-upload/initial-files" />

### Съёмка с камеры

Используйте `capture` вместе с `accept` для изображения или видео, чтобы предложить мобильному браузеру открыть камеру.
Укажите `"user"` или `"environment"`, чтобы выбрать переднюю или заднюю камеру. Это только подсказка для браузера,
а не гарантия, что камера действительно откроется.

### Отклонённые файлы

Выводите `rejectedFiles` в отдельной группе `FileUploadItemGroup type="rejected"`, если пользователю нужно видеть причины

### Root Provider и вставка файлов

Используйте `useFileUpload` вместе с `FileUploadRootProvider`, если состояние или методы должны находиться за пределами
дерева загрузки. В этом примере `setClipboardFiles` передаёт файлы, вставленные в текстовое поле, в состояние загрузки.

### Преобразование файлов

Используйте `transformFiles(files)` для асинхронной обработки файлов до того, как они попадут в `acceptedFiles`.

### Интеграция с Field

Оберните загрузку в `Field`, если к полю формы нужно добавить поясняющий текст или сообщение об ошибке либо

## Композиция

`FileUpload` можно импортировать из `@moduix/react/file-upload` и `@moduix/vue/file-upload`. Компонент и хуки `useFileUpload` и
`useFileUploadContext` также доступны из `@moduix/react`.

Тот же компонент доступен из `@moduix/solid/file-upload`, `@moduix/react-tailwind/file-upload`,
`@moduix/solid-tailwind/file-upload` и `@moduix/vue-tailwind/file-upload`. Все шесть вариантов используют одинаковые части компонента и модель
состояния. Выберите пакет, который соответствует вашему фреймворку и варианту стилизации.

`FileUpload` по умолчанию хранит состояние выбранных файлов внутри себя. Используйте `defaultAcceptedFiles` для начального
значения в неуправляемом режиме, а `acceptedFiles` вместе с `onFileChange(details)`, если состояние принадлежит приложению.
Если состояние или методы нужно создать за пределами дерева загрузки, используйте `useFileUpload()` и `FileUploadRootProvider`.

Явно добавляйте `FileUploadHiddenInput` в `FileUpload` или `FileUploadRootProvider` даже вне формы: через него `FileUploadTrigger` открывает
нативное окно выбора файлов. Чтобы включить файлы в нативную отправку формы, задайте `name` корневому компоненту. Если
`FileUploadTrigger` находится внутри `FileUploadDropzone`, передайте `disableClick`, чтобы окно выбора открывалось только один раз.

Для стандартных строк используйте `FileUploadItems` внутри `FileUploadItemGroup`. Для собственной разметки выводите
`FileUploadContext` и выбирайте одно превью для каждого файла из `acceptedFiles` или `rejectedFiles`.

## Стилизация

Используйте `className` в React или `class` в Solid и Vue на экспортируемых частях для структурных стилей. Варианты Tailwind
используют нативные utility-классы и классы потребителя. CSS Modules построены на токенах foundation и не имеют
переменных компонента: класс на части перекрывает стили из слоя компонентов. Оба варианта стилизации используют общие
атрибуты состояния Ark и хуки moduix `data-slot`.

Корень занимает всю ширину контейнера; чтобы ограничить её, задайте `max-width` классом. Элемент файла это grid с
именованными областями `preview`, `name`, `meta` и `delete`, поэтому дочерний элемент без области встаёт под имя файла.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `Enter` / `Space` | Открывает выбор файлов с кнопки или зоны перетаскивания. |
| `Tab` | Перемещает между зоной, кнопкой и действиями с файлами. |
