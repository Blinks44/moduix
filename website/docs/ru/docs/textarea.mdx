## Справочник API

В Ark UI нет отдельного примитива `Textarea`. В moduix этот компонент построен на
[`Field.Textarea` из Ark UI](https://ark-ui.com/docs/components/field): он сохраняет нативный API
`textarea`, поддерживает `autoresize` и `asChild`, передаёт ref на нативный элемент и наследует
состояние `Field`.

## Выбор подходящего компонента

Используйте `Textarea` для обычного текста, который может занимать несколько строк и должен вести
себя как нативное поле `textarea` в браузере.

- Выбирайте **`Input`** для коротких однострочных значений, например имён, URL и компактных фильтров.
- Выбирайте **`Textarea`** для заметок, комментариев, описаний и другого длинного текста со свободным вводом.
- Выбирайте **`Editable`**, если текст сначала отображается, а редактирование включается отдельно.
- Выбирайте **`Field` + `Textarea`**, если вы хотите декларативно задать метку, пояснение,
  обязательность или валидацию.

## Базовое использование

Поместите `Textarea` внутрь `Field`, если полю нужны доступная метка или поясняющий текст. Это
рекомендуемый вариант для комментариев, заметок, описаний задач и похожих полей.

## Анатомия

В публичной структуре есть только одна часть:

```text
Field (optional wrapper)
└─ Textarea
```

| Часть      | Назначение                                               |
| ---------- | -------------------------------------------------------- |
| `Textarea` | Нативный `textarea` со стилями moduix и состоянием `Field`. |

`Textarea` не экспортирует дополнительные оболочки, составные подкомпоненты, провайдеры и
контекстные хуки, скрытые поля, подпись или счётчик символов.

## Композиция

### Рекомендуемая композиция

Для обычного многострочного ввода используйте `Textarea` как основной элемент.

Передавайте ему нативные свойства, например `rows`, `name`, `placeholder`, `maxLength`, `readOnly`,
`disabled`, `required`, `value`, `defaultValue` и `form`.

Добавьте `Field`, `Field.Label`, `Field.HelperText` и `Field.ErrorText`, если вы хотите декларативно
связать с полем метку, пояснение или сообщение об ошибке. Если `Textarea` используется без `Field`, задайте ему
доступное имя через нативный `<label>` или `aria-label`.

### Когда нужна собственная композиция

Используйте `Field.Textarea` только если нужна низкоуровневая композиция через пространство имён
`Field`. В обычных формах лучше выбирать `Textarea`, чтобы все многострочные поля следовали единому
контракту стилей moduix.

Если текст сначала отображается, а затем редактируется, используйте `Editable`.

### Свойства по умолчанию

| Свойство     | По умолчанию | Примечание                                           |
| ------------ | ------- | ------------------------------------------------ |
|`autoresize`|`false`|Автоматическое изменение высоты Ark включается явно.|

### Особенности поведения

- Чтобы управлять значением из состояния React, передавайте `value` и нативный `onChange`.
- Задайте `name`, чтобы включить textarea в нативную отправку формы, и читайте его значение через `FormData`.
- При нативном сбросе формы неуправляемое поле возвращается к `defaultValue`. Атрибут `form` позволяет
  связать textarea с формой, расположенной вне его DOM-ветки.
- Переданный ref указывает на настоящий `HTMLTextAreaElement`. При использовании `asChild` передавайте
  один семантический элемент textarea, который принимает объединённые свойства и ref.
- Включайте `autoresize`, если поле должно расти вместе с содержимым. Пока этот режим включён, Ark
  отключает ручное изменение размера, поэтому `--moduix-textarea-resize` действует только при
  `autoresize={false}`.
- Для сценария, где текст просматривают, а затем редактируют, используйте `Editable`.

## Стилизация

`--moduix-textarea-*`, перечисленные в CSS API.

### Хуки стилизации

Оформляйте внешний вид через `Textarea`, а расположение поля и дополнительного текста - через окружающий `Field`.

- `Textarea` отвечает за границу, фон, placeholder, изменение размера и индикатор фокуса.
- `Field` задаёт ширину, интервалы и расположение метки, описания и сообщения об ошибке.
- `data-slot="textarea-root"` служит стабильным селектором для локальных стилей.
- `data-autoresize` присутствует, когда включён `autoresize`.
- Для стилизации состояний используйте `data-invalid`, `[aria-invalid='true']`, `[disabled]`,
  `data-disabled`, `:read-only` и `data-readonly`.
