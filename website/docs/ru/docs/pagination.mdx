## Анатомия

```text
Pagination
├─ Pagination.FirstTrigger (необязательно)
├─ Pagination.PrevTrigger
├─ Pagination.Items (рекомендуется)
├─ Pagination.Context (расширенный доступ к состоянию через render prop)
│  ├─ Pagination.Item
│  └─ Pagination.Ellipsis
├─ Pagination.NextTrigger
└─ Pagination.LastTrigger (необязательно)

Pagination.RootProvider
└─ та же структура из триггеров, элементов, многоточий и контекста, подключённая к usePagination()
```

| Часть                             | Назначение                                                            |
| --------------------------------- | --------------------------------------------------------------------- |
| `Pagination`                      | Корневой компонент навигации, который управляет текущей страницей и числом элементов на странице. |
| `Pagination.RootProvider`         | Подключает части к состоянию, созданному через `Pagination.usePagination()`.                     |
| `Pagination.Items`                | Выводит рассчитанные элементы страниц и многоточия.                                              |
| `Pagination.Context`              | Открывает доступ к состоянию корня и методам навигации через render prop Ark UI.                  |
| `Pagination.usePagination`        | Создаёт состояние пагинации за пределами дерева, где отображается компонент.                      |
| `Pagination.usePaginationContext` | Даёт потомку доступ к состоянию пагинации.                                                        |
| `Pagination.Item`                 | Интерактивный элемент страницы. Принимает объект страницы в качестве свойств.                    |
| `Pagination.Ellipsis`             | Неинтерактивный маркер скрытой части диапазона страниц. Требует `index`.                          |
| `Pagination.PrevTrigger`          | Переходит на предыдущую страницу и отключается, когда выбрана первая страница.                    |
| `Pagination.NextTrigger`          | Переходит на следующую страницу и отключается, когда выбрана последняя страница.                  |
| `Pagination.FirstTrigger`         | Переходит на первую страницу и отключается, если она уже выбрана.                                 |
| `Pagination.LastTrigger`          | Переходит на последнюю страницу и отключается, если она уже выбрана.                              |

## Композиция

### Рекомендуемая композиция

`Pagination` и `Pagination.Root` управляют навигацией с клавиатуры, текущей страницей, числом
элементов на странице, состоянием кнопок навигации, расчётом диапазона страниц и подписями для средств
доступности. Укажите в `count` общее число элементов данных, а не число страниц. Вместе с `pageSize`
или `defaultPageSize` это позволит Ark вычислить `totalPages`.

Для стандартного списка страниц используйте `Pagination.Items`. Компонент выводит текущий массив
`pages`, рассчитанный Ark, через `Pagination.Item` и `Pagination.Ellipsis`, сохраняя выбранное
состояние, подписи и обработчики событий.

### Когда нужна собственная композиция

Используйте `Pagination.Context`, если нужно изменить отображение элементов страниц или элементов
управления рядом с ними. Если состояние нужно создать за пределами дерева пагинации, создайте его
с помощью `Pagination.usePagination()` и передайте в `Pagination.RootProvider`. Потомок может получить
то же состояние через `Pagination.usePaginationContext()`. Если вместо кнопок нужны ссылки, задайте
`type="link"` и передайте `getPageUrl(details)`.

### Свойства по умолчанию

| Свойство          | По умолчанию | Примечание                                                        |
| ----------------- | ------------ | ----------------------------------------------------------------- |
| `aria-label`      | `Pagination` | Подпись области навигации по умолчанию в moduix.                     |
| `defaultPage`     | `1`          | Начальная активная страница в неуправляемом режиме.                 |
| `defaultPageSize` | `10`         | Начальное число элементов на странице в неуправляемом режиме.       |
| `siblingCount`    | `1`          | Число страниц рядом с активной страницей.                            |
| `boundaryCount`   | `1`          | Число страниц в начале и конце диапазона.                            |
| `type`            | `button`     | Тип элемента навигации. Для ссылок задайте `link` и передайте `getPageUrl(details)`. |

### Особенности поведения

Когда компонент должен сам управлять состоянием, используйте `defaultPage` и `defaultPageSize`.
Чтобы управлять состоянием из приложения, передайте `page`, `pageSize`, `onPageChange(details)` и
`onPageSizeChange(details)`. Колбэки получают объекты `details` от Ark, поэтому читайте `details.page`
и `details.pageSize` напрямую. Компонент сохраняет навигацию с клавиатуры, семантику выбранного элемента,
недоступность кнопок навигации, `ids`, `asChild`, локализацию и генерацию URL для ссылок.

## Стилизация

moduix сохраняет атрибуты состояния Ark и добавляет стабильные хуки `data-slot` для локальной стилизации.
В номерах страниц используются табличные цифры и компактные горизонтальные отступы. Поэтому одно- и
двузначные номера сохраняют квадратную форму, а более длинные значения расширяются без обрезки.

### Хуки стилизации

- `data-scope="pagination"` и `data-part="item"` на `Pagination.Item`
- `data-scope="pagination"` и `data-part="prev-trigger"` на `Pagination.PrevTrigger`
- `data-scope="pagination"` и `data-part="next-trigger"` на `Pagination.NextTrigger`
- `data-scope="pagination"` и `data-part="first-trigger"` или `data-part="last-trigger"` на крайних триггерах
- `data-selected` на активном элементе страницы
- `data-disabled` на недоступных триггерах
- `data-slot="pagination-root"`, `pagination-root-provider`, `pagination-item`,
  `pagination-ellipsis`, `pagination-prev-trigger`, `pagination-next-trigger`,
  `pagination-first-trigger` и `pagination-last-trigger` для переопределения стилей moduix
