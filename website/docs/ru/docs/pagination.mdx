## Анатомия

```text
Pagination
├─ PaginationFirstTrigger (необязательно)
├─ PaginationPrevTrigger
├─ PaginationItems (рекомендуется)
├─ PaginationContext (расширенный доступ к состоянию через render prop)
│  ├─ PaginationItem
│  └─ PaginationEllipsis
├─ PaginationNextTrigger
└─ PaginationLastTrigger (необязательно)

PaginationRootProvider
└─ та же структура из триггеров, элементов, многоточий и контекста, подключённая к usePagination()
```

| Часть                             | Назначение                                                            |
| --------------------------------- | --------------------------------------------------------------------- |
| `Pagination`                      | Корневой компонент навигации, который управляет текущей страницей и числом элементов на странице. |
| `PaginationRootProvider`         | Подключает части к состоянию, созданному через `usePagination()`.                     |
| `PaginationItems`                | Выводит рассчитанные элементы страниц и многоточия.                                              |
| `PaginationContext`              | Открывает доступ к состоянию корня и методам навигации через render prop Ark UI.                  |
| `usePagination`        | Создаёт состояние пагинации за пределами дерева, где отображается компонент.                      |
| `usePaginationContext` | Даёт потомку доступ к состоянию пагинации.                                                        |
| `PaginationItem`                 | Интерактивный элемент страницы. Принимает объект страницы в качестве свойств.                    |
| `PaginationEllipsis`             | Декоративный маркер скрытой части диапазона страниц, скрыт от вспомогательных технологий. Требует `index`.                          |
| `PaginationPrevTrigger`          | Переходит на предыдущую страницу и отключается, когда выбрана первая страница.                    |
| `PaginationNextTrigger`          | Переходит на следующую страницу и отключается, когда выбрана последняя страница.                  |
| `PaginationFirstTrigger`         | Переходит на первую страницу и отключается, если она уже выбрана.                                 |
| `PaginationLastTrigger`          | Переходит на последнюю страницу и отключается, если она уже выбрана.                              |

## Композиция

Используйте `defaultPage` и `defaultPageSize`, если состояние должен хранить сам компонент. Если
состоянием управляет другая часть приложения, передайте `page`, `pageSize` и соответствующие
обработчики изменений. В `count` указывайте общее число элементов данных, а не страниц, и задавайте
размер страницы, чтобы Ark мог вычислить `totalPages`.

Для стандартного списка страниц используйте `PaginationItems`. Если нужно изменить отображение
страниц или добавить элементы управления рядом с ними, используйте `PaginationContext`. Когда
состояние создаётся за пределами дерева, создайте его через `usePagination()` и передайте
в `PaginationRootProvider`. Для навигации по URL задайте `type="link"`, передайте `getPageUrl(details)`
и отрисуйте семантические ссылки через `asChild`.

В Vue используйте `v-model:page` и `v-model:page-size` для управляемого состояния. События
`pageChange` и `pageSizeChange` доступны как `@page-change` и `@page-size-change`.

## Примеры

### Управляемое состояние

Передайте текущую страницу через `page` и обновляйте её в `onPageChange(details)`.

<Example name="pagination/controlled" />

### Контекст

Используйте `PaginationContext`, чтобы разместить собственные элементы управления рядом со списком
страниц и вызывать методы навигации, например `goToFirstPage()` или `goToLastPage()`.

<Example name="pagination/context" />

### Постраничный вывод данных на клиенте

Используйте `pagination.slice(data)` из контекста, чтобы на текущей странице показывать только нужную
часть уже загруженного массива.

<Example name="pagination/data-slicing" />

### Навигация по ссылкам

Используйте `type="link"`, `getPageUrl(details)` и якоря с `asChild`, если переход между страницами
должен менять URL и выполнять настоящую навигацию.

<Example name="pagination/link" />

### Диапазон элементов

Используйте `pagination.pageRange`, чтобы показать, какие элементы видны на текущей странице.

<Example name="pagination/page-range" />

### Число элементов на странице

Вызывайте `pagination.setPageSize(nextSize)` из контекста, когда отдельный элемент управления меняет
число элементов на странице.

<Example name="pagination/page-size-control" />

### Root Provider

Создайте состояние через `usePagination()` и передайте его в `PaginationRootProvider`,
если это состояние нужно использовать за пределами дерева с пагинацией.

<Example name="pagination/root-provider" />

### Локализация

Передайте `translations`, чтобы настроить подписи для средств доступности. Параметры `siblingCount`,
`boundaryCount` и параметры, задающие число элементов на странице, позволяют изменить видимый диапазон страниц.

<Example name="pagination/customized" />

### Кнопки первой и последней страницы

Добавьте `PaginationFirstTrigger` и `PaginationLastTrigger`, если пользователям нужны быстрые
переходы к первой и последней странице.

<Example name="pagination/with-edges" />

### Расширенная настройка

Используйте `PaginationContext` вместо `PaginationItems`, если кнопкам страниц или многоточиям нужно
нестандартное содержимое. Передавайте каждый объект страницы в `PaginationItem` без изменений, чтобы
сохранить состояние и доступность Ark.

## Стилизация

moduix сохраняет атрибуты состояния Ark и добавляет стабильные хуки `data-slot` для локальной стилизации.
В номерах страниц используются табличные цифры и компактные горизонтальные отступы. Поэтому одно- и
двузначные номера сохраняют квадратную форму, а более длинные значения расширяются без обрезки.

Цвета, рамки, скругление и типографика берутся из токенов foundation. Переопределяйте их через `className`
в React или `class` в Solid и Vue на нужной части; для текущей страницы используйте `[data-selected]` на
`PaginationItem`. CSS-переменная ниже задаёт общий размер страниц, многоточий и кнопок в вариантах CSS
Modules.

### Хуки стилизации

- `data-scope="pagination"` и `data-part="item"` на `PaginationItem`
- `data-scope="pagination"` и `data-part="prev-trigger"` на `PaginationPrevTrigger`
- `data-scope="pagination"` и `data-part="next-trigger"` на `PaginationNextTrigger`
- `data-scope="pagination"` и `data-part="first-trigger"` или `data-part="last-trigger"` на крайних триггерах
- `data-selected` на активном элементе страницы
- `data-disabled` на недоступных триггерах
- `data-slot="pagination-root"`, `pagination-root-provider`, `pagination-item`,
  `pagination-ellipsis`, `pagination-prev-trigger`, `pagination-next-trigger`,
  `pagination-first-trigger` и `pagination-last-trigger` для переопределения стилей moduix
