## Анатомия

```text
Pagination
├─ Pagination.FirstTrigger (необязательно)
├─ Pagination.PrevTrigger
├─ Pagination.Items (рекомендуется)
├─ Pagination.Context (расширенный доступ к состоянию через render prop)
│  ├─ Pagination.Item
│  └─ Pagination.Ellipsis
├─ Pagination.NextTrigger
└─ Pagination.LastTrigger (необязательно)

Pagination.RootProvider
└─ та же структура из триггеров, элементов, многоточий и контекста, подключённая к usePagination()
```

| Часть                             | Роль                                                                  |
| --------------------------------- | --------------------------------------------------------------------- |
| `Pagination`                      | Корневой компонент навигации, который хранит состояние текущей страницы и размера страницы. |
| `Pagination.RootProvider`         | Подключает части компонента к состоянию, созданному через `Pagination.usePagination()`.       |
| `Pagination.Items`                | Выводит стандартный набор страниц и многоточий, рассчитанный Ark.                              |
| `Pagination.Context`              | Даёт доступ к состоянию корня и его методам через render prop Ark.                              |
| `Pagination.usePagination`        | Создаёт состояние пагинации Ark за пределами дерева компонента.                                |
| `Pagination.usePaginationContext` | Даёт потомку доступ к состоянию пагинации Ark.                                                   |
| `Pagination.Item`                 | Интерактивный элемент страницы. Получает объект `{ type: 'page', value }`.                      |
| `Pagination.Ellipsis`             | Неинтерактивный маркер скрытой части диапазона; параметр `index` обязателен.                    |
| `Pagination.PrevTrigger`          | Переходит на предыдущую страницу и отключается на первой странице.                              |
| `Pagination.NextTrigger`          | Переходит на следующую страницу и отключается на последней странице.                            |
| `Pagination.FirstTrigger`         | Переходит на первую страницу и отключается, если она уже выбрана.                               |
| `Pagination.LastTrigger`          | Переходит на последнюю страницу и отключается, если она уже выбрана.                            |

## Композиция

### Рекомендуемая композиция

Компонент `Pagination.Root` отвечает за навигацию с клавиатуры, текущую страницу, размер страницы,
состояние отключённых триггеров, расчёт диапазона страниц и подписи для средств доступности. Используйте `count` для общего
числа элементов данных, а не для количества страниц. Укажите `pageSize` или `defaultPageSize`,
чтобы Ark мог вычислить `totalPages`.

Для стандартного списка страниц используйте `Pagination.Items`. Он берёт текущий массив Ark `pages`,
выводит его с помощью `Pagination.Item` и `Pagination.Ellipsis`, а также сохраняет выбранное состояние,
подписи элементов и обработчики.

### Когда нужна собственная композиция

Используйте `Pagination.Context`, если нужно изменить отображение элементов страниц или соседних элементов
управления. Если состояние нужно создать за пределами дерева пагинации, создайте его с помощью
`Pagination.usePagination()`, а затем передайте в `Pagination.RootProvider`. Потомок, которому нужно это
состояние, может получить его через `Pagination.usePaginationContext()`. Если вместо кнопок должны быть
навигационные ссылки, задайте `type="link"` и передайте `getPageUrl(details)`.

### Свойства по умолчанию

| Свойство          | По умолчанию | Примечание                                                        |
| ----------------- | ------------ | ----------------------------------------------------------------- |
| `aria-label`      | `Pagination` | Подпись навигационного ориентира по умолчанию в moduix.             |
| `defaultPage`     | `1`          | Начальная активная страница в неуправляемом режиме Ark.            |
| `defaultPageSize` | `10`         | Начальное число элементов на странице в неуправляемом режиме.      |
| `siblingCount`    | `1`          | Число страниц, отображаемых рядом с активной страницей.            |
| `boundaryCount`   | `1`          | Число страниц, отображаемых в начале и конце диапазона.            |
| `type`            | `button`     | Тип по умолчанию. Для ссылок задайте `link` и передайте `getPageUrl(details)`. |

### Особенности поведения

Если состояние должно храниться внутри компонента, используйте `defaultPage` и `defaultPageSize`.
Чтобы управлять им из кода приложения, передайте `page`, `pageSize`, `onPageChange(details)` и
`onPageSizeChange(details)`. Обработчики получают исходные объекты `details` от Ark, поэтому читайте
`details.page` и `details.pageSize` напрямую. Ark сохраняет навигацию с клавиатуры, семантику выбранного
элемента, состояние отключённых триггеров, `ids`, `asChild`, локализацию и генерацию URL для ссылок.

## Стилизация

moduix сохраняет атрибуты состояния Ark и добавляет стабильные хуки `data-slot` для локальной стилизации.
В номерах страниц используются табличные цифры и небольшие горизонтальные отступы. Поэтому одно- и
двузначные номера сохраняют квадратную форму, а более длинные значения расширяются без обрезки.

### Хуки стилизации

- `data-scope="pagination"` и `data-part="item"` на `Pagination.Item`
- `data-scope="pagination"` и `data-part="prev-trigger"` на `Pagination.PrevTrigger`
- `data-scope="pagination"` и `data-part="next-trigger"` на `Pagination.NextTrigger`
- `data-scope="pagination"` и атрибуты частей первого и последнего триггеров
- `data-selected` на активном элементе страницы
- `data-disabled` на недоступных триггерах
- `data-slot="pagination-root"`, `pagination-root-provider`, `pagination-item`,
  `pagination-ellipsis` и слоты отдельных триггеров для переопределения стилей moduix
