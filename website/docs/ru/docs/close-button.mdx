## Использование

<Usage />

Используйте `CloseButton`, чтобы добавить кнопку закрытия к уведомлению, карточке, оверлею или другой области
интерфейса. Свяжите обработчик `onClick` с состоянием, которое скрывает или удаляет эту область. Компонент
рендерит семантическую кнопку, задаёт доступное имя по умолчанию и показывает иконку `CloseIcon`, но не управляет
состоянием закрываемого элемента.

## Примеры

### Отключённое состояние

Используйте нативное `disabled`, если кнопка не должна получать фокус. Применяйте `aria-disabled="true"`, если
кнопка должна оставаться доступной для фокуса, но не должна активироваться.

<Example name="close-button/disabled-state" />

### Пользовательское содержимое

Передайте содержимое через `children`, чтобы заменить стандартную иконку и сохранить контракт корневой кнопки.
Если имя кнопки задаётся отдельной подписью, сделайте пользовательскую иконку декоративной с помощью
`aria-hidden="true"`.

<Example name="close-button/custom-children" />

### Использование `asChild`

Используйте `asChild`, если существующая семантическая кнопка должна остаться итоговым DOM-элементом и получить стили
и `data-*`-атрибуты `CloseButton`. Поместите иконку в дочерний элемент и явно укажите его тип.

## Композиция

`CloseButton` не хранит состояние закрываемой области: обработчик `onClick` должен изменить состояние, которое
скрывает или удаляет её. Если у Dialog, Drawer или другого оверлея уже есть триггер закрытия, используйте его,
чтобы родительский компонент сохранил управление закрытием и возвратом фокуса.

Используйте `asChild`, если другой семантический элемент `<button>` должен отвечать за итоговый DOM-узел. Разместите
иконку в дочернем элементе и при необходимости явно укажите на нём `type="button"`, особенно внутри формы. В Vue
поместите кнопку в слот по умолчанию. В Solid `asChild` принимает функцию рендера: передайте её результат в дочерний
элемент через `props()`.

## Стилизация

Используйте `className` в React или `class` в Solid и Vue на корневом элементе для структурных стилей. Варианты
Tailwind используют обычные utility-классы и классы приложения; переменные ниже относятся к вариантам с CSS Modules.
Атрибуты состояния и хуки `data-slot` общие для обоих вариантов стилизации.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `CloseButton` | `close-button-root` |

- `data-scope="close-button"` определяет семейство компонента.
- `data-part="root"` определяет единственную экспортируемую часть.
- `data-disabled` указывает на нормализованное отключённое состояние для `disabled` и `aria-disabled="true"`.
- `className`/`class` объединяется со стандартными стилями компонента на корневом элементе.
- В вариантах с CSS Modules размер непосредственно вложенных SVG задаётся через `--moduix-close-button-icon-size`.

## Клавиатура

`CloseButton` отрисовывает нативную кнопку, поэтому фокус и нажатие обрабатывает браузер. Задайте
доступное имя, если подпись по умолчанию не подходит.

## Справочник API

| Проп | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `aria-label` | `string` | `'Close'` | Доступное имя кнопки; переведите его под свою локаль. |
| `children` | `ReactNode` | `CloseIcon` | Заменяет иконку закрытия по умолчанию. |
| `asChild` | `boolean` | `false` | Переносит стили и свойства кнопки на единственный дочерний элемент. |
| `disabled` | `boolean` | `false` | Отключает кнопку. |
