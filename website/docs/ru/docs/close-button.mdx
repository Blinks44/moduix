## Справочник API

В Ark UI нет отдельного примитива для кнопки закрытия. `moduix` создаёт `CloseButton` с помощью официальной
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
работе с [ref](https://ark-ui.com/docs/guides/ref).

## Базовый пример

Используйте `CloseButton`, чтобы добавить кнопку закрытия к уведомлению, карточке, оверлею или другому элементу
интерфейса. Свяжите `onClick` с состоянием, которое скрывает или удаляет этот элемент. Компонент задаёт семантику
кнопки, доступное имя по умолчанию и стандартную иконку `CloseIcon`, но сам не управляет состоянием элемента.

## Анатомия

У `CloseButton` одна корневая часть, соответствующая модели Ark.

```text
CloseButton / CloseButton.Root
└─ root[data-scope="close-button"][data-part="root"][data-slot="close-button-root"]
   └─ CloseIcon (стандартная) | пользовательские дочерние элементы
```

| Часть                              | Назначение                                                              |
| ---------------------------------- | ------------------------------------------------------------------------ |
| `CloseButton` / `CloseButton.Root` | Интерактивная кнопка закрытия с семантикой и поддержкой доступности обычной кнопки. |

## Композиция

### Рекомендуемая композиция

Используйте `CloseButton` напрямую, когда обычная HTML-кнопка должна выполнять действие закрытия. Обёртка передаёт
свойства кнопки Ark factory, нативные атрибуты, обработчики событий и ref.

### Когда нужна другая разметка

Используйте `asChild`, если другой компонент кнопки должен рендерить корневой DOM-элемент. Композиция Ark допускает
только одного дочернего элемента, и он должен содержать собственную иконку.

Если компонент оверлея уже предоставляет триггер закрытия, используйте его. Такой триггер сам управляет состоянием
закрытия и возвратом фокуса.

### Свойства по умолчанию

| Свойство     | По умолчанию                                | Значения и примечания                           |
| ------------ | ------------------------------------------- | ----------------------------------------------- |
| `type`       | `button`                                    | Только для нативной кнопки                      |
| `aria-label` | `Close`, если нет `aria-labelledby`         | Укажите, что именно закрывает кнопка            |
| `children`   | `CloseIcon`                                 | Заменяет иконку по умолчанию                    |
| `asChild`    | `false`                                     | Композиция Ark factory с одним дочерним элементом |

### Особенности поведения

- `CloseButton` сам ничего не закрывает. Передайте `onClick` с логикой закрытия или используйте триггер закрытия,
  который предоставляет компонент оверлея.
- Если `aria-label` и `aria-labelledby` не заданы, доступным именем будет `Close`. Укажите один из этих атрибутов,
  чтобы описать, что именно закроет кнопка.
- Нативные `disabled` и `aria-disabled="true"` добавляют `data-disabled`, по которому можно стилизовать состояние,
  и блокируют активацию по клику.
- При `asChild` свойство `disabled` не добавляет пользовательскому элементу нативный атрибут `disabled`. Вместо
  этого компонент добавляет `aria-disabled="true"` и `data-disabled`, а активация по клику блокируется.
- Свойства `render`, `nativeButton` и `focusableWhenDisabled` больше не поддерживаются.
- Можно также использовать `CloseButton.Root`. Это эквивалентная форма записи, соответствующая модели Ark.

### Атрибуты для стилизации

- `data-scope="close-button"` определяет семейство компонента.
- `data-part="root"` определяет единственную экспортируемую часть.
- `data-slot="close-button-root"` служит стабильным селектором слота moduix.
- `data-disabled` указывает на нормализованное отключённое состояние для `disabled` и `aria-disabled="true"`.
- SVG-элементы, вложенные непосредственно в кнопку, получают размер из `--moduix-close-button-icon-size`.
