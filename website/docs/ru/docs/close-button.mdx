## Справочник API

В Ark UI нет отдельного примитива для кнопки закрытия. `moduix` создаёт `CloseButton` с помощью официальной
[фабрики Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
работе с [ref](https://ark-ui.com/docs/guides/ref).

## Базовый пример

Используйте `CloseButton`, чтобы добавить кнопку закрытия к уведомлению, карточке, оверлею или другой области
интерфейса. Свяжите обработчик `onClick` с состоянием, которое скрывает или удаляет эту область. Компонент
рендерит семантическую кнопку, задаёт доступное имя по умолчанию и показывает иконку `CloseIcon`, но не управляет
состоянием закрываемого элемента.

## Анатомия

У `CloseButton` одна корневая часть, построенная по модели Ark.

```text
CloseButton / CloseButton.Root
└─ root[data-scope="close-button"][data-part="root"][data-slot="close-button-root"]
   └─ CloseIcon (стандартная) | пользовательские дочерние элементы
```

| Часть                              | Назначение                                                              |
| ---------------------------------- | ------------------------------------------------------------------------ |
| `CloseButton` / `CloseButton.Root` | Интерактивный элемент закрытия на основе семантики кнопки с поддержкой доступности. |

## Композиция

### Рекомендуемая композиция

Используйте `CloseButton` напрямую, если компонент должен отрисовать нативный элемент `<button>`. Он передаёт
свойства кнопки из Ark factory, нативные атрибуты, обработчики событий и `ref`.

### Когда нужна другая разметка

Используйте `asChild`, если другой компонент кнопки должен отвечать за итоговый DOM-узел. Передайте ровно один
дочерний элемент и поместите иконку внутрь него.

Если оверлей уже предоставляет триггер закрытия, используйте его: он сам управляет закрытием и возвратом фокуса.

### Свойства по умолчанию

| Свойство     | По умолчанию                                | Значения и примечания                           |
| ------------ | ------------------------------------------- | ----------------------------------------------- |
| `type`       | `button`                                    | Только для нативной кнопки                      |
| `aria-label` | `Close`, если оба атрибута доступного имени не заданы | Укажите, что именно закрывает кнопка            |
| `children`   | `CloseIcon`                                         | Заменяет содержимое по умолчанию                 |
| `asChild`    | `false`                                             | Использует один дочерний элемент как корневой    |

### Особенности поведения

- `CloseButton` сам ничего не закрывает. Передайте `onClick` с логикой закрытия или используйте триггер закрытия,
  который предоставляет оверлей.
- Если не заданы ни `aria-label`, ни `aria-labelledby`, доступным именем будет `Close`. В интерфейсе указывайте
  название конкретного элемента, например `Dismiss notification`.
- Свойства `disabled` и `aria-disabled="true"` задают `data-disabled` и блокируют активацию по клику.
- Для нативного корня `type="button"` задаётся по умолчанию. При использовании `asChild` укажите `type` на
  дочернем элементе сами, особенно если кнопка находится внутри формы.
- При `asChild` свойство `disabled` представлено атрибутом `aria-disabled="true"`, а не нативным `disabled`.
  Активация по клику всё равно блокируется.
- Можно также использовать `CloseButton.Root`. Это эквивалентная форма записи.

### Атрибуты для стилизации

- `data-scope="close-button"` определяет семейство компонента.
- `data-part="root"` определяет единственную экспортируемую часть.
- `data-slot="close-button-root"` служит стабильным селектором слота moduix.
- `data-disabled` указывает на нормализованное отключённое состояние для `disabled` и `aria-disabled="true"`.
- `className` объединяется со стандартными стилями компонента на корневом элементе.
- У непосредственно вложенных SVG-элементов ширина и высота задаются через `--moduix-close-button-icon-size`.
