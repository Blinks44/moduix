## Базовый пример

ScrollArea доступен для React и Solid как в пакетах с CSS Modules, так и в вариантах на Tailwind.
Предпросмотр на этой странице использует React и CSS Modules, а вкладки с кодом показывают нативный код с тем же
публичным контрактом.

Используйте `ScrollArea` как корневой элемент. Разместите `Viewport` вокруг `Content`, добавьте по
одному `Scrollbar` и `Thumb` для каждой оси прокрутки, а при переполнении по обеим осям добавьте
`Corner`. Задайте корневому элементу ограниченную высоту или размер по блочной оси, чтобы
содержимое можно было прокручивать.

## Анатомия

```text
ScrollArea / ScrollArea.Root
├─ ScrollArea.Viewport
│  └─ ScrollArea.Content
│     └─ children
├─ ScrollArea.Scrollbar
│  └─ ScrollArea.Thumb
└─ ScrollArea.Corner

ScrollArea.RootProvider
└─ то же дерево, подключённое к состоянию useScrollArea()
```

| Часть                             | Назначение                                                       |
| -------------------------------- | ---------------------------------------------------------------- |
| `ScrollArea` / `ScrollArea.Root` | Управляет состоянием прокрутки и позиционированием.              |
| `ScrollArea.RootProvider`        | Подключает части к состоянию из `useScrollArea()`.               |
| `ScrollArea.Viewport`            | Нативный контейнер прокрутки и элемент, принимающий фокус.      |
| `ScrollArea.Content`             | Внутренняя оболочка содержимого, которую измеряет Ark UI.       |
| `ScrollArea.Scrollbar`           | Стилизованная полоса прокрутки для одной оси.                   |
| `ScrollArea.Thumb`               | Перетаскиваемый бегунок внутри полосы прокрутки.                 |
| `ScrollArea.Corner`              | Заполняет область пересечения при переполнении по обеим осям.  |

## Композиция

Для каждой оси прокрутки нужна отдельная `ScrollArea.Scrollbar` с `ScrollArea.Thumb`. По умолчанию
полоса вертикальная, для горизонтальной установите `orientation="horizontal"`. Размещайте
`Viewport` вокруг `Content`, а для вложенных областей сохраняйте полное независимое дерево.

Используйте `ScrollArea.RootProvider` вместе с `ScrollArea.useScrollArea()`, если внешним элементам
управления нужен API прокрутки. Передайте возвращённое состояние в `RootProvider` и не используйте
`ScrollArea` и `ScrollArea.RootProvider` для одного состояния. В Solid читайте состояние и вызывайте
его методы через аксессор, возвращённый `useScrollArea()`.

## Стилизация

Таблица CSS-переменных относится к пакетам с CSS Modules. В пакетах Tailwind используйте нативные
утилиты и пользовательские переопределения через `className` или `class`. CSS-переменные на корне
подходят, если нужно изменить толщину полосы, оформление кольца фокуса или поверхность, не меняя
структуру.

### Хуки стилизации

- moduix добавляет стабильные хуки `data-slot` со значениями `scroll-area-root`,
  `scroll-area-root-provider`, `scroll-area-viewport`, `scroll-area-content`,
  `scroll-area-scrollbar`, `scroll-area-thumb` и `scroll-area-corner`.
- Свойство `fade` добавляет `data-fade`, а свойство `variant` добавляет
  `data-variant="hover" | "always"` на `ScrollArea` и `ScrollArea.RootProvider`.
- Ark добавляет `data-scope="scroll-area"` и `data-part` для каждой части.
- `data-overflow-x` и `data-overflow-y` появляются, когда измеренное содержимое переполняется по
  соответствующей оси.
- `data-at-top`, `data-at-bottom`, `data-at-left` и `data-at-right` доступны на `Viewport`.
- `data-orientation="vertical"` и `data-orientation="horizontal"` доступны на полосах прокрутки
  и бегунках.
- `data-hover` и `data-dragging` доступны на полосах и бегунках, а `data-scrolling` на полосах.
- Корневые переменные Ark `--corner-width`, `--corner-height`, `--thumb-width` и `--thumb-height`
  управляют смещением угла и размерами бегунка. Переменные `Viewport`
  `--scroll-area-overflow-x-start`, `--scroll-area-overflow-x-end`,
  `--scroll-area-overflow-y-start` и `--scroll-area-overflow-y-end` показывают расстояние до краёв.
