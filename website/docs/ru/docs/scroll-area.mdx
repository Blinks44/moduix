## Базовый пример

Используйте `ScrollArea` как корневой элемент Ark и явно добавьте части `Viewport`, `Content`,
`Scrollbar`, `Thumb` и `Corner`. `Viewport` остаётся нативным контейнером прокрутки, поэтому
прокрутка колёсиком мыши, тачпадом, касанием и клавиатурой продолжает работать. Части `Scrollbar`
добавляют стилизованные элементы управления. moduix также добавляет `fade`: он накладывает
градиентную маску у верхнего и нижнего края на основе данных Ark о переполнении.

## Анатомия

```text
ScrollArea
├─ ScrollArea.Viewport
│  └─ ScrollArea.Content
│     └─ children
├─ ScrollArea.Scrollbar
│  └─ ScrollArea.Thumb
└─ ScrollArea.Corner
```

| Часть                             | Назначение                                                                    |
| -------------------------------- | ----------------------------------------------------------------------------- |
| `ScrollArea` / `ScrollArea.Root` | Управляет состоянием и служит внешним контейнером для позиционирования.       |
| `ScrollArea.RootProvider`        | Корневой элемент, который получает состояние из `ScrollArea.useScrollArea()`. |
| `ScrollArea.Viewport`            | Нативный контейнер прокрутки и элемент, принимающий фокус.                    |
| `ScrollArea.Content`             | Внутренняя оболочка содержимого, которую измеряет Ark UI.                     |
| `ScrollArea.Scrollbar`           | Стилизованная дорожка полосы прокрутки для одной оси.                         |
| `ScrollArea.Thumb`               | Перетаскиваемый бегунок внутри полосы прокрутки.                              |
| `ScrollArea.Corner`              | Заполняет область на пересечении двух полос, когда переполняются обе оси.     |

## Композиция

### Рекомендуемая композиция

В большинстве случаев используйте `ScrollArea`. Компонент не создаёт автоматически `Viewport`,
`Content` или `Scrollbar`: добавьте части Ark явно, чтобы управлять каждым узлом структуры. Задайте
корневому элементу ограниченную высоту или размер по блочной оси. Без ограничения содержимое будет
расширять корневой элемент, а не прокручиваться.

### Когда нужна собственная композиция

Используйте `ScrollArea.useScrollArea()` с `ScrollArea.RootProvider`, если элементы управления за
пределами корневого элемента должны вызывать методы API области прокрутки. Пакет также экспортирует
`useScrollArea` и `useScrollAreaContext`; `useScrollArea` доступен и как `ScrollArea.useScrollArea()`.
Для чтения расширенного состояния используйте `ScrollArea.Context` или `useScrollAreaContext()`.
Не используйте `ScrollArea` и `ScrollArea.RootProvider` для одного объекта состояния.

### Свойства по умолчанию

| Свойство                                               | По умолчанию  | Примечания                                                                       |
| ------------------------------------------------------ | ------------- | -------------------------------------------------------------------------------- |
| `fade` на `ScrollArea` и `ScrollArea.RootProvider`    | `false`       | Добавляет маску сверху и снизу на основе значений Ark `--scroll-area-overflow-y-*`. |
| `variant` на `ScrollArea` и `ScrollArea.RootProvider` | `hover`       | Используйте `always`, чтобы переполняющиеся полосы оставались видимыми и интерактивными. |
| `orientation` на `ScrollArea.Scrollbar`                | `vertical`    | Установите `orientation="horizontal"` для горизонтальной дорожки.             |
| `asChild`                                              | `false`       | Доступно для каждой части Ark, чтобы использовать один дочерний элемент как узел хоста. |
| `ids` на `ScrollArea`                                  | сгенерированы | Используйте, если другому коду нужны стабильные ID корня, viewport, content, scrollbar или thumb. |

### Особенности поведения

- Добавьте по одной части `ScrollArea.Scrollbar` для каждой нужной оси.
- Передайте корневому элементу свойство Ark `dir="rtl"` для прокрутки справа налево. moduix
  использует логическое позиционирование, поэтому вертикальная полоса размещается у логического
  конечного края.
- Ark добавляет `data-overflow-x` и `data-overflow-y`, а moduix скрывает полосы, пока содержимое
  действительно не переполнится по соответствующей оси.
- Установите `variant="always"`, если переполняющаяся полоса должна оставаться видимой и
  интерактивной в состоянии покоя.
- Стили `Viewport` скрывают нативные полосы прокрутки браузера с помощью `scrollbar-width: none`
  и правила для WebKit, необходимого Ark UI.
- В режиме `forced-colors` moduix отключает необязательную маску `fade`, чтобы она не перекрывала
  содержимое, и использует системные цвета для кольца фокуса `Viewport` и бегунка.
- `ref` пробрасывается на фактический DOM-элемент каждой части. В частности, `ref` на `ScrollArea`
  указывает на корневой элемент, а `ref` на `ScrollArea.Viewport` указывает на нативный контейнер
  прокрутки.

## Стилизация

Используйте CSS-переменные на корневом элементе, если нужно изменить толщину полосы прокрутки,
оформление кольца фокуса или стили контейнера, не меняя его структуру. По умолчанию бегунок
использует цвет токена границы, а при наведении или перетаскивании полоса становится на `2px` толще,
поэтому вместе с ней увеличивается и бегунок. Настройте величину через
`--moduix-scroll-area-thumb-hover-increase`, а длительность перехода через
`--moduix-scroll-area-thumb-hover-transition`.

### Хуки стилизации

- moduix добавляет стабильный атрибут `data-slot` со значениями `scroll-area-root`,
  `scroll-area-root-provider`, `scroll-area-viewport`, `scroll-area-content`,
  `scroll-area-scrollbar`, `scroll-area-thumb` и `scroll-area-corner`.
- Свойство `fade` добавляет `data-fade`, а `variant` добавляет `data-variant="hover" | "always"`
  на `ScrollArea` и `ScrollArea.RootProvider`.
- Ark добавляет `data-scope="scroll-area"` и `data-part` для каждой части.
- `data-overflow-x` и `data-overflow-y` появляются, когда измеренное содержимое переполняется по
  соответствующей оси.
- `data-at-top`, `data-at-bottom`, `data-at-left` и `data-at-right` доступны на `Viewport`.
- `data-orientation="vertical"` и `data-orientation="horizontal"` доступны на полосах прокрутки
  и бегунках.
- `data-hover` и `data-dragging` доступны на полосах и бегунках, а `data-scrolling` на полосах.
- Корневые переменные Ark `--corner-width`, `--corner-height`, `--thumb-width` и `--thumb-height`
  управляют смещением угла и размерами бегунка. Переменные `Viewport` Ark
  `--scroll-area-overflow-x-start`, `--scroll-area-overflow-x-end`,
  `--scroll-area-overflow-y-start` и `--scroll-area-overflow-y-end` показывают расстояние до краёв.
