## Базовый пример


Используйте `ScrollArea` как корневой элемент. Разместите `ScrollAreaViewport` вокруг
`ScrollAreaContent`, добавьте по одному `ScrollAreaScrollbar` и `ScrollAreaThumb` для каждой оси
прокрутки, а при переполнении по обеим осям добавьте
`ScrollAreaCorner`. Задайте корневому элементу ограниченную высоту или размер по блочной оси, чтобы
содержимое можно было прокручивать.

## Анатомия

```text
ScrollArea
├─ ScrollAreaViewport
│  └─ ScrollAreaContent
│     └─ children
├─ ScrollAreaScrollbar
│  └─ ScrollAreaThumb
└─ ScrollAreaCorner

ScrollAreaRootProvider
└─ то же дерево, подключённое к состоянию useScrollArea()
```

| Часть                             | Назначение                                                       |
| -------------------------------- | ---------------------------------------------------------------- |
| `ScrollArea`                     | Управляет состоянием прокрутки и позиционированием.              |
| `ScrollAreaRootProvider`        | Подключает части к состоянию из `useScrollArea()`.               |
| `ScrollAreaViewport`            | Нативный контейнер прокрутки и элемент, принимающий фокус.      |
| `ScrollAreaContent`             | Внутренняя оболочка содержимого, которую измеряет Ark UI.       |
| `ScrollAreaScrollbar`           | Стилизованная полоса прокрутки для одной оси.                   |
| `ScrollAreaThumb`               | Перетаскиваемый бегунок внутри полосы прокрутки.                 |
| `ScrollAreaCorner`              | Заполняет область пересечения при переполнении по обеим осям.  |

## Композиция

Для каждой оси прокрутки нужна отдельная `ScrollAreaScrollbar` с `ScrollAreaThumb`. По умолчанию
полоса вертикальная, для горизонтальной установите `orientation="horizontal"`. Размещайте
`ScrollAreaViewport` вокруг `ScrollAreaContent`, а для вложенных областей сохраняйте полное
независимое дерево.

Используйте `ScrollAreaRootProvider` вместе с `useScrollArea()`, если внешним элементам
управления нужен API прокрутки. Передайте возвращённое состояние в `ScrollAreaRootProvider` и не
используйте `ScrollArea` и `ScrollAreaRootProvider` для одного состояния. В Solid читайте состояние и вызывайте
его методы через аксессор, возвращённый `useScrollArea()`.

## Стилизация

Таблица CSS-переменных относится к пакетам с CSS Modules. В пакетах Tailwind используйте нативные
утилиты и пользовательские переопределения через `className` или `class`. CSS-переменные на корне
меняют толщину полосы, цвет ползунка и глубину затухания. Viewport наследует `border-radius` корня,
поэтому скруглённый корень скругляет и обрезанный контент, и кольцо фокуса.

### Хуки стилизации

- moduix добавляет стабильные хуки `data-slot` со значениями `scroll-area-root`,
  `scroll-area-root-provider`, `scroll-area-viewport`, `scroll-area-content`,
  `scroll-area-scrollbar`, `scroll-area-thumb` и `scroll-area-corner`.
- Свойство `fade` добавляет `data-fade`, а свойство `variant` добавляет
  `data-variant="hover" | "always"` на `ScrollArea` и `ScrollAreaRootProvider`.
- Ark добавляет `data-scope="scroll-area"` и `data-part` для каждой части.
- `data-overflow-x` и `data-overflow-y` появляются, когда измеренное содержимое переполняется по
  соответствующей оси.
- `data-at-top`, `data-at-bottom`, `data-at-left` и `data-at-right` доступны на
  `ScrollAreaViewport`.
- `data-orientation="vertical"` и `data-orientation="horizontal"` доступны на полосах прокрутки
  и бегунках.
- `data-hover` и `data-dragging` доступны на полосах и бегунках, а `data-scrolling` на полосах.
- Корневые переменные Ark `--corner-width`, `--corner-height`, `--thumb-width` и `--thumb-height`
  управляют смещением угла и размерами бегунка. Переменные `ScrollAreaViewport`
  `--scroll-area-overflow-x-start`, `--scroll-area-overflow-x-end`,
  `--scroll-area-overflow-y-start` и `--scroll-area-overflow-y-end` показывают расстояние до краёв.
