# React Hook Form

[React Hook Form](https://react-hook-form.com/get-started) работает только с React. Эта страница
описывает интеграцию с React-адаптером Moduix и не подразумевает поддержку Solid, Vue или Svelte.

## Поддержка фреймворков

<PackageManagerTabs command="install react-hook-form" />

Используйте эту интеграцию только с `@moduix/react` или `@moduix/react-tailwind`. Для Solid выберите
нативную форму, [Formisch](/docs/formisch) или [TanStack Form](/docs/tanstack-form).

## Подключение компонентов

Используйте `register` для нативных элементов и `Controller` для составных компонентов, значение
которых передается через свойства и объекты деталей в callback-функциях.

| Компонент Moduix                     | Подключение React Hook Form                              |
| ------------------------------------ | -------------------------------------------------------- |
| `Input`, `Textarea`, нативные select | Передайте элементу `register(name, rules)`.              |
| `Select`, `Combobox`                 | Через `Controller` преобразуйте скаляр в `string[]`.     |
| `Checkbox`                           | Преобразуйте `details.checked === true` в boolean.       |
| Другие управляемые компоненты        | Через `Controller` свяжите их публичный контракт значения. |

Задайте каждому управляемому полю значение в `defaultValues`. Оставьте нативную часть формы Moduix
в композиции и не регистрируйте второй скрытый input для того же значения.

## Валидация и сброс

Используйте `rules` для локальной проверки поля и resolver для схемы или межполевых правил.
Передавайте `fieldState.invalid` в `Field`, а `fieldState.error?.message` выводите через
`Field.ErrorText`.

Добавляйте `noValidate`, только если отображением ошибок управляет React Hook Form. Для управляемых
полей вызывайте `reset()`, чтобы состояние библиотеки и значения Moduix сбрасывались вместе.

## Повторяющиеся поля и серверные ошибки

Для редактируемых списков используйте `useFieldArray`. Отрисовывайте строки по стабильному
`field.id`, а текущий индекс оставляйте только в зарегистрированном пути. Общую легенду и сообщение
группы размещайте в `Fieldset`.

Для серверной ошибки конкретного поля вызывайте `setError(name, ...)`, а для общей ошибки используйте
пространство имен `root`. После неудачного запроса сохраняйте введенные значения.

## Фокус и поведение

- Передавайте `field.ref` в `Select.Trigger` или `ComboboxInput`, чтобы фокус попадал на видимый элемент.
- Вызывайте `field.onBlur` при завершении составного взаимодействия.
- Явно преобразуйте объекты деталей Ark, а не передавайте поле `Controller` целиком корневому компоненту.
- Используйте `formState.isSubmitting` для состояния загрузки и блокировки повторной отправки.
