## Какой компонент выбрать

Используйте `Collapsible` для одного независимого раскрывающегося блока. Если несколько связанных
секций должны использовать общую навигацию с клавиатуры или общее состояние, выбирайте `Accordion`.

## Базовый пример

## Анатомия

```text
Collapsible.Root
├─ Collapsible.Trigger
│  ├─ метка
│  └─ Collapsible.Indicator (необязательно)
└─ Collapsible.Content
   └─ Collapsible.Body
       └─ содержимое
```

| Часть                              | Назначение                                                               |
| ---------------------------------- | ------------------------------------------------------------------------ |
| `Collapsible` / `Collapsible.Root` | Управляет состоянием одного раскрывающегося блока.                       |
| `Collapsible.RootProvider`         | Подключает части к состоянию, созданному через `useCollapsible`.          |
| `Collapsible.Trigger`              | Доступная кнопка для раскрытия и сворачивания содержимого.                |
| `Collapsible.Indicator`            | Необязательный индикатор состояния с шевроном moduix по умолчанию.        |
| `Collapsible.Content`              | Анимируемая область, размер которой измеряет Ark.                        |
| `Collapsible.Body`                 | Внутренняя обёртка для отступов и размещения содержимого.                 |

## Композиция

### Рекомендуемая композиция

Начните с `Collapsible`, `Collapsible.Trigger`, `Collapsible.Content` и `Collapsible.Body`.
Добавляйте `Collapsible.Indicator`, если нужен визуальный признак состояния. Корневой компонент
принимает свойства `open`, `defaultOpen`, `onOpenChange(details)`, `disabled`, `collapsedHeight`,
`collapsedWidth`, `hideMode`, `lazyMount`, `unmountOnExit`, `ids` и `onExitComplete`.

Размещайте отступы и стили поверхности на `Collapsible.Body`, а не на `Collapsible.Content`. Ark
измеряет содержимое и предоставляет переменные `--height`, `--width`, `--collapsed-height` и
`--collapsed-width`.

При переходе с shadcn замените `CollapsibleTrigger` на `Collapsible.Trigger`, а `CollapsibleContent`
на `Collapsible.Content`. В moduix сохраняется объект `details` из Ark, поэтому в управляемом режиме
следующее состояние берите из `details.open`, а не из самого аргумента.

### Когда нужна своя композиция

Используйте `asChild`, если итоговый DOM-узел должен принадлежать другому семантическому элементу.
Часть добавляет к этому элементу поведение Ark и атрибуты состояния, а внешний вид остаётся под вашим
контролем. Пользовательский триггер должен оставаться доступным с клавиатуры и вести себя как кнопка.

Используйте `useCollapsible()` из `@moduix/react/collapsible` вместе с `Collapsible.RootProvider`, когда
состояние нужно создать за пределами дерева отрисованных компонентов. В moduix также доступны
`Collapsible.Context` и `useCollapsibleContext()`.

`Collapsible.Indicator` необязателен. Если не передать дочерние элементы, он выводит шеврон moduix,
направленный вниз. При необходимости передайте собственное содержимое.

### Свойства по умолчанию

| Свойство          | По умолчанию | Примечания                                                                    |
| ----------------- | ------------ | ----------------------------------------------------------------------------- |
| `collapsedHeight` | не задано    | Высота, которая сохраняется, когда содержимое свёрнуто.                       |
| `collapsedWidth`  | не задано    | Ширина, которая сохраняется, когда содержимое свёрнуто.                       |
| `defaultOpen`     | `false`      | При первом рендере область свёрнута.                                          |
| `disabled`        | `false`      | Триггер не может открыть или закрыть содержимое.                              |
| `hideMode`        | `display-none` | Смонтированное закрытое содержимое скрывается через `hidden`. `activity` требует React 19. |
| `lazyMount`       | `false`      | Содержимое монтируется при первом открытии.                                   |
| `open`            | не задано    | Управляемое состояние. Используйте вместе с `onOpenChange`.                  |
| `unmountOnExit`   | `false`      | После закрытия содержимое удаляется из DOM.                                   |

### Особенности поведения

- `onOpenChange` получает объект `details` от Ark. Следующее состояние находится в `details.open`.
- `open` описывает целевое состояние. `visible` остаётся равным `true`, пока закрывающееся содержимое
  смонтировано для анимации выхода.
- Триггер рендерится как нативная кнопка. Клавиши `Enter` и `Space` открывают и закрывают область.
- Не помещайте интерактивные элементы внутрь `Collapsible.Trigger`, чтобы триггер оставался кнопкой.
- При `hideMode="activity"` смонтированное закрытое содержимое использует режим Activity React 19,
  а его эффекты приостанавливаются. По умолчанию `hideMode="display-none"` используется атрибут
  `hidden`.
- Анимации содержимого и индикатора учитывают `prefers-reduced-motion`.

## Стилизация

Используйте `className` у экспортируемых частей для структурных стилей. Для стилей, зависящих от
состояния, предпочитайте атрибуты данных Ark, например `data-state` и `data-disabled`, вместе с
селекторами `data-slot` библиотеки moduix.

### Хуки стилизации

- Части DOM предоставляют `data-slot="collapsible-root"`, `collapsible-root-provider`,
  `collapsible-trigger`, `collapsible-indicator`, `collapsible-content` и `collapsible-body`.
- Части Ark предоставляют `data-scope="collapsible"` и значения `data-part` для корня, триггера,
  индикатора и содержимого. `Collapsible.Body` добавляет `data-part="body"`.
- Ark добавляет `data-state="open" | "closed"` к корневому компоненту, триггеру, индикатору и содержимому.
- Ark добавляет `data-collapsible` к части `Content`.
- `data-disabled` помечает триггер, индикатор и содержимое, если они отключены.
- `data-has-collapsed-size` помечает содержимое, настроенное через `collapsedHeight` или `collapsedWidth`.
- Для анимации содержимого используются переменные Ark `--height`, `--width`, `--collapsed-height` и `--collapsed-width`.
