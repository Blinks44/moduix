## Какой компонент выбрать

Используйте `Collapsible` для одного независимого раскрывающегося блока. Если несколько связанных
секций должны использовать общую навигацию с клавиатуры или общее состояние, выбирайте `Accordion`.

## Базовый пример


Используйте `Collapsible` с частями `CollapsibleTrigger`, необязательным `CollapsibleIndicator` и `CollapsibleContent`, чтобы
раскрывать и сворачивать одну область содержимого. Размещайте содержимое внутри `CollapsibleBody`,
если нужна рекомендуемая внутренняя обёртка для отступов и размещения.

## Анатомия

```text
Collapsible
├─ CollapsibleTrigger
│  ├─ метка
│  └─ CollapsibleIndicator (необязательно)
└─ CollapsibleContent
   └─ CollapsibleBody
       └─ содержимое

CollapsibleRootProvider
└─ то же дерево частей, подключённое к состоянию из useCollapsible()
```

| Часть                     | Назначение                                                               |
| ------------------------- | ------------------------------------------------------------------------ |
| `Collapsible`             | Управляет состоянием одного раскрывающегося блока.                       |
| `CollapsibleRootProvider` | Подключает части к состоянию, созданному через `useCollapsible`.          |
| `CollapsibleTrigger`      | Доступная кнопка для раскрытия и сворачивания содержимого.                |
| `CollapsibleIndicator`    | Необязательный индикатор состояния с шевроном moduix по умолчанию.        |
| `CollapsibleContent`      | Анимируемая область, размер которой измеряет Ark.                        |
| `CollapsibleBody`         | Внутренняя обёртка для отступов и размещения содержимого.                 |

## Композиция

`Collapsible` хранит состояние в корневом компоненте. Используйте `defaultOpen` для неконтролируемого
раскрытия, а `open` с `onOpenChange(details)`, если состоянием управляет другая часть приложения. В
Vue для того же управляемого контракта используйте `v-model:open`. Колбэк сохраняет объект `details`
из Ark, поэтому управляемое состояние нужно брать из `details.open`.

Используйте `CollapsibleRootProvider` вместе с `useCollapsible()` из пакета нужного фреймворка, если
хранилище нужно создать вне дерева или разделить между границами композиции. Передайте это хранилище
в `CollapsibleRootProvider` и не рендерите второй корневой `Collapsible` для того же состояния.

Размещайте отступы и стили поверхности на `CollapsibleBody`, а не на `CollapsibleContent`, чтобы Ark
корректно измерял анимируемую область. `CollapsibleIndicator` необязателен и по умолчанию показывает
шеврон moduix.

Используйте `asChild`, только если поведение триггера должен получить семантический элемент приложения.
Он должен оставаться доступной с клавиатуры кнопкой. В Solid передайте функцию рендера, например
`asChild={(props) => <button {...props()} />}`.

## Примеры

### Контекст

Используйте `useCollapsibleContext()` внутри дочернего компонента, которому нужно получить состояние
или программно закрыть область.

<Example name="collapsible/context" />

### Управляемое состояние

Используйте `open` с колбэком Ark `onOpenChange(details)`, когда состояние хранится в другой части
интерфейса.

<Example name="collapsible/controlled" />

### Открыт по умолчанию

Задайте `defaultOpen`, чтобы неуправляемый компонент изначально был открыт.

<Example name="collapsible/default-open" />

### Отключённое состояние

Задайте `disabled` корневому компоненту, чтобы запретить открытие и закрытие области.

<Example name="collapsible/disabled" />

### Отложенное монтирование

Установите `lazyMount`, чтобы монтировать содержимое только после первого открытия. Добавьте
`unmountOnExit`, чтобы удалять его из DOM после закрытия.

<Example name="collapsible/lazy-mount" />

### Вложенные компоненты

Если внутри раскрытой секции нужен ещё один необязательный блок, вкладывайте независимые корневые компоненты.

<Example name="collapsible/nested" />

### Частичное сворачивание

Укажите `collapsedHeight` или `collapsedWidth`, чтобы после закрытия часть содержимого оставалась видимой.
Интерактивные элементы в этой области становятся недоступными для взаимодействия и навигации с
клавиатуры, пока компонент свёрнут. Поэтому действия, которые должны оставаться доступными, размещайте
за пределами `CollapsibleContent`.

<Example name="collapsible/partial-collapse" />

### Частичная ширина

Используйте `collapsedWidth`, когда удобнее оставлять видимой часть содержимого по ширине, а не по высоте.

<Example name="collapsible/partial-collapse-width" />

### Root Provider

Создайте состояние через `useCollapsible()` и передайте его в `CollapsibleRootProvider`, если код за
пределами дерева отрисованных компонентов должен обращаться к этому состоянию.

<Example name="collapsible/root-provider" />

### Расширенная настройка

Используйте `asChild`, чтобы передать поведение триггера кнопке, которую стилизует ваше приложение.
Стилизация `CollapsibleTrigger` по умолчанию не применяется, но поведение Ark и атрибуты состояния сохраняются.

<Example name="collapsible/custom-composition" />

## Стилизация

Используйте `className` в React или `class` в Solid и Vue у экспортируемых частей для структурных стилей.
Для стилей, зависящих от состояния, предпочитайте атрибуты данных Ark, например `data-state` и
`data-disabled`, вместе с селекторами `data-slot` библиотеки moduix. Варианты на Tailwind используют
нативные утилиты и классы приложения, а переменные ниже настраивают варианты с CSS Modules. Атрибуты
данных и хуки `data-slot` общие для обоих способов стилизации.

Размещайте отступы на `CollapsibleBody`, а не на `CollapsibleContent`, чтобы Ark мог корректно
измерять и анимировать содержимое.

### Хуки стилизации

- Части DOM предоставляют `data-slot="collapsible-root"`, `collapsible-root-provider`,
  `collapsible-trigger`, `collapsible-indicator`, `collapsible-content` и `collapsible-body`.
- Части Ark предоставляют `data-scope="collapsible"` и значения `data-part` для корня, триггера,
  индикатора и содержимого.
- Ark добавляет `data-state="open" | "closed"` к корневому компоненту, триггеру, индикатору и содержимому.
- Ark добавляет `data-collapsible` к части `CollapsibleContent`.
- `data-disabled` помечает триггер, индикатор и содержимое, если они отключены.
- `data-has-collapsed-size` помечает содержимое, настроенное через `collapsedHeight` или `collapsedWidth`.
- Для анимации содержимого используются переменные Ark `--height`, `--width`, `--collapsed-height` и `--collapsed-width`.
