## Анатомия

```text
Collapsible.Root
├─ Collapsible.Trigger
│  ├─ метка
│  └─ Collapsible.Indicator (необязательно)
└─ Collapsible.Content
   └─ Collapsible.Body
       └─ содержимое
```

| Часть                              | Назначение                                             |
| ---------------------------------- | ------------------------------------------------------ |
| `Collapsible` / `Collapsible.Root` | Управляет состоянием открытия. Его можно задавать извне или оставить под управлением компонента. |
| `Collapsible.RootProvider`         | Передаёт частям состояние, созданное через `useCollapsible`. |
| `Collapsible.Trigger`              | Доступная кнопка, которая открывает и закрывает содержимое. |
| `Collapsible.Indicator`            | Необязательный индикатор состояния с шевроном moduix по умолчанию. |
| `Collapsible.Content`              | Область содержимого, размер которой Ark вычисляет с помощью CSS-переменных. |
| `Collapsible.Body`                 | Внутренняя обёртка moduix для отступов и размещения содержимого. |

## Композиция

### Рекомендуемая композиция

Используйте `Collapsible`, `Collapsible.Trigger`, `Collapsible.Content` и `Collapsible.Body`, а
`Collapsible.Indicator` добавляйте при необходимости. Корневой компонент поддерживает
свойства `open`, `defaultOpen`, `onOpenChange(details)`, `disabled`, `collapsedHeight`,
`collapsedWidth`, `lazyMount`, `unmountOnExit`, `ids` и `onExitComplete`.

Добавляйте отступы и стили контейнера к `Collapsible.Body`, а не к `Collapsible.Content`. Ark измеряет
содержимое и делает доступными переменные `--height`, `--width`, `--collapsed-height` и `--collapsed-width`.

При переходе с shadcn замените `CollapsibleTrigger` на `Collapsible.Trigger`, а `CollapsibleContent`
на `Collapsible.Content`. В moduix сохраняется объект `details` из Ark, поэтому в управляемом режиме
следующее состояние берите из `details.open`, а не из самого аргумента.

### Когда нужна нестандартная композиция

Используйте `asChild`, если отрисованный узел должен быть другим семантическим элементом. В этом режиме
Collapsible добавляет к нему поведение Ark и атрибуты состояния, а внешний вид остаётся под вашим контролем.

Используйте `useCollapsible` из moduix вместе с `Collapsible.RootProvider`, когда состояние нужно создать
за пределами дерева компонента. В moduix также доступны `Collapsible.Context` и `useCollapsibleContext()`.

`Collapsible.Indicator` необязателен. Если не передать дочерние элементы, он выводит шеврон moduix,
направленный вниз. При необходимости можно передать собственное содержимое.

### Свойства по умолчанию

| Часть                   | По умолчанию     | Примечания                                         |
| ----------------------- | ---------------- | -------------------------------------------------- |
| `Collapsible`           | закрыт           | `defaultOpen={false}`, содержимое смонтировано      |
| `Collapsible.Trigger`   | `button`         | Поддерживает `asChild` из Ark                       |
| `Collapsible.Indicator` | шеврон вниз      | Поворачивается вверх при `data-state="open"`       |
| `Collapsible.Content`   | свёрнутая область | Использует переменные измерения и стратегию рендеринга Ark |
| `Collapsible.Body`      | `div`            | Внутренняя обёртка с отступами и интервалом         |

### Особенности поведения

- `onOpenChange` получает объект `details` от Ark. Следующее состояние находится в `details.open`.
- `open` описывает целевое состояние. `visible` остаётся равным `true`, пока закрывающееся содержимое
  смонтировано для анимации выхода.
- Не помещайте вложенные интерактивные элементы внутрь `Collapsible.Trigger`.
- Анимации содержимого и индикатора учитывают `prefers-reduced-motion`.
- Используйте `Accordion`, если нескольким раскрывающимся секциям нужны единые правила работы с клавиатурой
  или общие значения.

### CSS-свойства

### Точки подключения стилей

- Части DOM предоставляют `data-slot="collapsible-root"`, `collapsible-root-provider`,
  `collapsible-trigger`, `collapsible-indicator`, `collapsible-content` и `collapsible-body`.
- Ark добавляет `data-state="open" | "closed"` к корневому компоненту, триггеру, индикатору и содержимому.
- Ark добавляет `data-collapsible` к части `Content`.
- `data-disabled` помечает триггер, индикатор и содержимое, если они отключены.
- `data-has-collapsed-size` помечает содержимое, настроенное через `collapsedHeight` или `collapsedWidth`.
- Для анимации содержимого используются переменные Ark `--height`, `--width`, `--collapsed-height` и `--collapsed-width`.
