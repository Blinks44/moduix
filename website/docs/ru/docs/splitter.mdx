## Базовый пример


Соберите Splitter из `Splitter`, `Splitter.Panel` и `Splitter.ResizeTrigger`. Свойство `panels`
содержит идентификаторы панелей и ограничения их размеров. У каждой отрисованной `Splitter.Panel`
должен быть один из этих идентификаторов. Если не передавать триггеру дочерние элементы, moduix
добавит индикатор изменения размера автоматически.

## Анатомия

```text
Splitter / Splitter.Root
├─ Splitter.Panel[id]
├─ Splitter.ResizeTrigger[id="panel-a:panel-b"]
│  └─ Splitter.ResizeTriggerIndicator (по умолчанию, настраивается)
└─ Splitter.Panel[id]

Splitter.RootProvider
└─ то же дерево панелей, подключённое к состоянию useSplitter()
```

| Часть                              | Назначение                                                                     |
| ---------------------------------- | ------------------------------------------------------------------------------ |
| `Splitter` / `Splitter.Root`       | Управляет панелями, их размерами, ориентацией, колбэками и состоянием.          |
| `Splitter.Panel`                   | Область с изменяемым размером. Её `id` должен совпадать с записью в `panels`.  |
| `Splitter.ResizeTrigger`           | Доступная кнопка для изменения размера двух соседних панелей.                  |
| `Splitter.ResizeTriggerIndicator`  | Стандартная визуальная ручка. Дочерние элементы триггера заменяют её.           |
| `Splitter.RootProvider`            | Отображает те же части, используя состояние из `useSplitter()`.                |

## Композиция

Используйте `size` вместе с `onResize(details)`, если приложение владеет текущими размерами панелей.
Выбирайте `Splitter.RootProvider` с `useSplitter()`, если состояние или элементы управления должны
находиться за пределами дерева панелей, и используйте только один корень для каждого состояния. Для
вложенных Splitter, которые должны изменять размер одновременно на пересечениях ручек, создайте один
`createSplitterRegistry()` и передайте его каждому корню. Числовые значения `defaultSize`, `size` и
`minSize` — это проценты, которые в сумме должны давать 100, а Ark также принимает для этих размеров
значения длин CSS.

Используйте `asChild` только с одним интерактивным дочерним элементом, который сохраняет семантику
кнопки, работу фокуса и управление с клавиатуры. В этом режиме стандартный индикатор не добавляется.
В Solid `useSplitter()` возвращает accessor: передавайте его в `value`, а API читайте через
`splitter()`.

## Доступность

`ResizeTrigger` создаёт кнопку и поддерживает изменение размера указателем и клавиатурой в соответствии
с паттерном WAI-ARIA Window Splitter. Задайте каждой ручке доступное имя, например через
`aria-label="Resize panels"`, если на визуальной ручке нет текстовой подписи. При использовании
`asChild` пользовательский элемент должен сохранять семантику кнопки, работу фокуса и управление с
клавиатуры.

Ark сообщает о состоянии через атрибуты `data-orientation`, `data-dragging`, `data-focus` и
`data-disabled`. Используйте их для стилизации состояний взаимодействия.

## Стилизация

Используйте `className` в React или `class` в Solid на экспортируемых частях для структурных стилей.
Варианты Tailwind используют нативные utility-классы и классы потребителя, а вариант с CSS Modules
предоставляет переменные компонента ниже. Атрибуты состояния и точки привязки `data-slot` общие для
обоих вариантов стилизации.

Ручка изменения размера занимает в раскладке разделитель толщиной `1px`, поверх которого рисуется
линия толщиной `0.5px`. Прозрачная область нажатия упрощает взаимодействие, а скруглённый индикатор
располагается поверх линии. При наведении и перетаскивании усиливаются линия, граница и тень. Если
нужен другой вид, переопределите соответствующие переменные
`--moduix-splitter-resize-trigger-*`.

### Точки привязки для стилей

Ark записывает `data-scope="splitter"` и `data-part` в отрисованные части. moduix также добавляет
значения `data-slot`: `splitter-root`, `splitter-root-provider`, `splitter-panel`,
`splitter-resize-trigger` и `splitter-resize-trigger-indicator`.

Полезные атрибуты отдельных частей включают `data-id` и `data-index` у панелей, а также
`data-orientation`, `data-dragging`, `data-focus` и `data-disabled` у соответствующих элементов.
