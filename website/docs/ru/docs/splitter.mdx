## Базовый пример

Соберите Splitter из трёх частей: `Splitter`, `Splitter.Panel` и `Splitter.ResizeTrigger`. Свойство
`panels` содержит идентификаторы панелей и ограничения их размеров. У каждой отрисованной
`Splitter.Panel` должен быть идентификатор из этого массива. Если не передавать триггеру дочерние
элементы, moduix автоматически добавит индикатор изменения размера.

## Анатомия

```text
Splitter
├─ Splitter.Panel[id]
├─ Splitter.ResizeTrigger[id="panel-a:panel-b"]
│  └─ Splitter.ResizeTriggerIndicator (по умолчанию, настраивается)
└─ Splitter.Panel[id]
```

| Часть                            | Назначение                                                                  |
| -------------------------------- | --------------------------------------------------------------------------- |
| `Splitter` / `Splitter.Root`     | Управляет панелями, их размерами, ориентацией, колбэками и состоянием.     |
| `Splitter.Panel`                 | Область с изменяемым размером. Её `id` должен быть в массиве `panels`.      |
| `Splitter.ResizeTrigger`         | Доступная кнопка для изменения размера двух соседних панелей.              |
| `Splitter.ResizeTriggerIndicator` | Стандартная визуальная ручка. Дочерние элементы триггера заменяют её.      |
| `Splitter.RootProvider`          | Отображает те же части, используя состояние из `useSplitter()`.            |

## Композиция

### Рекомендуемый вариант

Размещайте панели и ручки изменения размера в том же порядке, в котором они видны на странице.
Задавайте каждой ручке идентификатор в формате `"left:right"`, чтобы Ark связал две соседние панели.
Чтобы использовать стандартный индикатор, не передавайте ручке дочерние элементы. Добавляйте их,
только если нужно изменить содержимое.

### Когда нужна расширенная настройка

Используйте управляемое значение `size` вместе с `onResize(details)`, если текущие размеры панелей
нужно хранить в состоянии приложения. Для императивных методов внутри дерева Splitter используйте
`useSplitterContext()`. Создавайте состояние через `useSplitter()` и передавайте его в
`Splitter.RootProvider`, если состояние или элементы управления должны находиться за пределами
отрисованного дерева частей. Для вложенных Splitter, которые должны изменять размер одновременно на
пересечениях ручек, создайте один реестр через `createSplitterRegistry()` и передайте его каждому корню.

Для каждого экземпляра выбирайте либо `Splitter`, либо `Splitter.RootProvider`. Не используйте оба
корня для одного состояния.

Используйте `asChild`, только когда отрисованный узел должен принадлежать другому элементу. В
пользовательской ручке должны сохраняться семантика кнопки, работа фокуса и управление с клавиатуры.
При `asChild` передавайте ровно один интерактивный дочерний элемент. Стандартный индикатор в этом
режиме не добавляется.

### Свойства по умолчанию

| Свойство           | По умолчанию | Примечания                                                                  |
| ------------------ | ------------ | --------------------------------------------------------------------------- |
| `orientation`      | `"horizontal"` | Используйте `"vertical"` для вертикального расположения панелей.        |
| `defaultSize`      | не задано    | Ark рассчитывает начальные размеры. Проценты удобны для серверного рендеринга. |
| `keyboardResizeBy` | не задано    | Используется стандартный для Ark шаг изменения размера в пикселях.        |
| `size`             | не задано    | Без него используется неуправляемый режим. Для управления добавьте `onResize(details)`. |
| `disabled`         | `false`      | Установите на `ResizeTrigger`, чтобы отключить одну ручку.                 |
| `registry`         | не задано    | Передайте общий реестр вложенным Splitter для одновременного перетаскивания нескольких ручек. |

### Поведение

Свойство `panels` обязательно. Для каждой панели можно задать ограничения `minSize`, `maxSize`,
`collapsible` и `collapsedSize`. Числовые значения `defaultSize` и управляемого `size` являются
процентами, и их сумма должна быть равна `100`. Ark также принимает CSS-длины для начальных размеров
и ограничений. Браузер измеряет такие значения сам, поэтому после гидратации раскладка может немного
измениться.

Колбэки получают исходные объекты details от Ark: `onResize(details)`, `onResizeEnd(details)`,
`onCollapse(details)` и `onExpand(details)`. `onResizeStart()` вызывается в начале изменения размера.

## Доступность

`ResizeTrigger` создаёт кнопку и поддерживает изменение размера указателем и клавиатурой в соответствии
с паттерном WAI-ARIA Window Splitter. Задайте каждой ручке доступное имя, например через
`aria-label="Resize panels"`, если на самой визуальной ручке нет текстовой подписи. При использовании
`asChild` пользовательский элемент должен сохранять семантику кнопки, работу фокуса и управление с
клавиатуры.

Ark сообщает о состоянии через атрибуты `data-orientation`, `data-dragging`, `data-focus` и
`data-disabled`. Используйте их для стилизации состояний взаимодействия.

## Стилизация

Стилизуйте `Splitter` с помощью `className`, атрибутов Ark, стабильных точек привязки
`data-slot="splitter-*"` и публичных CSS-переменных moduix ниже. `Splitter.Root` и
`Splitter.RootProvider` задают значения `--moduix-splitter-width` и `--moduix-splitter-height` во
встроенном стиле. Поэтому эти переменные могут переопределить размер корня, заданный Ark. Стандартный
фон применяется к корню, а панели остаются плоскими и вплотную прилегающими друг к другу.

Ручка изменения размера занимает в раскладке разделитель толщиной `1px`, поверх которого рисуется
линия толщиной `0.5px`. Прозрачная область нажатия упрощает взаимодействие, а скруглённый индикатор
располагается поверх линии. При наведении и перетаскивании усиливаются линия, граница и тень. Если
нужен другой вид, переопределите соответствующие переменные
`--moduix-splitter-resize-trigger-*`.

### Точки привязки для стилей

Ark записывает `data-scope="splitter"` и `data-part` в отрисованные части. moduix также добавляет
значения `data-slot`: `splitter-root`, `splitter-root-provider`, `splitter-panel`,
`splitter-resize-trigger` и `splitter-resize-trigger-indicator`.

Полезные атрибуты отдельных частей включают `data-id` и `data-index` у панелей, а также
`data-orientation`, `data-dragging`, `data-focus` и `data-disabled` у соответствующих элементов.
