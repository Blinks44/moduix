## Базовый пример


Соберите Splitter из `Splitter`, `SplitterPanel` и `SplitterResizeTrigger`. Свойство `panels`
содержит идентификаторы панелей и ограничения их размеров. У каждой отрисованной `SplitterPanel`
должен быть один из этих идентификаторов. Если не передавать триггеру дочерние элементы, moduix
добавит индикатор изменения размера автоматически.

## Анатомия

```text
Splitter
├─ SplitterPanel[id]
├─ SplitterResizeTrigger[id="panel-a:panel-b"]
│  └─ SplitterResizeTriggerIndicator (по умолчанию, настраивается)
└─ SplitterPanel[id]

SplitterRootProvider
└─ то же дерево панелей, подключённое к состоянию useSplitter()
```

| Часть                              | Назначение                                                                     |
| ---------------------------------- | ------------------------------------------------------------------------------ |
| `Splitter`                    | Управляет панелями, их размерами, ориентацией, колбэками и состоянием.          |
| `SplitterPanel`                   | Область с изменяемым размером. Её `id` должен совпадать с записью в `panels`.  |
| `SplitterResizeTrigger`           | Доступная кнопка для изменения размера двух соседних панелей.                  |
| `SplitterResizeTriggerIndicator`  | Стандартная визуальная ручка. Дочерние элементы триггера заменяют её.           |
| `SplitterRootProvider`            | Отображает те же части, используя состояние из `useSplitter()`.                |

## Композиция

Используйте `size` вместе с `onResize(details)`, если приложение владеет текущими размерами панелей.
Выбирайте `SplitterRootProvider` с `useSplitter()`, если состояние или элементы управления должны
находиться за пределами дерева панелей, и используйте только один корень для каждого состояния. Для
вложенных Splitter, которые должны изменять размер одновременно на пересечениях ручек, создайте один
`createSplitterRegistry()` и передайте его каждому корню. Числовые значения `defaultSize`, `size` и
`minSize` - это проценты, которые в сумме должны давать 100, а Ark также принимает для этих размеров
значения длин CSS.

Используйте `asChild` только с одним интерактивным дочерним элементом, который сохраняет семантику
кнопки, работу фокуса и управление с клавиатуры. В этом режиме стандартный индикатор не добавляется.
В Solid `useSplitter()` возвращает accessor: передавайте его в `value`, а API читайте через
`splitter()`.

В Vue используйте `v-model:size` для управляемого Ark состояния размеров. `useSplitter()` возвращает
реактивное состояние, которое можно напрямую передать в `SplitterRootProvider`; вызывайте его методы
в шаблоне и не создавайте второй контейнер состояния.

## Примеры

### Сворачиваемые панели

Задайте `collapsible: true` и `collapsedSize`, если панель должна превращаться в узкую боковую полосу.
Чтобы изменение размера указателем оставалось плавным до самого свёрнутого состояния, задайте для
`minSize` то же значение. Если `minSize` больше, Splitter переключается между минимальным
развёрнутым размером и свёрнутой полосой.

<Example name="splitter/collapsible-panels" />

### Управляемое состояние

Храните размеры панелей в состоянии приложения и обновляйте его значением `details.size` из
`onResize`.

<Example name="splitter/controlled" />

### Несколько панелей

Добавьте ещё одну `SplitterPanel` и соседний `SplitterResizeTrigger`, чтобы получить раскладку из трёх панелей. Для
каждой панели нужна запись в `panels`, а идентификатор каждой ручки должен связывать двух её соседей.

<Example name="splitter/multiple-panels" />

### Вложенные Splitter

Передайте один и тот же реестр вложенным Splitter, чтобы одновременно перетаскивать несколько ручек
на пересечениях горизонтальных и вертикальных разделителей.

<Example name="splitter/nested" />

### Адаптивное сворачивание

Используйте `collapsePanel()` и `expandPanel()`, если боковая панель должна реагировать на доступную
ширину, измеренную приложением.

<Example name="splitter/dynamic-collapsible" />

### SplitterRootProvider

Используйте `useSplitter()` с `SplitterRootProvider`, если состояние или элементы управления должны
находиться за пределами отрисованных частей Splitter. Возвращаемый API включает, например,
`getSizes()`, `setSizes()`, `resizePanel()`, `collapsePanel()`, `expandPanel()` и `resetSizes()`.

<Example name="splitter/root-provider" />

### Вертикальная ориентация

Задайте `orientation="vertical"` и укажите корню стабильную высоту, чтобы вертикальным панелям было
достаточно места для изменения размера.

<Example name="splitter/vertical" />

## Доступность

`SplitterResizeTrigger` создаёт кнопку с `type="button"`, поэтому она не отправляет окружающую форму, и поддерживает изменение размера указателем и клавиатурой в соответствии
с паттерном WAI-ARIA Window Splitter. Задайте каждой ручке доступное имя, например через
`aria-label="Resize panels"`, если на визуальной ручке нет текстовой подписи. При использовании
`asChild` пользовательский элемент должен сохранять семантику кнопки, работу фокуса и управление с
клавиатуры.

Ark сообщает о состоянии через атрибуты `data-orientation`, `data-dragging`, `data-focus` и
`data-disabled`. Используйте их для стилизации состояний взаимодействия.

## Стилизация

Используйте `className` в React или `class` в Solid и Vue на экспортируемых частях, чтобы изменить их
стили. Классом меняется и размер корня: moduix убирает inline `width` и `height` от Ark, а по умолчанию
корень занимает контейнер (`width: 100%` и `height: 100%`, как в Ark). Если у родителя нет высоты,
задайте её корню.

Ark ставит каждой панели inline `overflow: hidden`, чтобы содержимое не меняло размеры панелей.
Длинное содержимое оборачивайте в прокручиваемый контейнер внутри панели, например `ScrollArea`.

Ручка изменения размера занимает в раскладке разделитель толщиной `1px`, поверх которого рисуется
линия толщиной `0.5px`. Прозрачная область нажатия упрощает взаимодействие, а скруглённый индикатор
располагается поверх линии. При наведении и перетаскивании линия и граница индикатора темнеют, а тень
индикатора усиливается. Линия и область нажатия нарисованы псевдоэлементами, поэтому в вариантах
с CSS Modules для них есть переменные ниже.

### Точки привязки для стилей

Ark записывает `data-scope="splitter"` и `data-part` в отрисованные части. moduix также добавляет
значения `data-slot`: `splitter-root`, `splitter-root-provider`, `splitter-panel`,
`splitter-resize-trigger` и `splitter-resize-trigger-indicator`.

Полезные атрибуты отдельных частей включают `data-id` и `data-index` у панелей, а также
`data-orientation`, `data-dragging`, `data-focus` и `data-disabled` у соответствующих элементов.
