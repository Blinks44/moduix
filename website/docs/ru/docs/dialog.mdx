## Выбор подходящего компонента

Используйте `Dialog` для форм, подтверждений, просмотра подробной информации и других задач, которые должны выполняться
в контексте текущей страницы. Выбирайте `Drawer`, если панель должна оставаться у края окна или поддерживать
перетаскивание.

## Анатомия

```text
Dialog / Dialog.Root
├─ Dialog.Trigger
└─ Поддерево оверлея (автоматически помещается в портал)
   ├─ Dialog.Backdrop (необязательно)
   └─ Dialog.Positioner
      └─ Dialog.Content
         ├─ Dialog.CloseTrigger или Dialog.CloseIcon
         ├─ Dialog.Title
         ├─ Dialog.Description
         ├─ Dialog.Header (вспомогательная часть moduix для разметки)
         ├─ Dialog.Body (вспомогательная часть moduix для разметки)
         └─ Dialog.Footer (вспомогательная часть moduix для разметки)

Dialog.RootProvider
└─ то же дерево частей, подключённое к состоянию из useDialog() moduix

Dialog.Context
└─ функция рендера с текущим состоянием и методами диалога
```

| Часть                    | Назначение                                                            |
| ------------------------ | --------------------------------------------------------------------- |
| `Dialog` / `Dialog.Root` | Управляет состоянием открытия, фокусом и закрытием диалога.           |
| `Dialog.RootProvider`    | Подключает части к состоянию, созданному через `useDialog()`.         |
| `Dialog.Trigger`         | Открывает диалог.                                                     |
| `Dialog.Backdrop`        | Необязательный фоновый слой модального диалога.                       |
| `Dialog.Positioner`      | Размещает содержимое диалога.                                         |
| `Dialog.Content`         | Содержит видимую поверхность диалога.                                |
| `Dialog.Title`           | Задаёт доступное имя диалога в виде заголовка.                        |
| `Dialog.Description`     | Добавляет вспомогательный доступный текст.                            |
| `Dialog.CloseTrigger`    | Закрывает диалог.                                                      |
| `Dialog.CloseIcon`       | Вспомогательная кнопка moduix, которая закрывает диалог.              |
| `Dialog.Header`          | Вспомогательная часть moduix для разметки заголовка.                  |
| `Dialog.Body`            | Вспомогательная часть moduix для основного содержимого.              |
| `Dialog.Footer`          | Вспомогательная часть moduix для действий.                            |
| `Dialog.Context`         | Рендерит дочерние элементы с текущим состоянием и методами диалога.   |

Импортируйте `useDialog()`, если состояние должно находиться вне дерева, в котором отрисован диалог. Читайте или
изменяйте его через `Dialog.Context` или `useDialogContext()` из `@moduix/react`.

## Композиция

Корневой компонент автоматически помещает `Dialog.Backdrop` и `Dialog.Positioner` в портал. Задайте `portalled={false}`
для рендера в текущем дереве или передайте `portalRef`, чтобы использовать свой контейнер. Оставляйте структурные
части явными, чтобы настраивать и стилизовать их независимо.

### Рекомендуемая композиция

Явно отрендерите `Dialog.Backdrop`, `Dialog.Positioner` и `Dialog.Content`. Добавляйте фон для модального диалога и
не добавляйте его, если диалог должен быть немодальным.

Используйте `Dialog.Trigger asChild` и `Dialog.CloseTrigger asChild` с одним семантическим дочерним элементом. Он должен
получать фокус и сохранять поведение кнопки. `Dialog.CloseIcon` - вспомогательная часть moduix, которая объединяет
триггер закрытия Ark с кнопкой закрытия библиотеки.

### Когда нужна собственная композиция

Используйте `open` и `onOpenChange(details)`, если состоянием открытия должен управлять React. Колбэк получает объект
`details` от Ark, поэтому следующее состояние нужно читать из `details.open`.

Используйте `useDialog()` вместе с `Dialog.RootProvider`, если состояние или методы должны быть доступны за пределами
дерева диалога. Не создавайте второй `Dialog` для того же хранилища. Если переиспользуемому дочернему компоненту нужно
читать это состояние, используйте `Dialog.Context` или `useDialogContext()`.

Используйте `ids`, если отдельно собранным частям нужны стабильные общие идентификаторы доступности. С помощью
`initialFocusEl` и `finalFocusEl` можно явно задать элементы, которым передаётся фокус. Укажите `role="alertdialog"`
для опасных или других критически важных решений.

Не размонтируйте корневой компонент при изменении состояния открытия. Используйте `lazyMount` и `unmountOnExit`, чтобы
управлять появлением и удалением содержимого из DOM. Задавайте `present`, только если JavaScript-анимация закрытия сама
должна управлять тем, остаётся ли содержимое в DOM.

### Свойства по умолчанию

Первые два значения задаёт moduix, остальные компонент наследует из Ark UI.

| Свойство                 | По умолчанию | Примечания                                                       |
| ------------------------ | ------------ | ---------------------------------------------------------------- |
| `lazyMount`              | `true`       | Монтирует содержимое в портале только после первого открытия.    |
| `unmountOnExit`          | `true`       | Удаляет содержимое после анимации закрытия.                      |
| `modal`                  | `true`       | Запрещает взаимодействие с содержимым за пределами диалога.     |
| `preventScroll`          | `true`       | Запрещает прокрутку страницы, пока диалог открыт.               |
| `trapFocus`              | `true`       | Удерживает фокус внутри модального диалога.                     |
| `closeOnEscape`          | `true`       | Закрывает диалог при нажатии `Escape`.                           |
| `closeOnInteractOutside` | `true`       | Закрывает диалог после взаимодействия за его пределами.         |
| `role`                   | `"dialog"`   | По умолчанию использует обычную семантику диалога.              |

### Особенности поведения

- Модальный диалог удерживает фокус внутри окна, блокирует прокрутку страницы, скрывает содержимое за диалогом от
  вспомогательных технологий и возвращает фокус после закрытия.
- Укажите `modal={false}`, чтобы отключить удержание фокуса и блокировку прокрутки. В этом режиме не добавляйте
  `Dialog.Backdrop`, чтобы страница оставалась доступной для взаимодействия.
- `closeOnEscape`, `closeOnInteractOutside`, `trapFocus`, `preventScroll`, `restoreFocus`, `persistentElements` и
  колбэки внешнего взаимодействия без изменений передаются в Ark UI.
- Отрендерите `Dialog.Title` или задайте `aria-label` на корневом компоненте, чтобы у диалога было доступное имя.
  Используйте `Dialog.Description`, если пользователю нужно дополнительное объяснение задачи.
- Если пользователь включил настройку уменьшения анимации, moduix сокращает анимации открытия и закрытия, а Ark UI
  завершает обычный жизненный цикл присутствия компонента.
- Если в диалоге несколько элементов закрытия, задайте каждому `Dialog.CloseTrigger` явный уникальный `id`. Для одного
  `Dialog.CloseIcon` идентификатор не нужен.
- При вложении диалогов родительский `Content` получает `data-has-nested` и `--nested-layer-count`. Moduix использует
  их, чтобы уменьшить и немного сместить родительский диалог, пока вложенный диалог открыт.
- Не размонтируйте корневой компонент условно, чтобы закрыть диалог. Оставьте его в дереве и управляйте `open`, а для
  удаления содержимого из DOM используйте `lazyMount` и `unmountOnExit`.

### Хуки стилизации

- Значения `data-slot` moduix: `dialog-trigger`, `dialog-backdrop`, `dialog-positioner`, `dialog-content`, `dialog-title`,
  `dialog-description`, `dialog-close-trigger`, `dialog-close-icon`, `dialog-header`, `dialog-body` и `dialog-footer`.
- Атрибуты Ark: `data-scope="dialog"` и `data-part="trigger|backdrop|positioner|content|title|description|close-trigger"`.
- Атрибуты состояния: `data-state="open|closed"`, `data-has-nested`, `data-nested`, `data-current` и `data-value`.
- Переменные времени выполнения: `--layer-index` и `--nested-layer-count`.
- `Dialog.CloseIcon` позиционируется относительно угла `Dialog.Content`, поэтому его расположение не зависит от
  `Dialog.Header`.
