# Быстрый старт

Оба способа используют одни и те же нативные компоненты, контракты Ark UI и токены. Выбирайте по тому, где должен жить исходный код и как вы будете его обновлять.

:::info Перед началом
Нужно готовое приложение на React 18 или 19, Solid 1.9+ или Vue 3.5+. Для пакетов и реестров Tailwind уже должен быть настроен Tailwind CSS v4.
:::

## Установить через shadcn CLI

Исходный код компонентов, стили и утилиты копируются в ваш репозиторий. У каждого фреймворка и варианта стилизации свой namespace реестра.

<Steps>

### Настройте shadcn

Создайте `components.json` в корне проекта для вашего варианта стилизации.

<Tabs groupId="styling">
  <Tab label="CSS Modules" value="css-modules">

<CodeBlockRuntime lang="json" title="components.json" code={componentsCssModules} />

  </Tab>
  <Tab label="Tailwind CSS" value="tailwind">

<CodeBlockRuntime lang="json" title="components.json" code={componentsTailwind} />

  </Tab>
</Tabs>

Сопоставьте алиас `@/*` с папкой исходников в TypeScript и сборщике: CLI пишет файлы в `@/components/ui` и `@/lib/moduix`. Ставьте `rsc: true` только в приложении с React Server Components.

### Добавьте компонент

Используйте namespace, который соответствует вашему фреймворку и варианту стилизации, и не смешивайте namespace в одном дереве компонентов.

## Настройте слои порталов

Эта настройка нужна при обоих способах установки. `Dialog`, `Popover`, `Menu`, `Select` и другие компоненты
выводят содержимое оверлеев через порталы. Изолируйте корневой элемент приложения, чтобы подложки и всплывающие
элементы всегда были поверх страницы и не конфликтовали с локальными значениями `z-index`.

```html title="index.html"
<body>
  <div id="app-root"></div>
</body>
```

```css title="styles.css"
#app-root {
  isolation: isolate;
}
```

Если приложение поддерживает Safari на iOS 26, проверьте прокручиваемое модальное окно при видимой панели браузера.
Если контент виден под подложкой, задайте `body` значение `position: relative`, чтобы абсолютно позиционированная
подложка могла закрыть всю видимую область.

```css title="styles.css"
body {
  position: relative;
}
```

## Устранение неполадок

| Проблема | Что проверить |
| --- | --- |
| Компоненты отображаются без стилей | Убедитесь, что базовый файл стилей импортируется в точке входа приложения и загружается до стилей компонентов; см. [Стилизация](/docs/styling). |
| Скрытое содержимое компонентов остаётся видимым | С CSS Modules проверьте, что загружен reset moduix или собственный reset приложения. Для варианта с Tailwind не отключайте Preflight. |
| Сборщик не находит импорт созданного компонента | Проверьте алиас `@/*` в TypeScript и сборщике, затем `components.json`. |
| Всплывающий элемент отображается под содержимым страницы | Добавьте `isolation: isolate` корневому элементу приложения и избегайте несвязанных глобальных значений `z-index`. |
| При серверном рендеринге появляются ошибки о клиентских API | В нужных фреймворках размещайте интерактивные компоненты в клиентском компоненте. |
