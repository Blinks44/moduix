## Параметры форматирования

По умолчанию используется 24-часовой формат. Укажите `format="12h"`, чтобы использовать 12-часовой формат,
`withSeconds`, чтобы добавить секунды, а `amLabel` и `pmLabel`, чтобы заменить обозначения части суток в 12-часовом
выводе.

Добавляйте секунды только тогда, когда они помогают человеку действовать. Не выводите их в расписании только потому,
что они есть в исходных данных.

## Локаль и значения Date

`Format.Time` получает локаль из ближайшего `LocaleProvider`. Если провайдер не задан, Ark UI использует `en-US`.
Используйте `Date`, когда значение обозначает конкретный момент, например временную метку из API. Отображаемое время
для `Date` определяется часовым поясом среды выполнения. `LocaleProvider` меняет локаль, но не часовой пояс.

Оставляйте время по расписанию строкой. Передавайте `Date` только тогда, когда преобразование часового пояса задумано.
