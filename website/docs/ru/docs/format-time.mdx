## Когда использовать

Используйте `Format.Time`, когда нужно показать время в формате текущей локали: в расписании, ленте событий, часах
работы службы поддержки и других элементах интерфейса. Компонент принимает объект `Date` или строку времени формата `HH:mm`
либо `HH:mm:ss`.

Для времени по расписанию используйте строку: она не будет меняться при смене часового пояса. Передавайте `Date`, если
значение обозначает конкретный момент.

Импортируйте `Format` напрямую из Ark UI:

```tsx
import { Format } from '@ark-ui/react';
```

## 12-часовой формат, секунды и обозначения AM/PM

По умолчанию `Format.Time` использует 24-часовой формат. Укажите `format="12h"`, чтобы переключиться на 12-часовой
формат. Добавляйте `withSeconds`, когда секунды действительно важны, например в индикаторе последней синхронизации.
В 12-часовом формате `amLabel` и `pmLabel` заменяют стандартные обозначения части суток.

Не добавляйте секунды в расписание только потому, что они есть в исходных данных. Выбирайте точность, которая помогает
человеку сориентироваться.

## Локаль и значения Date

`Format.Time` получает локаль из `LocaleProvider`. moduix переэкспортирует этот провайдер, поэтому его можно
использовать как единый провайдер локали для всего интерфейса:

```tsx
import { Format } from '@ark-ui/react';
import { LocaleProvider } from '@moduix/react/locale';

export function LocalizedTime() {
  return (
    <LocaleProvider locale="fr-FR">
      <Format.Time value="17:15" />
    </LocaleProvider>
  );
}
```

Используйте `Date`, если у вас уже есть точное значение даты и времени, например временная метка из API:

```tsx
import { Format } from '@ark-ui/react';

export function UpdatedAt({ value }: { value: Date }) {
  return <Format.Time value={value} />;
}
```

Для `Date` компонент отображает время в часовом поясе среды выполнения. `LocaleProvider` задаёт локаль,
но не часовой пояс. Поэтому не заменяйте время из расписания на `Date`, если такое преобразование не нужно.

## Использование с moduix

`Format.Time` выводит только текст. Используйте `Card`, `Stack`, `Text` и компоненты статуса moduix, чтобы пояснить,
что означает время. Не создавайте отдельный компонент только для вызова форматтера.

## Границы ответственности

Ark UI отвечает за форматирование времени и API `Format.Time`. moduix предоставляет окружающие компоненты интерфейса и
переэкспортирует `LocaleProvider`, но не переэкспортирует `Format.Time`.
