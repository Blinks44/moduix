## Когда использовать

Используйте `Format.Time`, чтобы показать время в привычном для текущей локали виде: в расписаниях, лентах активности,
часах работы поддержки и других элементах интерфейса. Он принимает `Date` или строку времени формата `HH:mm` либо
`HH:mm:ss`.

Импортируйте `Format` напрямую из Ark UI:

```tsx
import { Format } from '@ark-ui/react';
```

## Секунды и обозначения AM/PM

Добавляйте `withSeconds`, когда секунды действительно важны, например в индикаторе последней синхронизации.
`amLabel` и `pmLabel` позволяют заменить обозначения AM/PM в 12-часовых локалях.

Не добавляйте секунды в расписание только потому, что они есть в исходных данных. Выбирайте точность, которая помогает
человеку сориентироваться.

## Локаль и значения Date

`Format.Time` получает локаль из `LocaleProvider`. moduix переэкспортирует этот провайдер, поэтому его можно
использовать как единый провайдер локали для всего интерфейса:

```tsx
import { Format } from '@ark-ui/react';
import { LocaleProvider } from '@moduix/react/locale';

export function LocalizedTime() {
  return (
    <LocaleProvider locale="fr-FR">
      <Format.Time value="17:15" />
    </LocaleProvider>
  );
}
```

Используйте `Date`, если у вас уже есть точное значение даты и времени. Отображаемое время зависит от локали и
часового пояса пользователя, поэтому не заменяйте время из расписания на `Date`, если такое преобразование не нужно.

## Использование с moduix

`Format.Time` выводит только текст. Используйте `Card`, `Stack`, `Text` и компоненты статуса moduix, чтобы пояснить,
что означает время. Не создавайте отдельный компонент только для вызова форматтера.

## Границы ответственности

Ark UI отвечает за форматирование времени и API `Format.Time`. moduix предоставляет окружающие компоненты интерфейса
и переэкспортирует `LocaleProvider`, но не переэкспортирует `Format.Time`.
