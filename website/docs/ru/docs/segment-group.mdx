## Как выбрать подходящий компонент

Используйте `SegmentGroup`, когда пользователь выбирает одно значение из небольшого набора,
который целиком виден на экране.

- Выбирайте **`Tabs`**, когда выбор должен менять видимую панель с содержимым.
- Выбирайте **`ToggleGroup`**, когда элементы работают как кнопки панели инструментов и одновременно могут быть активны несколько значений.
- Выбирайте **`RadioGroup`**, когда элемент управления должен выглядеть как обычная группа радиокнопок.
- Выбирайте **`SegmentGroup`**, когда по поведению компонент похож на радиогруппу, но интерфейсу нужен компактный сегментированный вид.

## Анатомия

```text
SegmentGroup / SegmentGroup.Root
├─ SegmentGroup.Label (необязательно)
├─ SegmentGroup.Indicator
└─ SegmentGroup.Item[value]
   ├─ SegmentGroup.ItemText
   ├─ SegmentGroup.ItemControl
   └─ нативное поле формы

SegmentGroup.RootProvider
└─ то же дерево элементов, подключённое к хранилищу moduix useSegmentGroup()

SegmentGroup.Context / SegmentGroup.ItemContext
└─ расширенный доступ к состоянию Ark через render prop
```

| Часть                                 | Назначение                                                               |
| ------------------------------------ | ------------------------------------------------------------------------ |
| `SegmentGroup` / `SegmentGroup.Root` | Управляет выбранным значением, навигацией с клавиатуры и формами.        |
| `SegmentGroup.RootProvider`          | Подключает части к состоянию, созданному хуком `useSegmentGroup()` из moduix. |
| `SegmentGroup.Context`               | Даёт расширенный доступ к состоянию корневого элемента через render prop. |
| `SegmentGroup.ItemContext`           | Даёт расширенный доступ к состоянию текущего элемента через render prop. |
| `SegmentGroup.Label`                 | Необязательная доступная подпись группы.                                 |
| `SegmentGroup.Indicator`             | Размещает выделение активного элемента с помощью CSS-переменных Ark.     |
| `SegmentGroup.Items`                 | Рекомендуемый способ отрисовать стандартные текстовые сегменты.         |
| `SegmentGroup.Item`                  | Один выбираемый сегмент; по умолчанию создаёт элемент `label`.           |
| `SegmentGroup.ItemText`              | Видимая подпись сегмента.                                                  |
| `SegmentGroup.ItemControl`           | Часть Ark для состояния элемента; по умолчанию скрыта стилями moduix.    |

## Композиция

### Рекомендуемый вариант

В обычном случае используйте короткую форму `<SegmentGroup>` вместе с `SegmentGroup.Items`.
Разместите `SegmentGroup.Indicator` перед элементами, чтобы измеренное выделение находилось под
выбранным сегментом. `Items` сохраняет нативное поле формы в каждом созданном элементе, поэтому
работают отправка формы и её сброс.

### Когда нужна собственная композиция

Используйте `SegmentGroup.Item`, если сегменту нужны произвольное содержимое, отдельный класс или
`asChild`. Прямой дочерний элемент `asChild` всё равно должен быть одним семантическим `label`.
Используйте `SegmentGroup.RootProvider` вместе с `useSegmentGroup()` из `@moduix/react`, если
элементам управления за пределами дерева сегментов нужен доступ к методам `setValue`, `clearValue`
или `focus`. Для собственной разметки, зависящей от состояния, используйте
`SegmentGroup.Context`, `SegmentGroup.ItemContext`, `useSegmentGroupContext` или
`useSegmentGroupItemContext` из `@moduix/react`.

`ItemHiddenInput` является внутренней частью moduix. Каждый `SegmentGroup.Item` уже создаёт ровно
одно синхронизированное нативное поле радиокнопки, в том числе при использовании `asChild`. Не добавляйте
`ItemHiddenInput` Ark повторно.

### Свойства по умолчанию

| Свойство       | По умолчанию | Примечания                                                          |
| -------------- | ------------ | ------------------------------------------------------------------- |
| `defaultValue` | не задано    | Начальное значение неконтролируемой группы.                         |
| `value`        | не задано    | Выбранное значение управляемой группы.                              |
| `orientation`  | `horizontal` | Значение moduix по умолчанию; для вертикальной группы укажите `vertical`. |
| `disabled`     | `false`      | Отключает всю группу, если задано на корневом элементе.             |
| `readOnly`     | `false`      | Запрещает изменения, но оставляет текущее значение видимым.         |
| `required`     | `false`      | Делает нативные поля обязательными при проверке формы.              |
| `invalid`      | `false`      | Добавляет атрибуты недопустимого состояния Ark для стилей и ARIA.   |

### Поведение

`onValueChange(details)` сохраняет формат обратного вызова Ark. Выбранное значение находится в
`details.value`. Ark управляет выбранным значением, перемещением фокуса, навигацией стрелками,
состояниями `disabled`, `readOnly`, `invalid` и `required`, а также отправкой формы и синхронизацией
при её сбросе.

Клавиша <kbd>Tab</kbd> переводит фокус на выбранный элемент, а если выбор ещё не сделан, на
первый элемент. Стрелки перемещают фокус и выбирают следующий или предыдущий элемент, а
<kbd>Space</kbd> выбирает элемент в фокусе. Укажите `name` на корневом элементе, чтобы выбранное
значение попало в нативный `FormData`.

`Root`, `RootProvider`, `Label`, `Item`, `ItemControl`, `ItemText` и `Indicator` передают ref на
соответствующие DOM-части Ark. Используйте `Field` или `Fieldset`, если их общее состояние должно
распространяться на группу: `Field` передаёт состояния `disabled`, `invalid`, `required` и
`readOnly`, а `Fieldset` передаёт `disabled` и `invalid`. Используйте `ids`, если составным
подписям или элементам управления нужны предсказуемые идентификаторы доступности.

## Стилизация

Стилизуйте `SegmentGroup` с помощью `className`, стабильных хуков `data-slot="segment-group-*"`,
атрибутов Ark `data-scope`, `data-part` и атрибутов состояния, а также публичных CSS-переменных
`--moduix-segment-group-*`, перечисленных ниже.

### CSS-свойства

### Хуки стилизации

- Хуки анатомии Ark: `data-scope="segment-group"` и `data-part` на корневом элементе, подписи,
  индикаторе, элементе, тексте элемента, контроле элемента и скрытом поле ввода.
- Хуки состояний Ark: `data-state="checked" | "unchecked"`, `data-orientation`,
  `data-disabled`, `data-readonly`, `data-invalid`, `data-required`, `data-active` и
  `data-focus-visible`.
- Хуки moduix: `data-slot="segment-group-root"`, `segment-group-root-provider`,
  `segment-group-label`, `segment-group-indicator`, `segment-group-item`,
  `segment-group-item-text`, `segment-group-item-control` и `segment-group-item-hidden-input`.
- Индикатор использует переменные времени выполнения Ark `--left`, `--top`, `--width` и `--height`
  для размера. Его анимация использует `--transition-duration` и `--transition-timing-function`,
  а значения moduix по умолчанию задаются через `--moduix-segment-group-indicator-transition-duration`
  и `--moduix-segment-group-indicator-transition-timing-function`.
