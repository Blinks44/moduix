Интерактивные

Используйте `SegmentGroup` как корневой компонент, разместите `SegmentGroupIndicator` перед
элементами и выберите `SegmentGroupItems`, если каждому сегменту нужна только текстовая подпись.
`SegmentGroupItems` создаёт для каждого элемента части item и text, а также одно нативное поле формы. Передайте строки, если значение и подпись
совпадают, или объекты `{ value, label, disabled }`.

## Как выбрать подходящий компонент

Используйте `SegmentGroup`, когда пользователь выбирает одно значение из небольшого набора,
который целиком виден на экране.

- Выбирайте **`Tabs`**, когда выбор должен менять видимую панель с содержимым.
- Выбирайте **`ToggleGroup`**, когда элементы работают как кнопки панели инструментов и одновременно могут быть активны несколько значений.
- Выбирайте **`RadioGroup`**, когда элемент управления должен выглядеть как обычная группа радиокнопок.
- Выбирайте **`SegmentGroup`**, когда по поведению компонент похож на радиогруппу, но интерфейсу нужен компактный сегментированный вид.

## Примеры

### Размеры

Задайте `size` на `SegmentGroup` или `SegmentGroupRootProvider`: `sm`, `md` (по умолчанию) или `lg`.
Тогда вся группа получает высоту `Button` или `Input` того же размера.

<Example name="segment-group/sizes" />

### Вертикальная ориентация

Укажите `orientation="vertical"`, если группе нужны вертикальная раскладка и навигация стрелками
вверх и вниз.

<Example name="segment-group/vertical-orientation" />

### Пользовательская разметка элемента

Используйте `SegmentGroupItem asChild` вместо `SegmentGroupItems`, если собственная разметка
подписи должна владеть DOM-узлом элемента.

<Example name="segment-group/custom-item-layout" />

### Отключённый элемент и группа

Задайте `disabled` на отдельном элементе, если недоступным должен быть только этот сегмент. Чтобы
отключить всю группу, задайте `disabled` на корневом элементе. Стиль отключённой группы уменьшает
её непрозрачность один раз, не складывая её с прозрачностью отдельных элементов.

<Example name="segment-group/disabled" />

### Недопустимое состояние

Задайте `invalid` на корневом элементе, если проверка завершилась ошибкой. Сочетайте его с
`required` и `name`, когда группа участвует в нативной проверке формы.

<Example name="segment-group/invalid" />

### Field

Оберните группу в `Field`, если нативные поля должны сопровождаться поясняющим
текстом или сообщением об ошибке. `Field` не передаёт группе своё состояние, поэтому задайте
`invalid`, `required`, `disabled` или `readOnly` и на `SegmentGroup`.

<Example name="segment-group/field" />

### Отправка формы

Передайте `name` в корневой элемент, чтобы выбранное значение попало в данные нативной формы.
`SegmentGroupItems` добавляет нативное поле формы в каждый созданный элемент.

<Example name="segment-group/form-submission" />

### Управляемое состояние

Храните выбранное значение в состоянии React и обновляйте его из `details.value` в обработчике
`onValueChange`. Подробнее в разделе [Управляйте состоянием из приложения](/docs/composition-patterns#controlled-state).

<Example name="segment-group/controlled" />

### Условное монтирование

Группу сегментов можно монтировать условно. Когда она появляется, Ark заново рассчитывает
геометрию элементов, необходимую индикатору.

<Example name="segment-group/conditional-mount" />

### Root Provider

Используйте `useSegmentGroup()` вместе с `SegmentGroupRootProvider`, если элементам управления за пределами
дерева сегментов нужен доступ к тому же состоянию. Подробнее в разделе [Выносите состояние за пределы дерева](/docs/composition-patterns#root-provider).

<Example name="segment-group/root-provider" />

## Композиция

Для обычной композиции используйте `SegmentGroup` с `SegmentGroupIndicator` перед
`SegmentGroupItems`. `SegmentGroupItems` добавляет к каждому элементу `SegmentGroupItemText`
и ровно одно `SegmentGroupItemHiddenInput`. Если вы собираете
`SegmentGroupItem` напрямую, добавьте эти части самостоятельно и оставьте внутри каждого элемента
ровно одно `SegmentGroupItemHiddenInput`. Прямой дочерний элемент
`asChild` должен оставаться одним семантическим `label`.

Используйте `SegmentGroupRootProvider` вместе с `useSegmentGroup()`, если состояние нужно создать
вне дерева компонента или передать управление другой части приложения. React и Vue читают хранилище как
объект, а Solid получает реактивное состояние через возвращаемую функцию доступа.

## Стилизация

В React используйте `className`, а в Solid/Vue `class` на экспортируемых частях для структурных
стилей. Для стилей состояний используйте атрибуты Ark, например `data-state`, `data-disabled` и
`data-orientation`, вместе с селекторами moduix `data-slot`. Варианты Tailwind используют нативные
utility-классы и классы потребителя, а переменные ниже настраивают варианты CSS Modules. Атрибуты
состояния и хуки data-slot общие для обоих способов стилизации.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `SegmentGroup` | `segment-group-root` |
| `SegmentGroupRootProvider` | `segment-group-root-provider` |
| `SegmentGroupLabel` | `segment-group-label` |
| `SegmentGroupItem` | `segment-group-item` |
| `SegmentGroupItemText` | `segment-group-item-text` |
| `SegmentGroupIndicator` | `segment-group-indicator` |

- Селекторы частей Ark: `data-scope="segment-group"` и `data-part` на корневом элементе, подписи,
  индикаторе, элементе, тексте элемента и скрытом поле.
- Селекторы состояний Ark: `data-state="checked|unchecked"`, `data-orientation`, `data-disabled`,
  `data-readonly`, `data-invalid`, `data-required` и `data-focus-visible`.
- Индикатор использует переменные Ark `--left`, `--top`, `--width` и `--height` для определения
  размера. Для анимации используются переменные Ark `--transition-duration` и
  `--transition-timing-function`, по умолчанию `--moduix-duration-normal` и `--moduix-ease-in-out`. Задайте их классом на `SegmentGroupIndicator` (в Tailwind `[--transition-duration:300ms]`);
  утилиты `duration-*` проигрывают инлайн-переходу, который пишет Ark.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `ArrowDown` / `ArrowUp` / `ArrowLeft` / `ArrowRight` | Переходит к следующей или предыдущей опции и выбирает её. |
| `Tab` | Переводит фокус в группу и из неё. |
