## Как выбрать подходящий компонент

Используйте `SegmentGroup`, когда пользователь выбирает одно значение из небольшого набора,
который целиком виден на экране.

- Выбирайте **`Tabs`**, когда выбор должен менять видимую панель с содержимым.
- Выбирайте **`ToggleGroup`**, когда элементы работают как кнопки панели инструментов и одновременно могут быть активны несколько значений.
- Выбирайте **`RadioGroup`**, когда элемент управления должен выглядеть как обычная группа радиокнопок.
- Выбирайте **`SegmentGroup`**, когда по поведению компонент похож на радиогруппу, но интерфейсу нужен компактный сегментированный вид.

## Базовый пример

`SegmentGroup` доступен для React и Solid в пакетах с CSS Modules и Tailwind. Интерактивные
превью на этой странице используют React и CSS Modules, а вкладки с кодом показывают нативный

Используйте `SegmentGroup` как корневой компонент, разместите `SegmentGroup.Indicator` перед
элементами и выберите `SegmentGroup.Items`, если каждому сегменту нужна только текстовая подпись.
`Items` создаёт для каждого элемента части item, text и control, а также одно синхронизированное

## Анатомия

```text
SegmentGroup / SegmentGroup.Root
├─ SegmentGroup.Label (необязательно)
├─ SegmentGroup.Indicator
└─ SegmentGroup.Item[value]
   ├─ SegmentGroup.ItemText
   ├─ SegmentGroup.ItemControl
   └─ нативное поле формы

SegmentGroup.RootProvider
└─ то же дерево элементов, подключённое к хранилищу moduix useSegmentGroup()

SegmentGroup.Context / SegmentGroup.ItemContext
└─ расширенный доступ к состоянию Ark через render prop
```

| Часть                                 | Назначение                                                               |
| ------------------------------------ | ------------------------------------------------------------------------ |
| `SegmentGroup` / `SegmentGroup.Root` | Управляет выбранным значением, навигацией с клавиатуры и формами.        |
| `SegmentGroup.ItemHiddenInput` | Нативное поле Ark; правила явной композиции описаны ниже. |
| `SegmentGroup.RootProvider`          | Подключает части к состоянию, созданному хуком `useSegmentGroup()` из moduix. |
| `SegmentGroup.Context`               | Даёт расширенный доступ к состоянию корневого элемента через render prop. |
| `SegmentGroup.ItemContext`           | Даёт расширенный доступ к состоянию текущего элемента через render prop. |
| `SegmentGroup.Label`                 | Необязательная доступная подпись группы.                                 |
| `SegmentGroup.Indicator`             | Размещает выделение активного элемента с помощью CSS-переменных Ark.     |
| `SegmentGroup.Items`                 | Рекомендуемый способ отрисовать стандартные текстовые сегменты.         |
| `SegmentGroup.Item`                  | Один выбираемый сегмент; по умолчанию создаёт элемент `label`.           |
| `SegmentGroup.ItemText`              | Видимая подпись сегмента.                                                  |
| `SegmentGroup.ItemControl`           | Часть Ark для состояния элемента; по умолчанию скрыта стилями moduix.    |

## Композиция

Для обычной композиции используйте `SegmentGroup` с `SegmentGroup.Indicator` перед
`SegmentGroup.Items`. `Items` добавляет к каждому элементу `ItemText`, `ItemControl` и ровно одно
`ItemHiddenInput`. Если вы собираете `SegmentGroup.Item` напрямую, добавьте эти части самостоятельно
и оставьте внутри каждого элемента ровно одно `ItemHiddenInput`. Прямой дочерний элемент
`asChild` должен оставаться одним семантическим `label`.

Используйте `SegmentGroup.RootProvider` вместе с `useSegmentGroup()`, если состояние нужно создать
вне дерева компонента или передать управление другой части приложения. React читает хранилище как
объект, а Solid получает реактивное состояние через возвращаемую функцию доступа.

## Стилизация

В React используйте `className`, а в Solid `class` на экспортируемых частях для структурных
стилей. Для стилей состояний используйте атрибуты Ark, например `data-state`, `data-disabled` и
`data-orientation`, вместе с селекторами moduix `data-slot`. Варианты Tailwind используют нативные
utility-классы и классы потребителя, а переменные ниже настраивают варианты CSS Modules. Атрибуты
состояния и хуки data-slot общие для обоих способов стилизации.

### Хуки стилизации

- Стабильные селекторы `data-slot`: `segment-group-root`, `segment-group-root-provider`,
  `segment-group-label`, `segment-group-indicator`, `segment-group-item`,
  `segment-group-item-text` и `segment-group-item-control`.
- Селекторы частей Ark: `data-scope="segment-group"` и `data-part` на корневом элементе, подписи,
  индикаторе, элементе, тексте элемента, его control и скрытом поле.
- Селекторы состояний Ark: `data-state="checked|unchecked"`, `data-orientation`, `data-disabled`,
  `data-readonly`, `data-invalid`, `data-required` и `data-focus-visible`.
- Индикатор использует переменные Ark `--left`, `--top`, `--width` и `--height` для определения
  размера. Для анимации используются `--transition-duration` и `--transition-timing-function`;
  значения moduix по умолчанию задаются через `--moduix-segment-group-indicator-transition-duration`
  и `--moduix-segment-group-indicator-transition-timing-function`.
