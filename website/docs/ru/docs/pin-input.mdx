## Выбор подходящего компонента

Используйте `PinInput`, если короткий код фиксированной длины нужно вводить по одному символу в отдельных ячейках.

- Выбирайте **`PinInput`** для одноразовых кодов, PIN-кодов, резервных кодов и кодов приглашений.
- Выбирайте **`Input`**, когда достаточно одного обычного текстового поля.
- Выбирайте **`PasswordInput`**, когда значение представляет собой одну секретную строку с переключателем видимости.

Проп `size` на корне подгоняет размер ячеек под высоту контролов `Input` и `Button`. По умолчанию `md`;
текст в ячейках масштабируется вместе с ним.

Включите `otp`, чтобы добавить видимым полям `autocomplete="one-time-code"` и включить подсказки одноразовых
кодов в поддерживаемых мобильных браузерах.

### Маскирование

Включите `mask`, если введённый код нельзя показывать открыто.

<Example name="pin-input/masking" />

### Символ-заполнитель

Передайте `placeholder`, чтобы показывать символ в каждой пустой ячейке. По умолчанию moduix оставляет заполнитель
пустым.

### Сгруппированная раскладка

Используйте явные части `PinInputInput` с `PinInputSeparator`, если разделитель должен разделить код на группы. Индексы должны
идти непрерывно во всей композиции.

### Снять фокус после завершения ввода

Укажите `blurOnComplete`, если после заполнения всех ячеек фокус должен покинуть последнее поле.

Поместите `PinInput` внутрь `Field`, если подпись, вспомогательный текст, сообщение об ошибке и состояние поля
должны быть связаны с видимыми ячейками механизмами доступности Ark для форм.

Храните массив значений в состоянии и читайте `details.value` или `details.valueAsString` из колбэков Ark.

## Композиция

Явно добавьте `PinInputHiddenInput` внутрь `PinInput` или `PinInputRootProvider`, если значение должно
отправляться с нативной формой и сбрасываться вместе с ней. Задайте корню `name`, а `form` используйте, если
форма находится вне дерева компонента.

`PinInputInputs` создаёт по одной индексированной ячейке для каждого элемента контекста Ark. Используйте явные
части `PinInputInput` с непрерывными индексами от нуля и `PinInputSeparator`, если код нужно разделить на группы. Значения
представлены массивом строк. Используйте `PinInputRootProvider` с `usePinInput`, когда состоянием или императивными
методами нужно управлять за пределами дерева компонентов. В React передаётся объект состояния. В Solid вызывайте реактивную функцию доступа, а в Vue читайте
состояние непосредственно в шаблоне.

Ark управляет переводом фокуса, распределением вставленного текста, редактированием с клавиатуры и
автозаполнением одноразовых кодов; добавьте `PinInputLabel`, чтобы у группы было доступное имя.
`PinInputSeparator` по умолчанию декоративный и получает `aria-hidden`, поэтому
содержательный текст размещайте вне него.

## Стилизация

### CSS-переменные

Наведите на переменную или выберите её, чтобы увидеть её в превью.

<CssPropertiesSection properties={PinInputDocs.pinInputOverrideCssProperties}>
  <AnatomyScene />
</CssPropertiesSection>

Пакеты с CSS Modules предоставляют три переменные: `--moduix-pin-input-input-size` (действует для всех
размеров), `--moduix-pin-input-gap` и `--moduix-pin-input-radius`. Цвета, рамки, типографика и focus ring
берутся из токенов foundation; переопределяйте их классом на нужной части. В Tailwind-вариантах используются
нативные utility-классы и пользовательские переопределения через `className` или `class`.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `PinInput` | `pin-input-root` |
| `PinInputRootProvider` | `pin-input-root-provider` |
| `PinInputLabel` | `pin-input-label` |
| `PinInputControl` | `pin-input-control` |
| `PinInputInput` | `pin-input-input` |
| `PinInputSeparator` | `pin-input-separator` |

- Селекторы состояния Ark: `data-required` на подписи.

- Части Ark используют `data-scope="pin-input"` и `data-part="root" | "label" | "control" | "input"`.
- Для стилей состояния корня используются `data-disabled`, `data-invalid`, `data-complete` и `data-readonly`.
- Для стилей состояния ячейки используются `data-disabled`, `data-invalid`, `data-complete`, `data-filled` и
  `data-index`.
- Корень дублирует `size` в `data-size`. Отключённый `PinInput` внутри отключённого `Field` или `Fieldset` не
  затемняется второй раз.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| Символы | Заполняют ячейку и переходят к следующей. |
| `Backspace` | Очищает ячейку и переходит к предыдущей. |
| `ArrowLeft` / `ArrowRight` | Перемещает между ячейками. |
| `Ctrl+V` | Вставляет весь код по ячейкам. |
