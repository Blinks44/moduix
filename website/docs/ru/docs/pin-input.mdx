## Выбор подходящего компонента

Используйте `PinInput`, если короткий код фиксированной длины нужно вводить по одному символу в отдельных ячейках.

- Выбирайте **`PinInput`** для одноразовых кодов, PIN-кодов, резервных кодов и кодов приглашений.
- Выбирайте **`Input`**, когда достаточно одного обычного текстового поля.
- Выбирайте **`PasswordInput`**, когда значение представляет собой одну секретную строку с переключателем видимости.

## Анатомия

```text
PinInput / PinInput.Root
├─ PinInput.Label
├─ PinInput.Control
│  ├─ PinInput.Input[index=0]
│  ├─ PinInput.Input[index=1]
│  └─ PinInput.Input[index=2]
└─ PinInput.HiddenInput (явно)

PinInput.RootProvider
└─ то же дерево частей, связанное с состоянием usePinInput()
```

| Часть | Назначение |
| --- | --- |
| `PinInput` / `PinInput.Root` | Управляет количеством ячеек, состоянием значения, проверкой и параметрами формы. |
| `PinInput.HiddenInput` | Нативное поле Ark, которое нужно добавлять явно. |
| `PinInput.RootProvider` | Подключает части к состоянию, созданному через `usePinInput()`. |
| `PinInput.Context` | Передаёт текущее состояние корневого компонента потомкам через render prop. |
| `PinInput.Label` | Задаёт подпись для группы PIN-кода или кода подтверждения. |
| `PinInput.Control` | Контейнер видимых ячеек с индексами. |
| `PinInput.Input` | Одна видимая ячейка для символа. Передайте индекс, начиная с нуля. |
| `PinInput.Inputs` | Создаёт по одному `Input` с индексом для каждой ячейки контекста Ark. |
| `PinInput.Separator` | Декоративный вспомогательный компонент moduix для группировки, а не часть примитива Ark. |
| `usePinInput` | Создаёт состояние для `PinInput.RootProvider`. |
| `usePinInputContext` | Читает текущее состояние Pin Input внутри дерева компонента. |

## Композиция

Явно добавьте `PinInput.HiddenInput` внутрь `PinInput` или `PinInput.RootProvider`, если значение должно
отправляться с нативной формой и сбрасываться вместе с ней. Задайте корню `name`, а `form` используйте, если
форма находится вне дерева компонента.

`PinInput.Inputs` создаёт по одной индексированной ячейке для каждого элемента контекста Ark. Используйте явные
части `Input` с непрерывными индексами от нуля и `Separator`, если код нужно разделить на группы. Значения
представлены массивом строк. Используйте `RootProvider` с `usePinInput`, когда состоянием или императивными
методами нужно управлять за пределами дерева компонентов. В React передаётся объект состояния, а в Solid
реактивный accessor.

## Доступность

Ark управляет переводом фокуса, распределением вставленного текста, редактированием с клавиатуры, данными формы
и автозаполнением одноразовых кодов. Добавьте `Label`, чтобы у группы было доступное имя.

`PinInput.Separator` по умолчанию является декоративным и получает `aria-hidden` и `role="presentation"`. Не
размещайте внутри него содержательный текст.

### Хуки стилизации

- Корневой элемент и `RootProvider` имеют `data-slot="pin-input-root"` и `data-slot="pin-input-root-provider"`.
- `Label`, `Control` и `Input` имеют `data-slot="pin-input-label"`, `data-slot="pin-input-control"` и
  `data-slot="pin-input-input"`.
- Части Ark используют `data-scope="pin-input"` и `data-part="root" | "label" | "control" | "input"`.
- Для стилей состояния корня используются `data-disabled`, `data-invalid`, `data-complete` и `data-readonly`.
- Для стилей состояния ячейки используются `data-disabled`, `data-invalid`, `data-complete`, `data-filled` и
  `data-index`.
- `PinInput.Separator` имеет `data-slot="pin-input-separator"` и по умолчанию является декоративным.
