## Выбор подходящего компонента

Используйте `PinInput`, если короткий код фиксированной длины нужно вводить по одному символу в отдельных ячейках.

- Выбирайте **`PinInput`** для одноразовых кодов, PIN-кодов, резервных кодов и кодов приглашений.
- Выбирайте **`Input`**, когда достаточно одного обычного текстового поля.
- Выбирайте **`PasswordInput`**, когда значение представляет собой одну секретную строку с переключателем видимости.

## Анатомия

```text
PinInput / PinInput.Root
├─ PinInput.Label
├─ PinInput.Control
│  ├─ PinInput.Input[index=0]
│  ├─ PinInput.Input[index=1]
│  └─ PinInput.Input[index=2]
└─ скрытое нативное поле (добавляется автоматически)
```

| Часть                                  | Назначение                                                                                         |
| -------------------------------------- | --------------------------------------------------------------------------------------------------- |
| `PinInput` / `PinInput.Root`           | Корневой компонент и машина состояний: количество ячеек, массив значений, проверка и параметры формы. |
| `PinInput.RootProvider`                | Создаёт дерево компонента на основе состояния, возвращённого `usePinInput`.                         |
| `PinInput.Context`                     | Передаёт потомкам состояние корневого элемента через render prop.                                  |
| `PinInput.Label`                       | Подпись группы для ввода PIN-кода или кода подтверждения.                                          |
| `PinInput.Control`                     | Контейнер видимых полей с индексами.                                                               |
| `PinInput.Input`                       | Одна видимая ячейка для символа. Передайте индекс `index`, начиная с нуля.                         |
| `PinInput.Inputs`                      | Создаёт по одному `Input` с индексом для каждой ячейки контекста Ark. Его `className` передаётся каждой ячейке. |
| `PinInput.Separator`                   | Декоративный вспомогательный компонент moduix для группировки. Это не часть примитива Ark.         |
| `usePinInput`                          | Создаёт состояние для `PinInput.RootProvider`.                                                     |
| `usePinInputContext`                    | Читает текущее состояние Pin Input внутри дерева компонента.                                      |

## Композиция

### Рекомендуемая композиция

Используйте компактную форму `<PinInput>`, добавьте видимую `Label` и поместите `Inputs` внутрь `Control`.
Передайте `name`, если код должен отправляться вместе с формой.

### Когда нужна собственная композиция

Явно добавьте части `Input` с индексами и `Separator`, если код нужно разделить на группы или отдельным
ячейкам требуются разные свойства. Используйте `PinInput.RootProvider` и `usePinInput`, когда состояние нужно
создать за пределами дерева компонентов. Индексы должны начинаться с нуля и идти непрерывно во всей композиции.

### Свойства по умолчанию

| Свойство         | По умолчанию    | Примечания                                                                                     |
| ---------------- | --------------- | ----------------------------------------------------------------------------------------------- |
| `count`          | -               | Количество ячеек. Указывайте явно для предсказуемой SSR-разметки и ARIA-атрибутов.              |
| `type`           | `numeric`       | `numeric`, `alphabetic` или `alphanumeric`.                                                      |
| `placeholder`    | `''` в moduix   | В Ark по умолчанию отображается `○`, а moduix использует пустую строку, пока свойство не задано. |
| `otp`            | `false`         | Добавляет `autocomplete="one-time-code"` видимым полям.                                         |
| `mask`           | `false`         | Скрывает введённые символы, как поле с `type="password"`.                                      |
| `blurOnComplete` | `false`         | Убирает фокус с последнего поля после заполнения всех ячеек.                                    |
| `selectOnFocus`  | -               | Выделяет текущее значение при получении фокуса.                                                 |
| `autoFocus`      | -               | Переводит фокус в первую ячейку при монтировании компонента.                                    |
| `autoSubmit`     | -               | Отправляет связанную форму после заполнения всех ячеек.                                         |
| `pattern`        | -               | Пользовательское регулярное выражение для допустимых символов.                                  |
| `sanitizeValue`  | -               | Очищает вставленное значение до проверки, например удаляет пробелы или дефисы.                 |
| `defaultValue`   | `[]`            | Начальное значение для неконтролируемого режима, массив строк.                                  |
| `value`          | -               | Управляемое значение, массив строк.                                                             |

### Особенности поведения

`value` и `defaultValue` принимают массивы строк. Колбэки `onValueChange(details)` и `onValueComplete(details)`
передают `details.value` и `details.valueAsString`. Колбэк `onValueInvalid(details)` передаёт отклонённое значение
в `details.value` и его индекс `details.index`.

Используйте `type` для встроенных наборов допустимых символов, а `pattern` для собственного регулярного выражения.
`sanitizeValue` получает вставленный текст и возвращает значение, которое нужно проверить.

`Field.Root` и `Fieldset.Root` могут передавать через контекст Ark состояния `disabled`, `invalid`, `required` и
`readOnly`. Передавайте в `PinInput` корневые свойства, например `name`, `form`, `ids` и `translations`. Корневой
элемент и его части поддерживают `asChild`.

Передайте `className` в `PinInput.Inputs`, если всем созданным ячейкам нужен один класс. Используйте явные части
`Input`, если для отдельных ячеек нужны разные свойства или стили.

Включайте `autoSubmit` только тогда, когда завершение ввода должно отправлять связанную форму. Компонент использует
клавиатурное поведение Ark: клавиши со стрелками перемещают фокус между ячейками, Backspace очищает ячейку и при
необходимости возвращает фокус назад, Delete очищает текущую ячейку, а вставка заполняет оставшиеся ячейки.

## Доступность

Ark управляет переводом фокуса, распределением вставленного текста, редактированием с клавиатуры, данными формы
и автозаполнением одноразовых кодов. Добавьте `Label`, чтобы у группы было доступное имя.

`PinInput.Separator` по умолчанию является декоративным и получает `aria-hidden` и `role="presentation"`. Не
размещайте внутри него содержательный текст.

Для отправки значения в нативную форму передайте корневому элементу `name`. Используйте также `form`, если форма
находится в другом месте документа. Корневой элемент автоматически добавляет скрытое нативное поле.

### Хуки стилизации

- Корневой элемент и `RootProvider` имеют `data-slot="pin-input-root"` и `data-slot="pin-input-root-provider"`.
- `Label`, `Control`, `Input` и скрытое поле имеют `data-slot="pin-input-label"`,
  `data-slot="pin-input-control"`, `data-slot="pin-input-input"` и `data-slot="pin-input-hidden-input"`.
- Части Ark используют `data-scope="pin-input"` и `data-part="root" | "label" | "control" | "input"`.
- Для стилизации состояния корневого элемента используются `data-disabled`, `data-invalid`, `data-complete` и
  `data-readonly`.
- Для стилизации состояния ячейки используются `data-disabled`, `data-invalid`, `data-complete`, `data-filled` и
  `data-index`.
- `PinInput.Separator` имеет `data-slot="pin-input-separator"` и по умолчанию является декоративным.
