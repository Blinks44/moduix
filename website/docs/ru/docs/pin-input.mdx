## Выбор подходящего компонента

Используйте `PinInput`, если короткий код фиксированной длины нужно вводить по одному символу в отдельных ячейках.

- Выбирайте **`PinInput`** для одноразовых кодов, PIN-кодов, резервных кодов и кодов приглашений.
- Выбирайте **`Input`**, когда достаточно одного простого текстового поля.
- Выбирайте **`PasswordInput`**, когда значение представляет собой одну секретную строку с возможностью показать или скрыть её.

## Базовый пример

Начните с дерева частей Ark: корневого элемента, метки, `Control` и `Inputs`. moduix автоматически добавляет
скрытое нативное поле формы, поэтому значение участвует в отправке формы и синхронизируется при её сбросе.

## Анатомия

```text
PinInput / PinInput.Root
├─ PinInput.Label
├─ PinInput.Control
│  ├─ PinInput.Input[index=0]
│  ├─ PinInput.Input[index=1]
│  └─ PinInput.Input[index=2]
└─ скрытое нативное поле (добавляется автоматически)
```

| Часть                           | Назначение                                                                |
| ------------------------------- | ------------------------------------------------------------------------- |
| `PinInput` / `PinInput.Root`    | Машина состояний корневого элемента: количество ячеек, массив значений, валидация и параметры формы. |
| `PinInput.RootProvider`         | Строит дерево Pin Input на основе состояния, возвращённого `usePinInput`.                          |
| `PinInput.Label`                | Подпись группы полей PIN-кода.                                                                     |
| `PinInput.Control`              | Контейнер видимых полей с индексами.                                                               |
| `PinInput.Input`                | Одна видимая ячейка для символа. Передайте индекс `index`, начиная с нуля.                         |
| `PinInput.Inputs`               | Создаёт стандартный набор полей с индексами из контекста Ark.                                      |
| `PinInput.Separator`            | Декоративный разделитель для группировки. Это вспомогательная часть moduix, а не часть примитива Ark. |
| `usePinInput` / `PinInput.RootProvider` | Управление состоянием за пределами дерева и императивные методы.                         |

## Композиция

### Рекомендуемая композиция

Используйте сокращённую форму `<PinInput>`, добавьте видимую `Label` и поместите `Inputs` внутрь `Control`.
Корневой элемент всегда добавляет скрытое нативное поле формы, поэтому сохраняются отправка формы, синхронизация
со сбросом и автозаполнение OTP.

### Когда нужна другая композиция

Используйте части `Input` с явными индексами, если между группами нужен разделитель или отдельным полям требуются
свои свойства. Используйте `PinInput.RootProvider` и `usePinInput`, когда состояние должно создаваться за пределами
отрисовываемого дерева. Индексы полей Ark должны идти подряд во всём коде.

### Свойства по умолчанию

| Свойство         | По умолчанию    | Примечания                                                              |
| ---------------- | --------------- | ----------------------------------------------------------------------- |
| `count`          | -               | Количество ячеек. Явно указывайте его для предсказуемой SSR-разметки.                              |
| `type`           | `numeric`       | `numeric`, `alphabetic` или `alphanumeric`.                                                         |
| `placeholder`    | `''` в moduix   | В Ark по умолчанию `○`; moduix скрывает его, пока не передан `placeholder`.                        |
| `otp`            | `false`         | Включает автозаполнение одноразового кода.                                                          |
| `mask`           | `false`         | Скрывает введённые символы, как поле пароля.                                                        |
| `blurOnComplete` | `false`         | Убирает фокус с последней ячейки после заполнения кода.                                             |
| `selectOnFocus`  | -               | Выделяет текущее значение ячейки при получении фокуса.                                              |
| `autoFocus`      | -               | Автоматически переводит фокус в первую ячейку.                                                      |
| `autoSubmit`     | -               | Отправляет форму после заполнения всех ячеек.                                                       |
| `pattern`        | -               | Пользовательское регулярное выражение для допустимых символов.                                      |
| `sanitizeValue`  | -               | Очищает вставленное значение до проверки, например удаляет пробелы и дефисы.                        |
| `defaultValue`   | `[]`            | Начальное значение в виде массива строк для неуправляемого режима.                                  |
| `value`          | -               | Управляемое значение в виде массива строк.                                                          |

### Особенности поведения

`value` и `defaultValue` имеют тип «массив строк». Колбэки `onValueChange(details)` и `onValueComplete(details)`
передают `details.value` и `details.valueAsString`. `onValueInvalid(details)` передаёт отклонённое значение
`details.value` и его индекс `details.index`.

Используйте `type` и `pattern` для проверки значения. Свойство `sanitizeValue` позволяет очистить вставленный текст
до проверки. `Field.Root` и `Fieldset.Root` могут передать через контекст Ark состояния `disabled`, `invalid`,
`required` и `readOnly`. Части Ark поддерживают `asChild`, а `ids` позволяет задать стабильные идентификаторы для
внешних меток и описаний.

Включайте `autoSubmit`, только если после завершения ввода нужно отправить форму, которой принадлежит поле.
Клавиатурное поведение предоставляет Ark: стрелки перемещают фокус между ячейками, Backspace очищает ячейку и
при необходимости переводит фокус назад, Delete очищает текущую ячейку, а вставка заполняет оставшиеся ячейки.

### Хуки стилизации

- Корневой элемент и `RootProvider` имеют `data-slot="pin-input-root"` и `data-slot="pin-input-root-provider"`.
- Части Ark сохраняют `data-scope="pin-input"` и `data-part="root" | "label" | "control" | "input"`.
- Для стилизации состояния корня используются `data-disabled`, `data-invalid`, `data-complete` и `data-readonly`.
- Для стилизации состояния поля используются `data-disabled`, `data-invalid`, `data-complete`, `data-filled` и `data-index`.
- `PinInput.Separator` имеет `data-slot="pin-input-separator"` и по умолчанию является декоративным.

## Доступность

Ark управляет переносом фокуса, распределением вставленного текста, редактированием с клавиатуры, данными формы в
скрытом поле и автозаполнением. Добавьте `Label`, чтобы у группы было доступное имя. Корневой элемент автоматически
добавляет скрытое нативное поле формы; настройте участие в форме с помощью свойств корня, таких как `name` и `form`.
