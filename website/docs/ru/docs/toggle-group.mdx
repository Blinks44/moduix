## Использование

<Usage />

Интерактивный

Используйте `ToggleGroup` как корневой компонент и добавьте по одному `ToggleGroupItem` на каждый
вариант. Задайте группе доступное имя через `aria-label` или `aria-labelledby`.

## Выбор подходящего компонента

Используйте `ToggleGroup`, когда связанные кнопки-переключатели должны работать как один элемент
управления с навигацией с клавиатуры. Группа может поддерживать один или несколько выбранных вариантов.

- Выберите **`ToggleGroup`** для сегментированных переключателей, компактных наборов фильтров и панелей форматирования.
- Выберите **`Toggle`** для одного отдельного действия с двумя состояниями.
- Выберите **`Tabs`**, если выбор должен также показывать связанную панель содержимого.
- Выберите **`RadioGroup`**, если варианты являются полями формы и должны участвовать в её нативной отправке.

## Композиция

`ToggleGroup` оборачивает примитив Toggle Group из Ark UI и добавляет визуальные свойства moduix для
вариантов и размеров. Импортируйте его из пакета нужного фреймворка: `@moduix/react/toggle-group`,
`@moduix/solid/toggle-group`, `@moduix/react-tailwind/toggle-group` или
`@moduix/solid-tailwind/toggle-group`. Vue-пакеты: `@moduix/vue/toggle-group` и `@moduix/vue-tailwind/toggle-group`; Svelte-пакеты: `@moduix/svelte/toggle-group` и `@moduix/svelte-tailwind/toggle-group`.

Используйте `defaultValue` для неконтролируемой группы, а `value` вместе с `onValueChange(details)`,
если состояние выбора хранится в другой части приложения на React или Solid. Во Vue используйте
`v-model`, а детали Ark получайте через `@value-change`; в скрипте хранилище читается через `.value`. В Svelte используйте `bind:value` и callback `onValueChange`; хук возвращает геттер, поэтому состояние читается через `toggleGroup().value`.
Выбранные значения имеют тип `string[]` в режимах
одиночного и множественного выбора. Используйте `ToggleGroupRootProvider` с `useToggleGroup()` из
пакета нужного фреймворка, если состояние нужно создать вне дерева. В React хранилище читается как
объект, в Solid его реактивное состояние доступно через возвращаемую функцию, во Vue реактивное хранилище доступно непосредственно в шаблоне, а в Svelte хук возвращает геттер.

Используйте `ToggleGroupContext` или `useToggleGroupContext()`, если пользовательскому элементу нужно
текущее состояние группы. При использовании `asChild` React получает одного потомка, который ведёт себя
как кнопка, Solid получает функцию рендера, возвращающую элемент с поведением Ark, Vue получает один элемент-потомок, а Svelte получает сниппет `asChild`, который передаёт `props()` элементу. Не используйте
`ToggleGroup` и `ToggleGroupRootProvider` одновременно для одного экземпляра состояния.

## Стилизация

Используйте `className` в React или `class` в Solid, Vue и Svelte на экспортируемых частях для структурных стилей.
Варианты Tailwind используют нативные утилиты и классы потребителя, а варианты CSS Modules
предоставляют токены `--moduix-toggle-group-*`. Элементы наследуют `variant` и `size` от корневой
части и могут переопределить любое из этих свойств для отдельного оформления.

### CSS-переменные

Наведите на переменную или выберите её, чтобы увидеть её в превью.

<CssPropertiesSection properties={ToggleGroupDocs.toggleGroupOverrideCssProperties}>
  <AnatomyScene />
</CssPropertiesSection>

В таблице перечислены свойства уровня группы. Каждый `ToggleGroupItem` также поддерживает [CSS-свойства
Toggle](/docs/toggle#css-переменные) для цветов и состояний взаимодействия. Задайте свойство
`--moduix-toggle-*` на корневом компоненте, чтобы оформить все элементы, или на элементе, чтобы изменить
оформление только одного элемента.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `ToggleGroup` | `toggle-group-root` |
| `ToggleGroupRootProvider` | `toggle-group-root-provider` |
| `ToggleGroupItem` | `toggle-group-item` |

- Селекторы частей Ark: `data-scope="toggle-group"` и `data-part="root" | "item"`.
- Селекторы состояния Ark: `data-state="on" | "off"`, `data-disabled`, `data-focus` и
  `data-orientation="horizontal" | "vertical"`.
- Селекторы moduix: `data-variant` и `data-size`.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `ArrowLeft` / `ArrowRight` | Перемещает фокус между пунктами; ArrowUp и ArrowDown в вертикальном режиме. |
| `Home` / `End` | Переводит фокус на первый или последний пункт. |
| `Enter` / `Space` | Нажимает или отжимает пункт в фокусе. |

## Справочник API

| Проп | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `value` | `string[]` | — | Нажатые элементы в управляемом режиме. |
| `defaultValue` | `string[]` | — | Изначально нажатые элементы. |
| `onValueChange` | `(details: ValueChangeDetails) => void` | — | Вызывается при изменении нажатых элементов. |
| `multiple` | `boolean` | `false` | Разрешает нажать несколько элементов сразу. |
| `deselectable` | `boolean` | `true` | Разрешает отжать последний нажатый элемент. |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Раскладка и направление стрелок: `horizontal` или `vertical`. |
| `loopFocus` | `boolean` | `true` | Навигация с клавиатуры переходит с последнего элемента на первый. |
| `rovingFocus` | `boolean` | `true` | Стрелки переводят фокус между элементами, Tab выводит из группы. |
| `variant` | `'default' \| 'outline' \| 'ghost'` | `'default'` | Вид всех элементов: `default`, `outline` или `ghost`. |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'icon-sm' \| 'icon-md' \| 'icon-lg'` | `'md'` | `xs`, `sm`, `md`, `lg` или квадратные `icon-sm`, `icon-md`, `icon-lg`. |
| `disabled` | `boolean` | `false` | Отключает все элементы. |
