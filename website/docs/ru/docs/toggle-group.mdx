## Справочник API

`ToggleGroup` оборачивает примитив Toggle Group из Ark UI и добавляет визуальные свойства moduix для
вариантов оформления и размеров. Импортируйте компонент из `@moduix/react/toggle-group`.

<PrimitiveReference href="https://ark-ui.com/docs/components/toggle-group" />

## Выбор подходящего компонента

Используйте `ToggleGroup`, когда связанные кнопки-переключатели должны работать как один элемент
управления с навигацией с клавиатуры. Группа может поддерживать один или несколько выбранных вариантов.

- Выберите **`ToggleGroup`** для сегментированных переключателей, компактных наборов фильтров и панелей форматирования.
- Выберите **`Toggle`** для одного отдельного действия с двумя состояниями.
- Выберите **`Tabs`**, если выбор должен также показывать связанную панель содержимого.
- Выберите **`RadioGroup`**, если варианты являются полями формы и должны участвовать в её нативной отправке.

## Анатомия

```text
ToggleGroup / ToggleGroup.Root
├─ ToggleGroup.Context (необязательно)
└─ ToggleGroup.Item[value]

ToggleGroup.RootProvider
└─ ToggleGroup.Item[value]
```

| Часть                               | Назначение                                                                        |
| ----------------------------------- | --------------------------------------------------------------------------------- |
| `ToggleGroup` / `ToggleGroup.Root`  | Хранит выбранные значения, управляет фокусом, ориентацией и отключённым состоянием. |
| `ToggleGroup.Item`                  | Интерактивный элемент с обязательным `value` и состоянием выбора, которым управляет Ark. |
| `ToggleGroup.RootProvider`          | Подключает дерево элементов к экземпляру состояния `useToggleGroup()`, созданному вне этого дерева. |
| `ToggleGroup.Context`               | Передаёт текущее состояние группы через render prop.                              |

## Композиция

### Рекомендуемая композиция

`ToggleGroup` является сокращённой формой `ToggleGroup.Root`. Для неконтролируемой группы задайте
`defaultValue`, а для группы, которой управляет состояние React, передайте `value` и `onValueChange`.
И `value`, и `defaultValue` являются массивами строк в режимах одиночного и множественного выбора.

moduix добавляет два визуальных свойства к `ToggleGroup`, `ToggleGroup.Root`, `ToggleGroup.RootProvider`
и `ToggleGroup.Item`:

| Свойство  | По умолчанию | Значения                                                |
| --------- | ------------ | ------------------------------------------------------- |
| `variant` | `default`    | `default`, `outline`, `ghost`                           |
| `size`    | `md`         | `xs`, `sm`, `md`, `lg`, `icon-sm`, `icon-md`, `icon-lg` |

Элементы наследуют `variant` и `size` от корневого компонента. Переопределяйте эти свойства на элементе
только тогда, когда ему нужно другое оформление.

### Когда нужна собственная композиция

Используйте `asChild` на корневом компоненте, `ToggleGroup.RootProvider` или элементе, если отрисовываемым элементом
должен управлять другой компонент. Для элемента передавайте ровно одного потомка, который ведёт себя как
кнопка, чтобы Ark мог объединить с ним свойства взаимодействия и состояние ARIA.

Используйте `ToggleGroup.RootProvider` с `useToggleGroup()` из moduix, когда состояние нужно создать вне
дерева компонентов. Используйте `useToggleGroupContext()` во вложенном пользовательском компоненте, которому
нужно текущее состояние группы. Не используйте `ToggleGroup.Root` и `ToggleGroup.RootProvider` одновременно
для одного экземпляра состояния. Прямой импорт из Ark UI нужен только для композиций, которые выходят за
пределы API moduix.

### Свойства по умолчанию

| Свойство      | По умолчанию | Примечания                                                         |
| ------------- | ------------ | ------------------------------------------------------------------ |
| `deselectable` | `true`       | Позволяет снять выбор в режиме одиночного выбора.                  |
| `loopFocus`    | `true`       | Переводит фокус стрелкой с последнего элемента на первый и обратно. |
| `orientation`  | `horizontal` | Задаёт направление группы и соответствующую навигацию с клавиатуры. |
| `rovingFocus`  | `true`       | Оставляет в порядке перехода по Tab только один элемент.           |
| `multiple`     | `false`      | Позволяет одновременно оставить выбранными несколько элементов.   |
| `variant`      | `default`    | Визуальное оформление moduix.                                      |
| `size`         | `md`         | Размер элементов moduix.                                          |

### Особенности поведения

- `onValueChange` получает объект с данными Ark. Читайте выбранный массив строк из `details.value`.
- Используйте `value` вместе с `onValueChange`, когда группой управляет состояние React.
- `deselectable` игнорируется, если включён `multiple`.
- Задайте группе доступное имя через `aria-label` или `aria-labelledby`.
- Элементам только с иконками нужно собственное доступное имя, например `aria-label="Align left"`.
- Используйте `disabled` на группе для всего набора или на одном элементе для отдельного недоступного варианта.
- Используйте `ids`, чтобы задать стабильные ID корневого элемента и элементов при интеграции группы с другим доступным интерфейсом.
- В режиме одиночного выбора используются роли `radiogroup` и `radio`. В режиме множественного выбора группа использует роль `group` и атрибут `aria-pressed`.
- В горизонтальной группе стрелки влево и вправо перемещают фокус, в вертикальной для этого служат стрелки вверх и вниз. Home и End переводят фокус к первому и последнему доступному элементу. Space и Enter активируют кнопку в фокусе, а `loopFocus` управляет зацикливанием навигации стрелками.
- `ref` корневого компонента и элемента передаётся в соответствующий DOM-элемент. При использовании `asChild` он указывает на дочерний элемент, которому передаётся поведение Ark.
- Ark записывает `data-scope="toggle-group"`, `data-part`, `data-orientation`, `data-disabled`, `data-focus` и `data-state="on" | "off"` на элементах для стилизации.
- Горизонтальная группа прокручивается, если не помещается в контейнер, вместо переноса элементов на новую строку. Это сохраняет линейную навигацию с клавиатуры.

## Стилизация

`ToggleGroup` предоставляет стабильные атрибуты `data-slot` для moduix, а также атрибуты анатомии и состояния
Ark для стилизации по состоянию компонента.

В таблице перечислены свойства уровня группы. Каждый `ToggleGroup.Item` также поддерживает [CSS-свойства
Toggle](/docs/toggle#css-properties) для цветов и состояний взаимодействия. Задайте свойство
`--moduix-toggle-*` на корневом компоненте, чтобы оформить все элементы, или на элементе, чтобы изменить
оформление только одного элемента.

### Хуки стилизации

- `data-slot="toggle-group-root"` и `data-slot="toggle-group-root-provider"` являются стабильными селекторами корневого элемента.
- `data-slot="toggle-group-item"` является стабильным селектором элемента.
- `data-scope="toggle-group"` и `data-part="root" | "item"` предоставляются Ark.
- На каждом элементе записывается `data-state="on" | "off"`.
- На корневом и дочерних элементах записывается `data-orientation="horizontal" | "vertical"`.
- `data-disabled` и `data-focus` являются атрибутами состояния Ark.
- `data-variant` и `data-size` отражают визуальные свойства moduix.
