## Анатомия

```text
Menu / Menu.Root
├─ Menu.Trigger
│  ├─ Menu.TriggerIcon
│  └─ Menu.Indicator
├─ Menu.ContextTrigger
└─ Ветка всплывающего слоя (автоматически переносится в портал)
   └─ Menu.Positioner
      └─ Menu.Content
         ├─ Menu.Arrow
         │  └─ Menu.ArrowTip
         └─ Menu.Viewport
            ├─ Menu.Item
            │  ├─ Menu.ItemText
            │  │  ├─ Menu.ItemTextIcon
            │  │  └─ Menu.ItemTextLabel
            │  └─ Menu.ItemShortcut
            ├─ Menu.CheckboxItem
            │  └─ Menu.ItemIndicator
            ├─ Menu.RadioItemGroup
            │  └─ Menu.RadioItem
            ├─ Menu.ItemGroup
            │  └─ Menu.ItemGroupLabel
            ├─ Menu.Separator
            └─ Menu
               └─ Menu.TriggerItem
                  └─ Menu.TriggerItemIcon
```

| Часть | Назначение |
| --- | --- |
| `Menu` / `Menu.Root` | Корневой компонент, который управляет открытием, позиционированием, поиском по начальным символам, фокусом и закрытием меню. |
| `Menu.RootProvider` | Подключает меню к экземпляру состояния, созданному с помощью `useMenu`. |
| `Menu.Trigger` | Кнопка, открывающая меню. Используйте `asChild`, чтобы передать другой семантический элемент. |
| `Menu.TriggerIcon` | Обёртка для иконки триггера. Если потомок не передан, отображается шеврон по умолчанию. |
| `Menu.Indicator` | Индикатор состояния триггера, обычно шеврон. |
| `Menu.ContextTrigger` | Триггер для контекстного меню по правому клику или долгому нажатию. |
| `Menu.Positioner` | Позиционирует плавающий слой меню. |
| `Menu.Content` | Всплывающая область с ролью `menu` и коллекцией пунктов. |
| `Menu.Viewport` | Явный прокручиваемый контейнер вокруг коллекции пунктов. |
| `Menu.Arrow` / `Menu.ArrowTip` | Необязательная стрелка, визуально связывающая всплывающее меню с триггером. |
| `Menu.Item` | Обычный пункт, выполняющий команду. |
| `Menu.CheckboxItem` | Пункт с независимым логическим состоянием. |
| `Menu.RadioItemGroup` / `Menu.RadioItem` | Группа и пункты для выбора одного значения. |
| `Menu.ItemIndicator` | Индикатор выбора для пунктов с флажками и вариантами с единственным выбором. |
| `Menu.ItemText` и помощники для текста | Компоненты для текста пункта, иконки и подписи. |
| `Menu.ItemShortcut` | Обёртка для сочетания клавиш или другой подсказки справа. |
| `Menu.ItemGroup` / `Menu.ItemGroupLabel` | Группа и подпись для связанных пунктов. |
| `Menu.Separator` | Разделитель между группами пунктов. |
| `Menu.TriggerItem` / `Menu.TriggerItemIcon` | Пункт и иконка для открытия вложенного меню. |
| `Menu.ItemContext` | Передаёт состояние пункта его содержимому. |

## Композиция

Используйте `defaultOpen` для неуправляемого меню. Если другая часть приложения владеет состоянием
открытия или подсветки, передайте `open` или `highlightedValue` вместе с соответствующим обработчиком
изменения. Используйте `useMenu()` с `Menu.RootProvider`, если хранилище состояния нужно создать
за пределами дерева компонентов; не добавляйте второй корневой `Menu` для того же хранилища.

`Menu.Positioner`, `Menu.Content` и `Menu.Viewport` являются разными частями, но позиционер автоматически помещается
в портал. Установите `portalled={false}` внутри диалога или прокручиваемого контейнера и добавьте
`positioning={{ strategy: 'fixed', hideWhenDetached: true }}`, если этот контейнер может прокручиваться.
Используйте `asChild` ровно с одним семантическим потомком, если триггер, пункт или контейнер
содержимого должны владеть DOM-узлом. В Solid назначайте ref элементу, созданному внутри
render-функции `asChild`: ref на самой части `Menu` через этот путь композиции не передаётся.
Внутри `Menu.Content` оберните прокручиваемые пункты в
`Menu.Viewport`. Необязательный `Menu.Arrow` оставьте непосредственным потомком `Menu.Content`, рядом
с viewport, чтобы стрелка не обрезалась при прокрутке. Вложенное меню - это ещё один корневой `Menu` внутри
родительского содержимого с собственными `TriggerItem`, `Positioner` и `Content`.

## Стилизация

Используйте `className` в React или `class` в Solid на экспортируемых частях для структурных стилей.
Для стилей по состоянию предпочитайте атрибуты Ark, такие как `data-state`, `data-disabled` и
`data-highlighted`, вместе с селекторами `data-slot` moduix. Варианты Tailwind используют нативные
утилиты и классы потребителя; CSS-переменные ниже настраивают варианты с CSS Modules. Атрибуты
состояния и хуки `data-slot` общие для обоих вариантов стилизации.

  `[data-state='open' | 'closed' | 'checked' | 'unchecked']`, `[data-current]`, `[data-highlighted]`,
  `[data-disabled]`, `[data-placement]` и `[data-side]`.

  `[data-slot='menu-separator']`, `[data-slot='menu-item-group']`, `[data-slot='menu-item-group-label']`,
