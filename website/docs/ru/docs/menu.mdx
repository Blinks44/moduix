## Выбор подходящего компонента

Используйте `Menu` для списков команд, которые открываются по триггеру, контекстных меню, простого выбора и
вложенных действий.

- Выбирайте **`Menu`** для дополнительных действий, действий над строками и списков команд, которые открываются
  кнопкой или триггером контекстного меню.

## Анатомия

```text
Menu
├─ Menu.Trigger
│  └─ Menu.Indicator
├─ Menu.ContextTrigger
├─ Ветка всплывающего слоя (автоматически переносится в портал)
│  └─ Menu.Positioner
│     └─ Menu.Content
│        ├─ Menu.Arrow
│        │  └─ Menu.ArrowTip
│        ├─ Menu.Item
│        ├─ Menu.CheckboxItem
│        │  ├─ Menu.ItemIndicator
│        │  └─ Menu.ItemText
│        ├─ Menu.RadioItemGroup
│        │  └─ Menu.RadioItem
│        ├─ Menu.ItemGroup
│        │  └─ Menu.ItemGroupLabel
│        └─ Menu
│           └─ Menu.TriggerItem
```

| Часть                  | Назначение                                                        |
| --------------------- | ----------------------------------------------------------------- |
| `Menu` / `Menu.Root`  | Корень Ark, который управляет открытием, позиционированием, поиском по первым символам и закрытием. |
| `Menu.RootProvider`   | Отрисовывает меню на основе экземпляра состояния `useMenu`.             |
| `Menu.Trigger`        | Кнопка-триггер; используйте `asChild`, чтобы передать свой элемент. |
| `Menu.Indicator`      | Индикатор триггера Ark, который учитывает состояние меню.                   |
| `Menu.ContextTrigger` | Триггер по правому клику или долгому нажатию для контекстного меню. |
| `Menu.Positioner`     | Позиционирует плавающий слой.                                      |
| `Menu.Content`        | Поверхность всплывающего меню с ролью menu и коллекцией пунктов.     |
| `Menu.Item`           | Пункт меню, выполняющий команду.                                                   |
| `Menu.CheckboxItem`   | Пункт, который можно включить или выключить.                                   |
| `Menu.RadioItemGroup` | Группа пунктов, из которых можно выбрать только один.            |
| `Menu.RadioItem`      | Пункт для выбора одного варианта.                             |
| `Menu.TriggerItem`    | Пункт, открывающий вложенное `Menu`.                             |
| `Menu.ItemIndicator`  | Индикатор выбора для пунктов с флажками и пунктов с выбором одного варианта.                     |

## Композиция

Корневой элемент автоматически помещает `Positioner` в портал. Используйте `portalled={false}`, чтобы оставить меню
в текущем контейнере, а `portalRef`, чтобы указать другой контейнер для портала. Структурные части остаются явными,
и их можно стилизовать.

### Рекомендуемая композиция

Сохраняйте структуру всплывающего меню явной. `Menu.Content` отвечает за содержимое Ark, а `Menu.Positioner` остаётся
отдельной частью.

```tsx
<Menu positioning={{ placement: 'bottom-start', gutter: 8 }}>
  <Menu.Trigger asChild>
    <Button>
      Actions
      <Menu.Indicator />
    </Button>
  </Menu.Trigger>
  <Menu.Positioner>
    <Menu.Content className="menu-content">
      <Menu.Item value="edit">Edit</Menu.Item>
    </Menu.Content>
  </Menu.Positioner>
</Menu>
```

### Когда нужна собственная композиция

Используйте `asChild`, если триггер, пункт или содержимое должны рендериться другим семантическим элементом.
Передавайте ровно одного семантического потомка, чтобы Ark мог корректно добавить ARIA-атрибуты и настроить
фокус и клавиатурное управление. Для ссылок указывайте `asChild` на `Menu.Item`, а для своего контейнера
всплывающего меню на `Menu.Content`.

Вложенное меню представляет собой обычный корень `Menu` внутри содержимого родительского меню. Для него используйте
`Menu.TriggerItem`, затем его собственные `Menu.Positioner` и `Menu.Content`.

### Свойства по умолчанию

Содержимое меню в портале по умолчанию монтируется при открытии и удаляется после анимации закрытия.
Установите `unmountOnExit={false}`, чтобы сохранить его после первого открытия. Указывайте `lazyMount={false}`
и `unmountOnExit={false}` только если содержимое нужно отрисовать сразу.

| Поверхность                       | По умолчанию | Примечания                                                  |
| --------------------------------- | ------------ | ----------------------------------------------------------- |
| `Menu` / `Menu.Root`                  | -       | Дополнительных значений по умолчанию в moduix нет, используются значения Ark. |
| `Menu.CheckboxItem` / `Menu.RadioItem` | `start` | `indicator` управляет позицией столбца индикатора.                         |

### Особенности поведения

- В moduix свойства `lazyMount` и `unmountOnExit` по умолчанию имеют значение `true`. Свойства `open`, `defaultOpen`,
  `onOpenChange(details)`, `highlightedValue`, `onHighlightChange(details)`, `onSelect(details)`, `closeOnSelect`,
  `ids` и `present` передаются в Ark без дополнительных значений по умолчанию со стороны moduix.
- Для идентификации пункта меню используйте `value`, а не собственный `id`.
- `Menu.CheckboxItem.onCheckedChange` получает новое логическое значение состояния.
- `Menu.RadioItemGroup.onValueChange` получает `details.value`.
- `Menu.RootProvider` нужно использовать с экземпляром `useMenu`, а не отрисовывать второй корневой элемент `Menu` для того же состояния.
- `Menu.Context`, `useMenuContext` и `useMenuItemContext` дают потомкам доступ к состоянию Ark для расширенной композиции.
- Корневой компонент автоматически помещает `Menu.Positioner` в портал. Используйте `portalled={false}`, чтобы оставить
  меню внутри диалога или прокручиваемого контейнера. Если контейнер прокручивается, добавьте
  `positioning={{ strategy: 'fixed', hideWhenDetached: true }}`.
- Анимации открытия и закрытия учитывают `prefers-reduced-motion`.
- `Menu.Indicator` соответствует части indicator в Ark. `Menu.TriggerIcon`, `Menu.TriggerItemIcon`, `Menu.ItemShortcut`
  и помощники для текста пунктов являются вспомогательными компонентами moduix для типового содержимого.

### Хуки стилизации

- Атрибуты Ark: `[data-scope='menu']`, `[data-part='trigger']`, `[data-part='indicator']`, `[data-part='content']`, `[data-part='item']`, `[data-type='checkbox' | 'radio']`, `[data-state='open' | 'closed' | 'checked' | 'unchecked']`, `[data-current]`, `[data-highlighted]`, `[data-disabled]`, `[data-placement]` и `[data-side]`.
- Переменные Ark: `--reference-width`, `--available-width`, `--available-height`, `--transform-origin`, `--layer-index`, `--arrow-size` и `--arrow-background`.
- Хуки moduix: `data-slot="menu-trigger"`, `menu-content`, `menu-item`, `menu-checkbox-item`, `menu-radio-item`, `menu-trigger-item`, `menu-item-indicator` и `menu-item-shortcut`.
