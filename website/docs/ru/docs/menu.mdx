Используйте `Menu` как корневой компонент и задайте каждому `MenuItem` стабильное значение
`value`. Оставляйте `MenuPositioner` и `MenuContent` явными, а внутрь содержимого добавляйте
пункты, группы, разделители или вложенные меню. `MenuIndicator` необязателен и по умолчанию
отображает шеврон moduix.

Не задавайте собственный `id` для `MenuItem`: Ark идентифицирует пункты по `value`, а лишний
`id` ломает поиск пунктов, навигацию вводом и управление фокусом.

## Выбор подходящего компонента

Используйте `Menu` для контекстных действий во временном всплывающем меню: команд, ссылок или
контекстного меню. Для постоянной навигации по сайту или продукту используйте `NavigationMenu`,
а `Dialog` - для сценариев, требующих полного внимания пользователя.

## Примеры

### Группировка

Используйте `MenuItemGroup` и `MenuItemGroupLabel`, чтобы объединить связанные пункты, а
`MenuSeparator` - чтобы разделить группы.

<Example name="menu/grouping" />

### Пункты с флажками

Используйте пункты с флажками для независимых параметров. Установите `closeOnSelect={false}`, если
пользователь должен изменить несколько настроек до закрытия меню.

<Example name="menu/checkbox-items" />

### Пункты с выбором одного варианта

Используйте `MenuRadioItemGroup`, если пользователь должен выбрать одно значение из нескольких
вариантов. Установите `closeOnSelect={false}`, если меню должно оставаться открытым во время выбора.

<Example name="menu/radio-items" />

### Размещение индикатора

Задайте для пунктов с флажками и вариантами с единственным выбором `indicator="start"`, `"end"`
или `"none"`, чтобы выбрать положение индикатора.

<Example name="menu/indicator-placement" />

### Ссылки

Используйте `MenuItem asChild` и сделайте саму ссылку пунктом меню. Тогда ссылка получит
ARIA-атрибуты, клавиатурное поведение и обработку фокуса пункта.

<Example name="menu/links" />

### Вложенное меню

Разместите дочерний `Menu` внутри содержимого родительского меню и открывайте его с помощью
`MenuTriggerItem`.

<Example name="menu/nested" />

### Со стрелкой

Добавьте `MenuArrow` и `MenuArrowTip` непосредственно внутрь `MenuContent`, если нужно визуально
связать всплывающее меню с триггером.

<Example name="menu/with-arrow" />

### Контекстное меню

Используйте `MenuContextTrigger`, если действия должны появляться по правому клику. На сенсорных
устройствах и при использовании пера меню также открывается долгим нажатием.

<Example name="menu/context-menu" />

### Несколько триггеров

Чтобы использовать одно меню с несколькими триггерами, передайте каждому `MenuTrigger` своё
значение `value`. Меню будет позиционироваться относительно триггера, который его открыл.

<Example name="menu/multiple-triggers" />

### Меню в диалоге

Установите `portalled={false}`, чтобы оставить всплывающее меню внутри диалога или прокручиваемого
контейнера. Если контейнер может прокручиваться, используйте фиксированное позиционирование и
`hideWhenDetached`, чтобы скрывать меню после выхода за видимую область.

<Example name="menu/menu-in-dialog" />

### Событие выбора

Используйте `onSelect(details)` на корневом компоненте, если один обработчик должен реагировать на
выбор любого пункта. Выбранное значение находится в `details.value`.

<Example name="menu/select-event" />

### Управляемое состояние

Управляйте `open` через состояние выбранного фреймворка, если меню должно открываться или закрываться
другим элементом управления. Подробнее в разделе [Управляйте состоянием из приложения](/docs/composition-patterns#controlled-state).

<Example name="menu/controlled" />

### Контекст элемента

Используйте `MenuItemContext`, если содержимое пункта должно реагировать на его состояние, например
на наличие подсветки.

<Example name="menu/item-context" />

### Контекстное меню с отложенным монтированием

По умолчанию содержимое контекстного меню добавляется в DOM при первом открытии и удаляется после
анимации закрытия. Установите `unmountOnExit={false}`, если поддерево должно оставаться смонтированным
после закрытия меню.

<Example name="menu/lazy-mounted-context-menu" />

### Root Provider

Используйте `useMenu` и `MenuRootProvider`, если коду за пределами дерева компонентов нужно читать
состояние меню или изменять его. Подробнее в разделе [Выносите состояние за пределы дерева](/docs/composition-patterns#root-provider).

<Example name="menu/root-provider" />

### Сборка из частей

То же меню, что в Basic, но с явным шевроном в триггере: `MenuIndicator` рисует иконку по умолчанию,
только когда у него нет дочерних элементов. `MenuItemIndicator` и `MenuTriggerItemIcon` принимают
иконку так же. Начинайте с него, если дизайн заменяет иконки меню.

## Композиция

Используйте `defaultOpen` для неуправляемого меню. Если другая часть приложения управляет состоянием
открытия или подсветки, передайте `open` или `highlightedValue` вместе с соответствующим обработчиком
изменения. Используйте `useMenu()` с `MenuRootProvider`, если хранилище состояния нужно создать
за пределами дерева компонентов; не добавляйте второй корневой `Menu` для того же хранилища.

`MenuPositioner`, `MenuContent` и `MenuViewport` являются разными частями, но позиционер автоматически помещается
в портал. Установите `portalled={false}` внутри диалога или прокручиваемого контейнера и добавьте
`positioning={{ strategy: 'fixed', hideWhenDetached: true }}`, если этот контейнер может прокручиваться.
Используйте `asChild` ровно с одним семантическим потомком, если триггер, пункт или контейнер
содержимого должны отрисовываться вашим элементом. В Solid назначайте ref элементу, созданному внутри
render-функции `asChild`: ref на самой части `Menu` через этот путь композиции не передаётся.
Внутри `MenuContent` оберните прокручиваемые пункты в
`MenuViewport`. Необязательный `MenuArrow` оставьте непосредственным потомком `MenuContent`, рядом
с viewport, чтобы стрелка не обрезалась при прокрутке. Вложенное меню - это ещё один корневой `Menu` внутри
родительского содержимого с собственными `TriggerItem`, `Positioner` и `Content`.

## Стилизация

Стилизуйте Menu через `className` в React или `class` в Solid и Vue на экспортируемых частях.
Варианты Tailwind используют нативные utility-классы и классы потребителя. Варианты с CSS Modules берут
цвета, отступы и типографику из токенов foundation и выносят в CSS-переменные только ограничения ширины
содержимого и максимальную высоту viewport; остальное переопределяйте классом на части. Пункты, подписи
групп, разделители, отступы списка и анимация попапа также следуют общим переменным `--moduix-popup-*`.
`MenuTrigger` и `MenuContextTrigger` не стилизованы: собирайте триггер через `asChild` и `Button`, а
область контекстного меню оформляйте сами. Атрибуты состояния и хуки `data-slot` общие для обоих
вариантов стилизации.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `Enter` / `Space` | Открывает меню с кнопки или выбирает подсвеченный пункт. |
| `ArrowDown` / `ArrowUp` | Переводит подсветку на следующий или предыдущий пункт. |
| `ArrowRight` / `ArrowLeft` | Открывает или закрывает вложенное меню. |
| `Home` / `End` | Подсвечивает первый или последний пункт. |
| `Esc` | Закрывает меню и возвращает фокус на кнопку. |
| Буквы | Подсвечивает пункт, который начинается с набранного текста. |
