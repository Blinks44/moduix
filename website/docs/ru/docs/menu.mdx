## Анатомия

```text
Menu / Menu.Root
├─ Menu.Trigger
│  ├─ Menu.TriggerIcon
│  └─ Menu.Indicator
├─ Menu.ContextTrigger
└─ Ветка всплывающего слоя (автоматически переносится в портал)
   └─ Menu.Positioner
      └─ Menu.Content
         ├─ Menu.Arrow
         │  └─ Menu.ArrowTip
         ├─ Menu.Item
         │  ├─ Menu.ItemText
         │  │  ├─ Menu.ItemTextIcon
         │  │  └─ Menu.ItemTextLabel
         │  └─ Menu.ItemShortcut
         ├─ Menu.CheckboxItem
         │  └─ Menu.ItemIndicator
         ├─ Menu.RadioItemGroup
         │  └─ Menu.RadioItem
         ├─ Menu.ItemGroup
         │  └─ Menu.ItemGroupLabel
         ├─ Menu.Separator
         └─ Menu
            └─ Menu.TriggerItem
               └─ Menu.TriggerItemIcon
```

| Часть | Назначение |
| --- | --- |
| `Menu` / `Menu.Root` | Корневой компонент, который управляет открытием, позиционированием, поиском по начальным символам, фокусом и закрытием меню. |
| `Menu.RootProvider` | Подключает меню к экземпляру состояния, созданному с помощью `useMenu`. |
| `Menu.Trigger` | Кнопка, открывающая меню. Используйте `asChild`, чтобы передать другой семантический элемент. |
| `Menu.TriggerIcon` | Обёртка для иконки триггера. Если потомок не передан, отображается шеврон по умолчанию. |
| `Menu.Indicator` | Индикатор состояния триггера, обычно шеврон. |
| `Menu.ContextTrigger` | Триггер для контекстного меню по правому клику или долгому нажатию. |
| `Menu.Positioner` | Позиционирует плавающий слой меню. |
| `Menu.Content` | Всплывающая область с ролью `menu` и коллекцией пунктов. |
| `Menu.Arrow` / `Menu.ArrowTip` | Необязательная стрелка, визуально связывающая всплывающее меню с триггером. |
| `Menu.Item` | Обычный пункт, выполняющий команду. |
| `Menu.CheckboxItem` | Пункт с независимым логическим состоянием. |
| `Menu.RadioItemGroup` / `Menu.RadioItem` | Группа и пункты для выбора одного значения. |
| `Menu.ItemIndicator` | Индикатор выбора для пунктов с флажками и вариантами с единственным выбором. |
| `Menu.ItemText` и помощники для текста | Компоненты для текста пункта, иконки и подписи. |
| `Menu.ItemShortcut` | Обёртка для сочетания клавиш или другой подсказки справа. |
| `Menu.ItemGroup` / `Menu.ItemGroupLabel` | Группа и подпись для связанных пунктов. |
| `Menu.Separator` | Разделитель между группами пунктов. |
| `Menu.TriggerItem` / `Menu.TriggerItemIcon` | Пункт и иконка для открытия вложенного меню. |
| `Menu.ItemContext` | Передаёт состояние пункта его содержимому. |

## Композиция

`Menu` автоматически помещает `Menu.Positioner` в портал. Установите `portalled={false}`, чтобы отрисовать меню в текущем контейнере, или передайте `portalRef`, чтобы использовать определённый контейнер портала. `Menu.Positioner` и `Menu.Content` остаются явными частями, поэтому их можно независимо стилизовать и компоновать.

### Рекомендуемая композиция

Оставляйте структуру всплывающего меню видимой в коде. `Menu.Content` является частью содержимого Ark, а `Menu.Positioner` отвечает за отдельное позиционирование.

```tsx
import { Button } from '@moduix/react/button';
import { Menu } from '@moduix/react/menu';

export function ActionsMenu() {
  return (
    <Menu positioning={{ placement: 'bottom-start', gutter: 8 }}>
      <Menu.Trigger asChild>
        <Button>
          Actions
          <Menu.Indicator />
        </Button>
      </Menu.Trigger>
      <Menu.Positioner>
        <Menu.Content>
          <Menu.Item value="edit">Edit</Menu.Item>
        </Menu.Content>
      </Menu.Positioner>
    </Menu>
  );
}
```

### Когда нужна собственная композиция

Используйте `asChild`, если триггер, пункт или содержимое должны отображаться другим семантическим элементом. Передавайте ровно одного семантического потомка, чтобы Ark мог объединить его ARIA-атрибуты, обработчики событий и ref. Для ссылок указывайте `asChild` на `Menu.Item`, чтобы сама ссылка получила поведение пункта меню. Для собственного контейнера всплывающего меню указывайте `asChild` на `Menu.Content`.

Вложенное меню представляет собой обычный корневой `Menu` внутри содержимого родительского меню. Добавьте в него `Menu.TriggerItem`, а затем собственные `Menu.Positioner` и `Menu.Content`.

### Свойства по умолчанию

По умолчанию moduix добавляет содержимое всплывающего меню в DOM при первом открытии и удаляет его после анимации закрытия. Установите `unmountOnExit={false}`, чтобы сохранить содержимое в DOM после первого открытия. Указывайте одновременно `lazyMount={false}` и `unmountOnExit={false}` только если содержимое нужно отрисовать сразу и оставить в DOM.

| Свойство или часть | По умолчанию | Примечания |
| --- | --- | --- |
| `lazyMount` | `true` | Откладывает монтирование всплывающего меню до первого открытия. |
| `unmountOnExit` | `true` | Удаляет всплывающее меню после анимации закрытия. |
| `closeOnSelect` | `true` | Значение Ark по умолчанию. Установите `false`, если пользователь должен выбрать несколько пунктов до закрытия меню. |
| `loopFocus` | `false` | Значение Ark по умолчанию. При навигации с клавиатуры фокус не переходит с последнего пункта на первый. |
| `typeahead` | `true` | Значение Ark по умолчанию. Ввод печатных символов переводит подсветку на подходящий пункт. |
| `indicator` у `Menu.CheckboxItem` / `Menu.RadioItem` | `start` | Свойство только moduix, которое управляет столбцом индикатора. При необходимости используйте `end` или `none`. |

### Особенности поведения

- Управляйте меню с помощью `open`, `defaultOpen` и `onOpenChange(details)`. Колбэк получает объект с деталями Ark.
- Используйте `value` для идентификации пункта. Свойство `valueText` позволяет задать отдельный текст для поиска по начальным символам. Не задавайте пунктам произвольные значения `id`: Ark сам создаёт эти идентификаторы и использует их внутри компонента.
- Используйте `highlightedValue` и `onHighlightChange(details)`, чтобы управлять подсветкой пункта или реагировать на её изменение. Свойство `present` нужно только для внешнего управления жизненным циклом уже смонтированного содержимого.
- `onSelect(details)` на корневом компоненте вызывается при выборе любого пункта. У отдельных пунктов также есть собственные обработчики `onSelect`.
- `Menu.CheckboxItem.onCheckedChange` получает новое логическое значение состояния.
- `Menu.RadioItemGroup.onValueChange` получает объект с деталями. Выбранное значение находится в `details.value`.
- Для нескольких триггеров используйте `triggerValue`, `defaultTriggerValue` и `onTriggerValueChange(details)`, если активный триггер нужно контролировать или отслеживать.
- Используйте `Menu.RootProvider` с экземпляром `useMenu`, если коду за пределами дерева компонентов нужен доступ к API меню. Не создавайте второй корневой компонент для того же экземпляра состояния.
- `Menu.Context`, `useMenuContext`, `Menu.ItemContext` и `useMenuItemContext` открывают доступ к состоянию для расширенной композиции.
- Корневой компонент автоматически помещает `Menu.Positioner` в портал. Используйте `portalled={false}` внутри диалога или прокручиваемого контейнера. Если контейнер прокручивается, добавьте `positioning={{ strategy: 'fixed', hideWhenDetached: true }}`.
- `Menu.ContextTrigger` открывает меню по правому клику, а на сенсорных устройствах и при использовании пера также после долгого нажатия примерно 700 мс.
- Анимации открытия и закрытия учитывают настройку `prefers-reduced-motion`.
- В moduix есть `tone="destructive"` для опасных действий и вспомогательные компоненты `Menu.TriggerIcon`, `Menu.TriggerItemIcon`, `Menu.ItemTextContent`, `Menu.ItemTextIcon`, `Menu.ItemTextLabel` и `Menu.ItemShortcut`.

### Хуки стилизации

Используйте атрибуты состояния Ark, чтобы стилизовать меню и его пункты:

- Атрибуты Ark: `[data-scope='menu']`, `[data-part='trigger']`, `[data-part='indicator']`, `[data-part='content']`, `[data-part='item']`, `[data-type='checkbox' | 'radio']`, `[data-state='open' | 'closed' | 'checked' | 'unchecked']`, `[data-current]`, `[data-highlighted]`, `[data-disabled]`, `[data-placement]` и `[data-side]`.
- Атрибуты moduix: `[data-slot='menu-trigger']`, `[data-slot='menu-trigger-icon']`, `[data-slot='menu-indicator']`, `[data-slot='menu-context-trigger']`, `[data-slot='menu-positioner']`, `[data-slot='menu-content']`, `[data-slot='menu-arrow']`, `[data-slot='menu-arrow-tip']`, `[data-slot='menu-item']`, `[data-slot='menu-trigger-item']`, `[data-slot='menu-trigger-item-icon']`, `[data-slot='menu-separator']`, `[data-slot='menu-item-group']`, `[data-slot='menu-item-group-label']`, `[data-slot='menu-radio-item-group']`, `[data-slot='menu-radio-item']`, `[data-slot='menu-checkbox-item']`, `[data-slot='menu-item-indicator']`, `[data-slot='menu-item-text']`, `[data-slot='menu-item-text-content']`, `[data-slot='menu-item-text-icon']`, `[data-slot='menu-item-text-label']`, `[data-slot='menu-item-shortcut']` и `[data-indicator-position='start' | 'end' | 'none']`.
- Переменные позиционирования: `--reference-width`, `--available-width`, `--available-height`, `--transform-origin`, `--layer-index`, `--arrow-size` и `--arrow-background`.
