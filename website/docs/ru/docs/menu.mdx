## Выбор подходящего компонента

Используйте `Menu` для списков команд, привязанных к триггеру, контекстных меню, простого выбора и
вложенных действий.

- Выбирайте **`Menu`** для действий переполнения, действий строки и списков команд, открываемых кнопкой или контекстным триггером.

## Базовый пример

поиска по вводу элементы используют стабильные идентификаторы `value`.

## Анатомия

```text
Menu
├─ Menu.Trigger
│  └─ Menu.Indicator
├─ Menu.ContextTrigger
├─ Поддерево оверлея (автоматически портируется)
│  └─ Menu.Positioner
│     └─ Menu.Content
│        ├─ Menu.Arrow
│        │  └─ Menu.ArrowTip
│        ├─ Menu.Item
│        ├─ Menu.CheckboxItem
│        │  ├─ Menu.ItemIndicator
│        │  └─ Menu.ItemText
│        ├─ Menu.RadioItemGroup
│        │  └─ Menu.RadioItem
│        ├─ Menu.ItemGroup
│        │  └─ Menu.ItemGroupLabel
│        └─ Menu
│           └─ Menu.TriggerItem
```

| Часть                  | Назначение                                                        |
| --------------------- | ----------------------------------------------------------------- |
| `Menu` / `Menu.Root`  | Корневой элемент Ark для состояния открытия, позиционирования, поиска по вводу и закрытия. |
| `Menu.RootProvider`   | Отрисовывает меню из экземпляра состояния `useMenu`.             |
| `Menu.Trigger`        | Триггер-кнопка; используйте `asChild` для пользовательского хоста. |
| `Menu.Indicator`      | Индикатор триггера Ark, учитывающий состояние.                   |
| `Menu.ContextTrigger` | Триггер по правому клику и долгому нажатию для контекстных меню. |
| `Menu.Positioner`     | Позиционер плавающего слоя.                                      |
| `Menu.Content`        | Всплывающая поверхность с ролью меню и коллекцией элементов.     |
| `Menu.Item`           | Строка команды.                                                   |
| `Menu.CheckboxItem`   | Элемент логического параметра.                                   |
| `Menu.RadioItemGroup` | Группа одного выбранного значения для radio-элементов.            |
| `Menu.RadioItem`      | Элемент взаимоисключающего параметра.                             |
| `Menu.TriggerItem`    | Строка, открывающая вложенное `Menu`.                             |
| `Menu.ItemIndicator`  | Индикатор галочки для строк checkbox и radio.                     |

## Композиция

Корневой элемент автоматически портирует `Positioner`. Используйте `portalled={false}` для встроенного рендеринга и
`portalRef` для пользовательского контейнера; структурные части остаются явными и доступными для стилизации.

### Рекомендуемая композиция

Сохраняйте структуру всплывающего окна явной. `Menu.Content` - фактическая часть содержимого Ark; `Menu.Positioner`
остаётся отдельной частью.

```tsx
<Menu positioning={{ placement: 'bottom-start', gutter: 8 }}>
  <Menu.Trigger asChild>
    <Button>
      Actions
      <Menu.Indicator />
    </Button>
  </Menu.Trigger>
  <Menu.Positioner>
    <Menu.Content className="menu-content">
      <Menu.Item value="edit">Edit</Menu.Item>
    </Menu.Content>
  </Menu.Positioner>
</Menu>
```

### Когда нужна собственная композиция

Используйте `asChild`, когда триггер, элемент или содержимое должны отрисовываться другим семантическим
элементом. Передайте одного семантического потомка, чтобы Ark мог применить правильные ARIA-атрибуты,
фокус и поведение клавиатуры. Для ссылок ставьте `asChild` на `Menu.Item`; для пользовательского хоста
всплывающего окна - на `Menu.Content`.

Вложенные меню - обычные корни `Menu` внутри содержимого родительского меню. Вложенный корневой элемент использует
`Menu.TriggerItem`, затем собственные `Menu.Positioner` и `Menu.Content`.

### Свойства по умолчанию

Содержимое портированного оверлея по умолчанию лениво монтируется и размонтируется после анимации закрытия.
Установите `unmountOnExit={false}`, чтобы сохранить его после первого открытия; устанавливайте оба пропа
жизненного цикла в `false`, только когда нужен начальный рендеринг без задержки.

| Поверхность                       | По умолчанию | Примечания                                                  |
| --------------------------------- | ------------ | ----------------------------------------------------------- |
| `Menu` / `Menu.Root`              | -            | Дополнительных поведенческих значений нет; применяются значения Ark. |
| `Menu.CheckboxItem` / `RadioItem` | `start`      | `indicator` управляет позицией столбца индикатора.          |

### Особенности поведения

- В moduix свойства `lazyMount` и `unmountOnExit` по умолчанию равны `true`. Свойства `open`, `defaultOpen`, `onOpenChange(details)`, `highlightedValue`, `onHighlightChange(details)`, `onSelect(details)`, `closeOnSelect`, `ids` и `present` передаются в Ark без дополнительных значений по умолчанию.
- Для идентичности элемента меню используйте `value`, а не пользовательский `id`.
- `Menu.CheckboxItem.onCheckedChange` получает следующее логическое выбранное состояние.
- `Menu.RadioItemGroup.onValueChange` получает `details.value`.
- `Menu.RootProvider` нужно использовать с экземпляром `useMenu`, а не отрисовывать второй корневой элемент `Menu` для того же состояния.
- `Menu.Context`, `useMenuContext` и `useMenuItemContext` предоставляют состояние Ark потомкам для расширенной композиции.
- Корни автоматически портируют `Menu.Positioner`. Используйте `portalled={false}`, чтобы оставить меню внутри диалога или контейнера прокрутки, и сочетайте с `positioning={{ strategy: 'fixed', hideWhenDetached: true }}`, если контейнер прокручивается.
- Анимации открытия и закрытия учитывают `prefers-reduced-motion`.
- `Menu.Indicator` повторяет часть индикатора Ark. `Menu.TriggerIcon`, `Menu.TriggerItemIcon`, `Menu.ItemShortcut` и помощники текста элемента - только leaf-сокращения moduix.

- Переменные Ark: `--reference-width`, `--available-width`, `--available-height`, `--transform-origin`, `--layer-index`, `--arrow-size` и `--arrow-background`.
- Хуки moduix: `data-slot="menu-trigger"`, `menu-content`, `menu-item`, `menu-checkbox-item`, `menu-radio-item`, `menu-trigger-item`, `menu-item-indicator` и `menu-item-shortcut`.
