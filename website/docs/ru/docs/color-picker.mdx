## Выбор подходящего компонента

Выбирайте `ColorPicker`, когда пользователю нужно выбрать цвет или точно его настроить. Если достаточно ввести заранее
известное значение без редактирования самого цвета, используйте `Input`.

## Базовый пример

Начните с компактного поля: добавьте корневой компонент, поле одного канала, стандартный цветовой образец в кнопке
открытия и явное содержимое всплывающего окна. Внутренние части селектора можно оставить без дочерних элементов,
тогда компонент подставит их встроенную разметку. Явно добавьте `ColorPickerHiddenInput` и передайте
`name`, если цвет нужно отправлять вместе с формой.

## Анатомия

```text
ColorPicker
├─ ColorPickerLabel
├─ ColorPickerControl
│  ├─ ColorPickerChannelInput[channel]
│  └─ ColorPickerTrigger
│     └─ ColorPickerValueSwatch
├─ Ветка всплывающего окна (по умолчанию выводится через портал)
│  └─ ColorPickerPositioner
│     └─ ColorPickerContent
│        ├─ ColorPickerArea
│        │  ├─ ColorPickerAreaBackground
│        │  └─ ColorPickerAreaThumb
│        ├─ ColorPickerEyeDropperTrigger
│        ├─ ColorPickerChannelSlider[channel]
│        │  ├─ ColorPickerTransparencyGrid
│        │  ├─ ColorPickerChannelSliderTrack
│        │  └─ ColorPickerChannelSliderThumb
│        ├─ ColorPickerSwatchGroup
│        │  └─ ColorPickerSwatchTrigger[value]
│        │     └─ ColorPickerSwatch[value]
│        │        └─ ColorPickerSwatchIndicator
│        └─ ColorPickerView[format]
│           └─ ColorPickerChannelInput[channel]
└─ ColorPickerHiddenInput (явно)
```

| Часть | Назначение |
| --- | --- |
| `ColorPicker` | Хранит выбранный цвет и его формат, управляет открытием всплывающего окна и связывает компонент с формой. |
| `ColorPickerHiddenInput` | Нативное поле Ark; правила явной композиции описаны ниже. |
| `ColorPickerLabel` | Доступная подпись видимых элементов управления. |
| `ColorPickerControl` | Объединяет видимые поля ввода и кнопку открытия. |
| `ColorPickerTrigger` | Кнопка, которая открывает всплывающее окно и по умолчанию показывает образец текущего цвета. |
| `ColorPickerPositioner` | Плавающий слой, который позиционирует всплывающее окно и предоставляет CSS-переменные позиционирования Ark. |
| `ColorPickerContent` | Содержимое всплывающего окна на базе Ark. |
| `ColorPickerArea` | Двумерная область для выбора цвета. |
| `ColorPickerAreaBackground` | Фоновый слой, который обрабатывает ввод указателя в области выбора цвета. |
| `ColorPickerEyeDropperTrigger` | Пипетка для снятия цвета с экрана; отображается только там, где браузер поддерживает EyeDropper API. |
| `ColorPickerChannelSlider` | Одномерный регулятор для оттенка, альфа-канала или другого канала. |
| `ColorPickerTransparencyGrid` | Шахматный фон, который делает альфа-канал видимым за дорожкой слайдера канала. Свотчи рисуют шахматку сами. |
| `ColorPickerSliders` | Готовая пара слайдеров для оттенка и альфа-канала. |
| `ColorPickerChannelInput` | Текстовое или числовое поле для отдельного канала цвета. |
| `ColorPickerSwatchTrigger` | Кнопка выбора готового цвета. |
| `ColorPickerSwatch` | Цветная поверхность внутри кнопки-образца или образца текущего значения. |
| `ColorPickerSwatchIndicator` | Необязательный маркер внутри образца, например галочка у выбранного готового цвета. |
| `ColorPickerValueSwatch` | Показывает образец текущего цвета. |
| `ColorPickerValueText` | Текст только для чтения с форматированным значением. |

`ColorPickerRootProvider`, `parseColor`, `useColorPicker` и `useColorPickerContext` подходят для типичных расширенных
сценариев управления состоянием.

## Композиция

Используйте `defaultValue` для локального состояния. Если выбранный цвет или состояние открытия должны храниться в состоянии приложения, передайте `value` с `onValueChange(details)` или `open` с `onOpenChange(details)`. Во Vue то же состояние привязывается нативно через `v-model`, `v-model:open` и `v-model:format`. Если состояние создаётся вне дерева рендера, передайте результат `useColorPicker()` в `ColorPickerRootProvider`; для одного хранилища не рендерьте одновременно `ColorPicker` и `ColorPickerRootProvider`.

`ColorPickerPositioner` по умолчанию рендерится через портал. Укажите `portalled={false}`, если оверлей должен находиться в другом контексте наложения. Чтобы отправить цвет в нативной форме, задайте `name` у корня и явно добавьте `ColorPickerHiddenInput`. `ColorPickerArea`, `ColorPickerChannelSlider` и `ColorPickerSwatchTrigger` сами добавляют стандартные визуальные части; передавайте дочерние элементы только при изменении их структуры.

В Solid назначьте ref элементу, созданному внутри функции рендера `asChild`: ref на самой части
ColorPicker через этот путь композиции не пробрасывается. Во Vue используйте обычный шаблонный
`ref` на части и читайте отрендеренный элемент через `$el`.

## Примеры

### Область и слайдеры

Используйте эту компактную композицию, если пользователям нужны область выбора цвета и слайдеры каналов, но не нужны
поля для ввода каналов с клавиатуры.

<Example name="color-picker/slider-only" />

### Компактная кнопка открытия

Используйте `data-fit-content` на `ColorPickerTrigger`, если кнопка по размеру содержимого удобнее квадратного
образца. Такой вариант подходит, например, для замены цветового поля на основе кнопки.

<Example name="color-picker/compact-trigger" />

### Управляемое значение

Используйте управляемое значение, когда выбранный цвет должен оставаться синхронизированным с состоянием приложения.

<Example name="color-picker/controlled" />

### Отключённый компонент

Задайте `disabled` на корневом компоненте, если все части выбора цвета должны стать недоступными для взаимодействия, но
текущий цвет должен остаться видимым.

<Example name="color-picker/disabled" />

### Состояние поля

Используйте свойства состояния формы корневого компонента, например `required` и `invalid`, если селектор находится
внутри контейнера поля и должен передавать это состояние через атрибуты данных Ark.

<Example name="color-picker/field-state" />

### Использование в форме

Передайте `name` в `ColorPicker` и явно добавьте `ColorPickerHiddenInput`.

<Example name="color-picker/form-usage" />

### Представления формата

Используйте `format`, `onFormatChange`, `ColorPickerFormatSelect` и `ColorPickerView`, если пользователям нужно переключаться между группами
полей каналов без изменения структуры селектора. `ColorPickerFormatSelect` сохраняет нативный селектор формата Ark, а его
свёрнутый вид оформлен в стиле поля `Select` из moduix и единообразно показывает варианты RGBA, HSLA и HSBA. Список
вариантов открывает браузер.

<Example name="color-picker/format-views" />

### Встроенный режим

Используйте `inline` в панелях настроек, если инструменты работы с цветом должны оставаться видимыми без кнопки открытия
всплывающего окна.

<Example name="color-picker/inline" />

### Только ввод

Используйте поля каналов с пассивным образцом, если важен ввод цвета с клавиатуры, а всплывающее окно только усложнит
интерфейс.

<Example name="color-picker/input-only" />

### Внутри Dialog

Если селектор находится внутри модального диалога, отключите портал у всплывающего окна. Тогда оно останется в том же
контексте наложения, что и диалог, и будет интерактивным поверх его содержимого.

<Example name="color-picker/inside-dialog" />

### Управляемое открытие

Используйте управляемое состояние `open`, если другой элемент управления или сценарий отвечает за видимость
всплывающего окна.

<Example name="color-picker/open-controlled" />

### Root Provider

Используйте `useColorPicker` из moduix вместе с `ColorPickerRootProvider`, если состояние селектора нужно создать вне дерева
компонентов и разделить с соседними элементами управления.

<Example name="color-picker/root-provider" />

### Только цветовые образцы

Используйте композицию только с образцами, если достаточно готовой палитры и не нужны область, слайдеры и поля ввода.

<Example name="color-picker/swatch-only" />

### Готовые цвета

Добавьте образцы во всплывающее окно, если селектор должен предлагать готовую палитру вместе со свободным редактированием.
`closeOnSelect` сохраняет поведение Ark и закрывает окно после выбора образца.

<Example name="color-picker/swatches" />

### Текущее значение

Используйте `ColorPickerValueSwatch` и `ColorPickerValueText`, если соседнему интерфейсу нужно показать выбранный цвет без открытия полного
селектора.

<Example name="color-picker/value-swatch" />

### Расширенная настройка

Используйте явные части и дочерние элементы, если встроенной композиции недостаточно и нужна другая визуальная структура.

## Стилизация

Используйте `className` в React и `class` в Solid и Vue для экспортируемых частей. Варианты Tailwind используют классы-утилиты и классы приложения, а варианты CSS Modules дают короткий список переменных `--moduix-color-picker-*` для размеров, общих для нескольких частей или дочерних элементов по умолчанию; цвета, отступы и типографика берутся из токенов foundation, их меняют классом на нужной части. Обе стилистические версии предоставляют стабильные хуки `data-slot="color-picker-*"` и атрибуты Ark `data-scope` / `data-part`.

### Точки стилизации

Используйте часть, которая отвечает за нужный визуальный аспект:

- `ColorPicker` - для ширины, отступов, цвета текста и прозрачности отключённого состояния;
- `ColorPickerControl`, `ColorPickerChannelInput`, `ColorPickerTrigger`, `ColorPickerFormatSelect` и `ColorPickerFormatTrigger` - для видимых элементов поля;
- `ColorPickerPositioner` и `ColorPickerContent` - для слоя, ширины, отступов, скругления, тени и анимаций состояния
  всплывающего окна;
- `ColorPickerArea`, `ColorPickerAreaBackground` и `ColorPickerAreaThumb` - для двумерной области выбора цвета;
- `ColorPickerChannelSlider`, `ColorPickerChannelSliderTrack`, `ColorPickerChannelSliderThumb` и `ColorPickerSliders` - для слайдеров оттенка,
  альфа-канала и других каналов;
- `ColorPickerSwatchGroup`, `ColorPickerSwatchTrigger`, `ColorPickerSwatch` и `ColorPickerSwatchIndicator` - для сеток готовых цветов;
- `ColorPickerValueSwatch`, `ColorPickerValueText`, `ColorPickerView` и `ColorPickerTransparencyGrid` - для отображения значения и раскладки
  выбранного формата.

Основные атрибуты состояния: `data-state`, `data-focus`, `data-invalid`, `data-disabled`, `data-readonly`,
`data-required`, `data-channel`, `data-orientation`, `data-value`, `data-placement` и `data-side`. Переменные Ark,
доступные во время работы, включают `--color`, `--value`, `--available-width`, `--available-height` и
`--transform-origin`.

При включённом `prefers-reduced-motion` анимации появления и закрытия всплывающего окна отключаются; Ark
по-прежнему завершает жизненный цикл закрытия.
