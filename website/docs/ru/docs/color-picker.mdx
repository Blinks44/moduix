## Выбор подходящего компонента

Выбирайте `ColorPicker`, когда пользователю нужно выбрать цвет или точно его настроить. Если достаточно ввести заранее
известное значение без редактирования самого цвета, используйте `Input`.

## Базовый пример

тогда компонент подставит их встроенную разметку. Компонент также автоматически рендерит скрытое нативное поле.

## Анатомия

```text
ColorPicker
├─ ColorPicker.Label
├─ ColorPicker.Control
│  ├─ ColorPicker.ChannelInput[channel]
│  └─ ColorPicker.Trigger
│     ├─ ColorPicker.TransparencyGrid
│     └─ ColorPicker.ValueSwatch
├─ Ветка всплывающего окна (по умолчанию выводится через портал)
│  └─ ColorPicker.Positioner
│     └─ ColorPicker.Content
│        ├─ ColorPicker.Area
│        │  ├─ ColorPicker.AreaBackground
│        │  └─ ColorPicker.AreaThumb
│        ├─ ColorPicker.EyeDropperTrigger
│        ├─ ColorPicker.ChannelSlider[channel]
│        │  ├─ ColorPicker.TransparencyGrid
│        │  ├─ ColorPicker.ChannelSliderTrack
│        │  └─ ColorPicker.ChannelSliderThumb
│        ├─ ColorPicker.SwatchGroup
│        │  └─ ColorPicker.SwatchTrigger[value]
│        │     └─ ColorPicker.Swatch[value]
│        │        └─ ColorPicker.SwatchIndicator
│        └─ ColorPicker.View[format]
│           └─ ColorPicker.ChannelInput[channel]
└─ скрытое нативное поле (добавляется автоматически)
```

| Часть | Назначение |
| --- | --- |
| `ColorPicker` | Хранит выбранный цвет и его формат, управляет открытием всплывающего окна и связывает компонент с формой. |
| `ColorPicker.Control` | Объединяет видимые поля ввода и кнопку открытия. |
| `ColorPicker.Trigger` | Кнопка, которая открывает всплывающее окно и по умолчанию показывает образец текущего цвета. |
| `ColorPicker.Content` | Содержимое всплывающего окна на базе Ark. |
| `ColorPicker.Area` | Двумерная область для выбора цвета. |
| `ColorPicker.ChannelSlider` | Одномерный регулятор для оттенка, альфа-канала или другого канала. |
| `ColorPicker.Sliders` | Готовая пара слайдеров для оттенка и альфа-канала. |
| `ColorPicker.ChannelInput` | Текстовое или числовое поле для отдельного канала цвета. |
| `ColorPicker.SwatchTrigger` | Кнопка выбора готового цвета. |
| `ColorPicker.ValueSwatch` | Показывает образец текущего цвета. |

`ColorPicker.RootProvider`, `parseColor`, `useColorPicker` и `useColorPickerContext` подходят для типичных расширенных
сценариев управления состоянием. Вспомогательные типы Ark импортируйте напрямую только при необходимости.

## Композиция

По умолчанию `ColorPicker.Positioner` выводится через портал. Задайте `portalled={false}`, чтобы отобразить его в
текущей структуре документа, или передайте `portalRef`, чтобы использовать собственный контейнер. Структурные части
остаются явными и доступны для стилизации.

### Рекомендуемая композиция

В варианте со всплывающим окном явно добавьте `ColorPicker.Positioner` и `ColorPicker.Content`. `Content` содержит
всплывающее окно Ark, а `Positioner` отвечает за его размещение.

Оставьте `Trigger`, `Area`, `ChannelSlider` и `SwatchTrigger` без дочерних элементов, чтобы использовать встроенную
разметку. Для обычной пары слайдеров оттенка и альфа-канала используйте `ColorPicker.Sliders`. Стилизуйте каналы
через `data-channel` или CSS-переменные. Дочерние элементы добавляйте только тогда, когда нужна собственная структура
части. Задайте `data-fit-content`, если размер кнопки открытия должен определяться содержимым, например образцом и
`ValueText`.

Чтобы цвет участвовал в отправке и сбросе формы, передайте `name` в `ColorPicker`. Компонент автоматически создаёт и
синхронизирует нативное поле, поэтому для `FormData` и `form.reset()` не нужна дополнительная настройка.

### Когда нужна собственная композиция

Используйте `inline`, если область, слайдеры, поля и образцы должны постоянно оставаться видимыми в панели, а не
открываться во всплывающем окне. С помощью `ColorPicker.View` можно показывать поля только одного формата за раз.

Используйте `useColorPicker` вместе с `ColorPicker.RootProvider`, если состояние нужно создать вне дерева, в котором
рендерируется компонент. Не рендерьте `Root` и `RootProvider` для одного экземпляра состояния.

Используйте `asChild` на экспортируемых частях Ark, если DOM-узлом должен стать другой семантический элемент. Дочерний
элемент должен быть единственным и сохранять необходимое поведение фокуса и взаимодействия.

### Свойства по умолчанию

По умолчанию содержимое всплывающего окна монтируется при первом открытии, а после анимации закрытия удаляется. Задайте
`unmountOnExit={false}`, чтобы не удалять его после первого открытия. Отключайте оба параметра жизненного цикла только
тогда, когда компонент нужно отрендерить сразу, ещё до первого открытия.

| Часть или свойство | Значение по умолчанию | Описание |
| --- | --- | --- |
| `defaultValue` | `parseColor("#000000")` | Начальное значение цвета Ark. |
| `defaultFormat` | `"rgba"` | Начальный формат Ark. |
| Ширина `ColorPicker.Content` | `16rem` | Не позволяет окну сжаться до ширины образца в кнопке открытия. |
| `ColorPicker.EyeDropperTrigger` | Встроенная иконка пипетки moduix | Используется, если дочерние элементы не переданы. |
| Дочерние элементы `ColorPicker.Trigger` | Образец текущего цвета | Рендерятся `TransparencyGrid` и `ValueSwatch`. |
| Дочерние элементы `ColorPicker.Area` | Фон и ползунок | Используются, если дочерние элементы не переданы. |
| Дочерние элементы `ColorPicker.ChannelSlider` | Дорожка и ползунок | Слайдеры альфа-канала также рендерят `TransparencyGrid`. |
| `ColorPicker.Sliders` | Пара слайдеров оттенка и альфа-канала | Стилизуйте через `data-channel` или CSS-переменные. |
| Дочерние элементы `ColorPicker.SwatchTrigger` | Образец и индикатор | Для образца используется значение `value` триггера. |
| `ColorPicker.SwatchIndicator` | Встроенная иконка галочки moduix | Используется, если дочерние элементы не переданы. |
| Ширина `ColorPicker` | `16rem` (макс. `100%`) | Ширина компонента по умолчанию. |

### Особенности поведения

- `value` и `defaultValue` принимают объекты `Color` из Ark. Для строковых значений используйте `parseColor()`.
- `onValueChange(details)` и `onValueChangeEnd(details)` передают объект `details` в формате Ark.
- `onFormatChange(details)` и `onOpenChange(details)` также передают объект `details` в формате Ark.
- Параметр `ids` передаётся в Ark, чтобы использовать общие идентификаторы доступности в собственных композициях.
- Компонент поддерживает состояние поля и группы полей через совместимые с Ark свойства корневого компонента:
  `disabled`, `invalid`, `required` и `readOnly`.
- Используйте `positioning`, `initialFocusEl` и `openAutoFocus`, если размещение окна или начальный фокус должны
  соответствовать окружающему сценарию.
- `lazyMount` и `unmountOnExit` по умолчанию равны `true`. Параметры `present` и `onExitComplete` позволяют вручную
  управлять монтированием и анимацией закрытия.
- Все части Ark, которые рендерят DOM-элемент, поддерживают `asChild`.

### Точки стилизации

Используйте часть, которая отвечает за нужный визуальный аспект:

- `ColorPicker` - для ширины, отступов, цвета текста и прозрачности отключённого состояния;
- `ColorPicker.Control`, `ChannelInput`, `Trigger`, `FormatSelect` и `FormatTrigger` - для видимых элементов поля;
- `ColorPicker.Positioner` и `ColorPicker.Content` - для слоя, ширины, отступов, скругления, тени и анимаций состояния
  всплывающего окна;
- `ColorPicker.Area`, `AreaBackground` и `AreaThumb` - для двумерной области выбора цвета;
- `ColorPicker.ChannelSlider`, `ChannelSliderTrack`, `ChannelSliderThumb` и `Sliders` - для слайдеров оттенка,
  альфа-канала и других каналов;
- `ColorPicker.SwatchGroup`, `SwatchTrigger`, `Swatch` и `SwatchIndicator` - для сеток готовых цветов;
- `ColorPicker.ValueSwatch`, `ValueText`, `View` и `TransparencyGrid` - для отображения значения и раскладки
  выбранного формата.

Основные атрибуты состояния: `data-state`, `data-focus`, `data-invalid`, `data-disabled`, `data-readonly`,
`data-required`, `data-channel`, `data-orientation`, `data-value`, `data-placement` и `data-side`. Переменные Ark,
доступные во время работы, включают `--color`, `--value`, `--available-width`, `--available-height` и
`--transform-origin`.

При включённом `prefers-reduced-motion` анимации появления и закрытия всплывающего окна длятся 1 мс. Это позволяет Ark
завершить жизненный цикл закрытия без заметного движения.
