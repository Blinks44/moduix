## Выбор подходящего компонента

Выбирайте `ColorPicker`, когда пользователю нужно выбрать цвет или точно его настроить. Если достаточно ввести заранее
известное значение без редактирования самого цвета, используйте `Input`.

## Анатомия

```text
ColorPicker / ColorPicker.Root
├─ ColorPicker.Label
├─ ColorPicker.Control
│  ├─ ColorPicker.ChannelInput[channel]
│  └─ ColorPicker.Trigger
│     ├─ ColorPicker.TransparencyGrid
│     └─ ColorPicker.ValueSwatch
├─ Ветка всплывающего окна (по умолчанию выводится через портал)
│  └─ ColorPicker.Positioner
│     └─ ColorPicker.Content
│        ├─ ColorPicker.Area
│        │  ├─ ColorPicker.AreaBackground
│        │  └─ ColorPicker.AreaThumb
│        ├─ ColorPicker.EyeDropperTrigger
│        ├─ ColorPicker.ChannelSlider[channel]
│        │  ├─ ColorPicker.TransparencyGrid
│        │  ├─ ColorPicker.ChannelSliderTrack
│        │  └─ ColorPicker.ChannelSliderThumb
│        ├─ ColorPicker.SwatchGroup
│        │  └─ ColorPicker.SwatchTrigger[value]
│        │     └─ ColorPicker.Swatch[value]
│        │        └─ ColorPicker.SwatchIndicator
│        └─ ColorPicker.View[format]
│           └─ ColorPicker.ChannelInput[channel]
└─ ColorPicker.HiddenInput (явно)
```

| Часть | Назначение |
| --- | --- |
| `ColorPicker` / `ColorPicker.Root` | Хранит выбранный цвет и его формат, управляет открытием всплывающего окна и связывает компонент с формой. |
| `ColorPicker.HiddenInput` | Нативное поле Ark; правила явной композиции описаны ниже. |
| `ColorPicker.Control` | Объединяет видимые поля ввода и кнопку открытия. |
| `ColorPicker.Trigger` | Кнопка, которая открывает всплывающее окно и по умолчанию показывает образец текущего цвета. |
| `ColorPicker.Content` | Содержимое всплывающего окна на базе Ark. |
| `ColorPicker.Area` | Двумерная область для выбора цвета. |
| `ColorPicker.ChannelSlider` | Одномерный регулятор для оттенка, альфа-канала или другого канала. |
| `ColorPicker.Sliders` | Готовая пара слайдеров для оттенка и альфа-канала. |
| `ColorPicker.ChannelInput` | Текстовое или числовое поле для отдельного канала цвета. |
| `ColorPicker.SwatchTrigger` | Кнопка выбора готового цвета. |
| `ColorPicker.ValueSwatch` | Показывает образец текущего цвета. |

`ColorPicker.RootProvider`, `parseColor`, `useColorPicker` и `useColorPickerContext` подходят для типичных расширенных
сценариев управления состоянием. Вспомогательные типы Ark импортируйте напрямую только при необходимости.

## Композиция

Используйте `defaultValue` для локального состояния. Если выбранный цвет или состояние открытия должны храниться в состоянии приложения, передайте `value` с `onValueChange(details)` или `open` с `onOpenChange(details)`. Если состояние создаётся вне дерева рендера, передайте результат `useColorPicker()` в `ColorPicker.RootProvider`; для одного хранилища не рендерьте одновременно `ColorPicker` и `ColorPicker.Root`.

`ColorPicker.Positioner` по умолчанию рендерится через портал. Укажите `portalled={false}`, если оверлей должен находиться в другом контексте наложения. Чтобы отправить цвет в нативной форме, задайте `name` у корня и явно добавьте `ColorPicker.HiddenInput`. `Area`, `ChannelSlider` и `SwatchTrigger` сами добавляют стандартные визуальные части; передавайте дочерние элементы только при изменении их структуры.

## Стилизация

Используйте `className` в React и `class` в Solid для экспортируемых частей. Варианты Tailwind используют классы-утилиты и классы приложения, а варианты CSS Modules настраиваются через публичные CSS-переменные `--moduix-color-picker-*`, указанные ниже. Обе стилистические версии предоставляют стабильные хуки `data-slot="color-picker-*"` и атрибуты Ark `data-scope` / `data-part`.

### Точки стилизации

Используйте часть, которая отвечает за нужный визуальный аспект:

- `ColorPicker` - для ширины, отступов, цвета текста и прозрачности отключённого состояния;
- `ColorPicker.Control`, `ChannelInput`, `Trigger`, `FormatSelect` и `FormatTrigger` - для видимых элементов поля;
- `ColorPicker.Positioner` и `ColorPicker.Content` - для слоя, ширины, отступов, скругления, тени и анимаций состояния
  всплывающего окна;
- `ColorPicker.Area`, `AreaBackground` и `AreaThumb` - для двумерной области выбора цвета;
- `ColorPicker.ChannelSlider`, `ChannelSliderTrack`, `ChannelSliderThumb` и `Sliders` - для слайдеров оттенка,
  альфа-канала и других каналов;
- `ColorPicker.SwatchGroup`, `SwatchTrigger`, `Swatch` и `SwatchIndicator` - для сеток готовых цветов;
- `ColorPicker.ValueSwatch`, `ValueText`, `View` и `TransparencyGrid` - для отображения значения и раскладки
  выбранного формата.

Основные атрибуты состояния: `data-state`, `data-focus`, `data-invalid`, `data-disabled`, `data-readonly`,
`data-required`, `data-channel`, `data-orientation`, `data-value`, `data-placement` и `data-side`. Переменные Ark,
доступные во время работы, включают `--color`, `--value`, `--available-width`, `--available-height` и
`--transform-origin`.

При включённом `prefers-reduced-motion` анимации появления и закрытия всплывающего окна длятся 1 мс. Это позволяет Ark
завершить жизненный цикл закрытия без заметного движения.
