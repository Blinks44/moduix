## Как выбрать компонент

Используйте `TagsInput`, когда пользователю нужно вводить и редактировать список строковых значений
в одном элементе управления формы.

- Выбирайте **`TagsInput`** для меток, навыков, фильтров, получателей, тем и других списков строк, которые пользователь вводит сам.
- Выбирайте **`Tag`**, когда интерфейс только показывает существующий токен и может предложить отдельное действие удаления.
- Выбирайте **`Combobox`**, когда пользователь выбирает значение из известного списка, а основное взаимодействие связано с фильтрацией.

### Разрешить дубликаты

Включите `allowDuplicates`, если одна и та же строка может появляться несколько раз.

### Управляемое состояние

Храните массив тегов в состоянии компонента, если от него зависит другая часть экрана или его нужно
сбрасывать программно.

<Example name="tags-input/controlled" />

### Управляемое значение поля ввода

Управляйте `inputValue` отдельно, если другой элемент интерфейса должен заранее заполнить или
очистить поле ввода.

<Example name="tags-input/controlled-input-value" />

### Разделитель и вставка

Используйте `delimiter` вместе с `addOnPaste`, если вставленный текст должен превратиться в несколько
тегов. В этом примере разделителями служат запятая, точка с запятой и пробел.

<Example name="tags-input/delimiter-and-paste" />

### Запретить редактирование

Задайте `editable={false}`, если существующие теги можно удалять, но нельзя редактировать на месте.

<Example name="tags-input/disable-editing" />

### Отключено и только для чтения

Используйте `disabled` для неинтерактивного поля. `readOnly` оставляет теги видимыми, но запрещает
добавлять, удалять и редактировать их.

<Example name="tags-input/disabled-and-read-only" />

### Field

Оберните `TagsInput` в `Field`, если подпись, поясняющий текст, невалидное состояние и сообщение об
ошибке должны использовать общую схему доступности форм Ark.

<Example name="tags-input/field" />

### Форма

Передайте корню `name` и добавьте `TagsInputHiddenInput`, чтобы список тегов попал в `FormData`.

<Example name="tags-input/form" />

### Максимум с превышением

Используйте `allowOverflow` вместе с `max`, если пользователь может временно превысить лимит, а поле
должно сообщить о невалидном состоянии.

<Example name="tags-input/max-with-overflow" />

### TagsInputRootProvider

Используйте `useTagsInput` с `TagsInputRootProvider`, когда состояние и императивные методы нужны за пределами
дерева отрисованного поля.

<Example name="tags-input/root-provider" />

### Нормализация и потеря фокуса

Используйте `sanitizeValue`, чтобы нормализовать вводимые теги, а `blurBehavior="add"`, чтобы добавить
текущее значение при потере фокуса.

<Example name="tags-input/sanitize-and-blur" />

### Проверка и максимум

Используйте `validate`, `max` и `onValueInvalid`, чтобы отклонять недопустимые значения и понимать
причину отказа. Добавьте `maxLength`, если поле не должно принимать слишком длинные значения до

### Вместе с Combobox

Объедините `TagsInput` с `Combobox`, если поле должно предлагать варианты из известного списка и
одновременно разрешать пользовательские теги. Используйте общие идентификаторы поля и элемента
управления и объединяйте поля через `asChild`.

### Расширенная настройка

Не используйте `TagsInputItems`, если каждому тегу нужны собственное содержимое или действия. Свяжите значения
корня с полной структурой частей и оставьте `TagsInputItemInput` внутри каждого тега, если редактирование на
месте всё ещё нужно.

## Композиция

Используйте короткую форму `<TagsInput>` для стандартной композиции. Оставьте `TagsInputItems`,
`TagsInputInput` и `TagsInputClearTrigger` внутри `TagsInputControl`. Добавьте
`TagsInputHiddenInput` явно и передайте корню `name`, если теги нужно отправлять с формой. Если
связанная форма находится вне дерева компонента, задайте `form`.

Для собственного содержимого или действий тегов используйте `TagsInputContext` и свяжите его
значения с `TagsInputItem`, передав `index` и `value`. Оставьте `TagsInputItemInput` внутри каждого
элемента, если нужно сохранить редактирование на месте. Используйте `TagsInputRootProvider` с
`useTagsInput()` только тогда, когда состояние или методы вроде `addValue`, `clearValue` и `focus`
нужны за пределами дерева компонента. В Solid store является accessor: читайте `tagsInput().value`
и вызывайте `tagsInput().addValue()`. При объединении с `Combobox` используйте общие идентификаторы
поля и элемента управления и объединяйте поля через `asChild`.

- Части Ark сохраняют `data-scope="tags-input"` и значения `data-part` из анатомии.
- Состояния можно стилизовать через `data-disabled`, `data-readonly`, `data-invalid`, `data-focus`, `data-empty`, `data-required`, `data-value` и `data-highlighted`, если Ark добавляет их к части.
- Кнопки удаления и очистки имеют стабильные `data-slot`. Для отдельного тега используется компактный значок закрытия, а очистка всех тегов использует оформление общей кнопки закрытия.
- CSS Modules дают три переменные: `--moduix-tags-input-width`, `--moduix-tags-input-min-height` и `--moduix-tags-input-radius`. Цвета, отступы, типографика и геометрия тегов берутся из токенов foundation; меняйте их классом на части. Варианты на Tailwind используют нативные утилиты и классы, которые задаёт потребитель.
- В режиме только для чтения moduix скрывает поле ввода, кнопки удаления тегов и кнопку очистки, оставляя видимыми только неизменяемые значения тегов.

## Доступность

Ark связывает подпись с полем, управляет выделением и редактированием тегов, удалением, вставкой и
скрытым полем формы. Явно добавленное скрытое поле сериализует список тегов для нативной отправки
формы. Передайте `name`, а при необходимости и `form`, чтобы связать его с формой.

### Поддержка клавиатуры

- `Enter` в поле ввода добавляет его текущее значение. `Enter` на выделенном теге переводит его в режим редактирования.
- Двойной щелчок по тегу также включает редактирование, если `editable` имеет значение `true`.
- Когда поле ввода пусто или курсор стоит в его начале, `ArrowLeft` и `ArrowRight` перемещают визуальный фокус между тегами.
- `Backspace` и `Delete` удаляют выделенный тег. `Backspace` также удаляет последний тег, если поле ввода пусто.
- При включённом `addOnPaste` сочетание `Control+V` добавляет вставленные значения после разделения их по `delimiter`.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `Enter` | Добавляет введённый текст как метку. |
| `ArrowLeft` / `ArrowRight` | Перемещает между метками, когда поле пустое. |
| `Backspace` / `Delete` | Подсвечивает, затем удаляет метку. |
| `Enter` на метке | Редактирует подсвеченную метку, если включён editable. |
