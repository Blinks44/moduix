## Как выбрать компонент

Используйте `TagsInput`, когда пользователю нужно вводить и редактировать список строковых значений
в одном элементе управления формы.

- Выбирайте **`TagsInput`** для меток, навыков, фильтров, получателей, тем и других списков строк, которые пользователь вводит сам.
- Выбирайте **`Tag`**, когда интерфейс только показывает существующий токен и может предложить отдельное действие удаления.
- Выбирайте **`Combobox`**, когда пользователь выбирает значение из известного списка, а основное взаимодействие связано с фильтрацией.

## Анатомия

```text
TagsInput / TagsInput.Root
├─ TagsInput.Label
├─ TagsInput.Control
│  ├─ TagsInput.Items
│  └─ TagsInput.Item[index, value]
│     ├─ TagsInput.ItemPreview
│     │  ├─ TagsInput.ItemText
│     │  └─ TagsInput.ItemDeleteTrigger
│     └─ TagsInput.ItemInput
│  ├─ TagsInput.Input
│  └─ TagsInput.ClearTrigger
└─ TagsInput.HiddenInput (explicit)

TagsInput.RootProvider
└─ same part tree connected to a useTagsInput() store
```

| Часть | Назначение |
| --- | --- |
| `TagsInput` / `TagsInput.Root` | Корень, который управляет состоянием, значениями тегов, вводом, проверкой и формой. |
| `TagsInput.RootProvider` | Подключает части к состоянию, которое вернул `useTagsInput()`. |
| `TagsInput.Label` | Доступная подпись поля тегов. |
| `TagsInput.Control` | Видимая область с тегами, полем ввода и кнопкой очистки. |
| `TagsInput.Items` | Стандартно отображает редактируемые теги из текущего состояния. |
| `TagsInput.Item` | Один тег. Передайте `index` и `value` для собственных элементов. |
| `TagsInput.ItemPreview` | Отображает тег вне режима редактирования. |
| `TagsInput.ItemText` | Видимый текст тега. |
| `TagsInput.ItemDeleteTrigger` | Удаляет один тег и по умолчанию показывает компактный значок закрытия. |
| `TagsInput.ItemInput` | Поле для редактирования тега на месте. |
| `TagsInput.Input` | Поле ввода новых тегов. |
| `TagsInput.ClearTrigger` | Удаляет все теги и по умолчанию использует оформление общей кнопки закрытия. |
| `TagsInput.HiddenInput` | Явно добавляемое нативное поле для отправки формы. |
| `TagsInput.Context` | Render prop с доступом к состоянию корня внутри дерева компонента. |

## Композиция

Используйте короткую форму `<TagsInput>` для стандартной композиции. Оставьте `TagsInput.Items`,
`TagsInput.Input` и `TagsInput.ClearTrigger` внутри `TagsInput.Control`. Добавьте
`TagsInput.HiddenInput` явно и передайте корню `name`, если теги нужно отправлять с формой. Если
связанная форма находится вне дерева компонента, задайте `form`.

Для собственного содержимого или действий тегов используйте `TagsInput.Context` и свяжите его
значения с `TagsInput.Item`, передав `index` и `value`. Оставьте `TagsInput.ItemInput` внутри каждого
элемента, если нужно сохранить редактирование на месте. Используйте `TagsInput.RootProvider` с
`useTagsInput()` только тогда, когда состояние или методы вроде `addValue`, `clearValue` и `focus`
нужны за пределами дерева компонента. В Solid store является accessor: читайте `tagsInput().value`
и вызывайте `tagsInput().addValue()`. При объединении с `Combobox` используйте общие идентификаторы
поля и элемента управления и объединяйте поля через `asChild`.

### Хуки стилизации

- Корень и `RootProvider` предоставляют `data-slot="tags-input-root"` и `data-slot="tags-input-root-provider"`.
- Части Ark сохраняют `data-scope="tags-input"` и значения `data-part` из анатомии.
- Состояния можно стилизовать через `data-disabled`, `data-readonly`, `data-invalid`, `data-focus`, `data-empty`, `data-required`, `data-value` и `data-highlighted`, если Ark добавляет их к части.
- Кнопки удаления и очистки имеют стабильные `data-slot`. Для отдельного тега используется компактный значок закрытия, а очистка всех тегов использует оформление общей кнопки закрытия.
- CSS Modules используют документированные переменные `--moduix-tags-input-*`. Варианты на Tailwind используют нативные утилиты и классы, которые задаёт потребитель.
- В режиме только для чтения moduix скрывает поле ввода и кнопку очистки, оставляя видимыми только неизменяемые значения тегов.

## Доступность

Ark связывает подпись с полем, управляет выделением и редактированием тегов, удалением, вставкой и
скрытым полем формы. Явно добавленное скрытое поле сериализует список тегов для нативной отправки
формы. Передайте `name`, а при необходимости и `form`, чтобы связать его с формой.

### Поддержка клавиатуры

- `Enter` в поле ввода добавляет его текущее значение. `Enter` на выделенном теге переводит его в режим редактирования.
- Двойной щелчок по тегу также включает редактирование, если `editable` имеет значение `true`.
- Когда поле ввода пусто или курсор стоит в его начале, `ArrowLeft` и `ArrowRight` перемещают визуальный фокус между тегами.
- `Backspace` и `Delete` удаляют выделенный тег. `Backspace` также удаляет последний тег, если поле ввода пусто.
- При включённом `addOnPaste` сочетание `Control+V` добавляет вставленные значения после разделения их по `delimiter`.
