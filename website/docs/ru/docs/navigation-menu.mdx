## Какой компонент выбрать

Используйте `NavigationMenu` для основной навигации по сайту или продукту, если некоторые пункты
верхнего уровня открывают группы связанных страниц.

- Выбирайте **`NavigationMenu`**, если пункт верхнего уровня может показать группу связанных ссылок.
- Выбирайте **`Menu`** для контекстных действий, а не для навигации.
- Выбирайте **`Tabs`**, если каждый выбранный элемент переключает содержимое в одной области текущей страницы.

## Анатомия

```text
NavigationMenu
├─ NavigationMenuList
│  ├─ NavigationMenuItem[value]
│  │  └─ NavigationMenuLink
│  └─ NavigationMenuItem[value]
│     ├─ NavigationMenuTrigger
│     ├─ NavigationMenuItemIndicator (необязательно)
│     └─ NavigationMenuContent
│        └─ NavigationMenuLink
│  └─ NavigationMenuIndicator > NavigationMenuArrow (необязательно)
└─ NavigationMenuViewportPositioner (необязательно)
   └─ NavigationMenuViewport

NavigationMenuRootProvider
└─ то же дерево частей, подключённое к хранилищу из useNavigationMenu()

NavigationMenuContext
└─ расширенный доступ к текущему состоянию навигации через функцию рендера (`render prop`)
```

| Часть | Назначение |
| --- | --- |
| `NavigationMenu` | Корневой элемент `nav`, который управляет открытым элементом, задержками, фокусом и ориентацией. |
| `NavigationMenuRootProvider` | Подключает части к хранилищу, созданному через `useNavigationMenu()`. |
| `NavigationMenuContext` | Передаёт текущее состояние навигации через функцию рендера (`render prop`). |
| `NavigationMenuList` | Объединяет элементы навигации верхнего уровня. |
| `NavigationMenuItem` | Требует уникальное значение `value` и связывает триггер, содержимое и ссылки элемента. |
| `NavigationMenuTrigger` | Кнопка, открывающая и закрывающая раскрывающуюся панель элемента. |
| `NavigationMenuContent` | Раскрывающаяся панель элемента. Может отображаться рядом с элементом или внутри общей области `NavigationMenuViewport`. |
| `NavigationMenuLink` | Ссылка на прямую страницу или ссылка внутри раскрывающейся панели. |
| `NavigationMenuItemIndicator` | Необязательный визуальный маркер активного элемента. |
| `NavigationMenuIndicator` | Необязательный маркер активного триггера; размещайте его внутри `NavigationMenuList`. Используйте `NavigationMenuArrow` с общей областью `NavigationMenuViewport`. |
| `NavigationMenuViewportPositioner` | Размещает общую область `NavigationMenuViewport`. |
| `NavigationMenuViewport` | Общая анимированная область для открытого содержимого. |

## Композиция

Используйте `defaultValue` для неконтролируемого меню. Если открытым элементом управляет другая часть
приложения, передайте `value` и `onValueChange(details)`; `details.value` содержит значение открытого
элемента или пустую строку, если все панели закрыты. Если хранилище должно жить вне отрисовываемого
дерева, создайте его через `useNavigationMenu()` и передайте в `NavigationMenuRootProvider`; не
создавайте для него ещё один корневой компонент. В React хранилище представлено объектом, а в Solid
реактивное состояние читается через возвращаемую функцию доступа. Если вложенному компоненту нужно
текущее состояние, используйте `NavigationMenuContext` с render-функцией вместо хранилища.

Без общей области `NavigationMenuViewport` компонент `NavigationMenuContent` отображается рядом со
своим элементом. Добавьте `NavigationMenuViewportPositioner` и `NavigationMenuViewport`, если несколько
панелей должны открываться в одной анимированной области; свойство `align` позиционера
(`"start" | "center" | "end"`, по умолчанию `"center"`) выравнивает область относительно позиции
активного элемента. Используйте `asChild` для ссылок маршрутизатора или собственных триггеров только
тогда, когда дочерний элемент остаётся одним интерактивным элементом, способным получать фокус.

## Стилизация

Используйте `className` в React или `class` в Solid на экспортируемых частях для структурных стилей. Для
стилей, зависящих от состояния, используйте атрибуты данных Ark, например `data-state`, `data-current`
и `data-orientation`, вместе с селекторами moduix `data-slot`. Варианты Tailwind используют нативные
утилиты и классы потребителя, а переменные ниже настраивают варианты CSS Modules. Атрибуты данных и
хуки `data-slot` общие для обоих вариантов стилизации.

### Хуки стилизации

Настраивайте ту часть, которая отвечает за нужный визуальный элемент:

- `NavigationMenu` отвечает за ширину корневого элемента, цвет текста и его расположение.
- `NavigationMenuList` отвечает за интервалы между элементами верхнего уровня и их ориентацию.
- `NavigationMenuTrigger` и `NavigationMenuLink` отвечают за элементы навигации, текущее состояние и фокус.
- `NavigationMenuContent` отвечает за внешний вид раскрывающихся панелей и ссылок внутри них.
- `NavigationMenuIndicator` и `NavigationMenuItemIndicator` отвечают за необязательные элементы оформления активного состояния; используйте `NavigationMenuArrow` с общей областью `NavigationMenuViewport`.
- `NavigationMenuViewportPositioner` и `NavigationMenuViewport` отвечают за общую анимированную область панели.

Основные публичные точки подключения: `data-slot="navigation-menu-root"`,
`data-slot="navigation-menu-root-provider"`, `data-slot="navigation-menu-list"`,
`data-slot="navigation-menu-item"`, `data-slot="navigation-menu-trigger"`,
`data-slot="navigation-menu-content"`, `data-slot="navigation-menu-link"`,
`data-slot="navigation-menu-indicator"`, `data-slot="navigation-menu-item-indicator"`,
`data-slot="navigation-menu-arrow"`, `data-slot="navigation-menu-viewport-positioner"` и
`data-slot="navigation-menu-viewport"`.

Полезные атрибуты Ark: `data-scope="navigation-menu"`, `data-part`, `data-state`, `data-current`,
`data-disabled`, `data-orientation` и `data-motion`. Во время работы Ark записывает переменные
`--trigger-x`, `--trigger-y`, `--trigger-width`, `--trigger-height`, `--viewport-x`, `--viewport-y`,
`--viewport-width` и `--viewport-height`.
