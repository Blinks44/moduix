## Справочник API

Ark UI пока не публикует отдельную документацию по Navigation Menu. Компонент следует [исходному коду Ark для React](https://github.com/chakra-ui/ark/tree/main/packages/react/src/components/navigation-menu) и сохраняет его части и модель состояния.

## Выбор подходящего компонента

Используйте `NavigationMenu` для основной навигации продукта или сайта, если несколько связанных ссылок нужно объединить с раскрывающимися панелями.

- Выбирайте **`NavigationMenu`**, если пункт верхнего уровня может открыть компактную панель со связанными ссылками.
- Выбирайте **`Menu`** для контекстных действий, а не для переходов на другие страницы.
- Выбирайте **`Tabs`**, если каждый выбранный элемент показывает соответствующую панель содержимого на текущей странице.

## Анатомия

```text
NavigationMenu
├─ NavigationMenu.List
│  ├─ NavigationMenu.Item[value]
│  │  └─ NavigationMenu.Link
│  └─ NavigationMenu.Item[value]
│     ├─ NavigationMenu.Trigger
│     └─ NavigationMenu.Content
│        ├─ NavigationMenu.Indicator > NavigationMenu.Arrow (необязательно без Viewport)
│        └─ NavigationMenu.Link
└─ NavigationMenu.ViewportPositioner (необязательно)
   ├─ NavigationMenu.Indicator > NavigationMenu.Arrow (необязательно с Viewport)
   └─ NavigationMenu.Viewport

NavigationMenu.RootProvider
└─ то же дерево частей, подключённое к состоянию из useNavigationMenu()

NavigationMenu.Context
└─ расширенный доступ к текущему состоянию навигации через функцию рендера
```

| Часть | Назначение |
| --- | --- |
| `NavigationMenu` | Корневой `nav`, управляющий открытым элементом, задержками, фокусом и направлением. |
| `NavigationMenu.RootProvider` | Подключает части к хранилищу, созданному с помощью `useNavigationMenu()`. |
| `NavigationMenu.Context` | Даёт расширенный доступ к текущему состоянию через функцию рендера. |
| `NavigationMenu.List` | Объединяет элементы навигации верхнего уровня. |
| `NavigationMenu.Item` | Требует `value` и связывает его с триггером, ссылкой и содержимым элемента. |
| `NavigationMenu.Trigger` | Кнопка, открывающая панель элемента. |
| `NavigationMenu.Content` | Раскрывающаяся панель элемента; может отображаться в общем `Viewport`. |
| `NavigationMenu.Link` | Ссылка навигации, в том числе прямой переход верхнего уровня. |
| `NavigationMenu.Indicator` / `NavigationMenu.Arrow` | Необязательный визуальный указатель в отдельном содержимом или общем `Viewport`. |
| `NavigationMenu.ItemIndicator` | Необязательный визуальный индикатор текущего элемента. |
| `NavigationMenu.ViewportPositioner` | Позиционирует необязательный общий `Viewport`. |
| `NavigationMenu.Viewport` | Общая анимированная область для открытого содержимого. |

## Композиция

### Рекомендуемая композиция

Явно указывайте части Ark в разметке. Задайте каждому `NavigationMenu.Item` стабильное `value`. Связанные с ним `Trigger` и `Content` автоматически используют это значение. Используйте `NavigationMenu.Link` и для прямых переходов, и для ссылок внутри раскрывающейся панели.

Корневой компонент принимает свойства Ark `value`, `defaultValue`, `onValueChange(details)`, `openDelay`, `closeDelay`, `orientation`, `disableClickTrigger`, `disableHoverTrigger`, `disablePointerLeaveClose`, `ids`, `lazyMount` и `unmountOnExit`.

### Когда нужна собственная композиция

Используйте `asChild` у `NavigationMenu.Trigger` или `NavigationMenu.Link`, если ссылка роутера или другой семантический элемент должны получить поведение Ark. Дочерний элемент должен оставаться одним интерактивным элементом, который может получать фокус.

Добавьте `NavigationMenu.ViewportPositioner` и `NavigationMenu.Viewport`, когда несколько панелей должны открываться в одной анимированной области. Если нужна визуальная связь между активным триггером и панелью, поместите один `Indicator` с `Arrow` перед `Viewport` внутри `ViewportPositioner`. Общий viewport измеряет каждую панель и анимирует свою ширину и высоту при переходе между триггерами. Без общего viewport `Content` остаётся рядом со своим `Item` в виде компактной раскрывающейся панели и может содержать собственный `Indicator`.

Используйте `useNavigationMenu()` вместе с `NavigationMenu.RootProvider`, когда состояние навигации должно существовать за пределами дерева отрисованных компонентов. Используйте `NavigationMenu.Context` или `useNavigationMenuContext()`, когда окружающему интерфейсу нужно прочитать это состояние.

### Особенности поведения

- `onValueChange` получает объект `details` от Ark; `details.value` содержит значение открытого элемента.
- `NavigationMenu` создаёт семантический `nav`. Ark управляет ARIA-атрибутами раскрывающихся панелей, поведением при наведении и клике, а также навигацией с клавиатуры.
- `Content` и `Viewport` сохраняют атрибуты присутствия Ark, поэтому `lazyMount` и `unmountOnExit` работают вместе с анимацией выхода по умолчанию.
- Обёртка не добавляет иконку триггера и `Viewport`. Добавляйте их только тогда, когда этого требует композиция.
- Стрелки добавляются по желанию и не входят в рекомендуемую базовую композицию.

### Селекторы CSS

- `NavigationMenu` задаёт ширину корневого элемента, цвет текста и его положение в макете.
- `NavigationMenu.List` задаёт интервалы и ориентацию элементов верхнего уровня.
- С помощью `NavigationMenu.Trigger` и `NavigationMenu.Link` можно стилизовать элементы навигации, текущее состояние и фокус.
- `NavigationMenu.Content` отвечает за внешний вид раскрывающихся панелей и ссылок внутри них.
- `NavigationMenu.Indicator`, `ItemIndicator` и `Arrow` отвечают за необязательные элементы оформления активного состояния.
- `NavigationMenu.ViewportPositioner` и `Viewport` отвечают за общую анимированную область панели.

Основные публичные хуки: `data-slot="navigation-menu-root"`, `data-slot="navigation-menu-root-provider"`, `data-slot="navigation-menu-list"`, `data-slot="navigation-menu-item"`, `data-slot="navigation-menu-trigger"`, `data-slot="navigation-menu-content"`, `data-slot="navigation-menu-link"`, `data-slot="navigation-menu-indicator"`, `data-slot="navigation-menu-item-indicator"`, `data-slot="navigation-menu-arrow"`, `data-slot="navigation-menu-viewport-positioner"` и `data-slot="navigation-menu-viewport"`.

Полезные хуки Ark: `data-scope="navigation-menu"`, `data-part`, `data-state`, `data-current`, `data-disabled`, `data-orientation` и `data-motion`. Во время работы Ark записывает переменные `--trigger-x`, `--trigger-y`, `--trigger-width`, `--trigger-height`, `--viewport-x`, `--viewport-y`, `--viewport-width` и `--viewport-height`.
