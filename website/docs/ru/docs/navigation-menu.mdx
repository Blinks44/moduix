## Выбор подходящего компонента

Используйте `NavigationMenu` для основной навигации по сайту или продукту, если некоторые пункты
верхнего уровня открывают группы связанных страниц.

- Выбирайте **`NavigationMenu`**, если пункт верхнего уровня может показать группу связанных ссылок.
- Выбирайте **`Menu`** для контекстных действий, а не для навигации.
- Выбирайте **`Tabs`**, если каждый выбранный элемент переключает содержимое в одной области текущей страницы.

## Базовый пример

Используйте `NavigationMenu` вместе с `NavigationMenu.List` и `NavigationMenu.Item`. У каждого
элемента должно быть уникальное значение `value`. Для группы ссылок поместите
`NavigationMenu.Trigger` и `NavigationMenu.Content` в один элемент. `NavigationMenu.Link` используйте
для прямых переходов из верхнего уровня и для ссылок внутри панели.

## Анатомия

```text
NavigationMenu (NavigationMenu.Root)
├─ NavigationMenu.List
│  ├─ NavigationMenu.Item[value]
│  │  └─ NavigationMenu.Link
│  └─ NavigationMenu.Item[value]
│     ├─ NavigationMenu.Trigger
│     ├─ NavigationMenu.ItemIndicator (необязательно)
│     └─ NavigationMenu.Content
│        ├─ NavigationMenu.Indicator > NavigationMenu.Arrow (необязательно без общей области Viewport)
│        └─ NavigationMenu.Link
└─ NavigationMenu.ViewportPositioner (необязательно)
   ├─ NavigationMenu.Indicator > NavigationMenu.Arrow (необязательно с общей областью Viewport)
   └─ NavigationMenu.Viewport

NavigationMenu.RootProvider
└─ то же дерево частей, подключённое к хранилищу из useNavigationMenu()

NavigationMenu.Context
└─ расширенный доступ к текущему состоянию навигации через функцию рендера (`render prop`)
```

| Часть | Назначение |
| --- | --- |
| `NavigationMenu` | Корневой элемент `nav`, который управляет открытым элементом, задержками, фокусом и ориентацией. |
| `NavigationMenu.RootProvider` | Подключает части к хранилищу, созданному через `useNavigationMenu()`. |
| `NavigationMenu.Context` | Передаёт текущее состояние навигации через функцию рендера (`render prop`). |
| `NavigationMenu.List` | Объединяет элементы навигации верхнего уровня. |
| `NavigationMenu.Item` | Требует уникальное значение `value` и связывает триггер, содержимое и ссылки элемента. |
| `NavigationMenu.Trigger` | Кнопка, открывающая и закрывающая раскрывающуюся панель элемента. |
| `NavigationMenu.Content` | Раскрывающаяся панель элемента. Может отображаться рядом с элементом или внутри общей области `Viewport`. |
| `NavigationMenu.Link` | Ссылка на прямую страницу или ссылка внутри раскрывающейся панели. |
| `NavigationMenu.ItemIndicator` | Необязательный визуальный маркер активного элемента. |
| `NavigationMenu.Indicator` / `NavigationMenu.Arrow` | Необязательный указатель активного элемента в отдельном содержимом или общей области `Viewport`. |
| `NavigationMenu.ViewportPositioner` | Размещает общую область `Viewport` и необязательный индикатор. |
| `NavigationMenu.Viewport` | Общая анимированная область для открытого содержимого. |

## Композиция

### Рекомендуемая композиция

Явно задавайте части Ark в разметке. Каждому `NavigationMenu.Item` задайте стабильное уникальное
значение `value`. Его `Trigger` и `Content` связываются через родительский `Item`, поэтому им не нужно
повторять `value`. Используйте `NavigationMenu.Link` для прямых переходов и ссылок внутри
раскрывающейся панели.

Корневой компонент принимает свойства Ark, например `value`, `defaultValue`, `onValueChange(details)`,
`openDelay`, `closeDelay`, `orientation`, `disableClickTrigger`, `disableHoverTrigger`,
`disablePointerLeaveClose`, `ids`, `translations`, `lazyMount`, `unmountOnExit` и `hideMode`.

### Когда нужна собственная композиция

Используйте `asChild` у `NavigationMenu.Trigger` или `NavigationMenu.Link`, если ссылкой должен стать
компонент маршрутизатора или другой семантический элемент. Дочерний элемент должен оставаться одним
интерактивным элементом, способным получать фокус, чтобы Ark сохранил клавиатурное управление, фокус
и ARIA-атрибуты.

Добавляйте `NavigationMenu.ViewportPositioner` и `NavigationMenu.Viewport`, если несколько панелей
должны открываться в одной анимированной области. Если панель должна указывать на свой триггер,
поместите `Indicator` с `Arrow` перед `Viewport` внутри `ViewportPositioner`. Общая область `Viewport`
измеряет каждую панель и анимирует ширину и высоту при переключении триггеров. Без общей области
`Viewport` `Content` отображается рядом с `Item` как компактная раскрывающаяся панель; при необходимости
в неё можно добавить собственный `Indicator`.

Используйте `useNavigationMenu()` вместе с `NavigationMenu.RootProvider`, если состояние навигации нужно
создать вне дерева компонентов. Передайте результат хука в обязательное свойство `value` компонента
`NavigationMenu.RootProvider`. Используйте `NavigationMenu.Context` или `useNavigationMenuContext()`, если
соседним элементам интерфейса нужно получить доступ к этому состоянию.

### Свойства по умолчанию

| Свойство | По умолчанию | Примечание |
| --- | --- | --- |
| `NavigationMenu.openDelay` | `200` | Задержка перед открытием панели при наведении. |
| `NavigationMenu.closeDelay` | `300` | Задержка перед закрытием открытой панели. |
| `NavigationMenu.orientation` | `horizontal` | Задаёт направление раскладки и клавиатурной навигации. |
| `NavigationMenu.lazyMount` | `false` | Монтирует содержимое только после первого открытия. |
| `NavigationMenu.unmountOnExit` | `false` | Удаляет неактивное содержимое из DOM после закрытия. |
| `NavigationMenu.hideMode` | `display-none` | Скрывает смонтированное содержимое с помощью атрибута `hidden`. В React 19 также доступен режим `activity`. |
| `NavigationMenu.Link.closeOnClick` | `true` | Закрывает меню после выбора ссылки. |
| `NavigationMenu.ViewportPositioner.align` | `center` | Выравнивает общую область `Viewport` относительно триггера. |

### Особенности поведения

- `onValueChange` получает объект `details` от Ark. `details.value` содержит значение открытого элемента или пустую строку, если все панели закрыты.
- По умолчанию наведение указателя мыши или нажатие на триггер открывает его панель. Используйте `disableHoverTrigger`, `disableClickTrigger` и `disablePointerLeaveClose`, чтобы изменить это поведение.
- `NavigationMenu` создаёт семантический элемент `nav`. Ark управляет ARIA-атрибутами панелей, перемещением фокуса и клавиатурной навигацией между триггерами и панелями.
- Передайте `current` в `NavigationMenu.Link`, чтобы отметить текущую страницу. Ссылка добавит атрибут `data-current`, который можно использовать в стилях.
- `Content` и `Viewport` сохраняют атрибуты присутствия Ark, поэтому `lazyMount`, `unmountOnExit` и стандартная анимация закрытия работают вместе.
- Компонент не добавляет иконку триггера и общую область `Viewport`. Добавляйте их только тогда, когда этого требует композиция.
- `Indicator` и `Arrow` необязательны и не входят в рекомендуемую базовую композицию.

### Точки подключения для стилей

Настраивайте ту часть, которая отвечает за нужный визуальный элемент:

- `NavigationMenu` отвечает за ширину корневого элемента, цвет текста и его расположение.
- `NavigationMenu.List` отвечает за интервалы между элементами верхнего уровня и их ориентацию.
- `NavigationMenu.Trigger` и `NavigationMenu.Link` отвечают за элементы навигации, текущее состояние и фокус.
- `NavigationMenu.Content` отвечает за внешний вид раскрывающихся панелей и ссылок внутри них.
- `NavigationMenu.Indicator`, `ItemIndicator` и `Arrow` отвечают за необязательные элементы оформления активного состояния.
- `NavigationMenu.ViewportPositioner` и `Viewport` отвечают за общую анимированную область панели.

Основные публичные точки подключения: `data-slot="navigation-menu-root"`,
`data-slot="navigation-menu-root-provider"`, `data-slot="navigation-menu-list"`,
`data-slot="navigation-menu-item"`, `data-slot="navigation-menu-trigger"`,
`data-slot="navigation-menu-content"`, `data-slot="navigation-menu-link"`,
`data-slot="navigation-menu-indicator"`, `data-slot="navigation-menu-item-indicator"`,
`data-slot="navigation-menu-arrow"`, `data-slot="navigation-menu-viewport-positioner"` и
`data-slot="navigation-menu-viewport"`.

Полезные атрибуты Ark: `data-scope="navigation-menu"`, `data-part`, `data-state`, `data-current`,
`data-disabled`, `data-orientation` и `data-motion`. Во время работы Ark записывает переменные
`--trigger-x`, `--trigger-y`, `--trigger-width`, `--trigger-height`, `--viewport-x`, `--viewport-y`,
`--viewport-width` и `--viewport-height`.
