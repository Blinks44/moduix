Используйте `NavigationMenu` вместе с `NavigationMenuList` и `NavigationMenuItem`. У каждого элемента
должно быть уникальное значение `value`. Для группы ссылок поместите `NavigationMenuTrigger` и
`NavigationMenuContent` в один элемент. `NavigationMenuLink` используйте для прямых переходов из
верхнего уровня и для ссылок внутри панели.

## Какой компонент выбрать

Используйте `NavigationMenu` для основной навигации по сайту или продукту, если некоторые пункты
верхнего уровня открывают группы связанных страниц.

- Выбирайте **`NavigationMenu`**, если пункт верхнего уровня может показать группу связанных ссылок.
- Выбирайте **`Menu`** для контекстных действий, а не для навигации.
- Выбирайте **`Tabs`**, если каждый выбранный элемент переключает содержимое в одной области текущей страницы.

### Общая область Viewport

Используйте общую область `NavigationMenuViewport`, если панели имеют разный размер, но должны анимироваться в одной

## Композиция

Используйте `defaultValue` для неконтролируемого меню. Если открытым элементом управляет другая часть
приложения, передайте `value` и `onValueChange(details)`; `details.value` содержит значение открытого
элемента или пустую строку, если все панели закрыты. Если хранилище должно жить вне отрисовываемого
дерева, создайте его через `useNavigationMenu()` и передайте в `NavigationMenuRootProvider`; не
создавайте для него ещё один корневой компонент. В React хранилище представлено объектом, в Solid
реактивное состояние читается через возвращаемую функцию доступа, а в Vue используются ref и привязки
шаблона. Для управляемого значения во Vue используйте `v-model:value`. Если вложенному компоненту
нужно текущее состояние, используйте `NavigationMenuContext` с render-функцией вместо хранилища.

Без общей области `NavigationMenuViewport` компонент `NavigationMenuContent` отображается рядом со
своим элементом. Добавьте `NavigationMenuViewportPositioner` и `NavigationMenuViewport`, если несколько
панелей должны открываться в одной анимированной области; свойство `align` позиционера
(`"start" | "center" | "end"`, по умолчанию `"center"`) выравнивает область относительно позиции
активного элемента. Используйте `asChild` для ссылок маршрутизатора или собственных триггеров только
тогда, когда дочерний элемент остаётся одним интерактивным элементом, способным получать фокус.

## Стилизация

Используйте `className` в React, `class` в Solid или `class` во Vue на экспортируемых частях для структурных стилей. Для
стилей, зависящих от состояния, используйте атрибуты данных Ark, например `data-state`, `data-current`
и `data-orientation`, вместе с селекторами moduix `data-slot`. Варианты Tailwind используют нативные
утилиты и классы потребителя. Варианты с CSS Modules берут цвета, отступы и типографику из токенов
foundation и выносят в CSS-переменные только ограничения размеров панели и viewport; остальное
переопределяйте классом на части. Анимация панели и viewport следует общим переменным
`--moduix-popup-motion-*`. Атрибуты данных и хуки `data-slot` общие для обоих вариантов стилизации.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `NavigationMenu` | `navigation-menu-root` |
| `NavigationMenuRootProvider` | `navigation-menu-root-provider` |
| `NavigationMenuList` | `navigation-menu-list` |
| `NavigationMenuItem` | `navigation-menu-item` |
| `NavigationMenuTrigger` | `navigation-menu-trigger` |
| `NavigationMenuContent` | `navigation-menu-content` |
| `NavigationMenuLink` | `navigation-menu-link` |
| `NavigationMenuIndicator` | `navigation-menu-indicator` |
| `NavigationMenuItemIndicator` | `navigation-menu-item-indicator` |
| `NavigationMenuArrow` | `navigation-menu-arrow` |
| `NavigationMenuViewportPositioner` | `navigation-menu-viewport-positioner` |
| `NavigationMenuViewport` | `navigation-menu-viewport` |

Настраивайте ту часть, которая отвечает за нужный визуальный элемент:

- `NavigationMenu` отвечает за ширину корневого элемента, цвет текста и его расположение.
- `NavigationMenuList` отвечает за интервалы между элементами верхнего уровня и их ориентацию.
- `NavigationMenuTrigger` и `NavigationMenuLink` отвечают за элементы навигации, текущее состояние и фокус.
- `NavigationMenuContent` отвечает за внешний вид раскрывающихся панелей и ссылок внутри них.
- `NavigationMenuIndicator` и `NavigationMenuItemIndicator` отвечают за необязательные элементы оформления активного состояния; используйте `NavigationMenuArrow` с общей областью `NavigationMenuViewport`.
- `NavigationMenuViewportPositioner` и `NavigationMenuViewport` отвечают за общую анимированную область панели.

Полезные атрибуты Ark: `data-scope="navigation-menu"`, `data-part`, `data-state`, `data-current`,
`data-disabled`, `data-orientation` и `data-motion`. Во время работы Ark записывает переменные
`--trigger-x`, `--trigger-y`, `--trigger-width`, `--trigger-height`, `--viewport-x`, `--viewport-y`,
`--viewport-width` и `--viewport-height`.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `Tab` / `Shift+Tab` | Перемещает между кнопками и ссылками верхнего уровня. |
| `Enter` / `Space` | Открывает или закрывает панель кнопки в фокусе. |
| `Esc` | Закрывает открытую панель и возвращает фокус на её кнопку. |
