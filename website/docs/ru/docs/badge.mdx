## Справочник API

В Ark UI нет отдельного примитива `Badge`. В moduix компонент построен с помощью официальной
[фабрики Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и работе с
[ref](https://ark-ui.com/docs/guides/ref).

## Какой компонент выбрать

Используйте `Badge`, чтобы показать краткую информацию о другом объекте. Это компонент только для отображения,
поэтому он не заменяет элемент управления, с помощью которого пользователь выбирает или изменяет значение.

- Выбирайте **`Badge`** для коротких метаданных: статуса, категории, версии или количества.
- Выбирайте **`Tag`** для выбранных значений, фильтров, назначений или меток, которые относятся к текущему состоянию интерфейса.

Экспорты Vue доступны из `@moduix/vue/badge` для CSS Modules и `@moduix/vue-tailwind/badge` для Tailwind CSS.

## Анатомия

`Badge` - корневой компонент семейства. Публичный API небольшой и включает только
видимые части.

```text
Badge
├─ BadgeLabel (необязательно; используйте явно для усечения)
├─ BadgeDot (необязательно)
└─ svg-иконка (необязательно)
```

| Часть      | Назначение                                                                              |
| ---------- | --------------------------------------------------------------------------------------- |
| `Badge`    | Корневая часть. Отвечает за вариант, границу и отступы.                                |
| `BadgeLabel` | Явная часть с текстом. Позволяет обрезать составную подпись.                           |
| `BadgeDot` | Декоративная часть. Рисует круглый индикатор, который наследует цвет текста.             |

## Композиция

`Badge` отображает данные и не владеет состоянием. Обычный дочерний текст остаётся без изменений;
используйте `BadgeLabel` явно, если подпись нужно усечь в ограниченном пространстве или объединить с
`BadgeDot` либо иконкой. Для семантической ссылки или кнопки в React передайте в `asChild` ровно один
дочерний элемент. В Solid передайте в `asChild` функцию рендера - созданный элемент сохранит нативную
семантику.

В Vue поместите ровно один дочерний элемент в слот по умолчанию при использовании `as-child`; он сохранит нативную семантику.

## Стилизация

Начните с готового варианта оформления. Для разовой настройки размера или внешнего вида задайте публичные
переменные `--moduix-badge-*` на бейдже через класс или встроенный стиль. Используйте переменные
`--moduix-badge-<variant>-*`, чтобы настроить вариант во всём приложении. Общие переменные
`--moduix-badge-bg`, `--moduix-badge-border-color` и `--moduix-badge-color` переопределяют значения варианта
для отдельного бейджа. Таблица CSS-переменных относится к пакетам с CSS Modules; в пакетах Tailwind используются
обычные утилитарные классы и классы приложения.

Для структурных стилей передавайте экспортируемым частям `className` в React или `class` в Solid и Vue. Стабильные
хуки `data-slot` и атрибуты данных Ark общие для всех подходов.

### Хуки стилизации

- `data-slot="badge-root"`, `data-slot="badge-label"` и `data-slot="badge-dot"` - стабильные селекторы экспортируемых частей.
- `Badge` также предоставляет `data-scope="badge"` и `data-part="root"`. `BadgeLabel` и `BadgeDot` предоставляют `data-part="label"` и `data-part="dot"`.
- `Badge` записывает выбранный вариант в `data-variant`.
- Фокусируемые элементы, созданные через `Badge asChild`, получают стандартное кольцо фокуса. Корневые ссылки также получают стили наведения и курсор-указатель; оформление взаимодействия кнопок остаётся ответственностью приложения.
- Дочерние `svg`-иконки наследуют `currentColor`, не получают события указателя и используют `--moduix-badge-icon-size`.
- У Badge нет отдельного примитива или машины поведения Ark, поэтому он не предоставляет управляемые Ark-состояния и runtime CSS-переменные.
