## Справочник API

В Ark UI нет отдельного примитива `Badge`. В moduix компонент построен с помощью официальной
[фабрики Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и работе с
[ref](https://ark-ui.com/docs/guides/ref).

## Выбор подходящего компонента

Используйте `Badge`, чтобы показать краткую информацию о другом объекте. Это компонент только для отображения,
поэтому он не заменяет элемент управления, с помощью которого пользователь выбирает или изменяет значение.

- Выбирайте **`Badge`** для коротких метаданных: статуса, категории, версии или количества.
- Выбирайте **`Tag`** для выбранных значений, фильтров, назначений или меток, которые относятся к текущему состоянию интерфейса.

## Анатомия

Запись `Badge` это сокращённая форма `Badge.Root`. У компонента небольшой публичный API, состоящий только из видимых частей.

```text
Badge / Badge.Root
├─ Badge.Label (необязательно; обычный текст автоматически оборачивается)
├─ Badge.Dot (необязательно)
└─ svg-иконка (необязательно)
```

| Часть                  | Назначение                                                                                 |
| ---------------------- | ------------------------------------------------------------------------------------------ |
| `Badge` / `Badge.Root` | Корневая часть. Отвечает за вариант, границу, отступы и усечение текста.                    |
| `Badge.Label`          | Явная часть с текстом. Позволяет корректно обрезать составной бейдж.                       |
| `Badge.Dot`            | Декоративная часть. Рисует круглый индикатор, который наследует цвет текста.                |

## Композиция

### Рекомендуемая композиция

Для большинства коротких статусов, категорий, версий и счётчиков достаточно использовать `<Badge>`.
Запись `Badge.Root` обозначает тот же корневой компонент в пространстве имён `Badge`.

Используйте `variant` для готовых вариантов оформления: `default`, `secondary`, `destructive`, `outline`,
`ghost` и `link`.

Если бейджу нужна точка или иконка, разместите `Badge.Dot` либо дочернюю иконку рядом с `Badge.Label`.
Прямой текст компонент автоматически оборачивает в `Badge.Label`.

`Badge.Root`, `Badge.Label` и `Badge.Dot` пробрасывают `ref` в созданные DOM-элементы.

### Когда нужна собственная композиция

Используйте `Badge asChild`, когда корневым DOM-элементом должен стать семантический элемент, например `<a>` или
`<button>`. В композиции Ark должен быть ровно один дочерний элемент. Он сохраняет нативную семантику, а ссылки,
кнопки и элементы с `role="button"` получают стандартные стили курсора, наведения и видимого фокуса.

Если нужен нестандартный размер или внешний вид, задайте локальную CSS-переменную или переопределите `className`.
У компонента нет свойства `size`: размеры настраиваются публичными CSS-переменными.

### Свойства по умолчанию

| Свойство  | По умолчанию | Значения / примечания                                      |
| --------- | ------------ | ---------------------------------------------------------- |
| `variant` | `default`    | `default`, `secondary`, `destructive`, `outline`, `ghost`, `link` |
| `asChild` | `false`      | Рендерит единственный дочерний элемент вместо корневого `span` |

### Особенности поведения

- По умолчанию `Badge` только отображает информацию и рендерит `span`.
- `Badge.Dot` декоративен и скрыт от вспомогательных технологий, поэтому смысл статуса должен быть понятен из видимого текста.
- `Badge` сам по себе не добавляет интерактивность и семантику ссылки или кнопки.
- Ссылки, кнопки и другие семантические элементы, переданные через `asChild`, сохраняют нативную семантику и получают стандартные стили курсора, наведения и видимого фокуса.
- Отключённые кнопки и элементы с `aria-disabled="true"` сохраняют свою семантику, не получают стили наведения и используют публичную переменную прозрачности для отключённого состояния.
- Длинный текст остаётся в одну строку и обрезается у корневого элемента. Добавьте `title`, чтобы полное значение можно было увидеть при наведении курсора. На сенсорных устройствах выбирайте текст, который помещается в доступное пространство.
- Прямой текст автоматически оборачивается в `Badge.Label`. Используйте `Badge.Label` явно, если текст нужно скомпоновать с точкой, иконкой или другим элементом.
- Дочерние `svg`-иконки, переданные напрямую, наследуют `currentColor` и используют `--moduix-badge-icon-size`.
- Числовое содержимое использует табличные цифры, а текст бейджа по умолчанию нельзя выделить.

## Стилизация

Сначала выберите готовый вариант. Для разовой настройки размера или оформления задайте публичные
`--moduix-badge-*` через класс или встроенный стиль. Используйте переменные
`--moduix-badge-<variant>-*`, чтобы изменить оформление варианта во всём приложении. Общие переменные
`--moduix-badge-bg`, `--moduix-badge-border-color` и `--moduix-badge-color` перекрывают значения варианта для отдельного бейджа.

### Хуки стилизации

- `data-slot="badge-root"`, `data-slot="badge-label"` и `data-slot="badge-dot"` это стабильные селекторы для стилизации экспортируемых частей.
- `Badge.Root` также предоставляет `data-scope="badge"` и `data-part="root"`. `Badge.Label` и `Badge.Dot` предоставляют `data-part="label"` и `data-part="dot"`.
- `Badge.Root` помещает выбранный вариант в атрибут `data-variant`.
- Ссылки и кнопки, отрисованные через `Badge asChild` или `Badge.Root asChild`, получают стандартные стили видимого фокуса от корневого элемента.
- Дочерние `svg`-иконки, переданные напрямую, наследуют `currentColor`, не перехватывают события указателя и используют `--moduix-badge-icon-size`.
- У `Badge` нет отдельного примитива Ark и собственного механизма поведения, поэтому компонент не предоставляет состояния, которыми управляет Ark, и динамические CSS-переменные.
