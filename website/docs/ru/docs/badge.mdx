## Справочник API

Ark UI не предоставляет отдельный примитив `Badge`. moduix собирает этот компонент на основе официальной
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) и следует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и работе с
[ref](https://ark-ui.com/docs/guides/ref).

## Выбор подходящего компонента

Используйте `Badge`, когда нужно показать краткую информацию о другом объекте, а не выбранное пользователем значение.

- Выбирайте **`Badge`** для коротких метаданных: статуса, категории, версии или количества.
- Выбирайте **`Tag`**, когда нужно показать выбранные значения, фильтры, назначения или метки, связанные с текущим состоянием интерфейса.

## Анатомия

`Badge` сохраняет небольшой публичный интерфейс и предоставляет только видимые части.

```text
Badge / Badge.Root
├─ Badge.Label (optional; direct text is wrapped automatically)
├─ Badge.Dot (optional)
└─ svg icon (optional)
```

| Часть                  | Роль                                                                                |
| ---------------------- | ----------------------------------------------------------------------------------- |
| `Badge` / `Badge.Root` | Корневая часть. Применяет вариант, границу, отступы и усечение текста.              |
| `Badge.Label`          | Явная текстовая часть. Позволяет обрезать составную метку.                          |
| `Badge.Dot`            | Дополнительная часть с индикатором. Отображает круглый маркер, который наследует цвет текста. |

## Композиция

### Рекомендуемая композиция

Для большинства меток статуса, категорий, версий и небольших счётчиков используйте `Badge` напрямую.

Используйте `variant` для готовых вариантов оформления: `default`, `secondary`, `destructive`, `outline`, `ghost` и `link`.

Если составному бейджу нужен дополнительный визуальный сигнал, разместите `Badge.Dot` или дочерний значок рядом с `Badge.Label`. При передаче обычного текста компонент сам оборачивает его в `Badge.Label`.

`Badge.Root`, `Badge.Label` и `Badge.Dot` пробрасывают `ref` в соответствующие DOM-элементы.

### Когда нужна собственная композиция

Используйте `Badge asChild`, если корневым DOM-элементом должен стать другой семантический элемент. Композиция Ark требует ровно одного дочернего элемента. Интерактивный дочерний элемент сохраняет нативную семантику и получает от бейджа стандартные стили курсора, наведения и фокуса клавиатуры.

Используйте локальные CSS-переменные или переопределяйте `className`, если компоненту нужен нестандартный размер или другое оформление.

### Свойства по умолчанию

| Свойство  | По умолчанию | Значения / примечания                                           |
| --------- | ------------ | ---------------------------------------------------------------- |
| `variant` | `default`    | `default`, `secondary`, `destructive`, `outline`, `ghost`, `link` |
| `asChild` | `false`      | Композиция Ark factory с ровно одним дочерним элементом          |

### Особенности поведения

- По умолчанию `Badge` только отображает информацию и рендерит `span`.
- `Badge.Dot` декоративен и скрыт от вспомогательных технологий, поэтому смысл статуса должен быть понятен из видимого текста.
- `Badge` сам по себе не добавляет интерактивность и семантику ссылки или кнопки.
- Ссылки и кнопки, переданные через `asChild`, сохраняют нативную семантику и получают стандартные стили курсора, наведения и видимого фокуса.
- Отключённые кнопки и элементы с `aria-disabled="true"` сохраняют свою семантику, не получают стили наведения и используют публичную переменную прозрачности для отключённого состояния.
- Длинные метки остаются в одну строку и обрезаются многоточием у корневого элемента. `title` показывает полное значение при наведении курсора. На устройствах с сенсорным вводом лучше выбрать метку, которая помещается в доступное пространство.
- Обычный текст автоматически оборачивается в `Badge.Label`. Используйте `Badge.Label` явно, если текст нужно скомпоновать с точкой, значком или другим элементом.
- Дочерние значки `svg`, переданные напрямую, наследуют `currentColor` и используют `--moduix-badge-icon-size`.
- Числовое содержимое использует табличные цифры, а текст бейджа по умолчанию нельзя выделить.
- Размеры из рецепта Chakra задаются публичными CSS-переменными, а не свойством `size`.

## Стилизация

Сначала выберите готовый вариант. Для точечной настройки размера и оформления используйте локальные CSS-переменные.
Используйте переменные `--moduix-badge-<variant>-*`, чтобы настроить вариант во всём приложении. Общие
`--moduix-badge-bg`, `--moduix-badge-border-color` и `--moduix-badge-color` имеют более высокий приоритет и подходят
для настройки отдельного бейджа.

### Хуки стилизации

- `data-slot="badge-root"`, `data-slot="badge-label"` и `data-slot="badge-dot"` - стабильные селекторы для стилизации экспортируемых частей.
- `Badge.Root` также предоставляет `data-scope="badge"` и `data-part="root"`. `Badge.Label` и `Badge.Dot` предоставляют `data-part="label"` и `data-part="dot"`.
- `Badge.Root` записывает выбранный вариант в `data-variant`.
- Ссылки и кнопки, отрисованные через `Badge asChild` или `Badge.Root asChild`, получают от корневого элемента стандартные стили видимого фокуса.
- Дочерние значки `svg`, переданные напрямую, наследуют `currentColor`, не реагируют на события указателя и используют `--moduix-badge-icon-size`.
- У Badge нет отдельного примитива Ark или машины поведения, поэтому компонент не предоставляет управляемых состояний Ark и CSS-переменных времени выполнения.
