# Тёмный режим

По умолчанию moduix использует светлый набор токенов. Добавьте к элементу атрибут
`data-moduix-color-scheme="dark"`, чтобы применить тёмные токены к этому элементу и его потомкам.
Базовую таблицу стилей достаточно импортировать один раз:

```tsx
import '@moduix/react/style.css';
```

## Задайте схему на корне документа

Для темы всего приложения задайте итоговую цветовую схему на `<html>`. Для тёмного режима используйте
`data-moduix-color-scheme="dark"`, а для светлого - `data-moduix-color-scheme="light"`. moduix не
определяет предпочтение пользователя, не хранит его и не требует провайдера темы. Приложение само
решает, как выбирать и сохранять настройку.

```html
<!-- Dark theme -->
<html data-moduix-color-scheme="dark"></html>
```

Компоненты, которые рендерятся через портал, например Dialog, Popover и Select, тоже наследуют токены
с `<html>`.

Если приложение использует серверный рендеринг, установите атрибут до первой отрисовки с помощью
механизма ранней инициализации темы вашего фреймворка. Это не даст светлой теме кратко появиться,
пока клиентский JavaScript применяет сохранённую настройку.

## Добавьте переключатель

Храните явный выбор пользователя в приложении и обновляйте атрибут документа. Если выбор ещё не
сохранён, определяйте системное предпочтение через `matchMedia`.

```tsx
type ColorScheme = 'light' | 'dark';

export function applyColorScheme(scheme: ColorScheme) {
  document.documentElement.dataset.moduixColorScheme = scheme;
}

export function resolveColorScheme(): ColorScheme {
  const saved = localStorage.getItem('moduix-color-scheme');
  if (saved === 'light' || saved === 'dark') return saved;

  return matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
}

export function saveColorScheme(scheme: ColorScheme) {
  localStorage.setItem('moduix-color-scheme', scheme);
  applyColorScheme(scheme);
}
```

Выполните эквивалент `applyColorScheme(resolveColorScheme())` в скрипте ранней инициализации темы
вашего фреймворка до первой отрисовки. Переключатель должен вызывать `saveColorScheme` с выбранным
пользователем значением. Так системное предпочтение остаётся значением по умолчанию, пока пользователь
сам не выберет режим. Укажите переключателю доступное имя, описывающее действие, например
`Switch to dark mode`.

## Используйте пресет

Цветовая схема и визуальный пресет - разные уровни настройки, поэтому их можно использовать вместе.
Задайте `data-moduix-color-scheme` и `data-moduix-theme` на одном корневом элементе, чтобы обычные и
портальные компоненты использовали одну палитру, плотность, радиус и токены фокуса.

```tsx
import '@moduix/react/style.css';
import '@moduix/react/presets/dense.css';
```

<div style={{ height: '1rem' }} aria-hidden="true" />

```html
<html data-moduix-color-scheme="dark" data-moduix-theme="dense"></html>
```

Смена цветовой схемы не меняет плотность пресета. Выбранный пресет остаётся активным в обоих режимах.
Сравнение пресетов и создание собственной темы описаны в разделе [Темы](/docs/themes).

## Ограничьте область действия

Если тёмные токены нужны только для предпросмотра или встроенной поверхности, установите атрибут
`data-moduix-color-scheme="dark"` на обычный контейнер:

```tsx
import { Card } from '@moduix/react';
import '@moduix/react/style.css';

export function SettingsPreview() {
  return (
    <section data-moduix-color-scheme="dark">
      <Card>Dark preview</Card>
    </section>
  );
}
```

Так можно оформить предпросмотр настроек или встроенный виджет. Портальный контент рендерится за
пределами контейнера и не наследует его токены. Если поверхность открывает оверлеи, задайте атрибут
на контейнере портала, `<body>` или `<html>`.

## Настройте токены

Чтобы изменить палитру в обеих схемах, переопределите одинаковые базовые цветовые токены в `:root` и
`[data-moduix-color-scheme='dark']`. Семантические алиасы, например `--moduix-color-background`,
`--moduix-color-foreground` и `--moduix-color-border`, ссылаются на эти базовые токены, поэтому
компоненты единообразно используют ваши значения во всей библиотеке.

Подключите таблицу стилей с переопределениями после `style.css`:

```css
:root {
  --moduix-background: oklch(0.99 0.004 285);
  --moduix-primary: oklch(0.5 0.18 260);
}

[data-moduix-color-scheme='dark'] {
  --moduix-background: oklch(0.16 0.01 285);
  --moduix-primary: oklch(0.76 0.13 260);
}
```

В этом примере меняются только цвет фона и основной цвет. Для остальных токенов сохраняются встроенные
значения. Полный справочник системных токенов приведён в разделе [Токены](/docs/tokens), а локальные
визуальные переопределения описаны на страницах компонентов.
