# Тёмный режим

Moduix поставляется со светлыми и тёмными семантическими токенами. Подключите stylesheet выбранного
фреймворка и способа стилизации, затем задайте `data-moduix-color-scheme` на элементе, которому
принадлежит цветовая схема. Отдельный provider темы или состояние Moduix не нужны.

## Выберите область действия

| Задача | Где задать атрибут |
| --- | --- |
| Тема всего приложения | На `<html>` |
| Встроенная область без порталов | На контейнере области |
| Встроенная область с порталами | На portal-контейнере внутри области |

Для обычного приложения выбирайте `<html>`, чтобы стандартные и портальные компоненты получили
одинаковые токены.

## Задайте схему документа

Используйте нативный атрибут документа как источник истины:

```html
<html data-moduix-color-scheme="dark"></html>
```

Допустимы значения `dark` и `light`. Moduix не читает системные настройки, не сохраняет выбор и не
синхронизирует состояние браузера. Этим управляет приложение.

При серверной отрисовке определите схему до первого отображения страницы через ранний theme-механизм
своего фреймворка. Так светлая палитра не появится перед гидратацией.

## Определите и сохраните выбор

Логику выбора можно оставить независимой от фреймворка. Видимому переключателю достаточно вызывать
`saveColorScheme()`.

```ts
type ColorScheme = 'light' | 'dark';

export function applyColorScheme(scheme: ColorScheme) {
  document.documentElement.dataset.moduixColorScheme = scheme;
}

export function resolveColorScheme(): ColorScheme {
  const saved = localStorage.getItem('moduix-color-scheme');
  if (saved === 'light' || saved === 'dark') return saved;

  return matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
}

export function saveColorScheme(scheme: ColorScheme) {
  localStorage.setItem('moduix-color-scheme', scheme);
  applyColorScheme(scheme);
}
```

Используйте системную схему, пока пользователь не сделал явный выбор. Дайте переключателю понятное
доступное имя действия, например `Switch to dark mode`.

## Совместите схему и пресет

Цветовая схема и визуальный пресет независимы. Храните оба атрибута на одном корне:

```html
<html data-moduix-color-scheme="dark" data-moduix-theme="dense"></html>
```

Смена схемы не меняет плотность, радиусы и другие решения пресета. Настройка пресетов описана на
странице [Темы](/docs/themes).

## Ограничьте тему одной областью

Код отличается только импортом нативного пакета:

<Tabs groupId="framework">
  <Tab label="React" value="react">

<CodeBlockRuntime lang="tsx" code={reactScopedSurface} />

  </Tab>
  <Tab label="Solid" value="solid">

<CodeBlockRuntime lang="tsx" code={solidScopedSurface} />

  </Tab>
</Tabs>

Портальное содержимое находится вне обычного контейнера и не наследует его токены. Если область
открывает оверлеи, перенесите атрибут на portal-контейнер, `<body>` или `<html>`.

## Настройте токены

Подключайте стили приложения после stylesheet Moduix и явно переопределяйте обе схемы:

```css
:root {
  --moduix-background: oklch(0.99 0.004 285);
  --moduix-primary: oklch(0.5 0.18 260);
}

[data-moduix-color-scheme='dark'] {
  --moduix-background: oklch(0.16 0.01 285);
  --moduix-primary: oklch(0.76 0.13 260);
}
```

Токены без переопределений сохраняют встроенные значения.

## Проверьте тему

- Проверьте первую серверную отрисовку и клиентскую гидратацию.
- Откройте портальные Dialog, Popover, Menu и Select.
- Проверьте контраст текста, границ, focus ring и отключенных состояний.
- Убедитесь, что сохраненный выбор важнее системной настройки.
- Проверьте обе схемы со всеми активными пресетами.
