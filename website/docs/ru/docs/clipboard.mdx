Используйте `Clipboard` как корневой компонент. Внутри `ClipboardControl` разместите одну
поверхность значения - `ClipboardInput` или `ClipboardValueText` - и `ClipboardTrigger`.
`ClipboardLabel` необязателен. Внутри триггера можно разместить `ClipboardIndicator`. В React и
Solid его `children` и `copied` принимают текст и иконки, а в Vue для этого используются обычный
слот и именованный слот `copied`.

## Выбор подходящего компонента

Используйте `Clipboard`, когда пользователю нужно скопировать текст. В зависимости от выбранных
частей значение можно показать в поле только для чтения или вывести как обычный текст.

## Композиция

`Clipboard` владеет значением и состоянием после копирования. Внутри `ClipboardControl` размещайте
одну поверхность значения (`ClipboardInput` или `ClipboardValueText`) и `ClipboardTrigger`;
`ClipboardIndicator` необязателен внутри триггера. Он следует состоянию копирования, а moduix
подставляет стандартные иконки копирования и подтверждения, если содержимое не задано. Для
текстовых подписей в React и Solid передайте `copied="Copied"` и `children`, а в Vue используйте
обычный и именованный слот `copied`.

Используйте `defaultValue` для неконтролируемого значения. Если значение принадлежит другой части
приложения или интерфейсу нужно реагировать на копирование, используйте `value` вместе с
`onValueChange(details)` и `onStatusChange(details)`; `timeout` задаёт длительность состояния после
копирования.

Используйте `useClipboard()` вместе с `ClipboardRootProvider`, только если состояние
нужно создать или разделить вне отрисовываемого дерева. Вложенные компоненты могут читать его через
`ClipboardContext` или `useClipboardContext()`. В Solid `useClipboard()` возвращает функцию доступа:
передайте её как `value={clipboard}` и читайте состояние как `clipboard().copied` или
`clipboard().value`. В Vue `useClipboard()` сразу возвращает реактивное состояние: передайте его
как `:value="clipboard"` и читайте `clipboard.copied` или `clipboard.value`. У корневого компонента нет состояния `disabled`: передайте нативное свойство
`disabled` и `ClipboardInput`, и `ClipboardTrigger`. Используйте `asChild` для этих частей только
если другой семантический элемент должен отрисовать узел DOM.

## Анатомия

```text
Clipboard | ClipboardRootProvider
├─ ClipboardLabel (необязательно)
├─ ClipboardControl
│  ├─ ClipboardInput или ClipboardValueText
│  └─ ClipboardTrigger
│     └─ ClipboardIndicator (необязательно)
```

| Часть | Назначение |
| --- | --- |
| `Clipboard` | Хранит значение и управляет временным состоянием после копирования. |
| `ClipboardRootProvider` | Связывает части с состоянием, созданным через `useClipboard()`. |
| `ClipboardLabel` | Задаёт доступную подпись для значения. |
| `ClipboardControl` | Объединяет отображение значения и кнопку копирования. |
| `ClipboardInput` | Показывает значение в поле только для чтения. Для изменения используйте контролируемое состояние или `ClipboardContext.setValue()`. |
| `ClipboardTrigger` | Копирует текущее значение при активации. По умолчанию отображается как кнопка. |
| `ClipboardIndicator` | Показывает разное содержимое до и после копирования. По умолчанию это иконки копирования и подтверждения; в React и Solid передайте `copied="Copied"` и `children`, а в Vue используйте соответствующие слоты. |
| `ClipboardValueText` | Выводит значение как текст, когда поле ввода не подходит. |

## Стилизация

Используйте `className` в React или `class` в Solid и Vue на экспортируемых частях для структурных стилей.
Варианты Tailwind используют стандартные утилиты и классы потребителя, а варианты CSS Modules -
приведённые ниже CSS-переменные. Для стилей состояния после копирования используйте атрибут Ark
`data-copied` вместе с хуками moduix `data-slot`.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `Clipboard` | `clipboard-root` |
| `ClipboardRootProvider` | `clipboard-root-provider` |
| `ClipboardLabel` | `clipboard-label` |
| `ClipboardControl` | `clipboard-control` |
| `ClipboardInput` | `clipboard-input` |
| `ClipboardTrigger` | `clipboard-trigger` |
| `ClipboardIndicator` | `clipboard-indicator` |
| `ClipboardValueText` | `clipboard-value-text` |

- Пока активно состояние копирования, Ark добавляет `data-copied` к `Clipboard`, `ClipboardLabel`,
  `ClipboardControl`, `ClipboardInput` и `ClipboardTrigger`.
- Ark делает `ClipboardInput` доступным только для чтения и добавляет к нему `data-readonly`.
- `ClipboardIndicator` рендерит стандартную иконку прямым дочерним `svg`.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `Tab` / `Shift+Tab` | Перемещает фокус между полем и кнопкой. |
| `Enter` / `Space` | Копирует значение, когда фокус на кнопке. |
