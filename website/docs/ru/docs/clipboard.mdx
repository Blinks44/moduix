Используйте `Clipboard`, когда пользователю нужно скопировать текст. В зависимости от выбранных
частей значение можно редактировать, оставить только для чтения или вывести как обычный текст.

## Анатомия

```text
Clipboard | Clipboard.RootProvider
├─ Clipboard.Label (необязательно)
├─ Clipboard.Control
│  ├─ Clipboard.Input или Clipboard.ValueText
│  └─ Clipboard.Trigger
│     ├─ Clipboard.Indicator (необязательно)
│     └─ Clipboard.CopyText (необязательно)
```

| Часть | Назначение |
| --- | --- |
| `Clipboard` | Хранит значение и управляет временным состоянием после копирования. |
| `Clipboard.RootProvider` | Связывает части с состоянием, созданным через `Clipboard.useClipboard()`. |
| `Clipboard.Label` | Задаёт доступную подпись для значения. |
| `Clipboard.Control` | Объединяет отображение значения и кнопку копирования. |
| `Clipboard.Input` | Показывает значение в поле. Поле можно редактировать, если не указать `readOnly`. |
| `Clipboard.Trigger` | Копирует текущее значение при активации. По умолчанию отображается как кнопка. |
| `Clipboard.Indicator` | Показывает разное содержимое до и после копирования. |
| `Clipboard.CopyText` | Текстовый вариант такого индикатора. По умолчанию это `Copy` и `Copied`. |
| `Clipboard.ValueText` | Выводит значение как текст, когда поле ввода не подходит. |

## Композиция

### Рекомендуемая композиция

В большинстве случаев используйте короткую форму `<Clipboard>` в качестве корневого компонента.
Соберите её из `Clipboard.Label`, `Clipboard.Control`, `Clipboard.Input` и `Clipboard.Trigger`.
Добавьте `Clipboard.Indicator` для иконки, `Clipboard.CopyText` для подписи состояния или обе части
сразу.

Все свойства корневого компонента Ark передаются без изменений. Используйте `defaultValue` для
неконтролируемого значения, `value` вместе с `onValueChange(details)` для управляемого значения,
а `onStatusChange(details)` - чтобы отслеживать состояние копирования. `timeout` задаёт длительность
этого состояния, а `ids` позволяет задать стабильные идентификаторы частей.

`Clipboard.Indicator` и `Clipboard.CopyText` можно не указывать. Если не передавать им содержимое,
moduix добавит иконки копирования и подтверждения, а также подписи `Copy` и `Copied`.

### Когда выбрать другую композицию

Используйте `Clipboard.ValueText`, когда значение должно быть частью обычного текста или компактного
блока без поля ввода.

Используйте `Clipboard.useClipboard()` вместе с `Clipboard.RootProvider`, когда состояние нужно
создать отдельно от дерева компонентов или использовать в нескольких местах. Вложенные компоненты
могут получить его через `Clipboard.Context` или `useClipboardContext()`.

Используйте `asChild` для `Clipboard.Input` или `Clipboard.Trigger`, только если другой семантический
элемент должен взять на себя отрисовку узла DOM. Например, можно использовать `Input` или `Button` из
moduix, сохранив явные части Clipboard в разметке.

### Свойства по умолчанию

| Свойство | Значение по умолчанию | Примечание |
| --- | --- | --- |
| `timeout` | `3000` | Длительность состояния копирования в миллисекундах. |
| `Indicator.children` | не задано | В обычном состоянии используется `CopyIcon` moduix. |
| `Indicator.copied` | не задано | После копирования используется `CheckIcon` moduix. |
| `CopyText.children` | `Copy` | Текст до копирования. |
| `CopyText.copied` | `Copied` | Текст в состоянии после копирования. |

### Особенности поведения

- `onValueChange(details)` передаёт новое значение в `details.value`.
- `onStatusChange(details)` сообщает об изменении состояния копирования. Проверяйте
  `details.copied`, если нужно обновить соседний элемент интерфейса, аналитику или счётчик.
- Пока активно состояние копирования, Ark добавляет `data-copied` к `Root`, `Label`, `Control`,
  `Input` и `Trigger`. По умолчанию moduix не меняет внешний вид поля и кнопки, поэтому этот атрибут
  можно использовать в собственных стилях.
- У корневого компонента нет свойства `disabled`. Передайте нативное свойство `disabled` и
  `Clipboard.Input`, и `Clipboard.Trigger`, если значение нельзя изменять или копировать.
- `Clipboard` по умолчанию не ограничивает ширину. Если макету нужна максимальная ширина, задайте
  `--moduix-clipboard-max-width`.
- При переходе со старого `CopyButton` используйте части Clipboard. Свойства `copiedDuration`,
  `copyLabels`, `onCopy` и `onCopyError` не входят в этот API.

## Стилизация

### CSS-свойства

<CssPropertiesSection properties={ClipboardDocs.clipboardOverrideCssProperties} />

### Хуки стилизации

- `Clipboard` -> `data-slot="clipboard-root"`
- `Clipboard.RootProvider` -> `data-slot="clipboard-root-provider"`
- `Clipboard.Label` -> `data-slot="clipboard-label"`
- `Clipboard.Control` -> `data-slot="clipboard-control"`
- `Clipboard.Input` -> `data-slot="clipboard-input"`
- `Clipboard.Trigger` -> `data-slot="clipboard-trigger"`
- `Clipboard.Indicator` -> `data-slot="clipboard-indicator"`
- `Clipboard.CopyText` -> `data-slot="clipboard-copy-text"`
- `Clipboard.ValueText` -> `data-slot="clipboard-value-text"`
- Пока активно состояние копирования, Ark добавляет `data-copied` к `Root`, `Label`, `Control`,
  `Input` и `Trigger`.
- Ark добавляет `data-readonly` к `Clipboard.Input`, когда поле доступно только для чтения.
- `Clipboard.Indicator` добавляет `data-slot="clipboard-indicator-idle-icon"` и
  `data-slot="clipboard-indicator-copied-icon"` к стандартным узлам иконок.
