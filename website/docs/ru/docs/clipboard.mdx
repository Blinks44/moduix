## Анатомия

```text
Clipboard | Clipboard.RootProvider
├─ Clipboard.Label (необязательно)
├─ Clipboard.Control
│  ├─ Clipboard.Input или Clipboard.ValueText
│  └─ Clipboard.Trigger
│     ├─ Clipboard.Indicator (необязательно)
│     └─ Clipboard.CopyText (необязательно)
```

| Часть | Назначение |
| --- | --- |
| `Clipboard` | Хранит значение и управляет состоянием копирования. |
| `Clipboard.RootProvider` | Передаёт состояние из `Clipboard.useClipboard()`, созданное вне поддерева. |
| `Clipboard.Label` | Добавляет доступную подпись к значению. |
| `Clipboard.Control` | Объединяет и располагает значение и кнопку копирования. |
| `Clipboard.Input` | Показывает значение в редактируемом поле или поле только для чтения. |
| `Clipboard.Trigger` | Копирует текущее значение при нажатии. |
| `Clipboard.Indicator` | Показывает иконку копирования или подтверждения в зависимости от состояния. |
| `Clipboard.CopyText` | Показывает подпись состояния. По умолчанию это `Copy` и `Copied`. |
| `Clipboard.ValueText` | Показывает значение как текст, когда поле ввода не подходит. |

## Композиция

### Рекомендуемая композиция

В большинстве случаев используйте вместе `Clipboard`, `Clipboard.Label`, `Clipboard.Control`,
`Clipboard.Input`, `Clipboard.Trigger` и `Clipboard.Indicator`. Это стандартная композиция Ark,
в которой каждую часть удобно настраивать.

`value`, `defaultValue`, `onValueChange(details)`, `onStatusChange(details)`, `timeout` и `ids`
работают точно так же, как в Ark. moduix сохраняет исходные имена свойств и аргументы колбэков.

`Clipboard.Indicator` и `Clipboard.CopyText` необязательны. Если не передавать им содержимое, они
покажут иконки копирования и подтверждения moduix, а также подписи `Copy` и `Copied`.

### Когда нужна настройка

Используйте `Clipboard.ValueText`, если значение должно выглядеть как обычный текст, а не как поле
ввода.

Используйте `Clipboard.useClipboard()` вместе с `Clipboard.RootProvider`, когда состояние нужно
создать вне отображаемого поддерева. Дочерние компоненты могут прочитать его через
`Clipboard.Context` или `useClipboardContext()` из moduix.

Используйте `asChild` на `Clipboard.Input` и `Clipboard.Trigger`, если требуется отрисовать другой
элемент, например `Input` или `Button` из moduix. Оставляйте части Ark в разметке: так структура
компонента будет понятной и доступной.

### Свойства по умолчанию

| Свойство | По умолчанию | Значения и примечания |
| --- | --- | --- |
| `timeout` | `3000` | Длительность состояния копирования Ark в миллисекундах |
| `Indicator.copied` | - | По умолчанию используется `CheckIcon` из moduix |
| `Indicator.children` | - | По умолчанию используется `CopyIcon` из moduix |
| `CopyText.copied` | `Copied` | Подпись после успешного копирования |
| `CopyText.children` | `Copy` | Подпись до копирования |

### Особенности поведения

- `onValueChange(details)` передаёт новое значение в `details.value`.
- Используйте `onStatusChange(details)`, если после копирования нужно обновить соседний элемент
  интерфейса, аналитику или счётчик.
- Пока активно состояние копирования, Ark добавляет `data-copied`. По умолчанию moduix не меняет
  внешний вид поля и кнопки, но этот атрибут можно использовать в своих стилях.
- У Ark нет свойства `disabled` на корневом компоненте. Передайте нативное свойство `disabled` и
  `Clipboard.Input`, и `Clipboard.Trigger`, когда значение нельзя редактировать или копировать.
- `Clipboard` по умолчанию не ограничивает ширину поля. Если макету нужна максимальная ширина,
  задайте `--moduix-clipboard-max-width`.
- Старый API `CopyButton` больше недоступен. `Clipboard` не поддерживает `copiedDuration`,
  `copyLabels`, `onCopy` и `onCopyError`.

### CSS-свойства

### Хуки стилизации

- `Clipboard` -> `data-slot="clipboard-root"`
- `Clipboard.RootProvider` -> `data-slot="clipboard-root-provider"`
- `Clipboard.Label` -> `data-slot="clipboard-label"`
- `Clipboard.Control` -> `data-slot="clipboard-control"`
- `Clipboard.Input` -> `data-slot="clipboard-input"`
- `Clipboard.Trigger` -> `data-slot="clipboard-trigger"`
- `Clipboard.Indicator` -> `data-slot="clipboard-indicator"`
- `Clipboard.CopyText` -> `data-slot="clipboard-copy-text"`
- `Clipboard.ValueText` -> `data-slot="clipboard-value-text"`
- Пока активно состояние копирования, Ark добавляет `data-copied` к `Root`, `Label`, `Control`,
  `Input` и `Trigger`.
- Ark добавляет `data-readonly` к `Clipboard.Input`, когда поле доступно только для чтения.
- `Clipboard.Indicator` добавляет `data-slot="clipboard-indicator-idle-icon"` и
  `data-slot="clipboard-indicator-copied-icon"` к стандартным узлам иконок.
