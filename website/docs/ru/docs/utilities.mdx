# Утилиты

Используйте утилиту, когда приложение само управляет окружающей разметкой или поведением. Если нужное
взаимодействие уже реализует компонент moduix, начните с него.

Ниже собраны прямые утилиты Ark UI и компоненты moduix на базе тех же примитивов. Утилиты Ark UI отвечают за
поведение, зависящее от фреймворка, и не задают систему стилей. `Highlight`, `JsonTreeView` и `Swap` оборачивают
соответствующие примитивы Ark UI и добавляют композицию и стили moduix. Они доступны в пакетах React и Solid для
обоих вариантов стилизации.

## Компоненты moduix на базе Ark UI

Эти компоненты сохраняют один публичный API в пакетах React и Solid для обоих вариантов стилизации. Пакеты с CSS
Modules поставляют стили компонентов. Tailwind-пакеты используют нативные utility-классы и позволяют переопределять
их классами потребителя.

## Контекст Locale

`Locale` передаёт локаль и направление текста форматтерам Ark UI и компонентам, работающим с локалью. Это контекст
фреймворка, а не стилизованный компонент: в React используйте `@moduix/react/locale`, а в Solid -
`@moduix/solid/locale`. Настройка пакетов и таблиц стилей описана в разделе [Quick Start](/docs/quick-start).
