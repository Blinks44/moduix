# Утилиты

В этом разделе собраны низкоуровневые инструменты Ark UI и обёртки moduix. Они пригодятся, когда нужно
отрисовать содержимое только в браузере, работать с iframe или другим документом, управлять фокусом, форматировать
значения, обрабатывать сочетания клавиш или контролировать, когда содержимое появляется в DOM.

В большинстве руководств используется прямой импорт из Ark UI. `Highlight`, `JsonTreeView` и `Swap` - обёртки
moduix с готовыми стилями или настройками, а `Locale` доступен через стабильный путь `@moduix/react/locale`.
В каждом руководстве показаны нужный импорт, рабочий пример и ссылка на полный API Ark.

Если взаимодействием уже управляет компонент moduix, начните с него. Одну из этих утилит стоит подключать, когда
приложение управляет окружающей разметкой или поведением.
