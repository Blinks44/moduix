# Утилиты

Утилиты Ark UI - небольшие строительные блоки для задач, которые не относятся к конкретному компоненту moduix:
рендеринга в браузере, работы с другим документом, управления фокусом, форматирования и жизненного цикла.

Если нужным взаимодействием уже управляет компонент moduix, начните с него. Подключайте утилиту напрямую, когда
разметкой или поведением вокруг неё управляет приложение. На каждой странице есть рекомендуемый импорт, рабочие
примеры и ссылка на полный API Ark.
