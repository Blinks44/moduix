## Справочник API

В Ark UI нет отдельного примитива для отображения клавиш. `Kbd` в moduix построен на официальной [фабрике Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory), поэтому использует привычные для Ark подходы к композиции,
стилизации и работе с `ref`. Подробнее о них можно узнать в руководствах Ark: [композиция](https://ark-ui.com/docs/guides/composition), [стилизация](https://ark-ui.com/docs/guides/styling) и [работа с ref](https://ark-ui.com/docs/guides/ref).

## Анатомия

Структура сочетания проста. Знак `+` в этой схеме является обычным текстом, а не отдельной частью компонента.

```text
Kbd.Group
├─ Kbd / Kbd.Root
├─ +
└─ Kbd / Kbd.Root
```

| Часть               | Назначение                                                                  |
| ------------------- | --------------------------------------------------------------------------- |
| `Kbd` / `Kbd.Root` | Корневой элемент клавиши. По умолчанию выводит элемент `<kbd>`.             |
| `Kbd.Group`         | Строчный контейнер для связанных клавиш. По умолчанию получает роль `group`. |

## Композиция

### Рекомендуемая композиция

В обычном случае используйте `Kbd` как короткую запись `Kbd.Root` для отдельных клавиш. `Kbd.Group` объединяет клавиши
в одно сочетание, подсказку для меню команд или встроенную справку.

`Kbd` и `Kbd.Root` принимают `HTMLArkProps<'kbd'>`, а `Kbd.Group` принимает `HTMLArkProps<'span'>` и по умолчанию
получает `role="group"`. Все части передают `ref` конечному элементу и поддерживают `asChild`.
В API нет свойств для вариантов оформления, размеров, разделителей, колбэков или состояния.

### Когда нужна собственная композиция

Используйте `asChild`, если семантический элемент `<kbd>` уже создаёт другой компонент и к нему нужно применить стили Kbd.
Передайте ровно один дочерний элемент и сохраните семантику обозначения клавиши.

### Особенности поведения

- `Kbd`, `Kbd.Root` и `Kbd.Group` выводят статичные обозначения клавиш. Это не интерактивные элементы управления.
- Оставляйте `+`, `/` и слова вроде `then` обычным текстом за пределами `Kbd`.
- Добавьте `aria-label` к `Kbd.Group`, если сокращение или символ могут быть непонятны при чтении с экрана.
- Части компонента предоставляют `data-scope="kbd"`, `data-part` и стабильные атрибуты `data-slot`.

## Стилизация

Настраивайте `Kbd` и `Kbd.Group` с помощью `className`, атрибутов анатомии Ark, стабильных хуков `data-slot` и публичных
CSS-переменных `--moduix-kbd-*`, перечисленных ниже.

### CSS-свойства

<CssPropertiesSection properties={KbdDocs.kbdOverrideCssProperties} />

### Хуки стилизации

- `data-slot="kbd-root"` выбирает отдельный элемент клавиши
- `data-slot="kbd-group"` выбирает строчный контейнер для сгруппированных сочетаний
- `[data-scope="kbd"][data-part="root"]` и `[data-part="group"]` предоставляют селекторы анатомии в стиле Ark
- Разделители в `Kbd.Group` наследуют цвет текста группы. Чтобы задать этот цвет, используйте `--moduix-kbd-group-separator-color`
