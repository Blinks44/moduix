## Справочник API

В Ark UI нет отдельного примитива для отображения клавиш. В moduix этот компонент создан на основе официальной
[фабрики Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory) и соответствует рекомендациям Ark по
[композиции](https://ark-ui.com/docs/guides/composition), [стилизации](https://ark-ui.com/docs/guides/styling) и
[работе с ref](https://ark-ui.com/docs/guides/ref).

## Базовый пример

Используйте `Kbd` для одной клавиши. Для сочетания из нескольких клавиш объедините их в `Kbd.Group`.

## Анатомия

Обычно достаточно такой композиции:

```text
Kbd.Group
├─ Kbd / Kbd.Root
├─ +
└─ Kbd / Kbd.Root
```

| Часть               | Назначение                                                   |
| ------------------- | ------------------------------------------------------------ |
| `Kbd` / `Kbd.Root` | Корневой элемент клавиши. По умолчанию это элемент `kbd`. |
| `Kbd.Group`         | Строчный контейнер для сочетания клавиш, который по умолчанию получает роль `group`. |

## Композиция

### Рекомендуемая композиция

Для большинства случаев используйте `Kbd` как короткую запись корневого элемента, а `Kbd.Group` для подсказок о сочетаниях
клавиш, меню команд и встроенной справки.

`Kbd` и `Kbd.Root` принимают `HTMLArkProps<'kbd'>`; `Kbd.Group` принимает `HTMLArkProps<'span'>` и по умолчанию
получает `role="group"`. Каждая часть передаёт `ref` отрисованному элементу и поддерживает `asChild`.
У компонента нет API для вариантов, размеров, разделителей, колбэков или состояния.

### Когда нужна собственная композиция

Используйте `asChild`, если другой слой уже отвечает за семантический элемент `<kbd>`, а вам нужно добавить к нему стили
Kbd и композицию Ark. Передайте ровно один дочерний элемент и сохраните семантику клавиши.

### Особенности поведения

- `Kbd`, `Kbd.Root` и `Kbd.Group` выводят статические обозначения клавиш, а не интерактивные элементы управления.
- Разделители, такие как `+`, `/` или `then`, оставляйте обычным текстом в окружающей композиции.
- Добавьте `aria-label` к `Kbd.Group`, если сокращение или символ может быть непонятен при озвучивании.
- Части предоставляют `data-scope="kbd"`, `data-part` и стабильные атрибуты `data-slot`.

## Стилизация

Стилизуйте `Kbd` и `Kbd.Group` с помощью `className`, атрибутов анатомии Ark, стабильных хуков `data-slot` и публичных
CSS-переменных `--moduix-kbd-*`, перечисленных ниже.

### CSS-свойства

<CssPropertiesSection properties={KbdDocs.kbdOverrideCssProperties} />

### Хуки стилизации

- `data-slot="kbd-root"` выбирает отдельный элемент клавиши
- `data-slot="kbd-group"` выбирает строчный контейнер для сгруппированных сочетаний
- `[data-scope="kbd"][data-part="root"]` и `[data-part="group"]` предоставляют селекторы анатомии в стиле Ark
- `Kbd.Group` наследует окружающий стиль текста для разделителей. Их цвет задаёт `--moduix-kbd-group-separator-color`
