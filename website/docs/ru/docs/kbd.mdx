## Справочник API

В Ark UI нет отдельного примитива для отображения клавиш. `Kbd` в moduix построен на официальной [фабрике Ark](https://ark-ui.com/docs/guides/composition#the-ark-factory), поэтому использует привычные для Ark подходы к композиции,
стилизации и работе с `ref`. Подробнее о них можно узнать в руководствах Ark: [композиция](https://ark-ui.com/docs/guides/composition), [стилизация](https://ark-ui.com/docs/guides/styling) и [работа с ref](https://ark-ui.com/docs/guides/ref).

## Анатомия

Структура сочетания проста. Знак `+` в этой схеме является обычным текстом, а не отдельной частью компонента.

```text
KbdGroup
├─ Kbd
├─ +
└─ Kbd
```

| Часть               | Назначение                                                                  |
| ------------------- | --------------------------------------------------------------------------- |
| `Kbd`              | Корневой элемент клавиши. По умолчанию выводит элемент `<kbd>`.             |
| `KbdGroup`         | Строчный контейнер для связанных клавиш. По умолчанию получает роль `group`. |

## Композиция

Используйте `Kbd` для отдельной клавиши, а `KbdGroup` для объединения связанных клавиш. Оставляйте разделители, например `+`, обычным текстом внутри группы и добавляйте `aria-label`, если визуальные символы или сокращения могут быть непонятны без контекста.

Kbd не хранит состояние и не обрабатывает нажатия клавиш. Используйте `asChild`, только когда другой компонент должен вывести семантический элемент `<kbd>`; передавайте ровно один дочерний элемент.

### Компактный размер

Используйте локальные CSS-переменные, если в отдельной части интерфейса нужны более компактные клавиши. Для этого не нужно добавлять новые свойства компонента.

### Пользовательский элемент

Используйте `asChild`, если другой компонент уже выводит семантический элемент `<kbd>` и к нему нужно применить стили Kbd.

### Список сочетаний

Объедините `KbdGroup` с поясняющим текстом, чтобы показать список доступных сочетаний клавиш.

<Example name="kbd/shortcut-list" />

### Одна клавиша

Используйте `Kbd` напрямую, если нужно показать одну клавишу, например `Esc`.

<Example name="kbd/single-key" />

### С иконкой

Иконку можно положить прямо в `Kbd`: она получает размер под текст клавиши, если у самой иконки нет класса размера. Задайте группе `aria-label`, чтобы у сочетания было понятное озвучиваемое название.

## Стилизация

Настраивайте `Kbd` и `KbdGroup` с помощью `className` в React или `class` в Solid и Vue, атрибутов анатомии Ark, стабильных хуков `data-slot` и публичных CSS-переменных `--moduix-kbd-*`, перечисленных ниже. Варианты Tailwind используют нативные utility-классы, а варианты CSS Modules используют переменные компонента и CSS приложения.

### Хуки стилизации

- `data-slot="kbd-root"` выбирает отдельный элемент клавиши
- `data-slot="kbd-group"` выбирает строчный контейнер для сгруппированных сочетаний
- `[data-scope="kbd"][data-part="root"]` и `[data-part="group"]` предоставляют селекторы анатомии в стиле Ark
- Разделители в `KbdGroup` наследуют цвет текста группы. Чтобы его изменить, задайте `color` для `KbdGroup` своим классом
