## Что делает Presence

`Presence` является утилитой Ark UI, а не компонентом, экспортируемым из `@moduix/react`. Он управляет одним
поддеревом через свойство `present`. В зависимости от параметров стратегии рендеринга это поддерево может оставаться
смонтированным и скрытым, монтироваться только при первом показе или размонтироваться после анимации выхода.

По умолчанию Presence рендерит корневой `<div>` с атрибутами `data-scope="presence"` и `data-part="root"`. На корень
также добавляется `data-state="open"` или `data-state="closed"`, поэтому состояния появления и исчезновения можно
настроить с помощью CSS. Укажите `asChild`, если существующий дочерний элемент должен получить свойства Presence без
дополнительной обёртки.

Импортируйте Presence напрямую из Ark UI:

```tsx
import { Presence } from '@ark-ui/react/presence';
```

## Когда использовать

Используйте отдельный `Presence` для панелей, уведомлений, карточек и другого содержимого, которым управляет приложение
и для которого нужно явно контролировать жизненный цикл монтирования.

Для Dialog, Drawer, Lightbox, Menu, Popover, Tooltip, Tour и похожих корневых компонентов moduix используйте встроенные
свойства Presence. Эти компоненты уже согласуют монтирование с управлением фокусом, позиционированием и закрытием.
Отдельный `Presence` нужен, когда жизненным циклом содержимого управляет само приложение, а не существующий корневой
компонент moduix.

## Монтирование по требованию

Сочетайте `lazyMount` и `unmountOnExit`, если содержимое не должно существовать до первого показа и после закрытия.
`lazyMount` откладывает первое монтирование, но само по себе не удаляет содержимое при закрытии. За это отвечает
`unmountOnExit`.

## Анимации выхода

Когда включён `unmountOnExit`, Presence оставляет корень в DOM на время CSS-анимации выхода. Используйте
`data-state="open"` и `data-state="closed"`, чтобы задать стили появления и исчезновения. Если другой код должен
дождаться окончания анимации выхода, используйте `onExitComplete`.

```tsx
import { Presence } from '@ark-ui/react/presence';
import { Card } from '@moduix/react/card';

export function ActivityPanel({ open }: { open: boolean }) {
  return (
    <Presence className="activity-panel" present={open} unmountOnExit>
      <Card>Saved filters will apply to the next refresh.</Card>
    </Presence>
  );
}
```

```css
@keyframes activity-panel-enter {
  from {
    opacity: 0;
    transform: translateY(-0.25rem);
  }
}

@keyframes activity-panel-exit {
  to {
    opacity: 0;
    transform: translateY(-0.25rem);
  }
}

.activity-panel[data-state='open'] {
  animation: activity-panel-enter 160ms ease-out;
}

.activity-panel[data-state='closed'] {
  animation: activity-panel-exit 120ms ease-in;
}
```

Укажите `skipAnimationOnMount`, если первое появление не должно быть анимированным. Укажите `immediate`, если
изменение `present` нужно применить сразу, не откладывая его до следующего кадра.

## Как скрывать смонтированное содержимое

Если содержимое остаётся смонтированным, параметр `hideMode` определяет способ его скрытия:

- `display-none` используется по умолчанию. Он добавляет атрибут `hidden`, поэтому эффекты в поддереве продолжают
  работать.
- `activity` использует компонент `Activity` из React 19 с параметром `mode="hidden"`, приостанавливая эффекты
  скрытого содержимого. Этот режим требует React 19 или более новой версии. Если `Activity` недоступен, Ark
  возвращается к поведению с атрибутом `hidden`.

Выбирайте `lazyMount` и `unmountOnExit`, если поддерево не должно существовать вне активной части своего жизненного
цикла. Выбирайте `hideMode`, если содержимое должно оставаться смонтированным, но скрываться другим способом.

## Композиция

### Рекомендуемая композиция

Размещайте `Presence` непосредственно вокруг содержимого, жизненным циклом монтирования которого он управляет. Внутри
может находиться компонент moduix или семантический HTML-элемент. Передайте `className` корню Presence, если этому
контейнеру нужны стили компоновки или анимации.

### Когда использовать `asChild`

Используйте `asChild`, если у вас уже есть подходящий корневой элемент и свойства Presence нужно передать ему без
дополнительной обёртки. Убедитесь, что дочерний элемент принимает `ref`, `hidden`, `data-*` и передаваемый класс.
Не используйте `asChild` с несколькими дочерними элементами.

## Использование с moduix

Внутри `Presence` можно разместить любой компонент moduix: карточки, кнопки, формы и собственные панели сохранят
обычные стили и поведение. Presence управляет только жизненным циклом монтирования и атрибутами состояния, не меняя
семантику и модель взаимодействия дочернего элемента.

## Ark UI и moduix

Ark UI предоставляет API `Presence`, управляет стратегией монтирования и жизненным циклом анимации. `@moduix/react` не экспортирует
`Presence`, поэтому импортируйте его из `@ark-ui/react/presence`, а компоненты moduix размещайте внутри. Корневые
компоненты moduix, которые сами управляют открытием, закрытием или поведением оверлея, предоставляют аналогичные
свойства Presence там, где это уместно.

Если вы используете отдельный Presence вместе с moduix, установите оба пакета:

```bash
pnpm add @ark-ui/react @moduix/react
```
