## Базовый жизненный цикл

`Presence` - утилита Ark UI для содержимого, жизненным циклом которого управляет приложение. Она
рендерит одно поддерево, пока `present` равно `true`, и добавляет `data-state="open"` или `data-state="closed"`
для стилизации состояний.

Укажите `unmountOnExit`, если поддерево нужно удалить после анимации выхода. Без этого параметра корень остаётся
смонтированным, а Ark скрывает его атрибутом `hidden`, когда `present` становится `false`.

## Монтирование по требованию

Добавьте `lazyMount`, если содержимое не должно монтироваться до первого появления. Сочетайте его с
`unmountOnExit`, если содержимое должно отсутствовать и до первого открытия, и после закрытия.

Сам по себе `lazyMount` только откладывает первое монтирование и не удаляет поддерево после закрытия.

## Анимации выхода и обратные вызовы

При включённом `unmountOnExit` Ark оставляет корень смонтированным, пока выполняется CSS-анимация выхода. Задавайте
стили для `data-state="open"` и `data-state="closed"` в таблице стилей того же корня. Используйте
`onEnterComplete` и `onExitComplete`, если окружающий интерфейс или аналитика должны реагировать после завершения
анимации.

## Параметры, влияющие на рендеринг

| Параметр | Поведение |
| --- | --- |
| `present` | Управляет присутствием поддерева. |
| `lazyMount` | Откладывает первое монтирование до момента, когда `present` станет `true`. |
| `unmountOnExit` | Удаляет корень после завершения анимации закрытого состояния. |
| `onEnterComplete` / `onExitComplete` | Вызываются после завершения анимации появления или выхода. |
| `skipAnimationOnMount` | Отключает начальную анимацию присутствия. |
| `immediate` | Применяет изменение `present` сразу, не дожидаясь следующего кадра. |
| `hideMode` | Только React. `display-none` использует `hidden`, а `activity` приостанавливает эффекты через `Activity` из React 19. |

Общие параметры жизненного цикла и обратные вызовы имеют одинаковый смысл в React и Solid. Ark Solid не экспортирует
`hideMode`: смонтированное, но отсутствующее содержимое скрывается атрибутом `hidden`.

## Композиция и доступность

Используйте `Presence`, когда приложение управляет жизненным циклом панели, уведомления, карточки или другого
поддерева. Утилита не добавляет управление фокусом, закрытие, позиционирование или семантику диалога. Для Dialog,
Drawer, Menu, Popover, Tooltip, Tour и других интерактивных корней используйте их собственные параметры Presence,
чтобы сохранить согласованную модель взаимодействия.

По умолчанию `Presence` рендерит `<div>` с атрибутами `data-scope="presence"` и `data-part="root"`. Укажите
`asChild`, если эти свойства должен получить существующий элемент без дополнительной обёртки. Дочерний элемент React
должен принимать передаваемые ref, `hidden`, `data-*` и класс. В Solid используется форма с render-функцией:
`asChild={(props) => <article {...props()} />}`. В обоих фреймворках сохраняйте один семантический корень и его
доступное имя и содержимое. Не заменяйте поведение `hidden` одной только прозрачностью, если неактивное содержимое
должно исчезать из дерева доступности.
