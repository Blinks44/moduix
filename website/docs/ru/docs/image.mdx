выпущенного адаптера с тем же публичным контрактом.

Используйте `Image` с URL из поддерживаемого CDN или с обычным URL изображения. В режиме
`layout="constrained"` укажите `width` и `height`. Если Unpic распознаёт провайдера, он генерирует
адаптивные атрибуты `srcset` и `sizes`. Для остальных URL Unpic сохраняет исходный адрес без изменений,
но стили `layout` применяются и к ним.
Браузер заранее резервирует место под изображение до его загрузки.

Изображения по умолчанию используют `loading="lazy"` и `decoding="async"`, в том числе
локальные файлы и URL без поддерживаемого CDN. Для главного изображения на первом экране
укажите `priority`: он задаёт `loading="eager"` и `fetchpriority="high"`, не устанавливая
`decoding`. Явно заданные нативные атрибуты имеют преимущество перед этими значениями.

## Примеры

### Фиксированный размер

Используйте `layout="fixed"`, когда изображение должно сохранять точные размеры в CSS-пикселях.
Проверьте, что в родительском контейнере достаточно места: фиксированное изображение не уменьшится,
чтобы поместиться в более узкий контейнер.

<Example name="image/fixed" />

### На всю ширину

Используйте `layout="fullWidth"` для главного изображения или медиа-блока, который должен занять
всю ширину контейнера. Передайте `height`, если высота кадрирования должна оставаться фиксированной.

<Example name="image/full-width" />

### Адаптивное кадрирование

Используйте `ImageSource`, чтобы на больших экранах показывать широкий план офиса, а на маленьких
экранах использовать изображение в портретной ориентации. Первый источник для больших экранов
запрашивает AVIF, а следующий служит запасным вариантом для браузеров без поддержки AVIF.
`ImageSource` должен находиться внутри нативного `<picture>`.

## Композиция

Компонент `Image` в moduix представляет собой лёгкую обёртку над нативным `<img>` и API [Unpic](https://unpic.pics/img/).
В Ark UI нет отдельного примитива для изображений. Поэтому `Image` использует нативную композицию `<img>` и `<picture>`
вместо части Ark UI. Подробнее о модели нативных элементов рассказывает [руководство Ark по композиции](https://ark-ui.com/docs/guides/composition).

`Image` является корневым компонентом и может использоваться напрямую. Используйте `ImageSource`
только внутри нативного `<picture>` и оставляйте `Image` последним, чтобы он оставался запасным
изображением, если браузер не выбрал источник. Для выбора формата поставьте источник с `type`
перед эквивалентным источником без `type`: браузер выберет первый поддерживаемый формат.
`ImageSource` генерирует `srcset` только для поддерживаемого CDN или провайдера `fallback`; для локальных
файлов используйте нативный `<source srcset>`.

## Стилизация

Используйте `className` в React или `class` в Solid и Vue на `Image` и `ImageSource` для локальной
стилизации. Варианты Tailwind используют нативные утилиты и классы потребителя. Переменная
`--moduix-image-radius` настраивает варианты с CSS Modules, а хуки `data-slot` общие для обоих
вариантов стилизации.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `Image` | `image-root` |
| `ImageSource` | `image-source` |

- `data-slot="image-root"` позволяет выбрать отрисованный `<img>` в CSS.
- `data-slot="image-source"` позволяет выбрать узел `<source>` внутри нативного `<picture>`.
- `className` в React и `class` в Solid и Vue являются рекомендуемым способом локальной стилизации.

## Справочник API

`Image` принимает пропсы изображения Unpic и нативные пропсы `img`.

| Проп | Тип | По умолчанию |
| --- | --- | --- |
| `src` | `string` | — |
| `alt` | `string` | — |
| `layout` | `'constrained' \| 'fixed' \| 'fullWidth'` | `'constrained'` |
| `width` | `number` | — |
| `height` | `number` | — |
| `aspectRatio` | `number` | — |
| `priority` | `boolean` | `false` |
| `background` | `string` | — |
