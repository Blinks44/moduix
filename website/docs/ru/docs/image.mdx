## Справочник API

Компонент `Image` в moduix представляет собой лёгкую обёртку над компонентом `<img>` из [Unpic React](https://unpic.pics/img/react/).
В Ark UI нет отдельного примитива для изображений. Поэтому `Image` использует нативную композицию `<img>` и `<picture>`,
а не композицию из частей Ark UI. Подробнее о модели нативных элементов рассказывает [руководство Ark по композиции](https://ark-ui.com/docs/guides/composition).

## Базовый пример

Используйте `Image` с URL из поддерживаемого CDN или с обычным URL изображения. В режиме `layout="constrained"` укажите
`width` и `height`. Если Unpic распознаёт провайдера, он генерирует адаптивные атрибуты `srcset` и `sizes`. Для остальных
URL Unpic сохраняет исходный адрес без изменений. Браузер заранее резервирует место под изображение до его загрузки.

## Анатомия

```text
Image / Image.Root
└─ img

picture (native)
├─ Image.Source
└─ Image / Image.Root
```

| Часть                  | Роль                                                                            |
| ---------------------- | ------------------------------------------------------------------------------ |
| `Image` / `Image.Root` | Адаптивный нативный элемент `<img>`; Unpic генерирует `srcset`, `sizes` и стили. |
| `Image.Source`         | Адаптивный `<source>` для нативного элемента `<picture>`.                      |

## Композиция

### Рекомендуемая композиция

Короткая запись `Image` соответствует корневому компоненту `Image.Root`. Для режимов `layout="constrained"` и
`layout="fixed"` укажите `width` и `height`, чтобы браузер зарезервировал место перед загрузкой. В режиме
`constrained` эти размеры сохраняют соотношение сторон и позволяют изображению уменьшаться, если контейнер стал уже.
Если URL получен от поддерживаемого провайдера, Unpic определит его и автоматически сгенерирует `srcset` с
преобразованными вариантами изображения.

Используйте `priority` только для изображений, которые должны загрузиться сразу, например для главного изображения,
видимого при открытии страницы. Свойство включает немедленную загрузку и повышает приоритет загрузки, если явно не задать
нативный `loading` или React-свойство `fetchPriority` в camelCase.

### Когда нужна собственная композиция

Используйте нативный `<picture>` с `Image.Source`, если для разных экранов нужно менять кадрирование или выбирать разные
источники по медиазапросам. Всегда оставляйте `Image` последним дочерним элементом. Он служит запасным изображением,
если браузер не выберет ни один элемент `<source>`. Передавайте `fallback`, `options` или `operations`, если Unpic не
распознаёт URL и должен использовать конкретного провайдера.

Чтобы выбрать формат, поставьте `Image.Source` со значением `type` перед эквивалентным источником без `type`. Браузер
выберет первый поддерживаемый формат.

### Свойства по умолчанию

| Свойство                | По умолчанию                       | Примечания                                                               |
| ----------------------- | --------------------------------- | ------------------------------------------------------------------------ |
| `layout`                | `constrained`                     | Вписывается в указанные размеры и при необходимости уменьшается.        |
| `loading`               | `lazy`                            | Становится `eager`, когда задан `priority`.                              |
| `decoding`              | `async` для изображений без `priority` | Нативное значение сохраняется; при `priority` по умолчанию не задаётся. |
| `fetchPriority`         | `high` с `priority`                | Нативное значение переопределяет значение, заданное `priority`.         |
| `objectFit`             | `cover`                           | Добавляется во встроенные стили, которые генерирует Unpic.               |
| `--moduix-image-radius` | `var(--moduix-radius-md)`         | Стандартный видимый радиус скругления в moduix.                          |

### Особенности поведения

- `fixed` сохраняет указанные размеры в CSS-пикселях и может выходить за границы более узкого родительского контейнера,
  а `fullWidth` заполняет ширину контейнера.
- Для информативных изображений указывайте содержательный текст в `alt`. Для декоративных используйте `alt=""`.
  В этом случае Unpic добавляет `role="presentation"`, если вы явно не переопределили роль.
- Используйте `aspectRatio` вместо `width` и `height`, если нужно указать только соотношение сторон изображения.
- Unpic генерирует `srcset` на основе URL источника. Используйте `breakpoints`, если стандартный набор адаптивных ширин
  не подходит.
- Unpic автоматически определяет поддерживаемые провайдеры изображений. Для остальных URL он сохраняет исходный адрес
  без изменений, если не передать провайдер через `fallback`.
- Нативные `loading`, `decoding` и React-свойство `fetchPriority` в camelCase остаются доступными, если нужны другие
  настройки загрузки.
- `background="auto"` создаёт фоновое изображение с низким разрешением для поддерживаемых провайдеров. После загрузки
  основного изображения фон остаётся, поэтому используйте эту настройку только для непрозрачных изображений или задайте
  собственный фон.
- `unstyled` отключает встроенные стили раскладки, которые генерирует Unpic. Стиль отображения и скругление, а также хуки
  `data-slot` moduix остаются доступными. Используйте эту настройку, если источникам с разным кадрированием нужны свои
  адаптивные правила. Задайте их в собственном CSS.

## Примеры

### Адаптивное кадрирование

Используйте `Image.Source`, чтобы на больших экранах показывать широкий план офиса, а на маленьких экранах использовать
изображение в портретной ориентации. Первый источник для больших экранов запрашивает AVIF. Следующий источник с тем же медиазапросом
служит запасным вариантом для браузеров без поддержки AVIF. `Image.Source` должен находиться внутри нативного `<picture>`.

### Фиксированный размер

Используйте `layout="fixed"`, когда изображение должно сохранять точные размеры в CSS-пикселях. Проверьте, что в
родительском контейнере достаточно места: фиксированное изображение не уменьшится, чтобы поместиться в более узкий

### Хуки стилизации

- `data-slot="image-root"` позволяет выбрать отрисованный `<img>` в CSS.
- `data-slot="image-source"` позволяет выбрать узел `<source>` внутри нативного `<picture>`.
- `className` у `Image` служит рекомендуемым способом локальной стилизации. Корневой элемент по умолчанию блочный.
