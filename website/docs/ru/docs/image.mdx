## Справочник API

Компонент `Image` оборачивает `<img>` из [Unpic React](https://unpic.pics/img/react/).
В Ark UI нет отдельного примитива для изображений, поэтому `Image` использует стандартные HTML-элементы `<img>` и
`<picture>`, а не композицию из частей Ark. Подробнее о модели нативных элементов рассказывает [руководство Ark по
композиции](https://ark-ui.com/react/docs/guides/composition).

## Базовый пример

Используйте `Image` с URL изображения из поддерживаемого CDN и укажите `width` и `height`. По умолчанию компонент
использует режим `layout="constrained"`. Unpic генерирует адаптивные `srcSet` и `sizes`, а браузер заранее резервирует
место под изображение до его загрузки.

## Анатомия

```text
Image / Image.Root
└─ img

picture (native)
├─ Image.Source
└─ Image / Image.Root
```

| Часть                  | Роль                                                                            |
| ---------------------- | ------------------------------------------------------------------------------ |
| `Image` / `Image.Root` | Адаптивный нативный элемент `<img>`; Unpic генерирует `srcSet`, `sizes` и стили. |
| `Image.Source`         | Адаптивный `<source>` для нативного элемента `<picture>`.                      |

## Композиция

### Рекомендуемая композиция

`Image` представляет собой сокращённую форму корневого компонента, эквивалентную `Image.Root`. В режиме `layout="constrained"`
передайте `width` и `height`. Это сохраняет соотношение сторон и позволяет браузеру заранее зарезервировать место,
чтобы содержимое не сдвигалось во время загрузки. Если URL получен от поддерживаемого провайдера, Unpic определит его
и автоматически сгенерирует преобразованные значения `srcSet`.

Используйте `priority` только для изображений, которые должны загрузиться сразу, например для главного изображения,
видимого при открытии страницы. Свойство включает немедленную загрузку и повышает приоритет загрузки, если явно не
задать нативный `loading` или React-свойство `fetchPriority` в camelCase.

### Когда нужна своя разметка

Используйте нативный `<picture>` с `Image.Source`, если изображение нужно по-разному кадрировать на разных экранах или
выбирать источники по медиазапросам. Оставляйте `Image` последним дочерним элементом: он будет запасным изображением.
Передавайте `fallback`, `options` или `operations`, если Unpic не распознаёт URL и должен использовать определённого
провайдера.

Для выбора формата поместите `Image.Source` со значением `type` перед эквивалентным источником без `type`. Браузер
выберет первый поддерживаемый формат.

### Свойства по умолчанию

| Свойство                | По умолчанию                       | Примечания                                                               |
| ----------------------- | --------------------------------- | ------------------------------------------------------------------------ |
| `layout`                | `constrained`                     | Вписывается в указанные размеры и при необходимости уменьшается.        |
| `loading`               | `lazy`                            | Становится `eager`, когда задан `priority`.                              |
| `decoding`              | `async` для изображений без `priority` | Нативное значение сохраняется; при `priority` по умолчанию не задаётся. |
| `fetchPriority`         | `high` с `priority`                | Нативное значение переопределяет значение, заданное `priority`.         |
| `objectFit`             | `cover`                           | Добавляется во встроенные стили, которые генерирует Unpic.               |
| `--moduix-image-radius` | `var(--moduix-radius-md)`         | Стандартный видимый радиус скругления в moduix.                          |

### Особенности поведения

- `fixed` сохраняет указанные размеры в CSS-пикселях и может выходить за границы более узкого родительского контейнера,
  а `fullWidth` заполняет ширину контейнера.
- `alt` обязателен для информативных изображений. Для декоративных используйте `alt=""`: в этом случае Unpic применяет
  `role="presentation"`, если вы явно не переопределите роль.
- Unpic генерирует `srcSet` на основе URL источника. Используйте `breakpoints`, если стандартный набор адаптивных ширин
  не подходит.
- Нативные `loading`, `decoding` и React-свойство `fetchPriority` в camelCase остаются доступными, если нужны другие
  настройки загрузки.
- `background="auto"` создаёт фон с низким разрешением для поддерживаемых провайдеров. После загрузки изображения фон
  остаётся, поэтому используйте эту настройку только для непрозрачных изображений или задайте собственное значение
  фона.
- `unstyled` отключает встроенные стили компоновки, которые генерирует Unpic. Стиль отображения и скругление, а также хуки
  `data-slot` moduix остаются доступными. Используйте эту настройку, если источникам с разным кадрированием нужны свои
  адаптивные правила. Задайте их в собственном CSS.

## Примеры

### Адаптивное кадрирование

Используйте `Image.Source`, чтобы на больших экранах показывать более широкий вид офиса, а на маленьких использовать
портретное запасное изображение. Первый источник для больших экранов запрашивает AVIF, следующий источник с тем же
медиазапросом служит запасным вариантом для браузеров без поддержки AVIF. `Image.Source` должен находиться внутри
нативного `<picture>`.

### Фиксированный размер

Используйте `layout="fixed"`, когда изображение должно сохранять точные размеры в CSS-пикселях. Проверьте, что в
родительском контейнере достаточно места: фиксированное изображение не уменьшится, чтобы поместиться в более узкий
контейнер.

Передайте `height`, если высота кадрирования должна оставаться фиксированной.

### Хуки стилизации

- `data-slot="image-root"` позволяет выбрать отрисованный `<img>` в CSS.
- `data-slot="image-source"` позволяет выбрать узел `<source>` внутри нативного `<picture>`.
- `className` у `Image` служит рекомендуемым способом локальной стилизации. Корневой элемент по умолчанию блочный.
