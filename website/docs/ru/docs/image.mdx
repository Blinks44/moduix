## Справочник API

Компонент `Image` в moduix представляет собой лёгкую обёртку над компонентом `<img>` из [Unpic React](https://unpic.pics/img/react/).
В Ark UI нет отдельного примитива для изображений. Поэтому `Image` использует нативную композицию `<img>` и `<picture>`
вместо части Ark UI. Подробнее о модели нативных элементов рассказывает [руководство Ark по композиции](https://ark-ui.com/docs/guides/composition).

## Базовый пример

`Image` доступен для React и Solid в вариантах с CSS Modules и Tailwind. Пример на этой странице
отрисовывается пакетом React CSS Modules, а во вкладках показан нативный исходный код для обоих
фреймворков с тем же публичным контрактом.

Используйте `Image` с URL из поддерживаемого CDN или с обычным URL изображения. В режиме
`layout="constrained"` укажите `width` и `height`. Если Unpic распознаёт провайдера, он генерирует
адаптивные атрибуты `srcset` и `sizes`. Для остальных URL Unpic сохраняет исходный адрес без изменений.
Браузер заранее резервирует место под изображение до его загрузки.

## Анатомия

```text
Image / Image.Root
└─ img

picture (native)
├─ Image.Source
└─ Image / Image.Root
```

| Часть                  | Роль                                                                   |
| ---------------------- | ---------------------------------------------------------------------- |
| `Image` / `Image.Root` | Адаптивный нативный элемент `<img>`; Unpic генерирует `srcset`, `sizes` и стили. |
| `Image.Source`         | Адаптивный `<source>` для нативного элемента `<picture>`.              |

## Композиция

`Image` является корневым компонентом и может использоваться напрямую. Используйте `Image.Source`
только внутри нативного `<picture>` и оставляйте `Image` последним, чтобы он оставался запасным
изображением, если браузер не выбрал источник. Для выбора формата поставьте источник с `type`
перед эквивалентным источником без `type`: браузер выберет первый поддерживаемый формат.

## Примеры

### Адаптивное кадрирование

Используйте `Image.Source`, чтобы на больших экранах показывать широкий план офиса, а на маленьких
экранах использовать изображение в портретной ориентации. Первый источник для больших экранов
запрашивает AVIF, а следующий служит запасным вариантом для браузеров без поддержки AVIF.
`Image.Source` должен находиться внутри нативного `<picture>`.

## Стилизация

Используйте `className` в React или `class` в Solid на `Image` и `Image.Source` для локальной
стилизации. Варианты Tailwind используют нативные утилиты и классы потребителя. Переменная
`--moduix-image-radius` настраивает варианты с CSS Modules, а хуки `data-slot` общие для обоих
вариантов стилизации.

### CSS-свойства

<CssPropertiesSection properties={ImageDocs.imageCssProperties} />

### Хуки стилизации

- `data-slot="image-root"` позволяет выбрать отрисованный `<img>` в CSS.
- `data-slot="image-source"` позволяет выбрать узел `<source>` внутри нативного `<picture>`.
- `className` в React и `class` в Solid являются рекомендуемым способом локальной стилизации.
