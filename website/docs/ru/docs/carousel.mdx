## Анатомия

```text
Carousel / Carousel.Root
├─ Carousel.ItemGroup
│  └─ Carousel.Item[index]
├─ Carousel.Control
│  ├─ Carousel.PrevTrigger
│  └─ Carousel.NextTrigger
├─ Carousel.IndicatorGroup
│  └─ Carousel.Indicator[index]
└─ Carousel.ProgressText
```

| Элемент                       | Назначение                                                                 |
| ---------------------------- | -------------------------------------------------------------------------- |
| `Carousel` / `Carousel.Root` | Создаёт карусель и управляет её состоянием, навигацией и списком слайдов.  |
| `Carousel.RootProvider`       | Подключает части карусели к состоянию, созданному через `useCarousel()`.   |
| `Carousel.Control`            | Контейнер для кнопок навигации и других элементов управления.              |
| `Carousel.ItemGroup`          | Лента слайдов, содержащая элементы `Carousel.Item`.                       |
| `Carousel.Item`               | Отдельный слайд с постоянным значением `index`.                            |
| `Carousel.PrevTrigger`        | Кнопка перехода на предыдущую страницу.                                   |
| `Carousel.NextTrigger`        | Кнопка перехода на следующую страницу.                                   |
| `Carousel.Indicators`         | Удобный компонент moduix для стандартных индикаторов страниц.              |
| `Carousel.IndicatorGroup`     | Контейнер для пользовательских индикаторов страниц.                       |
| `Carousel.Indicator`          | Кнопка перехода на страницу с указанным индексом.                         |
| `Carousel.ProgressText`       | Текст с номером текущей страницы и общим числом страниц.                   |

`Carousel.Indicators` получает из контекста `pageSnapPoints` и создаёт по одному
`Carousel.Indicator` на страницу. Используйте его вместо ручного вывода
`Carousel.IndicatorGroup`, если достаточно стандартных индикаторов. Для стилизации созданных кнопок
можно передать `indicatorClassName`.

Для более сложных вариантов также доступны:

- `Carousel.Context`
- `Carousel.AutoplayTrigger`
- `Carousel.AutoplayIndicator`
- `Carousel.RootProvider`

`Carousel`, `useCarousel` и `useCarouselContext` экспортируются из `@moduix/react`. Сам компонент
также можно импортировать из `@moduix/react/carousel`.

## Композиция

### Рекомендуемая композиция

Используйте `Carousel` как корневой компонент, `Carousel.ItemGroup` как ленту слайдов, а
`Carousel.Control` как контейнер для навигации. Добавьте `Carousel.Indicators`, если достаточно
стандартных индикаторов в виде точек.

Обычно `Carousel.Control` размещают рядом с `Carousel.ItemGroup` и используют как панель навигации.
Если нужен компактный вариант в одну строку, `Carousel.ItemGroup` можно поместить внутрь
`Carousel.Control`.

`Carousel.Root` это явное имя того же корневого компонента, что и `Carousel`. Используйте его, если
в коде удобнее обращаться к частям через пространство имён.

### Когда нужна собственная композиция

Используйте `Carousel.Context` вместе с `Carousel.IndicatorGroup` и `Carousel.Indicator`, если нужна
своя раскладка индикаторов, миниатюры или прямой доступ к `pageSnapPoints`.

Используйте `Carousel.RootProvider` вместе с `useCarousel()`, если состояние карусели нужно создать
вне дерева компонентов и передать в несколько частей композиции.

Используйте `useCarouselContext()` в собственных дочерних компонентах, которым нужен API карусели
без функции-рендера в дочернем элементе.

Используйте `Carousel.AutoplayTrigger` и `Carousel.AutoplayIndicator`, если управление автопрокруткой
должно быть видимой частью интерфейса, а не только свойством корневого компонента.

### Свойства по умолчанию

| Свойство     | По умолчанию | Примечания                                                                                 |
| ------------ | ------------ | ------------------------------------------------------------------------------------------- |
| `slideCount` | -            | Обязательно для `Carousel` / `Carousel.Root`; для `RootProvider` передайте его в `useCarousel()`. |

### Особенности поведения

- `onPageChange(details)` использует формат callback Ark и передаёт активную страницу в `details.page`.
- Добавьте к `Carousel` или `Carousel.RootProvider` атрибут `aria-label` либо `aria-labelledby`, чтобы
  навигационный ориентир карусели получил доступное имя.
- `spacing`, `padding`, `slidesPerPage`, `slidesPerMove` и `autoSize` используют стандартные для Ark
  правила расчёта размеров и точек привязки.
- В вертикальной ориентации API не меняется. Встроенные шевроны moduix автоматически поворачиваются,
  а `--moduix-carousel-height` задаёт высоту корневого элемента.
- При `dir="rtl"` стандартные горизонтальные триггеры автоматически отражаются.
- `Carousel.ProgressText` сохраняет порядок чисел `current / total`, чтобы прогресс оставался читаемым
  в RTL-каруселях.
- `--moduix-carousel-indicator-size` управляет размером самой кнопки индикатора. Кольцо фокуса
  подстраивается под форму точки или активной капсулы.
- При `prefers-reduced-motion: reduce` лента прокручивается сразу, а moduix отключает переходы для
  элементов управления и индикаторов.

## Стилизация

Используйте `className` у экспортируемых элементов для структурных стилей. Для стилей состояний
предпочитайте атрибуты данных Ark (`data-part`, `data-orientation`, `data-current`, `data-dragging`)
и хуки `data-slot` из moduix.

### CSS-свойства

<CssPropertiesSection properties={CarouselDocs.carouselOverrideCssProperties} />

### Хуки стилизации

- `data-slot="carousel-root"`, `carousel-root-provider`, `carousel-control`, `carousel-item-group`,
  `carousel-item`, `carousel-prev-trigger`, `carousel-next-trigger`, `carousel-indicator-group`,
  `carousel-indicator`, `carousel-autoplay-trigger`, `carousel-autoplay-indicator` и
  `carousel-progress-text` это стабильные селекторы экспортируемых элементов.
- Ark также добавляет к отрендеренным узлам `data-scope="carousel"` и имена в `data-part`.
- `data-orientation="horizontal" | "vertical"` доступен у корневого компонента и структурных частей.
- `Carousel.ItemGroup` получает `data-dragging` во время перетаскивания.
- `Carousel.Indicator` получает `data-current`, а `Carousel.Item` получает `data-index` и `data-inview`.
- `Carousel.Indicator` получает `data-readonly`, а `Carousel.AutoplayTrigger` получает `data-pressed`.
