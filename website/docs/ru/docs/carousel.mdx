## Анатомия

```text
Carousel / Carousel.Root
├─ Carousel.ItemGroup
│  └─ Carousel.Item[index]
├─ Carousel.Control
│  ├─ Carousel.PrevTrigger
│  └─ Carousel.NextTrigger
├─ Carousel.Indicators
│  └─ Carousel.IndicatorGroup
│     └─ Carousel.Indicator[index]
└─ Carousel.ProgressText
```

| Часть                        | Назначение                                                      |
| ---------------------------- | -------------------------------------------------------------- |
| `Carousel` / `Carousel.Root` | Управляет состоянием карусели, навигацией и коллекцией элементов. |
| `Carousel.Control`           | Контейнер для триггеров навигации и дополнительных элементов управления. |
| `Carousel.ItemGroup`         | Лента слайдов, содержащая части `Carousel.Item`.                  |
| `Carousel.Item`              | Отдельный слайд со стабильным `index`.                             |
| `Carousel.PrevTrigger`       | Триггер перехода на предыдущую страницу.                          |
| `Carousel.NextTrigger`       | Триггер перехода на следующую страницу.                           |
| `Carousel.Indicators`        | Удобная обёртка moduix для стандартных индикаторов страниц.        |
| `Carousel.IndicatorGroup`    | Контейнер для индикаторов страниц.                                 |
| `Carousel.Indicator`         | Триггер индикатора для определённого индекса слайда или страницы.  |
| `Carousel.ProgressText`      | Текст с текущей страницей и общим количеством страниц.             |

Эти части также доступны, если нужен более точный контроль:

- `Carousel.Context`
- `Carousel.AutoplayTrigger`
- `Carousel.AutoplayIndicator`
- `Carousel.RootProvider`

`useCarousel` и `useCarouselContext` доступны из `@moduix/react`.

## Композиция

### Рекомендуемая композиция

Используйте `Carousel` как корневой компонент, `Carousel.ItemGroup` как ленту слайдов, а `Carousel.Control` для
навигации. Добавляйте `Carousel.Indicators`, когда достаточно стандартных точечных индикаторов.

Обычно `Carousel.Control` располагается рядом с `Carousel.ItemGroup` и служит панелью инструментов.

`Carousel.Root` остаётся явным алиасом `Carousel`; используйте его, когда в коде нужна форма с пространством имён.

### Когда нужна нестандартная композиция

Используйте `Carousel.Context` вместе с `Carousel.IndicatorGroup` и `Carousel.Indicator`, когда нужна собственная
раскладка пагинации, индикаторы-миниатюры или более точный контроль над `pageSnapPoints`.

Используйте `Carousel.RootProvider` из moduix вместе с `useCarousel()`, когда состояние карусели нужно создать вне
дерева компонентов.

Используйте `useCarouselContext()` внутри собственных дочерних компонентов, которым нужен API карусели без
использования render prop.

Используйте `Carousel.AutoplayTrigger` и `Carousel.AutoplayIndicator`, когда управление автопрокруткой должно быть
видимой частью интерфейса, а не задаваться только свойством корневого компонента.

### Свойства по умолчанию

| Свойство     | По умолчанию | Примечания                            |
| ------------ | ------- | ----------------------------------------- |
| `slideCount` | -       | Обязательно для `Carousel` / `Carousel.Root`. |

### Особенности поведения

- `onPageChange(details)` использует формат callback Ark и передаёт активную страницу в `details.page`.
- Задайте `Carousel` или `Carousel.RootProvider` атрибут `aria-label` либо `aria-labelledby`, чтобы навигационный
  ориентир карусели получил доступное имя.
- `spacing`, `padding`, `slidesPerPage`, `slidesPerMove` и `autoSize` напрямую используют правила Ark для размеров
  и точек привязки.
- Вертикальные карусели используют тот же публичный API. Если компонент использует шевроны moduix, стандартные
  триггеры автоматически поворачиваются.
- При `dir="rtl"` стандартные горизонтальные триггеры автоматически меняют направление.
- `Carousel.ProgressText` сохраняет читаемый порядок чисел «текущий / всего» в RTL-каруселях.
- `--moduix-carousel-indicator-size` управляет компактной кнопкой индикатора, поэтому кольцо фокуса
  повторяет геометрию точки или активной капсулы.
- При `prefers-reduced-motion: reduce` лента прокручивается сразу, а moduix отключает переходы элементов управления
  и индикаторов.

## Стилизация

Используйте `className` на экспортируемых частях, чтобы изменить их структуру. Для стилизации состояний отдавайте
предпочтение data-атрибутам Ark (`data-part`, `data-orientation`, `data-current`, `data-dragging`) и хукам `data-slot`
из moduix.

### CSS-свойства

<CssPropertiesSection properties={CarouselDocs.carouselOverrideCssProperties} />

### Хуки стилизации

- `data-slot="carousel-root"`, `carousel-control`, `carousel-item-group`, `carousel-item`,
  `carousel-prev-trigger`, `carousel-next-trigger`, `carousel-indicator-group`,
  `carousel-indicator`, `carousel-autoplay-trigger`, `carousel-autoplay-indicator` и
  `carousel-progress-text` - стабильные селекторы экспортируемых частей.
- Ark также добавляет `data-scope="carousel"` и имена `data-part` на отрендеренные узлы.
- `data-orientation="horizontal" | "vertical"` доступен на корневом компоненте и структурных частях.
- `Carousel.ItemGroup` предоставляет `data-dragging` во время перетаскивания.
- `Carousel.Indicator` предоставляет `data-current`, а `Carousel.Item` - `data-index` и
  `data-inview`.
- `Carousel.Indicator` предоставляет `data-readonly`, а `Carousel.AutoplayTrigger` -
  `data-pressed`.
