## Анатомия

```text
Carousel
├─ CarouselItemGroup
│  └─ CarouselItem[index]
├─ CarouselControl
│  ├─ CarouselPrevTrigger
│  └─ CarouselNextTrigger
├─ CarouselIndicatorGroup
│  └─ CarouselIndicator[index]
└─ CarouselProgressText

CarouselRootProvider
└─ та же структура частей, подключённая к хранилищу useCarousel()
```

| Элемент                   | Назначение                                                        |
| ------------------------- | ----------------------------------------------------------------- |
| `Carousel`                | Управляет состоянием, навигацией и коллекцией слайдов.            |
| `CarouselRootProvider`    | Подключает части к состоянию, созданному через `useCarousel()`.   |
| `CarouselControl`           | Контейнер для кнопок навигации и других элементов управления.    |
| `CarouselItemGroup`         | Лента слайдов, содержащая части `CarouselItem`.                 |
| `CarouselItem`              | Отдельный слайд со стабильным `index`.                            |
| `CarouselPrevTrigger`       | Кнопка перехода на предыдущую страницу.                          |
| `CarouselNextTrigger`       | Кнопка перехода на следующую страницу.                           |
| `CarouselIndicators`        | Компонент moduix для стандартных точек страниц.                  |
| `CarouselIndicatorGroup`    | Контейнер для пользовательских индикаторов страниц.              |
| `CarouselIndicator`         | Кнопка перехода на страницу с указанным индексом.                |
| `CarouselProgressText`      | Текст с номером текущей страницы и общим числом страниц.          |

## Композиция

`Carousel` хранит состояние внутри корневого компонента. Используйте `defaultPage` для
неконтролируемой карусели, а `page` вместе с `onPageChange(details)`, если текущей страницей управляет
маршрутизация, фильтры или другая часть приложения. Свойство `slideCount` обязательно и должно
соответствовать отрисованным элементам при изменении коллекции.

Используйте `CarouselRootProvider` вместе с `useCarousel()`, если хранилище нужно создать вне дерева
компонентов или разделить между границами композиции. Передайте это хранилище в `CarouselRootProvider` и не
отрисовывайте второй корневой `Carousel` для того же состояния.

`CarouselIndicators` читает `pageSnapPoints` из контекста и создаёт стандартные индикаторы. Для
пользовательского содержимого индикаторов разместите `CarouselIndicatorGroup` и `CarouselIndicator`
внутри `CarouselContext`; используйте `pageSnapPoints` из API контекста, если число индикаторов должно
соответствовать рассчитанным страницам.

## Стилизация

Используйте `className` в React или `class` в Solid на экспортируемых частях для структурных стилей.
Для стилей состояний предпочитайте атрибуты Ark UI, например `data-orientation`, `data-current` и
`data-dragging`, вместе с селекторами moduix `data-slot`. Варианты Tailwind используют нативные
utility-классы и переопределения через классы потребителя; приведённый ниже справочник CSS-свойств
относится к пакетам CSS Modules.

### CSS-свойства

### Хуки стилизации

- `data-slot="carousel-root"`, `carousel-root-provider`, `carousel-control`, `carousel-item-group`,
  `carousel-item`, `carousel-prev-trigger`, `carousel-next-trigger`, `carousel-indicator-group`,
  `carousel-indicator`, `carousel-autoplay-trigger`, `carousel-autoplay-indicator` и
  `carousel-progress-text` - стабильные селекторы экспортируемых частей.
- Ark UI также добавляет к отрисованным узлам `data-scope="carousel"` и имена `data-part`.
- `data-orientation="horizontal" | "vertical"` доступен на корневом и структурных элементах.
- `CarouselItemGroup` получает `data-dragging` во время перетаскивания.
- `CarouselIndicator` получает `data-current`, а `CarouselItem` - `data-index` и `data-inview`.
- `CarouselIndicator` получает `data-readonly`, а `CarouselAutoplayTrigger` - `data-pressed`.
