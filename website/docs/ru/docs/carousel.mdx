Начните с `Carousel` в качестве корневого компонента. Добавьте `CarouselItemGroup` для ленты слайдов,
поместите кнопки перехода в `CarouselControl`, а стандартный пейджер выведите с помощью
`CarouselIndicators` и `CarouselProgressText`.

## Примеры

### Слайдов на странице

Увеличьте `slidesPerPage`, чтобы одновременно показывать несколько элементов вместо одной панели на
всю ширину.

### Интервал

Увеличьте `spacing`, чтобы добавить расстояние между соседними слайдами в редакционных макетах,
товарных лентах или фирменных интерфейсах.

<Example name="carousel/spacing" />

### Вертикальная ориентация

работать вдоль вертикальной оси.

<Example name="carousel/vertical" />

### Зацикливание

Установите `loop`, чтобы после последнего слайда карусель возвращалась к первому.

<Example name="carousel/loop" />

### Автопрокрутка

Используйте автопрокрутку для галерей, в которых слайды переключаются сами, но оставляйте видимые
элементы управления. В этом примере автопрокрутка останавливается при наведении указателя на карусель
или при переходе фокуса внутрь неё. Пользователь может запустить её снова через
`CarouselAutoplayTrigger`.

<Example name="carousel/autoplay" />

Полный пример галереи с боковой навигацией, текстом на слайдах и индикаторами прогресса, которые
заполняются по мере переключения, смотрите в [блоке галереи с автопрокруткой](/blocks/autoplay-gallery).

### Пауза при наведении

Используйте этот вариант, если автопрокрутка должна останавливаться, пока указатель находится над
каруселью. В примере `CarouselContext` вызывает `api.pause()` и `api.play()`, а фокус внутри карусели
также приостанавливает прокрутку.

### Перетаскивание мышью

Включите перетаскивание мышью, чтобы на компьютере пользователи могли листать слайды тем же жестом,

### Индикаторы-миниатюры

Выведите собственное содержимое индикаторов, если пейджер должен показывать миниатюры слайдов вместо

управления или требует своего содержимого.

## Композиция

`Carousel` хранит состояние внутри корневого компонента. Используйте `defaultPage` для
неконтролируемой карусели, а `page` вместе с `onPageChange(details)`, если текущей страницей управляет
маршрутизация, фильтры или другая часть приложения. Свойство `slideCount` обязательно и должно
соответствовать отрисованным элементам при изменении коллекции.

Используйте `CarouselRootProvider` вместе с `useCarousel()`, если хранилище нужно создать вне дерева
компонентов или разделить между границами композиции. Передайте это хранилище в `CarouselRootProvider` и не
отрисовывайте второй корневой `Carousel` для того же состояния.

`CarouselIndicators` читает `pageSnapPoints` из контекста и создаёт стандартные индикаторы. Для
пользовательского содержимого индикаторов разместите `CarouselIndicatorGroup` и `CarouselIndicator`
внутри `CarouselContext`; используйте `pageSnapPoints` из API контекста, если число индикаторов должно
соответствовать рассчитанным страницам.

В Solid назначайте ref на элемент, созданный внутри рендер-функции `asChild`. Ref на самой части
Carousel не пробрасывается через этот путь композиции.

Во Vue template-ref на части указывает на её отрисованный хост через `$el`, включая замещающий
хост, созданный при использовании `asChild`.

## Стилизация

Используйте `className` в React или `class` в Solid и Vue на экспортируемых частях для структурных
стилей. Для стилей состояний предпочитайте атрибуты Ark UI, например `data-orientation`,
`data-current` и `data-dragging`, вместе с селекторами moduix `data-slot`. Варианты Tailwind используют нативные
utility-классы и переопределения через классы потребителя; приведённый ниже справочник CSS-свойств
относится к пакетам CSS Modules.

### Хуки стилизации

| Часть | `data-slot` |
| --- | --- |
| `Carousel` | `carousel-root` |
| `CarouselRootProvider` | `carousel-root-provider` |
| `CarouselControl` | `carousel-control` |
| `CarouselItemGroup` | `carousel-item-group` |
| `CarouselItem` | `carousel-item` |
| `CarouselPrevTrigger` | `carousel-prev-trigger` |
| `CarouselNextTrigger` | `carousel-next-trigger` |
| `CarouselIndicatorGroup` | `carousel-indicator-group` |
| `CarouselIndicator` | `carousel-indicator` |
| `CarouselAutoplayTrigger` | `carousel-autoplay-trigger` |
| `CarouselAutoplayIndicator` | `carousel-autoplay-indicator` |
| `CarouselProgressText` | `carousel-progress-text` |

- Ark UI также добавляет к отрисованным узлам `data-scope="carousel"` и имена `data-part`.
- `data-orientation="horizontal" | "vertical"` доступен на корневом и структурных элементах.
- `CarouselItemGroup` получает `data-dragging` во время перетаскивания.
- `CarouselIndicator` получает `data-current`, а `CarouselItem` - `data-index` и `data-inview`.
- `CarouselIndicator` получает `data-readonly`, а `CarouselAutoplayTrigger` - `data-pressed`.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `ArrowLeft` / `ArrowRight` | Перемещает между индикаторами и страницами; ArrowUp и ArrowDown в вертикальном режиме. |
| `Home` / `End` | Переходит на первую или последнюю страницу с индикаторов. |
| `Enter` / `Space` | Нажимает кнопку назад, вперёд или автопрокрутки в фокусе. |
