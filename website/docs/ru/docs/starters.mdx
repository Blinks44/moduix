## Запуск локально

Предпочитаете свой редактор? giget скопирует папку проекта без клонирования монорепозитория и его истории.

<Steps>

### Скопируйте проект

Выберите фреймворк. Команда создаст папку `my-app` с теми же файлами, что и в StackBlitz.

### Установите зависимости и запустите

Проекты используют опубликованные пакеты, поэтому подойдёт любой менеджер пакетов.

<StarterInstall />

### Настройте под себя

Подключите свой API вместо примеров данных в `src/data.ts` и удалите ненужные страницы.

</Steps>

## Что внутри

Небольшое приложение для каждого фреймворка. Любой исходный файл можно изменить или удалить.

<StarterContents />

:::info Используете Tailwind?
В готовых проектах подключены CSS Modules. Выберите соответствующий пакет `-tailwind` и настройте Tailwind CSS v4 и его стили по [инструкции для Vite](/docs/installation/vite).
:::
