# List Selection

`useListSelection` хранит выбранные значения в `ListCollection`, а приложение отвечает за разметку и
логику взаимодействия.

## Справочник API

<PrimitiveReference href="https://ark-ui.com/docs/collections/list-selection" />

Хук предоставляется Ark UI и не реэкспортируется Moduix. Импортируйте его из точки входа коллекции
для нужного фреймворка:

использовать вместе с любым из этих пакетов.

## Одиночный выбор

Хук хранит состояние выбора. В примере есть секция с подписью, нативные кнопки с `aria-pressed` и
сообщение о текущем состоянии. Preview работает на React-исходнике, а вкладка Solid содержит
эквивалентную нативную реализацию для Solid.

По умолчанию `deselectable` равен `true`, поэтому повторный выбор текущего значения снимает выбор.
Хук не рендерит элементы управления и не отключает их. Получайте значение `disabled` из данных
элемента коллекции в своей разметке, как в примере.

## Множественный выбор

Используйте `selectionMode: 'multiple'`, когда пользователь может выбрать несколько значений без
модификаторов клавиш. В примере также используются `isAllSelected`, `setSelectedValues` и `clear`
для действия «выбрать все».

## Основные части API

### Конфигурация

| Параметр                  | Описание                                                             | По умолчанию |
| ------------------------- | -------------------------------------------------------------------- | ------------ |
| `collection`              | `ListCollection` со значениями, которые можно выбирать.              | обязателен   |
| `selectionMode`           | `'single'`, `'multiple'`, `'extended'` или `'none'`.                 | `'single'`   |
| `deselectable`            | Можно ли снять выбор повторным выбором текущего значения.            | `true`       |
| `initialSelectedValues`   | Начальные значения для неконтролируемого выбора.                     | `[]`         |
| `resetOnCollectionChange` | Очищать ли выбор при изменении коллекции.                            | `false`      |

`initialSelectedValues` читается при создании состояния выбора. После этого меняйте состояние через
`setSelectedValues` или другие действия. В Solid свойства состояния являются accessors, поэтому их
нужно читать как `selection.selectedValues()` и `selection.isEmpty()`. Действия вызываются так же,
как в React.

### Состояние и действия

| API                                | Описание                                                    |
| ---------------------------------- | ----------------------------------------------------------- |
| `selectedValues`                   | Текущие выбранные значения.                                 |
| `isEmpty`                          | Показывает, выбран ли хотя бы один элемент.                 |
| `firstSelectedValue`               | Первое выбранное значение в порядке коллекции или `null`.  |
| `lastSelectedValue`                | Последнее выбранное значение в порядке коллекции или `null`. |
| `isSelected(value)`                | Проверяет, выбрано ли значение.                             |
| `canSelect(value)`                 | Проверяет, можно ли выбрать значение в текущем режиме.     |
| `isAllSelected()`                  | Проверяет, выбраны ли все значения коллекции.               |
| `isSomeSelected()`                 | Проверяет, выбрано ли хотя бы одно значение коллекции.      |
| `select(value, forceToggle?)`      | Выбирает значение согласно текущему режиму.                 |
| `deselect(value)`                  | Снимает выбор с одного значения.                            |
| `toggle(value)`                    | Переключает выбор одного значения.                          |
| `replace(value)`                   | Заменяет выбор одним значением.                             |
| `extend(anchorValue, targetValue)` | Расширяет выбор между значениями в порядке коллекции.       |
| `setSelectedValues(values)`        | Устанавливает выбор с учётом текущего режима.               |
| `clear()`                          | Очищает выбор, если `deselectable` равен `true`.             |
| `resetSelection()`                 | Создаёт пустой выбор с текущими настройками.                 |

`replace(null)` оставляет текущий выбор без изменений. Используйте `resetSelection()`, если нужен
пустой выбор даже при `deselectable: false`.

## Взаимодействие и доступность

`useListSelection` не обрабатывает события мыши и клавиатуры и не добавляет ARIA-атрибуты. Выбирайте
семантику в соответствии со своей разметкой:

- Используйте нативные кнопки с `aria-pressed`, если каждый вариант является независимым переключателем,
  как в примерах.
- Реализуйте управление фокусом, сочетания клавиш и сообщения о состоянии в слое взаимодействия
  приложения.
- Для клика с Shift или другого жеста выбора диапазона храните опорное значение в состоянии приложения
  и вызывайте `extend(anchorValue, targetValue)`. Для переключения с модификатором клавиш вызывайте
  `select(value, true)`.
- Используйте `Listbox`, если нужен обычный выбор вариантов с семантикой listbox и клавиатурным
  управлением. `Select` и `Combobox` также сами управляют выбором.

Если коллекция меняется, оставьте `resetOnCollectionChange: false`, когда временная фильтрация должна
сохранять выбор. Для нового набора данных установите `true`. Если удалённые значения больше не должны
оставаться выбранными, отфильтруйте их через `collection.has(value)` и вызовите `setSelectedValues` в
обработчике события или эффекте, а не во время рендера.
