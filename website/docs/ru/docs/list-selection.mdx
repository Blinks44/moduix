# List Selection

## Справочник API

<PrimitiveReference href="https://ark-ui.com/docs/collections/list-selection" />

Хук `useListSelection` хранит выбранные значения в `ListCollection`. Используйте его, когда создаёте
свой список и хотите добавить в него состояние выбора, не подключая готовый компонент для работы с
коллекцией. `Select`, `Combobox` и `Listbox` уже управляют выбором, поэтому вместе с ними этот хук
обычно не нужен.

Импортируйте вспомогательные функции для работы с коллекцией из Ark UI:

```tsx
import { createListCollection, useListSelection } from '@ark-ui/react/collection';
```

В этом примере для короткого списка независимых вариантов используются кнопки. Хук хранит выбранные
значения, а интерфейс отвечает за отображение, семантические роли, фокус, взаимодействие с
клавиатурой и доступные подписи.

Кнопки подходят здесь, потому что каждый вариант является отдельным действием, а `aria-pressed`
сообщает о его состоянии выбора. Не добавляйте `role="listbox"` в пользовательскую разметку, если
не готовы также реализовать полную модель клавиатурного управления и фокуса listbox. Для обычного
списка вариантов используйте [Listbox](/docs/listbox), который предоставляет семантику listbox и
клавиатурное управление.

## Конфигурация

| Свойство                  | Описание                                                              | По умолчанию |
| ------------------------- | --------------------------------------------------------------------- | ------------ |
| `collection`              | Коллекция со значениями, которые можно выбирать.                      | обязательное |
| `selectionMode`           | `'single'`, `'multiple'`, `'extended'` или `'none'`.                 | `'single'`   |
| `deselectable`            | Можно ли снять выбор повторным выбором текущего значения.             | `true`       |
| `initialSelectedValues`   | Начальные значения для неконтролируемого выбора.                      | `[]`         |
| `resetOnCollectionChange` | Очищать ли выбор при изменении коллекции.                             | `false`      |

`initialSelectedValues` используется только при создании состояния выбора. Чтобы изменить выбор
после монтирования, используйте `setSelectedValues`. Режим `extended` подходит, если слой взаимодействия
передаёт модификаторы клавиш в `select(value, true)`; сам хук не обрабатывает события мыши и клавиатуры.

## Состояние

| Значение             | Описание                                                  |
| -------------------- | --------------------------------------------------------- |
| `selectedValues`     | Массив выбранных значений.                                |
| `isEmpty`            | Показывает, пуст ли выбор.                                |
| `firstSelectedValue` | Первое выбранное значение в порядке коллекции или `null`. |
| `lastSelectedValue`  | Последнее выбранное значение в порядке коллекции или `null`. |

## Методы проверки

| Метод               | Описание                                                   |
| ------------------- | ---------------------------------------------------------- |
| `isSelected(value)` | Проверяет, выбрано ли значение.                            |
| `canSelect(value)`  | Проверяет, разрешён ли выбор в текущем режиме.              |
| `isAllSelected()`   | Проверяет, выбраны ли все элементы коллекции.              |
| `isSomeSelected()`  | Проверяет, выбран ли хотя бы один элемент коллекции.       |

Используйте `canSelect`, прежде чем показывать действие выбора, если `selectionMode` может быть
равен `'none'`.

## Действия

| Метод                              | Описание                                                       |
| ---------------------------------- | -------------------------------------------------------------- |
| `select(value, forceToggle?)`      | Выбирает значение согласно текущему режиму.                    |
| `deselect(value)`                  | Снимает выбор с одного значения.                              |
| `toggle(value)`                    | Переключает состояние выбора одного значения.                 |
| `replace(value)`                   | Заменяет выбор одним значением. При передаче `null` выбор не меняется. |
| `extend(anchorValue, targetValue)` | Расширяет выбор между двумя значениями в порядке коллекции.   |
| `setSelectedValues(values)`        | Устанавливает выбор из переданных значений с учётом текущего режима. |
| `clear()`                          | Очищает выбор, если `deselectable` равен `true`.                |
| `resetSelection()`                 | Очищает выбор и создаёт его заново с текущими настройками.    |

`clear()` учитывает `deselectable`. Используйте `resetSelection()`, если нужно получить пустой выбор
даже при `deselectable: false`.

## Множественный выбор

```tsx
import { createListCollection, useListSelection } from '@ark-ui/react/collection';
import { Button } from '@moduix/react/button';

const teams = createListCollection({
  items: [
    { label: 'Platform', value: 'platform' },
    { label: 'Product', value: 'product' },
    { label: 'Design', value: 'design' },
  ],
});

function TeamSelectionActions() {
  const selection = useListSelection({
    collection: teams,
    selectionMode: 'multiple',
    initialSelectedValues: ['platform'],
  });

  function toggleAll() {
    if (selection.isAllSelected()) {
      selection.clear();
      return;
    }

    selection.setSelectedValues(teams.getValues());
  }

  return (
    <Button type="button" onClick={toggleAll}>
      {selection.isAllSelected() ? 'Clear all' : 'Select all'}
    </Button>
  );
}
```

Установите `selectionMode` в `'multiple'`, если пользователь должен иметь возможность выбрать
несколько значений одновременно. В примере `isAllSelected()` помогает выбрать между очисткой выбора
и выбором всех значений.

Хук только хранит состояние выбора и не отключает элементы интерфейса. Отключайте их на основе
состояния элемента в коллекции, как в базовом примере. Если передаёте в `setSelectedValues` внешние
значения, проверяйте их через `collection.has` и `collection.getItemDisabled`, если отключённые
элементы нужно исключить.

## Выбор диапазона

Храните опорное значение в логике взаимодействия, а при выборе диапазона вызывайте `extend`:

```tsx
import { useRef } from 'react';
import { useListSelection, type ListCollection } from '@ark-ui/react/collection';

type Team = {
  label: string;
  value: string;
};

function useRangeSelection(collection: ListCollection<Team>) {
  const selection = useListSelection({
    collection,
    selectionMode: 'multiple',
  });
  const anchorRef = useRef<string | null>(null);

  function handleSelect(value: string, withRange: boolean) {
    if (withRange && anchorRef.current) {
      selection.extend(anchorRef.current, value);
      return;
    }

    selection.replace(value);
    anchorRef.current = value;
  }

  return { selection, handleSelect };
}
```

Передавайте в `withRange` признак клика с зажатой клавишей Shift или другого жеста выбора диапазона. Для выбора
диапазона с клавиатуры также нужны управление фокусом и обработка Shift + клавиш со стрелками. Если нужен
стандартный `Listbox` с поддержкой ARIA, используйте [Listbox](/docs/listbox) и поручите ему эти
взаимодействия.

## Изменения коллекции

Установите `resetOnCollectionChange: true`, если новая коллекция представляет другой набор данных и
старый выбор не должен переноситься.

Оставьте значение по умолчанию `false`, если фильтрация временно скрывает элементы, а выбор нужно
сохранить при фильтрации. Если коллекция удаляет значения, которые больше не должны быть выбраны,
отфильтруйте выбранные значения и передайте результат в `setSelectedValues`:

```tsx
const validValues = selection.selectedValues.filter((value) => collection.has(value));

selection.setSelectedValues(validValues);
```

Выполняйте эту синхронизацию в обработчике события или эффекте при изменении коллекции, а не во время
рендера.
