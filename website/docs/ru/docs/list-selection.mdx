# List Selection

## API

<PrimitiveReference href="https://ark-ui.com/docs/collections/list-selection" />

`useListSelection` добавляет состояние выбора в `ListCollection`. Используйте его для пользовательских
списков, в которых ещё нет поведения выбора. `Select`, `Combobox` и `Listbox` сами управляют выбором и
обычно не нуждаются в этом хуке.

```tsx
import { createListCollection, useListSelection } from '@ark-ui/react/collection';
```

## Одиночный выбор

```tsx preview file="../../en/docs/_snippets/list-selection/basic.tsx"

```

Этот базовый пример показывает одиночный выбор. Хук управляет только значениями выбора. За
семантические роли, взаимодействие с клавиатурой, фокус и доступные подписи по-прежнему отвечает
ваш интерфейс. Если нужно стандартное поведение listbox, предпочитайте `Listbox`.

Пример с кнопками уместен, потому что каждый вариант можно переключать независимо. Не добавляйте
`role="listbox"` в пользовательскую разметку, если также не реализуете всю модель клавиатурного
управления и фокуса listbox. Для обычного выбора вариантов используйте [Listbox](/docs/listbox) и
поручите ему это поведение.

## Конфигурация

| Свойство                  | Назначение                                         | По умолчанию |
| ------------------------- | -------------------------------------------------- | ------------ |
| `collection`              | Коллекция, значения которой можно выбрать.         | обязательное |
| `selectionMode`           | `'single'`, `'multiple'` или `'none'`.            | `'single'`   |
| `deselectable`            | Позволяет отменить текущий выбор.                  | `true`       |
| `initialSelectedValues`   | Начальные значения для неконтролируемого выбора.   | `[]`         |
| `resetOnCollectionChange` | Очищает выбор при изменении коллекции.             | `false`      |

`initialSelectedValues` задаёт только начальное состояние. Используйте `setSelectedValues`, если
выбор должен измениться после монтирования.

## Состояние

| Значение             | Описание                                                   |
| -------------------- | ---------------------------------------------------------- |
| `selectedValues`     | Выбранные значения в порядке выбора.                       |
| `isEmpty`            | Нет выбранных значений.                                    |
| `firstSelectedValue` | Первое выбранное значение в порядке коллекции или `null`. |
| `lastSelectedValue`  | Последнее выбранное значение в порядке коллекции или `null`. |

## Проверки

| Метод               | Назначение                                                   |
| ------------------- | ------------------------------------------------------------ |
| `isSelected(value)` | Проверяет, выбрано ли значение.                              |
| `canSelect(value)`  | Проверяет режим, отключённость и допустимость выбора.       |
| `isAllSelected()`   | Проверяет, выбран ли каждый элемент коллекции.               |
| `isSomeSelected()`  | Проверяет, выбран ли хотя бы один элемент коллекции.         |

Используйте `canSelect`, прежде чем показывать действия выбора, которые интерфейс ещё не отключает.

## Действия

| Метод                              | Назначение                                                  |
| ---------------------------------- | ----------------------------------------------------------- |
| `select(value, forceToggle?)`      | Выбирает значение в соответствии с текущим режимом.         |
| `deselect(value)`                  | Удаляет одно выбранное значение.                            |
| `toggle(value)`                    | Переключает одно значение.                                  |
| `replace(value)`                   | Заменяет выбор одним значением или очищает его с `null`.   |
| `extend(anchorValue, targetValue)` | Выбирает диапазон коллекции между двумя значениями.          |
| `setSelectedValues(values)`        | Заменяет выбор явными значениями.                           |
| `clear()`                          | Очищает текущий выбор.                                      |
| `resetSelection()`                 | Создаёт пустой выбор с текущими настройками заново.          |

## Множественный выбор

```tsx
import { Button } from '@moduix/react/button';

function TeamSelectionActions() {
  const selection = useListSelection({
    collection,
    selectionMode: 'multiple',
    initialSelectedValues: ['platform'],
  });

  function toggleAll() {
    if (selection.isAllSelected()) {
      selection.clear();
      return;
    }

    selection.setSelectedValues(collection.getValues());
  }

  return (
    <Button type="button" onClick={toggleAll}>
      {selection.isAllSelected() ? 'Clear all' : 'Select all'}
    </Button>
  );
}
```

Отключённые значения нельзя выбрать через `select` или `toggle`. При прямой установке значений
проверяйте внешние данные через `selection.canSelect`, если они ещё не считаются доверенными.

## Диапазонный выбор

Храните опорное значение в логике взаимодействия, затем расширяйте выбор от него:

```tsx
import { useRef } from 'react';

function useRangeSelection() {
  const selection = useListSelection({
    collection,
    selectionMode: 'multiple',
  });
  const anchorRef = useRef<string | null>(null);

  function handleSelect(value: string, extend: boolean) {
    if (extend && anchorRef.current) {
      selection.extend(anchorRef.current, value);
      return;
    }

    selection.replace(value);
    anchorRef.current = value;
  }

  return { selection, handleSelect };
}
```

В интерфейсах с мышью `extend` обычно соответствует клику с Shift. Диапазонный выбор с клавиатуры
дополнительно требует управления фокусом и обработки Shift+стрелок; используйте компонент коллекции,
если такая модель поведения соответствует устоявшемуся шаблону ARIA.

## Изменения коллекции

Установите `resetOnCollectionChange: true`, когда новая коллекция представляет другой набор данных
и старые значения никогда не должны переноситься.

Сохраняйте значение по умолчанию `false`, когда фильтрация лишь временно скрывает элементы и выбор
должен переживать фильтр. Если удалённые значения нужно выборочно исключить, получите допустимые
значения и вызовите `setSelectedValues`:

```tsx
const validValues = selection.selectedValues.filter((value) => collection.has(value));

selection.setSelectedValues(validValues);
```

Выполняйте эту синхронизацию в обработчике события или эффекте при изменении коллекции, а не во время
рендера.
