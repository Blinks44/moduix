## Справочник API

В Ark UI нет отдельного примитива для графиков. moduix добавляет к
[React-компоненту TanStack Charts](https://tanstack.com/charts/latest/docs/framework/react/reference/chart)
семантическую оболочку `figure`, заголовок, описание, легенду и компактное тело подсказки.
Графические элементы, шкалы, взаимодействия и колбэки вы по-прежнему задаёте средствами TanStack Charts.

`@tanstack/charts` - необязательная peer-зависимость moduix. Текущий диапазон совместимых версий -
`^0.16.0`, а React-адаптер TanStack требует React 19.

## Анатомия

```text
Chart / Chart.Root
├─ Chart.Header (необязательный figcaption)
│  ├─ Chart.Title
│  └─ Chart.Description
├─ Chart.Plot
│  └─ область графика TanStack (по умолчанию SVG)
└─ Chart.Legend (необязательно)
   └─ Chart.LegendItem
```

| Часть | Назначение |
| --- | --- |
| `Chart` / `Chart.Root` | Составной корневой элемент `figure`. Принимает нативные свойства, `asChild` и ref на `HTMLElement`. |
| `Chart.Plot` | React-компонент TanStack Charts. Требует `definition` и `ariaLabel`, по умолчанию использует пресет анимации Moduix и принимает `motion={false}`. |
| `Chart.Header` | Разметка `figcaption` для заголовка и описания. |
| `Chart.Title` | Заголовок графика, по умолчанию рендерится как `h3`. |
| `Chart.Description` | Видимое пояснение к графику. |
| `Chart.Legend` | Семантический список видимых серий. |
| `Chart.LegendItem` | Элемент легенды с необязательным цветом индикатора `color`. |

## Композиция

### Рекомендуемая композиция

Если определение TanStack не меняется, объявите его за пределами компонента. Затем в корневом
компоненте соберите `Chart.Header`, `Chart.Plot` и `Chart.Legend`. `barY`, `areaY`, `lineY`,
`stack()`, шкалы, направляющие и цветовые каналы задавайте прямо в TanStack Charts: moduix не
превращает их в отдельные React-части.

Используйте одну и ту же цветовую шкалу из определения для графических элементов и индикаторов
подсказки. Укажите соответствующие токены moduix в `Chart.LegendItem`, чтобы цвета легенды совпадали
с графиком.

### Выбор графических элементов

`Chart.Plot` предоставляет область отрисовки, а свойство `marks` внутри `definition` определяет,
что именно будет нарисовано. Во всех вариантах используется одна и та же композиция:
`<Chart.Plot definition={definition} />`.

| Задача | Элементы TanStack | Пример |
| --- | --- | --- |
| Вертикальные столбцы | `barY` | Базовый пример, Столбцы с накоплением |
| Горизонтальные столбцы | `barX` | Горизонтальные столбцы |
| Линия или область | `lineY`, `areaY` | Анимированная область, Цвета графика |
| Круговая или кольцевая диаграмма | `pie`, `polar`, `radialArc` | Кольцевая диаграмма |
| Точечная диаграмма | `dot` | Точечная диаграмма |
| Тепловая карта | `cell` | Тепловая карта |

### Когда нужна собственная настройка

По умолчанию `Chart.Plot` использует адаптивный пресет TanStack `motion()`. Задайте `motion={false}`,
если нужен статичный SVG-график, или передайте другой `renderer`, когда требуется самостоятельно
управлять отрисовкой. Явно заданный `renderer` важнее `motion`. Если приложение должно само управлять
поверхностью отрисовки, используйте canvas- или низкоуровневый рендерер TanStack напрямую.

```tsx
<Chart.Plot definition={definition} ariaLabel="Monthly revenue" motion={false} />
```

По умолчанию Chart использует компактное тело подсказки moduix: строки без цветового индикатора не
резервируют пустой столбец. Используйте `renderTooltipBody`, только если нужно добавить React-содержимое.
В контексте колбэка есть нативный `defaultBody` TanStack с заголовком, строками, форматированием и
цветовыми метками. TanStack по-прежнему управляет привязкой подсказки к графику, её положением,
порталом, закреплением и закрытием. Интерактивные элементы выводите только при `pinned: true`.

### Свойства по умолчанию

| Часть | Свойство | По умолчанию | Примечания |
| --- | --- | --- | --- |
| `Chart.Root` | элемент | `figure` | `Chart.Header` является его `figcaption`. |
| `Chart.Plot` | `definition` | - | Обязательное определение графика TanStack. |
| `Chart.Plot` | `ariaLabel` | - | Обязательное доступное имя графика. |
| `Chart.Plot` | `motion` | `true` | Задайте `false`, чтобы использовать статичный SVG-рендерер TanStack. |
| `Chart.Plot` | `renderer` | Пресет анимации Moduix | Анимирует геометрию и подсказку; учитывает системное предпочтение уменьшить анимацию. |
| `Chart.Plot` | `height` | `320` | Используется, когда `aspectRatio` не задан. |
| `Chart.Plot` | `width` | адаптивная | Подстраивается под ширину контейнера. |
| `Chart.Plot` | `initialWidth` | `640` | Ширина на сервере и до первого измерения. |
| `Chart.Plot` | `tabIndex` | `0` | Оставляет клавиатурную навигацию TanStack в порядке перехода по Tab. |

### Особенности поведения

- Если определение не зависит от свойств или состояния, храните его на уровне модуля. В противном
  случае мемоизируйте определение целиком через `useMemo`.
- Стандартный рендерер анимирует начальную геометрию, обновления данных с ключами, направляющие фокуса
  и встроенную подсказку. При `prefers-reduced-motion: reduce` он переключается на мгновенные обновления,
  а `motion={false}` отключает анимацию независимо от системных настроек.
- TanStack отвечает за фокус при взаимодействии указателем, навигацию стрелками, активацию клавишами
  Enter и Space,
  `onFocusChange` и `onSelect`.
- Доступный для фокуса SVG-элемент графика использует обводку фокуса moduix. Не отключайте `focusRing`, пока
  определение не предоставляет собственную геометрию фокуса.
- Добавьте `ariaDescription`, если одного видимого заголовка и описания недостаточно.
- `className` и `style` у `Chart.Plot` применяются к внешнему элементу TanStack. Этот элемент не предоставляет API для `ref`.

### Расширенная настройка

Компоненты Ark factory принимают `asChild` и могут применять свои стили к семантическим элементам
вашей разметки. В этом примере дашборда Chart используется вместе с Button: стандартные `figure` и
`figcaption` заменены на `section` и `header`, связанные с заголовком через `aria-labelledby`, а
легенда перенесена в `header`.

`Chart.Plot` остаётся компонентом TanStack, а не слотом. Его `className` и `style` применяются к
внешнему элементу, а `renderTooltipBody` позволяет расширить подсказку. Выводите `defaultBody` внутри
собственной обёртки: TanStack продолжит управлять её положением и выводом через портал. Интерактивные
элементы добавляйте только в закреплённую подсказку.

## Стилизация

Настраивайте `figure` через `Chart.Root`, а область отрисовки TanStack - через `Chart.Plot`.
Публичные CSS-свойства
управляют самим блоком, обводкой фокуса, оболочкой подсказки и её стандартной разметкой. Геометрию
графика задавайте в определении TanStack с помощью параметров графических элементов, шкал и цветовых
каналов.

Передайте корневому элементу класс, если графику нужны локальные переопределения:

```tsx
<Chart className="sales-chart">...</Chart>
```

```css
.sales-chart {
  --moduix-chart-tooltip-bg: var(--moduix-color-card);
  --moduix-chart-tooltip-font-size: var(--moduix-text-sm);
  --moduix-chart-tooltip-line-height: var(--moduix-line-height-text-sm);
}
```

### Хуки стилизации

- `Chart.Root`, `Chart.Header`, `Chart.Title`, `Chart.Description`, `Chart.Legend`,
  и `Chart.LegendItem` предоставляют `data-scope="chart"`, `data-part` и `data-slot`.
- `className` у `Chart.Plot` применяется к внешнему элементу `.ts-chart-host`.
- Стандартная подсказка использует слоты данных `chart-tooltip-body`,
  `chart-tooltip-title`, `chart-tooltip-rows`, `chart-tooltip-row`, `chart-tooltip-swatch`,
  `chart-tooltip-label`, `chart-tooltip-value` и `chart-tooltip-text`.
- Используйте `--moduix-color-chart-1` - `--moduix-color-chart-5` в цветовых шкалах TanStack.
- Оболочка подсказки настраивается через документированные переменные `--ts-chart-tooltip-*`,
  связанные со свойствами Moduix. Для собственных CSS-селекторов используйте
  `tooltip.className`, а для React-содержимого - `renderTooltipBody` и нативный `defaultBody`.
