## Справочник API

В Ark UI нет отдельного примитива для графиков. moduix добавляет семантические `figure`, заголовок,
описание, легенду и компактное тело подсказки вокруг [API графиков TanStack
Charts](https://tanstack.com/charts/latest/docs/framework/react/reference/chart). Графические
элементы, шкалы, взаимодействия и колбэки вы по-прежнему задаёте средствами TanStack Charts, а
moduix предоставляет доступную оболочку композиции.

`@tanstack/charts` - необязательная peer-зависимость moduix. Пакеты для React, Solid и Vue
используют одинаковый API определения графика; пакеты Solid и Vue работают через адаптер рендерера
TanStack.

## Базовый пример


Создайте определение графика в TanStack Charts и передайте его в `ChartPlot`. Добавьте вокруг
графика видимые заголовок, описание и легенду, а для пользователей вспомогательных технологий
задайте короткое доступное имя в `ariaLabel`.

## Анатомия

```text
Chart
├─ ChartHeader (необязательный figcaption)
│  ├─ ChartTitle
│  └─ ChartDescription
├─ ChartPlot
│  └─ Поверхность графика TanStack (по умолчанию SVG)
└─ ChartLegend (необязательно)
   └─ ChartLegendItem
```

| Часть | Назначение |
| --- | --- |
| `Chart` | Составной корневой элемент `figure`. Принимает нативные свойства, `asChild` и ref на `HTMLElement` (у Vue это `$el` компонента). |
| `ChartPlot` | Хост TanStack Charts. Требует `definition` и `ariaLabel`, по умолчанию использует пресет анимации moduix и принимает `motion={false}`. |
| `ChartHeader` | Разметка `figcaption` для заголовка и описания. |
| `ChartTitle` | Заголовок графика, по умолчанию рендерится как `h3`. |
| `ChartDescription` | Видимое пояснение к графику. |
| `ChartLegend` | Семантический список видимых серий. |
| `ChartLegendItem` | Элемент легенды с необязательным цветом индикатора `color`. |

## Композиция

`Chart` - это презентационная оболочка. TanStack `definition` владеет графическими элементами,
шкалами, взаимодействиями и колбэками, поэтому храните его на уровне модуля или мемоизируйте
полностью, если он зависит от props или состояния. Собирайте `ChartHeader`, `ChartPlot` и
`ChartLegend` внутри корневого элемента; `ChartPlot` продолжает передавать TanStack состояние
рендеринга, фокуса и подсказки.

Используйте `renderTooltipBody`, только если нужно обернуть или расширить нативную подсказку:
отрендерите переданный `defaultBody`, а интерактивные элементы добавляйте только при `pinned=true`.
`Chart` и `ChartHeader` поддерживают `asChild`, если семантическая оболочка или её разметка
должны принадлежать приложению.

## Примеры

### Анимированная область

Область, линия, точки, группировка фокуса и анимация подсказки остаются нативным поведением
TanStack.

<Example name="chart/animated-area" />

### Цвета графика

Используйте токены moduix для графиков в цветовой шкале TanStack. CSS-свойства работают как значения
заливки SVG и автоматически учитывают активную тему.

<Example name="chart/line-colors" />

### Интерактивная легенда

Используйте `interactiveColorLegend` TanStack вместо отдельного `ChartLegend`, если нужно скрывать
серии. В v1 параметр `hover: 'series'` также применяет состояния графических элементов при наведении
и клавиатурном фокусе. Состояния с `source: 'legend'` выделяют серию, не открывая подсказку и не меняя
фокус графика. Храните видимые серии в состоянии фреймворка через `controlledSignal`; кнопками,
фильтрацией и клавиатурным управлением занимается TanStack.

<Example name="chart/interactive-legend" />

### Радарная диаграмма

Сравнивайте показатели по общей шкале 0–100 с помощью `radialLine` и замкнутой кривой D3. Радарные
диаграммы были доступны и до v1; в этом примере добавлены `polar.states`, которые приглушают точки вне
фокуса. `focusGroupAngle` объединяет оба продукта по показателю для подсказки и клавиатурного
управления.

Для этого примера также нужны `d3-shape` и его TypeScript-типы:

### Кольцевая диаграмма

Сочетайте необязательные примитивы TanStack `pie`, `polar` и `radialArc`, чтобы показывать части
целого. Та же композиция `ChartPlot`, анимации, фокуса, подсказки и легенды работает и за пределами
декартовых графиков.

<Example name="chart/donut" />

### Тепловая карта

Используйте `cell` с полосовыми шкалами по обеим осям, чтобы построить компактную категориальную
матрицу. Цветовой канал превращает уровень каждой ячейки в значение цвета с учётом темы.

<Example name="chart/heatmap" />

### Горизонтальные столбцы

Используйте `barX`, когда подписи категорий длинные или рейтинг должен читаться сверху вниз.
Числовое значение передаётся по оси x, а категория - по оси y.

<Example name="chart/horizontal-bars" />

### Точечная диаграмма

Используйте `dot`, чтобы сравнить два количественных значения. Цвет может передавать дополнительное
категориальное измерение, не меняя связь по осям x и y.

<Example name="chart/scatter" />

### Столбцы с накоплением

Используйте цветовой канал TanStack и раскладку `stack()` для столбцов с несколькими сериями.
`focus: 'group-x'` группирует подсказку и клавиатурный фокус по кварталу.

<Example name="chart/stacked-bars" />

### Расширенная настройка

Части фабрики Ark принимают `asChild`, поэтому могут применять свои стили к семантическим
элементам вашей разметки. В этом примере панели Chart и Button объединяются в один экран: стандартные
`figure` и `figcaption` заменяются на размеченные `section` и `header`, а легенда переносится в
заголовок.

`ChartPlot` остаётся хостом TanStack, а не слотом. Используйте `class` или `className` и `style`
для внешнего элемента, а `renderTooltipBody` - для расширения подсказки. Рендерите `defaultBody`
внутри своей оболочки, пока TanStack продолжает управлять позиционированием и порталом. Добавляйте
интерактивные элементы только в закреплённую подсказку.

## Стилизация

Стилизуйте `figure` через `Chart`, а хост TanStack - через `ChartPlot`. CSS-свойства ниже управляют
поверхностью `Chart` и индикатором легенды. Геометрию графика задавайте в определении TanStack через
параметры графических элементов, шкалы и цветовые каналы.

Варианты на Tailwind используют обычные утилиты и пользовательские классы, а перечисленные ниже
CSS-свойства настраивают варианты с CSS Modules. Оба подхода задают переменные TanStack
`--ts-chart-tooltip-*` на хосте `ChartPlot`, а атрибуты данных и селекторы `data-slot` у них общие.

Чтобы изменить оболочку подсказки, переопределите эти переменные классом на `ChartPlot` (`className`
в React или `class` в Solid и Vue):

```css
.sales-plot {
  --ts-chart-tooltip-background: var(--moduix-color-card);
  --ts-chart-tooltip-font: var(--moduix-weight-medium) var(--moduix-text-sm) /
    var(--moduix-line-height-text-sm) var(--moduix-font-sans);
}
```

### Хуки стилизации

- `Chart`, `ChartHeader`, `ChartTitle`, `ChartDescription`, `ChartLegend` и
  `ChartLegendItem` предоставляют `data-scope="chart"`, `data-part` и `data-slot`.
- `className` в React и `class` в Solid и Vue у `ChartPlot` применяются к внешнему элементу `.ts-chart-host`.
- Стандартная подсказка использует слоты данных `chart-tooltip-body`, `chart-tooltip-title`,
  `chart-tooltip-rows`, `chart-tooltip-row`, `chart-tooltip-swatch`, `chart-tooltip-label`,
  `chart-tooltip-value` и `chart-tooltip-text`.
- Используйте `--moduix-color-chart-1` - `--moduix-color-chart-5` в цветовых шкалах TanStack.
- Строки подсказки, которые TanStack помечает как `active`, получают `data-active`.
- Оболочка подсказки читает переменные TanStack `--ts-chart-tooltip-*` с хоста `ChartPlot`. Для
  собственных CSS-селекторов используйте `tooltip.className`, а для собственного содержимого вокруг
  `defaultBody` от moduix - `renderTooltipBody`.
