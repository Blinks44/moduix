## Справочник API

В Ark UI нет примитива для графиков. moduix объединяет части, созданные через Ark factory, с
[React-хостом TanStack Charts](https://tanstack.com/charts/latest/docs/framework/react/reference/chart),
сохраняя независимые от фреймворка определения, метки, шкалы, взаимодействия и колбэки TanStack.
TanStack Charts 0.14 требует React 19.

## Базовый пример

описание и легенду в корневом компоненте, а для области графика задайте краткий `ariaLabel`.

## Анатомия

```text
Chart / Chart.Root
├─ Chart.Header (необязательный figcaption)
│  ├─ Chart.Title
│  └─ Chart.Description
├─ Chart.Plot
│  └─ поверхность графика TanStack (по умолчанию SVG)
└─ Chart.Legend (необязательно)
   └─ Chart.LegendItem

Chart.TooltipContent (внутри renderTooltipBody)
```

| Часть | Назначение |
| --- | --- |
| `Chart` / `Chart.Root` | Составная поверхность `figure`. Принимает нативные свойства, `asChild` и ref на `HTMLElement`. |
| `Chart.Plot` | React-хост TanStack. Требует `definition` и `ariaLabel`; по умолчанию использует пресет анимации Moduix и принимает `motion={false}`. |
| `Chart.Header` | Контейнер `figcaption` для заголовка и описания. |
| `Chart.Title` | Заголовок графика; по умолчанию рендерит `h3`. |
| `Chart.Description` | Дополнительный видимый контекст. |
| `Chart.Legend` | Семантический список видимых серий. |
| `Chart.LegendItem` | Элемент легенды с необязательным цветом индикатора `color`. |
| `Chart.TooltipContent` | Контейнер для React-содержимого, которое возвращает `renderTooltipBody`. |

## Композиция

### Рекомендуемая композиция

Храните неизменяемое определение TanStack вне компонента, а внутри корневого компонента соберите
`Chart.Header`, `Chart.Plot` и `Chart.Legend`. Используйте напрямую `barY`, `areaY`, `lineY`,
стек, шкалы, направляющие и цветовые каналы TanStack: moduix не дублирует их отдельными React-частями.

Используйте цветовую шкалу определения для меток и цветовых индикаторов в подсказке. Те же цветовые
токены moduix укажите в `Chart.LegendItem`, чтобы легенда соответствовала графику.

### Выбор меток

`Chart.Plot` служит хостом рендерера, а метки внутри `definition` определяют, что будет нарисовано.
Во всех вариантах используется одна и та же композиция: `<Chart.Plot definition={definition} />`.

| Задача | Метки | Пример |
| --- | --- | --- |
| Вертикальные столбцы | `barY` | Базовый пример, Составные столбцы |
| Горизонтальные столбцы | `barX` | Горизонтальные столбцы |
| Линия или область | `lineY`, `areaY` | Анимированная область, Цвета графика |
| Круговая или кольцевая диаграмма | `pie`, `polar`, `radialArc` | Кольцевая диаграмма |
| Точечная диаграмма | `dot` | Точечная диаграмма |
| Тепловая карта | `cell` | Тепловая карта |

### Когда нужна собственная композиция

По умолчанию `Chart.Plot` использует адаптивный пресет TanStack `motion()`. Задайте `motion={false}`
для полностью статичного SVG-графика или передайте другой `renderer`, чтобы настроить анимацию.
Явно заданный `renderer` имеет приоритет над `motion`. Если поверхность графика полностью
контролирует приложение, используйте напрямую canvas- или низкоуровневый рендерер TanStack.

```tsx
<Chart.Plot definition={definition} ariaLabel="Monthly revenue" motion={false} />
```

Настраивая подсказку, оставляйте `defaultBody` внутри `Chart.TooltipContent`. TanStack по-прежнему
управляет привязкой, позиционированием, рендерингом в портале, закреплённым состоянием и закрытием.
Интерактивные элементы добавляйте только при `pinned: true`.

### Свойства по умолчанию

| Часть | Свойство | По умолчанию | Примечания |
| --- | --- | --- | --- |
| `Chart.Root` | элемент | `figure` | `Chart.Header` является его `figcaption`. |
| `Chart.Plot` | `definition` | - | Обязательное определение графика TanStack. |
| `Chart.Plot` | `ariaLabel` | - | Обязательное доступное имя графика. |
| `Chart.Plot` | `motion` | `true` | Задайте `false`, чтобы использовать статичный SVG-рендерер TanStack. |
| `Chart.Plot` | `renderer` | Пресет анимации Moduix | Анимирует геометрию и подсказку; учитывает настройки уменьшенного движения. |
| `Chart.Plot` | `height` | `320` | Используется, когда `aspectRatio` не задан. |
| `Chart.Plot` | `width` | адаптивная | Следует ширине хоста. |
| `Chart.Plot` | `initialWidth` | `640` | Ширина на сервере и до измерения. |
| `Chart.Plot` | `tabIndex` | `0` | Сохраняет клавиатурную навигацию TanStack в порядке обхода по Tab. |

### Особенности поведения

- Храните статичное определение на уровне модуля. Если оно зависит от свойств или состояния,
  мемоизируйте определение целиком через `useMemo`.
- Стандартный рендерер анимации анимирует исходную геометрию, обновления данных с ключами, направляющие
  фокуса и встроенную подсказку. При `prefers-reduced-motion: reduce` изменения применяются без
  анимации; `motion={false}` отключает её независимо от системных настроек пользователя.
- Фокус при наведении указателя, навигация стрелками, активация клавишами Enter и Space,
  `onFocusChange` и `onSelect` остаются под управлением TanStack.
- Фокусируемый SVG в области графика использует индикатор фокуса moduix. Не задавайте
  `focusRing: false`, если пользовательская геометрия фокуса не заменяет индикатор точки TanStack.
- `ariaDescription` добавляет детали, когда видимых заголовка и описания недостаточно.
- `className` и `style` у `Chart.Plot` применяются к внешнему хосту TanStack. У него нет API для ref.

### Расширенная настройка

Части, созданные через Ark factory, принимают `asChild`, поэтому могут стилизовать семантические
элементы вашей разметки. Этот раздел панели управления объединяет Chart и Button, заменяет
стандартные `figure` и `figcaption` на связанные с заголовком `section` и `header`, а легенду
переносит в `header`.

`Chart.Plot` остаётся хостом TanStack, а не слотом: используйте его `className` и `style` для
внешнего элемента, а `renderTooltipBody` — чтобы дополнить подсказку. Оставляйте `defaultBody` в
`Chart.TooltipContent`: TanStack продолжает позиционировать подсказку и рендерить её через портал.
Добавлять интерактивные элементы можно только в закреплённую подсказку.

## Стилизация

Стилизуйте фигуру через `Chart.Root`, а хост TanStack — через `Chart.Plot`. Публичные CSS-свойства
управляют поверхностью, индикатором фокуса, оболочкой подсказки и её стандартными строками. Геометрия
графика остаётся в определении TanStack и настраивается через параметры меток, шкалы и цветовые каналы.

Передайте корневому элементу класс, если графику нужны локальные переопределения:

```tsx
<Chart className="sales-chart">...</Chart>
```

```css
.sales-chart {
  --moduix-chart-tooltip-bg: var(--moduix-color-card);
  --moduix-chart-tooltip-column-gap: var(--moduix-spacing-3);
  --moduix-chart-tooltip-font-size: var(--moduix-text-sm);
  --moduix-chart-tooltip-label-color: var(--moduix-color-foreground);
  --moduix-chart-tooltip-line-height: var(--moduix-line-height-text-sm);
}

.sales-chart [data-slot='chart-tooltip-value'] {
  font-weight: var(--moduix-weight-bold);
}
```

### Хуки стилизации

- `Chart.Root`, `Chart.Header`, `Chart.Title`, `Chart.Description`, `Chart.Legend`,
  `Chart.LegendItem` и `Chart.TooltipContent` предоставляют `data-scope="chart"`, `data-part` и
  `data-slot`.
- `className` на `Chart.Plot` достигает внешнего элемента `.ts-chart-host`.
- Стандартная подсказка предоставляет data slots `chart-tooltip-body`, `chart-tooltip-title`,
  `chart-tooltip-rows`, `chart-tooltip-row`, `chart-tooltip-swatch`, `chart-tooltip-label` и
  `chart-tooltip-value`.
- Используйте `--moduix-color-chart-1` — `--moduix-color-chart-5` в цветовых шкалах TanStack.
- TanStack по-прежнему управляет позиционированием и взаимодействием оболочки подсказки; её тело
  принадлежит Moduix, не требует переопределения специфичности и полностью заменяется через
  `renderTooltipBody`.
