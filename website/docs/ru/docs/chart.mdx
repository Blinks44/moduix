## Справочник API

В Ark UI нет примитива chart. moduix объединяет части Ark factory с
[React-хостом TanStack Charts](https://tanstack.com/charts/latest/docs/framework/react/reference/chart),
сохраняя framework-agnostic определения, метки, шкалы, взаимодействия и колбэки TanStack.
TanStack Charts 0.14 требует React 19.

## Базовый пример

## Анатомия

```text
Chart / Chart.Root
├─ Chart.Header (необязательный figcaption)
│  ├─ Chart.Title
│  └─ Chart.Description
├─ Chart.Plot
│  └─ поверхность TanStack chart (по умолчанию SVG)
└─ Chart.Legend (необязательно)
   └─ Chart.LegendItem

Chart.TooltipContent (внутри renderTooltipBody)
```

| Часть | Назначение |
| --- | --- |
| `Chart` / `Chart.Root` | Композиционная поверхность `figure`. Принимает нативные props, `asChild` и `HTMLElement` ref. |
| `Chart.Plot` | React-хост TanStack. Требует `definition` и `ariaLabel`; по умолчанию использует motion-пресет Moduix и принимает `motion={false}`. |
| `Chart.Header` | Layout `figcaption` для заголовка и описания. |
| `Chart.Title` | Заголовок chart; по умолчанию рендерит `h3`. |
| `Chart.Description` | Дополнительный видимый контекст. |
| `Chart.Legend` | Семантический список видимых серий. |
| `Chart.LegendItem` | Элемент легенды с необязательным цветом индикатора `color`. |
| `Chart.TooltipContent` | Layout для React-содержимого из `renderTooltipBody`. |

## Композиция

### Рекомендуемая композиция

Храните стабильное определение TanStack вне компонента, затем скомпонуйте `Chart.Header`,
`Chart.Plot` и `Chart.Legend` внутри callable root. Используйте `barY`, `areaY`, `lineY`, stacking,
шкалы, guides и цветовые каналы TanStack напрямую: moduix не дублирует их React-частями.

Используйте цветовую шкалу определения для меток и индикаторов tooltip. Повторно используйте
соответствующие цветовые токены moduix в `Chart.LegendItem`, чтобы видимая легенда совпадала с chart.

### Выбор marks

`Chart.Plot` — это хост renderer, а результат определяют marks внутри `definition`. Все варианты
используют одну композицию `<Chart.Plot definition={definition} />`.

| Задача | Marks | Пример |
| --- | --- | --- |
| Вертикальные столбцы | `barY` | Базовый пример, Составные столбцы |
| Горизонтальные столбцы | `barX` | Горизонтальные столбцы |
| Линия или область | `lineY`, `areaY` | Анимированная область, Цвета chart |
| Пирог или кольцевая диаграмма | `pie`, `polar`, `radialArc` | Кольцевая диаграмма |
| Точечная диаграмма | `dot` | Точечная диаграмма |
| Тепловая карта | `cell` | Тепловая карта |

### Когда нужна собственная композиция

По умолчанию `Chart.Plot` использует быстрый пресет TanStack `motion()`. Задайте `motion={false}`
для полностью статичного SVG chart или передайте другой `renderer` для собственной политики
анимации. Явный `renderer` имеет приоритет над `motion`. Если приложение само владеет поверхностью,
используйте canvas или low-level renderer entry TanStack напрямую.

```tsx
<Chart.Plot definition={definition} ariaLabel="Monthly revenue" motion={false} />
```

При настройке tooltip сохраняйте `defaultBody` внутри `Chart.TooltipContent`. TanStack продолжает
владеть anchor, позиционированием, portalling, закреплённым состоянием и закрытием. Интерактивные
элементы рендерите только при `pinned: true`.

### Свойства по умолчанию

| Часть | Свойство | По умолчанию | Примечания |
| --- | --- | --- | --- |
| `Chart.Root` | элемент | `figure` | `Chart.Header` является его `figcaption`. |
| `Chart.Plot` | `definition` | - | Обязательное определение chart TanStack. |
| `Chart.Plot` | `ariaLabel` | - | Обязательное доступное имя chart. |
| `Chart.Plot` | `motion` | `true` | Задайте `false`, чтобы использовать статичный SVG renderer TanStack. |
| `Chart.Plot` | `renderer` | Motion-пресет Moduix | Анимирует геометрию и tooltip; учитывает reduced motion. |
| `Chart.Plot` | `height` | `320` | Используется, когда `aspectRatio` не задан. |
| `Chart.Plot` | `width` | адаптивная | Следует ширине хоста. |
| `Chart.Plot` | `initialWidth` | `640` | Ширина на сервере и до измерения. |
| `Chart.Plot` | `tabIndex` | `0` | Сохраняет клавиатурную навигацию TanStack в tab order. |

### Особенности поведения

- Храните статичное определение на уровне модуля. Если оно захватывает props или state, мемоизируйте
  всё определение через `useMemo`.
- Стандартный motion renderer анимирует начальную геометрию, keyed-обновления данных, focus guides и
  нативный tooltip. При `prefers-reduced-motion: reduce` значения меняются без анимации;
  `motion={false}` отключает её независимо от пользовательских media preferences.
- Pointer focus, навигация стрелками, активация через Enter/Space, `onFocusChange` и `onSelect`
  остаются под управлением TanStack.
- Фокусируемый SVG внутри plot использует focus ring moduix. Не задавайте `focusRing: false`, если
  собственная focus-геометрия не заменяет индикатор точки TanStack.
- `ariaDescription` добавляет детали, когда видимых заголовка и описания недостаточно.
- `className` и `style` на `Chart.Plot` применяются к внешнему TanStack-хосту. У хоста нет ref API.

## Стилизация

Стилизуйте фигуру через `Chart.Root`, а TanStack-хост — через `Chart.Plot`. Публичные CSS-свойства
управляют поверхностью, focus ring, оболочкой tooltip и его стандартными строками. Геометрия chart
остаётся в определении TanStack и настраивается через параметры marks, шкалы и цветовые каналы.

Передайте корню класс, если конкретному chart нужны локальные переопределения:

```tsx
<Chart className="sales-chart">...</Chart>
```

```css
.sales-chart {
  --moduix-chart-tooltip-bg: var(--moduix-color-card);
  --moduix-chart-tooltip-column-gap: var(--moduix-spacing-3);
  --moduix-chart-tooltip-font-size: var(--moduix-text-sm);
  --moduix-chart-tooltip-label-color: var(--moduix-color-foreground);
  --moduix-chart-tooltip-line-height: var(--moduix-line-height-text-sm);
}

.sales-chart [data-slot='chart-tooltip-value'] {
  font-weight: var(--moduix-weight-bold);
}
```

### Хуки стилизации

- `Chart.Root`, `Chart.Header`, `Chart.Title`, `Chart.Description`, `Chart.Legend`,
  `Chart.LegendItem` и `Chart.TooltipContent` предоставляют `data-scope="chart"`, `data-part` и
  `data-slot`.
- `className` на `Chart.Plot` достигает внешнего элемента `.ts-chart-host`.
- Стандартный tooltip предоставляет data slots `chart-tooltip-body`, `chart-tooltip-title`,
  `chart-tooltip-rows`, `chart-tooltip-row`, `chart-tooltip-swatch`, `chart-tooltip-label` и
  `chart-tooltip-value`.
- Используйте `--moduix-color-chart-1` — `--moduix-color-chart-5` в цветовых шкалах TanStack.
- TanStack по-прежнему управляет позицией и взаимодействием оболочки tooltip; тело принадлежит
  Moduix, не требует переопределения специфичности и полностью заменяется через `renderTooltipBody`.
