## Справочник API

В Ark UI нет примитива для графиков. moduix добавляет к
[React-компоненту TanStack Charts](https://tanstack.com/charts/latest/docs/framework/react/reference/chart)
фигуру, заголовок, легенду и подсказку. Сами графические элементы, шкалы, взаимодействия и
колбэки по-прежнему описываются средствами TanStack Charts. Для TanStack Charts 0.14 нужен React 19.

## Базовый пример

разместите рядом с областью графика. Для пользователей ассистивных технологий задайте краткий

## Анатомия

```text
Chart / Chart.Root
├─ Chart.Header (необязательный figcaption)
│  ├─ Chart.Title
│  └─ Chart.Description
├─ Chart.Plot
│  └─ поверхность графика TanStack (по умолчанию SVG)
└─ Chart.Legend (необязательно)
   └─ Chart.LegendItem
```

| Часть | Назначение |
| --- | --- |
| `Chart` / `Chart.Root` | Корневой элемент `figure`. Принимает нативные свойства, `asChild` и ref на `HTMLElement`. |
| `Chart.Plot` | React-компонент TanStack. Требует `definition` и `ariaLabel`; по умолчанию использует пресет анимации Moduix, его можно отключить через `motion={false}`. |
| `Chart.Header` | Элемент `figcaption` с заголовком и описанием. |
| `Chart.Title` | Заголовок графика, по умолчанию это `h3`. |
| `Chart.Description` | Видимое пояснение к графику. |
| `Chart.Legend` | Семантический список видимых серий. |
| `Chart.LegendItem` | Элемент легенды с необязательным цветом индикатора `color`. |

## Композиция

### Рекомендуемая композиция

Если определение TanStack не меняется, объявите его вне компонента. В корневом компоненте соберите
`Chart.Header`, `Chart.Plot` и `Chart.Legend`. `barY`, `areaY`, `lineY`, `stack()`, шкалы,
направляющие и цветовые каналы задавайте в TanStack Charts. moduix не дублирует их отдельными
React-компонентами.

Цветовую шкалу из определения используют и графические элементы, и индикаторы в подсказке. Укажите
те же токены moduix в `Chart.LegendItem`, чтобы цвета легенды совпадали с графиком.

### Выбор графических элементов

`Chart.Plot` отвечает за отрисовку, а содержимое `definition` определяет вид графика. Во всех
вариантах используется один и тот же компонент: `<Chart.Plot definition={definition} />`.

| Задача | Элементы TanStack | Пример |
| --- | --- | --- |
| Вертикальные столбцы | `barY` | Базовый пример, Столбцы с накоплением |
| Горизонтальные столбцы | `barX` | Горизонтальные столбцы |
| Линия или область | `lineY`, `areaY` | Анимированная область, Цвета графика |
| Круговая или кольцевая диаграмма | `pie`, `polar`, `radialArc` | Кольцевая диаграмма |
| Точечная диаграмма | `dot` | Точечная диаграмма |
| Тепловая карта | `cell` | Тепловая карта |

### Настройка рендеринга

По умолчанию `Chart.Plot` использует адаптивный пресет TanStack `motion()`. Чтобы получить статический
SVG-график, задайте `motion={false}`. Для собственной логики анимации передайте другой `renderer`.
Явно заданный `renderer` важнее `motion`. Если приложению нужно самостоятельно управлять поверхностью
отрисовки, используйте canvas- или низкоуровневый рендерер TanStack напрямую.

```tsx
<Chart.Plot definition={definition} ariaLabel="Monthly revenue" motion={false} />
```

По умолчанию Chart использует компактную подсказку Moduix: строки без цветной метки не оставляют
пустую колонку. `renderTooltipBody` нужен только для React-содержимого в подсказке. В его колбэк
передаётся нативный `defaultBody` TanStack с заголовком, строками, форматированием и цветовыми
метками. TanStack сам привязывает, размещает, выводит через портал, закрепляет и закрывает подсказку.
Интерактивные элементы можно рендерить только при `pinned: true`.

### Свойства по умолчанию

| Часть | Свойство | По умолчанию | Примечания |
| --- | --- | --- | --- |
| `Chart.Root` | элемент | `figure` | `Chart.Header` является его `figcaption`. |
| `Chart.Plot` | `definition` | - | Обязательное определение графика TanStack. |
| `Chart.Plot` | `ariaLabel` | - | Обязательное доступное имя графика. |
| `Chart.Plot` | `motion` | `true` | Задайте `false`, чтобы использовать статичный SVG-рендерер TanStack. |
| `Chart.Plot` | `renderer` | Пресет анимации Moduix | Анимирует геометрию и подсказку; учитывает настройки уменьшенного движения. |
| `Chart.Plot` | `height` | `320` | Используется, когда `aspectRatio` не задан. |
| `Chart.Plot` | `width` | адаптивная | Подстраивается под ширину контейнера. |
| `Chart.Plot` | `initialWidth` | `640` | Ширина на сервере и до первого измерения. |
| `Chart.Plot` | `tabIndex` | `0` | Оставляет клавиатурную навигацию TanStack в порядке перехода по Tab. |

### Особенности поведения

- Храните неизменяемое определение на уровне модуля. Если оно зависит от свойств или состояния,
  мемоизируйте всё определение через `useMemo`.
- Стандартный рендерер анимирует начальную геометрию, обновления данных с ключами, направляющие фокуса
  и встроенную подсказку. При `prefers-reduced-motion: reduce` значения меняются без анимации.
  `motion={false}` отключает её независимо от системных настроек.
- Наведение, переходы стрелками, активация клавишами Enter и Space, `onFocusChange` и `onSelect`
  обрабатывает TanStack.
- SVG в области графика получает обводку фокуса moduix. Не задавайте `focusRing: false`, если
  собственная геометрия фокуса не заменяет индикатор точки TanStack.
- Добавьте `ariaDescription`, если одного видимого заголовка и описания недостаточно.
- `className` и `style` у `Chart.Plot` применяются к внешнему элементу TanStack. Ref API у него нет.

### Расширенная настройка

Компоненты, созданные с помощью Ark factory, принимают `asChild` и могут применять свои стили к
семантическим элементам вашей разметки. В этом разделе панели Chart работает вместе с Button:
вместо стандартных `figure` и `figcaption` используются связанные с заголовком `section` и `header`,
а легенда находится в `header`.

`Chart.Plot` остаётся компонентом TanStack, а не слотом. Его `className` и `style` применяются к
внешнему элементу, а `renderTooltipBody` позволяет дополнить подсказку. Рендерьте `defaultBody` в
своём контейнере: TanStack продолжит размещать его и выводить через портал. Интерактивные элементы
добавляйте только в закреплённую подсказку.

## Стилизация

Стилизуйте фигуру через `Chart.Root`, а элемент TanStack через `Chart.Plot`. Публичные CSS-свойства
управляют поверхностью, обводкой фокуса, оболочкой подсказки и её стандартной разметкой. Геометрия
графика остаётся в определении TanStack и настраивается параметрами графических элементов, шкалами
и цветовыми каналами.

Передайте корневому элементу класс, если графику нужны локальные переопределения:

```tsx
<Chart className="sales-chart">...</Chart>
```

```css
.sales-chart {
  --moduix-chart-tooltip-bg: var(--moduix-color-card);
  --moduix-chart-tooltip-font-size: var(--moduix-text-sm);
  --moduix-chart-tooltip-line-height: var(--moduix-line-height-text-sm);
}
```

### Хуки стилизации

- `Chart.Root`, `Chart.Header`, `Chart.Title`, `Chart.Description`, `Chart.Legend`,
  и `Chart.LegendItem` предоставляют `data-scope="chart"`, `data-part` и `data-slot`.
- `className` у `Chart.Plot` применяется к внешнему элементу `.ts-chart-host`.
- Стандартная подсказка использует слоты данных `chart-tooltip-body`,
  `chart-tooltip-title`, `chart-tooltip-rows`, `chart-tooltip-row`, `chart-tooltip-swatch`,
  `chart-tooltip-label` и `chart-tooltip-value`.
- Используйте `--moduix-color-chart-1` - `--moduix-color-chart-5` в цветовых шкалах TanStack.
- Оболочка подсказки настраивается через документированные переменные `--ts-chart-tooltip-*`,
  связанные со свойствами Moduix. Для собственных CSS-селекторов используйте
  `tooltip.className`, а для React-содержимого - `renderTooltipBody` и нативный `defaultBody`.
