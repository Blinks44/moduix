# Вход

Этот рецепт поможет собрать компактную форму входа со встроенной проверкой полей в браузере, автозаполнением
электронной почты и пароля, а также ссылками для восстановления доступа и регистрации. В нём используются
компоненты moduix `Card`, `Field`, `Input`, `Checkbox` и `Button`. Рецепт не выполняет вход и не
управляет состоянием запроса. Подключите обработку входа в своём приложении через `onSubmit`.

Живое превью использует React-пакет. Во вкладках исходников приведены нативные реализации для React и Solid с общими стилями.

## Подключение обработки входа

`LoginSimple` передаёт обработчик `onSubmit` обычному элементу `<form>`. Обработчик получает обычное событие формы,
поэтому вызовите `event.preventDefault()`, соберите данные через `new FormData(event.currentTarget)` и
отправьте их в свой API. Поля формы имеют имена `email`, `password` и `remember`. Параметр `remember`
добавляется в данные только если флажок отмечен.

## Что учесть в продакшене

| Сценарий | Что сделать |
| -------- | ----------- |
| Запрос выполняется | Пока запрос выполняется, заблокируйте кнопку отправки и не допускайте повторной отправки. |
| Неверные учётные данные | Покажите одно сообщение на уровне формы, не раскрывая, какое именно поле оказалось неверным. |
| Ошибка сети | Сохраните введённый адрес и предложите повторить попытку. Очищайте пароль только если этого требуют правила безопасности приложения. |
| Успешный вход | Перенаправьте пользователя на безопасный маршрут или замените текущую запись в истории в соответствии с логикой приложения. |

Если приложение принимает параметр `returnTo` или URL для перенаправления, проверьте его на сервере до перехода.
