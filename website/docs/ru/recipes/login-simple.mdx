## В маршруте

Рендерите `LoginSimple` в маршруте, который отвечает за аутентификацию, и передайте ему реальный обработчик
отправки формы. Замените ссылки `/forgot-password` и `/sign-up` маршрутами своего приложения.

| Результат | Поведение маршрута |
| --------- | ----------------- |
| Отправка | Заблокируйте повторную отправку и задайте кнопке текст `Signing in…`. |
| Неверные данные | Покажите одну ошибку формы, не уточняя, что именно введено неверно. |
| Ошибка сети | Сохраните адрес электронной почты и предложите повторить попытку; не очищайте пароль без необходимости. |
| Успех | Замените запись в истории или перенаправьте пользователя на безопасную страницу, выбранную приложением. |

Проверяйте на сервере любой URL `returnTo` или перенаправления перед переходом по нему.
