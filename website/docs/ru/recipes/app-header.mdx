## Настройка

В рецепте для всех навигационных действий используются настоящие ссылки, а активный пункт помечен
`aria-current="page"`. Замените демонстрационные данные значениями из роутера и состояния учётной записи.

| Что заменить | На что заменить в приложении |
| ------------ | ---------------------------- |
| Orbit и Acme Studio | Ссылку на главную страницу продукта и текущее рабочее пространство |
| Навигационные ссылки | Ссылки роутера; задавайте `aria-current="page"` по текущему маршруту |
| Поле поиска | Триггер Command Palette с маршрутами и действиями приложения |
| Аватар и данные учётной записи | Данные авторизованного пользователя и URL изображения, которым управляет приложение |
| Ссылки в меню учётной записи | Маршруты профиля, настроек, справки и другие действительно нужные пользователям страницы |

Если роутер предоставляет компонент Link, передайте его через `Button asChild` или `Menu.Item asChild`, а не
вкладывайте один интерактивный элемент в другой. Оставьте fallback аватара, чтобы элемент управления учётной
записью оставался узнаваемым во время загрузки изображения и когда изображения нет вовсе.

## Адаптивное поведение

При ширине менее 48rem центрированная навигация переезжает в полноценный `Menu`, а не исчезает. При ширине
менее 36rem подписи рабочего пространства и учётной записи скрываются, но у кнопок с иконками сохраняются
доступные имена. Для более глубокой навигации с группами или вложенными маршрутами замените компактное меню рецептом
[Мобильная навигация с выдвижной панелью](/recipes/mobile-drawer-navigation).
