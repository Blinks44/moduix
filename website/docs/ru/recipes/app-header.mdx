# Шапка приложения

В этом рецепте показано, как собрать адаптивную шапку приложения из `Avatar`, `Button`,
`CommandPalette` и `Menu`. В одной компактной панели собраны ссылка на продукт, текущее рабочее
пространство, основная навигация, поиск и действия с учётной записью.

## Что входит в рецепт

- Основная навигация с `aria-current="page"` для активного маршрута.
- Палитра команд `CommandPalette`, которая фильтрует сгруппированные пункты навигации и действия рабочего пространства.
- Меню учётной записи со ссылками на профиль, настройки рабочего пространства и справку.
- Отдельное меню `Menu` для основной навигации на узких экранах.
- Доступные имена для кнопок только с иконками и резервное отображение аватара.

## Подключение к приложению

В примере используются хеш-ссылки вроде `#overview`, а при выборе команды обновляется
`window.location.hash`. Благодаря этому пример работает без роутера. Замените хеш-ссылки и
обработчик выбора команд на навигацию вашего роутера.

Разместите рецепт в общем макете, который отвечает за основную навигацию и состояние учётной
записи. Оставляйте `aria-current="page"` только у ссылки текущего маршрута.

## Настройка

Замените демонстрационные данные маршрутами, состоянием рабочего пространства и данными
авторизованного пользователя.

| Что заменить | Что использовать в приложении |
| ----------- | ----------------------------- |
| Orbit и Acme Studio | Ссылку на главную страницу продукта и название активного рабочего пространства |
| Хеш-ссылки вроде `#overview` | Маршруты приложения и навигацию роутера при выборе команды |
| Навигационные ссылки | Ссылки роутера с `aria-current="page"` для текущего маршрута |
| Команды поиска | Нужные пользователям маршруты и действия, сгруппированные понятным образом |
| Аватар и данные пользователя | Данные авторизованного пользователя и URL изображения, которым управляет приложение |
| Пункты меню учётной записи | Маршруты профиля, настроек, справки и другие действительно нужные страницы |

Если роутер предоставляет компонент `Link`, используйте `Button asChild` или `Menu.Item asChild`,
чтобы интерактивным элементом оставалась ссылка роутера. Не вкладывайте ссылку в кнопку. Сохраните
`Avatar.Fallback`, чтобы элемент управления учётной записью оставался понятным во время загрузки
изображения и когда изображения нет.

## Адаптивное поведение

В CSS-модуле заданы три порога:

- При ширине менее `64rem` скрывается рабочее пространство вместе с индикатором, чтобы освободить место для основных элементов.
- При ширине менее `48rem` обычная навигация скрывается, а вместо неё появляется кнопка, открывающая `Menu`.
- При ширине менее `36rem` скрываются имя и должность пользователя, а также стрелка меню. Аватар остаётся видимым.

Если в приложении больше ссылок или есть вложенные маршруты, подстройте пороги и вариант мобильной навигации под свою структуру.
