# Галерея

Карусель для основного контента с частично видимыми соседними слайдами, боковой навигацией, размытым блоком
текста и индикаторами, которые заполняются в течение задержки автопрокрутки. Используются только части
`Carousel`: `Carousel.Context` передаёт состояние воспроизведения в CSS-анимацию, а переходы по стрелкам и
индикаторам перезапускают автопрокрутку без отдельной кнопки запуска.

## На странице

Замените изображения и текст слайдов своим контентом. Длительность CSS-анимации должна совпадать с
`autoplay.delay`, чтобы заполнение индикатора заканчивалось вместе с появлением следующего слайда. После ручного
перехода колбэки откладывают `api.play()` до следующего кадра: Ark сначала обрабатывает смену слайда и ставит
автопрокрутку на паузу, затем запускается новый интервал - без отдельного элемента управления. Ark ставит
автопрокрутку на паузу, когда документ скрыт; рецепт вызывает публичный `api.play()`, когда он снова видим.
