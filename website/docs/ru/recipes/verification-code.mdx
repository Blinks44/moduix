Подтвердите адрес электронной почты одноразовым шестизначным кодом. `PinInput` даёт нативное поле формы,
клавиатурную навигацию и автозаполнение OTP на мобильных устройствах. Отправьте форму с менее чем шестью
цифрами, чтобы увидеть встроенную ошибку поля.

## В маршруте

Рендерите `VerificationCode` после отправки кода по электронной почте и передайте ему реальный обработчик
отправки формы. `onSubmit` получает нативное событие формы: прочитайте `new FormData(event.currentTarget)` и
проверьте значение `code` на сервере. Замените ссылку `/sign-in` маршрутом своего приложения.

В превью сервера подтверждения намеренно нет. После ввода шести цифр запускается пустой обработчик отправки;
в скопированном рецепте вместо него будет вызван обработчик, который вы передадите.

Пока запрос не завершён, блокируйте повторную отправку. Если код неверный, сохраняйте введённые цифры и
показывайте ошибку у поля; если код просрочен, объясняйте, что нужно запросить новый. Разрешайте повторную
отправку только после короткой задержки, сообщайте об отправке нового кода и поручите серверу реальное ограничение
частоты. Не считайте обратный отсчёт на клиенте подтверждением авторизации.
