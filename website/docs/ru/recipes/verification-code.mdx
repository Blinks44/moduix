# Код подтверждения

Используйте этот рецепт, когда приложение отправляет пользователю одноразовый код на электронную почту.
В нём `Card`, `Field`, `Button` и `PinInput` собраны в готовую форму. `PinInput` сохраняет код в скрытом
нативном поле формы, обрабатывает навигацию с клавиатуры и вставку, а также включает автозаполнение
одноразового кода на мобильных устройствах. Отправьте форму, не заполнив все шесть цифр, чтобы увидеть
встроенную ошибку поля. Эта проверка подтверждает только наличие всех шести цифр. Проверяйте сам код на
сервере.

Живое превью использует React-пакет. Во вкладках исходников приведены нативные реализации для React и Solid с общими стилями.

## Добавьте рецепт в маршрут

Скопируйте компонент `VerificationCode` и его стили, затем добавьте его в маршрут, который отвечает за
подтверждение электронной почты. Показывайте форму после того, как приложение отправит код. `onSubmit`
получает нативное событие формы. Если отправляете код в API из браузера, вызовите
`event.preventDefault()`, получите значение через `new FormData(event.currentTarget).get('code')` и
отправьте его на сервер. Замените ссылку `/sign-in` маршрутом своего приложения.

Интерактивное превью намеренно не обращается к серверу. Его обработчик вызывает
`event.preventDefault()`, поэтому браузер остаётся на странице. В скопированном рецепте передайте обработчик,
который подключает форму к вашему API.

## Обработка состояний в рабочем приложении

- Пока идёт проверка, отключайте кнопку отправки, чтобы избежать повторных запросов.
- Если сервер отклонил код, оставьте введённые цифры и покажите ошибку через `Field`. Встроенная ошибка
  этого примера проверяет только, что введены все шесть цифр.
- Если код истёк, сообщите пользователю, что нужно запросить новый, и добавьте действие для повторной
  отправки. Сделайте короткую паузу перед повторной отправкой, сообщите об отправке нового кода и ограничьте
  частоту запросов на сервере. Обратный отсчёт на клиенте не заменяет проверку на сервере.
