## Использование в маршруте

Замените примеры ссылок, подписи и содержимое панели управления своими маршрутами и данными. Этот рецепт ориентирован
на десктоп: меню учётной записи, уведомления и мобильная навигация с выдвижной панелью остаются отдельными рецептами,
чтобы вы добавляли их только тогда, когда они нужны приложению.

Отмечайте активный пункт назначения через `aria-current="page"` и используйте ссылки роутера через `asChild` там,
где роутер должен управлять навигацией. Сохраняйте свёрнутую ширину, только если эта настройка полезна возвращающимся
пользователям; читайте хранилище браузера после гидратации и сохраняйте пригодный к использованию вариант по умолчанию без него. Сочетайте этот каркас для десктопа
с [мобильной навигацией с выдвижной панелью](/recipes/mobile-drawer-navigation), а не пытайтесь втиснуть изменяемую по ширине
боковую панель в узкий viewport.
