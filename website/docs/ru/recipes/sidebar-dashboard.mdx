# Панель управления

и простым обзором ключевых показателей. `Sidebar` отвечает за сворачивание, изменение размера с клавиатуры и
подсказки в свёрнутом состоянии. Пункт Projects показывает вложенную навигацию, а в подвале расположено меню
рабочего пространства.

## В маршруте

Замените демонстрационные ссылки, подписи и содержимое панели своими маршрутами и данными. Рецепт рассчитан
на десктоп; адаптируйте отзывчивую навигацию, меню учётной записи и уведомления под своё приложение.

Помечайте активный раздел через `aria-current="page"`. Если навигацией управляет Link из роутера, передайте его
через `asChild`. Запоминайте свёрнутую ширину, только если это действительно удобно возвращающимся пользователям;
читайте хранилище браузера после гидратации и оставьте рабочее состояние по умолчанию без него.
