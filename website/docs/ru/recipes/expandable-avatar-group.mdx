# Группа аватаров

Используйте этот компактный список команды, когда места мало, но каждого участника всё равно нужно легко
распознать. При наведении или фокусе аватар освобождает место справа от себя и показывает свою подсказку.

## Детали

Группа использует `Avatar.Image` с `Avatar.Fallback` на время загрузки и `Tooltip.Trigger asChild`, поэтому
каждый аватар остаётся семантической кнопкой. Анимация сделана только на CSS: активная кнопка слегка
приподнимается, а следующие элементы освобождают для неё место. Перед использованием рецепта замените
демонстрационные URL изображений источником аватаров из приложения.

Текст подсказки должен быть коротким и необязательным для понимания интерфейса. Если выбор участника ведёт по
ссылке или выполняет действие, замените кнопку подходящим семантическим элементом и сохраните его доступное имя.

Используйте `role="group"` с понятной подписью для списка. Добавляйте роль человека в доступное имя кнопки,
если она помогает различать похожие имена. Для большой команды показывайте несколько первых участников и элемент
`+N`, который открывает полный список с поиском. Сохраняйте порядок списка стабильным. При
`prefers-reduced-motion: reduce` оставляйте раскрытый интервал, но отключайте подъём и переходы.
