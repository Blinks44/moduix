# Карточка с параллаксом

Этот рецепт сочетает `Card.Background`, небольшой обработчик указателя и CSS-трансформации. Получается
карточка с фоновым изображением на всю площадь и лёгким 3D-наклоном. Это готовая композиция приложения,
а не компонент `ParallaxCard`, экспортируемый moduix.

`Card.Background` размещает изображение за содержимым карточки. Градиент поверх изображения и контраст
текста задаются в CSS-примере, поэтому их можно настроить под выбранное изображение. Наклон включается
только на устройствах с точным указателем, поддерживающим наведение. Если такой указатель недоступен или
пользователь включил уменьшение анимации, карточка остаётся статичной.

Живое превью использует React-пакет. Во вкладках исходников приведены нативные реализации для React и Solid с общими стилями.

## Использование на странице

Скопируйте компонент и CSS выше в своё приложение, затем:

- замените URL изображения и видимый текст своим содержимым;
- оставьте для изображения внутри `Card.Background` пустой `alt=""`, поскольку оно декоративное. Если
  изображение передаёт важную информацию, используйте `Card.Media` и добавьте альтернативный текст;
- воспринимайте наклон как визуальное дополнение. Карточка должна оставаться читаемой и удобной без
  наведения и анимации;
- добавьте настоящую ссылку или кнопку, если карточка должна выполнять действие. Если вся карточка является
  одной ссылкой без вложенных элементов управления, используйте `Card.Root asChild`. Если в карточке есть
  отдельные действия, поместите `Card.Link` в `Card.Title`.
