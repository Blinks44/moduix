# Карточка с параллаксом

Карточка с изображением на весь фон и лёгким 3D-наклоном. `Card.Background` управляет декоративным слоем,
а `react-parallax-tilt` — движением курсора. Эффект не включается без точного указателя с hover и при
включённом уменьшении анимации.

## На странице

Замените URL изображения и текст карточки своим контентом. У декоративного фона должен остаться `alt=""`;
если изображению нужен альтернативный текст, используйте `Card.Media`. Анимация здесь только декоративная,
поэтому карточка должна быть читаемой и полезной без hover. Для перехода используйте обычную ссылку или кнопку.
