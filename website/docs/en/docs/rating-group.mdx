## Anatomy

```text
RatingGroup / RatingGroup.Root
├─ RatingGroup.Label
└─ RatingGroup.Control
   ├─ RatingGroup.Items (recommended)
   │  └─ RatingGroup.Item[index]
   │     └─ RatingGroup.ItemIndicator
   ├─ RatingGroup.Context (advanced, optional)
   │  └─ RatingGroup.Item[index]
   │     └─ RatingGroup.ItemIndicator
   └─ native form input (automatic)

RatingGroup.RootProvider
└─ same part tree connected to a moduix useRatingGroup() store
```

| Part                               | Role                                                      |
| ---------------------------------- | --------------------------------------------------------- |
| `RatingGroup` / `RatingGroup.Root` | Owns rating state, keyboard navigation, focus, and form integration. |
| `RatingGroup.RootProvider`         | Connects the parts to state created with `useRatingGroup()`.       |
| `RatingGroup.Context`              | Render-prop access to the current root state.                      |
| `RatingGroup.ItemContext`          | Render-prop access to the current item state.                      |
| `RatingGroup.Label`                | Accessible label for the rating group.                             |
| `RatingGroup.Control`              | Groups the interactive rating items.                               |
| `RatingGroup.Items`                | Creates one item for each value and supplies the default star.     |
| `RatingGroup.Item`                 | One selectable rating item; requires a numeric `index`.            |
| `RatingGroup.ItemIndicator`        | The default moduix star visual that reflects the item's state.      |

## Composition

### Recommended composition

`RatingGroup` is the short root form of `RatingGroup.Root`. It keeps rating state, focus management,
labels, form integration, and keyboard and pointer behavior in one place. For the standard star UI,
add `RatingGroup.Items`; it creates an item for each value up to `count` and supplies the default star
indicator. The root also renders the synchronized native form input. To change the icon while keeping
the same interaction, pass a custom `RatingGroup.ItemIndicator` as the child of `RatingGroup.Items`.

### When to go custom

Use `RatingGroup.Context` or `RatingGroup.ItemContext` when you need to render your own item tree or
build visuals from the current root or item state. For the same state in a custom component, use
`useRatingGroupContext()` or `useRatingGroupItemContext()` from `@moduix/react`. Use
`RatingGroup.RootProvider` with `useRatingGroup()` when the rating state must be created outside the
rendered tree.

The Ark DOM parts exposed by the component support `asChild`. Keep the direct child a single semantic
element that can preserve the part's focus and interaction behavior. `RatingGroup.ItemIndicator` is
a moduix visual helper and does not replace an Ark DOM part.

### Default props

| Surface                     | Default | Notes                                                        |
| --------------------------- | ------- | ------------------------------------------------------------ |
| `count`                     | `5`     | Number of rating items.                                     |
| `size`                      | `md`    | moduix styling size: `xs`, `sm`, `md`, `lg`, or `xl`.        |
| `RatingGroup.Items`         | -       | Creates items from `1` through `count`.                     |
| `RatingGroup.ItemIndicator` | star    | Renders layered background and foreground stars by default. |

### Behavioral notes

- `value` and `defaultValue` are numbers. Use `defaultValue` for an uncontrolled rating.
- `onValueChange(details)` receives Ark details; read the selected value from `details.value`.
- `onHoverChange(details)` receives Ark hover details; use them for a live preview or related UI.
- `allowHalf` enables half-step selection and half-star rendering.
- `autoFocus` focuses the rating when it mounts.
- `name`, `form`, and `required` apply to the native form input rendered automatically by the root.
- `disabled` and `readOnly` are handled by Ark and reflected through data attributes.
- Ark handles keyboard navigation. `ArrowRight` and `ArrowLeft` move between items, and `Enter`
  selects the focused item. With `allowHalf`, the arrow keys also move in half-step increments.
- Use `ids` to provide deterministic IDs for composed markup and `translations` to customize Ark's
  localized accessible messages.

Refs on `Root`, `RootProvider`, `Label`, `Control`, and `Item` point to their corresponding Ark DOM
parts. `ItemIndicator` forwards its ref to its own visual wrapper.

## Styling

Style `RatingGroup` with `className`, Ark `data-scope="rating-group"` and `data-part` attributes,
Ark state attributes, moduix `data-slot` hooks, and the registered `--moduix-rating-group-*` CSS
variables.

### Styling hooks

- `data-slot="rating-group-root"` and `data-slot="rating-group-root-provider"`
- `data-slot="rating-group-label"`
- `data-slot="rating-group-control"`
- `data-slot="rating-group-item"`
- `data-slot="rating-group-item-indicator"`
- `data-slot="rating-group-item-indicator-bg"` and `data-slot="rating-group-item-indicator-fg"`
- `data-slot="rating-group-hidden-input"`
- `data-size="xs" | "sm" | "md" | "lg" | "xl"` on the root or root provider
- Ark label attributes: `data-disabled` and `data-required`
- Ark control attributes: `data-disabled` and `data-readonly`
- Ark item attributes: `data-checked`, `data-highlighted`, `data-half`, `data-disabled`, and `data-readonly`
