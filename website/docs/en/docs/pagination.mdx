## Anatomy

```text
Pagination / Pagination.Root
├─ Pagination.FirstTrigger (optional)
├─ Pagination.PrevTrigger
├─ Pagination.Items (recommended)
├─ Pagination.Context (advanced render-prop access)
│  ├─ Pagination.Item
│  └─ Pagination.Ellipsis
├─ Pagination.NextTrigger
└─ Pagination.LastTrigger (optional)

Pagination.RootProvider
└─ same trigger, item, ellipsis, and context tree connected to usePagination()
```

| Part                              | Role                                                               |
| --------------------------------- | ------------------------------------------------------------------ |
| `Pagination`                      | Navigation root that manages the current page and page size.       |
| `Pagination.RootProvider`         | Connects parts to state created by `Pagination.usePagination()`.   |
| `Pagination.Items`                | Renders the computed page items and ellipses.                      |
| `Pagination.Context`              | Exposes root state and navigation helpers through an Ark render prop. |
| `Pagination.usePagination`        | Creates pagination state outside the rendered tree.                |
| `Pagination.usePaginationContext` | Reads pagination state from a descendant.                          |
| `Pagination.Item`                 | Interactive page control. Pass a page object as its props.        |
| `Pagination.Ellipsis`             | Non-interactive marker for a collapsed page range. Requires `index`. |
| `Pagination.PrevTrigger`          | Moves to the previous page and disables itself on the first page.  |
| `Pagination.NextTrigger`          | Moves to the next page and disables itself on the last page.      |
| `Pagination.FirstTrigger`         | Moves to the first page and disables itself when already there.    |
| `Pagination.LastTrigger`          | Moves to the last page and disables itself when already there.     |

## Composition

Use `defaultPage` and `defaultPageSize` for internal state, or pass `page`, `pageSize`, and the
matching change callbacks when another part of the application owns it. Set `count` to the total
number of data items, not the number of pages, and pair it with a page-size prop so Ark can calculate
`totalPages`.

Use `Pagination.Items` for the standard page list. Use `Pagination.Context` when page items or
nearby controls need custom rendering. If state must be created outside the rendered tree, create it
with `Pagination.usePagination()` and pass it to `Pagination.RootProvider`. For URL navigation, set
`type="link"`, provide `getPageUrl(details)`, and render semantic anchors with `asChild`.

## Styling

moduix keeps Ark's state attributes and adds stable `data-slot` hooks for local styling. Page items
use tabular figures and compact inline padding. One- and two-digit labels keep the default square
footprint, while longer labels can expand without being clipped.

### Styling hooks

- `data-scope="pagination"` and `data-part="item"` on `Pagination.Item`
- `data-scope="pagination"` and `data-part="prev-trigger"` on `Pagination.PrevTrigger`
- `data-scope="pagination"` and `data-part="next-trigger"` on `Pagination.NextTrigger`
- `data-scope="pagination"` with `data-part="first-trigger"` or `data-part="last-trigger"` on edge triggers
- `data-selected` on the active page item
- `data-disabled` on unavailable triggers
- `data-slot="pagination-root"`, `pagination-root-provider`, `pagination-item`,
  `pagination-ellipsis`, `pagination-prev-trigger`, `pagination-next-trigger`,
  `pagination-first-trigger`, and `pagination-last-trigger` for moduix overrides
