## Anatomy

```text
Pagination
├─ PaginationFirstTrigger (optional)
├─ PaginationPrevTrigger
├─ PaginationItems (recommended)
├─ PaginationContext (advanced render-prop access)
│  ├─ PaginationItem
│  └─ PaginationEllipsis
├─ PaginationNextTrigger
└─ PaginationLastTrigger (optional)

PaginationRootProvider
└─ same trigger, item, ellipsis, and context tree connected to usePagination()
```

| Part                              | Role                                                               |
| --------------------------------- | ------------------------------------------------------------------ |
| `Pagination`                      | Navigation root that manages the current page and page size.       |
| `PaginationRootProvider`         | Connects parts to state created by `usePagination()`.   |
| `PaginationItems`                | Renders the computed page items and ellipses.                      |
| `PaginationContext`              | Exposes root state and navigation helpers through an Ark render prop. |
| `usePagination`        | Creates pagination state outside the rendered tree.                |
| `usePaginationContext` | Reads pagination state from a descendant.                          |
| `PaginationItem`                 | Interactive page control. Pass a page object as its props.        |
| `PaginationEllipsis`             | Decorative marker for a collapsed page range, hidden from assistive technology. Requires `index`. |
| `PaginationPrevTrigger`          | Moves to the previous page and disables itself on the first page.  |
| `PaginationNextTrigger`          | Moves to the next page and disables itself on the last page.      |
| `PaginationFirstTrigger`         | Moves to the first page and disables itself when already there.    |
| `PaginationLastTrigger`          | Moves to the last page and disables itself when already there.     |

## Composition

Use `defaultPage` and `defaultPageSize` for internal state, or pass `page`, `pageSize`, and the
matching change callbacks when another part of the application owns it. Set `count` to the total
number of data items, not the number of pages, and pair it with a page-size prop so Ark can calculate
`totalPages`.

Use `PaginationItems` for the standard page list. Use `PaginationContext` when page items or
nearby controls need custom rendering. If state must be created outside the rendered tree, create it
with `usePagination()` and pass it to `PaginationRootProvider`. For URL navigation, set
`type="link"`, provide `getPageUrl(details)`, and render semantic anchors with `asChild`.

In Vue, use `v-model:page` and `v-model:page-size` for controlled state. The `pageChange` and
`pageSizeChange` events are exposed as `@page-change` and `@page-size-change`.

## Styling

moduix keeps Ark's state attributes and adds stable `data-slot` hooks for local styling. Page items
use tabular figures and compact inline padding. One- and two-digit labels keep the default square
footprint, while longer labels can expand without being clipped.

Colors, borders, radius, and typography come from foundation tokens. Override them with `className` in
React or `class` in Solid and Vue on the part; target `[data-selected]` on `PaginationItem` to restyle the
current page. The CSS variable below sets the shared size of items, ellipses, and triggers in the CSS
Modules variants.

### Styling hooks

- `data-scope="pagination"` and `data-part="item"` on `PaginationItem`
- `data-scope="pagination"` and `data-part="prev-trigger"` on `PaginationPrevTrigger`
- `data-scope="pagination"` and `data-part="next-trigger"` on `PaginationNextTrigger`
- `data-scope="pagination"` with `data-part="first-trigger"` or `data-part="last-trigger"` on edge triggers
- `data-selected` on the active page item
- `data-disabled` on unavailable triggers
- `data-slot="pagination-root"`, `pagination-root-provider`, `pagination-item`,
  `pagination-ellipsis`, `pagination-prev-trigger`, `pagination-next-trigger`,
  `pagination-first-trigger`, and `pagination-last-trigger` for moduix overrides
