## Usage

<Usage />

Use `Pagination` as the root component. `PaginationItems` renders the page buttons and ellipses for
the current page range.

## Examples

### Page range

Use `pagination.pageRange` to show which items are visible on the current page.

<Example name="pagination/page-range" />

### Items per page

Call `pagination.setPageSize(nextSize)` from context when a separate control changes the number of
items per page.

<Example name="pagination/page-size-control" />

### First and last page controls

Add `PaginationFirstTrigger` and `PaginationLastTrigger` when users need shortcuts to the first
and last page.

<Example name="pagination/with-edges" />

### Link navigation

Use `type="link"` with `getPageUrl(details)` and `asChild` anchors when changing pages should
navigate to a real URL.

<Example name="pagination/link" />

### Client-side data

Use `pagination.slice(data)` from context to render only the part of an already-loaded array that
belongs to the current page.

<Example name="pagination/data-slicing" />

### Translations

Use `translations` to customize accessible labels. Adjust the visible page window with
`siblingCount`, `boundaryCount`, and the page-size props.

<Example name="pagination/customized" />

### Controlled

Pass the active page with `page` and update it in `onPageChange(details)`. See [Control state from the application](/docs/composition-patterns#controlled-state).

<Example name="pagination/controlled" />

### Context

Use `PaginationContext` to place custom controls next to the page list and call helpers such as
`goToFirstPage()` and `goToLastPage()`.

<Example name="pagination/context" />

### Root provider

Create state with `usePagination()` and pass it to `PaginationRootProvider` when the

<Example name="pagination/root-provider" />

### Build from parts

The same pagination as Basic, without `PaginationItems`: `PaginationContext` provides the pages, and
each entry renders a `PaginationItem` or a `PaginationEllipsis` with an explicit icon. Pass each page
object to `PaginationItem` unchanged so Ark keeps its state and accessibility behavior. The previous
and next triggers keep their default chevrons: passing children turns them into text buttons.

## Composition

Use `defaultPage` and `defaultPageSize` for internal state, or pass `page`, `pageSize`, and the
matching change callbacks when another part of the application controls it. Set `count` to the total
number of data items, not the number of pages, and pair it with a page-size prop so Ark can calculate
`totalPages`.

Use `PaginationItems` for the standard page list. Use `PaginationContext` when page items or
nearby controls need custom rendering. If state must be created outside the rendered tree, create it
with `usePagination()` and pass it to `PaginationRootProvider`. For URL navigation, set
`type="link"`, provide `getPageUrl(details)`, and render semantic anchors with `asChild`.

In Vue, use `v-model:page` and `v-model:page-size` for controlled state. The `pageChange` and
`pageSizeChange` events are exposed as `@page-change` and `@page-size-change`.

## Styling

moduix keeps Ark's state attributes and adds stable `data-slot` hooks for local styling. Page items
use tabular figures and compact inline padding. One- and two-digit labels keep the default square
footprint, while longer labels can expand without being clipped.

Colors, borders, radius, and typography come from foundation tokens. Override them with `className` in
React or `class` in Solid and Vue on the part; target `[data-selected]` on `PaginationItem` to restyle the
current page. The CSS variable below sets the shared size of items, ellipses, and triggers in the CSS
Modules variants.

- `data-selected` on the active page item
- `data-disabled` on unavailable triggers

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `count` | `number` | — | Total number of items, not pages. |
| `page` | `number` | — | Current page for controlled use. |
| `defaultPage` | `number` | `1` | Initial page. |
| `onPageChange` | `(details: PageChangeDetails) => void` | — | Called when the page changes. |
| `pageSize` | `number` | — | Items per page for controlled use. |
| `defaultPageSize` | `number` | `10` | Initial items per page. |
| `onPageSizeChange` | `(details: PageSizeChangeDetails) => void` | — | Called when the page size changes. |
| `siblingCount` | `number` | `1` | Pages shown on each side of the current page. |
| `boundaryCount` | `number` | `1` | Pages always shown at the start and end. |
| `type` | `'button' \| 'link'` | `'button'` | Renders page items as `button` or `link`. |
| `getPageUrl` | `(details: PageUrlDetails) => string` | — | Builds the `href` of each page when `type` is `link`. |
| `translations` | `IntlTranslations` | — | Localized strings for accessibility labels. |
