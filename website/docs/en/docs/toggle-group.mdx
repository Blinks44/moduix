## Usage

<Usage />

Use `ToggleGroup` as the root and add one `ToggleGroupItem` for each choice. Give the group an
accessible name with `aria-label` or `aria-labelledby`.

## Choosing the right component

Use `ToggleGroup` when related toggle buttons should work as one keyboard-navigable control. A group
can allow one selected value or several selected values.

- Choose **`ToggleGroup`** for segmented controls, compact filter sets, and formatting toolbars.
- Choose **`Toggle`** for one standalone two-state action.
- Choose **`Tabs`** when selecting an item should also show its associated panel.
- Choose **`RadioGroup`** when the choices are form options and need native form integration.

## Composition

`ToggleGroup` wraps Ark UI's Toggle Group primitive and adds moduix visual props for variants and
sizes. Import it from the matching framework package: `@moduix/react/toggle-group`,
`@moduix/solid/toggle-group`, `@moduix/react-tailwind/toggle-group`, or
`@moduix/solid-tailwind/toggle-group`. Vue packages are `@moduix/vue/toggle-group` and `@moduix/vue-tailwind/toggle-group`; Svelte packages are `@moduix/svelte/toggle-group` and `@moduix/svelte-tailwind/toggle-group`.

Use `defaultValue` for an uncontrolled group, or pass `value` with `onValueChange(details)` when
another part of the application controls the selection in React and Solid. In Vue, use `v-model` and
listen to `@value-change` for Ark details; inside script, read the store through `.value`. In Svelte, use `bind:value` and the `onValueChange` callback; the hook returns a getter, so read `toggleGroup().value`. Selected
values are `string[]` in single and
multiple-selection modes. Use `ToggleGroupRootProvider` with `useToggleGroup()` from the matching
framework package when state must be created outside the rendered tree. React reads the store as an
object, Solid reads its reactive state through the returned accessor, Vue exposes the reactive store directly to the template, and Svelte returns a getter.

Use `ToggleGroupContext` or `useToggleGroupContext()` when a custom item needs the current group
state. With `asChild`, React receives one button-like child, Solid receives a render function
that returns the element hosting the Ark behavior, Vue receives one element child, and Svelte receives an `asChild` snippet that spreads `props()` onto the element. Do not render `ToggleGroup` and
`ToggleGroupRootProvider` for the same state instance.

## Styling

Use `className` in React or `class` in Solid, Vue, and Svelte on exported parts for structural styles. Tailwind
variants use native utilities and consumer classes; CSS Modules variants expose the
`--moduix-toggle-group-*` tokens. Items inherit `variant` and `size` from the root, and can override
either prop when one item needs different treatment.

## Keyboard

| Key | Action |
| --- | --- |
| `ArrowLeft` / `ArrowRight` | Moves focus between items; ArrowUp and ArrowDown when vertical. |
| `Home` / `End` | Moves focus to the first or last item. |
| `Enter` / `Space` | Presses or releases the focused item. |

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string[]` | — | Pressed items for controlled use. |
| `defaultValue` | `string[]` | — | Initially pressed items. |
| `onValueChange` | `(details: ValueChangeDetails) => void` | — | Called when the pressed items change. |
| `multiple` | `boolean` | `false` | Lets several items be pressed at once. |
| `deselectable` | `boolean` | `true` | Lets the user unpress the last item. |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Layout and arrow-key direction: `horizontal` or `vertical`. |
| `loopFocus` | `boolean` | `true` | Keyboard navigation wraps from the last item to the first. |
| `rovingFocus` | `boolean` | `true` | Arrow keys move focus between items, Tab leaves the group. |
| `variant` | `'default' \| 'outline' \| 'ghost'` | `'default'` | Visual style of every item: `default`, `outline`, or `ghost`. |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'icon-sm' \| 'icon-md' \| 'icon-lg'` | `'md'` | `xs`, `sm`, `md`, `lg`, or a square `icon-sm`, `icon-md`, `icon-lg`. |
| `disabled` | `boolean` | `false` | Disables every item. |
