## API Reference

`ToggleGroup` wraps Ark UI's Toggle Group primitive and adds moduix visual props for variants and
sizes. Import it from the matching framework package: `@moduix/react/toggle-group`,
`@moduix/solid/toggle-group`, `@moduix/react-tailwind/toggle-group`, or
`@moduix/solid-tailwind/toggle-group`. Vue packages are `@moduix/vue/toggle-group` and
`@moduix/vue-tailwind/toggle-group`.

<PrimitiveReference href="https://ark-ui.com/docs/components/toggle-group" />

## Choosing the right component

Use `ToggleGroup` when related toggle buttons should work as one keyboard-navigable control. A group
can allow one selected value or several selected values.

- Choose **`ToggleGroup`** for segmented controls, compact filter sets, and formatting toolbars.
- Choose **`Toggle`** for one standalone two-state action.
- Choose **`Tabs`** when selecting an item should also show its associated panel.
- Choose **`RadioGroup`** when the choices are form options and need native form integration.

## Basic


Use `ToggleGroup` as the root and add one `ToggleGroupItem` for each choice. Give the group an
accessible name with `aria-label` or `aria-labelledby`.

## Anatomy

```text
ToggleGroup
├─ ToggleGroupContext (optional)
└─ ToggleGroupItem[value]

ToggleGroupRootProvider
└─ ToggleGroupItem[value]
```

| Part                    | Role                                                                                 |
| ----------------------- | ------------------------------------------------------------------------------------ |
| `ToggleGroup`           | Root part that owns selected values, focus movement, orientation, and disabled state. |
| `ToggleGroupItem`       | Interactive item with a required `value` and Ark selection state.                    |
| `ToggleGroupRootProvider` | Connects the item tree to state created with `useToggleGroup()`.                    |
| `ToggleGroupContext`    | Exposes the current group state through a render prop or Vue scoped slot.             |

## Composition

Use `defaultValue` for an uncontrolled group, or pass `value` with `onValueChange(details)` when
another part of the application owns the selection in React and Solid. In Vue, use `v-model` and
listen to `@value-change` for Ark details; inside script, read the store through `.value`. Selected
values are `string[]` in single and
multiple-selection modes. Use `ToggleGroupRootProvider` with `useToggleGroup()` from the matching
framework package when state must be created outside the rendered tree. React reads the store as an
object, Solid reads its reactive state through the returned accessor, and Vue exposes the reactive
store directly to the template.

Use `ToggleGroupContext` or `useToggleGroupContext()` when a custom item needs the current group
state. With `asChild`, React receives one button-like child, Solid receives a render function
that returns the element hosting the Ark behavior, and Vue receives one element child. Do not render `ToggleGroup` and
`ToggleGroupRootProvider` for the same state instance.

## Styling

Use `className` in React or `class` in Solid and Vue on exported parts for structural styles. Tailwind
variants use native utilities and consumer classes; CSS Modules variants expose the
`--moduix-toggle-group-*` tokens. Items inherit `variant` and `size` from the root, and can override
either prop when one item needs different treatment.

### CSS Properties

<CssPropertiesSection properties={ToggleGroupDocs.toggleGroupOverrideCssProperties} />

The table covers group-level properties. Each `ToggleGroupItem` also supports the [Toggle CSS
properties](/docs/toggle#css-properties) for its colors and interaction states. Set a
`--moduix-toggle-*` property on the root to theme every item, or on an item to override one control.

### Styling hooks

- Stable `data-slot` selectors: `toggle-group-root`, `toggle-group-root-provider`, and `toggle-group-item`.
- Ark part selectors: `data-scope="toggle-group"` and `data-part="root" | "item"`.
- Ark state selectors: `data-state="on" | "off"`, `data-disabled`, `data-focus`, and
  `data-orientation="horizontal" | "vertical"`.
- moduix selectors: `data-variant` and `data-size`.
