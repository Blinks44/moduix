## API Reference

`ToggleGroup` wraps Ark UI's Toggle Group primitive and adds moduix visual props for variants and
sizes. Import it from `@moduix/react/toggle-group`.

<PrimitiveReference href="https://ark-ui.com/docs/components/toggle-group" />

## Choosing the right component

Use `ToggleGroup` when related toggle buttons should work as one keyboard-navigable control. A group
can allow one selected value or several selected values.

- Choose **`ToggleGroup`** for segmented controls, compact filter sets, and formatting toolbars.
- Choose **`Toggle`** for one standalone two-state action.
- Choose **`Tabs`** when selecting an item should also show its associated panel.
- Choose **`RadioGroup`** when the choices are form options and need native form integration.

## Basic

Use `<ToggleGroup>` for the common case. It is shorthand for `<ToggleGroup.Root>`; add one

## Anatomy

```text
ToggleGroup / ToggleGroup.Root
├─ ToggleGroup.Context (optional)
└─ ToggleGroup.Item[value]

ToggleGroup.RootProvider
└─ ToggleGroup.Item[value]
```

| Part                               | Role                                                                                   |
| ---------------------------------- | -------------------------------------------------------------------------------------- |
| `ToggleGroup` / `ToggleGroup.Root` | Owns selected values, focus movement, orientation, and disabled state.                |
| `ToggleGroup.Item`                 | An interactive item with a required `value` and Ark selection state.                  |
| `ToggleGroup.RootProvider`         | Connects the item tree to a `useToggleGroup()` state instance created outside the tree. |
| `ToggleGroup.Context`              | Exposes the current group state through a render prop.                                 |

## Composition

### Recommended composition

`ToggleGroup` is the short form of `ToggleGroup.Root`. Use `defaultValue` for an uncontrolled group,
or pass `value` with `onValueChange` when React state should control the selection. Both `value` and
`defaultValue` are string arrays in single and multiple-selection modes.

moduix adds two visual props to `ToggleGroup`, `ToggleGroup.Root`, `ToggleGroup.RootProvider`, and
`ToggleGroup.Item`:

| Prop      | Default   | Values                                                  |
| --------- | --------- | ------------------------------------------------------- |
| `variant` | `default` | `default`, `outline`, `ghost`                           |
| `size`    | `md`      | `xs`, `sm`, `md`, `lg`, `icon-sm`, `icon-md`, `icon-lg` |

Items inherit `variant` and `size` from the root. Set either prop on an item only when that control
needs a different visual treatment.

### When to go custom

Use `asChild` on the root, `ToggleGroup.RootProvider`, or an item when another element should host
the rendered part. For an item, pass exactly one button-like child so Ark can merge its interaction
props and ARIA state into that element.

Use `ToggleGroup.RootProvider` with moduix `useToggleGroup()` when state must be created outside the
rendered tree. Use `useToggleGroupContext()` below a root or provider when a custom component needs
the current group state. Do not render `ToggleGroup.Root` and `ToggleGroup.RootProvider` for the
same state instance. Direct Ark imports are only needed for compositions outside the moduix API.

### Default props

| Prop           | Default      | Notes                                                           |
| -------------- | ------------ | --------------------------------------------------------------- |
| `deselectable` | `true`       | Allows selection to be cleared in single-selection mode.       |
| `loopFocus`    | `true`       | Wraps arrow-key focus from the last item to the first and back. |
| `orientation`  | `horizontal` | Sets the layout axis and matching keyboard navigation.         |
| `rovingFocus`  | `true`       | Keeps one item in the tab order while arrow keys move focus.   |
| `multiple`     | `false`      | Allows several items to stay pressed at the same time.         |
| `variant`      | `default`    | moduix visual treatment.                                        |
| `size`         | `md`         | moduix item size.                                               |

### Behavioral notes

- `onValueChange` receives Ark details. Read the selected string array from `details.value`.
- Use `value` together with `onValueChange` when the group is controlled by React state.
- `deselectable` is ignored when `multiple` is enabled.
- Give the group an accessible name with `aria-label` or `aria-labelledby`.
- Icon-only items need their own accessible name, such as `aria-label="Align left"`.
- Use `disabled` on the group for the whole set or on one item for a single unavailable choice.
- Use `ids` to provide stable root and item IDs when composing the group with other accessible UI.
- Single-selection groups use `radiogroup` and `radio` semantics. Multiple-selection groups use
  `group` and `aria-pressed`.
- Horizontal groups use Left/Right arrows, vertical groups use Up/Down, and Home/End move focus to
  the first or last enabled item. Space and Enter activate the focused button, while `loopFocus`
  controls whether arrow navigation wraps.
- Refs are forwarded to the rendered root and item elements. With `asChild`, the ref points to the
  child element that receives the Ark behavior.
- Ark writes `data-scope="toggle-group"`, `data-part`, `data-orientation`, `data-disabled`,
  `data-focus`, and item `data-state="on" | "off"` for styling.
- Horizontal groups scroll when they are wider than their container instead of wrapping and changing
  the arrow-key navigation layout.

## Styling

`ToggleGroup` exposes stable `data-slot` hooks for moduix and Ark anatomy and state attributes for
behavior-based styling.

The table covers group-level properties. Each `ToggleGroup.Item` also supports the [Toggle CSS
properties](/docs/toggle#css-properties) for its colors and interaction states. Set a
`--moduix-toggle-*` property on the root to theme every item, or on an item to override one control.

### Styling hooks

- `data-slot="toggle-group-root"` and `data-slot="toggle-group-root-provider"` are stable root selectors.
- `data-slot="toggle-group-item"` is the stable item selector.
- `data-scope="toggle-group"` and `data-part="root" | "item"` come from Ark.
- `data-state="on" | "off"` is written on each item.
- `data-orientation="horizontal" | "vertical"` is written on the root and item parts.
- `data-disabled` and `data-focus` are Ark state attributes.
- `data-variant` and `data-size` reflect the moduix visual props.
