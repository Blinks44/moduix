[Table of Contents](/docs/table-of-contents) helps readers navigate long articles. Pass the
headings you want to track, and it highlights the section in view while its links take readers
to the matching heading.

### Highlights

- Compose the article with `Toc.Content` and its navigation region with `Toc.Nav`; each tracked
  item maps to one stable heading ID.
- Add `Toc.Indicator` or `Toc.Rail` for visual hierarchy, and use `Toc.RootProvider` when controls
  outside the component need the same tracking state.
</ChangelogNewsItem>

<ChangelogNewsItem>
  <NavigationMenuHero />

[Navigation Menu](/docs/navigation-menu) gives product and site navigation a clear structure. Use
direct links for destinations, disclosure panels for related links, and a shared
`NavigationMenu.Viewport` when panels should transition through one surface.

### Highlights

- Use `NavigationMenu.Link` for direct destinations and a `Trigger` / `Content` pair for a group of
  related links.
- Ark manages keyboard interaction, focus, and the open value; `Viewport` and `Arrow` remain
  optional when several panels should share an animated surface.
</ChangelogNewsItem>

<ChangelogNewsItem>
  <ChartHero />

[Chart](/docs/chart) adds accessible data visualizations that you can compose around TanStack Charts.
Create line, area, bar, donut, scatter, and heatmap charts with moduix defaults for figures,
legends, tooltips, and motion while keeping TanStack’s configuration API.

### Highlights

- Keep marks, scales, interactions, and callbacks in a TanStack definition, then compose it with
  `Chart.Header`, `Chart.Plot`, and `Chart.Legend`.
- The default tooltip and motion preset respect keyboard navigation and reduced-motion preferences;
  pass `motion={false}` when the chart should render statically.
</ChangelogNewsItem>

<ChangelogNewsItem>
  <V2MigrationHero />

v2 is a major release with a new foundation for component behavior and accessibility. Components
with a dedicated primitive now use Ark UI, while moduix keeps its native CSS and both installation
paths.

### Highlights

- Ark UI primitives now provide state, interaction behavior, and accessibility for components with a
  dedicated primitive.
- Public composition and low-level props follow Ark contracts, while moduix retains its native CSS
  and supports both package installation and copy-owned source.
</ChangelogNewsItem>

## Version and support policy

moduix follows Semantic Versioning. Major releases may include breaking changes; minor releases add
backward-compatible features; patch releases contain backward-compatible fixes.

The latest major is actively supported. v2 supports React 18 and 19, and moduix keeps its Ark UI
integration aligned with current releases. For each major release, this page records affected APIs,
migration steps, and package or registry implications.
