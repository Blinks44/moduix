## More updates

### v2.2.4 - August 10, 2026

- `DatePicker` now inherits disabled and invalid state from `Field` and `Fieldset`, plus read-only and required state from `Field`.
- `DatePicker.Field` and `DatePicker.RangeField` keep stable input indexes, so native form values stay predictable.
- `DateInput` ranges automatically render indexed native inputs while preserving Ark keyboard and accessibility semantics.

### v2.2.3 - July 24, 2026

- Restored Next.js App Router compatibility for copy-owned components that use local client APIs.
- Refined the Menu arrow so it stays aligned with the popup border.

### v2.2.2 - July 24, 2026

### v2.2.1 - July 23, 2026

- Added a non-runtime Ark UI variable-reference stylesheet for repository tooling.

### v2.1.0 - July 21, 2026

- Refined primary controls, popup density, Select composition, and theming tokens.

## Version and support policy

moduix follows Semantic Versioning. Major releases may include breaking changes; minor releases add
backward-compatible features; patch releases contain backward-compatible fixes.

The latest major is actively supported. v2 supports React 18 and 19, and moduix keeps its Ark UI
integration aligned with current releases. For each major release, this page records affected APIs,
migration steps, and package or registry implications.
