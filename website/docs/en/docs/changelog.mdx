<ChangelogNewsItem>
  <TableOfContentsHero />

  [Table of Contents](/docs/table-of-contents) helps readers navigate long articles. Pass the
  headings you want to track, and it highlights the section in view while its links take readers
  to the matching heading.

  ### What’s included

  - `Toc.Content` for the article and `Toc.Nav` for its navigation region.
  - Active-section tracking, same-page links, optional `Toc.Indicator` and `Toc.Rail`, plus
    `Toc.RootProvider` for controls that need access to the same state.
</ChangelogNewsItem>

<ChangelogNewsItem>
  <NavigationMenuHero />

  [Navigation Menu](/docs/navigation-menu) gives product and site navigation a clear structure.
  Use direct links for destinations, disclosure panels for related links, and a shared
  `NavigationMenu.Viewport` when panels should transition through one surface.

  ### What’s included

  - Explicit `NavigationMenu.List`, `Item`, `Link`, `Trigger`, and `Content` composition.
  - Keyboard-friendly disclosure behavior, optional arrows and indicators, controlled state, and a
    shared viewport example.
</ChangelogNewsItem>

<ChangelogNewsItem>
  <ChartHero />

  [Chart](/docs/chart) adds accessible data visualizations that you can compose around TanStack
  Charts. Create line, area, bar, donut, scatter, and heatmap charts with moduix defaults for
  figures, legends, tooltips, and motion while keeping TanStack’s configuration API.

  ### What’s included

  - A semantic figure composition with `Chart.Header`, `Chart.Plot`, and `Chart.Legend`.
  - A compact default tooltip, keyboard navigation, visible focus styles, and motion that respects reduced-motion preferences.
</ChangelogNewsItem>

<ChangelogNewsItem>

  ### What’s included

  - Complete component documentation, setup guides, API references, and recipes in both languages.
  - Aligned navigation, page metadata, locale-aware routes, and copyable examples across English,

</ChangelogNewsItem>

<ChangelogNewsItem>
  <V2MigrationHero />

  v2 is a major release with a new foundation for component behavior and accessibility. Components
  with a dedicated primitive now use Ark UI, while moduix keeps its native CSS and both installation
  paths.

  ### What changed in v2

  - Built component behavior and accessibility on Ark UI primitives.
  - Aligned public composition, state access, and lower-level props with Ark contracts.
  - Kept native CSS and both installation paths: install the package or copy the source into your app.
</ChangelogNewsItem>

## More updates

- Added `Table of Contents` for accessible active-section tracking and same-page links.
- Added a resizable, collapsible `Sidebar` for application navigation.

- Added `JSON Tree View` for displaying nested JSON data.

- Added `Chart`, based on TanStack Charts, with moduix composition and styling defaults.

## Version and support policy

moduix follows Semantic Versioning. Major releases may include breaking changes; minor releases add
backward-compatible features; patch releases contain backward-compatible fixes.

The latest major is actively supported. v2 supports React 18 and 19, and moduix keeps its Ark UI
integration aligned with current releases. For each major release, this page records affected APIs,
migration steps, and package or registry implications.
