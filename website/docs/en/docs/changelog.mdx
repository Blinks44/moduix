[Table of Contents](/docs/table-of-contents) keeps document navigation in sync with the section in
view. Pass the headings you want to track: the component highlights the active entry and links
each item to its matching heading.

### Highlights

- Build the reading area with `Toc.Content` and the navigation with `Toc.Nav`. Each tracked item
  points to one stable heading ID.
- Use `Toc.Indicator` or `Toc.Rail` to show hierarchy. Add `Toc.RootProvider` only when controls
  outside the table of contents need to share its tracking state.
</ChangelogNewsItem>

<ChangelogNewsItem>
  <NavigationMenuHero />

[Navigation Menu](/docs/navigation-menu) gives top-level product or site navigation a clear
structure. Use direct links for destinations and disclosure panels when a destination has related
links.

### Highlights

- Use `NavigationMenu.Link` for direct destinations and a `NavigationMenu.Trigger` /
  `NavigationMenu.Content` pair for a group of related links.
- Add `NavigationMenu.Viewport` when several panels should animate inside one shared surface.
  Ark UI manages keyboard interaction, focus, and the open value; `Arrow` is optional.
</ChangelogNewsItem>

<ChangelogNewsItem>
  <ChartHero />

[Chart](/docs/chart) adds an accessible `figure` around TanStack Charts. Define the chart with
TanStack, then use moduix for the figure header, legend, compact tooltip, and motion defaults.
The TanStack configuration API remains unchanged.

### Highlights

- Keep marks, scales, interactions, and callbacks in a TanStack definition, then compose it with
  `Chart.Header`, `Chart.Plot`, and `Chart.Legend`.
- TanStack continues to own keyboard navigation and the tooltip lifecycle. The moduix motion preset
  respects reduced-motion preferences; pass `motion={false}` for a static chart.
</ChangelogNewsItem>

<ChangelogNewsItem>
  <V2MigrationHero />

v2 is a major release. Components with a matching Ark UI primitive now use Ark UI for state,
interaction, and accessibility, while moduix keeps its CSS Modules, design tokens, and both
installation paths.

### Highlights

- Ark UI provides state, interaction behavior, and accessibility for components with a matching
  primitive.
- Public composition and low-level props follow Ark contracts. You can install the package or copy
  component source into your application, where you control it.
</ChangelogNewsItem>

## Version and support policy

moduix follows Semantic Versioning. Major releases may include breaking changes, minor releases add
backward-compatible features, and patch releases contain backward-compatible fixes.

The latest major release is actively supported. v2 supports React 18 and 19, and its Ark UI
integration stays compatible with supported releases. For each major release, this page records
affected APIs, migration steps, and package or registry implications.
