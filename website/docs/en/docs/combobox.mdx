## Choosing the right component

Use `Combobox` when users select from known values and typing helps filter the available options.
Use `Select` when the same predefined choice does not need an editable input.

## Basic

Combobox ships for React and Solid in both the CSS Modules and Tailwind packages. The rendered preview
on this page uses the React CSS Modules package; the framework tabs show native source for the same
public contract.

Create an Ark collection with `useListCollection`, pass it to `Combobox`, and keep the popup structure
explicit. Use `Combobox.Option` for ordinary rows; use `Combobox.Item` when a row needs custom structure.
`onInputValueChange` receives an Ark details object.

## Anatomy

```text
Combobox / Combobox.Root[collection]
├─ Combobox.Label
├─ Combobox.Control
│  ├─ Combobox.Input
│  ├─ Combobox.ClearTrigger
│  └─ Combobox.Trigger
└─ Overlay subtree (automatically portalled)
 └─ Combobox.Positioner
    └─ Combobox.Content
       ├─ Combobox.Empty
       ├─ Combobox.Status
       ├─ Combobox.List
       │  ├─ Combobox.Option[item]
       │  └─ Combobox.Item[item]
       │     ├─ Combobox.ItemText
       │     └─ Combobox.ItemIndicator
       └─ Combobox.ItemGroup
          ├─ Combobox.ItemGroupLabel
          └─ Combobox.Item
```

| Part                         | Role                                                               |
| ---------------------------- | ------------------------------------------------------------------ |
| `Combobox` / `Combobox.Root` | Owns combobox state, filtering, highlighting, and selected values. |
| `Combobox.Control`           | Wrapper for input and trigger controls.                            |
| `Combobox.Input`             | Text input that drives search and selection.                       |
| `Combobox.Trigger`           | Opens and closes the popup list.                                   |
| `Combobox.ClearTrigger`      | Clears current value and/or input.                                 |
| `Combobox.Positioner`        | Floating positioner for popup content.                             |
| `Combobox.Content`           | Popup content container.                                           |
| `Combobox.Status`            | Styled consumer-owned loading, error, or guidance message.         |
| `Combobox.List`              | Option list wrapper.                                               |
| `Combobox.Option`            | Convenience row for simple options with text and an indicator.     |
| `Combobox.Item`              | Selectable option row.                                             |
| `Combobox.ItemText`          | Text label slot inside an item.                                    |
| `Combobox.ItemIndicator`     | Selected/highlight indicator slot for an item.                     |
| `Combobox.Context`           | Renderless access to the current combobox state.                   |
| `Combobox.ItemContext`       | Renderless access to the current item state.                       |

`Combobox.RootProvider` renders the same styled root for state created with moduix's `useCombobox`.
Read combobox state inside the tree with `Combobox.Context` or `useComboboxContext`; use
`Combobox.ItemContext` or `useComboboxItemContext` for item state.

## Composition

Use `createListCollection` for static items and `useListCollection` when filtering or other updates
change the collection. For object items, provide `itemToString` and `itemToValue`.

The root portals `Positioner` automatically, but `Positioner` and `Content` stay explicit in the
composition. Set `portalled={false}` to keep the popup in the current tree, or pass `portalRef` for
a specific container. Use `Combobox.Option` for simple rows and `Combobox.Item` with `asChild` for
custom rows.

Keep selection in `value` when other UI needs it. When state is created outside the rendered tree,
pass `useCombobox` to `Combobox.RootProvider`. In multiple mode, tags and other value summaries are
application-owned; compose with `TagsInput` when they should share one field. `Combobox.Status` is
also an application-owned message container and does not manage loading or error state.

## Styling

Use `className` in React or `class` in Solid on exported parts for structural styles. Tailwind
variants use native utilities and consumer classes; the CSS variables below customize CSS Modules
variants. Data attributes and `data-slot` hooks are shared by both styling tracks.

### Styling hooks

- Ark parts keep `data-scope="combobox"` and their `data-part` values. moduix adds stable `data-slot`
  hooks to the styled parts.
- Stable slots include `combobox-root`, `combobox-root-provider`, `combobox-label`, `combobox-control`,
  `combobox-input`, `combobox-clear-trigger`, `combobox-trigger`, `combobox-positioner`,
  `combobox-content`, `combobox-empty`, `combobox-status`, `combobox-list`, `combobox-item-group`,
  `combobox-item-group-label`, `combobox-item`, `combobox-item-text`, and `combobox-item-indicator`.
  `Combobox.Option` reuses the item slots instead of adding its own styling hook.
- Ark state hooks include `data-state="open|closed"`, `data-focus`, `data-invalid`,
  `data-disabled`, `data-highlighted`, `data-empty`, `data-placement`, and `data-side`.
- Ark positioning variables include `--reference-width`, `--available-width`,
  `--available-height`, `--transform-origin`, `--z-index`, and `--layer-index`. The shared theme
  registers neutral initial values for tooling and unpositioned content; Ark replaces them with
  measured values on `Positioner`.
