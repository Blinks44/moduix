## Usage

<Usage />

Create a toaster once with `createToaster()`, use its methods to add notifications, and render it
with `ToastToaster`.

## Composition

moduix exports `Toast`, `ToastToaster`, `createToaster`, and `useToastContext` from
`@moduix/react/toast`, `@moduix/solid/toast`, and `@moduix/vue/toast`. The Ark reference contains
the complete store and part API.

Create the toaster once and pass the same store to `ToastToaster`. In Vue, create it inside
`<script setup>` so each component instance creates its own store; an application-wide store can live in a
separate module. Keep server-rendered stores isolated per request. The store manages placement,
stacking, queue size, timing, and focus behavior. `ToastToaster`
portals the group to `document.body` by default; use `portalled={false}` or `portalRef` when it must
stay in another container. A separate `Portal` wrapper is not needed.

Use the default `ToastToaster` renderer for a title, description, action, and close button. For a different
layout or custom controls, pass a render prop in React/Solid or a default scoped slot in Vue, keep
`Toast` as the outer item, and compose its parts inside. The Vue slot receives the toast options;
`useToastContext()` returns a computed ref. Use a semantic button child with `asChild` on action
and close triggers, and use `useToastContext()`
when a custom child needs direct access to the current toast.

With `@ark-ui/vue@5.39.3`, `asChild` on `Toast` applies the root attributes to an internal ghost
element, and `ToastToaster` ignores `asChild`. Keep their default hosts until upstream fixes these
composition paths. Title, description, action, and close-trigger `asChild` composition is supported.

## Styling

Style `Toast` with Ark part attributes, `data-slot` hooks, and classes on its parts. The CSS Modules
variants also read the four variables below; `--moduix-toast-bg`, `--moduix-toast-border-color`, and
`--moduix-toast-color` override every type, so scope them with `[data-type='success']` and similar
selectors to theme one type. Tailwind variants use native utilities and consumer classes.

### Styling hooks

| Part | `data-slot` |
| --- | --- |
| `ToastToaster` | `toast-toaster` |
| `Toast` | `toast-root` |
| `ToastTitle` | `toast-title` |
| `ToastDescription` | `toast-description` |
| `ToastActionTrigger` | `toast-action-trigger` |
| `ToastCloseTrigger` | `toast-close-trigger` |

- Ark state selectors: `data-type`, `data-state="open|closed"`, `data-placement`, `data-paused`, `data-first`, and `data-overlap` on `Toast`.

Use the toast root for the surface, border, motion, and type-based variants. Use `ToastTitle`,
`ToastDescription`, `ToastActionTrigger`, and `ToastCloseTrigger` for inner typography and
controls.

Useful Ark selectors:

- `[data-scope='toast'][data-part='group']` on `ToastToaster`
- `[data-scope='toast'][data-part='root']` on `Toast`
- `[data-scope='toast'][data-part='title']` on `ToastTitle`
- `[data-scope='toast'][data-part='description']` on `ToastDescription`
- `[data-scope='toast'][data-part='action-trigger']` on `ToastActionTrigger`
- `[data-scope='toast'][data-part='close-trigger']` on `ToastCloseTrigger`
- `--x`, `--y`, `--scale`, `--z-index`, `--height`, `--opacity`, and `--gap` on `Toast`

At viewport widths up to `40rem`, every placement is centered horizontally. Toasts keep their
`20rem` width and shrink to fit between Ark's `offsets` and the horizontal safe-area insets.

## Keyboard

| Key | Action |
| --- | --- |
| `Alt+T` | Moves focus to the toast region. Change it with the hotkey option. |
| `Esc` | Dismisses the focused toast. |

## API reference

Options of `createToaster()`. Each `toaster.create()` call also takes `title`, `description`, `type`, `duration`, `action`, and `closable`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `placement` | `'top-start' \| 'top' \| 'top-end' \| 'bottom-start' \| 'bottom' \| 'bottom-end'` | `'bottom'` | Screen edge where toasts appear. |
| `max` | `number` | `24` | Maximum number of visible toasts. |
| `overlap` | `boolean` | `false` | Stacks toasts on top of each other until hovered. |
| `duration` | `number` | — | Default display time in milliseconds. |
| `gap` | `number` | `16` | Space between toasts in pixels. |
| `offsets` | `string \| Record<Side, string>` | — | Distance from the viewport edges. |
| `hotkey` | `string[]` | `['altKey', 'KeyT']` | Keys that move focus to the toast region. |
| `removeDelay` | `number` | `200` | Delay before a dismissed toast is removed, for its exit animation. |
| `pauseOnPageIdle` | `boolean` | `true` | Pauses timers while the page is hidden. |
