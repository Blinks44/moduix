## Basic

Pass the number of bytes to `value`. `Format.Byte` renders only the formatted text, so keep it next to a label or
another element that explains what the value represents. The examples use a paragraph for one value and a definition
list when several values need a shared context.

## Decimal and binary systems

Use `unitSystem="decimal"` for multiples of 1000 and `unitSystem="binary"` for multiples of 1024. Choose one
system deliberately when the product distinguishes advertised disk capacity from technical storage values.

## Options

| Prop | Values | Default | Purpose |
| --- | --- | --- | --- |
| `value` | `number` | required | Byte count to format. |
| `unit` | `'byte'` or `'bit'` | `'byte'` | Unit represented by `value`. |
| `unitDisplay` | `'short'`, `'narrow'`, or `'long'` | `'short'` | How the unit label is written. |
| `unitSystem` | `'decimal'` or `'binary'` | `'decimal'` | Base used to scale the value. |

The current public `FormatByteProps` type does not include `precision`, `locale`, or `sizes`. Use `LocaleProvider` for
locale changes and only the props listed above for component configuration.
