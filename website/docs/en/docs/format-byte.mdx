## When to use it

Use `Format.Byte` when you have a byte count but need to show a readable file size, such as an upload, download,
storage quota, or telemetry value. Pass the number of bytes in `value`; the formatter chooses an appropriate unit such
as kB, MB, or GB.

Import `Format` directly from Ark UI:

```tsx
import { Format } from '@ark-ui/react';
```

## Basic

`Format.Byte` returns formatted text without a label or layout. Place it next to a label or status that explains what
the value represents. The example keeps the file size close to the export it describes.

## Decimal and binary systems

Use `unitSystem="decimal"` when units are scaled in multiples of 1000, and `unitSystem="binary"` when they are scaled
in multiples of 1024. Make the choice explicit whenever a product distinguishes advertised disk capacity from
technical storage values.

## Locale and display options

`Format.Byte` reads its locale from the nearest `LocaleProvider`. Without a provider, Ark uses `en-US`. moduix
re-exports the provider from `@moduix/react/locale`, so you can place it around the localized part of your interface:

```tsx
import { Format } from '@ark-ui/react';
import { LocaleProvider } from '@moduix/react/locale';

export function LocalizedFileSize() {
  return (
    <LocaleProvider locale="fr-FR">
      <Format.Byte value={1_450.45} />
    </LocaleProvider>
  );
}
```

Use `unit="byte"` for a byte count, or `unit="bit"` when `value` is a bit count. `unitDisplay="narrow"`, `"short"`,
or `"long"` controls how the unit is written. `precision` sets the number of significant digits and defaults to 3.
`unitSystem` defaults to `decimal`, `unit` to `byte`, and `unitDisplay` to `short`. Unit labels follow the active
locale. Keep the same unit system, display style, and precision for related file sizes so they remain easy to compare.

## Using moduix

`Format.Byte` does not add a label, spacing, or other interface elements. Use moduix `Card`, `Stack`, `Text`, and status
components to explain what the size represents. If you only need formatted text, no additional moduix component is
required.

## Ownership

Ark UI owns byte formatting and the `Format.Byte` API. moduix supplies the surrounding interface components and
re-exports `LocaleProvider` from `@moduix/react/locale`, but does not re-export `Format.Byte`.
