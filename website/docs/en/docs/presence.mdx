## When to use it

Use `Presence` when you need explicit control over the mount lifecycle of application-owned content. It renders a root
`<div>` around the content and adds `data-state="open"` or `data-state="closed"` for styling.

Import it directly from Ark UI:

```tsx
import { Presence } from '@ark-ui/react/presence';
```

For Dialog, Drawer, Popover, Menu, Tooltip, Lightbox, Tour, and similar moduix roots, use their built-in presence
props. Use standalone `Presence` for application-owned content.

## Exit animations

`Presence` adds `data-state` to its root so CSS can react to `open` and `closed`. Use `onExitComplete` when other work
must wait for a root-level exit animation to finish.

```tsx
import { Presence } from '@ark-ui/react/presence';
import { Card } from '@moduix/react/card';

export function ActivityPanel({ open }: { open: boolean }) {
  return (
    <Presence className="activity-panel" present={open} unmountOnExit>
      <Card>Saved filters will apply to the next refresh.</Card>
    </Presence>
  );
}
```

```css
@keyframes activity-panel-enter {
  from {
    opacity: 0;
    transform: translateY(-0.25rem);
  }
}

@keyframes activity-panel-exit {
  to {
    opacity: 0;
    transform: translateY(-0.25rem);
  }
}

.activity-panel[data-state='open'] {
  animation: activity-panel-enter 160ms ease-out;
}

.activity-panel[data-state='closed'] {
  animation: activity-panel-exit 120ms ease-in;
}
```

## Hiding strategy

The default `hideMode="display-none"` uses the `hidden` attribute, so effects inside the subtree continue to run.
With React 19 or later, `hideMode="activity"` uses React’s `Activity` component instead; hidden effects pause.

Choose `lazyMount` and `unmountOnExit` when the subtree should not exist, not merely be invisible. Use `hideMode`
when it should stay mounted but needs a different effect lifecycle.

## Using moduix

Place any moduix interface inside `Presence`: cards, buttons, forms, and custom panels keep their regular styling.
The Ark root handles only visibility and lifecycle. Pass `className` to `Presence` when its container needs an
animation or layout rule.

## Ownership

Ark UI owns the `Presence` API, mounting strategy, and animation lifecycle. moduix supplies the surrounding
interface components and exposes equivalent presence props on its Ark-backed roots where that behavior already
belongs to the component.
