## API Reference

`RadioGroup` follows the Ark UI radio-group primitive and adds moduix styling, stable `data-slot`
attributes, and the `RadioGroupOption` convenience component. It is exported from
`@moduix/react/radio-group`, `@moduix/solid/radio-group`, and `@moduix/vue/radio-group`.

<PrimitiveReference href="https://ark-ui.com/docs/components/radio-group" />

## Choosing the right component

Use `RadioGroup` when people need to choose exactly one option from a visible set, such as a
framework, plan, or account type. Use `Checkbox` for independent choices and `Switch` for a setting
that takes effect immediately.

## Basic


Use `RadioGroup` as the root and give every option a value. `RadioGroupOption` renders a labelled
item with its control, text, and native input.

## Anatomy

```text
RadioGroup
├─ RadioGroupLabel
├─ RadioGroupIndicator (optional)
└─ RadioGroupItem[value]
   ├─ RadioGroupItemControl
   ├─ RadioGroupItemText
   └─ RadioGroupItemHiddenInput (explicit)

RadioGroupRootProvider
└─ the same item tree connected to useRadioGroup()

RadioGroupOption
└─ RadioGroupItem + RadioGroupItemControl + RadioGroupItemText + RadioGroupItemHiddenInput (fixed composition)
```

| Part                         | Role                                                            |
| ---------------------------- | --------------------------------------------------------------- |
| `RadioGroup`       | Owns value state, keyboard navigation, orientation, and forms. |
| `RadioGroupRootProvider`    | Connects parts to state created with `useRadioGroup()`.         |
| `RadioGroupLabel`           | Accessible label for the group.                                 |
| `RadioGroupItem`            | One selectable option; renders a `label` by default.            |
| `RadioGroupOption`          | Convenience item with a control, text, and hidden input.        |
| `RadioGroupItemControl`     | Visual radio control; its size comes from the root `size`.      |
| `RadioGroupItemText`        | Visible option text.                                             |
| `RadioGroupItemHiddenInput` | Native form control for explicit `RadioGroupItem` composition.             |
| `RadioGroupIndicator`       | Optional active-item indicator using Ark measurement variables.  |

## Composition

Use `defaultValue` for an uncontrolled group. Use `value` with `onValueChange(details)` when another
part of the application owns the selected value. When state must be created outside the rendered
tree, use `RadioGroupRootProvider` with `useRadioGroup()` from the matching framework package. Do not render
`RadioGroup` and `RadioGroupRootProvider` for the same state instance. React reads the store as an
object; Solid reads its reactive state through the returned accessor; Vue exposes the reactive store directly to the
template.

`RadioGroupOption` includes `RadioGroupItemHiddenInput` in its fixed composition. When composing
`RadioGroupItem` directly, add `RadioGroupItemHiddenInput` yourself. Use the explicit item tree
when nested parts need custom placement or when `asChild` should let another element own the item
DOM node. In Solid, `asChild` uses a render function; in Vue, use `as-child`. In both cases the
direct child must remain a semantic `label`.

`Field` provides a visible label, helper text, and error text, but it does not pass its state to
the group. Pass `disabled`, `invalid`, `readOnly`, and `required` to `RadioGroup` itself.
`Fieldset` passes its Ark `disabled` and `invalid` state to nested radio groups.

Set `defaultValue` when the initial checked item is known and the group should manage later changes

Use `RadioGroupRootProvider` when a `useRadioGroup()` store needs to be shared with controls outside the radio

### Sizes

Set the moduix `size` prop on `RadioGroup` or `RadioGroupRootProvider` to change the diameter of every radio
control in the group. Supported values are `xs`, `sm`, `md` (default), `lg`, and `xl`.

<Example name="radio-group/sizes" />

### With Field

Use `Field` when a radio group needs a field-level label, helper text, or error message. Pass

<Example name="radio-group/with-field" />

### With Fieldset

Wrap the group in `Fieldset` when several radio items share a legend and belong to the same form

<Example name="radio-group/with-fieldset" />

## Styling

Use `className` in React or `class` in Solid and Vue on exported parts for structural styles. For state-based
styles, prefer Ark data attributes such as `data-state`, `data-disabled`, and `data-orientation`,
together with moduix `data-slot` selectors. Tailwind variants use native utilities and consumer
classes; the component variables below customize the CSS Modules variants. Data attributes and
`data-slot` hooks are shared by both styling tracks.

### Styling hooks

- Ark anatomy hooks: `data-scope="radio-group"` and `data-part` on the root, label, item,
  item-control, item-text, item-hidden-input, and indicator.
- Ark state hooks: `data-state="checked|unchecked"`, `data-disabled`, `data-readonly`,
  `data-invalid`, `data-required`, `data-focus`, `data-focus-visible`, `data-hover`,
  `data-active`, and `data-orientation`.
- Ark indicator variables: `--transition-property`, `--left`, `--top`, `--width`, and `--height`.
- moduix hooks: `data-slot="radio-group-root"`, `radio-group-root-provider`,
  `radio-group-label`, `radio-group-item`, `radio-group-item-control`, `radio-group-item-text`,
  and `radio-group-indicator`, plus `data-size` on the root and `RadioGroupRootProvider`.
