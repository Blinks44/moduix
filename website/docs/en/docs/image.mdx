## API Reference

`Image` is a thin moduix wrapper around the `<img>` component from [Unpic React](https://unpic.pics/img/react/).
Ark UI does not provide a dedicated image primitive, so `Image` uses native `<img>` and `<picture>`
composition instead of an Ark part. See Ark's [Composition guide](https://ark-ui.com/docs/guides/composition)
for more on its native-element model.

## Basic

Use `Image` with a URL from a supported image CDN or any regular image URL. For the default
`layout="constrained"`, provide `width` and `height`. When Unpic recognizes the provider, it
generates responsive `srcset` and `sizes` attributes. Otherwise, it keeps the source URL unchanged.
The browser reserves space for the image before it loads.

## Anatomy

```text
Image / Image.Root
└─ img

picture (native)
├─ Image.Source
└─ Image / Image.Root
```

| Part                   | Role                                                                  |
| ---------------------- | --------------------------------------------------------------------- |
| `Image` / `Image.Root` | Responsive native `<img>` element; Unpic creates `srcset`, `sizes`, and styles. |
| `Image.Source`         | Responsive `<source>` for a native `<picture>` element.                     |

## Composition

### Recommended composition

`Image` is the short form of `Image.Root`. For `layout="constrained"` and `layout="fixed"`, provide
`width` and `height` so the browser can reserve space before loading. In the constrained layout,
these dimensions preserve the asset's aspect ratio and let the image shrink when its container is
narrower. For URLs from supported providers, Unpic detects the provider and generates transformed
`srcset` entries automatically.

Use `priority` only for images that must load immediately, such as the primary hero image visible
when the page opens. It enables eager loading and high fetch priority unless native `loading` or
React's camel-cased `fetchPriority` prop is set explicitly.

### When to go custom

Use native `<picture>` with `Image.Source` when you need art direction or different sources for
different media queries. Keep `Image` as the last child. It acts as the fallback image when the
browser does not select a `<source>`. Pass `fallback`, `options`, or `operations` when Unpic cannot
recognize a URL and needs a specific provider.

For format selection, put an `Image.Source` with a `type` before an equivalent source without `type`.
The browser uses the first format it supports.

### Default props

| Prop                    | Default                        | Notes                                                               |
| ----------------------- | ------------------------------ | ------------------------------------------------------------------- |
| `layout`                | `constrained`                  | Fits within the supplied dimensions and scales down if needed.     |
| `loading`               | `lazy`                         | Becomes `eager` when `priority` is set.                             |
| `decoding`              | `async` for non-priority images | A native value is preserved; omitted by default with `priority`.   |
| `fetchPriority`         | `high` with `priority`         | A native value overrides the priority default.                     |
| `objectFit`             | `cover`                        | Applied through Unpic's generated inline styles.                    |
| `--moduix-image-radius` | `var(--moduix-radius-md)`     | moduix's default visible radius.                                   |

### Behavioral notes

- `fixed` keeps the requested pixel dimensions and can overflow a narrower parent, while
  `fullWidth` fills its container width.
- For informative images, provide meaningful `alt` text. Use `alt=""` for decorative images; Unpic
  then applies `role="presentation"` unless you override the role.
- Use `aspectRatio` instead of `width` and `height` when you want to provide only the image's aspect
  ratio.
- Unpic generates `srcset` from the source URL. Use `breakpoints` when its standard responsive
  widths are not a good fit.
- Unpic detects supported image providers automatically. For other URLs, it keeps the source URL
  unchanged unless you provide a `fallback` provider.
- Native `loading`, `decoding`, and React's camel-cased `fetchPriority` remain available when the
  generated defaults do not match the image's loading needs.
- `background="auto"` creates a low-resolution background from supported providers. It remains
  after loading, so use it only for opaque images or provide an explicit background value instead.
- `unstyled` disables Unpic's generated inline layout styles; moduix's display, radius, and
  `data-slot` hooks remain available. Use it when art-directed sources need different responsive
  layout rules, then provide those rules in your own CSS.

### Styling hooks

- `data-slot="image-root"` targets the rendered `<img>` for styling.
- `data-slot="image-source"` targets the source node inside a native `<picture>`.
- `className` on `Image` is the recommended way to apply local styles. The root is block-level by default.
