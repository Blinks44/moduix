<PropChips
  items={[
    ['layout', 'constrained, fixed, or fullWidth.'],
    ['width / height', 'Intrinsic size; needed for constrained and fixed.'],
    ['priority', 'Loads eagerly for images above the fold.'],
  ]}
/>

Use `Image` with a URL from a supported image CDN or any regular image URL. For the default
`layout="constrained"`, provide `width` and `height`. When Unpic recognizes the provider, it
generates responsive `srcset` and `sizes` attributes. Otherwise, it keeps the source URL unchanged
but still applies the `layout` styles.
The browser reserves space for the image before it loads.

Images default to `loading="lazy"` and `decoding="async"`, including local files and URLs
without a supported CDN. Set `priority` for the main image in the initial viewport: it defaults
to `loading="eager"` and `fetchpriority="high"` without setting `decoding`. Explicit native
attributes override these defaults.

## Examples

### Art Direction

Use `ImageSource` to show a wider office view on larger screens and a portrait fallback on smaller
screens. The first large-screen source requests AVIF; the next source provides a fallback for
browsers that do not support AVIF. `ImageSource` must stay inside a native `<picture>` element.

### Fixed

Use `layout="fixed"` when the image must keep exact dimensions in CSS pixels. Make sure its parent
has enough room, since fixed images do not shrink to fit a narrower container.

### Full Width

Use `layout="fullWidth"` for a hero image or media strip that should fill its container's width.

## Composition

`Image` provides a thin moduix wrapper around the [Unpic image API](https://unpic.pics/img/).
Ark UI does not provide a dedicated image primitive, so `Image` uses native `<img>` and `<picture>`
composition instead of an Ark part. See Ark's [Composition guide](https://ark-ui.com/docs/guides/composition)
for more on its native-element model.

`Image` is the root and can be rendered directly. Use `ImageSource` only as a child of a native
`<picture>`, and keep `Image` last so it remains the fallback when no source is selected. For
format selection, place a typed source before an equivalent source without `type`; the browser
chooses the first format it supports.
`ImageSource` generates `srcset` only for a supported CDN or a `fallback` provider; for local files,
use a native `<source srcset>` instead.

## Styling

Use `className` in React or `class` in Solid and Vue on `Image` for local visual styles. `ImageSource`
configures `srcset`, `media`, and `type`; style the fallback `Image` rather than the native `<source>`.
Tailwind variants use native utilities and consumer classes. The `--moduix-image-radius` variable
customizes the CSS Modules variants, while `data-slot` hooks are shared by both styling tracks.

### Styling hooks

| Part | `data-slot` |
| --- | --- |
| `Image` | `image-root` |
| `ImageSource` | `image-source` |

- `data-slot="image-root"` targets the rendered `<img>` for styling.
- `data-slot="image-source"` targets the source node inside a native `<picture>`.
- `className` in React and `class` in Solid and Vue are the recommended ways to apply local styles.
