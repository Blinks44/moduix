## Basic

Use the standard composition for a menu opened by a button, custom trigger, or context trigger. The root manages
keyboard navigation, typeahead, focus, and dismissal. Give every item a stable `value` so selection and typeahead
continue to work when the list changes.

## Anatomy

```text
Menu / Menu.Root
├─ Menu.Trigger
│  ├─ Menu.TriggerIcon
│  └─ Menu.Indicator
├─ Menu.ContextTrigger
└─ Overlay subtree (automatically portalled)
   └─ Menu.Positioner
      └─ Menu.Content
         ├─ Menu.Arrow
         │  └─ Menu.ArrowTip
         ├─ Menu.Item
         │  ├─ Menu.ItemText
         │  │  ├─ Menu.ItemTextIcon
         │  │  └─ Menu.ItemTextLabel
         │  └─ Menu.ItemShortcut
         ├─ Menu.CheckboxItem
         │  └─ Menu.ItemIndicator
         ├─ Menu.RadioItemGroup
         │  └─ Menu.RadioItem
         ├─ Menu.ItemGroup
         │  └─ Menu.ItemGroupLabel
         ├─ Menu.Separator
         └─ Menu
            └─ Menu.TriggerItem
               └─ Menu.TriggerItemIcon
```

| Part | Role |
| --- | --- |
| `Menu` / `Menu.Root` | Root that manages open state, positioning, typeahead, focus, and dismissal. |
| `Menu.RootProvider` | Connects a menu to a state instance created with `useMenu`. |
| `Menu.Trigger` | Button that opens the menu. Use `asChild` to provide another semantic element. |
| `Menu.TriggerIcon` | Wrapper for a trigger icon. It renders the default chevron when no child is provided. |
| `Menu.Indicator` | State-aware trigger indicator, usually rendered as a chevron. |
| `Menu.ContextTrigger` | Trigger for right-click and long-press context menus. |
| `Menu.Positioner` | Positions the floating menu layer. |
| `Menu.Content` | Popup surface with the menu role and its item collection. |
| `Menu.Arrow` / `Menu.ArrowTip` | Optional visual anchor for the popup. |
| `Menu.Item` | Standard command item. |
| `Menu.CheckboxItem` | Item with an independent boolean state. |
| `Menu.RadioItemGroup` / `Menu.RadioItem` | Group and items for choosing one value. |
| `Menu.ItemIndicator` | Selection indicator for checkbox and radio items. |
| `Menu.ItemText` and text helpers | Helpers for composing item text with icons and labels. |
| `Menu.ItemShortcut` | Wrapper for a keyboard shortcut or other trailing hint. |
| `Menu.ItemGroup` / `Menu.ItemGroupLabel` | Group and label for related items. |
| `Menu.Separator` | Divider between groups of items. |
| `Menu.TriggerItem` / `Menu.TriggerItemIcon` | Item and icon for opening a nested menu. |
| `Menu.ItemContext` | Provides item state to content rendered inside an item. |

## Composition

`Menu` automatically portals `Menu.Positioner`. Set `portalled={false}` to render the menu in its current container,
or pass `portalRef` to use a specific portal container. `Menu.Positioner` and `Menu.Content` stay explicit, so you can
style and compose them independently.

### Recommended composition

Keep the popup structure visible in your code. `Menu.Content` is the Ark content part, while `Menu.Positioner` is the
separate positioning part.

```tsx
import { Button } from '@moduix/react/button';
import { Menu } from '@moduix/react/menu';

export function ActionsMenu() {
  return (
    <Menu positioning={{ placement: 'bottom-start', gutter: 8 }}>
      <Menu.Trigger asChild>
        <Button>
          Actions
          <Menu.Indicator />
        </Button>
      </Menu.Trigger>
      <Menu.Positioner>
        <Menu.Content>
          <Menu.Item value="edit">Edit</Menu.Item>
        </Menu.Content>
      </Menu.Positioner>
    </Menu>
  );
}
```

### When to go custom

Use `asChild` when a trigger, item, or content part should render as another semantic element. Pass exactly one
semantic child so Ark can merge its ARIA attributes, event handlers, and ref. For links, put `asChild` on `Menu.Item`
so the anchor itself receives menu behavior. For a custom popup host, put it on `Menu.Content`.

A nested menu is a regular `Menu` root inside the parent content. Give it a `Menu.TriggerItem`, followed by its own
`Menu.Positioner` and `Menu.Content`.

### Default props

Moduix mounts popup content on first open and removes it after the exit animation by default. Set
`unmountOnExit={false}` to keep the content mounted after it has opened once. Set both `lazyMount={false}` and
`unmountOnExit={false}` only when the content must be rendered immediately and stay mounted.

| Prop or surface | Default | Notes |
| --- | --- | --- |
| `lazyMount` | `true` | Defers mounting the popup until the first open. |
| `unmountOnExit` | `true` | Removes the popup after its exit animation. |
| `closeOnSelect` | `true` | Ark default. Set it to `false` when users should make several selections before closing the menu. |
| `loopFocus` | `false` | Ark default. Keyboard focus does not wrap from the last item to the first. |
| `typeahead` | `true` | Ark default. Printable characters move the highlight to a matching item. |
| `Menu.CheckboxItem` / `Menu.RadioItem` `indicator` | `start` | Moduix-only prop that controls the indicator column. Use `end` or `none` when needed. |

### Behavioral notes

- Control the menu with `open`, `defaultOpen`, and `onOpenChange(details)`. The callback receives Ark's detail object.
- Use `value` for item identity. Use `valueText` when the text shown in an item should differ from the string used by typeahead. Do not assign arbitrary `id` values to items because Ark generates and uses those IDs internally.
- Use `highlightedValue` and `onHighlightChange(details)` to control or observe the highlighted item. Use `present` only when the mounted content needs an externally controlled lifecycle.
- `onSelect(details)` on the root runs for every selected item. Item-level `onSelect` handlers are also available.
- `Menu.CheckboxItem.onCheckedChange` receives the next boolean checked state.
- `Menu.RadioItemGroup.onValueChange` receives a detail object; read the selected value from `details.value`.
- For multiple triggers, use `triggerValue`, `defaultTriggerValue`, and `onTriggerValueChange(details)` when the active trigger needs to be controlled or observed.
- Use `Menu.RootProvider` with a `useMenu` instance when code outside the rendered tree needs the menu API. Do not
  render a second root for the same state instance.
- `Menu.Context`, `useMenuContext`, `Menu.ItemContext`, and `useMenuItemContext` expose state for advanced composition.
- The root portals `Menu.Positioner` automatically. Use `portalled={false}` inside a dialog or scroll container. When
  that container scrolls, add `positioning={{ strategy: 'fixed', hideWhenDetached: true }}`.
- `Menu.ContextTrigger` opens on right-click and on a long press of roughly 700 ms for touch and pen input.
- Open and close animations respect `prefers-reduced-motion`.
- Moduix adds `tone="destructive"` for destructive actions and helper components such as `Menu.TriggerIcon`,
  `Menu.TriggerItemIcon`, `Menu.ItemTextContent`, `Menu.ItemTextIcon`, `Menu.ItemTextLabel`, and `Menu.ItemShortcut`.

Use Ark state attributes to style the menu and its items:

- Ark attributes: `[data-scope='menu']`, `[data-part='trigger']`, `[data-part='indicator']`,
  `[data-part='content']`, `[data-part='item']`, `[data-type='checkbox' | 'radio']`,
  `[data-state='open' | 'closed' | 'checked' | 'unchecked']`, `[data-current]`, `[data-highlighted]`,
  `[data-disabled]`, `[data-placement]`, and `[data-side]`.
- Moduix attributes: `[data-slot='menu-trigger']`, `[data-slot='menu-trigger-icon']`,
  `[data-slot='menu-indicator']`, `[data-slot='menu-context-trigger']`, `[data-slot='menu-positioner']`,
  `[data-slot='menu-content']`, `[data-slot='menu-arrow']`, `[data-slot='menu-arrow-tip']`,
  `[data-slot='menu-item']`, `[data-slot='menu-trigger-item']`, `[data-slot='menu-trigger-item-icon']`,
  `[data-slot='menu-separator']`, `[data-slot='menu-item-group']`, `[data-slot='menu-item-group-label']`,

  and `[data-indicator-position='start' | 'end' | 'none']`.
- Positioning variables: `--reference-width`, `--available-width`, `--available-height`, `--transform-origin`,
  `--layer-index`, `--arrow-size`, and `--arrow-background`.
