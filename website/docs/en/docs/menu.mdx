## Choosing the right component

Use `Menu` for contextual actions in a transient popup, such as commands, links, or a context
menu. Use `NavigationMenu` for persistent site or product navigation, and `Dialog` for workflows
that need the user's full attention.

## Basic


Use `Menu` as the root and give every `MenuItem` a stable `value`. Keep `MenuPositioner` and
`MenuContent` explicit, then place items, groups, separators, or nested menus inside the content.
`MenuIndicator` is optional and defaults to the moduix chevron.

Do not set a custom `id` on `MenuItem`: Ark identifies items by `value`, and an extra `id` breaks
its item lookup, typeahead, and focus management.

## Anatomy

```text
Menu
├─ MenuTrigger
│  └─ MenuIndicator
├─ MenuContextTrigger
└─ Overlay subtree (automatically portalled)
   └─ MenuPositioner
      └─ MenuContent
         ├─ MenuArrow
         │  └─ MenuArrowTip
         └─ MenuViewport
            ├─ MenuItem
            │  ├─ MenuItemText
            │  │  ├─ MenuItemTextIcon
            │  │  └─ MenuItemTextLabel
            │  └─ MenuItemShortcut
            ├─ MenuCheckboxItem
            │  └─ MenuItemIndicator
            ├─ MenuRadioItemGroup
            │  └─ MenuRadioItem
            ├─ MenuItemGroup
            │  └─ MenuItemGroupLabel
            ├─ MenuSeparator
            └─ Menu
               └─ MenuTriggerItem
                  └─ MenuTriggerItemIcon
```

| Part | Role |
| --- | --- |
| `Menu` | Root that manages open state, positioning, typeahead, focus, and dismissal. |
| `MenuRootProvider` | Connects a menu to a state instance created with `useMenu`. |
| `MenuTrigger` | Button that opens the menu. It has no styles of its own; use `asChild` with `Button` or another semantic element. |
| `MenuIndicator` | State-aware trigger indicator, usually rendered as a chevron. |
| `MenuContextTrigger` | Unstyled area that opens the menu on right-click and long press. |
| `MenuPositioner` | Positions the floating menu layer. |
| `MenuContent` | Popup surface with the menu role and its item collection. |
| `MenuViewport` | Explicit scroll container around the item collection. |
| `MenuArrow` / `MenuArrowTip` | Optional visual anchor for the popup. |
| `MenuItem` | Standard command item. |
| `MenuCheckboxItem` | Item with an independent boolean state. |
| `MenuRadioItemGroup` / `MenuRadioItem` | Group and items for choosing one value. |
| `MenuItemIndicator` | Selection indicator for checkbox and radio items. |
| `MenuItemText` and text helpers | Helpers for composing item text with icons and labels. |
| `MenuItemShortcut` | Wrapper for a keyboard shortcut or other trailing hint. |
| `MenuItemGroup` / `MenuItemGroupLabel` | Group and label for related items. |
| `MenuSeparator` | Divider between groups of items. |
| `MenuTriggerItem` / `MenuTriggerItemIcon` | Item and icon for opening a nested menu. |
| `MenuItemContext` | Provides item state to content rendered inside an item. |

## Composition

Use `defaultOpen` for an uncontrolled menu. When another part of the application owns the open or
highlighted state, pass `open` or `highlightedValue` with the matching change handler. Use
`useMenu()` with `MenuRootProvider` when the state store must be created outside the rendered tree;
do not render a second `Menu` root for the same store.

`MenuPositioner`, `MenuContent`, and `MenuViewport` are separate parts, but the positioner is portalled automatically.
Set `portalled={false}` inside a dialog or scroll container and use
`positioning={{ strategy: 'fixed', hideWhenDetached: true }}` when that container can scroll. Use
`asChild` with exactly one semantic child when a trigger, item, or content host must own the DOM node.
In Solid, assign a ref to the element created inside the `asChild` render function, because a ref on
a `Menu` part itself is not forwarded through that composition path.
A `MenuContent` must contain `MenuViewport` around its scrollable items. Keep an optional
`MenuArrow` directly under `MenuContent`, next to the viewport, so it is not clipped while items scroll.
A nested menu is another `Menu` root inside the parent content, paired with its own `TriggerItem`,
`Positioner`, and `Content`.

Use checkbox items for independent boolean options. Set `closeOnSelect={false}` when users should
change several options before closing the menu.

### Grouping

Use `MenuItemGroup` and `MenuItemGroupLabel` to organize related items, and `MenuSeparator` to

### Indicator Placement

### Item Context

<Example name="menu/item-context" />

### Lazy Mounted Context Menu

By default, context-menu content mounts on first open and unmounts after the exit animation. Set
`unmountOnExit={false}` when the subtree must remain mounted after the menu closes.

<Example name="menu/lazy-mounted-context-menu" />

### Links

Use `MenuItem asChild` and make the anchor the item itself. This lets the link receive the menu
item's ARIA attributes, keyboard behavior, and focus handling.

### Menu in Dialog

Set `portalled={false}` to keep the popup inside a dialog or scroll container. When the container can
scroll, use fixed positioning with `hideWhenDetached` so the menu is hidden after it leaves the
visible area.

<Example name="menu/menu-in-dialog" />

### Multiple Triggers

Share one menu across several triggers by giving each `MenuTrigger` a distinct `value`. The menu
repositions itself relative to the trigger that opened it.

### Nested

### Radio Items

## Styling

Style Menu through `className` in React or `class` in Solid and Vue on exported parts. Tailwind
variants use native utilities and consumer classes. CSS Modules variants take colors, spacing, and
typography from foundation tokens and expose only the content width limits and the viewport maximum
height as CSS variables; override other styles with a class on the part. Items, group labels,
separators, the list padding, and the popup motion also follow the shared `--moduix-popup-*`
variables. `MenuTrigger` and `MenuContextTrigger` are unstyled, so compose the trigger with
`asChild` and `Button`, or style the context area yourself. Data attributes and `data-slot` hooks
are shared by both styling tracks.
