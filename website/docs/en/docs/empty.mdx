## API Reference

Ark UI does not include a dedicated empty-state primitive. `moduix` builds `Empty` with the official
[Ark factory](https://ark-ui.com/react/docs/guides/composition#the-ark-factory) and follows Ark's
guidance for [composition](https://ark-ui.com/react/docs/guides/composition), [styling](https://ark-ui.com/react/docs/guides/styling), and
[refs](https://ark-ui.com/react/docs/guides/ref). The explicit composition is informed by
[Chakra's Empty State](https://chakra-ui.com/docs/components/empty-state). Unlike Chakra, `moduix`
exposes optional `Empty.Icon` and `Empty.Actions` as siblings of the root so you can place them
where they make sense for your layout.

## Anatomy

```text
Empty
├─ Empty.Icon (optional)
├─ Empty.Content
│  ├─ Empty.Title
│  └─ Empty.Description
└─ Empty.Actions (optional)
```

| Part                   | Role                                                               |
| ---------------------- | ------------------------------------------------------------------ |
| `Empty` / `Empty.Root` | Root container that controls padding, border, background, and alignment. |
| `Empty.Icon`           | Optional container for an icon or small visual cue.                    |
| `Empty.Content`        | Groups the title and description with tighter spacing.                 |
| `Empty.Title`          | Main heading for the empty state.                                      |
| `Empty.Description`    | Supporting text block for one or more pieces of content.               |
| `Empty.Actions`        | Optional row for actions that can wrap onto multiple lines.            |

## Composition

### Recommended composition

For most empty states, use the exported parts:

- `Empty` for the container and centered layout
- `Empty.Content` for the text block
- `Empty.Title` for the heading
- `Empty.Description` for supporting copy
- `Empty.Icon` and `Empty.Actions` only when they add value

This keeps the common structure easy to read while leaving room for richer descriptions, links, or
custom buttons. You do not need a separate configuration API.

### When to go custom

`Empty` exposes its parts directly, so customization usually means changing the structure with
normal component composition:

- leave out `Empty.Icon` or `Empty.Actions`
- add richer markup inside `Empty.Description`
- change the surrounding landmark or heading level with `Empty asChild` and `Empty.Title asChild`
- apply `className` and `--moduix-empty-*` variables to the parts that control the visual property

### Default props

| Surface                | Default | Notes                                                  |
| ---------------------- | ------- | ------------------------------------------------------ |
| `Empty` / `Empty.Root` | -       | No component-specific behavior is added; Ark defaults apply. |

### Behavioral notes

- `Empty.Title` renders an `h3` by default. Use Ark factory `asChild` when you need a different
  heading level for the document outline.
- `Empty.Description` renders a `div` rather than a `p`, so it can safely contain block content.
- Every part forwards its ref to the rendered DOM element and accepts Ark factory `asChild` with a
  single semantic child.
- Every part adds `data-scope="empty"` and the matching `data-part` attribute for Ark-style
  styling, along with stable `data-slot="empty-*"` hooks for moduix overrides.
- `Empty.Actions` centers its children and lets them wrap when needed. This keeps paired actions and
  long button or link labels readable in narrow layouts.
- `Empty` only handles presentation. It does not add a landmark, `role`, or live-region behavior.
  Add those semantics when the surrounding screen needs them. Use `aria-hidden` for decorative
  icons and give meaningful icons an accessible name.

### Styling hooks

Target the part that controls the visual property you want to change:

- `[data-scope="empty"][data-part="root"]` / `data-slot="empty-root"` for container layout, border,
  background, and shadow overrides
- `[data-scope="empty"][data-part="icon"]` / `data-slot="empty-icon"` for icon container size,
  padding, and colors
- `[data-scope="empty"][data-part="content"]` / `data-slot="empty-content"` for text block width
  and spacing
- `[data-scope="empty"][data-part="title"]` and
  `[data-scope="empty"][data-part="description"]` for typography
- `[data-scope="empty"][data-part="actions"]` / `data-slot="empty-actions"` for action row spacing
  and alignment
