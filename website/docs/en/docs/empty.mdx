## API Reference

Ark UI does not include a dedicated empty-state primitive. `moduix` builds `Empty` with Ark's
official [factory](https://ark-ui.com/react/docs/guides/composition#the-ark-factory) and follows
Ark's guidance for [composition](https://ark-ui.com/react/docs/guides/composition),
[styling](https://ark-ui.com/react/docs/guides/styling), and
[refs](https://ark-ui.com/react/docs/guides/ref). Its composition also draws on Chakra UI's
[Empty State](https://chakra-ui.com/docs/components/empty-state). Unlike Chakra UI, `moduix`
exposes optional `Empty.Icon` and `Empty.Actions` as root-level parts alongside
`Empty.Content`, so you can arrange them in the order your screen needs.

## Anatomy

```text
Empty / Empty.Root
├─ Empty.Icon (optional)
├─ Empty.Content
│  ├─ Empty.Title
│  └─ Empty.Description
└─ Empty.Actions (optional)
```

| Part                   | Role                                                                                         |
| ---------------------- | -------------------------------------------------------------------------------------------- |
| `Empty` / `Empty.Root` | Root container for padding, border, background, and alignment.                               |
| `Empty.Icon`           | Optional container for an icon or another small visual cue.                                  |
| `Empty.Content`        | Groups the title and description with tighter spacing.                                       |
| `Empty.Title`          | Main heading for the empty state.                                                            |
| `Empty.Description`    | Supporting content below the title. It can contain paragraphs, links, or other block content. |
| `Empty.Actions`        | Optional action row that wraps its children when needed.                                     |

## Composition

### Recommended composition

Most empty states only need the exported parts:

- `Empty` for the container and centered layout
- `Empty.Content` for the text block
- `Empty.Title` for the heading
- `Empty.Description` for supporting content
- `Empty.Icon` and `Empty.Actions` when they add value

This keeps the common structure readable while leaving room for richer descriptions, links, and
custom buttons. Add or remove parts with normal JSX composition.

### When to go custom

Use normal JSX composition when the default structure needs to change:

- omit `Empty.Icon` or `Empty.Actions`
- add richer block content inside `Empty.Description`
- use the `asChild` prop on `Empty` or `Empty.Title` when the surrounding section needs a different
  semantic element or heading level
- apply `className` and `--moduix-empty-*` variables to the parts that control the visual property

### Default props

| Surface                | Default element | Notes                                                                    |
| ---------------------- | --------------- | ------------------------------------------------------------------------ |
| `Empty` / `Empty.Root` | `div`           | Presentational root with no built-in role or state.                      |
| `Empty.Title`          | `h3`            | Use `asChild` when the document outline needs a different heading level. |
| `Empty.Description`    | `div`           | Supports paragraphs, links, and other block content.                    |

### Behavioral notes

- Every part forwards its `ref` to the rendered DOM element and accepts Ark factory `asChild`.
  Pass exactly one semantic child that can receive the part's props and ref.
- Every part emits `data-scope="empty"` and its matching `data-part` attribute for Ark-style
  styling, along with a stable `data-slot="empty-*"` hook for moduix overrides.
- `Empty.Actions` centers its children and lets them wrap when needed, keeping paired actions and
  long button or link labels readable in narrow layouts.
- `Empty` only handles presentation. It does not add a landmark, role, `aria-live` behavior, or
  focus management. Add the semantics your surrounding screen needs. Mark decorative icons with
  `aria-hidden` and give meaningful icons an accessible name.

### Styling hooks

Target the part that controls the visual property you want to change:

- `[data-scope="empty"][data-part="root"]` or `[data-slot="empty-root"]` for container layout,
  border, background, and shadow overrides
- `[data-scope="empty"][data-part="icon"]` or `[data-slot="empty-icon"]` for icon container
  size, padding, and colors
- `[data-scope="empty"][data-part="content"]` or `[data-slot="empty-content"]` for text block
  width and spacing
- `[data-scope="empty"][data-part="title"]` or `[data-slot="empty-title"]`, and
  `[data-scope="empty"][data-part="description"]` or `[data-slot="empty-description"]` for
  typography
- `[data-scope="empty"][data-part="actions"]` or `[data-slot="empty-actions"]` for action row
  spacing and alignment
