## API Reference

Ark UI does not include a dedicated empty-state primitive. `moduix` builds `Empty` with Ark's
official [factory](https://ark-ui.com/react/docs/guides/composition#the-ark-factory) and follows
Ark's guidance for [composition](https://ark-ui.com/react/docs/guides/composition),
[styling](https://ark-ui.com/react/docs/guides/styling), and
[refs](https://ark-ui.com/react/docs/guides/ref). Its composition also draws on Chakra UI's
[Empty State](https://chakra-ui.com/docs/components/empty-state). Unlike Chakra UI, `moduix`
exposes optional `EmptyIcon` and `EmptyActions` as root-level parts alongside `EmptyContent`,
so you can arrange them in the order your screen needs.

## Anatomy

```text
Empty
├─ EmptyIcon (optional)
├─ EmptyContent
│  ├─ EmptyTitle
│  └─ EmptyDescription
└─ EmptyActions (optional)
```

| Part                   | Role                                                                                          |
| ---------------------- | --------------------------------------------------------------------------------------------- |
| `Empty`               | Root container for padding, border, background, and alignment.                                |
| `EmptyIcon`           | Optional container for an icon or another small visual cue.                                   |
| `EmptyContent`        | Groups the title and description with tighter spacing.                                        |
| `EmptyTitle`          | Main heading for the empty state.                                                             |
| `EmptyDescription`    | Supporting content below the title. It can contain paragraphs, links, or other block content. |
| `EmptyActions`        | Optional action row that wraps its children when needed.                                      |

## Composition

Compose `Empty` from its root-level parts. `EmptyContent` groups the title and description;
`EmptyIcon` and `EmptyActions` are optional siblings, so you can omit or reorder them to match
the screen. `Empty` is presentational and does not own application state or live-region behavior.

Use `asChild` on `Empty` or `EmptyTitle` when the surrounding section needs a semantic container or
a different heading level. Pass exactly one child to an `asChild` part so it can receive that part's
props and ref in React. In Solid, assign a ref inside the `asChild` render function. Then add any
required landmark, role, focus management, or `aria-live` behavior in the surrounding interface.

`data-slot="empty-*"` hooks, and the public `--moduix-empty-*` CSS variables shown below.

### Styling hooks

Target the part that controls the visual property you want to change:

- `[data-scope="empty"][data-part="root"]` or `[data-slot="empty-root"]` for container layout,
  border, background, and shadow overrides
- `[data-scope="empty"][data-part="icon"]` or `[data-slot="empty-icon"]` for icon container
  size, padding, and colors
- `[data-scope="empty"][data-part="content"]` or `[data-slot="empty-content"]` for text block
  width and spacing
- `[data-scope="empty"][data-part="title"]` or `[data-slot="empty-title"]`, and
  `[data-scope="empty"][data-part="description"]` or `[data-slot="empty-description"]` for
  typography
- `[data-scope="empty"][data-part="actions"]` or `[data-slot="empty-actions"]` for action row
  spacing and alignment
