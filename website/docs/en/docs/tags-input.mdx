Start with `TagsInput`, `TagsInputLabel`, `TagsInputControl`, `TagsInputItems`,
`TagsInputInput`, and `TagsInputClearTrigger`. Add an explicit `TagsInputHiddenInput` when the
tags should be submitted with a form.

## Choosing the right component

Use `TagsInput` when users need to enter and manage a list of editable string values in one form
control.

- Choose **`TagsInput`** for labels, skills, filters, recipients, topics, and other free-form string lists.
- Choose **`Tag`** when the interface only displays an existing token and may offer a separate remove action.
- Choose **`Combobox`** when users should select from a known collection and filtering is the main interaction.

## Composition

Use the short `<TagsInput>` form for the standard composition. Keep `TagsInputItems`,
`TagsInputInput`, and `TagsInputClearTrigger` inside `TagsInputControl`. Add
`TagsInputHiddenInput` explicitly and pass `name` to the root when the tags must be submitted with
a form. Use `form` when the associated form is outside the component tree.

For custom tag content or actions, use `TagsInputContext` and map its values to
`TagsInputItem` with `index` and `value`. Keep `TagsInputItemInput` inside each item when inline
editing should remain available. Use `TagsInputRootProvider` with `useTagsInput()` only when state
or methods such as `addValue`, `clearValue`, or `focus` must be used outside the component tree.
In Solid, the store is an accessor, so read `tagsInput().value` and call `tagsInput().addValue()`.
When combining `TagsInput` with `Combobox`, share the input and control IDs and compose the inputs
with `asChild`.

## Accessibility

Ark wires the label, tag highlighting, inline edit mode, deletion, paste handling, and hidden form
input. The explicit hidden input serializes the tag list for native form submission; pass `name` and,
when needed, `form` to associate it with a form.

### Keyboard support

- `Enter` in the entry input adds its current value. `Enter` on a highlighted tag enters edit mode.
- Double-clicking a tag also enters edit mode when `editable` is `true`.
- When the entry input is empty or the caret is at its start, `ArrowLeft` and `ArrowRight` move visual focus between tags.
- `Backspace` and `Delete` remove the highlighted tag. `Backspace` also removes the last tag when the entry input is empty.
- With `addOnPaste`, `Control+V` adds pasted values after splitting them with `delimiter`.

## Keyboard

| Key | Action |
| --- | --- |
| `Enter` | Adds the typed text as a tag. |
| `ArrowLeft` / `ArrowRight` | Moves between tags when the input is empty. |
| `Backspace` / `Delete` | Highlights and then removes a tag. |
| `Enter` on a tag | Edits the highlighted tag when editable is on. |
| `Ctrl+V` | Adds pasted values as tags when addOnPaste is on. |
