## API Reference

`Toggle` wraps Ark UI's Toggle primitive and adds moduix visual props for variants and sizes.
Import it from `@moduix/react/toggle` or `@moduix/solid/toggle`.

<PrimitiveReference href="https://ark-ui.com/docs/components/toggle" />

## Choosing the right component

Use `Toggle` when the control should behave like a button and expose whether it is pressed.

- Choose **`Toggle`** for favorites, saved items, formatting controls, and compact toolbar actions.
- Choose **`Switch`** for settings presented as on/off preference rows.
- Choose **`Checkbox`** for selections that are submitted with a list or form.
- Choose **`ToggleGroup`** when several toggles should share one selection model.

## Anatomy

```text
Toggle
└─ ToggleIndicator (optional)

ToggleContext (state reader, not a DOM part)
```

| Part | Role |
| ---- | ---- |
| `Toggle` | Root part that owns pressed state, focus, disabled state, and `asChild` composition. |
| `ToggleIndicator` | Optional part that renders pressed content and its `fallback` when the toggle is off. |
| `ToggleContext` | Reads the nearest toggle state for custom descendants; it does not render a DOM part. |

## Composition

Use `defaultPressed` for an uncontrolled toggle, or pass `pressed` with `onPressedChange` when
application state owns the value. Use `ToggleIndicator` when
the button content changes with its pressed state. For custom descendants that need the state, use
`ToggleContext` or `useToggleContext()` from the matching package. Use `asChild` when another button
should host the toggle behavior. In Solid, `asChild` takes a render function; in React, it takes one
button-like child.

## Styling

Use `className` in React or `class` in Solid on exported parts for structural styles. Tailwind
variants use native utilities and consumer classes; CSS Modules variants additionally expose the
`--moduix-toggle-*` tokens for variants, sizes, focus ring, spacing, and icon sizing.

### Styling hooks

- Stable `data-slot` selectors: `toggle-root` and `toggle-indicator`.
- Ark part selectors: `data-scope="toggle"` and `data-part="root" | "indicator"`.
- Ark state selectors: `data-state="on" | "off"`, `data-pressed`, and `data-disabled`.
- moduix selectors: `data-variant` and `data-size`, including `icon-sm`, `icon-md`, and `icon-lg`.
- Direct icon children and icons inside `ToggleIndicator` are sized through
  `--moduix-toggle-icon-size` on the CSS Modules path.
