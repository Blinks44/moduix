## API Reference

Ark UI does not provide a dedicated `container` primitive. moduix implements `Container` with Ark's official
[factory](https://ark-ui.com/docs/guides/composition#the-ark-factory), so it follows Ark's guidance for
[composition](https://ark-ui.com/docs/guides/composition), [styling](https://ark-ui.com/docs/guides/styling), and
[ref forwarding](https://ark-ui.com/docs/guides/ref).

## Basic

Import `Container` from `@moduix/react/container` when you need a centered content column with a readable width.
It adds responsive horizontal gutters and leaves vertical spacing to the surrounding layout.

## Anatomy

`Container` renders one root element and does not add an extra wrapper.

```text
Container / Container.Root
└─ children
```

| Part                           | Role                                                     |
| ------------------------------ | -------------------------------------------------------- |
| `Container` / `Container.Root` | Root layout element. Centers content and controls its width and horizontal padding. |

## Composition

### Recommended composition

Use `Container` for page shells, article bodies, documentation sections, settings screens, and any other layout
that needs a centered content column with predictable space at the edges.

`Container.Root` is the same component exposed through a namespace alias. Use it when that naming pattern is useful
for consistency with other Ark-style component APIs.

Set `size` to choose the content width and `gutter` to choose the horizontal padding. Use `asChild` to replace the
default `div` with exactly one child element. Choose a semantic element such as `main`, `section`, or `article` when
the wrapper should describe the document structure. The forwarded `ref` points to the rendered root, or to that child
when `asChild` is used.

All standard `<div>` props are forwarded, including `className` and `style`.

### When to go custom

`Container` has one root and no subcomponents, slots, or nested layout helpers.

Most custom layouts only need one of these options:

- pass `className` for local layout or surface styles;
- override `--moduix-container-*` variables when the page needs different width or gutter values;
- use `asChild` when another element should own the rendered DOM node;
- compose with `Bleed` when a child needs to extend beyond the constrained text column.

### Default props

| Prop      | Default | Values / Notes                       |
| --------- | ------- | ------------------------------------ |
| `size`    | `lg`    | `xs` (40rem), `sm` (48rem), `md` (64rem), `lg` (72rem), `xl` (90rem), `full` (uncapped) |
| `gutter`  | `md`    | `none`, `sm`, `md`, `lg`                                                                |
| `asChild` | `false` | Replaces the root `div` with one child element                                          |

### Behavioral notes

- `Container` does not manage vertical rhythm. Add section spacing outside it or on its children.
- `size="full"` removes only the max-width cap. The selected gutter still applies unless
  `gutter="none"` is used.
- The max-width calculation includes both horizontal gutters, so the constrained shell keeps its selected padding.
- With `asChild`, pass exactly one child element. The forwarded `ref` then points to that element.
- `Container` is presentational. It adds no ARIA roles, labels, focus management, or keyboard behavior. Use `asChild`
  with `main`, `section`, or `article` when the wrapper should carry semantic meaning.
- The root exposes `data-scope="container"`, `data-part="root"`, `data-slot="container-root"`, `data-size`, and
  `data-gutter` for styling and tests.

## Styling

Override the CSS variables on the root when a page shell needs different width or gutter values. Use `className` for
local block styles such as padding, borders, or backgrounds.

### Styling hooks

- `Container` and `Container.Root` expose `data-slot="container-root"` on the root.
- `data-scope="container"` and `data-part="root"` follow Ark's styling conventions.
- `data-size` selects the width preset: `xs`, `sm`, `md`, `lg`, `xl`, `full`.
- `data-gutter` selects the gutter preset: `none`, `sm`, `md`, `lg`.
- `--moduix-container-*` variables control horizontal gutters and max-width math only. Vertical spacing and child layout
  remain the responsibility of the surrounding CSS.
