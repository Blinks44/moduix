## API Reference

Ark UI does not provide a dedicated `container` primitive. moduix implements `Container` with Ark's official
[factory](https://ark-ui.com/docs/guides/composition#the-ark-factory), so it follows Ark's guidance for
[composition](https://ark-ui.com/docs/guides/composition), [styling](https://ark-ui.com/docs/guides/styling), and
[ref forwarding](https://ark-ui.com/docs/guides/ref).

## Basic


Import `Container` from the matching package: `@moduix/react/container`, `@moduix/solid/container`, or
`@moduix/vue/container` for CSS Modules, and `@moduix/react-tailwind/container`,
`@moduix/solid-tailwind/container`, or `@moduix/vue-tailwind/container` for Tailwind CSS.

Use `Container` for a centered content column with a readable width. It adds responsive horizontal gutters and leaves
vertical spacing to the surrounding layout.

## Anatomy

`Container` renders one root element and does not add an extra wrapper.

```text
Container
└─ children
```

| Part        | Role                                                     |
| ----------- | -------------------------------------------------------- |
| `Container` | Root layout element. Centers content and controls its width and horizontal padding. |

## Composition

`Container` has no managed state and no child parts to coordinate. Use it as the root and place the page or section
content directly inside it.

Use `asChild` when a semantic element should own the rendered root. Pass exactly one child: React and Vue render that
child as the Container root, while Solid uses the render-function form
`asChild={(props) => <main {...props()} />}`. In Solid, assign a ref to the element created inside that render
function, because a ref on `Container` itself is not forwarded through `asChild`; in Vue, read the rendered element
from the component ref's `$el`. Use `Bleed` inside `Container` when only one child needs to extend beyond the
constrained text column.

## Styling

For CSS Modules packages, override the CSS variables on the root when a page shell needs different width or gutter
values. Tailwind packages use utility classes and consumer class overrides instead of these CSS variables. Use
`className` in React, `class` in Solid, or `class` in Vue for local block styles such as padding, borders, or
backgrounds.

These variables apply to the CSS Modules packages. Tailwind packages expose the same `size` and `gutter` choices
through utilities.

### Styling hooks

- `Container` exposes `data-slot="container-root"` on the root.
- `data-scope="container"` and `data-part="root"` follow Ark's styling conventions.
- `data-size` selects the width preset: `xs`, `sm`, `md`, `lg`, `xl`, `full`.
- `data-gutter` selects the gutter preset: `none`, `sm`, `md`, `lg`.
- `--moduix-container-*` variables control horizontal gutters and max-width math for CSS Modules. Vertical spacing and
  child layout remain the responsibility of the surrounding CSS.
