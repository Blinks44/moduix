## Choosing the right component

Use `Drawer` for a panel that slides in from the edge of the viewport. It works well for navigation,
forms, mobile bottom sheets, and workflows where users need to drag the panel or move between snap
points. Choose `Dialog` for a centered surface that does not need to be dragged.

## Anatomy

```text
Drawer.Root
├─ Drawer.Trigger
├─ Drawer.SwipeArea (optional)
├─ Drawer.Backdrop
└─ Drawer.Positioner
   └─ Drawer.Content
      ├─ Drawer.Grabber
      │  └─ Drawer.GrabberIndicator
      ├─ Drawer.Title
      ├─ Drawer.Description
      └─ Drawer.CloseTrigger
```

| Part                      | Role                                                 |
| ------------------------- | ---------------------------------------------------- |
| `Drawer` / `Drawer.Root`  | Controls state, snap points, and swipe behavior.     |
| `Drawer.Trigger`          | Opens the drawer.                                    |
| `Drawer.Backdrop`         | Modal backdrop layer.                                |
| `Drawer.Positioner`       | Positions the drawer content.                        |
| `Drawer.Content`          | Interactive surface of the drawer.                  |
| `Drawer.Grabber`          | Container for the drag handle.                      |
| `Drawer.GrabberIndicator` | Visual indicator inside the drag handle.             |
| `Drawer.CloseTrigger`     | Closes the drawer.                                   |
| `Drawer.SwipeArea`        | Optional edge region that opens the drawer on swipe. |
| `Drawer.Stack`            | Coordinates nested drawers and indented surfaces.    |
| `Drawer.Indent`           | Surface that moves back when a stacked drawer opens. |
| `Drawer.IndentBackground` | Background behind an indented surface.               |
| `Drawer.Header`           | Optional layout helper for the header.               |
| `Drawer.Body`             | Optional flexible content area.                      |
| `Drawer.Footer`           | Optional layout helper for actions.                  |
| `Drawer.CloseIcon`        | Styled close control.                                |
| `Drawer.RootProvider`     | Connects parts to state created with `useDrawer()`.  |

`Drawer.Header`, `Drawer.Body`, `Drawer.Footer`, and `Drawer.CloseIcon` are optional moduix helpers for
layout and visual defaults. They do not replace or hide Ark structural parts.

`Drawer` and `Drawer.Root` are equivalent root components. Use the shorter `<Drawer>` form in application code;
`Drawer.Root` is useful when you prefer the namespaced form.

## Composition

The root component automatically renders `Backdrop` and `Positioner` through a portal. Because a
portalled drawer is positioned against the viewport, the preview size affects only the trigger. Set
`portalled={false}` to render it inline, or pass `portalRef` to use a custom container. The structural
parts remain explicit and can be styled.

### Recommended composition

Use `Drawer` as the root when it should own state and behavior. Render `Backdrop`, `Positioner`, and
`Content` explicitly, then place `Grabber` and `GrabberIndicator` inside `Content` when the drawer
should have a visible drag handle.

Use `asChild` to compose `Drawer.Trigger` or `Drawer.CloseTrigger` with `Button`. The child must be a
single semantic element that can receive focus.

Ark callbacks receive a `details` object:

- `onOpenChange(details)` → `details.open`
- `onSnapPointChange(details)` → `details.snapPoint`
- `onTriggerValueChange(details)` → `details.value` and `details.triggerElement`

### When to go custom

Apply `className` directly to any exported part. If state needs to live outside the drawer tree, import
`useDrawer` from `@moduix/react` and pass its return value to `Drawer.RootProvider`. Do not use
`Drawer` and `Drawer.RootProvider` for the same state instance. For advanced composition,
`@moduix/react` also exports `useDrawerContext`, `useDrawerStackContext`, and `Drawer.Context`.

Wrap the surfaces that should indent together in `Drawer.Stack`, then render `Drawer.IndentBackground`
and `Drawer.Indent`.

### Default props

By default, portalled overlay content mounts lazily and unmounts after its exit animation. Set
`unmountOnExit={false}` to keep it mounted after the first open. Set both lifecycle props to `false`
only when you need the content rendered immediately on initial load.

| Prop                     | Default    | Notes                                                  |
| ------------------------ | ---------- | ------------------------------------------------------ |
| `modal`                  | `true`     | Hides page content and blocks interaction outside.      |
| `swipeDirection`         | `"down"`   | Opens from the bottom by default.                       |
| `snapPoints`             | `[1]`      | Uses the full drawer height when no snap points exist.  |
| `closeOnEscape`          | `true`     | Keeps Ark Escape-to-close behavior enabled.             |
| `closeOnInteractOutside` | `true`     | Closes a modal drawer after outside interaction.        |
| `preventDragOnScroll`    | `true`     | Prevents dragging from starting in scrollable content.  |
| `preventScroll`          | `true`     | Stops background scrolling while the drawer is open.    |
| `restoreFocus`           | `true`     | Returns focus to the element active before opening.    |
| `trapFocus`              | `true`     | Keeps focus inside modal drawer content.                |
| `lazyMount`              | `true`     | moduix default; Ark's default is `false`.               |
| `unmountOnExit`          | `true`     | moduix default; Ark's default is `false`.               |
| `Drawer.Content draggable` | `true`     | Dragging from the content is enabled. Set it to `false` to keep the grabber as the drag handle. |
| `closeThreshold`         | `0.25`     | Swipe distance ratio needed to close the drawer.        |
| `snapToSequentialPoints` | `false`    | Moves through snap points one at a time.                |
| `swipeVelocityThreshold` | `700`      | Swipe velocity threshold for closing.                   |
| `role`                   | `"dialog"` | Use `"alertdialog"` for urgent blocking content.       |

### Behavioral notes

- Direction values are logical: `up`, `down`, `start`, and `end`. For styling, Ark exposes the
  resolved physical `left` or `right` values through `data-swipe-direction`.
- `Drawer.Content draggable={false}` disables dragging from the content while keeping the grabber draggable.
- `Drawer.Content variant="island"` adds an inset from the viewport, rounds every content corner, and removes
  the bleed extension used during overdrag.
- `data-no-drag` prevents a drag gesture from starting inside a specific subtree.
- The modal backdrop stays fully visible while the drawer moves between snap points, then fades when
  closing begins.
- `ids` sets accessibility IDs when composing parts across separate trees.
- `Drawer.CloseIcon` uses `Close drawer` as its default accessible label. Pass your own `aria-label`
  when the context requires different wording.
- `Drawer.Content` forwards its ref to the dialog surface, which is useful for measuring it or moving
  focus there imperatively.
- `stack` accepts an external Ark drawer stack store for app-level stack visuals.
- `immediate` and `skipAnimationOnMount` control when Ark mounts and unmounts the drawer while you
  manage the animation yourself.
- `present`, `lazyMount`, `unmountOnExit`, and `onExitComplete` control the render lifecycle. moduix
  defaults `lazyMount` and `unmountOnExit` to `true`, so exit animations can finish without rendering
  hidden drawers on initial page load.
- When `prefers-reduced-motion: reduce` matches, entry, exit, and stack animations run for 1ms while
  Ark still completes its lifecycle.
- Ark preserves dialog focus trapping, Escape handling, title and description associations, and focus
  restoration.

### Non-Modal

Set `modal={false}` when the page must remain interactive and scrollable while the drawer is open. On
touch devices, disable dragging on `Content` and use `Header` as `Grabber`. This keeps one vertical
gesture from moving both the drawer and the page. Add `data-no-drag` to every interactive control in
`Header`, such as the close button. If the whole content should be draggable instead, set
`preventScroll={true}`. Outside controls remain interactive, but background scrolling is locked while
the drawer is open.
