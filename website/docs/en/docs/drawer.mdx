## Choosing the right component

Use `Drawer` for a panel that slides in from the edge of the viewport. It works well for navigation,
forms, mobile bottom sheets, and workflows where users need to drag the panel or move between snap
points. Choose `Dialog` for a centered surface that does not need to be dragged.

## Basic

the user drag it to full height. `DrawerContent` is the interactive surface, `DrawerPositioner`
places it, and `DrawerBackdrop` provides the modal layer.

## Anatomy

```text
Drawer
├─ DrawerTrigger
├─ DrawerSwipeArea (optional)
├─ DrawerBackdrop
└─ DrawerPositioner
   └─ DrawerContent
      ├─ DrawerGrabber
      │  └─ DrawerGrabberIndicator
      ├─ DrawerHeader (optional layout helper)
      │  ├─ DrawerTitle
      │  ├─ DrawerDescription
      │  └─ DrawerCloseIcon (optional helper)
      ├─ DrawerBody (optional layout helper)
      └─ DrawerFooter (optional layout helper)

DrawerRootProvider
└─ same part tree connected to a useDrawer() store
```

| Part | Role |
| --- | --- |
| `Drawer` | Root part that owns open state, snap points, and swipe behavior. |
| `DrawerRootProvider` | Connects the parts to state created with `useDrawer()`. |
| `DrawerTrigger` | Opens the drawer. |
| `DrawerSwipeArea` | Optional edge region that opens the drawer on swipe. |
| `DrawerBackdrop` | Modal backdrop layer. |
| `DrawerPositioner` | Positions the drawer content. |
| `DrawerContent` | Interactive surface of the drawer. |
| `DrawerGrabber` | Container for the drag handle. |
| `DrawerGrabberIndicator` | Visual indicator inside the drag handle. |
| `DrawerTitle` | Accessible title for the drawer. |
| `DrawerDescription` | Accessible description for the drawer. |
| `DrawerCloseTrigger` | Closes the drawer. |
| `DrawerCloseIcon` | Moduix close control composed from `DrawerCloseTrigger`. |
| `DrawerStack` | Coordinates nested drawers and indented surfaces. |
| `DrawerIndent` | Surface that moves back when a stacked drawer opens. |
| `DrawerIndentBackground` | Background behind an indented surface. |
| `DrawerHeader`, `DrawerBody`, `DrawerFooter` | Optional layout helpers with no state of their own. |

## Composition

`Drawer` owns its state by default and renders `DrawerBackdrop` and `DrawerPositioner` through a portal. Keep
those structural parts explicit. Set `portalled={false}` to render them inline, or pass `portalRef`
to use a custom container.

When state must be created outside the drawer tree, create one store with `useDrawer()` and pass it to
one `DrawerRootProvider`. Do not render `Drawer` for that same store. Nested drawers
use separate stores and separate `DrawerRootProvider` trees so each drawer keeps its own focus and open state.

Wrap surfaces that should move together in `DrawerStack`, then pair `DrawerIndentBackground` with
`DrawerIndent`. Use `asChild` for a custom trigger or close host: React receives one focusable child,
Solid uses a render function that spreads `props()` onto the child, and Vue uses the `as-child`
attribute with a single child element. Ark callbacks receive detail
objects, such as `details.open`, `details.snapPoint`, and `details.value`.

### Floating Grabber

Place `DrawerGrabber` above the surface when the handle should appear as a separate control. The

### Indent Background

`DrawerStack` uses Ark stack state and swipe progress to move `DrawerIndentBackground` and `DrawerIndent` together.

### Island

Set `variant="island"` on `DrawerContent` when a compact drawer should sit inside the viewport with

<Example name="drawer/island" />

### Multiple Triggers

Give each trigger a `value` to reuse one drawer for a list. The callback tells you which trigger is
active.

<Example name="drawer/multiple-triggers" />

### Nested

Use separate Ark `useDrawer` instances and separate moduix `DrawerRootProvider` trees for nested
drawers. Each drawer then keeps its own open state and focus lifecycle.

<Example name="drawer/nested" />

### Non-Modal

Set `modal={false}` when the page must remain interactive while the drawer is open. This example
keeps the drawer draggable from its grabber while `ScrollArea` owns the long content viewport.

<Example name="drawer/non-modal" />

### Root Provider

Use the moduix `useDrawer` export when buttons outside the drawer tree need to open it or change its
snap points.

<Example name="drawer/root-provider" />

### Scrollable

Put long content in `DrawerBody`. Use `ScrollArea` when the drawer should have a dedicated scroll

<Example name="drawer/scrollable" />

### Sizes

Set `size` on `DrawerContent` to `sm`, `md` (default), `lg`, or `xl` to choose the width of a
`start` or `end` drawer: 18rem, 22rem, 28rem, or 36rem. On narrow screens the drawer still leaves
a gap at the opposite edge. Top and bottom drawers take the full width, and their height comes from
snap points.

<Example name="drawer/sizes" />

### Swipe Direction

Use logical `start` and `end` values for side drawers so the same code works in LTR and RTL. Use `up`

## Styling

Use `className` in React or `class` in Solid and Vue on exported parts for structural styles. For state-based
styles, prefer Ark data attributes such as `data-state`, `data-swipe-direction`, and `data-dragging`,
together with moduix `data-slot` selectors. Tailwind variants use native utilities and consumer
classes; the component variables below customize the CSS Modules variants. Data attributes and
`data-slot` hooks are shared by both styling tracks.

### Styling hooks

- moduix `data-slot` values: `drawer-trigger`, `drawer-backdrop`, `drawer-positioner`, `drawer-content`,
  `drawer-grabber`, `drawer-grabber-indicator`, `drawer-title`, `drawer-description`,
  `drawer-close-trigger`, `drawer-close-icon`, `drawer-swipe-area`, `drawer-indent`,
  `drawer-indent-background`, `drawer-header`, `drawer-body`, and `drawer-footer`.
- `DrawerContent` writes `data-size` (default `md`) and `data-variant="island"` when its island
  presentation is active.
- Ark part hooks: `data-scope="drawer"` with `data-part`.
- State hooks: `data-state="open|closed"`, `data-swipe-direction`, `data-swiping`,
  `data-dragging`, `data-expanded`, `data-current`, `data-value`, `data-disabled`,
  `data-nested-drawer-open`, and `data-nested-drawer-swiping`.
- Runtime variables: `--drawer-translate`, `--drawer-translate-x`, `--drawer-translate-y`,
  `--drawer-snap-point-offset-x`, `--drawer-snap-point-offset-y`, `--drawer-swipe-movement-x`,
  `--drawer-swipe-movement-y`, `--drawer-swipe-progress`, `--drawer-swipe-strength`,
  `--drawer-height`, `--drawer-frontmost-height`, `--nested-drawers`, `--nested-layer-count`,
  and `--layer-index`.
- `DrawerTrigger` and `DrawerCloseTrigger` are unstyled. Compose them with `asChild` and a `Button`,
  or style the native button with a class.
- Colors, borders, spacing, and typography come from foundation tokens. Change them for one drawer
  with a class on the part. The backdrop reads the shared `--moduix-backdrop-bg` and
  `--moduix-backdrop-filter`.
- Top and bottom drawers are capped at `max-height: 80dvh`; set another `max-height` with a class on
  `DrawerContent`.
