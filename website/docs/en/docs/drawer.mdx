## Choosing the right component

Use `Drawer` for a panel that slides in from the edge of the viewport. It works well for navigation,
forms, mobile bottom sheets, and workflows where users need to drag the panel or move between snap
points. Choose `Dialog` for a centered surface that does not need to be dragged.

## Anatomy

```text
Drawer / Drawer.Root
├─ Drawer.Trigger
├─ Drawer.SwipeArea (optional)
├─ Drawer.Backdrop
└─ Drawer.Positioner
   └─ Drawer.Content
      ├─ Drawer.Grabber
      │  └─ Drawer.GrabberIndicator
      ├─ Drawer.Header (optional layout helper)
      │  ├─ Drawer.Title
      │  ├─ Drawer.Description
      │  └─ Drawer.CloseIcon (optional helper)
      ├─ Drawer.Body (optional layout helper)
      └─ Drawer.Footer (optional layout helper)

Drawer.RootProvider
└─ same part tree connected to a useDrawer() store
```

| Part | Role |
| --- | --- |
| `Drawer` / `Drawer.Root` | Root part that owns open state, snap points, and swipe behavior. |
| `Drawer.RootProvider` | Connects the parts to state created with `useDrawer()`. |
| `Drawer.Trigger` | Opens the drawer. |
| `Drawer.SwipeArea` | Optional edge region that opens the drawer on swipe. |
| `Drawer.Backdrop` | Modal backdrop layer. |
| `Drawer.Positioner` | Positions the drawer content. |
| `Drawer.Content` | Interactive surface of the drawer. |
| `Drawer.Grabber` | Container for the drag handle. |
| `Drawer.GrabberIndicator` | Visual indicator inside the drag handle. |
| `Drawer.Title` | Accessible title for the drawer. |
| `Drawer.Description` | Accessible description for the drawer. |
| `Drawer.CloseTrigger` | Closes the drawer. |
| `Drawer.CloseIcon` | Moduix close control composed from `CloseTrigger`. |
| `Drawer.Stack` | Coordinates nested drawers and indented surfaces. |
| `Drawer.Indent` | Surface that moves back when a stacked drawer opens. |
| `Drawer.IndentBackground` | Background behind an indented surface. |
| `Drawer.Header`, `Drawer.Body`, `Drawer.Footer` | Optional layout helpers with no state of their own. |

## Composition

`Drawer` owns its state by default and renders `Backdrop` and `Positioner` through a portal. Keep
those structural parts explicit. Set `portalled={false}` to render them inline, or pass `portalRef`
to use a custom container.

When state must be created outside the drawer tree, create one store with `useDrawer()` and pass it to
one `Drawer.RootProvider`. Do not render `Drawer` or `Drawer.Root` for that same store. Nested drawers
use separate stores and separate `RootProvider` trees so each drawer keeps its own focus and open state.

Wrap surfaces that should move together in `Drawer.Stack`, then pair `Drawer.IndentBackground` with
`Drawer.Indent`. Use `asChild` for a custom trigger or close host: React receives one focusable child,
while Solid uses a render function that spreads `props()` onto the child. Ark callbacks receive detail
objects, such as `details.open`, `details.snapPoint`, and `details.value`.

## Styling

Use `className` in React or `class` in Solid on exported parts for structural styles. For state-based
styles, prefer Ark data attributes such as `data-state`, `data-swipe-direction`, and `data-dragging`,
together with moduix `data-slot` selectors. Tailwind variants use native utilities and consumer
classes; the component variables below customize the CSS Modules variants. Data attributes and
`data-slot` hooks are shared by both styling tracks.

### Styling hooks

- moduix `data-slot` values: `drawer-trigger`, `drawer-backdrop`, `drawer-positioner`, `drawer-content`,
  `drawer-grabber`, `drawer-grabber-indicator`, `drawer-title`, `drawer-description`,
  `drawer-close-trigger`, `drawer-close-icon`, `drawer-swipe-area`, `drawer-indent`,
  `drawer-indent-background`, `drawer-header`, `drawer-body`, and `drawer-footer`.
- `Drawer.Content` writes `data-variant="island"` when its island presentation is active.
- Ark part hooks: `data-scope="drawer"` with `data-part`.
- State hooks: `data-state="open|closed"`, `data-swipe-direction`, `data-swiping`,
  `data-dragging`, `data-expanded`, `data-current`, `data-value`, `data-disabled`,
  `data-nested-drawer-open`, and `data-nested-drawer-swiping`.
- Runtime variables: `--drawer-translate`, `--drawer-translate-x`, `--drawer-translate-y`,
  `--drawer-snap-point-offset-x`, `--drawer-snap-point-offset-y`, `--drawer-swipe-movement-x`,
  `--drawer-swipe-movement-y`, `--drawer-swipe-progress`, `--drawer-swipe-strength`,
  `--drawer-height`, `--drawer-frontmost-height`, `--nested-drawers`, `--nested-layer-count`,
  and `--layer-index`.
