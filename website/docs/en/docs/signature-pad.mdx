## Anatomy

```text
SignaturePad / SignaturePad.Root
├─ SignaturePad.Label
├─ SignaturePad.Canvas (moduix ready-made composition)
│  └─ SignaturePad.Control
│     ├─ SignaturePad.Segment
│     ├─ SignaturePad.ClearTrigger
│     └─ SignaturePad.Guide
└─ SignaturePad.HiddenInput value={serializedPaths} (explicit)

SignaturePad.RootProvider
└─ same part tree connected to useSignaturePad()
```

| Part                                 | Role                                                                    |
| ------------------------------------ | ----------------------------------------------------------------------- |
| `SignaturePad` / `SignaturePad.Root` | Owns paths, drawing options, form name, ids, and callbacks.              |
| `SignaturePad.HiddenInput`            | Native Ark form control that you compose explicitly.                    |
| `SignaturePad.RootProvider`           | Renders the same part tree from state created with `useSignaturePad()`. |
| `SignaturePad.Label`                 | Associates the visible label with the drawing area and hidden input.    |
| `SignaturePad.Canvas`                | Ready-made drawing surface that renders the standard parts and forwards `Control` props. |
| `SignaturePad.Control`               | Focusable pointer and touch drawing area.                               |
| `SignaturePad.Segment`               | SVG layer for saved strokes and the current in-progress stroke.         |
| `SignaturePad.ClearTrigger`          | Native button that clears paths.                                        |
| `SignaturePad.Guide`                 | Non-interactive baseline inside the drawing area.                       |

## Composition

Use `Label` and `Canvas` for the standard composition. `Canvas` uses a fixed child tree, so switch
to `Control`, `Segment`, `ClearTrigger`, and `Guide` when the drawing structure or clear control
needs to change.

`SignaturePad.HiddenInput` is not rendered automatically. Add it explicitly and pass a serialized
value, usually read from `SignaturePad.Context` or `useSignaturePadContext()`, when the signature
must be submitted by a native form.

Use `defaultPaths` for local uncontrolled state. Use `paths` with `onDraw(details)` when the
application owns the signature data. Use `RootProvider` with `useSignaturePad()` when state must be
created outside the rendered tree or external controls need `paths`, `clear()`, or `getDataUrl()`.

### Styling hooks

Use `className` in React or `class` in Solid on any exported part for local styling. moduix also
adds stable `data-slot` attributes:

| Part                                 | `data-slot`                   |
| ------------------------------------ | ----------------------------- |
| `SignaturePad` / `SignaturePad.Root` | `signature-pad-root`          |
| `SignaturePad.RootProvider`          | `signature-pad-root-provider` |
| `SignaturePad.Label`                 | `signature-pad-label`          |
| `SignaturePad.Control`               | `signature-pad-control`        |
| `SignaturePad.Segment`               | `signature-pad-segment`        |
| `SignaturePad.Guide`                 | `signature-pad-guide`          |
| `SignaturePad.ClearTrigger`          | `signature-pad-clear-trigger` |

Ark attributes remain available for targeted styles. `Root`, `Label`, `Control`, `Segment`,
`Guide`, `ClearTrigger`, and the internal segment paths expose `data-scope="signature-pad"` and
`data-part`; `data-disabled` appears on root, label, control, and guide, while `data-required`
appears on label.
