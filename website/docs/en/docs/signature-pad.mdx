## Anatomy

```text
SignaturePad / SignaturePad.Root
├─ SignaturePad.Label
├─ SignaturePad.Canvas (moduix ready-made composition)
│  └─ SignaturePad.Control
│     ├─ SignaturePad.Segment
│     ├─ SignaturePad.ClearTrigger
│     └─ SignaturePad.Guide
└─ hidden native input (automatic)

SignaturePad.RootProvider
└─ same part tree connected to useSignaturePad()
```

| Part                                 | Role                                                                    |
| ------------------------------------ | ----------------------------------------------------------------------- |
| `SignaturePad` / `SignaturePad.Root` | Owns paths, drawing options, form name, ids, and callbacks.              |
| `SignaturePad.RootProvider`          | Renders the same part tree from state created with `useSignaturePad()`. |
| `SignaturePad.Label`                 | Associates the visible label with the drawing area and hidden input.    |
| `SignaturePad.Canvas`                | Ready-made drawing surface that renders the standard parts and forwards `Control` props and ref. |
| `SignaturePad.Control`               | Focusable pointer and touch drawing area.                               |
| `SignaturePad.Segment`               | SVG layer for saved strokes and the current in-progress stroke.         |
| `SignaturePad.ClearTrigger`          | Native button that clears paths; Ark hides it while empty or drawing.   |
| `SignaturePad.Guide`                 | Non-interactive baseline inside the drawing area.                       |

## Composition

### Recommended composition

Use `Label` and `Canvas` for the standard composition. `Canvas` provides Ark's focus target, pointer
capture, accessible clear button behavior, and SVG rendering without repeated drawing-surface markup.
It forwards `Control` props and its DOM ref. `Canvas` uses a fixed child tree, so use the lower-level
parts when you need a different structure.

### When to go custom

Use explicit `Control`, `Segment`, `ClearTrigger`, and `Guide` parts when you need to change their
structure, replace the icon, or use `asChild`. Use controlled `paths` when application state needs
to restore, clear, autosave, or validate a signature outside the component. Use `RootProvider` with
`useSignaturePad()` when state must be created outside the rendered tree or external controls need
direct access to `paths`, `clear()`, or `getDataUrl()`.

For advanced reads inside the component tree, use `SignaturePad.Context` or
`useSignaturePadContext()`.

Pass `name` when the signature should be included in native form submission. moduix adds a hidden
native input automatically and serializes the paths as `paths.join(' ')` by default. Pass
`getFormValue(paths)` when the form needs a different representation.

Use `drawing` to customize each stroke. `drawing.size` changes stroke width,
`drawing.simulatePressure` controls pressure simulation, and `drawing.fill` sets the stroke color.
`drawing.fill` must be a valid CSS color string. Ark does not accept a CSS custom property in this
option. To use a theme token, omit `fill` and override `--moduix-signature-pad-stroke-color`
instead.

### Default props

| Prop           | Default                               | Notes                                                           |
| -------------- | ------------------------------------- | --------------------------------------------------------------- |
| `defaultPaths` | -                                     | Initial uncontrolled SVG path array.                            |
| `paths`        | -                                     | Controlled SVG path array. Pair with `onDraw(details)`.         |
| `drawing`      | `{ size: 2, simulatePressure: false }` | Zag stroke options; `fill` must be a valid CSS color string.    |
| `name`         | -                                     | Native form field name.                                         |
| `getFormValue` | `paths.join(' ')`                     | Custom serialization for the automatically rendered input.      |
| `disabled`     | -                                     | Disables drawing and clear trigger interaction.                 |
| `readOnly`     | -                                     | Prevents drawing and disables the clear trigger.                |
| `required`     | -                                     | Marks the label and hidden input as required.                   |
| `ids`          | -                                     | Stable ids for root, control, hidden input, and label.           |
| `translations` | Ark defaults                          | Accessible labels for the control and clear trigger.            |

The default drawing control is `17.5rem` by `10rem`, or approximately `280px` by `160px` with the
default token scale. Override `--moduix-signature-pad-width`, `--moduix-signature-pad-height`, or
the more specific `--moduix-signature-pad-control-*` variables to resize the signing area. The
default minimum height follows the configured control height, so a smaller height remains effective.

### Behavioral notes

Use `defaultPaths` for an initial uncontrolled signature. Use `paths` with `onDraw(details)` when the
signature must stay in application state. `onDraw(details)` runs while drawing and when committed
paths change. `details.paths` contains committed strokes, while `details.currentPath` contains the
stroke currently in progress.

`onDrawEnd(details)` fires after a stroke ends or the signature is cleared. Its
`details.getDataUrl(type, quality?)` method supports `image/png`, `image/jpeg`, and `image/svg+xml`.
It returns an empty string for an empty signature.

Set `name` on the root when native form submission is needed. The hidden input is rendered
automatically. Pass `getFormValue(paths)` when the form needs custom serialization. Wrap the pad in
`Field.Root` when helper text, error text, required state, or disabled state should be shared with
surrounding form UI. The `Field` invalid state controls field messaging and descriptions; it does not add
`data-invalid` to the signature pad parts.

`Control` is keyboard-focusable and exposes `role="application"` with
`aria-roledescription="signature pad"`. Drawing uses pointer and touch input rather than arrow-key
navigation. `ClearTrigger` is a native button, so Enter and Space activation remain standard button
behavior. In read-only state, moduix disables the clear trigger so the displayed signature cannot be
changed accidentally.

### Styling hooks

Use `className` on any exported part for local styling. moduix also adds stable `data-slot`
attributes:

| Part                                 | `data-slot`                   |
| ------------------------------------ | ----------------------------- |
| `SignaturePad` / `SignaturePad.Root` | `signature-pad-root`          |
| `SignaturePad.RootProvider`          | `signature-pad-root-provider` |
| `SignaturePad.Label`                 | `signature-pad-label`         |
| `SignaturePad.Control`               | `signature-pad-control`       |
| `SignaturePad.Segment`               | `signature-pad-segment`       |
| `SignaturePad.Guide`                 | `signature-pad-guide`         |
| `SignaturePad.ClearTrigger`          | `signature-pad-clear-trigger` |

Ark attributes remain available for targeted styles. `Root`, `Label`, `Control`, `Segment`,
`Guide`, `ClearTrigger`, and the internal segment paths expose `data-scope="signature-pad"` and
`data-part`; `data-disabled` appears on root, label, control, and guide, while `data-required`
appears on label.
