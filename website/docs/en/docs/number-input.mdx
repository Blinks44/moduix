## Anatomy

```text
NumberInput / NumberInput.Root
├─ NumberInput.Label
├─ NumberInput.Scrubber (optional)
├─ NumberInput.Field (recommended shortcut)
│  └─ renders NumberInput.Control
│     ├─ NumberInput.DecrementTrigger
│     ├─ NumberInput.Input
│     └─ NumberInput.IncrementTrigger
└─ NumberInput.ValueText (optional)

NumberInput.RootProvider
└─ same part tree connected to state created by `useNumberInput()`
```

| Part | Role |
| --- | --- |
| `NumberInput` / `NumberInput.Root` | Owns number input state, parsing, formatting, and keyboard behavior. |
| `NumberInput.RootProvider` | Connects parts to state created with `useNumberInput()`. |
| `NumberInput.Context` | Exposes formatted and numeric values plus imperative state methods. |
| `NumberInput.Label` | Accessible label for the managed input. |
| `NumberInput.Scrubber` | Optional drag target that changes the value as the pointer moves. |
| `NumberInput.Control` | Groups the input and increment and decrement triggers. |
| `NumberInput.Field` | Convenience part that renders the standard control and trigger group. |
| `NumberInput.DecrementTrigger` | Button that decreases the current value. It renders the moduix minus icon by default. |
| `NumberInput.Input` | Editable numeric text input managed by Ark UI. |
| `NumberInput.IncrementTrigger` | Button that increases the current value. It renders the moduix plus icon by default. |
| `NumberInput.ValueText` | Read-only text element for the formatted value. |

## Composition

Use `NumberInput.Field` for the standard three-part control. Keep `value` and `defaultValue` as
strings, and read `details.value` from `onValueChange` when the input is controlled. When state must
be created outside the rendered part tree, call `useNumberInput()` and pass the matching store to
`NumberInput.RootProvider`; do not render `NumberInput` or `NumberInput.Root` for the same store.
React reads store properties directly, while Solid reads them through the returned accessor.

Use `NumberInput.Control` with individual parts when the trigger order, icons, or input styling must
differ. Add `NumberInput.Scrubber` alongside the field for drag-to-change behavior. Use
`NumberInput.Context` only when another part, such as a hidden form control, needs the formatted value
or `valueAsNumber`.

## Styling

Use `className` in React or `class` in Solid on exported parts for structural styles. Tailwind variants
use native utilities and consumer classes; the CSS variables below customize the CSS Modules variants.
Data attributes and `data-slot` hooks are shared by both styling tracks.

### Styling hooks

- Stable `data-slot` selectors: `number-input-root`, `number-input-root-provider`, `number-input-label`,
  `number-input-scrubber`, `number-input-control`, `number-input-decrement-trigger`,
  `number-input-input`, `number-input-increment-trigger`, and `number-input-value-text`.
- Ark state hooks: `data-disabled`, `data-invalid`, `data-focus`, and `data-scrubbing`.
- Ark part hooks: `data-scope="number-input"` and `data-part` values matching the Ark anatomy.
