## Choosing the right component

Use `NumberInput` when users enter numeric values that need stepping, clamping, and formatting. Use
`Input` for free text, and `Slider` when choosing a point in a visual range is the goal.

## Basic

Import it from `@moduix/react/number-input`, `@moduix/solid/number-input`, or
`@moduix/vue/number-input` for CSS Modules. For Tailwind CSS, use the matching
`@moduix/react-tailwind/number-input`, `@moduix/solid-tailwind/number-input`, or
`@moduix/vue-tailwind/number-input` path.

Use `NumberInput` as the root and `NumberInputField` for the standard input with increment and
decrement controls. Give the input an accessible name with `NumberInputLabel`, `aria-label`, or
`aria-labelledby`.

## Anatomy

```text
NumberInput
├─ NumberInputLabel
├─ NumberInputScrubber (optional)
├─ NumberInputField (recommended shortcut)
│  └─ renders NumberInputControl
│     ├─ NumberInputDecrementTrigger
│     ├─ NumberInputInput
│     └─ NumberInputIncrementTrigger
└─ NumberInputValueText (optional)

NumberInputRootProvider
└─ same part tree connected to state created by `useNumberInput()`
```

| Part | Role |
| --- | --- |
| `NumberInput` | Owns number input state, parsing, formatting, and keyboard behavior. |
| `NumberInputRootProvider` | Connects parts to state created with `useNumberInput()`. |
| `NumberInputContext` | Exposes formatted and numeric values plus imperative state methods. |
| `NumberInputLabel` | Accessible label for the managed input. |
| `NumberInputScrubber` | Optional drag target that changes the value as the pointer moves. |
| `NumberInputControl` | Groups the input and increment and decrement triggers. |
| `NumberInputField` | Convenience part that renders the standard control and trigger group. |
| `NumberInputDecrementTrigger` | Button that decreases the current value. It renders the moduix minus icon by default. |
| `NumberInputInput` | Editable numeric text input managed by Ark UI. |
| `NumberInputIncrementTrigger` | Button that increases the current value. It renders the moduix plus icon by default. |
| `NumberInputValueText` | Read-only text element for the formatted value. |

## Composition

Use `NumberInputField` for the standard three-part control. Keep `value` and `defaultValue` as
strings, and read `details.value` from `onValueChange` when the input is controlled. When state must
be created outside the rendered part tree, call `useNumberInput()` and pass the matching store to
`NumberInputRootProvider`; do not render `NumberInput` or `NumberInputRootProvider` for the same store.
React reads store properties directly, Solid reads them through the returned accessor, and Vue exposes the reactive store directly to the template.

Use `NumberInputControl` with individual parts when the trigger order, icons, or input styling must
differ. Add `NumberInputScrubber` alongside the field for drag-to-change behavior. Use
`NumberInputContext` only when another part, such as a hidden form control, needs the formatted value
or `valueAsNumber`.

### Formatting

Pass `formatOptions` to format the visible value with `Intl.NumberFormat`.

<Example name="number-input/formatting" />

### Min and Max

Use `min`, `max`, and `step` to define the range and increment for keyboard, trigger, and scrubber
changes. The value is clamped on blur by default. Set `clampValueOnBlur={false}` when an out-of-range
typed value should remain visible after the input loses focus.

<Example name="number-input/min-and-max" />

### Mouse Wheel

Set `allowMouseWheel` when changing the value with the mouse wheel is intentional for the workflow.

<Example name="number-input/mouse-wheel" />

### Native form submission

Set `name` to submit the visible text spinbutton through a native form. `NumberInput` submits its
displayed string value. Use `NumberInputContext` for a second hidden input only when the form needs
the parsed numeric representation.

<Example name="number-input/form-submission" />

### Precision

Use `formatOptions` with `Intl.NumberFormatOptions` when the visible value needs a fixed number of
fraction digits.

### Root Provider

Use `useNumberInput()` with `NumberInputRootProvider` when state must be created outside the rendered
part tree.

### Sizes
