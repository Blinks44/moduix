## Usage

<Usage />

Use `NumberInput` as the root and `NumberInputField` for the standard input with increment and
decrement controls. Give the input an accessible name with `NumberInputLabel`, `aria-label`, or
`aria-labelledby`.

## Choosing the right component

Use `NumberInput` when users enter numeric values that need stepping, clamping, and formatting. Use
`Input` for free text, and `Slider` when choosing a point in a visual range is the goal.

## Composition

Use `NumberInputField` for the standard three-part control. Keep `value` and `defaultValue` as
strings, and read `details.value` from `onValueChange` when the input is controlled. When state must
be created outside the rendered part tree, call `useNumberInput()` and pass the matching store to
`NumberInputRootProvider`; do not render `NumberInput` or `NumberInputRootProvider` for the same store.
React reads store properties directly, Solid reads them through the returned accessor, Vue exposes the reactive store directly to the template, and Svelte returns a getter, so read the state with `numberInput().value`.

Use `NumberInputControl` with individual parts when the trigger order, icons, or input styling must
differ. Add `NumberInputScrubber` alongside the field for drag-to-change behavior. Use
`NumberInputContext` only when another part, such as a hidden form control, needs the formatted value
or `valueAsNumber`.

## Keyboard

| Key | Action |
| --- | --- |
| `ArrowUp` / `ArrowDown` | Increases or decreases by one step. |
| `Shift` + arrows | Changes by a large step, 10 steps by default. |
| `Alt` + arrows | Changes by a small step, 0.1 by default. |
| `Home` / `End` | Sets the minimum or maximum. |
| `Enter` | Commits the typed value. |

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | — | Value as a string, for controlled use. |
| `defaultValue` | `string` | — | Initial value as a string. |
| `onValueChange` | `(details: ValueChangeDetails) => void` | — | Called with `value` and `valueAsNumber` on every change. |
| `onValueCommit` | `(details: ValueChangeDetails) => void` | — | Called on blur or Enter. |
| `min` | `number` | `Number.MIN_SAFE_INTEGER` | Minimum value. |
| `max` | `number` | `Number.MAX_SAFE_INTEGER` | Maximum value. |
| `step` | `number` | `1` | Step for buttons and arrow keys. |
| `largeStep` | `number` | `10 * step` | Step with Shift held. |
| `formatOptions` | `Intl.NumberFormatOptions` | — | `Intl.NumberFormat` options, for example currency or percent. |
| `locale` | `string` | `'en-US'` | Locale for formatting; defaults to the nearest `LocaleProvider`. |
| `allowMouseWheel` | `boolean` | `false` | Changes the value with the mouse wheel while focused. |
| `clampValueOnBlur` | `boolean` | `true` | Clamps the value to `min` and `max` on blur. |
| `spinOnPress` | `boolean` | `true` | Keeps changing the value while a button is held. |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | Control size: `xs`, `sm`, `md`, `lg`, or `xl`. |
| `name` | `string` | — | Form field name of the underlying input. |
| `disabled` | `boolean` | `false` | Disables the control. |
| `readOnly` | `boolean` | `false` | Shows the value but prevents changes. |
| `invalid` | `boolean` | `false` | Marks the control as invalid. |
| `required` | `boolean` | `false` | Requires a value before form submission. |
| `form` | `string` | — | Id of the form the underlying input belongs to. |
| `pattern` | `string` | `'-?[0-9]*(.[0-9]+)?'` | Pattern the typed value must match. |
| `smallStep` | `number` | `step / 10` | Step with Alt held. |
| `allowOverflow` | `boolean` | `true` | Allows typed values outside `min` and `max`. |
| `focusInputOnChange` | `boolean` | `true` | Focuses the input when a button changes the value. |
| `translations` | `IntlTranslations` | — | Localized strings for accessibility labels. |
| `inputMode` | `InputMode` | `'decimal'` | Virtual keyboard hint. |
| `onValueInvalid` | `(details: ValueInvalidDetails) => void` | — | Called when the value goes outside `min` or `max`. |
| `onFocusChange` | `(details: FocusChangeDetails) => void` | — | Called when the input gains or loses focus. |
