## Anatomy

```text
NumberInput.Root
├─ NumberInput.Label
├─ NumberInput.Scrubber (optional)
├─ NumberInput.Field (recommended)
├─ NumberInput.Control
│  ├─ NumberInput.DecrementTrigger
│  ├─ NumberInput.Input
│  └─ NumberInput.IncrementTrigger
└─ NumberInput.ValueText (optional)

NumberInput.RootProvider
└─ same part tree connected to state created by `useNumberInput()`
```

| Part                               | Role                                                                   |
| ---------------------------------- | ---------------------------------------------------------------------- |
| `NumberInput` / `NumberInput.Root` | Owns number input state, parsing, formatting, and keyboard behavior.   |
| `NumberInput.RootProvider`         | Connects parts to state created by `useNumberInput()`.                 |
| `NumberInput.Context`              | Exposes formatted and numeric values plus imperative state methods.    |
| `NumberInput.Label`                | Accessible label for the managed input.                                |
| `NumberInput.Scrubber`             | Optional drag target that changes the value as the pointer moves.      |
| `NumberInput.Control`              | Structural wrapper for the input and increment/decrement triggers.    |
| `NumberInput.Field`                | Renders the standard control, input, and trigger group.                |
| `NumberInput.DecrementTrigger`     | Button that decreases the current value. Renders the moduix minus icon by default. |
| `NumberInput.Input`                | Editable numeric text input managed by Ark UI.                         |
| `NumberInput.IncrementTrigger`     | Button that increases the current value. Renders the moduix plus icon by default.  |
| `NumberInput.ValueText`            | Read-only text element for the formatted value.                       |

## Composition

### Recommended composition

`NumberInput` handles parsing, range validation, keyboard increment and decrement, repeated changes
while a trigger is held, drag-to-change interaction, and formatting. Set `allowMouseWheel` when
wheel-based changes are intentional. Use `NumberInput.Field` for the standard visible parts.

Use strings for `value` and `defaultValue`. Ark reports changes through `onValueChange(details)`,
where `details.value` is the string value and `details.valueAsNumber` is the parsed number.

### When to go custom

Use `NumberInput.Control` with its individual parts when the trigger order, icons, or input styling
must differ from the standard `NumberInput.Field`. Add `NumberInput.Scrubber` alongside the field
when users should be able to change the value by dragging.

### Default props

| Prop                               | Default | Notes                                                        |
| ---------------------------------- | ------- | ------------------------------------------------------------ |
| `NumberInput` / `NumberInput.Root` | -       | No additional behavioral defaults. Ark defaults apply.       |
| `NumberInput.Field`                | -       | Renders the standard control, input, and trigger group.      |
| `NumberInput.DecrementTrigger`     | -       | Renders the moduix minus icon when no children are provided. |
| `NumberInput.IncrementTrigger`     | -       | Renders the moduix plus icon when no children are provided.  |

### Behavioral notes

- Use `formatOptions`, not `format`, for localized number formatting.
- Use `translations.incrementLabel`, `translations.decrementLabel`, and `translations.valueText` for accessible labels in the current language.
- `min`, `max`, `step`, `allowOverflow`, `clampValueOnBlur`, `spinOnPress`, `inputMode`, and `allowMouseWheel` are passed through to Ark.
- `onValueInvalid(details)` reports `rangeUnderflow` or `rangeOverflow` when the value exceeds configured bounds.
- Set `clampValueOnBlur={false}` when typed values outside `min` or `max` should remain unchanged on blur.
- Use `ids` when external labels or descriptions need stable element IDs.
- Ark-backed parts support `asChild` for custom host elements. `NumberInput.Field` intentionally
  renders its fixed three-part structure and forwards its ref to `NumberInput.Control`.
- `useNumberInput`, `useNumberInputContext`, and `NumberInput.Context` are available from `@moduix/react`.
- `name` and `form` are forwarded to the visible spinbutton for native form submission. Render a
  hidden native input through `NumberInput.Context` with `context.valueAsNumber` only when the form
  needs the parsed numeric representation instead of the displayed string.
