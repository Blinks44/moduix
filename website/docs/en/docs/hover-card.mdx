## Usage

<Usage />

Compose the card from explicit Ark parts. `HoverCardTrigger` opens the card, while
`HoverCardPositioner` and `HoverCardContent` define its floating content. The basic composition
does not include an arrow. Put long content in `HoverCardBody` so it can scroll within the
available height while `HoverCardContent` stays overflow-visible for an optional arrow.

## Choosing the right component

Use `Tooltip` for short, non-interactive hints. Use `Popover` when the popup contains richer
content or actions. Use `HoverCard` when you need a supplementary preview tied to a trigger, such as
a profile or article summary. Keep essential information and its accessible alternative outside the
hover card.

## Composition

`HoverCard` manages the state and portals `HoverCardPositioner` by default. Set `portalled={false}`
inside another overlay, or pass `portalRef` for a custom container. Use `HoverCardRootProvider`
with `useHoverCard()` when state belongs outside the card tree; React reads the store as an object,
while Solid reads it through its accessor, and Vue exposes the reactive store directly to the template.

Keep `HoverCardArrow` inside `HoverCardContent` and wrap long previews in `HoverCardBody`:
`Content` stays overflow-visible for the arrow, while `Body` provides the scroll region. Use
`asChild` with one focusable child when the trigger should be a link or another semantic element.
For several triggers sharing one content area, give each trigger a `value` and update external
content from `onTriggerValueChange(details)`.

## Styling

`HoverCardTrigger` without `asChild` looks like an inline link in the primary color; its underline
follows `currentColor`, so a `color` class recolors both. `HoverCardContent` is 14–24rem wide and at
most 24rem tall within the available viewport space. Content motion reads the shared
`--moduix-popup-motion-*` variables.

Use `className` in React or `class` in Solid and Vue on exported parts. Tailwind variants use native
utilities and consumer classes. CSS Modules variants build on foundation tokens and have no component
variables: a class on the part overrides the layered component styles. Data attributes and
`data-slot` hooks are shared by both styling tracks.

### Styling hooks

| Part | `data-slot` |
| --- | --- |
| `HoverCardTrigger` | `hover-card-trigger` |
| `HoverCardPositioner` | `hover-card-positioner` |
| `HoverCardContent` | `hover-card-content` |
| `HoverCardArrow` | `hover-card-arrow` |
| `HoverCardArrowTip` | `hover-card-arrow-tip` |
| `HoverCardBody` | `hover-card-body` |

moduix adds `data-slot="hover-card-*"` hooks to the trigger, positioner, content, arrow, arrow tip,
and body. `HoverCard` and `HoverCardRootProvider` only provide state and do not render DOM elements, so they have no styling hooks. Ark adds
`data-scope="hover-card"` and `data-part` to its parts. For state-aware styling, target
`data-state="open|closed"`, `data-placement`, `data-side`, `data-value`, `data-current`,
`data-nested`, and `data-has-nested`.

`HoverCardPositioner` exposes `--reference-width`, `--reference-height`, `--available-width`,
`--available-height`, `--x`, `--y`, `--z-index`, and `--transform-origin`. `HoverCardContent`
exposes `--layer-index` and `--nested-layer-count`. `HoverCardArrow` exposes `--arrow-size`,
`--arrow-size-half`, `--arrow-background`, and `--arrow-offset`.

## Keyboard

| Key | Action |
| --- | --- |
| `Tab` | Focusing the trigger opens the card after the delay. |
| `Esc` | Closes the card. |

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | — | Open state for controlled use. |
| `defaultOpen` | `boolean` | `false` | Initial open state when it is not controlled. |
| `onOpenChange` | `(details: OpenChangeDetails) => void` | — | Called when it opens or closes. |
| `openDelay` | `number` | `600` | Hover delay before opening, in milliseconds. |
| `closeDelay` | `number` | `300` | Delay before closing after the pointer leaves, in milliseconds. |
| `positioning` | `PositioningOptions` | — | Placement, offset, and other popup positioning options. |
| `disabled` | `boolean` | `false` | Disables the control. |
| `lazyMount` | `boolean` | `true` | Mounts the content on first open. |
| `unmountOnExit` | `boolean` | `true` | Unmounts the content after it closes. |
| `triggerValue` | `string \| null` | — | Active trigger for controlled use when several triggers share one popup. |
| `defaultTriggerValue` | `string \| null` | — | Initially active trigger. |
| `onTriggerValueChange` | `(details: TriggerValueChangeDetails) => void` | — | Called when another trigger becomes active. |
| `onPointerDownOutside` | `(event: PointerDownOutsideEvent) => void` | — | Called when the pointer is pressed outside the popup. |
| `onFocusOutside` | `(event: FocusOutsideEvent) => void` | — | Called when focus moves outside the popup. |
| `onInteractOutside` | `(event: InteractOutsideEvent) => void` | — | Called on any interaction outside the popup. |
