## Choosing the right component

- Choose **`Input`** for plain text values.
- Choose **`DateInput`** when users need keyboard-editable date segments.
- Choose **`DatePicker`** when users need a popup or inline calendar. `DateInput` is keyboard-first and
  does not include a calendar.

## Basic

Render `DateInput.Segments` inside `DateInput.Control` to get a locale-aware group of date segments. Ark
UI handles segment order, keyboard editing, focus, placeholders, and form synchronization. moduix adds
the styled parts and automatic native form inputs, keeping the common composition small.

## Anatomy

```text
DateInput.Root
├─ DateInput.Label
├─ DateInput.Control
│  ├─ DateInput.Segments
│  └─ DateInput.Separator (optional, range layouts)
└─ native hidden input(s) (automatic)

Advanced customization:

DateInput.SegmentGroup
└─ DateInput.SegmentContext
   └─ DateInput.Segment

DateInput.RootProvider
└─ same part tree connected to a useDateInput() store
```

| Part                           | Role                                                               |
| ------------------------------ | ------------------------------------------------------------------ |
| `DateInput` / `DateInput.Root` | Owns date values, locale formatting, segment focus, and validation. |
| `DateInput.RootProvider`       | Connects the parts to state created by `useDateInput()`.           |
| `DateInput.Label`              | Accessible label for the date input.                               |
| `DateInput.Control`            | Visual frame around one or more segment groups.                    |
| `DateInput.SegmentGroup`       | Groups segments for one date index.                                |
| `DateInput.Segment`            | Editable or literal segment supplied by Ark UI.                    |
| `DateInput.Segments`           | Renders one locale-aware segment group for the common case.        |
| `DateInput.Separator`          | Presentational text used between range groups.                     |
| `DateInput.Context`            | Renderless access to the current date input state.                 |
| `DateInput.SegmentContext`     | Render helper for locale-aware segment rendering.                  |

## Composition

### Recommended composition

Use the shorthand root, `DateInput`, instead of `DateInput.Root`. Render `DateInput.Segments` inside
`DateInput.Control` for a standard locale-aware segment group.

The root automatically adds the hidden native inputs needed for form submission and reset. Pass `name`
for a single date or a shared base name for a range. For ranges, render two indexed
`DateInput.Segments` groups. With `name="date"`, the submitted names are `date[0]` and `date[1]`. To
use different base names, pass the two-item `names` tuple, for example
`names={['check-in', 'check-out']}`, which submits `check-in[0]` and `check-out[1]`.

### When to go custom

Use `DateInput.SegmentGroup`, `DateInput.SegmentContext`, and `DateInput.Segment` directly when
segment classes or rendering need to vary by segment. Use `asChild` on Ark-backed parts when you need
a custom host element, and keep the child as one semantic element. Use `ids` when an external label or
description needs stable, shared IDs.

### Default props

| Prop                              | Default        | Notes                                                 |
| --------------------------------- | -------------- | ----------------------------------------------------- |
| `DateInput` / `DateInput.Root`    | -              | No local behavioral defaults; Ark defaults apply.     |
| `DateInput.Segments`              | -              | Renders one locale-aware segment group for one index. |
| `DateInput.names`                 | -              | Two base names for range inputs; Ark appends indexes. |
| `DateInput.Separator.aria-hidden` | `true`         | Presentational text is hidden from assistive tech.    |
| `DateInput.Separator.role`        | `presentation` | Keeps range separators out of the accessibility tree. |

### Behavioral notes

- Values use the `DateInputDateValue[]` shape from `@internationalized/date`, not strings.
- `onValueChange(details)` retains Ark's details object with `details.value` and `details.valueAsString`.
- `focused`, `defaultFocused`, and `onFocusChange(details)` control focus on the root.
- `placeholderValue`, `defaultPlaceholderValue`, and `onPlaceholderChange(details)` control the date used to fill empty segments.
- `selectionMode="range"` enables indexed segment groups and automatic native inputs.
- `shouldForceLeadingZeros` controls whether numeric segments are padded.
- `min`, `max`, `isDateUnavailable`, and `invalid` constrain and report date validity.
- `locale`, `timeZone`, `hourCycle`, `granularity`, `formatter`, `format`, `translations`, `dir`, and
  `createCalendar` are passed through to Ark. For time-only input, use a time-only formatter with
  `granularity="minute"` or `"second"`.
- Import `useDateInput()`, `useDateInputContext()`, and `DateInputDateValue` from `@moduix/react`.
  Use `DateInput.Context` or `useDateInputContext()` to read root state from inside the component tree,
  and use `DateInput.SegmentContext` for custom segment rendering. Direct Ark imports are for lower-level
  types and helpers that moduix does not export.

### Styling hooks

- `data-slot="date-input-root"` on the root.
- `data-slot="date-input-label"` on the label.
- `data-slot="date-input-control"` on the visual frame.
- `data-slot="date-input-segment-group"` on each segment group.
- `data-slot="date-input-segment"` on editable and fixed segments.
- `data-slot="date-input-hidden-input"` on the hidden native input.
- `data-slot="date-input-separator"` on moduix range separator sugar.
- Ark state attributes include `data-disabled`, `data-readonly`, `data-invalid`, `data-focus` on
  control and segment groups, `data-type`, `data-editable`, and `data-placeholder-shown`.
