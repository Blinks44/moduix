## Usage

<Usage />

`DateInput` renders locale-aware date segments that users can edit with the keyboard. Put
`DateInputSegments` inside `DateInputControl` for the standard composition.

## Choosing the right component

- Choose **`Input`** for plain text values.
- Choose **`DateInput`** when users need keyboard-editable date segments.
- Choose **`DatePicker`** when users need a popup or inline calendar. `DateInput` is keyboard-first and
  does not include a calendar.

## Composition

Use `DateInput` with `DateInputControl` and `DateInputSegments` for the standard field. Keep the
state uncontrolled with `defaultValue`, control it with `value` and `onValueChange(details)`, or
create it with `useDateInput()` and connect the parts through `DateInputRootProvider`. In Vue, use
`v-model` for the controlled value; in Svelte, use `bind:value`. Values use
the `DateInputDateValue[]` shape from `@internationalized/date`, not strings.

`DateInputHiddenInput` is explicit because the root does not add native inputs. Render one hidden
input for each submitted date and use matching `index` values for a range. Use
`DateInputSegmentGroup`, `DateInputSegmentContext`, and `DateInputSegment` only when the default
`DateInputSegments` rendering is not enough.

## Styling

Use `className` in React or `class` in Solid, Vue, and Svelte on exported parts for structural styles. Tailwind
variants use native utilities and consumer classes. CSS Modules variants also expose the component
variables below. Data attributes and `data-slot` hooks are shared by both styling tracks.

The root is sized to its content and the control fills it. To stretch the input in a form, set
`--moduix-date-input-width: 100%` in CSS Modules or add `w-full` to the root in Tailwind.

  `data-placeholder-shown` on segments.

## Keyboard

| Key | Action |
| --- | --- |
| `ArrowLeft` / `ArrowRight` | Moves to the previous or next segment. |
| `ArrowUp` / `ArrowDown` | Increases or decreases the focused segment. |
| Digits | Type the value and move to the next segment. |
| `Backspace` | Clears the focused segment. |

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `DateValue[]` | — | Selected dates for controlled use. |
| `defaultValue` | `DateValue[]` | — | Initial selected dates. |
| `onValueChange` | `(details: ValueChangeDetails) => void` | — | Called when the selected dates change. |
| `min` | `DateValue` | — | Earliest selectable date. |
| `max` | `DateValue` | — | Latest selectable date. |
| `isDateUnavailable` | `(date: DateValue, locale: string) => boolean` | — | Returns `true` for dates that cannot be picked. |
| `granularity` | `'day' \| 'hour' \| 'minute' \| 'second'` | `'day'` | Smallest editable unit: `day`, `hour`, `minute`, or `second`. |
| `selectionMode` | `'single' \| 'range'` | `'single'` | `single` date or a `range`. |
| `locale` | `string` | `'en-US'` | Locale for formatting; defaults to the nearest `LocaleProvider`. |
| `timeZone` | `string` | `'UTC'` | Time zone used for dates. |
| `hourCycle` | `12 \| 24` | — | 12- or 24-hour time. |
| `shouldForceLeadingZeros` | `boolean` | `false` | Always pads month, day, and hour with a zero. |
| `name` | `string` | — | Form field name of the underlying input. |
| `disabled` | `boolean` | `false` | Disables the control. |
| `readOnly` | `boolean` | `false` | Shows the value but prevents changes. |
| `invalid` | `boolean` | `false` | Marks the control as invalid. |
| `required` | `boolean` | `false` | Requires a value before form submission. |
| `createCalendar` | `(identifier: CalendarIdentifier) => Calendar` | — | Creates a non-Gregorian calendar system. |
| `translations` | `IntlTranslations` | — | Localized strings for accessibility labels. |
| `form` | `string` | — | Id of the form the underlying input belongs to. |
| `placeholderValue` | `DateValue` | — | Date shown in empty segments, for controlled use. |
| `defaultPlaceholderValue` | `DateValue` | — | Initial date shown in empty segments. |
| `onPlaceholderChange` | `(details: PlaceholderChangeDetails) => void` | — | Called when the placeholder date changes. |
| `onFocusChange` | `(details: FocusChangeDetails) => void` | — | Called when the input gains or loses focus. |
| `hideTimeZone` | `boolean` | `false` | Hides the time zone segment of a `ZonedDateTime`. |
| `formatter` | `DateFormatter` | — | Custom `DateFormatter` for the segments. |
| `allSegments` | `Segments` | — | Segment map computed for a custom formatter. |
| `format` | `(date: DateValue, details: FormatDateDetails) => string` | — | Converts a date to the hidden input value. |
