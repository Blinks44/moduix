## When to use it

Use `Format.Time` when you need to display a clock time according to the active locale: in schedules, activity feeds,
support hours, and other user-facing UI. It accepts a `Date` object or a time string in `HH:mm` or `HH:mm:ss` form.

Use a string for a wall-clock time from a schedule that should not change with the time zone. Use a `Date` when the
value represents a specific moment.

Import `Format` directly from Ark UI:

```tsx
import { Format } from '@ark-ui/react';
```

## 12-hour format, seconds, and AM/PM labels

`Format.Time` uses the 24-hour format by default. Set `format="12h"` to use a 12-hour clock. Set `withSeconds` when
seconds matter, such as in a recent sync indicator. In 12-hour format, `amLabel` and `pmLabel` replace the default
day-period labels.

Do not add seconds to a schedule merely because the source includes them. Choose the precision people need to act on
the information.

## Locale and Date values

`Format.Time` reads its locale from `LocaleProvider`. moduix re-exports that provider, so it can be the shared locale
provider for your interface:

```tsx
import { Format } from '@ark-ui/react';
import { LocaleProvider } from '@moduix/react/locale';

export function LocalizedTime() {
  return (
    <LocaleProvider locale="fr-FR">
      <Format.Time value="17:15" />
    </LocaleProvider>
  );
}
```

Use a `Date` when you already have a date-time value, for example a timestamp received from an API:

```tsx
import { Format } from '@ark-ui/react';

export function UpdatedAt({ value }: { value: Date }) {
  return <Format.Time value={value} />;
}
```

For a `Date`, `Format.Time` uses the runtime’s local time zone to determine the displayed clock time. `LocaleProvider`
sets the locale, not the time zone. Do not replace a schedule’s plain local time with a `Date` unless that conversion is
intended.

## Using moduix

`Format.Time` renders text only. Use moduix `Card`, `Stack`, `Text`, and status components around it to explain what the
time means; do not create a wrapper just to call the formatter.

## Ownership

Ark UI provides time formatting and the `Format.Time` API. moduix supplies the surrounding interface components and
re-exports `LocaleProvider`, but does not re-export `Format.Time`.
