## Basic

Pass a string in `HH:mm` or `HH:mm:ss` form for a wall-clock value such as a scheduled departure. A string is not
converted between time zones.

## Formatting options

The default format is 24-hour. Set `format="12h"` for a 12-hour clock, `withSeconds` to include seconds, and
`amLabel` or `pmLabel` to replace the day-period labels in 12-hour output.

<Example name="format-time/seconds-and-labels" />

Use seconds only when they help people act on the information. Do not add them to a schedule just because the source
data contains them.

## Locale and date values

`Format.Time` reads the locale from the nearest `LocaleProvider`. Without one, Ark UI uses `en-US`. Use a `Date` when
the value represents a specific moment, such as an API timestamp. Its displayed clock time uses the runtime's local
time zone. `LocaleProvider` changes the locale, not the time zone.

Keep scheduled wall-clock times as strings. Pass a `Date` only when the time-zone conversion is intended.
