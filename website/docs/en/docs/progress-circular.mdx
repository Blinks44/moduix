## Choosing the right component

Use `ProgressCircular` for compact progress feedback in inline content, cards, toolbar badges, and
small dashboards. Use `ProgressLinear` when progress is easier to compare on a horizontal track.

## Basic

Use `ProgressCircular.Ring` to render the standard circle with its track and range. Add
`ProgressCircular.ValueText` to show the current value. The example wraps the circle and value text
so the value appears in the center. Give `Ring` an `aria-label` that names the task and matches the
visible label.

## Anatomy

```text
ProgressCircular / ProgressCircular.Root
├─ ProgressCircular.Label
├─ ProgressCircular.Circle
│  ├─ ProgressCircular.CircleTrack
│  └─ ProgressCircular.CircleRange
├─ ProgressCircular.Ring
│  └─ fixed Circle, CircleTrack, and CircleRange subtree
├─ ProgressCircular.ValueText
└─ ProgressCircular.View

ProgressCircular.RootProvider
└─ same part tree connected to ProgressCircular.useProgress()
```

| Part                                         | Role                                                                                       |
| -------------------------------------------- | ------------------------------------------------------------------------------------------ |
| `ProgressCircular` / `ProgressCircular.Root` | Owns progress state, formatting, and generated ids.                                        |
| `ProgressCircular.RootProvider`              | Connects parts to state created with `ProgressCircular.useProgress()`.                     |
| `ProgressCircular.Context`                   | Exposes the current progress state through a render prop.                                  |
| `ProgressCircular.Label`                     | Provides visible context for the progress indicator.                                      |
| `ProgressCircular.Ring`                      | Convenience part that renders the default circle, track, and range.                       |
| `ProgressCircular.Circle`                    | SVG progressbar element with Ark's role and ARIA value attributes.                         |
| `ProgressCircular.CircleTrack`               | Background circle.                                                                         |
| `ProgressCircular.CircleRange`               | Foreground circle that reflects the current progress or indeterminate state.               |
| `ProgressCircular.ValueText`                 | Displays the formatted value and announces updates.                                      |
| `ProgressCircular.View`                      | Renders content for `indeterminate`, `loading`, or `complete`.                             |

## Composition

### Recommended composition

`ProgressCircular` is the shorthand root and is equivalent to `ProgressCircular.Root`. For the
standard circle, use `ProgressCircular.Ring`; it renders `Circle`, `CircleTrack`, and `CircleRange`
for you. `Ring` accepts `className`, ARIA props, and the same CSS variables as `Circle`.

Use `defaultValue` for uncontrolled progress. Use `value` with `onValueChange(details)` for
controlled progress. Set `defaultValue={null}` or `value={null}` when progress cannot be measured
yet.

### When to go custom

Use `translations.value(details)` to provide Ark with a task-specific accessible name when `Ring`
or `Circle` does not have an explicit `aria-label`. This only changes the accessible name. To show
the same wording in the UI, render `ValueText` inside `ProgressCircular.Context` and pass
`progress.valueAsString` as its child. To center it, wrap the circle and value text in a layout
element of your choice.

Use `Circle`, `CircleTrack`, and `CircleRange` when you need to change the SVG structure or use
Ark's `asChild` composition. Use `ids` when a custom tree needs stable, explicit IDs for the root,
label, or circle. Use `ProgressCircular.useProgress()` with `RootProvider` when progress state
needs to be created outside the rendered tree or shared with another component. Use
`ProgressCircular.useProgressContext()` below a root or provider when a custom component needs the
current state. Use direct Ark imports only for integrations that cannot use the moduix API.

### Default props

| Prop            | Default                | Notes                                                       |
| --------------- | ---------------------- | ----------------------------------------------------------- |
| `defaultValue`  | `50`                   | Initial uncontrolled value.                                 |
| `min`           | `0`                    | Lower bound for percent and ARIA value.                     |
| `max`           | `100`                  | Upper bound for percent and ARIA value.                     |
| `formatOptions` | `{ style: 'percent' }` | Controls `ValueText` formatting.                            |
| `locale`        | `'en-US'`              | Locale used by `Intl.NumberFormat`.                         |
| `orientation`   | `'horizontal'`         | Ark orientation. Usually leave it horizontal for a circle. |

### Behavioral notes

`ProgressCircular.Circle` receives the `progressbar` role and ARIA value attributes from Ark.
`ProgressCircular.Label` provides visible context, but it does not automatically name the circle.
Give `Ring` or `Circle` an `aria-label` or `aria-labelledby` that identifies the task. Ark also
sets the SVG variables for radius, circumference, percent, and stroke offset.

All exported Ark parts except `Ring` support `asChild` through polymorphic composition. When you
replace a rendered element, keep it semantic and preserve the progressbar semantics on the circle.

`ProgressCircular.ValueText` announces changes with `aria-live="polite"`. Keep a visible label in
the tree, or provide `aria-label`/`aria-labelledby` when composing without
`ProgressCircular.Label`.

## Styling

Use `className` on exported parts for structural styling. For state-based styles, use Ark data
attributes, Ark SVG variables, and moduix `data-slot` hooks.

Use `--moduix-progress-circular-range-indeterminate-bg` to give indeterminate progress a different
semantic color from determinate progress. When reduced motion is preferred, the range neither
transitions nor spins. Use `--moduix-progress-circular-range-indeterminate-reduced-motion-dasharray`
to keep a visible static cue.

### Styling hooks

- `data-slot="progress-circular-root"`, `data-slot="progress-circular-root-provider"`,
  `data-slot="progress-circular-label"`, `data-slot="progress-circular-circle"`,
  `data-slot="progress-circular-circle-track"`, `data-slot="progress-circular-circle-range"`,
  `data-slot="progress-circular-value-text"`, and `data-slot="progress-circular-view"`.
- `ProgressCircular.Ring` shares `ProgressCircular.Circle`'s `data-slot`, `className`, ref, and
  `--moduix-progress-circular-*` size and thickness variables.
- Ark hooks: `data-scope="progress"`, `data-part`, `data-state="indeterminate|loading|complete"`,
  `data-orientation`, `data-value`, and `data-max`.
- Ark circle variables: `--size`, `--thickness`, `--radius`, `--circumference`, `--percent`, and
  `--offset`.
