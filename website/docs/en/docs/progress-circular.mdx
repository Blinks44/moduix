## Choosing the right component

Use `ProgressCircular` for compact progress feedback in inline content, cards, toolbar badges, and
small dashboards. Use `ProgressLinear` when progress is easier to compare on a horizontal track.

## Basic


Use `ProgressCircularRing` to render the standard circle with its track and range. Add
`ProgressCircularValueText` to show the current value. The example wraps the circle and value text
so the value appears in the center. Give `ProgressCircularRing` an `aria-label` that names the task and matches the
visible label.

## Anatomy

```text
ProgressCircular
├─ ProgressCircularLabel
├─ ProgressCircularCircle
│  ├─ ProgressCircularCircleTrack
│  └─ ProgressCircularCircleRange
├─ ProgressCircularRing
│  └─ fixed ProgressCircularCircle, ProgressCircularCircleTrack, and ProgressCircularCircleRange subtree
├─ ProgressCircularValueText
└─ ProgressCircularView

ProgressCircularRootProvider
└─ same part tree connected to useProgress()
```

| Part                                         | Role                                                                                       |
| -------------------------------------------- | ------------------------------------------------------------------------------------------ |
| `ProgressCircular` | Owns progress state, formatting, and generated ids.                                        |
| `ProgressCircularRootProvider`              | Connects parts to state created with `useProgress()`.                     |
| `ProgressCircularContext`                   | Exposes the current progress state through a render prop.                                  |
| `ProgressCircularLabel`                     | Provides visible context for the progress indicator.                                       |
| `ProgressCircularRing`                      | Convenience part that renders the default circle, track, and range.                       |
| `ProgressCircularCircle`                    | SVG progressbar element with Ark's role and ARIA value attributes.                        |
| `ProgressCircularCircleTrack`               | Background circle.                                                                         |
| `ProgressCircularCircleRange`               | Foreground circle that reflects the current progress or indeterminate state.               |
| `ProgressCircularValueText`                 | Displays the formatted value and announces updates.                                       |
| `ProgressCircularView`                      | Renders content for `indeterminate`, `loading`, or `complete`.                             |

## Composition

Use `ProgressCircularRing` when the
standard circle is enough: it combines `ProgressCircularCircle`, `ProgressCircularCircleTrack`, and `ProgressCircularCircleRange`, but it does not
render or center `ProgressCircularValueText`. Keep the label, circle, and value text composition explicit when the
value should appear in the center.

Use `defaultValue` when the component owns progress state. Use `value` with
`onValueChange(details)` when the application owns it. Set `defaultValue={null}` or `value={null}`
for indeterminate progress. When state must be created outside the rendered tree, create it with
`useProgress()` and pass the store to `ProgressCircularRootProvider` instead of
rendering another root for the same store.

give `ProgressCircularCircleTrack` and `ProgressCircularCircleRange` their own classes, as in this example.

## Styling

Use `className` in React and `class` in Solid and Vue on exported parts for structural styling. Tailwind
variants use native utility classes and consumer class overrides. CSS Modules variants expose the
CSS variables below. For state-based styles, use Ark data attributes, Ark SVG variables, and moduix
`data-slot` hooks.

Indeterminate progress spins a quarter-circle arc. When reduced motion is preferred, the range
does not transition and the arc stays still. To give indeterminate progress its own color, style
`ProgressCircularCircleRange` with `[data-state='indeterminate']`.

### Styling hooks

- `data-slot="progress-circular-root"`, `data-slot="progress-circular-root-provider"`,
  `data-slot="progress-circular-label"`, `data-slot="progress-circular-circle"`,
  `data-slot="progress-circular-circle-track"`, `data-slot="progress-circular-circle-range"`,
  `data-slot="progress-circular-value-text"`, and `data-slot="progress-circular-view"`.
- `ProgressCircularRing` shares `ProgressCircularCircle`'s `data-slot`, `className`/`class`, ref, and
  `--moduix-progress-circular-*` size and thickness variables.
- Ark hooks: `data-scope="progress"`, `data-part`, `data-state="indeterminate|loading|complete"`,
  `data-orientation`, `data-value`, and `data-max`.
- Ark circle variables: `--size`, `--thickness`, `--radius`, `--circumference`, `--percent`, and
  `--offset`.
