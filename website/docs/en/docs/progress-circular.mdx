## Choosing the right component

Use `ProgressCircular` for compact status indicators in inline content, cards, toolbar badges, and
small dashboards. Use `ProgressLinear` when users need to compare progress against a horizontal
track.

## Basic

Use `ProgressCircular.Ring` for the standard SVG circle, track, and range. Add
`ProgressCircular.ValueText` when the current value should be visible. In this example, the wrapper
places the value in the center of the circle. Give `Ring` an `aria-label` that describes the task and
matches the visible label.

## Anatomy

```text
ProgressCircular / ProgressCircular.Root
├─ ProgressCircular.Label
├─ ProgressCircular.Circle
│  ├─ ProgressCircular.CircleTrack
│  └─ ProgressCircular.CircleRange
├─ ProgressCircular.Ring
│  └─ fixed Circle, CircleTrack, and CircleRange subtree
├─ ProgressCircular.ValueText
└─ ProgressCircular.View

ProgressCircular.RootProvider
└─ same part tree connected to ProgressCircular.useProgress()
```

| Part                                         | Role                                                                   |
| -------------------------------------------- | ---------------------------------------------------------------------- |
| `ProgressCircular` / `ProgressCircular.Root` | Owns progress state, formatting, and ids.                              |
| `ProgressCircular.RootProvider`              | Connects parts to state created with `ProgressCircular.useProgress()`. |
| `ProgressCircular.Context`                   | Passes the current progress state to a render prop.                    |
| `ProgressCircular.Label`                     | Adds visible context for the progressbar.                              |
| `ProgressCircular.Ring`                      | Convenience shorthand for the default circle, track, and range.        |
| `ProgressCircular.Circle`                    | SVG progressbar surface with its role and ARIA value attributes.       |
| `ProgressCircular.CircleTrack`               | Background circle.                                                     |
| `ProgressCircular.CircleRange`               | Foreground circle that reflects the current percent or state.          |
| `ProgressCircular.ValueText`                 | Displays the formatted value and announces its changes.               |
| `ProgressCircular.View`                      | Displays content for `indeterminate`, `loading`, or `complete`.        |

## Composition

### Recommended composition

`ProgressCircular` is the shorthand root component and is equivalent to `ProgressCircular.Root`.
Use `ProgressCircular.Ring` for the standard circle, track, and range. It accepts `className`, ARIA
props, and the same CSS variables as `ProgressCircular.Circle`.

Use `defaultValue` for uncontrolled progress. Use `value` with `onValueChange(details)` for
controlled progress. Set `defaultValue={null}` or `value={null}` when the task's completion is
unknown.

### When to go custom

Use `translations.value(details)` to customize Ark's generated accessible name when `Ring` or
`Circle` does not have an explicit `aria-label`. To show the same text in the UI, render `ValueText`
inside `ProgressCircular.Context` and pass `progress.valueAsString` as its child. If the value should
appear in the center of the circle, wrap the circle and value text in a layout element of your choice.

Use `Circle`, `CircleTrack`, and `CircleRange` when you need to change the SVG structure or use
Ark's `asChild` composition. Use `ids` when the label, circle, or surrounding layout need stable,
explicit IDs in a custom tree. Use `ProgressCircular.useProgress()` with `RootProvider` when another
component needs to create or control the state outside the rendered tree. Use
`ProgressCircular.useProgressContext()` below a root or provider when a custom component needs the
current state. Reserve direct Ark imports for integrations that cannot use the moduix API.

### Default props

| Prop            | Default                | Notes                                   |
| --------------- | ---------------------- | --------------------------------------- |
| `defaultValue`  | `50`                   | Starting value for uncontrolled progress.  |
| `min`           | `0`                    | Minimum used for the percent and ARIA value. |
| `max`           | `100`                  | Maximum used for the percent and ARIA value. |
| `formatOptions` | `{ style: 'percent' }` | Options used to format `ValueText`.         |
| `locale`        | `'en-US'`              | Locale passed to `Intl.NumberFormat`.       |

### Behavioral notes

`ProgressCircular.Circle` receives the progressbar role and ARIA value attributes from Ark. Give
`Ring` or `Circle` an `aria-label` that names the task. `ProgressCircular.Label` adds visible
context, but it does not automatically associate that text with the circle. Ark also manages the
SVG variables for radius, circumference, percent, and stroke offset.

All Ark-backed parts except `Ring` support `asChild` through polymorphic composition. Keep replacement
children semantic and preserve the progressbar semantics on the circle.

`ProgressCircular.ValueText` announces changes with `aria-live="polite"`. Keep a visible label in the
tree, or provide `aria-label`/`aria-labelledby` when composing without `ProgressCircular.Label`.

## Styling

Use `className` on exported parts for structural styling. For state-based styles, use Ark data
attributes, Ark SVG variables, and moduix `data-slot` hooks.

Use `--moduix-progress-circular-range-indeterminate-bg` to give indeterminate progress a different
semantic color from determinate progress. When reduced motion is preferred, the range neither
transitions nor spins. Use the reduced-motion dash-pattern variable to keep a visible static cue.

### Styling hooks

- `data-slot="progress-circular-root"`, `progress-circular-root-provider`,
  `progress-circular-label`, `progress-circular-circle`, `progress-circular-circle-track`,
  `progress-circular-circle-range`, `progress-circular-value-text`, and `progress-circular-view`.
- `ProgressCircular.Ring` shares `ProgressCircular.Circle`'s `data-slot`, `className`, ref, and
  `--moduix-progress-circular-*` size and thickness variables.
- Ark hooks: `data-scope="progress"`, `data-part`, `data-state="indeterminate|loading|complete"`,
  `data-orientation`, `data-value`, and `data-max`.
- Ark circle variables: `--size`, `--thickness`, `--radius`, `--circumference`, `--percent`, and
  `--offset`.
