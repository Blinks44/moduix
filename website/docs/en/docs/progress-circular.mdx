## Usage

<Usage />

Use `ProgressCircularRing` to render the standard circle with its track and range. Add
`ProgressCircularValueText` to show the current value. The example wraps the circle and value text
so the value appears in the center. Give `ProgressCircularRing` an `aria-label` that names the task and matches the
visible label.

## Choosing the right component

Use `ProgressCircular` for compact progress feedback in inline content, cards, toolbar badges, and
small dashboards. Use `ProgressLinear` when progress is easier to compare on a horizontal track.

## Composition

Use `ProgressCircularRing` when the
standard circle is enough: it combines `ProgressCircularCircle`, `ProgressCircularCircleTrack`, and `ProgressCircularCircleRange`, but it does not
render or center `ProgressCircularValueText`. Keep the label, circle, and value text composition explicit when the
value should appear in the center.

Use `defaultValue` when the component manages progress state. Use `value` with
`onValueChange(details)` when the application controls it. Set `defaultValue={null}` or `value={null}`
for indeterminate progress. When state must be created outside the rendered tree, create it with
`useProgress()` and pass the store to `ProgressCircularRootProvider` instead of
rendering another root for the same store.

## Styling

Use `className` in React and `class` in Solid, Vue, and Svelte on exported parts for structural styling. Tailwind
variants use native utility classes and consumer class overrides. CSS Modules variants expose the
CSS variables below. For state-based styles, use Ark data attributes, Ark SVG variables, and moduix
`data-slot` hooks.

Indeterminate progress spins a quarter-circle arc. When reduced motion is preferred, the range
does not transition and the arc stays still. To give indeterminate progress its own color, style
`ProgressCircularCircleRange` with `[data-state='indeterminate']`.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `number \| null` | — | Progress value for controlled use; `null` shows an indeterminate state. |
| `defaultValue` | `number \| null` | `50` | Initial value when it is not controlled; `null` is indeterminate. |
| `onValueChange` | `(details: ValueChangeDetails) => void` | — | Called when the value changes. |
| `min` | `number` | `0` | Minimum value. |
| `max` | `number` | `100` | Maximum value. |
| `formatOptions` | `Intl.NumberFormatOptions` | `{ style: 'percent' }` | `Intl.NumberFormat` options for the value text. |
| `locale` | `string` | — | Locale for number formatting; defaults to the nearest `LocaleProvider`. |
| `translations` | `IntlTranslations` | — | Localized strings for accessibility labels. |
