# Vite

This guide assumes an app created from Vite's React, React + TypeScript, Solid, or Solid + TypeScript
template. If you are starting from scratch, create the app with Vite and choose the matching runtime.

The examples below use the CSS Modules packages, which contain the full component catalog. For a
component available in the Tailwind track, follow the [Tailwind package setup](/docs/quick-start#tailwind-package-setup)
and choose the matching React or Solid Tailwind package or registry.

## Install with the shadcn CLI

Complete the [shadcn CLI setup](/docs/quick-start#install-with-the-shadcn-cli), then map `@/*` to
`src/*`. Vite's TypeScript templates split their configuration between `tsconfig.json` and a
runtime-specific app config. Add the alias to both files:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Use the same `compilerOptions` values in `tsconfig.app.json`, then add the matching runtime alias to
Vite. This example imports `node:url`, so install Node.js types if the project does not already have
them:

<PackageManagerTabs command="install -D @types/node" />

<Tabs groupId="framework">
  <Tab label="React" value="react">

```ts title="vite.config.ts"
import { fileURLToPath, URL } from 'node:url';
import react from '@vitejs/plugin-react';
import { defineConfig } from 'vite';

export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url)),
    },
  },
});
```

<PackageManagerTabs command="shadcn@latest add @moduix-react/button" dlx />

  </Tab>
  <Tab label="Solid" value="solid">

```ts title="vite.config.ts"
import { fileURLToPath, URL } from 'node:url';
import { defineConfig } from 'vite';
import solid from 'vite-plugin-solid';

export default defineConfig({
  plugins: [solid()],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url)),
    },
  },
});
```

<PackageManagerTabs command="shadcn@latest add @moduix-solid/button" dlx />

  </Tab>
</Tabs>

## Verify

Start Vite. With the package workflow, a component imported from the selected moduix package should
render with its styles. With the shadcn workflow, both the generated stylesheet and
`@/components/ui/button` should resolve in the editor and the build.

See the official [Vite guide](https://vite.dev/guide/) for project creation and runtime templates.
