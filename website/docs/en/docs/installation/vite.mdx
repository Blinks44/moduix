# Vite

This guide assumes an existing app created from Vite's React or React + TypeScript template. If you are starting a
new project, follow the [Vite getting started guide](https://vite.dev/guide/) first.

## Install moduix as a package

<PackageManagerTabs command="install @moduix/react @ark-ui/react" />

Import the foundation stylesheet once from `src/main.tsx`:

```tsx title="src/main.tsx"
import '@moduix/react/style.css';
```

Then import components from their package subpaths:

```tsx title="src/App.tsx"
import { Button } from '@moduix/react/button';

export function App() {
  return <Button>Continue</Button>;
}
```

## Install with the shadcn CLI

Complete the [shadcn CLI setup](/docs/quick-start#install-with-the-shadcn-cli), then map `@/*` to `src/*`. Vite's
TypeScript template splits its configuration across `tsconfig.json` and `tsconfig.app.json`. Add the alias to both
files and add the matching runtime alias to `vite.config.ts`.

Add these properties to the existing `compilerOptions` object in `tsconfig.json`:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Add the same properties to `compilerOptions` in `tsconfig.app.json`:

```json title="tsconfig.app.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Add the corresponding alias to `vite.config.ts`. Vite expects an absolute file-system path for an alias, so this
example resolves `@` to the app's `src` directory:

This configuration imports `node:url`. If your project does not already include the Node.js types, install them as a
development dependency:

<PackageManagerTabs command="install -D @types/node" />

```ts title="vite.config.ts"
import { fileURLToPath, URL } from 'node:url';
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';

export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url)),
    },
  },
});
```

Once the alias is configured, add a component from the moduix registry:

<PackageManagerTabs command="shadcn@latest add @moduix-react/button" dlx />

Import the generated foundation stylesheet in `src/main.tsx` instead of the package stylesheet. Do not import both:

```tsx title="src/main.tsx"
import '@/lib/moduix/styles/style.css';
```

Import the generated component from your application source:

```tsx title="src/App.tsx"
import { Button } from '@/components/moduix/button';

export function App() {
  return <Button>Continue</Button>;
}
```

## Verify

Start Vite's development server. With the package install, the button imported from `@moduix/react/button` should
render with moduix styles. With the shadcn CLI setup, the generated stylesheet and the import from
`@/components/moduix/button` should resolve in the editor and during the build.

See the [Vite guide](https://vite.dev/guide/) for the framework's complete setup.
