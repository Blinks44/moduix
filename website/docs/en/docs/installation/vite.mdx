# Vite

This guide assumes an existing app created from Vite's React, React + TypeScript, Solid, or Solid +
TypeScript template.


## Choose your setup

- **Runtime:** React or Solid with the matching Vite plugin.
- **Styling:** CSS Modules or Tailwind CSS v4.
- **Distribution:** a package or source copied with the shadcn CLI.

Complete the shared [package setup](/docs/quick-start#install-as-a-package) or
[shadcn setup](/docs/quick-start#install-with-the-shadcn-cli) for your styling track first. This page
uses CSS Modules package imports; Vite entry points and alias configuration stay the same with the
matching Tailwind package or registry.

The package setup below uses CSS Modules and includes the moduix reset. If you use the Tailwind
registry commands instead, keep the global stylesheet from
[Quick Start](/docs/quick-start#install-as-a-package) configured in your application.

## Install with the shadcn CLI

Complete the [shadcn CLI setup](/docs/quick-start#install-with-the-shadcn-cli), then map `@/*` to
`src/*`. Vite's TypeScript templates split their configuration between `tsconfig.json` and a
runtime-specific app config. Add the alias to both files:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Use the same `compilerOptions` values in `tsconfig.app.json`, then add the matching runtime alias to
Vite. This example imports `node:url`, so install Node.js types if the project does not already have
them:

<PackageManagerTabs command="install -D @types/node" />

<Tabs groupId="framework">
  <Tab label="React" value="react">

```ts title="vite.config.ts"
import { fileURLToPath, URL } from 'node:url';
import react from '@vitejs/plugin-react';
import { defineConfig } from 'vite';

export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url)),
    },
  },
});
```

<ShadcnInstallOptions

/>

## Verify

Start Vite. With the package workflow, a component imported from the selected moduix package should
render with its styles. With the shadcn workflow, both the generated stylesheet and
`@/components/ui/button` should resolve in the editor and the build.

See the official [Vite guide](https://vite.dev/guide/) for project creation and runtime templates.
