# Vite

This guide assumes an existing app created from Vite's React, React + TypeScript, Vue, Vue + TypeScript, Solid, or Solid +
TypeScript template.

## Choose your setup

- **Runtime:** React, Solid, or Vue with the matching Vite plugin.
- **Styling:** CSS Modules or Tailwind CSS v4.
- **Distribution:** a package or source copied with the shadcn CLI.

Quick Start covers [package choices](/docs/quick-start#install-as-a-package) and
[shadcn configuration](/docs/quick-start#install-with-the-shadcn-cli).

The examples below use CSS Modules with the moduix reset. Omit the reset if your app already
provides an equivalent one. For Tailwind, install the matching `-tailwind` package and import your
application’s Tailwind stylesheet at the same entry point, using the setup from Quick Start.

## Install with the shadcn CLI

Complete the [shadcn CLI setup](/docs/quick-start#install-with-the-shadcn-cli), then map `@/*` to
`src/*`. Vite's TypeScript templates split their configuration between `tsconfig.json` and a
runtime-specific app config. Add the alias to both files:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Keep the same `paths` in `tsconfig.app.json` for application type checking. In Vite 8 or later,
enable native TypeScript path resolution in the existing configuration. Keep the framework plugin
and other settings in place:

<Tabs groupId="framework">
  <Tab label="React" value="react">

```ts title="vite.config.ts"
import react from '@vitejs/plugin-react';
import { defineConfig } from 'vite';

export default defineConfig({
  plugins: [react()],
  resolve: {
    tsconfigPaths: true,
  },
});
```

For Vue, keep `src/**/*.vue` in the app configuration’s `include` so Vite can associate SFCs with
their TypeScript paths. For Vite 7 or earlier, use an explicit
[`resolve.alias`](https://vite.dev/config/shared-options#resolve-alias) instead.

Import the generated foundation stylesheet from the framework entry point instead of the package
stylesheet; do not import both:

<Tabs groupId="framework">
  <Tab label="React" value="react">

```tsx title="src/main.tsx"
import '@/lib/moduix/styles/style.css';
```

  </Tab>
  <Tab label="Solid" value="solid">

```tsx title="src/index.tsx"
import '@/lib/moduix/styles/style.css';
```

  </Tab>
  <Tab label="Vue" value="vue">

```ts title="src/main.ts"
import '@/lib/moduix/styles/style.css';
```

  </Tab>
</Tabs>

The stylesheet import above is for CSS Modules. For Tailwind, load the generated foundation from
your existing Tailwind stylesheet as shown in [Quick Start](/docs/quick-start#install-with-the-shadcn-cli),
and import that application stylesheet at the same entry point. Use the generated component import
`@/components/ui/button` in place of the package import.

## Verify

Start Vite. With the package workflow, a component imported from the selected moduix package should
render with its styles. With the shadcn workflow, both the generated stylesheet and
`@/components/ui/button` should resolve in the editor and the build.

See the official [Vite guide](https://vite.dev/guide/) for project creation and runtime templates.
