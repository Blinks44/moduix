# Next.js

moduix works with the Next.js App Router. Import the foundation stylesheet from the root layout, and
add a client boundary with the `'use client'` directive only where your composition needs client-side behavior.

## Install as a package

<PackageManagerTabs command="install @moduix/react @ark-ui/react" />

Import the foundation stylesheet once from the root layout:

```tsx title="app/layout.tsx"
import '@moduix/react/style.css';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  );
}
```

Components that only render markup can stay in a Server Component. Add the `'use client'` directive to your own
component when it owns state, effects, browser APIs, or event handlers:

```tsx title="app/continue-button.tsx"
'use client';

import { useState } from 'react';
import { Button } from '@moduix/react/button';

export function ContinueButton() {
  const [isComplete, setIsComplete] = useState(false);

  return (
    <Button type="button" onClick={() => setIsComplete(true)}>
      {isComplete ? 'Done' : 'Continue'}
    </Button>
  );
}
```

Render the client component from a Server Component:

```tsx title="app/page.tsx"
import { ContinueButton } from './continue-button';

export default function Page() {
  return (
    <main>
      <ContinueButton />
    </main>
  );
}
```

Server Components can render the surrounding markup and include `ContinueButton`. Pass serializable
data to a client component. Event handlers and other functions cannot cross the server/client boundary.

## Use the shadcn CLI

Choose this route when you want to copy moduix components into your application. Complete the
[shadcn CLI setup](/docs/quick-start#install-with-the-shadcn-cli) and set `"rsc": true` in
`components.json`.

Keep the default `@/*` alias from the Next.js starter. If your aliases are different, update
`components.json` and the paths to the generated files. Import the generated foundation stylesheet
from the root layout instead of importing `@moduix/react/style.css`:

```tsx title="app/layout.tsx"
import '@/lib/moduix/styles/style.css';
```

With `rsc: true`, the shadcn CLI preserves an existing `'use client'` directive in a registry
component's source file. It does not infer whether a copied component or your own wrapper needs one.
Add the directive to your wrapper when it owns state, effects, browser APIs, or event handlers.

## Verify

The integration is working when moduix styles are applied on the initial render, interactive
components work after hydration, and Next.js reports no server/client boundary errors or hydration errors.

See the Next.js guides for [CSS](https://nextjs.org/docs/app/getting-started/css) and the
[`use client` directive](https://nextjs.org/docs/app/api-reference/directives/use-client).
