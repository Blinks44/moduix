# Next.js

This guide assumes an existing Next.js project using the App Router. Import the foundation
stylesheet from the root layout, and add a client boundary with the `'use client'` directive only
where your composition needs client-side behavior.

## Choose your setup

- **Runtime:** React with the Next.js App Router.
- **Styling:** CSS Modules or Tailwind CSS v4.
- **Distribution:** a package or source copied with the shadcn CLI.

Quick Start covers [package choices](/docs/quick-start#install-as-a-package) and
[shadcn configuration](/docs/quick-start#install-with-the-shadcn-cli).

The examples below use CSS Modules with the moduix reset. Omit the reset if your app already
provides an equivalent one. For Tailwind, install the matching `-tailwind` package and import your
application’s Tailwind stylesheet at the same entry point, using the setup from Quick Start.

## Install as a package

<PackageManagerTabs command="install @moduix/react @ark-ui/react" />

Import the foundation stylesheet once from the root layout:

```tsx title="app/layout.tsx"
import '@moduix/react/reset.css';
import '@moduix/react/style.css';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  );
}
```

Components that only render markup can stay in a Server Component. Add the `'use client'` directive to your own
component when it owns state, effects, browser APIs, or event handlers:

```tsx title="app/continue-button.tsx"
'use client';

import { useState } from 'react';
import { Button } from '@moduix/react/button';

export function ContinueButton() {
  const [isComplete, setIsComplete] = useState(false);

  return (
    <Button type="button" onClick={() => setIsComplete(true)}>
      {isComplete ? 'Done' : 'Continue'}
    </Button>
  );
}
```

Render the client component from a Server Component:

```tsx title="app/page.tsx"
import { ContinueButton } from './continue-button';

export default function Page() {
  return (
    <main>
      <ContinueButton />
    </main>
  );
}
```

moduix modules that need client behavior carry their own `'use client'` directive in both package
and registry source. A Server Component can render them with serializable props; your own component
needs a client boundary when it supplies event handlers or render functions.

## Install with the shadcn CLI

Choose this route when you want to copy moduix components into your application. Complete the
[shadcn CLI setup](/docs/quick-start#install-with-the-shadcn-cli) and set `"rsc": true` in
`components.json`.

Keep the default `@/*` alias from the Next.js starter. If your aliases are different, update
`components.json` and the paths to the generated files. Import the generated foundation stylesheet
from the root layout instead of importing `@moduix/react/style.css`:

<ShadcnInstallOptions
  options={[
    { label: 'CSS Modules', command: 'shadcn@latest add @moduix-react/button' },
    { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-react-tailwind/button' },
  ]}
/>

```tsx title="app/layout.tsx"
import '@/lib/moduix/styles/style.css';
```

The stylesheet import above is for CSS Modules. For Tailwind, load the generated foundation from
your existing Tailwind stylesheet as shown in [Quick Start](/docs/quick-start#install-with-the-shadcn-cli),
and import that application stylesheet at the same entry point. Use the generated component import
`@/components/ui/button` in place of the package import.

With `rsc: true`, the shadcn CLI preserves an existing `'use client'` directive in a registry
component's source file. It does not infer whether a copied component or your own wrapper needs one.
Add the directive to your wrapper when it owns state, effects, browser APIs, or event handlers.

## Verify

The integration is working when moduix styles are applied on the initial render, interactive
components work after hydration, and Next.js reports no server/client boundary errors or hydration errors.

See the Next.js guides for [CSS](https://nextjs.org/docs/app/getting-started/css) and the
[`use client` directive](https://nextjs.org/docs/app/api-reference/directives/use-client).
