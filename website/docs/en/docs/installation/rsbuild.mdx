# Rsbuild

This guide assumes an existing Rsbuild app configured for React or Solid. Rsbuild honors TypeScript
path aliases automatically, so the shadcn setup does not need a second `resolve.alias` entry.

The examples below use the CSS Modules packages, which contain the full component catalog. For a
component available in the Tailwind track, follow the [Tailwind package setup](/docs/quick-start#tailwind-package-setup)
and choose the matching React or Solid Tailwind package or registry.

```ts title="rsbuild.config.ts"
import { pluginBabel } from '@rsbuild/plugin-babel';
import { pluginSolid } from '@rsbuild/plugin-solid';
import { defineConfig } from '@rsbuild/core';

export default defineConfig({
  plugins: [
    pluginBabel({
      include: /\.(?:jsx|tsx)$/,
    }),
    pluginSolid(),
  ],
});
```

## Install with the shadcn CLI

First complete the [shadcn CLI setup](/docs/quick-start#install-with-the-shadcn-cli), then map `@/*`
to `src/*` in `tsconfig.json`:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Rsbuild reads `compilerOptions.paths` automatically. Add the component for your runtime:

<PackageManagerTabs command="shadcn@latest add @moduix-react/button" dlx />

Replace the package stylesheet import with the generated stylesheet; do not import both:

```tsx title="src/index.tsx"
import '@/lib/moduix/styles/style.css';
```

## Verify

Start the development server. A moduix component should render with its styles, and both TypeScript
and Rsbuild should resolve `@/components/ui/*` after a registry install.

See the Rsbuild [React guide](https://rsbuild.rs/guide/framework/react) or the official
[Solid plugin guide](https://rsbuild.rs/plugins/list/plugin-solid) for runtime-specific setup.
