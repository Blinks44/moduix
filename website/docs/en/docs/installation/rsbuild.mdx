# Rsbuild

This guide assumes you already have a React app built with Rsbuild. If you are starting from scratch, follow the
[Rsbuild quick start](https://rsbuild.rs/guide/start/quick-start) first. Rsbuild automatically honors TypeScript path
aliases, so the shadcn CLI setup does not need a separate `resolve.alias` entry.

## Install the package

<PackageManagerTabs command="install @moduix/react @ark-ui/react" />

Import the shared stylesheet once from your application entry point:

```tsx title="src/index.tsx"
import '@moduix/react/style.css';
```

Import each component from its package subpath:

```tsx title="src/App.tsx"
import { Button } from '@moduix/react/button';

export function App() {
  return <Button>Continue</Button>;
}
```

## Install with the shadcn CLI

First follow the [shadcn CLI setup](/docs/quick-start#install-with-the-shadcn-cli), then add the `@/*` path alias to
`tsconfig.json`:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Rsbuild reads `compilerOptions.paths` automatically, so you do not need to duplicate this alias in
`resolve.alias` inside `rsbuild.config.ts`. Replace the package stylesheet import with the generated stylesheet below;
do not import both:

```tsx title="src/index.tsx"
import '@/lib/moduix/styles/style.css';
```

## Verify

Start the Rsbuild development server. The integration is working when a component renders with moduix styles and both
TypeScript and Rsbuild resolve `@/components/moduix/*`.

For the complete Rsbuild setup, including how to create a React app, see the [Rsbuild quick start](https://rsbuild.rs/guide/start/quick-start)
and [React guide](https://rsbuild.rs/guide/framework/react).
