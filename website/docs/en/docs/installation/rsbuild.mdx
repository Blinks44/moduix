# Rsbuild

This guide assumes an existing Rsbuild app configured for React or Solid. Rsbuild honors TypeScript
path aliases automatically, so the shadcn setup does not need a second `resolve.alias` entry.


## Choose your setup

- **Runtime:** React or Solid with the matching Rsbuild plugin.
- **Styling:** CSS Modules or Tailwind CSS v4.
- **Distribution:** a package or source copied with the shadcn CLI.

Complete the shared [package setup](/docs/quick-start#install-as-a-package) or
[shadcn setup](/docs/quick-start#install-with-the-shadcn-cli) for your styling track first. This page
uses CSS Modules package imports; Rsbuild entry points and TypeScript alias handling stay the same
with the matching Tailwind package or registry.

The package setup below uses CSS Modules and includes the moduix reset. If you use the Tailwind
registry commands instead, keep the global stylesheet from
[Quick Start](/docs/quick-start#install-as-a-package) configured in your application.

## Install with the shadcn CLI

First complete the [shadcn CLI setup](/docs/quick-start#install-with-the-shadcn-cli), then map `@/*`
to `src/*` in `tsconfig.json`:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Rsbuild reads `compilerOptions.paths` automatically. Add the component for your runtime:

<Tabs groupId="framework">
  <Tab label="React" value="react">

<ShadcnInstallOptions
  options={[
    { label: 'CSS Modules', command: 'shadcn@latest add @moduix-react/button' },
    { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-react-tailwind/button' },
  ]}
/>

  </Tab>
  <Tab label="Solid" value="solid">

<ShadcnInstallOptions
  options={[
    { label: 'CSS Modules', command: 'shadcn@latest add @moduix-solid/button' },
    { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-solid-tailwind/button' },
  ]}
/>

  </Tab>
</Tabs>

Replace the package stylesheet import with the generated stylesheet; do not import both:

```tsx title="src/index.tsx"
import '@/lib/moduix/styles/style.css';
```

## Verify

Start the development server. A moduix component should render with its styles, and both TypeScript
and Rsbuild should resolve `@/components/ui/*` after a registry install.

See the Rsbuild [React guide](https://rsbuild.rs/guide/framework/react) or the official
[Solid plugin guide](https://rsbuild.rs/plugins/list/plugin-solid) for runtime-specific setup.
