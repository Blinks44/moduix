# Astro

Astro can render moduix components through its official React and Solid integrations. Components are
rendered as static HTML by default; add a `client:*` directive when they need to become interactive in
the browser.

The examples below use the CSS Modules packages, which contain the full component catalog. For a
component available in the Tailwind track, follow the [Tailwind package setup](/docs/quick-start#tailwind-package-setup)
and choose the matching React or Solid Tailwind package or registry.

## Add your framework to Astro

Run the command for the runtime used by your components:

<Tabs groupId="framework">
  <Tab label="React" value="react">

```bash
npx astro add react
```

This installs and configures `@astrojs/react`.

  </Tab>
  <Tab label="Solid" value="solid">

```bash
npx astro add solid
```

This installs and configures `@astrojs/solid-js`.

  </Tab>
</Tabs>

## Install moduix

Install the framework-native package and its Ark UI peer dependency:

<Tabs groupId="framework">
  <Tab label="React" value="react">

<PackageManagerTabs command="install @moduix/react @ark-ui/react" />

  </Tab>
  <Tab label="Solid" value="solid">

<PackageManagerTabs command="install @moduix/solid @ark-ui/solid solid-js" />

  </Tab>
</Tabs>

Import the foundation stylesheet once in a shared layout:

<Tabs groupId="framework">
  <Tab label="React" value="react">

```astro title="src/layouts/Layout.astro"
---
import '@moduix/react/style.css';
---

<html lang="en">
  <body><slot /></body>
</html>
```

  </Tab>
  <Tab label="Solid" value="solid">

```astro title="src/layouts/Layout.astro"
---
import '@moduix/solid/style.css';
---

<html lang="en">
  <body><slot /></body>
</html>
```

  </Tab>
</Tabs>

Create a framework component:

<Tabs groupId="framework">
  <Tab label="React" value="react">

```tsx title="src/components/ContinueButton.tsx"
import { Button } from '@moduix/react/button';

export function ContinueButton() {
  return <Button>Continue</Button>;
}
```

  </Tab>
  <Tab label="Solid" value="solid">

```tsx title="src/components/ContinueButton.tsx"
import { Button } from '@moduix/solid/button';

export function ContinueButton() {
  return <Button>Continue</Button>;
}
```

  </Tab>
</Tabs>

Import it directly into an Astro page and add a client directive:

```astro title="src/pages/index.astro"
---
import { ContinueButton } from '../components/ContinueButton';
---

<ContinueButton client:load />
```

Without a `client:*` directive, Astro sends static HTML without the component's client-side
JavaScript. Use `client:load` for immediately visible controls, `client:idle` when interaction can
wait, and `client:visible` for components below the fold. Interactive components such as `Dialog`,
`Menu`, and `Select` need a client directive.

## Install with the shadcn CLI

Complete the [shadcn CLI setup](/docs/quick-start#install-with-the-shadcn-cli), map `@/*` to `src/*`
in `tsconfig.json`, and import `@/lib/moduix/styles/style.css` from the shared layout. Then add the
component for your runtime:

<Tabs groupId="framework">
  <Tab label="React" value="react">

<PackageManagerTabs command="shadcn@latest add @moduix-react/button" dlx />

  </Tab>
  <Tab label="Solid" value="solid">

<PackageManagerTabs command="shadcn@latest add @moduix-solid/button" dlx />

  </Tab>
</Tabs>

Import the generated component directly into the `.astro` file before applying a `client:*`
directive. Astro only accepts client directives on framework components imported directly into the
page.

## Verify

The page should contain styled server-rendered markup before hydration, then respond after the client
directive runs.

See Astro's [framework components guide](https://docs.astro.build/en/guides/framework-components/),
plus the official [React](https://docs.astro.build/en/guides/integrations-guide/react/) and
[Solid](https://docs.astro.build/en/guides/integrations-guide/solid-js/) integration guides.
