# Astro

moduix is a React component library. Astro renders React components as static HTML by default. Add an Astro `client:*`
directive when a component needs to become interactive in the browser.

## Add React to Astro

From your project root, run:

```bash
npx astro add react
```

This command installs and configures Astro's official `@astrojs/react` integration.

## Install moduix

Install `@moduix/react` and its Ark UI peer dependency:

<PackageManagerTabs command="install @moduix/react @ark-ui/react" />

`@moduix/react` supports React 18 and 19 and expects `react`, `react-dom`, and `@ark-ui/react` to be installed in your
project. The `astro add react` command normally sets up `react` and `react-dom`. If you installed `@astrojs/react`
manually, make sure those packages are present before continuing.

Import the base stylesheet once in a shared layout:

```astro title="src/layouts/Layout.astro"
---
import '@moduix/react/style.css';
---

<html lang="en">
  <body><slot /></body>
</html>
```

Create a React component and import it directly into an Astro page:

```tsx title="src/components/ContinueButton.tsx"
import { Button } from '@moduix/react/button';

export function ContinueButton() {
  return <Button>Continue</Button>;
}
```

Add `client:load` to make it interactive as soon as the page loads:

```astro title="src/pages/index.astro"
---
import { ContinueButton } from '../components/ContinueButton';
---

<ContinueButton client:load />
```

Without a `client:*` directive, Astro renders the component as static HTML without sending its client-side JavaScript.
Choose the directive based on when the component needs to become interactive: use `client:load` for immediately visible
controls, `client:idle` when interaction can wait until the browser is idle, and `client:visible` for components that
can wait until they enter the viewport. A static server render is not enough for `Dialog`, `Menu`, `Select`, or other
interactive components.

## Install with the shadcn CLI

Complete the [shadcn CLI setup](/docs/quick-start#install-with-the-shadcn-cli). In `tsconfig.json`, map `@/*` to
`src/*` and import `@/lib/moduix/styles/style.css` from the shared layout. In an Astro page, import the generated React
component directly and add a `client:*` directive to it. Astro only accepts a client directive on a framework
component that is imported directly into a `.astro` file.

## Verify

The page should contain styled server-rendered markup before hydration, and the component should respond after its
client directive runs.

See Astro's [front-end framework guide](https://docs.astro.build/en/guides/framework-components/) for the available
client directives. For manual React integration setup, see the [@astrojs/react integration guide](https://docs.astro.build/en/guides/integrations-guide/react/).
