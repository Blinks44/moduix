# Astro

This guide assumes an existing Astro project with its official React, Solid, or Vue integration already
configured. Components render as static HTML by default; add a `client:*` directive when they need
to become interactive in the browser.

## Choose your setup

- **Runtime:** React, Solid, or Vue with the matching official Astro integration.
- **Styling:** CSS Modules or Tailwind CSS v4.
- **Distribution:** a package or source copied with the shadcn CLI.

Quick Start covers [package choices](/docs/quick-start#install-as-a-package) and
[shadcn configuration](/docs/quick-start#install-with-the-shadcn-cli).

The examples below use CSS Modules with the moduix reset. Omit the reset if your app already
provides an equivalent one. For Tailwind, install the matching `-tailwind` package and import your
application’s Tailwind stylesheet at the same entry point, using the setup from Quick Start.

```

```

  </Tab>

Create a framework component:

<Tabs groupId="framework">
  <Tab label="React" value="react">

```tsx title="src/components/ContinueButton.tsx"
import { Button } from '@moduix/react/button';

export function ContinueButton() {
  return <Button>Continue</Button>;
}
```

  </Tab>
  <Tab label="Solid" value="solid">

```tsx title="src/components/ContinueButton.tsx"
import { Button } from '@moduix/solid/button';

export function ContinueButton() {
  return <Button>Continue</Button>;
}
```

  </Tab>
  <Tab label="Vue" value="vue">

```vue title="src/components/ContinueButton.vue"
<script setup lang="ts">
import { Button } from '@moduix/vue/button';
</script>

<template>
  <Button>Continue</Button>
</template>
```

  </Tab>
</Tabs>

Import it directly into an Astro page and add a client directive:

<Tabs groupId="framework">
  <Tab label="React / Solid" value="react-solid">

```astro title="src/pages/index.astro"
---
import Layout from '../layouts/Layout.astro';
import { ContinueButton } from '../components/ContinueButton';
---

<Layout>
  <ContinueButton client:load />
</Layout>
```

  </Tab>
  <Tab label="Vue" value="vue">

```astro title="src/pages/index.astro"
---
import Layout from '../layouts/Layout.astro';
import ContinueButton from '../components/ContinueButton.vue';
---

<Layout>
  <ContinueButton client:load />
</Layout>
```

  </Tab>
</Tabs>

Without a `client:*` directive, Astro sends static HTML without the component's client-side
JavaScript. Use `client:load` for immediately visible controls, `client:idle` when interaction can
wait, and `client:visible` for components below the fold. Interactive components such as `Dialog`,
`Menu`, and `Select` need a client directive.

## Install with the shadcn CLI

Complete the [shadcn CLI setup](/docs/quick-start#install-with-the-shadcn-cli), map `@/*` to `src/*`
in `tsconfig.json`, then add the
component for your runtime:

<Tabs groupId="framework">
  <Tab label="React" value="react">

<ShadcnInstallOptions
  options={[
    { label: 'CSS Modules', command: 'shadcn@latest add @moduix-react/button' },
    { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-react-tailwind/button' },
  ]}
/>

  </Tab>
  <Tab label="Solid" value="solid">

<ShadcnInstallOptions
  options={[
    { label: 'CSS Modules', command: 'shadcn@latest add @moduix-solid/button' },
    { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-solid-tailwind/button' },
  ]}
/>

  </Tab>
  <Tab label="Vue" value="vue">

<ShadcnInstallOptions
  options={[
    { label: 'CSS Modules', command: 'shadcn@latest add @moduix-vue/button' },
    { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-vue-tailwind/button' },
  ]}
/>

  </Tab>
</Tabs>

For CSS Modules, import `@/lib/moduix/styles/style.css` from `src/layouts/Layout.astro`; keep
the reset configured as shown in Quick Start. For Tailwind, load the generated foundation from your
Tailwind stylesheet and import that stylesheet from the layout. Change the framework wrapper’s
Button import to `@/components/ui/button`, and keep the wrapper directly imported by the Astro page.

## Verify

The page should contain styled server-rendered markup before hydration, then respond after the client
directive runs.

See Astro's [framework components guide](https://docs.astro.build/en/guides/framework-components/),
plus the official [React](https://docs.astro.build/en/guides/integrations-guide/react/) and
[Solid](https://docs.astro.build/en/guides/integrations-guide/solid-js/) / [Vue](https://docs.astro.build/en/guides/integrations-guide/vue/) integration guides.
