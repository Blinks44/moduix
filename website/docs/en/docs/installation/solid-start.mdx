# SolidStart

SolidStart renders Solid applications on the server and hydrates them in the browser. This guide
assumes an existing SolidStart v2 project created with `create-solid`.

## Choose your setup

- **Runtime:** Solid.
- **Styling:** CSS Modules or Tailwind CSS v4.
- **Distribution:** a package or source copied with the shadcn CLI.

Quick Start covers [package choices](/docs/quick-start#install-as-a-package) and
[shadcn configuration](/docs/quick-start#install-with-the-shadcn-cli).

The examples below use CSS Modules with the moduix reset. Omit the reset if your app already
provides an equivalent one. For Tailwind, install the matching `-tailwind` package and import your
application’s Tailwind stylesheet at the same entry point, using the setup from Quick Start.

## Install as a package

Install moduix and its Solid peer dependencies:

<PackageManagerTabs command="install @moduix/solid @ark-ui/solid" />

Import the foundation stylesheet once from the application root:

```tsx title="src/app.tsx"
import '@moduix/solid/reset.css';
import '@moduix/solid/style.css';
```

Use components from their package subpaths:

```tsx title="src/routes/index.tsx"
import { Button } from '@moduix/solid/button';

export default function Home() {
  return <Button>Continue</Button>;
}
```

## Install with the shadcn CLI

SolidStart provides `~` as an alias for `src`, while the moduix registry examples use `@`. Complete
the [shadcn CLI setup](/docs/quick-start#install-with-the-shadcn-cli), then map `@/*` to `src/*` in
`tsconfig.json`:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Add the same runtime alias to the existing Vite configuration:

```ts title="vite.config.ts"
import { fileURLToPath, URL } from 'node:url';
import { solidStart } from '@solidjs/start/config';
import { defineConfig } from 'vite';

export default defineConfig({
  plugins: [solidStart()],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url)),
    },
  },
});
```

Then add a Solid component:

<ShadcnInstallOptions
  options={[
    { label: 'CSS Modules', command: 'shadcn@latest add @moduix-solid/button' },
    { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-solid-tailwind/button' },
  ]}
/>

Import the generated foundation stylesheet from `src/app.tsx` instead of the package stylesheet:

```tsx title="src/app.tsx"
import '@/lib/moduix/styles/style.css';
```

The stylesheet import above is for CSS Modules. For Tailwind, load the generated foundation from
your existing Tailwind stylesheet as shown in [Quick Start](/docs/quick-start#install-with-the-shadcn-cli),
and import that application stylesheet at the same entry point. Use the generated component import
`@/components/ui/button` in place of the package import.

## Verify

Start the development server and open the index route. The server-rendered response should include
moduix styles, hydrate without a mismatch, and remain interactive in the browser.

See the official SolidStart [getting started guide](https://docs.solidjs.com/solid-start/v2/getting-started)
for project creation and current runtime requirements.
