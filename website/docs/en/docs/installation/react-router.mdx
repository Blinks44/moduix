# React Router

This guide covers React Router in Framework Mode. If you already have a Framework Mode app, add moduix with the
steps below. For Data Mode or Declarative Mode, follow the [Vite setup](/docs/installation/vite); the moduix imports
stay the same.

## Choose your setup

- **Runtime:** React in Framework Mode. Use the Vite guide for Data or Declarative Mode.
- **Styling:** CSS Modules or Tailwind CSS v4.
- **Distribution:** a package or source copied with the shadcn CLI.

Complete the shared [package setup](/docs/quick-start#install-as-a-package) or
[shadcn setup](/docs/quick-start#install-with-the-shadcn-cli) for your styling track first. This page
uses CSS Modules package imports; the React Router entry files, aliases, SSR, and hydration checks stay
the same with the React Tailwind package or registry.

All package commands and stylesheet imports shown below belong to CSS Modules. Use the moduix reset
shown below or a correct reset from your application. With Tailwind, keep the global stylesheet configured in
Quick Start instead.

## Install as a package

<PackageManagerTabs command="install @moduix/react @ark-ui/react" />

React Router renders framework route modules inside `app/root.tsx`. Import the foundation stylesheet there once:

```tsx title="app/root.tsx"
import '@moduix/react/reset.css';
import '@moduix/react/style.css';
```

Register the route in `app/routes.ts`:

```tsx title="app/routes.ts"
import { type RouteConfig, index } from '@react-router/dev/routes';

export default [index('routes/home.tsx')] satisfies RouteConfig;
```

Use a moduix component in the route module:

```tsx title="app/routes/home.tsx"
import { Button } from '@moduix/react/button';

export default function Home() {
  return <Button>Continue</Button>;
}
```

The index route renders at `/`, so you can open that URL after starting the development server.

## Install with the shadcn CLI

Use this method when you want the component source and styles in your repository. First complete the [shadcn CLI
setup](/docs/quick-start#install-with-the-shadcn-cli). The standard React Router template keeps application code in
`app`, so map `@/*` to `app/*` instead of `src/*`:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./app/*"]
    }
  }
}
```

Framework Mode uses Vite. Make the same alias available to the bundler by following the [Vite setup](/docs/installation/vite#install-with-the-shadcn-cli) and changing `./src` to `./app`. Keep the React Router plugin and any other existing Vite configuration in place.

Add the Button from the namespace for your styling track:

<ShadcnInstallOptions
  options={[
    { label: 'CSS Modules', command: 'shadcn@latest add @moduix-react/button' },
    { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-react-tailwind/button' },
  ]}
/>

After shadcn generates the files, replace the package stylesheet import in `app/root.tsx` with the generated one:

```tsx title="app/root.tsx"
import '@/lib/moduix/styles/style.css';
```

Do not import both stylesheets. The generated file is the foundation stylesheet for the source-owned setup.

## Verify

Start the development server and open `/`. The page should render on the server, hydrate without a mismatch, and keep
interactive components working after hydration. Do not branch component markup on browser globals during render.

See the [React Router framework installation guide](https://reactrouter.com/start/framework/installation) and
[routing guide](https://reactrouter.com/start/framework/routing) for the framework's complete setup.
