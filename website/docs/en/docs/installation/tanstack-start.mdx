# TanStack Start

This guide assumes an existing TanStack Start app configured for React or Solid. Start can build
with Vite or Rsbuild, renders the route tree on the server, and hydrates it in the browser; moduix
does not require a `use client` directive in the standard setup.

## Choose your setup

- **Runtime:** React or Solid with the matching TanStack Start adapter.
- **Styling:** CSS Modules or Tailwind CSS v4.
- **Distribution:** a package or source copied with the shadcn CLI.

Quick Start covers [package choices](/docs/quick-start#install-as-a-package) and
[shadcn configuration](/docs/quick-start#install-with-the-shadcn-cli).

The examples below use CSS Modules with the moduix reset. Omit the reset if your app already
provides an equivalent one. For Tailwind, install the matching `-tailwind` package and import your
application’s Tailwind stylesheet at the same entry point, using the setup from Quick Start.

Import the foundation stylesheet once from `src/routes/__root.tsx`:

<Tabs groupId="framework">
  <Tab label="React" value="react">

```tsx title="src/routes/__root.tsx"

import '@moduix/react/style.css';
```

  </Tab>
  <Tab label="Solid" value="solid">

```tsx title="src/routes/__root.tsx"
import '@moduix/solid/reset.css';
import '@moduix/solid/style.css';
```

  </Tab>
</Tabs>

Use a component in a route:

<Tabs groupId="framework">
  <Tab label="React" value="react">

```tsx title="src/routes/index.tsx"
import { createFileRoute } from '@tanstack/react-router';
import { Button } from '@moduix/react/button';

export const Route = createFileRoute('/')({
  component: Home,
});

function Home() {
  return <Button>Continue</Button>;
}
```

  </Tab>
  <Tab label="Solid" value="solid">

```tsx title="src/routes/index.tsx"

  component: Home,

}
```

## Install with the shadcn CLI

Complete the [shadcn CLI setup](/docs/quick-start#install-with-the-shadcn-cli). If the starter does
not already map `@/*` to `src/*`, add the alias to the root `tsconfig.json`:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Make the same alias available to the selected bundler. Rsbuild reads the TypeScript paths directly;
for Vite, follow TanStack Start's path-alias guide for
[React](https://tanstack.com/start/latest/docs/framework/react/guide/path-aliases) or
[Solid](https://tanstack.com/start/latest/docs/framework/solid/guide/path-aliases). Then add the
component:

<Tabs groupId="framework">
  <Tab label="React" value="react">

<ShadcnInstallOptions
  options={[
    { label: 'CSS Modules', command: 'shadcn@latest add @moduix-react/button' },
    { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-react-tailwind/button' },
  ]}
/>

  </Tab>
  <Tab label="Solid" value="solid">

<ShadcnInstallOptions
  options={[
    { label: 'CSS Modules', command: 'shadcn@latest add @moduix-solid/button' },
    { label: 'Tailwind CSS', command: 'shadcn@latest add @moduix-solid-tailwind/button' },
  ]}
/>

  </Tab>
</Tabs>

Replace the package stylesheet with the generated stylesheet in the root route:

```tsx title="src/routes/__root.tsx"
import '@/lib/moduix/styles/style.css';
```

The stylesheet import above is for CSS Modules. For Tailwind, load the generated foundation from
your existing Tailwind stylesheet as shown in [Quick Start](/docs/quick-start#install-with-the-shadcn-cli),
and import that application stylesheet at the same entry point. Use the generated component import
`@/components/ui/button` in place of the package import.

## Verify

Open `/` after starting the development server. The initial server-rendered page should include
moduix styles, hydrate without a mismatch, and remain interactive. Keep browser-only APIs and values
that may differ between server and client out of the server render.

Continue with the official TanStack Start guides for
[React](https://tanstack.com/start/latest/docs/framework/react/getting-started) or
[Solid](https://tanstack.com/start/latest/docs/framework/solid/getting-started).
