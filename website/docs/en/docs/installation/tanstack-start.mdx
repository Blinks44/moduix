# TanStack Start

TanStack Start is bundler-agnostic and hydrates route components on the client, so moduix components work in the
normal route tree without a `use client` directive. It supports both Vite and Rsbuild.

## Package install

<PackageManagerTabs command="install @moduix/react @ark-ui/react" />

Add the foundation stylesheet to the global stylesheet already loaded by your root route:

```css title="src/styles.css"
@import '@moduix/react/style.css';
```

Use a component in a route:

```tsx title="src/routes/index.tsx"
import { createFileRoute } from '@tanstack/react-router';
import { Button } from '@moduix/react/button';

export const Route = createFileRoute('/')({
  component: Home,
});

function Home() {
  return <Button>Continue</Button>;
}
```

## shadcn CLI install

Complete the [shadcn CLI setup](/docs/quick-start#install-with-the-shadcn-cli). If your starter
already maps `@/*` to `src/*`, keep that alias. Otherwise add the TypeScript and bundler alias from the
[Vite](/docs/installation/vite#shadcn-cli-install) or [Rsbuild](/docs/installation/rsbuild#shadcn-cli-install)
setup.

Replace the package CSS import with the generated stylesheet:

```css title="src/styles.css"
@import '@/lib/moduix/styles/style.css';
```

## Verify

The setup is complete when the server-rendered page hydrates without a mismatch and an interactive
component responds after hydration. Keep browser-only application code out of the server render as
you would elsewhere in TanStack Start.

See the [TanStack Start quick start](https://tanstack.com/start/latest/docs/framework/react/quick-start)
for the framework's complete setup.
