# TanStack Start

This guide assumes you already have a TanStack Start app. TanStack Start renders the route tree on the server and
hydrates it in the browser. moduix works with both Vite and Rsbuild. In the standard setup, you do not need a
`use client` directive.

## Install as a package

<PackageManagerTabs command="install @moduix/react @ark-ui/react" />

Import the foundation stylesheet once from the root route. In a standard TanStack Start project, the root route is
`src/routes/__root.tsx`:

```tsx title="src/routes/__root.tsx"
import '@moduix/react/style.css';
```

Use a moduix component in a route:

```tsx title="src/routes/index.tsx"
import { createFileRoute } from '@tanstack/react-router';
import { Button } from '@moduix/react/button';

export const Route = createFileRoute('/')({
  component: Home,
});

function Home() {
  return <Button>Continue</Button>;
}
```

## Install with the shadcn CLI

Use this method when you want the component source and styles in your repository. First complete the
[shadcn CLI setup](/docs/quick-start#install-with-the-shadcn-cli).

TanStack Start does not add path aliases by default. If your starter already maps `@/*` to `src/*`, keep that alias.
Otherwise add it to the root `tsconfig.json`:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Make the same alias available to your bundler. For Vite, follow the [TanStack Start path aliases guide](https://tanstack.com/start/latest/docs/framework/react/guide/path-aliases).
Rsbuild reads `paths` from the root `tsconfig.json` automatically.

Replace the package stylesheet import in the root route with the generated stylesheet. Do not import both:

```tsx title="src/routes/__root.tsx"
import '@/lib/moduix/styles/style.css';
```

## Verify

Start the development server and open `/`. The integration is working when the initial server-rendered page uses moduix
styles, hydrates without a mismatch, and the button responds to clicks. Keep browser-only APIs and values that can
differ between the server and client out of code that runs during server rendering.

See TanStack Start's [Getting Started](https://tanstack.com/start/latest/docs/framework/react/getting-started) and
[Build from Scratch](https://tanstack.com/start/latest/docs/framework/react/build-from-scratch) guides for the
framework's complete setup.
