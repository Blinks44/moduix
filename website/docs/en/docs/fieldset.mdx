Build a group with `Fieldset`, `FieldsetLegend`, the related controls, and optional helper or error
text. `Fieldset` is the root component for the group.

## Choosing the right component

Use `Fieldset` when several related controls belong to one group and need a shared legend, such as
contact details or notification preferences. Use `Field` when one control needs its own label, helper
text, and validation message.

## Composition

Keep one visible `FieldsetLegend` inside the root, then place related controls and their `Field`
parts inside the same composition. Set `invalid` on the root for a group-level error and on nested
`Field` components when individual controls need their own validation state. A disabled fieldset
passes its state to native controls and Ark-aware descendants.

Use `useFieldset` with `FieldsetRootProvider` when state must be created outside the rendered tree or
shared with sibling controls. Use `FieldsetContext` or `useFieldsetContext()` to read that state in a
descendant, and do not render `Fieldset` together with `FieldsetRootProvider` for the same store.
Use `asChild` with one semantic child when replacing a part's rendered element.

## Styling

The root resets the browser's fieldset border, margin, and padding and fills the width of its
container. A disabled `Fieldset` dims the whole group once; `Field` and `Input` inside it do not dim
again. `invalid` does not draw a border on the group: show the problem with `FieldsetErrorText` and
mark the affected controls through their own `Field`.

Use `className` in React or `class` in Solid and Vue on exported parts. Tailwind variants use native
utilities and consumer classes. CSS Modules variants build on foundation tokens and have no component
variables: a class on the part overrides the layered component styles.

### Styling hooks

| Part | `data-slot` |
| --- | --- |
| `Fieldset` | `fieldset-root` |
| `FieldsetRootProvider` | `fieldset-root-provider` |
| `FieldsetLegend` | `fieldset-legend` |
| `FieldsetHelperText` | `fieldset-helper-text` |
| `FieldsetErrorText` | `fieldset-error-text` |

Every DOM part has Ark's `data-scope="fieldset"` and a `data-part` that matches the anatomy. The root
and legend expose `data-disabled` and `data-invalid`; moduix also adds `data-slot="fieldset-*"` hooks.
