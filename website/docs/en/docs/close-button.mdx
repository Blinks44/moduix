## API Reference

Ark UI does not ship a dedicated primitive for close buttons. moduix builds `CloseButton` with the official
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) and follows Ark's guidance for
[composition](https://ark-ui.com/docs/guides/composition), [styling](https://ark-ui.com/docs/guides/styling), and
[refs](https://ark-ui.com/docs/guides/ref).

## Basic

Use `CloseButton` to add a close control to a notification, card, overlay, or another UI surface. Connect
`onClick` to the state that hides or removes that surface. The component provides button semantics, a fallback
accessible name, and a default `CloseIcon`, but it does not manage the surface's state.

## Anatomy

`CloseButton` exposes one Ark-style root part.

```text
CloseButton / CloseButton.Root
└─ root[data-scope="close-button"][data-part="root"][data-slot="close-button-root"]
   └─ CloseIcon (default) | custom children
```

| Part                               | Role                                                                     |
| ---------------------------------- | ------------------------------------------------------------------------ |
| `CloseButton` / `CloseButton.Root` | Interactive dismiss control built on button semantics and accessibility. |

## Composition

### Recommended composition

Use `CloseButton` directly when a native button should render the close control. The wrapper forwards
Ark factory button props, native attributes, event handlers, and refs.

### When to go custom

Use `asChild` when another button component must own the DOM node. Ark composition requires one
child element, and that child must include its own icon content.

If an overlay component already provides a close trigger, use that trigger so it can manage
dismissal state and focus behavior.

### Default props

| Prop         | Default                                         | Values / Notes                             |
| ------------ | ----------------------------------------------- | ------------------------------------------ |
| `type`       | `button`                                        | Applied only to the native root            |
| `aria-label` | `Close` when `aria-labelledby` is absent        | Prefer a surface-specific label in real UI |
| `children`   | `CloseIcon`                                     | Replaced by custom icon content            |
| `asChild`    | `false`                                         | Ark factory single-child composition       |

### Behavioral notes

- `CloseButton` does not close anything by itself. Connect `onClick` to your state logic or use an
  overlay's close trigger.
- If neither `aria-label` nor `aria-labelledby` is provided, the accessible name is `Close`. Set one
  of them to describe what the control closes.
- Native `disabled` and `aria-disabled="true"` expose `data-disabled` for Ark-style state
  targeting and suppress click activation.
- With `asChild`, `disabled` does not add a native `disabled` attribute to the custom host. It
  adds `aria-disabled="true"` and `data-disabled`, then suppresses click activation.
- The previous `render`, `nativeButton`, and `focusableWhenDisabled` props are removed.
- `CloseButton.Root` is available as the equivalent Ark-aligned namespace form.

### Styling hooks

- `data-scope="close-button"` identifies the component family.
- `data-part="root"` identifies the only exported part.
- `data-slot="close-button-root"` provides the moduix slot hook.
- `data-disabled` exposes the normalized `disabled` and `aria-disabled="true"` styling state.
- Direct nested SVG children inherit sizing from `--moduix-close-button-icon-size`.
