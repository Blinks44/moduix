## API Reference

Ark UI does not ship a dedicated primitive for close buttons. moduix builds `CloseButton` with the official
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) and follows Ark's guidance for
[composition](https://ark-ui.com/docs/guides/composition), [styling](https://ark-ui.com/docs/guides/styling), and
[refs](https://ark-ui.com/docs/guides/ref).

## Basic

CloseButton ships for React and Solid in both the CSS Modules and Tailwind packages. The rendered preview on this
page uses the React CSS Modules package; the framework tabs show native source for the same public contract.

Use `CloseButton` to add a close control to a notification, card, overlay, or another UI surface. Connect its
`onClick` handler to the state that hides or removes that surface. The component renders a semantic button, provides
a default accessible name, and shows a `CloseIcon`, but it does not manage the surface's state.

## Anatomy

`CloseButton` exposes a single root part following the Ark model.

```text
CloseButton / CloseButton.Root
└─ root[data-scope="close-button"][data-part="root"][data-slot="close-button-root"]
   └─ CloseIcon (default) | custom children
```

| Part                               | Role                                                                     |
| ---------------------------------- | ------------------------------------------------------------------------ |
| `CloseButton` / `CloseButton.Root` | Interactive dismiss control based on button semantics and accessibility. |

## Composition

`CloseButton` does not own the state of the surface it dismisses. Connect `onClick` to the state that hides or
removes that surface. If a Dialog, Drawer, or another overlay already provides a close trigger, use that trigger so
the parent keeps control of dismissal and focus return.

Use `asChild` when one semantic button from another component must own the DOM node. The child must render the icon;
set `type="button"` on it when needed, especially inside a form. In Solid, pass a render function to `asChild` and
spread `props()` onto the child.

## Styling

Use `className` in React or `class` in Solid on the root for structural styles. Tailwind variants use native utility
classes and consumer class overrides; the variables below apply to the CSS Modules variants. Data attributes and
`data-slot` hooks are shared by both styling tracks.

### CSS Properties

### Styling hooks

- `data-scope="close-button"` identifies the component family.
- `data-part="root"` identifies the only exported part.
- `data-slot="close-button-root"` provides the moduix slot hook.
- `data-disabled` exposes the normalized `disabled` and `aria-disabled="true"` styling state.
- `className`/`class` is merged with the component's default styles on the root.
- For CSS Modules variants, direct child SVG elements use `--moduix-close-button-icon-size` for their width and height.
