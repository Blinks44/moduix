Use `CloseButton` to add a close control to a notification, card, overlay, or another UI surface. Connect its
`onClick` handler to the state that hides or removes that surface. The component renders a semantic button, provides
a default accessible name, and shows a `CloseIcon`, but it does not manage the surface's state.

## Examples

### Custom content

Pass custom content through `children` to replace the default icon while keeping the root button contract. Keep a
custom icon decorative with `aria-hidden="true"` when the button's accessible name comes from its label.

<Example name="close-button/custom-children" />

### Disabled state

Use native `disabled` when the button should not be focusable. Use `aria-disabled="true"` when it should remain
focusable but must not activate.

### Using `asChild`

Use `asChild` when an existing semantic button must be the rendered element while receiving CloseButton's styles
and data attributes. Put the icon in that child and set its type explicitly.

## Composition

`CloseButton` does not own the state of the surface it dismisses. Connect `onClick` to the state that hides or
removes that surface. If a Dialog, Drawer, or another overlay already provides a close trigger, use that trigger so
the parent keeps control of dismissal and focus return.

Use `asChild` when one semantic button from another component must own the DOM node. The child must render the icon;
set `type="button"` on it when needed, especially inside a form. In Vue, place that button in the default slot. In
Solid, pass a render function to `asChild` and spread `props()` onto the child.

## Anatomy

`CloseButton` exposes a single root part following the Ark model.

```text
CloseButton
└─ root[data-scope="close-button"][data-part="root"][data-slot="close-button-root"]
   └─ CloseIcon (default) | custom children
```

| Part          | Role                                                                     |
| ------------- | ------------------------------------------------------------------------ |
| `CloseButton` | Interactive dismiss control based on button semantics and accessibility. |

## Styling

Use `className` in React or `class` in Solid and Vue on the root for structural styles. Tailwind variants use native
utility classes and consumer class overrides; the variables below apply to the CSS Modules variants. Data attributes
and `data-slot` hooks are shared by both styling tracks.

### Styling hooks

| Part | `data-slot` |
| --- | --- |
| `CloseButton` | `close-button-root` |

- `data-scope="close-button"` identifies the component family.
- `data-part="root"` identifies the only exported part.
- `data-disabled` exposes the normalized `disabled` and `aria-disabled="true"` styling state.
- `className`/`class` is merged with the component's default styles on the root.
- For CSS Modules variants, direct child SVG elements use `--moduix-close-button-icon-size` for their width and height.

## Keyboard

| Key | Action |
| --- | --- |
| `Tab` / `Shift+Tab` | Moves focus to and from the button. |
| `Enter` / `Space` | Activates the focused button. |
