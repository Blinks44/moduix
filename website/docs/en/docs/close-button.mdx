## API Reference

Ark UI does not ship a dedicated primitive for close buttons. moduix builds `CloseButton` with the official
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) and follows Ark's guidance for
[composition](https://ark-ui.com/docs/guides/composition), [styling](https://ark-ui.com/docs/guides/styling), and
[refs](https://ark-ui.com/docs/guides/ref).

## Basic

Use `CloseButton` to add a close control to a notification, card, overlay, or another UI surface. Connect its
`onClick` handler to the state that hides or removes that surface. The component renders a semantic button,
provides a default accessible name, and shows a `CloseIcon`, but it does not manage the surface's state.

## Anatomy

`CloseButton` exposes a single root part following the Ark model.

```text
CloseButton / CloseButton.Root
└─ root[data-scope="close-button"][data-part="root"][data-slot="close-button-root"]
   └─ CloseIcon (default) | custom children
```

| Part                               | Role                                                                     |
| ---------------------------------- | ------------------------------------------------------------------------ |
| `CloseButton` / `CloseButton.Root` | Interactive dismiss control based on button semantics and accessibility. |

## Composition

### Recommended composition

Use `CloseButton` directly when you want it to render a native button. The component forwards button props
from Ark's factory, native attributes, event handlers, and refs.

### When to go custom

Use `asChild` when another button component needs to own the rendered DOM node. Pass exactly one child,
and put the icon content inside that child.

If an overlay already provides a close trigger, use that trigger so it can manage dismissal state and
focus behavior.

### Default props

| Prop         | Default                                         | Values / Notes                             |
| ------------ | ----------------------------------------------- | ------------------------------------------ |
| `type`       | `button`                                        | Applied only to the native root            |
| `aria-label` | `Close` when both label attributes are absent | Prefer a surface-specific label in real UI |
| `children`   | `CloseIcon`                                   | Replaced by custom content                 |
| `asChild`    | `false`                                       | Uses one child as the rendered root        |

### Behavioral notes

- `CloseButton` does not close anything by itself. Connect `onClick` to your state logic or use an
  overlay's close trigger.
- If neither `aria-label` nor `aria-labelledby` is provided, the accessible name defaults to `Close`.
  Use a surface-specific label, such as `Dismiss notification`, in a real interface.
- `disabled` and `aria-disabled="true"` set `data-disabled` and prevent click activation.
- The native root defaults to `type="button"`. With `asChild`, set `type` on the child yourself,
  especially when the button is inside a form.
- With `asChild`, `disabled` is represented by `aria-disabled="true"` instead of a native `disabled`
  attribute. Click activation is still blocked.
- `CloseButton.Root` is the equivalent namespace form.

### Styling hooks

- `data-scope="close-button"` identifies the component family.
- `data-part="root"` identifies the only exported part.
- `data-slot="close-button-root"` provides the moduix slot hook.
- `data-disabled` exposes the normalized `disabled` and `aria-disabled="true"` styling state.
- `className` is merged with the component's default styles on the root.
- Direct child SVG elements use `--moduix-close-button-icon-size` for their width and height.
