## Basic

Use `Swap` when one piece of UI needs to switch between two visual states, such as an icon that
changes after an action. Pass the current boolean to `swap`: `false` shows the `off` indicator and
`true` shows the `on` indicator. The surrounding control owns the interaction and accessible name.

## Anatomy

```text
Swap / Swap.Root
├─ Swap.Indicator type="off"
└─ Swap.Indicator type="on"
```

| Part                  | Role                                                               |
| --------------------- | ------------------------------------------------------------------ |
| `Swap` / `Swap.Root`  | Supplies the Ark `swap` state and stacks both visual states.       |
| `Swap.RootProvider`   | Provides state created with `Swap.useSwap()` outside the subtree.  |
| `Swap.Indicator`      | Renders the `on` or `off` state selected by its `type` prop.       |

Render both indicators as direct children of the root. They share one grid cell, and the built-in
animation recipes stay scoped to that `Swap` instance.

## Composition

### Recommended composition

`Swap` is a visual primitive, not a button or a toggle. Put it inside a semantic button, link, or
status element. Keep state updates, event handlers, focus behavior, and the accessible name on that
parent. If the indicators contain only icons, set `aria-hidden="true"` on both of them.

### When to use a custom animation

Use `animation` to choose one of the built-in `fade`, `scale`, `rotate`, or `flip` recipes. The prop
also accepts a custom name. moduix writes that name to `data-animation` and applies no built-in
animation, so your CSS can use Ark's `data-state` attributes to define the transition.

### Default props

| Prop              | Default | Description                                                        |
| ----------------- | ------- | ------------------------------------------------------------------ |
| `swap`            | `false` | Shows the `off` indicator.                                         |
| `animation`       | `scale` | Uses moduix's scale-and-fade preset.                              |
| `lazyMount`       | `false` | Mounts both indicators instead of delaying the inactive one.       |
| `unmountOnExit`   | `false` | Keeps an indicator mounted after its exit animation.              |

### Behavioral notes

- `swap` is controlled. `Swap` does not react to hover or clicks by itself and renders a `span` by
  default.
- Ark Presence adds `data-state="open" | "closed"` to indicators so CSS can style their enter and
  exit states. Set `lazyMount` or `unmountOnExit` when you need to control when inactive indicators
  enter or leave the DOM.
- `Swap.RootProvider` accepts the state returned by `Swap.useSwap()`, and `useSwapContext()` reads
  the nearest provider state from a descendant.
- `asChild` is available on every rendered part. Pass exactly one semantic child so Ark can merge
  its props and ref with that element.

### Custom animation

Pass a custom `animation` name and target the root's `data-animation` together with the indicators'
Ark `data-state`. The `bounce` recipe below is plain CSS. No extra Swap API or JavaScript is needed,
but a custom recipe must define both enter and exit animations and should include a reduced-motion
fallback.

<style>{SwapDocs.swapCustomAnimationCss}</style>

<PreviewFrame>
  ```tsx preview file="./_snippets/swap/custom-animation.tsx"

  ```
</PreviewFrame>

```css
.swap-custom-animation[data-animation='bounce'] [data-slot='swap-indicator'][data-state='open'] {
  animation: swap-bounce-enter var(--moduix-swap-transition, var(--moduix-transition-slow));
}

.swap-custom-animation[data-animation='bounce'] [data-slot='swap-indicator'][data-state='closed'] {
  animation: swap-bounce-exit var(--moduix-swap-transition, var(--moduix-transition-slow));
}

@keyframes swap-bounce-enter {
  from {
    opacity: 0;
    transform: scale(0.7);
  }

  70% {
    transform: scale(1.1);
  }
}

@keyframes swap-bounce-exit {
  to {
    opacity: 0;
    transform: scale(0.7);
  }
}

@media (prefers-reduced-motion: reduce) {
  .swap-custom-animation[data-animation='bounce'] [data-slot='swap-indicator'][data-state] {
    animation-duration: 1ms;
  }
}
```

## Styling

Built-in recipes read the CSS variables below. A custom animation name disables those recipes, but
you can still reuse `--moduix-swap-transition` in your own CSS.

### CSS Properties

### Styling hooks

- `Swap.Root` uses `data-slot="swap-root"`.
- `Swap.RootProvider` uses `data-slot="swap-root-provider"`.
- `Swap.Indicator` uses `data-slot="swap-indicator"`.
- `animation` is exposed as `data-animation` on `Swap` and `Swap.RootProvider`.
- Built-in recipes target only direct `Swap.Indicator` children of their root.
- Ark adds `data-scope="swap"` and `data-part="root" | "indicator"`.
- Ark adds `data-state="open" | "closed"` to indicators. moduix uses those attributes for its
  built-in animations and for custom recipes.
