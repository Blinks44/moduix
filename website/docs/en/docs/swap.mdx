## Anatomy

```text
Swap / Swap.Root
├─ Swap.Indicator type="off"
└─ Swap.Indicator type="on"
```

| Part                 | Role                                                             |
| -------------------- | ---------------------------------------------------------------- |
| `Swap` / `Swap.Root` | Owns the Ark `swap` state and layers both visual states.         |
| `Swap.RootProvider`  | Uses state created with `Swap.useSwap()` outside the subtree.    |
| `Swap.Indicator`     | Renders one `on` or `off` visual state with Presence attributes. |

Render both indicators as direct children of the root. They then share one grid cell, and the included
animation recipes stay scoped to this Swap.

## Composition

### Recommended composition

Keep `Swap` focused on visual replacement. Put it inside a semantic button, link, or status
surface; that parent owns events, focus handling, and accessible naming. Mark icon-only indicators
as `aria-hidden="true"` and put the current accessible name on the host control.

### When to go custom

Use `animation` to select the included `fade`, `scale`, `rotate`, or `flip` recipes. The prop also
accepts a custom name: moduix writes it to `data-animation` and leaves the indicators unanimated,
so consumer CSS can use Ark's `data-state` attributes without fighting a default animation.

### Default props

| Prop              | Default | Notes                                                               |
| ----------------- | ------- | ------------------------------------------------------------------- |
| `swap`            | `false` | Selects the `off` indicator.                                       |
| `animation`       | `scale` | Uses moduix's scale-and-fade animation preset.                      |
| `lazyMount`       | `false` | Defers mounting an inactive indicator until it is first displayed. |
| `unmountOnExit`   | `false` | Removes an inactive indicator after its exit animation.            |

### Behavioral notes

- `swap` is controlled; `Swap` does not react to hover or clicks by itself.
- Each indicator receives Ark `data-state="open" | "closed"` while transitioning.
- `Swap.RootProvider` accepts state from `Swap.useSwap()`, and `useSwapContext()` reads that state
  from a descendant when custom composition needs it.
- `asChild` is available on every part. Pass exactly one semantic child so it can receive Ark props,
  refs, and the moduix styling hooks.

### Custom animation

Pass a custom `animation` name and target the root's `data-animation` plus the indicators' Ark
`data-state`. This bounce recipe is intentionally ordinary CSS: no extra Swap API or JavaScript is
needed.

<style>{SwapDocs.swapCustomAnimationCss}</style>

<PreviewFrame>
  ```tsx preview file="./_snippets/swap/custom-animation.tsx"

  ```
</PreviewFrame>

```css
.swap-custom-animation[data-animation='bounce'] [data-slot='swap-indicator'][data-state='open'] {
  animation: swap-bounce-enter var(--moduix-swap-transition, var(--moduix-transition-slow));
}

.swap-custom-animation[data-animation='bounce'] [data-slot='swap-indicator'][data-state='closed'] {
  animation: swap-bounce-exit var(--moduix-swap-transition, var(--moduix-transition-slow));
}
```

### Styling hooks

- `Swap.Root` -> `data-slot="swap-root"`
- `Swap.RootProvider` -> `data-slot="swap-root-provider"`
- `Swap.Indicator` -> `data-slot="swap-indicator"`
- `animation` is exposed as `data-animation` on `Swap` and `Swap.RootProvider`.
- Included animation recipes target only direct `Swap.Indicator` children of that root.
- Ark adds `data-scope="swap"` and `data-part="root" | "indicator"`.
- Ark adds `data-state="open" | "closed"` to indicators; moduix uses those attributes for its
  included animations.
