## Usage

<Usage />

`SliderThumbs` renders one thumb with a native input per value. For custom thumb content, compose
`SliderThumb` explicitly and nest `SliderHiddenInput` inside it.

## Choosing the right component

Use `Slider` when users need to adjust a numeric value within defined bounds with a pointer or
keyboard.

- Choose **`Slider`** for volume, brightness, budgets, thresholds, and ranges with multiple thumbs.
- Choose **`Input`** or **`NumberInput`** when users need to type an exact value instead of dragging
  to choose it.
- Choose **`ProgressLinear`** or **`ProgressCircular`** when the value is for display only.

Use `thumbAlignment="center"` when the thumb should extend beyond the track edges.

### Thumb collision

Use `thumbCollisionBehavior` to control what happens when range thumbs meet. `none` (the default)
keeps one thumb from moving past the other, `push` moves the other thumb, and `swap` exchanges
their positions.

### Thumb overlap

Use `minStepsBetweenThumbs` to keep a minimum gap between range thumbs. The gap is calculated as
`minStepsBetweenThumbs * step`.

### Dragging indicator

Use `onValueChange` (or Vue's `value-change` event) for updates during interaction and

Use moduix `useSliderContext` inside a child component when it needs to read slider state such as

## Composition

Use `SliderThumbs` for the standard one-thumb-per-value composition; it also renders one
`SliderHiddenInput` per thumb. When a thumb needs custom children, an accessible name, or a
specific order, compose `SliderThumb` explicitly and place one `SliderHiddenInput` inside it.
Set `name` on the root for form submission.

For controlled state, store `details.value` from `onValueChange` or `onValueChangeEnd`; in Vue,
bind `v-model` to a ref for the same controlled contract. Use `useSliderContext` inside descendants
to read state. If state must live outside the rendered tree, create it with `useSlider` and pass it
to `SliderRootProvider`; do not render another root for the same store. React reads the store as an
object, Solid reads it through the returned accessor, and Vue exposes the reactive store directly in
the template.

### Styling hooks

| Part | `data-slot` |
| --- | --- |
| `Slider` | `slider-root` |
| `SliderRootProvider` | `slider-root-provider` |
| `SliderLabel` | `slider-label` |
| `SliderValueText` | `slider-value-text` |
| `SliderControl` | `slider-control` |
| `SliderTrack` | `slider-track` |
| `SliderRange` | `slider-range` |
| `SliderThumb` | `slider-thumb` |
| `SliderMarkerGroup` | `slider-marker-group` |
| `SliderMarker` | `slider-marker` |
| `SliderDraggingIndicator` | `slider-dragging-indicator` |

Ark adds `data-scope="slider"` and `data-part` to all rendered parts.

Important Ark state attributes include `data-orientation`, `data-disabled`, `data-invalid`,
`data-focus`, `data-dragging`, marker `data-state`, and dragging-indicator
`data-state="open | closed"`. Ark runtime CSS variables include `--slider-thumb-width`,
`--slider-thumb-height`, `--slider-thumb-transform`, `--slider-range-start`,
`--slider-range-end`, `--translate-x`, and `--translate-y`.

moduix adds `data-readonly` to `Slider` when its `readOnly` prop is set. The default invalid state
uses the destructive color for the track, selected range, thumb, and active markers.

A horizontal `Slider` places `SliderLabel` and `SliderValueText` on one row above the control and
fills its container. A vertical `Slider` is `12rem` tall; set `width` or `height` on the root to
change either size.

The default thumb focus ring uses `:focus-visible` for keyboard focus and Ark `data-dragging` while
the thumb is pressed. It is removed after pointer release.

## Keyboard

| Key | Action |
| --- | --- |
| `ArrowRight` / `ArrowUp` | Increases the value by one step. |
| `ArrowLeft` / `ArrowDown` | Decreases the value by one step. |
| `PageUp` / `PageDown`, `Shift` + arrows | Changes the value by a large step. |
| `Home` / `End` | Sets the minimum or maximum. |

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `number[]` | — | Thumb values for controlled use; one number per thumb. |
| `defaultValue` | `number[]` | — | Initial thumb values. |
| `onValueChange` | `(details: ValueChangeDetails) => void` | — | Called while the value changes. |
| `onValueChangeEnd` | `(details: ValueChangeDetails) => void` | — | Called once the user finishes changing the value. |
| `min` | `number` | `0` | Minimum value. |
| `max` | `number` | `100` | Maximum value. |
| `step` | `number` | `1` | Step between values. |
| `largeStep` | `number` | `10 * step` | Step for Shift + arrows and Page Up or Page Down. |
| `minStepsBetweenThumbs` | `number` | `0` | Minimum distance between thumbs, in steps. |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Direction: `horizontal` or `vertical`. |
| `origin` | `'start' \| 'center' \| 'end'` | `'start'` | Where the filled range starts: `start`, `center`, or `end`. |
| `thumbCollisionBehavior` | `'none' \| 'push' \| 'swap'` | `'none'` | What thumbs do when they meet: `none`, `push`, or `swap`. |
| `getAriaValueText` | `(details: ValueTextDetails) => string` | — | Returns readable text for a thumb value, for screen readers. |
| `name` | `string` | — | Form field name for the thumb inputs. |
| `disabled` | `boolean` | `false` | Disables the control. |
| `readOnly` | `boolean` | `false` | Shows the value but prevents changes. |
| `invalid` | `boolean` | `false` | Marks the control as invalid. |
| `required` | `boolean` | `false` | Requires a value before form submission. |
| `aria-label` | `string[]` | — | Accessible name of each thumb. |
| `aria-labelledby` | `string[]` | — | Ids of the elements that label each thumb. |
| `form` | `string` | — | Id of the form the underlying input belongs to. |
| `onFocusChange` | `(details: FocusChangeDetails) => void` | — | Called when another thumb gets focus. |
| `thumbAlignment` | `'contain' \| 'center'` | `'contain'` | Keeps thumbs inside the track (`contain`) or centered on the value (`center`). |
| `thumbSize` | `{ width: number; height: number }` | — | Thumb size, needed for `contain` alignment during server rendering. |
