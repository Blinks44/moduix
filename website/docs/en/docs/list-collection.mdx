# List Collection

A `ListCollection` is a data structure built from an array of items. It does not render a list and
does not provide selection or keyboard behavior. Use it as the data source for `Select`,
`Combobox`, and `Listbox`, or for an interface of your own.

Although this page is part of the moduix documentation, `ListCollection` is an Ark UI utility. It
is not re-exported by `@moduix/react`.

## API reference

<PrimitiveReference href="https://ark-ui.com/docs/collections/list-collection" />

A collection maps each item to a value and display text. It can also track disabled items, group
items, search by text, move through values, and create updated collections without changing the
original.

Import the helpers directly from Ark UI:

```tsx
import { createListCollection, useListCollection } from '@ark-ui/react/collection';
```

## Create a collection

When items have `label` and `value` properties, Ark uses them automatically. It also reads the
optional `disabled` property:

```tsx
const fruits = [
  { label: 'Apple', value: 'apple' },
  { label: 'Banana', value: 'banana' },
  { label: 'Blueberry', value: 'blueberry' },
];

const collection = createListCollection({
  items: fruits,
});
```

Pass the collection to an Ark-based component and render its items from `collection.items`. The
runnable example below shows the same pattern with `Select`.

Keep a static collection outside the component when its items do not change. If the items come
from props, state, or a request, memoize `createListCollection` so a new collection is created only
when the items change. Use `useListCollection` when filtering or updates are part of React state.

## Custom items

If your data uses different property names, tell the collection how to get the value, display text,
and disabled state:

```tsx
type Team = {
  id: number;
  name: string;
  archived: boolean;
};

const customTeams: Team[] = [
  { id: 1, name: 'Platform', archived: false },
  { id: 2, name: 'Legacy', archived: true },
];

const collection = createListCollection<Team>({
  items: customTeams,
  itemToValue: (item) => String(item.id),
  itemToString: (item) => item.name,
  isItemDisabled: (item) => item.archived,
});
```

Collection values are strings. Convert numeric IDs when you map application data to the collection.
By default, `itemToValue`, `itemToString`, and `isItemDisabled` read `value`, `label`, and
`disabled`.

| Option           | Purpose                                                                  |
| ---------------- | ------------------------------------------------------------------------ |
| `items`          | Items to include. Accepts any iterable.                                 |
| `itemToValue`    | Returns the string value used by the collection and its components.     |
| `itemToString`   | Returns the display text used for rendering and search.                 |
| `isItemDisabled` | Returns whether an item is disabled.                                    |
| `groupBy`        | Returns a group key for each item.                                      |
| `groupSort`      | Sorts groups with a comparator, an explicit order, `'asc'`, or `'desc'`. |

## Read and query

Use these methods to inspect items and convert between item objects and string values.

| API                                 | Result                                                         |
| ----------------------------------- | -------------------------------------------------------------- |
| `collection.items`                  | Items in the collection's current item order.                  |
| `collection.size`                   | Number of items.                                               |
| `getValues(items?)`                 | Values for all items or for the supplied items.                |
| `find(value)` / `findMany(values)`  | The item for one value or the items for several values.         |
| `at(index)`                         | The item at an index, or `null`.                               |
| `indexOf(value)`                    | The collection index, or `-1` when the value is not found.     |
| `has(value)` / `hasItem(item)`      | Whether a value or item is present.                            |
| `getItemValue(item)`                | The item's normalized string value.                            |
| `stringifyItem(item)`               | Display text for an item.                                      |
| `stringify(value)`                  | Display text for a value.                                      |
| `stringifyItems(items, separator?)` | Joined display text for several items.                         |
| `stringifyMany(values, separator?)` | Joined display text for several values.                        |
| `getItemDisabled(item)`             | The item's normalized disabled state.                          |
| `group()`                           | `[groupKey, items]` pairs using the configured grouping options. |

```tsx
collection.find('product'); // { label: 'Product', value: 'product' }
collection.stringify('product'); // 'Product'
collection.has('unknown'); // false
```

## Navigation

Use these properties and methods when an interaction needs to move through the enabled items or
sort values according to collection order:

```tsx
collection.firstValue; // 'platform'
collection.lastValue; // 'product' - disabled items are skipped
collection.getNextValue('platform'); // 'product'
collection.getPreviousValue('design'); // 'product'
collection.getValueRange('platform', 'product'); // ['platform', 'product']
collection.sort(['design', 'platform']); // ['platform', 'design']
```

`firstValue`, `lastValue`, `getNextValue`, `getPreviousValue`, and `getValueRange` skip disabled
items. The next and previous methods accept an optional `step` and `clamp` flag. Without clamping,
moving past an edge returns `null`. `getValueRange` returns values in collection order, regardless
of which endpoint comes first.

`compareValue(a, b)` compares two values by collection order. `isEqual(other)` compares the item
arrays of two collections. A collection is iterable. `toString()` returns a compact representation
of its items, while `toJSON()` returns its size and first and last values.

The `search(query, options)` method performs prefix matching for typeahead interactions and skips
disabled items. Keep the search state between calls:

```tsx
const searchState = { keysSoFar: '', timer: -1 };

const nextValue = collection.search('p', {
  state: searchState,
  currentValue: null,
  timeout: 350,
});
```

In a React component, keep `searchState` in a `useRef` so it survives re-renders.

## Immutable updates

Collection update methods return a new collection. Store the result when you need to keep the
change; the original collection is unchanged.

```tsx
const nextCollection = collection
  .append({ label: 'Support', value: 'support' })
  .remove('design')
  .reorder(0, 1);
```

| API                                      | Operation                                        |
| ---------------------------------------- | ------------------------------------------------ |
| `copy(items?)` / `setItems(items)`       | Copy the collection or replace all items.        |
| `update(value, item)`                    | Replace an existing item.                       |
| `upsert(value, item, mode?)`             | Update an item or add it at the chosen edge.    |
| `insert(index, ...items)`                | Insert items at an index.                       |
| `insertBefore(value, ...items)`          | Insert items before a value.                    |
| `insertAfter(value, ...items)`           | Insert items after a value.                     |
| `prepend(...items)` / `append(...items)` | Add items at the beginning or end.              |
| `filter(predicate)`                      | Return a collection containing matching items.  |
| `remove(...itemsOrValues)`               | Remove items or values.                         |
| `move(value, index)`                     | Move one value to an index.                     |
| `moveBefore(value, ...values)`           | Move the supplied values before a target value. |
| `moveAfter(value, ...values)`            | Move the supplied values after a target value.  |
| `reorder(from, to)`                      | Move an item between numeric indexes.           |

`upsert` accepts `mode: 'append' | 'prepend'` when the value does not exist.

## React state

Use `useListCollection` when filtering or collection updates should be driven by React state:

```tsx
import { useFilter } from '@ark-ui/react/locale';
import { useListCollection } from '@ark-ui/react/collection';

const teams = [
  { label: 'Platform', value: 'platform' },
  { label: 'Product', value: 'product' },
  { label: 'Design', value: 'design' },
];

function useTeams() {
  const { contains } = useFilter({ sensitivity: 'base' });

  return useListCollection({
    initialItems: teams,
    filter: contains,
    limit: 20,
  });
}
```

The hook returns the active `collection` and methods for filtering and updating it:
`filter`, `set`, `reset`, `clear`, `insert`, `insertBefore`, `insertAfter`, `remove`, `move`,
`moveBefore`, `moveAfter`, `reorder`, `append`, `prepend`, `update`, and `upsert`.

Call `filter('')` to show the unfiltered items again. Call `reset()` to restore `initialItems`.
The `filter` function receives an item's display text and the current filter text. For locale-aware
matching, pass a matcher such as `contains` from Ark UI's `useFilter`, as shown above.

Keep a static `createListCollection` outside the component when the items never change. Use the
hook when React needs to own filtering or collection mutations.
