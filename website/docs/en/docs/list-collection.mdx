# List Collection

`ListCollection` is Ark UI's data utility for array-backed items. It maps each item to a string
value and display text, and provides lookup, navigation, filtering, grouping, and immutable update
methods. It renders nothing and does not implement selection or keyboard interaction. `Select`,
`Combobox`, and `Listbox` consume it.

## Custom item shapes

Use `itemToValue`, `itemToString`, and `isItemDisabled` when your data does not use the default
property names. Collection values are strings, so convert numeric identifiers explicitly:

```tsx
type Team = {
  id: number;
  name: string;
  archived: boolean;
};

const collection = createListCollection<Team>({
  items: [
    { id: 1, name: 'Platform', archived: false },
    { id: 2, name: 'Legacy', archived: true },
  ],
  itemToValue: (item) => String(item.id),
  itemToString: (item) => item.name,
  isItemDisabled: (item) => item.archived,
});
```

| Option           | Purpose                                                      |
| ---------------- | ------------------------------------------------------------ |
| `items`          | Items to include. Accepts an iterable or readonly iterable. |
| `itemToValue`    | Returns the string value for an item.                        |
| `itemToString`   | Returns display and searchable text.                         |
| `isItemDisabled` | Returns whether an item is disabled.                         |
| `groupBy`        | Returns a group key for an item.                             |
| `groupSort`      | Sorts groups with a comparator, explicit order, `'asc'`, or `'desc'`. |

## Query and navigation

Use the collection to convert between item objects and values, inspect its order, or move through
enabled items:

| API                                | Result                                                        |
| ---------------------------------- | ------------------------------------------------------------- |
| `collection.items` / `collection.size` | Current items and item count.                             |
| `getValues(items?)`                | Values for all or selected items.                             |
| `find(value)` / `findMany(values)` | One item or several items by value.                           |
| `at(index)` / `indexOf(value)`     | An item by index, or an index by value.                       |
| `has(value)` / `hasItem(item)`     | Whether a value or item exists.                               |
| `getItemValue(item)`               | The normalized string value for an item.                      |
| `stringifyItem(item)` / `stringify(value)` | Display text for an item or value.                    |
| `getItemDisabled(item)`            | The normalized disabled state.                                |
| `group()`                          | `[groupKey, items]` pairs using the grouping options.          |

```tsx
const teamCollection = createListCollection({
  items: [
    { label: 'Platform', value: 'platform' },
    { label: 'Product', value: 'product' },
  ],
});

teamCollection.find('product'); // { label: 'Product', value: 'product' }
teamCollection.stringify('product'); // 'Product'
teamCollection.getNextValue('platform'); // 'product'
teamCollection.has('unknown'); // false
```

`firstValue`, `lastValue`, `getNextValue`, `getPreviousValue`, and `getValueRange` follow
collection order and skip disabled items. The traversal methods accept an optional `step` and
`clamp` flag. `sort(values)` orders values by collection order, and `compareValue(a, b)` compares
two values by that order.

For typeahead behavior, call `search(queryString, options)` with a stable search state:

```tsx
const searchState = { keysSoFar: '', timer: -1 };

const nextValue = collection.search('p', {
  state: searchState,
  currentValue: null,
  timeout: 350,
});
```

Keep `searchState` for the lifetime of the interaction. In React, `useRef` is a convenient place for
it. In Solid, keep the same object in the component scope or another stable store.

## Dynamic collections

Use `useListCollection` when the collection is filtered or updated from component state. Its
`filter` callback receives the item's display text, the current filter text, and the item. `limit`
can cap the number of items kept in the collection for large datasets.

In React, `collection` is a `ListCollection`. In Solid, it is an accessor, so use
`collection()` when passing it to a component or reading `collection().items` in a `<For>` loop.
The hook exposes `filter`, `set`, `reset`, `clear`, `insert`, `insertBefore`, `insertAfter`,
`remove`, `move`, `moveBefore`, `moveAfter`, `reorder`, `append`, `prepend`, `update`, and `upsert`.

Call `filter('')` to restore the unfiltered items and `reset()` to restore `initialItems`.

## Immutable updates

`ListCollection` update methods return a new collection. Keep the returned value when the change
should become the next collection:

```tsx
const nextCollection = collection
  .append({ label: 'Support', value: 'support' })
  .remove('design')
  .reorder(0, 1);
```

| API                                      | Operation                                        |
| ---------------------------------------- | ------------------------------------------------ |
| `copy(items?)` / `setItems(items)`       | Copy the collection or replace all items.       |
| `update(value, item)`                    | Replace an existing item.                       |
| `upsert(value, item, mode?)`             | Update an item or add it at an edge.             |
| `insert(index, ...items)`                | Insert items at an index.                        |
| `insertBefore` / `insertAfter`           | Insert items around a value.                     |
| `prepend` / `append`                     | Add items at the beginning or end.               |
| `filter(predicate)` / `remove(...)`      | Keep matching items or remove items and values.  |
| `move` / `moveBefore` / `moveAfter`       | Move one or more values.                         |
| `reorder(from, to)`                      | Move an item between numeric indexes.            |

`upsert` accepts `mode: 'append' | 'prepend'` when the value does not exist. The original collection
is unchanged.

## Integration and accessibility

Use `Select`, `Combobox`, or `Listbox` when you need their built-in selection, focus, keyboard, and
ARIA behavior. The collection only supplies data. If you render a custom interface, implement its
accessible name, keyboard interaction, roles, states, and empty or disabled item feedback in the
UI layer.
