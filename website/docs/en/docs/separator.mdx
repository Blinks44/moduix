## API Reference

Ark UI does not ship a dedicated separator primitive. moduix builds this component with the official
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) and follows Ark's guidance on
[composition](https://ark-ui.com/docs/guides/composition), [styling](https://ark-ui.com/docs/guides/styling), and
[refs](https://ark-ui.com/docs/guides/ref).

The `orientation`, `variant`, and `size` props follow the familiar Chakra UI Separator model. See the
[Chakra UI Separator docs](https://chakra-ui.com/docs/components/separator) for the upstream reference
that informed this API.

## Basic


Use `Separator` to make the boundary between related sections visible. The defaults are
`orientation="horizontal"`, `variant="solid"`, and `size="sm"`.

## Anatomy

`Separator` exposes one root part.

```text
Separator
└─ root[data-scope="separator"][data-part="root"][data-slot="separator-root"]
```

| Part        | Role                                                                       |
| ----------- | -------------------------------------------------------------------------- |
| `Separator` | Root divider element. Sets orientation, accessibility metadata, and style. |

## Composition

`Separator` is a root-only component, so it does not own state or require a provider. Use
`<Separator />` for the usual divider. When another element must host the divider, use `asChild`
with one child that accepts the merged role, ARIA,
`data-*`, class, and ref props. React and Vue pass the child element directly, while Solid uses
`asChild={(props) => <hr {...props()} />}`.

## Styling

Use `className` in React or `class` in Solid and Vue on the root. Tailwind variants use native utility
classes and consumer classes; the CSS properties below customize the CSS Modules variants. Data
attributes and `data-slot` hooks are shared by both styling tracks.

### Styling hooks

- `data-scope="separator"` and `data-part="root"` identify the Ark-style root part.
- `data-slot="separator-root"` is the stable moduix selector.
- `data-orientation="horizontal"` and `data-orientation="vertical"` target axis-specific styles.
- `data-size="xs|sm|md|lg"` and `data-variant="solid|dashed|dotted"` expose the visual settings.
- `className` or `class` and `style` are applied directly to the root separator element.
