## API Reference

Ark UI does not ship a dedicated separator primitive. moduix builds this component with the official
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) and follows Ark's guidance on
[composition](https://ark-ui.com/docs/guides/composition), [styling](https://ark-ui.com/docs/guides/styling), and
[refs](https://ark-ui.com/docs/guides/ref).

The `orientation`, `variant`, and `size` props follow the familiar Chakra UI Separator model. See the
[Chakra UI Separator docs](https://chakra-ui.com/docs/components/separator) for the upstream reference
that informed this API.

## Anatomy

`Separator` exposes one root part.

```text
Separator / Separator.Root
└─ root[data-scope="separator"][data-part="root"][data-slot="separator-root"]
```

| Part                           | Role                                                                   |
| ------------------------------ | ---------------------------------------------------------------------- |
| `Separator` / `Separator.Root` | Root divider element. Sets orientation, accessibility metadata, and visual style. |

Use `className` and the `--moduix-separator-*` CSS properties to style the root. Use `asChild` when a
different element should host the divider.

## Composition

### Recommended composition

For most dividers, use the short `<Separator />` form. It is the same root component as
`<Separator.Root />`, so you can switch between them without changing behavior.

### When to go custom

Use `asChild` only when you need a different element to host the divider. `Separator` already renders a
semantic divider. Pass one child that can receive the merged `role`, ARIA and `data-*` attributes, class
name, and ref.

### Default props

| Prop          | Default      | Notes                                  |
| ------------- | ------------ | -------------------------------------- |
| `orientation` | `horizontal` | `horizontal`, `vertical`               |
| `variant`     | `solid`      | `solid`, `dashed`, `dotted`            |
| `size`        | `sm`         | `xs`, `sm`, `md`, `lg`                 |
| `asChild`     | `false`      | Ark factory single-child composition   |
| `role`        | `separator`  | Pass `presentation` for decorative use |

### Behavioral notes

- When its role is `separator`, `Separator` sets `aria-orientation` from `orientation`. For another role,
  such as `presentation`, it omits `aria-orientation`, even if you pass one yourself.
- Use `role="presentation"` when the line is purely visual and carries no structural meaning for assistive
  technology.
- A horizontal separator fills the available width by default.
- A vertical separator is `1em` high by default, which helps it align with inline text and compact action rows.
- `Separator` is not interactive and does not expose state, callbacks, disabled behavior, or focus management.
- For whitespace-only gaps, use layout primitives or spacing tokens.

## Styling

`Separator` exposes Ark-style part selectors and a focused set of `--moduix-separator-*` CSS properties for
color, border style, thickness, and orientation-specific length.

### Styling hooks

- `data-scope="separator"` and `data-part="root"` identify the Ark-style root part.
- `data-slot="separator-root"` is the stable moduix selector.
- `data-orientation="horizontal"` and `data-orientation="vertical"` target axis-specific styles.
- `data-size="xs|sm|md|lg"` and `data-variant="solid|dashed|dotted"` expose the visual settings.
- `className` and `style` are applied directly to the root separator element.
