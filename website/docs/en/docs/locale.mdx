`LocaleProvider` supplies a locale and its text direction to a subtree. Ark formatters and locale-aware content use
that context.

## Set a locale

Wrap the part of the interface that shares a locale. Formatters and locale-aware components below the provider read
the same context.

<Example name="locale/basic" />

`LocaleProvider` accepts a BCP 47 locale string such as `fr-FR`. Without a provider, Ark uses `en-US` and `ltr`.

## Read the locale context

`useLocaleContext` returns `locale` and `dir` from the nearest provider. Use them when custom content must follow the
same language and direction as locale-aware components. React reads the values directly; Solid reads them from an
accessor. Vue returns a computed ref: use `.value` in setup code; templates unwrap it automatically. Svelte returns a getter: call `locale()` to read `locale` and `dir`.

## Set document language and direction

`LocaleProvider` derives `dir` for Ark from the locale, but it does not change the document's native `lang` and `dir`
attributes. Set both on the document root when the whole application uses one direction:

## Translate default labels

`LocaleProvider` does not translate text. Icon-only controls and a few landmarks, such as close buttons, clear buttons,
`Spinner`, `TableEmpty`, and `Breadcrumbs`, fall back to English accessible names like `Close` or `Clear search`.

Wrap your application with `ModuixProvider` to set both `locale` and partial accessible label overrides in one place, or use `LabelsProvider` when you only want to override labels:

```tsx
import { ModuixProvider } from '@moduix/react/locale';

export function App() {
  return (
    <ModuixProvider
      locale="de-DE"
      labels={{
        close: 'Schließen',
        closeDialog: 'Dialog schließen',
        clearSearch: 'Suche leeren',
        loading: 'Wird geladen',
        noResults: 'Keine Ergebnisse.',
      }}
    >
      {/* app */}
    </ModuixProvider>
  );
}
```

Nested `LabelsProvider` or `ModuixProvider` instances merge their `labels` over the nearest parent provider, while explicit per-component `aria-label` or `aria-labelledby` props always take precedence:

```tsx
<DialogCloseIcon aria-label="Dismiss modal" />
<CommandPaletteSearch aria-label="Find a command" />
```

Custom components can read the active label map via `useA11yLabels()` (React returns `A11yLabels`, Solid returns `Accessor<A11yLabels>`, Vue returns `ComputedRef<A11yLabels>`, and Svelte returns `() => A11yLabels`).
