`LocaleProvider` supplies a locale and its text direction to a subtree. Ark formatters and locale-aware content use
that context.

## API Reference

<PrimitiveReference href="https://ark-ui.com/docs/utilities/locale" />

Import the utility from the matching moduix package, which re-exports the Ark UI locale provider:

`LocaleProvider` accepts a BCP 47 locale string such as `fr-FR`. Without a provider, Ark uses `en-US` and `ltr`.

## Read the locale context

`useLocaleContext` returns `locale` and `dir` from the nearest provider. Use them when custom content must follow the
same language and direction as locale-aware components. React reads the values directly; Solid reads them from an
accessor.

## Set document language and direction

`LocaleProvider` derives `dir` for Ark from the locale, but it does not change the document's native `lang` and `dir`
attributes. Set both on the document root when the whole application uses one direction:

For an RTL section inside an LTR application, set `lang` and the matching `dir` on that section's root element, as in
the context example. If users can switch between LTR and RTL locales without a page reload, update the document
attributes together with `locale`. See [Right-to-left (RTL)](/docs/rtl) for portals, logical CSS properties, and
directional icons.
