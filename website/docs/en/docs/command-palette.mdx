## API Reference

Ark UI does not provide a dedicated `command-palette` primitive. `CommandPalette` combines Ark
[`Dialog`](https://ark-ui.com/docs/components/dialog) and
[`Combobox`](https://ark-ui.com/docs/components/combobox), then adds a standard palette shell and
search row. The wrapper follows Ark's guidance for [composition](https://ark-ui.com/docs/guides/composition),
[styling](https://ark-ui.com/docs/guides/styling), and [refs](https://ark-ui.com/docs/guides/ref).

## Basic

Use `CommandPalette.Panel` for the standard dialog layout. It renders the backdrop, positioner, content,
and body for you. Add `CommandPalette.Combobox` inside it, pass a collection, and render the filtered
items in `CommandPalette.List`. `CommandPalette.Search` adds the input and a clear button that appears
once the user enters a query.

         │  ├─ CommandPalette.Title
         │  └─ CommandPalette.Description
         └─ CommandPalette.Body
            └─ CommandPalette.Combobox
               ├─ CommandPalette.Control
               │  ├─ CommandPalette.Input
               │  └─ CommandPalette.ClearTrigger
               ├─ CommandPalette.List
               │  ├─ CommandPalette.Empty
               │  └─ CommandPalette.ItemGroup
               │     ├─ CommandPalette.ItemGroupLabel
               │     └─ CommandPalette.Item
               │        ├─ CommandPalette.ItemIcon
               │        ├─ CommandPalette.ItemText
               │        │  ├─ CommandPalette.ItemLabel
               │        │  └─ CommandPalette.ItemDescription
               │        ├─ CommandPalette.ItemMeta
               │        └─ CommandPalette.ItemIndicator
               └─ CommandPalette.Footer
                  └─ CommandPalette.Kbd

CommandPalette.Panel
└─ shorthand for Backdrop, Positioner, Content, and Body

└─ the same content tree connected to state from useDialog()

| --- | --- |
| `CommandPalette` / `CommandPalette.Root` | Owns Ark Dialog state and the optional global shortcut listener. |
| `CommandPalette.RootProvider` | Connects the palette parts to dialog state created outside the rendered tree. |
| `CommandPalette.Trigger` | Opens the palette. Use `asChild` to provide your own trigger element. |
| `CommandPalette.Backdrop` | Ark Dialog backdrop with `data-state` animation state. |
| `CommandPalette.Positioner` | Positions the dialog in the viewport and keeps its content within it. |
| `CommandPalette.Content` | The dialog content and visual palette surface. |
| `CommandPalette.Panel` | Convenience shell for the standard backdrop, positioner, content, and body. |
| `CommandPalette.Header` / `Title` / `Description` | Optional layout helpers and accessible Dialog title and description parts. |
| `CommandPalette.Body` | Layout boundary for the combobox region inside the dialog. |
| `CommandPalette.Combobox` | Ark Combobox root for search state and command selection. |
| `CommandPalette.Control` | Wraps the search input and clear button. |
| `CommandPalette.Input` | Ark Combobox input. |
| `CommandPalette.Search` | Convenience search row that renders `Control`, `Input`, and `ClearTrigger`. It also adds a default accessible label to the input. Render the explicit parts when their individual configuration is needed. |
| `CommandPalette.ClearTrigger` | Clears the search input and stays hidden while it is empty. |
| `CommandPalette.List` | Ark Combobox listbox wrapped in a moduix `ScrollArea`. |
| `CommandPalette.Empty` | Message shown when the filtered collection has no results. |
| `CommandPalette.ItemGroup` / `ItemGroupLabel` | Grouped sections of command results. |
| `CommandPalette.Item` | A command row with highlighted, selected, and disabled states. |
| `CommandPalette.ItemText` | Text container for the command label and description. |
| `CommandPalette.ItemIndicator` | Selected-state indicator with a check icon by default. |
| `CommandPalette.ItemIcon`, `ItemLabel`, `ItemDescription`, `ItemMeta` | Visual parts for command icons, text, descriptions, and trailing metadata. |
| `CommandPalette.Separator` | Visual separator between command sections. |
| `CommandPalette.Footer` / `Kbd` | Footer area and command-palette wrapper around moduix `Kbd`. |

## Composition

The root automatically portals `Backdrop` and `Positioner`. Set `portalled={false}` to render them
inline, or pass `portalRef` to use a custom container. Do not add a separate `Portal` wrapper. The
structural parts remain explicit and can be styled individually.

### Recommended composition

Use `useListCollection` from `@ark-ui/react/collection` for command objects. Set `itemToString` and
`itemToValue` so the collection knows how to search and identify each command, and use `groupBy` when
commands should be shown in sections. In `onInputValueChange`, call `filter(details.inputValue)` to
update the visible items. If the collection is managed outside the palette, reset it with `filter('')`
when the dialog closes so the next open starts with the full list. `Panel` and `Search` cover the usual
dialog and search markup without hiding the collection or rendering logic.

### When to go custom

Render `Backdrop`, `Positioner`, `Content`, `Header`, `Body`, `Control`, `Input`, and `ClearTrigger`
directly when you need a custom dialog layout or search controls. Set `closeOnSelect={false}` on
`CommandPalette.Combobox` when selecting a command should leave the palette open. Ark-backed parts keep
their `asChild` and ref behavior. Give the root an
`aria-label`, or render `CommandPalette.Title` when the dialog needs a visible title. `Search` adds a
default accessible label to its input; a direct `CommandPalette.Input` should have its own label or
`aria-label`. `CommandPalette.ItemIndicator` renders a check icon by default and can share the trailing
row layout with `ItemMeta`.

For externally managed dialog state, create it with `useDialog` from `@moduix/react/dialog` and pass
the returned state to `CommandPalette.RootProvider`. If a child needs to read or update that state,
use `useDialogContext` from the same package. Import advanced Combobox provider and context APIs
directly from `@ark-ui/react/combobox`; `CommandPalette` does not re-export them.

Other Ark Dialog props, including `modal`, `closeOnEscape`, `closeOnInteractOutside`, `ids`,
`initialFocusEl`, `finalFocusEl`, `present`, `skipAnimationOnMount`, and `onExitComplete`, keep their original contracts. Refs
forward to the matching Ark DOM parts. The component does not render a `HiddenInput` because a command
palette is an action surface, not a form control. Use the standalone [Combobox](/docs/combobox) when
you need native form submission or a Combobox feature that is outside this command-palette pattern.

### Default props

Portalled overlay content is mounted lazily and unmounted after its exit animation by default. It is not
in the DOM until the first open and is removed after closing. Set `unmountOnExit={false}` to keep it
mounted after the first open. Set both `lazyMount={false}` and `unmountOnExit={false}` only when eager
initial rendering is needed.

| Prop | Default | Notes |
| --- | --- | --- |
| `CommandPalette.portalled` | `true` | Portals `Backdrop` and `Positioner`. Set to `false` for inline rendering. |
| `CommandPalette.portalRef` | `-` | Sends portalled content to a custom container. |
| `CommandPalette.shortcut` | `false` | Pass `mod+k` or another [Ark Hotkeys](https://ark-ui.com/docs/utilities/hotkeys)-compatible shortcut to enable the toggle listener. |
| `CommandPalette.lazyMount` | `true` | Defers dialog DOM creation until the palette is opened. |
| `CommandPalette.unmountOnExit` | `true` | Keeps the content mounted during the exit animation, then removes it. |
| `CommandPalette.Combobox.open` | `true` | Keeps the listbox visible while the dialog is mounted. |
| `CommandPalette.Combobox.inputBehavior` | `autohighlight` | Highlights the first matching command as the user types. |
| `CommandPalette.Combobox.selectionBehavior` | `preserve` | Keeps the typed query instead of replacing it with the selected item. |
| `CommandPalette.Combobox.disableLayer` | `true` | Avoids registering an extra dismissable layer inside the dialog. |
| `CommandPalette.Combobox.closeOnSelect` | `true` | Closes the palette after an item is selected. |

### Behavioral notes

The global shortcut is opt-in because an application may mount more than one command palette. Its syntax
is parsed by `@zag-js/hotkeys`, the hotkey utility used by Ark. The component owns document-listener
cleanup and repeated-key suppression. Use `mod+k` for platform-aware Command/Control bindings.
It ignores editable targets while the palette is closed; when the palette is open, the same shortcut closes it.

Inside the palette, Arrow keys move the highlighted item, Home and End jump to the first or last item,
Enter selects the highlighted item, and Escape closes the dialog. `CommandPalette.ClearTrigger` clears
`inputValue`, not the Combobox selection value, and stays hidden while the search is empty. The
`CommandPalette` `onOpenChange(details)` callback and Combobox callbacks such as
`onInputValueChange(details)`, `onSelect(details)`, and `onValueChange(details)` keep Ark's detail object
shape.

## Styling

Use CSS variables on the trigger, backdrop, content, list, and item parts when the palette needs to
match a denser tool UI or a branded overlay. Use the structural parts when you need to change layout
or layering. `CommandPalette.List` remains scrollable, but it does not render a visible scrollbar track.

### Styling hooks

- Exported parts expose stable `data-slot` hooks, including `command-palette-trigger`, `command-palette-backdrop`, `command-palette-positioner`, `command-palette-content`, `command-palette-title`, `command-palette-description`, `command-palette-header`, `command-palette-body`, `command-palette-combobox`, `command-palette-control`, `command-palette-input`, `command-palette-clear-trigger`, `command-palette-list`, `command-palette-scroll-area`, `command-palette-scroll-viewport`, `command-palette-scroll-content`, `command-palette-empty`, `command-palette-item-group`, `command-palette-item-group-label`, `command-palette-item`, `command-palette-item-text`, `command-palette-item-indicator`, `command-palette-item-icon`, `command-palette-item-label`, `command-palette-item-description`, `command-palette-item-meta`, `command-palette-separator`, `command-palette-footer`, and `command-palette-kbd`.
- Ark Dialog state hooks include `data-scope="dialog"`, `data-part`, and `data-state="open" | "closed"` on dialog parts such as the trigger, backdrop, and content.
- Ark Combobox state hooks include `data-scope="combobox"`, `data-part`, `data-state`, `data-highlighted`, `data-disabled`, `data-invalid`, and `data-empty` where applicable.
- Motion is tied to Ark `data-state`. Legacy `data-starting-style`, `data-ending-style`, and `data-open` attributes are not part of the command-palette contract.
