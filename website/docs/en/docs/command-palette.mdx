## API Reference

Ark UI does not provide a dedicated `command-palette` primitive. `CommandPalette` combines Ark
[`Dialog`](https://ark-ui.com/docs/components/dialog) and
[`Combobox`](https://ark-ui.com/docs/components/combobox), then adds a standard palette shell and
search row. The wrapper follows Ark's guidance for [composition](https://ark-ui.com/docs/guides/composition),
[styling](https://ark-ui.com/docs/guides/styling), and [refs](https://ark-ui.com/docs/guides/ref).

## Basic

`CommandPalette` ships for React and Solid in both the CSS Modules and Tailwind packages. The rendered
preview on this page uses the React CSS Modules package; the framework tabs show native source for the
same public contract.

Use `CommandPalette.Panel` for the standard dialog layout. It renders the backdrop, positioner, content,
and body for you. Add `CommandPalette.Combobox` inside it, pass a collection, and render the filtered
items in `CommandPalette.List`. `CommandPalette.Search` adds the input and a clear button that appears
once the user enters a query.

## Anatomy

```text
CommandPalette / CommandPalette.Root
├─ CommandPalette.Trigger
└─ Overlay content (automatically portalled)
   ├─ CommandPalette.Backdrop
   └─ CommandPalette.Positioner
      └─ CommandPalette.Content
         ├─ CommandPalette.Header
         │  ├─ CommandPalette.Title
         │  └─ CommandPalette.Description
         └─ CommandPalette.Body
            └─ CommandPalette.Combobox
               ├─ CommandPalette.Control
               │  ├─ CommandPalette.Input
               │  └─ CommandPalette.ClearTrigger
               ├─ CommandPalette.List
               │  ├─ CommandPalette.Empty
               │  └─ CommandPalette.ItemGroup
               │     ├─ CommandPalette.ItemGroupLabel
               │     └─ CommandPalette.Item
               │        ├─ CommandPalette.ItemIcon
               │        ├─ CommandPalette.ItemText
               │        │  ├─ CommandPalette.ItemLabel
               │        │  └─ CommandPalette.ItemDescription
               │        ├─ CommandPalette.ItemMeta
               │        └─ CommandPalette.ItemIndicator
               └─ CommandPalette.Footer
                  └─ CommandPalette.Kbd

CommandPalette.Panel
└─ shorthand for Backdrop, Positioner, Content, and Body

CommandPalette.RootProvider
└─ the same content tree connected to state from useDialog()
```

| Part | Role |
| --- | --- |
| `CommandPalette` / `CommandPalette.Root` | Owns Ark Dialog state and the optional global shortcut listener. |
| `CommandPalette.RootProvider` | Connects the palette parts to dialog state created outside the rendered tree. |
| `CommandPalette.Trigger` | Opens the palette. Use `asChild` to provide your own trigger element. |
| `CommandPalette.Backdrop` | Ark Dialog backdrop with `data-state` animation state. |
| `CommandPalette.Positioner` | Positions the dialog in the viewport and keeps its content within it. |
| `CommandPalette.Content` | The dialog content and visual palette surface. |
| `CommandPalette.Panel` | Convenience shell for the standard backdrop, positioner, content, and body. |
| `CommandPalette.Header` / `Title` / `Description` | Optional layout helpers and accessible Dialog title and description parts. |
| `CommandPalette.Body` | Layout boundary for the Combobox region inside the dialog. |
| `CommandPalette.Combobox` | Ark Combobox root for search state and command selection. |
| `CommandPalette.Control` | Wraps the search input and clear button. |
| `CommandPalette.Input` | Ark Combobox input. |
| `CommandPalette.Search` | Convenience search row that renders `Control`, `Input`, and `ClearTrigger`. It also adds a default accessible label to the input. Render the explicit parts when their individual configuration is needed. |
| `CommandPalette.ClearTrigger` | Clears the search input and stays hidden while it is empty. |
| `CommandPalette.List` | Ark Combobox listbox wrapped in a moduix `ScrollArea`. |
| `CommandPalette.Empty` | Message shown when the filtered collection has no results. |
| `CommandPalette.ItemGroup` / `ItemGroupLabel` | Grouped sections of command results. |
| `CommandPalette.Item` | A command row with highlighted, selected, and disabled states. |
| `CommandPalette.ItemText` | Text container for the command label and description. |
| `CommandPalette.ItemIndicator` | Selected-state indicator with a check icon by default. |
| `CommandPalette.ItemIcon`, `ItemLabel`, `ItemDescription`, `ItemMeta` | Visual parts for command icons, text, descriptions, and trailing metadata. |
| `CommandPalette.Separator` | Visual separator between command sections. |
| `CommandPalette.Footer` / `Kbd` | Footer area and command-palette wrapper around moduix `Kbd`. |

## Composition

The root owns Dialog state and automatically portals `Backdrop` and `Positioner`. Set `portalled={false}`
to render them inline, or pass `portalRef` for a custom container. Use `Panel` and `Search` for the usual
layout, and render the structural parts directly when the dialog or search controls need a different shape.

Keep collection filtering with the `Combobox` owner: configure `useListCollection` with `itemToString`,
`itemToValue`, and `groupBy`, then call `filter(details.inputValue)` from `onInputValueChange`. Reset the
filter on close when the collection is managed outside the palette. Use `closeOnSelect={false}` to keep the
palette open after an action, or `RootProvider` with `useDialog` from the matching framework package when
dialog state must be created outside the rendered tree.

## Styling

Use CSS variables on the trigger, backdrop, content, list, and item parts when the palette needs to match
a denser tool UI or a branded overlay. Use the structural parts when you need to change layout or layering.
`CommandPalette.List` remains scrollable, but it does not render a visible scrollbar track.

### Styling hooks

- Exported parts expose stable `data-slot` hooks, including `command-palette-trigger`, `command-palette-backdrop`, `command-palette-positioner`, `command-palette-content`, `command-palette-title`, `command-palette-description`, `command-palette-header`, `command-palette-body`, `command-palette-combobox`, `command-palette-control`, `command-palette-input`, `command-palette-clear-trigger`, `command-palette-list`, `command-palette-scroll-area`, `command-palette-scroll-viewport`, `command-palette-scroll-content`, `command-palette-empty`, `command-palette-item-group`, `command-palette-item-group-label`, `command-palette-item`, `command-palette-item-text`, `command-palette-item-indicator`, `command-palette-item-icon`, `command-palette-item-label`, `command-palette-item-description`, `command-palette-item-meta`, `command-palette-separator`, `command-palette-footer`, and `command-palette-kbd`.
- Ark Dialog state hooks include `data-scope="dialog"`, `data-part`, and `data-state="open" | "closed"` on dialog parts such as the trigger, backdrop, and content.
- Ark Combobox state hooks include `data-scope="combobox"`, `data-part`, `data-state`, `data-highlighted`, `data-disabled`, `data-invalid`, and `data-empty` where applicable.
- Motion is tied to Ark `data-state`. Legacy `data-starting-style`, `data-ending-style`, and `data-open` attributes are not part of the command-palette contract.
