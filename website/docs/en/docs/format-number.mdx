`Format.Number` formats a numeric value with the browser's `Intl.NumberFormat` rules. It is a read-only formatter, not
an input control.

## Basic

Pass a number to `value`. Without formatting options, the result follows the active locale. `Format.Number` renders
only text, so keep its label and surrounding layout in your own markup.

## Formatting options

`Format.Number` accepts the standard `Intl.NumberFormatOptions`, including `style`, `currency`, `unit`,
`unitDisplay`, `notation`, and fraction digit options.

`style="percent"` multiplies the value by 100: pass `0.0642` to display `6.4%` with
`maximumFractionDigits={1}`. Combine `minimumFractionDigits` and `maximumFractionDigits` when the number of decimal
places must stay fixed. Use `notation="compact"` for values such as `125_000`, and `style="unit"` with a supported
`unit` when the number represents a measurement.

## Locale
