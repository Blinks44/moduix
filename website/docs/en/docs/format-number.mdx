## When to use it

`Format.Number` is for displaying read-only numeric values. It applies the active locale's rules for grouping,
decimal separators, currencies, percentages, units, and compact notation. For editable values, use moduix
`NumberInput`.

Import `Format` directly from Ark UI:

```tsx
import { Format } from '@ark-ui/react';
```

## Basic

Pass a number to `value`. With no formatting options, the component follows the default behavior of
`Intl.NumberFormat` for the active locale. Without a `LocaleProvider`, Ark uses `en-US`.

`Format.Number` renders only text. Place it next to a label or another element that explains what the value means. In
this example, `Card` and `Stack` provide the surrounding context and visual hierarchy.

## Currency, percentage, and compact notation

`Format.Number` accepts the standard `Intl.NumberFormat` options. For a monetary value, combine
`style="currency"` with the `currency` prop set to a currency code. Use `style="percent"` for percentages, and use
`notation="compact"` when space is limited, such as in a dashboard.

The input value for 6.42% is `0.0642`; `6.42` is formatted as 642%. Set `maximumFractionDigits={2}` when you need to
keep both decimal places. Use `minimumFractionDigits` and `maximumFractionDigits` when the number of fraction digits
needs to stay consistent.

## Locale and units

`Format.Number` gets its locale from `LocaleProvider`. moduix re-exports the provider from
`@moduix/react/locale`, so you can use it around the part of the interface that shares one locale:

```tsx
import { Format } from '@ark-ui/react';
import { LocaleProvider } from '@moduix/react/locale';

export function LocalizedPrice() {
  return (
    <LocaleProvider locale="de-DE">
      <Format.Number currency="EUR" style="currency" value={1234.5} />
    </LocaleProvider>
  );
}
```

For measurements, use `style="unit"` with a supported `unit`, such as `kilometer`, `celsius`, or `megabyte`. Set
`unitDisplay` to `"narrow"`, `"short"`, or `"long"` to choose how the unit is written.

## Using moduix

Keep `Format.Number` close to the label, status, or metric it describes. Use moduix `Card`, `Stack`, `Text`, and
data-display components to structure the interface. There is no need to create a wrapper just to call the formatter.
For editable amounts, use `NumberInput`; its `formatOptions` prop controls the display format and parsing of the
entered value.

## Ownership

Ark UI provides `Format.Number` and the number-formatting logic. moduix re-exports `LocaleProvider` and provides the
components used to structure the interface. It does not re-export `Format.Number`, so import `Format` from Ark UI.
