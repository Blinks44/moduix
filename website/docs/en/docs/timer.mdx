`TimerSegments` is the quickest way to render a conventional time display separated by colons. By default, it shows
hours, minutes, and seconds. Pass `types` to choose a different set of units. Use the individual parts when you need
unit labels, custom separators, or per-item styling.

`TimerSegments` accepts all `TimerArea` props except `children` and `asChild`, and forwards the area ref. Because
it creates the items and separators itself, use `TimerArea` when you need to replace its host element or provide
custom children.

## Composition

`Timer` owns the timer state. `TimerSegments` creates its own `TimerArea`,
`TimerItem`, and `TimerSeparator` parts, so use the full `TimerArea` composition when you need unit labels,
custom separators, or per-item layout.

Use `TimerRootProvider` with `useTimer()` when the state must be created outside the rendered part tree. Use
`TimerContext` or `useTimerContext()` when other UI needs the timer state or methods. In Solid, the store and context
are accessors, so read them as `timer()` and `api()`. In Vue, refs are unwrapped in templates, while script logic
uses the usual `.value` access.

In the installed Ark UI version, `TimerItem` replaces child content with the formatted value before `asChild`
composition. Its replacement host is therefore lost in Vue and React. Use the default `TimerItem` host until
upstream fixes this behavior; the examples above use that supported composition.

## Styling

Use `className` in React or `class` in Solid and Vue on any exported part. Tailwind variants use native
utilities and consumer classes. CSS Modules variants build on foundation tokens and have no component
variables: a class on a part, or a `data-slot` selector, overrides the layered component styles.

### Styling hooks

| Part | `data-slot` |
| --- | --- |
| `Timer` | `timer-root` |
| `TimerRootProvider` | `timer-root-provider` |
| `TimerArea` | `timer-area` |
| `TimerItem` | `timer-item` |
| `TimerSeparator` | `timer-separator` |
| `TimerControl` | `timer-control` |
| `TimerActionTrigger` | `timer-action-trigger` |

- Ark anatomy attributes: `data-scope="timer"` and
  `data-part="root|area|item|separator|control|action-trigger"`.
- `TimerItem` exposes `data-type` and Ark's `--value` runtime variable.
- Ark adds `hidden` to action triggers that are unavailable in the current timer state.
