## Basic

`Timer.Segments` is the quickest way to render a conventional time display separated by colons. By default, it
shows hours, minutes, and seconds. Pass `types` to choose a different set of units. Use the individual parts when
you need unit labels, custom separators, or per-item styling.

`Timer.Segments` accepts all `Timer.Area` props except `children` and `asChild`, and forwards the area ref. Because
it creates the items and separators itself, use `Timer.Area` when you need to replace its host element or provide
custom children.

## Anatomy

```text
Timer.Root
├─ Timer.Area
│  ├─ Timer.Item
│  └─ Timer.Separator
└─ Timer.Control
   └─ Timer.ActionTrigger

Timer.RootProvider
└─ same part tree connected to state from `useTimer()`

Timer.Segments
└─ Timer.Area with Timer.Item and Timer.Separator
```

| Part                   | Role                                                                    |
| ---------------------- | ----------------------------------------------------------------------- |
| `Timer` / `Timer.Root` | Owns the Ark timer state, ids, interval, and callbacks.                 |
| `Timer.RootProvider`   | Connects parts to timer state created with Ark `useTimer()`.            |
| `Timer.Segments`       | Builds standard time units and separators.                              |
| `Timer.Area`           | Groups the visible time parts.                                          |
| `Timer.Item`           | Displays one formatted time unit such as `hours`, `minutes`, or `seconds`. |
| `Timer.Separator`      | Displays a separator between time units.                                |
| `Timer.Control`        | Groups action triggers.                                                 |
| `Timer.ActionTrigger`  | Dispatches the `start`, `pause`, `resume`, `reset`, or `restart` action. |

## Composition

### Recommended composition

`Timer` is the abbreviated root component and is equivalent to `Timer.Root`. Use `Timer.Segments` for the default
hours, minutes, and seconds display without repeating items and separators by hand. Pass `types` when you need a
different set of units.

Use `targetMs` to set the value at which the timer completes. Use `startMs` to set the initial elapsed or remaining
time. For a countdown, combine `countdown` with `startMs` to start from a specified duration.

### When to go custom

Use `Timer.RootProvider` with `useTimer()` when you need to create the timer API separately from the markup that
consumes it. Use `Timer.Context` or `useTimerContext()` when other UI needs access to `running`, `paused`, `time`,
`formattedTime`, `progressPercent`, or the programmatic `start()`, `pause()`, `resume()`, `reset()`, and `restart()`
methods.

Use `interval` for sub-second updates. Keep it as large as the UI allows; Ark defaults to `1000` milliseconds.

### Default props

| Prop              | Default   | Notes                                                               |
| ----------------- | --------- | ------------------------------------------------------------------- |
| `autoStart`       | `false`   | Starts the timer on mount.                                          |
| `countdown`       | `false`   | Counts down instead of up.                                          |
| `startMs`         | `0`       | Initial elapsed or remaining time in milliseconds.                   |
| `targetMs`        | -         | Completion boundary in milliseconds.                                |
| `interval`        | `1000`    | Tick interval in milliseconds.                                      |
| `ids`             | generated | Overrides the generated root and area ids.                           |
| `translations`    | built in  | Sets the accessible area label, including through `areaLabel`.       |
| `onTick(details)` | -         | Runs after each timer tick.                                           |
| `onComplete()`    | -         | Runs when the timer reaches its completion boundary.                  |

### Behavioral notes

`Timer.ActionTrigger` renders a button by default, so keyboard activation follows native button semantics. Ark hides
the state-dependent `start`, `pause`, `resume`, and `reset` actions when they are unavailable; `restart` remains
available when rendered. The timer does not implement composite keyboard navigation or automatic focus movement
between controls.

The Ark parts exposed by moduix, including `Timer.Root`, `Timer.RootProvider`, `Timer.Area`, `Timer.Item`,
`Timer.Separator`, `Timer.Control`, and `Timer.ActionTrigger`, support `asChild` through Ark's polymorphic
composition. Keep replacement elements semantic, especially for `Timer.ActionTrigger`. `Timer.Segments`
intentionally does not support `asChild` because it owns the generated area and children.

`Timer.Item` preserves Ark's `data-scope="timer"`, `data-part="item"`, `data-type`, and `--value` attributes.
`Timer.Segments` is limited to standard items and separators, so unit labels remain an explicit composition around
`Timer.Item`. moduix adds a centered root layout, a time area that wraps when needed,
stable `data-slot` selectors, SVG icon sizing inside action triggers, and CSS defaults without changing
the Ark timer machine.

### Styling hooks

- `data-slot="timer-root"`, `timer-root-provider`, `timer-area`, `timer-item`,
  `timer-separator`, `timer-control`, and `timer-action-trigger`.
- Ark anatomy attributes: `data-scope="timer"` and
  `data-part="root|area|item|separator|control|action-trigger"`.
- `Timer.Item` exposes `data-type` and Ark's `--value` runtime variable.
- Ark adds `hidden` to action triggers that are unavailable in the current timer state.
