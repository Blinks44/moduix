## Basic

Timer ships for React and Solid in both the CSS Modules and Tailwind packages. The rendered preview on this page uses
the React CSS Modules package; the framework tabs show native source for the same public contract.

`Timer.Segments` is the quickest way to render a conventional time display separated by colons. By default, it shows
hours, minutes, and seconds. Pass `types` to choose a different set of units. Use the individual parts when you need
unit labels, custom separators, or per-item styling.

`Timer.Segments` accepts all `Timer.Area` props except `children` and `asChild`, and forwards the area ref. Because
it creates the items and separators itself, use `Timer.Area` when you need to replace its host element or provide
custom children.

## Anatomy

```text
Timer.Root
├─ Timer.Area
│  ├─ Timer.Item
│  └─ Timer.Separator
└─ Timer.Control
   └─ Timer.ActionTrigger

Timer.RootProvider
└─ same part tree connected to state from `useTimer()`

Timer.Segments
└─ Timer.Area with Timer.Item and Timer.Separator
```

| Part                   | Role                                                                    |
| ---------------------- | ----------------------------------------------------------------------- |
| `Timer` / `Timer.Root` | Owns the Ark timer state, ids, interval, and callbacks.                 |
| `Timer.RootProvider`   | Connects parts to timer state created with Ark `useTimer()`.            |
| `Timer.Segments`       | Builds standard time units and separators.                              |
| `Timer.Area`           | Groups the visible time parts.                                          |
| `Timer.Item`           | Displays one formatted time unit such as `hours`, `minutes`, or `seconds`. |
| `Timer.Separator`      | Displays a separator between time units.                                |
| `Timer.Control`        | Groups action triggers.                                                 |
| `Timer.ActionTrigger`  | Dispatches the `start`, `pause`, `resume`, `reset`, or `restart` action. |

## Composition

`Timer` is equivalent to `Timer.Root` and owns the timer state. `Timer.Segments` creates its own `Timer.Area`,
`Timer.Item`, and `Timer.Separator` parts, so use the full `Timer.Area` composition when you need unit labels,
custom separators, or per-item layout.

Use `Timer.RootProvider` with `useTimer()` when the state must be created outside the rendered part tree. Use
`Timer.Context` or `useTimerContext()` when other UI needs the timer state or methods. In Solid, the store and context
are accessors, so read them as `timer()` and `api()`.

### Styling hooks

- `data-slot="timer-root"`, `timer-root-provider`, `timer-area`, `timer-item`,
  `timer-separator`, `timer-control`, and `timer-action-trigger`.
- Ark anatomy attributes: `data-scope="timer"` and
  `data-part="root|area|item|separator|control|action-trigger"`.
- `Timer.Item` exposes `data-type` and Ark's `--value` runtime variable.
- Ark adds `hidden` to action triggers that are unavailable in the current timer state.
