## API Reference

`NativeSelect` is a styled wrapper around Ark UI's
[`Field.Select`](https://ark-ui.com/docs/components/field). It renders a real HTML `<select>`, so the
browser remains responsible for option rendering, keyboard interaction, form submission, autofill,
validation, and reset.

## Choosing the right component

Use `NativeSelect` for simple option lists when you want native browser behavior, including autofill,
form reset, keyboard interaction, and the platform picker on mobile. Choose [`Select`](/docs/select)
when you need a custom popup, collection APIs, rich option content, clearing, or programmatic control
of the popup.

## Anatomy

`NativeSelect` renders the real `<select>` inside an outer wrapper `<span>`. Collapsed single-select
controls also get a decorative `ChevronDownIcon`; the indicator is hidden for `multiple` and
`size > 1`, when the browser displays a list.

```text
NativeSelect / NativeSelect.Root
└─ span[data-scope="native-select"][data-part="control"][data-slot="native-select-control"]
   ├─ select[data-scope="field"][data-part="select"][data-slot="native-select-root"]
   │  ├─ option
   │  └─ optgroup
   └─ span[data-scope="native-select"][data-part="indicator"][data-slot="native-select-indicator"]
      └─ ChevronDownIcon
```

| Part                       | Role                                                                        |
| -------------------------- | --------------------------------------------------------------------------- |
| `NativeSelect` / `NativeSelect.Root` | Public root component. Renders the native `<select>` and decorative indicator. |

## Composition

### Recommended composition

Use `NativeSelect` directly for a simple control. Its children are native `option` and `optgroup`
elements. Wrap it in `Field.Root` when the control needs a visible label, helper text, error text, or
shared `required`, `invalid`, or `disabled` state.
Give the control an accessible name with `Field.Label`, a native `<label>`, `aria-label`, or
`aria-labelledby`.

`NativeSelect.Root` is a compatibility alias. Use `NativeSelect` in application code.

### When to go custom

Switch to `Select` when the application needs a custom popup, collection state, rich option rendering,
an explicit clear action, or programmatic popup control. Keep `NativeSelect` when you want the browser
to manage selection.

### Default props

| Prop           | Default         | Notes                                                              |
| -------------- | --------------- | ------------------------------------------------------------------ |
| `value`        | -               | Controlled value.                                                  |
| `defaultValue` | -               | Initial uncontrolled value.                                        |
| `onChange`     | -               | Native `ChangeEvent<HTMLSelectElement>`.                          |
| `multiple`     | `false`         | Enables native multiple selection.                                |
| `size`         | browser default | Number of visible rows, not a visual size variant.                 |
| `disabled`     | `false`         | Disables the control.                                              |
| `controlProps` | -               | Props for the outer `<span>`, including wrapper styles.            |
| `asChild`      | `false`         | Ark composition; the child must remain a semantic `<select>`.     |

### Behavioral notes

- `ref` points to the real `HTMLSelectElement`.
- Native form submission, autofill, reset, `required` validation, option handling, and keyboard
  behavior are preserved.
- With `multiple` or a native `size` greater than one, the browser determines the list's height and
  controls its appearance and interaction.
- `Field.Root` connects labels and supporting text to the select and supplies ids, `aria-describedby`,
  `aria-invalid`, `disabled`, and `required` state.
- With `asChild`, pass one semantic HTML `<select>` as the child.
- HTML `<select>` does not support a read-only mode.
- `ChevronDownIcon` is decorative and hidden for list controls; the browser still controls the popup's
  appearance.

## Styling

### CSS Properties

`NativeSelect` reuses the same `--moduix-select-*` variables as `Select`, so dimensions, indicator
spacing, borders, colors, radius, focus ring, disabled opacity, and transitions can be tuned
consistently. Default padding and indicator geometry use the shared 4px spacing scale.

### Styling hooks

- `className` styles the real `<select>`. Use `controlProps.className` for the outer wrapper `<span>`.
- Set indicator-related `--moduix-select-*` variables in `controlProps.style` when both the select and
  indicator should inherit them.
- `data-scope="field"` and `data-part="select"` preserve the Ark Field styling contract.
- `data-slot="native-select-root"` is the stable moduix selector for the `<select>` control.
- `data-slot="native-select-control"` and `data-slot="native-select-indicator"` target the internal
  layout and icon.
- Native `:focus-visible`, `:disabled`, `[aria-invalid="true"]`, `[multiple]`, and `[size]` selectors
  control the visual states.
