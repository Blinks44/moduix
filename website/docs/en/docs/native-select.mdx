## Choosing the right component

Use `NativeSelect` for simple option lists when you want native browser behavior, including autofill,
form reset, keyboard interaction, and the platform picker on mobile. Choose [`Select`](/docs/select)
when you need a custom popup, collection APIs, rich option content, clearing, or programmatic control
of the popup.

## Composition

`NativeSelect` is a styled wrapper around Ark UI's
[`FieldSelect`](https://ark-ui.com/docs/components/field). It renders a real HTML `<select>`, so the
browser remains responsible for option rendering, keyboard interaction, form submission, autofill,
validation, and reset.

React builds an uncontrolled select with the native `defaultValue` prop. In Solid and Vue, pass the
native `selected` attribute to the `<option>` that should be initially selected: a `defaultValue` prop
on the Solid or Vue `NativeSelect` has no effect. Use `value` with `onChange` in React and Solid, or
`v-model` in Vue, when application state owns the current value. Wrap `NativeSelect` in `Field` when
the label, supporting text, validation, or disabled state should be shared with the control. The
`Field` parts connect that content to the native select while the browser still owns option selection.
With `multiple` or `size > 1`, the browser owns the list interaction and the decorative indicator is
hidden. `asChild` can replace the rendered select, but the child must remain one semantic HTML
`<select>`.

## Anatomy

`NativeSelect` renders the real `<select>` inside an outer wrapper `<span>`. Collapsed single-select
controls also get a decorative `ChevronDownIcon`; the indicator is hidden for `multiple` and
`size > 1`, when the browser displays a list.

```text
NativeSelect
└─ span[data-scope="native-select"][data-part="control"][data-slot="native-select-control"]
   ├─ select[data-scope="field"][data-part="select"][data-slot="native-select-root"]
   │  ├─ option
   │  └─ optgroup
   └─ span[data-scope="native-select"][data-part="indicator"][data-slot="native-select-indicator"]
      └─ ChevronDownIcon
```

| Part | Role |
| ---- | ---- |
| `NativeSelect` | Public root component. Renders the native `<select>` and decorative indicator. |

## Styling

`NativeSelect` reads the same width, height, radius, and indicator size variables as the CSS Modules
variants of `Select`, so both selects can be resized together. Colors, borders, focus rings, and
motion come from foundation tokens; override them with a class. Tailwind variants use native utility
classes and consumer class overrides.

### Styling hooks

| Part | `data-slot` |
| --- | --- |
| `NativeSelect`, inner element | `native-select-control` |
| `NativeSelect` | `native-select-root` |
| `NativeSelect`, inner element | `native-select-indicator` |

- In React use `className` on the select, and in Solid or Vue use `class`. Use
  `controlProps.className` or `controlProps.class` for the outer wrapper `<span>`.
- Set `--moduix-select-action-size` in `controlProps.style` (or on an ancestor) so both the select
  padding and the indicator follow it.
- `data-scope="field"` and `data-part="select"` preserve the Ark Field styling contract.
- `data-slot="native-select-root"` is the stable moduix selector for the `<select>` control.
- Native `:focus-visible`, `:disabled`, `[aria-invalid="true"]`, `[multiple]`, and `[size]` selectors
  control the visual states.

## Keyboard

The browser handles the keyboard, as in any native select.

| Key | Action |
| --- | --- |
| `ArrowDown` / `ArrowUp` | Changes the selected option. |
| `Space` / `Alt+ArrowDown` | Opens the option list. |
