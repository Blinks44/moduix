## API Reference

`NativeSelect` wraps Ark UI's
[Field.Select](https://ark-ui.com/docs/components/field) and renders a real HTML `<select>`.
It uses the same visual language as the custom `Select`, similar to Chakra UI's
[Native Select](https://chakra-ui.com/docs/components/native-select), while moduix keeps the public API
to one component.

## Choosing the right component

Use `NativeSelect` for simple option lists when you want browser autofill, form reset, native keyboard
behavior, and mobile-native selection UI. Choose [`Select`](/docs/select) when you need a custom popup,
collection APIs, rich option content, clearing, multiple selected values, or programmatic control of the
popup.

## Anatomy

`NativeSelect` keeps the real `<select>` as the form control and adds a non-interactive moduix
`ChevronDownIcon` so the closed control stays aligned with `Select`.

```text
NativeSelect
└─ span[data-scope="native-select"][data-part="control"]
   ├─ select[data-scope="field"][data-part="select"][data-slot="native-select-root"]
   │  ├─ option
   │  └─ optgroup
   └─ span[data-scope="native-select"][data-part="indicator"]
      └─ ChevronDownIcon
```

| Part           | Role                                          |
| -------------- | --------------------------------------------- |
| `NativeSelect` | Styled native `<select>` with an indicator. |

## Composition

### Recommended composition

Use the compact `NativeSelect` form with native children and the usual controlled or uncontrolled
props. Wrap it in `Field.Root` when the control needs a visible label, helper text, error text, or
shared `required`, `invalid`, or `disabled` state.

`NativeSelect.Root` is a compatibility alias. Use `NativeSelect` in application code.

### When to go custom

Switch to `Select` when the application needs to control option rendering, popup positioning,
collection state, or custom indicators. Keep `NativeSelect` when you want the browser to manage
selection.

### Default props

| Prop           | Default         | Notes                                               |
| -------------- | --------------- | --------------------------------------------------- |
| `value`        | -               | Controlled value                               |
| `defaultValue` | -               | Initial uncontrolled value                     |
| `onChange`     | -               | Native `ChangeEvent<HTMLSelectElement>`       |
| `multiple`     | `false`         | Enables multiple selection                    |
| `size`         | browser default | Visible row count, not a visual size variant  |
| `disabled`     | `false`         | Disables the control                          |
| `controlProps` | -               | Props for the outer layout span               |
| `asChild`      | `false`         | Ark composition; child must remain a `<select>` |

### Behavioral notes

- The ref points to the real `HTMLSelectElement`.
- Native form submission, autofill, reset, `required` validation, option handling, and keyboard
  behavior are preserved.
- With `multiple` or a native `size` greater than one, the browser determines the list's intrinsic height.
- `Field.Root` supplies ids and `aria-describedby`, and passes through invalid and other native field state.
- With `asChild`, keep the child as a semantic HTML `<select>`.
- HTML `<select>` does not support a read-only mode.
- `ChevronDownIcon` keeps the closed control aligned with `Select`. The browser still controls the
  popup's appearance.

## Styling

### CSS Properties

`NativeSelect` uses the same control-level `--moduix-select-*` variables as `Select`, so both controls can
share dimensions, indicator spacing, borders, colors, radius, focus ring, disabled opacity, and transitions.
Its default padding and indicator geometry use the shared 4px spacing scale.

### Styling hooks

- `className` styles the real `<select>`. Use `controlProps.className` for the outer layout span.
- Set indicator-related `--moduix-select-*` variables in `controlProps.style` so both the select and
  indicator inherit them.
- `data-scope="field"` and `data-part="select"` preserve the Ark Field styling contract.
- `data-slot="native-select-root"` is the stable moduix selector for the `<select>` control.
- `data-slot="native-select-control"` and `data-slot="native-select-indicator"` target the internal
  layout and icon.
- Native `:focus-visible`, `:disabled`, `[aria-invalid="true"]`, `[multiple]`, and `[size]` selectors
  control the visual states.
