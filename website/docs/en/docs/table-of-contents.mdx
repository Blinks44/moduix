## Basic

`Toc` is the shorthand root component. Pass an `items` array with the headings you want to track.
Each item needs a `value` that matches a heading's `id` and a `depth` that matches its semantic
level, such as `2` for `<h2>`. Use the same item when rendering `TocItem`, then build the matching
`TocLink` fragment from its `value`.


On a regular document page, omit `scrollEl` and the component observes the page viewport. The
preview below uses an inner scroll container, so it passes that element to `scrollEl` to keep
tracking and link navigation inside the preview.

## Anatomy

```text
Toc
├─ TocContent
└─ TocNav
   ├─ TocTitle
   └─ TocList
      ├─ TocIndicator (optional)
      └─ TocItem[item]
         └─ TocLink
            └─ TocRail (optional)

TocRootProvider
└─ same part tree connected to useToc()
```

| Part               | Role                                                                 |
| ------------------ | -------------------------------------------------------------------- |
| `Toc`             | Root part that owns tracking state from the item list.               |
| `TocContent`      | Article containing headings whose IDs match item values.             |
| `TocNav`          | Navigation region connected to the table of contents title.          |
| `TocTitle`        | Accessible name and visible heading for the navigation.              |
| `TocList`         | List containing heading links and the optional indicator.             |
| `TocItem`         | List item bound to one heading, with depth and active-state metadata. |
| `TocLink`         | Same-page anchor that scrolls to its matching heading.               |
| `TocIndicator`    | Subtle marker that follows the active range in the list.              |
| `TocRootProvider` | Connects the parts to tracking state created outside the part tree.   |
| `TocRail`         | Optional SVG branch connecting neighbouring heading depths.            |

## Composition

Pass one item for every tracked heading. Keep `item.value`, the heading `id`, and the `TocLink`
fragment identical, and use the heading's semantic level for `depth`. Omit `scrollEl` when the page
viewport owns scrolling; pass the reading pane when the content has its own scroll container.

Unlike Ark UI, `autoScroll` defaults to `false` for both `Toc` and `useToc()`. Pass `autoScroll` to
opt in only when automatically revealing the active navigation item cannot scroll an ancestor
container.

Use `TocRootProvider` with `useToc()` only when controls outside the part tree need the same
tracking state, such as `activeIds` or `scrollTo`. React reads the store as an object; Solid reads
its reactive state through the returned accessor. In Vue, the reactive store is exposed directly to
the template. Use `TocContext` when a surrounding composition such as `Collapsible` needs the
active items. For router links, use `TocLink asChild` with one semantic `<a>` child; in Solid, pass
that child through the render function expected by `asChild`.
Choose either `TocIndicator` for an active-range marker or `TocRail` for per-link hierarchy; do
not render both in the same list.

:::warning Upstream limitations
Controlled `activeIds` changes report the requested IDs in `activeChange` with Ark UI Vue 5.39.3
and Zag 1.45.0. `TocNav` still reuses the root ID when both parts render, producing duplicate IDs.
This remaining limitation is tracked in [Ark #4187](https://github.com/chakra-ui/ark/issues/4187).
:::

### Root Provider

Use `useToc()` when another control needs to read the active headings or scroll the reading pane.

### Rail

Place `TocRail` inside each link to draw an SVG connector between neighbouring heading depths.
Pass the current, previous, and next depths from the same ordered `items` array. The rail on the
active link uses the indicator colour. Do not render `TocIndicator` in the same list.

<Example name="table-of-contents/rail" />

### With Collapsible

Place the navigation list inside `Collapsible` when readers should be able to hide the full table
of contents. `TocContext` supplies the active item for the trigger label and progress ring, while
the links continue to target the same reading pane.

## Styling

Use `className` in React or `class` in Solid and Vue on any exported part. Tailwind variants use native
utilities and consumer classes. CSS Modules variants build on foundation tokens and have no component
variables: a class on a part, or a `data-slot` selector, overrides the layered component styles. To
change the navigation column, override `grid-template-columns` on `Toc`.

### Styling hooks

- `data-slot="toc-root"`, `toc-root-provider`, `toc-content`, `toc-nav`, `toc-title`, `toc-list`,
  `toc-item`, `toc-link`, `toc-indicator`, and `toc-rail`
- Ark `data-scope="toc"` and `data-part` attributes on primitive parts
- `TocItem` attributes and variables: `data-value`, `data-depth`, `data-active`, `data-first`,
  `data-last`, and `--depth`; `TocLink` exposes `data-value`, `data-active`, and `aria-current`
- Ark runtime `--top`, `--left`, `--width`, and `--height` variables on the root
