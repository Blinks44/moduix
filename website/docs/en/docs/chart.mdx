## API Reference

Ark UI does not include a chart primitive. moduix adds a semantic `figure`, title, description,
legend, and compact tooltip body around the [TanStack Charts React host](https://tanstack.com/charts/latest/docs/framework/react/reference/chart).
Define marks, scales, interactions, and callbacks with TanStack Charts; moduix keeps the chart
composition around them.

`@tanstack/charts` is an optional peer dependency of moduix. The current peer range is `^0.16.0`,
and TanStack's React adapter requires React 19.

## Anatomy

```text
Chart / Chart.Root
├─ Chart.Header (optional figcaption)
│  ├─ Chart.Title
│  └─ Chart.Description
├─ Chart.Plot
│  └─ TanStack chart surface (SVG by default)
└─ Chart.Legend (optional)
   └─ Chart.LegendItem
```

| Part | Role |
| --- | --- |
| `Chart` / `Chart.Root` | Composed `figure` root. Accepts native props, `asChild`, and an `HTMLElement` ref. |
| `Chart.Plot` | TanStack Charts React host. Requires `definition` and `ariaLabel`; uses the Moduix motion preset by default and accepts `motion={false}`. |
| `Chart.Header` | `figcaption` layout for the title and description. |
| `Chart.Title` | Chart heading; renders `h3` by default. |
| `Chart.Description` | Supporting visible context. |
| `Chart.Legend` | Semantic list of visible series. |
| `Chart.LegendItem` | Legend item with an optional indicator `color`. |

## Composition

### Recommended composition

Keep a stable TanStack definition outside the component, then assemble `Chart.Header`,
`Chart.Plot`, and `Chart.Legend` in the root component. Define `barY`, `areaY`, `lineY`, stacking,
scales, guides, and color channels directly with TanStack. moduix does not mirror them as React
parts.

Use the definition's `color` scale for marks and tooltip swatches. Reuse the corresponding moduix
chart tokens in `Chart.LegendItem` so the visible legend stays aligned with the chart.

### Choosing marks

`Chart.Plot` provides the rendering host, while the marks inside `definition` determine what is
drawn. All variants use the same `<Chart.Plot definition={definition} />` composition.

| Goal | Marks | Example |
| --- | --- | --- |
| Vertical bars | `barY` | Basic, Stacked bars |
| Horizontal bars | `barX` | Horizontal bars |
| Line or area | `lineY`, `areaY` | Animated area, Chart colors |
| Pie or donut | `pie`, `polar`, `radialArc` | Donut chart |
| Scatter plot | `dot` | Scatter plot |
| Heatmap | `cell` | Heatmap |

### When to go custom

`Chart.Plot` uses TanStack's responsive `motion()` preset by default. Set `motion={false}` for a
static SVG chart, or pass a different `renderer` when you need to control rendering yourself. An
explicit `renderer` takes precedence over `motion`. If your application owns the rendering surface,
use TanStack's canvas or low-level renderer directly.

```tsx
<Chart.Plot definition={definition} ariaLabel="Monthly revenue" motion={false} />
```

Chart uses a compact Moduix tooltip body by default, so rows without a swatch do not leave an empty
column. Use `renderTooltipBody` only when you need to add React content. Its context includes
TanStack's native `defaultBody` with the title, rows, formatting, and swatches. TanStack continues
to handle the tooltip's anchor, placement, portal, pinned state, and dismissal. Render interactive
controls only when `pinned` is true.

### Default props

| Part | Prop | Default | Notes |
| --- | --- | --- | --- |
| `Chart.Root` | element | `figure` | `Chart.Header` is its `figcaption`. |
| `Chart.Plot` | `definition` | - | Required TanStack chart definition. |
| `Chart.Plot` | `ariaLabel` | - | Required accessible chart name. |
| `Chart.Plot` | `motion` | `true` | Set to `false` to use TanStack's static SVG renderer. |
| `Chart.Plot` | `renderer` | Moduix motion preset | Animates geometry and tooltip; respects reduced-motion preferences. |
| `Chart.Plot` | `height` | `320` | Used when `aspectRatio` is absent. |
| `Chart.Plot` | `width` | responsive | Follows the host width. |
| `Chart.Plot` | `initialWidth` | `640` | Server and pre-measurement width. |
| `Chart.Plot` | `tabIndex` | `0` | Keeps TanStack keyboard navigation in the tab order. |

### Behavioral notes

- Keep a static definition at module scope. When it captures props or state, memoize the complete
  definition with `useMemo`.
- The default motion renderer animates initial geometry, keyed data updates, focus guides, and the
  native tooltip. It switches to instant updates when `prefers-reduced-motion: reduce` matches;
  `motion={false}` disables animation independently of the user's media preference.
- TanStack owns pointer focus, arrow-key navigation, Enter/Space activation, `onFocusChange`, and
  `onSelect`.
- The focusable plot SVG uses the moduix focus ring. Keep TanStack's `focusRing` enabled unless your
  definition provides replacement focus geometry.
- `ariaDescription` adds detail when the visible title and description are not sufficient.
- `className` and `style` on `Chart.Plot` target the outer TanStack host. The host has no ref API.

## Styling

Style the figure with `Chart.Root` and the TanStack host with `Chart.Plot`. Public CSS properties
control the surface, focus ring, tooltip shell, and default tooltip layout. Keep chart geometry in
the TanStack definition through mark options, scales, and color channels.

Give the root a class when a chart needs local overrides:

```tsx
<Chart className="sales-chart">...</Chart>
```

```css
.sales-chart {
  --moduix-chart-tooltip-bg: var(--moduix-color-card);
  --moduix-chart-tooltip-font-size: var(--moduix-text-sm);
  --moduix-chart-tooltip-line-height: var(--moduix-line-height-text-sm);
}
```

### Styling hooks

- `Chart.Root`, `Chart.Header`, `Chart.Title`, `Chart.Description`, `Chart.Legend`,
  and `Chart.LegendItem` expose `data-scope="chart"`, `data-part`, and `data-slot`.
- `className` on `Chart.Plot` reaches the outer `.ts-chart-host` element.
- The default tooltip uses `chart-tooltip-body`, `chart-tooltip-title`,
  `chart-tooltip-rows`, `chart-tooltip-row`, `chart-tooltip-swatch`, `chart-tooltip-label`,
  `chart-tooltip-value`, and `chart-tooltip-text` data slots.
- Use `--moduix-color-chart-1` through `--moduix-color-chart-5` in TanStack color scales.
- The tooltip shell is styled through the documented `--ts-chart-tooltip-*` variables mapped from
  Moduix properties. Use TanStack's `tooltip.className` for custom selectors, or
  `renderTooltipBody` when you need React content and the native `defaultBody`.
