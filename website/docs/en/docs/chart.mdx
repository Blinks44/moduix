## API Reference

Ark UI does not provide a chart primitive. moduix combines Ark factory parts with the
[TanStack Charts React host](https://tanstack.com/charts/latest/docs/framework/react/reference/chart),
keeping TanStack's framework-independent definition, marks, scales, interactions, and callbacks.
TanStack Charts 0.14 requires React 19.

## Basic

Create a definition with TanStack Charts, then render it in `Chart.Plot`. Keep the visible title,
description, and legend in the root composition, and give the plot a concise `ariaLabel`.

## Anatomy

```text
Chart / Chart.Root
├─ Chart.Header (optional figcaption)
│  ├─ Chart.Title
│  └─ Chart.Description
├─ Chart.Plot
│  └─ TanStack chart surface (SVG by default)
└─ Chart.Legend (optional)
   └─ Chart.LegendItem
```

| Part | Role |
| --- | --- |
| `Chart` / `Chart.Root` | Composed `figure` surface. Accepts native props, `asChild`, and an `HTMLElement` ref. |
| `Chart.Plot` | TanStack React host. Requires `definition` and `ariaLabel`; defaults to the Moduix motion preset and accepts `motion={false}`. |
| `Chart.Header` | `figcaption` layout for the title and description. |
| `Chart.Title` | Chart heading; renders `h3` by default. |
| `Chart.Description` | Supporting visible context. |
| `Chart.Legend` | Semantic list of visible series. |
| `Chart.LegendItem` | Legend item with an optional indicator `color`. |

## Composition

### Recommended composition

Keep a stable TanStack definition outside the component, then compose `Chart.Header`,
`Chart.Plot`, and `Chart.Legend` inside the callable root. Use TanStack's `barY`, `areaY`, `lineY`,
stacking, scales, guides, and color channels directly; moduix does not duplicate them as React
parts.

Use the definition's `color` scale for marks and tooltip swatches. Reuse the corresponding moduix
chart tokens in `Chart.LegendItem` so the visible legend stays aligned with the chart.

### Choosing marks

`Chart.Plot` is the renderer host, while the marks inside `definition` determine what is drawn. All
variants use the same `<Chart.Plot definition={definition} />` composition.

| Goal | Marks | Example |
| --- | --- | --- |
| Vertical bars | `barY` | Basic, Stacked bars |
| Horizontal bars | `barX` | Horizontal bars |
| Line or area | `lineY`, `areaY` | Animated area, Chart colors |
| Pie or donut | `pie`, `polar`, `radialArc` | Donut chart |
| Scatter plot | `dot` | Scatter plot |
| Heatmap | `cell` | Heatmap |

### When to go custom

`Chart.Plot` uses a responsive TanStack `motion()` preset by default. Set `motion={false}` for a
fully static SVG chart, or pass another `renderer` for a custom motion policy. An explicit
`renderer` takes precedence over `motion`. Use the TanStack canvas or low-level renderer entry
directly when the surface itself is application-owned.

```tsx
<Chart.Plot definition={definition} ariaLabel="Monthly revenue" motion={false} />
```

Use `renderTooltipBody` only when the tooltip needs React-owned content. Its TanStack `defaultBody`
preserves the native title, rows, formatting, and swatches; TanStack still owns the anchor,
placement, portalling, pinned state, and dismissal. Render interactive controls only while `pinned`
is true.

### Default props

| Part | Prop | Default | Notes |
| --- | --- | --- | --- |
| `Chart.Root` | element | `figure` | `Chart.Header` is its `figcaption`. |
| `Chart.Plot` | `definition` | - | Required TanStack chart definition. |
| `Chart.Plot` | `ariaLabel` | - | Required accessible chart name. |
| `Chart.Plot` | `motion` | `true` | Set to `false` to use TanStack's static SVG renderer. |
| `Chart.Plot` | `renderer` | Moduix motion preset | Animates geometry and tooltip; respects reduced motion. |
| `Chart.Plot` | `height` | `320` | Used when `aspectRatio` is absent. |
| `Chart.Plot` | `width` | responsive | Follows the host width. |
| `Chart.Plot` | `initialWidth` | `640` | Server and pre-measurement width. |
| `Chart.Plot` | `tabIndex` | `0` | Keeps TanStack keyboard navigation in the tab order. |

### Behavioral notes

- Keep a static definition at module scope. When it captures props or state, memoize the complete
  definition with `useMemo`.
- The default motion renderer animates initial geometry, keyed data updates, focus guides, and the
  native tooltip. It snaps when `prefers-reduced-motion: reduce` matches; `motion={false}` disables
  it independently of the user's media preference.
- Pointer focus, arrow-key navigation, Enter/Space activation, `onFocusChange`, and `onSelect`
  remain owned by TanStack.
- The plot's focusable SVG uses the moduix focus ring. Do not set `focusRing: false` unless custom
  focus geometry replaces TanStack's point indicator.
- `ariaDescription` adds detail when the visible title and description are not sufficient.
- `className` and `style` on `Chart.Plot` target the outer TanStack host. The host has no ref API.

## Styling

Style the figure through `Chart.Root` and the TanStack host through `Chart.Plot`. Public CSS
properties control the surface, focus ring, and native tooltip shell. Chart geometry remains in the
TanStack definition through mark options, scales, and color channels.

Give the root a class when a chart needs local overrides:

```tsx
<Chart className="sales-chart">...</Chart>
```

```css
.sales-chart {
  --moduix-chart-tooltip-bg: var(--moduix-color-card);
  --moduix-chart-tooltip-font-size: var(--moduix-text-sm);
  --moduix-chart-tooltip-line-height: var(--moduix-line-height-text-sm);
}
```

### Styling hooks

- `Chart.Root`, `Chart.Header`, `Chart.Title`, `Chart.Description`, `Chart.Legend`,
  and `Chart.LegendItem` expose `data-scope="chart"`, `data-part`, and `data-slot`.
- `className` on `Chart.Plot` reaches the outer `.ts-chart-host` element.
- Use `--moduix-color-chart-1` through `--moduix-color-chart-5` in TanStack color scales.
- The native tooltip is styled through the documented `--ts-chart-tooltip-*` variables mapped from
  Moduix properties. Use TanStack's `tooltip.className` for application-owned selectors, or
  `renderTooltipBody` for React content.
