## Installation

<ComponentInstall />

Chart does not map to an Ark UI primitive. moduix adds a semantic `figure`, title, description,
legend, and compact tooltip body around the [TanStack Charts chart
API](https://tanstack.com/charts/latest/docs/framework/react/reference/chart). Define marks,
scales, interactions, and callbacks with TanStack Charts; moduix keeps the accessible composition
around them.

`@tanstack/charts` is an optional peer dependency of moduix. The React, Solid, and Vue packages
expose the same chart definition API; the Solid and Vue packages use TanStack's renderer adapter.

## Usage

<UsageCode
  react={'<Chart>\n  <ChartHeader>\n    <ChartTitle>Monthly revenue</ChartTitle>\n    <ChartDescription>In thousands of dollars.</ChartDescription>\n  </ChartHeader>\n  <ChartPlot definition={definition} height={320} ariaLabel="Monthly revenue" />\n  <ChartLegend aria-label="Series">\n    <ChartLegendItem color="var(--moduix-color-chart-1)">Revenue</ChartLegendItem>\n  </ChartLegend>\n</Chart>'}
  vue={'<Chart>\n  <ChartHeader>\n    <ChartTitle>Monthly revenue</ChartTitle>\n    <ChartDescription>In thousands of dollars.</ChartDescription>\n  </ChartHeader>\n  <ChartPlot :definition="definition" :height="320" ariaLabel="Monthly revenue" />\n  <ChartLegend aria-label="Series">\n    <ChartLegendItem color="var(--moduix-color-chart-1)">Revenue</ChartLegendItem>\n  </ChartLegend>\n</Chart>'}
/>

<PropChips

Create a TanStack definition and pass it to `ChartPlot`. Add a visible title, description, and
legend around the plot, then provide a concise `ariaLabel` for assistive technology.

### Interactive legend

Use TanStack's `interactiveColorLegend` instead of a separate `ChartLegend` when readers need to
hide series. With v1, `hover: 'series'` also applies mark states on pointer hover and keyboard
focus. The `source: 'legend'` states highlight the series without opening a tooltip or changing
plot focus. Keep the visible series in framework state through `controlledSignal`; TanStack owns
the buttons, filtering, and keyboard interaction.

### Advanced Customization

The Ark factory parts accept `asChild`, so they can apply their styles to semantic elements in your
layout. This dashboard example combines Chart with Button, replaces the default `figure` and
`figcaption` with a labelled `section` and `header`, and places the legend in the header.

`ChartPlot` is still the TanStack host, not a slot. Use its `class` or `className` and `style` on
the outer element, and use `renderTooltipBody` to extend the tooltip. Render `defaultBody` inside
your own wrapper while TanStack continues to position and portal it. Add interactive controls only
to a pinned tooltip.

## Composition

`Chart` is a presentational shell. TanStack's `definition` owns marks, scales, interactions, and
callbacks, so keep it at module scope or memoize the complete definition when it depends on props
or state. Compose `ChartHeader`, `ChartPlot`, and `ChartLegend` under the root; `ChartPlot`
continues to own rendering, focus, and tooltip state through TanStack.

Use `renderTooltipBody` only when you need to wrap or extend the native tooltip: render the supplied
`defaultBody` and add interactive controls only while `pinned` is true. `Chart` and
`ChartHeader` support `asChild` when the semantic wrapper or layout needs to be owned by your
application.

## Styling

Style the figure with `Chart` and the TanStack host with `ChartPlot`. The CSS properties below
control the `Chart` surface and the legend indicator. Keep chart geometry in the TanStack definition
through mark options, scales, and color channels.

Tailwind variants use native utilities and consumer classes; the CSS properties below customize the
CSS Modules variants. Both styling tracks set TanStack's `--ts-chart-tooltip-*` variables on the
`ChartPlot` host, and data attributes and `data-slot` hooks are shared by both.

To restyle the tooltip shell, override those variables with a class on `ChartPlot` (`className` in
React or `class` in Solid and Vue):

```css
.sales-plot {
  --ts-chart-tooltip-background: var(--moduix-color-card);
  --ts-chart-tooltip-font: var(--moduix-weight-medium) var(--moduix-text-sm) /
    var(--moduix-line-height-text-sm) var(--moduix-font-sans);
}
```

### Styling hooks

| Part | `data-slot` |
| --- | --- |
| `Chart` | `chart-root` |
| `Chart`, inner element | `chart-tooltip-text` |
| `Chart`, inner element | `chart-tooltip-body` |
| `Chart`, inner element | `chart-tooltip-title` |
| `Chart`, inner element | `chart-tooltip-swatch` |
| `Chart`, inner element | `chart-tooltip-rows` |
| `Chart`, inner element | `chart-tooltip-row` |
| `Chart`, inner element | `chart-tooltip-label` |
| `Chart`, inner element | `chart-tooltip-value` |
| `ChartHeader` | `chart-header` |
| `ChartTitle` | `chart-title` |
| `ChartDescription` | `chart-description` |
| `ChartLegend` | `chart-legend` |
| `ChartLegendItem` | `chart-legend-item` |

- `Chart`, `ChartHeader`, `ChartTitle`, `ChartDescription`, `ChartLegend`, and
  `ChartLegendItem` expose `data-scope="chart"`, `data-part`, and `data-slot`.
- `className` in React and `class` in Solid and Vue on `ChartPlot` reach the outer `.ts-chart-host` element.
- Use `--moduix-color-chart-1` through `--moduix-color-chart-5` in TanStack color scales.
- Tooltip rows that TanStack marks as `active` get `data-active`.
- The tooltip shell reads TanStack's `--ts-chart-tooltip-*` variables from the `ChartPlot` host. Use
  TanStack's `tooltip.className` for custom selectors, or `renderTooltipBody` when you need custom
  content around the moduix `defaultBody`.
