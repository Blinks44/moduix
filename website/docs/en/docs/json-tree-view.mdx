## Choosing the right component

Use `JsonTreeView` when you already have a JavaScript value and need to inspect it without writing a recursive
renderer. Choose `TreeView` when you own the node model and need custom labels, icons, links, renaming, or branch
content.

## Basic

JsonTreeView ships for React and Solid in both the CSS Modules and Tailwind packages. The rendered preview on this
page uses the React CSS Modules package; the framework tabs show native source for the same public contract.

Pass any JSON-like JavaScript value through `data`, then render `<JsonTreeView.Tree />` inside the component.
`JsonTreeView` generates the object, array, and value nodes for you. moduix styles the rows, indentation, focus
states, and default disclosure icon.

The example starts with two levels expanded. Use `defaultExpandedDepth` to choose how much of a response or
configuration should be visible on the first render.

## Anatomy

```text
JsonTreeView / JsonTreeView.Root
└─ JsonTreeView.Tree
   └─ generated JSON branches and items

JsonTreeView.RootProvider
└─ same tree connected to a useJsonTreeView store
```

| Part | Role |
| --- | --- |
| `JsonTreeView` / `JsonTreeView.Root` | Owns the data, generated tree collection, and Ark tree state. |
| `JsonTreeView.RootProvider` | Connects the parts to a `useJsonTreeView` state instance created outside the tree. |
| `JsonTreeView.Tree` | Renders the generated object, array, and value nodes. |

## Composition

Keep `JsonTreeView.Tree` as the child of `JsonTreeView` or `JsonTreeView.Root`; it renders the generated JSON nodes.
When controls outside the tree own its state, create `useJsonTreeView` from the matching framework package and pass
the store to `JsonTreeView.RootProvider`, then render `Tree` inside it. Use controlled `expandedValue`,
`selectedValue`, `checkedValue`, or `focusedValue` only when that state belongs to the application. Do not render
`Root` and `RootProvider` for the same store.

## Styling

Use `className` in React or `class` in Solid on `Root`, `RootProvider`, or `Tree` for local layout changes. Tailwind
variants use utility classes and consumer classes; CSS Modules variants use their bundled styles and foundation
tokens.

`JsonTreeView.Tree` uses the `ChevronRightIcon` supplied by moduix when `arrow` is omitted. Pass your own `arrow`
when the inspection surface needs a different disclosure icon.

Generated nodes preserve Ark's `data-scope="json-tree-view"` and `data-part` attributes. moduix adds the stable
`data-slot="json-tree-view-root"`, `json-tree-view-root-provider`, and `json-tree-view-tree` hooks.

The component uses foundation tokens directly, without a separate `--moduix-json-tree-view-*` variable layer. Add a
class or target Ark part attributes when an inspection surface needs different styling.
