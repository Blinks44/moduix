## Usage

<Usage />

Pass any JSON-like JavaScript value through `data`, then render `<JsonTreeViewTree />` inside the component.
`JsonTreeView` generates the object, array, and value nodes for you. moduix styles the rows, indentation, focus
states, and default disclosure icon.

The framework adapters keep the same flat public names; the Vue example uses native SFC syntax and named slots.

The example starts with two levels expanded. Use `defaultExpandedDepth` to choose how much of a response or
configuration should be visible on the first render.

## Choosing the right component

Use `JsonTreeView` when you already have a JavaScript value and need to inspect it without writing a recursive
renderer. Choose `TreeView` when you own the node model and need custom labels, icons, links, renaming, or branch
content.

## Composition

Keep `JsonTreeViewTree` as the child of `JsonTreeView` or `JsonTreeViewRootProvider`; it renders the generated JSON nodes.
When controls outside the tree own its state, create `useJsonTreeView` from the matching framework package and pass
the store to `JsonTreeViewRootProvider`, then render `JsonTreeViewTree` inside it. Use controlled `expandedValue`,
`selectedValue`, `checkedValue`, or `focusedValue` only when that state belongs to the application. Do not render
`JsonTreeView` and `JsonTreeViewRootProvider` for the same store.

## Styling

Use `className` in React, or `class` in Solid and Vue, on `JsonTreeView`, `JsonTreeViewRootProvider`, or `JsonTreeViewTree` for local layout changes. Tailwind
variants use utility classes and consumer classes; CSS Modules variants use their bundled styles and foundation
tokens.

`JsonTreeViewTree` uses the `ChevronRightIcon` supplied by moduix when `arrow` is omitted in React or Solid. In Vue,
provide the `#arrow` slot when the inspection surface needs a different disclosure icon.

Generated nodes preserve Ark's `data-scope="json-tree-view"` and `data-part` attributes.

`JsonTreeViewTree` forwards Ark's `indentGuide` prop when you opt into indentation guides. moduix does not style the
generated `[data-part='branch-indent-guide']` elements; target that attribute with your own styles when guides are
enabled.

In Vue, use the native `#indentGuide` slot to provide custom guide content.

The component uses foundation tokens directly, without a separate `--moduix-json-tree-view-*` variable layer. Add a
class or target Ark part attributes when an inspection surface needs different styling.

## Keyboard

| Key | Action |
| --- | --- |
| `ArrowDown` / `ArrowUp` | Moves focus to the next or previous row. |
| `ArrowRight` / `ArrowLeft` | Opens or closes the focused object or array. |
| `Home` / `End` | Moves focus to the first or last row. |

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `unknown` | — | JSON value to display. |
| `defaultExpandedDepth` | `number` | — | How many levels are expanded initially. |
| `quotesOnKeys` | `boolean` | `false` | Wraps object keys in quotes. |
| `maxPreviewItems` | `number` | — | Number of items shown in a collapsed preview. |
| `collapseStringsAfterLength` | `number` | — | Truncates longer strings after this many characters. |
| `groupArraysAfterLength` | `number` | — | Groups longer arrays into ranges of this size. |
| `showNonenumerable` | `boolean` | `false` | Shows non-enumerable properties. |
