# List Selection

## API reference

<PrimitiveReference href="https://ark-ui.com/docs/collections/list-selection" />

The `useListSelection` hook tracks selected values in a `ListCollection`. Use it when you are
building a custom list and need selection state without adopting a ready-made collection
component. `Select`, `Combobox`, and `Listbox` already manage selection, so you normally do not
need this hook with them.

Import the collection helpers from Ark UI:

```tsx
import { createListCollection, useListSelection } from '@ark-ui/react/collection';
```

This example uses buttons for a short list of independent options. The hook tracks selected values,
while your UI controls rendering, semantic roles, focus, keyboard interaction, and accessible
labels.

Buttons work well here because each option is an independent action, and `aria-pressed` exposes its
selected state. Do not add `role="listbox"` to custom markup unless you also implement the complete
listbox keyboard and focus model. For a conventional option picker, use [Listbox](/docs/listbox),
which provides listbox semantics and keyboard behavior.

## Configuration

| Prop                      | Description                                                               | Default    |
| ------------------------- | ------------------------------------------------------------------------- | ---------- |
| `collection`              | Collection that provides the values that can be selected.                 | required   |
| `selectionMode`           | `'single'`, `'multiple'`, `'extended'`, or `'none'`.                      | `'single'` |
| `deselectable`            | Whether selecting the current value again can clear the selection.        | `true`     |
| `initialSelectedValues`   | Initial values for uncontrolled selection.                                | `[]`       |
| `resetOnCollectionChange` | Whether to clear the selection when the collection changes.              | `false`    |

`initialSelectedValues` is used only when the selection is created. Use `setSelectedValues` to
change the selection after mount. Use `extended` when your interaction layer maps modifier keys to
`select(value, true)`; the hook does not implement pointer or keyboard events for you.

## State

| Value                | Description                                            |
| -------------------- | ------------------------------------------------------ |
| `selectedValues`     | Array of currently selected values.                    |
| `isEmpty`            | Whether no values are selected.                        |
| `firstSelectedValue` | First selected value in collection order, or `null`.   |
| `lastSelectedValue`  | Last selected value in collection order, or `null`.    |

## Query methods

| Method              | Description                                                  |
| ------------------- | ------------------------------------------------------------ |
| `isSelected(value)` | Checks whether a value is selected.                          |
| `canSelect(value)`  | Checks whether selection is allowed by the current mode.   |
| `isAllSelected()`   | Checks whether every collection item is selected.            |
| `isSomeSelected()`  | Checks whether at least one collection item is selected.     |

Use `canSelect` before exposing a custom selection action when `selectionMode` may be `'none'`.

## Actions

| Method                             | Description                                                      |
| ---------------------------------- | ---------------------------------------------------------------- |
| `select(value, forceToggle?)`      | Selects a value according to the current mode.                    |
| `deselect(value)`                  | Removes one selected value.                                     |
| `toggle(value)`                    | Toggles one value between selected and unselected.              |
| `replace(value)`                   | Replaces the selection with one value. Passing `null` leaves it unchanged. |
| `extend(anchorValue, targetValue)` | Extends the selection between two values in collection order.    |
| `setSelectedValues(values)`        | Sets the selection to the values you provide, subject to the current mode. |
| `clear()`                          | Clears selected values when `deselectable` is `true`.             |
| `resetSelection()`                 | Clears the selection and recreates it with the current settings. |

`clear()` respects `deselectable`. Use `resetSelection()` when you need an empty selection even when
`deselectable` is `false`.

## Multiple selection

```tsx
import { createListCollection, useListSelection } from '@ark-ui/react/collection';
import { Button } from '@moduix/react/button';

const teams = createListCollection({
  items: [
    { label: 'Platform', value: 'platform' },
    { label: 'Product', value: 'product' },
    { label: 'Design', value: 'design' },
  ],
});

function TeamSelectionActions() {
  const selection = useListSelection({
    collection: teams,
    selectionMode: 'multiple',
    initialSelectedValues: ['platform'],
  });

  function toggleAll() {
    if (selection.isAllSelected()) {
      selection.clear();
      return;
    }

    selection.setSelectedValues(teams.getValues());
  }

  return (
    <Button type="button" onClick={toggleAll}>
      {selection.isAllSelected() ? 'Clear all' : 'Select all'}
    </Button>
  );
}
```

Set `selectionMode` to `'multiple'` when users should be able to select several values at once. The
example uses `isAllSelected()` to choose between clearing the selection and selecting every value.

The hook only tracks selection state, so it does not disable your controls. Disable them from the
collection's item state, as the basic example does. When calling `setSelectedValues` with external
values, validate them with `collection.has` and `collection.getItemDisabled` if disabled items should
be excluded.

## Range selection

Keep the anchor value in your interaction layer, then call `extend` when the user selects a range:

```tsx
import { useRef } from 'react';
import { useListSelection, type ListCollection } from '@ark-ui/react/collection';

type Team = {
  label: string;
  value: string;
};

function useRangeSelection(collection: ListCollection<Team>) {
  const selection = useListSelection({
    collection,
    selectionMode: 'multiple',
  });
  const anchorRef = useRef<string | null>(null);

  function handleSelect(value: string, withRange: boolean) {
    if (withRange && anchorRef.current) {
      selection.extend(anchorRef.current, value);
      return;
    }

    selection.replace(value);
    anchorRef.current = value;
  }

  return { selection, handleSelect };
}
```

Map `withRange` to Shift-click or another range gesture. Keyboard range selection also requires
focus management and Shift+Arrow handling. If you need a standard ARIA listbox, use [Listbox](/docs/listbox)
and let it manage those interactions.

## Collection changes

Set `resetOnCollectionChange: true` when a new collection represents a different dataset and the old
selection must not carry over.

Keep the default `false` when filtering temporarily hides items and the selection should survive the
filter. If the collection removes values that must no longer be selected, filter the selected values
and pass the result to `setSelectedValues`:

```tsx
const validValues = selection.selectedValues.filter((value) => collection.has(value));

selection.setSelectedValues(validValues);
```

Run this synchronization in an event handler or effect when the collection changes, not during
render.
