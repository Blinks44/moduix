# Parallax card

A full-bleed image card with a subtle 3D tilt. `Card.Background` owns the decorative photo layer,
while `react-parallax-tilt` handles pointer motion and stays still when a precise hover pointer is
unavailable or reduced motion is requested.

## Use in a page

Replace the image URL and copy with your content. Keep the background image decorative with `alt=""`;
use `Card.Media` when the image itself needs an alternative text. The motion is decorative, so keep
the card readable and usable without hover; use a regular link or button for the real destination.
