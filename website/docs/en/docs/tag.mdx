## API Reference

Ark UI does not ship a dedicated `tag` primitive. moduix builds this component with the official
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) and follows Ark's guidance for
[composition](https://ark-ui.com/docs/guides/composition), [styling](https://ark-ui.com/docs/guides/styling), and
[refs](https://ark-ui.com/docs/guides/ref).

## Choosing the right component

Use `Tag` when the UI shows a value or item that belongs to the current interface state and may
need a local action, such as removal.

- Choose **`Badge`** for short metadata such as status, category, version, or count.
- Choose **`Tag`** for selected values, filters, assignments, or labels that are part of the current interface state.

## Basic

`Tag` ships for React and Solid in both the CSS Modules and Tailwind packages. Start with a `Tag`
root and `Tag.Label`. Add the other parts only when the token needs an icon, supporting content,
or an inline close action. The rendered preview uses the React CSS Modules package; the framework
tabs show native source for the same public contract.

## Anatomy

The root is also available as `Tag.Root`. The short `<Tag>` form and `<Tag.Root>` are equivalent.

```text
Tag / Tag.Root
├─ Tag.StartElement (optional)
├─ Tag.Label
└─ Tag.EndElement (optional)
   └─ Tag.CloseTrigger (optional)
```

| Part               | Role                                                                                     |
| ------------------ | ---------------------------------------------------------------------------------------- |
| `Tag` / `Tag.Root` | Root element. Applies the token layout, border, size, variant, and `asChild` composition. |
| `Tag.Label`        | Visible value wrapper and truncation boundary.                                            |
| `Tag.StartElement` | Optional leading area for an icon, avatar, or status indicator.                           |
| `Tag.EndElement`   | Optional trailing area for an icon or action.                                              |
| `Tag.CloseTrigger` | Optional button for removing the token.                                                   |

## Composition

`Tag` is presentational and does not own selected or removed values. Keep the collection in the
parent, update it from `Tag.CloseTrigger`, and place that trigger inside `Tag.EndElement`.

Use `asChild` only when the root or close trigger must replace its default host element. The single
child becomes the DOM host and must provide the required semantics. In particular,
`Tag.CloseTrigger asChild` needs an explicit close control and accessible name.

## Styling

Start with a built-in variant. CSS Modules users can adjust the public variables or override an
exported part with `className` in React or `class` in Solid. Tailwind users can use native utility
classes on the exported parts. Data attributes and `data-slot` hooks are shared by both styling tracks.

### Styling hooks

- Exported parts emit `data-scope="tag"` and `data-part="root" | "label" | "start-element" | "end-element" | "close-trigger"`.
- `data-slot="tag-root"`, `data-slot="tag-label"`, `data-slot="tag-start-element"`, `data-slot="tag-end-element"`, and `data-slot="tag-close-trigger"` are stable moduix selectors.
- `Tag` writes the selected size and variant to `data-size` and `data-variant`.
- `Tag.CloseTrigger` exposes `data-disabled` for disabled or `aria-disabled` states and inherits the token color.
