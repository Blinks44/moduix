## Choosing the right component

Use `Tag` when the UI shows a value or item that belongs to the current interface state and may
need a local action, such as removal.

- Choose **`Badge`** for short metadata such as status, category, version, or count.
- Choose **`Tag`** for selected values, filters, assignments, or labels that are part of the current interface state.

Use `size="sm"` for dense token rows. Keep the default `md` size for standalone tokens and more

### Interactive tag

Use `asChild` when the whole token is an action. This replaces the default `span`; the single child
becomes the semantic and interactive host, so it must provide the behavior expected from a button or link. A `button` or `a`
host gets a pointer cursor.

<Example name="tag/interactive" />

### Overflow

Constrain the root when long values need to fit a narrow area. `TagLabel` becomes the truncation
boundary and shows an ellipsis; add `title` when the full value should remain discoverable.

## Composition

`Tag` is presentational and does not own selected or removed values. Keep the collection in the
parent, update it from `TagCloseTrigger`, and place that trigger inside `TagEndElement`.

Use `asChild` only when the root or close trigger must replace its default host element. The single
child becomes the DOM host and must provide the required semantics. In particular,
`TagCloseTrigger asChild` needs an explicit close control.

`TagCloseTrigger` is named `Remove tag` unless it receives `aria-label` or `aria-labelledby`,
including with custom children or `asChild`. When several tags are shown, pass a name that includes
the value, such as `aria-label="Remove TypeScript tag"`.

## Styling

Start with a built-in variant. CSS Modules users can adjust the public variables or override an
exported part with `className` in React or `class` in Solid and Vue. Tailwind users can use native utility
classes on the exported parts. Data attributes and `data-slot` hooks are shared by all three framework tracks.

The CSS Modules variables override the background, border, and text color of every variant. Size,
spacing, typography, radius, and close trigger geometry use foundation tokens; change them with a
class on the part.

### Styling hooks

| Part | `data-slot` |
| --- | --- |
| `Tag` | `tag-root` |
| `TagLabel` | `tag-label` |
| `TagStartElement` | `tag-start-element` |
| `TagEndElement` | `tag-end-element` |
| `TagCloseTrigger` | `tag-close-trigger` |

- Exported parts emit `data-scope="tag"` and `data-part="root" | "label" | "start-element" | "end-element" | "close-trigger"`.
- `Tag` writes the selected size and variant to `data-size` and `data-variant`.
- `TagCloseTrigger` exposes `data-disabled` for disabled or `aria-disabled` states and inherits the token color.

## API reference

Also accepts the native props of its element and `asChild`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'default' \| 'secondary' \| 'outline' \| 'ghost' \| 'destructive'` | `'default'` | Visual style: `default`, `secondary`, `outline`, `ghost`, or `destructive`. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Tag size: `sm`, `md`, or `lg`. |
