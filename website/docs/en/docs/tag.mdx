## API Reference

Ark UI does not ship a dedicated `tag` primitive. moduix builds this component with the official
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) and follows Ark's guidance for
[composition](https://ark-ui.com/docs/guides/composition), [styling](https://ark-ui.com/docs/guides/styling), and
[refs](https://ark-ui.com/docs/guides/ref).

## Choosing the right component

Use `Tag` when the UI shows a value or item that belongs to the current interface state and may
need a local action, such as removal.

- Choose **`Badge`** for short metadata such as status, category, version, or count.
- Choose **`Tag`** for selected values, filters, assignments, or labels that are part of the current interface state.

## Anatomy

The root is also available as `Tag.Root`. The short `<Tag>` form and `<Tag.Root>` are equivalent.

```text
Tag / Tag.Root
├─ Tag.StartElement (optional)
├─ Tag.Label
└─ Tag.EndElement (optional)
   └─ Tag.CloseTrigger (optional)
```

| Part               | Role                                                                                     |
| ------------------ | ---------------------------------------------------------------------------------------- |
| `Tag` / `Tag.Root` | Root element. Applies the token layout, border, size, variant, and `asChild` composition. |
| `Tag.Label`        | Visible value wrapper and truncation boundary.                                            |
| `Tag.StartElement` | Optional leading area for an icon, avatar, or status indicator.                           |
| `Tag.EndElement`   | Optional trailing area for an icon or action.                                              |
| `Tag.CloseTrigger` | Optional button for removing the token.                                                   |

## Composition

### Recommended composition

For a simple token, use `Tag` with `Tag.Label`. Keep the visible value in `Tag.Label`, and use
`Tag.StartElement` and `Tag.EndElement` for inline content. If the token can be removed, place
`Tag.CloseTrigger` inside `Tag.EndElement`.

All exported parts forward `ref` and `className` and accept the standard props for their rendered
element.

### When to go custom

Use `asChild` on the root when it should render as a semantic element such as a `button` or link
instead of the default `span`. Pass exactly one child. That child becomes the DOM host and owns its
semantics and interaction behavior.

Use `Tag.CloseTrigger asChild` only when the close action needs its own semantic child. Provide the
child's icon and accessible name yourself because the default close icon is not rendered in this mode.

### Default props

| Surface            | Prop         | Default      | Notes                                                                                  |
| ------------------ | ------------ | ------------ | -------------------------------------------------------------------------------------- |
| `Tag`              | `variant`    | `default`    | `default`, `secondary`, `outline`, `ghost`, `destructive`                              |
| `Tag`              | `size`       | `md`         | `sm`, `md`                                                                             |
| `Tag`              | `asChild`    | `false`      | Replaces the default `span` with one child element.                                    |
| `Tag.CloseTrigger` | `type`       | `button`     | Applied to the default native button and prevents accidental form submission.         |
| `Tag.CloseTrigger` | `asChild`    | `false`      | Replaces the default `button`; the child must provide the close content.               |
| `Tag.CloseTrigger` | `children`   | close icon   | Used only without `asChild`; custom children replace the default icon.                 |
| `Tag.CloseTrigger` | `aria-label` | `Remove tag` | Used when there are no custom children, no `aria-labelledby`, and no `asChild`.         |

### Behavioral notes

- `Tag` does not own selected, removed, or reordered state. The parent component owns the values and the handler that updates them.
- `Tag.CloseTrigger` is explicit composition. There is no root-level `onClose` prop.
- All built-in variants use the same color roles as `Badge`; `Tag` adds token anatomy and an optional inline close action.
- Give each close trigger a specific accessible name when several removable tags appear together.
- Without custom children, `Tag.CloseTrigger` uses the moduix close icon and the `Remove tag` fallback label. With custom children and no label, the shared `CloseButton` fallback is `Close`.
- A disabled or `aria-disabled` close trigger exposes `data-disabled` and does not activate its click handler.
- `asChild` follows Ark factory composition and requires exactly one child. `Tag.CloseTrigger asChild` also requires an explicit semantic child.

## Styling

Start with a built-in variant. For one-off size or color changes, use local CSS variables or a
`className` override. The component-wide color variables take precedence over the variables for
individual variants.

### Styling hooks

- Exported parts emit `data-scope="tag"` and `data-part="root" | "label" | "start-element" | "end-element" | "close-trigger"`.
- `data-slot="tag-root"`, `data-slot="tag-label"`, `data-slot="tag-start-element"`, `data-slot="tag-end-element"`, and `data-slot="tag-close-trigger"` are stable moduix selectors.
- `Tag` writes the selected size and variant to `data-size` and `data-variant`.
- `Tag.CloseTrigger` exposes `data-disabled` for disabled or `aria-disabled` states and inherits the token color.
