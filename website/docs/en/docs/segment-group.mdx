## Choosing The Right Component

Use `SegmentGroup` when users choose one value from a small set that is visible at the same time.

- Choose **`Tabs`** when changing the selection should also change a visible content panel.
- Choose **`ToggleGroup`** when the items act like toolbar buttons and may have multiple active values.
- Choose **`RadioGroup`** when the control should keep the familiar visual appearance of radio buttons.
- Choose **`SegmentGroup`** when the interaction is radio-like but the UI should use a compact segmented control.

## Basic

Use `SegmentGroup.Items` when each segment only needs a text label. It creates the Ark item, text,

## Anatomy

```text
SegmentGroup / SegmentGroup.Root
├─ SegmentGroup.Label (optional)
├─ SegmentGroup.Indicator
└─ SegmentGroup.Item[value]
   ├─ SegmentGroup.ItemText
   ├─ SegmentGroup.ItemControl
   └─ the native form input

SegmentGroup.RootProvider
└─ the same item tree connected to a moduix useSegmentGroup() store

SegmentGroup.Context / SegmentGroup.ItemContext
└─ advanced render-prop access to Ark state
```

| Part                                 | Role                                                                |
| ------------------------------------ | ------------------------------------------------------------------- |
| `SegmentGroup` / `SegmentGroup.Root` | Owns the selected value, keyboard navigation, and form integration. |
| `SegmentGroup.RootProvider`          | Connects the parts to state created with moduix `useSegmentGroup()`. |
| `SegmentGroup.Context`               | Provides advanced render-prop access to the root state.            |
| `SegmentGroup.ItemContext`            | Provides advanced render-prop access to the current item state.    |
| `SegmentGroup.Label`                 | Optional accessible label for the group.                           |
| `SegmentGroup.Indicator`             | Positions the active-item highlight using Ark CSS variables.      |
| `SegmentGroup.Items`                 | Recommended renderer for standard text segments.                   |
| `SegmentGroup.Item`                  | One selectable segment; renders a `label` by default.              |
| `SegmentGroup.ItemText`              | Visible text for a segment.                                         |
| `SegmentGroup.ItemControl`           | Ark control part used for item state; hidden by moduix styles.     |

## Composition

### Recommended composition

For the common case, use the short root form `<SegmentGroup>` with `SegmentGroup.Items`. Place
`SegmentGroup.Indicator` before the items so the measured highlight appears behind the selected
segment. `Items` keeps a native form input in every generated item, which supports native form
submission and reset behavior.

### When to go custom

Use `SegmentGroup.Item` when a segment needs custom content, its own class, or `asChild`. The direct
child passed to `asChild` must still be one semantic `label`. Use `SegmentGroup.RootProvider` with
`useSegmentGroup()` from `@moduix/react` when controls outside the segment tree need to call methods
such as `setValue`, `clearValue`, or `focus`. For custom visuals driven by state, use
`SegmentGroup.Context`, `SegmentGroup.ItemContext`, `useSegmentGroupContext`, or
`useSegmentGroupItemContext` from `@moduix/react`.

`ItemHiddenInput` is internal to moduix. Every `SegmentGroup.Item` already renders exactly one
synchronized native radio input, including when `asChild` is used. Do not add Ark's
`ItemHiddenInput` a second time.

### Default props

| Prop           | Default      | Notes                                                     |
| -------------- | ------------ | --------------------------------------------------------- |
| `defaultValue` | not set      | Initial value for an uncontrolled group.                 |
| `value`        | not set      | Selected value for a controlled group.                   |
| `orientation`  | `horizontal` | moduix default; set `vertical` for a vertical group.    |
| `disabled`     | `false`      | Disables the whole group when set on the root.            |
| `readOnly`     | `false`      | Prevents changes while keeping the current value visible. |
| `required`     | `false`      | Marks the native inputs as required for form validation.  |
| `invalid`      | `false`      | Adds Ark invalid-state attributes for styling and ARIA.   |

### Behavioral notes

`onValueChange(details)` keeps Ark's callback shape. Read the selected value from `details.value`.
Ark manages the selected value, focus movement, arrow-key navigation, disabled, read-only,
invalid, and required states, as well as form submission and reset synchronization.

Press <kbd>Tab</kbd> to focus the selected item, or the first item when nothing is selected. Use
the arrow keys to move between items and <kbd>Space</kbd> to select the focused item. Set `name`
on the root when the selected value should be included in native `FormData`.

`Root`, `RootProvider`, `Label`, `Item`, `ItemControl`, `ItemText`, and `Indicator` forward refs to
their corresponding Ark DOM parts. Use `Field` or `Fieldset` when their shared state should apply:
`Field` passes disabled, invalid, required, and read-only state, while `Fieldset` passes disabled
and invalid state. Use `ids` when composed labels or controls need deterministic accessibility
identifiers.

## Styling

Style `SegmentGroup` with `className`, stable `data-slot="segment-group-*"` hooks, Ark's
`data-scope`, `data-part`, and state attributes, and the public `--moduix-segment-group-*` CSS
variables listed below.

### CSS Properties

<CssPropertiesSection properties={SegmentGroupDocs.segmentGroupOverrideCssProperties} />

### Styling hooks

- Ark anatomy hooks: `data-scope="segment-group"` and `data-part` on the root, label, indicator,
  item, item text, item control, and hidden input.
- Ark state hooks: `data-state="checked" | "unchecked"`, `data-orientation`, `data-disabled`,
  `data-readonly`, `data-invalid`, `data-required`, `data-active`, and `data-focus-visible`.
- moduix hooks: `data-slot="segment-group-root"`, `segment-group-root-provider`,
  `segment-group-label`, `segment-group-indicator`, `segment-group-item`,
  `segment-group-item-text`, `segment-group-item-control`, and
  `segment-group-item-hidden-input`.
- The indicator uses Ark runtime variables `--left`, `--top`, `--width`, and `--height` for its
  size. Its motion uses `--transition-duration` and `--transition-timing-function`, with moduix
  defaults mapped from `--moduix-segment-group-indicator-transition-duration` and
  `--moduix-segment-group-indicator-transition-timing-function`.
