## Basic

Use `Listbox` when users need to choose one or more items from a list that stays open. Provide a
`collection`, render `Content`, and pass each collection item to `Listbox.Item` through `item`.

## Anatomy

```text
Listbox / Listbox.Root
├─ Listbox.Label
├─ Listbox.Filter
│  ├─ Listbox.Input
│  └─ Listbox.ClearTrigger
├─ Listbox.Content
│  ├─ Listbox.Empty
│  ├─ Listbox.ItemGroup
│  │  ├─ Listbox.ItemGroupLabel
│  │  └─ Listbox.Item[item]
│  │     ├─ Listbox.ItemText
│  │     └─ Listbox.ItemIndicator
│  └─ Listbox.Item[item]
│     ├─ Listbox.ItemText
│     │  └─ Listbox.ItemTextContent (optional)
│     │     ├─ Listbox.ItemTextIcon (optional)
│     │     └─ Listbox.ItemTextLabel (optional)
│     └─ Listbox.ItemIndicator
└─ Listbox.ValueText
```

| Part                       | Role                                                          |
| -------------------------- | ------------------------------------------------------------- |
| `Listbox` / `Listbox.Root` | Manages the collection, selected values, highlighted item, and selection mode. |
| `Listbox.RootProvider`     | Renders a listbox tree from state returned by `useListbox`.                     |
| `Listbox.Label`            | Accessible label for the listbox.                                               |
| `Listbox.Filter`           | Default search field with an icon. Place it before `Content`.                  |
| `Listbox.Input`            | Filter input, usually placed inside `Filter`.                                  |
| `Listbox.ClearTrigger`     | Accessible query-reset button with the default close icon.                     |
| `Listbox.Content`          | Focusable listbox container that handles keyboard navigation.                   |
| `Listbox.Empty`            | Content shown when the filtered collection has no items.                        |
| `Listbox.ItemGroup`        | Group wrapper for related collection items.                                     |
| `Listbox.ItemGroupLabel`   | Label for a collection group.                                                   |
| `Listbox.Item`             | Selectable row. Pass its collection item through `item`.                        |
| `Listbox.ItemText`         | Text used for display and accessibility.                                        |
| `Listbox.ItemTextContent`  | Optional helper for laying out icon and text inside `ItemText`.                 |
| `Listbox.ItemTextIcon`     | Optional icon wrapper inside `ItemTextContent`.                                |
| `Listbox.ItemTextLabel`    | Label inside `ItemTextContent` that can truncate safely.                        |
| `Listbox.ItemIndicator`    | Selection indicator with the default moduix check icon.                         |
| `Listbox.ValueText`        | Summary of the selected values.                                                 |

## Composition

### Recommended composition

Render the Ark part tree directly. `Listbox` manages the collection, `Listbox.Content` manages focus
and keyboard navigation, and each `Listbox.Item` receives its original collection item through `item`.
Add `Listbox.ItemIndicator` when rows need to reserve space for a selection indicator.

For filtering, place `Listbox.Input` inside `Listbox.Filter` immediately before `Listbox.Content`.
`Filter` adds the default search icon and visually joins the input and results into one bordered surface.

### When to go custom

Use `asChild` only when your custom element can preserve the required listbox semantics and accept
Ark props. Use `ids` when listbox parts need stable IDs to integrate with surrounding UI. Use moduix
`useListbox` with `Listbox.RootProvider` when state is controlled outside the rendered tree; do not
render `Listbox.Root` for that same state instance. Render `Listbox.Input` directly when the filter
should remain visually separate from the list or live in custom surrounding UI.

### Default props

| Prop                      | Default    | Notes                                                                 |
| ------------------------- | ---------- | --------------------------------------------------------------------- |
| `collection`              | -          | Required Ark collection. Create one with `createListCollection` or use a grid variant. |
| `defaultValue`            | `[]`       | Initial selected values for uncontrolled state.                                      |
| `defaultHighlightedValue` | -          | Initial highlighted item in uncontrolled state.                                    |
| `deselectable`            | -          | Allows Escape to clear a non-empty selection.                          |
| `disabled`                | `false`    | Disables the whole listbox.                                           |
| `disallowSelectAll`       | `false`    | Disables `Cmd/Ctrl + A` selection.                                    |
| `loopFocus`               | `false`    | Prevents arrow-key navigation from wrapping.                          |
| `orientation`             | `vertical` | Controls the layout and arrow-key direction.                          |
| `selectionMode`           | `single`   | Supports `single`, `multiple`, and `extended`.                        |
| `selectOnHighlight`       | `false`    | Selects items as keyboard highlight changes.                          |
| `typeahead`               | `true`     | Enables typeahead when no filtering input owns text entry.             |

### Behavioral notes

`value`, `defaultValue`, and `onValueChange(details)` use string arrays. Read `details.value` for
selected keys and `details.items` for selected collection items.

`highlightedValue`, `defaultHighlightedValue`, and `onHighlightChange(details)` control movement of
the active descendant. `onSelect(details)` fires when an item is selected and includes its value.

`useListbox`, `useListboxContext`, `useListboxItemContext`, `Listbox.Context`, and
`Listbox.ItemContext` are available from `@moduix/react` for advanced state and item composition.
Refs are forwarded to the corresponding Ark part. Refs on the root and root provider target their
rendered `div` elements. Use `ids` when listbox parts need stable IDs for composition with surrounding UI.

Listbox does not render a native form control for selected values. If the selection must be submitted,
keep submission and reset state in your form model.

`Listbox.Input` is only needed for filtering. Put it in `Listbox.Filter` for the default search
appearance, or render it directly for a separate input. Set `typeahead={false}` so typeahead and
filtering do not compete. Keep filtering state explicit: render `Listbox.ClearTrigger` when the query
is not empty, and clear both the query and the collection filter in its `onClick` handler.

Ark handles the ARIA listbox pattern, active-descendant focus management, keyboard navigation,
typeahead, Home/End behavior, disabled items, and orientation-specific arrow keys. Keep
`Listbox.Label` in the tree when the listbox needs a visible label.

- moduix hooks: `data-slot="listbox-root"`, `listbox-label`, `listbox-filter`,
