## Choosing the right component

Use `Listbox` when the options should stay visible and users choose from a collection. Use `Select`
when users should choose from a popup. Use `Combobox` when users need an input-driven popup for
searching or entering a value.

## Basic


Pass a `collection`, render `ListboxContent`, and pass each collection item to `ListboxItem`
through `item`. Add `ListboxItemIndicator` when rows should show the selected state.

## Anatomy

```text
Listbox
├─ ListboxLabel
├─ ListboxFilter
│  ├─ ListboxInput
│  └─ ListboxClearTrigger
├─ ListboxContent
│  ├─ ListboxEmpty
│  ├─ ListboxItemGroup
│  │  ├─ ListboxItemGroupLabel
│  │  └─ ListboxItem[item]
│  │     ├─ ListboxItemText
│  │     └─ ListboxItemIndicator
│  └─ ListboxItem[item]
│     ├─ ListboxItemText
│     │  └─ ListboxItemTextContent (optional)
│     │     ├─ ListboxItemTextIcon (optional)
│     │     └─ ListboxItemTextLabel (optional)
│     └─ ListboxItemIndicator
└─ ListboxValueText

ListboxRootProvider
└─ same item tree connected to a useListbox() store
```

| Part                       | Role                                                                                   |
| -------------------------- | -------------------------------------------------------------------------------------- |
| `Listbox` | Manages the collection, selected values, highlighted item, and selection mode.         |
| `ListboxRootProvider`     | Renders the listbox tree from state returned by `useListbox`.                          |
| `ListboxLabel`            | Label that gives the listbox an accessible name.                                       |
| `ListboxFilter`           | Visual wrapper for a filter input with the default search icon. Place it before `ListboxContent`. |
| `ListboxInput`            | Filter input, usually placed inside `ListboxFilter`.                                         |
| `ListboxClearTrigger`     | Button for resetting the filter query, with the default close icon.                    |
| `ListboxContent`          | Focusable listbox container that handles keyboard navigation.                          |
| `ListboxEmpty`            | Content shown when the filtered collection has no items.                               |
| `ListboxItemGroup`        | Group wrapper for related collection items.                                            |
| `ListboxItemGroupLabel`   | Label for a collection group.                                                          |
| `ListboxItem`             | Selectable item. Pass its collection item through `item`.                              |
| `ListboxItemText`         | Text used for display and accessibility.                                               |
| `ListboxItemTextContent`  | Optional wrapper for laying out an icon and text inside `ListboxItemText`.                    |
| `ListboxItemTextIcon`     | Optional icon wrapper inside `ListboxItemTextContent`.                                       |
| `ListboxItemTextLabel`    | Text wrapper inside `ListboxItemTextContent` that can truncate long labels without breaking layout. |
| `ListboxItemIndicator`    | Selection indicator with the default moduix check icon.                                |
| `ListboxValueText`        | Summary of the selected values.                                                        |

## Composition

Use `defaultValue` for uncontrolled selection. When another part of the application owns the
selection, pass `value` and update it from `onValueChange(details.value)`. For filtering, set
`typeahead={false}`, keep the query in application state, and call the `filter` function returned by
`useListCollection` from the input handler. `ListboxFilter` only provides the joined search-field appearance, so a
clear action must reset both the query and the collection filter.

Use `useListbox` from the matching framework package with `ListboxRootProvider` when the store must
be created outside the rendered tree. Pass the returned store to `ListboxRootProvider` and do not render
`Listbox` for the same store. `ListboxInput` can be rendered directly when the
filter needs a separate wrapper, and `ListboxValueText` can be placed after `ListboxContent` for a selected
value summary.

## Styling

Style Listbox through `className` in React or `class` in Solid and Vue on exported parts. Tailwind
variants use native utilities and consumer classes. CSS Modules variants take colors, spacing, and
typography from foundation tokens and expose only the root width and content maximum height as CSS
variables; override other styles with a class on the part. Items, group labels, and the list padding
also follow the shared `--moduix-popup-item-*`, `--moduix-popup-group-label-*`, and
`--moduix-popup-list-padding-y` variables.
