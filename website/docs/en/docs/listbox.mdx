## Choosing the right component

Use `Listbox` when the options should stay visible and users choose from a collection. Use `Select`
when users should choose from a popup. Use `Combobox` when users need an input-driven popup for
searching or entering a value.

## Basic

Use `Listbox` when users need to choose one or more items from a list that stays open. Pass a
`collection`, render `Listbox.Content`, and pass each collection item to `Listbox.Item` through `item`.

## Anatomy

```text
Listbox / Listbox.Root
├─ Listbox.Label
├─ Listbox.Filter
│  ├─ Listbox.Input
│  └─ Listbox.ClearTrigger
├─ Listbox.Content
│  ├─ Listbox.Empty
│  ├─ Listbox.ItemGroup
│  │  ├─ Listbox.ItemGroupLabel
│  │  └─ Listbox.Item[item]
│  │     ├─ Listbox.ItemText
│  │     └─ Listbox.ItemIndicator
│  └─ Listbox.Item[item]
│     ├─ Listbox.ItemText
│     │  └─ Listbox.ItemTextContent (optional)
│     │     ├─ Listbox.ItemTextIcon (optional)
│     │     └─ Listbox.ItemTextLabel (optional)
│     └─ Listbox.ItemIndicator
└─ Listbox.ValueText

Listbox.RootProvider
└─ same item tree connected to a useListbox() store
```

| Part                       | Role                                                                                   |
| -------------------------- | -------------------------------------------------------------------------------------- |
| `Listbox` / `Listbox.Root` | Manages the collection, selected values, highlighted item, and selection mode.         |
| `Listbox.RootProvider`     | Renders the listbox tree from state returned by `useListbox`.                          |
| `Listbox.Label`            | Label that gives the listbox an accessible name.                                       |
| `Listbox.Filter`           | Visual wrapper for a filter input with the default search icon. Place it before `Listbox.Content`. |
| `Listbox.Input`            | Filter input, usually placed inside `Filter`.                                         |
| `Listbox.ClearTrigger`     | Button for resetting the filter query, with the default close icon.                    |
| `Listbox.Content`          | Focusable listbox container that handles keyboard navigation.                          |
| `Listbox.Empty`            | Content shown when the filtered collection has no items.                               |
| `Listbox.ItemGroup`        | Group wrapper for related collection items.                                            |
| `Listbox.ItemGroupLabel`   | Label for a collection group.                                                          |
| `Listbox.Item`             | Selectable item. Pass its collection item through `item`.                              |
| `Listbox.ItemText`         | Text used for display and accessibility.                                               |
| `Listbox.ItemTextContent`  | Optional wrapper for laying out an icon and text inside `ItemText`.                    |
| `Listbox.ItemTextIcon`     | Optional icon wrapper inside `ItemTextContent`.                                       |
| `Listbox.ItemTextLabel`    | Text wrapper inside `ItemTextContent` that can truncate long labels without breaking layout. |
| `Listbox.ItemIndicator`    | Selection indicator with the default moduix check icon.                                |
| `Listbox.ValueText`        | Summary of the selected values.                                                        |

## Composition

### Recommended composition

Compose the listbox from its Ark parts. `Listbox` manages the collection, `Listbox.Content` manages
focus and keyboard navigation, and each `Listbox.Item` receives its original collection item through
`item`. Add `Listbox.ItemIndicator` when rows should reserve space for a selection indicator.

`Listbox` is the concise root form and is equivalent to `Listbox.Root`. For filtering, place
`Listbox.Input` inside `Listbox.Filter` immediately before `Listbox.Content`. `Filter` adds the
default search icon and visually joins the input and results into one bordered surface. It is only a
visual wrapper, so your code still owns the query and collection filtering state.

### When to go custom

Use `asChild` only when your custom element can preserve the required listbox semantics and accept
Ark props. Use `ids` when listbox parts need stable IDs to integrate with surrounding UI. Use
`useListbox` from `@moduix/react/listbox` with `Listbox.RootProvider` when state is controlled
outside the rendered tree. Do not render `Listbox.Root` for that same state instance. Render
`Listbox.Input` directly when the filter should remain visually separate from the list or live in a
custom surrounding UI.

### Default props

| Prop                      | Default    | Notes                                                                                     |
| ------------------------- | ---------- | ----------------------------------------------------------------------------------------- |
| `collection`              | -          | Required Ark collection. Create one with `createListCollection` or use a grid collection. |
| `defaultValue`            | `[]`       | Initial selected values for uncontrolled state.                                           |
| `defaultHighlightedValue` | -          | Initial highlighted item for uncontrolled state.                                          |
| `deselectable`            | -          | Allows `Escape` to clear a non-empty selection.                                           |
| `disabled`                | `false`    | Disables the whole listbox.                                                               |
| `disallowSelectAll`       | `false`    | Disables `Cmd/Ctrl + A` selection.                                                        |
| `loopFocus`               | `false`    | Prevents arrow-key navigation from wrapping.                                              |
| `orientation`             | `vertical` | Controls the layout and arrow-key direction.                                              |
| `selectionMode`           | `single`   | Supports `single`, `multiple`, and `extended`.                                             |
| `selectOnHighlight`       | `false`    | Selects items as keyboard highlight changes.                                               |
| `typeahead`               | `true`     | Enables typeahead when no filter input handles text entry.                                |

### Behavioral notes

`value`, `defaultValue`, and `onValueChange(details)` use string arrays. Read `details.value` for
selected keys and `details.items` for selected collection items.

`highlightedValue`, `defaultHighlightedValue`, and `onHighlightChange(details)` control the active
item during navigation. `onSelect(details)` fires when an item is selected and includes its value.

`useListbox`, `useListboxContext`, `useListboxItemContext`, `Listbox.Context`, and
`Listbox.ItemContext` are available from `@moduix/react/listbox` for advanced state and item
composition. Refs are forwarded to the corresponding Ark part. Refs on the root and root provider
target their rendered `div` elements. Use `ids` when listbox parts need stable IDs for composition
with surrounding UI.

Listbox does not render a native form control for selected values. If the selection must be submitted,
keep submission and reset state in your form model.

`Listbox.Input` is only needed for filtering. Put it in `Listbox.Filter` for the default search
appearance, or render it directly for a separate input. Set `typeahead={false}` so typeahead and
filtering do not compete. Keep filtering state explicit: render `Listbox.ClearTrigger` when the query
is not empty, and clear both the query and the collection filter in its `onClick` handler.

Ark handles the ARIA listbox pattern, active-descendant focus management, keyboard navigation,
typeahead, Home/End behavior, disabled items, and orientation-specific arrow keys. Keep
`Listbox.Label` in the tree when the listbox needs a visible label.

## Styling

Style `Listbox` through `className`, stable `data-slot="listbox-*"` hooks, Ark
`data-scope="listbox"` / `data-part`, state attributes, and the public `--moduix-listbox-*`
CSS variables.

- Ark anatomy hooks: `data-scope="listbox"` and `data-part` on root, label, input, content,
