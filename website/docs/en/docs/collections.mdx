# Collections

Collections are data structures and hooks for list-based interfaces. They keep item values, labels, disabled state,
hierarchy, and asynchronous state in a form that Ark UI components can consume. Collections do not render UI by
themselves; moduix components provide the accessible interaction around that data.

Use a collection with `Select`, `Combobox`, `Listbox`, `TreeView`, or a custom list or tree. The collection helpers
come directly from Ark UI. The guides below show how to create and update collections, connect them to moduix
components, and manage loading or selection state.
