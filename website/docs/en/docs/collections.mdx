# Collections

Ark UI collections are the data layer behind list-based interfaces. They model item identity, labels, disabled state,
and traversal; moduix components render the accessible interaction on top.

Use a collection when data is shared by `Select`, `Combobox`, `Listbox`, `TreeView`, or a custom list. These APIs come
directly from Ark UI, while the linked pages show how to connect them to moduix components.
