## API Reference

Ark UI does not ship a dedicated primitive for displaying keyboard keys. moduix builds `Kbd` with the official
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory), so it follows Ark's familiar composition,
styling, and ref patterns. See the Ark guides for [composition](https://ark-ui.com/docs/guides/composition),
[styling](https://ark-ui.com/docs/guides/styling), and [refs](https://ark-ui.com/docs/guides/ref) when you need to
customize the rendered elements.

## Anatomy

The structure of a shortcut is simple. The `+` in this example is ordinary text, not a component part.

```text
KbdGroup
├─ Kbd
├─ +
└─ Kbd
```

| Part               | Role                                                                          |
| ------------------ | ----------------------------------------------------------------------------- |
| `Kbd`              | Root keycap; renders a `<kbd>` element by default.                            |
| `KbdGroup`         | Inline wrapper for related keycaps; uses the `group` role by default.         |

## Composition

Use `Kbd` when you need an individual key, and use `KbdGroup` to combine related keycaps. Keep separators such as
`+` as plain text inside the group, and give the group an `aria-label` when visual
symbols or abbreviations need a clearer accessible name.

Kbd is static and owns no state or keyboard interaction. Use `asChild` only when another component must render the
semantic `<kbd>` element, and pass exactly one child.

## Styling

Customize `Kbd` and `KbdGroup` with `className` in React, `class` in Solid and Vue, Ark anatomy attributes, stable
`data-slot` hooks, and the public `--moduix-kbd-*` CSS variables listed below. Tailwind variants use native utility
classes, while CSS Modules variants use the component variables and consumer CSS.

### Styling hooks

- `data-slot="kbd-root"` targets each keycap element
- `data-slot="kbd-group"` targets the inline wrapper for grouped shortcuts
- `[data-scope="kbd"][data-part="root"]` and `[data-part="group"]` expose Ark-style anatomy selectors
- Separators in `KbdGroup` inherit the group's text color. To change it, set `color` on `KbdGroup` with your own class
