## API Reference

Ark UI does not ship a dedicated kbd primitive. moduix builds this component with the official
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory), follows Ark's
[composition](https://ark-ui.com/docs/guides/composition), [styling](https://ark-ui.com/docs/guides/styling), and
[ref](https://ark-ui.com/docs/guides/ref) guidance.

## Anatomy

The typical composition is simple:

```text
Kbd.Group
├─ Kbd / Kbd.Root
├─ +
└─ Kbd / Kbd.Root
```

| Part               | Role                                                    |
| ------------------ | ------------------------------------------------------- |
| `Kbd` / `Kbd.Root` | Keycap root; renders a `kbd` element by default. |
| `Kbd.Group`        | Inline wrapper for shortcut combinations; uses the `group` role by default. |

## Composition

### Recommended composition

Use `Kbd` as the root shorthand. Use `Kbd.Group` for shortcut hints, command menus, and inline help.

`Kbd` and `Kbd.Root` accept `HTMLArkProps<'kbd'>`; `Kbd.Group` accepts `HTMLArkProps<'span'>` and renders with
`role="group"` by default. Every part forwards its ref to the rendered element and supports `asChild`.
The component has no variant, size, separator, callback, or state API.

### When to go custom

Use `asChild` when another layer already owns a semantic `<kbd>` element and you want to apply Kbd's styles and Ark
composition to it. Pass exactly one child and preserve its keyboard-input semantics.

### Behavioral notes

- `Kbd`, `Kbd.Root`, and `Kbd.Group` render static keyboard labels. They are not interactive controls.
- Keep separators such as `+`, `/`, or `then` as regular text in the surrounding composition.
- Give `Kbd.Group` an `aria-label` when abbreviations or symbols could be unclear when announced.
- The parts expose `data-scope="kbd"`, `data-part`, and stable `data-slot` attributes.

## Styling

Style `Kbd` and `Kbd.Group` with `className`, Ark anatomy attributes, stable `data-slot` hooks, and the public
`--moduix-kbd-*` CSS variables listed below.

### CSS Properties

<CssPropertiesSection properties={KbdDocs.kbdOverrideCssProperties} />

### Styling hooks

- `data-slot="kbd-root"` targets each keycap element
- `data-slot="kbd-group"` targets the inline wrapper for grouped shortcuts
- `[data-scope="kbd"][data-part="root"]` and `[data-part="group"]` expose Ark-style anatomy selectors
- `Kbd.Group` inherits the surrounding text style for separators. Use `--moduix-kbd-group-separator-color` to set their color
