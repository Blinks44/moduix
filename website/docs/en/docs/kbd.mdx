Use `Kbd` to show one key. For a shortcut made of several keys, place the keycaps and their text separators inside
`KbdGroup`.

## Composition

Use `Kbd` when you need an individual key, and use `KbdGroup` to combine related keycaps. Keep separators such as
`+` as plain text inside the group, and give the group an `aria-label` when visual
symbols or abbreviations need a clearer accessible name.

Kbd is static and has no state or keyboard interaction. Use `asChild` only when another component must render the
semantic `<kbd>` element, and pass exactly one child.

## Anatomy

A shortcut is a `KbdGroup` of `Kbd` keycaps. A `+` between keys is ordinary text, not a component part.

## Styling

Customize `Kbd` and `KbdGroup` with `className` in React, `class` in Solid and Vue, Ark anatomy attributes, stable
`data-slot` hooks, and the public `--moduix-kbd-*` CSS variables listed below. Tailwind variants use native utility
classes, while CSS Modules variants use the component variables and consumer CSS.

### Styling hooks

| Part | `data-slot` |
| --- | --- |
| `Kbd` | `kbd-root` |
| `KbdGroup` | `kbd-group` |

- `[data-scope="kbd"][data-part="root"]` and `[data-part="group"]` expose Ark-style anatomy selectors
- Separators in `KbdGroup` inherit the group's text color. To change it, set `color` on `KbdGroup` with your own class

## API reference

`Kbd` renders a `kbd` element and `KbdGroup` a `span`. Both accept their native props and `asChild`.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |
