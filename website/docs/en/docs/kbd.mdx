## API Reference

Ark UI does not ship a dedicated primitive for displaying keyboard keys. moduix builds `Kbd` with the official
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory), so it follows Ark's familiar composition,
styling, and ref patterns. See the Ark guides for [composition](https://ark-ui.com/docs/guides/composition),
[styling](https://ark-ui.com/docs/guides/styling), and [refs](https://ark-ui.com/docs/guides/ref) when you need to
customize the rendered elements.

## Basic

Use `Kbd` to show one key. For a shortcut made of several keys, place the keycaps and their text separators inside
`Kbd.Group`.

## Anatomy

The structure of a shortcut is simple. The `+` in this example is ordinary text, not a component part.

```text
Kbd.Group
├─ Kbd / Kbd.Root
├─ +
└─ Kbd / Kbd.Root
```

| Part               | Role                                                                          |
| ------------------ | ----------------------------------------------------------------------------- |
| `Kbd` / `Kbd.Root` | Root keycap; renders a `<kbd>` element by default.                            |
| `Kbd.Group`        | Inline wrapper for related keycaps; uses the `group` role by default.         |

## Composition

### Recommended composition

Use `Kbd` as the shorthand for `Kbd.Root` when you need to show an individual key. Use `Kbd.Group` to keep a shortcut
together, or for shortcut hints in command menus and inline help.

`Kbd` and `Kbd.Root` accept `HTMLArkProps<'kbd'>`. `Kbd.Group` accepts `HTMLArkProps<'span'>` and uses
`role="group"` by default. Every part forwards its ref to the rendered element and supports `asChild`.
The component has no API for variants, sizes, separators, callbacks, or state.

### When to go custom

Use `asChild` when another component already renders a semantic `<kbd>` element and you want to apply Kbd's styles to
it. Pass exactly one child and preserve its keyboard-label semantics.

### Behavioral notes

- `Kbd`, `Kbd.Root`, and `Kbd.Group` render static keyboard labels. They are not interactive controls.
- Keep separators such as `+`, `/`, or `then` as regular text outside `Kbd`.
- Give `Kbd.Group` an `aria-label` when an abbreviation or symbol could be unclear when announced.
- The parts expose `data-scope="kbd"`, `data-part`, and stable `data-slot` attributes.

## Styling

Customize `Kbd` and `Kbd.Group` with `className`, Ark anatomy attributes, stable `data-slot` hooks, and the public
`--moduix-kbd-*` CSS variables listed below.

### CSS Properties

<CssPropertiesSection properties={KbdDocs.kbdOverrideCssProperties} />

### Styling hooks

- `data-slot="kbd-root"` targets each keycap element
- `data-slot="kbd-group"` targets the inline wrapper for grouped shortcuts
- `[data-scope="kbd"][data-part="root"]` and `[data-part="group"]` expose Ark-style anatomy selectors
- Separators in `Kbd.Group` inherit the group's text color. Use `--moduix-kbd-group-separator-color` to set it
