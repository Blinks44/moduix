Pass a collection to `Select`, use `SelectField` for the standard visible control, and keep the popup structure explicit. `clearLabel` adds an accessible clear action. Add `SelectHiddenSelect` explicitly when native submission, autofill, validation, and reset are needed.

## Choosing the right component

Use `Select` when users choose from a fixed collection and the trigger stays read-only. Use
`Combobox` when typing helps find or create a value.

## Composition

`SelectField` is the shortcut for `SelectControl`, `SelectTrigger`, `SelectValueText`, and the default `SelectIndicator`. Add `clearLabel` for a labelled clear action, or use the explicit parts when the trigger layout needs independent styling. Keep `SelectPositioner`, `SelectContent`, and the collection items in the same Select tree. Use `SelectOption` for ordinary rows: it renders `SelectItem` with `SelectItemText` and `SelectItemIndicator`. Pass `indicator={false}` to hide the check or an icon to replace it, and use `SelectItem` when a row needs custom structure.

Add `SelectHiddenSelect` explicitly inside `Select` or `SelectRootProvider` when the selection must participate in native form submission, validation, autofill, or reset. The root does not render it automatically. `Positioner` is portalled automatically; set `portalled={false}` for inline rendering or use `portalRef` for a custom container.

Use `useSelect` with `SelectRootProvider` when state must be shared with controls outside the Select tree. The returned store is an object in React, an accessor in Solid, and a ref in Vue.

## Styling

Style Select with `className` in React, `class` in Solid and Vue, stable `data-slot="select-*"` hooks, and Ark attributes. Tailwind variants use native utility classes and consumer classes. CSS Modules variants keep five size variables, listed below; colors, borders, focus rings, item spacing, and motion come from foundation tokens and the shared `--moduix-popup-*` variables, so override them with a class on the part.

Its `indicator` prop supplies the
child of the existing indicator slot. `SelectOption` reuses the item slots
instead of adding its own styling hook.

- Ark anatomy uses `data-scope="select"` and `data-part`.
- State styling uses `data-state="open" | "closed"`, `data-focus`, `data-invalid`,
  `data-disabled`, `data-readonly`, `data-required`, `data-placeholder-shown`, `data-highlighted`,
  and item `data-state="checked" | "unchecked"`.
- `SelectPositioner` exposes `--reference-width`, `--reference-height`, `--available-width`,
  `--available-height`, `--x`, `--y`, `--z-index`, and `--transform-origin`.

## Keyboard

| Key | Action |
| --- | --- |
| `Enter` / `Space` / `ArrowDown` | Opens the list from the trigger. |
| `ArrowDown` / `ArrowUp` | Highlights the next or previous option. |
| `Enter` | Selects the highlighted option. |
| `Esc` | Closes the list. |
| Letters | Highlights the next option that starts with the typed text. |
