## Choosing the right component

Use `Select` when users choose from a fixed collection and the trigger stays read-only. Use
`Combobox` when typing helps find or create a value.

Pass a collection to `Select`, use `SelectField` for the standard visible control, and keep the popup structure explicit. `clearLabel` adds an accessible clear action. Add `SelectHiddenSelect` explicitly when native submission, autofill, validation, and reset are needed.

## Anatomy

```text
Select
├─ SelectLabel
├─ SelectControl / SelectField
│  ├─ SelectTrigger
│  │  ├─ SelectValueText
│  ├─ SelectClearTrigger
│  └─ SelectIndicator
├─ Overlay subtree (automatically portalled)
│  └─ SelectPositioner
│     └─ SelectContent
│        ├─ SelectList
│        └─ SelectItemGroup
│           ├─ SelectItemGroupLabel
│           └─ SelectItem[item]
│              ├─ SelectItemText
│              │  └─ SelectItemTextContent
│              │     ├─ SelectItemTextIcon
│              │     └─ SelectItemTextLabel
│              └─ SelectItemIndicator
└─ SelectHiddenSelect (explicit)
```

| Part                     | Role                                                                   |
| ------------------------ | ---------------------------------------------------------------------- |
| `Select`                  | Root state, collection, selection, popup lifecycle, and form data.     |
| `SelectHiddenSelect`      | Native Ark form control; compose explicitly as described below.       |
| `SelectRootProvider`      | Renders a select tree from state returned by `useSelect`.              |
| `SelectContext`           | Root context for advanced state reads.                                 |
| `SelectItemContext`       | Item context for advanced state reads.                                 |
| `SelectLabel`           | Accessible label inherited by the trigger and native form control.     |
| `SelectControl`         | Visual field wrapper that receives focus, invalid, and open state.     |
| `SelectField`           | moduix helper that renders the standard control, trigger, and actions. |
| `SelectTrigger`         | Button that opens the popup and owns keyboard entry.                   |
| `SelectValueText`       | Placeholder or selected item labels.                                   |
| `SelectClearTrigger`    | Button that clears the current value.                                  |
| `SelectIndicator`       | Trigger indicator with the moduix default chevron icon.                |
| `SelectPositioner`      | Floating layer that exposes Ark positioning CSS variables.             |
| `SelectContent`         | Popup surface and listbox container.                                   |
| `SelectList`            | Optional list wrapper for virtualized or custom list layouts.          |
| `SelectItemGroup`       | Group wrapper for related collection items.                            |
| `SelectItemGroupLabel`  | Label for a collection group.                                          |
| `SelectItem`            | Selectable row. Pass the collection item through `item`.               |
| `SelectItemText`        | Text used for display and accessibility.                               |
| `SelectItemTextContent` | Layout helper for rich item text.                                     |
| `SelectItemTextIcon`    | Icon wrapper for rich item text.                                      |
| `SelectItemTextLabel`   | Label wrapper for rich item text.                                    |
| `SelectItemIndicator`   | Selected-state indicator with the moduix default check icon.           |

## Composition

`SelectField` is the shortcut for `SelectControl`, `SelectTrigger`, `SelectValueText`, and the default `SelectIndicator`. Add `clearLabel` for a labelled clear action, or use the explicit parts when the trigger layout needs independent styling. Keep `SelectPositioner`, `SelectContent`, and the collection items in the same Select tree.

Add `SelectHiddenSelect` explicitly inside `Select` or `SelectRootProvider` when the selection must participate in native form submission, validation, autofill, or reset. The root does not render it automatically. `Positioner` is portalled automatically; set `portalled={false}` for inline rendering or use `portalRef` for a custom container.

Use `useSelect` with `SelectRootProvider` when state must be shared with controls outside the Select tree. The returned store is an object in React and an accessor in Solid.

## Styling

Style Select with `className` in React or `class` in Solid, stable `data-slot="select-*"` hooks, Ark attributes, and public `--moduix-select-*` CSS variables. Tailwind variants use native utility classes and consumer classes; CSS Modules variants use the variables documented below.

### CSS Properties

<CssPropertiesSection properties={SelectDocs.selectOverrideCssProperties} />

### Styling hooks

`SelectField` renders the existing `select-control`, `select-trigger`, `select-value-text`,
`select-indicator`, and optional `select-clear-trigger` slots. Its `indicator` prop supplies the
child of the existing indicator slot. Rich item text helpers expose `select-item-text-content`,
`select-item-text-icon`, and `select-item-text-label` slots.

- Roots expose `data-slot="select-root"` and `data-slot="select-root-provider"`.
- Ark anatomy uses `data-scope="select"` and `data-part`.
- State styling uses `data-state="open" | "closed"`, `data-focus`, `data-invalid`,
  `data-disabled`, `data-readonly`, `data-required`, `data-placeholder-shown`, `data-highlighted`,
  and item `data-state="checked" | "unchecked"`.
- `SelectPositioner` exposes `--reference-width`, `--reference-height`, `--available-width`,
  `--available-height`, `--x`, `--y`, `--z-index`, and `--transform-origin`.
