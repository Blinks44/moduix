keyboard flow, and mobile OTP autofill. Submit fewer than six digits to see the inline field error.

## Use in a route

Render `VerificationCode` after your application sends the email code and pass its real submit
handler. `onSubmit` receives the native form event, so read `new FormData(event.currentTarget)`
and verify the `code` value with your server. Replace the default `/sign-in` link with your
application route.

The preview intentionally has no verification server. After six digits it runs its empty submit
handler; the copied recipe runs the handler you provide instead.

Disable duplicate verification while the request is pending. For an invalid code, keep the entered
digits available and attach the error to the field; for an expired code, explain that a new code is
required. Put resend behind a short cooldown, announce when a new code is sent, and let the server
enforce the real rate limit. Never treat the client countdown as authorization.
