## Choosing the right component

Use `AngleSlider` when users need to set a direction or rotation on a circular dial.

- Choose **`AngleSlider`** for rotation, heading, spotlight direction, and other angular values.
- Choose **`Slider`** when the value is easier to understand on a linear scale.
- Choose **`NumberInput`** when entering an exact degree value matters more than direct manipulation.

fills from the top as the angle grows. `AngleSlider` accepts one angle

`aria-label` to the root.

## Anatomy

```text
AngleSlider
├─ AngleSliderLabel
├─ AngleSliderDial
│  ├─ AngleSliderValueText
│  └─ AngleSliderThumb
├─ AngleSliderMarks (optional)
│  └─ AngleSliderMarker[value]
└─ AngleSliderHiddenInput (explicit)

AngleSliderRootProvider
└─ same part tree connected to a useAngleSlider() store
```

| Part                               | Role                                                                  |
| ---------------------------------- | --------------------------------------------------------------------- |
| `AngleSlider` | Styled root that owns controlled or uncontrolled slider state.        |
| `AngleSliderRootProvider`         | Connects the parts to state created with `useAngleSlider()`.          |
| `AngleSliderLabel`                | Associates a visible label with the slider.                           |
| `AngleSliderControl`              | Provides the circular pointer interaction area.                       |
| `AngleSliderDial`                 | Convenience composition of `Control`, the centered `ValueText`, and `Thumb`. |
| `AngleSliderThumb`                | Focusable circular handle that rides the track at the current angle.  |
| `AngleSliderMarkerGroup`          | Contains optional reference markers.                                  |
| `AngleSliderMarker`               | Places a numeric marker around the dial.                               |
| `AngleSliderMarks`                | Convenience composition that creates markers from a `values` array.    |
| `AngleSliderValueText`             | Displays the current value in degrees; `AngleSliderDial` centers it in the dial. |
| `AngleSliderHiddenInput`           | Native form control; compose it explicitly when submitting the value. |

## Composition

Use `defaultValue` for an uncontrolled slider and `value` with `onValueChange(details)` when
another part of the application owns the angle. Use `AngleSliderRootProvider` with
`useAngleSlider()` from the matching framework package only when the store must be created outside
the rendered slider tree; do not render the root and `AngleSliderRootProvider` for the same
state instance. In
Solid, read the provider store through its accessor, for example `angleSlider().value`.

`AngleSliderDial` and `AngleSliderMarks` are convenience compositions. Use `AngleSliderControl` with
`AngleSliderThumb`, or `AngleSliderMarkerGroup` with `AngleSliderMarker`, when you need custom
children, a different order, or per-marker props.
Compose `AngleSliderHiddenInput` explicitly for native forms. Set `name` on the root for a form in the same
tree, or set `form` on `AngleSliderHiddenInput` when the form is elsewhere.

## Styling

Use `className` in React or `class` in Solid and Vue on exported parts for structural styles. For state-based
styles, prefer Ark data attributes such as `data-state`, `data-disabled`, `data-invalid`, and
`data-readonly`, together with moduix `data-slot` selectors. Tailwind variants use native utilities
and consumer classes; the component variables below customize the CSS Modules variants. Ark runtime
variables and the listed data hooks remain available in both styling tracks.

### CSS Properties

### Styling hooks

- Stable `data-slot` selectors include `angle-slider-root`, `angle-slider-root-provider`,
  `angle-slider-label`, `angle-slider-control`, `angle-slider-thumb`, `angle-slider-marker-group`,
  `angle-slider-marker`, and `angle-slider-value-text`.
- Ark part selectors use `data-scope="angle-slider"` and `data-part`.
- `AngleSliderMarks` renders the same marker hooks as the explicit `AngleSliderMarkerGroup` and `AngleSliderMarker`
  parts.
- Root variables `--value` and `--angle`, and marker variables `--marker-value` and
  `--marker-display-value`, remain available for styling.
- Thumb motion is removed when the user prefers reduced motion.
