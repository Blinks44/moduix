# React Hook Form

[React Hook Form](https://react-hook-form.com/get-started) is a React-only form library. This guide
connects it to the React Moduix adapter without implying support for Solid, Vue, or Svelte.

## Framework support

<PackageManagerTabs command="install react-hook-form" />

Use this integration only with `@moduix/react` or `@moduix/react-tailwind`. For Solid, use a native
form, [Formisch](/docs/formisch), or [TanStack Form](/docs/tanstack-form).

## Connect controls

Use `register` for native inputs and `Controller` for compound controls whose value is exposed through
props and callback detail objects.

| Moduix control                          | React Hook Form mapping                                  |
| --------------------------------------- | -------------------------------------------------------- |
| `Input`, `Textarea`, native selects     | Spread `register(name, rules)` onto the control.         |
| `Select`, `Combobox`                    | Use `Controller` and map the scalar value to `string[]`. |
| `Checkbox`                              | Map `details.checked === true` to a boolean.             |
| Other controlled compound controls      | Use `Controller` and map their public value contract.    |

Give every controlled field a value in `defaultValues`. Keep each Moduix native form part in the
composition and do not register a second hidden input for the same value.

## Validation and reset

Use `rules` for local field validation and a resolver for schema or cross-field rules. Pass
`fieldState.invalid` to `Field`, and render `fieldState.error?.message` with `FieldErrorText`.

Add `noValidate` only when React Hook Form owns the visible error flow. Call its `reset()` API for
controlled fields so the library state and Moduix values reset together.

## Repeated fields and server errors

Use `useFieldArray` for editable lists. Render rows with the stable `field.id`, keep the current index
only in the registered path, and use `Fieldset` for the shared legend and group message.

Use `setError(name, ...)` for a server error tied to one field and the `root` namespace for a
form-level failure. Keep entered values visible after the request fails.

## Focus and behavior

- Forward `field.ref` to `Select.Trigger` or `ComboboxInput` so invalid-submit focus reaches the
  visible control.
- Call `field.onBlur` when a compound interaction ends so touched state stays accurate.
- Map Ark detail objects explicitly instead of spreading a `Controller` field onto a compound root.
- Use `formState.isSubmitting` for pending UI and block duplicate requests.
