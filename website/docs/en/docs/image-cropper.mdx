## Usage

<Usage />

Use `ImageCropper` with `ImageCropperViewport`, `ImageCropperImage`, and `ImageCropperCropArea`.
Pass the image URL to `ImageCropperImage`. `ImageCropperCropArea` adds the selection, grid lines,
and resize handles for you.

## Examples

### Aspect ratio

Set `aspectRatio` to keep the selection at a fixed width-to-height ratio. Change it from React state
when users choose an output format.

<Example name="image-cropper/aspect-ratio" />

### Circle crop

Use `cropShape="circle"` with `aspectRatio={1}` for avatars and profile images.

<Example name="image-cropper/circle-crop" />

### Initial crop

Set `initialCrop` to open the cropper with a predefined crop rectangle in viewport coordinates and
pixels.

<Example name="image-cropper/initial-crop" />

### Fixed crop area

Set `fixedCropArea` when the crop area must keep the same size and position while users pan the image
behind it.

<Example name="image-cropper/fixed-crop-area" />

### Min and max size

Constrain the selection with `minWidth`, `minHeight`, `maxWidth`, and `maxHeight`.

<Example name="image-cropper/min-and-max-size" />

### Rotation, flip, and reset

Use `ImageCropperContext` to connect toolbar actions for zooming, rotating, flipping, and resetting
the cropper. The example keeps rotation and flip state controlled.

<Example name="image-cropper/rotation-flip-and-reset" />

### Crop preview

Call `getCroppedImage()` on a `useImageCropper` instance to create a rendered result. With
`{ output: 'dataUrl' }`, the method returns a data URL that you can use as an `img` source. Use
`getCropData()` when you only need the crop coordinates and transform data.

<Example name="image-cropper/crop-preview" />

### Controlled zoom

Use controlled `zoom` with `onZoomChange` when buttons or another part of the UI needs to change or
display the current zoom. Set `minZoom` and `maxZoom` to constrain the range. See [Control state from the application](/docs/composition-patterns#controlled-state).

<Example name="image-cropper/controlled-zoom" />

### Events

Subscribe to `onCropChange` and `onZoomChange` to display the current crop data or synchronize it
with other UI.

<Example name="image-cropper/events" />

### Root provider

Use `ImageCropperRootProvider` with a `useImageCropper` instance when a toolbar or workflow needs to
control the cropper from outside its component tree. See [Share state outside the tree](/docs/composition-patterns#root-provider).

<Example name="image-cropper/root-provider" />

### Build from parts

The same cropper as Basic, without `ImageCropperCropArea`: `ImageCropperSelection` holds two
`ImageCropperGrid` lines with an `axis` and one `ImageCropperHandle` per `position` from
`ImageCropperHandles`. Start here when the crop area needs fewer handles or custom children.

## Composition

Use `ImageCropperCropArea` for the standard selection. It renders the two grids and all resize handles,
so do not pass `children` or `asChild`. Use `className`, `gridClassName`, and `handleClassName` to
style the selection and its generated parts.

Use `ImageCropperContext` for controls inside the root. Create `useImageCropper()` and pass it to
`ImageCropperRootProvider` when a toolbar, preview, or form logic needs the cropper instance outside
the component tree. For one state instance, render either `ImageCropper` or
`ImageCropperRootProvider`.

Use controlled `zoom`, `rotation`, or `flip` with the matching change callback when another part of
the application controls that state. Ark passes the updated value in the callback's `details` object. The Vue and Svelte examples use native SFC syntax with the same parts, events, and controlled state. In Svelte, bind `zoom`, `rotation`, and `flip` with `bind:`, and pass `onCropChange` and `onZoomChange` as props.
`fixedCropArea` keeps the selection fixed and makes the viewport the panning surface.

## Styling

The root is 32rem wide and shrinks with its container. The viewport keeps an 8:5 ratio and shows a
checkerboard where the image does not cover it. The image keeps its own ratio: it shrinks to fit the
viewport and stays centered, so the crop always matches the visible pixels.

Use `className` in React or `class` in Solid, Vue, and Svelte on exported parts. Tailwind variants use native
utilities and consumer classes. CSS Modules variants build on foundation tokens and have no component
variables: a class on the part overrides the layered component styles, for example a different
viewport `aspect-ratio` or `height`. Data attributes and `data-slot` hooks are shared by both styling
tracks.

### Styling hooks

| Part | `data-slot` |
| --- | --- |
| `ImageCropper` | `image-cropper-root` |
| `ImageCropperRootProvider` | `image-cropper-root-provider` |
| `ImageCropperViewport` | `image-cropper-viewport` |
| `ImageCropperImage` | `image-cropper-image` |
| `ImageCropperSelection` | `image-cropper-selection` |
| `ImageCropperGrid` | `image-cropper-grid` |
| `ImageCropperHandle` | `image-cropper-handle` |

- Ark state selectors: `data-flip-horizontal` and `data-flip-vertical` on `ImageCropperImage`.

Ark also exposes `data-scope="image-cropper"`,
`data-part`, and state attributes such as `data-fixed`, `data-shape`, `data-pinch`, `data-ready`,
`data-disabled`, `data-measured`, `data-dragging`, `data-panning`, `data-axis`, and `data-position`
on the relevant parts.

Ark writes `--crop-width`, `--crop-height`, `--crop-x`, `--crop-y`, `--image-zoom`,
`--image-rotation`, `--image-offset-x`, and `--image-offset-y` on the root. These are read-only
runtime values for synchronizing custom UI. Do not override them.

## Keyboard

| Key | Action |
| --- | --- |
| `ArrowUp` / `ArrowDown` / `ArrowLeft` / `ArrowRight` | Moves the crop area; Shift and Ctrl take larger steps. |
| `Alt` + arrows | Resizes the crop area. |
| `+` / `-` | Zooms in or out. |

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `aspectRatio` | `number` | — | Locks the crop to a width-to-height ratio. |
| `cropShape` | `'rectangle' \| 'circle'` | `'rectangle'` | Crop area shape: `rectangle` or `circle`. |
| `initialCrop` | `Rect` | — | Initial crop rectangle. |
| `fixedCropArea` | `boolean` | `false` | Keeps the crop area fixed; the image pans and zooms under it. |
| `minWidth` | `number` | `40` | Minimum crop width in pixels. |
| `minHeight` | `number` | `40` | Minimum crop height in pixels. |
| `maxWidth` | `number` | `Infinity` | Maximum crop width in pixels. |
| `maxHeight` | `number` | `Infinity` | Maximum crop height in pixels. |
| `zoom` | `number` | — | Zoom level for controlled use. |
| `defaultZoom` | `number` | `1` | Initial zoom when it is not controlled. |
| `minZoom` | `number` | `1` | Smallest allowed zoom. |
| `maxZoom` | `number` | `5` | Largest allowed zoom. |
| `zoomStep` | `number` | `0.1` | Zoom change per wheel step. |
| `rotation` | `number` | — | Rotation in degrees for controlled use. |
| `defaultRotation` | `number` | `0` | Initial rotation in degrees. |
| `flip` | `{ horizontal: boolean; vertical: boolean }` | — | Horizontal and vertical flip for controlled use. |
| `onCropChange` | `(details: CropChangeDetails) => void` | — | Called with the crop rectangle as it changes. |
| `onZoomChange` | `(details: ZoomChangeDetails) => void` | — | Called when the zoom changes. |
| `onRotationChange` | `(details: RotationChangeDetails) => void` | — | Called when the rotation changes. |
| `translations` | `IntlTranslations` | — | Localized strings for accessibility labels. |
| `defaultFlip` | `FlipState` | `{ horizontal: false, vertical: false }` | Initial flip state. |
| `zoomSensitivity` | `number` | `2` | How strongly pinch gestures zoom. |
| `nudgeStep` | `number` | `1` | Arrow-key move step in pixels. |
| `nudgeStepShift` | `number` | `10` | Arrow-key step with Shift held, in pixels. |
| `nudgeStepCtrl` | `number` | `50` | Arrow-key step with Ctrl or Cmd held, in pixels. |
| `onFlipChange` | `(details: FlipChangeDetails) => void` | — | Called when the flip state changes. |
