## Usage

<UsageCode
  react={'<ImageCropper aspectRatio={1} cropShape="circle" onCropChange={(details) => setCrop(details.crop)}>\n  <ImageCropperViewport>\n    <ImageCropperImage src={photo} alt="Profile photo" crossOrigin="anonymous" />\n    <ImageCropperCropArea />\n  </ImageCropperViewport>\n</ImageCropper>'}

<PropChips
  items={[

Use `ImageCropper` with `ImageCropperViewport`, `ImageCropperImage`, and `ImageCropperCropArea`.
Pass the image URL to `ImageCropperImage`. `ImageCropperCropArea` adds the selection, grid lines,
and resize handles for you.

`getCropData()` when you only need the crop coordinates and transform data.

### Controlled zoom

Use controlled `zoom` with `onZoomChange` when buttons or another part of the UI needs to change or

<Example name="image-cropper/controlled-zoom" />

### Events

Subscribe to `onCropChange` and `onZoomChange` to display the current crop data or synchronize it
with other UI.

<Example name="image-cropper/events" />

### Root provider

Use `ImageCropperRootProvider` with a `useImageCropper` instance when a toolbar or workflow needs to

## Composition

Use `ImageCropperCropArea` for the standard selection. It renders the two grids and all resize handles,
so do not pass `children` or `asChild`. Use `className`, `gridClassName`, and `handleClassName` to
style the selection and its generated parts.

Use `ImageCropperContext` for controls inside the root. Create `useImageCropper()` and pass it to
`ImageCropperRootProvider` when a toolbar, preview, or form logic needs the cropper instance outside
the component tree. For one state instance, render either `ImageCropper` or
`ImageCropperRootProvider`.

Use controlled `zoom`, `rotation`, or `flip` with the matching change callback when another part of
the application controls that state. Ark passes the updated value in the callback's `details` object. The Vue examples use native SFC syntax with the same parts, events, and controlled state.
`fixedCropArea` keeps the selection fixed and makes the viewport the panning surface.

## Styling

The root is 32rem wide and shrinks with its container. The viewport keeps an 8:5 ratio and shows a
checkerboard where the image does not cover it. The image keeps its own ratio: it shrinks to fit the
viewport and stays centered, so the crop always matches the visible pixels.

Use `className` in React or `class` in Solid and Vue on exported parts. Tailwind variants use native
utilities and consumer classes. CSS Modules variants build on foundation tokens and have no component
variables: a class on the part overrides the layered component styles, for example a different
viewport `aspect-ratio` or `height`. Data attributes and `data-slot` hooks are shared by both styling
tracks.

### Styling hooks

| Part | `data-slot` |
| --- | --- |
| `ImageCropper` | `image-cropper-root` |
| `ImageCropperRootProvider` | `image-cropper-root-provider` |
| `ImageCropperViewport` | `image-cropper-viewport` |
| `ImageCropperImage` | `image-cropper-image` |
| `ImageCropperSelection` | `image-cropper-selection` |
| `ImageCropperGrid` | `image-cropper-grid` |
| `ImageCropperHandle` | `image-cropper-handle` |

- Ark state selectors: `data-flip-horizontal` and `data-flip-vertical` on `ImageCropperImage`.

Ark also exposes `data-scope="image-cropper"`,
`data-part`, and state attributes such as `data-fixed`, `data-shape`, `data-pinch`, `data-ready`,
`data-disabled`, `data-measured`, `data-dragging`, `data-panning`, `data-axis`, and `data-position`
on the relevant parts.

Ark writes `--crop-width`, `--crop-height`, `--crop-x`, `--crop-y`, `--image-zoom`,
`--image-rotation`, `--image-offset-x`, and `--image-offset-y` on the root. These are read-only
runtime values for synchronizing custom UI. Do not override them.

## Keyboard

| Key | Action |
| --- | --- |
| `ArrowUp` / `ArrowDown` / `ArrowLeft` / `ArrowRight` | Moves the crop area; Shift and Ctrl take larger steps. |
| `Alt` + arrows | Resizes the crop area. |
| `+` / `-` | Zooms in or out. |
