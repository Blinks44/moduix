## Anatomy

```tsx
<ImageCropper>
  <ImageCropper.Viewport>
    <ImageCropper.Image />
    <ImageCropper.CropArea />
  </ImageCropper.Viewport>
</ImageCropper>
```

| Part                                 | Role                                                                                 |
| ------------------------------------ | ------------------------------------------------------------------------------------ |
| `ImageCropper` / `ImageCropper.Root` | Root component that owns crop and transform state, ARIA attributes, and runtime CSS variables. |
| `ImageCropper.RootProvider`          | Root connected to a `useImageCropper` instance created outside the component tree.   |
| `ImageCropper.Viewport`              | Viewport that clips overflow and provides the surface for panning the image.         |
| `ImageCropper.Image`                 | Image element that Ark transforms as the user edits the crop.                        |
| `ImageCropper.Selection`             | Focusable crop area and keyboard target. It is removed from the tab order when `fixedCropArea` is enabled. |
| `ImageCropper.Grid`                  | Non-interactive horizontal or vertical crop guide. Requires `axis`.                  |
| `ImageCropper.Handle`                | Resize handle for a position from `ImageCropper.handles`. Requires `position`.       |
| `ImageCropper.CropArea`              | Ready-made selection with both grids and every resize handle. It does not accept `children` or `asChild`. |

## Composition

### Recommended composition

Use `ImageCropper.CropArea` for the usual cropper. It renders both grid directions and all resize
handles, so you do not need to repeat that markup. Pass `className`, `gridClassName`, or
`handleClassName` to style the corresponding parts. `CropArea` owns its child structure, so do not
pass `children` or `asChild` to it.

### When to go custom

Use `ImageCropper.Context` or `useImageCropperContext` for controls rendered inside the cropper
root. Use `useImageCropper` with `ImageCropper.RootProvider` when a toolbar, preview, or form logic
needs the cropper instance outside the component tree. Render only one of `Root` and `RootProvider`
for each state instance.

### Default props

| Prop                     | Default                                  | Notes                                                        |
| ------------------------ | ---------------------------------------- | ------------------------------------------------------------ |
| `aspectRatio`            | not set                                  | The crop area can be resized freely.                        |
| `cropShape`              | `"rectangle"`                            | Use `"circle"` for avatar crops.                            |
| `initialCrop`            | computed                                 | Ark computes an initial area from the viewport and aspect ratio. |
| `defaultZoom`            | `1`                                      | Initial image zoom.                                          |
| `defaultRotation`        | `0`                                      | Initial image rotation in degrees.                           |
| `defaultFlip`             | `{ horizontal: false, vertical: false }` | Initial horizontal and vertical flip state.                  |
| `minZoom`                | `1`                                      | Minimum zoom factor.                                         |
| `maxZoom`                | `5`                                      | Maximum zoom factor.                                         |
| `minWidth` / `minHeight` | `40`                                     | Minimum crop area size in pixels.                            |
| `maxWidth` / `maxHeight` | `Infinity`                               | Maximum crop area size in pixels.                            |
| `nudgeStep`              | `1`                                      | Arrow-key movement step in pixels.                           |
| `nudgeStepShift`         | `10`                                     | Movement step when `Shift` is held.                          |
| `nudgeStepCtrl`          | `50`                                     | Movement step when `Ctrl` or `Cmd` is held.                  |
| `fixedCropArea`          | `false`                                  | Keeps the crop area's size and position fixed.               |

### Behavioral notes

The cropper starts measuring the selection after the image has loaded. Drag the handles to resize
the selection and drag the image in the viewport to pan it. Arrow keys move the selection, `Alt` plus
an arrow key resizes it, `Shift` and `Ctrl`/`Cmd` use the corresponding nudge-step props, and `+` / `-`
change the zoom. When `fixedCropArea` is enabled, the selection stays fixed and the viewport becomes
the panning surface; the selection is removed from the tab order.

The root has `role="group"`, and the selection uses `role="slider"` when it is interactive. Give
the root an accessible name with `aria-label` or configure the Ark `translations` prop. In controlled
mode, `onCropChange`, `onZoomChange`, `onRotationChange`, and `onFlipChange` receive Ark detail
objects, such as `details.crop`, `details.zoom`, `details.rotation`, and `details.flip`.

### Styling hooks

Use the stable `data-slot` hooks `image-cropper-root`, `image-cropper-root-provider`,
`image-cropper-viewport`, `image-cropper-image`, `image-cropper-selection`, `image-cropper-grid`,
and `image-cropper-handle` for local styling. Ark also exposes `data-scope="image-cropper"`,
`data-part`, and state attributes such as `data-fixed`, `data-shape`, `data-pinch`, `data-ready`,
`data-disabled`, `data-measured`, `data-dragging`, `data-panning`, `data-axis`, and `data-position`
on the relevant parts.

Ark writes `--crop-width`, `--crop-height`, `--crop-x`, `--crop-y`, `--image-zoom`,
`--image-rotation`, `--image-offset-x`, and `--image-offset-y` on the root. These are read-only
runtime values for synchronizing custom UI. Do not override them. Use the documented
`--moduix-image-cropper-*` properties for visual customization.
