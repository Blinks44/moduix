## Anatomy

```text
Avatar.Root | Avatar.RootProvider
├─ Avatar.Fallback
└─ Avatar.Image
```

| Part                     | Role                                                              |
| ------------------------ | ----------------------------------------------------------------- |
| `Avatar` / `Avatar.Root` | Creates and owns the Ark UI avatar state.                         |
| `Avatar.RootProvider`    | Renders an avatar from Ark UI state created outside the component. |
| `Avatar.Fallback`        | Shows consumer-provided content until the image loads.             |
| `Avatar.Image`           | Shows the image after it loads successfully.                     |

## Composition

Keep `Avatar.Fallback` and `Avatar.Image` under the same root so Ark can switch their visibility.
When another part of the application owns the state, create it with `useAvatar()` from the matching
framework package and pass it directly to `Avatar.RootProvider`; do not render another root for the
same store. React receives the store as an object, while Solid receives a reactive accessor. For a
custom image renderer, use `useAvatarContext()` and preserve the hidden and visible states returned
by `getImageProps()`. Use `asChild` with one semantic child when another element must own the root
DOM node.

## Styling

Use `className` in React or `class` in Solid on exported parts for structural styles. Tailwind
variants use native utility classes and consumer classes; the CSS Variables reference below applies
to CSS Modules variants. For state-based styles, prefer Ark data attributes together with moduix
`data-slot` selectors.

### CSS Properties

<CssPropertiesSection properties={AvatarDocs.avatarCssProperties} />

### Styling hooks

- `data-slot="avatar-root"`, `avatar-root-provider`, `avatar-image`, and `avatar-fallback`.
- Ark anatomy hooks: `data-scope="avatar"` and
  `data-part="root" | "image" | "fallback"`.
- Ark image state: `data-state="visible" | "hidden"` on `Avatar.Image` and
  `Avatar.Fallback`.
- moduix size state: `data-size="xs" | "sm" | "md" | "lg" | "xl"` on
  `Avatar.Root` and `Avatar.RootProvider` when `size` is provided.
