## Usage

<Usage />

Compose a checkbox from Ark's parts. Leave `CheckboxControl` empty to use moduix's built-in checked
and indeterminate icons. Add `CheckboxLabel` for the visible text and `CheckboxHiddenInput` for
native interaction and form behavior.

## Choosing the right component

Use `Checkbox` when people need to select one or more independent options in a form, settings panel,
or filter list. Use `RadioGroup` when only one option can be selected. Use `Switch` when a setting
should take effect immediately.

## Composition

`CheckboxHiddenInput` is Ark's native input. Render it explicitly inside `Checkbox` or
`CheckboxRootProvider`, even outside a form: it handles native focus, keyboard interaction,
accessibility, and form participation. Put `name` and `value` on the root for a standalone field;
for a group, put `name` on `CheckboxGroup` and `value` on each `Checkbox`.

`CheckboxGroup` holds an array of selected values, and each child is a `Checkbox` with its own
`value`. Leave `CheckboxControl` empty for moduix's built-in icons. Add `CheckboxIndicator` inside
`CheckboxControl` only for a custom indicator.

When state must be created outside the rendered tree, create it with `useCheckbox()` and pass the
store to `CheckboxRootProvider`. Do not render `Checkbox` or `CheckboxRootProvider` for the same store.

## Styling

Use `className` in React or `class` in Solid, Vue, and Svelte on exported parts for structural styles. For state-based
styles, prefer Ark data attributes such as `data-state`, `data-disabled`, and `data-invalid`,
together with moduix `data-slot` selectors. Tailwind variants use native utilities and consumer
classes; the variables below customize the CSS Modules variants. Data attributes and `data-slot`
hooks are shared by both styling tracks.

### Styling hooks

| Part | `data-slot` |
| --- | --- |
| `Checkbox` | `checkbox-root` |
| `CheckboxRootProvider` | `checkbox-root-provider` |
| `CheckboxIndicator` | `checkbox-indicator` |
| `CheckboxControl` | `checkbox-control` |
| `CheckboxLabel` | `checkbox-label` |
| `CheckboxGroup` | `checkbox-group` |

- `Checkbox` exposes `data-slot="checkbox-root"`, `data-size`, and Ark state attributes such as `data-state`, `data-active`, `data-disabled`, `data-readonly`, `data-invalid`, `data-required`, `data-hover`, `data-focus`, and `data-focus-visible`.
- `CheckboxControl` exposes `data-slot="checkbox-control"` and Ark state attributes including `data-state="checked" | "indeterminate" | "unchecked"` and `data-active`.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `checked` | `boolean \| 'indeterminate'` | — | Checked state for controlled use; `indeterminate` shows a dash. |
| `defaultChecked` | `boolean \| 'indeterminate'` | `false` | Initial checked state when it is not controlled. |
| `onCheckedChange` | `(details: CheckedChangeDetails) => void` | — | Called when the checked state changes. |
| `value` | `string` | `'on'` | Value submitted with the form when checked. |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | Checkbox size: `xs`, `sm`, `md`, `lg`, or `xl`. |
| `name` | `string` | — | Form field name of the underlying input. |
| `disabled` | `boolean` | `false` | Disables the control. |
| `readOnly` | `boolean` | `false` | Shows the value but prevents changes. |
| `invalid` | `boolean` | `false` | Marks the control as invalid. |
| `required` | `boolean` | `false` | Requires a value before form submission. |
| `form` | `string` | — | Id of the form the underlying input belongs to. |
