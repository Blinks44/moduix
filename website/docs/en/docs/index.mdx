# moduix

moduix is a library of accessible components for React, Solid, Vue, and Svelte. [Ark UI](https://ark-ui.com/)
handles keyboard interaction, focus, and ARIA semantics; moduix adds styles, design tokens, and
ready-made compositions. Each package uses the props, events, and reactivity of its framework.

To render your first component, go to [Quick start](/docs/quick-start).

## How moduix is built

| Layer | Provided by | What you can change |
| ----- | ----------- | ------------------- |
| Behavior | Ark UI | Compose named parts, control state, use `asChild`, Ark providers, and context hooks. |
| Styles | CSS Modules or Tailwind CSS | Override `--moduix-*` tokens, add classes, or target `data-slot` attributes. |
| Source | npm package or shadcn registry | Update through your package manager, or edit the copied source in your app. |

## Choose your setup

Each choice is independent of the others. [Quick start](/docs/quick-start) covers every combination.

| Choice | Options | When to pick it |
| ------ | ------- | --------------- |
| Framework | React, Solid, Vue, Svelte | The framework your app already uses. Components and parts have the same names in every framework. |
| Styling | CSS Modules, Tailwind CSS | CSS Modules when your app does not use Tailwind; Tailwind CSS v4 when it styles with utilities. |
| Installation | Package, shadcn CLI | A package to update through your package manager; the shadcn CLI to copy the source and edit it. |

Packages are named `@moduix/<framework>` and `@moduix/<framework>-tailwind`, for example
`@moduix/vue-tailwind`. A package and its registry expose the same API.

## Supported versions

The package peer dependencies define the supported ranges:

| Technology | Supported versions | Used by |
| ---------- | ------------------ | ------- |
| React and React DOM | 18 and 19 | `@moduix/react`, `@moduix/react-tailwind` |
| Solid | 1.9 and later 1.x releases | `@moduix/solid`, `@moduix/solid-tailwind` |
| Vue | 3.5 and later 3.x releases | `@moduix/vue`, `@moduix/vue-tailwind` |
| Svelte | 5.29 and later 5.x releases | `@moduix/svelte`, `@moduix/svelte-tailwind` |
| Tailwind CSS | 4.x | Tailwind packages and registries only |
| Ark UI | `^5.40.0` for React, Solid, and Vue; `^5.25.1` for Svelte | The matching React, Solid, Vue, or Svelte package |

Your package manager checks these ranges during installation. CSS Modules packages do not require
Tailwind CSS.

## Styling

Both styling options share semantic colors, tokens, animations, and component behavior. Import
`style.css` once for the tokens and base styles, then:

- pass `className` in React or `class` in Solid, Vue, and Svelte to any root or part;
- target `data-slot` and Ark state attributes such as `data-state` for state-specific rules;
- override `--moduix-*` tokens to theme the whole library.

CSS Modules packages also expose `--moduix-<component>-*` variables, such as `--moduix-button-*`, to
change one component. Tailwind packages use utility classes instead. See [Tokens](/docs/tokens) for
the token hierarchy, [Themes](/docs/themes) for ready-made presets, and [Styling](/docs/styling) for
overrides.
