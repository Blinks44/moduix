## API Reference

Ark UI does not provide a dedicated `Text` component. moduix provides this typography component
with the official [Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) and follows Ark's
[composition](https://ark-ui.com/docs/guides/composition), [styling](https://ark-ui.com/docs/guides/styling), and
[ref](https://ark-ui.com/docs/guides/ref) guidance.

## Choosing the right component

Use `Text` for body copy, helper text, inline emphasis, and other supporting UI text that belongs
on moduix's typography scale.

- Choose **`Heading`** for document structure and heading hierarchy.
- Choose **`Text`** when content should keep paragraph or inline semantics while using body-text styles.
- Use local CSS when the concern is rich text layout, spacing, or disclosure around clamped text.

## Anatomy

`Text` renders a single root element using Ark's factory through the flat root export.

```text
Text
└─ text or inline content
```

| Part                 | Role                                                             |
| -------------------- | ---------------------------------------------------------------- |
| `Text`              | Typography root with semantic HTML and stable data attributes. |

## Composition

`Text` is root-only and owns no state or child parts. Use `<Text>` for the root,
`as` for a supported semantic element, and `asChild` only when one existing element should receive
the text props and ref. Truncation only constrains rendering, so disclosure state and its control stay
in the surrounding UI.

## Styling

Use `className` in React or `class` in Solid and Vue on `Text`. Tailwind variants use native
utilities and consumer classes. CSS Modules variants build on foundation typography tokens and have no
component variables: a class on the root overrides the layered component styles.

### Styling hooks

- `data-scope="text"` and `data-part="root"` identify the Ark-style root.
- `data-slot="text-root"` is the stable moduix selector on the exported root.
- `data-size` reflects the resolved visual size: `xs`, `sm`, `md`, `lg`, or `xl`.
- `data-weight` reflects the resolved weight preset: `regular`, `medium`, `semibold`, or `bold`.
- `data-tone` reflects the active tone preset: `default`, `muted`, `primary`, or
  `destructive`.
- `data-align` appears only when `align` is set to `start`, `center`, `end`, `left`, `right`, or
  `justify`. Without it, `Text` inherits the alignment of its container.
- `data-truncate` appears when single-line ellipsis is active.
- `data-line-clamp` appears when `lineClamp` is a positive integer; the line count is set inline as
  `-webkit-line-clamp`.
