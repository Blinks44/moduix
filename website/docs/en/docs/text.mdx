## API Reference

Ark UI does not provide a dedicated `Text` component. moduix provides this typography component
with the official [Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) and follows Ark's
[composition](https://ark-ui.com/docs/guides/composition), [styling](https://ark-ui.com/docs/guides/styling), and
[ref](https://ark-ui.com/docs/guides/ref) guidance.

## Choosing the right component

Use `Text` for body copy, helper text, inline emphasis, and other supporting UI text that belongs
on moduix's typography scale.

- Choose **`Heading`** for document structure and heading hierarchy.
- Choose **`Text`** when content should keep paragraph or inline semantics while using body-text styles.
- Use local CSS when the concern is rich text layout, spacing, or disclosure around clamped text.

## Anatomy

`Text` renders a single root element using Ark's factory. The short `<Text>` form and `<Text.Root>`
are equivalent.

```text
Text / Text.Root
└─ text or inline content
```

| Part                 | Role                                                             |
| -------------------- | ---------------------------------------------------------------- |
| `Text` / `Text.Root` | Typography root with semantic HTML and stable data attributes. |

## Composition

### Recommended composition

Use the short `<Text>` root for body copy and supporting text. It is equivalent to `<Text.Root>`,
renders a `p` by default, and forwards the ref to the rendered `HTMLElement`.

### When to go custom

Use `as` for supported intrinsic HTML elements when the semantic element should change. Use `asChild`
when an existing element, such as a link, should become the root and receive the moduix class name,
style, data attributes, and ref. The child must be a single element that accepts the forwarded props.

`Text` also accepts standard HTML props for the rendered element, including `className`, `style`,
event handlers, and a forwarded `ref`.

### Default props

| Prop        | Default                       | Notes                                                                  |
| ----------- | ----------------------------- | ---------------------------------------------------------------------- |
| `as`        | `p`                           | `p`, `span`, `small`, `strong`, `em`, or `div`.                        |
| `asChild`   | `false`                       | Uses the single child as the host element.                             |
| `size`      | Element-based                 | `small` defaults to `sm`; other elements default to `md`.              |
| `weight`    | Element-based                 | `strong` defaults to `semibold`; other elements default to `regular`. |
| `tone`      | `default`                     | `default`, `muted`, `subtle`, `primary`, or `destructive`.             |
| `align`     | Not set (visually `start`)    | `start`, `center`, `end`, `left`, `right`, or `justify`.               |
| `truncate`  | `false`                       | Single-line CSS ellipsis.                                              |
| `lineClamp` | Not set                       | Positive integer; invalid values disable clamping.                     |

### Behavioral notes

`Text` handles text presentation and semantics. It does not manage state, keyboard interactions, or
disclosure. `truncate` and `lineClamp` apply visual CSS constraints only. Add a button or another
control separately when users need to reveal the full text.

### Styling hooks

- `data-scope="text"` and `data-part="root"` identify the Ark-style root.
- `data-slot="text-root"` is the stable moduix selector on the exported root.
- `data-size` reflects the resolved visual size: `xs`, `sm`, `md`, `lg`, or `xl`.
- `data-weight` reflects the resolved weight preset: `regular`, `medium`, `semibold`, or `bold`.
- `data-tone` reflects the active tone preset: `default`, `muted`, `subtle`, `primary`, or
  `destructive`.
- `data-align` appears only when `align` is explicitly set to `start`, `center`, `end`, `left`,
  `right`, or `justify`.
- `data-truncate` appears when single-line ellipsis is active.
- `data-line-clamp` appears when `lineClamp` is a positive integer. In that case, `lineClamp` sets
  the fallback line count. Set `--moduix-text-line-clamp` to override it through the public CSS API.
