## Anatomy

```text
Collapsible.Root
├─ Collapsible.Trigger
│  ├─ label
│  └─ Collapsible.Indicator (optional)
└─ Collapsible.Content
   └─ Collapsible.Body
      └─ content
```

| Part                               | Role                                                   |
| ---------------------------------- | ------------------------------------------------------ |
| `Collapsible` / `Collapsible.Root` | Manages the open state, whether controlled or uncontrolled. |
| `Collapsible.RootProvider`         | Provides the parts with state created by `useCollapsible`. |
| `Collapsible.Trigger`              | Accessible button that toggles the content.                 |
| `Collapsible.Indicator`            | Optional state indicator with a moduix chevron by default. |
| `Collapsible.Content`              | Expandable region measured through Ark CSS variables.      |
| `Collapsible.Body`                 | moduix wrapper for padding and content layout.             |

## Composition

### Recommended composition

Use `Collapsible`, `Collapsible.Trigger`, optional `Collapsible.Indicator`,
`Collapsible.Content`, and `Collapsible.Body` to compose the component. Root props include `open`,
`defaultOpen`, `onOpenChange(details)`, `disabled`, `collapsedHeight`, `collapsedWidth`,
`lazyMount`, `unmountOnExit`, `ids`, and `onExitComplete`.

Put padding and surface styles on `Collapsible.Body`, not `Collapsible.Content`. Ark measures the
content and exposes `--height`, `--width`, `--collapsed-height`, and `--collapsed-width`.

When migrating from shadcn, replace `CollapsibleTrigger` with `Collapsible.Trigger` and
`CollapsibleContent` with `Collapsible.Content`. moduix keeps Ark's `details` object, so controlled
state reads `details.open` instead of receiving a boolean directly.

### When to go custom

Use `asChild` when you want another semantic element to render the part. Collapsible adds Ark
behavior and state attributes to that element while leaving its visual styling under your control.

Use moduix `useCollapsible` with `Collapsible.RootProvider` when you need to create the state
outside the component tree. moduix also exports `Collapsible.Context` and
`useCollapsibleContext()`.

`Collapsible.Indicator` is optional. Without children, it renders the moduix down chevron and
accepts custom children when needed.

### Default props

| Part                    | Default          | Notes                                              |
| ----------------------- | ---------------- | -------------------------------------------------- |
| `Collapsible`           | closed           | `defaultOpen={false}`, content mounted by default       |
| `Collapsible.Trigger`   | `button`         | Supports Ark `asChild`                                  |
| `Collapsible.Indicator` | down chevron     | Rotates upward when `data-state="open"`                 |
| `Collapsible.Content`   | collapsed region | Uses Ark measurement variables and render strategy       |
| `Collapsible.Body`      | `div`            | Inner wrapper for padding and gap                        |

### Behavioral notes

- `onOpenChange` receives an Ark `details` object. Read the next state from `details.open`.
- `open` is the target state. `visible` stays true while closing content remains mounted for the
  exit animation.
- Keep nested interactive controls outside `Collapsible.Trigger`.
- Content and indicator animations respect `prefers-reduced-motion`.
- Use `Accordion` when multiple disclosures need coordinated keyboard or value behavior.

## Styling

### CSS Properties

<CssPropertiesSection properties={CollapsibleDocs.collapsibleOverrideCssProperties} />

### Styling hooks

- DOM parts expose `data-slot="collapsible-root"`, `collapsible-root-provider`,
  `collapsible-trigger`, `collapsible-indicator`, `collapsible-content`, and `collapsible-body`.
- Ark exposes `data-state="open" | "closed"` on root, trigger, indicator, and content.
- Ark adds `data-collapsible` to the content part.
- `data-disabled` marks disabled trigger, indicator, and content parts.
- `data-has-collapsed-size` marks content configured with `collapsedHeight` or `collapsedWidth`.
- Content animation uses Ark `--height`, `--width`, `--collapsed-height`, and `--collapsed-width`.
