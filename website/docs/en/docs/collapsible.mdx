## Choosing the right component

Use `Collapsible` for one independent disclosure. Use `Accordion` when several related sections
need shared keyboard navigation or coordinated state.

## Basic

## Anatomy

```text
Collapsible.Root
├─ Collapsible.Trigger
│  ├─ label
│  └─ Collapsible.Indicator (optional)
└─ Collapsible.Content
   └─ Collapsible.Body
      └─ content
```

| Part                               | Role                                                               |
| ---------------------------------- | ------------------------------------------------------------------ |
| `Collapsible` / `Collapsible.Root` | Owns the open state for one disclosure.                            |
| `Collapsible.RootProvider`         | Connects the parts to state created with `useCollapsible`.         |
| `Collapsible.Trigger`              | Accessible button that opens or closes the content.                 |
| `Collapsible.Indicator`            | Optional state indicator that renders a moduix chevron by default. |
| `Collapsible.Content`              | Animated region whose dimensions Ark measures.                     |
| `Collapsible.Body`                 | Inner wrapper for spacing and content layout.                       |

## Composition

### Recommended composition

Start with `Collapsible`, `Collapsible.Trigger`, `Collapsible.Content`, and `Collapsible.Body`.
Add `Collapsible.Indicator` when a visual state cue is useful. Root props include `open`,
`defaultOpen`, `onOpenChange(details)`, `disabled`, `collapsedHeight`, `collapsedWidth`, `hideMode`,
`lazyMount`, `unmountOnExit`, `ids`, and `onExitComplete`.

Put padding and surface styles on `Collapsible.Body`, not `Collapsible.Content`. Ark measures the
content and exposes `--height`, `--width`, `--collapsed-height`, and `--collapsed-width`.

When migrating from shadcn, replace `CollapsibleTrigger` with `Collapsible.Trigger` and
`CollapsibleContent` with `Collapsible.Content`. moduix keeps Ark's `details` object, so controlled
state reads `details.open` instead of receiving a boolean directly.

### When to go custom

Use `asChild` when another semantic element should own the rendered part. The part adds Ark behavior
and state attributes to that element while leaving its visual styling under your control. A custom
trigger should remain keyboard-accessible and behave like a button.

Use `useCollapsible()` from `@moduix/react/collapsible` with `Collapsible.RootProvider` when you
need to create the state outside the rendered component tree. moduix also exports
`Collapsible.Context` and `useCollapsibleContext()`.

`Collapsible.Indicator` is optional. Without children, it renders the moduix down chevron. Pass
custom children when you need a different indicator.

### Default props

| Prop               | Default        | Notes                                                                 |
| ------------------ | -------------- | --------------------------------------------------------------------- |
| `collapsedHeight`  | not set        | Height to keep visible when the content is closed.                    |
| `collapsedWidth`   | not set        | Width to keep visible when the content is closed.                     |
| `defaultOpen`      | `false`        | The disclosure starts closed.                                         |
| `disabled`         | `false`        | The trigger cannot open or close the content.                         |
| `hideMode`         | `display-none` | Uses `hidden` for mounted closed content. `activity` requires React 19. |
| `lazyMount`        | `false`        | Mounts content when it is opened for the first time.                  |
| `open`             | not set        | Controlled state. Use it with `onOpenChange`.                         |
| `unmountOnExit`    | `false`        | Removes content from the DOM after it closes.                         |

### Behavioral notes

- `onOpenChange` receives an Ark `details` object. Read the next state from `details.open`.
- `open` is the target state. `visible` stays true while closing content remains mounted for the
  exit animation.
- The trigger renders as a native button. `Enter` and `Space` open or close the disclosure.
- Keep nested interactive controls outside `Collapsible.Trigger` so the trigger remains a button.
- With `hideMode="activity"`, mounted closed content uses React 19 Activity mode and pauses its
  effects. The default `hideMode="display-none"` uses the `hidden` attribute.
- Content and indicator animations respect `prefers-reduced-motion`.

## Styling

Use `className` on exported parts for structural styles. For state-based styles, prefer Ark data
attributes such as `data-state` and `data-disabled`, together with moduix `data-slot` selectors.

### CSS Properties

<CssPropertiesSection properties={CollapsibleDocs.collapsibleOverrideCssProperties} />

### Styling hooks

- DOM parts expose `data-slot="collapsible-root"`, `collapsible-root-provider`,
  `collapsible-trigger`, `collapsible-indicator`, `collapsible-content`, and `collapsible-body`.
- Ark parts expose `data-scope="collapsible"` and `data-part` values for the root, trigger, indicator,
  and content. `Collapsible.Body` adds `data-part="body"`.
- Ark exposes `data-state="open" | "closed"` on root, trigger, indicator, and content.
- Ark adds `data-collapsible` to the content part.
- `data-disabled` marks disabled trigger, indicator, and content parts.
- `data-has-collapsed-size` marks content configured with `collapsedHeight` or `collapsedWidth`.
- Content animation uses Ark `--height`, `--width`, `--collapsed-height`, and `--collapsed-width`.
