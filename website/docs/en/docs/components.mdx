# Components

moduix provides accessible, composable components across shipped framework adapters with shared CSS tokens. Each
implementation preserves the same public behavior while using its framework's native APIs. Many
interactive components build on Ark UI primitives and keep their composition explicit.

The catalog below is available in every shipped CSS Modules adapter. Tailwind packages include components whose
framework-native style ports are complete and continue expanding toward the same catalog. Choose a
category, then open a component page from the sidebar or search. Each page includes a copyable basic
example, public anatomy, styling hooks, and component-specific guidance when it is useful.

## Before you build

- Use [Quick start](/docs/quick-start) to choose between installing the package and copying source
  files into your project.
- Read [Composition Patterns](/docs/composition-patterns) before wrapping component parts in
  product-specific components.
- Use [Themes](/docs/themes) and [Tokens](/docs/tokens) for system-wide visual changes. Keep
  component aliases for deliberate, local exceptions.
- Start with [Recipes](/recipes) when you need a copyable product pattern built from several
  components.
