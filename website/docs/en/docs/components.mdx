# Components

moduix provides accessible, composable React components with shared CSS tokens. Many interactive
components build on Ark UI primitives while keeping their composition explicit in the public API.
Choose a category below, then open a component page from the sidebar or search. Each page includes a
copyable basic example, the public part structure, behavior notes, and the styling options available
for that component.

## Before you build

- Use [Quick start](/docs/quick-start) to choose between installing the package and copying source
  files into your project.
- Read [Composition Patterns](/docs/composition-patterns) before wrapping component parts in
  product-specific components.
- Use [Themes](/docs/themes) and [Tokens](/docs/tokens) for system-wide visual changes. Keep
  component aliases for deliberate, local exceptions.
- Start with [Recipes](/recipes) when you need a copyable product pattern built from several
  components.
