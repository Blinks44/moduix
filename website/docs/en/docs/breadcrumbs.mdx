[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) and follows Ark's guidance for

[refs](https://ark-ui.com/docs/guides/ref).

## Basic

## Anatomy

`Breadcrumbs` exposes its parts through an Ark-style namespace.

```text
Breadcrumbs / Breadcrumbs.Root
└─ Breadcrumbs.List
   ├─ Breadcrumbs.Item
   │  └─ Breadcrumbs.Link
   ├─ Breadcrumbs.Separator
   └─ Breadcrumbs.Item
      └─ Breadcrumbs.Page
```

| Part                               | Role                                                              |
| ---------------------------------- | ----------------------------------------------------------------- |
| `Breadcrumbs` / `Breadcrumbs.Root` | Root navigation landmark with a default `aria-label`.             |
| `Breadcrumbs.List`                 | Ordered list of breadcrumb segments.                              |
| `Breadcrumbs.Item`                 | List item wrapper for a segment.                                  |
| `Breadcrumbs.Link`                 | Styled anchor for navigable segments; supports `asChild`.         |
| `Breadcrumbs.Page`                 | Current page text with `aria-current="page"`.                     |
| `Breadcrumbs.Separator`            | Visual delimiter hidden from assistive technology.               |
| `Breadcrumbs.Ellipsis`             | Compact marker for a menu trigger that reveals hidden segments.   |

`Breadcrumbs.Path` is a moduix shorthand that builds `Breadcrumbs.List`, `Breadcrumbs.Item`,
`Breadcrumbs.Link`, `Breadcrumbs.Page`, and `Breadcrumbs.Separator` from an `items` array.

## Composition

`Breadcrumbs` owns no interactive or form state, so it has no controlled props, callbacks, context
hooks, or `RootProvider`. State for a collapsed path belongs to the composed `Menu`, while router
navigation remains owned by the app's link component.

Use `Breadcrumbs.Path` for an anchor-based path. It owns the generated list children, makes the last
item the current page, and does not accept `children` or `asChild`. Use the explicit parts when a path
needs router links, hidden middle segments, or different markup. For a router link, pass one semantic
child to `Breadcrumbs.Link asChild` so the link keeps the expected `href`, focus, and keyboard behavior.

For collapsed paths, put `Breadcrumbs.Ellipsis` inside the `Menu.Trigger`, then keep the menu's
`Positioner`, `Content`, and `Item asChild` parts explicit. `Breadcrumbs.Ellipsis` is presentational;
the trigger owns the accessible label and interaction.

## Styling

Use `className` in React or `class` in Solid on exported parts for structural styles. Tailwind variants
use native utility classes and consumer classes; the CSS Variables reference below applies to CSS Modules
variants. For state-based styles, prefer Ark data attributes together with moduix `data-slot` selectors.

### Styling hooks

- `data-slot="breadcrumbs-root"`, `breadcrumbs-list`, `breadcrumbs-item`, `breadcrumbs-link`,
  `breadcrumbs-page`, `breadcrumbs-separator`, and `breadcrumbs-ellipsis` remain stable moduix selectors.
- `Breadcrumbs.Link`, `Breadcrumbs.Page`, and `Breadcrumbs.Ellipsis` share the horizontal padding from
  `--moduix-breadcrumbs-item-padding-x` in CSS Modules variants.
- Visible `Breadcrumbs.Item` parts can shrink to keep the trail in one line. The last visible item
  remains the primary truncation target and uses `--moduix-breadcrumbs-item-max-width` in CSS Modules variants.
