## API Reference

Ark UI does not provide a dedicated breadcrumbs primitive. moduix builds this component with the official
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) and follows Ark's guidance for
[composition](https://ark-ui.com/docs/guides/composition), [styling](https://ark-ui.com/docs/guides/styling), and
[refs](https://ark-ui.com/docs/guides/ref).

## Basic


Use `BreadcrumbsPath` when you already have the path segments to display. It builds the ordered list,
items, links, current page, and separators from required `links` and `page` props.

React and Solid use the same flat value names. Import `Breadcrumbs` as the root and import each
additional part directly, such as `BreadcrumbsPath` and `BreadcrumbsLink`. The same names work
with npm packages and shadcn registry source.

## Anatomy

```text
Breadcrumbs
└─ BreadcrumbsList
   ├─ BreadcrumbsItem
   │  └─ BreadcrumbsLink
   ├─ BreadcrumbsSeparator
   └─ BreadcrumbsItem
      └─ BreadcrumbsPage
```

| Part                  | Role                                                              |
| --------------------- | ----------------------------------------------------------------- |
| `Breadcrumbs`         | Root navigation landmark with a default `aria-label`.             |
| `BreadcrumbsList`     | Ordered list of breadcrumb segments.                              |
| `BreadcrumbsItem`     | List item wrapper for a segment.                                  |
| `BreadcrumbsLink`     | Styled anchor for navigable segments; supports `asChild`.         |
| `BreadcrumbsPage`     | Current page text with `aria-current="page"`.                     |
| `BreadcrumbsSeparator`| Visual delimiter hidden from assistive technology.                |
| `BreadcrumbsEllipsis` | Compact marker for a menu trigger that reveals hidden segments.   |

`BreadcrumbsPath` is a moduix shorthand that builds `BreadcrumbsList`, `BreadcrumbsItem`,
`BreadcrumbsLink`, `BreadcrumbsPage`, and `BreadcrumbsSeparator` from `links` and `page` props.

## Composition

`Breadcrumbs` owns no interactive or form state, so it has no controlled props, callbacks, context
hooks, or `RootProvider`. State for a collapsed path belongs to the composed `Menu`, while router
navigation remains owned by the app's link component.

Use `BreadcrumbsPath` for an anchor-based path. It owns the generated list children, renders every
`links` entry as an anchor, renders `page` as the current page, and does not accept `children` or
`asChild`. Use the explicit parts when a path
needs router links, hidden middle segments, or different markup. For a router link, pass one semantic
child to `BreadcrumbsLink asChild` so the link keeps the expected `href`, focus, and keyboard behavior.
In Solid, assign a ref to the element created inside the `asChild` render function, because a ref on
`BreadcrumbsLink` itself is not forwarded through that composition path.

For collapsed paths, put `BreadcrumbsEllipsis` inside the `Menu.Trigger`, then keep the menu's
`Positioner`, `Content`, and `Item asChild` parts explicit. `BreadcrumbsEllipsis` is presentational;
the trigger owns the accessible label and interaction.

## Styling

Use `className` in React or `class` in Solid on exported parts for structural styles. Tailwind variants
use native utility classes and consumer classes; the CSS Variables reference below applies to CSS Modules
variants. For state-based styles, prefer Ark data attributes together with moduix `data-slot` selectors.

### Styling hooks

- `data-slot="breadcrumbs-root"`, `breadcrumbs-list`, `breadcrumbs-item`, `breadcrumbs-link`,
  `breadcrumbs-page`, `breadcrumbs-separator`, and `breadcrumbs-ellipsis` remain stable moduix selectors.
- `BreadcrumbsLink`, `BreadcrumbsPage`, and `BreadcrumbsEllipsis` share the horizontal padding from
  `--moduix-breadcrumbs-item-padding-x` in CSS Modules variants.
- Visible `BreadcrumbsItem` parts can shrink to keep the trail in one line. The last visible item
  remains the primary truncation target and uses `--moduix-breadcrumbs-item-max-width` in CSS Modules variants.
