[composition](https://ark-ui.com/docs/guides/composition), [styling](https://ark-ui.com/docs/guides/styling), and
[refs](https://ark-ui.com/docs/guides/ref).

## Anatomy

`Breadcrumbs` exposes its parts through an Ark-style namespace.

```text
Breadcrumbs / Breadcrumbs.Root
└─ Breadcrumbs.List
   ├─ Breadcrumbs.Item
   │  └─ Breadcrumbs.Link
   ├─ Breadcrumbs.Separator
   └─ Breadcrumbs.Item
      └─ Breadcrumbs.Page
```

| Part                               | Role                                                              |
| ---------------------------------- | ----------------------------------------------------------------- |
| `Breadcrumbs` / `Breadcrumbs.Root` | Root navigation landmark with a default `aria-label`.             |
| `Breadcrumbs.List`                 | Ordered list of breadcrumb segments.                              |
| `Breadcrumbs.Item`                 | List item wrapper for a segment.                                  |
| `Breadcrumbs.Link`                 | Styled anchor for navigable segments; supports `asChild`.         |
| `Breadcrumbs.Page`                 | Current page text with `aria-current="page"`.                     |
| `Breadcrumbs.Separator`            | Visual delimiter hidden from assistive technology.               |
| `Breadcrumbs.Ellipsis`             | Compact marker for a menu trigger that reveals hidden segments.   |

`Breadcrumbs.Path` is a moduix shorthand that builds `Breadcrumbs.List`, `Breadcrumbs.Item`,
`Breadcrumbs.Link`, `Breadcrumbs.Page`, and `Breadcrumbs.Separator` from an `items` array.

## Composition

### Recommended composition

Use `Breadcrumbs.Path` for simple trails whose ancestor pages are links. The last item becomes the
current page, a chevron appears between items by default, and `separator` replaces it in every visible
gap. The shorthand creates all of its children, so it does not accept `children` or `asChild`. Native
ordered-list props and the ref are forwarded to the generated `Breadcrumbs.List`.

### When to go custom

Use the explicit parts when you need framework router links, hidden middle segments, or different
markup for individual items. Ark `asChild` lets you render a router link in place of
`Breadcrumbs.Link`. Pass a single semantic link as the child so it preserves the expected `href`, focus,
and keyboard behavior.

Pair the breadcrumb parts with `Menu` when middle segments should be hidden behind an ellipsis trigger.
Keep the menu structure explicit: `Menu.Positioner`, `Menu.Content`, and `Menu.Item asChild`. The
`Menu` component provides the portal boundary.

### Default props

| Surface                            | Default | Notes                                                  |
| ---------------------------------- | ------- | ------------------------------------------------------ |
| `Breadcrumbs` / `Breadcrumbs.Root` | None    | No additional behavioral defaults; Ark defaults apply. |
| `Breadcrumbs.Path`                 | chevron | Uses chevrons between items unless `separator` is set. |

### Behavioral notes

- `Breadcrumbs` renders a `nav` landmark with `aria-label="Breadcrumb"` by default.
- `Breadcrumbs.Path` builds an ordered list from `items`; the last item is always the current page.
- Every item except the last renders as a `Breadcrumbs.Link`; provide `href` for items that should be navigable and leave
  the last item without `href`.
- `Breadcrumbs.Path` forwards native ordered-list props and the ref, but its generated children are
  fixed, so it does not support `children` or `asChild`.
- `Breadcrumbs.Separator` is purely presentational and hidden from assistive technology.
- `Breadcrumbs.Ellipsis` is visual-only and hidden from assistive technology; place it inside a `Menu`
  trigger and put the accessible label for the collapsed path on `Menu.Trigger`.
- Visible breadcrumb items can shrink when space is tight. The current page remains the primary
  truncation target through `--moduix-breadcrumbs-item-max-width`.
- Breadcrumbs has no controlled props, callbacks, context hooks, `RootProvider`, ids, `HiddenInput`,
  or form-state integrations because it owns no interactive or form state.

## Styling

Each exported part exposes a stable moduix `data-slot` hook. Public `--moduix-breadcrumbs-*` variables control layout, typography,
the focus ring, separators, and ellipsis sizing.

### CSS Properties

<CssPropertiesSection properties={BreadcrumbsDocs.breadcrumbsCssProperties} />

### Styling hooks

- `data-slot="breadcrumbs-root"`, `breadcrumbs-list`, `breadcrumbs-item`, `breadcrumbs-link`,
  `breadcrumbs-page`, `breadcrumbs-separator`, and `breadcrumbs-ellipsis` remain stable moduix
  selectors.
- `Breadcrumbs.Link`, `Breadcrumbs.Page`, and `Breadcrumbs.Ellipsis` share the horizontal padding from
  `--moduix-breadcrumbs-item-padding-x`.
- Visible `Breadcrumbs.Item` parts can shrink to keep the trail in one line. The last visible item
  remains the primary truncation target and uses `--moduix-breadcrumbs-item-max-width`.
