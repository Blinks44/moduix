## Choosing the right component

Use `ProgressLinear` when users need to follow progress along a bar. Use `ProgressCircular` for a
compact status indicator in a card, toolbar, or other space-constrained surface.

## Basic


Compose the progress bar from the explicit `ProgressLinearLabel`, `ProgressLinearValueText`, `ProgressLinearTrack`, and `ProgressLinearRange` parts. Give
`ProgressLinearTrack` an accessible name that describes the task.
React, Solid, and Vue expose the same flat part names; Vue uses native `class`, slots, and `v-model` where applicable.

## Anatomy

```text
ProgressLinear
├─ ProgressLinearLabel
├─ ProgressLinearValueText
├─ ProgressLinearTrack
│  └─ ProgressLinearRange
└─ ProgressLinearView

ProgressLinearRootProvider
└─ the same part tree connected to useProgress()
```

| Part                                     | Role                                                                       |
| ---------------------------------------- | -------------------------------------------------------------------------- |
| `ProgressLinear` | Owns progress state and passes formatting, IDs, and other props to Ark.    |
| `ProgressLinearRootProvider`             | Connects parts to the store returned by `useProgress()`.    |
| `ProgressLinearContext`                 | Provides the current progress state to a render prop.                     |
| `ProgressLinearLabel`                   | Visible task label. It is not automatically used as `ProgressLinearTrack`'s accessible name. |
| `ProgressLinearValueText`                | Displays the formatted percentage and announces changes. Use `ProgressLinearContext` for custom text. |
| `ProgressLinearTrack`                   | Progressbar surface. Ark adds the role and ARIA value attributes.         |
| `ProgressLinearRange`                   | Filled portion that reflects the current progress.                        |
| `ProgressLinearView`                    | Shows content only when its `state` matches the current progress state.   |

## Composition

Use `defaultValue` for uncontrolled progress. Use `value` with `onValueChange(details)` when your
application owns the current value, and use `defaultValue={null}` or `value={null}` when progress is
unknown. If state is created with `useProgress()`, render the parts inside
`ProgressLinearRootProvider` instead of `ProgressLinear`. Use
`ProgressLinearView` for state-specific content and `ProgressLinearContext` when custom visible text
needs the current state.
In Vue, use `v-model` for the same controlled value.

## Styling

Use `className` in React or `class` in Solid and Vue on exported parts for structural styling. For state-based
styles, use Ark data attributes and moduix `data-slot` hooks. Tailwind variants use native utilities
and consumer classes; the variables below customize the CSS Modules variants.

The root fills the width of its container. In vertical mode, it is as wide as its content and
`12rem` tall. Set `width` or `height` on the root to fit your layout. `--moduix-progress-linear-track-size` sets the bar
thickness in both orientations. Indeterminate progress sweeps a 35% range from the start edge to the
end edge (right to left in RTL); when reduced motion is preferred, the range stays still at the start
edge.
