# Themes

moduix themes are CSS token layers. `Calm` is the default foundation theme; `Dense`, `Soft`, and
`Contrast` are optional presets for different visual directions. A preset can change the palette,
radii, spacing, control density, and shadows without changing component APIs or adding a theme
provider or runtime.

## Choose a preset

| Preset   | Main control / popup row | Good starting point for                                                           |
| -------- | ------------------------ | --------------------------------------------------------------------------------- |
| Calm     | 36px / 32px              | Most product interfaces: a neutral rhythm and quiet surfaces.                     |
| Dense    | 34px / 30px              | Admin and data-heavy tools where more information must fit on screen.             |
| Soft     | 40px / 34px              | Spacious or touch-friendly workflows with rounded surfaces and a warmer accent.  |
| Contrast | 36px / 32px              | Interfaces that benefit from sharper borders and clearer focus separation.         |

The sizes in the table are the default heights for the preset's main controls and popup rows.
The preview uses real moduix components. Use the preset and color mode buttons, then open the
Select and move through its fields with the keyboard to compare control height, popup row height,
labels, surfaces, and focus styles together.

Preset names describe a visual direction, not an accessibility guarantee. Test text contrast,
focus visibility, zoom, and interactive target sizes with your content and application overrides
before release.

## How the layers work

The foundation stylesheet defines the complete token contract and the default `Calm` values. A
preset overrides selected values, and your application can then override only the decisions that
belong to your product. Components read semantic and component-level aliases, so a palette or
density change flows through related controls instead of becoming a collection of one-off rules.

```text
foundation tokens → optional preset → application overrides → component aliases
```

Preset files contain only their overrides, so they stay easy to inspect and remove. Use
[Tokens](/docs/tokens) to see which variables form the public theming surface.

## Use with the npm package

Import the foundation once, then import a preset. If users can switch between multiple presets,
load every preset they can choose before switching. `Calm` uses the foundation values and does not
have a `calm.css` file.

Put `data-moduix-theme` on `<html>` so portalled components resolve the same tokens as the rest of
the document. Set `data-moduix-color-scheme="dark"` on that element for the moduix dark mode; omit
it for the light mode.

```tsx
import '@moduix/react/style.css';
import '@moduix/react/presets/soft.css';
```

```html
<html data-moduix-theme="soft" data-moduix-color-scheme="dark"></html>
```

To use another preset, replace `soft.css` with one of these paths:

```text
@moduix/react/presets/dense.css
@moduix/react/presets/contrast.css
```

## Use with the registry

Install a preset from the hosted moduix registry. The CLI copies its CSS source into your project;
import that file after the foundation stylesheet.

```bash
npx shadcn@latest add @moduix-react/theme-dense
```

```tsx
import '@/lib/moduix/styles/style.css';
import '@/lib/moduix/presets/dense.css';
```

```html
<html data-moduix-theme="dense"></html>
```

Replace `dense` with `soft` or `contrast` for another preset. If users can switch between presets,
install and import each preset that can be selected.

## Switch themes at runtime

Theme switching only changes the `data-moduix-theme` attribute. Keep the selected name on the
document element so regular content and portalled overlays receive the same tokens. Persist the
name only if your product needs to remember the user's choice.

```tsx
type Theme = 'calm' | 'dense' | 'soft' | 'contrast';

function setTheme(theme: Theme) {
  document.documentElement.dataset.moduixTheme = theme;
  localStorage.setItem('moduix-theme', theme);
}
```

The `calm` value leaves the foundation values in place. The CSS for every other selectable preset
must already be loaded. Apply the saved value before the first paint to avoid a visible theme
change during startup.

## Customize a preset

A preset is only a layer of CSS variables. Load your own stylesheet after the preset and override
the values that need to change. Prefer semantic tokens for product-wide decisions and component
aliases for deliberate exceptions.

```css
[data-moduix-theme='soft'] {
  --moduix-primary: oklch(0.5 0.17 285);
  --moduix-radius: 0.875rem;
}
```

## Create a custom theme

If the provided presets are not a fit, create a stylesheet loaded after the foundation and use a
new value for `data-moduix-theme`. Start with the tokens that define your visual direction. Tokens
you leave out keep their foundation values. Add size or spacing tokens only when your theme
intentionally changes density. Use a preset as a reference when you want to replace the complete
palette, spacing, and shadows.

```tsx
import '@moduix/react/style.css';
import './brand.css';
```

```css
/* brand.css */
[data-moduix-theme='brand'] {
  --moduix-background: oklch(0.98 0.01 260);
  --moduix-foreground: oklch(0.2 0.02 260);
  --moduix-card: oklch(1 0 0);
  --moduix-card-foreground: oklch(0.2 0.02 260);
  --moduix-primary: oklch(0.5 0.18 260);
  --moduix-primary-foreground: oklch(0.99 0.002 260);
  --moduix-border: oklch(0.86 0.02 260);
  --moduix-input: oklch(0.82 0.025 260);
  --moduix-ring: oklch(0.58 0.15 260);
  --moduix-radius: 0.875rem;
  --moduix-size-sm: 2rem;
  --moduix-size-md: 2.25rem;
}

[data-moduix-theme='brand'][data-moduix-color-scheme='dark'] {
  --moduix-background: oklch(0.17 0.02 260);
  --moduix-foreground: oklch(0.97 0.004 260);
  --moduix-card: oklch(0.22 0.024 260);
  --moduix-card-foreground: oklch(0.97 0.004 260);
  --moduix-primary: oklch(0.78 0.13 260);
  --moduix-primary-foreground: oklch(0.18 0.024 260);
  --moduix-border: oklch(0.76 0.03 260 / 0.28);
  --moduix-input: oklch(0.76 0.03 260 / 0.34);
  --moduix-ring: oklch(0.74 0.12 260);
}
```

```html
<html data-moduix-theme="brand" data-moduix-color-scheme="dark"></html>
```

Use [Tokens](/docs/tokens) for the system token reference and [Dark mode](/docs/dark-mode) for
the application-owned light and dark mode switch.
