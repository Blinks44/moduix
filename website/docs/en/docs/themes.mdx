# Themes

Themes are CSS token layers. `Calm` is the default; `Dense`, `Soft` and `Contrast` are optional
presets that change palette, radii, spacing, density and shadows without touching component APIs.

<ThemePresets />

## Choose a preset

Sizes are the default heights of the main controls and popup rows in each preset.

| Preset   | Control / popup row | Good starting point for                                                  |
| -------- | ------------------- | ------------------------------------------------------------------------ |
| Calm     | 36px / 32px         | General application screens with neutral colors and standard spacing.    |
| Dense    | 34px / 30px         | Admin interfaces and data tables with compact spacing and blue accents.  |
| Soft     | 40px / 34px         | Interfaces with larger controls, rounded corners and violet accents.     |
| Contrast | 36px / 32px         | Interfaces with stronger borders and more distinct focus indicators.     |

:::info Test with your content
Preset names describe a visual direction, not an accessibility guarantee. Check text contrast,
focus visibility, zoom and target sizes before release.
:::

## How the layers work

The foundation defines the full token contract and the `Calm` values. A preset overrides selected
values, your app overrides only its own decisions, and components read the resulting aliases.

```text
foundation tokens → optional preset → application overrides → component aliases
```

## Use with the npm package

Import the foundation once, then a preset. Set `data-moduix-theme` on `<html>` so portalled
content gets the same values.

## Use with the registry

Presets share the foundation registry across frameworks and styling tracks. Install each preset
you want to offer.

<PackageManagerTabs command="shadcn@latest add https://moduix.dev/r/foundation/theme-dense.json" dlx />

```tsx
import '@/lib/moduix/styles/style.css';
import '@/lib/moduix/presets/dense.css';
```

## Switch themes at runtime

Load selectable presets first. Apply the selection on `html` so portalled content receives the
same tokens.

```ts
document.documentElement.dataset.moduixTheme = 'soft';
document.documentElement.dataset.moduixColorScheme = 'dark';
```

## Customize a preset

Load your product overrides after the preset. Change semantic tokens for decisions shared across
components.

```css
[data-moduix-theme='soft'] {
  --moduix-primary: oklch(0.5 0.17 285);
  --moduix-radius: 0.875rem;
}
```

## Create a custom theme

Start with the foundation and add a named CSS layer. Omitted values keep their foundation
defaults.

To pick values visually or bring a shadcn theme, use the [Theme builder](/docs/theme-builder).

```css
/* brand.css · loaded after the foundation */
[data-moduix-theme='brand'] {
  --moduix-primary: oklch(0.5 0.17 250);
  --moduix-radius: 0.75rem;
}

/* Apply to html: data-moduix-theme="brand" */
```
