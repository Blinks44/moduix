## API Reference

Ark UI does not provide a dedicated split-button primitive. moduix composes this component from the
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) and preserves the behavior of
[Ark Menu](https://ark-ui.com/docs/components/menu).

## Choosing the right component

Use `SplitButton` when one action should stay immediately available and related alternatives belong in a menu.
Use `Button` for a single action. Use `Menu` when the available actions are peers and none of them should be primary.

## Basic


Use `<SplitButton>` as the root and keep the menu structure explicit
with `SplitButtonAction`, `SplitButtonTrigger`, `SplitButtonPositioner`, and `SplitButtonContent`.
The primary action follows the same `onClick` contract as `Button`.

## Anatomy

```text
SplitButton
├─ SplitButtonAction
├─ SplitButtonTrigger
└─ Popup subtree (automatically portalled)
   └─ SplitButtonPositioner
      └─ SplitButtonContent
         ├─ MenuItem
         ├─ MenuSeparator
         └─ other shared Menu parts
```

| Part                               | Role                                                                  |
| ---------------------------------- | --------------------------------------------------------------------- |
| `SplitButton`                     | Root that owns menu state and the semantic group around both buttons. |
| `SplitButtonAction`               | Primary Button action.                                                |
| `SplitButtonTrigger`              | Ark Menu trigger rendered as a moduix Button with a chevron by default. |
| `SplitButtonPositioner`           | Positions the Ark Menu popup.                                         |
| `SplitButtonContent`              | Ark Menu content surface for shared `MenuItem` and `MenuItemGroup` parts. |

## Composition

`SplitButton` combines one primary `SplitButtonAction` with a `SplitButtonTrigger`; keep the popup tree explicit as
`SplitButtonPositioner` → `SplitButtonContent` and place shared `MenuItem` rows inside `SplitButtonContent`. The positioner is portalled automatically;
use `portalled={false}` or `portalRef` only when the popup must use a different container. Root `size` and `variant`
provide the defaults for both button parts. The root renders a semantic `role="group"`; provide `aria-label` or
`aria-labelledby` when the surrounding context does not already identify the group.

Menu state is internal by default. Pass `open` with `onOpenChange(details)` when another part of the application
owns the open state. For advanced state access, use the shared `Menu` API instead of adding a split-button-specific
state wrapper. Use `SplitButtonAction asChild` for a link; custom trigger content goes through `SplitButtonTrigger` `children` so Ark's
menu trigger and the moduix Button remain on one element.

In Vue, listen with `@click` on the action, use `@open-change` or `v-model:open` for menu state, and pass trigger content through its default slot.

`SplitButtonPositioner` wraps a portal, so its Vue component ref's `$el` points to the portal anchor. The positioned element carries `data-slot="split-button-positioner"`.

## Styling

Use `className` in React or `class` in Solid and Vue on exported parts for structural styles. Tailwind variants use native
utilities and consumer classes; the CSS variables below customize the CSS Modules variants. Data attributes and
`data-slot` hooks are shared by both styling tracks.

The joined appearance comes from the shared `Button` and `Menu` styles plus SplitButton slots. Filled variants draw a
separator on the trigger's `::before`; outline variants share the border instead. Set
`--moduix-split-button-separator-color` to recolor the separator, and change the trigger padding with a class on
`SplitButtonTrigger`.

### Styling hooks

- `data-scope="split-button"` and `data-part="root"` target the semantic group.
- `data-slot="split-button-root"` targets the group wrapper.
- `data-slot="split-button-action"` targets the primary action.
- `data-slot="split-button-trigger"` targets the menu trigger.
- `data-slot="split-button-positioner"` targets the Ark Menu positioner.
- `data-slot="split-button-content"` targets the Ark Menu content surface.
- `SplitButtonTrigger` carries Ark Menu state attributes such as `aria-expanded`, `aria-controls`, and `data-state`.
- `SplitButtonContent` carries Ark Menu attributes such as `data-state`, `data-side`, `data-placement`, `data-nested`,
  and `data-has-nested`.
