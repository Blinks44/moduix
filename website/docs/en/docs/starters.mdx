### Install and run

Starters use published packages, so any package manager works.

<StarterInstall />

### Make it yours

Replace the sample rows in `src/data.ts` with your API, then remove the pages you do not need.

</Steps>

## What’s inside

One small app per framework. Every file is plain source you can edit or delete.

<StarterContents />

:::info Using Tailwind?
Starters ship with CSS Modules. Choose the matching `-tailwind` package and follow [Framework setup](/docs/installation/vite) to configure Tailwind CSS v4 and its stylesheet.
:::
