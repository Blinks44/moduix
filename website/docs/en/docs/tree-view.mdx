Create the data collection with `createTreeCollection`, then pass it to `TreeView`.
`TreeViewNode` gives each recursive render callback the current `node`, `indexPath`, and `state`, so
you can render a branch or a leaf while keeping the part structure explicit.

React, Solid, and Vue use the same flat TreeView names; the examples below keep each framework's native composition.

## Examples

### Links

Use `asChild` on `TreeViewItem` when a leaf should be one semantic element, such as a link. The
child must accept the Ark props so focus and keyboard behavior stay intact.

<Example name="tree-view/links" />

### Async loading

For a branch with a known `childrenCount`, load its children with `loadChildren`. In
`onLoadChildrenComplete`, replace the application collection with `details.collection`.

<Example name="tree-view/async-loading" />

### Checkbox tree

Place `TreeViewNodeCheckbox` in both branch controls and leaf items. Its default indicator already covers
the checked and indeterminate states.

Vue uses the default slot for the checked icon and the named `indeterminate` and `fallback`
slots for the mixed and unchecked states. These states are customized through slots, not props.

<Example name="tree-view/checkboxes" />

### File icons

Put decorative file and folder icons inside `TreeViewBranchText` and `TreeViewItemText`. Keep `TreeViewBranchIndicator`
separate so it remains the only expand and collapse affordance.

<Example name="tree-view/file-icons" />

### Multiple selection

Set `selectionMode="multiple"`. Use Ctrl or ⌘ to add or remove individual items, and Shift to
extend a selection range. The example keeps the selected values in application state.

<Example name="tree-view/controlled-selection" />

### Root provider

Create tree state with `useTreeView` when controls outside the tree need methods such as `expand()`
or `collapse()`. Pass that state to `TreeViewRootProvider` instead of rendering a second `TreeView`.
This example also shows the low-level node composition: each node uses `TreeViewNodeProvider` and
reads its state from `TreeViewNodeContext` instead of the `TreeViewNode` shortcut.

## Composition

Use `TreeViewNode` for recursive renderers. It supplies `node`, `indexPath`, and the current node
`state` while you choose the `TreeViewBranch` or `TreeViewItem` parts. If a custom recursive component needs direct
node context, use `TreeViewNodeProvider` directly. When controls outside the tree
own its state, create it with `useTreeView` and pass it to `TreeViewRootProvider`; do not render a
second root for the same store. If a branch has a separate `TreeViewBranchTrigger`, set `role="none"` on
`TreeViewBranchControl`.

In Vue, `TreeViewNode` exposes its render data through a scoped default slot. Control values with
`v-model:expanded-value`, `v-model:selected-value`, `v-model:checked-value`, and
`v-model:focused-value`; events such as `@selection-change` keep Ark's detail objects. Keep a
replaceable collection in a `shallowRef` so Vue preserves its class instance.

## Styling

Use `className` in React, `class` in Solid, or `class` in Vue on any exported part for structural styling. Branch
parts expose `data-state="open|closed"`; checkbox parts expose
`data-state="checked|unchecked|indeterminate"`; and node parts expose `data-focus`, `data-selected`,
`data-disabled`, `data-loading`, `data-renaming`, `data-depth`, `data-path`, and `data-value`. The
wrapper respects Ark's `--depth` indentation and `--height` collapse-measurement variables, and it
disables branch animation when reduced motion is preferred.

Tailwind variants use native utilities and consumer classes. CSS Modules variants take colors,
spacing, and typography from foundation tokens and expose only the root width and the indentation
step as CSS variables; override other styles with a class on the part.

## Keyboard

| Key | Action |
| --- | --- |
| `ArrowDown` / `ArrowUp` | Moves focus to the next or previous visible node. |
| `ArrowRight` | Opens a closed branch or moves into an open one. |
| `ArrowLeft` | Closes an open branch or moves to the parent. |
| `Home` / `End` | Moves focus to the first or last node. |
| `Enter` / `Space` | Selects the node or toggles a branch. |
| `*` | Opens all sibling branches. |
| `F2` | Starts renaming when canRename allows it. |
