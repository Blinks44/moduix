## Basic

Create the data collection with `createTreeCollection`, then pass it to `TreeView`.
`TreeView.Node` gives each recursive render callback the current `node`, `indexPath`, and `state`, so
you can render a branch or a leaf without wiring a provider and context into every level yourself.

## Anatomy

```text
TreeView / TreeView.Root
├─ TreeView.Label
└─ TreeView.Tree
   └─ TreeView.Node or TreeView.NodeProvider
      ├─ TreeView.Branch
      │  ├─ TreeView.BranchControl
      │  │  ├─ TreeView.BranchIndicator
      │  │  └─ TreeView.BranchText
      │  └─ TreeView.BranchContent
      │     ├─ TreeView.BranchIndentGuide
      │     └─ nested nodes
      └─ TreeView.Item
         └─ TreeView.ItemText
```

| Part                             | Role                                                                  |
| -------------------------------- | --------------------------------------------------------------------- |
| `TreeView` / `TreeView.Root`     | Stores the collection and manages expansion, selection, focus, checking, and renaming. |
| `TreeView.RootProvider`          | Connects tree parts to an instance returned by `useTreeView`.        |
| `TreeView.Label`                 | Gives the tree an accessible name.                                    |
| `TreeView.Tree`                  | Renders the ARIA tree container.                                      |
| `TreeView.Node`                  | A convenience provider that exposes `{ node, indexPath, state }`.    |
| `TreeView.NodeProvider`          | The low-level Ark context boundary for custom composition.           |
| `TreeView.Branch*`               | An expandable node, its control, indicator, text, and child content. |
| `TreeView.Item*`                 | A leaf node and its optional selected-state indicator.               |
| `TreeView.NodeCheckbox*`         | The checkbox control and its checked or indeterminate indicator.     |
| `TreeView.NodeRenameInput`       | The inline input shown while a node is being renamed.                |

## Composition

### Recommended composition

Use `TreeView.Node` for a regular recursive renderer. Its child function receives the current
`node`, `indexPath`, and Ark node `state`, then returns either branch or leaf markup. This keeps the
part structure explicit while removing repeated context setup.

### When to use NodeProvider

Use `TreeView.NodeProvider` when your own recursive component needs direct access to tree-node
context. It is the lower-level alternative to `TreeView.Node`, not an additional wrapper to use with it.

### Branch rows and expand buttons

`BranchControl` makes the whole branch row expandable by default. If you render a separate
`BranchTrigger`, set `role="none"` on `BranchControl` so one interactive tree item is not nested
inside another.

### Link items

Use `asChild` on `TreeView.Item` when a leaf should be a single semantic child, such as a link. The
child must accept the Ark props so that focus and keyboard behavior stay intact.

### State and keyboard support

Ark UI implements the WAI-ARIA tree pattern. People can move through the tree with the arrow keys,
Home and End, and typeahead; you normally do not need to manage focus yourself. Make
`expandedValue`, `selectedValue`, `checkedValue`, or `focusedValue` controlled only when your
application needs to own that state, and pair each value with its corresponding callback.

| Prop            | Default    | Notes                                                       |
| --------------- | ---------- | ----------------------------------------------------------- |
| `selectionMode` | `"single"` | Use `"multiple"` for modifier-key and range selection.      |
| `expandOnClick` | `true`     | Clicking a branch row opens or closes it.                   |
| `typeahead`     | `true`     | Matches the text returned by the collection's `nodeToString`. |
| `lazyMount`     | `false`    | Renders branch content only after its first expansion.      |
| `unmountOnExit` | `false`    | Removes closed content after its exit lifecycle.            |

### Renaming and large trees

To allow renaming, provide `canRename`, render `NodeRenameInput` while `state.renaming` is true, and
update the collection in `onRenameComplete`. For a virtualized tree, create state with
`useTreeView`, connect it with `RootProvider`, render the flattened result of `getVisibleNodes()`,
and provide `scrollToIndexFn` so keyboard navigation can scroll to a node. Moduix does not add a
separate virtualization API.

## Styling

Use `className` on any exported part for structural styling. Branch parts expose
`data-state="open|closed"`; checkbox parts expose
`data-state="checked|unchecked|indeterminate"`; and node parts expose `data-focus`,
`data-selected`, `data-disabled`, `data-loading`, `data-renaming`, `data-depth`, `data-path`, and
`data-value`. The wrapper respects Ark's `--depth` indentation and `--height` collapse-measurement
variables, and it disables branch animation when reduced motion is preferred.
