## Basic

`Accordion` groups related content into expandable sections. It works well for FAQs, settings, and
filters when users may need to compare several sections. Use `Collapsible` for a single standalone
expandable section.

Use `Accordion` with these Ark-style parts: `Accordion.Item`, `Accordion.ItemTrigger`,
`Accordion.ItemIndicator`, `Accordion.ItemContent`, and `Accordion.ItemBody`.

## Anatomy

```text
Accordion.Root
└─ Accordion.Item[value]
 ├─ Accordion.ItemTrigger
 │  ├─ label
 │  └─ Accordion.ItemIndicator (optional)
 └─ Accordion.ItemContent
    └─ Accordion.ItemBody
       └─ content

Accordion.RootProvider
└─ same item tree connected to a useAccordion() store
```

| Part                           | Role                                                                                   |
| ------------------------------ | -------------------------------------------------------------------------------------- |
| `Accordion` / `Accordion.Root` | Controls accordion state and keyboard interaction.                                      |
| `Accordion.RootProvider`       | Connects the parts to state created with `useAccordion()`.                              |
| `Accordion.Item`               | A collapsible item with a required `value`.                                            |
| `Accordion.ItemTrigger`        | An interactive button that opens or closes the item.                                   |
| `Accordion.ItemIndicator`      | Visual cue for the item's state. Defaults to the moduix plus icon when no children are provided. |
| `Accordion.ItemContent`        | Collapsible content region that preserves Ark's size-animation behavior.               |
| `Accordion.ItemBody`           | Inner wrapper that provides default spacing for panel content.                          |

## Composition

### Recommended composition

`Accordion` manages keyboard navigation, focus movement, and open-item state. Use it for
`value`, `defaultValue`, `onValueChange(details)`, `onFocusChange(details)`, `multiple`,
`collapsible`, `orientation`, `lazyMount`, `unmountOnExit`, and `ids`.

For the standard Ark composition, use `Accordion`, `Accordion.Item`, `Accordion.ItemTrigger`,
`Accordion.ItemIndicator`, `Accordion.ItemContent`, and `Accordion.ItemBody`.

### Custom composition

Choose a custom composition when state must be created outside the rendered subtree, other UI needs
access to it, or you need to replace the default parts.

`value` and `defaultValue` are always arrays, even when only one item can be open. `onValueChange`
keeps the Ark callback shape and exposes the current item values as `details.value`.

Use `Accordion.RootProvider` with `useAccordion()` from `@moduix/react` when accordion state must
be created outside the rendered subtree.

Use `Accordion.Context`, `Accordion.ItemContext`, `useAccordionContext()`, and
`useAccordionItemContext()` from moduix when surrounding UI needs access to root or item state. Item
state includes Ark's `expanded`, `focused`, and `disabled` booleans.

`Accordion.Item` requires a stable `value`. Set `disabled` on an item when its section should stay
visible but unavailable for interaction.

`Accordion.ItemIndicator` is optional. In moduix it renders `PlusIcon` by default when no children
exist, but you can replace the indicator content entirely.

Use `asChild` only when another element must own the rendered DOM node. Keep the Ark part tree
explicit instead of hiding it behind convenience wrappers.

### Default props

| Prop                   | Default    | Notes                                                 |
| ---------------------- | ---------- | ----------------------------------------------------- |
| `collapsible`          | `false`    | Prevents the open item from closing without opening another one. |
| `lazyMount`            | `false`    | Renders item content when the accordion mounts.                 |
| `multiple`             | `false`    | Allows only one expanded item at a time.                        |
| `orientation`          | `vertical` | Uses vertical layout and keyboard behavior.                     |
| `unmountOnExit`        | `false`    | Leaves collapsed content mounted.                               |
| `value`/`defaultValue` | `[]`       | Values are string arrays, even in single-open mode.              |

### Behavioral notes

Put spacing on `Accordion.ItemBody` rather than `Accordion.ItemContent`. Ark measurement variables
drive the open and close animation: `--height` for vertical accordions and `--width` for horizontal
accordions.

Each trigger is a native button linked to its content with `aria-expanded`, `aria-controls`, and the
matching content label. `Enter` or `Space` toggles the item. In vertical orientation, `ArrowDown`
and `ArrowUp` move between triggers; horizontal orientation uses `ArrowRight` and `ArrowLeft`.
`Home` and `End` move focus to the first and last trigger.

Every styled part forwards its ref and supports `asChild` when another semantic element must own the
rendered node. Keep custom triggers keyboard-focusable and button-like.

When the user prefers reduced motion, Accordion removes trigger and indicator transitions and reduces
panel motion to an effectively instant animation that preserves Ark's lifecycle.

## Styling

Use `className` on exported parts to change structural styles. For state-based styles, prefer Ark
data attributes (`data-state`, `data-disabled`, `data-orientation`) and moduix `data-slot` selectors.

### CSS Properties

<CssPropertiesSection properties={AccordionDocs.accordionOverrideCssProperties} />

### Styling hooks

- Stable `data-slot` selectors: `accordion-root`, `accordion-root-provider`, `accordion-item`,
  `accordion-item-trigger`, `accordion-item-indicator`, `accordion-item-content`, and
  `accordion-item-body`.
- Ark part selectors: `data-scope="accordion"` and `data-part="root|item|item-trigger|item-indicator|item-content"`.
- moduix-specific selector: `data-part="item-body"` on `Accordion.ItemBody`.
- Ark state selectors: `data-state="open|closed"`, `data-disabled`, `data-focus`,
  `data-controls`, and `data-orientation="horizontal|vertical"`.
- Ark content variables: `--height` for vertical animation and `--width` for horizontal animation.
