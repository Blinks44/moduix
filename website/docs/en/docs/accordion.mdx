## Choosing the right component

Use `Accordion` when several related sections should share keyboard navigation and state. Use
`Collapsible` when you need one independent disclosure.

## Basic

Accordion ships for React and Solid in both the CSS Modules and Tailwind packages. The rendered
preview on this page uses the React CSS Modules package; the framework tabs show native source for
the same public contract.

Use `Accordion` as the root and give every `Accordion.Item` a stable `value`. Put the interactive
label in `Accordion.ItemTrigger`, the panel in `Accordion.ItemContent`, and the panel's inner
content in `Accordion.ItemBody`. `Accordion.ItemIndicator` is optional and defaults to the moduix
plus icon.

Use `Accordion` as the root in most cases. `Accordion.Root` is an alias for the same root when you
want to make that part explicit in your composition.

## Anatomy

```text
Accordion / Accordion.Root
└─ Accordion.Item[value]
 ├─ Accordion.ItemTrigger
 │  ├─ label
 │  └─ Accordion.ItemIndicator (optional)
 └─ Accordion.ItemContent
    └─ Accordion.ItemBody
       └─ content

Accordion.RootProvider
└─ same item tree connected to a useAccordion() store
```

| Part                           | Role                                                                                         |
| ------------------------------ | -------------------------------------------------------------------------------------------- |
| `Accordion` / `Accordion.Root` | Root part that owns accordion state and keyboard navigation.                                 |
| `Accordion.RootProvider`       | Connects the parts to state created with `useAccordion()`.                                   |
| `Accordion.Item`               | A collapsible item with a required, stable `value`.                                           |
| `Accordion.ItemTrigger`        | The button that opens or closes the item.                                                     |
| `Accordion.ItemIndicator`      | Optional state indicator. Defaults to the moduix plus icon when no children are provided.     |
| `Accordion.ItemContent`        | The collapsible panel, with Ark's size-animation behavior.                                   |
| `Accordion.ItemBody`           | The moduix inner wrapper that provides default panel spacing.                                |

## Composition

Use `defaultValue` for an uncontrolled accordion. Use `value` with `onValueChange(details)` when
another part of the application owns the state. Both props use `string[]`, even when only one item
can be open.

Use `Accordion.RootProvider` with `useAccordion()` from the matching framework package when the
accordion state must be created outside the rendered tree. Pass the returned store to
`RootProvider`, and do not render `Accordion` or `Accordion.Root` for the same store. React reads
the store as an object; Solid reads its reactive state through the returned accessor.

## Styling

Use `className` in React or `class` in Solid on exported parts for structural styles. For state-based
styles, prefer Ark data attributes such as `data-state`, `data-disabled`, and `data-orientation`,
together with moduix `data-slot` selectors. Tailwind variants use native utilities and consumer
classes; the component variables below customize the CSS Modules variants. Data attributes and
`data-slot` hooks are shared by both styling tracks.

Put panel spacing on `Accordion.ItemBody`, not `Accordion.ItemContent`, so Ark can measure and
animate the panel correctly.

### Styling hooks

- Stable `data-slot` selectors: `accordion-root`, `accordion-root-provider`, `accordion-item`,
  `accordion-item-trigger`, `accordion-item-indicator`, `accordion-item-content`, and
  `accordion-item-body`.
- Ark part selectors: `data-scope="accordion"` and
  `data-part="root|item|item-trigger|item-indicator|item-content"`.
- moduix-specific selector: `data-part="item-body"` on `Accordion.ItemBody`.
- Ark state selectors: `data-state="open|closed"`, `data-disabled`, `data-focus`, `data-controls`,
  and `data-orientation="horizontal|vertical"`.
- Ark content variables: `--height` for vertical animation and `--width` for horizontal animation.
