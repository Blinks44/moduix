## Choosing the right component

Use `Accordion` when several related sections should share keyboard navigation and state. Use
`Collapsible` when you need one independent disclosure.

## Basic


Use `Accordion` as the root and give every item a stable `value`. Put the interactive label in the
item trigger, the panel in the item content, and the panel's inner content in the item body. The
item indicator is optional and defaults to the moduix plus icon.

Use `Accordion` as the root in most cases. In React and Solid, `Accordion.Root` is an alias for the
same root when you want to make that part explicit in your composition.

React and Solid expose compound parts such as `Accordion.Item`. Vue keeps the same `Accordion` root
name and exports its parts with native flat names such as `AccordionItem` and
`AccordionItemTrigger`. The flat Vue imports work the same way with the npm package and shadcn
registry source.

## Anatomy

```text
React and Solid
Accordion / Accordion.Root
└─ Accordion.Item[value]
 ├─ Accordion.ItemTrigger
 │  ├─ label
 │  └─ Accordion.ItemIndicator (optional)
 └─ Accordion.ItemContent
    └─ Accordion.ItemBody
       └─ content

Accordion.RootProvider
└─ same item tree connected to a useAccordion() store

Vue
Accordion / AccordionRoot
└─ AccordionItem[value]
 ├─ AccordionItemTrigger
 │  ├─ label
 │  └─ AccordionItemIndicator (optional)
 └─ AccordionItemContent
    └─ AccordionItemBody
       └─ content

AccordionRootProvider
└─ same item tree connected to a useAccordion() store
```

| Part                                                        | Role                                                                                      |
| ----------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `Accordion` / `Accordion.Root` / `AccordionRoot` in Vue     | Root part that owns accordion state and keyboard navigation.                              |
| `Accordion.RootProvider` / `AccordionRootProvider` in Vue   | Connects the parts to state created with `useAccordion()`.                                |
| `Accordion.Item` / `AccordionItem` in Vue                   | A collapsible item with a required, stable `value`.                                       |
| `Accordion.ItemTrigger` / `AccordionItemTrigger` in Vue     | The button that opens or closes the item.                                                 |
| `Accordion.ItemIndicator` / `AccordionItemIndicator` in Vue | Optional state indicator. Defaults to the moduix plus icon when no children are provided. |
| `Accordion.ItemContent` / `AccordionItemContent` in Vue     | The collapsible panel, with Ark's size-animation behavior.                                |
| `Accordion.ItemBody` / `AccordionItemBody` in Vue           | The moduix inner wrapper that provides default panel spacing.                             |

## Composition

Use `defaultValue` for an uncontrolled accordion. Use `value` with `onValueChange(details)` when
another part of the application owns the state. Both props use `string[]`, even when only one item
can be open.

Use `Accordion.RootProvider` in React and Solid, or `AccordionRootProvider` in Vue, with
`useAccordion()` from the matching framework package when the accordion state must be created
outside the rendered tree. Do not render a root component for the same store. React reads the
store as an object; Solid reads its reactive state through the returned accessor; Vue exposes the
reactive store directly to the template.

## Styling

Use `className` in React or `class` in Solid and Vue on exported parts for structural styles. For
state-based styles, prefer Ark data attributes such as `data-state`, `data-disabled`, and
`data-orientation`, together with moduix `data-slot` selectors. Tailwind variants use native
utilities and consumer classes; the component variables below customize the CSS Modules variants.
Data attributes and `data-slot` hooks are shared by both styling tracks.

Put panel spacing on `Accordion.ItemBody` in React and Solid, or `AccordionItemBody` in Vue, rather
than on the content part so Ark can measure and animate the panel correctly.

### Styling hooks

- Stable `data-slot` selectors: `accordion-root`, `accordion-root-provider`, `accordion-item`,
  `accordion-item-trigger`, `accordion-item-indicator`, `accordion-item-content`, and
  `accordion-item-body`.
- Ark part selectors: `data-scope="accordion"` and
  `data-part="root|item|item-trigger|item-indicator|item-content"`.
- moduix-specific selector: `data-part="item-body"` on the item body part.
- Ark state selectors: `data-state="open|closed"`, `data-disabled`, `data-focus`, `data-controls`,
  and `data-orientation="horizontal|vertical"`.
- Ark content variables: `--height` for vertical animation and `--width` for horizontal animation.
