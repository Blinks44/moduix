Use `Accordion` as the root and give every item a stable `value`. Put the interactive label in the
item trigger, the panel in the item content, and the panel's inner content in the item body. The
item indicator is optional and defaults to a chevron that turns when the item opens. Wrap each
trigger in a heading (`h3` in the examples) so screen reader users can jump between sections.

## Choosing the right component

Use `Accordion` when several related sections should share keyboard navigation and state. Use
`Collapsible` when you need one independent disclosure.

## Composition

Use `defaultValue` for an uncontrolled accordion. Use `value` with `onValueChange(details)` when
another part of the application owns the state. Both props use `string[]`, even when only one item
can be open.

Use `AccordionRootProvider` with `useAccordion()` from the matching framework package when the
accordion state must be created outside the rendered tree. Do not render `Accordion` for the same
store. React reads the store as an object; Solid reads its reactive state through the returned
accessor; Vue exposes the reactive store directly to the template.

## Anatomy

```text
Accordion
└─ AccordionItem[value]
 ├─ h3 (recommended heading)
 │  └─ AccordionItemTrigger
 │     ├─ label
 │     └─ AccordionItemIndicator (optional)
 └─ AccordionItemContent
    └─ AccordionItemBody
       └─ content

AccordionRootProvider
└─ same item tree connected to a useAccordion() store
```

| Part                     | Role                                                                                      |
| ------------------------ | ----------------------------------------------------------------------------------------- |
| `Accordion`              | Root part that owns accordion state and keyboard navigation.                              |
| `AccordionRootProvider`  | Connects the parts to state created with `useAccordion()`.                                |
| `AccordionItem`          | A collapsible item with a required, stable `value`.                                       |
| `AccordionItemTrigger`   | The button that opens or closes the item.                                                 |
| `AccordionItemIndicator` | Optional state indicator. Defaults to a chevron when no children are provided. |
| `AccordionItemContent`   | The collapsible panel, with Ark's size-animation behavior.                                |
| `AccordionItemBody`      | The moduix inner wrapper that provides default panel spacing.                             |

## Styling

Use `className` in React or `class` in Solid and Vue on exported parts for structural styles. For
state-based styles, prefer Ark data attributes such as `data-state`, `data-disabled`, and
`data-orientation`, together with moduix `data-slot` selectors. Tailwind variants use native
utilities and consumer classes; the component variables below customize the CSS Modules variants.
Data attributes and `data-slot` hooks are shared by both styling tracks.

Put panel spacing on `AccordionItemBody` rather than on `AccordionItemContent` so Ark can measure
and animate the panel correctly.

### Styling hooks

| Part | `data-slot` |
| --- | --- |
| `Accordion` | `accordion-root` |
| `AccordionRootProvider` | `accordion-root-provider` |
| `AccordionItem` | `accordion-item` |

| `AccordionItemContent` | `accordion-item-content` |
| `AccordionItemBody` | `accordion-item-body` |

- Ark part selectors: `data-scope="accordion"` and
  `data-part="root|item|item-trigger|item-indicator|item-content"`.
- moduix-specific selector: `data-part="item-body"` on the item body part.
- Ark state selectors: `data-state="open|closed"`, `data-disabled`, `data-focus`, `data-controls`,
  and `data-orientation="horizontal|vertical"`.
- Ark content variables: `--height` for vertical animation and `--width` for horizontal animation.

## Keyboard

| Key | Action |
| --- | --- |
| `Enter` / `Space` | Opens or closes the focused item. |
| `ArrowDown` / `ArrowUp` | Moves focus to the next or previous trigger. |
| `Home` / `End` | Moves focus to the first or last trigger. |
