## Anatomy

```text
Carousel / Carousel.Root
├─ Carousel.ItemGroup
│  └─ Carousel.Item[index]
├─ Carousel.Control
│  ├─ Carousel.PrevTrigger
│  └─ Carousel.NextTrigger
├─ Carousel.Indicators
│  └─ Carousel.IndicatorGroup
│     └─ Carousel.Indicator[index]
└─ Carousel.ProgressText
```

| Part                         | Role                                                           |
| ---------------------------- | -------------------------------------------------------------- |
| `Carousel` / `Carousel.Root` | Owns carousel state, navigation, and item collection.           |
| `Carousel.Control`           | Container for navigation triggers and related controls.         |
| `Carousel.ItemGroup`         | Slide track that contains `Carousel.Item` parts.                 |
| `Carousel.Item`              | A single slide with a stable `index`.                            |
| `Carousel.PrevTrigger`       | Trigger for the previous page.                                  |
| `Carousel.NextTrigger`       | Trigger for the next page.                                      |
| `Carousel.Indicators`        | moduix convenience wrapper for the default page indicators.     |
| `Carousel.IndicatorGroup`    | Container for page indicators.                                  |
| `Carousel.Indicator`         | Indicator trigger for a specific slide or page index.           |
| `Carousel.ProgressText`      | Text showing the current page and total number of pages.        |

These lower-level parts are also available when you need more control:

- `Carousel.Context`
- `Carousel.AutoplayTrigger`
- `Carousel.AutoplayIndicator`
- `Carousel.RootProvider`

`useCarousel` and `useCarouselContext` are available from `@moduix/react`.

## Composition

### Recommended composition

Use `Carousel` as the root, `Carousel.ItemGroup` as the slide track, and `Carousel.Control` for
navigation. Add `Carousel.Indicators` when the default dot pager is all you need.

`Carousel.Control` usually sits beside `Carousel.ItemGroup` as a toolbar.

`Carousel.Root` is an explicit alias for `Carousel`. Use it when you prefer the namespaced form in
your code.

### When to go custom

Use `Carousel.Context` with `Carousel.IndicatorGroup` and `Carousel.Indicator` when you need a
custom pager layout, thumbnail indicators, or direct control over `pageSnapPoints`.

Use moduix `Carousel.RootProvider` with `useCarousel()` when you need to create carousel state
outside the rendered subtree.

Use `useCarouselContext()` inside custom child components that need the carousel API without using
a render prop.

Use `Carousel.AutoplayTrigger` and `Carousel.AutoplayIndicator` when autoplay controls should be
visible in the UI instead of being configured only through a root prop.

### Default props

| Prop         | Default | Notes                                     |
| ------------ | ------- | ----------------------------------------- |
| `slideCount` | -       | Required on `Carousel` / `Carousel.Root`. |

### Behavioral notes

- `onPageChange(details)` uses Ark's callback shape and exposes the active page as `details.page`.
- Give `Carousel` or `Carousel.RootProvider` an `aria-label` or `aria-labelledby` so its carousel
  landmark has an accessible name.
- `spacing`, `padding`, `slidesPerPage`, `slidesPerMove`, and `autoSize` use Ark's sizing and
  snap-point behavior directly.
- Vertical carousels use the same public API. When the component uses moduix chevrons, the default
  triggers rotate automatically.
- With `dir="rtl"`, default horizontal triggers mirror automatically.
- `Carousel.ProgressText` keeps the numeric `current / total` order readable in RTL carousels.
- `--moduix-carousel-indicator-size` controls the compact indicator button, so its focus ring follows
  the dot or current capsule geometry.
- With `prefers-reduced-motion: reduce`, the track scrolls immediately, and moduix disables
  transitions for controls and indicators.

## Styling

Use `className` on exported parts for structural styling. For state styles, prefer Ark data
attributes (`data-part`, `data-orientation`, `data-current`, `data-dragging`) and moduix `data-slot`
hooks.

### Styling hooks

- `data-slot="carousel-root"`, `carousel-control`, `carousel-item-group`, `carousel-item`,
  `carousel-prev-trigger`, `carousel-next-trigger`, `carousel-indicator-group`,
  `carousel-indicator`, `carousel-autoplay-trigger`, `carousel-autoplay-indicator`, and
  `carousel-progress-text` are stable selectors for the exported parts.
- Ark also adds `data-scope="carousel"` and `data-part` names to the rendered nodes.
- `data-orientation="horizontal" | "vertical"` is available on root and structural parts.
- `Carousel.ItemGroup` exposes `data-dragging` while a drag interaction is active.
- `Carousel.Indicator` exposes `data-current`, while `Carousel.Item` exposes `data-index` and
  `data-inview`.
- `Carousel.Indicator` exposes `data-readonly`, while `Carousel.AutoplayTrigger` exposes
  `data-pressed`.
