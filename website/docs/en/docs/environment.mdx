`EnvironmentProvider` tells Ark UI which DOM root, `Document`, and `Window` to use for Ark-backed components. It is useful when the component tree is rendered outside the page's main document.

## API Reference

<PrimitiveReference href="https://ark-ui.com/docs/utilities/environment" />

## Basic setup

Use `EnvironmentProvider` around the whole subtree that belongs to the environment. Without a `value`, it resolves the environment where the provider is rendered. Use `useEnvironmentContext` when application code needs the resolved root, document, or window.

The preview uses the main document, so the provider resolves `document` automatically. In Solid, `useEnvironmentContext()` returns an accessor, so call it before reading `getRootNode`, `getDocument`, or `getWindow`.

## Use a custom root

Pass a `Document`, `ShadowRoot`, or other root node through `value` when your application owns that root. The provider does not create the root, move content, or create a portal. Mount the subtree in the root yourself and pass the same root to `EnvironmentProvider`.

Use the function form of `value` when the root is not available during the first render, such as while an iframe is loading or before a shadow root is attached.

This example needs only the Ark environment API, a `Button` from the selected Moduix package, and the framework's portal API. It can run in a client component when the application framework separates server and client rendering:

## Iframes

If you use Ark UI's `Frame`, place the embedded components directly inside it. `Frame` creates the iframe mount point
and supplies its document to Ark UI, so an additional `EnvironmentProvider` is not needed. See [Frame](/docs/frame) for
iframe styles, lifecycle, and security.
