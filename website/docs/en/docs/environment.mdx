## When to use it

Use `EnvironmentProvider` when a component renders in a different DOM environment than the page’s main `document`,
such as an iframe, a Shadow DOM root, or an Electron window. Ark UI uses that environment to find elements and IDs,
manage focus, and work with the correct document.

Import the provider and its context hook directly from Ark UI:

```tsx
import { EnvironmentProvider, useEnvironmentContext } from '@ark-ui/react/environment';
```

## Basic setup

Wrap the part of the React tree that renders in the custom environment. If you omit `value`, the provider detects the
environment where it renders. `useEnvironmentContext` provides functions for reading that root, its `Document`, and
its `Window`.

## Custom roots

`value` accepts a root node directly or a function that returns one. Use the function form when the root is not
available during the first render, for example while an iframe is loading or before a shadow root is attached.

```tsx
import { EnvironmentProvider } from '@ark-ui/react/environment';
import { Button } from '@moduix/react/button';
import { createPortal } from 'react-dom';
import { useEffect, useRef, useState } from 'react';

export function ShadowDomSettings() {
  const hostRef = useRef<HTMLDivElement>(null);
  const [shadowRoot, setShadowRoot] = useState<ShadowRoot | null>(null);

  useEffect(() => {
    const host = hostRef.current;
    if (!host) return;
    setShadowRoot(host.shadowRoot ?? host.attachShadow({ mode: 'open' }));
  }, []);

  return (
    <>
      <div ref={hostRef} />
      {shadowRoot
        ? createPortal(
            <EnvironmentProvider value={shadowRoot}>
              <Button type="button">Save settings</Button>
            </EnvironmentProvider>,
            shadowRoot,
          )
        : null}
    </>
  );
}
```

The provider only tells Ark UI which root to use for DOM APIs. It does not move React content into an iframe or Shadow
DOM. Your application or iframe library still controls the mount point and any portal. Render the provider in the same
environment as the subtree it configures.

## Using `Frame`

Ark’s `Frame` utility renders its children into an iframe and supplies that iframe’s document to Ark UI. Place moduix
components directly inside `Frame`; you do not need another `EnvironmentProvider`:

```tsx
import { Frame } from '@ark-ui/react/frame';
import { Button } from '@moduix/react/button';

export function IframeAction() {
  return (
    <Frame title="Account settings">
      <Button type="button">Save settings</Button>
    </Frame>
  );
}
```

## Using moduix

Use moduix components inside `EnvironmentProvider` as usual. Wrap the whole subtree once instead of configuring
individual components. Dialog, Menu, Popover, and other Ark-backed components can then resolve focus and DOM
relationships against the correct root.

The provider does not copy CSS into an iframe or Shadow DOM. Load the moduix stylesheet in that environment too, so
components keep their intended appearance.

## Ownership

`EnvironmentProvider` and `useEnvironmentContext` are Ark UI APIs. moduix does not re-export them. This page explains
how to use them with moduix components; see the Ark UI reference for the complete API.
