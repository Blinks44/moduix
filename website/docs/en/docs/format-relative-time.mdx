## When to use it

Use `Format.RelativeTime` when elapsed or remaining time matters more than the exact timestamp: activity feeds, save
states, deadlines, and upcoming events. It accepts a `Date`, compares it with the current time during render, and
returns text such as “12 minutes from now” or “yesterday”.

Import `Format` directly from Ark UI:

```tsx
import { Format } from '@ark-ui/react';
```

## Basic

Use `numeric="auto"` when natural words such as “tomorrow” and “yesterday” are clearer than a number. Place the
formatted result beside the status or event it describes.

## Locale and updates

`Format.RelativeTime` receives its locale from `LocaleProvider`. moduix re-exports that provider, so it can be the
shared locale provider for your interface:

```tsx
import { Format } from '@ark-ui/react';
import { LocaleProvider } from '@moduix/react/locale';

const lastUpdatedAt = new Date(Date.now() - 24 * 60 * 60 * 1000);

export function LocalizedUpdate() {
  return (
    <LocaleProvider locale="fr-FR">
      <Format.RelativeTime numeric="auto" value={lastUpdatedAt} />
    </LocaleProvider>
  );
}
```

The formatter calculates the text when React renders it; it does not refresh itself as time passes. Re-render it at
the interval your interface needs when the text must stay current, and use `Timer` for a live countdown.

## Using moduix

`Format.RelativeTime` renders text only. Use moduix `Card`, `Stack`, `Text`, and status components to establish the
event’s hierarchy and meaning; do not create a component just to call the formatter.

## Ownership

Ark UI handles relative-time formatting and the `Format.RelativeTime` API. moduix supplies the surrounding interface
components and re-exports `LocaleProvider`, but does not re-export `Format.RelativeTime`.
