## When to use it

Use `Format.RelativeTime` when knowing how long ago or how soon something happens is more useful than an exact
timestamp: for activity feeds, save status, deadlines, and upcoming events. Pass a `Date` to `value`. When it
renders, Ark compares that date with the current time, chooses a unit from seconds to years, and formats the result
with `Intl.RelativeTimeFormat`.

By default, `numeric` is set to `"always"`, so the output is numeric, such as “in 12 minutes” or “1 day ago”.
Set `numeric="auto"` to allow natural phrases such as “tomorrow” and “yesterday”.

Import `Format` directly from Ark UI:

```tsx
import { Format } from '@ark-ui/react';
```

## Locale

`Format.RelativeTime` reads its locale from `LocaleProvider`. Without a provider, Ark uses `en-US`. moduix re-exports
`LocaleProvider`, so you can use one provider for relative-time output and other locale-aware parts of your interface:

```tsx
import { Format } from '@ark-ui/react';
import { LocaleProvider } from '@moduix/react/locale';

const lastUpdatedAt = new Date(Date.now() - 24 * 60 * 60 * 1000);

export function LocalizedUpdate() {
  return (
    <LocaleProvider locale="fr-FR">
      <Format.RelativeTime numeric="auto" value={lastUpdatedAt} />
    </LocaleProvider>
  );
}
```

## Display options

`Format.RelativeTime` accepts the standard `Intl.RelativeTimeFormatOptions`. The most useful display options are:

| Option    | Values                                      | Purpose                                      |
| --------- | ------------------------------------------- | -------------------------------------------- |
| `numeric` | `"always"` (default), `"auto"`             | Use numbers or natural words where available. |
| `style`   | `"long"` (default), `"short"`, `"narrow"` | Control how much text the result uses.        |

You do not need to provide a unit or a numeric distance separately. The component derives both from the `Date` you
pass to `value`.

## Updating over time

`Format.RelativeTime` does not start a timer. It computes the string during render and keeps that value until your
application renders it again. If a label must stay current, trigger re-renders at a cadence that suits the interface.
For a duration or countdown that updates continuously, use [`Timer`](/docs/timer).

## Using moduix

`Format.RelativeTime` renders text only; it does not add a wrapper element. Place it inside the layout, status, or
data-display component that explains what the relative time refers to. The examples on this page use moduix `Card`
and `Stack` for that surrounding context.

The formatter itself comes from Ark UI and is imported from `@ark-ui/react`. moduix provides the surrounding
components and re-exports `LocaleProvider`, but it does not re-export `Format.RelativeTime`.
