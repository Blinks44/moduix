## When to use it

Use `Format.RelativeTime` when the distance from now is more useful than an exact timestamp: for activity feeds,
save status, deadlines, and upcoming events. Pass a `Date` to `value`. At render time, Ark calculates the difference,
chooses a unit from seconds to years, and formats the result with `Intl.RelativeTimeFormat`.

The formatter renders text only. Wrap it in the surrounding markup that explains the value. When the value represents a
timestamp, use a semantic `<time>` element with its exact ISO value in `dateTime`.

## Short format

Set `style="short"` when space is limited, such as in a compact status row. `style="narrow"` produces the shortest
form when the surrounding interface already makes the meaning clear. Keep the exact timestamp available through
`dateTime` when people may need to inspect it.

`Format.RelativeTime` accepts all standard `Intl.RelativeTimeFormatOptions` in addition to `value`:

| Option          | Values                                                   | Purpose                                      |
| --------------- | -------------------------------------------------------- | -------------------------------------------- |
| `localeMatcher` | `"best fit"` (default), `"lookup"`                    | Choose the locale matching algorithm.       |
| `numeric`       | `"always"` (default), `"auto"`                          | Use numbers or natural words where possible. |
| `style`         | `"long"` (default), `"short"`, `"narrow"`              | Control the length of the result.            |

The unit and numeric distance are derived from the `Date`; you do not pass them separately.

## Updating over time

`Format.RelativeTime` calculates its text during render and does not start a timer. A label such as “2 minutes ago”
stays unchanged until your application renders it again. Schedule updates in application state at a cadence that fits
the interface. For a continuously updating duration or countdown, use [`Timer`](/docs/timer).
