Use `Clipboard` when users need to copy a text value. The value can be editable, read-only, or
rendered as ordinary text, depending on which parts you use.

## Basic

Use `Clipboard` to show a value that users can copy. Add `Clipboard.Input` when users should see
the value in a field, and set `readOnly` when they should not edit it. `Clipboard.Trigger` is the
copy button. `Clipboard.Indicator` and `Clipboard.CopyText` provide the default icon and text for
the idle and copied states.

## Anatomy

```text
Clipboard | Clipboard.RootProvider
├─ Clipboard.Label (optional)
├─ Clipboard.Control
│  ├─ Clipboard.Input or Clipboard.ValueText
│  └─ Clipboard.Trigger
│     ├─ Clipboard.Indicator (optional)
│     └─ Clipboard.CopyText (optional)
```

| Part | Role |
| --- | --- |
| `Clipboard` | Owns the value and the temporary copied state. |
| `Clipboard.RootProvider` | Connects the parts to a store created with `Clipboard.useClipboard()`. |
| `Clipboard.Label` | Provides an accessible label for the value. |
| `Clipboard.Control` | Groups the value surface and the copy button. |
| `Clipboard.Input` | Renders the value in an input. It is editable unless you set `readOnly`. |
| `Clipboard.Trigger` | Copies the current value when activated. It renders a button by default. |
| `Clipboard.Indicator` | Shows different content for the idle and copied states. |
| `Clipboard.CopyText` | A text convenience for the same states. Its defaults are `Copy` and `Copied`. |
| `Clipboard.ValueText` | Renders the value as text when an input is not the right surface. |

## Composition

### Recommended composition

Use the short `<Clipboard>` root in most cases. Compose it from `Clipboard.Label`,
`Clipboard.Control`, `Clipboard.Input`, and `Clipboard.Trigger`. Add `Clipboard.Indicator` for an
icon, `Clipboard.CopyText` for a status label, or both.

The Ark root props pass through unchanged. Use `defaultValue` for an uncontrolled value, `value`
with `onValueChange(details)` for a controlled value, and `onStatusChange(details)` to observe the
copied state. `timeout` controls how long that state remains active, and `ids` lets you provide
stable ids for the parts.

`Clipboard.Indicator` and `Clipboard.CopyText` are optional conveniences. When you do not provide
their content, moduix renders its copy and check icons and the `Copy` and `Copied` labels.

### When to use another composition

Use `Clipboard.ValueText` when the value belongs in running text or a compact text-only layout
rather than an input field.

Use `Clipboard.useClipboard()` with `Clipboard.RootProvider` when the store must be created or
shared separately from the rendered component tree. Descendants can read it through
`Clipboard.Context` or `useClipboardContext()`.

Use `asChild` on `Clipboard.Input` or `Clipboard.Trigger` only when another semantic element should
own the rendered DOM node. For example, you can provide a moduix `Input` or `Button` while keeping
the Clipboard parts explicit in the markup.

### Default props

| Prop | Default | Notes |
| --- | --- | --- |
| `timeout` | `3000` | Duration of the copied state, in milliseconds. |
| `Indicator.children` | not set | Uses moduix `CopyIcon` while idle. |
| `Indicator.copied` | not set | Uses moduix `CheckIcon` while copied. |
| `CopyText.children` | `Copy` | Text shown before copying. |
| `CopyText.copied` | `Copied` | Text shown while the copied state is active. |

### Behavioral notes

- `onValueChange(details)` provides the new value as `details.value`.
- `onStatusChange(details)` reports copied-state changes. Check `details.copied` when you need to
  update nearby UI, analytics, or a counter.
- Ark adds `data-copied` to `Root`, `Label`, `Control`, `Input`, and `Trigger` while the copied
  state is active. moduix does not change the input or trigger appearance by default, so you can
  use that attribute for your own styles.
- The root has no `disabled` prop. Pass the native `disabled` prop to both `Clipboard.Input` and
  `Clipboard.Trigger` when users should not be able to edit or copy the value.
- `Clipboard` does not limit its width by default. Set `--moduix-clipboard-max-width` when your
  layout needs a maximum width.
- If you are migrating from `CopyButton`, use the Clipboard parts instead. `copiedDuration`,
  `copyLabels`, `onCopy`, and `onCopyError` are not part of this API.

### Styling hooks

- `Clipboard` -> `data-slot="clipboard-root"`
- `Clipboard.RootProvider` -> `data-slot="clipboard-root-provider"`
- `Clipboard.Label` -> `data-slot="clipboard-label"`
- `Clipboard.Control` -> `data-slot="clipboard-control"`
- `Clipboard.Input` -> `data-slot="clipboard-input"`
- `Clipboard.Trigger` -> `data-slot="clipboard-trigger"`
- `Clipboard.Indicator` -> `data-slot="clipboard-indicator"`
- `Clipboard.CopyText` -> `data-slot="clipboard-copy-text"`
- `Clipboard.ValueText` -> `data-slot="clipboard-value-text"`
- Ark adds `data-copied` to `Root`, `Label`, `Control`, `Input`, and `Trigger` while the copied
  state is active.
- Ark adds `data-readonly` to `Clipboard.Input` when the input is read-only.
- `Clipboard.Indicator` adds `data-slot="clipboard-indicator-idle-icon"` and
  `data-slot="clipboard-indicator-copied-icon"` to its default icon nodes.
