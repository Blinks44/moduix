Use `Clipboard` as the root. Put one value surface, `ClipboardInput` or `ClipboardValueText`, and
`ClipboardTrigger` inside `ClipboardControl`. `ClipboardLabel` is optional. The trigger can contain
`ClipboardIndicator`, whose children and `copied` content accept text as well as icons in React and
Solid. In Vue, use its default and named `copied` slots for the same content.

## Choosing the right component

Use `Clipboard` when users need to copy a text value. The value can be rendered in a read-only
input or as ordinary text, depending on which parts you use.

## Composition

`Clipboard` owns the value and copied state. Keep one value surface (`ClipboardInput` or
`ClipboardValueText`) and `ClipboardTrigger` inside `ClipboardControl`; `ClipboardIndicator` is
optional in the trigger. It follows the same copied state, and moduix supplies the default
copy/check icons when its content is omitted. Pass `copied="Copied"` and children for text labels
in React and Solid; in Vue, use the default and named `copied` slots.

Use `defaultValue` for an uncontrolled value. When another part of the application owns the value
or needs to react to copying, use `value` with `onValueChange(details)` and
`onStatusChange(details)`; `timeout` controls how long the copied state remains active.

Use `useClipboard()` with `ClipboardRootProvider` only when the store must be created or
shared outside the rendered tree. Descendants can read that state through `ClipboardContext` or
`useClipboardContext()`. In Solid, `useClipboard()` returns an accessor, so pass it as
`value={clipboard}` and read state as `clipboard().copied` or `clipboard().value`. In Vue,
`useClipboard()` returns the reactive store directly, so pass it with `:value="clipboard"` and read
state as `clipboard.copied` or `clipboard.value`. The root has no disabled state: pass the native
`disabled` prop to both `ClipboardInput` and `ClipboardTrigger`.
Use `asChild` on those parts only when another semantic element should own the rendered DOM node.

## Anatomy

```text
Clipboard | ClipboardRootProvider
├─ ClipboardLabel (optional)
├─ ClipboardControl
│  ├─ ClipboardInput or ClipboardValueText
│  └─ ClipboardTrigger
│     └─ ClipboardIndicator (optional)
```

| Part | Role |
| --- | --- |
| `Clipboard` | Owns the value and the temporary copied state. |
| `ClipboardRootProvider` | Connects the parts to a store created with `useClipboard()`. |
| `ClipboardLabel` | Provides an accessible label for the value. |
| `ClipboardControl` | Groups the value surface and the copy button. |
| `ClipboardInput` | Renders the value in a read-only input. Use controlled state or `ClipboardContext.setValue()` to change it. |
| `ClipboardTrigger` | Copies the current value when activated. It renders a button by default. |
| `ClipboardIndicator` | Shows different content for the idle and copied states. Its defaults are the copy/check icons; pass `copied="Copied"` and children in React/Solid, or use the matching Vue slots. |
| `ClipboardValueText` | Renders the value as text when an input is not the right surface. |

## Styling

Use `className` in React or `class` in Solid and Vue on exported parts for structural styles. Tailwind
variants use native utilities and consumer classes; the CSS Modules variants use the CSS variables
below. For copied-state styles, use Ark's `data-copied` attribute together with moduix's
`data-slot` hooks.

### Styling hooks

| Part | `data-slot` |
| --- | --- |
| `Clipboard` | `clipboard-root` |
| `ClipboardRootProvider` | `clipboard-root-provider` |
| `ClipboardLabel` | `clipboard-label` |
| `ClipboardControl` | `clipboard-control` |
| `ClipboardInput` | `clipboard-input` |
| `ClipboardTrigger` | `clipboard-trigger` |
| `ClipboardIndicator` | `clipboard-indicator` |
| `ClipboardValueText` | `clipboard-value-text` |

- Ark adds `data-copied` to `Clipboard`, `ClipboardLabel`, `ClipboardControl`, `ClipboardInput`, and
  `ClipboardTrigger` while the copied state is active.
- Ark renders `ClipboardInput` read-only and adds `data-readonly` to it.
- `ClipboardIndicator` renders its default icon as a direct `svg` child.

## Keyboard

| Key | Action |
| --- | --- |
| `Tab` / `Shift+Tab` | Moves focus between the input and the trigger. |
| `Enter` / `Space` | Copies the value when the trigger has focus. |
