## Basic

Use `Clipboard` to present a value that users can copy. Add `Clipboard.Input` for the value and
`Clipboard.Trigger` for the copy button. `Clipboard.Indicator` and `Clipboard.CopyText` show the
current copy status with the default moduix icons and labels.

## Anatomy

```text
Clipboard | Clipboard.RootProvider
├─ Clipboard.Label (optional)
├─ Clipboard.Control
│  ├─ Clipboard.Input or Clipboard.ValueText
│  └─ Clipboard.Trigger
│     ├─ Clipboard.Indicator (optional)
│     └─ Clipboard.CopyText (optional)
```

| Part | Purpose |
| --- | --- |
| `Clipboard` | Holds the value and manages the copied state. |
| `Clipboard.RootProvider` | Supplies state created with `Clipboard.useClipboard()` outside the subtree. |
| `Clipboard.Label` | Gives the clipboard value an accessible label. |
| `Clipboard.Control` | Groups and lays out the value and copy button. |
| `Clipboard.Input` | Displays the current value in an editable or read-only field. |
| `Clipboard.Trigger` | Copies the current value when activated. |
| `Clipboard.Indicator` | Shows a copy or confirmation icon for the current status. |
| `Clipboard.CopyText` | Shows a status label. The defaults are `Copy` and `Copied`. |
| `Clipboard.ValueText` | Displays the value as text when a field is not appropriate. |

## Composition

### Recommended composition

For most cases, use `Clipboard`, `Clipboard.Label`, `Clipboard.Control`, `Clipboard.Input`,
`Clipboard.Trigger`, and `Clipboard.Indicator` together. This is the standard Ark composition and
keeps each part easy to customize.

`value`, `defaultValue`, `onValueChange(details)`, `onStatusChange(details)`, `timeout`, and `ids`
work exactly as they do in Ark. moduix keeps the original prop names and callback details.

`Clipboard.Indicator` and `Clipboard.CopyText` are optional conveniences. When you do not provide
their content, they render moduix copy and check icons and the `Copy` and `Copied` labels.

### When to customize

Use `Clipboard.ValueText` when the value should look like ordinary text instead of a text field.

Use `Clipboard.useClipboard()` with `Clipboard.RootProvider` when state must be created outside the
rendered subtree. Descendants can read it with `Clipboard.Context` or `useClipboardContext()`.

Use `asChild` on `Clipboard.Input` and `Clipboard.Trigger` to render another element, such as moduix
`Input` or `Button`. Keep the Ark parts in the markup so the component stays clear and accessible.

### Default props

| Prop | Default | Values / Notes |
| --- | --- | --- |
| `timeout` | `3000` | Duration of Ark's copied state, in milliseconds |
| `Indicator.copied` | - | Defaults to moduix `CheckIcon` |
| `Indicator.children` | - | Defaults to moduix `CopyIcon` |
| `CopyText.copied` | `Copied` | Label shown after a successful copy |
| `CopyText.children` | `Copy` | Label shown before copying |

### Behavioral notes

- `onValueChange(details)` provides the new value as `details.value`.
- Use `onStatusChange(details)` to update nearby UI, analytics, or a counter after a copy action.
- Ark adds `data-copied` while the copied state is active. moduix keeps the input and trigger
  unchanged by default, but you can use this attribute in custom styles.
- Ark has no disabled prop on the root. Pass native `disabled` to both `Clipboard.Input` and
  `Clipboard.Trigger` when users should not be able to edit or copy the value.
- `Clipboard` does not limit field width by default. Set `--moduix-clipboard-max-width` when your
  layout needs a maximum width.
- The legacy `CopyButton` API is unavailable. `Clipboard` does not support `copiedDuration`,
  `copyLabels`, `onCopy`, or `onCopyError`.

### Styling hooks

- `Clipboard` -> `data-slot="clipboard-root"`
- `Clipboard.RootProvider` -> `data-slot="clipboard-root-provider"`
- `Clipboard.Label` -> `data-slot="clipboard-label"`
- `Clipboard.Control` -> `data-slot="clipboard-control"`
- `Clipboard.Input` -> `data-slot="clipboard-input"`
- `Clipboard.Trigger` -> `data-slot="clipboard-trigger"`
- `Clipboard.Indicator` -> `data-slot="clipboard-indicator"`
- `Clipboard.CopyText` -> `data-slot="clipboard-copy-text"`
- `Clipboard.ValueText` -> `data-slot="clipboard-value-text"`
- Ark adds `data-copied` to `Root`, `Label`, `Control`, `Input`, and `Trigger` while copied state is active.
- Ark adds `data-readonly` to `Clipboard.Input` when the input is read-only.
- `Clipboard.Indicator` adds `data-slot="clipboard-indicator-idle-icon"` and
  `data-slot="clipboard-indicator-copied-icon"` to its default icon nodes.
