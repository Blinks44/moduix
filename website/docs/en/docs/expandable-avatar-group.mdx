## How it works

The group uses `Avatar.Image` with `Avatar.Fallback` as a loading fallback, and
`Tooltip.Trigger asChild` so each avatar remains a semantic button. The motion is CSS-only: the
active button lifts slightly while its following siblings make room for it. Replace the fixture
image URLs with your application's avatar source before shipping the recipe.

Keep the tooltip content short and non-essential. If selecting a member should navigate or perform
an action, replace the button with the appropriate semantic control and preserve its accessible
name.

Use `role="group"` with a useful label for the roster, and include each person's role in the
button's accessible name when the role helps users distinguish similar names. For a long team, show
only the first few members and a final `+N` control that opens a complete, searchable people list.
Keep the list order stable, and preserve the expanded spacing while removing lift and transition
effects under `prefers-reduced-motion: reduce`.
