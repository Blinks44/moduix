## Usage

Use `Skeleton` for text lines, cards, avatars, and media placeholders. The surrounding layout sets spacing and
responsive composition. See [Quick Start](/docs/quick-start) for package setup, registry configuration, and
choosing a styling track.

## Composition

`Skeleton` does not own loading state. The data or page region that makes the request passes `loading` and should
carry `aria-busy`; the placeholder itself is decorative. Set `loading={false}` (`:loading="false"` in Vue) to reveal children through the
same root element.

`Skeleton` is a single visual part, so compose cards, media rows, and responsive layouts with your own wrapper.
`Stack` is available in both styling tracks; Tailwind layouts can also use native flex and grid utilities.
Use `asChild` only when a different semantic root is required. Solid passes a render function to
`asChild`; Vue uses `as-child` with a single semantic element in the default slot.

## Styling

Use `className` in React or `class` in Solid or Vue for structural styles and consumer utility classes. Tailwind
variants use native utilities and consumer classes; CSS Modules variants expose the variables below. State
attributes and `data-slot` hooks are shared by both styling tracks.

### Styling hooks

| Part | `data-slot` |
| --- | --- |
| `Skeleton` | `skeleton-root` |

- `[data-scope="skeleton"][data-part="root"]` targets the exported root.
- `data-state="loading"` and `data-state="loaded"` reflect the `loading` prop.
- `data-variant="pulse"` and `data-variant="none"` reflect the variant.
- `data-loading` is present only while placeholder styles are active.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `loading` | `boolean` | `true` | Shows the placeholder; `false` reveals the children. |
| `variant` | `'pulse' \| 'none'` | `'pulse'` | Animation: `pulse` or `none`. |
| `width` | `number \| string` | — | Placeholder width; numbers are pixels. |
| `height` | `number \| string` | — | Placeholder height; numbers are pixels. |
| `boxSize` | `number \| string` | — | Sets width and height together. |
| `borderRadius` | `number \| string` | — | Corner radius, for example for a circular avatar placeholder. |
| `asChild` | `boolean` | `false` | Renders the placeholder as its single child element. |
