Ark UI does not ship a dedicated `Skeleton` primitive. moduix builds `Skeleton` with the official
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) and follows Ark's guidance for
[composition](https://ark-ui.com/docs/guides/composition), [styling](https://ark-ui.com/docs/guides/styling), and
[refs](https://ark-ui.com/docs/guides/ref).

## Anatomy

`Skeleton` is a single visual part. Keep layout in the surrounding markup.

```text
Skeleton.Root
└─ children (optional, shown when loading={false})
```

| Part                         | Role                                                                                        |
| ---------------------------- | ------------------------------------------------------------------------------------------- |
| `Skeleton` / `Skeleton.Root` | Placeholder block. Renders an Ark factory element and accepts `asChild` when you need a different semantic root element. |

## Composition

### Recommended composition

Use `Skeleton` directly for text lines, cards, avatars, and media placeholders. While `loading` is true,
it renders a decorative block. Set `loading={false}` to show children in the same root element.

The default variant is `pulse`, which animates the placeholder. Use `variant="none"` for a static
placeholder. The component also disables the animation when the user prefers reduced motion.

### When to go custom

Use `asChild` when the root should be a semantic element other than `div`. The child must be one
semantic element, as required by Ark's composition model.

Use `width`, `height`, `boxSize`, and `borderRadius` for common dimensions. For a more specialized
appearance, use `className`, `style`, or the public CSS variables.

### Default props

| Prop           | Default                                | Notes                                                                                                       |
| -------------- | -------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `loading`      | `true`                                 | Controls whether placeholder styles are active or children are shown normally.                              |
| `variant`      | `pulse`                                | Supports `pulse` and `none`.                                                                                |
| `height`       | `var(--moduix-spacing-4)` (while loading) | Loading CSS sets the default placeholder height. Loaded content uses natural height unless a height is set. |
| `width`        | `100%`                                 | CSS sets the default root width. Numeric prop values become `px`.                                           |
| `boxSize`      | Not set                              | Sets width and height together. An explicit `width` or `height` takes precedence on that axis.              |
| `borderRadius` | `var(--moduix-skeleton-border-radius, var(--moduix-radius-md))` | Numeric prop values become `px`; inline style overrides still win. |

### Behavioral notes

- `Skeleton.Root` is the same component as `Skeleton`, provided for namespace consistency.
- Refs are forwarded to the root element.
- `loading={true}` sets `aria-hidden`, `data-state="loading"`, and `data-loading` unless you explicitly set `aria-hidden`.
- `loading={false}` sets `data-state="loaded"` and lets children use their natural height unless `height`, `boxSize`, or `style.height` is set.
- `variant` is styling-only; no internal timers or state management are added.
- `Skeleton` is decorative and does not announce loading. Put `aria-busy` on the region that owns the loading state, or use `Spinner` when an inline status must be announced.

### Styling hooks

- `[data-scope="skeleton"][data-part="root"]` targets the exported root.
- `data-slot="skeleton-root"` is the stable moduix selector for the root.
- `data-state="loading"` and `data-state="loaded"` reflect the `loading` prop.
- `data-variant="pulse"` and `data-variant="none"` reflect the variant.
- `data-loading` is present only while placeholder styles are active.
