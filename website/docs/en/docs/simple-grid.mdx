## API Reference

`SimpleGrid` is not an Ark UI primitive. moduix provides it as a small layout wrapper built with
Ark's factory. It follows Ark's guidance for [composition](https://ark-ui.com/docs/guides/composition),
[styling](https://ark-ui.com/docs/guides/styling), and [refs](https://ark-ui.com/docs/guides/ref).
Its `columns` and `minChildWidth` props borrow the layout model from Chakra UI
[SimpleGrid](https://chakra-ui.com/docs/components/simple-grid), but moduix does not include Chakra's
responsive style props.

## Basic


Use `minChildWidth` when the number of equal columns should follow the available width. The component
uses CSS Grid `auto-fit` and `minmax()`; numeric values are treated as pixels, while strings can
contain any valid CSS length.

The number of columns changes with the root width, and the children remain direct grid items. If a
child contains unbreakable content, add `min-width: 0` or an appropriate overflow rule to that child.

## Anatomy

`SimpleGrid` renders one CSS Grid root and does not add wrappers around its children.

```text
SimpleGrid
└─ root[data-scope="simple-grid"][data-part="root"][data-slot="simple-grid-root"]
   └─ children
```

| Part         | Role                                                   |
| ------------ | ------------------------------------------------------ |
| `SimpleGrid` | Root wrapper that creates equal-width CSS Grid columns. |

## Composition

Use the short `<SimpleGrid>` form for the root; `SimpleGrid.Root` is an equivalent compatibility
alias. Choose either `minChildWidth` for an intrinsic column count or `columns` for a fixed count.
If both are provided, `minChildWidth` takes priority.

Use `asChild` when the grid root should be a semantic element such as `ul`, `section`, or `nav`.
It requires exactly one element child, which becomes the rendered root. In React, pass `asChild` as
a boolean; in Solid, use its render-function form to return that element. For named grid areas,
unequal tracks, or items that span tracks, omit both layout props and define the grid template in
your own CSS; this works in the Tailwind variants, while the CSS Modules packages override
`grid-template-columns` per instance through the `style` prop because the root always writes an
inline one-column fallback.

## Styling

`SimpleGrid` does not define component-specific CSS variables. Its layout props are written as
inline styles on the rendered root. In the Tailwind variants, the root has no inline
`grid-template-columns`, so you can omit `columns` and `minChildWidth` and let your stylesheet or
`grid-cols-*` utilities own the template. In the CSS Modules packages, the root always writes an
inline `grid-template-columns` (the one-column fallback), and inline styles beat any consumer class,
so pass custom templates per instance through the `style` prop.

Use `className` in React or `class` in Solid for structural styles. Tailwind variants use native
utility classes and consumer class overrides; the data attributes and `data-slot` hook are shared by
both styling tracks.

### Styling hooks

- `className` or `class` styles the rendered root for width, placement, and backgrounds; responsive
  `grid-template-columns` overrides go through `grid-cols-*` utilities in the Tailwind variants and
  through `style` in the CSS Modules packages.
- `data-scope="simple-grid"` and `data-part="root"` follow Ark's styling conventions.
- `data-slot="simple-grid-root"` is the stable moduix selector for local CSS.
- `columns`, `minChildWidth`, `gap`, `rowGap`, and `columnGap` write inline styles and take priority
  over declarations from consumer classes.
- `style` is merged after those props and is the final per-instance override.
- The component exposes no state or animation styling hooks.
