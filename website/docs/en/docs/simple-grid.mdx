## API Reference

`SimpleGrid` is not an Ark UI primitive. moduix provides it as a small layout wrapper built with
Ark's factory. It follows Ark's guidance for [composition](https://ark-ui.com/docs/guides/composition),
[styling](https://ark-ui.com/docs/guides/styling), and [refs](https://ark-ui.com/docs/guides/ref).
Its `columns` and `minChildWidth` props borrow the layout model from Chakra UI
[SimpleGrid](https://chakra-ui.com/docs/components/simple-grid), but moduix does not include Chakra's
responsive style props.

## Basic

Import `SimpleGrid` from `@moduix/react/simple-grid`. Use `minChildWidth` when the number of equal
columns should follow the available width. The component uses CSS Grid `auto-fit` and `minmax()`;
numeric values are treated as pixels, while strings can contain any valid CSS length.

The number of columns changes with the root width, and the children remain direct grid items. If a
child contains unbreakable content, add `min-width: 0` or an appropriate overflow rule to that child.

## Anatomy

`SimpleGrid` renders one CSS Grid root and does not add wrappers around its children.

```text
SimpleGrid
└─ root[data-scope="simple-grid"][data-part="root"][data-slot="simple-grid-root"]
   └─ children
```

| Part         | Role                                                   |
| ------------ | ------------------------------------------------------ |
| `SimpleGrid` | Root wrapper that creates equal-width CSS Grid columns. |

## Composition

### Recommended composition

Use the short `<SimpleGrid>` form for the root. `SimpleGrid.Root` renders the same component and is
kept as a compatibility alias.

Choose one layout mode:

- `minChildWidth` lets the browser fit as many equal columns as the available width allows.
- `columns` creates an exact number of equal columns.

If the items need visual separation, set `gap`, `rowGap`, or `columnGap`. Use `asChild` when the
root should be a semantic element such as `ul`, `section`, or `nav`. `asChild` requires exactly one
element child, which becomes the rendered root.

### When to go custom

Use local CSS when the layout needs named grid areas, unequal tracks, items that span tracks, or
different templates at media or container query breakpoints. Leave both `columns` and
`minChildWidth` unset, then define `grid-template-columns` in the stylesheet.

### Default props

| Prop            | Default         | Notes                                                    |
| --------------- | --------------- | -------------------------------------------------------- |
| `columns`       | `1`             | Finite positive integer for equal-width columns          |
| `minChildWidth` | not set         | CSS length; numbers are treated as pixels                |
| `gap`           | browser default | CSS length; numbers are treated as pixels                |
| `rowGap`        | browser default | CSS length; numbers are treated as pixels                |
| `columnGap`     | browser default | CSS length; numbers are treated as pixels                |
| `asChild`       | `false`         | Renders the root through Ark's single-child composition |
| `className`     | not set         | Applied to the rendered root                             |
| `style`         | not set         | Applied last as the per-instance override                |

### Behavioral notes

- If neither `columns` nor `minChildWidth` is set, the grid has one equal-width column.
- If both layout props are set, `minChildWidth` takes priority over `columns`.
- `columns={3}` creates three equal tracks without wrapping the children.
- `minChildWidth={160}` creates as many tracks as fit and treats the number as `160px`.
- A numeric `columns` value must be a finite positive integer. A numeric `minChildWidth` value must
  be finite and non-negative.
- The `auto-fit` mode guards against overflow when the grid is narrower than `minChildWidth`.
- `gap`, `rowGap`, and `columnGap` are written to inline styles only when provided.
- `style` is applied last and can override any generated style, including `display`,
  `gridTemplateColumns`, and the gaps.
- `ref` targets the rendered root. With `asChild`, it targets the single child element.
- The component adds no roles, labels, keyboard behavior, focus management, state, or provider
  context. Choose semantic children in your own markup.

## Styling

`SimpleGrid` does not define component-specific CSS variables. Its layout props are written as
inline styles on the rendered root, so omit `columns` and `minChildWidth` when the stylesheet should
own `grid-template-columns`.

### Styling hooks

- `className` styles the rendered root for width, placement, backgrounds, and responsive layout.
- `data-scope="simple-grid"` and `data-part="root"` follow Ark's styling conventions.
- `data-slot="simple-grid-root"` is the stable moduix selector for local CSS.
- `columns`, `minChildWidth`, `gap`, `rowGap`, and `columnGap` write inline styles and take priority
  over declarations from `className`.
- `style` is merged after those props and is the final per-instance override.
- The component exposes no state or animation styling hooks.
