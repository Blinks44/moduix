## Usage

<Usage />

Use the short `Marquee` root and compose `MarqueeViewport`, `MarqueeContent`, and `MarqueeItem` inside it. Add
`aria-label` or `translations.root` when the moving content conveys information. `Marquee`
provides the behavior and required animation styles, but it does not style individual items or add a
frame. The example styles its items and limits the root width separately.

## Examples

### Speed

Control motion with `speed`, measured in pixels per second. Lower values are easier to read.

<Example name="marquee/speed" />

### Reverse

Use `reverse` when the content should move opposite the configured side without changing
orientation.

<Example name="marquee/reverse" />

### Vertical

Set `side="top"` or `side="bottom"` for vertical marquees. A vertical root is `15rem` tall by
default so the viewport has a stable block size; set `height` with a class to change it.

<Example name="marquee/vertical" />

### Auto fill

Use `autoFill` when the available content is shorter than the viewport. `spacing` controls the gap
between duplicated content instances.

<Example name="marquee/auto-fill" />

### Edge fades

Add `MarqueeEdge` on the sides that should fade into the page background. The edge part is
decorative and does not receive pointer events.

<Example name="marquee/edges" />

### Pause on interaction

Use `pauseOnInteraction` to pause while the user hovers the marquee or focuses content inside it.

Marquees move continuously, so screen reader users cannot reliably read content in motion and
motion itself can be distracting or harmful. Treat marquee content as non-essential: give the
marquee a descriptive label, provide a way to pause it (`pauseOnInteraction` or explicit pause
and resume controls), and never put critical information only inside a marquee.

<Example name="marquee/pause-on-interaction" />

### Finite loops

Set `loopCount` for finite playback. `onLoopComplete` fires after each loop and `onComplete` fires
after the final loop.

<Example name="marquee/finite-loops" />

### Right to left

Wrap the marquee in `LocaleProvider` with an RTL locale. Logical `start` and `end` edges then follow
the configured direction.

<Example name="marquee/rtl" />

### Root provider

Use moduix `useMarquee()` with `MarqueeRootProvider` when external controls need to pause, resume,
or restart playback.

<Example name="marquee/programmatic-control" />

## Composition

Use `Marquee` with its explicit `MarqueeViewport`, `MarqueeContent`, and `MarqueeItem` parts. Add `MarqueeEdge` inside the
same root when the content should fade into the page background; each edge needs a `side`.

Use `defaultPaused` for an uncontrolled initial state. If another part of the application controls playback,
use `paused` with `onPauseChange(details)`. For controls outside the marquee tree, create state with
`useMarquee()` and pass it to `MarqueeRootProvider`; do not render `Marquee` and `MarqueeRootProvider` for the
same state. Controls inside the tree can read the current API from `MarqueeContext` or
`useMarqueeContext()`.

## Styling

Marquee includes the keyframes required to animate its content. Use Ark state attributes for
behavioral styles and pick the customization model of your registry variant:

- CSS Modules variants: use `--moduix-marquee-edge-color` and `--moduix-marquee-edge-size` for edge
  fades, and `className` (React) or `class` (Solid, Vue, and Svelte) for size, color, and item styles.
- Tailwind variants: use `className` (React) or `class` (Solid, Vue, and Svelte) with Tailwind utilities for the
  same aspects. Marquee exposes no CSS-variable API in Tailwind packages.

`Marquee` is transparent by default, inherits the text color, and adds no border, background, padding, or radius. Add a framed
surface in your own CSS when you need one.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `speed` | `number` | `50` | Scroll speed in pixels per second. |
| `side` | `'start' \| 'end' \| 'top' \| 'bottom'` | `'start'` | Direction the content moves towards: `start`, `end`, `top`, or `bottom`. |
| `spacing` | `string` | `'1rem'` | Gap between repeated items, as a CSS length. |
| `autoFill` | `boolean` | `false` | Duplicates the content until it fills the container. |
| `reverse` | `boolean` | `false` | Reverses the animation direction. |
| `pauseOnInteraction` | `boolean` | `false` | Pauses on hover and focus. |
| `paused` | `boolean` | — | Paused state for controlled use. |
| `defaultPaused` | `boolean` | `false` | Initial paused state when it is not controlled. |
| `delay` | `number` | `0` | Delay before the animation starts, in seconds. |
| `loopCount` | `number` | `0` | Number of loops; `0` repeats forever. |
| `onPauseChange` | `(details: PauseStatusDetails) => void` | — | Called when the marquee pauses or resumes. |
| `onComplete` | `() => void` | — | Called after the last loop when `loopCount` is set. |
| `translations` | `IntlTranslations` | — | Localized strings for accessibility labels. |
| `onLoopComplete` | `() => void` | — | Called after each loop. |
