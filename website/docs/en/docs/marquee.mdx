## Basic

Marquee ships for React and Solid in both the CSS Modules and Tailwind packages. The rendered
preview on this page uses the React CSS Modules package; the framework tabs show native source for
the same public contract.

Use the short `Marquee` root and compose `Viewport`, `Content`, and `Item` inside it. Add
`aria-label` or `translations.root` when the moving content conveys information. `Marquee`
provides the behavior and required animation styles, but it does not style individual items or add a
frame. The example styles its items and limits the root width separately.

## Anatomy

```text
Marquee / Marquee.Root
├─ Marquee.Edge (optional)
├─ Marquee.Viewport
│  └─ Marquee.Content
│     └─ Marquee.Item
└─ Marquee.Edge (optional)

Marquee.RootProvider
└─ same part tree connected to moduix useMarquee()
```

| Part                       | Role                                                                  |
| -------------------------- | --------------------------------------------------------------------- |
| `Marquee` / `Marquee.Root` | Root state, labels, ids, orientation, pause state, and CSS variables. |
| `Marquee.RootProvider`     | Renders a marquee tree from state returned by `useMarquee`.           |
| `Marquee.Viewport`         | Clipping viewport for the scrolling content.                          |
| `Marquee.Content`          | Animated content wrapper. Ark clones it when needed.                  |
| `Marquee.Item`             | Individual repeated item inside the content.                          |
| `Marquee.Edge`             | Optional fade overlay. Pass `side` to choose the edge.                |
| `Marquee.Context`          | Advanced access to the context of the enclosing marquee.              |

## Composition

Use `Marquee` with its explicit `Viewport`, `Content`, and `Item` parts. Add `Marquee.Edge` inside the
same root when the content should fade into the page background; each edge needs a `side`.

Use `defaultPaused` for an uncontrolled initial state. If another part of the application owns playback,
use `paused` with `onPauseChange(details)`. For controls outside the marquee tree, create state with
`useMarquee()` and pass it to `Marquee.RootProvider`; do not render `Marquee` and `RootProvider` for the
same state. Controls inside the tree can read the current API from `Marquee.Context` or
`useMarqueeContext()`.

## Styling

Marquee includes the keyframes required to animate its content. Use `className` for layout and item
styles, CSS variables for dimensions, color, spacing, and edge fades, and Ark state attributes for
behavioral styles.

`Marquee` is transparent by default and adds no border, background, padding, or radius. Add a framed
surface in your own CSS when you need one.

### Styling hooks

- `data-slot="marquee-root"`, `marquee-root-provider`, `marquee-viewport`, `marquee-content`,
  `marquee-item`, and `marquee-edge`.
- Ark hooks: `data-scope="marquee"`, `data-part="root|viewport|content|item|edge"`,
  `data-state="paused|idle"`, `data-orientation`, `data-side`, `data-index`, `data-paused`,
  `data-reverse`, and `data-clone`.
- Ark CSS variables: `--marquee-duration`, `--marquee-spacing`, `--marquee-delay`,
  `--marquee-loop-count`, and `--marquee-translate`.
