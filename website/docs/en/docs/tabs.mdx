Start with `Tabs` and give each `TabsTrigger` and `TabsContent` the same `value`. Render
`TabsIndicator` explicitly when you want a visual marker for the selected tab.

## Choosing the right component

Use `Tabs` to switch between related views in one page region. Selecting a tab shows its matching
content panel and hides the other panels.

- Choose **`Tabs`** when each tab should reveal one associated content panel.
- Choose **`Accordion`** when sections should stay stacked and open independently.
- Choose **`ToggleGroup`** when the control changes a state or mode without owning panel content.

## Composition

Use `defaultValue` for an uncontrolled component. When another part of the application owns the
selection, pass `value` and `onValueChange(details)` and read the selected value from
`details.value`.

In Vue, use `v-model` for controlled selection and `@value-change` to receive the same details
object. `TabsContext` exposes that state through its default scoped slot.

Use `TabsRootProvider` with `useTabs()` when the state must be created outside the rendered tree
or shared with adjacent UI. Pass the store to `TabsRootProvider` and do not render another `Tabs` root
for the same state. Use `asChild` on `TabsTrigger` for a link or router component, and render
`TabsIndicator` explicitly because `TabsList` does not add one automatically.

## Styling

Use `className` in React or `class` in Solid and Vue on exported parts for structural styles. For state-based
styles, prefer Ark data attributes such as `data-selected`, `data-disabled`, and `data-orientation`,
together with moduix `data-slot` selectors. Tailwind variants use native utilities and consumer
classes; the variables below customize the CSS Modules variants.

### Styling hooks

| Part | `data-slot` |
| --- | --- |
| `Tabs` | `tabs-root` |
| `TabsRootProvider` | `tabs-root-provider` |
| `TabsList` | `tabs-list` |
| `TabsTrigger` | `tabs-trigger` |
| `TabsIndicator` | `tabs-indicator` |
| `TabsContent` | `tabs-content` |

Target the part that owns the visual concern:

- `Tabs` for layout width, overall gap, orientation, and variant-level overrides
- `TabsList` for list chrome, borders, background, and indicator-container spacing
- `TabsTrigger` for label layout, icon spacing, selected and disabled states, and focus styling
- `TabsIndicator` for custom indicator color, size, and transitions; set Ark
  `--transition-duration` and `--transition-timing-function` on it to change the movement
- `TabsContent` for the panel surface, padding, and focus styling

Useful Ark hooks include `data-scope="tabs"`, `data-part`, `data-orientation`, `data-selected`,
`data-disabled`, `data-focus`, and the indicator variables `--left`, `--top`, `--width`,
`--height`, and `--transition-property`.

## Keyboard

| Key | Action |
| --- | --- |
| `ArrowLeft` / `ArrowRight` | Moves to the previous or next tab; ArrowUp and ArrowDown when vertical. |
| `Home` / `End` | Moves to the first or last tab. |
| `Enter` / `Space` | Selects the focused tab when activationMode is manual. |
| `Tab` | Moves focus from the tab list into the active panel. |
