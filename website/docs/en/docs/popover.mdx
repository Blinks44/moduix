## Usage

<Usage />

Use `Popover` as the root and import each additional part directly, such as `PopoverTrigger` and
`PopoverContent`. The same flat names work with npm packages and shadcn registry source. Set
positioning on the root and use `asChild` when your own button should render the trigger.

## Choosing the right component

Use `Popover` for compact interactive content that opens from a trigger. Use `Tooltip` for short,
non-interactive hints. Use `Dialog` for larger workflows that need the user's full attention.

## Composition

Keep `PopoverPositioner` and `PopoverContent` explicit so the overlay structure stays easy to
style. `PopoverPositioner` is portalled by default. Set `portalled={false}` for an inline overlay, or pass
`portalRef` for a custom portal container. With `PopoverRootProvider`, configure `portalled` in
`usePopover()` and pass the store to the provider. Do not render `Popover` and
`PopoverRootProvider` for the same store.

Use `PopoverAnchor` when another element should determine positioning. Use `asChild` with one semantic
child when your own element should render a trigger, anchor, or close trigger. For nested popovers,
set `portalled={false}` on the nested root so it stays inside the parent overlay. When several
triggers share one popover, give each trigger a `value` and update the surrounding content from
`onTriggerValueChange(details)`.

## Styling

`PopoverTrigger` and `PopoverCloseTrigger` without `asChild` render as outlined buttons.
`PopoverContent` is 16–28rem wide and at most 24rem tall within the available viewport space; with a
direct `PopoverBody` child, the body scrolls. `PopoverBody` is spaced from a preceding
`PopoverHeader`, and `PopoverFooter` from the content above it. Content motion reads the shared
`--moduix-popup-motion-*` variables.

Use `className` in React or `class` in Solid, Vue, and Svelte on exported parts. Tailwind variants use native
utilities and consumer classes. CSS Modules variants build on foundation tokens and have no component
variables: a class on the part overrides the layered component styles. Data attributes and
`data-slot` hooks are shared by both styling tracks.

| `PopoverCloseTrigger` | `popover-close-trigger` |

| `PopoverHeader` | `popover-header` |

| `PopoverFooter` | `popover-footer` |

Every rendered part accepts `className` or `class`. Ark parts retain `data-scope="popover"` and
their `data-part` values, while moduix adds `data-slot="popover-*"` to rendered wrappers. `Popover`
and `PopoverRootProvider` provide state but do not render DOM elements. For state-aware styling,
target `data-state="open|closed"`, `data-placement`, `data-side`, `data-value`, `data-nested`,
`data-has-nested`, `data-expanded`, and `data-current` when several valued triggers share one
popover.

`PopoverPositioner` exposes `--reference-width`, `--reference-height`, `--available-width`,
`--available-height`, `--x`, `--y`, `--z-index`, and `--transform-origin`. `PopoverContent` exposes
`--layer-index` and `--nested-layer-count`. `PopoverArrow` exposes Ark's arrow measurement variables. Content wraps long unbroken strings and disables its motion when the user prefers reduced motion.

## Keyboard

| Key | Action |
| --- | --- |
| `Enter` / `Space` | Opens or closes the popover from the trigger. |
| `Tab` / `Shift+Tab` | Moves through the content; leaving it closes a non-modal popover. |
| `Esc` | Closes it and returns focus to the trigger. |

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | — | Open state for controlled use. |
| `defaultOpen` | `boolean` | `false` | Initial open state when it is not controlled. |
| `onOpenChange` | `(details: OpenChangeDetails) => void` | — | Called when it opens or closes. |
| `positioning` | `PositioningOptions` | — | Placement, offset, and other popup positioning options. |
| `modal` | `boolean` | `false` | Traps focus, blocks outside interaction, and locks page scroll. |
| `autoFocus` | `boolean` | `true` | Moves focus to the first focusable element on open. |
| `closeOnEscape` | `boolean` | `true` | Closes on Escape. |
| `closeOnInteractOutside` | `boolean` | `true` | Closes on a click outside. |
| `initialFocusEl` | `() => HTMLElement \| null \| false` | — | Returns the element to focus on open. |
| `portalled` | `boolean` | `true` | Renders the popup in a portal at the end of `body`. |
| `lazyMount` | `boolean` | `true` | Mounts the content on first open. |
| `unmountOnExit` | `boolean` | `true` | Unmounts the content after it closes. |
| `translations` | `IntlTranslations` | — | Localized strings for accessibility labels. |
| `finalFocusEl` | `() => MaybeElement` | — | Returns the element to focus on close. |
| `restoreFocus` | `boolean` | `true` | Returns focus to the previously focused element on close. |
| `triggerValue` | `string \| null` | — | Active trigger for controlled use when several triggers share one popup. |
| `defaultTriggerValue` | `string \| null` | — | Initially active trigger. |
| `onTriggerValueChange` | `(details: TriggerValueChangeDetails) => void` | — | Called when another trigger becomes active. |
