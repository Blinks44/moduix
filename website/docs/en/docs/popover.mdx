## Choosing the right component

Use `Popover` for compact interactive content that opens from a trigger. Use `Tooltip` for short,
non-interactive hints. Use `Dialog` for larger workflows that need the user's full attention.

## Anatomy

```text
Popover / Popover.Root
├─ Popover.Anchor (optional)
├─ Popover.Trigger
│  └─ Popover.Indicator (optional)
└─ Overlay subtree (automatically rendered in a portal)
   └─ Popover.Positioner
      └─ Popover.Content
         ├─ Popover.Arrow
         │  └─ Popover.ArrowTip
         ├─ Popover.Header
         │  ├─ Popover.Title
         │  └─ Popover.Description
         ├─ Popover.Body
         ├─ Popover.Footer
         └─ Popover.CloseTrigger / Popover.CloseIcon

Popover.RootProvider
└─ the same part tree connected to state from moduix usePopover()

Popover.Context
└─ a render prop with the current popover state
```

| Part                         | Role                                                                  |
| ---------------------------- | --------------------------------------------------------------------- |
| `Popover` / `Popover.Root`   | Owns state, opening and closing, focus, dismissal, and positioning.    |
| `Popover.RootProvider`       | Connects the parts to state created with `usePopover()`.              |
| `Popover.Context`            | Exposes current state through a render prop for descendants.          |
| `Popover.Anchor`             | Optional reference element used for positioning.                      |
| `Popover.Trigger`            | Button that toggles the popover and can have a trigger `value`.       |
| `Popover.Indicator`           | Optional indicator for the trigger's state.                            |
| `Popover.Positioner`         | Floating layer that exposes Ark positioning CSS variables.             |
| `Popover.Content`             | Visible interactive popover surface.                                   |
| `Popover.Arrow` / `ArrowTip` | Optional positioned arrow and its visible tip.                        |
| `Popover.Title`               | Accessible title associated with the content.                          |
| `Popover.Description`         | Accessible description associated with the content.                    |
| `Popover.CloseTrigger`        | Low-level trigger that closes the popover.                             |
| `Popover.CloseIcon`            | Moduix helper that combines Ark's close trigger with an icon button.   |
| `Popover.Header` / `Body`      | Moduix layout helpers with stable slots.                               |
| `Popover.Footer`               | Moduix action-row helper with a stable slot.                            |

Use the short `Popover` root form in application code. `Popover.Root` remains available when the
explicit Ark name makes the composition easier to read.

## Composition

Keep `Popover.Positioner` and `Popover.Content` explicit so the overlay structure stays easy to
style. `Positioner` is portalled by default. Set `portalled={false}` for an inline overlay, or pass
`portalRef` for a custom portal container. With `Popover.RootProvider`, configure `portalled` in
`usePopover()` and pass the store to the provider. Do not render `Popover` or `Popover.Root` for the
same store.

Use `Anchor` when another element should determine positioning. Use `asChild` with one semantic
child when your own element should render a trigger, anchor, or close trigger. For nested popovers,
set `portalled={false}` on the nested root so it stays inside the parent overlay. When several
triggers share one popover, give each trigger a `value` and update the surrounding content from
`onTriggerValueChange(details)`.

## Styling

Use `className` in React or `class` in Solid on exported parts for structural styles. Tailwind
variants use native utilities and consumer classes. The CSS variables below customize the CSS
Modules variants, while Ark data attributes and moduix `data-slot` hooks are shared by both styling
tracks.

### Styling hooks

Every rendered part accepts `className` or `class`. Ark parts retain `data-scope="popover"` and
their `data-part` values, while moduix adds `data-slot="popover-*"` to rendered wrappers. `Popover`
and `Popover.RootProvider` provide state but do not render DOM elements. For state-aware styling,
target `data-state="open|closed"`, `data-placement`, `data-side`, `data-value`, `data-nested`,
`data-has-nested`, `data-expanded`, and `data-current` when several valued triggers share one
popover.

`Positioner` exposes `--reference-width`, `--reference-height`, `--available-width`,
`--available-height`, `--x`, `--y`, `--z-index`, and `--transform-origin`. `Content` exposes
`--layer-index` and `--nested-layer-count`. `Arrow` exposes Ark's arrow measurement variables.
Content wraps long unbroken strings and disables its motion when the user prefers reduced motion.
