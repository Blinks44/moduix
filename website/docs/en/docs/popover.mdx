## Choosing the right component

Use `Popover` for compact interactive content associated with a trigger. Use `Tooltip` for
non-interactive hints and `Dialog` for larger workflows that need to interrupt the current task.

## Basic

Keep the Ark parts explicit. Set positioning on `Popover`, and use `asChild` when a custom button
should act as the trigger.

## Anatomy

```text
Popover / Popover.Root
├─ Popover.Anchor (optional)
├─ Popover.Trigger
│  └─ Popover.Indicator (optional)
└─ Overlay subtree (automatically portalled)
   └─ Popover.Positioner
      └─ Popover.Content
         ├─ Popover.Arrow
         │  └─ Popover.ArrowTip
         ├─ Popover.Header
         │  ├─ Popover.Title
         │  └─ Popover.Description
         ├─ Popover.Body
         ├─ Popover.Footer
         └─ Popover.CloseTrigger / Popover.CloseIcon
```

| Part                         | Role                                                             |
| ---------------------------- | ---------------------------------------------------------------- |
| `Popover` / `Popover.Root`   | Manages state, the open/close lifecycle, dismissal, focus, and positioning. |
| `Popover.RootProvider`       | Renders a popover tree from the state returned by `usePopover`.       |
| `Popover.Context`            | Reads current state through a render prop on a descendant.           |
| `Popover.Anchor`             | Optional custom positioning reference.                           |
| `Popover.Trigger`            | Button that toggles the popover and can have a trigger `value`.  |
| `Popover.Indicator`          | Optional trigger state indicator.                                |
| `Popover.Positioner`         | Floating layer that exposes Ark positioning CSS variables.       |
| `Popover.Content`            | Interactive popover surface.                                     |
| `Popover.Arrow` / `ArrowTip` | Optional positioned arrow and visible tip.                       |
| `Popover.Title`              | Accessible title associated with the content.                     |
| `Popover.Description`        | Accessible description associated with the content.               |
| `Popover.CloseTrigger`       | Low-level trigger that dismisses the popover.                     |
| `Popover.CloseIcon`          | Shared icon-only close button built on Ark's close trigger.       |
| `Popover.Header` / `Body`    | moduix layout wrappers with stable slots.                        |
| `Popover.Footer`             | moduix action row wrapper with stable slot.                      |

## Composition

The root automatically renders `Positioner` in a portal. Use `portalled={false}` to render it in the
current container, or `portalRef` to choose a custom portal container. Structural parts remain
explicit and can be styled.

### Recommended composition

Keep `Popover.Positioner` and `Popover.Content` explicit. `Popover` is an alias for
`Popover.Root`. Configure placement, collision handling, and offsets through `positioning`. Set
`positioning.sameWidth` to match the popover's width to its reference.

### When to go custom

Use `Anchor` when the positioning reference differs from the trigger. Use `asChild` with exactly one
semantic child when you want your own element to render the trigger, anchor, content, or close
trigger. Set `portalled={false}` when a popover inside another overlay should render in place. Use
`lazyMount` and `unmountOnExit` only when deferred mounting and removal after the exit animation are
useful.

### Default props

By default, portalled overlay content mounts on first open and unmounts after its exit animation.
Set `unmountOnExit={false}` to keep it mounted after the first open. Set both lifecycle props to
`false` only when the content must render from the start.

| Prop                     | Default | Notes                                                        |
| ------------------------ | ------- | ------------------------------------------------------------ |
| `autoFocus`              | `true`  | Moves focus to the first focusable element when the popover opens. |
| `closeOnEscape`          | `true`  | Closes the popover when the user presses Escape.              |
| `closeOnInteractOutside` | `true`  | Closes the popover when the user interacts outside it.        |
| `lazyMount`              | `true`  | Defers popup content mounting until first open.              |
| `modal`                  | `false` | Enables focus trapping, scroll lock, and isolation of outside content. |
| `portalled`              | `true`  | Renders the positioner in a portal and preserves Ark's tab behavior. |
| `portalRef`              | -       | Targets a custom portal container.                           |
| `skipAnimationOnMount`   | `false` | Keeps the initial enter animation enabled.                   |
| `unmountOnExit`          | `true`  | Removes popup content after its exit animation.              |
| `defaultOpen`            | -       | Initial uncontrolled open state.                             |
| `open`                   | -       | Controlled open state.                                       |
| `ids`                    | -       | Stable IDs for trigger, content, title, description, anchor. |
| `initialFocusEl`         | -       | Function returning the element to focus on open.             |
| `positioning`            | -       | Ark floating positioning options.                            |
| `present`                | -       | Controls presence for JavaScript animation lifecycles.       |

### Behavioral notes

- Refs point to the underlying Ark DOM parts: `Trigger` and `CloseTrigger` point to buttons, while
  `Anchor`, `Positioner`, `Content`, `Arrow`, `ArrowTip`, `Title`, `Description`, `Indicator`,
  `Header`, `Body`, and `Footer` point to their rendered elements.
- `onOpenChange` receives `{ open }`; the callback receives an object rather than a positional
  argument.
- `modal` is a boolean. When true, it traps focus, locks scrolling, blocks outside interaction,
  and isolates content from screen readers. Modal popovers are always rendered in a portal, even
  when `portalled={false}` is passed.
- Pass the object returned by `usePopover` to `RootProvider`. Do not wrap the same state in `Root`.
- `Popover.Context` and `usePopoverContext` expose the current Ark state to descendants. The hook
  is exported from `@moduix/react`; use `Context` when a render prop is clearer.
- Use `usePopover` to own state outside the rendered tree and pass it to `RootProvider`.
- `Popover.Arrow` renders the default `ArrowTip`; render `ArrowTip` explicitly only to customize it.
- Ark closes on Escape and outside interaction by default. Both behaviors can be disabled separately.
- Use `ids` when stable trigger, content, title, description, anchor, or close-trigger IDs are needed.
- CSS exit animations use Ark's closed presence state. Use `present` for JavaScript-driven lifecycles.
- For content that can exceed the available height, place the scrollable region in `Popover.Body`.

### Styling hooks

Ark parts retain `data-scope="popover"` and their `data-part` values. Every exported rendered part
accepts `className`, and moduix adds `data-slot="popover-*"` to rendered wrappers. Target
`data-state="open|closed"`, `data-placement`, `data-side`, `data-nested`, `data-has-nested`, and
`data-expanded` to style by state. When multiple triggers have `value`, use `data-current` to style
only the trigger that opened the popover.

`Positioner` exposes `--reference-width`, `--reference-height`, `--available-width`,
`--available-height`, `--x`, `--y`, `--z-index`, and `--transform-origin`. `Content` exposes
`--layer-index` and `--nested-layer-count`; `Arrow` exposes Ark's arrow measurement variables.
Content wraps long unbroken strings and disables its motion when the user prefers reduced motion.
