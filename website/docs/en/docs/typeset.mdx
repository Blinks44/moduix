## API Reference

Ark UI does not ship a dedicated typesetting primitive. moduix builds `Typeset` with the
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory), so its root and optional
scroll wrapper preserve standard HTML props, `asChild`, and refs to their rendered elements.

## Basic

Use the short `<Typeset>` root for rendered HTML. Add `asChild` when the container itself should
be semantic, such as an `article` or `section`. Use plain `<ul>` and `<ol>` elements: Typeset adds
the bullets, numbering, nested markers, and reading rhythm without utility classes.

## Anatomy

```text
Typeset
└─ Typeset.Scroll (optional)
```

| Part | Role |
| --- | --- |
| `Typeset` / `Typeset.Root` | Scoped root that styles semantic descendants. |
| `Typeset.Scroll` | Focusable horizontal scroller for a wide rendered block. |

## Composition

### Recommended composition

Keep Markdown parsing, sanitization, rendering, and reading measure in the application. `Typeset`
only supplies the scoped visual rhythm and deliberately does not set a reading width. Use
`Typeset.Scroll` around a wide table or another block that should scroll horizontally.

### When to go custom

Use semantic HTML directly when a rendered subtree needs a different visual contract, then add
`.not-typeset` or `data-not-typeset` to exclude it and all of its descendants. Give every
user-facing `Typeset.Scroll` an `aria-label` or `aria-labelledby`; moduix then gives that named
wrapper the `region` role. You can also pass a custom `role` or `tabIndex`.

### Default props

| Part | Default | Notes |
| --- | --- | --- |
| `Typeset` | `div` | Use `asChild` with exactly one semantic child to render another container. |
| `Typeset.Scroll` | `div`, `tabIndex={0}` | The focusable default makes an overflowing static table reachable by keyboard. Give a user-facing scroller an accessible name; it adds `role="region"`. |

### Behavioral notes

`Typeset` has no state machine, controlled state, keyboard behavior, form integration, or hidden
inputs. `Typeset.Scroll` is the exception: it is keyboard-focusable by default so the browser can
scroll a wide static block. Its styles use `margin-block-start` and avoid `:last-child`, `:has()`,
and `:empty`, so appending a streaming Markdown block does not restyle earlier blocks.

The three rhythm controls are `--moduix-typeset-size`, `--moduix-typeset-leading`, and `--moduix-typeset-flow`. Font
variables are optional; colors, borders, and radius come straight from the active moduix theme.
Element rules live in the `moduix.components` layer and use low-specificity `:where()` selectors, so
normal application CSS can override individual elements without `!important`.

### Styling hooks

- `data-slot="typeset"` targets the root container.
- `data-slot="typeset-scroll"` targets the optional overflow wrapper and its focus-visible state.
- `[data-scope="typeset"][data-part="root"]` and `[data-part="scroll"]` expose stable anatomy
  hooks.
