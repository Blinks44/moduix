## API Reference

`Typeset` applies a consistent reading rhythm to the semantic HTML inside its boundary. It does not
render or parse Markdown, sanitize content, or decide the content width. Your application remains
responsible for those decisions.

moduix builds `Typeset` with the
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory). `Typeset` and
`TypesetScroll` therefore accept native `div` props, refs, and `asChild` composition.

The CSS-first contract follows the approach documented in
[shadcn/typeset](https://ui.shadcn.com/docs/typeset). It uses the same three rhythm controls while
leaving content rendering and reading width to the application; moduix adds framework-native
components and `TypesetScroll`.

## Basic


Wrap HTML that your renderer has already produced in `<Typeset>`. Use `asChild` only when the outer
container needs to be semantic, such as an `article` or `section`. Keep lists as native `<ul>` and
`<ol>` elements: Typeset provides their markers and spacing without utility classes.

## Anatomy

```text
Typeset
└─ TypesetScroll (optional)
```

| Part | Role |
| --- | --- |
| `Typeset` | Scoped root that styles semantic descendants. |
| `TypesetScroll` | Focusable horizontal scroller for a wide rendered block. |

## Composition

`Typeset` owns no state and does not parse, sanitize, or size content. Keep rendered semantic
elements inside the root, use `asChild` when the root must be an `article` or `section`, and compose
`TypesetScroll` around a wide block that should scroll instead of compressing. Keep `TypesetScroll`
inside a `Typeset` boundary: the horizontal scrolling, flow spacing, and table
widening for the wrapped block come from the Typeset element rules. Mark an application-owned
subtree with `.not-typeset` or `data-not-typeset` when it needs its own visual treatment. A
user-facing scroll region should have an accessible name; `TypesetScroll` is keyboard-focusable by
default.

### CSS Properties

Use `--moduix-typeset-size`, `--moduix-typeset-leading`, and `--moduix-typeset-flow` to control the
reading rhythm. Font variables are optional; colors, borders, and radius come from the active moduix
theme. Element rules live in the `components` cascade layer, with the variable defaults in `base`,
and use low-specificity `:where()` selectors, so normal application CSS can override individual
elements without `!important`.

Use `className` in React or `class` in Solid on exported parts for structural styles. The Tailwind
variants ship the same CSS Module with `cn` class merging instead of utility classes, so the six CSS
variables customize both styling tracks.

### Styling hooks

- `data-slot="typeset"` targets the root container.
- `data-slot="typeset-scroll"` targets the optional overflow wrapper and its focus-visible state.
- `[data-scope="typeset"][data-part="root"]` and `[data-part="scroll"]` expose stable anatomy
  hooks.
