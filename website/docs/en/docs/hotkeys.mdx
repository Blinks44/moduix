`Hotkeys` is Ark UI's utility for registering keyboard commands. It listens on a document or another
target, while your application owns the command action and the visible controls.

## Register a shortcut

Use `useHotkey` for one command. The command is registered when the component mounts and removed when
it unmounts. `mod` means Command on macOS and Control on Windows and Linux, so the same declaration
works across platforms.

The `action` receives the `KeyboardEvent`, so it can inspect the event when needed. Add
`options.preventDefault` when the shortcut intentionally replaces a browser command. Keep a visible
button or another accessible action as an alternative to the keyboard shortcut.

## Register several shortcuts

Use `useHotkeys` with a `commands` array when a screen has multiple commands or the commands come from
data. Each command needs a `hotkey` and an `action`; `id`, `label`, `description`, `category`, and
`keywords` are available for stable references and command-palette metadata.

Separate the steps in a sequence with `>`. The default sequence timeout is 1000 milliseconds.

## Scope behavior and options

Hotkeys uses a shared store by default. Create a stable store with `createHotkeyStore` when a part of
the application needs its own commands, defaults, or active scopes. Create it outside the component,
or memoize it in React, so it is not recreated during render. Pass the same store to `useHotkey`,
`useHotkeys`, `useHotkeyRegistrations`, or `useHotkeyStore`.

- `scopes` can be a string or an array. A command fires when one of its scopes is active. Use
  `store.setScope('preview')` to replace the active scopes, or `addScope`, `removeScope`, and
  `toggleScope` to update them.
- `enabled` accepts a boolean or a function. A function is checked when the key fires, so it can read
  current application state without re-registering the command.
- `options.enableOnFormTags` is `false` for single-key shortcuts by default. Set it to `true`, or to
  an array of `input`, `textarea`, and `select`, only when the shortcut should work while typing.
  Shortcuts with a modifier still work in form fields.
- Use `options.enableOnContentEditable` for editable regions, `options.target` for a DOM subtree,
  and `options.stopPropagation` when the action must stop the event from travelling further.
- Set `options.eventType` to `'keyup'` to run on release and `options.requireReset` to prevent key
  repeat from firing the command more than once before release.
- `conflictBehavior` controls duplicate shortcuts in a store: `'warn'` is the default, while
  `'error'`, `'replace'`, and `'allow'` provide stricter or quieter alternatives. Set the sequence
  window with `sequenceTimeoutMs` and shared command defaults with `defaultOptions`.

## Display a shortcut

Hotkeys does not render a hint. Use `useFormatHotkey` inside a component to display a platform-aware
label, for example `mod+K` becomes `⌘ K` on macOS and `Ctrl K` elsewhere. In an SSR application,
prefer this hook over calling `formatHotkey` directly during component render so the server and
browser use the same initial markup.

## Read registrations and key state

Use the additional hooks when the application needs to build on the registry rather than register a
command only:

| Need | API |
| --- | --- |
| Show registered commands in a command palette | `useHotkeyRegistrations` |
| Let users record a new shortcut | `useHotkeyRecorder` |
| React to keys held during another interaction | `usePressedKeys` or `useIsKeyPressed` |
| Read the current platform | `usePlatform` |

In Solid, state returned by these hooks is an accessor, so read it as `registrations()`,
`pressedKeys()`, `isPressed()`, or `platform()`. React returns the current value directly. A recorded
shortcut can be committed with `stop`, discarded with `cancel`, or removed with `clear`.

Hotkeys manages registration, matching, formatting, scopes, and recorder state. Your application
still owns side effects, navigation, persistence, command-palette UI, focus management, and an
accessible non-keyboard path for every important action.
