## API Reference

Ark UI does not provide a dedicated list primitive. moduix uses the official
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) to compose native `ul`, `ol`, and
`li` elements. See Ark's guides to [composition](https://ark-ui.com/docs/guides/composition),
[styling](https://ark-ui.com/docs/guides/styling), and [refs](https://ark-ui.com/docs/guides/ref) for the
underlying model.

## Choosing the right component

Use `List` for static grouped content such as steps, features, or metadata. It keeps native `ul` and `ol`
semantics while adding controls for spacing, typography, tone, and markers.

If users need to navigate with the keyboard and select one or more options, use [Listbox](/docs/listbox).
`Listbox` manages focus, the collection, and selection.

## Basic


`List` renders a semantic `<ul>` by default. Use `ListItem` when you need the stable item part and its
styling hooks, or use native `<li>` children when you do not need the wrapper. The root controls spacing,
typography, tone, and markers. By default, `ul` gets `disc` markers and `ol` gets `decimal`;
set `marker` to `disc`, `decimal`, or `none` to choose explicitly. With `asChild`, pass `marker` to match the child.

## Anatomy

```text
List
└─ ListItem | li
   └─ ListIndicator
```

| Part                 | Role                                                                                              |
| -------------------- | ------------------------------------------------------------------------------------------------- |
| `List`     | Semantic list root that renders `ul` or `ol` and controls markers, spacing, size, and tone.      |
| `ListItem` | Optional item part that renders `li`, forwards native attributes and refs, and supports `asChild`. |
| `ListIndicator` | Optional `span` placed first in an item for an icon instead of a native marker. |

## Composition

Use `List` for the root. Its direct children should be `ListItem` or native `li` elements,
because root spacing and marker styling target direct list items. Use `ListItem` when you need its stable
slot, `className`/`class`, or `asChild`; native `li` is enough otherwise. Use `asChild` only when an application
component owns one semantic `ul`, `ol`, or `li` and forwards the received props and ref. In Solid, pass the
render function form of `asChild`; in Vue, pass the semantic element as the component slot. `List` has no state
machine or callbacks, so keyboard selection belongs to `Listbox`.

## Examples

### Custom Root

Use `List asChild` when a component from your application must render the semantic list element. It must
forward the received props and ref to one `<ul>` or `<ol>` in React, use the render-function form in Solid, or pass
one semantic child in Vue.

### Markerless

Use `marker="none"` when you need list semantics without visible markers. `List` adds `role="list"` by default
in this mode unless you provide another `role`.

### Native Items

Use native `li` elements when you do not need the exported `ListItem` part.

<Example name="list/native-items" />

### Ordered

Use `as="ol"` to render an ordered list while keeping the styling applied by the moduix root. Native props such
as `start` and `reversed` are forwarded to the ordered-list root. Markers come from `marker`, so the native `type`
attribute does not change them; set `list-style-type` with a class for letters or roman numerals.

<Example name="list/ordered" />

### Tone

Use `tone` to apply a semantic text and marker color to the list.

<Example name="list/tone" />

### Nested

Put a nested `List` inside a `ListItem`. The nested list starts one `gap` below the item text, using its own
`gap`, so nesting needs no extra margins.

<Example name="list/nested" />

### With Indicator

Use `ListIndicator` to show an icon instead of a native marker, and set `marker="none"` on the root. An item
with an indicator becomes a flex row: the icon is sized to `1em`, aligned with the first line, and long text wraps
next to it instead of under it.

<Example name="list/with-indicator" />

### Advanced Customization

Use `ListItem asChild` when a custom component must render the `<li>` itself. It must forward the received
props and ref and preserve the semantic `<li>` element. In other cases, use `ListItem className` or `class` directly.

## Styling

Style `List` with the framework's class prop (`className` in React and `class` in Solid and Vue), the exported Ark-style
`data-*` attributes, and native `li::marker`. CSS Modules variants build on foundation tokens and have no component
variables: a class on the root overrides the layered component styles.

### Styling Hooks

`List` exposes these public styling hooks:

- root: `data-scope="list"`, `data-part="root"`, `data-slot="list-root"`
- item: `data-scope="list"`, `data-part="item"`, `data-slot="list-item"`
- indicator: `data-scope="list"`, `data-part="indicator"`, `data-slot="list-indicator"`
- `data-gap="xs" | "sm" | "md" | "lg" | "xl" | "2xl"` for spacing-related styles
- `data-marker="disc" | "decimal" | "none"` for marker-related styles
- `data-size="xs" | "sm" | "md" | "lg" | "xl"` for typography size styles
- `data-tone="default" | "muted" | "primary" | "destructive"` for semantic colors
- native `li::marker` for overriding marker color or weight
