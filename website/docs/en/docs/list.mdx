## API Reference

Ark UI does not ship a dedicated list primitive. moduix builds this component with the official
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) and follows Ark's guidance on
[composition](https://ark-ui.com/docs/guides/composition), [styling](https://ark-ui.com/docs/guides/styling), and
[refs](https://ark-ui.com/docs/guides/ref).

## Anatomy

The usual composition is simple:

```text
List / List.Root
└─ List.Item | li
```

| Part                 | Role                                                               |
| -------------------- | ------------------------------------------------------------------ |
| `List` / `List.Root` | Semantic list root that controls markers, spacing, size, and tone. |
| `List.Item`          | Optional item part that provides a stable `li` slot and supports `asChild`. |

## Composition

### Recommended composition

Use `<List>` for unordered content and `as="ol"` when you need ordered semantics. Use `asChild` only when you
need to replace `List` with a single semantic `<ul>` or `<ol>`, or `List.Item` with a single semantic `<li>`.

### When to go custom

`List` does not expose an internal state machine, helpers for nested structures, or a marker rendering API. For
ordinary item styling, use `className` and native CSS such as `li::marker`. Use `asChild` only with a component
from your application that forwards its ref and props and renders the required semantic element.

Keep each item as a direct child of the list. The built-in spacing and marker styling apply only to direct list items.

### Default props

| Prop      | Default         | Notes                                                                |
| --------- | --------------- | -------------------------------------------------------------------- |
| `gap`     | `sm`            | Spacing between direct list items.                                   |
| `size`    | `md`            | Typography size from the design scale.                               |
| `tone`    | `default`       | Semantic color used for text and markers.                            |
| `marker`  | semantic `auto` | `disc` on `ul`, browser defaults on `ol`, or `none`.                 |
| `as`      | `ul`            | Switches the native list element between `ul` and `ol`.              |
| `asChild` | `false`         | Uses one child from your code as the semantic list element.           |

### Behavioral notes

- Native ordered-list props such as `start`, `reversed`, and `type` are available when `as="ol"` is used.
- Use `marker="none"` to hide markers while keeping list semantics. When markers are disabled, `List` adds
  `role="list"` unless you explicitly override `role`.
- `List.Item` is optional. Use plain `li` elements when you do not need the exported item slot.

### Styling hooks

`List` exposes a small set of public styling hooks:

- root: `data-scope="list"`, `data-part="root"`, `data-slot="list-root"`
- item: `data-scope="list"`, `data-part="item"`, `data-slot="list-item"`
- `data-gap="xs" | "sm" | "md" | "lg" | "xl" | "2xl"` for styles based on spacing
- `data-marker="auto" | "disc" | "decimal" | "none"` for styles based on markers
- `data-size="xs" | "sm" | "md" | "lg" | "xl"` for size-specific typography styles
- `data-tone="default" | "muted" | "subtle" | "primary" | "destructive"` for semantic color styles
- native `li::marker` targeting for marker-specific color or weight overrides
