## What it does

`DownloadTrigger` is an Ark UI utility that renders a native button by default and starts a browser download when the
user activates it. The `data` prop accepts file contents as a string, a `Blob`, a `File`, or a function that returns
one of these values directly or through a promise. A string is treated as file contents, not as a remote URL. To
download a remote resource, fetch it in your application and return `await response.blob()` from the function passed to
`data`.

Import the generic utility directly from Ark UI. It is not re-exported by `@moduix/react`:

```tsx
import { DownloadTrigger } from '@ark-ui/react/download-trigger';
```

## Basic

Use `data` for content that is already available, then set `fileName` and `mimeType`. With `asChild`, Ark applies the
download behavior to the child element. In this example, the child is a moduix `Button`.

## Generate data on demand

Pass a function when the file needs to be created before it can be downloaded. Ark calls it after the user activates
the trigger. If it returns a promise, Ark waits for it to resolve before saving the file.

`DownloadTrigger` does not expose loading state or an error callback. If generation can take time, track its state in
your application and handle errors inside the function passed to `data`. Disable or replace the trigger while the
operation is in progress.

## Choosing file metadata

Give `fileName` an extension that matches the content and provide the corresponding `mimeType`, such as
`application/json`, `text/csv`, `image/svg+xml`, or `application/pdf`. When you return a `Blob` or `File`, keep its
`type` consistent with `mimeType` as well.

## Using moduix

`DownloadTrigger` has no visual styles of its own. Compose it with `asChild` and a moduix `Button` so the action fits
the rest of your interface. For an image generated by the moduix `QrCode` component, prefer `QrCode.DownloadTrigger`
on the [QrCode](/docs/qr-code) page. It reads the image from the nearest QR code and exports it for you.

## What comes from Ark UI

Ark UI owns the generic download behavior and the `data`, `fileName`, and `mimeType` API. moduix documents how to
combine that utility with its components, but does not provide a generic `DownloadTrigger` export or add styles to
the Ark component.
