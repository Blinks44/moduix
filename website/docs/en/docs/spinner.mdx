## API Reference

Ark UI does not provide a dedicated Spinner component. moduix builds `Spinner` with Ark UI's
`ark.span` factory and exposes a small API around one root element. The component follows Ark's
[composition](https://ark-ui.com/docs/guides/composition), [styling](https://ark-ui.com/docs/guides/styling), and
[ref](https://ark-ui.com/docs/guides/ref) guidance.

## Basic

Use `Spinner` for short-lived loading states in buttons, inline status rows, and compact empty
states. By default, it exposes the loading status to assistive technology with `role="status"` and
the fallback label `aria-label="Loading"`. The fallback is the literal English string `Loading`, so
set a localized `aria-label` or use `aria-labelledby` in a non-English interface.

## Anatomy

`Spinner` exposes one public root. In the default composition, moduix adds an internal indicator
wrapper and a default ring. These are DOM nodes and styling hooks, not exported React components.
Custom `children` replace the ring, while `asChild` replaces the root and leaves the indicator
markup to the child.

```text
Spinner / Spinner.Root
└─ root[data-scope="spinner"][data-part="root"][data-slot="spinner-root"][data-size]
   └─ indicator[data-scope="spinner"][data-part="indicator"][data-slot="spinner-indicator"]
      └─ ring[data-scope="spinner"][data-part="ring"][data-slot="spinner-ring"] (default only)
```

| Part                       | Role                                                                                  |
| -------------------------- | ------------------------------------------------------------------------------------- |
| `Spinner` / `Spinner.Root` | Public root. Accepts `size`, `decorative`, `asChild`, `children`, and native `span` props. |
| indicator                  | Internal rotating wrapper that owns the indicator's size and animation.                     |
| ring                       | Internal default ring. It is omitted when custom `children` are provided.                    |

## Composition

### Recommended composition

Use the default ring when a compact loading indicator is enough.

- Use `size` for density changes.
- Use `decorative` when adjacent visible text already communicates the loading state.
- Use `aria-label` or `aria-labelledby` when the status name should be more specific than
  `"Loading"`.
- Render `Spinner` from your own loading state. It does not start, stop, or otherwise manage the
  operation being represented.

### When to go custom

Pass custom `children` when the default ring is not the right visual, but the standard root, size,
and rotating wrapper should stay in place.

Use `asChild` only when another component must provide the actual root DOM element. Pass exactly one
non-interactive child. In this mode, the built-in indicator wrapper and ring are not rendered, so the
child must provide the visual indicator markup itself.

### Default props

| Prop              | Default     | Notes                                                                                              |
| ----------------- | ----------- | -------------------------------------------------------------------------------------------------- |
| `size`            | `'md'`      | Accepts `'inherit' \| 'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`. `inherit` uses `1em`.               |
| `decorative`      | `false`     | Gives the default root `role="presentation"` and `aria-hidden="true"`; with `asChild`, preserves the child's semantics. |
| `asChild`         | `false`     | Passes the root props to the single child element.                                                  |
| `aria-label`      | `'Loading'` | Used when the spinner is not decorative and `aria-labelledby` is not provided.                    |
| `aria-labelledby` | not set     | Use it to name the status with visible text elsewhere in the page.                                 |

### Behavioral notes

- The default root renders as a `span` with `data-scope="spinner"`, `data-part="root"`,
  `data-slot="spinner-root"`, and `data-size`.
- `Spinner.Root` is a compatibility alias for `Spinner`; use `Spinner` in new code.
- Non-decorative spinners render with `role="status"`.
- `decorative={true}` hides the default root from assistive technology. With `asChild`, it does not
  add Spinner's role or labelling attributes, so the custom child keeps its own semantics.
- Spinner controls its status semantics and its `data-scope`, `data-part`, `data-slot`, and
  `data-size` hooks. Conflicting native props do not replace these values.
- The rotating wrapper is `data-scope="spinner"`, `data-part="indicator"`, and
  `data-slot="spinner-indicator"`.
- Custom `children` replace only the default ring. The wrapper still owns sizing and rotation.
- With `asChild`, the consumer-provided child becomes the root and must provide any visual indicator
  content it needs.
- `size="inherit"` sets the spinner size to `1em`; all other size values write the selected value to
  `data-size`.
- Spinner keeps its loading motion when `prefers-reduced-motion: reduce` is active because the
  animation is the visual loading cue.

### Styling hooks

- `[data-scope="spinner"][data-part="root"]` targets the Ark-style root.
- `[data-scope="spinner"][data-part="indicator"]` targets the rotating inner wrapper.
- `[data-scope="spinner"][data-part="ring"]` targets the default ring only.
- `data-slot="spinner-root"` is the stable moduix selector for the rendered root.
- `data-slot="spinner-indicator"` is the stable moduix selector for the rotating inner wrapper.
- `data-slot="spinner-ring"` targets the default ring only.
- `Spinner` writes `data-size="inherit" | "xs" | "sm" | "md" | "lg" | "xl"` on the root.
- `className` applies to the rendered root. With `asChild`, that is the single child element. Target
  the indicator or ring with descendant selectors when needed.
