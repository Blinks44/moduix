## API Reference

Ark UI does not provide a dedicated Spinner component. moduix builds `Spinner` with Ark UI's
`ark.span` factory and exposes a small API around one root element. The component follows Ark's
[composition](https://ark-ui.com/docs/guides/composition), [styling](https://ark-ui.com/docs/guides/styling), and
[ref](https://ark-ui.com/docs/guides/ref) guidance.

## Basic

Use `Spinner` for short-lived loading states in buttons, inline status rows, and compact empty
states. By default, it exposes the loading status to assistive technology with `role="status"` and
the fallback label `aria-label="Loading"`. The fallback is the literal English string `Loading`, so
set a localized `aria-label` or use `aria-labelledby` in a non-English interface.

Spinner ships for React and Solid in both the CSS Modules and Tailwind packages. The rendered
preview on this page uses the React CSS Modules package; the framework tabs show native source for
the same public contract.

Use `Spinner` as the root in most cases. `Spinner.Root` is an alias for the same root when you want
to make that part explicit in your composition.

## Anatomy

`Spinner` exposes one public root. In the default composition, moduix adds an internal indicator
wrapper and a default ring. These are DOM nodes and styling hooks, not exported React components.
Custom `children` replace the ring, while `asChild` replaces the root and leaves the indicator
markup to the child.

```text
Spinner / Spinner.Root
└─ root[data-scope="spinner"][data-part="root"][data-slot="spinner-root"][data-size]
   └─ indicator[data-scope="spinner"][data-part="indicator"][data-slot="spinner-indicator"]
      └─ ring[data-scope="spinner"][data-part="ring"][data-slot="spinner-ring"] (default only)
```

| Part                       | Role                                                                                  |
| -------------------------- | ------------------------------------------------------------------------------------- |
| `Spinner` / `Spinner.Root` | Public root. Accepts `size`, `decorative`, `asChild`, `children`, and native `span` props. |
| indicator                  | Internal rotating wrapper that owns the indicator's size and animation.                     |
| ring                       | Internal default ring. It is omitted when custom `children` are provided.                    |

## Composition

`Spinner` represents an app-owned loading state; it does not start, stop, or otherwise manage the
operation being represented. Render it from the state that already owns that operation.

Pass custom `children` to replace the default ring while keeping the standard root, sizing, and
rotating indicator wrapper. Use `asChild` only when another component must own the root element: the
built-in indicator and ring are not rendered in that mode, so exactly one non-interactive child must
provide the visual indicator markup.

## Styling

Style `Spinner` with `className` in React, `class` in Solid, Ark `data-scope` / `data-part`
selectors, stable `data-slot` hooks, `data-size`, and the public `--moduix-spinner-*` variables
documented by the CSS API. The CSS Modules packages expose those variables; Tailwind packages use
utility classes and consumer class overrides instead of mirroring the CSS Modules variable layer.

### Styling hooks

- `[data-scope="spinner"][data-part="root"]` targets the Ark-style root.
- `[data-scope="spinner"][data-part="indicator"]` targets the rotating inner wrapper.
- `[data-scope="spinner"][data-part="ring"]` targets the default ring only.
- `data-slot="spinner-root"` is the stable moduix selector for the rendered root.
- `data-slot="spinner-indicator"` is the stable moduix selector for the rotating inner wrapper.
- `data-slot="spinner-ring"` targets the default ring only.
- `Spinner` writes `data-size="inherit" | "xs" | "sm" | "md" | "lg" | "xl"` on the root.
- `className` or `class` applies to the rendered root. With `asChild`, that is the single child
  element. Target the indicator or ring with descendant selectors when needed.
