## API Reference

Ark UI does not provide a dedicated `button` primitive. moduix builds this component with the official
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) and follows Ark's guidance for
[composition](https://ark-ui.com/docs/guides/composition), [styling](https://ark-ui.com/docs/guides/styling), and
[refs](https://ark-ui.com/docs/guides/ref).

## Anatomy

`Button` has a single part.

```text
Button.Root
└─ root[data-scope="button"][data-part="root"][data-slot="button-root"]
   └─ children
```

| Part                     | Role                                          |
| ------------------------ | --------------------------------------------- |
| `Button` / `Button.Root` | Interactive root element with moduix styles. |
| `Button`                 | Callable alias for `Button.Root`.             |

## Composition

### Recommended composition

Use the native root for actions. It defaults to `type="button"` to prevent accidental form submission;
set `type="submit"` explicitly when the button should submit a form.

### Default props

| Prop      | Default   | Values                                                                                   |
| --------- | --------- | ---------------------------------------------------------------------------------------- |
| `loading` | `false`   | `boolean`                                                                                |
| `variant` | `default` | `default`, `outline`, `secondary`, `destructive`, `destructive-outline`, `ghost`, `link` |
| `size`    | `md`      | `xs`, `sm`, `md`, `lg`, `xl`, `icon-sm`, `icon-md`, `icon-lg`                            |
| `type`    | `button`  | Native roots only                                                                        |
| `asChild` | `false`   | Uses the single child as the rendered root                                               |

### When to use a custom element

Use `asChild` when an existing semantic element should own the rendered DOM node. Ark composition
requires exactly one child. The default `type="button"` is not injected into an `asChild` target.

When `Dialog.Trigger`, `Menu.Trigger`, or another Ark part composes Button as its child, the parent
part's `data-scope` and `data-part` take precedence on the shared DOM node. Button retains its
recipe classes and stable `data-slot`; Ark continues to merge the trigger handlers and refs.

Use a real anchor for navigation. On an element used with `asChild`, `disabled`, `loading`, and
`aria-disabled="true"` expose `aria-disabled`, apply the disabled styling state, and prevent click
activation. They do not add a native `disabled` attribute to the custom element.

### Behavioral notes

- Native attributes, `style`, and event handlers are forwarded to the root. `className` is merged
  with the moduix styles, and disabled roots prevent activation.
- The forwarded ref targets the rendered root.
- Native `disabled`, `aria-disabled="true"`, and `loading` expose `data-disabled`.
- `loading` is a small convenience prop: it sets `data-loading`, `aria-busy`, and the disabled styling
  state while the spinner and label remain fully compositional.
- Direct child `svg` elements inherit `currentColor` and use `--moduix-button-icon-size`.
- Icon-only buttons require an accessible name.
- Chakra-only APIs such as `colorPalette`, responsive recipe props, `ButtonGroup`, and managed loading
  props are intentionally outside moduix's root-only contract.

### Styling hooks

- `data-slot="button-root"` is the stable moduix selector.
- Standalone roots default to `data-scope="button"` and `data-part="root"`. A composing Ark parent
  may replace them with its own anatomy values.
- `data-variant` and `data-size` reflect the active visual recipe.
- `data-disabled` is present for native `disabled`, `aria-disabled="true"`, and `loading`.
- `data-loading` is present when `loading={true}`.
- `[data-disabled]` drives disabled visuals for native `disabled`, `aria-disabled="true"`, and `loading`.
- Enabled button variants use a subtle press movement; `link` keeps opacity feedback only, and the movement is
  omitted when the user prefers reduced motion.
