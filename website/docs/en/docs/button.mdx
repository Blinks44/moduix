## API Reference

Ark UI does not provide a dedicated `button` primitive. moduix builds this component with the official
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) and follows Ark's guidance for
[composition](https://ark-ui.com/docs/guides/composition), [styling](https://ark-ui.com/docs/guides/styling), and
[refs](https://ark-ui.com/docs/guides/ref).

## Anatomy

`Button` has a single part.

```text
Button
└─ root[data-scope="button"][data-part="root"][data-slot="button-root"]
   └─ children
```

| Part     | Role                                                |
| -------- | --------------------------------------------------- |
| `Button` | Single interactive root element with moduix styles. |

## Composition

`Button` is a single-part root. Use `asChild` when another semantic element should own the rendered DOM node:
React passes exactly one child, Solid uses an `asChild` render function, and Vue supplies its semantic element as
the default slot child. When an Ark part composes Button, the parent keeps ownership of `data-scope` and `data-part`;
Button keeps its recipe classes and stable `data-slot`.

The `loading` prop owns only busy and disabled state (`data-loading`, `aria-busy`, and `data-disabled`); your
application owns the spinner, label, and async lifecycle. Native roots default to `type="button"`, while
`asChild` targets do not receive that default.

### Ref

The forwarded ref points to the rendered root and can be used to focus or measure it programmatically. In Solid,
assign a ref to the element created inside the `asChild` render function, because a ref on `Button` itself is not
forwarded through that composition path. In Vue, a template ref points to the component instance; use `$el` for the
rendered root, which is the semantic child when using `asChild`.

## Styling

Start with a built-in variant and size. For a one-off change, set the public `--moduix-button-*`
variables on the button through a class or inline style. To theme one variant across the application,
set the same variables on `[data-slot='button-root'][data-variant='<variant>']`. These CSS variables
apply to the CSS Modules packages; Tailwind packages use native utilities and consumer classes instead.

Use `className` in React or `class` in Solid and Vue on the root. State attributes and `data-slot` hooks are
shared by both styling tracks.

### Styling hooks

- `data-slot="button-root"` is the stable moduix selector.
- Standalone roots default to `data-scope="button"` and `data-part="root"`. A composing Ark parent may replace
  them with its own anatomy values.
- `data-variant` and `data-size` reflect the active visual recipe.
- `data-disabled` is present for native `disabled`, `aria-disabled="true"`, and `loading`.
- `data-loading` is present when `loading={true}`.
- `[data-disabled]` drives disabled visuals for native `disabled`, `aria-disabled="true"`, and `loading`.
- Standalone Button roots move down by 1px when pressed. Link variants, popup triggers with `aria-haspopup`,
  composed parts with another `data-slot`, and reduced-motion preferences omit this movement.
  InputGroupButton and SplitButton stay stationary; hover, focus, and opacity feedback remain available.
