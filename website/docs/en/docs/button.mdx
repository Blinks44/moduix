## Composition

`Button` is a single-part root built with the [Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory).
Use `asChild` when another semantic element should own the rendered DOM node: React passes exactly one child,
Solid uses an `asChild` render function, and Vue supplies its semantic element as the default slot child. When an
Ark part composes Button, the parent keeps its own `data-scope` and `data-part`; Button keeps its recipe
classes and stable `data-slot`.

The `loading` prop sets only busy and disabled state; your application controls the spinner, label, and async
lifecycle. Native roots default to `type="button"`, while `asChild` targets do not receive that default.

## Styling

Start with a built-in variant and size. For a one-off change, set the public `--moduix-button-*`
variables on the button through a class or inline style. To theme one variant across the application,
set the same variables on `[data-slot='button-root'][data-variant='<variant>']`. These CSS variables
apply to the CSS Modules packages; Tailwind packages use native utilities and consumer classes instead.

### Styling hooks

Use `className` in React or `class` in Solid and Vue on the root. These attributes are shared by both
styling tracks.

| Attribute                 | Present when                                                   |
| ------------------------- | -------------------------------------------------------------- |
| `data-slot="button-root"` | Always. The stable moduix selector.                            |
| `data-scope`, `data-part` | `button` and `root` on a standalone root; a composing Ark parent replaces them. |
| `data-variant`            | Always. Reflects the `variant` prop.                           |
| `data-size`               | Always. Reflects the `size` prop.                              |
| `data-loading`            | `loading` is `true`.                                           |
| `data-disabled`           | `disabled`, `aria-disabled="true"`, or `loading`.              |

A standalone Button moves down by 1px when pressed. Link variants, popup triggers with `aria-haspopup`,
composed parts with another `data-slot`, and reduced-motion preferences omit this movement.

## Keyboard

Native buttons keep browser keyboard behavior, and an `asChild` link keeps the behavior of the
rendered element. Give icon-only buttons an accessible name.

## API reference

| Prop       | Type            | Default     | Description |
| ---------- | --------------- | ----------- | --- |
| `variant`  | `ButtonVariant` | `'default'` | Visual style: `default`, `outline`, `secondary`, `destructive`, `destructive-outline`, `ghost`, or `link`. |
| `size`     | `ButtonSize`    | `'md'`      | `xs`, `sm`, `md`, `lg`, `xl`, or a square `icon-sm`, `icon-md`, `icon-lg` for icon-only buttons. |
| `loading`  | `boolean`       | `false`     | Sets `aria-busy` and blocks activation. Render your own `Spinner` inside. |
| `asChild`  | `boolean`       | `false`     | Applies Button styles and props to its single child, for example a link. |
| `disabled` | `boolean`       | `false`     | Disables the button. |
