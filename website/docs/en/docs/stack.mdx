### Responsive direction

Use responsive `direction` for a simple column-on-mobile, row-on-desktop layout. The desktop value starts at `640px`.
Responsive values are mobile-first: an omitted `mobile` value stays `column`, and an omitted `desktop` value keeps the
mobile direction.

## Composition

`Stack` has no state and exposes one root. Use `<Stack>` for regular `div` output. `fill` applies to the
`Stack` as a flex item, not to its children. Add `Separator` directly as a child when the layout needs a divider,
and use `asChild` when the root should be a semantic element.

## Anatomy

`Stack` renders one flex root that follows Ark's factory model. It controls direction, gap, alignment, wrapping, and
a simple responsive direction switch. Keep broader layout rules in your local CSS.

## Styling

`Stack` does not define component-specific CSS variables. The default `display: flex` and column direction come from
the component stylesheet (or the `flex flex-col` utilities in the Tailwind variants), so your classes can replace them,
including a responsive `flex-direction` in your own media queries.

Use `className` in React or `class` in Solid and Vue for structural styles. Tailwind variants use native utility
classes and consumer class overrides; the data attributes and `data-slot` hook are shared by both styling tracks.

### Styling hooks

| Part | `data-slot` |
| --- | --- |
| `Stack` | `stack-root` |

- `className` or `class` styles the single root for width, padding, borders, backgrounds, and other surface concerns.
- `data-scope="stack"` and `data-part="root"` align the wrapper with Ark styling conventions.
- `direction` and `fill` are applied through the component stylesheet or utilities, so consumer classes can override
  them. `gap`, `align`, `justify`, and `wrap` write inline styles.
- `style` is applied last, so it can override the inline `gap`, `alignItems`, `justifyContent`, and `flexWrap`.
- There are no state attributes, CSS animation variables, or `slotProps` maps in the public contract.

## API reference

Also accepts the native props of its element and `asChild`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `direction` | `StackDirection \| { mobile?: StackDirection; desktop?: StackDirection }` | `'column'` | `column` or `row`, or separate values for mobile and desktop. |
| `gap` | `number \| string` | — | Gap between children; numbers are pixels. |
| `align` | `CSSProperties['alignItems']` | — | CSS `align-items`. |
| `justify` | `CSSProperties['justifyContent']` | — | CSS `justify-content`. |
| `wrap` | `CSSProperties['flexWrap']` | — | CSS `flex-wrap`. |
| `fill` | `boolean` | `false` | Stretches the stack to the full width and height of its parent. |
