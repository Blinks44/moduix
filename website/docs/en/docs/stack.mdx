## API Reference

Ark UI does not include a dedicated `Stack` primitive. moduix implements this component with Ark's official
[factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) and follows Ark's guidance for
[composition](https://ark-ui.com/docs/guides/composition), [styling](https://ark-ui.com/docs/guides/styling), and
[refs](https://ark-ui.com/docs/guides/ref). Chakra UI's [Stack](https://chakra-ui.com/docs/components/stack)
documentation informs the layout prop names only.

## Anatomy

`Stack` renders one flex root that follows Ark's factory model. It controls direction, gap, alignment, wrapping, and
a simple responsive direction switch. Keep broader layout rules in your local CSS.

```text
Stack / Stack.Root
└─ root[data-scope="stack"][data-part="root"][data-slot="stack-root"]
   └─ children
```

| Part                   | Role                                                                |
| ---------------------- | ------------------------------------------------------------------- |
| `Stack` / `Stack.Root` | Root flex wrapper for direction, gap, alignment, and child spacing. |

## Composition

### Recommended composition

Use the short `<Stack>` form for regular `div` output. Use `Stack.Root` when matching the namespace pattern is useful
alongside multipart components.

Use `direction`, `gap`, `align`, `justify`, and `wrap` for common flex layouts. Use `fill` when a nested `Stack`
should grow as a flex item. Add the moduix `Separator` directly as a child when the layout needs a visual divider.
Use `asChild` when the `Stack` should render as a semantic element.

### When to go custom

Move layout rules to local CSS when you need multiple flex containers, different gaps at different breakpoints,
item-level rules, or more responsive behavior than the built-in mobile/desktop direction switch. CSS may also be
clearer than a long combination of component props.

Use `style` for a one-off override of public `--moduix-stack-*` variables or computed flex properties.

### Default props

| Prop        | Default         | Notes                                                   |
| ----------- | --------------- | ------------------------------------------------------- |
| `direction` | `column`        | `row`, `row-reverse`, `column`, `column-reverse`, or responsive object |
| `gap`       | browser default | CSS length (`number` = `px`)                            |
| `align`     | browser default | Any valid `align-items` value                           |
| `justify`   | browser default | Any valid `justify-content` value                       |
| `wrap`      | browser default | Any valid `flex-wrap` value                             |
| `fill`      | `initial`       | `true` sets `flex: 1 1 0`; `false` sets `flex: initial` |
| `asChild`   | `false`         | Ark factory composition with one semantic child element |

### Behavioral notes

- `Stack` renders exactly one root and forwards Ark factory DOM props to that root.
- `direction={{ mobile, desktop }}` uses the desktop value from `640px` upward. If only one value is provided,
  `Stack` uses it at both breakpoints.
- `direction` also accepts `row-reverse` and `column-reverse` for reversed visual order.
- `fill` affects the `Stack` as a flex item, not its children.
- `Separator` is an ordinary child. Mark decorative dividers with `aria-hidden`.
- `gap`, `align`, `justify`, and `wrap` are written inline only when you provide them.
- `Stack` exposes `data-scope="stack"`, `data-part="root"`, and `data-slot="stack-root"` for Ark-style styling.
- `Stack` does not add item wrappers, keyboard behavior, ARIA semantics, context, or managed state.

## Styling

### CSS Properties

`Stack` exposes public CSS variables on its root. By default, they use `column` and `initial`; the `direction` and
`fill` props write inline values when provided, and `style` can override them for a single instance.

### Styling hooks

- `className` styles the single root for width, padding, borders, backgrounds, and other surface concerns.
- `data-scope="stack"` and `data-part="root"` align the wrapper with Ark styling conventions.
- `data-slot="stack-root"` is the stable moduix selector for targeting the root in local CSS.
- `style` is applied last, so it can override computed `gap`, `alignItems`, `justifyContent`, `flexWrap`, and any
  `--moduix-stack-*` variables written by props.
- There are no state attributes, CSS animation variables, or `slotProps` maps in the public contract.
