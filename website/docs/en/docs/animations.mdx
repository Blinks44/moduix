# Animations

Use motion to explain a state change, not to decorate every interaction. Start with the motion shipped
by moduix, change a shared rule only when the whole product needs it, and keep one-off adjustments on
the visual component part that owns the animation.

Ark exposes entry and exit state through `data-state` attributes and keeps closing content mounted
until its exit animation finishes. The foundation also reduces shared motion when the operating system
requests `prefers-reduced-motion`.

## Choose a styling track

| Styling track | Recommended path |
| --- | --- |
| CSS Modules | Override the documented shared or component-level motion variables. |
| Tailwind CSS | Use the motion utilities shipped by the Tailwind component, then override consumer classes or source-owned registry code for a deliberate exception. |

The CSS variables below belong to the CSS Modules packages for every shipped framework. React and
Solid use the same variable names, so the stylesheet stays framework-neutral. Tailwind packages use
utility-backed motion and do not promise the component-level CSS Modules variable contract.

## Set shared popup motion

Use `--moduix-popup-motion-*` on `:root` when supported popup content should share one duration,
easing, fade, scale, or offset. Entry uses `starting` values and exit uses `ending` values.

```css
:root {
  --moduix-popup-motion-duration: 220ms;
  --moduix-popup-motion-easing: cubic-bezier(0.22, 1, 0.36, 1);
  --moduix-popup-motion-starting-opacity: 0;
  --moduix-popup-motion-ending-opacity: 0;
  --moduix-popup-motion-starting-scale: 0.96;
  --moduix-popup-motion-ending-scale: 0.98;
  --moduix-popup-motion-starting-translate-y: 0.5rem;
  --moduix-popup-motion-ending-translate-y: 0.5rem;
}
```

Use `:root` for the normal portalled setup. A variable on a local wrapper reaches an overlay only
when the overlay renders in that subtree, for example with `portalled={false}` or a custom portal
container.

Shared popup variables cover the content surfaces of Popover, Menu, Tooltip, Hover Card, Floating
Panel, Dialog, Command Palette, Lightbox, Tour, Navigation Menu, Select, Combobox, Date Picker, and
Color Picker.

## Add a local exception

Component-level variables take precedence over the shared fallback. Put them on the visual part that
owns the animation.

| Surface | Part | Variable family |
| --- | --- | --- |
| Popover | `Popover.Content` | `--moduix-popover-content-*` |
| Dialog | `DialogContent` | `--moduix-dialog-content-*` |
| Select | `Select.Content` | `--moduix-select-content-*` |
| Navigation Menu | `NavigationMenuContent` | `--moduix-navigation-menu-content-*` |

For example, make one picker open with a softer scale by assigning a class to `Select.Content`:

```css
.softScalePicker {
  --moduix-select-transition: 180ms cubic-bezier(0.22, 1, 0.36, 1);
  --moduix-select-content-closed-opacity: 0;
  --moduix-select-content-closed-scale: 0.96;
}
```

Use the component page for its complete variable list. Modal backdrops have their own transition,
opacity, and blur variables; they do not inherit popup scale or translation.

## Keep state motion separate

Some interactions have geometry or lifecycle constraints and intentionally use their own motion
contract.

| Component | Why it stays separate |
| --- | --- |
| Accordion and Collapsible | Content height and disclosure state own the transition. |
| Drawer | Drag direction owns the content transform. |
| Swap | Entering and leaving indicators animate independently. |
| Tree View | Branch disclosure uses its own content timing. |
| Toast | Ark runtime variables coordinate stacking and dismissal. |

Do not replace Drawer transforms or Toast layout variables with popup recipes.

Choose one motion language for similar surfaces:

| Intent | Start with |
| --- | --- |
| Quiet disclosure | Fade |
| Movement from a nearby edge | The matching slide direction |
| Anchored menu or picker | Zoom or lift |
| Short, friendly confirmation | Soft pop, used sparingly |

## Verify motion

- Test entry and exit, not only opening.
- Check portalled content and local overrides in their real container.
- Verify keyboard focus is not delayed or hidden by the animation.
- Test with reduced motion enabled.
- Keep entry and exit values symmetric unless the asymmetry explains direction or hierarchy.
