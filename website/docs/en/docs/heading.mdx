## API Reference

Ark UI does not provide a dedicated heading primitive. moduix implements `Heading` with the official
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) and follows Ark guidance for
[composition](https://ark-ui.com/docs/guides/composition), [styling](https://ark-ui.com/docs/guides/styling), and
[ref forwarding](https://ark-ui.com/docs/guides/ref).

## Basic

Heading ships for React and Solid in both the CSS Modules and Tailwind packages. The rendered preview
on this page uses the React CSS Modules package; the framework tabs show native source for the same
public contract.

`Heading` renders an `h1` by default. Use it for document headings and choose the `as` value that
matches the heading's place in the document outline. Set `size` separately when the visual emphasis
should differ from the semantic level.

## Anatomy

`Heading` renders one native heading element. `<Heading>` and `<Heading.Root>` are equivalent forms.

```text
Heading / Heading.Root
└─ text or inline content
```

| Part                       | Role                                                    |
| -------------------------- | ------------------------------------------------------- |
| `Heading` / `Heading.Root` | Native semantic heading with moduix typography styling. |

## Composition

`Heading` is a root-only, stateless component, so it does not need a provider or coordinated parts.
Use `<Heading>` or the equivalent `<Heading.Root>` form, pass `as` for the semantic `h1` through `h6`
level, and set `size` independently when visual emphasis should differ. Without an explicit `size`,
the rendered element selects the scale from `2xl` for `h1` through `xs` for `h6`; `weight` defaults to
`semibold`. Use `asChild` only when a custom semantic heading host must own the rendered DOM node.

## Styling

Style `Heading` through `className` in React or `class` in Solid, root data attributes, and the public
`--moduix-heading-*` variables listed in the CSS reference below. The CSS Modules packages expose
these variables; the Tailwind packages use native utility classes and consumer class overrides.

### Styling hooks

- `data-scope="heading"` and `data-part="root"` identify the Ark-aligned root.
- `data-slot="heading-root"` is the stable moduix selector.
- `data-size` is present when `size` is explicitly set.
- `data-weight` reflects `regular`, `medium`, `semibold`, or `bold`.
- `Heading` owns these attributes. Matching `data-*` props cannot replace its styling contract.
- Use `className` or `class` for consumer utility or local style overrides.
