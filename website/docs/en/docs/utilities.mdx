# Utilities

Ark UI utilities are small building blocks for behavior that does not belong to a specific moduix component: browser
rendering, document environments, focus management, formatting, and rendering lifecycle.

Start with a moduix component when it already owns the interaction. Use a utility directly when your application owns
the surrounding markup or behavior. Each page below explains the recommended import, provides runnable examples, and
links to the complete Ark API.
