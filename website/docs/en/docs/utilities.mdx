# Utilities

Use a utility when your application owns the surrounding markup or behavior. If a moduix component already owns the
interaction you need, start with that component instead.

The guides below cover direct Ark UI utilities and moduix components built on the same primitives. Ark UI utilities
provide framework-specific behavior and do not choose a styling system. `Highlight`, `JsonTreeView`, and `Swap` wrap
the corresponding Ark UI primitives and add moduix composition and styling. They are available in React and Solid
packages for both styling tracks.

## Locale context

`Locale` provides locale and text direction to Ark UI formatters and locale-aware components. It is framework context,
not a styled component: use `@moduix/react/locale` in React or `@moduix/solid/locale` in Solid. Package and stylesheet
setup is covered in [Quick Start](/docs/quick-start).
