# Utilities

This section covers lower-level building blocks from Ark UI and moduix. Use them for browser-only rendering, custom
document contexts, focus management, formatting, keyboard shortcuts, or control over when content mounts.

Most guides use Ark UI directly. `Highlight`, `JsonTreeView`, and `Swap` are moduix wrappers with library styles or
defaults, while `Locale` is exposed through a stable `@moduix/react/locale` entry point. Each guide shows the import
you need, a runnable example, and a link to the complete Ark API.

Start with a moduix component when it already owns the interaction. Use one of these utilities when your application
owns the surrounding markup or behavior.
