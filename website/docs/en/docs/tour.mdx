## Anatomy

```text
Tour
└─ Overlay subtree (portalled by default)
   ├─ Tour.Backdrop
   ├─ Tour.Spotlight
   └─ Tour.Positioner
      └─ Tour.Content
         ├─ Tour.Arrow
         ├─ Tour.CloseIcon / Tour.CloseTrigger
         ├─ Tour.Body
         │  ├─ Tour.Title
         │  ├─ Tour.Description
         │  └─ Tour.ProgressText
         └─ Tour.Control
            ├─ Tour.ActionList
            └─ Tour.Actions
               └─ Tour.ActionTrigger[action]
```

| Part | Role |
| --- | --- |
| `Tour` | Root bound to the `UseTourReturn` object. `Tour.Root` remains an alias. |
| `Tour.Backdrop` / `Tour.Spotlight` | Optional overlay and current-target highlight. |
| `Tour.Positioner` / `Tour.Content` | Positions and renders the Ark `alertdialog` surface. |
| `Tour.Arrow` | Renders the moduix `ArrowTip` by default for tooltip steps. |
| `Tour.CloseIcon` | Accessible icon-only dismiss helper; use `CloseTrigger` for custom markup. |
| `Tour.Body` | moduix scrollable content wrapper for title, description, and progress. |
| `Tour.Control` / `Tour.ActionList` | Recommended action row and direct mapping from the current step actions. |
| `Tour.Actions` / `Tour.ActionTrigger` | Ark-shaped render-prop escape hatch for custom action UI. |

## Composition

`Tour` portals `Backdrop`, `Spotlight`, and `Positioner` automatically. Set `portalled={false}`
only when an inline overlay is required, or pass `portalRef` for a custom container. The structural
parts remain explicit and independently styleable.

### Accessible content

Render `Tour.Title` for the alert dialog's accessible name and `Tour.Description` for its
description. Ark owns focus movement, focus return, Escape, outside interaction, and Left/Right
navigation; keep `keyboardNavigation` enabled unless the step deliberately owns those keys. In RTL,
Ark reverses Left and Right navigation.

### State and custom actions

`useTour` owns `steps`, `stepId`, `onStepChange`, `onStepsChange`, and `onStatusChange`. Use the
moduix-exported `useTourContext` or `Tour.Context` inside the tree when custom UI needs the active
step or navigation methods. `Tour.ActionList` is the concise default; use `Tour.Actions` only when
the action UI itself must vary.

### Default props

The portalled overlay content lazily mounts and unmounts after its exit animation by default. Set
`unmountOnExit={false}` to retain it after first open; set both lifecycle props to `false` only when
eager initial rendering is needed.

| Prop | Default | Notes |
| --- | --- | --- |
| `closeOnEscape` | `true` | Escape dismisses the tour. |
| `closeOnInteractOutside` | `true` | Outside interaction dismisses unless disabled. |
| `keyboardNavigation` | `true` | Left and Right navigate available steps. |
| `preventInteraction` | `false` | Set to `true` to block page interaction while open. |
| `spotlightOffset` | `{ x: 10, y: 10 }` | Expands the highlighted target region. |
| `spotlightRadius` | `4` | Sets the spotlight clip-path corner radius. |
| `lazyMount` | `true` | Defers the tour overlay until it first opens. |
| `unmountOnExit` | `true` | Unmounts after the closing animation. |

### Styling hooks

Use moduix `data-slot` hooks such as `tour-content`, `tour-body`, and `tour-action-trigger` for
local styling. Ark exposes `data-scope="tour"`, `data-part`, `data-state`, `data-type`,
`data-placement`, `data-side`, `data-step`, and `data-disabled`; its runtime variables include
`--tour-layer`, `--tour-z-index`, `--available-width`, `--available-height`, `--transform-origin`, and the arrow
variables. Pass `className` to `Tour.ActionList` to style every generated trigger. Tour shortens
overlay presence animations and removes action-button transitions when the user prefers reduced motion.
