## Anatomy

```text
Tour / Tour.Root
└─ Overlay subtree (portalled by default)
   ├─ Tour.Backdrop
   ├─ Tour.Spotlight
   └─ Tour.Positioner
      └─ Tour.Content
         ├─ Tour.Arrow
         ├─ Tour.CloseIcon / Tour.CloseTrigger
         ├─ Tour.Body
         │  ├─ Tour.Title
         │  ├─ Tour.Description
         │  └─ Tour.ProgressText
         └─ Tour.Control
            ├─ Tour.ActionList
            └─ Tour.Actions
               └─ Tour.ActionTrigger[action]
```

| Part | Role |
| --- | --- |
| `Tour` / `Tour.Root` | Root bound to the object returned by `useTour`. |
| `Tour.Backdrop` / `Tour.Spotlight` | Optional page overlay and highlight for the current target. |
| `Tour.Positioner` / `Tour.Content` | Position and render Ark's `alertdialog` surface. |
| `Tour.Arrow` | Renders moduix's `ArrowTip` by default for tooltip steps. |
| `Tour.CloseIcon` / `Tour.CloseTrigger` | Default accessible dismiss control or a custom close control. |
| `Tour.Body` | Scrollable moduix wrapper for the title, description, and progress text. |
| `Tour.Control` / `Tour.ActionList` | Recommended action row and the actions from the current step. |
| `Tour.Actions` / `Tour.ActionTrigger` | Custom action UI while preserving each Ark action object. |

## Composition

Create state with `useTour` and pass its return value to `Tour`; in Solid, the return value is an accessor, so call
`tour()` to use methods such as `start()` and `next()`. Keep the structural parts explicit and include `Title` and
`Description` so the alert dialog has an accessible name and description. `Backdrop`, `Spotlight`, and `Positioner`
are portalled by default; use `portalled={false}` or `portalRef` only when the overlay must stay in or target a specific
container. Use `ActionList` for the actions declared in `steps`, or replace it with `Actions` and
`ActionTrigger asChild` when each action needs custom markup. `lazyMount` and `unmountOnExit` default to `true`; pass
callbacks to `useTour` when surrounding UI or analytics need to react to step or status changes.

### Styling hooks

Use moduix `data-slot` hooks such as `tour-content`, `tour-body`, and `tour-action-trigger` for local styling. Ark also
provides `data-scope="tour"`, `data-part`, `data-state`, `data-type`, `data-placement`, `data-side`, `data-step`, and
`data-disabled`, plus runtime variables including `--tour-layer`, `--tour-z-index`, `--available-width`,
`--available-height`, `--transform-origin`, and the arrow variables. Pass `className` to `Tour.ActionList` to style
every generated trigger. The stylesheet shortens overlay animations and removes action-button transitions for people
who prefer reduced motion.
