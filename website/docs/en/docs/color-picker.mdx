## Usage

<Usage />

Start with a compact field that combines a root, one channel input, the trigger's default swatch,
explicit popup content, and the picker's default internal parts. Add `ColorPickerHiddenInput`
explicitly when the color should be submitted with a form.

## Choosing the right component

Choose `ColorPicker` when users need to pick or fine-tune a color. Choose `Input` when they only need
to enter a known value and do not need to manipulate the color directly.

## Composition

Use `defaultValue` for local state. When application state controls the selected color or popup, pass `value` with `onValueChange(details)` or `open` with `onOpenChange(details)`. In Vue, bind the same state with `v-model`, `v-model:open`, and `v-model:format`. In Svelte, use `bind:value`, `bind:open`, and `bind:format`. For state created outside the rendered tree, pass `useColorPicker()` to `ColorPickerRootProvider`; do not render `ColorPicker` and `ColorPickerRootProvider` for the same store.

`ColorPickerPositioner` is portalled by default. Set `portalled={false}` for an overlay inside another stacking context. To submit the color with a native form, set `name` on the root and render `ColorPickerHiddenInput` explicitly. Parts such as `ColorPickerArea`, `ColorPickerChannelSlider`, and `ColorPickerSwatchTrigger` provide default visual children; pass children only when changing their structure.

In Solid, assign a ref to the element created inside the `asChild` render function. A ref on a
ColorPicker part itself is not forwarded through that composition path. In Vue, use the ordinary
template `ref` on a part and read the rendered element through `$el`. In Svelte, use `bind:ref` on a part to get its element.

## Styling

Use `className` in React or `class` in Solid, Vue, and Svelte on exported parts. Tailwind variants use native utilities and consumer classes; CSS Modules variants expose a short list of `--moduix-color-picker-*` variables for sizes that several parts or default children share; colors, spacing, and typography follow foundation tokens, so change them with a class on the part. Both styling tracks expose stable `data-slot="color-picker-*"` hooks and Ark `data-scope` / `data-part` attributes.

Use the part that renders the element you want to style:

- `ColorPicker` for width, gap, shared color, and disabled opacity
- `ColorPickerControl`, `ColorPickerChannelInput`, `ColorPickerTrigger`, `ColorPickerFormatSelect`, and `ColorPickerFormatTrigger` for the
  visible field controls
- `ColorPickerPositioner` and `ColorPickerContent` for popup layering, width, padding, radius,
  shadow, and state animations
- `ColorPickerArea`, `ColorPickerAreaBackground`, and `ColorPickerAreaThumb` for the two-dimensional color surface
- `ColorPickerChannelSlider`, `ColorPickerChannelSliderTrack`, `ColorPickerChannelSliderThumb`, and `ColorPickerSliders` for hue,
  alpha, and other channel sliders
- `ColorPickerSwatchGroup`, `ColorPickerSwatchTrigger`, `ColorPickerSwatch`, and `ColorPickerSwatchIndicator` for preset color
  grids
- `ColorPickerValueSwatch`, `ColorPickerValueText`, `ColorPickerView`, and `ColorPickerTransparencyGrid` for value display and
  format-specific layouts

The main state hooks are `data-state`, `data-focus`, `data-invalid`, `data-disabled`,
`data-readonly`, `data-required`, `data-channel`, `data-orientation`, `data-value`,
`data-placement`, and `data-side`. Ark runtime variables include `--color`, `--value`,
`--available-width`, `--available-height`, and `--transform-origin`.

When `prefers-reduced-motion` is enabled, popup entry and exit animations are disabled; Ark still
completes its exit lifecycle.

## Keyboard

| Key | Action |
| --- | --- |
| `Enter` / `Space` | Opens the picker from the trigger. |
| `ArrowUp` / `ArrowDown` / `ArrowLeft` / `ArrowRight` | Moves the thumb of the focused area or slider. |
| `Esc` | Closes the picker. |

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `Color` | — | Color for controlled use; create it with `parseColor()`. |
| `defaultValue` | `Color` | `#000000` | Initial color when it is not controlled. |
| `onValueChange` | `(details: ValueChangeDetails) => void` | — | Called while the color changes, including during drags. |
| `onValueChangeEnd` | `(details: ValueChangeDetails) => void` | — | Called when the user stops dragging. |
| `format` | `'rgba' \| 'hsla' \| 'hsba'` | — | Color format for controlled use: `rgba`, `hsla`, or `hsba`. |
| `defaultFormat` | `'rgba' \| 'hsla' \| 'hsba'` | `'rgba'` | Initial color format. |
| `open` | `boolean` | — | Open state for controlled use. |
| `defaultOpen` | `boolean` | `false` | Initial open state when it is not controlled. |
| `onOpenChange` | `(details: OpenChangeDetails) => void` | — | Called when it opens or closes. |
| `inline` | `boolean` | `false` | Renders the picker in place instead of in a popup. |
| `closeOnSelect` | `boolean` | `false` | Closes the popup when a swatch is picked. |
| `positioning` | `PositioningOptions` | — | Placement, offset, and other popup positioning options. |
| `name` | `string` | — | Form field name of the underlying input. |
| `disabled` | `boolean` | `false` | Disables the control. |
| `readOnly` | `boolean` | `false` | Shows the value but prevents changes. |
| `invalid` | `boolean` | `false` | Marks the control as invalid. |
| `required` | `boolean` | `false` | Requires a value before form submission. |
| `lazyMount` | `boolean` | `true` | Mounts the content on first open. |
| `unmountOnExit` | `boolean` | `true` | Unmounts the content after it closes. |
| `initialFocusEl` | `() => HTMLElement \| null \| false` | — | Element to focus when the popup opens. |
| `onFormatChange` | `(details: FormatChangeDetails) => void` | — | Called when the color format changes. |
| `openAutoFocus` | `boolean` | `true` | Moves focus into the popup when it opens. |
| `onPointerDownOutside` | `(event: PointerDownOutsideEvent) => void` | — | Called when the pointer is pressed outside the popup. |
| `onFocusOutside` | `(event: FocusOutsideEvent) => void` | — | Called when focus moves outside the popup. |
| `onInteractOutside` | `(event: InteractOutsideEvent) => void` | — | Called on any interaction outside the popup. |
