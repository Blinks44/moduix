## Usage

<Usage />

Use `DatePicker` as the root, `DatePickerField` for a standard field, and
`DatePickerDayTable`, `DatePickerMonthTable`, and `DatePickerYearTable` for the calendar views. Each table
renders its own header, so the view trigger can switch between them. Render `DatePickerPositioner` and
`DatePickerContent` explicitly when the calendar should float.

## Choosing the right component

- Choose **`Input`** for plain date text when calendar behavior is not needed.
- Choose **`DateInput`** for keyboard-first segmented date entry.
- Choose **`DatePicker`** when users need an editable date field with a popup or inline calendar.

## Examples

### Range

Use `selectionMode="range"` with two values. Ark manages range hover, the first and last day in
the range, and input formatting. A range uses two indexed inputs, one for each date.

<Example name="date-picker/range" />

### Multiple dates

Use `selectionMode="multiple"` and optionally cap the number of selections with
`maxSelectedDates`. Render selected-date chips through `DatePickerContext` and call
`datePicker.setValue()` when a chip is removed.

<Example name="date-picker/multiple" />

### Presets

`DatePickerPresetTrigger` accepts built-in range preset names such as `last7Days`, or a custom
`DateValue[]`. Use range mode with two indexed inputs so the selected preset displays both dates.

<Example name="date-picker/presets" />

### Date and time

Keep the time in the selected value by storing `CalendarDateTime` objects. Pair the calendar with
a `DateInput` configured for minute input so both controls edit the same value.

<Example name="date-picker/with-time" />

### Select today

Use `DatePickerContext` when a nearby control needs to call helpers such as `selectToday()`.

<Example name="date-picker/select-today" />

### Month and year selects

Use `DatePickerMonthSelect` and `DatePickerYearSelect` for native selects linked to the focused
date. Use `DatePickerContext` only when composing a different custom header or calendar layout.

<Example name="date-picker/month-year-select" />

### Month picker

Set `defaultView="month"` and `minView="month"` to let users select a month only. Use `format`
and `parse` when the input should accept a month and year string.

<Example name="date-picker/month-picker" />

### Year picker

Set `defaultView="year"`, `minView="year"`, and `maxView="year"` to let users select a year only.
Use `DatePickerRangeText` in the header because the year view has no higher view to switch to.

<Example name="date-picker/year-picker" />

### Multiple months

Set `numOfMonths` when users need to see more than one month while choosing dates. Render one
`DatePickerDayTable` per month and pass `offset={1}` to the second one.

<Example name="date-picker/multiple-months" />

### Inline calendar and week numbers

Set `inline` when the calendar should stay in the document flow. An inline calendar renders
`DatePickerContent` directly, without `DatePickerPositioner`. Set `showWeekNumbers` on the root;
`DatePickerDayTable` reads it and adds the week-number column.

<Example name="date-picker/inline-and-week-numbers" />

### Default view and fixed weeks

Use `defaultView` to open a different panel. Add `fixedWeeks` to keep the day view at a stable
six-row height while users navigate between months.

<Example name="date-picker/default-view-and-fixed-weeks" />

### Locale and format

`locale`, `startOfWeek`, `format`, and `parse` are passed through to Ark.

<Example name="date-picker/locale-and-format" />

### Minimum, maximum, and unavailable dates

Use `min`, `max`, and `isDateUnavailable` for validation rules that should affect both the input
and calendar cells.

<Example name="date-picker/min-max-and-unavailable" />

### Field state

`DatePicker` reads field state from Ark. Set `invalid`, `disabled`, `readOnly`, and `required` on
the root when you are not composing it through `Field`.

<Example name="date-picker/field-state" />

### Form

Pass `name` to include the selected date in native form submission. `DatePickerField` provides
the locale-aware placeholder and translated action labels unless you override them.

<Example name="date-picker/form" />

### Controlled

Control the selected `DateValue[]` by updating it with `details.value`. In Vue, use `v-model` for
the controlled value; in Svelte, use `bind:value`. See [Control state from the application](/docs/composition-patterns#controlled-state).

<Example name="date-picker/controlled" />

### Root provider

Use `useDatePicker()` from the matching framework package with `DatePickerRootProvider` when
calendar state must be shared with controls outside the root tree. See [Share state outside the tree](/docs/composition-patterns#root-provider).

<Example name="date-picker/root-provider" />

### Build from parts

The same picker as Basic, without `DatePickerField` and the table helpers: the control holds the
input, clear trigger, and trigger, and each view renders its own header and grid from
`DatePickerContext`. Triggers receive explicit icons. Start here when the field or the calendar cells
need custom rendering, such as a class or extra content on individual days.

<Example name="date-picker/build-from-parts" />

## Composition

Use `DatePickerField` for a standard single-date field, `DatePickerRangeField` for a range, and
`DatePickerDayTable`, `DatePickerMonthTable`, and `DatePickerYearTable` inside the matching views. Pass
`showHeader={false}` to a table when the header is composed separately. Use `DatePickerRootProvider` with `useDatePicker()`
when state must be shared with controls outside the root tree.

For a custom field or calendar grid, compose `DatePickerControl`, `DatePickerInput`,
`DatePickerTrigger`, `DatePickerClearTrigger`, and the `DatePickerTable*` parts directly. Read
`weekDays`, `weeks`, or grid helpers through `DatePickerContext`. In multiple-selection mode, render
selected values through `DatePickerContext` because one input cannot
represent the full list, and call `setValue()` when a value is removed.

The root portals the popup automatically. Use `portalled={false}` for the current DOM subtree,
`portalRef` for a custom container, or `inline` when `DatePickerContent` should stay in normal document flow.

## Keyboard

| Key | Action |
| --- | --- |
| `ArrowLeft` / `ArrowRight` / `ArrowUp` / `ArrowDown` | Moves focus by a day or a week in the calendar. |
| `PageUp` / `PageDown` | Goes to the previous or next month; with Shift, the year. |
| `Home` / `End` | Moves to the start or end of the week. |
| `Enter` / `Space` | Selects the focused date. |
| `Esc` | Closes the calendar. |
