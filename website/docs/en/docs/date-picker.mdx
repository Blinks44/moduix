## Choosing the right component

- Choose **`Input`** for plain date text when calendar behavior is not needed.
- Choose **`DateInput`** for keyboard-first segmented date entry.
- Choose **`DatePicker`** when users need an editable date field with a popup or inline calendar.

## Anatomy

```text
DatePicker
├─ DatePickerLabel
├─ DatePickerControl
│  ├─ DatePickerInput
│  ├─ DatePickerClearTrigger
│  └─ DatePickerTrigger
├─ DatePickerField / DatePickerRangeField (convenience controls)
├─ Overlay subtree (portalled automatically)
│  └─ DatePickerPositioner
│     └─ DatePickerContent
│        ├─ DatePickerView[view="day" | "month" | "year"]
│        │  ├─ DatePickerViewControl
│        │  │  ├─ DatePickerPrevTrigger
│        │  │  ├─ DatePickerViewTrigger / DatePickerRangeText
│        │  │  └─ DatePickerNextTrigger
│        │  ├─ DatePickerDayTable (convenience day table)
│        │  └─ DatePickerTable
│        │     ├─ DatePickerTableHead / TableBody / TableRow
│        │     ├─ DatePickerTableHeader
│        │     ├─ DatePickerTableCell
│        │     ├─ DatePickerTableCellTrigger
│        │     ├─ DatePickerWeekNumberHeaderCell
│        │     └─ DatePickerWeekNumberCell
│        ├─ DatePickerMonthSelect / DatePickerYearSelect
│        └─ DatePickerPresetTrigger
├─ DatePickerValueText (optional selected-value summary)
└─ DatePickerContext

DatePickerRootProvider
└─ same part tree connected to a useDatePicker() store
```

| Part                              | Role                                                               |
| --------------------------------- | ------------------------------------------------------------------ |
| `DatePicker`                    | Root that manages value, view, open state, locale, validation, and form context. |
| `DatePickerRootProvider`         | Renders parts using state returned by `useDatePicker()`.           |
| `DatePickerLabel`                | Accessible label for the date field.                              |
| `DatePickerControl`              | Field wrapper for custom input layouts.                           |
| `DatePickerField`                | Convenience control with an input, clear trigger, and open trigger. |
| `DatePickerRangeField`           | Convenience range control with indexed start and end inputs.      |
| `DatePickerInput`                | Editable date input that participates in native form submission.   |
| `DatePickerTrigger`              | Opens the calendar.                                                |
| `DatePickerClearTrigger`         | Clears the current value.                                          |
| `DatePickerPositioner`           | Positions the popup.                                               |
| `DatePickerContent`              | Calendar container for popup or inline mode.                       |
| `DatePickerView`                 | Day, month, or year panel.                                          |
| `DatePickerViewControl`          | Header containing calendar navigation controls.                    |
| `DatePickerPrevTrigger`          | Moves to the previous month, year, or decade.                      |
| `DatePickerNextTrigger`          | Moves to the next month, year, or decade.                          |
| `DatePickerViewTrigger`          | Switches between calendar views.                                   |
| `DatePickerRangeText`            | Displays the visible date range in the calendar header.            |
| `DatePickerValueText`            | Displays selected values.                                          |
| `DatePickerDayTable`             | Standard day-view table.                                           |
| `DatePickerTable*`               | Parts for a custom calendar grid.                                  |
| `DatePickerWeekNumberHeaderCell` | Header cell for the week-number column.                            |
| `DatePickerWeekNumberCell`       | Body cell for a week number.                                       |
| `DatePickerMonthSelect`          | Native month select linked to the focused date.                    |
| `DatePickerYearSelect`           | Native year select linked to the focused date.                     |
| `DatePickerPresetTrigger`        | Button for a predefined range.                                     |
| `DatePickerContext`              | Renderless access to calendar state.                               |

## Composition

Use `DatePickerField` for a standard single-date field, `DatePickerRangeField` for a range, and
`DatePickerDayTable` inside the day view. Use `DatePickerRootProvider` with `useDatePicker()`
when state must be shared with controls outside the root tree.

For a custom field or calendar grid, compose `DatePickerControl`, `DatePickerInput`,
`DatePickerTrigger`, `DatePickerClearTrigger`, and the `DatePickerTable*` parts directly. Read
`weekDays`, `weeks`, or grid helpers through `DatePickerContext`. In multiple-selection mode, render
selected values through `DatePickerContext` because one input cannot
represent the full list, and call `setValue()` when a value is removed.

The root portals the popup automatically. Use `portalled={false}` for the current DOM subtree,
`portalRef` for a custom container, or `inline` when `DatePickerContent` should stay in normal document flow.

### Styling hooks

Use these `data-slot` hooks to target individual parts:

- `date-picker-root`, `date-picker-root-provider`, `date-picker-label`, `date-picker-control`, and `date-picker-input`.
- `date-picker-trigger`, `date-picker-clear-trigger`, and `date-picker-value-text`.
- `date-picker-positioner`, `date-picker-content`, `date-picker-view`, and `date-picker-view-control`.
- `date-picker-view-trigger`, `date-picker-prev-trigger`, `date-picker-next-trigger`, and `date-picker-range-text`.
- `date-picker-table-*`, `date-picker-table-cell-trigger`, `date-picker-week-number-header-cell`, and `date-picker-week-number-cell`.
- `date-picker-month-select`, `date-picker-year-select`, and `date-picker-preset-trigger`.

Ark state attributes include `data-state`, `data-disabled`, `data-readonly`, `data-invalid`,
`data-focus`, `data-selected`, `data-today`, `data-unavailable`, `data-outside-range`,
`data-in-range`, `data-range-start`, `data-range-end`, `data-in-hover-range`,
`data-hover-range-start`, `data-hover-range-end`, and `data-view`.
