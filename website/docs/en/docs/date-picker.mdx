## Choosing the right component

- Choose **`Input`** for plain date text when calendar behavior is not needed.
- Choose **`DateInput`** for keyboard-first segmented date entry.
- Choose **`DatePicker`** when users need an editable date field with a popup or inline calendar.

## Anatomy

```text
DatePicker / DatePicker.Root
├─ DatePicker.Label
├─ DatePicker.Control
│  ├─ DatePicker.Input
│  ├─ DatePicker.ClearTrigger
│  └─ DatePicker.Trigger
├─ DatePicker.Field / DatePicker.RangeField (convenience controls)
├─ Overlay subtree (portalled automatically)
│  └─ DatePicker.Positioner
│     └─ DatePicker.Content
│        ├─ DatePicker.View[view="day" | "month" | "year"]
│        │  ├─ DatePicker.ViewControl
│        │  │  ├─ DatePicker.PrevTrigger
│        │  │  ├─ DatePicker.ViewTrigger / DatePicker.RangeText
│        │  │  └─ DatePicker.NextTrigger
│        │  ├─ DatePicker.DayTable (convenience day table)
│        │  └─ DatePicker.Table
│        │     ├─ DatePicker.TableHead / TableBody / TableRow
│        │     ├─ DatePicker.TableHeader
│        │     ├─ DatePicker.TableCell
│        │     ├─ DatePicker.TableCellTrigger
│        │     ├─ DatePicker.WeekNumberHeaderCell
│        │     └─ DatePicker.WeekNumberCell
│        ├─ DatePicker.MonthSelect / DatePicker.YearSelect
│        └─ DatePicker.PresetTrigger
├─ DatePicker.ValueText (optional selected-value summary)
└─ DatePicker.Context

DatePicker.RootProvider
└─ same part tree connected to a useDatePicker() store
```

| Part                              | Role                                                               |
| --------------------------------- | ------------------------------------------------------------------ |
| `DatePicker` / `DatePicker.Root`  | Root that manages value, view, open state, locale, validation, and form context. |
| `DatePicker.RootProvider`         | Renders parts using state returned by `useDatePicker()`.           |
| `DatePicker.Label`                | Accessible label for the date field.                              |
| `DatePicker.Control`              | Field wrapper for custom input layouts.                           |
| `DatePicker.Field`                | Convenience control with an input, clear trigger, and open trigger. |
| `DatePicker.RangeField`           | Convenience range control with indexed start and end inputs.      |
| `DatePicker.Input`                | Editable date input that participates in native form submission.   |
| `DatePicker.Trigger`              | Opens the calendar.                                                |
| `DatePicker.ClearTrigger`         | Clears the current value.                                          |
| `DatePicker.Positioner`           | Positions the popup.                                               |
| `DatePicker.Content`              | Calendar container for popup or inline mode.                       |
| `DatePicker.View`                 | Day, month, or year panel.                                          |
| `DatePicker.ViewControl`          | Header containing calendar navigation controls.                    |
| `DatePicker.PrevTrigger`          | Moves to the previous month, year, or decade.                      |
| `DatePicker.NextTrigger`          | Moves to the next month, year, or decade.                          |
| `DatePicker.ViewTrigger`          | Switches between calendar views.                                   |
| `DatePicker.RangeText`            | Displays the visible date range in the calendar header.            |
| `DatePicker.ValueText`            | Displays selected values.                                          |
| `DatePicker.DayTable`             | Standard day-view table.                                           |
| `DatePicker.Table*`               | Parts for a custom calendar grid.                                  |
| `DatePicker.WeekNumberHeaderCell` | Header cell for the week-number column.                            |
| `DatePicker.WeekNumberCell`       | Body cell for a week number.                                       |
| `DatePicker.MonthSelect`          | Native month select linked to the focused date.                    |
| `DatePicker.YearSelect`           | Native year select linked to the focused date.                     |
| `DatePicker.PresetTrigger`        | Button for a predefined range.                                     |
| `DatePicker.Context`              | Renderless access to calendar state.                               |

## Composition

Use `DatePicker.Field` for a standard single-date field, `DatePicker.RangeField` for a range, and
`DatePicker.DayTable` inside the day view. Use `DatePicker.RootProvider` with `useDatePicker()`
when state must be shared with controls outside the root tree.

For a custom field or calendar grid, compose `Control`, `Input`, `Trigger`, `ClearTrigger`, and
the `Table*` parts directly. Read `weekDays`, `weeks`, or grid helpers through `DatePicker.Context`.
In multiple-selection mode, render selected values through `Context` because one input cannot
represent the full list, and call `setValue()` when a value is removed.

The root portals the popup automatically. Use `portalled={false}` for the current DOM subtree,
`portalRef` for a custom container, or `inline` when `Content` should stay in normal document flow.

### Styling hooks

Use these `data-slot` hooks to target individual parts:

- `date-picker-root`, `date-picker-root-provider`, `date-picker-label`, `date-picker-control`, and `date-picker-input`.
- `date-picker-trigger`, `date-picker-clear-trigger`, and `date-picker-value-text`.
- `date-picker-positioner`, `date-picker-content`, `date-picker-view`, and `date-picker-view-control`.
- `date-picker-view-trigger`, `date-picker-prev-trigger`, `date-picker-next-trigger`, and `date-picker-range-text`.
- `date-picker-table-*`, `date-picker-table-cell-trigger`, `date-picker-week-number-header-cell`, and `date-picker-week-number-cell`.
- `date-picker-month-select`, `date-picker-year-select`, and `date-picker-preset-trigger`.

Ark state attributes include `data-state`, `data-disabled`, `data-readonly`, `data-invalid`,
`data-focus`, `data-selected`, `data-today`, `data-unavailable`, `data-outside-range`,
`data-in-range`, `data-range-start`, `data-range-end`, `data-in-hover-range`,
`data-hover-range-start`, `data-hover-range-end`, and `data-view`.
