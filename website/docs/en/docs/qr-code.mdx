## Usage

<UsageCode
  react={'<QrCode defaultValue="https://moduix.dev" encoding={{ ecc: \'H\' }}>\n  <QrCodeFrame role="img" aria-label="QR code for moduix.dev">\n    <QrCodePattern />\n  </QrCodeFrame>\n  <QrCodeDownloadTrigger fileName="moduix.png" mimeType="image/png">Download</QrCodeDownloadTrigger>\n</QrCode>'}

/>

<PropChips
  items={[
    ['defaultValue', 'Text or URL to encode; use value to control it.'],
    ['encoding', 'Error correction level L, M, Q, or H.'],
    ['QrCodeDownloadTrigger', 'Saves the code as an image file.'],
  ]}
/>

Use `QrCode` for the usual case. Pass the content to encode with `defaultValue`, then render
`QrCodeFrame` and `QrCodePattern` to display the generated SVG. Give `QrCodeFrame` an accessible
name when the QR code conveys information.

## Examples

### Fill

The QR modules use `currentColor` by default. Change the SVG fill with `style` or a class on
`QrCodeFrame`, or set the text color of a parent.

<Example name="qr-code/fill" />

### Overlay

Use `QrCodeOverlay` for a compact logo or text mark. Set a high error-correction level and keep the
overlay small enough that scanners can still read the code.

<Example name="qr-code/overlay" />

### Error correction

Use `encoding.ecc` to choose how much damaged data the QR code can recover. Higher levels help when
an overlay covers part of the code or when the code may be scratched or distorted.

- `L`: recovers up to 7% of damaged data.
- `M`: recovers up to 15%.
- `Q`: recovers up to 25%.
- `H`: recovers up to 30%.

<Example name="qr-code/error-correction" />

### Download

Add `QrCodeDownloadTrigger` when users need to save the generated code as an image. Set both
`fileName` and `mimeType` on the trigger.

<Example name="qr-code/download" />

### Input

Bind `value` to a text field when users need to enter or edit the content encoded in the QR code.
Give the frame an accessible name that explains what the code represents.

<Example name="qr-code/input" />

### Controlled

Control `value` when the QR code should follow a selected destination or another piece of application
state. See [Control state from the application](/docs/composition-patterns#controlled-state).

<Example name="qr-code/controlled" />

### Root provider

Create QR state with `useQrCode()` when it must be shared with controls outside the QR tree, then
pass that state to `QrCodeRootProvider`. See [Share state outside the tree](/docs/composition-patterns#root-provider).

## Composition

Use `defaultValue` for an uncontrolled QR code. When application state controls the value, use `value`
with `onValueChange(details)` and read the new value from `details.value`. Create state with
`useQrCode()` from the matching framework package and pass it to `QrCodeRootProvider` when it must
be shared outside the QR tree. Do not render `QrCode` and `QrCodeRootProvider` for the same store.

Use `QrCodeContext` or `useQrCodeContext()` when a descendant needs the current QR API. Add
`QrCodeOverlay` only with enough error correction for the covered area, then test the final code
with the scanners your users rely on.

## Styling

Use `className` in React or `class` in Solid and Vue on exported parts for structural styles. Tailwind
variants use native utilities and consumer classes; the variables below customize the CSS Modules
variants. Data attributes and `data-slot` hooks are shared by both styling tracks.

The CSS Variables panel lists the complete public variable set. Ark also sets
`--qrcode-pixel-size`, `--qrcode-width`, and `--qrcode-height` on the root at runtime.
