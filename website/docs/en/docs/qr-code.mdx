`QrCodeFrame` and `QrCodePattern` to display the generated SVG. Give `QrCodeFrame` an accessible

## Anatomy

```text
QrCode
├─ QrCodeFrame
│  └─ QrCodePattern
├─ QrCodeOverlay
└─ QrCodeDownloadTrigger

QrCodeRootProvider
└─ same part tree connected to a useQrCode() store
```

| Part                     | Role                                                                    |
| ------------------------ | ----------------------------------------------------------------------- |
| `QrCode`                 | Owns the encoded value and generation options, and provides QR state.   |
| `QrCodeRootProvider`     | Connects the parts to state created with `useQrCode()`.                 |
| `QrCodeFrame`            | SVG element that contains the generated QR code.                       |
| `QrCodePattern`          | SVG path that draws the QR modules.                                     |
| `QrCodeOverlay`          | Centered content rendered over the QR code.                             |
| `QrCodeDownloadTrigger`  | Button that downloads the current QR code as an image.                  |

## Composition

Use `defaultValue` for an uncontrolled QR code. When application state owns the value, use `value`
with `onValueChange(details)` and read the new value from `details.value`. Create state with
`useQrCode()` from the matching framework package and pass it to `QrCodeRootProvider` when it must
be shared outside the QR tree. Do not render `QrCode` and `QrCodeRootProvider` for the same store.

Use `QrCodeContext` or `useQrCodeContext()` when a descendant needs the current QR API. Add
`QrCodeOverlay` only with enough error correction for the covered area, then test the final code
with the scanners your users rely on.

### Error Correction

Use `encoding.ecc` to choose how much damaged data the QR code can recover. Higher levels help when
an overlay covers part of the code or when the code may be scratched or distorted.

- `L`: recovers up to 7% of damaged data.
- `M`: recovers up to 15%.
- `Q`: recovers up to 25%.
- `H`: recovers up to 30%.

## Styling

Use `className` in React or `class` in Solid on exported parts for structural styles. Tailwind
variants use native utilities and consumer classes; the variables below customize the CSS Modules
variants. Data attributes and `data-slot` hooks are shared by both styling tracks.

The CSS Variables panel lists the complete public variable set. Ark also sets
`--qrcode-pixel-size`, `--qrcode-width`, and `--qrcode-height` on the root at runtime.

### Styling hooks

- Stable `data-slot` selectors: `qr-code-root`, `qr-code-root-provider`, `qr-code-frame`,
  `qr-code-pattern`, `qr-code-overlay`, and `qr-code-download-trigger`.
- Ark part selectors: `data-scope="qr-code"` and
  `data-part="root|frame|pattern|overlay|download-trigger"`.
