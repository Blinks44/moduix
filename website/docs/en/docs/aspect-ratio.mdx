## API Reference

Ark UI does not ship a dedicated `aspect-ratio` primitive. moduix builds this component with the official
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory), follows Ark's
[composition](https://ark-ui.com/docs/guides/composition), [styling](https://ark-ui.com/docs/guides/styling), and
[ref](https://ark-ui.com/docs/guides/ref) guidance.

## Basic

Start with `AspectRatio`. Set width or max-width on the root element and pass a finite, positive
number to `ratio`. Direct `img`, `video`, `iframe`, `canvas`, and `svg` children fill the frame
automatically. Set `object-fit` on images and videos when you want to crop or contain their content.

## Composition

### Recommended composition

Use `AspectRatio` for most media frames. Put sizing, border-radius, and layout classes on the root.
`AspectRatio.Root` exposes the same root under a namespace for consistency with the rest of the library.

- `ratio` is required and numeric; pass a finite value greater than zero for valid CSS behavior
- `asChild` uses Ark factory composition and requires exactly one React element
- direct `img`, `video`, `iframe`, `canvas`, and `svg` children fill the frame automatically; set
  `object-fit` on images and videos to choose whether their content is cropped or contained
- `className` applies styles and sizing directly to the root
- `--moduix-aspect-ratio-radius` controls the frame's default corner radius

### When to add a wrapper

Wrap `AspectRatio` in another element when shadows, focus rings, or decorative layout elements need
to extend beyond the clipped frame. Keep clipping on the root, and override its `aspect-ratio` in
your CSS when the frame needs a different ratio at a particular breakpoint.

### Default props

| Entry                          | Default                   | Values / Notes                       |
| ------------------------------ | ------------------------- | ------------------------------------ |
| `ratio`                        | -                         | Required positive finite `number`    |
| `className`                    | `undefined`               | Applies styles and sizing to the root |
| `style`                        | `undefined`               | Can override `aspect-ratio` directly |
| `asChild`                      | `undefined`               | Ark factory composition              |
| `--moduix-aspect-ratio-radius` | `var(--moduix-radius-md)` | CSS length or token value            |

### Behavioral notes

- The root renders with `data-scope="aspect-ratio"`, `data-part="root"`, and
  `data-slot="aspect-ratio-root"`.
- The root is block-level and uses border-box sizing, even when `asChild` changes which element is
  rendered.
- `position: relative` on the root is intentional and supports absolutely positioned children that
  fill the frame, such as Next.js `Image fill`.
- Direct `iframe` children fill the frame without the browser's default border.
- The previous preset strings (`square`, `video`, `portrait`, `photo`) were removed during the Ark
  migration. Use numbers such as `1`, `16 / 9`, `9 / 16`, and `4 / 3`.

### Styling hooks

- `data-scope="aspect-ratio"` and `data-part="root"` are Ark-aligned hooks on the root.
- `data-slot="aspect-ratio-root"` is the stable moduix root hook.
- Put width, max-width, and layout styles on the root. Override `aspect-ratio` in your own CSS when
  the frame needs a different ratio at a particular breakpoint.
- Direct media uses border-box sizing. Images and videos keep their own `object-fit` value so you
  can choose between cropping and containment.
- `overflow: hidden` is intentional. If decoration must extend beyond the frame, put it on an outer
  wrapper instead of removing clipping from the root.
