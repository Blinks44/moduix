## API Reference

Ark UI does not ship a dedicated `aspect-ratio` primitive. moduix builds this component with the official
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) and follows Ark's guidance for
[composition](https://ark-ui.com/docs/guides/composition), [styling](https://ark-ui.com/docs/guides/styling), and
[refs](https://ark-ui.com/docs/guides/ref).

Import `AspectRatio` from the matching runtime and styling package: `@moduix/react/aspect-ratio` or
`@moduix/solid/aspect-ratio` for CSS Modules, and the corresponding `@moduix/react-tailwind/aspect-ratio` or
`@moduix/solid-tailwind/aspect-ratio` subpath for Tailwind.

## Basic

AspectRatio ships for React and Solid in both the CSS Modules and Tailwind packages. The rendered preview on this
page uses the React CSS Modules package; the framework tabs show native source for the same public contract.

Use `AspectRatio` as the root for a responsive frame. It fills the width of its containing block by default.
Add `width` or `max-width` to the root when the frame needs a different size, then pass a finite, positive
number to `ratio`.

Direct `img`, `video`, `iframe`, `canvas`, and `svg` children fill the frame automatically. Other children are not
sized automatically, so add the styles they need. Set `object-fit` on images and videos when you want to crop
their content or contain it within the frame.

## Anatomy

```text
AspectRatio / AspectRatio.Root
└─ media | iframe | canvas | svg | custom content
```

| Part                               | Role                                      |
| ---------------------------------- | ----------------------------------------- |
| `AspectRatio` / `AspectRatio.Root` | Responsive frame that clips its contents. |

## Composition

`AspectRatio` is presentational and owns no state. Use the callable `AspectRatio` root in the usual case;
`AspectRatio.Root` is an alias when you want to make the root part explicit. The component has one root part and
no child parts to combine. Use `asChild` only when another semantic element must own the rendered root, and provide
exactly one child in React or the Solid render-function form shown in Advanced customization.

<CssPropertiesSection properties={AspectRatioDocs.aspectRatioCssProperties} />

### Styling hooks

- `data-scope="aspect-ratio"` and `data-part="root"` are Ark-aligned hooks on the root.
- `data-slot="aspect-ratio-root"` is the stable moduix root hook.
- Put width, max-width, and layout styles on the root. Override `aspect-ratio` in your own CSS when the frame
  needs a different ratio at a particular breakpoint.
- Direct media uses border-box sizing. Images and videos keep their own `object-fit` value, so you can choose
  between cropping and containment.
- `overflow: hidden` is intentional. If decoration must extend beyond the frame, put it on an outer wrapper
  instead of removing clipping from the root.
