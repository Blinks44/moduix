## API Reference

Ark UI does not ship a dedicated `aspect-ratio` primitive. moduix builds this component with the official
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) and follows Ark's guidance for
[composition](https://ark-ui.com/docs/guides/composition), [styling](https://ark-ui.com/docs/guides/styling), and
[refs](https://ark-ui.com/docs/guides/ref).

Import `AspectRatio` from the matching runtime and styling package: `@moduix/react/aspect-ratio`,
`@moduix/solid/aspect-ratio`, or `@moduix/vue/aspect-ratio` for CSS Modules, and the corresponding
`@moduix/react-tailwind/aspect-ratio`, `@moduix/solid-tailwind/aspect-ratio`, or
`@moduix/vue-tailwind/aspect-ratio` subpath for Tailwind.

## Basic


Use `AspectRatio` as the root for a responsive frame. It fills the width of its containing block by default.
Add `width` or `max-width` to the root when the frame needs a different size, then pass the width-to-height
ratio to `ratio`. It defaults to `1`; a missing or invalid value (zero, negative, `NaN`) falls back to `1`.

`AspectRatio` owns only the ratio layout. Size and style its children explicitly-for example, apply full width,
full height, and `object-fit` to an image. Put clipping and border radius on the root when the composition needs
them.

## Composition

`AspectRatio` is presentational and owns no state. The component has one root part and
no child parts to combine. Use `asChild` only when another semantic element must own the rendered root, and provide
exactly one child in React or the Solid render-function form shown in Advanced customization. Vue uses the
`as-child` attribute with a single child element. Child sizing,
fitting, borders, radius, and clipping remain owned by the application.

In Solid, assign a ref to the element created inside the `asChild` render function. A ref on
`AspectRatio` itself is not forwarded through that composition path.

## Styling

### Styling hooks

- `data-scope="aspect-ratio"` and `data-part="root"` are Ark-aligned hooks on the root.
- `data-slot="aspect-ratio-root"` is the stable moduix root hook.
- Put width, max-width, and layout styles on the root. Override `aspect-ratio` in your own CSS when the frame
  needs a different ratio at a particular breakpoint.
- The component does not style its children. Apply media sizing and `object-fit` directly to the child.
- Content taller than the frame does not stretch it; it overflows. Add `overflow: hidden` and a border radius to
  the root when the composition needs clipping.
