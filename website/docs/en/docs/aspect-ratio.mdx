## Usage

<Usage />

Use `AspectRatio` as the root for a responsive frame. It fills the width of its containing block by default.
Add `width` or `max-width` to the root when the frame needs a different size, then pass the width-to-height
ratio to `ratio`. It defaults to `1`; a missing or invalid value (zero, negative, `NaN`, `Infinity`) falls back to `1`.

`AspectRatio` handles only the ratio layout. Size and style its children explicitly-for example, apply full width,
full height, and `object-fit` to an image. Put clipping and border radius on the root when the composition needs
them.

## Examples

### Common ratios

Pass the width divided by height to `ratio`: `1` for a square avatar or thumbnail, `4 / 3` for photos,
and `16 / 9` for video.

<Example name="aspect-ratio/common-ratios" />

### Responsive ratio

Set the ratio for small screens with `ratio`, then override `aspect-ratio` in your own class inside a
media query. The class wins over the component style, so this frame is square on phones and 21:9 from
40rem.

### Card layouts

Use the same aspect ratio for card media to keep repeated cards aligned, even when the source images have
different dimensions.

### Embedded content

Wrap a video or another embed in `AspectRatio` to keep the frame stable while external content loads.

## Composition

Import `AspectRatio` from the matching runtime and styling package: `@moduix/react/aspect-ratio`,
`@moduix/solid/aspect-ratio`, `@moduix/vue/aspect-ratio`, or `@moduix/svelte/aspect-ratio` for CSS Modules, and the corresponding
`@moduix/react-tailwind/aspect-ratio`, `@moduix/solid-tailwind/aspect-ratio`,
`@moduix/vue-tailwind/aspect-ratio`, or `@moduix/svelte-tailwind/aspect-ratio` subpath for Tailwind.

`AspectRatio` is presentational and has no state. The component has one root part and
no child parts to combine. Use `asChild` only when another semantic element must own the rendered root, and provide
exactly one child in React or the Solid render-function form shown in Custom Element. Vue uses the
`as-child` attribute with a single child element. Svelte uses an `asChild` snippet that spreads `props()` on one element. Child sizing,
fitting, borders, radius, and clipping remain up to the application.

In Solid, assign a ref to the element created inside the `asChild` render function. A ref on
`AspectRatio` itself is not forwarded through that composition path.

## Styling

### Styling hooks

| Part | `data-slot` |
| --- | --- |
| `AspectRatio` | `aspect-ratio-root` |

- `data-scope="aspect-ratio"` and `data-part="root"` are Ark-aligned hooks on the root.
- Put width, max-width, and layout styles on the root. Override `aspect-ratio` in your own CSS when the frame
  needs a different ratio at a particular breakpoint.
- The component does not style its children. Apply media sizing and `object-fit` directly to the child.
- Content taller than the frame does not stretch it; it overflows. Add `overflow: hidden` and a border radius to
  the root when the composition needs clipping.

## API reference

Also accepts the native props of its element and `asChild`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `ratio` | `number` | `1` | Width divided by height, for example `16 / 9`. |
