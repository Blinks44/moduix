## API Reference

Ark UI does not ship a dedicated `aspect-ratio` primitive. moduix builds this component with the official
[Ark factory](https://ark-ui.com/docs/guides/composition#the-ark-factory) and follows Ark's guidance for
[composition](https://ark-ui.com/docs/guides/composition), [styling](https://ark-ui.com/docs/guides/styling), and
[refs](https://ark-ui.com/docs/guides/ref).

## Basic

Use `AspectRatio` as the root for a responsive frame. It fills the width of its containing block by default.
Add `width` or `max-width` to the root when the frame needs a different size, then pass a finite, positive
number to `ratio`.

Direct `img`, `video`, `iframe`, `canvas`, and `svg` children fill the frame automatically. Other children are not
sized automatically, so add the styles they need. Set `object-fit` on images and videos when you want to crop
their content or contain it within the frame.

## Composition

### Recommended composition

Use `AspectRatio` for most media frames. Put width, border-radius, and layout classes on the root.
`AspectRatio.Root` exposes the same root under a namespace for consistency with the rest of the library.
The root also accepts the standard props supported for a `div` by the Ark factory.

- `ratio` is required and must be a finite number greater than zero. An invalid value throws a `RangeError`.
- `asChild` uses Ark factory composition and requires exactly one React element.
- Direct `img`, `video`, `iframe`, `canvas`, and `svg` children fill the frame automatically. Set `object-fit`
  on images and videos to choose whether their content is cropped or contained.
- Other children are not sized automatically. Add the styles they need for the frame.
- `className` applies styles and sizing directly to the root.
- `--moduix-aspect-ratio-radius` controls the frame's default corner radius.

### When to use a wrapper

Wrap `AspectRatio` in another element when shadows, focus rings, or decorative elements need to extend beyond
the clipped frame. Keep clipping on the root. If the frame needs a different ratio at a particular breakpoint,
override `aspect-ratio` in your CSS.

### Default props

| Entry                          | Default                   | Values / Notes                         |
| ------------------------------ | ------------------------- | -------------------------------------- |
| `ratio`                        | -                         | Required positive finite `number`      |
| `className`                    | `undefined`               | Applies styles and sizing to the root  |
| `style`                        | `undefined`               | Can override `aspect-ratio` directly   |
| `asChild`                      | `undefined`               | Ark factory composition                |
| Standard `div` props           | -                         | Forwarded to the rendered root         |
| `--moduix-aspect-ratio-radius` | `var(--moduix-radius-md)` | CSS length or token value              |

### Behavioral notes

- The root renders with `data-scope="aspect-ratio"`, `data-part="root"`, and
  `data-slot="aspect-ratio-root"`.
- The root is block-level and uses `box-sizing: border-box`, even when `asChild` changes which element is
  rendered.
- The forwarded `ref` points to the rendered root, or to the only child when `asChild` is used.
- `position: relative` on the root is intentional. It supports absolutely positioned children that fill the
  frame, such as Next.js `Image` with `fill`.
- Direct `iframe` children fill the frame without the browser's default border.
- The previous preset strings (`square`, `video`, `portrait`, `photo`) were removed during the Ark migration.
  Use numbers such as `1`, `16 / 9`, `9 / 16`, and `4 / 3`.

### Accessibility

`AspectRatio` is presentational. It does not add a role, manage state, or change the accessibility behavior of
its children. Use `asChild` with a semantic element such as `figure` when the content needs that structure.
Provide meaningful `alt` text for informative images and a `title` for embedded content such as an `iframe`.

### Styling hooks

- `data-scope="aspect-ratio"` and `data-part="root"` are Ark-aligned hooks on the root.
- `data-slot="aspect-ratio-root"` is the stable moduix root hook.
- Put width, max-width, and layout styles on the root. Override `aspect-ratio` in your own CSS when the frame
  needs a different ratio at a particular breakpoint.
- Direct media uses border-box sizing. Images and videos keep their own `object-fit` value, so you can choose
  between cropping and containment.
- `overflow: hidden` is intentional. If decoration must extend beyond the frame, put it on an outer wrapper
  instead of removing clipping from the root.
