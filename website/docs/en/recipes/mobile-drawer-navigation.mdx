## In a route

Replace the example anchors and dashboard content with your routes and data. Keep each navigation
link inside `Drawer.CloseTrigger` so a selection closes the mobile drawer automatically.

Use your router's Link through `asChild` when it must own navigation, and mark the current link with
`aria-current="page"`. Keep the trigger visible at mobile widths and provide the same destinations
in a persistent desktop header or [Sidebar dashboard](/recipes/sidebar-dashboard) at wider widths.
Do not render two focusable copies of the same navigation at one breakpoint.
