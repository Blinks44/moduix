## In a route

Render `ForgotPassword` in the route that owns password recovery and pass its real submit handler.
Replace the default `/sign-in` link with your application route.

While the request is pending, disable duplicate submission and change the button label to a clear
progress message. After the request finishes, show the same neutral confirmation whether or not the
email belongs to an account; this avoids exposing account membership. Keep rate-limit and network
errors near the form and let the user retry.
