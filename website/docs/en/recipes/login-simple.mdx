# Sign in

This recipe gives you a compact sign-in form with native browser validation, email and password
autocomplete, and links for account recovery and registration. It uses moduix `Card`, `Field`,
`Input`, `Checkbox`, and `Button` components. The recipe does not authenticate users or manage request
state. Connect those pieces to your application through `onSubmit`.

The live preview uses the React package. The source tabs show native React and Solid implementations that share the same stylesheet.

## Connect it to authentication

`LoginSimple` passes `onSubmit` to its native `<form>`. The handler receives the regular form event,
so call `event.preventDefault()`, read `new FormData(event.currentTarget)`, and send it to your API.
The form fields are named `email`, `password`, and `remember`; `remember` is included only when the
checkbox is checked.

## Production checklist

| Situation | What to do |
| --------- | ---------- |
| Request pending | Disable the submit button and prevent duplicate submissions while the request is in flight. |
| Invalid credentials | Show one form-level message without revealing which credential was incorrect. |
| Network error | Keep the entered email and offer a retry. Clear the password only when your security policy requires it. |
| Successful sign-in | Redirect to a safe route or replace the current history entry, according to your application flow. |

If your application accepts a `returnTo` or redirect URL, validate it on the server before navigating.
