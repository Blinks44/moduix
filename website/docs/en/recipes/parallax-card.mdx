# Parallax card

This recipe combines `CardBackground` with a small pointer handler and CSS transforms to create a
card with a full-bleed image and a subtle 3D tilt. It is a copy-ready application composition, not a
`ParallaxCard` component exported by moduix.

`CardBackground` places the image behind the card content. The gradient overlay and text contrast are
defined in the example CSS, so you can adjust them for the image you choose. The tilt effect is enabled
only when the device has a fine pointer that supports hover. The card stays still when that pointer is
unavailable or the user prefers reduced motion.

The live preview uses the React package. The source tabs show native React and Solid implementations that share the same stylesheet.

## Use the recipe in your application

Copy the component and CSS above into your application, then:

- Replace the image URL and visible copy with your content.
- Keep the image inside `CardBackground` decorative with `alt=""`. Use `CardMedia` when the image
  conveys information and needs alternative text.
- Treat the tilt as a visual enhancement. The card must remain readable and usable without hover or
  motion.
- Add a real link or button if the card has an action. Use `Card asChild` when the entire card is
  one link with no nested controls, or `CardLink` inside `CardTitle` when the card also contains
  separate actions.
