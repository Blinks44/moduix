`Sidebar` owns the collapse, keyboard resize, and collapsed-nav tooltips. The Projects item also
demonstrates nested navigation, and the footer includes a workspace menu.

## In a route

Replace the example anchors, labels, and dashboard content with your routes and data. This recipe is
desktop-first: account menus, notifications, and mobile drawer navigation remain separate recipes so
you can compose them only when your application needs them.

Mark the active destination with `aria-current="page"` and use router links through `asChild` where
the router must own navigation. Persist the collapsed width only when that preference helps returning
users; read browser storage after hydration and keep the default usable without it. Pair this desktop
shell with [Mobile drawer navigation](/recipes/mobile-drawer-navigation) instead of forcing the resizable
sidebar into a narrow viewport.
