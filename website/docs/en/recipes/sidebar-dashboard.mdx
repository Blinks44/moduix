Start a desktop workspace with a resizable navigation sidebar and a simple dashboard overview.
`Sidebar` handles collapsing, keyboard resizing, and labels for the collapsed navigation. The
Projects item also demonstrates nested navigation, and the footer contains a workspace menu.

## In a route

Replace the example links, labels, and dashboard content with your routes and data. This recipe
starts with a desktop layout, so adapt responsive navigation, account menus, and notifications to
your application.

Mark the active destination with `aria-current="page"`. Use router links through `asChild` when
the router should own navigation. Persist the collapsed width only when it helps returning users;
read browser storage after hydration and keep the default usable without it.
