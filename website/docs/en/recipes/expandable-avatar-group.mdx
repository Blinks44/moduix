# Expandable avatar group

Use this recipe for a small team roster when space is limited but people still need to be easy to
identify. Hover or focus an avatar to spread the group and show that person's name and role.

This is a copy-ready composition, not an `ExpandableAvatarGroup` component exported by
`@moduix/react`. It combines `Avatar` and `Tooltip`. Install those components, copy the source
and styles below, then replace the sample members with data from your application.

## Customize the recipe

Replace the sample `members` data with data from your application and keep the order stable. Use an
image URL from your application for each member. `Avatar.Fallback` shows initials while an image
loads or when it is unavailable.

The recipe renders each member as a native `button`. `Tooltip.Trigger asChild` lets the tooltip
reuse that button without adding another wrapper, while `Tooltip.Body` displays the member's name
and role. The button's `aria-label` includes both values because the image uses `alt=""` and the
tooltip is supplemental. Keep the tooltip content short and non-essential.

If selecting a member should navigate or perform an action, connect the button to that behavior or
replace it with the appropriate semantic control. Preserve the accessible name when changing the
trigger.

Use `role="group"` with a useful label for the roster. For a long team, show only the first few
members and add a final `+N` button that opens a complete, searchable people list.

The motion is CSS-only. The active button lifts slightly while the other buttons make room for it.
The included `prefers-reduced-motion: reduce` rule disables transition interpolation, so these
position changes happen immediately. If your accessibility policy also removes the position
changes, set the hover and focus transforms to `none` in that media query.
