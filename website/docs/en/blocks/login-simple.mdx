## Connect it to authentication

`LoginSimple` passes `onSubmit` to its native `<form>`. Read the fields with `FormData` and send
them to your API. The fields are named `email`, `password`, and `remember`; `remember` is sent only
when the box is checked.

links in the copied block.

## Production checklist

The block renders the form only. Handle these states in your route:

| Situation | What to do |
| --- | --- |
| Request pending | Disable submit and block duplicate requests while it runs. |
| Invalid credentials | Show one form message without saying which field was wrong. |
| Network error | Keep the entered email and offer a retry. |
| Signed in | Redirect to a validated route or replace the history entry. |
