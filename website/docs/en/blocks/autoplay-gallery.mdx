# Autoplay gallery

Use this block for featured content that advances automatically while keeping navigation within reach. It combines
`Carousel` with partially visible neighbouring slides, overlaid copy, arrow controls, and indicators that fill during
each autoplay interval.

The preview runs React. The source tabs contain React, Solid, and Vue implementations with a shared stylesheet.

## Use the block in your application

The copied block is ready to adapt:

- Replace the `slides` data with your own images, labels, titles, descriptions, and alternative text. Keep each
  `id` stable and keep `slideCount` in sync with `slides.length`.
- Update `aria-label` so it describes the purpose of your carousel, not the demo content.
- Keep `autoplay.delay` and the progress animation duration in sync. This block uses `3500` milliseconds and a `3.5s`
  CSS animation, so the indicator finishes filling as the next slide appears.
- Replace the Unsplash URLs before shipping the block. Use an image source that your application controls and that
  matches your loading, caching, and content requirements.

Adjust `slidesPerPage`, `spacing`, and `padding` to change how much of the neighbouring slide is visible and how the
gallery sits within its container.

## How it works

React and Solid read the carousel state through `CarouselContext`; Vue uses `useCarousel` with
`CarouselRootProvider`. The state identifies the active slide and supplies `pageSnapPoints` for the
progress indicators. Each indicator marks the current page with `data-current`.

Each indicator keeps `overflow: visible` so its transparent `::after` area can make the thin progress bar easier to
tap. The fill is a background on the indicator itself. Animating `background-size` keeps it inside the indicator’s
rounded outline throughout the interval.

Arrow and indicator clicks call `requestAnimationFrame(api.play)`. Manual navigation pauses autoplay, so starting it on
the next frame lets the page change finish before a fresh interval begins. Touch and horizontal wheel interaction pause
autoplay as well. If your product needs playback to resume after those interactions, add that behavior to your own
interaction flow or expose `CarouselAutoplayTrigger`.

Ark pauses autoplay while the document is hidden. The block listens for `visibilitychange` and calls the public
`api.play()` method when the document becomes visible again.

## Accessibility and motion

Keep an accessible name on the root with `aria-label` or `aria-labelledby`. Give meaningful images useful `alt` text;
use `alt=""` when an image is decorative and the adjacent slide copy already provides the information. Keep the
previous and next buttons and the indicators available so users do not have to wait for the timer.

The block removes slide transitions and the indicator animation when `prefers-reduced-motion: reduce` is active. The
autoplay timer still advances the carousel. If users need to stop automatic changes, add
`CarouselAutoplayTrigger` or remove the `autoplay` prop for that use case. See the [Carousel documentation](/docs/carousel)
for the autoplay controls and the full component API.
